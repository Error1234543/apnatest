🎯 પરીક્ષા ટ્રિક્સ

એલ્ડિહાઇડ/કેટોનમાં C=O બંધનો ધ્રુવીભાવ યાદ રાખો: O વધુ વિદ્યુતોણ હોવાથી δ− અને C δ+ થાય છે. આથી ન્યુક્લિયોફિલિક ઉમેરામાં હંમેશા ન્યુક્લિયોફિલ (Nu−) C પર હુમલો કરે છે. આ સિદ્ધાંત પરથી આઇસોમારાઈઝેશન પ્રક્રિયાઓ ઝડપથી ઉકેલી શકાય.
જ્યારે પ્રશ્નમાં ન્યુક્લિયોફિલિક ઉમેરાની દિશા અથવા મુખ્ય ઉત્પાદન પૂછવામાં આવે, ખાસ કરીને NaBH₄/LiAlH₄ સાથે.
દા.ત.: CH₃CHO + NaBH₄ → CH₃CH₂OH (એસિટાલડિહાઇડનું રિડક્શન) -- C=O પર Nu− હુમલો, NaBH₄ માંથી H− આવે છે.
Cannizzaro પ્રક્રિયા માટે ઝડપી ચકાસણી: જે એલ્ડિહાઇડમાં α-હાઇડ્રોજન નથી (જેમ કે HCHO, C₆H₅CHO), Cannizzaro થાય; જો α-H હોય તો Aldol થાય. આથી બે-ચરણીઓમાં જવાબ મળી જાય.
જ્યારે પ્રશ્નમાં aldol vs cannizzaro પ્રક્રિયા પસંદગી પૂછવામાં આવે. માત્ર α-હાઇડ્રોજનની ગણતરી કરો.
દા.ત.: C₆H₅CHO (બેન્ઝાલડિહાઇડ) માં α-C પર કોઈ H નથી → Cannizzaro. CH₃CHO માં α-C પર 3 H છે → Aldol.
કાર્બોક્સિલિક એસિડના આమ్લધર્મ ક્રમ યાદ રાખવાની ટૂંકી રીત: EWG (+M/−I) = એસિડ વધુ પ્રબળ, EDG (−M/+I) = એસિડ દુર્બળ. NO₂ અને Cl એસિટિક એસિડ કરતાં પ્રબળ બનાવે છે; CH₃ દુર્બળ બનાવે છે.
જ્યારે વિવિધ ક્ષારો/ઉપયોગી રાસાયણિકોના આમ્લપણાનું અનુક્રમણિકા પૂછાય.
દા.ત.: HCOOH > CH₃COOH > C₆H₅COOH > (CH₃)₂CHCOOH (ક્રમ ઘટતો આમ્લપણ: હેટરોજન > મીથેનોઇક > બેન્ઝોઇક > સમૂહક જથ્થા) -- વધુ α-શૃંખલા +I બળતા એસિડ દુર્બળ.
Tollens અને Fehling વચ્ચે તફાવતની ઝડપી યાદવણી: Tollens હંમેશા એલ્ડિહાઇડ ઓક્સિડાઇઝ કરે છે (Ag⁺ → Ag, આરસીન સ્પષ્ટ), Fehling માત્ર અલિપિડ એલ્ડિહાઇડ (જેમ કે aliphatic) ઓક્સિડાઇઝ કરે, એરોમેટિક એલ્ડિહાઇડ (જેમ કે benzaldehyde) Nottellens દ્વારા પણ ઓક્સિડાઇઝ થાય પણ Fehling સાથે નહીં.
અલગઅલગ ઓળખ પરીક્ષણો પર આધારિત પ્રશ્નોમાં જ્યાં two tests ઉલ્લેખિત હોય.
દા.ત.: Fehling solution: HCHO, CH₃CHO → red ppt. C₆H₅CHO → no reaction (aromatic). Tollens: both give silver mirror.
સેમીએકલ / એસિટાલ બનાવતી પ્રક્રિયામાં રસાયણશાસ્ત્રીય સંતુલન: ડાયોલ + carbonyl → cyclic acetal/hemiacetal. બે OH એક જ carbon પર હોય (1,2- या 1,3- diol) → cyclic five/six-membered ring બનશે. NEET માં ethylene glycol સાથે protection જોવા મળે છે.
જ્યારે carbonyl compound + diol સાથે reactant પૂછવામાં આવે. Ring size 5 (1,2-diol) અથવા 6 (1,3-diol) સ્પષ્ટ.
દા.ત.: CH₃CHO + HOCH₂CH₂OH (ethylene glycol, cat. H⁺) → 1,3-dioxolane (5-membered cyclic acetal). Ethylene glycol 1,2-diol હોવાથી 5-membered ring બને.
Haloform પ્રક્રિયા માટે ઝડપી યાદવણી: CH₃–CO–(કોઈ પણ group) > halogenation સાથે સરળતાથી. જો જોડાણમાં CH₃CO– અથવા CH₃CH(OH)– હોય, તો +X₂/NaOH → CHI₃ (પીળો અવક્ષેપ) + carboxylate. આથી 4 carbons વાળા ketone માટે પણ જવાબ ઝડપી મળે.
જ્યારે haloform reaction પૂછવામાં આવે અથવા iodoform test દ્વારા અલગ કરવાની ક્રિયા પૂછવામાં આવે.
દા.ત.: CH₃COCH₃ + 3I₂ + 4NaOH → CHI₃ (pallido yellow) + CH₃COONa + 3NaI + 3H₂O. પ્રશ્નમાં 'compound with CH₃CH(OH)–' → positive iodoform.
એસિડ ડિરિવેટિવ્સની પ્રતિક્રિયાશીલતા ક્રમ યાદ રાખો: Acyl chloride > Anhydride > Ester > Amide. આ ક્રમમાંથી ન્યુક્લિયોફિલિક સ્થાનાંતરણ પ્રક્રિયાઓમાં કયો ડેરિવેટિવ કયામાંથી બનશે તે સહેજે નક્કી કરી શકાય.
જ્યારે esterification, amidation, hydrolysis પ્રકારના પ્રશ્નોમાં પ્રતિક્રિયા દિશા નક્કી કરવી હોય.
દા.ત.: RCOCl + R'OH → RCOOR' (ester, ઝડપી); RCOOCH₃ + NH₃ → RCONH₂ (amidel) -- પણ reverse (amide → acid chloride) શક્ય નથી કારણ કે amide ઓછું પ્રતિક્રિયાશીલ છે.
Carbonyl compound ના nomenclature માટે: -al (醛), -one (કેટોન), -oic acid (એસિડ). NEET માં સામાન્ય રીતે trivial નામો આવે છે -- formic acid = HCOOH, acetic acid = CH₃COOH, benzoic acid = C₆H₅COOH યાદ રાખો, આમણે પ્રશ્ન સાથે ઝડપી મેળવો.
જ્યારે IUPAC નામ અથવા સંಯોજન ઓળખ પ્રશ્ન હોય.
દા.ત.: HCOOH = મીથેનોઇક એસિડ (formic acid), CH₃COOH = એથેનોઇક એસિડ (acetic acid), C₆H₅CHO = બેન્ઝાલડિહાઇડ.
Aldol condensation અને Cross-Aldol વચ્ચેનો તફાવત: Aldol માટે બંને carbonyl compounds માં α-H હોવું જોઈએ. જો એક પણ α-H ન ધરાવતું હોય (જેમ કે benzaldehyde), cross-aldol શક્ય છે પણ Cannizzaro જો બંને α-H ધરાવતું ન હોય.
જ્યારે cross-aldol vs Cannizzaro ચોકસાઈથી તફાવત કરવાનો પ્રશ્ન આવે.
દા.ત.: C₆H₅CHO (no α-H) + CH₃CHO (α-H present) → Cross-Aldol. C₆H₅CHO + HCHO → Cannizzaro (both have no α-H).
કાર્બોક્સિલિક એસિડના ઉત્પાદન માટે ઝડપી વિચાર: CN⁻ + KOH(aq) + H⁺ → carboxylic acid (nitrile hydrolysis). આથી R–Br → R–CN → RCOOH આગળ જઈ શકાય, 1 carbon વધુ મળે છે. આ પ્રક્રિયા માત્ર CN⁻ હોય તો અનુક્રમે ઉત્પાદન 1C વધે છે.
જ્યારે conversion પ્રકારના પ્રશ્નમાં carbon chain length વધારવાનું હોય.
દા.ત.: CH₃CH₂Br + KCN → CH₃CH₂CN → H₃O⁺/Δ → CH₃CH₂COOH (propionic acid). EtBr → Propionic acid, 1C addition જોવા મળે.
Benzene ringsવાળા carbonyl compounds માટે: C₆H₅COOH (benzoic acid), C₆H₅CHO (benzaldehyde), C₆H₅COCH₃ (acetophenone). Benzaldehyde → Cannizzaro (no α-H), Acetophenone → Aldol (α-H presence on methyl). આ ટૂંકી યાદવણીથી fast answer મળે.
જ્યારે benzene-based carbonyl compound ના properties અથવા reactions પૂછવામાં આવે.
દા.ત.: C₆H₅CHO → Cannizzaro, C₆H₅COCH₃ → Aldol (methyl group gives α-H).
Decarboxylation પ્રક્રિયા: soda-lime (NaOH/CaO) સાથે heating -> CO₂ બહાર નીકળે. Carboxylate saltનું sodium સાથે heating -> alkane મળે (એક carbon ઓછું). Kolbe's electrolysis માં પણ CO₂ + alkane મળે છે.
જ્યારે carboxylic acid → alkane conversion અથવા gas evolution પ્રકારના પ્રશ્નો હોય.
દા.ત.: CH₃COONa + NaOH/CaO (heat) → CH₄ + Na₂CO₃. Acetate થી methane મળે, 1C ઘટે છે.
સ્ટીરીયોકેમિસ્ટ્રી યાદ રાખો: Carboxylic acids માં −COOH કાર્બન sp² હોય છે (trigonal planar). આથી આમ્લિક પ્રોટોન (H⁺) છૂટો થાય છે. આ ભૌમિતિક બંધારણ યાદ રાખો, એટલે resonance structure સમજી શકાય.
જ્યારે hybridization અને geometry પૂછવામાં આવે અથવા resonance structure દોરવાનો પ્રશ્ન હોય.
દા.ત.: CH₃COOH: both O અਤੇ C sp², bond angle ≈ 120°, carboxylate anion સપાટ (planar) due to resonance stabilization.
એસિડ એનહેડ્રાઇડ (Anhydride) formation: બે એકસરખા carboxylic acid molecules dehydration -> anhydride. જો different acid હોય, mixed anhydride બને. NEET માં acetic anhydride (CH₃CO)₂O ખૂબ જ સામાન્ય છે -- ethanoic anhydride.
જ્યારે acetic anhydride અથવા anhydride પ્રક્રિયાઓ પૂછવામાં આવે.
દા.ત.: 2CH₃COOH —(P₂O₅/heat)→ (CH₃CO)₂O + H₂O. (CH₃CO)₂O = ethanoic anhydride.
Grignard reagent + carbonyl: Grignard + HCHO → primary alcohol (1C addition). Grignard + aldehyde → secondary alcohol. Grignard + ketone → tertiary alcohol. Grignard + CO₂ → carboxylic acid. આ ચાર-ચાર જોડણી યાદ રાખો, NEET માં 70% પ્રશ્નો આમાંથી આવે છે.
જ્યારે Grignard પ્રક્રિયાઓ પર પ્રશ્ન આવે, ખાસ કરી产物 prediction પ્રશ્નોમાં.
દા.ત.: CH₃MgBr + HCHO → CH₃CH₂OH (primary). CH₃MgBr + CH₃CHO → CH₃CH(OH)CH₃ (secondary). CH₃MgBr + CH₃COCH₃ → (CH₃)₃COH (tertiary). CH₃MgBr + CO₂ → CH₃COOH.
