📄 Short Notes

એલ્ડિહાઇડ્સ, કેટોન્સ અને કાર્બોક્સિક એસિડ — ઝટપટ પુનરાવર્તન

🩺 NEET UG — Gujarati • Chemistry • Aldehydes, Ketones and Carboxylic Acids

📘 વ્યાખ્યાઓ

  • એલ્ડિહાઇડ: કાર્બોનિલ સમૂહ (−CHO) ધરાવતી સંયોજન જેમાં કાર્બોનિલ C એ હાઇડ્રોજન સાથે જોડાયેલું હોય છે.
  • કેટોન: કાર્બોનિલ સમૂહ (C=O) ધરાવતી સંયોજન જેમાં કાર્બોનિલ C બે કાર્બન સાથે જોડાયેલું હોય છે.
  • કાર્બોક્સિક એસિડ: −COOH (કાર્બોક્સિલ) સમૂહ ધરાવતી સંયોજન; રચના H−O−C(=O)−R.
  • ઍલ્ડોલ: બે સમાન અથવા ભિન્ન એલ્ડિહાઇડ/કેટોન અણુઓના ન્યુક્લિયોફિલિક ઉમેરાથી મળતું β-હાઇડ્રોક્સિ એલ્ડિહાઇડ/કેટોન.
  • ઇમાઇન (શિફ્બેઝ): C=N બંધ ધરાવતું સંયોજન, જે એલ્ડિહાઇડ/કેટોન + પ્રાથમિક એમાઇનના ઉમેરાથી બને છે.
  • એસિડ ક્લોરાઇડ: કાર્બોક્સિક એસિડનો દહિત, RCOCl, જ્યાં −OH ને −Cl બદલાયેલો હોય છે.
  • એસ્ટર: કાર્બોક્સિક એસિડ અને આલ્કોહોલ વચ્ચેના એસ્ટરીકરણથી બનતું સંયોજન, RCOOR'.
  • અમોડ: કાર્બોક્સિક એસિડના એમાઇડ સાથેના પ્રતિસ્થાપનથી બનતું સંયોજન, RCONH₂.

⚡ સૂત્રો

  • CₙH₂ₙO — એલ્ડિહાઇડ અને કેટોનનો સામાન્ય સૂત્ર.
  • CₙH₂ₙO₂ — સંતૃપ્ત મોનોકાર્બોક્સિક એસિડનો સામાન્ય સૂત્ર.
  • કાર્બોક્સિલેટ આયન: RCOO⁻ — પ્રત્યાહનીકરણથી સ્થિરતા.
  • pKa(HCOOH) ≈ 3.75; CH₃COOH ≈ 4.76; ClCH₂COOH < CH₃COOH (ઇલેક્ટ્રોન ખેંચતો –I દળ).
  • Tollens પ્રક્રિયા: RCHO + 2[Ag(NH₃)₂]⁺ + 3OH⁻ → RCOO⁻ + 2Ag↓ + 4NH₃ + 2H₂O.
  • Fehling પ્રક્રિયા: RCHO + Cu²⁺ + 5OH⁻ → RCOO⁻ + Cu₂O↓ + 3H₂O.
  • આઇડોફોર્મ: CH₃COR + 3I₂ + 4NaOH → CHI₃↓ + RCOONa + 3NaI + 3H₂O.
  • એમોડ રિડક્શન: RCONH₂ + LiAlH₄ → RCH₂NH₂ (પ્રાથમિક એમાઇડ).
  • Stein પ્રક્રિયા: RNC + 2H₂O/H⁺ → RCOOH + NH₄⁺.

⭐ મુખ્ય તથ્યો

  • એલ્ડિહાઇડ્સ/કેટોન્સમાં ketyl આયન (•C–O⁻) જેવા મુક્ત મૂલક બને છે.
  • આલ્ફા H ધરાવતી એલ્ડિહાઇડ/કેટોન ફક્ત ઍલ્ડોલ સંઘનન આપે છે.
  • કેવીએલ પ્રક્રિયા: બે સમાન કાર્બોક્સિક એસિડના તેજસ્વી વિદ્યુતવિભાજનથી એલ્કેન બને છે.
  • HCHO (મધ્યસ્થ એલ્ડિહાઇડ) ઍલ્ડોલ આપતું નથી પણ કેન્નીઝારો આપે છે.
  • એસિડ ક્લોરાઇડની પ્રક્રિયાશીલતા: RCOCl > (RCO)₂O > RCOOR' > RCONH₂.
  • ગ્રિગ્નર્ડ પ્રતિભાવ: R-MgX + CO₂ → RCOO⁻MgX⁺ → H₃O⁺ → RCOOH.
  • Nitrile (CN) નું અર્ધજળવિભાજન → એમાઇડ; પૂર્ણ જળવિભાજન → કાર્બોક્સિક એસિડ.
  • એસિલિયમ આયન (Acylium ion): R−C≡O⁺, એલ્ડિહાઇડ/કેટોનની તૈયારીમાં મધ્યસ્થી.
  • અમોડનું Hoffmann બ્રોમો અવચયન: RCONH₂ + Br₂ + 4NaOH → RNH₂ + Na₂CO₃ + 2NaBr + 2H₂O.
  • Hinsberg પરીક્ષણ: પ્રાથમિક, દ્વિતીયક, તૃતીયક એમાઇડ પૃથક્કરણ માટે.
  • એસિડ એનહાઇડ્રાઇડ: 2RCOOH → (RCO)₂O + H₂O (P₂O₅ ઉપસ્થિતિએ).

⚠️ સામાન્ય ભૂલો

  • તમામ એલ્ડિહાઇડ Tollens/Fehling આપે છે પણ ફોર્માલ્ડિહાઇડ બંને આપે છે; મધ્યસ્થ એલ્ડિહાઇડ ધ્યાનમાં લો.
  • ફેનૉલ કાર્બોક્સિક એસિડ કરતાં ઓછું તાકાતવર છે; CH₃COOH > H₂CO₃ > C₆H₅OH > C₂H₅OH.
  • કેટોન ટોલેન્સ પ્રક્રિયા આપે છે (ખોટું); ફક્ત એલ્ડિહાઇડ આપે છે.
  • આલ્ડોલ પરિણામ β-હાઇડ્રોક્સિ એલ્ડિહાઇડ છે, α,β-અસંતૃપ્ત એલ્ડિહાઇડ નહીં — વિભિન્નતા યાદ રાખો.
  • એસિડ એનહાઇડ્રાઇડના નામમાં 'એનહાઇડ્રાઇડ' મૂકવો, 'એસ્તર' નહીં.
  • Rosenmund રિડક્શન (Pd/BaSO₄ + S) એક્લ RCOCl → RCHO; આ RCOOH → RCHO નથી.
  • Stephen પ્રક્રિયા: RNC ને SnCl₂/HCl થી RCHO મળે; RNO₂ નથી.
  • ઍલ્કોહોલનું આક્સિડેશન: પ્રાથમિક → એલ્ડિહાઇડ (PCC); પુનરાવર્તી → એસિડ (KMnO₄).
  • કેટલાક એસિડ (Oxalic, Malonic) વીજ્ઞાસી ગરમીએ CO₂ છોડે છે; યાદ રાખો.
  • Friedel-Crafts એસિલેશનમાં RCOCl + AlCl₃ → Acylium ion બને; સીધું સંયોજન નહીં.
  • Haloform પ્રક્રિયા માટે CH₃−C=O (અથવા CH₃CH(OH)−) જરૂરી છે — CH₃− જોકે C=O વિના તે આપે છે?
  • એમાઇડનું જળવિભાજન: RCONH₂ + H₂O → RCOOH + NH₃ (ઉષ્મા/એસિડથી).

🔥 હાઈ-યીલ્ડ મુદ્દા

  • Nucleophilic addition priority: δ⁺C=O → Nu⁻ ઉમેરો; tetrahedral intermediate સ્પષ્ટ રાખો.
  • એલ્ડિહાઇડ્સ > કેટોન્સ ન્યુક્લિયોફિલિક ઉમેરામાં પ્રતિક્રિયાશીલ — સ્ટેરિક + ઇલેક્ટ્રોનિક.
  • Cannizzaro: α-H વિનાના એલ્ડિહાઇડ (ફોર્માલ્ડિહાઇડ, benzaldehyde) strong base માં disproportionation આપે.
  • ઍલ્ડોલ કન્ડેન્સેશન: dilute OH⁻ + α-H ધરાવતો અણુ → β-hydroxy then dehydration → α,β-unsaturated carbonyl.
  • Carbocation stability order: CH₃⁺ < 1° < 2° < 3° → આ અનુक्रम એસિડ પ્રબળતામાં પણ લાગુ.
  • Haloform reaction specificity: only methyl ketone or compounds with CH₃−CH(OH)− give yellow CHI₃.
  • Amide stability vs acyl chloride: acyl chloride 가장 reactive, amide સૌથી ઓછું પ્રતિક્રિયાશીલ.
  • Electron-withdrawing groups (−NO₂, −Cl) carboxylic acid પ્રબળતા વધારે; e-donating (−CH₃) ઘટાડે.
  • Esterification (Fischer): RCOOH + R'OH ⇌ RCOOR' + H₂O (conc. H₂SO₄ catalyst, reflux).
  • Acid derivatives interconversion: acyl chloride → ester/amide/anhydride via nucleophilic substitution.
  • LiAlH₄ reduces all carbonyls (aldehyde/ketone/acid/ester/amide) to alcohols/amines; milder NaBH₄ selective.
