Q1. ઓક્સિડેશન (Oxidation) પ્રક્રિયા દરમિયાન પરમાણુ કે આયન સાથે શું થાય છે?
A. ઈલેક્ટ્રોનનો લાભ થાય છે
B. ઈલેક્ટ્રોનનો અપભ્રંશ થાય છે
C. પ્રોટોનનો અપભ્રંશ થાય છે
D. ન્યુટ્રોનનો લાભ થાય છે
✅ B — ઓક્સિડેશન એટલે ઈલેક્ટ્રોન ગુમાવવાની પ્રક્રિયા. જ્યારે કોઈ પરમાણુ કે આયન એક કે એકથી વધુ ઈલેક્ટ્રોન મુક્ત કરે છે, તો તેની ઓક્સિડેશન અવસ્થા વધે છે.
Q2. રિડક્શન (Reduction) પ્રક્રિયાની સાચી વ્યાખ્યા કઈ છે?
A. ઈલેક્ટ્રોનનો લાભ
B. ઈલેક્ટ્રોનનો અપભ્રંશ
C. આકર્ષણ બળ વધવું
D. તટસ્થીકરણ પ્રક્રિયા
✅ A — રિડક્શન એટલે ઈલેક્ટ્રોન મેળવવાની પ્રક્રિયા. ઈલેક્ટ્રોન પ્રાપ્ત થતાં પરમાણુ કે આયનની ઓક્સિડેશન અવસ્થા ઘટે છે.
Q3. નીચેનામાંથી કઈ પ્રક્રિયા ઓક્સિડેશન-રિડક્શન (Redox) પ્રક્રિયા દર્શાવે છે?
A. Zn + Cu²⁺ → Zn²⁺ + Cu
B. Na⁺ + Cl⁻ → NaCl
C. H⁺ + OH⁻ → H₂O
D. AgNO₃ → Ag + NO₃
✅ A — આ પ્રક્રિયામાં Zn ઈલેક્ટ્રોન ગુમાવી Zn²⁺ બને છે (ઓક્સિડેશન), જ્યારે Cu²⁺ ઈલેક્ટ્રોન મેળવી Cu બને છે (રિડક્શન). તેથી તે રેડોક્સ પ્રક્રિયા છે.
Q4. KMnO₄ માં મેંગેનીઝ (Mn) ની ઓક્સિડેશન અવસ્થા કેટલી છે?
A. +7
B. +5
C. +3
D. 0
✅ A — K ની ઓક્સિડેશન અવસ્થા +1 અને O ની -2 લેતાં, KMnO₄ માં: (+1) + Mn + 4(-2) = 0 ⇒ Mn = +7.
Q5. ઓક્સિડેશન એજન્ટ (Oxidising agent) શું કરે છે?
A. અન્ય પદાર્થને ઓક્સિડાઈઝ કરે છે અને પોતે રિડ્યુસ થાય છે
B. અન્ય પદાર્થને રિડ્યુસ કરે છે અને પોતે ઓક્સિડાઈઝ થાય છે
C. ઈલેક્ટ્રોન આપે છે
D. પ્રોટોન મુક્ત કરે છે
✅ A — ઓક્સિડેશન એજન્ટ બીજા પદાર્થને ઈલેક્ટ્રોન દૂર કરી ઓક્સિડાઈઝ કરે છે, જ્યારે તે પોતે ઈલેક્ટ્રોન મેળવી રિડ્યુસ થાય છે.
Q6. નીચેમાંથી કયા સંયોજનમાં સલ્ફર (S) ની ઓક્સિડેશન અવસ્થા (Oxidation state) સૌથી વધુ છે?
A. H2S
B. SO2
C. H2SO4
D. S8
✅ C — H2SO4 માં S ની ઓક્સિડેશન અવસ્થા +6 છે, જે આપેલા વિકલ્પોમાં સૌથી વધુ છે. H2S માં -2, SO2 માં +4 અને S8 (મૂળ તત્વ) માં 0 હોય છે.
Q7. Cr2O7^{2-} આયનનું Cr^{3+} માં રિડક્શન થાય ત્યારે ક્રોમિયમ (Cr) ની ઓક્સિડેશન અવસ્થામાં કેટલો ફેરફાર થાય છે?
A. 1 એકમ વધે છે
B. 3 એકમ ઘટે છે
C. 6 એકમ ઘટે છે
D. 3 એકમ વધે છે
✅ B — Cr2O7^{2-} માં દરેક Cr ની ઓક્સિડેશન અવસ્થા +6 હોય છે અને Cr^{3+} માં તે +3 હોય છે. આમ, દરેક Cr પરમાણુની ઓક્સિડેશન અવસ્થા 3 એકમ ઘટે છે (રિડક્શન).
Q8. નીચેમાંથી કઈ પ્રક્રિયા ડિસ્પ્રોપોર્શનેશન (Disproportionation) પ્રક્રિયા છે?
A. Zn + Cu^{2+} -> Zn^{2+} + Cu
B. 2H2O2 -> 2H2O + O2
C. AgNO3 + NaCl -> AgCl + NaNO3
D. CaCO3 -> CaO + CO2
✅ B — હાઇડ્રોજન પેરાઑક્સાઇડ (H2O2) ની વિઘટન પ્રક્રિયામાં ઓક્ટોજનની ઓક્સિડેશન અવસ્થા -1 માંથી -2 (H2O માં) અને 0 (O2 માં) બને છે. એક જ તત્વ એકસાથે ઓકસિડાઈ અને રિડ્યુઝ થાય છે, તેથી આ ડિસ્પ્રોપોર્શનેશન પ્રક્રિયા છે.
Q9. આસિડિક માધ્યમમાં MnO4^- નું Mn^{2+} માં રિડક્શન થાય છે. આ પ્રક્રિયામાં MnO4^- નો n-ફેક્ટર (n-factor) કેટલો છે?
A. 1
B. 3
C. 5
D. 7
✅ C — MnO4^- માં Mn ની ઓક્સિડેશન અવસ્થા +7 છે અને Mn^{2+} માં તે +2 થાય છે. ઓક્સિડેશન અવસ્થામાં 5 એકમનો ઘટાડો થાય છે, તેથી n-ફેક્ટર 5 છે.
Q10. સાચા વિધાનનું પસંદગી કરો:
A. ઓક્સિડેશન એજન્ટ રિડ્યુસ થાય છે.
B. રિડક્શન એજન્ટ ઓક્સિડ થાય છે.
C. ઓક્સિડેશન અને રિડક્શન એકબીજા વિના સ્વતંત્ર રીતે થઈ શકે છે.
D. ઓક્સિડેશન પ્રક્રિયામાં ઈલેક્ટ્રોન મળે છે.
✅ B — રિડક્શન એજન્ટ (પ્રતિક્ષાપક) પોતે ઓક્સિડાઈને બીજા પદાર્થનું રિડક્શન કરે છે. વિધાન A ખોટું છે કારણ કે ઓક્સિડેશન એજન્ટ પોતે રિડ્યુઝ થાય છે. વિધાન C ખોટું છે કારણ કે લોકેડોક્સ પ્રક્રિયાઓ સાથે જ થાય છે. વિધાન D ખોટું છે કારણ કે ઓક્સિડેશનમાં ઈલેક્ટ્રોન ગુમાવવામાં આવે છે.
Q11. H2O2 ના વિઘટન પ્રક્રિયામાં (MnO2 ઉપસ્થિતિમાં), ઓક્સિજનની ઓક્સિડેશન સંખ્યામાં કયો ફેરફાર થાય છે?
A. -1 માંથી 0 અને -2
B. 0 માંથી +1 અને -1
C. +1 માંથી 0 અને -1
D. -2 માંથી 0 અને -1
✅ A — H2O2 માં ઓક્સિજનની ઓક્સિડેશન સંખ્યા -1 છે. વિઘટન દરમ્યાન તે ઓક્સિજન ગેસ (O2, 0) અને પાણી (H2O, -2) બનાવે છે, તેથી ઓક્સિડેશન સંખ્યા -1 માંથી 0 અને -2 તરફ બદલાય છે.
Q12. 0.1 M KMnO4 ના 20.0 mL દ્રાવણ સાથે સંપૂર્ણ પ્રક્રિયા કરવા માટે 0.2 M FeSO4 ના કેટલા કદની જરૂર પડશે? (અમ્લીય માધ્યમમાં MnO4^- નું Mn^{2+} માં રિડક્શન થાય છે.)
A. 10 mL
B. 20 mL
C. 50 mL
D. 100 mL
✅ C — અમ્લીય માધ્યમમાં સંતુલિત પ્રક્રિયા: MnO4^- + 5Fe^{2+} + 8H^+ -> Mn^{2+} + 5Fe^{3+} + 4H2O. 1 mol KMnO4, 5 mol Fe^{2+} ને ઓક્સિડાઈઝ કરે. n(KMnO4) = 0.1 × 0.020 = 0.002 mol, તેથી n(Fe^{2+}) = 0.010 mol. V(FeSO4) = 0.010 / 0.2 = 0.050 L = 50 mL.
Q13. IO3^- આયનનું I^- માં રિડક્શન થાય છે. આ પ્રક્રિયામાં કેટલા ઇલેક્ટ્રોનનો સ્વીકાર થાય છે?
A. 3
B. 5
C. 6
D. 8
✅ C — IO3^- માં આયોડિન (I) ની ઓક્સિડેશન સંખ્યા +5 છે અને I^- માં તે -1 છે. ઓક્સિડેશન સંખ્યામાં ઘટાડો 6 થાય છે, તેથી દરેક IO3^- આયન 6 ઇલેક્ટ્રોન સ્વીકારે છે.
Q14. 2S2O3^{2-} + I2 -> S4O6^{2-} + 2I^- ો પ્રક્રિયામાં, 2 mol S2O3^{2-} દ્વારા કેટલા mol ઇલેક્ટ્રોન દેવામાં આવે છે?
A. 1
B. 2
C. 3
D. 4
✅ A — થાયોસલ્ફેટ (S2O3^{2-}) માં સલ્ફરની સરેરાશ ઓક્સિડેશન સંખ્યા +2 છે અને ટેટ્રાથાયોનેટ (S4O6^{2-}) માં તે +2.5 છે. દરેક સલ્ફર પરમાણુ 0.5 e^- ગુમાવે છે. 2 mol S2O3^{2-} માં 2 mol S હોય છે, તેથી કુલ 1 mol e^- દેવામાં આવે છે.
Q15. નીચેમાંથી કઈ પ્રક્રિયા ડિસપ્રોપોર્શનેશન (Disproportionation) પ્રક્રિયા નથી?
A. 2H2O2 -> 2H2O + O2
B. Cl2 + 2NaOH -> NaCl + NaClO + H2O
C. 3NO2 + H2O -> 2HNO3 + NO
D. 2KClO3 -> 2KCl + 3O2
✅ D — ડિસપ્રોપોર્શનેશન પ્રક્રિયામાં એક જ તત્વની ઓક્સિડેશન સંખ્યા એકસાથે વધે છે અને ઘટે છે. KClO3 ના વિઘટનમાં, Cl ની ઓક્સિડેશન સંખ્યા +5 માંથી -1 થાય છે (રિડક્શન) અને O ની -2 માંથી 0 થાય છે (ઓક્સિડેશન). આ આંતર-અણુ રેડોક્સ પ્રક્રિયા છે, ડિસપ્રોપોર્શનેશન નથી.
Q16. નીચેમાંથી કયો તત્વ ઓક્સિડેશન અને રિડક્શન બંને કરી શકે છે?
A. સોડિયમ (Na)
B. હાઇડ્રોજન (H₂)
C. કેલ્શિયમ (Ca)
D. મેગ્નેશિયમ (Mg)
✅ B — હાઇડ્રોજન (H₂) ઓક્સિડેશન અને રિડક્શન બંને પ્રક્રિયાઓમાં ભાગ લઈ શકે છે. ઉદાહરણ તરીકે, H₂ + Cl₂ → 2HClમાં તે ઓક્સિડાઇઝ થાય છે, જ્યારે CuO + H₂ → Cu + H₂Oમાં તે રિડ્યુસ કરે છે.
Q17. નીચેમાંથી કયો આયન સૌથી મજબૂત ઓક્સિડાઇઝિંગ એજન્ટ છે?
A. F⁻
B. Cl⁻
C. MnO₄⁻
D. SO₄²⁻
✅ C — MnO₄⁻ (પરમેંગેનેટ આયન) એ અત્યંત મજબૂત ઓક્સિડાઇઝિંગ એજન્ટ છે, ખાસ કરીને આસિડિક માધ્યમમાં, જ્યાં તે Mn²⁺માં રિડ્યુસ થાય છે.
Q18. રેડોક્સ પ્રક્રિયામાં, ઓક્સિડેશન નંબરમાં થતો ફેરફાર કયો હોય છે?
A. ઓક્સિડેશન નંબરમાં વધારો અથવા ઘટાડો
B. ઓક્સિડેશન નંબરમાં ફક્ત વધારો
C. ઓક્સિડેશન નંબરમાં ફક્ત ઘટાડો
D. ઓક્સિડેશન નંબરમાં કોઈ ફેરફાર નહીં
✅ A — રેડોક્સ પ્રક્રિયામાં, ઓક્સિડેશન નંબરમાં વધારો (ઓક્સિડેશન) અથવા ઘટાડો (રિડક્શન) થાય છે. ઓક્સિડેશનમાં ઇલેક્ટ્રોન ગુમાવવામાં આવે છે, જ્યારે રિડક્શનમાં ઇલેક્ટ્રોન મેળવવામાં આવે છે.
Q19. નીચેમાંથી કયા યોગિકમાં સલ્ફરની ઓક્સિડેશન અવસ્થા +4 છે?
A. H₂S
B. SO₂
C. SO₃
D. H₂SO₄
✅ B — SO₂ (સલ્ફર ડાયોક્સાઇડ)માં સલ્ફરની ઓક્સિડેશન અવસ્થા +4 હોય છે. H₂Sમાં તે -2, SO₃માં +6, અને H₂SO₄માં પણ +6 હોય છે.
Q20. નીચેમાંથી કયો પ્રક્રિયા રેડોક્સ પ્રક્રિયાનું ઉદાહરણ નથી?
A. 2H₂ + O₂ → 2H₂O
B. NaOH + HCl → NaCl + H₂O
