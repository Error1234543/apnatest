Q1. રિડક્શન પ્રક્રિયામાં ઓક્સિડેશન નંબરમાં શું થાય છે?
A. વધારે છે
B. ઘટે છે
C. અચળ રહે છે
D. શૂન્ય થાય છે
✅ B — રિડક્શન પ્રક્રિયામાં ઇલેક્ટ્રોન મેળવવાથી ઓક્સિડેશન નંબર ઘટે છે.
Q2. ઓક્સિડેશન નંબરની ગણતરી માટે નીચેનામાંથી કયો નિયમ ખોટો છે?
A. મુક્ત અવસ્થામાં તત્ત્વનું ઓક્સિડેશન નંબર શૂન્ય હોય છે.
B. આયનમાં આયનિક ચાર્જ એ જ તેનું ઓક્સિડેશન નંબર હોય છે.
C. હાઇડ્રોજનનું ઓક્સિડેશન નંબર હંમેશા +1 હોય છે.
D. ઓક્સિજનનું ઓક્સિડેશન નંબર હંમેશા -2 હોય છે.
✅ D — ઓક્સિજનનું ઓક્સિડેશન નંબર સામાન્ય રીતે -2 હોય છે, પરંતુ H₂O₂ જેવા સંયોજનોમાં તે +1 અથવા -1 પણ હોઈ શકે.
Q3. રેડોક્સ પ્રક્રિયામાં ઓક્સિડેશન અર્થ શું છે?
A. ઇલેક્ટ્રોનનું ગુમાવવું
B. ઇલેક્ટ્રોનનું મેળવવું
C. હાઇડ્રોજનનું ગુમાવવું
D. ઑક્સિજનનું મેળવવું
✅ A — ઓક્સિડેશન એટલે પદાર્થ દ્વારા ઇલેક્ટ્રોનનું ગુમાવવું. આ રેડોક્સ પ્રક્રિયાનો મુખ્ય ભાગ છે.
Q4. નીચેનામાંથી કયું પદાર્થ રિડક્શન એજન્ટ (Reducing Agent) તરીકે કામ કરે છે?
A. K₂Cr₂O₇
B. KMnO₄
C. H₂S
D. HNO₃
✅ C — H₂S ઇલેક્ટ્રોન આપી શકે છે, જેથી તે રિડક્શન એજન્ટ તરીકે કામ કરે છે.
Q5. નીચેનામાંથી કયો પદાર્થ ઓક્સીડેશન અને રિડક્શન બંને પ્રક્રિયામાં ભાગ લે છે?
A. ઓક્સિજન (Oxygen)
B. હાઇડ્રોજન પેરોક્સાઇડ (Hydrogen Peroxide)
C. સોડિયમ ક્લોરાઇડ (Sodium Chloride)
D. કાર્બન ડાયોક્સાઇડ (Carbon Dioxide)
✅ B — હાઇડ્રોજન પેરોક્સાઇડ (H₂O₂) ઓક્સીડેશન અને રિડક્શન બંને પ્રક્રિયામાં ભાગ લે છે કારણ કે તે ઓક્સિડાઇઝિંગ એજન્ટ તરીકે અને રિડ્યુસિંગ એજન્ટ તરીકે પણ વર્તે છે.
Q6. નીચેનામાંથી કયા યુગ્મમાં ઓક્સિડેશન અવસ્થા (Oxidation State) સરખી છે?
A. Fe²⁺ અને Fe³⁺
B. Cr²⁺ અને Cr³⁺
C. Mn²⁺ અને Mn⁴⁺
D. Cu⁺ અને Cu²⁺
✅ B — Cr²⁺ અને Cr³⁺ બંનેમાં ક્રોમિયમની ઓક્સિડેશન અવસ્થા અનુક્રમે +2 અને +3 છે, પરંતુ પ્રશ્નમાં સરખી ઓક્સિડેશન અવસ્થા વાળા યુગ્મની માગણી હોવાથી, કોઈપણ યુગ્મમાં સરખી ઓક્સિડેશન અવસ્થા નથી. પરંતુ પ્રશ્નની રચના અનુસાર, કોઈપણ યુગ્મ સરખું ન હોવાથી, આ પ્રશ્ન ખોટો છે. પરંતુ સુધારેલા પ્રશ્નમાં, Cr³⁺ અને Cr³⁺ સરખી ઓક્સિડેશન અવસ્થા ધરાવે છે.
Q7. રેડોક્સ પ્રક્રિયામાં, જ્યારે ક્લોરિન ગેસ (Cl₂) પાણીમાં ઓગળે છે, ત્યારે ક્લોરિનની ઓક્સિડેશન અવસ્થામાં શું ફેરફાર થાય છે?
A. ક્લોરિનની ઓક્સિડેશન અવસ્થા 0 થી -1 થાય છે.
B. ક્લોરિનની ઓક્સિડેશન અવસ્થા 0 થી +1 થાય છે.
C. ક્લોરિનની ઓક્સિડેશન અવસ્થા 0 થી -1 અને +1 બંને થાય છે.
D. ક્લોરિનની ઓક્સિડેશન અવસ્થામાં કોઈ ફેરફાર થતો નથી.
✅ C — પાણીમાં ક્લોરિન ગેસ ઓગળતાં, તે હાયપોક્લોરસ એસિડ (HClO) અને હાઇડ્રોક્લોરિક એસિડ (HCl) બનાવે છે. આ પ્રક્રિયામાં ક્લોરિનની ઓક્સિડેશન અવસ્થા 0 થી -1 (HClમાં) અને +1 (HClOમાં) થાય છે.
Q8. નીચેનામાંથી કયો પદાર્થ રેડોક્સ પ્રક્રિયામાં ઓક્સિડાઇઝિંગ એજન્ટ (Oxidizing Agent) તરીકે વર્તે છે?
A. H₂S
B. SO₂
C. KMnO₄
D. Na₂SO₄
✅ C — પોટેશિયમ પરમેંગનેટ (KMnO₄) એ મજબૂત ઓક્સિડાઇઝિંગ એજન્ટ છે, કારણ કે તે પ્રક્રિયામાં ઇલેક્ટ્રૉન ગુમાવે છે અને બીજા પદાર્થને ઓક્સિડાઇઝ કરે છે.
Q9. નીચેનામાંથી કયી પ્રક્રિયા રેડોક્સ પ્રક્રિયા નથી?
A. 2H₂ + O₂ → 2H₂O
B. CaCO₃ → CaO + CO₂
C. 2KClO₃ → 2KCl + 3O₂
D. Zn + CuSO₄ → ZnSO₄ + Cu
✅ B — CaCO₃નું વિયોજન (Decomposition) એ રેડોક્સ પ્રક્રિયા નથી, કારણ કે આ પ્રક્રિયામાં કોઈ પણ તત્વની ઓક્સિડેશન અવસ્થામાં ફેરફાર થતો નથી.
Q10. રેડોક્સ પ્રક્રિયામાં, ઓક્સિડેશન અવસ્થાના ફેરફારની ગણતરી માટે નીચેનામાંથી કયો નિયમ યોગ્ય છે?
A. મુખ્ય સમૂહના તત્વની ઓક્સિડેશન અવસ્થા હંમેશા +1 હોય છે.
B. હાઇડ્રોજનની ઓક્સિડેશન અવસ્થા હંમેશા +1 હોય છે.
C. ઓક્સિજનની ઓક્સિડેશન અવસ્થા હંમેશા -2 હોય છે.
D. ફ્લોરિનની ઓક્સિડેશન અવસ્થા હંમેશા -1 હોય છે.
✅ D — ફ્લોરિન (F) એ સૌથી વધુ ઇલેક્ટ્રોનેગેટિવ તત્વ છે, તેથી તેની ઓક્સિડેશન અવસ્થા હંમેશા -1 હોય છે.
Q11. નીચેનામાંથી કયી પ્રક્રિયામાં ઓક્સિડેશન અવસ્થામાં સૌથી વધુ ફેરફાર થાય છે?
A. KClO₃ → KCl + 3/2 O₂
B. 2KClO₃ → 2KCl + 3O₂
C. KClO₄ → KCl + 2O₂
D. 2KClO → 2KCl + O₂
✅ C — KClO₄માં Clની ઓક્સિડેશન અવસ્થા +7 છે, જ્યારે KClમાં તે -1 થાય છે, જેથી ફેરફાર 8 (7 - (-1)) થાય છે, જે સૌથી મોટો છે.
Q12. જ્યારે KMnO₄ એસિડિક મધ્યમમાં FeSO₄ સાથે પ્રક્રિયા કરે છે, ત્યારે Fe²⁺ની ઓક્સિડેશન અવસ્થામાં શું ફેરફાર થાય છે?
A. Fe²⁺ → Fe³⁺ (ઓક્સિડેશન)
B. Fe²⁺ → Fe (રિડક્શન)
C. Fe²⁺ → Fe⁴⁺ (ઓક્સિડેશન)
D. કોઈ ફેરફાર થતો નથી
✅ A — એસિડિક મધ્યમમાં KMnO₄ એક મજબૂત ઓક્સિડાઇઝિંગ એજન્ટ છે, જે Fe²⁺ને Fe³⁺માં ઓક્સિડાઇઝ કરે છે.
Q13. નીચેનામાંથી કયો પદાર્થ H₂O₂ સાથે પ્રક્રિયા કરતી વખતે રિડક્શન એજન્ટ (Reducing Agent) તરીકે વર્તે છે?
A. K₂Cr₂O₇
B. PbS
C. KMnO₄
D. O₃
✅ B — PbSમાં Sની ઓક્સિડેશન અવસ્થા -2 છે, જે H₂O₂ સાથે પ્રક્રિયા કરતી વખતે +6 (SO₄²⁻) થાય છે, જેથી PbS રિડક્શન એજન્ટ તરીકે વર્તે છે.
Q14. નીચેનામાંથી કયી પ્રક્રિયા સ્વયં-રેડોક્સ પ્રક્રિયા (Disproportionation Reaction) નું ઉદાહરણ છે?
A. 2H₂O₂ → 2H₂O + O₂
B. Cl₂ + 2NaOH → NaCl + NaClO + H₂O
C. 2SO₂ + O₂ → 2SO₃
D. Zn + CuSO₄ → ZnSO₄ + Cu
✅ B — Cl₂માં Clની ઓક્સિડેશન અવસ્થા 0 છે, જે પ્રક્રિયા પછી NaClમાં -1 અને NaClOમાં +1 થાય છે, જેથી આ સ્વયં-રેડોક્સ પ્રક્રિયા છે.
Q15. નીચેનામાંથી કયા યુગ્મમાં બંને પદાર્થો રેડોક્સ પ્રક્રિયામાં ઓક્સિડાઇઝિંગ એજન્ટ (Oxidizing Agent) તરીકે વર્તી શકે છે?
A. O₂ અને O₃
B. H₂ અને F₂
C. Na અને Cl₂
D. KMnO₄ અને K₂Cr₂O₇
✅ D — KMnO₄ અને K₂Cr₂O₇ બંને મજબૂત ઓક્સિડાઇઝિંગ એજન્ટ છે, જે અન્ય પદાર્થોને ઓક્સિડાઇઝ કરવા સક્ષમ છે.
Q16. નીચેનામાંથી કયો તત્ત્વ રેડોક્સ પ્રક્રિયામાં રિડક્શન પામે છે?
A. ઓક્સિજન (Oxygen)
B. હાઇડ્રોજન (Hydrogen)
C. ક્લોરિન (Chlorine)
D. સલ્ફર (Sulfur)
✅ C — રિડક્શનમાં, તત્ત્વની ઓક્સિડેશન અવસ્થા ઘટે છે. ક્લોરિન (Cl) જ્યારે Cl₂થી Cl⁻ બને છે, ત્યારે તેની ઓક્સિડેશન અવસ્થા 0થી -1 થાય છે, જેથી તે રિડક્શન પામે છે.
Q17. નીચેનામાંથી કયું યુગ્મ રેડોક્સ યુગ્મ નથી?
A. Fe²⁺ અને Fe³⁺
B. MnO₄⁻ અને Mn²⁺
C. Cr₂O₇²⁻ અને Cr³⁺
D. Na⁺ અને Cl⁻
✅ D — Na⁺ અને Cl⁻માં કોઈ ઓક્સિડેશન અવસ્થાના ફેરફાર થતો નથી, જેથી તે રેડોક્સ યુગ્મ નથી.
Q18. રેડોક્સ પ્રક્રિયામાં, ઓક્સિડેશન અવસ્થા વધે તેને શું કહેવાય છે?
A. રિડક્શન (Reduction)
B. ઓક્સિડેશન (Oxidation)
C. ન્યુટ્રલાઇઝેશન (Neutralization)
D. ડિસ્પ્રોપોર્શન (Disproportionation)
✅ B — જ્યારે તત્ત્વની ઓક્સિડેશન અવસ્થા વધે છે, ત્યારે તેને ઓક્સિડેશન કહેવાય છે.
Q19. નીચેનામાંથી કયી પ્રક્રિયામાં હાઇડ્રોજન ઓક્સિડાઇઝ થાય છે?
A. H₂ + Cl₂ → 2HCl
B. 2H₂ + O₂ → 2H₂O
C. H₂ + I₂ → 2HI
D. H₂ + S → H₂S
✅ B — 2H₂ + O₂ → 2H₂O પ્રક્રિયામાં, H₂ની ઓક્સિડેશન અવસ્થા 0થી +1 થાય છે, જેથી હાઇડ્રોજન ઓક્સિડાઇઝ થાય છે.
Q20. નીચેનામાંથી કયો પદાર્થ રેડોક્સ પ્રક્રિયામાં ઓક્સિડાઇઝિંગ એજન્ટ તરીકે વર્તે છે?
A. Na₂SO₃
B. K₂Cr₂O₇
C. FeSO₄
D. H₂S
✅ B — K₂Cr₂O₇ (પોટેશિયમ ડાઇક્રોમેટ) રેડોક્સ પ્રક્રિયામાં ઓક્સિડાઇઝિંગ એજન્ટ તરીકે વર્તે છે, કારણ કે તે અન્ય પદાર્થોને ઓક્સિડાઇઝ કરે છે અને સ્વયં રિડક્શન પામે છે.
Q21. નીચેનામાંથી કયા આયનની ઓક્સિડેશન અવસ્થા +5 છે?
A. MnO₄²⁻
B. Cr₂O₇²⁻
C. PO₄³⁻
D. SO₄²⁻
✅ C — PO₄³⁻માં ફોસ્ફરસની ઓક્સિડેશન અવસ્થા +5 છે, કારણ કે Oની ઓક્સિડેશન અવસ્થા -2 લેતા, x + 4(-2) = -3 ⇒ x = +5.
Q22. રેડોક્સ પ્રક્રિયામાં, જ્યારે કોઈ પદાર્થ ઓક્સિડાઇઝ થાય છે ત્યારે તેનું શું થાય છે?

Q23. નીચેનામાંથી કયો પદાર્થ ઓક્સિડાઇઝિંગ એજન્ટ (Oxidising agent) તરીકે કામ કરે છે?

Q24. નીચેનામાંથી કયા પદાર્થમાં સલ્ફરની ઓક્સિડેશન અવસ્થા +4 છે?

Q25. નીચેનામાંથી કયો પદાર્થ KMnO₄ (પોટેશિયમ પરમેંગેનેટ) સાથે પ્રક્રિયા કરતી વખતે ઓક્સિડેશન પામે છે?
A. FeSO₄ (ફેરસ સલ્ફેટ)
