સંતુલન (Equilibrium) અભ્યાસક્રમ માટે પરીક્ષા ટ્રિક્સ

🩺 NEET UG — Gujarati • Chemistry • Equilibrium

🎯 પરીક્ષા ટ્રિક્સ

જ્યારે પ્રશ્નમાં Kp અને Kcનો ગુણોત્તર પૂછવામાં આવે, ત્યારે Δn = (ગેઝિયસ આણ્વિક સૂત્રમાં ગેઝની મોલની સંખ્યા) - (રિએક્ટન્ટમાં ગેઝની મોલની સંખ્યા) મૂકો. Kp = Kc (RT)^Δn.
Kp અને Kc વચ્ચેના સંબંધને શોધવાનું હોય ત્યારે.
દા.ત.: N₂(g) + 3H₂(g) ⇌ 2NH₃(g) માટે Δn = 2 - (1+3) = -2. તેથી Kp = Kc (RT)^(-2).
જો પ્રશ્નમાં સંતુલન અચળાંક (K) મૂલ્ય 1 કરતાં ખૂબ જ મોટું હોય (પરિમાણરહિત), તો પૂર્ણ પ્રતિક્રિયા થયેલી ગણી શકાય. જો K ખૂબ જ નાનું હોય, તો પ્રતિક્રિયા લગભગ થતી નથી.
પ્રતિક્રિયાની પૂર્ણતા અથવા અપૂર્ણતા નક્કી કરવાની હોય ત્યારે.
દા.ત.: K = 10^10 હોય, તો પ્રતિક્રિયા લગભગ પૂર્ણ થાય છે.
લેચાટેલિયરના સિદ્ધાંત મુજબ, જો દબાણ વધારવામાં આવે, તો સંતુલન તે બાજુ વળે જ્યાં ગેઝના મોલની સંખ્યા ઓછી હોય.
દબાણમાં ફેરફાર થવાને લીધે સંતુલન પર થતી અસર શોધવાની હોય ત્યારે.
દા.ત.: N₂(g) + 3H₂(g) ⇌ 2NH₃(g)માં દબાણ વધારતાં સંતુલન NH₃ તરફ વળે.
જો તાપમાન વધારવામાં આવે, તો સંતુલન એન્ડોથર્મિક (શોષક) દિશામાં વળે. જો તાપમાન ઘટાડવામાં આવે, તો એક્ઝોથર્મિક (મુક્તકર) દિશામાં વળે.
તાપમાનમાં ફેરફાર થવાને લીધે સંતુલન પર થતી અસર શોધવાની હોય ત્યારે.
દા.ત.: 2SO₂(g) + O₂(g) ⇌ 2SO₃(g) (ΔH = -198 kJ) એક્ઝોથર્મિક પ્રતિક્રિયા છે. તાપમાન ઘટાડતાં સંતુલન SO₃ તરફ વળે.
સંતુલન અચળાંક (K) માટે, જો પ્રતિક્રિયા ઉલટાવી દેવામાં આવે, તો નવો K = 1/K (મૂળ K).
પ્રતિક્રિયાની દિશા ઉલટાવવાની હોય ત્યારે.
દા.ત.: A + B ⇌ C માટે K = x, તો C ⇌ A + B માટે K = 1/x.
જો પ્રતિક્રિયાને n વખત ગુણાકાર કરવામાં આવે, તો નવો K = K^n.
પ્રતિક્રિયાને સ્કેલ કરવાની હોય ત્યારે.
દા.ત.: A + B ⇌ C માટે K = x, તો 2A + 2B ⇌ 2C માટે K = x².
હેટરોજીનિયસ સંતુલન (વિવિધ પ્રાવસ્થામાં) માટે, સંતુલન અચળાંક (K) ને સાંદ્રતા વડે વ્યક્ત ન કરતાં, આંશિક દબાણ અથવા પ્રવૃત્તિ વડે વ્યક્ત કરવામાં આવે છે.
હેટરોજીનિયસ પ્રતિક્રિયાઓના સંતુલન અચળાંકને શોધવાની હોય ત્યારે.
દા.ત.: CaCO₃(s) ⇌ CaO(s) + CO₂(g) માટે Kp = P_CO₂.
જો પ્રશ્નમાં સંતુલન અવસ્થામાં ગાઢતાનો (concentration) ગુણોત્તર પૂછવામાં આવે, તો સ્ટોઇકિયોમેટ્રિક ગુણોત્તરનો ઉપયોગ કરો.
સંતુલન અવસ્થામાં પદાર્થોની સાંદ્રતા વચ્ચેના સંબંધને શોધવાની હોય ત્યારે.
દા.ત.: N₂(g) + 3H₂(g) ⇌ 2NH₃(g)માં, સંતુલનમાં [H₂] = 3/2 [N₂] જો પ્રારંભિક મોલ સમાન હોય.
જો પ્રતિક્રિયામાં પાણી (H₂O) હાજર હોય અને તે પદાર્થ અથવા દ્રાવક તરીકે વર્તે, તો તેને સંતુલન અચળાંકના અભિવ્યક્તિમાં સમાવિષ્ટ કરવામાં આવતું નથી.
જલીય પ્રતિક્રિયાઓમાં સંતુલન અચળાંક શોધવાની હોય ત્યારે.
દા.ત.: CH₃COOH(l) + H₂O(l) ⇌ CH₃COO⁻(aq) + H₃O⁺(aq) માટે K = [CH₃COO⁻][H₃O⁺] / [CH₃COOH].
સમાન આયન પ્રભાવ (Common Ion Effect) મુજબ, જો કોઈ પ્રતિક્રિયામાં આયનની સાંદ્રતા વધારવામાં આવે, તો સંતુલન તે દિશામાં વળે જ્યાં તે આયનનો ઉપયોગ થાય.
સમાન આયનના પ્રભાવને લીધે સંતુલન પર થતી અસર શોધવાની હોય ત્યારે.
દા.ત.: CH₃COOH ⇌ CH₃COO⁻ + H⁺માં, જો CH₃COONa ઉમેરવામાં આવે, તો સંતુલન બાયાં તરફ વળે.
જો પ્રશ્નમાં સંતુલન અચળાંક (K) નું એકમ પૂછવામાં આવે, તો તે પ્રતિક્રિયાના સ્ટોઇકિયોમેટ્રિક ગુણોત્તર પર આધાર રાખે છે. K નું એકમ (મોલ/L)^Δn હોય છે, જ્યાં Δn = (પ્રોડક્ટના મોલ) - (રિએક્ટન્ટના મોલ).
K નું એકમ શોધવાનું હોય ત્યારે.
દા.ત.: N₂(g) + 3H₂(g) ⇌ 2NH₃(g) માટે Δn = 2 - 4 = -2, તેથી Kc નું એકમ (મોલ/L)^(-2) અથવા L²/mol².
જો પ્રતિક્રિયા સંપૂર્ણપણે ગેઝિયસ હોય અને મોલની સંખ્યા સમાન હોય (Δn = 0), તો Kp = Kc.
Kp અને Kc વચ્ચેનો સંબંધ શોધવાનું હોય અને Δn = 0 હોય ત્યારે.
દા.ત.: H₂(g) + I₂(g) ⇌ 2HI(g) માટે Δn = 0, તેથી Kp = Kc.
સંતુલન અવસ્થામાં, પ્રતિક્રિયા વેગ (rate of forward reaction) = ઉલટ પ્રતિક્રિયા વેગ (rate of backward reaction). આનો ઉપયોગ સંતુલનની શરત તપાસવા માટે થઈ શકે.
સંતુલનની શરત તપાસવાની હોય ત્યારે.
દા.ત.: A + B ⇌ C + D માટે, જ્યારે k₁[A][B] = k₂[C][D], ત્યારે સંતુલન પ્રાપ્ત થાય છે.
જો પ્રશ્નમાં સંતુલન અચળાંક (K) નું મૂલ્ય તાપમાન સાથે બદલાતું હોય, તો વાન્ટ હોફ સમીકરણ (van't Hoff equation) નો ઉપયોગ કરો: ln(K₂/K₁) = -ΔH/R (1/T₂ - 1/T₁).
તાપમાનના ફેરફાર સાથે K ના ફેરફારને શોધવાની હોય ત્યારે.
દા.ત.: જો K₁ = 0.1 (T₁ = 300 K) અને ΔH = -50 kJ/mol, તો T₂ = 400 K માટે K₂ શોધી શકાય.
