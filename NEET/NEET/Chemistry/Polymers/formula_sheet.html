પોલિમર — સૂત્ર શીટ

🩺 NEET UG — Gujarati • Chemistry • Polymers

⚡ સૂત્રો

સંખ્યા-સરાસરી આણ્વીય દળ (M_n): M_n = (Σ N_i × M_i) / Σ N_i
N_i = આપેલા આણ્વીય દળ M_i ધરાવતા અણુઓની સંખ્યા; M_i = તે અણુઓનું આણ્વીય દળ · SI: g/mol (કિળોદળ) · જ્યારે નમૂનામાં વિવિધ શૃંખલા લંબાઈ ધરાવતા પોલિમર અણુઓ હોય — માળખાગત રીતે વિસંગત (polydisperse) નમૂના માટે
ભાર-સરાસરી આણ્વીય દળ (M_w): M_w = (Σ N_i × M_i²) / (Σ N_i × M_i)
N_i = આપેલા M_i દળ ધરાવતા અણુઓની સંખ્યા; M_i = તે અણુઓનું આણ્વીય દળ · SI: g/mol (કિળોદળ) · જ્યારે પ્રયોગમાં ઓસ્મોટિક દબાણ જેવા ગુણધર્મો દ્વારા માપન કરવાનું હોય અથવા ભાર-આધારિત સરાસરી જોઈતી હોય
પ્રમાણભૂત વિચલન/પોલિડિસ્પર્સિટી (PDI): PDI = M_w / M_n
M_w = ભાર-સરાસરી આણ્વીય દળ; M_n = સંખ્યા-સરાસરી આણ્વીય દળ · SI: પરિમાણરહિત (અનેકતાનો ગુણોત્તર) · દરેક પોલિમર નમૂના માટે. Monodisperse (એકસમાન) પોલિમર માટે PDI = 1; સામાન્ય સિન્થેટિક પોલિમર માટે PDI > 1
પોલિમરાઇઝેશન મોડ (n): n = મોલિબલ્ક ડબલ્યુ / મોનોમેર યુનિટ ડબલ્યુ
મોલિબલ્ક ડબલ્યુ = પોલિમરનું આણ્વીય દળ; મોનોમેર યુનિટ ડબલ્યુ = પુનરાવર્તિત એકમનું આણ્વીય દળ · SI: પરિમાણરહિત (એક અપૂર્ણાંક પૂર્ણાંક હોય છે) · ચરમ પોલિમરાઇઝેશન (step-growth) ને અનુસરતી પ્રતિક્રિયાઓમાં અને ઉદા. પોલીએથિલીન, પોલીએથિલીન તેરેફ્થેલેટ જેવા ટેરેપ પોલિમરની ગણતરીમાં
પોલીએથિલીન તેરેફ્થેલેટ (PET) બંધારણ — બ્રેક ડાઉન પરિણામ: −[CO−C₆H₄−CO−O−CH₂−CH₂−O]ₙ−
C₆H₄ = બેઝિન રિંગ; −CO−O− = એસ્ટર બંધનું પુનરાવર્તિત એકમ; −CH₂−CH₂− = એથિલીન વિભાગ · SI: બંધારણ દર્શાવતું — આણ્વીય દળ એ n પર આધારિત · ટેરેફ્થેલિક એસિડ + ઇથિલીન ગ્લાઇકોલથી (condensation/polyestering) બનતું પોલિમર
બેકલાઇટ (ફેનોલ−ફોર્મલડિહાઇડ રેઝિન)નું બંધારણ: −[−C₆H₃(OH)−CH₂−]ₙ− (ક્રોસ-લિંક્ડ ત્રિપરિમાણીય નેટવર્ક)
C₆H₃(OH) = હાઈડ્રોક્સિફેનોલ એકમ; CH₂ = મિથિલીન જોડાણ (ફોર્મલડિહાઇડમાંથી); ક્રોસ-લિંક્ડ = ત્રિપરિમાણીય જાળી · SI: બંધારણ દર્શાવતું · ફેનોલ + ફોર્મલડિહાઇડ, બેઝ પ્રેરિત, ઊંચા તાપમાને થતું રિપ્લેસમેન્ટ/કન્ડેન્સેશન પોલિમરાઇઝેશન
નિયોલ (ફોર્મલડિહાઇડ + યુરિઆ)ની વાલ્યુ: −[−NH−CO−NH−C₆H₄−SO₂−]ₙ− અથવા સામાન્ય રીતે F−C₆H₄−SO₂−Cl + (NH₂)₂CO → નેટવર્ક
F = ફ્લોરીન સબસ્ટિટ્યુએન્ટ; C₆H₄ = બેન્ઝીન રિંગ; SO₂ = સલ્ફોનિલ; (NH₂)₂CO = યુરિઆ · SI: બંધારણ દર્શાવતું · ફ્લોરોબેન્ઝીન સલ્ફોનિક્લોરાઇડ + યુરિઆનાં રિપ્લેસમેન્ટ/કન્ડેન્સેશન દ્વારા નિર્માણ
બેકલાઇટમાં ક્રોસ-લિંકિંગ તાપમાન પ્રભાવ: બેકલાઇટ (398–413 K પર સંશ્લેષિત) → ગરમી મળતાં ક્રોસ-લિંક્ડ થાય છે → થર્મોસેટિંગ પ્લાસ્ટિક
398–413 K = અંદાજિત ઉષ્મીય વિભાગ તાપમાન; ક્રોસ-લિંક્ડ = ત્રિપરિમાણીય જાળી બનવી · SI: K (તાપમાન) · ફેનોલ + ફોર્મલડિહાઇડની બેઝ પ્રેરિત પ્રતિક્રિયા
પુનરાવર્તિત એકમનું આણ્વીય દળ — ઉદાહરણ: PET: M(PET repeat unit) = 192 g/mol (≈)
C₁₀H₈O₄ → 10×12 + 8×1 + 4×16 = 120 + 8 + 64 = 192; CO−C₆H₄−CO = 166; O−CH₂−CH₂−O = 62; સરવાળો ≈ 192 · SI: g/mol · ટુટેડ (hydraulytic cleavage) પછી મળતું પુનરાવર્તિત એકમ
કન્ડેન્સેશન પોલિમરાઇઝેશનમાં પાણી/અન્ય નાનું અણુ મુક્ત થાય છે: n HOOC−C₆H₄−COOH + n HOCH₂CH₂OH → [−CO−C₆H₄−CO−OCH₂CH₂O−]ₙ + (2n−1) H₂O
HOOC−C₆H₄−COOH = ટેરેફ્થેલિક એસિડ; HOCH₂CH₂OH = ઇથિલીન ગ્લાઇકોલ; H₂O = મુક્ત થતું પાણી · SI: સ્ટોઇકિયોમેટ્રિક — પાણીના n સમાન અણુઓ · ડાયકાર્બોક્સિલિક એસિડ + ડાયોલ → પોલિએસ્ટર (ટેરેપ)

🔗 સંબંધો

  • M_w ≥ M_n હંમેશા; PDI = M_w/M_n ≥ 1; જ્યારે PDI = 1 હોય ત્યારે પોલિમર એકધારો (monodisperse) ગણાય — જૈવિક પોલિમરો (પ્રોટીન, DNA) એકધારા ગણાય.
  • પોલિમરનું આણ્વીય દળ જેટલું વધુ, તેટલું જ PDI પણ વધુ મજબૂત કારણ કે શૃંખલા લંબાઈ વિતરણ વધે છે.
  • થર્મોપ્લાસ્ટિક્સ (PE, PP, PVC, PS) ગરમીથી નરમ પડે છે અને વારંવાર આકાર આપી શકાય છે કારણ કે તેમની શૃંખલાઓ વચ્ચે કોઈ ક્રોસ-લિંક ન હોય.
  • થર્મોસેટિંગ પ્લાસ્ટિક્સ (બેકલાઇટ, વુલોકનાઇટ, નિયોલ) એકવાર આકાર મેળવ્યા પછી ગરમીથી પીગળતા નથી કારણ કે ત્રિપરિમાણીય ક્રોસ-લિંક્ડ નેટવર્ક હોય છે.
  • ઇલાસ્ટોમર્સ (Buna-S, Buna-N, પરુવ) માં શૃંખલાઓ વચ્ચે નિર્બળ આંતરઆણ્વીય બળો હોય છે, એકવાર ખેંચ્યા પછી પણ પાછા તંગ થાય છે.
  • જેટલો વધુ ક્રોસ-લિંકિંગ, તેટલો વધુ PDI પણ વધુ — કારણ કે નેટવર્કમાં શૃંખલા લંબાઈનું વિતરણ વિશાળ હોય છે.
  • રેખીય પોલિમરો (HDPE, નેલોન) માં સંકુચિત શૃંખલા સંક્રમણ તાપમાન (Tg) નીચું હોય છે; શાખાંકિત (LDPE) માં Tg વધુ હોય છે.
  • બ્રાઇડ (Buna-S)માં 1,3-બ્યુટેડાઇન અને સ્ટાયરીનનું આણ્વીય ગુણોત્તર બદલવાથી રબરના ગુણધર્મો બદલાય છે.

🎯 ટ્રિક્સ

પોલિમરનાં નામની રચના યાદ કરવાની સરળ રીત: મોનોમેરનું નામ લઈને આગળ '-y' અથવા 'પોલી-' ઉમેરો. ઉદા: એથિલીન → પોલીએથિલીન, વિનાઇલ ક્લોરાઇડ → પોલીવિનાઇલ ક્લોરાઇડ.
KMM અને કન્ડેન્સેશન પોલિમર વચ્ચેનો તફાવત યાદ રાખવાની રીત: કન્ડેન્સેશનમાં 'તેરેપ' (терра) + 'પેલેટ' (palate) = PET — એસ્ટરિફિકેશન દ્વારા બનતું પોલિમર.
Buna-S અને Buna-N યાદ રાખવાની રીત: 'Buna' = સોડિયમ (Na) + બ્યુટેડાઇન (Bu); 'S' = સ્ટાયરીન; 'N' = નાઈટ્રાઇલ (cyanide) યુક્ત.
થર્મોપ્લાસ્ટિક્સ vs થર્મોસેટિંગ યાદ રાખો: 'થર્મોપ્લાસ્ટિક'માં '-plas' = પ્લાસ્ટિક/નરમ, ગરમીથી પિગળે; 'થર્મોસેટ'માં '-set' = સેટ થઈ ગયું, પાછું નરમ ન પડે.
વિનાઇલ ક્લોરાઇડનું નામ યાદ રાખો: CH₂=CH−Cl — Cl સબસ્ટિટ્યુએન્ટ ધરાવતો એકલ બંધિત મોનોમેર. તેની નેટ આલ્ફાટિયન (α-ટીન) પદ્ધતિથી બનેલા પ્લાસ્ટિકો માટે વપરાય છે.
ક્રોસ-લિંક્ડ પોલિમરો યાદ રાખો: બેકલાઇટ, વુલોકનાઇટ, નિયોલ — આ ત્રણેય ઉષ્મા લાગતાં સખત થઈ જાય છે અને પીગળતા નથી.
પોલિએથિલીનનો પ્રકાર યાદ રાખો: LDPE = ઓછું ઘનતા, ટૂંકા શાખાઓ, બરફના સ્ફટિક સમાન; HDPE = વધુ ઘનતા, રેખીય શૃંખલા, વધુ મજબૂત.
પ્રક્રિયાનો પ્રકાર યાદ રાખવાની રીત: એડિશન પોલિમરાઇઝેશનમાં π-બંધ તૂટે છે અને નવો σ-બંધ બને છે; કન્ડેન્સેશનમાં H₂O અથવા CH₃OH જેવું નાનું અણુ બહાર નીકળે છે.

⚠️ ભૂલો

M_n અને M_w ની વ્યાખ્યા ગૂંચવવી — M_n સંખ્યા-આધારિત છે, M_w ભાર-આધારિત છે. ઘણા વિદ્યાર્થીઓ ગણતરીમાં આ બંનેને ઉલટા ચડાવી દે છે.
PDI ની ગણતરી ઉલટી કરવી — PDI = M_w / M_n, ન કે M_n / M_w. PDI હંમેશા ≥ 1 હોય છે.
કન્ડેન્સેશન પોલિમરાઇઝેશનમાં મુક્ત થતું અણુ ચૂકવવું — PET માં H₂O મુક્ત થાય છે, ન કે CO₂ અથવા અન્ય અણુ.
થર્મોપ્લાસ્ટિક્સ અને થર્મોસેટિંગ વચ્ચેનો તફાવત ભૂલવાથી — HDPE થર્મોપ્લાસ્ટિક છે, બેકલાઇટ થર્મોસેટિંગ છે; ઘણા વિદ્યાર્થીઓ બેકલાઇટને થર્મોપ્લાસ્ટિક માની લે છે.
બ્રાઇડ અને નેઇલોન-6,6 વચ્ચેનો તફાવત ભૂલવો — બ્રાઇડ રબર (ઇલાસ્ટોમર) છે, નેઇલોન-6,6 ફાઈબર છે. બંને કન્ડેન્સેશન પોલિમર છે પરંતુ ગુણધર્મો અલગ છે.
કન્ડેન્સેશન પોલિમરોમાં 'અણુનું આણ્વીય દળ' ગણતરીમાં કન્ડેન્સેશન દ્વારા મુક્ત થતા અણુનું દળ નહીં ધ્યાનમાં લેવું — PET ના પુનરાવર્તિત એકમનું દળ 192 g/mol (એસિડ + ગ્લાઇકોલમાંથી 2×H₂O ગુમાવ્યા પછી).
Buna-S અને Buna-N ના મોનોમેર યાદ રાખવામાં ભૂલ — Buna-S: 1,3-બ્યુટેડાઇન + સ્ટાયરીન; Buna-N: 1,3-બ્યુટેડાઇન + એક્રિલોનાઈટ્રાઇલ.
વિનાઇલ ક્લોરાઇડ (CH₂=CH−Cl) નું બંધારણ ભૂલવું — ઘણા વિદ્યાર્થીઓ Cl ને wrong position પર મૂકી દે છે અથવા CH₃−CHCl₂ માની લે છે.
પોલિમરાઇઝેશન મોડ (n) ની ગણતરીમાં કન્ડેન્સેશન દ્વારા મુક્ત થતું અણુ ધ્યાનમાં લેવાનું બાકી રાખવું — ઉદા. PET માં કન્ડેન્સેશન દ્વારા H₂O ના n અણુઓ નીકળે છે, જેથી પોલિમરનું દળ M_monomer × n − (n×18) જેવું થાય છે.
નિયોલનું બંધારણ યાદ રાખવામાં F, SO₂, NH₂ ની સ્થિતિ ગૂંચવી જવો — નિયોલ F−C₆H₄−SO₂−Cl + (NH₂)₂CO પ્રક્રિયાથી બને છે, F અને SO₂Cl બેન્ઝીન રિંગ પર એકબીજાથી વિરોધી ભાગમાં હોય છે.
