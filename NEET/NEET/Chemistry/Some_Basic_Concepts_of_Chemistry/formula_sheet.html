રસાયણશાસ્ત્ર — કેટલાક મૂળભૂત વિષયો (Some Basic Concepts of Chemistry) : સૂત્ર શીટ

🩺 NEET UG — Gujarati • Chemistry • Some Basic Concepts of Chemistry

⚡ સૂત્રો

મોલ (Mole) અને કણોનો સંબંધ: n = N / N_A
n = મોલની સંખ્યા; N = કણોની કુલ સંખ્યા; N_A = એવોગેડ્રો અંક (6.022 × 10^23 mol^-1) · SI: મોલ (mol) · જ્યારે પદાર્થમાં રહેલા પરમાણુઓ, અણુઓ, આયનો વગેરેની કુલ સંખ્યા આપેલી હોય.
મોલ અને દળ (Mole-Mass): n = m / M
n = મોલની સંખ્યા; m = પદાર્થનું દળ (g); M = મોલર દળ (g/mol) · SI: m: g; M: g/mol · ઘન અથવા પ્રવાહી પદાર્થનું દળ આપેલું હોય અને મોલ શોધવાના હોય.
બે સૂત્રોનું મિશ્રણ: n = m / M = N / N_A
આ એક જ મોલની પરિભાષાનું બે સમાનરૂપ સૂત્ર છે. · SI: mol · કોઈ પણ સમયે દળ અને કણો બંનેનો ઉપયોગ કરી શકાય છે.
ગેસનું મોલ અને પ્રમાણભૂત તાપમાન-દબાણ (STP) પર કદ: n = V / V_m
n = મોલની સંખ્યા; V = ગેસનું કદ (L); V_m = મોલર કદ; STP પર V_m ≈ 22.4 L/mol · SI: V: L (કે m^3); V_m: L/mol · આદર્શ ગેસ (Ideal Gas) ધારીને, 1 atm અને 0°C (273.15 K) પર.
આદર્શ ગેસ સમીકરણ (Ideal Gas Equation): PV = nRT
P = દબાણ; V = કદ; n = મોલ; R = સાર્વત્રિક ગેસ અચળાંક; T = પારદર્શી તાપમાન (K) · SI: P: Pa; V: m^3; R: 8.314 J/(mol·K); T: K · આદર્શ ગેસ વર્તણૂક ધરાવતી હોય.
R ના મૂલ્યો (Common Units): R = 0.0821 L·atm/(mol·K) અથવા R = 8.314 J/(mol·K)
L·atm એકમ માટે 0.0821; SI એકમ માટે 8.314 · SI: J/(mol·K), L·atm/(mol·K) · ગણતરીમાં એકમ મુજબ યોગ્ય R પસંદ કરો.
દ્રાવણની મોલારિટી (Molarity): M = n_solute / V_solution(L)
M = મોલારિટી (mol/L); n_solute = દ્રાવ્યના મોલ; V_solution = દ્રાવણનું કદ (L) · SI: mol/L અથવા M · દ્રાવણનું કદ લિટરમાં હોય.
મોલારિટીનો વ્યાવહારિક સૂત્ર: M = (w_solute × 1000) / (M_solute × V_solution(mL))
w_solute = દ્રાવ્યનું દળ (g); M_solute = દ્રાવ્યનું મોલર દળ (g/mol); V_solution(mL) = દ્રાવણનું કદ mL માં · SI: mol/L · દ્રાવ્યનું દળ અને દ્રાવણનું કદ mL માં આપેલું હોય.
મોલારિટી ડાઈલ્યુશન સૂત્ર (Dilution Formula): M1V1 = M2V2
M1, V1 = મૂળ દ્રાવણની મોલારિટી અને કદ; M2, V2 = નવી દ્રાવણની મોલારિટી અને કદ · SI: M1,M2: mol/L; V1,V2: same volume unit · પાણી ઉમેરીને દ્રાવણને મોટું (dilute) કરતી વખતે.
મોલality (Molality): m = n_solute / mass_solvent(kg)
m = મોલલિટી; n_solute = દ્રાવ્યના મોલ; mass_solvent = દ્રાવકનું દળ (kg) · SI: mol/kg (અથવા m) · તાપમાન ફેરવાતા મોલલિટી અચળ રહે છે તેથી ઊંચા તાપમાનની ગણતરી માટે.
ફ્રેક્શન ઓફ મોલ (Mole Fraction): X_A = n_A / (n_A + n_B)
X_A = ઘટક A નો મોલ ફ્રેક્શન; n_A, n_B = અનુક્રમે ઘટકોના મોલ · SI: એકમ વગર · દ્રાવણના દરેક ઘટકનો મોલ ફ્રેક્શન 0 થી 1 વચ્ચે હોય છે.
મોલ ફ્રેક્શનનો સરવાળો: X_A + X_B + ... = 1
દ્રાવણમાં રહેલા તમામ ઘટકોના મોલ ફ્રેક્શનનો સરવાળો 1 થાય. · SI: એકમ વગર · બહુ-ઘટકીય દ્રાવણ માટે.
પર્સેન્ટ ઇન્ડેક્સ (Percent by Mass): % w/w = (mass_solute / mass_solution) × 100
mass_solute = દ્રાવ્યનું દળ; mass_solution = દ્રાવણનું કુલ દળ · SI: % (પ્રતિશત) · દળ દ્વારા પ્રમાણ.
પર્સેન્ટ ઇન્ડેક્સ (Percent by Volume): % v/v = (volume_solute / volume_solution) × 100
volume_solute = દ્રાવ્યનું કદ; volume_solution = દ્રાવણનું કુલ કદ · SI: % (પ્રતિશત) · તરલ-તરલ દ્રાવણ માટે.
પર્સેન્ટ ઇન્ડેક્સ (Percent by Mass/Volume): % w/v = (mass_solute(g) / volume_solution(mL)) × 100
mass_solute: g; volume_solution: mL · SI: % w/v · વાદળી દવાખાનાઓ અને બાયોકેમિસ્ટ્રીમાં સામાન્ય.
પાર્ટ્સ પર મિલિયન (PPM): ppm = (mass_solute / mass_solution) × 10^6
અત્યંત સૂક્ષ્મ પ્રદૂષકો માટેનો એકમ · SI: ppm · દ્રાવણ અત્યંત મિથ્યું ધરાવતું હોય ત્યારે.
સ્ટોઇકિયોમેટ્રી — કચરાના ગેસનું કદ: ગેસનું કદ = (n × 22.4 L) at STP
n = આદર્શ ગેસના મોલ · SI: L (STP પર) · રાસાયણિક સમીકરણ પરથી મોલ શોધ્યા પછી.
સાંદ્રતાનું રૂપાંતર (Density and Molarity): M = (% w/w × d × 10) / M_solute
d = દ્રાવણની ઘનતા (g/mL); % w/w = દળ પ્રતિશત; M_solute = મોલર દળ · SI: mol/L · તાગડી (conc.) દ્રાવણની મોલારિટી શોધવા માટે.
સરેરાશ પરમાણુ દળ (Isotopic Abundance): M_avg = (M1×p1 + M2×p2 + ...) / 100
M1, M2 = آئسوટોપના દળ; p1, p2 = આકરા પ્રમાણ (%) · SI: u અથવા g/mol · જ્યારે આકરા આઇસોટોપના પ્રમાણ આપેલા હોય.
પરમાણુ દળ ગણતરી (Atomic Mass Unit to grams): 1 u = 1.6605 × 10^-24 g
u = atomic mass unit · SI: g · એક પરમાણુના દળને ગ્રામમાં બદલવા.
મોલિટી (Normality): N = n_e / V(L)
n_e = સમાન (equivalents); V(L) = દ્રાવણનું કદ (L) · SI: N (eq/L) · ટાઇટ્રેશન (titration) અને પ્રવાહી પ્રક્રિયાઓમાં.
સમાન સંખ્યા (Equivalents): n_eq = n × n-factor
n = મોલ; n-factor = ચયાપચયિકી (valence) factor: આયનોની સંખ્યા, જારક-અપચાયકમાં ઈલેક્ટ્રોન ફેરફાર · SI: eq · ટાઇટ્રેશન અને સમાનતા (equivalence) માટે.
એવોગેડ્રો નિયમ (Avogadro's Law): V ∝ n (T અને P અચળ)
V = કદ; n = મોલ; સમાન T,P પર સમાન કદમાં સમાન અણુઓ હોય છે. · SI: L · આદર્શ ગેસ માટે.

🔗 સંબંધો

  • મોલ (n) એ દળ (m), કણોની સંખ્યા (N), અને ગેસનું કદ (V) વચ્ચેનો પૂરક સેતુ છે: n = m/M = N/N_A = V/22.4(L at STP).
  • મોલારિટી (M) તાપમાન પર આધારિત છે કારણ કે કદ બદલાય છે, પણ મોલલિટી (m) તાપમાનથી અસ્પર્શ્ય રહે છે.
  • મોલ ફ્રેક્શનનો સરવાળો હંમેશા 1 થાય છે; એથી અજ્ઞાત ઘટક શોધી શકાય છે.
  • STP પર આદર્શ ગેસનું મોલર કદ 22.4 L/mol હોય છે, જે ગેસ-પ્રક્રિયાઓમાં મોલ-કદ રૂપાંતરણનું મુખ્ય સાધન છે.
  • સાંદ્ર દ્રાવણ માટે: M = (%w/w × d × 10)/M_solute; આ સૂત્ર ઘનતા અને પ્રતિશતને મોલારિટીમાં રૂપાંતરિત કરે છે.

🎯 ટ્રિક્સ

STP પર 1 મોલ ગેસ ≈ 22.4 L: પ્રશ્નમાં ગેસનું કદ મોલમાં બદલવા માટે V/22.4. દ્વિવિકલ્પમાં આ આંકડો યાદ રાખો.
મોલ અચળાંક R = 0.0821 L·atm/(mol·K) યાદ રાખવા માટે: 'એક આદર્શ ગેસ દબાણ-કદ ગણતરીમાં 0.0821' — આ NEET માં રુઢિગત છે.
મોલલિટી vs મોલારિટી: દ્રાવ્યનું પ્રમાણ વધે તો મોલારિટી વધે, પણ મોલલિટી અચળ રહે છે — તાપમાનમાં ફેરફાર થાય તો સૂઝે.
મોલ ફ્રેક્શનનો સરવાળો 1 છે: એક ઘટક મોલ ફ્રેક્શન વગર બાકી બધાનો સરવાળો કાઢો.
સમાન (equivalent) = મોલ × n-factor: n-factor શોધવા HCl માટે 1, H2SO4 માટે 2, NaOH માટે 1, Ca(OH)2 માટે 2 — એસિડ/બેઝમાં પ્રોટોન/હાઈડ્રોક્સાઈડ આયનોની સંખ્યા.

⚠️ ભૂલો

મોલર દળ (M) ને આંકડા તરીકે લખીને એકમ (g/mol) ભૂલવું અને સૂત્રમાં ગાળવું — અંતિમ જવાબWrong unit ધરાવે છે.
STP પર V_m = 22.4 L/mol લેવું અને બદલે સૂત્ર PV=nRT લાગુ પાડી વિરોધાભાસ ઉભો કરવો — સામાન્ય રીતે 22.4 L/મોલ જ લાગુ પાડો.
મોલારિટીમાં V(L) ને mL માં મૂકી ગણતરી કરવી — 1000 વડે ભાગવું ભૂલવું.
n-factor ભૂલવું (દા.ત. H2SO4 માટે 2 લેવાને બદલે 1 લખવો) → ઇક્વિવેલન્ટ્સWrong.
મોલ ફ્રેક્શનનો સરવાળો 1 હોવા છતાં બે ઘટકોના સરવાળાનું અવલોકન ન કરવું → ખોટો જવાબ.
સાંદ્ર દ્રાવણના % w/w અને ઘનતા (d) વચ્ચેનો સંબંધ વાપરતી વખતે 1000÷d અથવા d×10 નું સૂત્ર ઊલટું મૂકવું — M = (%×d×10)/M_solute નું ધ્યાન રાખો.
માનવ ત્રુટિ: 1 u = 1.6605×10^-24 g ને યાદ રાખ્યા વિના અંદાજિત મૂલ્ય વાપરવું.
રાસાયણિક સમીકરણનું સંતુલન ન કરીને સ્ટોઇકિયોમેટ્રી શરૂ કરવી — પ્રથમ સમીકરણ સંતુલિત કરો.
પ્રશ્નમાં T અને P એકમ કેલ્વિનમાં ન હોય ત્યારે 273.15 ઉમેરવું ભૂલવું — PV=nRT માટે T હંમેશા K માં હોવો જોઈએ.
આયનીકરણ (dissociation) થતાં મોલની સંખ્યા બદલાય છે — ઉદા. NaCl → Na+ + Cl- માટે i = 2, પણ આ મૂળભૂત ધોરણમાં આ ઘટના સામાન્ય રીતે ઉપયોગમાં લેવાતી નથી. NEET UG માં આ સાદા મૂળભૂત ગણતરીમાં સામેલ નથી.
