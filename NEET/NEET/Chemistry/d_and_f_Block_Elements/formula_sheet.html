d અને f બ્લોકના તત્વો — સૂત્ર શેડ્યૂલ

🩺 NEET UG — Gujarati • Chemistry • d and f Block Elements

⚡ સૂત્રો

સામાન્ય ઇલેક્ટ્રોનિક વિન્યાસ (d-બ્લોક): (n-1)d¹⁻¹⁰ ns⁰⁻²
(n-1)d = આંતરિક d-કક્ષક, ns = બાહ્ય s-કક્ષક, n = મુખ્ય કક્ષા સંખ્યા · SI: — · સંક્રાંતિ તત્વો (3d, 4d, 5d, 6d શ્રેણી) માટે
સામાન્ય ઇલેક્ટ્રોનિક વિન્યાસ (f-બ્લોક): (n-2)f¹⁻¹⁴ (n-1)d⁰⁻¹ ns²
(n-2)f = આંતરિક f-કક્ષક, (n-1)d = આંતરિક d-કક્ષક, ns = બાહ્ય s-કક્ષક · SI: — · લેન્થેનોઇડ્સ (4f) અને એક્ટિનોઇડ્સ (5f) માટે
ચુંબકીય ચુંબકત્વ (ચોખ્ખા સ્પિન — Spin-only magnetic moment): μ = √[n(n+2)] B.M.
μ = ચુંબકીય ચુંબકત્વ, n = અયુગ્મિત ઇલેક્ટ્રોનની સંખ્યા, B.M. = બોહર મેગ્નેટોન (Bohr Magneton) · SI: B.M. (બોહર મેગ્નેટોન) · કેવળ સ્પિન યોગદાન માન્ય હોય ત્યારે; d-અયુગ્મિત ઇલેક્ટ્રોન ધરાવતા આયનો માટે
ઘનત્વ અને એકમ કોષ (Unit cell) વચ્ચેનો સંબંધ: ρ = (Z × M) / (a³ × Nₐ)
ρ = ઘનત્વ, Z = એકમ કોષમાં પરમાણુઓની સંખ્યા, M = મોલર દળ, a = એકમ કોષની ધાર, Nₐ = એવોગેડ્રો સંખ્યા · SI: kg/m³ અથવા g/cm³ · ઘન સ્ફટિકીય ઢાંચા માટે; d-બ્લોક તત્વો સામાન્ય રીતે FCC/BCC/HCP ઢાંચા ધરાવે છે
લેન્થેનોઇડ સંકોચન (Lanthanoid contraction): 4d તત્વોનું પરમાણ્વીય ત્રિજ્યા ≈ 5d તત્વોનું પરમાણ્વીય ત્રિજ્યા (ઉદા. Zr ≈ Hf, Nb ≈ Ta, Mo ≈ W)
લેન્થેનોઇડ સંકોચનને કારણે 5d શ્રેણીના તત્વોનું પરમાણ્વીય ત્રિજ્યા 4d શ્રેણીના સમાન તત્વો જેટલું જ હોય છે · SI: — · લેન્થેનોઇડ્સમાં 4f કક્ષક ભરાવાને કારણે પરમાણ્વીય ત્રિજ્યામાં ધીમો ઘટાડો
લેન્થેનોઇડ સંકોચનનું કારણ: 4f ઇલેક્ટ્રોનનું ન્યુક્લિયસ આકર્ષણ અસરકારક રીતે સ્ક્રીનિંગ ન કરી શકે → પ્રભાવી ન્યુક્લિયર ચાર્જ વધે → ત્રિજ્યા ઘટે
4f ઇલેક્ટ્રોનનું સ્ક્રીનિંગ અસરકારક ન હોવાથી પરમાણ્વીય ત્રિજ્યામાં ઘટાડો · SI: — · લેન્થેનોઇડ્સ (Ce થી Lu) માટે
KMnO₄ નું પ્રમાણિત ઓક્સિડેશન — એસિડિક માધ્યમ: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O (E° = +1.51 V)
MnO₄⁻ = પરમેંગેનેટ આયન, H⁺ = એસિડિક માધ્યમ, Mn²⁺ = મેંગેનીઝ આયન, E° = પ્રમાણિત વિભવ · SI: V (વોલ્ટ) · એસિડિક માધ્યમમાં KMnO₄ નું રિડક્શન
KMnO₄ નું રિડક્શન — ન્યૂટ્રલ/અલ્કલાઇન માધ્યમ: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻ (E° = +0.59 V)
MnO₄⁻ = પરમેંગેનેટ આયન, MnO₂ = મેંગેનીઝ ડાયોક્સાઇડ, OH⁻ = હાઇડ્રોક્સાઇડ આયન · SI: V (વોલ્ટ) · ન્યૂટ્રલ અથવા અલ્કલાઇન માધ્યમમાં KMnO₄ નું રિડક્શન
K₂Cr₂O₇ નું રિડક્શન — એસિડિક માધ્યમ: Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O (E° = +1.33 V)
Cr₂O₇²⁻ = ડાયક્રોમેટ આયન, Cr³⁺ = ક્રોમિયમ(III) આયન, H⁺ = એસિડિક માધ્યમ · SI: V (વોલ્ટ) · એસિડિક માધ્યમમાં K₂Cr₂O₇ નું રિડક્શન
K₂Cr₂O₇ → K₂CrO₄ સંતુલન (pH આધારિત): Cr₂O₇²⁻ (નારંગી) + H₂O ⇌ 2CrO₄²⁻ (પીળો) + 2H⁺
Cr₂O₇²⁻ = ડાયક્રોમેટ આયન (નારંગી), CrO₄²⁻ = ક્રોમેટ આયન (પીળો), H⁺ = એસિડિટી · SI: — · એસિડિક માધ્યમમાં નારંગી, અલ્કલાઇન માધ્યમમાં પીળો રંગ
KMnO₄ ની તૈયારી — મિનિયમ અયસ્કથી: 2MnO₂ + 4KOH + O₂ → 2K₂MnO₄ + 2H₂O (ઉકેલમાં, હરિત K₂MnO₄)
MnO₂ = મેંગેનીઝ ડાયોક્સાઇડ, KOH = પોટેશિયમ હાઇડ્રોક્સાઇડ, K₂MnO₄ = પોટેશિયમ મેંગેનેટ · SI: — · MnO₂ નું ઓક્સિડેશન અલ્કલાઇન માધ્યમમાં O₂ હાજરીમાં
KMnO₄ ની તૈયારી — અનુચ્છેદન (Disproportionation): 3K₂MnO₄ + 2H₂SO₄ → 2KMnO₄ + MnO₂ + 2K₂SO₄ + 2H₂O
K₂MnO₄ = પોટેશિયમ મેંગેનેટ, KMnO₄ = પોટેશિયમ પરમેંગેનેટ, H₂SO₄ = સલ્ફ્યુરિક એસિડ · SI: — · K₂MnO₄ નું એસિડિક માધ્યમમાં અનુચ્છેદન
K₂Cr₂O₇ ની તૈયારી — ક્રોમાઇટ અયસ્કથી: 4FeCr₂O₄ + 8Na₂CO₃ + 7O₂ → 8Na₂CrO₄ + 2Fe₂O₃ + 8CO₂
FeCr₂O₄ = ફેરસ ક્રોમાઇટ, Na₂CO₃ = સોડિયમ કાર્બોનેટ, Na₂CrO₄ = સોડિયમ ક્રોમેટ · SI: — · ક્રોમાઇટ અયસ્કનું સોડિયમ કાર્બોનેટ સાથે ઓક્સિડેશન
K₂Cr₂O₇ ની તૈયારી — Na₂CrO₄ → Na₂Cr₂O₇: 2Na₂CrO₄ + H₂SO₄ → Na₂Cr₂O₇ + Na₂SO₄ + H₂O
Na₂CrO₄ = સોડિયમ ક્રોમેટ, H₂SO₄ = સલ્ફ્યુરિક એસિડ, Na₂Cr₂O₇ = સોડિયમ ડાયક્રોમેટ · SI: — · ક્રોમેટ આયનનું એસિડિક માધ્યમમાં ડાયક્રોમેટમાં રૂપાંતર
K₂Cr₂O₇ → K₂Cr₂O₇ (વપરાશ — Fe²⁺ સાથે): Cr₂O₇²⁻ + 14H⁺ + 6Fe²⁺ → 2Cr³⁺ + 6Fe³⁺ + 7H₂O
Cr₂O₇²⁻ = ડાયક્રોમેટ, Fe²⁺ = આયર્ન(II), Cr³⁺ = ક્રોમિયમ(III), Fe³⁺ = આયર્ન(III) · SI: — · KMnO₄/K₂Cr₂O₇ દ્વારા Fe²⁺ ના ઓક્સિડેશનનું ટાઇટ્રેશન
KMnO₄ → I⁻ સાથે (એસિડિક માધ્યમ): 2MnO₄⁻ + 16H⁺ + 10I⁻ → 2Mn²⁺ + 5I₂ + 8H₂O
MnO₄⁻ = પરમેંગેનેટ, I⁻ = આયોડાઇડ, I₂ = આયોડિન · SI: — · KMnO₄ દ્વારા આયોડાઇડનું ઓક્સિડેશન
KMnO₄ → SO₂ સાથે (એસિડિક માધ્યમ): 2MnO₄⁻ + 6H⁺ + 5SO₂ → 2Mn²⁺ + 5SO₄²⁻ + 3H₂O
MnO₄⁻ = પરમેંગેનેટ, SO₂ = સલ્ફર ડાયોક્સાઇડ, SO₄²⁻ = સલ્ફેટ આયન · SI: — · KMnO₄ દ્વારા SO₂ નું ઓક્સિડેશન
KMnO₄ → C₂O₄²⁻ સાથે (એસિડિક માધ્યમ): 2MnO₄⁻ + 16H⁺ + 5C₂O₄²⁻ → 2Mn²⁺ + 10CO₂ + 8H₂O
MnO₄⁻ = પરમેંગેનેટ, C₂O₄²⁻ = ઓક્સાલેટ આયન, CO₂ = કાર્બન ડાયોક્સાઇડ · SI: — · KMnO₄ દ્વારા ઓક્સાલેટનું ઓક્સિડેશન
KMnO₄ → Fe²⁺ સાથે (એસિડિક માધ્યમ): MnO₄⁻ + 8H⁺ + 5Fe²⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O
MnO₄⁻ = પરમેંગેનેટ, Fe²⁺ = આયર્ન(II), Fe³⁺ = આયર્ન(III) · SI: — · KMnO₄ દ્વારા Fe²⁺ ના ઓક્સિડેશનનું ટાઇટ્રેશન
d-બ્લોક તત્વોની ઓક્સિડેશન અવસ્થાઓ: ઓક્સિડેશન અવસ્થા = (n-1)d + ns ઇલેક્ટ્રોનની સંયુક્ત સંખ્યા (ઉચ્ચતમ)
(n-1)d અને ns કક્ષકના ઇલેક્ટ્રોન બંને ભાગ લઈ શકે છે · SI: — · સંક્રાંતિ તત્વોમાં વિવિધ ઓક્સિડેશન અવસ્થાઓ દર્શાવવા માટે
લેન્થેનોઇડ્સની પ્રબળ ઓક્સિડેશન અવસ્થા: લેન્થેનોઇડ્સ: +3 (પ્રબળ), કેટલાક +2 (Eu, Yb) અને +4 (Ce, Tb) પણ દેખાય
+3 = સર્વસામાન્ય ઓક્સિડેશન અવસ્થા, +2/+4 = અપવાદી · SI: — · લેન્થેનોઇડ્સની રાસાયણિક પ્રવૃત્તિ માટે
એક્ટિનોઇડ્સની ઓક્સિડેશન અવસ્થા: એક્ટિનોઇડ્સ: +3 (પ્રબળ), ઉચ્ચ +4, +5, +6, +7 પણ દેખાય (ઉદા. U: +6, Pu: +4,+6,+7)
એક્ટિનોઇડ્સમાં f, d, s બંને કક્ષકોના ઇલેક્ટ્રોન ભાગ લે છે · SI: — · એક્ટિનોઇડ્સ માટે
લેન્થેનોઇડ સંકોચનના પરિણામ — ત્રિજ્યા તફાવત: લેન્થેનોઇડ સંકોચનને કારણે 5d શ્રેણીના તત્વોની ત્રિજ્યા ≈ 4d શ્રેણીના સમાન તત્વની ત્રિજ્યા
ઉદા. Zr (4d) ≈ Hf (5d), Nb ≈ Ta, Mo ≈ W · SI: pm (પિકોમીટર) · લેન્થેનોઇડ સંકોચનને કારણે
લેન્થેનોઇડ્સનું પૃથક્કરણ — આયન વિનિમય પદ્ધતિ: લેન્થેનોઇડ્સના આયનોનું વિનિમય રેઝિન પર શોષણ → Na₂EDTA દ્વારા ધોવાણ → પ્રત્યેક તત્વ અલગ
લેન્થેનોઇડ્સના સમાન ગુણધર્મોને કારણે આ પદ્ધતિ અનન્ય છે · SI: — · લેન્થેનોઇડ્સનું પૃથક્કરણ

🔗 સંબંધો

  • d-બ્લોક તત્વોમાં પરમાણ્વીય ત્રિજ્યા ડાબેથી જમણે ઘટે છે, પરંતુ 3d શ્રેણીમાં અંતે થોડી વધારો થાય છે કારણ કે d-ઇલેક્ટ્રોનનું સ્ક્રીનિંગ અસરકારક નથી હોતું.
  • લેન્થેનોઇડ સંકોચનને કારણે 5d શ્રેણીના તત્વો (Hf, Ta, W) ની પરમાણ્વીય ત્રિજ્યા 4d શ્રેણીના સમાન તત્વો (Zr, Nb, Mo) જેટલી જ હોય છે, જેના કારણે તેમના રાસાયણિક ગુણધર્મો સમાન છે.
  • KMnO₄ એ K₂Cr₂O₇ કરતાં વધુ પ્રબળ ઓક્સિડાઇઝિંગ એજન્ટ છે (E° MnO₄⁻/Mn²⁺ = +1.51 V > E° Cr₂O₇²⁻/Cr³⁺ = +1.33 V).
  • d-બ્લોક તત્વોના આયનોમાં અયુગ્મિત ઇલેક્ટ્રોન હોવાથી તેઓ પર ચુંબકીય ગુણધર્મ દર્શાવે છે; અયુગ્મિત ઇલેક્ટ્રોન વધુ હોય તો ચુંબકીય ચુંબકત્વ વધુ હોય છે.
  • લેન્થેનોઇડ્સમાં +3 ઓક્સિડેશન અવસ્થા સર્વસામાન્ય છે કારણ કે f-ઇલેક્ટ્રોન ન્યુક્લિયસ સાથે મજબૂત બંધન ધરાવે છે અને સહેલાઈથી ભાગ લેતા નથી.
  • KMnO₄ નું એસિડિક માધ્યમમાં રિડક્શન MnO₄⁻ → Mn²⁺ (5e⁻) થાય છે, જ્યારે અલ્કલાઇન માધ્યમમાં MnO₄⁻ → MnO₂ (3e⁻) થાય છે.

🎯 ટ્રિક્સ

d-બ્લોક તત્વોમાં ઉચ્ચતમ ઓક્સિડેશન અવસ્થા = (n-1)d અને ns કક્ષકના ઇલેક્ટ્રોનની કુલ સંખ્યા; ઉદા. Mn (3d⁵4s²) → +7, Cr (3d⁵4s¹) → +6.
ચુંબકીય ચુંબકત્વની ગણતરી: n = અયુગ્મિત ઇલેક્ટ્રોન, μ = √[n(n+2)] B.M. — ઉદા. Fe²⁺ (d⁶, 4 અયુગ્મિત) → μ = √24 = 4.90 B.M.
KMnO₄ ના ટાઇટ્રેશનમાં H₂SO₄ જ ઉપયોગ કરવો; HCl ઉપયોગ કરીએ તો Cl⁻ નું ઓક્સિડેશન થઈ Cl₂ બને છે, HNO₃ પોતે ઓક્સિડાઇઝર છે.
K₂Cr₂O₇ નારંગી રંગનું, K₂CrO₄ પીળું — એસિડ ઉમેરતાં પીળું → નારંગી, ક્ષાર ઉમેરતાં નારંગી → પીળું.
લેન્થેનોઇડ સંકોચનને કારણે Zr અને Hf, Nb અને Ta, Mo અને W એકસરખા ગુણધર્મ ધરાવે છે — આ યાદ રાખવાનું સૂત્ર: '4d-5d સમાનતા = લેન્થેનોઇડ સંકોચન'.
d-બ્લોક તત્વોના રંગનું કારણ d-d સંક્રાંતિ છે; જેમ અયુગ્મિત d-ઇલેક્ટ્રોન વધુ, તેમ રંગ ગાઢો.

⚠️ ભૂલો

MnO₄⁻ નું એસિડિક માધ્યમમાં રિડક્શન Mn²⁺ સુધી થાય છે, MnO₄²⁻ સુધી નહીં — ઘણા વિદ્યાર્થીઓ MnO₄²⁻ (મેંગેનેટ) માની લે છે.
K₂Cr₂O₇ નું એસિડિક માધ્યમમાં રિડક્શન Cr³⁺ સુધી થાય છે, Cr⁶⁺ સુધી નહીં — ઓક્સિડેશન અવસ્થા 6 થી 3 થાય છે.
લેન્થેનોઇડ સંકોચન 4f કક્ષકના ઇલેક્ટ્રોનના અસરકારક સ્ક્રીનિંગને કારણે થાય છે, 5d નહીં.
KMnO₄ નું અલ્કલાઇન માધ્યમમાં રિડક્શન MnO₂ (Mn⁴⁺) સુધી થાય છે, Mn²⁺ સુધી નહીં.
d-બ્લોક તત્વોની પરમાણ્વીય ત્રિજ્યા ડાબેથી જમણે સામાન્ય રીતે ઘટે છે, પરંતુ Zn અને Cu માં થોડી વધારો થાય છે — આને 'સામાન્ય ઘટાડો' માની લેવામાં આવે છે.
લેન્થેનોઇડ્સમાં +3 ઓક્સિડેશન અવસ્થા સર્વસામાન્ય છે, પણ Ce⁴⁺ અને Eu²⁺ સ્થિર છે કારણ કે f⁰ અને f⁷ વિન્યાસ મળે છે.
KMnO₄ ની તૈયારીમાં K₂MnO₄ નું અનુચ્છેદન (disproportionation) થાય છે — MnO₄⁻ અને MnO₂ બંને બને છે.
d-બ્લોક તત્વોમાં ઓક્સિડેશન અવસ્થાઓની વિવિધતા (n-1)d અને ns બંને કક્ષકોના ઇલેક્ટ્રોન ભાગ લે છે — માત્ર ns નહીં.
