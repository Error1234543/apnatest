s-Block Elements: NEET UG માટે ઉપયોગી પરીક્ષા ટીપ્સ (Exam Tricks)

🩺 NEET UG — Gujarati • Chemistry • s-Block Elements

🎯 પરીક્ષા ટ્રિક્સ

આલ્કલી ધાતુઓ (Alkali Metals) ના ગલનબિંદુ અને ઉત્કલનબિંદુ નીચે તરફ જતાં ઘટે છે. યાદ રાખવા માટે: Li > Na > K > Rb > Cs (ગલનબિંદુ ક્રમ).
જ્યારે આલ્કલી ધાતુઓના ભૌતિક ગુણધર્મોની તુલના કરવાની હોય.
દા.ત.: Cs નો ગલનબિંદુ સૌથી ઓછો (28.5°C) હોવાથી તે ઓરડાના તાપમાને દ્રવ્ય સ્વરૂપે હોઈ શકે.
આલ્કલી ધાતુઓની પ્રતિક્રિયાશીલતા પાણી સાથે નીચે તરફ જતાં વધે છે: Li < Na < K < Rb < Cs.
પ્રતિક્રિયાશીલતાના ક્રમને યાદ રાખવા માટે.
દા.ત.: Cs પાણી સાથે સૌથી જોરદાર પ્રતિક્રિયા આપે છે, જ્યારે Li સૌથી ધીમી પ્રતિક્રિયા આપે છે.
આલ્કલી ધાતુઓના હાઇડ્રોક્સાઇડ (MOH) ના જલીય દ્રાવણો ક્ષારીય (basic) હોય છે. pH ક્રમ: LiOH < NaOH < KOH < RbOH < CsOH.
જ્યારે ક્ષારીયતાની તીવ્રતાનો ક્રમ યાદ રાખવો હોય.
દા.ત.: CsOH સૌથી મજબૂત ક્ષાર (strongest base) છે.
બેરિલિયમ (Be) અને મેગ્નેશિયમ (Mg) ના હાઇડ્રોક્સાઇડ ઉષ્મા સાથે વિઘટન પામે છે અને ઓક્સાઇડ બનાવે છે: M(OH)₂ → MO + H₂O.
આલ્કલાઇન અરથ ધાતુઓના હાઇડ્રોક્સાઇડના ગુણધર્મો યાદ રાખવા માટે.
દા.ત.: Mg(OH)₂ ને ગરમ કરતાં MgO બને છે.
લિથિયમ (Li) ની પ્રતિક્રિયાઓ એલ્યુમિનિયમ (Al) સાથે મળતી આવે છે (Diagonal Relationship). ઉદા. LiOH અને Al(OH)₃ બંને ઉષ્મા સાથે વિઘટન પામે છે.
Diagonal Relationship ના ઉદાહરણો યાદ રાખવા માટે.
દા.ત.: LiOH → Li₂O + H₂O (ગરમ કરતાં).
આલ્કલી ધાતુઓના કાર્બોનેટ (M₂CO₃) અને બાઇકાર્બોનેટ (MHCO₃) ઉષ્મીય સ્થિરતા: Li₂CO₃ < Na₂CO₃ < K₂CO₃ < Rb₂CO₃ < Cs₂CO₃. લિથિયમનું કાર્બોનેટ સૌથી ઓછું સ્થિર છે.
કાર્બોનેટની ઉષ્મીય સ્થિરતાનો ક્રમ યાદ રાખવા માટે.
દા.ત.: Li₂CO₃ ગરમ કરતાં Li₂O અને CO₂માં વિઘટન પામે છે.
બેરિલિયમ (Be) અને મેગ્નેશિયમ (Mg) ના કાર્બોનેટ ઉષ્મા સાથે વિઘટન પામી ઓક્સાઇડ અને CO₂ બનાવે છે: MCO₃ → MO + CO₂.
આલ્કલાઇન અરથ ધાતુઓના કાર્બોનેટના ગુણધર્મો યાદ રાખવા માટે.
દા.ત.: MgCO₃ → MgO + CO₂ (ગરમ કરતાં).
લિથિયમ ક્લોરાઇડ (LiCl) અતિ દ્રાવ્ય અને હાઇગ્રોસ્કોપિક (Hygroscopic) છે, જ્યારે અન્ય આલ્કલી ધાતુઓના ક્લોરાઇડ ઓછા દ્રાવ્ય હોય છે.
આલ્કલી ધાતુઓના ક્લોરાઇડના દ્રાવ્યતાના ગુણધર્મો યાદ રાખવા માટે.
દા.ત.: LiCl નો ઉપયોગ વાયુ શોષક (drying agent) તરીકે થાય છે.
આલ્કલી ધાતુઓના નાઇટ્રેટ (MNO₃) અને સલ્ફેટ (M₂SO₄) જલીય દ્રાવણોમાં દ્રાવ્ય હોય છે, પરંતુ લિથિયમ લિથોફિલ (Lithophil) હોવાથી તેના નાઇટ્રેટ અને સલ્ફેટ ઓછા દ્રાવ્ય હોય છે.
દ્રાવ્યતાના ગુણધર્મોની તુલના કરવા માટે.
દા.ત.: Li₂SO₄ ઓછું દ્રાવ્ય છે, જ્યારે Na₂SO₄ અતિ દ્રાવ્ય છે.
બેરિલિયમ (Be) અને મેગ્નેશિયમ (Mg) ના નાઇટ્રેટ વિઘટન પામી ઓક્સાઇડ, નાઇટ્રોજન ડાયોક્સાઇડ (NO₂) અને ઓક્સિજન (O₂) બનાવે છે: 2M(NO₃)₂ → 2MO + 4NO₂ + O₂.
નાઇટ્રેટના વિઘટન પ્રતિક્રિયાઓ યાદ રાખવા માટે.
દા.ત.: 2Mg(NO₃)₂ → 2MgO + 4NO₂ + O₂ (ગરમ કરતાં).
આલ્કલી ધાતુઓના સલ્ફેટ (M₂SO₄) ની ઉષ્મીય સ્થિરતા નીચે તરફ જતાં વધે છે: Li₂SO₄ < Na₂SO₄ < K₂SO₄ < Rb₂SO₄ < Cs₂SO₄.
સલ્ફેટની ઉષ્મીય સ્થિરતાનો ક્રમ યાદ રાખવા માટે.
દા.ત.: Li₂SO₄ સૌથી ઓછું સ્થિર છે અને ગરમ કરતાં વિઘટન પામે છે.
લિથિયમ (Li) એકમાત્ર આલ્કલી ધાતુ છે જે નાઇટ્રોજન સાથે સીધી પ્રતિક્રિયા આપી લિથિયમ નાઇટ્રાઇડ (Li₃N) બનાવે છે: 6Li + N₂ → 2Li₃N.
લિથિયમના અસાધારણ ગુણધર્મો યાદ રાખવા માટે.
દા.ત.: અન્ય આલ્કલી ધાતુઓ નાઇટ્રોજન સાથે પ્રતિક્રિયા આપતી નથી.
બેરિલિયમ (Be) અને મેગ્નેશિયમ (Mg) ના હાઇડ્રોક્સાઇડ એમ્ફોટેરિક (Amphoteric) હોય છે, જ્યારે અન્ય આલ્કલાઇન અરથ ધાતુઓના હાઇડ્રોક્સાઇડ ક્ષારીય હોય છે.
હાઇડ્રોક્સાઇડના ગુણધર્મોની તુલના કરવા માટે.
દા.ત.: Be(OH)₂ અને Mg(OH)₂ એસિડ અને બેઇઝ સાથે પ્રતિક્રિયા આપે છે.
આલ્કલી ધાતુઓના ફ્લોરાઇડ (MF) ઓછા દ્રાવ્ય હોય છે, જ્યારે ક્લોરાઇડ (MCl), બ્રોમાઇડ (MBr), અને આયોડાઇડ (MI) અતિ દ્રાવ્ય હોય છે.
હેલાઇડના દ્રાવ્યતાના ગુણધર્મો યાદ રાખવા માટે.
દા.ત.: LiF ઓછું દ્રાવ્ય છે, જ્યારે LiCl અતિ દ્રાવ્ય છે.
