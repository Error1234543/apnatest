એમાઇન્સ (Amines) — NEET UG ગુજરાતી મધ્યમ શાળા માટે પરીક્ષા ટ્રિક્સ

🩺 NEET UG — Gujarati • Chemistry • Amines

🎯 પરીક્ષા ટ્રિક્સ

પ્રાથમિક, દ્વિતીયક અને તૃતીયક એમાઇન્સની ઓળખ: N પર બંધાયેલા H પરમાણુઓ ગણો. 3 H = પ્રાથમિક, 2 H = દ્વિતીયક, 1 H = તૃતીયક.
જ્યારે પ્રશ્નમાં એમાઇનનો પ્રકાર પૂછવામાં આવે અથવા ઓળખવાની હોય.
દા.ત.: CH₃NH₂ માં N પર 2 H છે → દ્વિતીયક એમાઇન. (CH₃)₃N માં N પર 0 H છે → તૃતીયક એમાઇન.
બેઝિક લક્ષણની તુલના: એલિફેટિક એમાઇન્સ > એરોમેટિક એમાઇન્સ. +I અસર બેઝિકતા વધારે, -M/-I અસર બેઝિકતા ઘટાડે.
જ્યારે બે એમાઇન્સની બેઝિકતાની તુલના કરવાની હોય.
દા.ત.: CH₃NH₂ > C₆H₅NH₂ કારણ કે CH₃ ની +I અસર N પર ઇલેક્ટ્રોન ઘનતા વધારે, જ્યારે C₆H₅ ની -M અસર ઘટાડે.
એરોમેટિક એમાઇન્સમાં -NH₂ સમૂહ ઇલેક્ટ્રોન દાતા (EDG) છે → બેન્ઝીન રિંગને સક્રિય કરે છે → ઇલેક્ટ્રોફિલિક સબસ્ટિટ્યુશન સરળ બને છે.
જ્યારે એનાઇલીનના રિએક્ટિવિટી અથવા સબસ્ટિટ્યુશન પોઝિશન વિશે પૂછે.
દા.ત.: એનાઇલીનનું નાઇટ્રેશન → o- અને p-નાઇટ્રોએનાઇલીન મળે છે કારણ કે -NH₂ ortho/para ડાયરેક્ટર છે.
હોફમેન બ્રોમામાઇડ રિએક્શન: એમાઇડ → પ્રાથમિક એમાઇન (1 કાર્બન ઓછો). આ રિએક્શન માત્ર પ્રાથમિક એમાઇન્સ બનાવે છે.
જ્યારે પ્રાથમિક એમાઇન તૈયાર કરવાની રીત પૂછે અથવા પ્રોડક્ટ ઓળખવાની હોય.
દા.ત.: C₆H₅CONH₂ + Br₂ + 4NaOH → C₆H₅NH₂ + Na₂CO₃ + 2NaBr + 2H₂O (એનાઇલીન મળે છે, 1 C ઓછો).
કાર્બાયલામાઇન ટેસ્ટ: માત્ર પ્રાથમિક એમાઇન્સ (એલિફેટિક અને એરોમેટિક બંને) આ ટેસ્ટ આપે છે._secondary_ અને_tertiary_ આપતા નથી.
જ્યારે પ્રાથમિક એમાઇનની ઓળખ કરવાની હોય અથવા ટેસ્ટ વિશે પૂછે.
દા.ત.: C₆H₅NH₂ + CHCl₃ + 3KOH(ઉષ્મા) → C₆H₅NC (ખરાબ ગંધ, પ્રાથમિક એમાઇનની ઓળખ).
ડાયઝોનિયમ સોલ્ટ સ્થિરતા: એરોમેટિક ડાયઝોનિયમ સોલ્ટ એલિફેટિક કરતા વધુ સ્થિર છે કારણ કે રેઝોનન્સથી st abilization મળે છે.
જ્યારે ડાયઝોનિયમ સોલ્ટની સ્થિરતા અથવા પ્રકાર વિશે પૂછે.
દા.ત.: C₆H₅N₂⁺Cl⁻ (એરોમેટિક) 0-5°C સુધી સ્થિર રહે છે, જ્યારે CH₃N₂⁺Cl⁻ તરત વિઘટન પામે છે.
એમાઇન્સનું હાઇડ્રોજન બોન્ડિંગ: પ્રાથમિક એમાઇન્સ (2 H) > દ્વિતીયક (1 H) > તૃતીયક (0 H) → ઉત્કલન બિંદુ ક્રમ.
જ્યારે એમાઇન્સના ભૌતિક ગુણધર્મો અથવા ઉત્કલન બિંદુની તુલના કરવાની હોય.
દા.ત.: CH₃CH₂NH₂ > (CH₃)₂NH > (CH₃)₃N → ઉત્કલન બિંદુ: પ્રાથમિક > દ્વિતીયક > તૃતીયક (હાઇડ્રોજન બોન્ડિંગ કારણે).
એનાઇલીનનું એસિલેશન: -NH₂ સમૂહને બ્લોક કરવા માટે એસિટેટ સમૂહ મૂકો, પ્રક્રિયા પછી હાઇડ્રોલિસિસથી ફરી -NH₂ મેળવો.
જ્યારે એનાઇલીનમાં સબસ્ટિટ્યુશન કરવાનું હોય અને મલ્ટિપલ પ્રોડક્ટ બનતી અટકાવવી હોય.
દા.ત.: C₆H₅NH₂ + (CH₃CO)₂O → C₆H₅NHCOCH₃ (એસિટેમાઇડ) → નાઇટ્રેશન → હાઇડ્રોલિસિસ → o/p-નાઇટ્રોએનાઇલીન.
એમાઇન્સની ગંધ: પ્રાથમિક એમાઇન્સમાં માછલી જેવી ગંધ, દ્વિતીયક અને તૃતીયક એમાઇન્સમાં પણ સમાન ગંધ. કાર્બાયલામાઇન (R-NC) ખૂબ જ ખરાબ ગંધ ધરાવે છે.
જ્યારે એમાઇન પ્રકાર અથવા કાર્બાયલામાઇન ટેસ્ટ વિશે પૂછે.
દા.ત.: CH₃NC (મિથાઇલ કાર્બાયલામાઇન) → અસહ્ય ગંધ, આ ટેસ્ટથી પ્રાથમિક એમાઇન ઓળખાય.
સોડા લાઇમ ડીકાર્બોક્સિલેશન: RCOONa + NaOH/CaO → RH + Na₂CO₃. આ રીતે પ્રાથમિક એમાઇન બનાવી શકાતું નથી, પરંતુ એમાઇડથી બનાવી શકાય.
જ્યારે એમાઇન તૈયારીની રીતો વિશે પૂછે અને વિકલ્પોમાંથી સાચો પસંદ કરવો હોય.
દા.ત.: CH₃CONH₂ + Br₂/4KOH → CH₃NH₂ (હોફમેન રિએક્શન, પ્રાથમિક એમાઇન મળે).
એરોમેટિક એમાઇન્સમાં N પરના ઇલેક્ટ્રોનનું રેઝોનન્સ → બેઝિકતા ઘટે. જેટલું મજબૂત -M સમૂહ (NO₂, CN) નજીક હોય, બેઝિકતા તેટલી ઓછી.
જ્યારે વિવિધ એરોમેટિક એમાઇન્સની બેઝિકતા ક્રમ પૂછે.
દા.ત.: p-નાઇટ્રોએનાઇલીન < એનાઇલીન < p-મેથોક્સીએનાઇલીન (NO₂ -M, OCH₃ +M).
ગાઉટ્ટબેર્ગ રિએક્શન: એરોમેટિક નાઇટ્રો સંયોજન → Sn/HCl અથવા Fe/HCl → એરોમેટિક પ્રાથમિક એમાઇન.
જ્યારે પ્રાથમિક એમાઇન તૈયારીની રીતોમાંથી સાચો વિકલ્પ પસંદ કરવો હોય.
દા.ત.: C₆H₅NO₂ + 6[H] (Sn/HCl) → C₆H₅NH₂ + 2H₂O (એનાઇલીન મળે).
એમાઇન્સ એસિડ સાથે પ્રક્રિયા કરી એમાઇન લવણ બનાવે છે: R-NH₂ + HCl → R-NH₃⁺Cl⁻. આ લવણ બેઝ સાથે મુક્ત એમાઇન આપે.
જ્યારે એમાઇનની અલગતા અથવા શુદ્ધિકરણ વિશે પૂછે.
દા.ત.: C₆H₅NH₂ + HCl → C₆H₅NH₃⁺Cl⁻ (એનાઇલીન હાઇડ્રોક્લોરાઇડ) + NaOH → C₆H₅NH₂ (ફરી મુક્ત એમાઇન).
જ્યારે પ્રશ્નમાં 'કયો પ્રાથમિક એમાઇન નથી' પૂછે → તૃતીયક એમાઇન (3°) અથવા દ્વિતીયક એમાઇન (2°) શોધો. 3° એમાઇનમાં N પર કોઈ H નથી.
જ્યારે એમાઇન પ્રકારની ઓળખ અથવા વર્ગીકરણ વિશે પૂછે.
દા.ત.: (CH₃CH₂)₃N → તૃતીયક એમાઇન (3°), N પર 0 H. CH₃NHCH₃ → દ્વિતીયક (2°), N પર 1 H.
એમાઇન્સનું એલિલેશન: પ્રાથમિક એમાઇન + alkyl halide → દ્વિતીયક → તૃતીયક → ક્વાટર્નરી એમાઇન સોલ્ટ. આ રિએક્શન સતત ચાલે છે.
જ્યારે એમાઇનની એલિલેશન પ્રક્રિયા અથવા પ્રોડક્ટ ક્રમ વિશે પૂછે.
દા.ત.: CH₃NH₂ + CH₃I → (CH₃)₂NH → (CH₃)₃N → (CH₃)₄N⁺I⁻ (ક્વાટર્નરી એમાઇન સોલ્ટ).
