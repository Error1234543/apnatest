એમિનીઝ — મહત્વના બિંદુઓ

🩺 NEET UG — Gujarati • Chemistry • Amines

⭐ મહત્વના મુદ્દા

એમિનીઝ એ એમાઇન સમૂહ (−NH₂, −NHR અથવા −NR₂) ધરાવતી એલિફેટિક/એરોમેટિક એમોનિયા વ્યુત્પન્નો છે; આધારીય ગુણધર્મ તેમનું મુખ્ય સവിશેષ લક્ષણ છે.
NEET માં ક્લાસિફિકેશન અને મૂળભૂત નામકરણમાંથી સીધું પ્રશ્ન આવે છે.
IUPAC નામકરણમાં R−NH₂ → એલિફેઇમાઇન, R₂NH → ડાયએલિફેઇમાઇન, R₃N → ટ્રાયએલિફેઇમાઇન; બેન્ઝીન રિંગ જોડાણે બેઝાઇન/નેપથાલીન જેવું ઉમેરવામાં આવે છે.
નામકરણ NEETમાં હંમેશા પ્રાથમિકતા સાથે પૂછાય છે.
પ્રાથમિક, દ્વિતીયક અને તૃતીયક એમિનીઝની પરિભાષા NH₃માંથી એક, બે કે ત્રણ H પરમાણુઓ હટાડી R સમૂહ મેળવવા મળે છે.
આધારીયતા અને પ્રતિક્રિયાઓના વિષયમાં ક્લાસિફિકેશન જરૂરી છે.
એરોમેટિક એમિનીઝમાં એનાઇલિન (C₆H₅−NH₂) સૌથી મહત્વપૂર્ણ છે; તેની એમિનો ગ્રુપ રિંગમાં +M (મેસોમરિક) પ્રભાવથી ઇલેક્ટ્રોન ઘનતા વધારે છે.
ઇલેક્ટ્રોફિલિક સબસ્ટિટ્યુશન પ્રતિક્રિયાઓનો અભ્યાસ કરવા માટે એનાઇલિન આધાર છે.
એમિનીઝની પ્રসિદ્ધ તૈયારી પદ્ધતિઓ: (૧) નાઈટ્રો સંયોજનોની રિડક્શન (Sn/HCl, Fe/HCl, Zn/HCl, LiAlH₄), (૨) ગેબ્રીઅલ ફથાલિમાઇડ પદ્ધતિ (શુદ્ધ પ્રાથમિક એમિનીઝ), (૩) હોફમાન બ્રોમેડ ગ્રેડેશન (એમાઇડ → 1° એમિન, એક કાર્બન ઓછું), (૪) એમાઇડની રિડક્શન, (૫) એઝાઇડ પદ્ધતિ.
NEETમાં કોઈ એક પદ્ધતિથી એમિન બનાવવાનો પ્રશ્ન હંમેશા આવે છે; દરેક પદ્ધતિની શરતો અને ઉપજ યાદ રાખવી જરૂરી છે.
ગેબ્રીઅલ ફથાલિમાઇડ પદ્ધતિ ફકત પ્રાથમિક એમિનીઝ આપે છે — દ્વિતીયક/તૃતીયક એમિનીઝ આ પદ્ધતિથી મેળવી શકાતી નથી.
વધુ-તૃતીયક એમિનીઝ અપ્રાપ્ય હોવાનો અનુભવ NEET પસંદગી પૂછે છે.
હોફમાન બ્રોમેડ ગ્રેડેશન: RCONH₂ + Br₂ + 4KOH (alc.) → RNH₂ (1°) + K₂CO₃ + 2KBr + 2H₂O; કન્વર્ઝનમાં એક −C સાથે R-છૂટો થાય છે.
એક કાર્બન ઓછું કરીને 1° એમિન મેળવવું — NEETમાં સંખ્યાબંધ પ્રશ્નો આ પાછળથી આવે છે.
એમિનીઝના નાઈટ્રસ એસિડ (HNO₂) સાથે પ્રતિક્રિયાઓ: 1° એમિન (એલિફેટિક) → અસ્થિર ડાયઝોનિયમ → N₂ + એલ્કોહોલ; 1° એમિન (એરોમેટિક) → સ્થિર એરોમેટિક ડાયઝોનિયમ લવણ; 2° એમિન → N-નાઇટ્રોસો એમિન (પીળો તેલ); 3° એમિન (એલિફેટિક) → સોલ્યુબલ નાઇટ્રાઇટ સ્વરૂપે પ્રતિક્રિયા.
1°, 2°, 3° એમિનીઝ અચાનક તફાવત આપતું આ પ્રતિક્રિયા શ્રેષ્ઠ છે; ડાયઝોનિયમ કემિકલ્સનો ભાગ પણ આ પર આધારિત છે.
કાર્બાઇલામાઇન પ્રતિક્રિયા (ઇસોકાનાઇડ તૈયારી): 1° એમિન + CHCl₃ + alc. KOH → R−N≡C (ઇસોકાનાઇડ, દુર્ગંધ); 2° અને 3° એમિનીઝ આ પ્રતિક્રિયા આપતી નથી.
1° એમિનીઝની આ ચોકસાઇથી ઓળખ (distinction test) NEETમાં હંમેશા આવે છે.
એસીલેશન પ્રતિક્રિયા (Schotten-Baumann): 1° અને 2° એમિનીઝ + એસિડ ક્લોરાઇડ/એસિડ એનહેડ્રાઇડ → એમાઇડ. 3° એમિનીઝ એસીલેશન આપતી નથી કારણ કે N પર H હોતો નથી.
એમાઇડ બનાવવાની પ્રતિક્રિયા અને 3° એમિનીઝનો અભાવ NEET-પ્રધાન છે.
એનાઇલિનની એસિટીલેશન (Acetylation): એનાઇલિન + (CH₃CO)₂O/pyridine → એસિટેનાઇડ (ACE, એસિટામાઇન); એક સંરક્ષણ પદ્ધતિ તરીકે કાર્યરત.
રક્ષણ સમૂહ (protecting group) નો ઉપયોગ NEET રાસાયણિક સંશ્લેષણ પ્રશ્નોમાં આવે છે.
એનાઇલિનની ઇલેક્ટ્રોફિલિક એરોમેટિક સબસ્ટિટ્યુશન: −NH₂ +M હેતુથી ઓર્થો અને પારા પોઝિશનને સક્રિય કરે છે; નાઇટ્રેશન → મિશ્ર 2- અને 4-નાઇટ્રો એનાઇલિન; બ્રોમીનેશન → 2,4,6-ટ્રાઇબ્રોમો એનાઇલિન (શ્વેત અવક્ષેપ).
મલ્ટીપ્લ સાબિતી (precipitate, orientation) NEETમાં પ્રયોગ-આધારિત પ્રશ્નો માટે વપરાય છે.
એનાઇલિનની નાઇટ્રેશન મિશ્ર એસિડ (conc. HNO₃ + conc. H₂SO₄) વડે: 1° નાઇટ્રો એનાઇલિન (પારા) અને 2° નાઇટ્રો એનાઇલિન (ઓર્થો) બંને બનશે; ઉચ્ચ તાપમાને 2,4,6-ટ્રાઇનાઇટ્રો એનાઇલિન (ટેક્સોગન) મળે.
ઉત્પાદન વંટન અને સ્થિતિઓ NEETમાં પસંદગી અને પ્રતિક્રિયા-અનુભવ પ્રશ્નોમાં આવે છે.
એમિનીઝની આધારીયતા (basicity) યોગ્ય રીતે સમજવી જરૂરી છે: ગેસ ફેઝમાં — 3° > 2° > 1° > NH₃ (ઇલેક્ટ્રોન દાન +I સમૂહ); જલદ્રાવણમાં — 2° > 1° > 3° > NH₃ (સોલવેશન / H-bonding અને સ્ટેરિક અવરોધ સંયુક્ત).
આધારીયતાનો અનુક્રમ NEETનો સર્વપ્રચલિત પ્રશ્ન છે; ગેસ અને જલદ્રાવણમાં તફાવત સમજવો ફરજિયાત છે.
એરોમેટિક એમિનીઝ (બેઝાઇન)ની આધારીયતા એલિફેટિક એમિનીઝ કરતા ઓછી હોય છે કારણ કે N પરનો એકલા ઇલેક્ટ્રોન જોડી એરોમેટિક રિંગ સાથે સંયુગ્મન (conjugation) ધરાવે છે; એનાઇલિન < NH₃.
એરોમેટિક vs એલિફેટિક એમિનીઝની આધારીયતા યોગ્ય રીતે સરખામણી NEETમાં પૂછાય છે.
ડાયઝોનિયમ લવણ (Ar−N₂⁺ X⁻) ની પ્રતિક્રિયાઓ: (૧) H₂O/t.gرمی → Ar−OH + N₂, (૨) HBF₄/ઉષ્મા → સ્ક્રિપ્સ પ્રતિક્રિયા, (૩) CuCN → એરોનેટ્રાઇલ, (૪) CuX → એરોમાઇલો હેલાઇડ, (૫) SnCl₂/HCl → એરોલાઇન (એરોમેટિક 1° એમિન).
ડાયઝોનિયમ પ્રતિક્રિયાઓ એમિનીઝ બેચમાં NEETનો ખૂબ જ મહત્વપૂર્ણ અને પ્રચલિત વિષય છે.
ડાયઝોનિયમ લવણ સાથે યુગ્મન (coupling) પ્રતિક્રિયા: એસિડિક માધ્યમમાં પ્રિયોલાઇન/બેઝાઇન સાથે → એઝો સંયોજન (Ar−N=N−Ar); આ સંયોજનો પ્રબળ રંગક (dye) તરીકે વપરાય છે.
એઝો રંગક અને યુગ્મન પ્રતિક્રિયા NEETમાં રંગક રાસાયણિક વિષય માટે આવે છે.
એનિલિન + H₂O/Pb → સ્નર્કલ ઇન્ડીકેટર (phenylhydrazine) બને છે; આ પ્રતિક્રિયા એનાઇલિનની વિશિષ્ટ ઓળખ છે.
સ્નર્કલ અને એનાઇલિનની પ્રતિક્રિયા NEET રસાયણ વિષયમાં વારંવાર પૂછાય છે.
એમિનીઝની ભૌતિક ગુણધર્મો: 1° અને 2° એમિનીઝ H-bonding ધરાવે છે → ઉચ્ચ ઉત્કલનબિંદુ; 3° એમિનીઝમાં H-bonding ન હોવાથી ઉત્કલનબિંદુ ઓછું. નાના એમિનીઝ (મિથાઇલ, એથાઇલ) પાણીમાં ઓગળે છે; મોટા એમિનીઝમાં જಲદ્રાવ્યતા ઘટે છે.
ભૌતિક ગુણધર્મ અને H-bonding NEET પૂછાડમાં આવે છે.
એમિનીઝ + HNO₂ (નાઇટ્રસ એસિડ) પ્રતિક્રિયાથી 1°, 2°, 3° એમિનીઝ વચ્ચે તફાવત મેળવી શકાય: 1° (એલિફેટિક) → N₂ વાયુ; 2° → પીળો તેલ (N-નાઇટ્રોસો એમિન); 3° (એલિફેટિક) → પ્રતિક્રિયા/ઘોળ.
ત્રણેય એમિનીઝનો અનુભવ એક પ્રતિક્રિયાથી કરવો — NEETમાં પ્રયોગ શ્રેષ્ઠ તફાવત છે.
એમિનીઝની એલિફેટિક અને એરોમેટિક ક્લાસમાં વિભાજન: એનાઇલિન એટલેક 1° એરોમેટિક એમિન; તેના ઇલેક્ટ્રોનિક, સંયોજન અને પ્રતિક્રિયા લક્ષણો એલિફેટિક 1° એમિન કરતાં મૂળભૂત રીતે અલગ છે.
એનાઇલિન-ખાસ જ પ્રશ્નો અને ક્લાસિકલ તફાવત NEETમાં બંને ખંડોમાંથી આવે છે.
સંશ્લેષણ પ્રશ્નોમાં: જો 1° એમિન બનાવવાનું કહેવાય તો ગેબ્રીઅલ, હોફમાન, એઝાઇડ સહિત કોઈ પણ પદ્ધતિ યોગ્ય છે; પરંતુ 3 કાર્બન ધરાવતી 1° એમિન → પ્રોપાઇલ એમિન → RCONH₂ (બ્યુટાનોઇડ) → HOFman પદ્ધતિ અથવા નાઇટ્રેશન + રિડક્શન.
રોડ-મેપ/સંશ્લેષણ પ્રશ્નો NEET ઉચ્ચ-સ્તરે પૂછાય છે; બધી તૈયારી પદ્ધતિઓની યોજના સમજવી પડે છે.
