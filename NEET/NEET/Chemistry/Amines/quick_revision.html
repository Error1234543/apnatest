એમાઈન (Amines) — ઝડપી રિવિઝન શીટ

🩺 NEET UG — Gujarati • Chemistry • Amines

🧠 યાદ રાખો

એમાઈન એ એમોનિયાનાં હાઈડ્રોજન પરમાણુઓના આલ્કિલ/એરાઇલ સમૂહ વડે બદલાયેલાં સંયોજનો છે.
પ્રાથમિક (1°), દ્વિતીયક (2°), તૃતીયક (3°) એમાઈન — N પર આલ્કિલ/એરાઇલ સમૂહની સંખ્યા પર આધારિત.
આલ્ફા-એલાકિલેશન માત્ર પ્રાથમિક એમાઈન સાથે આવર્તન થાય છે; દ્વિતીયક/તૃતીયક એમાઈન આ પ્રક્રિયા આપતા નથી.
એરાઇલ એમાઈન (જેમ કે અનિલીન) આલ્કાઇલ એમાઈન કરતા ઓછી બેઝિક હોય છે.
એમાઈનની બેઝિકતા: પ્રાથમિક > દ્વિતીયક > તૃતીયક (જળીય મધ્યમમાં); ગેસીય અવસ્થામાં તૃતીયક > દ્વિતીયક > પ્રાથમિક.
અનિલીનની બેઝિકતા H₂N-NH₂ (ડાયઅઝોટિક ઘટક) કરતા પણ ઓછી છે કારણ કે N પર ઇલેક્ટ્રોન ઘનતા રેઝોનન્સથી ઓછી થાય છે.
એમોનિયમ લવણ યુક્ત પ્રક્રિયાઓમાં NaNO₂/HCl (0-5°C) એ ડાયોઝોટીકરણ દર્શાવે છે; ફક્ત પ્રાથમિક એરાઇલ એમાઈન આ પ્રક્રિયા આપે છે.
હેબર્લની વિભાજન પ્રક્રિયા (Hofmann's degradation) માં બ્રોમિન + KOH સાથે એમાઈડ → પ્રાથમિક એમાઈન (એક कार्बન ઓછી).
એનાયલિન સાથે Br₂/H₂O માં ત્વરિત 2,4,6-ટ્રાઇબ્રોમોઅનાયલિન (સફેદ અવક્ષેપ) મળે છે.
એમાઈનનાં સુગંધદાર ગુણધર્મો, ઉર્ધ્વપાતનશીલતા અને હાઈડ્રોજન બંધન તેમના ભૌતિક ગુણધર્મો માટે જવાબદાર છે.
કાર્બાયલેટ પ્રક્રિયા (Carbylamine reaction) — ફક્ત પ્રાથમિક એમાઈન (આલ્કાઇલ/એરાઇલ) આ પ્રક્રિયા આપે છે; આ એક લક્ષણીય પરીક્ષણ છે.
એનાયલિનનું નાઇટ્રેશન મિશ્રિત એસિડથી (HNO₃/H₂SO₄) કરતાં પેરા-નાયટ્રોઅનાયલિન મુખ્ય ઉત્પાદન મળે છે, પણ ઓર્થો પણ મળે છે.

⚡ ઝડપી સૂત્રો

એમાઈનનું સૂત્ર: R-NH₂ / R₂NH / R₃N (જ્યાં R = આલ્કિલ અથવા એરાઇલ)
ડાયોઝોનિયમ લવણ: Ar-NH₂ + NaNO₂ + 2HX → Ar-N₂⁺X⁻ + NaX + 2H₂O (0-5°C)
હેબર્લ વિભાજન: R-CONH₂ + Br₂ + 4NaOH → R-NH₂ + Na₂CO₃ + 2NaBr + 2H₂O
કાર્બાયલેટ: R-NH₂ + CHCl₃ + 3KOH → R-NC (આઇસોસાયનાઇડ, દુર્ગંધિત) + 3KCl + 3H₂O
એસિલેશન (Šcutzenberg): R-NH₂ + R'-COCl → R-NH-CO-R' + HCl
સલ્ફોનઇલેશન (હિન્સબર્ગ): R-NH₂ + C₆H₅SO₂Cl → C₆H₅SO₂NHR + HCl
ડાયોઝોટીકરણ પછીનું ગ્રીનાર્ડ પ્રક્રિયા: Ar-N₂⁺ + H₃PO₂ → Ar-H + N₂ + H₃PO₄

✅ વન-લાઈનર્સ

પ્રાથમિક એમાઈનનો હાઈડ્રોજન બંધ બાહ્ય (intermolecular) હોય છે → ઊંચા ક્વેાંઠબિંદુ.
તૃતીયક એમાઈનમાં H બંધ બનાવવા માટે N પર H નથી હોતો → હાઈડ્રોજન બંધ નથી.
એનાયલિનમાં N પરનો એકલા યુગ્મ (lone pair) બેન્ઝીન રિંગ સાથે રેઝોનન્સ કરે છે → બેઝિકતા ઘટે છે.
CH₃NH₂ > C₆H₅NH₂ (એનાયલિન કરતા મિથાઇલએમાઈન વધુ બેઝિક).
(CH₃)₂NH > CH₃NH₂ > (CH₃)₃N > NH₃ (જળીય મધ્યમમાં બેઝિકતાનો ક્રમ).
ડાયોઝોટીક લવણ 0-5°C તાપમાને સ્થિર રહે છે; 5°C થી ઉપર તાપમાને વિઘટન પામે છે.
એનાયલિનનું બ્રોમિનેશન Br₂/H₂O માં 2,4,6-ટ્રાઇબ્રોમોઅનાયલિન આપે છે; Br₂/CS₂ માં મોનોબ્રોમોઅનાયલિન મળે છે.
એનાયલિનનું નાઇટ્રેશનમાં ઓર્થો અને પેરા એડ્ડ્ક્ટ બંને મળે છે; નાઇટ્રો સમૂહ મેટા-નિર્દેશક છે.
એમાઈન ઇથર કરતાં વધુ સંબંધિત હોય છે કારણ કે એમાઈનમાં હાઈડ્રોજન બંધ હોય છે.
એનાયલિન સાથે NaNO₂/HCl (0°C) પછી β-નેપ્થોલ સાથે પ્રક્રિયા કરતા એઝો રંગદ્રવ્ય (લાલ/નાગરિ) મળે છે.
એમાઈનનું એસિડ સાથેનું ઉપચયન: RNH₂ + HCl → RNH₃⁺Cl⁻ (એમાઈનિયમ લવણ).
હેબર્લ પ્રક્રિયામાં એમાઈડનાં N પર R સમૂહ એકમ ઓછો થાય છે.
