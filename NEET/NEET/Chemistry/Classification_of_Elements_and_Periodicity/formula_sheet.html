તત્વોનું વર્ગીકરણ અને આવર્તિતા — માનક સૂત્રો અને સંબંધો

⚡ સૂત્રો

બોહ્ર પરમાણુમાં નિષ્ઠા ઊર્જા (Hydrogen-like species): E_n = -13.6 × Z^2 / n^2 eV
E_n = n-મું કક્ષકની ઊર્જા; Z = પરમાણ્વીય ક્રમાંક; n = મુખ્ય કક્ષક અંક (1, 2, 3…) · SI: eV (ઇલેક્ટ્રોન-વોલ્ટ); 1 eV = 1.602 × 10⁻¹⁹ J · માત્ર એક ઇલેક્ટ્રોન ધરાવતા પ્રજાતિઓ (H, He⁺, Li²⁺) માટે; બહુ-ઇલેક્ટ્રોન પરમાણુઓ માટે આંકડાકીય અંદાજ છે.
બોહ્ર ત્રિજ્યા (Hydrogen-like species): r_n = 0.529 × n^2 / Z Å
r_n = n-મી કક્ષકની ત્રિજ્યા; n = મુખ્ય કક્ષક અંક; Z = પરમાણ્વીય ક્રમાંક · SI: Å (આંગસ્ટ્રોમ); 1 Å = 10⁻¹⁰ m · બોહ્ર મોડેલ લાગુ પડે તેવી હાઇડ્રોજન-સદૃશ પ્રજાતિઓ માટે; નોંધ: 0.529 Å એ હાઇડ્રોજનની બોહ્ર ત્રિજ્યા (a₀) છે.
આયનીકરણ ઊર્જા (IE) — બાહ્યતમ ઇલેક્ટ્રોન માટે કુલંબ આકર્ષણ અંદાજ: IE ∝ Z_eff / r
Z_eff = અસરકારક ન્યુક્લિયર વીજભાર ( screened nuclear charge ); r = ઇલેક્ટ્રોનની ન્યુક્લિયસથી સરેરાશ દૂરી · SI: kJ/mol અથવા eV (પરમાણુ દીઠ); SI પ્રણાલીમાં J/mol · આવર્ત સારણીમાં ડાબેથી જમણે અને ઉપરથી નીચે IE વધે/ઘટે તેની ગુણાત્મક સમજણ માટે; ચોકસાઈપૂર્વકનું મૂલ્ય પ્રાયોગિક રીતે માપવામાં આવે છે.
પ્રથમ આયનીકરણ ઊર્જાની પ્રક્રિયા (સામાન્ય સ્વરૂપ): X(g) → X⁺(g) + e⁻ ΔH = IE₁
IE₁ = પ્રથમ આયનીકરણ ઊર્જા; X(g) = વાયુ અવસ્થામાં તટસ્થ પરમાણુ; e⁻ = બાહ્ય ઇલેક્ટ્રોન · SI: kJ/mol (સામાન્ય રીતે); ધન મૂલ્ય (ઊર્જા શોષાય છે) · વાયુ અવસ્થાના તટસ્થ પરમાણુમાંથી પ્રથમ ઇલેક્ટ્રોન દૂર કરવા માટેનો ઊર્જાપરિવર્તન; બીજા/ત્રીજા IE માટે IE₂, IE₃ એ રીતે લખાય.
ઇલેક્ટ્રોન ગ્રાહિતા (Electron Affinity, EA): X(g) + e⁻ → X⁻(g) ΔH = EA
EA = ઇલેક્ટ્રોન ગ્રાહિતા; X(g) = વાયુ અવસ્થાનું તટસ્થ પરમાણુ; X⁻(g) = વાયુ અવસ્થાનું ઋણ આયન · SI: kJ/mol; ઘણાં તત્વો માટે EA ઋણ હોય છે (ઊર્જા મુક્ત થાય), અન્ય cases માટે ધન પણ હોઈ શકે · વાયુ અવસ્થાના તટસ્થ પરમાણુમાં પ્રથમ ઇલેક્ટ્રોન ઉમેરાય છે ત્યારે થતો એન્થાલ્પી ફેરફાર; ઋણ EA એટલે પ્રક્રિયા ઉષ્માક્ષેપક છે.
મલલિકેન ઇલેક્ટ્રોનેગેટિવિટી સ્કેલ: χ_M = (IE + EA) / 2
χ_M = મલલિકેન ઇલેક્ટ્રોનેગેટિવિટી (એકમ વિહીન); IE = પ્રથમ આયનીકરણ ઊર્જા; EA = પ્રથમ ઇલેક્ટ્રોન ગ્રાહિતા · SI: IE અને EA નું એકમ સમાન હોવું જોઈએ (સામાન્ય રીતે kJ/mol અથવા eV); પરિણામ એકમ વિહીન · ફક્ત તત્વોના પરમાણ્વીય ગુણધર્મો (IE, EA) વડે ઇલેક્ટ્રોનેગેટિવિટીનો અંદાજ લગાવવા; અન્ય સ્કેલ (પાઉલિંગ, મલલિકેન-રોચેવ) અલગ રીતે વ્યાખ્યાયિત છે.
સહસંયોજક ત્રિજ્યા (Covalent radius): r_cov = d(X–X) / 2
r_cov = સહસંયોજક ત્રિજ્યા; d(X–X) = સમાન પરમાણુઓ વચ્ચેની સહસંયોજક બંધ લંબાઈ · SI: pm (picometer) અથવા Å (1 pm = 10⁻¹² m; 1 Å = 100 pm) · બે સમાન પરમાણુઓ વચ્ચેની એકલ બંધ લંબાઈ માપી શકાય તેવા તત્વો (ધાતુઓ સિવાય) માટે; બહુ-બંધ (દ્વિ/ત્રિ) સહસંયોજક ત્રિજ્યા અલગ હોય છે.
ધાત્વીય ત્રિજ્યા (Metallic radius): r_met = d(M–M) / 2
r_met = ધાત્વીય ત્રિજ્યા; d(M–M) = ધાત્વીય રચનામાં બે相邻 ધાતુ પરમાણુઓ વચ્ચેની અંતઃઅણુકીય દૂરી · SI: pm અથવા Å · વિશુદ્ધ ધાતુઓની ઘન અવસ્થાની ક્રિસ્ટલ રચનામાં માપી શકાય તેવા તત્વો માટે.
કેટલાક સામાન્ય આવર્તિતા સંબંધો (ગુણાત્મક): IE: જમણી તરફ ↑, ઉપર તરફ ↑ ; EA: જમણી તરફ વધુ ઋણ (સામાન્ય), ઉપર તરફ વધુ ઋણ; ઇલેક્ટ્રોનેગેટિવિટી: F > O > Cl > N …; પરમાણ્વીય ત્રિજ્યા: ડાબે ↓, નીચે ↓
↑ = વધે છે; ↓ = ઘટે છે. આ સંબંધો મુખ્યત્વે શાસ્ત્રીય ગ્રુપ અને પિરિયડમાં સામાન્ય ઝડપી નિયમો છે. · SI: આ અનુપાતોમાં કોઈ ચોક્કસ એકમ નથી. · સામાન્ય આવર્તિતા પ્રવૃત્તિ સમજવા માટે; બહુ-ઇલેક્ટ્રોન પરમાણુઓમાં વિચલનો (દા.ત., Be vs B, N vs O) હંમેશા ધ્યાનમાં લેવા જોઈએ.

🔗 સંબંધો

  • આયનીકરણ ઊર્જા, ઇલેક્ટ્રોન ગ્રાહિતા અને ઇલેક્ટ્રોનેગેટિવિટી ત્રણેય પરમાણ્વીય ત્રિજ્યાના વિપરીત અનુપાતી હોય છે — ત્રિજ્યા ઘટતા આ ત્રણેય વધે છે.
  • બોહ્ર મોડેલ મુજબ, ઊર્જા n² વડે વિપરીત અનુપાતી અને Z² વડે સમપ્રમાણ છે; તેથી ઊંચા Z અને નાના n ઊર્જાના મૂલ્યને ઝડપી બનાવે છે.
  • ઈલેક્ટ્રોન ગ્રાહિતા (EA) અને આયનીકરણ ઊર્જા (IE) બંને ધન ગાણિતિક મૂલ્યો વડે દર્શાવાય છે (ઊર્જા વહન), પણ EA નો એન્થાલ્પી ફેરફાર ઘણીવાર ઋણ હોય છે કારણ કે ઇલેક્ટ્રોન ઉમેરવાથી ઉષ્મા મુક્ત થાય છે.
  • ઇલેક્ટ્રોનેગેટિવિટી એ પરમાણ્વીય ગુણધર્મ છે (બંધમાં ઇલેક્ટ્રોન ખેંચવાની ક્ષમતા), જ્યારે ઇલેક્ટ્રોન ગ્રાહિતા એ અલગ માપી શકાતી પ્રાયોગિક ઊર્જા છે — બંને એક સાથે જોડાયેલા છે પણ સમાન નથી.
  • દ્વિતીય અને તૃતીય આયનીકરણ ઊર્જા પ્રથમ કરતાં હંમેશા વધારે હોય છે કારણ કે ધન આયનમાંથી ઇલેક્ટ્રોન દૂર કરવો વધુ મુશ્કેલ છે.
  • સહસંયોજક ત્રિજ્યા ≤ ધાત્વીય ત્રિજ્યા < આયનીય ત્રિજ્યા (ધન આયન માટે ધાત્વીય ત્રિજ્યા કરતાં નાના, ઋણ આયન માટે મોટા).

🎯 ટ્રિક્સ

એક ઇલેક્ટ્રોન ધરાવતી પ્રજાતિ (H, He⁺, Li²⁺) માટે E_n ≈ -13.6 Z²/n² eV સૂત્ર યાદ રાખો; આ સૂત્ર તમે ઝડપી ગણતરી માટે વાપરી શકો છો અને બહુ-ઇલેક્ટ્રોન માટેનો ગુણાત્મક આકારો સમજવામાં મદદરૂપ થાય છે.
રસાયણ વિજ્ઞાનમાં IE, EA, χ ત્રણેય એક જ 'પરમાણ્વીય ચાહ' ના ત્રણ પાસાં છે: ડાબેથી જમણે વધતાં ત્રણેય વધે છે, ઉપરથી નીચે ઘટતાં ત્રણેય ઘટે છે — આ 'એક જ સૂત્ર' તરીકે યાદ કરો.
ઇલેક્ટ્રોન ગ્રાહિતાની ચિહ્ન સંપ્રદાયને યાદ રાખવા માટે: "EA negative means energy released" (ઇલેક્ટ્રોન ગ્રાહિતા ઋણ = ઊર્જા મુક્ત). પ્રશ્નોમાં EAનું મૂલ્ય ઋણ જ આપેલું હોય છે ત્યારે યાદ રાખો કે તેનો અર્થ છે પ્રક્રિયા ઉષ્માક્ષેપક છે.
આયનીકરણ ઊર્જાનો આંશિક ભંગ (IE₂ > IE₁) યાદ રાખવા માટે: "એક ઇલેક્ટ્રોન કાઢ્યો તો બાકીનાનું આકર્ષણ વધે" — આ સરળ ભાષામાં મૂળભૂત સિદ્ધાંત યાદ રાખે છે.
કુલંબના નિયમ સાથે જોડાણ: IE ∝ Z/r નો ઉપયોગ કરીને તમામ આવર્તિતા વલનોની સામાન્ય સમજણ મેળવો — Z_eff વધે અને r ઘટે તો IE વધે.

⚠️ ભૂલો

ઇલેક્ટ્રોન ગ્રાહિતા (EA) અને ઇલેક્ટ્રોનેગેટિવિટી (EN) એક જ છે એવું સમજી લેવું. EA એ પ્રાયોગિક રીતે માપી શકાય તેવી ઊર્જા છે; EN એ બંધમાં ઇલેક્ટ્રોન જોડાણની સાપેક્ષ ક્ષમતા દર્શાવે છે અને તે એકમ વિહીન છે.
આયનીકરણ ઊર્જાને હંમેશા ધન માની લેવી અને ઋણ EA વાળા તત્વો (જેમ કે કેટલાક Halogens) ની ઊર્જા-મુક્તિ વાળી પ્રવૃત્તિને ધ્યાનમાં ન લેવી.
બોહ્ર મોડેલના સૂત્રો (E_n, r_n) નો ઉપયોગ બહુ-ઇલેક્ટ્રોન પરમાણુઓ પર સીધો કરી લેવો — આ સૂત્રો ફક્ત હાઇડ્રોજન-સદૃશ પ્રજાતિઓ માટે જ ચોક્કસ છે.
ત્રિજ્યાના એકમો (pm, Å) માં રૂપાંતર ભૂલી જવું: 1 Å = 100 pm = 10⁻¹⁰ m. આ ભૂલ સીધી ગણતરીઓ ખોટી પાડે છે.
આવર્ત સારણીમાં 'જમણી તરફ IE વધે' એ સામાન્ય નિયમને ધ્યાનમાં લેતાં એક ઇલેક્ટ્રોન સ્થિરતું ધરાવતાં p³ (N, P) અને p⁶ (Ne, Ar) વિન્યાસના તત્વોમાં થતા વિચલનો (Be-B, N-O, Mg-Al, P-S) ભૂલી જવા.
IE₁, IE₂, IE₃ ના ક્રમને ભાંખીને આયનીકરણ ઊર્જાનો ગ્રાફ અથવા ક્રમ ગેરમાર્ગે દર્શાવવો; વાસ્તવમાં IE₁ < IE₂ < IE₃ હંમેશા સાચું છે.
સહસંયોજક ત્રિજ્યા અને ધાત્વીય ત્રિજ્યા વચ્ચેનો તફાવત ભૂલી જવો અને બંનેને એક જ તરીકે વાપરવા, જોકે બંધના પ્રકાર (સહસંયોજક vs ધાત્વીય) મુજબ તેમના મૂલ્યો ફરકતા હોય છે.
