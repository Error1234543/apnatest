કેટલાક p-બ્લોક તત્વો — ઝડપી પુનરાવર્તન નોંધો

📘 વ્યાખ્યાઓ

  • બોરેન: bH₃ રૂપે અસ્થિર, સદા દ્વિલક્ષી બોરેન (B₂H₆) સ્વરૂપે મળે છે.
  • ડાયબોરેન: B₂H₆, એન્ટરેડ બોન્ડ (3c-2e) ધરાવતું હાઇડ્રોજન બોરાઇડ.
  • બોરેક્સ: Na₂B₄O₇·10H₂O, બોરોનનું પ્રમાણભૂત ખનીજ.
  • બોરાઝીન (ઇનઓર્ગેનિક બેન્ઝીન): B₃N₃H₆, બોરન અને નાઈટ્રોજનના વૈકલ્પિક પરમાણુ ધરાવતું ચક્રીય સંયોજન.
  • ઇнер્ટ પેર અસર: ns² ઇલેક્ટ્રોન જોડીનું સહાયક બંધ બનવામાં અક્રિયાશીલ રહેવું.
  • સિલિકોન: SiO₄⁴⁻ એકમથી બનેલા સંયોજનોનો વિશાળ સમૂહ (સિલિકેટ્સ).
  • સિલિકોન પોલીમર: [R₂SiO]ₙ એકમ ધરાવતું સિલિકોન-ઓક્સિજન પાયો સંયોજન.
  • ઝીઓલાઇટ્સ: હાઇડ્રેટેડ એલ્યુમિનિયમ સિલિકેટ્સ, સાથ્રક તરીકે વપરાય છે.
  • બોરિક ઍસિડ: H₃BO₃, Lī'બોરિક ઍસિડ, બ્રોન્સ્ટેડ ખાટું નહીં પણ લૂઈઝ ખાટું.

⚡ સૂત્રો

  • બોરેક્સ + HCl → H₃BO₃ (બોરિક એસિડ)
  • Na₂B₄O₇ + 2HCl + 5H₂O → 4H₃BO₃ + 2NaCl
  • B₂H₆ + 6H₂O → 2H₃BO₃ + 6H₂
  • BCl₃ + 3H₂O → H₃BO₃ + 3HCl
  • 2B + 3Br₂ → 2BBr₃
  • BF₃ + NH₃ → F₃B←NH₃ (એડિટ સંયોજન)
  • SiCl₄ + 4CH₃Cl → (CH₃)₄Si + 4HCl (સિલિકોન ઉત્પાદન)
  • n(CH₃)₂SiCl₂ + H₂O → [Si(CH₃)₂O]ₙ + 2nHCl
  • C + O₂ → CO₂ (પૂર્ણ દહન), 2C + O₂ → 2CO (અપૂર્ણ દહન)
  • Ca(OH)₂ + CO₂ → CaCO₃ + H₂O
  • Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]
  • Ga₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]

⭐ મુખ્ય તથ્યો

  • પ્રથમ પુરસ્કાર વિજેતા બોરોન છે અને આર્સેનિક છે — બંને બિનધાતુ.
  • ગ્રુપ 13ના tત્વોની ઇલેક્ટ્રૉનિક બંધારણ: [Noble gas] ns² np¹ છે.
  • ગ્રુપ 14ના tત્વોની ઇલેક્ટ્રૉનિક બંધારણ: [Noble gas] ns² np² છે.
  • બોરોનની પ્રથમ આયનીકરણ ઉર્જા બોરોન કરતાં ઓછી છે.
  • બોરોનની ઇલેક્ટ્રૉન આકર્ષણ ક્ષમતા ફ્લોરિન કરતાં ઓછી છે.
  • બોરોન માત્ર +3 ઑક્સિડેશન અવસ્થા દર્શાવે છે.
  • થેલિયમ (+1) ઑક્સિડેશન અવસ્થા +3 કરતાં વધુ સ્થિર છે.
  • કાર્બનમાં ઇનર્ટ પેર અસરનો અભાવ છે; તે +4 ઑક્સિડેશન અવસ્થા પ્રમાણભૂત છે.
  • ડાયબોરેનમાં બે ભૂમિ (bridging) H પરમાણુઓ અને બે સાદા H પરમાણુઓ હોય છે.
  • ડાયબોરેનના બોન્ડ કોણ 95° થી 97° મધ્યે હોય છે.
  • BF₃માં B-F બંધ લંબાઈ એકસમાન છે; બોરોન sp² સંકરણ ધરાવે છે.
  • બોરેનમાં B-H-B (3c-2e) બંધ હોય છે.
  • હીલિયમ (He) ગ્રુપ 13માં નથી — હીલિયમ નોબલ ગેસ છે.
  • આલ્યુમિનિયમ દ્વિધાત્મક (amphoteric) ઑક્સાઇડ ધરાવે છે.
  • Ga³⁺ આયન BF₄⁻ સાથે સંકીર્ણ બનાવે છે.
  • ઇન્ડિયમના ઑક્સાઇડ In₂O₃ પ્રમાણભૂત મૃદ્વાધારી છે.
  • તલિયમ(III) ઑક્સાઇડ Tl₂O₃ પ્રબળ ઑક્સિડાઇઝિંગ એજન્ટ છે.
  • કાર્બનના ત્રણ સ સ્વરૂપો: વજ્ર (diamond), ગ્રેફાઇટ (graphite), બુક્સ્ટ્રાઇટ (buckminsterfullerene).
  • ગ્રેફાઇટમાં કાર્બન sp² સંકરણ ધરાવે છે; દરેક પ્રલંબિત π બંધમાં ઇલેક્ટ્રૉન મુક્ત ગતિ કરે છે.
  • કાર્બન મોનોક્સાઇડ (CO) વિષાક્ત ગેસ છે; HB માયોગ્લોબિન સાથે જોડાય છે.
  • CO₂ અનિયમિત રચના ધરાવતો રેખીય અણુ છે; sp સંકરણ ધરાવે છે.
  • સિલિકોન મુખ્યત્વે સિલિકા (SiO₂) અને સિલિકેટ્સ રૂપે પ્રાપ્ત થાય છે.
  • સિલિકોન ટેટ્રાક્લોરાઇડ (SiCl₄) હાઇડ્રોલિસિસ પામે છે.
  • આલ્યુમિનિયમ ધાતુ પ્રબળ રિડ્યુસિંગ એજન્ટ છે.
  • બોરોન ધાતુ ઉષ્મા અને વિદ્યુતનું અવાહક છે.

⚠️ સામાન્ય ભૂલો

  • બોરોન સંયોજનોમાં 3c-2e બંધ હોય છે — સામાન્ય 2c-2e નહીં.
  • બોરેન તંતુ (BH₃) સ્વતંત્ર અણુ છે — તે સદા Dimer (B₂H₆) રૂપે મળે છે.
  • BF₃ લૂઈઝ ખાટું છે — ઇલેક્ટ્રૉન સ્વીકારી શકે છે.
  • બોરિક એસિડ બ્રોન્સ્ટેડ ખાટું નથી — OH⁻ સ્વીકારે છે, H⁺ મુક્ત નથી કરતો.
  • બોરેનની રિડ્યુસિંગ ક્ષમતા NaBH₄ કરતાં વધુ છે.
  • Ga નું પરમાણુ વ્યાસ Al કરતાં થોડું મોટું છે — d-બ્લોક સંકોચનને કારણે.
  • Tl⁺ જલીય દ્રાવણમાં સ્થિર છે; Tl³⁺ પ્રબળ ઑક્સિડાઇઝિંગ એજન્ટ છે.
  • C (ગ્રેફાઇટ) નું મુક્ત ઇલેક્ટ્રૉન છે — ઇલેક્ટ્રિકલ વાહક છે.
  • CO કોઇ પણ ક્ષાર ઉત્પન્ન કરતું નથી — તે તટસ્થ એન્હાઇડ્રાઇડ છે.
  • CO₂ જલીય દ્રાવણમાં ક્ષાર ઉત્પન્ન કરતું નથી.
  • SiC (સિલિકોન કાર્બાઇડ) ગાઢા માત્રામાં વજ્ર જેટલું જડ છે.
  • Silicones જલીય દ્રાવણમાં હાઇડ્રોફોબિક હોય છે.
  • Zeolites એટલે કે ચાલક (catalysts) છે.
  • B₂H₆ માં Bsp² સંકરણ ધરાવે છે, B-H-B બંધમાં 3c-2e છે.
  • B₂H₆ નું બંધ કોણ 97° છે — સામાન્ય સંયોજન બંધ કોણ 120°.
  • B₂H₆ + O₂ → B₂O₃ + H₂O (જારણ)

🔥 હાઈ-યીલ્ડ મુદ્દા

  • બોરેનનો +3 ઑક્સિડેશન અવસ્થામાં છે.
  • બોરેન તંતુ (BH₃) સ્વતંત્ર અણુ છે — તે સદા Dimer (B₂H₆) રૂપે મળે છે.
  • તલિયમ (Tl) સૌથી ભારે અને ઇલેક્ટ્રોપોઝિટિવ tત્વ છે ગ્રુપ 13માં.
  • બોરેન અને નાઈટ્રોજન સમઘટક છે.
  • બોરેક્સના આંખો (Na₂B₄O₇·10H₂O) માં 10 પાણીના અણુઓ હોય છે.
  • બોરેન ફ્લોરિન સાથે પ્રક્રિયા કરી BF₃ ઉત્પન્ન કરે છે.
  • BF₃ સાથે હાઇડ્રોજન યોજકો (hydride) બનાવે છે.
  • ડાયબોરેન જલીય દ્રાવણમાં H₂ બહાર કરે છે.
  • બોરેનનું જ્વાલન કરવામાં આવે તો B₂O₃ + H₂O બને છે.
  • ડાયબોરેન (B₂H₆) + 3O₂ → B₂O₃ + 3H₂O.
  • ડાયબોરેન (B₂H₆) નું બંધ કોણ 97° થી 95° છે.
  • ડાયબોરેન (B₂H₆) માં બે ભૂમિ (bridging) H પરમાણુઓ હોય છે.
  • ડાયબોરેન (B₂H₆) માં ચાર સાદા H પરમાણુઓ અને બે ભૂમિ H પરમાણુઓ હોય છે.
  • ડાયબોરેન (B₂H₆) માં ત્રણ B-H-B બંધ હોય છે.
  • બોરેન (BH₃) અને NH₃ વચ્ચે F₃B←NH₃ સંયોજન બને છે.
  • બોરેન (B₂H₆) + CH₄ → (CH₃)₃B + H₂ (હીટ થવાથી).
  • સિલિકોન (Si) નું ઉત્પાદન SiO₂ + 2C → Si + 2CO.
  • સિલિકોન ટેટ્રાક્લોરાઇડ (SiCl₄) + 4CH₃Cl → (CH₃)₄Si + 4HCl.
  • સિલિકોન પોલીમર [R₂SiO]ₙ સિલિકોન-ઓક્સિજન પાયો સંયોજન છે.
  • સિલિકોન પોલીમર (Silicone) હાઇડ્રોફોબિક છે — પાણી પાસેથી ભય છે.
  • સિલિકોન (Silicon) નું પરમાણુ વ્યાસ SiO₂ કરતાં વધુ છે.
  • ઝીઓલાઇટ્ (Zeolite) એટલે કે સાથ્રક (catalyst) છે.
  • ઝીઓલાઇટ્ (Zeolite) નું રાસાયણિક સૂત્ર Naₙ[(AlO₂)ₙ(SiO₂)ₘ]·xH₂O છે.
  • ઝીઓલાઇટ્ (Zeolite) નું પ્રમાણભૂત ઉદાહરણ Na₈Al₆Si₆O₂₄·2H₂O છે.
  • કાર્બન (C) ના ત્રણ સ સ્વરૂપો: વજ્ર (diamond), ગ્રેફાઇટ (graphite), ફુલેરીન (fullerene).
  • વજ્ર (Diamond) માં કાર્બન sp³ સંકરણ ધરાવે છે.
  • ગ્રેફાઇટ (Graphite) માં કાર્બન sp² સંકરણ ધરાવે છે.
  • ગ્રેફાઇટ (Graphite) ની રચના પડદાર (layered) છે.
  • ફુલેરીન (C₆₀) બુક્સ્ટ્રાઇટ (Buckminsterfullerene) નું સૂત્ર C₆₀ છે.
  • કાર્બન મોનોક્સાઇડ (CO) HB માયોગ્લોબિન સાથે 200 ગુણો વધુ પ્રબળ બંધ બનાવે છે.
  • કાર્બન ડાયએક્સાઇડ (CO₂) + Ca(OH)₂ → CaCO₃ + H₂O.
  • કાર્બન મોનોક્સાઇડ (CO) + Cl₂ → COCl₂ (કાર્બનીલ ક્લોરાઇડ).
  • આલ્યુમિનિયમ ઑક્સાઇડ (Al₂O₃) દ્વિધાત્મક છે.
  • આલ્યુમિનિયમ ધાતુ પ્રબળ રિડ્યુસિંગ એજન્ટ છે.
