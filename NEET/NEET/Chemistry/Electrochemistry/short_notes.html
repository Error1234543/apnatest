વિદ્યુતરાસાયણશાસ્ત્ર — ટૂંકા નોંધો

🩺 NEET UG — Gujarati • Chemistry • Electrochemistry

📘 વ્યાખ્યાઓ

  • વિદ્યુતરાસાયણશાસ્ત્ર: રાસાયણિક પ્રક્રિયાઓ અને વિદ્યુતપ્રવાહ વચ્ચેના સંબંધનું અભ્યાસ.
  • ગેલ્વેનિક કોષ (વોલ્ટાઈક કોષ): રાસાયણિક ઊર્જાનું વિદ્યુતઊર્જામાં રૂપાંતર કરતો કોષ.
  • વિદ્યુતવિભાજ્ય: પીગળેલ અથવા દ્રાવણ સ્થિતિમાં વિદ્યુતપ્રવાહ વહન કરી શકતું સંયોજન.
  • વિદ્યુતધ્રુવ (ઇલેક્ટ્રોડ): કોષમાં વિદ્યુતપ્રવાહનો પ્રવેશ/નિર્ગમન બિંદુ.
  • એનોડ: એવો ઇલેક્ટ્રોડ જ્યાં ઑક્સિડેશન થાય છે.
  • કેથોડ: એવો ઇલેક્ટ્રોડ જ્યાં રિડક્શન થાય છે.
  • વિદ્યુતવિભાજન: વિદ્યુતપ્રવાહ મારફતે વિદ્યુતવિભાજ્યનું વિઘટન.
  • મોલર ચાલકતા (Λm): એક મોલ વિદ્યુતવિભાજ્યના દ્રાવણની ચાલકતા.
  • માનક વિદ્યુતધ્રુવ বিভવ (E°): સ્ટાન્ડર્ડ પરિસ્થિતિઓમાં (1 M, 298 K, 1 atm) માપવામાં આવતો વિદ્યુતધ્રુવ বিভવ.
  • સંકલન કિરચહૉફનો નિયમ: મર્યાદિત તન્યતા પર મોલર ચાલકતા આયનોની સ્વતંત્ર યોગદાનનું સરવાળો છે.
  • કોરોઝન: ધાતુનું પર્યાવરણ સાથે રાસાયણિક/વિદ્યુતરાસાયણિક પ્રક્રિયાથી નુકસાન.

⚡ સૂત્રો

  • E°cell = E°(કેથોડ) − E°(એનોડ)
  • ΔrG° = −nFE°cell
  • Ecell = E°cell − (2.303RT/nF) log(Q) → 298 K: Ecell = E°cell − (0.059/n) log(Q)
  • R = ρ × (A/l), G = 1/R = κ × (A/l)
  • κ = G × (l/A) (એકમ: S m⁻¹)
  • Λm = κ / C (એકમ: S m² mol⁻¹)
  • kWh = 3.6 × 10⁶ J
  • n1Q1 = n2Q2 (તપાસ/રૂપાંતરણ)
  • Λ°m = λ°+ + λ°− (કિરચહૉફનો નિયમ)

⭐ મુખ્ય તથ્યો

  • ડાબી બાજુનું ઇલેક્ટ્રોડ ઘટાડું (Reduction) અને જમણી બાજુનું ઓક્સિડેશન (Oxidation) દર્શાવે છે.
  • Zn|Zn²⁺ || Cu²⁺|Cu — ડેનિયલ કોષ; E°cell = +1.10 V.
  • સ્ટાન્ડર્ડ હાઇડ્રોજન ઇલેક્ટ્રોડ (SHE) નો E° = 0.00 V હંમેશા.
  • વધુ ધન E° ધરાવતું ઇલેક્ટ્રોડ કેથોડ બને; ઓછું ધન/ઋણ એનોડ બને.
  • E°cell > 0 હોય તો પ્રક્રિયા સ્ફૂરત હોય છે; ΔrG < 0.
  • F = 96500 C mol⁻¹ (ફેરાડે અચળાંક).
  • દ્રાવ્યતા ગુણાકાર Ksp ≈ (κ − κвода) મારફતે શોધી શકાય.
  • ઉષ્માક્ષમતા η = (વિદ્યુતચુંબકીય રૂપાંતરણ) / (ઇલેક્ટ્રોડ થર્મોડાયનેમિક ઊર્જા).
  • ફ્યુઅલ સેલ: H₂/O₂ ફ્યુઅલ સેલનું E° ≈ 1.23 V.
  • લીડ-એક્યુમ્યુલેટર ( Lead-acid battery) નો E° ≈ 2.05 V; 50% H₂SO₄ વાપરે છે.
  • H₂–O₂ ફ્યુઅલ સેલમાં કાટ્લાઇટ: 2H₂ + 4OH⁻ → 4H₂O + 4e⁻.
  • નોન-રિચાર્જેબલ કોષ: ડ્રાઇ સેલ (અમલગમિત Zn).
  • Li-ion બેટરી: લાઇટવેઇટ, ઉચ્ચ એનર્જી ઘનતા, રિચાર્જેબલ.
  • રંગદ્રવ્યોના વિદ્યુતરાસાયણિક વિઘટનમાં ધ્રુવીયતાનું મહત્ત્વ.
  • વિદ્યુતધ્રુવ বিভવનો સ્કેલ: ધન એ ઓક્સિડાઈઝિંગ એજન્ટ તરીકે; ઋણ એ રિડ્યુસિંગ એજન્ટ તરીકે.

⚠️ સામાન્ય ભૂલો

  • E°cell = E°cathode − E°anode; E°cell ≠ E°oxidation − E°reduction. ચોકસાઈ રાખો.
  • Nernst eq માં n એ ઇલેક્ટ્રોનની સંખ્યા છે — reaction balanced કર્યા बिना ઉપયોગ ન કરો.
  • 0.059/n ગુણક માત્ર 298 K (25°C) પર લાગુ પડે છે, અન્ય તાપમાને બદલાય છે.
  • Λm નો એકમ S m² mol⁻¹ છે, S cm² mol⁻¹ નહીં; એકમ રૂપાંતર જરૂરી.
  • κ (specific conductance) એ તાપમાન પર આધારિત છે; તાપ વધે તો κ વધે.
  • E°cell ઋણ હોય તો પ્રક્રિયા અસ્ફૂરત; ΔrG ધન હોય છે.
  • Ksp શોધતી વખતે κwater નો બાદબાકી ભૂલ્યા વગર કરવો.
  • Λm vs Molarity: Λm = κ/C, C = mol/m³ ને બદલે mol/L લઈએ તો 1000 વડે ગુણવું પડે.
  • ફેરાડેના નિયમોમાં Q = I×t એ coulomb માં હોવું જોઈએ, A અથવા s માં.
  • E°cell નું મૂલ્ય intensive property છે; તે stoichiometric coefficients પર આધારિત નથી.
  • SHE માં Pt નો ઉપયોગ inert electrode તરીકે થાય છે, તે પ્રક્રિયામાં ભાગ નથી લેતું.
  • કોષ સંकेत (cell notation) માં ડાબી બાજુ anode અને જમણી બાજુ cathode હોય છે.
