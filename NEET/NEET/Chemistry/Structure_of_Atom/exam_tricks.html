🎯 પરીક્ષા ટ્રિક્સ

kappa = h/mv = h/p; ભારે કણની કમ્પ્ટન તરંગલંબાઈ હંમેશા ઓછી હોય છે. એકસરખા વેગવાળા ઇલેક્ટ્રોન vs પ્રોટોન vs આલ્ફા કણ -> m_α > m_p > m_e -> λ_α < λ_p < λ_e (તરંગલંબાઈ ઊલટું પ્રમાણમાં દળને).
જ્યારે વિવિધ કણો (e⁻, p, α, n) ની તરંગલંબાઈની સરખામણી માંગે.
દા.ત.: એકસરખા વેગથી ગતિ કરતા ઇલેક્ટ્રોન અને પ્રોટોનમાં પ્રોટોનની તરંગલંબાઈ ~1/1836 ગણી હોય છે.
કક્ષકમાં ઇલેક્ટ્રોનની મહત્તમ સંખ્યા = 2(2l+1). s=2, p=6, d=10, f=14. તેજીથી બોલવા: 2,6,10,14 -> +4 લઘુગણુક.
ઇલેક્ટ્રોનિક વિન્યાસ, ખાલી કક્ષકોની સંખ્યા કે પૂછાય ત્યારે.
દા.ત.: n=3 માટે: 3s²(2) + 3p⁶(6) + 3d¹⁰(10) = 18 e⁻.
હાઇડ્રોજન જેવા પરમાણુ: E_n = -13.6 Z²/n² eV. ΔE (absorption, n₁→n₂) = 13.6Z²(1/n₁² - 1/n₂²) eV. ફોટોન: λ(nm) ≈ 1240/E(eV).
પ્રકાશવિદ્યુત પરીણામ / ફોટોનની તરંગલંબાઈ શોધવી હોય ત્યારે.
દા.ત.: H પરમાણુ n=2→3: ΔE = 13.6(1/4 - 1/9) = 13.6×5/36 ≈ 1.89 eV. λ ≈ 1240/1.89 ≈ 656 nm (લાલ હેઝળ).
ઓફબૌના સિદ્ધાંત મુજબ કક્ષકોનો ક્રમ: 1s<2s<2p<3s<3p<4s<3d<4p<5s<4d<5p<6s<4f<5d<6p<7s... છેડેના ઇલેક્ટ્રોનનો 'n+l' ચેક: ઓછો n+l = ઓછી ઊર્જા. સમાન n+l → નીચો n = ઓછી ઊર્જા.
અજ्ञાત તત્વની ઇલેક્ટ્રોનિક વિન્યાસ ઝડપથી લખવી હોય ત્યારે.
દા.ત.: 4s (n+l=4+0=4) < 3d (3+2=5), એટલે 4s પહેલા ભરાય. Cr(Z=24): [Ar] 4s¹ 3d⁵ (અર્ધભરેલી અપવાદ stabilities).
તરંગલંબાઈ-ઊર્જા: E ∝ 1/λ. UV >可见光 > IR. 10⁻¹⁰ m = 1 Å = 100 pm. રેન્જ યાદ રાખો: γ<10⁻¹², X-ray ~10⁻¹⁰,可见光 ~5×10⁻⁷,微波~10⁻³ m.
EM spectrum ના ક્રમ/તરંગલંબાઈ પ્રશ્નોમાં.
દા.ત.: γ-rays (πરમાણુ સ્તરે) > X-ray > UV > visible > IR > microwave > radio.
આયનીકરણ ઊર્જા: ઉત્તરાધિકાર (↓ સમૂહ) ઘટે છે, ડાબેથી જમણે (+Z_eff) વધે છે. અપવાદ: Be>B, N>O (સંપૂર્ણ/અર્ધભરેલી સ્થિરતા).
IE order માં સાચું/ખોટું કહેવું હોય.
દા.ત.: N(O>?) નથી, BE> B (Be 2s² સ્થિર). O < N કારણ O 2p⁴ → e⁻ કાઢવું સરળ.
ઇલેક્ટ્રોન વિન્યાસમાં ઇલેક્ટ્રોનનો સેટ (set) જોઈએ તો: s→1, p→3, d→5, f→7 કક્ષકો. સમાંતર ઇલેક્ટ્રોન = અયુગ્મિત = અનુચુંબકીય; બધા ζુગ્મિત = પ્રતિચુંબકીય.
અનુચુંબકીય/પ્રતિચુંબકીય ભાવ પ્રશ્ન.
દા.ત.: Fe²⁺([Ar]3d⁶): 4 સમાંતર e⁻ → અનુચુંબકીય. Zn²⁺(3d¹⁰): 0 સમાંતર → પ્રતિચુંબકીય.
પ્રકાશ-વિદ્યુત પરીણામ: K_max = hν - φ = hc/λ - φ. Stopping potential V_s = K_max/e. λ(cutoff) = hc/φ. φ(eV) → λ₀(nm) ≈ 1240/φ.
фотоэффект માં V_s કે λ₀ શોધવાનું હોય.
દા.ત.: φ=2.3 eV (Na): λ₀ = 1240/2.3 ≈ 539 nm. 400 nm પ્રકાશ પડે → ke_max = 1240/400 - 2.3 = 0.8 eV.
હાઈડ્રોજન-જેવા માત્ર પરીણામ: r_n = 0.529 n²/Z Å, v_n = 2.18×10⁶ Z/n m/s, E_n = -13.6 Z²/n² eV. r ∝ n²/Z, v ∝ Z/n, E ∝ Z²/n².
Bohr કક્ષા ત્રિજ્યા/ઝડપ/ઊર્જા ગણતરી માં.
દા.ત.: He⁺(Z=2) n=2: r = 0.529×4/2 = 1.058 Å.
Heisenberg અનિશ્ચિતતા: Δx·Δp ≥ ℏ/2. ઇલેક્ટ્રોન માટે Δx ઓછું → Δv વધુ. જો Δx ≈ 0 (ક્ષેત્રમાં), Δv → અનંત.
અનિશ્ચિતતા સિદ્ધાંતના ગણતરી/સંકલ્પના પ્રશ્ન.
દા.ત.: ઇલેક્ટ્રોનનું સ્થાન ±10⁻⁸ cm → Δv ≥ 5.8×10⁶ m/s (~પ્રકાશના વેગની નજીક).
