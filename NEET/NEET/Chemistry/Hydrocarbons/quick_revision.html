હાઇડ્રોકાર્બન્સ — ક્વિક રિવિઝન શીટ

🩺 NEET UG — Gujarati • Chemistry • Hydrocarbons

🧠 યાદ રાખો

હાઇડ્રોકાર્બન્સના ત્રણ પ્રકાર: એલ્કેન (સંતૃપ્ત), એલ્કીન/એલ્કાઇન (અસંતૃપ્ત), એરોમેટિક (બેન્ઝીન વર્ગ).
એલ્કેનનું સામાન્ય સૂત્ર CₙH₂ₙ₊₂, એલ્કીનનું CₙH₂ₙ, એલ્કાઇનનું CₙH₂ₙ₋₂.
બેન્ઝીન (C₆H₆) માં 6 π-ઇલેક્ટ્રોન હોય છે; તે સંયુગ્મિત દ્વિ-બંધો ધરાવતું સમતલીય ચક્રીય અણુ છે.
હૂકેલનો નિયમ: ચક્રીય, સમતલીય, સંયુગ્મિત યોજિતમાં (4n+2) π-ઇલેક્ટ્રોન હોય તો એરોમેટિક.
એલ્કીન/એલ્કાઇનમાં σ + π બંધ હોય છે; π-બંધ નબળો હોવાથી પ્રક્રિયાશીલ હોય છે.
બેન્ઝીનમાં C–C બંધ લંબાઈ 139 pm (એલ્કેન 154 pm અને એલ્કીન 134 pm ની વચ્ચે).
sp³ → એલ્કેન, sp² → એલ્કીન, sp → એલ્કાઇન; બંધકોણ અનુક્રમે 109.5°, 120°, 180°.
બેન્ઝીન ઇલેક્ટ્રોફિલિક સંયોજન કરે છે, ન્યુક્લિયોફિલિક સંયોજન નહીં.
પેરોક્સાઇડ અસર (Kharasch): HBr + એલ્કીન → એન્ટિ-માર્કોવનિકોફ ઉત્પાદન (ફક્ત HBr માટે).
બેન્ઝીનનું દહન: 2C₆H₆ + 15O₂ → 12CO₂ + 6H₂O (ધૂમ્રયુક્ત જ્વાળા).

⚡ ઝડપી સૂત્રો

એલ્કેન: CₙH₂ₙ₊₂ | એલ્કીન: CₙH₂ₙ | એલ્કાઇન: CₙH₂ₙ₋₂
હૂકેલનો નિયમ: (4n + 2) π-ઇલેક્ટ્રોન = એરોમેટિક
માર્કોવનિકોફ નિયમ: H⁺ એ હાઇડ્રોજન ધરાવતા C પર જોડાય છે → કાર્બોકેટાઇન વધુ સ્થિર.
ડિહાઇડ્રોહેલોજન થર્મલ ક્રોસ-કપલિંગ (Wurtz): 2R–X + 2Na → R–R + 2NaX
એલ્કાઇનનું સાંકેતિક સૂત્ર: R–C≡C–R' (ટર્મિનલ એલ્કાઇન: –C≡C–H)
બેન્ઝીનનું આણ્વીય સૂત્ર: C₆H₆ | આણ્વીય દળ: 78 g/mol

✅ વન-લાઈનર્સ

એલ્કેન → સંતૃપ્ત હાઇડ્રોકાર્બન્સ; મુખ્ય પ્રક્રિયા: મુક્ત મૂલક પ્રતિસ્થાપન.
એલ્કીન → દ્વિ-બંધ ધરાવે; મુખ્ય પ્રક્રિયા: ન્યુક્લિયોફિલિક સંયોજન.
એલ્કાઇન → ત્રિ-બંધ ધરાવે; ટર્મિનલ એલ્કાઇન એસિડિક હોય છે (pKa ≈ 25).
ઝેલેક્યુલેશન (Dehydrohalogenation): એલ્કાઇલ હેલાઇડ + alcoholic KOH → એલ્કીન (Zaitsev નિયમ).
હેલોજનયોજન: એલ્કીન + X₂ → વિકલ્પિક હેલાઇડ (1,2-ડાયહેલાઇડ).
હેલોજનહાઇડ્રાઇડ યોજન: એલ્કીન + HX → એલ્કાઇલ હેલાઇડ (માર્કોવનિકોફ).
જળવિભાજન (Hydration): એલ્કીન + H₂O/H⁺ → એલ્કોહોલ.
હેટરોજનસ ઉત્પ્રેરક હાઇડ્રોજનયોજન: એલ્કીન/એલ્કાઇન + H₂/Ni → એલ્કેન.
ઓઝોનોલિસિસ: એલ્કીન + O₃/Zn,H₂O → એલ્ડિહાઇડ/કીટોન (C=C તૂટે છે).
બેન્ઝીન નાઇટ્રેશન: HNO₃/H₂SO₄ → નાઇટ્રોબેન્ઝીન (NO₂⁺ ઇલેક્ટ્રોફાઇલ).
બેન્ઝીન સલ્ફોએમિડેશન: fuming H₂SO₄ → બેન્ઝીન સલ્ફોએસિડ (SO₃ ઇલેક્ટ્રોફાઇલ).
ફ્રીડલ-ક્રાફ્ટ્સ એલ્કાઇલેશન: બેન્ઝીન + RCl/AlCl₃ → એલ્કાઇલબેન્ઝીન.
ફ્રીડલ-ક્રાફ્ટ્સ એસિલેશન: બેન્ઝીન + RCOCl/AlCl₃ → એસિલબેન્ઝીન (એરોએસ્ટર).
બેન્ઝીનનું વિકલ્પિક હેલોજનયોજન: Cl₂/FeCl₃ → ક્લોરોબેન્ઝીન.
એરોમેટિકિટી માટે 4 શરતો: ચક્રીય, સમતલીય, સંયુગ્મિત, (4n+2) π-ઇલેક્ટ્રોન.
સાયક્લોહેક્ઝેન (C₆H₁₂) એ એલ્કેન છે, એરોમેટિક નહીં — π-ઇલેક્ટ્રોન 0.
સાયક્લોબ્યુટેન (C₄H₄²⁻) 6 π-ઇલેક્ટ્રોન ધરાવે છે → એરોમેટિક.
બેન્ઝીનનું દહન ધૂમ્રયુક્ત જ્વાળા આપે છે (ઉચ્ચ C/H ગુણોત્તર).
એલ્કાઇનનું Na/NH₃(l) રિડક્શન → ટ્રાન્સ-એલ્કીન.
એલ્કાઇનનું Lindlar ઉત્પ્રેરક + H₂ → સિસ-એલ્કીન.
