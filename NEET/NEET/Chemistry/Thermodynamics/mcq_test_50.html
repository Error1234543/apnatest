Q1. થર્મોડાયનેમિક્સમાં, સિસ્ટમ અને પર્યાવરણ વચ્ચે ઊર્જાનું સ્થાનાંતરણ કયા રૂપમાં થાય છે?
A. કામ (Work)
B. ઊષ્મા (Heat)
C. કામ અને ઊષ્મા બંને
D. દબાણ (Pressure)
✅ C — થર્મોડાયનેમિક્સમાં, સિસ્ટમ અને પર્યાવરણ વચ્ચે ઊર્જાનું સ્થાનાંતરણ કામ (Work) અથવા ઊષ્મા (Heat) રૂપે થાય છે.
Q2. કયા પ્રકારની પ્રક્રિયામાં સિસ્ટમ દ્વારા પર્યાવરણ પર કામ કરવામાં આવે છે?
A. સમતાપી પ્રક્રિયા (Isothermal Process)
B. રૂદ્ધોષ્મ પ્રક્રિયા (Adiabatic Process)
C. પ્રસરણ પ્રક્રિયા (Expansion Process)
D. સંકોચન પ્રક્રિયા (Compression Process)
✅ C — પ્રસરણ પ્રક્રિયામાં સિસ્ટમ દ્વારા પર્યાવરણ પર કામ કરવામાં આવે છે, જ્યારે સંકોચન પ્રક્રિયામાં પર્યાવરણ દ્વારા સિસ્ટમ પર કામ કરવામાં આવે છે.
Q3. ઊષ્મા ગતિશીલતાનો SI એકમ કયો છે?
A. જૂલ (Joule)
B. કેલોરી (Calorie)
C. વોટ (Watt)
D. ન્યૂટન (Newton)
✅ A — ઊર્જા અને ઊષ્મા ગતિશીલતાનો SI એકમ જૂલ (Joule) છે.
Q4. થર્મોડાયનેમિક્સમાં, કયા નિયમ અનુસાર, એન્ટ્રોપી હંમેશા વધે છે?
A. પ્રથમ નિયમ (First Law)
B. બીજો નિયમ (Second Law)
C. ત્રીજો નિયમ (Third Law)
D. શૂન્યમો નિયમ (Zeroth Law)
✅ B — થર્મોડાયનેમિક્સના બીજા નિયમ અનુસાર, એન્ટ્રોપી (Entropy) હંમેશા વધે છે અથવા સ્થિર રહે છે.
Q5. થર્મોડાયનેમિક્સમાં, સિસ્ટમ દ્વારા શોષાયેલી ઉર્જાનું માપ કયા પરિબળ દ્વારા થાય છે?
A. ઉષ્મા (Heat - Q)
B. કામ (Work - W)
C. આંતરિક ઉર્જા (Internal Energy - U)
D. એન્ટ્રોપી (Entropy - S)
✅ A — થર્મોડાયનેમિક્સમાં, સિસ્ટમ દ્વારા શોષાયેલી અથવા મુક્ત થતી ઉર્જાનું માપ 'ઉષ્મા (Q)' દ્વારા થાય છે. ઉષ્મા એ ઉર્જાનું એક સ્વરૂપ છે જે તાપમાનના તફાવતને કારણે સિસ્ટમમાં અથવા સિસ્ટમથી બહાર વહન પામે છે.
Q6. થર્મોડાયનેમિક્સના પ્રથમ નિયમ અનુસાર, ΔU = q + wમાં, w નું લખાણ કયા પરિબળ દર્શાવે છે?
A. સિસ્ટમ દ્વારા શોષાયેલી ઉષ્મા (Heat absorbed by the system)
B. સિસ્ટમ પર કરાયેલ કામ (Work done on the system)
C. સિસ્ટમ દ્વારા કરાયેલ કામ (Work done by the system)
D. આંતરિક ઊર્જામાં થતો ફેરફાર (Change in internal energy)
✅ C — થર્મોડાયનેમિક્સના પ્રથમ નિયમમાં, w એ સિસ્ટમ દ્વારા પર્યાવરણ પર કરાયેલ કામ (work done by the system) દર્શાવે છે. જ્યારે સિસ્ટમ કામ કરે ત્યારે w નું મૂલ્ય નકારાત્મક ગણાય છે.
Q7. એક આદર્શ વાયુના સંપીડન (compression) દરમિયાન, જો પ્રક્રિયા રૂદ્ધોષ્મ (adiabatic) હોય, તો નીચેનામાંથી કયું વિધાન સાચું છે?
A. ΔU = 0
B. q = 0
C. w = 0
D. T = 0
✅ B — રૂદ્ધોષ્મ પ્રક્રિયામાં (adiabatic process), સિસ્ટમ અને પર્યાવરણ વચ્ચે ઉષ્માનો વિનિમય થતો નથી, એટલે કે q = 0.
Q8. એનથાલ્પી (Enthalpy) ની વ્યાખ્યા કયા સૂત્ર દ્વારા આપવામાં આવે છે?
A. H = U + PV
B. H = U - PV
C. H = PV - U
D. H = U + TΔS
✅ A — એનથાલ્પી (H) ની વ્યાખ્યા આંતરિક ઊર્જા (U), દબાણ (P), અને કદ (V) ના ગુણાકારના સરવાળા તરીકે કરવામાં આવે છે, એટલે કે H = U + PV.
Q9. થર્મોડાયનેમિક્સના દ્વિતીય નિયમ અનુસાર, સ્વતઃસ્ફૂર્ત પ્રક્રિયાઓ માટે નીચેનામાંથી કયું વિધાન સાચું છે?
A. ΔG > 0
B. ΔG = 0
C. ΔG < 0
D. ΔG = ΔH
✅ C — થર્મોડાયનેમિક્સના દ્વિતીય નિયમ અનુસાર, સ્વતઃસ્ફૂર્ત પ્રક્રિયાઓ માટે ગિબ્સ મુક્ત ઊર્જામાં ઘટાડો થાય છે, એટલે કે ΔG < 0.
Q10. એક પ્રક્રિયા માટે, જો ΔH = -50 kJ અને ΔS = 100 J/K હોય, તો 300 K તાપમાને ΔG નું મૂલ્ય કેટલું હશે?
A. -80 kJ
B. -20 kJ
C. 20 kJ
D. 80 kJ
✅ A — ΔG = ΔH - TΔS. અહીં, ΔH = -50 kJ, ΔS = 100 J/K = 0.1 kJ/K, અને T = 300 K. આમ, ΔG = -50 kJ - (300 K × 0.1 kJ/K) = -50 kJ - 30 kJ = -80 kJ.
Q11. એક ઉદ્દીપક (catalyst) હાજર હોવા છતાં, પ્રક્રિયાની ગિબ્સ મુક્ત ઉર્જામાં (ΔG) કયો ફેરફાર થાય છે?
A. ΔG ઋણ થાય છે
B. ΔG ધન થાય છે
C. ΔG પર કોઈ અસર થતી નથી
D. ΔG શૂન્ય થાય છે
✅ C — ઉદ્દીપક પ્રક્રિયાનો વેગ વધારે છે પરંતુ સંતુલન અવસ્થા અથવા ΔGમાં કોઈ ફેરફાર કરતો નથી, કારણ કે ΔG માત્ર પ્રારંભિક અને અંતિમ અવસ્થા પર આધાર રાખે છે.
Q12. જ્યારે એક આદર્શ વાયુ અવરોધ વિના (free expansion) ફેલાય છે, ત્યારે તેની એન્ટ્રોપી (ΔS) માં કયો ફેરફાર થાય છે?
A. ΔS = 0
B. ΔS < 0
C. ΔS > 0
D. ΔS ની ગણતરી નથી કરી શકાતી
✅ C — અવરોધ વિના ફેલાવવા (free expansion) દરમિયાન વાયુની અવ્યવસ્થા (disorder) વધે છે, જેનાથી એન્ટ્રોપી ધન (ΔS > 0) થાય છે.
Q13. થર્મોડાયનેમિક્સના ત્રીજા નિયમ અનુસાર, શુદ્ધ પદાર્થની એન્ટ્રોપી શૂન્ય કેલ્વિન (0 K) પર કેટલી હોય છે?
A. 1 J/K
B. 0 J/K
C. -1 J/K
D. અનંત (infinite)
✅ B — થર્મોડાયનેમિક્સના ત્રીજા નિયમ અનુસાર, શુદ્ધ અને સંપૂર્ણ રીતે સુવ્યવસ્થિત પદાર્થની એન્ટ્રોપી 0 K પર શૂન્ય (0 J/K) હોય છે.
Q14. એક પ્રક્રિયા માટે ΔH = 10 kJ અને ΔS = 50 J/K હોય, તો કયા તાપમાને પ્રક્રિયા સ્વતઃસ્ફૂર્ત (spontaneous) બનશે?
A. 200 K
B. 250 K
C. 300 K
D. 350 K
✅ A — ΔG = ΔH - TΔS < 0 માટે, T > ΔH/ΔS = 10,000 J / 50 J/K = 200 K. સ્વતઃસ્ફૂર્તતા માટે તાપમાન 200 K થી વધુ હોવું જોઈએ, પરંતુ પ્રશ્નમાં નીચેના તાપમાનની વાત કરવામાં આવી છે, જેથી 200 K એ સીમાબિંદુ છે.
Q15. એક એક્સોથર્મિક પ્રક્રિયામાં (ΔH < 0), જો એન્ટ્રોપી ઘટે (ΔS < 0), તો કયા તાપમાને પ્રક્રિયા સ્વતઃસ્ફૂર્ત (spontaneous) રહેશે?
A. નીચા તાપમાને
B. ઉચ્ચ તાપમાને
C. કોઈપણ તાપમાને
D. કદી નહીં
✅ A — ΔG = ΔH - TΔS માટે, ΔH < 0 અને ΔS < 0 હોવા છતાં, નીચા તાપમાને TΔS નું મૂલ્ય ઓછું હોય છે, જેનાથી ΔG < 0 થાય છે અને પ્રક્રિયા સ્વતઃસ્ફૂર્ત બને છે.
Q16. થર્મોડાયનેમિક્સના પ્રથમ નિયમ અનુસાર, ઉર્જાનું સંરક્ષણ કયા સૂત્ર દ્વારા વ્યક્ત કરવામાં આવે છે?
A. ΔU = Q + W
B. ΔU = Q - W
C. ΔU = W - Q
D. ΔU = Q × W
✅ B — થર્મોડાયનેમિક્સના પ્રથમ નિયમ મુજબ, આંતરિક ઉર્જામાં થતો ફેરફાર (ΔU) પ્રણાલી દ્વારા શોષાયેલ ઉષ્મા (Q) અને પ્રણાલી પર થયેલ કામ (W) ના તફાવત જેટલો હોય છે. સૂત્ર ΔU = Q - W છે.
Q17. એન્ટ્રોપી (Entropy) નું એકમ કયું છે?
A. J/mol
B. J/K
C. J/(mol·K)
D. kJ/mol
✅ C — એન્ટ્રોપી (S) નું SI એકમ જૂલ પ્રતિ મોલ પ્રતિ કેલ્વિન (J/(mol·K)) છે, જેમાં તાપમાનનો ફેરફાર અને પદાર્થની માત્રા ધ્યાનમાં લેવામાં આવે છે.
Q18. જો એક પ્રક્રિયા માટે ΔG (ગિબ્સ મુક્ત ઉર્જા) < 0 હોય, તો પ્રક્રિયા કેવી હશે?
A. અસ્વતઃસ્ફૂર્ત (Non-spontaneous)
B. સંતુલનમાં (Equilibrium)
C. સ્વતઃસ્ફૂર્ત (Spontaneous)
D. ઉષ્મા શોષી લેનારી (Endothermic)
✅ C — ગિબ્સ મુક્ત ઉર્જામાં ઘટાડો (ΔG < 0) દર્શાવે છે કે પ્રક્રિયા સ્વતઃસ્ફૂર્ત છે અને તે પોતાને જ ચાલુ રહેશે.
Q19. આદર્શ વાયુ માટે, આંતરિક ઉર્જા (U) કયા પર આધાર રાખે છે?
A. દબાણ (P)
B. કદ (V)
C. તાપમાન (T)
D. વાયુની માત્રા (n)
✅ C — આદર્શ વાયુની આંતરિક ઉર્જા ફક્ત તાપમાન (T) પર જ આધાર રાખે છે, દબાણ અથવા કદ પર નહીં. આ જોયલના નિયમ (Joule's Law) દ્વારા સિદ્ધ થાય છે.
Q20. થર્મોડાયનેમિક્સમાં, 'સિસ્ટમ' (System) એટલે શું?
A. બ્રહ્માંડનો એક ભાગ જેમાં અભ્યાસ કરવામાં આવે છે
B. પર્યાવરણનો એક ભાગ જેમાં પ્રક્રિયા થાય છે
C. ઉર્જાનો સ્ત્રોત
D. ફક્ત વાયુનો સમૂહ
✅ A — થર્મોડાયનેમિક્સમાં, સિસ્ટમ (System) એ બ્રહ્માંડનો એવો ભાગ છે જેમાં અભ્યાસ કરવામાં આવે છે, જ્યારે બાકીનો ભાગ પર્યાવરણ (Surroundings) કહેવાય છે.
Q21. થર્મોડાયનેમિક્સના દ્વિતીય નિયમ અનુસાર, કયું વિધાન સત્ય છે?
A. ઉર્જાનું સંરક્ષણ થાય છે.
B. એન્ટ્રોપી (Entropy) હંમેશા ઘટતી રહે છે.
C. એન્ટ્રોપી (Entropy) હંમેશા વધતી રહે છે.
D. ઉષ્મા (Heat) પૂર્ણપણે કામમાં રૂપાંતરિત થઈ શકે છે.
✅ C — થર્મોડાયનેમિક્સના દ્વિતીય નિયમ અનુસાર, અલગ થયેલી સિસ્ટમમાં એન્ટ્રોપી હંમેશા વધતી રહે છે અથવા સ્થિર રહે છે, પરંતુ કદી ઘટતી નથી.
Q22. કયા પરિસ્થિતિમાં પ્રક્રિયા સ્વયંસ્ફૂર્ત (Spontaneous) થશે?
A. ΔG > 0 અને ΔS > 0
B. ΔG < 0 અને ΔH > 0
C. ΔG < 0 અને ΔS < 0
D. ΔG = 0 અને ΔH = 0
✅ B — પ્રક્રિયા સ્વયંસ્ફૂર્ત થવા માટે ગિબ્સ મુક્ત ઉર્જા (ΔG) નકારાત્મક હોવી જોઈએ. ΔG < 0 હોવા છતાં ΔH > 0 હોઈ શકે, પરંતુ ΔG < 0 એ મુખ્ય શરત છે.
Q23. આદર્શ વાયુ માટે, કયું સૂત્ર આંતરિક ઉર્જા (U) ને વ્યાખ્યાયિત કરે છે?
A. U = (3/2) nRT
B. U = (5/2) PV
C. U = nCvΔT
D. U = nCpΔT
✅ C — આદર્શ વાયુ માટે, આંતરિક ઉર્જા (U) નું સૂત્ર U = nCvΔT છે, જ્યાં n મોલની સંખ્યા, Cv મોલર ઉષ્મા ધારિતા (Molar Heat Capacity at constant volume), અને ΔT તાપમાનનો ફેરફાર છે.
Q24. કયા પ્રકારની પ્રક્રિયામાં ΔH = ΔU હોય છે?
A. સ્થિર કદે થતી પ્રક્રિયા
B. સ્થિર દબાણે થતી પ્રક્રિયા
C. સ્થિર તાપમાને થતી પ્રક્રિયા
D. ઉત્કલન પ્રક્રિયા
✅ A — સ્થિર કદે (ΔV = 0) થતી પ્રક્રિયામાં, PΔV = 0 હોવાથી ΔH = ΔU થાય છે.
Q25. એક પ્રક્રિયા માટે ΔG = ΔH – TΔS સૂત્રમાં, T નું એકમ કયું હોવું જોઈએ જેથી ΔG, ΔH અને TΔS ના એકમો સુસંગત રહે?
A. J/mol
B. K
C. J/K
D. kJ/mol·K
✅ B — ΔG અને ΔH ના એકમો kJ/mol અથવા J/mol હોય છે, જ્યારે ΔS નું એકમ J/mol·K હોય છે. સૂત્ર ΔG = ΔH – TΔS માં T નું એકમ K (કેલ્વિન) હોવું જરૂરી છે, જેથી TΔS નું એકમ J/mol થાય અને સૂત્રના તમામ પડ સુસંગત રહે.
Q26. એક એન્ટ્રોપી (Entropy) વૃદ્ધિ પામતી પ્રક્રિયામાં, તાપમાન (T) વધારવા પર ΔG (ગિબ્સ મુક્ત ઉર્જા) પર શું અસર થાય છે?
A. ΔG વધે છે.
B. ΔG ઘટે છે.
C. ΔG અચળ રહે છે.
D. ΔG ના મૂલ્ય પર કોઈ અસર થતી નથી.
✅ B — ΔG = ΔH – TΔS સૂત્ર અનુસાર, જો ΔS > 0 હોય તો T વધારવાથી –TΔS વધુ ઋણ થાય, પરિણામે ΔG ઘટે છે.
Q27. થર્મોડાયનેમિક્સના પહેલા નિયમ અનુસાર, કયું સૂત્ર યોગ્ય છે?
A. ΔU = q + w
B. ΔU = q – w
C. ΔU = w – q
D. ΔU = –q – w
✅ B — થર્મોડાયનેમિક્સના પહેલા નિયમ મુજબ, આંતરિક ઉર્જામાં ફેરફાર (ΔU) ઉષ્મા (q) અને કાર્ય (w) ના સરવૈયા પર આધાર રાખે છે, જ્યાં w = –PΔV. સંકેત પરંપરા અનુસાર ΔU = q – w.
Q28. એક પ્રક્રિયામાં જ્યારે ΔH = 30 kJ/mol અને ΔS = 100 J/mol·K હોય, તો કયા તાપમાને પ્રક્રિયા સ્વયંસ્ફૂર્ત (Spontaneous) બનશે?
A. 273 K
B. 300 K
C. 323 K
D. 373 K
✅ B — ΔG = ΔH – TΔS < 0 માટે, T > ΔH/ΔS = 30000 J/mol / 100 J/mol·K = 300 K. આથી 300 K થી વધુ તાપમાને પ્રક્રિયા સ્વયંસ્ફૂર્ત બનશે.
Q29. આદર્શ વાયુ માટે, કયું વિધાન સત્ય છે?
A. આંતરિક ઉર્જા (U) દબાણ પર આધાર રાખે છે.
B. એન્થાલ્પી (H) તાપમાન અને દબાણ પર આધાર રાખે છે.
C. એન્ટ્રોપી (S) દબાણ પર આધાર રાખતી નથી.
D. ગુપ્ત ઉષ્મા (Latent heat) દબાણ પર આધાર રાખે છે.
✅ B — આદર્શ વાયુ માટે, એન્થાલ્પી (H) તાપમાન અને દબાણ પર આધાર રાખે છે, જ્યારે આંતરિક ઉર્જા (U) ફક્ત તાપમાન પર જ આધાર રાખે છે.
Q30. થર્મોડાયનેમિક્સના ત્રીજા નિયમ અનુસાર, શૂન્ય કેલ્વિન તાપમાને (0 K) કયા પદાર્થની એન્ટ્રોપી (S) શૂન્ય હોય છે?

B. ફક્ત વાયુ પદાર્થની
C. ફક્ત ઘન પદાર્થની
D. પૂર્ણપણે શુદ્ધ અને સફેદ ક્રિસ્ટલીન પદાર્થની
✅ D — થર્મોડાયનેમિક્સના ત્રીજા નિયમ મુજબ, 0 K તાપમાને પૂર્ણપણે શુદ્ધ અને સફેદ ક્રિસ્ટલીન પદાર્થની એન્ટ્રોપી શૂન્ય હોય છે.
Q31. થર્મોડાયનેમિક્સમાં, કયું એકમ ઉષ્માક્ષમતા (Heat Capacity) ને દર્શાવે છે?

B. J/K
C. J/(mol·K)

Q32. એક એક્સોથર્મિક પ્રક્રિયામાં (Exothermic Reaction), ΔH નું ચિહ્ન કયું હોય છે?
A. ધન (+)
B. ઋણ (–)
C. શૂન્ય (0)
D. અનિશ્ચિત
✅ B — એક્સોથર્મિક પ્રક્રિયામાં ઉર્જા બહાર પડે છે, તેથી એનથાલ્પી ફેરફાર (ΔH) ઋણ હોય છે.
Q33. થર્મોડાયનેમિક્સના દ્વિતીય નિયમ અનુસાર, પ્રકૃતિમાં સ્વત:સ્ફૂર્ત પ્રક્રિયાઓ માટે કયું વિધાન સત્ય છે?

B. ΔS < 0
C. ΔS = 0

✅ A — થર્મોડાયનેમિક્સના દ્વિતીય નિયમ મુજબ, સ્વત:સ્ફૂર્ત પ્રક્રિયાઓમાં એન્ટ્રોપી (ΔS) વૃદ્ધિ પામે છે, એટલે કે ΔS > 0.
Q34. કયા તાપમાને પાણીનું ગલનાંક (Melting Point) 0°C હોય છે?

B. 373 K
C. 0 K
D. 100 K
✅ A — 0°C તાપમાન 273 K બરાબર હોય છે, અને આ તાપમાને પાણીનું ગલનાંક (Melting Point) હોય છે.
Q35. થર્મોડાયનેમિક્સમાં, કયું સૂત્ર આંતરિક ઉર્જા (Internal Energy, U) ના ફેરફારને વ્યક્ત કરે છે?

B. ΔU = q – w
C. ΔU = w – q
D. ΔU = q × w
✅ B — થર્મોડાયનેમિક્સના પહેલા નિયમ અનુસાર, આંતરિક ઉર્જાના ફેરફાર (ΔU) નું સૂત્ર ΔU = q – w છે, જ્યાં q ઉષ્મા (heat) અને w કાર્ય (work) છે.
Q36. એક પ્રક્રિયામાં ΔG = ΔH – TΔS હોવાથી, જો ΔH = -50 kJ/mol, ΔS = -150 J/mol·K અને T = 300 K હોય, તો ΔG ની કિંમત કેટલી થશે?

Q37. થર્મોડાયનેમિક્સના પ્રથમ નિયમ અનુસાર, કયું સૂત્ર યોગ્ય છે?
A. ΔU = q + w
B. ΔU = q – w
C. ΔU = w – q
D. ΔU = -q + w
✅ A — થર્મોડાયનેમિક્સના પ્રથમ નિયમ મુજબ આંતરિક ઉર્જામાં ફેરફાર (ΔU) ઉષ્મા (q) અને કાર્ય (w) ના સરવળા બરાબર હોય છે, જ્યાં w = -PΔV હોવાથી ΔU = q + w લખાય છે.
Q38. એક આદર્શ વાયુના સંપીડન (Compression) દરમિયાન, જો પ્રક્રિયા રૂદ્ધોષ્મ (Adiabatic) હોય, તો કયું વિધાન સત્ય છે?

Q39. એન્ટ્રોપી (Entropy) ની SI એકમ કઈ છે?

✅ C — એન્ટ્રોપી (ΔS) ની SI એકમ જૂલ પ્રતિ મોલ પ્રતિ કેલ્વિન (J/mol·K) છે.
Q40. જ્યારે એક પદાર્થનું તાપમાન વધારે છે, ત્યારે તેની એન્ટ્રોપી પર શું અસર થાય છે?

D. એન્ટ્રોપી શૂન્ય થાય છે

Q41. એક થર્મોડાયનેમિક પ્રક્રિયામાં, જો ΔH = +40 kJ/mol અને ΔS = +120 J/(mol·K) હોય, તો કયા તાપમાને પ્રક્રિયા સ્વત:સ્ફૂરતાથી (spontaneously) થશે?

Q42. એક આદર્શ વાયુના અચળ દબાણે (isobaric) પ્રસરણ દરમિયાન, કયું વક્ર p-V આલેખ (graph) પર દર્શાવશે?

Q43. થર્મોડાયનેમિક્સના ત્રીજા નિયમ અનુસાર, શૂન્ય કેલ્વિન તાપમાને કોઈ પદાર્થની એન્ટ્રોપી (Entropy) કેટલી હોય છે?

Q44. એક પ્રક્રિયામાં ΔU = 100 J અને W = -60 J હોય, તો પ્રક્રિયામાં શોષાયેલી ઉષ્મા (q) કેટલી હશે?

Q45. કયા પ્રકારની પ્રક્રિયામાં ΔH = q_p હોય છે?

B. અચળ દબાણવાળી (Isobaric)
C. અચળ તાપમાનવાળી (Isothermal)
D. અચળ ઉર્જાવાળી (Adiabatic)
✅ B — અચળ દબાણે (p = constant), પ્રક્રિયામાં શોષાયેલી ઉષ્મા (q_p) એ એન્થાલ્પી પરિવર્તન (ΔH) બરાબર હોય છે.
Q46. થર્મોડાયનેમિક્સના પહેલા નિયમ અનુસાર, ΔU = q + Wમાં, 'W' શું દર્શાવે છે?
A. ઊર્જાનો નુકશાન (Energy loss)
B. પ્રણાલી પર થયેલું કામ (Work done on the system)
C. પ્રણાલી દ્વારા થયેલું કામ (Work done by the system)
D. ઉષ્મા ઉર્જા (Heat energy)
✅ C — થર્મોડાયનેમિક્સના પહેલા નિયમ મુજબ, ΔU = q + W, જ્યાં 'W' પ્રણાલી દ્વારા પરિસર પર થયેલું કામ દર્શાવે છે. જ્યારે પ્રણાલી કામ કરે ત્યારે W નેગેટિવ હોય છે.
Q47. એન્થાલ્પી (Enthalpy) ની વ્યાખ્યા કઈ છે?
A. H = U + PV
B. H = U - TS
C. H = q + W
D. H = PV - U
✅ A — એન્થાલ્પી (H) ની વ્યાખ્યા H = U + PV છે, જ્યાં U આંતરિક ઊર્જા (Internal energy), P દબાણ (Pressure), અને V કદ (Volume) છે.
Q48. અચળ કદે (Isochoric) થતી પ્રક્રિયામાં, કયું વિધાન સાચું છે?
A. ΔU = q_v
B. ΔH = q_p
C. W = 0
D. A અને C બંને
✅ D — અચળ કદે (Isochoric) પ્રક્રિયામાં કદમાં ફેરફાર થતો નથી, તેથી W = 0. થર્મોડાયનેમિક્સના પહેલા નિયમ મુજબ, ΔU = q_v.
Q49. એક પ્રક્રિયાની એન્ટ્રોપી (Entropy) નો ફેરફાર ΔS = q_rev/T દ્વારા ગણવામાં આવે છે. અહીં 'q_rev' શું દર્શાવે છે?
A. અવ્યવસ્થિત ઉષ્મા (Irreversible heat)
B. વ્યવસ્થિત ઉષ્મા (Reversible heat)
C. પ્રણાલીની આંતરિક ઊર્જા (Internal energy of the system)
D. પરિસરની એન્ટ્રોપી (Entropy of surroundings)
✅ B — એન્ટ્રોપીના ફેરફારના સૂત્ર ΔS = q_rev/Tમાં, 'q_rev' વ્યવસ્થિત (Reversible) રીતે વહન પામતી ઉષ્મા દર્શાવે છે.
Q50. થર્મોડાયનેમિક્સના બીજા નિયમ અનુસાર, અવ્યવસ્થિત પ્રક્રિયાઓમાં એન્ટ્રોપી (Entropy) નો ફેરફાર કેવો હોય છે?
A. ΔS = 0
B. ΔS < 0
C. ΔS > 0
D. ΔS = q/T
✅ C — થર્મોડાયનેમિક્સના બીજા નિયમ મુજબ, અવ્યવસ્થિત (Irreversible) પ્રક્રિયાઓમાં એન્ટ્રોપી (Entropy) નો ફેરફાર હંમેશા ધન (ΔS > 0) હોય છે.
