Q1. થર્મોડાયનેમિક્સમાં, સિસ્ટમ અને સરરાઉન્ડિંગ્સ વચ્ચે ઉર્જાનું વહન કયા સ્વરૂપે થાય છે?
A. કામ (Work)
B. ઉષ્મા (Heat)
C. દબાણ (Pressure)
D. વોલ્યુમ (Volume)
✅ B — થર્મોડાયનેમિક્સમાં, ઉર્જાનું વહન ઉષ્મા (Heat) અથવા કામ (Work) સ્વરૂપે થાય છે. પરંતુ પ્રશ્નમાં સરરાઉન્ડિંગ્સ સાથે ઉર્જા વહનનો સીધો સંદર્ભ ઉષ્મા (Heat) તરફ દર્શાવે છે.
Q2. થર્મોડાયનેમિક્સના પહેલા નિયમ મુજબ, ΔU = q + w માં, ΔU શું દર્શાવે છે?
A. અંતર્ગત ઉર્જામાં ફેરફાર (Change in Internal Energy)
B. એન્ટ્રોપીમાં ફેરફાર (Change in Entropy)
C. એન્થાલ્પીમાં ફેરફાર (Change in Enthalpy)
D. ગિબ્સ મુક્ત ઉર્જામાં ફેરફાર (Change in Gibbs Free Energy)
✅ A — થર્મોડાયનેમિક્સના પહેલા નિયમ અનુસાર, ΔU અંતર્ગત ઉર્જામાં ફેરફાર (Change in Internal Energy) દર્શાવે છે, જ્યાં q ઉષ્મા અને w કામ છે.
Q3. નીચેનામાંથી કયું પદાર્થનું ગુણધર્મ નથી?
A. દબાણ (Pressure)
B. તાપમાન (Temperature)
C. વોલ્યુમ (Volume)
D. ઉર્જા (Energy)
✅ D — દબાણ, તાપમાન અને વોલ્યુમ એ પદાર્થના ભૌતિક ગુણધર્મો છે, જ્યારે ઉર્જા એક મૂળભૂત ભૌતિક રાશિ છે, પદાર્થનું ગુણધર્મ નહીં.
Q4. એક આદર્શ વાયુના વિસ્તરણ દરમિયાન, જો સિસ્ટમ પર કોઈ બાહ્ય કામ ન કરવામાં આવે, તો q (ઉષ્મા)નું મૂલ્ય શું હશે?
A. શૂન્ય (Zero)
B. ધન (Positive)
C. ઋણ (Negative)
D. અનંત (Infinite)
✅ B — જો સિસ્ટમ પર કોઈ બાહ્ય કામ ન કરવામાં આવે (w = 0), તો થર્મોડાયનેમિક્સના પહેલા નિયમ મુજબ ΔU = q. વિસ્તરણ દરમિયાન અંતર્ગત ઉર્જા વધે છે, તેથી q ધન (Positive) હશે.
Q5. થર્મોડાયનેમિક્સમાં, કયું પારિભાષિક શબ્દ 'સિસ્ટમના અવ્યવસ્થિતપણાનું માપન' દર્શાવે છે?
A. એન્ટ્રોપી (Entropy)
B. એન્થાલ્પી (Enthalpy)
C. ગિબ્સ મુક્ત ઉર્જા (Gibbs Free Energy)
D. અંતર્ગત ઉર્જા (Internal Energy)
✅ A — એન્ટ્રોપી (Entropy) એ સિસ્ટમના અવ્યવસ્થિતપણાનું માપન છે. તે થર્મોડાયનેમિક્સનો મહત્વનો પારિભાષિક શબ્દ છે.
Q6. થર્મોડાયનેમિક્સના બીજા નિયમ મુજબ, એન્ટ્રોપી (Entropy) ની વ્યાખ્યા કયા સૂત્ર દ્વારા આપવામાં આવે છે?
A. ΔS = q_rev / T
B. ΔS = q_irrev / T
C. ΔS = ΔH / T
D. ΔS = w / T
✅ A — થર્મોડાયનેમિક્સના બીજા નિયમ અનુસાર, રિવર્સિબલ પ્રક્રિયામાં એન્ટ્રોપીનો ફેરફાર (ΔS) તાપમાન (T) દ્વારા વહેંચાયેલ ઉષ્મા (q_rev) ના ગુણોત્તર બરાબર હોય છે.
Q7. એક એક્સોથર્મિક પ્રક્રિયામાં (Exothermic Process), સિસ્ટમની એન્થાલ્પી (Enthalpy) માં કયો ફેરફાર થાય છે?
A. ΔH > 0
B. ΔH = 0
C. ΔH < 0
D. ΔH = q_p
✅ C — એક્સોથર્મિક પ્રક્રિયામાં સિસ્ટમ ઉર્જા મુક્ત કરે છે, જેથી એન્થાલ્પીનો ફેરફાર (ΔH) નકારાત્મક હોય છે.
Q8. થર્મોડાયનેમિક્સમાં, આઈસોથર્મલ પ્રક્રિયા (Isothermal Process) ની વ્યાખ્યા કયા પરિબળને સ્થિર રાખીને કરવામાં આવે છે?
A. દબાણ (Pressure)
B. તાપમાન (Temperature)
C. વોલ્યુમ (Volume)
D. એન્ટ્રોપી (Entropy)
✅ B — આઈસોથર્મલ પ્રક્રિયામાં તાપમાન (Temperature) સ્થિર રહે છે, જ્યારે અન્ય પરિબળો બદલાઈ શકે છે.
Q9. એક આદર્શ વાયુના સંકોચન દરમિયાન, જો પ્રક્રિયા એડિયાબેટિક (Adiabatic) હોય, તો કયું પદાર્થનું ગુણધર્મ સ્થિર રહે છે?
A. તાપમાન (Temperature)
B. દબાણ (Pressure)
C. ઉર્જા (Energy)
D. ઉષ્મા (Heat)
✅ D — એડિયાબેટિક પ્રક્રિયામાં સિસ્ટમ અને સરરાઉન્ડિંગ્સ વચ્ચે ઉષ્માનો વિનિમય થતો નથી, જેથી ઉષ્મા (q) શૂન્ય હોય છે.
Q10. થર્મોડાયનેમિક્સના ત્રીજા નિયમ મુજબ, શૂન્ય કેલ્વિન તાપમાને પૂર્ણ ક્રિસ્ટલીન પદાર્થની એન્ટ્રોપી કેટલી હોય છે?
A. 1 J/K
B. 0 J/K
C. -1 J/K
D. અનંત (Infinity)
✅ B — થર્મોડાયનેમિક્સના ત્રીજા નિયમ અનુસાર, શૂન્ય કેલ્વિન તાપમાને પૂર્ણ ક્રિસ્ટલીન પદાર્થની એન્ટ્રોપી શૂન્ય (0 J/K) હોય છે.
Q11. થર્મોડાયનેમિક્સમાં, એક પ્રક્રિયાના ગિબ્સ મુક્ત ઊર્જા (Gibbs Free Energy, G) ની વ્યાખ્યા કયી છે?
A. G = H + TS
B. G = H - TS
C. G = U + PV
D. G = TS - H
✅ B — ગિબ્સ મુક્ત ઊર્જાની વ્યાખ્યા G = H - TS છે, જ્યાં H એ એન્થાલ્પી (Enthalpy), T એ તાપમાન, અને S એ એન્ટ્રોપી (Entropy) છે.
Q12. થર્મોડાયનેમિક્સના પ્રથમ નિયમ મુજબ, ΔU = q + w, જ્યાં w એ સિસ્ટમ દ્વારા કરેલ કામ છે. જો સિસ્ટમ પર 50 J કામ કરવામાં આવે અને સિસ્ટમ 30 J ઉષ્મા ગુમાવે, તો સિસ્ટમની આંતરિક ઊર્જામાં થતો ફેરફાર (ΔU) કેટલો હશે?
A. -80 J
B. 20 J
C. -20 J
D. 80 J
✅ B — ΔU = q + w, જ્યાં q = -30 J (ઉષ્મા ગુમાવવી) અને w = +50 J (સિસ્ટમ પર કામ કરવું). આથી, ΔU = -30 J + 50 J = 20 J.
Q13. એક પ્રક્રિયા માટે ΔH = -120 kJ અને ΔS = -0.4 kJ/K છે. તો પ્રક્રિયા ક્યારે સ્વત:સ્ફૂર્ત (spontaneous) બનશે?
A. T < 300 K
B. T > 300 K
C. T = 300 K
D. કોઈપણ તાપમાને નહીં
✅ A — ગિબ્સ મુક્ત ઊર્જા ΔG = ΔH - TΔS. પ્રક્રિયા સ્વત:સ્ફૂર્ત બનવા ΔG < 0 હોવું જોઈએ. ΔH = -120 kJ અને ΔS = -0.4 kJ/K લેતા, ΔG = -120 - T(-0.4) = -120 + 0.4T. ΔG < 0 માટે, -120 + 0.4T < 0 → T < 300 K.
Q14. થર્મોડાયનેમિક્સમાં, એક આદર્શ વાયુના આઈસોબેરિક પ્રક્રિયા (Isobaric Process) દરમિયાન, નીચેનામાંથી કયું સત્ય છે?
A. ΔU = 0
B. q = 0
C. w = -PΔV
D. ΔH = ΔU
✅ C — આઈસોબેરિક પ્રક્રિયામાં દબાણ (P) સ્થિર રહે છે, અને સિસ્ટમ દ્વારા કરેલ કામ w = -PΔV હોય છે. બાકીના વિકલ્પો આ પ્રક્રિયા માટે સત્ય નથી.
Q15. એક પ્રક્રિયામાં, સિસ્ટમની એન્ટ્રોપી 0.5 J/K વધે છે અને પરિસરની એન્ટ્રોપી 0.3 J/K ઘટે છે. તો કુલ એન્ટ્રોપીમાં થતો ફેરફાર (ΔS_total) કેટલો હશે?
A. 0.2 J/K
B. -0.2 J/K
C. 0.8 J/K
D. -0.8 J/K
✅ A — કુલ એન્ટ્રોપીમાં ફેરફાર ΔS_total = ΔS_system + ΔS_surroundings = 0.5 J/K + (-0.3 J/K) = 0.2 J/K.
Q16. થર્મોડાયનેમિક્સમાં, એનથાલ્પી (Enthalpy) ની વ્યાખ્યા કયા સૂત્ર દ્વારા આપવામાં આવે છે?
A. H = U + PV
B. H = U - PV
C. H = PV - U
D. H = U + TS
✅ A — એનથાલ્પી (H) ની વ્યાખ્યા આંતરિક ઊર્જા (U), દબાણ (P), અને કદ (V) ના ગુણાકારના સરવળા દ્વારા આપવામાં આવે છે, જેથી H = U + PV.
Q17. થર્મોડાયનેમિક્સના પ્રથમ નિયમ અનુસાર, સિસ્ટમની આંતરિક ઊર્જામાં થતો ફેરફાર (ΔU) કયા પરિબળો પર આધાર રાખે છે?
A. કેવલ ઉષ્મા (q) પર
B. કેવલ કામ (w) પર
C. ઉષ્મા (q) અને કામ (w) બંનેપર
D. તાપમાન (T) અને દબાણ (P) પર
✅ C — થર્મોડાયનેમિક્સના પ્રથમ નિયમ મુજબ, ΔU = q + w, જેમાં ΔU એ આંતરિક ઊર્જામાં ફેરફાર, q એ ઉષ્મા, અને w એ કામ છે.
Q18. એક પ્રક્રિયા માટે ΔG (ગિબ્સ મુક્ત ઊર્જામાં ફેરફાર) નું મૂલ્ય શૂન્ય હોય ત્યારે પ્રક્રિયા કેવી હોવાની સંભાવના છે?
A. સ્વતઃસ્ફૂર્ત (Spontaneous)
B. અસ્વતઃસ્ફૂર્ત (Non-spontaneous)
C. સંતુલનમાં (Equilibrium)
D. એન્ડોથર્મિક (Endothermic)
✅ C — જ્યારે ΔG = 0 હોય ત્યારે પ્રક્રિયા સંતુલન અવસ્થામાં હોય છે, એટલે કે અગ્રગામી અને પશ્ચગામી પ્રક્રિયાઓની ગતિ સરખી હોય છે.
Q19. થર્મોડાયનેમિક્સમાં, એન્ટ્રોપી (Entropy) નું પ્રતીક કયું છે?
A. H
B. G
C. S
D. U
✅ C — એન્ટ્રોપી (Entropy) નું પ્રતીક 'S' છે, જે સિસ્ટમની અવ્યવસ્થા અથવા અશાંતિનું માપ દર્શાવે છે.
Q20. એક આદર્શ વાયુ માટે, આઈસોકોરિક પ્રક્રિયા (Isochoric Process) દરમિયાન કયો પરિબળ સ્થિર રહે છે?
A. દબાણ (P)
B. કદ (V)
C. તાપમાન (T)
D. ઉષ્મા (Q)
✅ B — આઈસોકોરિક પ્રક્રિયામાં, વાયુનું કદ (V) સ્થિર રહે છે, જ્યારે દબાણ અને તાપમાન બદલાઈ શકે છે.
Q21. થર્મોડાયનેમિક્સમાં, એક પ્રક્રિયાની સ્વયંસ્ફૂર્તતા (spontaneity) નક્કી કરવા માટે કયો થર્મોડાયનેમિક પોટેન્શિયલ વપરાય છે?
A. આંતરિક ઊર્જા (Internal Energy)
B. એનથાલ્પી (Enthalpy)
C. ગિબ્સ મુક્ત ઊર્જા (Gibbs Free Energy)
D. એન્ટ્રોપી (Entropy)
✅ C — ગિબ્સ મુક્ત ઊર્જા (ΔG) પ્રક્રિયાની સ્વયંસ્ફૂર્તતા નક્કી કરવા માટેનો મુખ્ય માપદંડ છે. જો ΔG < 0 હોય, તો પ્રક્રિયા સ્વયંસ્ફૂર્ત છે.
Q22. થર્મોડાયનેમિક્સના બીજા નિયમ અનુસાર, એક અલગ થયેલી સિસ્ટમ (isolated system) ની એન્ટ્રોપીમાં કયો ફેરફાર થાય છે?
A. ઘટે છે
B. વધે છે
C. સ્થિર રહે છે
D. શૂન્ય થાય છે
✅ B — થર્મોડાયનેમિક્સના બીજા નિયમ અનુસાર, અલગ થયેલી સિસ્ટમની એન્ટ્રોપી હંમેશા વધે છે અથવા સ્થિર રહે છે, પરંતુ કદી ઘટતી નથી.
Q23. એક પ્રક્રિયા માટે ΔH = 30 kJ અને ΔS = 0.1 kJ/K છે. તો 300 K તાપમાને ΔG નું મૂલ્ય કેટલું હશે?
A. 0 kJ
B. 20 kJ
C. 30 kJ
D. 40 kJ
✅ A — ΔG = ΔH - TΔS = 30 kJ - (300 K × 0.1 kJ/K) = 30 kJ - 30 kJ = 0 kJ.
Q24. થર્મોડાયનેમિક્સમાં, કયા પ્રકારની પ્રક્રિયામાં સિસ્ટમ દ્વારા કોઈ કામ કરવામાં આવતું નથી?
A. આઈસોથર્મલ પ્રક્રિયા (Isothermal Process)
B. આઈસોબેરિક પ્રક્રિયા (Isobaric Process)
C. આઈસોકોરિક પ્રક્રિયા (Isochoric Process)
D. એડિયાબેટિક પ્રક્રિયા (Adiabatic Process)

Q25. થર્મોડાયનેમિક્સમાં, 'q' એ કયા પ્રકારની ઊર્જાનું પ્રતીક છે?
