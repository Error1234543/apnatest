NEET UG — પરમાણુઓ અને ન્યુક્લિયસ (Atoms and Nuclei) EXAM TRICKS

🩺 NEET UG — Gujarati • Physics • Atoms and Nuclei

🎯 પરીક્ષા ટ્રિક્સ

બોહર મોડલની ઊર્જા માટેની યાદ રહે તેમ છો કે E_n = -13.6/n² eV (H-અણુ માટે). ઋણ ચિહ્ન દર્શાવે છે કે ઇલેક્ટ્રોન બંધાયેલ છે; n વધે તો ઊર્જા ઓછી ઋણ (વધે) છે.
જ્યારે કોઈ પ્રશ્નમાં ઇલેક્ટ્રોનની ઊર્જા, ઇલેક્ટ્રિક સ્થિતિજ ઊર્જા અથવા ગતિજ ઊર્જા પૂછે હોય.
દા.ત.: n=2 માટે E₂ = -13.6/4 = -3.4 eV. n=3 માટે E₃ = -13.6/9 ≈ -1.51 eV. જવાબ એકદમ મોટી અંકગણિત વિના મળે.
ઇલેક્ટ્રોનની ટ્રાન્ઝિશન સમયે ઉત્સર્જિત/શોષાતું ફોટોન: ΔE = 13.6×Z²×(1/n₁² - 1/n₂²) eV. Lyman શ્રેણી માટે હંમેશા n₁=1, Balmer માટે n₁=2 લેવું, અને β-કણ (ઇલેક્ટ્રોન) ની ઊર્જા = ΔE જ હોય તે યાદ રાખો.
સ્પેક્ટ્રલ શ્રેણી, લિમિટ અથવા ફોટોનની તરંગલંબાઈ/ઊર્જા શોધવાનો પ્રશ્ન હોય.
દા.ત.: Lyman શ્રેણીની લિમિટ (n₂→∞, n₁=1): ΔE = 13.6(1 - 0) = 13.6 eV. Balmer લિમિટ = 13.6(1/4 - 0) = 3.4 eV.
કક્ષાની ત્રિજ્યા r_n = 0.529 n²/Z Å (Bore ત્રિજ્યા a₀ = 0.529 Å). માત્ર n² જોડણી યાદ રાખો: r₁:a₂:r₃ = 1:4:9. ત્રિજ્યા n² પ્રમાણે, વેગ n⁻¹ પ્રમાણે, ઊર્જા n⁻² પ્રમાણે.
ત્રિજ્યા, વેગ, આવર્તકાળ સંબંધી સરખામણી પ્રશ્નો.
દા.ત.: H-અણુમાં r₃/r₁ = 9, v₃/v₁ = 1/3. સાચો જવાબ તરત બહાર કરી શકાય.
પ્રોટોન/ઊર્જા/આવૃત્તિનો સીધો સંબંધ: E = hν = hc/λ. NEET માં પ્રાયોગિક રીતે ν (Hz) શોધવા λ = 600 nm દત્ત હોય તો ν ≈ 5×10¹⁴ Hz લઈ શકાય (hc ≈ 1240 eV·nm યાદ રાખો).
ફોટોનની આવૃત્તિ/ઊર્જા/તરંગલંબાઈ એકબીજામાં રૂપાંતરિત કરવાનો પ્રશ્ન.
દા.ત.: λ = 400 nm → E = 1240/400 = 3.10 eV; λ = 800 nm → E = 1240/800 = 1.55 eV. ગણિત વિના જવાબ.
α-ક્ષય: C → A-4, Z-2; β⁻-ક્ષય: C → A, Z+1 (ન્યુટ્રોન → પ્રોટોન + ઇલેક્ટ્રોન); β⁺-ક્ષય: C → A, Z-1 (પ્રોટોન → ન્યુટ્રોન + પોઝિટ્રોન). ગામા ક્ષય: કોઈ ફેરફાર નહીં.
核વિકિરણ (Radioactive decay) શ્રેણી પ્રશ્નો જેમાં નવા મૂલકનું પ્રતીક શોધવું હોય.
દા.ત.: ²³⁸₉₂U → α ક્ષય → ²³⁴₉₀Th. β⁻ ક્ષય પછી Z+1 થાય છે, આથી પરમાણુ ક્રમાંક બદલાય પણ દળ પ્રમાણબંધ નથી રહેતો.
અર્ધ-આયુ (t½) ની ગણતરી: N/N₀ = (1/2)ⁿ જ્યાં n = t/t½. પૂર્ણાંક n માટે તરત જવાબ: n=1→50%, n=2→25%, n=3→12.5%, n=4→6.25%. જો n અપૂર્ણાંક હોય તો log વાપરો: t = t½ × ln(N₀/N)/ln2.
રેડિયોક્ટિવ ડિકે (Radioactive decay) અને સમયની ગણતરીનો પ્રશ્ન.
દા.ત.: જો n = 3.5 વખતો હોય તો બાકી મોટાઈ = (1/2)^3.5 ≈ 0.088 (8.8%). સામાન્ય NEET પ્રશ્નોમાં n=1,2,3 જ આવે છે.
બાંધકાણીય ઊર્જા (Binding energy per nucleon) નો વક્ર યાદ રાખો: Fe-56 (nucleon પ્રતિ બંધની ઊર્જા ≈ 8.8 MeV) સૌથી વધુ સ્થિર. H-ન્યુક્લિયસ ≈ 1.1 MeV, U ≈ 7.6 MeV. ગુરુ ન્યુક્લિયસનું વિખંડન અને હલકા ન્યુક્લિયસનું સંલયન બંને ऊर्जा મુક્ત કરે.
ન્યુક્લિયર બંધન ઊર્જા, ફિશન/ફ્યુઝન માટે કયા પ્રક્રિયા શક્તિ ઉત્પન્ન કરશે તેના પ્રશ્નો.
દા.ત.: A≈235 (U) → નાના ભાગ (A≈117) ની બંધની ઊર્જા ≈8.5 MeV, વૃદ્ધિ ≈0.9 MeV/ન્યુક્લિયોન → લગભગ 200 MeV ફિશન ઊર્જા.
કુલ બાંધકાણીય ઊર્જા = Δm × 931.5 MeV, જ્યાં Δm એ amu (u) માં દળ ખાધો (Mass defect). NEET માં સામાન્ય રીતે 931.5 MeV/u એ constant તરીકે આપેલ છે.
દળ ખાધો (Mass defect) થી બંધન ઊર્જા શોધવી હોય.
દા.ત.: Δm = 0.03 u → BE = 0.03 × 931.5 ≈ 27.95 MeV. પ્રતિ ન્યુક્લિયોન = 27.95/6 ≈ 4.66 MeV (દા.ત. Li-6).
રેડિયોએક્ટિવ સક્રિયતા: A = λN = (0.693/t½) × N. એકમ: Becquerel (Bq = 1 decay/s), Curie (Ci = 3.7×10¹⁰ Bq). NEET માં રૂપાંતર વારંવાર પૂછાય છે.
Activity/સક્રિયતા (Becquerel/Curie) ની ગણતરી અથવા રૂપાંતર પ્રશ્ન.
દા.ત.: 1 Ci = 3.7×10¹⁰ Bq. 10 Ci = 3.7×10¹¹ Bq. સીધું ગુણાકાર, કોઈ અન્ય ગણિત જરૂર નથી.
ઇલેક્ટ્રોનની ઊર્જા અને તરંગલંબાઈ સંબંધ: de Broglie λ = h/p, કક્ષીય કોણીય વેગમાન L = nh/2π. પરમાણુની સ્થિર કક્ષા માટે નિયત: 2πr = nλ (de Broglie શરત).
ડિ બ્રોગલી તરંગલંબાઈ અને બોહરની દ્વિતીય શરત (quantization) નો સંયુક્ત પ્રશ્ન.
દા.ત.: n=2 કક્ષામાં: 2πr₂ = 2λ → λ = πr₂. r₂ = 4a₀ = 4×0.529Å → λ ≈ 6.64 Å.
ઉત્સર્જન સ્પેક્ટ્રમનું મહત્તમ તરંગલંબાઈ: ΔE ન્યૂનતમ એટલે λ મહત્તમ. એક જ શ્રેણીમાં n₂=n₁+1 → લિમિટ (n₂→∞) → λ ન્યૂનતમ. શ્રેણી મહત્તમ λ = λ(n₁+1→∞).
Lyman/Balmer શ્રેણીની મહત્તમ/ન્યૂનતમ તરંગલંબાઈ શોધવાનો પ્રશ્ન.
દા.ત.: Balmerની મહત્તમ λ: n=3→2 → λ_max = 6563 Å (H-α). લિમિટ (n=∞→2): λ_min ≈ 3646 Å. આ પેટર્ન યાદ રાખો.
પરમાણુમાં ઇલેક્ટ્રોનની કુલ ઊર્જા K.E. + P.E.: K.E. = |E_total| અને P.E. = 2E_total (વિરુદ્ધ ચિહ્ન). એટલે કે KE = -E, PE = 2E (જ્યાં E ઋણ છે).
કોઈ પણ કક્ષામાં ગતિજ ઊર્જા અથવા સ્થિતિજ ઊર્જા શોધવી હોય તો ઝડપી ગણતરી.
દા.ત.: n=1: E = -13.6 eV → KE = 13.6 eV, PE = -27.2 eV. n=2: E = -3.4 eV → KE = 3.4 eV, PE = -6.8 eV.
α-કણ અને β-કણ વચ્ચેનો તફાવત યાદ રાખો: α = ⁴₂He ન્યુક્લિયસ (દળ 4u, વીજભાર +2e, ઓછું ભેદન, વધુ આયનીકરણ). β⁻ = ઇલેક્ટ્રોન (દળ ≈ 1/1836u, ભાર -e, વધુ ભેદન, ઓછું આયનીકરણ). γ = વિદ્યુતચુંબકીય તરંગ (દળ શૂન્ય, ભાર શૂન્ય, મહત્તમ ભેદન).
કણોના ગુણધર્મો (ભેદન શક્તિ, આયનીકરણ, વિચલન) સંબંધી પ્રશ્નો.
દા.ત.: ત્રણેય કિરણોને વિદ્યુતક્ષેત્રમાં મોકલવા: α +ve તરફ વળે, β⁻ -ve તરફ વળે (વધુ વળાંક), γ ન વળે. β નો વળાંક α કરતા વધુ કારણે ભાર ઓછો અને વેગ વધુ.
રેડિયોએક્ટિવ ડિકે પ્રશ્નમાં: N(t) = N₀e^(-λt), λ = 0.693/t½. N/N₀ નો ગુણોત્તર જો 1/8, 1/16, 1/32 આવે તો n=3,4,5 અર્ધ-આયુ. 1/7 = ln7/ln2 ≈ 2.807 અર્ધ-આયુ.
પ્રશ્નમાં N/N₀ નો સાંખ્યિક ગુણોત્તર આપેલ હોય અને સમય શોધવો હોય.
દા.ત.: જો બાકી મોટાઈ 1/16 હોય → n = 4 → t = 4t½. પ્રશ્નમાં t = 32 દિવસ → t½ = 8 દિવસ. આ પેટર્ન ઝડપી ઓળખી શકાય.
Rutherford નો α-પ્રકીર્ણ પ્રયોગ: સૌથી નજીકનું અંતર d = (1/4πε₀)×(2Ze²)/(KE). આ d = b (impact parameter) ના બદલે minimum distance છે જ્યાં KE → 0 થાય. શ્રેષ્ઠ ગાણિતિક રીતે: d = k(2Ze²/E_kinetic).
α-પ્રકીર્ણનું લઘુત્તમ અંતર કે impact parameter શોધવાનો પ્રશ્ન.
દા.ત.: 5 MeV α કણ, Au (Z=79): d ≈ (9×10⁹×2×79×(1.6×10⁻¹⁹)²)/(5×1.6×10⁻¹³) ≈ 4.5×10⁻¹⁴ m. આ ન્યુક્લિયસના આकार के आकार સાથે સરખાવવાનો પ્રશ્ન આવે છે.
