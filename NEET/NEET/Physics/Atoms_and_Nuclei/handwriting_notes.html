પરમાણુ અને નાભિક — પ્રસ્તાવના
આધુનિક પરમાણુ મોડેલ બે ભાગ ધરાવે છે: (૧) બોહરનો પરમાણુ મોડેલ અને (૨) નાભિકીય ભૌતિકશાસ્ત્ર.
પરમાણુનું કદ ~ 10⁻¹⁰ m થાય છે, જ્યારે નાભિકનું કદ ~ 10⁻¹⁵ m થાય છે.
⭐ નાભિકમાં પ્રોટોન અને ન્યુટ્રોન (ન્યુક્લિયોન) હોય છે; ઇલેક્ટ્રોન નાભિકની આસપાસ ફરે છે.
📝 ⚡ નોંધ: પરમાણુ વજન સંખ્યા A = પ્રોટોન + ન્યુટ્રોન (Z + N)
રેઝર્ડફોર્ડનો અલ્ફા-કણ વિખેરવાનો પ્રયોગ
અહેલિ (Gold) ના પાતળા થપ્પડ પર ઉચ્ચ ઊર્જા ધરાવતા અલ્ફા કણો ચલાવવામાં આવ્યા.
અલ્ફા કણ: He⁺⁺ ન્યુક્લિયસ, દળ ~ 6.64 × 10⁻²⁷ kg, વિદ્યુતભાર +2e.
નિરીક્ષણો: (૧) અધિકાંશ કણ સીધા પસાર થયા, (૨) કેટલાક ખૂબ નાના ખૂણે વિચલિત થયા, (૩) ખૂબ જ ઓછા (~1/8000) પાછા ફર્યા.
અનુકૂળ અંતર (Distance of closest approach): r₀ = (1/(4πε₀)) × (2Ze²)/(m v²)
કેન્દ્રાભિમુખી બળ = અલ્ફા કણ પર લાગતું અમ્બેરલિક વિદ્યુતઅપાકર્ષણ બળ
અધિકાંશ કણ સીધા પસાર → તોપરમાણુ મુખ્યત્વે ખાલી જગ્યા ધરાવે છે.
ઓછા કણ વિચલિત → તોધન ભાર એક સરસ્વતીબિંદુએ કેન્દ્રિત છે (નાભિક).
⭐ આ પ્રયોગથી નાભિકની શોધ થઈ. નાભિકમાં સંપૂર્ણ ધનભાર અને અધિકાંશ દળ કેન્દ્રિત છે.
📝 ⚡ NEET ટીપ: પ્રયોગનો મુખ્ય નિષ્કર્ષ 'નાભિકની存在' સાબિત કરે છે.
રેઝર્ડફોર્ડના પરમાણુ મોડેલના સીમાંતો
રેઝર્ડફોર્ડ મોડેલ: ઇલેક્ટ્રોન નાભિકની આસપાસ વર્તુળાકાર કક્ષામાં ફરે છે (સૌર મંડલ જેવું).
સમસ્યા: ગતિમાન ઇલેક્ટ્રોન (ત્વરિત ભાર) નિરंतर અળેક્ટ્રોમેગ્નેટિક તરંગો ઉત્સર્જિત કરે છે.
પરિણામે ઇલેક્ટ્રોન ઊર્જા ગુમાવે → તે spirally નાભિક પર પડે (અસ્થિરતા).
ઉત્સર્જન સપ્રદાય સતત હોત — પણ વાસ્તવમાં સપ્રદાય રેખાઓ વ્યવધાન ધરાવે છે.
⭐ રેઝર્ડફોર્ડ મોડેલ સ્થિર પરમાણુઓનું વિવરણ નથી કરી શકતું. તેની જગ્યાએ બોહરનો મોડેલ લાવ્યો.
📝 ⚡ યાદ રાખો: રેઝર્ડફોર્ડ મોડેલ માત્ર નાભિકની શોધ આપે છે.
બોહરનો પરમાણુ મોડેલ
બોહરના પ્રધાન સિધ્ધાંતો: (૧) સ્થિર કક્ષાઓ, (૨) કોણીય વેગમાનનું ક્વોન્ટમીકરણ, (૩) ઉર્જાનું શોષણ/ઉત્સર્જન.
કોણીય વેગમાનનું ક્વોન્ટમીકરણ: m v r = n h/(2π) = nℏ, જ્યાં n = 1, 2, 3, ...
કક્ષાની ત્રિજ્યા: rₙ = n² h² ε₀ / (π m e² Z) = n² × 0.529 Å / Z (હાઇડ્રોજન માટે)
ઇલેક્ટ્રોનની ઊર્જા: Eₙ = – (m e⁴ Z²) / (8 ε₀² h² n²) = –13.6 Z²/n² eV (હાઇડ્રોજન)
⭐ સૌથી નીચલી કક્ષા (n=1) → મૂળભૂત અવસ્થા (Ground state); ઉચ્ચ n → ઉત્તેજિત અવસ્થા.
n ↑ → તોr ↑ (ત્રિજ્યા વધે), |E| ↓ (બંધન ઊર્જા ઘટે).
📝 ⚡ NEET ટીપ: E₁ = –13.6 eV (હાઇડ્રોજન). E∞ = 0 eV.
હાઇડ્રોજન સપ્રદાય (Hydrogen Spectrum)
બોહર મોડેલ અનુસાર: જ્યારે ઇલેક્ટ્રોન એક કક્ષામાંથી બીજીમાં કૂદે છે ત્યારે ફોટોનનું ઉત્સર્જન/શોષણ થાય છે.
ફોટોન ઊર્જા: ΔE = E₂ – E₁ = hν = hc/λ
રિબર્ગ સૂત્ર: 1/λ = R Z² (1/n₁² – 1/n₂²), જ્યાં R = 1.097 × 10⁷ m⁻¹
લિમેન સપ્રદાય (Lyman): n₁=1, n₂=2,3,... → પરવેટ્રોલ્ટ્રા (UV)
બાલમર સપ્રદાય (Balmer): n₁=2, n₂=3,4,... → દૃશ્યમાન પ્રકાશ
પાશન સપ્રદાય (Paschen): n₁=3, n₂=4,5,... → અવરક્ત (IR)
બ્રાકેટ સપ્રદાય (Brackett): n₁=4, n₂=5,6,... → અવરક્ત (IR)
પફન્ડ સપ્રદાય (Pfund): n₁=5, n₂=6,7,... → અવરક્ત (IR)
⭐ NEET માટે: લિમેન (UV), બાલમર (દૃશ્યમાન), પાશન/બ્રાકેટ/પફન્ડ (IR) — આ યાદ રાખો!
📝 ⚡ યાદ રાખો: n₁ સમૂહ = સપ્રદાયનું નામ; n₂ > n₁ હોવું જોઈએ.
નાભિકનું કદ અને નાભિકીય ઘનતા
નાભિકીય ત્રિજ્યા: R = R₀ A^(1/3), જ્યાં R₀ ≈ 1.2 fm (1 fm = 10⁻¹⁵ m).
નાભિકનું કદ ન્યુક્લિયોન સંખ્યા A પર આધારિત છે.
નાભિકીય ઘનતા: ρ = (3M) / (4π R₀³ A) ≈ 2.3 × 10¹⁷ kg/m³
⭐ નાભિકીય ઘનતા સર્વન્યૂન (nearly constant) — બધા જ નાભિકો માટે લગભગ સમાન!
📝 ⚡ NEET ટીપ: નાભિકીય ઘનતા ~ 10¹⁷ kg/m³ — આ એક મહત્વપૂર્ણ અંક છે.
R ∝ A^(1/3) → તોનાભિકનું કદ A સાથે ધીમે ધીમે વધે છે.
દળ ઘાટ (Mass Defect) અને બંધન ઊર્જા
દળ ઘાટ (Δm): નાભિકનું વાસ્તવિક દળ vs સંયોજિત ન્યુક્લિયોનનું કુલ દળ — વચ્ચેનો તફાવત.
Δm = [Z·m_p + (A–Z)·m_n] – M_nucleus
બંધન ઊર્જા (B.E.): B = Δm × c² = Δm (અમ્બ્રલિક એકમમાં) × 931.5 MeV
બંધન ઊર્જા પ્રતિ ન્યુક્લિયોન (B.E./A): નાભિકની સ્થિરતા માપે છે.
⭐ B.E./A વધુ હોય તો નાભિક વધુ સ્થિર. Fe⁵⁶ નું B.E./A ~ 8.8 MeV (ઉચ્ચતમ).
નાભિકીય સંયોજન (Nuclear fusion) → તોહલકા નાભિકો જોડાઈ ભારે નાભિક બનાવે. B.E./A વધે → ઊર્જા મુક્ત થાય.
નાભિકીય વિખંડન (Fission) → તોભારે નાભિક બે ભાગમાં વહેંચાય. B.E./A વધે → ઊર્જા મુક્ત થાય.
📝 ⚡ NEET ટીપ: 1 u = 931.5 MeV/c² — આ કન્વર્ઝન ફેક્ટર યાદ રાખો.
નાભિકીય બળ (Nuclear Force)
નાભિકીય બળ એ પ્રબળ ન્યુક્લિયર બળ (Strong Nuclear Force) છે.
ગુણધર્મો: (૧) અત્યંત મજબૂત, (૨) અત્યંત ઓછા પરાસ (Range ~ 1-3 fm), (૩) વિદ્યુતભાર-અનિર્પેક્ષ (charge independent).
નાભિકીય બળ વિદ્યુતઅપાકર્ષણ બળ કરતા ~100 ગણું પ્રબળ હોય છે.
⭐ બિન-કેન્દ્રીય (Non-central) અને સંપૃક્ત (Saturable) બળ છે. આના વગર નાભિક અસ્થિર રહે.
📝 ⚡ યાદ રાખો: નાભિકીય બળ ~ 1-3 fm પરાસ ધરાવે છે.
તેજસ્ક્રિયતા (Radioactivity)
તેજસ્ક્રિયતા: અસ્થિર નાભિકો સ્વયંસ્ફૂર્ત રીતે કણો/વિકિરણ ઉત્સર્જિત કરીને સ્થિર બનવાની પ્રક્રિયા.
હિન્કિન્સ (Becquerel) ne 1896માં યાદચ્છિક (spontaneous) વિઘટન શોધ્યું.
ત્રણ પ્રકારના કિરણો: (૧) અલ્ફા α, (૨) બીટા β, (૩) ગામા γ.
⭐ α: He ન્યુક્લિયસ, β: ઇલેક્ટ્રોન/પોઝિટ્રોન, γ: ઉચ્ચ ઊર્જાવાળું વિદ્યુતચુંમકીય વિકિરણ.
📝 ⚡ NEET ટીપ: γ કિરણોનો વેગ = પ્રકાશનો વેગ (c).
α-વિઘટન (Alpha Decay)
ᴬ_Z X → ᴬ⁻⁴_{Z-2} Y + ⁴₂He + Q
α-વિઘટનમાં નાભિકમાંથી 2 પ્રોટોન + 2 ન્યુટ્રોન (He-4 ન્યુક્લિયસ) નીકળે છે.
α કણોનું સંવેદનશીલતા: ઓછી (દળ વધુ, ઇલેક્ટ્રોનિંગ ઓછી).
ઈલેક્ટ્રોનિક વિદ્યુતક્ષેપ: ન્યૂન — હવામાં ~few cm, કાગળના ટુકડાથી અવરોધિત.
Q-મૂલ્ય: Q = [M(X) – M(Y) – M(He)] × c²
α-વિઘટન → તોનાભિકીય સંખ્યા Z માં 2 ઘટે, દળ સંખ્યા A માં 4 ઘટે.
β-વિઘટન (Beta Decay)
β⁻-વિઘટન: ન્યુટ્રોન → પ્રોટોન + ઇલેક્ટ્રોન + એન્ટિન્યુટ્રિનો
ᴬ_Z X → ᴬ_{Z+1} Y + e⁻ + ν̄_e + Q
β⁺-વિઘટન (પોઝિટ્રોન ઉત્સર્જન): પ્રોટોન → ન્યુટ્રોન + પોઝિટ્રોન + ન્યુટ્રિનો
ᴬ_Z X → ᴬ_{Z-1} Y + e⁺ + ν_e + Q
β-કણોનું સંવેદનશીલતા: α કરતાં વધુ, ગામા કરતાં ઓછું.
⭐ β-વિઘટનમાં ન્યુક્લિયોન સંખ્યા A ઊંચે રહે છે; Z માત્ર ±1 બદલાય છે.
📝 ⚡ યાદ રાખો: એન્ટિન્યુટ્રિનો (ν̄_e) અને ન્યુટ્રિનો (ν_e) નું દળ અત્યંત નગણ્ય.
γ-વિઘટન (Gamma Decay)
γ-વિકિરણ: ઉત્તેજિત નાભિક નીચલી ઊર્જા અવસ્થામાં આવે છે અને ફોટોન ઉત્સર્જિત કરે છે.
ᴬ_Z X* → ᴬ_Z X + γ
γ કણોનો વિદ્યુતભાર = 0, તેમનો વેગ = c (પ્રકાશનો વેગ).
ઈલેક્ટ્રોનિક વિદ્યુતક્ષેપ: અત્યંત વધુ — અલ્ફા/બીટા કરતાં ઘણી વધુ ભેદી.
⭐ γ-વિઘટનમાં Z અને A બંને બદલાતા નથી; ફક્ત નાભિકની ઊર્જા ઘટે છે.
📝 ⚡ NEET ટીપ: γ કિરણોને અવરોધવા માટે સીસો (lead) ના સ્તરની જરૂર પડે છે.
તેજસ્ક્રિય વિઘટનનો નિયમ (Law of Radioactive Decay)
વિઘટન દર: પ્રતિ એકમ સમયે વિઘટિત થતા નાભિકોની સંખ્યા વર્તમાન નાભિક સંખ્યાના સમપ્રમાણમાં છે.
dN/dt = –λN → N(t) = N₀ e^(–λt)
λ = વિઘટન અચળાંક (Decay constant); એકમ: s⁻¹
અર્ધ-આયુષ્ય: T½ = ln(2)/λ ≈ 0.693/λ
આયુષ્ય (Mean life): τ = 1/λ = T½ / 0.693 ≈ 1.44 T½
કાર્યકલાપ (Activity): R = λN એકમ: Curie (Ci) અથવા Becquerel (Bq)
1 Ci = 3.7 × 10¹⁰ Bq; 1 Bq = 1 વિઘટન/સેકન્ડ
⭐ T½ એ નમૂનાના પ્રારંભિક જથ્થા પર આધારિત નથી — તે નાભિક પ્રકારનો ગુણધર્મ છે.
📝 ⚡ NEET ટીપ: T½ અને τ બંને નોંધો. τ ≈ 1.44 T½.
નાભિકીય પ્રક્રિયાઓ (Nuclear Reactions)
નાભિકીય પ્રક્રિયામાં નાભિકો પાર્શ્વિત થઈને નવા નાભિકો બનાવે છે.
સંરક્ષણ નિયમો: (૧) ન્યુક્લિયોન સંખ્યા A, (૨) વિદ્યુતભાર Z, (૩) ઊર્જા, (૪) વેગમાન.
Q-મૂલ્ય: Q = [M_reactants – M_products] × c²
Q > 0: ઉષ્મણ પ્રક્રિયા (Exothermic/Exoergic) — ઊર્જા મુક્ત થાય છે.
Q < 0: શીત પ્રક્રિયા (Endothermic/Endoergic) — ઊર્જા શોષાય છે.
⭐ NEET માટે Q-મૂલ્યની ગણતરી મહત્વપૂર્ણ: Δm (u) × 931.5 = Q (MeV).
📝 ⚡ યાદ રાખો: પ્રક્રિયામાં A અને Z બંને સંરક્ષિત રહે છે.
નાભિકીય વિખંડન (Nuclear Fission)
નાભિક વિખંડન: ભારે નાભિક ન્યૂટ્રોન દ્વારા પ્રેરિત થઈ બે મધ્યમ દળના નાભિકોમાં વહેંચાય છે.
¹₀n + ²³⁵U → ¹⁴¹Ba + ⁹²Kr + 3¹₀n + Q (ઉષ્મણ)
વિખંડન દરમિયાન વધુ ન્યુટ્રોન મુક્ત થાય છે → સ્વયંચાલિત શૃંખલા પ્રતિક્રિયા (Chain reaction).
દરેક વિખંડનમાં ~200 MeV ઊર્જા મુક્ત થાય છે.
કritisch દળ: જરૂરી ન્યૂનતમ ન્યુટ્રોન પ્રમાણ જે શૃંખલા પ્રતિક્રિયા જાળવી રાખે.
⭐ પરમાણુ રિએક્ટર: નિયંત્રિત વિખંડન; પરમાણુ બોમ્બ: અનિયંત્રિત શૃંખલા પ્રતિક્રિયા.
📝 ⚡ NEET ટીપ: ¹⁴³U સામાન્ય વિખંડન ઈંધણ છે.
નાભિકીય સંયોજન (Nuclear Fusion)
સંયોજન: હલકા નાભિકો ઊચ્ચ તાપમાને જોડાઈ ભારે નાભિક બનાવે છે.
²₁H + ³₁H → ⁴₂He + ¹₀n + 17.6 MeV
સંયોજન માટે અત્યંત ઊંચું તાપમાન (~10⁷ K) જોઈએ — આથી આ પ્રક્રિયા ઑન્યુકલર (Thermonuclear) છે.
સૂર્ય અને તારાઓમાં હાઈડ્રોજન સંયોજન થાય છે → ઊર્જા ઉત્પન્ન થાય છે.
⭐ વિખંડન કરતાં સંયોજન વધુ ઊર્જા આપે છે — એકમ દળ પ્રતિ યુનિટ ઊર્જા.
📝 ⚡ NEET ટીપ: સંયોજન 'હરિત ઊર્જા' માટેનો ઉત્તમ સ્રોત છે.
સારાંશ: મહત્વના સૂત્રો અને મૂલ્યો
કક્ષા ત્રિજ્યા: rₙ = n² × 0.529 Å / Z
ઊર્જા સ્તર: Eₙ = –13.6 Z²/n² eV
રિબર્ગ: 1/λ = R (1/n₁² – 1/n₂²), R = 1.097 × 10⁷ m⁻¹
નાભિકીય ત્રિજ્યા: R = R₀ A^(1/3), R₀ = 1.2 fm
દળ ઘાટ: Δm = [Zm_p + Nm_n] – M_nuc
બંધન ઊર્જા: B = Δm × 931.5 MeV
વિઘટન: N = N₀ e^(–λt), T½ = 0.693/λ
કાર્યકલાપ: R = λN
