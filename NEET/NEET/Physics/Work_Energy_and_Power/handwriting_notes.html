🩺 NEET UG — Gujarati • Physics • Work, Energy and Power

પાઠ્યક્રમ વિષય: કાર્ય, ઊર્જા અને શક્તિ
જે બળ લાગુ પાડવાથી પદાર્થ સ્થાનાંતરિત થાય છે, તે બળ દ્વારા કરાયેલું 'કાર્ય' થાય છે.
W = F·s = Fs cosθ (જ્યાં θ એ બળ અને સ્થાનાંતર વચ્ચેનો ખૂણો છે)
⚠ કાર્ય એ અદિશ રાશિ છે. તેનું એકમ જૂલ (J) અને પરિમાણ [ML²T⁻²] છે.
📝 📝 વૃત્તીય ગતિમાં કેન્દ્રગામી બળ દ્વારા કાર્ય શૂન્ય હોય છે, કારણ કે θ = 90°, cos90° = 0.
અચળ બળ દ્વારા કરેલું કાર્ય
જ્યારે પદાર્થ પર સ્થિર (અચળ) બળ F લાગુ પડે અને પદાર્થ s દૂર સ્થાનાંતરિત થાય, ત્યારે:
W = F → · s → = F_x·s_x + F_y·s_y + F_z·s_z
જો θ < 90° હોય → કાર્ય ધન (ધન છે) — બળ ગતિની દિશામાં સહાયક છે.
જો θ > 90° હોય → કાર્ય ઋણ (ઋણ છે) — બળ ગતિનો વિરોધ કરે છે.
જો θ = 90° હોય → કાર્ય શૂન્ય છે.
વિશિષ્ટ કિસ્સા: ગુરુત્વાકર્ષણ બળ દ્વારા ઉપર ચઢતા પદાર્થ પર ઋણ કાર્ય અને નીચે ઉતરતા પદાર્થ પર ધન કાર્ય થાય છે.
📝 📝 શૂન્ય કાર્યની બે સ્થિતિઓ: (i) સ્થાનાંતર શૂન્ય (ii) બળ અને સ્થાનાંતર પરસ્પર લંબરૂપ.
ચલ બળ દ્વારા કરેલું કાર્ય
જ્યારે બળ F = F(x) સ્થાન સાથે બદલાતું હોય, ત્યારે સ્થાનાંતર dx માટે: dW = F(x)·dx
W = ∫(x₁ to x₂) F(x) dx
F-x ક્રાફ (બળ-સ્થાન ગ્રાફ) ની નીચેનું ક્ષેત્રફળ = કરેલું કાર્ય.
⚠ સ્પ્રિંગ બળ માટે: F = -kx → સ્પ્રિંગ દ્વારા કરેલું કાર્ય W = ½k(x₁² - x₂²)
📝 📝 સ્પ્રિંગને k₁ અને k₂ લંબાઈના સંયોજન કરવા પર પરિણામી સ્પ્રિંગ અચળાંક: 1/k = 1/k₁ + 1/k₂ (શ્રેણીબદ્ધ).
ઘર્ષણ બળ દ્વારા કરેલું કાર્ય
ઘર્ષણ બળ હંમેશા ગતિની વિરુદ્ધ દિશામાં હોય છે → તે હંમેશા ઋણ કાર્ય કરે છે.
W_friction = -μ_k · m g · s (ગતિજ ઘર્ષણ માટે)
ઘર્ષણ બળ ચાલુ રહે ત્યાં સુધી યાંત્રિક ઊર્જા ઘટે છે અને ઉષ્મામાં પરિવર્તિત થાય છે.
⚠ સ્થિતિજ ઘર્ષણ (Static friction) સ્થાનાંતર કરાવતી નથી, તેથી તે દ્વારા કરેલું કાર્ય શૂન્ય છે.
ગતિ ઊર્જા (Kinetic Energy)
ગતિશીલ પદાર્થ પાસે ગતિ ઊર્જા હોય છે. તે પદાર્થની ગતિજ અવસ્થા પર આધારિત છે.
K.E. = ½mv² (v = વેગ, m = દળ)
K.E. = p² / (2m) (જ્યાં p = સંવેગ = mv)
ગતિ ઊર્જા અને સંવેગ વચ્ચેનો સંબંધ: જો સંવેગ દ્વિગુણિત થાય → K.E. ચાર ગણી થાય.
પદાર્થનો વેગ દ્વિગુણિત કરવા માટે જરૂરી કાર્ય = ½m(2v)² - ½mv² = ¾mv² = 3K.E.
📝 📝 K.E. અને સંવેગ — બંને ગતિજ ઊર્જાની માહિતી આપે છે, પણ સંવેગ સદિશ છે, K.E. અદિશ છે.
ઊર્જા-કાર્ય પ્રમેય (Work-Energy Theorem)
⚡ બધા જ બળો (અંતર્ગત + બાહ્ય) દ્વારા કરાયેલું કુલ કાર્ય = ગતિ ઊર્જામાં ફેરફાર.
W_total = ΔK.E. = ½mv_f² - ½mv_i² = K_f - K_i
જો કુલ કાર્ય ધન હોય → ગતિ ઊર્જા વધે છે (વેગ વધે છે).
જો કુલ કાર્ય ઋણ હોય → ગતિ ઊર્જા ઘટે છે (વેગ ઘટે છે).
આ પ્રમેય સ્થિર અને ગતિશીલ બંને સંદર્ભ ફ્રેમમાં લાગુ પડે છે, પણ v હંમેશા ભૌતિક સંદર્ભ ફ્રેમ સાપેક્ષ હોવો જોઈએ.
📝 📝 NEET માં બહુ આવે છે: એક પદાર્થનું વેગ દ્વિગુણિત કરવા જરૂરી કાર્ય શોધો. (ઉત્તર: 3K.E.)
સ્થિતિ ઊર્જા (Potential Energy)
સ્થિતિ ઊર્જા એ પદાર્થની સ્થિતિ અથવા ગોઠવણી (configuration) પર આધારિત ઊર્જા છે.
U = mgh (ગુરુત્વીય સ્થિતિ ઊર્જા, જ્યાં h = ઊંચાઈ)
U_spring = ½kx² (સ્પ્રિંગ સ્થિતિ ઊર્જા, x = વિસ્થાપન)
સ્થિતિ ઊર્જામાં ફેરફાર: ΔU = -W_cons (જ્યાં W_cons = સંરક્ષક બળ દ્વારા કરેલું કાર્ય)
⚡ સ્થિતિ ઊર્જા માત્ર સંરક્ષક બળો (conservative forces) માટે વ્યાખ્યાયિત થઈ શકે છે.
📝 📝 સ્થિતિ ઊર્જાનું મૂલ્ય સંદર્ભ બિંદુ (reference point) પર આધારિત છે — સામાન્ય રીતે z = 0 પર U = 0 લેવામાં આવે છે.
સંરક્ષક અને અસંરક્ષક બળો
સંરક્ષક બળ (Conservative force): જે બળનું કાર્ય માર્ગ પર આધારિત ન હોય, ફક્ત પ્રારંભિક અને અંતિમ સ્થાન પર આધારિત હોય.
સંરક્ષક બળ: ગુરુત્વાકર્ષણ, સ્પ્રિંગ બળ (Hooke's law), સ્થિર વિદ્યુત બળ.
અસંરક્ષક બળ (Non-conservative force): જે બળનું કાર્ય માર્ગ પર આધારિત હોય.
અસંરક્ષક બળ: ઘર્ષણ બળ, હવા પ્રતિકાર, પ્રવાહી સંસિદ્ધિ બળ.
⚡ સંરક્ષક બળ દ્વારા વર્તુળાકાર માર્ગ પર કરેલું કાર્ય હંમેશા શૂન્ય છે: ∮F·ds = 0.
F_cons = -dU/dx (બળ = સ્થિતિ ઊર્જાનો ઋણ વ્યુત્પન્ન)
📝 📝 ઘર્ષણ બળ અસંરક્ષક છે કારણ કે તે હંમેશા ગતિની વિરુદ્ધ દિશામાં કાર્ય કરે છે, માળખાકીય દિશા માર્ગ પર નિર્ભર કરે છે.
યાંત્રિક ઊર્જા સંરક્ષણનો નિયમ
⚡ જો પદાર્થ પર ફક્ત સંરક્ષક બળોનું કાર્ય થતું હોય, તો કુલ યાંત્રિક ઊર્જા (K.E. + P.E.) અચળ રહે છે.
K.E._i + P.E._i = K.E._f + P.E._f => ½mv_i² + mgh_i = ½mv_f² + mgh_f
આ નિયમ માત્ર ત્યારે લાગુ પડે છે જ્યારે અસંરક્ષક બળો (ઘર્ષણ, હવા) અવગણ્ય હોય.
મુક્ત પતન: ઊંચાઈ ઘટતી જાય ત્યારે P.E. ઘટે અને K.E. વધે — કુલ યાંત્રિક ઊર્જા અચળ રહે.
ઉર્ધ્વગામી ગોળો: શિરોબિંદુ પર K.E. = 0, P.E. = mgh_max; પ્રારંભિક બિંદુ પર P.E. = 0, K.E. = ½mv₀².
📝 📝 મુક્ત પતનમાં ½mv² + mgh = constant — આ સમીકરણ NEET માં ખૂબ જરૂરી છે.
સુસ્થિર અને અસ્થિર સંતુલન
U-X ગ્રાફ પર સંતુલન બિંદુઓ જ્યાં dU/dx = 0 (બળ શૂન્ય).
સુસ્થિર સંતુલન: d²U/dx² > 0 (સ્થિતિ ઊર્જાનું ન્યૂનતમ બિંદુ). થોડું સ્થાનાંતર કરતાં પદાર્થ પાછો આવે છે.
અસ્થિર સંતુલન: d²U/dx² < 0 (સ્થિતિ ઊર્જાનું મહત્તમ બિંદુ). થોડું સ્થાનાંતર કરતાં પદાર્થ દૂર જાય છે.
dU/dx = 0બળ F = 0 → સંતુલન બિંદુ
d²U/dx² > 0સુસ્થિર સંતુલન
d²U/dx² < 0અસ્થિર સંતુલન
સંતુલન અને કણની ગતિ (Potential Energy Curve)
જો કુલ ઊર્જા E = K + U હોય, તો ગતિ તે વિસ્તારમાં શક્ય છે જ્યાં K ≥ 0 એટલે E ≥ U.
બંધ ગતિ (Bound motion): કણ સીમાબંધિત વિસ્તારમાં કંપન કરે છે જો E < 0 અને બે પરિવર્તન બિંદુઓ વચ્ચે ધકેલાય છે.
વિમુક્ત ગતિ (Unbound motion): જો E ≥ 0 હોય તો કણ અનંત સુધી દૂર જઈ શકે છે.
⚡ પરિવર્તન બિંદુએ (Turning point): K = 0, E = U, v = 0.
વિદ્યુત સ્થિતિ ઊર્જા (Electrostatic Potential Energy)
U = kQq/r (બે બિંદુ વિદ્યુતભાર વચ્ચેની સ્થિતિ ઊર્જા)
સમાન ચિહ્નના વિદ્યુતભારો વચ્ચે U ધન, વિરુદ્ધ ચિહ્નના વિદ્યુતભારો વચ્ચે U ઋણ.
વિદ્યુતભારને r₁ થી r₂ સુધી લઇ જવા માટેનું કાર્ય: W = kQq(1/r₂ - 1/r₁) — આ સંરક્ષક બળ છે.
📝 📝 વિદ્યુત સ્થિતિ ઊર્જાનું સૂત્ર ગુરુત્વીય સ્થિતિ ઊર્જા jaiso જ છે, પણ r⁻¹ પર આધારિત છે, h નહીં.
શક્તિ (Power)
શક્તિ એ કાર્ય કરવાની દર છે — એકમ સમયમાં થતું કાર્ય.
P_avg = W / t (સરેરાશ શક્તિ)
P_instantaneous = dW/dt = F·v (તાત્કાલિક શક્તિ)
એકમ: વોટ (Watt) = J/s. પરિમાણ: [ML²T⁻³].
⚡ 1 kWp (ઘોડાની શક્તિ) = 746 W (લગભગ).
📝 📝 P = F·v → જો F અચળ હોય અને v વધે, તો P વધે. ઉતરતી ગતિમાં P = F·v sinθ પણ યાદ રાખો.
શક્તિ અને ઊર્જાનો સંબંધ
P = dE/dt (શક્તિ = ઊર્જા પરિવર્તન દર)
P = F·v (જ્યારે બળ અને વેગ સમદિશીય હોય)
સ્થિર વેગથી ઉંચકતાં, જરૂરી શક્તિ: P = mgv.
ન્યૂનતમ શક્તિ જરૂરી હોય ત્યારે વેગ અચળ રાખવો જોઈએ (ત્વરિત ઊર્જા વ્યય ટાળવા).
ઘર્ષણને કારણે ઊર્જા વ્યય
ઘર્ષણને કારણે યાંત્રિક ઊર્જા ઘટે છે અને તે ઉષ્મામાં પરિવર્તિત થાય છે.
ΔE_mech = W_friction = -f_k · d = -μ_k m g d
ઘર્ષણ વડે થતાં ઉષ્મા ઉત્પાદનની દર: P = f_k · v.
⚡ ઘર્ષણને કારણે યાંત્રિક ઊર્જાનું સંરક્ષણ થતું નથી — આ અસંરક્ષક બળ છે.
મુક્ત પતનનો અભ્યાસ
ઉંચાઈ h પરથી મુક્ત પતન કરતા પદાર્થ માટે:
v = √(2gh) (મिट्टિ પર પહોંચેલો વેગ)
હાઈટ h/2 પર: v = √(gh), K.E. = ½mgh, P.E. = ½mgh — બંને સમાન.
શિરોબિંદુ પરP.E. = mgh, K.E. = 0
પૃષ્ઠ પરP.E. = 0, K.E. = mgh
h/2 પરP.E. = K.E. = ½mgh
લંબ સમતલ પર ગલન (Frictionless Inclined Plane)
લંબ સમતલ (ઢાળ α) પરથી નીચે આવતા પદાર્થ માટે:
v = √(2gh) = √(2gLsinα) (નીચે ઉતરેલો દૂર L હોય તો)
ઘર્ષણ હોય તો: v = √[2gL(sinα - μcosα)].
📝 📝 NEET માં ઝાઝીવાર ઢાળ પર પદાર્થની ગતિનું વિશ્લેષણ આવે છે — યાંત્રિક ઊર્જા સંરક્ષણ વાપરો.
લંબ વર્તુળાકાર પથ (Vertical Circle)
l ના દોરીથી બાંધેલો દળ m નો પદાર્થ ઊભો વર્તુળ કરે છે.
નેમચિંદ્રે ન્યૂનતમ વેગ: v_min = √(gl) (દોરી ઢીલી પડતી ન હોય તે માટે)
નીચેનું બિંદુ (Lowest point): T_bottom = mg + mv²/l.
ઉપરનું બિંદુ (Highest point): T_top = mv²/l - mg (v ≥ √(gl) હોવું જોઈએ).
v_bottom(min) = √(5gl) (પૂર્ણ વર્તુળ બનાવવા માટે જરૂરી ન્યૂનતમ વેગ)
⚡ NEET માં સૌથી વધુ આવતો વિષય: ઊભો વર્તુળ (Vertical circle) — v_min = √(5gl) યાદ રાખો.
📝 📝 ઉપરના બિંદુએ દોરીમાં તણાવ શૂન્ય થાય ત્યારે T = 0 → mg = mv²/l → v = √(gl).
સ્થિતિ ઊર્જા અને બળ વચ્ચેનો સંબંધ (Force from Potential Energy)
F_x = -dU/dx (બળ = સ્થિતિ ઊર્જાનો ઋણ વ્યુત્પન્ન)
3D માં: F_x = -∂U/∂x, F_y = -∂U/∂y, F_z = -∂U/∂z.
U(r) = kQq/r હોય તો F = -dU/dr = kQq/r² (સ્થિત વિદ્યુત બળ).
⚡ U-X વક્રના ઢાળ (slope) = -F → જે બિંદુએ slope શૂન્ય હોય તે સંતુલન બિંદુ છે.
પ્રારંભિક ગતિ સમીકરણો અને ઊર્જા સંરક્ષણ
સમીકરણ v² = u² + 2as ને બદલે ઊર્જા સંરક્ષણનો ઉપયોગ સરળતાથી કરી શકાય.
ઘર્ષણ વિનાની સમસ્યાઓમાં ઊર્જા સંરક્ષણનો ઉપયોગ કરવો વધુ ઝડપી અને સીધો છે.
½mv² - ½mu² = Fs (સંવેગ-ઊર્જા સંબંધ, F અચળ હોય તો)
કુલ ઊર્જા સંરક્ષણ (સંરક્ષક + અસંરક્ષક બળો)
W_non-conservative = ΔK.E. + ΔP.E. = ΔE_mech
જો અસંરક્ષક બળ (ઘર્ષણ) હોય તો: K_i + U_i + W_nc = K_f + U_f.
⚡ ઘર્ષણ હોય ત્યારે: ½mv_i² + mgh_i - μmgcosα·d = ½mv_f² + mgh_f — આ સૂત્ર યાદ રાખો.
📝 📝 અસંરક્ષક બળ દ્વારા થતું કાર્ય યાંત્રિક ઊર્જામાં ઘટાડો કરે છે.
NEET માટે મહત્વના પ્રયોગો અને અવલોકનો
માર્ક-ઊર્જા ચોકછાપ (Mark-energy balance): K_i + U_i + W_external = K_f + U_f.
ગતિ ઊર્જા-ઝડપ વક્ર: K vs v² રેખીય છે (સુરેખ ગ્રાફ).
ઊર્જા સંરક્ષણનો ઉપયોગ ઝડપી ઉકેલ માટે થાય છે, કારણ કે તે માર્ગની ચિંતા કરતો નથી.
મહત્વપૂર્ણ સૂત્રોનો સંગ્રહ (Formula Summary)
W = Fs cosθ | K.E. = ½mv² | P.E. = mgh
W_total = ΔK | P = F·v | U_spring = ½kx²
E_mech = K + U = constant (conservative only)
F = -dU/dx | v_vertical_circle = √(5gl)
⚡ NEET માટે સૌથી મહત્વપૂર્ણ: ઊર્જા સંરક્ષણનો નિયમ, વર્ક-એનર્જી પ્રમેય, અને ઊભા વર્તુળ (v = √(5gl)).
