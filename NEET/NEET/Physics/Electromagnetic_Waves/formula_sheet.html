ઇલેક્ટ્રોમેગ્નેટિક તરંગો — સૂત્ર પુસ્તિકા

🩺 NEET UG — Gujarati • Physics • Electromagnetic Waves

⚡ સૂત્રો

વિસ્થાપન પ્રવાહ (Displacement Current): I_d = ε₀ · (dΦ_E / dt)
ε₀ = મુક્ત અવકાશનું પરમિટિવિટી, Φ_E = વિદ્યુત ક્ષેત્ર ફ્લક્સ, t = સમય · SI: એમ્પીયર (A) · જ્યારે વિદ્યુત ક્ષેત્ર સમય સાથે બદલાતું હોય
મેક્સવેલ-આંડરસન સમીકરણ (સંયુક્ત): ∮ B·dl = μ₀ I + μ₀ ε₀ (dΦ_E / dt)
μ₀ = મુક્ત અવકાશનું પારગમ્યતા, I = વાહક પ્રવાહ, dΦ_E/dt = ફ્લક્સ નિર્દેશ · SI: — · જ્યારે વિદ્યુત અને ચુંબકીય ક્ષેત્રો બંને સમય સાથે બદલાતા હોય (મેક્સવેલનું સંશોધિત આંપીયર નિયમ)
ઇલેક્ટ્રોમેગ્નેટિક તરંગની ચુંબકીય ક્ષેત્ર અને વિદ્યુત ક્ષેત્રનો ગુણોત્તર: E / B = c
E = વિદ્યુત ક્ષેત્ર તીવ્રતા, B = ચુંબકીય ક્ષેત્ર તીવ્રતા, c = પ્રકાશની ગતિ · SI: m/s · મુક્ત અવકાશમાં અનંત દૂર જતાં સમતલ તરંગ માટે
તરંગની ગતિ (મેક્સવેલ સૂત્ર): c = 1 / √(μ₀ ε₀)
μ₀ = 4π × 10⁻⁷ H/m, ε₀ = 8.854 × 10⁻¹² F/m · SI: m/s · મુક્ત અવકાશમાં ઇલેક્ટ્રોમેગ્નેટિક તરંગો માટે
વિદ્યુત ક્ષેત્ર ઊર્જા ઘનત્વ: u_E = (1/2) ε₀ E²
ε₀ = પરમિટિવિટી, E = વિદ્યુત ક્ષેત્ર તીવ્રતા · SI: J/m³ · કોઈપણ બિંદુએ વિદ્યુત ક્ષેત્ર હોય ત્યારે
ચુંબકીય ક્ષેત્ર ઊર્જા ઘનત્વ: u_B = B² / (2 μ₀)
μ₀ = પારગમ્યતા, B = ચુંબકીય ક્ષેત્ર · SI: J/m³ · કોઈપણ બિંદુએ ચુંબકીય ક્ષેત્ર હોય ત્યારે
કુલ ઊર્જા ઘનત્વ: u = u_E + u_B = ε₀ E² = B² / μ₀
E અને B એકબીજા સાથે સંબંધિત છે (E = cB) · SI: J/m³ · મુક્ત અવકાશમાં સમતલ ઇલેક્ટ્રોમેગ્નેટિક તરંગ માટે
પોઈન્ટિંગ વેક્ટર (S): S = (1/μ₀) E × B
E = વિદ્યુત ક્ષેત્ર, B = ચુંબકીય ક્ષેત્ર, μ₀ = મુક્ત અવકાશ પારગમ્યતા · SI: W/m² · તરંગ દિશામાં ઊર્જા પ્રવાહ ઘનત્વ માટે
સરેરાશ પોઈન્ટિંગ વેક્ટર (સમતલ તરંગ): S_avg = (E₀ B₀) / (2 μ₀) = (1/2) c ε₀ E₀²
E₀ = વિદ્યુત ક્ષેત્રનો પરામિટર (Amplitude), B₀ = ચુંબકીય ક્ષેત્રનો પરામિટર · SI: W/m² · સાઇનુસોઇડલ સમતલ તરંગ માટે, સમય સાથે સરેરાશ
તરંગ સમીકરણ (સમતલ તરંગ): E(x,t) = E₀ sin(kx − ωt), B(x,t) = B₀ sin(kx − ωt)
k = તરંગ સંખ્યા (2π/λ), ω = કોણીય આવર્તન (2πf), λ = તરંગલંબાઈ · SI: E: V/m, B: T · ધન x-દિશામાં જતાં સમતલ ઇલેક્ટ્રોમેગ્નેટિક તરંગ માટે
ઇલેક્ટ્રોમેગ્નેટિક તરંગ માટે કક્ષક સંબંધ: c = f λ, k = 2π/λ, ω = 2πf
f = આવર્તન, λ = તરંગલંબાઈ, k = તરંગ સંખ્યા, ω = કોણીય આવર્તન · SI: f: Hz, λ: m, k: rad/m, ω: rad/s · મુક્ત અવકાશમાં તરંગ માટે
તરંગ દ્વારા લગાડાતું દબાણ (પૂર્ણ શોષણ): P = I / c
I = તરંગનો પ્રાપ્ત થતો તીવ્રતા (સરેરાશ પોઈન્ટિંગ), c = પ્રકાશની ગતિ · SI: N/m² (Pa) · જ્યારે તરંગ સપાટી દ્વારા પૂર્ણપણે શોષાય
તરંગ દ્વારા લગાડાતું દબાણ (પૂર્ણ પરાવર્તન): P = 2I / c
I = તીવ્રતા, c = પ્રકાશની ગતિ · SI: N/m² (Pa) · જ્યારે તરંગ સપાટી પરથી પૂર્ણપણે પરાવર્તિત થાય
ઇલેક્ટ્રોમેગ્નેટિક સ્પેક્ટ્રમ — ક્રમ (હ્રસ્વતમ → દીર્ઘતમ તરંગલંબાઈ): γ < X < UV < દૃશ્ય < IR < માઇક્રોવેવ < રેડિયો
γ = ગામા કિરણ, X = એક્સ-રે, UV = અલ્ટ્રાવાયલેટ, દૃશ્ય = દૃશ્યમાન પ્રકાશ, IR = ઇન્ફ્રારેડ, માઇક્રોવેવ = માઇક્રોવેવ, રેડિયો = રેડિયો તરંગ · SI: — · આવર્તન ઘટતા ક્રમ મુજબ; કમ્પાઉન્ડ ક્રમમાં વધતા
તરંગની દિશા (E, B, S સંબંધ): S = (1/μ₀) E × B → તરંગ દિશા E અને B ના મૂલ્યના સમાંતર છે
E ⊥ B ⊥ તરંગ પ્રસરણ દિશા · SI: — · ઇલેક્ટ્રોમેગ્નેટિક તરંગમાં વિદ્યુત અને ચુંબકીય ક્ષેત્રો પરસ્પર લંબ અને તરંગ દિશાને પણ લંબ હોય છે

🔗 સંબંધો

  • E / B = c → વિદ્યુત અને ચુંબકીય ક્ષેત્રોનું મૂલ્ય સમપ્રમાણમાં રહે છે; E વધે તો B પણ સમપ્રમાણમાં વધે છે.
  • u_E = u_B → ઇલેક્ટ્રોમેગ્નેટિક તરંગમાં વિદ્યુત અને ચુંબકીય ઊર્જા ઘનત્વ સમાન હોય છે.
  • c = 1/√(μ₀ε₀) → મુક્ત અવકાશમાં પ્રકાશની ગતિ એ μ₀ અને ε₀ પર આધારિત છે, જે તરંગના વિદ્યુતચુંબકીય પ્રકૃતિ સાબિત કરે છે.
  • I_d અને I (વાહક પ્રવાહ) નો સરવાળો સતત રહે છે → કન્ડેન્સરમાં I_d, વાહકમાં I → બંનેનો સરવાળો સમાન.
  • S (પોઈન્ટિંગ વેક્ટર) ની દિશા તરંગ પ્રસરણ દિશામાં હોય છે અને E અને B બંનેને લંબ હોય છે.

🎯 ટ્રિક્સ

ઈલેક્ટ્રોમેગ્નેટિક સ્પેક્ટ્રમનું ORTVIM એક્રોનિમ: γ (ગામા), X (એક્સ-રે), UV (અલ્ટ્રાવાયલેટ), દૃશ્ય, IR (ઇન્ફ્રારેડ), માઇક્રોવેવ, રેડિયો — આવર્તન ઘટતો ક્રમ.

⚠️ ભૂલો

વિસ્થાપન પ્રવાહ (I_d) ને વાહક પ્રવાહ (I) સમાન માનવો; વાસ્તવમાં I_d એ ફક્ત બદલાતા વિદ્યુત ક્ષેત્રથી ઉત્પન્ન થાય છે.
જવાબમાં E અને B ના ગુણોત્તરમાં c ની ખોટી દિશા રાખવી; સાચો સંબંધ E = cB છે.
ઈલેક્ટ્રોમેગ્નેટિક તરંગમાં E અને B એકબીજાને સમાંતર હોવાનું ધારવું; સાચું તેઓ પરસ્પર લંબ હોય છે.
પોઈન્ટિંગ વેક્ટરમાં μ₀ ને અવગણીને S = E·B લખવું; સાચું સૂત્ર S = (E×B)/μ₀ છે.
ઊર્જા ઘનત્વના સૂત્રમાં u = ε₀E² અને u = B²/μ₀ નો અર્ધો ગુણાંક (1/2) ભૂલી જવો.
