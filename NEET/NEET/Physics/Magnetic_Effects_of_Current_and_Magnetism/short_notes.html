ધારા અને ચુંબકત્વના ચુંબકીય અસરો — ઝડપી પુનરાવર્તન

🩺 NEET UG — Gujarati • Physics • Magnetic Effects of Current and Magnetism

📘 વ્યાખ્યાઓ

  • ચુંબકીય ક્ષેત્ર (Magnetic Field): એવો પ્રદેશ જ્યાં ચુંબક અથવા પ્રવાહવાહી તાર પર ચુંબકીય બળ લાગે છે.
  • ચુંબકીય ક્ષેત્રગામિતા (Magnetic Field Strength B): એકમ ધન પ્રવાહ-લંબાઈ પર લાગતું ચુંબકીય બળ.
  • ચુંબકીય ફ્લક્સ (Magnetic Flux Φ): B અને ક્ષેત્રફળ A નો અદિશ ગુણાકાર, Φ = B·A.
  • ચુંબકીય ડોમેન (Magnetic Domain): સૂક્ષ્મ અંતર્ગત ક્ષેત્રો જ્યાં પરમાણ્વિક ચુંબકીય મોમેન્ટ સમાંતર ગોઠવાય છે.
  • લોન્ગિટ્યુડિનલ ફીલ્ડ (Longitudinal Field): ચુંબકીય ક્ષેત્ર સાથે સમાંતર રીતે લગાડેલ ઇલેક્ટ્રિક ક્ષેત્ર.
  • ટ्राન્સવર્સ ફીલ્ડ (Transverse Field): કણના વેગને લંબરૂપે લગાડેલ ચુંબકીય ક્ષેત્ર.

⚡ સૂત્રો

  • બાયોત-સાવર્ટનો નિયમ: dB = (μ₀/4π) · (I dl sinθ)/r²
  • અનંત સીધી વાહિકા માટે: B = μ₀I/(2πr)
  • વર્તુળાકાર કોઇલ કેન્દ્રે: B = μ₀NI/(2R)
  • ટોઇડ (Toroid) માટે: B = μ₀nI, બહાર B = 0
  • સોલેનોઇડ માટે: B = μ₀nI (અંદર), બહાર B ≈ 0
  • પરાવર્તિત વાહિકા વચ્ચે બળ: F/l = μ₀I₁I₂/(2πd)
  • ચુંબકીય બળ: F = qvB sinθ (ઇલેક્ટ્રિક ક્ષેત્ર વિના)
  • સંયુક્ત બળ (લોરેન્ઝ): F = q(E + v×B)
  • વર્તુળાકાર માર્ગની ત્રિજ્યા: r = mv/(qB)
  • કોણીય આવૃત્તિ: ω = qB/m; આવર્તકાળ: T = 2πm/(qB)
  • ટોર્ક (વહનકોઇલ): τ = NIAB sinθ; મોમેન્ટ pₘ = NIA
  • ગોલ્ડસ્ટીન-બેકેટ સમીકરણ: B/δ = constant

⭐ મુખ્ય તથ્યો

  • μ₀ = 4π × 10⁻⁷ T·m/A (વાક્યુઝમની પારગમ્યતા).
  • સમાન ચુંબકીય ક્ષેત્રમાં આયન પર થતું બળ વેગની દિશા પર આધારિત છે.
  • ચુંબકીય બળ હંમેશા ગતિને લંબરૂપ હોય છે; તે કોઈ કાર્ય કરતું નથી.
  • આયન જ્યારે B ની દિશામાં ગતિ કરે છે ત્યારે F = 0.
  • વર્તુળાકાર ગતિમાં કેન્દ્રગામી બળ ચુંબકીય બળ પૂરું પાડે છે.
  • ચાર્જિત કણની ત્રિજ્યા आवર્તકાળ ઊર્જા પર આધારિત નથી.
  • વહનકોઇલનું ચુંબકીય દ્વિધ્રુવ મોમેન્ટ pₘ = NIA.
  • વહનકોઇલ સ્થિર અવસ્થામાં τ = pₘ × B મુજબ ટોર્ક અનુભવે છે.
  • બે સમાંતર વાહિકાઓમાં સમાન દિશાએ પ્રવાહ → આકર્ષણ; વિરુદ્ધ દિશાએ → અપાકર્ષણ.
  • સોલેનોઇડની અંદરનું ક્ષેત્ર સમાન હોય છે; બહાર લગભગ શૂન્ય.
  • ટોઇડની અંદર B સુસ્થિર, બહાર શૂન્ય હોય છે.
  • માઇક્રોસ્કોપિક સ્તરે, પરમાણ્વિક કક્ષકીય અને સ્પિન મોમેન્ટ જ ચુંબકત્વનું મૂળ છે.
  • ડાયમેગનેટિક પદાર્થો B ને વિરુદ્ધ દિશામાં નિર્બળ પ્રતિભાવ આપે છે.
  • પેરામેગનેટિક પદાર્થો B ની દિશામાં નિર્બળ આકર્ષાય છે.
  • ફેરોમેગનેટિક પદાર્થો બળવંત્તાથી B ની દિશામાં ચુંબકાય છે.

⚠️ સામાન્ય ભૂલો

  • ચુંબકીય બળ ગતિની દિશા સાથે કોણીય આધારિત છે; સદાય બળ F = qvB ન લેવું.
  • કણ B ની દિશામાં ગતિ કરતો હોય તો પણ F = qvB એ લાગુ નથી – F = 0 થાય છે.
  • ચુંબકીય બળ દ્વારા કરેલું કાર્ય શૂન્ય છે; તે ગતિજ ઊર્જા બદલતું નથી.
  • પ્રવાહવાહી તાર પર B સંપૂર્ણપણે ન હોય તો τ ≠ NIAB લેવું.
  • ચુંબકીય ક્ષેત્ર R ની દિશા ચેતવણીપૂર્વક નક્કી કરવી; તે ધન આવેગ પરના બળ પર આધારિત છે.
  • ટોર્કના સૂત્રમાં θ એ ક્ષેત્ર અને સોલેનોઇડના અક્ષ વચ્ચેનો ખૂણો છે.
  • આવર્તકાળ T = 2πm/(qB) માં ઊર્જા દેખાતી નથી – તે ઊર્જા પર આધારિત નથી.
  • μ₀ ની કિંમત 4π × 10⁻⁷ છે; π ને 22/7 તરીકે લઈ ગણતરી ભૂલશક્ય બને છે.
  • સોલેનોઇડની અંદર B = μ₀nI છે; n એ પ્રતિ એકમ લંબાઈના વલયો છે, કુલ વલયો નહીં.
  • ટોઇડમાં B = μ₀nI; n એ પ્રતિ એકમ લંબાઈના વલયો છે.
  • ચાર્જિત કણ B ની દિશામાં ગતિ કરતો હોય તો F = qvB sin90° = qvB લખવું ભૂલ છે.
  • લોરેન્ઝ બળ F = q(E + v×B) માં E અને B બંને હોઈ શકે છે; બંનેની અસર ઉમેરવી પડે છે.
  • ચુંબકીય ક્ષેત્રમાં આયનની ગતિ સુરેખ પણ થઈ શકે છે જો v ∥ B હોય.
  • કણ B ની દિશામાં ગતિ કરતો હોય તો F = 0; પણ ક્ષેત્રમાં આયન ગતિ કરી શકે છે.
  • ચુંબકીય ક્ષેત્રની દિશા નક્કી કરતી વખતે ડાબા હાથના નિયમનો ઉપયોગ કરવો ન જોઈએ; જમણા હાથનો નિયમ યોગ્ય છે.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • બાયોત-સાવર્ટનો નિયમ પ્રવાહી વહનકોઇલ માટે ચુંબકીય ક્ષેત્રની ગણતરી કરવા માટે આવશ્યક છે.
  • અનંત સીધી વાહિકાનું ક્ષેત્ર B = μ₀I/(2πr) NEET માં વારંવાર આવે છે.
  • ટોઇડ અને સોલેનોઇડના ક્ષેત્રનું વિભેદન સ્પષ્ટ રાખવું: ટોઇડ B = μ₀nI; સોલેનોઇડ B = μ₀nI.
  • વહનકોઇલ પર ટોર્ક τ = NIAB sinθ અને મોમેન્ટ pₘ = NIA યાદ રાખવા મહત્વપૂર્ણ છે.
  • ચાર્જિત કણનું વર્તુળાકાર માર્ગ r = mv/(qB) અને આવર્તકાળ T = 2πm/(qB) નિયમિત પુનરાવર્તન ધરાવે છે.
  • સંયુક્ત ક્ષેત્ર (E અને B) માં કણની ગતિનો વિશ્લેષણ ઘણીવાર પ્રશ્નબાહ્ય આવે છે.
  • બે સમાંતર વાહિકાઓ વચ્ચેનું બળ આકર્ષણ અથવા અપાકર્ષણ પરિક્ષણ તરીકે વારંવાર આવે છે.
  • B ની દિશા નક્કી કરવા માટે જમણા હાથનો નિયમ અને ચુંબકીય ક્ષેત્રરેખાઓની ગોઠવણી સ્પષ્ટ રાખવી.
  • કણની ઊર્જા બદલાય છે તો પણ આવર્તકાળ અચળ રહે છે; તેની સમજ NEET માટે મહત્વપૂર્ણ છે.
  • ચુંબકીય ડોમેનનું સ્તરે ચુંબકત્વનું મૂળ સમજવું ફેરોમેગનેટિક પદાર્થોની સમજૂતી માટે જરૂરી છે.
  • ડાયમેગનેટિક અને પેરામેગનેટિક પદાર્થોની ચુંબકીય પ્રતિભાવની તુલના સ્પષ્ટ રાખવી.
  • ચુંબકીય ક્ષેત્ર B ની દિશા અને કણના v ની દિશા વચ્ચેનો ખૂણો θ જ F ની માત્રા નક્કી કરે છે.
  • F = qvB sinθ માં sinθ નો ઉપયોગ કરવો; θ = 0 હોય તો F = 0; θ = 90° હોય તો F = qvB.
  • ટોર્ક τ = NIAB sinθ માં θ એ ચુંબકીય ક્ષેત્ર અને કોઇલના અક્ષ વચ્ચેનો ખૂણો છે.
  • ચાર્જિત કણ માટે કેન્દ્રગામી બળ = ચુંબકીય બળ → mv²/r = qvB સમીકરણનો ઉપયોગ રાખવો.
