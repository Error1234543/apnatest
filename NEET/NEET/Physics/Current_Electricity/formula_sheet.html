વિદ્યુત પ્રવાહ (Current Electricity) — સૂત્ર પડકાળ

🩺 NEET UG — Gujarati • Physics • Current Electricity

⚡ સૂત્રો

વિદ્યુત પ્રવાહ (Current): I = Q / t
I = વિદ્યુત પ્રવાહ, Q = વિદ્યુતભાર, t = સમય · SI: એમ્પિયર (A) · જ્યારે સમયાંતર t માં ભાર Q પ્રવાહી વાયરમાંથી પસાર થાય.
સરેરાશ પ્રવાહ (Average Current): I_avg = ΔQ / Δt
ΔQ = સમય અંતરાલ Δt માં પ્રવાહી ભાર · SI: એમ્પિયર (A) · જ્યારે પ્રવાહ અચળ ન હોય.
તત્કાલીન પ્રવાહ (Instantaneous Current): I = dq / dt
dq = અત્યંત નાના સમય dt માં પ્રવાહી અનંતસ્ફૂટ ભાર · SI: એમ્પિયર (A) · સામાન્ય કિસ્સા, વક્ર ગ્રાફનો ઢાળ.
ડ્રિફ્ટ વેગ (Drift Velocity): v_d = e E τ / m
e = ઇલેક્ટ્રોન પર ભાર, E = વિદ્યુતક્ષેત્ર, τ = રિલેક્સેશન સમય (અવરોધકતાનો સરેરાશ સમય), m = ઇલેક્ટ્રોન દળ · SI: m/s · ધાતુમાં મુક્ત ઇલેક્ટ્રોન પર ઇલેક્ટ્રિક ફીલ્ડ લાગે ત્યારે.
ડ્રિફ્ટ વેગ (બીજું સ્વરૂપ): v_d = I / (n A e)
n = મુક્ત ઇલેક્ટ્રોનની સંખ્યા ઘનતા (number density), A = વાયરનું ક્રોસ-સેક્શનલ એરિયા, e = ઇલેક્ટ્રોન ભાર, I = પ્રવાહ · SI: m/s · જ્યારે પ્રવાહ I, વિભાગ K્ષેત્રફળ A અને n જણાતા હોય.
ઓમનો નિયમ (Ohm's Law): V = I R
V = રોકાણ (પotential difference), I = પ્રવાહ, R = અવરોધ · SI: V (વોલ્ટ), I (એમ્પિયર), R (ઓમ Ω) · તાપમાન અને ભૌતિક અવસ્થા અચળ હોય; ઓમનિયમ પાળતું સાધન (ohmic conductor).
અવરોધ (Resistance): R = ρ L / A
ρ = વિદ્યુતરાજ્ય (resistivity), L = વાયરની લંબાઈ, A = ક્રોસ-સેક્શનલ એરિયા · SI: ઓમ (Ω) · સમાંગ (uniform) વાહક તાર માટે.
વિદ્યુતરાજ્ય / વિષેષ અવરોધ (Resistivity): ρ = m A / (n e² τ)
m = ઇલેક્ટ્રોન દળ, n = મુક્ત ઇલેક્ટ્રોન ઘનતા, e = ઇલેક્ટ્રોન ભાર, τ = રિલેક્સેશન સમય · SI: ઓમ·મીટર (Ω·m) · ધાતુઓ માટે માઇક્રોસ્કોપિક સ્વરૂપ.
વિદ્યુત પ્રવાહ ઘનતા (Current Density): J = I / A = σ E
J = પ્રવાહ ઘનતા, σ = વિદ્યુત વાહકતા (σ = 1/ρ), E = વિદ્યુતક્ષેત્ર · SI: A/m² · સમાંગ પ્રવાહ વિતરણ.
તાપમાન પર અવરોધની નિર્ભરતા: R = R₀ (1 + α ΔT) અથવા R = R₀ (1 + α (T - T₀))
R₀ = પ્રાથમિક તાપમાન T₀ પર અવરોધ, α = અવરોધનો તાપમાન ગુણાંક, ΔT = તાપમાન ફેરફાર · SI: α નો એકમ: K⁻¹ અથવા °C⁻¹ · મર્યાદિત તાપમાન શ્રેણી માટે; ધાતુઓમાં α ધન હોય છે.
તાપમાન પર વિદ્યુતરાજ્યની નિર્ભરતા: ρ = ρ₀ (1 + α ΔT)
ρ₀ = T₀ તાપમાન પર વિદ્યુતરાજ્ય, α = તાપમાન ગુણાંક · SI: ρ: Ω·m · આંશિક તાપમાન ફેરફાર માટે.
વિદ્યુત શક્તિ (Electrical Power): P = V I = I² R = V² / R
P = શક્તિ, V = વોલ્ટેજ, I = પ્રવાહ, R = અવરોધ · SI: વોટ (W) · જુલા પ્રતિરોધક ભાર માટે.
વિદ્યુત ઊર્જા / કાર્ય (Electrical Energy): W = V I t = I² R t = V² t / R
W = કાર્ય / ઊર્જા, t = સમય · SI: જૂલ (J) · સમય t સુધી અચળ પ્રવાહ વહે ત્યારે.
જૂલની ઉષ્મા (Joule Heating): H = I² R t
H = ઉત્પન્ન થતી ઉષ્મા, I = પ્રવાહ, R = અવરોધ, t = સમય · SI: જૂલ (J) · અવરોધકમાં ઉષ્મા ઉત્પાદન (જૂલનો નિયમ).
વિદ્યુત કાર્ય / વિક્ષેપણ (Electrical Work): W = Q V = n e V
Q = કુલ ભાર, n = ઇલેક્ટ્રોનની સંખ્યા, e = ઇલેક્ટ્રોન ભાર, V = વિક્ષેપણ · SI: જૂલ (J) · ભાર Q ને V પotential તફાવતથી ગતિમાન કરવાનું કાર્ય.
શ્રેણી સંયોજન (Series Combination): R_eq = R₁ + R₂ + R₃ + ...
R_eq = બદલી અવરોધ, R₁, R₂, ... = શ્રેણીમાં જોડેલા અવરોધો · SI: ઓમ (Ω) · બધા અવરોધમાંથી સમાન પ્રવાહ પસાર થાય.
સમાંતર સંયોજન (Parallel Combination): 1 / R_eq = 1/R₁ + 1/R₂ + 1/R₃ + ...
R_eq = બદલી અવરોધ, R₁, R₂, ... = સમાંતરમાં જોડેલા અવરોધો · SI: ઓમ (Ω) · બધા અવરોધો પર સમાન વોલ્ટેજ હોય.
બે અવરોધો સમાંતર (Two Resistors in Parallel): R_eq = R₁ R₂ / (R₁ + R₂)
R₁, R₂ = બે અવરોધો · SI: ઓમ (Ω) · ફક્ત બે અવરોધો સમાંતર જોડાયેલા હોય.
કોષનું વિદ્યુતચાલક બળ (EMF of Cell): ε = E / q
ε = EMF, E = કરવામાં આવેલું કાર્ય (non-electrostatic બળ દ્વારા), q = ખસેડેલો ભાર · SI: વોલ્ટ (V) · કોષના ટerminals પર કોઈ પ્રવાહ ન વહે (open circuit).
અંદરૂની અવરોધ સાથે વાયરિંગ (Terminal Voltage with Internal Resistance): V = ε - I r
V = ટerminal voltage, ε = EMF, I = પ્રવાહ, r = આંતરિક અવરોધ · SI: V (વોલ્ટ) · કોષ discharge થતો હોય ત્યારે (પ્રવાહ બહારની દિશામાં).
કોષનો મહત્તમ પ્રવાહ (Maximum Current): I_max = ε / r
ε = EMF, r = આંતરિક અવરોધ · SI: એમ્પિયર (A) · જ્યારે બાહ્ય અવરોધ R = 0 (short circuit).
શ્રેણીમાં કોષો (Cells in Series): ε_eq = ε₁ + ε₂ + ... ; r_eq = r₁ + r₂ + ...
ε₁, ε₂ = EMF, r₁, r₂ = આંતરિક અવરોધ · SI: ε: V, r: Ω · સમાન દિશામાં જોડેલા કોષો શ્રેણીમાં.
સમાંતરમાં કોષો (Cells in Parallel): ε_eq = (ε₁/r₁ + ε₂/r₂ + ...) / (1/r₁ + 1/r₂ + ...)
ε₁, ε₂ = EMF, r₁, r₂ = આંતરિક અવરોધ · SI: ε_eq: V · સમાન દિશામાં જોડેલા કોષો સમાંતરમાં; r₁ = r₂ = r હોય તો ε_eq = ε.
કોષની વર્તુળ પ્રતિરોધક શક્તિ (Power Delivered by Cell): P = ε I - I² r = I² R
P = બાહ્ય ભારને પ્રાપ્ત થતી શક્તિ, R = બાહ્ય અવરોધ · SI: વોટ (W) · બાહ્ય પરિપથમાં.
મહત્તમ શક્તિ સ્થાનાંતરણ (Maximum Power Transfer): R = r હોય ત્યારે P_max = ε² / (4r)
R = બાહ્ય અવરોધ, r = આંતરિક અવરોધ, ε = EMF · SI: W · બાહ્ય અવરોધ, આંતરિક અવરોધ બરાબર હોય ત્યારે મહત્તમ શક્તિ.
કિર્ચહોફનો પ્રથમ નિયમ (Kirchhoff's First Law / Junction Rule): Σ I_in = Σ I_out અથવા Σ I = 0 (બિંદુ પર)
બધા બાહુઓમાં પ્રવાહનો બીજગણિતીય સરવાળો શૂન્ય · SI: — · ભાર સંરક્ષણ નિયમ પર આધારિત.
કિર્ચહોફનો બીજો નિયમ (Kirchhoff's Second Law / Loop Rule): Σ V = 0 (બંધ પરિપથમાં)
બંધ લૂપમાં વોલ્ટેજ ફેરફારનો સરવાળો શૂન્ય · SI: — · ઊર્જા સંરક્ષણ નિયમ પર આધારિત.
વેટસ્ટોન બ્રિજ (Wheatstone Bridge) — સંતુલન અવસ્થા: P / Q = R / S અથવા P S = Q R
P, Q, R, S = ચાર બાહુના અવરોધો · SI: — ·
મીટર બ્રિજ (Meter Bridge): R / S = l / (100 - l) અથવા R = S × l / (100 - l)
R = અજ્ઞાત અવરોધ, S = જ्ञાત અવરોધ (resistance box), l = સંતુલન બિંદુની ડાબી બાજુની લંબાઈ (cm) · SI: R: Ω · મીટર બ્રિજનું તાર લંબાઈ 100 cm હોય.
પોટેન્શિયોમીટર — EMF ની તુલના: ε₁ / ε₂ = l₁ / l₂
ε₁, ε₂ = બે કોષોનું EMF, l₁, l₂ = તેમના સંતુલન લંબાઈ · SI: — ·
પોટેન્શિયોમીટર — આંતરિક અવરોધ શોધવો: r = R (l₁ / l₂ - 1) અથવા r = R (l₁ - l₂) / l₂
r = કોષનો આંતરિક અવરોધ, R = જ्ञાત અવરોધ (resistance box), l₁ = ખુલ્લો પરિપથ સંતુલન લંબાઈ (EMF), l₂ = બંધ પરિપથ સંતુલન લંબાઈ (terminal voltage) · SI: r: Ω · પોટેન્શિયોમીટર વડે કોષનો આંતરિક અવરોધ માપવા.
પોટેન્શિયોમીટરની પોટેન્શિયલ ગ્રેડિયન્ટ (Potential Gradient): k = V / L = ε_s R / ((R_s + R) L)
k = પોટેન્શિયલ ગ્રેડિયન્ટ (V/m), V = ક્ષેત્ર તાર પર વોલ્ટેજ, L = ક્ષેત્ર તારની કુલ લંબાઈ, ε_s = સહાયક કોષનું EMF, R_s = સરીઅસ રેઝિસ્ટન્સ, R = ક્ષેત્ર તારનો અવરોધ · SI: V/m અથવા V/cm · સમાંગ તાર માટે.
અવરોધકતાનું એકમ પડતું સૂત્ર: 1 Ω·m = 100 Ω·cm
એકમ રૂપાંતરણ · SI: Ω·m = SI, Ω·cm = CGS-સંબંધિત · ગણતરીમાં એકમ ફેરફાર.

🔗 સંબંધો

  • v_d ∝ E : ડ્રિફ્ટ વેગ વિદ્યુતક્ષેત્રના સમાંગ સમપ્રમાણમાં છે.
  • J = σE : પ્રવાહ ઘનતા વિદ્યુતક્ષેત્રના સમાંગ સમપ્રમાણમાં (ઓમનો નિયમનું અવકાશ સ્વરૂપ).
  • ρ = m/(n e²τ) : વિદ્યુતરાજ્ય રિલેક્સેશન સમયના વ્યસ્ત સમપ્રમાણમાં છે.
  • v_d = I/(nAe) : સમાન n અને A માટે v_d ∝ I.
  • R ∝ 1/A : સમાન લંબાઈ અને સામગ્રી માટે અવરોધ ક્રોસ-સેક્શનલ એરિયાના વ્યસ્ત સમપ્રમાણમાં.
  • I_max = ε/r : short-circuit પ્રવાહ ફક્ત EMF અને આંતરિક અવરોધ પર આધારિત.
  • P_max ત્યારે જ R = r : મહત્તમ શક્તિ સ્થાનાંતરણ સિદ્ધાંત.
  • શ્રેણીમાં અવરોધો → R_eq > મોટામાં મોટો અવરોધ; સમાંતરમાં → R_eq < સૌથી નાનો અવરોધ.
  • પોટેન્શિયોમીટર તાર પર k = V/L = અચળ રહે છે; ε ∝ l (સંતુલન લંબાઈ).

🎯 ટ્રિક્સ

માત્ર બે સમાંતર અવરોધો: R_eq = 'અડધા નીચે × ઉપર' (પરસ્પર ગુણાકાર ÷ સરવાળો); મોટામાં મોટો અવરોધ સમાન હોય તો R_eq ≈ નાનો અવરોધ.
n સમાન અવરોધો R ની શ્રેણી → nR; સમાંતર → R/n.
શ્રેણીમાં કોષો: EMF ઉમેરાય, r ઉમેરાય; એક કોષ ઉલટો જોડાયો હોય → તેનું EMF બાદ થાય.
સમાંતરમાં n સમાન કોષો: ε_eq = ε, r_eq = r/n.
મેટર બ્રિજમાં જમણી બાજુ l મળે તો ડાબી બાજુ = (100-l); સંતુલન બિંદુ વામાવર્તન (interchangeable) છે — P/Q = R/S ↔ Q/P = S/R.
મીટર બ્રિજમાં અજ્ઞાત અવરોધ ડાબી બાજુ મૂકો તો l > 50 cm આવે (વધુ ચોકસાઈ); જમણી બાજુ ક્ષેત્રમાં R નું મૂલ્ય ફેરવીને l ≈ 50 cm કરવા પ્રયત્ન કરો.
પોટેન્શિયોમીટરમાં સંતુલન લંબાઈ l = ε/k; k ઘટાડતા (સરીઅસ રેઝિસ્ટન્સ વધારી) સંવેદનશીલતા વધે (મોટી l મળે).

પોટેન્શિયોમીટરના ક્ષેત્ર તાર પર પ્રવાહ સતત રાખવા સહાયક કોષનું EMF મુખ્ય પરિપથના EMF થી વધુ હોવું જોઈએ.

EMF એ વિભવ નથી; EMF એ એકમ ભારે કરવામાં આવેલું કાર્ય છે (V = joule/coulomb = volt), જોકે એકમ સમાન છે.
