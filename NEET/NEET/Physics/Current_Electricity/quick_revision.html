ધારા વિદ્યુત — QUICK REVISION (NEET UG)

🩺 NEET UG — Gujarati • Physics • Current Electricity

🧠 યાદ રાખો

વિદ્યુત પ્રવાહ (I) એ એકમ કળમાં પ્રવાહી થરમાંથી પસાર થતા વિદ્યુતભારનો ગુણોત્તર છે: I = Q/t; દિશા: ધનથી ઋણ (પરંપરાગત પ્રવાહ), આચલિત ઇલેક્ટ્રોનની વિરુદ્ધ.
પ્રવાહ ઘનતા J = I/A; એકમ: A/m²; I = nAe v_d સંબંધ યાદ રાખો.
ઇલેક્ટ્રોનનું વિસ્થાપન વેગ v_d = eEτ/m = I/(nAe); τ એ સરેરાશ મુક્ત સમય છે. E વધે તો v_d વધે.
ઓહ્મનો નિયમ V = IR → માત્ર સુસંગત (ohmic) પદાર્થો માટે લાગુ; DIYD (diode, bulb, thermistor, etc.) non-ohmic છે.
અવરોધ R = ρl/A; અવરોધકતા ρ = mA·m; એકમ: Ω·m. ધાતુઓમાં ρ તાપમાન સાથે વધે, અર્ધવાહકોમાં ઘટે.
તાપમાન સાથે અવરોધ: R = R₀(1 + αΔT); α એ અવરોધકતાનું તાપમાન ગુણાંક.
શ્રેણી જોડાણ: R_eq = R₁+R₂+… (સમાન I); સમાંતર જોડાણ: 1/R_eq = 1/R₁+1/R₂+… (સમાન V).
કીર્ચહોફના બે નિયમો: (1) જંક્શન નિયમ — ΣI = 0, (2) લૂપ નિયમ — ΣV = 0; ઊર્જા સંરક્ષણના આધારે.
વ્હીટસ્ટોન સેતુ સંતુલન શરત: P/Q = R/S; galvanometer માં શૂન્ય પ્રવાહ.
કોષનું વેદનબળ ε = IR + Ir = V + Ir; આંતરિક અવરોધ r = (ε−V)/I.
સમાન કોષોની શ્રેણી જોડાણ: ε_eq = nε, r_eq = nr. સમાંતર જોડાણ: ε_eq = ε, r_eq = r/n.
જૂલ ઉષ્મા: H = I²Rt; શક્તિ P = VI = I²R = V²/R; ઊર્જા E = Pt.

⚡ ઝડપી સૂત્રો

I = Q/t, I = nev_d A, J = I/A = ne v_d
v_d = eEτ/m, σ = ne²τ/m, ρ = 1/σ
R = ρl/A, R = R₀(1 + αΔT)
শ্রেষ্ঠী: R_eq = R₁+R₂, સમાંતર: 1/R_eq = 1/R₁+1/R₂
P = VI = I²R = V²/R, H = I²Rt
ε = V + Ir, r = (ε − V)/I, I = ε/(R+r)
સમાન કોષો શ્રેણી: ε_eq = nε, r_eq = nr; સમાંતર: ε_eq = ε, r_eq = r/n
વ્હીટસ્ટોન સેતુ: P/Q = R/S
વોલ્ટમીટર વડે R શોધ: V/I (ohm law)
પોટેન્શિયલ ગ્રેડિયન્ટ k = V/l = K I / (nAe l), વડે λ ∝ ε: ε = kλ

✅ વન-લાઈનર્સ

ઇલેક્ટ્રોનનું RMS વેગ (~10⁵ m/s) >> વિસ્થાપન વેગ (~10⁻⁴ m/s); ઇલેક્ટ્રિક ક્ષેત્ર મૂકતાં ઇલેક્ટ્રોન બંને વેગનું સંયુક્ત ગતિ કરે.
અવરોધકતા ρ પદાર્થની પ્રકૃતિ પર આધારિત છે, પરંતુ આકાર પર નહીં; અવરોધ R આકાર પર પણ આધારિત છે.
કુપર (Copper) ની અવરોધકતા મસૂરી ધાતુઓમાં સૌથી ઓછી; તેથી જોડાણ તારો કોપરનો બનાવે છે.
માળાતંતુ (filament) બલ્બની અવરોધકતા ગરમ અવસ્થામાં ~10× વધારે હોય છે.
અર્ધવાહક (semiconductor) ની અવરોધકતા તાપમાન વધારવાથી ઘટે છે (ઋણ તાપમાન ગુણાંક).
સુપરકન્ડક્ટર્સ: ચોક્કસ તાપમાન (T_c) નીચે R = 0 થાય છે.
કેલ્વિન સેતુ (Kelvin bridge) નો ઉપયોગ ખૂબ નાના અવરોધ માપવા માટે થાય છે.
વોલ્ટમીટરનો અવરોધ શક્ય તેટલો વધારે હોવો જોઈએ (આદર્શ: अनंत); એમીટરનો અવરોધ શક્ય તેટલો ઓછો (આદર્શ: 0).
વ્હीटস্টोन સેતુનો ઉપયોગ મધ્યમ અવરોધ (1–10⁵ Ω) માપવા માટે થાય છે.
પોટેન્શિયોમીટર વડે બે EMF ની તુલના: ε₁/ε₂ = λ₁/λ₂ (સંતુલન લંબાઈનો ગુણોત્તર).
