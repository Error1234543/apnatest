⚡ સૂત્રો

કુલંબનો નિયમ (બે બિંદુ વિદ્યુતભાર વચ્ચે): F = k·q₁·q₂/r²
F = બળ, k = 1/(4πε₀) ≈ 9×10⁹ N·m²/C², q₁,q₂ = વિદ્યુતભાર, r = અંતર · SI: ન્યૂટન (N) · સ્ટેટિક (ગતિહીન) બિંદુભારો માટે; શૂન્યાવકાશ/વાયુમાં
કુલંબ બળ વેક્ટર સ્વરૂપ: F⃗ = k·q₁·q₂/r² · r̂
r̂ = એકમ સ્થાન સદિશ (એક ભાર પરથી બીજા ભાર તરફ) · SI: ન્યૂટન (N) · દિશા સાથેનું વિદ્યુત બળ; સમાન ચિહ્ન → અપાકર્ષણ, વિરોધી ચિહ્ન → આકર્ષણ
વેરિએશન ફોર્મ / પ્રકાશના વેગ સાથે સંબંધ: k = 1/(4πε₀εᵣ)
ε₀ = શૂન્યાવકાશનું પરમેટિવિટી ≈ 8.854×10⁻¹² C²/(N·m²), εᵣ = માધ્યમનું સાપેક્ષ પરમેટિવિટી (ડાયઇલેક્ટ્રિક કન્સ્ટેન્ટ) · SI: N·m²/C² · કોઈ પણ માધ્યમમાં કુલંબ અચળાંક
વિદ્યુત ક્ષેત્રની વ્યાખ્યા: E⃗ = F⃗/q₀
E⃗ = વિદ્યુત ક્ષેત્ર, F⃗ = પરાક્ષેપિત ભાર q₀ પર લાગતું બળ, q₀ = પરીક્ષણ ભાર · SI: N/C અથવા V/m · કોઈપણ સ્થાને વિદ્યુત ક્ષેત્રની મૂળભૂત વ્યાખ્યા
બિંદુભારના વિદ્યુત ક્ષેત્રની તીવ્રતા: E = k·Q/r²
Q = સ્રોત ભાર, r = ભારથી અંતર · SI: N/C · શૂન્યાવકાશમાં બિંદુભાર Q ની આસપાસ
વિદ્યુત ક્ષેત્રનું સુપરપોઝિશન સિદ્ધાંત: E⃗_net = E⃗₁ + E⃗₂ + E⃗₃ + ...
E⃗₁,E⃗₂,... = અલગ-અલગ ભારોના ક્ષેત્રો · SI: N/C · એકаზეથી વધુ ભારોના ક્ષેત્રો વેક્ટર જોડાણ દ્વારા
રેખીય ભાર ઘનતા (λ) ધરાવતી અનંત સીધી તારની ક્ષેત્ર: E = λ/(2πε₀r)
λ = રેખીય ભાર ઘનતા (C/m), r = તારથી લંબ અંતર · SI: N/C · અનંત સીધો સમભાર તાર
બિંદુભાર q પર લાગતું વિદ્યુત બળ: F⃗ = qE⃗
q = ભાર, E⃗ = વિદ્યુત ક્ષેત્ર · SI: ન્યૂટન (N) · સમાન અથવા અસમાન ક્ષેત્રમાં ભાર
વિદ્યુત ડાયપોલનો ડાયપોલ મોમેન્ટ: p⃗ = q·(2a) = q·d⃗
q = ભાર, d = ધન અને ઋણ ભાર વચ્ચેનું અંતર, 2a = અંતર · SI: C·m (કુલંબ-મીટર) · બે સમાન પરંતુ વિરોધી ચિહ્નના ભારો માટે
ડાયપોલ પર અચળ વિદ્યુત ક્ષેત્રમાં ટોર્ક: τ⃗ = p⃗ × E⃗ ; |τ| = pE sinθ
p = ડાયપોલ મોમેન્ટ, E = ક્ષેત્ર, θ = p⃗ અને E⃗ વચ્ચેનું ખૂણો · SI: N·m · સમાન વિદ્યુત ક્ષેત્રમાં ડાયપોલ
ડાયપોલ પર ક્ષેત્ર દ્વારા થતું કાર્ય / સ્થિતિસ્થાપક સંભવિત ઊર્જા: U = -p⃗·E⃗ = -pE cosθ
U = સંભવિત ઊર્જા, θ = p⃗ અને E⃗ વચ્ચેનું ખૂણો · SI: જૂલ (J) · સમાન ક્ષેત્રમાં ડાયપોલ
ડાયપોલ અક્ષ પર વિદ્યુત ક્ષેત્ર (દૂરનું અંતર r >> a): E_axial = 2kp/(r³) = 2pq/(4πε₀r³)
p = ડાયપોલ મોમેન્ટ, r = કેન્દ્રથી અક્ષ પરનું અંતર · SI: N/C · રિપ્લિક્સ (બોર) અંતરે r >> d
ડાયપોલ લઘુ અક્ષ પર વિદ્યુત ક્ષેત્ર (દૂરનું અંતર r >> a): E_bisect = kp/(r³) = pq/(4πε₀r³)
p = ડાયપોલ મોમેન્ટ, r = કેન્દ્રથી લઘુ અક્ષ પરનું અંતર · SI: N/C · રિપ્લિક્સ અંતરે r >> d
ડાયપોલ સમાન ક્ષેત્રમાં પાટાપૂર્ણ ઘૂર્ણન આવર્તકાળ: T = 2π√(I/pE)
I = ડાયપોલનો જડત્વ વ્યાસાર્ધ, p = ડાયપોલ મોમેન્ટ, E = ક્ષેત્ર · SI: સેકન્ડ (s) · સમાંપાત વિસ્થાપન સાથેના ઓસિલેશન માટે
વિદ્યુત ફ્લક્સ (સમાંપાત સપાટી): Φ = E·A = EA cosθ
E = ક્ષેત્ર, A = સપાટીનું ક્ષેત્રફળ, θ = E⃗ અને સામાન્ય સદિશ n̂ વચ્ચેનો ખૂણો · SI: N·m²/C અથવા V·m · સમાન ક્ષેત્ર અને સમાંપાત સપાટી
વિદ્યુત ફ્લક્સ (વક્ર સપાટી / સામાન્ય કિસ્સો): Φ = ∮ E⃗ · dA⃗
dA⃗ = સૂક્ષ્મ સપાટી તત્વ (બહારની તરફ સામાન્ય) · SI: N·m²/C · કોઈપણ વક્ર બંધ સપાટી
ગાઉસનો સિદ્ધાંત (બંધ સપાટી): ∮ E⃗ · dA⃗ = Q_encl/ε₀
Q_encl = સપાટી વડે ઘેરાયેલો કુલ ભાર, ε₀ = શૂન્યાવકાશ પરમેટિવિટી · SI: N·m²/C · કોઈપણ બંધ ગાઉસિયન સપાટી માટે
અનંત સીધા સમભાર તારનું ક્ષેત્ર (ગાઉસથી): E = λ/(2πε₀r)
λ = રેખીય ભાર ઘનતા, r = તારથી લંબ અંતર · SI: N/C · અનંત સીધી તાર, વર્તુળાકાર ગાઉસિયન સપાટી
અનંત સમતલ ભાર પડ (સપાટી ભાર ઘનતા σ): E = σ/(2ε₀)
σ = સપાટી ભાર ઘનતા (C/m²) · SI: N/C · અનંત સમતલ; બંને બાજુ સમાન, લંબરૂપ
વાહક ગોળાકાર ખોલ ઉપર / બહાર / અંદર ક્ષેત્ર: r ≥ R: E = kQ/r²; r < R: E = 0
Q = કુલ ભાર, R = ગોળાની ત્રિજ્યા, r = કેન્દ્રથી અંતર · SI: N/C · વાહક ગોળાકાર ખોલ; ભાર બાહ્ય પૃષ્ઠ પર
વાહક ગોળાની અંદર ક્ષેત્ર શૂન્ય: E_inside = 0
E = વિદ્યુત ક્ષેત્ર · SI: N/C · વાહક શરીરની અંદર (સ્થિતવિદ્યુત સંતુલન)
વિદ્યુત સ્થિતિજ સંભવિત (બિંદુભાર સ્રોત): V = kQ/r = Q/(4πε₀r)
Q = સ્રોત ભાર, r = સ્રોતથી અંતર · SI: વોલ્ટ (V) · શૂન્યાવકાશમાં બિંદુભાર; V(∞) = 0 ધારીને
વિદ્યુત સ્થિતિજ સંભવિત — સુપરપોઝિશન: V = V₁ + V₂ + V₃ + ...
V₁,V₂,... = દરેક ભારનું સંભવિત · SI: વોલ્ટ (V) · બહુ-ભાર સિસ્ટમ
વિદ્યુત ક્ષેત્ર અને સંભવિત વચ્ચેનો સંબંધ: E = -dV/dr (એક પરિમાણ); E⃗ = -∇V
dV/dr = સંભવિતનો ગ્રેડિએન્ટ, ऋણ ચિહ્ન = ક્ષેત્ર ઓછા સંભવિત તરફ · SI: V/m અથવા N/C · કોઈપણ સ્થાને
બિંદુભાર પ્રણાલીની સ્થિતિજ સંભવિત ઊર્જા: U = k·q₁·q₂/r₁₂
q₁,q₂ = બે ભારો, r₁₂ = તેમની વચ્ચેનું અંતર · SI: જૂલ (J) · બે બિંદુભારો માટે; યાદૃચ્છિક પ્રણાલી માટે બધા જોડીઓનો સરવાળો
વિદ્યુત ડાયપોલની સંભવિત ઊર્જા (બાહ્ય ક્ષેત્રમાં): U = -p·E·cosθ
p = ડાયપોલ મોમેન્ટ, E = ક્ષેત્ર, θ = ખૂણો · SI: જૂલ (J) · સમાન બાહ્ય ક્ષેત્રમાં
સંભવિત તફાવત: V_B - V_A = -∫_A^B E⃗ · dl⃗
E⃗ = વિદ્યુત ક્ષેત્ર, dl⃗ = સ્થાનાંતર તત્વ · SI: વોલ્ટ (V) · કોઈપણ માર્ગ માટે (કન્ઝર્વેટિવ ક્ષેત્ર)
સમાન વિદ્યુત ક્ષેત્રમાં સંભવિત તફાવત: ΔV = E·d
E = ક્ષેત્રની તીવ્રતા, d = ક્ષેત્રની દિશામાંનું અંતર · SI: વોલ્ટ (V) · સમાન ક્ષેત્ર
વિદ્યુત ડાયપોલ સંભવિત (દૂરના બિંદુએ): V = kp·cosθ/r²
p = ડાયપોલ મોમેન્ટ, θ = અક્ષ સાથેનું ખૂણો, r = અંતર · SI: વોલ્ટ (V) · રિપ્લિક્સ અંતર r >> d
સમભારી ગોળાકાર ખોલ પર સંભવિત (સપાટી પર): V_surface = kQ/R
Q = કુલ ભાર, R = ત્રિજ્યા · SI: વોલ્ટ (V) · વાહક સમાન ભારિત ગોળો
સમભારી ગોળાકાર ખોલની અંદર સંભવિત: V_inside = kQ/R = constant
Q = ભાર, R = ત્રિજ્યા · SI: વોલ્ટ (V) · વાહક ગોળો; સપાટીથી અંદર સમાન
વિદ્યુતધારિતા (Capacitance): C = Q/V
C = વિદ્યુતધારિતા, Q = સંગ્રહિત ભાર, V = સંભવિત તફાવત · SI: ફેરાડ (F) · કોઈપણ કેપેસિટર
પેરાલલ-પ્લેટ કેપેસિટર (શૂન્યાવકાશ/વાયુ): C = ε₀A/d
A = પ્લેટનું ક્ષેત્રફળ, d = પ્લેટ વચ્ચેનું અંતર · SI: ફેરાડ (F) · સમાનાંતર પ્લેટ, d ≪ √A
પેરાલલ-પ્લેટ કેપેસિટર (ડાયઇલેક્ટ્રિક ભર્યું): C = ε₀εᵣA/d = κC₀
εᵣ = κ = સાપેક્ષ પરમેટિવિટી (ડાયઇલેક્ટ્રિક અચળાંક) · SI: ફેરાડ (F) · પ્લેટ વચ્ચે ડાયઇલેક્ટ્રિક ભરેલું
કેપેસિટરોનો શ્રેણી સંગાયોજન: 1/C_eq = 1/C₁ + 1/C₂ + 1/C₃ + ...
C₁,C₂,C₃ = અલગ અલગ વિદ્યુતધારિતાઓ · SI: ફેરાડ (F) · શ્રેણી (Series) જોડાણ
કેપેસિટરોનો સમાંતર સંગાયોજન: C_eq = C₁ + C₂ + C₃ + ...
C₁,C₂,C₃ = અલગ અલગ વિદ્યુતધારિતાઓ · SI: ફેરાડ (F) · સમાંતર (Parallel) જોડાણ
કેપેસિટરમાં સંગ્રહિત ઊર્જા: U = ½CV² = ½QV = Q²/(2C)
C = વિદ્યુતધારિતા, V = સંભવિત તફાવત, Q = ભાર · SI: જૂલ (J) · કોઈપણ કેપેસિટર
વિદ્યુત ક્ષેત્ર ઊર્જા ઘનતા: u = ½ε₀E²
ε₀ = શૂન્યાવકાશ પરમેટિવિટી, E = વિદ્યુત ક્ષેત્ર · SI: J/m³ · કોઈપણ સ્થાને વિદ્યુત ક્ષેત્ર
પોલારાઈઝેશન (ડાયઇલેક્ટ્રિકમાં): P⃗ = χ_e · ε₀ · E⃗
P⃗ = પોલારાઈઝેશન, χ_e = વિદ્યુત પોલારાઈઝેબિલિટી (પ્રતિભાવશીલતા), ε₀ = શૂન્યાવકાશ પરમેટિવિટી · SI: C/m² · સમાન ડાયઇલેક્ટ્રિક
સાપેક્ષ પરમેટિવિટી અને પોલારાઈઝેબિલિટી વચ્ચેનો સંબંધ: εᵣ = κ = 1 + χ_e
κ = ડાયઇલેક્ટ્રિક અચળાંક, χ_e = વિદ્યુત પોલારાઈઝેબિલિટી · SI: એકમરહિત · રેખીય સમઘન ડાયઇલેક્ટ્રિક
વિદ્યુત ડાયપોલ મોમેન્ટ (પરમાણ્વીય સ્તરે): p⃗ = α·E⃗
α = પોલેરાઈઝેબિલિટી, E⃗ = સ્થાનિક ક્ષેત્ર · SI: C·m · પરમાણુ/અણુ ડાયપોલ

🔗 સંબંધો

  • ફારેડીએ ક્ષેત્ર અને સંભવિત વચ્ચે E = -dV/dr, એટલે કે ક્ષેત્ર સંભવિત ઘટાડાનો દર છે — એક્વિપોટેન્શિયલ સપાટી પર E⃗ હંમેશા લંબરૂપ હોય.
  • કેપેસિટર ઊર્જા U = ½CV² માં V² નો ઉપયોગ કરતાં ક્ષેત્ર ઊર્જા ઘનતા u = ½ε₀E² બદલાય; બંને સમાન રીતે ઊર્જા વર્ણવે છે.
  • ગાઉસના નિયમથી ગણતરી કરતાં સમભારી ગોળાકાર ક્ષેત્ર E = kQ/r² (bāhya) અને સંભવિત V = kQ/r (સપાટી + અંદર), જે સમાન છે.
  • ડાયપોલ અક્ષ પર E = 2kp/r³ અને લઘુઅક્ષ પર E = kp/r³ છે; બેયનું અંતરપડું r³ પર નિર્ભર છે.
  • પેરાલલ-પ્લેટ કેપેસિટરમાં C ∝ A અને C ∝ 1/d; ડાયઇલેક્ટ્રિક મૂકતા C = κC₀ વધે છે.
  • શ્રેણી જોડાણમાં બધા C પર સમાન Q રહે છે, પણ સમાંતર જોડાણમાં બધા C પર સમાન V રહે છે.

🎯 ટ્રિક્સ

રેખીય ભાર ઘનતા λ અને સપાટી ભાર ઘનતા σ વચ્ચે: λ = σ·(પરિઘ) ની સમજ બે-પરિમાણ તાર/સપાટીમાં સરળતાથી કરે છે.
ડાયપોલ અક્ષ પરનું E, લઘુઅક્ષ કરતાં બમણું હોય છે (ઉભયr³): સરળ યાદ રાખવા E_axial = 2E_bisect.
ગોળાકાર ભાગ માટે C = 4πε₀R (એકલા ગોળા); R ≈ 9×10⁻³ m લેતાં ~1 pF મળે છે — આ યાદ હોય તો કદ માપણી સરળ બને.
કેપેસિટર ઊર્જાના ત્રણ સ્વરૂપો U = ½CV² = ½QV = Q²/(2C) માંથી એક સમીકરણ ગણતરી સરળ બનાવે: જો Q વાપરવાનો હોય તો Q²/(2C), જો V વાપરવાનો હોય તો ½CV².
ગાઉસના નિયમથી E = λ/(2πε₀r) નીમિત્ત: વર્તુળાકાર ગાઉસિયન સપાટી 2πrL અને Q_encl = λL → E·2πrL = λL/ε₀ → E = λ/(2πε₀r).
રિપ્લિક્સ અંતરે ડાયપોલ E ∝ 1/r³, બિંદુભાર E ∝ 1/r²; ઊંચા ઘાતનો અર્થ ઝડપી ઘટાડો — અંદરો અંતર વાપરતાં ડાયપોલ ઓછું પ્રભાવી.

⚠️ ભૂલો

F = kq₁q₂/r² માં r ને 'અંતર' લખીને પણ vektor સૂત્રમાં r̂ નો ઉપયોગ કરવો — ચિહ્ન સાચું રાખવું: સમાન ચિહ્ન → અપાકર્ષણ, વિરોધી → આકર્ષણ.
E = -dV/dr માં ऋણ ચિહ્ન છોડી દેવું — ક્ષેત્ર હંમેશા ઓછા સંભવિત તરફ હોય, ઊંચા સંભવિત તરફ નહીં.
વાહક ગોળાકાર ખોલની અંદર E = 0 હોય છતાં V = 0 ધારી લેવું — અંદર V = kQ/R (શૂન્ય નહીં), સમાન.
પેરાલલ-પ્લેટ કેપેસિટરમાં C = ε₀A/d માં d ને પ્લેટની જાડાઈ સમજી લેવું — d એ પ્લેટ વચ્ચેનું અંતર છે.
શ્રેણી અને સમાંતર જોડાણ ગૂંચવી જવું — શ્રેણીમાં 1/C_eq = 1/C₁ + 1/C₂, સમાંતરમાં C_eq = C₁ + C₂.
ડાયપોલ મોમેન્ટની દિશા ઋણ ભારથી ધન ભાર તરફ લખવી જોઈએ; કેટલાક વિદ્યાર્થીઓ વિરોધી દિશા લે છે.
ગાઉસના નિયમમાં Q_encl માત્ર સપાટીની અંદરના ભાર છે — બહારના ભારનો ફ્લક્સ શૂન્ય બને છે.
ડાયઇલેક્ટ્રિક દાખલ કરતાં C = κC₀ સમીકરણમાં κ > 1 હોય છે — કદાચ ક્લોઝેજ ભૂલથી C ઘટે તેમ સમજી લેવું.
ε₀ ની કિંમત 8.854×10⁻¹² F/m છે; gautiyan ગણતરીમાં 10⁻⁹, 10⁻¹² જેવી ઘાત ભૂલ ઘણી બને છે.
