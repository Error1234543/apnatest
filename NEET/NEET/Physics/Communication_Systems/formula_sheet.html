🩺 NEET UG — Gujarati • Physics • Communication Systems

⚡ સૂત્રો

માનવ કંપનવિસ્તાર (Audible Range): 20 Hz ≤ f ≤ 20,000 Hz
f = ધ્વનિ તરંગની આવૃત્તિ; એકમ Hz · SI: Hz · માનવ કાન સાંભળી શકે તેવો ધ્વનિ
ઘટનાર (Baseband Signal) નું અવકાશીય બેન્ડવિડ્થ: BW = f_m - f_min ≈ f_m (જ્યારે f_min ≈ 0)
f_m = મહત્તમ સંદેશ આવૃત્તિ; f_min = ન્યૂનતમ આવૃત્તિ · SI: Hz · મૂળ ઘટનાર સંકેત માટે
મોડ્યુલેશન સૂચકાંક (AM માટે) — વિસ્તાર પરથી: μ = A_m / A_c = (A_max - A_min) / (A_max + A_min)
A_m = સંદેશ તરંગનું વિસ્ફારણ; A_c = વાહક તરંગનું વિસ્ફારણ; A_max = AM તરંગનું મહત્તમ વિસ્ફારણ; A_min = ન્યૂનતમ વિસ્ફારણ · SI: કોઈ નહીં (અપરિમાણ) · AM તરંગ માટે; μ ≤ 1 હોવું જોઈએ (ઓવરમોડ્યુલેશન ટાળવું)
મોડ્યુલેશન સૂચકાંક — ફ્રિકવન્સી રીતે: μ = E_m / E_c = I_m / I_c
E_m, E_c = સંદેશ અને વાહક વિદ્યુતક્ષેપ; I_m, I_c = સંદેશ અને વાહક પ્રવાહ · SI: કોઈ નહીં (અપરિમાણ) · AM તરંગ માટે
AM તરંગનું સમીકરણ: s(t) = A_c [1 + μ cos(2π f_m t)] cos(2π f_c t)
A_c = વાહકનું વિસ્ફારણ; f_m = સંદેશ આવૃત્તિ; f_c = વાહક આવૃત્તિ; μ = મોડ્યુલેશન સૂચકાંક · SI: V (જો વિદ્યુતક્ષેપ હોય) · એકસરળ ઘટનાર સંકેત માટે
AM તરંગનું વિસ્તૃત સ્વરૂપ: s(t) = A_c cos(2π f_c t) + (μ A_c / 2) cos[2π(f_c - f_m)t] + (μ A_c / 2) cos[2π(f_c + f_m)t]
પ્રથમ પદ = વાહક; બીજું પદ = નીચલો પાર્શ્વી બેન્ડ (LSB); ત્રીજું પદ = ઉર્ધ્વપાર્શ્વી બેન્ડ (USB) · SI: V · AM તરંગના આવૃત્તિ સ્પેક્ટ્રમને દર્શાવવા
પાર્શ્વી બેન્ડ આવૃત્તિઓ: f_USB = f_c + f_m ; f_LSB = f_c - f_m
f_USB = ઉર્ધ્વપાર્શ્વી બેન્ડની આવૃત્તિ; f_LSB = નીચલો પાર્શ્વી બેન્ડની આવૃત્તિ; f_c = વાહક આવૃત્તિ; f_m = સંદેશ આવૃત્તિ · SI: Hz · AM તરંગમાં ઉત્પન્ન થતા પાર્શ્વી બેન્ડ માટે
AM નું બેન્ડવિડ્થ: BW_AM = 2 f_m
f_m = ઉચ્ચતમ સંદેશ આવૃત્તિ · SI: Hz · AM સંચાર માટે
AM વાહક શક્તિ: P_c = V_c² / (2R)
V_c = વાહક વિદ્યુતક્ષેપનો શિખર મૂલ્ય; R = ભાર પ્રતિબાધા (Load resistance) · SI: W · વાહક તરંગની પ્રભાવી શક્તિ
AM પાર્શ્વી બેન્ડ શક્તિ (દરેક): P_sideband_each = (μ² / 4) × P_c
μ = મોડ્યુલેશન સૂચકાંક; P_c = વાહક શક્તિ · SI: W · કોઈ પણ એક પાર્શ્વી બેન્ડ (USB અથવા LSB) માટે
AM કુલ સંચાર શક્તિ: P_total = P_c (1 + μ² / 2)
P_total = AM તરંગની કુલ શક્તિ; P_c = વાહક શક્તિ; μ = મોડ્યુલેશન સૂચકાંક · SI: W · AM સંકેતની કુલ શક્તિ
AM ની શક્તિ બચત (Single Sideband Suppressed Carrier - SSB-SC): Power saved = [1 - μ²/(2(2+μ²))] × 100 %
સંપૂર્ણ AM ની સરખામણીએ ટ્રાન્સમિટ કરવામાં લાગતી શક્તિ બચત · SI: % · SSB-SC વાપરવાથી મળતી બચત
આવર્તી મોડ્યુલેશન સૂચકાંક (FM): β = Δf / f_m
Δf = મહત્તમ આવર્તી વિચલન (Frequency deviation); f_m = સંદેશ આવૃત્તિ · SI: કોઈ નહીં (અપરિમાણ) · FM મોડ્યુલેશન માટે
આવર્તી વિચલન (Frequency Deviation): Δf = k_f × A_m
k_f = ફ્રિકવન્સી સેન્સિટિવિટી (Hz/V); A_m = સંદેશ વિસ્ફારણ · SI: Hz · FM ટ્રાન્સમિટરમાં
Carson નું બેન્ડવિડ્થ સૂત્ર (FM): BW_FM = 2(Δf + f_m) = 2(β + 1)f_m
Δf = મહત્તમ આવર્તી વિચલન; f_m = મહત્તમ સંદેશ આવૃત્તિ; β = મોડ્યુલેશન સૂચકાંક · SI: Hz · FM તરંગનું અંદાજિત બેન્ડવિડ્થ
FM કુલ શક્તિ: P_FM = V_c² / (2R) = P_c
FM માં શક્તિ વાહક શક્તિ બરાબર રહે છે; μ (અથવા β) વધે તો પણ કુલ શક્તિ બદલાતી નથી · SI: W · FM સંકેત માટે; કારણ કે FM માં વિસ્ફારણ સ્થિર રહે છે
દૂરધ્વનિ ટાવર / સ્પેશ આલ્લાહ દૂરત્વ (Line-of-Sight): d_max = √(2Rh_T) + √(2Rh_R)
R = પૃથ્વીની ત્રિજ્યા (≈ 6400 km); h_T = ટ્રાન્સમિટર ટાવરની ઊંચાઈ; h_R = રીસિવર ટાવરની ઊંચાઈ · SI: m અથવા km · Space-wave (line-of-sight) સંચાર માટે
એકલ ટાવરથી ડાર્શનક્ષમ દૂરત્વ (Receiver भू-उत्तरापर): d = √(2Rh)
R = પૃથ્વીની ત્રિજ્યા (≈ 6.4 × 10⁶ m); h = ટ્રાન્સમિટર ટાવરની ઊંચાઈ · SI: m · રિસિવર પૃથ્વી પર હોય ત્યારે maximum line-of-sight coverage
કંપનવિસ્તાર અનુસાર સંચાર પ્રકાર: BF (કિરણોત્સર્ગ બેન્ડ) < બેન્ડવિડ્થ < BW; તરંગदैर्घ्य λ = c / f
c = પ્રકાશની વેગ (3 × 10⁸ m/s); f = આવૃત્તિ; λ = તરંગદૈર્ઘ્ય · SI: c → m/s; f → Hz; λ → m · આવૃત્તિ અને તરંગદૈર્ઘ્ય વચ્ચેનો સંબંધ
સંદેશ (Message Signal) ની પરમાણુ ગુણવત્તા માટે SNR: SNR = P_signal / P_noise
P_signal = સંદેશ શક્તિ; P_noise = નોઇઝ શક્તિ · SI: વોટ (W); dB માં: 10 log₁₀(P_s/P_n) · સંદેશની ગુણવત્તા તપાસવા

🔗 સંબંધો

  • AM માં કુલ શક્તિ P_total = P_c(1 + μ²/2); μ વધે તો P_total વધે છે, પણ વાહક શક્તિ P_c અચળ રહે છે.
  • AM માં બેન્ડવિડ્થ FM કરતાં અર્ધું હોય છે: BW_AM = 2f_m, જ્યારે BW_FM = 2(β+1)f_m ≥ 2f_m.
  • FM માં મોડ્યુલેશન સૂચકાંક β = Δf/f_m; β > 1 હોય તો wide FM, β < 1 હોય તો narrow FM કહેવાય.
  • Space-wave દૂરત્વ d √h સમપ્રમાણમાં હોય છે; ટાવરની ઊંચાઈ ચાર ગણી કરવાથી coverage દૂરત્વ બમણું થાય.
  • AM ના ઉર્ધ્વપાર્શ્વી અને નીચલપાર્શ્વી બેન્ડની શક્તિ સમાન હોય છે: P_USB = P_LSB = (μ²/4)P_c.
  • FM ની કુલ શક્તિ મોડ્યુલેશન સૂચકાંક β પર આધારિત નથી — ફક્ત વાહક વિસ્ફારણ A_c પર.
  • AM ની શક્તિ બચત: SSB-SC વાપરવાથી સૌથી વધુ શક્તિ બચત મળે છે કારણ કે કેરિયર અને એક પાર્શ્વી બેન્ડ બંધ રદ કરવામાં આવે છે.
  • ધ્વનિ સંકેતની ઉચ્ચતમ આવૃત્તિ 20 kHz સુધીની હોય છે, તેથી AM બ્રોડકાસ્ટિંગનું બેન્ડવિડ્થ 40 kHz હોય છે.

🎯 ટ્રિક્સ

AM માટે μ = (A_max - A_min)/(A_max + A_min) — ઓસિલોસ્કોપ પર દેખાતા AM તરંગમાંથી સીધું μ શોધવાનો સૌથી ઝડપી રસ્તો.
AM કુલ શક્તિ P_total = P_c(1 + μ²/2) — જો μ = 1 હોય (100% modulation) તો P_total = 1.5 P_c, એટલે કે 50% વધારાની શક્તિ પાર્શ્વી બેન્ડમાં જાય.
FM નું બેન્ડવિડ્થ Carson ના નિયમ થી: BW = 2(Δf + f_m); સામાન્ય FM બ્રોડકાસ્ટિંગ (Δf = 75 kHz, f_m = 15 kHz) માટે BW = 180 kHz.
ટાવરની ઊંચાઈ ચાર ગણી કરવાથી coverage દૂરત્વ બમણું થાય — d = √(2Rh) સૂત્ર પરથી સ્પષ્ટ.
AM માં μ > 1 (overmodulation) હોય તો distortion આવે છે; આંતરિક રીતે યાદ રાખો: μ ≤ 1 હંમેશા જરૂરી.
FM નું બેન્ડવિડ્થ હંમેશા AM કરતાં વધુ હોય છે: BW_FM ≥ BW_AM, કારણ કે β ≥ 0 → 2(β+1)f_m ≥ 2f_m.
AM ની શક્તિ બચત સૂત્ર યાદ રાખવાને બદલે, યોગ્યતા: SSB-SC માં કુલ શક્તિ P_c(1+μ²/4) હોય છે, જે FM કરતાં ઓછી છે — ઓછી શક્તિમાં વધુ દૂર સંચાર.

⚠️ ભૂલો

AM નું બેન્ડવિડ્થ f_m લખવું — સાચું જવાબ 2f_m છે (બે પાર્શ્વી બેન્ડ હોય છે).
AM કુલ શક્તિ P_total = P_c(1 + μ) લખવી — સાચું સૂત્ર P_total = P_c(1 + μ²/2) છે.
FM માં μ = A_m/A_c લખવું — આ AM નું સૂત્ર છે; FM માટે μ = Δf/f_m થાય.
FM ની કુલ શક્તિ μ પર આધારિત હોય એમ માનવું — FM માં શક્તિ અચળ હોય છે.
space-wave દૂરત્વ d = 2√(2Rh) લખવું — રિસિવર ભૂ-ઉપરી હોય તો d = √(2Rh) (ટાવર માત્ર એક).
μ = 1 કરતાં વધારે મોડ્યુલેશન (overmodulation) સૂત્રમાં મૂકવું — μ ≤ 1 હોવું જોઈએ, નહીંતર distortion આવે.
FM બેન્ડવિડ્થનું સૂત્ર BW = 2Δf લખવું — ખોટું; સાચું સૂત્ર BW = 2(Δf + f_m) છે (Carson's rule).
AM માં બંને પાર્શ્વી બેન્ડની શક્તિ અલગ-અલગ છે એમ ધારી લેવું — બંનેની શક્તિ સમાન (μ²/4)P_c છે.
આવર્તી મોડ્યુલેશન સૂચકાંક β ને μ સાથે ગૂંચવણ પાડવી — AM માટે μ, FM માટે β (અથવા μ) વપરાય છે, પણ સૂત્ર અલગ છે.
