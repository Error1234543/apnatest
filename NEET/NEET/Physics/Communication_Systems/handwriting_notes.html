સંચાર વ્યવસ્થા — હાથથી લખેલી નોટ્સ

🩺 NEET UG — Gujarati • Physics • Communication Systems

📡 સંચાર વ્યવસ્થા
સંચાર = માહિતીનો એક સ્થાન પરથી બીજા સ્થાને હસ્તાંતર
સંચાર વ્યવસ્થામાં મુખ્યત્વે ત્રણ ઘટકો હોય છે: પ્રેષક (Transmitter), માધ્યમ (Channel), અને પ્રાપક (Receiver).
પ્રેષક સ્થાને સંદેશ (Message Signal) ને વિદ્યુત સંકેતમાં રૂપાંતરિત કરવામાં આવે છે.
સંચાર પદ્ધતિ: સંચારક (પ્રેષક) → માધ્યમ → પ્રાપક
સંકેતની પ્રકૃતિ મુજબ સંચાર બે પ્રકારનો હોય છે: અનાલોગ (Analog) અને ડિજિટલ (Digital).
અનાલોગ સંકેતસતત (Continuous) મૂલ્યો ધરાવે છે; ઉદા. ધ્વનિ સંકેત
ડિજિટલ સંકેતઅલગ-અલગ (Discrete) મૂલ્યો ધરાવે છે; 0 અને 1 ના સ્વરૂપમાં
📊 સંકેત પરિણામી પ્રતિબંધ (Signal Bandwidth)
કોઈ પણ સંકેત દ્વારા વહન પામતી મહત્તમ આવૃત્તિ શ્રેણીને બેન્ડવિડ્થ કહે છે.
ધ્વનિ સંકેતની બેન્ડવિડ્થ સામાન્ય રીતે 20 Hz થી 20 kHz અંતરે હોય છે.
TV સિગ્નલની બેન્ડવિડ્થ ~4 MHz હોય છે; રેડિયો બેન્ડવિડ્થ ઘટ્ટ હોય છે.
બેન્ડવિડ્થ B = f_max − f_min
🔑 સંકેત પસાર કરવા માટે ચોક્કસ બેન્ડવિડ્થ જરૂરી છે — માધ્યમ પૂરતી બેન્ડવિડ્થ ધરાવતું હોવું જોઈએ.
🛰️ સંચાર માધ્યમ અને પ્રસરણ મોડ (Mode of Propagation)
સંચાર માધ્યમ મુખ્યત્વે ત્રણ પ્રકારના હોય છે: ભૂમિ તરંગ (Ground wave), આયનોસ્ફિયર પરાવર્તન (Sky wave), અને રેખા દ્રષ્ટિ (Line-of-sight).
ભૂમિ તરંગ પ્રસરણ: નીચી આવૃત્તિ (≤ 2 MHz) વાળા તરંગો ભૂમિની સપાટી પર ગલિયો છે.
આયનોસ્ફિયર પરાવર્તન: 2 MHz થી 30 MHz આવૃત્તિના વાયુચાલિત તરંગો આયનોસ્ફિયરથી પરાવર્તિત થાય છે.
રેખા દ્રષ્ટિ પ્રસરણ: UVF (Ultra High Frequency) તરંગો માટે આ મોડ ઉપયોગી છે.
રેખા દ્રષ્ટિ અંતર d = √(2Rh) ; જ્યાં R = પૃથ્વીની ત્રિજ્યા, h = એન્ટેનાની ઊંચાઈ
📝 ⚡ યાદ રાખો: સ્કાય વેવ માટે આયનોસ્ફિયરનું IONOSPHERE રિફ્લેક્શન જવાબદાર છે.
🔑 આવૃત્તિની પસંદગી પ્રસરણ મોડ નક્કી કરે છે — ચોખ્ખું સંબંધ જાણવું પડે.
🎛️ મોડ્યુલેશન (Modulation) — જરૂરિયાત અને સિદ્ધાંત
મોડ્યુલેશન એટલે સંદેશ સંકેત (Message Signal) ને ઉચ્ચ આવૃત્તિના વાહક તરંગ (Carrier Wave) પર સવારી કરાવવી.
મોડ્યુલેશનની જરૂરિયાત: નીચી આવૃત્તિના સંકેત લાંબા અંતર સુધી પહોંચતા નથી.
ઉંચા એન્ટેનાની ઊંચાઈ વિના સંકેતનો પ્રસરણ અસરકારક રીતે થતો નથી.
एकाधिक સંકેતો એક જ માધ્યમ દ્વારા પસાર થઈ શકે (Multiplexing).
કોલાહલ (Noise) ની અસર ઘટાડવા મોડ્યુલેશન અનિવાર્ય છે.
એન્ટેનાની લઘુત્તમ લંબાઈ = λ/4 = v/(4f) → ઉંચી આવૃત્તિ = ટૂંકું એન્ટેના
🔑 મોડ્યુલેશન વગર લાંબું અંતર શક્ય નથી — કેમ કે λ = c/f મુજબ નીચી f = લાંબું λ.
📝 ⚡ NEET માં 'મોડ્યુલેશન શા માટે?' જેવો પ્રશ્ન સીધો આવે.
📐 મોડ્યુલેશન પ્રકારો — AM, FM, PM
ત્રણ મુખ્ય પ્રકારના મોડ્યુલેશન: ધ્વનિવિસ્તર મોડ્યુલેશન (AM), આવૃત્તિ મોડ્યુલેશન (FM), અને કળા મોડ્યુલેશન (PM).
AM માં વાહકના વિસ્તાર (Amplitude) માં ફેરફાર થાય છે.
FM માં વાહકની આવૃત્તિ (Frequency) માં ફેરફાર થાય છે.
PM માં વાહકની કળા (Phase) માં ફેરફાર થાય છે.
🔑 FM એ AM કરતાં વધુ noise-resistance ધરાવે છે — તેથી FM રેડિયો વધુ સ્પષ્ટ.
📉 AM — મોડ્યુલેશન સ્થિરાંક (Modulation Index μ)
મોડ્યુલેશન સ્થિરાંક μ = A_m / A_c , જ્યાં A_m = સંદેશ સંકેતનો વિસ્તાર, A_c = વાહક તરંગનો વિસ્તાર.
μ ≤ 1 હોવું જોઈએ; જો μ > 1 હોય તો વિકૃતિ (Distortion) આવે છે.
100% મોડ્યુલેશન એટલે μ = 1.
μ = A_m / A_c = (A_max − A_min) / (A_max + A_min)
🔑 μ = 1 હોય ત્યારે જ સંપૂર્ણ મોડ્યુલેશન; μ > 1 એ વિકૃતિનું કારણ બને છે.
📝 ⚡ μ ≥ 1 એ ભૂલ છે — AM માં સદા μ < 1.
🌊 AM તરંગનું સમીકરણ અને આવૃત્તિ સ્પેક્ટ્રમ
AM તરંગનું સામાન્ય સમીકરણ: s(t) = [A_c + A_m cos(ω_m t)] cos(ω_c t)
s(t) = A_c[1 + μ cos(ω_m t)] cos(ω_c t)
AM તરંગમાં ત્રણ આવૃત્તિ ઘટકો હોય છે: ω_c (વાહક), ω_c + ω_m (ઉપરનો sideband), ω_c − ω_m (નીચેનો sideband).
AM આવૃત્તિઓ: f_c, f_c + f_m, f_c − f_m
વાહક આવૃત્તિ f_cમૂળ સંકેત ધરાવતો નથી — માહિતી બંને sidebands માં
Upper Sideband (USB)f_c + f_m
Lower Sideband (LSB)f_c − f_m
⚡ AM તરંગમાં પાવર (Power in AM Wave)
AM તરંગનું કુલ પાવર: P_total = P_c (1 + μ²/2)
P_total = P_c + P_USB + P_LSB = P_c(1 + μ²/2)
P_c = વાહક તરંગનું પાવર (A_c²/2R), R = ભાર પ્રતિબંધ (Load resistance).
USB અને LSB માં પાવર સમાન હોય છે.
🔑 μ = 1 હોય ત્યારે પાવર વધારો મહત્તમ થાય છે — P_total = 1.5 P_c.
📝 ⚡ AM માં જ्यादात પાવર wastage થાય છે — સાઇડબેન્ડ જ માહિતી ધરાવે.
📻 AM — ડિમોડ્યુલેશન (Demodulation)
AM સંકેત પાછો મેળવવાના પ્રક્રિયાને ડિમોડ્યુલેશન કહે છે.
સૌથી સામાન્ય ડિમોડ્યુલેટર: ડાયોડ ડિમોડ્યુલેટર (Envelope Detector).
ડિમોડ્યુલેશનમાં RC સમય અચળાંકનો યોગ્ય પસંદગી જરૂરી છે.
RC ≥ 1/f_m — RC સમય અચળાંક મોટો હોવો જોઈએ (સંદેશ આવૃત્તિથી)
ડાયોડ અર્ધ-તરંગ rectification કરે છે, RC filter envelope (આવરી) પસાર કરે છે.
🔑 Envelope detector એ AM ડિમોડ્યુલેશનનું સરળ અને વ્યાપક ઉપકરણ છે.
🔊 FM — આવૃત્તિ મોડ્યુલેશન
FM માં સંદેશ સંકેતના વિસ્તારને anુપાતમાં વાહકની તરંગની આવૃત્તિ બદલાય છે.
FM નું સમીકરણ: s(t) = A_c cos[ω_c t + β sin(ω_m t)]
β = Δf / f_m — Δf = મહત્તમ આવૃત્તિ વિચલન (frequency deviation)
FM માં β = 1 હોય તો Narrow band FM; β >> 1 હોય તો Wide band FM.
FM માં noise ઓછો પડે છે — amplitude distortion from noise ફ્લોઅરમાં આવતો નથી.
FM બેન્ડવિડ્થ ≈ 2(Δf + f_m) (Carson's rule)
🔑 FM રેડિયો 88 MHz થી 108 MHz બેન્ડમાં કામ કરે છે.
📝 ⚡ FM નું વિસ્તાર-અનુપાત μ = 0 (અંશતઃ) — FM માં μ ની જગ્યાએ β.
📡 ઉપગ્રહ સંચાર (Satellite Communication)
ઉપગ્રહ સંચારમાં C-band અને Ku-band વપરાય છે.
GEOSynchronous ઉપગ્રહ પૃથ્વીની સપાટીથી ~35,786 km ઊંચાઈએ orbટ કરે છે.
ત્રણ geosynchronous ઉપગ્રહો પૂરતા છે — વિશ્વવ્યાપી સંચાર.
uplink આવૃત્તિ: 5.9–6.4 GHz; downlink આવૃત્તિ: 3.7–4.2 GHz
C-band: 4–8 GHz; Ku-band: 12–18 GHz — બંને ઉપગ્રહ સંચારમાં વપરાય.
🔑 ઉપગ્રહ repeater તરીકે કામ કરે છે — ઉપરેલ સિગ્નલ પાછું ફેરવે છે (frequency conversion સાથે).
📝 ⚡ 3 geostationary satellites cover entire Earth — standard textbook claim.
🌐 ઈન્ટરનેટ અને ઇલેક્ટ્રોનિક મીડિયા
ઈન્ટરનેટ — વિશ્વભરના કમ્પ્યુટરને જોડતી netવર્ક પ્રણાલી.
ISP (Internet Service Provider) — ઈન્ટરનેટ સર્વિસ પ્રદાતા.
OTT પ્લેટફોર્મ્સ (Over-The-Top): Netflix, Amazon Prime વગેરે.
Electronic media: ટીવી, રેડિયો, ઈન્ટરનેટ — સંચારના ત્રણ મુખ્ય માધ્યમ.
Optical fiber: n_core > n_cladding → total internal reflection
Optical FiberData传输 via light pulses — high bandwidth, low loss
🔑 Optical fiber સંચારમાં information loss ખૂબ ઓછો — આધુનિક યુગની રીત.
📝 જરૂરી તથ્યો અને quick revision points
AM: μ = A_m/A_c ; P_total = P_c(1 + μ²/2); Sidebands at f_c ± f_m.
FM: β = Δf/f_m ; Bandwidth = 2(Δf + f_m); Noise immunity વધુ.
રેખા દ્રષ્ટિ અંતર: d = √(2Rh).
ભૂમિ તરંગ: ≤ 2 MHz; આયનોસ્ફિયર: 2–30 MHz; Line-of-sight: VHF/UHF+.
c = 3 × 10⁸ m/s (તરંગનો વેગ, શૂન્યાવકાશમાં)
fm = 1/(4√(LC)) — લૉર રેઝોનેન્સ ( Tuning condition )
🔑 AM કરતાં FM વધુ effective છે — FM નો ઉપયોગ广播 (Broadcasting) માં.
📝 ⚡ Numerical: μ = (A_max − A_min)/(A_max + A_min) યાદ રાખો — often asked!
📋 મહત્વના numerical types
Type 1: μ શોધો — μ = A_m/A_c અથવા (A_max − A_min)/(A_max + A_min).
Type 2: AM પાવર — P_total = P_c(1 + μ²/2).
Type 3: રેખા દ્રષ્ટિ અંતર — d = √(2Rh).
Type 4: FM બેન્ડવિડ્થ — Carson's rule B = 2(Δf + f_m).
Type 5: ઉપગ્રહ આવૃત્તિ પ્રશ્નો — uplink/downlink બેન્ડ યાદ રાખો.
d_max = √(2Rh) + √(2Rh') — બે એન્ટેના વચ્ચે અંતર
🔑 AM પાવર પ્રશ્નોમાં P_c = V_c²/2R લગાડો — R = 50 Ω or 75 Ω typical.
📝 ⚡ R values: antenna load રહ્યું છે — યાદ રાખો 50 Ω અને 75 Ω.
