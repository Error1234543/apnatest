ગતિના નિયમો — સૂત્ર પત્રક

🩺 NEET UG — Gujarati • Physics • Laws of Motion

⚡ સૂત્રો

ન્યૂટનનો દ્વિતીય નિયમ (બળ): F = ma
F = અનુભવાયેલું નિરપેક્ષ બળ (Net Force), m = વસ્તુનું દળ, a = પ્રવેગ · SI: newton (N) અથવા kg·m/s² · જ્યારે નેટ બળ શૂન્ય ન હોય; જડત્વ ચaranframe માં લાગુ પડતી નથી
વેગભૌતિક (Momentum): p = mv
p = વેગભૌતિક, m = દળ, v = વેગ · SI: kg·m/s · અચળ દળ માટે; ચોકસાઈથી વેગ p = mv તરીકે વ્યાખ્યાયિત
બળની વેગભૌતિક સાથે જોડાણ: F = dp/dt
F = બળ, dp/dt = વેગભૌતિકમાં સમય સાથે થતો ફેરફાર · SI: N (kg·m/s²) · સામાન્ય રૂપ; જ્યારે દળ પણ બદલાતું હોય (જેમ કે રોકેટ)
અવેગ (Impulse): J = F_avg × Δt = Δp = m(v − u)
J = અવેગ, F_avg = સરેરાશ બળ, Δt = બળ લાગવાનો સમયગાળો, Δp = વેગભૌતિકમાં ફેરફાર, u = પ્રારંભિક વેગ, v = અંતિમ વેગ · SI: N·s અથવા kg·m/s · જ્યારે બળ સમય સાથે ફેરવાતું હોય; F_avg એ સરેરાશ મૂલ્ય
સ્થિત ઘર્ષણ બળ (Static Friction): f_s ≤ μ_s N
f_s = સ્થિત ઘર્ષણ બળ, μ_s = સ્થિત ઘર્ષણાંક, N = અભિલંબ પ્રપીડન બળ (Normal Reaction) · SI: N · વસ્તુ સ્થિર હોય; ઘર્ષણ બળ સૌથી વધુ f_s(max) = μ_s N સુધી હોઈ શકે
ગતિ ઘર્ષણ બળ (Kinetic Friction): f_k = μ_k N
f_k = ગતિ ઘર્ષણ બળ, μ_k = ગતિ ઘર્ષણાંક, N = અભિલંબ પ્રપીડન બળ · SI: N · વસ્તુ સરકતી/ફिसલતી હોય; μ_k < μ_s હંમેશા
ઢાળ પર વિશ્રામી દળ — અભિલંબ બળ અને ઘર્ષણ: N = mg cosθ ; f = mg sinθ (વિશ્રામ)
N = અભિલંબ પ્રપીડન બળ, θ = ઢાળનો કોણ, f = સ્થિત ઘર્ષણ બળ · SI: N · ઢાળ પર સ્થિર મૂકેલી વસ્તુ માટે; f ≤ μ_s N
ઢાળ પર પહોળાયેલી ઘર્ષણ સાથે પ્રવેગ: a = g(sinθ − μ_k cosθ) (નીચે તરફ ફिसલાતી વખતે)
a = પ્રવેગ, θ = ઢાળનો કોણ, μ_k = ગતિ ઘર્ષણાંક, g = ગુરુત્વાકર્ષણ પ્રવેગ · SI: m/s² · જ્યારે વસ્તુ નીચે તરફ ઘર્ષણ સાથે ગલન કરતી હોય
ઘર્ષણ વિના ઢાળ પર પ્રવેગ: a = g sinθ
a = પ્રવેગ, g = ગુરુત્વાકર્ષણ પ્રવેગ, θ = ઢાળનો કોણ · SI: m/s² · ઘર્ષણ શૂન્ય હોય; વસ્તુ ઢાળની નીચેની તરફ ગતિ કરે
સીધા બાંધેલા બે ઘન (એક સપાટી પર, એક ટાંગેલી દોરી): a = m₂g/(m₁ + m₂) ; T = m₁m₂g/(m₁ + m₂)
a = પદાર્થોનો પ્રવેગ, T = દોરીમાં તણાવ, m₁ = સપાટી પરનું દળ, m₂ = લંબાતું દળ · SI: a → m/s² ; T → N · રિંગલ (pulley) અને દોરી દળવિહીન, ઘર્ષણ અને રિંગલ અવરોધ શૂન્ય
ઘર્ષણ સાથે બે ઘન પ્રવેગ અને તણાવ: a = (m₂g − μ m₁g)/(m₁ + m₂) ; T = m₁(a + μg)
μ = ઘર્ષણાંક (sપાટી માટે), a = પ્રવેગ, T = તણાવ, m₁ = સપાટી પર, m₂ = લંબાતું · SI: a → m/s² ; T → N · સપાટી પર ઘર્ષણ હોય, rringl અને દોરી આદર્શ
એટવુડ યંત્ર (Atwood Machine): a = (m₂ − m₁)g/(m₁ + m₂) ; T = 2m₁m₂g/(m₁ + m₂)
a = પ્રવેગ (મોટા દળની તરફ), T = દોરીમાં તણાવ, m₂ > m₁ · SI: a → m/s² ; T → N · બે દળ એક દળવિહીન, રગડરહિત rringl થી ટાંગેલ; ઘર્ષણ અને હવાનું અવરોધ નગણ્ય
ઓકકિનિયાલી (Observer) દ્રષ્ટિકોણ — આભાસી બળ (Pseudo Force): F_pseudo = −Ma
F_pseudo = આભાસી બળ, M = નિરીક્ષણ કરતા પદાર્થનું દળ, a = ત്વરિત ચaranframeનો પ્રવેગ · SI: N · ત્વરિત ચaranframe (non-inertial frame) માં ગણતરી કરતી વખતે વાપરવું
એકસમાન ગતિમાં ગતિશીલ લંઘન (Uniform Circular Motion — Centripetal Force): F_c = mv²/r = mω²r
F_c = કેન્દ્રગામી બળ, v = રેખીય વેગ, ω = કોણીય વેગ, r = વર્તુળની ત્રિજ્યા · SI: N · વસ્તુ સમવ્યાસી વર્તુળમાં ગતિ કરતી હોય
આડી સપાટી પર વળાંક — ઘર્ષણ સાથે અવરોધક વેગ (Maximum Speed on Flat Curve): v_max = √(μ_s gr)
v_max = કુદરતી રીતે સરકાતી નહીં તેવો મહતમ વેગ, μ_s = સ્થિત ઘર્ષણાંક, g = ગુરુત્વાકર્ષણ પ્રવેગ, r = વળાંકની ત્રિજ્યા · SI: m/s · સપાટ (banking રહિત) રસ્તા પર વાહન વળાંક લેતી વખતે
banked (ઢાળિયું) રસ્તો — ઘર્ષણ વિના આદર્શ વેગ: v₀ = √(rg tanθ)
v₀ = આદર્શ વેગ (ઘર્ષણ રહિત), r = વળાંકની ત્રિજ્યા, g = ગુરુત્વાકર્ષણ પ્રવેગ, θ = banking angle · SI: m/s · ઘર્ષણ વિના, વાહનને સાઇડ સરકાતી ન કરે તેવો વેગ
banked રસ્તો — ઘર્ષણ સાથે મહતમ વેગ: v_max = √[rg (tanθ + μ_s)/(1 − μ_s tanθ)]
v_max = મહતમ વેગ, θ = banking angle, μ_s = સ્થિત ઘર્ષણાંક, r = ત્રિજ્યા, g = ગુરુત્વાકર્ષણ પ્રવેગ · SI: m/s · વાહન ઉંચી તરફ સરકાતી ન કરે; θ એ banking angle
banked રસ્તો — ઘર્ષણ સાથે લઘુતમ વેગ: v_min = √[rg (tanθ − μ_s)/(1 + μ_s tanθ)]
v_min = લઘુતમ વેગ (નીચે તરફ ન સરકે), θ = banking angle, μ_s = સ્થિત ઘર્ષણાંક · SI: m/s · વાહન નીચે તરફ સરકાતી ન કરે; જે વેગમાં ઘર્ષણની જરૂર ન પડે તે v₀ છે
સ્પ્રિંગ બળ (Hooke's Law): F = kx
F = સ્પ્રિંગ બળ, k = સ્પ્રિંગ અચળાંક (Spring Constant), x = વિસ્થાપન/વિસાકટ · SI: N (k → N/m) · લચકદારતાની મર્યાદા within Elastic Limit; x એ સંતુલન સ્થાનથી વિસ્થાપન
લંબગત (Perpendicular) સુવિધા — તણાવનું સૂત્ર (Angle θ): T = mg/(2cosθ) — જ્યારે બે સમાન દોરીઓથી મધ્યમાં જોડાણ
T = દરેક દોરીમાં તણાવ, m = દળ, g = ગુરુત્વાકર્ષણ પ્રવેગ, θ = દોરી અને અભિલંબ સાથેનો કોણ · SI: N · બે સમાન દોરીઓથી લટકતો પુંગાર્ધ; θ = 0 હોય તો T = mg/2
લઘુતમ તણાવ (Minimum Tension Condition): T_min = mg/(2cosθ) ; θ → 0 હોય તો T_min = mg/2
θ = દોરી અને અભિલંબ વચ્ચેનો કોણ · SI: N · સમાન બે દોરીઓના કિસ્સામાં; θ વધતાં T વધે
સંતુલન (Equilibrium) — એકલંબી (Concurrent) બળો: ΣF_x = 0 ; ΣF_y = 0 ; ΣF = 0
ΣF_x = આડી દિશામાં બળોનો સરવાળો, ΣF_y = ઊભી દિશામાં બળોનો સરવાળો · SI: N · વસ્તુ સ્થિર અથવા સમવેગથી ગતિ કરતી હોય; સંતુલન શરત

🔗 સંબંધો

  • બળ એ વેગભૌતિકમાં સમય સાથે થતો ફેરફાર છે: F = dp/dt; જો દળ અચળ હોય તો F = ma.
  • અવેગનું ક્ષેત્રફળ (F-t વક્રની નીચે) બરાબર વેગભૌતિકમાં ફેરફાર Δp થાય છે.
  • સ્થિત ઘર્ષણ બળ આપોઆપ ગુજરાતી બળની વિરુદ્ધ જરૂરિયાત મુજબ સમાયોજન પામે છે: f_s = applied force (જ્યાં સુધી f_s ≤ μ_s N).
  • બે ઘન પદ્ધતિમાં તણાવ T એ બંને દળોને જોડતી દોરીમાં સમાન હોય (દોરી દળવિહીન અને રિંગલ અઘર્ષણીય હોય તો).
  • એટવુડ યંત્રમાં a = (m₂ − m₁)g/(m₁ + m₂); જો m₁ = m₂ હોય તો a = 0, T = m₁g.
  • ઘર્ષણાંકનો આધાર સપાટીની પ્રકૃતિ પર છે, ક્ષેત્રફળ અને સરેરાશ વેગ પર નહીં (આશરે).
  • banked રસ્તા પર θ = tan⁻¹(v²/rg) થાય તો ઘર્ષણની જરૂર પડતી નથી; એટલેકે v₀ = √(rg tanθ) આદર્શ વેગ છે.

🎯 ટ્રિક્સ

એટવુડ યંત્રનું તણાવ તુરંત યાદ કરો: T = 2m₁m₂g/(m₁ + m₂); એ a = (m₂−m₁)g/(m₁+m₂) નો ઉપયોગ કર્યા વિના પરીક્ષામાં ઝડપી જવાબ.
બે ઘન (m₁ સપાટી પર, m₂ લંબાતું) માટે a = m₂g/(m₁+m₂) અને T = m₁m₂g/(m₁+m₂) — આ બે સૂત્રો યાદ કરો; ઘર્ષણ ઉમેરવા માટે ફક્ત a માં માત્ર m₂g ને બદલે (m₂g − μm₁g) કરો.
ઢાળ પર પ્રવેગ a = g(sinθ − μ cosθ) અને ઘર્ષણ વિના a = g sinθ — ઘર્ષણ હોય તો ફક્ત μ cosθ બાદ કરો.
સંતુલનની સમસ્યાઓમાં θ ખૂણા સાથે બળો હોય તો Lami's theorem (ત્રણ બળો સંતુલનમાં હોય ત્યારે F₁/sinα = F₂/sinβ = F₃/sinγ) ઝડપી જવાબ આપે.
સ્પ્રિંગ બળ F = kx માં x એ વિસ્થાપન છે, કુલ લંબાઈ નહીં — આ ભૂલ સામાન્ય છે.
banked રસ્તા પર θ → 90° (લંબગત) હોય તો v_max → ∞, પણ વાસ્તવિકતામાં μ અને મર્યાદા હોય છે.

⚠️ ભૂલો

ઘર્ષણ બળને હંમેશા μN લખવું — ખરેખર સ્થિત ઘર્ષણ f_s ≤ μ_s N છે; f_s એ હંમેશા μ_s N નહીં (અંતિમ મર્યાદા સુધી).
તણાવ T ને દરેક જગ્યાએ અલગ લખવું — દોરી દળવિહીન અને રિંગલ અઘર્ષણીય હોય તો સરળ દોરીમાં તણાવ સમાન હોય છે.
સંતુલનમાં F = ma લખવું — સંતુલનમાં a = 0 હોય છે, તેથી F_net = 0.
ઢાળ પર N = mg લખવું — ખરેખર N = mg cosθ, કારણ કે વજનનો ખડખાડ હિસ્સો ઢાળને લંબરૂપે દબાવે છે.
અવેગ J = FΔt માં F એ સરેરાશ બળ લેવું જોઈએ; જો બળ અચળ ન હોય તો J = ∫F dt.
Pseudo force ની દિશા ચાર્તફ્રેમના પ્રવેગની વિરુદ્ધ લખવી — F_pseudo = −Ma, એટલે ધન દિશામાં પ્રવેગ હોય તો આભાસી બળ ઋણ દિશામાં.
Centripetal force ને અલગ બળ તરીકે FBD માં દોરવું — કેન્દ્રગામી બળ અલગ બળ નથી, તે અન્ય બળોનું નિર્દેશીય અવયવ છે.
Banked રસ્તાના સૂત્રમાં v = √(μgr) લખવું — આ ફક્ત સપાટ રસ્તાનું મહતમ વેગ છે; banked રસ્તા માટે v₀ = √(rg tanθ).
