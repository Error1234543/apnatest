આદર્શ વાયુ અને ગતિજ સિદ્ધાંત (Behaviour of Perfect Gas and Kinetic Theory)

🩺 NEET UG — Gujarati • Physics • Behaviour of Perfect Gas and Kinetic Theory

1. આદર્શ વાયુનો પરિચય
વાયુના કણો એકબીજાથી દૂર હોય છે અને તેમની વચ્ચે આકર્ષણ-બળ નહિવત હોય છે.
આદર્શ વાયુ (Ideal Gas) એ એક સૈદ્ધાંતિક રૂપ છે; વાસ્તવિક વાયુઓ ઊંચા તાપમાન અને નીચા દબાણે આદર્શ વર્તન દર્શાવે છે.
PV = nRT
📝 R = 8.314 J mol⁻¹ K⁻¹ (વાયુ અચળાંક)
2. વાયુ નિયમોનો સંગ્રહ
બોયલનો નિયમ: સ્થિર તાપમાને P ∝ 1/V (અથવા PV = અચળ)
ચાર્લ્સનો નિયમ: સ્થિર દબાણે V ∝ T (અથવા V/T = અચળ)
આવોગેડ્રોનો નિયમ: સમાન તાપમાન અને દબાણે સમાન કદમાં સમાન અણુઓની સંખ્યા હોય.
સંયુક્ત વાયુ નિયમ: PV/T = અચળ → PV = nRT (એકતા સમીકરણ)
n = m/M = N/Nₐ
3. ગતિજ સિદ્ધાંતના પરિકલ્પનાઓ
વાયુ અસંખ્ય સૂક્ષ્મ કણો (અણુઓ/પરમાણુઓ) નો બનેલો છે જે સતત યાદચ્છિક ગતિ કરે છે.
કણોની કુલ ક્રિયાશીલ કદ ઓછું ગણી શકાય.
કણો વચ્ચેનું આકર્ષણ-બળ નગણ્ય છે (ટકરાવ સિવાય).
ટકરાવ સંપૂર્ણપણે સ્થિતિસ્થાપક છે → ગતિજ ઊર્જા સંરક્ષિત રહે છે.
📝 તાપમાન એ સરેરાશ ગતિજ ઊર્જાનું માપ છે.
4. દબાણનું ગતિજ સૂત્ર
વાયુનું દબાણ એ દીવાલ પર અણુઓના ટકરાવથી થતા વેગમાન ફેરફારનું પરિણામ છે.
P = (1/3)·(N/V)·m·vᵣₘₛ²
P = (1/3)·ρ·vᵣₘₛ² (ρ = ઘનતા)
vᵣₘₛ એ વર્ગમાધ્યસ્થ (Root Mean Square) વેગ છે.
📝 ઈકમલ આંતરરાષ્ટ્રીય એકમ: N/m² = Pa
5. અણુની ગતિજ ઊર્જા
એક અણુની સરેરાશ ગતિજ ઊર્જા (KE) પ્રત્યેક મુક્તિના અંશ (degree of freedom) માટે (1/2)kT હોય છે.
KE₁ અણુ = (3/2)·k_B·T ( એક પરમાણ્વીય વાયુ )
KE_કુલ = (3/2)·n·R·T
k_B = R/Nₐ = 1.38×10⁻²³ J/K (બોલ્ટ્ઝમેન અચળાંક)
તાપમાન વધારોસરેરાશ ગતિજ ઊર્જામાં વધારો
6. સમભાજન પ્રમેય (Equipartition Theorem)
સામાન્ય સમતોલનમાં, દરેક સ્વતંત્ર મુક્તિના અંશને (1/2)kT જેટલી ગતિજ ઊર્જા મળે છે.
એકપારમાણ્વીય: f = 3 (કેવલ રેખીય) → KE = (3/2)kT
દ્વિપારમાણ્વીય: f = 5 (298 K પાસે) → KE = (5/2)kT
બહુપારમાણ્વીય (રેખીય ન હોય): f = 6 (298 K પાસે) → KE = 3kT
📝 કંપન મુક્તિના અંશો ઊંચા તાપમાને સક્રિય થાય છે.
7. વિશિષ્ટ ઉષ્મા ધારિતા
સ્થિર કદે મોલર ઉષ્મા ધારિતા: C_V = (f/2)R
સ્થિર દબાણે મોલર ઉષ્મા ધારિતા: C_P = C_V + R = (f/2 + 1)R
ગેટ (γ) = C_P / C_V = (f+2)/f
એકપારમાણ્વીય: γ = 5/3 ≈ 1.67 | દ્વિપારમાણ્વીય: γ = 7/5 = 1.4
C_P – C_V = R (મેયરનો સંબંધ)
8. વાયુ અણુઓના વેગ
વર્ગમાધ્યસ્થ વેગ: vᵣₘₛ = √(3RT/M) = √(3P/ρ)
સરેરાશ વેગ: v_avg = √(8RT/πM)
સંભાવ્ય વેગ: v_mp = √(2RT/M)
ક્રમ: v_mp < v_avg < vᵣₘₛ
vᵣₘₛ : v_avg : v_mp = √3 : √(8/π) : √2
📝 સમાન તાપમાને હલકા વાયુનો vᵣₘₛ વધુ હોય છે.
9. મેક્સવેલ-બોલ્ટ્ઝમેન વિતરણ
નિશ્ચિત તાપમાને વાયુ અણુઓના વિવિધ વેગ ધરાવે છે; દરેક વેગની સંભાવના બિંદુ આલેખ દ્વારા દર્શાવવામાં આવે છે.
તાપમાન વધારતા આલેખની ચૂડી જમણી તરફ ખસે છે અને પહોળી બને છે.
સંભાવના ઘનતા f(v) ∝ v²·exp(–mv²/2kT)
📝 ચૂડી પાસેનો વેગ = સંભાવ્ય વેગ (v_mp)
10. મુક્ત પથ (Mean Free Path)
બે ક્રમિક ટકરાવ વચ્ચે અણુ દ્વારા કપાયેલું સરેરાશ અંતર λ.
λ = 1 / (√2·π·d²·N/V)
d = અણુનો વ્યાસ; N/V = એકમ કદમાં અણુઓની સંખ્યા
📝 દબાણ ઘટતા λ વધે છે.
11. સાંદ્રતા અને વાયુનો વેગ
વાયુની સાંદ્રતા C = N/V = P/(k_B·T)
vᵣₘₛ ∝ √(T/M) અને vᵣₘₛ ∝ 1/√M
સમાન તાપમાને હલકા વાયુનો vᵣₘₛ ભારે વાયુ કરતાં વધુ હોય છે.
તાપમાન બમણુંvᵣₘₛ √2 ગણો
12. વાસ્તવિક વાયુ અને આદર્શ વાયુ
વાસ્તવિક વાયુઓમાં અણુઓ વચ્ચે આકર્ષણ બળ હોય છે અને તેમનું કદ ગણતરીમાં લેવું પડે છે.
(P + a/V²)(V – b) = RT (વાનડરવાલ્સ સમીકરણ)
a = આકર્ષણ બળનું માપ | b = અણુના કદનું માપ
📝 નીચા તાપમાને અને ઊંચા દબાણે વાસ્તવિક વાયુ આદર્શ સમીકરણથી હટી જાય છે.
13. ક્રાંતિક અવસ્થા (Critical State)
ક્રાંતિક તાપમાન T_c: તે તાપમાન જેના ઉપર વાયુનું પ્રવાહીકરણ શક્ય નથી.
T_c = 8a/(27Rb), P_c = a/(27b²), V_c = 3b
ક્રાંતિક વોકમિલ્ટી (Z_c) = P_c V_c/(R T_c) = 3/8 = 0.375
📝 Z = PV/RT (કોમપ્રેશિબિલિટી ગુણાંક)
14. NEET-ઉપયોગી મૂલ્યો અને તથ્યો
STP (પ્રમાણિત તાપમાન-દબાણ): T = 273 K, P = 1 atm = 1.013×10⁵ Pa
1 મોલ આદર્શ વાયુનું STP પર કદ = 22.4 L
Nₐ = 6.022×10²³ mol⁻¹
હવા (દ્વિપારમાણ્વીય): γ = 1.4, C_V = 5/2 R, C_P = 7/2 R
📝 હيليયમ (એકપારમાણ્વીય): γ = 1.67
15. સમૂહ શ્વસન સંબંધિત સૂત્રોનું સંકલન
વાયુનો દબાણ અને તાપમાન બદલાય ત્યારે PV^n = અચળ રૂપે સાદા પ્રક્રિયાઓ યાદ રાખો.
આદર્શ વાયુ: PV = nRT → P = ρRT/M
ગતિજ ઊર્જા K = (f/2) nRT → ઉષ્માધ ગતિજ સંબંધ
📝 f = મુક્તિના અંશોની સંખ્યા
16. પ્રયોગિક પાસાર (Experimental Background)
ગ્રેહામેનો વિસરણ નિયમ: વાયુનો વિસરણ દર ∝ 1/√(સાપેક્ષ અણુભાર)
Rate₁/Rate₂ = √(M₂/M₁)
ડાટનના આંશિક દબાણનો નિયમ: P_કુલ = P₁ + P₂ + …
આંશિક દબાણ P_i = x_i · P_કુલ (x_i = મોલ ભિન્ન)
17. NEET સ્તરના મહત્વના પ્રશ્નો
vᵣₘₛ, v_avg, v_mp ની ગણતરી અને સરખામણી
C_V, C_P, γ ની ગણતરી (એકપારમાણ્વીય/દ્વિપારમાણ્વીય/બહુપારમાણ્વીય)
વાનડરવાલ્સ સમીકરણનો ઉપયોગ કરીને T_c, P_c, V_c શોધવું
મેક્સવેલ વિતરણ વક્રના આકારમાં થતો ફેરફાર સમજવો
📝 પ્રશ્નોમાં એકમ રૂપાંતરણ (°C → K, atm → Pa) ધ્યાનમાં રાખો.
18. સારાંશ અને સૂત્ર સંગ્રહ
આદર્શ વાયુ: PV = nRT
vᵣₘₛ = √(3RT/M) = √(3P/ρ)
v_avg = √(8RT/πM)
v_mp = √(2RT/M)
C_V = (f/2)R, C_P = (f/2+1)R, γ = (f+2)/f
KE/અણુ = (f/2)k_BT
P = (1/3)(N/V)m·vᵣₘₛ²
વાનડરવાલ્સ: (P+a/V²)(V-b)=RT
દરેક સૂત્રના એકમો ચકાસો — NEET માં એકમ ભૂલો સામાન્ય છે.
