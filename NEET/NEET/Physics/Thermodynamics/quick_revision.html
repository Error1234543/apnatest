ઉષ્માગતિશાસ્ત્ર (Thermodynamics) — ઝડપી રિવિઝન શીટ

🩺 NEET UG — Gujarati • Physics • Thermodynamics

🧠 યાદ રાખો

ઉષ્માગતિશાસ્ત્ર ચાર મૂળભૂત નિયમો પર આધારિત છે; પ્રથમ, બીજો અને ત્રીજો નિયમ NEET માટે પ્રાથમિક છે.
ચાર પ્રકારના ઉષ્માગતિય પ્રક્રિયાઓ: સમતાપી (Isothermal), સમવિષયક (Adiabatic), સમદબાવી (Isobaric), સમકદ (Isochoric).
ઉષ્માગતિશાસ્ત્રનો પ્રથમ નિયમ: ΔU = Q - W; આ ઊર્જા સંરક્ષણનો નિયમ છે.
ઉષ્મા એ પથ ફલન (Path function) છે, કાર્ય પણ પથ ફલન છે; અંદરૂની ઊર્જા (U), એન્થાલપી (H), એન્ટ્રોપી (S) અવસ્થા ફલન (State function) છે.
કાર્નોટ ઇજનિનની કાર્યક્ષમતા η = 1 - (T₂ / T₁) હોય છે, જ્યાં T₁ > T₂; આ કાર્યક્ષમતા હંમેશા 1 (100%) થી ઓછી હોય છે.
એન્ટ્રોપી (Entropy) એ વ્યવસ્થાની અવ્યવસ્થાનું માપ છે; બંધ વ્યવસ્થામાં સ્વયંસ્ફૂર્ત પ્રક્રિયા માટે ΔS_total > 0.
આદર્શ વાયુ માટે: C_p - C_v = R અને γ = C_p / C_v. સમતાપી પ્રક્રિયામાં γ = 1 નહીં, પણ PV = અચળ; સમવિષયકમાં PV^γ = અચળ.

⚡ ઝડપી સૂત્રો

ΔU = Q - W (પ્રથમ નિયમ)
W = ∫ P dV; સમદબાવી પ્રક્રિયા: W = PΔV
સમતાપી પ્રક્રિયા (આદર્શ વાયુ): W = nRT ln(V₂/V₁) = 2.303 nRT log(V₂/V₁)
સમવિષયક પ્રક્રિયા: PV^γ = અચળ; W = (P₁V₁ - P₂V₂) / (γ - 1)
એન્થાલપી: H = U + PV; ΔH = ΔU + PΔV (સમદબાવી પ્રક્રિયા)
ઉષ્મા: Q = mcΔT; મોલર ઉષ્માધારિતા: C_v, C_p
કાર્યક્ષમતા: η = W / Q_in = 1 - Q_out / Q_in = 1 - T₂ / T₁ (કાર્નોટ)
એન્ટ્રોપી ફેરફાર: ΔS = Q_rev / T; ΔS_total = ΔS_system + ΔS_surroundings > 0

✅ વન-લાઈનર્સ

સમતાપી પ્રક્રિયામાં તાપમાન અચળ રહે છે; ΔU = 0 અને Q = W.
સમવિષયક પ્રક્રિયામાં ઉષ્મા આદાન-પ્રદાન શૂન્ય હોય છે; Q = 0 અને ΔU = -W.
સમદબાવી પ્રક્રિયામાં દબાણ અચળ રહે છે; વાયુએ કરેલું કાર્ય W = PΔV.
સમકદ પ્રક્રિયામાં કદ અચળ રહે છે; W = 0 અને ΔU = Q.
P-V આલેખમાં પ્રક્રિયા વક્ર તળેનું ક્ષેત્રફળ કરેલા કાર્યને દર્શાવે છે.
કાર્નોટ ઇજનિન એ આદર્શ ઇજનિન છે; તેની કાર્યક્ષમતા ફક્ત બે તાપમાન પર આધારિત છે.
ઉષ્માગતિશાસ્ત્રનો બીજો નિયમ મુજબ ઉષ્મા આપમેળે ગરમ શરીરથી ઠંડા શરીર તરફ જાય છે, વિપરીત નહીં.
