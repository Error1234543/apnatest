થર્મોડાયનેમિક્સ — નીટ UG એક્ઝામ ટ્રિક્સ

🩺 NEET UG — Gujarati • Physics • Thermodynamics

🎯 પરીક્ષા ટ્રિક્સ

PV આલેખ પર પ્રક્રિયા ઓળખવાની ટૂંકી રીત: સમભોજી (Isothermal) વક્રનો ઢાલ = −P/V, જ્યારે સમાવરોકી (Adiabatic) વક્રનો ઢાલ = −γP/V. તેથી સમાવરોકી વક્ર હંમેશા સમભોજી વક્ર કરતાં વધુ ચપટો (steeper) હોય છે.
જ્યારે PV આલેખમાં બે વક્રો આપેલા હોય અને પૂછે કે કયો વક્ર સમાવરોકી/સમભોજી છે.
દા.ત.: બે વક્ર A અને B જોવા મળે. A વધુ ચપટો છે → A સમાવરોકી, B સમભોજી.
ગેસ માટે Cv અને Cp વચ્ચેનો સંબંધ: Cp − Cv = R (Mendeleev-Clapeyron). દ્વિપારમાણ્વીય (diatomic) ગેસ માટે γ = 7/5 = 1.4; ત્રિપારમાણ્વીય (triatomic) γ ≈ 1.33; મોનૉૉ૱ટેમિક (monatomic) γ = 5/3 = 1.67. γ નું મૂલ્ય શીઘ્ર યાદ રાખો.
જ્યારે ગેસનો પ્રકાર આપેલો હોય અને Cp/Cv, Cv, અથવા γ શોધવાના હોય.
દા.ત.: H₂ ગેસ (દ્વિપારમાણ્વીય) માટે γ = 7/5, તેથી Cv = R/(γ−1) = R/(2/5) = 5R/2.
સમાવરોકી પ્રક્રિયામાં (Adiabatic): Q = 0, તેથી પ્રથમ નિયમ મુજબ W = −ΔU. જો ગેસ વિસ્તરણ કરે (W > 0), તો ΔU < 0 → તાપમાન ઘટે. વિপরીત: સંકોચન = તાપમાન વધે.
જ્યારે સવાલ કહે કે 'સમાવરોકી વિસ્તરણ' થાય છે અને તાપમાનમાં ફેરફાર પૂછે.
દા.ત.: સમાવરોકી વિસ્તરણમાં વાયુ દ્વારા કામ થાય → અંદરૂની ઊર્જા ઘટે → તાપમાન ઘટે. નોટ: તાપમાન વધે તેવો વિકલ્પ ખોટો.
Carnot એન્જિનની કાર્યક્ષમતા η = 1 − TL/TH (તાપમાન કેલ્વિનમાં). એન્જિનની કાર્યક્ષમતા વધારવાની રીત: TH વધારો અથવા TL ઘટાડો. TH વધારવાનો અસરકારકતા વધુ હોય છે કારણ કે TH છેદમાં છે.
Carnot એન્જિનની કાર્યક્ષમતામાં ફેરફાર કરવા માંગતાં કયા રસ્તે વધુ સુધારો થાય તે નક્કી કરવા.
દા.ત.: TH = 600 K, TL = 300 K → η = 0.5. જો TH વધારી 700 K કરીએ → η = 1−300/700 = 0.57. જો TL ઘટાડી 200 K કરીએ → η = 1−200/600 = 0.67. તેથી TL ઘટાડવો વધુ અસરકારક છે.
મુક્ત વિસ્તરણ (Free Expansion): બાહ્ય દબાણ Pext = 0, તેથી W = 0. સામાન્ય રીતે ઉષ્મારોધી હોય તેથી Q = 0. ∴ ΔU = 0 (આદર્શ ગેસ માટે). આ પ્રક્રિયા અનિવાર્યપણે અપ્રત્યાવર્તી (irreversible) છે.
જ્યારે આદર્શ ગેસનું મુક્ત વિસ્તરણ થાય અને ΔU, Q, W પૂછાય.
દા.ત.: આદર્શ ગેસનું મુક્ત વિસ્તરણ: W = 0, Q = 0, ΔU = 0 → તાપમાન અચળ રહે (Isothermal but not quasi-static).
ઉષ્મા ઇન્જિનની કાર્યક્ષમતા η = W/Q1 = 1 − Q2/Q1. જો કાર્ય W અને ઉષ્મા Q1 આપેલી હોય, તો Q2 = Q1 − W. ક્યારેય તાપમાન નોટે લખો અને કેલ્વિનમાં રૂપાંતરિત કરો.
ઉષ્મા ઇન્જિનમાં Q1, W, η માંથી અજ્ઞાત મૂલ્ય શોધવાનું હોય.
દા.ત.: η = 0.25, Q1 = 400 J → W = η×Q1 = 100 J, Q2 = 400 − 100 = 300 J.
સમદાબિત (Isobaric) પ્રક્રિયામાં વાયુ દ્વારા થતું કાર્ય: W = PΔV = nRΔT. સમઘનફળ (Isochoric) પ્રક્રિયામાં કાર્ય શૂન્ય. સમતાપી (Isothermal) પ્રક્રિયામાં ΔU = 0, તેથી W = Q = nRT ln(V2/V1).
વિવિધ પ્રક્રિયાઓમાં કાર્ય ગણવાનું હોય અને સૂત્ર યાદ રાખવું પડે.
દા.ત.: 2 mol આદર્શ ગેસ 300 K પર સમતાપી વિસ્તરણ V1→V2: W = nRT ln(V2/V1) = 2×8.314×300×ln(2) ≈ 3456 J.
એન્ડ્રે (Entropy) એ અવસ્થાચલ (State function) છે. એન્ડ્રે વેધક (adiabatic) પ્રક્રિયામાં ΔS = 0. અપ્રત્યાવર્તી (irreversible) પ્રક્રિયામાં એન્ડ્રે વધે છે (ΔS_universe > 0). ઉષ્મારોધી પ્રક્રિયા એંડ્રે બદલાતી નથી.
જ્યારે પ્રક્રિયા પ્રત્યાવર્તી છે કે અપ્રત્યાવર્તી તે નક્કી કરવાનું હોય અને એન્ડ્રે ફેરફાર પૂછે.
દા.ત.: આદર્શ ગેસનું સમાવરોકી પ્રત્યાવર્તી પ્રતિસંકોચન: ΔS = 0. પણ જો સ્વેచ్છ વિસ્તરણ થાય → ΔS > 0.
દ્વિપારમાણ્વીય આદર્શ ગેસ માટે નિશ્ચિત દબાણે ઉષ્માધારિતા C_p = 7R/2 અને નિશ્ચિત ઘનફળે C_v = 5R/2. મોનૉૉ૱ટેમિક: C_v = 3R/2, C_p = 5R/2. સ્થિર અણુઓની સંખ્યાના આધારે યાદ રાખો: દરેક સ્વતંત્રતાના અંશ (degree of freedom f) માટે C_v = fR/2.
વિવિધ ગેસોની C_v, C_p શોધવાની જરૂર પડે ત્યારે.
દા.ત.: N₂ (દ્વિપારમાણ્વીય) ની C_v = 5R/2, C_p = 7R/2, γ = 7/5.
ઉષ્મારોધી સાધન (Heat Pump / Refrigerator) ની COP: COP_R = TL/(TH − TL) જ્યારે COP_HP = TH/(TH − TL). ધ્યાન રાખો — COP > 1 હોઈ શકે છે. પ્રશ્નમાં TH અને TL કેલ્વિનમાં આપેલા હોય તો જ આ પ્રમાણે લાગુ કરો.
રેફ્રિજિરેટર અથવા હીટ પંપની COP શોધવાની હોય.
દા.ત.: TH = 300 K, TL = 250 K → COP_R = 250/(300−250) = 5. એટલે 1 J વીજળીએ 5 J ઠંડક મળે.
કોઈ પણ વળાંક (curve) નીચેનું ક્ષેત્રફળ PV આલેખમાં થયેલા કાર્યનું મૂલ્ય આપે છે. ક્ષેત્રફળ ધન方向માં (વિસ્તરણ) હોય → W > 0. ઋણ directionમાં (સંકોચન) → W < 0. વડા ચોરસ/ત્રિકોણ/સમલંબ પद्धતિથી ક્ષેત્રફળ ગણો.
PV ચતુષ્કોણમાં કુલ કાર્ય શોધવાનું હોય.
દા.ત.: A→B સમદાબિત વિસ્તરણ (P = 10 Pa, V: 1→3 m³): W = PΔV = 10×2 = 20 J.
દર્શક (Observer) ને ખબર ન હોય ત્યારે 'ગેસનું તાપમાન અચળ છે' એવા શબ્દો જોવા મળે → સમતાપી પ્રક્રિયા. 'ઉષ્માની આપ-લે નથી' → સમાવરોકી. 'દબાણ અચળ' → સમદાબિત. 'ઘનફળ અચળ' → સમઘનફળ.
પ્રશ્નમાં પ્રક્રિયાનો પ્રકાર સીધો જણાવ્યો ન હોય અને પ્રશ્નના શબ્દો પરથી પકડવાનો હોય.
દા.ત.: 'ગેસ ધીમે ધીમે સંકોચાય છે અને તાપમાન અચળ રહે છે' → સમતાપી પ્રક્રિયા, ΔU = 0.
જ્યારે ચક્ર (Cycle) પૂરું થાય ત્યારે અંદરૂની ઊર્જાનો ફેરફાર ΔU = 0 કારણ કે તે અવસ્થાચલ છે. તેથી ચક્રમાં કુલ ઉષ્મા = કુલ કાર્ય (Q_net = W_net).
ચક્રીય પ્રક્રિયા (Cyclic process) ના પ્રશ્નોમાં, જ્યાં ચારેય ભાગની ઉષ્મા આપેલી હોય.
દા.ત.: ચક્રમાં Q₁ = 200 J, Q₂ = −80 J, Q₃ = −50 J → Q_net = 70 J → W_net = 70 J.
બ્લેઝ પાસ્કલ (Blaise Pascal) નામનું ગૂંચવણ દૂર કરો: ઉષ્મા ચાલકતા (Thermal conductivity) k નું એકમ W·m⁻¹·K⁻¹ છે. તે ઊર્જા પ્રવાહ નહીં. ગ્રેગરી (Gregory) નો દર ≠ ઉષ્મા વહન.
જ્યારે એકમો અને માત્રાઓ ગૂંચવણ પેદા કરતી હોય અને કોઈ ચોક્કસ પ્રશ્ન આવતો હોય.
દા.ત.: કોઈપણ પ્રશ્નમાં 'k નો એકમ શું?' → W/(m·K) = W·m⁻¹·K⁻¹.
નોબલ ગેસ (noble gas) હંમેશા મોનૉૉ૱ટેમિક છે → γ = 5/3 ≈ 1.67. O₂, N₂, H₂, Cl₂, CO સૌ દ્વિપારમાણ્વીય છે → γ = 7/5 = 1.4. આ તથ્ય યાદ રાખો અને ગણતરી ઝડપી કરો.
જ્યારે ગેસનો પ્રકાર આપેલો હોય અને γ, C_p/C_v નું મૂલ્ય શોધવાનું હોય.
દા.ત.: He ગેસ (મોનૉૉ૱ટેમિક): γ = 5/3. CO₂ (રેખીય દ્વિપારમાણ્વીય જેવું): સિદ્ધાંતશઃ દ્વિપારમાણ્વીય. પરંતુ NEET માત્ર O₂, N₂, H₂ → γ = 1.4.
