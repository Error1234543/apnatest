પ્રણાલીકોશ (Ecosystem)

🩺 NEET UG — Gujarati • Biology • Ecosystem

પ્રણાલીકોશ (Ecosystem) – પરિચય
પ્રણાલીકોશ એ જૈવિક (Biotic) અને અજૈવિક (Abiotic) ઘટકો વચ્ચેની ક્રિયાપ્રતિક્રિયાનું સંયુક્ત તંત્ર છે.
આ શબ્દ પ્રથમ વખત ઇ. વિ. ટેન્સલી (A.G. Tansley) દ્વારા ૧૯૩૫માં ઉપયોગમાં લેવાયો હતો.
પ્રણાલીકોશ = જીવજડ પારિસ્થિતિકી (Ecology) નો મૂળભૂત એકમ છે.
જૈવિક ઘટક: સ્વયંભુ (પોષક), વિઘટક, વિભક્તકારી.
અજૈવિક ઘટક: પ્રકાશ, તાપમાન, આર્દ્રતા, મৃত્ટિ, ખनिज, વાયુઓ.
📝 📝 PYQ: પ્રણાલીકોશ શબ્દ કેણે રચ્યો? – ટેન્સલી
પ્રણાલીકોશના ઘટકો
૧. અજૈવિક ઘટકો: પ્રકાશ, તાપમાન, જળ, ખनिज પદાર્થો, વાયુઓ, મૃત્ટિ.
૨. જૈવિક ઘટકો: સ્વયંભુ (Autotrophs), પરોક્ષભોજી (Heterotrophs).
સ્વયંભુ = પ્રકાશસંશ્લેષણ કરનારા (ઉત્પાદક). પરોક્ષભોજી = પ્રાણીઓ (ભોક્તા).
અજૈવિક ઘટકોમાં વર્ષા, હવામાન, ભૂ-ભાગ અને રાસાયણિક ઘટકોનો સમાવેશ થાય છે.
જૈવિક ઘટકો વચ્ચે ફૂડ ચેઇન અને એનર્જી ફ્લો દ્વારા સંબંધ રહે છે.
📝 📌 યાદ રાખો: પ્રકાશ એ ઊર્જાનો પ્રાથમિક સ્રોત છે.
પોષણ સ્તરો (Trophic Levels)
પ્રથમ પોષણ સ્તર: સ્વયંભુ (ઉત્પાદક) – પ્રબોધ, શાકાહારી પાનખોર.
દ્વિતીય પોષણ સ્તર: પ્રાથમિક ભોક્તા – શાકાહારી પ્રાણીઓ.
તૃતીય પોષણ સ્તર: દ્વિતીયક ભોક્તા – માંસાહારી પ્રાણી.
ચતુર્થ પોષણ સ્તર: તૃતીયક ભોક્તા – શિખર અથવા ટોચના શિકારી.
દરેક પોષણ સ્તર પર ઊર્જાનો ~૧૦% નિયમ લાગુ પડે છે (લિંડમેનનો ૧૦% નિયમ).
લિંડમેનનો ૧૦% નિયમ: પરવર્તી પોષણ સ્તર ≈ અગલા સ્તરની ઊર્જા × ૧૦%
📝 ⚡ ઊર્જા પ્રવાહ એકદિશીય હોય છે – સૂર્ય → ઉત્પાદક → વિઘટક.
પોષણ શૃંખલા (Food Chain)
પોષણ શૃંખલા એ ઊર્જા અને પોષણનું એક પોષણ સ્તરથી બીજા સ્તરમાં સ્થાનાંતરણ છે.
પ્રકાર: ચારા પોષણ શૃંખલા (Grazing) અને વિઘટન પોષણ શૃંખલા (Detritus).
ચારા પોષણ શૃંખલા: પ્રબોધ → સસલું → સાપ → ચિલ્લર.
વિઘટન પોષણ શૃંખલા: મૃતજીવ → વિઘટક (બેક્ટેરિયા/ફંગસ) → ખनिજ.
પોષણ શૃંખલામાં શૃંખલાની લંબાઈ સામાન્ય રીતે ૪-૫ પોષણ સ્તરની હોય છે.
પ્રકાશસંશ્લેષણરાસાયણિક ઊર્જામાં રૂપાંતર
પોષણ જાળ (Food Web)
બહુવિધ પોષણ શૃંખલાઓનો આંતરસંબંધ પોષણ જાળ રચે છે.
પોષણ જાળ વાસ્તવિક પર્યાવરણમાં વધુ સ્થિર અને ટકાઉ હોય છે.
એક પ્રાણી એકથી વધુ પ્રજાતિઓને ખાય અને એકથી વધુ પ્રાણીઓ તેને ખાય.
પોષણ જાળ = એકીકૃત અને વક્રીય પોષણ સંબંધોનું ચિત્રણ.
📝 📌 પોષણ જાળની જટિલતા વધારે → સ્થિરતા વધારે.
ઉર્જા પираמיד (Pyramid of Energy)
ઉર્જા પирамикો દરેક પોષણ સ્તરે ઉપલબ્ધ ઊર્જાનો આલેખ છે.
ઈ ઓડમ (Odum) દ્વારા આ પираમિકની સ્થાપના કરવામાં આવી.
ઉર્જા પирамид હંમેશા સીધો ( upright ) હોય છે.
ઉત્પાદક સ્તર > ભોક્તા સ્તર > વિઘટક સ્તર – ઊર્જા સતત ઘટે છે.
ઉર્જા ગુમાવટ = શ્વસન + ઉષ્મા + અપચ્ય ભાગ (૧૦% નિયમ મુજબ)
📝 ⚠️ ઉર્જા пирамик એકમાત્ર સર્વદા સીધો પирамик છે.
બાયોમાસ пирамид (Pyramid of Biomass)
દરેક પોષણ સ્તરે મળતું કુલ સજીવ દળ (Biomass) દર્શાવે છે.
ચારા પирамид હંમેશા સીધા હોય છે.
સमुદ્રી પирамिक ઉલટો (inverted) હોઈ શકે છે.
સमुદ્રમાં: પ્લંકટન બાયોમાસ < ઉત્પાદક (ફાઇટોપ્લંકટન) બાયોમાસ ઉલટું.
📝 📝 ઉલટો બાયોમાस пирамिक: સમુદ્રી પ્રણાલીકોશમાં જોવા મળે છે.
આંક пираمид (Pyramid of Numbers)
દરેક પોષણ સ્તર પર સજીવોની સંખ્યા દર્શાવે છે.
ધ્યાનમાં લેવું: કદ અને બાયોમાસની ગણતરી થતી નથી.
પирамид સીધો હોઈ શકે (ઘાસ → સસલું → સાપ) અથવા ઉલટો હોઈ શકે.
વૃક્ષ પર બેસેલા અસંખ્ય કીટાણુઓ: એક મોટું વૃક્ષ → ઘણા સસલાં → ઉલટો пирамик.
📝 📌 આંક пирамид સમસ્યાગ્રસ્ત છે કારણ કે કદની તુલના નથી કરતો.
પ્રાથમિક ઉત્પાદન (Primary Productivity)
પ્રકાશસંશ્લેષણ દ્વારા ઊત્પાદક દ્વારા ઉત્પાદિત ઓર્ગેનિક પદાર્થોની માત્રા.
GPP ( Gross Primary Productivity ) = કુલ પ્રકાશસંશ્લેષણ દ્વારા ઉત્પન્ન ઊર્જા.
NPP ( Net Primary Productivity ) = GPP – શ્વસન દ્વારા વપરાતી ઊર્જા (R).
NPP = GPP – R (શ્વસન ગુમાવટ)
NPP એ જ ભોક્તાઓ માટે ઉપલબ્ધ ઊર્જા છે.
📝 📝 GPP > NPP હંમેશા.
વિઘટન (Decomposition)
વિઘટકો (બેક્ટેરિયા, ફંગસ) મૃત જૈવિક પદાર્થોનું વિઘટન કરી ખनिજ પદાર્થો મુક્ત કરે છે.
પ્રક્રિયાઓ: વિઘટન (Fragmentation) → વિઘટન (Leaching) → ક્ષયકરણ (Catabolism).
વિઘટન દરતાપમાન અને આર્દ્રતા પર આધાર રાખે છે.
ઉષ્ણકટિબંધીય પ્રદેશમાં વિઘટન ઝડપી; ધ્રુવીય પ્રદેશમાં ધીમું.
મૃત જંતુ/પાનખોરખनिज ખાદક તત્વો
📝 ⚡ વિઘટન થી પોષક તત્વો ફરી ચક્રમાં આવે છે.
પોષક ચક્ર (Nutrient Cycling)
પોષક તત્વો પર્યાવરણ અને જીવો વચ્ચે પુનરાવર્તન પામે છે.
મુખ્ય પોષક ચક્ર: કાર્બન ચક્ર, નાઇટ્રોજન ચક્ર, ફોસ્ફરસ ચક્ર, સલ્ફર ચક્ર.
વાયુમાળીય ચક્ર (Atmospheric) vs. જમાચક (Sedimentary) – બે પ્રકાર.
વાયુમાળીય ચક્ર: CO₂, N₂ (વાયુઓ સ્રોત). જમાચક: P, Ca (મૃત્ટિ સ્રોત).
📝 📌 પોષક ચક્ર જૈવિક ગુણાત્મક સંતુલન જાળવે છે.
કાર્બન ચક્ર (Carbon Cycle)
કાર્બનનું મુખ્ય ભંડાર વાતાવરણ (CO₂) અને સમુદ્રોમાં છે.
પ્રકાશસંશ્લેષણ: CO₂ + H₂O → ગ્લુકોઝ + O₂ (ઉત્પાદકો દ્વારા).
શ્વસન: ગ્લુકોઝ + O₂ → CO₂ + H₂O + ઊર્જા (સૌજીવો દ્વારા).
જળાશયો CO₂ નો મોટો સંગ્રહ તરીકે કામ કરે છે.
6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂ (પ્રકાશસંશ્લેષણ)
માનવકાર્યો: જેવન ઇંધણ, વનઉપાડાંનું કાપણ → CO₂ વધારો → ગ્રીનહાઉઝ અસર.
📝 📝 CO₂ વધારો → વિશ્વ તાપમાનમાં વધારો.
નાઇટ્રોજન ચક્ર (Nitrogen Cycle)
નાઇટ્રોજન વાતાવરણમાં ૭૮% N₂ તરીકે છે.
નાઇટ્રીકરણ (Nitrification): NH₃ → NO₂⁻ → NO₃⁻ (બેક્ટેરિયા દ્વારા: Nitrosomonas, Nitrobacter).
નાઇટ્રોજન સ્થાપન (Nitrogen Fixation): N₂ → NH₃ (Rhizobium, Azotobacter દ્વારા).
એમોનીફિકેશન: પ્રોટીન → NH₃ (વિઘટકો દ્વારા).
ડિનિટ્રીફિકેશન: NO₃⁻ → N₂ (ડિનિટ્રીફાઇંગ બેક્ટેરિયા દ્વારા).
N₂ --(Rhizobium)--> NH₃ --(Nitrosomonas)--> NO₂⁻ --(Nitrobacter)--> NO₃⁻
નાઇટ્રોજન સ્થાપન કાર્ય સિંબાયોસિસ (Rhizobium-અળવી વંશ) માં મહત્વપૂર્ણ છે.
📝 📌 નાઇટ્રોજન ચક્ર સૌથી જટિલ પોષક ચક્ર છે.
ફોસ્ફરસ ચક્ર (Phosphorus Cycle)
ફોસ્ફરસનો મુખ્ય સ્રોત ખડકો (Rock phosphates) છે.
ફોસ્ફરસ ચક્ર વાતાવરણીય રૂપ ધરાવતું નથી – સેડિમેન્ટરી ચક્ર.
ખડકોના વિઘટનથી PO₄³⁻ મુક્ત થાય છે જે સસારી સ્વરૂપે સંશોષિત થાય છે.
ફોસ્ફેટ્સ ઓછામાં ઓછું પોષક તત્વ છે જે પ્રામાણિક ઉત્પાદકોની મર્યાદા નક્કી કરે છે.
ફોસ્ફરસ ચક્રમાં ગેસીય સ્ટોરેજ નથી – ધીમું અને સંપૂર્ણ ચક્ર.
📝 ⚡ ડુનર ફોસ્ફેટ્સ ખાણકામ → ખાતર ઉદ્યોગ.
ઊર્જા પ્રવાહ (Energy Flow)
ઊર્જા પ્રવાહ એકદિશીય (unidirectional) છે – સૂર્ય → ઉત્પાદક → ભોક્તા → વિઘટક.
દરેક પોષણ સ્તરે ~૯૦% ઊર્જા ઉષ્મા રૂપે ગુમાવાય છે.
૧૦% ઊર્જા આગળના પોષણ સ્તર સુધી પહોંચે છે.
ઊર્જા પೈપલાઇન: S→P→H1→H2→H3 (પ્રત્યેક પગલે ~૯૦% ઉષ્મા ગુમાવટ)
ઊર્જા નવસર્જન કરી શકાતી નથી; સતત સૂર્યદ્વારા પુરી પાડવી પડે.
📝 📝 પ્રથમ થર્મોડાયનેમિક્સ નિયમ: ઊર્જા નવસર્જિત/વિનાશિત થઈ શકતી નથી.
પારિસ્થિતિકીય સફર (Ecological Succession)
સફર એ સમય સાથે સમુદાયમાં થતો બદલાવ છે જે એક સ્થિર અવસ્થા (climax community) તરફ આગળ વધે છે.
પ્રકાર: પ્રાથમિક સફર (Primary) અને દ્વિતીયક સફર (Secondary).
પ્રાથમિક સફર: ખાલી/નવા સપાટી પર (જ્વાળામુખી પથ્થર, બરફ ઓગળેલું).
દ્વિતીયક સફર: પહેલાથી અસ્તિત્વ ધરાવતા સમુદાય બાદ (આગ, ખેતર છોડયા બાદ).
પ્રાથમિક સફર ધીમી; દ્વિતીયક સફર ઝડપી (મૃત્ટિ પહેલેથી ઉપલબ્ધ).
📝 📌 સફરના તબક્કા: પાયનિયર → અંતર્ગત → ક્લાઇમેક્સ.
સફરના તબક્કાઓ (Successional Stages)
પાયનિયર સમુદાય (Pioneer community): જાળ (Lichens), મોસ (Bryophytes) પ્રારંભિક જીવો.
અંતર્ગત તબક્કો (Intermediate stages): ઘાસ, ઝાડિયા, વૃક્ષોનું આગમન.
ક્લાઇમેક્સ સમુદાય (Climax community): સ્થિર, સંતુલિત, સ્થાનિક હવામાન સાથે સંરેખિત.
બેરિ ( bare rock ) → જાળ → મોસ → ઘાસ → ઝાડિયા → વૃક્ષો → ક્લાઇમેક્સ
ક્લાઇમેક્સ સમુદાય સ્થિર હોય છે પણ અનંત સમય સુધી અલગ ન હોય.
જાળ/મોસમૃત્ટિ નિર્માણ કરે છે
મૃત્ટિઘાસ અને ઝાડિયા અનુકૂલન
પારિસ્થિતિકીય સેવાઓ (Ecological Services)
પ્રકૃતિ દ્વારા મનુષ્યતાને પૂરી પાડવામાં આવતી અનમોલ સેવાઓ.
સેવાઓ: હવામાન નિયંત્રણ, જળ શુદ્ધિકરણ, મૃત્ટિ નિર્માણ, પરિશ્રમ પરાગસ્પર્શ.
બોબિ યાન (Costanza et al.) દ્વારા પારિસ્થિતિકીય સેવાઓનો મૂલ્યાંકન કરવામાં આવ્યો.
પ્રકૃતિ સેવાઓની કિંમત ખરેખર અસંખ્ય ડોલર વાર્ષિક છે.
📝 🌍 પારિસ્થિતિકીય સેવાઓ વગર જીવન અશક્ય.
સંતુલન અને સ્થિરતા
પ્રણાલીકોશની સ્થિરતા એટલે બાહ્ય દખલગીરી બાદ પુનઃપ્રાપ્તિની ક્ષમતા.
જટિલ સમુદાયો વધુ સ્થિર હોય છે (વૈવિધ્યમય જીવજાળ = વધુ સ્થિરતા).
પ્રતિરોધ (Resilience) અને પ્રતિરોધ (Resistance) – બે પ્રકારની સ્થિરતા.
વૃક્ષીય વન (Tropical rainforest) = ઊંચું વૈવિધ્ય + ઊંચી સ્થિરતા.
📝 📝 પ્રતિરોધ = બાધા પ્રતિકાર; પ્રતિરોધ = પુનઃસ્થાપન.
મહત્વના પ્રશ્નો – સંક્ષિપ્ત સારાંશ
પ્રણાલીકોશ શબ્દ ઇ. વિ. ટેન્સલી (૧૯૩૫) દ્વારા પ્રસ્તાવિત.
૧૦% નિયમ લિંડમેન (Lindeman) દ્વારા રજૂ કરવામાં આવ્યો.
ઉર્જા пирамик સર્વદા સીધો; બાયોમાસ પирамид ઉલટો પણ થઈ શકે.
કાર્બન ચક્ર: પ્રકાશસંશ્લેષણ/શ્વસન/દહન.
નાઇટ્રોજન ચક્ર: સ્થાપન, નાઇટ્રીકરણ, એમોનીફિકેશન, ડિનિટ્રીફિકેશન.
ફોસ્ફરસ ચક્ર: સેડિમેન્ટરી (ખડકો સ્રોત).
પ્રણાલીકોશ એ પારિસ્થિતિકીનો મૂળભૂત એકમ – પ્રકાશસંશ્લેષણથી વિઘટન સુધીનું ચક્ર.
