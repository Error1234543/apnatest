જૈવ-અણુઓ (Biomolecules) — NEET UG ગુજરાતી: પરીક્ષા ટ્રિક્સ

🎯 પરીક્ષા ટ્રિક્સ

પ્રોટીનમાં N (નાઇટ્રોજન)ની ટકાવારી ૧૬% હોવાનું લક્ષણ યાદ રાખો. જો કોઈ પદાર્થમાં Nની ટકાવારી ≈૧૬% હોય તો તે પ્રોટીન છે.
પ્રોટીન, કાર્બોહાઇડ્રેટ, ચરબી વચ્ચે ઓળખવાની પરીક્ષામાં.
દા.ત.: એક પદાર્થમાં ૧૫.૫% N મળે છે → તે પ્રોટીન જ છે (કાર્બોહાઇડ્રેટ/ચરબીમાં N હોતું નથી).
મોનોસેકેરાઇડ્સ (Monosaccharides) હંમેશા CₙH₂ₙOₙ ફોર્મ્યુલા ધરાવે છે. જો ફોર્મ્યુલામાં H અને Oની સંખ્યા સરખી ન હોય તો તે મોનોસેકેરાઇડ નથી.
શર્કરાના પ્રકાર ઓળખવા માટે.
દા.ત.: C₆H₁₂O₆ (ગ્લુકોઝ) → મોનોસેકેરાઇડ; C₁₂H₂₂O₁₁ (સુક્રોઝ) → ડાઇસેકેરાઇડ.
એમિનો એસિડમાં કમપલ્સરી (Essential) એમિનો એસિડની સંખ્યા ૧૦ યાદ રાખો. જો પ્રશ્નમાં એમિનો એસિડની સંખ્યા પૂછે તો ૨૦ કુલમાંથી ૧૦ કમપલ્સરી છે.
એમિનો એસિડ સંબંધી પ્રશ્નોમાં.
દા.ત.: મનુષ્ય માટે કેટલા એમિનો એસિડ કમપલ્સરી છે? → ૧૦.
લિપિડ્સ (ચરબી) પાણીમાં અદ્રાવ્ય (Insoluble) હોવા છતાં ઇથર, ક્લોરોફોર્મ જેવા સોલ્વન્ટમાં દ્રાવ્ય હોય છે. જો પદાર્થ પાણીમાં અદ્રાવ્ય અને સેન્દ્રિય સોલ્વન્ટમાં દ્રાવ્ય હોય તો તે લિપિડ છે.
પદાર્થનો વર્ગ ઓળખવા માટે.
દા.ત.: એક પદાર્થ પાણીમાં નથી દ્રાવતો પરંતુ ઇથરમાં દ્રાવે છે → લિપિડ.
ડી.એન.એ. (DNA) અને આર.એન.એ. (RNA) વચ્ચેનો તફાવત: DNAમાં શર્કરા ડિઓક્સીરાઇબોઝ (Deoxyribose) અને નાઇટ્રોજન બેઇઝ થાયમિન (Thymine) હોય છે, જ્યારે RNAમાં રાઇબોઝ (Ribose) અને યુરેસિલ (Uracil) હોય છે.
ન્યુક્લિક એસિડ સંબંધી પ્રશ્નોમાં.
દા.ત.: જો નાઇટ્રોજન બેઇઝમાં યુરેસિલ હોય તો તે RNA છે.
પોલિસેકેરાઇડ્સ (Polysaccharides)માં ગ્લાઇકોસિડિક બંધ (Glycosidic bond) હોવો જરૂરી છે. જો પ્રશ્નમાં બંધનો પ્રકાર પૂછે તો ગ્લાઇકોસિડિક બંધ જવાબ છે.
શર્કરાના બંધ સંબંધી પ્રશ્નોમાં.
દા.ત.: સ્ટાર્ચમાં કયો બંધ જોવા મળે છે? → ગ્લાઇકોસિડિક બંધ.
પ્રોટીનની પ્રાથમિક રચના (Primary structure)માં એમિનો એસિડની ક્રમબદ્ધતા (Sequence) મહત્વની હોય છે. જો પ્રશ્ન પ્રાથમિક રચના વિશે પૂછે તો એમિનો એસિડનો ક્રમ જવાબ છે.
પ્રોટીનની રચના સંબંધી પ્રશ્નોમાં.
દા.ત.: પ્રોટીનની પ્રાથમિક રચના શું દર્શાવે છે? → એમિનો એસિડનો ક્રમ.
વિટામિન C (એસ્કોર્બિક એસિડ) પાણીમાં દ્રાવ્ય વિટામિન છે અને તે એન્ટી-ઑક્સિડન્ટ (Antioxidant) તરીકે કામ કરે છે. જો પ્રશ્નમાં પાણીમાં દ્રાવ્ય વિટામિન પૂછે તો વિટામિન B અને C યાદ રાખો.
વિટામિન સંબંધી પ્રશ્નોમાં.
દા.ત.: કયા વિટામિન પાણીમાં દ્રાવ્ય છે? → વિટામિન B અને C.
એન્ઝાઇમ્સ (Enzymes) પ્રોટીન હોય છે અને તેઓ બાયોકેટેલિસ્ટ (Biocatalyst) તરીકે કામ કરે છે. જો પ્રશ્નમાં બાયોકેટેલિસ્ટ પૂછે તો એન્ઝાઇમ જવાબ છે.
એન્ઝાઇમ સંબંધી પ્રશ્નોમાં.
દા.ત.: જૈવિક ઉત્પ્રેરકને શું કહેવાય છે? → એન્ઝાઇમ.
ન્યુક્લિક એસિડમાં ફોસ્ફેટ સમૂહ (Phosphate group), શર્કરા (Sugar), અને નાઇટ્રોજન બેઇઝ (Nitrogenous base) હોય છે. જો પ્રશ્નમાં ન્યુક્લિક એસિડના ઘટકો પૂછે તો આ ત્રણ યાદ રાખો.
ન્યુક્લિક એસિડ સંબંધી પ્રશ્નોમાં.
દા.ત.: ન્યુક્લિક એસિડના ઘટકો કયા કયા છે? → ફોસ્ફેટ, શર્કરા, નાઇટ્રોજન બેઇઝ.
ચરબી (Fats) અને તેલ (Oils) વચ્ચેનો તફાવત: ચરબી ઘન (Solid) અને તેલ પ્રવાહી (Liquid) હોય છે. જો પ્રશ્નમાં લિપિડના પ્રકાર પૂછે તો આ તફાવત યાદ રાખો.
લિપિડ સંબંધી પ્રશ્નોમાં.
દા.ત.: ચરબી અને તેલ વચ્ચેનો મુખ્ય તફાવત શું છે? → ભૌતિક અવસ્થા (ઘન vs. પ્રવાહી).
પ્રોટીનની દ્વિતીય રચના (Secondary structure)માં આલ્ફા-હેલિક્સ (Alpha-helix) અને બીટા-પ્લીટેડ શીટ (Beta-pleated sheet) હોય છે. જો પ્રશ્ન દ્વિતીય રચના વિશે પૂછે તો આ બંને યાદ રાખો.
પ્રોટીનની રચના સંબંધી પ્રશ્નોમાં.
દા.ત.: પ્રોટીનની દ્વિતીય રચનામાં શું જોવા મળે છે? → આલ્ફા-હેલિક્સ અને બીટા-પ્લીટેડ શીટ.
કાર્બોહાઇડ્રેટ્સ (Carbohydrates)નો વર્ગીકરણ તેમની પોલિમરાઇઝેશન (Polymerization)ના આધારે થાય છે: મોનોસેકેરાઇડ્સ, ડાઇસેકેરાઇડ્સ, ઓલિગોસેકેરાઇડ્સ, અને પોલિસેકેરાઇડ્સ.
કાર્બોહાઇડ્રેટ્સના વર્ગીકરણ સંબંધી પ્રશ્નોમાં.
દા.ત.: કાર્બોહાઇડ્રેટ્સના પ્રકાર કયા કયા છે? → મોનોસેકેરાઇડ્સ, ડાઇસેકેરાઇડ્સ, ઓલિગોસેકેરાઇડ્સ, પોલિસેકેરાઇડ્સ.
એમિનો એસિડમાં એમિનો સમૂહ (NH₂) અને કાર્બોક્સિલ સમૂહ (COOH) હોવો જરૂરી છે. જો પ્રશ્નમાં એમિનો એસિડની રચના પૂછે તો આ બંને સમૂહ યાદ રાખો.
એમિનો એસિડ સંબંધી પ્રશ્નોમાં.
દા.ત.: એમિનો એસિડમાં કયા સમૂહ હોવા જરૂરી છે? → એમિનો સમૂહ અને કાર્બોક્સિલ સમૂહ.
