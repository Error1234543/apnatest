જીવો અને જનસંખ્યા (Organisms and Populations)

🩺 NEET UG — Gujarati • Biology • Organisms and Populations

પરિચય — ઉષ્મીયશાસ્ત્ર (Ecology)
ઉષ્મીયશાસ્ત્ર એ જીવ વિજ્ઞાનની તે શાખા છે જે જીવો અને તેમના પર્યાવરણ વચ્ચેની પરસ્પર ક્રિયાઓનો અભ્યાસ કરે છે.
શબ્દ 'Ecology' — યુગલ 'Oikos' (આવાસ) + 'Logos' (અભ્યાસ)માંથી આવ્યો છે. પ્રથમવાર આ શબ્દ અર્ન્સ્ટ હેકેલ (1869) દ્વારા વપરાયો.
બાયોમ (Biosphere) — પૃથ્વીનો ભાગ જ્યાં જીવન શક્ય છે. તેમાં ઉષ્મીયકોશ (Biosphere), બાયોમ (Biome), સમુદાય (Community), જનસંખ્યા (Population) અને સજીવ (Organism) સામેલ છે.
📝 📌 યાદ રાખો: પર્યાવરણ કારકો = જૈવિક + અજૈવિક
પર્યાવરણીય કારકો
અજૈવિક કારકો (Abiotic factors): પ્રકાશ, તાપમાન, જળવાયુ, મિટ્ટી, pH, ખनिज, વરસાદ.
જૈવિક કારકો (Biotic factors): સ્પર્ધા, શિકાર, પરોપજીવી, પરભક્ષી, સહપોષણ.
શુદ્ધ પ્રખ્યાપન દર (R) = જન્મ દર (B) - મૃત્યુ દર (D) જ્યાં B = Janmak, D = Mrityu dar
⚡ પ્રકાશ સૂರ್‍યમંડળનો મુખ્ય પ્રાથમિક ઊર્જા સ્ત્રોત છે. તે સંયુક્ત પ્રક્રિયા (Photosynthesis) માટે આવશ્યક છે.
તાપમાન: બિન-ઉષ્ણકટિબંધીય પ્રદેશોમાં તાપમાન વધુ વિચલન ધરાવે છે. ઉષ્ણકટિબંધીય પ્રદેશમાં ઓછું વિચલન.
📝 🔑 NEET પ્રશ્ન: R = B - D સૂત્ર યાદ રાખો.
અનુકૂલન (Adaptation)
અનુકૂલન એટલે પર્યાવરણીય પરિસ્થિતિઓ પ્રત્યે જીવના શારીરિક, વર્તનપૂર્ણ અથવા રચનાત્મક ફેરફારો.
ઉષ્ણતાનિયંત્રણ (Thermoregulation): • SSS (Stenothermal): કિંગ્ગૂપ (Kinugupp) — થોડા તાપમાન શ્રેણીમાં જીવંત રહે.
ઉષ્ણતાનિયંત્રણ: • Eurythermal: બંધન (Bandhyan) / અન્ય — ઘણા તાપમાન શ્રેણીમાં ટકી શકે.
જળનિયંત્રણ (Water Regulation): • Hygrolytes: ઓછા જળવાળા પર્યાવરણમાં રહેતા, જળનાભિ રક્ષક.
અનુકૂલન ઉદાહરણો: • તલનો છૂપો છલકાવ (Transpiration) નાબૂદ થયેલો. • ખડખંડી (Kharakhundi) — રાત્રે સક્રિય.
⚡ કેટલાક પ્રાણીઓ ઠંડીમાં શિયાળાનિદ્રા (Hibernation) / ગરમીમાં ગ્રીષ્મનિદ્રા (Aestivation) માં જાય છે.
📝 📝 Hibernation = શિયાળાનિદ્રા | Aestivation = ગ્રીષ્મનિદ્રા
પર્યાવરણીય સ્પર્ધા (Competition)
અન્ય જીવો સાથે સંસાધનો (ભોજન, પાણી, આશ્રય, પ્રકાશ) માટેની લડાઈ.
લોકમિત્ર સ્પર્ધા (Intraspecific): એ જ પ્રજાતિ વચ્ચે.
અન્ય સ્પર્ધા (Interspecific): બે અલગ પ્રજાતિઓ વચ્ચે.
⚡ સ્પર્ધા બંને પ્રજાતિઓ માટે નુકસાનકારક છે — કારણ કે બંનેને ઓછા સંસાધનો મળે છે.
સ્પર્ધાજનસંખ્યાના વિકાસ પર દબાણ
પરોપજીવિતા (Parasitism)
પરોપજીવ (Parasite) હોસ્ટમાંથી આહાર અને આશ્રય મેળવે છે; હોસ્ટને નુકસાન થાય છે.
અન્તઃપરોપજીવી (Endoparasite): હોસ્ટની અંદર (ઉદા. પાર્શ્વ, કપ્રો). બાહ્ય (Ectoparasite): હોસ્ટની બાહ્ય પટલ પર (ઉદા. નુક, મચ્છર).
⚡ પરોપજીવોમાં રચનાત્મક સાદગી (Simplification) જોવા મળે છે — ક્ષેત્રમ (Attachment) માટે કોટિનું અંતર.
📝 📌 હોસ્ટ-પરોપજીવ પક્ષે વિકસિત ચંડલક્ષણો જોવા મળે છે.
પરભક્ષી (Predation)
પરભક્ષી (Predator) નું મૂળ ભાઈ (Prey) નું શિકાર કરી ખાય છે.
ઉદાહરણ: પુષ્પા (Lion), બેરો (Tiger), હુડ (Shark), પંખી (Bird) ઇત્યાદિ.
⚡ પરભક્ષણ એક પ્રકારનું જૈવિક નિયંત્રણ છે — તે હુડની જનસંખ્યાને નિયંત્રિત રાખે છે.
📝 🔑 predator-prey relationship: Lotka-Volterra model
સહપોષણ (Mutualism)
બંને પ્રજાતિઓ એકબીજાને લાભ પહોંચાડે છે.
ઉદાહરણો: • પરાગસંચાર (Pollination): મધમધુડા + પુષ્પ • સહઅન્તઃપરોપજીવિતા (Symbiosis): હોર્મોનિયમ (Lichen) — શેવાલ + શૈવલ
⚡ Mycorrhiza: ફંજસ + મૂળ વચ્ચેનો સહપોષી સંબંધ (Phosphate શોષણ માટે).
મ્યુચુઅલિઝ્મબંનેનો લાભ
જનસંખ્યા ઘટકો (Population Attributes)
જન્મ દર (Birth Rate): જન્મ દર (B) = જન્મ્યા સંખ્યા / કુલ જનસંખ્યા
મૃત્યુ દર (Death Rate): D = મૃત્યુ પામનાર / કુલ જનસંખ્યા
વાવેતર (Immigration): નવા જીવોનું આવકારણ — આંતરિક પ્રવાસ.
પ્રવાસ (Emigration): જીવોનો ચાલી જવો — બાહ્ય પ્રવાસ.
જનસંખ્યા વૃદ્ધિ: Nt+1 = Nt + [(B + I) - (D + E)] જ્યાં I = Immigration, E = Emigration
⚡ જો (B+I) > (D+E) → જનસંખ્યા વધે છે. જો (B+I) < (D+E) → જનસંખ્યા ઘટે છે.
📝 📌 જન્મ-મૃત્યુ દર એ મૂળભૂત ઘટકો છે. પરવાનગી-પ્રવાસ (Migration) પણ મહત્વપૂર્ણ છે.
જનસંખ્યા વૃદ્ધિના મોડેલ
બે મુખ્ય મોડેલો: (1) ચાંડલક્ષી (Exponential) (2) સીમિત (Logistic)
ચાંડલક્ષી વૃદ્ધિ (Exponential Growth): dN/dt = rN જ્યાં r = અંતર્ગત વૃદ્ધિ દર, N = જનસંખ્યા
r નો અર્થ: અંતર્ગત વૃદ્ધિ દર (Intrinsic rate of natural increase).
એવઠ્ઠ સમાધાન (Solution): N(t) = N₀ × e^(rt) જ્યાં N₀ = પ્રારંભિક જનસંખ્યા
⚡ ચાંડલક્ષી વૃદ્ધિ આકાર J-આકારનો ગ્રાફ આપે છે.
📝 🔑 NEET માં r ને યાદ રાખો = intrinsic rate of natural increase.
સીમિત/લોજિસ્ટિક વૃદ્ધિ મોડેલ (Logistic Growth)
પર્યાવરણીય મર્યાદાઓ (Environmental Resistance) ને ધ્યાનમાં લેતું મોડેલ.
dN/dt = rN × (1 - N/K) જ્યાં K = વહનશક્તિ (Carrying Capacity)
K (Carrying Capacity): પર્યાવરણ દ્વારા આપવામાં આવતું મહત્તમ જનસંખ્યા જેટલું સંસાધન ટકાવી શકાય.
⚡ જ્યારે N = K ત્યારે dN/dt = 0 → જનસંખ્યા સ્થિર.
લોજિસ્ટિક વૃદ્ધિ સિગ્મા (S-આકાર) વળાંક આપે છે.
N = Kવહનશક્તિ સીમા
📝 📌 logistic curve is also called sigmoid growth curve.
વહનશક્તિ (Carrying Capacity)
વહનશક્તિ (K) એ પર્યાવરણની એવી ક્ષમતા છે જે જનસંખ્યાને ટકાવી શકે.
જો જનસંખ્યા K કરતા વધી જાય → સંસાધનોની કમી, અસ્થિરતા, મૃત્યુ દર વધે છે.
⚡ વાસ્તવિક પ્રકૃતિમાં જનસંખ્યા K ની આસપાસ oscillate થાય છે.
પર્યાવરણીય મર્યાદાઓ: ખોરાક, પાણી, આશ્રય, રોગો, શિકાર.
જનસંખ્યા પરસ્પર ક્રિયાઓ (Population Interactions)
જનસંખ્યા બે પ્રકારની ક્રિયાઓ દ્વારા પરસ્પર સંબંધિત છે: (1) સકારાત્મક (+) (2) નકારાત્મક (-)
અનુકૂલન સંબંધોની સારાંશ: • +/+ = સહપોષણ (Mutualism) • +/- = પરોપજીવિતા (Parasitism) • +/0 = commensalism • -/- = સ્પર્ધા • +/- = પરભક્ષી (Predation)
⚡ લોટ્કા-વોલ્ટેરા મોડેલ (Lotka-Volterra) પરભક્ષી-પ્રિ ચક્ર દર્શાવે છે.
Lotka-Volterra equations: dN₁/dt = r₁N₁(1 - N₁/K₁) dN₂/dt = r₂N₂(1 - N₂/K₂) - aN₁N₂
📝 📌 + = लाभ, - = हानि, 0 = निष्प्रभावी (Neutral)
સહપોષણ (Commensalism)
એક જીવને લાભ, બીજાને કોઈ પણ ફાયદો-નુકસાન નહીં (+/0).
ઉદાહરણ: Epiphytic plants on trees, Orchids on tree branches.
⚡ એક જીવનો ફાયદો, બીજો બેજોડ રહે છે.
📝 🔑 Commensalism = +/0 interaction
ઉમ્ર ચક્ર (Age Pyramid / Age Structure)
ઉમ્ર-લિંગ પાયરેમિડ એ જનસંખ્યાના બંધારણને દર્શાવતો ચિત્ર છે.
ત્રણ પ્રકાર: 1. વિસ્તૃત (Expanding) — young population, high growth 2. સ્થિર (Stable) — uniform age distribution 3. ઘટી રહેલો (Declining) — old population, low growth
⚡ પાયરેમિડના તળિયે બાળકો, ઉપર વૃદ્ધ હોય છે.
બાળકોની % વધુ હોય → જનસંખ્યા ઝડપથી વધશે. વૃદ્ધોની % વધુ હોય → જનસંખ્યા ઘટશે.
📝 📌 Age pyramid is a graphical representation of age distribution.
