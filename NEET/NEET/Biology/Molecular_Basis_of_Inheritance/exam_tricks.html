🎯 પરીક્ષા ટ્રિક્સ

ચાર્ગૃફના નિયમને યાદ રાખવાની ટ્રિક: 'A=T, G≡C' → એડિનાઈન-થાઈમિન બે હાઈડ્રોજન બંધ, ગ્વાનિન-સાયટોઝિન ત્રણ હાઈડ્રોજન બંધ. તેથી G+C ધરાવતું DNA વધુ સ્થિર (ધ્રુવક તાપમાન ઉચ્ચ).
જ્યારે પ્રશ્નમાં DNA ના કમ્પોઝિશન અથવા થર્મલ સ્થિરતા વિશે પૂછવામાં આવે.
દા.ત.: જો DNA માં G = 20% હોય, તો C = 20%, A = T = 30% દરેક. A+T = 60%, G+C = 40%.
Replication 'semi-conservative' યાદ રાખવાની ટ્રિક: 'અર્ધ-સંરક્ષણ' = દરેક નવા DNA માં એક જૂનો અને એક નવો સ્તંભ. Meselson-Stahl પ્રયોગ → N¹⁵(ભારે) અને N¹⁴(هلકા) સ્ટ્રેન્ડ્સ. પહેલી પીઢીમાં મધ્યમ ઘનત્વ, બીજી પીઢીમાં મધ્યમ+હલકો.
જ્યારે DNA પ્રતિકૃતિના પ્રકાર અથવા Meselson-Stahl પ્રયોગ પર પ્રશ્ન આવે.
દા.ત.: Meselson-Stahl પ્રયોગમાં F¹⁵ DNA ને F¹⁴ મીડિયામાં ૨ જનરેશન રાખીએ → ૫૦% એવાંઝાઈટિક (ગાઢ) અને ૫૦% લાઇટ બેન્ડ.
Transcription માં RNA Polymerase III vs II: RNA Pol II → mRNA, tRNA → Pol III, rRNA (પ્રોકેરીયોટ્સમાં સિંગલ Pol). Eukaryotes માં: Pol I (rRNA), Pol II (mRNA), Pol III (tRNA/rRNA) — યાદ રાખવા: 'Pol I rRNA, Pol II mRNA, Pol III tRNA'.
જ્યારે eukaryotic RNA polymerases ની ભૂમિકા અંગે પ્રશ્ન આવે.
દા.ત.: મુખ્ય પ્રશ્ન: mRNA નું સંશ્લેષણ કયા enzyme દ્વારા? → RNA Polymerase II.
Operon મોડેલ (Jacob-Monod): 'Lac operon' માં repressor, operator, promoter, structural genes (Z, Y, A). યાદ રાખો: 'Z = β-galactosidase, Y = permease, A = transacetylase'.lac operator પર repressor જોડાય તો transcription બંધ. Lactose (inducer) repressor ને detach કરે → transcription શરૂ.
ઓપેરોન કોન્સેપ્ટ, lac operon નું નિયમન, અથવા જનીન અભિવ્યક્તિ પર પ્રશ્ન.
દા.ત.: જ્યારે lactose (allolactose) હાજર હોય → તે repressor સાથે જોડાય → repressor-conformation બદલાય → operator પરથી ઉતરી જાય → RNA polymerase transcription શરૂ કરે.
Genetic code ના ગુણધર્મો: Universal (બધામાં), Degenerate (એકથી વધુ codon એક જ amino acid માટે), Non-overlapping, Comma-less, Start/Amino acid-specific. AUG = both START (Met) + STOP (UGA, UAG, UAA = 'UAre Stop/End').
જ્યારે genetic code ના ગુણધર્મો અથવા codon-અમીનો એસિડ સંબંધિત પ્રશ્ન આવે.
દા.ત.: Stop codons યાદ રાખવા: 'UAA (Ochre), UAG (Amber), UGA (Opal)' → 'U Are Stop'. 61 codons amino acid માટે, 3 stop codon.
Translation માં initiation complex યાદ રાખો: '5S-18S-40S' ઇયુકેરियोટ = 40S (small subunit) + Met-tRNA + 5S-RNA (28S, 5.8S, 18S rRNA સહિત 60S large subunit) → 80S ribosome. પ્રોકેરીયોટ્સમાં: 30S + fMet-tRNA + 50S = 70S.
Translation નું initiation stage અને ribosome subunits પર પ્રશ્ન આવે ત્યારે.
દા.ત.: ઇયુકેરियोટિક 80S ribosome ના small અને large subunit નું કદ? → 40S + 60S = 80S. fMet-tRNA ફક્ત પ્રોકેરીયોટ્સમાં.
DNA vs RNA તફાવત ઝડપી યાદ રાખો: DNA = Double stranded, deoxyribose, Thymine, stable; RNA = Single stranded, ribose, Uracil, less stable. ટ્રિક: 'DNA = Dual (double), RNA = Random (single)'
DNA અને RNA વચ્ચેનો તફાવત અથવા structure પ્રશ્નો પર.
દા.ત.: Hershey-Chase પ્રયોગમાં: protein (³²S) vs DNA (³²P) નક્કી કરતો. ³²P (radioactive phosphorus) બેક્ટેરિયામાં ગયો → DNA遗传物质.
Human Genome Project (HGP): ૨૦૦૩માં પૂર્ણ, ~૩ અબજ base pairs, ~૨૦,૦૦૦-૨૫,૦૦૦ genes. યાદ રાખો: 'એક કોષમાં DNA લંબાઈ ~૨ મીટર, ~૨૦,૦૦૦ genes'. HGP નો કોસ્મિડ ક્લોન આધારિત sequencing ( shotgun approach ).
HGP વિશેનો કોઈ પણ પ્રશ્ન — dates, statistics, methodology.
દા.ત.: HGP માટે કौन सा organism નમૂનಾಗಿ રાખવામાં આવ્યો? → માનવી (Homo sapiens). 99.9% humans વચ્ચે sequence similarity.
DNA Fingerprinting (Bharadwaj/Alec Jeffreys): VNTR (Variable Number Tandem Repeats) પર આધારિત. Restriction enzymes (RFLP), probe hybridization (Southern blot), agarose gel electrophoresis. Saha-પિતૃતાવચન (paternity), forensic sciences માં.
DNA fingerprinting અને તેના applications પર પ્રશ્ન આવે.
દા.ત.: કઈ techniqueVNTR-based profiling માટે વપરાય? → RFLP (Restriction Fragment Length Polymorphism). Probes: radioactive DNA sequences specific to VNTR regions.
Histone યાદ રાખો: H1, H2A, H2B, H3, H4 — ન્યુક્લિયોસોમનું core (八聚体 H2A×2 + H2B×2 + H3×2 + H4×2) + H1 linker. 'One H' સિવાય બધા core component. ટ્રિક: 'All four are present — H1 is the extra'.
Euchromatin/Heterochromatin, nucleosome structure, histone proteins પર પ્રશ્ન.
દા.ત.: ન્યુક્લિયોસોમ coreParticle માં કેટલા histone proteins? → 8 (H2A, H2B, H3, H4 દરેક 2 copies) + linker H1.
Semiconservative replication માં leading vs lagging strand: Leading strand continuous (5'→3'), lagging strand discontinuous (Okazaki fragments). DNA ligase fragments જોડે. Primase RNA primer બનાવે છે.
DNA replication machinery, leading/lagging strand, Okazaki fragments પર પ્રશ્ન.
દા.ત.: કઈ enzyme Okazaki fragments જોડે? → DNA ligase. કઈ enzyme RNA primer બનાવે? → Primase (DnaG in bacteria).
Messenger RNA (mRNA) પ્રોકેરૉટ્સ vs યુકેરૉટ્સ: પ્રોકેરૉટ્સમાં polycistronic (એક mRNA mehreren genes), યુકેરૉટ્સમાં monocistronic. 5' cap (m⁷G) અને 3' poly-A tail (eukaryotes)翻译稳定性 માટે.
mRNA structure, prokaryotic vs eukaryotic gene organization પર પ્રશ્ન.
દા.ત.: પ્રોકેરૉટ્સમાં mRNA polycistronic કારણે: રibosomes simultaneous multiple genes પર translate કરી શકે.
Transformation પ્રયોગ (Griffith, 1928): 'S strain (virulent) → heat-killed + R strain (live) → mouse dies → R strain transformed into S strain.' Transformation factor = DNA (Avery-MacLeod-McCarty, 1944). Enzyme responsible: DNase destroys transformation.
Proof of DNA as genetic material, Griffith's experiment, Avery-Macleod-McCarty પર પ્રશ્ન.
દા.ત.: Avery-MacLeod-McCarty实验中, transformation activity消失 upon addition of: →DNase (degrades DNA), પ્રોટીએઝ/RNase ਨਹੀਂ.
Transposons (jumping genes) — Barbara McClintock (1950s, maize): Transposable elements genes નું position બદલી શકે. IS elements, Composite transposons, Tn3 families. Transposase enzyme mobilization માટે જરૂરી.
Mobile genetic elements, transposon types, McClintock discovery પર પ્રશ્ન.
દા.ત.: Transposon movement માં transposase enzyme role? → recognition of inverted repeats and catalyze excision/insertion.
RNA world hypothesis: સૌપ્રથમ બાયોકેમિકલ world માં RNA both informational (like DNA) and catalytic (like enzyme/ribozyme) role માં રહ્યો. Ribozyme = RNA with enzymatic activity (self-splicing introns, RNase P, peptidyl transferase in ribosome).
Origin of life, RNA world, ribozyme function પર પ્રશ્ન.
દા.ત.: કઈ enzymatic activity RNA દ્વારા થાય છે? → Peptidyl transferase (ribosome નો catalytic core) — RNA (rRNA) enzyme છે.
