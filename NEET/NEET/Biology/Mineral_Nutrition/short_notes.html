ખનિજ પોષણ (Mineral Nutrition) — ટૂંકા નોંધો

🩺 NEET UG — Gujarati • Biology • Mineral Nutrition

📘 વ્યાખ્યાઓ

  • ખનિજ પોષણ: છોડ દ્વારા જમીનમાંથી અવયવિક તત્વોનું શોષણ અને વપરાશ.
  • આવશ્યક તત્વ: તે તત્વ જે વિના છોડનો જીવનચક્ર પૂરું ન થાય.
  • મૂળભૂત તત્વ: પાંદડાં દ્વારા CO₂ અને H₂O માંથી બનતાં કાર્બનિક તત્વો.
  • અવયવિક તત્વ: જમીનમાંથી મળતાં તત્વો જે કાર્બનિક સંયોજનો બનાવતાં નથી.
  • હાઇડ્રોપોનિક્સ: જમીન વિના પોષક દ્રાવણમાં છોડ ઉગાડવાની પદ્ધતિ.
  • નાઇટ્રોજેન સ્થાપન: વાતાવરણનું N₂ → NH₃/NO₃⁻ માં રૂપાંતર કરવાની પ્રક્રિયા.
  • નાઇટ્રોજેનેઝ ઉત્સેચક: N₂ ને NH₃ માં રૂપાંતરિત કરનારું ઉત્સેચક.
  • હિમોગ્લોબિન: રાઇઝોબિયમમાં ઓક્સિજન વહન કરતું પ્રોટીન.
  • મેથેમોગ્લોબિન: ઓક્સિજન બંધાયેલું હિમોગ્લોબિન જે N₂ ને બંધ કરતું નથી.

⚡ સૂત્રો

  • N₂ + 8H⁺ + 8e⁻ → 2NH₃ + H₂ (નાઇટ્રોજેન સ્થાપન)
  • NH₃ + α-કેટોગ્લુટારેટ + NADPH → ગ્લુટામેટ + NADP⁺ (GDH)
  • ગ્લુટામેટ + NH₃ + ATP → ગ્લુટામીન + ADP + Pi (GS)
  • NO₃⁻ + NADPH + H⁺ → NO₂⁻ + NADP⁺ + H₂O (નાઇટ્રેટ રિડક્ટેઝ)
  • NO₂⁻ + 6Fd(red) + 8H⁺ → NH₄⁺ + 6Fd(ox) + 2H₂O (નાઇટ્રાઇટ રિડક્ટેઝ)
  • 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂ (પ્રકાશસંશ્લેષણ — મૂળભૂત તત્વોનો સંદર્ભ)

⭐ મુખ્ય તથ્યો

  • છોડને ૧૭ આવશ્યક તત્વો જરૂરી છે.
  • મૂળભૂત તત્વો: C, H, O, N, P, S, K, Ca, Mg — ૯ તત્વો.
  • અવયવિક તત્વો: Fe, Mn, B, Zn, Cu, Mo, Cl — ૭ તત્વો.
  • Na, Si, Se, Al કેટલાક છોડ માટે ઉપયોગી તત્વો છે.
  • મેક્રોન્યુટ્રિઅન્ટ્સ: N, P, K, Ca, Mg, S — મોટી માત્રામાં જરૂરી.
  • માઇક્રોન્યુટ્રિઅન્ટ્સ: Fe, Mn, Zn, Cu, B, Mo, Cl — ઓછી માત્રામાં જરૂરી.
  • નાઇટ્રોજન પ્રોટીન, ન્યુક્લિક એસિડ, ક્લોરોફિલ, હોર્મોન્સમાં હોય છે.
  • ફોસ્ફરસ ATP, ન્યુક્લિક એસિડ, ફોસ્ફોલિપિડ્સમાં હોય છે.
  • મૉલિબ્ડેનમ નાઇટ્રોજેઝ અને નાઇટ્રેટ રિડક્ટેઝનું સહ-ઉત્સેચક છે.
  • હિમોગ્લોબિન રાઇઝોબિયમમાં ઓક્સિજન સાંદ્રતા ઓછી રાખે છે.
  • નાઇટ્રોજેઝ ઓક્સિજન પ્રત્યે અતિ સંવેદનશીલ છે.
  • નાઇટ્રેટ રિડક્ટેઝ Cu અને Fe સહ-ઉત્સેચક ધરાવે છે.
  • નાઇટ્રાઇટ રિડક્ટેઝ Fe-S પ્રોટીન છે.
  • ગ્લુટામીન સંશ્લેષણમાં GS ઉત્સેચક મુખ્ય ભૂમિકા ભજવે છે.
  • ગ્લુટામેટ સંશ્લેષણ GDH દ્વારા પણ થાય છે.
  • રાઇઝોબિયમ લેગ્યુમીનોસી (દા.ત. મટર, ડાલ) સાથે સહજીવન કરે છે.
  • એઝોટોબેક્ટર અને ક્લોસ્ટ્રિડિયમ સ્વતંત્ર નાઇટ્રોજેન સ્થાપક બેક્ટેરિયા છે.
  • બ્લેક ફર્ન એઝોલા સાથે અઝોલ્લા (સાયનોબેક્ટેરિયા)નું સહજીવન ધરાવે છે.
  • મૉલિબ્ડેનમની અછતથી નાઇટ્રેટ સંચિત થાય છે.
  • મૅંગેનીઝ ક્લોરોફિલ સંશ્લેષણમાં મદદ કરે છે.
  • બોરોન પરાગદાન અને શર્કરા પરિવહનમાં મદદ કરે છે.
  • ક્લોરિન પાણી વિભાજન (ફોટોસિસ્ટમ II) માં જરૂરી છે.
  • ઝિંક પીઆરડી (pyruvate decarboxylase) ઉત્સેચકનું સહ-ઉત્સેચક છે.
  • કોપર પ્લાસ્ટોસાયનિન અને સાયટોક્રોમ ઓક્સિડેઝમાં હોય છે.

⚠️ સામાન્ય ભૂલો

  • નાઇટ્રોજેન સ્થાપનમાં N₂ → NH₃ થાય છે, NO₂⁻ નહીં.
  • હિમોગ્લોબિન N₂ ને બંધ કરતું નથી, ઓક્સિજનને બંધ કરે છે.
  • નાઇટ્રેટ રિડક્ટેઝ NO₃⁻ → NO₂⁻ કરે છે, NO₂⁻ → NH₃ નહીં.
  • નાઇટ્રાઇટ રિડક્ટેઝ NO₂⁻ → NH₃ કરે છે.
  • નાઇટ્રોજેઝ Cu/Fe નહીં, Mo અને Fe ધરાવે છે.
  • ગ્લુટામીન સંશ્લેષણમાં ATP વપરાય છે, NADPH નહીં.
  • ગ્લુટામેટ સંશ્લેષણ GDH માં NADPH વપરાય છે.
  • મૉલિબ્ડેનમ માઇક્રોન્યુટ્રિઅન્ટ છે, મેક્રોન્યુટ્રિઅન્ટ નહીં.
  • સિલિકન અને સોડિયમ આવશ્યક તત્વો નથી, ઉપયોગી તત્વો છે.
  • કેલ્શિયમ મેક્રોન્યુટ્રિઅન્ટ છે, માઇક્રોન્યુટ્રિઅન્ટ નહીં.
  • રાઇઝોબિયમ લેગ્યુમીનોસી સાથે જ સહજીવન કરે છે.
  • એઝોટોબેક્ટર સ્વતંત્ર નાઇટ્રોજેન સ્થાપક છે, સહજીવન નહીં.
  • નાઇટ્રોજેઝ ઓક્સિજન પ્રત્યે સંવેદનશીલ છે, N₂ પ્રત્યે નહીં.
  • મૉલિબ્ડેનમની અછતથી નાઇટ્રેટ સંચિત થાય, નાઇટ્રાઇટ નહીં.
  • ક્લોરિન પાણી વિભાજનમાં જરૂરી છે, પ્રકાશસંશ્લેષણમાં નહીં.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • છોડના ૧૭ આવશ્યક તત્વો યાદ રાખો.
  • મેક્રોન્યુટ્રિઅન્ટ્સ: N, P, K, Ca, Mg, S.
  • માઇક્રોન્યુટ્રિઅન્ટ્સ: Fe, Mn, B, Zn, Cu, Mo, Cl.
  • નાઇટ્રોજેન સ્થાપન: N₂ → NH₃ (નાઇટ્રોજેઝ દ્વારા).
  • નાઇટ્રેટ રિડક્ટેઝ: NO₃⁻ → NO₂⁻.
  • નાઇટ્રાઇટ રિડક્ટેઝ: NO₂⁻ → NH₃.
  • ગ્લુટામેટ સંશ્લેષણ: GDH ઉત્સેચક દ્વારા.
  • ગ્લુટામીન સંશ્લેષણ: GS ઉત્સેચક દ્વારા.
  • હિમોગ્લોબિન રાઇઝોબિયમમાં ઓક્સિજન વહન કરે છે.
  • મૉલિબ્ડેનમ નાઇટ્રોજેઝનું સહ-ઉત્સેચક છે.
  • રાઇઝોબિયમ-લેગ્યુમીનોસી સહજીવન મહત્વપૂર્ણ છે.
  • એઝોટોબેક્ટર અને ક્લોસ્ટ્રિડિયમ સ્વતંત્ર નાઇટ્રોજેન સ્થાપક છે.
  • બ્લેક ફર્ન-અઝોલ્લા સહજીવન મહત્વપૂર્ણ છે.
  • નાઇટ્રોજેઝ O₂ પ્રત્યે સંવેદનશીલ છે.
  • હિમોગ્લોબિન O₂ બંધાય છે, N₂ નહીં.
  • નાઇટ્રેટ રિડક્ટેઝ Cu અને Fe ધરાવે છે.
  • નાઇટ્રાઇટ રિડક્ટેઝ Fe-S પ્રોટીન છે.
  • ગ્લુટામીન સંશ્લેષણમાં ATP વપરાય છે.
  • ગ્લુટામેટ સંશ્લેષણમાં NADPH વપરાય છે.
  • મૉલિબ્ડેનમની અછતથી નાઇટ્રેટ સંચિત થાય છે.
  • બોરોન પરાગદાન અને શર્કરા પરિવહનમાં મદદ કરે છે.
  • ક્લોરિન પાણી વિભાજનમાં જરૂરી છે.
  • ઝિંક પીઆરડી ઉત્સેચકનું સહ-ઉત્સેચક છે.
  • કોપર પ્લાસ્ટોસાયનિનમાં હોય છે.
  • મૅંગેનીઝ ક્લોરોફિલ સંશ્લેષણમાં મદદ કરે છે.
