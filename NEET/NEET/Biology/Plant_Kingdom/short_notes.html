ધ્રુવવંશ (Plant Kingdom) — ઝડપી રિવિઝન

🩺 NEET UG — Gujarati • Biology • Plant Kingdom

📘 વ્યાખ્યાઓ

  • ક્રિપ્ટોગેમ: બીજ રચતા નહીં એવા છોડ; અલિંગી, લિંગી અને જન્યુદ્વારા પ્રજનન કરે.
  • થેલોફાઈટ્સ: શરીર ધ્રુવભૂત (differentiated) ન હોય; મૂળ, તંદ્રુ, પર્ણ નથી.
  • બ્રાયોફાઈટ્સ: 'સ્થળરંગ પરંપરાના જંતુ' — આધારરંગી (gametophyte) પ્રબળ, મૃદુરંગી (sporophyte) અધીન.
  • પ્ટેરીડોફાઈટ્સ: 'અધૂરા વૃક્ષ' — મૃદુરંગી પ્રબળ, મૂળ/તંદ્રુ/પર્ણ છે, પણ બીજ નથી.
  • હેટરોસ્પોરિયસ: બે પ્રકારનાં જન્યુ (માઈક્રોસ્પોર +મેગેસ્પોર) રચતા સ્पोરોફાઈટ્સ.
  • એન્જિઓસ્પેર્મ: બીજ આવૃત (ઓવેરીમાં) હોય; ફળ રચે છે; દ્વિનિષેચન થાય છે.
  • ગાયનોફોર: સાયકાસમાં દેખાતું અંડાશય સ્તર; નગ્ન બીજવાળું.
  • કોરલોઈડ મૂળ: સાયકાસમાં ઉપરની તરફ વધતા મૂળ; સાયનોબેક્ટેરિયા (એન્ટેરોડર્મ) સાથે સહજીવન.
  • વિવર: પુષ્પરંગ (petal) નું નામ.
  • એપોગેમી: ગેમેટોફાઈટ બીજા પ્રજનનથી વિનિર્મિત થાય.

⭐ મુખ્ય તથ્યો

  • છોડનો ક્લાસિફિકેશન સિસ્ટમ: બેટલેન્ડ અને પ્રાઉટ (1951) — 4 વિભાગો: ક્રિપ્ટોગેમિ પ્લાન્ટ્સ, બ્રાયોફાઈટા, પ્ટેરીડોફાઈટા, સ્પેર્મેટોફાઈટા.
  • શેવોલ્કેન્સ (Algae): થ્રોમ્ફાઈટ્સ — મરિન/મીઠાપાણી/સ્થળ; ક્લોરોફિલ a, b, c + ફાઈકોબિલિન.
  • સાયનોબેક્ટેરિયા (नीलहरित शैवाल): પ્રોકેરિઓટિક; ફિકોસાયનેન + ફાઈકોએરિથ્રિન; સેન્ટ્રામાં ડાઇનોકાર્પિયલ (hormogonia).
  • લાલ શેવ (Rhodophyceae): ફાઈકોએરિથ્રિન → લાલ રંગ; દ્વિ-કેન્દ્રી વિભાજન.
  • ભૂરા શેવ (Phaeophyceae): ફાઈકોફ્યુકોઝાન્થિન; મુખ્યત્વે સમુદ્રી; અલ્જિન + ફ્યુકોઝાન.
  • હેરોનાનથેસીસ: બ્રાયોફાઈટ્સમાં આંતરિક બંધારણવાળા જન્યુક્ષ (antheridium) અને સ્ત્રીજન્યુક્ષ (archegonium).
  • કેલોગોન (Calogonium): વંશાંગ (moss) નો પ્રથમ તબક્કો; પ્રોટોનિમા (protonema) પછી.
  • સ્રાવરંગી (Sporophyte): સહાયક/અધીન — બ્રાયોફાઈટ્સમાં; પોટેટોફાઈટ્સ (bryophytes) નો આધાર.
  • મેરિસ્ટેમેટિક: પ્ટેરીડોફાઈટ્સમાં મૂળ, તંદ્રુ, પર્ણ રચે છે — પ્રથમ વિકસિત કોષરચના.
  • વેસક્યુલર થ્રોમ્બાઈટ્સ: પ્ટેરીડોફાઈટ્સ; સિલેજેનિન, ડાટા, પ્લેનિયોટ્સ, એન્ટોફાઈટા.
  • સાયકેડોફિટા (Cycadopsida): સાયકાસ, ગ્નોઈટ્સ, એન્જીઓપ્ટેરિસ — ગરમ દેશોમાં; વિશાળ પર્ણ (pinnae).
  • ગેમેટોફાઈટ અપરિણામી (reduced): પુષ્પરંગમાં (pollen grain) 3-કોષીય; અંડકોષમાં 7-કોષીય.
  • ડબલ ફર્ટિલાઈઝેશન: એક સ્પર્મ અંડકોષ સાથે (zygote), બીજો સેન્ટ્રલ ન્યુક્લિયસ સાથે (triploid endosperm).
  • એન્જિઓસ્પેર્મ: 3,00,000+ પ્રજાતિઓ; દ્વિ-લિંગી પુષ્પ; ફળ + બીજ રચના.
  • એન્જિઓસ્પેર્મ વર્ગીકરણ: મોનોકોટ અને ડાયકોટ — મૂળ તંતુ, પર્ણ સંવેધન, પુષ્પ અંગો સંખ્યા.

⚠️ સામાન્ય ભૂલો

  • ગલત: બ્રાયોફાઈટ્સમાં મૃદુરંગી પ્રબળ છે. સાચું: આધારરંગી (gametophyte) પ્રબળ છે, મૃદુરંગી (sporophyte) અધીન/સહાયક.
  • ગલત: પ્ટેરીડોફાઈટ્સમાં બીજ હોય છે. સાચું: સ્पोરથી પ્રજનન; બીજ નથી.
  • ગલત: ગાયનોસ્પેર્મ્સમાં દ્વિનિષેચન (double fertilization) હોય છે. સાચું: માત્ર એન્જિઓસ્પેર્મ્સમાં.
  • ગલત: અલ્જીમાં વેસક્યુલર ટિશ્યુ હોય છે. સાચું: અલ્જી થ્રોમ્ફાઈટ્સ છે, વેસક્યુલર ટિશ્યુ નથી.
  • ગલત: સાયકાસનું બીજ 'વેલ્વેટ ફેરન' કહેવાય. સાચું: સુવર્ણ વનસ્પતિ (golden weed) — એન્ટેરોડર્મ સહજીવન.
  • ગલત: પુષ્પરંગમાં (pollen) દ્વિગુણ (diploid) હોય છે. સાચું: એકગુણ (haploid) ગેમેટોફાઈટ છે.
  • ગલત: ફાઈકોબિલિન ફક્ત લાલ શેવમાં હોય છે. સાચું: સાયનોબેક્ટેરિયા અને લાલ શેવ બંનેમાં.
  • ગલત: ગેમેટોફાઈટનું દ્વિગુણ જન્યુક્ષ (antheridium) ધરાવે છે. સાચું: એકગુણ ગેમેટોફાઈટમાં દ્વિગુણ જન્યુક્ષ નથી — એકગુણ જન્યુઓ હોય છે.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • કોનોફોર (cone/strobilus): સાયકાસ/સેલ્વિનમાં; સ્પોરોફાઈટ્સનું પ્રજનનંગ.
  • વિવિધ મેગેસ્પોરોફાઈટ્સ: ગનેફોરા, જીન્કો, એન્ટોફાઈટા — નગ્નબીજી છોડનાં વર્ગ.
  • પુષ્પરંગ (pollen grain) 3-કોષીય: 2 પુરૂષ ગેમેટ + 1 વૃદ્ધિ કોષ.
  • અંડકોષ (ovule): 7-કોષીય 8-કેન્દ્રીય — 3 પ્રોક્સિમલ + 3 ડિસ્ટલ + 2 સેન્ટ્રલ + 1 અંડકોષ.
  • ટ્રિપ્લોઈડ એન્ડોસ્પર્મ: દ્વિનિષેચન દ્વારા બને છે; પોષક સંગ્રહ.
  • ફ્રુટ: આવૃત બીજી છોડમાં ઓવેરીમાંથી રચાય છે; બીજ + ભોજન સંગ્રહ.
  • વેનુંસક્યુલર થ્રોમ્બાઈટ્સ: પ્ટેરીડોફાઈટ્સ + સ્પેર્મેટોફાઈટ્સ — પ્રથમ વિકસિત જલવાહક પટલ.
  • પ્રોટોકોર્ડ (protocorm): પ્ટેરીડોફાઈટ્સનું ગેમેટોફાઈટ; સ્પોરમાંથી ઉત્પન્ન.
  • ફોર્મ્યુલા: 2n (sporophyte) → n (spores) → n (gametophyte) → n (gametes) → 2n (zygote) → 2n (sporophyte).
  • એન્જિઓસ્પેર્મ વિભાગ: 2 વર્ગ — મોનોકોટ (1 ભૂમિ, નેટ રસાયણ, પર્યાયત પર્ણ) / ડાયકોટ (2 ભૂમિ, વિરોધી પર્ણ).
