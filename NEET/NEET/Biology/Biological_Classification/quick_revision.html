જૈવિક વર્ગીકરણ — ક્વિક રિવિઝન શીટ

🩺 NEET UG — Gujarati • Biology • Biological Classification

🧠 યાદ રાખો

જીવસૃષ્ટિનું વર્ગીકરણ લિનિયસ (Linnaeus) એ કર્યું, જેને 'અભિજાત વર્ગીકરણ' (Artificial Classification) કહેવાય.
અરિસ્ટોટલ એ પ્રથમ વખત જીવોને ઉચ્ચતમ (Plants) અને નીચતમ (Animals) એમ વર્ગીકૃત કર્યા.
હ્વિટેકર (Whittaker) એ ૫-રાજ્ય વર્ગીકરણ પ્રસ્તાવિત કર્યું: મોનેરા, પ્રોટિસ્ટા, ફંગી, પ્લાન્ટી, એનિમેલિયા.
વર્ગીકરણના મૂળભૂત એકમને 'જાતિ' (Species) કહેવાય, જે વંશીય અને શારીરિક ગુણધર્મો ધરાવે.
બેક્ટરિયા અને સાયનોબેક્ટરિયા (Cyanobacteria) મોનેરા રાજ્ય હેઠળ આવે છે — તે એકકોષી, પ્રોકેરિયોટિક (Prokaryotic) જીવો છે.
અમીબા, પેરામીશિયમ અને ડાયટમ્સ પ્રોટિસ્ટા રાજ્યના ઉદાહરણો છે — તે યૂકેરિયોટિક (Eukaryotic) અને સરળ સંરચના ધરાવે.
ફંગી (Fungi) હેટેરોટ્રોફિક (Heterotrophic), સેપ્રોફાઇટિક (Saprophytic) અથવા પેરાસાઇટિક (Parasitic) હોય છે, જેમ કે મશરૂમ અને યીસ્ટ.
વાઇરસમાં કોષરસ (Protoplasm) નથી, તે કેવળ ન્યુક્લિક એસિડ (DNA અથવા RNA) અને પ્રોટીન કવચ ધરાવે છે.
લાઇકેન (Lichen) એ શેવાળ (Algae) અને ફંગી વચ્ચેનો સહજીવી (Symbiotic) સંબંધ છે.
વર્ગીકરણના ૭ પાયાના વર્ગો: રાજ્ય (Kingdom), સમૂહ (Phylum), વર્ગ (Class), ગણ (Order), કુળ (Family), વંશ (Genus), જાતિ (Species).

⚡ ઝડપી સૂત્રો

વર્ગીકરણનો ક્રમ: રાજ્ય → સમૂહ → વર્ગ → ગણ → કુળ → વંશ → જાતિ (Kingdom → Phylum → Class → Order → Family → Genus → Species).

✅ વન-લાઈનર્સ

લિનિયસને 'વર્ગીકરણનો પિતા' કહેવાય.
બેક્ટરિયા દ્વિખંડન (Binary Fission) દ્વારા પ્રજનન કરે.
પ્રોટિસ્ટામાં ક્લોરોપ્લાસ્ટ (Chloroplast) ધરાવતા સદસ્યો સ્વયંપોષી (Autotrophic) હોય છે.
ફંગીની કોષભિત્તિ કાઇટિન (Chitin) ની બનેલી હોય છે.
વાઇરસને 'જીવિત અને નિર્જીવ' વચ્ચેનો સીમાચિહ્ન ગણવામાં આવે.
અગિયેલા (Agelas) એ સ્પંજ (Porifera) નું ઉદાહરણ છે.
યૂગ્લીના (Euglena) એ મિશ્રપોષી (Mixotrophic) પ્રોટિસ્ટ છે.
