મનુષ્ય પ્રજનન (Human Reproduction) — મહત્વના બિંદુઓ

🩺 NEET UG — Gujarati • Biology • Human Reproduction

⭐ મહત્વના મુદ્દા

પુરુષ પ્રજનન તંત્રમાં પ્રજનક ગ્રંથીઓ પરીશ ( testes / ટેસ્ટીઝ ) છે, જે કુક્ષિ ગહ્વર ( scrotal sac ) માં સ્થિત હોય છે અને શરીરના બાહ્ય તાપમાન કરતા 2-2.5°C ઓછું તાપમાન જાળવી રાખે છે — આ ઉચ્ચ તાપમાને સ્પર્માટોગોનીયાના વિકાસમાં અડચણ આવે છે.
NEET માં પરીશનું સ્થાન અને કુક્ષિ ગહ્વરનું મહત્વ ઘણીવાર પ્રશ્ન તરીકે પૂછાય છે.
પરીશની અંદર વળાંકવાળા નળીના આધાર પર અન્વસ્થિત અન્તર્ગ્રંથિક ( seminiferous tubules ) હોય છે, જેમાં સ્પર્માટોગોનીયા ( stem cells ), સેર્ટોલી કોષો ( nourishment આપે છે ) અને લેડિગ કોષો ( interstitial / Leydig cells — એન્ડ્રોજેન / testosterone સ્રાવ કરે છે ) હોય છે.
અન્વસ્થાની અંતર્ગ્રંથિક રચના અને લેડિગ કોષોનું કાર્ય NEET નો સ્થિર પ્રશ્ન વિષય છે.
સ્પર્મોજેનિસિસ ( Spermatogenesis ) — સ્પર્માટોગોનીયા → પ્રાઇમેરી સ્પર્મેટોસાઈટ ( Meiosis-I ) → સેકન્ડરી સ્પર્મેટોસાઈટ ( Meiosis-II ) → સ્પર્મટોઝોઈટ → સ્પર્મ ( સ્પર્મિયેશન દ્વારા પૂર્ણરૂપે વિભાજન ) એક પ્રાઇમેરી સ્પર્મેટોસાઈટ પરથી 4 સક્રિય સ્પર્મ બને છે.
સ્પર્મોજેનિસિસનો ક્રમ અને Meiosis સંબંધિત અંકગણિત (4:1) પ્રતિયોગી પરીક્ષાઓમાં બarıંકી આવે છે.
સ્પર્મની રચના: શિર (head) માં ન્યુક્લિયસ અને એક્કોઝોમ (acrosome), મધ્ય ભાગ (midpiece) માં માઇટોકોન્ડ્રિયા (ઊર્જા), પૂંછડી (tail) — ચાલકાઇ માટે. સેર્ટોલી કોષો 'ગોષ્ટિષ્ઠ' (blood-testis barrier) પ્રદાન કરે છે.
સ્પર્મની રચના અને એક્કોઝોમ / માઇટોકોન્ડ્રિયાનું કાર્ય NEET માં વારંવાર આવે છે.
શુક્રધારા ( Vas deferens ) ના અંતભાગ પર સ્પર્મદાની ગ્રંથિ ( seminal vesicle ), પ્રોસ્ટેટ ગ્રંથિ અને ગુલ્ફવર્મીક ગ્રંથિ ( bulbourethral gland ) જોડાયેલી હોય છે; આ ત્રણેય ગ્રંથિઓનો સ્રાવ મિશ્ર થઈ 'વীর્ય' ( semen ) બનાવે છે. વીર્યમાં ફ્રકટોઝ, પ્રોટીન, મ્યુસિન, કેલ્શિયમ અને પ્રોસ્તાગ્લૅન્ડિન્સ હોય છે.
ગ્રંથિઓ અને વીર્યનું સંયોજન NEET માં યાદ કરવાલાયક મહત્વનું છે.
સ્ત્રી પ્રજનન તંત્રમાં અંડગ્રંથિ ( ovary ) અગ્રાંતર ( abdomen ) માં સ્થિત છે; અંડનળી ( fallopian tube / oviduct ) ના ચાર ભાગ: ઇન્ફન્ડિબ્યુલમ ( fimbriae વડે અંડાશયની આસપાસ ), એમ્પુલા ( સામાન્ય રીતે ઉત્પન્ન થતો ફર્ટિલાઇઝેશન અહીં જ થાય છે ), ઇસ્થમસ અને અંત્રા uterine (uterus સાથે જોડાયેલો ભાગ).
અંડનળીના ભાગો અને ઉત્પન્ન સ્થાન NEET માં ખૂબ જ મહત્વનો પ્રશ્ન છે.
અન્ડોજેનિસિસ ( Oogenesis ) — ઓવાયો ( oogonium ) → પ્રાઇમેરી અંડકોષ ( primary oocyte, Meiosis-I શરૂ ) → મીટાફેઝ-II માં અટકે છે → દ્વિતીયક અંડકોષ + પ્રથમ પોલર બોડી → ફર્ટિલાઇઝેશન બાદ બીજું Meiosis વિભાજન → સક્રિય અંડકોષ + બીજી પોલર બોડી. એક પ્રાઇમેરી અંડકોષ પરથી માત્ર 1 સક્રિય અંડકોષ બને છે.
અન્ડોજેનિસિસમાં પોલર બોડીની રચના અને અંતિમ પરિણામ (1:3) NEET માં સતત આવે છે.
માસિક ચક્ર ( Menstrual cycle ) — 28-29 દિવસના સરેરાશ ચક્રમાં ત્રણ તબક્કા: અંડોત્પાતી ( follicular phase, Day 1-14 ), અંડપાત ( ovulatory phase, Day 14 ) અને માસિક પश्चाત્ / પ્રોજેસ્ટેરોનિક ( luteal phase, Day 15-28 ).
માસિક ચક્રના તબક્કાઓ અને તેમનો કાળ NEET માં વારંવાર પ્રશ્ન તરીકે આવે છે.
અંડોત્પાતી તબક્કામાં FSH ( Follicle Stimulating Hormone ) ફોલિકલના વિકાસને પ્રેરે છે; ગ્રાફ પોલીકલ ( Graafian follicle ) ઇસ્ટ્રોજેન સ્રાવે છે, જે અંતઃસ્તરને ( endometrium ) જાડુ કરે છે ( પ્રોલિફરેટિવ phase ).
FSH અને ઇસ્ટ્રોજેનનું પરસ્પર સંબંધ NEET માં હોર્મોન વિભાગમાં મહત્વનું છે.
અંડપાત ( Ovulation ) LH ( Luteinizing Hormone ) ના પીક ( surge ) દ્વારા થાય છે. ગ્રાફ પોલીકલ ફૂટી અંડકોષ મુક્ત કરે છે. આ LH સર્જ NEET માં ખૂબ જ મહત્વપૂર્ણ છે અને પરીક્ષામાં સીધો પ્રશ્ન આવે છે.
LH સર્જ → અંડપાત — આ NEET નો સ્થિર પ્રશ્ન વિષય છે.
અંડપાત પછી ખાલી થયેલ ગ્રાફ પોલીકલ 'યલો બોડી' ( corpus luteum ) માં પરિવર્તિત થાય છે, જે પ્રોજેસ્ટેરોન અને ઇસ્ટ્રોજેન સ્રાવે છે. પ્રોજેસ્ટેરોન અંતઃસ્તરને સુપ્રિમ ( secretory phase ) બનાવે છે.
યલો બોડીનું રૂપાંતર અને પ્રોજેસ્ટેરોનનું કાર્ય NEET માં બહુ આવે છે.
જો ગર્ભધારણ ન થાય તોયલો બોડી ક્ષય પામી કોર્પસ અલ્બિકન્સ બને છે; પ્રોજેસ્ટેરોન સ્તર ગિરતા અંતઃસ્તર બહિર્સ્તર ( shed ) થાય છે → માસિક સ્રાવ. આને માસિક ( menstruation ) કહેવાય છે.
માસિક સ્રાવનું હોર્મોનલ કારણ NEET માં વારંવાર આવે છે.
ફર્ટિલાઇઝેશન ( નિષેચન ) સામાન્ય રીતે અંડનળીના એમ્પુલામાં થાય છે. સ્પર્મની ટોચ પર રહેલો એક્કોઝોમ અંડકોષની ઝોના પેલુસિડા પર પ્રતિક્રિયા કરી કેપાસિટેશન ( capacitation ) પામેલો હોવો જરૂરી છે.
ફર્ટિલાઇઝેશનનું સ્થાન (એમ્પુલા) અને કેપાસિટેશન NEET માં ખૂબ મહત્વનું છે.
ફર્ટિલાઇઝેશન પછી અંડકોષ બીજું Meiosis-II પૂર્ણ કરે છે અને પુરુષ / સ્ત્રી પ્રોકોર્ટિક્સ ( pronuclei ) એકદમ થઈ ઝિગોટ ( зигота ) બનાવે છે. ઝિગોટ વિભાજન શરૂ કરે છે ( cleavage ) → મોરુલા → બ્લાસિટોસિસ્ટ ( blastocyst ).
ફર્ટિલાઇઝેશન પश्चाત્નું વિભાજન અને બ્લાસિટોસિસ્ટ રચના NEET માં મહત્વનું છે.
ગર્ભસ્થાપન ( Implantation ) — બ્લાસિટોસિસ્ટ અંતઃસ્તરમાં ( endometrium ) ધસાઈ જાય છે. ટ્રોફોબ્લાસ્ટ ( trophoblast ) પ્લાસેન્ટા રચના માટે જવાબદાર છે. ગર્ભસ્થાપન અંડપાત પછી ~6-7 દિવસે થાય છે.
ગર્ભસ્થાપનનું સ્થાન અને સમય NEET માં અંકગણિત સહિત પૂછાય છે.
પ્લાસેન્ટા ( Placenta ) — માતા અને ભ્રૂણ વચ્ચે પદાર્થ વિનિમયનું અંગ. hCG ( human Chorionic Gonadotropin ) ટ્રોફોબ્લાસ્ટ દ્વારા સ્રાવ થાય છે, જે ગર્ભાવસ્થાના પ્રારંભમાં પ્રોજેસ્ટેરોન સ્રાવ ટકાવી રાખે છે.
પ્લાસેન્ટા અને hCG — બંને NEET માં વારંવાર પ્રશ્ન આવે છે.
ગર્ભાવસ્થા ( Pregnancy ) દરમિયાન અંડપાત અને માસિક ચક્ર બંધ થાય છે. હોર્મોનલ સંતુલન માટે પ્રોજેસ્ટેરોન પ્રબળ છે. લક્ષ્ણોમાં દાડની ( breast ) માં ફેરફાર, વિકલ્પ ( mood swings ) અને ઉલ્ટી જેવા લક્ષણો.
ગર્ભાવસ્થા દરમિયાન હોર્મોન્સ અને માસિક ચક્રનું બંધ થવું NEET માં આવે છે.
પ્રસૂતિ ( Parturition ) — સસ્તન પ્રાણીઓમાં ભ્રૂણનું જનમ. આ પ્રક્રિયાને પ્રેરક HPA અક્ષ ( Hypothalamus-Pituitary-Adrenal axis ) અને ઓક્સિટોસિન સમાવે છે. પ્રથમ સંકેત 'ફૂલ ટર્મ' ભ્રૂણ અને પ્લાસેન્ટા દ્વારા આપવામાં આવે છે.
પ્રસૂતિનો હોર્મોનલ સંકેત (ઓક્સિટોસિન) NEET માં સ્થિર પ્રશ્ન છે.
સ્તন્યપાન ( Lactation ) — પ્રસૂતિ પછી પ્રોલેક્ટિન ( prolactin ) દૂધ ઉત્પાદન માટે અને ઓક્સિટોસિન દૂધ નિષ્ક્રિયત ( milk ejection/reflex ) માટે જવાબદાર છે. પ્રથમ દૂધ 'કોલોસ્ટ્રમ' ( colostrum ) છે, જે婴儿 ની પ્રતિકારક શક્તિ ( immunity ) માટે ખૂબ મહત્વનું છે.
કોલોસ્ટ્રમ અને પ્રોલેક્ટિન/ઓક્સિટોસિનનું વિભિન્ન કાર્ય NEET માં ખૂબ મહત્વનું છે.
માસિક ચક્રનું હોર્મોનલ નિયંત્રણ: અગ્રસ્તરી ( anterior pituitary ) માંથી FSH અને LH; અંડાશયમાંથી ઇસ્ટ્રોજેન અને પ્રોજેસ્ટેરોન. આ બધા હોર્મોન્સ એકબીજાને પીઠબળ ( feedback ) આપે છે — ધન / ઋણ both પ્રકારે.
હોર્મોનલ ફીડબેક NEET માં ડાયાગ્રામ સહિત પૂછાય છે; એન્ડોક્રાઇન અને પ્રજનન બંને સાથે જોડાયેલું છે.
અંડાશયમાં કોષિકીય સ્તરે: ડીગ્રાન્યુલોઝા કોષો ( granulosa cells ) → ઇસ્ટ્રોજેન; થીકા સેલ્સ → એન્ડ્રોજેન. એન્ડ્રોજેન ફેરવવા માટે અરોમેટેઝ એન્ઝાઇમ જરૂરી છે.
કોષિકીય સ્તરે હોર્મોન સંશ્લેષણ NEET માં advanced પ્રશ્ન તરીકે આવે છે.
અંડકોષ અને સ્પર્મ બંને હાફ્લોઇડ ( haploid / n ) હોય છે; ફર્ટિલાઇઝેશન પછી ઝિગોટ ડિપ્લોઇડ ( 2n ) બને છે. માનવમાં n=23, 2n=46. Y રંગસૂત્ર ( Y chromosome ) પુરુષ લિંગ નિર્ધારણ માટે જવાબદાર છે.
રંગસૂત્રીય સંખ્યા અને લિંગ નિર્ધારણ NEET માં પ્રારંભિક પરંતુ મહત્વપૂર્ણ પ્રશ્ન છે.
અંતઃસ્તર ( Endometrium ) ના ત્રણ સ્તર: સ્ટ્રાટમ ગ્રાન્યુલોઝમ ( functionalis ), સ્ટ્રાટમ બેઝલિસ ( basalis ), સ્ટ્રાટમ પેરિટોનિયમ ( perimetrium ). ફર્ટિલાઇઝેશન પછી functionalis જ ગર્ભસ્થાપન માટે તૈયાર રહે છે.
અંતઃસ્તરના સ્તરો NEET માં રચના પ્રશ્ન તરીકે આવે છે.
