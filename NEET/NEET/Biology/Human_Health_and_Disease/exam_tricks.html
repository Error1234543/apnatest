🎯 પરીક્ષા ટ્રિક્સ

HIV નું લક્ષ્ય કોષ: CD4+ T-લિમ્ફોસાઇટ (Helper T-cell). જો વાક્યમાં 'CD4 count ઘટે' અથવા 'opportunistic infections' હોય, તો HIV જવાબ. ઉલટું, IFN-β/γ એન્ટિવાયરલ છે, HIV ને સીધું નષ્ટ કરતા નથી.
જ્યારે પ્રશ્નમાં રોગચાળો અથવા રક્ષણક્ષમતા દર્શાવતો હોય અને વિષયનો સંદર્ભ હોય.
દા.ત.: Q: HIV કયા કોષોને પ્રભાવિત કરે છે? (A) RBC (B) Platelets (C) CD4+ T-cells (D) Neutrophils → C
Oncogene vs Tumor Suppressor: Oncogene = ' Gas pedal' (activated mutation → cancer). Tumor suppressor = 'Brake' (loss of function → cancer). પૂછે: 'Gain of function'? → Oncogene. 'Loss of function'? → Tumor suppressor.
કેન્સર જનીન પાઠ્યક્રમનો પ્રશ્ન આવે ત્યારે.
દા.ત.: Q: નીચેમાંથી કયું oncogene છે? (A) p53 (B) RB1 (C) RAS (D) BRCA1 → C (RAS gain-of-function mutant oncogene છે).
Plasmodium ચક્ર યાદ કરવા: 'Sporozoite → Liver → Merozoite → RBC → Schizont → Gametocyte'. Cyclical fever 48h (vivax/ovale) અથવા 72h (malariae) અથવા irregular (falciparum).
મલેરિયાના લક્ષણો અથવા જીવનચક્ર સંબંધી પ્રશ્નમાં.
દા.ત.: Q: 48-घंटेનો cyclical fever દર્દીને આપેલો છે, કયા Plasmodium નો સંભવ? (A) P. falciparum (B) P. vivax (C) P. malariae (D) P. knowlesi → B
Widal Test: Salmonella typhi માટે સામગ્રી-અધારિત (serological) પરિક્ષણ. O અને H antibody titer માપે છે. સાવચેતી: false positive/ negative શક્ય, PCR/Vaccine prophylaxis (Vi polysaccharide) ને ધ્યાનમાં લો.
ટાયફોઇડ નિદાન અથવા પરીક્ષણ વિશે પ્રશ્ન.
દા.ત.: Q: Typhoid નું નિદાન કયા પરીક્ષણથી થાય? (A) Widal (B) ELISA (C) AFB smear (D) CT scan → A
Dengue vs Malaria differentiation: Dengue = Aedes mosquito, thrombocytopenia, plasma leakage; Malaria = Anopheles, hemolysis, cyclical fever. Q માં 'platelet count < 1 لખ' હોય → Dengue shock syndrome.
જરૂરી રોગ અલગ પાડવાના પ્રશ્નમાં.
દા.ત.: Q: શું રક્તમાં પ્લાઝ્મા leakage અને platelet ઘટાડો કોના લક્ષણો છે? (A) Malaria (B) Dengue (C) Typhoid (D) Chikungunya → B
Allergy: IgE-mediated, mast cell degranulation → histamine. લક્ષણ: sneezing, wheezing, runny nose. Epinephrine (Adrenaline) એ acute anaphylaxis નું પ્રથમ ઔષધ. Corticosteroids long-term માટે.
એલર્જી અથવા Hypersensitivity પ્રશ્નમાં.
દા.ત.: Q: Anaphylactic shock માં તરત આપવું પડે તે ઔષધ કયું? (A) Antihistamine (B) Epinephrine (C) Antibiotic (D) Vaccine → B
Autoimmune disease targeting ઓળખ: Rheumatoid Arthritis = synovial joint; Myasthenia Gravis = neuromuscular junction (ACh receptors); Multiple Sclerosis = CNS myelin sheath; Type 1 Diabetes = pancreatic β-cells.
સ્વયં-રોગપ્રતિકારક રોગો ઓળખવા.
દા.ત.: Q: કયો રોગ Myelin sheath નું નાશ કરે છે? (A) RA (B) MG (C) MS (D) T1DM → C
કોષ્ટક ટ્રિક: 'Opioids' (Heroin/Morphine) → analgesic + sedative + constipation; 'Cannabinoids' → euphoria + altered perception; 'Cocaine' → stimulant + vasodilator (paradox). યાદ રાખો: 'Opioid = Opium family, CNS depressant'.
દવા અકલ્પિતા/વ્યસન વિશે પ્રશ્ન.
દા.ત.: Q: કઈ દવા 'respiratory depression' ઉત્પન્ન કરે? (A) Cannabis (B) Cocaine (C) Heroin (D) Nicotine → C
Vaccine type ટ્રિક: Live attenuated = weakened whole pathogen (BCG, OPV). Inactivated = killed whole pathogen (IPV, Rabies). Subunit/Recombinant =部分 antigens (HBV, HPV). mRNA = instructions for spike protein (COVID-19 vaccines).
ટીકાકરણ પ્રકારો અથવા પાઠ્યક્રમમાં બેસેલા પ્રશ્નો.
દા.ત.: Q: કઈ vaccine live attenuated છે? (A) Hepatitis B (B) BCG (C) Polio (inactivated) (D) Rabies → B
ELISA vs PCR: ELISA = antigen/antibody detection (e.g., HIV antibody). PCR = nucleic acid amplification (e.g., SARS-CoV-2 RNA, HIV viral load). જો પ્રશ્નમાં 'RNA detection' હોય → RT-PCR; 'antibody' હોય → ELISA.
રોગનિદાન પદ્ધતિ વિશે પ્રશ્ન.
દા.ત.: Q: HIV રોગચાળાના પ્રારંભિક સમયગાળામાં શેષ પદ્ધતિ કઈ? (A) ELISA (B) Western blot (C) PCR (D) Culture → C (viral load early phase)
Immunity તરફથી ઇન્હીબિશન ટ્રિક: Innate = non-specific, no memory, first line. Adaptive = specific, memory, B/T cells. જો પ્રશ્નમાં 'memory response' હોય → Adaptive. 'skin/mucus' → Innate.
રક્ષણક્ષમતા પ્રકારો જૂદા પાડવા.
દા.ત.: Q: કઈ રક્ષણક્ષમતામાં ' Immunological memory' હોય છે? (A) Innate (B) Adaptive (C) Physical barrier (D) Phagocytosis → B
Cancer staging/grading ટ્રિક: Benign = localized, encapsulated; Malignant = invasive, metastasis. Metastasis = spread via blood/lymph. Primary tumor = મૂળ; Secondary = metastasis site.
કેન્સર લક્ષણો અથવા પ્રકારો.
દા.ત.: Q: Metastasis શું દર્શાવે છે? (A) Localized growth (B) Spread to distant organs (C) Differentiation (D) Angiogenesis → B
Interferon ટ્રિક: IFN-α/β (Type I) = antiviral, induce ' antiviral state' in neighboring cells. IFN-γ (Type II) = macrophage activation, immune modulation. જો પ્રશ્નમાં ' viral infection પ્રતિકાર' હોય → IFN-α/β.
સિગનલિંગ/રાઇટોપ્રોટીન વિશે પ્રશ્ન.
દા.ત.: Q: Interferons મુખ્યત્વે કયા રોગપ્રતિકારક તત્વને ઉત્પ્રેરિત કરે? (A) Bacterial growth (B) Viral replication (C) Fungal spores (D) Parasite eggs → B
