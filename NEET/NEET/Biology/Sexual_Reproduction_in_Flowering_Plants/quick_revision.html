ફूलવાળા છોડમાં યૌન પ્રજનન — ઝડપી પુનરાવર્તન

🧠 યાદ રાખો

ફૂલ એ પરિવર્તિત શાખા છે; તેનું ઉત્પન્ન અંગ એટલે અંતર્ગ્રંથિ (Ovary).
બીજકણ (Pollen grain) — નર ગેમેટોફાઇટ; ૨-કોષીય અંદરના ભાગમાં અંતઃકોષજ (Vegetative cell) અને સ્પર્મજનોદ (Sperm generative cell) હોય છે.
અંડકોષ (Embryo sac) — માદા ગેમેટોફાઇટ; સામાન્ય રીતે ૭-કોષીય અને ૮-બીજાણુય હોય છે.
દ્વિસંસર્જન (Double fertilization) — એક સ્પર્મજન્યુસ કડકણી બને છે (જાયગર્ભ), બીજો સંયુક્ત મૂળકણજન્યુસ બનાવે છે (ત્રિકક).
ઉત્કલિપ (Pericarp) — ફળની બાહ્ય આવરણ; ફળ એ પક્વ ઓવરી થાય છે.
એન્ડોસ્પર્મ (Endosperm) — ત્રિક (3n); પોષક સજ્જી તરીકે કામ કરે છે.
ફૂલકું (Pistil) = સ્ત્રીબીજપટલ + ગર્ભાશય + કેસર.
ફૂલાભ (Tapetum) — અન્નાસ્રાવક આંતરસ્તર જે પરાગકણને પોષક અને ભોજનરસ પ્રદાન કરે છે.

⚡ ઝડપી સૂત્રો

અંડકોષના કોષ : ૩ અંડકોષ (Antipodal) + ૨ ધ્રુવીય કોષ (Polar nuclei) + ૨ સહાયક કોષ (Synergids) + ૧ અંડકોષ (Egg) = ૭ કોષ, ૮ બીજાણુ.
ત્રિક બનાવવા માટે: સ્પર્મજન્યુસ (n) + બે ધ્રુવીય બીજાણુઓ (n + n) = 3n (ત્રિક/Primary Endosperm Nucleus).
અંતઃકોષજ ચરણ → સ્પર્મજન્યુસ બનાવે છે; બે સ્પર્મજન્યુસ → દ્વિસંસર્જન કરે છે.
સંયુક્ત મૂળકણજન્યુસ (Secondary Nutritive Nucleus) = trik (3n).

✅ વન-લાઈનર્સ

પરાગરજા (Pollination) પ્રકારો — સ્વપરાગરજા, પરપરાગરજા, પક્ષીપરાગરજા, કીટિકાપરાગરજા વગેરે.
પરાગકણની બહારની પોલાણ (Exine) સ્પોરીડોપોલેન ( Sporopollenin) બનેલી છે — જડીબુટ્ટી પ્રતિરોધી.
ગર્ભાશયમાંથી નીકળતો અંતરજ (Style) → અન્તરજનદી (Stigma) ઉપર અંકુરણ થાય છે.
કેસર (Anther) → ૪ પરાગકોષકોશ (Pollen sacs) ધરાવે છે; પ્રકાંડી સ્થાવર કોષો અન્તઃસ્તર સહિતના પ્રક્રિયાઓ દ્વારા પરાગકણ બનાવે છે.
મહાબીજકણ (Megaspore mother cell) → અર્ધવર્ધન વિભાજનથી ૪ મહાબીજાણુ બનાવે છે, જ્યાંથી એક જીવંત બને છે (monosporic embryo sac).
દ્વિસંસર્જન — ફક્ત ફૂલવાળા છોડ (Angiosperms) માં જોવા મળે છે.
જાયગર્ભ (Zygote) → દ્વિક (2n); પાર્થેનોજનરિક (Parthenocarpy) → ફળ બિનબીજાણુમય બને છે.
બીજ વિકાસ: બીજાણુ (Seed coat) → બહિર્ત્વી (Testa) + અંતર્ત્વી (Tegmen); હાયપોકોટીલ + ઇપોકોટીલ અંતર્ગ્રંથિનો ભાગ છે.
એપોમિક્સિસ (Apomixis) — બીજ રચના વિનાની પ્રજનન પ્રક્રિયા; ડેન્ટલ (Dandelion) અને સિટ્રસમાં જોવા મળે છે.
પોલીએમ્બ્રિઓનિ (Polyembryony) — એક બીજમાં એકથી વધુ અંકુરો; સામાન્ય રીતે ફૂલકું બહુવિધ અંકુર ધરાવે છે.
સ્ત્રીબીજપટલ (Carpel) = ભવિષ્યની અંડકોષ; પરાગરજા ગ્રહણ પછી અંતઃકોષજ માર્ગદર્શિકા (Guidance) બનાવે છે.
ગર્ભાશયદી (Ovule) → ભૂમિ, નલિકા, ઇલિગમેન્ટમ, અંડકોષકોષ (Nucellus), બહિર્ત્વી (Integuments) ધરાવે છે.
પરાગકણનું અન્તઃકોષજ તરફ વધવાનો ગુણધર્મ — ગાઈડન્સ ટેક્સ (Chalazogamy) / મિક્સોગેમી / સ્ટિગમોગેમી.
ફૂલમાં અન્તર્ગ્રંથિ (Ovary) — ઉપરી (Superior) અથવા અધોરી (Inferior) હોઈ શકે છે.
બીજકણમાંથી નવર (Generative cell) વિભાજિત થઈ બે સ્પર્મજન્યુસ બનાવે છે.
