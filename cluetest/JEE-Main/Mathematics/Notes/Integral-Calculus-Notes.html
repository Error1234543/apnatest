1. समाकलन की मूलभूत अवधारणा (Fundamental Concept of Integration)

समाकलन, अवकलन का व्युत्क्रम है। यदि d/dx [F(x)] = f(x), तो ∫f(x)dx = F(x) + C, जहाँ C समाकलन स्थिरांक (constant of integration) है। समाकलन दो प्रकार के होते हैं—अनिश्चित समाकलन (indefinite integral), जिसमें सीमाएँ नहीं होतीं और परिणाम एक फलन + C के रूप में मिलता है; तथा निश्चित समाकलन (definite integral), जिसमें ऊपरी ও निचली सीमाएँ होतीं हैं और परिणाम एक संख्या होती है।

महत्वपूर्ण बिंदु:
• समाकलन अवकलन से कम 'कठिन' होता है क्योंकि अवकलन में हम सूत्र लागू करते हैं, पर समाकलन में प्रतिपादन करने वाले रूप को पहचानना पड़ता है।
• प्रत्येक अनिश्चित समाकलन के साथ C जोड़ना अनिवार्य है, क्योंकि d/dx(constant) = 0 होता है।
• JEE Main में ∫dx, ∫k·f(x)dx, रैखिकता (linearity) जैसे आधारभूत नियम बार-बार पूछे जाते हैं।
• समाकलन में चिह्न का ध्यान रखें: √(x²) = |x|, ln(x) केवल धनात्मक x के लिए परिभाषित, आदि।

2. मानक समाकलन सूत्र (Standard Integrals)

ये सूत्र समाकलन की आधारशिला हैं। इन्हें अवकलन करके सत्यापित किया जा सकता है:

बहुपद: ∫x^n dx = x^(n+1)/(n+1) + C, जहाँ n ≠ -1
इकाई: ∫dx = x + C

घातांकीय: ∫e^x dx = e^x + C, ∫a^x dx = a^x/ln(a) + C
लघुगणकीय: ∫(1/x)dx = ln|x| + C

वज्रज्या-विलोम (Trigonometric):
∫sin x dx = -cos x + C
∫cos x dx = sin x + C
∫sec²x dx = tan x + C
∫cosec²x dx = -cot x + C
∫sec x·tan x dx = sec x + C
∫cosec x·cosec x dx = -cosec x + C

प्रतिवज्रज्या-विलोम (Inverse trigonometric):
∫1/√(1-x²) dx = sin⁻¹x + C = -cos⁻¹x + C₁
∫1/(1+x²) dx = tan⁻¹x + C = cot⁻¹x + C₁
∫1/(x√(x²-1)) dx = sec⁻¹x + C, |x| > 1

यूलीय संबंध (अतिपरवलयिक):
∫1/√(x²+a²) dx = ln|x + √(x²+a²)| + C = sinh⁻¹(x/a) + C
∫1/√(x²-a²) dx = ln|x + √(x²-a²)| + C = cosh⁻¹(x/a) + C, |x| > a

सावधानी: ∫1/x dx = ln|x| + C, न कि ln x + C; x < 0 होने पर ln x अपरिभाषित है।

3. प्रतिस्थापन विधि (Substitution Method)

जब समाकल्य को किसी उपयुक्त फलन u = g(x) के द्वारा सरल बनाया जा सके, तब प्रतिस्थापन विधि प्रयुक्त होती है।

विधि:
1) u = g(x) मान लें।
2) du = g'(x)dx निकालें।
3) ∫f(x)dx को ∫f(x(u))·(dx/du)du के रूप में लिखें।
4) u के सापेक्ष समाकलन करें, फिर x वापस रखें।

प्रमुख प्रतिस्थापन:
• ∫f(g(x))·g'(x)dx → u = g(x)
• √(a²-x²) प्रकार → x = a sin θ या x = a cos θ
• √(a²+x²) प्रकार → x = a tan θ
• √(x²-a²) प्रकार → x = a sec θ
• ax²+bx+c → pūrṇ varg में बदलें या x = t - b/(2a)
• अपरिमेय: √(ax+b) = t, √((ax+b)/(cx+d)) = t

उदाहरण:
∫x·√(1-x²)dx में u = 1-x², du = -2x dx → -½∫√u du = -½·(2/3)u^(3/2)+C = -(1/3)(1-x²)^(3/2)+C

सामान्य त्रुटि: du/dx निकालने में चिह्न भूल जाना, या अंत में x वापस न रखना।

4. खंडशः समाकलन (Integration by Parts)

उत्पत्ति: ∫u dv = uv - ∫v du, जो गुणनफल नियम d(uv)/dx = u·dv/dx + v·du/dx से आती है।

ILATE नियम (प्रथम चयन के लिए):
I = Inverse trigonometric
L = Logarithmic
A = Algebraic
T = Trigonometric
E = Exponential

जिसका क्रम पहले आता है, उसे u मानें। शेष को dv मानकर समाकलन करें।

महत्वपूर्ण उदाहरण:
• ∫ln x dx = x ln x - x + C (u = ln x, dv = dx)
• ∫sin⁻¹x dx = x sin⁻¹x + √(1-x²) + C
• ∫x·e^x dx = x e^x - e^x + C
• ∫x·sin x dx = -x cos x + sin x + C
• ∫e^x[f(x)+f'(x)]dx = e^x·f(x) + C (प्रत्यक्ष सूत्र)

कठिन अवस्थाएँ:
• दो बार खंडशः लगाना पड़े (जैसे ∫e^x·cos x dx, ∫e^x·sin x dx) → इकाई प्राप्त होती है, फलन को एक तरफ ले जाएँ।
• लघुगणकीय + त्रिकोणमितीय: ∫ln(sinx)dx जैसी समस्याओं में प्रतिस्थापन + खंडशः संयोजन।
• ILATE का उल्टा क्रम कभी-कभी काम करता है जब सामान्य चयन असफल रहे।

5. आंशिक भिन्न विधि (Partial Fractions)

यह विधि तब प्रयुक्त होती है जब समाकल्य एक परिमेय फलन (rational function) P(x)/Q(x) हो, जहाँ deg(P) < deg(Q)।

प्रकार एवं प्रत्याश्व भिन्न:

Type 1: Q(x) = (x-a)(x-b), a≠b
P(x)/[(x-a)(x-b)] = A/(x-a) + B/(x-b)

Type 2: Q(x) = (x-a)²
P(x)/(x-a)² = A/(x-a) + B/(x-a)²

Type 3: Q(x) = (x-a)(x²+bx+c), जहाँ x²+bx+c अविखंडनीय
P(x)/[(x-a)(x²+bx+c)] = A/(x-a) + (Bx+C)/(x²+bx+c)

गुणांक निर्धारण:
• A, B, C के मान x के विशिष्ट मान रखकर या गुणांक तुलना द्वारा ज्ञात करें।
• (x-a) = 0 रखने से A निकल आता है (Heaviside cover-up method)।

सामान्य समाकलन परिणाम:
• ∫A/(x-a)dx = A·ln|x-a|
• ∫B/(x-a)²dx = -B/(x-a)
• ∫(Bx+C)/(ax²+bx+c)dx → अंश को (derivative of denominator) के रूप में लिखें
• ∫1/(x²+a²)dx = (1/a)tan⁻¹(x/a)

सामान्य त्रुटि: हर का उचित अवयवीकरण न करना, अविखंडनीय द्विघात को आगे भिन्न नहीं तोड़ना, या A, B, C ज्ञात करते समय चिह्न भूल जाना।

6. कुछ महत्वपूर्ण विशेष समाकलन (Special Integrals)

ये कुछ ऐसे समाकलन हैं जो JEE Main में बार-बार पूछे जाते हैं:

1) ∫dx/(x²-a²) = (1/2a)·ln|(x-a)/(x+a)| + C
2) ∫dx/(a²-x²) = (1/2a)·ln|(a+x)/(a-x)| + C
3) ∫dx/(x²+a²) = (1/a)·tan⁻¹(x/a) + C
4) ∫dx/√(x²-a²) = ln|x+√(x²-a²)| + C
5) ∫dx/√(a²-x²) = sin⁻¹(x/a) + C
6) ∫dx/√(x²+a²) = ln|x+√(x²+a²)| + C
7) ∫√(a²-x²)dx = (x/2)√(a²-x²) + (a²/2)sin⁻¹(x/a) + C
8) ∫√(x²+a²)dx = (x/2)√(x²+a²) + (a²/2)ln|x+√(x²+a²)| + C
9) ∫√(x²-a²)dx = (x/2)√(x²-a²) - (a²/2)ln|x+√(x²-a²)| + C
10) ∫√(ax+b) dx = (2/3a)·(ax+b)^(3/2) + C

वर्गमूल वाले बहुपदों के समाकलन (∫√(ax²+bx+c)dx):
• पूर्ण वर्ग बनाकर, फिर सूत्र 7-9 का उपयोग करें।
• ax²+bx+c > 0 होने की शर्त सदैव जाँचें।

ध्यान दें: इन सभी सूत्रों को अवकलन से पुनः सत्यापित कर लें—यही सबसे अच्छा अभ्यास है।

7. निश्चित समाकलन और उसके गुण (Definite Integral and Properties)

Fundamental Theorem of Calculus:
यदि F'(x) = f(x), तो ∫_a^b f(x)dx = F(b) - F(a)

महत्वपूर्ण गुण (Properties):

P1: ∫_a^b f(x)dx = -∫_b^a f(x)dx
P2: ∫_a^a f(x)dx = 0
P3: ∫_a^b f(x)dx = ∫_a^b f(a+b-x)dx ← सबसे अधिक प्रयोग होने वाला
P4: ∫_0^a f(x)dx = ∫_0^a f(a-x)dx (P3 का विशेष case)
P5: सम फलन: ∫_{-a}^{a} f(x)dx = 2∫_0^a f(x)dx, यदि f(-x)=f(x)
विषम फलन: ∫_{-a}^{a} f(x)dx = 0, यदि f(-x)=-f(x)
P6: ∫_a^b f(x)dx = ∫_a^b f(a+b-x)dx
P7: ∫_0^{2a} f(x)dx = ∫_0^a [f(x)+f(2a-x)]dx
यदि f(2a-x) = -f(x), तो ∫_0^{2a} f(x)dx = 0

निश्चित समाकलन के लाभ:
• समाकलन स्थिरांक C नहीं आता।
• ग्राफीय रूप से: वक्र y=f(x), x-अक्ष, x=a, x=b से घिरा क्षेत्रफल।

सावधानियाँ:
• f(x) discontinuous हो तो समाकलन अपसरित (divergent) हो सकता है।
• निरंतरता (continuity) की जाँच अनिवार्य है।
• ∫_{-π/2}^{π/2} sin(nx)dx = 0 (विषम फलन)।
• ∫_0^{π} x·f(sin x)dx = (π/2)·∫_0^{π} f(sin x)dx

8. वक्रों द्वारा परिबद्ध क्षेत्र (Area Under Curves)

वक्र y = f(x), x-अक्ष, और रेखाएँ x = a, x = b द्वारा घिरा क्षेत्रफल:
A = |∫_a^b f(x)dx|

यदि f(x) x-अक्ष को काटे, तो:
A = ∫_a^α |f(x)|dx + ∫_α^b |f(x)|dx, जहाँ α वह मूल है।

प्रमुख उदाहरण:
1) Parabola y² = 4ax और रेखा x = a:
A = ∫₀ᵃ 2√(4ax) dx = 2·(2/3)·√(4a)·[x^(3/2)]₀ᵃ = (8a²)/3

2) वृत्त x²+y²=a² का एक चतुथांश:
A = ∫₀ᵃ √(a²-x²)dx = (πa²)/4

3) ज्या (sine) वक्र y = sin x, 0 से π तक:
A = ∫₀^π sin x dx = [-cos x]₀^π = 2

4) परवलय y = x² और रेखा y = 4:
प्रतिच्छेद बिन्दु: x = ±2
A = ∫_{-2}^2 (4-x²)dx = 2∫_0^2 (4-x²)dx = 2·[4x - x³/3]₀² = 2·(8-8/3) = 32/3

XY-अक्ष के सापेक्ष समाकलन:
यदि वक्र x = g(y), y=c, y=d हो, तो A = ∫_c^d g(y)dy

Zig-zag वक्र (sin, cos) में निरंतरता और चिह्न परिवर्तन बिन्दुओं पर ध्यान दें।

9. द्विक समाकलन एवं सूत्रीय संयोजन (Double Integrals & Formula Applications)

JEE Main स्तर पर द्विक समाकलन (double integrals) सीधा पूछा नहीं जाता, पर निश्चित समाकलन के सूत्रों के संयोजन से संबंधित प्रश्न बार-बार आते हैं।

महत्वपूर्ण संयोजन सूत्र:
• ∫₀^π x·f(sin x)dx = (π/2)·∫₀^π f(sin x)dx
• ∫₀^{π/2} f(sin x, cos x)dx = ∫₀^{π/2} f(cos x, sin x)dx
• ∫₀^{2π} f(sin x, cos x)dx = 2∫₀^π f(sin x, cos x)dx (सम सममिति)

Wallis-type प्रश्न:
• ∫₀^{π/2} sinⁿx dx = ∫₀^{π/2} cosⁿx dx
n विषम: [(n-1)!! / n!!] · 1
n सम: [(n-1)!! / n!!] · (π/2)

समुच्चय सिद्धांत सम्बन्धी:
• ∫_a^b f(x)dx + ∫_c^d f(x)dx = ∫_a^d f(x)dx + ∫_c^b f(x)dx (अतिव्यापन सम्बन्ध)

प्रतिस्थापन के बाद लब्ध निश्चित समाकलन में सीमाएँ भी बदलती हैं:
यदि x = g(t), तो a → g⁻¹(a), b → g⁻¹(b)

10. अक्सर पूछे जाने वाले प्रश्न प्रकार एवं नुस्खा (Exam-Focused Problem Types)

JEE Main में Integral Calculus से निम्नलिखित प्रकार के प्रश्न आते हैं:

Type 1 — मानक समाकलन से सीधा प्रश्न:
उदा: ∫(3x²+2x+1)dx = ?
नुस्खा: पद-दर-पद x^(n+1)/(n+1) लगाएँ।

Type 2 — प्रतिस्थापन:
उदा: ∫x·e^(x²)dx, ∫dx/√(9-4x²)
नुस्खा: u चयन करके du निकालें, सीमाएँ बदलें यदि निश्चित हो।

Type 3 — खंडशः समाकलन:
उदा: ∫x²·e^x dx, ∫x·cos x dx
नुस्खा: ILATE से u चुनें, आवश्यक हो तो दो बार लगाएँ।

Type 4 — आंशिक भिन्न:
उदा: ∫dx/(x²-5x+6)
नुस्खा: हर के अवयव बनाएँ, आंशिक भिन्न में तोड़ें।

Type 5 — निश्चित समाकलन के गुण:
उदा: ∫_0^{π/2} sin²x dx
नुस्खा: ∫_0^{π/2} f(sin x)dx = ∫_0^{π/2} f(cos x)dx का उपयोग करें।

Type 6 — क्षेत्रफल:
उदा: y=x² और y=2x के बीच का क्षेत्रफल
नुस्खा: प्रतिच्छेद बिन्दु ज्ञात करें, बड़ा वक्र - छोटा वक्र का समाकलन करें।

Type 7 — f(x)+f(-x) या सम-विषम फलन:
नुस्खा: f(x) के सम/विषम भागों में विश्लेषण करें।

Type 8 — निरंतरता की जाँच:
उदा: ∫_0^2 f(x)dx जहाँ f(x) में x=1 पर असंततता
नुस्खा: समाकलन को ∫_0^1 + ∫_1^2 में बाँटें, प्रत्येक का सीमा मान लें।

Important facts

  • समाकलन, अवकलन का व्युत्क्रम है; ∫f(x)dx = F(x)+C
  • ILATE नियम: Inverse trig > Log > Algebraic > Trigonometric > Exponential — पहले u के लिए इस क्रम में चयन करें
  • ∫x^n dx = x^(n+1)/(n+1)+C, n≠-1 (n=-1 के लिए ln|x|)
  • ∫_a^b f(x)dx = ∫_a^b f(a+b-x)dx — सबसे अधिक प्रयुक्त गुण
  • सम फलन: ∫_{-a}^{a}f(x)dx = 2∫_0^a f(x)dx; विषम फलन: ∫_{-a}^{a}f(x)dx = 0
  • आंशिक भिन्न में पहले deg(P) < deg(Q) होना चाहिए, नहीं तो भागाई करवाएँ
  • निश्चित समाकलन में C नहीं आता; सीमाएँ भी प्रतिस्थापन के साथ बदल जाती हैं
  • ∫e^x[f(x)+f'(x)]dx = e^x·f(x)+C — प्रत्यक्ष सूत्र
  • वर्गमूल वाले समाकलनों के लिए पूर्ण वर्ग बनाएँ, फिर मानक सूत्र लागू करें
  • क्षेत्रफल हमेशा धनात्मक लें: A = |∫_a^b f(x)dx|

Common mistakes

  • ∫1/x dx में |x| भूलकर ln x लिख देना — ऋणात्मक x के लिए अमान्य
  • प्रतिस्थापन में du निकालने के बाद चिह्न (ऋण/धन) भूल जाना
  • निश्चित समाकलन में प्रतिस्थापन के बाद सीमाएँ न बदलना
  • खंडशः समाकलन में u और dv का चयन ILATE के उल्टा क्रम में करना
  • आंशिक भिन्न में हर का अवयवीकरण करने से पहले deg(P) ≥ deg(Q) की जाँच न करना
  • ∫dx/(x²-a²) में ln|...| के स्थान पर tan⁻¹ लगाना — यह galti बहुत आम है
  • क्षेत्रफल ज्ञात करते समय चिह्न न लेना — निरंतर फलन x-अक्ष को काटता हो तो मापांक आवश्यक है
  • समाकलन के अंत में +C भूल जाना (अनिश्चित समाकलन में)
  • f(2a-x) = -f(x) होने पर ∫_0^{2a}f(x)dx = 0 यह भूल जाना
  • वृत्त/अर्धवृत्त क्षेत्रफल में √(a²-x²) के समाकलन के सूत्र को याद किए बिना सीधा हल करने का प्रयास
  • निश्चित समाकलन में असंतत बिन्दु पर विभाजन न करना जब f discontinuous हो
  • x²+a² वाले हर में tan⁻¹ सूत्र के अग्र भाग में a (न कि √a) आता है — (1/a)tan⁻¹(x/a)
