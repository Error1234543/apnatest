z = a + ib, where i² = −1

Symbols: a = वास्तविक भाग (Re(z)), b = काल्पनिक भाग (Im(z)), i = √−1

Unit: N/A

When to use: कॉम्प्लेक्स नंबर का मानक रूप, सभी सूत्रों की आधारशिला

Conditions: a और b वास्तविक संख्याएँ हैं

Common mistake: i² = −1 को भूलकर i² = 1 ले लेना, या Re(z) और Im(z) में b को भूलकर a लिख देना

|z| = √(a² + b²)

Symbols: |z| = मापांक (modulus), a = Re(z), b = Im(z)

Unit: N/A

When to use: कॉम्प्लेक्स नंबर की दूरी मूल बिंदु से, ज्‍यामितीय व्याख्या

Conditions: a, b ∈ ℝ

Common mistake: मापांक ऋणात्मक लेना; |z| हमेशा अऋणात्मक होता है। या √(a²+b²) को a+ib समझ लेना

z · z̄ = |z|² = a² + b²

Symbols: z̄ = संयुग्मी (conjugate) = a − ib

Unit: N/A

When to use: संयुग्मी के गुणनफल से मापांक ज्ञात करना; हर को परिमेय बनाना

Conditions: z = a + ib

Common mistake: z̄ = −a − ib लिख देना (चिन्ह गलत); या z + z̄ = |z|² मान लेना

z⁻¹ = z̄ / |z|² = (a − ib)/(a² + b²)

Symbols: z⁻¹ = व्युत्क्रम (multiplicative inverse)

Unit: N/A

When to use: कॉम्प्लेक्स विभाजन (division) सरल बनाने के लिए

Conditions: z ≠ 0

Common mistake: हर को केवल |z| से भाग देना, |z|² नहीं

arg(z) = tan⁻¹(b/a) — चतुर्थांश ध्यान रखें

Symbols: arg(z) = कोणांक (argument), a = Re(z), b = Im(z)

Unit: रेडियन (rad) या अंश (°)

When to use: ध्रुवीय रूप में बदलाव, घातांकीय रूप

Conditions: z ≠ 0; a > 0, b > 0 (प्रथम चतुर्थांश) के लिए सरल

Common mistake: tan⁻¹(b/a) सीधा ले लेना बिना चतुर्थांश देखे; arg(z) की मुख्य श्रेणी (−π, π] को न जानना

z = r(cos θ + i sin θ) = r cis θ (ध्रुवीय रूप)

Symbols: r = |z|, θ = arg(z)

Unit: N/A

When to use: गुणा, भाग, घात, मूल निकालने के लिए सबसे उपयोगी

Conditions: r ≥ 0

Common mistake: r को ऋणात्मक लेना; cos और sin में अंश/कोणांक बदल देना

z = re^(iθ) (घातांकीय रूप — Euler's form)

Symbols: e^(iθ) = cos θ + i sin θ (Euler's identity)

Unit: N/A

When to use: गुणा/भाग/घात सबसे सरल: e^(iθ₁)·e^(iθ₂) = e^(i(θ₁+θ₂))

Conditions: r ≥ 0

Common mistake: e^i × e^j = e^(ij) जैसे गलत नियम लगाना; घातांक जोड़ने-घटाने का नियम ठीक है

z₁·z₂ = r₁r₂[cos(θ₁+θ₂) + i sin(θ₁+θ₂)]

Symbols: r₁,r₂ मापांक; θ₁,θ₂ कोणांक

Unit: N/A

When to use: ध्रुवीय रूप में दो कॉम्प्लेक्स संख्याओं का गुणन

Conditions: —

Common mistake: कोणांक जोड़ने की जगह गुणा कर देना; मापांक जोड़ देना

z₁/z₂ = (r₁/r₂)[cos(θ₁−θ₂) + i sin(θ₁−θ₂)]

Symbols: r₁/r₂ = मापांकों का भागफल; θ₁−θ₂ = कोणांकों का अंतर

[zⁿ = rⁿ(cos nθ + i sin nθ)] — De Moivre's Theorem

Symbols: n = पूर्णांक (positive/negative)

Unit: N/A

When to use: किसी कॉम्प्लेक्स नंबर की घात ज्ञात करना

Conditions: n ∈ ℤ; z ≠ 0

Common mistake: n के बाद कोणांक को n से गुणा न करना; cos(nθ) की जगह cos θ(n) लिख देना

z^(1/n) = r^(1/n)[cos((θ+2kπ)/n) + i sin((θ+2kπ)/n)], k = 0,1,...,n−1

Symbols: k = 0 से n−1 तक; n-वें मूलों की ठीक n संख्या

Unit: N/A

When to use: इकाई के घातांक मूल (nth roots of unity)

Conditions: z ≠ 0

Common mistake: k के mूल्य 0 से n तक ले लेना (n+1 मूल बन जाते हैं); cos/sin में 2kπ भूल जाना
