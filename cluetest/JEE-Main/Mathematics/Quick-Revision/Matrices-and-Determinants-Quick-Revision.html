Matrices and Determinants — Quick Revision (JEE Main)

JEE MainHindiQuick Revision

Definitions

  • Matrix: rectangular array of numbers arranged in rows and columns, written as A = [a_ij]_{m×n}. Order means m rows × n columns.
  • Square Matrix: matrix having equal number of rows and columns (n×n). Diagonal elements are a_ii where i = 1 to n.
  • Determinant: scalar value defined only for square matrices. For 2×2 matrix [[a,b],[c,d]], determinant = ad - bc. Denoted by |A| or det(A).
  • Trace: sum of diagonal elements of a square matrix, tr(A) = a_11 + a_22 + ... + a_nn.
  • Singular Matrix: square matrix whose determinant equals zero (|A| = 0). Such matrix has no inverse.
  • Non-Singular Matrix: square matrix with non-zero determinant (|A| ≠ 0). Such matrix always has an inverse.
  • Transpose: matrix obtained by interchanging rows and columns. If A = [a_ij], then A^T = [a_ji]. (A^T)^T = A, (kA)^T = kA^T, (AB)^T = B^T A^T.
  • Symmetric Matrix: square matrix satisfying A^T = A, meaning a_ij = a_ji for all i,j.
  • Skew-Symmetric Matrix: square matrix satisfying A^T = -A, meaning a_ij = -a_ji. All diagonal elements must be zero. Order must be even for non-zero skew-symmetric matrix with real entries to have non-zero determinant.
  • Diagonal Matrix: square matrix where all off-diagonal elements are zero, a_ij = 0 for i ≠ j.
  • Scalar Matrix: diagonal matrix where all diagonal elements are equal, A = kI.
  • Identity Matrix (Unit Matrix): diagonal matrix with all diagonal elements equal to 1, denoted by I_n or simply I.
  • Elementary Row Operations: three types — (1) Interchange two rows R_i ↔ R_j, (2) Multiply a row by non-zero constant k: R_i → kR_i, (3) Add multiple of one row to another: R_i → R_i + kR_j.
  • Adjoint Matrix: adj(A) is the transpose of the cofactor matrix. Cofactor C_ij = (-1)^{i+j} M_ij, where M_ij is the minor (determinant of submatrix obtained by deleting row i and column j).
  • Inverse of a Matrix: A^{-1} exists only if A is non-singular. A^{-1} = (1/|A|) · adj(A). Also AA^{-1} = A^{-1}A = I.

Key concepts

  • Properties of Determinants: (1) |A^T| = |A|. (2) If any row/column has all zeros, determinant is zero. (3) Interchanging two rows/columns changes sign. (4) Multiplying a row/column by k multiplies determinant by k. (5) If two rows/columns are identical, determinant is zero. (6) If elements of one row/column are expressed as sum, determinant splits into sum of determinants. (7) Operating R_i → R_i + kR_j does not change determinant value.
  • Sarrus Rule: valid only for 3×3 matrices. Extend first two columns to the right; sum of products of diagonals from top-left to bottom-right minus sum of products of diagonals from bottom-left to top-right.
  • Cramer's Rule: for system AX = B where A is non-singular n×n, unique solution is X = A^{-1}B. For 2×2 or 3×3, x = |A_1|/|A|, y = |A_2|/|A|, z = |A_3|/|A| where A_i is matrix A with i-th column replaced by B.
  • Consistency of Linear Equations: For AX = B, (1) If |A| ≠ 0, unique solution exists, X = A^{-1}B, consistent. (2) If |A| = 0 and (adj A)B ≠ 0, no solution, inconsistent. (3) If |A| = 0 and (adj A)B = 0, infinitely many solutions, consistent but dependent.
  • Multiplication Property: |AB| = |A||B|. Generalises to |A_1 A_2 ... A_n| = |A_1||A_2|...|A_n|.
  • Properties of Inverse: (A^{-1})^{-1} = A, (A^T)^{-1} = (A^{-1})^T, (AB)^{-1} = B^{-1}A^{-1}, (A^n)^{-1} = (A^{-1})^n. For orthogonal matrix A (AA^T = I), A^{-1} = A^T.
  • Elementary Matrices: obtained by applying one elementary row operation to identity matrix. Post-multiplying by elementary matrix performs column operation; pre-multiplying performs row operation. Any invertible matrix can be reduced to I via elementary row operations.
  • Rank of a Matrix: maximum order of non-vanishing minor. Also equals number of non-zero rows in row-echelon form. Rank(A) ≤ min(m,n) for m×n matrix. Rank(AB) ≤ min(Rank(A), Rank(B)). Rank(A) = Rank(A^T).
  • Classification of Matrices by Rank: For n×n matrix A, if Rank(A) = n, A is non-singular. If Rank(A) < n, A is singular.
  • Key Formula — Matrix Equation Solutions: For AX = B, X = A^{-1}B when |A| ≠ 0. System is homogeneous when B = 0; trivial solution X = 0 always exists. Non-trivial solutions exist iff |A| = 0.
  • Properties of Symmetric and Skew-Symmetric: Sum of symmetric matrices is symmetric. Product of symmetric matrices is symmetric only if they commute (AB = BA). A^T A and AA^T are always symmetric. Every square matrix can be written as A = (1/2)(A + A^T) + (1/2)(A - A^T) — sum of symmetric and skew-symmetric matrices (unique decomposition). For skew-symmetric matrix of odd order, |A| = 0. If A is skew-symmetric and |A| ≠ 0, order of A is even.
  • Determinant of Block Matrix: For block matrix [[A,O],[C,D]] where A and D are square, |M| = |A||D|.
  • Useful Shortcuts for JEE: (1) If rows are proportional, |A| = 0. (2) Factor theorem for determinants: if substituting a value makes determinant zero, then (variable - that value) is a factor. (3) For triangular matrix, determinant = product of diagonal entries. (4) |kA| = k^n |A| for n×n matrix.

Important facts

  • For 2×2 matrix [[a,b],[c,d]], inverse exists iff ad - bc ≠ 0, and A^{-1} = (1/(ad-bc))[[d,-b],[-c,a]].
  • For 3×3 matrix, expanding along any row or column gives same result. Choose row/column with most zeros for speed.
  • If A is singular, then |adj(A)| = |A|^{n-1} = 0 for n ≥ 2. More generally, |adj(A)| = |A|^{n-1} for any n×n matrix.
  • For orthogonal matrix: A A^T = A^T A = I, so |A| = ±1 and A^{-1} = A^T.
  • For idempotent matrix: A^2 = A. Eigenvalues are 0 or 1. If also invertible, A = I.
  • For involutory matrix: A^2 = I, so A^{-1} = A.
  • Cayley-Hamilton Theorem: every square matrix satisfies its own characteristic equation. Characteristic equation: |A - λI| = 0. Used to find powers of matrices and inverses.
  • For 3×3 matrix, adj(adj(A)) = |A|^{n-2} A = |A| A when n = 3.
  • Rank nullity theorem: Rank(A) + Nullity(A) = n (number of columns). Nullity = dimension of solution space of AX = 0.
  • If A and B are invertible matrices of same order, (AB)^{-1} = B^{-1}A^{-1} — note the reversed order, a common exam trap.
  • If A is invertible, then |A^{-1}| = 1/|A|. Also |kA| = k^n|A|.
  • For polynomial determinants: if det(A) is a polynomial in x and f(x) is a factor, then x = root of f(x) makes determinant vanish.
  • The determinant of a matrix equals the product of its eigenvalues. Trace equals sum of eigenvalues.
  • For circulant determinant [[a,b,c],[c,a,b],[b,c,a]] = a^3 + b^3 + c^3 - 3abc = (a+b+c)(a^2+b^2+c^2-ab-bc-ca).
  • Vandermonde Determinant: |1, a, a^2; 1, b, b^2; 1, c, c^2| = (b-a)(c-a)(c-b). Frequently appears in JEE.

Memory aids

  • TAJ rule for 3×3 inverse: write matrix alongside first two columns, draw 3 down-right diagonals (positive product) and 3 up-right diagonals (negative product).
  • Cofactor expansion mnemonic: 'Checkerboard pattern +1/-1 starting from top-left as +'. Sign pattern: + - + / - + - / + - +.
  • 'SA' for Singular-Absolute: Singular means |A| = 0, Absolute value never negative but determinant can be negative — don't confuse.
  • For skew-symmetric: 'Skiww' — diagonal must be zero (can't ski on flat ground), order must be even for non-zero determinant.
  • 'AB' inverse becomes 'BA' reversed: think of putting on socks then shoes — to remove, take off shoes (B) first then socks (A).
  • |kA| = k^n|A|: remember 'k goes to power n because every row gets multiplied by k, and there are n rows.',
  • Characteristic equation shortcut: for 3×3 matrix, |A-λI| = -λ^3 + tr(A)λ^2 - (sum of principal minors)λ + |A| = 0.
  • Cramer's rule: 'Replace column, divide by original' — replace i-th column of coefficient matrix with constants, that determinant over original determinant gives x_i.
  • Every matrix decomposition: 'A = S + K' where S is symmetric half-sum (A+A^T)/2 and K is skew-symmetric half-difference (A-A^T)/2. Think 'Same + Kiddo'.

Exam tips

  • JEE Main pattern: 75 questions total (20 MCQ + 5 numerical per subject), 300 marks, 3 hours. Mathematics has 25 questions. +4 for correct MCQ, -1 for wrong MCQ, no negative marking for numerical-value questions.
  • In Matrices and Determinants, expect 2-4 questions directly from this chapter. Common question types: finding inverse, solving system of equations, determinant evaluation, properties-based MCQs, finding rank.
  • For numerical-type questions: always double-check your determinant calculation. One sign error gives wrong answer and no partial credit.
  • When a question gives conditions on A (like A is symmetric, skew-symmetric, orthogonal, singular), immediately write what those conditions imply mathematically before proceeding.
  • Use option elimination in MCQs: substitute simple values (like A = I, or a specific 2×2 matrix) to test general statements quickly.
  • For determinant problems with variables, look for common factors in rows/columns first — factorisation often reduces computation dramatically.
  • Memorise standard results: |adj(A)| = |A|^{n-1}, adj(adj(A)) = |A|^{n-2}A, and (kA)^{-1} formulas. These appear frequently as direct MCQs.
  • When asked about rank: perform Gaussian elimination (row reduction) systematically. Count non-zero rows in echelon form — that is the rank.
  • For consistency questions: compute |A| first. If non-zero, unique solution. If zero, check (adj A)B to decide between no solution or infinite solutions.
  • Practice writing any square matrix as sum of symmetric and skew-symmetric parts — this is a classic JEE Main proof/question type.
  • Time management: spend maximum 3-4 minutes per Mathematics question. If stuck, mark and move on. Return if time permits.
  • For 3×3 determinants with patterns (arithmetic progression in rows/columns, identical entries), the determinant is often zero — check this possibility before full expansion.
  • Numerical-value questions carry no negative marking — attempt all of them. Even partial method execution may help you reach the correct answer.

Common traps

  • Confusing (AB)^{-1} with A^{-1}B^{-1}. Correct: (AB)^{-1} = B^{-1}A^{-1}. Order reverses.
  • Assuming |A+B| = |A| + |B|. This is FALSE in general. Determinant is not linear.
  • Writing A^{-1} = adj(A)/|A| without checking |A| ≠ 0. Inverse does not exist for singular matrices.
  • Forgetting that (A^2)^{-1} = (A^{-1})^2, not A^{-2} as a separate concept — they are the same but notation confuses students.
  • Applying Cramer's rule when |A| = 0. Cramer's rule is valid ONLY when determinant is non-zero.
  • Assuming product of two symmetric matrices is always symmetric. Only true when AB = BA (they commute).
  • Thinking every skew-symmetric matrix has determinant zero. True only for ODD order. Even-order skew-symmetric matrices can have non-zero determinant.
  • For (kA)^{-1}, writing 1/k · A^{-1} instead of (1/k)A^{-1} = A^{-1}/k. Same thing actually but students often mess up scalar placement.
  • When using row operations to find inverse via [A|I], performing column operations mixed with row operations incorrectly. Must stick to one type.
  • Forgetting that elementary row operations preserve solution set but changing determinant values (except type 3: R_i → R_i + kR_j which preserves determinant).
  • Confusing trace property: tr(AB) = tr(BA) is TRUE but tr(A+B) ≠ tr(A)·tr(B). Also tr(A^2) ≠ (tr A)^2 generally.
  • In consistency of equations, forgetting the case |A|=0, (adj A)B=0 gives infinite solutions (not 'no solution'). Both conditions must be checked carefully.
  • When finding rank by row reduction, making arithmetic errors in determinant calculation at each step. Always verify with original matrix.
  • Assuming |A|^2 = |A^2|. Actually |A^2| = |A|·|A| = |A|^2 — this IS true! But students sometimes confuse with (|A|)^n = |A^n| which is also true. The trap is thinking determinant properties work like regular algebra everywhere.
