Card 1

बाइनोमियल प्रमेय क्या है? n एक धनात्मक पूर्णांक होने पर (x + a)^n का विस्तार कैसे लिखते हैं?

बाइनोमियल प्रमेय: यदि n एक धनात्मक पूर्णांक है, तो (x + a)^n = Σ(r=0 से n) ⁺nCᵣ · x^(n−r) · a^r या इसे इस प्रकार भी लिखा जा सकता है: (x + a)^n = ⁺nC₀·x^n + ⁺nC₁·x^(n−1)·a + ⁺nC₂·x^(n−2)·a² + … + ⁺nCₙ·a^n सामान्य पद (General Term): T_{r+1} = ⁺nCᵣ · x^(n−r) · a^r जहाँ r = 0, 1, 2, …, n इस विस्तार में कुल (n + 1) पद होते हैं।

Card 2

(x − a)^n का विस्तार और इसमें सामान्य पद का स्वरूप कैसे बदलता है?

(x − a)^n का विस्तार: (x − a)^n = ⁺nC₀·x^n − ⁺nC₁·x^(n−1)·a + ⁺nC₂·x^(n−2)·a² − … + (−1)^n·⁺nCₙ·a^n इसके लिए बस (x + a)^n के सूत्र में 'a' की जगह '(−a)' रख देते हैं: T_{r+1} = ⁺nCᵣ · x^(n−r) · (−a)^r = (−1)^r · ⁺nCᵣ · x^(n−r) · a^r ध्यान दें: विषम क्रमांक वाले पद (jodd position) ऋणात्मक होते हैं जबकि सम क्रमांक वाले पद धनात्मक रहते हैं।

Card 3

बाइनोमियल विस्तार के पदों की कुल संख्या और मध्यपद (Middle Term) कैसे निर्धारित करते हैं?

विस्तार में पदों की कुल संख्या = n + 1 मध्यपद (Middle Term) के नियम: प्रकरण 1: यदि n EVEN है, तो मध्यपद = T_{(n/2)+1} यह केवल एक ही मध्यपद होगा। उदाहरण: n = 4 पद = 5 मध्यपद = T_3 = ⁺⁴C₂ · x² · a² प्रकरण 2: यदि n ODD है, तो दो मध्यपद होंगे: T_{(n+1)/2} और T_{(n+3)/2} उदाहरण: n = 5 पद = 6 मध्यपद = T_3 और T_4 JEE Main परीक्षा में अक्सर mth पद को सामान्य रूप से T_m = T_{(m−1)+1} लिखकर पूछा जाता है।

Card 4

स्वतंत्र पद (Independent Term / Constant Term) कैसे ज्ञात करें?

स्वतंत्र पद वह पद होता है जिसमें चर (variable) की घात शून्य हो जाए। विधि: 1) सामान्य पद लिखें: T_{r+1} = ⁺nCᵣ · x^(n−r) · a^r 2) x की घात में r का मान रखकर समीकरण बनाएं: x की घात = 0 3) r का मान ज्ञात करें जो पूर्णांक आये (r ∈ Z और 0 ≤ r ≤ n) 4) प्राप्त r के लिए पद निकालें उदाहरण: (3x² − 2/x)^15 में स्वतंत्र पद T_{r+1} = ⁺¹⁵Cᵣ · (3x²)^(15−r) · (−2/x)^r x की घात = 2(15−r) − r = 30 − 3r = 0 ⇒ r = 10 स्वतंत्र पद = ⁺¹⁵C₁₀ · 3⁵ · (−2)¹⁰ नोट: यदि r पूर्णांक न आए तो स्वतंत्र पद अस्तित्व में नहीं होगा।

Card 5

बाइनोमियल गुणांकों के महत्वपूर्ण गुणधर्म कौन से हैं?

बाइनोमियल गुणांक: ⁺nC₀, ⁺nC₁, ⁺nC₂, …, ⁺nCₙ गुणधर्म 1: सभी गुणांकों का योग ⁺nC₀ + ⁺nC₁ + ⁺nC₂ + … + ⁺nCₙ = 2^n गुणधर्म 2: विषम क्रमांक वाले गुणांकों का योग = सम क्रमांक वाले गुणांकों का योग ⁺nC₀ + ⁺nC₂ + ⁺nC₄ + … = ⁺nC₁ + ⁺nC₃ + ⁺nC₅ + … = 2^(n−1) गुणधर्म 3: r×(nCr) = n×((n−1)C(r−1)) गुणधर्म 4: ∑(r=0 to n) ⁺nCᵣ/(r+1) = (2^(n+1)−1)/(n+1) गुणधर्म 5: सबसे बड़ा बाइनोमियल गुणांक • यदि n EVEN: सबसे बड़ा = ⁺nC_{n/2} • यदि n ODD: सबसे बड़े दो = ⁺nC_{(n−1)/2} और ⁺nC_{(n+1)/2} गुणधर्म 6: सम मापांक और विषम मापांक के बीच का अंतर ⁺nC₀ − ⁺nC₁ + ⁺nC₂ − … + (−1)^n·⁺nCₙ = 0

Card 6

ऋणात्मक और भिन्नात्मक घातों वाले द्विपद प्रमेय (Negative/Fractional Binomial) में क्या विशेष बात ध्यान रखनी चाहिए?

जब घात n ऋणात्मक या भिन्नात्मक हो, तब: (1 + x)^n = 1 + nx + n(n−1)x²/2! + n(n−1)(n−2)x³/3! + … यह अनंत श्रेणी है (शर्त: |x| < 1) मापांकीय गुणांक (Binomial Coefficient): ⁿCᵣ = n(n−1)(n−2)…(n−r+1)/r! मुख्य बिंदु: • यह केवल तभी वैध है जब |x| < 1 (अभिसरण की शर्त) • रैखिक सन्निकटन (Linear Approximation): (1+x)^n ≈ 1 + nx, यदि x बहुत छोटा हो • द्विघात सन्निकटन: (1+x)^n ≈ 1 + nx + n(n−1)x²/2 JEE Main पर अक्सर (1+x)^{-1}, (1+x)^{-2}, (1−x)^{-1} के विस्तार आधारभूत रूप में पूछे जाते हैं।

Card 7

द्विपद प्रमेय का उपयोग करके सन्निकटन (Approximation) कैसे करें?

JEE Main के लिए महत्वपूर्ण सन्निकटन प्रश्न: 1) यदि |x| बहुत छोटा हो (x → 0), तो: (1 + x)^n ≈ 1 + nx (1 − x)^n ≈ 1 − nx 2) √(1+x) ≈ 1 + x/2 − x²/8 + … 1/√(1+x) ≈ 1 − x/2 + 3x²/8 − … 3) (a + b)^n जहाँ b/a छोटा हो: (a+b)^n = a^n(1 + b/a)^n 4) (1+x)^n ≈ 1 + nx + n(n−1)x²/2 (1−x)^n ≈ 1 − nx + n(n−1)x²/2 उदाहरण: (1.02)^5 का सन्निकट मान ज्ञात करें (1 + 0.02)^5 ≈ 1 + 5(0.02) + 10(0.0004) = 1 + 0.10 + 0.004 = 1.104 आमतौर पर द्विघात पद तक की गणना पर्याप्त होती है।

Card 8

किसी द्विपद विस्तार में सबसे बड़ा पद (Greatest Term) कैसे ज्ञात करें?

(a + x)^n के विस्तार में r-th पद और (r+1)-th पद का अनुपात: T_r/T_{r+1} = [⁺nC_{r−1} · a^(n−r+1) · x^{r−1}] / [⁺nCᵣ · a^(n−r) · x^r] = (n − r + 1) · a / (r · x) सबसे बड़ा पद तब मिलता है जब: T_{r+1}/T_r ≥ 1 ⇒ r ≤ (n+1)|x| / (|a| + |x|) मान लीजिए m = (n+1)|x|/(|a|+|x|) प्रकरण 1: यदि m पूर्णांक है, तो T_m और T_{m+1} दोनों सबसे बड़े हैं (समान) प्रकरण 2: यदि m पूर्णांक नहीं है, तो m < r < m+1 वाले r के लिए T_{⌊m⌋+1} सबसे बड़ा पद होगा JEE Main पर आमतौर पर x = a वाले सरल प्रश्न पूछे जाते हैं।

Card 9

द्विपद प्रमेय के उपयोग से विभाज्यता (Divisibility) संबंधी प्रश्न कैसे हल करें?

विभाज्यता संबंधी महत्वपूर्ण प्रश्न पैटर्न: 1) (101)^50 > 10100 * (50/101)? → (100+1)^50 का विस्तार करके पहला कई पद निकालें और तुलना करें 2) n^2 − 1 को (n+1) से भाग देने पर शेषफल: इसमें द्विपद का प्रयोग सीधा न करें, बल्कि n ≡ −1 mod(n+1) का प्रयोग करें। 3) सामान्य सिद्धांत: किसी संख्या को (a ± 1) के रूप में लिखकर द्विपद प्रमेय लागू करें। उदाहरण: 99^10 का दहाई और इकाई अंक ज्ञात करें 99 = 100 − 1 99^10 = (100−1)^10 इकाई अंक: अंतिम पद (−1)^10 = 1 दहाई अंक: दूसरा अंतिम पद = ⁺¹⁰C₉·100¹·(−1)⁹ = −10 = 0 आता है दहाई में अतः इकाई = 1, दहाई = 0 JEE Main में अक्सर शेषफल (remainder) और अंकों से जुड़े प्रश्न आते हैं।

Card 10

बाइनोमियल विस्तार से संबंधित प्रमेय ⁿC₀ + ⁿC₁ + ⁿC₂ + … + ⁿCₙ = 2^n कैसे सिद्ध करें और इसके व्युत्पन्न (corollaries) क्या हैं?

सिद्ध: (1 + x)^n = Σ ⁺nCᵣ · x^r x = 1 रखने पर: (1+1)^n = Σ ⁺nCᵣ · 1^r 2^n = ⁺nC₀ + ⁺nC₁ + ⁺nC₂ + … + ⁺nCₙ ✓ व्युत्पन्न: 1) x = −1 रखने पर: 0 = ⁺nC₀ − ⁺nC₁ + ⁺nC₂ − … + (−1)^n·⁺nCₙ 2) x = 1 और x = −1 जोड़ने पर: 2^n + 0 = 2(⁺nC₀ + ⁺nC₂ + ⁺nC₄ + …) ∴ ⁺nC₀ + ⁺nC₂ + … = 2^(n−1) 3) ∫₀¹ (1+x)^n dx = [(1+x)^{n+1}/(n+1)]₀¹ = (2^{n+1} − 1)/(n+1) लेकिन ∫₀¹ Σ ⁺nCᵣ · x^r dx = Σ ⁺nCᵣ/(r+1) ∴ Σ ⁺nCᵣ/(r+1) = (2^{n+1}−1)/(n+1) 4) r · ⁺nCᵣ = n · ⁺ⁿ⁻¹C_{r−1} → सिद्ध: r·n!/((r!)((n−r)!)) = n·(n−1)!/(((r−1)!)((n−r)!))

Card 11

(a + b)^n और (a − b)^n के योग और अंतर से संबंधित महत्वपूर्ण सर्वसमिकाएँ कौन सी हैं?

1) (a+b)^n + (a−b)^n = 2[⁺nC₀·a^n + ⁺nC₂·a^{n−2}·b² + ⁺nC₄·a^{n−4}·b⁴ + …] (केवल सम मापांक वाले पद आते हैं) 2) (a+b)^n − (a−b)^n = 2[⁺nC₁·a^{n−1}·b + ⁺nC₃·a^{n−3}·b³ + …] (केवल विषम मापांक वाले पद आते हैं) 3) यदि n EVEN है: (a+b)^n + (a−b)^n = 2(a^n + ⁺nC₂·a^{n−2}b² + … + ⁺nCₙ·b^n) 4) विशेष स्थिति a = b = 1: 2^n + 0 = 2(⁺nC₀ + ⁺nC₂ + …) ∴ ⁺nC₀ + ⁺nC₂ + … = 2^(n−1) 5) a = 1, b = x रखने पर रैखिक संयोजन बना सकते हैं: (1+x)^n + (1−x)^n = 2Σ ⁺nC_{2k}·x^{2k} ये सर्वसमिकाएँ JEE Main में गुणांक ज्ञात करने वाले प्रश्नों में प्रायः प्रयुक्त होती हैं।

Card 12

ⁿC₀·ⁿCᵣ + ⁿC₁·ⁿC_{r+1} + ⁿC₂·ⁿC_{r+2} + … + ⁿC_{n−r}·ⁿCₙ का मान क्या होता है?

यह एक महत्वपूर्ण सर्वसमिका है जिसका मान ⁺²ⁿC_r होता है। प्रमाण: ज्ञात सर्वसमिका ⁺nC₀·⁺nCᵣ + ⁺nC₁·⁺nC_{r+1} + … + ⁺nC_{n−r}·⁺nCₙ = ⁺²ⁿC_r वैकल्पिक प्रमाण (Coefficient Comparison): (1+x)^n · (1+x)^n = (1+x)^{2n} बाएँ हाथ की ओर x^r का मापांक: ⁺nC₀·⁺nCᵣ + ⁺nC₁·⁺nC_{r−1} + … + ⁺nCᵣ·⁺nC₀ = ⁺²ⁿC_r यदि पदों को इस प्रकार लिखा जाए: S = ⁺nC₀·⁺nCᵣ + ⁺nC₁·⁺nC_{r+1} + … + ⁺nC_{n−r}·⁺nCₙ तो S = ⁺²ⁿC_r यह द्विपद प्रमेय का एक बहुत ही महत्वपूर्ण परिणाम है जो JEE Main में प्रत्यक्ष रूप से पूछा जा सकता है। अतिरिक्त महत्वपूर्ण परिणाम: Σ(⁺nCᵣ)² = ⁺²ⁿC_n

Card 13

द्विपद प्रमेय का उपयोग करके साबित करें कि 11^n − 10n − 1, 100 से विभाज्य है (n > 1)।

11^n = (10 + 1)^n (10+1)^n = ⁺ⁿC₀·10^n + ⁺ⁿC₁·10^{n−1} + ⁺ⁿC₂·10² + ⁺ⁿC₃·10¹ + ⁺ⁿCₙ·10⁰ = 10^n + n·10^{n−1} + [n(n−1)/2]·100 + … + 1 11^n − 10n − 1 = 10^n + n·10^{n−1} + 50n(n−1) + … + 1 − 10n − 1 चूँकि n > 1, प्रत्येक पद में कम से कम 100 का गुणनखंड है: • n·10^{n−1} में (n−1≥1) तो 10 का एक घात कम से कम है • n(n−1)/2 · 100 अवश्य 100 से विभाज्य है • 1 − 1 = 0 • शेष सभी पदों में 100 ≥ 10² इसलिए 11^n − 10n − 1 सदैव 100 से विभाज्य है। यह प्रश्न JEE Main में नियमित रूप से पूछा जाता है, जिसमें द्विपद विस्तार द्वारा शेषफल विश्लेषण किया जाता है।

Card 14

(1 + x)^n के विस्तार में r-th मापांक और (r+1)-th मापांक के अनुपात का सूत्र क्या है और इसका क्या महत्व है?

सामान्य द्विपद मापांक: ⁺nC₀, ⁺nC₁, ⁺nC₂, …, ⁺nCₙ मापांक अनुपात: ⁺nC_r / ⁺nC_{r−1} = [(n!)/(r!(n−r)!)] / [(n!)/((r−1)!(n−r+1)!)] = (n−r+1)/r इससे: ⁺nC_r = ⁺nC_{r−1} · (n−r+1)/r महत्व: 1) मापांक बढ़ते-बढ़ते अधिकतम होते हैं फिर घटते हैं 2) Maapank बड़ा होने का नियम: ⁺nC_r ≥ ⁺nC_{r−1} ⇔ r ≤ (n+1)/2 3) अधिकतम मापांक: r = ⌊(n+1)/2⌋ के पास JEE Main में 'सबसे बड़ा मापांक' वाले प्रश्न अक्सर इसी सूत्र से हल किए जाते हैं।

Card 15

(x + a)^n में mth बायाँ पद और mth दायाँ पद (m-th from beginning and end) क्या होते हैं?

(x+a)^n के विस्तार में कुल पद = n+1 m-th पद शुरू में (from beginning): T_m = ⁺nC_{m−1} · x^{n−(m−1)} · a^{m−1} = ⁺nC_{m−1} · x^{n−m+1} · a^{m−1} m-th पद अंत से (from end): T'_m = ⁺nC_{n−(m−1)} · x^{m−1} · a^{n−(m−1)} = ⁺nC_{m−1} · x^{m−1} · a^{n−m+1} (यह ⁺nC_{n−m+1} के बराबर है क्योंकि ⁺nC_k = ⁺nC_{n−k}) महत्वपूर्ण तथ्य: m-th पद from beginning = (n−m+2)-th पद from end JEE Main में अक्सर m-th मापांक का मान ज्ञात करना या समानता दिखानी होती है।

Card 16

(a+b)^n में चार लगातार पदों के मापांक A, B, C, D हों तो इनके बीच क्या संबंध होता है?

चौके लगातार पदों के मापांक: A = ⁺nC_{r−1}, B = ⁺nC_r, C = ⁺nC_{r+1}, D = ⁺nC_{r+2} महत्वपूर्ण संबंध: 1) B/A = (n−r+1)/r 2) C/B = (n−r)/(r+1) 3) D/C = (n−r−1)/(r+2) विशेष सर्वसमिका: B/A + C/B + D/C = (n+2)/r या अधिक प्रचलित संबंध: (A+B)(B+C) = (B+C)(C+D) ? नहीं, बल्कि: AC = BD × [कारक] मुख्य परिणाम (JEE Main): 1/A + 1/B + 1/C + 1/D जैसी राशि का मूल्यांकन या C/A, C/B, C/D जैसे अनुपात अधिक महत्वपूर्ण: B² = AC के समान नहीं, बल्कि: (⁺nC_r)² ≠ ⁺nC_{r−1} · ⁺nC_{r+1} (केवल विलोम क्रम में बराबर होता है यदि r = n/2)
