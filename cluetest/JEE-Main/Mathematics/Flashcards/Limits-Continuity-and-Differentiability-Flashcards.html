Card 1

सीमा (Limit) की परिभाषा क्या है? बाएँ और दाएँ सीमाएँ (Left & Right Hand Limits) कैसे पढ़ी जाती हैं?

यदि f(x) का मान x, a के सन्निकट आते समय किसी निश्चित संख्या L के अत्यंत निकट पहुँच जाता है, तो L को f(x) की a पर सीमा कहते हैं: lim(x→a) f(x) = L। बाएँ हाथ की सीमा (LHL): x, a से बाएँ से आए → lim(x→a⁻) f(x) = L₁ दाएँ हाथ की सीमा (RHL): x, a से दाएँ से आए → lim(x→a⁺) f(x) = L₂ सीमा अस्तित्व में तभी होगी जब LHL = RHL (दोनों बराबर और परिमित हों)।

Card 2

lim(x→0) sin x / x = 1 कैसे स्थापित किया जाता है? इसका उपयोग कैसे करें?

त्रिकोणमितीय असमिका से: शंकु में वृत्तखंड का क्षेत्रफल ≤ त्रिभुज ABC का क्षेत्रफल ≤ त्रिभुज OAB का क्षेत्रफल। इससे प्राप्त होता है: cos x < sin x / x < 1 (0 < x < π/2) x → 0⁺ रखने पर: cos 0 = 1, अतः सिज्‍वीप नियम से lim(x→0) sin x / x = 1 महत्वपूर्ण सामान्यीकरण: - lim(x→0) sin(ax) / bx = a/b - lim(x→0) tan x / x = 1 - lim(x→0) (sin⁻¹ x)/x = 1

Card 3

lim(x→0) (e^x - 1)/x = 1 और lim(x→0) log_e(1+x)/x = 1 — प्रमाण एवं सामान्य रूप?

ये दोनों मानक सीमाएँ जेएफ में अत्यंत महत्वपूर्ण हैं। प्रमाण (e^x - 1)/x के लिए: e^x = 1 + x + x²/2! + x³/3! + ... (घात श्रेणी विस्तार) e^x - 1 = x + x²/2! + x³/3! + ... (e^x - 1)/x = 1 + x/2! + x²/3! + ... x → 0 रखने पर: 1 + 0 + 0 + ... = 1 ∎ सामान्य रूप: - lim(x→0) (e^(ax) - 1)/(bx) = a/b - lim(x→0) log_e(1+ax)/bx = a/b - lim(x→0) (a^x - 1)/x = log_e a

Card 4

lim(x→0) (1+cos x)/x = ? और lim(x→∞) (1 + 1/x)^x = e — याद रखें

lim(x→0) (1 - cos x)/x = 0 (क्योंकि 1 - cos x ≈ x²/2, अतः (1-cos x)/x = x/2 → 0) लेकिन lim(x→0) (1+cos x)/x अनुशोषित (Indeterminate) नहीं है: अंश → 2, हर → 0 → यह ∞ की ओर अग्रसर है (सीमा अस्तित्व में नहीं है) 🔑 lim(x→∞) (1 + 1/x)^x = e 🔑 lim(x→0) (1 + x)^(1/x) = e सामान्यीकरण: lim f(x)^(g(x)) जहाँ f→1, g→∞ = e^{lim (f(x)-1)·g(x)}

Card 5

अनिर्धारित रूप (Indeterminate Forms) की पूरी सूची और पहचान कैसे करें?

जब सीमा सीधे स्थिरांक नहीं देती: 1. 0/0 — जब अंश व हर दोनों 0 की ओर जाएँ 2. ∞/∞ — जब अंश व हर दोनों अनांत की ओर जाएँ 3. 0 × ∞ — जब एक पद 0 की ओर व दूसरा ∞ की ओर जाए 4. ∞ - ∞ — दोनों अनांत पद घटाएँ 5. 0⁰ — आधार 0, घात 0 की ओर 6. 1^∞ — आधार 1 की ओर, घात ∞ की ओर 7. ∞⁰ — आधार ∞ की ओर, घात 0 की ओर पहचान: सीधा मान रखें। यदि अज्ञात रूप आए तो वह अनिर्धारित रूप है।

Card 6

अनिर्धारित रूपों को हल करने के मुख्य तकनीक क्या हैं? बाइनोमियल प्रमेय कब काम आता है?

मुख्य तकनीकें: 1. सरलीकरण: (x²-a²)/(x-a) जैसे रूप में उभयनिष्ठ काटें 2. लघुगणकीय विधि: y = [f(x)]^{g(x)} लेने पर log y = g(x)·log f(x) 3. चर प्रतिस्थापन: x = 1/h या x = a+h रखें 4. बाइनोमियल प्रमेय: जब (1 ± x)^n जहाँ n भिन्नात्मक/ऋणात्मक हो (1+x)^n = 1 + nx + n(n-1)x²/2! + ... (|x|<1) 5. लॉपिटल नियम (अगला फ्लैशकार्ड देखें) उदाहरण: lim(x→0) [(1+2x)^(1/x)] = e² (बाइनोमियल से: 1 + (1/x)(2x) + ... = e²)

Card 7

लॉपिटल नियम (L'Hôpital's Rule) क्या है? क्या हम इसे बार-बार लगा सकते हैं?

यदि lim(x→a) f(x)/g(x) का रूप 0/0 या ∞/∞ हो, तो: lim f(x)/g(x) = lim f'(x)/g'(x) शर्तें: - f(a)=0, g(a)=0 या f,g→∞ - g'(x) ≠ 0 सन्निकट बिंदु पर - lim f'(x)/g'(x) का अस्तित्व हो हाँ, हम बार-बार लगा सकते हैं: lim f/g = lim f'/g' = lim f''/g'' = ... जब तक अनिर्धारित रूप टूटे। ⚠️ चेतावनी: लॉपिटल केवल 0/0 व ∞/∞ पर लागू होता है। अन्य रूपों (जैसे 1^∞, ∞-∞) को पहले उपयुक्त रूप में बदलें।

Card 8

लॉपिटल नियम से तीन उदाहरण हल करें: 1) lim(x→0) sin x / x 2) lim(x→0) (e^x - 1-x)/x² 3) lim(x→∞) x/e^x

1) lim(x→0) sin x / x → 0/0 रूप → L'H.: cos x / 1 = cos 0 = 1 ✓ 2) lim(x→0) (e^x - 1 - x)/x² → 0/0 रूप → L'H.: (e^x - 1)/(2x) → पुनः 0/0 → L'H.: e^x/2 = 1/2 अतः उत्तर = 1/2 3) lim(x→∞) x/e^x → ∞/∞ रूप → L'H.: 1/e^x = 0 अतः उत्तर = 0 🔑 यही ज्ञात परिणाम: e^x, x के सापेक्ष तेज़ी से बढ़ता है।

Card 9

सीमाओं की गुणधर्म (Properties of Limits) — योग, गुणन, भाग के नियम

यदि lim f(x) = L व lim g(x) = M: 1. lim [f ± g] = L ± M 2. lim [c·f] = c·L (c स्थिरांक) 3. lim [f·g] = L·M 4. lim [f/g] = L/M (M ≠ 0) 5. lim [fⁿ] = Lⁿ 6. lim [√f] = √L (L ≥ 0) 7. lim [c] = c 8. lim xⁿ = aⁿ (नैसर्गिक संख्या n के लिए) 9. lim [f]^n = [lim f]^n ये नियम केवल तभी लागू होते हैं जब दोनों सीमाएँ परिमित हों।

Card 10

फंक्शन (फलन) क्या है? फंक्शन के प्रकार, प्रक्षेप (Domain), परिसर (Range) क्या हैं?

फलन: यदि प्रत्येक x ∈ A के लिए y ∈ B का एक ही निर्धारित मान हो, तो y = f(x) एक फलन है। प्रकार: 1. एक-एक (Injective/One-to-one): f(x₁)=f(x₂) → x₁=x₂ 2. आरोप्य (Surjective/Onto): प्रत्येक y ∈ B का पूर्वसंगी हो 3. एक-एक आरोप्य (Bijective): both injective + surjective 4. स्थिरांक फलन: f(x) = c 5. सर्वसमक फलन: f(x) = x 6. परिमेय फलन: P(x)/Q(x) 7. पूर्णांक फलन (Greatest Integer): ⌊x⌋ ≤ x < ⌊x⌋+1 8. निरंतरता परीक्षण फलन (Signum): sgn(x) = {-1,0,1} प्रक्षेप (Domain): सभी मान्य x परिसर (Range): सभी प्राप्त y

Card 11

निरंतरता (Continuity) की परिभाषा — गणित की भाषा में शर्तें

फलन f, बिंदु x=a पर निरंतर है यदि: 1. f(a) परिभाषित है (defined) 2. lim(x→a) f(x) अस्तित्व में है (LHL = RHL) 3. lim(x→a) f(x) = f(a) अंतराल [p,q] पर निरंतरता: - (p,q) के प्रत्येक आन्तरिक बिंदु पर निरंतर - बाएँ छोर पर दाएँ निरंतर: lim(x→p⁺) f(x) = f(p) - दाएँ छोर पर बाएँ निरंतर: lim(x→q⁻) f(x) = f(q) सामान्य नियम: बहुपद, परिमेय, त्रिकोणमितीय, घातांकीय, लघुगणकीय फलन अपने प्रादेशिक अंतराल पर निरंतर होते हैं।

Card 12

वियोजन (Discontinuity) के प्रकार — प्रथम व द्वितीय श्रेणी

प्रथम श्रेणी (First Kind): 1. खंडित वियोजन (Removable): LHL=RHL≠f(a) या f(a) अपरिभाषित 2. संपत्ति वियोजन (Jump/Finite): LHL≠RHL (दोनों परिमित) द्वितीय श्रेणी (Second Kind): 1. अनंत वियोजन (Infinite): LHL या RHL ∞ की ओर 2. आवधिक वियोजन (Oscillatory): LHL/RHL अस्तित्व में नहीं (sin(1/x) प्रकार) उदाहरण: - f(x)=sin x/x at x=0 → प्रथम श्रेणी, खंडित वियोजन - f(x)=1/x at x=0 → द्वितीय श्रेणी, अनंत वियोजन - f(x)=sin(1/x) at x=0 → द्वितीय श्रेणी, आवधिक वियोजन

Card 13

निरंतरता पर बीजीय संक्रियाएँ — क्या दो निरंतर फलनों का योग/गुणन निरंतर होता है?

यदि f व g, x=a पर निरंतर हैं, तो: 1. f ± g → निरंतर 2. c·f → निरंतर (c स्थिरांक) 3. f · g → निरंतर 4. f/g → निरंतर, जहाँ g(a) ≠ 0 5. fⁿ → निरंतर (n नैसर्गिक संख्या) 6. संयोजन (Composition): f(g(x)) → निरंतर, यदि g, a पर निरंतर व f, g(a) पर निरंतर 7. |f(x)| → निरंतर 8. √f(x) → निरंतर, जहाँ f(x) ≥ 0 ⚠️ सावधान: ⌊x⌋ जैसे पूर्णांक फलन निरंतर नहीं होते (पूर्णांक बिंदुओं पर कूद वियोजन)।

Card 14

अवकलनीयता (Differentiability) की परिभाषा — f'(a) क्या है?

फलन f, x=a पर अवकलनीय है यदि सीमा मौजूद हो: f'(a) = lim(h→0) [f(a+h) - f(a)] / h इसे f'(a) या df/dx|_{x=a} लिखा जाता है। महत्वपूर्ण: - अवकलनीयता → निरंतरता (सदैव सत्य) - निरंतरता → अवकलनीयता (हमेशा नहीं) - उदाहरण: f(x)=|x| at x=0 → निरंतर लेकिन अवकलनीय नहीं शर्तें: 1. f, x=a पर निरंतर होना चाहिए 2. बाएँ अवकलज = दाएँ अवकलज हो 3. दोनों परिमित हों

Card 15

nिरंतर लेकिन अवकलनीय नहीं — ऐसे उदाहरण और कारण

1. f(x) = |x| at x=0 LHD: lim(h→0⁻)(|h|-0)/h = -1 RHD: lim(h→0⁺)(|h|-0)/h = +1 LHD ≠ RHD → अवकलनीय नहीं 2. f(x) = (x)^(1/3) at x=0 f'(0) = lim(h→0) h^(1/3)/h = lim h^(-2/3) = ∞ → अवकलज अस्तित्व में नहीं (अनंत) 3. f(x) = x·sin(1/x), x≠0; f(0)=0 निरंतर है ( squeeze theorem से), पर x=0 पर अवकलनीय नहीं 🔑 नियम: कोणीय बिंदु (cusp/corner) या ऊर्ध्वाधर स्पर्शरेखा वाले बिंदु अवकलनीय नहीं होते।

प्रसिद्ध सीमाएँ (Standard Limits) — JEE Main के लिए याद रखें

1. lim(x→0) sin x/x = 1 2. lim(x→0) (1-cos x)/x² = 1/2 3. lim(x→0) tan x/x = 1 4. lim(x→0) (e^x-1)/x = 1 5. lim(x→0) log(1+x)/x = 1 6. lim(x→0) (a^x-1)/x = log a 7. lim(x→∞) (1+1/x)^x = e 8. lim(x→0) (1+x)^(1/x) = e 9. lim(x→0) sinh x/x = 1 10. lim(x→0) (x-sin x)/x³ = 1/6 11. lim(x→0) (tan x - sin x)/x³ = 1/2 12. lim(x→0) (e^x - 1 - x)/x² = 1/2

Card 17

साइन और कोसाइन की श्रेणी विस्तार (Series Expansion) — JEE Main के लिए

sin x = x - x³/3! + x⁵/5! - x⁷/7! + ... cos x = 1 - x²/2! + x⁴/4! - x⁶/6! + ... tan x = x + x³/3 + 2x⁵/15 + ... e^x = 1 + x + x²/2! + x³/3! + ... ln(1+x) = x - x²/2 + x³/3 - x⁴/4 + ... (1+x)^n = 1 + nx + n(n-1)x²/2! + ... श्रेणी विस्तार का उपयोग सीमा ज्ञात करने में अत्यंत उपयोगी है। उदाहरण: lim(x→0) (x-sin x)/x³ = lim(x→0) [x³/3! - x⁵/5!+...]/x³ = 1/6

Card 18

श्वार्ज़-क्रोन्रोकर प्रमेय (Squeeze/Sandwich Theorem) क्या है? उदाहरण सहित समझें

यदि g(x) ≤ f(x) ≤ h(x) सभी x ∈ I पर (a के सन्निकट) और lim(x→a) g(x) = lim(x→a) h(x) = L, तो: lim(x→a) f(x) = L उदाहरण 1: lim(x→0) x·sin(1/x) -1 ≤ sin(1/x) ≤ 1 -x ≤ x·sin(1/x) ≤ x x→0 रखने पर: -0 ≤ f ≤ 0 → सीमा = 0 उदाहरण 2: lim(x→0) x²·cos(1/x) - x² ≤ x²·cos(1/x) ≤ x² → 0 (Squeeze theorem) 🔑 यह प्रमेय कोणीय बिंदुओं पर निरंतरता सिद्ध करने में सहायक है।

Card 19

रोल का प्रमेय (Rolle's Theorem) — conditions व conclusion

योl के प्रमेय की शर्तें: 1. f, [a,b] पर निरंतर हो 2. f, (a,b) पर अवकलनीय हो 3. f(a) = f(b) निष्कर्ष: कम से कम एक c ∈ (a,b) मौजूद है जहाँ f'(c) = 0। उदाहरण: f(x) = x(x-2) on [0,2] - निरंतर व अवकलनीय ✓ - f(0)=0, f(2)=0 ✓ - f'(x) = 2x-2 = 0 → x=1 ∈ (0,2) ✓ ⚠️ चतुर्थ शर्त जरूरी है: f(x) = |x| on [-1,1]: - निरंतर ✓, पर x=0 पर अवकलनीय नहीं ✗ - f(-1)=f(1)=1, पर f'(c)=0 का कोई हल नहीं

Card 20

लग्रांज का मध्यमान प्रमेय (Lagrange's Mean Value Theorem) — कथन एवं अनुप्रयोग

शर्तें: 1. f, [a,b] पर निरंतर हो 2. f, (a,b) पर अवकलनीय हो निष्कर्ष: कम से कम एक c ∈ (a,b) मौजूद है जहाँ: f'(c) = [f(b) - f(a)] / (b - a) अर्थ: वक्र पर कोई बिंदु है जहाँ स्पर्शरेखा, जीवा AB के समांतर है। उदाहरण: f(x) = x² on [1,3] f'(c) = (9-1)/(3-1) = 4 2c = 4 → c = 2 ∈ (1,3) ✓ 🔑 रोल्स प्रमेय, लग्रांज प्रमेय का विशेष मामला है जब f(a)=f(b)।

Card 21

लेब्नीज प्रमेय (Leibniz Theorem) — nth derivative of product (u·v)

यदि y = u·v, तो: y_n = C(n,0)·u_n·v + C(n,1)·u_{n-1}·v_1 + C(n,2)·u_{n-2}·v_2 + ... + C(n,n)·u·v_n सংक्षेप में: y_n = Σ_{k=0}^{n} C(n,k) · u_{n-k} · v_k उदाहरण: y = x²·e^x, y_5 ज्ञात करें u=x²: u₂=2, u₃=u₄=u₅=0 v=e^x: v_k=e^x for all k y_5 = C(5,0)·0·e^x + C(5,1)·0·e^x + C(5,2)·2·e^x = 10·2·e^x = 20e^x

Card 22

logarithmic differentiation — कहाँ उपयोग करें? उदाहरण से समझें

जब f(x) [u(x)]^{v(x)} प्रकार का हो (चर घात वाली), तब logarithmic differentiation का उपयोग करें। विधि: y = [u(x)]^{v(x)} ln y = v(x)·ln u(x) (1/y)·y' = v'(x)·ln u + v·(u'/u) y' = y · [v'·ln u + v·u'/u] उदाहरण: y = x^{sin x} ln y = sin x · ln x (1/y)y' = cos x·ln x + sin x/x y' = x^{sin x} [cos x·ln x + sin x/x]

Card 23

पैरामेट्रिक अवकलन (Parametric Differentiation) — dx/dt, dy/dt से dy/dx कैसे ज्ञात करें?

यदि x = f(t) व y = g(t), तो: dy/dx = (dy/dt) / (dx/dt) उदाहरण: x = a(t + sin t), y = a(1 - cos t) dx/dt = a(1 + cos t) dy/dt = a sin t dy/dx = sin t/(1+cos t) = tan(t/2) d²y/dx² = d/dx(dy/dx) = (d/dt[tan(t/2)]) / (dx/dt) = [sec²(t/2)·(1/2)] / [a(1+cos t)] = sec²(t/2) / [2a·2cos²(t/2)] = 1/(4a·cos²(t/2))

गुणन नियम (Product Rule) — (uv)' = u'v + uv' का प्रमाण स्वरूप में
