Card 1

समाकलन (Integration) क्या है? इसका मूल सिद्धांत बताइए।

समाकलन, अवकलन का व्युत्क्रम (inverse) है। यदि d/dx[f(x)] = g(x), तो ∫g(x)dx = f(x) + C, जहाँ C समाकलन स्थिरांक है। मुख्य सिद्धांत: - ∫[af(x) + bg(x)]dx = a∫f(x)dx + b∫g(x)dx - ∫d/dx[f(x)]dx = f(x) + C - समाकलन की रैखिकता (Linearity) हमेशा लागू होती है। - C को केवल अंतिम उत्तर में जोड़ा जाता है, मध्य में नहीं।

मानक समाकलन सूत्र (Standard Integration Formulas) लिखिए:

∫xⁿdx = xⁿ⁺¹/(n+1) + C, n ≠ −1 ∫(1/x)dx = ln|x| + C ∫eˣdx = eˣ + C ∫aˣdx = aˣ/ln(a) + C ∫sin x dx = −cos x + C ∫cos x dx = sin x + C ∫sec²x dx = tan x + C ∫cosec²x dx = −cot x + C ∫sec x·tan x dx = sec x + C ∫cosec x·cot x dx = −cosec x + C ∫tan x dx = ln|sec x| + C = −ln|cos x| + C ∫cot x dx = ln|sin x| + C ∫sec x dx = ln|sec x + tan x| + C ∫cosec x dx = ln|cosec x − cot x| + C ∫1/√(1−x²)dx = sin⁻¹x + C ∫1/(1+x²)dx = tan⁻¹x + C ∫1/(x√(x²−1))dx = sec⁻¹x + C

Card 3

प्रतिस्थापन विधि (Substitution Method) — संपूर्ण नियम और उदाहरण

जब समाकल्य के दो भाग हों जिनमें से एक का अवकलज दूसरे भाग से संबंधित हो: माना u = g(x), तब du = g'(x)dx ∫f(g(x))·g'(x)dx = ∫f(u)du चरण: 1. उपयुक्त प्रतिस्थापन u चुनें। 2. du/dx ज्ञात करें। 3. dx को du के पदों में लिखें। 4. समाकलन करें, फिर वापस x में रखें। उदाहरण: ∫2x·cos(x²)dx u = x² ⇒ du = 2x dx = ∫cos u du = sin u + C = sin(x²) + C विशेष टिप: ∫f'(x)/f(x)dx = ln|f(x)| + C हमेशा याद रखें।

Card 4

खंडशः समाकलन (Integration by Parts) — सूत्र, ILATE नियम और उदाहरण

सूत्र: ∫u dv = uv − ∫v du ILATE नियम (प्रथम फलन चुनने का क्रम): I — Inverse trigonometric (sin⁻¹x, tan⁻¹x…) L — Logarithmic (ln x, log x…) A — Algebraic (x, x², polynomials) T — Trigonometric (sin x, cos x…) E — Exponential (eˣ, aˣ…) जिसका पहले आना, वह प्रथम फलन (u) बनेगा। उदाहरण: ∫x·eˣdx u = x, dv = eˣdx ⇒ du = dx, v = eˣ = x·eˣ − ∫eˣdx = x·eˣ − eˣ + C = eˣ(x−1) + C बहु बार पुनरावृत्ति चाहिए (जैसे ∫x²·eˣdx): ILATE दो बार लगाएँ।

Card 5

आंशिक भिन्न विधि (Partial Fractions) — संपूर्ण विधि

जब समाकल्य rational function p(x)/q(x) हो, जहाँ degree(p) < degree(q): स्थिति 1: q(x) = (x−a)(x−b), a ≠ b p(x)/[(x−a)(x−b)] = A/(x−a) + B/(x−b) स्थिति 2: q(x) = (x−a)² p(x)/(x−a)² = A/(x−a) + B/(x−a)² स्थिति 3: q(x) = ax²+bx+c (अवियोज्य), degree 2 p(x)/[(ax²+bx+c)(x−d)] = (Mx+N)/(ax²+bx+c) + C/(x−d) A, B, C, M, N ज्ञात करने के लिए: - गुणांक तुलना (coefficient comparison) या - निश्चित मान रखकर (substitution method) फिर प्रत्येक पद का अलग-अलग समाकलन करें।

Card 6

विशिष्ट समाकलन (Special Integrals) — JEE Main के महत्वपूर्ण स्वरूप

1. ∫dx/(√(x²±a²)) = ln|x + √(x²±a²)| + C या sinh⁻¹(x/a) + C 2. ∫dx/√(a²−x²) = sin⁻¹(x/a) + C 3. ∫dx/(a²+x²) = (1/a)tan⁻¹(x/a) + C 4. ∫dx/(x²−a²) = (1/2a)ln|(x−a)/(x+a)| + C 5. ∫dx/(a²−x²) = (1/2a)ln|(a+x)/(a−x)| + C 6. ∫√(a²−x²)dx = (x/2)√(a²−x²) + (a²/2)sin⁻¹(x/a) + C 7. ∫√(x²±a²)dx = (x/2)√(x²±a²) ± (a²/2)ln|x+√(x²±a²)| + C 8. ∫dx/(x²+a²)ⁿ — रेडक्शन सूत्र से हल करें 9. ∫f(x)/[f(x)+f(a−x)]dx = x/2 (symmetry trick)

Card 7

निश्चित समाकलन (Definite Integral) — परिभाषा और घातांक नियम

परिभाषा: ∫ₐᵇ f(x)dx = F(b) − F(a), जहाँ F'(x) = f(x) घातांक नियम (Fundamental Theorem of Calculus): 1. ∫ₐᵇ f(x)dx = F(b)−F(a) 2. ∫ₐᵇ f(x)dx = −∫ᵦₐ f(x)dx 3. ∫ₐᵃ f(x)dx = 0 4. ∫ₐᵇ f(x)dx = ∫ₐᶜ f(x)dx + ∫ᶜᵇ f(x)dx 5. ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b−x)dx ← सबसे महत्वपूर्ण! यदि f(x) = g(x) + h(x) और g सम, h विषम है, तो: ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ g(x)dx (सम फलन का गुणा 2) विषम फलन: ∫₋ₐᵃ f(x)dx = 0

Card 8

निश्चित समाकलन के महत्वपूर्ण गुण (Properties of Definite Integrals) — JEE Main

1. ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b−x)dx ← अक्सर प्रयोग में आता है 2. ∫₋ₐᵃ f(x)dx: - यदि f सम है (f(−x)=f(x)): = 2∫₀ᵃ f(x)dx - यदि f विषम है (f(−x)=−f(x)): = 0 3. ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a−x)dx 4. ∫₀²ᵃ f(x)dx: - f सम: 2∫₀ᵃ f(x)dx - f विषम: 0 5. ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b−t)dt 6. ∫₀ᵃ f(x)/(f(x)+f(a−x)) dx = a/2 7. बीटा/गामा फलनों से संबंध: ∫₀¹ xᵃ(1−x)ᵇdx = B(a+1,b+1)

Card 9

गामा फलन (Gamma Function) — परिभाषा, गुण और JEE Main अनुप्रयोग

परिभाषा: Γ(n) = ∫₀^∞ xⁿ⁻¹e⁻ˣdx, n > 0 गुण: 1. Γ(n+1) = n·Γ(n) 2. Γ(n) = (n−1)! 3. Γ(1) = 1 4. Γ(1/2) = √π 5. Γ(3/2) = √π/2 6. Γ(5/2) = 3√π/4 7. Γ(n+1/2) = (2n)!·√π/(4ⁿ·n!) JEE में प्रायः प्रयोग: ∫₀^∞ xⁿe⁻ˣdx = Γ(n+1) = n! ∫₀^∞ xⁿe⁻ᵃˣdx = Γ(n+1)/aⁿ⁺¹ ∫₀^{π/2} sinⁿx·cosᵐx dx = (1/2)·Γ((n+1)/2)·Γ((m+1)/2)/Γ((n+m+2)/2)

Card 10

बीटा फलन (Beta Function) — परिभाषा, गामा से संबंध और निश्चित समाकलनों में प्रयोग

परिभाषा: B(m,n) = ∫₀¹ xᵐ⁻¹(1−x)ⁿ⁻¹dx, m>0, n>0 गामा से संबंध: B(m,n) = Γ(m)·Γ(n)/Γ(m+n) त्रिकोणमितीय रूप: B(m,n) = 2∫₀^{π/2} sin²ᵐ⁻¹θ · cos²ⁿ⁻¹θ dθ JEE में महत्वपूर्ण: ∫₀^{π/2} sinⁿx dx = ∫₀^{π/2} cosⁿx dx = √π·Γ((n+1)/2) / [2·Γ((n+2)/2)] विशेषcase n≥1 पूर्णांक: - n सम: ((n−1)!!/n!!)·(π/2) - n विषम: (n−1)!!/n!! जहाँ n!! = n·(n−2)·(n−4)….

Card 11

निश्चित समाकलन से क्षेत्रफल ज्ञात करना — विधि और महत्वपूर्ण उदाहरण

वक्र y=f(x), x-अक्ष, x=a और x=b के बीच: क्षेत्रफल = |∫ₐᵇ f(x)dx| वक्र y=f(x) और y=g(x) के बीच: क्षेत्रफल = ∫ₐᵇ |f(x)−g(x)|dx प्रत्येक खंड में चिन्ह बदल सकता है — इसलिए निरपेक्ष मान और इंटरसेक्शन बिंदु ज़रूर निकालें। अनुदैर्ध्य (parametric) वक्र x=f(t), y=g(t): क्षेत्रफल = ∫ y dx = ∫ g(t)·f'(t)dt निर्देशांक ज्यामिति के संयुक्त प्रश्न: - परवलय y²=4ax और रेखा x=a → क्षेत्रफल = (4/3)a² - वृत्त x²+y²=a² के चतुर्थांश का क्षेत्रफल = πa²/4 - दीर्घवृत्त x²/a²+y²/b²=1 → क्षेत्रफल = πab

JEE Main के लिए सबसे महत्वपूर्ण 10 समाकलन प्रश्न प्रकार (High-Yield Patterns)

Card 14

त्रिकोणमितीय प्रतिस्थापन (Trigonometric Substitution) — कब और कैसे?

√(a²−x²) देखें → x = a·sin θ, dx = a·cos θ dθ √(a²+x²) देखें → x = a·tan θ, dx = a·sec²θ dθ √(x²−a²) देखें → x = a·sec θ, dx = a·sec θ·tan θ dθ सुधारित रूप: √(a²−a²sin²θ) = a·cos θ √(a²+a²tan²θ) = a·sec θ √(a²sec²θ−a²) = a·tan θ उदाहरण: ∫dx/√(9−x²) = sin⁻¹(x/3)+C उदाहरण: ∫dx/(x²+4) = (1/2)tan⁻¹(x/2)+C टीप: t = tan(x/2) प्रतिस्थापन भी बहुत उपयोगी है जब sin x और cos x दोनों हों।

Card 15

sinⁿx·cosᵐx के निश्चित समाकलन के लिए Wallis सूत्र

∫₀^{π/2} sinⁿx·cosᵐx dx यदि n, m ≥ 0 पूर्णांक हैं: 1. n और m दोनों सम: ( (n−1)!!(m−1)!! / (n+m)!! ) × (π/2) 2. n सम, m विषम (या इसके विपरीत): (n−1)!!(m−1)!! / (n+m)!! 3. n और m दोनों विषम: (n−1)!!(m−1)!! / (n+m)!! (नोट: n!! = n·(n−2)·(n−4)…., 0!! = 1!! = 1) विशेष case m=0: ∫₀^{π/2} sinⁿx dx = ∫₀^{π/2} cosⁿx dx

Card 16

JEE Main में समाकलन के लिए सबसे आम भूलें (Common Mistakes)

1. ∫(1/x)dx = ln x + C — गलत! सही: ln|x| + C (निरपेक्ष मान भूलें नहीं) 2. ∫xⁿdx = xⁿ⁺¹/(n+1)+C — n=−1 के लिए नहीं लागू होता; यह ln|x| बन जाता है। 3. समाकलन के दौरान C न जोड़ना या बार-बार जोड़ना (प्रत्येक पृथक् समाकलन में एक C) 4. ∫₋ₐᵃ f(x)dx में सम/विषम का पहचान नहीं पाटना — समय बर्बाद। 5. आंशिक भिन्न में अंश का degree भूलकर (हमेशाdegree(p)<degree(q) होना चाहिए, वरfirst division करें) 6. खंडशः में u और dv का चयन गलत करना — ILATE नियम का उल्लंघन। 7. निश्चित समाकलन में सीमाएँ (limits) नहीं बदलना जब प्रतिस्थापन करें।

Card 17

f(x)+f(a−x) सममिति सूत्र — JEE Main का सबसे महत्वपूर्ण ट्रिक

मुख्य परिणाम: ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a−x)dx विशेष परिणाम: ∫₀ᵃ f(x)/[f(x)+f(a−x)] dx = a/2 यह नियम विशेषकर तब काम आता है जब f(x) जटिल दिखे लेकिन f(a−x) मिलाने पर सरल हो जाए। उदाहरण: ∫₀^{π/2} sin³x/(sin³x+cos³x) dx = π/4 इसी तरह: ∫₀^{π/2} 1/(1+tanᵃx) dx = π/4 ∫₀^{π/2} 1/(1+(cot x)ᵃ) dx = π/4 प्रमाण सूत्र: I = ∫f(x)dx = ∫f(a−x)dx, जोड़ने पर 2I = ∫[f(x)+f(a−x)]dx ⇒ I = a/2

Card 18

घातांकीय समाकलन (Exponential Integrals) — e^(ax+b) और मिश्रित उदाहरण

मूल सूत्र: ∫e^(ax+b)dx = e^(ax+b)/a + C ∫e^(kx)·sin(mx)dx = e^(kx)/(k²+m²)[k·sin mx − m·cos mx] + C ∫e^(kx)·cos(mx)dx = e^(kx)/(k²+m²)[k·cos mx + m·sin mx] + C विशिष्ट केस: ∫x·e^(ax)dx = e^(ax)/(a²)(ax−1) + C ∫x²·e^(ax)dx = e^(ax)/(a³)(a²x²−2ax+2) + C JEE ट्रिक: ∫e^(f(x))[f(x)+f'(x)]dx = e^(f(x))+C यदि समाकल्य e^(g(x))[g'(x)+1] स्वरूप हो, तो उत्तर सीधा e^(g(x))+C।

Card 19

प्रतिस्थापन द्वारा जटिल समाकलन — sin⁻¹x, tan⁻¹x, log x वाले प्रश्न

sin⁻¹x वाले: ∫sin⁻¹x dx = x·sin⁻¹x + √(1−x²) + C ∫x·sin⁻¹x dx = (x²−1)/4 · sin⁻¹x + x/4·√(1−x²) + C tan⁻¹x वाले: ∫tan⁻¹x dx = x·tan⁻¹x − (1/2)ln(1+x²) + C ∫x·tan⁻¹x dx = (x²+1)/4 · tan⁻¹x − x/4 + C log x वाले: ∫log x dx = x·log x − x + C ∫x·log x dx = x²/4 ·(2log x − 1) + C ∫log(x+√(1+x²))dx = x·log(x+√(1+x²)) − √(1+x²) + C इनमें हमेशा खंडशः (parts) का ही उपयोग होता है — u = व्युत्क्रम त्रिकोण/लघुगणक फलन।

Card 21

निश्चित समाकलन में अंकों का प्रयोग (Substitution x → a+b−x tricks)

सबसे शक्तिशाली JEE ट्रिक: जब ∫₀ᵃ f(x)dx हो और f(x) जटिल लगे。 x → a−x रखें: I = ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a−x)dx उदाहरण: ∫₀^{π/2} x·sin x/(1+cos²x) dx x→π/2−x रखें और जोड़ें: 2I = ∫₀^{π/2} (π/2)·[sin x+cos x]/(1+sin x·cos x) dx और भी सरल: ∫₀^{π/2} 1/(1+√(tan x))dx = π/4 ∫₀¹ ln(1+x)/(1+x²)dx = π·ln 2/8 यह तकनीक सममिति (symmetry) पर आधारित है और जटिल समाकलनों को सरल बना देती है।

लघुगणकीय समाकलन (Logarithmic Integrals) — JEE Main高频题型
