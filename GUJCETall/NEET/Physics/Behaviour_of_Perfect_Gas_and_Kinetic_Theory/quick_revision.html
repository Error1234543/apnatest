પૂર્ણ ગેસની વર્તણૂક અને ગતિજ સિદ્ધાંત — ઝડપી पुનરાવર્તન

🧪 GUJCET — Gujarati • Physics • Behaviour of Perfect Gas and Kinetic Theory

🧠 યાદ રાખો

પૂર્ણ ગેસ માટે PV = nRT; R = 8.314 J mol⁻¹ K⁻¹ = 0.0821 L atm mol⁻¹ K⁻¹
બોઈલનો નિયમ: T અચળ હોય ત્યારે PV = અચળ (P ∝ 1/V)
ચાર્લ્સનો નિયમ: P અચળ હોય ત્યારે V/T = અચળ (V ∝ T)
ગેей-લુસ્સેકનો નિયમ: V અચળ હોય ત્યારે P/T = અચળ
એવોગેડ્રોનો નિયમ: સમાન તાપમાને અને દબાણે, સમાન કદમાં ગેસના સમાન અણુઓ હોય છે; 1 mol = 6.022 × 10²³ અણુઓ (લાવોઝડ્રો સંખ્યા)
સંયુક્ત ગેસ સમીકરણ: PV/T = અચળ; સ્ટાન્ડર્ડ તાપમાન અને દબાણ (STP) પર 1 mol પૂર્ણ ગેસનું કદ = 22.4 L
ગતિજ સમીકરણ: PV = (1/3) mN v²rms → P = (1/3) ρ v²rms
v_rms = √(3RT/M) = √(3k_BT/m); v_avg = √(8RT/πM); v_mp = √(2RT/M)
v_mp : v_avg : v_rms = √2 : √(8/π) : √3 ≈ 1 : 1.128 : 1.224
તાપમાન એ અણુઓની સરેરાશ ગતિજ ઊર્જાનું માપ છે: KE_avg = (3/2) k_BT per molecule = (3/2) RT per mole
આદર્શ ગેસનો આંશિક દબાણનો અંશ: P_i = x_i × P_total (ડાલ્ટનનો નિયમ)
ગેસના અણુઓ વચ્ચે આંતરક્રિયા નહિવત હોય; અણુઓનું કદ નગણ્ય હોય — આ પૂર્ણ ગેસની મૂળભૂત ધારણાઓ છે
ગતિજ સિદ્ધાંતની અનુમતિઓ: અણુઓ નિરંતર યાદૃચ્છિક ગતિ કરે છે, સંપૂર્ણ સ્થિતિસ્થાપક ટકરાવ થાય છે, ન્યૂટનના ગતિનિયમો મാനે છે

⚡ ઝડપી સૂત્રો

PV = nRT, જ્યાં n = m/M (મોલની સંખ્યા)
v_rms = √(3RT/M) = √(3P/ρ)
KE_mole = (3/2) RT; KE_molecule = (3/2) k_BT
v_avg = √(8RT/πM); v_mp = √(2RT/M)
k_B = R/N_A = 1.38 × 10⁻²³ J/K (બોલ્ટ્ઝમેન અચળાંક)
P = (1/3) ρ v²rms, જ્યાં ρ = ગેસની ઘનતા
અણુની સ્વાતંત્ર્યની ડિગ્રી (f): એકપરમાણ્વિક f=3, દ્વિપરમાણ્વિક f=5 (સામાન્ય T), ત્રિપરમાણ્વિક f=6
મોલની વિશિષ્ટ ઉષ્મા: C_v = fR/2, C_p = (f+2)R/2; γ = C_p/C_v = (f+2)/f
એડિઅબેટિક પ્રક્રિયા: PV^γ = અચળ; TV^(γ-1) = અચળ; P^(1-γ) T^γ = અચળ
વર્ક (એડિઅબેટિક): W = (P₁V₁ - P₂V₂)/(γ-1)
માક્સવેલ વેગ વિતરણ વક્ર: વક્રનું ક્ષેત્રફળ = કુલ અણુઓની સંખ્યા N; શિખર વેગ = v_mp
દબાણ એકમ રૂપાંતરણ: 1 atm = 1.013 × 10⁵ Pa = 76 cm Hg

✅ વન-લાઈનર્સ

v_rms હંમેશા v_avg કરતાં અને v_avg હંમેશા v_mp કરતાં મોટો હોય છે.
તાપમાન દ્વિગુણ કરતાં v_rms √2 ગણી થાય; કારણ v_rms ∝ √T.
માક્સવેલ વિતરણ વક્ર અસમભાસી (asymmetric) હોય છે — જમણી બાજુ લાંબો પૂંછડો ધરાવે છે.
તાપમાન વધતાં v_mp, v_avg, v_rms બધા જ વધે છે અને વિતરણ વક્ર પહોળો થાય છે.
ગેસનું દ્રવ્યમાન વધારતાં (M વધારતાં) v_rms ઘટે છે: v_rms ∝ 1/√M.
એકપરમાણ્વિક ગેસ (He, Ne) માટે γ = 5/3 ≈ 1.67; દ્વિપરમાણ્વિક (H₂, N₂, O₂) માટે γ = 7/5 = 1.4.
આયોથર્મલ પ્રક્રિયામાં ΔU = 0, Q = W; એડિઅબેટિકમાં Q = 0, ΔU = -W.
STP પર O₂ નો v_rms ≈ 483 m/s; H₂ નો v_rms ≈ 1845 m/s.
સરેરાશ મુક્ત પથ (mean free path) λ = 1/(√2 π d² n) — દબાણ વધારતાં λ ઘટે છે.
આદર્શ ગેસનો અંદરનો ऊर्जा ફટો માત્ર તાપમાન પર નિર્ભર કરે છે, દબાણ કે કદ પર નહીં.
