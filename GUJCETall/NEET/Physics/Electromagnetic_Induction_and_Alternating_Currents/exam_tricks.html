🎯 પરીક્ષા ટ્રિક્સ

ફેરાડેના નિયમમાં ΔΦ/Δt ની જગ્યાએ, જો ફ્લક્સ સમાન હારે બદલાતો હોય તો સાદું સૂત્ર |ε| = N × |ΔΦ|/Δt વાપરો. ઉત્પાદિત EMF એ ફ્લક્સના ફેરફારની દર પર આધારિત છે, ફ્લક્સની મોટાઈ પર નહીં.
જ્યારે પ્રશ્નમાં ચુંબકીય ફ્લક્સમાં થતો ફેરફાર અને સમય અંતરાલ સ્પષ્ટ રીતે આપેલ હોય (ઉદા. ફ્લક્સ 0.5 Wb થી 0.2 Wb બદલાય છે, સમય 0.1 s).
દા.ત.: 50 ફેરામળાવાળા કોઇલમાંથી ફ્લક્સ 0.8 Wb થી 0.2 Wb 0.02 s માં ઘટે છે. |ε| = 50 × (0.6)/0.02 = 1500 V.
લેન્ઝનો નિયમ = "ચુંબકીય મંદન". જો ચુંબક કોઇલ તરફ આવે તો કોઇલનું તે અંત્યોતરી ભાગ ધ્રુવ બની જાય છે (વિલક્ષણ પ્રતિકાર); જો ચુંબક દૂર જાય તો સર્વસમાન ધ્રુવ બને છે (આકર્ષણ). આ વિચારથી દિશા તુરંત મળે છે.
પ્રવેગી કે સમાન ગતિથી ચુંબકના આગમન/નિર્ગમન દરમ્યાન પ્રેરિત પ્રવાહની દિશા નક્કી કરવી હોય.
દા.ત.: ઉત્તર ધ્રુવવાળું ચુંબક કોઇલ તરફ ગતિ કરે → કોઇલનું એમ અંત્યોતરી ભાગ ઉત્તર ધ્રુવ બને → પ્રવાહ ઊભાક્રમમાં (anti-clockwise). ચુંબક દૂર જાય → દક્ષિણ ધ્રુવ બને → પ્રવાહ કલાકક્રમમાં.
ગતિજ EMF (motional EMF) ε = Bℓv સાધારણ કિસ્સામાં (B, ℓ, v એકબીજાને લંબરૂપ હોય). જો ખૂણો θ હોય તો ε = Bℓv sinθ. ડ્રૂટ વેલોસિટી v_d નો ઉપયોગ કરીને પણ ε = Bℓv_d (නિવેદિત કિસ્સામાં).
દા.ત.:
LR સર્કિટમાં સમય અચળાંક τ = L/R. τ સેકન્ડ પછી પ્રવાહ I₀(1 - 1/e) ≈ 0.632 I₀ થાય છે. 5τ પછી પ્રવાહ સ્થિરમાન મનાય (99.3%). LC સર્કિટમાં ઊર્જા ફેરબદલી આવર્તક બને છે, ત્યાં τ નો વિચાર ન લાગે.
LR અથવા LC સર્કિટમાં પ્રવાહ/ચાર્જનો સમય સાથેનો ફેરફાર પૂછતો પ્રશ્ન.
દા.ત.: L = 2 H, R = 4 Ω → τ = 0.5 s. 1 s (2τ) પછી પ્રવાહ I₀(1 - e⁻²) ≈ 0.865 I₀. 5 s (10τ) પછી વધુ 99%.
AC જનરેટરમાં ε = NBAω sin(ωt). મહત્તમ EMF ε_max = NBAω. જો ω = 2πf, તો ε_max = 2πf NBA. આ સૂત્રમાં N, B, A, f નો ગુણાકાર કરી 2π વડે ગુણો.
જનરેટરના પ્રશ્નમાં મહત્તમ કે effective EMF પૂછવામાં આવે.
દા.ત.: N = 100, B = 0.5 T, A = 0.02 m², f = 50 Hz → ε_max = 2π × 50 × 100 × 0.5 × 0.02 = 100π ≈ 314 V.
LCR શ્રેણી સર્કિટમાં અનુનાદ (resonance) પર X_L = X_C, એટલે Z = R (Minimum), પ્રવાહ મહત્તમ, પાવર ફેક્ટર = 1. અનુનાદ આવૃત્તિ f₀ = 1/(2π√(LC)).
જ્યારે LCR સર્કિટનું impedances, પ્રવાહ અથવા પાવર ફેક્ટર મહત્તમ/ઓછામાં ઓછા હોય તેવું પૂછાય.
દા.ત.: L = 0.1 H, C = 10 μF → f₀ = 1/(2π√(0.1×10⁻⁵)) = 1/(2π×10⁻³) ≈ 159 Hz. આ આવૃત્તિએ I_max = V/R.
પાવર ફેક્ટર cos φ = R/Z. શુદ્ધ અવરોધક (pure resistor) → pf = 1; શુદ્ધ પ્રેરક (pure inductor) → pf = 0 (lagging); શુદ્ધ ધારિત્ર (pure capacitor) → pf = 0 (leading). LCR માં X_L > X_C → lagging, X_C > X_L → leading.
પાવર ફેક્ટરના પ્રશ્નમાં, અથવા કોઈપણ શુદ્ધ ઘટકવાળી સર્કિટમાં.
દા.ત.: X_L = 80 Ω, X_C = 40 Ω, R = 30 Ω → Z = √(30² + (80-40)²) = 50 Ω, cos φ = 30/50 = 0.6 lagging.
ટ્રાન્સફોર્મરમાં V_s/V_p = N_s/N_p = I_p/I_s (આદર્શ). Step-up → V વધે, I ઘટે; step-down → V ઘટે, I વધે. શક્તિ સંરક્ષિત રહે છે: V_p I_p = V_s I_s.
ટ્રાન્સફોર્મરના ટર્ન્સ ગુણોત્તરથી વોલ્ટેજ/પ્રવાહ શોધવાના.
દા.ત.: N_p : N_s = 1:10, V_p = 220 V, I_p = 5 A → V_s = 2200 V, I_s = 0.5 A (step-up transformer).
પ્રત્યાવર્તી પ્રવાહનું effective (rms) મૂલ્ય = Peak / √2. I_rms = I₀/√2, V_rms = V₀/√2. AC મીટર હંમેશા rms વાંચે છે.
Peak મૂલ્યથી rms મૂલ્ય શોધવું અથવા વ્યસ્ત.
દા.ત.: V₀ = 311 V → V_rms = 311/√2 ≈ 220 V. I₀ = 10 A → I_rms = 10/√2 ≈ 7.07 A.
Q-ફેક્ટર (Quality factor) Q = ω₀L/R = 1/(ω₀RC) અનુનાદ પર. Q જitવું = સર્કિટનું selectivity. Q > 10 → Sharp resonance, Q < 10 → Broad resonance.
અનુનાદ વક્રની sharpness અથવા frequency selectivity પૂછતો પ્રશ્ન.
દા.ત.: L = 0.5 H, C = 20 μF, R = 10 Ω → ω₀ = 1/√(LC) = 1/√(0.5×20×10⁻⁶) = 1000 rad/s, Q = 1000×0.5/10 = 50 (Sharp).
પ્રેરક (Inductor) માં વોલ્ટેજ પ્રવાહથી 90° આગળ (leads); કપેસિટર (Capacitor) માં વોલ્ટેજ પ્રવાહથી 90° પાછળ (lags). યાદ રાખો: "ELI the ICE man" — E leads I in L, I leads E in C.
AC સર્કિટમાં phase relationship પૂછતો પ્રશ્ન, અથવા phasor diagram ગોઠવવાનો.
દા.ત.: Pure inductor: V = V₀ sin(ωt + π/2), I = I₀ sin(ωt). Pure capacitor: V = V₀ sin(ωt - π/2), I = I₀ sin(ωt).
અવઘટ (Impedance) નો ત્રિકોણ: Z² = R² + (X_L - X_C)². જો X_L = X_C → Z = R (minimum). જો X_C > X_L → net reactive is capacitive; if X_L > X_C → net reactive is inductive.
LCR સર્કિટમાં impedance શોધવાની કોઈ પણ સ્થિતિમાં.
દા.ત.: R = 6 Ω, X_L = 8 Ω, X_C = 3 Ω → Z = √(36 + (8-3)²) = √(36+25) = √61 ≈ 7.81 Ω.
