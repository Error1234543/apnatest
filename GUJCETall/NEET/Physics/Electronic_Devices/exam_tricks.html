🎯 પરીક્ષા ટ્રિક્સ

ડાયોડનો PIV (Peak Inverse Voltage) યાદ રાખવાની સરળ રીત: બ્રિજ રેક્ટિફાયરમાં PIV = Vm (પીક વોલ્ટેજ) અને સેન્ટર-ટેપ્ડ ફુલ-વેવ રેક્ટિફાયરમાં PIV = 2Vm. આ એકમાત્ર મોટો ફરક છે જે સામાન્ય રીતે પ્રશ્ન પૂછે છે.
જ્યારે રેક્ટિફાયરના PIV વિશે પ્રશ્ન આવે — બંને પ્રકારોની તુલના સાથેનું બહુવિકલ્પી પ્રશ્ન.
દા.ત.: બ્રિજ રેક્ટિફાયરમાં દરેક ડાયોડ પર PIV = Vm (જ્યાં Vm એ સીકે એમ વોલ્ટેજનો શિખર મૂલ્ય છે). સેન્ટર-ટેપ્ડમાં PIV = 2Vm.
ફુલ-વેવ રેક્ટિફાયરની DC આઉટપુટ વહેંચણી અર્ધ-વેવ કરતા બમણી: I_dc = 2I_m/π (ફુલ-વેવ) vs I_dc = I_m/π (અર્ધ-વેવ). આ તફાવત જાણતા ઝડપથી જવાબ મળે.
DC આઉટપુટ વર્તમાનનું ગણતરી કરતો પ્રશ્ન — અર્ધ-વેવ કે ફુલ-વેવ પેચિત હોય તે તપાસીને જવાબ પસંદ કરો.
દા.ત.: જો I_m = 100 mA હોય, તો ફુલ-વેવમાં I_dc = 2×100/π ≈ 63.7 mA; અર્ધ-વેવમાં I_dc = 100/π ≈ 31.8 mA.
N-p-N ટ્રાન્ઝિસ્టરમાં: એમિટર કરંટ I_E = I_B + I_C, α = I_C/I_E, β = I_C/I_B, અને α = β/(β+1). આ સંબંધો યાદ રાખો — કોઈ પણ બે મૂલ્યો આપે તો બીજા બે શોધી શકાય.
જ્યારે α અને β ની વચ્ચેનો સંબંધ અથવા કરંટ ગુણોત્તરનો પ્રશ્ન આવે.
દા.ત.: β = 100 હોય, તો α = 100/101 ≈ 0.9901. β = 50 હોય, તો α = 50/51 ≈ 0.9804.
ટ્રાન્ઝિસ્టરમાં બેઝ વિસ્તાર હંમેશા સૌથી પાતળો અને સૌથી ઓછા ડોપિંગ વાળો હોય છે; એમિટર વિસ્તાર સૌથી વધુ ડોપિંગ વાળો. આ ખ્યાલથી જ્યારે 'કયો વિસ્તાર કયા કારણોસર પાતળો છે?' પ્રશ્ન આવે ત્યારે તરત જ 'બેઝ' પસંદ કરો.
ટ્રાન્ઝિસ્્ટરના બંધારણના ગુણધર્મો વિશે પ્રશ્ન — એમિટર/બેઝ/કલેક્ટરની રચના સંબંધી.
દા.ત.: પ્રશ્ન: ટ્રાન્ઝિસ્્ટરમાં કયા વિસ્તારમાં ડોપિંગ સૌથી વધુ હોય? → એમિટર (Emitter). કયો વિસ્તાર સૌથી પાતળો હોય? → બેઝ (Base).
Zener ડાયોડ હંમેશા 'રિવર્સ બાયસ'માં કામ કરે છે અને તેનું મુખ્ય કાર્ય 'વોલ્ટેજ રેગ્યુલેશન' છે. જો પ્રશ્નમાં Zener ડાયોડના ઉપયોગ વિશે પૂછે, તો 'વોલ્ટેજ સ્ટેબિલાઇઝર/રેગ્યુલેટર' વિકલ્પ સાચો છે.
Zener ડાયોડના સંચાલન અને ઉપયોગ સંબંધી પ્રશ્ન.
દા.ત.: Zener ડાયોડનો ઉપયોગ ક્યાં થાય? → વોલ્ટેજ રેગ્યુલેટર સર્કિટમાં. તે સામાન્ય રીતે રિવર્સ બાયસમાં કામ કરે છે.
લોજિક ગેટના સાચા જવાબો તપાસવાની ઝડપી રીત: AND (બધા 1 → આઉટપુટ 1), OR (કોઈ એક 1 → આઉટપુટ 1), NAND (AND નો ઇન્વર્સ), NOR (OR નો ઇન્વર્સ), XOR (અલગ બિટ્સ → 1). આ પેટર્ન યાદ રાખો.
લોજિક ગેટના ટ્રુથ ટેબલ અથવા આઉટપુટ શોધતો પ્રશ્ન — વિભિન્ન ઇનપુટ કોમ્બિનેશન આપેલ હોય.
દા.ત.: XOR ગેટ: A=0, B=1 → આઉટપુટ 1; A=1, B=1 → આઉટપુટ 0. 'અલગ' બિટ્સ મળે તો 1, 'સમાન' મળે તો 0.
LED નું ઉત્સર્જિત પ્રકાશનો રંગ (તરંગલંબાઈ) એડિશન બેન્ડગેપ (Band gap) દ્વારા નક્કી થાય છે: E_g = hc/λ. વધુ બેન્ડગેપ → ટૂંકી તરંગલંબાઈ (નેરો/વાયોલેટ); ઓછો બેન્ડગેપ → લાંબી તરંગલંબાઈ (લાલ).
LED ના પ્રકાશના રંગ અને બેન્ડગેપ વચ્ચેનો સંબંધ પ્રશ્ન.
દા.ત.: લાલ LED નો બેન્ડગેપ ≈ 1.8 eV (લાંબી તરંગલંબાઈ ~650 nm); બેન્ડગેપ ઓછો → લાલ પ્રકાશ. વાયોલેટ LED નો બેન્ડગેપ ≈ 3.1 eV (ટૂંકી તરંગલંબાઈ ~400 nm).
ફોટોડાયોડ 'રિવર્સ બાયસ'માં ચાલે છે. પ્રકાશ વધે → ફોટો કરંટ વધે. પ્રશ્નમાં 'ફોટોડાયોડ કયા બાયસમાં?' પૂછે → તરત 'રિવર્સ બાયસ' પસંદ કરો.
ફોટોડાયોડના સંચાલન સ્થિતિ અને કાર્યદક્ષતા સંબંધી પ્રશ્ન.
દા.ત.: ફોટોડાયોડ લાલ-તાંબાના સેલ કરતાં શ્રેષ્ઠ છે કારણ કે: તેઓ દરેક ફોટોન-ઉત્પન્ન કરેલો કેરિયર જોડો (electron-hole pair) એકત્ર કરી શકે છે → વધુ સંવેદનશીલતા.
અનિસરિંગ (Intrinsic) અર્ધવાહકમાં n_e = n_h = n_i (ઇલેક્ટ્રોન અને છિદ્રો સંખ્યા સમાન). n-type માં n_e >> n_h; p-type માં n_h >> n_e. ગુણધર્મ: n_e × n_h = n_i² (ઉષ્માસંતુલનમાં).
અર્ધવાહકમાં કેરિયર સાંદ્રતા અથવા ડોપિંગ પ્રકાર વિશે પ્રશ્ન.
દા.ત.: જો n-type સિલિકોનમાં n_e = 5n_h હોય, તો n_i² = n_e × n_h = 5n_h² થાય. આ સૂત્ર યાદ રાખો.
ટ્રાન્ઝિસ્റ്റરના 'એક્ટિવ રીજન'માં: બેઝ-એમિટર જંકશન ફોરવર્ડ બાયસ અને બેઝ-કલેક્ટર જંકશન રિવર્સ બાયસ. આ જ પ્રશ્ન અલગ અલગ રીતે પૂછાય — બંને શરતો એકસાથે યાદ રાખો.
ટ્રાન્ઝિસ્ટરના કાર્યરત પ્રદેશ (રિજન) નક્કી કરતો પ્રશ્ન.
દા.ત.: N-p-N ટ્રાન્ઝિસ્્ટર એક્ટિવ રીજનમાં: બેઝ-એમિટર = ફોરવર્ડ, બેઝ-કલેક્ટર = રિવર્સ. આ ક્રમ ભૂલશો નહીં!
કેપેસિટર ફિલ્ટર સાથેના ફુલ-વેવ રેક્ટિફાયરમાં ripple frequency = 2f (જ્યાં f એ મેઇનસ ફ્રિકવેન્સી છે). સરળ રીતે: ફુલ-વેવમાં ripple અર્ધ-વેવ કરતા બમણી ફ્રિકવેન્સીની હોય છે.
રિપલ ફ્રિકવેન્સી અથવા કેપેસિટર ફિલ્ટર સંબંધી પ્રશ્ન.
દા.ત.: જો mains frequency f = 50 Hz હોય, તો ફુલ-વેવ રેક્ટિફાયરમાં ripple frequency = 2×50 = 100 Hz.
કોઈપણ ઇલેક્ટ્રોનિક ઉપકરણ/ડાયોડનો I-V ગ્રાફ જુઓ: ડાયોડ ફોરવર્ડ બાયસમાં જમણી બાજુ ઝડપથી ઉપર જાય, રિવર્સ બાયસમાં ખાલી રહે અથવા Zener બ્રેકડાઉન પછી ઊંચો થાય. આકૃતિ ઓળખવાની આ ઝડપી રીત.
I-V લાક્ષણિકતા વક્રની ઓળખ પ્રશ્ન (બહુવિકલ્પી ચિત્ર પ્રશ્નો).
દા.ત.: ગ્રાફ જમણી બાજુ ધ્રુવક ગાળામાં (threshold voltage પછી) ઊંચો થાય અને ડાબી બાજુ નજીક શૂન્ય રહે → સાદો PN જંકશન ડાયોડ. ડાબી બાજુ રિવર્સ બાયસમાં તીવ્રતાથી ગિરફટ → Zener ડાયોડ.
ટ્રાન્ઝિસ્ટરમાં કલેક્ટર પાવર ડિસિપેશન P = V_CE × I_C. આ મૂલ્ય સર્કિટ ડિઝાઇનમાં સીમાંકન માટે ઉપયોગી. આ પ્રશ્નમાં ઘણીવાર P_max નક્કી કરવા માટે I_C_max શોધવાનું હોય.
ટ્રાન્ઝિસ્ટર પાવર ડિસિપેશન અથવા મહત્તમ करंट સંબંધી પ્રશ્ન.
દા.ત.: P_max = 1 W, V_CE = 2 V હોય, તો I_C_max = P/V_CE = 1/2 = 0.5 A. સૂત્ર yaad rakho: I_C_max = P_max / V_CE.
સમસ્થિતિક (Static) અને સંચલન (Dynamic) અવરોધ: વક્રના કોઈ બિંદુ પર R_static = V/I (મૂળબિંદુથી તે બિંદુ સુધીનું સલોપ). r_dynamic = dV/dI (તત્કાલીન સલોપ). પ્રશ્નમાં બંને પૂછાય તો તફાવત ઓળખો.
ડાયોડના અવરોધ સંબંધી ગણતરી પ્રશ્ન — બહુવિકલ્પી અથવા ગણતરી પ્રકાર.
દા.ત.: કોઈ PN જંકશન ડાયોડના I-V વક્ર પર બિંદુ (0.6 V, 20 mA): R_static = 0.6/0.020 = 30 Ω. r_dynamic એ વક્રના તે બિંદુ પરનો સ્પર્શક સલોપ છે.
પદાર્થોના શ્રેણીબદ્ધ વર્ગીકરણ: ચાલક (Conductor) > અર્ધવાહક (Semiconductor) > વિરોધક (Insulator) — બેન્ડગેપના આધારે. બેન્ડગેપ શૂન્ય અથવા નગણ્ય → ચાલક; 0–3 eV → અર્ધવાહક; >3 eV → વિરોધક. આ યાદ હોય તો મોટાભાગના પ્રશ્નો સીધા હલ થાય.
પદાર્થોના વિદ્યુત ગુણધર્મો અથવા બેન્ડગેપ સંબંધી પ્રશ્ન.
દા.ત.: Si નો બેન્ડગેપ ≈ 1.1 eV → અર્ધવાહક. Ge નો બેન્ડગેપ ≈ 0.7 eV → અર્ધવાહક. Diamond નો બેન્ડગેપ ≈ 5.5 eV → વિરોધક. Cu નો બેન્ડગેપ ≈ 0 → ચાલક.
