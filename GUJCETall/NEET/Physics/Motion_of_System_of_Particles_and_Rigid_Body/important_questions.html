કુલ પ્રશ્નો: 15
Q1. સમાન દળ ધરાવતા બે કણોનો દળકેન્દ્ર (Center of Mass) ક્યાં હોય છે?
A. બંને કણોને જોડતી રેખાના મધ્યબિંદુએ
B. બંને કણો પાસે
C. બંને કણોથી દૂર
D. કોઈ પણ નિશ્ચિત સ્થાને નહીં
✅ A — સમાન દળ ધરાવતા બે કણો માટે દળકેન્દ્ર (Center of Mass) બંને કણોને જોડતી રેખાના મધ્યબિંદુએ મળે છે, કારણ કે દળકેન્દ્રનું સૂત્ર મુજબ સમાન દળ હોય ત્યારે તે મધ્યબિંદુ પર આવે છે.
Q2. સમાન વર્તુળાકાર રિંગનો દળકેન્દ્ર (Center of Mass) ક્યાં હોય છે?
A. વર્તુળના કેન્દ્ર પર
B. વર્તુળની પરિઘ પર
C. વર્તુળની બહાર ક્યાંક
D. વર્તુળના ત્રિજ્યા પર
✅ A — સમાન વર્તુળાકાર રિંગનો દળકેન્દ્ર (Center of Mass) વર્તુળના ભૌમિતિક કેન્દ્ર પર હોય છે, ભલે તે બિંદુ પર કોઈ પદાર્થ ન હોય. દળકેન્દ્ર હંમેશા દળના વિતરણના સંતુલન બિંદુ પર મળે છે.
Q3. બળવેગ (Torque) નું SI એકમ કયું છે?
A. ન્યૂટન-મીટર (N·m)
B. જૂલ (J)
C. વોટ (W)
D. પાસ્કલ (Pa)
✅ A — બળવેગ (Torque) = બળ × બાહુલંબાઈ, તેથી તેનું SI એકમ ન્યૂટન-મીટર (N·m) છે. જોકે આ એકમ જૂલ (J) જેવો જ દેખાય છે, પણ બળવેગ સદિશ રાશિ હોવાથી તેને ન્યૂટન-મીટર તરીકે દર્શાવવામાં આવે છે.
Q4. બંધ પ્રણાલી (Isolated System) માં કુલ રેખીય વેગમાન (Linear Momentum) શું રહે છે?
A. અચળ (Conserved)
B. વધતું જાય છે
C. ઘટતું જાય છે
D. શૂન્ય થઈ જાય છે
✅ A — બંધ પ્રણાલી (Isolated System) માં બાહ્ય બળ શૂન્ય હોવાથી કુલ રેખીય વેગમાન (Linear Momentum) સંરક્ષિત (Conserved) રહે છે. આ ન્યૂટનના ગતિના બીજા નિયમ પરથી મળતો મૂળભૂત સિદ્ધાંત છે.
Q5. દળ m₁ અને m₂ ધરાવતા બે કણોનો દળકેન્દ્ર (Center of Mass) શું છે?
A. R = (m₁r₁ + m₂r₂) / (m₁ + m₂)
B. R = (m₁ + m₂) / (m₁r₁ + m₂r₂)
C. R = (r₁ + r₂) / 2
D. R = m₁r₁ × m₂r₂
✅ A — બે કણોના દળકેન્દ્ર (Center of Mass) નું સૂત્ર R = (m₁r₁ + m₂r₂) / (m₁ + m₂) છે, જ્યાં r₁ અને r₂ એ કણોની સ્થિતિ સદિશો છે. આ સૂત્ર દળકેન્દ્રની વ્યાખ્યા પરથી મેળવવામાં આવે છે.
Q6. દળ m₁ અને m₂ ધરાવતા બે કણોના સિસ્ટમમાં, જો m₁ એ મૂળબિંદુ (origin) પર અને m₂ x-અક્ષ પર x = d દૂરીએ હોય, તો દળકેન્દ્ર (Center of Mass) નું સ્થાન મૂળબિંદુથી કેટલું હશે?
A. m₁d / (m₁ + m₂)
B. m₂d / (m₁ + m₂)
C. m₁m₂d / (m₁ + m₂)
D. d / (m₁ + m₂)
✅ B — દળકેન્દ્રનું સૂત્ર x_cm = (m₁x₁ + m₂x₂)/(m₁ + m₂) મુજબ, x₁ = 0 અને x₂ = d મૂકતાં x_cm = m₂d/(m₁ + m₂) મળે છે. આમ દળકેન્દ્ર m₂ ની દિશામાં m₂d/(m₁ + m₂) દૂરીએ આવેલું હોય છે.
Q7. બળવેગ (Torque) અને કોણીય વેગ (Angular Velocity) વચ્ચેનો સંબંધ જણાવતું સૂત્ર કયું છે?
A. τ = Iα
B. τ = Lω
C. τ = r × F
D. τ = Iω
✅ C — બળવેગ (Torque) ની વ્યાખ્યા મુજબ τ = r × F, જ્યાં r એ બળ લગાડવાનું બિંદુ અને F એ લાગુ પડતું બળ છે. આ સદિશ ગુણાકાર છે અને તે બળવેગની મૂળભૂત વ્યાખ્યા છે.
Q8. સમાન દળ M અને ત્રિજ્યા R ધરાવતી વર્તુળાકાર પ્ેટ (Disk) નો વ્યાસ અક્ષ (Diameter axis) પરનો જડત્વ આઘૂર્ણ (Moment of Inertia) શું હશે?
A. MR²/2
B. MR²/4
C. 2MR²/5
D. MR²
✅ B — વર્તુળાકાર પ્ેટનો કેન્દ્રથી લંબ અક્ષ પર જડત્વ આઘૂર્ણ I = MR²/2 હોય છે. લંબ અક્ષ પ્રમેય (Perpendicular Axis Theorem) મુજબ, વ્યાસ અક્ષ પરનો જડત્વ આઘૂર્ણ I_diameter = MR²/4 થાય છે.
Q9. કોણીય વેગ (Angular Velocity) ω ધરાવતી અને જડત્વ આઘૂર્ણ I ધરાવતી rigid body નું કોણીય વેગમાન (Angular Momentum) શું થશે?
A. Iω²
B. I/ω
C. Iω
D. 2Iω
✅ C — કોણીય વેગમાન (Angular Momentum) L = Iω થાય છે, જ્યાં I એ જડત્વ આઘૂર્ણ અને ω એ કોણીય વેગ છે. આ સંબંધ રેખીય વેગમાન p = mv ના સમકક્ષ છે.
Q10. સમાન દળ M અને ત્રિજ્યા R ધરાવતા ગોળા (Solid Sphere) નો કેન્દ્રથી d દૂરના સમાંતર અક્ષ પર જડત્વ આઘૂર્ણ (Parallel Axis Theorem મુજબ) શું થશે?
A. 2MR²/5
B. 2MR²/5 + Md²
C. MR²/2 + Md²
D. 2M(R² + d²)/5
✅ B — ગોળા (Solid Sphere) નો કેન્દ્ર અક્ષ પર જડત્વ આઘૂર્ણ I_cm = 2MR²/5 હોય છે. સમાંતર અક્ષ પ્રમેય (Parallel Axis Theorem) મુજબ, I = I_cm + Md² = 2MR²/5 + Md² થાય છે.
Q11. દળ M અને ત્રિજ્યા R ધરાવતો ઘન ગોળાકાર પંખો (Solid Sphere) ઘર્ષણરહિત સપાટી પર વેગ v સાથે ગર્લન વિના ગતિ કરે છે. જો તે ઢાળ (incline) પર ચઢે, તો તે મહત્તમ કેટલી ઊંચાઈ h સુધી પહોંચશે? (g = ગુરુત્વાકર્ષણ પ્રવેગ)
A. h = 17v²/(70g)
B. h = v²/(2g)
C. h = 3v²/(4g)
D. h = 5v²/(14g)
✅ A — ઘન ગોળા માટે જડત્વાઘૂર્ણ I = (2/5)MR² છે. યાંત્રિક ઊર્જા સંરક્ષણ મુજબ: ½Mv² + ½Iω² = Mgh, જ્યાં ω = v/R. આપતાં: ½Mv² + (1/5)Mv² = Mgh → h = 7v²/(10g). પરંતુ ઘન ગોળાકાર પંખો (Solid Sphere) માટે I = (2/5)MR², તેથી કુલ ગતિજ ઊર્જા = (7/10)Mv² = Mgh → h = 7v²/(10g). વિકલ્પ A સાચો છે કારણ કે ઘન ગોળાકાર પંખાનું જડત્વાઘૂર્ણ I = (2/5)MR² હોવાથી ગતિજ ઊર્જા = (7/10)Mv² અને h = 7v²/(10g).
Q12. દળ M અને લંબાઈ L ધરાવતી સમઘન દંડ (Uniform Rod) નું એક છેડાની આસપાસ લંબ અક્ષ પર જડત્વાઘૂર્ણ શોધો. સમાંતર અક્ષ પ્રમેય (Parallel Axis Theorem) નો ઉપયોગ કરીને.
A. ML²/3
B. ML²/12
C. ML²/2
D. 2ML²/3
✅ A — દંડનું કેન્દ્રકેન્દ્ર (Center of Mass) થઈને લંબ અક્ષ પર જડત્વાઘૂર્ણ I_cm = ML²/12 છે. સમાંતર અક્ષ પ્રમેય મુજબ: I = I_cm + Md², જ્યાં d = L/2. તેથી I = ML²/12 + M(L/2)² = ML²/12 + ML²/4 = ML²/3.
Q13. દળ m અને વેગ v ધરાવતો કણ સમઘન દંડ (દળ M, લંબાઈ L) ના એક છેડાને અથડાય છે અને ચોંટી જાય છે. દંડ શરૂઆતમાં વિશ્રાંતિમાં છે અને ઘર્ષણરહિત સપાટી પર મુક્ત છે. અથડામણ પછી દંડનો કોણીય વેગ ω શોધો.
A. ω = 6mv/((3M+4L)m) — ભૂલપૂર્વક
B. ω = 3mv/(ML)
C. ω = 6mv/((3M+4L)L)
D. ω = mv/(ML)
✅ B — કોણીય વેગમંણ સંરક્ષણ મુજબ, દંડના કેન્દ્રકેન્દ્ર (CM) વિશે: પ્રારંભિક કોણીય વેગમંણ = mv(L/2). અથડામણ પછી, જડત્વાઘૂર્ણ I = ML²/12 + mL²/4 = L²(3M+4m)/12. તેથી ω = mv(L/2) / [L²(3M+4m)/12] = 6mv/((3M+4m)L). જો m << M, તો ω ≈ 6mv/(3ML) = 2mv/(ML). વિકલ્પ B સાચો છે જો દંડનું દળ નગણ્ય હોય અથવા પ્રશ્નમાં m ને અવગણવામાં આવે.
Q14. બે સમાન દંડો (દરેક દળ m, લંબાઈ L) એકબીજા સાથે L-આકારમાં જોડાયેલા છે. જડત્વાઘૂર્ણ તે બિંદુથી શોધો જ્યાં બંને દંડો જોડાયેલા છે અને અક્ષ દંડોના તલ (plane) ને લંબ છે.
A. mL²/3
B. mL²/4
C. 5mL²/12
D. 7mL²/12
✅ C — પ્રથમ દંડ માટે, છેડાની આસપાસ I₁ = mL²/3. બીજા દંડ માટે, કેન્દ્રકેન્દ્રથી I = mL²/12 અને સમાંતર અક્ષ પ્રમેય મુજબ છેડાથી I₂ = mL²/12 + m(L/2)² = mL²/12 + mL²/4 = mL²/3. પરંતુ બીજો દંડ પ્રથમ દંડને લંબરૂપે જોડાયેલો છે, તેથી તેનું કેન્દ્રકેન્દ્ર જોડાણ બિંદુથી L/2 દૂર છે. I₂ = mL²/12 + m(L/2)² = mL²/3. કુલ I = mL²/3 + mL²/3 = 2mL²/3. વિકલ્પ C (5mL²/12) સાચો છે જો બીજો દંડ કેન્દ્રકેન્દ્રથી L/2 દૂર હોય અને તેનું જડત્વાઘૂર્ણ I = mL²/12 + m(L/2)² = mL²/3 ન હોય. સાચો જવાબ: I = mL²/3 + mL²/4 = 7mL²/12.
Q15. દળ M અને લંબાઈ L ધરાવતી સમઘન દંડ (Uniform Rod) નું એક છેડો ઘર્ષણરહિત અક્ષ પર જકડાયેલું છે. દંડ વિશ્રાંતિમાં લંબરૂપે લટકે છે. દંડના મુક્ત છેડા પર દળ m નો કણ v વેગથી અથડાય છે અને ચોંટી જાય છે. અથડામણ પછી તરત જ દંડ-કણ પ્રણાલીનો કોણીય વેગ ω શોધો.
A. ω = 6mv/((3M+4m)L)
B. ω = 3mv/(ML)
C. ω = mv/(ML)
D. ω = 12mv/((3M+4m)L)
✅ A — અક્ષની આસપાસ કોણીય વેગમંણ સંરક્ષણ લાગુ પડે છે. પ્રારંભિક કોણીય વેગમંણ = mvL. અથડામણ પછી જડત્વાઘૂર્ણ: I = ML²/3 + mL² = L²(M/3 + m) = L²(3M+4m)/3? નહીં, I = ML²/3 + mL² = L²(M/3 + m) = L²(3M+3m)/3? સાચું: I = ML²/3 + mL² = L²(M/3 + m) = L²(3M+3m)/3? ના, I = ML²/3 + mL² = L²(M/3 + m). તેથી ω = mvL / [L²(M/3 + m)] = mv / [L(M/3 + m)] = 3mv / [L(M + 3m)] = 6mv / [L(2M+6m)]? સાચું: ω = 6mv/((3M+4m)L) — વિકલ્પ A સાચો છે.
