પ્રકાશશાસ્ત્ર — સૂત્ર પત્રિકા (Optics — Formula Sheet)

⚡ સૂત્રો

પ્રતિબિંબનો પ્રથમ નિયમ: આપાત કિરણ, પ્રતિબિંબિત કિરણ અને અભિલંબ એક જ સમતલમાં હોય છે.
આપાત કોણ = i, પ્રતિબિંબ કોણ = r · SI: — · સપાટ અને વક્ર બંને પ્રકારના પૃષ્ઠ માટે
પ્રતિબિંબનો દ્વિતીય નિયમ: i = r
i = આપાત કોણ, r = પ્રતિબિંબ કોણ · SI: — · દરેક પ્રતિબિંબ માટે
સપાટ અરીસાનું મોટવણ: m = +1
m = રેખીય મોટવણ · SI: — · સપાટ અરીસા માટે
ગોળાકાર અરીસાનું અવકાશ સૂત્ર: 1/v + 1/u = 1/f
v = પ્રતિબિંબ અંતર, u = વસ્તુ અંતર, f = નાભિઅંતર · SI: m (મીટર) · અભિસારી અને અપસારી બંને અરીસાઓ માટે (કાર્ટેઝિયન ચિહ્ન પ્રણાલી)
નાભિઅંતર અને વક્રતા ત્રિજ્યા વચ્ચેનો સંબંધ: f = R / 2
f = નાભિઅંતર, R = વક્રતા ત્રિજ્યા · SI: m (મીટર) · અરીસાઓ માટે, જ્યારે પરિધિ અંતર (aperture) નાનું હોય
અરીસાનું રેખીય મોટવણ: m = -v / u
m = રેખીય મોટવણ, v = પ્રતિબિંબ અંતર, u = વસ્તુ અંતર · SI: — · અરીસાઓ માટે, કાર્ટેઝિયન ચિહ્ન પ્રણાલી
સ્નેલનો નિયમ (લંઘન): n1 * sin(i) = n2 * sin(r)
n1, n2 = માધ્યમોના વક્રીભવન સૂચકાંક, i = આપાત કોણ, r = લંઘન કોણ · SI: — · બે સ્પષ્ટ માધ્યમોની સીમા પર
પરિણામી વક્રીભવન સૂચકાંક: n21 = n2 / n1 = sin(i) / sin(r)
n21 = માધ્યમ 1 ની સાપેક્ષે માધ્યમ 2 નો વક્રીભવન સૂચકાંક · SI: — · પ્રકાશ માધ્યમ 1 માંથી માધ્યમ 2 માં પ્રવેશે ત્યારે
વક્રીભવન સૂચકાંક અને પ્રકાશવેગ: n = c / v
n = વક્રીભવન સૂચકાંક, c = શૂન્યાવકાશમાં પ્રકાશવેગ (3 × 10⁸ m/s), v = માધ્યમમાં પ્રકાશવેગ · SI: v નો એકમ m/s · દરેક પારદર્શક માધ્યમ માટે
સંપૂર્ણ આંતરિક પ્રતિબિંબ — ક્રાંતિકોણ: sin(C) = 1 / n (જ્યારે પ્રકાશ ઘન માધ્યમમાંથી સ્ફટિકમાં જાય)
C = ક્રાંતિકોણ, n = ઘન માધ્યમનો વક્રીભવન સૂચકાંક · SI: — · પ્રકાશ ઘન માધ્યમમાંથી વિરળ માધ્યમમાં જાય અને આપાત કોણ > ક્રાંતિકોણ હોય
લેન્સ મેકરનું સૂત્ર: 1/f = (n - 1) * (1/R1 - 1/R2)
f = લેન્સનું નાભિઅંતર, n = લેન્સ સામગ્રીનો વક્રીભવન સૂચકાંક, R1 અને R2 = બંને પૃષ્ઠોની વક્રતા ત્રિજ્યા · SI: f નો એકમ m · પાતળા લેન્સ માટે, કાર્ટેઝિયન ચિહ્ન પ્રણાલી
પાતળા લેન્સનું અવકાશ સૂત્ર: 1/v - 1/u = 1/f
v = પ્રતિબિંબ અંતર, u = વસ્તુ અંતર, f = નાભિઅંતર · SI: m (મીટર) · અભિસારી અને અપસારી બંને પાતળા લેન્સ માટે (કાર્ટેઝિયન ચિહ્ન પ્રણાલી)
લેન્સનું રેખીય મોટવણ: m = v / u
m = રેખીય મોટવણ, v = પ્રતિબિંબ અંતર, u = વસ્તુ અંતર · SI: — · પાતળા લેન્સ માટે, કાર્ટેઝિયન ચિહ્ન પ્રણાલી
લેન્સની શક્તિ: P = 1 / f
P = લેન્સની શક્તિ, f = નાભિઅંતર (મીટરમાં) · SI: D (ડાયોપ્ટર) · નાભિઅંતર મીટરમાં હોય ત્યારે
લેન્સોની જોડી — પરિણામી શક્તિ: P = P1 + P2
P = પરિણામી શક્તિ, P1, P2 = વ્યક્તિગત લેન્સની શક્તિ · SI: D (ડાયોપ્ટર) · બે પાતળા લેન્સ સંપર્કમાં હોય ત્યારે
લેન્સોની જોડી — પરિણામી નાભિઅંતર: 1/F = 1/f1 + 1/f2
F = પરિણામી નાભિઅંતર, f1, f2 = વ્યક્તિગત નાભિઅંતર · SI: m (મીટર) · બે પાતળા લેન્સ સંપર્કમાં હોય ત્યારે
પ્રિઝમ — ન્યૂનતમ વિચ્યુતિ સૂત્ર: n = sin((A + Dm) / 2) / sin(A / 2)
n = પ્રિઝમ સામગ્રીનો વક્રીભવન સૂચકાંક, A = પ્રિઝમ કોણ, Dm = ન્યૂનતમ વિચ્યુતિ કોણ · SI: — · ન્યૂનતમ વિચ્યુતિની સ્થિતિમાં
સૂક્ષ્મદર્શક — મોટવણ (સામાન્ય દ્રષ્ટિ): M = (L / f_o) * (1 + f_e / D)
M = મોટવણ, L = ટ્યુબ લંબાઈ, f_o = અભિસારી લેન્સનું નાભિઅંતર, f_e = અપસારી લેન્સનું નાભિઅંતર, D = સ્પષ્ટ દર્શન અંતર (~25 cm) · SI: — · પ્રતિબિંબ સ્પષ્ટ દર્શન અંતરે બને ત્યારે
સૂક્ષ્મદર્શક — મોટવણ (અનંત દ્રષ્ટિ): M = L / f_o * (D / f_e)
M = મોટવણ, L = ટ્યુબ લંબાઈ, f_o = અભિસારી લેન્સનું નાભિઅંતર, f_e = અપસારી લેન્સનું નાભિઅંતર, D = સ્પષ્ટ દર્શન અંતર · SI: — · પ્રતિબિંબ અનંતે બને ત્યારે
દૂરબીન — મોટવણ: M = f_o / f_e
M = મોટવણ, f_o = અભિસારી લેન્સનું નાભિઅંતર, f_e = અપસારી લેન્સનું નાભિઅંતર · SI: — · અનંત દ્રષ્ટિ માટે (સામાન્ય સંરેખણ)
યંગના દ્વિ-સ્લિટ પ્રયોગ — પ્રકાશીય માર્ગાંતર: Δx = d * sin(θ) ≈ d * y / D
d = સ્લિટ વચ્ચેનું અંતર, y = પડદા પર બિંદુનું કેન્દ્રથી અંતર, D = સ્લિટથી પડદાનું અંતર · SI: m (મીટર) · પરંપરાગત દ્વિ-સ્લિટ વિવર્તન/વ્યતિકરણ
યંગ પ્રયોગ — પ્રકાશીય પટ્ટાની પહોળાઈ: β = λ * D / d
β = પટ્ટાની પહોળાઈ, λ = પ્રકાશની તરંગલંબાઈ, D = સ્લિટ-પડદા અંતર, d = સ્લિટ વચ્ચેનું અંતર · SI: m (મીટર) · સુસંહ પ્રકાશ માટે
વ્યતિકરણ — સ્પષ્ટ મહત્તમ (constructive): Δx = n * λ, n = 0, 1, 2, ...
Δx = માર્ગાંતર, λ = તરંગલંબાઈ, n = પૂર્ણાંક · SI: — · સ્પષ્ટ મહત્તમ માટેની શરત
વ્યતિકરણ — સ્પષ્ટ ન્યૂનતમ (destructive): Δx = (2n - 1) * λ / 2, n = 1, 2, 3, ...
Δx = માર્ગાંતર, λ = તરંગલંબાઈ · SI: — · સ્પષ્ટ ન્યૂનતમ માટેની શરત
વિવર્તન — પ્રથમ ન્યૂનતમ (એકલ સ્લિટ): sin(θ) = λ / a
θ = વિવર્તન કોણ, λ = તરંગલંબાઈ, a = સ્લિટની પહોળાઈ · SI: — · એકલ સ્લિટ વિવર્તનમાં પ્રથમ ન્યૂનતમ માટે
ધ્રુવીભવન — મલ્લસનો નિયમ: I = I0 * cos²(θ)
I = નિર્ગત પ્રકાશની તીવ્રતા, I0 = આપાત ધ્રુવીભૂત પ્રકાશની તીવ્રતા, θ = ધ્રુવીકરણ અક્ષ અને પોલરાઇડ અક્ષ વચ્ચેનો કોણ · SI: W/m² (તીવ્રતા) · ધ્રુવીભૂત પ્રકાશ પોલારોઇડમાંથી પસાર થાય ત્યારે
બ્રુસ્ટરનો નિયમ (ધ્રુવીભવન કોણ): tan(θp) = n
θp = ધ્રુવીભવન કોણ (બ્રુસ્ટર કોણ), n = માધ્યમનો વક્રીભવન સૂચકાંક · SI: — · પ્રકાશ વક્રીભવનથી સંપૂર્ણ ધ્રુવીભૂત થાય ત્યારે
પ્રકાશની તરંગલંબાઈ અને આવૃત્તિ: c = λ * f
c = પ્રકાશવેગ, λ = તરંગલંબાઈ, f = આવૃત્તિ · SI: c = m/s, λ = m, f = Hz · શૂન્યાવકાશ/વાયુમાં
ફેરમાટનો સિદ્ધાંત (સંક્ષિપ્ત): પ્રકાશ હંમેશા એવા માર્ગે ગમન કરે છે જેમાં સમય (અથવા પ્રકાશીય માર્ગ) ન્યૂનતમ હોય.
— · SI: — · પ્રતિબિંબ અને લંઘન બંનેના મૂળભૂત સિદ્ધાંત તરીકે

🔗 સંબંધો

  • અરીસાનું નાભિઅંતર f અને વક્રતા ત્રિજ્યા R વચ્ચે f = R/2 છે; અભિસારી અરીસા માટે f ધન અને અપસારી અરીસા માટે f ઋણ લેવાય.
  • લેન્સની શક્તિ P અને નાભિઅંતર f વચ્ચે P = 1/f છે; નાભિઅંતર મીટરમાં હોય તો શક્તિ ડાયોપ્ટરમાં મળે.
  • બે સંપર્કમાં રહેલા લેન્સોની પરિણામી શક્તિ P = P1 + P2 છે, એટલે કે શક્તિઓ સ્કેલર જોડાણ ધરાવે છે.
  • વક્રીભવન સૂચકાંક n = c/v છે; માધ્યમ જંડ હોય તેટલો n મોટો અને પ્રકાશવેગ v ઓછો.
  • ક્રાંતિકોણ C અને વક્રીભવન સૂચકાંક n વચ્ચે sin(C) = 1/n છે; n મોટો હોય તો C નાનો.
  • અરીસાનું મોટવણ m = -v/u અને લેન્સનું મોટવણ m = v/u છે; અરીસામાં ઋણ ચિહ્ન પ્રતિબિંબના ઉલટા હોવા સૂચવે છે.
  • યંગ પ્રયોગમાં પટ્ટાની પહોળાઈ β = λD/d છે; λ વધે તો β વધે, d વધે તો β ઘટે.
  • મલ્લસના નિયમ મુજબ I = I0 cos²θ છે; θ = 0° હોય તો મહત્તમ તીવ્રતા, θ = 90° હોય તો શૂન્ય તીવ્રતા.
  • પ્રિઝમના ન્યૂનતમ વિચ્યુતિ સૂત્રમાં n = sin((A+Dm)/2) / sin(A/2) છે; A નાનું હોય તો Dm પણ નાનો હોય છે.

🎯 ટ્રિક્સ

અરીસા સૂત્ર 1/v + 1/u = 1/f અને લેન્સ સૂત્ર 1/v - 1/u = 1/f વચ્ચેનો ફરક માત્ર u ના ચિહ્નનો છે; યાદ રાખો: અરીસામાં '+' અને લેન્સમાં '-' (કાર્ટેઝિયન પ્રણાલીમાં).
f = R/2 સૂત્ર યાદ રાખવાની રીત: 'નાભિ અડધી ત્રિજ્યા' — અરીસા/લેન્સ બંને માટે આ સંબંધ લાગુ પડે છે.
લેન્સ મેકર સૂત્રમાં (1/R1 - 1/R2): અભિસારી લેન્સ માટે પરિણામ ધન અને અપસારી લેન્સ માટે ઋણ આવે છે.
યંગ પ્રયોગમાં પટ્ટાની પહોળાઈ β = λD/d છે; યાદ રાખવાની રીત: 'બીટા = લાંબો × દૂર / દૂર' — λ, D, d માં D ઉપર અને d નીચે.
મલ્લસના નિયમમાં θ = 45° હોય તો I = I0/2 થાય; આ અર્ધ-તીવ્રતા બિંદુ છે.
લેન્સોની જોડીમાં શક્તિનો સરવાળો સીધો કરી શકાય: P_total = P1 + P2; ફોકસ લંબાઈનો સરવાળો નહીં.
સંપૂર્ણ આંતરિક પ્રતિબિંબ માત્ર ત્યારે જ શક્ય છે જ્યારે પ્રકાશ ઘન માધ્યમમાંથી વિરળ માધ્યમમાં જતો હોય અને i > C હોય.

⚠️ ભૂલો

અરીસા અને લેન્સના સૂત્રમાં u ના ચિહ્નનો ફરક ભૂલી જવો: અરીસામાં 1/v + 1/u = 1/f, લેન્સમાં 1/v - 1/u = 1/f.
લેન્સ મેકર સૂત્રમાં R1 અને R2 ના ચિહ્નની ગેરસમજ: કાર્ટેઝિયન પ્રણાલી મુજબ પ્રકાશની દિશા પ્રમાણે વક્રતા કેન્દ્ર ધન કે ઋણ લેવાય.
મોટવણ m = -v/u (અરીસા) અને m = v/u (લેન્સ) વચ્ચે ચિહ્નનો ફરક ભૂલી જવો.
વક્રીભવન સૂચકાંક n = c/v માં v ને પ્રકાશવેગ માની ભૂલ કરવી; v એ માધ્યમમાં પ્રકાશવેગ છે, વેગ નહીં.
ક્રાંતિકોણ C = sin⁻¹(1/n) માં n ને વિરુદ્ધ માધ્યમનો સૂચકાંક લઈ ભૂલ કરવી; n હંમેશા ઘન માધ્યમનો સૂચકાંક હોવો જોઈએ.
લેન્સની શક્તિ P = 1/f માં f ને સે.મી.માં મૂકી શક્તિ ડાયોપ્ટરમાં લેવી — f હંમેશા મીટરમાં લેવી.
યંગ પ્રયોગમાં β = λD/d સૂત્રમાં D અને d ને ઉલટા મૂકવા.
મલ્લસના નિયમ I = I0 cos²θ માં θ ને પ્રકાશની દિશા અને પોલારોઇડ અક્ષ વચ્ચેનો કોણ માની ભૂલ કરવી; θ એ ધ્રુવીભવન અક્ષ અને પોલારોઇડ અક્ષ વચ્ચેનો કોણ છે.
પ્રિઝમના ન્યૂનતમ વિચ્યુતિ સૂત્રમાં A અને Dm ને ગેરસમજી (A+Dm)/2 ને A/2 વડે ભાગવા બદલે ઉલટું કરવું.
લેન્સોની જોડીમાં 1/F = 1/f1 + 1/f2 ને P = P1 + P2 તરીકે યાદ રાખવું જોઈએ; ફોકસ લંબાઈનો સરવાળો કરવો નહીં.
