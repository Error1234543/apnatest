ઉષ્માગતિશાસ્ત્ર — હસ્તાક્ષર શૈલી નોંધો

🧪 GUJCET — Gujarati • Physics • Thermodynamics

1. ઉષ્માગતિશાસ્ત્ર — પરિચય
ઉષ્માગતિશાસ્ત્ર (Thermodynamics) એ ભૌતિકશાસ્ત્રની એવી શાખા છે જે ઉષ્મા, કાર્ય, તાપમાન અને ઊર્જાના રૂપાંતર વચ્ચેના સંબંધોનો અભ્યાસ કરે છે.
▶ ઉષ્માગતિશાસ્ત્ર એ સૂક્ષ્મ (microscopic) કણોને બદલે સ્થૂલ (macroscopic) લક્ષણો જેવા કે દબાણ, ઘનફળ, તાપમાન પર આધારિત છે.
ઉષ્માગતિશાસ્ત્રના નિયમો પ્રયોગો દ્વારા પ્રાપ્ત થયા છે અને તેઓ શક્તિ સંરક્ષણ, ઉષ્માનો પ્રવાહ દિશા અને મહત્તમ કાર્યક્ષમતાની મર્યાદા નક્કી કરે છે.
📝 📌 GUJCET માટે: ઉષ્માગતિશાસ્ત્રના બે નિયમો (પ્રથમ અને દ્વિતીય) પર ખાસ ધ્યાન આપો.
2. વ્યવસ્થા, પર્યાવરણ અને અનુરૂપ વ્યવસ્થાઓ
વ્યવસ્થા (System): ભૌતિકશાસ્ત્રના અભ્યાસ માટે વ્યાખ્યાયિત ભાગ અથવા વિસ્તાર જેનું વિશ્લેષણ કરવામાં આવે છે.
પર્યાવરણ (Surroundings): વ્યવસ્થાની બહારનો સમગ્ર વિશ્વ જે વ્યવસ્થા સાથે ઊર્જા કે દ્રવ્યની આપ-લે કરે છે.
સમગ્ર વિશ્વ = વ્યવસ્થા + પર્યાવરણ
ખુલી વ્યવસ્થા (Open System): વ્યવસ્થા અને પર્યાવરણ વચ્ચે ઊર્જા અને દ્રવ્ય — બંનેની આપ-લે થાય છે.
બંધ વ્યવસ્થા (Closed System): માત્ર ઊર્જાની આપ-લે થાય છે; દ્રવ્યની આપ-લે થતી નથી.
અલગ વ્યવસ્થા (Isolated System): ઊર્જા કે દ્રવ્ય — કોઈ પણ પ્રકારની આપ-લે થતી નથી.
▶ બંધ વ્યવસ્થામાં શક્તિની આપ-લે થાય છે પણ દ્રવ્ય અવરોધિત છે (દા.ત. બંધ પાત્રમાં વાયુ). અલગ વ્યવસ્થા — દા.ત. આદર્શ થર્મોસ.
📝 📌 અનુરૂપ વ્યવસ્થાઓના પ્રશ્નો GUJCET માં પ્રત્યેક વર્ષે આવે છે.
3. થર્મોડાયનેમિક સંતુલન અને અવસ્થા ચલો
થર્મોડાયનેમિક સંતુલન: જ્યારે વ્યવસ્થાના તમામ થર્મોડાયનેમિક ગુણધર્મો (તાપમાન, દબાણ, ઘનફળ, સાંદ્રતા) સમય સાથે બદલાતા ન હોય ત્યારે વ્યવસ્થા સંતુલનમાં છે.
અવસ્થા ચલો (State Variables): એવા પરિમાણો જે વ્યવસ્થાની અવસ્થા (state) નક્કી કરે છે. ઉદા. દબાણ P, ઘનફળ V, તાપમાન T, આંતરિક ઊર્જા U.
અવસ્થા વિધેયો (State Functions): એવા વિધેયો જેમની કિંમત માત્ર વર્તમાન અવસ્થા પર આધાર રાખે છે, પથ પર નહીં. ઉદા. P, V, T, U, H, S.
▶ વ્યવસ્થા વિધેયો એકપક્ષીય (exact) સંકલન ધરાવે છે. દા.ત., ∫dU માનવાની મૂલ્ય એ છેડાની અવસ્થાઓ પર આધારિત છે, પથ પર નહીં.
📝 📌 U, H, S — ત્રણેય અવસ્થા વિધેયો છે; Q અને W અવસ્થા વિધેયો નથી.
4. આદર્શ વાયુનું અવસ્થા સમીકરણ
આદર્શ વાયુના ગેસ નિયમ મુજબ: PV = nRT
PV = nRT અહીં R = સામાન્ય વાયુ અચળાંક = 8.314 J mol⁻¹ K⁻¹
જો વાયુનું દળ m અને મોલર દળ M હોય, તો n = m/M અને PV = (m/M)RT.
એવોગેડ્રો નિયમ: સમાન તાપમાન અને દબાણે સમાન ઘનફળમાં સમાન અણુઓની સંખ્યા હોય છે.
સામાન્ય તાપમાન અને દબાણ (STP): P = 1 atm, T = 273.15 K, 1 mol વાયુનું ઘનફળ = 22.4 L
📝 📌 R ના વિવિધ એકમો: 8.314 J/mol·K, 0.0821 L·atm/mol·K, 2 cal/mol·K
5. થર્મોડાયનેમિક પ્રક્રિયાઓ (Thermodynamic Processes)
સમતાપી પ્રક્રિયા (Isothermal Process): તાપમાન અચળ રહે છે (T = constant). આદર્શ વાયુ માટે: PV = constant.
સમતાપી પ્રક્રિયામાં આદર્શ વાયુ માટે ΔU = 0 કારણ કે U માત્ર T પર આધારિત છે.
સમતાપી: ΔU = 0Q = W (પ્રથમ નિયમ મુજબ)
સમતાપી કાર્ય: W = nRT ln(V₂/V₁) = 2.303 nRT log₁₀(V₂/V₁)
રૂઢિગત (Adiabatic Process): વ્યવસ્થા અને પર્યાવરણ વચ્ચે ઉષ્માની આપ-લે શૂન્ય હોય છે (Q = 0).
રૂઢિગત: PV^γ = constant, તથા TV^(γ−1) = constant, PT^((1−γ)/γ) = constant
રૂઢિગત પ્રક્રિયામાં γ = Cp/Cv > 1 હોય છે. રૂઢિગત વક્ર સમતાપી વક્ર કરતાં વધુ steep (ઢાળવાળો) હોય છે.
રૂઢિગત કાર્ય: W = (P₁V₁ − P₂V₂)/(γ − 1) = nR(T₁ − T₂)/(γ − 1)
▶ રૂઢિગત વિસ્તરણ: વાયુ કાર્ય કરે → તાપમાન ઘટે. રૂઢિગત સંકોચન: કાર્ય થાય → તાપમાન વધે.
સમદાબી પ્રક્રિયા (Isobaric Process): દબાણ અચળ (P = constant). ચાર્લ્સના નિયમ મુજબ V/T = constant.
સમદાબી કાર્ય: W = P(V₂ − V₁) = nR(T₂ − T₁)
સમઘનફલ પ્રક્રિયા (Isochoric Process): ઘનફળ અચળ (V = constant), તેથી કાર્ય W = 0.
સમઘનફલ: V = constantW = 0, Q = ΔU
ચક્રીય પ્રક્રિયા (Cyclic Process): પ્રારંભિક અને અંતિમ અવસ્થા સમાન હોય. ΔU = 0, તથા Q_net = W_net.
▶ PV આલેખમાં બંધ વલયાનું ક્ષેત્રફળ = ચક્ર દરમિયાન થતું કુલ કાર્ય.
📝 📌 આ પ્રક્રિયાઓના PV-આલેખ અને સમીકરણો યાદ રાખો — GUJCET માં વિશેષ મહત્વ.
6. ઉષ્માગતિશાસ્ત્રનો પ્રથમ નિયમ (First Law of Thermodynamics)
ઉષ્માગતિશાસ્ત્રનો પ્રથમ નિયમ એ શક્તિ સંરક્ષણનો નિયમ છે.
ΔQ = ΔU + ΔW અથવા dQ = dU + dW
જો વ્યવસ્થામાંથી ઉષ્મા ΔQ મળે અને વ્યવસ્થા દ્વારા કાર્ય ΔW થાય, તો આંતરિક ઊર્જામાં વધારો ΔU = ΔQ − ΔW.
▶ ચિહ્ન પરંપરા: વ્યવસ્થા પર કાર્ય થાય (compression) → ΔW ઋણ; વ્યવસ્થા દ્વારા કાર્ય થાય (expansion) → ΔW ધન.
📝 📌 પ્રથમ નિયમ મુજબ 'અમર્યાદિત કાર્ય મેળવતું એન્જિન' (Perpetual Motion Machine of 1st kind) અશક્ય છે.
7. વિશિષ્ટ ઉષ્મા ધારિતાઓ અને તેમનો સંબંધ
Cv: સમઘનફલે મોલર ઉષ્મા ધારિતા — ઘનફળ અચળ રાખી 1 mol વાયુનું તાપમાન 1 K વધારવા માટે જરૂરી ઉષ્મા.
Cp: સમદાબીએ મોલર ઉષ્મા ધારિતા — દબાણ અચળ રાખી 1 mol વાયુનું તાપમાન 1 K વધારવા માટે જરૂરી ઉષ્મા.
Cp − Cv = R (મેયરનું સમીકરણ, Mayer's Relation)
γ = Cp / Cv (એડિયાબેટિક ઇન્ડેક્સ, Adiabatic Index)
એક પરમાણુીય (Monatomic) વાયુ: Cv = (3/2)R, Cp = (5/2)R, γ = 5/3 ≈ 1.67
દ્વિપરમાણુીય (Diatomic) વાયુ (સામાન્ય તાપમાને): Cv = (5/2)R, Cp = (7/2)R, γ = 7/5 = 1.4
▶ Cp > Cv હોય છે કારણ કે સમદાબી પ્રક્રિયામાં વાયુ ઉષ્માનું_some_ભાગ બાહ્ય કાર્યમાં ખર્ચે છે, ફક્ત ΔU માં નહીં.
📝 📌 γ ની કિંમત જાણવી GUJCET માટે ખૂબ મહત્વની છે — મોનોએટોમિક vs ડાયાટોમિક વાયુઓ.
8. મહત્તમ કાર્ય અને ઉષ્મા એન્જિન
ઉષ્મા એન્જિન (Heat Engine): એવી યંત્રવ્યવસ્થા જે ઉચ્ચ તાપમાનની ઉષ્માભંડોળ (reservoir) માંથી ઉષ્મા શોષીને કુદરતી રીતે કાર્ય ઉત્પન્ન કરે છે.
કાર્યક્ષમતા: η = W / Q₁ = (Q₁ − Q₂) / Q₁ = 1 − Q₂/Q₁
Q₁: ઉચ્ચ તાપમાન TH માંથી શોષાયેલી ઉષ્મા; Q₂: નીચા તાપમાન TL તરફ વહેરાયેલી ઉષ્મા; W: ઉત્પન્ન થતું કાર્ય.
▶ ઉષ્મા એન્જિનની કાર્યક્ષમતા હંમેશા 1 થી ઓછી હોય છે — કારણ કે Q₂ > 0 હોય છે. 100% કાર્યક્ષમતા અશક્ય.
📝 📌 કાર્યક્ષમતા η એ સંખ્યાઓ (0 < η < 1) માં દર્શાવે છે, ટકાવારી ≠ η × 100.
9. કાર્નોટ ચક્ર (Carnot Cycle) અને કાર્નોટ એન્જિન
કાર્નોટ ચક્ર ચાર પ્રક્રિયાઓનું બનેલું છે: (1) સમતાપી વિસ્તરણ, (2) રૂઢિગત વિસ્તરણ, (3) સમતાપી સંકોચન, (4) રૂઢિગત સંકોચન.
કાર્નોટ એન્જિન એક આદર્શ એન્જિન છે જે કાર્નોટ ચક્ર મુજબ કામ કરે છે. તેની કાર્યક્ષમતા તમામ એન્જિનો કરતાં વધુ છે.
કાર્નોટ કાર્યક્ષમતા: η = 1 − TL/TH (તાપમાન કેલ્વિનમાં)
▶ કાર્નોટ એન્જિનની કાર્યક્ષમતા માત્ર TH અને TL પર આધારિત છે, કાર્યરત પદાર્થ પર નહીં.
જો TL = 0 K (પરિપૂર્ણ શૂન્ય), તો η = 1; પરંતુ 0 K પ્રાપ્ત કરી શકાય નહીં.
કાર્નોટ એન્જિન એ_rev_પ્રક્રિયાઓનું બનેલું છે, તેથી તે સંપૂર્ણપણે વિપરીત (reversible) એન્જિન છે.
કાર્નોટ ચક્ર100% કાર્યક્ષમતા અશક્ય — દ્વિતીય નિયમ પ્રમાણે
📝 📌 કાર્નોટ ચક્ર PV-આલેખ ચાર વલય-ખંડો ધરાવે છે; ચતુષ્કોણ જેવો આકાર બને છે.
10. ઉષ્માગતિશાસ્ત્રનો દ્વિતીય નિયમ
કલ્વિન-પ્લાન્ક કथન (Kelvin-Planck Statement): કોઈ પણ એન્જિન એકલી ઉષ્માભંડોળમાંથી ઉષ્મા લઈને તેનું સંપૂર્ણ રૂપાંતર કાર્યમાં કરી શકતું નથી.
ક્લાઉઝિયસ કથન (Clausius Statement): ઉષ્મા સ્વતઃની રીતે (auto)matically ઠંડી વસ્તુથી ગરમ વસ્તુ તરફ પ્રવાહિત થઈ શકતી નથી.
▶ કલ્વિન-પ્લાન્ક અને ક્લાઉઝિયસ બંને કથનો સમકક્ષ છે — એક નીકળે તો બીજું પણ નીકળે.
દ્વિતીય નિયમનું એન્થ્રોપી કથન: બંધ વ્યવસ્થાની એન્થ્રોપી ક્યારેય ઘટતી નથી; સ્વયંસ્ફુર્ત પ્રક્રિયામાં એન્થ્રોપી વધે છે.
સ્વયંસ્ફુર્ત પ્રક્રિયાસમગ્ર બ્રહ્માંડની એન્થ્રોપી વધે છે
📝 📌 દ્વિતીય નિયમ ઉષ્મા એન્જિનની મહત્તમ કાર્યક્ષમતાની મર્યાદા સ્થાપિત કરે છે.
11. એન્થ્રોપી (Entropy)
એન્થ્રોપી (S) એ થર્મોડાયનેમિક અવસ્થા વિધેય છે જે વ્યવસ્થાના અવ્યવસ્થા (disorder) નું માપ છે.
dS = dQ_rev / T અથવા ΔS = Q_rev / T (સમતાપી પ્રક્રિયા માટે)
એન્થ્રોપીનું SI એકમ: J K⁻¹ (જૂલ પ્રતિ કેલ્વિન).
▶ સ્વયંસ્ફુર્ત પ્રક્રિયાઓમાં બ્રહ્માંડની કુલ એન્થ્રોપી હંમેશા વધે છે: ΔS_total > 0.
રિવર્સિબલ પ્રક્રિયા માટે ΔS_total = 0; આઈરિવર્સિબલ પ્રક્રિયા માટે ΔS_total > 0.
📝 📌 એન્થ્રોપી વધારો એ પ્રક્રિયાની દિશા નક્કી કરે છે — ગરમી હંમેશા ગરમ → ઠંડી તરફ જાય છે.
12. ઉષ્માગતિશાસ્ત્રના અન્ય મહત્વના સંકલ્પનાઓ
ઉષ્મા ઓગાળણી (Latent Heat of Fusion): ઘન પદાર્થ ઓગાળીને પ્રવાહી બનાવવા માટે જરૂરી ઉષ્મા — T અચળ રહે છે.
Q = mL_f (L_f = ઓગાળણીની ગુપ્ત ઉષ્મા)
ઉષ્મા બાષ્પીભવન (Latent Heat of Vaporization): પ્રવાહીને બાષ્પમાં ફેરવવા માટે જરૂરી ઉષ્મા — T અચળ રહે છે.
Q = mL_v (L_v = બાષ્પીભવનની ગુપ્ત ઉષ્મા)
ઉષ્માગતિશાસ્ત્રનો તૃતીય નિયમ (Third Law): પરિપૂર્ણ સ્ફટિકનો એન્થ્રોપી 0 K (પરિપૂર્ણ શૂન્ય) તાપમાને શૂન્ય હોય છે.
▶ 0 K પ્રાપ્ત કરી શકાય નહીં — તૃતીય નિયમ અનુસાર એ અશક્ય છે.
ઉષ્માગતિશાસ્ત્રના નિયમો શૂન્યમથી તૃતીય સુધી છે: → 0 નો નિયમ (સંતુલન), 1 નો નિયમ (ઊર્જા સંરક્ષણ), 2 નો નિયમ (એન્થ્રોપી/દિશા), 3 નો નિયમ (0 K).

13. પ્રક્રિયાઓના PV-આલેખ અને કાર્ય
સમતાપી પ્રક્રિયાનો PV-આલેખ અતિપરાવલય (hyperbola) જેવો હોય છે.
રૂઢિગત પ્રક્રિયાનો PV-આલેખ સમતાપી કરતાં વધુ steep હોય છે કારણ કે PV^γ = constant, γ > 1.
PV-આલેખનું વલય-ક્ષેત્રફળ = ચક્રીય પ્રક્રિયામાં થયેલું કુલ કાર્ય W_net
ઘડિયાળદિશા ચક્રધન કાર્ય (વ્યવસ્થા દ્વારા થયેલું)
ઘડિયાળવિરોધી ચક્રઋણ કાર્ય (વ્યવસ્થા પર થયેલું)
▶ જમણી તરફનું વિસ્તરણ = વ્યવસ્થા દ્વારા કાર્ય; ડાબી તરફનું સંકોચન = વ્યવસ્થા પર કાર્ય.
સમદાબી પ્રક્રિયામાં કાર્ય = સમાંતરબાહુ ચતુષ્કોણનું ક્ષેત્રફળ (પ્રક્રિયા રેખા નીચેનું). સમઘનફલ પ્રક્રિયામાં કાર્ય = શૂન્ય.
📝 📌 PV-આલેખનો વલય = ચક્રીય પ્રક્રિયાનું કાર્ય — આ મૂળભૂત સિદ્ધાંત યાદ રાખો.
