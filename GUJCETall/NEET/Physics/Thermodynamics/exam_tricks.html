થર્મોડાયનેમિક્સ — GUJCET એક્ઝામ ટ્રિક્સ

🎯 પરીક્ષા ટ્રિક્સ

આયસોકોરિક પ્રક્રિયામાં કાર્ય શૂન્ય: V = અચળ → W = 0, તેથી ΔU = Q. જવાબમાં Q અને ΔU સમાન હોય તો આ પ્રક્રિયા ઓળખો.
જ્યારે પ્રશ્નમાં કહેવાય કે 'કદ અચળ રહે' અથવા PV આલેખમાં ક્ષિતિજ સરળ રેખા દેખાય.
દા.ત.: એક મોલ આદર્શ ગેસનું કદ અચળ રાખી 100 J ઉષ્મા આપે. ΔU = ? → 100 J (કારણ W = 0).
આઈસોથર્મલ પ્રક્રિયામાં ΔU = 0 (આદર્શ ગેસ). તેથી Q = W. જવાબમાં Q અને W સમાન મૂલ્યના હોય તો આ પ્રક્રિયા ઓળખો.
તાપમાન અચળ હોય અથવા PV = અચળ શરત આપી હોય.
દા.ત.: 300 K પર 2 મોલ ગેસનું કદ દ્વિગુણિત કરે. Q = W = nRT ln(V₂/V₁) = 2 × 8.314 × 300 × ln2 ≈ 3456 J.
એડિયાબેટિક પ્રક્રિયામાં Q = 0, તેથી ΔU = −W. જો ગેસ વિસ્તરણ કરે (W > 0) તો ΔU ઋણ → તાપમાન ઘટે. સંકોચનમાં તાપમાન વધે.
ઉષ્મા આદાન-પ્રદાન ન હોય તેવી પ્રક્રિયા, અથવા PV^γ = અચળ આપેલ હોય.
દા.ત.: એડિયાબેટિક વિસ્તરણમાં ગેસનું કદ વધે → તાપમાન ઘટે. તેથી T₂ < T₁.
γ = Cp/Cv ની કિંમત યાદ રાખો: એકપરમાણ્વિક = 5/3 ≈ 1.67, દ્વિપરમાણ્વિક = 7/5 = 1.4, બહુપરમાણ્વિક = 4/3 ≈ 1.33. PV^γ = અચળ સમીકરણમાં આ γ નો ઉપયોગ થાય.
એડિયાબેટિક પ્રક્રિયાના પ્રશ્નો અથવા Cp − Cv = R સંબંધવાળા પ્રશ્નો.
દા.ત.: હિલિયમ (એકપરમાણ્વિક) માટે γ = 5/3. જો Cv = 3R/2 હોય તો Cp = 5R/2.
Cp − Cv = R (આદર્શ ગેસ માટે). આ સૂત્ર યાદ રાખો: Cp હંમેશા Cv કરતા R જેટલું મોટું હોય. વિકલ્પોમાં Cp < Cv હોય તો તરત અપવાદ ગણો.
વિશિષ્ટ ઉષ્મા ધારિતાઓ સંબંધી કોઈ પણ પ્રશ્ન.
દા.ત.: જો Cv = 20.8 J/(mol·K) હોય, તો Cp = 20.8 + 8.314 ≈ 29.1 J/(mol·K).
કાર્નોટ એન્જિનની કાર્યક્ષમતા η = 1 − T_c/T_h (તાપમાન કેલ્વિનમાં). T_c અને T_h ને સીધા ડિગ્રી સેલ્સિયસમાં મૂકશો તો ભૂલ થશે — પહેલા K માં ફેરવો.
કાર્નોટ એન્જિન અથવા મહત્તમ કાર્યક્ષમતાનો પ્રશ્ન.
દા.ત.: T_h = 500 K, T_c = 300 K → η = 1 − 300/500 = 0.40 = 40%.
PV આલેખમાં વક્રની ઢાળ: એડિયાબેટિક વક્ર આઈસોથર્મલ વક્ર કરતા વધુ ઢળવો (steeper) હોય છે, કારણ કે γ > 1. આલેખથી પ્રક્રિયા ઓળખવા માટે આ ટ્રિક ઉપયોગી.
PV આલેખમાં બે વક્રો આપેલા હોય અને કઈ પ્રક્રિયા કઈ છે તે પૂછે.
દા.ત.: બે વક્રો A અને B: A વધુ ઢળવો → એડિયાબેટિક; B ઓછો ઢળવો → આઈસોથર્મલ.
ચક્રીય પ્રક્રિયામાં ΔU = 0 (કારણ U અવસ્થા ફલન છે). તેથી Q_net = W_net. PV ચક્રનો ક્ષેત્રફળ = શુદ્ધ કાર્ય. આલેખમાં ઘડિયાળદિશા = એન્જિન, વિરુદ્ધ દિશા = રિફ્રિજરેટર.
ચક્રીય પ્રક્રિયા અથવા PV ચક્ર સંબંધી પ્રશ્ન.
દા.ત.: PV ચક્રનો ક્ષેત્રફળ 50 J → ચક્ર દરમિયાન શુદ્ધ કાર્ય 50 J, ΔU = 0.
ઉષ્મા ઇજનની કાર્યક્ષમતા η = W/Q_h = 1 − Q_c/Q_h. જો Q_c > Q_h હોય તો તે અશક્ય (થર્મોડાયનેમિક્સના પ્રથમ નિયમનો ભંગ). આ ટ્રિકથી ખોટો વિકલ્પ તરત બાદ કરી શકાય.
ઉષ્મા ઇજનની કાર્યક્ષમતા અથવા Q_c, Q_h સંબંધી પ્રશ્ન.
દા.ત.: Q_h = 200 J, Q_c = 150 J → η = 1 − 150/200 = 0.25 = 25%. W = 50 J.
બીજો નિયમ: એન્ટ્રોપી વૃદ્ધિનો નિયમ — વિશ્વની કુલ એન્ટ્રોપી ક્યારેય ઘટતી નથી. પ્રતિવર્તી પ્રક્રિયામાં ΔS_universe = 0, અપ્રતિવર્તીમાં ΔS_universe > 0. આ ટ્રિકથી 'એન્ટ્રોપી ઘટે' વિકલ્પ તરત બાદ.
એન્ટ્રોપી અથવા બીજા નિયમ સંબંધી પ્રશ્ન.
દા.ત.: સ્વયંભૂ પ્રક્રિયામાં એન્ટ્રોપી વધે → ΔS > 0. સંતુલનમાં ΔS = 0.
આઈસોબારિક પ્રક્રિયામાં W = PΔV. PV આલેખમાં ક્ષિતિજ સરળ રેખા નીચેનો આયતકારનો ક્ષેત્રફળ = કાર્ય. આલેખથી સીધું કાર્ય શોધી શકાય.
દબાણ અચળ હોય અથવા PV આલેખમાં આઈસોબારિક રેખા હોય.
દા.ત.: P = 10⁵ Pa, ΔV = 2 × 10⁻³ m³ → W = 10⁵ × 2 × 10⁻³ = 200 J.
ગેસના અણુની સરેરાશ ગતિજ ઊર્જા: KE = (f/2)kT, જ્યાં f = સ્વાતંત્ર્યની માત્રા. એકપરમાણ્વિક f=3, દ્વિપરમાણ્વિક f=5. તાપમાન દ્વિગુણિત કરો તો KE પણ દ્વિગુણિત.
અણુઓની ગતિજ ઊર્જા અથવા તાપમાન-ઊર્જા સંબંધી પ્રશ્ન.
દા.ત.: દ્વિપરમાણ્વિક ગેસ, T = 300 K → KE = (5/2)kT = (5/2) × 1.38 × 10⁻²³ × 300 ≈ 1.035 × 10⁻²⁰ J.
થર્મોડાયનેમિક્સનો પ્રથમ નિયમ: ΔU = Q − W (ચિહ્ન સંમતિ: Q ધન = ઉષ્મા પ્રાપ્ત, W ધન = ગેસ દ્વારા થયેલ કાર્ય). જો પ્રશ્ન ΔU = Q + W સ્વરૂપમાં હોય તો W ની વ્યાખ્યા વિપરીત છે — સાવચેત રહો.
કોઈ પણ પ્રથમ નિયમનો પ્રશ્ન. ચિહ્ન સંમતિ ગેરસમજથી ભૂલ થાય છે.
દા.ત.: ગેસે 80 J ઉષ્મા લીધી અને 30 J કાર્ય કર્યું → ΔU = 80 − 30 = 50 J.
રિફ્રિજરેટરનો COP = Q_c/W = T_c/(T_h − T_c). COP > 1 હોય છે. જો કોઈ વિકલ્પમાં COP = 0 અથવા COP < 0 હોય તો તે ખોટો છે (જ્યાં સુધી T_c = 0 ન હોય).
રિફ્રિજરેટર અથવા COP સંબંધી પ્રશ્ન.
દા.ત.: T_c = 270 K, T_h = 300 K → COP = 270/(300−270) = 9.
માક્સવેલ-બોલ્ટઝમેન વેગ વિતરણ: સૌથી સંભાવ્ય વેગ v_mp = √(2RT/M). જો પ્રશ્નમાં 'સરેરાશ વેગ' અને 'વર્ગમાધ્ય વેગ' પૂછે તો: v_rms > v_avg > v_mp. આ ક્રમ યાદ રાખો.
અણુઓના વેગ સંબંધી પ્રશ્ન.
દા.ત.: O₂ ગેસ માટે 300 K પર: v_mp < v_avg < v_rms. v_rms = √(3RT/M) સૌથી મોટું.
