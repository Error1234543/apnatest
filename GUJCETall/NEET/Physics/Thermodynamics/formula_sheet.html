ઉષ્માગતિ વિજ્ઞાન (Thermodynamics) — સૂત્ર પત્રક

🧪 GUJCET — Gujarati • Physics • Thermodynamics

⚡ સૂત્રો

બીજું નિયમ પ્રમાણે આંતરિક ઊર્જા ફેરફાર: ΔU = q + w
ΔU = આંતરિક ઊર્જામાં ફેરફાર, q = ગરમી (પ્રણાલીએ મેળવે), w = કાર્ય (પ્રણાલી પર થતું) · SI: જૂલ (J) · કોઈપણ ઉષ્માગતીય પ્રક્રિયા માટે
સ્થિર દબાણે થતું કાર્ય: w = –Pex × ΔV
w = થયેલું કાર્ય, Pex = બાહ્ય દબાણ, ΔV = કદમાં ફેરફાર · SI: જૂલ (J) · અચળ બાહ્ય દબાણે થતી પ્રક્રિયા
ઇસોથર્મલ રિવર્સિબલ વિસ્તરણ કાર્ય (આદર્શ વાયુ): w = –nRT ln(V2/V1) અથવા w = –2.303 nRT log₁₀(V2/V1)
n = મોલ સંખ્યા, R = ગેસ અચળાંક, T = તાપમાન, V₁ અને V₂ = પ્રારંભિક અને અંતિમ કદ · SI: જૂલ (J) · આદર્શ વાયુનું અચળ તાપમાને રિવર્સિબલ વિસ્તરણ/સંકોચન
આદર્શ વાયુનું આંતરિક ઊર્જા ફેરફાર: ΔU = nCvΔT
nCv = મોલર કદ ઉષ્માધારિતા × મોલ સંખ્યા, ΔT = તાપમાન ફેરફાર · SI: જૂલ (J) · આદર્શ વાયુની સક્રિય પ્રક્રિયા
એન્થાල්પીમાં ફેરફાર: ΔH = ΔU + PΔV અથવા ΔH = qP (અચળ દબાણે)
ΔH = એન્થાल्પી ફેરફાર, ΔU = આંતરિક ઊર્જા ફેરફાર, PΔV = દબાણ × કદ ફેરફાર · SI: જૂલ (J) · અચળ દબાણે થતી પ્રક્રિયા
ગેસ વાયુઓ માટે ΔH અને ΔU વચ્ચેનો સંબંધ: ΔH = ΔU + Δn(g)RT
Δn(g) = ઉત્પાદનોના વાયુ મોલ – પ્રતિક્રિયકોના વાયુ મોલ, R = ગેસ અચળાંક, T = તાપમાન · SI: જૂલ (J) · રાસાયણિક પ્રક્રિયા જેમાં વાયુ મોલમાં ફેરફાર થાય
આદર્શ વાયુ માટે Cp અને Cv વચ્ચેનો સંબંધ: Cp – Cv = R
Cp = અચળ દબાણે મોલર ઉષ્માધારિતા, Cv = અચળ કદે મોલર ઉષ્માધારિતા, R = ગેસ અચળાંક · SI: J mol⁻¹ K⁻¹ · આદર્શ વાયુ
ઉષ્માધારિતા ગુણોત્તર (ગેમનું સૂત્ર): γ = Cp/Cv
γ = એડિઅબેટિક સૂચક (ગેમનો ગુણોત્તર), Cp અને Cv = મોલર ઉષ્માધારિતા · SI: એકમ રહિત · આદર્શ વાયુ
એડિઅબેટિક પ્રક્રિયા સમયે દબાણ-કદ સંબંધ: PV^γ = અચળ અથવા P₁V₁^γ = P₂V₂^γ
P = દબાણ, V = કદ, γ = એડિઅબેટિક સૂચક · SI: Pa, m³ · એડિઅબેટિક રિવર્સિબલ પ્રક્રિયા
એડિઅબેટિક પ્રક્રિયા સમયે તાપમાન-કદ સંબંધ: TV^(γ–1) = અચળ અથવા T₁V₁^(γ–1) = T₂V₂^(γ–1)
T = તાપમાન, V = કદ, γ = એડિઅબેટિક સૂચક · SI: K, m³ · એડિઅબેટિક રિવર્સિબલ પ્રક્રિયા
એડિઅબેટિક પ્રક્રિયા સમયે દબાણ-તાપમાન સંબંધ: P^(1–γ)T^γ = અચળ અથવા P₁^(1–γ)T₁^γ = P₂^(1–γ)T₂^γ
P = દબાણ, T = તાપમાન, γ = એડિઅબેટિક સૂચક · SI: Pa, K · એડિઅબેટિક રિવર્સિબલ પ્રક્રિયા
એડિઅબેટિક રિવર્સિબલ વિસ્તરણ કાર્ય: w = –Cv(T₂ – T₁)
Cv = અચળ કદે મોલર ઉષ્માધારિતા, T₁ = પ્રારંભિક તાપમાન, T₂ = અંતિમ તાપમાન · SI: જૂલ (J) · એડિઅબેટિક રિવર્સિબલ પ્રક્રિયા, q = 0
આદર્શ વાયુના આઈસોથર્મલ વિસ્તરણમાં કાર્ય (કન્સ્ટન્ટ એક્સ્ટર્નલ પ્રેશર): w = –Pex × V₁ × (1 – P₂/P₁)
Pex = બાહ્ય દબાણ, V₁ = પ્રારંભિક કદ, P₁ અને P₂ = પ્રારંભિક અને અંતિમ દબાણ · SI: જૂલ (J) · આઈસોથર્મલ અરિવર્સિબલ વિસ્તરણ
હેસના નિયમ પ્રમાણે પ્રતિક્રિયા એન્થાल्पી: ΔrH = ΣΔfH(ઉત્પાદનો) – ΣΔfH(પ્રતિક્રિયકો)
ΔfH = પ્રમાણિત બન્ધન એન્થાल्пી, ઉત્પાદનો અને પ્રતિક્રિયકોના સ્ટોઇકિયોમેટ્રિક ગુણાંક સાથે · SI: kJ mol⁻¹ · સામાન્ય ઉષ્મારાસાયણિક ગણતરી
બન્ધન એન્થાಲ್પી દ્વારા પ્રતિક્રિયા એન્થાल्пી: ΔrH = Σબન્ધ તોડવાની એન્થાल्пી – Σબન્ધ બનવાની એન્થાल्пી
બન્ધ તોડવાની એન્થાल्пી = પ્રતિક્રિયકોમાં તૂટતા બન્ધ, બન્ધ બનવાની એન્થાल्пી = ઉત્પાદનોમાં બનતા બન્ધ · SI: kJ mol⁻¹ · ગેસીય પ્રતિક્રિયા
કિર્ચોફનું સૂત્ર: ΔrH(T₂) = ΔrH(T₁) + ΔrCp × (T₂ – T₁)
ΔrCp = ઉત્પાદનોની Cp – પ્રતિક્રિયકોની Cp, T₁ અને T₂ = તાપમાન · SI: kJ mol⁻¹ · તાપમાન ફેરફાર સમયે પ્રતિક્રિયા એન્થાल्пી ગણતરી
એન્ટ્રોપી ફેરફાર – આદર્શ વાયુ (કદ અને તાપમાન બંને બદલાય): ΔS = nCv ln(T₂/T₁) + nR ln(V₂/V₁)
nCv = મોલર ઉષ્માધારિતા × મોલ, R = ગેસ અચળાંક, T = તાપમાન, V = કદ · SI: J K⁻¹ · આદર્શ વાયુની અકેસર પ્રક્રિયા
એન્ટ્રોપી ફેરફાર – આદર્શ વાયુ (દબાણ અને તાપમાન બંને બદલાય): ΔS = nCp ln(T₂/T₁) – nR ln(P₂/P₁)
nCp = મોલર ઉષ્માધારિતા × મોલ, R = ગેસ અચળાંક, T = તાપમાન, P = દબાણ · SI: J K⁻¹ · આદર્શ વાયુ
પ્રતિવર્તી આઈસોથર્મલ પ્રક્રિયામાં એન્ટ્રોપી ફેરફાર: ΔS = qrev / T
qrev = પ્રતિવર્તી પ્રક્રિયામાં શોષાયેલી/મુક્ત થતી ગરમી, T = તાપમાન · SI: J K⁻¹ · પ્રતિવર્તી આઈસોથર્મલ પ્રક્રિયા
આવીશન/વાष्पीकरण એન્ટ્રોપી: ΔvapS = ΔvapH / Tb
ΔvapH = વාष्पीकरण એન્થાल्пી, Tb = ઉત્કલન બિંદુ (K માં) · SI: J K⁻¹ mol⁻¹ · આવીશન / વાष्पीकरण પ્રક્રિયા
ગિબ્સ મુક્ત ઊર્જા ફેરફાર: ΔG = ΔH – TΔS
ΔG = ગિબ્સ મુક્ત ઊર્જા ફેરફાર, ΔH = એન્થાल्пી ફેરફાર, T = તાપમાન, ΔS = એન્ટ્રોપી ફેરફાર · SI: J mol⁻¹ · અચળ તાપમાન અને દબાણ
ગિબ્સ મુક્ત ઊર્જા અને સંતુલન અચળાંક: ΔG° = –RT ln Keq અથવા ΔG° = –2.303 RT log₁₀ Keq
R = ગેસ અચળાંક, T = તાપમાન, Keq = સંતુલન અચળાંક · SI: J mol⁻¹ · માનક અવસ્થા, રાસાયણિક સંતુલન
ગિબ્સ-હેલ્મહોલ્ટ્ઝ સમીકરણ (તાપમાન પર ΔG નો ફેરફાર): ΔG(T₂) = ΔH – T₂ΔS (અંદાજિત, જ્યારે ΔH અને ΔS સ્થિર હોય)
ΔG = ગિબ્સ મુક્ત ઊર્જા, ΔH = એન્થાल्пી, ΔS = એન્ટ્રોપી, T = તાપમાન · SI: J mol⁻¹ · તાપમાન બદલાય ત્યારે પ્રતિક્રિયાની સ્વયંભૂતા ચકાસણી
પ્રક્રિયાની સ્વયંભૂતા શરત: ΔG < 0 → સ્વયંભૂ પ્રક્રિયા; ΔG > 0 → અસ્વયંભૂ પ્રક્રિયા; ΔG = 0 → સંતુલન
ΔG = ગિબ્સ મુક્ત ઊર્જા ફેરફાર · SI: J mol⁻¹ · અચળ તાપમાન અને દબાણ
આઈસોથર્મલ પ્રક્રિયા (T અચળ): ΔU = 0, ΔH = 0, q = –w
ΔU = આંતરિક ઊર્જા ફેરફાર, ΔH = એન્થાल्पी ફેરફાર, q = ગરમી, w = કાર્ય · SI: — · આદર્શ વાયુનું આઈસોથર્મલ વિસ્તરણ/સંકોચન
આઈસોકોરિક પ્રક્રિયા (V અચળ): w = 0, ΔU = qv
w = કાર્ય, ΔU = આંતરિક ઊર્જા ફેરફાર, qv = અચળ કદે ગરમી · SI: J · અચળ કદે પ્રક્રિયા
આઈસોબેરિક પ્રક્રિયા (P અચળ): qP = ΔH
qP = અચળ દબાણે ગરમી, ΔH = એન્થાल्пી ફેરફાર · SI: J · અચળ દબાણે પ્રક્રિયા
એડિઅબેટિક પ્રક્રિયા (q = 0): ΔU = w, q = 0
ΔU = આંતરિક ઊર્જા ફેરફાર, w = કાર્ય, q = ગરમી · SI: J · એડિઅબેટિક પ્રક્રિયા, ગરમીનો આદાનપ્રદાન નથી
ચક્રીય પ્રક્રિયા (Cyclic Process): ΔU = 0, ΔH = 0, qnet = –wnet
ΔU = આંતરિક ઊર્જા ફેરફાર, qnet = શુદ્ધ ગરમી, wnet = શુદ્ધ કાર્ય · SI: — · પ્રણાલી તેની પ્રારંભિક અવસ્થાએ પાછી ફરે
ઉષ્માઇન્જિન કાર્યક્ષમતા: η = W / q₁ = 1 – (q₂/q₁) = 1 – (T₂/T₁)
η = કાર્યક્ષમતા, W = ઉત્પાદિત કાર્ય, q₁ = ઉષ્માસ્ત્રોતમાંથી મળતી ગરમી, q₂ = ઉષ્માગ્રાહીમાં જતી ગરમી, T₁ અને T₂ = અનુક્રમે ઉષ્માસ્ત્રોત અને ઉષ્માગ્રાહીનું તાપમાન · SI: એકમ રહિત · કાર્નોટ ઉષ્માઇન્જિન (આદર્શ)

🔗 સંબંધો

  • ΔG = ΔH – TΔS પરથી: જો ΔH ઋણ અને ΔS ધન હોય તો ΔG હંમેશા ઋણ → પ્રક્રિયા સર્વત્ર સ્વયંભૂ
  • આદર્શ વાયુ માટે: Cp = Cv + R અને γ = Cp/Cv → Cp = γR/(γ–1) અને Cv = R/(γ–1)
  • એડિઅબેટિક પ્રક્રિયામાં: PV^γ = અચળ અને TV^(γ–1) = અચળ એકસાથે લાગુ પડે છે
  • ΔG° = –RT ln Keq પરથી: Keq = e^(–ΔG°/RT) — જો ΔG° ઋણ હોય તો Keq > 1, ઉત્પાદનોનું પ્રમાણ વધુ
  • આઈસોથર્મલ પ્રક્રિયામાં: દબાણ અને કદ વ્યસ્ત પ્રમાણમાં (PV = અચળ)
  • એડિઅબેટિક વિસ્તરણમાં વાયુનું તાપમાન ઘટે છે કારણ કે પ્રણાલી પોતાની આંતરિક ઊર્જા વપરાવે છે
  • ગિબ્સ મુક્ત ઊર્જા ગેલેવાનિક કોષમાં: ΔG = –nFE (n = ইলেক্ট્રોન મોલ, F = ફેરાડે અચળાંક, E = કોષ વિભવ)
  • તાપમાન વધારવાથી એન્ટ્રોપી વધે છે કારણ કે અણુઓની યાદૈચ્છિક ગતિ વધે છે
