વિદ્યુત પ્રવાહ — સૂત્ર તાલિકા (Current Electricity)

🧪 GUJCET — Gujarati • Physics • Current Electricity

⚡ સૂત્રો

વિદ્યુત પ્રવાહ: I = Q / t
I = વિદ્યુત પ્રવાહ, Q = વિદ્યુતભાર, t = સમય · SI: એમ્પિયર (A) · જ્યારે વિદ્યુતભાર Q, સમય t દરમિયાન ક્રોસ કરે
વિદ્યુતપ્રવાહની ઘનતા: J = I / A
J = પ્રવાહઘનતા, I = પ્રવાહ, A = આડછેદનું ક્ષેત્રફળ · SI: A/m² · સમાન પ્રવાહઘનતા માટે એકસમાન તારમાં
ઊર્જા / ઊષ્મા ઉત્પન્ન (જૂલનું તાપ): H = I² R t
H = ઉત્પન્ન થતી ઊષ્મા, I = પ્રવાહ, R = અવરોધ, t = સમય · SI: જૂલ (J) · જ્યારે પ્રવાહ અવરોધકમાંથી પસાર થાય
વિદ્યુતશક્તિ (Power): P = V I = I² R = V² / R
P = શક્તિ, V = વિભવાંતર, I = પ્રવાહ, R = અવરોધ · SI: વોટ (W) · ઓહ્મીય અવરોધકમાં
વિદ્યુત energie / ખર્ચાયેલી ઊર્જા: E = V I t = I² R t = V² t / R
E = ઊર્જા, V = વિભવાંતર, I = પ્રવાહ, R = અવરોધ, t = સમય · SI: જૂલ (J) · અવરોધકમાં વિદ્યુત ઊર્જાના રૂપાંતર માટે
ઓહ્મનો નિયમ: V = I R
V = વિભવાંતર, I = પ્રવાહ, R = અવરોધ · SI: ઓહ્મ (Ω) · તાપમાન અને ભૌતિક સ્થિતિ અચળ રહે ત્યારે; ઓહ્મીય અવરોધકો માટે
અવરોધ (રોધ): R = ρ l / A
R = અવરોધ, ρ = વિશિષ્ટ અવરોધકતા (Resistivity), l = લંબાઈ, A = આડછેદનું ક્ષેત્રફળ · SI: ઓહ્મ (Ω) · એકસમાન આડછેદ ધરાવતા તાર માટે
વિશિષ્ટ અવરોધકતા: ρ = R A / l
ρ = વિશિષ્ટ અવરોધકતા, R = અવરોધ, A = આડછેદનું ક્ષેત્રફળ, l = લંબાઈ · SI: Ω·m · પદાર્થના ગુણધર્મ તરીકે
પરોહ (Conductance): G = 1 / R
G = પરોહ, R = અવરોધ · SI: સિમેન્સ (S) · સર્વત્ર
વિદ્યુતચાલક બળ (emf): ε = W / Q
ε = emf, W = પ્રયાસ ( lavoro ), Q = વિદ્યુતભાર · SI: વોલ્ટ (V) · કોષમાં રાસાયણિક ઉર્જાનું વિદ્યુત ઊર્જામાં રૂપાંતર
આંતરિક અવરોધ સાથે emf અને વિભવાંતર: V = ε − I r
V = ટર્મિનલ વિભવાંતર, ε = emf, I = પ્રવાહ, r = આંતરિક અવરોધ · SI: વોલ્ટ (V) · કોષને બાહ્ય લોડ સાથે જોડેલો હોય ત્યારે પ્રવાહ વહેતો હોય
કોષમાં પ્રવાહ: I = ε / (R + r)
I = પ્રવાહ, ε = emf, R = બાહ્ય અવરોધ, r = આંતરિક અવરોધ · SI: એમ્પિયર (A) · એકમાત્ર બાહ્ય અવરોધ R ધરાવતા સર્કિટમાં
શ્રેણી જોડાણમાં કુલ અવરોધ: R_eq = R₁ + R₂ + R₃ + ...
R_eq = સમકક્ષ અવરોધ, R₁, R₂, R₃ = અલગ-અલગ અવરોધો · SI: ઓહ્મ (Ω) · બધા અવરોધોમાંથી એકસરખો પ્રવાહ પસાર થાય
સમાંતર જોડાણમાં કુલ અવરોધ: 1 / R_eq = 1 / R₁ + 1 / R₂ + 1 / R₃ + ...
R_eq = સમકક્ષ અવરોધ, R₁, R₂, R₃ = અલગ-અલગ અવરોધો · SI: ઓહ્મ (Ω) · બધા અવરોધો પર સમાન વિભવાંતર હોય
બે અવરોધોના સમાંતર જોડાણનો સરળ સૂત્ર: R_eq = (R₁ × R₂) / (R₁ + R₂)
R_eq = સમકક્ષ અવરોધ, R₁ અને R₂ = બે અવરોધો · SI: ઓહ્મ (Ω) · કેવળ બે અવરોધો સમાંતરમાં જોડેલા હોય
શ્રેણીમાં વિભવ વિભાજન: V₁ = V × R₁ / (R₁ + R₂)
V₁ = R₁ પરનું વિભવાંતર, V = કુલ વિભવાંતર, R₁, R₂ = શ્રેણીમાં જોડેલા અવરોધો · SI: વોલ્ટ (V) · શ્રેણી જોડાણમાં R₁ પરનું વિભવાંતર શોધવા માટે
સમાંતરમાં પ્રવાહ વિભાજન: I₁ = I × R₂ / (R₁ + R₂)
I₁ = R₁ માંથી વહેતો પ્રવાહ, I = કુલ પ્રવાહ, R₁, R₂ = સમાંતર જોડેલા અવરોધો · SI: એમ્પિયર (A) · સમાંતર જોડાણમાં R₁ માંથી વહેતો પ્રવાહ શોધવા માટે
વ્હીટસ્ટોન બ્રિજની સંતુલન સ્થિતિ: P / Q = R / S અથવા P S = Q R
P, Q, R, S = ચાર બાહુઓના અવરોધો, G = ગેલ્વેનોમીટર · SI: - · ગેલ્વેનોમીટરમાં પ્રવાહ શૂન્ય હોય (સંતુલન)
મીટર બ્રિજ — અજ્ઞાત અવરોધ: X = R × l₂ / l₁ અથવા X = R × (100 − l) / l
X = અજ્ઞાત અવરોધ, R = જાણીતો અવરોધ, l₁ = l, l₂ = 100−l, l = સંતુલન બિંદુનું અંતર · SI: ઓહ્મ (Ω) · મીટર બ્રિજ તારની લંબાઈ 100 cm હોય
પોટેન્શિયોમીટર — emf ની સરખામણી: ε₁ / ε₂ = l₁ / l₂
ε₁, ε₂ = બે કોષોનું emf, l₁, l₂ = અનુરૂપ સંતુલન લંબાઈઓ · SI: - · સમાન પ્રવાહ ધરાવતી પ્રાથમિક સર્કિટમાં
પોટેન્શિયોમીટર — અજ્ઞાત emf: ε_x = ε_standard × (l_x / l_s)
ε_x = અજ્ઞાત emf, ε_standard = જાણીતું emf, l_x, l_s = અનુરૂપ સંતુલન લંબાઈ · SI: વોલ્ટ (V) · પોટેન્શિયોમીટરના સંતુલન બિંદુથી
પોટેન્શિયોમીટર — આંતરિક અવરોધ: r = R × (l₁ / l₂ − 1)
r = આંતરિક અવરોધ, R = બાહ્ય અવરોધ, l₁ = ખુલ્લા સર્કિટની સંતુલન લંબાઈ, l₂ = બંધ સર્કિટની સંતુલન લંબાઈ · SI: ઓહ્મ (Ω) · કોષનો આંતરિક અવરોધ માપવા માટે
તાપમાન સાથે અવરોધ: R_t = R₀ (1 + α ΔT) અથવા R_t = R₀ (1 + α (T − T₀))
R_t = T તાપમાને અવરોધ, R₀ = T₀ તાપમાને અવરોધ, α = તાપમાન ગુણાંક, ΔT = તાપમાન ફેરફાર · SI: Ω / °C (α નો એકમ) · ધાતુઓ માટે, મધ્યમ તાપમાન શ્રેણીમાં
તાપમાન ગુણાંક ( α ): α = (R_t − R₀) / (R₀ × ΔT)
α = અવરોધ તાપમાન ગુણાંક, R_t, R₀ = અનુરૂપ અવરોધો, ΔT = તાપમાન ફેરફાર · SI: °C⁻¹ · રેખીય અંદાજ માટે
કિરચોફનો પ્રથમ નિયમ (Junction rule): Σ I_in = Σ I_out અથવા Σ I = 0
I = ગુચ્છ (જંકશન) પાસે આવતા/જતા પ્રવાહો · SI: એમ્પિયર (A) · વિદ્યુતભારના સંરક્ષણના સિદ્ધાંત પર આધારિત
કિરચોફનો દ્વિતીય નિયમ (Loop rule): Σ V = 0 અથવા Σ ε = Σ I R (કોઈ પણ બંધ લૂપ માટે)
ε = emf, I = પ્રવાહ, R = અવરોધ · SI: વોલ્ટ (V) · ઊર્જાના સંરક્ષણના સિદ્ધાંત પર આધારિત
ડ્રિફ્ટ વેગ (વિસ્થાન વેગ): v_d = I / (n e A)
v_d = ડ્રિફ્ટ વેગ, I = પ્રવાહ, n = મુક્ત ઇલેક્ટ્રોનઘનતા, e = ઇલેક્ટ્રોન પર વિદ્યુતભાર, A = આડછેદનું ક્ષેત્રફળ · SI: m/s · ધાતુઓમાં મુક્ત ઇલેક્ટ્રોન માટે
ડ્રિફ્ટ વેગ — બળ-વેગ સંબંધ: v_d = e E τ / m અથવા v_d = e V τ / (m L)
v_d = ડ્રિફ્ટ વેગ, e = ઇલેક્ટ્રોન વિદ્યુતભાર, E = વિદ્યુતક્ષેત્ર, τ = મુક્ત સમય (relaxation time), m = ઇલેક્ટ્રોન દળ, V = વિભવાંતર, L = તારની લંબાઈ · SI: m/s · કلاसिक Drude મોડેલ અંતર્ગત
વિશિષ્ટ અવરોધકતા — Drude મોડેલ: ρ = m / (n e² τ)
ρ = વિશિષ્ટ અવરોધકતા, m = ઇલેક્ટ્રોન દળ, n = મુક્ત ઇલેક્ટ્રોનઘનતા, e = ઇલેક્ટ્રોન વિદ્યુતભાર, τ = મુક્ત સમય · SI: Ω·m · ધાતુઓ માટે Drude મોડેલ અંતર્ગત
વિશિષ્ટ વાહકતા (Conductivity): σ = 1 / ρ = n e² τ / m
σ = વિશિષ્ટ વાહકતા, ρ = વિશિષ્ટ અવરોધકતા, n = મુક્ત ઇલેક્ટ્રોનઘનતા, e = ઇલેક્ટ્રોન વિદ્યુતભાર, τ = મુક્ત સમય, m = ઇલેક્ટ્રોન દળ · SI: S/m · ધાતુઓ માટે
રેઝિસ્ટરોનો શ્રેણી-સમાંતર મિશ્ર જોડાણ: પ્રથમ શ્રેણી ગણો, પછી સમાંતર ગણો
દરેક બ્લોકને સરળ રીતે સમકક્ષ કરો અને એકમૂળ કરો · SI: ઓહ્મ (Ω) · મિશ્ર સર્કિટ માટે
કોષોનો શ્રેણી જોડાણ (સહાયક): ε_eq = ε₁ + ε₂ + ε₃ + ..., r_eq = r₁ + r₂ + r₃ + ...
ε_eq = સમકક્ષ emf, ε₁, ε₂, ... = વ્યક્તિગત emf, r_eq = સમકક્ષ આંતરિક અવરોધ, r₁, r₂, ... = વ્યક્તિગત આંતરિક અવરોધો · SI: વોલ્ટ (V), Ω · ધન ટર્મિનલ → ઋણ ટર્મિનલ પ્રમાણે જોડણી
કોષોનો સમાંતર જોડાણ (સમાન emf): ε_eq = ε, r_eq = r / n (n સમાન કોષો)
ε_eq = સમકક્ષ emf, ε = દરેક કોષનું emf, r_eq = સમકક્ષ આંતરિક અવરોધ, r = દરેક કોષનો આંતરિક અવરોધ, n = કોષોની સંખ્યા · SI: વોલ્ટ (V), Ω · સમાન emf ધરાવતા n કોષો સમાંતરમાં

🔗 સંબંધો

  • પ્રવાહનું આયતન ઘનતા J = n e v_d છે, જ્યાં n મુક્ત ઇલેક્ટ્રોનઘનતા છે અને v_d ડ્રિફ્ટ વેગ છે — આ સૂત્ર I = n e A v_d સાથે સંબંધિત છે.
  • ઓહ્મનો નિયમ V = I R એ રેખીય I-V લાક્ષણિકતા દર્શાવે છે; રેખાનો ઢાળ અવરોધ R છે.
  • આંતરિક અવરોધ r હંમેશા emf ε અને ટર્મિનલ વિભવ V વચ્ચેનો તફાવત સર્જે છે: V = ε − Ir.
  • વ્હીટસ્ટોન બ્રિજ સંતુલન પર P/Q = R/S થાય છે, જે મીટર બ્રિજના સૂત્ર X = R(100−l)/l માં પરિણમે છે.
  • પોટેન્શિયોમીટરમાં સંતુલન લંબાઈ l એ સંબંધિત emf/V સાથે સમપ્રમાણ છે: V ∝ l.
  • તાપમાન વધતાં ધાતુઓનો અવરોધ વધે છે (α > 0), જ્યારે અર્ધવાહકોનો અવરોધ ઘટે છે (α < 0).
  • શ્રેણી જોડાણમાં પ્રવાહ સમાન રહે છે, વિભવ વિભાજિત થાય છે; સમાંતર જોડાણમાં વિભવ સમાન રહે છે, પ્રવાહ વિભાજિત થાય છે.

શ્રેણીમાં અવરોધોનો સરવાળો હંમેશા સૌથી મોટા અવરોધ કરતાં વધારે હોય છે; સમાંતરમાં સમકક્ષ અવરોધ હંમેશા સૌથી નાના અવરોધ કરતાં ઓછો હોય છે.
સમાંતરમાં બે સમાન અવરોધો R હોય તો R_eq = R/2 થાય — યાદ રાખો: 'બે સમાન, અડધો થાય'.
વ્હીટસ્ટોન બ્રિજમાં ઉલટાડો: જો P/Q = R/S, તો P/R = Q/S પણ સાચું છે (cross-multiply કરો).
મીટર બ્રિજમાં સંતુલન બિંદુ l > 50 cm હોય તો અજ્ઞાત અવરોધ X > R (જાણીતો અવરોધ) થાય.
પ્રશ્નમાં જો R >> r હોય, તો V ≈ ε; જો r >> R હોય, તો V ≈ 0 — બે સીમા પ્રસંગો યાદ રાખો.
ડ્રિફ્ટ વેગનો સંકેત: v_d = I/(n e A); જો તારની ત્રિજ્યા દ્વિગણ કરો, તો A ચાર ગણો થાય → v_d ચાર ગુણો ઘટે (સ્થિર પ્રવાહ માટે).
શક્તિ P = I²R અને P = V²/R બંને સાચાં છે; તમે કયું વાપરશો તે આપેલા ચલ પર આધારિત છે — પ્રશ્નમાં I સ્પષ્ટ હોય તો P=I²R, V સ્પષ્ટ હોય તો P=V²/R.

⚠️ ભૂલો

શ્રેણી અને સમાંતર જોડાણ ગૂંચવી પડે છે — શ્રેણીમાં R સીધો સરવાળો, સમાંતરમાં વ્યસ્ત સરવાળો યાદ રાખો.
પોટેન્શિયોમીટરમાં પ્રાથમિક સર્કિટનો પ્રવાહ સ્થિર રાખવો પડે છે; જો એ રાખવાનું ભૂલવાથી l₁/l₂ નો ગુણોત્તર ખોટો આવે.
R = ρl/A માં A ને ત્રિજ્યાના વર્ગ (πr²) થી શોધવાની ભૂલ સામાન્ય છે.
ઓહ્મનો નિયમ બધા ઉપકરણો પર लागू નથી — સેમિકન્ડક્ટર, ડાયોડ, LED આदि non-ohmic ઉપકરણોમાં लागू નથી.

કિરચોફના નિયમોમાં લૂપની દિશા (clockwise/anti-clockwise) એકસરખી રાખવી જરૂરી છે; ચિહ્ન પદ્ધિતિ સમજ્યા વિના સમીકરણો ખોટાં બની શકે છે.
