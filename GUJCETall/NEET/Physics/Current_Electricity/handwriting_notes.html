વીજપ્રવાહ વિદ્યુતશાસ્ત્ર (Current Electricity)

🧪 GUJCET — Gujarati • Physics • Current Electricity

અંક ૧ – વીજપ્રવાહ અને વીજભાર
કોઈ પણ પરિપથમાં સમય સાથે ચાલતા વીજભારની દરને વીજપ્રવાહ કહે છે.
I = Q / t (એકમ : એમ્પિયર, A)
ધાતુઓમાં વીજવાહકો મુક્ત ઇલેક્ટ્રોન હોય છે; અર્ધવાહકોમાં ઇલેક્ટ્રોન અને છિદ્ર બંને.
વીજપ્રવાહ દિશા : ધન ભારની ગતિની દિશાને પ્રવાહ દિશા ગણાય છે.
📝 સામાન્ય રીતે ઇલેક્ટ્રોન પાસેથી ધન ખાતે પ્રવાહ દિશા નક્કી કરાય છે.
વોલ્ટમીટર સદા શ્રેણીમાં જોડાય છે; એમ્પિયરમીટર સદા શ્રેણીમાં.
અંક ૨ – કરંટ ઘનતા (Current Density)
J = I / A (ઇकाઈ : A m⁻²)
જો લેખચલ્પરવાહકનું ક્રોસ-સેક્શનલ ક્ષેત્રફળ બદલાય તો પ્રવાહ ઘનતા બદલાય છે.
J = n e v_d (n = ઇલેક્ટ્રોનઘનતા, v_d = ડ્રિફ્ટ વેગ)
સમાન પ્રવાહ ધરાવતા બે સિક્તા પર, વ્યાસ જેટલો ઓછો, તેટલી J વધારે.
અંક ૩ – ઓહ્મનો નિયમ
સ્થિર તાપમાને, વિદ્યુતપ્રવાહ (I) એ વોલ્ટેજ (V) ને સમપ્રમાણમાં હોય છે.
V = I R (R = અવરોધ, આંખમ : Ω)
ઓહ્મિક ઉપકરણ : પ્રતિરોધક, ટંგસ્ટન ફિલામેન્ટ બલ્બ નહીં (તે અનૉહ્મિક છે).
ઓહ્મનો નિયમ માત્ર ધાતુઓના સુવાહકો માટે જ સાચો પડે છે.
અંક ૪ – અવરોધ અને અવરોધકતા
R = ρ L / A
ρ (રો) = અવરોધકતા (Resistivity) — માદા-નિર્ભર, તાપમાન-આધારિત.
અવરોધ R એ આકાર/લંબાઈ/ક્ષેત્રફળ પર આધારિત; ρ માત્ર માદા પર.
વાહકના દળ અને ક્ષેત્રફળ સમાન રાખી લંબાઈ બમણી કરીએ તો R બમણું થાય.
📝 વાયરને ખેંચીને લંબાઈ વધારીએ તો સરેરાશ R વધે છે અને A ઘટે છે.
અંક ૫ – ડ્રિફ્ટ વેગ અને રિલેક્સેશન સમય
ઇલેક્ટ્રોન યાદચ્છિક ગતિ કરે છે; F = eE લાગતા સરેરાશ ગતિ v_d (ડ્રિફ્ટ વેગ).
v_d = e E τ / m અથવા v_d = I / (n e A)
τ = સરેરાશ મુક્ત પથ સમય (Mean free time) — ધાતુમાં ~10⁻¹⁴ s.
E વધે તો v_d વધે; પણ τ લગભગ અચળ રહે છે (તાપમાન પર આધાર).
તાપમાન ↑τ ↓ → v_d ↓ → R ↑
અંક ૬ – તાપમાન-આધારિત અવરોધ
R_T = R_0 (1 + α ΔT)
α = તાપમાન-ગુણાંક (Temperature coefficient) — ધાતુઓ માટે ધન.
અર્ધવાહકોમાં α ઋણ હોય છે ; રૂધિરમાં તાપમાન વધે તો R ઘટે છે.
ધાતુની રોધકતા રેખીય રીતે T સાથે વધે છે.
📝 ઉચ્ચ તાપમાને કણ-કણ અથડામણ વધે છે, તેથી τ ઘટે છે.
અંક ૭ – વિદ્યુત ઊર્જા અને પاور
P = V I = I² R = V² / R
એકમ : વોલ્ટ (Joule) or Watt-hour (Wh) — 1 kWh = 3.6 × 10⁶ J.
સિરીઝમાં રિઝિસ્ટરના P = I²R થાય ; તેથી જ જે R વધુ હોય તેનું P પણ વધુ.
પેરાલલમાં P = V²/R — અહીં જે R ઓછું હોય તેનું P વધુ.
અંક ૮ – પ્રતિરોધોનું સંયોજન (Series & Parallel)
Series : R_eq = R₁ + R₂ + …
Parallel : 1/R_eq = 1/R₁ + 1/R₂ + …
Series માં પ્રવાહ સમાન, વોલ્ટેજ વહેંચાય ; parallel માં વોલ્ટેજ સમાન, પ્રવાહ વહેંચાય.
સમરૂપ પ્રતિરોધોના n સમાન parallel જોડાણમાં R_eq = R/n.
📝 સિરીઝમાં અવરોધ વધે છે, parallel માં ઘટે છે.
અંક ૯ – કિર્ચોફના નિયમો
જંક્શન નિયમ (KCL) : ΣI_in = ΣI_out (વીજભાર સંરક્ષણ).
લૂપ નિયમ (KVL) : કોઈ પણ બંધ પરિપથમાં EMF નું સરવાળું = અવરોધીય પતનનું સરવાળું.
Σ V = 0 (લૂપમાં)
KVL એ ઊર્જા સંરક્ષણનો નિયમ છે.
📝 ચિન્હ રીત : KCL માં પ્રવાહ જંક્શન نحوંતર = ધન, બહાર = ઋણ.
અંક ૧૦ – વ્હીટસ્ટોન બ્રિજ (Wheatstone Bridge)
ચાર અવરોધો રાખીએ તો બ્રિજ બને ; ગેલ્વેનોમીટર વચ્ચે જોડાય.
સંતુલન : R₁/R₂ = R₃/R₄
સંતુલિત બ્રિજમાં ગેલ્વેનોમીટરમાં પ્રવાહ શૂન્ય હોય છે.
અજ્ઞાત અવરોધ શોધવા માટે વ્હીટસ્ટોન બ્રિજની સાહાય્ય લેવાય છે.
📝 ગેલ્વેનોમીટર ખૂબ જ સંવેદનશીલ પ્રવાહ માપન ઉપકરણ છે.
અંક ૧૧ – મીટર બ્રિજ (Meter Bridge)
R / S = l / (100 - l) (l cm માં)
મીટર બ્રિજ એ વ્હીટસ્ટોન બ્રિજનું સરળ રૂપ છે ; 1 m તારનો ઉપયોગ.
સંતુલન બિંદુ l મેળવી અજ્ઞાત R શોધી શકાય.
📝 તાર સરખો હોવો જોઈએ, તાપમાન અચળ રાખવું.
અંક ૧૨ – પોટેન્શિયોમીટર (Potentiometer)
પોટેન્શિયોમીટર એ ચોકસાઈથી વોલ્ટેજ માપન અને EMF સરખામણી માટેનું સાધન.
V ∝ l (સમાન પ્રવાહ હેઠળ)
શૂન્ય પ્રવાહ પર જંકશન મળે છે, તેથી માપન ચોકસાઈપૂર્વક હોય છે.
બે સેલના EMF નો ગુણોત્તર : E₁/E₂ = l₁/l₂.
📝 તાર લાંબો હોય તો sensitivity વધે ; તેથી પ્રાથમિક તાર લાંબો રાખવો.
અંક ૧૩ – સેલ (Cell), EMF અને આંતરિક અવરોધ
EMF (ε) = ખુલ્લા પરિપથમાં સેલનું વોલ્ટેજ.
V = ε – I r (r = આંતરિક અવરોધ)
સંતુલન પર V = ε ; પ્રવાહ વહે ત્યારે V < ε.
આંતરિક અવરોધ : ઇલેક્ટ્રોલાઇટ, ઇલેક્ટ્રોડ સામગ્રી પર આધાર રાખે છે.
અંક ૧૪ – સેલોનું સંયોજન
શ્રેણી જોડાણ : n સમાન સેલો → ε_eq = nε, r_eq = nr.
સમરાઈ જોડાણ : n સમાન સેલો → ε_eq = ε, r_eq = r/n.
I = n ε / (R + n r) (n સેલો શ્રેણીમાં)
સામાન્ય રીતે વધુ પ્રવાહ માટે શ્રેણી જોડાણ વપરાય છે.
📝 કમ્પાઉન્ડ જોડાણ (m સેલોની n શ્રેણી) માં : I = mnε / (mR + nr).
