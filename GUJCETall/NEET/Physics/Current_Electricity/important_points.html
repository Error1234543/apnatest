વિદ્યુત પ્રવાહ (Current Electricity)

🧪 GUJCET — Gujarati • Physics • Current Electricity

⭐ મહત્વના મુદ્દા

વિદ્યુત પ્રવાહ (I) એ વિદ્યુતભારના પ્રવાહનો દર છે: I = Q/t, એકમ એમ્પિયર (A).
GUJCET માં મૂળભૂત વ્યાખ્યાત્મક પ્રશ્નો આવે છે.
ઓહ્મનો નિયમ: V = IR, જ્યાં R અચળ તાપમાને અચળ રહે છે. આ નિયમ અનુસરતા પદાર્થો 'ઓહ્મીય' કહેવાય.
અત્યંત મહત્વપૂર્ણ; ગણતરી અને સિદ્ધાંત બંને પ્રકારના પ્રશ્નો આવે છે.
પ્રતિબાધકતા (ρ): R = ρL/A. પ્રતિબાધકતા તાપમાન પર આધારિત છે: ρ = ρ₀(1 + αΔT).
સૂત્ર આધારિત પ્રશ્નો GUJCET માં નિયમિત આવે છે.
અવરોધકતા (ρ) અને વાહકતા (σ) એ પરસ્પર વ્યસ્ત છે: σ = 1/ρ. વાહકતાનો એકમ S/m (સિમેન્સ પ્રતિ મીટર).
વ્યાખ્યાત્મક પ્રશ્નો અને એકમ સંબંધી પ્રશ્નો આવે છે.
તાપમાન ગુણાંક (α): R = R₀(1 + αT). ધાતુઓમાં α ધન, અર્ધવાહકોમાં α ઋણ હોય છે.
ધાતુ અને અર્ધવાહક વચ્ચેનો તફાવત સમજવો GUJCET માં મહત્વપૂર્ણ છે.
શ્રેણી જોડાણ: R_eq = R₁ + R₂ + R₃ + ... ; સમાન પ્રવાહ વિભાજિત થાય છે.
ગણતરી પ્રશ્નોમાં શ્રેણી અને સમાંતર જોડાણ બંને આવે છે.
સમાંતર જોડાણ: 1/R_eq = 1/R₁ + 1/R₂ + 1/R₃ + ... ; સમાન વોલ્ટેજ વિભાજિત થાય છે.
સમાંતર જોડાણનો સૂત્ર અને ગુણધર્મ GUJCET માં પુનરાવર્તિત પ્રશ્ન છે.
કિર્ચહોફના બે નિયમો: (1) જંકશન નિયમ — ΣI = 0, (2) લૂપ નિયમ — ΣV = 0.
જટિલ પરિપથોના વિશ્લેષણ માટે અત્યંત મહત્વપૂર્ણ; GUJCET માં નિયમિત પ્રશ્નો આવે છે.
વોટસ્ટોન બ્રિજ (Wheatstone Bridge): સંતુલન સ્થિતિમાં G માંથી પ્રવાહ શૂન્ય, R₁/R₂ = R₃/R₄.
અજ્ઞાત અવરોધ માપવાની પદ્ધતિ; સંતુલન શરત GUJCET માં મહત્વપૂર્ણ છે.
મીટર બ્રિજ: R/X = l/(100−l), જ્યાં l સંતુલન બિંદુની લંબાઈ (cm માં).
ગણતરી પ્રશ્નોમાં મીટર બ્રિજનો ઉપયોગ GUJCET માં આવે છે.
વિદ્યુતચુંબકીય બળ (EMF, ε): ε = W/Q. આંતરિક અવરોધ (r) સાથે: V = ε − Ir.
EMF અને સંભાવ્ય તફાવત વચ્ચેનો તફાવત સમજવો GUJCET માં મહત્વપૂર્ણ છે.
સેલોનું શ્રેણી જોડાણ: ε_eq = ε₁ + ε₂ + ... ; r_eq = r₁ + r₂ + ...
સેલ જોડાણના સૂત્રો GUJCET માં સીધા પ્રશ્નો આવે છે.
સેલોનું સમાંતર જોડાણ: ε_eq = (ε₁/r₁ + ε₂/r₂ + ...)/(1/r₁ + 1/r₂ + ...); r_eq = 1/(1/r₁ + 1/r₂ + ...)
સમાંતર જોડાણમાં EMF અને આંતરિક અવરોધની ગણતરી GUJCET માં આવે છે.
વિદ્યુત શક્તિ: P = VI = I²R = V²/R. એકમ વોટ (W).
શક્તિ અને ઉર્જા સંબંધી પ્રશ્નો GUJCET માં નિયમિત આવે છે.
જૂલનું ઉષ્મા નિયમ: H = I²Rt. વિદ્યુત ઉર્જા E = VIt = I²Rt = V²t/R.
ઉષ્મા અને ઉર્જા ગણતરી પ્રશ્નો GUJCET માં મહત્વપૂર્ણ છે.
હીટિંગ એલિમેન્ટ, ફ્યુઝ વાયર: ફ્યુઝ વાયરની ગલનબિંદુ ઓછી અને પ્રતિબાધકતા વધુ હોવી જોઈએ.
વ્યવહારુ ઉપયોગ સંબંધી પ્રશ્નો GUJCET માં આવે છે.
વોલ્ટમીટર: અનંત અવરોધ ધરાવે છે, સમાંતર જોડે છે. એમ્મીટર: શૂન્ય અવરોધ ધરાવે છે, શ્રેણી જોડે છે.
વાદ્યોના જોડાણ અને ગુણધર્મો GUJCET માં મહત્વપૂર્ણ છે.
પોટેન્શિયોમીટર: ε₁/ε₂ = l₁/l₂. આંતરિક અવરોધ r = R(l₁−l₂)/l₂.
EMF અને આંતરિક અવરોધ માપવાની પદ્ધતિ GUJCET માં મહત્વપૂર્ણ છે.
ડ્રિફ્ટ વેગ (v_d): v_d = eEτ/m = I/neA. સરેરાશ મુક્ત પથ (λ) = v_th × τ.
સૂક્ષ્મ સિદ્ધાંત સમજવા GUJCET માં મહત્વપૂર્ણ છે.
વિદ્યુત પ્રવાહ ઘનતા: J = I/A = nev_d. Ohm's law નો સદિશ સ્વરૂપ: J = σE.
ઘનતા અને ડ્રિફ્ટ વેગ વચ્ચેનો સંબંધ GUJCET માં આવે છે.
રંગ કોડ (Color Code): ચાર રંગ પટ્ટીઓ — પ્રથમ બે અંક, ત્રીજો ગુણક, ચોથી સહનશીલતા (Tolerance).
રંગ કોડ વાંચવાની કૌશલ્ય GUJCET માં ગણતરી પ્રશ્ન તરીકે આવે છે.
તાંબા (Cu) અને અલ્યુમિનિયમ (Al) ના પ્રતિબાધકતા ક્રમ: ρ_Cu < ρ_Al. તાંબું વધુ વાહક છે.
વાહકોની સરખામણી GUJCET માં વ્યાખ્યાત્મક પ્રશ્ન તરીકે આવે છે.
સુપરકન્ડક્ટિવિટી: અત્યંત નીચા તાપમાને પ્રતિબાધકતા શૂન્ય થઈ જાય છે. ક્રાંતિક તાપમાન (T_c).
સુપરકન્ડક્ટરનો મૂળભૂત ગુણધર્મ GUJCET માં મહત્વપૂર્ણ છે.
વોટર મીટર (વાટમીટર): P = VIcosφ (AC માં). ઘરેલું વિદ્યુત બિલ kWh માં ગણાય છે: 1 kWh = 3.6 × 10⁶ J.
વ્યવહારુ એકમ અને ગણતરી GUJCET માં મહત્વપૂર્ણ છે.
