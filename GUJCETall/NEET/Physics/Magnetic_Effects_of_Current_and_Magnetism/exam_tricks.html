ચુંબકીય પ્રભાવ અને ચુંબકત્વ — ગણતરી/ઉપરાહ્ય તરક

🎯 પરીક્ષા ટ્રિક્સ

વેધનિર્દેશક નિયમ (Right-Hand Thumb Rule) — વાયરમાંથી વહેતા વિદ્યુતપ્રવાહની દિશા જણાય તો ચુંબકીય ક્ષેત્રની દિશા ચારે બાજુ ચક્રીય મળે છે.
સીધા તાર, વૃત્તાકાર લૂપ, સોલેનોઇડનું ચુંબકીય ક્ષેત્ર મળવાની દિશા પૂછે તો
દા.ત.: આડો તાર જેમાં ડાબેથી જમણે પ્રવાહ વહે, તેના ઉપર ચુંબકીય ક્ષેત્ર દર્શક તરફ (out of page) અને નીચે પેજમાં (into page) હશે.
Biot-Savartનો અંદાજ: બિંદુ પ તારથી d દૂર હોય તો B ∝ I/d. આ રૂપરેખાથી જવાબો સાંપેક્ષિક ક્રમમાં ગોઠવી શકાય.
એકই પ્રવાહ ધરાવતા બે તાર કે લૂપમાં ક્ષેત્રની તીવ્રતા સરખાવવી હોય
દા.ત.: અર્ધવૃત્તની ત્રિજ્યા a હોય તો કેન્દ્ર પર B = μ₀I/(4a); સંપૂર્ણ વૃત્તમાં B = μ₀I/(2a). તેથી અર્ધવૃત્તનું ક્ષેત્ર અડધું હોય છે.
સોલેનોઇડની અંદર B = μ₀nI (n = ઝુંડેલી સંખ્યા/લંબાઈ). બહાર B ≈ 0. તેથી જવાબમાં 'શૂન્ય' વિકલ્પ આવે તો સોલેનોઇડ બહારનો ભાગ તપાસો.
સોલેનોઇડના અંદર/બહાર ક્ષેત્ર કે તેની તીવ્રતા પૂછે
દા.ત.: જો n દસગણું કરાય અને I અડધું કરાય, તો B = μ₀(10n)(I/2) = 5 μ₀nI — એટલે 5 ગણું થશે.
Helmholtz કોઇલ: બે સમાન વૃત્તાકાર કોઇલ, ત્રિજ્યા R, દૂરી = R. કેન્દ્રની મધ્યબિંદુએ B = (4/5)^(3/2) · μ₀nI/R ≈ 0.716 μ₀nI/R. આ નિરપેક્ષ મૂલ્ય યાદ રાખવું ફાયદાકારક.
Helmholtz કોઇલનું મધ્યબિંદુનું ક્ષેત્ર પૂછે અથવા સ્થિરસમાન ક્ષેત્ર બનાવવાના પ્રયોગમાં
દા.ત.: જવાબChoices માં (4/5)^{3/2}નો અંદાજો 0.716 ની સરખામણી કરો.
Lorentz બળ F = qvB sinθ. કણ સમાંતર જતા હોય (θ = 0°) → F = 0; લંબ (θ = 90°) → F = qvB (વધુમાં વધુ).
આવેશિત કણ ચુંબકીય ક્ષેત્રમાં ગતિ કરે ત્યારે બળ, પથ કે ગતિનો પ્રકાર પૂછે
દા.ત.: ઇલેક્ટ્રોન B તરફ સમાંતર ગતિ કરે તો તે સીધી રેખામાં જાય, વલયન બને નહીં.
ચુંબકીય ક્ષેત્રમાં લંબ રીતે પ્રવેશતા આવેશિત કણનો ત્રિજ્યા r = mv/qB. m, q, B સમાન હોય તો r ∝ v; v, q, B સમાન હોય તો r ∝ m.
પ્રોટોન, ઇલેક્ટ્રોન, α-કણ જેવા કણોની વલયની ત્રિજ્યા સરખાવવી હોય
દા.ત.: સમાન વેગ v અને ચુંબકીય ક્ષેત્ર B હોય: r_α/r_p = (m_α/q_α)/(m_p/q_p) = (4/2)/(1/1) = 2. α-કણની ત્રિજ્યા પ્રોટોનથી બમણી.
વલયન આવૃત્તિ f = qB/(2πm) — વેગ v પર આધારિત નથી! તેથી સમાન q/m ધરાવતા કણોની આવૃત્તિ સમાન રહે, ભલે તેમનો વેગ કંઇ પણ હોય.
cyclotron આવૃત્તિ અથવા કણની ભ્રમણ આવૃત્તિ સંબંધી પ્રશ્ન
દા.ત.: સમાન B માં પ્રોટોન અને deuteron (q સમાન, m_d ≈ 2m_p): f_d/f_p = m_p/m_d ≈ 1/2.
Ampereનું પરિભ્રમણ પ્રમેય: ∮B·dl = μ₀I_enc. બિંદુની ત્રિજ્યા r > R (બહાર) માં I_enc = કુલ I; r < R (અંદર) માં સમગ્રધારાના ગણતરી હેઠળ I_enc = I(r²/R²) સુધી.
બિંજો તારની અંદર/બહાર B શોધવાનો પ્રશ્ન
દા.ત.: R ત્રિજ્યાના તારની બહાર r દૂર: B = μ₀I/(2πr). આ તારની સપાટીએ (r = R) મહત્તમ B મળે છે.
સમાંતર તારો વચ્ચે આકર્ષણ/વિકર્ષણ: પ્રવાહ સમાન દિશામાં → આકર્ષણ; વિરોધી દિશામાં → વિકર્ષણ. વિગત B = μ₀I/(2πd), એકમ લંબાઈ બળ F/l = μ₀I₁I₂/(2πd).
બે સમાંતર વહનકારક તારો વચ્ચે બળ સંબંધી પ્રશ્ન
દા.ત.: જો પ્રવાહ દરેક બમણો કરાય અને દૂરી અડધી, તો F/l = μ₀(2I)(2I)/(2π·d/2) = 8× મૂળ મૂલ્ય.
ઓલ્ટરનેટિંગ પ્રવાહ (AC) માં RMS અને Peak સંબંધ: I_rms = I₀/√2, V_rms = V₀/√2. √2 ≈ 1.414. Peak = RMS × 1.414.
AC મૂલ્યોમાંથી Peak અથવા RMS શોધવાનો પ્રશ્ન
દા.ત.: V_rms = 220 V → V₀ = 220 × 1.414 ≈ 311 V.
સેન્જરી (Motor) અને જનરેટરનો મૂળભૂત તફાવત: Motor → વિદ્યુતને યાંત્રિકમાં ફેરવે (F = BIl); Generator → યાંત્રિકને વિદ્યુતમાં ફેરવે (ε = NBAω sinωt).
Motor vs Generator નો તફાવત અથવા કોઇક ચોક્કસ ઉપકરણનો પ્રશ્ન
દા.ત.: જો commutator (રિંગ) હોય → DC Motor/Generator; slip rings હોય → AC Generator.
ટ્રાન્સફોર્મર: V_s/V_p = N_s/N_p = I_p/I_s (આદર્શ). Step-up → N_s > N_p → V_s વધુ, I_s ઓછો; step-down → નીચુત.
ટ્રાન્સફોર્મરનો વોલ્ટેજ/કરન્ટ ગુણોત્તર શોધવાનો પ્રશ્ન
દા.ત.: N_p : N_s = 1 : 10, V_p = 220 V → V_s = 2200 V. જો I_p = 2 A, I_s = I_p×(N_p/N_s) = 0.2 A.
વાયરલૂપ પર ટોર્ક τ = NIAB sinθ. θ = 90° (સमतલ વેલ્વ B ને લંબ) → τ max; θ = 0° (સमतલ B સમાંતર) → τ = 0.
કોઇલ પર લાગતું ટોર્ક કે ટોર્કની દિશા પૂછે
દા.ત.: જો coil સંખ્યા બમણી કરાય અને પ્રવાહ અડધો, τ અચળ રહે (NI અચળ).
માધ્યમની સાપેક્ષ પરપ્રવાહિતા χ_m: ferromagnetic (>0, મોટું), paramagnetic (સાગર, ધન), diamagnetic (ઋણ, ખુબ નાનું). ડાયમેગ્નેટિક પદાર્થ બહારનું ક્ષેત્ર દૂર કરે છે.
પદાર્થનો ચુંબકીય પ્રકાર નક્કી કરવાનો અથવા ક્ષેત્રવંકીરણ સંબંધી પ્રશ્ન
દા.ત.: તાંબું (paramagnetic), એલ્યુમિનિયમ (paramagnetic), સીસું (diamagnetic), લોખંડ (ferromagnetic).
ચુંબકીય ડોમેન: ફેરોમેગ્નેટિક પદાર્થમાં ડોમેન બંધારણીય રીતે ગોઠવાય છે. હીટિંગ અથવા ઝડપી મારવાથી ડોમેન ઘેરખાઈ જાય → ચુંબકત્વ ઓછું. Curie તાપમાનથી ઉપર → પરમેગ્નેટિક બને.
ચુંબકની ગુણધર્મો કે ગુમાવવાની ઘટના પૂછે
દા.ત.: લોખંડનું Curie તાપમાન ≈ 1043 K. તેમાંથી ઉપર ગરમ કરતા તે પરમેગ્નેટિક બને છે.
એકમ પરિચયની ચકાસણી: ટેસ્લા (T) = Wb/m², B એકમ. H એ ampere/m. μ₀ = 4π × 10⁻⁷ T·m/A. યાદ: B નો SI એકમ T, χ_m અયાપમિત.
એકમ/પરિમાણ સંબંધી પ્રશ્ન
દા.ત.: χ_m (ચુંબકીય સંવેદનશીલતા) એ અયાપમિત રાશિ છે. B = μ₀(H + M) → μ₀H નો એકમ B જેવો (T).
