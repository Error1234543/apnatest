📄 Short Notes

વિદ્યુતપ્રવાહ અને ચુંબકત્વના અસરો — શોર્ટ નોટ્સ

🧪 GUJCET — Gujarati • Physics • Magnetic Effects of Current and Magnetism

📘 વ્યાખ્યાઓ

  • ચુંબકીય પ્રવાહ (Magnetic Field): એકમ ધન આવેશ પર એકમ વેગથી ગતિ કરતો હોય ત્યારે લાગતું બળ
  • ઓરસ્ટેડનો પ્રયોગ (Oersted's Experiment): વિદ્યુતપ્રવાહ ધરાવતા તારની આજુબાજુ કંપનશીલ સૂઈ મુકતા સૂઈ વિચલિત થાય છે — પ્રવાહ ચુંબકીય ક્ષેત્ર ઉત્પન્ન કરે છે તે સાબિત કરે છે
  • બાયો-સેવાર્ટનો નિયમ (Biot-Savart Law): d**B** = (μ₀/4π)(I d**l** × **r̂**)/r²; વિદ્યુતપ્રવાહના તત્વની આસપાસ ચુંબકીય ક્ષેત્ર શોધે છે
  • આ૰પિયરનો પરિભ્રમણ નિયમ (Ampere's Circuital Law): ∮**B**·d**l** = μ₀I_enclosed; ચુંબકીય ક્ષેત્રનું રેખા સઘનત્વ બંધ પથમાં ફાળવતા પ્રવાહ પર આધારિત છે
  • લોરેન્ત્ઝ બળ (Lorentz Force): F = q(**E** + **v** × **B**); ધન આવેશ પર વિદ્યુત અને ચુંબકીય ક્ષેત્રના સંયુક્ત બળ
  • ચુંબકીય ક્ષેત્રની તીવ્રતા (Magnetic Field Strength B): એકમ ધન આવેશ પર એકમ વેગથી ગતિ કરતા પ્રભાર પર લાગતું ચુંબકીય બળ
  • ગેલ્વેનોમીટર (Galvanometer): વિદ્યુતપ્રવાહના લઘુતમ મૂલ્યની માપન કરતો સાધન; ચુંબકીય ક્ષેત્રમાં કુંડલી પર લાગતું ટર્ક દ્વારા કાર્યરત
  • વેગીય પસંદગાકાર (Velocity Selector): જ્યાં વિદ્યુત ક્ષેત્ર અને ચુંબકીય ક્ષેત્ર પરસ્પર લંબરૂપ હોય; v = E/B વેગ ધરાવતા કણો કોઈ પણ વિચલન વગર પસાર થાય છે
  • ચુંબકીય ડાયપોલ મોમેન્ટ (Magnetic Dipole Moment): **m** = N I **A**; પ્રવાહિત કુંડલીનું ચુંબકીય લાક્ષણિક મૂલ્ય
  • સાયક્લોટ્રોન (Cyclotron): ચુંબકીય ક્ષેત્રમાં ધન આવેશિત કણોને ચક્રીય પથે પુનઃ પુનઃ પ્રવેગિત કરી ઊંચી ઊર્જા આપતો સાધન
  • શંટ અવરોધ (Shunt Resistance): ગેલ્વેનોમીટરને અમીટરમાં રૂપાંતરિત કરવા તેના સમાંતર જોડેલો નીચો અવરોધ
  • ફિગર ઑફ મેરિટ (Figure of Merit): k = I_g/θ_g; એકમ કોણીય વિચલન માટે જરૂરી પ્રવાહ

⚡ સૂત્રો

  • દીર્ઘ સીધા તારનું મધ્યમાં: B = μ₀I/(2πr)
  • વર્તુળાકાર કુંડલીનું કેન્દ્રમાં: B = μ₀NI/(2R)
  • અક્ષ પરના બિંદુએ: B = μ₀NI R²/[2(R²+x²)^(3/2)]
  • સોલેનોઇડનું અંદર: B = μ₀nI (n = N/L એકમ લંબાઈના ભ્રમણો)
  • ટોરોઇડ: B = μ₀nI (كورમાં); બહાર અને છિદ્રમાં B = 0
  • ચુંબકીય ક્ષેત્રમાં ગતિમાન પ્રભાર પર બળ: F = qvB sinθ (વિદ્યુતક્ષેત્ર વગર)
  • પ્રવાહ વાહક પર ચુંબકીય બળ: F = BIl sinθ
  • બે સમાંતર પ્રવાહવાહક વચ્ચેનું બળ: F/l = μ₀I₁I₂/(2πd)
  • સાયક્લોટ્રોન આવર્તન: f = qB/(2πm)
  • ચુંબકીય ડાયપોલ પર ટર્ક: τ = mB sinθ = NIAB sinθ
  • ગેલ્વેનોમીટર → અમીટર: S = (I_g R_g)/(I - I_g)
  • ગેલ્વેનોમીટર → વોલ્ટમીટર: R = (V/I_g) - R_g
  • μ₀ = 4π × 10⁻⁷ T·m/A (શૂન્યાવકાશની પરમેએબિલિટી)

⭐ મુખ્ય તથ્યો

  • પ્રવાહ ધરાવતો તાર ચારે બાજુ ચુંબકીય ક્ષેત્ર ઉત્પન્ન કરે છે; આ ચુંબકીય ક્ષેત્રની રેખાઓ વર્તુળાકાર હોય છે
  • ક્ષેત્ર રેખાઓની સ્પર્શક ચુંબકીય ક્ષેત્રની દિશા આપે છે; ક્યારેય બે રેખા એકબીજાને છેદતી નથી
  • જમણા હાથના બાઠા નિયમ મુજબ: અંગૂઠો પ્રવાહ દિશામાં, વળેલા આંગળીઓ ક્ષેત્ર દિશા દર્શાવે છે
  • બાયો-સેવાર્ટ નિયમ મુજબ d**B** ∝ I, ∝ dl, ∝ sinθ, ∝ 1/r²
  • સીધા તારની અક્ષ પર (θ = 0 અથવા π) ચુંબકીય ક્ષેત્ર શૂન્ય છે
  • સમાન દિશામાં પ્રવાહ ધરાવતા સમાંતર તાર પરસ્પર આકર્ષે; વિપરીત દિશામાં પ્રવાહ ધરાવતા તાર પરસ્પર અપાકર્ષે
  • ચુંબકીય ક્ષેત્રમાં ગતિમાન પ્રભાર પર બળ હંમેશા વેગ અને ક્ષેત્ર બંનેને લંબરૂપ હોય છે
  • જો પ્રભાર ક્ષેત્રને લંબરૂપ પ્રવેશે તો વૃત્તાકાર પથ; સમકોણે પ્રવેશે તો સ્પંદલ (helical) પથ
  • ચુંબકીય બળ પ્રભારની ગતિજ ઊર્જા બદલતું નથી; તે માત્ર દિશા બદલે છે
  • કુંડલી પર લાગતું ટર્ક τ = NIAB sinθ; મહત્તમ τ = NIAB જ્યારે સપાટી ક્ષેત્રને સમાંતર
  • વેગીય પસંદગાકારમાં: qE = qvB ⇒ v = E/B
  • સાયક્લોટ્રોનમાં મહત્તમ ગતિજ ઊર્જા: K_max = q²B²R²/(2m)
  • અમીટરનો અવરોધ ખૂબ જ ઓછો (શંટ અવરોધ સમાંતર જોડે) — તેથી શ્રેણીમાં જોડાય
  • વોલ્ટમીટરનો અવરોધ ખૂબ જ વધારે (મોટો અવરોધ શ્રેણીમાં જોડે) — તેથી સમાંતરમાં જોડાય
  • ગેલ્વેનોમીટરની સંવેદનશીલતા વધારવા: N, A, B વધારો અથવા k (પુનઃસ્થાપક ટર્ક અચળાંક) ઘટાડો
  • ભૂ-ચુંબકીય ક્ષેત્ર: ગુણોત્તર રેખાઓ ભૂભૌગોલિક ઉત્તરમાંથી દક્ષિણ તરફ જાય છે; ચુંબકીય અક્ષ ભૂભૌગોલિક અક્ષ સાથે ~11.5° ખૂણો બનાવે છે
  • ચુંબકીય પદાર્થો: લોહચુંબકીય, પ્રતિચુંબકીય, અને ઉચ્ચચુંબકીય — ત્રણ શ્રેણી
  • સ્થાયી ચુંબક સામાન્ય રીતે સમચોરસ/દંડ આકારના લોખંડ-કોબાલ્ટ મિશ્રધાતુથી બને છે; વિદ્યુતચુંબક લૉહદંડ અને કુંડલીનો સંયોગ છે
  • ચુંબકીય ડોમેન (Domain) સિદ્ધાંત મુજબ લોહચુંબકીય પદાર્થમાં ડોમેન સંરેખણથી પ્રબળ ચુંબકત્વ મળે છે

⚠️ સામાન્ય ભૂલો

  • બળ સમીકરણ F = qvB sinθ માં θ એ **વેગ અને ક્ષેત્ર વચ્ચેનો ખૂણો** છે — તાર અને ક્ષેત્રનો નહીં
  • સાયક્લોટ્રોન આવર્તન f = qB/(2πm) એ કણના વેગ પર આધારિત નથી — આ એક મહત્વપૂર્ણ તથ્ય છે
  • ચુંબકીય બળ કાર્ય કરતું નથી, તેથી ઊર્જા બદલાતી નથી — કણનો વેગધર (speed) સ્થિર રહે છે
  • ગેલ્વેનોમીટરને અમીટરમાં બદલતા શંટ અવરોધ શ્રેણીમાં નહીં, **સમાંતર**માં જોડાય છે
  • ગેલ્વેનોમીટરને વોલ્ટમીટરમાં બદલતા અવરોધ **શ્રેણી**માં જોડાય છે — સમાંતર નહીં
  • અમીટર શ્રેણીમાં જોડે → નિમ્ન અવરોધ; વોલ્ટમીટર સમાંતરમાં જોડે → ઉચ્ચ અવરોધ (આ બંને ઉલટા ન કરવા)
  • બાયો-સેવાર્ટમાં d**l** × **r̂** ક્રોસ ગુણાકાર છે — દિશા ડાબા હાથના નિયમથી નહીં, જમણા હાથના ક્રોસ ગુણાકાર નિયમથી મળે
  • સોલેનોઇડના અંદર B = μ₀nI — 'n' એકમ લંબાઈના ભ્રમણો છે, કુલ ભ્રમણો N નહીં (n = N/L)
  • ટોરોઇડમાં કોરની અંદર જ ક્ષેત્ર હોય છે; બહાર અને છિદ્રમાં B = 0 — બહારના વિસ્તારને ગણતરીમાં લેવા નહીં
  • F = BIl માં θ એ **પ્રવાહ દિશા અને ક્ષેત્ર વચ્ચેનો ખૂણો** છે — કણના ખૂણા સાથે ગેરધારણા ન કરવી
  • સાયક્લોટ્રોન આવર્તન T = 2πm/(qB) — આવર્તકાળ દોરડાની લંબાઈ પર આધારિત નથી (પેન્ડૂલમ સાથે ગેરધારણા)
  • ચુંબકીય ક્ષેત્ર રેખાઓ સતત બંધ વલય બનાવે છે — ક્યારેય અનંત તરફ ખુલ્લી નથી હોતા
  • સમાંતર તાર વચ્ચેનું બળ F/l = μ₀I₁I₂/(2πd) — અંતર d વધે તો બળ ઘટે (વર્ગના વિપરીત નહીં, રેખીય)
  • ચુંબકીય ડાયપોલ મોમેન્ટ **m** = N I **A** — **A** સદિશ કુંડલીના તલને લંબરૂપ અને જમણા હાથના બાઠા નિયમ મુજબ
  • પ્રતિચુંબકીય (Diamagnetic) પદાર્થ ચુંબકીય ક્ષેત્રને પ્રતિકૂલ વિચલિત કરે છે — આકર્ષાતા નથી

🔥 હાઈ-યીલ્ડ મુદ્દા

  • B = μ₀I/(2πr) — દીર્ઘ સીધા તારનું મધ્યમાં ચુંબકીય ક્ષેત્ર (GUJCET માં સતત આવતું સૂત્ર)
  • F = qvB (લંબરૂપ પ્રવેશ) → કણનો વૃત્તાકાર પથ; ત્રિજ્યા r = mv/(qB) તંત્રમાંથી મેળવો
  • τ = NIAB sinθ — ગેલ્વેનોમીટર અને મોટરનો મૂળ સિદ્ધાંત
  • સાયક્લોટ્રોન આવર્તન f = qB/(2πm) — પ્રવેગકની આવૃત્તિ આ જ હોવી જોઈએ
  • સમાંતર તારો: સમાન દિશામાં પ્રવાહ → આકર્ષણ; વિપરીત દિશા → અપાકર્ષણ
  • ગેલ્વેનોમીટર → અમીટર: શંટ S = I_g R_g/(I - I_g) — યાદ રાખો: સમાંતર + નિમ્ન અવરોધ
  • ગેલ્વેનોમીટર → વોલ્ટમીટર: R = V/I_g - R_g — શ્રેણી + ઉચ્ચ અવરોધ
  • બાયો-સેવાર્ટ: d**B** = (μ₀/4π)(I dl sinθ/r²) — ક્ષેત્ર તત્વની દિશા dl × r̂ પર આધારિત
