📘 વ્યાખ્યાઓ

  • α-કણ: હિલીયમ-4 ના ન્યુક્લિયસ જેવું બે પ્રોટોન અને બે ન્યુટ્રોન ધરાવતું ધન વીજભારિત કણ.
  • β-કણ: ઉચ્ચ ઊર્જા ધરાવતું ઇલેક્ટ્રોન (β⁻) અથવા પોઝિટ્રોન (β⁺) જે રેડિયોએક્ટિવ ક્ષય દરમિયાન ઉત્સર્જિત થાય છે.
  • γ-રિક્ત: ન્યુક્લિયસની ઉત્તેજિત અવસ્થાથી ઉત્તેજાઓ ત્યારે ઉત્સર્જિત થતું ઉચ્ચ-ઊર્જા ઇલેક્ટ્રોમેગ્નેટિક ફોટોન.
  • આઇસોટોપ: સમાન પરમાણ્વીય ક્રમાંક (Z) પણ ભિન્ન ન્યુક્લિયોન સંખ્યા (A) ધરાવતી પરમાણુ પ્રજાતિ.
  • આઇસોન્યુટ્રોન: સમાન ન્યુટ્રોન સંખ્યા પણ ભિન્ન પ્રોટોન સંખ્યા ધરાવતી ન્યુક્લિયસ પ્રજાતિ.
  • આઇસોબાર: સમાન ન્યુક્લિયોન સંખ્યા (A) પણ ભિન્ન પરમાણ્વીય ક્રમાંક (Z) ધરાવતી પ્રજાતિ.
  • રેડિયોસક્રિયતા: અસ્થિર ન્યુક્લિયસનું સ્વયંસ્ફુરિત વિઘટન થઈને સ્થિર ન્યુક્લિયસમાં રૂપાંતરિત થવાની ઘટના.
  • ક્ષય અચળાંક (λ): એકમ સમયમાં એક ન્યુક્લિયસના ક્ષય થવાની સંભાવનાનો માપદંડ.
  • અર્ધ-આયુષ્ય (t₁/₂): ક્ષય થતાં ન્યુક્લિયસની સંખ્યા અર્ધી થવામાં લાગતો સમય.
  • સરેરાશ આયુષ્ય (τ): ન્યુક્લિયસના આયુષ્યનું અંકગણિત મધ્યક, τ = 1/λ.
  • સક્રિયતા (Activity): એકમ સમયે થતા ક્ષયની સંખ્યા, A = λN. એકમ: becquerel (Bq).
  • ક્રાંતિક દળ: સ્વચાલિત શૃંખલા પ્રક્રિયા ચાલુ રહે તે માટે જરૂરી ક્રિયાશીલ દ્રવ્યનું ન્યૂનતમ દળ.
  • માસ ડેફેક્ટ (Δm): સ્વતંત્ર ન્યુક્લિયોનના કુલ દળ અને બંધાયેલા ન્યુક્લિયસના દળ વચ્ચેનું તફાવત.
  • બંધન ઊર્જા: ન્યુક્લિયસને તેના ન્યુક્લિયોનમાં છૂટો પાડવા માટે જરૂરી ઊર્જા.
  • ન્યુક્લિયર ફિશન: ભારે ન્યુક્લિયસનું મધ્યમ ન્યુક્લિયસમાં વિભાજન થઈ ઊર્જા મુક્ત કરવી.
  • ન્યુક્લિયર ફ્યુઝન: હલકા ન્યુક્લિયસના મિલનથી ભારે ન્યુક્લિયસ બનવાની પ્રક્રિયા અને ઊર્જા મુક્તિ.

⚡ સૂત્રો

  • હાઈડ્રોજન જેવી પરમાણુમાં ઊર્જા સ્તર: Eₙ = −13.6 × Z² / n² eV, n = 1,2,3…
  • કક્ષીય વેગવિધિ: vₙ = Z e² / (2 ε₀ h n), n = 1,2,3…
  • કક્ષાની ત્રિજ્યા: rₙ = n² h² ε₀ / (π mₑ Z e²) = a₀ n² / Z, જ્યાં a₀ ≈ 0.529 Å.
  • ડિ ब्रॉગ्ली તરંગલંબાઈ: λ = h / p.
  • રેડિયોએક્ટિવ ક્ષય નિયમ: N = N₀ e^{−λt}.
  • અર્ધ-આયુષ્ય અને ક્ષય અચળાંક: t₁/₂ = ln 2 / λ ≈ 0.693 / λ.
  • સક્રિયતા: A = λN = A₀ e^{−λt}, એકમ Bq = s^{−1}.
  • માસ ડેફેક્ટ: Δm = Zmₚ + Nmₙ − m_{Nucleus}.
  • બંધન ઊર્જા: B = Δm c².
  • પ્રતિ ન્યુક્લિઓન બંધન ઊર્જા: B/A.

⭐ મુખ્ય તથ્યો

  • ગેગર-માર્સડેનના α-પ્રકીર્ણન પ્રયોગથી પોઝિટિવ ન્યુક્લિયસની શોધ થઈ.
  • વધુમાં વધુ α-કણ સીધા પસાર થઈ ગયા; નાનો ભાગ મોટા ખૂણે વળ્યા, જેથી કોષની મોટી સંખ્યા શૂન્યમાં કેન્દ્રિત હોવાનું જાણવા મળ્યું.
  • કણનું લિંબ સિદ્ધાંત: b = (Z e² / 4πε₀) cot(θ/2) / (½ m v²).
  • બોહ્રના બે મુખ્ય ધારણા: (1) સ્થિર અવસ્થામાં ઇલેક્ટ્રોન ફરે છે, (2) L = nℏ.
  • હાઈડ્રોજન સ્પેક્ટ્રલ સીરીઝ: 1/λ = R_H (1/n_f² − 1/n_i²).
  • લાયમેન સીરીઝ n_f = 1 (અલ્ટ્રાવાયોલેટ).
  • બાલમેર સીરીઝ n_f = 2 (દૃશ્યમાન).
  • પાશ્કન સીરીઝ n_f = 3 (ઇન્ફ્રારેડ).
  • α-કણ: ઓછું ભેદન, મોટી આયનીકરણ ક્ષમતા, ધન વીજભાર; મેગ્નેટિક ક્ષેત્રમાં મૂકાઈ જાય છે.
  • β-કણ: મધ્યમ ભેદન, ઋણ/ધન વીજભાર, ક્ષેત્રમાં વિપરીત માર્ગે મૂકાઈ જાય છે.
  • γ-રિક્ત: મહત્તમ ભેદન, વિદ્યુત/ચુંબકીય ક્ષેત્રમાં અઅભિવર્તી, વેગ c.
  • β⁻ ક્ષય: n → p + e⁻ + ν̄ₑ, પરમાણ્વીય ક્રમાંક +1, દળ સંખ્યા સમાન.
  • β⁺ ક્ષય: p → n + e⁺ + νₑ, પરમાણ્વીય ક્રમાંક −1, દળ સંખ્યા સમાન.
  • γ-ઉત્સર્જન: ન્યુક્લિયસ ઉત્તેજિત અવસ્થામાંથી નીચલી અવસ્થામાં આવે છે, નવો દળ/ક્રમાંક બદલાતો નથી.
  • પ્રતિ ન્યુક્લિઓન બંધન ઊર્જા વળાંક: Fe-56 ની આસપાસ શિખર, મધ્યમ દળવાળા ન્યુક્લિયસ સૌથી સ્થિર.
  • હેલાક પ્રક્રિયામાં H-2 + H-3 → He-4 + n + 17.6 MeV.
  • યુરેનિયમ-235 નું ઉષ્મીય ન્યુટ્રોન દ્વારા ફિશન, સામાન્યતઃ ~200 MeV ઊર્જા મુક્ત.
  • શૃંખલા પ્રક્રિયા ચાલુ રહે તે માટે ન્યુટ્રોન મોડરેટર અને બિલ્ટ્સ વડે નિયંત્રિત કરવામાં આવે છે.
  • ન્યુટ્રોન-થી-પ્રોટોન ગુણોત્તર: હલકા ન્યુક્લિયસમાં ≈1, ભારે ન્યુક્લિયસમાં ~1.5.

⚠️ સામાન્ય ભૂલો

  • માસ ડેફેક્ટની વ્યાખ્યા વિપરીત ન લખો: Δm = (સંયોજન પૂર્વેનું દળ) − (સંયોજન પછીનું દળ).
  • β-કણ ન્યુક્લિયસમાં આદિથી મોજૂદ હોય છે તેમ ન સમજો; તે ન્યુક્લિયન રૂપાંતરથી ઉત્પન્ન થાય છે.
  • ગેગર-માર્સડેન પ્રયોગમાં ડિટેક્ટર scintillation સ્ક્રીન પર દૃશ્યમાન ચમક ગણતરી કરતો હતો.
  • α-પ્રકીર્ણન દર સમીકરણમાં 1/sin⁴(θ/2) ની આંતરઆધારી યાદ રાખવી.
  • અર્ધ-આયુષ્ય પુનરાવર્તન કરતાં N = N₀(½)^{t/t₁/₂} નો સીધો સંબંધ ઉપયોગ કરો.
  • બંધન ઊર્જા ધન છે, પણ ન્યુક્લિયસની કુલ ઊર્જા બંધાયેલ અવસ્થામાં ઋણ ગણાય છે.
  • પ્રતિ ન્યુક્લિઓન બંધન ઊર્જાની ગણતરી કરતી વખતે mass number A વડે ભાગોવાનું ભૂલશો નહિ.
  • યુનિટ રૂપાંતર: 1 Ci = 3.7×10¹⁰ Bq; 1 eV = 1.602×10⁻¹⁹ J.
  • ન્યુક્લિયર પ્રક્રિયામાં દળ સંખ્યા અને પરમાણ્વીય ક્રમાંક બંને સમાન રહે છે; γ ઉત્સર્જનમાં બંને બદલાતા નથી.
  • હાઈડ્રોજનના n = 1 લેવલનું ઋણ મૂલ્ય ધન ઊર્જા નથી; તે બંધાયેલ સ્થિતિ દર્શાવે છે.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • રેડિયોએક્ટિવ ઇશ્યુ: A → A' + કણ; દળ સંખ્યા અને Z ની સંરક્ષણ નિયમ સૌથી પ્રાયોગિક ગણતરીમાં આવશે.
  • પ્રતિ ન્યુક્લિઓન બંધન ઊર્જા વળાંક માંથી ફિશન અને ફ્યુઝન બંનેની ઊર્જા મુક્તિ સમજાવો.
  • બોહ્ર મોડેલ માત્ર એક-ઇલેક્ટ્રોન સિસ્ટમ માટે સચોટ છે; multi-electron માટે સામાન્યીકરણ નથી.
  • સ્પેક્ટ્રલ સીરીઝના રૂપાંતર n_i → n_f ને ઓળખો; visible બાલમેર સીરીઝમાં હેલિયમની 468.6 nm line આવી શકે છે.
  • કક્ષા ઊર્જા Eₙ ∝ −Z²/n² નું પ્રકાશસ્પંદન યાદ રાખો: આયનીકરણ ઊર્જા = |E₁|.
  • મોડરેટર સામાન્ય રીતે હળવા ન્યુક્લિયસ (પાણી, ભારે પાણી, ગ્રેફાઈટ) વડે ન્યુટ્રોનની ઊર્જા ઘટાડવામાં આવે છે.
  • શૃંખલા પ્રક્રિયાની સમયગતિ માટે k_eff = 1 નિયંત્રિત રિએક્ટરમાં, k_eff > 1 માં વધતી જતી પ્રક્રિયા હોય છે.
  • α, β, γ નું ભેદન ગોઠવણ: α < β < γ; આયનીકરણ ક્ષમતા ગોઠવણ: α > β > γ.
  • ન્યુટ્રોન ઝડપી ન્યુટ્રોન કરતાં થર્મલ ન્યુટ્રોન U-235 નું વિભાજન કરવામાં અસરકારક છે.
  • બંધાયેલ ન્યુક્લિયસનું દળ સંયોજન પૂર્વેના ન્યુક્લિયોનના કુલ દળ કરતાં હંમેશાં ઓછું હોય છે.
