Biomolecules (જૈવઅણુઓ) — GUJCET ઝટપટ ટ્રિક્સ

🧪 GUJCET — Gujarati • Biology • Biomolecules

🎯 પરીક્ષા ટ્રિક્સ

મોનોસેકેરાઇડમાં કાર્બનની સંખ્યા શોધવા: પ્રીફિક્સ યાદ રાખો — મોનો = 1, ડાય = 2, ટ્રાય = 3, ટેટ્રા = 4, પેન્ટા = 5, હેક્સ = 6.
જ્યારે પ્રશ્નમાં ઘટ્ટાંક અથવા બહુલઘટ્ટાંકનું વર્ણન આપેલ હોય અને તેમાં કાર્બનની સંખ્યા પૂછાય.
દા.ત.: પેન્ટોઝ (Pentose) એ 5-કાર્બન ડાય અથવા મોનોસેકેરાઇડ છે. ઉદા.: રિબોઝ, ડીઓક્સિરીબોઝ.
પ્રોટીનમાંPeptide (પેપ્ટાઇડ) બંધ અને Carbohydrate (કાર્બોહાઇડ્રેટ) માં Glycosidic (ગ્લાયકોસિડિક) બંધ — બંધનો પ્રકાર મોનોમર પરથી ઓળખો: એમિનો<->એમિનો = પેપ્ટાઇડ, શર્કરા<->શર્કરા = ગ્લાયકોસિડિક.
જ્યારે પ્રશ્ન પૂછે કે ચોક્કસ જૈવઅણુ કયા પ્રકારના બંધથી જોડાયેલા છે.
દા.ત.: ડાયસેકેરાઇડ (માલ્ટોઝ, સુક્રોઝ) માં α-1,4-ગ્લાયકોસિડિક બંધ હોય છે. પ્રોટીનમાં α-અમિનો એસિડ વચ્ચે Peptide બંધ હોય છે.
Nucleotide (ન્યુક્લિયોટાઇડ) ના ત્રણ ભાગ યાદ રાખવાની ટ્રિક: Nucleic acid (ન્યુક્લિક એસિડ) → Nitrogenous base (નાઇટ્રોજનયુક્ત ક્ષાર) + Pentose sugar (પેન્ટોઝ શર્કરા) + Phosphate group (ફોસ્ફેટ સમૂહ).
જ્યારે પ્રશ્નમાં ન્યુક્લિયોટાઇડની રચના અથવા તેના ઘટકો પૂછવામાં આવે.
દા.ત.: DNA નું ન્યુક્લિયોટાઇડ: adenine/guanine/cytosine/thymine + deoxyribose + phosphate.
Purine (પ્યુરિન) = 2 રિંગ, Pyrimidine (પાયરીમિડિન) = 1 રિંગ. યાદ કરવા: Purine → ‘Pure As Gold’ (Adenine, Guanine); Pyrimidine → ‘CUT the PYe’ (Cytosine, Uracil, Thymine).
જ્યારે નાઇટ્રોજનયુક્ત ક્ષારોના વર્ગીકરણ અથવા રિંગની સંખ્યા પૂછાય.
દા.ત.: adenine અને guanine પ્યુરિન છે; cytosine, thymine, uracil પાયરીમિડિન છે.
Enzyme (આધિરસ/કીટાણુનાશક નહીં, ઉત્સેચક) – Lock and Key (તાળું-કી) vs Induced Fit (અનુકૂલિત ફીટ): Lock and Key માં સક્રિય stite (સક્રિય કેન્દ્ર) પહેલાથી જ આકાર ધરાવે છે; Induced fit માં સબસ્ટ્રેટ (અધિરાગી) આવતાં આકાર બદલાય છે.
જ્યારે ઉત્સેચક-અધિરાગી ક્રિયાપ્રતિક્રિયાના મોડેલ વિશે પ્રશ્ન હોય.
દા.ત.: પ્રશ્ન: “કયા મોડેલમાં ઉત્સેચકનો આકાર સબસ્ટ્રેટ બાઉન્ડિંગ પછી બદલાય છે?” જવાબ: Induced fit.
Triglyceride (ત્રિઘટક ચર્બી/ટ્રાઈગ્લિસરાઇડ) = Glycerol (ગ્લિસરોલ) + 3 Fatty acids (ચર્બીના અમ્લ). Ester (એસ્ટર) બંધની સંખ્યા = 3. Hydrolysis (જળવિઘટન) થી 1 ગ્લિસરોલ + 3 ચર્બીના અમ્લ મળે.
જ્યારે લિપિડની રચના, બંધોની સંખ્યા અથવા જળવિઘટન ઉત્પાદનો પૂછાતા હોય.
દા.ત.: ટેગ (TAG) નું જળવિઘટન કર્યે 1 ગ્લિસરોલ + 3 ફેટી એસિડ મળે. આથી ઇસ્ટર બંધ = 3.
Condensation (સંઘનન) vs Hydrolysis (જળવિઘટન) ટ્રિક: Condensation માં H₂O નીકળે અને નવો બંધ બને; Hydrolysis માં H₂O ઉમેરાય અને બંધ તૂટે. યાદ રાખો: ConDENSE = Remove Water; HYDRO = Add Water.
જ્યારે બાયોમોલેક્યુલ બંધના ગठન અથવા વિઘટન પ્રક્રિયા વિશે પ્રશ્ન હોય.
દા.ત.: બે અમિનો એસિડ જોડાઈ ડાયપેપ્ટાઇડ બનાવે → Condensation (H₂O નીકળે). પેપ્ટાઇડ તૂટીને અમિનો એસિડ મળે → Hydrolysis (H₂O ઉમેરાય).
Primary structure (પ્રાથમિક રચના) = amino acid sequence; Secondary = α-helix / β-pleated sheet (હાઈડ્રોજન બંધ); Tertiary = 3D folding (-disulfide, ionic, H-bonds); Quaternary = multiple polypeptide chains.
જ્યારે પ્રોટીનની રચનાના સ્તરો અથવા તેમને જાળવતા બંધો વિશે પ્રશ્ન હોય.
દા.ત.: Insulin (ઇન્સુલિન) માં disulfide bridges હોય છે → tertiary/quaternary structure જાળવી રાખે છે.
ઋણાત્મક ચુંબકીય ક્ષેત્ર (Negative charge) ધરાવતા જૈવઅણુઓ: Nucleic acids (ફોસ્ફેટના કારણે), Acidic amino acids (glutamic, aspartic). ધનઆવેશિત (Positive): Lysine, arginine, histidine.
જ્યારે પ્રશ્નમાં ચુસકત સ્વભાવ અથવા электрофорેસિસ (ઇલેક્ટ્રોફોરેસિસ) દિશા પૂછાય.
દા.ત.: Electrophoresis માં DNA ધન ધ્રુવ તરફ ખસે (કારણ કે તેઋણ આયનિત હોય છે).
મોનોસેકેરાઇડના ઓપ્ટિકલ આઈસોમર (D/L) ટ્રિક:最后一个 અસંતુલિત કાર્બન પર –OH ગ્રૂપ જમણી બાજુએ (Fischer projection) = D; ડાબી બાજુએ = L. મોટાભાગના જૈવિક શર્કરા D-સ્વરૂપની હોય છે.
જ્યારે પ્રશ્ન D-અથવા L-સ્વરૂપ વિશે પૂછે અથવા ઓપ્ટિકલ સક્રિયતા સંબંધી પ્રશ્ન હોય.
દા.ત.: D-glucose (ડી-ગ્લુકોઝ) અને L-glucose (એલ-ગ્લુકોઝ) એ એકબીજાના આઈસોમર છે; કિણ્વન માટે D-ગ્લુકોઝ જ ઉપયોગી છે.
અનુરૂપ પ્રશ્નો (Matching type) માટે: Protein – Enzyme/Structure; Carbohydrate – Energy/Storage; Lipid – Membrane/Energy storage; Nucleic acid – Genetic info.
જ્યારે ઝડપી રીતે સામગ્રી-કાર્ય મિલાવવાનો પ્રશ્ન આવે.
દા.ત.: ગ્લાયકોજન (Glycogen) → energy storage (જળિત શર્કરા); Phospholipid → cell membrane (કોષપટલ).
Reducing sugar (લઘુતમ શર્કરા) test: Benedict’s/Fehling’s reagent with heat → Brick-red precipitate. Non-reducing sugar (ઉદા. sucrose) માટે પ્રથમ hydrolysis કરવો પડે.
જ્યારે પ્રयोगાત્મક પ્રશ્ન અથવા રાસાયણિક પરીક્ષણ વિશે પ્રશ્ન હોય.
દા.ત.: Maltose reducing છે, Sucrose non-reducing છે. આથી Benedict’s test માં maltose brick-red આપે, sucrose નહીં (હાઇડ્રોલાઇઝ ન કર્યું હોય તો).
