ધ્વજપુષ્પી (Plant Kingdom) — હાથે લખેલી નોટ્સ

🧪 GUJCET — Gujarati • Biology • Plant Kingdom

🌿 પ્રસ્તાવના: છોડની વર્ગીકરણ
છોડજગત (Plant Kingdom) માં સભ્યો દ્વિકોષીય (Eukaryotic), બહુકોષીય અને સવંદ્રિય (Autotrophic) અથવા પરોષઢ (Parasitic) જীবો આવેલ છે.
🔑 યાદ રાખો: છોડમાં સવંદ્રિય આહાર (Photosynthesis દ્વારા) મુખ્ય છે — ક્લોરોફિલ ઉપસ્થિત હોય છે.
વૈદ્યાની પ્રચલિત વર્ગીકરણ: સદીઓથી થાયુઃ (Cryptogamae = ગુપ્તબીજી) અને ફેનોગેમ્સ (Phanerogamae = દૃષ્ટબીજી) માં વિભાજિત.
થાયુઃ (Cryptogamae)અપુષ્પી છોડ — બીજ રચતા નથી, પ્રજનન સાદું
ફેનોગેમ્સ (Phanerogamae)પુષ્પી છોડ — બીજ ધરાવે છે, સંકળામય પ્રજનન
📝 📝 GUJCET એક્ઝામ: Cryptogamae → Algae + Bryophyta + Pteridophyta | Phanerogamae → Gymnosperm + Angiosperm
🟢 પ્રકરણ 1: શૈવાળ (Algae)
શૈવાળ મૂળભૂત રીતે જળાશયી (Aquatic), સાદી બનતી (Thallophyta) છોડ છે. કોષભિત્તિ સેલ્યુલોઝની બનેલી હોય છે.
🔑 શૈવાળ = પ્રથમ જમીન પર આવેલા છોડ. તેઓ પ્રકાશસંશ્લેષણ કરનારા સવંદ્રી (Autotrophic) જીવ છે.
ત્રણ પ્રમેય શૈવાળ: (1) હરિત શૈવાળ (Chlorophyceae), (2) પીતશૈવાળ/ભૂરો શૈવાળ (Phaeophyceae), (3) રક્તશૈવાળ (Rhodophyceae).
ક્લોરોફિલ a + b = હરિત શૈવાળ | ફ્યુકોક્સાન્થિન = પીતશૈવાળ | ફિકોઆઈરિથ્રિન = રક્તશૈવાળ
હરિત શૈવાળ (Chlorophyceae): કલોરોફિલ a અને b ધરાવે; સંગ્રહીત ખાદ્ય પદાર્થ સ્ટાર્ચ; દા.ત. ચેટોફોરા, સ્પાયરાગાઇના, ક્લેમિડોમોનાડ્સ.
પીતશૈવાળ (Phaeophyceae): ભૂરા રંગના; ફ્યુકોક્સાન્થિન રંગદ્રવ્ય ઉપસ્થિત; સંગ્રહીત ખોરાક માર્જિનાલ કે સફેદ સ્ટાર્ચ જેવો; દા.ત. કેલ્પા, લેમિનારીયા.
રક્તશૈવાળ (Rhodophyceae): લાલ રંગના; ફિકોઆઈરિથ્રિન (Red pigment) હોય; સમુદ્રી (Marine); સંગ્રહીત ખોરાક ફ્લોરાઇડિન; દા.ત. કોરેડોન, પોલીસिफाइन.
શૈવાળનું પ્રજનનઅલિંગી (Zoospores) + લિંગી (ગેમેટ્સ) + અયૌગિક
📝 📝 શૈવાળ કોષભિત્તિ = સેલ્યુલોઝ + પેક્ટિન/અલજિનેટ | પ્રકાશસંશ્લેષણનું મુખ્ય ઉત્પાદન O₂
🌱 પ્રકરણ 2: બ્રાયોફાઇટ્સ (Bryophytes) — મોસ પ્લાન્ટ્સ
બ્રાયોફાઇટ્સને 'સ્ત્રીલોકના ઉભયચર' (Amphibians of plant kingdom) કહે છે — આંશિક રીતે જમીન પર પણ જીવે છે.
🔑 બ્રાયોફાઇટ્સનું લક્ષણ: વાહક પેશીઓ (Vascular tissue) નથી હોતી — તેથી ઊંચાઈ મર્યાદિત
બે પ્રકાર: લીવરવર્ટ્સ (Liverworts) અને મોસીસ (Mosses).
લીવરવર્ટ્સ (Marchantia): થાલસ (Thallus) સપાટ, દ્વિધ્રુવીય; સ્પોરોજીટા (Sporophyte) થોડું જટિલ; ગામેટોફાઇટ પ્રબળ.
મોસીસ: આંધ્રિક (Acrocarp) અને તળમથ્થ (Penduculate) એમ બે પ્રકાર. સ્પોરોફાઇટ વધુ જટિલ; વાસન્ટ (Cap) રૂપી સ્પોરેન્જિયા.
ગામેટોફાઇટ (n) + સ્પોરોફાઇટ (2n) → એક્ટરોસ્પોરોજેનિક જીવનચક્ર
બ્રાયોફાઇટ્સશૈવાળ → સર્વસામાન્ય યોજના, પરંતુ ગામેટોફાઇટ પ્રબળ
📝 📝 ब्रायोफाइट्स में संरक्षण (Oogamy + Archegonia) — यह प्लैंट किंगडम में पहली बार दिखता है
🌿 પ્રકરણ 3: પ્ટેરિડોફાઇટ્સ (Pteridophytes)
પ્ટેરિડોફાઇટ્સ = પ્રથમ વાહક પેશી ધરાવતા છોડ (Xylem + Phloem). 'ફર્ન' એ સૌથી સુંદર ઉદાહરણ છે.
🔑 પ્ટેરિડોફાઇટ્સ = પ્રથમ ધરતી પર સુંદર છોડ. ડ્રાયોનામા, લીકોપ્સિડ્સ, સ્ફેનોપ્સિડ્સ, પ્ટેરોપ્સિડ્સ.
ચાર પ્રકાર: (1) પ્સિલોપ્સિડા — રેજિયા, (2) લાઇકોપ્સિડા — સિલેજિનિયા, (3) સ્ફેનોપ્સિડા — સિલેજિનોટેલ્સ, (4) પ્ટેરોપ્સિડા — ડ્રાયોનામા.
સેલેજિનિયા અને સિલેજિનોટેલ્સ = ઘડીપાન જેવા લાગે; સિલેજિનોટેલ્સની જડ (Rhizome) અને પર્ણ (Frond) ભિન્ન.
ડ્રાયોનામા (Ferns): સર્વસામાન્ય પ્લાન્ટ; સ્પોરોફાઇટ પ્રબળ; ગામેટોફાઇટ (પ્રોથેલિયમ) નાનું, હૃદયાકાર.
ડિપ્લોબાયોન્ટિક (Diplontic) જીવનચક્ર — બે પગલું: સ્પોરોફાઇટ (2n) → સ્પોરોજેનિસિસ → ગામેટોફાઇટ (n)
બ્રાયોફાઇટ્સ → પ્ટેરિડોફાઇટ્સવાહક પેશી + સ્પોરોફાઇટ પ્રબળ
📝 📝 પ્ટેરિડોફાઇટ્સમાં સહયોગ (Sporophyll) અને સ્પોરેન્જિયા દેખાય છે — ફર્નના પર્ણ પાછળના કાળા દાણા = સ્પોરોફાઇલ્સ
🌲 પ્રકરણ 4: જાઈમનોસ્પર્મ્સ (Gymnosperms)
જાઈમનોસ્પર્મ્સ = ખુલ્લા બીજ ધરાવતા છોડ. બીજ બનાતું નથી — તેથી 'જાઈમનો' (ખુલ્લું) + 'સ્પર્મ્સ' (બીજ).
🔑 Gymnosperms = Naked seeds. No fruit. Conifers (સુગંધિત વૃક્ષો) મુખ્ય પ્રતિનિધિ.
ચાર વર્ગ: (1) સೈકાડેસ (Cycas), (2) એન્ટરોઝોઓ (Equisetum - wait, no), (3) ગનગેસ (Gnetum), (4) કોનિફેર્સ (Pinus). સાચા: સિકાડ, ગેટેસ, કોનિફેર્સ.
સિકાડ (Cycas): 'રિવિવર પ્લાન્ટ'; પાદપ (Male cone) અને અંડપ (Female cone) ભિન્ન; જટિલ સ્પોરોફાઇટ.
પાઇનસ (Pinus): હંમેશા વાંધોધર વૃક્ષ; દ્વિધ્રુવીય કોન; બીજ ધડ પર બેસેલું — સુકેલા પાંદડા જેવું.
જાઈમનોસ્પર્મ્સ: Sporangia (Strobilus) → Pollen (microspore) + Ovule (megaspore) → Seed (open)
પ્ટેરિડોફાઇટ્સજાઈમનોસ્પર્મ્સ — સ્પોર → બીજમાં રૂપાંતર
📝 📝 Gymnosperms માં FLOWER હોતી નથી, પણ STROBUS ( cone ) હોય છે | pollination દ્વારા seed બને છે
🌸 પ્રકરણ 5: એંગિયોસ્પર્મ્સ (Angiosperms)
એંગિયોસ્પર્મ્સ = આવરિતબીજી છોડ. બીજ ફળમાં આવરિત હોય છે. સૌથી વધુ વિકસિત છોડવર્ગ.
🔑 Angiosperms = Flowering plants. Double fertilization is UNIQUE to angiosperms! (બેવડો સંયોજન)
બે વિભાગ: એકદળી (Monocots) અને દ્વિદળી (Dicots).
એકદળી: એક દળ (Cotyledon), શિરારચના સમાંતર (Parallel venation), જડતંત્ર તંતુમય (Fibrous roots), પુષ્પાંગો 3 અથવા 3 ના ગુણકમાં.
દ્વિદળી: બે દળ, શિરારચના જાળીદાર (Reticulate), મુખ્ય જડ (Taproot), પુષ્પાંગો 4-5 અથવા 4-5 ના ગુણકમાં.
એકદળી: n=10 | દ્વિદળી: n=7 | એકદળી પુષ્પમાં tepals (ફૂલપત્ર + દળ એકસરખા) — દા.ત. લિલી
એકદળી છોડઘઉં, મકાઈ, ચોખા, બંસ, ખીરડી, પાટલીપુષ્પ
દ્વિદળી છોડબદામ, કેળા, આંબા, મગફળી, તમાકૂ, રોઝ
📝 📝 एन्जियोस्पर्म में double fertilization → Primary endosperm (3n) + Zygote (2n)
🔬 એંગિયોસ્પર્મ્સની રચના
પુષ્પના આંગિક: પુષ્પપાત્ર (Calyx), પાંદડા (Corolla), પુંકેસર (Androecium), સ્ત્રીકેસર (Gynoecium).
🔑 પુંકેસર = Anther + Filament | સ્ત્રીકેસર = Stigma + Style + Ovary
અંડકોષ (Ovule): નિંગણી (Integument), નિર્વિધા (Micropyle), એમ્બ્રિયોસેક (Embryo sac).
બેવડો સંયોજન (Double Fertilization): 1精子 + ઑગમા (Zygote, 2n) | 1精子 + 2 Polar nuclei (Primary endosperm, 3n)
પર પરಾಗસંપર્કસ્વ-પર-પરાગસ્પર્શ > સંકર (Hybrid) > રોગપ્રતિકાર
📝 📝 एन्जियोस्पर्म의独有特征: 2精子参与受精 —这是高中生物最重要的考点之一
🧬 છોડવર્ગનું વર્ગીકરણ (શ્રેણીબદ્ધ વિચારધારા)
પ્રથમ છોડ = પ્રાઇમરી પ્રોકેરિઓટ્સ (cyanobacteria-like) → પ્રોટોસ્ટાઇટ → શૈવાળ → બ્રાયોફાઇટ્સ → પ્ટેરિડોફાઇટ્સ → જાઈમનોસ્પર્મ્સ → એંગિયોસ્પર્મ્સ.
🔑 Evolution trend: Simple → Complex, Aquatic → Terrestrial, Gametophyte dominant → Sporophyte dominant
શૈવાળ સૌથી સાદી, એંગિયોસ્પર્મ્સ સૌથી જટિલ અને સફળ. વાહક પેશી ધીમે ધીમે વિકસિત થાય છે.
Evolutionary sequence: Algae → Bryophytes → Pteridophytes → Gymnosperms → Angiosperms
શૈવાળસૌથી સાદી — થાલસ શરીર, જળાશયી
બ્રાયોફાઇટ્સપ્રથમ સ્થલચર છોડ — પણ પાણી જરૂરી
પ્ટેરિડોફાઇટ્સપ્રથમ વાહક પેશીયુક્ત છોડ
જાઈમનોસ્પર્મ્સપ્રથમ બીજધારી છોડ — પણ ખુલ્લા બીજ
એંગિયોસ્પર્મ્સપ્રથમ ફળ અને પુષ્પ ધરાવતી છોડ
📝 📝 GUJCET में Evolution का क्रम पूछते हैं — याद रखो: Algae → Bryo → Pteri → Gymno → Angio
📋 યાદ રાખવાના મુખ્ય તફાવતો (Comparison)
શૈવાળ vs બ્રાયોફાઇટ્સ: શૈવાળમાં જડ/દંડ/પર્ણ નથી, બ્રાયોફાઇટ્સમાં થોડું સરળ અંગીકરણ.
બ્રાયોફાઇટ્સ vs પ્ટેરિડોફાઇટ્સ: બ્રાયોફાઇટ્સમાં વાહક પેશી નથી, પ્ટેરિડોફાઇટ્સમાં Xylem અને Phloem બંને છે.
જાઈમનોસ્પર્મ્સ vs એંગિયોસ્પર્મ્સ: જાઈમનોસ્પર્મ્સમાં ખુલ્લા બીજ, એંગિયોસ્પર્મ્સમાં આવરિત બીજ + ફળ.
🔑 Gymnosperms में no fruit — Angiosperms में fruit present (ovary matures into fruit)
સારાંશ કોષ્ટક: Kingdom Protista → Kingdom Plantae → 5 divisions: Thallophyta, Bryophyta, Pteridophyta, Gymnosperms, Angiosperms
