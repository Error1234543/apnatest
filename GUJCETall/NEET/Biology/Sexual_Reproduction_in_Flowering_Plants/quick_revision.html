ફૂલવાળા છોડમાં લિંગી પ્રજનન — ક્વિક રિવિઝન

🧪 GUJCET — Gujarati • Biology • Sexual Reproduction in Flowering Plants

🧠 યાદ રાખો

ફૂલ એ છોડનું અંગૂઠું (inflorescence) નહીં, પણ પ્રજનન અંગ છે; ફૂલના તળિયે સ્ત્રાવ (receptacle/thalamus) હોય છે.
પુંકેસર (Androecium) = સ્તંભ (stamen) = અનુસાર (filament) + પરાગકોશ (anther); દરેક પરાગકોશમાં ૪ પરાગકોષકોશ (microsporangia) હોય છે.
પરાગકોષકોશની પેરાડિક્સ (tapetum) પોષક આપે છે અને પરાગદાણા પર પરાગરેત (pollenkallazin) બનાવે છે.
પરાગદાણા (pollen grain) = જનક (generative) + અંતઃકોષ (tube cell); બહિર્કોષ (exine) સ્પોરોપોલેનિનનું બનેલું હોય છે — સૌથી અધૌષણીય પદાર્થ.
અંડકોષકોશ (ovule) = અંડક (ovule body) + નિવાહ (integument) + અંડરંધ્ર (micropyle) + અંડસ્થળ (chalaza).
મેગાસ્પોરોજેનિસિસ: અંડકોષકમાં માત્ર એક મેગાસ્પોરોસિટ (megaspore mother cell) અર્ધસૂત્રણ પામે છે → ૪ મેગાસ્પોરો બને છે, જેમાંથી ૩ વિઘટિત થાય છે.
એંબ્રિયો સેક (embryo sac) = ૭ કોષીય / ૮ ન્યુક્લિયસ યુક્ત (7-celled, 8-nucleate) ગેમેટોફાઇટ.
એંબ્રિયો સેકમાં: ૩ વહીન કોષો (antipodals), ૨ સહાયક કોષો (synergids), ૧ અંડકોષ (egg), ૧ કેન્દ્રક (central cell with ૨ ધ્રુવકેન્દ્રો).
દ્વિ-નિષેચન (double fertilisation) એ ફક્ત આવૃતબીજી છોડમાં જ જોવા મળે છે — એક સ્પર્મ + અંડકોષ = ઝાયગોટ (2n); બીજો સ્પર્મ + ૨ ધ્રુવકેન્દ્રો = ત્રિગુણક અંડકજ (3n endosperm).
અંડકજ (endosperm) પ્રથમ ત્રિગુણક (3n) હોય છે; ઝાયગોટ દ્વિગુણક (2n) હોય છે.
બીજ (seed) = ભ્રૂણ + અંડકજ + બીજકવચ (seed coat); ફળ (fruit) = પકવેલા અંડકોષક (ovary) નું રૂપાંતર.

⚡ ઝડપી સૂત્રો

અંડકજ (endosperm) = 3n (ત્રિગુણક); ઝાયગોટ = 2n (દ્વિગુણક); એંબ્રિયો સેક = 7 કોષીય / 8 ન્યુક્લિયસ.
પરાગકોષકોશમાં: 1 મેગાસ્પોરોસિટ → અર્ધસૂત્રણ → 4 મેગાસ્પોરો (3 વિઘટિત, 1 સક્રિય).
એંબ્રિયો સેકનું ન્યુક્લિયસ વિભાજન: 3 વાર પૂર્વસ્થ (pre-nuclear) વિભાજન → 8 ન્યુક્લિયસ → કોષદીવાલ રચના → 7 કોષો.
અંડકજનું પ્રકાર: ન્યુક્લિયર (nuclear type), સેલ્યુલર (cellular type), એંબ્રિયોએન્ડ (embryo-end).
ફળ પ્રકાર: સત્તવ ફળ (true fruit = ovary), આભાસી ફળ (false/pseudocarp = thalamus સહિત).

✅ વન-લાઈનર્સ

પરાગરજ (pollen grain) નું બહિર્કોષ (exine) સ્પોરોપોલેનિનનું બનેલું હોય છે — બેક્ટેરિયા, ઉષ્મા, રસાયણો પ્રત્યે અતિરેઘટ્ટીય છે.
પરાગરજ અંકુરણ (pollen germination) અંડરંધ્ર (micropyle) થઈને થાય છે.
પરાગરજ અંકુરણ નળી (pollen tube) અંડકોષક (ovule) માં પ્રવેશે છે.
પરાગરજ અંકુરણ નળીમાં જનક કોષ વિભાજન પામી ૨ પુરષ ગેમેટ બનાવે છે.
પ્રથમ નિષેચન (primary fertilisation) = સિનેમેગેમી (syngamy) → ઝાયગોટ; બીજું નિષેચન = ટ્રિપલ નિષેચન (triple fusion) → અંડકજ.
અંડકજ (endosperm) ભ્રૂણને પોષણ પૂરું પાડે છે.
અંડકકવચ (seed coat) = બાહ્ય કવચ (testa) + અંતઃકવચ (tegmen).
હિલ (hilum) = બીજ અને અંડકાંશ (funicle) જોડાણ સ્થળ.
એંબ્રિયો = ઝાયગોટમાંથી બને છે; અંડકજ = ત્રિગુણક; બીજકવચ = અંડકકવચ (integument) માંથી.
અપોમિક્સિસ (apomixis) = બીજ રચના વિના નિષેચનની; આ પ્રક્રિયામાં સંતતિ માતાજની જનીનિક રચના ધરાવે છે.
પોલીએમ્બ્રાયોની (polyembryony) = એક બીજમાં એકથી વધુ ભ્રૂણ; સેક્યુલર પોલીએમ્બ્રાયોની (gametophytic) અને સંવહન પોલીએમ્બ્રાયોની (sporophytic) પ્રકારની.
પરાગણ (pollination) પ્રકારો: સ્વપરાગણ (self-pollination), પરપરાગણ (cross-pollination).
પરાગણ માટેના સાધનો: હવા, જળ, કીટકો, પક્ષીઓ, સસ્તન પ્રાણીઓ.
અંડકોષક (ovary) → ફળ; અંડક (ovule) → બીજ; ઝાયગોટ → ભ્રૂણ; અંડકજ → અંડકજ.
અંડકોષક (ovule) નું રૂપાંતર બીજ બનતી વખતે અંડકકવચ (integument) બીજકવચ (seed coat) બને છે.
