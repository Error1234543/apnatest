🎯 પરીક્ષા ટ્રિક્સ

S ફેઝ પહેલાં અને પછી ક્રોમોઝોમની સંખ્યા સમાન રહે છે — ફક્ત DNA નું પ્રમાણ દુગણું થાય છે. ગણતરીમાં 'ક્રોમોઝોમ' અને 'ક્રોમેટિડ' વચ્ચેનો તફાવત યાદ રાખો.
જ્યારે પ્રશ્નમાં G1, S અથવા G2 ફેઝમાં ક્રોમોઝોમ/ક્રોમેટિડ/DNA ની સંખ્યા પૂછેલી હોય.
દા.ત.: 2n = 46 ધરાવતા માનવ કોષમાં S ફેઝ પછી ક્રોમોઝોમની સંખ્યા 46 hi રહે છે, પણ ક્રોમેટિડ 92 અને DNA 4C થાય છે.
Meiosis-I માં સમજૂત ક્રોમોઝોમ (homologous chromosomes) છૂટા પડે છે, Meiosis-II માં સોબતી ક્રોમેટિડ (sister chromatids) છૂટા પડે છે. 'Anaphase' શબ્દ સાંભળતાં બધામાં જ ક્રોમેટિડ છૂટા પડે છે — પણ Meiosis-I Anaphase માં છૂટા પડતાં તેઓ અલગ ક્રોમોઝોમ ગણાતા નથી.
જ્યારે પ્રશ્ન Anaphase-I vs Anaphase-II અથવા ક્રોમોઝોમ વિભાજનની દિશા વિશે પૂછે.
દા.ત.: Meiosis-II ના Anaphase માં 4n થી 2n થાય છે (ક્રોમેટિડ છૂટા પડીને અલગ ક્રોમોઝોમ બને છે). Meiosis-I ના Anaphase માં ક્રોમોઝોમની સંખ્યા ઘટે છે, પણ ક્રોમેટિડ સંખ્યા સ્થિર રહે છે.
Metaphase ની ઓળખ: 'Metaphase Plate' — બધા ક્રોમોઝોમ કોષના મધ્યભાગે (કક્ષાપટ પર) ગોઠવાય. Metaphase-I માં સમજૂત જોડ (bivalent/tetrad) મધ્યમાં ગોઠવાય; Metaphase-II માં અર્ધસૂત્રી ક્રોમોઝોમ મધ્યમાં ગોઠવાય.
જ્યારે પ્રશ્નમાં કોષભંજનનો કઈ કોષિકા (phase) છે તે શોધવાનું હોય અને વિકલ્પોમાં માત્ર વિગતો આપેલ હોય.
દા.ત.: જો ક્રોમોઝોમ કક્ષાપટ પર ન હોય પણ સમજૂત જોડ મધ્યમાં હોય → Metaphase-I; જો ક્રોમેટિડ જોડ મધ્યમાં હોય → Metaphase-II અથવા Metaphase (Mitosis).
Cytokenesis (કોષद्रव્ય વિભાજન) દરમિયાન વનસ્પતિકોષમાં 'cell plate' બને છે, પ્રાણીકોષમાં 'cleavage furrow' બને છે. આ વિકલ્પોમાંથી તરત જ ઓળખી શકાય.
જ્યારે પ્રશ્ન Cytokenesis ના પ્રકાર અથવા કોષનીયાપડ (cell plate) / cleavage furrow વિશે હોય.
દા.ત.: 'Cell plate' → ઉદ્ભિદ કોષ; 'Cleavage furrow' → પ્રાણી કોષ. જો પ્રશ્નમાં માત્ર 'ગુચ્છરજ્જુ' (midbody) હોય તો પ્રાણીકોષ.
બે સમજૂત ક્રોમોઝોમ + ચાર ક્રોમેટિડ = 1 Bivalent (ટેટ્રાડ). પ્રશ્નમાં 'ટૅટ્રાડ' = 'બાયવેલન્ટ' = 'ચાર ક્રોમેટિડ' — આ ત્રણેય શબ્દો એક જ વસ્તુ સૂચવે છે.
જ્યારે પ્રશ્નમાં Meiosis-I ની પ્રોફેઝ-I ના ચોક્કસ ઉપ-પ્રકરણ (stage) વિશે પૂછ્યું હોય.
દા.ત.: Pachytene માં સહસંયોજક પુનર્ગઠન (crossing over) થાય છે → ક્રોમેટિડ વચ્ચે Chiasmata બને છે → આ પછી_diakinesis_માં Chiasmata સ્પષ્ટ દેખાય છે.
Apoptosis (કાર્પણિક કોષમૃત્યુ) programmable અને physiological છે — તેમાં Chromatin contraction, membrane blebbing અને apoptotic bodies બને છે. Necrosis (અકસ્માતજન્ય મૃત્યુ) unpredictable અને pathological છે — તેમાં લાઇસોઝોમલ એન્ઝાઇમ્સ છૂટા પડે છે અને સ્નાયુકોષરસ (cytoplasm) ગળી જાય છે.
જ્યારે પ્રશ્ન કોષમૃત્યુના પ્રકાર અથવા તેના લક્ષણો વિશે હોય.
દા.ત.: જો વિકલ્પમાં 'membrane blebbing', 'chromatin condensation', 'apoptotic bodies' હોય → Apoptosis; જો 'cytoplasmic leakage', 'inflammation', 'lysosomal enzymes release' હોય → Necrosis.
Centromere વિભાજન ફક્ત Anaphase (Mitosis) અને Anaphase-II (Meiosis) માં જ થાય છે. Anaphase-I માં કદી Centromere વહેંચાતું નથી.
જ્યારે પ્રશ્નમાં 'ક્યારે centromere વિભાજન થાય?' અથવા 'Anaphase-I vs Anaphase-II'નો તફાવત પૂછે.
દા.ત.: Anaphase-I → સમજૂત ક્રોમોઝોમ છૂટા પડે, પણ centromere અખંડ રહે; Anaphase-II → centromere વિભાજન પામે અને સોબતી ક્રોમેટિડ છૂટા પડે.
Interphase (G0, G1, S, G2) કોષચક્રનો સૌથી મોટો ભાગ રોકે છે (~90%). જો કોષચક્રની કુલ અવધિ આપેલી હોય તો Interphase = 90% × કુલ અવધિ અંદાજિત કરી શકાય.
જ્યારે ગણતરીનો પ્રશ્ન હોય કે 'અમુક કોષચક્રની અવધિ X કલાક છે, Interphase કેટલી?'
દા.ત.: કુલ 24 કલાકનો કોષચક્ર → Interphase ≈ 21.6 કલાક (≈90%) અને M phase ≈ 2.4 કલાક (≈10%).
G0 ફેઝ = 'વિરામ અવસ્થા' — કોષ સક્રિય રીતે વિભાજન કરતો નથી, પણ જરૂર પડે ત્યારે G1 માં પાછો ફરી શકે છે. Stem cells, તંતુકોષો (fibroblasts) અને હૃદ્‌વાહિકા પરિઘકોષો (pericytes) જેવા કોષો G0 માં રહે છે.
જ્યારે G0 ફેઝના કાર્ય, સ્થિતિ અથવા તેમાં રહેતા કોષો વિશે પૂછે.
દા.ત.: પાચન પ્રણાલીના ઉત્કલનકોષો (epithelial cells) ઝડપથી વિભાજન પામે છે → G0 નથી; જ્યારે સ્નાયુકોષો અને તંતુકોષો મોટા ભાગે G0 માં રહે છે.
CDK (Cyclin-Dependent Kinase) ની સક્રિયતા Cyclin ની સાંદ્રતા પર આધારિત છે — CDK ની સંખ્યા સ્થિર રહે છે, પણ Cyclin ની માત્રા વધઘટ થાય છે. Cyclin-D → G1 phase; Cyclin-E → G1/S સંક્રાંતિ; Cyclin-A → S phase; Cyclin-B → M phase.
જ્યારે Cell cycle regulation અથવા Cyclin-CDK complex ના કાર્ય વિશે પ્રશ્ન હોય.
દા.ત.: જો પ્રશ્નમાં 'કયું Cyclin M phase માં સક્રિય થાય?' → Cyclin-B (અને CDK1). જો 'MPF' (Maturation Promoting Factor) નો ઉલ્લેખ હોય → Cyclin-B + CDK1.
Spindle fibres (કણાસ્પંદી તંતુ) Microtubules થી બનેલી છે (α-tubulin + β-tubulin). Kinetochore microtubules ક્રોમેટિડના Kinetochore સાથે જોડાય છે; Astral microtubules વેલ્કાકાર (aster) બનાવે છે; Polar microtubules ધ્રુવો વચ્ચેની ધરી પર રહે છે.
જ્યારે Spindle fibre નું બંધારણ અથવા તેના પ્રકારો વિશે પૂછે.
દા.ત.: Colchicine → Microtubule polymerization રોકે છે → Spindle બનતું નથી → Metaphase માં જ ક્રોમોઝોમ અટકી જાય છે.
Pachytene દરમિયાન Crossing over થાય છે, પણ Morphologically Chiasmata Diakinesis અને Metaphase-I માં જ દેખાય છે. પ્રશ્નમાં 'ક્યારે Crossing over થાય?' → Pachytene; 'ક્યારે Chiasmata દેખાય?' → Diakinesis/Metaphase-I.
જ્યારે Meiosis-I ની વિવિધ ઉપ-પ્રકરણો (leptotene, zygotene, pachytene, diplotene, diakinesis) નું કાર્ય અથવા લક્ષણ ઓળખવું હોય.
દા.ત.: Leptotene → ક્રોમોઝોમ દેખાય; Zygotene → Synapsis શરૂ; Pachytene → Crossing over; Diplotene → Chiasmata દેખાય; Diakinesis → Nucleolus અને nuclear membrane અંતર્ધ્યાન પામે.
Mitosis માં એક ક્ષણ这样: Prophase → Prometaphase → Metaphase → Anaphase → Telophase. સૌથી પહેલાં Nuclear envelopeનું વિઘટન Prometaphase માં થાય છે અને ક્રોમોઝોમ spindle સાથે જોડાય છે.
જ્યારે પ્રશ્નમાં કોષભંજનના તબક્કાઓનો ક્રમ અથવા કોઈ ચોક્કસ ઘટના ક્યારે થાય છે તે પૂછે.
દા.ત.: ન્યુક્લિયર પડ (nuclear envelope) નું વિઘટન → Prometaphase; Kinetochore spindle સાથે જોડાણ → Prometaphase; ક્રોમોઝોમ કક્ષાપટ પર ગોઠવણી → Metaphase.
અર્ધસૂત્રણ (Meiosis) ને બે પૂર્ણાંક તબક્કાઓમાં યાદ રાખો: Meiosis-I = 'સંખ્યા ઘટે છે' ( Reduction division ); Meiosis-II = 'માઇટોસિસ જેવું' (Equational division).
જ્યારે Meiosis-I અને Meiosis-II વચ્ચેનો મૂળભૂત તફાવત ઝડપથી યાદ કરવો હોય અથવા પ્રશ્નનો સાચો જવાબ પસંદ કરવો હોય.
દા.ત.: Meiosis-I ના અંતે 2n → n થાય (હોમોલોગસ ક્રોમોઝોમ અલગ); Meiosis-II ના અંતે n → n રહે (ક્રોમેટિડ અલગ). એક Meiosis → 4 હેપ્લોઇડ કોષો.
Rb (Retinoblastoma) પ્રોટીન tumor suppressor છે — E2F ને બંધ કરે છે. Cyclin-D/CDK4 phosphorylation થતાં Rb non-active થાય અને E2F મુક્ત થાય → S phase માં પ્રવેશ. Rb gene mutation →uncontrolled cell division → retinoblastoma.
જ્યારે Cell cycle checkpoints અથવા cancer biology સાથે જોડાયેલો પ્રશ્ન આવે.
દા.ત.: G1 checkpoint → Rb-E2F માર્ગ; G2 checkpoint → Cyclin-B/CDK1; M checkpoint → Spindle assembly checkpoint (SAC).
