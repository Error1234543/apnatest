GUJCET — ફૂલવાળા છોડની રચનાવિદ્યા (Anatomy of Flowering Plants) : ત્વરિત ઉકેલ ટ્રિક્સ

🧪 GUJCET — Gujarati • Biology • Anatomy of Flowering Plants

🎯 પરીક્ષા ટ્રિક્સ

અપિકલ (Apical) vs સેકન્ડરી (Secondary) વૃદ્ધિ — ઝટપટ ઓળખ:
જ્યારે પ્રશ્નમાં 'લંબાઈ વૃદ્ધિ' કે 'ઘાટી વૃદ્ધિ' વિશે પૂછાય અને કોષકેન્દ્રગ્રંથિ (Meristem) નો પ્રકાર પસંદ કરવાનો હોય.
દા.ત.: શાખા અને મૂળની લંબાઈ વધારવી = અપિકલ અંકુરકલા (Apical meristem); લંબાઈ વધારવી = બાદબાકિ સંયુક્ત અંકુરકલા (Intercalary meristem); ત્રિજ્યાવાડો = પાર્શ્વીય અંકુરકલા (Lateral meristem). 'લંબાઈ' શબ્દ દેખાય → Apical/Intercalary; 'ઘાટી/ત્રિજ્યા' શબ્દ દેખાય → Lateral.
સરળ (Simple) vs જટિલ (Complex) સદ્ભાસ્કરિકા — કોષવર્ણ/કાર્ય આધારિત કટોકટી ઉન્મૂલન:
જ્યારે ચારો વિલકૌતિક વિકલ્પોમાંથી સાચો જોડાણ જોડવો હોય.
દા.ત.: સરળ: એક જ પ્રકારના કોષ → પરિડર્મ (Epidermis), મેલેંકાઈમ, પેરાન્કાઈમ, કોલેંકાઈમ, સ્કલેરેંકાઈમ. જટિલ: બહુવિધ કોષ + ચાલક કાર્ય → ક્ષૈરાંગ (Xylem) અને પાઈથોંગ (Phloem). જો કોઈ વિકલ્પમાં 'એક્ટ્સિલમ = simple' અથવા 'ક્ષૈરાંગ = complex નથી' એમ લખેલું હોય → તરત ખોટું.
બીજદળી (Dicot) vs એકદળી (Monocot) મૂળ ક્રોસ-સેક્શન ઝડપી ઓળખ:
AB-type / CD-type પ્રશ્નમાં ક્રોસ-સેક્શન આપેલું હોય અને પરમાણુ/સ્થળ ઓળખવું હોય.
દા.ત.: બીજદળી મૂળ: ਕેશ (Casparian) પટ્ટીવાળું એન્ડોડર્મિસ, વડલીય (Radial) ક્ષૈરાંગ-પાઈથોંગ ગોઠવણી, કેન્દ્રમાં નાનું કે બિન-હોવાતું પાઈથ, ફ્લોએમ વચ્ચે કેલ (Cambium) હોઈ શકે. એકદળી મૂળ: કેન્દ્રમાં મોટું પાઈથ, ક્ષૈરાંગ અને પાઈથોંગનાં પાંચ/આઠ ભુજાઓ, એન્ડોડર્મિસ મજબૂત. 'વડલી ગોઠવણી' જોવા મળે → Dicot root; 'મોટું કેન્દ્રીય પાઈથ' જોવા મળે → Monocot root.
બીજદળી vs એકદળી તંતુ (Stem) — ફક્ત બે નિદાન લક્ષણો:
તંતુનાં ક્રોસ-સેક્શન આપેલ હોય અને બીજદળી/એકદળી પહચવાની હોય.
દા.ત.: બીજદળી તંતુ: સંયુક્ત વહન પેશીઓ (Vascular bundles) વલયાકાર ગોઠવાયેલી, બહારથી અંદર કોર્ટેક્સ → એન્ડોડર્મિસ → પેરિસાયકલ → વહનપેશીઓ. એકદળી તંતુ: વહનપેશીઓ વંધ્યરૂપે વિખેરાયેલી, કોર્ટેક્સ/એન્ડોડર્મિસ/પેરિસાયકલની સ્પષ્ટ સીમા નથી, મધ્યમાં મોટું પાઈથ. 'વહનપેશીઓ રિંગમાં' = Dicot stem; 'વહનપેશીઓ અસ્પષ્ટ/વિખેરાયેલી' = Monocot stem.
ડોરિસિવેન્ટ્રલ (Dorsiventral) vs આઈસોબેલેટ્રલ (Isobilateral) પર્ણ — ઝટ ઓળખ:
પર્ણનાં લંબકાટિછેદ પર કોષવિન्याસ/ઉપરી-અધોચર્મ પહેચવું હોય.
દા.ત.: ડોરિસિવેન્ટ્રલ (બીજદળી): ઉપરી ચર્મ પર પેલેઇસાડ મેસોફિલ (સ્તંભાકાર), અધોચર્મ પર સ્પંજીય મેસોફિલ (વિષમકોષી), મોટા સ્ટોમેટા. આઈસોબેલેટ્રલ (એકદળી): બંને ચર્મ પાસે સમાન મેસોફિલ, સ્ટોમેટા બંને બાજુએ, હોર્ઝ ક્ષૈરાંગ-પાઈથોંગ. 'પેલેઇસાડ vs સ્પંજીય' અલગ હોય → Dorsiventral; 'સમાન મેસોફિલ' → Isobilateral.
પેરિડર્મ (Periderm) બનતી કઈ અંકુરકલાથી — એક શબ્દ યાદ રાખો:
કાષ્ઠીય (Woody) સ્ટેમમાં ઇપિડર્મિસ/કોર્ટેક્સ બદલાઈને જે પેશી બને તેનો પ્રશ્ન આવે.
દા.ત.: ફેલોજન (Phellogen) = કોર્ક કૅમ્બિયમ; તે ઉભયમુખી છે. બહાર તરફ ફેલમ (ઉપચર્મ/કોર્ક), અંદર તરફ ફેલોડર્મ (અન્તઃઉપચર્મ). પ્રશ્નમાં 'કઈ અંકુરકલા ફેલોજન બનાવે?' → Phellogen; 'ફેલમ દ્વારા બચાવ' → Cork protection. 'સેકન્ડરી ફેલોજન' શબ્દ જોવા મળે → Periderm formation.
ક્ષૈરાંગનાં ઉષ્ણકોષીય vs અશીતકોષીય તંતુ — દૃશ્ય ટ્રિક:
ક્ષૈરાંગનાં ઘટકોને ઓળખવાના પ્રશ્નમાં સંદર્ભ આપેલ હોય.
દા.ત.: ક્ષૈરાંગ: પાઇપ-આકારના વાહિકાઓ (Tracheids/Vessels), ધાતુકોષ (Sclerenchyma fibers), મેલેંકાઈમ. તંતુ (Fibers): મૃત કોષ, ભરપૂર લિગ્નિન, મજબૂત ટેકો. જો વિકલ્પમાં 'વર્દ્ધિક (Accessory) કોષ/Companion cell' ક્ષૈરાંગમાં મુક્યું હોય → તરત ખોટું (Companion cell ફ્લોએમમાં હોય).
સિવ ટ્યુબ (Sieve tube) vs કમ્પેનિયન સેલ (Companion cell) — 'ફ્લોએમ' માત્ર:
ફ્લોએમના ઘટકો સંબંધી ઝડપી પ્રશ્ન (PYQ-style).
દા.ત.: સિવ ટ્યુબ: જીવંત, ન્યુક્લિયસ-વિહીન, સિવ પ્લેટ (Sieve plate) સાથે, ફક્ટર ડાયનેમિક. કમ્પેનિયન સેલ: જીવંત, પૂરું ન્યુક્લિયસ, મેટાબોલિક આધાર. જો વિકલ્પ 'સિવ ટ્યુબમાં ન્યુક્લિયસ હોય' અથવા 'કમ્પેનિયન સેલ મૃત હોય' → ખોટું. બંને ફક્ત ફ્લોએમ (Phloem) માં જ. વહેલા ઉન્મૂલન કરો.
એન્ડોડર્મિસનો C-shape/casparian strip — રૂટ vs સ્ટેમ ભેદ:
સંયુક્ત વહનપેશી અને એન્ડોડર્મિસ સંબંધી પ્રશ્નમાં.
દા.ત.: મૂળમાં એન્ડોડર્મિસ C-আકારના Casparian strips ધરાવે છે, જે પોલાણ દ્વારા પાણીનું ચોક્કસ નિયંત્રણ કરે. તંતુમાં એન્ડોડર્મિસ ઓછું સ્પષ્ટ/અવ્યવસ્થિત. જો 'Casparian strip' નો ઉલ્લેખ હોય → મૂળ; 'સ્ટ્રિપ અસ્પષ્ટ' → તંતુ.
હાર્ડવૂડ vs સોફ્ટવૂડ (Hardwood/Softwood) — કાષ્ઠની ઓળખ ટ્રિક:
કાષ્ઠ (Wood) સંબંધી પ્રશ્ન, ખાસ કરીને વર્ષીય વલય (Annual ring) અને ક્ષૈરાંગ ઘટકો.
દા.ત.: હાર્ડવૂડ (બીજદળી દારૂ): વધુ સ્કલેરેંકાઈમ, વૃક્ષના વલય સ્પષ્ટ, વર્ષીય વલયમાં પ્રારંભિક (Early) અને અંતિમ (Late) કાષ્ઠ. સોફ્ટવૂડ (એકદળી/ગાયનોજર્મ): મુખ્યત્વે ટ્રેઇકિડ્સ, વર્ષીય વલય ઓછું સ્પષ્ટ. 'સ્કલેરેંકાઈમ વધારે' = Hardwood; 'ટ્રેઇકિડ્સ પ્રબળ' = Softwood.
ક્ષૈરાંગ-પાઈથોંગ ગોઠવણી (બીજદળી મૂળ) — 'તારા+' યાદ ગીત:
મૂળના ક્રોસ-સેક્શનમાં ક્ષૈરાંગ/પાઈથોંગની સ્થિતિ ઝડપથી ઓળખવી હોય.
દા.ત.: બીજદળી મૂળ: ક્ષૈરાંગ તારા-આકાર (Radial star) મધ્યમાં, પાઈથોંગ તારાની ભુજાઓ વચ્ચે. એકદળી મૂળ: મધ્યમાં મોટું પાઈથ, ક્ષૈરાંગ-પાઈથોંગ એકબીજાની આસપાસ ગોઠવાયેલા. 'તારું + ભુજા' શબ્દ મનમાં ઊભો કરો: તારું = Xylem, ભુજા = Phloem between arms.
પાર્શ્વીય અંકુરકલા (Lateral meristem) ફક્ત બે — અન્ય સંબંધી ગેરમાર્ગે દોરતાં વિકલ્પ ઓળખો:
વિકલ્પી પ્રશ્નમાં 'કઈ અંકુરકલા સેકન્ડરી વૃદ્ધિ કરે છે?' જેવો પ્રશ્ન આવે.
દા.ત.: ફક્ત બે જ: વેસિક્યુલર કૅમ્બિયમ (Vascular cambium) અને ફેલોજન (Phellogen/Cork cambium). અપિકલ/ઇન્ટરકેલેરી → એપિકલ/ઇન્ટરકેલેરી જ રહે છે. 'ફેલોજન = cork cambium', 'વેસિક્યુલર = vascular'. જો વિકલ્પમાં 'આપિકલ', 'ઇન્ટરકેલેરી', 'પ્રાઇમરી' સેકન્ડરી તરીકે આપેલ હોય → ખોટું.
