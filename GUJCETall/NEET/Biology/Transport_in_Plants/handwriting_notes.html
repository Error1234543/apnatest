પ્રવાહી પરિવહન (Transport in Plants)

🧪 GUJCET — Gujarati • Biology • Transport in Plants

પરિચય : વનસ્પતિઓમાં પદાર્થોનું પ્રવાહ
વનસ્પતિમાં જળ, ખनिज પદાર્થો અને જટિલ કાર્બનિક પદાર્થોના સ્થાનાંતરને પરિવહન કહે છે.
આંતરકોષીય પરિવહન માટે મુખ્ય રસ્તાઓ : પ્લાઝમા પટલ, અંતઃકોષરસજાળ (Symplast), અવકાશીય અંતરાળ (Apoplast).
કોષપટલ વડે પરિવહન (Transport Across Cell Membrane)
પ્લાઝમા પટલ (Plasma Membrane) ચયક ભેદ્ય (Selectively Permeable) હોય છે.
પટલ બે વિધાનો ધરાવે છે : 1) લિપિડ બાયલેયર 2) સપાટી પ્રોટીન.
જળ-દ્રાવ્ય પદાર્થો પ્રોટીન ચેનલ દ્વારા પસાર થાય છે; ચર્બી-દ્રાવ્ય પદાર્થો લિપિડ બાયલેયરમાંથી પસાર થાય છે.
પટલની ચયક ભેદ્યતા જૈવિક પરિવહનનું મૂળભૂત સિદ્ધાંત છે.
📝 ગુજરાતીમાં : પ્લાઝમા પટલ = પ્લાઝમેમબ્રેન
પ્લાઝમોડેઝમاتا અને તેમનો રોલ
સજીવ કોષો વચ્ચે પ્લાઝમોડેઝમاتا (Plasmodesmata) નામના સૂક્ષ્મ સેતુઓ જોવા મળે છે.
આ સેતુઓ અંતઃકોષરસજાળ (Symplast) માટે જળ સંપર્ક પૂરો પાડે છે.
Apoplast = કોષદીવાલ અને કોષાંતર રસધાર વચ્ચેનો ભાગ.
Symplast = પ્લાઝમા પટલની અંદરનું જીવંત અંતઃકોષરસ અને પ્લાઝમોડેઝમاتا.
Apoplast Pathway ≠ Cell Cytoplasm Symplast Pathway = Continuously Connected Cytoplasm
સરળ પ્રસરણ (Simple Diffusion)
ઉચ્ચ સાંદ્રતા ધરાવતા ક્ષેત્રથી નીચી સાંદ્રતા ધરાવતા ક્ષેત્ર તરફ દ્રાવ્ય/વાયુના અણુઓનો ચાલ છે — પ્રસરણ.
પ્રસરણ સક્રિય શક્તિ (ATP) વિના થાય છે → નિષ્ક્રિય પરિવહન.
CO₂, O₂ જેવા ગેસો સરળ પ્રસરણ દ્વારા પ્રવેશે છે.
Net Diffusion Rate ∝ Concentration Gradient (ΔC)
📝 પ્રસરણનો દર વધે છે જ્યારે તાપમાન, અણુનું કદ ઓછું અને સાંદ્રતા અંતર વધે.
પર્યાવરણોષ્ણ (Osmosis)
અર્ધભેદ્ય પટલ (Semipermeable Membrane) થકી દ્રાવક (પાણી) નું ઉચ્ચ જલસ્થિતિભાવવાળા ક્ષેત્રથી નીચા જલસ્થિતિભાવવાળા ક્ષેત્ર તરફ વહન.
ઓસ્મોસિસ માત્ર દ્રાવક (પાણી) માટેજ લાગુ પડે છે, દ્રાવ્ય માટે નહીં.
પાણીની ચાલ ત્રણ બાબતો પર આધારિત છે : 1) દ્રાવણ કેન્દ્રિત્વ 2) દબાણ 3) તાપમાન.
જલસ્થિતિભાવ (Water Potential – Ψw)
Ψw = Ψs + Ψp Ψs = સોલ્યુટ પોટેન્શિયલ (ઋણ) Ψp = પ્રેશર પોટેન્શિયલ (ધન)
સ્વચ્છ પાણીનું Ψw = 0 (શૂન્ય). દ્રાવ્ય ઉમેરતા Ψs ઋણ બને છે.
ઉચ્ચ Ψw ધરાવતું દ્રાવણ = ક્ષારહીન/ધુળું; નીચા Ψw = મોટું ક્ષારકેન્દ્રિત (Hypertonic).
📝 ગુજરાતીમાં : Water Potential = જલસ્થિતિભાવ
બાહ્યવહન (Exosmosis) અને અંતર્વહન (Endosmosis)
Exosmosis : જ્યારે કોષને hypertonic દ્રાવણમાં મૂકવામાં આવે, ત્યારે પાણી કોષની બહાર નીકળે છે.
Endosmosis : જ્યારે કોષને hypotonic (વધુ પાણીવાળા) દ્રાવણમાં મૂકવામાં આવે, ત્યારે પાણી કોષમાં પ્રવેશે છે.
Endosmosis ના કારણે જ મૂળની જડબા (Root Hair) પાણી શોષે છે.
વિષ્કંભ (Plasmolysis)
જીવંત સમસ્થિતિકોષીય વનસ્પતિ કોષને hypertonic દ્રાવણમાં મૂકતા, પ્લાઝમા પટલ કોષદીવાલથી છૂટા પડે છે.
આ પ્રક્રિયાને વિષ્કંભ (Plasmolysis) કહે છે.
વિષ્કંભના તબક્કા : પ્રારંભિક વિષ્કંભ (Initial) → પૂર્ણ વિષ્કંભ (Complete).
તણાવ દબાણ (Turgor Pressure, TP) + ક્ષાર દબાણ (OP) = ભાગભાવ દબાણ (DP)
📝 Plasmolysis = વિષ્કંભ, Turgor = ફુગ્ગા દબાણ
ક્ષાર દબાણ (Osmotic Pressure)
જ્યારે બે દ્રાવણો અર્ધભેદ્ય પટલ દ્વારા જોડાયેલા હોય, ત્યારે ઓછી સાંદ્રતાવાળા દ્રાવણમાંથી વધુ સાંદ્રતાવાળા દ્રાવણમાં જતા પાણીને અટકાવવા જરૂરી એટલું બાહ્ય દબાણ.
ક્ષાર દબાણ (OP) = તાપમાન, અણુ સંખ્યા, દ્રાવ્ય પ્રકાર પર આધારિત.
π = iCRT i = van't Hoff factor C = મોલર સાંદ્રતા
અવશોષણ (Imbibition)
ઘન પદાર્થો (Hydrophilic colloids) પાણી શોષીને ફૂલે છે → આ પ્રક્રિયા અવશોષણ છે.
અવશોષણ દરમિયાન ઉષ્મા ઉત્પન્ન થાય છે અને ઘનફલ વધે છે.
અવશોષણ દબાણ (Imbibition Pressure) → મળીને જીવાણુજન્ય પર્યાવરણોષ્ણ (Matric Potential) ની રચના કરે છે.
ઉદાહરણ : બીજને પાણી આપતાં તે ફૂલે છે.
મૂળના જળાવશોષણની રીતો
1. સક્રિય (Active) અને નિષ્ક્રિય (Passive) રીતો. 2. જલસ્થિતિભાવના તફાવતથી પાણીનું કોષમાં પ્રવેશ.
જડબા (Root Hair) નું ક્ષેત્રફળ વધારે હોવાથી પાણીનું સોષણ વેગવંતું થાય છે.
📝 Passive uptake = જલસ્થિતિભાવ ગ્રેડિયન્ટ દ્વારા
પ્રસરણ દબાણ (Diffusion Pressure Deficit - DPD)
DPD = OP - TP (ક્ષાર દબાણ - તણાવ દબાણ)
જ્યારે કોષ પૂર્ણ ફુગ્ગો હોય (Turgid), ત્યારે TP = OP અને DPD = 0.
વધુ DPD ધરાવતું કોષ પાણી ખેંચે છે.
વાહિકા પેરેંકાયમા અને પેરેંકાયમા
પેરેંકાયમા (Parenchyma) : મૂળભૂત પેશી.
વાહિકા પેરેંકાયમા (Transfer cells) : પાણી/ખનીજ સંચાલનમાં મદદરૂપ.
પ્રસારણ (Transpiration) : પરિભાષા અને પ્રકાર
પાણીનું વરાળ સ્વરૂપે વનસ્પતિ પરથી બાષ્પીભવન.
પ્રકાર : 1) ભૌમિતિક (Stomatal) ~90% 2) છાલિકા (Cuticular) 3) અંતઃકોષીય (Lenticular).
ભૌમિતિક પ્રસારણ સતત થાય છે અને સ્ટોમેટા દ્વારા નિયંત્રિત થાય છે.
Transpiration Rate ∝ (Vapor Pressure Gradient) ∝ Wind Speed ∝ Surface Area
સ્થાનિક પ્રસારણ માટેના અંગો
ભૌમિતિક (Stomata) : પોલીના અને કવરોસિટા (Guard cells) ધરાવે છે.
કવરોસિટામાં ક્લોરોપ્લાસ્ટ હોય છે અને starch/sugar ના આંતરરૂપાંતરણથી ખુલે/બંધ થાય.
📝 Closing of Stomata at Night prevents excess water loss.
પ્રસારણ-કણન્ટ અને સંલગ્નતા-તણાવ સિદ્ધાંત (Cohesion-Tension Theory)
એ.સી. મેલવિક (E.C. Zimmermann) દ્વારા સુચવેલ સિદ્ધાંત.
1) Xylem માં જળ અણુઓ વચ્ચે સંલગ્નતા (Cohesion) અને સંસંજન (Adhesion) હોય છે. 2) પ્રસારણ દ્વારા બાષ્પીભવનથી ટ્રેક્ટિલ ટેન્શન (તણાવ) ઉભરાય છે. 3) આ તણાવ પાણીને ઉપર ઊંચકે છે.
સંચાલન (Translocation) : FLOEM નું સંચાલન
પર્ણમાં બનેલા શર્કરાદ્રવ્યને વનસ્પતિના અન્ય ભાગોમાં પહોંચાડવાની પ્રક્રિયા.
ફ્લોઈમ (Phloem) > સીવ સ્નાયુ (Sieve tube) > સહાયક કોષ (Companion cell).
Münch Pressure-Flow Hypothesis : પ્રવાહ દબાણ તફાવત પર આધારિત છે.
Source (Leaf) -> High Osmotic Pressure Sink (Root/Fruit) -> Lower Osmotic Pressure
📝 Translocation = સંચાલન, Phloem = ફ્લોઈમ પેશી
સક્રિય પરિવહન (Active Transport)
ATP (Adenosine Triphosphate) નો ઉપયોગ કરીને આયનોને ગ્રેડિયન્ટ વિરુદ્ધ પરિવહિત કરવું.
પ્રોટોન પંપ (Proton Pump) દ્વારા H⁺ નું સ્રાવ.
Na⁺/K⁺ Pump (Animals) H⁺ Pump (Plants) : ATP -> ADP + Pi + Energy
મૂળ દબાણ (Root Pressure)
મૂળ ખેંચ (Root Pull) કરતાં ઉત્પન્ન થતું ધન દબાણ.
બેકા (Guttation) દરમિયાન બિંદુઓ દ્રવ્યની બરોબરી થાય છે.
Root Pressure alone cannot explain water ascent to great heights.
📝 Guttation = બેકા દ્રવ્યરૂપે જળબિંદુઓનું નિર્ગમન
કોષભાવ અને દબાણ (Turgor and Wall Pressure)
કોષ પાણીથી ભરાય છે ત્યારે કોષદીવાલ દબાણ (Wall Pressure) થાય છે.
TP + WP = 0 (At equilibrium)
ફુગ્ગા કોષ (Turgid Cell) : કોષદીવાલથી ચાપ.
વાહિકાના પ્રકાર અને રચના
ખાંડ (Xylem) : Tracheids, Vessels, Xylem parenchyma, fibers.
ફ્લોઈમ (Phloem) : Sieve tubes, Companion cells, Phloem parenchyma, fibers.
ખાંડ મૃત પેશી છે; ફ્લોઈમ જીવંત પેશી છે.
અવયવ-વિશિષ્ટ પરિવહન (Special Cases)
Euphratia : સિંચાઈ વિના પણ ઓસ્મોસિસ દ્વારા શોષણ.
Parasitic plants : haustoria દ્વારા પોષક તત્વો શોષે છે.
Matric Potential (Ψm) < 0 Osmotic Potential (Ψs) < 0
📝 Haustoria = શોષક તંતુ, Parasitic = પરોपोधी
વાતાવરણીય પરિબળો અને પ્રસારણ
તાપમાન વધે → પ્રસારણ દર વધે.
હવામા વરાળ ક્ષાર ઓછું હોય → પ્રસારણ વધુ.
પવન વેગ વધે → boundary layer thin → પ્રસારણ દર વધે.
વનસ્પતિનું ગરમી પ્રબંધન (Thermoregulation)
પ્રસારણ દ્વારા વનસ્પતિ ઠંડી રહે છે.
Evaporative cooling helps maintain optimum temperature.
📝 Transpiration = Cooling effect, નહીં કે ફક્ત જળક્ષય
રસ સંચાલન માટે માર્ગ
અંતઃકોષરસજાળ (Symplast) માર્ગ : કોષ દીવાલોમાંથી પસાર થઈને.
અવકાશીય માર્ગ (Apoplast) : કોષદીવાલ અને વચ્ચેનો ભાગ.
ગંતવ્ય-કેન્દ્ર (Sink) અને મૂળ (Source)
Source = પર્ણ (પ્રકાશસંશ્લેષણ દ્વારા શર્કરા બનાવે છે).
Sink = ફળ, બીજ, મૂળ (શર્કરાનો સંગ્રહ/ઉપયોગ).
Mass Flow : Source -> Sink (Phloem Loading / Unloading)
📝 Loading/Unloading = આંતરિક ભારણ/વેડફણ
સારાંશ અને મહત્વના નિષ્કર્ષ
વનસ્પતિ પરિવહન ત્રણ મુખ્ય પ્રક્રિયાઓ પર આધારિત છે : પ્રસરણ, પ્રસારણ, સંચાલન.
ગુજરાતીમાં અભ્યાસક્રમમાં ઉપરોક્ત તમામ શબ્દો અને સિદ્ધાંતો આવરી લેવામાં આવ્યા છે.
