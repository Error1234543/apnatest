કોષ — જીવનનો મૂળભૂત એકમ: પરીક્ષા ચેતક્ટ્રિ ટ્રિક્સ

🧪 GUJCET — Gujarati • Biology • Cell — The Unit of Life

🎯 પરીક્ષા ટ્રિક્સ

જો પ્રશ્નમાં "કોષનો સૌથી મોટો/સૌથી નાનો" શબ્દપ્રયોગ હોય, તો તરત જ યાદ કરો: પક્ષીઓનો અંડકોષ (શુકતુર્કી) સૌથી મોટો અને માઇકોપ્લાઝમા સૌથી નાનો કોષ છે.
કોષના આકાર અને કદ વિશેના ગુણોત્તર / સરવાળો પ્રશ્નોમાં, જ્યાં વિકલ્પોમાં અનેક કોષોના નામ હોય.
દા.ત.: પ્રશ્ન: ભારતમાં આવેલો સૌથી નાનો કોષ કયા સજીવનો છે? → યાદ રાખો: માઇકોપ્લાઝમા (પ્રોટીન-સર્વાઇવિંગ સૌથી નાનો કોષ).
"ઇલેક્ટ્રોન માઇક્રોસ્કોપ" એટલે ઉલ્ટાક્ષર (UPTO) ઇમેજ — જ્યાં તમને સૌચક્ષમી (Ultrastructure) જોઈતી હોય ત્યાં તે જ સરાય છે. 'ફ્લુઈડ મોઝેક મોડેલ' એ સિંગર અને નિકલ્સન (1972) નું છે, રોબર્ટસનનું નહીં.
કોષિક પટલનું મોડેલ / માઇક્રોસ્કોપના પ્રકાર વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: પ્રવાહી-મોઝેક કોષિક પટલ મોડેલ કોણે પ્રસ્તાવિત કર્યું? → વિકલ્પોમાં 'રોબર્ટસન' નામે હોય તો તે ખોટો છે, સાચો: સિંગર અને નિકલ્સન.
પ્રોકેર્યોટિક કોષમાં 'ન્યુક્લીયોઇડ' (કોષકેન્દ્રના વિસ્તારનો) હોય છે, 'ન્યુક્લિયસ' નહીં. જે વિકલ્પમાં 'ન્યુક્લિયસ' કહેવાયું હોય — તરત બહાર. પ્રોકેર્યોટમાં કોષકેન્દ્ર કવચ (Nuclear membrane) પણ નથી હોતું.
પ્રોકેર્યોટ અને યુકેર્યોટ કોષ વચ્ચેના તફાવત પૂછતા પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: પ્રોકેર્યોટિક કોષમાં કયું સ્ટ્રક્ચર ગેરહાજર છે? → 'કોષકેન્દ્ર કવચ' એ સાચો જવાબ. જો વિકલ્પમાં 'નાઇટ્રોજનબેઝ', 'RNA' જેવું હોય તો તે પ્રોકેર્યોટમાં હોય છે.
કોષિક અંગિકાઓના કાર્ય પરથી વિકલ્પો દૂર કરો: 'ATP નિર્માણ' → માઇટોકોન્ડ્રિયન; 'પ્રોટીન સંશ્લેષણ' → રાફ ER / રાયબોઝોમ; 'પેકેજિંગ / સ્રાવ' → ગોલ્જી; 'સ્વયંઉચ્છદન' → લાઇસોઝોમ.
અંગિકા અને તેના કાર્યને જોડતા પ્રશ્નોમાં, જ્યાં ચારેય વિકલ્પો પરસ્પર ભિન્ન હોય.
દા.ત.: પ્રશ્ન: કોષનું 'શ્વસન કેન્દ્ર' કયું અંગિકા છે? → વિકલ્પો: રાયબોઝોમ, ગોલ્જી, લાઇસોઝોમ, માઇટોકોન્ડ્રિયન. AT Pતૃતિક સંશ્લેષણ માઇટોકોન્ડ્રિયનમાં થાય છે.
પોષકોષ દીવાલ (Cell wall) બનાવતી જટિલશર્કરા:植物 = સેલ્યુલોઝ, ફૂગ = કાઇટિન, બેક્ટેરિયા = પેપ્ટિડોગ્લાયકેન. આ ત્રણેય જોડી યાદ રાખો.
કોષિક દીવાલની રચના વિશેના પ્રશ્નોમાં — ખાસ કરીને પાદપ vs પરોપજીવી/ફૂગ.
દા.ત.: પ્રશ્ન: સેલ્યુલોઝથી બનેલી કોષ દીવાલ કયામાં મળે છે? → યાદ રાખો: ફક્ત પાદપકોષમાં. ફૂગમાં કાઇટિન, બેક્ટેરિયામાં પેપ્ટિડોગ્લાયકેન.
પ્લાઝ્મોડેસ્મેટા (પાદપ) vs ડેસ્મોઝોમ / ગેપ જંક્શન (પ્રાણી) — પ્રશ્નમાં 'કોષીય સંપર્ક' / 'સંચાર' હોય તો પાદપનો ઉલ્લેખ હોય તો પ્લાઝ્મોડેસ્મેટા, પ્રાણીનો હોય તો ડેસ્મોઝોમ.
સેલ જંક્શન અથવા કોષો વચ્ચેનો સંચાર પૂછતા પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: પાદપકોષ વચ્ચે પ્રોટોપ્લાઝમનું સંચાર માધ્યમ શું છે? → વિકલ્પોમાં 'પ્લાઝ્મોડેસ્મેટા' સાચો. જો પ્રાણી કોષનો પ્રશ્ન હોય તો 'ગેપ જંક્શન'.
સент્રિઓલ (Centriole) ફક્ત પ્રાણીકોષમાં (અને કેટલાક નીચલા પાદપમાં) મળે છે. GUJCET માં સામાન્ય રીતે 'પ્લાસ્ટિડ ન હોય તેવો પ્રશ્ન' હોય તો જે વિકલ્પમાં સ્ટ્રોમા / થાયલાકોઇડ / ક્લોરોફિલ હોય — તે પ્લાસ્ટિડ છે.
પ્રાણી-પાદપ કોષ વચ્ચેનો તફાવત અને પ્લાસ્ટિડના પ્રકારો વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: કયા અંગિકામાં ક્લોરોફિલ હોય છે? → વિકલ્પો: માઇટોકોન્ડ્રિયન, ગોલ્જી, રાઇબોઝોમ, પ્લાસ્ટિડ. ક્લોરોફિલ ફક્ત પ્લાસ્ટિડમાં.
કોષિક વિભાજન (Cell division) ના પ્રશ્નમાં: માયટોસિસ = શારીરિક વૃદ્ધિ + અંગાણુ પ્રતિકૃતિ; મિઓસિસ = પ્રજનન કોષોનું નિર્માણ. જો પ્રશ્નમાં 'પ્રજનનકોષ / ગેમેટ' હોય તો મિઓસિસ.
કોષ વિભાજનના પ્રકાર અને તેના મહત્વ વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: માનવકોષમાં મિઓસિસથી ચાર ગેમેટ બને છે. હરિફ પ્રશ્ન: બે કોષો મળે? → તરત બહાર: મિટોસિસ (બે કોષ), મિઓસિસ (ચાર ગેમેટ).
રાયબોઝોમ 'રિબોન્યુક્લિયોપ્રોટીન' સંયુક્તિ છે (rRNA + પ્રોટીન). કોઈ પણ વિકલ્પમાં 'લિપિડ / કાર્બોહાઈડ્રેટ' રાયબોઝોમના ઘટક તરીકે હોય — તે ખોટો છે.
રાયબોઝોમની રચના / ઘટકો વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: રાયબોઝોમ કયા પદાર્થોનો બનેલો છે? → વિકલ્પોમાં 'ડીએનએ + લિપિડ' હોય તો ખોટો, 'આરએનએ + પ્રોટીન' સાચો.
લાઇસોઝોમમાં રહેલા ઉત્સેચકોનો pH = 5 (એસિડિક). જો પ્રશ્નમાં ઉત્સેચકોનું 'સક્રિય pH' પૂછે તો લાઇસોઝોમ = 5, ઇલેક્ટ્રોન ચેઇન ઉત્સેચકો = 8 (બેઝિક). આ તફાવતથી વિકલ્પો દૂર કરો.
લાઇસોઝોમ અને અન્ય ઉત્સેચકયુક્ત અંગિકાઓના ઉત્સેચકીય pH વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: લાઇસોઝોમના ઉત્સેચકો કેટલા pH પર સક્રિય થાય? → સાચો જવાબ: 5 (એસિડિફિક). જો વિકલ્પમાં 8 હોય તો તે માઇટોકોન્ડ્રિયલ ઉત્સેચકો છે.
કેન્સર કોષોમાં 'ટ્યુમર સુપ્રેસર જનીન' કાર્યહીન થાય છે. 'ટેલોમેરેઝ' એન્ઝાઇમ કેન્સર કોષોમાં સતત સક્રિય હોય છે — આથી તેઓ અમર બને છે.
કોષ ચક્ર / કેન્સર / સોમેટિક મ્યુટેશન વિશેના સંયોજક પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: કેન્સર કોષોમાં કયા એન્ઝાઇમની સતત સક્રિયતા જોવા મળે? → ટેલોમેરેઝ. ટ્યુમર સુપ્રેસર જનીન કાર્યહીન હોય છે.
કોષકેન્દ્રિકા (Nucleolus) માં rRNA નું સંશ્લેષણ થાય છે અને રાયબોઝોમ એકમોનું સંયોજન થાય છે. જો પ્રશ્નમાં 'રાઇબોઝોમ ઉત્પાદન' / 'rRNA' હોય તો Nucleolus.
કોષકેન્દ્રના ભાગો અને તેમના કાર્યો વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: કોષકેન્દ્રના કયા ભાગમાં rRNA સંશ્લેષણ થાય? → Nucleolus (કોષકેન્દ્રિકા). ક્રોમેટિનમાં નહીં.
