સચલન અને ગતિ — 🧪 GUJCET એક્ઝામ ટ્રિક્સ

🧪 GUJCET — Gujarati • Biology • Locomotion and Movement

🎯 પરીક્ષા ટ્રિક્સ

પટકુળના પ્રકાર → સચલન સાથે જોડો: કંકાલવાળું પટકુળ (Skeletal muscle) = અસ્થિપટકુળ, મુજબાર પટકુળ (Smooth muscle) = આંતરડા/રક્તવાહિનીઓમાં, દિલનો પટકુળ (Cardiac muscle) = હૃદયમાં. જો પ્રશ્નમાં 'સ્વૈચ્છિક' (Voluntary) શબ્દ આવે → સામાન્ય રીતે કંકાલવાળું પટકુળ; 'અસ્વૈચ્છિક' (Involuntary) → મુજબાર.
જ્યારે પટકુળના પ્રકાર અથવા તેમના નિયંત્રણ વિશે પ્રશ્ન આવે.
દા.ત.: પ્રશ્ન: 'ત્યાગિક પટકુળ (Striated voluntary muscle) કોને કહે છે?' → ત્યાગિક + સ્વૈચ્છિક = કંકાલવાળું પટકુળ (Skeletal muscle). વિકલ્પમાંથી તરત છેદી શકાય.
કર્ણવેધન (Cervical) = ૭, પૂર્વકટિ (Thoracic) = ૧૨, કરોડરજ્જુ (Lumbar) = ૫, મૂળાસ્થ (Sacrum) = ૧ (એકત્રિત), સૂક્ષ્મસ્થ (Coccyx) = ૧. યાદ રાખવા માટે: '૭-૧૨-૫-૧-૧'.
કરોડરજ્જુના ખંડોની સંખ્યા વિશે પ્રશ્ન આવે.
દા.ત.: પ્રશ્ન: 'કર્ણવેધન કરોડકાષ્ઠોની સંખ્યા કેટલી?' → ૭. વિકલ્પમાં ૭ ન હોય તો તરત ભુલ ચિહ્નિત.
ગોળાકાર ગતિપથ (Ball and Socket joint) = લાંબાભિમુખી, આંચકાવાળી ગતિ → ખાંભી અને નીચે. GUJCETમાં કોણી (Shoulder) અને ગૂંડા (Hip) બંને ગોળાકાર ગતિપથ છે. જો 'સૌથી વધુ ગતિ' પૂછે → ગોળાકાર ગતિપથ જવાબ.
ગતિપથના પ્રકાર અથવા ગતિની મર્યાદા વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'કઈ હાડકાં વચ્ચે ગોળાકાર ગતિપથ જોવા મળે છે?' → ખાંભીના કાંડાની હાડકાં (Humerus) અને લોરી (Scapula) વચ્ચે.
સ્લાયડિંગ ફિલામેન્ટ થિયરી (Sliding Filament Theory) = એ.એફ. હુક્સ્લી (A.F. Huxley). જો પ્રશ્નમાં 'ગતિપથના આધારે' કોણે સિદ્ધાંત આપ્યો → હુક્સ્લી જવાબ. એ.સી. હોલ (A.C. Hall) = હૃદય વિશે કાર્ય, બીજા વિકલ્પો છોડી દો.
સ્લાયડિંગ ફિલામેન્ટ સિદ્ધાંતના શોધક વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'સ્લાયડિંગ ફિલામેન્ટ સિદ્ધાંત કોણે આપ્યો?' → હુક્સ્લી. એ.સી. હોલ અથવા વિકલ્પોમાં બીજા નામો છોડી દો.
A-બેન્ડ (Anisotropic band) = ગહન રંગ (Dark) = માત્ર માયોસિન. I-બેન્ડ (Isotropic band) = હલકો રંગ (Light) = માત્ર એક્ટિન. જો પ્રશ્નમાં 'ગહન રંગિત બેન્ડ' = A-બેન્ડ; 'હલકો રંગિત બેન્ડ' = I-બેન્ડ. ગણતરી સાથે: A-બેન્ડનો આડો વિકાસ (Width) સ્થિર રહે છે, I-બેન્ડ સંકોચન દરમિયાન ઘટે છે.
સારકોમીયરના બેન્ડ અને તેમના ગુણધર્મો વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'સ્નાયુ સંકોચન દરમિયાન કયા બેન્ડની લંબાઈ ઘટે છે?' → I-બેન્ડ. A-બેન્ડની લંબાઈ સ્થિર રહે છે તે યાદ રાખો.
K-ઉર્જા (ATP) = પટકુળ સંકોચન માટે સીધી ઊર્જા. K-ઉર્જાનું વિઘટન (Hydrolysis) માયોસિનના મથાળા (Head) પર થાય છે → 'કોક' (Cock) સ્થિતિ. જો પ્રશ્નમાં 'સંકોચન માટેના સીધા સ્ત્રોત' → ATP. GTP, UTP, CTP છોડી દો.
પટકુળ સંકોચનમાં ઊર્જા સ્ત્રોત વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'પટકુળ સંકોચન માટે કઈ ઊર્જા સીધી રીતે વપરાય છે?' → ATP. બીજા ન્યુક્લિઓટાઇડ્સ છોડી દો.
ચયાપચય (Metabolism) ના પ્રકારો યાદ રાખો: એરોબિક = ઓક્સિજનની હાજરીમાં, એનેરોબિક = ઓક્સિજન વિના. સ્નાયુઓમાં લેક્ટિક એસિડ એનેરોબિક સંચય દરમિયાન બને છે → થાકનો અનુભવ. જો પ્રશ્નમાં 'થાક' + 'લેક્ટિક એસિડ' → એનેરોબિક.
સ્નાયુઓના ચયાપચય અથવા લેક્ટિક એસિડ વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'તીવ્ર વ્યાયામ દરમિયાન સ્નાયુઓમાં કયું સંયોજન જَمે છે?' → લેક્ટિક એસિડ (એનેરોબિક ચયાપચયથી). ઓક્સિજન-આધારિત વિકલ્પો છોડી દો.
સ્વાસ્થ્ય (Skeleton) = ૨૦૬ હાડકાં (વયસ્ક). ભ્રૂણમાં ~૨૭૦ હાડકાં. જો પ્રશ્નમાં 'વયસ્ક માનવી' → ૨૦૬; 'શિશુ/ભ્રૂણ' → ૨૭૦. મસ્તિષ્કહાડાં (Cranial bones) = ૨૨; મુખહાડાં (Facial bones) = ૧૪. સરવાળો = ૩૬.
હાડકાંની સંખ્યા વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'વયસ્ક માનવીમાં હાડકાંની સંખ્યા કેટલી?' → ૨૦૬. ૨૭૦ વિકલ્પમાં હોય તો પણ તે ભ્રૂણ માટે છે તે યાદ રાખો.
ગતિપથ (Joint) ના પ્રકાર: મૃદુ હાડકા (Cartilage) વચ્ચે = સંયોજક (Symphysis/Syndesmosis); લચીલું જોડાણ = ગમી (Gomphosis - દાંત); ઢાંકણા જેવું = કોઈપણ મુક્ત ગતિ ન હોય. જો પ્રશ્નમાં 'લચીલું ગતિપથ' = કાર્ટિલેજિનોસ. 'સ્થાયી ગતિપથ' = કંદ્રિત (Synarthrosis).
ગતિપથના શ્રેણીબદ્ધ વર્ગીકરણ વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'કંદ્રિત ગતિપથ (Synarthrosis joint) નું ઉદાહરણ કયું?' → ખોપરીના કાષ્ઠો વચ્ચે. ખોપરીના ગતિપથ = કંદ્રિત (ગતિ ન હોય).
કંકાલપટકુળ (Skeletal muscle) = વિષમઅક્ષી (Striated/Striped); મુજબાર પટકુળ = અવિષમઅક્ષી (Non-striated/Unstriped); હૃદયપટકુળ = વિષમઅક્ષી પરંતુ અસ્વૈચ્છિક. ટ્રિક: 'વિષમઅક્ષી = પટ્ટાદાર'; 'અવિષમઅક્ષી = સપાટ'. જો પ્રશ્નમાં 'અવિષમઅક્ષી પટકુળ' = આંતરડું/રક્તવાહિની.
પટકુળના સ્વરૂપ અને પટ્ટાદારપણા વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'કયું પટકુળ અવિષમઅક્ષી (Non-striated) છે?' → મુજબાર પટકુળ (Smooth muscle). વિષમઅક્ષીવાળા વિકલ્પો છોડી દો.
કેલ્શિયમ આયન (Ca²⁺) = સંકોચનનો 'તેજસ્વી ચાલક'. સાર્કોપ્લાઝ્મિક રેટિક્યુલમ (SR) = Ca²⁺ નું સંગ્રહ. જો પ્રશ્નમાં 'કયા આયનની ગેરહાજરીમાં સંકોચન થતું નથી' → Ca²⁺. Na⁺, K⁺, Mg²⁺ છોડી દો.
સ્નાયુ સંકોચનમાં આયનોની ભૂમિકા વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'સ્નાયુ સંકોચન માટે કયા આયનની ઉપસ્થિતિ જરૂરી?' → Ca²⁺. Na⁺/K⁺ છોડી દો.
કુહુળી (Elbow) = કંદ્રિત ગતિપથ (Hinge joint) → ફક્ત એક સમાંતરમાં ગતિ. ખાંભી = ગોળાકાર ગતિપથ → બહુદિશા ગતિ. જો પ્રશ્નમાં 'ફક્ત એક અક્ષે ગતિ' → હિંજ જોઈન્ટ (કુહુળી/જાંઘ). જો 'બહુદિશા ગતિ' → ગોળાકાર ગતિપથ.
ગતિપથના પ્રકાર અને ગતિની દિશા વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'કઈ ગતિપથ ફક્ત સમાનરેખીય ગતિ (Uniaxial) આપે છે?' → કંદ્રિત (Hinge) ગતિપથ. કુહુળી/જાંઘ ઉદાહરણ.
એક્ટિન = પાતળું ફિલામેન્ટ (Thin filament); માયોસિન = ઘટ્ટ ફિલામેન્ટ (Thick filament). ટ્રિક: 'એ' = નાનું, 'મ' = મોટું. જો પ્રશ્નમાં 'પાતળું' → એક્ટિન; 'ઘટ્ટ' → માયોસિન. ટ્રોપોમાયોસિન = એક્ટિનને ઢાંકે છે, ટ્રોપોનિન = Ca²⁺ બંધાય છે તે.
ફિલામેન્ટ પ્રોટીનની સંરચના અને કાર્ય વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'કયું પ્રોટીન Ca²⁺ સાથે બંધાય છે?' → ટ્રોપોનિન. ટ્રોપોમાયોસિન એક્ટિનને ઢાંકે છે (તે Ca²⁺ સાથે બંધાતું નથી). યાદ રાખો: 'ટ્રોપોનિન = Ca²⁺ બાઈન્ડિંગ.'
હૃદયપટકુળ (Cardiac muscle) = વિષમઅક્ષી (Striped) પરંતુ અસ્વૈચ્છિક + ਇકલું કોષ (Uninucleate) + આંતરકોષીય જંક્શન (Intercalated disc). જો પ્રશ્નમાં 'વિષમઅક્ષી + અસ્વૈચ્છિક' → હૃદયપટકુળ. કંકાલપટકુળ પણ વિષમઅક્ષી છે પણ સ્વૈચ્છિક.
હૃદયપટકુળના ગુણધર્મો વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'વિષમઅક્ષી અને અસ્વૈચ્છિક પટકુળ કયું?' → હૃદયપટકુળ. કંકાલપટકુળ સ્વૈચ્છિક છે તે યાદ રાખો.
ચરમસહિત (Axial skeleton) = શિરોમુખ (Skull), કરોડ (Vertebral column), વક્ર (Rib cage) + કસ્થિ (Sternum). ઉપરોક્ત (Appendicular) = હસ્ત અને પાદ ગોળા. જો પ્રશ્નમાં 'શિરોમુખ હાડકાં' → ચરમસહિત ગણાશે. પીઠપટ (Pectoral girdle) = ઉપરોક્ત.
કંકાલની વિભાજન (Axial vs Appendicular) વિશે પ્રશ્ન.
દા.ત.: પ્રશ્ન: 'કઈ હાડકાં ચરમસહિત કંકાલમાં આવે છે?' → કરોડ, પાંસળી, કસ્થ, ખોપરી. પીઠપટ/ગૂંડા ગોળા ઉપરોક્તમાં આવે છે.
