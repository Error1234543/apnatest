⚡ સૂત્રો

ગિબ્સ મુક્ત ઊર્જા ફેરફાર: ΔG = ΔH - TΔS
ΔG = ગિબ્સ મુક્ત ઊર્જા ફેરફાર; ΔH = એન્થાલ્પી ફેરફાર; T = નિરપેક્ષ તાપમાન (K); ΔS = એન્ટ્રોપી ફેરફાર · SI: ΔG અને ΔH → J અથવા kJ; T → K; ΔS → J K⁻¹ · સ્થિર દબાણ અને તાપમાને રાસાયણિક પ્રક્રિયાની આપમેળે થવાની દિશા નક્કી કરવા માટે
પ્રક્રિયાના ΔG° અને સંતુલન અચળાંક Kp વચ્ચેનો સંબંધ: ΔG° = -2.303 RT log₁₀ Kp
R = વાયુ અચળાંક (8.314 J K⁻¹ mol⁻¹); T = તાપમાન (K); Kp = પાર્શ્વિક સમતાડાત સંતુલન અચળાંક · SI: ΔG° → J mol⁻¹; R → J K⁻¹ mol⁻¹ · માનક અવસ્થામાં (298 K, 1 bar) પ્રક્રિયાના સંતુલનનો ગુણધર્મ જાણવા માટે
માનક ગિબ્સ મુક્ત ઊર્જા અને કોષ વિભવ વચ્ચેનો સંબંધ: ΔG° = -nFE°cell
n = વિનિમય પામતા ઇલેક્ટ્રોનના મોલ; F = ફારડે અચળાંક (96485 C mol⁻¹); E°cell = માનક કોષ વિભવ · SI: ΔG° → J mol⁻¹; F → C mol⁻¹; E°cell → V (વોલ્ટ) · ઇલેક્ટ્રોરાસાયણિક કોષની દૃષ્ટિએ ધાતુની ઓરેના રિડક્શનની શક્યતા તપાસવા માટે
તેર્મિટ પ્રક્રિયા (આયર્ન ઓક્સાઈડ + એલ્યુમિનિયમ): Fe₂O₃(s) + 2Al(s) → 2Fe(l) + Al₂O₃(s) ; ΔH < 0
ઉત્પન્ન થતું ઝીંદું લોહ (Fe) અને એલ્યુમિનિયા (Al₂O₃) ઉત્પન્ન થાય છે; ઉષ્માક્ષેપક પ્રક્રિયા · SI: ઉષ્મા → kJ · રેલ્ટ્રેલ/લોહની જોડાણ, સ્થાનિક રીતે ઝીંદું લોહ મેળવવા માટે
એલ્યુમિનિયમના અણવીય વિભાજન (હેલ-હરોલ્ટ પ્રક્રિયા): 2Al₂O₃ + 3C → 4Al(l) + 3CO₂(g)
Al₂O₃ = બોક્સાઈટ (સફોરિટેડ); C = кокс; Al = ઝીંદું એલ્યુમિનિયમ; CO₂ = કાર્બન ડાઈઓક્સાઈડ · SI: — · ગલિત ક્રાયોલાઈટમાં વિલયિત Al₂O₃ નું વિદ્યુતવિભાજન (≈950°C, 4–5 V)
રોસ્ટિંગ — સલ્ફાઈડ અયસ્કનો ઓક્સાઈડમાં પરિવર્તન (ઝિંક): ZnS(s) + ³/₂ O₂(g) → ZnO(s) + SO₂(g)
ZnS = ઝિંક સલ્ફાઈડ (ઝિંક બ્લેન્ડ); ZnO = ઝિંક ઓક્સાઈડ; SO₂ = સલ્ફર ડાયોક્સાઈડ · SI: — · હવાની ઉપસ્થિતિમાં પ્રકાશિત તાપમાને (800–900°C) રોસ્ટિંગ કરવામાં આવે છે
કેલ્સિનેશન — कार्बોનેટ/હાઈડ્રોક્સાઈડનો ઓક્સાઈડમાં વિઘટન: ZnCO₃(s) → ZnO(s) + CO₂(g)
ZnCO₃ = સ્ફેಲરાઈટ (ઝિંક કાર્બોનેટ); CO₂ ઉત્સર્જિત થાય છે · SI: — · વાયુશૂન્ય કે દ્રષ્ટિગોચર હવાના અભાવમાં ગરમ કરવામાં આવે (≈900°C)
ફલક્સ અને અશુદ્ધિ વચ્ચેનું સંબંધ: Slag = સ્નેહી ધાતુનો ઓક્સાઈડ + ફલક્સ
સ્નેહી ધાતુનો ઓક્સાઈડ = સિલિકા જેવી ઍક્સિડિક અશુદ્ધિ (SiO₂); ફલક્સ = બેઝિક (CaO) અથવા એસિડિક (SiO₂) · SI: — · સમાગમ પ્રક્રિયામાં અશુદ્ધિ દૂર કરવા માટે વપરાય છે
ઝિંકનું રિડક્શન (સમીકરણ સ્વરૂપ): ZnO(s) + C(s) → Zn(g) + CO(g)
C = કોકસ; Zn(વાયુ) ઉષ્મીય રિડક્શનથી મેળવે છે · SI: — · ≈1673 K જેટલા તાપમાને
કોપરનું સ્મેલ્ટિંગ (સલ્ફાઈડ અયસ્કથી): Cu₂S(s) + ²/₁ O₂(g) → 2Cu(s) + SO₂(g)
Cu₂S = કપરોસ્ પાઈરાઈટ; SO₂ ઉત્સર્જિત થાય છે · SI: — · બ્લોવર્ગમાં હવા ફુંકીને (1200–1300°C) થાય છે

🔗 સંબંધો

  • Ellingham રેખાની નીચલી ઢાળ (slope d(ΔG)/dT ≈ –ΔS): જો ΔS ધન હોય (વાયુ ઉત્પન્ન થાય) તો ઢાળ ઋણ; જો ΔS ઋણ હોય તો ઢાળ ધન.
  • બે ઓક્સાઈડ રેખાઓના છેદનબિંદુ (crossover point) તે તાપમાન છે જ્યાં વડા ધાતુની ઓરે એ બીજી ધાતુના ઓક્સાઈડને રિડ્યુસ કરી શકે છે — ઉપર તાપમાને માત્ર આ શક્ય બને છે.
  • ΔG = ΔH – TΔS પરથી: જો ΔH ધન અને ΔS ધન હોય, તો મોટા T (ઉચ્ચ તાપમાન) પર ΔG ઋણ થાય છે અને વિઘટન/રિડક્શન શક્ય બને છે — આ Ellingham રેખાઓનો ઉપર ચઢતો પ્રवृत्તિ સમજાવે છે.
  • Metals higher on the Ellingham chart (more negative ΔG of oxidation) are better reducing agents for metals below them — એલ્યુમિનિયમ (Al/Al₂O₃) Cr₂O₃ અને Fe₂O₃ બંનેને રિડ્યુસ કરી શકે છે.
  • સિલિકા (SiO₂) એ બેઝિક ફલક્સ (CaO) સાથે જોડાઈને કેલ્શિયમ સિલિકેટ (CaSiO₃) સ્વરૂપનું સ્લેગ બનાવે છે જે હળવું અને તરલ હોય છે અને અશુદ્ધિ તરીકે દૂર થાય છે.
  • ΔG° = –2.303 RT log Kp: જો ΔG° ઋણ હોય તો log Kp > 0 ⇒ Kp > 1, એટલે કે પ્રક્રિયા આગળની દિશામાં આપમેળે ચાલે છે; ΔG° ધન હોય તો પ્રતિક્રિયા પાછળની દિશામાં પ્રબળ છે.

🎯 ટ્રિક્સ

ઝડપી યાદ: 'ΔG = ΔH – TΔS' માં T બદલાતું હોય તો ΔG નો આધાર ΔS પર છે — ધન ΔS ⇒ ઢાળ ઋણ (રેખા નીચે આવે); ઋણ ΔS ⇒ ઢાળ ધન (રેખા ઉપર ચઢે).
ઘાતી રીતે ઓછું યાદ રાખવા માટે: 'Ellingham chart પર જે ધાતુની રેખા ઉપર છે તે નીચેની ધાતુના ઓક્સાઈડને રિડ્યુસ કરી શકે.' એટલે Al રેખા Fe રેખાથી ઉપર છે ⇒ Al Fe₂O₃ રિડ્યુસ કરી શકે.
કોપર અને ઝિંકનું રિડક્શન C થી શક્ય છે કારણ કે C/O₂ રેખા ઊંચા તાપમાને ZnO/Cu₂S રેખાની નીચે આવી જાય છે — આ અંતર મેળવવા માટે માત્ર 'તમાશા કરો': જે તાપમાને છેદન બને છે તે તાપમાને કામ થાય છે.
Slag formation ના બદલે માત્ર યાદ રાખો: ઍક્સિડિક અશુદ્ધિ + બેઝિક ફલક્સ = સ્લેગ; બેઝિક અશુદ્ધિ + એસિડિક ફલક્સ = સ્લેગ — બંને વસ્તુઓ એકબીજાને તટસ્થ કરે છે.
વિદ્યુતવિભાજનમાં Al નિર્માણ: 'cryolite lowers melting point of Al₂O₃ from 2300 K to ~950 K' — એટલે 3–4 V × 24000 A = ~100 MW, જે સીધું યાદ રાખવાને બદલે સૂત્ર ΔG° = –nFE°cell સાથે જોડો.
Zone refining માટે વિતરણ ગુણાંક k = C_s / C_l: જો k < 1 હોય તો પ્રદર્શન ક્ષેત્ર સ્થળાંતરિત થાય છે — આ k ≈ 0.05 થી 0.1 જેટલું ઓછું હોય છે, જે યાદ રાખવાનું સૂત્ર છે.

⚠️ ભૂલો

ΔG = ΔH – TΔS સૂત્રમાં તાપમાન K માં મૂકવું — °C નો ઉપયોગ કરવો ભૂલ છે. દા.ત. 27°C = 300 K, ન કે 27.
Ellingham રેખાના છેદનબિંદુએ ΔG = 0 થાય છે તેમ ધારવું — ખરેખર તો માત્ર અલગ-અલગ પ્રક્રિયાઓની ΔG રેખાઓ છેદે છે; કોઈ પણ રેખા ΔG = 0 ન હોઈ શકે.
રોસ્ટિંગ અને કેલ્સિનેશન વચ્ચેનો તફાવત કાઢવો: રોસ્ટિંગમાં હવાનું સંપર્ક હોય છે (સલ્ફાઈડ → ઓક્સાઈડ), કેલ્સિનેશનમાં હવાનો અભાવ હોય છે (કાર્બોનેટ → ઓક્સાઈડ + CO₂).
Slag = ઓક્સાઈડ અશુદ્ધિ + ફલક્સ; Slag નો ઉપયોગ ઓરેને સફળ બનાવવાનો નથી, પણ અશુદ્ધિ દૂર કરવાનો છે — કેટલાક વિદ્યાર્થીઓ Slag નો ઉપયોગ ખોટો સમજે છે.
ΔG° = –nFE°cell સૂત્રમાં n (ઇલેક્ટ્રોનની સંખ્યા) નું મૂલ્ય ખોટું મૂકવું; દા.ત. Al³⁺ + 3e⁻ → Al માટે n = 3, Al₂O₃ વિભાજન માટે n = 6 થાય (કારણ કે 2 Al²⁺).
કોપર અયસ્કમાંથી સ્વચ્છ Cu મેળવવા માટે હલ્કા-ફુલ્કા રિડક્શન જરૂરી છે — Cu₂O + Cu₂S → 6Cu + SO₂ એ સમીકરણના stœchiometry માં ભૂલ થાય છે.
ક્રાયોલાઈટ (Na₃AlF₆) નો ઉપયોગ માત્ર ઓગાળણ બિંદુ ઘટાડવા માટે થાય છે, એ Al₂O₃ નું રિડ્યુસર નથી — આ ગ્રંથ ભૂલ સામાન્ય છે.
વિદ્યુતવિભાજન દરમિયાન ધ્રુવોનું કાર્ય: C-આનોડ ઓક્સિડાઈઝ થઈ CO₂ બનાવે છે, Al-કેથોડ પર Al ઝુંડાય છે; આનોડનું નુકસાન થાય છે અને તે બદલવા પડે છે — આ બિંદુ ન યાદ રાખવું એ ભૂલ છે.
Mond પદ્ધતિ (Ni(CO)₄) અને van Arkel પદ્ધતિ (TiCl₄ + Mg) વચ્ચેનો તફાવત ન યાદ રાખવો: Mond અવયવીકરણ (volatilization) પર આધારિત છે, van Arkel તાપીય વિઘટન પર.
Fe-ઉત્પાદનમાં સૂત્ર Fe₂O₃ + 3CO → 2Fe + 3CO₂ એ સાચું છે, પરંતુ વિદ્યાર્થીઓ ઘણીવાર Fe₂O₃ + 3C → 2Fe + 3CO આ સમીકરણ સાથે ગૂંચવણ પામે છે; ઠંડા વિસ્તારમાં CO રિડ્યુસન્ટ છે, ગરમ વિસ્તારમાં C નું રિડક્શન પણ મહત્વનું છે.
