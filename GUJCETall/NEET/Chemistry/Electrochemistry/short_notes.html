ઇલેક્ટ્રોકેમિસ્ટ્રી — ટૂંકા નોટ્સ (વેગવંતી સમીક્ષા)

🧪 GUJCET — Gujarati • Chemistry • Electrochemistry

📘 વ્યાખ્યાઓ

  • ઇલેક્ટ્રોકેમિસ્ટ્રી: રાસાયણિક પ્રક્રિયાઓમાં વિદ્યુતઉર્જાના રૂપાંતરનું અભ્યાસ
  • ગેલ્વેનિક (વોલ્ટાઇક) કોષ: રાસાયણિક ઊર્જાને વિદ્યુત ઊર્જામાં રૂપાંતરિત કરતું સરঞ্জામ
  • ઇલેક્ટ્રોડ વિભવ (Electrode Potential): ધાતુ અને તેના આયન દ્રાવણ વચ્ચેનો વિભવાંતર
  • પ્રમાણિત ઇલેક્ટ્રોડ વિભવ (E°): બધી પ્રજાતિઓ 1 M સાંદ્રતા, 1 atm દબાણ, 298 K તાપમાને
  • ઇલેક્ટ્રોડ સ્થિતિ (Electrode Series): ધાતુઓને તેમના પ્રમાણિત રિડક્શન વિભવના ઘટતા ક્રમમાં ગોઠવવી
  • કોષનો વિદ్యુતચાલી બળ (EMF): કોષની વિદ્યુત પ્રવાહ ચલાવવાની ક્ષમતા; E°_cell = E°_કેથોડ – E°_એનોડ
  • સાંદ્રતા કોષ (Concentration Cell): સમાન ઇલેક્ટ્રોડ સામગ્રી છતાં વિવિધ સાંદ્રતાવાળા દ્રાવણ ધરાવતો કોષ
  • વિશિષ્ટ વાહકતા (Specific Conductivity, κ): દ્રાવણની વિદ્યુત ઓજનું માપ, એકમ S/cm
  • મોલર વાહકતા (Molar Conductivity, Λ_m): એક મોલ દ્રાવ્યની દ્રાવણની વાહકતા, એકમ S cm² mol⁻¹
  • ફેરાડે અચળાંક (F): 96500 C/mol; એક મોલ ઇલેક્ટ્રોન પર રહેતો વિદ્યુતભાર
  • ઇલેક્ટ્રોરાસાયણિક આત્મીયતા (Electrochemical Equivalent, z): F coulomb વિદ્યુતથી મુક્ત થતી દળ
  • ફ્યુઅલ સેલ: રાસાયણિક ઊર્જાને સીધી વિદ્યુત ઊર્જામાં રૂપાંતરિત કરતું અવિરત કોષ
  • ક્ષય (Corrosion): ધાતુનું વાતાવરણ સાથે રાસાયણિક/ઇલેક્ટ્રોકેમિકલ પ્રક્રિયાથી ક્ષય પામવું

⚡ સૂત્રો

  • E_cell = E_cathode – E_anode
  • ΔG° = –nFE°_cell
  • E_cell = E°_cell – (RT/nF) ln Q
  • E_cell = E°_cell – (0.0591/n) log Q (298 K પર)
  • Λ_m = κ / C અથવા Λ_m = κ × 1000 / M (M = મોલારિટી, κ = S/cm)
  • Λ°_m = ν₊ λ°_+ + ν₋ λ°₋ (કોલરાઉશનો નિયમ)
  • Λ°_m(CH₃COOH) = Λ°_m(CH₃COONa) + Λ°_m(HCl) – Λ°_m(NaCl)
  • m = zIt (ફેરાડેનું પ્રથમ સૂત્ર)
  • E°_cell = (RT/nF) ln K_c અથવા log K_c = nE°_cell / 0.0591
  • dE°_cell/dT = ΔS/nF (તાપમાન ગુણાંક)
  • κ = G × (l/A) = G × કોષ અચળાંક
  • Λ_eq = κ × 1000 / N (સમતુલ્ય વાહકતા, N = નોર્મિલિટી)

⭐ મુખ્ય તથ્યો

  • આંશિક પ્રક્રિયાનું ΔG° ધન હોય તો E°_cell ઋણ થાય અને પ્રક્રિયા સ્વયંસ્ફુરિત નથી
  • સમતુલ્ય વાહકતા એકમ S cm² equiv⁻¹ છે
  • દ્રાવ્યની સાંદ્રતા વધતા κ વધે છે પણ Λ_m ઘટે છે
  • Λ_m vs √C આલેખ મજબૂત વિદ્યુતવિભાજ્ય માટે સીધી રેખા આપે છે
  • H₂ સ્ટાન્ડર્ડ હાઇડ્રોજન ઇલેક્ટ્રોડનું વિભવ શૂન્ય લેવાય છે
  • Zn²⁺/Zn નું પ્રમાણિત રિડક્શન વિભવ –0.76 V છે; ડેનિયલ કોષનું E° = 1.10 V
  • Ag⁺/Ag, Cu²⁺/Cu, Cl₂/Cl⁻ જેવા પ્રમાણિત વિભવ યાદ રાખવા જોઈએ
  • ઉષ્ણતા વધતા ધાતુમાં વિદ્યુતવાહિતા ઘટે છે પણ વિદ્યુતવિભાજ્ય દ્રાવણમાં વધે છે
  • બેટરી એકથી વધુ ગેલ્વેનિક કોષનું સંયોજન છે
  • કોલરાઉશનો નિયમ નિર્ધારિત મોલર વાહકતાની ગણતરી કરાવે છે
  • ફેરાડેના બીજા નિયમ મુજબ સમાન વિદ્યુતભારે મુક્ત થતાં પદાર્થના દળ સમતુલ્ય દળના અનુપાતમાં હોય છે
  • Zn-લોક કોષની E° = 1.56 V; લાઇટનિંગ કોષમાં MnO₂ ઓક્સિડાઇઝર્ છે
  • કોષ અચળાંક l/A નો એકમ cm⁻¹ છે
  • લેડ એસિડ બેટરી પુનર્વ્યવહારપાત્ર (રીચાર્જેબલ) છે
  • ઇંધણ સેલમાં CO₂ નું ઉત્પાદન થાય છે જે કાર્બનિક ઇંધણના સેલમાં અવરોધ સર્જે છે

⚠️ સામાન્ય ભૂલો

  • E_cell = E_anode – E_cathode યાદ ન કરવું; સાચું સૂત્ર E_cell = E_cathode – E_anode
  • Λ_m એકમ S/m ન ગણવો; SI એકમ S m² mol⁻¹, પંચાંગ એકમ S cm² mol⁻¹
  • Nernst સમીકરણમાં Q = products/reactants લખી ભૂલ કરવી; Q = ઉત્પાદનો/અભિકારકો
  • m = ZIt માં I એમ્પિયર, t સેકન્ડમાં લેવું, કલાકમાં નહીં
  • ઋણ E°_cell હોય તો ΔG° ધન અને પ્રક્રિયા સ્વયંસ્ફુરિત ન હોય, એ ભૂલથી ધન માનવું
  • Λ_m અને κ એકસરખા છે માનવું; બંને અલગ રાશિઓ છે
  • સંતુલન અચળાંક K_c ની ગણતરીમાં n=1 લેવું; n = ઇલેક્ટ્રોન સંખ્યા ચોકસાઈથી શોધવી
  • ડેનિયલ કોષમાં Zn એનોડ છે અને Cu કેથોડ; ઉલટું ગણવું
  • સંકેતરૂપ લખતી વખતે ઘટતા ઇલેક્ટ્રોડ વિભવવાળો ઇલેક્ટ્રોડ બમણો ઇલેક્ટ્રોડ ગણવો
  • ક્ષાર પલ્લવીના વિના અર્ધ-કોષ બનાવી શકાતો નથી એ ભૂલથી બનાવવો
  • Λ_m નો √C પર આધાર મજબૂત અને નિર્બળ બંને વિદ્યુતવિભાજ્ય સમાન રીતે માનવો
  • E°_cell ને વોલ્ટમાં લખતી વખતે sign ગેરહાજર રાખવો; ઘટના વિસ્તારમાં ચિહ્ન મહત્વનું
  • ફેરાડે અચળાંક F = 96500 C/mol; 9650 નો ઉપયોગ ભૂલથી ન કરવો
  • પ્રમાણિત પરિસ્થિતિઓમાં 298 K (25°C) ધારવું; તાપમાન બદલાય તો Nernst સમીકરણ સુધારવું

🔥 હાઈ-યીલ્ડ મુદ્દા

  • ડેનિયલ કોષની રચના અને કાર્યપદ્ધતિ યાદ કરવી: Zn|Zn²⁺(1 M)||Cu²⁺(1 M)|Cu
  • E°_cell > 0 → સ્વયંસ્ફુરિત પ્રક્રિયા; E°_cell < 0 → અસ્વયંસ્ફુરિત
  • K_c ની ગણતરી: log K_c = nE°_cell/0.0591 (298 K) ઘણી વાર આવે છે
  • Nernst સમીકરણ મુજબ સાંદ્રતા બદલાય તો E_cell બદલાય; 298 K પર 0.0591/n લખવું
  • કોલરાઉશનો નિયમ મજબૂત અને નિર્બળ બંને વિદ્યુતવિભાજ્ય માટે લાગુ
  • Zn-લોક કોષ, લાઇટનિંગ કોષ, લેડ એસિડ બેટરી — બધી જાણીતી બેટરી પ્રકાર યાદ રાખવા
  • H₂-O₂ ફ્યુઅલ સેલ રચના અને કાર્યપદ્ધતિ સ્પષ્ટ હોવી જોઈએ
  • કોષ અચળાંક = l/A; R = ρ(l/A); G* = κ/(l/A)
  • ક્ષય રોકવાની પદ્ધતિઓ: બાહ્ય રક્ષણ, ઇલેક્ટ્રોડ સંરક્ષણ, ઇલેક્ટ્રોપ્લેટિંગ
  • ઇલેક્ટ્રોડ વિભવનું ચિહ્ન મહત્વનું: ઋણ = ઓક્સિડેશન પ્રવૃત્તિ વધારે
  • E°_cell = (RT/nF) ln K_c સૂત્ર મુજબ ઇલેક્ટ્રોડ વિભવથી K_c શોધવું
  • લેડ-એસિડ બેટરી પુનર્વ્યવહારપાત્ર છે; મજબૂત બેટરી એકવાર વપરાય છે
  • E°_cell ની ગણતરી: ઘટના વિસ્તારમાં ઘટતો વિભવ ધરાવતો ઇલેક્ટ્રોડ એનોડ
  • ફેરાડેનો પ્રથમ નિયમ: m = zIt, જ્યાં z = E.C.E.
  • ડેનિયલ કોષમાં E° = 1.10 V; સામાન્ય પ્રશ્નમાં આ કિંમત આવે છે
  • Λ_m નો √C વિશેનો આલેખ મજબૂત વિદ્યુતવિભાજ્ય માટે સીધો રેખા છે
  • ઇલેક્ટ્રોરાસાયણિક અનુશ્રેણીમાં ઊંચું E° = પ્રબળ ઓક્સિડાઇઝિંગ એજન્ટ
  • સંકેતરૂપમાં ઇલેક્ટ્રોડ વિભવ ઘટતો ધાતુ ડાબી બાજુ (એનોડ) અને વધતો જમણી બાજુ (કેથોડ)
  • કોષનું ΔG° = –nFE°_cell સંબંધ યાદ રાખવો; ΔG° ઘન હોય તો E°_cell ઋણ
  • Zn + Cu²⁺ → Zn²⁺ + Cu; ઇલેક્ટ્રોન પ્રવાહ Zn થી Cu તરફ
  • E_cell માટે Q = [ઉત્પાદન]/[અભિકારક]; ગેસ માટે દબાણ, દ્રાવણ માટે સાંદ્રતા
  • ફ્યુઅલ સેલમાં ઇંધણ સતત પૂરવણી કરવામાં આવે છે; કોષ નિષ્ફળ જતો નથી
  • E°_cell = E°_cathode – E°_anode; ઘટના વિસ્તારમાં ઇલેક્ટ્રોડ વિભવનો ઉપયોગ
