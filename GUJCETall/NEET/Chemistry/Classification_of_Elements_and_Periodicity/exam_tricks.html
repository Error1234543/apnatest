🎯 પરીક્ષા ટ્રિક્સ

પરમાણુ ક્રમાંકથી બ્લોક ચેક કરવાનો 'અંતિમ ઇલેક્ટ્રોન' મંત્ર: કક્ષકમાં અંતિમ ઇલેક્ટ્રોન સ્થિત થાય તે મુજબ (s=1-2, p=13-18, d=3-12, f=4-17) જન્મશોક મળે. ઉદા. Z=24 (Cr): 3d⁵ 4s¹ → d-બ્લોક.
તત્વ કયા બ્લોકમાં છે તે પૂછતી કોઈ પણ પ્રશ્નમાં, જ્યારે કોષ્ટકની મદદ લેવાનો સમય ન હોય.
દા.ત.: Z=35 (Br): અંતિમ ઇલેક્ટ્રોન 4p⁵ માં → p-બ્લોક. Z=56 (Ba): 6s² → s-બ્લોક.
સમયરેખા ક્રમ (4s પહેલાં 3d): 'Aufbau યાદ કરો: ...4s પહેલાં 3d, પણ આયનીકરણમાં 4s સામેલ...' એટલે તટસ્થ પરમાણુમાં 4s ભરાય પહેલાં, પણ ઇલેક્ટ્રોન કાઢતી વખતે 4s પહેલાં દૂર થાય. ઉદા. Fe²⁺: [Ar] 4s⁰ 3d⁶.
સંક્રાંત ધાતુઓ (Transition metals)ના આયનનું ઇલેક્ટ્રોનિક વિન્યાસ પૂછતો પ્રશ્ન આવે ત્યારે.
દા.ત.: Fe (Z=26): [Ar] 4s² 3d⁶ → Fe²⁺: [Ar] 3d⁶ (4s² દૂર થાય), Fe³⁺: [Ar] 3d⁵.
ચુંબકીય ગુણધર્મ — 'એકલા ઇલેક્ટ્રોન'ની રીત: વિન્યાસમાં જોડિયા (paired) ન હોય તેવા એકલા e⁻ ગણો. એકલો e⁻ = પ્રેરિત ચુંબકીય (paramagnetic). બધા જોડિયા = વિરુદ્ધચુંબકીય (diamagnetic).
તત્વ/આયન ચુંબકીય છે કે નહીં તે ઝડપથી નક્કી કરવા.
દા.ત.: O₂⁻ : 1π* ઑર્બિટલમાં 3 e⁻ → 1 એકલો e⁻ → પ્રેરિત ચુંબકીય. Na⁺: 1s² 2s² 2p⁶ → બધા જોડિયા → વિરુદ્ધચુંબકીય.
આયનીકરણ ઊર્જા (IE) — 'અસ્થિરતા વધારે, IE ઓછી': s² (purged) અને p³ (half-filled) રચનાઓ ઊર્જાપ્રદ હોવાથી તેમનો ઇલેક્ટ્રોન દૂર કરવો મુશ્કેલ → IE ઉંચી. s¹→s⁰ અને p⁴→p³ તરફ IE અસામાન્ય ઊંચી. ઉદા. Be > B અને N > O.
સમાન આવર્તમાં અસામાન્ય IE ક્રમ પૂછતો પ્રશ્ન.
દા.ત.: આવર્ત 2: Li < B < Be < C < O < N < F < Ne. અહીં Be > B (કારણ Be નું 2s²) અને N > O (કારણ N નું 2p³ અર્ધભરેલું).
ઉત્કૃષ્ટ ગેસનો IE સૌથી વધુ — એટલે કોઈ પણ આવર્તમાં અંતિમ તત્વનો IE મહત્તમ, પ્રથમ તત્વનો ઓછામાં ઓછો. આનાથી ઓપ્શનમાં સૌથી વધુ IE ધરાવતો તત્વ તરત ઓળખાય.
'સૌથી વધુ આયનીકરણ વિભવ ધરાવતો તત્વ કયો?' જેવા પ્રશ્નોમાં.
દા.ત.: આવર્ત 3: Na < Mg < Al < Si < P < S < Cl < Ar → Ar સૌથી વધુ IE. (Ne > F > O > N > C > B > Be > Li.)
ઇલેક્ટ્રોનબંધુતા (EA) — 'ઊષ્માક્ષેપક = ઋણ sign': વધુ ઋણ EA = વધુ સહજતાથી e⁻ લે. ક્લોરિન > ફ્લોરિન (F < Cl) એ GUJCETનું ગંભીર ટ્રેન્ડ: F ના ch. નાના કદને કારણે e⁻-e⁻ અપાકર્ષણ વધુ → Cl ની EA વધુ ઋણ.
halogensની EA ક્રમ અથવા 'સૌથી વધુ ઋણ EA' પૂછતો પ્રશ્ન.
દા.ત.: EA ક્રમ: F < Cl > Br > I. Cl સૌથી વધુ ઋણ EA ધરાવે છે. CO₂ કરતાં Cl ની EA વધુ ઋણ છે.
તડિતઋણતા (EN) — 'ફ્લોરિન શિખર': પાણીના ડ્રોપ જેવું — જમણી તરફ + ઉપર તરફ. F > O > N ≈ Cl > Br > I. GUJCET માં NaCl તોડતો પ્રશ્ન: Na⁺Cl⁻ માં બંધ આયનીય, HCl માં સહસંયોજક — EN તફાવત જવાબ આપે.
બંધ પ્રકાર, તેજસ્વી બહુવિધ પસંદગી, કે તત્વોનો EN ક્રમ.
દા.ત.: F (3.98) > O (3.44) > N (3.04) > Cl (3.16) > C (2.55) > H (2.20) > Na (0.93). ઇલેક્ટ્રોનયોજકતા વધતી જાય તે તત્વ: Na < C < N < O < F.
પરમાણ્વિક ત્રિજ્યા — 'માત્રા vs આવર્ત': વિભાજનમાં નીચે ઉતરતાં ત્રિજ્યા વધે (n વધે). આવર્તમાં જમણે જતાં ત્રિજ્યા ઘટે (Zeff વધે). તેથી નાની ત્રિજ્યા = ઊપર જમણે (F/He). મોટી ત્રિજ્યા = નીચે ડાબે (Fr/Cs).
આણ્વિક ત્રિજ્યાનો ક્રમ અથવા કનામ/મહત્તમ ત્રિજ્યા પૂછતો પ્રશ્ન.
દા.ત.: નાની ત્રિજ્યા: He < F < O < N < C < B < Be < Li. મોટી ત્રિજ્યા: Cs > Ba > ...> F > O > N.
d-બ્લોક ઑક્સિડેશન અંક — '(n-1)d + ns e⁻'નો જોડ: ઇલેક્ટ્રોનિક વિન્યાસમાં 3d + 4s ઇલેક્ટ્રોનનો સરવાળો મહત્તમ ઑક્સિડેશન અંક (ઉદા. Mn: 3d⁵ 4s² → +7; Fe: 3d⁶ 4s² → +6 મહત્તમ).
સંક્રાંત ધાતુના મહત્તમ ઑક્સિડેશન અંકની ગણતરી.
દા.ત.: Mn (Z=25): [Ar] 4s² 3d⁵ → મહત્તમ ઑક્સિડેશન અંક = +7. Cr (Z=24): [Ar] 4s¹ 3d⁵ → મહત્તમ +6.
બીજા આવર્તના અસામાન્ય તત્વો — 'F, O, N નો નાનો કદ': બીજા આવર્તના સૌથી ઊંચા EN + નાનું કદ + d-ઑર્બિટલની ગેરહાજરી → તેઓ હાઈડ્રોજન બંધ બનાવે છે (HF, H₂O, NH₃), દ્વિબંધ (C=O, N≡N) સરળતાથી બનાવે, પણ F₂ નું બંધવિભાજન ઊર્જા અપેક્ષાકૃત ઓછું (લون પેર અપાકર્ષણ).
'બીજા આવર્તના તત્વોની વિશેષતા' અથવા 'અસામાન્ય વર્તન' પૂછતો પ્રશ્ન.
દા.ત.: C, N, O, F બધા π-બંધ બનાવી શકે છે, પણ Si, P, S કરતાં વધુ સરળ. F₂ નું B.E. Cl₂ કરતાં ઓછું: 158 kJ/mol vs 242 kJ/mol.
આવર્ત કોષ્ટકમાં સમૂહ (group) શોધવાનો અંકગણિત મંત્ર: s-બ્લોક → group = valence e⁻ (1,2). p-બ્લોક → group = 10 + valence e⁻ (13–18). d-બ્લોક → group ≈ (n-1)d + ns valence e⁻ (3–12).
ઇલેક્ટ્રોનિક વિન્યાસ આપેલ હોય તો group તરત શોધવું હોય.
દા.ત.: વિન્યાસ: 4s² 3d³ → d-બ્લોક, valence = 2+3=5 → group 5 (V). વિન્યાસ: 3s² 3p⁴ → p-બ્લોક, group = 10+6 = 16 (O group).
આયનીય ત્રિજ્યા — 'કેટાયન < તટસ્થ < એનાયન': સમાન તત્વ માટે cation હંમેશા neutral કરતાં નાનું, anion હંમેશા neutral કરતાં મોટું. કારણ: cation માં e⁻ ઓછા → Zeff વધુ → ઓરબિટલ ઘટી જાય. anion માં e⁻ વધુ → અપાકર્ષણ વધુ → ફેલાવો.
સમાન તત્વના ઇ온 અને પરમાણુની ત્રિજ્યા સરખાવવા.
દા.ત.: Na⁺ < Na < Na⁻ (અસ્તિત્વ ઓછું પણ સિદ્ધાંત). Cl⁻ > Cl. Fe²⁺ < Fe³⁺ < Fe (ત્રિજ્યા ક્રમ: Fe > Fe²⁺ > Fe³⁺).
'સમાન-ઇલેક્ટ્રોનિક પ્રજાતિઓ' (Isoelectronic): સમાન e⁻ સંખ્યા ધરાવતી પ્રજાતિઓનો ક્રમ = પ્રોટોન (核 charge) વધે તેમ ત્રિજ્યા ઘટે. આપણે 'Zeff' નો ઉપયોગ કરીએ: e⁻ સમાન હોય, પણ nuclear charge મોટો → ઓછી ત્રિજ્યા.
Isoelectronic સિરીઝની ત્રિજ્યા ક્રમ.
દા.ત.: Isoelectronic: N³⁻, O²⁻, F⁻, Na⁺, Mg²⁺, Al³⁺ (બધા 10 e⁻). ત્રિજ્યા: N³⁻ > O²⁻ > F⁻ > Na⁺ > Mg²⁺ > Al³⁺ (Z = 7,8,9,11,12,13).
અસંતુલિત ઑક્સિડેશન અંકો — 'Cr³⁺ વધુ સ્થિર, Mn³⁺ અસ્થિર': સંક્રાંત ધાતુના આયનોની સ્થિરતા d-ઇલેક્ટ્રોન રચના પર આધારિત. d⁰, d⁵, d¹⁰ અત્યંત સ્થિર. Mn³⁺ (d⁴) ≠ d⁵ થવા પ્રવૃત્ત છે → બળપૂર્વક e⁻ ખોેડે → પ્રબળ ઑક્સિડાઈઝિંગ. Cr³⁺ (d³) સ્થિર.
કયા ઑક્સિડેશન અંક/આયન વધુ સ્થિર અથવા પ્રબળ ઑક્સિડાઈઝિંગ છે તે નક્કી કરવા.
દા.ત.: Mn³⁺ vs Mn²⁺: Mn³⁺ (d⁴) → Mn²⁺ (d⁵) થવા પ્રવૃત્ત, તેથી પ્રબળ ઑક્સિડાઈઝિંગ. Cr³⁺ (d³) સ્થિર. Fe²⁺ (d⁶) vs Fe³⁺ (d⁵) → Fe³⁺ વધુ સ્થિર.
p-બ્લોક તત્વોની ધાતુ-અધાતુ પ્રવૃત્તિ — 'સ્ટેટિક જગ': ડાબી તરફ નીચે જતાં ધાતુી ગુણ, ઉપર જમણે જતાં અધાતુ. B, Si, Ge, As, Sb, Te, Po — 'મેટલોઇડની રેખા'. આ રેખાથી ડાબે/diagonal all metals, જમણે non-metals.
તત્વ ધાતુ/અધાતુ/મેટલોઇડ છે તે ઝડપથી તાકીદ.
દા.ત.: Me, Al, Si, Ge, As, Sb, Te, Po — એક ઢાળતી રેખા. B (metalloid), Si (metalloid), C (non-metal). Na, Mg, Al — metals.
