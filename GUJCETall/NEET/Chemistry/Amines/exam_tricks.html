🎯 પરીક્ષા ટ્રિક્સ

પ્રાથમિક, દ્વિતીય અને તૃતીય એમીનને ઓળખવા માટે H-inspection પદ્ધતિ વાપરો. N સાથે જોડાયેલા H અણુઓની સંખ્યા જુઓ: 2H = પ્રાથમિક, 1H = દ્વિતીય, 0H = તૃતીય.
જ્યારે એમીનનું વર્ગીકરણ કરવાનું હોય.
દા.ત.: CH₃NH₂ માં N સાથે 2H છે → પ્રાથમિક એમીન. (CH₃)₂NH માં N સાથે 1H છે → દ્વિતીય એમીન.
એમીનની બેઝિકિટીનો ક્રમ યાદ રાખો: તૃતીય > દ્વિતીય > પ્રાથમિક > એમોનિયા. ઇલેક્ટ્રોન-દાતા સમૂહો (ઉદા. -CH₃) બેઝિકિટી વધારે છે.
બેઝિકિટીની તુલના કરતી વખતે.
દા.ત.: (CH₃)₃N > (CH₃)₂NH > CH₃NH₂ > NH₃ (બેઝિકિટીનો ઘટતો ક્રમ).
હિન્સબર્ગ ટેસ્ટ વડે પ્રાથમિક એમીન ઓળખો: પ્રાથમિક એમીન બેન્ઝીનસલ્ફોનાઇલ ક્લોરાઇડ (Hinsberg reagent) સાથે પ્રક્રિયા કરીને ક્ષારકીય દ્રાવણ આપે છે.
પ્રયોગશાળામાં એમીનનું વર્ગીકરણ કરતી વખતે.
દા.ત.: C₆H₅NH₂ + C₆H₅SO₂Cl → C₆H₅NHSO₂C₆H₅ (ક્ષારકીય, પાણીમાં દ્રાવ્ય).
ડાયઝોટાઇઝેશન પ્રક્રિયા માત્ર પ્રાથમિક એરોમેટિક એમીન (ArNH₂) સાથે જ થાય છે. N₂ ગેસનું નિર્ગમન થાય છે.
એરોમેટિક એમીનની ઓળખ કરતી વખતે.
દા.ત.: C₆H₅NH₂ + NaNO₂ + HCl → C₆H₅N₂⁺Cl⁻ (ડાયઝોનિયમ ક્લોરાઇડ) + 2H₂O → N₂ ગેસ.
ગેબ્રિયલ ફ્થેલિમાઇડ સિંથેસિસ વડે પ્રાથમિક એમીન તૈયાર કરવામાં આવે છે. ફ્થેલિમાઇડ સાથે KOH ની પ્રક્રિયાથી એમીન મળે છે.
પ્રાથમિક એમીનના સિંથેસિસ પ્રશ્નોમાં.
દા.ત.: ફ્થેલિમાઇડ + KOH → કાલીનો ફ્થેલેટ + NH₂R (પ્રાથમિક એમીન).
એમીનની એસિલેશન પ્રક્રિયામાં એસિડ ક્લોરાઇડ (RCOCl) સાથે પ્રક્રિયા થઈ એમાઇડ બને છે. પ્રતિક્રિયા વેગવાન હોય છે.
એમીનની રાસાયણિક પ્રક્રિયાઓના પ્રશ્નોમાં.
દા.ત.: CH₃NH₂ + CH₃COCl → CH₃NHCOCH₃ (એસિટામાઇડ) + HCl.
કાર્બાઇલએમીન પ્રક્રિયા (Isocyanide test) વડે પ્રાથમિક એમીન ઓળખી શકાય છે. CHCl₃ અને KOH સાથે ગરમ કરતાં દુર્ગંધયુક્ત ઇસોસાયનાઇડ બને છે.
પ્રાથમિક એમીનની ઓળખ માટે.
દા.ત.: CH₃NH₂ + CHCl₃ + 3KOH → CH₃NC (મિથાઇલ ઇસોસાયનાઇડ) + 3KCl + 3H₂O.
એમીનની નાઇટ્રોસેશન પ્રક્રિયામાં, તૃતીય એમીન N-નાઇટ્રોસો યૌગિક બનાવે છે, જ્યારે દ્વિતીય એમીન N-નાઇટ્રોસો એમીન બનાવે છે.
નાઇટ્રોસેશન પ્રક્રિયાના પ્રશ્નોમાં.
દા.ત.: (CH₃)₃N + HNO₂ → (CH₃)₃N-N=O (N-નાઇટ્રોસો તૃતીય એમીન).
એમીનની હેલોજનેશન પ્રક્રિયામાં, એનિલિન (C₆H₅NH₂) ક્લોરિન જળ સાથે 2,4,6-ટ્રાઇક્લોરોએનિલિન બનાવે છે (વ્હાઇટ પ્રેસિપિટેટ).
હેલોજનેશન પ્રક્રિયાના પ્રશ્નોમાં.
દા.ત.: C₆H₅NH₂ + 3Cl₂ → C₆H₂Cl₃NH₂ (2,4,6-ટ્રાઇક્લોરોએનિલિન) + 3HCl.
એમીનની ઓક્સિડેશનમાં, પ્રાથમિક એમીન નાઇટ્રાઇલ (R-CN) બનાવે છે, જ્યારે તૃતીય એમીન ઓક્સિડેશન પ્રતિરોધક હોય છે.
ઓક્સિડેશન પ્રક્રિયાના પ્રશ્નોમાં.
દા.ત.: CH₃CH₂NH₂ + [O] → CH₃CN (એસિટોનાઇટ્રાઇલ) + H₂O.
એમીનની દ્રાવ્યતાનો ક્રમ યાદ રાખો: પ્રાથમિક > દ્વિતીય > તૃતીય (H-બંધનની ક્ષમતા ઘટતી જાય છે).
દ્રાવ્યતાના પ્રશ્નોમાં.
દા.ત.: CH₃NH₂ (પ્રાથમિક) > (CH₃)₂NH (દ્વિતીય) > (CH₃)₃N (તૃતીય) (પાણીમાં દ્રાવ્યતાનો ઘટતો ક્રમ).
એમીન અને એસિડ વચ્ચેના પ્રક્રિયામાં, એમીન એસિડ સાથે ક્ષાર બનાવે છે. પ્રતિક્રિયા ઉષ્માક્ષેપી હોય છે.
એમીન અને એસિડની પ્રક્રિયાના પ્રશ્નોમાં.
દા.ત.: CH₃NH₂ + HCl → CH₃NH₃⁺Cl⁻ (મિથાઇલએમોનિયમ ક્લોરાઇડ).
એરોમેટિક એમીન (ઉદા. એનિલિન) એલિફેટિક એમીન કરતાં વધુ બેઝિક હોય છે કારણ કે લોન પેઅરનો રેઝોનન્સ સ્થાયિત્વ વધારે છે.
બેઝિકિટીની તુલના કરતી વખતે.
દા.ત.: C₆H₅NH₂ (એનિલિન) > CH₃NH₂ (મિથાઇલએમીન) (બેઝિકિટીનો ક્રમ).
એમીનની ડાયએલકાઇલેશન પ્રક્રિયામાં, એમોનિયા સાથે એલ્કાઇલ હેલાઇડની પ્રક્રિયાથી પ્રાથમિક, દ્વિતીય અને તૃતીય એમીન બને છે.
એમીનના સિંથેસિસ પ્રશ્નોમાં.
દા.ત.: NH₃ + CH₃I → CH₃NH₂ (પ્રાથમિક) → (CH₃)₂NH (દ્વિતીય) → (CH₃)₃N (તૃતીય).
એમીનની ડિકાર્બોક્સિલેશન પ્રક્રિયામાં, એમીનો એસિડના હીટિંગથી એમીન મળે છે. ઉદા. ગ્લાયસિનથી મિથાઇલએમીન.
ડિકાર્બોક્સિલેશન પ્રક્રિયાના પ્રશ્નોમાં.
દા.ત.: NH₂CH₂COOH → CH₃NH₂ (મિથાઇલએમીન) + CO₂.
