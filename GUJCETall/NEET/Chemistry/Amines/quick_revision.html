એમાઇન્સ — ઝડપી પુનરાવર્તન

🧪 GUJCET — Gujarati • Chemistry • Amines

🧠 યાદ રાખો

એમાઇન્સ એ એમોનિયાના એક, બે અથવા ત્રણ H પરમાણુઓનું એલ્કિલ/એરાઇલ સમૂહથી બદલાયેલા સંયોજનો છે.
પ્રાથમિક (1°), દ્વિતીયક (2°), તૃતીયક (3°) એમાઇન્સ: R-NH₂, R₂NH, R₃N.
એરાઇલ એમાઇન્સમાં એમિનો સમૂહ બેન્ઝીન રિંગ સાથે જોડાયેલો હોય છે (જેમ કે એનિલિન C₆H₅NH₂).
એમાઇન્સના નામકરણ: IUPACમાં -amine પ્રત્યય; સામાન્ય નામમાં એલ્કાઇલ + એમાઇન.
એમાઇન્સ એ બેઝિક પ્રકૃતિના છે કારણ કે N પર અબંધન ઇલેક્ટ્રોન જોડી હોય છે.
એનિલિનની બેઝિકતા એલ્કાઇલ એમાઇન્સ કરતાં ઓછી છે કારણ કે રેઝોનન્સથી N પરનો ઇલેક્ટ્રોન ઘનત્વ ઘટે છે.
એમાઇન્સમાં હાઇડ્રોજન બંધન: 1° અને 2° એમાઇન્સમાં H-bond હોય છે, 3° માં નથી.
એમાઇન્સનું ઉત્પાદન: નેગેટિવ હેલોજન સાથે એલ્કાઇલ હેલાઇડની પ્રતિસ્થાપન પ્રક્રિયા (એમોનિયાનો અતિરિક્ત પ્રમાણ જરૂરી).
ગેબ્રિયલ ફથાળાઇડ પ્રક્રિયા: માત્ર પ્રાથમિક એમાઇન મળે છે — બીજા સ્તરની ઉપજ નથી થતી.
એમાઇન્સની ક્ષારકતા ક્રમ (જલીય દ્રાવણ): 2° > 1° > 3° (એલ્કાઇલ સમૂહનું +I અસર અને સોલવેશન અસર બંને જવાબદાર).
એનિલિન + HNO₂ (NaNO₂/HCl, 0-5°C) → ડાયઝોનિયમ લવણ (સ્થિર, નીચા તાપમાને).
ડાયઝોનિયમ લવણનું વિઘટન: H₂O/ઉષ્મા → ફિનોલ; CuCN → બેન્ઝોનાઇટ્રાઇલ; H₃PO₂ → બેન્ઝીન.

⚡ ઝડપી સૂત્રો

એમિનો સમૂહ: —NH₂ (પ્રાથમિક), —NHR (દ્વિતીયક), —NR₂ (તૃતીયક)
એનિલિન: C₆H₅NH₂ (મોલ.ભર: 93 g/mol)
ડાયઝોનિયમ લવણ: C₆H₅N₂⁺Cl⁻ (બેન્ઝીન ડાયઝોનિયમ ક્લોરાઇડ)
એમાઇન + HCl → એમાઇન હાઇડ્રોક્લોરાઇડ (ક્ષાર): RNH₂ + HCl → RNH₃⁺Cl⁻
ગેબ્રિયલ પ્રક્રિયા: પોટેશિયમ પથાલાઇમિડ + R-X → N-એલ્કાઇલ પથાલાઇમિડ → હાઇડ્રોલિસિસ → RNH₂
હોફમેન બ્રોમેમાઇડ પ્રક્રિયા: RCONH₂ + Br₂ + 4NaOH → RNH₂ + Na₂CO₃ + 2NaBr + 2H₂O (એક C ઘટે છે)

✅ વન-લાઈનર્સ

એમાઇન્સના ત્રણ પ્રકાર: પ્રાથમિક, દ્વિતીયક અને તૃતીયક.
એમાઇન્સમાં N પર અબંધન ઇલેક્ટ્રોન જોડી હોવાથી તેઓ લ્યુઈસ બેઝ અને ન્યુક્લિયોફાઇલ છે.
એલ્કાઇલ એમાઇન્સની બેઝિકતા એનિલિન કરતાં વધુ હોય છે.
એનિલિનમાં +M અસર (રેઝોનન્સ) નીચે N પર ઇલેક્ટ્રોન ઘનત્વ ઘટાડે છે.
ઇલેક્ટ્રોન દાતા સમૂહ (જેમ —CH₃) એમાઇનની બેઝિકતા વધારે છે; ઇલેક્ટ્રોન ખેંચનાર સમૂહ (જેમ —NO₂) ઘટાડે છે.
એનિલિન + Br₂/H₂O → 2,4,6-ટ્રાઇબ્રોમોએનિલિન (સફેદ અવક્ષેપ).
એનિલિન + Br₂/CS₂ → મોનોબ્રોમોએનિલિન (પ્રધાનતઃ પાર્શ્વ-ઉત્પાદન).
એનિલિનનું નાઇટ્રેશન સીધું કરતાં પ્રતિબંધિત છે કારણ કે પ્રબળ એસિડમાં એનિલિન પ્રોટોનેટેડ થઈ H₃N⁺-બેન્ઝીન બને છે જે મજબૂત ડીએક્ટિવેટિંગ સમૂહ છે.
એમાઇન્સની ઓળખ: લિટમસ કાગળ નીલો થાય (બેઝિક પ્રકૃતિ).
કાર્બાઇલ એમાઇન પરીક્ષણ: એલ્કાઇલ આઇસોસાયનાઇડ (ચેતાવણીભર્યું ગંધ) + 3° KOH → પ્રાથમિક એમાઇન.
હિન્ડબર્ગ પરીક્ષણ: 1° એમાઇન + CHCl₃ +alc. KOH → કાર્બાઇલ એમાઇન (ખરાબ ગંધ); 2° → નિર્જળ ડાયએથિલ એમાઇન; 3° → કોઈ પ્રક્રિયા નહીં.
એમાઇન્સનું ડાયઝોટાઇઝેશન: એનિલિન + NaNO₂ + HCl (0-5°C) → બેન્ઝીન ડાયઝોનિયમ ક્લોરાઇડ.
એમાઇન્સ એલ્કાઇલ હેલાઇડ સાથે પ્રક્રિયા કરી સેકન્ડરી, તૃતીયક અને ક્વાર્ટનરી એમાઇનિયમ લવણ બનાવે છે (ઓવર-એલ્કાઇલેશન સમસ્યા).
એમાઇન્સનું ઉત્પાદન: નાઇટ્રોએલ્કેનના રિડક્શન (Sn/HCl અથવા H₂/Ni) દ્વારા પણ થાય છે.
એમાઇન્સમાં હાઇડ્રોજન બંધનને કારણે 1° અને 2° એમાઇન્સના ઉત્કલન બિંદુ 3° કરતાં વધુ હોય છે.
