જલ (Hydrogen) — સૂત્ર પત્રક

⚡ સૂત્રો

હાઇડ્રોજન પરમાણુનું દળ: H = 1 u
H = હાઇડ્રોજન પરમાણુનું પરમાણુદળ એકમ atomic mass unit માં · SI: u (Da) · સામાન્ય રીતે વપરાય છે
ડ્યુટેરિયમ (²H અથવા D) પરમાણુદળ: D = 2 u
D = ડ્યુટેરિયમ ન્યુક્લિયસમાં 1 પ્રોટોન અને 1 ન્યુટ્રોન હોય છે · SI: u (Da) · વાવસ્ટ (Aston) ને 1932 માં શોધ્યું
ટ્રિટિયમ (³H અથવા T) પરમાણુદળ: T = 3 u
T = ટ્રિટિયમ ન્યુક્લિયસમાં 1 પ્રોટોન અને 2 ન્યુટ્રોન હોય છે; રેડિયોએક્ટિવ · SI: u (Da) · રુધિરફુલ્ક (Rutherford), બેડેલ અને માર્ટિન (1934) દ્વારા શોધ
જૂથ સંબંધ: ડ્યુટેરિયમ અને ટ્રિટિયમ વચ્ચેનો ભાર ગુણોત્તર: D/T = 2/3
D = ડ્યુટેરિયમનું દળ, T = ટ્રિટિયમનું દળ · SI: કોઈ નહીં (ગુણોત્તર) · આઈસોટોપના પરમાણુદળ પરથી
સામાન્ય જળતાપમાને H₂ નું મોલર દળ: M(H₂) = 2 g/mol
H = 1 g/mol, તેથી H₂ = 2 × 1 = 2 g/mol · SI: g/mol · ગણતરીઓમાં વપરાય છે
વોટર્સ ફોર્જ પ્રક્રિયા (ઉદ્યોગગૃહ રીત): CH₄(g) + H₂O(g) → CO(g) + 3H₂(g) (ΔH > 0)
CH₄ = મીથેન, H₂O = બાષ્પ, CO = કાર્બન મોનોકસાઇડ, H₂ = હાઇડ્રોજન · SI: — · 1100 K તાપમાને નિકલ ઉત્પ્રેરક હેઠળ; ઉષ્માગ્રાહી
શૈક્ષણિક રીતે (Zn + HCl): Zn(s) + 2HCl(aq) → ZnCl₂(aq) + H₂(g)
Zn = જેન, HCl = હાઈડ્રોક્લોરિક એસિડ, ZnCl₂ = જેન ક્લોરાઇડ · SI: — · લાબોરેટરીમાં સામાન્ય રીતે પ્રયોગ
કોમ્બાસ્ડ્ટ રિએક્શન: હાઇડ્રોજનનું દહન: 2H₂(g) + O₂(g) → 2H₂O(l); ΔH = −285.8 kJ/mol
ΔH = એન્થાલ્પી ફેરફાર; વિપર્યામ પ્રક્રિયા · SI: kJ/mol · સળગાવીને અથવા પ્લેટિનમ ઉત્પ્રેરક હેઠળ
હાઇડ્રોજનનું ક્ષયકારક ગુણ: Fe₃O₄ નું રિડક્શન: Fe₃O₄(s) + 4H₂(g) → 3Fe(s) + 4H₂O(g)
Fe₃O₄ = મેગ્નેટાઇટ, Fe = આયર્ન · SI: — · તાપમાને (≈ 800–1000 K)
હાઇડ્રોજનનું ક્ષયકારક ગુણ: CuO નું રિડક્શન: CuO(s) + H₂(g) → Cu(s) + H₂O(g)
CuO = કોપર ઓક્સાઇડ, Cu = તાંબું · SI: — · ગરમ તાપમાને
હાઇડ્રોજનનું ક્ષયકારક ગુણ: PbO નું રિડક્શન: PbO(s) + H₂(g) → Pb(s) + H₂O(g)
PbO = લેડ ઓક્સાઇડ, Pb = લેડ · SI: — · ગરમ તાપમાને
ડ્યુટેરિયમનું ન્યુટ્રોન સાથે ટકરાવ (ટ્રિટિયમ બનાવતું): ²H + ¹n → ³H + γ
²H = ડ્યુટેરિયમ, ¹n = ન્યુટ્રોન, ³H = ટ્રિટિયમ, γ = ગામા કિરણ · SI: — · ન્યુક્લિયર પ્રક્રિયા; કેન્દ્રીય પ્રક્રિયાઓમાં
બોર પ્રક્રિયા (ટ્રિટિયમ ઉત્પાદન): ⁶Li + ¹n → ⁴He + ³H
⁶Li = લિથિયમ-6, ¹n = ન્યુટ્રોન, ⁴He = હિલીયમ, ³H = ટ્રિટિયમ · SI: — · ન્યુટ્રોન દ્વારા લિથિયમ-6 નું વિખંડન
ભારે જળ (D₂O) નું વિદ્યુતવિભાજન: 2D₂O(l) → 2D₂(g) + O₂(g)
D₂O = ભારે જળ, D₂ = ડ્યુટેરિયમ વાયુ, O₂ = ઑક્સિજન · SI: — · વિદ્યુતપ્રવાહ પાર કરતા
D₂O અને CO₂ વચ્ચેની વિનિમય પ્રક્રિયા: H₂O(l) + D₂O(l) ⇌ 2HDO(l)
HDO = આંશિક રીતે ડ્યુટેરેટેડ જળ · SI: — · સંતુલન પ્રક્રિયા
કાર્બન મોનોકસાઇડ સિંથેસિસ (સિંથેસિસ ગેસ): C(s) + H₂O(g) → CO(g) + H₂(g)
C = કોલસું, H₂O = બાષ્પ, CO = કાર્બન મોનોકસાઇડ, H₂ = હાઇડ્રોજન · SI: — · પ્રતિક્રિયા 1000°C તાપમાને; ઉષ્માગ્રાહી
કોપર(II) સલ્ફેટ અને સોડિયમ બાઈકાર્બોનેટથી હાઇડ્રોજન: NaBH₄ + 2H₂O → NaBO₂ + 4H₂(g)
NaBH₄ = સોડિયમ બોરાહાઈડ્રાઇડ, NaBO₂ = સોડિયમ બોરેટ · SI: — · ઓછા તાપમાને H₂ નો ઝડપી ઉત્પાદન
હાઇડ્રોજનનું સંક્રાન્તિ ધાતુ ઇન્ટરસ્ટીશિયલ હાઇડ્રાઇડ બનાવવા: M(s) + x/2 H₂(g) → MHₓ(s)
M = સંક્રાન્તિ ધાતુ (Pd, Pt, Ni, વગેરે), MHₓ = ઇન્ટરસ્ટીશિયલ હાઇડ્રાઇડ · SI: — · ઉચ્ચ દબાણે અને મધ્યમ તાપમાને
ઇયોનિક હાઇડ્રાઇડનું જળવિભાજન: MH(s) + H₂O(l) → MOH(aq) + H₂(g)
MH = આલ્કાઇ ધાતુ હાઇડ્રાઇડ (જેમ કે NaH, KH), MOH = આલ્કાઇ હાઈડ્રોક્સાઇડ · SI: — · જલીય દ્રાવણમાં ઝડપી પ્રક્રિયા
હાઇડ્રોજન પેરોક્સાઇડ (H₂O₂) નું વિઘટન: 2H₂O₂(aq) → 2H₂O(l) + O₂(g)
H₂O₂ = હાઇડ્રોજન પેરોક્સાઇડ, O₂ = ઑક્સિજન · SI: — · MnO₂, પ્રકાશ અથવા ઉષ્માની હાજરીમાં
હાઇડ્રોજન પેરોક્સાઇડનું ઓક્સિડાઇઝિંગ ગુણ (ક્ષાર્ક માધ્યમ): H₂O₂ + 2H⁺ + 2e⁻ → 2H₂O; E° = +1.77 V
E° = પ્રમાણિત ઇલેક્ટ્રોડ સંભાવના, H⁺ = એસિડિક માધ્યમ · SI: V (વોલ્ટ) · ક્ષાર્ક ઇલેક્ટ્રોડ પ્રક્રિયા
હાઇડ્રોજન પેરોક્સાઇડનું રિડ્યુસિંગ ગુણ (ક્ષાર્ક માધ્યમ): H₂O₂ + 2OH⁻ → O₂ + 2H₂O + 2e⁻; E° = −0.146 V
OH⁻ = ક્ષાર્ક માધ્યમ, O₂ = ઑક્સિજન વાયુ · SI: V (વોલ્ટ) · ક્ષાર્ક ઇલેક્ટ્રોડ પ્રક્રિયા
હાઇડ્રોજન પેરોક્સાઇડનું મોલર દળ: M(H₂O₂) = 34 g/mol
H = 1, O = 16; H₂O₂ = 2(1) + 2(16) = 34 · SI: g/mol · ગણતરીઓમાં
વોલ્યુમેટ્રિક ગ્રેડ: 'વોલ્યુમ સ્ટ્રેન્થ' (Vol. strength): Vol. strength = 11.2 × Molarity
Molarity = મોલારિટી (mol/L), 11.2 = STP પર 1 mol O₂ નું કદ (L) · SI: volume/volume · H₂O₂ ના દ્રાવણની સાંદ્રતા દર્શાવવા
પાણીની કઠિનતા (Hardness) — CaCO₃ સમતુલ્યમાં: Hardness (ppm) = (mg CaCO₃ equivalent / L) × 10⁶ / 10⁶
ppm = parts per million; mg/L = milligrams per litre · SI: ppm (mg/L) · કેલ્શિયમ/મેગ્નેશિયમ ધાતુ આયનોના આધારે
કઠિનતાનું રૂપાંતર: Ca²⁺ અને Mg²⁺ ને CaCO₃ માં: CaCO₃ equiv. (mg/L) = (ion conc. in mg/L) × (100 / ion's eq. wt.)
100 = CaCO₃ નું સમતુલ્ય દળ, eq. wt. = સમતુલ્ય દળ · SI: mg/L (as CaCO₃) · કઠિનતા માપવા માટે
સ્થાયી કઠિનતા (Permanent hardness) દૂર કરવા: સાય્ન અને ચૂનાની રીત: Ca(HCO₃)₂ + Ca(OH)₂ → 2CaCO₃↓ + 2H₂O
Ca(HCO₃)₂ = કેલ્શિયમ બાઇકાર્બોનેટ, Ca(OH)₂ = ચુનાનો પાણી · SI: — · અસ્થાયી કઠિનતા દૂર કરવા
કઠિન જળને નરમ કરવા: સાય્ન પ્રક્રિયા: CaSO₄ + Na₂CO₃ → CaCO₃↓ + Na₂SO₄
CaSO₄ = કેલ્શિયમ સલ્ફેટ, Na₂CO₃ = સોડિયમ કાર્બોનેટ · SI: — · સ્થાયી કઠિનતા દૂર કરવા
હેબર પ્રક્રિયામાં H₂ નો ઉપયોગ (NH₃ સંશ્લેષણ): N₂(g) + 3H₂(g) ⇌ 2NH₃(g); ΔH = −92.4 kJ/mol
N₂ = નાઈટ્રોજન, H₂ = હાઇડ્રોજન, NH₃ = એમોનિયા · SI: kJ/mol · ઉચ્ચ દબાણ (200 atm), Fe ઉત્પ્રેરક, 700 K
હાઇડ્રોજનનું મોલર કદ STP પર: V_m(STP) = 22.4 L/mol
STP = Standard Temperature and Pressure (273.15 K, 1 atm) · SI: L/mol · આદર્શ વાયુ માટે
હાઇડ્રોજન પરમાણુનું બોહ્ર ત્રિજ્યા: a₀ = 0.529 Å = 5.29 × 10⁻¹¹ m
a₀ = બોહ્ર ત્રિજ્યા, 1 Å = 10⁻¹0 m · SI: m (મીટર) · હાઇડ્રોજન પરમાણુના ઇલેક્ટ્રોન કક્ષાની ત્રિજ્યા
હાઇડ્રોજન પરમાણુની શોષણ/ઉત્સર્જન શ્રેણી (રિડબર્ગ સૂત્ર): 1/λ = R_H × (1/n₁² − 1/n₂²)
λ = તરંગલંબાઇ, R_H = રિડબર્ગ અચળાંક (1.09677 × 10⁷ m⁻¹), n₁ < n₂ · SI: m⁻¹ · સ્પેક્ટ્રલ સીમાઓ (Lyman, Balmer, વગેરે)
રિડબર્ગ અચળાંકનું મૂલ્ય: R_H = 1.09677 × 10⁷ m⁻¹
R_H = હાઇડ્રોજન માટે રિડબર્ગ અચળાંક · SI: m⁻¹ · સ્પેક્ટ્રલ રેખાઓની ગણતરી
ડ્યુટેરિયમ અને ટ્રિટિયમનું ન્યુક્લિયર સંયોજન (Fusion): ²H + ³H → ⁴He + ¹n + 17.6 MeV
²H = ડ્યુટેરિયમ, ³H = ટ્રિટિયમ, ⁴He = હિલીયમ, ¹n = ન્યુટ્રોન · SI: MeV (શક્તિ) · ન્યુક્લિયર ફ્યુઝન પ્રક્રિયા
H₂ નું આયનાઇઝેશન ઊર્જા: IE(H₂) = 15.42 eV
IE = આયનાઇઝેશન ઊર્જા, 1 eV = 1.602 × 10⁻¹9 J · SI: eV અથવા J · H₂ અણુમાંથી ઇલેક્ટ્રોન દૂર કરવા
હાઇડ્રોજન બંધન ઉર્જા (H—H બંધન): D(H—H) = 436 kJ/mol
D = બંધન વિઘટન ઊર્જા (Bond dissociation energy) · SI: kJ/mol · H₂ અણુમાં H—H બંધ તોડવા
ભારે જળ (D₂O) નું મોલર દળ: M(D₂O) = 20 g/mol
D = 2 g/mol, O = 16 g/mol; D₂O = 2(2) + 16 = 20 · SI: g/mol · ગણતરીઓમાં
કુદરતી હાઇડ્રોજનમાં D નું પ્રમાણ: D/H ≈ 1 : 6400
D = ડ્યુટેરિયમ, H = સામાન્ય હાઇડ્રોજન · SI: ગુણોત્તર · કુદરતી સ્રોતોમાં

🔗 સંબંધો

  • હાઇડ્રોજનનું પરમાણુદળ (1 u) આવર્ત કોષ્ટકમાં પ્રથમ તત્વ તરીકે સ્થાન આપવાનો મુખ્ય આધાર છે.
  • H₂O₂ નું 'વોલ્યુમ સ્ટ્રેન્થ' અને મોલારિટી વચ્ચે સીધો સંબંધ છે: Vol. strength = 11.2 × M.
  • જળની કઠિનતા (ppm માં) એ CaCO₃ ના સમતુલ્ય દળ પર આધારિત છે, જે Ca²⁺ અને Mg²⁺ આયનોના કુલ પરિમાણ દર્શાવે છે.
  • ડ્યુટેરિયમ (D) અને ટ્રિટિયમ (T) ની વચ્ચે દળ ગુણોત્તર 2:3 છે, પરંતુ રાસાયણિક ગુણધર્મો સમાન હોય છે.
  • ભારે જળ (D₂O) નું મોલર દળ સામાન્ય જળ (H₂O) કરતાં બમણું ન હોય પણ 20 g/mol હોય છે, જે H₂O (18 g/mol) કરતાં થોડું વધુ છે.
  • હાઇડ્રોજન પેરોક્સાઇડ બંને ઓક્સિડાઇઝિંગ અને રિડ્યુસિંગ એજન્ટ તરીકે કામ કરી શકે છે — આ તેના AMPHOTERIC ઓક્સિડેશન-રિડક્શન વર્તણૂકનું પરિણામ છે.
  • હાઇડ્રોજનનું આયનાઇઝેશન ઊર્જા (15.42 eV) હિલીયમ પછીના તમામ તત્વો કરતાં વધુ છે, જે H₂ અણુની સ્થિરતા દર્શાવે છે.

🎯 ટ્રિક્સ

D₂O નું મોલર દળ સરળતાથી મેળવવા: D = 2 u, તેથી D₂O = 2×2 + 16 = 20 g/mol; સામાન્ય Jળ H₂O = 18 g/mol. ગુણોત્તર 20:18 = 10:9.
H₂O₂ નું વોલ્યુમ સ્ટ્રેન્થ જાણીને મોલારિટી મેળવવા: M = Vol.strength ÷ 11.2; ઉદા. 11.2 vol → 1 M.
કઠિનતા ppm માં = mg/L as CaCO₃; 1 mmol/L Ca²⁺ = 100 ppm as CaCO₃ (કારણ કે CaCO₃ નું સમતુલ્ય દળ 50 ને બદલે 100 g/mol છે, પરંતુ 1 mmol/L × 100 mg/mmol = 100 mg/L).
સંક્રાન્તિ ધાતુઓ દ્વારા H₂ નું શોષણ (adsorption) — Pd, Pt, Ni હાઇડ્રોજનને પોતાની સપાટી પર ધારણ કરે છે, જેથી તે 'ઓક્ક્યુપેન્સી' દર્શાવે છે; ઇન્ટરસ્ટીશિયલ હાઇડ્રાઇડ બને છે.
રિડબર્ગ સૂત્રમાં Lyman શ્રેણી માટે n₁ = 1, Balmer માટે n₁ = 2 યાદ રાખો: Lyman = UV, Balmer = દૃશ્યમાન પ્રકાશ.

⚠️ ભૂલો

H₂O₂ ને માત્ર ઓક્સિડાઇઝિંગ એજન્ટ માનવું; પણ તે ક્ષાર્ક માધ્યમમાં રિડ્યુસિંગ એજન્ટ પણ છે — બંને પ્રકારની પ્રક્રિયાઓ શક્ય છે.
ભારે જળ (D₂O) નું મોલર દળ 18 g/mol લખવું (તે H₂O નું છે); સાચું મૂલ્ય 20 g/mol છે.
ટ્રિટિયમ (T) ને સ્થિર આઈસોટોપ માનવું — તે રેડિયોએક્ટિવ છે અને β⁻ કણ નિકાલે છે.
H₂ નું બંધન વિઘટન ઊર્જા 436 kJ/mol ને બદલે 436 kJ લખવું એ એકમ ગalti છે — તે 'per mol' હોવું જરૂરી છે.
જળવિભાજન પ્રક્રિયામાં NaBH₄ + H₂O → NaBO₂ + 4H₂ એ સંતુલિત સમીકરણ છે; ઘણા વિદ્યાર્થીઓ H₂ નો ગુણાંક 4 ને બદલે 2 લખે છે.
કઠિનતા માપવામાં Ca²⁺ અને Mg²⁺ બંનેનો સમાવેશ થાય છે; માત્ર એક આયનને ગણતરીમાં લેવો ભૂલ છે.
CH₄ + H₂O → CO + 3H₂ પ્રક્રિયામાં H₂ નો ગુણાંક 3 લખવો જરૂરી છે; ઘણા 1 અથવા 2 લખી દે છે.
