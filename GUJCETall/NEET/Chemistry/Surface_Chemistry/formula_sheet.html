પૃષ્ઠરાસાયણિક (Surface Chemistry) — સૂત્ર શેડ

⚡ સૂત્રો

ફ્રેન્ડલિચ અધશોષણ આઇસોથર્મ (Freundlich Adsorption Isotherm): x/m = k · P^(1/n)
x = અધશોષિત વાયુના દળનું પ્રમાણ, m = અધશોષક (Adsorbent) નું દળ, P = વાયુનો દબાણ, k અને n = અચળાંકો (n > 1) · SI: k એકમ દબાણ પર આધારિત; x/m એકમરહિત ગુણોત્તર · મધ્યમ દબાણ અને મધ્યમ તાપમાને વાયુ-ઘન અધશોષણ માટે
લઘુગણકીય રૂપ — ફ્રેન્ડલિચ સમીકરણ: log(x/m) = log k + (1/n) · log P
log(x/m) = અધશોષણ ઘનતાનું લઘુગણક, k અને n = પ્રयोगાત્મક અચળાંકો, P = દબાણ · SI: લઘુગણક રૂપ એકમરહિત · ફ્રેન્ડલિચ આઇસોથર્મનું રેખીય આલેખન સ્વરૂપ
ઉચ્ચ દબાણ પર — ફ્રેન્ડલિચ મર્યાદા: x/m ∝ P¹ (અથવા x/m = k) | log(x/m) = log k
x/m = સ્થિરાંક, P = દબાણ, k = અચળાંક · SI: એકમરહિત · જ્યારે દબાણ ખૂબ ઊંચું હોય (n → 1)
નીચું દબાણ પર — ફ્રેન્ડલિચ મર્યાદા: x/m ∝ P^(1/n) | log(x/m) = log k + (1/n)·log P (ઢાળ = 1/n)
1/n < 1, x/m = ઓછું, k અને n = અચળાંકો · SI: એકમરહિત · જ્યારે દબાણ નીચું હોય (આંશિક દબાણ)
ફ્રેન્ડલિચ આઇસોથર્મ — દબાણ = 1 હોય ત્યારે: log(x/m) = log k ⟹ x/m = k
k = ફ્રેન્ડલિચ અચળાંક, x/m = અધશોષણ ઘનતા · SI: એકમરહિત · જ્યારે log P = 0 (P = 1 atm), આલેખનો Y-અનતર છેદ
પ્રોટીન-લિપિડ અંતરપટલ (PMV) / ઝીટા વિભવ સંબંધ (સૈદ્ધાંતિક): ζ = (η · μ_e) / ε | v = μ_e · E
ζ = ઝીટા વિભવ, η = માધ્યમનું સ્નિગ્ધતા ગુણાંક, μ_e = વિદ્યુતગમનક્ષમતા, ε = પરમિટિવિટી, v = કણની ઝડપ, E = વિદ્યુતક્ષેત્ર તીવ્રતા · SI: ζ: V (વોલ્ટ), μ_e: m²·V⁻¹·s⁻¹, η: Pa·s, E: V·m⁻¹ · વિદ્યુતસંચલન / ઇલેક્ટ્રોફોરેસિસ સંબંધિત ગણતરીઓમાં
સપૃષ્ઠતા તણાવ અને પૃષ્ઠ ઉર્જા વચ્ચેનો સંબંધ: γ = ΔE_s / ΔA ⟹ S.T. = કણીય બળ / ક્ષેત્રફળ = જોડવું-ઉર્જા / ક્ષેત્રફળ
γ = સપૃષ્ઠતા તણાવ (S.T.), ΔE_s = પૃષ્ઠ ઉર્જામાં ફેરફાર, ΔA = ક્ષેત્રફળમાં ફેરફાર · SI: N·m⁻¹ અથવા J·m⁻² · તરલના પૃષ્ઠ વિસ્તરણ અથવા બાષ્પબિંદુ બનતી વખતે
પાત્રનલિકા ઉથલ (Capillary Rise): h = (2T cos θ) / (r ρ g)
h = ઊંડાણ (કેપિલરી ઊંચાઈ), T = સપૃષ્ઠતા તણાવ, θ = સંસ્રમણીય કોણ (Contact angle), r = નલિકા ત્રિજ્યા, ρ = દ્રવની ઘનતા, g = ગુરુત્વાકર્ષણ પ્રવેગ · SI: h: m, T: N·m⁻¹, r: m, ρ: kg·m⁻³, g: m·s⁻² · સંસ્રમણીય (wetting) દ્રવ — વાંકી ચઢાણ પૃષ્ઠ; θ < 90°
કેલ્વિનનું સૂત્ર (Kelvin Equation) — વળેલી પૃષ્ઠીય વાષ્પદબાણ: ln(P_r / P_0) = (2γM) / (ρ R T r)
P_r = ત્રિજ્યા r ધરાવતા વળેલા પૃષ્ઠનું વાષ્પદબાણ, P_0 = સમતલ પૃષ્ઠનું વાષ્પદબાણ, γ = સપૃષ્ઠતા તણાવ, M = મોલર દળ, ρ = ઘનતા, R = સામાન્ય વાયુ અચળાંક, T = તાપમાન, r = કણ/બિંદુ ત્રિજ્યા · SI: બધા SI એકમોમાં · સૂક્ષ્મ કણો, બુરકા, ફોમ અને વરસાદનાં બિંદુઓ માટે; r ખૂબ નાનું
Ostwald–Freundlich સમીકરણ (દ્રાવ્યતા અને કણ ત્રિજ્યા): ln(c_r / c_0) = (2γ M) / (ρ R T r)
c_r = ત્રિજ્યા r ધરાવતા કણની દ્રાવ્યતા, c_0 = મોટા/સમતલ ક્રિસ્ટલની દ્રાવ્યતા, અન્ય પ્રતીકો ઉપર મુજબ · SI: c: mol·m⁻³ અથવા g·L⁻¹ · નાના કણોની વધેલી દ્રાવ્યતા સમજાવવા; નાના કણો = વધુ દ્રાવ્ય
Eötvös નિયમ — સપૃષ્ઠતા તણાવ-તાપમાન સંબંધ: γ · V_m^(2/3) = k · (T_c − T)
γ = સપૃષ્ઠતા તણાવ, V_m = મોલર કદ, k = Eötvös અચળાંક (~1.1 × 10⁻⁷ J·K⁻¹·mol^(-2/3)), T_c = ક્રાંતિક તાપમાન, T = પરિવર્તિત તાપમાન · SI: γ: N·m⁻¹, V_m: m³·mol⁻¹, T: K · તાપમાન વધતા સપૃષ્ઠતા તણાવ ઘટે છે તે દર્શાવે છે
સંસ્રમણીય કોણ અને પાત્રની આકૃતિ સંબંધ: θ < 90° → અસંસ્રમણીય ઘસારો (Concave meniscus) | θ > 90° → ઉત્સરમણીય (Convex meniscus) | θ = 90° → સમતલ
θ = સંસ્રમણીય કોણ (Contact Angle), ઘર્ષણબળ vs. સંસ્રમણબળ પર આધારિત · SI: θ: રેડિયન અથવા ડિગ્રી · દ્રવ-ઘન પૃષ્ઠીય આંતરક્રિયાઓ, પાત્રનલિકા ઘટનાઓ
હાર્ડી-શુલ્ઝનો નિયમ — સંકોચનક્ષમતા (Coagulation) સંબંધિત: વિપરીત વીજભાર ધરાવતું આયન જ્યારે વધુ વેલેન્સ ધરાવતું હોય → મજબૂત સંકોચનક્ષમતા
વીજભાર ધરાવતા આયનની વેલેન્સ ∝ સંકોચનક્ષમતાની ક્ષમતા; પ્રતિ-આયન (Counter-ion) નો ભાગ · SI: વેલેન્સ એકમરહિત, સંકોચનક્ષમતા મિલિમોલ/L · કોલોઇડલ વિલયનું સંકોચન (Coagulation/Flocculation); વિપરીત વીજભારી આયનની અસર
ગોલ્ડ સંખ્યા (Gold Number) — રક્ષક કોલોઇડ: ગોલ્ડ સંખ્યા = ન્યૂનતમ mg રક્ષક કોલોઇડ / 10 cc પ્રમાણભૂત સોલ, જે વિલયને લાલ/અરેત (Reddish) બનાવે
નાની ગોલ્ડ સંખ્યા = મજબૂત રક્ષક અસર; સોડિયમ કાચ (Collodion) ≈ 0.005–0.01 mg · SI: mg (મિલિગ્રામ) · લ્યુબ્રિકેટીવ (Lyophobic) કોલોઇડનું રક્ષણ કરતા લ્યુબ્રિકેટીંગ (Lyophilic) કોલોઇડની ક્ષમતા માપવા
વિદ્યુતસંચલન ગતિ (Electrophoretic Mobility): μ_e = v / E | v = d/t | ζ = (η · v) / (ε · E)
μ_e = વિદ્યુતગમનક્ષમતા (m²·V⁻¹·s⁻¹), v = કણ ઝડપ (m/s), E = વિદ્યુતક્ષેત્ર (V/m), d = અંતર, t = સમય, η = સ્નિગ્ધતા, ε = પરમિટિવિટી, ζ = ઝીટા વિભવ · SI: μ_e: m²·V⁻¹·s⁻¹, v: m·s⁻¹, E: V·m⁻¹, ζ: V · ઇલેક્ટ્રોફોરેસિસ પ્રયોગોમાં કણોની ગતિ માપવા
બ્રاونિય ગતિ ગતિશક્તિ સંબંધ (સૈદ્ધાંતિક): KE_avg = (3/2) k_B T | r_ms = √(3k_B T / m)
k_B = બોલ્ટ્ઝમેન અચળાંક (1.38 × 10⁻²³ J/K), T = તાપમાન (K), m = કણ દળ, r_ms = રૂટ-મીન-સ્ક્વેર વેગ · SI: KE: J, v: m·s⁻¹, T: K · કોલોઇડલ કણોની બ્રાઉનિય ગતિની આંકડાકીય ગણતરીઓ
સપૃષ્ઠતા તણાવ અને વ્યાસમાં ફેરફાર: ΔE = T · ΔA | W = T · 4π(r_f² − r_i²)
W = કાર્ય, ΔE = ઉર્જા ફેરફાર, T = સપૃષ્ઠતા તણાવ, ΔA = ક્ષેત્રફળ ફેરફાર, r_i/r_f = પ્રારંભિક/અંતિમ ત્રિજ્યા · SI: W: J, T: N·m⁻¹, A: m² · બુરકા / સૂક્ષ્મ બિંદુ બનાવવા / તૂટવાના કાર્યમાં

🔗 સંબંધો

  • ફ્રેન્ડલિચ આઇસોથર્મ: x/m = k·P^(1/n) — x/m અને P વચ્ચેનો વક્ર રેખીય નથી; log-log આલેખ રેખીય બનાવે છે. ઢાળ = 1/n.
  • ઉચ્ચ દબાણ પર (n → 1): x/m ∝ P; નીચું દબાણ (n > 1): x/m ∝ P^(1/n) જેમ 1/n < 1.
  • અધશોષણ સदैव ઉષ્માક્ષેપક છે: adsorption ઉષ્મા ΔH_ads < 0 (એન્થાલ્પી ઋણ).
  • તાપમાન વધારવાથી ભૌતિક અધશોષણ ઘટે (ઉષ્માક્ષેપક) પરંતુ રાસાયણિક અધશોષણ પ્રારંભમાં વધી શકે.
  • સપ૜ષ્ઠતા તણાવ γ તાપમાન વધતા ઘટે છે (Eötvös): γ = k(T_c − T)/V_m^(2/3).
  • કેપિલરી ઊંચાઈ h ∝ 1/r: સૂક્ષ્મ નલિકામાં ઊંચું ઊભું ઊંડાણ.
  • કેલ્વિન સમીકરણ: chhota નાના r માટે P_r/P_0 > 1 (વાષ્પદબાણ વધે).
  • હાર્ડી-શુલ્ઝ: સંકોચનક્ષમતા સક્ષમ પ્રતિ-આયનની વેલેન્સ ∝ વિપરીત વીજભારિત આયન.
  • ગોલ્ડ સંખ્યા ↔ રક્ષક ક્ષમતા: ગોલ્ડ સંખ્યા જيتલી નાની, રક્ષક કોલોઇડ ત્યતી મજબૂત.
  • ઝીટા વિભવ ↔ સ્થિરતા: વધુ ઝીટા વિભવ = વધુ સ્થિર કોલોઇડ; ~30 mV બિંદુએ સંકોચન થાય છે.

🎯 ટ્રિક્સ

ફ્રેન્ડલિચ સમીકરણનું log-log આલેખ: ઢાળ = 1/n, Y-અનતર છેદ = log k. n > 1 હોવાથી ઢાળ હંમેશા 1 થી ઓછો.
ઉચ્ચ દબાણે x/m ∝ P¹; નીચું દબાણે x/m ∝ P^(1/n) — જ્ઞાનથી આઇસોથર્મના ત્રણ ક્ષેત્રો યાદ રાખો: ઘાતાંકીય, રેખીય, સંપૂર્ણ સમાધાન.
ધન અધશોષણ ΔH < 0 (ઉષ્માક્ષેપક), ΔS < 0, ΔG < 0. ΔG = ΔH − TΔS; ધન ΔH થી ΔG ઋણ થવા માટે ΔS ધન હોવો જરૂરી (અહીં ધન નથી, પણ અંશબંધ તાપમાનની મર્યાદામાં સ્વયંભૂ).
હેડે-શુલ્ઝનો નિયમ: 'વીજભારની સંખ્યા (Charge density) ∝ સંકોચનક્ષમતા' — Na⁺ < Ca²⁺ < Al³⁺ ક્રમમાં સંકોચનક્ષમતા વધે.
ગોલ્ડ સંખ્યા યાદ રાખવા: પ્રોટીન ≈ 0.03–0.10 mg; સ્ટાર્ચ ≈ 1.5–2.5 mg — પ્રોટીન વધુ પ્રભાવી રક્ષક.
સપૃષ્ઠતા તણાવ ઘટાડનારા પદાર્થો (Surface active agents/Surfactants) ને ટ્રિટ્ઝ એકસરખા યાદ રાખો: Na₂SO₄ (ઉદાહરણ), NaCl, KCl — આવા ઇલેક્ટ્રોલાઇટ્સ સપૃષ્ઠતા તણાવ વધારે છે.
કેપિલરી ઊંચાઈ h = 2T/(rρg) — d વ્યાસ (d = 2r) નો ઉપયોગ કરો: h = 4T/(dρg). વ્યાસ ∝ 1/h.
