પર્યાવરણ રસાયણશાસ્ત્ર — સૂત્ર શેડ (Formula Sheet)

🧪 GUJCET — Gujarati • Chemistry • Environmental Chemistry

⚡ સૂત્રો

વરષાના પાણીનો સ્વાભાવિક pH: pH = −log[H+]
[H+] = જળીય દ્રાવણમાં હાઇડ્રોજન આયનની મોલાર સાંદ્રતા (mol L⁻¹); વરષાના પાણીમાં CO₂ દ્રાવ્ય થઈ H₂CO₃ બનાવે છે, જેથી [H+] ≈ 2.5 × 10⁻⁶ mol L⁻¹ અને pH ≈ 5.6 · SI: dimensionless (એકમ રહિત) · 25 °C તાપમાને સામાન્ય વરષાના પાણી માટે લાગુ
pH ની ગણતરી (સામાન્ય): pH = −log₁₀[H+]
[H+] = H⁺ આયનોની મોલાર સાંદ્રતા; pH = એસિડિટીનું માપ · SI: dimensionless · સૌથી સામાન્ય દ્રાવણો માટે લાગુ
pOH ની ગણતરી: pOH = −log₁₀[OH−]
[OH−] = હાઇડ્રોક્સાઇડ આયનની મોલાર સાંદ્રતા; pOH = દ્રાવણની ક્ષારકતા (alkalinity) નું માપ · SI: dimensionless · 25 °C તાપમાને pH + pOH = 14
pH અને pOH વચ્ચેનો સંબંધ: pH + pOH = 14
25 °C તાપમાને જલ સંદિસંયત્વ અચળાંક Kw = 1.0 × 10⁻¹⁴ હોવાથી · SI: dimensionless · 25 °C (298 K) પર જળીય દ્રાવણ માટે
BOD (જૈવિક ઑક્સિજન માંગણી): BOD (mg L⁻¹) = (DO_initial − DO_final) × V_sample / V_bottle
DO_initial = પ્રારંભિક દ્રાવ્ય ઑક્સિજન (mg L⁻¹); DO_final = 5 દિવસના ઇન્ક્યુબેશન બાદ અંતિમ દ્રાવ્ય ઑક્સિજન; V_sample = નમૂનાનું કદ; V_bottle = BOD બોટલનું કદ. સામાન્ય રીતે V_sample = V_bottle હોય તો BOD = DO_initial − DO_final. · SI: mg L⁻¹ (mg प्रति ליטר) · 5 દિવસ, 27 °C (Standard BOD test) પર માપવામાં આવે છે
COD (રાસાયણિક ઑક્સિજન માંગણી): COD (mg L⁻¹) = (V_blank − V_sample) × M_K2Cr2O7 × 8000 / V aliquot
V_blank = ખાલી ટાઇટ્રેશનમાં વપરાયેલ FeSO₄નું કદ; V_sample = નમૂના માટે વપરાયેલ FeSO₄નું કદ; M_K2Cr2O7 = પોટેશિયમ ડાયક્રોમેટની મોલારિટી; 8000 = ઑક્સિજનનું તુલ્યભાર (16×50) સ્વરૂપ; V aliquot = COD માટે લેવાયેલા નમૂનાનું કદ mL માં · SI: mg L⁻¹ · ક્ષારકીય માધ્યમમાં K₂Cr₂O₇ વડે ઑર્ગેનિક પદાર્થોના ઑક્સિડેશન દ્વારા માપવામાં આવે છે
ઓઝોન સ્તરનું ઘટાડો — ક્લોરીન મુક્ત મુક્તક (Cl•) નો ઉત્પ્રેરક વિઘટન: Cl• + O₃ → ClO• + O₂ ClO• + O → Cl• + O₂ net: O₃ + O → 2O₂
Cl• = ક્લોરીન મુક્ત મુક્તક; O₃ = ઓઝોન; ClO• = ક્લોરીન મોનોક્સાઇડ મુક્ત મુક્તક; O = પરમાણ્વીય ઑક્સિજન. Cl• ઉત્પ્રેરક તરીકે કાર્ય કરે છે. · SI: N/A (રાસાયણિક સંતુલિત પ્રક્રિયા) · stratosphere (~15–35 km ઉંચાઇ) માં UV કિરણો વડે CFCs થી Cl• મુક્ત થાય છે
CFC-11 (CCl₃F) નું UV વિઘટન — Cl• મુક્તિ: CCl₃F + hv(λ < 220 nm) → Cl• + •CCl₂F
hv = UV ફોટોન; CCl₃F = ફ્રિઓન-11 (CFC); λ < 220 nm = stratospheric UV તરંગલંબાઇ · SI: N/A · stratosphere માં ઉચ્ચ ઊર્જા યુક્ત UV કિરણો દ્વારા CFC ના C–Cl બંધનું વિભાજન
CFC-12 (CCl₂F₂) નું UV વિઘટન: CCl₂F₂ + hv(λ < 220 nm) → Cl• + •CClF₂
CCl₂F₂ = ફ્રિઓન-12 (CFC-12); Cl• = ક્લોરીન મુક્ત મુક્તક · SI: N/A · stratospheric UV વડે CFC-12 નું વિભાજન
NOₓ દ્વારા ઓઝોન વિઘટન: NO• + O₃ → NO₂• + O₂ NO₂• + O → NO• + O₂ net: O₃ + O → 2O₂
NO• = નાઇટ્રિક ઑક્સાઇડ મુક્ત મુક્તક; NO₂• = નાઇટ્રોજન ડાયોકસાઇડ મુક્ત મુક્તક · SI: N/A · stratosphere માં.supersonic aircraft દ્વારા ઉચ્ચ ઊંચાઇએ NOₓ ની છૂટ
હેનરીના નિયમ દ્વારા વાયુનો જલદ્રાવ્યતા: p = KH × x
p = વાયુનું આંશિક દબાણ; KH = હેનરી અચળાંક; x = દ્રાવણમાં વાયુનો મોલ ભાગ (mole fraction) · SI: KH: bar (અથવા atm); p: bar (અથવા atm) · દ્રાવ્યતા ઓછી હોય અને દ્રાવણ તત્સમભાવે વર્તે તેવી શરતે
CO₂ સાંદ્રતામાં વધારો (%) — ઐતિહાસિક ડેટા: વર્ધન % = (C_current − C_preindustrial) / C_preindustrial × 100
C_current = વર્તમાન વાતાવરણીય CO₂ સાંદ્રતા (~420 ppm, 2024 સુધી); C_preindustrial = આગેકરોધયુગની સાંદ્રતા (~280 ppm) · SI: ppm (parts per million) અથવા % · ગ્લોબલ વોર્મિંગ અભ્યાસ માટે
પ્રકાશરાસાયણિક ધૂમ્રપીડ (Photochemical Smog) રચના — પ્રારંભિક પ્રક્રિયા: NO₂ + hv(λ < 420 nm) → NO• + O• O• + O₂ → O₃
NO₂ = નાઇટ્રોજન ડાયોકસાઇડ; hv = પ્રકાશ ફોટોન; O• = પરમાણ્વીય ઑક્સિજન; O₃ = ઓઝોન · SI: N/A · સૂર્યપ્રકાશની उपસ્ଥିতিમાં NO₂ નું વિભાજન થાય છે
પ્રકાશરાસાયણિક ધૂમ્રપીડ — O₃ અને PAN રચના: O₃ + RCH=CH₂ → Ozonide →醛 + O• O• + O₂ → O₃ NO₂ + O₃ → NO₃• → N₂O₅ → PAN રચના (peroxyacetyl nitrate)
RCH=CH₂ = અતૃપ્ત હાઇડ્રોકાર્બન (veh exhaust); PAN = પેરોક્સીએસિટાઇલ નાઇટ્રેટ, એક ગંભીર દૂષક · SI: N/A · સૂર્યપ્રકાશ, NOₓ અને હાઇડ્રોકાર્બનની ઉપસ્થિતિમાં
ક્ષારકીય વરষા pH (સામાન્ય vs પ્રદૂષિત): સામાન્ય વરષા: pH ≈ 5.6 (CO₂ નિમિત્તે H₂CO₃) ક્ષારકીય વરષા: pH < 5.6 (SO₂ + NOₓ નિમિત્તે H₂SO₄ / HNO₃)
SO₂ + H₂O → H₂SO₃ → H₂SO₄ (સल्फ्यूरिक એસિડ); NOₓ + H₂O → HNO₃ (નાઇટ્રિક એસિડ) · SI: dimensionless (pH) · ઉદ્યોગ અને વાહનોમાંથી ઉત્પન્ન SO₂ અને NOₓ ના કારણે
ગ્રીનહાઉસ અસર — IR શોષણ સંબંધિત સિદ્ધાંત: ΔT ∝ ln(C / C₀) (CO₂ સાંદ્રતા બે ગણી થાય ત્યારે तापમાनમાં ~1 °C વધારો અંદાજે)
ΔT = ગ્રીનહાઉસ કારણે તાપમાનમાં વધારો; C = વર્તમાન CO₂ સાંદ્રતા; C₀ = આગેકરોધયુગની સાંદ્રતા · SI: °C અથવા K · રેખીય નહીં, પરંતુ લઘુગણકીય (logarithmic) સંબંધ
જલ પ્રદૂષણ માટે DO નું મહત્વ: DO (mg L⁻¹) ≥ 6 mg L⁻¹ : સ્વચ્છ જଳ DO < 5 mg L⁻¹ : મધ્યમ પ્રદૂષણ DO < 2–3 mg L⁻¹ : ગંભીર પ્રદૂષણ
DO = દ્રાવ્ય ઑક્સિજન (Dissolved Oxygen); જલીય જીવનના ચાલુ રાખવા માટે આવશ્યક · SI: mg L⁻¹ · નદી/સરોવર/સમુદ્રના જળગુણવત્તા મૂલ્યાંકન માટે

🔗 સંબંધો

  • BOD અને COD વચ્ચેનો સંબંધ: COD ≥ BOD હંમેશા; COD બધા જ ઑર્ગેનિક પદાર્થો (જૈવિક + અજૈવિક) ને ઑક્સિડાઇઝ કરે છે, જ્યારે BOD માત્ર જૈવિક રીતે વિઘટનશીલ પદાર્થોને માપે છે.
  • pH અને [H⁺] વચ્ચે વિપરીત સંબંધ: pH જેટલો ઓછો, [H⁺] તેટલું વધારે; pHમાં 1 એકમનો ફેરફાર = [H⁺] માં 10 ગુણા ફેરફાર.
  • CO₂ સાંદ્રતા અને ગ્લોબલ તાપમાન વચ્ચે ધન સહસંબંધ: CO₂ વધે તેમ સરેરાશ ભૂતಾપીય તાપમાન પણ વધે છે.
  • CFC નું ઉચ્ચ stratospheric અસ્તિત્વ = વધુ ઓઝોન વિઘટન; એક Cl• પરમાણુ હજારો O₃ અણુઓને નष्ट કરી શકે છે.
  • ક્ષારકીય વરષાનું કારણ: SO₂ અને NOₓ નું વાતાવરણમાં જળવિભાજન થઈ પ્રબળ એસિડ (H₂SO₄, HNO₃) બનાવે છે, જેથી pH 5.6 કરતાં ઓછું થાય છે.
  • ઓઝોન સ્તર ઘટવાથી stratosphere નું તાપમાન ઘટે છે પરંતુ troposphere નું તાપમાન વધે છે — બંને વિપરીત દિશામાં અસર.

🎯 ટ્રિક્સ

BOD = (DO_initial − DO_final) જ્યારે નમૂનો બોટલ પૂરું ભરતું હોય — આ સીધી બાદબાકી યાદ રાખો, ગુણાકાર/ભાગાકારની જરૂર નથી.
pHમાં 1 એકમનો ફેરફાર એટલે [H⁺] માં 10× ફેરફાર: pH 3 → pH 4 એટલે [H⁺] 10 ગણો ઘટે; આ સંખ્યાત્મક સૂઝ GUJCET માં બહુ આવે છે.
CFC → Cl• → O₃ → O₂ ની chain reaction યાદ રાખવા સૂત્ર: 'एक Cl ने हज़ारों O₃ को मारा' — એક ક્લોરીન પરમાણુ સેંકડો ઓઝોન અણુઓ વિઘટિત કરી શકે છે.
COD ≥ BOD — આ તુલના યાદ રાખો: COD સदैव BOD કરતાં મોટો કે সমান હોય છે; ક્યારેય COD < BOD ન હોઈ શકે.
સામાન્ય વરષા pH = 5.6 (CO₂ નિમિત્તે); ક્ષારકીય વરષા pH < 5.6 (SO₂/NOₓ નિમિત્તે) — આ બે સંખ્યાઓ બાકી રાખો.
NO₂ નું UV વિભાજન λ < 420 nm — આ તરંગલંબાથે પ્રકાશરાસાયણિક ધૂમ્રપીડ શરૂ થાય છે; આ કડી યાદ રાખો.

⚠️ ભૂલો

BOD નું સૂત્ર જ્યારે નમૂનો બોટલ પૂરું ભરે ન હોય ત્યારે (DO_initial − DO_final) જ લખી દેવાય છે — સાચું સૂત્ર BOD = (DO_initial − DO_final) × (V_bottle / V_sample).
pH + pOH = 14 માત્ર 25 °C તાપમાને સાચું છે; અન્ય તાપમાને Kw બદલાય છે અને સરવાળો 14 રહેતો નથી.
CFC માત્ર refrigerator/AC માં જ નહીં, પણ propellant અને solvent તરીકે પણ વપરાતું હતું — એકલે કારણ યાદ રાખવું ભૂલ છે.
COD અને BOD બંનેનું SI એકમ mg L⁻¹ છે, પણ તેમનો അർથ ભિન્ન છે — COD રાસાયણિક, BOD જૈવિક.
ડાઇઓક્સિન (Dioxin) એ CFC નું વિઘટન ઉત્પાદન નથી; ડાઇઓક્સિન જ્વલન પ્રક્રિયામાં બને છે — આ ભ્રમણા ઘણીવાર આવે છે.
ઓઝોન સ્તર 'ઓઝોન છિદ્ર' ખરેખર Antarctic ઉપર દેખાયું છે; તેનું કારણ CFC નો Cl• છે, પણ O₃ ઘટવાથી ધરતીનું સપાટી તાપમાન સીધું ઘટે તેવું માનવું ભૂલ છે.
પ્રકાશરાસાયણિક ધૂમ્રપીડ (Photochemical smog) અને સल्फ्यूरिक धूम्रपীડ (London-type) વચ્ચેનો તફાવત ગૂંચવી જવો — પ્રથમ સૂર્યપ્રકાશ, NOₓ, O₃, PAN વડે; બીજો ઠંડું, ભીનું, SO₂ + fog વડે.
વરષાનું સામાન્ય pH 5.6 છે (શુદ્ધ નહીં, CO₂ નિમિત્તે એસિડિક); 7.0 લખવું ભૂલ છે.
