p-Block તત્વો — ઝડપીરીવીઝન નોટ્સ

🧪 GUJCET — Gujarati • Chemistry • p-Block Elements

📘 વ્યાખ્યાઓ

  • વૈષમ્ય (Anomalous behaviour): પ્રથમ પંક્તિના p-બ્લોક તત્વોનો બાકીના સદસ્યોથી ભિન્ન ગુણધર્મો દેખાડવો.
  • બોરેઝ (Borazine - B₃N₃H₆): બોરોન-નાઇટ્રોજન વલય સંયોગ; 'ઇનઓર્ગેનિક બેન્ઝીન' કહેવાય છે.
  • વલય સંયોજકતા (Group valency): બહિઃસ્તરની સંયોજકતા + ચાર;
  • ઇનર્ટ પેર અસર (Inert pair effect): ns² ઇલેક્ટ્રોનયુગ્મનો ઑક્સિડેશન અવસ્થામાં ભાગ લેવાને અકારણ રહેવું.
  • કેટેનേഷન (Catenation): સમાન તત્વના પરમાણુઓ એકબીજા સાથે જंजीર/વલય બનાવવાની ક્ષમતા.
  • એલોટ્રોપી (Allotropy): એક જ તત્વના વિવિધ ભૌતિક રૂપો.
  • પોલીહેલાઇડ આયન (Polyhalide ion): બે કે તેથી વધુ હેલાઇડ આયનોનું સંયોજન, ઉદા. I₃⁻.
  • મિક્સ્ડ એસિડ એનહેાઇડ્રાઇડ: એક આણ્વમાં બે પ્રકારના ઑક્સિડેશન અવસ્થા ધરાવતું ઑક્સાઇડ, ઉદા. NO₂.
  • બ્લીચિંગ પાઉડર: કૅલ્શિયમ ઑક્સીક્લોરાઇડ CaOCl₂.
  • ઇન્ટરહેલાઇડ: બે વિભિન્ન હેલાઇડ તત્વોનું બનતું સંયોજન, ઉદા. ClF, IF₇.
  • ઓઝોન (O₃): ઑક્સિજનનો ત્રિપરમાણ્વીય એલોટ્રોપ, મજબૂત ઑક્સિડાઇઝિંગ કારક.
  • અક્વા રેજિયા: HCl : HNO₃ = 3 : 1 ના મોલાર ગુણોત્તર ધરાવતું મિશ્રણ; સોનેલો ઘોળે છે.
  • ઝીઓલાઇટ: એલ્યુમિનોસિલિકેટનો જાળીદાર ઠોસ; એસિડ કેટાલીસિસમાં ઉપયોગી.
  • ઑર્થોબોરિક એસિડ: H₃BO₃; દુર્બળ લૂઇસ એસિડ છે.
  • ડાઇબોરેન (B₂H€): બોરોનનું હાઇડ્રાઇડ; ત્રિ-કેન્દ્રીય બંધ (3c-2e) ધરાવે છે.

⚡ સૂત્રો

  • B₂H₆ માં B-H-B ત્રિ-કેન્દ્રીય બંધ (3c-2e).
  • BF₃ + NH₃ → F₃B←NH₃ (લૂઇસ એસિડ-બેઝ એડિટ).
  • બોરેક્સ: Na₂B₄O₇·10H₂O.
  • ગ્રેફાઇટમાં C sp² સંકર; એક π-ઇલેક્ટ્રોન મુક્ત ગતિ કરે છે.
  • HCl: H₂ + Cl₂ → 2HCl (ધૂળધાબો/પ્રકાશ ઉત્તેજક).
  • ઓસ્ટવાલ્ડ પ્રક્રિયા: 4NH₃ + 5O₂ → 4NO + 6H₂O (Pt/Rh કેટાલીસિસ).
  • સંપર્ક પ્રક્રિયા: 2SO₂ + O₂ ⇌ 2SO₃ (V₂O₅ કેટાલીસિસ, 450°C).
  • F₂ + 2NaCl → 2NaF + Cl₂.
  • CO₃²⁻ + 2H⁺ → CO₂ + H₂O (લિટમ્સ દ્વારા ચકાસણી).
  • Pb₃O₄ (લેડ આરેઇટ/મિનાકી લાલ) = 2PbO·PbO₂.
  • PbO₂ + 4HCl → PbCl₂ + Cl₂ + 2H₂O.
  • Cl₂ + H₂O → HCl + HOCl (પ્રકાશમાં: 2HOCl → 2HCl + O₂).
  • CO₂ + Ca(OH)₂ → CaCO₃ (સફેદ અવકંઠન) + H₂O.
  • 2O₃ → 3O₂ (NO સંપ્રદાયથી પ્રવેગિત).
  • PCl₃ + SO₂ → POCl₃ + SCl₂ (અથવા P + Cl₂ → PCl₃/PCl₅).

⭐ મુખ્ય તથ્યો

  • B સૌથી harder (ક્ષયકારક) ધાતુરૂપ તત્વ; ડાયમંડ પછી.
  • B ક્યારેય સરળ ધન આયન બનાવતો નથી; સહસંયોજક સંયોજનો બનાવે છે.
  • Al ની સપાટી પર Al₂O₃ ની પાતળી પણ અભેદ્ય પાતળી પડ હોય છે, જે ધાત્વિક સંરક્ષણ કરે છે.
  • બોરેક્સ જ્વલા વલય પરીક્ષણમાં બોરોન મેધ (borax bead) બનાવે છે.
  • ગ્રેફાઇટ વિદ્યુતની અચાલક નથી; સપાટી પર મુક્ત π-ઇલેક્ટ્રોન્સ થી વાહક છે.
  • હીલીયમ રહેઠાણની વાયુ પૂરવણીમાં હાઈડ્રોજનને બદલે ઉપયોગી છે (જ્વલનશીલ નથી).
  • NH₃ માં N sp³ સંકર; એક લોન પેર હોય છે.
  • HNO₃ પીળો રંગ ધરાવે છે; ઘટતો NO₂ ઘોળમાં ઓગળી ગયો હોય છે.
  • નાઇટ્રેટની ચકાસણી: 'બ્રાઉન રિંગ' [Fe(H₂O)₅(NO)]²⁺ બનતું હોય છે.
  • NH₃ નું દ્રાવણીય નિરાળું ક્ષાર બનાવવા માટે NH₄Cl ઉમેરવાથી અવરોધ થાય છે (કોમન આયન અસર).
  • O₂ માં બે અયુગ્મિત ઇલેક્ટ્રોન હોવાથી તે પરમાગ્નેટિક છે.
  • O₃ ની રચના ખંડિત/બેન્ડ છે; Kₐ ≈ 10⁻¹⁰.
  • SO₂ એ ઘટાડનાર કારક છે; એક રંગહીન કાગળ પર બ્લીચિંગ કરે છે (સ્થાયી નહીં).
  • H₂SO₄ ની સાંદ્રણમાં બંને ગુણધર્મો: દ્રાવક (dehydrating) અને ઑક્સિડાઇઝિંગ.
  • H₂O₂ = ઑક્સિડાઇઝિંગ અને ઘટાડનાર બંને; પર્યાવરણબાંધવું ઉત્પાદન.
  • F સૌથી વધુ વિદ્યુતઋણ તત્વ; ઇલેક્ટ્રોન સખાતા (electron gain enthalpy) માં Cl > F.
  • ICl સૌથી વધુ ધ્રુવીય ઇન્ટરહેલાઇડ છે.
  • Cl₂ પીળછાંકીડો વાયુ; ગંધ દમાદાર; KOH થી શોષાય છે.
  • HF માં હાઇડ્રોજન બંધ હોવાથી સામાન્ય તાપમાને પ્રવાહી છે; બાકીના હાઇડ્રોજન હેલાઇડ વાયુ.
  • He નો ઉપયોગ ડાઇવિંગ ગેસમાં Air ની જગ્યાએ થાય છે કારણ કે તે સમાધાનશીલ નથી.
  • Ar નો ઉપયોગ તત્વજ્ઞાન બલ્બમાં ફિલામેન્ટને ઑક્સિડેશનથી બચાવવા માટે થાય છે.
  • XeF₂ રેખીય; XeF₄ ચતુષ્ફલકીય; XeF₆ વિકૃત અષ્ટફલકીય.
  • KrF₂ એકમાત્ર ડાયેલીક્ટ્રિક (diamagnetic) નોબલ ગેસ સંયોજન છે.
  • N₂ માં Trriple bond હોવાથી તે રાસાયણિક રીતે નિષ્ક્રિય છે.

⚠️ સામાન્ય ભૂલો

  • H₃BO₃ બ્રોન્સ્ટેડ એસિડ નથી; તે લૂઇસ એસિડ છે (OH⁻ ગ્રહણ કરે છે).
  • BCl₃ માં B પર લોન પેર નથી; તે લૂઇસ એસિડ છે, બેઝ નહીં.
  • CCl₄ પાણીથી બંધાય નહીં; SiCl₄ પાણીથી સહેજે હાઇડ્રોલાઇઝ થાય છે.
  • PCl₅ માં P sp³d સંકર; બંધકોણ 90° અને 120° થાય છે.
  • NO₂ મિશ્ર એસિડ એનહેાઇડ્રાઇડ છે (HNO₂ અને HNO₃ બનાવે છે).
  • SO₂ ની બ્લીચિંગ ક્રિયા સ્થાયી નથી; ઑક્સિડેશન થી રંગ પાછો આવે છે.
  • I₂ સ્ટાર્ચ સાથે નીલો રંગ આપે છે; HCl/NO₂ સહિત બીજી ઘણી વાયુઓ આ પરીક્ષણ કરતી નથી.
  • NH₃ માં H-N-H ખંડ 107° થાય છે, ન કે 109.5°.
  • O₃ ની રચના સમદ્વિબાજુ ત્રિકોણીય (bent) છે, સરળ રેખીય નથી.
  • N₂ માં π બંધ હોવા છતાં તે બહુ સક્રિય નથી; ત્રિવલ બંધ ખૂબ જ મજબૂત હોય છે.
  • F₂ ની ઇલેક્ટ્રોન સખાતા Cl₂ કરતાં ઓછી છે (પ્રથમ પંક્તિનું વૈષમ્ય).
  • H₂SO₄ સાંદ્ર HNO₃ ને ઑક્સિડાઇઝ કરી NO₂+ બનાવે છે (નાઇટ્રેશન).
  • Xe ના સંયોજનોમાં Xe sp³d સંકર થાય છે (XeF₂ માં).
  • P₄ માં દરેક P ત્રણ બંધ ધરાવે છે; ખંડ 60° નું તણાવ ધરાવે છે.
  • N₂O₅ માં બે NO₂ + એક NO₃ જેવા ઘટકો રૂપાંતરિત થાય છે.
  • B₂H₆ માં ચાર સામાન્ય (terminal) B-H બંધ અને બે બ્રિજિંગ (3c-2e) બંધ હોય છે.
  • સલ્ફરની અષ્ટક (S₈) રિંગ રચના ધરાવે છે; α-સલ્ફર અને β-સલ્ફર એલોટ્રોપ્સ છે.
  • H₂O₂ નું pH ≈ 5-6; તે દુર્બળ એસિડ છે, બેઝિક નહીં.
  • SiO₂ સહસંયોજક જાળીદાર ઠોસ છે; તે વાયુ/દ્રાવ્ય નથી.
  • NO એ વિષળુ વાયુ છે; તે લોહીમાં Hb સાથે જોડાઈને ઑક્સિજન વહન અવરોધે છે.
  • Xe ના સંયોજનોની પ્રથમ શોધ નીલ બેન્ડર્ગ (Neil Bartlett) એ 1962 માં કરી હતી.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • ઇનર્ટ પેર અસર: Tl⁺ > In⁺, Sn²⁺ > Pb²⁺, Sb³⁺ > Bi³⁺ — ઓક્સિડેશન અવસ્થાઓ.
  • બોરોનનો ઉપયોગ ન્યુક્લિયર રિએક્ટરમાં ન્યુટ્રોન શોષક તરીકે થાય છે.
  • ગ્રેફાઇટ vs ડાયમંડ: બંને C ના એલોટ્રોપ્સ; ગ્રેફાઇટ soft, ડાયમંડ hard.
  • NO₂ નું દ્વિઆણ્વીકરણ: 2NO₂ ⇌ N₂O₪ (ઠંડુ કરતાં N₂O₄ વધે છે).
  • NH₃ નું હેપ્સન પ્રક્રિયા: 4NH₃ + 5O₂ → 4NO + 6H₂O (Ostwald).
  • સલ્ફ્યુરિક એસિડનું ઉત્પાદન: સંપર્ક પ્રક્રિયા (V₂O₅, 450°C, 2 atm).
  • H₂SO₄ ના ત્રણ મુખ્ય ઉપયોગ: સેલ, ઔદ્યોગિક એસિડ, ડિહાઈડ્રેટિંગ એજન્ટ.
  • Cl₂ નું ઉત્પાદન: Dianscellery પ્રક્રિયા (MnO₂ + conc. HCl).
  • F₂ નું ઉત્પાદન: Moel’s પ્રક્રિયા (KHF₂ → KF + HF; ત્ય બાદ ઇલેક્ટ્રોલાઇસિસ).
  • N₂ ની ચકાસણી: લીટમ્સ → કંઈ નહીં; NH₃ માટે લીટમ્સ નીલું.
  • SO₂ ની ચકાસણી: K₂Cr₂O₇/H⁺ ને લીલું કરે છે (Cr³⁺ બને).
  • O₃ ની ચકાસણી: KH I/starch → નીલો રંગ.
  • XeF₂ + H₂O → Xe + HF + O₂ (પાણીથી વિઘટન).
  • બોરેક્સ જ્વલા વલય: Cu²⁺ → નીલો મેથડ; Cr³⁺ → પારદર્શક લાલ.
  • PCl₅ + H₂O → H₃PO₄ + 5HCl (સંપૂર્ણ હાઇડ્રોલાઇસિસ).
  • NH₄NO₂ → N₂ + 2H₂O (ઉષ્મીય વિઘટન).
  • CaCN₂ + 3H₂O → CaCO₃ + 2NH₃ (માર્સ્ટર સ્લગ પ્રક્રિયા).
  • P₄ + 3NaOH + 3H₂O → PH₃ + 3NaH₂PO₂ (ડિસપ્રોપોર્શનેશન).
  • S₈ + 16NaOH → 4Na₂S + 2Na₂S₂O₃ + 8H₂O (ડિસપ્રોપોર્શનેશન).
  • I₂ + 2Na₂S₂O₃ → Na₂S₄O₆ + 2NaI (થાઇઓસલ્ફેટ ટાઇટ્રેશન).
  • NO + O₃ → NO₂ + O₂ (ઝોન સ્તર પર NO ની ભૂમિકા).
  • SF₆ માં S sp³d²; અષ્ટફલકીય; રાસાયણિક રીતે અક્રિયાશીલ.
