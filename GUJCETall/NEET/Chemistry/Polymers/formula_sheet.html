પોલિમર — સૂત્ર શીટ

🧪 GUJCET — Gujarati • Chemistry • Polymers

⚡ સૂત્રો

અપંજન માળખું (Repeating Unit): —[મોનોમર એકમ]—n અથવા R = —[મોનોમર]—n
R = પોલિમર શૃંખલા, n = અપંજન સંખ્યા (ડિગ્રી ઑફ પોલિમરાઇઝેશન), મોનોમર = પ્રત્યેક પુનરાવર્તિત એકમ · SI: n — નહીં (સંખ્યા) · ઉમેરા પોલિમરાઇઝેશનમાં (એકકબંધ બનતા નથી)
અપંજન સંખ્યા / પોલિમરાઇઝેશન ડિગ્રી (Degree of Polymerization): n = Mn / M0 અથવા n = Mp / M0
n = અપંજન સંખ્યા, Mn અથવા Mp = પોલિમરની સંખ્યા-સરેરાશ / ભાર-સરેરાશ આણ્વીય દળ, M0 = મોનોમરનું આણ્વીય દળ · SI: n — નહીં; Mn, M0, Mp — g/mol · જ્યારે પોલિમરનું સરેરાશ આણ્વીય દળ અને મોનોમરનું આણ્વીય દળ જાણીતું હોય
બ્રાઉનિયન ગતિ દ્વારા મુક્ત-રાડિકલ સાંકેતિક અવસ્થા (Free Radical Addition — સામાન્ય રચના): CH2=CHX -->[પોલિમરાઇઝેશન]-- —[CH2—CH(X)]—n
X = સંયોજક સમૂહ (જેમ કે Cl, CN, C6H5, F, etc.), પોલિમરાઇઝેશન = ઉમેરા પોલિમરાઇઝેશન · SI: અપ્રસ્તુત · ઉમેરા પોલિમરાઇઝેશન દ્વારા બનતા એકધાટા પોલિમર માટે
મોનોમર કાર્યક્રમતા અને પોલિમર રચના વચ્ચેનો સંબંધ: f = 1 --> રેખીય શૃંખલા; f = 2 --> રેખીય / ઘાટી (Branched); f ≥ 3 --> જાળીદાર (Cross-linked) પોલિમર
f = મોનોમરની કાર્યક્રમતા (Functionality — બંધ બનાવવાની ક્ષમતા), રેખીય = Linear, ઘાટી = Branched, જાળીદાર = Cross-linked · SI: f — નહીં (પૂર્ણાંક) · બહુ-કાર્યક્રમીય (Polyfunctional) મોનોમર વર્તણૂકનું સામાન્ય નિયમ
નોઇલોન-6,6 નું પુનરાવર્તિત એકમ (Nylon-6,6 Repeat Unit): —[NH—(CH2)6—NH—CO—(CH2)4—CO]—n
NH = એમિનો સમૂહ, CO = કાર્બોનિલ સમૂહ, (CH2)6 = हेक्सામેથીલીન એકમ, (CH2)4 = એડિપિક એસિડનો ચાર-CH2 ભાગ · SI: અપ્રસ્તુત · હેક્ઝામેથીલીન ડાયામાઇન + એડિપિક એસિડના ઘનસંયોજન પોલિમરાઇઝેશન (Condensation Polymerisation) માં
નોઇલોન-6 એકમ (Nylon-6 Repeat Unit): —[NH—(CH2)5—CO]—n
NH = એમિનો સમૂહ, CO = કાર્બોનિલ સમૂહ, (CH2)5 = પેન્ટામેથીલીન એકમ; આ પોલિમર કેપ્રોલેક્ટમ (Caprolactam) થી બને છે · SI: અપ્રસ્તુત · કેપ્રોલેક્ટમનું જળઅપયોજન (Hydrolysis) પછી પોલિમરાઇઝેશન
Teflon (PTFE) નું પુનરાવર્તિત એકમ: —[CF2—CF2]—n
CF2 = ટ્રાફ્ટોરોઇથિલીન એકમ; મોનોમર: CF2=CF2 (ટ્રાફ્ટોરોઇથિલીન) · SI: અપ્રસ્તુત · ટ્રાફ્ટોરોઇથિલીનનું ઉમેરા પોલિમરાઇઝેશન
PVC નું પુનરાવર્તિત એકમ: —[CH2—CH(Cl)]—n
Cl = ક્લોરિન, મોનોમર: CH2=CHCl (વಿನાઇલ ક્લોરાઇડ) · SI: અપ્રસ્તુત · વિનાઇલ ક્લોરાઇડનું ઉમેરા પોલિમરાઇઝેશન
બુના- S (Buna-S) નું પુનરાવર્તિત એકમ: —[CH2—CH=CH—CH2—CH(C6H5)—CH2]—n
C6H5 = ફિનોઇલ (બેન્ઝીન વલય), બુના- S = 1,3-બ્યુટેડાઇન + સ્ટાયરીનનું સહપોલિમર (Copolymer) · SI: અપ્રસ્તુત · સહપોલિમરાઇઝેશન — બે વિભિન્ન મોનોમર એકસાથે
બુના- N (Buna-N) નું પુનરાવર્તિત એકમ: —[CH2—CH=CH—CH2—CH(CN)—CH2]—n
CN = સાયનો સમૂહ, મોનોમર: 1,3-બ્યુટેડાઇન + એક્રિલોનાઇટ્રાઇલ (Acrylonitrile) · SI: અપ્રસ્તુત · સહપોલિમરાઇઝેશન
PHBV નું પુનરાવર્તિત એકમ (Biodegradable Polymer): —[O—CH(CH3)—CH2—CO—O—CH(CH2CH3)—CH2—CO]—n
બે એસિડ એકમ: 3-હાઇડ્રોક્સીબ્યુટેનોઇક એસિડ + 3-હાઇડ્રોક્સીપેન્ટાનોઇક એસિડ, ઘનસંયોજન દ્વારા બને છે · SI: અપ્રસ્તુત · સંઘનન પોલિમરાઇઝેશન, જૈવભંગુર (Biodegradable) પોલિમર
પેરેનથીલિન (Bakelite) — પ્રથમ સંયોજક-જાળીદાર પોલિમર: —[C6H3(OH)—CH2]—n (ત્રિપરિમાણીય જાળીદાર રચના)
C6H3(OH) = હાઇડ્રોકસિફિનોઇલ એકમ, CH2 = મિથિલીન સેતુ; મોનોમર: ફિનોલ + મિથેનલ (Furfural નહીં, Formaldehyde) · SI: અપ્રસ્તુત · બેકેલાઇટ = ફિનોલ-ફોર્મલડિહાઇડ રેઝિન; ઉષ્માસ્થાયી (Thermosetting)
પોલિએસ્ટર (Dacron / Terylene) નું પુનરાવર્તિત એકમ: —[CO—C6H4—CO—O—CH2—CH2—O]—n
C6H4 = ટરેફ્થાલિક એસિડ અથવા તેનું સોડિયમ લવણ, OCH2CH2O = ઇಥિલીન ગ્લાઇકોલ એકમ, ઘનસંયોજન પોલિમરાઇઝેશન · SI: અપ્રસ્તુત · ટરેફ્થાલિક એસિડ + ઇથિલીન ગ્લાઇકોલનું સંયોજન
નોઇલોન-6,6 નું આણ્વીય દળ (મોનોમર કુલ): M(NO−6,6 repeat unit) = 2×M(hexamethylenediamine) + 2×M(adipic acid) − 2×M(H2O)
M = આણ્વીય દળ, H2O = દરેક બંધ બનતાં મુક્ત થતું જળઅણુ, 2H2O = બે સંયોજક જળઅણુ મુક્ત થાય છે (દરેક એમિડ બંધ માટે 1 H2O) · SI: g/mol · દરેક એમિડ બંધ બનતાં 1 જળઅણુ મુક્ત થાય છે; 2 એમિડ બંધ → 2 H2O
બાંધકામ-ક્ષમતા (Resilience) માટેનું મૂળભૂત સંબંધ (Elastomer): Elastomer: ફફડાટ પછી પ્રતિલિમિત સંકોચન; શ્રેણી: δ = (L − L0) / L0 (strain)
δ = વિરૂપણ (Strain), L0 = મૂળ લંબાઈ, L = વિરૂપ પછીની લંબાઈ · SI: δ — નહીં (અપ્રસ્તુત) · ઇલાસ્ટોમર યાંત્રિક ગુણધર્મોનું મૂલ્યાંકન

🔗 સંબંધો

  • n (અપંજન સંખ્યા) એટલું જ વધે જેટલું પોલિમરનું આણ્વીય દળ વધે; M_polymer = n × M_monomer
  • ધાતુ-બંધન (ક્રોસ-લિંક) નું પ્રમાણ જેટલું વધારે, પોલિમર તેટલો વધુ કઠોર અને ઉષ્મા-સ્થાયી (Thermosetting) બને છે.
  • ઓક્ટોપી (Octopus) પેરેનથીલિન ( Bakelite ) માં ત્રણ-પરિમાણીય જાળીદાર રચના હોવાથી તે ફરીથી ગરમ કરતાં પીગળતું નથી.
  • નોઇલોન-6,6 માં '6,6' એ બે મોનોમરના કાર્બન અણુઓની સંખ્યા દર્શાવે છે: 6 (ડાયામાઇન) અને 6 (એડિપિક એસિડ).
  • નોઇલોન-6 માં ફક્ત '6' એ કેપ્રોલેક્ટમમાં રહેલા કાર્બન અણુઓની સંખ્યા દર્શાવે છે (એક જ મોનોમર).
  • ઇનાઇટ (Rayon) એ કાચા રેશમનો સંશ્લેષિત વૈકલ્પિક સ્વરૂપ છે — તે પોલિવિસ્કોઝ (Viscose) છે, કુદરતી પોલિમર નહીં.
  • સંયોજક પોલિમરાઇઝેશન (Condensation) માં દરેક બંધ બનતાં નાનું અણુ (H2O, NH3, HCl) મુક્ત થાય છે; ઉમેરા (Addition) માં કશું મુક્ત થતું નથી.
  • Elastomer < Fiber < Thermoplastic < Thermosetting — બાંધકામ-ક્ષમતા અને ઉષ્મા-પ્રતિરોધમાં આ ક્રમ છે.
  • Buna-S અને Buna-N બંને 'બ્યુટેડાઇન-આધારિત' સહપોલિમર છે; S = સ્ટાયરીન, N = નાઇટ્રાઇલ (એક્રિલોનાઇટ્રાઇલ).

🎯 ટ્રિક્સ

'નોઇલોન' શબ્દ પછી આંકડા '6,6' એટલે બે મોનોમર, દરેકે 6 કાર્બન; ફક્ત '6' એટલે એક જ મોનોમર (કેપ્રોલેક્ટમ) — યાદ રાખો: બે એકમો = બે 6, એક એકમ = એક 6.
'Buna' શબ્દનો અર્થ: Bu = બ્યુટેડાઇન, Na = સોડિયમ (ઉત્પ્રેરક), a = એટા (સંસ્કરણ); બંને Buna-S અને Buna-N માં બ્યુટેડાઇન હોય છે.
PVC = P + VC (Polyvinyl Chloride) — ક્લોરિન ધરાવતું; Teflon = T + ef = ટ્રાફ્ટોરો — ફ્લોરિન ધરાવતું. એક પણ 'H' નથી.
પોલિએસ્ટર = ઇસ્ટર બંધ ધરાવતું પોલિમર; ઇસ્ટર = —COO— બંધ. Dacron / Terylene માં આ બંધ સપ્લાઇ છે.
'Thermosoftening' = Thermoplastic (ફરીથી પીગળે છે) · 'Thermosetting' = જાળીદાર (ફરી પીગળતું નથી) — 'softening' vs 'setting' એ સ્પષ્ટ સામસો છે.
Biodegradable Polymer = 'Jeev bhag dur' (ઊડી જાય) — આ પોલિમર પરબાઈઓટિક જીવો દ્વારા વિઘટન પામે છે; PHBV એ ઉદાહરણ છે.
બેકેલાઇટ = ફિનોલ + મિથેનલ (Formaldehyde), નામ 'ફર્માલડિહાઇડ' લેતાં 'Bakelite' આવે — આ યાદચ્છિક પણ સાહાયક છે.
સંયોજક (Condensation) પોલિમર માં જળઅણુ મુક્ત થાય છે → નામમાં '-one', '-amide', '-ester' જેવા પ્રત્યયો આવે છે. ઉમેરા (Addition) માં કશું મુક્ત થતું નથી.

⚠️ ભૂલો

નોઇલોન-6,6 ને કેવળ 'નોઇલોન' કહી દેવું — નોઇલોન-6 થી પૂરતું અલગ છે.
બુના- N ને 'બુના- S' માં ફેરવી દેવું — N = નાઇટ્રાઇલ (CN), S = સ્ટાયરીન (C6H5).
બેકેલાઇટનું મોનોમર 'ફિનોલ + ફોર્મલડિહાઇડ' (મિથેનલ) જણાવવું; ગલ્ટ્રાલડિહાઇડ નહીં.
પોલિએસ્ટરનું પુનરાવર્તિત એકમ લખતી વખતે —COO— (ઇસ્ટર) બંધને —CONH— (એમાઇડ) માં ફેરવી દેવું.
PHBV ને સામાન્ય પોલિએસ્ટર માની લેવું — તે 3-હાઇડ્રોક્સીબ્યુટેનોઇક એસિડ અને 3-હાઇડ્રોક્સીપેન્ટાનોઇક એસિડનું સંયોજન છે, ન કે સાદું પોલિએસ્ટર.
'નોઇલોન-6,6' માં H2O ની સંખ્યા ભૂલી જવું — 2 H2O મુક્ત થાય છે (દરેક એમિડ બંધ માટે 1).
