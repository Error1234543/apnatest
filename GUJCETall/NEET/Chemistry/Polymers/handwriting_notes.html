પોલિમર્સ – પ્રવેશ
મોટા અણુઓ જેટલા એકમોનું પુનરાવર્તન થાય છે, તેમને પોલિમર કહે છે.
પુનરાવર્તિત એકમને મોનોમર કહે છે.
પોલિમરાઈઝેશન = નાના મોનોમર અણુઓ જોડાઈ મોટા પોલિમર બનાવે.
પ્રাকૃતિક પોલિમર્સ: સ્ટાર્ચ, સેલ્યુલોઝ, પ્રોટીન, રેબર.
કૃત્રિમ / સંશ્લેષિત પોલિમર્સ: પોલિએથિલિન, પીવીસી, નાયલોન-6,6, બેકેલાઈટ.
📝 GUJCET માં "મોનોમર" અને "પુનરાવર્તિત એકમ" વચ્ચેનો તફાવત સ્પષ્ટ રાખવો.
પોલિમર્સનું વર્ગીકરણ
આધાર: મૂળ પ્રાપ્તિ પર → પ્રાકૃતિક, કૃત્રિમ, સંશ્લેષિત.
બનાવટ પદ્ધતિ પર → એડિશન પોલિમર, કંડેન્સેશન પોલિમર.
આંતરઅણ્વીય બળ પર → ઇલાસ્ટોમર, થર્મોપ્લાસ્ટિક, થર્મોસેટિંગ, ફાઇબર.
ઇલાસ્ટોમરસૌથી નબળી આંતરઅણ્વીય આકર્ષણ, લચીલાपन.
થર્મોપ્લાસ્ટિકઉષ્માથી નરમ, ફરીથી आकार આપી શકાય.
થર્મોસેટિંગકડક, વારંવાર ગરમ કરવાથી ભ્રૂષ્ટ ન થાય.
ફાઇબરમજબુત, उच्च गलनांक.
ધ્યાન રાખો: થર્મોપ્લાસ્ટિકમાં શૃંખલા વચ્ચે હલકા બળ, થર્મોસેટિંગમાં ક્રોસ-લિંકિંગ.
📝 GUJCET નોટ: પોલિમરના ગુણધર્મો તેમની રચના પર આધારિત.
પોલિમરાઈઝેશન પ્રકારો
એડિશન પોલિમરાઈઝેશન: યુગ્મ બંધ ધરાવતા મોનોમર જોડાઈ પોલિમર બનાવે. કોઈ ઉપજાત ઉત્પન્ન થતી નથી.
કંડેન્સેશન પોલિમરાઈઝેશન: બિન-યુગ્મ બંધ ધરાવતા બે કાર્યકર સમૂહ વાળા મોનોમર જોડાઈ, નાના અણુ (H₂O, HCl, NH₃) છૂટા પડે.
n CH₂=CH₂ → [–CH₂–CH₂–]ₙ (પોલિએથિલિન)
n HOOC–(CH₂)₄–COOH + n H₂N–(CH₂)₆–NH₂ → નાયલોન-6,6 + (2n–1) H₂O
એડિશન: મોનોમરનું દળ = પોલિમરનું દળ. કંડેન્સેશન: પાણી/અન્ય ઉત્પન્ન.
📝 એડિશનમાં સામાન્ય રીતે રેડિકલ પ્રારંભક (ઇનિશિએટર) નો ઉપયોગ થાય.
મહત્વના એડિશન પોલિમર્સ
પોલિએથિલિન (પોલિથિન): CH₂=CH₂ નું ઉચ્ચ દબાણ/તાપમાને પોલિમરાઈઝેશન.
LLDPE: લીનિયર લો ડેન્સિટી પોલિએથિલિન – વધુ મજબુત, પ્લાસ્ટિક ફિલ્મ.
પોલિપ્રોપિલિન: CH₂=CH–CH₃ → [–CH₂–CH(CH₃)–]ₙ. ભોજન પેકેજિંગ, રોપ.
પોલિવિનાઈલ ક્લોરાઈડ (PVC): CH₂=CH–Cl. પાઈપ, ફ્લોરિંગ, આઈસર.
ટેફલોન (પોલિટेट્રાફ્લોરોઇથિલિન): CF₂=CF₂ → [–CF₂–CF₂–]ₙ. ગરમાઈથી સ્થિર, બાષ્પસ્તર.
પોલિસ્ટાયરીન: CH₂=CH–C₆H₅ → [–CH₂–CH(C₆H₅)–]ₙ. સ્ટાઇરોફોમ, ઇન્સ્યુલેશન.
ટેફલોન: રાસાયણિક રીતે સક્રિય નહીં, non-stick પાત્રમાં વપરાય.
📝 PVC માં પ્લાસ્ટિસાઇઝર ઉમેરતા નરમ બને.
મહત્વના કંડેન્સેશન પોલિમર્સ
નાયલોન-6,6: એડિપિક એસિડ + હેક્સામેથીલિન ડાયએમાઇન → પાણીનું નિર્જળન.
નાયલોન-6: કેપ્રોલાક્ટમનું ઉદ્દીપક ઉપસ્થિતિમાં મુક્ત રેડિકલ પોલિમરાઈઝેશન.
બેકેલાઈટ:酚 + મેથાનેલ → થર્મોસેટિંગ, વિદ્યુત સાધનો, બટનો.
n C₆H₅OH + n HCHO → બેકેલાઈટ + (n) H₂O
ડેક્સોન (પોલિએસ્ટર): એડિપિક એસિડ + એથિલિન ગ્લાઈકોલ → પાણી.
નાયલોન-6 અને નાયલોન-6,6 વચ્ચેનો તફાવત: મોનોમરનો સ્રોત અને રચના.
📝 બેકેલાઈટ પ્રારંભિક સંશ્લેષિત પ્લાસ્ટિક હતું.
ઇલાસ્ટોમર અને રબર
ઇલાસ્ટોમર: નબળી આંતરઅણ્વીય બળ, ખેંચીને મૂકી દેતા મૂળ આકાર પામે.
પ્રકૃતિ રેબર: cis-1,4-પોલીઆઇસોપ્રિન, લચીલો પણ ચિપચિપો.
વાલ્કેનાઈઝેશન: પ્રકૃતિ રેબર + સલ્ફર (3–30%) → ક્રોસ-લિંકિંગ, સ્થિરતા, લચીલાપન.
R–S–S–R (ક્રોસ-લિંક) રચાય છે.
Buna-S: બ્યુટેડીઇન + સ્ટાયરીન. ટાયર, સોલ.
Buna-N: બ્યુટેડીઇન + એક્રિલોનિટ્રાઇલ. તેલ/ઘસીમણથી સ્થિર.
વાલ્કેનાઈઝેશન તાપમાન ~373–413 K, સલ્ફર પ્રમાણ મુજબ ગુણધર્મ બદલાય.
📝 Hard rubber (ઇબોનાઇટ) માં ~30% સલ્ફર.
બાયોડિગ્રેડેબલ પોલિમર્સ
જે પોલિમર્સ સૂક્ષ્મજીવો દ્વારા વિઘટન પામે છે, તે બાયોડિગ્રેડેબલ કહેવાય.
PHBV (પॉली β-હાઇड्रोजन valerate-co-3-hydroxybutyrate): કૃત્રિમ રેબર, મેડિકલ સ્ત્રાવ, પાઉચ.
નાયલોન-4, નાયલોન-6,6 સહજ પરિસ્થિતિમાં ઝડપી વિઘટન પામતા નથી.
PHBV માં બાયોડિગ્રેડેશનના યોગ્ય માળખા હોય છે.
📝 પર્યાવરણ મિત્ર પોલિમરના પ્રશ્ન GUJCET માં આવે છે.
પોલિમરના ગુણધર્મો અને ઉપયોગ
થર્મોપ્લાસ્ટિક: ઉષ્માથી ગલન, ફરીથી આકાર આપી શકાય (ઉદા. પીવીસી, પોલિએથિલિન).
થર્મોસેટિંગ: કડક, ગરમ કરવાથી દ્રવ ન થાય, તૂટે છે (ઉદા. બેકેલાઈટ, યુરિયા-ફોર્મલ્ડિહાઇડ).
ફાઇબર: ઉચ્ચ ખેંચાણ શક્તિ, સંશ્લેષિત વસ્ત્ર (નાયલોન, પોલિએસ્ટર).
ઇલાસ્ટોમર: ઓછી સખ્તાઈ, મોટો પ્રત્યયસ્થ વિરૂપણ.
માળખુંઉષ્મા-પ્રતિકારક ગુણધર્મ નક્કી કરે છે.
📝 GUJCET માં "કયા પોલિમરની શૃંખલા વચ્ચે હાઇડ્રોજન બંધ છે?" પ્રકારના પ્રશ્નો.
માપન: ડિગ્રી ઑફ પોલિમરાઈઝેશન
DP = પોલિમરનું મોલર દળ / મોનોમરનું મોલર દળ.
M_polymer = DP × M_monomer
સરેરાશ મોલર દળ: M_n (સંખ્યા સરેરાશ), M_w (ભાર સરેરાશ).
DP નો સીધો સંબંધ પોલિમરના ભૌતિક ગુણધર્મો સાથે.
📝 અંદાજિત DP મૂલ્યો યાદ રાખો: પોલિથિન 10³–10⁵.
પરીક્ષા-માર્ગદર્શન
મોનોમર અને પોલિમરના નામ યાદ રાખો.
એડિશન vs કંડેન્સેશન – ઉદાહરણો સાથે.
વાલ્કેનાઈઝેશન, BUNA-R/S/N ની રચના.
