એલકોહોલ, ફિનોલ અને ઇથર — સૂત્ર પત્રિકા

🧪 GUJCET — Gujarati • Chemistry • Alcohols, Phenols and Ethers

⚡ સૂત્રો

એલકોહોલનું સામાન્ય સૂત્ર: CnH2n+1OH અથવા R-OH
n = કાર્બન પરમાણુઓની સંખ્યા, R = એલકાઇલ સમૂહ · SI: — · સર્વસામાન્ય સૂત્ર
ફિનોલનું સૂત્ર: C6H5OH અથવા Ar-OH
Ar = એરાઇલ સમૂહ (બેન્ઝીન રિંગ) · SI: — · ફિનોલનું આણ્વીય સૂત્ર
ઇથરનું સામાન્ય સૂત્ર: R-O-R' અથવા CnH2n+2O
R, R' = એલકાઇલ/એરાઇલ સમૂહ · SI: — · ઇથરનું સામાન્ય સૂત્ર
એલ્કીનનું એસિડ-ઉત્પ્રેરિત જળવિભાજન: CH2=CH2 + H2O --(H+)> CH3CH2OH
H+ = એસિડ ઉત્પ્રેરક (સાંદ્ર H2SO4) · SI: — · એલ્કીનમાંથી એલકોહોલની તૈયારી
હાઇડ્રોબોરેશન-ઓક્સિડેશન (હાઇડ્રોક્સિલ સમૂહની વિપરીત દિશા): 3RCH=CH2 + BH3 --> (RCH2CH2)3B, પછી H2O2/OH- --> 3RCH2CH2OH
BH3 = બોરેન, H2O2/OH- = ઓક્સિડેશન પગલું · SI: — · ઝેઇટેસિફ્ નિયમનું પાલન ન થાય (એન્ટી-માર્કોવનિકોવ ઉત્પાદન)
એલ્કાઇલ હેલાઇડનું જલીય KOH સાથે હાઇડ્રોલિસિસ: R-X + aq.KOH --> R-OH + KX
X = હેલાઇડ (Cl, Br, I) · SI: — · એલકોહોલની તૈયારી
એસ્ટરનું ઘટાડણ (લિથિયમ એલ્યુમિનિયમ હાઇડ્રાઇડ): RCOOR' + LiAlH4 --> RCH2OH + R'OH
LiAlH4 = પ્રબળ ઘટાડક · SI: — · એસ્ટરનું એલકોહોલમાં રૂપાંતર
એલ્ડિહાઇડનું ઘટાડણ: RCHO + NaBH4 --> RCH2OH
NaBH4 = મધ્યમ ઘટાડક · SI: — · એલ્ડિહાઇડમાંથી પ્રાથમિક એલકોહોલ
કીટોનનું ઘટાડણ: RCOR' + NaBH4 --> RCH(OH)R'
NaBH4 = ઘટાડક · SI: — · કીટોનમાંથી દ્વિતીયક એલકોહોલ
ગ્રિગ્નાર્ડ પ્રતિક્રિયા — HCHO સાથે: R-MgX + HCHO --> RCH2OH + Mg(OH)X
R-MgX = ગ્રિગ્નાર્ડ પ્રતિકારક, HCHO = ફોર્મલ્ડિહાઇડ · SI: — · એક કાર્બન વધારા સાથે પ્રાથમિક એલકોહોલ
ગ્રિગ્નાર્ડ પ્રતિક્રિયા — એલ્ડિહાઇડ સાથે: R-MgX + R'CHO --> RCH(OH)R' + Mg(OH)X
R'CHO = એલ્ડિહાઇડ · SI: — · દ્વિતીયક એલકોહોલની તૈયારી
ગ્રિગ્નાર્ડ પ્રતિક્રિયા — કીટોન સાથે: R-MgX + R'COCH3 --> R-C(OH)(R')CH3 + Mg(OH)X
R'COCH3 = કીટોન · SI: — · તૃતીયક એલકોહોલની તૈયારી
પ્રાથમિક એલકોહોલનું ઓક્સિડેશન → એલ્ડિહાઇડ: RCH2OH + [O] --> RCHO + H2O
[O] = ઓક્સિડેશન એજન્ટ (PCC અથવા K2Cr2O7/H+) · SI: — · PCC વડે એલ્ડિહાઇડ મળે, સામાન્ય ઓક્સિડેશનમાં એસિડ
પ્રાથમિક એલકોહોલનું ઓક્સિડેશન → કાર્બોક્સિલિક એસિડ: RCH2OH + 2[O] --> RCOOH + H2O
[O] = K2Cr2O7/H+ અથવા KMnO4/H+ · SI: — · પ્રબળ ઓક્સિડેશન એજન્ટ વડે
દ્વિતીયક એલકોહોલનું ઓક્સિડેશન → કીટોન: RCH(OH)R' + [O] --> RCOR' + H2O
[O] = K2Cr2O7/H+ અથવા Na2Cr2O7/H+ · SI: — · દ્વિતીયક એલકોહોલ માત્ર કીટોન આપે
એલકોહોલનું વિજળીકરણ (ડિહાઇડ્રેશન) → એલ્કીન: RCH2CH2OH --(conc.H2SO4, 443K)> RCH=CH2 + H2O
conc.H2SO4 = જળાપસારક, 443K = તાપમાન · SI: — · ઝેઇટેસિફ નિયમ મુજબ એલ્કીન બને
એલકોહોલ + સક્રિય ધાતુ (સોડિયમ): 2ROH + 2Na --> 2RONa + H2
RONa = સોડિયમ એલ્કોક્સાઇડ · SI: — · એલકોહોલની એસિડ પ્રવૃત્તિ દર્શાવે
લુકાસ પ્રતિક્રિયા (પ્રાથમિક/દ્વિતીયક/તૃતીયક એલકોહોલની ઓળખ): R-OH + HCl --(ZnCl2)> R-Cl + H2O
ZnCl2 = લુકાસ અભિકારક, R-OH = એલકોહોલ · SI: — · તૃતીયક > દ્વિતીયક > પ્રાથમિક (ઝડપી ધૂંધળાપણું)
એલકોહોલ + PCl5: R-OH + PCl5 --> R-Cl + POCl3 + HCl
PCl5 = ફોસ્ફરસ પેન્ટાક્લોરાઇડ · SI: — · એલ્કાઇલ હેલાઇડ બને
એલકોહોલ + PCl3: 3R-OH + PCl3 --> 3R-Cl + H3PO3
PCl3 = ફોસ્ફરસ ટ્રાયક્લોરાઇડ · SI: — · એલ્કાઇલ હેલાઇડ બને
એલકોહોલ + SOCl2 (સૌથી શ્રેષ્ઠ પદ્ધતિ): R-OH + SOCl2 --> R-Cl + SO2 + HCl
SOCl2 = થાયોનિલ ક્લોરાઇડ, પાયરિડીન ઉત્પ્રેરક · SI: — · કોન્ફિગરેશન સંરક્ષિત રહે (વિનિમય વગર)
એસ્ટરીકરણ પ્રતિક્રિયા: R-OH + R'COOH --(H+)> R'COOR + H2O
H+ = સાંદ્ર H2SO4 ઉત્પ્રેરક · SI: — · એલકોહોલ + કાર્બોક્સિલિક એસિડ → એસ્ટર
એલકોહોલનું Cu/573K પર વિજારણ (ડિહાઇડ્રોજનેશન): RCH2OH --(Cu, 573K)> RCHO + H2
Cu = તાંબું ઉત્પ્રેરક, 573K = તાપમાન · SI: — · પ્રાથમિક એલકોહોલ → એલ્ડિહાઇડ
ફિનોલનું સોડિયમ હાઇડ્રોક્સાઇડ સાથે પ્રતિક્રિયા: C6H5OH + NaOH --> C6H5ONa + H2O
C6H5ONa = સોડિયમ ફિનોક્સાઇડ · SI: — · ફિનોલ એસિડિક પ્રકૃતિ દર્શાવે
ફિનોલનું બ્રોમીકરણ (જલીય): C6H5OH + 3Br2(aq) --> 2,4,6-tribromophenol (શ્વેત અવક્ષેપ) + 3HBr
Br2(aq) = જલીય બ્રોમિન · SI: — · ત્રિ-બ્રોમિનેશન, શ્વેત અવક્ષેપ
ફિનોલનું બ્રોમીકરણ (CS2, નીચા તાપમાને): C6H5OH + Br2/CS2 --> o-bromophenol + p-bromophenol
CS2 = દ્રાવક, નીચું તાપમાન · SI: — · એકલ-બ્રોમિનેશન, ઓર્થો અને પેરા ઉત્પાદન
ફિનોલનું નાઇટ્રેશન: C6H5OH + HNO3(dil.) --> o-nitrophenol + p-nitrophenol
HNO3 = નાઇટ્રિક એસિડ, dil. = મંદ · SI: — · ઓર્થો અને પેરા નાઇટ્રો ઉત્પાદન
કોલ્બે-શ્મિટ પ્રતિક્રિયા (સેલિસિલિક એસિડ): C6H5ONa + CO2 --(125°C, pressure)> o-HOC6H4COONa --(H+)> o-HOC6H4COOH
o-HOC6H4COOH = સેલિસિલિક એસિડ (ઓર્થો-હાઇડ્રોક્સિબેન્ઝોઇક એસિડ) · SI: — · સોડિયમ ફિનોક્સાઇડ + CO2 દબાણ હેઠળ
રાઇમર-ટિમાન પ્રતિક્રિયા (સેલિસાલ્ડિહાઇડ): C6H5OH + CHCl3 + 4NaOH --> o-HOC6H4CHO + 3NaCl + 3H2O
o-HOC6H4CHO = સેલિસાલ્ડિહાઇડ (ઓર્થો-હાઇડ્રોક્સિબેન્ઝાલ્ડિહાઇડ) · SI: — · ફિનોલ + ક્લોરોફોર્મ + સાંદ્ર NaOH
વિલ્યમસન ઇથર સંશ્લેષણ: R-X + R'ONa --> R-O-R' + NaX
R-X = એલ્કાઇલ હેલાઇડ, R'ONa = સોડિયમ એલ્કોક્સાઇડ · SI: — · ઇથરની તૈયારીની શ્રેષ્ઠ પદ્ધતિ
ઇથરનું HBr સાથે વિભાજન: R-O-R' + HBr --> R-OH + R'-Br
HBr = હાઇડ્રોબ્રોમિક એસિડ · SI: — · ઇથરનું એસિડીય વિભાજન
ઇથરનું વધુ HBr સાથે વિભાજન: R-OH + HBr --> R-Br + H2O
HBr = વધારાનું હાઇડ્રોબ્રોમિક એસિડ · SI: — · પ્રથમ પગલાંમાં બનેલો એલકોહોલ પણ હેલાઇડમાં રૂપાંતરિત થાય
ઇથરનું HI સાથે વિભાજન: R-O-R' + HI --> R-OH + R'-I
HI = હાઇડ્રોઆઇડિક એસિડ · SI: — · ઇથરનું એસિડીય વિભાજન
ઇથરનું બરોબર HI સાથે વિભાજન (બે પગલાં): R-OH + HI --> R-I + H2O
HI = વધારાનું હાઇડ્રોઆઇડિક એસિડ · SI: — · બંને એલ્કાઇલ સમૂહ હેલાઇડમાં રૂપાંતરિત થાય
ઇથરનું પેરોક્સાઇડ બનાવે (હવામાં): R-O-CH(R')-CH3 + O2 --> R-O-C(OOH)(R')-CH3
O2 = હવામાંથી ઓક્સિજન · SI: — · ઇથર હવા/પ્રકાશ સંપર્કમાં પેરોક્સાઇડ બનાવે (વિસ્ફોટક)
વિક્ટર મેયર પરીક્ષણ — પ્રાથમિક એલકોહોલ: RCH2OH --(I2/Hg)> RCH2I --(AgNO2)> RCH2ONO --(HNO2)> Red color
I2/Hg = આયોડિન-પારો, AgNO2 = એજેન્ટ, HNO2 = નાઇટ્રસ એસિડ · SI: — · પ્રાથમિક એલકોહોલ → લાલ રંગ
વિક્ટર મેયર પરીક્ષણ — દ્વિતીયક એલકોહોલ: R2CHOH --(I2/Hg)> R2CHI --(AgNO2)> R2CHONO --(HNO2)> Blue color
HNO2 = નાઇટ્રસ એસિડ · SI: — · દ્વિતીયક એલકોહોલ → નીલો રંગ
વિક્ટર મેયર પરીક્ષણ — તૃતીયક એલકોહોલ: R3COH --(I2/Hg)> No reaction --> No color
I2/Hg = આયોડિન-પારો · SI: — · તૃતીયક એલકોહોલ → કોઈ રંગ નહીં

🔗 સંબંધો

  • ફિનોલ એ એલકોહોલ કરતાં વધુ એસિડિક છે કારણ કે ફિનોક્સાઇડ આયન રેઝોનન્સથી સ્થિર થાય છે.
  • એલકોહોલનું એસિડિક ક્રમ: પ્રાથમિક > દ્વિતીયક > તૃતીયક (એલ્કાઇલ સમૂહનો +I અસર વધતા એસિડિટી ઘટે છે).
  • ફિનોલની એસિડિટી કાર્બોનિક એસિડ કરતાં ઓછી પરંતુ પ્રાથમિક એલકોહોલ કરતાં વધુ છે.
  • એલકોહોલનું ઉત્કલન બિંદુ એલકેન/ઇથર કરતાં ઊંચું હોય છે કારણે અંતરાણ્વીય હાઇડ્રોજન બંધ.
  • એલ્કાઇલ હેલાઇડ સાથે એલકોહોલની પ્રતિક્રિયા ક્રમ: તૃતીયક > દ્વિતીયક > પ્રાથમિક (SN1 માર્ગે).
  • ઇથરનું ઉત્કલન બિંદુ એલકોહોલ કરતાં ઓછું હોય છે કારણે ઇથરમાં હાઇડ્રોજન બંધ નથી.
  • ઓર્થો-નાઇટ્રોફિનોલ પેરા-નાઇટ્રોફિનોલ કરતાં વરાળ-વાહક છે કારણે અંતઃઅણુક હાઇડ્રોજન બંધ.
  • ઓર્થો અને પેરા-નાઇટ્રોફિનોલમાં અંતઃઅણુક હાઇડ્રોજન બંધ નથી, તેથી અણુક વચ્ચે હાઇડ્રોજન બંધ → ઊંચું ઉત્કલન બિંદુ.

🎯 ટ્રિક્સ

લુકાસ પરીક્ષણ: તૃતીયક એલકોહોલ તરત ધૂંધળું કરે, દ્વિતીયક 5-10 મિનિટમાં, પ્રાથમિક ગરમી વગર પ્રતિક્રિયા નહીં.
હાઇડ્રોબોરેશન-ઓક્સિડેશન = એન્ટી-માર્કોવનિકોવ ઉત્પાદન (OH વિપરીત દિશાએ જાય).
SOCl2 પદ્ધતિ = સૌથી શુદ્ધ એલ્કાઇલ હેલાઇડ (ઉત્પાદનો વાયુ રૂપે નીકળે → શુદ્ધતા).
વિલ્યમસન સંશ્લેષણમાં એલ્કાઇલ હેલાઇડ પ્રાથમિક હોવો જોઈએ (તૃતીયક હોય તો એલ્કીન બને — વિજારણ પ્રતિક્રિયા).
ફિનોલ + બ્રોમિન પાણી = તરત શ્વેત અવક્ષેપ (2,4,6-ટ્રાઇબ્રોમોફિનોલ) — ફિનોલની ઓળખ.
કોલ્બે-શ્મિટ = CO2 નો ઉપયોગ, ઉત્પાદન સેલિસિલિક એસિડ (ઓર્થો-હાઇડ્રોક્સિબેન્ઝોઇક એસિડ).
રાઇમર-ટિમાન = CHCl3 નો ઉપયોગ, ઉત્પાદન સેલિસાલ્ડિહાઇડ (ઓર્થો-હાઇડ્રોક્સિબેન્ઝાલ્ડિહાઇડ).
પ્રાથમિક એલકોહોલ → એલ્ડિહાઇડ માટે PCC વાપરો (વધુ ઓક્સિડેશન થતું નથી).
ઇથરને સંરક્ષિત કરતી વખતે એસિટોન/એથેનોલ ઉમેરો (પેરોક્સાઇડ નાશ કરવા).
ફિનોલ + Zn ધૂળ ગરમ કરતાં બેન્ઝીન બને (ડિહાઇડ્રોક્સિલેશન).

⚠️ ભૂલો

ફિનોલને સોડિયમ હાઇડ્રોજન કાર્બોનેટ સાથે પ્રતિક્રિયા કરે તેવું માનવું — ફિનોલ HCO3- ને વિસ્થાપિત કરી શકતો નથી (કાર્બોનિક એસિડ કરતાં નબળો એસિડ).
વિલ્યમસન સંશ્લેષણમાં તૃતીયક એલ્કાઇલ હેલાઇડ વાપરવાથી ઇથરને બદલે એલ્કીન મળે છે — આ ભૂલ સામાન્ય છે.
ફિનોલનું નાઇટ્રેશન સાંદ્ર HNO3 વડે કરવું — તે ઓક્સિડેશન પણ કરે છે; મંદ HNO3 વાપરવું જોઈએ.
કોલ્બે-શ્મિટ અને રાઇમર-ટિમાન પ્રતિક્રિયાઓમાં ઉત્પાદન ગૂંચવણ — કોલ્બેમાં -COOH, રાઇમર-ટિમાનમાં -CHO મળે છે.
એલકોહોલનું વિજળીકરણ (ડિહાઇડ્રેશન) નીચા તાપમાને કરવું — 443K (170°C) જરૂરી છે, નીચા તાપમાને ઇથર બને છે.
પ્રાથમિક એલકોહોલનું ઓક્સિડેશન કરતી વખતે Na2Cr2O7/H+ વડે એલ્ડિહાઇડ મળે તેવું માનવું — વધુ ઓક્સિડેશન થઈ એસિડ બને છે; PCC વાપરવું.
ઇથરનું વિભાજન કરતી વખતે એક જ HBr પર્યાપ્ત છે તેવું માનવું — બે મોલ HBr જરૂરી છે જો બંને એલ્કાઇલ સમૂહ હેલાઇડ બનાવવા હોય.
ફિનોલ + FeCl3 → વાદળી રંગ (ખોટું) — સાચો રંગ વાયલેટ/જાંબલી છે.
ઓર્થો-નાઇટ્રોફિનોલ પાણીમાં વધુ દ્રાવ્ય છે તેવું માનવું — અંતઃઅણુક હાઇડ્રોજન બંધને કારણે તે અપેક્ષાકૃત અદ્રાવ્ય છે.
તૃતીયક એલકોહોલનું ઓક્સિડેશન થાય તેવું માનવું — તૃતીયક એલકોહોલમાં α-હાઇડ્રોજન ન હોવાથી ઓક્સિડેશન થતું નથી.
