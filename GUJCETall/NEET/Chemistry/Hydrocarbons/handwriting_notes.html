હાઈડ્રોકાર્બન્સ — પૂર્ણ અધ્યાય નોંધો

🧪 GUJCET — Gujarati • Chemistry • Hydrocarbons

ભૂમિકા: હાઈડ્રોકાર્બન્સ શું છે?
હાઈડ્રોકાર્બન્સ એવા સંયોજનો છે જેમાં ફકત કાર્બન (C) અને હાઇડ્રોજન (H) પરમાણુઓ હોય છે.
હાઈડ્રોકાર્બન્સ = C + H — આ જ તેમની મૂળભૂત રચના છે. બધાં વ્યુત્પન્ન આથી જ આવે છે.
હાઈડ્રોકાર્બન્સની વર્ગીકરણ: એલિફેટિક (સમાધાનિક / ચક્રીય) અને એરોમેટિક.
હાઈડ્રોકાર્બન્સએલિફેટિક હાઈડ્રોકાર્બન્સ / એરોમેટિક હાઈડ્રોકાર્બન્સ
વર્ગીકરણ: સંતૃપ્ત અને અસંતૃપ્ત હાઈડ્રોકાર્બન્સ
સંતૃપ્ત હાઈડ્રોકાર્બન્સ (Alkanes): માત્ર એકલ બંધ — સામાન્ય સૂત્ર CnH2n+2.
Alkane = સંતૃપ્ત → બધા C–C એકલ બંધ → 'પેરાફિન' પણ કહેવાય.
અસંતૃપ્ત હાઈડ્રોકાર્બન્સ: દ્વિ-બંધ (Alkene, CnH2n) અને ત્રિ-બંધ (Alkyne, CnH2n-2).
Alkane : CₙH₂ₙ₊₂ | Alkene : CₙH₂ₙ | Alkyne : CₙH₂ₙ₋₂
📝 exam tip: સામાન્ય સૂત્ર યાદ રાખો — Alkane→2n+2, Alkene→2n, Alkyne→2n-2.
IUPAC નામકરણના મૂળભૂત નિયમો
સૌથી લાંબી સતત કાર્બન શૃંખલાને આધાર મનાય છે; તેમાં C સંખ્યા પ્રમાણે પ્રક્ષેપક મૂળ (meth-, eth-, prop-, but-, pent-, hex-, hept-, oct-, non-, dec-) મળે છે.
मुख्य नियम: (1) લાંબી શૃંખલા, (2) ન્યૂનતમ સ્થાનાંક, (3) વ્યવસ્થિત ક્રમ — આ ત્રણેય IUPAC નામકરણના પાયારૂપ છે.
બંધની પ્રકૃતિ મૂળમાં ઉમેરવામાં આવે છે: -ane, -ene, -yne.
સાઇડ-ચેઇન / બદલીઓને પ્રાથમિકતા ક્રમે: bromo < chloro < methyl < ethyl < propyl.
📝 exam tip: બહુવિધ બંધો માટે di-, tri- ઉપસર્ગ લાગુ પડે (მაგ. buta-1,3-diene).
આઈસોમેરિઝમ: સંરચનાત્મક અને ત્રિ-પરિમાણીય
સંરચનાત્મક આઈસોમેરિઝમ: શૃંખલા આઈસોમેરિઝમ, સ્થાન આઈસોમેરિઝમ, વિધાત્મક આઈસોમેરિઝમ.
તાંત્રિક (જ્યામિતીય) આઈસોમેરિઝમ: C=C ધરાવતા એલ્કીનોમાં cis/trans (E/Z) આઈસોમેરી出现.
cis–trans ત્યારે જ શક્ય છે જ્યારે દરેક બંધવાળા C પર બે ભિન્ન સમૂહ જોડાયેલા હોય — આ શરત ચોક્કસ યાદ રાખો.
C=C ડબલ બોન્ડનો ઘૂમrete ન થઈ શકવોતાંત્રિક આઈસોમેરિઝમ શક્ય
📝 Dipole moment cis > trans (સમપ્રમાણતાને કારણે transમાં dipole રદ થાય છે).
એલ્કેન્સ (Alkanes): બંધારણ અને ગુણધર્મો
એલ્કેન્સમાં C sp³ સંકરણ ધરાવે છે; ચતુષ્ફલકીય ભૌમિતિ; બંધ કોણ ≈ 109.5°.
sp³ સંકરણ = 4 સમાન બંધ + ચતુષ્ફલકીય ભૌમિતિ — આ જ એલ્કેન્સની રેઝોનન્સ છે.
ભૌતિક ગુણધર્મો: અધ્રુવીય, દ્રાવક તરીકે non-polar દ્રાવકોમાં દ્રાવ્ય; ઉત્કલનબિંદુ કાર્બન સંખ્યા વધતા વધે છે.
એલ્કેન્સ રાસાયણિક રીતે સક્રિય નથી (નીરવ) — તેથી 'પેરાફિન' = લેટિન parum + affinis = 'કಡಿમ જકડાણ'.
C—C બંધ લંબાઈ ≈ 1.54 Å ; C—H બંધ લંબાઈ ≈ 1.09 Å
એલ્કેન્સની તૈયારી (Preparation)
હેટ્રોજનیشن (Hydrogenation): Alkene/Alkyne + H₂ / Ni કે Pt → Alkane.
R—CH=CH—R' + H₂ →[Ni/Pt] R—CH₂—CH₂—R'
ગ્રિગ્નાર્ડ પ્રક્રિયા: R—MgX + H₂O → R—H + Mg(OH)X.
કોલ્ટર (Wurtz) પ્રક્રિયા: 2 R—X + 2 Na (dry ether માં) → R—R + 2 NaX.
📝 Wurtz પ્રક્રિયા ફકત સમાંતર Alkane આપે છે — asymmetrical alkane મેળવવા અયોગ્ય.
ડીહાલોજેનേഷન: vicinal dihalide + Zn dust → Alkene → further hydrogenation → Alkane.
Alkyl halideWurtz પ્રક્રિયા → symmetrical Alkane
Alkene/AlkyneH₂/Ni → Alkane
એલ્કેન્સની પ્રક્રિયાઓ (Reactions)
દહન (Combustion): CnH2n+2 + O₂ → CO₂ + H₂O + ઉષ્મા.
CH₄ + 2O₂ → CO₂ + 2H₂O + 890 kJ/mol
ઉત્સેચકીય ઓક્સિડેશન: વધુ પડતા O₂ માં incomplete combustion → CO અથવા C (કાળો ધુમાડો).
રેડિકલ સબસ્ટિટ્યુએશન (હેલોજેનേഷન): Alkane + X₂ / UV or heat → Alkyl halide + HX.
ખાસ નોંધ: Cl₂ > Br₂ reactivity; selectivity: I₂ < Br₂ > Cl₂. Br₂ વધુ selective છે.
પ્રક્રિયાMechanism (Free-radical): Initiation → Propagation → Termination.
📝 exam tip: Free-radical substitution માં tertiary H સૌથી વધુ પ્રતિક્રિયાશીલ (stable radical formation).
CH₄ + Cl₂ (UV)CH₃Cl + HCl (stepwise substitution)
આઈસોમેરાઇઝેશન: n-butane / AlCl₃-HCl → isobutane (2-methylpropane).
n-C₄H₁₀ →[AlCl₃/HCl, heat] i-C₄H₁₀ (Octane rating ↑)
સંક્રાઇઝિંગ (Cracking): મોટા Alkane → નાના Alkane + Alkene. વધુ મૂલ્યવાન ઉત્પાદનો મેળવવા.
Cracking = thermal or catalytic — તે ઔદ્યોગિક રીતે ખૂબ મહત્વનું છે (petrol yield વધારે છે).
એલ્કીન્સ (Alkenes): બંધારણ, sp² સંકરણ
એલ્કીનોમાં C sp² સંકરણ; સમતલીય ભૌમિતિ; બંધ કોણ ≈ 120°.
sp² = 3 σ બંધ + 1 π બંધ — π બંધ weakened → electrophilic addition ની સક્રિયતા.
સામાન્ય સૂત્ર: CnH2n; Ethene (C₂H₄) સૌથી સાદું એલ્કીન.
H₂C=CH₂ (Ethene) ; Bond angle ≈ 120° ; sp² hybridized
C=C બંધ લંબાઈ ≈ 1.34 Å (alkane C–C 1.54 Å કરતાં ટૂંકી).
📝 π બંધ σ બંધ કરતાં નબળો હોય છે; તેથી π બંધ તૂટે છે, σ બંધ રહે છે — addition reaction નો આધાર.
એલ્કીન્સની તૈયારી (Preparation)
Dehydrohalogenation: Alkyl halide + alc. KOH (heat) → Alkene + KX + H₂O. (β-elimination).
CH₃—CH₂—Cl + alc.KOH →[Δ] CH₂=CH₂ + KCl + H₂O
Zaitsev (Saytzeff) નિયમ: β- elimination માં વધુ બદલાયેલું (more substituted) Alkene પ્રમુખ ઉત્પાદન.
Zaitsev rule: more highly substituted alkene = major product. Stability order: tetra > tri > di > mono substituted.
Dehydration of alcohols: R—CH₂—CH₂—OH →[conc. H₂SO₄, heat] Alkene + H₂O.
CH₃CH₂OH →[conc.H₂SO₄, 170°C] CH₂=CH₂ + H₂O
部分 hydrogenation of alkyne: Alkyne + H₂ / Lindlar's catalyst → Cis alkene.
R—C≡C—R' + H₂ / Lindlar's cat. → Cis-RCH=CHR'
Na/NH₃(l) reduction: Alkyne → Trans alkene.
Alkyne + Na/NH₃(l)Trans-alkene
Alkyne + H₂/LindlarCis-alkene
📝 exam tip: Lindlar = cis; Na/NH₃ = trans — બંને stereoselective reduction છે.
એલ્કીન્સની પ્રક્રિયાઓ (Electrophilic Addition Reactions)
Markovnikov નિયમ: હાઇડ્રોજન તે C પર જોડાય જેના પર વધુ H છે; halide તે C પર જેના પર कम H છે.
Markovnikov: 'હાઇડ્રોજન તે સ્થાને જ્યાં વધુ હાઇડ્રોજન છે.' Carbocation intermediate stability determines the product.
CH₃—CH=CH₂ + HBr → CH₃—CHBr—CH₃ (Major: Markovnikov)
Anti-Markovnikov (Peroxide effect): HBr + ROOR → aldehyde-type addition — ફકહત HBr માં જ જોવા મળે છે.
Peroxide effect ફકત HBr સાથે — HCl અને HI માં થતું નથી. Radical mechanism દ્વારા Anti-Markovnikov મળે છે.
CH₃—CH=CH₂ + HBr →[ROOR] CH₃—CH₂—CH₂Br (Anti-Markovnikov)
Halogenation: Alkene + X₂ (CCl₄ માં) → Vicinal dihalide. (anti-addition, bromine test).
CH₂=CH₂ + Br₂/CCl₄ → BrCH₂—CH₂Br (Decolorization of bromine water)
HX addition: Alkene + HX → Alkyl halide (Markovnikov).
Hydration: Alkene + H₂O / H⁺ → Alcohol (Markovnikov).
CH₂=CH₂ + H₂O / H⁺ → CH₃CH₂OH
Hydrogenation: Alkene + H₂ / Ni or Pt → Alkane.
RCH=CHR' + H₂ / Ni → RCH₂—CH₂R'
Ozonolysis: Alkene + O₃ → Ozonide → Zn/H₂O → Aldehydes/Ketones. (Double bond position શોધવા उपयोगી).
RCH=CHR' →[1.O₃ / 2.Zn+H₂O] RCHO + R'CHO
Polymerisation: Ethene → Polythene (PE). Industrial important reaction.
Polymerisation: n CH₂=CH₂ → [—CH₂—CH₂—]ₙ (High-density / Low-density polythene).
📝 exam tip: Ozonolysis → cleavage at C=C; Zn/H₂O (reductive workup) gives aldehydes/ketones.
એલ્કાઇન્સ (Alkynes): બંધારણ, sp સંકરણ
એલ્કાઇનોમાં C sp સંકરણ; રેખીય ભૌમિતિ; બંધ કોણ 180°.
sp સંકરણ = 2 σ બંધ + 2 π બંધ — C≡C રેખીય હોય છે (bond angle 180°).
સામાન્ય સૂત્ર: CnH2n-2; Ethyne (C₂H₂) સૌથી સાદું એલ્કાઇન.
HC≡CH (Ethyne / Acetylene) ; sp hybridised ; linear geometry
C≡C બંધ લંબાઈ ≈ 1.20 Å. ત્રણ બંધો: 1 σ + 2 π.
📝 terminal alkyne (R—C≡C—H) acidic H ધરાવે છે — strong base વડે deprotonation શક્ય.
એલ્કાઇન્સની તૈયારી (Preparation)
Dihalide + alc. KOH (double dehydrohalogenation): vicinal dihalide → Alkyne.
CH₂Br—CH₂Br →[alc.KOH, Δ] CH≡CH + 2KBr + 2H₂O
Calcium carbide method: CaC₂ + 2H₂O → HC≡CH + Ca(OH)₂. (Industrial acetylene).
CaC₂ + 2H₂O → HC≡CH + Ca(OH)₂
Geminal dihalide + NaNH₂ (strong base) → Alkyne.
NaNH₂ એ very strong base છે — terminal alkyne નો H પણ તાકી શકે છે (acetylide formation).
CaC₂ + H₂OEthyne (Acetylene) — industrial source
એલ્કાઇન્સની પ્રક્રિયાઓ (Electrophilic & Acidic reactions)
Hydrogenation: Alkyne + H₂ / Ni → Alkane (complete); partial → Alkene.
RC≡CR' + 2H₂ / Ni → RCH₂—CH₂R'
HX addition (2 equivalents): Alkyne + 2HX → Geminal dihalide (Markovnikov).
HC≡CH + 2HBr → CH₃—CBr₂H (gem-dibromide)
Hydration (Kucherov): Alkyne + H₂O / H₂SO₄ + HgSO₄ → Enol → Tautomerism → Aldehyde/Ketone.
Kucherov reaction: Ethyne → Acetaldehyde; Higher alkynes → Ketones. Enol-keto tautomerism નો આધાર.
HC≡CH + H₂O / H₂SO₄+HgSO₄ → [CH₂=CH-OH] → CH₃CHO
Ozonolysis of alkynes → Carboxylic acids.
RC≡CR' →[1.O₃ / 2.H₂O] RCOOH + R'COOH
Acidic H of terminal alkyne: RC≡C—H + NaNH₂ → RC≡C⁻Na⁺ + NH₃. (Sodium acetylide).
HC≡CH + NaNH₂ → HC≡C⁻Na⁺ + NH₃
Metal acetylides: RC≡C⁻Ag⁺ (Tollens reagent test) and RC≡C⁻Cu⁺ — reddish/white precipitate.
Tollens test: Terminal alkyne + [Ag(NH₃)₂]⁺ → white ppt. of silver acetylide — distinguishing test!
📝 Non-terminal alkyne (internal) does NOT give Tollens test — only terminal ≡C—H reacts.
Terminal alkyne + NaNH₂Acetylide ion (nucleophilic C≡C⁻)
Acetylide ion + alkyl halideHigher alkyne (C-C bond formation)
