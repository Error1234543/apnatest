હાઇડ્રોકાર્બન્સ — ટૂંકા નોટ્સ (તેજીથી આવર્તન)

🧪 GUJCET — Gujarati • Chemistry • Hydrocarbons

📘 વ્યાખ્યાઓ

  • હાઇડ્રોકાર્બન્સ: એવા સંયોજનો જેમાં ફક્ત કાર્બન અને હાઇડ્રોજન હોય છે.
  • એલિફેમેટિક હાઇડ્રોકાર્બન્સ: બંધારણમાં શૃંખલા રૂપ ધરાવતા હાઇડ્રોકાર્બન્સ.
  • સિચ્લિક હાઇડ્રોકાર્બન્સ: બંધારણમાં વળાંક/છલ્લી રૂપ ધરાવતા હાઇડ્રોકાર્બન્સ.
  • અસંતૃપ્ત હાઇડ્રોકાર્બન્સ: C=C અથવા C≡C બંધ ધરાવતા હાઇડ્રોકાર્બન્સ.
  • આરોમેટિક હાઇડ્રોકાર્બન્સ: બેન્ઝીન રિંગ ધરાવતા હાઇડ્રોકાર્બન્સ જે હુકેલના નિયમનું પાલન કરે છે.
  • હુકેલનો નિયમ: સમતલ, એકતાંડીયલ, સંયુગ્મિત સિસ્ટમ ધરાવતા થાયે રિંગમાં 4n+2 π-ઇલેક્ટ્રોન હોવા જોઈએ.

⚡ સૂત્રો

  • ઍલ્કેન: CₙH₂ₙ₊₂ | ઍલ્કીન: CₙH₂ₙ | ઍલ્કાઇન: CₙH₂ₙ₋₂
  • બેન્ઝીનનું અણુસૂત્ર: C₆H₆
  • બેન્ઝીનનું બંધારણ: હેક્ઝાગોનલ રિંગ + ત્રણ દ્વિબંધ (રેઝોનન્સ સ્થિરતા ~150 kJ/mol)
  • DKH (Degree of Unsaturation): (2C + 2 - H)/X
  • ઇન્ડક્શન પ્રભાવ: સિગમા બંધમાં ઇલેક્ટ્રોન વિસ્થાપન (±I પ્રભાવ)

⭐ મુખ્ય તથ્યો

  • ઍલ્કેન્સને પેરાફિન્સ પણ કહે છે; તેઓ સૌથી ઓછી પ્રતિક્રિયાશીલ હાઇડ્રોકાર્બન્સ છે.
  • ઍલ્કીન્સમાં ભૂમિતિ સમતલીય (bond angle 120°); sp² સંકરણ.
  • ઍલ્કાઇન્સમાં ભૂમિતિ રેખીય (bond angle 180°); sp સંકરણ.
  • બેન્ઝીનમાં દરેક C–C બંધ લંબાઈ સમાન (~139 pm) હોય છે.
  • બેન્ઝીનનું સંપૂર્ણ હાઇડ્રોજનકરણ: ΔH = –208 kJ/mol; સાપેક્ષિક રીતે ઓછું ઉષ્મા મુક્ત થાય છે.
  • ઍલ્કીન્સમાં આંગિકા-ઇલેક્ટ્રોન બંધ હોય છે, ઍલ્કાઇન્સમાં એક σ + બે π બંધ હોય છે.
  • ઓક્સોસિન્થેસિસ (Kucherov પ્રક્રિયા): એથાઇન + H₂O → એસિટાલ્ડિહાઇડ (Hg²⁺/H₂SO₄ ઉપસ્થિતિમાં).
  • ડાયોડો એલ્કેન (Geminal): એક જ કાર્બન પર બે halogen — અસ્થિર, carbene ઉત્પન્ન કરે છે.
  • ઍલ્કેનનું મુક્ત-મૂલક હેલોજનીકરણ: Cl₂/hν અથવા Br₂/hν → alkyl halide + HX.
  • ઍલ્કીન્સનું ઍડિશન પ્રક્રિયાઓ: H-X, X₂, H₂O/H⁺, H₂/Pt.
  • માર્કોવનો નિયમ: હાઇડ્રોજન એટલો કાર્બન જોડાય છે જેણે વધુ હાઇડ્રોજન ધરાવતો હોય.
  • પેરોક્સાઇડ અસર (Kharasch): HBr + peroxide → anti-Markovnikov ઉત્પાદન (ફક્ત HBr માટે).
  • ઍલ્કીન્સનું ozonolysis: O₃ પછી Zn/H₂O → aldehyde/ketone (C=C બંધ તૂટે છે).
  • બેન્ઝીનનું નાઇટ્રેશન: HNO₃/H₂SO₄ → નાઇટ્રોબેન્ઝીન (EAS પ્રક્રિયા).
  • બેન્ઝીનનું સલ્ફોનિકરણ: fuming H₂SO₄ → benzenesulfonic acid.
  • બેન્ઝીનનું Friedel-Crafts अल्किनेशन: alkyl halide + AlCl₃ → alkylbenzene.
  • બેન્ઝીનનું Friedel-Crafts acylation: acyl chloride + AlCl₃ → aryl ketone.
  • ORTHO/PARA નિર્દેશક: –OH, –NH₂, –CH₃, –OCH₃ (ઇલેક્ટ્રોન દાતા ગ્રુપ્સ).
  • META નિર્દેશક: –NO₂, –COOH, –CHO, –CN (ઇલેક્ટ્રોન ખેંચનારા ગ્રુપ્સ).
  • બેન્ઝીનનું reduction: H₂/Ni (ઉચ્ચ તાપ) → cyclohexane.
  • ઍલ્કીન્સ β-હાઇડ્રોજન ધરાવતા alkyl halide થી dehydrohalogenation → alkene (Zaitsev નિયમ).
  • ઍલ્કાઇન્સ સોડિયમ અમોનિયલ AgNO₃ સાથે white precipitate (terminal alkyne માત્ર).
  • એરોમેટિસિટીની ચાર શરતો: (1) સિચ્લિક (2) સમતલ (3) એકતાંડીયલ (4) 4n+2 π-ઇલેક્ટ્રોન.

⚠️ સામાન્ય ભૂલો

  • પેરોક્સાઇડ અસર ફક્ત HBr માટે જ લાગુ પડે છે, HCl/HI માટે નહીં.
  • ઍલ્કીન્સમાં ભૂમિતિ વિસરીને રેખીય લખવાની ભૂલ; યાદ રાખો: ઍલ્કીન = સમતલીય.
  • બેન્ઝીનનું બંધારણ કેક્યુલે (alternating double bonds) તરીકે લખવાની ભૂલ; યોગ્ય: રેઝોનન્સ ફાળો દર્શાવો.
  • માર્કોવ નિયમનો ઉપયોગ terminal alkyne ના hydration માં ભૂલભરેલો — peroxide અસર યાદ રાખો.
  • DKH = 4 નક્કી કરતી વખતે બે π-બંધ + એક રિંગ ગણવાની ભૂલ; ધ્યાન રાખો.
  • ઍલ્કાઇન્સનું બ્રોમિનેશન 1 equivalent લેવાય ત્યારે vinyl bromide મળે છે, alkene નહીં.
  • Meta-directing groups અંદર –OH / –NH₂ ને સમાવી લેવાની ભૂલ; તે ORTHO/PARA directive છે.
  • ઍલ્કીન્સનું ozonolysis માં Zn નું સરળીકરણ ન કરવું; Zn ozonide ને stable કરે છે.
  • Benzene + Cl₂/UV (બિન-ઉત્પ્રેરક) → BHC (addition product), benzene chlorination નહીં.
  • Friedel-Crafts reaction phenol અને nitrobenzene સાથે થતી નથી.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • ઍલ્કેન, ઍલ્કીન, ઍલ્કાઇનના સંકરણ: sp³, sp², sp — પ્રત્યેકનો ભૂમિતિ અને બંધકોણ યાદ રાખો.
  • Markovnikov vs Anti-Markovnikov નિયમ: HBr + peroxide માં ધ્યાન રાખો.
  • Zaitsev નિયમ: Dehydrohalogenation માં વધુ બદલાયેલો alkene main product.
  • બેન્ઝીનની EAS પ્રક્રિયાઓ: નાઇટ્રેશન, સલ્ફોનિકરણ, halogenation, Friedel-Crafts — દરેકનું reagent અને_product.
  • Electrophilic substitution in benzene — nucleophilic addition નહીં ( Benzene સ્થિર છે ).
  • Geminal dihalide → carbene (divalent carbon intermediate).
  • Terminal alkyne acidic hydrogen: AgNO₃/NH₄OH તથા Tollen's reagent test.
  • બેન્ઝીનના ortho/meta/para isomers: substitution pattern નક્કી કરવા માટે directing effect.
  • Benzene → cyclohexane (H₂/Ni) vs benzene → chlorobenzene (Cl₂/FeCl₃) — distinction between addition and substitution.
  • Hybridization change: sp³ → sp² (dehydrogenation) → sp (dehydrohalogenation).
