Hydrocarbons — 🧪 GUJCET Exam Tricks

🧪 GUJCET — Gujarati • Chemistry • Hydrocarbons

🎯 પરીક્ષા ટ્રિક્સ

અસંતૃપ્તતાની માત્રા (Degree of Unsaturation) ફોર્મ્યુલા: D.O.U. = (2C + 2 - H - X + N)/2 — જવાબ 0 હોય તો શુદ્ધ સંતૃપ્ત સાંકેતિક, 1 = એક દ્વિબંધ અથવા એક વલય, 4 = બેન્ઝીન રિંગ. ઝડપથી ઓળખ.
જ્યારે મોલેક્યુલર ફોર્મ્યુલા આપેલું હોય અને સંયોજનની સંતૃપ્ત/અસંતૃપ્ત પ્રકૃતિ પૂછી હોય.
દા.ત.: C₆H₁₂ માટે D.O.U. = (12+2-12)/2 = 1 → એક દ્વિબંધ/વલય. C₆H₆ માટે D.O.U. = (12+2-6)/2 = 4 → બેન્ઝીન (3 દ્વિબંધ + 1 વલય).
બેન્ઝીન રિંગની અંદર દ્વિબંધ સંખ્યા ઝડપથી: D.O.U. − (બહારના દ્વિબંધ/વલય) = રિંગમાં 3 દ્વિબંધ. હૅક્કલનો નિયમ (4n+2 π-ઇલેક્ટ્રોન) લાગુ પાડતાં પહેલા D.O.U. ≈ 4 હોય તે ચકાસો.
સુગંધિતતા (Aromaticity) વਾਲા પ્રશ્નોમાં, ખાસ કરીને વૈકલ્પિક રચનાઓ આપી હોય તો.
દા.ત.: C₆H₆: D.O.U. = 4; તેમાંથી 1 વલય = બાકી 3 દ્વિબંધ → 6 π-ઇલેક્ટ્રોન → (4×1+2) = 6 ✅ સુગંધિત.
મેરકોફ્નીકોવના નિયમ (Markovnikov's Rule) નો ટૂંકો નિયમ: 'પરમાણુ સંખ્યા વધુ ધરાવતું કાર્બન (વધુ H ધરાવતું) હાઈડ્રોજન લે છે.' HBr ઉપરાંત અન્ય હાઈડ્રો હેલાઇડમાં (HCl, HI) પરોક્ષિડ અસર (Peroxide Effect) થતી નથી — અપવર્તન માત્ર HBr + ROOR માટે જ.
એલ્કીન + HX પ્રકારના પ્રશ્નોમાં, ખાસ કરીને વિષમરૂપ ઉમેરા (Asymmetric addition) પૂછાતા હોય.
દા.ત.: CH₃-CH=CH₂ + HBr → મુખ્ય નિષ્પન્ન: CH₃-CHBr-CH₃ (2-બ્રોમોપ્રોપેન). ROOR હોય તો વિપરીત: CH₃-CH₂-CH₂Br.
ઓજોનોલિસિસ (Ozonolysis) માટે યાદ રાખો: C=C બંધ તૂટે અને બંને કાર્બન પર C=O બને. જરૂરી નથી સંપૂર્ણ સમીકરણ લખવું — માત્ર C=C વચ્ચે કાપ મારો અને O મૂકો. મિથેનિલ (Methanal) જો મિથાઇલિન (terminal =CH₂) હોય તો મળશે.
એલ્કીનનું ઓજોનોલિટિક વિઘટન પરથી મૂળ એલ્કીન શોધવો હોય, અથવા નિષ્પન્ન ઓળખવા હોય.
દા.ત.: C₄H₈ + O₃/Zn,H₂O → CH₃CHO + CH₃CHO = બંને એક જ અલ્ડિહાઇડ → મૂળ: CH₃-CH=CH-CH₃ (બ્યુટ-2-ઈન). જો HCHO પણ મળે તો terminal =CH₂ હતું.
એલ્કાઇન (Alkyne) ની ઉમાક્ષિકતા (Acidity): sp સંકરણ ધરાવતા કાર્બન પરના H સૌથી વધુ એસિડિક. એસિડિક ક્રમ: હેક્સ-1-ઇન > હેક્સ-2-ઇન ≈ બેન્ઝીન > હેક્સેન. Na/NH₃(l) એલ્કાઇન રિડક્ટ કરી સિસ્-એલ્કીન બનાવે છે — ઝડપી ઓળખ માટે આ રિએજન્ટ યાદ રાખો.
એલ્કાઇનની એસિડિકતા કે રિડક્શન સંબંધી પ્રશ્નોમાં, વિકલ્પોમાંથી પસંદગી કરવી હોય.
દા.ત.: હેક્સ-1-ઇન (terminal) Na/NH₃ સાથે → હેક્સ-1-ઇનાઇડ બને (ડિપ્રોટોનેશન). હેક્સ-2-ઇન (internal) તેનાથી વિપરીત – Na/NH₃(l) એલ્કીન બનાવશે.
પરોક્ષિડ અસર (Peroxide Effect / Kharasch) માત્ર HBr સાથે જ લાગુ પડે છે — HCl અને HI માં ક્યારેય નહીં. જવાબમાં HCl/ROOR આપેલું હોય તો વિકલ્પ તરત બાદ.
વિકલ્પોમાં HX + ROOR આપેલા પ્રશ્નોમાં તરત જ ગેરફરજિયાત વિકલ્પો બાદ કરવા.
દા.ત.: CH₂=CH₂ + HCl/ROOR → HCl માં પરોક્ષિડ અસર થતી નથી, તેથી આ પ્રશ્નોનો જવાબ નિષ્પક્ષપણે માર્કોફ્નીકોવ જ રહેશે.
સંડાઉન-બેઈલર (Sandmeyer) / ગ્રિગ્નાર્ડ (Grignard) જેવા પ્રશ્નોમાં જવાબ નીપજવાની સંખ્યા તરત મેળવવા: પ્રત્યેક વિષમરૂપ નિષ્પન્ન (product) માટે રાસાયણિક રચના બદલાય છે — તેથી 1 પ્રતિભાવ માટે 1 મુખ્ય નિષ્પન્ન યાદ રાખો. વિપરિત પ્રકારના વિકલ્પો (જેમ કે બે સમાન નિષ્પન્ન અપ્રમાણ છે) તરત બાદ.
એક-પગલાં પ્રતિક્રિયા-નિષ્પન્ન પ્રશ્નોમાં, વિષમરૂપતા (stereochemistry/isomerism) જોડાઈ હોય તો.
દા.ત.: CH₃CH=CH₂ + HBr/ROOR → 1 મુખ્ય નિષ્પન્ન (anti-Markovnikov). જો વિકલ્પમાં 2 ભિન્ન નિષ્પન્નો હોય તો અશક્ય.
ઉપરોક્ત બ્રોમિન પરીક્ષણ (Bromine test): Br₂/CCl₄ (ભૂરો-લાલ) એલ્કીન/એલ્કાઇન સાથે રંગવિહોણું કરે છે; સંતૃપ્ત હાઈડ્રોકાર્બન (અલ્કેન) અને બેન્ઝીન (રૂટીન પરિસ્થિતિ) કરતાં રંગ અબદલી રહે છે. આ પ્રશ્નમાં સીધો જવાબ નીકળે.
સંતૃપ્ત vs અસંતૃપ્ત હાઈડ્રોકાર્બન ઓળખવાના પ્રશ્નમાં.
દા.ત.: પ્રશ્ન: કયું Br₂/CCl₄ સાથે રંગ ગુમાવે? વિકલ્પ: સાયક્લોહેક્ઝેન (અસંતૃપ્ત નથી) ❌, બ્યુટ-1-ઈન ✅ (રંગ ગુમાવે છે).
બેન્ઝીનના નાઈટ્રેશન (Nitration) માં NO₂⁺ નો ઉપયોગ થાય છે — HNO₃/H₂SO₄ = સંયુગ્મિક એસિડ. વિકલ્પમાં HNO₃/MgO અથવા અન્ય ભ્રમણાપૂર્ણ રેજન્ટ હોય તો તરત બાદ કરો.
બેન્ઝીનના વિધાન પ્રતિક્રિયાઓ (Electrophilic Aromatic Substitution) સંબંધી પ્રશ્નોમાં.
દા.ત.: બેન્ઝીન + HNO₃/H₂SO₄(conc.) → નાઈટ્રોબેન્ઝીન. HCl/H₂SO₄ અથવા HNO₃/MnO₂ જેવા વિકલ્પો ગેરમાર્ગદર્શક છે.
રેફ્રિનિંગ (Refining) / ક્રેકિંગ (Cracking) પ્રશ્નો: ભારે હાઈડ્રોકાર્બન → હલકા હાઈડ્રોકાર્બન. જો પ્રશ્નમાં દબાણ + તાપમાન + ઉત્પ્રેરક આપેલો હોય તો ઊર્જા-ઉચ્ચ (High temperature) = થર્મલ ક્રેકિંગ; ઓછું તાપમાન + Zeolite/Friedel-Crafts type = કાટાલાઇટિક ક્રેકિંગ. બંનેમાં ઉત્પન્ન થતી મુખ્ય નિષ્પન્ન હંમેશા અલ્કેન + એલ્કીન જોડો.
ઔદ્યોગિક તૈયારી / પ્રક્રિયા શર્તો સંબંધી પ્રશ્નમાં.
દા.ત.: C₁₂H₂₆ → C₆H₁₄ (હેક્સેન) + C₆H₁₂ (હેક્સેન) — આ રીતે ક્રેકિંગની નિષ્પન્ન યાદ રાખો.
ક્રાઉન એથીર (Crown Ether) સાથે K⁺ ની ઓળખ: 18-ક્રાઉન-6 (18-મેمبر, 6 ઓક્સીજન) K⁺ માટે સુંદર છે; 15-ક્રાઉન-5 Na⁺ માટે. GUJCET માં આ કોષ્ટક (table) ઘણીવાર પૂછાય છે — તરત જ યાદ કરો.
માસ્ક કરેલા આયન (Ion) ઓળખના પ્રશ્નોમાં, ખાસ કરીને cryptand/crown ether પ્રકારના.
દા.ત.: પ્રશ્ન: 18-ક્રાઉન-6 કયા આયનને બંધ કરે? જવાબ: K⁺ (Na⁺ ≠ 15-ક્રાઉન-5).
સ્વર્ણ (Combustion) પ્રશ્નો: 1 मोल એલ્કેન (CnH2n+2) → n मोल CO₂ + (n+1) मोल H₂O. એલ્કીન/એલ્કાઇન માટે પણ તે જ સૂત્ર લાગુ — H₂O ની માત્રા = C પરમાણુ સંખ્યા + 1 ઘટાડો અથવા સમીકરણ સંતુલિત કરી ગણતરી. CO₂ : H₂O નો ગુણોત્તર યાદ રાખો.
દહન પ્રક્રિયા (Combustion) ના પ્રશ્નમાં CO₂ / H₂O ના મોલ ગણવા હોય.
દા.ત.: CH₄ + 2O₂ → CO₂ + 2H₂O → 1 मोल CH₄ માંથી 1 मोल CO₂ + 2 मोल H₂O. C₃H₈: 3 मोल CO₂ + 4 मोल H₂O.
પ્રશ્નમાં 'વધુમાં વધુ Br₂' / 'અનંત H₂' જેવી શબ્દકલ્પના આવે તો: C=C દરેક દ્વિબંધ 1 Br₂ લે છે; C≡C 2 Br₂ લે છે (દ્વિ-ઉમેર). સંતુલન ચકાસવા: D.O.U. × 1 Br₂ = વપરાશ — એલ્કાઇન માટે 2×.
અસંતૃપ્ત હાઈડ્રોકાર્બનના વિસરણ/ઉમેરા પ્રકારના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 1 मोל બ્યુટ-1-ઇન કેટલા Br₂ લેશે? C≡C (એક ત્રિબંધ) → 2 मोल Br₂. જવાબ: 2.
સંકરણ (Hybridization) ઓળખ: sp³ = સંતૃપ્ત C (4 θેટા), sp² = દ્વિબંધ C (3 θેટા), sp = ત્રિબંધ C (2 θેટા). GUJCET માં ઘણા પ્રશ્નો સીધા સંકરણ પૂછે છે — ટૂંકી તપાસથી જવાબ.
કાર્બનના સંકરણ (sp, sp², sp³) શોધવાના પ્રશ્નોમાં.
દા.ત.: CH₃-C≡C-CH₃: મધ્યમ C → 2 θેટા (એક σ + બે π) → sp. છેડાના CH₃ → sp³.
આઈ.યુ.પી.એ.સી. (IUPAC) નામકરણમાં સૌથી ઓછી સંખ્યા (Lowest Locant) નિયમ: દ્વિબંધ/ત્રિબંધને ઓછી સંખ્યા આપો; જો સમાન હોય તો સબ્સ્ટિટ્યુએન્ટને ઓછી સંખ્યા. વિકલ્પો ચકાસતાં અવૈધ નામ તરત બાદ.
IUPAC નામકરણ વાળા પ્રશ્નોમાં, ખાસ કરીને વિકલ્પોમાંથી ચુકી કાઢવી હોય.
દા.ત.: CH₃-CH(Cl)-CH=CH₂: ડાયન (double bond) ને ઓછી સંખ્યા → 3-ક્લોરોબ્યુટ-1-ઈન (સાચું). 1-ક્લોરોબ્યુટ-3-ઈન ❌ (dwibond ને ઊંચી સંખ્યા મળી).
