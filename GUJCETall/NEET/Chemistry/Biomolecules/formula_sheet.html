⚡ સૂત્રો

મોનોસેકરેડ સામાન્ય બીજગણિત સૂત્ર: Cn(H2O)n ; જ્યાં n = 3 થી 7
n = કાર્બન પરમાણુઓની સંખ્યા ; C = કાર્બન ; H = હાઇડ્રોજન ; O = ઓક્સિજન · SI: બિનપરિમાણ (અણુસૂત્ર) · મોનોસેકરેડ શર્કરા માટે લાગુ (ત્રિઓઝ, પેન્ટોઝ, હેક્સોઝ आदि)
પોલીસેકરેડનું બીજગણિત સૂત્ર: (C6H10O5)n + H2O અથવા (C6H10O5)n·H2O
n = ગ્લૂકોઝ એકમોની સંખ્યા (મોટી) ; C6H10O5 = એક ગ્લૂકોઝ એકમનું સૂત્ર (ઘટાડા પછી) · SI: બિનપરિમાણ · સ્ટાર્ચ, સેલ્યુલોઝ, ગ્લાયકોજેન જેવા પોલીસેકરેડ માટે લાગુ
ડાઈસેકરેડ બનાવતી કંડેન્સેશન પ્રક્રિયા (ગ્લાઇકોસિડિક બંધ): C6H12O6 + C6H12O6 → C12H22O11 + H2O
C6H12O6 = મોનોસેકરેડ (ગ્લૂકોઝ/ફ્રુક્ટોઝ) ; C12H22O11 = ડાઈસેકરેડ ; H2O = જળઅપસરણથી નીકળતું પાણીનું અણુ · SI: બિનપરિમાણ · બે મોનોસેકરેડ વિભાજન થઈને ડાઈસેકરેડ બને ત્યારે લાગુ (ઉદા. સુક્રોઝ, મેલ્ટોઝ, લેક્ટોઝ)
પેપ્ટાઇડ બંધ રચના (જળઅપસરણ): H2N−CH(R1)−COOH + H2N−CH(R2)−COOH → H2N−CH(R1)−CO−NH−CH(R2)−COOH + H2O
R1, R2 = અમિનો એસિડના પાર્શ્વજૂથ (side chains) ; CO−NH = પેપ્ટાઇડ બંધ · SI: બિનપરિમાણ · બે અમિનો એસિડ વચ્ચે પ્રોટીન/પેપ્ટાઇડ રચાય ત્યારે લાગુ
પેપ્ટાઇડ બંધની આંશિક રચના (સારાંશ): −CO−NH− (પેપ્ટાઇડ બંધ / ઍમાઇડ બંધ)
−CO− = कार्बोनिल કાર્બોનિલ ; −NH− = એમાઇન નાઇટ્રોજન · SI: બિનપરિમાણ · પ્રોટીનના પ્રાથમિક ઘડામણમાં દરેક બે અમિનો એસિડ વચ્ચે લાગુ
અમિનો એસિડનો ઝટરઆયન (Zwitter-ion) સ્વરૂપ: H3N+−CH(R)−COO− (આંતરિક ઉભયધ્રુવી આયન)
H3N+ = પ્રોટોનેટેડ એમાઇન સમૂહ ; COO− = ડિપ્રોટોનેટેડ કાર્બોક્સિલેટ સમૂહ ; R = પાર્શ્વજૂથ · SI: બિનપરિમાણ · તટસ્થ pH પર અમિનો એસિડ અસ્તિત્વ ધરાવે છે તે સ્વરૂપ
આઇઝોઇલેક્ટ્રિક બિંદુ (pI) — મૂળભૂત પરિભાષા: pI = (pK1 + pK2) / 2 (એકઅધિકારીય (monoprotic) અમિનો એસિડ માટે)
pK1 = α−કાર્બોક્સિલ સમૂહનું विY dissociation constant ; pK2 = α−એમાઇન સમૂહનું dissociation constant ; pI = આઇઝોઇલેક્ટ્રિક બિંદુ · SI: બિનપરિમાણ (pH એકમ) · સાદા (non-polyatomic) અમિનો એસિડ માટે લાગુ ; ડાયઅમિનો કે ડાયકાર્બોક્સિલિક એસિડ માટે વધુ સૂત્રો જરૂરી
આલ્ફા-હેલીકલ (α-helix) પ્રોટીન દ્વિતીયક રચના: પ્રતિ 3.6 એમાઇનો એસિડ એકમ ~ 0.54 nm (રિપીટ દૂરિયા)
3.6 = એક પૂર્ણ ફેરમાં એમાઇનો એસિડ એકમોની સંખ્યા ; 0.54 nm = હેલીકલનો પિચ (pitch) · SI: nm (نانોમીટર) · પોલੀપેપ્ટાઇડ શૃંખલામાં આંતરિક H−બંધથી રચાતી α-હેલીકલ રચના માટે
β-પીક્ડ શીટ (β-pleated sheet) માટે સમતલ અંતર: પ્રતિ એમાઇનો એસિડ ~ 0.35 nm (પૂર્ણ વિસ્તરિત શૃંખલા)
0.35 nm = બે ક્રમિક એમાઇનો એસિડ વચ્ચેનું અંતર (extend chain માં) · SI: nm · β-શીટ રચના માટે લાગુ
ગ્લુકોઝનું બંધારણીય સૂત્ર (એકબાજુ રચના): CH2OH−(CHOH)4−CHO (n−ગ્લૂકોઝ / D-glyceraldehyde-derived)
CHO = આલ્ડિહાઇડ સમૂહ (C1) ; CHOH = હાઇડ્રોક્સિલ ધરાવતું કાર્બન ; CH2OH = પ્રાથમિક એલકોહોલિક સમૂહ (C6) · SI: બિનપરિમાણ · open-chain (ફિશર પ્રક્ષેપ) રૂપ માટે
ફ્રુક્ટોઝનું બંધારણીય સૂત્ર: CH2OH−(CHOH)3−CO−CH2OH
CO = ketone (કીટોન) સમૂહ (C2) ; CH2OH = બંને સिरों પર એલ્કોહોલિક સમૂહ · SI: બિનપરિમાણ · નળાયાર (Fructose / D-fructose) open-chain રૂપ
સુક્રોઝનું બીજગણિત સૂત્ર: C12H22O11
C = 12 કાર્બન ; H = 22 હાઇડ્રોજન ; O = 11 ઓક્સિજન ; = C6H12O6 + C6H12O6 − H2O · SI: બિનપરિમાણ · સુક્રોઝ (ગ્રાહકચર્ચી ખાંડ) માટે લાગુ
મેલ્ટોઝનું બીજગણિત સૂત્ર: C12H22O11
બે ગ્લૂકોઝ એકમો + જળઅપસરણ (−H2O) · SI: બિનપરિમાણ · મેલ્ટોઝ માટે (α-1,4 ગ્લાઇકોસિડિક બંધ)
ગ્લાયકોજેન / સ્ટાર્ચ નું એકમ એકમ સૂત્ર: −[C6H10O5]− (નવલગણિતમાં) ; જનરલ: (C6H10O5)nH2O
C6H10O5 = એક ગ્લૂકોઝ એકમ + જળઅપસરણ ; n = મોટી સંખ્યામાં પુનરાવર્તિત એકમ · SI: બિનપરિમાણ · પોલીસેકરેડ શૃંખલાના દરેક એકમ બિંદુ માટે
ગ્લુકોઝનું જૌથર પરિભ્રમણ (Dextrorotatory): [α]D25°C ≈ +52.7° (જળદ્રાવણમાં સંતુલન)
[α]D = સોડિયમ D-રેખા (589 nm) પર વિશિષ્ટ પરિભ્રમણ ; ° = ડિગ્રી · SI: ડિગ્રી (°) · D-(+)-ગ્લુકોઝ દ્રાવણ માટે
કાર્બોહાઇડ્રેટ વિઘટન પ્રક્રિયા (સામાન્ય): (C6H10O5)n + n H2O → n C6H12O6 (ગ્લૂકોઝ)
n = પોલીસેકરેડમાં ગ્લૂકોઝ એકમોની સંખ્યા ; H2O = અmla પાણીનું પ્રમાણ · SI: બિનપરિમાણ · એન્ઝાઇમેટિક અથવા ઍસિડ-ઉત્પ્રેરિત જળવિભાજન (hydrolysis) દરમિયાન
ન્યુક્લિયોટાઇડની રચના (એકમ): ન્યુક્લિયોટાઇડ = પ્યુરિન/પિરીમિડાઇન આલ્કેલિક + pentose શર્કરા + પોષ્ટિક аmla
પ્યુરિન = એડેનીન(A), ગ્વેનીન(G) ; પિરીમિડાઇન = સાયટોઝન(C), થાયમિન(T)/યુરેસિલ(U) ; pentose = ribose/deoxyribose · SI: બિનપરિમાણ · DNA / RNA બનાવતા મૂળભૂત એકમ માટે
DNA ન્યુક્લિયોટાઇડ શૃંખલા — બેઝ જોડી નિયમ (Chargaff): A = T ; G = C (બે ટ્રાન્ડ માટે)
A = એડેનીન ; T = થાયમિન ; G = ગ્વેનીન ; C = સાયટોઝન · SI: બિનપરિમાણ (મોલ અંશ) · રેખીય બે-સૂત્રી (double-stranded) DNA માટે
RNA ન્યુક્લિયોટાઇડ શૃંખલા — બેઝ જોડી: A = U ; G = C (જો જોડી બને તો)
U = યુરેસિલ (RNA માં T ને બદલે) ; બાકીના સમાન · SI: બિનપરિમાણ · tRNA / rRNA / mRNA ની secondary structure માં જોડી બનતી હોય
એન્ઝાઇમ પ્રણાલી સમીકરણ (સરળ): E + S ⇌ ES → E + P
E = એન્ઝાઇમ ; S = સબસ્ટ્રેટ ; ES = એન્ઝાઇમ−સબસ્ટ્રેટ અનુબંધ ; P = ઉત્પાદન · SI: બિનપરિમાણ · એન્ઝાઇમ પ્રતિક્રિયા પ્રકાશન માટે લાગુ (Michaelis–Menten મોડેલ પૂર્વધિગ્ગ)
Michaelis–Menten પ્રણાલી: v = (Vmax [S]) / (Km + [S])
v = પ્રારંભિક વેગ ; Vmax = લઘુત્તમ મહત્તમ વેગ ; [S] = સબસ્ટ્રેટ સાંદ્રતા ; Km = Michaelis sthiraank (અડધા Vmax આપતી [S]) · SI: [S] મોલ/L ; v, Vmax મોલ L⁻¹ s⁻¹ · એન્ઝાઇમ ગતિકી માટે લાગુ ; [S] << Km હોય તો પ્રથમ-ક્રમ ; [S] >> Km હોય તો શૂન્ય-ક્રમ
Km ની વ્યાખ્યા (સૂત્ર સ્વરૂપ): Km = (k₋₁ + k₂) / k₁
k₁ = E+S→ES દરસ્થિરાंक ; k₋₁ = ES→E+S પાછો દરસ્થિરાंक ; k₂ (kcat) = ES→E+P દરસ્થિરાंक · SI: મોલ/L (mol/L) · Michaelis−Menten સ્થિરાંકની વ્યાખ્યા
પ્રોટીનનું વિઘટન (જળવિભાજન) — અંતિમ ઉત્પાદન: પ્રોટીન + n H2O → n અમિનો એસિડ
n = પેપ્ટાઇડ બંધની સંખ્યા = એમાઇનો એસિડ એકમોની સંખ્યા · SI: બિનપરિમાણ · એન્ઝાઇમેટિક અથવા ઍસિડ હાઇડ્રોલિસિસ દ્વારા
રિબોઝ અને ડિঅક્સિરાઇબોઝ સૂત્ર: રિબોઝ: C5H10O5 ; ડિઅક્સિરાઇબોઝ: C5H10O4
રિબોઝ = pentose শর্करा (RNA માં) ; ડિઅક્સિરાઇબોઝ = 2-deoxyribose (DNA માં) ; O4 vs O5 તફાવત = C2' પર OH ની ગેરહાજરી · SI: બિનપરિમાણ · ન્યુક્લિક એસિડના પેન્ટોઝ શર્કરા એકમ માટે

  • બે મોનોસેકરેડનું જળઅપસરણ થઈ ડાઈસેકરેડ બને છે : 2 × C6H12O6 → C12H22O11 + H2O
  • n ગ્લૂકોઝ એકમોનું જળઅપસરણ થઈ પોલીસેકરેડ બને છે : n C6H12O6 → (C6H10O5)n + n H2O
  • પેપ્ટાઇડ બંધ એ કાર્બોક્સિલ (−COOH) અને એમાઇન (−NH2) વચ્ચેનો ઍમાઇડ બંધ છે
  • D-glyceraldehyde સાથે સંબંધિત બધા મોનોસેકરેડ D-શ્રેણીના છે ; (+)/(−) ચિહ્ન ભૌતિક પરિભ્રમણ દર્શાવે છે, R/S ગોઠવણી સાથે સીધું સંબંધિત નથી
  • Chargaff નો નિયમ : dsDNA માં A ના મોલ = T ના મોલ ; G ના મોલ = C ના મોલ
  • pI પર અમિનો એસિડનો શુદ્ધ વીજભાર શૂન્ય હોય છે (ઝટરઆયન સ્વરૂપ) ; pH < pI હોય તો કેટાયનિક, pH > pI હોય તો એનાઇનિક સ્વરૂપ પ્રબળ
  • Km નો નિમ્ન હોય તેટલું એન્ઝાઇમનું સબસ્ટ્રેટ પ્રત્યે આકર્ષણ વધુ ; Vmax એ સબસ્ટ્રેટ સાંદ્રતા પર આધારિત નથી (પ્રતિક્રિયા શૂન્ય-ક્રમ)
  • D − (+) −ગ્લુકોઝ = D-glucopyranose / D-galactose ના રિડ્યુસિંગ શર્કરા ; Fehling/ Tollens试剂 સાથે પ્રક્રિયા કરે છે
