🧠 યાદ રાખો

SI એકમ તંત્રમાં નવ મૂળભૂત એકમો યાદ રાખો: મીટર, કિલોગ્રામ, સેકન્ડ, એમ્પિયર, કેલ્વિન, મોલ, કैंડેલા.
મોલ = દળ / મોલર દળ; એક મોલમાં એવોગેડ્રો અંક (6.022 × 10²³) જેટલા મૂળભૂત એકમો હોય છે.
આપેલ દળમાં પરમાણુઓ/અણુઓની ગણતરી: n = N / N_A, જ્યાં N_A = 6.022 × 10²³.
ગણિતમાં મહત્તમ ચોકસાઈ માટે પરિણામનું સાર્થક અંક (significant figure) ધરાવવું ફરજિયાત છે.
દળ સંરક્ષણનો નિયમ: પ્રક્રિયા પહેલાં અને પછીનું કુલ દળ સમાન રહે છે.
સ્થિર આनुપાત્યનો નિયમ: યૌગિકના દરેક નમૂનામાં તત્વોનું દળ ગુણોત્તર સતત રહે છે.
બહુ-આણ્વીયતાનો નિયમ (Law of Multiple Proportion): બે તત્વ મળીને બેથી વધુ યૌગિક બનાવે તો બીજા તત્વના દળોનો ગુણોત્તર સરળ પૂર્ણાંકોમાં હોય છે.

⚡ ઝડપી સૂત્રો

મોલ = આપેલ દળ (g) ÷ મોલર દળ (g/mol)
મોલર દળ (g/mol) = પરમાણુ દળ (u) ની સંખ્યાત્મક કિંમત
ગેસના 1 મોલનું STP પર કદ = 22.7 L (NAIA નવા માપદંડ મુજબ; જૂના પાઠ્યક્રમમાં 22.4 L)
સાર્થક અંકો: શૂન્યેતર અંકો સાર્થક; શૂન્ય શરૂઆતમાં અસાર્થક, વચ્ચે અને છેડે સાર્થક.
તાપમાન કૂપમાન: K = °C + 273.15
મોલાલિટી (m) = વેડિંગ દ્રાવ્યના મોલ / દ્રાવકનું દળ (kg)
મોલારિટી (M) = દ્રાવ્યના મોલ / દ્રાવણનું કદ (L)
મોલ ભિન્નતા (χ_B) = B ના મોલ / કુલ મોલ
ટકાવારી મોલ ભિન્નતા = મોલ ભિન્નતા × 100
ટકાવારી સංಯોજક (w/w) = (દ્રાવ્યનું દળ / દ્રાવણનું દળ) × 100
પેર્ટ (ppm) = (દ્રાવ્યનું દળ / દ્રાવણનું દળ) × 10⁶

રિલેટિવ અણુભાર (vapor density) = 2 × રિલેટિવ અણુભાર; RD = M/2.
એમ્પિરિકલ ફોર્મ્યુલા = આયોનિક યૌગિકનું સૌથી સરળ પૂર્ણાંક ગુણોત્તર.
મોલેક્યુલર ફોર્મ્યુલા = n × એમ્પિરિકલ ફોર્મ્યુલા, જ્યાં n = મોલર દળ / એમ્પિરિકલ એકમ દળ.

કિસ્સાવાદ (limiting reagent) એ પ્રક્રિયક છે જે સૌથી પહેલાં ખતમ થાય છે અને ઉત્પાદન નક્કી કરે છે.
મોલલિટી તાપમાનથી બદલાતી નથી, જ્યારે મોલારિટી તાપમાન સાથે બદલાય છે.
સાર્થક અંકોના ગુણાકાર/ભાગાકારમાં અંતિમ પરિણામનો સાર્થક અંકોની સંખ્યા ન્યૂનતમ સાર્થક અંકો ધરાવતા પરિમાણ જેટલી હોય છે.
