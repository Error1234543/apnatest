ઉષ્માગતિશાસ્ત્ર (Thermodynamics) — સૂત્ર શેડ

🧪 GUJCET — Gujarati • Chemistry • Thermodynamics

⚡ સૂત્રો

ઉષ્માગતિશાસ્ત્રનું પ્રથમ નિયમ: ΔU = q + w
ΔU = અંતર્ગત ઊર્જામાં ફેરફાર, q = ઉષ્મા, w = કાર્ય · SI: જૂલ (J) · બંધ તંત્ર માટે; જ્યારે વરાળનું વિસ્તરણ/સંકોચન થાય
નિયત દબાણે ઉષ્મા (q_p) અને એન્થાલ્પી ફેરફાર: ΔH = q_p
ΔH = એન્થાલ્પી ફેરફાર, q_p = નિયત દબાણે લેવાતી/છોડાતી ઉષ્મા · SI: જૂલ (J) · અચળ દબાણ પર થતી પ્રક્રિયા
એન્થાલ્પી અને અંતર્ગત ઊર્જા વચ્ચેનો સંબંધ: ΔH = ΔU + PΔV
ΔH = એન્થાલ્પી ફેરફાર, ΔU = અંતર્ગત ઊર્જા ફેરફાર, PΔV = કાર્ય પદ · SI: જૂલ (J) · અચળ દબાણ પર
આદર્શ વાયુ માટે ΔH અને ΔU વચ્ચેનો સંબંધ (વાયુ મોલમાં ફેરફાર): ΔH = ΔU + Δn_g RT
Δn_g = ઉત્પાદનોના વાયવીય મોલ — પ્રક્રિયકોના વાયવીય મોલ, R = ગેસ અચળાંક (8.314 J K⁻¹ mol⁻¹), T = તાપમાન (K) · SI: જૂલ (J) · આદર્શ વાયુ, અચળ દબાણ, તાપમાન
અચળ કદે ઉષ્મા ધારિતા (C_v): C_v = (∂U/∂T)_V
C_v = અચળ કદે મોલર ઉષ્મા ધારિતા, U = અંતર્ગત ઊર્જા, T = તાપમાન, V = કદ · SI: J K⁻¹ mol⁻¹ · અચળ કદ પર
અચળ દબાણે ઉષ્મા ધારિતા (C_p): C_p = (∂H/∂T)_P
C_p = અચળ દબાણે મોલર ઉષ્મા ધારિતા, H = એન્થાલ્પી, T = તાપમાન, P = દબાણ · SI: J K⁻¹ mol⁻¹ · અચળ દબાણ પર
માયરનું સૂત્ર (આદર્શ વાયુ માટે): C_p — C_v = R
C_p = અચળ દબાણે ઉષ્મા ધારિતા, C_v = અચળ કદે ઉષ્મા ધારિતા, R = ગેસ અચળાંક · SI: J K⁻¹ mol⁻¹ · આદર્શ વાયુ
વિકલ્પીય રૂપ — MAYER સૂત્ર: γ = C_p / C_v
γ (ગેમા) = ઉષ્મા ધારિતાનો ગુણોત્તર, C_p અને C_v ઉપરોક્ત પ્રમાણે · SI: અમાત્રક · આદર્શ વાયુ
નિયત દબાણે કાર્ય (સ્થિરાંક દબાણે વિસ્તરણ): w = —P_ext ΔV
w = થયેલું કાર્ય, P_ext = બાહ્ય દબાણ, ΔV = કદમાં ફેરફાર · SI: જૂલ (J) · અચળ બાહ્ય દબાણ પર વિસ્તરણ/સંકોચન
આદર્શ વાયુ માટે નિયત દબાણે કાર્ય: w = —P ΔV = —nRΔT
n = મોલ સંખ્યા, R = ગેસ અચળાંક, ΔT = તાપમાનમાં ફેરફાર · SI: જૂલ (J) · આદર્શ વાયુ, અચળ દબાણ
આદર્શ વાયુ માટે મહત્તમ કાર્ય (સમાંતર પ્રક્રિયા): w_max = —nRT ln(V₂/V₁)
n = મોલ સંખ્યા, R = ગેસ અચળાંક, T = તાપમાન (K), V₁ અને V₂ = અંતિમ અને પ્રારંભિક કદ · SI: જૂલ (J) · સમાંતર (સમતાપી) પ્રક્રિયા, આદર્શ વાયુ
સમાંતર પ્રક્રિયામાં ઉષ્મા: q = nRT ln(V₂/V₁) = nRT ln(P₁/P₂)
P₁, P₂ = પ્રારંભિક અને અંતિમ દબાણ · SI: જૂલ (J) · સમાંતર પ્રક્રિયા, આદર્શ વાયુ
એડિયબાટિક પ્રક્રિયા (q = 0): ΔU = w
q = 0 હોવાથી ΔU = w, ΔU = nC_vΔT, તેથી w = nC_vΔT · SI: જૂલ (J) · એડિયબાટિક પ્રક્રિયા — ઉષ્માનો આદાન-પ્રદાન ન થાય
એડિયબાટિક પ્રક્રિયા માટે P—V—T સંબંધ: PV^γ = અચળ, TV^(γ—1) = અચળ, P^(1—γ) T^γ = અચળ
γ = C_p/C_v, P = દબાણ, V = કદ, T = તાપમાન · SI: — ·
અચળ કદે કાર્ય: w = —P_ext ΔV = 0 (કારણ કે ΔV = 0)
w = કાર્ય, P_ext = બાહ્ય દબાણ, ΔV = કદ ફેરફાર · SI: જૂલ (J) · અચળ કદ (આઇસોકોરિક) પ્રક્રિયા
અચળ તાપમાને કાર્ય: w = 0 (કારણ કે ΔT = 0, આદર્શ વાયુ માટે ΔU = 0)
w = કાર્ય, ΔT = તાપમાન ફેરફાર · SI: જૂલ (J) · સમાંતર પ્રક્રિયા (આદર્શ વાયુ)
આઇસોથર્મલ (સમાંતર) પ્રક્રિયા: ΔU = 0, ΔH = 0, q = —w = nRT ln(V₂/V₁)
ΔU = 0 (તાપમાન અચળ, આદર્શ વાયુ), q = ઉષ્મા, w = કાર્ય · SI: જૂલ (J) · આદર્શ વાયુ, અચળ તાપમાન
પ્રમાણિત રચના એન્થાલ્પી (Δ_f H°): Δ_r H° = Σ ν_p Δ_f H°(ઉત્પાદનો) — Σ ν_r Δ_f H°(પ્રક્રિયકો)
ν_p, ν_r = સ્થૂળ સહગુણકો (સ્ટૉઇકિઓમેટ્રિક કોએફિશિયન્ટ), Δ_f H° = પ્રમાણિત રચના એન્થાલ્પી · SI: kJ mol⁻¹ · હુન્સનું નિયમ
પ્રમાણિત દહન એન્થાલ્પી (Δ_c H°): Δ_c H° = ઉત્પાદનોની રચના એન્થાલ્પીના જમણાં બાજુના જેમ ગણતરી
Δ_c H° = પ્રમાણિત દહન એન્થાલ્પી, ઉત્પાદનો = CO₂, H₂O વગેરે · SI: kJ mol⁻¹ · ધન પરિણામ: 1 મોલ પદાર્થનું સંપૂર્ણ દહન
બંધ એન્થાલ્પી પદ્ધતિ: Δ_r H° = Σ બંધ ઉષ્મા (ભંગાણ) — Σ બંધ ઉષ્મા (બનાવણ)
બંધ ઉષ્મા = એક બંધ તોડવામાં ઊર્જા, ભંગાણ = તૂટતા બંધો, બનાવણ = બનતા બંધો · SI: kJ mol⁻¹ · ગેસીય અવસ્થાની પ્રક્રિયા
કિરહૉફ్ સમીકરણ — તાપમાન પર ΔH નો ફેરફાર: ΔH(T₂) = ΔH(T₁) + ΔC_p (T₂ — T₁)
ΔC_p = C_p(ઉત્પાદનો) — C_p(પ્રક્રિયકો), T₁ અને T₂ = તાપમાન · SI: kJ · અચળ દબાણ, C_p અચળ હોય તેમ ગણીએ
થર્મોકેમિકલ સંતુલન — પ્રક્રિયા ઊલટાવવી: જો પ્રક્રિયા ઊલટાવવી: ΔH_(ઊલટી) = —ΔH_(મૂળ)
ΔH_(મૂળ) = મૂળ પ્રક્રિયાની એન્થાલ્પી ફેરફાર · SI: kJ mol⁻¹ · થર્મોકેમિકલ સમીકરણનો ઉલટાવ
થર્મોકેમિકલ સંતુલન — ગુણાંક ગુણવા: જો સમીકરણના સહગુણકો n વડે ગુણવા: ΔH_(નવું) = n × ΔH_(મૂળ)
n = ગુણોત્તર, ΔH_(મૂળ) = મૂળ પ્રક્રિયાની એન્થાલ્પી ફેરફાર · SI: kJ mol⁻¹ · સ્ટૉઇકિઓમેટ્રિક સહગુણકો બદલવા
હેસનો નિયમ (પ્રક્રિયા એન્થાલ્પી): Δ_r H = Σ (ΔH_પગલાં)
Δ_r H = કુલ પ્રક્રિયા એન્થાલ્પી ફેરફાર, ΔH_પગલાં = વચગાળાની પ્રક્રિયાઓની એન્થાલ્પી ફેરફાર · SI: kJ mol⁻¹ · એન્થાલ્પી અવસ્થા વિધેય છે
પ્રક્રિયાના દિશા નક્કી કરવી (સ્વયંસ્ફુરિતતા માટે): gibbs free energy: ΔG = ΔH — TΔS
ΔG = ગિબ્સ મુક્ત ઊર્જા ફેરફાર, ΔH = એન્થાલ્પી ફેરફાર, T = તાપમાન (K), ΔS = એન્ટ્રોપી ફેરફાર · SI: kJ mol⁻¹ · અચળ તાપમાન અને દબાણ
સ્વયંસ્ફુરિત પ્રક્રિયાનું માપદંડ: જો ΔG < 0 → સ્વયંસ્ફુરિત; ΔG = 0 → સંતુલન; ΔG > 0 → અસ્વયંસ્ફુરિત
ΔG = ગિબ્સ મુક્ત ઊર્જા ફેરફાર · SI: kJ mol⁻¹ · અચળ T અને P
પ્રક્રિયા દરમિયાન થતું ઉષ્મા કાર્ય (સામાન્ય): w = —P_ext × (V₂ — V₁)
P_ext = બાહ્ય દબાણ, V₁ = પ્રારંભિક કદ, V₂ = અંતિમ કદ · SI: જૂલ (J) · અચળ બાહ્ય દબાણ
સંકોચન/વિસ્તરણ કાર્ય — દબાણ-કદ લેખ પર: w = —∫(P_ext dV)
P_ext = બાહ્ય દબાણ, dV = કદમાં અવયવ ફેરફાર · SI: જૂલ (J) · ચલ દબાણ પર વિસ્તરણ/સંકોચન

🔗 સંબંધો

  • એન્થાલ્પી H = U + PV, તેથી ΔH = ΔU + Δ(PV). આદર્શ વાયુ માટે ΔH = ΔU + Δn_gRT.
  • C_p — C_v = R (માયરનું સૂત્ર). γ = C_p/C_v = 1 + R/C_v.
  • એડિયબાટિક પ્રક્રિયામાં q = 0, તેથી ΔU = w. તાપમાન ફેરફારને કારણે ΔU = nC_vΔT.
  • સમાંતર (આઇસોથર્મલ) પ્રક્રિયામાં ΔT = 0, આદર્શ વાયુ માટે ΔU = 0, ΔH = 0, તેથી q = —w.
  • હેસના નિયમ મુજબ એન્થાલ્પી એ અવસ્થા વિધેય છે — પ્રક્રિયાના માર્ગ પર આધારિત નથી.
  • ΔG = ΔH — TΔS માંથી: તાપમાન વધતા ΔG નું મહત્વ ઘટે છે — ઊંચા તાપમાને એન્ટ્રોપી પ્રભાવ વધુ અસરકારક બને છે.
  • ગુણોત્તર γ = C_p/C_v ≥ 1. એકપાર્માણુક આદર્શ વાયુ માટે γ = 5/3, દ્વિપાર્માણુક માટે γ = 7/5.

🎯 ટ્રિક્સ

Δn_g શોધવા: સામાન્ય રીતે પ્રક્રિયકો અને ઉત્પાદનોમાં વાયુ સ્થિતિના મોલ ગણો. ઘન અને પ્રવાહીને બાદ કરો. ઉદા: CaCO₃(s) → CaO(s) + CO₂(g), Δn_g = 1 — 0 = 1.
જો પ્રક્રિયામાં વાયુ મોલની સંખ્યા વધે (Δn_g > 0) → ΔH > ΔU. ઘટે (Δn_g < 0) → ΔH < ΔU. સમાન (Δn_g = 0) → ΔH = ΔU.
એડિયબાટિક વિસ્તરણ: વાયુ કાર્ય કરે → ΔU ઘટે → તાપમાન ઘટે. એડિયબાટિક સંકોચન: ΔU વધે → તાપમાન વધે.
C_p — C_v = R નો ઉપયોગ: જો C_v જ્ઞાત હોય તો C_p = R + C_v. એકપાર્માણુક આદર્શ વાયુ: C_v = 3R/2, C_p = 5R/2.
γ = C_p/C_v નો ઉપયોગ: એકપાર્માણુક γ = 5/3 ≈ 1.67, દ્વિપાર્માણુક γ = 7/5 = 1.4.
Δ_r H = Σ(બંધ ઉષ્મા, ભંગાણ) — Σ(બંધ ઉષ્મા, બનાવણ): કોઈ પણ બંધ તૂટે ત્યારે ઊર્જા શોષાય (+), બંધ બને ત્યારે ઊર્જા મુક્ત થાય (—).
સમાન પ્રક્રિયાના બહુવિધ પગલાંનો સરવાળો કરીને મહત્તમ પ્રક્રિયા એન્થાલ્પી મેળવી શકાય (હેસનો નિયમ).
ΔG = 0 સંતુલન સૂચવે. તાપમાન માત્ર T = ΔH/ΔS જ્યારે ΔG = 0 હોય ત્યારે પ્રક્રિયા સંતુલનમાં હોય છે.

⚠️ ભૂલો

ΔU = q + w માં w નું ચિહ્ન ભૂલથી ધન લખવું. સાચું: w = —P_extΔV (વિસ્તરણ પર કાર્ય ઋણ, સંકોચન પર ધન).
ΔH = ΔU + PΔV ને ΔH = ΔU + VΔP તરીકે ભૂલથી લખવું. સાચું: અચળ દબાણે ΔH = ΔU + PΔV.
Δn_g ગણતરીમાં ઘન (s) અને પ્રવાહી (l) ને પણ વાયુ મોલ તરીકે ગણી લેવું. ફક્ત વાયુ (g) સ્થિતિના અણુઓ જ ગણવા.
C_p — C_v = R સૂત્રનો ઉપયોગ પ્રવાહી અને ઘન પદાર્થો માટે કરી દેવો. આ સૂત્ર ફક્ત આદર્શ વાયુ માટે છે.
એડિયબાટિક પ્રક્રિયામાં q = 0 હોવા છતાં ΔU = 0 ધારી લેવું. એડિયબાટિકમાં કાર્ય થાય છે, તેથી ΔU ≠ 0 (તાપમાન બદલાય).
સમાંતર પ્રક્રિયામાં ΔU ≠ 0 ધારી લેવું. આદર્શ વાયુ માટે સમાંતર પ્રક્રિયાએ ΔU = 0, ΔH = 0.
વાયુ મોલ સંખ્યાનો ફેરફાર (Δn_g) ઋણ લખવો જ્યારે વાયુ મોલ સંખ્યા વધે. Δn_g = ઉત્પાદન મોલ — પ્રક્રિયક મોલ.
બંધ એન્થાલ્પી પદ્ધતિમાં C=O (કાર્બોન ડાયોક્સાઇડમાં) અને O—H (પાણીમાં) ના મૂલ્યો યાદ ન રાખી ભૂલ કરવી.
કિરહૉફ્ સમીકરણમાં ΔC_p = C_p(પ્રક્રિયક) — C_p(ઉત્પાદનો) તરીકે લખી દેવું. સાચું: ΔC_p = C_p(ઉત્પાદન) — C_p(પ્રક્રિયક).
એન્થાલ્પીને સદિશ ગણી ચિહ્ન વડે મહત્વ આપવું. એન્થાલ્પી એ અવસ્થા વિધેય છે, માર્ગ વિધેય નહીં.
R નું મૂલ્ય 8.314 J K⁻¹ mol⁻¹ લેવું જોઈએ, પણ ક્યારેક 0.0821 L atm K⁻¹ mol⁻¹ લખી દેવાય — એ R અલગ એકમોમાં છે.
