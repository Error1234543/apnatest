ઉષ્માગતિશાસ્ત્ર (Thermodynamics) — ઝડપી પુનરાવર્તન

🧪 GUJCET — Gujarati • Chemistry • Thermodynamics

📘 વ્યાખ્યાઓ

  • ઉષ્માગતિશાસ્ત્ર: ઉષ્મા, કાર્ય અને ઉર્જા રૂપાંતરણનો અભ્યાસ.
  • તંત્ર: જે ભાગ આપણે અભ્યાસ માટે પસંદ કરીએ છીએ (system).
  • વાતાવરણ: તંત્રની બહારનો સમગ્ર ભાગ (surroundings).
  • ખુલ્લું તંત્ર: દળ અને ઉર્જા બંને બદલાય છે.
  • બંધ તંત્ર: માત્ર ઉર્જા બદલાય છે, દળ નહીં.
  • વિભાજિત તંત્ર: દળ અને ઉર્જા કોઈ પણ બદલાતું નથી.
  • અવસ્થા ચલ: તે મૂલ્યો જે તંત્રની સ્થિતિ વર્ણવે છે (દા.ત. દબાણ, કદ, તાપમાન).
  • અવસ્થા વિધેય: એવું વિધેય જે ફક્ત પ્રારંભિક અને અંતિમ અવસ્થા પર આધારિત હોય, માર્ગ પર નહીં.
  • અવસ્થા સમાનતા: સમાન તાપમાન પર રહેલા બે તંત્રો વચ્ચે ઉષ્માનો પ્રવાહ ન થાય.
  • ઉષ્માગતિશાસ્ત્રનો શૂન્યમો નિયમ: જો A અને B બંને C સાથે ઉષ્મા સંતુલનમાં હોય, તો A અને B પણ પરસ્પર સંતુલનમાં હોય.
  • ઉષ્માગતિશાસ્ત્રનો પ્રથમ નિયમ: ઉર્જાનું સર્જન કે નાશ શક્ય નથી, માત્ર રૂપાંતરણ શક્ય છે.
  • ઉષ્માગતિશાસ્ત્રનો દ્વિતીય નિયમ: ઉષ્મા આપમેળે ઠંડીથી ગરમ તરફ પ્રવાહ પામતી નથી.

⚡ સૂત્રો

  • ΔU = q + w (ઉષ્માગતિશાસ્ત્રનો પ્રથમ નિયમ)
  • w = –Pext × ΔV (ધાર સમીકરણ મુજબનું કાર્ય)
  • ΔH = ΔU + PΔV (આચર્ય ઉષ્મા / એન્થાલ્પી ફેરફાર)
  • ΔH = ΔU + ΔnRT (ગેરીય પ્રક્રિયાઓ માટે, જ્યાં Δn = વાયુ મોલનો ફેરફાર)
  • q = m × s × ΔT (ઉષ્મા માત્રાનો ગણતરી સૂત્ર)
  • q = n × Cp × ΔT (સ્થિર દબાણે ઉષ્મા)
  • q = n × Cv × ΔT (સ્થિર કદે ઉષ્મા)
  • Cp – Cv = R (મેયરનો સંબંધ)
  • γ = Cp / Cv (અનુનાદ ગુણોત્તર)
  • w = –nRT ln(V₂/V₁) (વાળાસો સમતાપી પ્રતાવર્તી વિસ્તરણ)
  • w = –Pext(V₂ – V₁) (વાળાસો સમતાપી અપ્રતાવર્તી વિસ્તરણ)
  • qrev = TΔS (પ્રતાવર્તી પ્રક્રિયામાં ઉષ્મા)
  • ΔG = ΔH – TΔS (ગિબ્સ મુક્ત ઊર્જા)
  • ΔG° = –nFE°cell (ઇલેક્ટ્રોકેમિસ્ટ્રી સાથે સંબંધ)

⭐ મુખ્ય તથ્યો

  • ઉષ્મા (q) અને કાર્ય (w) અવસ્થા વિધેય નથી, માર્ગ વિધેય છે.
  • ΔU અને ΔH અવસ્થા વિધેયો છે.
  • સમતાપી પ્રક્રિયામાં T અચળ રહે છે → ΔU = 0 → q = –w.
  • વાયુનું સમતાપી વિસ્તરણ કરતાં સંકોચનમાં ઉષ્મા શોષાય છે.
  • પ્રસરણ (adiabatic) પ્રક્રિયામાં q = 0 → ΔU = w.
  • સ્થિર કદે kinkરવામાં કોઈ બાહ્ય કાર્ય થતું નથી (w = 0).
  • વાળાસો સમતાપી વિસ્તરણમાં kકાર્ય મહત્તમ હોય છે.
  • સમતાપી પ્રતાવર્તી વિસ્તરણમાં kકાર્ય > અપ્રતાવર્તી વિસ્તરણમાં kકાર્ય.
  • આદર્શ વાયુ માટે, kતપમાન ફેરફાર વગર ΔU = 0 અને ΔH = 0.
  • સાંદ્ર પ્રક્રિયા (exothermic): ΔH < 0 (ઋણ), ઉષ્મા મુક્ત થાય છે.
  • ઉષ્માશોષી પ્રક્રિયા (endothermic): ΔH > 0 (ધન), ઉષ્મા શોષાય છે.
  • બળશેલ (Bond) તોડવામાં ઉષ્મા શોષાય છે, બનવામાં ઉષ્મા મુક્ત થાય છે.
  • જલાઉસના નિયમ મુજબ, પ્રક્રિયાનો ΔH માર્ગથી સ્વતંત્ર હોય છે.
  • ΔG < 0: સ્ફૂર્ત પ્રક્રિયા (spontaneous)
  • ΔG > 0: અસ્ફૂર્ત પ્રક્રિયા (non-spontaneous)
  • ΔG = 0: પ્રણાલી સંતુલનમાં છે.
  • સ્ફૂર્તતા માટે ΔSકુલ > 0 હોવું જરૂરી છે.
  • એન્ટ્રોપી (S) વિવિક્તતાનું માપ છે; ક્રમબદ્ધતા વધે તો S ઘટે છે.
  • ઘન → દ્રવ → વાયુ ક્રમમાં S વધે છે: Sઘન < Sદ્રવ < Sવાયુ.
  • તાપમાન વધતાં એન્ટ્રોપી વધે છે.
  • ગેરીય મોલ સંખ્યા વધતાં એન્ટ્રોપી વધે છે.
  • kદાહન ઉષ્મા (ΔcH) સંયોગના 1 मोल જલન થવા પર મુક્ત થતી ઉષ્મા.
  • bબંધ ક્રમ (bond order) વધે તો બંધ લંબાઈ ઘટે અને બંધ ઉર્જા વધે છે.

⚠️ સામાન્ય ભૂલો

  • q અને w ઋણ/ધન ચિહ્ન સમજવામાં ભૂલ: tનતંત્ર પર થતું કાર્ય ધન, tનતંત્ર દ્વારા થતું કાર્ય ઋણ.
  • ΔH = ΔU + ΔnRT માં Δn = ઉત્પાદનના વાયુ મોલ – પ્રક્રિયકોના વાયુ મોલ.
  • સમતાપી પ્રક્રિયામાં ΔT = 0 હોય છે, પણ q અને w શૂન્ય નથી.
  • Cp > Cv હંમેશા; Cp અને Cv બંને ધન હોય છે.
  • બધી સ્ફૂર્ત પ્રક્રિયાઓ ઉષ્માક્ષેપક નથી હોતી; કેટલીક ઉષ્માશોષી પણ સ્ફૂર્ત હોય છે.
  • ΔG = 0 એટલે પ્રક્રિયા થઈ નથી તેમ નથી; પ્રક્રિયા સંતુલનમાં છે.
  • એન્ટ્રોપી કુલ (વિશ્વ) માં હંમેશા વધે છે, તંત્રની એન્ટ્રોપી ઘટી શકે છે.
  • વાળાસો અપ્રતાવર્તી વિસ્તરણમાં w = –PextΔV, ન કે –nRT ln(V₂/V₁).
  • ΔG° અને ΔG વચ્ચેનો તફાવત: ΔG° પ્રમાણિત અવસ્થા માટે, ΔG કોઈ પણ અવસ્થા માટે.
  • gગેરીય પ્રક્રિયામાં Δn શૂન્ય હોય તો ΔH = ΔU થાય છે.
  • બળશેલ ઉષ્મા અને ઉત્પાદન ઉષ્મા (formation enthalpy) વચ્ચે ભેદ samajવામાં ભૂલ.
  • ઉષ્માગતિશાસ્ત્રનો પ્રથમ નિયમ ઉષ્માક્ષેપક કાલ્પનિક યંત્ર (perpetual motion machine) અશક્ય કહે છે, પણ સંપૂર્ણતાની વાત કરતો નથી.
  • ગિબ્સ મુક્ત ઊર્જા તાપમાન પર આધારિત છે; આથી પ્રક્રિયાની સ્ફૂર્તતા તાપમાન પર આધારિત હોઈ શકે છે.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • પ્રથમ નિયમ: ΔU = q + w અને તેની ચિહ્ન પરંપરા બરાબર યાદ રાખો.
  • ΔH = ΔU + ΔnRT સૂત્ર રોજિંદા પ્રશ્નોમાં ખૂબ આવે છે.
  • Cp – Cv = R અને γ = Cp/Cv સંબંધો નિયમિત પુછાય છે.
  • જલાઉસના નિયમનો ઉપયોગ કરી gગેરીય પ્રક્રિયાનું ΔH શોધવું.
  • એન્ટ્રોપી ફેરફારની દિશા નક્કી કરવી: વાયુ મોલ વધતાં ΔS > 0.
  • ΔG = ΔH – TΔS સૂત્રનો ઉપયોગ કરી સ્ફૂર્તતા તપાસવી.
  • સમતાપી, પ્રસરણ, સમકદ અને સમદબાણ પ્રક્રિયાઓના ΔU, ΔH, q, w નું વિશ્લેષણ.
  • gગેરીય પ્રક્રિયાઓમાં ΔnG ની ગણતરી અને ΔH–ΔU સંબંધ.
  • બંધ ઉષ્મા (bond energy) પરથી પ્રક્રિયાની ઉષ્મા ગણતરી.
  • kદાહન ઉષ્મા અને ઉત્પાદન ઉષ્મા વચ્ચેનો સંબંધ અને ગણતરી.
  • વાળાસો સમતાપી વિસ્તરણમાં મહત્તમ કાર્ય: w = –nRT ln(V₂/V₁).
  • ΔG° અને K સંતુલન અચળાંક વચ્ચેનો સંબંધ: ΔG° = –RT ln K.
  • તાપમાન પ્રભાવ: ΔH ઋણ, ΔS ધન → હંમેશા સ્ફૂર્ત; ΔH ધન, ΔS ઋણ → ક્યારેય નહીં સ્ફૂર્ત.
  • અનુનાદ ગુણોત્તર γ અને એટોમિકતા વચ્ચેનો સંબંધ: એકપરામાણ્વિક γ=5/3, દ્વિપરામાણ્વિક γ=7/5.
  • પ્રસરણ પ્રક્રિયામાં તાપમાન ઘટે છે (વાયુનું વિસ્તરણ કરતી વખતે).
