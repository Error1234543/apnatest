GUJCET રસાયણશાસ્ત્ર — ઉષ્માગતિશીતિ (Thermodynamics) માટે કાર્યક્ષમ તકનીકો

🧪 GUJCET — Gujarati • Chemistry • Thermodynamics

🎯 પરીક્ષા ટ્રિક્સ

કાર્ય અને ઉષ્માના ચિહ્નો યાદ રાખવાની ઝટપટ કોષ્ટક પદ્ધતિ: પ્રણાલી પર થતું કાર્ય +, પ્રણાલી દ્વારા થતું કાર્ય –; પ્રણાલી દ્વારા શોષાયેલી ઉષ્મા +, પ્રણાલી દ્વારા બહાર નિકળેલી ઉષ્મા –.
જ્યારે પ્રશ્નમાં કાર્ય (w) કે ઉષ્મા (q) નું ચિહ્ન પૂછવામાં આવ્યું હોય અથવા ગણતરી દરમિયાન ચિહ્ન ભૂલવાની શક્યતા હોય.
દા.ત.: પ્રશ્ન: 5 J કાર્ય પ્રણાલી પર થાય છે. w ની કિંમત? જવાબ: w = +5 J. (કાર્ય પ્રણાલી પર થતાં + લઈએ.)
Δn_g સૂત્ર: વાયુ મોલ સંખ્યામાં ફેરફાર = (વાયુ ઉત્પાદનોના મોલ) – (વાયુ અભિક્રાજકોના મોલ). ઘન/દ્રવને ગણતરીમાં લેતાં નહીં.
ΔH અને ΔU વચ્ચેનો સંબંધ ΔH = ΔU + Δn_g·R·T ગણતરી કરવા માટે.
દા.ત.: N₂(g) + 3H₂(g) → 2NH₃(g); Δn_g = 2 – (1+3) = –2. (અહીં ફક્ત વાયુ અણુઓ ગણ્યા.)
સ્થિર કદે ઉષ્મા (q_v) = ΔU; સ્થિર દબાણે ઉષ્મા (q_p) = ΔH. સીધો જોડાણ યાદ રાખો: 'v → U', 'p → H'.
જ્યારે પ્રશ્નમાં q_v કે q_p આપેલું હોય અને ΔU કે ΔH પૂછ્યું હોય, અથવા કેલોરીમેટ્રી પ્રશ્નો હોય.
દા.ત.: સ્થિર કદે પ્રક્રિયામાં 100 kJ ઉષ્મા મુક્ત થાય → q_v = –100 kJ → ΔU = –100 kJ.
એન્થાલ્પી ફેરફારનું ચિહ્ન: +ΔH = ઉષ્માશોષી (Endothermic), –ΔH = ઉષ્માક્ષેપી (Exothermic). પ્રશ્નમાં 'ઉષ્મા મુક્ત થાય' = –ΔH, 'ઉષ્મા શોષાય' = +ΔH.
ચિહ્ન સંબંધી સીધા પ્રશ્નો અથવા વિધાન સાચું/ખોટું તપાસવા માટે.
દા.ત.: C(s) + O₂(g) → CO₂(g); ΔH = –393.5 kJ/mol → ઉષ્માક્ષેપી પ્રક્રિયા.
હેસના નિયમનો ઝટપટ ઉપયોગ: જો માંગેલ પ્રક્રિયા બીજી પ્રક્રિયાઓના સરવાળા/વિયોગથી મળે, તો ΔH પણ તેમના ΔH ના સરવાળા/વિયોગથી મળે. સમીકરણોને ગુણકથી ગુણી કે ઉલટાવી શકાય.
જ્યારે સીધું ΔH આપેલું ન હોય અને બહુવિધ પગલાંવાળી પ્રક્રિયાઓ આપેલી હોય.
દા.ત.: C → CO₂ માટે ΔH ડાયરેક્ટ ન આપેલું હોય, પણ C → CO અને CO → CO₂ ના ΔH આપેલા હોય, તો બેની જોડી કરી ΔH મેળવો.
બંધ એન્થાલ્પીથી ΔH_rxn ≈ (અભિક્રાજકોના બધા બંધો તોડવાની ઊર્જા) – (ઉત્પાદનોના બધા બંધો બનવાની ઊર્જા). યાદ રાખો: 'તોડવું = ખર્ચ, બનાવવું = લાભ'.
જ્યારે બંધ એન્થાલ્પી (Bond Enthalpy) ની કિંમતો આપેલી હોય અને પ્રક્રિયાની ઉષ્મા ગણવી હોય.
દા.ત.: H–H + Cl–Cl → 2H–Cl: ΔH ≈ [BE(H–H) + BE(Cl–Cl)] – 2×BE(H–Cl).
એન્ટ્રોપી (S) નું ચિહ્ન અંદાજ: ઘન → દ્રવ → વાયુ પરિવર્તનમાં ΔS > 0; મોલ સંખ્યા વધે તો ΔS > 0; અવ્યવસ્થા વધે તો ΔS > 0.
એન્ટ્રોપી ફેરફારના ચિહ્ન વિશેની વાક્ય-આધારિત પસંદગી પ્રશ્નો.
દા.ત.: H₂O(l) → H₂O(g) માટે ΔS > 0, કારણ કે વાયુ અવસ્થામાં અવ્યવસ્થા વધે છે.
ગિબ્સ મુક્ત ઊર્જા નિયમ: ΔG = ΔH – TΔS. સ્વયંસ્ફુરિતતા માટે ΔG < 0. ચારેય કિસ્સાઓ યાદ રાખો: (i) –ΔH, +ΔS → સર્વત્ર સ્વયંસ્ફુરિત, (ii) +ΔH, –ΔS → ક્યારેય નહીં, (iii) –ΔH, –ΔS → નીચા T પર, (iv) +ΔH, +ΔS → ઊંચા T પર.
પ્રક્રિયાની સ્વયંસ્ફુરિતતા કે અસ્થાયિત્વ વિશેના પ્રશ્નો.
દા.ત.: જો ΔH = –ve અને ΔS = +ve, તો ΔG હંમેશા –ve → પ્રક્રિયા સર્વત્ર સ્વયંસ્ફુરિત.
સામાન્ય અવસ્થા (Standard State) ની ચોકસાઈ: 298 K, 1 bar દબાણ, 1 M સાંદ્રતા (દ્રાવણ), શુદ્ધ પદાર્થની સૌથી સ્થિર રૂપ. ΔH_f°, ΔS°, ΔG_f° ની વ્યાખ્યાઓ યાદ રાખો.
સામાન્ય અવસ્થા સંબંધી વ્યાખ્યા/વિધાન પ્રશ્નો.
દા.ત.: CO₂(g) ની ΔH_f° એ C(ગ્રેફાઈટ) + O₂(g) → CO₂(g) પ્રક્રિયાનો એન્થાલ્પી ફેરફાર.
એડિયાબેટિક પ્રક્રિયા: q = 0 → ΔU = w. ગરમીનો આદાપ્રદાન શૂન્ય. આ પદ્ધતિ યાદ રાખો: 'એડિયાબેટિક = અદળબદલ શૂન્ય'.
જ્યારે પ્રશ્નમાં 'એડિયાબેટિક' શબ્દ આવે.
દા.ત.: એડિયાબેટિક વિસ્તરણમાં પ્રણાલી દ્વારા કાર્ય કરવાથી આંતરિક ઊર્જા ઘટે → તાપમાન ઘટે.
સ્થિર કદ કેલોરીમીટર (Bomb Calorimeter) ΔU માપે; સ્થિર દબાણ કેલોરીમીટર ΔH માપે. 'Bomb' = સ્થિર કદ → ΔU.
કેલોરીમીટર પ્રકાર અને માપવામાં આવતું રાશિ વિશેના પ્રશ્નો.
દા.ત.: બમ્બ કેલોરીમીટરમાં જ્વલન ઉષ્મા માપતાં ΔU_u મળે, પછી ΔH_h = ΔU_u + Δn_gRT.
ΔG° = –RT ln K અથવા ΔG° = –2.303 RT log K. 298 K આસપાસ R = 8.314 J K⁻¹ mol⁻¹ લેતાં, log K = –ΔG°/(2.303RT). ગણતરીમાં ઘણીવાર K નું મૂલ્ય 1, >1, <1 પરથી ΔG° નું ચિહ્ન નક્કી કરી શકાય.
સંતુલન અચળાંક K અને પ્રમાણિત ગિબ્સ ઊર્જા વચ્ચેનો સંબંધ પૂછતો પ્રશ્ન.
દા.ત.: જો K > 1 → ln K > 0 → ΔG° < 0; જો K < 1 → ΔG° > 0; જો K = 1 → ΔG° = 0.
ત્રિક બિંદુ (Triple Point): એવી અદ્વિતીય તાપમાન અને દબાણ જ્યાં ઘન, દ્રવ અને વાયુ ત્રણેય અવસ્થાઓ સંતુલનમાં રહે. માત્ર એક જ અનન્ય તાપમાન-દબાણ.
અવસ્થા ચિત્ર (Phase Diagram) સંબંધી વ્યાખ્યા/ગુણધર્મ પ્રશ્નો.
દા.ત.: પાણીનું ત્રિક બિંદુ: 273.16 K અને 611 Pa (0.006 atm).
