હેલોએલ્કેન્સ અને હેલોઅરીન્સ — ટૂંકા નોટ્સ

🧪 GUJCET — Gujarati • Chemistry • Haloalkanes and Haloarenes

📘 વ્યાખ્યાઓ

  • હેલોએલ્કેન (Haloalkane): એલ્કેનનો આલ્ફા કાર્બન જ્યાં એક હેલોજન પરમાણુ બદલાતો હોય; સૂત્ર R−X
  • હેલોઅરીન્સ (Haloarene): બેન્ઝીન વર્તુળના હાઇડ્રોજન પરમાણુ બદલાતા હોય; Ar−X
  • નેક્લિયોફાઈલ (Nucleophile): ઇલેક્ટ્રોન જોડો આપતો કે અણુ/આયન જે ધન કેન્દ્રિત કાર્બન તરફ આકર્ષાય છે
  • ઇલેક્ત્રોફાઈલ (Electrophile): ઇલેક્ટ્રોન કમી ધરાવતો કે અણુ/આયન જે ઇલેક્ટ્રોન સમૃદ્ધ કેન્દ્ર તરફ આકર્ષાય છે
  • S_N2 પ્રતિક્રિયા: એક-પગલાં નેક્લિયોફીલિક બંધારણ-બદલાવ; બેક-સાઇડ હુમલો + વલય વિન્નતિ
  • S_N1 પ્રતિક્રિયા: બે-પગલાં નેક્લિયોફીલિક બંધારણ-બદલાવ; કાર્બોકેટાયન મધ્યસ્થી બને છે

⚡ સૂત્રો

  • હેલોએલ્કેનનું સામાન્ય સૂત્ર: C_nH_{2n+1}X
  • હેલોઅરીન્સનું સામાન્ય સૂત્ર: Ar−X (એક હેલોજન)
  • S_N2 નિયંત્રક દર = k[રેલોએલ્કેન][નેક્લિયોફાઈલ]
  • S_N1 નિયંત્રક દર = k[રેલોએલ્કેન] (હેલોએલ્કેનની ડિસોસિએશન પર આધારિત)
  • હોફમેન નિયમ: ઓછા સ્થાનબદ્ધ (less substituted) એલ્કીન મુખ્ય ઉત્પાદન (એલિમિનેશનમાં)
  • ઝેચેચેવ નિયમ: વધુ સ્થાનબદ્ધ (more substituted) એલ્કીન મુખ્ય ઉત્પાદન (એલિમિનેશનમાં)

⭐ મુખ્ય તથ્યો

  • હેલોજનની ઇલેક્ટ્રોનેગેટિવિટી: F > Cl > Br > I → C−X બંધના ધ્રુવીયણનું માપ
  • C−I બંધ સૌથી નબળો, તેથી આયોડોએલ્કેન સૌથી વધુ પ્રતિક્રિયાશીલ
  • સંયુગ્મિત હેલોજન (vinyl/aryl) S_N પ્રતિક્રિયાઓમાં અતિરિક્ત અસક્રિય છે
  • બેન્ઝીન સાથે Cl₂ + anhyd. FeCl₃ → ક્લોરોબેન્ઝીન (ઇલેક્ત્રોફીલિક એડિશન)
  • એલ્કોહોલ + SOCl₂ → એલ્કાઇલ ક્લોરાઇડ + SO₂ + HCl (પ્યોર શેલર રીત)
  • Friedel-Crafts alkyl: benzene + alkyl halide + AlCl₃ → alkylbenzene
  • Wurtz પ્રતિક્રિયા: 2R−X + 2Na (dry ether) → R−R + 2NaX
  • GriGNAR (Grignard): R−X + Mg (dry ether) → R−Mg−X
  • ડાયએલ્કાઇલ હેલાઇડ + Zn dust → એલ્કીન (ડિહેલોજેનેશન)
  • હેલોએલ્કેનનું NaOH(aq) સાથે હાઇડ્રોલિસિસ → એલ્કોહોલ
  • હેલોએલ્કેનનું alc. KOH સાથે એલિમિનેશન → એલ્કીન + H₂O + KX
  • હેલોએલ્કેન + alc. AgNO₂ → નાઇટ્રાઇટ (NO₂ આલ્કાઇડ)
  • હેલોએલ્કેન + KCN → એલ્કાઇલ સાયનાઇડ (સૌથી અગ્રણી ઉત્પાદન)
  • હેલોએલ્કેન + AgCN → એલ્કાઇલ આઇસોસાયનાઇડ (પ્રમાણમાં ઓછું)
  • બેન્ઝીન + Cl₂ + UV (ધૂપ) → BHC (6,6-dichlorocyclohexane)
  • BHC ને Linderan's powder કહેવાય છે; ખેતિમાં keet-naashak તરીકે વપરાય છે
  • સોડિયમ સાથે chlorobenzene નો ઉકેલ નથી S_N પ્રતિક્રિયા આપતો
  • એસિડિક/બેઇઝિક માધ્યમમાં C−X વધુ મજબૂત બને છે અને S_N શક્ય નથી થતું
  • એરિલ હેલાઇડ સંયુગ્મિત અણુઓ છે તેથી C−X બંધ આંશિક દ્વિબંધ લાક્ષણિકતા ધરાવે છે
  • રેલોએલ્કેનમાં 3D ચાર-અંક (stereocenter) હોય તો optical isomerism જોવા મળે છે
  • રેલોએલ્કેનની ઘનતા: R-I > R-Br > R-Cl; હેલોજનના ભાર પ્રમાણે વધે છે
  • એલ્કાઇલ હેલાઇડના ઉત્કલન બિંદુ: C−I > C−Br > C−Cl > C−F (van der Waals પ્રભાવ)
  • પોલીહેલોજેન યોગિકો: DDT, chloroform (CHCl₃), iodoform (CHI₃), Teflon
  • CHCl₃ + O₂ + light → highly toxic phosgene (COCl₂) બને છે, તેથી અંધકારમાં રાખવું
  • CHI₃ iodoform test માટે કાંઈક CH₃−C=O અથવા CH₃−CH(OH)− યુક્ટ ઓળખવા વપરાય છે

⚠️ સામાન્ય ભૂલો

  • alc. KOH સાથે R−X → એલ્કીન બને; aq. KOH સાથે R−X → એલ્કોહોલ બને (બંને અલગ છે)
  • KCN સાથે R−X માં CN⁻ નેક્લિયોફાઈલ છે → alkyl cyanide (main); AgCN માં C-બંધ બને → isonitrile
  • Vinyl and aryl halides S_N1/S_N2 બંનેમાં અસક્રિય છે તેથી બેચેન પર ધ્યાન આપો
  • S_N2 માં inversion of configuration (Walden inversion) થાય છે; S_N1 માં racemisation થાય છે
  • પ્રોપરેશન સમયે alkene નું મુખ્ય ઉત્પાદન Zaitsev નો નિયમ અનુસરે છે ( Hofmann નહીં!)
  • Wurtz પ્રતિક્રિયા સમમિતિય એલ્કેન બનાવે છે; different R માં mixed products મળે છે
  • ડાયઅલ્કાઇલ હેલાઇડ માં intra-molecular elimination થવાને બદલે ring formation થાય છે
  • હેલોઅરીન્સ ના nitration માં ortho/para directing −X નો ગુણધર્મ યાદ રાખવો
  • C−F બંધ સૌથી મજબૂત છે; તેથી haloalkane માં R−F સૌથી ઓછું પ્રતિક્રિયાશીલ
  • એલિમિનેશનમાં H−X ની દૂરી થાય છે; X અને β-H બંને એકબીજાની પાસે હોવા જોઈએ

🔥 હાઈ-યીલ્ડ મુદ્દા

  • સર્વાધિક પ્રતિક્રિયાશીલ: RI > RBr > RCl > RF (C−X બંધના પ્રબળતા પ્રમાણે)
  • S_N2: primary > secondary > tertiary (steric hindrance ને કારણે)
  • S_N1: tertiary > secondary > primary (stable carbocation બનાવવાની ક્ષમતા પ્રમાણે)
  • Tertiary haloalkane માટે S_N1 પ્રભાવી; primary માટે S_N2 પ્રભાવી
  • S_N1 માં રેસિમાઇઝેશન થાય છે (racemic mixture); સ્ટીરિયોકેમિસ્ટ્રીનું પ્રશ્ન આવે છે
  • S_N2 માં single step, inversion, no carbocation intermediate
  • સંયુગ્મિત એરિલ હેલાઇડ (chlorobenzene) માં પ્રતિક્રિયાશીલતા ખૂબ ઓછી
  • ડાયએલ્કેન (di-halides): vicinal (相邻) અને geminal (એક જ કાર્બન પર) બે પ્રકારના
  • Haloarene નું nucleophilic substitution extremely difficult: resonance stabilization + sp² hybridization
  • BHC = benzene + 3Cl₂ under UV light; 6,6-dichlorocyclohexane (addition product, not substitution)
