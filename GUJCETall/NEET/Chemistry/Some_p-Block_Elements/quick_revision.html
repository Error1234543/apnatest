🧠 યાદ રાખો

બોરોનમાં અપવાદી ગુણધર્મો: નાની ક્રિયાશીલ ત્રિજ્યા, ઊંચી આયનીકરણ ઉર્જા, ઉચ્ચ વિદ્યુતઋણતા, f-કક્ષકોનો અભાવ.
બોરોન–સિલીકોન વચ્ચે કર્ણ સંબંધ: બંનેના હાઈડ્રોક્સાઈડ નિર્બળ એસિડ છે, બંને ઓક્સાઈડ એમ્ફીટેરિક છે.
BX₃ (X=F,Cl,Br,I) લુઈસ ઍસિડ છે; BF₃ સૌથી નિર્બળ લુઈસ ઍસિડ છે કારણ B–F π-બંધ.
H₃BO₃ (બોરિક એસિડ) એ મોનોપ્રોટિક લુઈસ એસિડ છે; તેનો બંધારણ બોરેટ આયન [B(OH)₄]⁻ બનાવે છે.
ડાયબોરેન B₂H₆ માં બે બ્રિજ H પર ૩-કેન્દ્રીય ૨-ઇલેક્ટ્રોન બંધ (૩c-2e) હોય છે.
AlCl₃ ડાયમેરાઈઝ થઈ Al₂Cl₆ બનાવે છે; Al³⁺ આયન જલીય દ્રાવણમાં [Al(H₂O)₆]³⁺ બને છે.
Al₂O₃ અને Al(OH)₃ ઉભયગુણી છે; તે ત્રણ્ડરફ પ્રક્રિયામાં Na₃AlF₆માં વર્તૂળાય છે.
પારાના ધાત્વિક ગુણધર્મો Pb > Sn > Ge > Si > B ક્રમમાં વધે છે.
ઇનર્ટ પેયર અસર: ભારે તત્વો (Tl, Pb, Bi)માં ns² ઇલેક્ટ્રોનયુગ્મ અreaktive રહે છે, પરિણામે +3 કરતા +1 (Tl) અથવા +2 (Pb) સ્થિર.
C ઑલોટ્રોપ્સ: વજ્ર (tetrahedral sp³), ગ્રાફાઈટ (layered sp²), ફૂલરિન (C₆₀, spherical).
CO₂ રેખીય (sp), Non-polar; સશોષણિત શીતલ CO₂ સૂકો બરફ બને છે.
સિલિકેટ્સમાં SiO₄⁴⁻ ટેટ્રાહેડ્રનનો પુનરાવર્તિત એકમ; zeolite સોડિયમ એલ્યુમિનોસિલિકેટ Na[AlSiO₄]·nH₂O.
સિલિકોન (R₂SiO) એકમનો બહુલક; R=CH₃ હોય તો પોલીડાયમેથાઈલસિલોક્સેન, જે ઉષ્મા/રાસાયણિક પ્રતિરોધી છે.
બોક્સાઈટ શુદ્ધિકરણ (બાયર): Al₂O₃NaOHમાં વર્તૂળાઈ NaAl(OH)₄ બને છે, પછી CO₂થી Al(OH)₃ જમા કરે છે.

⚡ ઝડપી સૂત્રો

B₂O₃ + 3Mg → 2B + 3MgO (મગ્નેશિયમથી બોરોનની વ્યસ્તિ)
H₃BO₃ (→100°C) → HBO₂ (મيتાબોરિક એસિડ) (→160°C) → B₂O₃ (પેરાબોરિક એસિડ)
B₂O₃ + 6NaOH → 2Na₃BO₃ + 3H₂O
Na₂B₄O₇·10H₂O + H₂SO₄ → Na₂SO₄ + 4H₃BO₃ + 5H₂O (બોરેક્સથી બોરિક એસિડ)
B₂H₆ + 6H₂O → 2B(OH)₃ + 6H₂ (જળવિભાજન)
Al₂O₃ + 3C + 3Cl₂ → 2AlCl₃ + 3CO (ઉષ્મવિધારક ક્લોરીનેશન)
CO + Cl₂ → phosgene (COCl₂) (ઉત્પ્રેરક ZnCl₂, 298K)
Si + 3HCl → SiHCl₃ + H₂ (300°C, Cu ઉત્પ્રેરક)
nSiHCl₃ + (n+1)Zn → (SiH₂)ₙ + 2nZnCl₂ (ચેમ્બર પ્રક્રિયા, પોલીસિલેન)
SiCl₄ + 4H₂O → Si(OH)₄ → H₄SiO₄ (સિલિકાનિક એસિડ)

✅ વન-લાઈનર્સ

બોરોન એકધાતુ (monatomic) ન હોઈ શકે કારણ કે ત્રિસંયોજક (trivalent) હોવા છતાં તેના પાંચમા ઇલેક્ટ્રોન માટે યોગ્ય ખાલી d-કક્ષકોનો અભાવ.
બોરોનના સંયોગોમાં સહસંયોજક બંધ પ્રબળ છે; બોરોન આયનીય સંયોગો બનાવતું નથી.
BF₃, BCl₃, BBr₃ આંશિક π-બંધ ધરાવે છે (પરિણામે B–F બંધ બોરોનની સહસંયોજક ત્રિજ્યાથી ચૂકી હોય છે).
ડાયબોરેન (B₂H₆) માં ૬ સામાન્ય ૨c-2e બંધ અને ૨ બ્રિજ ૩c-2e બંધ હોય છે.
AlCl₃ સંયોગમાં બ્રિજ ક્લોરિન સહાયક બંધ (coordinate bond) બનાવે છે, જે ડાયમેરાઈઝેશનનું કારણ છે.
TlCl₃ અસ્થિર છે; TlCl સ્થિર છે (ઇનર્ટ પેયર અસર).
PbO₂ પ્રબળ ઑક્સિડાઈઝિંગ એજન્ટ છે; PbO₂ + 4HCl → PbCl₂ + Cl₂ + 2H₂O.
C સૂત્ર C₆₀ (ફૂલરિન) ૬૦ કેબલ બોન્ડથી ઘેરાયેલું અંતઃસ્થ બંધ ધરાવતું અણુ છે.
CO₂ માં C–O બંધ લંબાઈ (116 pm) સામાન્ય C=O બંધ કરતા ટૂંકી છે (π-બંધનો અંશવાદ).
સિલિકોન ડાયક્સાઈડ (SiO₂) ચતુષ્ફલકીય (tetrahedral) જಾಲકીય સંરચના ધરાવે છે; તે ભંગાણપૂર્વક તૂટે છે (conchoidal fracture).
Zeolite SODમાં [AlSiO₄]⁻ એકમો દ્વિ-પેંથ (double-ring) ધરાવે છે; આયન વિનિમય ગુણધર્મ ધરાવે છે.
સિલિકોન રબર (polysiloxane) –CH₃ R₂Si–O– નું બહુલક છે; UV પ્રતિરોધી અને ઓક્સિજન પ્રતિરોધી છે.
C પ્રક્રિયાએ ગ્રાફાઈટ–ગ્રાફાઈટ વચ્ચે weak van der Waals બળ હોવાથી તે મુક્ત સ્લિપ થાય છે (લ્યુબ્રિકન્ટ).
B સંયોગોમાં B–H–B બ્રિજ બંધ (3c-2e) હોય છે, જે બોરેનની હાઈડ્રોજન સંયોગોની પ્રતિક્રિયાશીલતા સમજાવે છે.
