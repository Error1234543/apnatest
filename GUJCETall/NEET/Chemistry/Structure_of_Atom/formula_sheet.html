પરમાણુની રચના (Structure of Atom) — સૂત્રોનો શીટ

🧪 GUJCET — Gujarati • Chemistry • Structure of Atom

⚡ સૂત્રો

તરંગ સમીકરણ (Wave Equation): c = ν × λ
c = પ્રકાશની ઝડપ (m/s), ν = આવર્તન (Hz અથવા s⁻¹), λ = તરંગલંબાઈ (m) · SI: m, Hz, m/s · શૂન્યાવકાશમાં વિદ્યુતચુંબકીય વિકિરણ માટે
પ્લાન્કનું સૂત્ર — ફોટોનની ઊર્જા (Planck's Formula): E = hν
E = ફોટોનની ઊર્જા (J), h = પ્લાન્કનો અચળાંક (6.626 × 10⁻³⁴ J·s), ν = આવર્તન (Hz) · SI: J · ફોટોન/વિકિરણની ઊર્જા ગણતરી માટે
ફોટોન ઊર્જા — તરંગલંબાઈના સ્વરૂપમાં: E = hc/λ
h = પ્લાન્ક અચળાંક, c = પ્રકાશની ઝડપ (3 × 10⁸ m/s), λ = તરંગલંબાઈ (m) · SI: J · જ્યારે તરંગલંબાઈ (λ) આપેલ હોય
પ્રકાશ-વીજળી અસર સમીકરણ (Photoelectric Effect): KE_max = hν − φ₀ અથવા KE_max = hν − hν₀
KE_max = ઉત્સર્જિત ઇલેક્ટ્રોનની મહત્તમ ગતિઊર્જા (J), φ₀ = કાર્યકાર્ય (Work function, J), ν₀ = દહન આવર્તન (Threshold frequency) · SI: J · પ્રકાશ-વીજળી અસરના મુખ્ય સમીકરણ તરીકે
ક્વોન્ટમ સંખ્યાઓ — કક્ષકોની સંખ્યા (Number of Orbitals): કુલ કક્ષકો = n² ; l માટે કક્ષકો = 2l + 1
n = મુખ્ય ક્વોન્ટમ સંખ્યા, l = સહાંશિક ક્વોન્ટમ સંખ્યા (Azimuthal quantum number) · SI: અપરિમાણ · એક કક્ષા કે ઉપકક્ષામાં રહેલી કક્ષકોની સંખ્યા શોધવા
ઇલેક્ટ્રોનની મહત્તમ સંખ્યા (Maximum Electrons in Shell/Subshell): કક્ષામાં મહત્તમ ઇલેક્ટ્રોન = 2n² ; ઉપકક્ષામાં = 4l + 2
n = મુખ્ય ક્વોન્ટમ સંખ્યા, l = સહાંશિક ક્વોન્ટમ સંખ્યા · SI: અપરિમાણ · કોઈ પણ કક્ષા અથવા ઉપકક્ષામાં ઇલેક્ટ્રોનની મહત્તમ ધારણા
બોરનો આંહ્ટમની ગતિકોણ સંદર્ભ (Bohr's Angular Momentum Quantisation): L = n · h/(2π) અથવા L = nℏ
L = કોણીય વેગમાન (kg·m²/s), n = પૂર્ણાંક (1, 2, 3,...), h = પ્લાન્ક અચળાંક · SI: J·s અથવા kg·m²/s · હાઇડ્રોજન પરમાણુમાં ઇલેક્ટ્રોનની સ્થિર કક્ષાઓ માટે
ડી બ્રોગ્લી તરંગલંબાઈ (De Broglie Wavelength): λ = h/(mv) અથવા λ = h/p
λ = તરંગલંબાઈ (m), h = પ્લાન્ક અચળાંક, m = દળ (kg), v = વેગ (m/s), p = વેગમાન · SI: m · કોઈ પણ ગતિશીલ કણ (ઇલેક્ટ્રોન, પ્રોટોન વગેરે) માટે
હાઈઝનબર્ગ નિશ્ચયહીનતા સિદ્ધાંત (Heisenberg Uncertainty Principle): Δx × Δp ≥ h/(4π)
Δx = સ્થાનમાં અનિશ્ચિતતા (m), Δp = વેગમાનમાં અનિશ્ચિતતા (kg·m/s), h = પ્લાન્ક અચળાંક · SI: J·s (right side નું એકમ) · ઇલેક્ટ્રોન જેવા સૂક્ષ્મ કણોની ચોકસાઈપૂર્વક ગણતરી માટે
હાઈઝનબર્ગ — ઇલેક્ટ્રોન માટે રૂપ: Δx × m·Δv ≥ h/(4π)
Δx = સ્થાનમાં અનિશ્ચિતતા, m = કણનું દળ, Δv = વેગમાં અનિશ્ચિતતા · SI: SI · જ્યારે તરંગલંબાઈ/વેગ મેળવવો હોય
બોર મોડેલ — હાઇડ્રોજન કક્ષા ત્રિજ્યા (Bohr Radius): r_n = 0.529 × n²/Z Å
r_n = nમી કક્ષાની ત્રિજ્યા (Å), n = મુખ્ય ક્વોન્ટમ સંખ્યા, Z = પરમાણુ ક્રમાંક, 0.529 Å = બોર ત્રિજ્યા (a₀) · SI: m (1 Å = 10⁻¹⁰ m) · હાઇડ્રોજન અથવા હાઇડ્રોજન સમાન આયનો માટે
બોર મોડેલ — ઊર્જા સ્તર (Bohr Energy Level): E_n = −13.6 × Z²/n² eV
E_n = nમી કક્ષાની ઊર્જા (eV), Z = પરમાણુ ક્રમાંક, n = મુખ્ય ક્વોન્ટમ સંખ્યા · SI: eV (1 eV = 1.602 × 10⁻¹⁹ J) · હાઇડ્રોજન-સમાન પરમાણુ/આયન માટે
બોર ઊર્જા — SI એકમમાં: E_n = −2.18 × 10⁻¹⁸ × Z²/n² J
E_n = ઊર્જા (J), Z = પરમાણુ ક્રમાંક, n = મુખ્ય ક્વોન્ટમ સંખ્યા · SI: J · SI એકમમાં હાઇડ્રોજન-સમાન પરમાણુની ઊર્જા
સ્પેક્ટ્રલ રેખાનું આવર્તન / ઉત્સર્જન ઊર્જા: ΔE = E₂ − E₁ = hν અથવા 1/λ = R_H × Z²(1/n₁² − 1/n₂²)
R_H = રીડબર્ગ અચળાંક (1.097 × 10⁷ m⁻¹), n₁ < n₂, Z = પરમાણુ ક્રમાંક, λ = તરંગલંબાઈ · SI: m⁻¹ (1/λ માટે) · સ્પેક્ટ્રમની તરંગલંબાઈ અથવા આવર્તન શોધવા
રિડબર્ગ સૂત્ર (Rydberg Formula): 1/λ = R_H × Z² (1/n_f² − 1/n_i²)
R_H = 1.097 × 10⁷ m⁻¹, n_f = અંતિમ કક્ષા, n_i = પ્રારંભિક કક્ષા · SI: m⁻¹ · હાઇડ્રોજન સ્પેક્ટ્રમની તરંગલંબાઈ ગણતરી
લૅર್ಮર ફ્રીક્વન્સી / કક્ષીય ચુંબકીય ક્ષેત્ર: μ_l = √[l(l+1)] × eħ/(2m) અથવા μ_l = √[l(l+1)] × μ_B
μ_l = કક્ષીય ચુંબકીય ચાકમાત્રા, l = સહાંશિક ક્વોન્ટમ સંખ્યા, μ_B = બોર મેગ્નેટોન (9.274 × 10⁻²⁴ J/T) · SI: J/T (A·m²) · ઇલેક્ટ્રોનના કક્ષીય ચુંબકીય ચાકમાત્રા માટે
ઇલેક્ટ્રોન ચુંબકીય ચાકમાત્રા (Spin Magnetic Moment): μ_s = √[s(s+1)] × 2μ_B ; સિંગલ ઇલેક્ટ્રોન: μ_s = √3 μ_B
s = સ્પિન ક્વોન્ટમ સંખ્યા (1/2), μ_B = બોર મેગ્નેટોન · SI: J/T · ઇલેક્ટ્રોનના સ્પિનથી ઉત્પન્ન થતી ચુંબકીય ચાકમાત્રા
ચુંબકીય ક્ષેત્રમાં ઊર્જા (Zeeman Interaction): E = −μ·B = m_l × μ_B × B
m_l = ચુંબકીય ક્વોન્ટમ સંખ્યા (−l થી +l), μ_B = બોર મેગ્નેટોન, B = ચુંબકીય ક્ષેત્ર (T) · SI: J · બાહ્ય ચુંબકીય ક્ષેત્રમાં ઇલેક્ટ્રોનની ઊર્જા
મૌલિચ સંભવિત ઊર્જા (Massey Parameter / Uncorrelated): N = n(N_max) અથવા ગેટનર નિયમ: 4l + 2
N = ઉપકક્ષામાં ઇલેક્ટ્રોન સંખ્યા, l = સહાંશિક ક્વોન્ટમ સંખ્યા · SI: અપરિમાણ · ઉપકક્ષામાં મહત્તમ ઇલેક્ટ્રોન
કક્ષકની ઊર્જા — હાઇડ્રોજન-સમાન (Energy of Orbital): E = −Z² × 13.6/n² eV અથવા E ∝ −Z²/n²
Z = પરમાણુ ક્રમાંક, n = મુખ્ય ક્વોન્ટમ સંખ્યા · SI: eV · એક-ઇલેક્ટ્રોન પ્રણાલી માટે
કક્ષકમાં ઇલેક્ટ્રોનની સંખ્યા — સૂત્ર: K કક્ષા: 2, L: 8, M: 18, N: 32, O: 32, ... → 2n²
n = કક્ષાની સંખ્યા (K=1, L=2, M=3, N=4, O=5) · SI: અપરિમાણ · વિદ્યાર્થીઓને યાદ રાખવા માટેનું સૂત્ર
ઉપકક્ષા ઇલેક્ટ્રોન ધારણા: s: 2, p: 6, d: 10, f: 14 (સૂત્ર: 4l+2)
l = 0(s), 1(p), 2(d), 3(f) · SI: અપરિમાણ · દરેક ઉપકક્ષામાં મહત્તમ ઇલેક્ટ્રોન
નિષ્ક્રિયતા સિદ્ધાંત — મેડલેફ ક્વોન્ટમ સંબંધ: √ν = a(Z − b)
ν = X-射线 આવર્તન, Z = પરમાણુ ક્રમાંક, a, b અચળાંકો · SI: Hz · Moseley's law for characteristic X-rays

🔗 સંબંધો

  • કુલ ક્વોન્ટમ સંખ્યા (n) વધે તેમ ઊર્જા વધે (ઓછી ઋણ) અને કક્ષાનું કદ વધે.
  • l (સહાંશિક ક્વોન્ટમ સંખ્યા) n−1 સુધીનો મૂલ્ય લઈ શકે છે; દરેક l માટે 2l+1 કક્ષકો.
  • m_l (−l થી +l) કક્ષકની દિશા/અવકાશીય વેતન દર્શાવે છે.
  • m_s (+½ અથવા −½) માત્ર બે સંભવિત મૂલ્યો ધરાવે છે.
  • E_n ∝ −Z²/n²; Z વધે તેમ ઊર્જા વધુ ઋણ (બંધનબલ વધારે).
  • r_n ∝ n²/Z; n વધે તેમ ત્રિજ્યા ચોરસના પ્રમાણમાં વધે.
  • Rydberg સૂત્રમાં n_f = 1 (Lyman), n_f = 2 (Balmer), n_f = 3 (Paschen), n_f = 4 (Brackett), n_f = 5 (Pfund).
  • હાઈઝનબર્ગ મુજબ સ્થાન વધુ ચોકસાઈપૂર્વક માપીએ તો વેગમાં અનિશ્ચિતતા વધે છે.
  • બોર મોડેલમાં ઇલેક્ટ્રોન ત્યારે જ ઉર્જા શોષે/ઉત્સર્જિત કરે છે જ્યારે તે એક સ્થિર કક્ષા પરથી બીજીમાં સંક્રમણ કરે.
  • ΔE = hν સંબંધ દર્શાવે છે કે ઉત્સર્જિત/શોષિત ફોટોનની ઊર્જા રેખાના આવર્તનના સમપ્રમાણ છે.
  • ડી બ્રોગ્લી સંબંધ λ = h/mv માટે, વેગમાન v વધે તો તરંગલંબાઈ ઘટે છે.
  • કુલ ક્વોન્ટમ સંખ્યા n = 1,2,3...; n દરેક મૂલ્ય માટે l = 0 થી n−1 સુધી મૂલ્યો લે છે.

🎯 ટ્રિક્સ

કક્ષકની કુલ સંખ્યા = n² — યાદ રાખવા: n=1→1, n=2→4, n=3→9, n=4→16.
દરેક કક્ષામાં ઇલેક્ટ્રોન સંખ્યા 2n²: n=1→2, n=2→8, n=3→18, n=4→32.
ΔE = hν સૂત્રમાં ν અને λ વ્યસ્ત પ્રમાણમાં છે; તેથી ΔE = hc/λ લખી શકાય.
હાઈડ્રોજન (Z=1) માટે E_n = −13.6/n² eV; Z≠1 હોય તો Z² વડે ગુણો.
ડી બ્રોગ્લી: λ = h/mv માટે ઇલેક્ટ્રોનનો v ≈ c (પ્રકાશનો વેગ) હોય તો λ ≈ h/mc.
l(n) = l_max માટે જરૂરી n = l+1 (ઉદા: d ઉપકક્ષા (l=2) માટે ન્યૂનતમ n=3).
કક્ષકમાં ઇલેક્ટ્રોન 2(2l+1) = 4l+2; s→2, p→6, d→10, f→14 (ક્રમ: 2,6,10,14).
બોર ત્રિજ્યા: r₁ (n=1) = 0.529 Å; r_n = r₁ × n² (સીધો ગુણોત્તર).

⚠️ ભૂલો

E = hν માં ν ને ભૂલથી તરંગલંબાઈ (λ) વડે બદલી દેવું. યાદ રાખો: ν = c/λ.
બોર ઊર્જા સૂત્ર E_n = −13.6Z²/n² eV માં ઋણ ચિહ્ન વિસરતા ઊર્જાની દિશા ખોટી ગણવા (ઊર્જા ઋણ છે = બંધન).
લક્ષ્ય (Z) શૂન્ય લેવું — હાઇડ્રોજન માટે Z=1 છે, શૂન્ય નહીં.
Δx × Δp ≥ h/(4π) માં h/(2π) લખી દેવું. સાચું મૂલ્ય h/(4π) છે.
ક્વોન્ટમ સંખ્યાઓના મૂલ્યો મર્યાદા વિસરવી: l < n હંમેશા, m_l માટે −l ≤ m_l ≤ +l.
n=3 માટે d ઉપકક્ષા (l=2) શક્ય છે; n=2 માટે d શક્ય નથી — l_max = n−1.
