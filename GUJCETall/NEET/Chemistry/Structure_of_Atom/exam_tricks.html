GUJCET — રચના અણુ (Structure of Atom) એક્ઝામ ટ્રિક્સ

🎯 પરીક્ષા ટ્રિક્સ

ઇલેક્ટ્રોનનું e/m અનુપાત (ચાર્જ-ટૂ-માસ રેશિયો) યાદ રાખો: 1.76 × 10¹¹ C/kg. આ કિંમત પ્રોટોનના e/m (9.6 × 10⁷ C/kg) કરતા લગભગ 1836 ગણી મોટી છે.
જ્યારે પ્રશ્નમાં થોમસનના પ્રયોગ અથવા વિદ્યુતચુંબकीય ક્ષેત્રમાં કણની વળાંક વિશે પૂછાય કે જે કણ વધુ વળે છે તે નક્કી કરવો હોય.
દા.ત.: α-કણ અને e⁻ બંને સમાન વેગથી ચુંબકીય ક્ષેત્રમાં પ્રવેશે. વધુ વળનારો કણ કયો? → ઇલેક્ટ્રોન (e/m વધુ હોવાથી).
ક્વોન્ટમ અંકોનો ક્રમ યાદ રાખો: n > l > |m| ≥ 0 અને s = +½ કે –½. આ સિદ્ધાંત સાથેની સાથે જો કોઈ ઓર્બિટલનો ઉલ્લેખ હોય તો તરત ચકાસી શકાય.
જ્યારે કોઈ ચોક્કસ ઇલેક્ટ્રોન માટે ચારેય ક્વોન્ટમ અંકોની યોગ્યતા ચકાસવાનો પ્રશ્ન આવે અથવા ખોટું જોડણું ગોલ્ડન ઓપ્શન હોય.
દા.ત.: આપેલ n=3, l=3, m=0, s=+½ — l નું મૂલ્ય n કરતા વધુ છે, તેથી અશક્ય. (l ના મૂલ્યો 0 થી n–1 સુધી જ શક્ય છે.)
કક્ષકનું આકૃતિ (સબશેલનું રૂપ) l ના મૂલ્ય પરથી સીધું નક્કી થાય: l=0 → s (ગોળાકાર), l=1 → p (ડમ્બેલ), l=2 → d (પંચહલી). પ્રશ્નમાં કક્ષકનું રૂપ પૂછાય તો l=નું મૂલ્ય જોઈ લો.
જ્યારે પ્રશ્નમાં કહેવાય 'l=2 માટેની કક્ષકનું રૂપ' અથવા કોઈ કક્ષકનું l મૂલ્ય શોધવું હોય.
દા.ત.: 3d કક્ષકમાં l=? → d સબશેલ છે, તેથી l=2. 4p માટે l=1.
ઓર્બિટલના નોડ્સની કુલ સંખ્યા = n – 1. ત્રિજ્યીય (radial) નોડ્સ = n – l – 1. કોણીય (angular) નોડ્સ = l. આ ત્રણેય સૂત્રો યાદ રાખો — પ્રશ્નમાં તરત વાપરી શકાય.
જ્યારે 2p, 3d, 4s જેવી કક્ષકના નોડ્સની સંખ્યા પૂછાય કે કુલ/ત્રિજ્યીય/કોણીય નોડ્સમાં કોઈ તફાવત માંગવામાં આવે.
દા.ત.: 3d કક્ષકના ત્રિજ્યીય નોડ્સ = 3 – 2 – 1 = 0; કોણીય નોડ્સ = 2; કુલ નોડ્સ = 3 – 1 = 2.
બોહરના મોડેલમાં ઇલેક્ટ્રોનના કક્ષકમાં ગતિશક્તિ અને સ્થિતિશક્તિનો સંબંધ: KE = –½ PE, કુલ ઊર્જા E = –KE = ½ PE. આ કાયદો હાઇડ્રોજન/હાઇડ્રોજન-સદૃશ પરમાણુ માટે તરત લાગુ પડે.
જ્યારે કક્ષામાં ઇલેક્ટ્રોનની કુલ ઊર્જા, ગતિજ ઊર્જા અથવા સ્થિતિજ ઊર્જા વચ્ચેનો સંબંધ માંગવામાં આવે.
દા.ત.: નાઇટ્રોજન આયન (He⁺) ની n=2 કક્ષાની કુલ ઊર્જા = –54.4 eV. ગતિજ ઊર્જા = 54.4 eV, સ્થિતિજ ઊર્જા = –108.8 eV.
હેસના બહુપદી સૂત્ર (Hund's rule) યાદ રાખો: સમાન ઊર્જા ધરાવતી કક્ષકોમાં ઇલેક્ટ્રોન અલગ અલગ કક્ષકોમાં સમાન સ્પિન સાથે ભરાય, પછી જોડાય. p, d, f માટે 'અનપેર્ડ' (એકલા) ઇલેક્ટ્રોનની સંખ્યા સીધી ગણી શકાય.
જ્યારે અયુગ્મિત (unpaired) ઇલેક્ટ્રોનની સંખ્યા અથવા ચુંબકીય આઘૂર્ણ (magnetic moment) μ = √[n(n+2)] B.M. શોધવાનું હોય.
દા.ત.: Cr (Z=24): [Ar] 4s¹ 3d⁵ — અયુગ્મિત ઇલેક્ટ્રોન = 6; μ = √(6×8) = √48 ≈ 6.93 B.M.
AUFBAU નિયમ મુજબ ઓર્બિટલ ભરાવના ક્રમનો ડાયગ્રામ: 1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f... ઊર્ધ્વ દિશામાં ત્રાંસી રેખા ઇન્ડેક્સ તરીકે વાપરો — શીઘ્ર ભૂલ ન થાય.
ઇલેક્ટ્રોનિક વિન્યાસ લખવાના પ્રશ્નમાં, ખાસ કરીને 4s vs 3d, 5s vs 4d જેવા વિવાદાસ્પદ ક્રમમાં ગૂંચવણ થાય.
દા.ત.: Fe (Z=26): 1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d⁶ — 4s પહેલાં ભરાય છે, ભલે લખતી વખતે 3d પહેલાં લખવું સરળ લાગે.
ચુંબકીય ક્વોન્ટમ અંક mₗ ના શક્ય મૂલ્યો: –l થી +l સુધી, કુલ (2l + 1) મૂલ્યો. દરેક mₗ મૂલ્ય એક કક્ષક દર્શાવે છે. p-સબશેલમાં 3, d-માં 5, f-માં 7 કક્ષકો — યાદ રાખો: 2l+1.
જ્યારે પ્રશ્નમાં એક સબશેલમાં કેટલી કક્ષકો છે અથવા mₗ ના કેટલા મૂલ્યો શક્ય છે તે પૂછવામાં આવે.
દા.ત.: 4f સબશેલ માટે l=3 → kક્ષકો = 2×3+1 = 7; mₗ ના મૂલ્યો: –3, –2, –1, 0, +1, +2, +3.
ડી બ્રોગ્લી સંબંધ: λ = h/mv = h/p. ઇલેક્ટ્રોનને V વોલ્ટથી પ્રવેગિત કરતાં, KE = eV = ½mv² → v = √(2eV/m) → λ = h/√(2meV). આ સૂત્ર યાદ રાખો (λ ∝ 1/√V).
જ્યારે પ્રવેગિત વિદ્યુતભારિત કણની de Broglie તરંગલંબાઇ V વોલ્ટમાં આપેલ હોય.
દા.ત.: 100 V થી પ્રવેગિત ઇલેક્ટ્રોનની λ = h/√(2me×100). ઇલેક્ટ્રોન માટે λ ≈ 1.227/√V nm (અંદાજિત), તેથી λ ≈ 0.1227 nm.
ચોમેલન (Chemical equivalent) / આયતન નિયમના સિદ્ધાંત મુજબ રુથરફોર્ડના પ્રયોગનો 1/4πϵ₀ ફેક્ટર: રુથરફોર્ડના વિખેરવાના સૂત્રમાં α-કણનો ન્યૂનતમ અંતર d = (1/4πϵ₀) × (2Ze²)/(KE). Z વધે તો d ઘટે.
જ્યારે α-કણનું ન્યૂનતમ અંતર અથવા પરમાણુ કેન્દ્રના કદનો અંદાજ કરવો હોય.
દા.ત.: Au (Z=79) કરતાં Al (Z=13) માટે α-કણનું ન્યૂનતમ અંતર ~6 ગણું વધુ હશે — તેથી H-foilમાં મોટા ખૂણે વિચલન દુર્લભ.
પ્લાન્કનું સૂત્ર E = hν = hc/λ. h = 6.626 × 10⁻³⁴ J·s, c = 3 × 10⁸ m/s. hc ≈ 1240 eV·nm (યાદ રાખો — ઝડપી ગણતરી માટે ઉપયોગી).
ફોટોનની ઊર્જા ગણતરી કરવી હોય, ખાસ કરીને પ્રકાશીય/અલ્ટ્રાવાયોલેટ પ્રદેશમાં λ આપેલ હોય.
દા.ત.: 400 nm પ્રકાશની ફોટોન ઊર્જા ≈ 1240/400 = 3.1 eV. આ મૂલ્ય સાથે ફોટોઇલેક્ટ્રિક ક્રિયાનો ક્ષય પotaંશ શોધી શકાય.
હેસના બહુપદી સૂત્ર (Aufbau) ની બે મુખ્ય અપવાદયુક્ત બનાવટો: Cr (Z=24) → [Ar]4s¹3d⁵, Cu (Z=29) → [Ar]4s¹3d¹⁰. અર્ધ-ભરેલી અને પૂર્ણ ભરેલી d-સબશેલ સ્થિર હોય છે.
ઇલેક્ટ્રોનિક વિન્યાસ લખતી વખતે Cr અને Cu ના કિસ્સામાં ગૂંચવણ ન થાય અને ઝડપથી સાચો વિન્યાસ લખી શકાય.
દા.ત.: Cu⁺ આયન: [Ar]3d¹⁰ (4s¹ એલિમિનેટ થાય). Cu²⁺: [Ar]3d⁹. યાદ રાખો — પ્રથમ 4s નીકળે, પછી 3d.
બોહર મોડેલ માત્ર હાઇડ્રોજન-સદૃશ (એક-ઇલેક્ટ્રોન) પ્રજાતિઓ માટે લાગુ પડે: H, He⁺, Li²⁺, Be³⁺. બહુ-ઇલેક્ટ્રોન પ્રણાલીઓમાં તે નિષ્ફળ જાય — આ હકીકત ધ્યાનમાં રાખો.
જ્યારે પ્રશ્નમાં બોહર મોડેલની મર્યાદા અથવા તેના લાગુ પડવા વિશે પૂછાય.
દા.ત.: Li²⁺ માટે રુબર સ્થિરાંક R = RH × Z² = RH × 9. Li²⁺ ની n=2 → n=1 સંક્રમણની તરંગલંબાઇ H ની તુલનામાં 9/36 = 1/4 ગણી હશે (ઝડપી ગણતરી).
આઇસોટોપ અને આઇસોબાર વચ્ચેનો તફાવત: આઇસોટોપ = સમાન Z (પ્રોટોન), વિભિન્ન A; આઇસોબાર = સમાન A, વિભિન્ન Z. પ્રશ્નમાં 'સમાન પ્રોટોન' એટલે આઇસોટોપ, 'સમાન ન્યુક્લિયોન' એટલે આઇસોબાર.
જ્યારે આઇસોટોપ/આઇસોબાર/આઇઝોટોન (સમાન N) વચ્ચેનો તફાવત ચિહ્નિત કરવાનો હોય.
દા.ત.: ⁴⁰Ar (Z=18, N=22), ⁴⁰K (Z=19, N=21), ⁴⁰Ca (Z=20, N=20) — બધા આઇસોબાર. ³⁵Cl અને ³⁷Cl આઇસોટોપ છે.
હેસનો ઊર્જા-ક્વોન્ટમ સંબંધ: ઇલેક્ટ્રોન n=1 → n=3 માં સંક્રમણ કરે તો શોષાતી ઊર્જા = E₃ – E₁. હાઇડ્રોજન માટે Eₙ = –13.6/n² eV. ઝડપી ગણતરી: E₁ = –13.6, E₃ = –1.51, તફાવત ≈ 12.09 eV.
સંક્રમણ ઊર્જા શોધવાની જરૂર પડે, લાંબી ગણતરી કરવાને બદલે સૂત્રનો સીધો ઉપયોગ.
દા.ત.: હાઇડ્રોજન પરમાણુમાં n=1 → n=4: E₄ = –13.6/16 = –0.85 eV. ઊર્જા = –0.85 – (–13.6) = 12.75 eV. Lyman શ્રેણીનો ફોટોન.
