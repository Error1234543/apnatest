પરમાણુ રચના — ઝડપી સમીક્ષા

🧪 GUJCET — Gujarati • Chemistry • Structure of Atom

📘 વ્યાખ્યાઓ

  • આવર્ત સંખ્યા (Atomic Number, Z): પરમાણુકેન્દ્રમાં રહેલા પ્રોટોનની સંખ્યા.
  • દળ સંખ્યા (Mass Number, A): કેન્દ્રમાં રહેલા પ્રોટોન અને ન્યુટ્રોનના સરવાળાને દળ સંખ્યા કહે છે.
  • આઇસોટોપ (Isotope): સમાન Z પરંતુ ભિન્ન A ધરાવતા પરમાણુઓ.
  • આઇસોબાર (Isobar): સમાન A પરંતુ ભિન્ન Z ધરાવતા પરમાણુઓ.
  • આઇસોટોન (Isotone): ભિન્ન Z અને A પરંતુ સમાન ન્યુટ્રોન સંખ્યા ધરાવતા પરમાણુઓ.
  • ફોટોન (Photon): વિद्यુતચુંબકીય વિકિરણનો એકમ ક્વોન્ટમ; શૂન્ય આરામ દળ ધરાવે છે.
  • તરંગલંબાઇ (Wavelength, λ): તરંગના બે ક્રમિક શૃંગ વચ્ચેનું અંતર.
  • આવૃત્તિ (Frequency, ν): એક સેકન્ડમાં કોઇ મુદ્રા પરથી પસાર થતા તરંગચಕ್રોની સંખ્યા.
  • ક્વોન્ટમ અંક (Quantum Number): ઇલેક્ટ્રોનની શક્તિસ્તર, કક્ષકનો આકાર અને દિશા નક્કી કરતા ચલ.
  • કક્ષક (Orbital): તે આકાશી પ્રદેશ જ્યાં ઇલેક્ટ્રોન મળી આવવાની સંભાવના સર્વાધિક હોય છે.
  • પોટેન્શિયલ ઊર્જા: બે વિદ્યુતભારિત કણો વચ્ચેના આકર્ષણ/વિકર્ષણથી ઉત્પન્ન થતી ઊર્જા.

⚡ સૂત્રો

  • c = νλ (પ્રકાશની ઝડપ = આવૃત્તિ × તરંગલંબાઇ), c = 3×10⁸ m/s.
  • E = hν = hc/λ (ફોટોનની ઊર્જા), h = 6.626×10⁻³⁴ J·s.
  • nλ = 2πr (બોહરનો કક્ષકનો વેગવિધિ સંકલ્પનાનો સંબંધ).
  • KE = ½mv², p = mv, де Broglie: λ = h/mv = h/p.
  • Δx · Δp ≥ h/4π (હાઇઝનબર્ગનું અનિશ્ચિતતા સિદ્ધાંત).
  • l = 0, 1, 2, … (n−1) (કોણીય વેગવિધિ ક્વોન્ટમ અંકની મર્યાદા).
  • mₗ = −l, …, 0, …, +l (ચુંબકીય ક્વોન્ટમ અંકની વિસ્તૃતિ).
  • mₛ = +½ અથવા −½ (સ્પિન ક્વોન્ટમ અંકના માત્ર બે મૂલ્યો).
  • કક્ષકોમાં મહત્તમ ઇલેક્ટ્રોન = 2n² (n-મા શક્તિસ્તરમાં).
  • subshell capacity: s=2, p=6, d=10, f=14 ઇલેક્ટ્રોન.
  • n+l નિયમ: અલ્પ n+l ધરાવતી કક્ષક પહેલા ભરાય; સમાન n+l હોય તો અલ્પ n પહેલા.

⭐ મુખ્ય તથ્યો

  • ઇલેક્ટ્રોનની શોધ J.J. થોમસને 1897માં કેથોડ કિરણ પ્રયોગથી કરી.
  • પ્રોટોનની શોધ ગોલ્ડસ્ટાઈન અને રૂથરફોર્ડએ એનોકિરણ પ્રયોગ દ્વારા કરી.
  • ન્યુટ્રોનની શોધ ચેડવિકે 1932માં કરી.
  • થોમસન મોડલને 'પ્લમ પુડિંગ' મોડલ પણ કહેવાય છે.
  • રૂથરફોર્ડના અल्ફા-કણ વિખેરવાના પ્રયોગમાં મોટાભાગના કણો સીધા પસાર થયા → ખાલી જગ્યા的存在 સિદ્ધ.
  • રૂથરફોર્ડ મોડલની મુખ્ય મર્યાદા: પ્રવેગિત વિદ્યુતભાર ઊર્જા ઉત્સર્જિત કરે, તેથી ઇલેક્ટ્રોન કેન્દ્રમાં પડી જાય એવું.
  • બોહર મોડલ માત્ર હાઈડ્રોજન-સમાન (એક-ઇલેક્ટ્રોન) પ્રણાલીઓને સફળતાપૂર્વક સમજાવે છે.
  • બોહરની શક્તિનું સૂત્ર: Eₙ = −2.18×10⁻¹⁸ (Z²/n²) J અથવા −13.6 (Z²/n²) eV.
  • ઇલેક્ટ્રોન જ્યારે ઉચ્ચ શક્તિસ્તરમાંથી નીચે આવે છે ત્યારે ફોટોન ઉત્સર્જિત થાય છે; શોષણ થાય ત્યારે ઉચ્ચ સ્તરે જાય છે.
  • s-કક્ષક ગોળાકાર, p-કક્ષક દ્વિદલીય (dumbbell), d-કક્ષક જટિલ આકાર ધરાવે છે.
  • Aufbau સિદ્ધાંત મુજબ કક્ષક ભરાનું ક્રમ: 1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p…
  • પાઉલીનો વર્જન સિદ્ધાંત: ekasii કક્ષકમાં મહત્તમ 2 ઇલેક્ટ્રોન અને તેમનું સ્પિન વિરુદ્ધ હોવું જોઈએ.
  • હુન્ડનો નિયમ: સમાન ઊર્જા ધરાવતી કક્ષકોમાં ઇલેક્ટ્રોન સર્વપ્રથમ એક-એક કરીને ભરાય છે.
  • અર્ધ-ભરેલી ( Half-filled ) અને પૂરેપૂરી ભરેલી ( Fully-filled ) उपshell સ્થિર હોય છે; ક્રોમિયમ (Z=24) અને તાंबेर (Z=29) આનો સ્પષ્ટ ઉદાહરણ છે.
  • Cr(24) ની રચના: [Ar] 3d⁵ 4s¹; Cu(29) ની રચના: [Ar] 3d¹⁰ 4s¹ (અસामान्य).
  • vd Broglie તરંગ-કણ દ્વૈતતા: દરેક ગતિશીલ કણ સાથે તરંગ લક્ષણ જોડાયેલું છે.
  • Electromagnetic spectrum ક્રમ (અલ્પ આવૃત્તિથી ઉચ્ચ): રેડિયો → માઇક્રો → Infrared → દ્રશ્ય → UV → X-ray → Gamma.
  • Planckના ક્વોન્ટમ સિદ્ધાંત મુજબ: ઊર્જા સતત નહીં, પણક્વોન્ટા/પૌડામાં મળે છે.

⚠️ સામાન્ય ભૂલો

  • રૂથરફોર્ડ મોડલ હાઈડ્રોજનના રેખા स्पेक्ट्रમને સમજાવી શક્યું નહીં; તે બોહરનું મોડલ છે જે સમજાવે છે.
  • n+l નિયમમાં 4s (n+l=4) એ 3d (n+l=5) કરતાં અલ્પ છે, તેથી 4s પહેલા ભરાય છે — આ બહુવિધ વિકલ્પોમાં ફસાણ છે.
  • આઇસોટોપ રાસાયણિક ગુણધર્મ સમાન રાખે છે કારણ કે ઇલેક્ટ્રોન રચના સમાન હોય છે.
  • mₗ અને mₛ બંને 'ક્વોન્ટમ અંક' છે; mₗ ત્રિજ્યાવર્તી દિશા/આકારની, mₛ ઇલેક્ટ્રોન સ્પિન દર્શાવે છે.
  • E = hν સમીકરણમાં ν (ઓमेगा નહીં) આવૃત્તિ છે; E એ joules માં મળે, eV માં નહીં જ્યાં સુધી રૂપાંતર ન કરવું.
  • Δx·Δp ≥ h/4π માં h/4π છે, h/2π નહીં — આ યાદ રાખવું મહત્વનું છે.
  • કક્ષક (Orbital) અને કક્ષા (Orbit) વચ્ચેનો તફાવત: કક્ષા નિશ્ચિત પથ છે (ભૂલપૂર્વક), કક્ષક સંભાવના પ્રદેશ છે.
  • d-ઉપકક્ષકમાં 5 કક્ષકો હોય છે, f-ઉપકક્ષકમાં 7 કક્ષકો હોય છે — દરેકમાં 2 ઇલેક્ટ્રોન, કુલ 10 અને 14.
  • n+l સમાન હોય ત્યારે ઓછી n ધરાવતી કક્ષક પહેલા ભરાય — આ ચડતું-ઉતરતું બંને વખતે પરખવું જરૂરી છે.
  • ઇલેક્ટ્રોનનો દળ 9.109×10⁻³¹ kg છે; પ્રોટોનનો દળ 1.672×10⁻²⁷ kg — પ્રોટોન ≈ 1836 × ઇલેક્ટ્રોન દળ.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • બોહરના બે મુખ્ય સિદ્ધાંત: (1) ઇલેક્ટ્રોન નિશ્ચિત કક્ષામાં સ્થિર ઊર્જા સાથે ફરે છે, (2) angular momentumનું ક્વોન્ટાઈઝેશન mvr = nh/2π.
  • spectral line શોષણ/ઉત્સર્જન: ΔE = E₂ − E₁ = hν = hc/λ.
  • ક્રોમિયમ અને તાंबेरની anomalous configuration જોડી GUJCET માં સામાન્ય છે.
  • જ્યારે ઇલેક્ટ્રોન n=3 માંથી n=2 માં આવે ત્યારે Balmer શ્રેણી; n=2 માંથી n=1 માં આવે ત્યારે Lyman શ્રેણી.
  • s-કક્ષક માટે l=0, mₗ=0, એક જ કક્ષક; p-કક્ષક માટે l=1, mₗ=−1,0,+1, ત્રણ કક્ષકો.
  • હાઇડ્રોજન પરમાણુની E₁ = −13.6 eV, E₂ = −3.4 eV, E₃ = −1.51 eV (યાદ રાખવાની આવશ્યક).
  • de Broglie લંબાઇ λ = h/mv → ઇલેક્ટ્રોનનો v વધે તો λ ઘટે છે (વ્યસ્ત સંબંધ).
  • Heisenberg અનિશ્ચિતતા: જો Δx ખૂબ ઓછું હોય (જેમ કે કેન્દ્રનાં નજીક) તો Δp ખૂબ મોટું હોય છે.
  • Hund નો નિયમ: C(6) = 1s² 2s² 2p² → 2p માં બંને ઇલેક્ટ્રોન અલગ કક્ષકમાં સમાન સ્પિન સાથે રહે.
  • કુલ ઇલેક્ટ્રોન સંખ્યા = Z (તટસ્થ પરમાણુ માટે); આયન માટે ઇલેક્ટ્રોન = Z ± charge.
  • Electron configuration ટૂંકમાં લખવા Noble gas notation વાપરો: Na = [Ne] 3s¹.
  • Bohr vs Rutherford: Bohr ne stationary orbits અને quantized energy દર્શાવી; Rutherford ne keval nuclear existence સાબિત કરી.
