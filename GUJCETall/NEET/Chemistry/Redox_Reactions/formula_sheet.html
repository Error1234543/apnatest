રિડોક્સ પ્રક્રિયાઓ – સૂત્ર શીટ

🧪 GUJCET — Gujarati • Chemistry • Redox Reactions

⚡ સૂત્રો

ચાર્જ-સમતુલ્ય સંબંધ: Q = n × F
Q = વીજભાર (કુલંબ), n = મોલમાં ઇલેક્ટ્રોનની સંખ્યા, F = ફેરાડે અચળાંક ≈ 96500 C mol⁻¹ · SI: C (કુલંબ) · જ્યારે રિડોક્સ પ્રક્રિયા દરમિયાન n મોલ ઇલેક્ટ્રોનનો આદાન-પ્રદાન થાય
દેહરાઇઝશન સંભાવ્ય (Oxidation Potential): E°_ox = – E°_red
E°_ox = પ્રમાણભૂત ઓક્સિડેશન સંભાવ્ય, E°_red = પ્રમાણભૂત રિડક્શન સંભાવ્ય · SI: V (વોલ્ટ) · જ્યારે કોઈ અર્ધ-કોષને ઓક્સિડેશન તરીકે લખવો હોય
કોષ સંભાવ્ય (Cell EMF): E°_cell = E°_cathode – E°_anode
E°_cell = પ્રમાણભૂત કોષ સંભાવ્ય, E°_cathode = કાથોડનું રિડક્શન સંભાવ્ય, E°_anode = એનોડનું રિડક્શન સંભાવ્ય · SI: V (વોલ્ટ) · પ્રમાણભૂત પરિસ્થિતિઓમાં ગેલ્વેનિક કોષના EMF ની ગણતરી માટે
ગિબ્સ મુક્ત ઊર્જા – કોષ સંભાવ્ય સંબંધ: ΔG° = –nFE°_cell
ΔG° = પ્રમાણભૂત ગિબ્સ મુક્ત ઊર્જા ફેરફાર, n = બદલાતા ઇલેક્ટ્રોનના મોલ, F = ફેરાડે અચળાંક, E°_cell = પ્રમાણભૂત કોષ સંભાવ્ય · SI: J (જૂલ) · રિડોક્સ પ્રક્રિયાની સ્વયંસ્ફુરિતતા ચકાસવા માટે; ΔG° < 0 હોય તો પ્રક્રિયા સ્વયંસ્ફુરિત
સંતુલન અચળાંક – કોષ સંભાવ્ય સંબંધ: log K = (n E°_cell) / 0.0591
K = સંતુલન અચળાંક, n = ઇલેક્ટ્રોનના મોલની સંખ્યા, E°_cell = પ્રમાણભૂત કોષ સંભાવ્ય · SI: અપ્રભાવી (logarithmic relation) · 298 K તાપમાને; E°_cell વોલ્ટમાં હોય ત્યારે
ઓક્સિડેશન અંક નક્કી કરવાનો સૂત્ર (મૂળભૂત નિયમ): એકત્વિયાતા વાળા અણુ/આયન માટે: ઑક્સિજન = –2, H = +1, F = –1, Alkaline metal (Group 1) = +1, Alkaline earth metal (Group 2) = +2; બધા પરમાણુઓના ઓક્સિડેશન અંકનો સરવાળો = આયનનો ભાર
ઓક્સિડેશન અંક = કાલ્પનિક ભાર જે પરમાણુને અલગ પાડતાં મળે · SI: અપ્રભાવી (સંખ્યા) · સંયોજનમાં ઓક્સિડેશન અંક શોધવા માટે; ચોક્કસ પરમાણુના ઓ.અ. ની શોધ માટે બાકીના પરમાણુઓના ઓ.અ. જાણીતા હોય
n-ફેક્ટર (રિડોક્સ માટે): n-factor = એક મોલ પદાર્થ દીઠ આપવામાં અથવા લેવાતા ઇલેક્ટ્રોનના મોલ
n-factor = ઇલેક્ટ્રોન વિનિમયની સંખ્યા પ્રતિ મોલ · SI: અપ્રભાવી · રિડોક્સ પ્રક્રિયામાં પદાર્થનું સમતુલ્યભાર શોધવા માટે
સમતુલ્યભાર (રિડોક્સ): સમતુલ્યભાર = આણ્વિકભાર / n-factor
સમતુલ્યભાર = સદૃશ ભાર જતાં ભાગફળ, આણ્વિકભાર = મોલર ભાર · SI: g eq⁻¹ (ગ્રામ પ્રતિ સમતુલ્ય) · રિડોક્સ ટાઇટ્રેશન અને સમતુલ્યગણનામાં
ઓક્સિડેશન અંક – peroxide માં O: H₂O₂, Na₂O₂, BaO₂ માં O નો ઓ.અ. = –1
–1 એ પરોક્સાઇડ આયન O₂²⁻ માટે લાગુ પડે છે · SI: અપ્રભાવી · જ્યારે ઑક્સિજન peroxide સ્વરૂપે હોય
ઓક્સિડેશન અંક – superoxide માં O: KO₂ માં O નો ઓ.અ. = –½
–½ એ સુપરآوکસાઇડ આયન O₂⁻ માટે લાગુ પડે છે · SI: અપ્રભાવી · જ્યારે ઑક્સિજન superoxide સ્વરૂપે હોય
ઓક્સિડેશન અંક – Fe₃O₄ માં: Fe નો સરેરાશ ઓ.અ. = +8/3
Fe₃O₄ એ FeO · Fe₂O₃ નો સંಕર છે; એક Fe +2 અને બે Fe +3 માં · SI: અપ્રભાવી · મગ્નેટાઇટમાં ઇસ્પૉટ ઓક્સિડેશન અંક શોધવા
ઓક્સિડેશન અંક – S₂O₃²⁻ (થાયોસલ્ફેટ) માં S: S નો સરેરાશ ઓ.અ. = +2
તપાસ: 2(S) + 3(–2) = –2 → 2S = +4 → S = +2 · SI: અપ્રભાવી · થાયોસલ્ફેટ આયનમાં સલ્ફરનું સરેરાશ ઓ.અ. શોધવા
ઓક્સિડેશન અંક – S₄O₆²⁻ (ટેટ્રાથાયોનેટ) માં S: S નો સરેરાશ ઓ.અ. = +2.5
તપાસ: 4(S) + 6(–2) = –2 → 4S = +10 → S = +2.5 · SI: અપ્રભાવી · ટેટ્રાથાયોનેટ આયનમાં સલ્ફરનું સરેરાશ ઓ.અ. શોધવા
ઓક્સિડેશન અંક – C₂H₅OH માં C: મધ્યમ C = –1, CH₃ના C = –3 (વિભિન્ન પરમાણુઓ)
સંપૂર્ણ રીતે: CH₃CH₂OH માં –CH₃ નો C = –3, –CH₂OH નો C = –1; સરેરાશ = –2 · SI: અપ્રભાવી · ઇથેનૉલમાં કાર્બનના ઓ.અ. શોધવા
ઓક્સિડેશન અંક – CHO₄ (perchloric acid) માં Cl: Cl નો ઓ.અ. = +7
તપાસ: +7 + 4(–2) = –1 → ચોક્કસ · SI: અપ્રભાવી · પરક્લોરિક ઍસિડમાં ક્લોરીનનું ઓ.અ. શોધવા
ઇલેક્ટ્રોન-વિનિમય સંતુલન (Half-Reaction પ્ર卡થ): ऑक्सीકरણ अर्ध-प्रतिक्रिया में इलेक्ट्रॉन दाहिनी ओर, अपचयन अर्ध-प्रतिक्रिया में इलेक्ट्रॉन बायीं ओर
Examples: Zn → Zn²⁺ + 2e⁻ (ऑक्सीकरण); Cu²⁺ + 2e⁻ → Cu (अपचयन) · SI: n/a · Ion-electron (half-cell) method માં સમીકરણ સંતુલિત કરવા
રિડોક્સ ટાઇટ્રેશનમાં મોલ સંબંધ: n₁M₁V₁ (oxidising agent) = n₂M₂V₂ (reducing agent) × (સ્ટોકિયોમેટ્રિક ગુણોત્તર)
n₁, n₂ = n-ફેક્ટર; M = મોલારિટી; V = ઘનફળ · SI: M (mol L⁻¹), V (L) · રિડોક્સ ટાઇટ્રેશનમાં પ્રમાણભૂત દ્રાવણની ગાઢતા શોધવા
વિદ્યુતવિભાજન દરમિયાન જમા થતું દળ: m = (M × Q) / (n × F) = (M × I × t) / (n × F)
m = જમા થતું દળ, M = મોલર દળ, I = પ્રવાહ (A), t = સમય (s), n = ઇલેક્ટ્રોન મોલ, F = 96500 C · SI: g (ગ્રામ) · ફેરાડેના વિદ્યુતવિભાજન નિયમ પ્રમાણે
પ્રમાણભૂત કોષ સંભાવ્ય – સ્વયંસ્ફુરિતતા માપદંડ: E°_cell > 0 → પ્રક્રિયા સ્વયંસ્ફુરિત; E°_cell < 0 → પ્રક્રિયા અસ્વયંસ્ફુરિત
E°_cell = cathode રિડક્શન સંભાવ્ય – anode રિડક્શન સંભાવ્ય · SI: V (વોલ્ટ) · પ્રમાણભૂત પરિસ્થિતિઓમાં પ્રક્રિયાની દિશા નક્કી કરવા
n-ફેક્ટર — ઓક્સિડાઇઝિંગ એજન્ટ માટે: n-factor (oxidising agent) = એક મોલ ऑक्सीकరण कारक દીઠ લેવાતા ઇલેક્ટ્રોનના મોલ
ઉદા: KMnO₄ (acidic medium) માં Mn⁷⁺ → Mn²⁺, n = 5 · SI: અપ્રભાવી · KMnO₄, K₂Cr₂O₇ વગેરે જેવા ऑक्सीकरण कारकના સમતુલ્યભાર શોધવા
n-ફેક્ટર — રિડ્યુસિંગ એજન્ટ માટે: n-factor (reducing agent) = એક મોલ还原कारक દીઠ આપવાતા ઇલેક્ટ્રોનના મોલ
ઉદા: Fe²⁺ → Fe³⁺ + e⁻, n = 1; C₂O₄²⁻ → 2CO₂ + 2e⁻, n = 2 · SI: અપ્રભાવી · FeSO₄, Na₂C₂O₄ વગેરે રિડ્યુસિંગ એજન્ટના સમતુલ્યભાર શોધવા
MnO₄⁻ ઑક્સિડેશન અંક – Mn: MnO₄⁻ માં Mn નો ઓ.અ. = +7
તપાસ: Mn + 4(–2) = –1 → Mn = +7 · SI: અપ્રભાવી · પરમંગેનેટ આયનમાં મંગેનીઝનું ઓ.અ. શોધવા
Cr₂O₇²⁻ ઑક્સિડેશન અંક – Cr: Cr₂O₇²⁻ માં Cr નો ઓ.અ. = +6
તપાસ: 2(Cr) + 7(–2) = –2 → 2Cr = +12 → Cr = +6 · SI: અપ્રભાવી · ડાયક્ரોમેટ આયનમાં ક્રોમિયમનું ઓ.અ. શોધવા
F⁻ / O₂ / સલ્ફર સંયોજનોમાં ઓ.અ.: F₂ માં F = 0; O₂ માં O = 0; સુલ્ફર સલ્ફાઇડ (S²⁻) માં S = –2; SO₄²⁻ માં S = +6
Mૂળ તત્વોના ઓ.અ. = 0; પ્રચલિત આયનોના ઓ.અ. = તેમના ભાર જેટલા · SI: અપ્રભાવી · આધારભૂત ઓક્સિડેશન અંક નક્કી કરવા
ઓક્સિડેશન અંક – NO₃⁻ માં N: NO₃⁻ માં N નો ઓ.અ. = +5
તપાસ: N + 3(–2) = –1 → N = +5 · SI: અપ્રભાવી · નાયટ્રેટ આયનમાં નાઈટ્રોજનનું ઓ.અ. શોધવા
ઓક્સિડેશન અંક – NO₂ માં N: NO₂ માં N નો ઓ.અ. = +4
તપાસ: N + 2(–2) = 0 → N = +4 · SI: અપ્રભાવી · નાઈટ્રોજન ડાયਆક્સાઇડમાં નાઈટ્રોજનનું ઓ.અ. શોધવા
ઓક્સિડેશન અંક – ClO₄⁻ માં Cl: ClO₄⁻ માં Cl નો ઓ.અ. = +7
તપાસ: Cl + 4(–2) = –1 → Cl = +7 · SI: અપ્રભાવી · પરક્લોરેટ આયનમાં ક્લોરીનનું ઓ.અ. શોધવા
ઓક્સિડેશન અંક – ClO₃⁻ માં Cl: ClO₃⁻ માં Cl નો ઓ.અ. = +5
તપાસ: Cl + 3(–2) = –1 → Cl = +5 · SI: અપ્રભાવી · ક્લોરેટ આયનમાં ક્લોરીનનું ઓ.અ. શોધવા
ઓક્સિડેશન અંક – ClO⁻ માં Cl: ClO⁻ માં Cl નો ઓ.અ. = +1
તપાસ: Cl + (–2) = –1 → Cl = +1 · SI: અપ્રભાવી · હાઈપોક્લોરાઇટ આયનમાં ક્લોરીનનું ઓ.અ. શોધવા

🔗 સંબંધો

  • E°_cell > 0 હોય તો ΔG° < 0 થાય; પ્રક્રિયા સ્વયંસ્ફુરિત છે. E°_cell < 0 હોય તો ΔG° > 0 થાય; પ્રક્રિયા અસ્વયંસ્ફુરિત છે.
  • n-ફેક્ટર જેટલો મોટો, સમતુલ્યભાર તેટલો નાનો: સમતુલ્યભાર = આણ્વિકભાર/n-factor.
  • ઓક્સિડેશન અંક વધે → ઓક્સિડેશન; ઓક્સિડેશન અંક ઘટે → રિડક્શન. બંને એકસાથે થાય છે (રિડોક્સ).
  • KMnO₄ નો n-ફેક્ટર માધ્યમ પર આધારિત છે: ઍસિડિક (n=5), તટસ્થ/બેઝિક (n=3), શક્તિશાળી બેઝિક (n=1).
  • K₂Cr₂O₇ નો n-ફેક્ટર હંમેશા 6 છે (Cr⁶⁺ → Cr³⁺, 2 Cr પરમાણુ × 3e⁻ = 6e⁻).
  • Oxidising agent નો ઓ.અ. ઘટે છે; reducing agent નો ઓ.અ. વધે છે.
  • F = 96500 C/mol એ એક મોલ ઇલેક્ટ્રોનના ભાર બરાબર છે.

🎯 ટ્રિક્સ

ઓક્સિડેશન અંક શોધવાનો ઝડપી રસ્તો: ઑક્સિજન = –2, હાઈડ્રોજન = +1 લઈ, બાકીના પરમાણુને x ધારો; સરવાળો = આયનનો ભાર.
peroxide માં ઑક્સિજનનો ઓ.અ. –1 અને superoxide માં –½ યાદ રાખવા માટે: 'પરોક્સાઇડ = બે ઑક્સિજન + 2 ભાર (દરેક –1), સુપરآوکસાઇડ = બે ઑક્સિજન + 1 ભાર (દરેક –½)'
KMnO₄ ના n-ફેક્ટર માટે: 'POT' યાદ રાખો — Permanganate Oxygen Total: ઍસિડિકમાં 5e⁻, Neutrals/Baseમાં 3e⁻, strong baseમાં 1e⁻.
દ્વિ-પરમાણુક સલ્ફર સંયોજનો (S₂O₃²⁻, S₄O₆²⁻) માં સરેરાશ ઓ.અ. આવે; ખરો અંક અલગ હોઈ શકે, પણ GUJCET માં સરેરાશ જ પૂછાય છે.
રિડોક્સ સમીકરણ સંતુલિત કરતી વખતે ઍસિડિક માધ્યમમાં H₂O અને H⁺ વપરાય; બેઝિક માધ્યમમાં H₂O અને OH⁻ વપરાય. OH⁻ ઉમેરવા પહેલાં બંને બાજુ OH⁻ ઉમેરો, પછી H⁺ + OH⁻ → H₂O બનાવો.
Oxidising power નો ક્રમ: જેનું E°_red વધુ ધન, તે વધુ শક્તિશાળી ऑक्सीकरण कारक. F₂ > MnO₄⁻ > Cr₂O₇²⁻ > Cl₂ > Br₂ > Fe³⁺ > I₂.

⚠️ ભૂલો

ઓક્સિડેશન અંક અને આયનીય ભાર (ionic charge) વચ્ચે ગેરસમજ: ઓ.અ. એ પરમાણુ માટેનો કાલ્પનિક ભાર છે, આયનીય ભાર તે આયનનો વાસ્તવિક ભાર છે. બંને સમાન નથી.
O અને H ના ઓ.અ. નિયમોનો અપવાદ ભૂલી જવો: peroxide માં O = –1, fluoride માં F = –1 (અન્ય તત્વો સાથે H સામાન્યતઃ +1, પરંતુ hydrides માં H = –1).
KMnO₄ નો n-ફેક્ટર હંમેશા 5 ધારી લેવો — પરંતુ બેઝિક/તટસ્થ માધ્યમમાં n = 3 કે 1 થાય છે.
સંતુલિત સમીકરણમાં ઇલેક્ટ્રોન દૂર કરતાં પહેલાં એનોડ અને કાથોડ અર્ધ-સમીકરણના ઇલેક્ટ્રોન સમાન ન થયા હોય તો ગડબડ થાય.
Kr₂Cr₂O₇ ના ઓક્સિડેશન અંક ગણતરીમાં Cr એકલ માંને બદલે બે Cr પરમાણુ ધ્યાનમાં લેવા.
S₂O₃²⁻ અને S₄O₆²⁻ માં સરેરાશ ઓ.અ. ના તફાવતને ભૂલવા: S₂O₃²⁻ માં S = +2, S₄O₆²⁻ માં S = +2.5.
ડાયક્રોમેટ (Cr₂O₇²⁻) નો n-ફેક્ટર 3 સમજી લેવો — ખોટો! તે 6 છે કારણ કે 2 Cr × 3e⁻ = 6e⁻.
રિડક્શન સંભાવ્ય સૂચીમાં સૌથી વધુ ધન E°_red ધરાવતો તત્વ/આયન સૌથી શક્તિશાળી ऑक्सीकरण कारक છે, પરંતુ વિદ્યાર્થીઓ ઘણીવાર ઉલટું સમજે છે.
ΔG° = –nFE°_cell માં n = 0 લઈ લેવો અથવા F ની કિંમત 96500 બદલે 9650 શોધી લેવી.
