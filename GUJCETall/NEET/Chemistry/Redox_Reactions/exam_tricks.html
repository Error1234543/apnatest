🧪 GUJCET — Gujarati • Chemistry • Redox Reactions

🎯 પરીક્ષા ટ્રિક્સ

ઓક્સિડેશન અંકની ગણતરી માટે સૂત્ર: (મૂળભૂત પરમાણુનો વિદ્યુતઋણતા ક્રમ + ક્ષારનો ઓક્સિડેશન અંક = શૂન્ય). બેસ્કી રચના ધરાવતા સંયોજનમાં ધન તત્વનો ઓ.અ. શોધવા માટે ઋણ તત્વોના ઓ.અ. સ્થિર મૂલ્યો ઉપયોગ કરો અને બાકીનું પરમાણુ ઓ.અ. x તરીકે ધરીને સરળ બીજગણિત કરો.
જ્યારે પ્રશ્નમાં કોઈ અજ્ઞાત તત્વનો ઓક્સિડેશન અંક પૂછવામાં આવ્યો હોય — યાદ રાખવો કે S₂O₃²⁻, S₄O₆²⁻, Na₂S₄O₃ વગેરે જેવા યૌગિકોમાં સરેરાશ ઓ.અ. કાઢીને પણ સાચો જવાબ મળે.
દા.ત.: K₂Cr₂O₇ માં Cr નો ઓ.અ.: 2(+1) + 2(x) + 7(-2) = 0 → 2x = +12 → x = +6. K₂CrO₄ માં પણ Cr = +6. આમ Cr(VI) સંયોજનોમાં હંમેશા +6.
બહુવિકલ્પી પ્રશ્નોમાં Cr₂O₇²⁻ / MnO₄⁻ પૂછાય ત્યારે 'ઓક્સિડાઇઝિંગ એજન્ટ' તરીકે ઓળખો. K₂Cr₂O₇ એ H₂SO₄ સાથે 'લાલ-ઓરેન્જ' થી 'હરિત (Cr³⁺)' બને — આ રંગ બદલાવ ઝડપી યાદગારી ટ્રિક છે.
જ્યારે પ્રશ્નમાં ઓક્સિડાઇઝિંગ એજન્ટ ચિહ્નિત કરવાનો હોય અથવા રંગ પરિવર્તન પૂછવામાં આવ્યું હોય.
દા.ત.: K₂Cr₂O₇ + H₂SO₄ + FeSO₄ → K₂SO₄ + Cr₂(SO₄)₃ + Fe₂(SO₄)₃ + H₂O. રેડ-ઓરેન્જ (Cr₂O₇²⁻) → હરિત (Cr³⁺).
H₂O₂ માં ઓક્સિજનનો ઓ.અ. = −1 (પેરોક્સાઇડ). O₂ માં = 0. O₃ માં = 0. OH⁻/H₂O માં = −2. એક પણ ઓક્સિડેશન-રિડક્શન પ્રશ્નમાં આ ચારેય મૂલ્યો ત્વરિત યાદ કરી લો.
જ્યારે H₂O₂, O₂, O₃, હાઇડ્રોક્સાઇડ/પાણીમાં ઓ.અ. નક્કી કરવાના હોય — ઘણા વિકલ્પો બરાબર આ મૂલ્યો પર આધારિત હોય છે.
દા.ત.: H₂O₂ → H₂O + ½O₂ : અહીં O(−1) → O(−2) + O(0) — એક જ સમયે ઓક્સિડેશન અને રિડક્શન, એટલે H₂O₂ વિવિધતા (disproportionation) દર્શાવે છે.
KMnO₄ નો રંગ 'વાદળી-જાંબલી (purple)' છે — તે ઓક્સિડાઇઝિંગ એજન્ટ છે. અmlacidic માદ્યામમાં MnO₄⁻ → Mn²⁺ (રંગહીન/ગુલાબી-ફિકો), તટસ્થ/ક્ષારીય માદ્યામમાં MnO₄⁻ → MnO₂ (ઘેરો બ્રાઉન અવકંદન).
જ્યારે KMnO₄ ની પ્રક્રિયાઓ અથવા તેના રંગ-બદલાવ વિશે પ્રશ્ન આવે.
દા.ત.: 酸性 માદ્યામ: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O. તટસ્થ/ક્ષારીય: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻.
સંતુલન ટ્રિક — KMnO₄ માટે n-ફેક્ટર: એસિડિક માદ્યામમાં = 5, ક્ષારીય/તટસ્થ માદ્યામમાં = 3. K₂Cr₂O₇ માટે હંમેશા n-ફેક્ટર = 6. આ આંકડા યાદ રાખો તેથી પ્રમાણબદ્ધ પ્રશ્નોમાં N₁V₁ = N₂V₂ ઝડપથી કાઢી શકાય.
જ્યારે પ્રમાણબદ્ધ ગણતરીઓ (titration/normality) સંબંધિત પ્રશ્ન આવે.
દા.ત.: 0.1 N K₂Cr₂O₭ ના 20 mL માં કેટલા gram KMnO₄ હોઈ શકે? K₂Cr₂O₇ નું Mol wt = 294, n-ફેક્ટર = 6, એક સમક. = 294/6 = 49 g. KMnO₄ નું Mol wt = 158, n-ફેક્ટર = 5, એક સમક. = 158/5 = 31.6 g.
Metall Hydrides માં H નો ઓ.અ. = −1. NaH, CaH₂, LiAlH₄ જેવા સંયોજનોમાં હાઇડ્રોજન ઋણ છે — આ ટ્રિક ઘણીવાર વિકલ્પોમાં ગૂંચવણ ઊભી કરે છે.
જ્યારે પ્રશ્નમાં NaH, CaH₂, LiAlH₄ વગેરેમાં H નો ઓ.અ. પૂછવામાં આવ્યો હોય.
દા.ત.: NaH માં Na = +1, H = −1. CaH₂ માં Ca = +2, H = −1. આમ H₂ ઓક્સિડાઇઝર તરીકે વર્તે છે (NaH + H₂O → NaOH + H₂).
Super oxide માં ઓ.અ. = −½. KO₂, RbO₂ જેવા સંયોજનોમાં ઓક્સિજનનો ઓ.અ. −½ છે — આ ટુકડો GUJCET માં બહુવિકલ્પી પ્રશ્નોમાં ઘણીવાર આવે છે.
જ્યારે KO₂ અથવા અન્ય સુપર ઑક્સાઇડ વિશે પ્રશ્ન આવે.
દા.ત.: KO₂ માં K = +1, તેથી O₂ નો કુલ ઓ.અ. = −1. દરેક O માટે = −½. KO₂ + 2H₂O → KOH + H₂O₂ + O₂.
Disproportionation ટ્રિક: જ્યાં એક જ પદાર્થ એકસાથે ઓક્સિડાઇઝ અને રિડ્યूस થાય તેવી પ્રક્રિયા ઓળખો. Cl₂ + OH⁻, H₂O₂, MnO₄²⁻ → MnO₄⁻ + MnO₂ જેવી પ્રક્રિયાઓ યાદ રાખો.
જ્યારે પ્રશ્નમાં 'કઈ પ્રક્રિયા disproportionation છે?' અથવા 'કઈ પ્રક્રિયામાં એક જ પદાર્થ ઓક્સિડાઇઝ અને રિડ્યુસ થાય છે?' પૂછવામાં આવ્યું હોય.
દા.ત.: 2MnO₄²⁻ + 2H₂O → 2MnO₄⁻ + MnO₂ + 4OH⁻ : અહીં MnO₄²⁻ (Mn = +6) → MnO₄⁻ (Mn = +7) + MnO₂ (Mn = +4). +6 થી +7 (ઓક્સિડેશન) અને +6 થી +4 (રિડક્શન).
Redox સમીકરણ સંતુલનમાં ઇલેક્ટ્રોન સંખ્યા સમાન કરો: ઓક્સિડેશન અને રિડક્શન અર્ધ-સમીકરણોમાં ઇલેક્ટ્રોનની સંખ્યા LCM લઈને બરાબર કરો, પછી H⁺/OH⁻/H₂O ઉમેરીને દળ અને વીજભાર સંતુલિત કરો.
જ્યારે આયન-ઇલેક્ટ્રોન પદ્ધતિથી સંતુલન પૂછાય.
દા.ત.: MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺ (એસિડિક): MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O · Fe²⁺ → Fe³⁺ + e⁻ · છેલ્લે બીજું સમીકરણ 5 વડે ગુણો: MnO₄⁻ + 8H⁺ + 5Fe²⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O.
ઓક્સિડાઇઝિંગ અને રિડ્યુસિંગ એજન્ટ ઓળખવાની ટ્રિક: જે પદાર્થનો ઓ.અ. ઘટે છે (ઇલેક્ટ્રોન મેળવે છે) તે ઓક્સિડાઇઝિંગ એજન્ટ છે; જેનો ઓ.અ. વધે છે (ઇલેક્ટ્રોન ગુમાવે છે) તે રિડ્યુસિંગ એજન્ટ છે.
જ્યારે પ્રશ્નમાં કઈ પ્રજાતિ ઓક્સિડાઇઝિંગ/રિડ્યુસિંગ એજન્ટ છે તે પૂછવામાં આવે.
દા.ત.: Zn + Cu²⁺ → Zn²⁺ + Cu : Zn (0 → +2) રિડ્યુસિંગ એજન્ટ, Cu²⁺ (+2 → 0) ઓક્સિડાઇઝિંગ એજન્ટ.
કોઈ સંયોજનમાં C નો ઓ.અ. શોધવા માટે CH₄, C₂H₆, CO₂, HCOOH, C₂H₅OH જેવા સામાન્ય જીવરસાયણિક સંયોજનોના ઓ.અ. યાદ રાખો: CH₄ માં C = −4, CO₂ માં = +4, C₂H₅OH માં બંને C ના મૂલ્યો અલગ (−3 અને −1) — આમ સરેરાશ = −2.
જ્યારે કાર્બનિક સંયોજનોમાં કાર્બનનો ઓ.અ. પૂછવામાં આવે.
દા.ત.: C₂H₅OH: પ્રથમ C (CH₃) → −3, બીજો C (CH₂OH) → −1. સરેરાશ = (−3 + −1)/2 = −2.
O.F. (Oxidation Number of Fluorine) હંમેશા −1 હોય છે — કોઈ પણ સંયોજનમાં F નો ઓ.અ. +1 ન હોઈ શકે. આમ OF₂ માં F = −1, O = +2.
જ્યારે F ધરાવતા સંયોજનનો ઓ.અ. પૂછવામાં આવે.
દા.ત.: OF₂ માં: O + 2(F) = 0 → O + 2(−1) = 0 → O = +2. F હંમેશા −1 જ રહે.
PbO₂, MnO₂, Ag₂O જેવા ઓક્સાઇડ્સ ઓક્સિડાઇઝિંગ એજન્ટ છે — તેમના ધાતુનો ઓ.અ. ઊંચો હોય છે (Pb⁴⁺, Mn⁴⁺, Ag⁺). આ ટ્રિકથી ઓક્સિડાઇઝિંગ એજન્ટની યાદી ઝડપથી બનાવી શકાય.
જ્યારે ધાતુ ઓક્સાઇડ્સમાં કौन सा ઓક્સિડાઇઝિંગ એજન્ટ છે તે પૂછવામાં આવે.
દા.ત.: PbO₂ (Pb⁴⁺) → Pb²⁺ + 2e⁻ ઓક્સિડાઇઝિંગ એજન્ટ. MnO₂ (Mn⁴⁺) → Mn²⁺. આમ ઊંચા ઓક્સિડેશન અવસ્થામાં ધાતુ ઓક્સાઇડ્સ ઓક્સિડાઇઝિંગ એજન્ટ તરીકે વર્તે છે.
કોઈ પ્રક્રિયા રેડોક્સ છે કે નહીં તંત્ર્ગત ઝડપી તપાસ: ડાબી બાજુ અને જમણી બાજુના સર્વ તત્વોના ઓ.અ. તુલના કરો — જો કોઈ પણ તત્વનો ઓ.અ. બદલાયો હોય તો પ્રક્રિયા રેડોક્સ છે.
જ્યારે પ્રશ્નમાં 'કઈ પ્રક્રિયા રેડોક્સ નથી?' અથવા 'કઈ રેડોક્સ પ્રક્રિયા છે?' પૂછવામાં આવે.
દા.ત.: NaCl + AgNO₃ → AgCl + NaNO₃ : દરેક તત્વનો ઓ.અ. બદલાયો નથી → રેડોક્સ નહીં. Zn + CuSO₄ → ZnSO₄ + Cu : Zn(0→+2), Cu(+2→0) → રેડોક્સ.
IO₃⁻, ClO₄⁻, NO₃⁻ જેવા યૌગિકોમાં ધાતુ/અધાતુનો ઓ.અ. = +5 અથવા +7 — આ યૌગિકો ઓક્સિડાઇઝિંગ એજન્ટ તરીકે વર્તે છે. ClO₄⁻ માં Cl = +7 (સૌથી ઊંચું), તેથી શક્તિશાળી ઓક્સિડાઇઝર.
જ્યારે ક્લોરેટ, નાઈટ્રેટ, પરક્લોરેટ વગેરેમાં ક્યાં તત્વનો ઓ.અ. શોધવાનો હોય અથવા ઓક્સિડાઇઝિંગ શક્તિ પૂછવામાં આવે.
દા.ત.: ClO₄⁻: x + 4(−2) = −1 → x = +7. NO₃⁻: x + 3(−2) = −1 → x = +5. IO₃⁻: x + 3(−2) = −1 → x = +5.
