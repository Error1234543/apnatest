d અને f બ્લોક તત્વો — સૂત્ર શેડ

⚡ સૂત્રો

સ્પિન-ઓનલી ચુંબકીય ચાકમાત્રા (Spin-Only Magnetic Moment): μ = √[n(n+2)] બોહર મેગ્નેટોન (B.M.)
μ = ચુંબકીય ચાકમાત્રા, n = અયુગ્મિત ઇલેક્ટ્રોનની સંખ્યા · SI: B.M. (બોહર મેગ્નેટોન) · જ્યારે ઓર્બિટલ કોણીય વેગમાનનું યોગદાન નગણ્ય હોય (પ્રથમ સંક્રાંતિ શ્રેણી માટે)
ઇલેક્ટ્રોનિક વિન્યાસ — સંક્રાંતિ તત્વો (d-બ્લોક): (n-1)d¹⁻¹⁰ ns⁰⁻²
n = મુખ્ય કક્ષા સંખ્યા, (n-1)d = આંતરિક d-કક્ષક, ns = બાહ્ય s-કક્ષક · SI: — · સંક્રાંતિ તત્વોનો સામાન્ય વિન્યાસ; d-કક્ષક ભરાતી હોય ત્યારે
ઇલેક્ટ્રોનિક વિન્યાસ — લેન્થેનાઇડ્સ (4f શ્રેણી): [Xe] 4f⁰⁻¹⁴ 5d⁰⁻¹ 6s²
[Xe] = ઝેનોનનો નિષ્ક્રિય ગેસ વિન્યાસ, 4f = f-કક્ષક ભરાય છે · SI: — · લેન્થેનાઇડ્સ (Ce થી Lu, Z=58–71) માટે
ઇલેક્ટ્રોનિક વિન્યાસ — એક્ટિનોઇડ્સ (5f શ્રેણી): [Rn] 5f⁰⁻¹⁴ 6d⁰⁻¹ 7s²
[Rn] = રેડોનનો નિષ્ક્રિય ગેસ વિન્યાસ, 5f = f-કક્ષક ભરાય છે · SI: — · એક્ટિનોઇડ્સ (Th થી Lr, Z=90–103) માટે
લેન્થેનાઇડ સંકોચન — પ્રભાવ: 4f ઇલેક્ટ્રોનનું ન્યુક્લિયસ આસપાસ અસરકારક રીતે આવરણ (shielding) નહિવત હોવાથી, પરમાણુ ત્રિજ્યામાં ધીમો ઘટાડો
4f ઇલેક્ટ્રોનનું shielding અસર ≈ 0.85 કરતાં ઓછું; પરિણામે Z_eff વધે છે · SI: — · લેન્થેનાઇડ્સમાં પરમાણુ ત્રિજ્યા Z વધે ત્યારે પણ ઘટે છે
K₂Cr₂O₇ નું પ્રમાણિત વિઘટન (તટસ્થ/ક્ષારક માધ્યમ): Cr₂O₇²⁻ + H₂O → 2CrO₄²⁻ + 2H⁺
Cr₂O₇²⁻ = ડાયક્રોમેટ આયન, CrO₄²⁻ = ક્રોમેટ આયન · SI: — · ક્ષારક માધ્યમમાં ડાયક્રોમેટ → ક્રોમેટમાં રૂપાંતર
K₂Cr₂O₇ નું અમ્લ માધ્યમમાં રિડક્શન (પ્રમાણિત): Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O E° = +1.33 V
Cr₂O₇²⁻ = ઓક્સિડાઇઝિંગ એજન્ટ, Cr³⁺ = અપચયિત ઉત્પાદ, E° = પ્રમાણિત વિભવ · SI: V (વોલ્ટ) · અમ્લ માધ્યમમાં K₂Cr₂O₇ પ્રબળ ઓક્સિડાઇઝિંગ એજન્ટ તરીકે વર્તે છે
KMnO₄ નું અમ્લ માધ્યમમાં રિડક્શન: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O E° = +1.51 V
MnO₄⁻ = પરમેંગેનેટ આયન, Mn²⁺ = અપચયિત ઉત્પાદ · SI: V (વોલ્ટ) · અમ્લ માધ્યમમાં KMnO₄ પ્રબળ ઓક્સિડાઇઝિંગ એજન્ટ
KMnO₄ નું ક્ષારક માધ્યમમાં રિડક્શન: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻ E° = +0.59 V
MnO₄⁻ = પરમેંગેનેટ, MnO₂ = મેંગેનીઝ ડાયઓક્સાઇડ · SI: V (વોલ્ટ) · ક્ષારક/નિષ્ક્રિય માધ્યમમાં KMnO₄ નું અપચયન
KMnO₄ નું અત્યંત ક્ષારક માધ્યમમાં રિડક્શન: MnO₄⁻ + e⁻ → MnO₄²⁻ E° = +0.56 V
MnO₄²⁻ = મેંગેનેટ આયન (હરિત) · SI: V (વોલ્ટ) · અત્યંત ક્ષારક માધ્યમમાં
K₂Cr₂O₇ → CrO₃ (ક્રોમિક એનહાઇડ્રાઇડ): K₂Cr₂O₇ + 2H₂SO₄(ઘન) → 2CrO₃ + 2KHSO₄ + H₂O
CrO₃ = ક્રોમિક એનહાઇડ્રાઇડ (લાલ-ભૂરો ઘન) · SI: — · સાંદ્ર H₂SO₄ સાથે K₂Cr₂O₇ નું પ્રતિક્રિયા
Cr₂O₃ → NaCrO₂ (સોડિયમ ક્રોમાઇટ): Cr₂O₃ + 2NaOH → 2NaCrO₂ + H₂O
NaCrO₂ = સોડિયમ ક્રોમાઇટ · SI: — · Cr₂O₃ નું ક્ષારક સાથે દ્રવણ
MnO₂ → K₂MnO₄ (પોટેશિયમ મેંગેનેટ): 2MnO₂ + 4KOH + O₂ → 2K₂MnO₄ + 2H₂O
K₂MnO₄ = પોટેશિયમ મેંગેનેટ (હરિત) · SI: — · MnO₂ નું KOH સાથે ઓક્સિજનની હાજરીમાં ગળણ
d-બ્લોક તત્વોનો સામાન્ય ઓક્સિડેશન અંક: ઓક્સિડેશન અંક = (n-1)d + ns ઇલેક્ટ્રોનની સંખ્યા (સીમાંત સુધી)
સંક્રાંતિ તત્વોમાં d અને s બંને કક્ષકના ઇલેક્ટ્રોન ભાગ લે છે · SI: — · વિવિધ ઓક્સિડેશન અવસ્થાઓ દર્શાવે છે
લેન્થેનાઇડ્સની પ્રબળ ઓક્સિડેશન અવસ્થા: સામાન્ય ઓક્સિડેશન અંક = +3
+3 એ લેન્થેનાઇડ્સની સૌથી સ્થિર અને સામાન્ય અવસ્થા · SI: — · લેન્થેનાઇડ્સ માટે
Ce⁴⁺ ની સ્થિરતા (લેન્થેનાઇડ્સમાં): Ce³⁺ → Ce⁴⁺ + e⁻ (4f¹ → 4f⁰ નિષ્ક્રિય ગેસ વિન્યાસ)
Ce⁴⁺ = નિષ્ક્રિય ગેસ વિન્યાસ [Xe] ધરાવે છે, તેથી પ્રબળ ઓક્સિડાઇઝિંગ એજન્ટ · SI: — · Ce⁴⁺ પ્રબળ ઓક્સિડાઇઝિંગ એજન્ટ તરીકે વર્તે છે
Eu²⁺ ની સ્થિરતા: Eu³⁺ + e⁻ → Eu²⁺ (4f⁷ → 4f⁷ અર્ધ-ભરેલી સ્થિર કક્ષક)
Eu²⁺ = 4f⁷ વિન્યાસ (અર્ધ-ભરેલી f-કક્ષક, વધુ સ્થિર) · SI: — · Eu²⁺ પ્રબળ રિડ્યુસિંગ એજન્ટ તરીકે વર્તે છે
લેન્થેનાઇડ્સ — f-f સંક્રાંતિ (વર્ણપટ): f-કક્ષકમાં ઇલેક્ટ્રોન સંક્રાંતિ → વર્ણક કિરણો (દૃશ્યમાન પ્રદેશ)
f-f સંક્રાંતિઓ તીક્ષ્ણ રેખાઓ આપે છે; આયનો રંગીન દેખાય છે · SI: — · લેન્થેનાઇડ આયનોના રંગનું કારણ
d-d સંક્રાંતિ (સંક્રાંતિ ધાતુ આયનોના રંગ): d-કક્ષકમાં ઇલેક્ટ્રોન સંક્રાંતિ → વર્ણક પ્રકાશ શોષાય છે
ક્રિસ્ટલ ફીલ્ડ વિભાજન (Δ) ને અનુરૂપ તરંગલંબાઈ શોષાય છે · SI: — · d⁰ અને d¹⁰ વિન્યાસવાળા આયનો રંગહીન હોય છે
Zn, Cd, Hg — d¹⁰ વિન્યાસ અને ગુણધર્મ: (n-1)d¹⁰ ns² → સંપૂર્ણ ભરેલી d-કક્ષક, ઓક્સિડેશન અંક +2
Zn, Cd, Hg માટે d-ઇલેક્ટ્રોન ભાગ લેતા નથી; તેઓ સંક્રાંતિ તત્વો ગણાતા નથી · SI: — · Group 12 તત્વો — d¹⁰ સંક્રાંતિ ન હોવાથી રંગહીન સંયોજનો
Sc³⁺ — રંગહીન આયન: Sc³⁺ : [Ar] 3d⁰ 4s⁰ → d-d સંક્રાંતિ શક્ય નથી
Sc³⁺ માં d-ઇલેક્ટ્રોન નથી, તેથી રંગહીન · SI: — · d⁰ વિન્યાસવાળા આયનો રંગહીન હોય છે
Mn²⁺ — અયુગ્મિત ઇલેક્ટ્રોન: Mn²⁺ : [Ar] 3d⁵ → n = 5, μ = √35 ≈ 5.92 B.M.
n = અયુગ્મિત ઇલેક્ટ્રોન, μ = ચુંબકીય ચાકમાત્રા · SI: B.M. · અર્ધ-ભરેલી d-કક્ષક, ઉચ્ચ ચુંબકીય ચાકમાત્રા
Fe³⁺ — અયુગ્મિત ઇલેક્ટ્રોન: Fe³⁺ : [Ar] 3d⁵ → n = 5, μ = √35 ≈ 5.92 B.M.
n = અયુગ્મિત ઇલેક્ટ્રોન · SI: B.M. · અર્ધ-ભરેલી d-કક્ષક
Cu²⁺ — અયુગ્મિત ઇલેક્ટ્રોન: Cu²⁺ : [Ar] 3d⁹ → n = 1, μ = √3 ≈ 1.73 B.M.
n = અયુગ્મિત ઇલેક્ટ્રોન · SI: B.M. · એક અયુગ્મિત ઇલેક્ટ્રોન
Ni²⁺ — અયુગ્મિત ઇલેક્ટ્રોન: Ni²⁺ : [Ar] 3d⁸ → n = 2, μ = √8 ≈ 2.83 B.M.
n = અયુગ્મિત ઇલેક્ટ્રોન · SI: B.M. · બે અયુગ્મિત ઇલેક્ટ્રોન
Co²⁺ — અયુગ્મિત ઇલેક્ટ્રોન: Co²⁺ : [Ar] 3d⁷ → n = 3, μ = √15 ≈ 3.87 B.M.
n = અયુગ્મિત ઇલેક્ટ્રોન · SI: B.M. · ત્રણ અયુગ્મિત ઇલેક્ટ્રોન
Cr³⁺ — અયુગ્મિત ઇલેક્ટ્રોન: Cr³⁺ : [Ar] 3d³ → n = 3, μ = √15 ≈ 3.87 B.M.
n = અયુગ્મિત ઇલેક્ટ્રોન · SI: B.M. · ત્રણ અયુગ્મિત ઇલેક્ટ્રોન
Ti³⁺ — અયુગ્મિત ઇલેક્ટ્રોન: Ti³⁺ : [Ar] 3d¹ → n = 1, μ = √3 ≈ 1.73 B.M.
n = અયુગ્મિત ઇલેક્ટ્રોન · SI: B.M. · એક અયુગ્મિત ઇલેક્ટ્રોન
Mn³⁺ — અયુગ્મિત ઇલેક્ટ્રોન: Mn³⁺ : [Ar] 3d⁴ → n = 4, μ = √24 ≈ 4.90 B.M.
n = અયુગ્મિત ઇલેક્ટ્રોન · SI: B.M. · ચાર અયુગ્મિત ઇલેક્ટ્રોન
Fe²⁺ — અયુગ્મિત ઇલેક્ટ્રોન: Fe²⁺ : [Ar] 3d⁶ → n = 4, μ = √24 ≈ 4.90 B.M.
n = અયુગ્મિત ઇલેક્ટ્રોન · SI: B.M. · ચાર અયુગ્મિત ઇલેક્ટ્રોન
લેન્થેનાઇડ્સ — +2 ઓક્સિડેશન અવસ્થા (સ્થિરતા): f⁰, f⁷, f¹⁴ વિન્યાસ ધરાવતા આયનો +2 અવસ્થામાં સ્થિર: Eu²⁺(4f⁷), Yb²⁺(4f¹⁴)
અર્ધ-ભરેલી અને સંપૂર્ણ ભરેલી f-કક્ષક સ્થિરતા આપે છે · SI: — · Eu અને Yb માટે +2 ઓક્સિડેશન અવસ્થા સ્થિર
લેન્થેનાઇડ્સ — +4 ઓક્સિડેશન અવસ્થા (સ્થિરતા): f⁰ વિન્યાસ ધરાવતો Ce⁴⁺ સ્થિર: Ce⁴⁺([Xe] 4f⁰)
Ce⁴⁺ નિષ્ક્રિય ગેસ વિન્યાસ ધરાવે છે · SI: — · Ce માટે +4 ઓક્સિડેશન અવસ્થા સ્થિર
લેન્થેનાઇડ સંકોચન — પરિણામી અસર: Z વધે તો પરમાણુ ત્રિજ્યા ધીમે ધીમે ઘટે છે (4f shielding ન્યૂન)
લેન્થેનાઇડ્સની પરમાણુ ત્રિજ્યા Ce થી Lu સુધી ઘટે છે · SI: pm (પિકોમીટર) · લેન્થેનાઇડ્સમાં 4f ઇલેક્ટ્રોનનું shielding અસર ન્યૂન
લેન્થેનાઇડ સંકોચન — રાસાયણિક અસર: લેન્થેનાઇડ્સ અને પછીના તત્વો (Hf, Ta, W) ની પરમાણુ ત્રિજ્યા સમાન

4f ઇલેક્ટ્રોન બાહ્ય કક્ષકો દ્વારા આવરિત; રાસાયણિક ગુણધર્મો મુખ્યત્વે +3 ઓક્સિડેશન અવસ્થા પર આધારિત · SI: — · લેન્થેનાઇડ્સના રાસાયણિક ગુણધર્મો

🔗 સંબંધો

  • અયુગ્મિત ઇલેક્ટ્રોનની સંખ્યા (n) જેટલી હોય તેટલી ચુંબકીય ચાકમાત્રા (μ) વધે છે; μ = √[n(n+2)] B.M.
  • લેન્થેનાઇડ સંકોચનને કારણે Zr અને Hf ની પરમાણુ ત્રિજ્યા લગભગ સમાન છે, જેથી તેમના રાસાયણિક ગુણધર્મો સમાન છે.
  • d-બ્લોક તત્વોમાં ઓક્સિડેશન અંક વધવા સાથે ઓક્સાઇડની અમ્લતા વધે છે (ઉદા. CrO નિરપેક્ષ, Cr₂O₃ ક્ષારક, CrO₃ અમ્લ).
  • લેન્થેનાઇડ્સમાં +2 અને +4 ઓક્સિડેશન અવસ્થાઓ f⁰, f⁷, f¹⁴ જેવી સ્થિર વિન્યાસ ધરાવતા તત્વોમાં દેખાય છે.
  • KMnO₄ અમ્લ માધ્યમમાં વધુ પ્રબળ ઓક્સિડાઇઝિંગ એજન્ટ છે (E° = +1.51 V) ક્ષારક માધ્યમ (E° = +0.59 V) કરતાં.
  • લેન્થેનાઇડ્સના આયનોના રંગનું કારણ f-f સંક્રાંતિ છે; જ્યારે d-બ્લોક તત્વોના આયનોના રંગનું કારણ d-d સંક્રાંતિ છે.
  • લેન્થેનાઇડ સંકોચનને કારણે Ln³⁺ આયન ત્રિજ્યા ઘટતી જાય છે, જેથી ક્ષારકતા પણ ઘટે છે.
  • d-બ્લોક તત્વોની આયનીકરણ ઊર્જા સામાન્ય રીતે ડાબેથી જમણે વધે છે, પરંતુ Cr અને Cu માં અપવાદ છે.
  • Zn, Cd, Hg (Group 12) માં d-કક્ષક સંપૂર્ણ ભરેલી (d¹⁰) હોવાથી તેઓ સંક્રાંતિ તત્વો ગણાતા નથી.
  • લેન્થેનાઇડ્સની પરમાણુ ત્રિજ્યા Ce થી Lu સુધી ધીમે ધીમે ઘટે છે (લેન્થેનાઇડ સંકોચન).

🎯 ટ્રિક્સ

μ = √[n(n+2)] B.M. માં n = અયુગ્મિત ઇલેક્ટ્રોન; n=1→1.73, n=2→2.83, n=3→3.87, n=4→4.90, n=5→5.92 B.M. યાદ રાખવા માટે: 1-2-3-4-5 → √3-√8-√15-√24-√35.
Cr (Z=24) અને Cu (Z=29) માં અપવાદ વિન્યાસ: Cr → [Ar]3d⁵4s¹ (અર્ધ-ભરેલી d), Cu → [Ar]3d¹⁰4s¹ (સંપૂર્ણ ભરેલી d).
લેન્થેનાઇડ્સમાં +2 સ્થિર: Eu (f⁷ અર્ધ-ભરેલી), Yb (f¹⁴ સંપૂર્ણ); +4 સ્થિર: Ce (f⁰ નિષ્ક્રિય ગેસ).
d-d સંક્રાંતિ માટે d⁰ અને d¹⁰ વિન્યાસવાળા આયનો રંગહીન હોય છે (ઉદા. Sc³⁺, Zn²⁺).
KMnO₄ નું અમ્લ માધ્યમમાં રિડક્શન: MnO₄⁻ → Mn²⁺ (5e⁻); ક્ષારક માધ્યમમાં: MnO₄⁻ → MnO₂ (3e⁻); અત્યંત ક્ષારક: MnO₄⁻ → MnO₄²⁻ (1e⁻).
K₂Cr₂O₇ માં Cr⁶⁺ → Cr³⁺ (3e⁻ પ્રતિ Cr, કુલ 6e⁻); KMnO₄ માં Mn⁷⁺ → Mn²⁺ (5e⁻).
લેન્થેનાઇડ સંકોચન: 4f ઇલેક્ટ્રોનનું shielding અસર ન્યૂન → Z_eff વધે → પરમાણુ ત્રિજ્યા ઘટે.
d-બ્લોક તત્વોના ઓક્સિડેશન અંક વધતાં ઓક્સાઇડની અમ્લતા વધે: નિરપેક્ષ → ક્ષારક → અમ્લ.
લેન્થેનાઇડ્સ અને પછીના તત્વો (Hf, Ta, W) ની ત્રિજ્યા સમાન → Zr-Hf, Nb-Ta, Mo-W વચ્ચે રાસાયણિક સમાનતા.
Mn²⁺ અને Fe³⁺ બંને d⁵ વિન્યાસ ધરાવે છે → n=5, μ=5.92 B.M.

⚠️ ભૂલો

Zn, Cd, Hg ને સંક્રાંતિ તત્વો માની લેવા — તેમની d-કક્ષક સંપૂર્ણ ભરેલી (d¹⁰) હોવાથી તેઓ સંક્રાંતિ તત્વો નથી.
Sc³⁺ રંગહીન છે તે ભૂલથી રંગીન માની લેવું — Sc³⁺ માં d-ઇલેક્ટ્રોન નથી (d⁰).
K₂Cr₂O₇ અને KMnO₄ ના ઇલેક્ટ્રોન ફેરફાર ગણતરીમાં ભૂલ: K₂Cr₂O₇ માં 6e⁻ (Cr⁶⁺→Cr³⁺, 2 Cr), KMnO₄ માં 5e⁻ (Mn⁷⁺→Mn²⁺).
લેન્થેનાઇડ સંકોચનનું કારણ 4f ઇલેક્ટ્રોનનું shielding અસર વધુ છે એમ માની લેવું — વાસ્તવમાં તે ન્યૂન છે.
Cr અને Cu નો સામાન્ય વિન્યાસ લખવો (3d⁴4s² અને 3d⁹4s¹) — વાસ્તવમાં 3d⁵4s¹ અને 3d¹⁰4s¹ છે.
લેન્થેનાઇડ્સની પ્રબળ ઓક્સિડેશન અવસ્થા +2 માની લેવી — પ્રબળ અવસ્થા +3 છે.
MnO₄²⁻ (મેંગેનેટ) અને MnO₄⁻ (પરમેંગેનેટ) વચ્ચે ભેદ ન રાખવો — MnO₄²⁻ હરિત, MnO₄⁻ જાંબલી.
d-d સંક્રાંતિ d⁰ અને d¹⁰ વિન્યાસમાં શક્ય છે એમ માની લેવું — d⁰ અને d¹⁰ માં d-d સંક્રાંતિ શક્ય નથી.
લેન્થેનાઇડ્સના આયનોના રંગનું કારણ d-d સંક્રાંતિ માની લેવું — લેન્થેનાઇડ્સમાં f-f સંક્રાંતિ થાય છે.
લેન્થેનાઇડ સંકોચનને કારણે Ln³⁺ આયન ત્રિજ્યા વધે છે એમ ભૂલથી માની લેવું — ત્રિજ્યા ઘટે છે.
K₂Cr₂O₇ નું અમ્લ માધ્યમમાં રંગ પીળો માની લેવો — અમ્લ માધ્યમમાં ડાયક્રોમેટ (ઓરેન્જ) સ્થિર રહે છે, ક્ષારકમાં પીળો ક્રોમેટ બને છે.
લેન્થેનાઇડ્સમાં f-ઇલેક્ટ્રોન બાહ્ય રાસાયણિક પ્રતિક્રિયાઓમાં ભાગ લે છે એમ માની લેવું — f-ઇલેક્ટ્રોન આવરિત હોય છે, રાસાયણિક ગુણધર્મો મુખ્યત્વે +3 અવસ્થા પર આધારિત.
