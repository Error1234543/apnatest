સંતતતા અને વિકલનીયતા — સૂત્ર શીટ

⚡ સૂત્રો

બિંદુએ સંતત વિધેયની વ્યાખ્યા: lim(x->a) f(x) = f(a)
f(x) = વિધેય; a = બિંદુ; lim = સીમા. વિધેય f, bિંદુ a પર સંતત હોય તે માટે a પર વ્યાખ્યાયિત હોવું જોઈએ અને સીમા અસ્તિત્વ ધરાવતી હોવી જોઈએ. · SI: એકમહીન · આપેલ બિંદુ a પર, જ્યાં f વ્યાખ્યાયિત હોય.
અંતરાલ પર સંતત વિધેય: f [a,b] પર સંતત જો: (i) દરેક c ∈ (a,b) પર lim(x->c) f(x) = f(c); (ii) જમણી બાજુ s limit at a: lim(x->a+) f(x) = f(a); (iii) ડાબી બાજુ s limit at b: lim(x->b-) f(x) = f(b)
f = વિધેય; a,b = અંતરાલના સિરા; lim = સીમા. · SI: એકમહીન · સંતત અંતરાલ [a,b] માટે.
પ્રથમ વિકલનીયતાની વ્યાખ્યા (a બિંદુએ): f'(a) = lim(h->0) [f(a+h) - f(a)] / h
f'(a) = a બિંદુએ વિકલજ; h = સ્વતંત્ર ચલમાં પરિવર્તન. · SI: એકમહીન · વિકલજ અસ્તિત્વ ધરાવે તે માટે ડાબી અને જમણી બાજુ s સીમાઓ સમાન અને ફાઇનાઇટ હોવી જોઈએ.
બીજું વિકલજ: f''(x) = d/dx [f'(x)]
f''(x) = બીજું વિકલજ; d/dx = x ની સાપેક્ષે વિકલન. · SI: એકમહીન · જ્યારે f'(x) વિકલનીય હોય.
ઘાતાંકીય વિધેયનું વિકલન: d/dx [x^n] = n·x^(n-1)
n = કોઈપણ વાસ્તવિક સંખ્યા; x = ચલ. · SI: એકમહીન · x > 0 જો n ભાગાકાર અથવા ઋણ હોય; અન્યથા સર્વત્ર જ્યાં વ્યાખ્યાયિત.
ઘાતાંકીય વિધેય e^x નું વિકલન: d/dx [e^x] = e^x
e = પ્રાકૃતિક લઘુગણકનો આધાર (~2.718); x = ચલ. · SI: એકમહીન · સર્વત્ર.
સામાન્ય ઘાતાંકીય વિધેય a^x નું વિકલન: d/dx [a^x] = a^x · ln(a)
a = ધન અચળાંક (a ≠ 1); ln(a) = a નું પ્રાકૃતિક લઘુગણક. · SI: એકમહીન · a > 0, a ≠ 1.
પ્રાકૃતિક લઘુગણક વિધેયનું વિકલન: d/dx [ln x] = 1/x
ln x = પ્રાકૃતિક લઘુગણક; x > 0. · SI: એકમહીન · x > 0.
સામાન્ય લઘુગણક વિધેય log_a x નું વિકલન: d/dx [log_a x] = 1/(x · ln(a))
a = આધાર (a > 0, a ≠ 1); x > 0. · SI: એકમહીન · x > 0, a > 0, a ≠ 1.
જ્યોમિતિક વિધેયોનું વિકલન: d/dx [√x] = 1/(2√x), d/dx [1/x] = -1/x², d/dx [|x|] = sign(x) for x≠0
√x = वर्गमूल; |x| = નિરપેક્ષ મૂલ્ય; sign(x) = ચિહ્ન વિધેય. · SI: એકમહીન · x > 0 for √x and 1/x; x ≠ 0 for |x|.
ત્રિકોણમિતિય વિધેયોનું વિકલન: d/dx [sin x] = cos x, d/dx [cos x] = -sin x, d/dx [tan x] = sec² x, d/dx [cot x] = -csc² x, d/dx [sec x] = sec x tan x, d/dx [csc x] = -csc x cot x
x = કોણ (રેડિયનમાં); sec, csc, cot = ત્રિકોણમિતિય વિપરીત વિધેયો. · SI: એકમહીન · x રેડિયનમાં; વિકલજનું અસ્તિત્વ માટે વિધેય વ્યાખ્યાયિત હોવું જોઈએ.
ત્રિકોણમિતિય વિપરીત વિધેયોનું વિકલન: d/dx [arcsin x] = 1/√(1-x²), d/dx [arccos x] = -1/√(1-x²), d/dx [arctan x] = 1/(1+x²), d/dx [arccot x] = -1/(1+x²), d/dx [arcsec x] = 1/(|x|√(x²-1)), d/dx [arccsc x] = -1/(|x|√(x²-1))
arcsin x = sin⁻¹ x; x = ચલ (-1 ≤ x ≤ 1 arcsin/arccos માટે). · SI: એકમહીન · આંતરિક વ્યાપ્તિ અનુસાર: arcsin/arccos માટે |x|<1, arctan/arccot માટે સર્વત્ર, arcsec/arccsc માટે |x|>1.
ચેઇન રૂલ (સંયુક્ત વિધેયનું વિકલન): d/dx [f(g(x))] = f'(g(x)) · g'(x) અથવા dy/dx = dy/du · du/dx, જ્યાં u = g(x)
f, g = વિધેયો; y = બહારનું વિધેય; u = આંતરું વિધેય. · SI: એકમહીન · g(x) વિકલનીય હોય અને f(y) y=g(x) પર વિકલનીય હોય.
ગુણાકાર નિયમ: d/dx [u(x)·v(x)] = u'(x)·v(x) + u(x)·v'(x)
u(x), v(x) = વિકલનીય વિધેયો. · SI: એકમહીન · u અને v બંને વિકલનીય હોય.
ભાગાકાર નિયમ: d/dx [u(x)/v(x)] = [u'(x)·v(x) - u(x)·v'(x)] / [v(x)]²
u(x), v(x) = વિકલનીય વિધેયો; v(x) ≠ 0. · SI: એકમહીન · v(x) ≠ 0 અને u, v વિકલનીય.
સ્વતંત્ર ચલની સાપેક્ષે વિકલન: d/dx [x] = 1, d/dx [c] = 0 (c = અચળાંક)
x = ચલ; c = અચળાંક. · SI: એકમહીન · સર્વત્ર.
વિપરીત વિધેયનું વિકલન: 如果 y = f⁻¹(x) અને f(y) = x, then dy/dx = 1 / [f'(y)]
f⁻¹ = વિપરીત વિધેય; f'(y) = mūળ વિધેયનું વિકલજ. · SI: એકમહીન · f'(y) ≠ 0.
લુ'હોપિટલનો નિયમ (0/0 સ્વરૂપ): lim(x->a) f(x)/g(x) = lim(x->a) f'(x)/g'(x), જો f(a)=g(a)=0 અને right-hand limit exists
f, g = વિકલનીય વિધેયો; a = સીમા બિંદુ. · SI: એકમહીન · f, g a બિંદુએ સંતત અને વિકલનીય, f(a)=g(a)=0, અને lim f'/g' અસ્તિત્વ ધરાવતું હોય.
લુ'હોપિટલનો નિયમ (∞/∞ સ્વરૂપ): lim(x->a) f(x)/g(x) = lim(x->a) f'(x)/g'(x), જો |f|,|g| -> ∞ as x->a
f, g = વિકલનીય વિધેયો; a = સીમા બિંદુ (અનંત અથવા સીमित). · SI: એકમહીન · f અને g અનંત તરફ જાય અને lim f'/g' અસ્તિત્વ ધરાવતું હોય.
સંતત વિધેયોના ગુણધર્મો: જો f,g સંતત હોય, તો f±g, f·g, f/g (g≠0) પણ સંતત. સંયુક્ત વિધેય f∘g સંતત જો g સંતત અને f, g(x) પર સંતત હોય.
f, g = વિધેયો; ∘ = સંયોજન. · SI: એકમહીન · ઉપરોકત શરતો સંતોષાય.
વિકલનીય વિધેયનું સંતત હોવું: જો f, a બિંદુએ વિકલનીય હોય, તો f, a બિંદુએ સંતત પણ હોય. પરંતુ વિપરીત સાચું નથી.
f = વિધેય; a = બિંદુ. · SI: એકમહીન · a બિંદુએ વિકલનીયતા.
પેરામેટ્રિક સમીકરણોનું વિકલન: dy/dx = (dy/dt) / (dx/dt), જો dx/dt ≠ 0
x = f(t), y = g(t); t = પરિમાણ. · SI: એકમહીન · f, g વિકલનીય અને dx/dt ≠ 0.
આંશિક વિકલન (પ્રારંભિક સ્તર): જો z = f(x,y) હોય, તો ∂z/∂x = d/dx[f(x,y)] જ્યારે y અચળ, ∂z/∂y = d/dy[f(x,y)] જ્યારે x અચળ.
∂ = આંશિક વિકલન ચિહ્ન. · SI: એકમહીન · બહુચલ વિધેયો માટે.

🔗 સંબંધો

  • વિકલનીયતા ⇒ સંતતતા, પરંતુ સંતતતા ⇏ વિકલનીયતા (ઉદા. |x| at x=0).
  • લુ'હોપિટલનો નિયમ સીમાની ગણતરી માટે વિકલજનો ઉપયોગ કરે છે, પરંતુ તે ફક્ત 0/0 અથવા ∞/∞ અનિર્ધારિત સ્વરૂપો માટે લાગુ પડે છે.
  • ચેઇન રૂલ એ ગુણાકાર અને વિપરીત નિયમો સાથે જોડાયેલું છે: ઉદા. d/dx[e^{g(x)}] = e^{g(x)}·g'(x).
  • ત્રિકોણમિતિય વિપરીત વિધેયોના વિકલન સૂત્રો ત્રિકોણમિતિય વિધેયોના વિકલન સૂત્રોથી વ્યુત્પન્ન થાય છે.
  • અચળાંકનો વિકલજ શૂન્ય હોય છે, જે વિકલનના રેખીય સ્વરૂપને કારણે મહત્વપૂર્ણ છે.

🎯 ટ્રિક્સ

વિકલન પહેલાં વિધેયનું સરળીકરણ કરો: ઉદા. (x²-1)/(x-1) ને (x+1) સ્વરૂપે લખી શકાય.
ચેઇન રૂલમાં 'બહારનું વિધેય' અને 'આંતરું વિધેય' ઓળખી નાખો; આંતરૂં વિધેયના વિકલનને અવગણશો તો ઝઘડો.
ત્રિકોણમિતિય વિપરીત વિધેયોના વિકલનમાં arcsin અને arccos ના સૂત્રોમાં વિરોધી ચિહ્નો હોય છે – યાદ રાખો: arcsin ધન, arccos ઋણ.
દ્વિપદી વિસ્તારનો ઉપયોગ કરીને જટિલ વિધેયોનું વિકલન સરળ બનાવી શકાય.
લુ'હોપિટલ લાગુ કરતી વખતે પહેલાં 0/0 અથવા ∞/∞ છે કે નહીં તપાસો; નહીંતર નિયમ લાગુ પડતો નથી.

⚠️ ભૂલો

સંતત વિધેયનું વિકલન લેતાં ચેઇન રૂલનું આંતરું વિકલન ભૂલવું (દા.ત. d/dx[sin(x²)] = cos(x²) લખવું, પરંતુ 2x ઉપેક્ષિત).
વિપરીત ત્રિકોણમિતિ વિધેયોના વિકલન સૂત્રમાં ચિહ્ન યાદ રાખવામાં ભૂલ (arccsc અને arcsec ના ચિહ્નો).
લુ'હોપિટલનો નિયમ બિનઅનિર્ધારિત સ્વરૂપો પર લાગુ કરવો (જેવું કે 1/0, ∞-∞, 0·∞).
સંતતતા માટે ડાબી અને જમણી બાજુ s સીમાઓ ચકાસવી જરૂરી છે, પરંતુ ઘણીવાર ફક્ત એક બાજુ જ તપાસવામાં આવે છે.
વિકલનીયતાની વ્યાખ્યામાં હ → 0 લેતી વખતે અંશ-છેદને સરળ રૂપમાં ન લખવો.
ઘાતાંકીય વિધેય a^x ના વિકલનમાં a^x·ln(a) માં ln(a) ઉપેક્ષિત કરવો.
ત્રિકોણમિતિય વિધેયોના વિકલનમાં x રેડિયનમાં હોવો જોઈએ, પરંતુ ડિગ્રીમાં ગણતરી કરવી.
ભાગાકાર નિયમમાં અંશ-છેદની ગોઠવણી ભૂલવી (u'v - uv' vs u'v + uv').
