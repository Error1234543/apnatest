અનુવર્તી ખંડ (Conic Sections)

🧪 GUJCET — Gujarati • Mathematics • Conic Sections

અધ્યાય — અનુવર્તી ખંડ (Conic Sections)
જ્યારે શંકુ (Cone) ને સમતલથી કપવામાં આવે ત્યારે જે વક્ર મળે છે તેને અનુવર્તી ખંડ કહે છે.
ચાર મૂળભૂત અનુવર્તી ખંડો છે — વૃત્ત (Circle), પરવલય (Parabola), જ્યાનખંડ (Ellipse), પરિવલય (Hyperbola).
બધા અનુવર્તી ખંડો દ્વિ-ઘાત સમીકરણ Ax² + Bxy + Cy² + Dx + Ey + F = 0 આકારના હોય છે.
શંકુનું સમીકરણ z² = x² + y² લેતા, y = k (સમતલ) થી કાપતા વિવિધ વક્રો મળે છે.
વિલગતાકોણ (Semi-vertical angle) α અને સમતલનો ઝુકાવ ββ = 90° → વર્તુળ, β > α → ઘનવલય, β = α → પરવલય, β < α → પરિવલય
📝 💡 GUJCET માં પ્રમાણિત સમીકરણો + કેન્દ્ર, નિર્દેશિકા, ઉદ્ગામી રેખા પર આધારિત પ્રશ્નો આવે છે.
વૃત્ત (Circle)
વૃત્ત એ બિંદુઓનો સમૂહ છે જે કોઈ ચોક્કસ બિંદુ (કેન્દ્ર) થી સમાન અંતરે (ત્રિજ્યા) હોય છે.
વાસ્ટાન (Standard) સમીકરણ: x² + y² = r², જ્યાં કેન્દ્ર C(0,0) અને ત્રિજ્યા = r
સામાન્ય સમીકરણ: x² + y² + 2gx + 2fy + c = 0 કેન્દ્ર C(−g, −f), ત્રિજ્યા r = √(g² + f² − c)
જો વ્યાસના અંત્યબિંદુઓ (a,b) અને (c,d) જાણીતા હોય, તો વૃત્તનું સમીકરણ: (x−a)(x−c) + (y−b)(y−d) = 0
વૃત્ત એ વિશિષ્ટ સંજ્ઞાવાળો ઘનવલય છે (એકસમાનતા e = 0).
પરિઘ = 2πr, ક્ષેત્રફળ = πr²
ત્રિજ્યા, સ્પર્શક (Tangent) અને મહાસ્પર્શિકા (Normal): મહાસ્પર્શિકા હંમેશા કેન્દ્રમાંથી પસાર થાય છે. સ્પર્શક ત્રિજ્યાને લંબ હોય છે.
📝 ⚠ g, f, c ના ચિન્હો સાવધાનથી લેવા — કેન્દ્ર (−g, −f) બિંદુ છે.
અનુવર્તી ખંડની વ્યાખ્યા — ઉત્કેન્દ્રતા (Eccentricity)
એક નિશ્ચિત બિંદુ (ઉત્કેન્દ્ર / Focus) અને એક નિશ્ચિત સરળ રેખા (નિર્દેશિકા / Directrix) થી સમાનુપાતમાં ગતિ કરતા બિંદુના માર્ગને અનુવર્તી ખંડ કહે છે.
ઉત્કેન્દ્રતા e = SP / PM (જ્યાં SP = ઉત્કેન્દ્રથી અંતર, PM = નિર્દેશિકાથી અંતર)
e = 0 → વૃત્ત, e < 1 → ઘનવલય, e = 1 → પરવલય, e > 1 → પરિવલય
ઉત્કેન્દ્રતા (e) એ અનુવર્તી ખંડનું સ્વરૂપ નક્કી કરતી મૂળભૂત મૂળાંક છે.
ઉત્કેન્દ્રતા e ની કિંમતવક્રનો પ્રકાર નક્કી કરે છે
પરવલય (Parabola)
e = 1વાળો અનુવર્તી ખંડ પરવલય છે. તે બે શાખાઓ ધરાવતો ખુલ્લો વક્ર છે.
પ્રમાણિત પરવલય: y² = 4ax ઉત્કેન્દ્ર F(a, 0), નિર્દેશિકા x = −a, ઉદ્ગામી રેખા (Latus Rectum) = 4a
બીજા પ્રમાણિત સ્વરૂપો: y² = −4ax (ઉત્કેન્દ્ર (−a, 0)) x² = 4ay (ઉત્કેન્દ્ર (0, a)) x² = −4ay (ઉત્કેન્દ્ર (0, −a))
ઉદ્ગામી રેખા (Latus Rectum): ઉત્કેન્દ્રમાંથી પસાર થતી નિર્દેશિકાને લંબરૂપ જીવા. દરેક પરવલય માટે તેની લંબાઈ 4a હોય છે.
લંબજીવા (Focal chord) ના સરમુસદસ્ય (Parametric) સ્વરૂપ: P(at², 2at) સ્વરૂપે લખી શકાય. t = અનુપરાપરણ
સ્પર્શક (Tangent): y² = 4ax પર બિંદુ (x₁, y₁) આગળ स्पर्शक: yy₁ = 2a(x + x₁)
y² = 4ax માં, બિંદુ (at², 2at) આગળનો સ્પર્શક yy₁ = 2a(x+x₁) → t માંથી બહાર કાઢી: ty = x + at²
સ્પર્શકનું પ્રમાણ: y = mx + a/m (જ્યાં m ≠ 0) આ પ્રમાણ માટે m = a/y₁ મૂકતા સ્પર્શક મળે.
બહિર્સ્પર્શક (Normal): બિંદુ t પર, નીચે મુજબ y − 2at = −t(x − at²)
📝 📌 y² = 4ax પ્રમાણ મેળવવા m = a/t સૂત્ર યાદ રાખો — આ GUJCET માં વારંવાર આવે છે.
ઘનવલય (Ellipse)
e < 1 (શૂન્ય સિવાય) ધરાવતા અનુવર્તી ખંડને ઘનવલય કહે છે. તે એક બંધ વક્ર છે.
પ્રમાણ સમીકરણ: x²/a² + y²/b² = 1, જ્યાં a > b મહાઅક્ષ (Major axis) = 2a, લઘુઅક્ષ (Minor axis) = 2b
ઉત્કેન્દ્ર F(ae, 0) અને F'(−ae, 0); નિર્દેશિકાઓ: x = a/e અને x = −a/e
u = 1 − e², jયાં a² − b² = a²e² ⇒ e = √(a²−b²)/a
ઘનવલય પરના કોઈ પણ બિંદુ P માટે PF + PF' = સદા 2a (સ્થિરાંક).
ઉદ્ગામી રેખા (Latus Rectum): LR = 2b²/a (દરેક ઉત્કેન્દ્ર માટે અલગ, પરંતુ લંબાઈ સમાન)
લંબજીવાના સરમુસદસ્ય (Parametric) સ્વરૂપ: P(a cos θ, b sin θ), જ્યાં θ = ઉત્પ્રેરણાકોણ (Eccentric anomaly)
સ્પર્શક: બિંદુ (x₁, y₁) આગળ xx₁/a² + yy₁/b² = 1
બહિર્સ્પર્શક: (xx₁/a²) − (yy₁/b²) = ... પ્રમાણ બહિર્સ્પર્શકના સ્વરૂપને અનુસરે.
b² = a²(1 − e²)જ્યારે e → 0, b → a, ઘનવલય → વૃત્ત બને
📝 ⚠ LR = 2b²/a યાદ રાખો — GUJCET માં સીધો સૂત્ર પ્રશ્ન આવે છે.
પરિવલય (Hyperbola)
e > 1 ધરાવતા અનુવર્તી ખંડને પરિવલય કહે છે. તે બે અલગ અલગ શાખાઓ ધરાવે છે.
પ્રમાણ સમીકરણ: x²/a² − y²/b² = 1 ઉત્કેન્દ્ર (ae, 0), નિર્દેશિકા x = a/e
મહાઅક્ષ (Transverse axis) = 2a, લઘુઅક્ષ (Conjugate axis) = 2b
e = √(1 + b²/a²) અથવા b² = a²(e² − 1)
પરિવલય પરના કોઈ પણ બિંદુ P માટે |PF − PF'| = સદા 2a (સ્થિરાંક).
ઉદ્ગામી રેખા (Latus Rectum): LR = 2b²/a
લંબજીવાના સરમુસદસ્ય (Parametric) સ્વરૂપ: P(a sec θ, b tan θ)
અસીમ્ટોટ્સ (Asymptotes): y = ±(b/a)x — પરિવલય આ રેખાઓને અનંત પર સ્પર્શે છે.
સ્પર્શક: બિંદુ (x₁, y₁) આગળ xx₁/a² − yy₁/b² = 1
અસીમ્ટોટ્સનું સમીકરણ બરોબર પરિવલયના પ્રમાણ સમીકરણ જમણી બાજુ 0 કરીને મળે છે. x²/a² − y²/b² = 0
વિકર્ણ પરિવલય (Rectangular/Hyperbola): a = b હોય ત્યારે x² − y² = a², e = √2
ઘનવલય (e<1)વૃત્ત (e=0) અને પરિવલય (e>1) વચ્ચેનો વિચલન ગુણોત્તર ઉત્કેન્દ્રતા છે
📝 📌 પરિવલયમાં અસીમ્ટોટ્સ હંમેશા જોડીમાં હોય. GUJCET માં અસીમ્ટોટ્સનું સમીકરણ મેળવવાનું પ્રશ્ન આવે છે.
સંકલન — તુલનાત્મક સારાંશ
વૃત્ત: x² + y² = r² પરવલય: y² = 4ax ઘનવલય: x²/a² + y²/b² = 1 પરિવલય: x²/a² − y²/b² = 1
ઉત્કેન્દ્રતાની કિંમતો: • વૃત્ત: e = 0 • ઘનવલય: 0 < e < 1 • પરવલય: e = 1 • પરિવલય: e > 1
બધા પ્રમાણ સમીકરણો (a > b > 0) એ x અને y માં દ્વિઘા પદો ધરાવે છે; xy પદ (B = 0) નથી.
ઉદ્ગામી રેખા (LR) ની લંબાઈ: • પરવલય: 4a • ઘનવલય: 2b²/a • પરિવલય: 2b²/a
સામાન્ય દ્વિઘા સમીકરણ: Ax² + Bxy + Cy² + Dx + Ey + F = 0 B² − 4AC < 0 → ઘનવલય B² − 4AC = 0 → પરવલય B² − 4AC > 0 → પરિવલય
📝 💡 GUJCET માં B² − 4AC નો ભેદ (Discriminant) વાપરીને વક્રની ઓળખ કરવાના પ્રશ્નો આવે છે.
અપગર્ભિત અનુવર્તી ખંડ (Degenerate Conics)
જ્યારે સમતલ શંકુના શિરોબિંદુમાંથી પસાર થાય, ત્યારે અપગર્ભિત (Degenerate) અનુવર્તી ખંડ મળે છે.
ત્રણ પ્રકારના અપગર્ભિત અનુવર્તી ખંડો મળે છે: • એકલ બિંદુ (Point): Sમતલ શિરોબિંદુમાંથી પસાર થાય અને ફક્ત શિરોબિંદુ મળે. • એક જીવા ( intersecting lines): Sમતલ શંકુની બંને શાખાઓને છેદે. • જોડાયેલી રેખાઓ (Parallel lines): special case.
અપગર્ભિત કેસોમાં વક્ર 'ખર્ચાળ' બની જાય છે — બિંદુ, રેખા, અથવા ખાલી જગ્યા.
ઉદાહરણ: x² + y² = 0 → ફક્ત બિંદુ (0,0) (વાસ્તવિક રેખાઓ નથી) x² − y² = 0 → y = x અને y = −x (અક્ષો પર રેખાઓ)
GUJCET માં આ ભાગ હલકો ગણાય છે, પરંતુ ખાલી જવાબ/નિષ્કર્ષ જોઇએ.
📝 📌 અપગર્ભિત કેસો B²−4AC ના મૂલ્ય પર આધારિત — આ રેખાંશની ઓળખ માટે ઉપયોગી.
GUJCET યોગ્ય અભ્યાસ ટિપ્સ
સૌ પ્રથમ પ્રમાણ સમીકરણો અને ઉત્કેન્દ્રતાના સંબંધ સારી રીતે યાદ કરો.
ઉદ્ગામી રેખા (LR = 4a, 2b²/a) ના સૂત્રો GUJCET માં સીધા આવે છે — ભૂલ ન કરવી.
સ્પર્શક અને બહિર્સ્પર્શકના સૂત્રો ત્રણેય અનુવર્તી ખંડો માટે બરાબર બનાવો. ધન (+) → ઘનવલય, ઋણ (−) → પરિવલય, સમાન સૂત્ર પરવલય માટે.
પરમ્યુટરી (Parametric) સ્વરૂપ (at²,2at)/(a cosθ, b sinθ)/(a secθ, b tanθ) યાદ રાખો — પ્રશ્નો ઝડપથી ઉકેલાય છે.
સરમુસદસ્ય સ્વરૂપ યાદબંધી: પરવલય: (at², 2at) ઘનવલય: (a cos θ, b sin θ) પરિવલય: (a sec θ, b tan θ)
GUJCET માં 50%+ પ્રશ્નો સીધા સૂત્ર પર આધારિત હોય છે — પ્રમાણ સમીકરણોના ચિન્હો (±) માં ભૂલ ન કરવી.
📝 🔑 અંતિમ સૂચન: ઘનવલય અને પરિવલયના સમીકરણો વચ્ચેના ભેદ (+/−) ને ધ્યાનથી વાંચો.
