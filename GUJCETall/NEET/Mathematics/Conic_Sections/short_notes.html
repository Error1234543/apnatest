અનુવર્તી આયાત — ટૂંકી નોટ (રેવિઝન)

🧪 GUJCET — Gujarati • Mathematics • Conic Sections

📘 વ્યાખ્યાઓ

  • અનુવર્તી આયાત: બિંદુનો બિમ્બ કેન્દ્રથીના અંતર અને નિશ્ચિત રેખાથીના અંતરનો ગુણોત્તર (ઉતકેન્દ્રતા e) અચળ હોય ત્યારે બનતો માર્ગ.
  • વર્તુળ: સમતલમાંના એવા બિંદુઓનો સમૂહ કે જે કક્ષાકેન્દ્રથી સમાન અંતરે હોય.
  • પરવલય: e = 1 ધરાવતી અનુવર્તી આયાત.
  • ઉપવલય: 0 ≤ e < 1 ધરાવતી અનુવર્તી આયાત.
  • અતિપરવલય: e > 1 ધરાવતી અનુવર્તી આયાત.
  • નાભિચ્યુત: પરવલય/ઉપવલય/અતિપરવલયનો એક કેન્દ્રબિંદુ.
  • નાભિસ્પર્શિકા: નાભિમાંથી પસાર થતી અને મુખઅક્ષને લંબરૂપ દોરેલી જીવા.
  • નાભિઅંતર: ઉપવલય/અતિપરવલયના કોઈ પણ બિંદુથી નાભિની દૂરી.
  • પ્રસાધક રેખા: નાભિની સાથે સંકળાયેલી નિશ્ચિત રેખા જે ઉતકેન્દ્રતા વ્યાખ્યામાં વપરાય છે.
  • નાભિસ્પર્શિકા ચર: પરવલય પરના બિંદુએ દોરેલી સ્પર્શિકા અને નાભિસ્પર્શિકા વચ્ચેનું કોણ 90° હોય છે.

⚡ સૂત્રો

  • વર્તુળનું પ્રમાણિત સમીકરણ: (x−h)² + (y−k)² = r²
  • વર્તુળનું સામાન્ય સમીકરણ: x² + y² + 2gx + 2fy + c = 0; કેન્દ્ર(−g, −f), ત્રિજ્યા √(g²+f²−c)
  • વ્યાસરૂપ સમીકરણ: (x−x₁)(x−x₂) + (y−y₁)(y−y₂) = 0
  • પરવલય y² = 4ax: નાભિ(a,0), પ્રસાધક rેખા x = −a, નાભિસ્પર્શિકાની લંબાઈ 4a
  • પરવલય y² = −4ax: નાભિ(−a,0), પ્રસાધક rેખા x = a
  • પરવલય x² = 4ay: નાભિ(0,a), પ્રસાધક rેખા y = −a
  • પરવલય x² = −4ay: નાભિ(0,−a), પ્રસાધક rેખા y = a
  • ઉપવલય x²/a² + y²/b² = 1 (a>b): નાભિ(±ae,0), b² = a²(1−e²), નાભિસ્પર્શિકા = 2b²/a
  • ઉપવલય x²/a² + y²/b² = 1 (b>a): નાભિ(0,±be), a² = b²(1−e²), નાભિસ્પર્શિકા = 2a²/b
  • અતિપરવલય x²/a² − y²/b² = 1: નાભિ(±ae,0), b² = a²(e²−1), નાભિસ્પર્શિકા = 2b²/a
  • અતિપરવલય y²/a² − x²/b² = 1: નાભિ(0,±ae), બીજગણિતીય વિકર્ણો y = ±(a/b)x
  • સમપરિણામી અતિપરવલય xy = c²: નાભિ(±c,±c), ઉતકેન્દ્રતા √2, વિકર્ણો y = ±x
  • ઉપવલય માટે પ્રેક્ષકવૃત: x² + y² = a² + b²; સહાયક વૃત: x² + y² = a²
  • અતિપરવલય માટે પ્રેક્ષકવૃત: x² + y² = a² − b² (જો a>b હોય તો)
  • બે વર્તુળો x²+y²+2g₁x+2f₁y+c₁=0 અને x²+y²+2g₂x+2f₂y+c₂=0 સંગોળ છે ↔ 2g₁g₂+2f₁f₂ = c₁+c₂
  • બે વર્તુળોની મૂળરેખા: S₁ − S₂ = 0
  • ત્રિજ્યાબિંદુ t પર પરવલય y²=4ax પર બિંદુ: (at², 2at)
  • ત્રિજ્યાબિંદુ θ પર ઉપવલય x²/a²+y²/b²=1 પર બિંદુ: (a cosθ, b sinθ)
  • t₁, t₂ પરના બિંદુઓ જોડતી પરવલય જીવા: m = 2/(t₁+t₂)
  • parabola y²=4ax પર t પર સ્પર્શિકા: ty = x + at²; પરપ્રેરક: y − 2at = −t(x − at²)

⭐ મુખ્ય તથ્યો

  • ઉતકેન્દ્રતા e = 1: પરવલય; e < 1: ઉપવલય; e > 1: અતિપરવલય.
  • પરવલયનું શિરોબિંદુ મૂળબિંદુથી શરૂ થાય છે.
  • ઉપવલયની મુખઅક્ષની લંબાઈ 2a, લઘુઅક્ષ 2b.
  • અતિપરવલયની મુખઅક્ષ 2a, અભિલઘુઅક્ષ 2b.
  • સમપરિણામી અતિપરવલયનો ઉતકેન્દ્રતા √2 હોય છે.
  • પરવલય પરના બિંદુ (x,y) માટે નાભિઅંતર = x + a (જો y²=4ax).
  • ઉપવલય પરના બિંદુનું નાભિઅંતર: a ± ex (ધન/ઋણ નાભિ અનુસાર).
  • અતિપરવલય પરના બિંદુનું નાભિઅંતર: |ex ± a|.
  • ઉપવલયના બે નાભિઓ અને બે પ્રસાધક રેખાઓ હોય છે.
  • અતિપરવલયના દ્વિભાજક (Asymptotes): y = ±(b/a)x (x²/a² − y²/b² = 1 માટે).
  • અતિપરવલયના બીજગણિતીય વિકર્ણો પરવલયને સીમાતે સ્પર્શે છે.
  • જો પરવલય પરના ત્રણ બિંદુઓનો પરિવૃત્ત દોરવો હોય તો તેનું કેન્દ્ર પરવલયના અક્ષ પર હોય છે.
  • ઉપવલય/અતિપરવલયની નાભિસ્પર્શિકાની લંબાઈ નાભિઅક્ષના અનુપાતે બદલાય છે.
  • પરવલય પરના કોઈ પણ બિંદુએ દોરેલી સ્પર્શિકા નાભિસ્પર્શિકા અને અક્ષ વચ્ચેનું કોણ સમાન કરે છે.
  • મૂળબિંદુ પર શિરોબિંદુ ધરાવતા પરવલય: y² = 4ax, x² = 4ay, y² = −4ax, x² = −4ay.
  • vartul narahe koi bhi jiva vyaas hoy toh tyare tyare shirop bindu par 90° ko bante.

⚠️ સામાન્ય ભૂલો

  • ઉપવલયમાં b² = a²(1−e²) છે, પરંતુ અતિપરવલયમાં b² = a²(e²−1) છે — ચિહ્ન ધ્યાનથી લખવું.
  • ઉપવલયના સમીકરણમાં જો a > b હોય તો મુખઅક્ષ x-અક્ષ પર, જો b > a હોય તો y-અક્ષ પર — ગૂંચવણ ઊભી કરે છે.
  • નાભિસ્પર્શિકાની લંબાઈ 4a (પરવલય) અને 2b²/a (ઉપવલય/અતિપરવલય) છે; બંને સરખી લાગે પણ સૂત્ર અલગ છે.
  • પરવલય y² = 4ax માટે fokal દૂરી x + a છે, પરંતુ y² = −4ax માટે −x + a બને છે.
  • vartul narahe koi bhi jiva vyaas hoy toh tyare tyare shirop bindu par 90° ko bante — eshno anabhilokshyo ganto hai.
  • અતિપરવલય x²/a² − y²/b² = 1 ના વિપરીત અતિપરવલય x²/a² − y²/b² = −1 હોય છે, જે અભિલઘુઅક્ષની અક્ષ પર હોય છે.
  • સમપરિણામી અતિપરવલય xy = c² નું પ્રમાણિત સ્વરૂપ x²/a² − y²/a² = 1 નથી — તેને ફેરવવા પડે છે.
  • બે વર્તુળોના યોગ્ય છે તે શરત 2g₁g₂ + 2f₁f₂ = c₁ + c₂, પરંતુ ત્રિજ્યાઓનો સરવાળો/અંતર નહીં.
  • ઉપવલય અને અતિપરવલયની ઉતકેન્દ્રતા બંને 1 કરતા અલગ હોય પણ એક <1, બીજું >1 — વાક્યમાં ગૂંચવણ.
  • પરવલય પરના બિંદુ માટે સ્પર્શિકા ty = x + at² છે; પરપ્રેરક માટે y − 2at = −t(x − at²) છે, આ બે સૂત્રો ચૂકવવાનું.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • વર્તુળનું સામાન્ય સમીકરણ અને કેન્દ્ર-ત્રિજ્યા કાઢવાના પ્રશ્નો હંમેશા આવે છે.
  • પરવલય y² = 4ax ના નાભિઅંતર અને નાભિસ્પર્શિકાના પ્રશ્નો GUJCET માં હંમેશા.
  • ઉપવલય/અતિપરવલયની ઉતકેન્દ્રતા e શોધવી — સૂત્ર b² = a²(1−e²) અને b² = a²(e²−1).
  • બે વર્તુળો વચ્ચેની મૂળરેખા અને તેમના સંગોળnessની શરત.
  • પરવલય પર t₁, t₂ વડે દર્શાવેલી જીવા, નાભિજીવા, અને તેમના ગુણધર્મો.
  • ઉપવલયની પ્રેક્ષકવૃત અને સહાયક વૃતના પ્રશ્નો.
  • અતિપરવલયના બીજગણિતીય વિકર્ણો — સમીકરણ y = ±(b/a)x.
  • સમપરિણામી અતિપરવલય xy = c² ના પ્રશ્નો — તેનું નાભિ, ઉતકેન્દ્રતા, વિકર્ણો.
  • પરવલય પરના બિંદુએ દોરેલી સ્પર્શિકા અને પરપ્રેરકના સમીકરણ.
  • ઉપવલય x²/a² + y²/b² = 1 માટે બિંદુ P(x₁,y₁) ની સ્થિતિ ચકાસવાની શરત.
  • જીવાનો મધ્યબિંદુ આપેલ હોય તેવા પરવલય/ઉપવલય/અતિપરવલયના સમીકરણ માટે S₁ = T формула.
  • vartul, parabol, upavalay, atiparabol — ચારેયનો સંયુક્ત પ્રશ્ન આવે તો ઉતકેન્દ્રતા સૌથી મહત્વપૂર્ણ છે.
