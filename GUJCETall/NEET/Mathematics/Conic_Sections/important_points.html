વ્યાસખંડો — મહત્વના બિંદુઓ

🧪 GUJCET — Gujarati • Mathematics • Conic Sections

⭐ મહત્વના મુદ્દા

જ્યારે સમતલ દ્રવ્યમાન શંકુને કાપે તેથી મળતા વક્રને 'વ્યાસખંડો' કહે છે — વર્તુળ, પરવલય, લંબ વૃत्तજા (Ellipse), અતિબૃહ્મક (Hyperbola) એ ચાર પ્રકારનાં વ્યાસખંડો છે.
GUJCET માં આધારભૂત વ્યાખ્યા તરીકે પ્રશ્નો આવે છે.
વૃત્તનું પ્રમાણભૂત સમીકરણ (x − h)² + (y − k)² = r² થાય, જ્યાં કેન્દ્ર (h, k) અને ત્રિજ્યા r હોય. કેન્દ્ર મૂળબિંદુ પર હોય ત્યારે x² + y² = r².
વર્તુળ સંબંધિત સીધા ગાણિતિક પ્રશ્નો પુનરાવર્તનથી આવે છે.
વૃત્તનો સામાન્ય સ્વરૂપ x² + y² + 2gx + 2fy + c = 0 હોય, જેનું કેન્દ્ર (−g, −f) અને ત્રિજ્યા √(g² + f² − c) થાય. c < g² + f² હોય ત્યારે જ વાસ્તવિક વૃત્ત મળે.
સામાન્ય સ્વરૂપના ગુણધર્મો પર GUJCET માં ઘણા પ્રશ્નો પડે છે.
વૃત્તનો સ્પર્શક: બિંદુ (x₁, y₁) પર x² + y² = r² નો સ્પર્શક xx₁ + yy₁ = r² થાય. સામાન્ય વર્તુળ x² + y² + 2gx + 2fy + c = 0 માટે સ્પર્શક xx₁ + yy₁ + g(x + x₁) + f(y + y₁) + c = 0.
સ્પર્શકનું સમીકરણ GUJCET નો સ્થિર પ્રશ્ન છે.
સ્પર્શક રેખા y = mx + c વર્તુળ x² + y² = a² ને સ્પર્શે છે જો c² = a²(1 + m²) થાય — આ શરત ઘણા પ્રશ્નોમાં વપરાય છે.
સ્પર્શકની શરત ધરાવતા પ્રશ્નો પુનરાવર્તનથી આવે છે.
પરવલય (Parabola) નું પ્રમાણભૂત સમીકરણ y² = 4ax હોય છે, જ્યાં કેન્દ્ર (a, 0), નિયતિરેખા x = −a અને ઉક્ષ્ણજ્યા (Latus Rectum) ની લંબાઈ 4a થાય.
પરવલયના પ્રમાણભૂત સ્વરૂપ અને ગુણધર્મો GUJCET માં અત્યંત મહત્વપૂર્ણ છે.
y² = 4ax પરવલય પરના બિંદુ (at², 2at) પરનો સ્પર્શક ty = x + at² થાય અને સ્પર્શાંત (Normal) y − 2at = −t(x − at²) થાય.
સ્પર્શક/સ્પર્શાંત સંબંધિત પ્રશ્નો GUJCET માં ઘણા આવે છે.
વક્ર પરનું બિંદુ પરસ્પર બિંદુ (Focus) થી માપેલ અંતર અને નિયતિરેખા (Directrix) થી માપેલ અંતર સમાન હોય — આ પરવલયનો મૂળભૂત સદૃશિ ગુણધર્મ છે.
વ્યાખ્યા આધારિત પ્રશ્નોમાં આ ગુણધર્મનો ઉપયોગ થાય છે.
લંબ વૃत्तજ (Ellipse) નું પ્રમાણભૂત સમીકરણ x²/a² + y²/b² = 1 (a > b) થાય, જ્યાં કેન્દ્રબિંદુઓ (±ae, 0), ઉક્ષ્ણજ્યાની લંબાઈ 2b²/a અને નિયતિરેખાઓ x = ±a/e હોય.
લંબ વૃत्तજના પ્રમાણભૂત સ્વરૂપ અને અચળાંકો GUJCET માં નિયમિત પ્રશ્નો આવે છે.
લંબ વૃत्तજમાં b² = a²(1 − e²) થાય, જ્યાં e એ ઉતકેન્દ્રતા (Eccentricity) છે. e < 1 હોય છે અને e = 0 હોય ત્યારે લંબ વૃत्तજ વર્તુળ બની જાય છે.
ઉતકેન્દ્રતાની ગણતરી કરતા પ્રશ્નો GUJCET માં મહત્વપૂર્ણ છે.
અતિબૃહ્મક (Hyperbola) નું પ્રમાણભૂત સમીકરણ x²/a² − y²/b² = 1 થાય, જ્યાં ઉતકેન્દ્રતા e > 1 હોય છે અને b² = a²(e² − 1) થાય.
અતિબૃહ્મક અને લંબ વૃत्तજ વચ્ચેના સમીકરણોની તુલના GUJCET માં આવે છે.
અતિબૃહ્મકની ઉત્કેન્દ્રિકાઓ (Asymptotes) y = ±(b/a)x થાય અને અતિબૃહ્મકની ઉત્કેન્દ્રિકાઓ તેના પ્રમાણભૂત સમીકરણના સમમાનરૂપે મળે છે.
ઉત્કેન્દ્રિકાઓ પરના પ્રશ્નો GUJCET માં પુનરાવર્તનથી આવે છે.
ઉતકેન્દ્રતા (Eccentricity, e) દરેક વ્યાસખંડનું વિશિષ્ટ ગુણધર્મ છે: વર્તુળ માટે e = 0, પરવલય માટે e = 1, લંબ વૃत्तજ માટે 0 < e < 1, અને અતિબૃહ્મક માટે e > 1.
e ની કિંમત પર આધારિત પ્રશ્નો GUJCET માં ઘણા આવે છે.
ઉક્ષ્ણજ્યા (Latus Rectum): વ્યાસખંડની કેન્દ્રબિંદુ (Focus) આગળ નિયતિરેખાને લંબરૂપે ઉત્તેરતી જીવા; પરવલય માટે લંબાઈ 4a, લંબ વૃत्तજ માટે 2b²/a, અતિબૃહ્મક માટે 2b²/a થાય.
ઉક્ષ્ણજ્યાની લંબાઈની ગણતરી GUJCET માં સીધો પ્રશ્ન છે.
દૂરબીજા (Conjugate) વૃत्तજ: x²/a² − y²/b² = 1 ની દૂરબીજા લંબ વૃत्तજ x²/a² − y²/b² = −1 એટલે y²/b² − x²/a² = 1 થાય. બંનેની ઉત્કેન્દ્રિકાઓની વચ્ચે સંબંધ છે.
દૂરબીજા વૃत्तજ પરના પ્રશ્નો GUJCET માં આવે છે.
સામાન્ય વર્તુળનું સમીકરણ x² + y² + Dx + Ey + F = 0 હોય, જેની ત્રિજ્યા √[(D/2)² + (E/2)² − F] થાય. D² + E² − 4F > 0 હોય તો જ વૃત્ત અસ્તિત્વ ધરાવે.
સામાન્ય સ્વરૂપની ગણતરીઓ GUJCET માં નિયમિત પ્રશ્નો આવે છે.
બે વર્તુળો પરસ્પર છેદે છે, સ્પર્શે છે, અથવા પ્રભાવિત નથી — આ ચારેય કિસ્સાઓ કેન્દ્રઓ વચ્ચેનું અંતર અને ત્રિજ્યાઓના સંઘ પર આધારિત છે.
વર્તુળોની સંબંધિત ગણતરીઓ GUJCET માં આવે છે.
પરવલય y² = 4ax પરના બે બિંદુઓ P(ap², 2ap) અને Q(aq², 2aq) ને જોડતી જીવા PQ નો મધ્યબિંદુ R માટેનું સ્થાનપથ (Locus) y² = 2a(x − a) થાય.
સ્થાનપથ (Locus) પ્રશ્નો GUJCET માં પુનરાવર્તનથી આવે છે.
લંબ વૃत्तજ અને અતિબૃહ્મક બંનેમાં ઉત્કેન્દ્રિકા e અને e' વચ્ચે 1/e² + 1/e'² = 1 સાચું સાબિત થાય જ્યારે બંને વ્યાસખંડો સમકેન્દ્રીય (Confocal) હોય.
આ ગુણધર્મ GUJCET માં ઊંચુ મહત્વ ધરાવતો પ્રશ્ન હોઈ શકે છે.
વક્ર પરના કોઈ પણ બિંદુ પરનો સ્પર્શક અને સ્પર્શાંત એકબીજાને લંબરૂપે છેદે છે — આ ગુણધર્મ પરવલય, લંબ વૃत्तજ અને અતિબૃહ્મક બધા માટે સાચું છે.
સ્પર્શક-સ્પર્શાંત લંબ ગુણધર્મ પર આધારિત પ્રશ્નો GUJCET માં આવે છે.
સમકક્ષ (Rectangular / Equilateral) અતિબૃહ્મક એટલે a = b વાળો અતિબૃહ્મક xy = c² સ્વરૂપે પણ લખી શકાય, જેની ઉત્કેન્દ્રતા √2 થાય.
સમકક્ષ અતિબૃહ્મક સંબંધિત પ્રશ્નો GUJCET માં ઓળખવાપાત્ર છે.
પરવલય y² = 4ax માટે foci જીવા (Focal Chord) ના સિરે (at₁², 2at₁) અને (at₂², 2at₂) લેખે તો t₁t₂ = −1 થાય — આ શરત foci જીવાઓ પરના પ્રશ્નોમાં ખૂબ ઉપયોગી છે.
foci જીવા શરત GUJCET માં ગાણિતિક પ્રશ્નો માટે મહત્વપૂર્ણ છે.
લંબ વૃत्तજ x²/a² + y²/b² = 1 નો બહિર્મુખ (External) ભાગમાંથી સ્પર્શકો દોરી શકાય; અતિબૃહ્મક x²/a² − y²/b² = 1 ના કિસ્સામાં યામ પ્રણાલીને ધ્યાનમાં રાખીને ચકાસણી કરવી જરૂરી છે.
સ્પર્શકોની અસ્તિત્વ શરતો GUJCET માં ઊંચા સ્તરના પ્રશ્નોમાં આવે છે.
