વિકલનના ઉપયોગો — મહત્વના મુદ્દાઓ

🧪 GUJCET — Gujarati • Mathematics • Application of Derivatives

⭐ મહત્વના મુદ્દા

સદિશ ફલન f(x) નું x = a બિંદુએ વિકલિત f'(a) એ સ્પર્શકની ઢાળ આપે છે: સ્પર્શકનું સમીકરણ y − f(a) = f'(a)(x − a), પ્રતિલંબનું સમીકરણ y − f(a) = −1/f'(a) · (x − a) (જ્યાં f'(a) ≠ 0).
સ્પર્શક-પ્રતિલંબ સંબંધિત પ્રશ્નો GUJCET માં સતત આવે છે.
f(a) ≠ 0 હોય ત્યારે x-અક્ષ પર અંતરખંડ = a − f(a)/f'(a) અને y-અક્ષ પર અંતરખંડ = f(a) − a·f'(a). આ અંતરખંડોનો ઉપયોગ ટ્રાયેન્ગલનું ક્ષેત્રફળ શોધવા માટે થાય છે.
અંતરખંડ અને ત્રિભુજના ક્ષેત્રફળના પ્રશ્નો ગાઉરી બહુવિકલ્પી પ્રશ્નોમાં પુષ્કળ આવે છે.
ચલ ગતિ (velocity) v(t) = ds/dt અને ત્વરણ (acceleration) a(t) = dv/dt = d²s/dt² છે. યોગ્ય ચિહ્ન વિશેષ રીતે ધ્યાન આપવું જરૂરી છે.
વિજ્ઞાન સંબંધી એપ્લાયડ પ્રશ્નો GUJCET માં નિયમિત આવે છે.
f(x) એ સંતત અને (a, b) પર વિકલનીય હોય, તો લાગ્રાંજના મધ્યમાન પ્રમેય મુજબ: f(b) − f(a) = f'(c)(b − a), જ્યાં c ∈ (a, b).
મધ્યમાન પ્રમેયનો પ્રશ્ન સૈદ્ધાંતિક અને સંખ્યાત્મિક બંને પ્રકારે GUJCET માં આવે છે.
વધારો-હ્રાસ (Increase/Decrease) નિયમ: f'(x) > 0 હોય તો f(x) વધતું, f'(x) < 0 હોય તો f(x) હ్రાસતું, અને f'(x) = 0 હોય તો f અચળ (સમતલ) છે. અંતરાલ (interval) નક્કી કરવા માટે આ નિયમો મૂળભૂત છે.
વધારો-હ્રાસના અંતરાલ શોધવાના પ્રશ્નો GUJCET માં આવશ્યક વિષય છે.
સ્થિરબિંદુ (Stationary point): f'(a) = 0. પ્રથમ વિકલિત પરીક્ષણ: f'(x) ધન થી ઋણ બને → મહત્તમ; ઋણ થી ધન બને → લઘુત્તમ. દ્વિતીય વિકલિત પરીક્ષણ: f''(a) < 0 → મહત્તમ, f''(a) > 0 → લઘુત્તમ.
મહત્તમ-લઘુત્તમ શોધવાના પ્રશ્નો ગાઉરી અત્યંત મહત્વપૂર્ણ છે અને બે તબક્કામાં આવે છે.
વક્રની વક્રતા (Convexity): f''(x) > 0 → વક્ર ઉપર તરફ (concave up); f''(x) < 0 → વક્ર નીચે તરફ (concave down). વક્રતા બદલાતું બિંદુ (Inflection point): f''(x) = 0 અને f'' નું ચિહ્ન બદલાય.
વક્રતા અને inflection point નો પ્રશ્ન GUJCET માં થાય છે.
વ્યાપ્તિ (Maximum/Minimum) શોધવાની પદ્ધતિ: (1) f'(x) = 0 માટે x શોધો (2) f''(x) નો ચેક (3) અંત્યબિંદુઓની તપાસ કરો (4) ગ્રાફના સ્વરૂપ મુજબ મહત્તમ/લઘુત્તમ મૂલ્ય નક્કી કરો.
આ પદ્ધતિની રોબોટિક અમલગતન પરીક્ષામાં પ્રશ્નો ઉકેલવા માટે આવશ્યક છે.
પોલર વક્ર r = f(θ) માટે: સ્પર્શકની ઢાળ = tan ψ, જ્યાં tan ψ = r/(dr/dθ). સ્પર્શકનું ધ્રુવીય સમીકરણ θ = α પણ મહત્વનું છે.
પોલર વક્રના સ્પર્શક-પ્રતિલંબના પ્રશ્નો GUJCET માં સીમિત પરંતુ આવે છે.
સાપેક્ષ દર (Relative rate of change): dy/dt ÷ dx/dt = dy/dx. જો y = f(x) હોય, તો y નું x સાપેક્ષે સાપેક્ષ દર = (1/f(x)) · f'(x) = f'(x)/f(x).
આ ખ્યાલ GUJCET માં ઓછો પરંતુ ક્યારેક પ્રશ્ન આવે છે.
અચળ ગુણન ફલન (Constant function): f'(x) = 0 હોય તો f(x) = C (અચળ). વિપરીત: f'(x) = k (અચળ સંખ્યા) હોય તો f(x) = kx + C.
આ મૂળભૂત સિદ્ધાંત એપ્લાયડ પ્રશ્નોમાં સહાયક થાય છે.
વિકલ સમીકરણ ઉકેલવા માટે: dy/dx = g(x) · h(y) → ∫dy/h(y) = ∫g(x)dx. વિભાજ્ય ચલ (Separable variables) પદ્ધતિનો ઉપયોગ થાય છે.
ચલ વિભાજ્ય વિકલ સમીકરણો GUJCET માં સામાન્ય છે.
પ્રમેય 2 (Mean Value Theorem) નું ભૌમિતિક અર્થઘટન: વક્ર પર એક એવું બિંદુ c મળે છે કે જેને બિંદુઓ (a, f(a)) અને (b, f(b)) ને જોડતા જયાંથી ખેંચેલા જ્યાંન સ્પર્શક સમાંતર હોય.
ભૌમિતિક અર્થઘટન સંબંધી પ્રશ્નો GUJCET માં આવે છે.
બહુપદી ફલન f(x) = ax³ + bx² + cx + d નું મહત્તમ-લઘુત્તમ શોધવા માટે f'(x) = 0 → x = ક્વેડ્રેટિક સૂત્રે મળે. f''(x) = 6ax + 2b નો ઉપયોગ કરો.
ત્રિઘાતી બહુપદીના મહત્તમ-લઘુત્તમ GUJCET માં વારંવાર આવે છે.
વાસ્તવિક જીવન આધારિત ઉત્તમીકરણ (Optimization) પ્રશ્નો: ક્ષેત્રફળ મહત્તમ, ખર્ચ લઘુત્તમ, ઝડપ મહત્તમ/લઘુત્તમ. પ્રથમ f ને એક ચલમાં દર્શાવો, f' = 0, ચિહ્ન તપાસો, મૂલ્ય શોધો.
ઉત્તમીકરણ પ્રશ્નો GUJCET માં સૌથી મહત્વપૂર્ણ અને વારંવાર આવતા પ્રશ્નો છે.
f(x) = x² + 1/x² (x > 0) જેવા ફલનોનું લઘુત્તમ મૂલ્ય MVT કે અવકલન વડે મળે છે. AM-GM અસમતા: x² + 1/x² ≥ 2, લઘુત્તમ મૂલ્ય = 2.
AM-GM અથવા અવકલન વડે લઘુત્તમ શોધના પ્રશ્નો GUJCET માં આવે છે.
f(x) = e^x, sin x, cos x, log x, tan x જેવા પ્રમાણભૂત ફલનોના પ્રથમ અને દ્વિતીય વિકલિત યાદ રાખવા જરૂરી છે. e^x → e^x, sin x → cos x → −sin x, log x → 1/x → −1/x².
વિકલિત યાદ ન હોય તો ઉત્તમીકરણ અને મહત્તમ-લઘુત્તમ પ્રશ્નો ઉકેલવા અશક્ય છે.
ચાઈન રૂલ (Chain Rule): dy/dx = dy/du · du/dx. u = g(x), y = f(u) હોય. z = f(g(h(x))) → dz/dx = f'(g(h(x))) · g'(h(x)) · h'(x).
ચાઈન રૂલ વિના ઘણા વિકલન પ્રશ્નો ઉકેલી શકાતા નથી.
Implicit differentiation: xy = 1 → y' = −y/x. (x−a)² + (y−b)² = r² નું x વડે વિકલન કરતાં v = −(x−a)/(y−b) (સ્પર્શકની ઢાળ).
ગોળના સ્પર્શક-પ્રતિલંબના પ્રશ્નો GUJCET માં આવે છે.
ઉચ્ચ ક્રમના વિકલિતો: f'''(x), f⁴(x) વગેરે. Inflection point માટે f''(x) = 0 અને f'' નું ચિહ્ન બદલાવું જરૂરી છે (ફક્ત f'' = 0 પૂરતું નથી).
Inflection point ના પ્રશ્નો GUJCET માં આવે છે.
અવકલન બિંદુ (Point of non-differentiability): |x|, √x, x^(1/3) જેવા ફલનો કેટલાક બિંદુએ વિકલનીય નથી. તેવા બિંદુઓ પર મહત્તમ/લઘુત્તમ હોઈ શકે છે.
Non-differentiable points GUJCET માં ચાલાક પ્રશ્નો માટે મહત્વપૂર્ણ છે.
f(x) = ax² + bx + c (a > 0) નું લઘુત્તમ મૂલ્ય −D/(4a), જ્યાં D = b² − 4ac. f(x) = ax² + bx + c (a < 0) નું મહત્તમ મૂલ્ય −D/(4a).
વર્ગસમીકરણના શિરોબિંદુ સૂત્રની રચના GUJCET માં સીધો પ્રશ્ન આવે છે.
f(x) = sin x + cos x (0 ≤ x ≤ π/2): f'(x) = cos x − sin x = 0 → x = π/4. f''(π/4) = −√2 < 0 → મહત્તમ મૂલ્ય √2.
ત્રિકોણમિતીય ફલનોના મહત્તમ-લઘુત્તમ GUJCET માં આવે છે.
વક્રની લંબાઈ (Arc length): s = ∫ₐᵇ √(1 + (dy/dx)²) dx. વક્ર લંબાઈની ગણતરી GUJCET માં વારંવાર પુનરાવર્તન થાય છે.
અર્ક લંબાઈનું સૂત્ર GUJCET માં આવે છે.
