આવેશના વિકલનના ઉપયોગ (Application of Derivatives)

🧪 GUJCET — Gujarati • Mathematics • Application of Derivatives

અધ્યાય — આવેશના વિકલનના ઉપયોગ
આવેશના વિકલનનો મૂળભૂત વિચાર: f(x) માં ફેરફારનો દર = df/dx
📝 ધ્યાન રાખો: વિકલન એ 'ફેરફારના દર' નું માપ છે.
૧. આવેશ (Rate of Change)
જો y = f(x) હોય, તો x ના આપેલ મૂલ્ય C બિંદુએ y નો આવેશ = dy/dx|_(x=C) થાય.
dy/dx = lim_(Δx→0) [f(x+Δx) − f(x)] / Δx (આવેશ = સીમાઓનો મૂલ્ય)
પ્રતિબિંબ: v = ds/dt (વેગ = પ્રવાસનો આવેશ), a = dv/dt (પ્રવેગ = વેગનો આવેશ).
GUJCET tip: 'આવેશ' અને 'વેગ' વચ્ચેનો સંબંધ ઘણીવાર પ્રશ્નમાં छुપાયેલો હોય છે — પહેલા ઓળખો!
y = f(x)dy/dx = આવેશ
૨. સંબંધિત આવેશ (Related Rates)
જ્યારે બે અથવા વધુ ચલો t સાથે બદલાતાં હોય, ત્યારે એક ચલનો આવેશ શોધવા અન્ય ચલોના આવેશનો ઉપયોગ કરીએ.
પદ્ધતિ: (1) સમીકરણ લખો, (2) બંને બાજુનું t ની સાપેક્ષે વિકલન કરો, (3) આપેલ મૂલ્યો મૂકીને શોધો.
ત્રિજ્યા r = 3 cm અને dV/dt = 10 cm³/s હોય, તો dr/dt શોધો → V = (4/3)πr³ વાપરો.
dV/dt = 4πr² · (dr/dt) (ગોળાના ઘનફળ માટે)
📝 સંબંધિત આવેશના પ્રશ્નોમાં તમારે સામાન્ય રીતે એક જ સમીકરણથી બે ચલો વચ્ચેનો સંબંધ શોધવો પડે.
એક ચલનો આવેશબીજા ચલના આવેશ પર આધારિત
૩. આશ્રિત ફેરફાર (Approximation using Differentials)
જો Δx ખૂબ ઇન્દ્રિય (छोटो) હોય, તો Δy ≈ dy = f'(x)·dx.
f(x + Δx) ≈ f(x) + f'(x)·Δx (આશ્રિત ફેરફારનું સૂત્ર)
ઉદા. 1. વાસ્તવિક મૂલ્યની આસપાસની ગણતરી માટે આ પદ્ધતિ ખૂબ ઉપયોગી છે.
Δx નું મૂલ્ય 0.01 જેટલું નાનું હોય તો આશ્રિત ફેરફાર અત્યંત ચોકસાઈપૂર્વક મળે છે.
📝 GUJCET માં √4.01, (1.02)^3 જેવા પ્રશ્નો આશ્રિત ફેરફારથી ઉકેલાય છે.
dy = f'(x)dxΔy ≈ dy (જ્યારે dx નાનું હોય)
૪. સ્પર્શક અને અભિક્ષેપ (Tangent and Normal)
y = f(x) પર P(x₁, y₁) બિંદુએ સ્પર્શકનું સમીકરણ:
સ્પર્શક: y − y₁ = f'(x₁)(x − x₁)
અભિક્ષેપ એ સ્પર્શકને લંબરૂપે છે. તેનું સમીકરણ:
અભિક્ષેપ: y − y₁ = [−1/f'(x₁)] (x − x₁) (જ્યાં f'(x₁) ≠ 0)
f'(x₁) = 0 હોય તો સ્પર્શક આડી (horizontal) અને અભિક્ષેપ લંબરૂપ (vertical) હોય.
જો f'(x₁) અનંત (infinite) હોય, તો સ્પર્શક લંબરૂપ અને અભિક્ષેપ આડી હોય.
📝 સ્પર્શક અને વક્ર વચ્ચેનો ખૂણો θ = tan⁻¹|f'(x)| થાય.
મૂલ્યાંકન = dy/dxસ્પર્શકનું નમૂનું = f'(x₁)(x − x₁)
૫. યામભૂમિતિમાં સ્પર્શક-અભિક્ષેપના ઉપયોગો
સ્પર્શાંતરા (Tangential intercept): સ્પર્શક x-અક્ષ પર જે છેદે તે બિંદુ P − (x₁ − y₁/f'(x₁), 0)
અભિક્ષેપાંતરા (Normal intercept): અભિક્ષેપ x-અક્ષ પર જે છેદે તે બિંદુ P + (f'(x₁)y₁, 0)
લંબ અંતર (Length of perpendicular from origin to tangent) = |y₁ − x₁·f'(x₁)| / √(1 + [f'(x₁)]²)
સ્પર્શક અને અભિક્ષેપના ખંડોની લંબાઈ ગણતરીની રીતો મહત્વની છે.
📝 PYQ style: 'સ્પર્શકના ખંડોની લંબાઈ સમાન હોય તેવો વક્ર શોધો' — આવો પ્રશ્ન આવ્યો છે.
વાલ્યુ = m = dy/dxસ્પર્શક = (y − y₁) = m(x − x₁)
૬. મોનોટોનિક ફંક્શન (Monotonic Functions)
વધતું ફંક્શન (Increasing function): f'(x) > 0 એ सर्व x ∈ (a,b) માટે → f વધતું છે.
ઘટતું ફંક્શન (Decreasing function): f'(x) < 0 એ सर्व x ∈ (a,b) માટે → f ઘટતું છે.
અચળ ફંક્શન (Constant function): f'(x) = 0 એ सर्व x માટે → f અચળ છે.
f વધતું છે ⟺ f'(x) ≥ 0 ∀ x ∈ I, અને સતત અંતરાળ પર f'(x) ≠ 0
GUJCET tip: f'(x) = 0 બિંદુઓ 'સ્થિર બિંદુઓ' (stationary points) કહેવાય. તે ચોક્કસપણે વધતું/ઘટતું નક્કી કરવા ઉપયોગી.
📝 આંતરિક મૂલ્ય પ્રમેય (Mean Value Theorem) નો ઉપયોગ મોનોટોનિસિટી સાબિત કરવા માટે થાય.
f'(x) > 0f વધતું ફંક્શન
f'(x) < 0f ઘટતું ફંક્શન
૭. મહત્તમ અને લઘુત્તમ મૂલ્યો (Maxima and Minima)
સ્થાનિક મહત્તમ (Local Maximum): f'(c) = 0 અને f''(c) < 0 → c આગળ f નું સ્થાનિક મહત્તમ.
સ્થાનિક લઘુત્તમ (Local Minimum): f'(c) = 0 અને f''(c) > 0 → c આગળ f નું સ્થાનિક લઘુત્તમ.
પ્રથમ કક્ષાચ્છેદ નિયમ (First derivative test): 若 f'(x) > 0 → < 0, તો x=c : સ્થાનિક મહત્તમ 若 f'(x) < 0 → > 0, તો x=c : સ્થાનિક લઘુત્તમ
ଦ୍વિତୀୟ କକ୍ଷ ଛେଦ ନିୟମ (Second derivative test): f'(c)=0, f''(c)>0 → ସ୍ଥାନିକ ଲଘୁତ୍ତମ f'(c)=0, f''(c)<0 → ସ୍ଥାନିକ ମହତ୍ତମ f''(c)=0 → ଅସଫଳ (inconclusive)
GUJCET માં પ્રથમ કક્ષાચ્છેદ નિયમ વિશ્વાસપાત્ર છે; f''(c) = 0 હોય તો ફરી પ્રથમ નિયમ વાપરો.
વિશ્વ મહત્તમ/લઘુત્તમ (Absolute Max/Min): બંધ અંતરાળ [a,b] પર f ના સ્થાનિક મહત્તમ, લઘુત્તમ, અને છેડાના મૂલ્યો f(a), f(b) તુલના કરો.
વિશ્વ મહત્તમ = max{f(c₁), f(c₂), ..., f(a), f(b)} જ્યાં cᵢ સ્થિર બિંદુઓ
📝 છેડાના મૂલ્યો ભૂલશો નહીં — ઘણા વિદ્યાર્થીઓ તેને ભૂલી જાય છે.
f'(x) = 0સ્થિર બિંદુઓ (Critical points)
f''(c) < 0સ્થાનિક મહત્તમ
f''(c) > 0સ્થાનિક લઘુત્તમ
૮. મહત્તમ-લઘુત્તમની ગાણિતિક પ્રક્રિયા
પગલું 1: f'(x) = 0 સમીકરણ ઉકેલો → સ્થિર બિંદુઓ m₁, m₂, ... મેળવો.
પગલું 2: દરેક સ્થિર બિંદુએ f''(x) ની ચકાસણી કરો.
પગલું 3: f''(x) > 0 → લઘુત્તમ, f''(x) < 0 → મહત્તમ, f''(x) = 0 → પ્રથમ નિયમ વાપરો.
પગલું 4: વિશ્વ મહત્તમ/લઘુત્તમ માટે f(a) અને f(b) ની સરખામણી કરો.
f''(c) = 0 બિંદુએ 'બિન્દુ ફેરફાર' (point of inflection) હોઈ શકે — તે મહત્તમ/લઘુત્તમ નથી.
📝 GUJCET: 'f(x) = x³ − 3x + 2 ના મહત્તમ-લઘુત્તમ મૂલ્યો શોધો' — આવો પ્રશ્ન ફેબ્રુઆરી 2020 માં આવ્યો હતો.
f'(c) = 0, f''(c) = 0પરીક્ષા: પ્રથમ કક્ષાચ્છેદ નિયમ
૯. વાસ્તવિક જીવનમાં ઉપયોગો (Real-life Applications)
ઘનફળ મહત્તમ કરવું (Maximum volume): ડબ્બા, પીપettes, ટાંકીઓનું ડિઝાઇન.
કિંમત ઓછી કરવી (Minimum cost): ઉત્પાદન ખર્ચનું અનુકૂલન.
ઊંચાઈ/અંતર મહત્તમ કરવું (Maximum height/distance): પ્રક્ષેપણ (projectile motion).
v = u sin θ, R = u²sin(2θ)/g, H = u²sin²θ/(2g) — પ્રક્ષેપણ ગતિમાં મહત્તમ શ્રેણ θ = 45° પર.
GUJCET tip: 'બંધ ખુરશીનું મહત્તમ ક્ષેત્રફળ' અથવા 'ઘનકાઠિન્યનું મહત્તમ ઘનફળ' જેવા પ્રશ્નો બહુ આવે છે.
📝 અચળ પરિમિતિ (perimeter/perimeter) સમક્ષ લંબચોરસનું મહત્તમ ક્ષેત્રફળ = વર્ગ બને છે.
f'(x) = 0વ્યાવહારિક ઑપ્ટિમાઇઝેશન
૧૦. મધ્યમાન મૂલ્ય પ્રમેય (Mean Value Theorem - MVT)
MVT શરતો: f, [a,b] પર સતત અને (a,b) પર વિકલનીય હોય.
MVT: f'(c) = [f(b) − f(a)] / (b − a), કોઈ c ∈ (a,b) માટે.
કોશીનું MVT (Cauchy's MVT): f,g બંને [a,b] પર સતત અને (a,b) પર વિકલનીય હોય, તો: [f(b)−f(a)]/[g(b)−g(a)] = f'(c)/g'(c), c ∈ (a,b).
MVT નું ભૌમિતિક અર્થઘટન: કોઈ એક બિંદુએ સ્પર્શક એ ચોરડ (chord) ને સમાંતર થાય છે.
📝 ગેટ/GUJCET માં MVT નું ભૌમિતિક અને બીજગણિતીય બંને પાસા પર પ્રશ્ન આવે છે.
f(b)−f(a)f'(c)·(b−a) (MVT પરથી)
૧૧. મહત્તમ-લઘુત્તમ નિર્ણયની રીતો — સારાંશ
પ્રથમ પદ્ધતિ (સીમાઓ પાસે): f'(x) = 0 ઉકેલો → f''(x) ની ગણતરી કરો.
દ્વિતીય પદ્ધતિ (આંતરિક વિશ્લેષણ): f'(x) ની ચિહ્ન રચના બદલાય છે કે કેમ તે જોવું.
f'(x) નું ચિહ્ન રચના: + → − : મહત્તમ (Max) − → + : લઘુત્તમ (Min) ન બદલાય : ન તો મહત્તમ ન લઘુત્તમ
f''(c) = 0 હોય ત્યારે ત્રીજા વિકલિત f'''(c) ની ચકાસણી પણ કરો — જો ત્રીજું વિકલિત પણ શૂન્ય હોય તો ઉચ્ચ કક્ષાનો ઉપયોગ કરો.
📝 સામાન્ય રીતે GUJCET માં f''(c) ≠ 0 જ આવે છે — તેથી પ્રથમ કક્ષાચ્છેદ નિયમ સૌથી ઉપયોગી.
૧૨. વિશિષ્ટ ઉદાહરણો અને પ્રકાર
વક્ર xy = c² પર P(t, c²/t) બિંદુએ સ્પર્શકનું સમીકરણ: x/t² + ty/c² = 2/c.
વર્તુળ x² + y² = a² પર P(x₁,y₁) બિંદુએ સ્પર્શક: xx₁ + yy₁ = a².
અર્ધવૃત્ત y = √(a²−x²) માટે f'(x) = −x/√(a²−x²)
વર્તુળ, અંબુજ, પરવલય, ઉપવૃત્ત જેવા સામાન્ય વક્રોના સ્પર્શક/અભિક્ષેપના સૂત્રો રટી લેવાં.
📝 પરવલય y² = 4ax પર P(at², 2at) બિંદુએ સ્પર્શક: ty = x + at².
૧૩. વિદ્યાર્થીઓ ઘણીવાર ભૂલે છે તે બાબતો
મહત્તમ/લઘુત્તમ શોધતી વખતે છેડાના મૂલ્યો f(a) અને f(b) નીચે રાખવા ભૂલે છે.
સ્પર્શકનું સમીકરણ લખતી વખતે છેદનમાં (−1/f'(x₁)) ને ભૂલો પાડે છે.
આશ્રિત ફેરફારમાં Δx ને ખોટું ચિહ્ન આપે છે — ઉદા: √4.01 માટે Δx = +0.01, √3.99 માટે Δx = −0.01.
એકમ (units) અને દિશા (sign) નું ધ્યાન રાખો — GUJCET માં ઘણા પ્રશ્નોમાં +/− નો ખેલ હોય છે.
📝 f'(x) = 0 અને f''(x) = 0 બંને સાથે આવે તો 'બિન્દુ ફેરફાર' (point of inflection) હોઈ શકે.
૧૪. આવેશના વિકલનના ઉપયોગ — અંતિમ સારાંશ
આવેશ: f'(x) એ x ના ફેરફારનો દર દર્શાવે છે.
આશ્રિત ફેરફાર: Δy ≈ f'(x)·Δx, નાના Δx માટે ચોકસાઈ.
સ્પર્શક-અભિક્ષેપ: f'(x) ના આધારે વક્રની સ્થાનિક દિશા નક્કી કરો.
મોનોટોનિસિટી: f'(x) > 0 → વધતું, f'(x) < 0 → ઘટતું.
મહત્તમ-લઘુત્તમ: f'(x) = 0, f''(x) ની ચિહ્ન રચના જોવા.
MVT: f'(c) = [f(b)−f(a)]/(b−a) — સંશોધન અને સાબિતીમાં મહત્વપૂર્ણ.
