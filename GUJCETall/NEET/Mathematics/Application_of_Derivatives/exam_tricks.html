🧪 GUJCET — સંવાહક (Derivatives) ના ઉપરોગ: ચાતુર્યપૂર્ણ ટ્રિક્સ અને ટૂંકા માર્ગો

🧪 GUJCET — Gujarati • Mathematics • Application of Derivatives

🎯 પરીક્ષા ટ્રિક્સ

f(x) = xⁿ માટે x = 0 બિંદુએ ઓળખ: જો n બીજ (even) અને n ≥ 2 હોય, તો f(x) x-અક્ષને સ્પર્શે છે પણ છેદતું નથી, અને x = 0 એ સ્થાનિક ન્યૂનતમ (local minimum) છે. જો n સરળ (odd) હોય, તો x = 0 એ ઇન્ફલેક્શન બિંદુ (inflection point) છે. આથી વેગવિભાજન (derivative) શોધ્યા વિના જ મહત્તમ/ન્યૂનતમ/ઇન્ફલેક્શનની પ્રકૃતિ સીધી નક્કી થાય.
જ્યારે વિકલ્પોમાં x = 0 એ ક્રાંતિક બિંદુ (critical point) તરીકે આવેલું હોય અને પ્રશ્ન માત્ર પ્રકૃતિ પૂછતો હોય, વેગવિભાજન કરવાનો સમય બચાવવા.
દા.ત.: f(x) = x⁴ – 4x² ના બધા ક્રાંતિક બિંદુઓ: f'(x) = 4x³ – 8x = 4x(x² – 2). f''(0) = –8 < 0 → x = 0 પર સ્થાનિક મહત્તમ. f''(±√2) > 0 → બંને પર ન્યૂનતમ.
આપેલ વર્ક (work) W(t) નો દર શોધવા માટે: W'(t) ને શૂન્ય મૂકીને 'વ્યસ્ત દર' (instantaneous rate) શોધો. જો પ્રશ્નમાં 'સૌથી વધુ દર કયા સમયે?' પૂછતા હોય, તો સીધું W''(t) = 0 સરજો. ઘણા GUJCET પ્રશ્નોમાં વર્ક સમીકરણ સાદું (દા.ત., W = at² + bt + c) હોય છે — તો W'(t) રેખીય છે અને તે શૂન્ય કરવું ખૂબ જલ્દી છે.
ભૌતિક વિજ્ઞાન / રસાયણ વિજ્ઞાન પ્રકૃતિના પ્રશ્નો જ્યાં કોઈ રાશિનો 'દર' માંગ્યો હોય અને વિકલ સંબંધ આપેલો હોય.
દા.ત.: W(t) = 3t³ – 9t² + 6t + 2. દર = W'(t) = 9t² – 18t + 6. દર મહત્તમ/ન્યૂનતમ માટે W''(t) = 18t – 18 = 0 → t = 1 સેકંડ.
સંપર્કરેખા (Tangent) અને લંબરેખા (Normal) ના સમીકરણ: y – y₁ = m(x – x₁), જ્યાં m = f'(a). લંબરેખાનો ઢાળ = –1/f'(a) (જ્યારે f'(a) ≠ 0). GUJCET માં ઘણીવાર સંપર્કબિંદુ (a, f(a)) આપેલો હોય છે — સીધો m અને y₁ મૂકી દો. જો પ્રશ્ન 'સંપર્કરેખા x-અક્ષને કયા બિંદુએ છેદે?' પૂછતો હોય, તો y = 0 મૂકી x શોધો.
જ્યારે બિંદુ આપેલ હોય અને સંપર્કરેખા/લંબરેખાનું સમીકરણ અથવા તેના છેદબિંદુ પૂછવાના હોય.
દા.ત.: y = x² – 3x + 2 at x = 1: y₁ = 0, f'(x) = 2x – 3 → m = –1. સંપર્કરેખા: y = –(x – 1) = –x + 1. x-અક્ષને છેદે જ્યાં y = 0 → x = 1. (અહીં સંપર્કબિંદુ જ x-અક્ષ પર છે.)
વર્ધમાન / હ્રાસમાન વિધેય (Increasing / Decreasing Function): ફક્ત f'(x) > 0 અથવા f'(x) < 0 તપાસો. વૃક્તિબિંદુઓ (turning points) જ્યાં f'(x) = 0. જો f'(x) સતત ધન હોય, તો વિધેય સર્વત્ર વર્ધમાન; જો સતત ઋણ, તો સર્વત્ર હ્રાસમાન. વિકલ્પોમાં અંતરાલ (interval) આપેલ હોય, તો તે અંતરાલમાં f'(x) નું ચિહ્ન તપાસો.
જ્યારે પ્રશ્નમાં કોઈ વિધેય કેટલા અંતરાલમાં વર્ધમાન/હ્રાસમાન છે તે પૂછવામાં આવતું હોય — વિકલ્પોના આધારે ઝડપી ચકાસણી.
દા.ત.: f(x) = x³ – 3x² + 2: f'(x) = 3x² – 6x = 3x(x – 2). f'(x) > 0 when x ∈ (–∞, 0) ∪ (2, ∞) → વર્ધમાન; f'(x) < 0 when x ∈ (0, 2) → હ્રાસમાન.
m x² + nx + p પ્રકારના દ્વિઘાત વિધેય (quadratic function) માટે સ્થાનિક મહત્તમ/ન્યૂનતમ સીધું: શિરોબિંદુ x = –n/(2m). જો m > 0 → ન્યૂનતમ, m < 0 → મહત્તમ. વેગવિભાજન કરવાની જરૂર નથી. GUJCET માં ઘણા મહત્તમ/ન્યૂનતમ પ્રશ્નો આ પ્રકારના જ હોય છે.
જ્યારે વિધેય દ્વિઘાત (quadratic) હોય અને સીધું મહત્તમ/ન્યૂનતમ મૂલ્ય પૂછવાનું હોય.
દા.ત.: f(x) = –2x² + 8x + 3: m = –2 < 0 → મહત્તમ. x = –8/(2×–2) = 2. f(2) = –8 + 16 + 3 = 11. મહત્તમ મૂલ્ય = 11.
બીજું વેગવિભાજન પરીક્ષણ (Second Derivative Test) યાદ રાખો: f'(c) = 0. f''(c) > 0 → સ્થાનિક ન્યૂનતમ (local min). f''(c) < 0 → સ્થાનિક મહત્તમ (local max). f''(c) = 0 → પરીક્ષણ વ્યર્થ, પ્રથમ વેગવિભાજન પરીક્ષણ (First Derivative Test) અપનાવો. આ ત્રણેય પરિણામો GUJCET માં ઘણીવાર સીધા પૂછવામાં આવે છે.
જ્યારે કોઈ પણ વિધેયના મહત્તમ/ન્યૂનતમ બિંદુઓ શોધવાના હોય અને f'(x) = 0 ના બિંદુઓ મળ્યા હોય.
દા.ત.: f(x) = x⁴ – 2x²: f'(x) = 4x³ – 4x = 4x(x² – 1) → x = 0, ±1. f''(x) = 12x² – 4. f''(0) = –4 < 0 → સ્થાનિક મહત્તમ; f''(±1) = 8 > 0 → સ્થાનિક ન્યૂનતમ.
વ્યાસત્રણ (Differentials) સાથે અંદાજિત મૂલ્ય: f(x + Δx) ≈ f(x) + f'(x)·Δx, જ્યાં Δx ખૂબ જ નાનો છે. GUJCET માં પ્રશ્નો આ પ્રકારના હોય છે: (1.01)³, √25.1, ln(1.02). સીધો x બાદ f(x) અને f'(x) શોધીને મૂલ્ય ગણો.
જ્યારે કોઈ અંદાજિત મૂલ્ય શોધવાનું હોય જેનાનું ચોકસાઈપૂર્વક મૂલ્ય કડક (exact) ગણવું મુશ્કેલ હોય પણ તે ખૂબ જ નજીકની સંખ્યા પરથી શક્ય હોય.
દા.ત.: (1.01)³: f(x) = x³, x = 1, Δx = 0.01. f(1) = 1, f'(1) = 3. ಅંદાજ = 1 + 3(0.01) = 1.03. (ચોકસાઈ: 1.030301, ખૂબ નજીક.)
જ્યારે ગોળાકાર ગોળા (sphere) ના ઘનફળ / પૃષ્ઠફળ / ત્રિજ્યાનો દર શોધવો હોય: V = (4/3)πr³, A = 4πr². dV/dt = 4πr²·(dr/dt), dA/dt = 8πr·(dr/dt). GUJCET માં 'બાષ્પીભવન દર' કે 'ઉબાળા દર' સંબંધિત પ્રશ્નોમાં આ સૂત્રો સીધા વપરાય છે — યાદ રાખો તો સમીકરણ વ્યુત્પન્ન (derive) કરવાનો સમય બચે.
ગોળાના ઘનફળ, પૃષ્ઠફળ અથવા ત્રિજ્યાના વેગવિભાજન-સંબંધી દર શોધવાના પ્રશ્નો.
દા.ત.: ગોળાની ત્રિજ્યા 5 cm અને dr/dt = 0.3 cm/s. ઘનફળના વધારાનો દર = 4π(5)² × 0.3 = 30π cm³/s.
અંતરાલમાં વિધેય વર્ધમાન છે: f'(x) ≥ 0 (અથવા > 0) for all x in the interval. GUJCET માં ઘણીવાર 'f(x) = x³ – 3x² + 4x + 7 (0 ≤ x ≤ 2)' એવો પ્રશ્ન આવે — f'(x) = 3x² – 6x + 4 = 3(x–1)² + 1 > 0 સર્વત્ર → વિધેય સર્વત્ર વર્ધમાન. આવા f'(x) હંમેશા ધન હોય, તેથી કોઈ ક્રાંતિક બિંદુ નથી.
જ્યારે પ્રશ્નમાં આપેલ અંતરાલમાં વિધેય વર્ધમાન છે કે કેમ તે તપાસવાનું હોય, ખાસ કરીને f'(x) નું વિવેચક (discriminant) ઋણ હોય ત્યારે.
દા.ત.: f(x) = 2x³ – 9x² + 12x + 5: f'(x) = 6x² – 18x + 12 = 6(x–1)(x–2). f'(x) > 0 માટે x < 1 અથવા x > 2; f'(x) < 0 માટે 1 < x < 2. તેથી (1,2) અંતરાલમાં હ્રાસમાન.
સ્થિરબિંદુઓ (Critical Points) શોધવાનો ઝડપી રસ્તો: f'(x) = 0 અથવા f'(x) અવિભાજ્ય (undefined) હોય તેવા બિંદુઓ. GUJCET માં ઘણા પ્રશ્નોમાં f'(x) ને સરળતાથી ઉત્પાદક વિભાજન (factorise) કરી શકાય છે — ઉદાહરણ તરીકે f'(x) = x(x–1)(x+2) જેવું. ફક્ત ઉત્પાદકોને શૂન્ય મૂકો: x = 0, 1, –2.
જ્યારે વિધેયના મહત્તમ/ન્યૂનતમ/ઇન્ફલેક્શન બિંદુઓ શોધવાના હોય. ફેક્ટરાઇઝેશન ઝડપી કરવા કોમન બહાર કાઢો.
દા.ત.: f(x) = x⁵ – 5x³ + 4x: f'(x) = 5x⁴ – 15x² + 4. અહીં ફેક્ટરાઇઝ શક્ય નથી, પણ f(x) = x(x⁴ – 5x² + 4) = x(x²–1)(x²–4). વિધેયના મૂળોથી મહત્તમ/ન્યૂનતમ સીધા મળતા નથી — ક્રાંતિક બિંદુઓ માટે f'(x)=0 ઉકેલવું પડશે.
રેખા અને વક્ર (curve) વચ્ચેનો અંતર / સંપર્કરેખાની શરત: જો સીધી રેખા Ax + By + C = 0 એ વક્ર y = f(x) ને સ્પર્શે છે, તો રેખાનું સમીકરણ f'(a)(x–a) + f(a) = 0 ના સ્વરૂપમાં લખો અને બંનેને સરખાવો. આ રીતે a શોધવાની જરૂરિયાત ઘટે.
જ્યારે પ્રશ્નમાં કહેવાય હોય કે 'કોઈ રેખા વક્રને સ્પર્શે છે' અને સ્પર્શબિંદુ શોધવાનું હોય.
દા.ત.: યોગ્ય રેખા y = mx + c ને vakra y = x²–2x+3 ને સ્પર્શે છે. સ્પર્શક: y – y₁ = 2x₁–2(x–x₁). બંને સરખાવતા m = 2x₁–2 અને c = y₁ – x₁(2x₁–2). બંધન ન મળે ત્યારે Δ = 0 નો ઉપયોગ કરો.
આલેખ (graph) ના આધારે નિર્ણય: GUJCET માં કેટલાક પ્રશ્નોમાં f(x) નો આલેખ આપેલો હોય છે — સ્પર્શકોની ઢાળ જોઈને f'(x) > 0 / < 0 નક્કી કરો. સ્પર્શક કાટખૂણે મજબૂત હોય → મહત્તમ, નીચે તરફ ઢળતી → ન્યૂનતમ, સમાંતર → inflection. આલેખી પદ્ધતિ ગણતરી કરતાં ઝડપી છે.
જ્યારે પ્રશ્નમાં f(x) નો આલેખ આપેલ હોય અને ચોક્કસ બિંદુએ સ્પર્શક / વર્ધમાન/હ્રાસમાન / મહત્તમ-ન્યૂનતમ પૂછવામાં આવ્યું હોય.
દા.ત.: આલેખમાં બિંદુ P પર સ્પર્શક ખિતિજ (horizontal) છે → f'(P) = 0. બિંદુ Q પર સ્પર્શક ઉપર તરફ ઢળેલો → f'(Q) > 0 (વર્ધમાન). બિંદુ R પર વક્ર વળાંક બદલે છે → inflection point (f''(R) = 0).
વ્યાવહારિક મહત્તમ/ન્યૂનતમ પ્રશ્નો (Optimization): GUJCET માં સામાન્ય રીતે 'આપેલ પરિમાણો વડે બનતી ઘનફળ / ક્ષેત્રફળ મહત્તમ/ન્યૂનતમ' પ્રશ્નો આવે છે. પ્રથમ પગલું: ચલ (variable) નક્કી કરો (દા.ત., ત્રિજ્યા r અથવા બાજુ a). બીજું પગલું: એક સમીકરણમાં વિકલ્પીય ચલ દૂર કરો. ત્રીજું: વિકલન કરી શૂન્ય મૂકો. આ ત્રણેય પગલાં ગોઠવીને હંમેશા મહત્તમ/ન્યૂનતમ મળશે.
જ્યારે GUJCET માં 'ઘનફળ મહત્તમ કરો' કે 'ક્ષેત્રફળ લઘુત્તમ કરો' પ્રકારના પ્રશ્નો આવે.
દા.ત.: 12 cm તારના ટુકડાઓને વર્તુળ અને વર્ગ બનાવવા. ક્ષેત્રફળ લઘુત્તમ થાય તેવો વિભાગ શોધો. ધારો v = r લંબાઈ વર્તુળ માટે: ક્ષેત્રફળ A = πr² + (12–r)²/4. v A/v r = 0 સરજો → r નો મૂલ્ય મળે.
સમાંતર/લંબ સંપર્કરેખા (Parallel/Perpendicular to given line): જો સંપર્કરેખા રેખા ax + by + c = 0 ને સમાંતર હોય, તો f'(x₀) = –a/b. જો લંબ હોય, તો f'(x₀) = b/a. GUJCET માં આ પ્રકારના પ્રશ્નો સીધા ઢાળ (slope) નો ઉપયોગ કરીને ઉકેલવામાં આવે છે — વ્યાપક વેગવિભાજન કરવાની જરૂર પડતી નથી.
જ્યારે પ્રશ્નમાં કહેવાય હોય કે 'વક્રના કયા બિંદુએ સંપર્કરેખા આપેલી રેખાને સમાંતર/લંબ છે?'
દા.ત.: vakra y = x² ના કયા બિંદુએ સંપર્કરેખા રેખા 4x – y + 1 = 0 ને સમાંતર છે? સમાંતર રેખાનો ઢાળ = 4. f'(x) = 2x = 4 → x = 2, y = 4. બિંદુ (2, 4).
f(x) = eˣ, f(x) = ln x, f(x) = sin x, f(x) = cos x ના પ્રથમ વેગવિભાજન યાદ રાખો: d/dx(eˣ) = eˣ, d/dx(ln x) = 1/x, d/dx(sin x) = cos x, d/dx(cos x) = –sin x. આ ચાર મૂળભૂત પરિણામો યાદ રાખવાથી ઘણા ગૂંચવણભર્યા પ્રશ્નો આસાનીથી ઉકેલાય છે. GUJCET માં આ પ્રશ્નો ઘણીવાર સીધા આવે છે.
જ્યારે eˣ, ln x, sin x, cos x ધરાવતું વિધેય હોય અને તેનું વેગવિભાજન કરવાનું હોય — કોઈ પણ અન્ય પદ્ધતિ વાપરવાની જરૂર નથી.
દા.ત.: f(x) = eˣ · sin x: ગુણન નિયમ (product rule) વાપરો → f'(x) = eˣ sin x + eˣ cos x = eˣ(sin x + cos x). સ્પર્શકનો ઢાળ x = 0 પર = e⁰(0 + 1) = 1.
