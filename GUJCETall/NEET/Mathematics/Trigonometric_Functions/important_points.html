ત્રિકોણમિતિના ફલનો (Trigonometric Functions)

🧪 GUJCET — Gujarati • Mathematics • Trigonometric Functions

⭐ મહત્વના મુદ્દા

રેડિયન પદ્ધતિ: એક રેડિયન એટલે તે કોણ જેનો અંત્યાર્ધ (arc) અને ત્રિજ્યા સમાન હોય. π રેડિયન = 180° અને 1 રેડિયન ≈ 57°17'.
અંતરાલ (interval) શોધવા અને ત્રિકોણમિતિય સમીકરણો ઉકેલવામાં મૂળભૂત; દરેક પ્રશ્નમાં સીધો ઉપયોગ.
ખૂબ જ મહત્વનો સંબંધ: θ(ડિગ્રી) × π/180 = θ(રેડિયન). વર્તુળના પરિઘ પર લંબાઈ s = rθ (θ રેડિયનમાં).
MCQ માં ઘણીવાર રેડિયન ↔ ડિગ્રી રૂપાંતર અને ધાર/લંબાઈનો સીધો પ્રશ્ન આવે છે.
અન્ય પરિભાષા: sin θ ને બિંદુ P(x,y) ને આધારે unit circle પર વ્યાખ્યાયિત કરવામાં આવે છે. જ્યાં x = cos θ, y = sin θ, x² + y² = 1.
સર્વસમકાઓની વ્યુત્પત્તિ એકમ વર્તુળ પરથી સમજવી આવશ્યક છે; આધુનિક પદ્ધતિ અનુસાર.
ચતુર્થાંશ (Quadrant) મુજબ ચિહ્નના નિયમ: પ્રથમ — બધા ધન; દ્વિતીય — sin, cosec; તૃતીય — tan, cot; ચતુર્થ — cos, sec. મંત્ર: 'All Silver Tea Cups'.
ચિહ્ન શોધવાના પ્રશ્ન નિયमित આવે છે; ખાસ કરીને વિશેષ કોણોમાં સાપેક્ષ ચિહ્ન મહત્વનું છે.
મૂળભૂત સર્વસમકાઓ (Fundamental Identities): (1) sin²θ + cos²θ = 1, (2) 1 + tan²θ = sec²θ, (3) 1 + cot²θ = cosec²θ.
ત્રિકોણમિતિના ફલનો અધ્યાયની સૌથી મહત્વપૂર્ણ પાયાની સર્વસમકાઓ; દરેક જટિલ પ્રમેય આમાંથી નીકળે છે.
sin²nθ + cos²nθ = 1 — આ સર્વસમકા f(θ) = sin²nθ + cos²nθ નો ગ્રાફ સમતલ y = 1 છે (ધ્રુવરેખા).
આ વૈશ્વિક સ્વરૂપ ઘણા MCQ માં ગ્રાફ પ્રશ્ન તરીકે આવે છે; ઉલ્લેખનીય છે કે આ હંમેશા સતત સ્થિર રહે છે.
ત્રિકોણમિતિય વિધેયોનું અંતરાલ (Domain) અને પરાય (Range): sin θ, cos θ → domain = ℝ, range = [−1, 1]; tan θ → domain = ℝ\{(2n+1)π/2}, range = ℝ.
domain-range શોધવાના પ્રશ્ન GUJCET માં સીધા આવે છે; ખાસ કરીને tan θ અને sec θ માં અસંગત બિંદુઓ.
પરિવર્તન સૂત્રો (Transformation Formulas): sin(A±B) = sinA cosB ± cosA sinB; cos(A±B) = cosA cosB ∓ sinA sinB; tan(A±B) = (tanA ± tanB)/(1 ∓ tanA tanB).
દરેક જટિલ ત્રિકોણમિતિય પ્રશ્નનો આધાર; values of sin75°, cos15° જેવા પ્રશ્નો આ પરથી ઉકેલાય છે.
દ્વિકોણ સૂત્રો: sin2θ = 2sinθcosθ; cos2θ = cos²θ − sin²θ = 2cos²θ − 1 = 1 − 2sin²θ; tan2θ = 2tanθ/(1−tan²θ).
GUJCET માં સૌથી વધુ આવતા સૂત્રોમાંના; cos2θ ના ત્રણેય સ્વરૂપ याद रखવા अनिवार्य છે.
આધારરૂપી (Base Form) cos2θ = 2cos²θ − 1 → cos²θ = (1+cos2θ)/2; sin²θ = (1−cos2θ)/2. આ સૂત્રો power-reduction માટે ઉપયોગી છે.
sin⁴θ + cos⁴θ જેવા પ્રશ્નોના ઉકેલ માટે આ સૂત્રો અનિવાર્ય છે; periodicity શોધવામાં મદદગાર.
ત્રિકોણમિતિય સમીકરણોના સામાન્ય ઉકેલ: sinθ = 0 → θ = nπ; cosθ = 0 → θ = (2n+1)π/2; tanθ = 0 → θ = nπ. જ્યાં n ∈ ℤ.
સામાન્ય ઉકેલ (general solution) શોધવાના પ્રશ્ન GUJCET માં નિયमित આવે છે; આધારભૂત ઉકેલ સૂત્ર.
cosθ = cosα → θ = 2nπ ± α; sinθ = sinα → θ = nπ + (−1)ⁿα; tanθ = tanα → θ = nπ + α.
આ ત્રણેય સામાન્ય ઉકેલ સૂત્રો GUJCET માં အهمિય છે; કોઈ પણ ત્રિકોણમિતિય સમીકરણનો ઉકેલ આમાંથી કોઈ એક સ્વરૂપે મળે છે.
sinθ = sinα અને cosθ = cosα સાથે: θ = 2nπ + α. આ કોણનો અનન્ય સામાન્ય ઉકેલ છે.
બે સમીકરણો સાથેનો પ્રશ્ન આવે ત્યારે અનન્ય ઉકેલ મેળવવા માટે આ મહત્વપૂર્ણ છે.
આંશિક અપૂર્ણાંક (Partial Fraction) પદ્ધતિ: sin2θ / (sinθ·cosθ) સરળ બનાવવા માટે. ઉદા: sin³θ + cos³θ = (sinθ+cosθ)(1−sinθcosθ).
સાદરૂપ પ્રકારના પ્રશ્નોમાં factorisation કौशल जरूरी છે; અવયવીકરણ ઝડપથી સાદરૂપ આપે છે.
विशिष्ट કોણોના મૂલ્યો (0°, 30°, 45°, 60°, 90°): sin0°=0, sin30°=½, sin45°=1/√2, sin60°=√3/2, sin90°=1. cos અને tan પણ સમાન રીતે.
આ મૂલ્યો બિન-સમજીએ વગર સાદરૂપ, સમીકરણ અને અસ્પષ્ટ પરાય (range) શોધવાના પ્રશ્નો ઉકેલવા અશક્ય છે.
ત્રિકોણમિતિય વિધેયોનો આવર્તકાળ (Period): sinθ, cosθ, cosecθ, secθ → 2π; tanθ, cotθ → π.
આવર્તકાળ શોધવાના પ્રશ્ન GUJCET માં બહુ આવે છે; ખાસ કરીને sin²θ, cos²θ નો આવર્તકાળ π હોય છે.
f(θ) = sin²θ + cos²θ → constant = 1, આવર્તકાળ અસ્પષ્ટ (period not defined as a non-trivial periodic function). f(θ) = sin2θ + cos2θ નો આવર્તકાળ π.
આવર્તકાળ શોધવાના MCQ માં આ પ્રકારના પ્રશ્નો આવે છે; special cases તરીકે યાદ રાખવા.
ઉપરોક્ત વિધેયોની લાક્ષણિકતાઓ: f(θ) = sin²nθ + cos²nθ = 1 હોવાથી, તેનું graph સમતલ y = 1 છે — આધારભૂત ઓળખ.
આ identity નો ગ્રાફ સમતલ રેખા છે — આ પ્રશ્ન GUJCET માં graphic interpretation તરીકે આવે છે.
સમીકરણોનું વિસ્તરણ: sin(3θ) = 3sinθ − 4sin³θ, cos(3θ) = 4cos³θ − 3cosθ, tan(3θ) = (3tanθ − tan³θ)/(1 − 3tan²θ).
t્રिकोणમිतीय समीकरणों में यह सूत्र बहुत महत्वपूर्ण है; polynomial रूप में बदलने के लिए.
समान्तर-गुणन (Product-to-Sum) सूत्र: 2sinA cosB = sin(A+B) + sin(A−B); 2cosA sinB = sin(A+B) − sin(A−B); 2cosA cosB = cos(A+B) + cos(A−B); 2sinA sinB = cos(A−B) − cos(A+B).
Product को sum/difference में बदलकर सादरूप करने में ये सूत्र अत्यंत उपयोगी हैं; MUHCET/GUJCET में बारंबार प्रश्न आते हैं.
विषम-सम (Odd-Even) गुण: sin(−θ) = −sinθ, cos(−θ) = cosθ, tan(−θ) = −tanθ. sin और tan विषम फलन, cos सम फलन है.
विषम-सम गुण का उपयोग symmetric expressions सरल बनाने और चिह्न निर्धारित करने में होता है.
sin(θ + 2nπ) = sinθ, cos(θ + 2nπ) = cosθ, tan(θ + nπ) = tanθ — आवर्तकाल की परिभाषा. n ∈ ℤ.
आवर्तकाल आधारित प्रश्न (जैसे sin(nπ+θ)) में यह नियम अनिवार्य है.
f(θ) = a·sinθ + b·cosθ का न्यूनतम मान −√(a²+b²), अधिकतम मान √(a²+b²).
अधिकतम/न्यूनतम मान शोधने वाले प्रश्न GUJCET में नियमित आते हैं; अत्यंत महत्वपूर्ण सूत्र.
tanθ·tan(60°−θ)·tan(60°+θ) = tan3θ — त्रिकोणमितीय सर्वसमिका।
यह एक विशेष सर्वसमिका है जो प्रतियोगी परीक्षाओं में frequently आती है; direct application question.
cotθ − tanθ = 2cot2θ; sinθ − sin3θ + sin5θ − ... (alternating series pattern recognition).
सामान्य पद ज्ञात करके योगफल निकालने वाले प्रश्न आवृत्ति से आते हैं; telescoping series type.
