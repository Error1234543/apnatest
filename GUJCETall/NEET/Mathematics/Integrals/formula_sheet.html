ઇન્ટિગ્રલ્સ (સંકલન) – સૂત્ર પત્રક

🧪 GUJCET — Gujarati • Mathematics • Integrals

⚡ સૂત્રો

ઘાતાંકિય ફંક્શનનું સંકલન: ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C
x – ચલ, n – ઘાતાંક (n ≠ -1), C – સંકલન અચળાંક (Integration constant) · SI: સંકલિત રાશિના એકમ પર આધારિત (ઉદા. x m માં અને dx s માં હોય તો પરિણામ m·s) · n ≠ -1 (જો n = -1 હોય તો આ સૂત્ર લાગુ પડતું નથી)
1/x નું સંકલન: ∫ (1/x) dx = ln|x| + C
x – ચલ, ln – પ્રાકૃતિક લઘુગુણક, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · x ≠ 0
ઘાતીય ફંક્શન eˣ નું સંકલન: ∫ eˣ dx = eˣ + C
e – યુલર અચળાંક (~2.718), x – ચલ, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · x કોઈ પણ વાસ્તવિક સંખ્યા
સામાન્ય ઘાતીય ફંક્શન aˣ નું સંકલન: ∫ aˣ dx = aˣ / ln(a) + C
a – ધન વાસ્તવિક અચળાંક (a ≠ 1), x – ચલ, ln – પ્રાકૃતિક લઘુગુણક, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · a > 0 અને a ≠ 1
正弦 (sin) નું સંકલન: ∫ sin x dx = -cos x + C
x – ખૂણો (રેડિયનમાં), C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · x કોઈ પણ વાસ્તવિક સંખ્યા (ખૂણો રેડિયનમાં)
કોસાઈન (cos) નું સંકલન: ∫ cos x dx = sin x + C
x – ખૂણો (રેડિયનમાં), C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · x કોઈ પણ વાસ્તવિક સંખ્યા (ખૂણો રેડિયનમાં)
સેકેન્ટ સ્ક્વેર (sec²x) નું સંકલન: ∫ sec²x dx = tan x + C
x – ખૂણો, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · x ≠ (2n+1)π/2, j્યાં n પ્રતીકક્ષણ (integer) છે
કોસેકેન્ટ સ્ક્વેર (cosec²x) નું સંકલન: ∫ cosec²x dx = -cot x + C
x – ખૂણો, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · x ≠ nπ, j્યાં n પ્રતીકક્ષણ છે
સેકેન્ટ-ટેન્ટ ગુણાકાર (sec x tan x) નું સંકલન: ∫ sec x tan x dx = sec x + C
x – ખૂણો, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · x ≠ (2n+1)π/2, j્યાં n પ્રતીકક્ષણ છે
કોસેકેન્ટ-કોટેન્ટ ગુણાકાર (cosec x cot x) નું સંકલન: ∫ cosec x cot x dx = -cosec x + C
x – ખૂણો, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · x ≠ nπ, j્યાં n પ્રતીકક્ષણ છે
આર્કસાઈન (arcsin) માટેનું પ્રમાણ્ય સંકલન સૂત્ર: ∫ 1/√(1-x²) dx = arcsin x + C
x – ચલ (-1 ≤ x ≤ 1), arcsin – વિપરીત ત્રિકોણમિતિય ફંક્શન, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · -1 < x < 1 (એકંદરે [-1,1] માં પણ વ્યાખ્યાયિત, પણ મુક્ત સંકલન માટે અંત્યબિંદુઓ સિવાય)
આર્કટેન્ટ (arctan) માટેનું પ્રમાણ્ય સંકલન સૂત્ર: ∫ 1/(1+x²) dx = arctan x + C
x – ચલ, arctan – વિપરીત ત્રિકોણમિતિય ફંક્શન, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · x કોઈ પણ વાસ્તવિક સંખ્યા
સંકલનનું રેખીય ગુણધર્મ (રેખીયતા): ∫ [f(x) ± g(x)] dx = ∫ f(x) dx ± ∫ g(x) dx
f(x), g(x) – સંકલનીય ફંક્શનો, C – સંકલન અચળાંક · SI: સંકલિત રાશિના એકમ પર આધારિત · f અને g સંકલનીય હોય
અચળાંકનો ગુણાકાર ગુણધર્મ: ∫ k·f(x) dx = k ∫ f(x) dx
k – અચળાંક, f(x) – સંકલનીય ફંક્શન · SI: સંકલિત રાશિના એકમ પર આધારિત · f સંકલનીય હોય
ફંક્શનનો સ્થાનાંતરિત સૂત્ર (Shift formula): ∫ f(x-a) dx = F(x-a) + C, જ્યાં F' = f
a – વાસ્તવિક અચળાંક, F – f નું પ્રાપ્તિક (primitive) · SI: સંકલિત રાશિના એકમ પર આધારિત · f સંકલનીય હોય

🔗 સંબંધો

  • સંકલન એ વિકલનનું વિપરીત પ્રક્રિયા છે: જો d/dx [F(x)] = f(x) હોય, તો ∫ f(x) dx = F(x) + C.
  • ઘાતાંકિય સૂત્ર (n≠-1) અને 1/x નું સૂત્ર એકબીજાથી ભિન્ન છે; n = -1 માટે ઘાતાંકિય સૂત્ર અમાન્ય બની જાય છે અને ln|x| સૂત્ર લાગુ પડે છે.
  • ત્રિકોણમિતિય સંકલન સૂત્રો એકબીજા સાથે જોડાયેલા છે: sin અને cos, sec અને tan, cosec અને cot જેવાં વિપરીત જોડ olarak બધાં જોડિયાં પ્રાપ્ત કરે છે.

🎯 ટ્રિક્સ

ચકાસણી: કોઈ પણ સંકલન કર્યા પછી પરિણામનું વિકલન કરો; જો મૂળ ફંક્શન મળે તો જવાબ સાચો છે.
સરવાળા/મિથુનો કાયદો: સંકલનનું વિસ્તરણ કરીને પ્રત્યેક પદનું અલગ સંકલન કરવું સરળ બને છે.
પ્રાપ્તિકનું સામાન્ય સ્વરૂપ હંમેશા '+ C' સાથે લખવું; C ભૂલવાથી અંક પરmarking નુકસાન થાય છે.

⚠️ ભૂલો

∫ xⁿ dx માં n = -1 લેતાં સૂત્ર xⁿ⁺¹/(n+1) વાપરવું; n = -1 માટે ln|x| સૂત્ર લાગુ પડે છે.
સંકલન કર્યા બાદ અચળાંક C છોડી દેવો.
ત્રિકોણમિતિય સંકલનમાં ચિહ્ન ભૂલવું: ∫ sin x dx = -cos x + C, naki cos x + C નહીં.
arcsin અને arctan ના પ્રમાણ્ય સૂત્રો વચ્ચે ગૂંચવણ: 1/√(1-x²) → arcsin, જ્યારે 1/(1+x²) → arctan.
અચળાંક k ને સંકલન ચિહ્નની અંદર રાખવા બદલે બહાર કાઢવામાં ભૂલ કરવી.
