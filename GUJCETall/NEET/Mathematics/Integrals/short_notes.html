સંકલન — ઝડપી પુનરાવર્તન નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Integrals

📘 વ્યાખ્યાઓ

  • સંકલન: અવકલનની વિપરીત ક્રિયા; f(x) નું સંકલન એ F(x) મેળવે છે જેમ કે F'(x) = f(x).
  • અનિશ્ચિત સંકલન: ∫f(x)dx = F(x) + C, જ્યાં C સંકલન અચળાંક છે.
  • નિશ્ચિત સંકલન: ∫ₐᵇ f(x)dx = F(b) − F(a); ફલનનું અવકલનપ્રતિભાવ પ્રમેય દ્વારા ગણવામાં આવે છે.
  • સંકલ્ય (Integrand): સંકલનzeichenની અંદરનું ફલન f(x).
  • પ્રતિઆવર્તી (Antiderivative): એવું ફલન F કે જેનું વિકલિત F' = f હોય.
  • સંકલનનો ભૌમિતિક અર્થ: વક્ર y=f(x), x-અક્ષ અને x=a, x=b રેખાઓ વડે રચાયેલા क्षेत्रનું ક્ષેત્રફળ.

⚡ સૂત્રો

  • ∫xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ −1
  • ∫eˣ dx = eˣ + C
  • ∫sin x dx = −cos x + C
  • ∫cos x dx = sin x + C
  • ∫sec²x dx = tan x + C
  • ∫sec x tan x dx = sec x + C
  • ∫1/√(1−x²) dx = arcsin x + C
  • ∫1/(1+x²) dx = arctan x + C
  • ∫1/x dx = ln|x| + C
  • ∫aˣ dx = aˣ/ln a + C, a>0, a≠1
  • પ્રતિસ્થાપન પદ્ધતિ: ∫f(g(x))·g'(x) dx = ∫f(u) du, u=g(x)
  • ખંડશઃ સંકલન: ∫u dv = uv − ∫v du
  • અંશભાગ વિભાજન: ∫[P(x)/Q(x)] dx માટે Q ના અવયવો પર આધારિત રચના.
  • ∫sec x dx = ln|sec x + tan x| + C
  • ∫csc x dx = ln|csc x − cot x| + C
  • ∫tan x dx = ln|sec x| + C
  • ∫cot x dx = ln|sin x| + C

⭐ મુખ્ય તથ્યો

  • સંકલન એ અવકલનનું વિપરીત છે; બંને ભૌતિક રીતે પરિમાણીય તબક્કાઓ છે.
  • રેખીયતા: ∫[af(x)+bg(x)] dx = a∫f(x)dx + b∫g(x)dx.
  • નિશ્ચિત સંકલનનું મૂલ્ય સ્થાનિક ચલ પર આધારિત નથી; ∫ₐᵇ f(x)dx = ∫ₐᵇ f(t)dt.
  • સંમિતિ ગુણધર્મ: ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx જો f સમ ફલન હોય; શૂન્ય જો f વિષમ ફલન હોય.
  • King's property: ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b−x)dx.
  • ∫ₐᵇ f(x)dx = −∫ᵇₐ f(x)dx (સીમાઓ અદલાબદલીથી ચિહ્ન બદલાય છે).
  • નિશ્ચિત સંકલનનો ઉપયોગ વક્રીય ક્ષેત્રફળ, કદ અને પેરામેટ્રિક વક્રની લંબાઈ માટે થાય છે.
  • અવકલનપ્રતિભાવ પ્રમેય (Fundamental Theorem of Calculus) સંકલન અને અવકલનને જોડે છે.

⚠️ સામાન્ય ભૂલો

  • અનિશ્ચિત સંકલનમાં +C ભૂલી જવું (સૌથી સામાન્ય ભૂલ).
  • ∫1/x dx માટે ln x લખવું પણ |x| નો ઉલ્લેખ ન કરવો.
  • પ્રતિસ્થાપન સમયે du = g'(x)dx લખીને dx ને યોગ્ય રીતે બદલવું.
  • ખંડશઃ સંકલનમાં u અને dv ની પસંદગી ખોટી કરવી (LIATE નિયમ ધ્યાનમાં રાખવો).
  • નિશ્ચિત સંકલનમાં સીમાઓ બદલવાનું ભૂલી જવું જ્યારે પ્રતિસ્થાપનનો ઉપયોગ કરવામાં આવે.
  • વિષમ ફલનની સંમિતિ ગુણધર્મ શર્તો ચકાસ્યા વિના લાગુ પાડવું.
  • aⁿ ના સૂત્રમાં n=−1 હોય ત્યારે ઘાત નિયમ લાગુ પાડવો (ભૂલ).
  • trigonometric substitution સમયે બૌદ્ધિક દ્વિભાજનનું સૂત્ર યાદ ન રાખવું.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • LIATE નિયમ: Logarithmic, Inverse trig, Algebraic, Trigonometric, Exponential — અવકલન માટે u પસંદ કરવાનો ક્રમ.
  • સમ અને વિષમ ફલનોના ગુણધર્મો પ્રત્યેક પરીક્ષામાં ઓછામાં ઓછા એક પ્રશ્ન આવે છે.
  • ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx (સમ ફલન) અને 0 (વિષમ ફલન) — ઝડપી ગણતરી માટે અગત્યનું.
  • ખંડશઃ સંકલન પછી સમાપ્તિ માટે પુનરાવર્તિત ખંડશઃ પદ્ધતિ અથવા વાળવું સૂત્ર વપરાય છે.
  • ∫1/(x²±a²) dx અને ∫1/√(a²−x²) dx ના સૂત્રો પરીક્ષામાં સીધા આવે છે.
  • પ્રતિસ્થાપન પદ્ધતિમાં ત્રિકોણમિતિય પ્રતિસ્થાપન x = a sinθ, x = a tanθ, x = a secθ હંમેશા યાદ રાખવાં.
  • નિશ્ચિત સંકલનનાં ગુણધર્મો ∫ₐᵇ f(x)dx = ∫ₐᶜ f(x)dx + ∫ᶜᵇ f(x)dx બહુપ્રયોગી છે.
  • સંકલનનું મૂલ્ય ઋણ પણ હોઈ શકે; ખેતરફળ હંમેશા ધન હોવાથી |f(x)| નો ઉપયોગ કરવો.
  • સામાન્ય પરીક્ષા પ્રશ્નો: ∫x·eˣdx, ∫x·sin x dx, ∫dx/(x²+4x+5), ∫₋π/₂^{π/2} cos x dx — આ ચારેય યાદ રાખવાં.
