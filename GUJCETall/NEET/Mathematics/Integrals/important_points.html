સંકલન (Integrals) — મહત્વના બિંદુઓ

🧪 GUJCET — Gujarati • Mathematics • Integrals

⭐ મહત્વના મુદ્દા

સંકલન એ અવકલનની વ્યસ્ત પ્રક્રિયા છે; જો d/dx[f(x)] = g(x), તો ∫g(x) dx = f(x) + C. C એ સંકલન અચળાંક (Integration Constant) છે.
મૂળભૂત વ્યાખ્યા—દરેક પ્રશ્ન આ જ પર આધારિત હોય છે.
ઘાત નિયમ: ∫x^n dx = x^(n+1)/(n+1) + C, જ્યાં n ≠ −1. n = −1 માટે ∫x^(-1) dx = ln|x| + C.
GUJCET માં સીધો અને પુનરાવર્તિત પ્રશ્ન આવે છે; n = −1 ચુકાતું કેસ ઘણીવાર પકડે છે.
સ્થિર અચળાંકનો સંકલન: ∫k dx = kx + C, અને ∫[af(x) + bg(x)] dx = a∫f(x)dx + b∫g(x)dx.
રેખીય ગુણધર્મ—મોટાભાગના સંકલનોને વિભાજીત કરવા માટે ઉપયોગ થાય છે.
ત્રિકોણમિતિય સંકલનો: ∫sin x dx = −cos x + C, ∫cos x dx = sin x + C, ∫sec²x dx = tan x + C, ∫cosec²x dx = −cot x + C, ∫sec x tan x dx = sec x + C, ∫cosec x cot x dx = −cosec x + C.
ધાર્મિક રીતે બધા GUJCET પ્રશ્નોમાં કોઈ ને કોઈ ત્રિકોણમિતિય સંકલન હોય છે; મનોરમ મંત્ર રીતે રટવું પડે.
વ્યસ્ત ત્રિકોણમિતિય વિધેયોના સંકલન: ∫1/(1+x²) dx = tan⁻¹x + C, ∫1/√(1−x²) dx = sin⁻¹x + C, ∫1/(x√(x²−1)) dx = sec⁻¹x + C.
દ્વિ-ઘાત છેદવાળા પ્રશ્નો ખૂબ જ સચોટ આવે છે; આ ડેરીવેટિવ્સ યાદ રાખવા જરૂરી.
ઘાતાંકીય સંકલન: ∫e^x dx = e^x + C, ∫a^x dx = a^x/ln a + C.
e^x નો સંકલન તેના જ ડેરીવેટિવ જેટલો જ હોવાથી ઘણીવાર પ્રશ્નમાં ફંદરું પાડે છે.
લઘુગણકીય સંકલન: ∫1/x dx = ln|x| + C.
સૌથી સામાન્ય પ્રશ્નોમાંથી એક; |x| નીચેનું ચિન્હ ભૂલવાનો પ્રચલિત ભૂલભરેલો પ્રશ્ન આવે છે.
પ્રતિસ્થાપન પદ્ધતિ (Substitution Method): u = g(x) લઈ ∫f(g(x))·g'(x) dx = ∫f(u) du તરીકે રૂપાંતરિત કરો. સામાન્ય પસંદગીઓ: u = ax+b, u = sin x, u = e^x, u = log x, u = f(x).
GUJCET માં સૌથી વધુ આવતા પદ્ધતિઓમાંનું એક; યોગ્ય પ્રતિસ્થાપન પસંદ કરવું મુખ્ય ગેરંटी છે.
આંશિક ભાગો પદ્ધતિ (Partial Fractions): જટિલ દ્વિઘાત છેદને A/(x−a) + B/(x−b) અથવા (Ax+B)/(quadratic)ના સરવાળા તરીકે છૂટો પાડીને સંકલન કરો.
અપૂર્ણાંક સ્વરૂપના પ્રશ્નો GUJCET માં નિયમિત આવે છે; A અને B શોધવાની રીત સ્પષ્ટ હોવી જરૂરી.
ખંડશઃ સંકલન (Integration by Parts): ∫u dv = uv − ∫v du. ILATE નિયમ: Inverse → Logarithmic → Algebraic → Trigonometric → Exponential ક્રમે પ્રથમ અને દ્વિતીય વિધેય પસંદ કરો.
બહુ-પદી × ત્રિકોણમિતિય/ઘાતાંકીય વિધેયના સંકલનો માટે અવિભાજ્ય; ILATE યાદ રાખવું પડે.
∫1/√(a²−x²) dx = sin⁻¹(x/a) + C, ∫1/(a²+x²) dx = (1/a)tan⁻¹(x/a) + C, ∫1/(x²−a²) dx = (1/2a)ln|(x−a)/(x+a)| + C, ∫1/√(x²−a²) dx = ln|x+√(x²−a²)| + C.
આ ચાર સૂત્રો GUJCET માં સીધા પ્રશ્નોમાં આવે છે; ગેરંटी સાથે રટાવવા પડે.
ત્રિકોણમિતિય નિત્યસમનો ઉપયોગ: sin²x = (1−cos2x)/2, cos²x = (1+cos2x)/2, sin x sin y = [cos(x−y)−cos(x+y)]/2, आदि. આ નિત્યસમો સંકલનને સરળ બનાવે છે.
sin²x અને cos²x ના સંકલન સીધા રૂપે માફ થતા નથી; દ્વિ-કોણીય સૂત્ર વગર પ્રશ્ન અધૂરું રહે.
નિશ્चित સંકલન (Definite Integral): ∫ₐᵇ f(x) dx = F(b) − F(a), જ્યાં F'(x) = f(x). સીમાઓ (limits) માં ફેરફાર થાય છે, C રદ્દ થઈ જાય છે.
નિશ્चित સંકલનના પ્રશ્નો GUJCET માં બંધનિશ્ચિત રીતે આવે છે; F(b)−F(a) યાદ રાખવું જરૂરી.
ગુણધર્મ: ∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx. આ ગુણધર્મ સિમીટ્રિક મુદ્દાઓ પર સંકલન સરળ બનાવે છે.
GUJCET માં ∫₀^π/2 આકારના પ્રશ્નોમાં આ ગુણધર્મ સૌથી વધુ ઉપયોગી સાબિત થાય છે.
ગુણધર્મ: ∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx સાથે જોડીને, જો f(x)+f(a−x) = constant મળે, તો સંકલન સીધું constant×a/2 બને છે.
આ પદ્ધતિથી ઘણા કઠિન-લાગતા નિશ્চিত સંકલન 30 સેકન્ડમાં ઉકેલાય છે; ઝડપી અંકવાળો પ્રશ્ન.
જો f(x) સમ વિધેય (even function) હોય, ∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx. જો f(x) વિષમ વિધેય (odd function) હોય, ∫₋ₐᵃ f(x) dx = 0.
સમ/વિષમ વિધેયની ಪરખ્ખણી GUJCET માં ઘણીવાર સીધા પ્રશ્ન તરીકે અથવા મહત્વપૂર્ણ સોપાન તરીકે આવે છે.
પ્રથમ મૂળભૂત પ્રમેય (Fundamental Theorem of Calculus — Part 1): જો F(x) = ∫ₐˣ f(t) dt, તો F'(x) = f(x).
સંકલન-અવકલન સંબંધ સમજવા માટે આ પ્રમેય મહત્વપૂર્ણ; GUJCET માં સૂક્ષ્મ પ્રશ્નો આવે છે.
∫e^[f(x)]·f'(x) dx = e^[f(x)] + C અને ∫(1/x)·e^(ln x) dx જેવા સ્વરૂપો ઓળખી શકવા જરૂરી છે; પ્રતિસ્થાપન સીધું લાગુ પડે છે.
કોમ્પોઝિટ વિધેયોના સંકલનમાં f'(x) છેદમાં કે અંશમાં હોય ત્યારે ઓળખ મહત્વપૂર્ણ.
∫√(a²−x²) dx = (x/2)√(a²−x²) + (a²/2)sin⁻¹(x/a) + C. આ સૂત્ર યાદ હોવું જોઈએ અથવા પ્રતિસ્થાપન x = a sin θ દ્વારા મેળવવું જોઈએ.
વર્તુળાકાર વિધેયોના સંકલન GUJCET માં વારંવાર આવે છે.
સંકલનની પદ્ધતિ પસંદગીનું યોગ્ય ક્રમ: (1) સાદું રૂપાંતર → (2) પ્રતિસ્થાપન → (3) આંશિક ભાગો → (4) ખંડશઃ સંકલન → (5) ત્રિકોણમિતિય નિત્યસમ.
પરીક્ષામાં સમય બચાવવા માટે કઈ પદ્ધતિ કયા ક્રમે અજમાવવી તેનું માર્ગદર્શન આવશ્યક છે.
∫tan x dx = ln|sec x| + C, ∫cot x dx = ln|sin x| + C, ∫sec x dx = ln|sec x + tan x| + C, ∫cosec x dx = ln|cosec x − cot x| + C.
આ ચાર વ્યસ્ત સંકલનો GUJCET માં સીધા પ્રશ્ન તરીકે અથવા પગલું તરીકે આવે છે; યાદ રાખવા જરૂરી.
∫f(x)/g(x) dx જ્યાં અંશ g'(x) નો ગુણક હોય: ∫g'(x)/g(x) dx = ln|g(x)| + C. ઉદા: ∫2x/(x²+1) dx = ln(x²+1) + C.
અંશ છેદના વ્યસ્ત અવકલન જેટલો હોય તો સીધો લઘુગણકીય પરિણામ; ઝડપી અંક.
નિશ્ચિત સંકલનમાં સંકલનચલ (variable of integration) નિરર્થક છે: ∫ₐᵇ f(x) dx = ∫ₐᵇ f(t) dt. પરંતુ સીમાઓ અચળ હોવી જોઈએ.
ચલ બદલવાનો આ ગુણધર્મ ખાસ કરીને પ્રમેયોના પ્રશ્નોમાં કામમાં આવે છે.
∫₀^{π/2} f(sin x, cos x) dx માટે π/2 − x પ્રતિસ્થાપન લાગુ પાડો: sin(π/2−x)=cos x, cos(π/2−x)=sin x. આથી f(sin,cos) + f(cos,sin) શોધીને સરળતા હાંસલ કરો.
π/2 સીમાવાળા પ્રશ્નો GUJCET માં ખૂબ જ પ્રચલિત; આ વિધિથી અડધા પ્રશ્નો સીધા ઉકેલાય છે.
