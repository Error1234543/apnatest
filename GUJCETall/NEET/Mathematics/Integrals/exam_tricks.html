🎯 પરીક્ષા ટ્રિક્સ

વિકલન કરી જવાબ પરીક્ષા કરો (Option Differentiation)
જ્યારે ચારેય વિકલ્પોના સ્વરૂપ સમાન હોય અને આપણી પાસે ખૂબ સમય ન હોય.
દા.ત.: ∫eˣ(sec x + tan x) dx નો જવાબ શોધવો હોય. વિકલ્પ A: eˣ sec x → વિકલન કરો: eˣ sec x + eˣ sec x·tan x = eˣ sec x(1+tan x). આ ∫f(x)eˣ(f'(x)+f(x)) પ્રકાર છે.
∫eˣ[f(x) + f'(x)] dx = eˣ·f(x) + C
જ્યારે ઇન્ટિગ્રેન્ડ eˣ સાથે કોઈ વિધેય અને તેનો વિકલન બંનેનો સરવાળો હોય. સીધું જવાબ લખી શકાય.
દા.ત.: ∫eˣ(tan⁻¹x + 1/(1+x²)) dx = eˣ·tan⁻¹x + C, કારણ કે d/dx(tan⁻¹x) = 1/(1+x²).
બદલી તકનીક (Substitution) — sin, cos, tan, eʸ, log માટે પેટર્ન ઓળખો
જ્યારે ઇન્ટિગ્રેન્ડમાં sin x, cos x, eˣ, log x જેવી પુનરાવર્તિત રચના દેખાય.
દા.ત.: ∫sin( sin x )·cos x dx માટે u = sin x લો, du = cos x dx → ∫sin u du = −cos u + C = −cos(sin x) + C.
પ્રમેય: ∫f(a−x)dx = ∫f(x)dx (પ્રમેય-4)
જ્યારે પ્રશ્નમાં [f(x)/{f(x)+f(a−x)}] જેવું સ્વરૂપ હોય, નીચેના સૂત્રનો ઉપયોગ કરી શકાય.
દા.ત.: ∫₀^{π/2} sin x/(sin x+cos x) dx માટે π/2−x મૂકતા ∫₀^{π/2} cos x/(sin x+cos x) dx મળે. બંનેનો સરવાળો = ∫₀^{π/2}1 dx = π/2. ∴ જવાબ = π/4.
∫₀^a f(x) dx = 0 જો f(−x) = −f(x) (કેસ 1)
જ્યારે સીમાઓ 0 થી a હોય અને ઇન્ટિગ્રેન્ડ કુતલ (odd) વિધેય હોય.
દા.ત.: ∫₋ₐ^ₐ x³ cos x dx = 0, કારણ કે f(−x) = (−x)³cos(−x) = −x³cos x = −f(x).
∫₀^a f(x) dx = 2∫₀^{a/2} f(x) dx જો f(a−x) = f(x) (કેસ 2)
જ્યારે f(a−x) = f(x) હોય અને સીમાઓ 0 થી a હોય.
દા.ત.: ∫₀^π x·sin²x dx માટે પ્રમેય લાગુ કરતાં સરળતાથી આંશિક ભાગ શોધી શકાય.
કાંતે (Standard Form) યાદ રાખો: d/dx(eᵘ) = eᵘ·du/dx → ∫eᵘ·u' dx = eᵘ + C
જ્યારે ઇન્ટિગ્રેન્ડમાં કોઈપણ વિધેયનું ઘાતાંકીય સ્વરૂપ હોય અને તે વિધેયનો વિકલન પણ મોડ્યુલમાં હોય.
દા.ત.: ∫(1/x)e^(logₑ x) dx — u = logₑx, du = dx/x → ∫eᵘ du = eᵘ+C = x+C.
કેસ: જો ∫f(ax+b)dx = F(x)+C તો F(ax+b) નહિ પણ F(x) જ જવાબ.
જ્યારે અચળાંક a ≠ 1 હોય અને v-પદ્ધતિ લાગુ પડતી હોય.
દા.ત.: ∫(3x+2)⁵ dx = (3x+2)⁶/(18) + C, ન કે (3x+2)⁶/6 + C.
v-પદ્ધતિ: ∫f(x)g'(x)dx = f(x)∫g'(x)dx − ∫[f'(x)∫g'(x)dx]dx
જ્યારે ઇન્ટિગ્રેન્ડ બે વિધેયોનો ગુણાકાર હોય અને એકનો સીધો સમીકરણ શોધી શકાય.
દા.ત.: ∫x·eˣ dx = x·eˣ − ∫1·eˣ dx = x·eˣ − eˣ + C.
અંશ-છેદ પદ્ધતિ: ∫(x·f(x))/g(x) dx માટે x = (ax+b−b)/a લખો
જ્યારે અંશમાં x હોય અને છેદ rેખીય હોય.
દા.ત.: ∫x/(x+1) dx = ∫[(x+1−1)/(x+1)]dx = ∫(1 − 1/(x+1))dx = x − ln|x+1| + C.
તકનીકી સૂચક: ∫₀^{2a} f(x) dx માટે પ્રમેય — જો f(2a−x) = f(x) તો = 2∫₀^a f(x) dx; જો f(2a−x) = −f(x) તો = 0
જ્યારે ઉચ્ચ સીમા 2a હોય અને પ્રશ્ન GUJCET-શૈલીનાં નિયત સમાંકલનો હોય.
દા.ત.: ∫₀^{2π} sin²x dx, f(2π−x) = sin²(2π−x) = sin²x = f(x), તેથી = 2∫₀^π sin²x dx.
અપૂર્ણાંક વિભાજન (Partial Fractions) — સીધું વ્યવહારિક સૂત્ર યાદ રાખો
જ્યારે છેદ અવિભાજ્ય બહુપદીના અવયવો સ્વરૂપમાં હોય અને પદાવલી સીધી ઓળખી શકાય.
દા.ત.: ∫dx/[(x−1)(x−2)] = ∫[1/(x−2) − 1/(x−1)]dx = ln|x−2| − ln|x−1| + C.
ત્રિકોણમિતીય ઓળખો યાદ રાખો: sin²x = (1−cos2x)/2, cos²x = (1+cos2x)/2
જ્યારે sinⁿx કે cosⁿx ના ઘાતક હોય અને n સરળ હોય.
દા.ત.: ∫sin²x dx = ∫(1−cos2x)/2 dx = x/2 − sin2x/4 + C.
GUJCET ચૂક વચ્ચે — વિકલ્પ C/D પર ધ્યાન આપો (અધિકાંશ વખત અચૂક જવાબ C/D)
જ્યારે ગણતરીમાં સમય ઓછો હોય અને બાકીના બે વિકલ્પો ખોટા એવો સ્પષ્ટ લાગે.
દા.ત.: ∫₂⁴ 1/x dx = ln4 − ln2 = ln2. વિકલ્પો: A) ln2/2 B) 2ln2 C) ln2 D) ln4 → C અને D બંને સાચા, પણ સાદૂપાયેલ સ્વરૂપ C સાચું.
