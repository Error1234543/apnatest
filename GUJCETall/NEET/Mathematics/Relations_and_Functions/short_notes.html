સંબંધ અને વિધેય (Relations and Functions)

🧪 GUJCET — Gujarati • Mathematics • Relations and Functions

📘 વ્યાખ્યાઓ

  • ભાગફળ સમૂહ (Cartesian Product): A × B = {(a, b) : a ∈ A, b ∈ B}
  • સંબંધ (Relation): R ⊆ A × B એ બે ગણો વચ્ચેનો સંબંધ છે
  • વિધેય (Function): દરેક x ∈ A નું B માં ચોક્કસ એક જ y સાથે સંગત થાય તેવો સંબંધ
  • ક્ષેત્રફળ (Domain): f ની વ્યાખ્યા હેઠળ આવેલા આંતરચલના કિંમતોનો ગણ
  • પરિણામક્ષેત્ર (Range): f(A) = {f(x) : x ∈ A}
  • ઓન્વન્ટિક (One-One/Injective): f(a)=f(b) ⇒ a=b, અર્થાત્ બે ભિન્ન બિંદુઓનું પ્રતિબિંબ સરખું ન હોય
  • આપર (Onto/Surjective): f(A) = B, એટલે કે B નું દરેક તત્વ A માંથી પ્રતિબિંબિત થાય
  • બાયજેક્ટિવ (Bijective): સંબંધ એક-એક અને આપર બંને હોય
  • સંયોજન વિધેય (Composition): (fog)(x) = f(g(x))
  • વ્યસ્ત વિધેય (Inverse): f⁻¹(y) = x જો f(x) = y, મળે તેનો ઉપયોગ ઓન્વન્ટિક+આપર હોય

⚡ સૂત્રો

  • A × B ≠ B × A (ક્રમ બદલાય છે)
  • n(A × B) = n(A) · n(B)
  • |A × B| = |A| · |B| જ્યારે |A|, |B| સસીમ હોય
  • fog ≠ gof સામાન્ય રીતે
  • (fog)⁻¹ = g⁻¹ ∘ f⁻¹
  • f(f⁻¹(x)) = x અને f⁻¹(f(x)) = x
  • f(x) = ax + b માટે f⁻¹(x) = (x - b)/a
  • f(f⁻¹(x)) = x ≠ ફક્ત ત્યારે જ જ્યારે f બાયજેક્ટિવ હોય
  • sin²x + cos²x = 1, ત્રિકોણમિતિય મૂળભૂત નિત્યસમ
  • sec²x = 1 + tan²x, cosec²x = 1 + cot²x

⭐ મુખ્ય તથ્યો

  • વિધેય હોવા માટે દરેક x નું એક જ y સાથે સંગત હોવું જોઈએ
  • રેખા આલેખ પરીક્ષણ: આડી રેખા દરેક વખતે એક જ બિંદુએ છેદે તો વિધેય
  • પાઘલી આલેખ પણ વિધેય છે કારણ કે દરેક x નું એક જ y
  • f(x) = c (અચળ વિધેય) એ એક-એક નથી, ક્ષેત્રફળ = R, પરિણામક્ષેત્ર = {c}
  • f(x) = x³ એ બાયજેક્ટિવ છે કારણ કે કઠોર રીતે વધતું વિધેય
  • ત્રિકોણમિતિય વિધેયોની પુનરાવર્તિતતા: sin(x+2π) = sin x, cos(x+2π) = cos x
  • f(x) = ⌊x⌋ (મહત્તમ પૂર્ણાંક વિધેય) એ સતત નથી, સઘન વિધેય છે
  • f(x) = |x| એ સમ વિધેય છે: f(-x) = f(x)
  • f(x) = x, x³, sin x એ વિષમ વિધેયો: f(-x) = -f(x)
  • સમ વિધેયનો આલેખ Y-અક્ષ પ્રત્યે સમમિત, વિષમ વિધેયનો મૂળબિંદુ પ્રત્યે સમમિત
  • f: R → R માટે f⁻¹ અસ્તિત્વ ધરાવે તેમ f બાયજેક્ટિવ હોવું જરૂરી છે
  • f(g(x)) ની વ્યાખ્યા ક્ષેત્રફળ = {x ∈ A : g(x) ∈ A અને f(g(x)) વ્યાખ્યાયિત}
  • f(x) = √(x-2) ની વ્યાખ્યા ક્ષેત્રફળ x ≥ 2, પરિણામક્ષેત્ર [0, ∞)
  • f(x) = 1/x માટે વ્યાખ્યા ક્ષેત્રફળ R - {0}, પરિણામક્ષેત્ર પણ R - {0}
  • f(x) = e^x બાયજેક્ટિવ R → (0, ∞), વ્યસ્ત f⁻¹(x) = ln x
  • ઘાતાંકીય વિધેય f(x) = a^x, a > 1 હોય તો વધતું, 0 < a < 1 હોય તો ઘટતું
  • લઘુગણક વિધેય ln x ની વ્યાખ્યા ક્ષેત્રફળ (0, ∞), પરિણામક્ષેત્ર R

⚠️ સામાન્ય ભૂલો

  • A × B = B × A સાચું માનવાની ભૂલ – સરખા ગણો હોય તો જ સરખા
  • દરેક સંબંધ વિધેય હોતો નથી, પરંતુ દરેક વિધેય સંબંધ છે
  • f⁻¹ હોય તે માટે ફક્ત ઓન્વન્ટિક પૂરતું નથી, આપર પણ જોઈએ
  • fog = gof હોય એ શરતી છે, સામાન્ય રીતે ખોટું
  • f(x) = x² એક-એક છે એવી ભૂલ – Y-અક્ષની જમણી-ડાબી બાજુ સરખું પ્રતિબિંબ
  • f: R → R માટે f(x) = x² આપર નથી કારણ કે ઋણ સંખ્યાઓનું પ્રતિબિંબ નથી
  • વ્યસ્ત વિધેયનું ક્ષેત્રફળ = મૂળ વિધેયનું પરિણામક્ષેત્ર હોય છે
  • ⌊x⌋ નું મહત્તમ પૂર્ણાંક છે, ⌈x⌉ ન્યૂનતમ પૂર્ણાંક – બંનેમાં ફર્ક
  • f(x) = sin x, f: R → [-1, 1] એ આપર છે પણ ઓન્વન્ટિક નથી (પુનરાવર્તન)
  • f(x) = x² + 1, f: R → [1, ∞) એ આપર છે પણ ઓન્વન્ટિક નથી
  • સંયોજનનો ક્રમ જરૂરી છે: (fog)(x) ≠ (gof)(x)
  • (f⁻¹)⁻¹ = f એ સાચું છે, પરંતુ હંમેશા f⁻¹ અસ્તિત્વ ધરાવતું નથી

🔥 હાઈ-યીલ્ડ મુદ્દા

  • GUJCET માં વ્યસ્ત વિધેય શોધવાની સીધી સમસ્યાઓ આવે છે – f⁻¹ શોધવાનું કૌશલ્ય
  • વિધેયના પ્રકાર (ઓન્વન્ટિક, આપર, બાયજેક્ટિવ) નક્કી કરવાના પ્રશ્નો હંમેશા આવે
  • ક્ષેત્રફળ અને પરિણામક્ષેત્ર શોધવાની સમસ્યાઓ ખૂબ સ્પષ્ટ છે
  • સંયોજન વિધેય (fog)(x) ની કિંમત શોધવી ઘણીવાર પૂછાય છે
  • સમ/વિષમ વિધેયની ઓળખ – ઘણા પ્રશ્નો આધારિત
  • त्रिकोणमિતીय વિધેયોની પુનરાવર્તિતતા અને ક્ષેત્રફળ/પરિણામક્ષેત્ર
  • f(x) = x², f: [0,∞)→[0,∞) એ બાયજેક્ટિવ છે – વિધેયની ક્ષેત્રફળ મર્યાદા મહત્વની
  • f(f⁻¹(x)) = x માટેનું સમીકરણ ઉકેલવું
  • પ્રતિબિંબનો ગણ શોધવાનો પ્રશ્નો – R = {(x,y): y = x², x ∈ {-2,-1,0,1,2}}
  • સંબંધ વિધેય છે કે કેમ તેની પરીક્ષા: ક્ષેત્રફળમાં દરેક તત્વનું એક જ પ્રતિબિંબ
  • f(x) = ax+b એ રેખીય વિધેય, ફક્ત a ≠ 0 હોય તો બાયજેક્ટિવ
  • f(x) = 1/(1+x²) નું પરિણામક્ષેત્ર (0, 1] – બહુ મહત્વનું ઉદાહરણ
  • f(x) = [x], g(x) = x - [x] (અપૂર્ણાંશ ભાગ) – એમિસ અને ટ્રેઈલિંગ કાર્ય
  • f: A→B અને g: B→C માટે fog: A→C, ક્ષેત્રફળ નોંધવું
