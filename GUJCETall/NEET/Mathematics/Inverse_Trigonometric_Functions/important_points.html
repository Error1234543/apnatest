🧪 GUJCET — Gujarati • Mathematics • Inverse Trigonometric Functions

⭐ મહત્વના મુદ્દા

વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયોની વ્યાખ્યા - તેઓ ત્રિકોણમિતિય વિધેયોના પ્રતિવર્ત વિધેયો છે, પરંતુ ફક્ત ત્યારે જ વ્યાખ્યાયિત થાય છે જ્યારે મૂળ વિધેય એક-અનુ-એક અને આવર્તી હોય. તેથી અંતરાલને સંકોચીને પ્રધાન શાખા (Principal Branch) નક્કી કરવામાં આવે છે.
GUJCET માં વ્યુત્પન્ન વિધેયોનું સરળ નામ અને તેમના મૂળભૂત ગુણધર્મો પૂછાય છે.
છેટલા ચાર વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયોનું પ્રધાન અંતરાલ: sin⁻¹x નું પ્રધાન અંતરાલ [-π/2, π/2], cos⁻¹x નું [0, π], tan⁻¹x નું (-π/2, π/2), cot⁻¹x નું (0, π), sec⁻¹x નું [0, π] - {π/2}, csc⁻¹x નું [-π/2, π/2] - {0}.
આ પ્રધાન અંતરાલ (Principal Value Branch) ગુણધર્મો અને સરવાળા-અયનોમાં બેઠાં રહે છે; ભૂલ થતાં પરીક્ષામાં નંબર ખોવાય છે.
વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયોના વિષમ-સમાન (Odd-Even) ગુણધર્મો: sin⁻¹(-x) = -sin⁻¹x, tan⁻¹(-x) = -tan⁻¹x, csc⁻¹(-x) = -csc⁻¹x (વિષમ); cos⁻¹(-x) = π - cos⁻¹x, cot⁻¹(-x) = π - cot⁻¹x, sec⁻¹(-x) = π - sec⁻¹x (ન થી વિષમ).
પરખમાં સીધા પ્રશ્નો કે સરવાળા-અયના ગુણધર્મો સાબિત કરવામાં આ ગુણધર્મો વારંવાર વપરાય છે.
મૂળભૂત વિલોમતા સંબંધો (Inverses): sin⁻¹(1/x) = csc⁻¹x (|x| ≥ 1); cos⁻¹(1/x) = sec⁻¹x (|x| ≥ 1); tan⁻¹(1/x) = cot⁻¹x (x > 0).
આ સંબંધો ગણતરીઓમાં મદદરૂપ થાય છે; ખાસ કરીને tan⁻¹(1/x) = cot⁻¹x માટે x>0 શરત યાદ રાખવી પડે છે.
પૂરક કોણ સંબંધ (Complementary angles): sin⁻¹x + cos⁻¹x = π/2, સ્વીકાર્ય x માટે; tan⁻¹x + cot⁻¹x = π/2, x > 0; sec⁻¹x + csc⁻¹x = π/2, |x| ≥ 1.
GUJCET માં સૌથી વધુ આવતા ગુણધર્મો પૈકીનું એક - ઉકેલમાં સરળતા લાવે છે.
tan⁻¹ વિધેય માટેના મૂળભૂત સરવાળા-અય ગુણધર્મો: tan⁻¹x + tan⁻¹y = tan⁻¹[(x+y)/(1-xy)], જ્યારે xy < 1; = tan⁻¹[(x+y)/(1-xy)] + π, જ્યારે xy > 1 અને x,y > 0; = tan⁻¹[(x+y)/(1-xy)] - π, જ્યારે xy > 1 અને x,y < 0.
આ ત્રણેય કિસ્સાઓ પરખમાં પૂછાયા છે અને ઘણીવાર ઉલટા સરવાળા-અય પૂછવામાં આવે છે.
tan⁻¹x - tan⁻¹y = tan⁻¹[(x-y)/(1+xy)], જ્યારે xy > -1; નહિતર π અથવા -π ઉમેરવું પડે છે.
વિયોજન સૂત્ર પણ પરખમાં આવે છે, ખાસ કરીને xy > -1 શરત ધ્યાનમાં રાખવી.
બે ગણાનું સૂત્ર: 2tan⁻¹x = tan⁻¹[2x/(1-x²)], જ્યારે |x| < 1; = tan⁻¹[2x/(1-x²)] + π, જ્યારે x > 1; = tan⁻¹[2x/(1-x²)] - π, જ્યારે x < -1.
આ ગુણધર્મો ઘણી ગણતરીઓમાં ઉપયોગી છે અને GUJCET માં યાદગાર છે.
સીમાબિંદુ મૂલ્યો: tan⁻¹(1) = π/4, sin⁻¹(1/2) = π/6, cos⁻¹(√3/2) = π/6, cot⁻¹(√3) = π/6, sec⁻¹(2) = π/3, csc⁻¹(√2) = π/4.
આ સીમાબિંદુ મૂલ્યો ઝડપી ગણતરી માટે અને બહુવિકલ્પી પ્રશ્નોમાં વારંવાર વપરાય છે.
વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયોનું પ્રતિબિંબ (Graphs) - sin⁻¹x, cos⁻¹x, tan⁻¹x ના આલેખ મૂળભૂત ત્રિકોણમિતિય વિધેયોના આલેખને y = x રેખા પ્રત્યે પ્રતિબિંબિત કરીને મળે છે. tan⁻¹x નો આલેખ સમાંતર asymptotes ધરાવે છે જે y = ±π/2 છે.
આલેખોના પ્રશ્નો કે સીમાઓ સમજવા માટે આલેખોની સમજણ જરૂરી છે.
ગૌણ વિધેયો (Sub-functions): sin⁻¹(sin θ) = θ, જ્યારે θ ∈ [-π/2, π/2]; નહિતર θ ને પ્રધાન અંતરાલમાં લાવવા માટે ખાસ ગણતરી કરવી પડે. cos⁻¹(cos θ) = θ, જ્યારે θ ∈ [0, π].
આવી સમસ્યાઓ પરખમાં ઘણીવાર આવે છે અને વિદ્યાર્થીઓ મોટે ભાગે પ્રધાન અંતરાલ ભૂલી જાય છે.
સામાન્ય રીતે, sin⁻¹(sin θ) = α, જ્યાં α એ [-π/2, π/2] માં એવો કોણ છે કે sin α = sin θ. એટલે θ ને π - θ, 2π + θ, -π - θ જેવા રૂપમાં પ્રધાન શાખામાં મૂકવું પડે છે.
આ રચના અવકાશીય પ્રશ્નોમાં ખૂબ મદદરૂપ છે અને ગણતરી યોગ્ય રીતે કરવામાં માર્ગદર્શન આપે છે.
ચતુર્થાંશ (Quadrant) નિયમ: પ્રત્યેક વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયનું પ્રધાન મૂલ્ય તેના પ્રધાન અંતરાલ મુજબ ચોક્કસ ચતુર્થાંશમાં હોય છે. ઉદા. sin⁻¹x નું મૂલ્ય પ્રથમ કે ચતુર્થ ચતુર્થાંશમાં; cos⁻¹x નું મૂલ્ય પ્રથમ કે દ્વિતીય ચતુર્થાંશમાં.
આ નિયમો ઉકેલમાં ચિહ્ન અને અંતરાલ ચકાસવા માટે ઉપયોગી છે.
tan⁻¹x ની ઘાતાંકીય રચના: જો xy < 1, તો tan⁻¹x + tan⁻¹y + tan⁻¹z = tan⁻¹[(x+y+z-xyz)/(1-xy-yz-zx)], જ્યારે xyz < 1; નહિતર π ઉમેરવું પડે છે.
આ પુરોગામી સૂત્ર અડધાંશ સરવાળા-અયના પ્રશ્નોમાં ઉપયોગી થાય છે.
વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયોના ડેરિવેટિવ્સ (અવકલન): d/dx(sin⁻¹x) = 1/√(1-x²), |x|<1; d/dx(cos⁻¹x) = -1/√(1-x²), |x|<1; d/dx(tan⁻¹x) = 1/(1+x²); d/dx(cot⁻¹x) = -1/(1+x²); d/dx(sec⁻¹x) = 1/(|x|√(x²-1)), |x|>1; d/dx(csc⁻¹x) = -1/(|x|√(x²-1)), |x|>1.
અવકલન વિભાગ સાથે સંબંધિત પ્રશ્નો GUJCET માં આવે છે; ક્રમ અને ચિહ્નો યાદ રાખવા જરૂરી છે.
સંયુક્ત વિધેયો અને સાચવી રાખવા વાળા નિયમો: જ્યારે વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયોનું બીજગણિતીય સમીકરણો સાથે સંયોજન થાય છે, ત્યારે પ્રતિબિંબ અને ચતુર્થાંશ નિયમો યોગ્ય રીતે લાગુ પાડવા પડે છે.
જટિલ પ્રશ્નો માટે આ સૂક્ષ્મતાઓ ગણતરી સાચી રાખે છે.
x > 1 કે x < -1 માટે sec⁻¹x અને csc⁻¹x ની વ્યાખ્યા - આ વિધેયો f(x) = sec⁻¹x અને csc⁻¹x માટે ડોમેન |x| ≥ 1 હોય છે. તેમના ડેરિવેટિવ્સમાં |x| નો સમાવેશ થાય છે.
આ પ્રશ્નોમાં ક્યારેક x ની સાપેક્ષે ચિહ્નની સમસ્યા આવે છે; |x| નો ઉપયોગ યાદ રાખવો જોઈએ.
ત્રિકોણમિતિય વિધેયોમાંથી વ્યુત્પન્ન વિધેયો બનાવવાની પદ્ધતિ: ઉદાહરણ તરીકે, sin⁻¹(2x/1+x²) = 2tan⁻¹x, જ્યારે |x| ≤ 1; અને અન્ય કિસ્સાઓમાં π ± 2tan⁻¹x લખવું પડે છે.
આ પ્રકારના પ્રશ્નો GUJCET માં સામાન્ય છે અને સીમાઓ યાદ રાખવી જરૂરી છે.
cos⁻¹(1-2x²) = 2cos⁻¹x, જ્યારે x ∈ [0,1]; અને sin⁻¹(2x√1-x²) = 2sin⁻¹x, જ્યારે x ∈ [-1/√2, 1/√2]. આવી રચનાઓ અડધાંશ કોણ સૂત્રો સાથે સંબંધિત છે.
આ સૂત્રો પરખમાં ઘણીવાર સીધા પ્રશ્ન રૂપમાં કે ઉકેલમાં વચગાળાના પગલાં તરીકે વપરાય છે.
વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયોના ઉલટા ગુણધર્મો: sin⁻¹x + cos⁻¹x = π/2, tan⁻¹x + cot⁻¹x = π/2, sec⁻¹x + csc⁻¹x = π/2 - આ ત્રણેય સંબંધો વારંવાર સરવાળા-અય સાબિતીમાં વપરાય છે.
આ પ્રકારના ગુણધર્મો GUJCET માં સૌથી વધુ આવતા પ્રશ્નો પૈકીના છે.
ઉચ્ચ કક્ષાની સાબિતી પ્રશ્નોમાં વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયોના વિધેયસમાન (Functional) સમીકરણો - ઉદા. tan⁻¹x - tan⁻¹y = tan⁻¹[(x-y)/(1+xy)] નો ઉપયોગ કરીને jaccobian અથવા સંકલન પ્રશ્નો તૈયાર કરવા.
જટિલ પ્રશ્નો માટે આ પદ્ધતિઓ માર્ગદર્શન આપે છે અને ગણતરીમાં યોગ્યતા ચકાસવામાં મદદરૂપ થાય છે.
વ્યુત્પન્ન ત્રિકોણમિતિય વિધેયોના ડોમેન અને રેન્જનું ધ્યાન: sin⁻¹x અને cos⁻¹x નું ડોમેન [-1,1], રેન્જ અનુક્રમે [-π/2,π/2] અને [0,π]; tan⁻¹x નું ડોમેન ℝ, રેન્જ (-π/2,π/2).
ડોમેન-રેન્જ ભૂલો ઉકેલમાં ખોટા વિકલ્પો તરફ દોરી જાય છે; આ બિંદુઓ પરખમાં ધ્યાનમાં રાખવા જેવા છે.
સામાન્ય ભૂલો - પ્રધાન અંતરાલ ભૂલીને જવાબ લખવો, xy < 1 / xy > 1 શરતોનો ઉપયોગ કરતાં ભૂલ, ચિહ્નોની ગેરહાજરી (ખાસ કરીને cos⁻¹ અને cot⁻¹ માં), અને sec⁻¹/csc⁻¹ માટે |x| ની જરૂરિયાત ભૂલી જવો.
GUJCET માં આ ભૂલો ખૂબ વારંવાર થાય છે; આ બિંદુઓ યાદ રાખવાથી ખોટા જવાબો ટાળી શકાય છે.
