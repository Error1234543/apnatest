બહુપદી પ્રમેય (Binomial Theorem) — ટૂંકા નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Binomial Theorem

📘 વ્યાખ્યાઓ

  • બહુપદી પ્રમેય: (a + b)ⁿ નું વિસ્તરણ કરવાની પદ્ધતિ, જ્યાં n એ અનૃણ પૂર્ણાંક છે.
  • સામાન્ય પદ (General Term): Tᵣ₊₁ = ⁿCᵣ · aⁿ⁻ʳ · bʳ, જે બીજગણિતીય વિસ્તરણનું (r+1)-મું પદ આપે છે.
  • વ્યુત્क्रम પદ (Middle Term): જો n સમ હોય તો (n/2 + 1)-મું પદ; જો n વિષમ હોય તો ((n+1)/2)-મું અને ((n+3)/2)-મું પદ મધ્યમ પદો.
  • ⁿCᵣ (બહુપદી સહગુણક): nમાંથી r વસ્તુઓ પસંદ કરવાની રીતોની સંખ્યા, જેને સંચય કહે છે.
  • સ્થિર પદ (Constant Term): વિસ્તરણનું તે પદ જ્યાં ચલનો ઘાતાંક શૂન્ય થાય.

⚡ સૂત્રો

  • (a + b)ⁿ = ⁿC₀·aⁿ + ⁿC₁·aⁿ⁻¹b + ⁿC₂·aⁿ⁻²b² + ... + ⁿCₙbⁿ
  • (a - b)ⁿ = ⁿC₀·aⁿ - ⁿC₁·aⁿ⁻¹b + ⁿC₂·aⁿ⁻²b² - ... + (-1)ⁿⁿCₙbⁿ
  • Tᵣ₊₁ = ⁿCᵣ · aⁿ⁻ʳ · bʳ (r = 0, 1, 2, ..., n)
  • Tₖ થી નવું પદ = Tₖ₊₁ = Tₖ × [(n - k + 1)/k] × (b/a)
  • ⁿC₀ + ⁿC₁ + ⁿC₂ + ... + ⁿCₙ = 2ⁿ
  • ⁿC₀ - ⁿC₁ + ⁿC₂ - ... + (-1)ⁿⁿCₙ = 0
  • ⁿC₀ + ⁿC₂ + ⁿC₄ + ... = ⁿC₁ + ⁿC₃ + ⁿC₅ + ... = 2ⁿ⁻¹
  • ⁿCᵣ = ⁿCₙ₋ᵣ (સંમિતિ ગુણધર્મ)
  • ⁿCᵣ₋₁ + ⁿCᵣ = ⁿ⁺¹Cᵣ (પાસકલેનું સૂત્ર)
  • n × ⁿCᵣ = (r+1) × ⁿ⁺¹Cᵣ₊₁
  • ⁿCᵣ / ⁿCᵣ₋₁ = (n - r + 1) / r
  • (a + b)ⁿ + (a - b)ⁿ = 2[ⁿC₀aⁿ + ⁿC₂aⁿ⁻²b² + ...]
  • (a + b)ⁿ - (a - b)ⁿ = 2[ⁿC₁aⁿ⁻¹b + ⁿC₃aⁿ⁻³b³ + ...]

⭐ મુખ્ય તથ્યો

  • બહુપદી વિસ્તરણમાં કુલ પદોની સંખ્યા = n + 1.
  • પ્રથમ પદ: ⁿC₀·aⁿ, છેલ્લું પદ: ⁿCₙ·bⁿ.
  • ⁿCᵣ ને "n રાઉન્ડ r" પણ કહેવાય છે.
  • જો r > n હોય તો ⁿCᵣ = 0.
  • ⁿC₀ = ⁿCₙ = 1 હંમેશા.
  • ⁿC₁ = ⁿCₙ₋₁ = n હંમેશા.
  • જો n સમ હોય તો એક જ મધ્યમ પદ; જો n વિષમ હોય તો બે મધ્યમ પદો.
  • બહુપદી સહગુણકોનો સરવાળો 2ⁿ થાય.
  • બહુપદી સહગુણકો સંમિત હોય છે: ⁿC₀ = ⁿCₙ, ⁿC₁ = ⁿCₙ₋₁.
  • ગુણાકાર રૂપે: ⁿCᵣ = n! / [r! × (n - r)!]
  • ન્યુટનનો બહુપદી પ્રમેય: (1 + x)ᵐ જ્યાં m કોઈ પણ વાસ્તવિક સંખ્યા, અનંત શ્રેણી.
  • x < 1 હોય ત્યારે જ ન્યુટનની અનંત બહુપદી શ્રેણી અભિસારી બને છે.
  • બહુપદી સહગુણકોનો મહત્તમ મૂલ્ય: n સમ હોય તો ⁿCₙ/₂; n વિષમ હોય તો ⁿC₍ₙ₋₁₎/₂ અને ⁿC₍ₙ₊₁₎/₂.

⚠️ સામાન્ય ભૂલો

  • (a - b)ⁿ માં વિષમ સ્થાનના પદો ઋણ મળે છે, આ યાદ રાખો.
  • Tᵣ₊₁ સૂત્રમાં r શરૂઆત 0 થી થાય, T₁ માટે r = 0 લેવું.
  • મધ્યમ પદ શોધતી વખતે n સમ/વિષમ હોય તે આધારે પદની સંખ્યા બદલાય છે.
  • ⁿCᵣ = ⁿCₙ₋ᵣ એ જાણીતું પણ ભૂલથી યાદ રાખવામાં આવે છે.
  • સ્થિર પદ શોધવા x નો ઘાતાંક શૂન્ય બરાબર મૂકવો, ઘાતાંક ગેરહાજર હોય તો પણ સમાન.
  • (a + b)ⁿ અને (b + a)ⁿ એક જ હોય પણ પદોના ક્રમમાં ફરક હોઈ શકે.
  • બહુપદી સહગુણકોનો સરવાળો 2ⁿ એ (a=1, b=1) મૂકવાથી મળે છે, આ યાદ રાખો.
  • ન્યુટનના સામાન્ય બહુપદી પ્રમેયમાં ઘાતાંક ધન પૂર્ણાંક ન હોઈ શકે, ભ્રમ ટાળો.
  • p-મું પદ ઉલટા ક્રમે શોધવા: Tₚ = ⁿCₚ₋₁ · aʳ · bⁿ⁻ᵖ⁺¹.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • Tᵣ₊₁ = ⁿCᵣ · aⁿ⁻ʳ · bʳ — આ મૂળભૂત સૂત્ર, આંખ બંધ રાખીને લખી શકવું.
  • બે પદોનો ગુણોત્તર: ⁿCᵣ / ⁿCᵣ₋₁ = (n - r + 1)/r — ગણતરી ઝડપી બનાવે.
  • સંચયનો સરવાળો 2ⁿ અને સમ-વિષમ સહગુણકોનો સરવાળો 2ⁿ⁻¹ — બંને સૂત્ર યાદ રાખો.
  • મધ્યમ પદ: n=6 હોય તો 4મું પદ; n=5 હોય તો 3મું અને 4થી પદ.
  • સ્થિર પદ શોધવા: x નો ઘાતાંક = 0 મૂકીને r શોધો, પછી પદ કાઢો.
  • જો (1 + x)ⁿ ના વિસ્તરણમાં (r-1), r, (r+1) મંદો સંચય સમઆંતર શ્રેણીમાં હોય, તો n = (r-1)(r+1)/r × 2.
  • ⁿC₀² + ⁿC₁² + ... + ⁿCₙ² = ⁿ⁺¹Cₙ — આ મહત્વપૂર્ણ પરિણામ.
  • બે સમાન બહુપદીઓનો ગુણાકાર: (a+b)ᵐ(a+b)ⁿ = (a+b)ᵐ⁺ⁿ.
  • નિશ્ચિત બહુપદી પદ માટે r ની શરત: 0 ≤ r ≤ n.
  • a(b)ⁿના વિસ્તરણમાં બીજા પદનો સહગુણક = n·aⁿ⁻¹·b.
