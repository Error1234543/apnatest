બિનોમિયલ પ્રમેય (Binomial Theorem) — પરીક્ષા ટ્રિક્સ

🧪 GUJCET — Gujarati • Mathematics • Binomial Theorem

🎯 પરીક્ષા ટ્રિક્સ

જ્યારે (a + b)^n મા a અથવા b એ 1 હોય, ત્યારે પદોની સંખ્યા n + 1 થી ઘટીને n થાય છે. ઉદા. (1 + x)^n મા પદો: n + 1, પરંતુ (1 + 1)^n = 2^n મા ફક્ત એક પદ (2^n) જ રહે છે.
જ્યારે a અથવા b ની કિંમત 1 હોય અને પદોની સંખ્યા શોધવી હોય.
દા.ત.: (1 + 2)^3 = 1 + 3*2 + 3*2^2 + 2^3 = 27. અહીં પદોની સંખ્યા 4 (n+1) છે, પરંતુ (1 + 1)^3 = 8 મા ફક્ત એક પદ જોવા મળે છે.
બિનોમિયલ વિસ્તરણમાં મધ્ય પદ શોધવા માટે: જો n બેકી હોય, ત્યારે (n/2 + 1)મું પદ મધ્ય પદ હોય છે. જો n અબેકી હોય, ત્યારે (n+1)/2 અને (n+3)/2 પદો મધ્ય પદો હોય છે.
વિસ્તરણમાં મધ્ય પદ શોધવું હોય ત્યારે.
દા.ત.: (a + b)^4 મા n=4 (બેકી), મધ્ય પદ 3રું (4/2 + 1 = 3) પદ છે: 6a²b².
પરિમાણીય સરખામણી દ્વારા ખોટા વિકલ્પો કાઢી નાખવા: જો પ્રશ્નમાં (a + b)^n ના વિસ્તરણના પદની કિંમત પૂછવામાં આવે અને વિકલ્પોના પરિમાણ (dimension) અલગ હોય, તો પરિમાણ મેળ ન ખાતા વિકલ્પો ખોટા ગણી શકાય.
વિકલ્પોના પરિમાણ તપાસવા માટે, ખાસ કરીને ભૌતિક રાશિઓ સાથે કામ કરતી વખતે.
દા.ત.: (x + y)^3 મા x નું પરિમાણ L હોય અને y નું પરિમાણ L^2 હોય, તો પદ x²y નું પરિમાણ L^4 હશે. જો વિકલ્પમાં L^3 હોય, તો તે ખોટો છે.
જો (a + b)^n + (a - b)^n વિસ્તરણ કરવું હોય, ત્યારે બેકી ઘાતવાળા પદો કાઢી નાખવા: (a + b)^n + (a - b)^n = 2[C(n,0)a^n + C(n,2)a^{n-2}b^2 + ...].
બેકી ઘાતવાળા પદો દૂર કરવા અને સરળીકરણ કરવા.
દા.ત.: (2 + x)^4 + (2 - x)^4 = 2[16 + 6*4*x² + x^4] = 32 + 48x² + 2x^4.
જો (a + b)^n - (a - b)^n વિસ્તરણ કરવું હોય, ત્યારે સમ ઘાતવાળા પદો કાઢી નાખવા: (a + b)^n - (a - b)^n = 2[C(n,1)a^{n-1}b + C(n,3)a^{n-3}b^3 + ...].
સમ ઘાતવાળા પદો દૂર કરવા અને સરળીકરણ કરવા.
દા.ત.: (3 + x)^3 - (3 - x)^3 = 2[3*9*x + x^3] = 54x + 2x^3.
કોઈ પણ પદનો ક્રમ શોધવા માટે: T_{r+1} = C(n, r) a^{n-r} b^r. અહીં r = 0 થી n સુધી હોય છે.
વિશિષ્ટ પદનો ક્રમ અથવા તેનું સૂત્ર લખવું હોય ત્યારે.
દા.ત.: (a + b)^5 મા 4થું પદ (T_4) = C(5, 3) a^{2} b^3 = 10a²b³.
જ્યારે a અને b ની કિંમતો એકસરખી હોય, ત્યારે (a + a)^n = (2a)^n = 2^n * a^n. અહીં ફક્ત એક જ પદ રહે છે.
a = b હોય ત્યારે વિસ્તરણ સરળ બનાવવા.
દા.ત.: (x + x)^4 = (2x)^4 = 16x^4.
બિનોમિયલ ગુણાંક C(n, r) ની કિંમત શોધવા માટે: C(n, r) = n! / (r! (n-r)!). જો r > n/2 હોય, તો C(n, r) = C(n, n-r) વાપરી શકાય.
ગુણાંકની ગણતરી સરળ બનાવવા.
દા.ત.: C(6, 4) = C(6, 2) = (6*5)/(2*1) = 15.
જો પ્રશ્નમાં (1 + x)^n ના વિસ્તરણમાં x^n નો ગુણાંક પૂછવામાં આવે, તો તે હંમેશા 1 હોય છે.
x^n નો ગુણાંક શોધવો હોય ત્યારે.
દા.ત.: (1 + x)^5 મા x^5 નો ગુણાંક C(5,5) = 1 છે.
વિસ્તરણમાં સૌથી મોટો ગુણાંક શોધવા: જો n બેકી હોય, ત્યારે મધ્ય પદનો ગુણાંક સૌથી મોટો હોય છે. જો n અબેકી હોય, ત્યારે મધ્યના બે પદોનો ગુણાંક સરખો અને સૌથી મોટો હોય છે.
સૌથી મોટો બિનોમિયલ ગુણાંક શોધવો હોય ત્યારે.
દા.ત.: (1 + 1)^6 મા મધ્ય પદો C(6,3) = 20 (સૌથી મોટો).
જો (a + b + c)^n વિસ્તરણ કરવું હોય, ત્યારે તેને (a + (b + c))^n તરીકે લખીને બિનોમિયલ પ્રમેય લાગુ કરો અને પછી (b + c)^k ને પુનરાવર્તિત વિસ્તરણ કરો.
ત્રણ પદવાળા બિનોમિયલ વિસ્તરણ માટે.
દા.ત.: (x + y + z)^2 = x^2 + y^2 + z^2 + 2xy + 2yz + 2xz.
જ્યારે પ્રશ્નમાં (a + b)^n + (a - b)^n + (b + a)^n + (b - a)^n જેવી રચના હોય, ત્યારે સરળીકરણ કરવા: (a + b)^n + (a - b)^n = 2[સમ ઘાતવાળા પદો], અને (b + a)^n + (b - a)^n = 2[સમ ઘાતવાળા પદો].
સરખી રચનાઓનું સરળીકરણ કરવા.
દા.ત.: (x + y)^3 + (x - y)^3 + (y + x)^3 + (y - x)^3 = 4[3x²y + y³].
જો પ્રશ્નમાં (1 + x)^{-n} વિસ્તરણ પૂછવામાં આવે, ત્યારે તે અનંત શ્રેણી હોય છે: 1 - nx + n(n+1)/2! x² - n(n+1)(n+2)/3! x³ + ...
નકારાત્મક ઘાતવાળા બિનોમિયલ વિસ્તરણ માટે.
દા.ત.: (1 + x)^{-2} = 1 - 2x + 3x² - 4x³ + ...
બિનોમિયલ ગુણાંકોનો સરવાળો: C(n,0) + C(n,1) + ... + C(n,n) = 2^n. આનો ઉપયોગ ગુણાંકોના સરવાળાની ચકાસણી કરવા માટે થઈ શકે.
ગુણાંકોના સરવાળાની ચકાસણી કરવા.
દા.ત.: C(4,0) + C(4,1) + C(4,2) + C(4,3) + C(4,4) = 1 + 4 + 6 + 4 + 1 = 16 = 2^4.
જો પ્રશ્નમાં (a + b)^n ના વિસ્તરણમાં a અને b ના ઘાતનો સરવાળો સરખો હોય, ત્યારે તે પદ મધ્ય પદ હોઈ શકે છે.
મધ્ય પદ શોધવા માટે ઘાતનો સરવાળો તપાસવા.
દા.ત.: (x + y)^6 મા x³y³ પદ મધ્ય પદ છે, કારણ કે 3 + 3 = 6 = n.
