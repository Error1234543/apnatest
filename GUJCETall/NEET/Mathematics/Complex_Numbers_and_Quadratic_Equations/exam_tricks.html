🎯 પરીક્ષા ટ્રિક્સ

દ્વિઘાત સમીકરણની મૂળની પ્રકૃતિ તર્કબદ્ધ ચકાસણી: D = b² − 4ac > 0 → બે વાસ્તવિક ભિન્ન મૂળ; D = 0 → બે સમાન વાસ્તવિક મૂળ; D < 0 → બે સંયુગ્મી સંકર મૂળ. જવાબની યાદીમાં D નું મૂલ્ય જોઈને જ સરળતાથી યોગ્ય વિકલ્પ પસંદ કરો.
જ્યારે દ્વિઘાત સમીકરણના મૂળની પ્રકૃતિ વિશે પૂછવામાં આવ્યું હોય અને સમીકરણના સહગુણકો આપેલા હોય.
દા.ત.: સમીકરણ x² − 4x + 7 = 0 માટે D = 16 − 28 = −12 < 0, તેથી બે સંયુગ્મી સંકર મૂળ. કોઈ પણ વિકલ્પ 'બે વાસ્તવિક મૂળ' કહેતો હોય તો તરત બાદ કરો.
જો દ્વિઘાત સમીકરણના સહગુણકો વાસ્તવિક હોય અને એક મૂળ સંકર z = a + bi હોય, તો બીજું મૂળ હંમેશા સંયુગ્મી z̄ = a − bi જ હોય. આ તર્કથી બે મૂળ શોધવાની ગણતરી ટાળી શકાય.
જ્યારે એક મૂળ આપેલું હોય અને બીજું મૂળ પૂછવામાં આવ્યું હોય, અથવા કોઈ અજ્ઞાત સહગુણક શોધવાનો હોય.
દા.ત.: જો x² + px + q = 0 નું એક મૂળ 2 + 3i હોય, તો બીજું મૂળ 2 − 3i જ થશે. પછી m + n = (મૂળનો સરવાળો) = 4 → p = −4 મળશે.
ઘનમૂળ આઈકોન (ω) ની મુખ્ય વિશેષતાઓ: ω³ = 1, 1 + ω + ω² = 0, અને ω^(3n) = 1, ω^(3n+1) = ω, ω^(3n+2) = ω². સંકર સંખ્યાઓ ધરાવતા પદાવલીના સાદું રૂપ આપવા આ ત્રણ સૂત્રો યાદ રાખો.
જ્યારે પ્રશ્નમાં ω (omega) સમાવિષ્ટ પદાવલી આપેલી હોય અથવા ઘનમૂળ વિશેષતા પર આધારિત પ્રશ્ન હોય.
દા.ત.: ω⁵ + ω² = ω^(3·1+2) + ω² = ω² + ω² = 2ω². અથવા ω⁷ + ω⁴ + 1 = ω + ω + 1 = 2ω + 1.
સંકર સંખ્યાના પરિમાણ (Modulus) માટે |z₁ · z₂| = |z₁| · |z₂| અને |z₁/z₂| = |z₁|/|z₂|. આ ગુણધર્મો વડે |z₁ × z₂| શોધવા માટે અલગથી ગુણાકાર કરવાની જરૂર ન રહે.
જ્યારે બે સંકર સંખ્યાઓના ગુણાકારનો પરિમાણ શોધવાનો હોય, ખાસ કરીને MCQ માં.
દા.ત.: જો |z₁| = 3 અને |z₂| = 4, તો |z₁ · z₂| = 3 × 4 = 12. સીધો જવાબ મળી જાય છે.
દ્વિઘાત સમીકરણ ax² + bx + c = 0 માટે મૂળનો સરવાળો α + β = −b/a અને ગુણાકાર αβ = c/a. યાદ રાખો: 'સરવાળા' માં ચિહ્ન ઉલટું (-b/a), 'ગુણાકાર' માં ચિહ્ન એ જ (c/a).
જ્યારે મૂળોના સરવાળા/ગુણાકારનો સંબંધ જોડતા પ્રશ્ન હોય, અથવા બીજું મૂળ શોધવાનું હોય.
દા.ત.: 2x² − 5x + 3 = 0 માટે α + β = 5/2, αβ = 3/2. જો એક મૂળ 3 હોય તો બીજું મૂળ = (3/2)÷3 = 1/2.
વિકલ્પ ચકાસણી (Option Elimination): MCQ માં દ્વિઘાત સમીકરણના મૂળ પૂછવા હોય, તો આપેલા વિકલ્પોમાંથી દરેક મૂળ સમીકરણમાં મૂકીને ચકાસો. સાચું મૂળ મૂકતાં F(z) = 0 મળે.
જ્યારે સમીકરણ જટિલ લાગતું હોય અથવા ડિસ્ક્રિમિનન્ટ શૂન્યાતિત હોય.
દા.ત.: x² − 3x + 2 = 0 ના મૂળ શોધવાના હોય. વિકલ્પ (a) 1,2 (b) −1,−2… x = 1 મૂકતાં 1 − 3 + 2 = 0 → સાચો મૂળ. x = 2 મૂકતાં 4 − 6 + 2 = 0 → બંને મૂળ.
સંકર સંખ્યાનું સંયુગ્મી (Conjugate): જો z = a + bi, તો z̄ = a − bi. વિશેષતા: z · z̄ = a² + b² = |z|². આ સૂત્ર વડે સંયુગ્મી શોધીને ભિન્નનું પરિમાણ મેળવી શકાય.
જ્યારે સંકર ભિન્નનો પરિમાણ શોધવાનો હોય અથવા 1/z જેવી પદાવલી સરળ બનાવવાની હોય.
દા.ત.: જો z = 3 + 4i, તો z̄ = 3 − 4i, અને |z|² = 9 + 16 = 25. આમ 1/z = z̄/|z|² = (3−4i)/25.
બે દ્વિઘાત સમીકરણો ax² + bx + c = 0 અને a'x² + b'x + c' = 0 નું સામાન્ય મૂળ હોય તો (ab' − a'b)(bc' − b'c) = (ca' − c'a)² શરત ઉપયોગમાં લો.
જ્યારે બે દ્વિઘાત સમીકરણો વચ્ચે સામાન્ય મૂળ માટેનો સંબંધ શોધવાનો હોય.
દા.ત.: x² − 5x + 6 = 0 અને 2x² − 7x + 6 = 0 માટે a=1,b=−5,c=6, a'=2,b'=−7,c'=6. સામાન્ય મૂળ = 2 છે (રેખીય અનુપાતથી પણ ચકાસી શકાય).
સંકર સમતલ (Argand plane) માં z = a + bi બિંદુ (a, b) પર દર્શાવે છે. જો પ્રશ્નમાં z નું કોઈ ભૌમિતિક સ્થાન પૂછતું હોય, તો સરળતાથી યાદી બનાવીને વિકલ્પ નક્કી કરો.
જ્યારે Argand પ્લેનમાં સંકર સંખ્યાના સ્થાન કે ભૂલબધાઈ (locus) વિશે પૂછવામાં આવ્યું હોય.
દા.ત.: z = 1 + i√3 હોય, તો |z| = √(1+3) = 2 અને arg(z) = tan⁻¹(√3) = π/3. આથી z = 2[cos(π/3) + i sin(π/3)].
પૂર્ણાંક ઘાતવાળા ω માટે: ω⁰ = 1, ω¹ = ω, ω² = ω², ω³ = 1, ω⁴ = ω, ω⁵ = ω², ω⁶ = 1… એટલે કે ઘાતને 3 વડે ભાગતા ભાગફળ અનુસાર ω, ω², અથવા 1 મળે. આ પેટર્ન યાદ રાખો.
જ્યારે ω ની ઉચ્ચ ઘાત ધરાવતી પદાવલી સાદું રૂપ આપવાનું હોય.
દા.ત.: ω¹⁰ = ω^(3·3+1) = ω, ω¹¹ = ω^(3·3+2) = ω², ω¹² = ω^(3·4) = 1.
d ≠ 0 માટે સમીકરણ ax² + bx + c = 0 નું બંને મૂળ વાસ્તવિક અને વિષમ (unequal) હોવા માટે D > 0 જરૂરી અને પુરતું છે. MCQ માં D ની કિંમતની ગણતરી કરીને વિકલ્પો છોડી શકાય.
જ્યારે પ્રશ્નમાં 'બંને મૂળ વાસ્તવિક અને અસમાન છે' તેવા શરતવાળા પ્રશ્ન હોય.
દા.ત.: x² + 2x + k = 0 ના મૂળ વાસ્તવિક અને અસમાન હોય તે માટે D = 4 − 4k > 0 → k < 1. આથી k = 0, −1, −2… સ્વીકાર્ય. k = 1 અથવા તેથી મોટું નહીં.
સંકર સંખ્યા z નું ધ્રુવીય સ્વરૂપ (Polar form): z = r(cos θ + i sin θ) જ્યાં r = |z| = √(a²+b²) અને θ = arg(z). D = r e^(iθ) સ્વરૂપ પણ અપનાવી શકાય. MCQ માં વિકલ્પો પડછાં જોઈને યોગ્ય સ્વરૂપ પસંદ કરો.
જ્યારે સંકર સંખ્યાનું ધ્રુવીય અથવા ઘાતાંકીય સ્વરૂપ શોધવાનું હોય.
દા.ત.: z = 1 − i √3 માટે r = 2, θ = −π/3 (અથવા 5π/3). આમ z = 2[cos(−π/3) + i sin(−π/3)] = 2e^(−iπ/3).
