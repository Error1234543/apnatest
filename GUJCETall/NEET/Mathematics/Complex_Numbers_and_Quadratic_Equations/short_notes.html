સંકીર્ણ સંખ્યાઓ અને દ્વિઘાત સમીકરણો — ઝડપી રીવિઝન

🧪 GUJCET — Gujarati • Mathematics • Complex Numbers and Quadratic Equations

📘 વ્યાખ્યાઓ

  • સંકીર્ણ સંખ્યા (Complex Number): a + ib સ્વરૂપની સંખ્યા, જ્યાં a, b વાસ્તવિક છે અને i = √(-1)
  • વાસ્તવિક ભાગ (Real Part): Re(z) = a એ z = a + ib માં iનો ગુણાંક વિનાનો ભાગ
  • કાલ્પનિક ભાગ (Imaginary Part): Im(z) = b એ z = a + ib માં iનો સહગુણક
  • શૂન્યકાલ્પનિક સંખ્યા (Pure Imaginary): z = ib સ્વરૂપ, જ્યાં a = 0
  • સંયુગ્મી (Conjugate): z = a + ib નું સંયુગ્મી z̄ = a - ib
  • અર્ગાંડ તલ (Argand Plane): કાલ્પનિક અક્ષ અને વાસ્તવિક અક્ષ પર સંકીર્ણ સંખ્યાઓ દર્શાવતી પ્લેન
  • મોડ્યુલસ (Modulus): |z| = √(a² + b²) — ઉગમબિંદુ થી બિંદુ સુધીનું અંતર
  • પ્રમાણભૂત તર્ક (Principal Argument): θ ∈ (-π, π] એવો કોણ કે z = r(cosθ + i sinθ)
  • વિમાન સ્વરૂપ (Polar Form): z = r(cosθ + i sinθ) = r cisθ, જ્યાં r = |z|
  • યુલર સ્વરૂપ (Euler's Form): z = re^(iθ), જ્યાં e^(iθ) = cosθ + i sinθ

⚡ સૂત્રો

  • જોડાણ: z₁ + z₂ = (a₁+a₂) + i(b₁+b₂)
  • ગુણાકાર: z₁·z₂ = (a₁a₂ - b₁b₂) + i(a₁b₂ + a₂b₁)
  • વિભાજન: z₁/z₂ = z₁·z̄₂/|z₂|²
  • મોડ્યુલસ ગુણધર્મ: |z₁z₂| = |z₁||z₂| ; |z₁/z₂| = |z₁|/|z₂|
  • 三角 સ્વરૂપ: z₁/z₂ = (r₁/r₂)[cos(θ₁-θ₂) + i sin(θ₁-θ₂)]
  • De Moivre: (cosθ + i sinθ)^n = cos(nθ) + i sin(nθ)
  • ઘાતાંક સ્વરૂપ: z₁·z₂ = r₁r₂·e^(i(θ₁+θ₂))
  • વર્ગમૂળ: √(a+ib) = ±[√((|z|+a)/2) + i·sgn(b)√((|z|-a)/2)]
  • સમીકરણનું મૂળ: ax² + bx + c = 0 → x = (-b ± √D)/2a, D = b² - 4ac
  • વિભેદક D < 0 → સંકીર્ણ મૂળ; D = 0 → સમાન મૂળ; D > 0 → વાસ્તવિક મૂળ
  • મૂળોનો સરવાળો: α + β = -b/a ; ગુણાકાર: αβ = c/a
  • સંયુગ્મી મૂળ પ્રમેય: વાસ્તવિક ગુણાંક વાળા બહુપદીનું સંકીર્ણ મૂળ z હોય → z̄ પણ મૂળ

⭐ મુખ્ય તથ્યો

  • i⁴ = 1 ; i² = -1 ; i³ = -i ; i⁴ⁿ = 1 ; i⁴ⁿ⁺¹ = i ; i⁴ⁿ⁺² = -1 ; i⁴ⁿ⁺³ = -i
  • |z| ≥ 0 અને |z| = 0 ⟺ z = 0
  • |z| = |z̄| = |-z| = |z₁z₂|^{1/n} લાગુ પડે છે
  • z + z̄ = 2Re(z) ; z - z̄ = 2i Im(z)
  • z·z̄ = |z|²
  • |z₁ + z₂| ≤ |z₁| + |z₂| (ત્રિભુજ અસમતા — Triangle Inequality)
  • |z₁ - z₂| ≥ ||z₁| - |z₂|| (વિപરીત ત્રિભુજ અસમતા)
  • ઘનમૂળ એકમ (Cube Roots of Unity): 1, ω, ω² જ્યાં ω = (-1 + i√3)/2, ω² = (-1 - i√3)/2
  • ω³ = 1 ; 1 + ω + ω² = 0 ; ω⁴ = ω ; ω⁵ = ω²
  • સમીકરણ x² + x + 1 = 0 ના મૂળ ω અને ω² છે
  • n-મા ઘનમૂળ એકમ એકમ વૃત્દ પર સમાન અંતરે વિન્યાસિત બિંદુઓ છે
  • દ્વિઘાત સમીકરણનાં મૂળ વાસ્તવિક છે ⟺ D ≥ 0

⚠️ સામાન્ય ભૂલો

  • √(-4) = 2i — કદાચ √(-4) = 4i લખી દે (તાકાત લાગુ પડતી નથી)
  • |z₁ + z₂| = |z₁| + |z₂| એ સામાન્ય રીતે ખોટું છે — ફક્ત ત્યારે જ જ્યારે યુકત (collinear)
  • Arg(z) અને amp(z)માં મુખ્ય તર્ક vs સામાન્ય તર્ક — વિભેદ જાળવો
  • z² = -1 ⟹ z = ±i — પણ z = i એ જ ઉકેલ છે (સમીકરણનો અર્થ સ્પષ્ટ કરો)
  • સંયુગ્મી મૂળ પ્રમેય ફક્ત વાસ્તવિક ગુણાંકવાળા બહુપદી માટે લાગુ
  • de Moivre નો ઉપયોગ ફક્ત વાસ્તવિક n માટે — n ભિન્ન હોય તો અન્ય રીત
  • ω² નો વર્ગમૂળ લેતી વખતે sgn(b) નો ગુણાકાર ભૂલે ચૂકે ભૂલી જવો
  • D = 0 હોય તો પણ મૂળ સંકીર્ણ નથી હોતા — બંને મૂળ વાસ્તવિક અને સમાન
  • |z|² = z² લખવું ગلط છે — |z|² = z·z̄ છે

🔥 હાઈ-યીલ્ડ મુદ્દા

  • z = a + ib માં a = Re(z), b = Im(z) નીચે iનો ગુણાંક યાદ રાખો — b સંખ્યા છે, ib નહીં
  • modulus શોધવા |z| = √(a² + b²) એ સૌથી વધુ ઉપયોગી સૂત્ર
  • ω મૂળછેદ પર 120°ના ખૂણે આવેલા બિંદુ — ત્રિભુજ યાદ રાખો
  • De Moivre નો ઉપયોગ: (a+ib)^n નું વિસ્તરણ અને sin/cos ના બહુગુણક સૂત્રો
  • સંકીર્ણ સંખ્યાનો અંદરનો સંચય: z = r(cosθ + i sinθ) — polar form પર ભાર
  • શરત: az² + bz + c = 0 માં a,b,c વાસ્તવિક હોય અને D < 0 હોય → મૂળ સંયુગ્મી જોડ
  • |z - z₁| = |z - z₂| એ z₁ અને z₂ ને જોડતી રેખાપર લંબદ્વિભાજક છે
  • ચતુષ્કોણ ABCD સમાંતરબાજુ છે ⟺ z₁ + z₃ = z₂ + z₄
  • એકમ ઘનમૂળ 1, ω, ω² એ સમબાજુ ત્રિભુજના શીર્ષબિંદુ બનાવે છે
  • પ્રશ્નોમાં z + 1/z સ્વરૂપ જોવા મળે → અથવા z - 1/z બનાવો, મોડ્યુલસ વડે સરળ બને
  • સંકીર્ણ સમીકરણોના મૂળો સંયુગ્મી જોડમાં હોય — એક મૂળ આપે → બીજું મૂળ તરત લખો
  • દ્વિઘાત સમીકરણના મૂળોનો સરવાળો અને ગુણાકાર નક્કી કરવા પ્રમેય અવશ્ય વાપરો
  • વર્ગમૂળ નીચેના સૂત્રમાં |z| શોધી પછી વપરાય — step-by-step યાદ રાખો
  • D = b² - 4ac ની ગણતરીમાં ચિહ્ન ભૂલો વધુ થાય છે — ધ્યાનથી ગણો
