સંકર સંખ્યાઓ અને દ્વિઘાત સમીકરણો

🧪 GUJCET — Gujarati • Mathematics • Complex Numbers and Quadratic Equations

આ અધ્યાય ગણિતના એક મહત્વપૂર્ણ વિભાગનું પ્રતિનિધિત્વ કરે છે, જ્યાં વાસ્તવિક સંખ્યાઓની બહાર સંખ્યાવ્યવસ્થાનું વિસ્તરણ કરવામાં આવે છે. વર્ગમૂળ હેઠળની ઋણ સંખ્યાઓનું સમાધાન કરવા 'કાલ્પનિક એકમ' i ની પરિભાષા રજૂ કરવામાં આવે છે. આ ભાગમાં સંકર સંખ્યાઓની બીજગણિતીય પ્રક્રિયાઓ, તેમના ગૂણધર્મો, દ્વિઘાત સમીકરણોના બીજ શોધવાની પદ્ધતિઓ અને તેમના ભૌમિતિક નિરૂપણનો સમાવેશ થાય છે. સંકર સંખ્યાઓનો ઉપયોગ પ્રતિબિંબ, ઘૂર્ણન (rotation) અને અન્ય ઘણા વૈજ્ઞાનિક અને ઇજનેરી વીતકોમાં થાય છે.

સંકર સંખ્યાઓની સ્વરૂપ અને પરિભાષા

જ્યારે કોઈ વાસ્તવિક સંખ્યા a નું વર્ગમૂળ લેવાનું હોય અને a ઋણ હોય, ત્યારે વાસ્તવિક સંખ્યાવ્યવસ્થામાં આ સંખ્યા મળતી નથી. તેથી, આપણે એક નવી સંખ્યા i ની પરિભાષા કરીએ છીએ, જ્યાં i² = -1. આ i ને 'કાલ્પનિક એકમ' કહે છે. હવે, k ∈ ℝ માટે ki એ ઋણ વાસ્તવિક સંખ્યાનો વર્ગમૂળ છે. જેથી √(-k) = √k · i. જો a અને b બે વાસ્તવિક સંખ્યાઓ હોય, તો z = a + bi એ સંકર સંખ્યા છે. અહીં 'a' ને સંકર સંખ્યાનો વાસ્તવિક ભાગ અને 'b' ને કાલ્પનિક ભાગ કહે છે. આપણે ℂ એટલે સંકર સંખ્યાઓના સમૂહની પરિભાષા કરીએ છીએ. જો Re(z) = 0 હોય, તો z શુદ્ધ કાલ્પનિક છે; જો Im(z) = 0 હોય, તો z વાસ્તવિક છે. દા.ત., z = 3 + 4i માં Re(z) = 3, Im(z) = 4.

સંકર સંખ્યાઓના ગુણધર્મો

સંકર સંખ્યાઓના ગુણધર્મો ખૂબ જ ઉપયોગી છે. મૂળભૂત ગુણધર્મોમાં, કોઈપણ સંકર સંખ્યા z = a + bi માટે, Re(z) = a અને Im(z) = b. જો z = x + iy હોય, તો iz = ix + i²y = -y + ix થાય. તેથી Re(iz) = -Im(z) અને Im(iz) = Re(z). આ ગુણધર્મ ભૌમિતિક રીતે સંકર સંખ્યાને મૂળબિંદુની આસપાસ 90° ગડીદીશમાં ફેરવવા (rotate) સમકક્ષ છે. બીજું મહત્વપૂર્ણ ગુણધર્મ: z = a + bi માટે, z + z̄ = 2a અને z - z̄ = 2bi, જ્યાં z̄ = a - bi એ સંકર સંખ્યાનો અનુબદ્ધ (conjugate) છે. આપણે સાબિતી કરી શકીએ કે zz̄ = a² + b², જે |z|² બરાબર છે. આ ગુણધર્મોનો ઉપયોગ સંકર સંખ્યાના વિલોમ (inverse) શોધવામાં અને ભાગાકાર સરળ બનાવવામાં થાય છે.

સંકર સંખ્યાઓની બીજગણિત

જો z₁ = a + ib અને z₂ = c + id હોય, તો તેમના વચ્ચેનો સરવાળો z₁ + z₂ = (a + c) + i(b + d) થાય. બાદબાકી z₁ - z₂ = (a - c) + i(b - d) બને. ગુણાકારમાં z₁z₂ = (ac - bd) + i(ad + bc) થાય, જેમ કે (a + ib)(c + id) = ac + iad + ibc + i²bd અને i² = -1 મૂકતાં મળે છે. સંકર સંખ્યાઓનો સરવાળો અને ગુણાકાર ઉપરોક્ત ગુણધર્મો ધરાવે છે: સંયોજક (associative), વિનિમય (commutative), અને વિતરણ (distributive) નિયમો લાગુ પડે છે. સંકર સંખ્યા z ≠ 0 માટે, z⁻¹ = z̄ / |z|² = (a - ib) / (a² + b²) મળે છે. આથી, કોઈપણ બે સંકર સંખ્યાઓના ભાગાકારમાં છેદને વાસ્તવિક બનાવવા આપણે અનુબદ્ધથી ગુણીએ છીએ. ઉદાહરણ તરીકે, (a + ib)/(c + id) = [(a + ib)(c - id)]/(c² + d²). આ બીજગણિતીય પ્રક્રિયાઓનો સરળતાથી ઉપયોગ પછીના ભાગમાં થશે.

સંકર સંખ્યાનો અનુબદ્ધ અને મોડ્યુલસ

જો z = a + ib હોય, તો z નો અનુબદ્ધ (conjugate) z̄ = a - ib થાય. અનુબદ્ધનો ઉપયોગ sંકર સંખ્યાને અર્ધ-વાસ્તવિક (real) અને અર્ધ-કાલ્પનિક ભાગોમાં અલગ પાડવા માટે થાય છે. મોડ્યુલસ |z| એટલે z માટેનું અંતર ઊગમબિંદુથી, જે |z| = √(a² + b²) છે. આ પાયથાગોરસ પ્રમેય પરથી સીધું મળે છે, કારણ કે z ને ડિફાર્ટ કોઓર્ડિનેટ્સ (a,b) પર વેક્ટર તરીકે ભાવી શકાય. મોડ્યુલસના ગુણધર્મો: |z₁z₂| = |z₁||z₂|, |z₁/z₂| = |z₁|/|z₂| (જો z₂ ≠ 0), અને t્રિકોણ અસમાનતા |z₁ + z₂| ≤ |z₁| + |z₂|. આ ગુણધર્મો બિન-સંકર સંખ્યાઓના મોડ્યુલસ ગુણધર્મો સાથે સમાન છે. શુદ્ધ કાલ્પનિક સંખ્યા z = iy માટે |z| = |y| અને વાસ્તવિક સંખ્યા z = x માટે |z| = |x|.

સંકર સંખ્યાનું ભૌમિતિક નિરૂપણ

કોમ્પ્લેક્સ પ્લેન (Argand plane) માં, x-અક્ષને વાસ્તવિક અક્ષ અને y-અક્ષને કાલ્પનિક અક્ષ લઈએ છીએ. z = a + ib ને (a, b) બિંદુ તરીકે દર્શાવી શકાય. આ બિંદુ અને ઊગમબિંદુ જોડતું રેખાખંડ |z| લંબાઈનું હોય છે. z ને polar સ્વરૂપમાં પણ રૂપાંતરિત કરી શકાય: z = r(cos θ + i sin θ), જ્યાં r = |z| અને θ = arg z. અહીં θ એ x-અક્ષ સાથેનો ખૂણો છે, જેને argument કહે છે. આ પોલર સ્વરૂપ ગુણાકાર અને ભાગાકારને સરળ બનાવે છે: z₁z₂ = r₁r₂[cos(θ₁+θ₂) + i sin(θ₁+θ₂)]. ભૌમિતિક રીતે, અનુબદ્ધ z̄ એ x-અક્ષ પર પ્રતિબિંબ છે. z₁ અને z₂ વચ્ચેનું અંતર |z₁ - z₂| થાય. આ ભૌમિતિક નિરૂપણ ભૌતિકશાસ્ત્ર અને ઇજનેરીમાં ખૂબ ઉપયોગી છે.

દ્વિઘાત સમીકરણોના બીજ અને તેમનો સંબંધ

દ્વિઘાત સમીકરણ ax² + bx + c = 0 (a ≠ 0) ને ધ્યાનમાં લઈએ. તેના બીજ α અને β હોય. α + β = -b/a અને αβ = c/a. આ સંબંધો વિએટાના સૂત્રો (Vieta's formulas) તરીકે ઓળખાય છે. બે બીજ વાસ્તવિક અને અલગ હોય જો discriminant Δ = b² - 4ac > 0 હોય; વાસ્તવિક અને સમાન જો Δ = 0 હોય; અને કાલ્પનિક (complex conjugate pair) જો Δ < 0 હોય. જ્યારે Δ < 0 હોય, ત્યારે બીજ α = [-b + i√(-Δ)]/(2a) અને β = [-b - i√(-Δ)]/(2a) મળે, જે એકબીજાના અનુબદ્ધ છે. આ સમીકરણનું વર્ગમૂળ વિસ્તારમાં સંકર સંખ્યાઓ વિના ઉકેલી શકાતું નથી. ઉદાહરણ: x² + 1 = 0 માટે બીજ i અને -i મળે છે. આ બીજનો સરવાળો 0 અને ગુણાકાર 1 થાય.

કોમ્પ્લેક્સ પ્લેનમાં ભૌમિતિક અર્થઘટન

સંકર સંખ્યાઓને કોમ્પ્લેક્સ પ્લેનમાં દર્શાવતાં ભૌમિતિક અર્થઘટન મળે છે. z₁ અને z₂ બે બિંદુઓ હોય, તો z₁ + z₂ એ parallelogram નો અન્ય શિરોબિંદુ બનાવે છે. z₁ - z₂ એ બે બિંદુઓ વચ્ચેનું વિસ્થાપન (displacement) દર્શાવે છે. |z - z₀| = r એ z₀ કેન્દ્ર ધરાવતું અને r ત્રિજા ધરાવતું વર્તુળ દર્શાવે છે. Re(z) = c એ uભી રેખા અને Im(z) = c એ આડી રેખા બનાવે છે. arg(z) = θ એ મૂળબિંદુથી નીકળતો એક કિરણ દર્શાવે છે. બે સંકર સંખ્યાઓ વચ્ચેનો ખૂણો arg(z₁/z₂) થાય. આ ભૌમિતિક અર્થઘટન સંકર સંખ્યાઓની ભૌતિક દૃષ્ટિએ વધુ સમજણ આપે છે. ઉદાહરણ તરીકે, |z - 1| = |z + 1| એ z ને (0,0) થી સમાન અંતરે રાખે છે, જે y-અક્ષ થાય.

ક્યુબિક સમીકરણોના બીજ અને સંબંધો

ત્રિઘાત સમીકરણ ax³ + bx² + cx + d = 0 (a ≠ 0) ના ત્રણ બીજ α, β, γ હોય. તેમના સંબંધો: α + β + γ = -b/a, αβ + βγ + γα = c/a, અને αβγ = -d/a. જો સમીકરણના સહગુણકો વાસ્તવિક હોય, તો કાલ્પનિક બીજ હંમેશા જોડીમાં (conjugate pairs) મળે. દા.ત., જો α = p + iq એ બીજ હોય, તો β = p - iq પણ બીજ હોય. ત્રીજું બીજ γ વાસ્તવિક હોય. ઉદાહરણ: x³ - 6x² + 11x - 6 = 0 ના બીજ 1, 2, 3 છે. જો બીજો સમીકરણ x³ - 3x² + 4x - 2 = 0 હોય, તો x = 1 બીજ છે. બાકીના બીજ શોધવા માટે ભાગાકાર કરતાં x² - 2x + 2 = 0 મળે, જેના બીજ 1 ± i છે. આમ, ત્રણેય બીજ 1, 1+i, 1-i થાય.

ઉદાહરણો અને અભ્યાસ પ્રશ્નો

ઉદાહરણ: જો z = 1 + i હોય, તો z² શોધો. z² = (1+i)² = 1 + 2i + i² = 1 + 2i - 1 = 2i. બીજું: જો z = 3 + 4i હોય, તો |z|² = 3² + 4² = 25. ત્રીજું: (2 + 3i)/(1 - i) નું સરળીકરણ: [(2+3i)(1+i)] / [(1-i)(1+i)] = (2 + 2i + 3i + 3i²)/(1 - i²) = (2 + 5i - 3)/(1 + 1) = (-1 + 5i)/2. ચોથું: x² + x + 1 = 0 ના બીજ શોધો. Δ = 1 - 4 = -3, તેથી બીજ [-1 ± i√3]/2, એટલે ω અને ω², જ્યાં ω એ આઇડિંગ (cube root of unity) છે. આ ઉદાહરણો સમજવડાવવા માટે છે અને વિદ્યાર્થીઓએ પોતે વધુ પ્રશ્નો ઉકેલવા જોઈએ.

⭐ મહત્વના મુદ્દા

  • i² = -1, તેથી √(-k) = i√k for k>0.
  • Non-real complex roots always appear in conjugate pairs for real-coefficient polynomials.
  • The geometric interpretation of z maps to the point (a,b) on the complex plane.
  • Conjugate z̄ is the reflection of z across the real axis.
  • The modulus |z| represents the distance from the origin to the point representing z.
  • For cubic equations with real coefficients, either all three roots are real or one is real and two are complex conjugates.
  • ω = (-1 + i√3)/2 and ω² = (-1 - i√3)/2 are cube roots of unity, satisfying 1 + ω + ω² = 0 and ω³ = 1.
  • Algebraic operations on complex numbers follow the same commutative, associative, and distributive laws as real numbers.

⚠️ સામાન્ય ભૂલો

Mistaking √(-4) as 2i instead of 2i (sign errors in extracting square roots of negatives).
Forgetting that (a+ib)² = a² - b² + 2abi, not a² + b² + 2abi.
Incorrectly computing the modulus as a + b instead of √(a²+b²).
Assuming complex roots can be arbitrary without considering conjugate pairs when coefficients are real.
Forgetting that z + z̄ = 2a and z - z̄ = 2bi, mixing up signs.
Not rationalizing denominators when dividing complex numbers by multiplying by the conjugate.
Confusing the argument θ with the angle in degrees rather than radians when using polar form.
Incorrectly applying Vieta's formulas by missing the negative sign for sum of roots.

🎯 પરીક્ષા ટિપ્સ

Always express complex numbers in the form a+ib before performing operations.
When finding square roots of negative numbers, explicitly write i first before simplifying the radical.
Use the property z·z̄ = |z|² to find inverses quickly.
For polynomial equations, check for integer roots using the Rational Root Theorem before using the quadratic formula.
Remember that the product of complex conjugates is always a real number.
In geometry problems on the complex plane, draw the Argand diagram to visualize relationships.
Practice computing arguments carefully, considering the quadrant in which the complex number lies.
For cubic equations, factorize by synthetic division after finding one root.
