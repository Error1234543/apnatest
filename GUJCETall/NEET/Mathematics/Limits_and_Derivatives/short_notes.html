મર્યાદાઓ અને વિકલજ (Limits and Derivatives)

🧪 GUJCET — Gujarati • Mathematics • Limits and Derivatives

📘 વ્યાખ્યાઓ

  • મર્યાદા (Limit): જ્યારે x નું મૂલ્ય a તરફ પ્રવેશે છે ત્યારે f(x) નું જે અચળ મૂલ્ય લે છે તેને x→a માટે f(x) ની મર્યાદા કહે.
  • ડાબી બાજુની મર્યાદા (Left-Hand Limit): x, a થી ઓછા મૂલ્યો તરફથી a તરફ જાય ત્યારે f(x) નું મૂલ્ય.
  • જમણી બાજુની મર્યાદા (Right-Hand Limit): x, a થી વધુ મૂલ્યો તરફથી a તરફ જાય ત્યારે f(x) નું મૂલ્ય.
  • સતતતા (Continuity): f(x) એ x=a પર સતત છે જો lim(x→a) f(x) = f(a) હોય.
  • વિકલજ (Derivative): f'(x) = lim(h→0) [f(x+h) - f(x)]/h એ f નો x સાપેક્ષે વિકલજ છે.
  • વિકલન (Differentiation): ફલનના મર્યાદા પ્રમેયનો ઉપયોગ કરીને તેનો વિકલજ શોધવાની પ્રક્રિયા.

⚡ સૂત્રો

  • lim(x→a) [f(x) ± g(x)] = lim(x→a) f(x) ± lim(x→a) g(x)
  • lim(x→a) [f(x) · g(x)] = lim(x→a) f(x) · lim(x→a) g(x)
  • lim(x→a) [f(x)/g(x)] = lim(x→a) f(x) / lim(x→a) g(x), જો g(a) ≠ 0
  • lim(x→a) c = c (જ્યાં c અચળ છે)
  • lim(x→a) x^n = a^n
  • lim(x→0) sin(x)/x = 1
  • lim(x→0) tan(x)/x = 1
  • lim(x→0) (1 - cos(x))/x = 0
  • lim(x→0) (a^x - 1)/x = logₑa
  • lim(x→0) (logₑ(1+x))/x = 1
  • lim(x→∞) (1 + 1/x)^x = e
  • lim(x→0) (1 + x)^(1/x) = e
  • d/dx(x^n) = n·x^(n-1)
  • d/dx(sinx) = cosx
  • d/dx(cosx) = -sinx
  • d/dx(tanx) = sec²x
  • d/dx(cotx) = -cosec²x
  • d/dx(secx) = secx·tanx
  • d/dx(cosecx) = -cosecx·cotx
  • d/dx(e^x) = e^x
  • d/dx(a^x) = a^x · logₑa
  • d/dx(logₑx) = 1/x
  • d/dx(logₐx) = 1/(x·logₑa)
  • d/dx[f(g(x))] = f'(g(x)) · g'(x) (Chain Rule)
  • d/dx[u·v] = u·dv/dx + v·du/dx (Product Rule)
  • d/dx[u/v] = (v·du/dx - u·dv/dx)/v² (Quotient Rule)

⭐ મુખ્ય તથ્યો

  • જો lim(x→a⁻) f(x) = lim(x→a⁺) f(x) = L, તો lim(x→a) f(x) = L.
  • જો lim(x→a⁻) f(x) ≠ lim(x→a⁺) f(x), તો મર્યાદા અસ્તિત્વમાં નથી.
  • x→0 માટે sin(x)/x = 1 માત્ર ત્યારે જ લાગુ પડે જ્યારે x રેડિયનમાં હોય.
  • lim(x→∞) (1 + 1/x)^x = e ≈ 2.7183 એક મહત્વપૂર્ણ અચળાંક છે.
  • પ્રમેય: દરેક બહુપદી ફલન સર્વત્ર સતત છે.
  • જો f(x) એ x=a પર સતત ન હોય, તો f'(a) અસ્તિત્વમાં ન હોઈ શકે.
  • વિકલજનો ભૌમિતિક અર્થ: વક્ર પરના બિંદુએ સ્પર્શકની ઢાળ.
  • dy/dx = (dy/dt)/(dx/dt) — પરિમાણીય વિકલન (Parametric Differentiation).
  • બંને બાજુએ લઘુગણક લઈને વિકલન કરવાની પદ્ધતિને લઘુગણકીય વિકલન કહે.
  • d²y/dx² = d/dx(dy/dx) — બીજો ક્રમનો વિકલજ.
  • lim(x→0) (a^x - 1)/x = logₑa, ખાસ કરીને a=e હોય તો મૂલ્ય 1 છે.
  • lim(x→0) sin(nx)/x = n અને lim(x→0) sin(ax)/sin(bx) = a/b.

⚠️ સામાન્ય ભૂલો

  • sin(x)/x ની મર્યાદા x→0 માટે લાગુ પડે છે, x→π માટે નહીં.
  • Chain Rule વિકલનમાં બાહ્ય ફલનનું વિકલજ લખીને આંતરિક ફલનનું વિકલજ ગુણવું ભૂલી જાય છે.
  • Quotient Rule માં અંશ-છેદનો ક્રમ મહત્વપૂર્ણ છે: (v·u' - u·v')/v², ઉલટો ક્રમ ભૂલ છે.
  • Product Rule માં u·v' + v·u' લખવું જરૂરી છે, u·v' + u·v' નહીં.
  • lim(x→0) (1-cosx)/x = 0, પણ lim(x→0) (1-cosx)/x² = 1/2 — બંને એકસરખા નથી.
  • lim(x→a) f(x) અસ્તિત્વમાં હોય તેવું હોય તો પણ f(a) વ્યાખ્યાયિત ન હોઈ શકે.
  • d/dx(e^(f(x))) = e^(f(x)) · f'(x), ન કે ફક્ત e^(f(x)) — Chain Rule ભૂલવાથી ભૂલ થાય.
  • d/dx(log(f(x))) = f'(x)/f(x), ન કે 1/f(x) — Chain Rule ભૂલી જવાય છે.
  • lim(x→∞) (1+1/x)^x = e, પણ lim(x→0) (1+x)^(1/x) = e — બંને સમાન પરિણામ આપે છે.
  • અનંત સ્વરૂપ 0/0, ∞/∞, 0·∞, ∞-∞ માટે L'Hôpital નો નિયમ લાગુ પડે છે.
  • lim(x→0) tan(x)/x = 1, પણ lim(x→0) x/tan(x) = 1 — ઉલટું પણ સમાન છે.
  • સતતતા તપાસતી વખતે f(a) નું મૂલ્ય ચકાસવું ભૂલી જાય છે.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • lim(x→0) sin(x)/x = 1 અને lim(x→0) tan(x)/x = 1 — GUJCET માં સૌથી વધુ આવે છે.
  • d/dx(x^n) = nx^(n-1) — ઘાત નિયમ મૂળભૂત અને પુનરાવર્તિત આવે છે.
  • Chain Rule (શૃંખલા નિયમ) — સંયુક્ત ફલનોના વિકલનમાં અનિવાર્ય છે.
  • Product Rule અને Quotient Rule — બંનેના સૂત્રો યાદ રાખવા જરૂરી.
  • lim(x→∞) (1+1/x)^x = e અને lim(x→0) (1+x)^(1/x) = e — બંને મર્યાદાઓ મહત્વપૂર્ણ.
  • L'Hôpital નો નિયમ — 0/0 અને ∞/∞ સ્વરૂપની મર્યાદાઓ ઉકેલવા માટે.
  • lim(x→0) (a^x - 1)/x = logₑa — ઘાતાંકીય મર્યાદાઓમાં ઉપયોગી.
  • ડાબી અને જમણી બાજુની મર્યાદાઓ સમાન હોય તો જ મર્યાદા અસ્તિત્વમાં હોય.
  • સતતતાની શરતો: (1) lim(x→a) f(x) અસ્તિત્વમાં, (2) f(a) વ્યાખ્યાયિત, (3) બંને સમાન.
  • d/dx(sinx)=cosx, d/dx(cosx)=-sinx, d/dx(tanx)=sec²x — ત્રિકોણમિતિય વિકલજો યાદ રાખવા જરૂરી.
  • d/dx(e^x)=e^x અને d/dx(logx)=1/x — સૌથી મહત્વપૂર્ણ વિકલજ સૂત્રો.
  • પરિમાણીય વિકલન: dy/dx = (dy/dt)/(dx/dt) — x=f(t), y=g(t) સ્વરૂપમાં આવે છે.
