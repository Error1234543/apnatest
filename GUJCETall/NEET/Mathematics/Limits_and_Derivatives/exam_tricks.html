🧪 GUJCET — Gujarati • Mathematics • Limits and Derivatives

🎯 પરીક્ષા ટ્રિક્સ

પ્રથમ પ્રયાસ: સીધો આદેશ (Direct Substitution) — x ની કિંમત મૂકો. જવાબ મળે તો જવાબ મળ્યો, વધુ ગણતરી કરવાની જરૂર નથી.
જ્યારે પ્રશ્નમાં x → a હોય અને f(a) પરિભાષિત (defined) હોય.
દા.ત.: lim(x→2) (x² − 3x + 2) = 4 − 6 + 2 = 0. જવાબ 0, કોઈ વિભાજન/સૂત્રની જરૂર નથી.
0/0 અનિર્ધારિત સ્વરૂપ મળે તો તરત L'Hôpital નિયમ (L'Hôpital's Rule) લાગુ કરો: અંશ અને છેદનો અલગ વિકલન કરો.
જ્યારે સીધો આદેશ મૂકતા 0/0 અથવા ∞/∞ સ્વરૂપ મળે.
દા.ત.: lim(x→0) sin(3x)/x = 0/0. L'Hôpital: cos(3x)·3 / 1 → x=0 મૂકતા 3. જવાબ: 3.
સામાન્ય લિમિટ યાદ રાખો: lim(x→0) sin(x)/x = 1, lim(x→0) tan(x)/x = 1, lim(x→0) (eˣ − 1)/x = 1, lim(x→0) log(1+x)/x = 1. આ ચારેય સીધા ઉપયોગમાં લેવા.
જ્યારે પ્રશ્ન આ સ્વરૂપમાં હોય અથવા તેમાં ફેરફાર (scaling) હોય.
દા.ત.: lim(x→0) sin(5x)/x = 5 · [sin(5x)/(5x)] = 5 × 1 = 5. (અહીં 5x/5x = 1 કરીને ગુણાકાર કરો.)
વિકલનના નિયમો યાદ રાખો: d/dx(xⁿ) = nxⁿ⁻¹, d/dx(sinx) = cosx, d/dx(cosx) = −sinx, d/dx(eˣ) = eˣ, d/dx(log x) = 1/x. આ પાંચેય પ્રશ્નોમાં સીધા ઉપયોગમાં લેવા.
વિકલન શોધવાના પ્રશ્નોમાં, ખાસ કરીને MCQ માં વિકલ્પો તપાસવા.
દા.ત.: d/dx(x³ + 2x) = 3x² + 2. સીધો n-નિયમ લાગુ કરો.
અવયવ પદ્ધતિ (Factorization Method): અંશ-છેદના અવયવ કરો અને સામાન્ય પદ રદ્દ કરો.
જ્યારે 0/0 મળે અને બહુપદી (polynomial) હોય.
દા.ત.: lim(x→1) (x²−1)/(x−1) = lim(x→1) (x+1)(x−1)/(x−1) = lim(x→1)(x+1) = 2.
વ્યુત્ક્રમણ પદ્ધતિ (Rationalization): જ્યારે છેદમાં વર્ગમૂળ (√) હોય, તો અંશ-છેદને સંયુગ્મ (conjugate) વડે ગુણો.
lim(x→a) માં √(f(x)) − √(g(x)) સ્વરૂપ મળે.
દા.ત.: lim(x→0) (√(1+x)−1)/x. અંશ-છેદને (√(1+x)+1) વડે ગુણતા: x/[x(√(1+x)+1)] = 1/2.
MCQ માં વિકલ્પો પરખો (Option Elimination): જવાબ ધન હોવો જોઈએ કે ઋણ, તે જોઈને ખોટા વિકલ્પો દૂર કરો.
જ્યારે ચિહ્ન (sign) નક્કી કરવું હોય, ઉદા. lim(x→0⁺) vs lim(x→0⁻).
દા.ત.: lim(x→0⁺) 1/x = +∞, lim(x→0⁻) 1/x = −∞. જો વિકલ્પોમાં −∞ હોય તો તે ખોટો છે.
સામાન્ય લિમિટ: lim(x→∞) (1 + 1/x)ˣ = e. આ સૂત્ર યાદ રાખો અને સીધો ઉપયોગ કરો.
જ્યારે પ્રશ્ન (1 + k/x)ˣ⁄ᵏ અથવા સમાન સ્વરૂપમાં હોય.
દા.ત.: lim(x→∞) (1 + 2/x)ˣ = e². (અહીં k=2, તેથી e².)
શૃંખલા નિયમ (Chain Rule) યાદ: d/dx[f(g(x))] = f'(g(x)) · g'(x). બહિર્વેશી (composite) ફલન માટે સીધો ઉપયોગ.
જ્યારે f(g(x)) સ્વરૂપનું ફલન હોય.
દા.ત.: d/dx[sin(x²)] = cos(x²) · 2x = 2x cos(x²).
ગુણાકાર નિયમ (Product Rule): d/dx[u·v] = u'v + uv'. જો u અથવા v સરળ હોય તો સીધો ઉપયોગ.
બે ફલનોનો ગુણાકાર હોય.
દા.ત.: d/dx[x·sin x] = 1·sin x + x·cos x = sin x + x cos x.
વિકલનની વ્યાખ્યા (Definition of Derivative): f'(a) = lim(h→0) [f(a+h) − f(a)]/h. જો પ્રશ્ન આ સ્વરૂપમાં હોય તો સીધો f'(a) શોધો.
જ્યારે પ્રશ્ન લિમિટના રૂપમાં વિકલન પૂછે.
દા.ત.: lim(h→0) [(2+h)² − 4]/h = f'(2) જ્યાં f(x)=x². f'(x)=2x, f'(2)=4.
અચળ ફલનનું વિકલન શૂન્ય: d/dx[c] = 0. જો વિકલ્પોમાં 0 હોય તો તરત પસંદ કરો.
જ્યારે ફલન અચળ (constant) હોય.
દા.ત.: d/dx[5] = 0. સીધો જવાબ.
સામાન્ય લિમિટ: lim(x→0) (1 − cos x)/x² = 1/2. આ સૂત્ર યાદ રાખો.
જ્યારે (1 − cos x) અંશમાં હોય.
દા.ત.: lim(x→0) (1 − cos 2x)/x² = 4 · lim(x→0)(1−cos(2x))/(2x)² = 4 × 1/2 = 2.
MCQ માં ડિફરન્સિએબિલિટી તપાસો: f'(a) અસ્તિત્વ ધરાવે તો f(a⁺) = f(a⁻) = f(a) (સતતતા). જો સતત ન હોય તો વિકલનીય નથી.
જ્યારે પ્રશ્ન કહે કે f(x) x=a પર વિકલનીય છે કે નહીં.
દા.ત.: જો f(x) = |x|, x=0 પર f(0⁺)=0, f(0⁻)=0 → સતત છે પણ f'(0⁺)=1, f'(0⁻)=−1 → અસમાન → વિકલનીય નથી.
