મર્યાદાઓ અને વિકલિતો

🧪 GUJCET — Gujarati • Mathematics • Limits and Derivatives

પ્રવેશ
ગણિતમાં ફંક્શનનું આચરણ જાણવા માટે મર્યાદાઓ (Limits) નો ઉપયોગ થાય છે.
વિકલિત (Derivative) એ ફંક્શનની દરિયા (Rate of change) દર્શાવે છે.
lim_(x→a) f(x) = L (જ્યારે x, a ની ખૂબ નજીક જાય ત્યારે f(x) નું મૂલ્ય L ની ખૂબ નજીક જાય)
📝 🔑 મર્યાદા શોધવા માટે x નું સીધું મૂલ્ય નાખવાની કોશિશ કરો; જો અવિભાજ્ય સ્વરૂપ મળે તો બીજી રીત અજમાવો.
મર્યાદાવિકલિતનું મૂળભૂત સ્વરૂપ
મર્યાદાઓના ગુણધર્મો (Algebra of Limits)
lim_(x→a)[f(x) ± g(x)] = lim_(x→a)f(x) ± lim_(x→a)g(x)
lim_(x→a)[c·f(x)] = c·lim_(x→a)f(x) (jathe c અચળ છે)
lim_(x→a)[f(x)·g(x)] = lim_(x→a)f(x) · lim_(x→a)g(x)
lim_(x→a)[f(x)/g(x)] = lim_(x→a)f(x) / lim_(x→a)g(x) (જ્યાં lim g(x) ≠ 0)
આ પાંચેય ગુણધર્મોનો ઉપયોગ મર્યાદા ગણતરીમાં બહુ આવે છે – યાદ રાખો!
lim_(x→a) k = k (જ્યાં k અચળ છે)
lim_(x→a) x = a
📝 ⚡ નીચે આપેલાં મૂળભૂત મર્યાદાના સૂત્રો અવશ્ય રટાવી લો.
મહત્વની મર્યાદાઓ (Standard Limits)
lim_(x→0) sin x / x = 1
lim_(x→0) (1 - cos x) / x = 0
lim_(x→0) tan x / x = 1
lim_(x→0) sin nx / x = n (n કોઈ પણ વાસ્તવિક સંખ્યા)
lim_(x→0) (a^x - 1)/x = log_e a (અથવા ln a)
lim_(x→0) log(1+x)/x = 1
lim_(x→∞) (1 + 1/x)^x = e
જો x → 0 હોય તો sin θ ≈ θ અને tan θ ≈ θ માની શકાય (રેખીય સन्नિકર્ષ).
📝 🎯 GUJCET માં આ મર્યાદાઓના સવાલો બહુ સામાન્ય છે.
બહુપદી અને ભિન્નરાશીની મર્યાદાઓ
f(x) = x^n માટે: lim_(x→a) x^n = a^n
lim_(x→a) (p(x)/q(x)) માટે, q(a) ≠ 0 હોય તો સીધું મૂલ્ય મૂકો.
જો q(a) = 0 અને p(a) = 0 હોય તો (x-a) લવણી/હેર કરતાં અવયવ રદ કરો.
lim_(x→a) (x^n - a^n)/(x - a) = n·a^(n-1)
lim_(x→a) (x^n - a^n)/(x^m - a^m) = (n/m)·a^(n-m)
અવિભાજ્ય સ્વરૂપ 0/0 મળે ત્યારે 'સંયુગ્મી' (conjugate) પદ્ધતિ અથવા 'અવયવ વિભાજન' વાપરો.
📝 📌 ધ્યાન રાખો: જ્યારે હાર શૂન્ય થાય પણ લવ પર શૂન્ય ન હોય, તો મર્યાદા અસ્તિત્વ ધરાવતી નથી.
એકપક્ષીય મર્યાદાઓ (One-sided Limits)
ડાબી બાજુની મર્યાદા: lim_(x→a^-) f(x) (x, a કરતાં થોડું ઓછું)
જમણી બાજુની મર્યાદા: lim_(x→a^+) f(x) (x, a કરતાં થોડું વધારે)
lim_(x→a) f(x) અસ્તિત્વ ધરાવે તે માટે: lim_(x→a^-) f(x) = lim_(x→a^+) f(x)
જો બંને એકપક્ષીય મર્યાદા અલગ-અલગ હોય, તો મર્યાદા અસ્તિત્વ ધરાવતી નથી.
📝 ⚠️ ઘાટ વિંધાણીય (step) ફંક્શન અને |x| જેવા ફંક્શનમાં એકપક્ષીય મર્યાદા મહત્વની છે.
અવકલનજનકતા (Differentiability) અને સંતતિ (Continuity)
જો f, a બિંદુએ સંતત હોય, તો lim_(x→a) f(x) = f(a) હોવું જોઈએ.
કોઈ પણ બિંદુએ વિકલિત અસ્તિત્વ ધરાવે તે માટે ફંક્શન સંતત હોવું જરૂરી પણ પર્યાપ્ત નથી.
દા.ત., f(x)=|x| બિંદુ x=0 પર સંતત છે પણ અવકલનીય નથી.
📝 💡 અવકલનીય ફંક્શન હંમેશા સંતત હોય છે, પરંતુ સંતત ફંક્શન હંમેશા અવકલનીય હોતું નથી.
વિકલિતની વ્યાખ્યા (Definition of Derivative)
f'(x) = dy/dx = lim_(h→0) [f(x+h) - f(x)] / h
f'(a) = lim_(h→0) [f(a+h) - f(a)] / h (જ્યાં h → 0)
વિકલિત એ 'ફંક્શનના ફેરફારનો દર' (instantaneous rate of change) છે.
promey (First Principle) પદ્ધતિ દ્વારા વિકલિત શોધવા માટે ઉપરોક્ત વ્યાખ્યા વપરાય છે.
📝 📝 GUJCET માં ઘણી વાર પ્રમેય-પદ્ધતિ દ્વારા vikalit nikalna maagvo che.
બહુપદીના વિકલિતો (Derivatives of Polynomials)
d/dx [x^n] = n·x^(n-1)
d/dx [c] = 0 (c અચળ)
d/dx [c·f(x)] = c·f'(x)
દા.ત., f(x)=3x^4 – 2x^2 + 5x – 7 હોય તો f'(x)=12x^3 – 4x + 5
ઘાતાંકનિયમ (Power Rule) સૌથી મહત્વનું છે: ઘાતને ઉડીને સામે લાવો અને ઘાતમાં 1 બાદ કરો.
📝 🎯 x^n માટે n = -1, ½, fractions પણ સાચું છે.
ત્રિકોણમિતિય ફંક્શનના વિકલિતો
d/dx [sin x] = cos x
d/dx [cos x] = -sin x
d/dx [tan x] = sec^2 x
d/dx [cot x] = -cosec^2 x
d/dx [sec x] = sec x · tan x
d/dx [cosec x] = -cosec x · cot x
sin → cos (ધન) અને cos → sin (ઋણ) – યાદ રાખવાનો ઉપાય: "સુરખી (positive) sine છે, કોસાઇન ઋણ છે."
📝 ⚡ અંદરનું ચલ બદલાય તો chain rule લાગુ પડશે (આગળ વાંચો).
ઘાતાંકીય અને લઘુગણક ફંક્શનના વિકલિતો
d/dx [e^x] = e^x
d/dx [a^x] = a^x · ln a
d/dx [ln x] = 1/x
d/dx [log_a x] = 1/(x · ln a)
e^xનું વિકલિત તે જ છે – આ એકમાત્ર ફંક્શન છે જે પોતાનું જ વિકલિત ધરાવે છે.
📝 📘 ln એ પ્રાકૃતિક લઘુગણક (base e) છે.
ગુણન અને ભાગફળ નિયમો (Product & Quotient Rules)
d/dx [u·v] = u·v' + v·u' (ગુણન નિયમ)
d/dx [u/v] = (v·u' - u·v') / v^2 (ભાગફળ નિયમ)
ગુણન નિયમ: પ્રથમ ફંક્શન × બીજાનું વિકલિત + બીજું ફંક્શન × પ્રથમનું વિકલિત
ભાગફળ નિયમ: (હાર × લવનું વિકલિત − લવ × હારનું વિકલિત) ÷ હાર²
ઘણા સવાલોમાં ગુણન/ભાગફળ નિયમ સાથે chain rule પણ લાગુ પડે છે.
📝 🔁 યાદ રાખો: "ultra–loose" = u·dv + v·du
શૃંખલા નિયમ (Chain Rule)
dy/dx = dy/du · du/dx જ્યાં y = f(u) અને u = g(x)
d/dx [f(g(x))] = f'(g(x)) · g'(x)
શૃંખલા નિયમ: બાહ્ય ફંક્શનનું વિકલિત (અંદરુ ફંક્શનને સામાન્ય રીતે) લો અને અંદરના ફંક્શનનું વિકલિત ગુણો.
દા.ત., d/dx [sin(x^2)] = cos(x^2) · 2x
શૃંખલા નિયમ વિના બહુકેન્દ્રીય ફંક્શનના વિકલિત શક્ય નથી – આ સૌથી વધુ વપરાતો નિયમ છે.
📝 🔗 chain = સાંકળ; સાંકળનો એક કડી છોડો નહીં.
અવકલનની ભૌમિતિક વ્યાખ્યા (Geometric Interpretation)
વક્ર y = f(x) પર P(a, f(a)) બિંદુએ સ્પર્શકની ઢાલ (slope) = f'(a)
જ્યારે Q બિંદુ P તરફ જાય છે, ત્યારે છેદક (secant) રેખા સ્પર્શક બને છે.
સ્પર્શકની ઢાલ m = tan θ = lim_(h→0) [f(a+h)-f(a)]/h = f'(a)
f'(a) > 0 → ફંક્શન વધતું; f'(a) < 0 → ફંક્શન ઘટતું; f'(a) = 0 → સ્થિર બિંદુ.
📝 📐 સ્પર્શક = વક્રને એક જ બિંદુએ छूने वाली રેખા; છેદક = બે બિંદુઓ શોધે.
સ્પર્શક અને અભિલંબ (Tangent and Normal)
સ્પર્શકનું સમીકરણ: y - y1 = f'(x1)(x - x1)
અભિલંબનું સમીકરણ: y - y1 = -1/f'(x1) · (x - x1)
સ્પર્શક અને અભિલંબ એકબીજાને લંબ (perpendicular) હોય છે; તેમની ઢાલોનો ગુણાકાર = -1
જો f'(x1) = 0 હોય, તો સ્પર્શક સમાંતર (horizontal) હોય.
GUJCET માં બહુવાર (x1,y1) બિંદુ પાસે સ્પર્શક/અભિલંબનું સમીકરણ માગવામાં આવે છે.
📝 ✅ સૂત્ર યાદ રાખો અને પ્લૉટ કરીને ચકાસી શકાય.
વિકલિતના નિયમોનો સંક્ષિપ્ત સારાંશ
ધ્રુવક નિયમ (Power rule): d/dx x^n = nx^{n-1}
ત્રિકોણમિતિય નિયમો: sin → cos, cos → –sin, tan → sec², cot → –cosec²
ઘાતાંકીય નિયમો: e^x → e^x, a^x → a^x·ln a
લઘુગણક નિયમ: ln x → 1/x
ગુણન નિયમ, ભાગફળ નિયમ, શૃંખલા નિયમ – આ ત્રણેય મહત્વપૂર્ણ છે.
તમામ નિયમોનું સંયોજન કરી કોઈ પણ સંયુક્ત ફંક્શનનું વિકલિત શક્ય છે.
📝 🧮 વ્યાજબી વ્યાયત કરવા માટે પ્રત્યેક નિયમનું ઉદાહરણ સમજવું જરૂરી છે.
મહત્વના ઉદાહરણો અને સામાન્ય ભૂલો
ભૂલ 1: d/dx [sin x^2] મા sin(2x) ગણવાને બદલે σωστού = 2x cos(x^2) લખવું.
ભૂલ 2: (f·g)' = f'·g' ગણવું – આ ખોટું છે; સાચું સૂત્ર છે f'g + fg'.
ભૂલ 3: lim_(x→0) cos x / x = 1 લેવું – ખોટું; આ મર્યાદા અસ્તિત્વ ધરાવતી નથી.
ભૂલ 4: √x નું વિકલિત 1/(2√x) છે, પણ ઘણા દેખાડે 1/√x.
આ ભૂલો ટાળવાના આદ્યક્ષમાં નિયમોની વ્યાખ્યા સ્પષ્ટ રાખો.
📝 🚫 GUJCET પેપરમાં આ ભૂલો પર નંબર કપાઈ શકે છે.
વિકલિતોનો ઉપયોગ (Applications of Derivatives)
દરિયા (rate) નક્કી કરવા: gati, veg, vat manavde, praveg etc.
વધારો / ઘટાડો જાણવા: f'(x) > 0 → વધતું, f'(x) < 0 → ઘટતું.
મહત્તમ/ન્યૂનતમ મૂલ્યો: f'(c)=0 અને f''(c) ના ચિહ્ન પરથી તપાસો.
અવકલન જ્ઞાન વિજ્ઞાન અને ઇજનેરીમાં વ્યાપક રીતે ઉપયોગી છે.
📝 🌍 વાસ્તવિક જીવનમાં વેગ, પ્રવેગ, વક્રતા – બધું અવકલનથી જ.
MUFT સરળ રીતો અને યાદ કરવાના ઉપાય
"મર્યાદાનો કોઈ પણ દર નામે ઓળખાય" – તેથી વિકલિત પણ દર જ છે.
મૂળભૂત મર્યાદાઓ ટૂંકી રીતે રટાવો: sin0→1, tan0→1, (1-cos)/x→0
chain rule નો ધ્યાન રાખો: બાહ્ય વિકલિત × અંદરું વિકલિત.
સંયોગાત્મક ફંક્શનમાં પ્રથમ ગુણન નિયમ, પછી chain rule – અનુક્રમ ચાલુ રાખો.
