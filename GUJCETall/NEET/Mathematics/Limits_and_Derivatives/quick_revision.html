લિમિટ અને વિકલન — ઝડપી પુનરાવર્તન

🧪 GUJCET — Gujarati • Mathematics • Limits and Derivatives

🧠 યાદ રાખો

લિમિટનો મૂળભૂત અર્થ: x, a ની નજીક જાય ત્યારે f(x) નો મૂલ્ય કયા બિંદુની નજીક જાય છે.
ડાબી બાજુની લિમિટ (x → a⁻) અને જમણી બાજુની લિમિટ (x → a⁺) સમાન હોય તો જ લિમિટ અસ્તિત્વ ધરાવે છે.
સતતતા: f(a) અસ્તિત્વ ધરાવતું હોય, લિમિટ અસ્તિત્વ ધરાવતી હોય અને બંને સમાન હોય — તો f, a બિંદુએ સતત છે.
વિકલન એ દરેક બિંદુએ સ્પર્શકની ઢાળ શોધવાની પ્રક્રિયા છે; f'(x) = lim(h→0) [f(x+h)−f(x)]/h.
વિકલનીય હોય તો સતત હોય, પણ સતત હોય તો વિકલનીય હોય એ શરત નથી (ઉદા. |x| at x=0).
લઘુગણકીય વિકલન (Logarithmic Differentiation) જટિલ ગુણાકાર/ભાગાકાર/ઘાતવાળા વિધેયો માટે ઉપયોગી છે.
શૃંખલા નિયમ (Chain Rule): dy/dx = dy/du × du/dx — બહિર્વ્યાપી વિધેયોનો મૂળભૂત નિયમ છે.
ગુણન નિયમ: (uv)' = u'v + uv'; ભાગાકાર નિયમ: (u/v)' = (u'v − uv')/v².

⚡ ઝડપી સૂત્રો

lim(x→0) sin x / x = 1
lim(x→0) (1 − cos x) / x = 0
lim(x→0) tan x / x = 1
lim(x→0) (eˣ − 1)/x = 1
lim(x→0) log(1 + x)/x = 1
lim(x→∞) (1 + 1/x)ˣ = e
d/dx[xⁿ] = n·xⁿ⁻¹
d/dx[sin x] = cos x
d/dx[cos x] = −sin x
d/dx[tan x] = sec²x
d/dx[eˣ] = eˣ
d/dx[log x] = 1/x
d/dx[sin⁻¹x] = 1/√(1−x²)
d/dx[cos⁻¹x] = −1/√(1−x²)
d/dx[tan⁻¹x] = 1/(1+x²)

✅ વન-લાઈનર્સ

0/0 અને ∞/∞ જેવી અનિર્ધારિત રૂપો મળે તો L'Hôpital નિયમ લાગુ પાડો: lim f/g = lim f'/g'.
lim(x→0) (aˣ − 1)/x = logₑa; વિશેષ રીતે a = e હોય તો મૂલ્ય 1 મળે.
પરિમિત વિધેયો બહુપદી, ત્રિકોણમિતીય, ઘાતાંકીય, લઘુગણકીય સ્વરૂપે લખી શકાય.
f(x) = |x − a| બિંદુ x = a પર સતત તો પણ વિકલનીય નથી.
અવકલનના નિયમો: અચળનો વિકલન 0, રેખીય સંયોજનનું વિકલન વિકલનનું સંયોજન.
દ્વિતીય ક્રમનું અવકલન d²y/dx² શોધવા માટે પ્રથમ વિકલન ફરી વિકલિત કરો.
પ્રત્યાંતર (Implicit) વિધેયોના અવકલનમાં y ને x નું વિધેય માની સામાન્ય નિયમો લાગુ કરો.
પરામેત્રિક સ્વરૂપમાં: dy/dx = (dy/dt)/(dx/dt).
વિકલનનો ભૌમિતિક અર્થ: વક્ર પરના બિંદુએ સ્પર્શકની ઢાળ = f'(x₀).
લિમિટની ગુણધર્મો: સરવાળો, વ્યવકલન, ગુણાકાર, ભાગાકાર — દરેકમાં લિમિટ અલગ-અલગ લાગુ પડે છે.
