અનુક્રમ અને શ્રેઢી — ક્વિક રીવિઝન

🧪 GUJCET — Gujarati • Mathematics • Sequences and Series

🧠 યાદ રાખો

શ્રેઢિક અનુક્રમ (AP): દરેક પદ અને તેના પૂર્વ પદ વચ્ચેનો તફાવત અચળ હોય છે; તેને સામાન્ય તફાવત (d) કહે.
જો પદ a, b, c એ AP માં હોય તો b – a = c – b = d અને 2b = a + c.
સમાંતર શ્રેઢી (GP): દરેક પદ અને તેના પૂર્વ પદનો ગુણોત્તર અચળ હોય છે; તેને સામાન્ય ગુણોત્તર (r) કહે.
જો પદ a, b, c એ GP માં હોય તો b/a = c/b = r અને b² = ac.
a, b, c એ AP માં હોય તો √a, √b, √c (ધન પદો હોય તો) સામાન્ય રીતે GP માં હોતા નથી; પરંતુ a, b, c GP માં હોય તો log a, log b, log c (આધાર > 0) AP માં આવે.
AM અને GM વચ્ચેનો સંબંધ: જો a, b ધન વાસ્તવિક સંખ્યાઓ હોય તો AM ≥ GM એટલે કે (a+b)/2 ≥ √(ab); સમાનતા ત્યારે જ જ્યારે a = b.
HM (પ્રત્યાસાદી મધ્યક): બે ધન સંખ્યાઓ a, b માટે HM = 2ab/(a+b). હંમેશા HM ≤ GM ≤ AM.
કોઈપણ શ્રેઢિક અનુક્રમના k ભાગો કરીએ તો દરેક ભાગના પદોની સંખ્યા સમાન હોય તો ભાગોના સરવાળા પણ AP માં હોય છે.
જો n-મો પદ a_n = pn + q (બહુપદી સ્વરૂપમાં) હોય તો આપેલ અનુક્રમ શ્રેઢિક અનુક્રમ છે.

⚡ ઝડપી સૂત્રો

AP નું n-મો પદ: Tₙ = a + (n−1)d
AP નો n પદોનો સરવાળો: Sₙ = n/2 [2a + (n−1)d] = n/2 (a + l), જ્યાં l = છેલ્લું પદ.
AP માં n-મો પદ પાછળથી: Tₙ = Sₙ − Sₙ₋₁
GP નું n-મો પદ: Tₙ = ar^(n−1)
GP નો n પદોનો સરવાળો: Sₙ = a(rⁿ − 1)/(r − 1), જો r ≠ 1
GP નો અનંત સરવાળો (|r| < 1 હોય તો): S∞ = a/(1 − r)
જો a, A, b એ AP માં હોય તો સમાંતર મધ્યક A = (a + b)/2
જો a, G, b એ GP માં હોય તો ભૌમિતિક મધ્યક G = ±√(ab)
જો a, H, b એ HP માં હોય તો પ્રત્યાસાદી મધ્યક H = 2ab/(a + b)

✅ વન-લાઈનર્સ

AP ના ત્રણ પદો a−d, a, a+d અને ચાર પદો a−3d, a−d, a+d, a+3d લેવા સહેલા થાય છે.
જો AP ના પદોનો સરવાળો Sₙ = an² + bn સ્વરૂપમાં હોય તો સામાન્ય તફાવત d = 2a અને પ્રથમ પદ a₁ = a + b.
GP માં r = 1 હોય તો Sₙ = na; r > 1 હોય તો Sₙ = a(rⁿ − 1)/(r − 1); 0 < r < 1 હોય તો સૂત્ર Sₙ = a(1 − rⁿ)/(1 − r) વાપરો.
અનંત મંદ શ્રેઢી (Geometric Series) માટે |r| < 1 શરત હોવી જરૂરી છે, નહીંતર અનંત સરવાળો અસ્તિત્વ ધરાવતો નથી.
AP અને GP ના સંયુક્ત પ્રશ્નોમાં સંબંધ it નો ઉપયોગ કરીને બંને શ્રેઢીઓના પદો વચ્ચેનો સંબંધ શોધી શકાય છે.
એક સમઘન (Cube) ના અંતઃક્રિયા (Inscribe) કરેલા ઘનની બાજુ = a√3 / 2 અને બહિર્ક્રિયા (Circumscribe) કરેલા ઘનની બાજુ = a√3 હોય છે.
