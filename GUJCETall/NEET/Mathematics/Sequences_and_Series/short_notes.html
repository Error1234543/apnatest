અનુક્રમ અને શ્રેણી (Sequences and Series)

🧪 GUJCET — Gujarati • Mathematics • Sequences and Series

📘 વ્યાખ્યાઓ

  • અનુક્રમ (Sequence): કોઈ પણ નિયમ મુજબ ગોઠવાયેલી સંખ્યાઓની ગોઠવણી.
  • શ્રેણી (Series): અનુક્રમના પદોનો સરવાળો.
  • સામાન્ય તફાવત (Common Difference - d): સમાન અંતરે વધતી/ઘટતી સંખ્યાઓનો અંતર.
  • સામાન્ય ગુણોત્તર (Common Ratio - r): સમાન ગુણોત્તરે વધતી/ઘટતી સંખ્યાઓનો ગુણોત્તર.
  • સમાંતર શ્રેડી (AP): એવી શ્રેડી જ્યાં બે ક્રમિક પદો વચ્ચેનો તફાવત સમાન હોય.
  • ગુણોત્તર શ્રેડી (GP): એવી શ્રેડી જ્યાં બે ક્રમિક પદોનો ગુણોત્તર સમાન હોય.
  • સમાંતર મધ્યક (AM): બે સંખ્યાઓ a અને b માટે AM = (a+b)/2.
  • ગુણોત્તર મધ્યક (GM): બે ધન સંખ્યાઓ a અને b માટે GM = √(ab).
  • વર્ગમૂળ શ્રેડી: જ્યાં પદોના વર્ગમૂળો AP માં હોય.
  • અનંત ગુણોત્તર શ્રેડી: જ્યાં |r| < 1 હોય ત્યારે સરવાળો અનંત સુધી શક્ય હોય.

⚡ સૂત્રો

  • AP નું nમું પદ: Tn = a + (n-1)d, જ્યાં a પ્રથમ પદ છે.
  • AP ના n પદોનો સરવાળો: Sn = n/2 [2a + (n-1)d] = n/2 (a+l), જ્યાં l છેલ્લું પદ.
  • GP નું nમું પદ: Tn = a·r^(n-1), જ્યાં a પ્રથમ પદ છે.
  • GP ના n પદોનો સરવાળો: Sn = a(r^n - 1)/(r-1), જો r ≠ 1.
  • અનંત GP નો સરવાળો: S∞ = a/(1-r), જો |r| < 1.
  • ત્રણ સંખ્યાઓ a, b, c AP માં હોય તો: 2b = a + c.
  • ત્રણ સંખ્યાઓ a, b, c GP માં હોય તો: b² = ac.
  • બે સંખ્યાઓ a અને b વચ્ચેનું AM: A = (a+b)/2.
  • બે ધન સંખ્યાઓ a અને b વચ્ચેનું GM: G = √(ab).
  • બે ધન સંખ્યાઓ a અને b વચ્ચેનું HM: H = 2ab/(a+b).
  • AM ≥ GM ≥ HM (સમાનતા ત્યારે જ જ્યારે a = b).
  • AM × HM = GM² (ત્રણેય મધ્યકો વચ્ચેનો સંબંધ).
  • 1, 3, 5, 7, ... ના n પદોનો સરવાળો = n².
  • 1² + 2² + 3² + ... + n² = n(n+1)(2n+1)/6.
  • 1³ + 2³ + 3³ + ... + n³ = [n(n+1)/2]².
  • 1 + 2 + 3 + ... + n = n(n+1)/2.
  • n સંખ્યાઓની AP માં: મધ્યમ પદ = (પ્રથમ પદ + છેલ્લું પદ)/2.
  • જો a, a+d, a+2d, ... AP માં હોય તો kવડો ગુણતાં પણ AP જ રહે.
  • જો a, ar, ar², ... GP માં હોય તો લઘુગુણક લેતાં AP મળે.
  • Sn = an² + bn હોય તો શ્રેડી AP છે, જ્યાં d = 2a.

⭐ મુખ્ય તથ્યો

  • AP માં દરેક પદ પોતાના પડોશી પદોનું સમાંતર મધ્યક હોય છે.
  • GP માં દરેક પદ પોતાના પડોશી પદોનું ગુણોત્તર મધ્યક હોય છે.
  • જો દરેક પદમાં સમાન સંખ્યા ઉમેરવી/કાઢવી તો AP/GP બદલાતું નથી.
  • જો દરેક પદમાં સમાન સંખ્યા ગુણવી/ભાગવી તો AP/GP બદલાતું નથી.
  • GP માં r = 1 હોય તો Sn = na (સરળ સરવાળો).
  • જો a, b, c AP માં હોય તો a-b = b-c = d (સામાન્ય તફાવત).
  • જો a, b, c GP માં હોય તો a/b = b/c = r (સામાન્ય ગુણોત્તર).
  • કોઈ પણ બે ધન સંખ્યાઓ માટે AM ≥ GM હંમેશા સાચું છે.
  • n સંખ્યાઓની AP માં સરવાળો = મધ્યમ પદ × n (જો n વિષમ હોય).
  • અનંત GP માં |r| ≥ 1 હોય તો સરવાળો અનંત થાય છે.
  • બે સંખ્યાઓ વચ્ચે k સમાંતર મધ્યકો મૂકતાં: દરેક મધ્યક વચ્ચેનો તફાવત = (b-a)/(k+1).
  • બે સંખ્યાઓ વચ્ચે k ગુણોત્તર મધ્યકો મૂકતાં: દરેક મધ્યકનો ગુણોત્તર = (b/a)^(1/(k+1)).
  • કોઈ પણ ત્રણ સંખ્યાઓ AP માં લેવી હોય તો: a-d, a, a+d લઈ શકાય.
  • કોઈ પણ ચાર સંખ્યાઓ AP માં લેવી હોય તો: a-3d, a-d, a+d, a+3d લઈ શકાય.
  • કોઈ પણ ત્રણ સંખ્યાઓ GP માં લેવી હોય તો: a/r, a, ar લઈ શકાય.
  • n પદોની AP માં: Sn = n/2 [2a + (n-1)d] સૂત્ર સિદ્ધ કરી શકાય.
  • જો Sn = an² + bn + c હોય તો c = 0 હોવું જોઈએ (AP માટે).
  • કોઈ પણ સંખ્યાનો વર્ગમૂળ લેતાં GP → AP બને છે.
  • n સંખ્યાઓની GP માં ગુણાકાર = (મધ્યમ પદ)^n (જો n વિષમ હોય).
  • સમાંતર શ્રેડીમાં પદોની સંખ્યા દ્વિગુણ કરતાં સરવાળો દ્વિગુણ થાય.

⚠️ સામાન્ય ભૂલો

  • GP ના સરવાળાનું સૂત્ર r = 1 હોય તો લાગુ પડતું નથી.
  • અનંત GP માં |r| < 1 શરત ભૂલથી છોડી દેવાય છે.
  • AM-GM અસમાનતા માત્ર ધન સંખ્યાઓ માટે લાગુ પડે છે.
  • HM શોધતી વખતે સંખ્યાઓ ધન હોવી જોઈએ.
  • AP ના સરવાળામાં n/2 [a+l] માં l એ છેલ્લું પદ છે, ભૂલથી nમું પદ ન લેવું.
  • GP માં r ઋણ હોઈ શકે છે, તેથી સ્પર્ધાત્મક પરીક્ષામાં ચિહ્ન ધ્યાનમાં લેવું.
  • AM, GM, HM વચ્ચેનો સંબંધ AM × HM = GM² માત્ર બે સંખ્યાઓ માટે.
  • n સંખ્યાઓની AP માં સરવાળો = n × મધ્યમ પદ ફક્ત n વિષમ હોય ત્યારે.
  • કોઈ પણ પદ શોધતી વખતે Tn = a + (n-1)d માં n-1 ભૂલથી n લખાય છે.
  • GP ના n પદોનો ગુણાકાર શોધતી વખતે a^n · r^(n(n-1)/2) સૂત્ર યાદ રાખવું.
  • સમાંતર મધ્યકોની સંખ્યા k હોય તો કુલ પદો n = k+2 થાય.
  • જો Sn = an² + bn હોય તો પ્રથમ પદ a₁ = a+b નીકળે, d = 2a.
  • GP માં r = 1 હોય તો S∞ અસ્તિત્વ ધરાવતું નથી.
  • AM ≥ GM માં સમાનતા ત્યારે જ જ્યારે બંને સંખ્યાઓ સમાન હોય.
  • શ્રેડી AP છે કે નહીં તે તપાસવા Sn = an² + bn સ્વરૂપ ચકાસવું.
  • અનંત શ્રેડીનો સરવાળો હંમેશા શક્ય નથી, |r| < 1 શરત મહત્વની.
  • GP માં r = -1 હોય તો સરવાળો oscillate કરે છે.
  • બે સંખ્યાઓ વચ્ચેનો તફાવત શોધતી વખતે ક્રમ ધ્યાનમાં લેવો.
  • n સંખ્યાઓની AP માં પ્રથમ અને છેલ્લા પદનો સરવાળો = બીજા અને બીજા છેલ્લાનો સરવાળો.
  • કોઈ પણ સંખ્યાનો વર્ગમૂળ લેતાં GP → AP બને છે, પણ વર્ગ લેતાં નહીં.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • AP નું nમું પદ: Tn = a + (n-1)d — સૌથી મહત્વનું સૂત્ર.
  • AP નો સરવાળો: Sn = n/2 [2a + (n-1)d] — નિયમિત પ્રશ્નોમાં વપરાય.
  • GP નું nમું પદ: Tn = a·r^(n-1) — મૂળભૂત સૂત્ર.
  • અનંત GP નો સરવાળો: S∞ = a/(1-r), |r| < 1 — GUJCET માં ઘણો આવે.
  • AM ≥ GM ≥ HM — સ્પર્ધાત્મક પરીક્ષાનું ગોલ્ડન રૂલ.
  • AM × HM = GM² — ત્રણેય મધ્યકો વચ્ચેનો સંબંધ.
  • 1+2+3+...+n = n(n+1)/2 — સૌથી મૂળભૂત શ્રેડી.
  • 1²+2²+...+n² = n(n+1)(2n+1)/6 — વર્ગોનો સરવાળો.
  • 1³+2³+...+n³ = [n(n+1)/2]² — ઘનનો સરવાળો.
  • n વિષમ હોય તો AP નો સરવાળો = મધ્યમ પદ × n — ઝડપી ગણતરી.
  • ત્રણ સંખ્યાઓ AP માં: a-d, a, a+d લેવાથી ગણતરી સરળ બને.
  • ત્રણ સંખ્યાઓ GP માં: a/r, a, ar લેવાથી ગણતરી સરળ બને.
  • જો a, b, c AP માં હોય તો 2b = a+c — ચકાસણીનું સૂત્ર.
  • જો a, b, c GP માં હોય તો b² = ac — ચકાસણીનું સૂત્ર.
  • Sn = an² + bn હોય તો શ્રેડી AP છે — પરીક્ષામાં ઘણો આવે.
  • GP માં r > 1 હોય તો Sn = a(r^n - 1)/(r-1), r < 1 હોય તો Sn = a(1-r^n)/(1-r).
  • કોઈ પણ સંખ્યાનો લઘુગુણક લેતાં GP → AP બને છે.
  • બે સંખ્યાઓ વચ્ચે k AM મૂકતાં: દરેક AM વચ્ચેનો તફાવત = (b-a)/(k+1).
  • બે સંખ્યાઓ વચ્ચે k GM મૂકતાં: દરેક GM નો ગુણોત્તર = (b/a)^(1/(k+1)).
  • n સંખ્યાઓની GP માં ગુણાકાર = (મધ્યમ પદ)^n (n વિષમ હોય તો).
  • AP માં દરેક પદ = પડોશી પદોનું AM — મહત્વનો ગુણધર્મ.
  • GP માં દરેક પદ = પડોશી પદોનું GM — મહત્વનો ગુણધર્મ.
  • જો Sn = an² + bn + c હોય તો c = 0 હોવું જોઈએ (AP માટે).
  • n સંખ્યાઓની AP માં: Tn = Sn - S(n-1) — nમું પદ શોધવાનું સૂત્ર.
  • કોઈ પણ સંખ્યાનો વર્ગમૂળ લેતાં GP → AP બને છે — ઉલટું પણ સાચું.
