શ્રેણીઓ અને શ્રેઢી (Sequences and Series)

🧪 GUJCET — Gujarati • Mathematics • Sequences and Series

શ્રેણી અને શ્રેઢી — પ્રવેશ
કોઈ પણ નિશ્ચિત નિયમ મુજબ ગોઠવાયેલી વાસ્તવિક સંખ્યાઓની ગણને શ્રેણી (Sequence) કહે છે.
પ્રથમ પદ a₁, બીજું પદ a₂, ... n-મું પદ aₙ₋₁, n-મું પદ aₙ એવો ક્રમ ધરાવે છે.
શ્રેણી = પદોની લીટી; શ્રેઢી = તે પદોનો સરવાળો. બંને વચ્ચેનો ભેદ સૌથી મહત્વનો છે!
📝 GUJCET tip: Sequence vs Series નો પ્રશ્ન ચોક્કસ આવે છે – ધ્યાન રાખવું.
સામાન્ય રૂપ: a₁, a₂, a₃, …, aₙ, …
અંકગાણિત શ્રેણી (AP – Arithmetic Progression)
જ્યાં દરેક પદ અને તેના આગળના પદ વચ્ચેનો તફાવત સતત સમાન હોય તેવી શ્રેણી અંકગાણિત શ્રેણી કહેવાય.
અહીં સામાન્ય અંતર (Common Difference) d = aₙ – aₙ₋₁ (n ≥ 2).
d > 0 → શ્રેણી વધતી; d < 0 → શ્રેણી ઘટતી; d = 0 → સ્થિર (Constant) શ્રેણી.
સામાન્ય અંતર: d = a₂ – a₁ = a₃ – a₂ = … = aₙ – aₙ₋₁
પ્રથમ પદ a, સામાન્ય અંતર dAP નું સૂત્ર તરફ
અંકગાણિત શ્રેણીનું n-મું પદ
a, a+d, a+2d, a+3d, … સ્વરૂપની AP નું n-મું પદ મેળવવાનું સૂત્ર:
aₙ = a + (n – 1)d
જ્યાં a = પ્રથમ પદ, d = સામાન્ય અંતર, n = પદની સંખ્યા.
n-મું પદ જ्ञात કરવા માટે a અને d બેઉ જાણીતાં જોઈએ.
📝 UT: aₙ = a + (n–1)d યાદ રાખો – આ AP નું સૌથી મહત્વનું સૂત્ર છે.
AP ના પ્રથમ n પદોનો સરવાળો
AP ના પ્રથમ n પદોનો સરવાળો Sₙ નીચે મુજબ મળે છે:
Sₙ = n/2 [2a + (n – 1)d]
વૈકલ્પિક રૂપ: Sₙ = n/2 [a + l] (જ્યાં l = aₙ = છેલ્લું પદ)
Sₙ = n/2 × (પ્રથમ પદ + છેલ્લું પદ) – આ સૂત્ર ઝડપી ઉકેલ આપે છે.
Sₙ = n/2[2a+(n-1)d]Sₙ = n/2(a+l) સાથે સમકક્ષ
AP માંથી ચોક્કસ પદ દૂર કરવાની રીત
k-મું પદ દૂર કરીએ તો બાકીના (n–1) પદોનો સરવાળો: S'ₙ = Sₙ – aₖ.
અહીં aₖ = a + (k – 1)d વડે k-મું પદ મેળવી શકાય.
આ પ્રકારના પ્રશ્ન GUJCET માં આવે છે – Sₙ માંથી એક પદ બાદ કરવું પડે છે.
સંકલન સૂત્રો ( summation formulas ) — મહત્વના
Σₖ₌₁ⁿ k = n(n+1)/2
Σₖ₌₁ⁿ k² = n(n+1)(2n+1)/6
Σₖ₌₁ⁿ k³ = [n(n+1)/2]²
Σₖ₌₁ⁿ c = nc (c = અચળ)
આ સંકલન સૂત્રો AP અને ઘાતીય સરવાળાના પ્રશ્નોમાં સીધા વાપરવા.
📝 UT: Σk³ = (Σk)² – એ રિલેશન યાદ રાખો, ખૂબ ફાયદાકારક!
અંકગાણિત મધ્યક (Arithmetic Mean – A.M.)
a અને b ની વચ્ચેનું અંકગાણિત મધ્યક એ ત્રીજું પદ હોય તેવી AP: a, A, b.
A = (a + b) / 2
a, A₁, A₂, ..., Aₙ, b – જો n મધ્યકો હોય તો દરેક Aₖ = a + k·d, જ્યાં d = (b–a)/(n+1).
બે સંખ્યાઓ વચ્ચેનો A.M. તેમના સરવાળાનો અડધોભાગ છે.
📝 UT: n A.M. ની વચ્ચે d = (b–a)/(n+1) યાદ રાખો.
સામાન્ય ગુણોત્તર શ્રેણી (GP – Geometric Progression)
જ્યાં દરેક પદ અને તેના આગળના પદનો ગુણોત્તર સતત સમાન હોય તેવી શ્રેણી GP કહેવાય.
સામાન્ય ગુણોત્તર (Common Ratio) r = aₙ / aₙ₋₁ (n ≥ 2), r ≠ 0.
GP માં દરેક પદ = આગળનું પદ ÷ r. r > 1 → શ્રેણી ઝડપી વધે છે; |r| < 1 → શ્રેણી ઘટે છે.
GP નું n-મું પદ: aₙ = a · rⁿ⁻¹
aₙ = a·rⁿ⁻¹ (n-મું પદ)GP સૂત્રની પાયા里的 વાનગી
GP ના પ્રથમ n પદોનો સરવાળો
Sₙ = a(rⁿ – 1)/(r – 1), જો r ≠ 1 અને r > 1
Sₙ = a(1 – rⁿ)/(1 – r), જો r ≠ 1 અને |r| < 1
જો r = 1 હોય તો Sₙ = na
r > 1 માટે (rⁿ – 1)/(r – 1); |r| < 1 માટે (1 – rⁿ)/(1 – r) – બંને સમાન પરિણામ આપે.
📝 UT: r=1 એ ખાસ કેસ છે – ગalti થતી નથી તે检查一下!
અનંત GP નો સરવાળો
જો |r| < 1 હોય તો અનંત પદોની GP નો સરવાળો અસ્તિત્વ ધરાવે છે અને મર્યાદિત છે.
S∞ = a / (1 – r), જો |r| < 1
|r| ≥ 1 હોય તો અનંત સરવાળો અપ્રભાવી (divergent) છે – સરવાળો મળતો નથી.
📝 UT: S∞ = a/(1–r) માત્ર |r|<1 પર લાગુ પડે છે – શરત યાદ રાખવી!
GP માંથી ચોક્કસ પદ દૂર કરવાની રીત
k-મું પદ દૂર કરીએ તો: S'ₙ = Sₙ – aₖ, જ્યાં aₖ = a·rᵏ⁻¹.
છૂટકો પદોનો સરવાળો = m × (મધ્યક) જેવી રીતે પણ ગણી શકાય.
અંકગાણિત અને ભૌમિતિક બંને પ્રકારના પ્રશ્નોમાં "પદ દૂર કરવું" આવે છે – સૂત્ર લાગુ કરો.
ગુણોત્તર મધ્યક (Geometric Mean – G.M.)
a અને b ની વચ્ચેનું ગુણોત્તર મધ્યક G એ ત્રીજું પદ હોય તેવી GP: a, G, b.
G = √(ab)
a, G₁, G₂, ..., Gₙ, b માં સામાન્ય ગુણોત્તર r = (b/a)^(1/(n+1)).
બે ધન સંખ્યાઓનો G.M. તેમના ગુણાકારનો વર્ગમૂળ છે.
📝 UT: a, G, b સતત GP માં G² = ab – આ ગુણધર્મ ઘણા પ્રશ્નોમાં વાપરે.
અંકગાણિત (A.M.) અને ગુણોત્તર (G.M.) મધ્યકો વચ્ચેનો સંબંધ
A.M. ≥ G.M. (બે ધન વાસ્તવિક સંખ્યાઓ માટે)
સમાનતા ત્યારે જ જ્યારે બંને સંખ્યાઓ સમાન હોય: a = b ⇒ A.M. = G.M.
AM-GM અસમાનતા: દરેક ધન સંખ્યાઓ માટે A.M. ≥ G.M. હંમેશા સાચું છે.
📝 UT: AM ≥ GM = GUJCET માં ઘણીવાર સાચું/મૂઢ પ્રશ્ન આવે છે.
હાર્મોનિક શ્રેણી (Harmonic Progression – HP)
જો કોઈ શ્રેણીના પદોના વ્યસ્તો (reciprocals) અંકગાણિત શ્રેણી બનાવતાં હોય તો તે શ્રેણી HP કહેવાય.
HP: 1/a, 1/(a+d), 1/(a+2d), … , 1/(a+(n-1)d)
HP નું n-મું પદ: aₙ = 1 / [a + (n–1)d]
HP ના સરવાળાનું સીધું સૂત્ર નથી! HP ને AP માં ફેરવીને ઉકેલો.
HP – વ્યસ્તો AP બનાવેHP નો ઉકેલ AP દ્વારા
ધન પૂર્ણાંકોના સરવાળા – મહત્વના પરિણામો
1 + 2 + 3 + … + n = n(n+1)/2
1² + 2² + 3² + … + n² = n(n+1)(2n+1)/6
1³ + 2³ + 3³ + … + n³ = [n(n+1)/2]²
Σk³ = (Σk)² – આ રિલેશન યાદ રાખો, પ્રતિસ્પર્ધી પરીક્ષામાં ખૂબ ઉપયોગી.
📝 UT: આ ત્રણેય સૂત્રો મનોરંજન સ્વરૂપે મુખસ્ત કરો.
(2n+1) અને (2n) સુધીના પ્રથમ n ધન બેજોડ પૂર્ણાંકો
1 + 3 + 5 + … + (2n–1) = n²
2 + 4 + 6 + … + 2n = n(n+1)
પ્રથમ n બેજોડ ધન પૂર્ણાંકોનો સરવાળો = n² – એ AP છે (a=1, d=2).
પ્રથમ n જેાડ ધન પૂર્ણાંકોનો સરવાળો = n(n+1) – એ AP છે (a=2, d=2).
bеjoੜ સંખ્યાઓનો સરવાળો n² થાય – આ ગુણધર્મ યાદ રાખવો.
સંકલન સૂત્રોની વ્યુત્પત્તિ (કુદરતી સંખ્યાઓના સરવાળા)
કુદરતી સંખ્યાઓનો સરવાળો એ પ્રથમ n ધન પૂર્ણાંકોનો સરવાળો છે: n(n+1)/2.
આ સૂત્ર (n+1)² – n² = 2n+1 જેવા પદોના સરવાળા દ્વારા પણ મેળવી શકાય.
n ટर्मોના સરવાળાના સૂત્રોની વ્યુત્પત્તિ સમજવી એમ્સના દૃષ્ટિકોણથી મહત્વની છે.
પરીક્ષામાં આવતા મહત્વના પ્રકારો
1) AP નું n-મું પદ શોધવું: aₙ = a + (n–1)d.
2) AP નો સરવાળો: Sₙ = n/2[2a + (n–1)d].
3) GP નું n-મું પદ: aₙ = a·rⁿ⁻¹.
4) GP નો સરવાળો: Sₙ = a(rⁿ–1)/(r–1).
5) અનંત GP: S∞ = a/(1–r), |r| < 1.
આ પાંચેય સૂત્રો મનોરંજન મુખસ્ત – પરીક્ષામાં સીધા આવશે!
📝 UT: દરેક સૂત્ર સાથે તેનો એક ઊદાહરણ પ્રશ્ન વિચારી રાખવો.
પુનરાવર્તિત (Repeated) અને મિશ્ર પ્રશ્નો
AB શ્રેણી: AP ના ઘણા પ્રશ્નો GP સાથે જોડાયેલા હોય છે – બંને જાણવા જોઈએ.
ઉદા. HP નું k-મું પદ શોધવું → પહેલા વ્યસ્ત લો, પછી AP નું k-મું પદ લાગુ કરો, પછી વ્યસ્ત કરો.
મિશ્ર પ્રશ્નોમાં AP/GP નું રૂપ છુપાવેલું હોય છે – પહેલા ઓળખવું જરૂરી છે.
📝 UT: HP પ્રશ્નોમાં વ્યસ્ત કરવાની પ્રક્રિયા ભૂલશો નહીં.
સ્પર્ધાત્મક પરીક્ષા માટે ટૂંક સારાંશ
AP: aₙ = a+(n−1)d, Sₙ = n/2[2a+(n−1)d] = n/2(a+l)
GP: aₙ = a·rⁿ⁻¹, Sₙ = a(rⁿ−1)/(r−1), S∞ = a/(1−r)
A.M. = (a+b)/2, G.M. = √(ab), AM ≥ GM
HP: વ્યસ્તો AP બનાવે; n-મું પદ = 1/[a+(n−1)d]
