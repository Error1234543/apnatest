અનુક્રમ અને શ્રેઢીઓ — સૂત્રપટ

⚡ સૂત્રો

સારણી / અનુક્રમ (Sequence) ની વ્યાખ્યા: f(n) = f(1), f(2), ..., f(n), ...
જ્યાં f એ ક્રમિક પ્રાકૃતિક સંખ્યાઓ પર વ્યાખ્યાયિત વિધેય છે; દરેક મૂલ્ય f(k) એ k-મું પદ છે. · SI: — · n ∈ ℕ (ન હોય તો n ≥ 1)
p-મું પદ સ્વરૂપે અનુક્રમ: T_p = a_p
T_p = p-મું પદ, a_p = પદનું મૂલ્ય · SI: — · p = 1, 2, 3, ...
n-મું પદ અને પૂર્વવર્તી પદ વચ્ચેનો સંબંધ: a_n = S_n - S_(n-1)
a_n = n-મું પદ, S_n = પ્રથમ n પદનો સરવાળો, S_(n-1) = પ્રથમ n-1 પદનો સરવાળો · SI: — · n ≥ 2; n = 1 માટે a_1 = S_1
સમાંતર શ્રેઢી (A.P.) નું સામાન્ય પદ: a_n = a + (n-1)d
a_n = n-મું પદ, a = પ્રથમ પદ, d = સામાન્ય પથ્થર (common difference), n = પદની સંખ્યા · SI: — · શ્રેઢી સમાંતર હોય (દરેક પછીના પદ-પૂર્વનું પદ = અચળ d)
સમાંતર પથ્થર (d): d = a_n - a_(n-1) = a_2 - a_1
d = સામાન્ય પથ્થર, a_n = n-મું પદ, a_(n-1) = (n-1)-મું પદ · SI: — · શ્રેઢી સમાંતર હોય ત્યારે
સમાંતર શ્રેઢીના n પદનો સરવાળો (પદાવલી સ્વરૂપ): S_n = n/2 · [2a + (n-1)d]
S_n = પ્રથમ n પદનો સરવાળો, a = પ્રથમ પદ, d = સામાન્ય પથ્થર, n = પદ સંખ્યા · SI: — · સમાંતર શ્રેઢી માટે
સમાંતર શ્રેઢીના n પદનો સરવાળો (અંતિમ પદ સ્વરૂપ): S_n = n/2 · (a + l)
S_n = પ્રથમ n પદનો સરવાળો, a = પ્રથમ પદ, l = અંતિમ (n-મું) પદ · SI: — · l = a_n જાણીતું હોય ત્યારે, સમાંતર શ્રેઢી માટે
n સ્વાભાવિક સંખ્યાઓનો સરવાળો: Σn = n(n+1)/2
Σn = 1+2+3+...+n, n = અંતિમ સંખ્યા · SI: — · n ∈ ℕ
n સ્વાભાવિક સંખ્યાઓના વર્ગોનો સરવાળો: Σn^2 = n(n+1)(2n+1)/6
Σn^2 = 1²+2²+...+n², n = અંતિમ સંખ્યા · SI: — · n ∈ ℕ
n સ્વાભાવિક સંખ્યાઓના ઘનનો સરવાળો: Σn^3 = [n(n+1)/2]^2
Σn^3 = 1³+2³+...+n³, n = અંતિમ સંખ્યા · SI: — · n ∈ ℕ
સમાંતર શ્રેઢીની m અને n પદોનો સરવાળો જો સમાન હોય: m/S_m = n/S_n ⇒ m²:n² = a(d મુક્ત ભાગ):d (વિશેષ રૂપે m = n હોય તો S_m = S_n)
S_m = m પદનો સરવાળો, S_n = n પદનો સરવાળો · SI: — · જો S_m = S_n, તો (m-n)[2a+(m+n-1)d]=0, તેથી 2a+(m+n-1)d=0
સમગુણોત્તર શ્રેઢી (G.P.) નું સામાન્ય પદ: a_n = a · r^(n-1)
a_n = n-મું પદ, a = પ્રથમ પદ, r = સામાન્ય ગુણોત્તર (common ratio), n = પદ સંખ્યા · SI: — · r ≠ 0, શ્રેઢી સમગુણોત્તર હોય
સામાન્ય ગુણોત્તર (r): r = a_n / a_(n-1) = a_2 / a_1
r = સામાન્ય ગુણોત્તર, a_n = n-મું પદ · SI: — · શ્રેઢી સમગુણોત્તર હોય, a_(n-1) ≠ 0
સમગુણોત્તર શ્રેઢીના n પદનો સરવાળો (r > 1 અથવા |r| > 1): S_n = a(r^n - 1)/(r - 1)
S_n = પ્રથમ n પદનો સરવાળો, a = પ્રથમ પદ, r = સામાન્ય ગુણોત્તર · SI: — · r ≠ 1
સમગુણોત્તર શ્રેઢીના n પદનો સરવાળો (|r| < 1): S_n = a(1 - r^n)/(1 - r)
S_n = પ્રથમ n પદનો સરવાળો, a = પ્રથમ પદ, r = સામાન્ય ગુણોત્તર · SI: — · r ≠ 1; સામાન્ય રીતે |r| < 1 સંજ્ઞા માટે
અનંત સમગુણોત્તર શ્રેઢીનો સરવાળો: S_∞ = a/(1 - r)
S_∞ = અનંત શ્રેઢીનો સરવાળો, a = પ્રથમ પદ, r = સામાન્ય ગુણોત્તર · SI: — · |r| < 1 (શ્રેઢી અભિસરણ કરે)
ત્રણ સંખ્યાઓ સમાંતર શ્રેઢીમાં: a, b, c સમાંતરમાં ⇒ 2b = a + c
b = મધ્ય પદ (સમાંતર માધ્ય), a, c = બાહ્ય પદો · SI: — · a, b, c સમાંતર શ્રેઢીના સતત ત્રણ પદો હોય
ચાર સંખ્યાઓ સમાંતર શ્રેઢીમાં: a-d, a, a+d, a+2d
a = બીજું પદ, d = સામાન્ય પથ્થર · SI: — · ચાર સતત પદો સમાંતરમાં હોય
ત્રણ સંખ્યાઓ સમગુણોત્તર શ્રેઢીમાં: a, ar, ar² સમગુણોત્તરમાં ⇒ b² = ac
b = મધ્ય પદ (ગુણોત્તર માધ્ય), a, c = બાહ્ય પદો, b² = ac · SI: — · a, b, c સમગુણોત્તર શ્રેઢીના સતત ત્રણ પદો હોય
ચાર સંખ્યાઓ સમગુણોત્તર શ્રેઢીમાં: a/r, a, ar, ar²
a = બીજું પદ, r = સામાન્ય ગુણોત્તર · SI: — · ચાર સતત પદો સમગુણોત્તરમાં હોય
સમાંતર-સમગુણોત્તર શ્રેઢી (A.P.-G.P.) — A.P. અને G.P. વચ્ચેનો સંબંધ: જો a, b, c સમાંતરમાં હોય ⇒ b = (a+c)/2; જો a, b, c સમગુણોત્તરમાં હોય ⇒ b = √(ac)
બંને કિસ્સાઓ માટે મધ્ય પદ બહુપુરસ્કાર છે · SI: — · ધન વાસ્તવિક સંખ્યાઓ માટે
H.P. (સંપૂર્ણ પ્રભેદ શ્રેઢી) ની વ્યાખ્યા: a, b, c H.P. મા ⇒ 1/a, 1/b, 1/c A.P. મા
H.P. = Harmonic Progression, તક્રમ ઉલ્ટાવતા A.P. મળે · SI: — · k-મું H.P. પદ = 1/(a + (k-1)d), જ્યાં a, d એ સંગત A.P. ના પ્રથમ પદ અને સામાન્ય પથ્થર
n સ્વાભાવિક સંખ્યાઓના વ્યસ્તનો સરવાળો (હાર્મોનિક): Σ(1/n) = 1 + 1/2 + 1/3 + ... + 1/n = H_n (હાર્મોનિક સંખ્યા)
H_n = n-મી હાર્મોનિક સંખ્યા, અંદાજ: H_n ≈ ln(n) + γ (γ ≈ 0.5772 = આઈલર-મેચેની અચળ) · SI: — · નિત્ય સંબંધ
શ્રેઢીને A.P. માં ફેરવવાનો પ્રમાણભૂત ખ્યાલ: a_n = an + b (n ની રેખીય વિધેય) ⇒ શ્રેઢી A.P. મા
a_n = n-મું પદ, a, b = અચળાંકો · SI: — · જો સામાન્ય પદ n માં રેખીય હોય, તો શ્રેઢી સમાંતર શ્રેઢી છે
સમાંતર શ્રેઢીમાં પદોની સંખ્યા શોધવી (અંતિમ પદ l): n = (l - a)/d + 1
n = પદ સંખ્યા, a = પ્રથમ પદ, l = અંતિમ પદ, d = સામાન્ય પથ્થર · SI: — · d ≠ 0
કોઈ પણ પદ m એ A.P. માં છે કે નહીં તપાસવાનું: m = a + (k-1)d ⇒ (m-a)/d = પૂર્ણાંક k-1 હોવો જોઈએ
m = તપાસવાનું પદ, a = પ્રથમ પદ, d = સામાન્ય પથ્થર, k = પદ સ્થાન · SI: — · k ∈ ℕ

🔗 સંબંધો

  • જો a_n = S_n - S_(n-1) હોય અને S_n એ n માં દ્વિઘાત વિધેય હોય (An²+Bn), તો શ્રેઢી સમાંતર શ્રેઢી છે.
  • સમાંતર શ્રેઢીના n પદનો સરવાળો S_n = n/2[2a+(n-1)d] એ n માં દ્વિઘાત વિધેય છે; S_n = 0 થાય ત્યારે શૂન્ય પદોનો સરવાળો મળે.
  • A.P., G.P., H.P. નું મૂળભૂત સંબંધ: A.P. ના પદોના વ્યસ્ત લેતાં H.P. મળે; G.P. માં દરેક પદ ધન હોય ત્યારે તેમના લઘુગુણક લેતાં A.P. મળે.
  • શ્રેઢીના ત્રણ સતત પદો a, b, c માટે: (b-a)/(c-b) = 1 (A.P.), b/a = c/b (G.P.).
  • n ત્રિકોણાકાર સંખ્યાઓનો સરવાળો (1+3+6+...+n(n+1)/2) = n(n+1)(n+2)/6.

🎯 ટ્રિક્સ

શ્રેઢીનું n-મું પદ શોધવું હોય ત્યારે T_n = S_n - S_(n-1) સૂત્રનો ઉપયોગ — S_n સીધું આપેલું હોય તો સૌથી ઝડપી રસ્તો.
A.P. ના n પદોનો સરવાળો S_n = n/2(a+l) માં l = a+(n-1)d મૂકતાં S_n = n/2[2a+(n-1)d] મળે — બંને સમીકરણો સમાન છે.
જો આપેલી શ્રેઢીના પદોનો સરવાળો S_n = An²+Bn પ્રકારનું હોય, તો A.P. નું પ્રથમ પદ a = S_1 = A+B અને સામાન્ય પથ્થર d = 2A.
G.P. માં a_n = a·r^(n-1); r^(n-1) ને ધ્યાનથી ગણતરી કરો — (n-1) ઘાત હોય છે, n નહીં.
T્રણ સંખ્યાઓ A.P. માં: a-d, a, a+d લેતાં સરવાળો 3a મળે — ગણતરી સરળ બને છે.
T્રણ ધન સંખ્યાઓ G.P. માં: a/r, a, ar લેતાં ગુણાકાર a³ મળે — પ્રમાણમાં સરળ.
H.P. નો કોઈ પણ પદ = 1/(A.P. નો અનુરૂપ પદ). તેથી H.P. ના સરવાળા માટે પહેલા સંગત A.P. શોધો.
A.P. માં બાહ્ય પદોનો સરવાળો = મધ્ય પદોનો સરવાળો જો સંખ્યા સમ (એven) હોય, અને બાહ્ય+આંતરિક જોડી સમાન રહે છે.

⚠️ ભૂલો

a_n = S_n - S_(n-1) માં n-1 ને ખોટો ગણીને (n-1) ને બદલે n લખવું અથવા n = 1 માટે સૂત્ર લાગુ પાડવું — n = 1 માટે a_1 = S_1 હોય છે.
A.P. ના સરવાળામાં S_n = n/2[a+l] અને S_n = n/2[2a+(n-1)d] વચ્ચે l = a_n યાદ રાખવું; l ને ગમતરથી a-(n-1)d ને બદલે a+(n-1)d લખવું.
G.P. ના સામાન્ય પદમાં a_n = a·r^n લખવું (ખોટું) — સાચું સૂત્ર a_n = a·r^(n-1) છે.
G.P. ના સરવાળામાં r = 1 હોય ત્યારે S_n = a(1-r^n)/(1-r) સૂત્ર લાગુ પાડવું — r = 1 હોય ત્યારે S_n = n·a લખવું જોઈએ.
અનંત G.P. ના સરવાળા S_∞ = a/(1-r) માટે |r| < 1 શરત ભૂલી જવા — |r| ≥ 1 હોય તો સરવાળો અપરિબંધિત છે.
H.P. ની વ્યાખ્યામાં વ્યસ્ત લેવાને બદલે પદોને ઉલટાવવાની ભૂલ — H.P. એ એવો ક્રમ છે કે જેના વ્યસ્ત A.P. બને.
A.P. માં n પદોના સરવાળામાં n/2 લેતાં (a+l) ને બદલે (a-l) લખવું.
સમાન A.P. ના S_m અને S_n સમાન હોય ત્યારે (m-n)[2a+(m+n-1)d]=0 યાદ રાખવું; મોટા ભાગના વિદ્યાર્થીઓ 2a+(m+n-1)d=0 કાઢવામાં ભૂલ કરે છે.
