આંકડાશાસ્ત્ર (Statistics) — ઝડપી પુનરાવર્તન નોંધ

🧪 GUJCET — Gujarati • Mathematics • Statistics

📘 વ્યાખ્યાઓ

  • આંકડા: એકત્રિત અને ગોઠવેલ સંખ્યાત્મક માહિતી, જેનું વિશ્લેષણ કરી શકાય.
  • મધ્યક (Mean): કુલ મૂલ્યોનો સરવાળો બાદ કુલ સંખ્યા.
  • મધ્યસ્થ (Median): ગોઠવેલ ડેટાનો મધ્યમ મૂલ્ય.
  • બહુલક (Mode): સૌથી વધુ આવૃત્તિ ધરાવતું મૂલ્ય.
  • વિચરણ (Variance): પ્રમાણિત વિચલનનો વર્ગ, એકમનો વર્ગ હોય છે.
  • પ્રમાણિત વિચલન (Standard Deviation): મૂલ્યો અને મધ્યક વચ્ચેના વિચલનનું વર્ગમૂળ.
  • સાધારણ વિચલન (Mean Deviation): મધ્યકથી આવી રહેલા પરમાણ્વિક અંતરનું સરેરાશ.
  • ચરમક (Range): મહત્તમ અને ન્યૂનતમ મૂલ્ય વચ્ચેનો તફાવત.
  • આવૃત્તિ (Frequency): કોઈ મૂલ્ય કે શ્રેણીની દોહરાવવામાં આવેલી સંખ્યા.
  • ડિગ્રી ઓફ ફ્રીડમ (Degree of Freedom): મધ્યક સુધી મર્યાદિત સ્વતંત્ર મૂલ્યોની સંખ્યા.

⚡ સૂત્રો

  • મધ્યક (સરળ) = Σx / n
  • મધ્યક (વિસ્તૃત) = Σ(f × x) / Σf
  • મધ્યક (અવશેષ પદ્ધતિ) = A + Σ(f × d) / Σf, જ્યાં d = x − A
  • મધ્યસ્થ સ્થાન = (n + 1) / 2 વામો ક્રમ
  • મધ્યસ્થ (સમૂહિત) = l + [(n/2 − cf) / f] × h
  • બહુલક = l + [f₁ − f₀] / [2f₁ − f₀ − f₂] × h
  • વિચરણ (σ²) = Σ(x − μ)² / n
  • પ્રમાણિત વિચલન (σ) = √[Σ(x − μ)² / n]
  • સાધારણ વિચલન = Σ|x − μ| / n
  • ચરમક = ઉચ્ચતમ મૂલ્ય − ન્યૂનતમ મૂલ્ય
  • ડિગ્રી ઓફ ફ્રીડમ (વિચરણ માટે) = n − 1

⭐ મુખ્ય તથ્યો

  • મધ્યક પર બધા મૂલ્યોની સમાન અસર હોય છે.
  • મધ્યસ્થ માત્ર મધ્યમ ક્રમાંકના મૂલ્ય પર આધારિત છે.
  • બહુલક હંમેશા સૌથી વધુ આવૃત્તિ ધરાવતું મૂલ્ય હોય છે.
  • પ્રમાણિત વિચલનનો એકમ મૂળ એકમના સમાન રહે છે.
  • વિચરણનો એકમ મૂળ એકમના વર્ગનો હોય છે.
  • સાધારણ વિચલન મધ્યકથી આસન્ન વિચલનને ધ્યાનમાં લે છે.
  • આવૃત્તિ કોષ્ટક મૂલ્યોની પુનરાવૃત્તિ દર્શાવે છે.
  • વિચરણની ગણતરીમાં ડિગ્રી ઓફ ફ્રીડમ n − 1 વપરાય છે.
  • ચરમક માત્ર બે ટકારાઉ મૂલ્યો પર આધારિત છે.
  • સંમિત વિતરણમાં મધ્યક = મધ્યસ્થ = બહુલક.
  • ઊજડાં ઢળેલા વિતરણમાં મધ્યક < મધ્યસ્થ < બહુલક.
  • ડાબે ઢળેલા વિતરણમાં મધ્યક > મધ્યસ્થ > બહુલક.
  • બહુલક એક થી વધુ હોઈ શકે (બહુ-બહુલકીય વિતરણ).
  • મધ્યક, મધ્યસ્થ, બહુલક એ સરેરાશના ત્રણ માપ છે.
  • પ્રમાણિત વિચલન જેટલું નાનું, એટલો ડેટા વધુ સંકુચિત.

⚠️ સામાન્ય ભૂલો

  • મધ્યક અને મધ્યસ્થની ગણતરીમાં ક્રમ ભૂલવો.
  • વિચરણ અને પ્રમાણિત વિચલન વચ્ચેનો તફાવત ન સમજવો.
  • ચરમક માટે મહત્તમ − ન્યૂનતમ ન કરતાં વધુ કામ કરવું.
  • વિચરણ શોધતી વખતે n ની જગ્યાએ n − 1 લેવાની ભૂલ.
  • સાધારણ વિચલનમાં (x − μ) નું ચિહ્ન અવહેળવેલું રાખવું.
  • મધ્યસ્થ શોધતી વખતે (n + 1)/2 ને બદલે n/2 વાપરવું.
  • બહુલકની શ્રેણી માટે f₁, f₀, f₂ ને યોગ્ય રીતે મૂકવામાં ભૂલ.
  • વિચરણનો એકમ મૂળ એકમ સાથે સમાન ગણી લેવો.
  • પ્રમાણિત વિચલનના વર્ગ કરવામાં વિચરણ મળે છે એ ભૂલવું.
  • આવૃત્તિ કોષ્ટકમાં મધ્યબિંદુ ગણતરીની ભૂલ.
  • શૂન્યવિચલન અથવા ઋણ વિચરણની ધારણા રાખવી.
  • મધ્યકની ગણતરીમાં દરેક મૂલ્યની આવૃત્તિ ન ગણવી.
  • ડિગ્રી ઓફ ફ્રીડમને n ગણી લેવું.
  • મધ્યસ્થ અને બહુલકની સૂત્ર એકબીજા સાથે ગૂંચવવી.
  • વિસ્તૃત મધ્યકમાં f × x ની કોષ્ટકભંડોળ ભૂલ.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • મધ્યક, મધ્યસ્થ, બહુલક વચ્ચેનો તફાવત અને સંબંધ.
  • વિચરણ અને પ્રમાણિત વિચલન વચ્ચેનો સીધો સંબંધ.
  • ડિગ્રી ઓફ ફ્રીડમની વ્યાખ્યા અને ગણતરી.
  • સાધારણ વિચલનની ગણતરી પદ્ધતિ.
  • સીધી, વિસ્તૃત અને અવશેષ પદ્ધતિથી મધ્યક શોધવું.
  • આવૃત્તિ કોષ્ટકથી મધ્યક, મધ્યસ્થ, બહુલક શોધવા.
  • મલ્ટિમોડલ અને એકમોડલ વિતરણને ઓળખવું.
  • પ્રમાણિત વિચલન અને વિચરણના એકમો.
  • વિતરણની ઢલણ (skewness) અને સરેરાશનો સંબંધ.
  • ચરમકની ગણતરી અને તેની મર્યાદાઓ.
  • સંમિત વિતરણમાં ત્રણેય સરેરાશ સમાન હોય.
  • ઊજડાં અને ડાબા ઢળેલા વિતરણનું લક્ષણ.
  • પ્રમાણિત વિચલન નાનો હોય તો ડેટા વધુ સંકુચિત.
  • મધ્યસ્થની સૂત્ર (n + 1)/2 અને સમૂહિત રૂપ.
  • વિચરણ માટે n − 1 અથવા n વાપરવાનો સંદર્ભ.
  • બહુલક માટે f₁, f₀, f₂ નું યોગ્ય સૂત્ર.
  • અવશેષ પદ્ધતિમાં A ની પસંદગીની અસર.
  • સાધારણ વિચલનમાં |x − μ| નું મહત્વ.
  • મધ્યક પર અસામાન્ય મૂલ્યો (outliers) ની અસર.
  • ડિગ્રી ઓફ ફ્રીડમનું વિચરણ ગણતરી પર પ્રભાવ.
