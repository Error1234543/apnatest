પરિસ્થિતિશાસ્ત્ર — આંકડાકિયો (Statistics)

🧪 GUJCET — Gujarati • Mathematics • Statistics

અધ્યાય: આંકડાકિયો (Statistics) — પ્રસ્તાવના
આંકડાકિયો એ આવૃત્તિ વિતરણ (Frequency Distribution) ના ગાણિતિક નિયમોનો અભ્યાસ કરતો વિભાગ છે.
GUJCET માં આંકડાકિયો એક મહત્વપૂર્ણ વિભાગ છે — સરેરાશ, મધ્યકાળ, બહુલક, પ્રમાણિત વિચલન, સહગામિતા, પૂર્વાભાસ—આ બધાના સૂત્રો યાદ રાખવા જરૂરી છે.
આંકડાકિયોમાં મુખ્યત્વે બે પ્રકારની પરિસ્થિતિઓ ગણીએ છીએ: (1) સાધનિમ અથવા કુલ સરેરાશ, (2) મધ્યકાળ અને બહુલક.
📝 📌 યાદ રાખો: આંકડાકિયો કોઈ પણ વ્યક્તિગત મૂલ્યને બદલે સામૂહિક ગુણધર્મોનું વિશ્લેષણ કરે છે.
સાધનિમ (Mean) = પદાવલી મૂલ્યોનો સરવાળો / કુલ પદોની સંખ્યા
વિતરણમધ્યક → બહુલક → પ્રમાણિત વિચલન
પરિભાષાઓ (Terminology)
આંકડો (Statistic): નમૂનામાંથી મેળવેલો એક ચલ.
પરિણામ (Parameter): જનસ્તોતીનો અંતર્ગત સ્થિરાંક.
ચલ (Variable): જેની કિંમતો બદલાય છે તેવું પદાવલિ.
ચલોના પ્રકારો: (1) અખંડ ચલ (Continuous), (2) અવિખંડ ચલ (Discrete).
જનસ્તોત (Population): સંશોધનનો વિષયબિંદુ બધા એકમોનો સમૂહ.
નમૂનો (Sample): જનસ્તોતનો નિદર્શ ભાગ, જેનો અભ્યાસ કરવામાં આવે છે.
📝 ⚠ નમૂનાનું દળ (n) મોટું હોય તો પરિણામ વધુ વિશ્વસનીય મળે છે.
જનસ્તોતનમૂનો
પરિભાષાઓ — આવૃત્તિ અને સદિશ
આવૃત્તિ (Frequency): કોઈ ચલના કોઈક મૂલ્ય જેટલી વાર ઉપસ્થિત રહે છે તેટલી વાર.
સદિશ (Class): આંકડાકિય વિતરણમાં ગટ્ટા (Class Interval) ને સદિશ કહેવાય છે.
સદિશમધ્ય (Class Mark): સદિશના મધ્યબિંદુનું મૂલ્ય = (ઉપરલી ચોરી + નીચલી ચોરી) / 2.
સદિશમધ્ય (xi) = (ઉપરલી ચોરી + નીચલી ચોરી) / 2
સદિશપહોળાઈ (Class Width): સદિશની ઉપરલી અને નીચલી ચોરી વચ્ચેનો તફાવત.
જ્યારે સદિશો અસતત હોય, ત્યારે તેમને સતત બનાવવા માટે 0.5 નો સુધારો કરવો પડે છે.
📝 📌 ઘણીવાર GUJCET માં સદિશો આપવામાં આવે છે, પ્રથમ સદિશમધ્યો શોધવાના હોય છે.
કુલ સરેરાશ — સાધનિમ માર્ગ (Direct Method)
જ્યારે ચલો મધ્યમ ક્રમની હોય અને મૂલ્યો ટૂંકા હોય, ત્યારે સાધનિમ માર્ગ ઉપયોગમાં લેવાય છે.
x̄ = Σ(fᵢ × xᵢ) / Σfᵢ
અહીં fᵢ = આવૃત્તિ, xᵢ = સદિશમધ્ય (Class Mark).
GUJCET માં વારંવાર આ માર્ગની ચોકસાઈ માટે કોષ્ટક બનાવવું શીખવું જરૂરી છે.
📝 ⚠ x̄ ની એકમો xᵢ ની જેમ જ રહે છે.
શુદ્ધ માર્ગસાધનિમ માર્ગ
કુલ સરેરાશ — પરિવર્તિત મધ્યક માર્ગ (Assumed Mean Method)
જ્યારે xᵢ મૂલ્યો મોટા હોય અથવા દશાંશ ધરાવતા હોય, ત્યારે પરિવર્તિત મધ્યક માર્ગ વધુ સરળ છે.
x̄ = A + [Σ(fᵢ × dᵢ) / Σfᵢ] જ્યાં dᵢ = xᵢ – A
A એ અંતરરાધ (Assumed Mean) છે. સામાન્ય રીતે મધ્યમ સદિશમધ્યને A તરીકે લેવાય છે.
dᵢ ની ગણતરીમાં ધન (+) અને ઋણ (–) ચિહ્નોનો ખ્યાલ રાખવો જરૂરી છે.
📝 📌 A પસંદ કરવાથી ફળિત બદલાતું નથી, પરંતુ ગણતરી સરળ બને છે.
A પસંદગીગણતરી સરળ બને
કુલ સરેરાશ — સદિષ્ટિ માર્ગ (Step-Deviation Method)
જ્યારે dᵢ = xᵢ – A ને c વડે ભાગી શકાય તેવું હોય, ત્યારે સદિષ્ટિ માર્ગ લાભદાયી છે.
x̄ = A + [Σ(fᵢ × uᵢ) / Σfᵢ] × c જ્યાં uᵢ = (xᵢ – A)/c
c = સદિશપહોળાઈ (Class Width).
GUJCET માં આ માર્ગ ખાસ કરીને સદિશપહોળાઈ સમાન હોય તેવા કિસ્સામાં વાપરવામાં આવે છે.
uᵢ = (xᵢ – A) / c
📝 📌 uᵢ એકમરહિત (unitless) ચલ છે.
મધ્યકાળ (Median)
મધ્યકાળ એવી કિંમત છે કે જે વિતરણમાં આधा (મધ્ય) પર આવેલું હોય છે.
Median = l + [ (N/2 – C.F.) / f ] × h
l = મધ્યકાળ સદિશની નીચલી ચોરી, N = કુલ આવૃત્તિનો સરવાળો, C.F. = આગળની સંચિત આવૃત્તિ, f = મધ્યકાળ સદિશની આવૃત્તિ, h = સદિશપહોળાઈ.
મધ્યકાળ સદિશ એવો સદિશ છે જેમાં C.F. ≥ N/2 થાય છે.
અવિખંડ ચલ (અવિચળ) માટે: મધ્યકાળ = (n+1)/2 મું બંધની ચલ.
📝 ⚠ સંચિત આવૃત્તિ પહેલાથી ગણી લેવી જોઈએ, નહીંતર મધ્યકાળ સદિશ શોધવો મુશ્કેલ પડે.
વિતરણમધ્યકાળ સદિશ નક્કી થાય
બહુલક (Mode)
બહુલક એવું મૂલ્ય છે જે સૌથી વધુ આવૃત્તિ ધરાવતું સદિશ હોય છે.
Mode = l + [ (f₁ – f₀) / (2f₁ – f₀ – f₂) ] × h
l = બહુલક સદિશની નીચલી ચોરી, f₁ = બહુલક સદિશની આવૃત્તિ, f₀ = તેના પહેલાના સદિશની આવૃત્તિ, f₂ = તેના પછીના સદિશની આવૃત્તિ, h = સદિશપહોળાઈ.
બહુલક સદિશ એવો સદિશ હોય છે જેની આવૃત્તિ સૌથી વધુ હોય.
📝 📌 GUJCET માં બહુલકની ગણતરી કરતી વખતે આગળ-પાછલા સદિશોની આવૃત્તિઓ ધ્યાનમાં રાખવી.
સૌથી વધુ આવૃત્તિબહુલક સદિશ
સરેરાશ–મધ્યકાળ–બહુલક વચ્ચેનો સંબંધ
Mode = 3(Median) – 2(Mean)
આ સંબંધ ફક્ત મોનોમોડલ (એકબહુલકીય) વિતરણ માટે લાગુ પડે છે.
GUJCET માં ઘણીવાર આ સૂત્રનો ઉપયોગ કરીને બહુલક અથવા મધ્યકાળ શોધવાનો પ્રશ્ન આવે છે.
જો Mean = 10, Median = 12 હોય, તો Mode = 3×12 – 2×10 = 36 – 20 = 16.
📝 ⚠ આ સંબંધ સદૃશ વિતરણ (Symmetric distribution) માટે Mean = Median = Mode થાય છે.
પ્રમાણિત વિચલન (Standard Deviation) — સાધનિમ માર્ગ
σ = √[ Σ(fᵢ × xᵢ²) / Σfᵢ – (Σ(fᵢ × xᵢ) / Σfᵢ)² ]
આ માર્ગમાં xᵢ ના વર્ગનો સરવાળો લેવામાં આવે છે.
GUJCET માં આ સૂત્રનો ઉપયોગ કરતી વખતે ગણતરીની ભૂલ ઓછી કરવા માટે કોષ્ટક તૈયાર કરવું.
📝 📌 σ નું એકમ xᵢ જેવું જ રહે છે.
પ્રમાણિત વિચલન — પરિવર્તિત મધ્યક માર્ગ
σ = √[ Σ(fᵢ × dᵢ²) / Σfᵢ – (Σ(fᵢ × dᵢ) / Σfᵢ)² ]
જ્યાં dᵢ = xᵢ – A (અથવા dᵢ = xᵢ – A).
A પસંદ કરવાથી પ્રમાણિત વિચલન પર કોઈ અસર નથી પડતી.
σ = √[ Σ(fᵢ × uᵢ²) / Σfᵢ – (Σ(fᵢ × uᵢ) / Σfᵢ)² ] × c
જો uᵢ = (xᵢ – A)/c લેવામાં આવે, તો અંતિમ ઉત્તરને c વડે ગુણવું.
📝 ⚠ uᵢ પદ્ધતિમાં અંતે c વડે ગુણવું ભૂલશો નહીં.
σ શોધવુંવિચલનનું વિશ્લેષણ
સહગામિતા (Correlation) — પીયરસન સૂત્ર
r = [ nΣxy – (Σx)(Σy) ] / √{ [nΣx² – (Σx)²] [nΣy² – (Σy)²] }
r ની કિંમત –1 થી +1 વચ્ચે હોય છે.
r = +1: સંપૂર્ણ ધન સહગામિતા | r = –1: સંપૂર્ણ ઋણ સહગામિતા | r = 0: કોઈ સહગામિતા નથી.
સહગામિતા એ બે ચલો વચ્ચેનું રેખીય સંબંધ દર્શાવે છે.
📝 📌 GUJCET માં r ની કિંમત શોધવાની સાથે જ તેનો અર્થ પણ લખવાનો હોય છે.
x અને yr ની ગણતરી
સહગામિતાનો અંદાજ ( Scatter Diagram )
Scatter diagram માં દરેક જોડી (xᵢ, yᵢ) ને બિંદુ તરીકે દર્શાવવામાં આવે છે.
જો બિંદુઓ ઊંચાતી ફરતે ઝુકે તો ધન સહગામિતા, જો નીચાતી ફરતે ઝુકે તો ઋણ સહગામિતા.
Scatter diagram માંથી જ સહગામિતાની દિશા અને પ્રબળતાનું અંદાજ લગાવી શકાય.
📝 ⚠ Scatter diagram એ r ની ચોકસાઈપૂર્વકની ગણતરી કરતું નથી, ફક્ત અંદાજ આપે છે.
પ્રત્યાભાસ સમીકરણો (Regression Equations)
y નું x પર પ્રત્યાભાસ (Regression of y on x): y – ȳ = b_yx (x – x̄)
x નું y પર પ્રત્યાભાસ (Regression of x on y): x – x̄ = b_xy (y – ȳ)
b_yx = r × (σ_y / σ_x)
b_xy = r × (σ_x / σ_y)
GUJCET માં બંને પ્રત્યાભાસ સમીકરણો આપેલા હોય, તો x̄, ȳ, r શોધવાના હોય છે.
📝 📌 બંને પ્રત્યાભાસ રેખાઓ (x̄, ȳ) બિંદુ પરથી પસાર થાય છે.
પ્રત્યાભાસ ગુણાંકોના ગુણધર્મો
r² = b_xy × b_yx — આ એક મહત્વનો ગુણધર્મ છે.
r ની ચિહ્ન બંને પ્રત્યાભાસ ગુણાંકોના ગુણાકાર પરથી નક્કી થાય છે.
જો બંને ગુણાંકોનું ચિહ્ન સમાન હોય તો r ધન, વિરુદ્ધ હોય તો r ઋણ.
જો r = 1, તો બંને પ્રત્યાભાસ રેખાઓ સમાન રેખા બને છે.
📝 ⚠ GUJCET માં r અને પ્રત્યાભાસ ગુણાંકો વચ્ચેનો સંબંધ યાદ રાખવો જરૂરી છે.
b_xy × b_yxr² મળે
પ્રત્યાભાસ રેખાઓનો ઉપયોગ (Prediction)
y નું x પર પ્રત્યાભાસ સમીકરણમાં x નું મૂલ્ય મૂકી y નું અંદાજિત મૂલ્ય શોધી શકાય.
