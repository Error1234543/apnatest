રીખીય પ્રોગ્રામિંગ (Linear Programming)

🧪 GUJCET — Gujarati • Mathematics • Linear Programming

રીખીય પ્રોગ્રામિંગ એ એક ગાણિતિક પદ્ધતિ છે જેનો ઉપયોગ લક્ષ્યિત ફલન (objective function) ને મહત્તમ અથવા ન્યૂનતમ કરવા માટે થાય છે, જ્યારે કેટલાક રીખીય બંધનો (linear constraints) હોય. આ અધ્યાયમાં વિદ્યાર્થીઓ રીખીય અસમતાઓ દ્વારા નિયત પ્રદેશ શોધવાની, શિરોબિંદુ (corner) પદ્ધતિ વડે ઉકેલ મેળવવાની અને વાસ્તવિક જીવનની પરિસ્થિતિઓને ગાણિતિક રૂપમાં વ્યક્ત કરવાની કુશળતા મેળવે છે. ઊત્પાદન, ખર્ચ, વિતરણ અને સંસાધન કેટલોકરણ જેવી ગ્રહણીય સમસ્યાઓનો ઉકેલ મેળવવા માટે આ પદ્ધતિ અત્યંત ઉપયોગી છે.

પરિચય અને પદ્ધતિનો સ્વરૂપ

રીખીય પ્રોગ્રામિંગ (Linear Programming) માં અમે એક રીખીય લક્ષ્યિત ફલન Z = px + qy ને મહત્તમ અથવા ન્યૂનતમ કરવાનો પ્રયાસ કરીએ છીએ. આ ફલન સામાન્ય રીતે લાભ, ખર્ચ, સમય કે વ્યય વગેરેને દર્શાવે છે. તેના પર રીખીય બંધનો લાગુ પડે છે, જેનું સ્વરૂપ ax + by ≤ c અથવા ax + by ≥ c હોઈ શકે છે. આવા બંધનો વિવિધ પ્રકારના સંસાધન મર્યાદાઓ, માંગ, ઉપલબ્ધિ વગેરેને દર્શાવે છે. રીખીય પ્રોગ્રામિંગ સમસ્યાને ગ્રાફિક પદ્ધતિ દ્વારા ઉકેલવી શક્ય બને છે, જ્યારે ચલો બે હોય. ઘણી વેળા આ પદ્ધતિથી ઉકેલ મેળવવો વધુ સ્પષ્ટ અને દ્રશ્યાત્મક રીતે સમજાતો હોય છે.

રીખીય અસમતાઓ અને તેમનો ગ્રાફ

રીખીય અસમતા (Linear Inequality) એ એવી અસમતા છે જેમાં ચલોનો ઉચ્ચતમ ઘાત 1 હોય. ઉદાહરણ તરીકે 2x + 3y ≤ 6, x ≥ 0, y ≥ 0. આવા બંધનોનો ઉકેલ પ્રદેશ (solution region) એ સમતલ પરનો એક ભાગ હોય છે. અસમતાને રેખા (line) તરીકે દોરવામાં આવે છે; વાસ્તવિક રેખા (solid line) ≤ અથવા ≥ માટે અને સ્થિતિજ રેખા (dashed line) < અથવા > માટે. પછી બે બિંદુઓ વડે રેખા દોરીને, મૂળબિંદુ (0,0) ને અસમતામાં મૂકીને જો તરક બને તો મૂળ બિંદુની તરફનો પ્રદેશ અથવા તેની વિરુદ્ધ દિશાનો પ્રદેશ ઉકેલ પ્રદેશ તરીકે ચિત્રિત કરવામાં આવે છે.

નિયત પ્રદેશ (Feasible Region)

બધી રીખીય બંધનો (અસમતાઓ) ના સાધારણ ઉકેલ પ્રદેશને નિયત પ્રદેશ (Feasible Region) કહે છે. આ પ્રદેશ સામાન્ય રીતે બહુબાજુ (polygon) જેવો રચાય છે અને તેમાં x ≥ 0, y ≥ 0 માટે પ્રથમ ચરણમાં હોય છે. નિયત પ્રદેશની સીમા રેખાઓ બંધનો પ્રમાણે બને છે. આ પ્રદેશનો દરેક આંતરિક અને સીમાબિંદુ અનુકૂળ ઉકેલ (feasible solution) ની ગણાાય છે. ઘણી વખત નિયત પ્રદેશ અનંત વિસ્તૃત પણ હોઈ શકે છે. ઉકેલ શોધવાની પ્રક્રિયામાં આ પ્રદેશનું ચોક્કસ ચિત્રણ અત્યંત જરૂરી છે કારણ કે શિરોબિંદુ પદ્ધતિ તેના પર આધારિત છે.

શિરોબિંદુ (Corner Point) પદ્ધતિ

જ્યારે નિયત પ્રદેશ બંધ અને બહુકોણાકાર હોય, ત્યારે લક્ષ્યિત ફલન Z = px + qy નું મહત્તમ અથવા ન્યૂનતમ મૂલ્ય કોઈએક શિરોબિંદુ (corner point) પર મળે છે. શિરોબિંદુ એટલે બહુકોણના શીર્ષબિંદુઓ. આ પદ્ધતિમાં પહેલા નિયત પ્રદેશ દોરી તેના બધા શિરોબિંદુઓ શોધવા, પછી દરેક શિરોબિંદુ પર Z ની કિંમત મેળવવી અને તેમાંથી મહત્તમ/ન્યૂનતમ પસંદ કરવું. આ પ્રક્રિયા સરળ અને ચોકસાઈપૂર્વક લાગુ પાડી શકાય છે. જો નિયત પ્રદેશ અબંધ (unbounded) હોય તો આધારભૂત ચોકસાઈ જાળવવી જરૂરી છે.

મહત્તમીકરણ અને ન્યૂનતમીકરણ

રીખીય પ્રોગ્રામિંગમાં મુખ્યત્વે બે પ્રકારના પ્રશ્નો આવે છે — લક્ષ્યિત ફલનને મહત્તમ કરવું અથવા ન્યૂનતમ કરવું. મહત્તમ પ્રકરણમાં ખર્ચ ઓછો કરવો, લાભ વધારવો, સમય બચાવવો જેવા પ્રશ્નો હોય છે. ન્યૂનતમ પ્રકરણમાં વૃદ્ધિ ખર્ચ ઓછો કરવો, પ્રવાસ સમય ઘટાડવો, પોષક તત્વોની ઓછી મર્યાદા પૂરી કરવી જેવા પ્રશ્નો આવે છે. શિરોબિંદુઓ પર Z ની કિંમતો મેળવ્યા પછી, મહત્તમ પ્રકરણમાં સૌથી મોટી કિંમત અને ન્યૂનતમ પ્રકરણમાં સૌથી નાની કિંમત પસંદ કરવામાં આવે છે.

અનિયત નિયત પ્રદેશ અને ચકાસણી

જ્યારે નિયત પ્રદેશ અનંત (unbounded) હોય છે, ત્યારે મહત્તમ અથવા ન્યૂનતમ મૂલ્ય ન હોઈ શકે. આવા પ્રકરણોમાં શિરોબિંદુ પદ્ધતિ વડે પસંદ કરેલી કિંમત નક્કી કરવા માટે ચકાસણી જરૂરી છે. ઉદાહરણ તરીકે, મહત્તમ મૂલ્ય શોધતી વેળા, Z = ax + by > k અસમતાનો ઉકેલ પ્રદેશ સાથે ખાલી હોય કે નહીં તે જોવું પડે. એ જ પ્રમાણે ન્યૂનતમ પ્રકરણમાં Z = ax + by < k નો ઉકેલ પ્રદેશ સાથે ખાલી હોય છે કે કેમ તે પರಿક્ષા કરવી પડે. આ ચકાસણી વગર ઉકેલ અધૂરો રહી શકે છે.

રીખીય પ્રોગ્રામિંગનાં વાસ્તવિક ઉદાહરણો

રીખીય પ્રોગ્રામિંગની વ્યાપક ક્ષેત્રમાં વાસ્તવિક ઉપયોગો છે. ખેતીમાં ઝાડી અને પશુધન માટે ખર્ચ ઓછો કરી પોષણ મેળવવા, કારખાનામાં બે પ્રકારના ઉત્પાદનોનું નિર્માણ માત્રા સાથે મહત્તમ લાભ મેળવવો, ખર્ચ નક્કી કરી સમય બચાવવો, મિશ્રણ (mixture) પ્રકારના પ્રશ્નોમાં ભાગ્ય માપન, ઉત્પાદન યોજના બનાવવી વગેરે. આમાં દરેક પ્રશ્નને રીખીય બંધનો અને લક્ષ્યિત ફલનના રૂપમાં રજૂ કરી ગ્રાફિક પદ્ધતિ અથવા શિરોબિંદુ પદ્ધતિ વડે ઉકેલવામાં આવે છે. આ પ્રક્રિયાથી વ્યવહારુ નિર્ણયો વધુ ચોકસાઈ સાથે લઈ શકાય છે.

બહુ-ચલ અને અનુપાત પ્રકારના પ્રશ્નો

કેટલાક પ્રશ્નોમાં ત્રણ અથવા વધુ ચલો હોઈ શકે છે, પરંતુ GUJCET માં મુખ્યત્વે બે ચલો wala પ્રશ્નો આવે છે. આવી સમસ્યાઓમાં બંધનો વધુ હોય છે અને તે બધા ગ્રાફ પર દોરવા પડે છે. ઉદાહરણ તરીકે, બે કંપનીઓના ઉત્પાદનો માટે કાચમલ, મજૂરિયાત, સમય, પુરવઠો વગેરેના બંધનો હોઈ શકે છે. આ બધા બંધનોનો સાધારણ પ્રદેશ શોધી શિરોબિંદુઓ પર ફલન મૂકી મહત્તમ/ન્યૂનતમ મૂલ્ય મેળવવામાં આવે છે. જો બંધનોની સંખ્યા વધુ હોય તો ચિત્રણમાં ચોકસાઈ અને સાવધાની જરૂરી છે.

અવૈધ અને અનિશ્ચિત ઉકેલો

ઘણી વાર બંધનો વિરોધાભાસી હોય છે અને કોઈ પણ ઉકેલ પ્રદેશ બનતો નથી; આવી સ્થિતિમાં ઉકેલ અવૈધ (infeasible) ગણાય છે. કેટલીક વખત લક્ષ્યિત ફલનનું મહત્તમ અથવા ન્યૂનતમ મૂલ્ય નક્કી થઈ શકે નહીં, એટલે કે પ્રદેશ અનંત હોવાથી કિંમત નિયત નથી રહેતી. આવા પ્રકરણોમાં પ્રશ્નકર્તા ચોક્કસપણે પૂછે છે કે ઉકેલ અસ્તિત્વ ધરાવે છે કે કેમ. વિદ્યાર્થીએ ઉકેલ પ્રદેશ ખાલી હોય તો 'અવૈધ' અને મૂલ્ય નિયત ન હોય તો 'અનિશ્ચિત' એમ જવાબ આપવો જોઈએ. આ મુદ્દા ગૂઢ સમજણ માટે અત્યંત મહત્વના છે.

⚡ સૂત્રો

Z = px + qy (લક્ષ્યિત ફલન, objective function)
ax + by ≤ c (અસમતા બંધન)
ax + by ≥ c (અસમતા બંધન)
x ≥ 0, y ≥ 0 (ઋણ સંખ્યા ન હોવાના બંધનો)

⭐ મહત્વના મુદ્દા

  • નીચે મર્યાદિત બંધ પ્રદેશ હોય તો મહત્તમ/ન્યૂનતમ કિંમત શિરોબિંદુ પર મળે છે.
  • શિરોબિંદુ પદ્ધતિ માત્ર બે ચલો ધરાવતી સમસ્યાઓ માટે લાગુ પડે છે.
  • અનંત પ્રદેશમાં મહત્તમ/ન્યૂનતમ મૂલ્યની ચકાસણી જરૂરી છે.
  • ઉકેલ પ્રદેશ ખાલી હોય તો પ્રશ્ન અવૈધ (infeasible) છે.
  • પ્રથમ ચરણ (first quadrant) માં દરેક ઉકેલ x ≥ 0, y ≥ 0 શરતો પૂરી કરે છે.

⚠️ સામાન્ય ભૂલો

અસમતાનો ઉકેલ પ્રદેશ સાચી દિશામાં ચિત્રિત કરવાને બદલે ઉલટો ચિત્રણ કરવો.
શિરોબિંદુઓ શોધતી વેળા રેખાઓના છેદનબિંદુઓને બદલે અન્ય બિંદુઓ ધ્યાનમાં લેવા.
અનંત પ્રદેશમાં ચકાસણી કર્યા વિના મહત્તમ/ન્યૂનતમ દાવો કરવો.
ઋણ ચલોને અનુમતિ આપવી, જ્યારે x ≥ 0, y ≥ 0 હોય.

🎯 પરીક્ષા ટિપ્સ

ગ્રાફિક સમસ્યાઓમાં પ્રદેશ ચોકસાઈથી દોરો, યામ (axes) અને એકમો નક્કી કરો.
બધા બંધનોનો યાદી બનાવી દરેક રેખા માટે બે બિંદુઓ શોધી ગ્રાફ પર દોરો.
શિરોબિંદુઓ શોધવા માટે બે રેખા સમીકરણોને સામાન્ય રીતે ઉકેલો.
અનંત પ્રદેશમાં ચકાસણી ફરજિયાત કરો, અ otherwise ખોટો જવાબ મળી શકે.
Z ની કિંમતોનું કોષ્ટક બનાવી મહત્તમ/ન્યૂનતમ સ્પષ્ટ રીતે દર્શાવો.

📌 સારાંશ

રીખીય પ્રોગ્રામિંગ એ એક શક્તિશાળી ગાણિતિક સાધન છે જે લક્ષ્યિત ફલનને બંધનો હેઠળ મહત્તમ અથવા ન્યૂનતમ કરે છે. બે ચલો ધરાવતી સમસ્યાઓ માટે ગ્રાફિક પદ્ધતિ અને શિરોબિંદુ પદ્ધતિ અત્યંત ઉપયોગી છે. નિયત પ્રદેશ, શિરોબિંદુઓ, મહત્તમ/ન્યૂનતમ કિંમતો અને અનંત પ્રદેશ ચકાસણી સહિતના મુદ્દાઓ સારી રીતે સમજવાથી વિદ્યાર્થીઓ વાસ્તવિક જીવનની સમસ્યાઓને સહેલાઈથી ગાણિતિક રૂપ આપી ઉકેલી શકે છે. ચોકસાઈ, યોગ્ય ચિત્રણ અને અનુશીલન આ અધ્યાય માટે મહત્વનું છે.
