રેખીય કાર્યક્રમનન (Linear Programming) — ઝડપી પુનરાવર્તન

🧪 GUJCET — Gujarati • Mathematics • Linear Programming

🧠 યાદ રાખો

રેખીય અસમતા (Linear Inequality) નો આલેખ દોરવા માટે, પ્રથમ સંબંધિત રેખા (Constraint Line) દોરીએ, છીન્ટરપોઈન્ટ્સ શોધીએ અને પછી અસમતાની દિશા અનુસાર અર્ધ-તલ (Half-plane) રંગીએ.
પૂર્ણ સમાધાન વિસ્તાર (Feasible Region) એ બધી જ અવરોધક રેખાઓના સકારાત્મક અર્ધ-તલોનો છેદ છે. તે હંમેશા બહુકોણ (Convex Polygon) હોય છે અથવા અસીમિત વિસ્તાર હોઈ શકે.
ખડગત બિંદુ (Corner Point / Vertex) એ પૂર્ણ સમાધાન વિસ્તારની રેખાખંડોના છેદબિંદુઓ છે. ઉચ્ચતમ/નીચ્ચમ મૂલ્ય માત્ર આ ખડગત બિંદુઓ પર જ મળે છે (કોઈ પણ અંદરના બિંદુ પર નહીં).
ચલો x ≥ 0 અને y ≥ 0 હોવા જોઈએ — આને 'અૃભિસામિક બંધન' (Non-negativity Constraints) કહે છે, કારણ કે વાસ્તવિક ધન (Physical) પ્રશ્નોમાં ઋણ મૂલ્યો અશક્ય હોય છે.
લક્ષ્ય ફલન (Objective Function) Z = ax + by નું મૂલ્ય પૂર્ણ સમાધાન વિસ્તારના દરેક ખડગત બિંદુએ ગણીએ. Z નું મહત્તમ અને લઘુત્તમ મૂલ્ય એ બે ખડગત બિંદુઓ પર જ મળશે (જ્યાં સુધી વિસ્તાર અસીમિત ન હોય ત્યાં સુધી).

⚡ ઝડપી સૂત્રો

લક્ષ્ય ફલન: Z = ax + by (જ્યાં Z ને મહત્તમ અથવા લઘુત્તમ કરવાનું હોય છે)
અવરોધક સમીકરણની ય-અક્ષ છેદ: (0, c/b) અને x-અક્ષ છેદ: (c/a, 0) — આ બે બિંદુઓ પરથી રેખા દોરવામાં આવે છે.
ખડગત બિંદુ શોધવા માટે બે અવરોધક રેખાઓને સામાન્ય છેદ બિંદુ માટે સમીકરણો ઉકેલીએ: R₁ = p, R₂ = q

✅ વન-લાઈનર્સ

પૂર્ણ સમાધાન વિસ્તાર બંધ (Closed) હોય તો Z નું મહત્તમ અને લઘુત્તમ બંને મળે; ખુલ્લો (Unbounded) વિસ્તાર હોય તો દરેક ખડગત બિંદુએ ગણતરી કરીએ અને જાંચીએ કે શું મળતું મૂલ્ય પર્યાપ્ત છે.
અસમતા 3x + 4y ≤ 60 ની દિશા શોધવા માટે ઉગમબિંદુ (0,0) ને તપાસો: 0 ≤ 60 સત્ય છે → માટે ઉગમબિંદુ ધરાવતો અર્ધતલ લઈએ.
જો Z નું મહત્તમ મૂલ્ય એક કરતાં વધુ ખડગત બિંદુએ મળે, તો તે બે ખડગત બિંદુઓને જોડતી રેખાખંડ પરના સૌથી બિંદુઓ પણ મહત્તમ સમાધાન આપે છે.
પ્રશ્નમાં 'તેલ' અથવા 'પ્રોટીન' જેવી ચોક્કસ આહાર આવશ્યક્તા આપવામાં આવે ત્યારે તે રેખા ઘણીવાર અવરોધક રેખા તરીકે કામ કરે છે અને ખડગત બિંદુઓ આથી મળે છે.
