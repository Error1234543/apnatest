રેખીય પ્રોગ્રામિંગ (Linear Programming)

🧪 GUJCET — Gujarati • Mathematics • Linear Programming

રેખીય પ્રોગ્રામિંગ – પ્રસ્તાવના
રેખીય પ્રોગ્રામિંગ એ ગાણિતિક આપણાત્મક પદ્ધતિ છે જેમાં આપણે કોઈ પણ ઉદ્દેશ્ય વિધેયને મહત્તમ અથવા લઘુત્તમ કરવાનું હોય છે.
આ પદ્ધતિનો ઉપયોગ ઉત્પાદન, વહન, નાણાકીય યોજના, સંસાધન વહેંચણી વગેરે ક્ષેત્રોમાં થાય છે.
રેખીય પ્રોગ્રામિંગમાં બધી જ શરતો રેખીય (Linear) હોય છે – એટલે કે ચલોની ઘાત 1 હોય.
Z = ax + by (ઉદ્દેશ્ય વિધેય)
📝 GUJCET માં ગ્રાફિકલ પદ્ધતિ પર ધ્યાન આપો.
રેખીય પ્રોગ્રામિંગની ગાણિતિક રચના
રેખીય પ્રોગ્રામિંગ સમસ્યાને ત્રણ ભાગોમાં વહેંચી શકાય: નિર્ણય ચલો, ઉદ્દેશ્ય વિધેય અને અવરોધો.
નિર્ણય ચલો (Decision Variables) એવા ચલો છે જે આપણે નક્કી કરવાના હોય છે, સામાન્યતઃ x અને y.
ઉદ્દેશ્ય વિધેય (Objective Function) એ રેખીય સમીકરણ છે જેને આપણે મહત્તમ અથવા લઘુત્તમ કરવું હોય છે.
અવરોધો (Constraints) એ અસમતાઓ અથવા સમીકરણો છે જે નિર્ણય ચલો પર લાગુ પડે છે.
અવરોધો: px + qy ≤ r અથવા px + qy ≥ r
અનૃણતા શરતો: x ≥ 0, y ≥ 0
📝 અનૃણતા શરતો ભૂલશો નહીં – તે અવિભાજ્ય છે.
નિર્ણય ચલોઉદ્દેશ્ય વિધેયમાં મૂકીને મૂલ્ય શોધો
રેખીય અસમતાઓનું ગ્રાફિકલ સ્વરૂપ
રેખીય અસમતાને ગ્રાફ પર દર્શાવવા માટે પહેલા સંબંધિત રેખીય સમીકરણની રેખા દોરો.
રેખા દોરતી વખતે, જો અસમતા ≤ અથવા ≥ હોય તો રેખા ભરેલી (solid) દોરો; જો < અથવા > હોય તો ખાલી (dashed) દોરો.
રેખાની કોઈ એક બાજુએ એક પરીક્ષણ બિંદુ (સામાન્યતઃ મૂળબિંદુ (0,0)) લઈને તપાસો કે અસમતા સંતોષાય છે કે નહીં.
જો પરીક્ષણ બિંદુ અસમતા સંતોષે, તો તે બિંદુ ધરાવતી અર્ધસમતલ (half-plane) રંગો.
રેખા: ax + by = c
📝 પરીક્ષણ બિંદુ તરીકે (0,0) લેવું સરળ છે, પરંતુ જો રેખા મૂળબિંદુમાંથી પસાર થતી હોય તો બીજું બિંદુ લો.
રેખીય સમીકરણરેખા દોરો
અસમતા ચિહ્નરેખાનો પ્રકાર નક્કી કરો
સંભવ્ય ક્ષેત્ર (Feasible Region)
બધા અવરોધોને સંતોષતા બિંદુઓનો સમૂહ સંભવ્ય ક્ષેત્ર કહેવાય છે.
સંભવ્ય ક્ષેત્ર હંમેશા એક બહુભુજ (polygon) હોય છે, જે રેખીય અસમતાઓની અર્ધસમતલોના છેદનથી બને છે.
જો સંભવ્ય ક્ષેત્ર ખાલી હોય, તો સમસ્યાનો કોઈ ઉકેલ નથી.
સંભવ્ય ક્ષેત્ર સીમિત (bounded) અથવા અસીમિત (unbounded) હોઈ શકે છે.
📝 સંભવ્ય ક્ષેત્ર શોધવું જ રેખીય પ્રોગ્રામિંગનું મુખ્ય પગલું છે.
દરેક અવરોધઅર્ધસમતલ
બધી અર્ધસમતલોનું છેદનસંભવ્ય ક્ષેત્ર
શિરોબિંદુ (Corner Point) પદ્ધતિ
સીમિત સંભવ્ય ક્ષેત્ર માટે, ઉદ્દેશ્ય વિધેયનું મહત્તમ અથવા લઘુત્તમ મૂલ્ય કોઈ પણ શિરોબિંદુ પર મળે છે.
શિરોબિંદુઓ એ સંભવ્ય ક્ષેત્રના બહુભુજના શિરોબિંદુઓ છે, જે અવરોધ રેખાઓના છેદનબિંદુઓ હોય છે.
પદ્ધતિ: શિરોબિંદુઓ શોધો → દરેક શિરોબિંદુ પર ઉદ્દેશ્ય વિધેયનું મૂલ્ય શોધો → મહત્તમ/લઘુત્તમ મૂલ્ય નક્કી કરો.
Z = ax + by ને દરેક શિરોબિંદુ (x, y) પર મૂકો.
📝 શિરોબિંદુ શોધવા માટે અવરોધ સમીકરણોનો જોડીવાર ઉકેલ કાઢો.
અવરોધ રેખાઓછેદનબિંદુઓ (શિરોબિંદુઓ)
મહત્તમીકરણ અને લઘુત્તમીકરણ
જો ઉદ્દેશ્ય વિધેય Z = ax + by નું મહત્તમ મૂલ્ય શોધવું હોય, તો શિરોબિંદુઓ પરના મૂલ્યોમાં સૌથી મોટું મૂલ્ય લો.
જો લઘુત્તમ મૂલ્ય શોધવું હોય, તો સૌથી નાનું મૂલ્ય લો.
સીમિત સંભવ્ય ક્ષેત્ર માટે મહત્તમ અને લઘુત્તમ બંને મૂલ્યો શિરોબિંદુઓ પર જ મળે છે.
Z_max = max { Z(શિરોબિંદુ) }
Z_min = min { Z(શિરોબિંદુ) }
📝 પ્રશ્નમાં મહત્તમ કે લઘુત્તમ પૂછેલું છે તે ધ્યાનથી વાંચો.
અસીમિત સંભવ્ય ક્ષેત્ર (Unbounded Feasible Region)
જ્યારે સંભવ્ય ક્ષેત્ર અસીમિત હોય, ત્યારે મહત્તમ અથવા લઘુત્તમ મૂલ્ય શિરોબિંદુ પર ન મળે તેવી શક્યતા હોય છે.
મહત્તમ મૂલ્ય માટે: શિરોબિંદુઓ પર મળતું મહત્તમ મૂલ્ય Z_max લો. પછી તપાસો કે અસમતા ax + by > Z_max સંભવ્ય ક્ષેત્ર સાથે છેદે છે કે નહીં.
જો ax + by > Z_max સંભવ્ય ક્ષેત્રને છેદતી હોય, તો મહત્તમ મૂલ્ય અસ્તિત્વમાં નથી (unbounded).
લઘુત્તમ મૂલ્ય માટે: શિરોબિંદુઓ પર મળતું લઘુત્તમ મૂલ્ય Z_min લો. તપાસો કે ax + by < Z_min સંભવ્ય ક્ષેત્રને છેદે છે કે નહીં.
📝 અસીમિત ક્ષેત્ર માટે ઉકેલ અસ્તિત્વમાં ન હોઈ શકે.
શિરોબિંદુ મૂલ્યઅસમતા તપાસો
બહુવિધ આદર્શ ઉકેલ (Multiple Optimal Solutions)
જો ઉદ્દેશ્ય વિધેયની રેખા કોઈ એક અવરોધ રેખાને સમાંતર હોય, તો બહુવિધ આદર્શ ઉકેલ મળી શકે છે.
આવી સ્થિતિમાં, ઉદ્દેશ્ય વિધેયનું આદર્શ મૂલ્ય એકથી વધુ શિરોબિંદુઓ પર સમાન મળે છે.
જો બે શિરોબિંદુઓ પર સમાન મૂલ્ય મળે, તો તે બે શિરોબિંદુઓને જોડતી રેખાખંડ પરના દરેક બિંદુઓ આદર્શ ઉકેલ હોય છે.
Z = ax + by અને px + qy = r સમાંતર હોય તો a/p = b/q.
📝 બહુવિધ ઉકેલની શક્યતા તપાસવા માટે ઢાળ (slope) સરખાવો.
રેખીય પ્રોગ્રામિંગની પરિકલ્પનાઓ
રેખીયતા: ઉદ્દેશ્ય વિધેય અને અવરોધો રેખીય હોવા જોઈએ.
સમગ્રતા (Certainty): બધા જ ગુણાંકો અને સંસાધનો નિશ્ચિત અને જાણીતા હોય છે.
વિભાજ્યતા (Divisibility): નિર્ણય ચલો પૂર્ણાંક હોવા જરૂરી નથી; તે ભિન્ન પણ હોઈ શકે છે.
અનૃણતા: નિર્ણય ચલો ઋણ ન હોઈ શકે (x ≥ 0, y ≥ 0).
📝 પરિકલ્પનાઓની સમજ પરીક્ષામાં સિદ્ધાંત પ્રશ્નો માટે મદદરૂપ થાય છે.
ઉદાહરણ: મહત્તમીકરણ સમસ્યા
ઉદાહરણ: Z = 3x + 5y નું મહત્તમ મૂલ્ય શોધો, જ્યાં અવરોધો છે: x + y ≤ 4, x ≥ 0, y ≥ 0.
અવરોધો દોરીને સંભવ્ય ક્ષેત્ર બનાવો. શિરોબિંદુઓ: (0,0), (4,0), (0,4).
દરેક શિરોબિંદુ પર Z નું મૂલ્ય: (0,0) → 0, (4,0) → 12, (0,4) → 20.
મહત્તમ મૂલ્ય Z = 20 બિંદુ (0,4) પર મળે છે.
Z(0,4) = 3(0) + 5(4) = 20
📝 ઉદાહરણોની વારંવાર પ્રેક્ટિસ કરો.
ઉદાહરણ: લઘુત્તમીકરણ સમસ્યા
ઉદાહરણ: Z = 2x + 3y નું લઘુત્તમ મૂલ્ય શોધો, જ્યાં અવરોધો: x + y ≥ 2, x ≥ 0, y ≥ 0.
સંભવ્ય ક્ષેત્ર અસીમિત છે. શિરોબિંદુઓ: (2,0), (0,2).
Z(2,0) = 4, Z(0,2) = 6. લઘુત્તમ મૂલ્ય 4 છે.
અસીમિત ક્ષેત્ર હોવા છતાં, લઘુત્તમ મૂલ્ય શિરોબિંદુ પર મળે છે.
Z_min = 4 at (2,0)
📝 લઘુત્તમ માટે પણ શિરોબિંદુ પદ્ધતિ લાગુ પડે છે.
રેખીય પ્રોગ્રામિંગના ઉપયોગ
ઉત્પાદન યોજન: મહત્તમ લાભ કે લઘુત્તમ ખર્ચ.
પોષણ યોજન: ન્યૂનતમ ખર્ચે પોષક તત્વોની જરૂરિયાત પૂરી કરવી.
વહન સમસ્યા: ન્યૂનતમ ખર્ચે માલની પહોંચાડણી.
રેખીય પ્રોગ્રામિંગ વ્યવસાયિક અને આર્થિક નિર્ણયોમાં મદદરૂપ છે.
📝 GUJCET માં ઉપયોગિતાના પ્રશ્નો પણ આવે છે.
મહત્વના નિયમો અને ટિપ્સ
ગ્રાફ દોરતી વખતે અક્ષોનું પ્રમાણ યોગ્ય રાખો.
અવરોધ રેખાઓના છેદનબિંદુઓ શોધવા માટે સમીકરણોનો જોડીવાર ઉકેલ કાઢો.
શિરોબિંદુઓની યાદી બનાવતી વખતે અનૃણતા શરતો ધ્યાનમાં લો.
ઉદ્દેશ્ય વિધેયનું મૂલ્ય શિરોબિંદુઓ પર જ તપાસો, મધ્યબિંદુઓ પર નહીં.
ઢાળ = -a/b (રેખા ax + by = c માટે)
📝 ઢાળ સરખાવવાથી બહુવિધ ઉકેલની શક્યતા તપાસી શકાય.
પરીક્ષા માટે વિશેષ ટિપ્સ
પ્રશ્ન પૂરો વાંચો: મહત્તમ કે લઘુત્તમ?
અવરોધોમાં ≤ અથવા ≥ ચિહ્ન ધ્યાનથી લો.
ગ્રાફિકલ પદ્ધતિ માત્ર બે ચલો સુધી મર્યાદિત છે.
સમય વ્યય ઘટાડવા માટે શિરોબિંદુઓની ગણતરી સીધી કરો.
📝 પાઠ્યપુસ્તકના ઉદાહરણો અને અભ્યાસપ્રશ્નો ફરીથી કરો.
સારાંશ
રેખીય પ્રોગ્રામિંગ એ સંસાધન વિતરણની આપણાત્મક પદ્ધતિ છે.
ગ્રાફિકલ પદ્ધતિ દ્વારા બે ચલો સુધીની સમસ્યાઓનો ઉકેલ મળે છે.
સંભવ્ય ક્ષેત્રના શિરોબિંદુઓ પર ઉદ્દેશ્ય વિધેયનું મૂલ્ય તપાસીને આદર્શ ઉકેલ મળે છે.
અસીમિત ક્ષેત્રમાં ઉકેલ અસ્તિત્વમાં ન હોઈ શકે.
આદર્શ ઉકેલ → શિરોબિંદુ પર અથવા રેખાખંડ પર.
📝 રેખીય પ્રોગ્રામિંગ ગણિત અને અર્થશાસ્ત્ર બંનેમાં મહત્વપૂર્ણ છે.
