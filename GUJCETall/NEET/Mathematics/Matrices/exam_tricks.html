માતૃકા -- ગુજરાતી માધ્યમ GUJCET એક્ઝામ ટ્રિક્સ

🧪 GUJCET — Gujarati • Mathematics • Matrices

🎯 પરીક્ષા ટ્રિક્સ

માતૃકાનો ગુણધર્મ A + Aᵀ હંમેશા સંમિત (Symmetric) માતૃકા આપે છે. જો વિકલ્પોમાં કોઈ એવી માતૃકા હોય કે જેને ક્રોસ-ચોકડાના અવયવો સરખા ન હોય, તે તરત અપાત્ય છે.
જ્યારે પ્રશ્નમાં A + Aᵀ અથવા A - Aᵀ શોધવાનું હોય અને વિકલ્પો મોટા હોય.
દા.ત.: જો A = [[1,2],[3,4]] તો A + Aᵀ = [[2,5],[5,8]] → ઉપર-દાहिना અને નીચે-બાયું બંને 5 (સરખા).
કોઈ પણ ચોરસ માતૃકા A માટે, A - Aᵀ હંમેશા એક શૂન્ય-વિકર્ણ (Skew-Symmetric / વિષમ-સંમિત) માતૃકા આપે છે: વિકર્ણ પર 0 અને aᵢⱼ = –aⱼᵢ. આ ગુણધર્મનો ઉપયોગ કરીને ખોટા વિકલ્પો તરત બાદ કરી શકાય.
જ્યારે પ્રશ્નમાં વિષમ-સંમિતતા (Skew-symmetry) માંગવામાં આવે અથવા A – Aᵀ ની ગણતરી હોય.
દા.ત.: A = [[1,3],[5,2]] → A – Aᵀ = [[0,-2],[2,0]]. વિકર્ણના મૂલ્યો 0 છે → સાચો જવાબ તરત ઓળખી શકાય.
કોઈ પણ માતૃકા A ને સંમિત + વિષમ-સંમિત રૂપે લખી શકાય: A = ½(A+Aᵀ) + ½(A–Aᵀ). આ ફોર્મ્યુલાની મદદથી જટિલ દાખલાઓના વિકલ્પો ચકાસી શકાય.
જ્યારે પ્રશ્નમાં માતૃકાના વિભાજન વિશે પૂછવામાં આવે અથવા સંમિત/વિષમ-સંમિત ભાગ શોધવાના હોય.
દા.ત.: A = [[2,5],[3,1]] → ½(A+Aᵀ) = [[2,4],[4,2]] (સંમિત), ½(A–Aᵀ) = [[0,1],[-1,0]] (વિષમ-સંમિત).
દ્વિકલની (Determinant) શૂન્ય તપાસ: જો માતૃકાની બે પંક્તિઓ અથવા બે સ્તંભો સરખા હોય, તો |A| = 0. આ ગુણધર્મ થિક-ટ્રાઉબલથી જવાબ પસંદ કરવામાં મદદરૂપ છે.
જ્યારે શૂન્ય માતૃકા (Zero Matrix) નીચેનો પ્રશ્ન આવે અથવા કોઈ ચોક્કસ પંક્તિ/સ્તંભ સમાનતા દેખાય.
દા.ત.: જો P = [[3,6],[1,2]], તો પંક્તિ 1 = 3×પંક્તિ 2 → |P| = 0.
ઇન્વર્ટ ન હોય તેવી (Singular) માતૃકા માટે det(A) = 0. વિકલ્પોમાં k નું મૂલ્ય શોધવાનું હોય, તો શૂન્ય વિના બધા વિકલ્પો પર |A| મૂકીને તપાસો — જે k માટે |A|=0 આવે તે જ સાચો જવાબ.
જ્યારે કોઈ પરિમાણ k માટે માતૃકા non-invertible (singular) હોય તેવો પ્રશ્ન હોય.
દા.ત.: A = [[k,2],[k,k]] → |A| = k²–2k = 0 → k(k–2)=0 → k=0 અથવા k=2.
આઇડેન્ટિટી માતૃકા (Identity Matrix) I માટે: AI = IA = A અને Iⁿ = I. જો કોઈ વિકલ્પમાં આ ગુણધર્મનો વિરોધ થતો જણાય, તે વિકલ્પ તરત અપાત્ય ગણો.
જ્યારે માતૃકા ગુણાકારમાં Identity નો ઉપયોગ થતો હોય અથવા દાવો કર્યો હોય કે某个 matrix એ identity પ્રકારનું કામ કરે છે.
દા.ત.: જો B = [[1,0],[0,1]] તો AB = A. જો કોઈ વિકલ્પ કહે કે AB ≠ A, તો તે ખોટો છે.
માતૃકાના વિકર્ણની જેમ જ, trace(A) = a₁₁ + a₂₂ + ... + aₙₙ. બે માતૃકાના ગુણાકાર માટે trace(AB) = trace(BA) હોય છે — આનો ઉપયોગ કરીને લાંબા ગુણાકાર વિના trace શોધી શકાય.
જ્યારે પ્રશ્નમાં trace(AB) અથવા trace(BA) શોધવાનું હોય, ખાસ કરીને 3×3 અથવા તેથી મોટી માતૃકા.
દા.ત.: A = [[1,2],[3,4]], B = [[5,6],[7,8]] → trace(AB) = trace(BA) = 53. સીધો ગુણાકાર કરવો પડશે નહીં.
કોઈ પણ n×n માતૃકા A માટે |kA| = kⁿ|A|. આ ગુણધર્મનો ઉપયોગ કરીને ખોટા વિકલ્પો તરત બાદ કરી શકાય, ખાસ કરીને જ્યારે |2A|, |3A| જેવા પ્રશ્ન આવે.
જ્યારે scalar દ્વારા માતૃકા ગુણીને determinant શોધવાનો પ્રશ્ન હોય.
દા.ત.: જો |A| = 5 અને A 3×3 હોય, તો |2A| = 2³ × 5 = 8 × 5 = 40.
(AB)⁻¹ = B⁻¹A⁻¹ (ક્રમ ઉલટો!). GUJCET માં ઘણા પ્રશ્ન આ જ ખોટો ક્રમ બતાવીને વિકલ્પમાં આપે છે. B⁻¹A⁻¹ ને યાદ રાખો: 'Shoe Sock Rule' — જૂતા પહેરીએ છીએ (A), પછી મोजа (B); ઊતારતી વખતે B⁻¹ પહેલાં, પછી A⁻¹.
જ્યારે (AB)⁻¹ અથવા (AB)ᵀ શોધવાનું હોય.
દા.ત.: જો A,B invertible હોય, તો (AB)⁻¹ = B⁻¹A⁻¹. વિકલ્પ A⁻¹B⁻¹ હોય તો તે ખોટો છે.
(AB)ᵀ = BᵀAᵀ — ગુણાકારનો ક્રમ ઉલટાય છે. જો પ્રશ્નમાં transpose નો ક્રમ પૂછે, તો BᵀAᵀ જ સાચો છે. આ ગુણધર્મ યાદ રાખવો ખૂબ જરૂરી છે.
જ્યારે પ્રશ્નમાં (AB)ᵀ અથવા (ABC)ᵀ જેવો પ્રશ્ન આવે.
દા.ત.: A = [[1,2],[3,4]], B = [[0,1],[1,0]] → (AB)ᵀ = BᵀAᵀ = [[0,1],[1,0]][[1,3],[2,4]] = [[2,4],[1,3]].
જો માતૃકા મોટી (3×3 અથવા વધુ) હોય અને શૂન્ય વિકલ્પોમાંથી કોઈક વિકલ્પ તપાસવાનો હોય, તો specific values (જેમ કે x=0, x=1) મૂકીને ચકાસો — આ 'Elimination by Substitution' ટ્રિક GUJCET માં ખૂબ કામનાર છે.
જ્યારે પ્રશ્નમાં કોઈ પરિમાણ (parameter) માટે માતૃકા ગુણધર્મ સાચો હોય તેવો પ્રશ્ન હોય.
દા.ત.: જો A = [[1,x],[x,1]] અને A² = [[2,2x],[2x,2]] હોય તો x=1 મૂકીને ચકાસો: A²=[[2,2],[2,2]] ✓.
પ્રતિચાબિક (Adjoint) અને ઇન્વર્સ વચ્ચેનો સંબંધ: A⁻¹ = adj(A)/|A|. જો |A| = 0 હોય, તો A⁻¹ અસ્તિત્વ ધરાવતું નથી — આ ખ્યાલથી non-invertible માતૃકા સંબંધી પ્રશ્નો તરત ઉકેલી શકાય.
જ્યારે પ્રશ્નમાં એડજોઈન્ટ અથવા ઇન્વર્સ અસ્તિત્વ ધરાવે છે કે કેમ તે પૂછવામાં આવે.
દા.ત.: જો |A| = 0, તો A⁻¹ exist કરતું નથી. વિકલ્પોમાં A⁻¹ = K આપેલ હોય તો તે ખોટો છે.
દ્વિકલની શૂન્ય (Zero Matrix) O માટે: AO = OA = O અને O + A = A. જો કોઈ વિકલ્પમાં દાવો કર્યો હોય કે O અથવા IA = A ≠ A, તો તે ખોટો છે.
જ્યારે પ્રશ્નમાં Zero Matrix સાથે સંબંધિત ગુણધર્મો પૂછવામાં આવે.
દા.ત.: O = [[0,0],[0,0]] → IO = O, IO = O. જો કોઈ વિકલ્પ કહે IO = I, તો તે ખોટો છે.
જ્યારે સમીકરણોનું સિસ્ટમ MA = B સ્વરૂપમાં હોય, તો A = M⁻¹B નો ઉપયોગ કરીને જવાબ શોધી શકાય — પરંતુ GUJCET માં 2×2 માતૃકાના ઇન્વર્સનું સૂત્ર yaad rakhvo: A⁻¹ = (1/|A|)[[d,–b],[-c,a]].
જ્યારે પ્રશ્નમાં માતૃકા સમીકરણ મુકાવવાનું અથવા અજ્ઞાત માતૃકા શોધવાનું હોય.
દા.ત.: જો [[2,1],[1,3]]·A = [[5,7],[2,4]], તો A = [[2,-1],[-1,2]]·[[5,7],[2,4]] = [[8,9],[1,2]].
માતૃકાનો અનંત પાવર (Matrix power) શોધવામાં જો કોઈ મેટ્રિક્સ A નો ગુણધર્મ A² = A (Idempotent) હોય, તો Aⁿ = A હંમેશા. આથી વિકલ્પોમાં A²=A હોય તો A¹⁰₀ પણ A જ થાય.
જ્યારે પ્રશ્નમાં Aⁿ, n→∞ જેવો પ્રશ્ન આવે અથવા Idempotent Matrix નો ગુણધર્મ પૂછવામાં આવે.
દા.ત.: A = [[1,0],[1,0]] → A² = [[1,0],[1,0]] = A. તેથી A¹⁰⁰ = A = [[1,0],[1,0]].
