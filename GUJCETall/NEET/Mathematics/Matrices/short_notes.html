મ્યાટ્રિસ (Matrices) — ઝડપી સમીક્ષા નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Matrices

📘 વ્યાખ્યાઓ

  • મ્યાટ્રિસ: r રો અને n સ્તંભ વાળી આયત્યાકાર ગોઠવણ rect(a[m×n])
  • શૂન્ય મ્યાટ્રિસ: જેના બધા જ ઉપાદનો શૂન્ય હોય, પ્રતીક O અથવા 0
  • કરણી મ્યાટ્રિસ: એક જ પંક્તિ ધરાવતી મ્યાટ્રિસ, ક્રમ 1×n
  • સ્તંભ મ્યાટ્રિસ: એક જ સ્તંભ ધરાવતી મ્યાટ્રિસ, ક્રમ m×1
  • વર્ગ મ્યાટ્રિસ: રો = સ્તંભ વાળી મ્યાટ્રિસ, ક્રમ n×n
  • અભિલક્ષણિક મ્યાટ્રિસ: વર્ગ મ્યાટ્રિસ જેમાં વિકર્ણ ઉપાદનો 1 અને બાકી બધા 0 હોય, I_n
  • સ્કેલર મ્યાટ્રિસ: વર્ગ મ્યાટ્રિસ જેમાં વિકર્ણના બધા ઉપાદનો સમાન k હોય અને બાકીના શૂન્ય હોય
  • વિકર્ણ મ્યાટ્રિસ: વર્ગ મ્યાટ્રિસ જેમાં વિકર્ણ સિવાયના બધા ઉપાદનો શૂન્ય હોય
  • ઉચ્ચ ત્રિકોણીય મ્યાટ્રિસ: a[ij] = 0 જ્યાં i > j
  • નીચ્ચ ત્રિકોણીય મ્યાટ્રિસ: a[ij] = 0 જ્યાં i < j
  • સંમિત મ્યાટ્રિસ: A^T = A, એટલે a[ji] = a[ij]
  • વિષમ-સંમિત મ્યાટ્રિસ: A^T = −A, દ્રષ્ટાંત તો વિકર્ણ ઉપાદનો શૂન્ય
  • સિંગ્યુલર મ્યાટ્રિસ: |A| = 0 વાળી વર્ગ મ્યાટ્રિસ, વ્યસ્ત અસ્તિત્વ ધરાવતી નથી
  • વ્યસ્ત મ્યાટ્રિસ: A·A^(-1) = A^(-1)·A = I

⚡ સૂત્રો

  • A^T: i,j ખાનાનો ઉપાદનો જ i,j ખાને ખસેડે → B[ij] = A[ji]
  • (A+B)^T = A^T + B^T
  • (kA)^T = k(A^T)
  • (AB)^T = B^T A^T
  • |kA| = k^n |A|, જ્યાં A નો ક્રમ n×n
  • |AB| = |A| · |B|
  • A · adj(A) = adj(A) · A = |A| · I
  • A^(-1) = adj(A) / |A|, જ્યાં |A| ≠ 0
  • (A^(-1))^T = (A^T)^(-1)
  • (AB)^(-1) = B^(-1) · A^(-1)
  • adj(kA) = k^(n−1) · adj(A), ક્રમ n×n
  • adj(adj(A)) = |A|^(n−2) · A
  • A · A^(-1) = I_n
  • બહુપદી સમીકરણ via Cayley–Hamilton: A^n + c₁A^(n−1) + ... + cₙI = 0
  • મ્યાટ્રિસ સમીકરણ ઉકેલ: X = A^(−1)B અથવા X = BA^(−1)

⭐ મુખ્ય તથ્યો

  • બે મ્યાટ્રિસનો સરવાળો માત્ર તેઓના ક્રમ સમાન હોય ત્યારે શક્ય
  • મ્યાટ્રિસ ગુણાકાર AB ત્યારે જ શક્ય કે જ્યારે A ના સ્તંભ = B ના રો, પરિણામનો ક્રમ (રો_A × સ્તંભ_B)
  • મ્યાટ્રિસ ગુણાકાર ક્રમપરવર્તી નથી: સામાન્ય રીતે AB ≠ BA
  • AB = 0 હોઈ શકે છે પરંતુ A ≠ 0 અને B ≠ 0
  • AB = AC હોય તો B = C લખી શકાતું નથી (જો |A| = 0 હોય તો)
  • A² = I હોય તો A એ અભિલાક્ષણિક અવયવિત (involutory) મ્યાટ્રિસ
  • A + A^T હંમેશા સંમિત અને A − A^T હંમેશા વિષમ-સંમિત
  • દરેક વર્ગ મ્યાટ્રિસને સંમિત અને વિષમ-સંમિતના સરવાળા તરીકે લખી શકાય: A = (A+A^T)/2 + (A−A^T)/2
  • વ્યસ્ત અસ્તિત્વમાં હોય તો જ A^(-1) અનન્ય હોય છે
  • શૂન્ય મ્યાટ્રિસનો વ્યસ્ત અસ્તિત્વમાં નથી, તે સિંગ્યુલર છે
  • આઈડેન્ટિટી મ્યાટ્રિસ I હંમેશા વ્યસ્તીય અને I^(-1) = I
  • A^(−1) = A તેવી મ્યાટ્રિસને અભિલાક્ષણિક (orthogonal) કહેવાય જો A^T = A^(−1)
  • m×n + m×n = m×n; m×n × n×p = m×p
  • કોઈ પણ વર્ગ મ્યાટ્રિસ A માટે |adj(A)| = |A|^(n−1)

⚠️ સામાન્ય ભૂલો

  • AB = BA છે તે ધારી લેવું — સામાન્ય રીતે મ્યાટ્રિસ ગુણાકાર ક્રમપરવર્તી નથી
  • A ≠ 0, B ≠ 0 હોવા છતાં AB = 0 શક્ય છે — આ સાબિત કરે છે કે અન્વયનશીલતા કાયદો લાગુ પડતો નથી
  • |A+B| = |A|+|B| લખવું — ધારણા ખોટી, નિર્ણાયક સામાન્ય રીતે રેખીય નથી
  • (A+B)² = A²+2AB+B² લખવું — AB≠BA હોય તો આ સાચું નથી
  • A^(−1)+B^(−1) = (A+B)^(−1) લખવું — આ સામાન્ય રીતે ખોટું
  • AB=AC ⇒ B=C નિષ્કર્ષ કાઢવો — જો |A|=0 હોય તો આ ચાલતું નથી
  • કોઈપણ મ્યાટ્રિસનો વ્યસ્ત અસ્તિત્વમાં છે તેવું ધારી લેવું — ફક્ત વર્ગ અને non-singular મ્યાટ્રિસનો જ
  • શૂન્ય મ્યાટ્રિસ I નથી — શૂન્ય મ્યાટ્રિસ તો તટસ્થ ઉપાદન છે, I એ જરૂરીય તટસ્થ ગુણન
  • n મ્યાટ્રિસ 2×2 છે ત્યારે |kA| = k²|A|, સામાન્ય kⁿ|A|
  • A^T = A⁻¹ નો અર્થ સંમિત સમજવો — આ orthogonal મ્યાટ્રિસની શરત છે
  • adj(A) = A⁻¹ લખવું — ખરું તો adj(A) = |A|·A⁻¹
  • m×n અને p×q નો ગુણાકાર શક્ય છે એમ ધારી લેવું — સ્તંભ=m×n, પંક્તિ=p×q, p=n હોય તો જ
  • ગુણાકાર શરત ગણતરી કરતી વખતે AB પરંતુ BA યાદ રાખવું જરૂરી
  • મ્યાટ્રિસ સમીકરણ ઉકેલતી વખતે ડાબી/જમણી બાજુ ગુણવાનું ક્રમ ભૂલવું

🔥 હાઈ-યીલ્ડ મુદ્દા

  • A માં જો A² = A હોય તો A ને idempotent કહે; A³ = A હોય તો tripotent
  • શૂન્ય મ્યાટ્રિસ O સાથે AO = OA = O અને I સાથે AI = IA = A
  • દ્વિકોણીય મ્યાટ્રિસનો નિર્ણાયક = વિકર્ણ ઉપાદનોનો ગુણાકાર
  • રો પદાર્થોની ઇલિમેન્ટરી ક્રિયાઓ: (Rᵢ ↔ Rⱼ), (Rᵢ → kRᵢ), (Rᵢ → Rᵢ + kRⱼ)
  • સ્તંભ પદાર્થોની ઇલિમેન્ટરી ક્રિયાઓ: (Cᵢ ↔ Cⱼ), (Cᵢ → kCᵢ), (Cᵢ → Cᵢ + kCⱼ)
  • ઇલિમેન્ટરી ક્રિયાઓ વડે A ને I સુધી લઈ જવાય તો પૂછતી કોલમ ડાબે ગોઠવવાથી A⁻¹ મળે
  • [I | A] → [A⁻¹ | I] એ ઇલિમેન્ટરી રો ઓપરેશનથી A⁻¹ શોધે
  • A · adj(A) = |A|·I સૂત્ર ઉપયોગથી સીધું A⁻¹ મળે
  • સમીકરણ પદ્ધતિ: XY = B ⇒ X = B Y⁻¹, YX = B ⇒ X = Y⁻¹ B
  • A(BC) = (AB)C — સાંકળ ગુણાકાર (associative) હંમેશા સાચું
  • A(B+C) = AB+AC અને (B+C)A = BA+CA — વિતરણ (distributive) સતત
  • k(A+B) = kA + kB — સ્કેલર વિતરણ
  • A + B = B + A — સરવાળો ક્રમપરવર્તી, પણ ગુણાકાર નહીં
  • A + (−A) = O — વ્યસ્ત (additive inverse) હંમેશા અસ્તિત્વમાં
  • તે જ ક્રમની બે મ્યાટ્રિસ સમાન જો તેમના બધા જ સરવરી રાસોના ઉપાદનો સરખા હોય
  • જો A નો ક્રમ m×n અને B નો n×p હોય, તો AB નો ક્રમ m×p
