માટ્રિક્સ (Matrices) — સંપૂર્ણ સરસાંખ

🧪 GUJCET — Gujarati • Mathematics • Matrices

1. મેટ્રિક્સનો પરિચય
મેટ્રિક્સ એક દ્વિ-પરિમાણીય કોષ્ટક છે જે સંખ્યાઓ (અથવા બીજગણિતીય પદો) ને ચોક્કસ ક્રમમાં હરિયાળી અને સ્તંભમાં ગોઠવે છે.
મેટ્રિક્સ → જર્મન ભાષાનો શબ્દ 'Matrix' (સમૂહ) માંથી લેવાયો છે.
📝 📌 GUJCET: મેટ્રિક્સના પરિચાયક પ્રશ્નો ફાલતો ચોક્કસપણે આવે છે.
2. મેટ્રિક્સની વ્યાખ્યા અને પ્રકારો
મંહદિશા m અને સ્તંભદિશા n ધરાવતી m × n રકમથી ગોઠવાયેલી સંખ્યાઓને 'm × n મેટ્રિક્સ' કહે છે.
A = [a_ij]_(m×n) જ્યાં i = 1,2,...,m અને j = 1,2,...,n
મેટ્રિક્સને સામાન્ય રીતે મોટા અંગ્રેજી અક્ષર (A, B, C ...) થી દર્શાવવામાં આવે છે.
કોષ 'a_ij' એ i-મા હરિયાળી અને j-મા સ્તંભમાં આવેલો અવયવ છે.
મેટ્રિક્સના દરેક અવયવને 'ઇલિમેન્ટ' અથવા 'અવયવ' કહે છે. કુલ અવયવો = m × n.
📝 📌 A_2×3 = 2 હરિયાળી, 3 સ્તંભ → કુલ 6 અવયવો.
3. મેટ્રિક્સના પ્રકારો
(1) શૂન્ય મેટ્રિક્સ (Zero Matrix / Null Matrix) — બધા જ અવયવો શૂન્ય હોય. ડુંઘાતિ શૂન્ય → [0]_(m×n)
(2) પંક્તિ મેટ્રિક્સ (Row Matrix) — ફાલતો 1 હરિયાળી હોય, m = 1 [દા.ત. (1 3 5)]
(3) સ્તંભ મેટ્રિક્સ (Column Matrix) — ફાલતો 1 સ્તંભ હોય, n = 1 [દા.ત. (1/2/3)]
(4) વર્ગીય મેટ્રિક્સ (Square Matrix) — હરિયાળી = સ્તંભ, m = n.
(5) વિકર્ણ મેટ્રિક્સ (Diagonal Matrix) — વર્ગીય મેટ્રિક્સ, જેમાં વિકર્ણ સિવાયના બધા અવયવો શૂન્ય હોય.
(6) એકમ મેટ્રિક્સ (Identity Matrix / Unit Matrix) — વિકર્ણ અવયવો બધા 1 હોય. ડુંઘાતિ I_n or E_n.
I_3 = ⎡1 0 0⎤ ⎢0 1 0⎥ ⎣0 0 1⎦
(7) ત્રિકોણીય મેટ્રિક્સ — ઉર્ધ્વ ત્રિકોણીય (Upper Triangular) અને અધો ત્રિકોણીય (Lower Triangular).
⚡ યાદ રાખો: વિકર્ણ મેટ્રિક્સનો ઇજેનવેલ્યુ = વિકર્ણના અવયવો.
📝 📌 એકમ મેટ્રિક્સનો ગુણાકારથી મૂળ મેટ્રિક્સ મળે — I×A = A×I = A.
4. બે મેટ્રિક્સની સમાનતા (Equality of Matrices)
બે મેટ્રિક્સ A = [a_ij]_(m×n) અને B = [b_ij]_(p×q) સમાન હોય તો:
m = p, n = q અને દરેક i,j માટે a_ij = b_ij
એટલે કે સમાન મેટ્રિક્સના પરિમાણ સમાન અને સંસ્થિત અવયવો સમાન હોવા જોઈએ.
📌 બે મેટ્રિક્સ સમાન હોય તો તેમના ક્રમ (order) અતિઆવશ્યક છે — અલગ ક્રમના મેટ્રિક્સ સમાન નો હોઈ શકે.
5. મેટ્રિક્સનો સરવાળો અને બાદબાકી
સમાન ક્રમના બે મેટ્રિક્સ A અને B નો સરવાળો = બંનેના અનुरूप અવયવોનો સરવાળો.
A + B = [a_ij + b_ij]
બાદબાકી: A − B = [a_ij − b_ij]
મેટ્રિક્સના સરવાળાના ગુણધર્મો:
સંચયન ગુણધર્મ(A + B) + C = A + (B + C)
અદલાબદલી ગુણધર્મA + B = B + A
તટસ્થ મેટ્રિક્સA + O = O + A = A (O = શૂન્ય મેટ્રિક્સ)
વિપરીત મેટ્રિક્સA + (−A) = (−A) + A = O
📌 અસમાન ક્રમના મેટ્રિક્સનો સરવાળો શક્ય નથી — આ પ્રશ્નો GUJCET માં પ્રસિદ્ધ છે!
6. મેટ્રિક્સનો સ્થિરાંક ગુણાકાર (Scalar Multiplication)
મેટ્રિક્સ A = [a_ij]_(m×n) અને સ્થિરાંક k માટે:
kA = [k·a_ij]
ગુણધર્મો: k(A+B) = kA + kB, (k+l)A = kA + lA, k(lA) = (kl)A.
📝 📌 kA નો ક્રમ અચળ રહે છે.
7. મેટ્રિક્સનો ગુણાકાર (Matrix Multiplication)
A = [a_ij]_(m×n) અને B = [b_jk]_(n×p) નો ગુણાકાર AB ત્યારે જ શક્ય જો A ના સ્તંભ = B ની હરિયાળી (n = n).
AB = [c_ik]_(m×p), જ્યાં c_ik = a_i1·b_1k + a_i2·b_2k + ... + a_in·b_nk
⚡ AB ≠ BA સામાન્ય રીતે (ગુણાકાર અદલાબદલી નથી થતો) — આ GUJCET નો મહત્વનો પ્રશ્ન.
સ્થિરાંક ગુણાકાર: (kA)B = A(kB) = k(AB)
સંચયનA(B + C) = AB + AC
સંયોજકતા(AB)C = A(BC)
એકમ મેટ્રિક્સAI = IA = A
📝 📌 AB = O => A=O અથવા B=O હોવું આવશ્યક નથી! (અશૂન્ય મેટ્રિક્સનો ગુણાકાર શૂન્ય મેટ્રિક્સ આપી શકે.)
8. મેટ્રિક્સના ગુણાકારના પ્રશ્નો
AB ગણવાની પદ્ધતિ: A ની હરિયાળી × B ના સ્તંભ → ઘાતિય ગુણોત્તર કરી સરવાળો.
ઉદા. A = [2 3], B = [1/4] ⇒ AB = 2×1 + 3×4 = 14
AB શોધવા માટે ગણતરીની સુવિધા: સૌથી પહેલાં ક્રમ ચકાસો, પછી ગુણાકાર.
📌 (AB)^T = B^T · A^T — ટ્રાન્સપોઝનો આ ગુણધર્મ યાદ રાખો!
9. મેટ્રિક્સનું ટ્રાન્સપોઝ (Transpose Matrix)
મેટ્રિક્સ A ના હરિયાળી-સ્તંભ બદલાઈને જે મેટ્રિક્સ બને તે A^T (અથવા A') કહે છે.
જો A = [a_ij]_(m×n), તો A^T = [a_ji]_(n×m)
ટ્રાન્સપોઝના ગુણધર્મો:
(A^T)^T = A
(A + B)^T = A^T + B^T
(kA)^T = k(A^T)
(AB)^T = B^T · A^T
📌 A A^T અને A^T A બંને વર્ગીય મેટ્રિક્સ છે, ભલે A વર્ગીય ન હોય.
10. સમમિતીય અને પ્રતિસામી મેટ્રિક્સ
(અ) સમમિતીય મેટ્રિક્સ (Symmetric Matrix): વર્ગીય મેટ્રિક્સ A જેના માટે A^T = A.
a_ij = a_ji ∀ i,j
(બ) પ્રતિસામી મેટ્રિક્સ (Skew-Symmetric Matrix): વર્ગીય મેટ્રિક્સ A જેના માટે A^T = −A.
a_ij = −a_ji, અને બધા વિકર્ણ અવયવો શૂન્ય.
📌 કોઈ પણ વર્ગીય મેટ્રિક્સ A ને સમમિતીય + પ્રતિસામી મેટ્રિક્સના સરવાળા તરીકે લખી શકાય: A = ½(A + A^T) + ½(A − A^T)
📝 📌 પ્રતિસામી મેટ્રિક્સનો વિકર્ણ હંમેશા શૂન્ય — ફરજિયાત!
11. મેટ્રિક્સની ચાલ (Determinant of a Square Matrix)
vargiya metrikks no 'chaal' (Determinant) — keval 2×2 ane 3×3 vaasata paribhashit.
જો A = [a_ij]_(2×2), તો |A| = a_11·a_22 − a_12·a_21
જો A = [a_ij]_(3×3), તો |A| = a_11(a_22·a_33 − a_23·a_32) − a_12(a_21·a_33 − a_23·a_31) + a_13(a_21·a_32 − a_22·a_31)
ચાલના ગુણધર્મો:
|A^T|= |A|
|AB|= |A| · |B|
|kA| (n×n)= k^n |A|
|I_n|= 1
⚡ |A| = 0 → મેટ્રિક્સ સિંગ્યુલર (અવ્યસ્ત); |A| ≠ 0 → મેટ્રિક્સ નોન-સિંગ્યુલર (વ્યસ્ત). આ પ્રકાશનો પ્રશ્ન GUJCET માં ફરજિયાત આવે છે.
12. અનુબંધ મેટ્રિક્સ (Adjoint Matrix)
મેટ્રિક્સ A ના દરેક અવયવ માટે અવયવક (cofactor) C_ij શોધો. તેઓથી બનેલો મેટ્રિક્સ 'અવયવક મેટ્રિક્સ' અને તેનો ટ્રાન્સપોઝ 'એડજોઇન્ટ મેટ્રિક્સ'.
adj(A) = [C_ji]_(n×n) જ્યાં C_ij = (−1)^(i+j) · M_ij
M_ij = i,j-અવયવની 'માઈનોર' (minor) — એટલે કે (i,j)-અવયવ બાદ કરતાં મળતી (n−1)×(n−1) ચાલ.
📌 adj(A) · A = A · adj(A) = |A| · I — આ સૂત્ર યાદ રાખો, વ્યસ્ત શોધવામાં ઉપયોગી.
📝 📌 2×2 નો adj(A) શોધવાની સરળ રીત: વિકર્ણ બદલો, બાકીના ચિન્હ બદલો.
13. વ્યસ્ત મેટ્રિક્સ (Inverse Matrix)
વર્ગીય મેટ્રિક્સ A નો વ્યસ્ત A^(-1) એવો મેટ્રિક્સ કે જેના માટે:
A · A^(-1) = A^(-1) · A = I
વ્યસ્ત અસ્તિત્વ માટે: |A| ≠ 0 (મેટ્રિક્સ નોન-સિંગ્યુલર હોવો જોઈએ).
A^(-1) = adj(A) / |A| (જ્યારે |A| ≠ 0)
વ્યસ્તના ગુણધર્મો:
(A^(-1))^(-1)= A
(AB)^(-1)= B^(-1) · A^(-1)
(A^T)^(-1)= (A^(-1))^T
|A^(-1)|= 1/|A|
⚡ |A| = 0 હોય તો A નો વ્યસ્ત અસ્તિત્વમાં નથી — પ્રશ્નનો ચાલાકી જવાબ.
📝 📌 (A^2)^(-1) = (A^(-1))^2 પણ યાદ રાખો.
14. સુસંગત રેખીય સમીકરણ પદ્ધતિ — મેટ્રિક્સ રીત
સમીકરણ પ્રણાલીને AX = B સ્વરૂપે લખાય. જો |A| ≠ 0, તો X = A^(-1) · B — એકમ ઉકેલ.
X = A^(-1) B, જ્યાં A^(-1) = adj(A)/|A|
પદ્ધતિ: (1) A, B, X શોધો. (2) |A| ગણો. (3) adj(A) શોધો. (4) A^(-1) = adj(A)/|A|. (5) X = A^(-1)B.
📌 જો |A| = 0: • AB ≠ O → સમીકરણ પ્રણાલી અસુસંગત (No solution) • AB = O → સમીકરણ પ્રણાલી સુસંગત (Infinite solutions)
📝 📌 સુસંગતતા તપાસવા માટે |A| = 0 હોય તો (adj A)·B = O ચકાસો.
15. વ્યસ્તની વિધી — ઉદાહરણ પ્રકાર
2×2 મેટ્રિક્સ A = [a b/c d] માટે:
A^(-1) = (1/(ad−bc)) · [d -b/-c a]
તપાસ: A · A^(-1) = I આવે ત્યાં સુધી ગણતરી ચકાસો.
પરીક્ષામાં 3×3 વ્યસ્ત માટે: પ્રથમ અવયવક ગણો → એડજોઇન્ટ → વ્યસ્ત.
📌 (kA)^(-1) = (1/k) · A^(-1), જ્યાં k ≠ 0.
16. માઈનોર અને અવયવક (Cofactor) — મહત્વના નિયમો
માઈનોર M_ij = (i,j)-અવયવ નીચેનું (n−1)×(n−1) ચોક્કસ ચાલ.
અવયવક C_ij = (−1)^(i+j) · M_ij.
A · adj(A) = adj(A) · A = |A| · I_n
📌 બીજા ક્રમમાં: C_11 = +M_11, C_12 = −M_12, C_21 = −M_21, C_22 = +M_22 (ચેસબોર્ડ ચિન્હ પદ્ધતિ).
📝 📌 અવયવક શોધતી વખતે ચિન્હની ભૂલ સૌથી સામાન્ય છે — ધ્યાન રાખો!
17. મેટ્રિક્સના અન્ય ગુણધર્મો
A મેટ્રિક્સ માટે, A + A^T સમમિતીય છે અને A − A^T પ્રતિસામી છે.
જો A વ્યસ્ત હોય, તો A^(-1) પણ વ્યસ્ત છે અને (A^(-1))^(-1) = A.
બે વ્યસ્ત મેટ્રિક્સનું ગુણન વ્યસ્તક્રમે વ્યસ્ત થાય: (AB)^(-1) = B^(-1)A^(-1).
⚡ બધા જ વ્યસ્ત ધરાવતા મેટ્રિક્સોનો સમૂહ 'સामાન્ય રીતે S_n' ગ્રૂપ રચે છે (ગુણાકાર અંતર્ગત).
📝 📌 (AB)^T = B^T A^T અને (AB)^(-1) = B^(-1) A^(-1) — બંનેમાં ક્રમ ઉલટાઈ જાય છે.
18. મેટ્રિક્સ — મહત્વના પ્રમેયો અને નિષ્કર્ષો
મહત્વનો પ્રમેય: જો A વ્યસ્ત હોય, તો A · adj(A) = |A| · I.
જો A, B બંને વ્યસ્ત હોય, તો AB પણ વ્યસ્ત છે.
વર્ગીય મેટ્રિક્સનો વિકર્ણ સરવાળો 'ટ્રેસ' — કોઈ પણ વર્ગીય મેટ્રિક્સ A માટે tr(A) = Σ a_ii.
tr(A + B) = tr(A) + tr(B) tr(kA) = k·tr(A) tr(AB) = tr(BA)
📌 tr(A) = tr(A^T) અને tr(I_n) = n.
19. સંકલ્પનાત્મક મેટ્રિક્સ પ્રશ્નો
જો A = [a_ij]_(2×2) અને a_ij = (i+j)/2 હોય, તો મેટ્રિક્સ શોધો.
જો A² = A હોય, તો A ને 'ઇડેમપોટેન્ટ' કહે છે. (A+I)(I−2A) શોધો.
જો A = [1 1/0 1] હોય, તો A², A³, A^n શોધો. સામાન્ય સ્વરૂપ નીકાળો.
📌 જો A = [a b/c d], તો કોઈ પણ વર્ગીય મેટ્રિક્સ માટે A² − tr(A)·A + |A|·I = O (હેલી-કેલિટન પ્રમેય).
📝 📌 ગુણોત્તર અંદાજ: A^n શોધવા માટે પેટર્ન ઓળખો — નિરંતર ગુણાકાર કરવું વ્યર્થ છે.
20. GUJCET — મેટ્રિક્સ વિભાગ માટે ટિપ્સ
1. ક્રમ (order) તપાસવો — વિપરીત ક્રમના મેટ્રિક્સનો સરવાળો/ગુણાકાર ન થાય.
2. |A| = 0 હોય તો વ્યસ્ત અસ્તિત્વમાં નથી — પ્રશ્નનો ઝટપટ જવાબ.
3. 2×2 માટે adj(A) = [d -b/-c a] યાદ રાખો — ઝડપી ગણતરી.
4. અવયવક ગણતરીમાં ચિન્હ ભૂલ ન કરવી — ચેસબોર્ડ પદ્ધતિ વાપરો.
5. R.L. (રાશનલ લીનિયર) સમીકરણ પ્રણાલીના ઉકેલ માટે |A| ≠ 0 તો એકમ ઉકેલ, |A|=0 તો સુસંગતતા તપાસો.
🔑 મેટ્રિક્સ બંધારણીય (structural) વિષય છે — યોગ્ય રીતે અભ્યાસ કરવાથી સંપૂર્ણ અંક મેળવી શકાય.
📝 📌 અંતિમ યાદદાસ્ત: transpose→ક્રમ બદલે, inverse→ચાલ જરૂરી, adjoint→ચાલ/ટ્રાન્સપોઝ, determinant→વ્યસ્તતા તપાસે.
