⚡ સૂત્રો

મેટ્રિક્સની વ્યાખ્યા અને ક્રમ: A = [a_ij]_{m×n} , જ્યાં i = 1,2,...,m ; j = 1,2,...,n
a_ij = m નામાં પંક્તિ (row) અને n નામાં સ્તંભ (column) નો કોટિબિંદુ · SI: — · jેવો કોટિ m×n ધરાવતાં મેટ્રિક્સ માટે
પંક્તિ (Row) મેટ્રિક્સ: A = [a_1j]_{1×n}
આડી (horizontal) હરોળ બંધારણ · SI: — · ક્રમ 1×n
સ્તંભ (Column) મેટ્રિક્સ: A = [a_i1]_{m×1}
ઊભી (vertical) હરોળ બંધારણ · SI: — · ક્રમ m×1
વર્ગ (Square) મેટ્રિક્સ: A = [a_ij]_{n×n} , pંક્તિઓ = સ્તંભો = n
n = કોટિ (order) · SI: — · pંક્તિ અને સ્તંભ સંખ્યા સમાન હોય
વિકર્ણ (Diagonal) મેટ્રિક્સ: A = diag(a_11, a_22, ..., a_nn) , a_ij = 0 જ્યારે i ≠ j
a_ii = વિકર્ણીય કોટિબિંદુઓ; બાકીનાં બધાં a_ij = 0 · SI: — · વર્ગ મેટ્રિક્સ હોય અને અવિકર્ણ કોટિબિંદુઓ શૂન્ય હોય
અદિશ (Scalar) મેટ્રિક્સ: A = diag(k, k, ..., k) = kI_n , jેથા a_ii = k (એકસમાન અચળાંક)
k = અચળાંક; I_n = એકમ મેટ્રિક્સ · SI: — · વિકર્ણ મેટ્રિક્સમાં બધાં વિકર્ણીય કોટિબિંદુઓ સમાન હોય
એકમ (Identity / Unit) મેટ્રિક્સ: I_n = diag(1, 1, ..., 1) , (I_n)_ij = δ_ij (Kronecker delta)
δ_ij = 1 જ્યારે i=j; 0 જ્યારે i≠j · SI: — · વર્ગ મેટ્રિક્સમાં વિકર્ણ કોટિબિંદુઓ = 1 અને બાકીનાં = 0
શૂન્ય (Zero / Null) મેટ્રિક્સ: O_{m×n} = [0] , જયાં બધાં a_ij = 0
O = શૂન્ય મેટ્રિક્સ; દરેક કોટિબિંદુ 0 · SI: — · જવાબદાર કોઈ પણ ક્રમનું મેટ્રિક્સ
મેટ્રિક્સનો સ્કંધ (Transpose): A^T : જો A = [a_ij]_{m×n} તો A^T = [a_ji]_{n×m}
A^T = A નું ટ્રાન્સપોઝ; પંક્તિઓ સ્તંભ અને સ્તંભો પંક્તિ બને · SI: — · કોઈ પણ m×n મેટ્રિક્સ માટે
ટ્રાન્સપોઝના ગુણધર્મો — પુનરાવર્તન: (A^T)^T = A
બે વાર ટ્રાન્સપોઝ કરતાં મૂળ મેટ્રિક્સ મળે છે · SI: — · કોઈ પણ વર્ગ/યાજ્ય મેટ્રિક્સ માટે
ટ્રાન્સપોઝ — સંયોજન (Addition): (A ± B)^T = A^T ± B^T
A, B = સમાન ક્રમના મેટ્રિક્સ · SI: — · A અને B નો ક્રમ સમાન હોય
ટ્રાન્સપોઝ — અદિશ ગુણાકાર: (kA)^T = k·A^T , જયાં k = અદિશ (scalar)
k = કોઈ પણ વાસ્તવિક સંખ્યા · SI: — · કોઈ પણ મેટ્રિક્સ A માટે
ટ્રાન્સપોઝ — ગુણાકાર (Product): (AB)^T = B^T · A^T , | જયાં AB અસ્તિત્વ ધરાવતું હોય
A = m×n , B = n×p ; AB = m×p ; (AB)^T = p×m · SI: — · A અને B ના માપ અનુકૂળ હોય (A ના સ્તંભ = B ની પંક્તિ)
મેટ્રિક્સનો સંયોગ (Addition): (A ± B)_ij = a_ij ± b_ij
A = [a_ij], B = [b_ij]; બંનેનો ક્રમ સમાન · SI: — · A અને B નો ક્રમ સમાન હોય
અદિશ ગુણાકાર (Scalar Multiplication): (kA)_ij = k·a_ij
k = વાસ્તવિક અદિશ; A = [a_ij] · SI: — · કોઈ પણ મેટ્રિક્સ A માટે
મેટ્રિક્સ ગુણાકાર — સામાન્ય સૂત્ર: C_ij = (AB)_ij = Σ_{k=1}^{n} a_ik · b_kj
A = m×n, B = n×p ; C = AB = m×p ; n = ઉંમદાંક (inner dimension) · SI: — · A ના સ્તંભો = B ની પંક્તિઓ
ગુણાકારનો જમણો-વધારો (Right Distributive Law): (A + B)·C = AC + BC
A, B = સમાન ક્રમના મેટ્રિક્સ; C = અનુકૂળ ક્રમ · SI: — · બધાં ગુણાકાર અસ્તિત્વ ધરાવતા હોય
ગુણાકારનો ડાબો-વધારો (Left Distributive Law): C·(A + B) = CA + CB
A, B = સમાન ક્રમના મેટ્રિક્સ; C = અનુકૂળ ક્રમ · SI: — · બધાં ગુણાકાર અસ્તિત્વ ધરાવતા હોય
ગુણાકારનું સંયોજક ગુણ (Associative Law): A·(B·C) = (A·B)·C
A = m×n, B = n×p, C = p×q ; ABC = m×q · SI: — · બધાં ગુણાકાર અસ્તિત્વ ધરાવતા હોય
ગુણાકારનું વિનિમય ગુણ (Commutativity — સામાન્ય રીતે NOT valid): AB ≠ BA (સામાન્ય રીતે)
AB = A × B; BA = B × A · SI: — · સિવાય કે A અને B એકબીજા સાથે વિનિમય કરતાં હોય
વર્ગ મેટ્રિક્સનો સંયોગ (Symmetric Matrix): A^T = A , | jેથા a_ij = a_ji બધા i,j માટે
A = વર્ગ મેટ્રિક્સ; a_ij = (i,j) કોટિબિંદુ · SI: — · વર્ગ મેટ્રિક્સમાં A^T = A
વિકર્ણ-વિપરીત (Skew-Symmetric) મેટ્રિક્સ: A^T = −A , | jેથા a_ij = −a_ji ; તથા a_ii = 0 બધા i માટે
A = વર્ગ મેટ્રિક્સ; a_ii = વિકર્ણ કોટિબિંદુઓ (શૂન્ય) · SI: — · A^T = −A
મહત્વપૂર્ણ પરિણામ — સંયોગ + વિકર્ણ-વિપરીત સ્વરૂપ: A = ½(A + A^T) + ½(A − A^T) , પ્રથમ પદ સંયોગ, દ્વિતીય પદ વિકર્ણ-વિપરીત
A = કોઈ પણ વર્ગ મેટ્રિક્સ · SI: — · કોઈ પણ વર્ગ મેટ્રિક્સ A માટે
મેટ્રિક્સ સમીકરણ — સમાનતા શરત: A = B ⟺ |A| = |B| , jેથા સમાન ક્રમ અને બધા a_ij = b_ij
A, B = સમાન ક્રમના મેટ્રિક્સ · SI: — · બંને મેટ્રિક્સનો ક્રમ સમાન હોય
મૂળભૂત પંક્તિ પരിવર્તન (Elementary Row Operations) — I: R_i ↔ R_j (અથવા C_i ↔ C_j) , | બે પંક્તિ/સ્તંભ ચાલુ
R_i, R_j = i ની અને j ની પંક્તિ · SI: — · બધાં મેટ્રિક્સ પર લાગુ
મૂળભૂત પંક્તિ પરીવર્તન — II: R_i → k·R_i (અથવા C_i → k·C_i) , jેથા k ≠ 0
k = અશૂન્ય અદિશ · SI: — · k ≠ 0
મૂળભૂત પંક્તિ પરીવર્તન — III: R_i → R_i + k·R_j (અથવા C_i → C_i + k·C_j), jેથા k ∈ ℝ
k = વાસ્તવિક અદિશ · SI: — · કોઈ પણ વાસ્તવિક k માટે
શ્રેષ્ઠ (Adjoint) મેટ્રિક્સ: adj(A) = [C_ji] , | jેથા C_ij = (i,j) નો ઉપાંશિકા (cofactor) અથવા કો-ફેક્ટર
C_ij = (−1)^{i+j} · M_ij; M_ij = ઉપાંશિકા (minor) = |A_ij|; A_ij = (i,j) થી સૂત્રિત ઉપમેટ્રિક્સ · SI: — · A વર્ગ મેટ્રિક્સ હોય
ઉપાંશિકા (Cofactor) ની ગણતરી: C_ij = (−1)^{i+j} · M_ij, | jેથા M_ij = શૂન્યત્વ (determinant) of submatrix obtained by deleting row i and column j
M_ij = ઉપાંશિકા; C_ij = ઉપાંશિકા અથવા cofactor · SI: — · A વર્ગ મેટ્રિક્સ હોય
શ્રેષ્ઠ અને મૂળભૂત સંબંધ: A · adj(A) = adj(A) · A = |A| · I_n
|A| = નિશ્ચાયક (determinant); I_n = n×n એકમ મેટ્રિક્સ · SI: — · A વર્ગ મેટ્રિક્સ હોય
પ્રતિલોમ (Inverse) મેટ્રિક્સ: A^{−1} = (1/|A|) · adj(A) , | જ્યાં |A| ≠ 0
|A| = નિશ્ચાયક; adj(A) = શ્રેષ્ઠ મેટ્રિક્સ · SI: — · A વર્ગ મેટ્રિક્સ અને |A| ≠ 0 (non-singular)
વિયોજ્ય (Singular) vs અવિયોજ્ય (Non-singular) મેટ્રિક્સ: સિંગ્યુલર: |A| = 0 ⟹ A^{−1} અસ્તિત્વ ધરાવતું નથી | Non-singular: |A| ≠ 0 ⟹ A^{−1} અસ્તિત્વ ધરાવે છે
|A| = નિશ્ચાયક · SI: — · A વર્ગ મેટ્રિક્સ
પ્રતિલોમના ગુણધર્મો: (A^{−1})^{−1} = A; (AB)^{−1} = B^{−1} · A^{−1}; (A^n)^{−1} = (A^{−1})^n; |A^{-1}| = 1/|A|
A,B = અવિયોજ્ય વર્ગ મેટ્રિક્સ; n ∈ ℕ · SI: — · બધાં ગુણાકાર અને પ્રતિલોમ અસ્તિત્વ ધરાવતા હોય
નિશ્ચાયક (Determinant) — 2×2: |A| = a_11·a_22 − a_12·a_21 , જ્યાં A = [a_ij]_{2×2}
a_ij = (i,j) કોટિબિંદુ; |A| = નિશ્ચાયક · SI: — · A = 2×2 વર્ગ મેટ્રિક્સ
નિશ્ચાયક (Determinant) — 3×3: |A| = a_11·C_11 + a_12·C_12 + a_13·C_13, | jેથા C_ij = (−1)^{i+j} M_ij
M_ij = ઉપાંશિકા; C_ij = cofactor; અન્ય વિકલ્પ: પંક્તિ/સ્તંભ ક્રમમાં વિસ્તરણ · SI: — · A = 3×3 વર્ગ મેટ્રિક્સ
એડજોઈન્ટનો નિશ્ચાયક: |adj(A)| = |A|^{n−1}, | jેથા A = n×n વર્ગ મેટ્રિક્સ
n = મેટ્રિક્સની કોટિ · SI: — · A vર્ગ મેટ્રિક્સ
પ્રતિલોમનું નિશ્ચાયક: |A^{−1}| = 1 / |A|, | અથવા |A| · |A^{−1}| = 1
|A| = નિશ્ચાયક; A અવિયોજ્ય · SI: — · |A| ≠ 0
પ્રતિલોમ — નામાંકિત પંક્તિ પરીવર્તન (Row-Reduction Method): [A | I] --RREF--> [I | A^{−1}], | જ્યાં A અને I નો ક્રમ સમાન
A = વર્ગ મેટ્રિક્સ; I = એકમ મેટ્રિક્સ; RREF = Reduced Row Echelon Form · SI: — · A અવિયોજ્ય (|A| ≠ 0) હોય

🔗 સંબંધો

  • A સંયોગ છે ⟺ A^T = A; A વિકર્ણ-વિપરીત છે ⟺ A^T = −A
  • કોઈ પણ વર્ગ મેટ્રિક્સ A ને બે સરળાંશ મેટ્રિક્સનો સરવાળો તરીકે લખી શકાય: A = ½(A + A^T) + ½(A − A^T), જ્યાં પ્રથમ પદ સંયોગ અને દ્વિતીય પદ વિકર્ણ-વિપરીત છે
  • A વિકર્ણ-વિપરીત હોય તો તેનાં બધાં વિકર્ણીય કોટિબિંદુઓ શૂન્ય હોય છે (a_ii = 0)
  • adj(A) = (C_ji) — ઉપાંશિકાઓનોTranspose (cofactors નોTranspose)
  • A · adj(A) = adj(A) · A = |A| · I_n — આ સંબંધ પ્રતિલોમ શોધવામાં મૂળભૂત છે
  • |AB| = |A|·|B| — બે વર્ગ મેટ્રિક્સના ગુણાકારના નિશ્ચાયકની ગુણાકારધર્મતા
  • A અને B અવિયોજ્ય હોય તો AB પણ અવિયોજ્ય: |AB| ≠ 0
  • જો A સંયોગ હોય તો A^n પણ સંયોગ; જો A વિકર્ણ-વિપરીત હોય તો A^n પણ વિકર્ણ-વિપરીત (n યુગ્મ હોય)
  • adj(A^T) = (adj A)^T અને (A^T)^{-1} = (A^{-1})^T
  • કોઈ પણ vર્ગ મેટ્રિક્સ A માટે: A^{-1} = adj(A) / |A| (જ્યારે |A| ≠ 0)

🎯 ટ્રિક્સ
