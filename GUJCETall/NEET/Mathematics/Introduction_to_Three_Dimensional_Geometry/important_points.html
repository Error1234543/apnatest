ત્રિ-પરિમાણ ભૂમિતિ (Introduction to Three Dimensional Geometry)

🧪 GUJCET — Gujarati • Mathematics • Introduction to Three Dimensional Geometry

⭐ મહત્વના મુદ્દા

ત્રિ-પરિમાણ ભૂમિતિમાં બિંદુની સ્થિતિ નક્કી કરવા માટે ત્રણ અક્ષો (x-અક્ષ, y-અક્ષ, z-અક્ષ) અને બિંદુના સંકલિત (x, y, z) વપરાય છે.
GUJCET માં આધારભૂત પ્રશ્નો અક્ષ-પ્રણાલી અને સંકલિત વિશે આવે છે.
ત્રણેય અક્ષો એકબીજાને મૂળબિંદુ (0, 0, 0) પર લંબરૂપે છેદે છે; આને અઠવાળા (Octants) કહે છે, કુલ 8 અઠવાળા હોય છે.
અઠવાળાઓના ચિહ્નો અને સંકલિતો સંબંધિત પ્રશ્નો GUJCET માં આવે છે.
બે બિંદુઓ P(x₁, y₁, z₁) અને Q(x₂, y₂, z₂) વચ્ચેનું અંતર: PQ = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
અંતર સૂત્ર GUJCET માં સીધો પ્રશ્ન આવે છે, ખાસ કરીને સંકલિત શોધવાના પ્રશ્નોમાં.
બિંદુ P(x₁, y₁, z₁) અને Q(x₂, y₂, z₂) ને m:n ના ગુણોત્તરમાં વિભાજિત કરતું બિંદુ: ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n))
વિભાજન સૂત્ર GUJCET માં અંતર અને વિભાજન મિશ્રિત પ્રશ્નોમાં આવે છે.
મધ્યબિંદુ સૂત્ર: P(x₁,y₁,z₁) અને Q(x₂,y₂,z₂) નું મધ્યબિંદુ = ((x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2)
મધ્યબિંદુ સૂત્ર સરળ અને સીધો પ્રશ્ન GUJCET માં આવે છે.
રેખાખંડના સંકલિતો (l, m, n) ને દિશા કોસાઇન (Direction Cosines) કહે છે, જ્યાં l² + m² + n² = 1.
દિશા કોસાઇનનો ગુણધર્મ l²+m²+n²=1 GUJCET માં બહુ આવે છે.
દિશા કોસાઇન (l, m, n) અને દિશા અનુપાત (Direction Ratios) (a, b, c) વચ્ચેનો સંબંધ: l = a/√(a²+b²+c²), m = b/√(a²+b²+c²), n = c/√(a²+b²+c²)
દિશા અનુપાતમાંથી દિશા કોસાઇન શોધવાનો પ્રશ્ન GUJCET માં આવે છે.
બે રેખાઓના દિશા અનુપાત (a₁,b₁,c₁) અને (a₂,b₂,c₂) હોય તો તેમની વચ્ચેનો ખૂણો: cos θ = |a₁a₂ + b₁b₂ + c₁c₂| / [√(a₁²+b₁²+c₁²) · √(a₂²+b₂²+c₂²)]
ખૂણાનું સૂત્ર GUJCET માં મહત્વપૂર્ણ છે; લંબરૂપતાની શરત પણ આવે છે.
બે રેખાઓ લંબરૂપ હોય તો: a₁a₂ + b₁b₂ + c₁c₂ = 0
લંબરૂપતાની શરત GUJCET માં સીધો પ્રશ્ન આવે છે.
બે રેખાઓ સમાંતર હોય તો: a₁/a₂ = b₁/b₂ = c₁/c₂
સમાંતરતાની શરત GUJCET માં આવે છે.
બિંદુ (x₁,y₁,z₁) માંથી પસાર થતી અને દિશા અનુપાત (a,b,c) ધરાવતી રેખાનું પ્રમાણભૂત સમીકરણ: (x−x₁)/a = (y−y₁)/b = (z−z₁)/c
રેખાનું સમીકરણ GUJCET માં સૌથી મહત્વપૂર્ણ વિષય છે.
બે બિંદુઓ (x₁,y₁,z₁) અને (x₂,y₂,z₂) માંથી પસાર થતી રેખાનું સમીકરણ: (x−x₁)/(x₂−x₁) = (y−y₁)/(y₂−y₁) = (z−z₁)/(z₂−z₁)
બે બિંદુઓમાંથી પસાર થતી રેખા GUJCET માં સીધો પ્રશ્ન આવે છે.
સમતલનું પ્રમાણભૂત સમીકરણ: ax + by + cz + d = 0, જ્યાં (a,b,c) સમતલના લંબ દિશા અનુપાત છે.
સમતલનું સમીકરણ GUJCET માં આવે છે.
બિંદુ (x₁,y₁,z₁) માંથી પસાર થતું અને દિશા અનુપાત (a,b,c) ધરાવતું સમતલ: a(x−x₁) + b(y−y₁) + c(z−z₁) = 0
સમતલનું સમીકરણ GUJCET માં મહત્વપૂર્ણ છે.
બે સમતલો a₁x+b₁y+c₁z+d₁=0 અને a₂x+b₂y+c₂z+d₂=0 વચ્ચેનો ખૂણો: cos θ = |a₁a₂+b₁b₂+c₁c₂| / [√(a₁²+b₁²+c₁²) · √(a₂²+b₂²+c₂²)]
બે સમતલો વચ્ચેનો ખૂણો GUJCET માં આવે છે.
બે સમતલો લંબરૂપ હોય તો: a₁a₂ + b₁b₂ + c₁c₂ = 0
સમતલોની લંબરૂપતા GUJCET માં સીધો પ્રશ્ન આવે છે.
બે સમતલો સમાંતર હોય તો: a₁/a₂ = b₁/b₂ = c₁/c₂
સમતલોની સમાંતરતા GUJCET માં આવે છે.
બિંદુ (x₁,y₁,z₁) માંથી સમતલ ax+by+cz+d=0 પર દોરેલા લંબનું અંતર: |ax₁+by₁+cz₁+d| / √(a²+b²+c²)
બિંદુ-સમતલ અંતર GUJCET માં મહત્વપૂર્ણ પ્રશ્ન છે.
સ્કેલેન સમીકરણ (Scalar form): r⃗ · (n̂) = d, જ્યાં r⃗ = xi + yj + zk, n̂ એકમ લંબ સદિશ, d મૂળબિંદુથી સમતલનું અંતર.
સદિશ સ્વરૂપ GUJCET માં આવે છે.
સ્કેલેન સમીકરણ (Vector form): r⃗ · n̂ = d, જ્યાં n̂ એકમ લંબ સદિશ છે.
સદિશ સ્વરૂપ GUJCET માં આવે છે.
રેખાનું પરામિત્રીય સ્વરૂપ: x = x₁ + at, y = y₁ + bt, z = z₁ + ct, જ્યાં t પરામાપ છે.
પરામાપ સ્વરૂપ GUJCET માં આવે છે.
રેખા-સમતલ છેદબિંદુ: રેખા (x−x₁)/a = (y−y₁)/b = (z−z₁)/c ને સમતલ ax+by+cz+d=0 માં મૂકીને t શોધવું અને છેદબિંદુ મેળવવું.
રેખા-સમતલ છેદબિંદુ GUJCET માં આવે છે.
રેખા સમતલ પર હોય તો: a·x₁ + b·y₁ + c·z₁ + d = 0 અને રેખાનો દિશા અનુપાત સમતલના લંબ સાથે લંબરૂપ હોય: aa₁+bb₁+cc₁=0.
રેખા-સમતલ સંબંધ GUJCET માં આવે છે.
અક્ષો સાથે રેખાના ખૂણા: x-અક્ષ સાથે α, y-અક્ષ સાથે β, z-અક્ષ સાથે γ, જ્યાં cos²α + cos²β + cos²γ = 1.
અક્ષો સાથેના ખૂણાનો ગુણધર્મ GUJCET માં આવે છે.
