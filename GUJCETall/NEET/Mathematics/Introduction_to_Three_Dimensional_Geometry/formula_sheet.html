ત્રિ-પરિમાણ ભૂમિતિનું પરિચય — સૂત્ર શેડ

🧪 GUJCET — Gujarati • Mathematics • Introduction to Three Dimensional Geometry

⚡ સૂત્રો

અક્ષો અને સમતલો: ત્રણ પરસ્પર લંબ અક્ષો X, Y, Z અને મૂળબિંદુ O(0,0,0). બિંદુ P ના નિરૂપક (x, y, z) એ P માંથી દોરેલા લંબોના પાદબિંદુઓના અનુરૂપ અંતરો છે.
x = X-અક્ષ પરનું અંતર, y = Y-અક્ષ પરનું અંતર, z = Z-અક્ષ પરનું અંતર · SI: એકમ · જ્યારે ત્રણેય અક્ષો પરસ્પર લંબ હોય
બે બિંદુઓ વચ્ચેનું અંતર: d = √[(x₂ - x₁)² + (y₂ - y₁)² + (z₂ - z₁)²]
P(x₁, y₁, z₁) અને Q(x₂, y₂, z₂) એ બે બિંદુઓ છે · SI: એકમ · ત્રિ-પરિમાણ અવકાશમાં કોઈ પણ બે બિંદુઓ માટે
મૂળબિંદુથી અંતર: OP = √(x² + y² + z²)
P(x, y, z) એ કોઈ પણ બિંદુ છે, O(0,0,0) મૂળબિંદુ છે · SI: એકમ · મૂળબિંદુ O થી બિંદુ P સુધીનું અંતર
ખંડસૂત્ર (આંતરિક વિભાજન): P = ((mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n), (mz₂ + nz₁)/(m+n))
P બિંદુ AB ને m:n ના ગુણોત્તરમાં આંતરિક રીતે વિભાજે છે. A(x₁,y₁,z₁), B(x₂,y₂,z₂) · SI: એકમ · m + n ≠ 0
ખંડસૂત્ર (બાહ્ય વિભાજન): P = ((mx₂ - nx₁)/(m-n), (my₂ - ny₁)/(m-n), (mz₂ - nz₁)/(m-n))
P બિંદુ AB ને m:n ના ગુણોત્તરમાં બાહ્ય રીતે વિભાજે છે. A(x₁,y₁,z₁), B(x₂,y₂,z₂) · SI: એકમ · m ≠ n
મધ્યબિંદુ સૂત્ર: M = ((x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2)
M એ A(x₁,y₁,z₁) અને B(x₂,y₂,z₂) નું મધ્યબિંદુ છે · SI: એકમ · કોઈ પણ બે બિંદુઓ માટે
દિશા કોસાઇન (Direction Cosines): l = cos α, m = cos β, n = cos γ, જ્યાં l² + m² + n² = 1
α, β, γ એ અક્ષો સાથે રેખા દ્વારા બનતા કોણો છે; l, m, n દિશા કોસાઇન છે · SI: એકમરહિત · રેખાની દિશા નક્કી કરવા માટે
દિશા અનુપાત (Direction Ratios): a, b, c એવા કે l = a/√(a²+b²+c²), m = b/√(a²+b²+c²), n = c/√(a²+b²+c²)
a, b, c એ દિશા અનુપાત છે; l, m, n એ દિશા કોસાઇન છે · SI: એકમરહિત · a² + b² + c² ≠ 0
રેખાનું પ્રમાણિત સમીકરણ (Symmetric Form): (x - x₁)/a = (y - y₁)/b = (z - z₁)/c
(x₁,y₁,z₁) રેખા પરનું એક બિંદુ, a, b, c દિશા અનુપાત · SI: એકમ · a, b, c માંથી કોઈ પણ શૂન્ય ન હોય
રેખાનું સદિશ સમીકરણ: r⃗ = a⃗ + λb⃗
a⃗ = સ્થાન સદિશ (બિંદુ), b⃗ = દિશા સદિશ, λ = અચળાંક · SI: એકમ · રેખા a⃗ પરથી પસાર થાય અને b⃗ દિશામાં હોય
સમતલનું પ્રમાણિત સમીકરણ: ax + by + cz + d = 0
a, b, c એ સમતલના લંબના દિશા અનુપાત છે; d અચળાંક છે · SI: એકમ · a² + b² + c² ≠ 0
સમતલનું નોર્મલ સ્વરૂપ: lx + my + nz = p
l, m, n એ લંબની દિશા કોસાઇન છે; p એ મૂળબિંદુથી લંબ અંતર છે · SI: એકમ · l² + m² + n² = 1, p ≥ 0
ત્રણ બિંદુઓમાંથી સમતલનું સમીકરણ: |x-x₁ y-y₁ z-z₁| / |a(x₂-x₁)+b(y₂-y₁)+c(z₂-z₁)| = 0 (સદિશ રીતે: (r⃗-a⃗)·[(b⃗-a⃗)×(c⃗-a⃗)] = 0)
A, B, C ત્રણ બિંદુઓ છે; r⃗ સમતલ પરનું કોઈ પણ બિંદુ · SI: એકમ · ત્રણેય બિંદુઓ સરરેખીય ન હોય
બે રેખાઓ વચ્ચેનો કોણ: cos θ = |a₁a₂ + b₁b₂ + c₁c₂| / [√(a₁²+b₁²+c₁²) · √(a₂²+b₂²+c₂²)]
a₁,b₁,c₁ અને a₂,b₂,c₂ એ બે રેખાઓના દિશા અનુપાત છે · SI: એકમરહિત · θ નો મૂળભૂત કોણ લેવામાં આવે છે
બે રેખાઓ સમાંતર હોવાની શરત: a₁/a₂ = b₁/b₂ = c₁/c₂
a₁,b₁,c₁ અને a₂,b₂,c₂ દિશા અનુપાત · SI: એકમરહિત · રેખાઓ સમાંતર હોય
બે રેખાઓ લંબ હોવાની શરત: a₁a₂ + b₁b₂ + c₁c₂ = 0
a₁,b₁,c₁ અને a₂,b₂,c₂ દિશા અનુપાત · SI: એકમરહિત · રેખાઓ લંબ હોય
બે સમતલો વચ્ચેનો કોણ: cos θ = |a₁a₂ + b₁b₂ + c₁c₂| / [√(a₁²+b₁²+c₁²) · √(a₂²+b₂²+c₂²)]
a₁,b₁,c₁ અને a₂,b₂,c₂ એ સમતલોના લંબના દિશા અનુપાત છે · SI: એકમરહિત · θ એ સમતલો વચ્ચેનો ન્યૂનતમ કોણ છે
બે સમતલો સમાંતર હોવાની શરત: a₁/a₂ = b₁/b₂ = c₁/c₂
a₁,b₁,c₁ અને a₂,b₂,c₂ સમતલોના લંબના દિશા અનુપાત · SI: એકમરહિત · સમતલો સમાંતર હોય
બે સમતલો લંબ હોવાની શરત: a₁a₂ + b₁b₂ + c₁c₂ = 0
a₁,b₁,c₁ અને a₂,b₂,c₂ સમતલોના લંબના દિશા અનુપાત · SI: એકમરહિત · સમતલો લંબ હોય
બિંદુ-સમતલ લંબ અંતર: d = |ax₁ + by₁ + cz₁ + d| / √(a² + b² + c²)
(x₁,y₁,z₁) બિંદુ; ax + by + cz + d = 0 સમતલ · SI: એકમ · કોઈ પણ બિંદુ અને સમતલ માટે
રેખા-સમતલ કોણ: sin θ = |a₁a + b₁b + c₁c| / [√(a₁²+b₁²+c₁²) · √(a²+b²+c²)]
a₁,b₁,c₁ રેખાના દિશા અનુપાત; a,b,c સમતલના લંબના દિશા અનુપાત · SI: એકમરહિત · θ એ રેખા અને સમતલ વચ્ચેનો કોણ છે
સ્ક્યુ (વિષમ) રેખાઓ વચ્ચેનું લઘુત્તમ અંતર: d = |(b⃗₁ × b⃗₂) · (a⃗₂ - a⃗₁)| / |b⃗₁ × b⃗₂|
r⃗ = a⃗₁ + λb⃗₁ અને r⃗ = a⃗₂ + μb⃗₂ બે સ્ક્યુ રેખાઓ · SI: એકમ · b⃗₁ × b⃗₂ ≠ 0 (રેખાઓ સમાંતર ન હોય)
સ્ક્યુ રેખાઓના લઘુત્તમ અંતરનું સ્કેલર સ્વરૂપ: d = |(x₂-x₁)a + (y₂-y₁)b + (z₂-z₁)c| / √(a²+b²+c²), જ્યાં a,b,c = b⃗₁ × b⃗₂ ના ઘટકો
a⃗₁=(x₁,y₁,z₁), a⃗₂=(x₂,y₂,z₂); b⃗₁=(l₁,m₁,n₁), b⃗₂=(l₂,m₂,n₂) · SI: એકમ · રેખાઓ સમાંતર ન હોય
સમતલીય રેખાઓની શરત: (a⃗₂ - a⃗₁) · (b⃗₁ × b⃗₂) = 0
a⃗₁, a⃗₂ સ્થાન સદિશો; b⃗₁, b⃗₂ દિશા સદિશો · SI: એકમરહિત · બે રેખાઓ સમતલીય હોય
ગોળાનું પ્રમાણિત સમીકરણ: (x - x₁)² + (y - y₁)² + (z - z₁)² = r²
(x₁,y₁,z₁) કેન્દ્ર; r ત્રિજ્યા · SI: એકમ² (વર્ગ) · કોઈ પણ ગોળા માટે
વ્યાસના સિરાંતે ગોળો: (x-x₁)(x-x₂) + (y-y₁)(y-y₂) + (z-z₁)(z-z₂) = 0
(x₁,y₁,z₁) અને (x₂,y₂,z₂) વ્યાસના સિરાંત · SI: એકમ² · આ બે બિંદુઓ વ્યાસ ધરાવતો ગોળો
સામાન્ય ગોળાનું સમીકરણ: x² + y² + z² + 2ux + 2vy + 2wz + d = 0
કેન્દ્ર = (-u, -v, -w); ત્રિજ્યા = √(u²+v²+w²-d) · SI: એકમ² · u²+v²+w²-d ≥ 0

🔗 સંબંધો

  • દિશા કોસાઇન હંમેશા l² + m² + n² = 1 નું પાલન કરે છે, જ્યારે દિશા અનુપાત માટે આવી કોઈ શરત નથી.
  • રેખા અને સમતલ વચ્ચેનો કોણ θ હોય, તો રેખા અને સમતલના લંબ વચ્ચેનો કોણ (90° - θ) હોય છે.
  • બે સ્ક્યુ રેખાઓ વચ્ચેનું લઘુત્તમ અંતર એ એકમાત્ર રેખા છે જે બંને રેખાઓને લંબરૂપે છેદે છે.
  • ખંડસૂત્રમાં m:n = 1:1 મૂકતા મધ્યબિંદુ સૂત્ર મળે છે.
  • રેખાનું પ્રમાણિત સમીકરણ (x-x₁)/a = (y-y₁)/b = (z-z₁)/c માં a, b, c શૂન્ય હોઈ શકે, પરંતુ છેદ શૂન્ય ન હોવો જોઈએ; શૂન્ય હોય તો અંશ શૂન્ય લેવાય.
  • સમતલનું નોર્મલ સ્વરૂપ lx + my + nz = p માં p એ મૂળબિંદુથી સમતલનું લંબ અંતર છે.
  • બે રેખાઓ સમાંતર હોય તો તેમના દિશા અનુપાત સમાન ગુણોત્તરમાં હોય; લંબ હોય તો દિશા અનુપાતોનો ગુણાકાર સરવાળો શૂન્ય થાય.

🎯 ટ્રિક્સ

રેખા-સમતલ કોણ શોધવાનો સૂત્ર cos નહીં sin છે — યાદ રાખો: 'રેખા-સમતલ = sin, સમતલ-સમતલ = cos'.
સ્ક્યુ રેખાઓનું લઘુત્તમ અંતર શૂન્ય હોય તો રેખાઓ સમતલીય થાય — આ શરત તરત યાદ રાખો.
દિશા કોસાઇન શોધવા માટે દિશા અનુપાત (a,b,c) ને √(a²+b²+c²) વડે ભાગો — આ એક જ પગલું છે.
ગોળાના સામાન્ય સમીકરણ x²+y²+z²+2ux+2vy+2wz+d=0 માં કેન્દ્ર (-u,-v,-w) અને ત્રિજ્યા √(u²+v²+w²-d) — u,v,w ના ચિહ્ન ઉલટાવીને કેન્દ્ર મળે.
બે રેખાઓ વચ્ચેનો કોણ શોધતી વખતે |a₁a₂+b₁b₂+c₁c₂| માં નિરપેક્ષ મૂલ્ય લેવાનું ભૂલશો નહીં — આથી કોણ હંમેશા ન્યૂનતમ (0° થી 90°) મળે.
રેખાનું સમીકરણ (x-x₁)/a = (y-y₁)/b = (z-z₁)/c માં જો a=0 હોય તો x=x₁ લખવું, એટલે કે અંશ શૂન્ય.

⚠️ ભૂલો

રેખા-સમતલ કોણના સૂત્રમાં cos નો ઉપયોગ કરવો — સાચું સૂત્ર sin θ = |a₁a+b₁b+c₁c|/(...| છે.
ખંડસૂત્રમાં આંતરિક અને બાહ્ય વિભાજનના સૂત્રો ગૂંચવી ફેરવવા — આંતરિકમાં + અને બાહ્યમાં -.
દિશા અનુપાત (DR) અને દિશા કોસાઇન (DC) વચ્ચેનો તફાવત ન સમજવો — DC માટે l²+m²+n²=1 હોય, DR માટે નહીં.
ગોળાની ત્રિજ્યા શોધતી વખતે √(u²+v²+w²-d) માં d નું ચિહ્ન ભૂલવું અથવા ગણતરીમાં ભૂલ કરવી.
બે સમતલો વચ્ચેના કોણના સૂત્રમાં નિરપેક્ષ મૂલ્ય લેવાનું ભૂલવું, જેથી ઋણ કોણ મળી જાય.
રેખાના પ્રમાણિત સમીકરણમાં છેદ શૂન્ય હોય ત્યારે તેને અવગણી દેવો — છેદ શૂન્ય હોય તો અંશ શૂન્ય લેવો.
સ્ક્યુ રેખાઓના લઘુત્તમ અંતરના સૂત્રમાં (a⃗₂-a⃗₁) ને (b⃗₁×b⃗₂) સાથે ડોટ ગુણાકાર કરવાને બદલે ક્રોસ ગુણાકાર કરી દેવો.
સમતલીય રેખાઓની શરત (a⃗₂-a⃗₁)·(b⃗₁×b⃗₂)=0 માં ડોટ અને ક્રોસ ગુણાકાર ગૂંચવી ફેરવવા.
