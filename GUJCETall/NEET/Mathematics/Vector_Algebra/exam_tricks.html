સદિશ બીજગણિત — GUJCET એક્ઝામ ટ્રિક્સ

🧪 GUJCET — Gujarati • Mathematics • Vector Algebra

🎯 પરીક્ષા ટ્રિક્સ

બે સદિશો અભિલંબ હોય તો તેમનો અદિશ ગુણાકાર શૂન્ય થાય છે: **a·b = 0**. સામેથી વર્ગાકાર કરવાની જરૂર ન પડે.
જ્યારે પ્રશ્નમાં બે સદિશો પરસ્પર લંબ હોય તથા ત્રીજો અજ્ઞાત સદિશ શોધવાનો હોય કે પછી વૈકલ્પિક પ્રશ્નમાંથી સફાઈથી ખુલ્લું વચન મળતું હોય.
દા.ત.: જો **a = î + 2ĵ - k̂** અને **b = 2î - ĵ + k̂**, તો **a·b = 2 - 1 - 1 = 0** → સીધું જ સાબિત થાય કે **a ⟂ b**.
બે સદિશો સમાંતર હોય તો તેમનો સદિશ ગુણાકાર શૂન્ય સદિશ આપે છે: **a × b = 0** (અથવા **|a × b| = 0**).
જ્યારે પરિકલ્પના 'બે સદિશો સમાંતર છે' એમ ચકાસવાનું હોય અથવા V/C પ્રશ્નમાં સમાનતા ચકાસવી હોય.
દા.ત.: **a = 2î + 4ĵ - 6k̂** અને **b = î + 2ĵ - 3k̂** → **a = 2b**, તેથી **a × b = 0**. વૈકલ્પિકમાં આ માત્ર અચળ ગુણાંક તરીકે જોઈને ઉત્તર કાઢી શકાય.
બે સદિશ વચ્ચેનું કોણ શોધવા **cos θ = (a·b) / (|a||b|)** સૂત્ર. GUJCET માં ઘણીવાર **θ = 60°** કે **θ = 90°** આવે છે — અચળ વિકલ્પો દ્વારા તાત્કાલિક ચકાસો.
કોણ શોધતા પ્રશ્નોમાં, ખાસ કરીને જ્યારે વિકલ્પો 30°, 45°, 60°, 90° જેવા પ્રમાણિત કોણો હોય.
દા.ત.: **a = î + ĵ** અને **b = î - ĵ** → **a·b = 1 - 1 = 0** → **cos θ = 0** → **θ = 90°** (કોઈ પણ ગણતરી વિના).
સદિશનો એકમ સદિશ (unit vector) શોધવા: **â = r / |r|**. એટલે કે **r** ને તેના પરિમાણથી ભાગવાથી જ. સીધો સંખ્યાત્મક ભાગલા.
જ્યારે પ્રશ્નમાં 'આપેલ સદિશની દિશામાં એકમ સદિશ શોધો' એવું હોય.
દા.ત.: **r = 3î + 4ĵ** → **|r| = √(9+16) = 5** → **û = (3/5)î + (4/5)ĵ**. 2/3 ની જરૂરિયાત પડે ત્યારે ભાગલા ઘટાડી શકાય.
**a + b** અને **a − b** નો પરિમાણ વર્ગનો સરવાળો: **|a+b|² + |a−b|² = 2(|a|² + |b|²)**. આ રુલ (પેરાલેલોગ્રામ નિયમ) GUJCET માં ઝડપથી ઉકેલ આપે છે.
જ્યારે **|a+b|** અને **|a−b|** નો સંબંધ અથવા **|a|**, **|b|** મેળવવાના હોય.
દા.ત.: જો **|a| = 3**, **|b| = 4** અને **a·b = 0** (અભિલંબ), તો **|a+b| = 5**, **|a−b| = 5**. ચકાસણી: 25 + 25 = 2(9+16) = 50. ✅
**ત્રણ બિંદુઓ A, B, C સરેખ (collinear) હોય** તો **AB** અને **BC** સમાંતર હોય — એટલે **AB × BC = 0**. અથવા **B** એ **AC** ને **m : n** ગુણોત્તરમાં વિભાજિત કરતું બિંદુ. વિભાજન સૂત્ર અહીં વધુ ઝડપી.
સરેખતાની ચકાસણી અથવા સરેખ બિંદુ શોધવાના પ્રશ્નોમાં.
દા.ત.: A(1,2,3), B(2,3,4), C(3,4,5): **AB = î + ĵ + k̂**, **BC = î + ĵ + k̂** → બંને સમાન, તેથી સરેખ. વૈકલ્પિકમાં 'બિંદુઓના x,y,z યામો સમાન અંતરે વધે છે' એમ જોઈને પણ ખૂલે છે.
સદિશ **a** ને સદિશ **b** પર પ્રક્ષેપિત (projection) કરવાનું સૂત્ર: **(a·b / |b|²) · b** અથવા સ્કેલર પ્રક્ષેપ = **|a| cos θ = (a·b)/|b|**. વૈકલ્પિક પ્રશ્નમાં ઘણીવાર સ્કેલર પ્રક્ષેપ જ પૂછાય છે.
જ્યારે પ્રશ્નમાં 'બીજા સદિશ પર પ્રક્ષેપ' પૂછાય, ખાસ કરીને V/C માં અંકગણિત ઓછું કરવાનું હોય.
દા.ત.: **a = 2î + 3ĵ - k̂**, **b = î + ĵ + k̂** → **a·b = 2+3-1 = 4**, **|b| = √3** → સ્કેલર પ્રક્ષેપ = **4/√3**. ગણતરી ઓછી કરીને જવાબ મળે છે.
**દિશા કોસાઇન (Direction Cosines) l, m, n** માટે: **l² + m² + n² = 1**. જો દિશા અનુપાત (D.R.) **a, b, c** આપેલા હોય, તો **l = a/√(a²+b²+c²)**, અને તેમ જ. GUJCET માં D.R. → D.C. બદલવાનું આ પ્રમાણિત રસ્તો.
દિશા અનુપાત થી દિશા કોસાઇન મેળવવા અથવા પરિકલ્પના ચકાસવા.
દા.ત.: D.R. = (1, 2, 2) → |DR| = √(1+4+4) = 3 → D.C. = **(1/3, 2/3, 2/3)**. ચકાસણી: (1/9)+(4/9)+(4/9)=1. ✅
**બે સદિશો વચ્ચેનો લઘુત્તમ કોણ** હંમેશા **[0°, 180°]** વચ્ચે હોય છે. જો **a·b < 0** હોય, તો કોણ **90° < θ ≤ 180°** (સ્પષ્ટપણે મોટો/ઊંઘડો). વૈકલ્પિક જવાબોમાં આ ખ્યાલથી ખોટા વિકલ્પો કાપી શકાય.
જ્યારે **a·b** ઋણ મળે, પણ વિકલ્પોમાં લઘુત્તમ કોણ હોય. તો **θ > 90°** હશે — ગણતરી વગર દિશા નક્કી થાય.
દા.ત.: **a·b = -6**, **|a|=3, |b|=4** → **cos θ = -6/12 = -½** → **θ = 120°**. વૈકલ્પિકમાં 60° ગેરહાજર રાખવું સરળ.
**રેખાના સદિશ સમીકરણ** **r = a + λb** માં **a** = સ્થાન સદિશ (બિંદુ પરથી પસાર થતી), **b** = દિશા સદિશ (રેખાના સમાંતર). GUJCET માં અચૂક યાદ રાખો: **λ = 0** હોય ત્યારે **r = a** એટલે મૂળ બિંદુ.
રેખાના સમીકરણની ચકાસણી અથવા બિંદુ રેખા પર છે કે નહીં તે જાણવા.
દા.ત.: રેખા **r = (î + ĵ) + λ(î - ĵ)**. λ = 1 મૂકતાં **r = 2î**. તપાસ: બિંદુ (2,0) રેખા પર છે. સીધું કામ.
**અદિશ ત્રિકગુણન (Scalar Triple Product) [a b c] = a·(b×c) = 0** હોય તો **ત્રણેય સદિશો સમતલીય (coplanar)** છે. આ પ્રશ્નોમાં **det** શૂન્ય ચકાસવાનું સીધું ઉકેલ છે.
જ્યારે ત્રણ સદિશો સમતલીય છે કે કેમ તે ચકાસવાનું હોય. GUJCET માં આ પ્રકારના પ્રશ્નો વારંવાર આવે છે.
દા.ત.: **a = î**, **b = ĵ**, **c = î + ĵ** → **b×c = k̂ - ĵ** નહીં, બરાબર: **b×c = ĵ×(î+ĵ) = -k̂**, **a·(-k̂) = 0** → સમતલીય. શૂન્ય મળ્યું.
**સદિશ ગુણાકારનો પરિમાણ** **|a × b| = |a||b| sin θ**. જો **θ = 90°** હોય, તો **|a×b| = |a||b|** (એટલે પરિમાણોનો ગુણાકાર). આ ખ્યાલ વિકલ્પો કાપવામાં ખૂબ કામ આવે છે.
જ્યારે સદિશ ગુણાકારનો પરિમાણ પૂછાય અને સદિશો અભિલંબ હોય.
દા.ત.: **|a| = 5**, **|b| = 3**, **a ⟂ b** → **|a×b| = 15**. ગણતરી વિના જવાબ.
**વિભાજન સૂત્ર** (Section formula): **r = (mx₂ + nx₁)/(m+n)**. GUJCET માં **'મધ્યબિંદુ'** એટલે **m:n = 1:1** — સૂત્ર સરળ બને: **(r₁ + r₂)/2**. યાદ રાખો: મધ્યબિંદુ = બે સ્થાન સદિશોનો સરવાળો વડે 2 ભાગતાં.
રેખાખંડનું મધ્યબિંદુ અથવા વિભાજન પ્રશ્નોમાં, ખાસ V/C પ્રશ્નો.
દા.ત.: બિંદુ **A(1,2,3)** અને **B(5,6,7)** નું મધ્યબિંદુ = **((1+5)/2, (2+6)/2, (3+7)/2) = (3, 4, 5)**. સીધું જ દિલમાં.
**ઋણ સદિશ**: **−a** એટલે સમાન પરિમાણ પરંતુ વિપરીત દિશા. સરવાળામાં **a + (−a) = 0**. GUJCET માં આ ગુણધર્મથી **'સદિશ શૂન્ય છે'** તે વૈકલ્પિકમાં તરત જ કાપી શકાય.
જ્યારે વિરુદ્ધ દિશાવાળા સદિશોનો સરવાળો કે બાદબાકી થતી હોય.
દા.ત.: **a = 3î - 2ĵ + k̂** → **−a = -3î + 2ĵ - k̂** → **a + (−a) = 0**. 0 મળે ત્યારે કોઈ પણ વિકલ્પમાં શૂન્ય સદિશ હોય તે ચકાસી શકાય.
**રેખાના પરિમાણ સમીકરણ**માં **r = a + λb** ના **b** ને તમે **b/|b|** (એકમ સદિશ) વડે ડાબે જોવા પણ આપી શકો છો; **λ** એટલે દૂર. GUJCET માં **b** ને સરળ સંખ્યામાં લીધા હોય તો **λ** નો ઉકેલ સરળ બને છે.
પરિમાણ સમીકરણો સરળ બનાવવા અથવા **λ** શોધવાનો પ્રશ્ન.
દા.ત.: રેખા પાસેથી **a = (1,1,1)**, **b = (1,0,0)**. બિંદુ **(2,1,1)** રેખા પર છે કે? → **(2,1,1) = (1,1,1) + λ(1,0,0)** → **λ = 1**. ✅
