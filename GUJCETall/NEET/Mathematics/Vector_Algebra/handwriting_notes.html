સદિશ બીજગણિત — સંપૂર્ણ નોંધ

🧪 GUJCET — Gujarati • Mathematics • Vector Algebra

1. સદિશો — મૂળભૂત પરિભાષા
અદિશ (Scalar): માત્ર મૂલ્ય (magnitude) ધરાવતી ભૌતિક રાશિ. ઉદા. દળ, તાપમાન, સમય, દૂરી.
સદિશ (Vector): માત્ર મૂલ્ય અને દિશા બંને ધરાવતી ભૌતિક રાશિ. ઉદા. વિસ્થાપન, વેગ, પ્રવેગ, બળ.
✅ GUJCET tip: પ્રશ્નમાં 'માત્ર મૂલ્ય' હોય તો અદિશ, 'મૂલ્ય + દિશા' હોય તો સદિશ.
સદિશનું પ્રતીક: AB એક સદિશ → a⃗, b⃗, r⃗, v⃗ વગેરે રૂપે લખાય.
|a⃗| = √(a₁² + a₂² + a₃²) (એકમ સદિશો i⃗, j⃗, k⃗ માં)
📝 → |a⃗| ને 'સદિશનું પરિમાણ' કહે છે.
2. સદિશોના પ્રકારો
સમસદિશ (Zero/Null vector): 0⃗, જેનું પરિમાણ શૂન્ય હોય.
એકમ સદિશ (Unit vector): |û| = 1. û = a⃗ / |a⃗|.
⚠ યાદ રાખો: k⃗ = a⃗/|a⃗| એ a⃗ ની દિશામાં એકમ સદિશ છે.
અભિસારી સદિશો (Collinear vectors): સमान્તર કે એક જ રેખા પર આવેલા સદિશો. a⃗ = λb⃗, λ ∈ R.
સમવિભાજી સદિશો (Co-initial vectors): એક જ શરૂઆતબિંદુ (initial point) ધરાવતા.
અસહભાજી સદિશો (Non-coplanar): ત્રણેય સદિશો એક જ સમતલમાં ન હોય.
ધન દિશા વાળો એકમ સદિશો: î = (1,0,0), ĵ = (0,1,0), k̂ = (0,0,1).
î · î = ĵ · ĵ = k̂ · k̂ = 1 , î · ĵ = ĵ · k̂ = k̂ · î = 0
📝 → î, ĵ, k̂ એકબીજાને લંબ છે.
3. સદિશોનો સરવાળો
ત્રિકોણ નિયમ (Triangle Law): AB⃗ + BC⃗ = AC⃗.
ચતુર્ભુજ નિયમ (Parallelogram Law): જો a⃗, b⃗ બાજુઓ હોય તો પરિણામી વિકર્ણ = a⃗ + b⃗.
✅ સદિશ સરવાળો ક્રમપરવર્તી (Commutative): a⃗ + b⃗ = b⃗ + a⃗
(a⃗ + b⃗) + c⃗ = a⃗ + (b⃗ + c⃗) (સહજાતી નિયમ)
વ્યસ્ત સદિશ (Negative vector): –a⃗, |a⃗| જોઈએ પણ વિરુદ્ધ દિશા.
a⃗ + (–a⃗) = 0⃗
📝 → સદિશ બાદબાકી: a⃗ – b⃗ = a⃗ + (–b⃗)
4. સદિશનું અદિશથી ગુણાકાર
જો λ ∈ R હોય તો λa⃗ એ સદિશ a⃗ નો λ ગણો છે.
|λa⃗| = |λ| · |a⃗|
λ > 0: દિશા એવી જ; λ < 0: દિશા ઉલટાવી; λ = 0: 0⃗.
⚠ λa⃗ = μb⃗ ⇒ a⃗ અને b⃗ અભિસારી (collinear).
મૂળભૂત નિયમો: (λμ)a⃗ = λ(μa⃗); (λ+μ)a⃗ = λa⃗ + μa⃗; λ(a⃗+b⃗) = λa⃗ + λb⃗.
📝 → આ સરવાળાના નિયમો અદિશ સાથેના સમાન છે.
5. સદિશોના ઘટકો (Components)
P(x, y, z) બિંદુ માટે સ્થતિ સદિશ: r⃗ = xi⃗ + yĵ + zk⃗.
r⃗ = xî + yĵ + zk̂ ; |r⃗| = √(x²+y²+z²)
બે બિંદુઓ P(x₁,y₁,z₁) અને Q(x₂,y₂,z₂) વચ્ચેનો સદિશ:
PQ⃗ = (x₂–x₁)î + (y₂–y₁)ĵ + (z₂–z₁)k̂
✅ PQ⃗ = OQ⃗ – OP⃗ (સ્થતિ સદિશોના તફાવત તરીકે)
સદિશના દિગંશાંકો: l = cosα, m = cosβ, n = cosγ, l²+m²+n²=1.
a⃗ = |a⃗|(lî + mĵ + nk̂) = |a⃗|·â
📝 → α, β, γ એ x, y, z અક્ષો સાથેના ખૂણા છે.
6. રેખાખંડનું વિભાજન (Section Formula)
P એ PQ ને m:n ના ગુણોત્તરમાં વિભાજે છે.
r⃗ = (n·a⃗ + m·b⃗)/(m+n) (આંતર વિભાજન)
r⃗ = (m·b⃗ – n·a⃗)/(m–n) (બહિર્ વિભાજન)
⚠ આંતર વિભાજન: + chihna; બહિર્ વિભાજન: – chihna.
મધ્યબિંદુ: r⃗ = (a⃗ + b⃗)/2
📝 → GUJCET માં 'm:n' ગુણોત્તર સાથે સ્પષ્ટ પ્રશ્નો આવે છે.
7. ડોટ ગુણાકાર (Scalar Product)
a⃗ · b⃗ = |a⃗||b⃗| cos θ, θ = બંને વચ્ચેનો ખૂણો, 0 ≤ θ ≤ π.
a⃗ · b⃗ = a₁b₁ + a₂b₂ + a₃b₃
✅ પરિણામ હંમેશા અદિશ (Scalar) જ હોય છે.
a⃗ · a⃗ = |a⃗|².
cos θ = (a⃗ · b⃗) / (|a⃗| · |b⃗|)
લંબતા (Projection): a⃗ નો b⃗ પર સમગ્ર પ્રક્ષેપ = (a⃗·b⃗)/|b⃗|.
a⃗ ⊥ b⃗ ⇒ a⃗ · b⃗ = 0.
📝 → GUJCET માં 'લંબરૂપે' શબ્દ આવે તો ડોટ ગુણાકાર શૂન્ય.
8. સદિશ ગુણાકાર (Cross Product)
a⃗ × b⃗ = |a⃗||b⃗| sin θ · n̂, n̂ એ a⃗ અને b⃗ ના સમતલને લંબ એકમ સદિશ.
a⃗ × b⃗ = |î ĵ k̂| |a₁ a₂ a₃| |b₁ b₂ b₃|
⚠ n̂ એ a⃗ થી b⃗ તરફ જમણા હાથના નિયમ (right-hand rule) અનુસાર.
a⃗ × b⃗ = – (b⃗ × a⃗) (ક્રમ બદલાય તો ચિહ્ન ઉલટાવે).
a⃗ ∥ b⃗ ⇒ a⃗ × b⃗ = 0⃗.
|a⃗ × b⃗| = |a⃗||b⃗| sin θ = ત્રિકોણનું ક્ષેત્રફળ × 2
त्रिकोણ ABC નું ક્ષેત્રફળ = ½ |AB⃗ × AC⃗|
સમાંતરબાજુ ચતુષ્ફલન = |a⃗ × b⃗|
📝 → i×j=k, j×k=i, k×i=j; i×i=j×j=k×k=0.
9. ડોટ અને ક્રૉસ ઉಭય સંબંધ
જો a⃗·b⃗ = 0 અને a⃗×b⃗ ≠ 0⃗, તો બંને લંબ છે.
a⃗·(b⃗×c⃗) = (a⃗×b⃗)·c⃗ (મિશ્ર ગુણાકારનો ગુણધર્મ).
✅ સદિશ ગુણાકારનો ઉત્પાદ ત્યાં સુધી અશૂન્ય જ્યારે θ ≠ 0, π.
📝 → જો a⃗×b⃗ = 0 હોય, તો a⃗, b⃗ અભિસારી.
10. ત્રિગુણ ગુણાકારો (Triple Products)
અદિશ ત્રિગુણ: [a⃗ b⃗ c⃗] = a⃗ · (b⃗ × c⃗) = અદિશ.
[a⃗ b⃗ c⃗] = [b⃗ c⃗ a⃗] = [c⃗ a⃗ b⃗]
દિશા બદલાય તો ચિહ્ન ઉલટાવે: [a⃗ c⃗ b⃗] = –[a⃗ b⃗ c⃗].
[a⃗ b⃗ c⃗] = શૂન્ય જો આ ત્રણેય સહસમતલીય (coplanar) હોય.
સદિશ ત્રિગુણ: a⃗ × (b⃗ × c⃗) = (a⃗·c⃗)b⃗ – (a⃗·b⃗)c⃗.
a⃗ × (b⃗ × c⃗) = (a⃗·c⃗) b⃗ – (a⃗·b⃗) c⃗ (BAC – CAB નિયમ)
⚠ (a⃗×b⃗)×c⃗ ≠ a⃗×(b⃗×c⃗) (ક્રમ મહત્વનો!)
📝 → GUJCET માં ત્રિગુણ સંબંધો પર સીધા પ્રશ્નો આવે છે.
11. સહસમતલીયતા (Coplanarity)
ત્રણ સદિશો સહસમતલીય જો: [a⃗ b⃗ c⃗] = 0.
chāર sદિશો સહસમતલીય જો [a⃗ b⃗ c⃗] = 0 હોય.
α(a⃗×b⃗) + β(b⃗×c⃗) + γ(c⃗×a⃗) = 0⃗ (જો a,b,c સહસમતલીય હોય)
✅ GUJCET tip: [a b c] = 0 મેળવવું એ સાબિતી માટે પૂરતું.
📝 → બિંદુઓ A,B,C,D સહસમતલીય જો AB, AC, AD સહસમતલીય હોય.
12. એકમ સદિશોના ગુણાકારો
î×ĵ=k̂, ĵ×k̂=î, k̂×î=ĵ.
ĵ×î=–k̂, k̂×ĵ=–î, î×k̂=–ĵ.
î·î=ĵ·ĵ=k̂·k̂=1; î·ĵ=ĵ·k̂=k̂·î=0.
⚠ k̂ = î × ĵ — યાદ રાખો! (જમણા હાથના નિયમ)
📝 → આ નિયમોથી ક્રૉસ ગુણાકારની ગણતરી ઝડપી થાય.
13. સદિશોનું અવકલન (Differentiation)
જો r⃗(t) = x(t)î + y(t)ĵ + z(t)k̂ હોય, તો dr⃗/dt = dx/dt î + dy/dt ĵ + dz/dt k̂.
d/dt (a⃗ + b⃗) = da⃗/dt + db⃗/dt
d/dt (λ(t) · b⃗(t)) = λ'(t)·b⃗ + λ(t)·b⃗'
d/dt (a⃗ · b⃗) = a⃗'·b⃗ + a⃗·b⃗'.
d/dt (a⃗ × b⃗) = a⃗' × b⃗ + a⃗ × b⃗'.
✅ GUJCET tip: a⃗(t)·a⃗(t) = constant ⇒ a⃗·a⃗' = 0 ⇒ a⃗ ⊥ a⃗'.
📝 → વેગ v⃗ = dr⃗/dt; પ્રવેગ a⃗ = dv⃗/dt.
14. સદિશોનું સંકલન (Integration)
∫ r⃗ dt = ∫x(t)dt î + ∫y(t)dt ĵ + ∫z(t)dt k̂.
∫ (a⃗ ± b⃗) dt = ∫a⃗ dt ± ∫b⃗ dt
∫ λ(t)·b⃗(t) dt = λ(t) ∫b⃗ dt – ∫λ'(t)·(∫b⃗ dt) dt (ઉપરાંત કિસ્સા)
✅ સંકલન એ ઘટકોની દિશામાં વ્યક્તિગત કરવું.
📝 → ∫₀ᵗ r⃗(τ)dτ એ સ્થાનાંતર.
15. મહત્વના નિયમો અને પરિણામો
a⃗ · (b⃗ + c⃗) = a⃗·b⃗ + a⃗·c⃗ (સંકલનશીલ).
a⃗ × (b⃗ + c⃗) = a⃗×b⃗ + a⃗×c⃗ (સંકલનશીલ).
a⃗ × (b⃗ × c⃗) ≠ (a⃗ × b⃗) × c⃗.
જો a⃗ × b⃗ = a⃗ × c⃗ તો b⃗ = c⃗ હોવું જોઈએ એ જરૂરી નથી — b⃗ અને c⃗ અભિસારી પણ હોઈ શકે.
⚠ a×b = a×c ≠ b=c, પણ b=c ⇒ a×b=a×c.
(a⃗+b⃗)² = a⃗² + b⃗² + 2a⃗·b⃗
|a⃗ × b⃗|² + |a⃗ · b⃗|² = |a⃗|² |b⃗|²
📝 → બીજું સૂત્ર લેઈબ્નીઝ સૂત્ર તરીકે ઓળખાય.
16. ભૂલો અને સાવચેતી (Common Pitfalls)
સદિશ ભાગાકાર અઅર્થપૂર્ણ છે (a⃗/b⃗ = શક્ય નથી).
a⃗×b⃗ = 0⃗ ≠ બંને શૂન્ય હોવા જોઈએ — માત્ર સમાંતરતા જ સૂચવે.
(a⃗×b⃗)×c⃗ = a⃗×(b⃗×c⃗) — અસત્ય!
⚠ ક્રમ બદલવાથી સદિશ ગુણાકાર બદલાય છે — ક્રમ ધ્યાનથી.
a⃗·b⃗ = a⃗·c⃗ ⇒ b⃗ = c⃗ નથી. (અદિશ ગુણાકાર 'રદ' કરી શકાતો નથી).
📝 → GUJCET માં આ ભૂલો પ્રશ્નોમાં છુપાયેલી હોય છે.
17. વ્યાવહારિક ઉપયોગ (Applications)
કાર્ય (Work): W = F⃗ · d⃗ = |F⃗||d⃗|cosθ.
ટૉર્ક (Torque): τ⃗ = r⃗ × F⃗.
બિંદુ-રેખા અંતર: |PQ⃗ × â| જ્યાં â એકમ સદિશ છે.
બે સરળ રેખાઓનું લઘુત્તમ અંતર (Shortest distance):
d = |((b⃗–a⃗)·(n̂))|, n̂ = (b₁⃗ × b₂⃗)/|b₁⃗ × b₂⃗|
✅ સમતલીય રેખાઓ માટે (b⃗–a⃗)·(b₁⃗×b₂⃗) = 0.
📝 → સમતલીય શબ્દનો અર્થ: [b⃗–a⃗, b₁⃗, b₂⃗] = 0.
18. સંકલન અને પ્રસಾರ (Vector Expansion)
a⃗ = a₁î + a₂ĵ + a₃k̂.
બે સદિશોનો સરવાળો: a⃗ + b⃗ = (a₁+b₁)î + (a₂+b₂)ĵ + (a₃+b₃)k̂.
અંતર: |a⃗ – b⃗| = √[(a₁–b₁)²+(a₂–b₂)²+(a₃–b₃)²].
✅ અંતર એ Sદિશ અવકલન (distance formula) છે.
📝 → જ્યારે t=0 હોય ત્યારે પ્રારંભિક સ્થાન.
19. નિયમોની તુલના
અદિશ ગુણાકારઅદિશ મળે છે; ક્રમસ્વાધીન (commutative).
સદિશ ગુણાકારસદિશ મળે છે; ક્રમ-બદલે છે (anti-commutative).
ડોટ ગુણાકારઉપયોગ: કાર્ય, પ્રક્ષેપ, ખૂણો શોધવો.
ક્રૉસ ગુણાકારઉપયોગ: ટૉર્ક, લંબાઈ, સમતલ શોધવો.
અદિશ ત્રિગુણઘનફળ = |a⃗·(b⃗×c⃗)|.
સદિશ ત્રિગુણસમાંતરબાજુ ઘનનું ઘનફળ.
📝 → બંનેનો ઉપયોગ ભૌતિકશાસ્ત્રમાં વધુ થાય છે.
