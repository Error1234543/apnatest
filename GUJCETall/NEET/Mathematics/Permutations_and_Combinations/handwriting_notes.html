ક્રમચય અને સંચય (Permutations and Combinations)

🧪 GUJCET — Gujarati • Mathematics • Permutations and Combinations

૧. પ્રસ્તાવના (Introduction)
ગણતરીમાં બે મુખ્ય પદ્ધતિઓ છે — ક્રમચય (Permutation) અને સંચય (Combination). બંને રીતે આપણે વસ્તુઓની ગોઠવણી કે પસંદગી કરીએ છીએ.
મૂળભૂત તફાવત: ક્રમચયમાં 'ક્રમ' (order) મહત્વનો છે, જ્યારે સંચયમાં ક્રમ જરૂરી નથી.
મૂળભૂત ગણતરીનો નિયમ: જો કાર્ય A માં m અને B માં n રીતો હોય, તો A અને B એકસાથે કરવાની રીતો = m × n
📝 📌 યાદ રાખો: 'ગોઠવણી' → ક્રમચય, 'પસંદગી' → સંચય
૨. ફેક્ટોરિયલ (Factorial)
ધન પૂર્ણાંક n માટે n! (n ફેક્ટોરિયલ) એ 1 થી n સુધીના તમામ પૂર્ણાંકોનો ગુણાકાર છે.
n! = n × (n−1) × (n−2) × ... × 3 × 2 × 1
ઉદા. 5! = 5 × 4 × 3 × 2 × 1 = 120
0! = 1 (શૂન્ય ફેક્ટોરિયલની કિંમત 1 લેવામાં આવે છે) — આનો ઉપયોગ વધુ પછી થશે.
(n+1)! = (n+1) × n! — આ ગુણધર્મ ઉપયોગી છે.
n! / (n−1)! = n
📝 ⚠️ 0! = 1 એ વ્યાખ્યા છે, ગણતરી કરી શકાતું નથી. યાદ રાખવું!
૩. ક્રમચય (Permutation)
જ્યારે n વસ્તુઓમાંથી r વસ્તુઓની ચોક્કસ ક્રમમાં ગોઠવણી કરવાની હોય ત્યારે તેને 'નું r ક્રમચય' કહે છે.
nP_r = n! / (n−r)! જ્યાં 0 ≤ r ≤ n
ઉદા. 5 વસ્તુઓમાંથી 3 ની ગોઠવણી: 5P_3 = 5!/2! = 60
nP_n = n! (સभी વસ્તુઓની ગોઠવણી).nP_0 = 1
ક્રમચયમાં ગોઠવણીનો ક્રમ મહત્વનોAB ≠ BA — બંને અલગ ગોઠવણી ગણાય
📝 📌 n > r હોવું જ જોઈએ; જો n < r, તો nP_r = 0
૪. ક્રમચયના ગુણધર્મો (Properties of Permutation)
nP_r = n × (n−1)P_{r−1}
nP_r = nC_r × rP_r = nC_r × r!
ઉપરનું સૂત્ર સૂચવે છે: r કણ પસંદ કરીને તેમની ગોઠવણી કરવી = પહેલા પસંદગી + પછી ગોઠવણી
જો કોઈ ચોક્કસ વસ્તુ હંમેશા હાજર હોય → (n−1)P_{r−1} રીતો
જો કોઈ ચોક્કસ વસ્તુ હંમેશા નામંજૂર હોય → (n−1)P_r રીતો
📝 📌 ક્રમચય ગુણધર્મો યાદ રાખો — પ્રશ્નમાં સીધો ઉપયોગ થાય છે!
૫. પુનરાવર્તન સાથે ક્રમચય (Permutation with Repetition)
જ્યારે દરેક વસ્તુને પુનઃપ્રયોગ કરી શકાય (દા.ત. PIN કોડ, લોકનાંબર), ત્યારે ગણતરી અલગ હોય છે.
r સ્થાનો પર n વસ્તુઓનો પુનરાવર્તન સાથે ક્રમચય = n^r
ઉદા. 3 અંકોમાંથી 2-અંકનો કોડ બનાવવો (અંક પુનરાવર્તી શકે) → 3² = 9 રીતો
નોંધ: આમાં કોઈ પણ વસ્તુ વારંવાર પસંદ થઈ શકે છે — પ્રશ્ન જો પુછે તો જ આનો ઉપયોગ કરવો!
📝 ⚠️ સામાન્ય nP_rમાં વસ્તુ પુનરાવર્તી શકતી નથી. તફાવત ધ્યાનમાં રાખો.
૬. ક્રમચયની વિશેષ પરિસ્થિતિઓ
સામૂહિક રીતે ક્રમચય: r1 સમાન વસ્તુઓ, r2 સમાન, ..., rk સમાન — કુલ n = r1+r2+...+rk
કુલ ગોઠવણીઓ = n! / (r1! × r2! × ... × rk!)
ઉદા: 'MISSISSIPPI' શબ્દની ગોઠવણીઓ: 11!/(4!×4!×2!×1!)
વર્તુળાકાર ગોઠવણી (Circular Permutation): n વસ્તુઓ વર્તુળમાં ગોઠવવાની રીતો = (n−1)!
વર્તુળાકાર ગોઠવણીમાં દિશા વિચારણા: જમણી/ ડાબી દિશા ભેદરહિત હોય → (n−1)!/2
સરળ રેખીય ગોઠવણીવર્તુળાકાર ગોઠવણી (n−1)! યાદ રાખો
📝 📌 પુનરાવર્તન સાથે વર્તુળાકાર ગોઠવણી → (n−1)!/(r1!×r2!×...)
૭. સંચય (Combination)
જ્યારે n વસ્તુઓમાંથી r વસ્તુઓની પસંદગી કરવી હોય અને ક્રમ જરૂરી ન હોય, ત્યારે તેને 'સંચય' કહે છે.
nC_r = n! / [ r! × (n−r)! ] જ્યાં 0 ≤ r ≤ n
ઉદા. 5 વસ્તુઓમાંથી 3 પસંદ કરવા: 5C_3 = 10 રીતો
nC_r માં પસંદગીનો ક્રમ લાગે નહીં — AB = BA (એક જ સંચય ગણાય)
nC_r = nC_{n−r} (સંમિતિ ગુણધર્મ)
nP_r = nC_r × r!સંચય × ક્રમચય = કુલ ગોઠવણીઓ
📝 📌nC_0 = 1, nC_n = 1 — બંને યાદ રાખો
૮. ક્રમચય અને સંચય વચ્ચેનો સંબંધ
nP_r = nC_r × rP_r એ સંબંધનો મુખ્ય સૂત્ર છે
nC_r = nP_r / r!
આ સંબંધ સમજવો મહત્વનો છે: r વસ્તુઓ પસંદ કરીને ગોઠવવી = પહેલા પસંદગી (nC_r) + પછી ગોઠવણી (rP_r)
ઉદા. 5vસ્તુઓમાંથી 3 ની પસંદગી અને ગોઠવણી: 5C_3 × 3! = 10 × 6 = 60 = 5P_3
જે પ્રશ્નમાં 'ચુનવણી' શબ્દ આવે → સંચય; 'ગોઠવણી' આવે → ક્રમચય
૯. સંચયના ગુણધર્મો (Properties of Combination)
nC_r = nC_{n−r} (સંમિતિ)
nC_r + nC_{r+1} = n+1C_{r+1} (પાસ્કલનો નિયમ — બહુ મહત્વનો!)
nC_0 + nC_1 + ... + nC_n = 2^n
સમાન સૂચકાંકોનો સરવાળો: nC_0 + nC_2 + nC_4 + ... = 2^{n−1}
વિષમ સૂચકાંકોનો સરવાળો: nC_1 + nC_3 + nC_5 + ... = 2^{n−1}
પાસ્કલનો નિયમ: C(n,r)+C(n,r+1)=C(n+1,r+1) — દ્વિપદી પ્રમેયમાં પણ સીધો ઉપયોગ
📝 📌 2^n અને 2^{n−1} વચ્ચેનો તફાવત યાદ રાખવો!
૧૦. ખૂબ જ મહત્વપૂર્ણ પરિણામો (Important Results)
કુલ સંચય: n વસ્તુઓમાંથી કોઈ પણ રકમ પસંદ કરવાની કુલ રીતો = 2^n − 1 (શૂન્ય ટાળીને)
ન્યૂનતમ 1 અને મહત્તમ n−1 વસ્તુઓ પસંદ કરવાની રીતો = 2^n − 2
nP_r = r! × nC_r એ સંબંધ વારંવાર ઉપયોગી થાય છે
જો k < l, તો કદ મહત્તમ: nC_k ≤ nC_l ત્યારે જ જ્યારે k= l
kC_k = 1દરેક સંચય ગુણધર્મ યાદ રાખવો
📝 📌 nC_k એટલે જ કિસ્સામાં nC_{n−k} સાથે સરખાવવું.
૧૧. સામાન્ય પ્રકારના પ્રશ્નો — ઉકેલ પદ્ધતિ
પ્રકાર 1: વસ્તુઓની ચોક્કસ પસંદગી — સીધો nC_r
પ્રકાર 2: કેટલાક ચોક્કસ ઘટકો હંમેશા હાજર — (n−m)C_{r−m}
પ્રકાર 3: કેટલાક ચોક્કસ ઘટકો હંમેશા નામંજૂર — (n−m)C_r
પ્રકાર 4: કેટલાક ચોક્કસ ઘટકો સાથે જ હોય — (n−m)C_r (ચુકરેલી વસ્તુઓ ગણીએ)
પ્રકાર 5: ઓછામાં ઓછા A અને વધુમાં વધુ B — બહુપદી પદ્ધતિ
પ્રશ્ન વાંચો → નક્કી કરો: ક્રમચય કે સંચય? → સૂત્ર લાગુ પાડો
📝 📌 ધ્યાન રાખો: 'ચુનવણી', 'સમૂહ', 'કમિટી' → સંચય; 'વ્યવસ્થા', 'પોઝિશન', 'લાઇન' → ક્રમચય
૧૨. દ્વિપદી પ્રમેય સાથે સંબંધ
દ્વિપદી પ્રમેયના સહગુણકો સંચય છે: (x+y)^n = Σ nC_r x^{n−r} y^r
(1+x)^n = nC_0 + nC_1 x + nC_2 x² + ... + nC_n x^n
વૈકલ્પિક ઉત્પાદન: C(n,k) = n!/k!(n−k)! જે nP_k / k! સમાન છે

📝 📌 દ્વિપદી સહગુણકોના ગુણધર્મો સંચયના ગુણધર્મો જ છે.
