⚡ સૂત્રો

નિશ્ચિત સંકલન દ્વારા વક્ર નીચેનું ક્ષેત્રફળ (y = f(x)): A = ∫ₐᵇ f(x) dx, જો f(x) ≥ 0 on [a, b]
A = ક્ષેત્રફળ, f(x) = વક્રનું ફંક્શન, a અને b = x-અક્ષ પરના સીમાબિંદુઓ · SI: વર્ગ એકમ (sq. units) · જ્યારે વક્ર x-અક્ષની ઉપર હોય અને લંબ રેખા x = a, x = b અને x-અક્ષ વડે ઘેરાયેલ વિસ્તાર મેળવવાનો હોય.
ઋણ વિસ્તારનું સંભાળ (f(x) ≤ 0): A = |∫ₐᵇ f(x) dx| = −∫ₐᵇ f(x) dx, જો f(x) ≤ 0 on [a, b]
A = ધન ક્ષેત્રફળ, ∫ₐᵇ f(x) dx = ઋણ મૂલ્ય આપે તેથી ક્ષેત્રફળ શૂન્ય કરવા માટે નીચેનો ચિહ્ન બદલવો. · SI: વર્ગ એકમ · જ્યારે વક્ર x-અક્ષની નીચે હોય.
y-અક્ષની સાપેક્ષે ક્ષેત્રફળ (x = g(y)): A = ∫꜀ᵈ g(y) dy, જો g(y) ≥ 0 on [c, d]
c, d = y-અક્ષના સીમાબિંદુઓ, g(y) = y-અક્ષની સાપેક્ષે x નું ફંક્શન · SI: વર્ગ એકમ · જ્યારે વક્રને y-અક્ષની સાપેક્ષે વ્યાખ્યાયિત કરવામાં આવ્યો હોય અથવા સંકલન y-દિશામાં સરળ હોય.
સીધી રેખા y = mx + c નીચેનું ક્ષેત્રફળ: A = ∫ₐᵇ (mx + c) dx = [m·x²/2 + c·x]ₐᵇ
m = ઢાળ, c = y-ઇન્ટરસેપ્ટ, a, b = x-સીમાઓ · SI: વર્ગ એકમ · y = mx + c એ સીધી રેખા છે અને a ≤ x ≤ b પર f(x) ≥ 0.
ઉત્પરવળય (Parabola) y² = 4ax નીચેનું ક્ષેત્રફળ (x = 0 થી x = h): A = ∫₀ʰ y dx = ∫₀ʰ 2√(ax) dx = (4/3)a¹ᐟ²·h³ᐟ²
a = ઉત્પરવળયનો પ્રાચલ, h = x-સીમા, y = 2√(ax) · SI: વર્ગ એકમ · ઉત્પરવળય y² = 4ax, x-અક્ષની ઉપરનો ભાગ (y ≥ 0), x = 0 થી x = h સુધી.
વૃત્ત x² + y² = r² ના ચતુર્થાંશનું ક્ષેત્રફળ: A = ∫₀ʳ √(r² − x²) dx = πr²/4
r = ત્રિજ્યા, √(r² − x²) = ઉપરનો અર્ધવૃત્તાકાર ભાગ · SI: વર્ગ એકમ · પહેલા ચતુર્થાંશમાં (x ≥ 0, y ≥ 0). પૂર્ણ વૃત્તનું ક્ષેત્રફળ πr².
પૂર્ણ વૃત્તનું ક્ષેત્રફળ સંકલન દ્વારા: A = 2∫₋ᵣʳ √(r² − x²) dx = πr²
r = ત્રિજ્યા, સંકલન ઉપર અને નીચેના અર્ધવૃત્તને 합算 કરે છે · SI: વર્ગ એકમ · વૃત્ત x² + y² = r² માટે.
વૃત્તચક્ર (Ellipse) x²/a² + y²/b² = 1 નું ક્ષેત્રફળ: A = ∫₋ₐᵃ b√(1 − x²/a²) dx = πab
a = અર્ધ-મહાન અક્ષ, b = અર્ધ-લઘુઅક્ષ, √(1 − x²/a²) = ઉત્પન્ન થયેલ y · SI: વર્ગ એકમ · વૃત્તચક્રનું પૂર્ણ ક્ષેત્રફળ. જો a = b તો વૃત્ત બને અને A = πa².
ઉત્પરવળય y² = 4ax અને સીધી રેખા x = h વડે ઘેરાયેલ ક્ષેત્રફળ: A = ∫₀ʰ (y_upper − y_lower) dx = ∫₀ʰ 2√(ax) dx × 2 (પૂર્ણ) = (4/3)√a · h³ᐟ² × 2 = (8/3)√a · h³ᐟ²
y_upper = 2√(ax), y_lower = −2√(ax), x = h એ উભી રેખા · SI: વર્ગ એકમ · ઉત્પરવળય અને ઉભી રેખા x = h વડે ઘેરાયેલ ક્ષેત્રફળ.
બે વક્રો વચ્ચેનું ક્ષેત્રફળ (x-અક્ષ પર): A = ∫ₐᵇ [f(x) − g(x)] dx, જો f(x) ≥ g(x) ≥ 0 on [a, b]
f(x) = ઉપરનો વક્ર, g(x) = નીચેનો વક્ર, a, b = છેદનબિંદુઓના x-મૂલ્યો · SI: વર્ગ એકમ · બે વક્રોના છેદનબિંદુઓ a અને b હોય અને [a, b] પર f(x) ≥ g(x).
બે વક્રો વચ્ચેનું ક્ષેત્રફળ — ચિહ્ન પર ધ્યાન: A = ∫ₐᵇ |f(x) − g(x)| dx
|f(x) − g(x)| = વક્રો વચ્ચેનું લંબ અંતર, સદિશ અથવા ધન ક્ષેત્રફળ આપે છે · SI: વર્ગ એકમ · જ્યારે વક્રો [a, b] પર એકબીજાને છેદતા હોય અથવા ચિહ્ન બદલતા હોય; ત્યારે અલગ અલગ સંકલન કરવું પડે.
બે વક્રો વચ્ચેનું ક્ષેત્રફળ — y-અક્ષ પર (x = g(y), x = h(y)): A = ∫꜀ᵈ |g(y) − h(y)| dy, જો g(y) ≥ h(y) on [c, d]
g(y) = જમણો વક્ર, h(y) = ડાબો વક્ર, c, d = છેદનબિંદુઓના y-મૂલ્યો · SI: વર્ગ એકમ · જ્યારે સંકલન y-અક્ષની દિશામાં કરવું સરળ હોય.
યોગ્ય (Standard) સંકલન ફોર્મ્યુલા — ઘાતાંક નિયમ: ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C, જો n ≠ −1; ∫ x⁻¹ dx = ln|x| + C
n = કોઈ પણ વાસ્તવિક સંખ્યા, C = સંકલન અચળાંક · SI: N/A · n ≠ −1 હોય તો ઘાતાંક નિયમ લાગુ; n = −1 હોય તો લઘુગુણક ફોર્મ્યુલા લાગુ.
ત્રિકોણમિતીય સંકલન — sin(ax): ∫ sin(ax) dx = −cos(ax)/a + C
a = અચળાંક, x = ચલ, C = સંકલન અચળાંક · SI: N/A · સામાન્ય સંકલન.
ત્રિકોણમિતીય સંકલન — cos(ax): ∫ cos(ax) dx = sin(ax)/a + C
a = અચળાંક, x = ચલ · SI: N/A · સામાન્ય સંકલન.
ત્રિકોણમિતીય સંકલન — sec²(ax): ∫ sec²(ax) dx = tan(ax)/a + C
a = અચળાંક · SI: N/A · સામાન્ય સંકલન.
ત્રિકોણમિતીય સંકલન — cosec²(ax): ∫ cosec²(ax) dx = −cot(ax)/a + C
a = અચળાંક · SI: N/A · સામાન્ય સંકલન.
ત્રિકોણમિતીય સંકલન — sec(ax)tan(ax): ∫ sec(ax)tan(ax) dx = sec(ax)/a + C
a = અચળાંક · SI: N/A · સામાન્ય સંકલન.
ત્રિકોણમિતીય સંકલન — cosec(ax)cot(ax): ∫ cosec(ax)cot(ax) dx = −cosec(ax)/a + C
a = અચળાંક · SI: N/A · સામાન્ય સંકલન.
ઘાતાંક સંકલન — e^(ax): ∫ e^(ax) dx = e^(ax)/a + C
a = અચળાંક · SI: N/A · સામાન્ય સંકલન.
ઘાતાંક સંકલન — a^(kx): ∫ a^(kx) dx = a^(kx)/(k·ln a) + C
a > 0, a ≠ 1, k = અચળાંક, ln a = પ્રાકૃતિક લઘુગુણક · SI: N/A · સામાન્ય સંકલન.
વ્યસ્ત ત્રિકોણમિતીય — ∫ 1/√(a² − x²) dx: ∫ 1/√(a² − x²) dx = arcsin(x/a) + C = sin⁻¹(x/a) + C
a > 0, |x| < a · SI: N/A · વર્ગમૂળ ધરાવતા છેદમાં.
વ્યસ્ત ત્રિકોણમિતીય — ∫ 1/(a² + x²) dx: ∫ 1/(a² + x²) dx = (1/a)·arctan(x/a) + C = (1/a)·tan⁻¹(x/a) + C
a > 0 · SI: N/A · વર્ગોનો સરવાળો છેદમાં.
વ્યસ્ત ત્રિકોણમિતીય — ∫ 1/(x√(x² − a²)) dx: ∫ 1/(x√(x² − a²)) dx = (1/a)·arcsec(|x|/a) + C = (1/a)·sec⁻¹(|x|/a) + C
a > 0, |x| > a · SI: N/A · વર્ગમૂળમાં vargo nu antar હોય.
વર્ગમૂળ સંકલન — ∫ √(a² − x²) dx: ∫ √(a² − x²) dx = (x/2)√(a² − x²) + (a²/2)·arcsin(x/a) + C
a > 0, |x| ≤ a · SI: N/A · વૃત્તના ક્ષેત્રફળ મેળવવા માટે મહત્ત્વનું.
વર્ગમૂળ સંકલન — ∫ √(x² + a²) dx: ∫ √(x² + a²) dx = (x/2)√(x² + a²) + (a²/2)·ln|x + √(x² + a²)| + C
a > 0 · SI: N/A · સામાન્ય સંકલન.
વર્ગમૂળ સંકલન — ∫ √(x² − a²) dx: ∫ √(x² − a²) dx = (x/2)√(x² − a²) − (a²/2)·ln|x + √(x² − a²)| + C
a > 0, |x| ≥ a · SI: N/A · સામાન્ય સંકલન.
ઉત્પરવળય y² = ax અને x-અક્ષ વચ્ચે x = 0 થી x = h સુધી: A = (2/3)·h·√(ah)
h = x-સીમા, a = ઉત્પરવળયનો પ્રાચલ · SI: વર્ગ એકમ · ઉત્પરવળય y² = ax અને x-અક્ષ વચ્ચેનો વિસ્તાર.
અધોલઘાત (Parabola) y = a − x² અને x-અક્ષ વચ્ચેનું ક્ષેત્રફળ: A = ∫₋√ₐ√ₐ (a − x²) dx = [ax − x³/3]₋√ₐ√ₐ = (4/3)a³ᐟ²
a > 0, છેદનબિંદુઓ x = ±√a · SI: વર્ગ એકમ · ઉત્પરવળય ઉપરની તરફ ઊંધી, શિરોબિંદુ (0, a) પર.
વૃત્તચક્ર x²/a² + y²/b² = 1 નું અર્ધ-ક્ષેત્રફળ: A = (1/2)·πab
a = અર્ધ-મહાન અક્ષ, b = અર્ધ-લઘુઅક્ષ · SI: વર્ગ એકમ · વૃત્તચક્રનો અડધો ભાગ (ઉપરો અથવા નીચેનો).
વળાંક (Hyperbola) x²/a² − y²/b² = 1 નું વિસ્તાર — અર્ધવક્ર: A = ∫ₐʳ (b/a)√(x² − a²) dx = (b/2)[x√(x²−a²) − a²·ln|x + √(x²−a²)|]ₐʳ
a, b = પ્રાચલ, r = જમણી બાજુની સીમા · SI: વર્ગ એકમ · વળાંકના જમણા અર્ધભાગ માટે.
દ્વિ-પરિમાણીય ક્ષેત્રફળ — સંયુક્ત પ્રદેશ (વક્રો વચ્ચે છેદન સુધી): A = ∫ₐᵇ |f(x) − g(x)| dx, જ્યાં a, b એ છેદનબિંદુઓ છે
a, b = f(x) = g(x) ના ઉકેલ, |·| = પરિમાણિત મૂલ્ય · SI: વર્ગ એકમ · જ્યારે બે વક્રો એકથી વધુ વખત છેદતા હોય તો અલગ અલગ અંતરાલમાં સંકલન કરવું.
પ્રથમ ઉત્પરવળય y² = 4ax અને સીધી રેખા y = mx (છેદનબિંદુઓ): આડકાટીય છેદનબિંદુઓ: x = 0 અને x = 4a/m²; ક્ષેત્રફળ A = ∫₀^(4a/m²) [2√(ax) − mx] dx
m = રેખાનો ઢાળ, a = ઉત્પરવળય પ્રાચલ · SI: વર્ગ એકમ · સીધી રેખા ઉત્પરવળયને બિંદુ (0,0) અને (4a/m², 4a/m) પર છેદે છે.

🔗 સંબંધો

  • વૃત્ત એ વૃત્તચક્રની વિશેષ સ્થિતિ છે: જો a = b = r તો vrttachakra નું ક્ષેત્રફળ πr² થાય.
  • ઉત્પરવળય y² = 4ax માટે x-અક્ષની સાપેક્ષે પરિકલન કરતાં ઉપર અને નીચેના ભાગ બંનેનો સમાવેશ કરવા માટે |y| નો ઉપયોગ થાય છે, કારણ કે y = ±2√(ax).
  • વક્રો વચ્ચેનું ક્ષેત્રફળ શોધતી વખતે છેદનબિંદુઓ (Intersection points) શોધવા માટે f(x) = g(x) સમીકરણ ઉકેલવું જરૂરી છે — બિંદુઓ a, b મેળવ્યા વગર સંકલનની સીમાઓ મળતી નથી.
  • y-અક્ષની સાપેક્ષે સંકલન કરતાં x = g(y) સ્વરૂપમાં વક્ર લખવો પડે છે, જે x-અક્ષ પર સંકલન કરતાં સરળ બને છે જ્યારે ઉભી રેખાઓ x = constant વડે ઘેરાયેલું ક્ષેત્રફળ શોધવું હોય.
  • vrtt (Circle) ના ક્ષેત્રફળનો ઉપયોગ ∫√(a²−x²)dx ના સંકલન દ્વારા ઉત્પન્ન થાય છે — આ સંકલનનું પરિણામ વૃત્તના ચતુર્થાંશને અનુરૂપ છે.
  • ક્ષેત્રફળ હંમેશા ધન હોય છે: ∫ₐᵇ f(x)dx ઋણ આવે તો પણ ક્ષેત્રફળ |∫ₐᵇ f(x)dx| લેવાય છે.

🎯 ટ્રિક્સ

સંમિતિ (Symmetry) નો ઉપયોગ: વક્ર x-અક્ષ અથવા y-અક્ષ પ્રત્યે સંમિત હોય તો એક ભાગનું ક્ષેત્રફળ શોધીને 2 વડે ગુણવું. ઉદા. vrtt x²+y²=r² માટે A = 4∫₀ʳ √(r²−x²)dx.
ઉત્પરવળય y² = 4ax અને સીધી રેખા x = h વચ્ચેનું ક્ષેત્રફળ = (8/3)√a · h³ᐟ² — આ તકનીકી રીતે યાદ રાખી શકાય તેવી પરિણામ છે.
વૃત્તચક્રનું ક્ષેત્રફળ πab એ સીધું સૂત્ર છે — સંકલન વિના યાદ રાખી શકાય. જો ઉપરો અડધો ભાગ માંગ્યો હોય તો πab/2.
ક્ષેત્રફળ શોધવાનું સૂત્ર: જો વક્રને બે અલગ અલગ સંકલનમાં વિભાજિત કરવો પડે (ઉદા. f(x) ≥ 0 on [a,c] અને f(x) ≤ 0 on [c,b]), તો A = |∫ₐᶜ f(x)dx| + |∫꜀ᵇ f(x)dx| લખવું.
y-અક્ષ પર સંકલનનો ઉપયોગ: જ્યારે વક્ર x = g(y) સ્વરૂપમાં સરળ હોય (ઉદા. ઉત્પરવળય y² = 4ax માટે x = y²/4a), તો x-અક્ષ પર સંકલન કરવાને બદલે y-અક્ષ પર સંકલન કરવું વધુ સરળ પડે છે.

⚠️ ભૂલો

ક્ષેત્રફળ હંમેશા ધન હોય છે, પણ ∫ₐᵇ f(x)dx ઋણ આવે તો પણ ઋણ જ છાપે — ક્ષેત્રફળ માટે અંતિમ જવાબનું ધન મૂલ્ય લેવું જરૂરી છે. |∫ₐᵇ f(x)dx|.
સંકલનની સીમાઓ a અને b એકબીજાથી અલગ હોવી જોઈએ (a < b). જો બિંદુઓ ઉલટા હોય તો ચિહ્ન બદલાઈ જશે.
જ્યારે વક્ર x-અક્ષને છેદતો હોય ત્યારે માત્ર ∫ₐᵇ f(x)dx કરવાથી ખોટો જવાબ મળે — અલગ અલગ ભાગોમાં સંકલન કરીને પરિમાણિત મૂલ્યોનો સરવાળો કરવો.
બે વક્રો વચ્ચેનું ક્ષેત્રફળ શોધતી વખતે ઉપરનો વક્ર અને નીચેનો વક્ર ઓળખવો જરૂરી છે — જો ઉલટું લખવું તો ઋણ ક્ષેત્રફળ આવે.
ઉત્પરવળય y² = 4ax માટે y = √(4ax) લખતાં ફક્ત ઉપરનો ભાગ (y ≥ 0) મળે છે — પૂર્ણ વિસ્તાર માટે નીચેના ભાગ (y = −√(4ax)) નો પણ સમાવેશ કરવો.
સંકલન કરતી વખતે x-અક્ષ અને y-અક્ષમાં કોઈ ભ્રમણા ન રાખવી — જે અક્ષની સાપેક્ષે ક્ષેત્રફળ શોધવું હોય તે અક્ષ પર લંબ રેખાઓનો ઉપયોગ કરવો.
વૃત્તચક્ર x²/a² + y²/b² = 1 માટે a અને b નો ગુણાકાર πab નું ક્ષેત્રફળ આપે છે — કેટલાક વિદ્યાર્થીઓ a અને b ને ઓળખ્યા વગર πr² જવાબ લખી દે છે.
