એકીકરણના પ્રયોગો — ઝડપી રિવિઝન નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Application of Integrals

📘 વ્યાખ્યાઓ

  • ચાપ હેઠળનું ક્ષેત્રફળ: y = f(x) વળાંક, x-અક્ષ, x = a અને x = b રેખાઓ વચ્ચેનું ક્ષેત્રફળ ∫ₐᵇ f(x) dx દ્વારા મળે છે.
  • નિશ્चित સંકલન: ∫ₐᵇ f(x)dx = F(b) − F(a), જ્યાં F એ f નું પ્રત્યવકલન છે.
  • બે વળાંક વચ્ચેનું ક્ષેત્રફળ: ઉપરનો વળાંક y = f(x) અને નીચેનો વળાંક y = g(x) માટે, ક્ષેત્રફળ = ∫ₐᵇ [f(x) − g(x)] dx.
  • સમમિતિથી બનતું ક્ષેત્રફળ: સમદળીય વળાંક (even function) માટે ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx.
  • વિકળ વિધેય (Odd function): f(−x) = −f(x); તેવા વિધેયનું −a થી a મધ્ય પ્રગામી નિશ્চিত સંકલન શૂન્ય બરોબર હોય છે.
  • પ્રાયોગિક રૂપ: સંકલન દ્વારા ભૌમિતિક રાશિઓ (ક્ષેત્રફળ, લંબાઈ) શોધવી એ એકીકરણના પ્રયોગ છે.

⚡ સૂત્રો

  • ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ −1
  • ∫ eˣ dx = eˣ + C
  • ∫ sin x dx = −cos x + C; ∫ cos x dx = sin x + C
  • ∫ sec²x dx = tan x + C; ∫ csc²x dx = −cot x + C
  • ∫ 1/x dx = ln|x| + C
  • ∫ aˣ dx = aˣ/ln a + C
  • ∫ 1/√(a²−x²) dx = arcsin(x/a) + C
  • ∫ 1/(a²+x²) dx = (1/a) arctan(x/a) + C
  • ∫ sin²x dx = x/2 − sin(2x)/4 + C
  • ∫ cos²x dx = x/2 + sin(2x)/4 + C
  • વર્તુળ x² + y² = a²નું ક્ષેત્રફળ = πa²
  • વૃત્તખંડ (Ellipse) x²/a² + y²/b² = 1નું ક્ષેત્રફળ = πab
  • વલયની લંબાઈ = ∫ₐᵇ √(1 + (dy/dx)²) dx
  • નિશ્ચિત સંકલનનો ગુણધર્મ: ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b−x)dx
  • ∫ₐᵇ f(x)dx = −∫ᵦᵃ f(x)dx

⭐ મુખ્ય તથ્યો

  • ક્ષેત્રફળ હંમેશા ધન (positive) હોય છે; ∫ₐᵇ |f(x)| dx એ ચોક્કસ ભૌમિતિક ક્ષેત્રફળ આપે છે.
  • જો f(x) ≥ 0 on [a,b], તો ∫ₐᵇ f(x)dx ≥ 0 હોય છે.
  • y² = 4ax (દિઘ્નિ) નું શિરોબિંદુ ઉગમબિંદુએ છે અને તે x-અક્ષની સાપેક્ષે સંમિત છે.
  • વલય y = sin x નું 0 થી 2π મધ્ય પ્રગામી નિશ્ચિત સંકલન શૂન્ય હોય છે, કારણ કે ધન અને ઋણ ક્ષેત્રફળ રદ થાય છે.
  • વલય xy = c (પરવલાય) પહેલા અને ત્રીજા પાદમાં આવેલું છે અને યામઅક્ષો સ્પર્શરેખાઓ છે.
  • y = x² અને y = x વચ્ચેનું બંધ ક્ષેત્રફળ = ∫₀¹ (x − x²) dx = 1/6 ચોપડાયકમ.
  • વર્તુળના કેન્દ્રથી સમકોણીય ચાપ હેઠળનું ક્ષેત્રફળ એ અર્ધવર્તુળ (half-circle) જેટલું હોય છે.
  • વક્ર y = f(x) ની x-અક્ષ સાથેની છેદનબિંદુઓ જાણતાં સંકલનની સીમાઓ નક્કી થાય છે.
  • ∫₋ₐᵃ f(x)dx = 0 જો f વિષમ વિધેય હોય; ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx જો f સમ વિધેય હોય.
  • ક્ષેત્રફળની એકમ ચોપડાયકમ (sq units) માં ગણતરી કરવામાં આવે છે.

⚠️ સામાન્ય ભૂલો

  • ∫ₐᵇ f(x)dx ને F(b) + F(a) કહી ભૂલથી ગણી લેવામાં આવે છે; સાચો રૂપ F(b) − F(a) છે.
  • f(x) < 0 હોય ત્યારે ∫ₐᵇ f(x)dx ઋણ મળે; ભૌમિતિક ક્ષેત્રફળ માટે |f(x)| લેવું પડે.
  • સંકલનની ઉપલી અને નીચલી સીમા બદલવાથી ચિહ્ન ઉલટાય છે — ∫ᵦᵃ = −∫ₐᵇ.
  • બે વક્રો વચ્ચેનું ક્ષેત્રફળ લેતી વખતે ઉપરનો અને નીચેનો વળાંક ઓળખવો જરૂરી છે; ગેરસમજથી ક્ષેત્રફળ ઋણ આવે.
  • y² = x નું y-અક્ષ પર સંકલન કરતી વખતે x = y² તરીકે ફરી લખવું પડે છે; સીમાઓ પણ y માં મૂકવી પડે.
  • વક્ર અને અક્ષ વચ્ચેનું ક્ષેત્રફળ શોધતી વખતે છેદનબિંદુઓ (limits) જાહેર કરવાનો વિસ્મરણ.
  • ∫ sin²x અને ∫ cos²x નું સીધું સૂત્ર ભૂલીને સરળ ઘાત સૂત્ર લાગુ પડતું ખોટું.
  • પરવલા y² = 4ax નું k સમીપી અક્ષ પરનું ક્ષેત્રફળ શોધવા સીમાઓ પરવલાના સમીકરણથી મેળવવી.
  • x-અક્ષ અને y-અક્ષ બંનેને સીમા તરીકે ઉપયોગી બનાવતાં ગૂંચવણ;
  • ∫₋ᵃᵃ x³dx = 0 સાચું છે, પણ વિદ્યાર્થીઓ તેની સમજૂતી વગર યાદ રાખી જ ખોટું કામ કરે છે.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • y = √(a² − x²) એ ઉર્ધ્વવર્તી અર્ધવર્તુળ છે; ∫₋ₐᵃ √(a² − x²) dx = πa²/2.
  • વૃત્તખંડ x²/a² + y²/b² = 1 નું પ્રથમ ચરણે ક્ષેત્રફળ = πab/4, ચાર ચરણોનું કુલ = πab.
  • y = x² અને y = 4x વચ્ચેનું ક્ષેત્રફળ = ∫₀⁴ (4x − x²) dx = 64/3 ચોપડાયકમ.
  • y = sin x નું 0 થી π મધ્ય ક્ષેત્રફળ = ∫₀π sin x dx = 2.
  • y = cos x નું 0 થી π/2 મધ્ય ક્ષેત્રફળ = ∫₀^(π/2) cos x dx = 1.
  • વક્ર y = 2x − x² અને x-અક્ષ વચ્ચેનું ક્ષેત્રફળ = ∫₀² (2x − x²) dx = 4/3.
  • y = x અને y = x² વચ્ચેનું ક્ષેત્રફળ = ∫₀¹ (x − x²) dx = 1/6.
  • વલય xy = 1, x = 1, x = 2 અને x-અક્ષ વચ્ચેનું ક્ષેત્રફળ = ∫₁² (1/x) dx = ln 2.
  • y = eˣ, y = 0, x = 0, x = 1 વચ્ચેનું ક્ષેત્રફળ = e − 1.
  • સમસ્યાઓમાં સૌથી પહેલા વળાંકોના છેદનબિંદુઓ શોધીને સીમાઓ નક્કી કરવી હંમેશા યાદ રાખવી.
  • જ્યારે vક્ર y-અક્ષની સાપેક્ષે સંમિત હોય, ત્યારે ∫₋ₐᵃ જગ્યાએ 2∫₀ᵃ લઈને ગણતરી સરળ બને છે.
  • ક્ષેત્રફળના પ્રશ્નોમાં વળાંકોની ચિત્ર રચના કરવી અને કયા ભાગનું ક્ષેત્રફળ લેવાનું છે એ સ્પષ્ટ કરવું જરૂરી.
  • ∫ₐᵇ f(x)dx માટે F(x) શોધ્યા બાદ F(b) − F(a) લખવું, નહીં કે F(a) − F(b).
  • વક્ર y = √(4x) અને y = x વચ્ચેનું ક્ષેત્રફળ ∫₀⁴ (2√x − x) dx = 8/3.
  • સંકલનની પદ્ધતિ એ ક્ષેત્રફળ શોધવાનો સૌથી સરળ અને સામાન્ય રીતે GUJCET માં આવતો મુખ્ય પ્રશ્ન છે.
