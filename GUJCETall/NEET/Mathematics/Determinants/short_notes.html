📄 Short Notes

નિશ્ચાયક — ટૂંકા નોટ્સ (રેવિઝન)

🧪 GUJCET — Gujarati • Mathematics • Determinants

📘 વ્યાખ્યાઓ

  • નિશ્ચાયક (Determinant): ચોરસ શ્રેણિકનો એક અદિશ મૂલ્ય, જેને |A| અથવા det(A) વડે દર્શાવવામાં આવે છે.
  • શ્રેણિક (Matrix): m×n કોષ્ટક જેમાં m હર અને n સ્તંભની સંખ્યામાં આબાદ માહિતી ગોઠવેલી હોય.
  • ચોરસ શ્રેણિક (Square Matrix): હર અને સ્તંભની સંખ્યા સમાન હોય તેવો શ્રેણિક.
  • એકમ શ્રેણિક (Identity Matrix I): વિકર્ણ પર 1 અને બાકી બધા જ શૂન્ય ધરાવતો ચોરસ શ્રેણિક.
  • શૂન્ય શ્રેણિક (Zero Matrix O): બધા જ અવયવો શૂન્ય ધરાવતો શ્રેણિક.
  • વિકર્ણ શ્રેણિક (Diagonal Matrix): વિકર્ણ સિવાયના બધા જ અવયવો શૂન્ય ધરાવતો ચોરસ શ્રેણિક.
  • સંયુક્ત શ્રેણિક (Adjoint Matrix adj A): A ના અવયવોના ગુણાંક (cofactors) ના transpose શ્રેણિક.
  • વ્યુત્ક્રમ શ્રેણિક (Inverse Matrix A⁻¹): એવો શ્રેણિક કે જેથી A·A⁻¹ = A⁻¹·A = I.

⚡ સૂત્રો

  • 2×2 નિશ્ચાયક: |A| = ad − bc જો A = [[a,b],[c,d]].
  • 3×3 નિશ્ચાયક (પહેલા હર પર વિસ્તરણ): |A| = a₁₁A₁₁ + a₁₂A₁₂ + a₁₃A₁₃ જ્યાં Aᵢⱼ = (−1)^(i+j) Mᵢⱼ.
  • અવયવ (Cofactor) Aᵢⱼ = (−1)^(i+j) × અવયવ્ય (Minor) Mᵢⱼ.
  • A(adj A) = (adj A)A = |A| · I.
  • વ્યુત્ક્રમ શ્રેણિક: A⁻¹ = (1/|A|) · adj A, જો |A| ≠ 0.
  • adj(adj A) = |A|^(n−2) · A, જ્યાં n = શ્રેણિકનો ક્રમ.
  • |AB| = |A| · |B| (ગુણાકારનો ગુણધર્મ).
  • |A⁻¹| = 1/|A|.
  • |kA| = k^n |A|, જ્યાં n = ક્રમ અને k અદિશ.
  • ત્રિકોણનું ક્ષેત્રફળ = ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|.
  • ત્રિકોણ ક્ષેત્રફળ નિશ્ચાયક સ્વરૂપ: ½ |x₁ y₁ 1; x₂ y₂ 1; x₃ y₃ 1|.
  • સિસ્ટમ AX = B નો ઉકેલ: X = A⁻¹B, જો |A| ≠ 0.

⭐ મુખ્ય તથ્યો

  • જો |A| = 0 હોય તો શ્રેણિક A ને અવ્યુત્ક્રમણીય (Singular) કહેવાય; A⁻¹ અસ્તિત્વ ધરાવતું નથી.
  • જો |A| ≠ 0 હોય તો શ્રેણિક A ને વ્યુત્ક્રમણીય (Non-singular) કહેવાય.
  • કોઈ પણ શ્રેણિક માટે A · adj A = adj A · A = |A| · I.
  • (A⁻¹)⁻¹ = A.
  • (AB)⁻¹ = B⁻¹ · A⁻¹ (વ્યુત્ક્રમનો વિપરીત ક્રમ).
  • (A^T)^T = A.
  • (AB)^T = B^T · A^T.
  • adj(A^T) = (adj A)^T.
  • |A^T| = |A|.
  • ત્રિકોણનું ક્ષેત્રફળ શૂન્ય હોય તેવા બિંદુઓ સમરેખ (Collinear) હોય છે.
  • રેખીય સમીકરણ વ્યવસ્થા AX = B માં |A| ≠ 0 હોય તો ઉકેલ એકમય (Unique) હોય છે.
  • 3×3 નિશ્ચાયકના મૂલ્યની ગણતરી સરણી-રુપ (Sarrus rule) વડે પણ કરી શકાય.
  • શૂન્ય લાઇન / સ્તંભ ધરાવતા શ્રેણિકનો નિશ્ચાયક શૂન્ય થાય.
  • સમાન હર અથવા સ્તંભ ધરાવતા શ્રેણિકનો નિશ્ચાયક શૂન્ય થાય.
  • કોઈ પણ હર/સ્તંભમાં એકબીજાનો પ્રમાણભૂત ગુણક (proportional) હોય તો નિશ્ચાયક શૂન્ય.

⚠️ સામાન્ય ભૂલો

  • |A + B| = |A| + |B| — આ ખોટું છે; નિશ્ચાયકનો ઉમેરો ગુણધર્મ લાગુ પડતો નથી.
  • (A + B)⁻¹ = A⁻¹ + B⁻¹ — આ પણ ખોટું છે.
  • A⁻¹ હોવા છતાં |A| = 0 લખવું — વિરોધાભાસ; |A| ≠ 0 જરૂરી છે.
  • adj A ની ગણતરીમાં ચિહ્ન Aᵢⱼ = (−1)^(i+j) ભૂલવું.
  • (kA)⁻¹ = kA⁻¹ સમીકરણ ખોટું છે; સાચું (kA)⁻¹ = (1/k)A⁻¹.
  • 3×3 નિશ્ચાયક ફેલાવતી વખતે 2×2 ના નિશ્ચાયક લેતી વખતે વિકર્ણ ઉતારવાને બદલે ઉડધર લેવું.
  • ત્રિકોણના ક્ષેત્રફળના સૂત્રમાં ½ શૂન્ય ગણી દેવું.
  • AX = B માં |A| = 0 હોય ત્યારે ઉકેલ નથી જ એમ માનવું — અસંગત (Inconsistent) હોઈ શકે અને અનંત ઉકેલ પણ હોઈ શકે.
  • A⁻¹ અસ્તિત્વ ધરાવતું હોય ત્યારે Adj A = |A|·A⁻¹ માં |A| શૂન્ય લખવું.
  • Sarrus નિયમ 3×3 સિવાયના ક્રમના નિશ્ચાયક માટે લાગુ પડતો નથી તે ભૂલવું.
  • બિંદુઓ (x₁,y₁),(x₂,y₂),(x₃,y₃) સમરેખ છે તેટલે |A| = 0 એટલું જ; સંક્રમણ (transpose) |A| બદલતો નથી.
  • (AB)^T = A^T · B^T લખવું — સાચું (AB)^T = B^T · A^T છે.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • 2×2 નિશ્ચાયકની ગણતરી ઝડપી રીતે |ad − bc| સ્વરૂપે યાદ રાખો.
  • 3×3 નિશ્ચાયકનું વિસ્તરણ હંમેશા પ્રથમ હર અથવા પહેલા સ્તંભમાંથી કરો — ચિહ્ન શૃંખલા (+,−,+) યાદ રાખો.
  • ચિહ્ન શૃંખલાના ટેબલ માટે: A₁₁(+), A₁₂(−), A₁₃(+); A₂₁(−), A₂₂(+), A₂₩(−); A₃₁(+), A₃₂(−), A₃₃(+).
  • |A| = 0 હોય તો શ્રેણિક Singular છે અને વ્યુત્ક્રમ શક્ય નથી — આ પ્રશ્નો GUJCET માં બહુ વારંવાર આવે છે.
  • ત્રિકોણના ક્ષેત્રફળના પ્રશ્નોમાં બિંદુઓ સમરેખ હોય તો ક્ષેત્રફળ શૂન્ય એટલે |A| = 0 થાય અને x,y નું મૂલ્ય શોધો.
  • AX = B ની સિસ્ટમમાં |A| ≠ 0 હોય તો Unique solution; |A| = 0 હોય તો adj A · B ≠ O હોય તો No solution; adj A · B = O હોય તો Infinite solutions.
  • adj A = |A| · A⁻¹ એ સૌથી વધુ વપરાતું સંબંધ — ઉલટું પણ યાદ રાખો.
  • n-ક્રમના શ્રેણિક માટે |kA| = k^n|A| હંમેશા યાદ રાખો, કારણ કે n=2 અને n=3 માં ખાસીક ગણતરીમાં ભૂલ થાય છે.
  • સમરેખતાની ચકાસણી: બિંદુઓ (x₁,y₁),(x₂,y₂),(x₃,y₃) માટે નિશ્ચાયક શૂન્ય હોય તો તેઓ સમરેખ છે.
  • Gaussian elimination વાપરીને AX=B ઉકેલતી વખતે |A|=0 હોય તો રેન્ક(A) vs રેન્ક(A|B) જોઈને નિર્ણય કરો.
  • આદર્શ પરીક્ષા પ્રશ્નોમાં સૌથી વધુ ગણતરી: A⁻¹ શોધો → |A| ની કિંમત કાઢો → (AB)⁻¹ અથવા adj A શોધો.
  • શ્રેણિકના અવયવ (cofactor) શોધવાની પ્રક્રિયામાં Aᵢⱼ = (−1)^(i+j)Mᵢⱼ આપમેળે ચિહ્ન ગણતરીના પગલામાં સામેલ કરવું.
  • સંકર સંખ્યા (complex number) ના પ્રશ્નો પણ GUJCET માં આવે છે: ઉદા. z = a+bi માં |z| અને z·z̄ = |z|² નો સંબંધ.
  • શૂન્ય સ્તંભ/હર, સમાન હર/સ્તંભ, પ્રમાણભૂત હર/સ્તંભ — આ ત્રણેય સ્થિતિમાં |A| = 0 જાય અને સીધો જવાબ મળી જાય.
