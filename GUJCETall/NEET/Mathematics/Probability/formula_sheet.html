ગુજરાતી ગણિત – સંભાવના (Probability) સૂત્ર શીટ

🧪 GUJCET — Gujarati • Mathematics • Probability

⚡ સૂત્રો

શાસ્ત્રીય સંભાવના: P(E) = n(E) / n(S)
n(E) = અનુકૂળ પરિણામોની સંખ્યા, n(S) = નમૂના અવકાશમાં કુલ પરિણામોની સંખ્યા · SI: નોંધ (મૂલ્ય રાહિત) · જ્યારે બધા પરિણામો સમાન સંભવિત હોય
સંભાવનાની દિશા: 0 ≤ P(E) ≤ 1
P(E) = ઘટના E ની સંભાવના · SI: નોંધ · હંમેશા લાગુ પડે
સૂન્યાવૃત્ત ઘટના: P(Φ) = 0
Φ = શૂન્ય ઘટના (જે ક્યારેય બનતી નથી) · SI: નોંધ · શૂન્ય ઘટના માટે
અનિવાર્ય ઘટના: P(S) = 1
S = નમૂના અવકાશ (અનિવાર્ય ઘટના) · SI: નોંધ · અનિવાર્ય ઘટના માટે
પૂરક ઘટના: P(E′) = 1 − P(E)
E′ = E નો અપવાદ (કે Not E), P(E′) = E નહીં બનવાની સંભાવના · SI: નોંધ · E બનશે અથવા નહીં, તે બે જ શક્યતાઓ
સંયોજક ઘટના (Union rule): P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
A ∪ B = A અથવા B બનવાની ઘટના, A ∩ B = A અને B બંને બનવાની ઘટના · SI: નોંધ · સામાન્ય કિસ્સો, A અને B પરસ્પર અપવાદક પણ હોઈ શકે
પરસ્પર અપવાદક ઘટનાઓ: P(A ∪ B) = P(A) + P(B) જ્યારે P(A ∩ B) = 0
A અને B પરસ્પર અપવાદક = એક સાથે બંને ન બનવાળી ઘટનાઓ · SI: નોંધ · જ્યારે A અને B એક સાથે બનવી શક્ય ન હોય
શરતી સંભાવના: P(A | B) = P(A ∩ B) / P(B), જ્યાં P(B) > 0
P(A|B) = B બન્યો હોય ત્યારે A બનવાની સંભાવના, A ∩ B = A અને B બંને બનવાની ઘટના · SI: નોંધ · જ્યારે B બન્યો હોય તેમ માનીને A ની સંભાવના શોધવી હોય
શરતી સંભાવના – B માટે: P(B | A) = P(A ∩ B) / P(A), જ્યાં P(A) > 0
P(B|A) = A બન્યો હોય ત્યારે B બનવાની સંભાવના · SI: નોંધ · જ્યારે A બન્યો હોય તેમ ધારીને B ની સંભાવના શોધવી હોય
ગુણાકાર નિયમ (Multiplication Rule): P(A ∩ B) = P(A) × P(B | A) = P(B) × P(A | B)
A ∩ B = A અને B બંને બનવાની ઘટના, P(B|A) = A બન્યો હોય ત્યારે B ની શરતી સંભાવના · SI: નોંધ · હંમેશા લાગુ પડે
સ્વતંત્ર ઘટનાઓ – ગુણાકાર સૂત્ર: P(A ∩ B) = P(A) × P(B) જ્યારે A, B સ્વતંત્ર હોય
A, B સ્વતંત્ર = એક ઘટના બનવી બીજી પર અસર ન કરે · SI: nozdh · જ્યારે A અને B પરસ્પર સ્વતંત્ર ઘટનાઓ હોય
બેથી વધુ સ્વતંત્ર ઘટનાઓ: P(A ∩ B ∩ C) = P(A) × P(B) × P(C) જ્યારે A, B, C સ્વતંત્ર હોય
A, B, C = ત્રણ સ્વતંત્ર ઘટનાઓ · SI: nozdh · ત્રણેય ઘટનાઓ પરસ્પર સ્વતંત્ર હોય
દ્વિપદી વિતરણ – સંભાવના સૂત્ર: P(X = r) = C(n, r) × p^r × q^(n−r)
n = કુલ પ્રયાસો, r = સાફળ્યોની સંખ્યા, p = સાફળ્યની સંભાવના, q = 1 − p (અસફળતાની સંભાવના), C(n,r) = ⁿCᵣ · SI: nozdh · બર્નૂલી પ્રયાસો, દરેક પ્રયાસ સ્વતંત્ર, p અચળ
દ્વિપદી વિતરણ – અપેક્ષિત મૂલ્ય: E(X) = μ = n × p
E(X) = અપેક્ષિત મૂલ્ય / સરેરાશ, n = કુલ પ્રયાસો, p = સાફળ્યની સંભાવના · SI: nozdh · દ્વિપદી વિતરણ માટે
દ્વિપદી વિતરણ – પ્રસરણ: Var(X) = σ² = n × p × q
Var(X) = પ્રસરણ, n = કુલ પ્રયાસો, p = સાફળ્યની સંભાવના, q = 1 − p · SI: nozdh · દ્વિપદી વિતરણ માટે
દ્વિપદી વિતરણ – પ્રમાણિત વિચલન: σ = √(n × p × q)
σ = પ્રમાણિત વિચલન, n = કુલ પ્રયાસો, p = સાફળ્યની સંભાવના, q = 1 − p · SI: nozdh · દ્વિપદી વિતરણ માટે
બાયેઝ પ્રમેય: P(E_i | A) = [ P(E_i) × P(A | E_i) ] / [ Σ_j P(E_j) × P(A | E_j) ]
E_i = પરસ્પર અપવાદક અને સમગ્ર અવકાશ રચતા પરિણામો, A = અવલોકિત ઘટના · SI: nozdh · E₁, E₂, …, E_n પરસ્પર અપવાદક અને S નો ભાગ હોય, P(E_i) > 0
સંયોજન સંખ્યા (Combination): C(n, r) = n! / [ r! × (n − r)! ]
n = કુલ તત્વો, r = ચૂંટવાના તત્વો, ! = ફેક્ટોરિયલ · SI: nozdh · જ્યારે યોજનાનો ક્રમ મહત્વનો ન હોય
ક્રમચય સંખ્યા (Permutation): P(n, r) = n! / (n − r)!
n = કુલ તત્વો, r = ગોઠવવાના તત્વો · SI: nozdh · જ્યારે યોજનાનો ક્રમ મહત્વનો હોય
સ્થાનાંતરિત સંભાવના: P(બીજો કાઢ્યો પહેલા વਾਲો/રંગો) = P(પહેલો કાઢ્યો) × P(બીજો | પહેલો)
સ્થાનાંતરિત = એક વસ્તુ કાઢીને પાછી મૂકવી નહીં · SI: nozdh · જ્યારે એક જ વસ્તુમાંથી વારાફરતી ચૂંટવામાં આવે અને પાછી મૂકવામાં ન આવે
પ્રત્યાયન સંભાવના: P(બીજો કાઢ્યો) = P(પહેલા વાલો) જ્યારે પ્રત્યાયનમાં કાઢ્યો પાછો મૂકાય
પ્રત્યાયન = કાઢેલો પરિણામ પાછો મૂકવો · SI: nozdh · જ્યારે દરેક વખતે કાઢ્યો પાછો મૂકીને બીજો પ્રયાસ કરવામાં આવે

🔗 સંબંધો

  • શરતી સંભાવના અને ગુણાકાર નિયમ: P(A ∩ B) = P(A) · P(B|A), એટલે કે છેદ પૂર્વલક્ષી સાથે ગુણતા ગુણાકાર ઘટના મળે છે.
  • પૂરક ઘટના: P(E) + P(E′) = 1, કારણ કે E અને E′ પરસ્પર અપવાદક છે અને તેમનો સંયોગ અનિવાર્ય ઘટના છે.
  • સ્વતંત્ર ઘટનાઓ માટે: P(A ∩ B) = P(A) · P(B); પણ P(A|B) = P(A) થાય, એટલે B નું પ્રભાવ A પર ન હોય.
  • સંયોજક ઘટના: P(A ∪ B) = P(A) + P(B) − P(A ∩ B); જો A, B પરસ્પર અપવાદક હોય તો P(A ∩ B) = 0, તેથી P(A ∪ B) = P(A) + P(B).
  • બાયેઝ પ્રમેય: P(E_i|A) = [P(E_i)·P(A|E_i)] / [Σ P(E_j)·P(A|E_j)], જે P(E_i) અને P(A|E_i) વડે P(A|E_i) ઉલટાવે છે.
  • દ્વિપદી વિતરણ: E(X) = np, Var(X) = npq; q = 1−p, એટલે પ્રસરણ સાફળ્યની સંભાવના પર આધારિત છે.
  • સંભાવનાનો વિસ્તાર 0 થી 1 છે, એટલે P(E′) = 1 − P(E) હંમેશા 0 થી 1 વચ્ચે જ મળે.

🎯 ટ્રિક્સ

જ્યારે P(A ∪ B) અને P(A ∩ B) જાણીતી હોય, તો P(A) + P(B) = P(A ∪ B) + P(A ∩ B) એ યાદ રાખવું સૂત્ર ઓછું યાદ રાખવા મદદ કરે છે.
'કુલ 1' ટેક્નિક: P(એક પણ નહીં) = 1 − P(કેમ બનતો નથી) એ પૂરક ઘટનાથી ઝડપી ગણતરી કરે છે.
સ્વતંત્ર ઘટના માટે P(A ∩ B) = P(A)·P(B); જો ગુણાકાર કરતાં સીધું જ મળતું જોવા મળે તો ઘટનાઓ સ્વતંત્ર છે.
બાયેઝમાં છેદને સંપૂર્ણ અવકાશના સરવાળા તરીકે લખો: Σ_j P(E_j)·P(A|E_j); આ રીતે ભૂલ ઓછી થાય છે.
દ્વિપદી વિતરણમાં યાદ રાખો: np = અપેક્ષિત મૂલ્ય, npq = પ્રસરણ; q = 1 − p, તેથી q = 0 થાય ત્યારે પ્રસરણ શૂન્ય થાય.
જ્યારે P(A|B) = P(A) હોય ત્યારે A અને B સ્વતંત્ર છે; આ ચકાસણી ઝડપી છે.
પરસ્પર અપવાદક ઘટનાઓ માટે P(A ∪ B) = P(A) + P(B); એક સાથે બંને બની શકે નહીં તેટલું જ.

⚠️ ભૂલો

P(A ∪ B) = P(A) + P(B) ભૂલથી લખવું, જ્યારે A અને B પરસ્પર અપવાદક ન હોય; યોગ્ય સૂત્ર P(A) + P(B) − P(A ∩ B) છે.
પૂરક ઘટના તરીકે P(E′) = P(E) લખવું, એ ભૂલ; યોગ્ય સૂત્ર P(E′) = 1 − P(E).
સ્વતંત્ર ઘટનાઓ માટે P(A ∩ B) = P(A) · P(B) નો ઉપયોગ કરતી વખતે ઘટનાઓ સ્વતંત્ર ન હોય તો પણ ઉપયોગ કરવો.
શરતી સંભાવના P(A|B) = P(B|A) ધારી લેવું, એ ભૂલ; સામાન્ય રીતે P(A|B) ≠ P(B|A).
દ્વિપદી વિતરણમાં P(X=r) માટે r! ની જગ્યાએ n! વાપરવું; સૂત્ર ⁿCᵣ · pʳ · qⁿ⁻ʳ છે.
પ્રત્યાયન અને સ્થાનાંતરિત વચ્ચેનો તફાવત ભૂલવો; પ્રત્યાયનમાં પાછો મૂકાય, સ્થાનાંતરિતમાં મૂકવો નહીં.
બાયેઝ પ્રમેયમાં P(E_i|A) અને P(A|E_i) ને ગૂંચવવા;
સંભાવના 1 થી વધુ અથવા 0 થી ઓછી મળે ત્યારે સૂત્ર/ગણતરી ભૂલ કરી હોવાનું ધ્યાનમાં લેવું.
