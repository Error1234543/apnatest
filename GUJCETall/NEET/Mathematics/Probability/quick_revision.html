સંભાવના — ક્વિક રિવિઝન શીટ

🧪 GUJCET — Gujarati • Mathematics • Probability

🧠 યાદ રાખો

પરિણામોની સંખ્યા n(S) ≥ 1 હોય તેવી યાદૃચ્છિક પ્રાયોગિક પદ્ધતિને સંભાવનાનો પ્રશ્ન કહે છે.
કોઈ ઘટના E થવાની સંભાવના P(E) = n(E)/n(S), જ્યાં n(S) ≠ 0.
શૂન્ય ઘટના (Impossible event): P(∅) = 0; નિશ્ચિત ઘટના (Sure event): P(S) = 1.
પ્રતિબંધિત ઘટના A': P(A') = 1 − P(A).
બે ઘટનાઓ પરસ્પર વર્જ્ય (Mutually Exclusive) હોય તો P(A ∩ B) = 0.
મુક્ત (Independent) ઘટનાઓ માટે P(A ∩ B) = P(A)·P(B).
P(A | B) = P(A ∩ B) / P(B), જ્યાં P(B) > 0.

⚡ ઝડપી સૂત્રો

સંયુક્ત ઘટનાનો સરવાળો નિયમ: P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
પરસ્પર વર્જ્ય ઘટનાઓ માટે: P(A ∪ B) = P(A) + P(B)
સ્વતંત્ર ઘટનાઓ માટે: P(A ∩ B) = P(A) · P(B)
શૂન્ય ઘટના: P(∅) = 0; નિશ્ચિત ઘટના: P(S) = 1
પ્રતિબંધિત ઘટના: P(A') = 1 − P(A) ⇒ P(A) = 1 − P(A')
પ્રતિબંધિત સંભાવના: P(A | B) = P(A ∩ B) / P(B)

✅ વન-લાઈનર્સ

નમૂના તરલ (Sample Space) S એ બધા શક્ય ફળિતાઓનો સમૂહ છે.
Favorable outcomes ની સંખ્યા n(E) અને કુલ પરિણામો n(S) વચ્ચેનો ગુણોત્તર સંભાવના આપે છે.
A અને B પરસ્પર વર્જ્ય હોય તો તેમની સાથે 'અથવા' (OR) નો પ્રશ્ન ઉકેલવા P(A ∪ B) = P(A) + P(B) વાપરો.
Bને આધારે A થવાની પ્રતિબંધિત સંભાવના P(A|B) છે, જ્યાં B થયા બાદ નમૂના તરલમાં ઘટાડો થાય છે.
બે ઘટનાઓ સ્વતંત્ર છે જો એકના થવાથી બીજાની સંભાવના પર કોઈ અસર ન થાય.
બંને સંભાવનાઓ 0 < P(A) < 1 અને 0 < P(B) < 1 હોય તો જ P(A ∩ B) = P(A)·P(B) લાગુ પડે.
P(A ∪ B) ≤ P(A) + P(B) હંમેશા સાચું છે (સમાનતા ત્યારે જ જ્યારે A, B પરસ્પર વર્જ્ય હોય).
સંભાવનાનું મૂલ્ય હંમેશા 0 થી 1ની વચ્ચે હોય: 0 ≤ P(E) ≤ 1.
