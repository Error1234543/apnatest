⚡ સૂત્રો

ઢાળ (Slope): m = (y2 - y1) / (x2 - x1)
m = ઢાળ, (x1, y1) અને (x2, y2) = રેખા પરના બે બિંદુઓ · SI: એકમરહિત · જ્યારે x2 ≠ x1 હોય
ઢાળ – x-અક્ષ સાથેનો ખૂણો: m = tan(θ)
m = ઢાળ, θ = રેખા અને ધન x-અક્ષ વચ્ચેનો ખૂણો (0° ≤ θ < 180°) · SI: એકમરહિત · θ = 90° હોય તો ઢાળ અસ્તિત્વમાં નથી
બે રેખાઓ વચ્ચેનો ખૂણો: tan(φ) = |(m2 - m1) / (1 + m1*m2)|
φ = બે રેખાઓ વચ્ચેનો લઘુકોણ, m1, m2 = રેખાઓના ઢાળ · SI: એકમરહિત · જ્યારે 1 + m1*m2 ≠ 0
સમાનતા શરત – સમાંતર રેખાઓ: m1 = m2
m1, m2 = બે રેખાઓના ઢાળ · SI: એકમરહિત · બે રેખાઓ સમાંતર હોય તો
લંબરેખા શરત: m1 * m2 = -1
m1, m2 = બે રેખાઓના ઢાળ · SI: એકમરહિત · બે રેખાઓ પરસ્પર લંબ હોય તો
બિંદુ-ઢાળ સ્વરૂપ: y - y1 = m(x - x1)
(x1, y1) = રેખા પરનું જ्ञાત બિંદુ, m = ઢાળ · SI: એકમરહિત · બિંદુ અને ઢાળ આપેલ હોય
બે બિંદુ સ્વરૂપ: y - y1 = [(y2 - y1) / (x2 - x1)] * (x - x1)
(x1, y1), (x2, y2) = રેખા પરના બે બિંદુઓ · SI: એકમરહિત · જ્યારે x1 ≠ x2
ત્રિજ્યાવર્ત સ્વરૂપ (Intercept Form): x/a + y/b = 1
a = x-અંતઃખંડ, b = y-અંતઃખંડ · SI: એકમરહિત · જ્યારે રેખાની x-અક્ષ પરના અંતઃખંડ a અને y-અક્ષ પરના અંતઃખંડ b આપેલા હોય
સામાન્ય સ્વરૂપ: Ax + By + C = 0
A, B, C = અચળાંકો, A અને B એકસાથે શૂન્ય ન હોય · SI: એકમરહિત · જ્યારે રેખાનો સામાન્ય સ્વરૂપ જોઈતો હોય
ઢાળ-અંતઃખંડ સ્વરૂપ: y = mx + c
m = ઢાળ, c = y-અંતઃખંડ · SI: એકમરહિત · જ્યારે ઢાળ અને y-અંતઃખંડ આપેલા હોય
બિંદુથી રેખા પરનું લંબ અંતર: d = |Ax1 + By1 + C| / sqrt(A^2 + B^2)
(x1, y1) = બિંદુ, Ax + By + C = 0 = રેખા, d = લંબ અંતર · SI: એકમ · જ્યારે બિંદુ (x1, y1) થી રેખા Ax + By + C = 0 નું લંબ અંતર જોઈતું હોય
સમાંતર રેખાઓ વચ્ચેનું અંતર: d = |C1 - C2| / sqrt(A^2 + B^2)
Ax + By + C1 = 0 અને Ax + By + C2 = 0 = સમાંતર રેખાઓ, d = અંતર · SI: એકમ · બે સમાંતર રેખાઓ વચ્ચેનું અંતર
ત્રણ બિંદુઓ સરખરેખીય હોવાની શરત: m12 = m23, અથવા x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2) = 0
(x1,y1), (x2,y2), (x3,y3) = ત્રણ બિંદુઓ · SI: એકમરહિત · જ્યારે ત્રણ બિંદુઓ સરખરેખીય હોય તો
બિંદુઓ દ્વારા વિભાજિત રેખાખંડ: x = (m*x2 + n*x1) / (m + n), y = (m*y2 + n*y1) / (m + n)
(x,y) = વિભાજનબિંદુ, (x1,y1) અને (x2,y2) = છેડાના બિંદુઓ, m:n = વિભાગાનુપાત · SI: એકમ · બિંદુ P રેખાખંડ A1A2 ને m:n અનુપાતમાં વિભાજિત કરે
મધ્યબિંદુ સૂત્ર: M = ((x1 + x2)/2, (y1 + y2)/2)
(x1,y1), (x2,y2) = રેખાખંડના છેડાના બિંદુઓ, M = મધ્યબિંદુ · SI: એકમ · રેખાખંડના મધ્યબિંદુ માટે m:n = 1:1
રેખાખંડનું લંબદ્વિભાજક: ઢાળ m' = -1/m, અને મધ્યબિંદુથી પસાર થાય
m = મૂળ રેખાખંડનો ઢાળ, m' = લંબદ્વિભાજકનો ઢાળ · SI: એકમરહિત · લંબદ્વિભાજક રેખાખંડને લંબરૂપે સમભાજિત કરે છે
રેખાનું સમીકરણ (પ્રવણતા-અંતઃખંડ): y = mx + c
m = પ્રવણતા (ઢાળ), c = y-અક્ષ પરનો અંતઃખંડ · SI: એકમરહિત · સૌથી સાદું સ્વરૂપ, ડેરિવેટિવ દ્વારા પણ મળે છે
રેખાનું સામાન્ય સ્વરૂપ (પ્રવણતા સ્વરૂપ): y - y1 = m(x - x1)
m = પ્રવણતા, (x1, y1) = રેખા પરનું કોઈ પણ બિંદુ · SI: એકમરહિત · એક બિંદુ અને પ્રવણતા આપેલ હોય
રેખા સુધીનું અંતર (સંકલન સ્વરૂપ): Ax + By + C = 0, જ્યાં A ≠ 0 અથવા B ≠ 0
A, B, C = સહગુણકો, x, y = ચલ · SI: એકમરહિત · કોઈપણ રેખાને આ સ્વરૂપમાં દર્શાવી શકાય
રેખાનું નોર્મલ સ્વરૂપ: x*cos(α) + y*sin(α) = p
p = મૂળબિંદુથી રેખા પરનું લંબ અંતર, α = લંબનો x-અક્ષ સાથેનો ખૂણો · SI: એકમ · જ્યારે રેખાનું નોર્મલ સ્વરૂપ જોઈતું હોય

🔗 સંબંધો

  • ઢાળ m = tan(θ) છે; તેથી θ = 45° હોય તો m = 1, θ = 60° હોય તો m = √3, θ = 135° હોય તો m = -1
  • સમાંતર રેખાઓનો ઢાળ સમાન હોય છે; લંબ રેખાઓના ઢાળનો ગુણાકાર -1 થાય છે
  • રેખા Ax + By + C = 0 નો ઢાળ m = -A/B છે અને y-અંતઃખંડ c = -C/B છે
  • x-અક્ષ પરના અંતઃખંડ a = -C/A અને y-અંતઃખંડ b = -C/B છે (સામાન્ય સ્વરૂપથી)
  • બે રેખાઓ y = m1*x + c1 અને y = m2*x + c2 સમાંતર હોય તો m1 = m2 અને લંબ હોય તો m1*m2 = -1
  • રેખા x = k એ y-અક્ષને સમાંતર રેખા છે અને તેનો ઢાળ અ વિકલનીય (undefined) છે
  • રેખા y = k એ x-અક્ષને સમાંતર રેખા છે અને તેનો ઢાળ 0 છે
  • આધારભૂત રેખાઓના સંદર્ભે, રેખા જૂથ (family of lines): L1 + λ*L2 = 0 એ L1=0 અને L2=0 છેદનબિંદુમાંથી પસાર થતી તમામ રેખાઓનું જૂથ દર્શાવે છે

🎯 ટ્રિક્સ

kોઈપણ રેખાનું x-અંતઃખંડ મેળવવા માટે y = 0 મૂકો; y-અંતઃખંડ મેળવવા માટે x = 0 મૂકો
લંબરેખા શરત m1*m2 = -1 યાદ રાખવાનું સરળ ફંડ: 'લંબ = નકારાત્મક ઉલટ'
સમાંતર રેખાઓ માટે Ax + By + C1 = 0 અને Ax + By + C2 = 0 — A અને B સમાન રહે! દ્વિસૂત્ર: દૂરી = |C1-C2|/√(A²+B²)
ત્રણ બિંદુઓ સરખરેખીય છે તે તપાસવા, બે જોડીના ઢાળ ગણો: m12 = m23 = m13, એકસરખા હોય તો સરખરેખીય
y-અક્ષ પરનું અંતર મેળવવા R (અથવા |c|) નો ઉપયોગ કરો; x-અક્ષ પરનું અંતર = |C/A| જો સામાન્ય સ્વરૂપમાં હોય
રેખાખંડ વિભાજન સૂત્રનો ORM (Online Ratio Formula Memory): '(m*x2 + n*x1)/(m+n)' — જે ભાગ મોટો, તેનો બિંદુ વધુ નજીક
નોર્મલ સ્વરૂપમાં x*cos(α) + y*sin(α) = p: p હંમેશા ધન હોય છે, અને α એ lંબનો દિશાખૂણો છે
L1 + λL2 = 0 એ 'રેખા જૂથ' (Line Family) નું સાધન છે — એક રેખાજૂથમાંથી અન્ય રેખા શોધવા માટે λ ની કિંમત શોધો

⚠️ ભૂલો

ઢાળનું સૂત્ર m = (y1-y2)/(x1-x2) લખવું (ચિહ્નની ભૂલ); સાચું સૂત્ર m = (y2-y1)/(x2-x1) છે — પરંતુ ગણતરીમાં ચિહ્ન બંને બાજુ સમાન રાખવું
લંબરેખા શરત m1 + m2 = 0 માની લેવી; સાચી શરત m1*m2 = -1 છે
સમાંતર રેખાઓ વચ્ચેનું અંતર શોધતી વખતે A અને B ને સમાન ન બનાવી શકવું
બિંદુથી રેખા પરનું અંતર શોધતી વખતે | | ની બહારની રેખાનું સ્વરૂપ Na + By + C = 0 માં C ની કિંમત નકારાત્મક લેવી
x-અક્ષ પરનો અંતઃખંડ શોધવા y = 1 મૂકવું (y = 0 નહીં)
મધ્યબિંદુ સૂત્રમાં (x1+x2)/2 તો સાચું પણ (y1+y2)/2 ન wrong પડવું — બંને સમાન પ્રક્રિયા
રેખાનું સમીકરણ લખતી વખતે બિંદુ-ઢાળ સ્વરૂપમાં (x - x1) ને બદલે (x + x1) લખી દેવું (ચિહ્ન ભૂલ)
ઢાળ અસ્તિત્વમાં ન હોય (જેમ કે x = 5) ત્યારે m = tan(θ) પ્રયોગ કરવો; x = a સ્વરૂપની રેખા માટે ઢાળ અવિકલનીય છે
રેખા x/a + y/b = 1 માં a અને b ને ઋણ લેવાની ભૂલ — અંતઃખંડ ઋણ હોઈ શકે પણ સૂત્રમાં ચિહ્ન સાવચેત રાખવું
L1 + λL2 = 0 માં L1 અને L2 ને પ્રથમ પ્રમાણિત (standardize) ન કરી શકવું — A, B, C એકસરખા કરવા પડે
