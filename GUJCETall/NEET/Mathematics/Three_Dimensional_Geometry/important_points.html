ત્રિપરિમાણીય ભૂમિતિ — મહત્વપૂર્ણ બિંદુઓ

🧪 GUJCET — Gujarati • Mathematics • Three Dimensional Geometry

⭐ મહત્વના મુદ્દા

ત્રિપરિમાણીય અંકગણિતમાં ત્રણ પરસ્પર લંબ અક્ષો (x-અક્ષ, y-અક્ષ, z-અક્ષ) અને તેઓ બનાવતાં ત્રણ યામતલો હોય છે: xy-તલ, yz-તલ અને zx-તલ.
આધારભૂત સમજ વિના આખા અધ્યાયનો અભ્યાસ શક્ય નથી; પ્રત્યેક પ્રશ્નની શરૂઆત આ ખ્યાલ પરથી થાય છે.
અવકાશમાં કોઈ પણ બિંદુના યામ (x, y, z) એ યામતલો સાથેના સંપર્કબિંદુઓ દર્શાવે છે; x, y, z નું ચિહ્ન ઑક્ટન્ટ (અષ્ટાંશ) નક્કી કરે છે.
ચિહ્ન-આધારિત પ્રશ્નો અને ઑક્ટન્ટ શોધવાના પ્રશ્નો GUJCET માં વારંવાર પૂછાય છે.
બે બિંદુઓ A(x₁,y₁,z₁) અને B(x₂,y₂,z₂) વચ્ચેનું અંતર AB = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²] થાય છે.
અંતર પ્રમેય આ અધ્યાયનું સૌથી મૂળભૂત સૂત્ર છે અને ઘણા બહુવિકલ્પી પ્રશ્નોમાં સીધો ઉપયોગ થાય છે.
P(x,y,z) બિંદુ O(0,0,0) થી રહેલું અંતર OP = √(x²+y²+z²) — આ મૂળબિંદુથી અંતર શોધવાનું સૂત્ર છે.
મૂળબિંદુ સંબંધિત પ્રશ્નો ઘણી વાર પરીક્ષામાં આવે છે.
રેખાખંડ PQ ને m:n માં વિભાજિત કરતું બિંદુ P(x₁,y₁,z₁), Q(x₂,y₂,z₂) માટે — આંતર વિભાજન: ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n)).
વિભાજન સૂત્ર ગેર-રેખીય પ્રશ્નોમાં વારંવાર ઉપયોગમાં લેવાય છે; બહુવિકલ્પી પરીક્ષામાં સીધું લાગુ પડે છે.
બહિઃ વિભાજન સૂત્ર: ((mx₂−nx₁)/(m−n), (my₂−ny₁)/(m−n), (mz₂−nz₁)/(m−n)) જ્યાં m ≠ n.
બહિઃ વિભાજનના પ્રશ્નો અલગથી આવે છે અને વિદ્યાર્થીઓ ભૂલથી આંતર/બહિઃ વિભાજનમાં સૂત્ર ભેળવી નાખે છે.
કોઈ પણ રેખાની દિશા સાથેના ખૂણા α, β, γ ના કોસાઇન d.cosα, d.cosβ, d.cosγ ને દિગ્વિકારકો (Direction Cosines) કહે છે અને તે d² = l²+m²+n² = 1 ને સંતોષે છે.
દિગ્વિકારકોનો મૂળભૂત ગુણધર્મ એ અધ્યાયનું કેન્દ્રબિંદુ છે; આ ગુણધર્મ વિના ઘણા પ્રશ્નો ઉકેલાતા નથી.
દિગ્વિકારો (l,m,n) અને દિગ્ગુણોતરો (a,b,c) વચ્ચેનો સંબંધ: l=a/√(a²+b²+c²), m=b/√(a²+b²+c²), n=c/√(a²+b²+c²).
દિગ્ગુણોતરોમાંથી દિગ્વિકારો શોધવાના પ્રશ્નો GUJCET માં ઘણા આવે છે.
બે રેખાઓના દિગ્વિકારો (l₁,m₁,n₁) અને (l₂,m₂,n₂) હોય તો તેમની વચ્ચેનો ખૂણો θ: cosθ = |l₁l₂ + m₁m₂ + n₁n₂|.
રેખાઓ વચ્ચેનો ખૂણો શોધવો એ અત્યંત મહત્વપૂર્ણ અને ઘણી વાર પૂછાતો પ્રશ્ન છે.
બે રેખાઓ પરસ્પર લંબ હોય તો l₁l₂ + m₁m₂ + n₁n₂ = 0; સમાંતર હોય તો l₁/l₂ = m₁/m₂ = n₁/n₂.
લંબતા/સમાંતરતાના શરતો ઝડપી બહુવિકલ્પી પ્રશ્નોમાં સીધા ઉપયોગી થાય છે.
રેખાના દિગ્ગુણોતરો (a,b,c) માટે આકાર રૂપ (Cartesian form): (x−x₁)/a = (y−y₁)/b = (z−z₁)/c.
આકાર રૂપ GUJCET માં સૌથી વધુ ઉપયોગમાં લેવાય છે; વેક્ટર રૂપ કરતાં આકાર રૂપના પ્રશ્નો ઘણા હોય છે.
સરળ રેખાનું વેક્ટર રૂપ: r⃗ = a⃗ + λb⃗, જ્યાં a⃗ એ રેખા પરનું સ્થિર બિંદુ અને b⃗ એ દિશા સૂચવતો સદિશ છે.
વેક્ટર સ્વરૂપ સમજવું પ્લેન અને રેખા વચ્ચેનો ખૂણો/અંતર શોધવા માટે જરૂરી છે.
સમતલનું સામાન્ય સમીકરણ: Ax + By + Cz + D = 0, જ્યાં (A,B,C) સમતલને લંબરૂપે સદિશ નોર્મલ છે.
સમતલનું સમીકરણ લખવા અને સમજવા બિનશરતી જરૂરી છે.
અંતરાખંડ સ્વરૂપ: x/a + y/b + z/c = 1, જ્યાં a, b, c એ અનુક્રમે x, y, z અક્ષો પરના અંતરાખંડો છે.
અંતરાખંડ આપેલ હોય ત્યારે સમીકરણ શોધવાના પ્રશ્નો પરીક્ષામાં બોલ્ડ આવે છે.
નોર્મલ સ્વરૂપ: lx + my + nz = p, જ્યાં (l,m,n) એ યામતલો સાથેના ખૂણાના દિગ્વિકારો છે અને p એ મૂળબિંદુ થી સમતલ પર દોરેલા લંબની લંબાઈ છે.
નોર્મલ સ્વરૂપ સમજવું પ્લેન-પર રહેલા પ્રશ્નો માટે સહાયક છે.
બે સમતલો પરસ્પર લંબ હોય તો AA' + BB' + CC' = 0; સમતલો સમાંતર હોય તો A/A' = B/B' = C/C'.
લંબતા અને સમપાર્શ્વતાની શરતો ઝડપી ગણતરી માટે ખૂબ ઉપયોગી છે.
બે સમતલો Ax+By+Cz+D=0 અને A'x+B'y+C'z+D'=0 વચ્ચેનો ખૂણો θ: cosθ = |AA'+BB'+CC'| / √(A²+B²+C²)√(A'²+B'²+C'²).
સમતલો વચ્ચેનો ખૂણો પૂછાતો પ્રશ્ન છે; સૂત્ર યાદ રાખવું આવશ્યક છે.
બિંદુ (x₁,y₁,z₁) થી સમતલ ax+by+cz+d=0 પરનું લંબ અંતર: |ax₁+by₁+cz₁+d| / √(a²+b²+c²).
એકદમ મહત્વપૂર્ણ અને ઘણી વાર પૂછાતો પ્રશ્ન; સીધું સૂત્ર લાગુ પડે છે.
એકબીજાના સમતલો પર લંબ હોય તેવી બે સમતલોનું ਛેદનબિંદુ એક રેખા આપે છે; તે રેખાનું સમીકરણ બંને સમતલોના સમીકરણો સંતોષે છે.
છેદનરેખા સમજવી પરંતુ બહુવિકલ્પી પ્રશ્નોમાં પ્રત્યક્ષપણે આવે છે.
બે સરળ રેખાઓ કો-પ્લેનર (એક જ સમતલમાં રહેલી) હોય તો તેઓનું લઘુત્તમ અંતર શૂન્ય હોય છે અને શરત |r₂−r₁ b₁ b₂| = 0 (સ્કેલર ત્રિપૂટ) સંતોષાય.
કો-પ્લેનર રેખાઓનું સૂત્ર અને શરત મહત્વપૂર્ણ છે અને મધ્યમ-કઠિનતાવાળા પ્રશ્નો આવે છે.
આકાર રૂપમાં રેખા 1: (x−x₁)/a₁ = (y−y₁)/b₁ = (z−z₁)/c₁ અને રેખા 2: (x−x₂)/a₂ = (y−y₂)/b₂ = (z−z₂)/c₂ વચ્ચેનું લઘુત્તમ અંતર: |(x₂−x₁)a₁(b₂c₁−b₁c₂) − (y₂−y₁)(a₂c₁−a₁c₂) + (z₂−z₁)(a₂b₁−a₁b₂)| / √[(b₁c₂−b₂c₁)²+(c₁a₂−c₂a₁)²+(a₁b₂−a₂b₁)²].
લઘુત્તમ અંતરનું સૂત્ર ગણતરી-આધારિત પ્રશ્નોમાં આવે છે; યાદ રાખવું અને યોગ્ય રીતે લાગુ કરવું મહત્વપૂર્ણ છે.
જો બે રેખાઓ સમતલમાં ન હોય (_skew lines)_ તો તેમની વચ્ચેનું લઘુત્તમ અંતર શૂન્ય ન હોય; વેક્ટર સ્વરૂપે: અંતર = |(b⃗₁×b⃗₂)·(r₂−r₁)| / |b⃗₁×b⃗₂|.
સ્ક્વુ (skew) રેખાઓની વ્યાખ્યા અને લઘુત્તમ અંતર વેક્ટર રૂપે શોધવું GUJCET માં મહત્વનું છે.
કોઈ પણ બિંદુ (x,y,z) xy-તલ પર હોય તો z=0; yz-તલ પર x=0; zx-તલ પર y=0.
યામતલો પર રહેલા બિંદુઓના યામ ઓળખવાના પ્રશ્નો સરળ પણ ઘણી વાર પૂછાય છે.
રેખા અને સમતલ વચ્ચેનો ખૂણો θ: sinθ = |aA+bB+cC| / √(a²+b²+c²)√(A²+B²+C²), જ્યાં (a,b,c) રેખાના દિગ્ગુણોતરો અને (A,B,C) સમતલના નોર્મલ દિગ્ગુણોતરો છે.
રેખા-સમતલ ખૂણો sin થી આવે છે (cos નહિં), જે વારંવાર વિદ્યાર્થીઓ ભૂલે છે — ધ્યાન આપવું જરૂરી છે.
રેખાના દિગ્ગુણોતરોમાંથી દિગ્વિકારો શોધવા માટે સૌ પ્રથમ m²+n²+p²=1 વાળો સમીકરણ ગોઠવવો જરૂરી છે.
દિગ્ગુણોતર→દિગ્વિકાર રૂપાંતરણમાં વિદ્યાર્થીઓ ઘણી વાર સંકલન ગુમાવી દે છે.
