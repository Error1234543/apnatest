🧪 GUJCET — Gujarati • Mathematics • Sets

⭐ મહત્વના મુદ્દા

સેટનો સંકલ્પના: સ્પષ્ટ અને અસ્પષ્ટ રાશિઓમાં ફરક સમજવો. 'સ્વભાવિક સંખ્યાઓ જે ૧૨ નું અવયવ હોય' એ સેટ છે, પરંતુ 'સારા વિદ્યાર્થીઓ' એ સેટ નથી.
મૂળભૂત પ્રશ્ન આવે છે કે કયો ગ્રુપ સેટ છે કે નહીં.
સેટની પ્રસ્તુતિ: તાલિકા રીત (Roster Form) અને સેટ-બिल्डર રીત (Set-Builder Form). ઉદા: A = {x : x ∈ ℕ અને x < 6} = {1, 2, 3, 4, 5}
બંને રીતે રૂપાંતર કરવાના પ્રશ્નો ગુજરાતી માધ્યમમાં વારંવાર આવે છે.
રિક્ત સેટ (Empty/Null Set, ∅), એકલ સેટ (Singleton), સમ સેટ (Equal Set), સમઅર્થ સેટ (Equivalent Set) અને અનંત સેટોની ઓળખ.
ચારે પ્રકારના સેટો વચ્ચેનો ભેદ સમજવો જરૂરી છે; MCQ માં ચૂકથી બચાડે છે.
ઉપસેટ (Subset, ⊆) અને સમપ્રોપર સબસેટ (Proper Subset, ⊂) વચ્ચેનો ફરક: B ⊆ A એટલે B, A નો ઉપસેટ; B ⊂ A એટલે B, A નો સમપ્રોપર સબસેટ (B ≠ A).
∅ ⊆ A હંમેશા સાચું, પણ ∅ ⊂ A ત્યારે જ જ્યારે A રિક્ત ન હોય — આ મહત્વનો નોଟ છે.
ધારણા સેટ (Power Set, P(A)): A માં n ઘટકો હોય તો P(A) માં 2^n ઘટકો. ઉદા: A = {1,2} → P(A) = {∅, {1}, {2}, {1,2}}.
n ઘટકોવાળા સેટનો Power Set શોધવાનો પ્રશ્ન GUJCET માં રેગ્યુલર આવે છે.
સાર્વત્રિક સેટ (Universal Set, U): આપેલા સંદર્ભના બધા ઘટકો ધરાવતો મોટો સેટ. વેન આલેખમાં તેને આયત અથવા વર્તુળ તરીકે દર્શાવવામાં આવે છે.
કમ્પ્લીમેન્ટ શોધવા માટે Uની જરૂર પડે; વેન આલેખના પ્રશ્નોમાં U સ્પષ્ટ હોવો જોઈએ.
વેન આલેખ (Venn Diagram): બે અથવા ત્રણ સેટોની લીનિયર, ઇન્ટરસેક્શન, યુનિયન દર્શાવવા આલેખનો ઉપયોગ.
આલેખ પરથી n(A∪B) શોધવાની રીત સમજવામાં મદદરૂપ — ડાયગ્રમ-આધારિત પ્રશ્નો આવે છે.
સેટોનો સંઘ (Union): A ∪ B = {x : x ∈ A અથવા x ∈ B}. ઘટક સૂત્ર: n(A ∪ B) = n(A) + n(B) – n(A ∩ B).
સૌથી મહત્વનું સૂત્ર. બે સેટોની યુનિયનના ઘટકો શોધવા આ સૂત્ર વડે ઉકેલ મળે.
સેટોનું છેદન (Intersection): A ∩ B = {x : x ∈ A અને x ∈ B}. જો A ∩ B = ∅ તો A અને B અસંયુક્ત (Disjoint) સેટો છે.
Disjoint set નો સંકલ્પ અને તેની રેખાકૃતિ મહત્વની; n(A∪B) = n(A)+n(B) જ્યારે disjoint હોય.
સેટોનો તફાવત (Difference): A – B = {x : x ∈ A અને x ∉ B}. નોટ: A – B ≠ B – A (ક્રમ બદલાય તો પરિણામ બદલાય).
A – B અને B – A બંનેનો વેન આલેખમાં ભાગ દર્શાવવાનો પ્રશ્ન આવે છે.
સેટનું પૂરક (Complement): A' = U – A = {x : x ∈ U અને x ∉ A}. n(A') = n(U) – n(A).
પૂરક શોધવાના પ્રશ્નો અને De Morgan ના નિયમો સાથે જોડાયેલો છે.
De Morgan ના નિયમો: (i) (A ∪ B)' = A' ∩ B' (ii) (A ∩ B)' = A' ∪ B'.
બંને નિયમો GUJCET માં સીધા પ્રશ્ન રૂપે આવે છે; પ્રૂફ અથવા ઉપયોગ પ્રશ્નો હોય છે.
t્રણ સેટો માટે ઘટક સૂત્ર: n(A ∪ B ∪ C) = n(A)+n(B)+n(C) – n(A∩B) – n(B∩C) – n(A∩C) + n(A∩B∩C).
ત્રણ સેટોવાળા પ્રશ્નોમાં આ સૂત્ર લાગુ પડે છે — વારંવાર આવતો પ્રશ્ન.
આંતરિક સેટ (Interval Sets): બંધ અંતરાલ [a,b], ખુલ્લા અંતરાલ (a,b), અર્ધ-બંધ [a,b) તથા (a,b] ની સંકલ્પના અને તેમનો વેન આલેખ.
અંતરાલ સેટો વચ્ચે સંઘ/છેદન શોધવાના પ્રશ્ન આવે છે.
સંયુક્ત સેટો (Composite Sets): જો n(A) = p, n(B) = q, તો n(P(A)) = 2^p, n(P(B)) = 2^q. P(A) ∩ P(B) = P(A ∩ B) જેમ ગુણધર્મો.
Power Set ની ગણતરી સાથે જોડાયેલા વિચારવાળા પ્રશ્નો આવે છે.
n(A–B) = n(A) – n(A∩B); n(B–A) = n(B) – n(A∩B); n(A∪B) – n(A∩B) = n(A–B) + n(B–A) = n(AΔB) (Symmetric Difference).
સિમેટ્રિક ડિફરન્સ અને તેના ઘટકો શોધવાના પ્રશ્નો GUJCET માં આવે છે.
બીજગણિતીય ગુણધર્મો: commutative (A∪B=B∪A, A∩B=B∩A), associative (A∪(B∪C)=(A∪B)∪C), distributive (A∪(B∩C)=(A∪B)∩(A∪C)).
ગુણધર્મો પર આધારિત સાચું/ખોટું પ્રશ્નો આવે છે; વિતરણ નિયમ ખાસ મહત્વનો.
n(A) + n(B) = n(A∪B) + n(A∩B) — આ સંબંધ યાદ રાખવો જરૂરી; તેથી n(A∩B) = n(A)+n(B)–n(A∪B) પણ મળે.
આધારભૂત સંબંધ; સૂત્ર બિનમાર્યા વિકલ્પે પણ ઉકેલ મળી જાય.
n(U) = n(A∪B∪C) + n((A∪B∪C)') — સાર્વત્રિક સેટમાં બધા ઘટકોનો સરવાળો અને બહારના ઘટકોનો સરવાળો થાય.
U, A, B, C આપેલ હોય ત્યારે ચોક્કસ ઘટકો શોધવા આ સંબંધ ઉપયોગી.
કોઈ પણ સેટ A માટે: A ∪ A' = U અને A ∩ A' = ∅. આ બે મૂળભૂત ગુણધર્મો De Morgan ના પ્રૂફમાં મદદરૂપ.
મૂળભૂત ગુણધર્મો — ખાલી અથવા U શોધવાના પ્રશ્નોમાં સીધો ઉપયોગ.
A ⊆ B ⇒ A ∪ B = B અને A ∩ B = A. ઉપસેટનો અર્થ સમજવો: A નો દરેક ઘટક B માં હોય.
ઉપસેટ હોય ત્યારે યુનિયન/ઇન્ટરસેક્શનનું પરિણામ શોધવાના પ્રશ્ન.
સેટોના સ્વરૂપો: n(A) = ધન પૂર્ણાંક, સામાન્ય પ્રશ્ન — n(A)=30, n(B)=50, n(A∩B)=10 તો n(A∪B)=? ઉકેલ: 30+50–10=70.
સૌથી વારંવાર આવતો પ્રકાર; સૂત્ર માર્યા વગર પણ ઉકેલી શકાય પણ સૂત્ર ઝડપી બનાવે છે.
ગણિતમાં ધારણા (Assumption): n(A∪B) ≤ n(U). જો n(A∪B) > n(U) આવી રહે તો આપેલ માહિતી ખોટી છે.
ચેકિંગનો રસ્તો; કોઈપણ પ્રશ્નમાં પરિણામ U થી મોટો આવે તો ફરિયાદ કરવી.
