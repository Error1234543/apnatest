📐 ગણ – ઝડપી રિવિઝન

🧪 GUJCET — Gujarati • Mathematics • Sets

🧠 યાદ રાખો

ગણનો અલંબારૂપ (Roaster/Tabular) સ્વરૂપ: {a, b, c, …} – મૂળભૂત, ક્રમ ગણ્યો નહીં.
ગણનો સમુચ્ચયરૂપ (Set-Builder Form): {x : x એ અરૂપરૂપમાં આપેલી શરત પાળે}
ખાલી ગણ (∅): ત્રણ સમાન દર્શાવણીઓ – ∅, {}, ( ) — બધા એક જ, કોઈ વૈકલ્પિક મૂલ્ય નથી.
ઉપગણ (⊆) vs સંગત ઉપગણ (⊂): A ⊆ B માટે A = B પણ ચાલે; A ⊂ B માટે A ≠ B ફરજિયાત.
પાવર સેટની ઘટકસંખ્યા: જો n(A) = n, તો P(A) ના ઘટકો = 2ⁿ — A ⊆ A અને ∅ ⊆ A હંમેશા સાચા.
n(A ∪ B) = n(A) + n(B) – n(A ∩ B); સૂત્ર સાચું રહે તેટલું ધ્યાન રાખવું.
n(A – B) ≠ n(B – A); તફાવત ગણ ક્રમગમિત (Ordered) છે.
n(A – B) = n(A) – n(A ∩ B); n(A ∪ B ∪ C) વિસ્તૃત સૂત્ર યાદ રાખવું.
A – B = A – (A ∩ B) = A ∩ B′ ; B – A = B – (A ∩ B) = B ∩ A′
ઉત્પલ ગણ (U): ચર્ચાનો સંદર્ભ ગણ; B′ = U – B, ઉત્પલ ગણ વિના પૂરક અર્થહીન.
De Morgan ના નિયમો: (A ∪ B)′ = A′ ∩ B′ અને (A ∩ B)′ = A′ ∪ B′ — ઉત્પલ લેવા એ જરા ખાસ ધ્યાન.
A ∩ A′ = ∅ અને A ∪ A′ = U — વ્યાખ્યા સ્પષ્ટ રાખવી.
સંયુક્ત ગણ ઘટકોનું કુલ n(A ∪ B) = n(A) + n(B) – n(A ∩ B) એ GUJCET માં અત્યંત પસંદગી પ્રશ્ન.
વેન ચિત્ર (Venn Diagram) માં ગોળા / દંડ આકાર — બે ગણો માટે 2 વર્તુળ; ત્રણ માટે એકબીજા પરછેદાતાં.
શૂન્ય / એકાકી ગણની ઘટકસંખ્યા: ∅ માટે n = 0; {0} માટે n = 1 — {0} ખાલી ગણ નથી.

⚡ ઝડપી સૂત્રો

n(P(A)) = 2ⁿ, જ્યાં n = n(A)
n(A ∪ B) = n(A) + n(B) – n(A ∩ B)
n(A – B) = n(A) – n(A ∩ B)
n(B – A) = n(B) – n(A ∩ B)
n(A ∪ B ∪ C) = n(A) + n(B) + n(C) – n(A ∩ B) – n(B ∩ C) – n(A ∩ C) + n(A ∩ B ∩ C)
n(U) = n(A) + n(A′) ⟹ n(A′) = n(U) – n(A)
n(A – B) = n(B – A) = 0 ⟺ A = B

✅ વન-લાઈનર્સ

ગણ = વિશેષતા ધરાવતી વસ્તુઓનો સમૂહ; અસ્પષ્ટ ગણ અશક્ય છે.
ગણને સામાન્ય રીતે A, B, C… અથવા S,T,U વડે દર્શાવવામાં આવે છે.
સમાન ગણ: A = B ⟺ A ના બધા ઘટક B માં અને B ના બધા ઘટક A માં.
પૂર્ણાંક ગણ ℤ, કાર્ડિનલ ગણ ℕ, યથાર્થ ગણ ℝ — પ્રમાણભૂત પ્રતીક જાણતા હોવ.
સંયુક્ત (Union) A ∪ B = {x : x ∈ A અથવા x ∈ B} — અથવા શબ્દ મહત્વપૂર્ણ.
છેદન (Intersection) A ∩ B = {x : x ∈ A અને x ∈ B} — 'અને' શબ્દ ભૂલતા નહીં.
વિયોજન (Difference) A – B = {x : x ∈ A પરંતુ x ∉ B}.
પૂરક (Complement) A′ = {x ∈ U : x ∉ A}.
ગણ સંચાલન અભિનયમૂલક (Commutative) છે: A ∪ B = B ∪ A, A ∩ B = B ∩ A.
ગણ સંચાલન સંಯોજક (Associative) છે: (A ∪ B) ∪ C = A ∪ (B ∪ C) અને તે જ રીતે છેદન માટે.
વિયોજન અભિનયમૂલક નથી: A – B ≠ B – A (સામાન્ય રીતે).
ઉત્પલ ગણ U માં A ⊆ A, ∅ ⊆ A અને A ⊆ U હંમેશા સાચા.
એકી યોગ (Disjoint) ગણ: A ∩ B = ∅ ⟹ n(A ∪ B) = n(A) + n(B).
A ⊆ B ⟹ A ∪ B = B અને A ∩ B = A — આ ગુણધર્મ GUJCET માં સીધો આવે છે.
n(A – B) ≠ n(A) – n(B); n(A – B) = n(A) – n(A ∩ B) — ઘણા વિદ્યાર્થીઓ આમાં ભૂલ કરે છે.
બે ગણો A અને B માટે: n(A – B) = n(B – A) = 0 ⟹ A = B (શૂન્ય તફાવત)
ગણમાં ઘટકો ક્રમગમિત નથી: {1,2} = {2,1}; પુનરાવર્તન પણ અવગણ્યું છે: {a,a,b} = {a,b}.
