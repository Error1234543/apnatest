ગણ (Sets) — પૂર્ણ અધ્યાય નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Sets

આધ્યાય: ગણ (Sets)
ગણ (Set): ઠરાવબદ્ધ અને અલગ-અલગ (distinct) વસ્તુઓનો સમૂહ ગણ કહેવાય.
✨ મહત્વ: ગણની વસ્તુઓને 'અવયવ' (Element) કહે છે. a ∈ A = 'a એ A નો અવયવ છે.'
ગણને S, A, B, U જેવા અંગ્રેજી વર્ણોથી દર્શાવવામાં આવે છે.
A = {a, b, c, d, e} સેટ-બ્રેસ (Curly braces) માં અવયવો લખાય.
📝 📝 યાદ રાખો: ગણમાં અવયવોનો ક્રમ મહત્त्वના નથી. {1,2,3} = {3,1,2}
ગણની લખાણ પદ્ધતિઓ (Methods of Writing Sets)
1. બાહ્ય રૂપ (Roster / Tabular form): તમામા અવયવો બ્રેકેટમાં કોমাથી અલગ કરીને.
E = {2, 4, 6, 8, 10, ...} (અનંત ગણ હોય ત્યારે '...' નો ઉપયોગ)
2. આત્મરૂપ (Set-builder form): ગણના અવયવોની સામાન્ય લાક્ષણિકતા写 દ્વારા.
O = {x : x એક વિષમ કુદરતી સંખ્યા છે} અથવા {x | x is odd natural}
⚡ ધ્યાન: | અથવા : બંનેનું અર્થ 'such that' એવો છે. ઉભય રૂપ સમાન ગણ દર્શાવે છે.
ખાલી / શૂન્ય ગણ (Empty / Null Set)
જે ગણમાં કોઈ અવયવ ન હોય તેને ખાલી / શૂન્ય ગણ કહે છે.
∅ (એલ્ફ) અથવા { } ∅ નો ક્રમ (Cardinality) = 0
ઉદા. {x : x ∈ N અને x < 1} = ∅ કારણ કે કોઈ કુદરતી સંખ્યા 1 થી ઓછી નથી.
∅ નો ક્રમ 0 છે∅ એ દરેક ગણનો ઉપગણ છે
📝 📝 ∅ એ એક અંગિક ગણ છે, ખાલી નહીં!
સમ ગણ (Equal Sets)
બે ગણ A અને B સમ (Equal) થાય જો તેઓના અવયવો એકસમાન હોય.
A = B જો અને ફقط જો A ⊆ B અને B ⊆ A
ઉદા: A = {1,2,3}, B = {3,2,1} ⇒ A = B (ક્રમની ફરક પડતી નથી.)
✨ સમ ગણ → સમાન અવયવો, સમાન ક્રમ (cardinality).
એક પદી ગણ (Singleton Set)
જે ગણમાં માત્ર એક જ અવયવ હોય તેને એક પદી ગણ કહે છે.
{0}, {∅}, {x : x ∈ R અને x² = 4, x < 0} = {-2}
एक पदी गण का क्रम n = 1 होता है.
સંહત અને અસંહત ગણ (Finite & Infinite Sets)
સંહત ગણ (Finite set): અવયવોની સંખ્યા ઠરાવબદ્ધ (નિયત) હોય. ગણ A નો ક્રમ n(A).
n(A) = A માં રહેલા અવયવોની કુલ સંખ્યા
ઉદા: P = {a, e, i, o, u} ⇒ n(P) = 5
અસંહત ગણ (Infinite set): અવયવો અનંત (ગણાય કે ન ગણાય તેવા) હોય.
N = {1, 2, 3, ...} અસંહત ગણ (Cardinality અનંત)
એક પદી, સંહત ગણક્રમ n = 0, 1, 2, 3, ... (સંહત)
📝 📝 n(∅) = 0 — શૂન્ય ગણ સંહત ગણ છે!
સમસ્થાન ગણ (Universal Set)
કોઈ પણ ચર્ચામાં સંબંધિત તમામ ગણના અવયવો ધરાવતો મોટો ગણ — સમસ્થાન ગણ U.
A ⊆ U, B ⊆ U, C ⊆ U, ... U નો ઉલ્લેખ σ (સિગ્મા)થી પણ થાય છે.
ઉદા: સંખ્યા સમસ્થાન U = {x : x ∈ R} પ્રદેશ-અથવા પ્રતિબિંબ સમસ્થાન અલગ હોઈ શકે.
⚡ સમસ્થાન ગણની પસંદગી સંદર્ભ પર આધારિત — બદલાઈ શકે છે.
ઉપગણ (Subset)
જો દરેક a ∈ A માટે a ∈ B થાય, તો A એ B નો ઉપગણ (Subset).
A ⊆ B ⇒ ∀x (x ∈ A → x ∈ B) ∅ ⊆ A હંમેશા સાચું
A ⊆ B અને B ⊆ A ⇒ A = B
ઉપગણની સંખ્યા = 2^{n(A)} (દરેક અવયવ લે/ન લે).
જો n(A) = m, તો ઉપગણોની કુલ સંખ્યા = 2^m
✨ ઉપગણમાં A ⊆ A (સ્વયં પણ ઉપગણ) અને ∅ ⊆ A (શૂન્ય ગણ દરેકનો ઉપગણ).
📝 📝 ⊂ ≠ ⊆ : ⊂ પ્રોપર સબસેટ (સખત ઉપગણ) — A ≠ B હોય.
સચિત્ર ગણ / પ્રોપર સબસેટ (Proper Subset)
જો A ⊆ B હોય પણ A ≠ B હોય, તો A એ B નો પ્રોપર સબસેટ (સચિત્ર ગણ).
A ⊂ B ⇔ A ⊆ B અને A ≠ B
ઉદા: A = {1,2}, B = {1,2,3} ⇒ A ⊂ B (સચિત્ર)
n(A) = m, n(B) = n હોય તો પ્રોપર સબસેટની સંખ્યા = 2^m − 1
સચિત્ર ગણ = ઉપગણ − સ્વયંA ⊂ B ⇒ n(A) < n(B)
બીજગણ / પાવર સેટ (Power Set)
ગણ A ના તમામા ઉપગણોનો ગણ બીજગણ (Power set) P(A) કહેવાય.
P(A) = {X : X ⊆ A} n(P(A)) = 2^{n(A)}
ઉદા: A = {a,b} ⇒ P(A) = {∅, {a}, {b}, {a,b}}
⚡ P(A) માં કુલ 2^n ઉપગણો હોય — ∅ પણ બીજગણમાં આવી જાય છે.
📝 📝 ∅ ∈ P(A) અને ∅ ⊆ P(A) — બંને સાચા!
વિરોધી / પૂરક ગણ (Complement Set)
સમસ્થાન U નો પાછળો ભાગ — જે U માં હોય પણ A માં ન હોય.
A' (અથવા Aᶜ) = {x ∈ U : x ∉ A}
મૂળભૂત નિત્યસત: A ∪ A' = U A ∩ A' = ∅ (A')' = A
n(A') = n(U) − n(A) (J ≈ U માં હોય)
✨ વિરોધી ગણ હંમેશા સમસ્થાન U સાથે સંબંધિત — U બદલાય તો A' પણ બદલાય.
સંયોગ (Union) — A ∪ B
A માં હોય અથવા B માં હોય (અથવા બંનેમાં) — તમામ અવયવોનો ગણ.
A ∪ B = {x : x ∈ A અથવા x ∈ B}
ઉદા: A = {1,2,3}, B = {3,4,5} ⇒ A ∪ B = {1,2,3,4,5}
n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
⚡ જો A ∩ B = ∅ (અસંયુક્ત), તો n(A ∪ B) = n(A) + n(B) — સરળ સરવાળો!
📝 📝 ∪ માં સામાન્ય અવયવ એક જ વાર ગણાય.
છેદ (Intersection) — A ∩ B
A અને B — બંનેમાં સામાન્ય અવયવોનો ગણ.
A ∩ B = {x : x ∈ A અને x ∈ B}
A ∩ B = ∅ ⇒ ગણ A, B અસંયુક્ત (Disjoint).
A ⊆ B ⇒ A ∩ B = A A ⊆ B ⇒ A ∪ B = B
✨ છેદ → સામાન્ય ટકાણું (common part). સંયોગ → સંપૂર્ણ ભાગ.
તફાવત (Difference) — A − B
A માં હોય પણ B માં ન હોય તેવા અવયવો.
A − B = {x : x ∈ A અને x ∉ B}
A − B ≠ B − A (અસંમિત) જરૂરી નથી.
A − B = A ∩ B' B − A = B ∩ A'
⚡ A − B એ A નો એવો ભાગ છે જે B નથી.
ક્રોડ ગણ (Cartesian Product) — A × B
ક્રમિત રિયા (Ordered pairs) નો ગણ.
A × B = {(a, b) : a ∈ A, b ∈ B}
n(A × B) = n(A) × n(B)
જો n(A) = p, n(B) = q ⇒ n(A × B) = p × q
ઉદા: A = {1,2}, B = {a,b,c} ⇒ A×B = {(1,a),(1,b),(1,c),(2,a),(2,b),(2,c)}
A × B ≠ B × Aજ્યાં સુધી A = B ન હોય (ક્રમિત હોવાથી)
✨ (a,b) ≠ (b,a) જ્યાં સુધી a = b ન હોય — ક્રમિત જોડી!
ગણના બીજગણ-સંબંધિત ગુણધર્મો
1. સંયુક્ત (Commutative): A ∪ B = B ∪ A A ∩ B = B ∩ A
2. સંಯોજક (Associative): (A ∪ B) ∪ C = A ∪ (B ∪ C)
3. વિતરણ (Distributive): A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
⚡ વિતરણ ગુણધર્મો — બે ગુણધર્મો એકબીજા પર લાગુ પડે (Dual).
ડી મોર્ગનના નિયમો (De Morgan's Laws)
(A ∪ B)' = A' ∩ B'
(A ∩ B)' = A' ∪ B'
ડી મોર્ગનનો અર્થ: યુનિયનનો પૂરક = પૂરકોનો છેદ; છેદનો પૂરક = પૂરકોનો સંયોગ.
'∪' બદલાય '∩' માં, '∩' બદલાય '∪' માંપૂરક લેતા બેઉ બદલાય — ડી મોર્ગન!

ગણના અન્ય મહત્વના સૂત્રો
n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
જો A ∩ B ≠ ∅ અને A ∪ B ≠ U: n(A ∪ B) − n(A ∩ B) = n(A − B) + n(B − A)
n(A ∪ B ∪ C) = n(A)+n(B)+n(C) − n(A∩B) − n(B∩C) − n(C∩A) + n(A∩B∩C)
ઉપરનું ત્રણ ગણ માટેનું સૂત્ર ( prinsip of inclusion-exclusion ).
📝 📝 ત્રણ ગણના સૂત્રમાં છેદનો ત્રણ વાર બાદ અને ત્રણેયનો છેદ ફરી ઉમેરવો.
વેન ચિત્રો (Venn Diagrams)
ગણ સંબંધો દર્શાવવા રેખાચિત્ર — ચોક્કસ આકારો (વર્તુળ) નો ઉપયોગ.
સમસ્થાન U → આયત / ચતુષ્કોણ; ગણ A, B → વર્તુળ.
A ⊆ B → A નું વર્તુળ B ની અંદરA ∩ B ≠ ∅ → વર્તુળો છેદે છે
⚡ વેન ચિત્ર ગણ ભાષાને દ્રશ્ય રીતે સમજાવે — GUJCET માં ચિત્ર આધારિત પ્રશ્નો આવે છે.
ગણ સંબંધિત મહત્વના નિયમો (રિવિઝન)
A ∪ ∅ = A A ∩ ∅ = ∅ A ∪ U = U A ∩ U = A
A ∪ A' = U A ∩ A' = ∅ A ∪ A = A A ∩ A = A
(A')' = A n(A − B) = n(A) − n(A ∩ B)
n(A − B) = n(A) − n(A ∩ B) n(A − B) = n(A ∪ B) − n(B − A)
✨ તમામ નિત્યસતો રટ્ટું — GUJCET માં ખૂબ વપરાય છે!
📝 📝 A − B ≠ B − A (અસંમિત). સામાન્ય ભૂલ યાદ રાખો!

8. ગણ સંયોગ/છેદ વેન ચિત્રમાં ભાગફળ છે — ચિત્ર વાંચો.

10. પ્રોપર સબસેટ = 2^n − 1; ઉપગણ = 2^n — બંને બદલાઈ જાય.
અધ્યાયનો અંત — સૂત્ર-ચોકઠું
n(A ∪ B) = n(A) + n(B) − n(A ∩ B) n(A ∪ B ∪ C) = n(A)+n(B)+n(C) − n(A∩B)−n(B∩C)−n(C∩A) + n(A∩B∩C)
(A ∪ B)' = A' ∩ B' (A ∩ B)' = A' ∪ B'
n(P(A)) = 2^n(A) n(A × B) = n(A)·n(B)
A − B = A ∩ B' A ∪ ∅ = A, A ∩ ∅ = ∅
