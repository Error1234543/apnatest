રેખીય અસમતાઓ (Linear Inequalities) — EXAM TRICKS & શોટકટ

🧪 GUJCET — Gujarati • Mathematics • Linear Inequalities

🎯 પરીક્ષા ટ્રિક્સ

અંકગણિત પદ્ધતિ (Arithmetic Method) નો ઉપયોગ: જ્યારે વિકલ્પો સરળ સંખ્યાઓમાં હોય, ત્યારે x = 0 મૂકીને ચકાસો. જો ડાબી બાજુ ≥ જમણી બાજુ થાય, તો ઉકેલક્ષેત્રમાં છે; નહીં તો નથી.
વિકલ્પાત્મક પ્રશ્નો જ્યાં ચકાસણીથી જવાબ નક્કી કરવો હોય. ખાસ કરીને 'નિરાપત ર્તાસ્થાન (Feasible Region)' પુરા કરે છે કે નહીં તે પૂછતા.
દા.ત.: a + b ≥ 6, a ≤ 4, b ≤ 3 → (0,6): 0+6=6≥6 ✓, 0≤4 ✓, 6≤3 ✗ → સ્વીકાર્ય નથી. એક જ વિકલ્પ ખોટો હોય તો તે દૂર.
ક્રમ ફેરવો (Reversal Rule): જ્યારે અસમતાની બંને બાજુ ઋણ સંખ્યા વડે ગુણવા/ભાગવા હોય, ત્યારે અસમતા ચિહ્ન પાછું ફરે છે. GUJCET માં આ જ મુખ્ય ટ્રેપ છે — ધ્યાન રાખો!
કોઈ પણ અસમતા જ્યારે -ve સંખ્યા વડે સાદુરૂપ આપવું હોય. દા.ત. −3x > 9 → x < −3 (ચિહ્ન < બની ગયું).
દા.ત.: −2x ≤ 8 → x ≥ −4 (બંને બાજુ −2 વડે ભાગતા ચિહ્ન ↑ બન્યું). ઘણા વિધાર્થીઓ આ ત્રુટિ કરે છે.
આદર્શ રેખાનું પ્રકાર (Solid vs Dashed Line): ≥ કે ≤ હોય → ભરેલી (solid) રેખા. > કે < હોય → તૂટેલી (dashed) રેખા. ઉકેલક્ષેત્ર રેખા પર છે કે નહીં તે આ રીતે ઝડપથી નક્કી કરો.
ગ્રાફ આધારિત પ્રશ્નોમાં 'ઉકેલક્ષેત્રમાં રેખાનો સમાવેશ થાય છે કે નહીં' પૂછતી વખતે અથવા સીમા રેખા નક્કી કરતી વખતે.
દા.ત.: 2x + y ≤ 6 → ભરેલી રેખા; 2x + y < 6 → તૂટેલી રેખા. વિકલ્પોમાં રેખાના પ્રકાર પરથી જ ખોટો વિકલ્પ દૂર કરી શકાય.
મૂળબિંદુ પરીક્ષણ (Origin Test): ax + by ? c માટે (0,0) મૂકો. જો અસમતા સત્ય થાય, તો ઉકેલક્ષેત્ર મૂળબિંદુ ધરાવતી બાજુએ હશે; નહીં તો વિરુદ્ધ બાજુએ. ઝડપથી કયા ભાગને રંગવો તે નક્કી કરે છે.
એકલ સ્થિતિની અસમતાનો ગ્રાફિકલ ઉકેલ દોરતી વખતે. અક્ષો પરછેદ શોધી, રેખા દોરી, પછી સરળતાથી બાજુ નક્કી કરો.
દા.ત.: 3x + 4y ≤ 12: (0,0) → 0 ≤ 12 સત્ય → મૂળબિંદુ ધરાવતી બાજુ રંગવી. 2x − y > 4: (0,0) → 0 > 4 મિથ્યા → મૂળબિંદુ વિરુદ્ધ બાજુ રંગવી.
સંયુક્ત અસમતા (Compound Inequality): a < x + b < c ને તરત બે ભાગમાં વહેંચો. વિકલ્પોમાં x નો વિસ્તાર પૂછ્યો હોય તો બંને શરતો એકસાથે સંતોષાય તેવા વિસ્તારનો છેદ લો.
'−2 < 3x + 1 ≤ 10' જેવી સંયુક્ત અસમતા ઉકેલતી વખતે અને સમગ્ર શ્રેણી શોધતી વખતે.
દા.ત.: −2 < 3x + 1 ≤ 10: −3 < 3x ≤ 9 → −1 < x ≤ 3. ઉકેલક્ષેત્ર: (−1, 3]. ધ્યાન: ડાબી બાજુ તૂટેલી, જમણી ભરેલી.
બહુવચનીય રેખીય અસમતા (System of Linear Inequalities): બધી રેખાઓ દોરી, ઉકેલક્ષેત્ર (Feasible Region) શોધો. શિરોબિંદુ (Corner Points) માત્ર રેખાઓના છેદબિંદુઓ પર મળે. બે રેખાઓના સમીકરણો સરવાળો/બાદબાકી કરી છેદબિંદુ મેળવો.
બે અથવા વધુ અસમતાઓનો સામૂહિક ઉકેલક્ષેત્ર શોધવાનો અથવા શિરોબિંદુઓના નિરાકરણ શોધવાના પ્રશ્નો.
દા.ત.: x + y = 4 અને x − y = 2: સરવાળો → 2x = 6 → x = 3, y = 1. શિરોબિંદુ (3,1). વિકલ્પોમાં આ બિંદુ હોય તો ચકાસો.
લઘુત્તમ/ગરીષ્ઠ મૂલ્યનું સૂત્ર: R.L.P. (Feasible Region) લંબચોરસ/બહુभुज હોય, તો Objective Function Z = px + qy નું મૂલ્ય માત્ર શિરોબિંદુઓ પર જ ચકાસો. મહત્તમ/લઘુત્તમ મૂલ્ય હંમેશા કોઈ એક શિરોબિંદુ પર મળે.
રેખીય પ્રोग्रामિંગ (LPP) પ્રકારના પ્રશ્નો જ્યાં Z નું મહત્તમ કે લઘુત્તમ મૂલ્ય શોધવું હોય. વિકલ્પોમાંથી સૌથી મોટું/ chhota શિરોબિંદુ મૂલ્ય શોધો.
દા.ત.: Z = 3x + 5y, શિરોબિંદુઓ: (0,0)=0, (4,0)=12, (0,3)=15, (2,3)=21 → મહત્તમ Z = 21 at (2,3). ફક્ત શિરોબિંદુઓ ગણતરી કરો.
અક્ષો પરછેદ પદ્ધતિ (Intercept Method): ax + by = c ની રેખા દોરવાનો ઝડપી રસ્તો: x-અક્ષ પરછેદ (c/a, 0) અને y-અક્ષ પરછેદ (0, c/b). બે બિંદુઓ મળ્યા પછી રેખા તરત દોરી શકાય. ગ્રાફિકલ ઉકેલ માટે આ સૌથી ઝડપી પદ્ધતિ.
એકલા અસમતાના ગ્રાફિકલ ઉકેલમાં રેખા ઝડપથી દોરવી હોય. કોષ્ટક બનાવ્યા વિના તરત રેખા મળે.
દા.ત.: 2x + 3y = 6: x-અક્ષ પરછેદ (3, 0), y-અક્ષ પરછેદ (0, 2). આ બે બિંદુ જોડો → રેખા મળી. ≤ હોય તો મૂળબિંદુ પરીક્ષણ કરી બાજુ રંગો.
સાપેક્ષ અસમતા તુલના (Relative Comparison Trick): જો x > a અને y > b હોય, તો x + y > a + b (સમાન ચિહ્નનો સરવાળો ચિહ્ન જ રાખે). પણ x > a અને y < b હોય તો x − y માટે ચિહ્ન ચોક્કસ નથી — ગણતરી કરવી પડે. આ ગਲત ધારણા ઘણા વિકલ્પોમાં ટ્રેપ છે.
જ્યારે પ્રશ્નમાં બે અથવા વધુ અસમતાઓ આપી હોય અને તેમના સરવાળો/ફેરફારનું પરિણામ પૂછતું હોય.
દા.ત.: x > 3, y > 2 → x + y > 5 નિશ્ચિત. પણ x > 3, y < 2 → x − y ની કોઈ ચોક્કસ મર્યાદા નથી. આવા વિકલ્પો ખોટા હોય.
પૂર્ણાંક ઉકેલ (Integer Solution) શોધવા: ઉકેલક્ષેત્ર આલેખ પર દોરી, તે પ્રદેશમાં આવતા પૂર્ણાંક બિંદુઓ ગણો. GUJCET માં 'કુલ કેટલા પૂર્ણાંક ઉકેલો' પૂછતા, ગણતરી કરવાને બદલે આલેખ પરથી ગણી શકાય.
જ્યારે પ્રશ્ન પૂછે: 'કુલ કેટલા પૂર્ણાંક જોડ (a,b) ઉકેલક્ષેત્રમાં આવે છે?' આલેખ દોરી પછી તરત ગણતરી.
દા.ત.: a + b ≤ 5, a ≥ 0, b ≥ 0: (0,0),(0,1)…(0,5),(1,0)…(1,4)…(5,0). કુલ = 21 પૂર્ણાંક બિંદુઓ. ગણતરી સરળ છે.
વિકલ્પ બાદપદ્ધતિ (Elimination by Substitution): સંયુક્ત અસમતાના વિકલ્પોમાં A, B, C, D આપેલ હોય તો દરેક બિંદુ તપાસો. જો કોઈ પણ એક શરત સંતોષાતી ન હોય, તો તે બિંદુ ઉકેલક્ષેત્રની bahuli નથી.
ઘણા બિંદુઓ આપેલા હોય અને તેમાંથી કઈ બિંદુઓ ઉકેલક્ષેત્રમાં છે તે નક્કી કરવાનો પ્રશ્ન. એક જ ખોટી શરતે બિંદુ દૂર.
દા.ત.: a + b ≥ 4, 2a − b ≤ 6, a ≤ 3: બિંદુ (4,0): 4+0=4≥4 ✓, 8−0=8≤6 ✗ → દૂર. માત્ર એક જ ચકાસણીથી જવાબ મળ્યો.
સમાન અંતર પ્રદેશ (Equidistant Region): જો બે અસમતાઓ અક્ષો સાથે સમાન કોણ કરતી હોય (દા.ત. x+y=5 અને x−y=5), તો તેમના ઉકેલક્ષેત્ર સમપ્રમાણ (symmetric) હોય. આ પ્રકારના પ્રશ્નોમાં શિરોબિંદુઓ સરળતાથી મળે.
જ્યારે અસમતાઓ સમપ્રમાણ હોય — x ± y ≤ k જેવી રચના. મહત્તમ/લઘુત્તમ શોધવામાં ઝડપ થાય.
દા.ત.: x + y ≤ 6, x − y ≤ 2, x ≥ 0, y ≥ 0: સંપૂર્ણ ઉકેલક્ષેત્ર x-અક્ષ, y-અક્ષ અને બે રેખાઓ વડે ઘેરાયેલું. શિરોબિંદુઓ: (0,0),(6,0),(4,2),(0,2).
અસમતાના ચિહ્નનું રૂપાંતર: ભાગીદારી (Division) અથવા ગુણાકારમાં (+ve અથવા −ve) ચિહ્ન ફરે છે. ગુણવેલું સંખ્યા ઋણ છે તેના અર્થમાં ફર્યા વિના આવી જાય — આ GUJCET નો સૌથી સામાન્ય ટ્રેપ છે.
કોઈ પણ અસમતા ઉકેલતી વખતે જ્યારે −ve સંખ્યા વડે ગુણવું/ભાગવું પડે. યાદ રાખો: ચિહ્ન ફરશે જ!
દા.ત.: −5x + 3 ≥ 2x − 4: 7 ≤ 7x → x ≥ 1. અથવા: −x/2 < 3 → x > −6 (ચિહ્ન ફર્યું!). આ પગલાં યાદ રાખો.
ઉકેલક્ષેત્રનું ક્ષેત્રફળ (Area of Feasible Region): જો ઉકેલક્ષેત્ર ત્રિકોણ હોય, તો ક્ષેત્રફળ = ½ × base × height. શિરોબિંદુઓ મેળવ્યા પછી સીધો ગણતરી. GUJCET માં અक्सર આ પ્રશ્નો આવે છે.
જ્યારે પ્રશ્ન પૂછે: 'ઉકેલક્ષેત્રનું ક્ષેત્રફળ શોધો.' શિરોબિંદુઓ મેળવી ત્રિકોણ/ચતુર્ભુજનું ક્ષેત્રફળ કાઢો.
દા.ત.: x ≥ 0, y ≥ 0, 2x + y ≤ 4: શિરોબિંદુઓ (0,0),(2,0),(0,4). ક્ષેત્રફળ = ½ × 2 × 4 = 4. સીધી ગણતરી.
વિકલ્પાત્મક ચકાસણી (Option Verification Shortcut): જો તમારું સંપૂર્ણ ઉકેલ કઠિન લાગે, તો વિકલ્પોના મૂલ્યો પ્રશ્નની તમામ શરતોમાં મૂકો. જે વિકલ્પ તમામ શરતો પૂરી કરે તે જવાબ છે. GUJCET માં આ સૌથી પ્રભાવશાળી ટ્રેપ-બ્રેકર.
અંતિમ પ્રશ્ન જેમ ગૂંચવણભર્યો લાગે અથવા સમય ઓછો હોય. તમામ વિકલ્પો ચકાસીને ગલત વિકલ્પો દૂર કરો. 2–3 મિનિટમાં જવાબ મળી જાય.
દા.ત.: કઈ જોડ (a,b) ઉકેલક્ષેત્રમાં નથી? a) (1,2) b) (2,1) c) (3,3) d) (0,0) — તમામ શરતોમાં દરેક મૂકો. (3,3): 3+3=6>5 → દૂર. જવાબ c.
