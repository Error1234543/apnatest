રેખીય અસમતાઓ (Linear Inequalities) — મહત્વપૂર્ણ બિંદુઓ

🧪 GUJCET — Gujarati • Mathematics • Linear Inequalities

⭐ મહત્વના મુદ્દા

અસમતાના ચિન્હો: < (કડક ઓછું), > (કડક વધુ), ≤ (ઓછું અથવા સમાન), ≥ (વધુ અથવા સમાન). = ચિન્હ સાથે મિશ્ર ન કરવા.
GUJCET માં પ્રશ્નમાં ચિન્હની સૂક્ષ્મ વ્યતિરિક્તા પૂછાય છે; ખાસ કરીને ≤ અને < વચ્ચેનો ફરક.
રેખીય અસમતા એ એવી અસમતા જેમાં ચલ (variable) નો ઉચ્ચતમ ઘાત 1 હોય, જેમ કે ax + b < c, ax + by ≥ d.
ઘાત ઓળખવી જરૂરી; 1 થી વધુ ઘાત આવે તો તે રેખીય અસમતા નથી.
અસમતાના બંને બાજુએ同一个 સંખ્યા ઉમેરવા અથવા બાદ કરવાથી અસમતાનું સૂચિહ્ન બદલાતું નથી.
આ ગુણધર્મનો ઉપયોગ પદોને એક બાજુ એકઠા કરવા માટે વારંવાર થાય છે.
અસમતાના બંને બાજુએ ધન સંખ્યાથી ગુણવા અથવા ભાગવાથી સૂચિહ્ન બદલાતું નથી.
ધન ગુણક સાથેની ક્રિયા સામાન્ય છે; પરંતુ ઋણ ગુણકનું સૂચિહ્ન બદલાય છે, તેનો ફરક સમજવો.
અસમતાના બંને બાજુએ ઋણ સંખ્યાથી ગુણવા અથવા ભાગવાથી અસમતાનું સૂચિહ્ન વિપરીત થાય છે (ઉલટાઈ જાય છે).
આ ગુણધર્મ GUJCET માં સૌથી વધુ પડતાં નંબરની ભૂલ માટે પ્રખ્યાત છે; ખાસ ધ્યાન આપવું.
જો a < b હોય, તો −a > −b હોય છે. આ ઋણ લીને અસમતા ઉલટાવવાનો સીધો નિયમ છે.
પરોક્ષ રીતે ઋણ લેવાના પ્રશ્નોમાં આ નિયમ સીધો ઉપયોગ થાય છે.
એક-ચલ રેખીય અસમતાનો ઉકેલ એ વાસ્તવિક સંખ્યાઓનો ઉપસમૂહ (subset of ℝ) હોય છે.
ઉકેલ સમૂહની પ્રકૃતિ સમજવી જરૂરી; ખાલી સમૂહ અથવા બધી વાસ્તવિક સંખ્યાઓ પણ શક્ય ઉકેલો છે.
સંકલન (union) ને બદલે છેદન (intersection) નો ઉપયોગ: બે અસમતાઓના સામાન્ય ઉકેલો શોધવા માટે છેદન લેવું પડે છે.
GUJCET માં બંને શરતો સાથેનો ઉકેલ મેળવવા છતાં સામાન્ય ભૂલ: union અને intersectionની ગડબડ.
અંતરાલ સંકેત: (a, b) = {x : a < x < b}, [a, b] = {x : a ≤ x ≤ b}. બંધ બ્રેકેટ ≤/≥ માટે, ખુલ્લું બ્રેકેટ < /> માટે.
અંતરાલ સંકેત જાણવો અનિવાર્ય; GUJCET માં ઉકેલ અંતરાલ સ્વરૂપે પૂછાય છે.
અનેકસંધિ (compound) અસમતા: a < x ≤ b સ્વરૂપની અસમતાને બે ભાગમાં વિભાજિત કરી ઉકેલવાનો નિયમ.
GUJCET માં અનેકસંધિ અસમતાઓ નિયમિત પૂછાય છે; બંને શરતો એકસાથે સંતોષાવી પડે છે.
રેખાખંડ પર ગ્રાફિકલ દર્શન: બંધ વર્તુળ (●) ≤/≥ માટે, ખાલી વર્તુળ (○) < /> માટે.
GUJCET માં ગ્રાફિકલ ઉત્તરો માટે આ પ્રમાણભૂત પ્રસ્તુતિ પૂછાય છે.
બે ચલવાળી રેખીય અસમતા ax + by ≤ c નો ઉકેલતલ (solution half-plane) અવકાશમાં એક અર્ધ-સમતલ હોય છે.
અર્ધ-સમતલ ખ્યાલ બહુચલ રેખીય અસમતા પ્રણાલીના ગ્રાફિકલ ઉકેલનો પાયો છે.
રેખા ax + by = c બાઈનરી (બાઈનરી) રેખા છે. અસમતા ≤ અથવા ≥ હોય તો રેખા સમાવિષ્ટ હોય, < અથવા > હોય તો રેખા સમાવિષ્ટ ન હોય.
GUJCET માં રેખા સમાવિષ્ટ છે કે નહીં તે પ્રશ્નની ગેરહાજરીમાં પણ ભૂલ થાય છે.
પરીક્ષણ બિંદુ (test point): ઉકેલતલ શોધવા માટે મૂળબિંદુ (0,0) ધરાવતી બાજુ છે કે નહીં તે તપાસવા માટે (0,0) મૂલ્ય મૂકી ચકાસવું.
રેખા (0,0) માંથી પસાર ન થતી હોય તો પરીક્ષણ બિંદુની પદ્ધતિ અનિવાર્ય.
બહુ-અસમતા પ્રણાલીનો ઉકેલ સમૂહ: દરેક અસમતાના ઉકેલતલોનું છેદન. તેથી ઉકેલ ક્ષેત્ર (feasible region) બંધ બહુભુજ હોય છે.
GUJCET માં ક્ષેત્રફળ, શિરોબિંદુઓ કે ઉકેલશક્યતા ચકાસવા આ ખ્યાલ આવશ્યક છે.
ક્ષેત્રફળશૂન્ય અથવા શૂન્ય ઉકેલ સમૂહ: જો બધી અસમતાઓનો છેદન શૂન્ય હોય, તો ઉકેલશૂન્ય અસમતાપ્રણાલી છે.
ક્યારેક પ્રશ્નમાં 'ઉકેલ શક્ય નથી' પસંદગી આપવામાં આવે છે; તે ઓળખવું જરૂરી.
બહુભુજીય ઉકેલક્ષેત્રના શિરોબિંદુઓ (corner points): આ બિંદુઓ રેખાઓના છેદનબિંદુઓ પરથી મેળવી શકાય.
GUJCET માં ઘણીવાર શિરોબિંદુઓના યામ પૂછાય છે; છેદનબિંદુ શોધવાની રીત પ્રમાણભૂત છે.
અસમતાઓમાં અચળાંકોને ડાબી બાજુ લઈ જતાં ચિન્હ બદલાય (ઉમેરક-બાદક ગુણધર્મ). સંકલન સાથેનો ઉકેલ: ક્રમબદ્ધ અવયવીકરણ નથી, માત્ર સંકલન.
સમીકરણો અને અસમતાઓ વચ્ચેનો તફાવત સ્પષ્ટ કરવો.
અંશ-છેદસ્ફૂરત અસમતા (rational inequality): ઉકેલવા માટે અંતરાલ પદ્ધતિ (interval/method-of-signs) નો ઉપયોગ થાય છે.
GUJCET માં rational inequalities સામાન્યતઃ અંતરાલ પદ્ધતિથી ઉકેલાય છે; મૂળબિંદુઓ (zeros) અને અવિભાજ્ય બિંદુઓ (undefined points) ઓળખવા જરૂરી.
અંતરાલ પદ્ધતિમાં: પૂર્ણાંક બિંદુઓ, વિંદુઓ, અને ચિન્હ-બદલાવના બિંદુઓને અંતરાલમાં વિભાજિત કરી દરેક અંતરાલમાં ચિન્હ તપાસવું.
આ પદ્ધતિ GUJCET માં rational અને polynomial અસમતા બંને માટે સામાન્ય છે.
અસમતાનો ઉકેલ ગ્રાફ સ્વરૂપે દર્શાવતાં: x-અક્ષ પર અંતરાલ દોરી, બંધ બિંદુ ≤/≥, ખુલ્લું બિંદુ < />, બિંદુની ડાબી/જમણી બાજુ ભરવું.
GUJCET માં ગ્રાફિકલ પ્રસ્તુતિને અનુરૂપ આકાર દોરવો આવશ્યક છે.
સમાન અસમતા ગુણધર્મ: જો a < b અને b < c, તો a < c (સંક્રામકધર્મ). આ ગુણધર્મ દ્વારા શ્રેણિક-અસમતાઓનો ઉકેલ મેળવી શકાય.
સંક્રામકધર્મનો ઉપયોગ ચકાસણી પ્રશ્નોમાં થાય છે.
અંતરાલ-સંકલન નિયમ: ઉકેલ સમૂહને યોગ્ય રીતે અંતરાલોના સંકલન સ્વરૂપે લખવું, દા.ત., (−∞, 2) ∪ (3, 5].
GUJCET માં ઉકેલ અંતરાલ સ્વરૂપે જ લખવાનો નિયમ છે; સંકલન/છેદન નિશ્ચિત રીતે બાકાદ કરવું.
બહુ-ચલ અસમતા પ્રણાલીમાં શક્ય ઉકેલક્ષેત્ર બંધ/અબંધ બહુભુજ હોઈ શકે; અનંત ઉકેલક્ષેત્ર પણ શક્ય છે.
GUJCET માં શક્ય/અશક્ય/અનંત ઉકેલક્ષેત્રની ઓળખ પ્રશ્નો આવે છે.
ચલનો ગુણાંક ઋણ હોય ત્યારે અસમતા ઉકેલવા બંને બાજુને ઋણ સંખ્યાથી ગુણી/ભાગી શકાય; પરંતુ સૂચિહ્ન બદલાય છે એ સૂक्ष्म યાદ રાખવું.
GUJCET માં આ એક પ્રमुख ભૂલબિંદુ છે; ઋણ ગુણાંકની ચકાસણી આવશ્યક.
