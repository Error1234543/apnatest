રેખીય અસમતાઓ — ઝડપી સમીક્ષા

🧪 GUJCET — Gujarati • Mathematics • Linear Inequalities

📘 વ્યાખ્યાઓ

  • અસમતા (Inequality): બે રાશિઓ વચ્ચેનો '<', '>', '≤' કે '≥' ચિહ્ન દ્વારા પ્રગટ થતો સંબંધ.
  • રેખીય અસમતા: એક ચલમાં, પ્રથમ ઘાત ધરાવતી અસમતા, જેમ કે ax + b > 0 (જ્યાં a ≠ 0).
  • અંતરાલ (Interval): યથાર્થ સંખ્યા રેખા પરના બે અંત્યબિંદુઓ વચ્ચેના બિંદુઓનો સમૂહ.
  • ઓપન અંતરાલ (Open Interval): અંત્યબિંદુઓ સમાવેલ ન હોય, કૌંસ ( ) વડે દર્શાવેલ, જેમ કે (a, b).
  • ક્લોઝડ અંતરાલ (Closed Interval): અંત્યબિંદુઓ સમાવેલ હોય, કૉઠા [ ] વડે દર્શાવેલ, જેમ કે [a, b].
  • અર્ધ-ખુલ્લો અંતરાલ (Half-open Interval): એક બિંદુ સમાવેલ અને બીજું બહાર, જેમ કે [a, b) અથવા (a, b].
  • અનંત અંતરાલ (Unbounded Interval): જ્યાં એક અથવા બંને અંત્યબિંદુ અનંત (+∞ કે –∞) હોય.
  • સેટ-બિલ્ડર રૂપ (Set-builder Notation): {x : x ની શરત} આ રીતે અસમતાનું ઉકેલ સમૂહ દર્શાવવો.
  • સંયુક્ત અસમતા (Compound Inequality): બે અથવા વધુ અસમતાઓનું એકસાથે પ્રસ્તુતિકરણ.
  • પરિપક્વ અંતરાલ (Bounded Interval): જેના બંને અંત્યબિંદુ યથાર્થ સંખ્યાઓ હોય.

⚡ સૂત્રો

  • ax + b > 0 → x > –b/a (જો a > 0 હોય તો દિશા આવતી રહે).
  • ax + b ≤ 0 → x ≤ –b/a (જો a > 0 હોય તો દિશા આવતી રહે).
  • |x| = a (a > 0) → x = ±a.
  • |x| < a (a > 0) → –a < x < a, એટલે x ∈ (–a, a).
  • |x| > a (a > 0) → x < –a અથવા x > a, એટલે x ∈ (–∞, –a) ∪ (a, ∞).
  • |x| ≤ a (a > 0) → –a ≤ x ≤ a, એટલે x ∈ [–a, a].
  • |x| ≥ a (a > 0) → x ≤ –a અથવા x ≥ a, એટલે x ∈ (–∞, –a] ∪ [a, ∞).
  • x < a → x ∈ (–∞, a), x ≤ a → x ∈ (–∞, a].
  • x > a → x ∈ (a, ∞), x ≥ a → x ∈ [a, ∞).
  • a < x < b → x ∈ (a, b), a ≤ x ≤ b → x ∈ [a, b].

⭐ મુખ્ય તથ્યો

  • રેખીય અસમતાનું ઉકેલ સૌદાય રેખા પરનો એક અંતરાલ હોય છે.
  • આંકરેખા (Number Line) પર ઉકેલ દર્શાવતી વખતે સંજ્ઞા ચિહ્ન મહત્વની છે.
  • ખૂલી ગોળી (○) = ખુલ્લો બિંદુ (boundary બહાર), ભરેલી ગોળી (●) = બંધ બિંદુ (boundary અંદર).
  • બે અસમતાઓનું સામાન્ય ઉકેલ એ તેમના અંતરાલોનો છેદ (Intersection) હોય છે.
  • ∞ અથવા –∞ કદાચ કૌંસ ( ) માં જ લખવું, કૉઠા [ ] નહીં.
  • ઉકેલ અંતરાલ લખતી વખતે નાનાથી મોટા ક્રમમાં લખવું.
  • રેખીય અસમતાની દરેક પદાવલીની ડાબી બાજુનું સમીકરણ સીધી રેખા આપે છે.
  • એક ચલવાળી રેખીય અસમતાનું ઉકેલ એકપરિમાણીય વિસ્તાર હોય છે.
  • અસમતાના બંને બાજુએ સમાન પદ ઉમેરવા/બાદ કરવાથી દિશા બદલાતી નથી.
  • ગુણાકાર/ભાગાકાર દ્વારા દિશા ફરીથી ચકાસવી — ઋણ સંખ્યા હોય તો દિશા ઉલટાવવી.

⚠️ સામાન્ય ભૂલો

  • ઋણ સંખ્યા વડે ગુણતા/ભાગતા અસમતાની દિશા બદલાતી નથી તેવી ભૂલ.
  • |x| < a → x < ±a લખવાની ભૂલ (સાચું: –a < x < a).
  • |x| > a → –a < x < a લખવાની ભૂલ (સાચું: બહારનો વિસ્તાર).
  • અંતરાલ લખતી વખતે [ અને ) નો ભ્રમ — ગોળી અને કૉઠા/કૌંસનો સંબંધ ગુંચવણ.
  • x ∈ (–∞, 5]ને x < 5 માની લેવી (સાચું: x ≤ 5).
  • સંયુક્ત અસમતામાં AND (∧) અને OR (∨) વચ્ચેનો તફાવત મૂળભૂત રીતે ભૂલવો.
  • બંને બાજુ વર્ગ કરતી વખતે અસમતાની દિશા વિશે ધ્યાન ન આપવું.
  • અનંત સુધીનો અંતરાલ લખતી વખતે ∞ સાથે કૉઠા [ લખી દેવા.
  • ઉકેલ અંતરાલનો છેદ લેતી વખતે ઓછામાં ઓછું બિંદુ ધ્યાનમાં લેવું.
  • અસમતાના બંને બાજુ શૂન્ય વડે ગુણવા/ભાગવાનો પ્રયત્ન (અવૈધ).

🔥 હાઈ-યીલ્ડ મુદ્દા

  • ઋણ સંખ્યા વડે ગુણતા/ભાગતા ચિહ્ન ફરીથી ફરવું — આ સૌથી મહત્વનું નિયમ છે.
  • અંતરાલ નિરૂપણમાં કૌંસ ( ) = ખુલ્લું, કૉઠા [ ] = બંધ — આ ચોકસાઈથી રેખા પર દર્શાવવું.
  • સંયુક્ત અસમતાનો ઉકેલ મેળવવા બંને અસમતાઓનો ઉકેલ અંતરાલ શોધી છેદ (Intersection) લેવો.
  • પરિપક્વ અંતરાલનો ઉકેલ મેળવવા માટે મૂળબિંદુ પદ્ધતિ (Test Point Method) વાપરવી.
  • બીજગણિતીય પદ્ધતિથી ઉકેલતાં પ્રથમ રેખીય સમીકરણ તરીકે ઉકેલતાં ચિહ્ન ચકાસવું.
  • આપેલ ઉકેલ અંતરાલ પરથી અસમતાનું નિરૂપણ કરવું — ઉલ્ટો પ્રશ્ન પણ આવે છે.
  • રેખા પર દર્શાવતી વખતે દિશા તীর (Arrow) → ધન અનંત તરફ, ← ઋણ અનંત તરફ.
  • |x – c| < R → x ∈ (c – R, c + R); |x – c| > R → x ∈ (–∞, c–R) ∪ (c+R, ∞).
  • સમગ્ર યથાર્થ સંખ્યાઓનો સમૂહ R = (–∞, ∞) એ અનંત અંતરાલ છે.
  • ઉકેલ અંતરાલ યોગ્ય રીતે લખવો: (-3, 5], [0, ∞), (–∞, 7) વગેરે.
