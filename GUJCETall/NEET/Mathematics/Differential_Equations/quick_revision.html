અધ્યાય: વિકલ સમીકરણો — ક્વિક રિવિઝન

🧪 GUJCET — Gujarati • Mathematics • Differential Equations

🧠 યાદ રાખો

વિકલ સમીકરણ એ એવું સમીકરણ છે જેમાં અજ્ઞાત ફંક્શન, તેના ચલો અને આંશિક/સામાન્ય વિકલજોનો સમાવેશ થાય છે.
ક્રમ (Order) = સમીકરણમાં રહેલા ઉચ્ચતમ ક્રમના વિકલજનો ક્રમ; ઘાત (Degree) = ઉચ્ચતમ વિકલજની ઘાત (પહેલેથીથી બહુપદી સ્વરૂપે લખ્યા બાદ).
ચલ પૃથક્કરણ પદ્ધતિ માટે: સમીકરણને f(x)dx = g(y)dy સ્વરૂપે ગોઠવી શકાય તે જરૂરી છે.
સамघાતાંકીય (Homogeneous) વિકલ સમીકરણ: f(x, y) એકસરખી ઘાતનું હોય, એટલે કે f(tx, ty) = tⁿ f(x, y).
રેખીય વિકલ સમીકરણનું પ્રમાણિત સ્વરૂપ: dy/dx + P(x)y = Q(x); પ્રતિસ્થાપન સાધન (Integrating Factor) = e^(∫P dx).
જરૂરી પૂર્ણાહાર (Particular Integral) મેળવવા માટે સામાન્ય ઉકેલમાં k નો મૂલ્ય શોધી વિકલ સમીકરણમાં મૂકવું.
વિકલ સમીકરણ બનાવતી વખતે m સ્વૈચ્છિક અચળાંક હોય તો m વખત વિકલન કરવું પડે.

⚡ ઝડપી સૂત્રો

dy/dx = g(y)/f(x) → ∫f(x)dx = ∫g(y)dy
સамघાતાંકીય: dy/dx = F(y/x), પ્રતિસ્થાપન y = vx લેતાં dy/dx = v + x(dv/dx)
વિકલ સમીકરણ: d²y/dx² + 2a·dy/dx + a²y = 0 → v = xe^(ax) એ બીજો સ્વતંત્ર ઉકેલ
બહુપદી ચલ પદ્ધતિ: જો Q(x) એ બહુપદી હોય, તો Y.P. = (1/φ(D)) Q(x) માં D ને 0 મૂકવાથી
e^(αx) માટે Y.P. = x·e^(αx)/φ'(α) (જો φ(α) = 0)
sin(ax), cos(ax) માટે: D² = −a² મૂકીને સરળ કરવું અને પરિમેય રૂપ આપવું
∫e^x[f(x) + f'(x)]dx = e^x f(x) + C (વажેદા સૂત્ર)

✅ વન-લાઈનર્સ

વિકલ સમીકરણનો સામાન્ય ઉકેલ (General Solution) માં એક સ્વૈચ્છિક અચળાંક (constant) હોય છે, વિશેષ ઉકેલ (Particular Solution) માં અચળાંકનું ચોક્કસ મૂલ્ય હોય છે.
v = ax + by + c સમાવેષ્ટ પરિવારમાંથી વિકલ સમીકરણ બનાવવા એક વાર વિકલન કરવું પડે.
xy(dy/dx) + y² = x² → આ Samghatakya સ્વરૂપનું સમીકરણ છે (બંને પદો 2 ઘાતના).
dy/dx = (x+y)/(x−y) → u = x+y, v = x−y લેતાં પણ ઉકેલ શક્ય છે, પરંતુ y = vx પ્રતિસ્થાપન સીધું લાગુ પડે છે.
સમીકરણ 3x²(dy/dx) + 2y³ = 6xydy/dx આ સ્વરૂપની છે: M dx + N dy = 0, જ્યાં ∂M/∂y = ∂N/∂x હોય તો exact (નિશ્ચિત) સમીકરણ.
બીજે ક્રમનું સમીકરણ: d²y/dx² = f(x) → બે વાર સંકલન કરવાથી સામાન્ય ઉકેલ મળે.
જ્યારે P અને Q અચળ હોય, ત્યારે ઇન્ટિગ્રેટિંગ ફેક્ટર e^(Px) બને છે.
d/dx[e^(∫Pdx) · y] = e^(∫Pdx) · Q → જમણી બાજુનું સંકલન કરતાં y મળે.
જો φ(D)y = e^(αx)·V(x) હોય, તો Y.P. = e^(αx)·(1/φ(D+α))V(x) (Shift Theorem).
sin³x એ 3x, sin3x વગેરે રૂપમાં વિસ્તરણ કરીને U.P. શોધી શકાય.
ફંક્શનલ ડેટા (વ્યાખ્યા / ઉકેલ) સ્વરૂપે આપેલ પ્રશ્નમાં v = f(x,y) પ્રતિસ્થાપન યોગ્ય છે કે નહીં તે પહેલાં તપાસવું.
v = ax+by+c સમતલની સામાન્ય સમીકરણમાંથી 1× વિકલન, v = ax²+by+cx+d માં 2× વિકલન જરૂરી.
પ્રતિસ્થાપન y = e^(mx) લેતાં m² + am + b = 0 એ સહાયક સમીકરણ (Auxiliary Equation) બને છે.
જો સહાયક સમીકરણના મૂળ વાસ્તવિક અને અસમાન હોય: y = C₁e^(m₁x) + C₂e^(m₂x).
વિકલ સમીકરણનું ઘાત 1 હોય ત્યારે તેને પ્રથમ ક્રમનું રેખીય સમીકરણ કહે છે.
