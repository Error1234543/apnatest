અવકલન સમીકરણો (Differential Equations)

🧪 GUJCET — Gujarati • Mathematics • Differential Equations

અવકલન સમીકરણ એ એવી સમીકરણ છે જેમાં એક અથવા વધુ ચલો અને તેમના વિકલિતોનો સમાવેશ થાય છે. આ અધ્યાય શૈક્ષણિક રીતે ગાણિતિક મોડેલિંગની પાયો ધરાવે છે — ભૌતિક વિજ્ઞાન, રસાયણ વિજ્ઞાન, આર્થિકશાસ્ત્ર અને જૈવિક પ્રણાલીઓમાં વપરાતા મોડેલોનું નિર્માણ અવકલન સમીકરણો દ્વારા જ થાય છે. GUJCET પરીક્ષામાં આ અધ્યાયનો સમાવેશ પ્રમાણભૂત છે અને તેમાં ક્રમ, ઘાત, સામાન્ય અને વિશિષ્ટ ઉકેલ તથા વિભિન્ન પદ્ધતિઓના ઉકેલનો સમાવેશ થાય છે.

અવકલન સમીકરણની આવશ્યક પરિભાષાઓ

અવકલન સમીકરણ એ સંબંધ છે જેમાં એક અથવા વધુ સ્વતંત્ર ચલો, આશ્રિત ચલ અને આશ્રિત ચલના વિકલિતોનો સમાવેશ થાય છે. ક્રમ (Order) એ અવકલન સમીકરણમાં મળી આવતો સર્વોચ્ચ વિકલનનો ક્રમ દર્શાવે છે. ઉદાહરણ તરીકે, dy/dx + y = sin x માં ક્રમ 1 છે; d²y/dx² + 3(dy/dx)² + y = e^x માં ક્રમ 2 છે. ઘાત (Degree) એ સમીકરણને વિકલિતોના પૂર્ણાંક ઘાતમાં રાખ્યા બાદ સર્વોચ્ચ વિકલનની ઘાત છે. ઉદા.dy/dx + (d²y/dx²)^2 = 0 માં ઘાત 1 છે. સામાન્ય ઉકેલ (General Solution) માં અવકલન સમીકરણના ક્રમ જેટલા સ્વૈચ્છિક અચળાંકો હોય છે. વિશિષ્ટ ઉકેલ (Particular Solution) મેળવવા માટે આપેલ પ્રારંભિક/સીમા શરતો (initial/boundary conditions) વાપરવામાં આવે છે. વિપરીત પ્રક્રિયા એ વિકલનની વિપરીત છે — અવકલન સમીકરણનો ઉકેલ શોધવા માટે સંકલન (integration) નો ઉપયોગ થાય છે.

અવકલન સમીકરણનો ક્રમ અને ઘાત નક્કી કરવો

અવકલન સમીકરણનો ક્રમ અને ઘાત શોધવા માટે પ્રથમ સમીકરણને સરળ બનાવવું જરૂરી છે — વિકલિતોના નેત્ર (radicals) દૂર કરવા, લવણ-અથવા-અભિન્ન સ્વરૂપે લખવા, તથા ત્રિકોણમિતીય/ઘાતાંકીય વિધેયોમાં વિકલિતોને સ્પષ્ટ કરવા. ક્રમ શોધવા માટે ફક્ત સર્વોચ્ચ વિકલન જોવું પડે છે; ઘાત શોધવા માટે સમીકરણમાં વિકલિતોની ઘાત પૂર્ણાંક હોવી જોઈએ. ઉદાહરણ: (dy/dx)^(1/2) + y = x ની ઘાત શોધવા માટે બંને બાજુ વર્ગ કરતાં dy/dx + y² = x², ત્યાં ઘાત 1 છે. એક બીજું ઉદાહરણ: sin(d²y/dx²) = x + y અવકલન સમીકરણનો ક્રમ 2 છે પરંતુ ઘાત નિર્ધારિત થઈ શકતી નથી કારણ કે sin વિકલિતની અંદર છે. GUJCET માં ઘણી વાર પ્રશ્નોમાં ક્રમ અને ઘાત સાથે સંકળાયેલા વિષમ પ્રશ્નો પૂછવામાં આવે છે — અહીં ધ્યાન રાખવું કે ઘાત હંમેશા પૂર્ણાંક જ હોય છે, ભિન્નાત્મક ઘાત ઘાત તરીકે ગણાતી નથી.

અવકલન સમીકરણનું નિર્માણ (Formation of Differential Equations)

આપેલ પરિવારના વક્ર (family of curves) માંથી અવકલન સમીકરણ નિર્માણ કરવા માટે, પ્રથમ વક્રનું સમીકરણ લખો જેમાં સ્વૈચ્છિક અચળાંકોની સંખ્યા n હોય. ત્યારબાદ તેનું વિકલન કરો અને અચળાંકો દૂર કરો. જો n = 1 હોય તો એકવાર વિકલન કરી પૂરતું છે; n = 2 હોય તો બે વાર વિકલન કરવું પડશે. ઉદાહરણ: vrt (વર્તુળ) x² + y² = r² ના પરિવારમાંથી અવકલન સમીકરણ બનાવો. x² + y² = r² નું x ની સાપેક્ષે વિકલન કરતાં 2x + 2y(dy/dx) = 0 ⇒ x + y(dy/dx) = 0. આ એક સર્વત્ર સત્ય અવકલન સમીકરણ છે. બીજું ઉદાહરણ: y = mx + c માંથી, dy/dx = m મળે, અને m = (y-c)/x મૂકતાં dy/dx = (y-c)/(x). અચળ c દૂર કરવું ફરી વિકલન કરીને: d²y/dx² = 0. આમ અવકલન સમીકરણ મળે છે. ઉકેલમાં અચળાંકોની સંખ્યા જેટલું જ ક્રમ હોય તેવું અવકલન સમીકરણ હોવું જોઈએ — આ ચકાસણી અગત્યની છે.

ચલ-વિભાજ્ય (Separable) અવકલન સમીકરણો

જ્યારે અવકલન સમીકરણને f(x)dx = g(y)dy સ્વરૂપમાં લખી શકાય ત્યારે તેને ચલ-વિભાજ્ય (separable) અવકલન સમીકરણ કહે છે. ઉકેલની પદ્ધતિ: બધા x પદોને એ બાજુ અને y પદોને બીજી બાજુ લઈ જઈ, બંને બાજુ સંકલન કરવા. ઉદાહરણ: dy/dx = xy → dy/y = x dx → ∫(1/y)dy = ∫x dx → ln|y| = x²/2 + C → y = ±e^(x²/2+C). GUJCET માં પ્રચલિત પ્રશ્નોમાં ઘણીવાર વિપરીત ત્રિકોણમિતિય વિધેયો પણ આવે છે — ઉદા. dy/dx = 1/(xy), તો xy dy = dx → ઉકેલ x²/2 = y²/2 + C. આ પદ્ધતિ ફક્ત પ્રથમ ક્રમના સમીકરણો માટે લાગુ પડે છે. યાદ રાખવું: જો પ્રથમ ક્રમનું સમીકરણ પણ ચલ-વિભાજ્ય સ્વરૂપમાં ન લખી શકાય, તો બીજી પદ્ધતિ વાપરવી પડે છે.

સમપરિમાણ (Homogeneous) અવકલન સમીકરણો

સમપરિમાણ અવકલન સમીકરણ એ પ્રથમ ક્રમનું સમીકરણ છે જે dy/dx = F(x,y) સ્વરૂપનું હોય અને F(tx, ty) = F(x,y) હોય, એટલે કે બધા પદો સમાન ઘાતના હોય. ઉકેલ માટે y = vx મૂકવામાં આવે છે, જ્યાં v એ x નું વિધેય છે. ત્યારે dy/dx = v + x(dv/dx) મળે. આને મૂળ સમીકરણમાં મૂકતાં સમીકરણ ચલ-વિભાજ્ય સ્વરૂપમાં ફેરવાઈ જાય છે. ઉદાહરણ: dy/dx = (x² + xy)/(xy). અહીં x²+xy નું કુલ ઘાત 2 છે અને xy નું ઘાત 2 છે, તેથી સમપરિમાણ છે. y=vx મૂકતાં v + x(dv/dx) = (x²+v x²)/(vx²) = (1+v)/v → x(dv/dx) = (1+v)/v - v = (1+v-v²)/v → સમીકરણ વિભાજ્ય બને. GUJCET માં પ્રચલિત ઓળખ: જો M(x,y)dx + N(x,y)dy = 0 હોય અને M,N બંને સમાન ઘાતના સમપરિમાણ હોય, તો સમપરિમાણ સમીકરણ છે.

રેખીય અવકલન સમીકરણો (Linear Differential Equations) — પ્રથમ ભાગ

પ્રથમ ક્રમનું રેખીય અવકલન સમીકરણ (Linear Differential Equation) એ s/dx + P(x)y = Q(x) સ્વરૂપનું સમીકરણ છે, જ્યાં P(x) અને Q(x) એ x ના વિધેયો છે. આમાં y અને dy/dx બંને પ્રથમ ઘાતના છે (ગુણાકાર/ઘાત નથી). ઉકેલ પદ્ધતિ: સંકલનઅંશક (Integrating Factor, IF) = e^(∫P(x)dx) શોધવો, ત્યારબાદ ઉકેલ y·(IF) = ∫Q(x)·(IF) dx + C. ઉદાહરણ: dy/dx + (1/x)y = x². અહીં P(x) = 1/x, Q(x) = x². IF = e^(∫1/x dx) = e^(ln x) = x. ઉકેલ: y·x = ∫x³ dx = x⁴/4 + C → y = x³/4 + C/x. આ પદ્ધતિ GUJCET માં ખૂબ જ મહત્વપૂર્ણ છે કારણ કે ઘણા પ્રશ્નો આ સ્વરૂપમાં જ આવે છે.

રેખીય અવકલન સમીકરણો — પ્રકાર II (y ની સાપેક્ષે રેખીય)

કેટલાંક અવકલન સમીકરણો મૂળ સ્વરૂપમાં dy/dx + Py = Q ન હોય, પરંતુ જ્યારે x ને y નું વિધેય માનીએ ત્યારે dx/dy + Px = Q સ્વરૂપ મેળવી શકાય. આવા સમીકરણો પણ રેખીય છે અને તેમનો ઉકેલ સમાન પદ્ધતિથી મળે છે, ફક્ત IF = e^(∫P dy) અને ઉકેલ x·(IF) = ∫Q·(IF) dy + C. ઉદાહરણ: dy/dx = y/(x+y²) → ઉકેલ સીધો મળતો નથી. પરંતુ dx/dy = (x+y²)/y = x/y + y મૂકતાં dx/dy - (1/y)x = y, જે પ્રકાર I સ્વરૂપ છે. અહીં P = -1/y, Q = y. IF = e^(-∫1/y dy) = e^(-ln y) = 1/y. ઉકેલ: x·(1/y) = ∫y·(1/y) dy = ∫1 dy = y + C → x = y² + Cy. આ પ્રકારના પ્રશ્નો GUJCET માં ઊંચા અંકના હોય છે.

વિકલન સમીકરણોનાં વિશેષ સ્વરૂપો

કેટલાંક સમીકરણો મૂળ સ્વરૂપમાં પ્રમાણભૂત ન હોય, પરંતુ ચોક્કસ બદલાવથી પ્રમાણભૂત સ્વરૂપમાં ફેરવી શકાય. મહત્વના સ્વરૂપો: (a) Bernoulli સમીકરણ: dy/dx + Py = Qy^n — y^(-n) વડે ગુણીને અને v = y^(1-n) મૂકીને રેખીય બનાવી શકાય. (b) સમપરિમાણ પરંતુ ઘાત અલગ હોય તેવા સમીકરણોમાં સુધારો: dy/dx = F(ax+by+c) — u = ax+by+c મૂકો. (c) સ્વરૂપ (bx+ay+c)/px+qy+r વાળા સમીકરણોમાં h,k શોધીને x=X+h, y=Y+k મૂકો. (d) સમીકરણો જેમાં M dx + N dy = 0 હોય અને ∂M/∂y = ∂N/∂x હોય, તે એકસૂત્રી (exact) છે. GUJCET માં ઘણા પ્રશ્નો આ પ્રકારનાં વિશેષ સ્વરૂપો પર આધારિત હોય છે, તેથી આ બધા પદ્ધતિઓનું સ્પષ્ટ જ્ઞાન જરૂરી છે.

ઉકેલની તપાસ અને પ્રારંભિક/સીમા શરતો (Initial/Boundary Conditions)

કોઈપણ અવકલન સમીકરણના સામાન્ય ઉકેલમાં એક અથવા વધુ સ્વૈચ્છિક અચળાંકો હોય છે. જ્યારે પ્રારંભિક શરત (initial condition) આપેલી હોય — ઉદા. y(0) = 1 — તો તેને સામાન્ય ઉકેલમાં મૂકીને સ્વૈચ્છિક અચળાંકનો ચોક્કસ મૂલ્ય શોધી શકાય. આનાથી વિશિષ્ટ ઉકેલ (particular solution) મળે છે. ઉદાહરણ: dy/dx = 2x, y(0) = 3. સામાન્ય ઉકેલ y = x² + C. y(0) = 3 ⇒ 3 = 0 + C ⇒ C = 3. વિશિષ્ટ ઉકેલ: y = x² + 3. સીમા શરતો (boundary conditions) માં પણ તે જ પ્રકારે ઉકેલમાં મૂકીને અચળાંક શોધવામાં આવે છે. ઉકેલની તપાસ: મળેલા વિશિષ્ટ ઉકેલનું વિકલન કરીને મૂળ સમીકરણમાં મૂકીને બંને બાજુ સમાન તપાસો. આ તપાસ પરીક્ષામાં સમય બચાવે છે અને ભૂલો ટાળે છે.

GUJCET સંદર્ભે પદ્ધતિઓનો સારાંશ અને ઓળખ

GUJCET પરીક્ષામાં અવકલન સમીકરણોના પ્રશ્નો ચોક્કસ પદ્ધતિઓ પર આધારિત હોય છે. પહેલાં દરેક સમીકરણને જોઈને તેનું પ્રકાર નક્કી કરવું જરૂરી છે. જો dy/dx = f(x)g(y) સ્વરૂપમાં હોય → ચલ-વિભાજ્ય પદ્ધતિ. જો dy/dx = F(x,y) જ્યાં F(tx,ty)=F(x,y) → સમપરિમાણ પદ્ધતિ (y=vx). જો dy/dx + Py = Q → રેખીય પદ્ધતિ (IF). જો dx/dy + Px = Q બનતું હોય → પ્રકાર II. જો dy/dx = f(ax+by+c) → u=ax+by+c. આ પ્રકારોની ઝડપી ઓળખ GUJCET માં સમય સંરક્ષણ કરે છે. વધુમાં, દરેક પ્રકારનો કંઈક સમય લાગે છે — રેખીય અને સમપરિમાણ પ્રશ્નોમાં ઘણી ગણતરી હોય છે, તેથી સંકલન સૂત્રો સાચાં રાખવા જરૂરી છે. દરેક ઉકેલમાં અચળાંક C ને ભૂલવો મહત્વની ભૂલ છે, તેથી ઉકેલ લખતી વખતે C હંમેશા ઉમેરો.

⚡ સૂત્રો

સામાન્ય ઉકેલમાં સ્વૈચ્છિક અચળાંકોની સંખ્યા = અવકલન સમીકરણનો ક્રમ
ચલ-વિભાજ્ય સમીકરણ: f(x)dx = g(y)dy → ∫f(x)dx = ∫g(y)dy + C
સમપરિમાણ સમીકરણ: y = vx મૂકો, તો dy/dx = v + x(dv/dx)
રેખીય સમીકરણ પ્રકાર I: dy/dx + P(x)y = Q(x)
રેખીય સમીકરણ પ્રકાર I નો ઉકેલ: y·(IF) = ∫Q·(IF) dx + C, જ્યાં IF = e^(∫P dx)
રેખીય સમીકરણ પ્રકાર II: dx/dy + P(y)x = Q(y)
રેખીય સમીકરણ પ્રકાર II નો ઉકેલ: x·(IF) = ∫Q·(IF) dy + C, જ્યાં IF = e^(∫P dy)
Bernoulli સમીકરણ: dy/dx + Py = Qy^n → v = y^(1-n) મૂકીને રેખીય બનાવો
એકસૂત્રી (Exact) સમીકરણ: ∂M/∂y = ∂N/∂x હોય તો M dx + N dy = 0
એકસૂત્રી સમીકરણનો ઉકેલ: ∫(M માં x ના પદ)dx + ∫(M માં y ના પદ)dy = C
સમપરિમાણ ઘાત નિર્ધારણ: F(tx, ty) = tⁿ F(x,y) → ઘાત n
u = ax + by + c મૂકીને dy/dx = f(ax+by+c) ને સમપરિમાણ બનાવો

⭐ મહત્વના મુદ્દા

  • અવકલન સમીકરણનો ક્રમ એ સર્વોચ્ચ વિકલનનો ક્રમ છે, ઘાત એ તે વિકલનની ઘાત છે.
  • સામાન્ય ઉકેલમાં ક્રમ જેટલા સ્વૈચ્છિક અચળાંકો હોય છે.
  • રેખીય અવકલન સમીકરણમાં y અને dy/dx બંને પ્રથમ ઘાતના હોય છે.
  • સમપરિમાણ અવકલન સમીકરણમાં y = vx મૂકવું પડે છે.
  • IF (સંકલનઅંશક) હંમેશા ધન હોય છે અને ગાણિતિક રીતે હંમેશા અસ્તિત્વ ધરાવે છે.
  • દરેક અનિર્ધારિત સંકલનમાં સ્વૈચ્છિક અચળાંક C ઉમેરવો જરૂરી છે.
  • અવકલન સમીકરણના ઉકેલને વક્રાવલી (family of curves) કહી શકાય.
  • dy/dx = f(x) સ્વરૂપના સમીકરણનો ઉકેલ સીધો y = ∫f(x)dx + C થાય.
  • જો s/dx + Py = Q હોય અને P, Q અચળ હોય, તો પણ રેખીય પદ્ધતિ લાગુ પડે છે.
  • GUJCET માં ઘણા પ્રશ્નો સીધા સૂત્ર/પદ્ધતિ ઓળખવાના આધારિત હોય છે.
  • અવકલન સમીકરણ નિર્માણમાં, n સ્વૈચ્છિક અચળાંકો માટે n-વાર વિકલન કરવું પડે છે.

⚠️ સામાન્ય ભૂલો

રેખીય સમીકરણની ઓળખમાં ભૂલ: y² તથા (dy/dx)² વાળા પદો સામેલ હોય તો તે રેખીય નથી.
IF શોધતી વખતે સંકલન કરતાં અચળાંક C ભૂલવો — IF માં C ની જરૂર નથી.
ચલ-વિભાજ્ય કરતી વખતે ચિહ્ન (sign) ખોટું રાખવું, ખાસ કરીને (-) ને ભૂલવું.
સમપરિમાણ સમીકરણમાં y = vx મૂક્યા બાદ v + x(dv/dx) ની જગ્યાએ ફક્ત dv/dx લખવું.
ઘાત શોધતી વખતે વિકલિતોના નેત્ર દૂર કરવાનું ભૂલવું (ઉદા. √(dy/dx) ની ઘાત 1 હોય, અર્ધી નહીં).
પ્રકાર II સમીકરણમાં dx/dy પરિવર્તન પછી IF = e^(∫P dy) મૂકવું બાકી રાખવું.
ઉકેલમાં અચળાંક C ને સંકલન પછી ઉમેરવાનું ભૂલવું — તે સૌથી સામાન્ય ભૂલ છે.
સમપરિમાણ સમીકરણમાં ઘાતની ગણતરી કરતી વખતે બધા પદોની ઘાત સમાન ન હોય તે બાકી રાખવી.
ત્રિકોણમિતિય સંકલનો ખોટા ઉપયોગ — ∫tan x dx = -ln|cos x| હોય, ln|sin x| નહીં.
અવકલન સમીકરણ નિર્માણમાં અચળાંકો દૂર કરતી વખતે પરસ્પર વિરોધી વિધાન લખવું.
ઉકેલની તપાસ કરવાનું ભૂલવું — વિશિષ્ટ ઉકેલનો ઉપયોગ ન કરવો.

🎯 પરીક્ષા ટિપ્સ

GUJCET માં પ્રથમ અંકનો પ્રશ્ન ઘણીવાર ક્રમ-ઘાત પર આધારિત હોય છે — ઝડપથી ઉકેલો.
રેખીય અવકલન સમીકરણનો ઉકેલ શોધતી વખતે IF ઘણીવાર સરળ બને છે (ઉદા. e^(ln x) = x).
સમીકરણ જોઈને પહેલાં પ્રકાર નક્કી કરો, ત્યારબાદ પદ્ધતિ અપનાવો — સમય બચે છે.
દરેક સંકલન બાદ C ઉમેરવાની આદત પાડો — આ ભૂલ ઓછી કરશે.
સમપરિમાણ સમીકરણમાં y=vx મૂક્યા બાદ સમીકરણ સરળ બનાવીને ચલ-વિભાજ્ય બનાવો.
ઘણી વખત પ્રશ્નોમાં Q(x) અથવા P(x) સરળ પદાવલી હોય છે — તેનું સંકલન યાદ કરો.
અવકલન સમીકરણ નિર્માણ પ્રશ્નોમાં, અંતિમ સમીકરણમાં કોઈ સ્વૈચ્છિક અચળાંક બાકી ન રહે.
પ્રારંભિક શરતવાળા પ્રશ્નોમાં ઉકેલ મળ્યા બાદ તરત જ C નું મૂલ્ય મેળવો.
દૈનંદિન ગણતરીમાં સંકલન સૂત્રોનું જાળવણી જરૂરી છે — કંઈક ત્રૂટી સમય બગાડે છે.
પરીક્ષામાં અવકલન સમીકરણના પ્રશ્નો સામાન્ય રીતે 2-4 અંકના હોય છે — 5-7 મિનિટ વાપરો.

📌 સારાંશ

અવકલન સમીકરણોનો અધ્યાય ગાણિતિક modeling નો પાયો ધરાવે છે. આ અધ્યાયમાં અવકલન સમીકરણની મૂળભૂત પરિભાષાઓ (ક્રમ, ઘાત, સામાન્ય તથા વિશિષ્ટ ઉકેલ), અવકલન સમીકરણ નિર્માણ (પરિવારના વક્રોમાંથી), ચલ-વિભાજ્ય પદ્ધતિ, સમપરિમાણ પદ્ધતિ (y=vx), રેખીય અવકલન સમીકરણો (પ્રકાર I અને II, IF પદ્ધતિ), અને વિશેષ સ્વરૂપો (Bernoulli, exact, u=ax+by+c) નો સમાવેશ થાય છે. GUJCET માં આ અધ્યાયના પ્રશ્નો મુખ્યત્વે પદ્ધતિ ઓળખ અને ગણતરી પર આધારિત હોય છે. દરેક ઉકેલમાં સ્વૈચ્છિક અચળાંક C ભૂલવો ન જોઈએ, અને રેખીય સમીકરણમાં IF ની યોગ્ય ગણતરી અગત્યની છે. સંકલન સૂત્રોની યાદદાસ્ત તથા ચિહ્નો પ્રત્યે ધ્યાન આપવાથી સ્કોર બાકી રહેશે.
