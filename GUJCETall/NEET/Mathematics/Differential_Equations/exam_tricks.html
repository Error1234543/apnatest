🎯 પરીક્ષા ટ્રિક્સ

ચલ વિભાજ્ય પદ્ધતિ (Variable Separable) — સૌથી પ્રથમ તપાસો
જ્યારે f(x,y) = g(x)·h(y) સ્વરૂપમાં લખી શકાય ત્યારે, અન્ય પદ્ધતિઓની તપાસ કર્યા વિના
દા.ત.: dy/dx = eˣ · eʸ → e^(-y) dy = eˣ dx એવી રીતે તરત અલગ કરી શકાય; સીધું સંકલન કરો.
સમાનતા (Homogeneous) — f(x,y) બધા સમાન ઘાતના હોય ત્યારે v = y/x મૂકો
P(x,y) અને Q(x,y) બંને સમાન ઘાતના પદો ધરાવતાં હોય, ઉદા. x²y dx + xy² dy = 0
દા.ત.: dy/dx = (x²+y²)/(xy) → y = vx મૂકો → dv/dxનું સમીકરણ ચલ વિભાજ્ય બને છે.
રેખીય વિકલ સમીકરણ — IF = e^(∫P dx) યાદ રાખો
dy/dx + Py = Q જ્યાં P, Q ફક્ત xના વિધેય હોય અથવા બંને yના વિધેય હોય (આવર્તન ગોઠવો)
દા.ત.: dy/dx + (1/x)y = x² → IF = e^∫(1/x)dx = x → ઉકેલ: y·x = ∫x³dx = x⁴/4 + C
MCQમાં ચોક્કસ ઉકેલ (Particular Solution) — દરેક વિકલ્પમાં x, y મૂકીને C શોધો
પ્રારંભિક શરત (Initial Condition) આપેલ હોય, જ્યારે સામાન્ય ઉકેલ પહેલેથી હોય
દા.ત.: y(0)=1 મળે, તો x=0, y=1 મૂકીને C શોધો; વિકલ્પોમાં આ C મેચ થતો હોય તે પસંદ કરો.
ક્રમ (Order) અને ઘાત (Degree) — સૌથી પહેલાં સમીકરણને વિકલજ-રહિત બનાવો
સમીકરણમાં √(dy/dx), sin(dy/dx), e^(d²y/dx²) જેવા પદો હોય
દા.ત.: √(1+dy/dx) = y → બંને બાજુ વર્ગ કરો: 1+dy/dx = y² → Degree = 1; Order = 1.
ઘાતીય/લઘુગણકીય સમીકરણ — ઘાતાંક દૂર કરો, પછી Degree નક્કી કરો
e^(dy/dx) = x + y અથવા ln(dy/dx) = x + y જેવા સમીકરણો
દા.ત.: e^(dy/dx)=x+y → dy/dx = ln(x+y) → Degree = 1, Order = 1.
ચલ વિભાજ્યમાં દ્વિપદી અવયવ — યોગ્ય વિભાજન ઓળખો
dy/dx = (2x+1)/(3y-2) અથવા તેજસ્વી અવયબંધવાળા પદ
દા.ત.: dy/dx = x/(y-1) → (y-1)dy = xdx → ∫(y-1)dy = ∫xdx → (y-1)²/2 = x²/2 + C.
સમાન સમીકરણ — ax+by+c / a'x+b'y+c' પ્રકાર, c,c' શૂન્ય હોય તો v=x,y અથવા v=ax+by મૂકો
dy/dx = (x+y+1)/(2x+2y+3) જેવું સમીકરણ
દા.ત.: dy/dx=(x+y+1)/(2x+2y+3): v=x+y મૂકો → dv/dx = 1+(x+y+1)/(2(x+y)+3) → ચલ વિભાજ્ય.
રૂપાંતરણ યોગ્ય — P = 1/y અથવા Q = 1/x લેખાતું હોય ત્યારે લઘુત્તમ પ્રયાસ
dy/dx = f(ax+by+c) પ્રકારનું સમીકરણ
દા.ત.: dy/dx = tan(x+y) → v=x+y મૂકો → dv/dx = 1+tan(v) → ∫dv/(1+tanv) = x+C.
ચકાસણી દ્વારા MCQ હલ કરો — દરેક વિકલ્પનું વિકલન લો અને સમીકરણમાં મૂકો
જ્યારે સમીકરણ સરળ હોય પણ સીધો ઉકેલ લાંબો લાગે
દા.ત.: y' = 2x, vિકલ્પ (a) y=x² (b) y=x²+1 (c) y=2x → (b)નું વિકલન 2x = y', શરત સંતોષે.
Exact Differential Equation — Mdx+Ndy=0 માટે ∂M/∂y = ∂N/∂x તપાસો
MCQમાં 'exact છે કે નહીં' તે પ્રશ્ન હોય
દા.ત.: (2x+sin y)dx + (x cos y)dy = 0 → ∂M/∂y = cos y, ∂N/∂x = cos y → Exact! સમાધાન: x²+ x sin y = C.
IF = 1/N જ્યારે M = f(xy) અને N = g(xy)·y
જ્યારે સમીકરણ M(x,y)dx + N(x,y)dy = 0 હોય અને IF શોધવાનું હોય
દા.ત.: y·f(xy)dx + x·g(xy)dy = 0 → IF = 1/(Mx-Ny) ક્યારેક; ચોકસાઈથી Mx-Ny તપાસો.
Homogeneous functionની ઘાત — ડિગ્રી શોધવા માટે એકસાથે ગુણો
Order/Degree પ્રશ્નમાં f(tx,ty) = t^n f(x,y) તપાસવાનું હોય
દા.ત.: f(x,y)=x³+xy² → f(tx,ty)=t³x³+t³xy²=t³f → n=3; તેથી સમાન (Homogeneous).
Linear DE: Q=0 હોય તો તે Variable Separable જ બને છે, IF=1
dy/dx + Py = 0 પ્રકાર — સીધું ઉકેલ:
દા.ત.: dy/dx + 2y = 0 → dy/y = -2dx → ln|y| = -2x+C → y = Ce^(-2x) — IF વાપર્યા વિના.
Forming DE from family of curves — C ની સંખ્યા = Order; અંતિમ સમીકરણમાં C ન હોવું જોઈએ
વિકલ સમીકરણ રચના પ્રશ્ન, વિકલ્પોમાં C હોય તો ભૂલ ઓળખો
દા.ત.: y = Ax + B/A (2 પરિમાણો) → Order = 2; જો વિકલ્પમાં C હોય તો તે ખોટું.
