Card 1

अवकलन समीकरण क्या है? उदाहरण सहित स्पष्ट करें।

जिस समीकरण में एक या अधिक आंशिक/सामान्य अवकलज हों, उसे अवकल समीकरण कहते हैं। जैसे: dy/dx = x² + y , d²y/dx² – 3dy/dx + 2y = 0, dx + y·dy/dx = sin x JEE Main स्तर पर प्रथम कोटि तथा प्रथम घात के अवकल समीकरण सबसे अधिक पूछे जाते हैं।

Card 2

अवकल समीकरण की कोटि (Order) और पघात (Degree) क्या है? dy/dx = 1 + (dy/dx)² की कोटि व घात ज्ञात करें।

कोटि : समीकरण में लिये गए उच्चतम अवकलज का क्रम। पघात : कोटि को परिमेय (रैखिक) करने के बाद उच्चतम अवकलज की घात। यहाँ उच्चतम अवकलज dy/dx ही है → कोटि = 1 (dy/dx)² है → घात = 1 (चूँकि पहले से रैखिक है) अतः कोटि = 1, घात = 1

Card 3

अवकल समीकरण बनाने की विधि — उदाहरण सहित।

दिए गए किसी फलन के परिवार से अवकल समीकरण बनाने के लिए: 1. दिए गए समीकरण को x के सापेक्ष इतनी बार अवकलित करें जितने स्वतंत्र स्थिरांक (arbitrary constants) हैं। 2. उन स्थिरांकों को एलीमिनेट (उन्मूलित) करके केवल x, y और अवकलज वाले समीकरण प्राप्त करें। उदा. y = mx + c (एक रैखिक परिवार, 2 स्थिरांक m,c): य = mx + c …(i) ⇒ dy/dx = m …(ii) (ii) का पुनः अवकलन ⇒ d²y/dx² = 0 (इच्छित अवकल समीकरण)

Card 4

समाकलन गुणक (Integrating Factor, IF) की परिभाषा व पहचान कैसे करें?

जब किसी प्रथम-क्रम रैखिक अवकल समीकरण को मानक रूप dy/dx + P(x)y = Q(x) में लिखा जा सके, तो यदि हम दोनों पक्षों को e^{∫P dx} से गुणा करें, तो बायाँ पक्ष d/dx[y·e^{∫P dx}] के बराबर हो जाता है। इस गुणक को समाकलन गुणक कहते हैं। IF = e^{∫P(x)dx} स्मरण युक्ति : "+" चिह्न वाली RHS वाली रैखिक रूप में IF निकालें, "–" वाले रूप (जैसे v' – Pv = …) में IF = e^{–∫Pdx} होता है।

Card 5

प्रथम कोटि रैखिक अवकल समीकरण का सामान्य समाधान सूत्र लिखें।

मानक रूप: dy/dx + P(x)·y = Q(x) समाधान : y · IF = ∫(Q · IF) dx + C जहाँ IF = e^{∫P dx} JEE Main में P, Q अक्सर x के सरल बहुपद या त्रिकोणमितीय फलन होते हैं; ∫P dx निकालकर IF स्थापित करें, फिर ∫Q·IF dx हल करें।

Card 6

चर-पृथक्करण (Variable Separable) विधि — कब लागू होती है व हल कैसे करते हैं?

जब समीकरण को M(y)·dy = N(x)·dx के रूप में लिखा जा सके। उदा. dy/dx = (1+y²)/x ⇒ dy/(1+y²) = dx/x ⇒ ∫dy/(1+y²) = ∫dx/x ⇒ tan⁻¹y = ln|x| + C ⇒ y = tan(ln|x| + C) सावधानी : हर में (1+y²) जैसे पद होने पर cos, tan substitutions अक्सर काम आते हैं; यदि अंश में y हो तो u = y² रखने पर भी विलगन हो सकता है।

Card 7

समघाती (Homogeneous) अवकल समीकरण क्या होती है और हल करने का मानक प्रतिस्थापन क्या है?

y = f(x,y) रचना यदि इस प्रकार हो कि f(tx, ty) = f(x,y), अर्थात् अंश-हर दोनों समघाती (same degree) हों, तो समीकरण समघाती कहलाती है। प्रतिस्थापन : y = vx ⇒ dy/dx = v + x(dv/dx) इससे x व v में विलग्य रूप मिल जाता है। उदा. dy/dx = (x²+y²)/(xy) वह घात 2 है → समघाती। y = vx रखने पर v + x(dv/dx) = (1+v²)/v → X(dv/dx) = 1/v (विलग्य)

Card 8

JEE Main में最常 पूछे जाने वाले समघाती अवकल समीकरण का एक पूर्ण worked example दें।

dy/dx = (x + 2y)/(2x + y) → अंश-हर दोनों घात 1 → समघाती। y = vx, dy/dx = v + x(dv/dx) v + x dv/dx = (1+2v)/(2+v) → x dv/dx = (1+2v–v(2+v))/(2+v) = (1+2v–2v–v²)/(2+v) = (1–v²)/(2+v) → (2+v)/(1–v²) dv = dx/x → ∫[(2+v)/(1–v)(1+v)] dv = ∫dx/x आंशिक भिन्न से : 2+v = A/(1–v) + B/(1+v) A=3/2, B=1/2 → (3/2)ln|1–v| + (1/2)ln|1+v| = ln|x| + C → |1–v|^{3/2} · |1+v|^{1/2} = Cx वापस v = y/x रखें → समाधान प्राप्त हो जाता है।

Card 9

बर्नौली (Bernoulli) अवकल समीकरण क्या है और उसका हल कैसे निकालें?

रूप : dy/dx + P(x)y = Q(x)·y^n (n ≠ 0,1) हल विधि : 1. दोनों पक्ष y^n से भाग दें → y^{–n}(dy/dx) + Py^{1–n} = Q 2. प्रतिस्थापन v = y^{1–n} करें, तब dv/dx = (1–n)y^{–n}(dy/dx) 3. (1/(1–n))·dv/dx + Pv = Q → मानक रैखिक रूप 4. IF = e^{∫P(1–n)dx} रखकर हल करें। JEE Main में n = 2,3 अक्सर पूछे जाते हैं।

Card 10

प्रतिस्थापन द्वारा रैखिक रूप में बदलने वाले कुछ महत्वपूर्ण अवकल समीकरण व उनके प्रतिस्थापन बताएँ।

1. dy/dx + P(x)y = Q(x)·yⁿ → v = y^{1–n} (बर्नौली) 2. dy/dx + P(x)y = Q(x)·f(ay+b) → u = ay+b 3. dy/dx = f((ax+by+c)/(a'x+b'y+c')) → ax+by = v (यदि c=c'=0 या अनुपात समान) 4. (1+xy)dy + y(1–xy)dx = 0 → u = xy (विलग्य बना देता है) 5. dy/dx + py = q/p (p,dq/dx संक्रमित) → y = ve^{–∫p dx} रखें। इन प्रतिस्थापनों की पहचान ही JEE Main में समय बचाती है।

Card 11

सटीक (Exact) अवकल समीकरण का मानक रूप व जाँच-परীक्षण क्या है?

मानक रूप : M(x,y)dx + N(x,y)dy = 0 सटीकता की शर्त : ∂M/∂y = ∂N/∂x यदि सटीक हो, तो समाधान : ∫M dx (y को स्थिर मानकर) + ∫(N के वे पद जिनमें x नहीं है) dy = C उदा. (2xy + y²)dx + (x² + 2xy)dy = 0 M_y = 2x+2y, N_x = 2x+2y → सटीक समाधान : x²y + xy² = C

Card 12

यदि अवकल समीकरण सटीक न हो तो समाकलन गुणक कैसे ज्ञात करें?

कई विशेष स्थितियाँ ज्ञात हैं : 1. यदि (My – Nx)/N केवल x का फलन हो : μ(x) = e^{∫((My–Nx)/N)dx} 2. यदि (Nx – My)/M केवल y का फलन हो : μ(y) = e^{∫((Nx–My)/M)dy} 3. यदि रूप Mx^a y^b(αydx+βxdy)=0 है, तो IF = x^h y^k, जहाँ h = α/(β–α), k = β/(α–β) (α≠β) 4. यदि M=yφ(xy), N=xψ(xy) तो IF = 1/(Mx+Ny) इनमें से प्रथम दो JEE Main में सबसे अधिक प्रासंगिक हैं।

Card 13

प्रथम कोटि रैखिक अवकल समीकरण का HINDI नाम व व्यावहारिक हल प्रक्रिया चरण-दर-चरण लिखें।

Hindi नाम : प्रथम कोटि रैखिक अवकल समीकरण चरण : 1. समीकरण को dy/dx + P(x)y = Q(x) के रूप में लाएँ (P, Q केवल x के फलन)। 2. समाकलन गुणक IF = e^{∫P(x)dx} निकालें। 3. सामान्य समाधान : y·IF = ∫(Q·IF)dx + C 4. ∫Q·IF dx की गणना करें (अक्सर आंशिक भिन्न या प्रतिस्थापन चाहिए)। 5. C रखकर सामान्य हल लिखें।

Card 14

निम्नलिखित का हल करें : dy/dx + y/x = x², y(1)= ? ज्ञात कीजिए।

P = 1/x, Q = x² IF = e^{∫1/x dx} = e^{ln x} = x समाधान : y·x = ∫x²·x dx = ∫x³ dx = x⁴/4 + C → y = x³/4 + C/x प्रारंभिक मान y(1) यदि दिया हो तो C ज्ञात। जहाड़ उदाहरण में यदि y(1)=1 : 1 = 1/4 + C → C = 3/4 → y = x³/4 + 3/(4x)

Card 15

dy/dx = (x–y)/(x+y) का हल निकालें — यह किस प्रकार का अवकल समीकरण है?

अंश-हर दोनों घात 1 → समघाती। y = vx रखें : v + x dv/dx = (1–v)/(1+v) → x dv/dx = (1–v–v–v²)/(1+v) = (1–2v–v²)/(1+v) → (1+v)/(1–2v–v²) dv = dx/x → –½ ∫(–2–2v)/(1–2v–v²) dv = ∫dx/x → –½ ln|1–2v–v²| = ln|x| + C v = y/x रखकर पुनः लिखें : |1–2y/x–y²/x²| = K/x² → x²–2xy–y² = C

Card 16

चर-पृथक्करण योग्य अवकल समीकरण में एक आम गलती क्या है? उदाहरण सहित बताएँ।

आम गलती : जब पुनर्व्यवस्थित करने पर अंश-हर में ऐसा पद रह जाए जो विलग्य नहीं बना रहा, तब भी विलगन का नाटक करना। उदा. dy/dx = (x+y)/(x–y) → इसे सीधे विलग नहीं किया जा सकता। यह समघाती है — y=vx रखें। दूसरी आम गलती : ∫f(y)dy = ∫g(x)dx करते समयdy वाला पद dy के साथ लिखना भूल जाना अथवा चिह्न बदल देना।

Card 17

JEE Main में Differential Equations से最常 पूछे जाने वाले प्रश्नों के प्रकार कौन-कौन से हैं?

1. कोटि व घात ज्ञात करना 2. दी गई प्रारंभिक/सीमा शर्त के साथ विशिष्ट हल ज्ञात करना 3. चर-पृथक्करण / समघाती / रैखिक का वर्गीकरण व हल 4. समाकलन गुणक ज्ञात करके रैखिक रूप हल करना 5. b bernoulli रूप को रैखिक में बदलकर हल 6. सटीकता जाँच व हल 7. अवकल समीकरण द्वारा वक्र का समीकरण ज्ञात करना 8. स्पर्शरेखा/अभिलंब संबंधी ज्यामितीय शर्त से बनी अवकल समीकरण को हल करना

Card 18

यदि एक वक्र पर प्रत्येक बिंदु पर स्पर्शरेखा का ढलान y/x के बराबर हो, तो वक्र का समीकरण ज्ञात करें।

dy/dx = y/x → चर-पृथक्करण योग्य → dy/y = dx/x → ln|y| = ln|x| + C₁ → y = Cx (C = ±e^{C₁}) यह एक बिंदु (0,0) से गुजरने वाली सभी रेखाओं का परिवार है (रैखिक कुल)। JEE Main में ऐसे ज्यामितीय-शर्त आधारित प्रश्न अक्सर वक्र के परिवार को निरूपित करते हैं।

Card 19

dy/dx + y·cot x = 2 sin x का हल निकालें।

P = cot x, Q = 2 sin x IF = e^{∫cot x dx} = e^{ln|sin x|} = sin x समाधान : y·sin x = ∫2 sin x · sin x dx = 2 ∫sin²x dx = 2 ∫(1–cos2x)/2 dx = ∫(1–cos2x) dx = x – (sin2x)/2 + C अतः y = (x – (sin2x)/2 + C)/sin x

Card 20

निम्नलिखित में से कौन-सा अवकल समीकरण सटीक है ? (M dx + N dy = 0) (i) (2xy+y²)dx+(x²+2xy)dy=0 (ii) xy dx+(x²+y²)dy=0 (iii) (y cos x + sin x)dx + (cos x – xy sin x)dy = 0

Card 21

यदि (x²+y²)dx – 2xy dy = 0 का IF ज्ञात करें।

M = x²+y², N = –2xy M_y = 2y, N_x = –2y M_y – N_x = 4y (My–Nx)/N = 4y/(–2xy) = –2/x (केवल x फलन) IF = e^{∫(–2/x)dx} = e^{–2ln x} = x^{–2} = 1/x² जाँच : Multiply by 1/x² → (1+(y/x)²)dx – 2(y/x)dy = 0 → अब यह समघाती व सटीक दोनों बन जाता है।

Card 22

dv/dx = (v+x)/(v–x) का हल ज्ञात करें (y=vx प्रतिस्थापन के बाद प्राप्त हुआ रूप)।

यह स्वयं समघाती है क्योंकि अंश-हर घात 1 हैं। व further यहाँ v स्वयं y/x के स्थान पर आ चुका है; इसलिए अब इसे चल चर v मानकर समाकलन करें। (v–x)dv/dx = v+x → (v–x)dv = (v+x)dx — यह मूल रूप में वापस नहीं गया; वास्तव में यहाँ v=ty रखने की आवश्यकता नहीं — बल्कि इसे मूल चर x,v में मानकर v = ux रखें अथवा सीधे समाकलित करें। सरलतम दृष्टि : m = v/x प्रतिस्थापन रखें; m+x(dm/dx) = (m+1)/(m–1) → x dm/dx = (m+1–m(m–1))/(m–1) = (m+1–m²+m)/(m–1) = (–m²+2m+1)/(m–1) → आगे विलगन द्वारा समाकलन जारी।

Card 23

JEE Main में Differential Equations का महत्त्व कितना है? किन टॉपिक से योजक प्रश्न आते हैं?

Differential Equations से वर्ष भर में 1–2 प्रश्न आते हैं। इनके साथ अक्सर ये विषय जोड़े जाते हैं : 1. Area between curves (वक्र के क्षेत्रफल से संबद्ध अवकल समीकरण) 2. Tangent/Normal संबंधी ज्यामितीय शर्त से बनी DE 3. Growth/decay models (जीवाणु वृद्धि, रेडियोधर्मी क्षय) 4. Velocity-acceleration संबंध (गति की समस्याएँ) 5. Orthogonal trajectories (लंबवत वृत्त/परवलय) इस विषय की तैयारी Integral Calculus के साथ parallel करनी चाहिए क्योंकि दोनों के समाकलन कौशल एक दूसरे पर निर्भर करते हैं।

Card 24

निम्न का सामान्य हल ज्ञात करें : x dy – y dx = x² dy

x dy – y dx = x² dy → x dy – x² dy = y dx → dy(x – x²) = y dx → dy/y = dx/(x(1–x)) आंशिक भिन्न : 1/(x(1–x)) = 1/x + 1/(1–x) → ∫dy/y = ∫[1/x + 1/(1–x)] dx → ln|y| = ln|x| – ln|1–x| + C → y = Cx/(1–x) यह द्विघाती वर्ग (hyperbola family) का परिणाम है जो JEE Main में पुनरावृत्ति दर्शाता है।
