n! = n × (n−1) × (n−2) × ... × 2 × 1

Symbols: n! = n का क्रमचय (factorial). 0! = 1 माना जाता है।

Unit: विहीन (dimensionless count)

When to use: जब क्रम मायने रखता हो और n तत्वों को एक पंक्ति में व्यवस्थित करना हो।

Conditions: n एक धनात्मक पूर्णांक हो; अक्सर n ≥ 0।

Common mistake: 0! = 1 भूल जाना या (n−1)! ≠ n! − 1 सोचना।

P(n, r) = nPr = n! / (n−r)!

Symbols: nPr = n तत्वों में से r तत्वों का क्रमचय; क्रम महत्वपूर्ण होता है।

Unit: विहीन

When to use: तथाकथित 'क्रम चुनना' — जैसे प्राथमिकता वाली कرسیँ, ट्रेन की सीट, शब्दों की पत्रविनिमय आदि।

Conditions: 0 ≤ r ≤ n; यदि r > n तो nPr = 0।

Common mistake: nPr और nCr को आपस में उलट देना; या (n−r)! को हर में भूल जाना।

C(n, r) = nCr = n! / [r!(n−r)!]

Symbols: nCr = n तत्वों में से r तत्वों का संचयीय चयन; क्रम महत्वप नहीं रखता।

Unit: विहीन

When to use: समिति बनाना, टीम चुनना, बिना क्रम के चयन — जहाँ केवल 'कौन' चुना गया है, वह मायने रखता है।

Conditions: 0 ≤ r ≤ n; nCr = 0 यदि r > n।

Common mistake: nCr = n!/r! या n!/(n−r)! लिख देना; अर्थात् एक factor छोटा कर देना।

nCr = nC(n−r)

Symbols: nCr = n तत्वों में से r का चयन इतना ही इतना कि (n−r) तत्वों के न चुनने जैसा है।

Unit: विहीन

When to use: जब r बड़ा हो तो nCr को nC(n−r) से आसान बनाकर गणना करनी हो (उदाहरण: nC98 ≈ nC2)।

Conditions: सदैव सत्य; r पूर्णांक, 0 ≤ r ≤ n।

Common mistake: nCr ≠ nC(r+1) समझ लेना या इस गुण से गलत निकालना।

nP r + r × nPr = (r+1) × nP(r+1) या nPr = n × (n−1)Pr−1

Symbols: परिवर्तनीय सूत्र: एक विशेष तत्व को चुनकर उसकी स्थिति को अलग से गिनना।

Unit: विहीन

When to use: जब किसी तत्व की स्थिति निर्धारित करनी हो; रिकरेंस संबंध स्थापित करना।

Conditions: r < n होना चाहिए।

Common mistake: रिकरेंस में (n−r) का गलत स्थान; सूत्र याद रखते समय nPr और nP(r−1) को उलट देना।

nCr + nC(r−1) = (n+1)Cr

Symbols: पास्कल का सर्वसमिका: nCr + nC(r−1) = (n+1)Cr।

Unit: विहीन

When to use: द्विपद प्रमेय के गुणांक जोड़ने, सिद्धांतिक प्रश्नों में उपयोगी; रिकरेंस संबंध।

Conditions: r ≥ 1, n ≥ r।

Common mistake: (n−1)Cr + (n−1)C(r−1) = nCr को (n+1)Cr लिख देना — दाहिना पक्ष छोटे n वाला होता है।

nP r / nCr = r!

Symbols: nPr और nCr का अनुपात r! के बराबर होता है, क्योंकि क्रमचय में क्रम को r! तरीकों से व्यवस्थित किया जा सकता है।

Unit: विहीन

When to use: nPr और nCr के बीच संबंध खोजने वाले प्रश्न; किसी एक से दूसरा निकालना।

Conditions: 0 ≤ r ≤ n।

Common mistake: nPr/nCr = (n−r)! या n!/r! लिख देना; अर्थ गलत समझ लेना।

nPr = n × (n−1) × (n−2) × ... × (n−r+1) [क्रम में r पद]

Symbols: nPr = गुणनफल के r पद जिनमें प्रत्येक क्रमशः 1 कम हो रहा है, पहला पद n है।

Unit: विहीन

When to use: जब r छोटा हो तो factorial लिखे बिना तेज़ी से गणना करनी हो।

Conditions: r ≤ n; यदि r = 0 तो nP0 = 1।

Common mistake: अंतिम पद को (n−r) या (n−r−1) लिख देना; सही अंतिम पद (n−r+1) है।

सम्पूर्ण क्रमचय (एक पंक्ति): n!

Symbols: n भिन्न वस्तुओं को एक पंक्ति में व्यवस्थित करने के कुल तरीके = n!।

Unit: विहीन

When to use: शब्दों/अक्षरों का क्रम बदलना, लोग बैठना, वस्तुओं को लाइन में लगाना।

Conditions: सभी तत्व भिन्न माने जाते हैं जब तक कि कोई प्रतिबंध न हो।

Common mistake: पुनरावृत्ति वाले अक्षरों के लिए n! लिख देना और भाग न करना (see duplicate-letter rule)।

पुनरावृत्ति सहित क्रमचय: n! / (p! q! r! ...)

Symbols: n में से p समान, q समान, r समान ... प्रकार की वस्तुओं का क्रमचय = n! ÷ (p!·q!·r!·...)।

Unit: विहीन

When to use: अक्षरों/शब्दों में समान अक्षर हों (उदा.
