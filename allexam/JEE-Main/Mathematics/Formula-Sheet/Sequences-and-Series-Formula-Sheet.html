क्रमानुक्रम एवं श्रेणी - सूत्र पत्रक (JEE Main गणित)

JEE MainHindiFormula Sheet
a_n = a + (n-1)d

Symbols: a = प्रथम पद, d = सार्व अंतर, n = पद क्रमांक, a_n = nवाँ पद

Unit: इकाई नहीं

When to use: समांतर श्रेढ़ी (AP) का nवाँ पद ज्ञात करने हेतु

Conditions: d कोई भी वास्तविक संख्या हो सकती है

Common mistake: कई छात्र (n-1)d की जगह nd लिख देते हैं या प्रथम पद a की जगह a_1 मान लेते हैं। यहाँ a_1 = a ही होता है।

S_n = \frac{n}{2}[2a + (n-1)d] = \frac{n}{2}(a + l)

Symbols: S_n = पहले n पदों का योग, a = प्रथम पद, d = सार्व अंतर, l = अंतिम पद (l = a+(n-1)d)

Unit: इकाई नहीं

When to use: AP के पहले n पदों का योग ज्ञात करने हेतु

Conditions: d स्थिर होना चाहिए

Common mistake: अंतिम पद l को भूलकर केवल 2a+(n-1)d का उपयोग करना, जबकि प्रश्न में अंतिम पद दिया हो तो दूसरा रूप उपयोगी है।

2b = a + c \quad (a, b, c \text{ AP में})

Symbols: a, b, c क्रमिक पद

Unit: इकाई नहीं

When to use: तीनों संख्याओं के AP में होने की शर्त

Conditions: कोई विशेष शर्त नहीं

Common mistake: बदल क्रम से लिख देना जैसे 2a = b+c आदि। ध्यान रहे बीच वाला पद दोगुना, बाकी दो का योग।

a_n = a \cdot r^{n-1}

Symbols: a = प्रथम पद, r = सार्व अनुपात, n = पद क्रमांक, a_n = nवाँ पद

Unit: इकाई नहीं

When to use: गुणोत्तर श्रेढ़ी (GP) का nवाँ पद ज्ञात करने हेतु

Conditions: r \neq 0

Common mistake: घात n के बजाय n-1 रख देना। उदाहरण के लिए चौथा पद a r^3 होता है, a r^4 नहीं।

S_n = \frac{a(1-r^n)}{1-r} \quad (r \neq 1) = \frac{a(r^n-1)}{r-1}

Symbols: S_n = पहले n पदों का योग, a = प्रथम पद, r = सार्व अनुपात

Unit: इकाई नहीं

When to use: GP के पहले n पदों का योग ज्ञात करने हेतु

Conditions: r \neq 1; यदि |r|<1 तो अनंत योग के लिए पहला रूप, यदि r>1 तो दूसरा रूप सुविधाजनक

Common mistake: हर (1-r) को शून्य मानकर सूत्र लागू करना जब r=1 हो, तथा चिन्हों में गलती (1-r^n) बनाम (r^n-1)

S_\infty = \frac{a}{1-r} \quad (|r| < 1)

Symbols: S_\infty = अनंत पदों का योग, a = प्रथम पद, r = सार्व अनुपात

Unit: इकाई नहीं

When to use: अभिसारी अनंत GP का योग

Conditions: |r| < 1 होना आवश्यक है

Common mistake: शर्त |r|<1 को न जाँचकर सीधे सूत्र लगाना, जिससे अपसारी श्रेणी का भ्रान्त उत्तर मिलता है।

\frac{2}{b} = \frac{1}{a} + \frac{1}{c} \quad (a, b, c \text{ HP में})

Symbols: a, b, c क्रमिक पद

Unit: इकाई नहीं

When to use: तीनों संख्याओं के HP में होने की शर्त

Conditions: a, b, c \neq 0

Common mistake: इसे AP की शर्त 2b = a+c के समान याद करना। HP में व्युत्क्रमों का AP होता है।

\text{AM} = \frac{a+b}{2}, \quad \text{GM} = \sqrt{ab}, \quad \text{HM} = \frac{2ab}{a+b}

Symbols: a, b धनात्मक वास्तविक संख्याएँ

Unit: इकाई नहीं

When to use: दो धनात्मक संख्याओं के लिए माध्य

Conditions: a, b > 0

Common mistake: GM और HM के सूत्र अदल-बदल लेना या वर्गमूल भूल जाना।

\text{AM} \geq \text{GM} \geq \text{HM} \quad (a,b>0)

Symbols: AM, GM, HM क्रमशः समांतर, गुणोत्तर, हरात्मक माध्य

Unit: इकाई नहीं

When to use: माध्यों के बीच असमानता

Conditions: a, b धनात्मक व वास्तविक

Common mistake: ऋणात्मक संख्याओं पर लागू करना या बराबरी की शर्त (a=b) भूल जाना।

\sum_{k=1}^{n} k = \frac{n(n+1)}{2}

Symbols: n = प्राकृत संख्या

Unit: इकाई नहीं

When to use: प्रथम n प्राकृत संख्याओं का योग

Conditions: n \in \mathbb{N}

Common mistake: n+1 की जगह n लिख देना या हर 2 को भूल जाना।

\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}

Symbols: n = प्राकृत संख्या

Unit: इकाई नहीं

When to use: प्रथम n प्राकृत संख्याओं के वर्गों का योग

Conditions: n \in \mathbb{N}

Common mistake: अंश में 2n+1 की जगह n+1 या 2n लिख देना, हर 6 को भूल जाना।

\sum_{k=1}^{n} k^3 = \left[\frac{n(n+1)}{2}\right]^2

Symbols: n = प्राकृत संख्या

Unit: इकाई नहीं

When to use: प्रथम n प्राकृत संख्याओं के घनों का योग

Conditions: n \in \mathbb{N}

Common mistake: इसे 2n+1 वाले सूत्र से मिश्रित कर देना। ध्यान रहे यह पूर्ण वर्ग है।

\frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}

Symbols: k = प्राकृत संख्या

Unit: इकाई नहीं

When to use: टीलेस्कोपिंग श्रेणी के पदों को विभक्त करने हेतु

Conditions: k \geq 1

Common mistake: चिन्ह गलत लिखना (जैसे \frac{1}{k+1} - \frac{1}{k}) जो ऋणात्मक योग देगा।

S = \frac{a}{1-r} + \frac{dr}{(1-r)^2} \quad (|r|<1)

Symbols: a = प्रथम पद, d = सार्व अंतर, r = सार्व अनुपात

Unit: इकाई नहीं

When to use: अनंत समांतर-गुणोत्तर श्रेढ़ी (AGP) का योग: a + (a+d)r + (a+2d)r^2 + \ldots

Conditions: |r|<1

Common mistake: सार्व अंतर d को भूल जाना या सूत्र में dr/(1-r)^2 की जगह d/(1-r)^2 लिख देना।

n-1 पदों का अंतर d = \frac{b-a}{n+1} \quad (a, b \text{ के मध्य n AP पद})

Symbols: a = प्रथम पद, b = अंतिम पद, n = इंटरपोल किए जाने वाले पद

Unit: इकाई नहीं

When to use: दो संख्याओं के मध्य n समांतर मध्य रखने हेतु सार्व अंतर

Conditions: कुल पद = n+2, इसलिए अंतर की संख्या = n+1

Common mistake: d = (b-a)/n लिख देना, जबकि सही भाजक n+1 है।

r = \left(\frac{b}{a}\right)^{\frac{1}{n+1}} \quad (a, b \text{ के मध्य n GP पद})

Symbols: a = प्रथम पद, b = अंतिम पद, n = इंटरपोल किए जाने वाले पद, r = सार्व अनुपात

Unit: इकाई नहीं

When to use: दो संख्याओं के मध्य n गुणोत्तर मध्य रखने हेतु सार्व अनुपात

Conditions: a, b धनात्मक, r > 0

Common mistake: घात 1/(n+1) के बजाय 1/n ले लेना। कुल पद n+2 होते हैं, इसलिए r^{n+1} = b/a।
