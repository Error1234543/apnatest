त्रिकोणमिति - सूत्र पत्रिका (JEE Main गणित)

JEE MainHindiFormula Sheet
sin θ = perpendicular / hypotenuse, cos θ = base / hypotenuse, tan θ = perpendicular / base

Symbols: θ = कोण, perpendicular = लंब, hypotenuse = कर्ण, base = आधार

Unit: कोणीय माप: रेडियन या डिग्री

When to use: समकोण त्रिभुज में त्रिकोणमितीय अनुपात ज्ञात करने के लिए

Conditions: θ = 90° नहीं हो सकता tan/cosec के लिए

Common mistake: कोण की ओर ध्यान न देना और भुजाओं का क्रम बदल देना

sec θ = hypotenuse / base, cosec θ = hypotenuse / perpendicular, cot θ = base / perpendicular

Symbols: प्रतीक उपर्युक्त जैसे

Unit: कोणीय माप: रेडियन या डिग्री

When to use: आवंतक त्रिकोणमितीय अनुपात ज्ञात करने के लिए

Conditions: θ ≠ 90° + n·180° sec/cot के लिए, θ ≠ n·180° cosec/cot के लिए

Common mistake: आवंतक अनुपात को व्युत्क्रम सूत्रों से भ्रमित करना

sin²θ + cos²θ = 1

Symbols: θ = कोई भी वास्तविक कोण

Unit: विहीन (अनुपात)

When to use: एक त्रिकोणमितीय फलन के मान से दूसरा ज्ञात करने के लिए

Conditions: सभी θ के लिए मान्य

Common mistake: sin²θ + cos²θ = 0 या 2 लिख देना

1 + tan²θ = sec²θ

Symbols: θ = वह कोण जहाँ tan, sec परिभाषित हों

Unit: विहीन

When to use: tan और sec के बीच संबंध स्थापित करने के लिए

Conditions: θ ≠ 90° + n·180°

Common mistake: 1 + cot²θ = cosec²θ के साथ भ्रमित करना

1 + cot²θ = cosec²θ

Symbols: θ = वह कोण जहाँ cot, cosec परिभाषित हों

Unit: विहीन

When to use: cot और cosec के बीच संबंध स्थापित करने के लिए

Conditions: θ ≠ n·180°

Common mistake: चिन्ह भ्रम (ऋणात्मक मान लेने पर)

sin(A ± B) = sinA cosB ± cosA sinB

Symbols: A, B = कोण

Unit: कोणीय माप

When to use: योग/अंतर के कोणों के sin की गणना के लिए

Conditions: सभी A, B के लिए मान्य

Common mistake: चिन्ह भ्रम (+/- का गलत प्रयोग)

cos(A ± B) = cosA cosB ∓ sinA sinB

Symbols: A, B = कोण

Unit: कोणीय माप

When to use: योग/अंतर के कोणों के cos की गणना के लिए

Conditions: सभी A, B के लिए मान्य

Common mistake: sinA sinB का चिन्ह भूल जाना

tan(A ± B) = (tanA ± tanB)/(1 ∓ tanA tanB)

Symbols: A, B = कोण जहाँ tan परिभाषित हों

Unit: विहीन

When to use: योग/अंतर के कोणों के tan की गणना के लिए

Conditions: denominator ≠ 0

Common mistake: हर के चिन्ह को गलत लिखना

sin 2θ = 2 sinθ cosθ

Symbols: θ = कोण

Unit: कोणीय माप

When to use: द्विकोण का sin ज्ञात करने के लिए

Conditions: सभी θ के लिए मान्य

Common mistake: 2 को(sin+cos) से गुणा करना

cos 2θ = cos²θ - sin²θ = 2cos²θ - 1 = 1 - 2sin²θ

Symbols: θ = कोण

Unit: कोणीय माप

When to use: द्विकोण का cos ज्ञात करने के लिए, विभिन्न रूपों का चयन समस्या के अनुसार

Conditions: सभी θ के लिए मान्य

Common mistake: सभी रूप समान हैं लेकिन किसी स्थिति में एक रूप उचित होता है

tan 2θ = 2tanθ/(1 - tan²θ)

Symbols: θ = कोण जहाँ tan परिभाषित

Unit: विहीन

When to use: द्विकोण का tan ज्ञात करने के लिए

Conditions: tan²θ ≠ 1

Common mistake: हर में चिन्ह भूल जाना

sin 3θ = 3sinθ - 4sin³θ

Symbols: θ = कोण

Unit: कोणीय माप

When to use: त्रिकोण का sin ज्ञात करने के लिए

Conditions: सभी θ के लिए मान्य

Common mistake: सूत्र याद रखने में त्रुटि

cos 3θ = 4cos³θ - 3cosθ

Symbols: θ = कोण

Unit: कोणीय माप

When to use: त्रिकोण का cos ज्ञात करने के लिए

Conditions: सभी θ के लिए मान्य

Common mistake: चिन्ह भ्रम

tan 3θ = (3tanθ - tan³θ)/(1 - 3tan²θ)

Symbols: θ = कोण जहाँ tan परिभाषित

Unit: विहीन

When to use: त्रिकोण का tan ज्ञात करने के लिए

Conditions: 1 - 3tan²θ ≠ 0

Common mistake: अंश-हर को उल्टा लिख देना

sin(A+B) + sin(A-B) = 2 sinA cosB

Symbols: A, B = कोण

Unit: कोणीय माप

When to use: योग/अंतर के सूत्रों को गुणनफल में बदलने के लिए

Conditions: सभी A, B के लिए मान्य

Common mistake: सूत्र याद रखने में भ्रम

cos(A+B) + cos(A-B) = 2 cosA cosB

Symbols: A, B = कोण

Unit: कोणीय माप

When to use: योग/अंतर के सूत्रों को गुणनफल में बदलने के लिए

Conditions: सभी A, B के लिए मान्य

Common mistake: sin/AsinB के साथ भ्रमित करना

sin(A+B) - sin(A-B) = 2 cosA sinB

Symbols: A, B = कोण

Unit: कोणीय माप

When to use: योग/अंतर के सूत्रों को गुणनफल में बदलने के लिए

Conditions: सभी A, B के लिए मान्य

Common mistake: चिन्ह भ्रम

cos(A+B) - cos(A-B) = -2 sinA sinB

Symbols: A, B = कोण

Unit: कोणीय माप

When to use: योग/अंतर के सूत्रों को गुणनफल में बदलने के लिए

Conditions: सभी A, B के लिए मान्य

Common mistake: ऋण चिन्ह भूल जाना

sin²θ = (1 - cos2θ)/2, cos²θ = (1 + cos2θ)/2

Symbols: θ = कोण

Unit: विहीन

When to use: वर्ग वाले पदों को सरल करने के लिए, समाकलन में उपयोगी

Conditions: सभी θ के लिए मान्य

Common mistake: सूत्र उल्टा लिख देना

sinθ ± sinφ = 2 sin((θ±φ)/2) cos((θ∓φ)/2)

Symbols: θ, φ = कोण

Unit: कोणीय माप

When to use: त्रिकोणमितीय समीकरण हल करने के लिए

Conditions: सभी θ, φ के लिए मान्य

Common mistake: (θ±φ)/2 और (θ∓φ)/2 को गलत जोड़ना

cosθ + cosφ = 2 cos((θ+φ)/2) cos((θ-φ)/2)

Symbols: θ, φ = कोण

Unit: कोणीय माप

When to use: त्रिकोणमितीय समीकरण हल करने के लिए

Conditions: सभी θ, φ के लिए मान्य

Common mistake: चिन्ह भ्रम

cosθ - cosφ = -2 sin((θ+φ)/2) sin((θ-φ)/2)

Symbols: θ, φ = कोण

Unit: कोणीय माप

When to use: त्रिकोणमितीय समीकरण हल करने के लिए

Conditions: सभी θ, φ के लिए मान्य

Common mistake: ऋण चिन्ह भूल जाना

sinθ ± cosφ = √2 sin(θ ± 45°) etc.

Symbols: θ, φ = कोण

Unit: कोणीय माप

When to use: sinθ ± cosφ को एकांगी बनाने के लिए

Conditions: विशिष्ट रूपों के लिए

Common mistake: 45° का चिन्ह भूल जाना

sin^{-1} x = tan^{-1}(x/√(1-x²)), cos^{-1} x = tan^{-1}(√(1-x²)/x)

Symbols: x = [-1,1] के लिए मान

Unit: कोणीय माप

When to use: व्युत्क्रम त्रिकोणमितीय फलनों को सरल करने के लिए

Conditions: x का परिसर सीमा के अंदर हो

Common mistake: व्युत्क्रम फलनों के मुख्य शाखा मानों को न देखना

sin^{-1} x + cos^{-1} x = π/2

Symbols: x ∈ [-1,1]

Unit: रेडियन

When to use: व्युत्क्रम त्रिकोणमितीय सर्वसमिकाओं का उपयोग

Conditions: सभी x ∈ [-1,1]

Common mistake: इसे tan^{-1} के साथ भ्रमित करना

tan^{-1} x + tan^{-1} y = tan^{-1}((x+y)/(1-xy)), if xy < 1

Symbols: x, y = वास्तविक संख्याएँ

Unit: रेडियन

When to use: व्युत्क्रम tan के योग को सरल करने के लिए

Conditions: xy < 1, यदि xy > 1 तो π जोड़ें, यदि xy < -1 तो -π जोड़ें

Common mistake: शर्तों को न देखकर सीधा सूत्र लगाना

A/sinA = b/sinB = c/sinC = 2R, R = circumradius

Symbols: A,B,C = त्रिभुज के कोण, a,b,c = अभिसरण भुजाएँ, R = परित्रिज्या

Unit: भुजा की लंबाई

When to use: त्रिभुज के कोण और भुजाओं के बीच संबंध स्थापित करने के लिए

Conditions: किन्हीं भी त्रिभुज के लिए

Common mistake: भुजा और कोण के सटीक संगतत्व को भूल जाना

a = b cosC + c cosB, b = c cosA + a cosC, c = a cosB + b cosA

Symbols: प्रतीक उपरोक्त जैसे

Unit: भुजा की लंबाई

When to use: प्रक्षेपण सूत्र द्वारा भुजा ज्ञात करने के लिए

Conditions: किन्हीं भी त्रिभुज के लिए

Common mistake: सूत्र याद रखने में भ्रम

Area = (1/2)ab sinC = (1/2)bc sinA = (1/2)ca sinB = √(s(s-a)(s-b)(s-c))

Symbols: s = अर्धपरिधि = (a+b+c)/2

Unit: वर्ग इकाई

When to use: त्रिभुज का क्षेत्रफल ज्ञात करने के लिए

Conditions: हेरोन सूत्र सभी त्रिभुजों के लिए, अन्य सूत्र दो भुजाओं और उनके बीच के कोण के लिए

Common mistake: s की गणना में त्रुटि

cos A = (b² + c² - a²)/(2bc), cos B = (a² + c² - b²)/(2ac), cos C = (a² + b² - c²)/(2ab)

Symbols: प्रतीक उपरोक्त जैसे

Unit: विहीन

When to use: को사인 नियम द्वारा कोण ज्ञात करने के लिए

Conditions: किन्हीं भी त्रिभुज के लिए

Common mistake: भुजाओं के वर्गों में अंतर को गलत रखना

sin A / a = sin B / b = sin C / c

Symbols: प्रतीक उपरोक्त जैसे

Unit: विहीन

When to use: साइन नियम द्वारा भुजा/कोण ज्ञात करने के लिए

Conditions: किन्हीं भी त्रिभुज के लिए

Common mistake: अनुपात उल्टा लिख देना

A + B + C = π (त्रिभुज के कोण)

Symbols: A,B,C = त्रिभुज के आंतरिक कोण

Unit: रेडियन या डिग्री

When to use: त्रिभुज के कोणों के योग का उपयोग

Conditions: यूक्लिडियन त्रिभुज के लिए

Common mistake: इसे 2π मान लेना

sin(nπ + θ) = (-1)^n sinθ, cos(nπ + θ) = (-1)^n cosθ

Symbols: n = पूर्णांक, θ = कोण

Unit: कोणीय माप

When to use: साधारण हल और अधिकतम/न्यूनतम मान ज्ञात करने के लिए

Conditions: सभी n, θ के लिए मान्य

Common mistake: (-1)^n का चिन्ह भूल जाना

sin(nπ/2 + θ) = कोटान्तर नियम के अनुसार

Symbols: n = पूर्णांक, θ = कोण

Unit: कोणीय माप

When to use: π/2 के गुणज वाले कोणों के लिए

Conditions: n के सम/विषम होने पर फलन बदल जाता है

Common mistake: कोटान्तर नियम को न लागू करना

sin θ = sin α ⇒ θ = nπ + (-1)^n α, n ∈ Z

Symbols: α = दिया गया कोण, θ = अभीष्ट कोण

Unit: रेडियन

When to use: त्रिकोणमितीय समीकरण का व्यापक हल

Conditions: सभी α के लिए मान्य

Common mistake: n के मानों को न जाँचना

cos θ = cos α ⇒ θ = 2nπ ± α, n ∈ Z

Symbols: प्रतीक उपरोक्त जैसे

Unit: रेडियन

When to use: cos समीकरण का व्यापक हल

Conditions: सभी α के लिए मान्य

Common mistake: ± चिन्ह को भूल जाना

tan θ = tan α ⇒ θ = nπ + α, n ∈ Z

Symbols: प्रतीक उपरोक्त जैसे

Unit: रेडियन

When to use: tan समीकरण का व्यापक हल

Conditions: α ≠ π/2 + nπ

Common mistake: nπ को遗漏 करना

sin θ = 0 ⇒ θ = nπ, cos θ = 0 ⇒ θ = nπ + π/2, tan θ = 0 ⇒ θ = nπ

Symbols: n ∈ Z

Unit: रेडियन

When to use: मूल त्रिकोणमितीय समीकरणों के हल

Conditions: सभी n के लिए मान्य

Common mistake: n का परिसर न देखना

a sin θ + b cos θ = √(a²+b²) sin(θ + α), जहाँ tan α = b/a

Symbols: a, b = अदिश, θ = कोण

Unit: विहीन

When to use: त्रिकोणमितीय व्यंजक का अधिकतम/न्यूनतम मान ज्ञात करने के लिए

Conditions: सभी a, b, θ के लिए मान्य

Common mistake: α की गणना में चतुर्थांश न देखना
