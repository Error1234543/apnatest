\(\bar{x} = \dfrac{\displaystyle\sum f_i x_i}{\displaystyle\sum f_i}\)

Symbols: f_i = प्रत्येक मान की आवृत्ति; x_i = प्रत्येक मान (असतत डेटा के लिए) या कक्षा का मध्यक (सातत्य डेटा के लिए); \(\sum f_i = N\) = कुल पर्यवेक्षण संख्या

Unit: आवेदन पर निर्भर (एकक x_i के समान)

When to use: सीधे योग और औसत ज्ञात करने के लिए प्रयोग किया जाता है; JEE Main में आवृत्ति बंटन के माध्य की गणना में सबसे अधिक उपयोगी

Conditions: x_i ज्ञात होने चाहिए; f_i ऋणेतर पूर्णांक हों; असतत तथा सातत्य दोनों डेटा प्रकारों पर लागू

Common mistake: सातत्य डेटा में class mark (कक्षा मध्यक) के स्थान पर class boundary या frequency ही x_i न ले लें; शून्य भार वाली कक्षाओं को गलती से शामिल कर देना

\(\bar{x} = A + h \cdot \dfrac{\displaystyle\sum f_i u_i}{\displaystyle\sum f_i}\) जहाँ \(u_i = \dfrac{x_i - A}{h}\)

Symbols: A = मान ली गई मध्यमा (assumed mean); h = class width या step size; u_i = step deviation

Unit: आवेदन पर निर्भर (एकक x_i के समान)

When to use: जब संख्याएँ बड़ी हों या बार-बार द्विगुणित हो रही हो तब गणना सरल बनाने के लिए

Conditions: class width समान होना चाहिए; A आमतौर पर mode class या median class का मध्यक लिया जाता है

Common mistake: u_i की गणना में (x_i - A)/h में A और h को उलट देना; चिन्ह (sign) भूल जाना

\(M = l + \dfrac{\tfrac{N}{2} - C}{f} \cdot h\)

Symbols: l = मध्यक वर्ग (median class) की निचली सीमा; N = \(\sum f_i\); C = मध्यक वर्ग से पूर्व संचयी आवृत्ति; f = मध्यक वर्ग की आवृत्ति; h = वर्ग चौड़ाई

Unit: x_i के समान एकक

When to use: सातत्य (continuous) आवृत्ति बंटन में मध्यक ज्ञात करने के लिए

Conditions: संचयी आवृत्ति सारणी बनाकर वह वर्ग चुनें जिसमें संचयी आवृत्ति \(\geq N/2\) पहली बार हो; वर्ग अंतराल समान हों तो भी यह सूत्र चलता है

Common mistake: C को मध्यक वर्ग की आवृत्ति न समझें — C पूर्व संचयी आवृत्ति है; l में से class boundary को गलती से class mark लिख देना

\(Z = l + \dfrac{f_1 - f_0}{2f_1 - f_0 - f_2} \cdot h\)

Symbols: l = मोड वर्ग (modal class) की निचली सीमा; f_1 = मोड वर्ग की आवृत्ति; f_0 = मोड वर्ग से ठीक पहले वाले वर्ग की आवृत्ति; f_2 = मोड वर्ग से ठीक बाद वाले वर्ग की आवृत्ति; h = वर्ग चौड़ाई

Unit: x_i के समान एकक

When to use: सातत्य आवृत्ति बंटन में मोड ज्ञात करने के लिए

Conditions: मोड वर्ग वह होता है जिसकी आवृत्ति सबसे अधिक हो; सभी फार्मूलो की आवृत्तियाँ परिभाषित हों (दो सहलग्रामी वर्गों से पहले-बाद वाला मौजूद हो)

Common mistake: f_0 या f_2 में मोड वर्ग की आवृत्ति घुस जाना; हॉरिज़ॉन्टल/वर्टिकल सीमा को गड़बड़ करना

\(MD(\bar{x}) = \dfrac{\displaystyle\sum f_i |x_i - \bar{x}|}{\displaystyle\sum f_i}\) और \(MD(M) = \dfrac{\displaystyle\sum f_i |x_i - M|}{\displaystyle\sum f_i}\)

Symbols: |x_i - \bar{x}| = प्रत्येक मान और माध्य का निरपेक्ष अंतर; f_i = आवृत्ति

Unit: x_i के समान एकक

When to use: परिसर के बजाय हर एक पर्यवेक्षण के विचलन के माध्य को मापने के लिए — JEE Main में MA तथा M के सापेक्ष माध्य विचलन पूछा जाता है

Conditions: सातत्य डेटा में class mark को x_i लें; ऋणात्मक चिन्ह को modulus से धनात्मक बना लें

Common mistake: वर्ग नहीं किए गए x_i - \bar{x} को सीधा जोड़ना (ऋणात्मक मान कट जाएँगे — modulus अनिवार्य); आवृत्ति से भाग देना भूल जाना

\(\sigma^2 = \dfrac{\displaystyle\sum f_i (x_i - \bar{x})^2}{\displaystyle\sum f_i} = \dfrac{\displaystyle\sum f_i x_i^2}{\displaystyle\sum f_i} - (\bar{x})^2\)

Symbols: \sigma^2 = प्रसरण (variance); x_i = मान या class mark; f_i = आवृत्ति

Unit: x_i इकाई का वर्ग (e.g. cm², kg²)

When to use: डेटा का फेलन (dispersion) मापने के लिए; JEE Main में प्रश्नों में दोनों रूपों में प्रयोग होता है

Conditions: \(\sum f_i \neq 0\); x_i या तो व्यक्तिगत मान या class mark हो; सातत्य डेटा के लिए class mark ही लें

Common mistake: दूसरा रूप \(\frac{\sum f_i x_i^2}{\sum f_i} - (\bar{x})^2\) का प्रयोग करते समय \(\bar{x}^2\) को \(\overline{x^2}\) समझ लेना — ये अलग-अलग हैं

\(\sigma^2 = h^2 \left[\dfrac{\displaystyle\sum f_i u_i^2}{\displaystyle\sum f_i} - \left(\dfrac{\displaystyle\sum f_i u_i}{\displaystyle\sum f_i}\right)^2\right]\) जहाँ \(u_i = \dfrac{x_i - A}{h}\)

Symbols: h = step size (कक्षा चौड़ाई); u_i = step deviation; A = assumed mean

Unit: x_i इकाई का वर्ग

When to use: बड़ी संख्याओं वाले डेटा को छोटे u_i में बदलकर प्रसरण निकालने के लिए गणना सरल बनाने हेतु

Conditions: सभी class width समान होनी चाहिए; A कोई भी सुविधाजनक मान हो सकता है

Common mistake: अंत में h² गुणा करना भूल जाना; u_i² के योग में f_i से गुणा करना भूल जाना

\(\sigma = \sqrt{\sigma^2}\)

Symbols: \sigma = मानक विचलन (standard deviation); \sigma^2 = प्रसरण

Unit: x_i के समान एकक

When to use: प्रसरण से मानक विचलन प्राप्त करने के लिए — JEE Main में \sigma ही माँगा जाता है ज़्यादातर

Conditions: प्रसरण ऋणेतर होना चाहिए (हमेशा होता है)

Common mistake: \sigma² लेने के बाद वर्गमूल भूल जाना; मानक विचलन को प्रसरण की जगह उत्तर में लिख देना

\(CV = \dfrac{\sigma}{\bar{x}} \times 100\%

Symbols: CV = विचरण गुणांक (coefficient of variation); \sigma = मानक विचलन; \bar{x} = माध्य

Unit: प्रतिशत (%)

When to use: दो या अधिक बंटनों की तुलना करने के लिए — जिनका माध्य भिन्न है वैसे डेटा की तुलना CV से करते हैं

Conditions: \bar{x} \neq 0; CV हमेशा धनात्मक होता है

Common mistake: माध्य शून्य या ऋणात्मक होने पर CV व्युत्पन्न करना; प्रतिशत चिन्ह लगाना भूल जाना

\(\bar{x}_{12} = \dfrac{n_1 \bar{x}_1 + n_2 \bar{x}_2}{n_1 + n_2}\)

Symbols: \bar{x}_{12} = संयुक्त माध्य; n_1, n_2 = क्रमशः समूह 1 व 2 की पर्यवेक्षण संख्याएँ; \bar{x}_1, \bar{x}_2 = क्रमशः उनके माध्य

Unit: x के एकक

When to use: दो समूहों के डेटा को जोड़कर एक ही समूह का माध्य ज्ञात करने के लिए

Conditions: प्रत्येक समूह का माध्य और उसकी संख्या ज्ञात होनी चाहिए

Common mistake: माध्य को सीधे औसत निकाल लेना (\(\frac{\bar{x}_1 + \bar{x}_2}{2}\)) बिना n से भार दिए

\(\sigma_{12}^2 = \dfrac{n_1(\sigma_1^2 + d_1^2) + n_2(\sigma_2^2 + d_2^2)}{n_1 + n_2}\) जहाँ \(d_1 = \bar{x}_1 - \bar{x}_{12},\ d_2 = \bar{x}_2 - \bar{x}_{12}\)

Symbols: \sigma_{12}^2 = संयुक्त प्रसरण; d_1, d_2 = क्रमशः प्रत्येक समूह के माध्यों का संयुक्त माध्य से अंतर

Unit: x इकाई का वर्ग

When to use: दो समूहों को मिलाने पर संयुक्त प्रसरण ज्ञात करने के लिए — JEE Main में संयुक्त SD पूछा जाता है

Conditions: सबसे पहले संयुक्त माध्य \(\bar{x}_{12}\) निकालना अनिवार्य है

Common mistake: d_1, d_2 के स्थान पर \sigma_1, \sigma_2 को ही वर्ग में लगा देना; d का वर्ग नहीं निकाल पाना

\(\gamma_{xy} = \dfrac{\text{Cov}(X,Y)}{\sigma_x \cdot \sigma_y}\), \(\text{Cov}(X,Y) = \dfrac{\displaystyle\sum f_i x_i y_i}{\displaystyle\sum f_i} - \bar{x} \cdot \bar{y}\)

Symbols: \gamma_{xy} = सहसंबंध गुणांक; Cov = सहप्रसरण; \sigma_x, \sigma_y = क्रमशः X व Y का मानक विचलन

Unit: आdimensionless (कोई एकक नहीं)

When to use: दो चरों X व Y के बीच रैखिक संबंध की दिशा व तीव्रता ज्ञात करने के लिए

Conditions: -1 \leq \gamma_{xy} \leq 1; \sigma_x, \sigma_y \neq 0

Common mistake: Cov(X,Y) को \(\sum f_i x_i y_i - \bar{x}\bar{y}\) लिखकर \(\sum f_i\) से भाग न करना; \gamma > 1 आने पर भी स्वीकार करना

\(\gamma_{xy} = \dfrac{\dfrac{\displaystyle\sum f_i u_i v_i}{n} - \bar{u}\,\bar{v}}{\sigma_u \cdot \sigma_v}\) जहाँ \(u_i = \dfrac{x_i-A}{a},\ v_i = \dfrac{y_i-B}{b}\)

Symbols: u_i, v_i = step deviations for X and Y; a, b = respective class widths; \bar{u}, \bar{v} = उनके माध्य; \sigma_u, \sigma_v = उनके मानक विचलन

Unit: आdimensionless

When to use: जब X व Y दोनों का डेटा grouped हो और step-deviation विधि अपनाई जाती हो

Conditions: u, v के लिए स्वतंत्र A, B चयन किए जा सकते हैं; a, b各自的 class width होते हैं

Common mistake: u और v के step sizes अलग-अलग रखकर \gamma में gड़बड़ करना — u,v के variance/outcome में अलग अलग divisor आते हैं

Y on X: \(Y - \bar{y} = b_{yx}(X - \bar{x})\), जहाँ \(b_{yx} = \dfrac{\text{Cov}(X,Y)}{\sigma_x^2}\)

X on Y: \(X - \bar{x} = b_{xy}(Y - \bar{y})\), जहाँ \(b_{xy} = \dfrac{\text{Cov}(X,Y)}{\sigma_y^2}\)

Symbols: b_{yx} = Y on X का रीग्रेशन गुणांक; b_{xy} = X on Y का रीग्रेशन गुणांक

Unit: b_{yx}: Y की इकाई/X की इकाई; b_{xy}: X की इकाई/Y की इकाई

When to use: एक चर द्वारा दूसरे चर की پیشान्दाज़ी (prediction) करने के लिए; JEE Main में रीग्रेशन रेखा का समीकरण पूछा जाता है

Conditions: \gamma \neq 0; दोनों रेखाएँ \((\bar{x}, \bar{y})\) से होती हैं

Common mistake: b_{yx} = \sigma_y/\sigma_x लगाना (यह सिर्फ \gamma=1 होने पर सही है); दोनो रेखाओं का समीकरण लिखते समय \bar{x},\bar{y} के चिन्ह गड़बड़ करना

\(|\gamma| \leq 1\); \(b_{yx} \cdot b_{xy} = \gamma^2\); \(\gamma\) का चिन्ह b_{yx} व b_{xy} दोनों के चिन्ह से मेल खाता है

Symbols: \gamma = सहसंबंध गुणांक; b_{yx}, b_{xy} = रीग्रेशन गुणांक

Unit: आdimensionless

When to use: दी हुई दो रीग्रेशन समीकरणों से \gamma ज्ञात करने या सत्य कथनों की जाँच करने के लिए

Conditions: रीग्रेशन गुणांक वास्तविक एवं परिमित हों

Common mistake: \gamma = b_{yx} + b_{xy} या \gamma = b_{yx}/b_{xy} मान लेना — केवल \gamma^2 = b_{yx}\,b_{xy} सही है; \gamma का चिन्ह अलग निकाल लेना

\(P(E) = \dfrac{n(E)}{n(S)}\), \(0 \leq P(E) \leq 1\), \(P(\emptyset)=0,\ P(S)=1\)

Symbols: n(E) = अनुकूल परिणामों की संख्या; n(S) = कुल संभावित परिणामों की संख्या

Unit: आdimensionless (0 से 1 के बीच)

When to use: कक्षा 11 के आधारभूत प्रायिकता प्रश्नों में — JEE Main में यह सबसे सरल स्वरूप में आता है

Conditions: सभी परिणाम equally likely होने चाहिए

Common mistake: sample space में non-equally likely outcomes को गिन लेना; n(E) गिनती में double-counting

\(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)

Symbols: P(A ∪ B) = कम से कम एक घटना होने की प्रायिकता; P(A ∩ B) = दोनों घटनाएँ एक साथ होने की प्रायिकता

Unit: आdimensionless

When to use: दो घटनाओं के संघ की प्रायिकता ज्ञात करने के लिए — JEE Main में बहुत आम

Conditions: सामान्य रूप से प्रयुक्त; यदि A व B परस्पर असंभव हों तो \(P(A \cap B)=0\)

Common mistake: \(P(A \cup B) = P(A)+P(B)\) लिख देना जब घटनाएँ असंभव न हों; P(A∩B) को भूल जाना

\(P(A|B) = \dfrac{P(A \cap B)}{P(B)},\ P(B) \neq 0\)

Symbols: P(A|B) = B के घटित होने की शर्त पर A की प्रायिकता; P(A ∩ B) = दोनों का प्रतिच्छेदन

Unit: आdimensionless

When to use: शर्तयुक्त प्रायिकता वाले प्रश्नों में — JEE Main में conditional probability का प्रश्न आता ही रहता है

Conditions: P(B) > 0 होना अनिवार्य

Common mistake: P(A|B) और P(B|A) को एक समझ लेना — ये अलग होते हैं; हर में P(B) को P(A) लिख देना

\(P(A \cap B) = P(A) \cdot P(B|A) = P(B) \cdot P(A|B)\)

Symbols: सबstitutions from multiplication rule

Unit: आdimensionless

When to use: क्रमिक घटनाओं की संयुक्त प्रायिकता निकालने के लिए (उदा. बिना प्रतिस्थापन के दो बल्ब निकालना)

Conditions: घटनाएँ क्रमागत हो सकती हैं; दूसरी शर्त प्रथम के बाद बदल सकती है

Common mistake: स्वतंत्र घटनाओं को शर्तयुक्त मानकर P(B|A) = P(B) के बजाय कुछ और ले लेना

स्वतंत्र घटनाएँ: \(P(A \cap B) = P(A)\cdot P(B)\)

Symbols: P(A ∩ B) = दोनों का प्रतिच्छेदन; P(A), P(B) = व्यक्तिगत प्रायिकताएँ

Unit: आdimensionless

When to use: जब घटनाएँ एक-दूसरे से स्वतंत्र हों (उदा. सिक्का उछालना, पासा पटकना, replacement के साथ चयन)

Conditions: घटनाएँ truly independent हों — sampling with replacement या भौतिक तौर पर स्वतंत्र

Common mistake: sampling without replacement में घटनाओं को independent मान लेना; mutually exclusive घटनाओं को independent समझ लेना (ये दो अलग अवधारणाएँ हैं)

\(P(A) = \displaystyle\sum_{i=1}^{n} P(B_i)\cdot P(A|B_i)\) — Total Probability

Symbols: B_i = S का partition (अपवर्तन); P(B_i) > 0; P(A|B_i) = B_i आने पर A की शर्तयुक्त प्रायिकता

Unit: आdimensionless

When to use: जब किसी घटना को कई स्थितियों के आधार पर देखना हो — उदा. कक्षा में लड़कों/लड़कियों में से यादृच्छिक चुनाव

Conditions: B_1,...,B_n परस्पर असंभव और समस्त S को ढकने वाले हों; \(\sum P(B_i) = 1\)

Common mistake: partition के सभी B_i को शामिल न करना; P(A) को एक ही P(B_i)P(A|B_i) से निकाल लेना

\(P(B_i|A) = \dfrac{P(B_i)\,P(A|B_i)}{\displaystyle\sum_{j=1}^{n} P(B_j)\,P(A|B_j)}\) — Bayes' Theorem

Symbols: P(B_i|A) = A घटित होने के बाद B_i की posterior प्रायिकता; P(B_i) = prior; P(A|B_i) = likelihood

Unit: आdimensionless

When to use: उल्टी शर्त निकालने के लिए — JEE Main में अक्सर दो डिब्बों/खेमे/मशीनों में से किसी के आने की शर्त पर दूसरी घटना की प्रायिकता पूछी जाती है

Conditions: हर = P(A) (total probability) ज्ञात होना चाहिए

Common mistake: Bayes के सूत्र में केवल अंश लिखकर उत्तर दे देना (हर भूल जाना); B_i के prior weights कोequal मान लेना जबकि वे unequal हों

\(P(X=r) = {^nC_r}\,p^r\,q^{\,n-r}\), जहाँ q = 1 - p — Binomial Distribution

Symbols: n = कुल प्रयास; r = सफलताओं की संख्या; p = एक प्रयास में सफलता की प्रायिकता; q = असफलता की प्रायिकता

Unit: आdimensionless (probability)

When to use: Bernoulli trials — दो परिणाम वाले क्रमिक प्रायोग में r सफलताओं की प्रायिकता ज्ञात करना; JEE Main में सबसे महत्वपूर्ण distribution

Conditions: प्रयास स्वतंत्र हों; p प्रत्येक प्रयास में समान रहे; केवल दो परिणाम (सफलता/असफलता)

Common mistake: {^nC_r} को {^rC_n} लिख देना; p और q को उलटा करना; n को प्रश्न के अनुसार कम/ज़्यादा ले लेना

Binomial Mean: \(E(X) = np\); Variance: \(Var(X) = npq\); SD: \(\sigma = \sqrt{npq}\)

Symbols: E(X) = प्रत्याशित मान; Var(X) = प्रसरण; \sigma = मानक विचलन

Unit: E(X): एकक r के समान; Var: एकक²; SD: एकक r के समान

When to use: Binomial distribution के माध्य और प्रसरण ज्ञात करने के लिए — JEE Main में इनके मान सीधे पूछे जाते हैं या reverse में p/n निकालने प्रयोग होते हैं

Conditions: X ~ B(n,p) होना चाहिए

Common mistake: Var(X) = np(1-p) के स्थान पर np² या npq² लिख देना; SD निकालते sqrt लена भूल जाना

\(P(X \leq r) = \displaystyle\sum_{k=0}^{r} {^nk}\,p^k\,q^{\,n-k}\), \(P(X \geq r) = \displaystyle\sum_{k=r}^{n} {^nk}\,p^k\,q^{\,n-k}\)

Symbols: X ~ B(n,p); k सफलताओं की संख्या

Unit: आdimensionless

When to use: cumulative probability निकालने के लिए — "कम से कम r" या "अधिक से अधिक r" वाले प्रश्नों में

Conditions: योग सीमाएँ ध्यान से लें; r ≥ 0 तथा r ≤ n

Common mistake: P(X ≥ r) = 1 - P(X ≤ r) लिखते समय r को गिनती में शामिल/निकालने में भूल; sum limits गलत लगाना

\(E(X) = \displaystyle\sum_{i} x_i \, P(x_i)\), \(Var(X) = E(X^2) - [E(X)]^2\), \(E(X^2) = \displaystyle\sum_{i} x_i^2\,P(x_i)\)

Symbols: X = यादृच्छिक चर; x_i = संभावित मान; P(x_i) = उसके आने की प्रायिकता

Unit: E(X): x_i का एकक; Var(X): x_i² का एकक

When to use: किसी भी discrete random variable का माध्य व प्रसरण निकालने के लिए — JEE Main में table दी जाती है

Conditions: \(\sum P(x_i) = 1\); सभी x_i मान्य हों

Common mistake: P(x_i) को weight के बिना x_i² जोड़ देना; E(X²) को (E(X))² समझ लेना — ये अलग हैं

\(Var(aX+b) = a^2\,Var(X)\), \(SD(aX+b) = |a|\,\sigma_X\)

Symbols: a, b = स्थिरांक; X = यादृच्छिक चर

Unit: Var: एकक²; SD: एकक

When to use: linear transformation के बाद variance/SD बदलाव पूछे जाने पर — JEE Main में अक्सर "Y = 3X+2" के बाद Var(Y) पूछते हैं

Conditions: b का variance पर कोई प्रभाव नहीं पड़ता

Common mistake: Var(aX+b) = a²Var(X) + b² लिख देना (b² गलत है); |a| का absolute value भूल जाना SD के लिए

\(P(A \cup B) = P(A) + P(B)\) यदि A व B mutually exclusive हों (\(A \cap B = \emptyset\))

Symbols: P(A ∪ B): कम से कम एक का आना; A, B : परस्पर असंभव घटनाएँ

Unit: आdimensionless

When to use: जब दो घटनाएँ एक साथ न हो सकें — उदा. एक सिक्के में Head व Tail एक साथ नहीं आते

Conditions: A ∩ B = ∅ होना अनिवार्य

Common mistake: सामान्य घटनाओं के लिए भी यह सूत्र लगा देना; mutually exclusive को independent समझ लेना

\(P(A'|B) = 1 - P(A|B)\), \(P(A' \cap B) = P(B) - P(A \cap B)\)

Symbols: A' = A का पूरक (complement)

Unit: आdimensionless

When to use: "कम से कम एक" या "नहीं आना" जैसे प्रश्नों में पूरक प्रायिकता का उपयोग

Conditions: मूल सूत्रों के आधार पर व्युत्पन्न

Common mistake: P(A'|B) को 1-P(A) लिख देना — शर्तयुक्त पूरक केवल शर्त B के सापेक्ष 1 से घटती है
