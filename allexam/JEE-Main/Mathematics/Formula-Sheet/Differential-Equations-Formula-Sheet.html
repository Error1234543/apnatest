order = उच्चतम अवकलज की घात; degree = order बाद पहले पद की घात

Symbols: order: समीकरण में सबसे अधिक कोटि का अवकलज; degree: उस अवकलज की घात जब समीकरण बहुपद रूप में हो

Unit: कोई इकाई नहीं

When to use: किसी अवकल समीकरण की कोटि और घात निर्धारित करने के लिए

Conditions: degree तभी परिभाषित है जब समीकरण सभी अवकलजों के सापेक्ष बहुपद रूप में हो (त्रिकोणमितीय/घातांकीय पद न हों)

Common mistake: sin(y'), √(y') जैसे पद होने पर degree शून्य या अपरिभाषित मान लेना। ऐसे मामलों में पहले समीकरण को बहुपद रूप में लाओ।

dy/dx = f(x,y) ⇔ g(y) dy = f(x) dx

Symbols: g(y): y के पदों वाला फलन; f(x): x के पदों वाला फलन

Unit: —

When to use: चर-पृथक्करणीय (Variable Separable) अवकल समीकरण का हल

Conditions: समीकरण को g(y)·dy = f(x)·dx के रूप में लिखा जा सके

Common mistake: d’Alembert का सूत्र y = vx रखने से पहले यह जाँच नहीं करना कि समीकरण वास्तव में चर-पृथक्करणीय है या नहीं।

∫g(y) dy = ∫f(x) dx + C

Symbols: C: समाकलन स्थिरांक (arbitrary constant)

Unit: —

When to use: चर-पृथक्करणीय समीकरण का सामान्य हल प्राप्त करना

Conditions: दोनों पक्षों का समाकलन संभव हो

Common mistake: स्थिरांक C को केवल एक पक्ष में लिखना (सही है), लेकिन दूसरे पक्ष में भी C जोड़ देना। केवल एक बार +C पर्याप्त है।

M(x,y)dx + N(x,y)dy = 0; यदि ∂M/∂y = ∂N/∂x → सटीक (Exact)

Symbols: M, N: x और y के फलन; ∂M/∂y: M का y के सापेक्ष आंशिक अवकलज; ∂N/∂x: N का x के सापेक्ष आंशिक अवकलज

Unit: —

When to use: सटीक अवकल समीकरण की पहचान और समाधान

Conditions: समीकरण M dx + N dy = 0 के रूप में हो और ∂M/∂y = ∂N/∂x हो

Common mistake: ∂M/∂y = ∂N/∂x होने पर भी ∫N dy में x को स्थिरांक नहीं मानना। दूसरी ओर, असटीक समीकरण को बिना समापन عامل (integrating factor) के हल करने का प्रयास करना।

यदि ∂M/∂y ≠ ∂N/∂x और (∂M/∂y − ∂N/∂x)/N = φ(x) [केवल x का फलन], तो IF = e^{∫φ(x)dx}

Symbols: IF: समापन कारक (Integrating Factor)

Unit: —

When to use: असटीक समीकरण को सटीक बनाने के लिए समापन कारक ज्ञात करना

Conditions: φ(x) केवल x का फलन हो (y के पद न हों)

Common mistake: (∂N/∂x − ∂M/∂y)/M की गणना करने पर y का फलन आ जाने पर भी IF खोजना जारी रखना — यह सूत्र केवल तभी काम करता है जब परिणाम पूर्णतः x का फलन हो।

यदि ∂M/∂y − ∂N/∂x)/M = ψ(y) [केवल y का फलन], तो IF = e^{∫ψ(y)dy}

Symbols: ψ(y): केवल y का फलन

Unit: —

When to use: जब समापन कारक केवल y का फलन हो

Conditions: वास्तव में: (∂M/∂y − ∂N/∂x)/M यदि केवल y का फलन आए

Common mistake: इसे पहचानने में विफल रहना और समय बर्बाद करना। JEE Main में यही दो ही IF केस बार-बार आते हैं।

समीकरण हल: u(x,y) = C, जहाँ u = ∫M(x,y)dx (y स्थिर) + ∫(N के वे पद जिनमें x नहीं) dy

Symbols: u(x,y): समापित फलन; C: मनorex स्थिरांक

Unit: —

When to use: सटीक अवकल समीकरण का सामान्य हल

Conditions: समीकरण सटीक हो (∂M/∂y = ∂N/∂x)

Common mistake: M को x के सापेक्ष समाकलित करते समय y के पदों को भी समाकलन में शामिल करना। पहले केवल x वाले पद समाकलित करो, फिर N के उन पदों को जोड़ो जिनमें x नहीं है।

dy/dx + P(x)y = Q(x); IF = e^{∫P(x)dx}; हल: y·IF = ∫Q(x)·IF dx + C

Symbols: P, Q: x के फलन (या स्थिरांक); IF: समापन कारक; C: समाकलन स्थिरांक

Unit: —

When to use: प्रथम कोटि रैखिक अवकल समीकरण (First Order Linear ODE)

Conditions: समीकरण का मानक रूप dy/dx + P(x)y = Q(x) होना आवश्यक है। Q(x) ≠ 0 होना चाहिए (समघात नहीं)।

Common mistake: P(x) का चिह्न भूल जाना — समीकरण dy/dx − 2y = x³ हो तो P = −2, IF = e^{−2x}। ऋणात्मक चिह्न छोड़ देना सबसे आम त्रुटि है।

Bernoulli: dy/dx + P(x)y = Q(x)yⁿ; v = y^{1−n} प्रतिस्थापन → dv/dx + P(1−n)v = Q(1−n)

Symbols: n: कोई वास्तविक संख्या (n ≠ 0, 1); v = y^{1−n}

Unit: —

When to use: Bernoulli समीकरण को रैखिक रूप में बदलना

Conditions: n = 0 या n = 1 न हो (वे पहले से रैखिक हैं)

Common mistake: v = y^{1−n} के स्थान पर v = y^n या v = y^{n−1} रख देना। y^{1−n} ही सही है।

Homogeneous: dy/dx = F(x,y) जहाँ F(tx,ty) = F(x,y); प्रतिस्थापन y = vx → dy/dx = v + x(dv/dx)

Symbols: v: नया चर; x(dv/dx): v का x के सापेक्ष अवकलज

Unit: —

When to use: समघात अवकल समीकरण को चर-पृथक्करणीय रूप में बदलना

Conditions: M(x,y) और N(x,y) समान कोटि के समघात बहुपद हों

Common mistake: y = vx रखने के बाद dy/dx = v + x(dv/dx) का उपयोग न करना — केवल v रख देना। यह सबसे सामान्य गलती है।

M(x,y)dx + N(x,y)dy = 0; दोनों M और N समान कोटि n के समघात हों → समघात समीकरण

Symbols: n: समघात कोटि; उदा. M=x²+xy, N=xy−y² दोनों कोटि 2

Unit: —

When to use: समघात अवकल समीकरण की पहचान

Conditions: M(λx, λy) = λⁿM(x,y) और N(λx, λy) = λⁿN(x,y)

Common mistake: एक पद समघात हो और दूसरा न हो, जैसे M = x²+y (एक कोटि 2, दूसरा कोटि 1) — ऐसे में समीकरण समघात नहीं है।

d/dx[e^{∫Pdx}·y] = e^{∫Pdx}·Q; इस प्रकार हल सीधे मिला जाता है

Symbols: P, Q: x के फलन

Unit: —

When to use: रैखिक समीकरण को अवकलज के रूप में लिखकर हल करना (संक्षिप्त विधि)

Conditions: P और Q केवल x के फलन हों

Common mistake: IF लगाने के बाद Q×IF का समाकलन करने में त्रुटि, विशेषकर जब ∫Pdx में x के घातपद हों।

x(dy/dx) + y = f(xy)·y; प्रतिस्थापन xy = t → dx/dt का उपयोग

Symbols: t: प्रतिस्थापन चर

Unit: —

When to use: विशिष्ट प्रकार के समीकरण जो xy के फलन में हों

Conditions: समीकरण L'Hopital-जैसा रूप ले सके

Common mistake: xy = t रखकर अवकलज सही से व्यक्त न करना: d(xy)/dx = y + x(dy/dx) = dt/dx → dy/dx = (dt/dx − y)/x

Orthogonal Trajectories: मूल परिवार φ(x,y,C)=0 का अवकल समीकरण m(x,y) पाएँ → लंबवत वक्रों का अवकल समीकरण: dy/dx → −dx/dy

Symbols: m: स्पर्शरेखा की ढाल; −1/m: लंबवत स्पर्शरेखा की ढाल

Unit: —

When to use: लंबवत प्रच्छेदन (Orthogonal Trajectories) ज्ञात करना

Conditions: प्रथम कोटि का समीकरण

Common mistake: ढाल को ऋणात्मक व्युत्क्रम (−1/m) करने के स्थान पर केवल ऋणात्मक (−m) लिख देना।

x¹⁻ⁿ dy/dx + (1−n)y/x = Q(x)y^{1−n} ; substitution u = y^{1−n}

Symbols: u = y^{1−n}, जो Bernoulli के तुल्य है

Unit: —

When to use: कठिन RODE को सरल बनाने के लिए

Conditions: समीकरण RODE के निकट हो

Common mistake: u = y^{n−1} लिख देना बजाय u = y^{1−n} के

d/dx[f(x)·y] = f(x)·g(x) → f(x)·y = ∫f(x)g(x)dx + C

Symbols: f(x): गुणनकारी कारक (एक विशिष्ट रूप)

Unit: —

When to use: कुछ विशेष रूपांतरण

Conditions: —

Common mistake: —

Second-order linear with constant coefficients: a·y'' + b·y' + c·y = 0; Auxiliary eqn: am² + bm + c = 0

Symbols: a,b,c: वास्तविक स्थिरांक; m: सहायक समीकरण का चर

Unit: —

When to use: स्थिरांक गुणांकों वाला द्वितीय कोटि रैखिक समघात समीकरण

Conditions: RHS = 0 (समघात)

Common mistake: Auxiliary equation में चिह्न गलत लिखना और पुनरावृत्ति मूल (repeated root) वाले मामले मेंsecond independent solution भूल जाना

Repeated roots m₁=m₂=m: y = (A + Bx)e^{mx}; Complex roots α±iβ: y = e^{αx}(A cos βx + B sin βx)

Symbols: A, B: स्वेच्छ अदिश; m, α, β: वास्तविक संख्याएँ

Unit: —

When to use: दोहराए गए और सम्मिश्र मूलों के लिए सामान्य हल

Conditions: स्थिरांक गुणांक, समघात

Common mistake: Complex case में e^{αx} को bhoolna और केवल A cos βx + B sin βx लिख देना।

Particular integral (PI) for RHS = e^{ax}: Replace D by a in 1/f(D); if f(a)=0, multiply by x and differentiate f(D)

Symbols: D = d/dx OPERATOR; f(D): Differential operator polynomial

Unit: —

When to use: Non-homogeneous समीकरण का विशेष समाधान

Conditions: f(a) ≠ 0; यदि f(a)=0 तो x·e^{ax}/f'(a)

Common mistake: f(a)=0 होने पर π直接 1/f(a) रख देना — परिणाम असीमित आ जाएगा।

General Solution: y = C.F. + P.I.; C.F. = complimentary function from auxiliary equation roots

Symbols: C.F.: पूरक फलन; P.I.: विशेष समाधान

Unit: —

When to use: non-homogeneous second-order ODE का पूर्ण हल

Conditions: linear, constant coefficients

Common mistake: PI और CF को जोड़ने में चिन्ह त्रुटि

Formation from family of curves y = mx + c: differentiate w.r.t. x → eliminate constants

Symbols: m, c: स्वतंत्र नियतांक

Unit: —

When to use: वक्रों के परिवार से अवकल समीकरण बनाना

Conditions: n स्वेच्छ नियतांकों के लिए n अवकलज की आवश्यकता

Common mistake: नियमित संख्या के अनुसार पर्याप्त अवकलज न लेना। 2 नियतांक → 2nd derivative.

Substitution y = v⁻¹ या y = vx² etc. for special forms

Symbols: v: नया अनजान फलन

Unit: —

When to use: विशेष प्रतिस्थापन से समीकरण सरल करना

Conditions: समीकरण का स्वरूप अनुकूल हो

Common mistake: गलत प्रतिस्थापन चुनना
