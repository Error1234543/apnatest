\(\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C,\quad n\neq -1\)

Symbols: x = चर; n = कोई वास्तविक संख्या; C = समाकलन स्थिरांक

Unit: यदि x परिमाण-रहित है तो एकक ही रहता है

When to use: प्राथमिक घातांक समाकलन के लिए आधार सूत्र

Conditions: n = −1 नहीं होना चाहिए (इस मामले में ln|x| लागू होता है)

Common mistake: n+1 से भाग देना न भूलें; n=−1 लेने पर log सूत्र लगाना ज़रूरी है, अन्यथा परिणाम अमान्य होगा

\(\int \dfrac{dx}{x} = \ln|x| + C\)

Symbols: x = चर; C = समाकलन स्थिरांक

Unit: रहित-एकक

When to use: \dfrac{1}{x} के प्रतिचालन का मानक रूप

Conditions: x \neq 0; अवधिमान absolute value \ln|x| होना चाहिए

Common mistake: \ln x लिख देना बिना mod के — ऋणात्मक x के लिए अमान्य; अक्सर परीक्षाओं में choice trap के रूप में आता है

\(\int e^x\,dx = e^x + C\)

Symbols: x = चर; C = समाकलन स्थिरांक

Unit: रहित-एकक

When to use: घातांकीय फलनों के मूल समाकलन

Conditions: कोई विशेष प्रतिबंध नहीं

Common mistake: e^x का समाकलन 'e^x/x' समझ लेना — यह विकल्प अक्सर MCQ में भ्रमित करता है

\(\int a^x\,dx = \dfrac{a^x}{\ln a} + C,\quad a>0,\; a\neq 1\)

Symbols: a = धनात्मक आधार (स्थिरांक); x = चर; C = समाकलन स्थिरांक

Unit: रहित-एकक

When to use: y=a^x जैसे सामान्य घातांकीय समाकलन

Conditions: a>0 और a≠1; \ln a ≠ 0

Common mistake: \ln a से भाग न करना — सीधा a^x लिख देना; या \log_{10} के साथ उलझना

\(\int \sin x\,dx = -\cos x + C\)

Symbols: x = कोण (रेडियन में); C = समाकलन स्थिरांक

Unit: रेडियन-आधारित

When to use: त्रिकोणमितीय समाकलन की आधारभूत इकाई

Conditions: x रेडियन में होना चाहिए; डिग्री में \dfrac{\pi}{180} गुणक आवश्यक

Common mistake: चिन्ह गलत रख देना (− cos के स्थान पर + cos); रेडियन/डिग्री भ्रम से त्रुटि

\(\int \cos x\,dx = \sin x + C\)

Symbols: x = कोण (रेडियन में); C = समाकलन स्थिरांक

Unit: रेडियन-आधारित

When to use: कॉस्ाइन समाकलन — कल्पनीय प्रश्नों का आधार

Conditions: x रेडियन में होना चाहिए

Common mistake: x रेडियन न होने पर सीधा सूत्र लगाना — r dx/dx गुणक की आवश्यकता होती है

\(\int \sec^2 x\,dx = \tan x + C\) ; \(\int \csc^2 x\,dx = -\cot x + C\)

Symbols: x = कोण (रेडियन); tan, cot, sec, csc क्रमशः प्रतिच्छेदी संबंधी फलन

Unit: रेडियन-आधारित

When to use: व्युत्पन्न-संयोजक समाकलन के दो प्रमुख रूप

Conditions: tan, cot के खंड जहाँ परिभाषित न हों वहाँ अलग से देखें

Common mistake: − चिन्ह cot वाले वाले मामले में छोड़ देना; \sec^2 का समाकलन \sec लिख देना

\(\int \sec x \tan x\,dx = \sec x + C\) ; \(\int \csc x \cot x\,dx = -\csc x + C\)

Symbols: sec, tan, csc, cot = प्राथमिक त्रिकोणमितीय फलन

Unit: रेडियन-आधारित

When to use: उत्पाद रूप में त्रिकोणमितीय समाकलन

Conditions: फलन परिभाषित होने वाले अंतराल पर ही लागू

Common mistake: − चिन्ह को csc case में गलत रखना या भूल जाना

\(\int \dfrac{dx}{\sqrt{1-x^2}} = \sin^{-1}x + C\)

Symbols: x = चर, |x|<1; C = समाकलन स्थिरांक

Unit: रेडियन

When to use: विलोम त्रिकोणमितीय समाकलन — JEE में अत्यंत बारंबार

Conditions: |x| < 1; हर में √(1−x²) रूप

Common mistake: \cos^{-1}x के साथ भ्रमित होना — दोनों के योग 90° होते हैं, परन्तु चिन्ह/हेतु भिन्न

\(\int \dfrac{dx}{1+x^2} = \tan^{-1}x + C\)

Symbols: x = चर; C = समाकलन स्थिरांक

Unit: रेडियन

When to use: विलोम परिबद्ध (inverse trig) समाकलन का सर्वाधिक प्रचलित रूप

Conditions: x ∈ ℝ; हर शून्य नहीं

Common mistake: हर में गुणांक 1 न रखने पर सीधा सूत्र लगाना — पहले 1 से गुणा/भाग करके प्रमाणीकृत रूप लाना होता है

\(\int \dfrac{dx}{x\sqrt{x^2-1}} = \sec^{-1}x + C,\quad |x|>1\)

Symbols: x = चर; sec⁻¹ सेकेंट का व्युत्क्रम

Unit: रेडियन

When to use: sec⁻¹ प्रकार के समाकलन में उपयोग

Conditions: |x| > 1

Common mistake: x²+1 और x²−1 को उल्टा लेना; अंतर्निहित mod या चिन्ह नियम को नजरअंदाज करना

\(\int \dfrac{dx}{x^2-a^2} = \dfrac{1}{2a}\ln\left|\dfrac{x-a}{x+a}\right| + C\)

Symbols: x = चर; a = अशून्य स्थिरांक; C = समाकलन स्थिरांक

Unit: यदि x, a समान एकक में हों

When to use: द्विघात हर जो द्वैध-रैखिक अवयवों में विघटित हो सके

Conditions: x ≠ ±a; a ≠ 0; |x| ≠ |a|

Common mistake: \dfrac{1}{2a} गुणांक भूल जाना; लघुगणक के आंतरिक भाग को उल्टा कर देना

\(\int \dfrac{dx}{a^2-x^2} = \dfrac{1}{2a}\ln\left|\dfrac{a+x}{a-x}\right| + C\)

Symbols: x = चर; a = अशून्य स्थिरांक

Unit: समान एकक

When to use: ऋणात्मक द्विघात हर के समाकलन

Conditions: x² ≠ a²; a ≠ 0

Common mistake: पहले सूत्र (x²−a²) के साथ भ्रमित होकर चिन्ह/अंश-हर उल्टा कर देना

\(\int \dfrac{dx}{x^2+a^2} = \dfrac{1}{a}\tan^{-1}\!\left(\dfrac{x}{a}\right) + C\)

Symbols: x = चर; a = धनात्मक स्थिरांक

Unit: रेडियन

When to use: परिबद्ध व्युत्क्रम त्रिकोणमितीय समाकलन का मानक रूप

Conditions: a ≠ 0; हर हमेशा धनात्मक

Common mistake: 1/a गुणांक न लगाना या x/a के स्थान पर ax लिख देना

\(\int \dfrac{dx}{\sqrt{a^2-x^2}} = \sin^{-1}\!\left(\dfrac{x}{a}\right) + C\)

Symbols: x = चर; a > 0

Unit: रेडियन

When to use: वर्गमूल रूप में द्विघात व्यंजक का समाकलन

Conditions: |x| ≤ a; a ≠ 0

Common mistake: x/a के स्थान पर ax या a/x लेकर उत्तर भ्रमित करना

\(\int \dfrac{dx}{\sqrt{x^2-a^2}} = \ln\left|x+\sqrt{x^2-a^2}\right| + C\)

Symbols: x = चर; a ≠ 0

Unit: समान एकक

When to use: द्विघात वर्गमूल वाले व्यंजक का लघुगणकीय समाकलन

Conditions: x² ≥ a²

Common mistake: ln |x+√(x²−a²)| के बजाय arcsinh या sec⁻¹ गलत चुन लेना

\(\int \dfrac{dx}{\sqrt{x^2+a^2}} = \ln\left|x+\sqrt{x^2+a^2}\right| + C\)

Symbols: x = चर; a ≠ 0

Unit: समान एकक

When to use: धनात्मक द्विघात वर्गमूल समाकलन

Conditions: सभी वास्तविक x के लिए परिभाषित

Common mistake: a² और −a² वाले सूत्रों में अंतर न रख पाना

\(\displaystyle\int u\,dv = uv - \int v\,du\)

Symbols: u, v = x के फलन; du, dv = उनके अवकलज/अवकल

Unit: —

When to use: खंडशः समाकलन — बहुपद×लघुगणकीय/त्रिकोणमितीय/घातांकीय के मिश्रित समाकलन

Conditions: u, v अवकलनीय; समाकलन सुगम होना चाहिए

\(\displaystyle\int_a^b f(x)\,dx = F(b) - F(a),\quad F'(x)=f(x)\)

Unit: क्षेत्रफल समानक

When to use: न्यूटन-लाइबनीज़ प्रमेय — निश्चित समाकलन की गणना का मुख्य उपकरण

Conditions: f, F अंतराल [a,b] पर सतत; सीमाएँ वास्तविक

Common mistake: F(b)−F(a) के स्थान पर F(a)−F(b) या C भूल जाना (निश्चित समाकलन में C शून्य हो जाता है)

When to use: प्रतिस्थापन-सममिति — निश्चित समाकलन को सरल बनाने का शक्तिशाली प्रमेय

Conditions: f समाकलनीय होना चाहिए

\(\int_0^a f(x)\,dx = \int_0^a f(a-x)\,dx\)
