(a + b)^n = \sum_{k=0}^{n} {^nC_k}\, a^{n-k}\, b^{k}

Symbols: n = धनात्मक पूर्णांक घातांक; k = pदं का सूचकांक (0 से n तक); {^nC_k} = द्विपद गुणांक = n!/(k!(n-k)!)

Unit: अमामिक

When to use: किसी भी धनात्मक पूर्णांक घात के लिए द्विपदीय विस्तार, पदों का सामान्य सूत्र निकालने हेतु सबसे महत्वपूर्ण मूल सूत्र।

Conditions: n एक धनात्मक पूर्णांक होना चाहिए; a व b किम्भी वास्तविक/जटिल संख्याएं हो सकती हैं।

Common mistake: {^nC_k} को ^nC_{k-1} या ^nC_{n-k+1} लिख देना; a और b की घातें उल्टा कर देना (a की घात n−k, b की घात k होनी चाहिए)।

T_{k+1} = {^nC_k}\, a^{n-k}\, b^{k}

Symbols: T_{k+1} = क (क+1)वाँ पद; k = 0,1,…,n; {^nC_k} = द्विपद गुणांक

Unit: अमामिक

When to use: विस्तार में किसी विशिष्ट पद (mवाँ पद, mठी अक्षरयुक्त पद आदि) की गणना तेजी से करने हेतु।

Conditions: सबसे पहले पद T_1 लेते हैं, इसलिए mवाँ पद निकालने हेतु k = m−1 रखें।

Common mistake: mवाँ पद चाहें तो k = m रख देना — यह गलत है, सही k = m−1 रखें। इसी तरह (n+1)वाँ पद = अंतिम पद, जहाँ k=n होता है।

{^nC_0},{^nC_1},…,{^nC_n} — समान्तर श्रेढ़ी अनुक्रम के गुणांक नहीं, वृद्धि क्रम: {^nC_0} < {^nC_1} < … (बढ़ते, फिर घटते) यदि n सम है तो {^nC_{n/2}} मध्यम पद सबसे बड़ा; यदि n विषम है तो {^nC_{(n-1)/2}} और {^nC_{(n+1)/2}} दो सबसे बड़े बराबर।

Symbols: प्रत्येक द्विपद गुणांक अपने दोनों ओर वाले गुणांकों से बड़ा होता है जब वह मध्य के निकट हो।

Unit: अमामिक

When to use: कौन-सा द्विपद गुणांक अधिकतम है या मध्य पद कौन-सा है, यह ज्ञात करने हेतु।

Conditions: सभी n ≥ 0 के लिए लागू; n सम या विषम हों।

Common mistake: समान्तर श्रेढ़ी मानकर {^nC_k} = a + kd की तरह व्यवहार करना; सही संबंध है {^nC_{k-1}}/{^nC_k} = (k)/(n−k+1)।

\text{गुणांक }{^nC_r} = {^nC_{n-r}}, \quad \sum_{r=0}^{n}{^nC_r}=2^n, \quad \sum_{r=0}^{n}(-1)^r{^nC_r}=0, \quad \sum_{r \text{even}}{^nC_r}=\sum_{r \text{odd}}{^nC_r}=2^{n-1}

Symbols: रैखिक गुण: संयोजनों का योग 2^n; बिजली गुणों का योग शून्य; सम व विषम स्थानों के द्विपद गुणांकों का योग बराबर 2^{n-1}; प्रतिस्थापन सममिति {^nC_r}={^nC_{n-r}} लागू।

Unit: अमामिक

When to use: बहुपद गुणांकों के योग/अंतर ज्ञात करने हेतु; JEE Main में अक्सर इनका प्रयोग किया जाता है।

Conditions: n ≥ 1; समीकरण {^nC_r} = {^nC_{n-r}} केवल तभी सत्य जब r ≠ n−r (अर्थात r ≠ n/2 जब n सम हो) या तब तब समान।

Common mistake: \sum {^nC_r} = n^2 मान लेना — सही उत्तर 2^n है; सम-विषम के योग बराबर होने का कथन n≥1 के लिए ही सत्य।

\text{मानक द्विपद विस्तार (धनात्मक पूर्णांक घातांक नहीं):}\quad (1+x)^n = 1 + nx + \frac{n(n-1)}{2!}x^2 + \frac{n(n-1)(n-2)}{3!}x^3 + \cdots, \quad |x|<1

Symbols: n — कोई भी वास्तविक/जटिल घातांक; x — छोटी माप (|x|<1) का चर; गुणांक {inom{n}{r}} = \frac{n(n-1)…(n-r+1)}{r!}

Unit: अमामिक

When to use: उत्पन्न णीय (negative/ fractional) घातों के विस्तार में उपयोग; सन्निकटन/अनुमान हेतु, जब |x| < 1 हो।

Conditions: n पूर्णांक नहीं हो सकता, |x|<1 अनिवार्य है; अन्यथा श्रेणी अभिसरण नहीं करती।

Common mistake: धनात्मक पूर्णांक घातांक के लिए भी इस सूत्र को बिना सरलीकरण के प्रयोग करना जिससे जटिल बीजगणित बन जाए; या |x|≥1 पर सूत्र लगाना जो अमान्य है।

\text{सामान्य अक्षरयुक्त पद:} \quad (1-x)^{-n} = \sum_{k=0}^{\infty}{(-1)^k {^nC_k} x^k} = \sum_{k=0}^{\infty}{(-1)^k \frac{n(n+1)…(n+k-1)}{k!} x^k}

Symbols: n — धनात्मक पूर्णांक; x — माप चर; k — पद सूचकांक

Unit: अमामिक

When to use: (1−x)⁻ⁿ के अनंत विस्तार में x^k का गुणांक खोजना, जो JEE Main में बार-बार पूछा जाता है।

Conditions: |x|<1 अनिवार्य है; n धनात्मक पूर्णांक होना चाहिए।

Common mistake: (1+x)⁻ⁿ के गुणांक = (+1)^k {^nC_k} लिख देना; वास्तव में (1−x)⁻ⁿ में (-1)^k होता है, जबकि (1+x)⁻ⁿ में (+1)^k {^nC_k} होता है — दोनों को भ्रमित न करें।

\text{x^n का गुणांक: } (1+ax)^n \text{ में } = {^nC_n} a^n

Symbols: n — घातांक; a — निश्चित गुणांक; x — चर

Unit: अमामिक

When to use: बहुपद विस्तार में किसी निश्चित घात का गुणांक निकालने हेतु, विशेषकर nवीं घात के लिए {^nC_n}=1 होने से सरल।

Conditions: घातांक n पूर्णांक होना चाहिए।

Common mistake: गुणांक a^n को भूल जाना या (1+ax)^n में x^n का गुणांक {^nC_n} a^n = a^n लिख देना — सही है, पर कई बार {^nC_{n-1}} a^{n-1} आदि के साथ भ्रमित कर देते हैं।

\text{मध्य पद:} \begin{cases} n \text{ सम} \Rightarrow \text{मध्य पद } = T_{\frac{n}{2}+1} = {^nC_{n/2}}\, a^{n/2}\, b^{n/2}\\ n \text{ विषम} \Rightarrow \text{दो मध्य पद } T_{\frac{n+1}{2}} \text{ व } T_{\frac{n+3}{2}} \end{cases}

Symbols: n — घातांक; a,b — पद (या राशि) {^nC_{n/2}} — जब n सम हो

Unit: अमामिक

When to use: विस्तार में मध्य स्थित पद(गण) ज्ञात करने हेतु; JEE Main में अक्सर पद की संख्या या मध्य पद पूछा जाता है।

Conditions: n पूर्णांक होना चाहिए; n सम होने पर एक मध्य पद, n विषम होने पर दो मध्य पद।

Common mistake: n विषम होने पर केवल एक मध्य पद मान लेना — सही 2 पद होते हैं; n=4 के लिए 5 पद, मध्य पद = T₃ = {^4C_2}a²b²; n=5 के लिए 6 पद, मध्य पद = T₃ व T₄।

\text{स्वतंत्र पद (constant term): } (ax^p + bx^{-q})^n \text{ में } T_{k+1} = {^nC_k}(ax^p)^{n-k}(bx^{-q})^k = {^nC_k}a^{n-k}b^k\,x^{(n-k)p - kq} \Rightarrow (n-k)p - kq = 0 \Rightarrow k = \frac{np}{p+q}

Symbols: a,b — गुणांक; p,q — x की घातें (धनात्मक); k — पद सूचकांक; n — घातांक

Unit: अमामिक

When to use: द्विपद विस्तार में स्वतंत्र पद (x की घात μηँ वाला पद) ज्ञात करने हेतु सबसे महत्वपूर्ण सूत्र।

Conditions: k पूर्णांक होना चाहिए (0≤k≤n); यदि \frac{np}{p+q} पूर्णांक नहीं आता तो स्वतंत्र पद नहीं है।

Common mistake: x की घात को (n−k)p + k(−q) = 0 के स्थान पर (+) चिन्ह लगाकर गलत स्वरूप देना; अथवा k = np/(p+q) के बाद k को पूर्णांक न मानकर उत्तर खोज लेना जबकि कथन गलत हो सकता है।

\text{गुणांक गुणनफल: } \sum_{k=0}^{n}{^nC_k}\cdot{^nC_{n-k}} = {^{2n}C_n}

Symbols: n — घातांक; k — पद सूचकांक

Unit: अमामिक

When to use: संयोजनों के गुणांक गुणनफल का योग ज्ञात करने हेतु; यह द्विपद प्रमेय के अंतर्गत सबसे महत्वपूर्ण पहचानों में से एक है।

Conditions: n ≥ 0 पूर्णांक होना चाहिए।

Common mistake: इसे \sum{^nC_k}^2 = {^{2n}C_n} के रूप में भ्रमित करना — वास्तव में ये दोनों बराबर हैं: \sum_{k=0}^n{^nC_k}^2 = {^{2n}C_n} ; ध्यान रहे \sum{^nC_k}{^nC_{n-k}} भी वही देता है।

\text{बहुपद गुणांक: } (x_1+x_2+…+x_m)^n = \sum_{k_1+…+k_m=n}\frac{n!}{k_1!k_2!… k_m!}x_1^{k_1}x_2^{k_2}… x_m^{k_m}

Symbols: m — राशिओं की संख्या; n — घातांक; k_i — प्रत्येक राशि की घात; \frac{n!}{k_1!\u2026 k_m!} = बहुपद गुणांक

Unit: अमामिक

When to use: 3 या अधिक राशिओं के द्विपद विस्तार (मल्टिनॉमियल) के लिए; JEE Main में (x+y+z)^n जैसी समस्याएं मिलती हैं।

Conditions: k_1+k_2+…+k_m = n, प्रत्येक k_i ≥ 0 पूर्णांक होना चाहिए।

Common mistake: द्विपद गुणांक {^nC_k} का प्रयोग करते समय m>2 वाली समस्या में m=2 ही मान लेना — यह गलत है, इसमें बहुपद गुणांक \frac{n!}{k_1!k_2!… k_m!} का प्रयोग करना अनिवार्य है।

\text{अधिकतम द्विपद गुणांक: } \text{यदि } \frac{{^nC_{k-1}}}{{^nC_k}} > 1 \Rightarrow k < \frac{n+1}{2} \Rightarrow \text{बढ़ता है;} \text{यदि } \frac{{^nC_{k-1}}}{{^nC_k}} < 1 \Rightarrow k > \frac{n+1}{2} \Rightarrow \text{घटता है}

Symbols: k — गुणांक का सऱकांक; n — घातांक

Unit: अमामिक

When to use: कौन-सा द्विपद गुणांक अधिकतम है, यह जल्दी निर्धारण हेतु।

Conditions: n पूर्णांक होना चाहिए; k पूर्णांक होना चाहिए; \frac{{^nC_{k-1}}}{{^nC_k}} = \frac{k}{n-k+1} का प्रयोग करें।

Common mistake: k = n/2 ही हमेशा अधिकतम मान लेना — जब n विषम है तो दो बराबर अधिकतम गुणांक होते हैं: {^nC_{(n-1)/2}} व {^nC_{(n+1)/2}}।
