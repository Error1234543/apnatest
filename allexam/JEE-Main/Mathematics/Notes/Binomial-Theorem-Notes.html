Binomial Theorem — JEE Main Complete Notes (Hindi)

JEE MainHindiNotes

1. द्विपद प्रमेय (Binomial Theorem) — कथन एवं सामान्य पद

द्विपद प्रमेय n के धनात्मक पूर्णांक होने पर किसी द्विपद (a + b)^n का प्रसार देता है। इसका कथन इस प्रकार है: (a + b)^n = Σ(k=0 se n) ^nC_k · a^(n-k) · b^k, जहाँ ^nC_k = n! / [k!(n-k)!] द्विपद गुणांक (binomial coefficient) है। इसे विस्तार से लिखने पर: (a+b)^n = ^nC_0·a^n + ^nC_1·a^(n-1)·b + ^nC_2·a^(n-2)·b^2 + ... + ^nC_n·b^n। प्रत्येक पद में a की घात n से घटती जाती है और b की घात 0 से बढ़ती जाती है, जबकि दोनों की घातों का योग हमेशा n होता है।

JEE Main के लिए सबसे महत्वपूर्ण सूत्र: r+1 वाँ सामान्य पद T_{r+1} = ^nC_r · a^(n-r) · b^r। यहाँ r = 0, 1, 2, ..., n तक जाता है। याद रखें कि indexing 0 से शुरू होती है — अर्थात् पहला पद r=0 के साथ आता है।

विपरीत क्रम वाला प्रसार भी आवश्यक है: (a+b)^n = ^nC_0·b^n + ^nC_1·b^(n-1)·a + ... + ^nC_n·a^n। प्रश्नों में कभी (x+a) की जगह (a+x) दिया जाता है तो paddy swap करने से भ्रमित न हों।

2. मध्य पद (Middle Terms) — n के सम/विषम होने पर

n सम (even) होने पर: कुल (n+1) पद होते हैं जो एक सम संख्या हैं। इसलिए दो मध्य पद होते हैं — (n/2 + 1)वाँ और (n/2 + 2)वाँ। उदाहरण: n=4 → 5 पद, मध्य पद 3वाँ (T_3 = ^4C_2·a^2·b^2)।

n विषम (odd) होने पर: कुल (n+1) पद सम संख्या में होते हैं। एक ही मध्य पद होता है — ((n+1)/2 + 1)वाँ, अर्थात् ((n+3)/2)वाँ पद। उदाहरण: n=5 → 6 पद, मध्य पद 4था (T_4 = ^5C_3·a^2·b^3)।

याद रखने का आसान तरीका: मध्य पद का r मान = n/2 (यदि n सम) और r = (n±1)/2 (यदि n विषम)। JEE Main में अक्सर 'तीसरा पद', 'पाँचवाँ पद' जैसे प्रश्न सीधे T_{r+1} सूत्र से निकाले जाते हैं — इसलिए सूत्र को रटने की बजाय तार्किक ढंग से याद रखें: r = पद-क्रमांक - 1।

3. स्वतंत्र पद (Independent Term) — बिन x वाला पद

स्वतंत्र पद वह पद है जिसमें चर (variable) x नहीं होता, अर्थात x की घात शून्य हो। जेईई मेन में यह एक बहुत ही frequently tested concept है।

विधि: सामान्य पद T_{r+1} = ^nC_r · a^(n-r) · b^r में x की घात को व्यक्त करें। उसके बाद x की घात = 0 रखकर r का मान ज्ञात करें। यदि r एक पूर्णांक आता है तो स्वतंत्र पद अस्तित्व में होता है; अन्यथा यह पद नहीं मिलेगा।

उदाहरण: (3x^2 - 2/(x^3))^10 में स्वतंत्र पद ज्ञात करें। सामान्य पद: T_{r+1} = ^10C_r · (3x^2)^(10-r) · (-2/x^3)^r = ^10C_r · 3^(10-r) · (-2)^r · x^(20-2r) · x^(-3r) = ^10C_r · 3^(10-r) · (-2)^r · x^(20-5r)। x की घात = 0 ⇒ 20 - 5r = 0 ⇒ r = 4। स्वतंत्र पद = ^10C_4 · 3^6 · (-2)^4 = 210 · 729 · 16 = 2,458,080।

सावधानी: कभी-कभी (ax^p + b/x^q)^n में p और q अलग-अलग होते हैं — उस स्थिति में भी वैधी विधि उही है: x की कुल घात = 0 रखें।

4. द्विपद गुणांकों के गुण (Properties of Binomial Coefficients)

कई महत्वपूर्ण गुण JEE Main में सीधे प्रश्नों के रूप में आते हैं:

• सम/विषम पदों का योग: ^nC_0 + ^nC_2 + ^nC_4 + ... = ^nC_1 + ^nC_3 + ^nC_5 + ... = 2^(n-1)

• सन्दर्भबिंदु विधि से प्रमाण: (1+1)^n = 2^n => सभी गुणांकों का योग = 2^n; (1-1)^n = 0 => सम पदों का योग = विषम पदों का योग => प्रत्येक = 2^(n-1)

• प्रतिस्थापन x = 1, x = -1, x = i इत्यादि से व्युत्पन्न संबंध:
- ^nC_0 - ^nC_2 + ^nC_4 - ^nC_6 + ... = 2^(n/2)·cos(nπ/4)
- ^nC_1 - ^nC_3 + ^nC_5 - ... = 2^(n/2)·sin(nπ/4)

• क्रमित गुणांकों का योग: 1·^nC_1 + 2·^nC_2 + 3·^nC_3 + ... + n·^nC_n = n·2^(n-1)

• द्वितीय प्रकार: 1²·^nC_1 + 2²·^nC_2 + ... + n²·^nC_n = n(n+1)·2^(n-2)

• ^nC_r = ^nC_{n-r} (प्रतिसाम्य)

• ^nC_r · r! = ^nP_r

• ^nC_{r-1} + ^nC_r = ^nC_r_{+1}

ये सभी गुण प्रमाण सहित याद रखें — JEE Main में कई बार प्रमाण आधारित प्रश्न भी आते हैं।

5. द्विपदीय प्रसार के महत्वपूर्ण सर्वसमिकाएँ

• ^nC_0 + ^nC_1 + ^nC_2 + ... + ^nC_n = 2^n

• ^nC_0 - ^nC_1 + ^nC_2 - ^nC_3 + ... + (-1)^n·^nC_n = 0

• (^nC_0 + ^nC_2 + ^nC_4 + ...)^2 - (^nC_1 + ^nC_3 + ...)^2 = 0

• (^nC_0)^2 + (^nC_1)^2 + ... + (^nC_n)^2 = ^2nC_n

• (^nC_0)·(^nC_r) + (^nC_1)·(^nC_{r+1}) + ... + (^nC_{n-r})·(^nC_n) = ^2nC_r

• ^nC_0 - 2·^nC_1 + 4·^nC_2 - ... + (-2)^n·^nC_n = (-1)^n

• (1+x)^(n-1) · (1+x) = (1+x)^n ⇒ गुणांकों का संयोजन

इन सर्वसमिकाओं को याद रखने का सबसे अच्छा तरीका है — प्रत्येक को (1±x)^n या x=1, x=-1 रखकर निकालना। JEE Main में अक्सर योग ∑(r=0 to n) ^nC_r / (r+1) जैसे व्यंजकों से सम्बन्धित प्रश्न आते हैं। अतिरिक्त सूत्र: ^nC_r / (r+1) = ^(n+1)C_{r+1} / (n+1)।

6. ऋणात्मक एवं भिन्नात्मक घातांक (Negative & Fractional Indices)

जेईई मेन में (a+x)^n जहाँ n ऋणात्मक या भिन्नात्मक है, केवल तभी प्रसारित किया जा सकता है जब |x/a| < 1 अर्थात |x| < |a|।

सामान्य रूप: (1+x)^n = 1 + nx + n(n-1)/2! · x² + n(n-1)(n-2)/3! · x³ + ..., जहाँ n कोई भी वास्तविक संख्या हो सकती है।

ऋणात्मक घातांक के उदाहरण:
• (1-x)^(-1) = 1 + x + x² + x³ + ... (अनंत श्रेणी, |x| < 1)
• (1+x)^(-2) = 1 - 2x + 3x² - 4x³ + ...

भिन्नात्मक घातांक के उदाहरण:
• (1+x)^(1/2) = 1 + x/2 - x²/8 + x³/16 - ...
• (1+x)^(-1/2) = 1 - x/2 + 3x²/8 - 5x³/16 + ...

JEE Main में अक्सर प्रश्न इस प्रकार आते हैं: (1+2x)^(-3) के प्रसार में x^4 का गुणांक ज्ञात करें। सामान्य पद = ^(-3)C_r · (2x)^r, जहाँ ^(-3)C_r = (-1)^r · (r+2)(r+1)/2!

अनिवार्य चेक: प्रसार की शर्त |x| < |a| हमेशा लिखें — कुछ प्रश्नों में यह शर्त पूछी जाती है।

7. महत्वपूर्ण अनुप्रयोग (Divisibility, Approximation, etc.)

(101)^50 : (100+1)^50 के रूप में लिखकर प्रसार से जटिल संख्याओं का अनुमान लगाया जा सकता है। प्रथम कुछ पदों से ही पर्याप्त सटीकता प्राप्त हो जाती है।

विभाज्यता (Divisibility): किसी भी पूर्णांक n के लिए (1+x)^n - 1 सदैव x से विभाज्य होता है। विशेषतः (1+1)^n = 2^n ⇒ 2^n - 1 सदैव 1 से विभाज्य (सर्वदा सत्य)।

(1+x)^n में x = 1 रखने पर 2^n मिलता है। इसी प्रकार, (1-1)^n = 0 से सम व विषम पदों का अंतर शून्य मिलता है।

(n+1)^n का अंक ज्ञात करना: (1+n)^n के प्रसार में अंतिम दो पदों से एकांक व दहांक का पता लगایا जा सकता है।

(1+x)^n (1+y)^m के गुणनफल में x^r·y^s का गुणांक: ^nC_r · ^mC_s। यह गुण JEE Main में बहुपद प्रसार से सम्बन्धित प्रश्नों में काम आता है।

8. गैर-पूर्णांक घातांक में सबसे बड़ा पद एवं अधिकतम गुणांक

जेईई मेन में (1+x)^n के प्रसार में सबसे बड़े पद (greatest term) और सबसे बड़े गुणांक (greatest coefficient) के बीच अंतर स्पष्ट होना आवश्यक है।

सबसे बड़ा गुणांक: ^nC_r में r = n/2 (यदि n सम) या r = (n±1)/2 (यदि n विषम)। अर्थात ^nC_0, ^nC_1, ..., ^nC_n में मध्य का गुणांक सबसे बड़ा होता है।

सबसे बड़ा पद: (1+x)^n में rवाँ पद T_r = ^nC_{r-1}·x^(r-1)। सबसे बड़े पद के लिए T_{r+1}/T_r > 1 रखकर r का मान ज्ञात करें। यदि T_{r+1}/T_r = 1 हो तो r+1 और r+2 दोनों पद बराबर व सबसे बड़े होंगे।

(1+x)^n में सबसे बड़ा पद ज्ञात करने का सूत्र: (n+1)|x| / (1+|x|)। यदि यह पूर्णांक m है तो mवाँ व (m+1)वाँ पद बराबर व सबसे बड़े होंगे; अन्यथा ⌊(n+1)|x|/(1+|x|)⌋ + 1 वाँ पद सबसे बड़ा होगा।

भिन्नात्मक घातांक के लिए भी यही सिद्धांत लागू होता है — केवल y = x/a रखकर लागू करें।

9. JEE Main में प्रायः पूछे जाने वाले प्रकार (Exam-Focused Types)

1. सामान्य पद ज्ञात करना: सीधा सूत्र T_{r+1} = ^nC_r · a^(n-r) · b^r।

2. स्वतंत्र पद ज्ञात करना: x की घात = 0 रखें।

3. विशिष्ट पद (rवाँ/ (r+1)वाँ) ज्ञात करना: सूत्र में r मान रखें।

4. गुणांक ज्ञात करना: ^nC_r · (स्थिरांक के गुणा)।

5. दो प्रसारों के गुणनफल में किसी विशिष्ट पद का गुणांक: ^nC_r · ^mC_s की अवधारणा।

6. सम/विषम पदों के गुणांकों का योग: 2^(n-1) या द्वितीय प्रकार के सूत्र।

7. सबसे बड़ा पद / सबसे बड़ा गुणांक ज्ञात करना: अनुपात विधि।

8. ऋणात्मक/भिन्नात्मक घातांक का प्रसार: सामान्य पद सूत्र का सीधा अनुप्रयोग।

9. द्विपदीय प्रमेय से संबंधित प्रमाण प्रश्न: प्रतिस्थापन विधि से सिद्ध करें।

10. (a+b)^n + (a-b)^n और (a+b)^n - (a-b)^n के सरलीकरण: केवल सम/विषम पद रहते हैं।

प्रत्येक प्रकार को कम से कम 2-3 उदाहरणों के साथ अभ्यास करें।

10. गलतियाँ एवं भ्रम (Common Mistakes & Confusion Points)

• ^nC_r की गणना में k! और (n-k)! को छोड़ देना — ^nC_r = n!/[k!(n-k)!] याद रखें।

• 'rवाँ पद' और '(r+1)वाँ पद' में भ्रम — सूत्र T_{r+1} में r = 0 से शुरू होता है, इसलिए rवाँ पद ≠ T_r (यह T_r = ^nC_{r-1}·... होगा)।

• ^nC_r · ^nC_{n-r} = ^nC_r है, लेकिन ^nC_r · ^nC_s ≠ ^nC_{r+s} — यह गलत है।

• ^nC_0 + ^nC_1 + ... + ^nC_n = 2^n केवल नॉन-नेगेटिव पूर्णांक n के लिए। ऋणात्मक/भिन्नात्मक n के लिए यह नियम लागू नहीं होता।

• (a+b)^n में a = 1 रखकर गुणांक निकालते समय b के चिह्न को भूल जाना — प्रत्येक पद में (-2)^r जैसी अभिव्यक्ति में चिह्न महत्वपूर्ण है।

• द्विपदीय प्रसार अनंत श्रेणी बन सकता है जब n ऋणात्मक या भिन्नात्मक हो — इस स्थिति में शर्त |x| < |a| होनी चाहिए।

• ^nC_r = ^nC_{n-r} का उपयोग करते समय r और n-r को interchange करने में भ्रम — दोनों सही हैं, केवल सुविधा के अनुसार चुनें।

• x = 1 रखकर सभी गुणांकों का योग 2^n आता है — यह x का मान व्यंजक में रखकर आता है, न कि गुणांक में अलग से।

Important facts

  • T_{r+1} = ^nC_r · a^(n-r) · b^r — द्विपद प्रमेय का सामान्य पद सूत्र, रट्टें।
  • ^nC_0 + ^nC_1 + ... + ^nC_n = 2^n — सर्वाधिक महत्वपूर्ण सर्वसमिका।
  • ^nC_0 + ^nC_2 + ... = ^nC_1 + ^nC_3 + ... = 2^(n-1) — सम/विषम पदों का योग।
  • (^nC_0)^2 + (^nC_1)^2 + ... + (^nC_n)^2 = ^2nC_n — अतिरिक्त महत्वपूर्ण सर्वसमिका।
  • n सम हो तो दो मध्य पद (n/2 +1 और n/2+2); n विषम हो तो एक मध्य पद ((n+3)/2)।
  • स्वतंत्र पद के लिए x की घात = 0 रखें — यह जेईई मेन का सबसे frequently tested type है।
  • सबसे बड़ा पद: (n+1)|x|/(1+|x|) सूत्र से ज्ञात करें।
  • ऋणात्मक/भिन्नात्मक घातांक के लिए प्रसार अनंत श्रेणी है, शर्त |x| < |a| अनिवार्य है।
  • ^nC_r · r! = ^nP_r — क्रमित चयन से संबंध।
  • 1·^nC_1 + 2·^nC_2 + ... + n·^nC_n = n·2^(n-1) — जेईई में प्राय: पूछा जाता है।
  • ^(n+1)C_{r+1} = ^nC_r + ^nC_{r+1} — पास्कल त्रिकोण का मूल सिद्धांत।
  • JEE Main मेंBinomial Theorem से लगभग 1-2 प्रश्न प्रत्येक वर्ष आते हैं — इसके लिए प्रत्येक type का अभ्यास आवश्यक है।

Formulas and relationships

(a+b)^n = Σ(k=0 to n) ^nC_k · a^(n-k) · b^k, जहाँ ^nC_k = n!/[k!(n-k)!]
T_{r+1} = ^nC_r · a^(n-r) · b^r — सामान्य पद
^nC_0 + ^nC_1 + ... + ^nC_n = 2^n
^nC_0 + ^nC_2 + ^nC_4 + ... = ^nC_1 + ^nC_3 + ^nC_5 + ... = 2^(n-1)
(^nC_0)^2 + (^nC_1)^2 + ... + (^nC_n)^2 = ^2nC_n
1·^nC_1 + 2·^nC_2 + ... + n·^nC_n = n·2^(n-1)
1²·^nC_1 + 2²·^nC_2 + ... + n²·^nC_n = n(n+1)·2^(n-2)
^nC_r · ^nC_{n-r} = (^nC_r)^2
^(n+1)C_{r+1} = ^nC_r + ^nC_{r+1} (पास्कल नियम)
(1+x)^n = 1 + nx + n(n-1)/2! · x² + n(n-1)(n-2)/3! · x³ + ... (n किसी भी वास्तविक संख्या के लिए, |x| < 1)
सबसे बड़ा पद (1+x)^n में: m = (n+1)|x|/(1+|x|); यदि m पूर्णांक हो तो mवाँ व (m+1)वाँ बराबर; अन्यथा ⌊m⌋+1 वाँ सबसे बड़ा
(a+b)^n + (a-b)^n = 2[^nC_0·a^n + ^nC_2·a^(n-2)·b² + ^nC_4·a^(n-4)·b⁴ + ...]
(a+b)^n - (a-b)^n = 2[^nC_1·a^(n-1)·b + ^nC_3·a^(n-3)·b³ + ...]

Common mistakes

  • सामान्य पद के सूत्र में r का मान गलत रख देना — याद रखें T_{r+1} में पहला पद r=0 के साथ आता है।
  • स्वतंत्र पद ज्ञात करते समय x की घात को व्यंजक में सही ढंग से जड़ना — अक्सर (x^p)^(n-r) में घात गुणा नहीं होती।
  • द्विपद गुणांकों के योग में x=1 और x=-1 रखना भूल जाना — यह सबसे बुनियादी त्रुटि है।
  • ^nC_r = ^nC_{n-r} का उपयोग करते समय r = n-r ⇒ r = n/2 केवल तभी लागू होता है जब n सम हो।
  • ऋणात्मक घातांक के प्रसार में अनंत श्रेणी होने के कारण प्रारंभिक केवल कुछ पद ले लेना — JEE Main में अक्सर विशिष्ट पद पूछा जाता है।
  • सबसे बड़े पद और सबसे बड़े गुणांक में भ्रम — सबसे बड़ा गुणांक ^nC_r में r ≈ n/2 पर होता है, जबकि सबसे बड़ा पद x के मान पर निर्भर करता है।
  • (1+x)^n का प्रसार लिखते समय चिह्न भूल जाना — यदि x ऋणात्मक है तो पदों के चिह्न बदल जाएँगे।
  • d/dx[(1+x)^n] = n(1+x)^(n-1) को लागू करते समय अक्सर z = 1+x रखकर chain rule भूल जाते हैं।
  • ^(2n)C_n को ^nC_n से गलत ज्ञात कर देना — ये पूरी तरह भिन्न हैं।
  • प्रश्न में (a+x)^n vs (x+a)^n — दोनों समान हैं लेकिन अंतिम उत्तर लिखते समय स्थिरांक को भूल जाना।
