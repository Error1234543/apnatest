1. Complex Number: Basic Definition, Algebraic Form, and Operations

Ek complex number ko z = x + iy ke roop mein likha jata hai, jahan x aur y real numbers hain. x ko real part (Re(z) = x) aur y ko imaginary part (Im(z) = y) kaha jata hai. i = √(-1) hai, jise iota khte hain. Dono real aur imaginary parts milakar ek plane banaate hain jise complex plane ya Argand plane kehte hain.

Jab y = 0 hota hai, to z purely real hota hai (z = x). Jab x = 0 hota hai, to z purely imaginary hota hai (z = iy). Na to purely real na purely imaginary — dono non-zero hone par use purely imaginary nahi, simply ek general complex number kehte hain.

Do complex numbers z₁ = a + ib aur z₂ = c + id ke liye basic operations:

• Addition: z₁ + z₂ = (a + c) + i(b + d)
• Subtraction: z₁ − z₂ = (a − c) + i(b − d)
• Multiplication: z₁ · z₂ = (ac − bd) + i(ad + bc) — yahan yaad rakhein ki i² = −1 se cross terms nikalte waqt sign change hota hai.
• Division: z₁/z₂ = z₁·z̄₂/|z₂|² — denominator ko real banane ke liye conjugate se multiply karna padta hai.

Complex numbers ka set all numbers (ℂ) field banata hai jisme addition aur multiplication dono commutative, associative, distributive hain. Har non-zero complex number ka multiplicative inverse exist karta hai: 1/z = z̄/|z|².

JEE Main mein frequently pucha jata hai: agar z = x + iy hai, to Re(z) = x, Im(z) = y. Kuch sawalon mein z + z̄ = 2Re(z) aur z − z̄ = 2i·Im(z) ka use hota hai. Zero ka real bhi 0 hai aur imaginary bhi 0 — yeh dono category mein aata hai.

2. Geometrical Representation: Argand Diagram and Locus

Complex numbers ko 2D Cartesian plane mein represent kiya ja sakta hai, jise Argand Diagram kehte hain. Isme horizontal axis ko real axis (Re-axis) aur vertical axis ko imaginary axis (Im-axis) kaha jata hai. Point z = x + iy ka coordinates (x, y) hote hain.

Locus ka matlab hai aisa point jo kisi specific condition ko satisfy karta ho. Common locus problems:

• |z − z₁| = r → circle whose centre is z₁ and radius is r. Example: |z − (1 + 2i)| = 3 means circle centre (1, 2) radius 3.
• |z − z₁| = |z − z₂| → perpendicular bisector of line segment joining z₁ and z₂.
• |z − z₁| = k|z − z₂| where k ≠ 1 → Circle of Apollonius.
• Re(z) = c → vertical line x = c; Im(z) = c → horizontal line y = c.
• arg(z − z₀) = α → ray starting from z₀ making angle α with positive real axis (excluding z₀ itself).

Triangle inequalities are very important for JEE:

• |z₁ + z₂| ≤ |z₁| + |z₂| (Equality when z₁, z₂ same direction)
• |z₁ − z₂| ≥ ||z₁| − |z₂|| (Equality when they are collinear from origin)
• |z₁ + z₂|² + |z₁ − z₂|² = 2(|z₁|² + |z₂|²) — parallelogram law

Geometrically, |z| represents distance of point z from origin. |z − w| represents distance between points z and w. Yeh distance interpretation bahut useful hoti hai locus problems solve karne mein.

3. Modulus, Argument, Conjugate and Their Properties

Modulus of z = x + iy is |z| = √(x² + y²). It is always non-negative real. Key properties:

• |z|² = z · z̄ — conjugate se multiplication karke modulus squared milta hai.
• |z₁·z₂| = |z₁|·|z₂|
• |z₁/z₂| = |z₁|/|z₂| (z₂ ≠ 0)
• |zⁿ| = |z|ⁿ for any integer n
• |z₁ + z₂| ≤ |z₁| + |z₂|
• |z₁ − z₂| ≥ ||z₁| − |z₂||
• |z| = |z̄| = |−z|

Conjugate: z̄ = x − iy. JEE Main mein in properties ko regularly use karna padta hai:

• z + z̄ = 2Re(z); z − z̄ = 2i·Im(z)
• z · z̄ = |z|² (real number)
• z is real iff z = z̄
• z is purely imaginary iff z = −z̄ (i.e., Re(z) = 0)
• z̄₁ ± z̄₂ = z̄₁ ± z̄₂; (z₁·z₂)̄ = z̄₁·z̄₂; (z₁/z₂)̄ = z̄₁/z̄₂
• (z̄)̄ = z
• z is real if and only if z = z̄

Argument (principal value): arg(z) = θ, jahan z = |z|(cosθ + i sinθ), aur −π < θ ≤ π. Tanθ = y/x, lekin quadrant check karna bahut zaroori hai.

Agar z third quadrant mein hai (x < 0, y < 0), to tan⁻¹(y/x) positive aayega, lekin actual argument negative hona chahiye — isliye arg(z) = −π + tan⁻¹(y/x) hoga.

Properties of argument:
• arg(z₁·z₂) = arg(z₁) + arg(z₂) (mod 2π)
• arg(z₁/z₂) = arg(z₁) − arg(z₂) (mod 2π)
• arg(zⁿ) = n·arg(z) (mod 2π)

Important identity: If z ≠ 0 then z/|z| = e^(i·arg(z)) ek unit complex number hai.

4. Polar and Euler Forms, De Moivre's Theorem

Polar form: z = r(cosθ + i sinθ), jahan r = |z| = √(x² + y²) aur θ = arg(z). Euler's form: z = re^(iθ) — yeh compact notation hai jo JEE mein bohot use hoti hai.

De Moivre's Theorem: (cosθ + i sinθ)ⁿ = cos(nθ) + i sin(nθ) — yeh theorem integer n ke liye directly apply hota hai. Fractional powers ke liye multiple values aate hain.

Iska use karke hum cos(nθ) aur sin(nθ) ko cosθ aur sinθ ke polynomials ke roop mein express kar sakte hain:

• cos(3θ) = 4cos³θ − 3cosθ
• sin(3θ) = 3sinθ − 4sin³θ
• cos(2θ) = cos²θ − sin²θ = 2cos²θ − 1 = 1 − 2sin²θ
• sin(2θ) = 2sinθ cosθ

Roots of a complex number using De Moivre:
z = r(cosα + i sinα) ke nth roots hain:
z_k = r^(1/n)[cos((α + 2kπ)/n) + i sin((α + 2kπ)/n)], k = 0, 1, 2, ..., n−1

Yeh n roots complex plane mein regularly spaced points banate hain jo ek regular n-gon ke vertices hote hain circle par.

JEE Main level ke liye most important application: finding roots of unity (see next section). Also very important: expressing sin³θ, cos³θ, sin⁴θ etc. in terms of multiples of θ using De Moivre — ye trigonometric integration mein bhi kaam aata hai.

Formula expansion (useful shortcut):
(cosθ + i sinθ)ⁿ + (cosθ − i sinθ)ⁿ = 2cos(nθ)
(cosθ + i sinθ)ⁿ − (cosθ − i sinθ)ⁿ = 2i sin(nθ)

5. Cube Roots of Unity and Their Properties

Equation z³ = 1 ke roots cube roots of unity kehte hain. Inhe nikalne ke liye z³ − 1 = 0 → (z − 1)(z² + z + 1) = 0.

Teeno roots hain:
• ω = (−1 + i√3)/2 = cos(2π/3) + i sin(2π/3)
• ω² = (−1 − i√3)/2 = cos(4π/3) + i sin(4π/3)
• 1 (trivial root)

Roots of unity ke fundamental properties:

• 1 + ω + ω² = 0 (very frequently used!)
• ω³ = 1 (har baar power reduce kar sakte hain)
• ω² = ω̄ (conjugate property)
• (ω)ⁿ = 1 if n is multiple of 3; = ω if n ≡ 1 mod 3; = ω² if n ≡ 2 mod 3
• (ω²)ⁿ = 1 if n is multiple of 3; = ω² if n ≡ 1 mod 3; = ω if n ≡ 2 mod 3

Geometrically, teeno roots (1, ω, ω²) equilateral triangle banate hain unit circle par. Argument differences hamesha 2π/3 = 120° hote hain.

Fourth roots of unity: 1, i, −1, −i — square roots of −1 hain i aur −i.

Cube roots of any complex number z₀ = r(cosα + i sinα):
³√r [cos((α+2kπ)/3) + i sin((α+2kπ)/3)] for k=0,1,2

JEE Main mein often pucha jata hai: if ω is a cube root of unity, then simplify expressions like (1 + ω)ⁿ ya (1 + ω²)ⁿ — answer hamesha simple aata hai kyunki 1 + ω = −ω² aur 1 + ω² = −ω.

Also important: Product of (z − ωᵏ) for k = 0 to n−1 equals zⁿ − 1.

6. Quadratic Equations: Nature of Roots and Fundamental Theorem of Algebra

General quadratic equation: ax² + bx + c = 0, a ≠ 0.

Discriminant D = b² − 4ac. Nature of roots depends on D:

• D > 0 and perfect square: real, distinct, rational roots → x = (−b ± √D)/(2a)
• D > 0 but not perfect square: real, distinct, irrational roots
• D = 0: real and equal roots (repeated root) → x = −b/(2a)
• D < 0: complex conjugate pair of roots → x = (−b ± i√|D|)/(2a)

Fundamental Theorem of Algebra: har polynomial equation of degree n ke exactly n roots hote hain (counting multiplicity). Ye complex numbers mein guaranteed hote hain.

Important corollaries:
• Every polynomial of odd degree has at least one real root (since complex roots come in conjugate pairs, odd degree can't have all complex non-real roots).
• If a quadratic with real coefficients has one root α + iβ, the other must be α − iβ.
• A cubic with real coefficients has either 3 real roots or 1 real + 2 complex conjugate roots.

If one root of ax² + bx + c = 0 is α, then aα² + bα + c = 0 (substitute to verify).

Special cases often tested:
• If coefficients are rational and one root is p + q√r (irrational), other root is p − q√r.
• If coefficients are complex (non-real), conjugate root theorem does NOT necessarily apply — roots need not be conjugates.

Reciprocal equation type: ax² + bx + c = 0 jahan roots reciprocals of each other → a = c (since product of roots = c/a = 1).

Pure quadratic (b = 0): x² + c = 0 → x = ±√(−c).

7. Relations Between Roots and Coefficients, Conditions for Common Roots

For ax² + bx + c = 0 with roots α, β:

• Sum of roots: α + β = −b/a
• Product of roots: α·β = c/a
• Equation with roots α, β: x² − (α+β)x + αβ = 0 → x² + (b/a)x + c/a = 0 → ax² + bx + c = 0

Common root conditions (two equations a₁x² + b₁x + c₁ = 0 and a₂x² + b₂x + c₂ = 0):

• If they have EXACTLY one common root α:
α = (b₁c₂ − b₂c₁)/(a₁c₂ − a₂c₁) = (c₁a₂ − c₂a₁)/(a₁b₂ − a₂b₁)
Equating these two expressions gives the condition: (a₁b₂ − a₂b₁)(b₁c₂ − b₂c₁) = (c₁a₂ − c₂a₁)(a₁b₂ − a₂b₁)
Simplified form: (a₁c₂ − a₂c₁)(b₁c₂ − b₂c₁) = (a₁b₂ − a₂b₁)(c₁a₂ − c₂a₁)

• If BOTH roots are common: a₁/a₂ = b₁/b₂ = c₁/c₂ (proportionality condition)

Special case: x³ − 1 = 0 aur x³ + 1 = 0 ka common root 1 nahi hai (kyunki 1³+1≠0), lekin ω common root hai: ω³−1=0 ✓ aur ω³+1=2≠0. Wait — ω³ = 1, so ω³ + 1 = 2 ≠ 0. Actually for x³+1=0, roots are −1, −ω, −ω². So no common root between x³−1=0 and x³+1=0.

Golden triangle condition (often asked): If α, β, γ are roots of x³ + px² + qx + r = 0, then:
α + β + γ = −p
αβ + βγ + γα = q
αβγ = −r

If α, β, γ form an AP: let them be a−d, a, a+d → sum = 3a = −p → a = −p/3 (middle term satisfies original equation). Substitute to get 2p³ − 9pq + 27r = 0.
If α, β, γ form a GP: let them be a/r, a, ar → sum = a(1/r + 1 + r) = −p; product = a³ = −r.

8. Solving Quadratic Equations with Complex Coefficients and Special Problems

When coefficients are complex (not all real), the conjugate root theorem doesn't apply. You solve directly using quadratic formula:
x = (−b ± √(b² − 4ac))/(2a)
where √(b² − 4ac) is evaluated as a complex square root.

Finding square root of a complex number: √(a + bi) = ±(√((|z|+a)/2) + i·sgn(b)√((|z|−a)/2))
This is very useful when you need to simplify nested radicals like √(7 − 24i).

Example: Find √(7 − 24i).
|7 − 24i| = √(49 + 576) = √625 = 25
So √(7 − 24i) = ±(√((25+7)/2) + i·√((25−7)/2)·sign) = ±(√16 − i√9) = ±(4 − 3i)
Verification: (4−3i)² = 16 − 24i + 9i² = 16 − 24i − 9 = 7 − 24i ✓

Common JEE Main problem types:

1. Minimum value of |z| given constraint: Use geometry. E.g., |z − 3 − 4i| ≤ 2 ka minimum |z| = 5 − 2 = 3 (distance from origin to centre minus radius).

2. Maximum value of |z₁ − z₂|: Triangle inequality — maximum is |z₁| + |z₂| when z₁ and z₂ are opposite directions.

3. If |z| = 1, simplify expressions: Use z·z̄ = 1 → z̄ = 1/z. Very useful trick.

4. If z satisfies |z − 1| = 1, find locus of w = z/(z−1): substitute and simplify to find |w − 1| = 1.

5. L'Hôpital-type problems: lim_{z→1} (z^n − 1)/(z − 1) = n for any complex n.

6. Condition for z₁/z₂ to be purely real: arg(z₁) = arg(z₂) (same direction from origin), meaning z₁ × z̄₂ is real.

9. Higher Order Roots of Unity and General Root Problems

nth roots of unity: Solutions of zⁿ = 1. These are e^(2kπi/n) for k = 0, 1, ..., n−1.

In exponential form: zₖ = cis(2kπ/n) = cos(2kπ/n) + i sin(2kπ/n)

These n points form a regular n-sided polygon inscribed in the unit circle, with one vertex at z = 1.

Sum of nth roots of unity = 0 for n ≥ 2. Product = (−1)^(n−1).

nth roots of any complex number w = r·cis(α):
zk = r^(1/n) · cis((α + 2kπ)/n), k = 0, 1, ..., n−1

Special case — square roots of unity: z² = 1 → z = 1, −1.
Square roots of −1: z² = −1 → z = ±i.
Square roots of i: z² = i = cis(π/2) → z = cis(π/4), cis(5π/4) = (±1 ± i)/√2.

Equation zⁿ = aⁿ (a real): roots are a·ωᵏ where ω is nth root of unity, k = 0,...,n−1.

If one root of zⁿ = 1 is ω, then all roots are 1, ω, ω², ..., ω^(n−1).

Very important JEE fact: The product of the non-real nth roots of unity = 1 if n is odd, = −1 if n is even. (Since product of ALL roots = (−1)^(n−1), and 1 is real, remaining product = (−1)^(n−1)/1.)

Solving equations like z⁴ + z³ + z² + z + 1 = 0: Multiply by (z−1) to get z⁵ − 1 = 0, excluding z = 1. Roots are the 5th roots of unity except 1.

10. Exam-Wise High-Yield Topics and Common Mistakes

HIGH-YIELD TOPICS FOR JEE MAIN:

• Modulus-argument form conversions and calculations — nearly guaranteed
• Properties of cube roots of unity (1 + ω + ω² = 0, ω³ = 1) — extremely high yield
• Nature of roots of quadratic equations based on discriminant
• Conditions for common roots of two quadratics
• Finding |z|, arg(z), Re(z), Im(z) from given equations
• Locus problems (circles, lines in complex plane)
• De Moivre's theorem applications (expressing cos3θ, sin3θ)
• Square root of complex numbers
• Minimum/maximum of |z| under constraints
• Equations reducible to quadratic form

COMMON MISTAKES TO AVOID:

• Forgetting that √(−4) = 2i, not 2√(−1) — always simplify to ai form
• Using conjugate root theorem when coefficients are NOT all real — it only applies when ALL coefficients are real
• When dividing complex numbers, forgetting to rationalize — always multiply numerator and denominator by conjugate of denominator
• Confusing arg(z) with tan⁻¹(y/x) — must check quadrant!
• In locus problems, writing |z − z₁| = |z − z₂| as line through z₁ and z₂ — it's the PERPENDICULAR bisector
• Forgetting that z + z̄ = 2Re(z), not just Re(z)
• Applying De Moivre for non-integer exponents without considering multiple values
• Writing |z₁ + z₂| = |z₁| + |z₂| without checking collinearity condition
• Sign errors when expanding (a + bi)² or (a + bi)(a − bi)
• Forgetting that for purely imaginary z = iy, we have z + z̄ = 0 (not 2iy)
• In quadratic equations, confusing sum of roots = −b/a with −b

Important facts

  • z = x + iy, Re(z) = x, Im(z) = y, i = √(−1)
  • |z| = √(x² + y²); |z|² = z·z̄
  • Conjugate: z̄ = x − iy; z + z̄ = 2Re(z); z − z̄ = 2i·Im(z)
  • arg(z) principal value: −π < θ ≤ π; tan⁻¹(y/x) must be adjusted by quadrant
  • Polar form: z = r(cosθ + i sinθ); Euler: z = re^(iθ)
  • De Moivre: (cosθ + i sinθ)ⁿ = cos(nθ) + i sin(nθ)
  • Cube roots of unity: 1, ω = (−1+i√3)/2, ω² = (−1−i√3)/2; 1+ω+ω²=0; ω³=1
  • Quadratic formula: x = (−b ± √(b²−4ac))/(2a); D = b²−4ac
  • Sum of roots = −b/a; Product of roots = c/a
  • If D < 0 for real-coeff quadratic: roots are complex conjugates α±iβ
  • |z₁+z₂| ≤ |z₁|+|z₂| (triangle inequality); equality when same direction
  • nth roots of unity form regular n-gon on unit circle; sum = 0 (n≥2)
  • Common root of ax²+bx+c=0 and a'x²+b'x+c'=0: (b₁c₂−b₂c₁)/(a₁c₂−a₂c₁) = (c₁a₂−c₂a₁)/(a₁b₂−a₂b₁)
  • Both common roots: a₁/a₂ = b₁/b₂ = c₁/c₂
  • √(a+bi) = ±(√((|z|+a)/2) + i·sgn(b)√((|z|−a)/2))

Common mistakes

  • Using conjugate root theorem when coefficients are not all real — it only works for real coefficients
  • Writing √(−4) = 2√(−1) instead of simplifying to 2i
  • Confusing arg(z) with tan⁻¹(y/x) without quadrant correction — must add/subtract π appropriately
  • Forgetting that z + z̄ = 2Re(z), not Re(z)
  • Writing |z₁+z₂| = |z₁|+|z₂| always — equality holds ONLY when z₁, z₂ are in same direction
  • In division of complex numbers, forgetting to multiply numerator and denominator by conjugate of denominator
  • When solving |z−z₁|=|z−z₂|, writing line through z₁ and z₂ instead of perpendicular bisector
  • Applying De Moivre for non-integer exponents without accounting for multiple values
  • Sign error in (a+bi)² expansion — remember i² = −1
  • For cube roots of unity: forgetting 1+ω+ω²=0 and ω³=1 which are used constantly in simplifications
  • Assuming a quadratic with complex coefficients has conjugate roots — this is false
  • In locus problems with |z|, forgetting geometric interpretation as distance from origin
