ભૌતિક વિજ્ઞાન અને માપન — સૂત્ર-શીટ (NEET ભૌતિકી)

NEETGujaratiFormula Sheet
સરેરાશ મૂલ્ય: a_mean = (a_1 + a_2 + ... + a_n) / n

Symbols: a_mean = સાપેક્ષ મૂલ્યોની સરેરાશ; a_1, a_2, ..., a_n = પુનરાવર્તિત માપન મૂલ્યો; n = માપનોની કુલ સંખ્યા

Unit: માપનની એકમ (મીટર, કિલોગ્રામ, સેકન્ડ ইত্যাদિ)

When to use: બહુવિધ માપનોનું સરેરાશ મૂલ્ય શોધવા માટે — ભૂલ ગણતરીની શરૂઆત

Conditions: માપન સાર્થક (correct) હોય; ત્રુટિ સંબંધિત સ્થિર પરિબળો દૂર કરેલા હોય

Common mistake: માપન સંખ્યા n ને ભૂલી જવો અથવા બધા મૂલ્યો ઉમેર્યા પછી n વડે ભાગતા ભૂલવી — ઉદા: (a1+a2)/n ને બદલે (a1+a2+...+an)/n લાગુ પડે

નિરપેક્ષ ભૂલ: Δa_i = | a_mean - a_i |

Symbols: Δa_i = i-માપન માટે નિરપેક્ષ ભૂલ; a_mean = સરેરાશ મૂલ્ય; a_i = i-માં મેળવેલું માપન

Unit: માપનની એકમ (જેમ કે m, kg, s)

When to use: દરેક વ્યક્તિગત માપન તેના સરેરાશથી કેટલું દૂર છે તે માપવા માટે

Conditions: સરેરાશ સही હોય; ચિહ્ન હંમેશા ધન લેવાય (સંપૂર્ણ મૂલ્ય)

Common mistake: ચિહ્ન બિનજરૂરી રાખવું (ધન/ઋણ); નિરપેક્ષ મૂલ્યનું સૂત્ર યાદ ન રહેવું

સરેરાશ નિરપેક્ષ ભૂલ: Δa_mean = (Σ |Δa_i|) / n = (|Δa_1| + |Δa_2| + ... + |Δa_n|) / n

Symbols: Δa_mean = સરેરાશ નિરપેક્ષ ભૂલ; |Δa_i| = દરેક નિરપેક્ષ ભૂલનું મૂલ્ય; n = માપનોની સંખ્યા

Unit: માપનની એકમ

When to use: પ્રાયોગિક માપનમાં સામાન્ય (mean) ભૂલનું પ્રમાણ આપે છે — NEET માં સાચો જવાબ આ સંદર્ભે આવે છે

Conditions: બધા |Δa_i| ધન હોય; n ≥ 1

Common mistake: શ્રેણીકરણમાં ઋણ કિંમતોનો સરવાળો કરી દેવો (ચિહ્ન રાખવું) — અહીં સંપૂર્ણ મૂલ્ય જરૂરી છે; n ને ભૂલી જવો

અનુપાતિક ભૂલ (Relative Error): (Δa_mean) / a_mean

Symbols: Δa_mean = સરેરાશ નિરપેક્ષ ભૂલ; a_mean = સરેરાશ માપન મૂલ્ય

Unit: એકમવિહોણો (dimensionless)

When to use: માપનની ચોકસાઈ જાણવા; અનુપાતિક ભૂલના આધારે ટકાવારી ભૂલ ગણી શકાય

Conditions: a_mean ≠ 0; માપન ધન હોય (NEET પ્રશ્નોમાં સામાન્યતઃ ધન)

Common mistake: અનુપાતિક ભૂલને ટકાવારીમાં ફેરવવા 100 વડે ગુણવા ભૂલવું; a_mean ને શૂન્ય ધારી લેવું

ટકાવારી ભૂલ: % ભૂલ = (Δa_mean / a_mean) × 100%

Symbols: Δa_mean = સરેરાશ નિરપેક્ષ ભૂલ; a_mean = સરેરાશ માપન મૂલ્ય

Unit: ટકા (%) — એકમવિહોણો

When to use: NEET માં સૌથી વધુ પૂછાતી ભૂલ ગણતરી; પ્રાયોગિક પરિણામોની ચોકસાઈ દર્શાવે છે

Conditions: a_mean ≠ 0; પ્રમાણભૂત માપન હોય

Common mistake: 100 વડે ગુણવું ભૂલવું; અનુપાતિક ભૂલ અને ટકાવારી ભૂલને એક જ માનવી; ડેસિમલ સ્થાનોમાં રાઉન્ડિંગ ભૂલ

જોડ/વ્યસ્ત ભૂલ (સરવાળો/અલગ): Z = A ± B → ΔZ = ΔA + ΔB

Symbols: Z = બે ભૌતિક રાશિઓનો સરવાળો અથવા તફાવત; ΔA, ΔB = અનુક્રમે A અને B માં ભૂલ; ΔZ = Z માં કુલ ભૂલ

Unit: માપનની એકમ

When to use: જ્યારે બે ભૌતિક રાશિઓનો સરવાળો/વ્યસ્ત માપવો હોય ત્યારે કુલ ભૂલ શોધવી — ખૂબ જ સીધું અને NEET માં બંધારી

Conditions: A અને B સ્વતંત્ર માપન હોય; ભૂલઓ નાની હોય (રેખીય અંદાજ)

Common mistake: બીજગણિતીય કિંમતોનો ઉપયોગ કરવો (ΔZ = ΔA - ΔB) — ભૂલ હંમેશા મોટામાં મોટી (સરવાળો) લેય; ઋણ ચિહ્નને કારણે ભૂલ ઘટે એવું માનવું

ગુણન/ભાગાકાર ભૂલ: Z = A × B અથવા Z = A / B → ΔZ / Z = (ΔA / A) + (ΔB / B)

Symbols: Z = ગુણિત અથવા ભાગફળ; ΔA/A, ΔB/B = અનુક્રમે A અને B ની અનુપાતિક ભૂલ; ΔZ/Z = Z ની અનુપાતિક ભૂલ

Unit: એકમવિહોણો (અનુપાતિક)

When to use: ગુણાકાર અથવા ભાગાકારથી મળતી રાશિમાં ભૂલ શોધવી; ઉદા: દળ અને ગુરુત્વપ્રવેગના ગુણાકાર F = mg માં

Conditions: A, B ≠ 0; ભૂલઓ નાની

Common mistake: મૂળભૂત ભૂલો (ΔA, ΔB) જોડી દેવી — અહીં અનુપાતિક ભૂલોનો સરવાળો થાય; ગુણન/ભાગ બંને માટે સૂત્ર સમાન છે, તે ભૂલવું

ઘાત/બીજગણિત સંબંધ: Z = A^x B^y / C^z → ΔZ / Z = |x|(ΔA/A) + |y|(ΔB/B) + |z|(ΔC/C)

Symbols: Z = એકબીજા સાથે બંધાયેલી રાશિ; x, y, z = ઘાતો (ધન/ઋણ); ΔA/A, ΔB/B, ΔC/C = અનુક્રમે અનુપાતિક ભૂલો; |x|, |y|, |z| = ઘાતના મૂલ્ય

Unit: એકમવિહોણો

When to use: T = 2π√(l/g) જેવી સૂત્રોમાં સમયગાળામાં ભૂલ; KE = ½mv² માં ઊર્જાની ભૂલ; NEET માં ઘણીવાર પૂછાય છે

Conditions: x, y, z પૂર્ણાંક અથવા ભિન્ન; A, B, C ≠ 0; નાની ભૂલો

Common mistake: ઘાતનું ચિહ્ન ધ્યાનમાં લેવાય પરંતુ નિરપેક્ષ મૂલ્ય લેવાય નહીં; વજન ઓછું લેવું (x, y, z ને છોડી દેવું); સૂત્રને સામાન્ય રાખવાને બદલે સીધું સંખ્યામાં ઉતારવું

મહત્તમ ભૂલ (ઘાત સંબંધમાં): ΔZ = Z × [ |x|(ΔA/A) + |y|(ΔB/B) + |z|(ΔC/C) ]

Symbols: ΔZ = Z માં મહત્તમ ભૂલ; Z = ગણતરી કરેલું મૂલ્ય; x, y, z = ઘાતો; ΔA/A, ΔB/B, ΔC/C = અનુપાતિક ભૂલો

Unit: માપનની એકમ

When to use: જ્યારે પરિણામી રાશિ Z નું સંખ્યાત્મક મૂલ્ય અને તેની ભૂલ બંને ગણવાની હોય — NEET માં સંપૂર્ણ ગણતરી

Conditions: ઉપરના સૂત્રની જ; Z ≠ 0

Common mistake: ΔZ ને સીધું ΔA, ΔB, ΔC તરીકે લખી દેવું; ઘાતોનો ગુણાકાર ભૂલવું; અંતિમ ઉત્તરમાં એકમ ન મૂકવો

મહત્તમ સંભવિત ભૂલ (વપરાયેલા માપન સાધનોની કિંમત): Δl, Δm, Δt વગેરે — સાધનની સૂક્ષ્મતા (least count) દ્વારા

Symbols: Δl = લંબાઈ માપનમાં ભૂલ (સૂક્ષ્મતા); Δm = દળમાં ભૂલ; Δt = સમયમાં ભૂલ

Unit: અનુરૂપ ભૌતિક રાશિની એકમ

When to use: प्रयोगातील साधनाच्या अल्पतम मूल्यावरून भूल काढणे — Vernier caliper, screw gauge, stop-watch ची कमाल भूल NEET मध्ये विचारली जाते

Conditions: साधन चुकीचे नसेल; सूर्यशक्ती (least count) अचूक माहीत असावी

Common mistake: सूर्यशक्ती आणि त्रुटी समजून घेणे; कॅलिपर्सची सूर्यशक्ती (1 MSD - 1 VSD) हाताळताना भूल करणे; स्क्रू गेजमध्ये Pitch / divisions चा वापर करताना गणना चुकवणे

भुजा अंक (Significant Figures) – बेरीज/वजाबाकी: परिणामातील दशांश स्थळांची संख्या = सर्वात कमी दशांश स्थळे असलेल्या संख्येइतकी

Symbols: दशांश स्थळे = decimal places; निकालाची अंदाजे अचूकता

Unit: एककनिर्भर नाही

When to use: 2.11 + 1.2 = 3.3 (1 दशांश स्थळ); NEET मध्ये अंदाजे अंक वापरून उत्तर ठरवणे

Conditions: फक्त बेरीज/वजाबाकी; गुणाकार/भागाकार नाही

Common mistake: गुणाकारासाठी हे नियम लागू करणे; दशांश स्थळे गणताना मूळ संख्येतील सर्व अंक गृहीत धरणे

भुजा अंक – गुणाकार/भाग: परिणामातील सार्थक अंकांची संख्या = सर्वात कमी सार्थक अंक असलेल्या संख्येइतकी

Symbols: सार्थक अंक = significant figures; निकालाची गुणात्मक अचूकता

Unit: एककनिर्भर नाही

When to use: 3.2 (2 सार्थक) × 4.56 (3 सार्थक) = 15 (2 सार्थक); NEET मध्ये गणना आणि उत्तर पर्याय ठरवण्यासाठी

Conditions: फक्त गुणाकार/भाग; बेरीज/वजाबाकी नाही

Common mistake: दोन्ही नियम उलटे वापरणे; शून्ये (उदा. 100, 0.001) ची महत्त्वाची भूमिका विसरणे

आयामी सूत्र (Dimensional Formula): [M^a L^b T^c] — प्रत्येक भौतिक राशीचे मासे, लांबी आणि काल यांच्या पटटीत प्रतिनिधित्व

Symbols: M = वस्तुमान (mass); L = लांबी (length); T = काल (time); a, b, c = घातांक

Unit: एककनिर्भर नाही (आयामी सूत्र)

When to use: सूत्रांची सार्थकता तपासणे; नवीन संबंध मिळवणे; एकक रूपांतरण; NEET मध्ये वारंवार विचारले जाते

Conditions: समीकरणाची दोन्ही बाजू समान आयामी असल्या पाहिजेत; फक्त बेरीज/वजाबाकी समान आयामी राशींसाठी

Common mistake: कोन, स्THRİ (strain), टक्केवारी यांना [M^0 L^0 T^0] समजून चूक करणे; आयामी सूत्रांची पडताळणी करताना दावे (assertion) आणि कारण (reason) वेगळे करणे

आयामी स्थिरांक: [M^a L^b T^c] – उदा. G → [M⁻¹ L³ T⁻²]; h (Planck) → [M¹ L² T⁻¹]; ε₀ → [M⁻¹ L⁻³ T⁴ A²]

Symbols: G = गुरुत्वीय स्थिरांक; h = प्लांक स्थिरांक; ε₀ = मुक्त अवकाशाची विद्युतशीलता; M, L, T = मूलभूत आयाम

Unit: आयामी सूत्रानुसार

When to use: NEET मध्ये वारंवार स्थिरांकांची आयामी सूत्रे विचारली जातात; सूत्र सिद्ध करण्यासाठी आधार

Conditions: प्रत्येक स्थिरांकाचे आयामी सूत्र आत्मसात करणे आवश्यक

Common mistake: घातांक चिन्हे उलटी करणे (विशेषतः ऋण घातांक); A (विद्युतप्रवाह) आणि I चा वापर करताना गोंधळ

SI मूलभूत एकके (7): लांबी — मीटर (m); वस्तुमान — किलोग्राम (kg); काल — सेकंद (s); विद्युतप्रवाह — एम्पिअर (A); तापमान — केल्विन (K); पदार्थाचे प्रमाण — मोल (mol); ज्यातिष तीव्रता — कॅन्डेला (cd)

Symbols: m, kg, s, A, K, mol, cd — SI पद्धतीतील 7 मूलभूत एकके

Unit: प्रत्येकाची स्वतंत्र एकके

When to use: NEET मध्ये moulkabhut ikaka chi yaadashan; derived units che construction yahe varshakunte yetatat

Conditions: SI पद्धत 2019 च्या पुनर्संकलनानंतरही ही 7 एकके मूलभूत आहेत

Common mistake: नवे एकके (जसे की kelvin ऐवजी celsius) टाकणे; मोल (mol) ला 'रेणू' किंवा 'अणू' समजणे — मोल हे 6.022×10²³ कणे यांचा समूह आहे

प्रायोगिक त्रुटींचे प्रकार: यादृच्छिक (Random) vs नियतात्मक (Systematic)

Symbols: यादृच्छिक = अनियमित, वारंवार बदलणारी; नियतात्मक = स्थिर दिशा/प्रमाणात

Unit: ——

When to use: NEET मध्ये 'त्रुटींचे वर्गीकरण' विषयक प्रश्न येतात — चिन्हाची दिशा, कमी-जास्त होणे इ.

Conditions: नियतात्मक त्रुटी: उपकरणात दोष, पद्धत दೋष, पर्यावरणीय बदल; यादृच्छिक: वाचन त्रुटी, अस्थिर परिस्थिती

Common mistake: दोन्ही प्रकारची उदाहरणे उलटी मानणे; नियतात्मक त्रुटी बरोबर केलेली सुधारणा करता येते हे गृहीत धरणे

त्रुटी-मुक्त मोजमाप शक्य नाही: 'प्रत्येक मोजमापात काही तरी त्रुटी असते' — हे भौतिकशास्त्राचे मूलभूत तत्त्व

Symbols: त्रुटी =measurement uncertainty; मोजमाप =experimental reading

When to use: NEET मध्ये सत्यास (Assertion) चे प्रश्न — 'त्रुटी शून्य असू शकते का?' यावर आधारित

Conditions: सैद्धांतिक आणि प्रायोगिक दोन्ही मर्यादा

Common mistake: 'शून्य त्रुटी' शक्य आहे असे मानणे; त्रुटी आणि त्रुटीची क्रियाभूमी (error analysis) यातील फरक न समजणे

आयामी विश्लेषणाचा उपयोग: (1) समीकरणाची सार्थकता तपासणे (2) नवीन संबंध मिळवणे (3) एकक रूपांतरण

Symbols: आयामी = dimensional; विश्लेषण = analysis; उपयोग = application

Unit: ——

When to use: NEET मध्ये वारंवार 'आयामी विश्लेषण कोणत्या गोष्टींसाठी वापरता येत नाही?' असे प्रश्न — उदा. t = 2π√(l/g) चा संबंध आयामीकरणावरून मिळवता येतो, पण त्रिकोणमितीय फलने (sin θ) यासाठी नाही

Conditions: आयामी विश्लेषण फक्त गुणाकार/भाग संबंधांसाठी कार्यक्षम; बेरीज/वजाबाकीच्या स्थिरांकांसाठी नाही

Common mistake: त्रिकोणमितीय, एक्सपोनन्शियल, लॉगरिदमिक पदे यांचे आयामी सूत्र लिहिण्याचा प्रयत्न करणे — ही पदे आयामीरहित (dimensionless) असतात; आयामी विश्लेषणाने पूर्ण सूत्र मिळत नाही हे विसरणे
