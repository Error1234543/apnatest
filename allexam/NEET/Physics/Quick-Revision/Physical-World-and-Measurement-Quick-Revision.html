ભૌતિક વિશ્વ અને માપન — ઝડપી પુનરાવર્તન (NEET Physics)

NEETGujaratiQuick Revision

Definitions

  • માપન (Measurement): કોઈ પણ ભૌતિક રાશિનું એકમથી સરખાણ કરીને જોવાની પ્રક્રિયા; પરિણામ = પૂર્ણાંક મૂલ્ય × એકમ.
  • ભૌતિક રાશિ (Physical Quantity): જે રાશિનું માપન કરી શકાય તેવી; બે પ્રકાર — મૂળભૂત (fundamental) અને વ્યુત્પન્ન (derived).
  • મૂળભૂત રાશિઓ (Fundamental Quantities): આઠ આધારભૂત; લંબાઈ, દળ, કાળ, વિદ્યુત પ્રવાહ, તાપમાન, પ્રકાશ તીવ્રતા, પદાર્થનો દ્રવ્યમાન, અને કોણ.
  • વ્યુત્પન્ન રાશિ (Derived Quantity): મૂળભૂત રાશિઓના ગુણાકાર/ભાગાકારથી મેળવવામાં આવતી; ઉદા: પ્રવેગ (m s⁻²), બળ (kg m s⁻² = N), કામ (N m = J).
  • સીમાન્ત પ્રશ્નક્રમ (Precision): માપન સાધનની ન્યૂનતમ માપી શકાય તેવી લંબાઈ (least count); ઓછું least count = વધુ precision.
  • પ્રમાણિતતા (Accuracy): માપેલ મૂલ્ય અને સત્ય મૂલ્ય (true value) વચ્ચેના સામીપ્યની માપ;
  • ત્રુટિ (Error): માપેલ મૂલ્ય અને સત્ય મૂલ્ય વચ્ચેનો તફાવત; બે પ્રકાર — systematic (ક્રમબદ્ધ) અને random (યાદચ્છિક).
  • સાર્થક અંક (Significant Figures): માપનમાં વિશ્વસનીય રીતે જાણીતા અંકો + પહેલો અનિશ્ચિત અંક;
  • પરિમાણ વિશ્લેષણ (Dimensional Analysis): ભૌતિક રાશિઓને M (દળ), L (લંબાઈ), T (કાળ), I (વિદ્યુત પ્રવાહ) વગેરે પરિમાણોમાં દર્શાવવી.

Key concepts

  • ભૌતિક વિજ્ઞાનની શાખાઓ: યાંત્રિકી (Mechanics), ઊર્મિ (Waves), તાપવિજ્ઞાન (Thermodynamics), વિદ્યુતચુંબકત્વ (Electromagnetism), પ્રકાશવિજ્ઞાન (Optics), આધુનિક ભૌતિક (Modern Physics). NEET માં Mechanic, Thermodynamics, EMI, Optics, Modern Physics સૌથી વધુ જોવા મળે છે.
  • SI એકમોની યાદી (મૂળભૂત): લંબાઈ → મીટર (m), દળ → કિલોગ્રામ (kg), કાળ → સેકન્ડ (s), વિદ્યુત પ્રવાહ → એમ્પિયર (A), તાપમાન → કેલ્વિન (K), પ્રકાશ તીવ્રતા → કેન્ડેલા (cd), પદાર્થનો દ્રવ્યમાન → મોલ (mol).
  • મહત્વપૂર્ણ વ્યુત્પન્ન એકમો: બળ → ન્યૂટન (N = kg m s⁻²), કામ/ઊર્જા → જૂલ (J = N m), પાવર → વોટ (W = J s⁻¹), દબાણ → પાસ્કલ (Pa = N m⁻²), आव्हान → ohm (Ω = V A⁻¹), ક્ષેત્રફળ → m², ઘનફળ → m³.
  • ત્રુટિના પ્રકારો: systematic — (a) સાધન ભૂલ (instrumental), (b) પદ્ધતિ ભૂલ (method), (c) નિરીક્ષક ભૂલ (personal); random — બહુવિધ માપનમાં થતી ફરફરિયું ભૂલ; absolute error = |true − measured|; relative error = absolute/error_true; percentage error = relative × 100%.
  • સાર્થક અંકના નિયમો: (1) શૂન્ય ન હોય તેવા અંકો હંમેશા સાર્થક; (2) બે non-zero અંકો વચ્ચેના શૂન્યો સાર્થક; (3) શૂન્યથી શરૂ થતા દશાંશમાં પ્રથમ non-zero પહેલાંના શૂન્યો અસાર્થક; (4) દશાંશ ચિહ્ન ધરાવતી સંખ્યામાં છેલ્લે આવેલો શૂન્ય સાર્થક; (5) શુદ્ધ સંખ્યાઓ અસાર્થક.
  • સાર્થક અંક સાથેની ગણતરી: (1) સરવાળો/બાદબાકી → દશાંશ બિંદુ પછીના અંકોની સંખ્યામાં સૌથી ઓછી સંખ્યા તેટલા જ રાખવા; (2) ગુણાકાર/ભાગાકાર → સાર્થક અંકોની સંખ્યામાં સૌથી ઓછી તેટલા જ રાખવા; (3) intermediate steps માં વધારાના અંકો રાખી, છેલ્લે round-off કરવો.
  • પરિમાણ નિરૂપણ (Dimensional Formula): દરેક રાશિ = [M^a L^b T^c I^d ...]. ઉદા: ઝડપ → [M⁰ L¹ T⁻¹], પ્રવેગ → [M⁰ L¹ T⁻²], બળ → [M¹ L¹ T⁻²], કામ → [M¹ L² T⁻²], દબાણ → [M¹ L⁻¹ T⁻²], વિદ્યુતભાર → [I¹ T¹], વોટ → [M¹ L² T⁻³].
  • પરિમાણ સમાનતાનો સિદ્ધાંત: બંને બાજુ પરિમાણો સમાન હોય તો સમીકરણ પરિમાણીય રીતે સાચું; વધુમાં, એ જ પ્રકારની રાશિઓનો સરવાળો/બાદબાકી શક્ય છે. આનો ઉપયોગ: (1) સમીકરણની તપાસ, (2) એકમ રૂપાંતર, (3) એક રાશિ માટે સૂત્ર મેળવવા.
  • NEET માં ખાસ મહત્વની વસ્તુઓ: (1) SI એકમોનું સ્મરણ અને વ્યુત્પન્ન એકમોના પરિમાણ, (2) સાર્થક અંકોની ગણતરી, (3) ત્રુટિ પ્રસરણ (Δz = Δx ± Δy, Δz/z = Δx/x ± Δy/y, power rule: z = x^a y^b → Δz/z = a·Δx/x + b·Δy/y), (4) કોઈ પણ આપેલ સમીકરણનું પરિમાણીય તૃપ્તિકરણ.
  • પરિમાણહીન રાશિઓ (Dimensionless): કોણ (radian), વક્રતા ત્રિજ્યાનો ગુણોત્તર, સાપેક્ષ ઘનતા, સ્નિગ્ધતા ગુણાંકનો પરિમાણ નથી (η = F·d/(A·v) → [ML⁻¹T⁻¹]).

Important facts

  • SI પદ્ધતિ 1960માં બનાવવામાં આવી; 7 મૂળભૂત રાશિઓ. 2019માં પુનઃવ્યાખ્યા થઈ: સેકન્ડ → સિઝિયમ આવર્તન, મીટર → પ્રકાશની ઝડપ, કિલોગ્રામ → પ્લાન્ક સ્થિરાંક, એમ્પિયર → મૂળભૂત વિદ્યુતભાર, કેલ્વિન → બોલ્ટ્ઝમેન સ્થિરાંક, મોલ → એવોગેડ્રો સંખ્યા, કેન્ડેલા → પ્રકાશીય તીવ્રતા.
  • SI એકમોનું મૂળભૂત સમૂહ: m, kg, s, A, K, mol, cd. યાદ રાખવાનું: 'મારે કલાકે આગ કોળી લાગી' (મીટર, કિલોગ્રામ, સેકન્ડ, એમ્પિયર, કેલ્વિન, મોલ, કેન્ડેલા).
  • લંબાઈના એકમો: 1 fermi = 10⁻¹⁵ m, 1 Å = 10⁻¹⁰ m, 1 nm = 10⁻⁹ m, 1 µm = 10⁻⁶ m, 1 light-year = 9.46×10¹⁵ m, 1 astronomical unit ≈ 1.5×10¹¹ m.
  • દળના એકમો: 1 amu = 1.66×10⁻²⁷ kg, 1 quilogram (q) = 10⁻³ kg, 1 metric tonne = 1000 kg.
  • કાળના એકમો: 1 year ≈ 3.156×10⁷ s, 1 day = 86400 s, 1 hour = 3600 s.
  • ઋણાત્મક નિરક્ષરતા (Negative marking): NEET માં દરેક ખોટા જવાબ પર −1 અંક; ચોક્કસ જવાબ +4 અંક. તેથી 'જાણતો' પ્રશ્ન જ ચકાસવો.
  • પરિમાણ સમીકરણની તપાસ: જો ડાબી બાજુનો પરિમાણ ≠ જમણી બાજુનો પરિમાણ, તો સમીકરણ ખોટું. પરંતુ પરિમાણો સમાન હોય તો સમીકરણ સત્ય હોય જ એમ નથી (ઉદા: v = u + at [સાચું], v² = u² + 2as [સાચું]; સ્થાનાંતર = vt [પરિમાણીય રીતે સાચું પરંતુ ગતિ વિજ્ઞાનની દૃષ્ટિએ ખોટું જો constant velocity ન હોય]).
  • સાર્થક અંકો વધારવાની રીત: દશાંશ યુક્ત સંખ્યાના છેલ્લે શૂન્ય ઉમેરવું (ઉદા: 2.00 → 3 significant figures).
  • NEETમાં 'Physical World and Measurement' માં 1-2 પ્રશ્ન સીધા આવે છે; વધુ 3-5 પ્રશ્ન ગતિ, બળ, ઊર્જા, તරંગો વગેરેમાં પરિમાણ/એકમ/સાર્થક અંકના સ્વરૂપે આવે છે.

Memory aids

  • મૂળભૂત રાશિઓનું મંત્ર: 'મારે કલાકે આગ કોળી લાગી' → મીટર(m), કિલોગ્રામ(kg), સેકન્ડ(s), એમ્પિયર(A), કેલ્વિન(K), મોલ(mol), કેન્ડેલા(cd).
  • સાર્થક અંકના નિયમનું સૂત્ર: 'non-zero હંમેશા, વચ્ચેનું શૂન્ય હંમેશા, શરૂઆતનું શૂન્ય નહીં, છેલ્લેનું શૂન્ય (દશાંશ હોય તો) હંમેશા'.
  • પરિમાણીય સમાનતાનો નિયમ: 'જે રાશિનો પરિમાણ સમાન, તે જ રાશિ; જેનો અલગ, તે અલગ.' દરેક સમીકરણના બંને પાસાંનું પરિમાણ સાચું હોવું જોઈએ.
  • ત્રુટિ પ્રસરણનું સૂત્ર: z = x ± y → Δz = Δx + Δy; z = xy → Δz/z = Δx/x + Δy/y; z = x/y → Δz/z = Δx/x + Δy/y; z = xⁿ → Δz/z = n·Δx/x.

Exam tips

  • NEETમાં Physical World and Measurement સીધા 1-2 પ્રશ્ન અને અન્ય 3-5 પ્રશ્ન વ્યુત્પન્ન સ્વરૂપે આવે છે; ઝડપથી single-step numericals અને unit conversion ટ્રેન કરો.
  • સમીકરણના પરિમાણીય તૃપ્તિકરણ માટે: દરેક પદનો પરિમાણ નીકાળો, બાદબાકી/સરવાળા માટે પરિમાણો સમાન હોવા જોઈએ, गुणाકાર/ભાગાકાર માટે પરિમાણોનો ગુણાકાર/ભાગાકાર કરો.
  • સાર્થક અંકોની ગણતરીમાં હંમેશા intermediate valuesમાં 1-2 વધારાના અંકો રાખો, final answer માં જ round-off કરો; એમ કરવું from round-off errors.
  • NEETમાં dimensional formula યાદ રાખવાનાં મહત્વનાં: [MLT⁻²] = force, [ML²T⁻²] = energy/work/torque, [ML⁻¹T⁻²] = pressure/stress, [M L⁰ T⁰] = mass, [M⁰ L¹ T⁰] = length.
  • Errors પ્રકરણમાં percentage error ની ગણતરી માટે: relative error × 100; multiple quantities માટે Δz/z = Δx/x + Δy/y (addition/subtraction માટે absolute errorsનો સરવાળો, multiplication/division માટે relative errorsનો સરવાળો).
  • Screw gauge નું pitch = smallest distance moved by thimble in one full rotation; least count = pitch / number of divisions on circular scale. NEETમાં screw gauge ના numericals સામાન્ય છે.
  • Vernier caliper: 1 MSD = main scale division; 1 VSD = (n−1)/n MSD; least count = 1 MSD − 1 VSD = 1/n MSD. NEETમાં vernier caliper + screw gauge એકસાથે પણ આવે છે.

Common traps

  • બળ (Force) અને દળ (Mass) અલગ છે: બળ = mass × acceleration, એકમ N; દળ = kg. NEETમાં એકમો બદલીને ચાકરી કરે છે.
  • ત્રુટિ (Error) હંમેશા ધન બને; absolute error = |measured − true|. ઋણાત્મક જવાબ સામાન્ય રીતે ખોટો.
  • સાર્થક અંકોની ગણતરીમાં add/subtract vs multiply/divide અલગ-અલગ નિયમ; વિદ્યાર્થીઓ ઘણીવાર બંનેમાં multiply/divide નો નિયમ લાગુ પાડે છે.
  • પરિમાણ સમાન હોય તો સમીકરણ હંમેશા ભૌતિક રીતે સાચું નથી; પરિમાણ વિરુદ્ધ હોય તો હંમેશા ખોટું. આ nuance NEETમાં જરા ઊંડાણથી પૂછાય છે.
  • કોણ (angle) અને ક્ષેત્રફળ (area) બંનેનો પરિમાણ [M⁰L²T⁰] છે, પરંતુ કોણ પરિમાણહીન છે અને area નહીં; કોણ એ dimensionless quantity.
  • Least count = main scale division / total divisions on vernier; NEETમાં ઘણીવાર vernier calipers/screw gauge નું least count શોધવાનું આવે છે.
  • Significant figures માં round-off: 5 પછીનો અંક ≥ 5 હોય તો round-up, < 5 હોય તો round-down; પરંતુ exact 5 હોય તો preceding digit even → round-up, odd → round-down (bankers rounding — NEETમાં ઓછું પૂછાય પણ આવી તકનીકી જાણીતી હોવી જોઈએ).
