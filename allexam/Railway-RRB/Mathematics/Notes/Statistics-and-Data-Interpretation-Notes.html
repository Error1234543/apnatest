सांख्यिकी का परिचय एवं महत्व

सांख्यिकी (Statistics) आँकड़ों के संग्रह, व्यवस्थित करने, विश्लेषण और निष्कर्ष निकालने की विज्ञान शाखा है। RRB परीक्षाओं में Statistics & Data Interpretation से प्रति वर्ष लगभग 2–4 प्रश्न पूछे जाते हैं, जो मुख्यतः औसत, मध्यक, प्रचुरक, प्रसरण, मानक विचलन और डेटा इंटरप्रिटेशन (तालिका, खंड चार्ट, पाई चार्ट, रेखा आलेख) से संबंधित होते हैं।

परिभाषाएँ:
- आँकड़ा (Data): किसी भी माप या गिनती से प्राप्त संख्यात्मक जानकारी।
- सांख्यिकीय जनांक (Population): पूर्ण समूह जिसके सभी अवयव अध्ययन के対象 हैं।
- प्रतिदर्श (Sample): जनसंख्या का एक प्रतिनिधि भाग।
- चर (Variable): ऐसा गुण जो मानों में बदलाव दिखाए।
- अपरिवर्तनीय चर (Constant): जिसका मान नहीं बदलता।

आँकड़ों के प्रकार:
- प्राथमिक आँकड़े: स्वयं जुटाए गए (survey, experiment)।
- द्वादुतीयक आँकड़े: पहले से उपलब्ध स्रोतों से लिए गए।
- गुणात्मक (Qualitative): वर्गीय/गुणवाची (रंग, लिंग)।
- परिमाणात्मक (Quantitative): संख्यात्मक (ऊँचाई, आयु, वेतन)।

RRB के संदर्भ में महत्वपूर्ण:
- अक्सर प्रश्न कार्यरत कर्मचारियों की आयु, वेतन, या उपस्थिति आदि के संदर्भ में दिए जाते हैं, जिन्हें या तो तालिका या आलेख के रूप में दिया जाता है।

माध्य (Mean) — सरल एवं भारित

माध्य (औसत) किसी दिए गए आँकड़ों के योग को उनके क्रम के बराबर भाग देने पर प्राप्त होता है।

सूत्र:
- सरल माध्य: X̄ = Σxᵢ / n
जहाँ xᵢ प्रत्येक मान है और n कुल पदों की संख्या है।
- भारित माध्य: X̄w = Σ(wᵢ × xᵢ) / Σwᵢ
जहाँ wᵢ वह भार (frequency) है जो प्रत्येक मान को प्राप्त है।

विधियाँ:
1. सीधा विधि (Direct Method): सभी मानों को जोड़कर n से भाग दें।
2. अपसारी विधि (Assumed Mean Method):
- एक अनुमानित माध्य A चुनें।
- dᵢ = xᵢ − A निकालें।
- X̄ = A + (Σdᵢ / n)
3. गुणनखंड विधि (Step-deviation Method):
- dᵢ = xᵢ − A, c = समान अंतर (common difference)
- uᵢ = dᵢ / c
- X̄ = A + c × (Σfᵢuᵢ / Σfᵢ)

उदाहरण: यदि 5 संख्याओं का माध्य 20 है, तो उनका योग = 5 × 20 = 100। यदि एक संख्या 12 हटा दी जाए, तो नया माध्य = (100 − 12) / 4 = 22।

भारित माध्य का उपयोग तब होता है जब प्रत्येक मान की आवृत्ति अलग-अलग हो, जैसे कई कक्षाओं में औसत अंक निकालना जहाँ प्रति कक्षा छात्रों की संख्या भिन्न हो।

मध्यक (Median)

मध्यक वह मान है जो क्रमित (अरोही या आरोही) आँकड़ों को ठीक दो बराबर भागों में बाँटता है।

अनियमित आँकड़ों के लिए:
- यदि n विषम है: M = ((n+1)/2)वाँ पद
- यदि n सम है: M = [(n/2)वाँ पद + (n/2 + 1)वाँ पद] / 2

समीकृत आवृत्ति बंटन (Grouped Frequency Distribution) के लिए मध्यक सूत्र:
- M = l + [(N/2 − C.F.) / f] × h
जहाँ:
l = मध्यक संपर्क class की निम्न सीमा
N = कुल आवृत्ति (Σfᵢ)
C.F. = मध्यक class से ठीक पहले वाली class का संचयी आवृत्ति (cumulative frequency)
f = मध्यक संपर्क class की आवृत्ति
h = class अंतराल की चौड़ाई

मध्यक class कैसे पहचानें?
- पहले संचयी आवृत्ति सারণी बनाएँ।
- N/2 वाला मान ढँढें; जो class इससे ऊपर पहली बार आए, वही मध्यक class होगी।

उदाहरण: यदि कुल 50 अवलोकन हैं, तो N/2 = 25। जिस class की संचयी आवृत्ति पहली बार ≥ 25 हो, उसी को मध्यक class मानेंगे।

RRB परीक्षा में मध्यक अक्सर 'दिए गए आँकड़ों का मध्यक ज्ञात कीजिए' प्रकार के सीधे प्रश्नों में आता है; कभी-कभी समीकरण रखकर अज्ञात frequency या class width भी पूछी जाती है।

प्रचुरक (Mode)

प्रचुरक वह मान है जिसकी आवृत्ति सबसे अधिक हो।

समीकृत आवृत्ति बंटन के लिए प्रचुरक सूत्र:
- Mo = l + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h
जहाँ:
l = प्रचुरक class की निम्न सीमा
f₁ = प्रचुरक class की आवृत्ति
f₀ = प्रचुरक class से ठीक पहले class की आवृत्ति
f₂ = प्रचुरक class से ठीक बाद class की आवृत्ति
h = class अंतराल की चौड़ाई

प्रचुरक class: सबसे अधिक f वाली class।

उदाहरण: यदि class intervals 0–10 (f=8), 10–20 (f=12), 20–30 (f=18), 30–40 (f=14) हैं, तो प्रचुरक class 20–30 है क्योंकि f=18 सर्वोच्च है।

ध्यान दें: प्रचुरक हमेशा एक ही नहीं हो सकता; दोहरे या बहु-प्रचुरक (bimodal/multimodal) भी संभव हैं। RRB में आमतौर पर एकाधिक प्रचुरक नहीं पूछा जाता, किंतु अवधारणा स्पष्ट रखें।

मध्यक-प्रचुरक-माध्य संबंध एवं अन्य माप

मध्यक, प्रचुरक और माध्य में एक प्रयोगिक संबंध होता है:
- प्रचुरक ≈ 3 × मध्यक − 2 × माध्य
यह तब लागू होता है जब बंटन लगभग सममित न हो।

अन्य महत्वपूर्ण माप:
- परास (Range) = अधिकतम मान − न्यूनतम मान
- चरण विचलन (Mean Deviation):
* SD模式下: MD = Σ|xᵢ − X̄| / n
* Grouped: MD = Σfᵢ|xᵢ − X̄| / Σfᵢ
- प्रसरण (Variance) σ²:
* Ungrouped: σ² = Σ(xᵢ − X̄)² / n
* Shortcut: σ² = Σxᵢ²/n − (Σxᵢ/n)²
* Grouped: σ² = Σfᵢ(xᵢ − X̄)² / Σfᵢ
- मानक विचलन (Standard Deviation) σ = √(variance)

RRB परीक्षा में अक्सर माध्य, मध्यक, प्रचुरक में से कोई एक ज्ञात हो तो अन्य दो निकालने वाले या सरल Range/SD वाले प्रश्न आते हैं। प्रसरण/SD सूत्र याद रखें; परीक्षा में shortcut-formula (σ² = Σx²/n − mean²) अक्सर गणना तेज करता है।

संभावना (Probability) — प्रारंभिक अवधारणाएँ

संभावना एक घटना के होने की प्रवृत्ति का सांख्यिकीय माप है, जिसका मान 0 से 1 के बीच होता है।

मूल सूत्र:
P(E) = Favorable outcomes / Total possible outcomes

महत्वपूर्ण नियम:
- P(E) + P(E') = 1, जहाँ E' पूरक घटना है।
- असंभव घटना: P = 0; निश्चित घटना: P = 1。
- स्वतंत्र घटनाएँ: P(A∩B) = P(A)×P(B)
- युक्त घटनाएँ: P(A∪B) = P(A)+P(B)−P(A∩B)

RRB स्तर के लिए आवश्यक:
- सिक्का, पासा, कार्ड आदि के मानक प्रश्न (एक सिक्का उछालने पर हेड आने की प्रायिकता = 1/2)。
- ट्रेन की समय सারণी या स्टेशन पर यात्रियों के आँकड़ों से संबंधित संभावना प्रश्न कभी-कभार आते हैं; ये सामान्य तर्क पर आधारित होते हैं।
- संयोजन-क्रमबद्ध (Permutation-Combination) की मूलभूत अवधारणाएं (nCr, nPr) तभी जरूरी हैं जब प्रश्न इस स्तर का हो, किंतु RRB में ज्यादातर सरल प्रायिकता आती है।

संख्या पद्धति एवं बारंग्राफ, पाई चार्ट, रेखा आलेख — प्रस्तुति

Data Representation (डेटा निरूपण) में हम आँकड़ों को तालिका, चित्र या आलेख के रूप में रखते हैं ताकि विश्लेषण सरल हो जाए।

तालिका (Table):
- सरल तालिका: एक चर का अनेक मान।
- द्विचर तालिका: दो चरों के बीच संबंध।
- त्रिचर तालिका: तीन चरों का मिश्रण।
- RRB में 'वर्षवार उपस्थिति/वेतन/लागत' की तालिकाएं आम हैं।

खंड चार्ट (Bar Graph):
- प्रत्येक श्रेणी का मान ऊँचाई वाले खंड से दिखता है।
- तुलनात्मक अध्ययन के लिए उपयोगी।
- Compound Bar Chart में समूहों के अंदर उप-समूह भी दिखाए जा सकते हैं।

पाई चार्ट (Pie Chart):
- वृत्त के केंद्र के चारों ओर खंड; प्रत्येक खंड का केंद्रीय कोण = (अंश / कुल) × 360°
- प्रतिशत का आलेखीय निरूपण इसमें स्पष्ट होता है।

रेखा आलेख (Line Graph):
- समय के साथ परिवर्तन दिखाता है।
- trend (प्रवृत्ति), वृद्धि-ह्रास और compare करना आसान होता है।

पठन कौशल:
- पाई चार्ट में कोण → अंश ज्ञात करने के लिए proportion लगाएँ;
- Bar graph में 'कुल बढ़ोतरी/घटाव' देखें;
- तालिका में 'fill in the blank' (गुम हुए मान) वाले प्रश्न अक्सर आते हैं, जहाँ माध्य/योग की शर्त से अज्ञात मान निकालते हैं।

डेटा इंटरप्रिटेशन — प्रकार एवं हल करने की विधियाँ

डेटा इंटरप्रिटेशन का अर्थ है दिए गए चार्ट/तालिका से प्रश्नोत्तर बनाना। RRB में अधिकांश प्रश्न इसी श्रेणी में आते हैं।

मुख्य प्रकार:
1. तालिका आधारित प्रश्न:
- दी गई तालिका के मानों को पढ़कर योग, अंतर, औसत, प्रतिशत, अनुपात निकालें।
- अक्सर एक column का मान 'fill in the blanks' के रूप में ढूंढना होता है।

2. खंड चार्ट आधारित:
- दो या अधिक वर्षों की तुलना, वृद्धि/ह्रास %, औसत, अनुपात।

3. पाई चार्ट आधारित:
- किसी खंड के केंद्रीय कोण से प्रश्न।
- दूसरे चार्ट के साथ merge करके combined प्रश्न भी आ सकते हैं।

4. रेखा आलेख आधारित:
- समय क्रम में trend पहचानें; growth rate, average, ratio निकालें।

5. Mixed DI (मिश्रित):
- एक तालिका + एक पाई चार्ट या बार ग्राथ + तालिका सहित प्रश्न समूह।

सामान्य हल-कौशल:
- पहले प्रश्न पढ़ें, फिर डेटा में देखें; 'क्या पूछा गया है' स्पष्ट करें।
- प्रतिशत निकालते समय base ध्यान से पहचानें।
- औसत निकालते समय सभी संदर्भित पंक्तियों/ कॉलम का योग याद रखें।
- approximation (लगभग गणना) का उपयोग तभी करें जब विकल्प दूर-दूर हों; otherwise exact calculation करें।
- त्रुटि से बचें: class interval, unit conversion (किलो/मेगा), base year vs current year को उल्टा न देखें।

Important facts

  • रेलवे परीक्षाओं (NTPC, Group D, ALP, etc.) में Mathematics के Statistics & DI से प्रति वर्ष लगभग 2–4 प्रश्न आते हैं।
  • माध्य = कुल योग ÷ कुल संख्या; भारित माध्य = Σ(वजन×मान) ÷ Σ(वजन)।
  • मध्यक class = वह class जिसकी संचामी आवृत्ति N/2 से पहली बार ऊपर पहुँचे।
  • प्रचुरक class = सबसे अधिक आवृत्ति वाली class; प्रचुरक सूत्र में f₁, f₀, f₂ का क्रम सावधानी से रखें।
  • प्रचुरक ≈ 3 मध्यक − 2 माध्य (asymmetric distribution के लिए empirical relation)।
  • पाई चार्ट में केंद्रीय कोण = (भाग/कुल) × 360°; प्रतिशत → कोण तथा कोण → प्रतिशत दोनों दिशा में convert कर सकते हैं।
  • मानक विचलन = √प्रसरण; प्रसरण shortcut सूत्र: σ² = (Σx²/n) − (mean)²।
  • Data Interpretation में base value (वर्ष/श्रेणी) सावधानी से पढ़ें; प्रतिशत वृद्धि/ह्रास के प्रश्नों में यह सबसे बड़ी त्रुटि का कारण बनता है।
  • संभावना का मान हमेशा 0 ≤ P ≤ 1 होता है; पूरक घटना का योग 1 होता है।
  • बार ग्राफ में ऊँचाई ∝ मान; रेखा आलेख trend समय-अनुसार दिखाता है; पाई चार्ट भाग-संबंध स्पष्ट करता है।

Formulas and relationships

X̄ = Σxᵢ / n (Simple Mean)
X̄w = Σ(wᵢ·xᵢ) / Σwᵢ (Weighted Mean)
X̄ = A + Σdᵢ/n (Assumed Mean Method)
X̄ = A + c·(Σfᵢuᵢ/Σfᵢ) (Step-deviation Method)
M = l + [(N/2 − C.F.) / f] × h (Median for grouped data)
Mo = l + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h (Mode for grouped data)
Range = Maximum − Minimum
MD = Σ|xᵢ − X̄| / n (Mean Deviation, ungrouped)
σ² = Σ(xᵢ − X̄)² / n (Variance, ungrouped)
σ² = Σfᵢ(xᵢ − X̄)² / Σfᵢ (Variance, grouped)
σ² = (Σxᵢ²/n) − (X̄)² (Shortcut formula for variance)
σ = √σ² (Standard Deviation)
P(E) = Favorable outcomes / Total outcomes (Basic Probability)
P(A∪B) = P(A) + P(B) − P(A∩B) (Addition Rule)
P(A∩B) = P(A)·P(B) (Independent events)
Central angle = (part/total) × 360° (Pie chart conversion)
