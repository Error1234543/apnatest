1. Set Theory and Algebra of Sets

A set is a well-defined collection of distinct objects called elements. Sets are denoted by capital letters (A, B, S, etc.) and elements by small letters. A set can be represented in roster form (listing elements) or set-builder form (describing a property that all elements satisfy).

Finite sets contain a countable number of elements; infinite sets do not. The empty set (ϕ or {}) contains no elements. Universal set U contains all objects under consideration.

Subsets: A ⊆ B means every element of A is also an element of B. Proper subset A ⊂ B requires A ≠ B.

Set operations:
• Union (A ∪ B): elements in A or B or both.
• Intersection (A ∩ B): elements common to both A and B.
• Difference (A − B): elements in A but not in B.
• Complement (A'): elements in U but not in A, where A' = U − A.
• Cartesian product: A × B = {(a, b) : a ∈ A, b ∈ B}.

Key identities (use these relentlessly in problems):
• A ∪ A' = U, A ∩ A' = ϕ
• (A ∪ B)' = A' ∩ B' (De Morgan's Law)
• (A ∩ B)' = A' ∪ B' (De Morgan's Law)
• A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
• A ∩ (B ∪ C) = (A ∩ B) ∩ (A ∩ C)
• n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
• n(A ∪ B ∪ C) = n(A)+n(B)+n(C)−n(A∩B)−n(B∩C)−n(A∩C)+n(A∩B∩C)

Venn diagrams are essential tools for visualising two-set and three-set relationships. When solving word-problem style questions, always identify U first, label each disjoint region step by step, and verify the total equals n(U). A frequent mistake is double-counting elements in overlapping regions when applying n(A ∪ B).

Relations and functions follow from Cartesian products. A relation R from A to B is any subset of A × B. A function is a special relation where each element of the domain maps to exactly one element of the codomain. Domain, co-domain, and range are the three fundamental terms. Linear functions f(x)=mx+c, quadratic functions f(x)=ax²+bx+c, and polynomial functions appear most often in the CMA context.

2. Quadratic Equations and Binomial Theorem

A quadratic equation has the form ax² + bx + c = 0 (a ≠ 0). The discriminant D = b² − 4ac determines the nature of roots:
• D > 0 and perfect square → two distinct real rational roots.
• D > 0 but not a perfect square → two distinct real irrational roots.
• D = 0 → equal (repeated) real roots: x = −b/(2a).
• D < 0 → two complex conjugate roots.

Roots formula: x = [−b ± √(b²−4ac)] / 2a

Sum of roots α+β = −b/a; product of roots αβ = c/a.
If one root is known, the other follows immediately from sum/product relations — a very common shortcut in exams.

Quadratic inequalities (e.g., ax²+bx+c > 0) are solved by finding critical points (roots), plotting sign changes on a number line, and selecting the required interval based on the inequality sign.

Binomial Theorem for positive integral index n:
(a+b)^n = Σ C(n,r)·a^(n−r)·b^r, r = 0 to n
where C(n,r) = n!/[r!(n−r)!] are binomial coefficients.

Key properties of binomial expansion:
• Total number of terms = n + 1
• Sum of binomial coefficients: C(n,0)+C(n,1)+…+C(n,n) = 2^n
• Sum of odd-indexed coefficients = Sum of even-indexed coefficients = 2^(n−1)
• Symmetry: C(n,r) = C(n, n−r)
• General term (r+1)-th term: T_{r+1} = C(n,r)·a^(n−r)·b^r
• Middle term(s): if n is even, middle term is T_{n/2+1}; if n is odd, there are two middle terms T_{(n+1)/2} and T_{(n+3)/2}

The coefficient of x^k in an expansion is found by setting the power of x equal to k in the general term and solving for r. A classic exam pattern asks for the independent term (term free of x) — set the combined exponent of x to zero.

3. Matrices and Determinants

A matrix is a rectangular array of numbers arranged in m rows and n columns, denoted by a capital letter. Order = m × n.

Special matrices:
• Row matrix: 1×n; Column matrix: m×1
• Square matrix: m = n
• Diagonal matrix: off-diagonal elements are zero
• Scalar matrix: diagonal matrix with equal diagonal entries
• Identity (unit) matrix I: diagonal entries all 1, rest 0
• Zero (null) matrix: all entries are 0
• Transpose A': swap rows and columns; (A')' = A; (A+B)' = A'+B'; (AB)' = B'A'
• Symmetric: A' = A; Skew-symmetric: A' = −A, diagonal entries = 0

Matrix operations:
• Addition/subtraction: same order required; associative, commutative for addition.
• Scalar multiplication: k(AB) ≠ (kA)B in general — only k multiplies every element.
• Matrix multiplication: AB exists only when columns of A = rows of B. NOT commutative: AB ≠ BA generally. (AB)C = A(BC) (associative). Distributive: A(B+C) = AB+AC.
• If AB = O (zero matrix), it does NOT imply A=O or B=O — singular matrices can multiply to give zero.

Determinant of a square matrix A (written |A| or det A):
• For 2×2: |A| = ad − bc for A = [[a,b],[c,d]]
• For 3×3: expand along any row/column using cofactor expansion
• Properties: |A'| = |A|; |AB| = |A||B|; |A^n| = |A|^n; |kA| = k^n|A| for n×n matrix
• Singular matrix: |A| = 0 (no inverse); Non-singular: |A| ≠ 0 (inverse exists)

Adjoint and Inverse:
• Adjugate (adj A): transpose of cofactor matrix
• A · adj(A) = adj(A) · A = |A| · I
• Inverse: A^−1 = adj(A)/|A|, exists only if |A| ≠ 0
• (AB)^−1 = B^−1 · A^−1 (note reversed order — frequent trap)
• (A^−1)^−1 = A; (A^n)^−1 = (A^−1)^n

Solving linear systems via matrices:
• Write system as AX = B. If |A| ≠ 0, X = A^−1B gives unique solution.
• If |A| = 0 and (adj A)B ≠ O → inconsistent, no solution.
• If |A| = 0 and (adj A)B = O → may have infinite solutions (check rank).

4. Permutations and Combinations

Permutation counts arrangements (order matters); Combination counts selections (order does not matter).

Permutation formula:
• P(n, r) = n! / (n−r)!
• n! = n × (n−1) × … × 2 × 1; 0! = 1 by definition
• Common identity: P(n,r) = n × P(n−1, r−1)
• P(n,n) = n!; P(n,0) = 1; P(n,1) = n

Combination formula:
• C(n, r) = n! / [r!(n−r)!]; also written as ^nC_r or choose(n,r)
• Key identity: C(n,r) = C(n, n−r)
• Pascal's identity: C(n,r) + C(n,r+1) = C(n+1, r+1)
• Relationship: P(n,r) = r! × C(n,r)

Classic application types in business mathematics:
• Words/letters arrangement: total = n!; with repetition of some letters, divide by factorials of repeated counts. Vowels together → treat them as one block; consonants together similarly.
• People seating around a round table: (n−1)! clockwise arrangement.
• Selection committees: combine permutation and combination logic carefully — distinguish whether position matters (permutation) or only membership (combination).
• Selection with constraints (must include / must exclude certain members): reduce available pool or fix selected items first then arrange remaining.
• Distinguish clearly between 'at least' and 'exactly' — 'at least one' problems are best solved as Total − None.

Common mistakes:
• Using permutation when order doesn't matter (combination needed).
• Forgetting that in circular arrangements, rotations are considered identical.
• Not dividing by factorials when items are repeated in arrangements.
• Double counting in selection-with-constraint problems.

5. Sequence and Series: AP, GP, HP

Arithmetic Progression (AP):
A sequence where consecutive terms differ by a constant d (common difference).
• nth term: a_n = a + (n−1)d, where a = first term
• Sum of n terms: S_n = n/2 [2a + (n−1)d] = n/2 (a + l), where l = last term
• Property: a_m + a_n = a_p + a_q whenever m+n = p+q
• Three quantities in AP: a−d, a, a+d (useful shortcut)
• Four quantities in AP: a−3d, a−d, a+d, a+3d

Geometric Progression (GP):
A sequence where consecutive terms have a constant ratio r (common ratio, r ≠ 0, r ≠ 1).
• nth term: a_n = a · r^(n−1), where a = first term
• Sum of n terms: S_n = a(r^n − 1)/(r − 1) if r > 1, or a(1 − r^n)/(1 − r) if r < 1
• Infinite GP sum (|r| < 1): S_∞ = a / (1 − r)
• Three quantities in GP: a/r, a, ar
• Property: a_m · a_n = a_p · a_q whenever m+n = p+q
• Between any two unequal positive numbers, GM = √(ab) is the unique geometric mean.

Harmonic Progression (HP):
A sequence whose reciprocals form an AP. There is no direct formula for nth term or sum in HP; convert to AP by taking reciprocals.
• nth term of HP: 1 / [a + (n−1)d]
• Three quantities in HP: 1/(a−d), 1/a, 1/(a+d)
• Harmonic mean of a and b: H = 2ab/(a+b)
• For any two positive numbers: AM ≥ GM ≥ HM, equality only when numbers are equal.

Business applications:
• Annuity and depreciation problems use GP formulas.
• Amortisation of loans often involves GP sum calculations.
• Population growth models use GP; decline models use GP with r < 1.

6. Limits and Differentiation

Limit notation: lim_{x→a} f(x) = L means f(x) approaches L as x approaches a.

Standard limits:
• lim_{x→0} sin x/x = 1
• lim_{x→0} (e^x − 1)/x = 1
• lim_{x→0} log(1+x)/x = 1
• lim_{x→∞} (1 + 1/x)^x = e
• lim_{x→a} (x^n − a^n)/(x − a) = n·a^(n−1)

Rules of limits:
• lim[f±g] = lim f ± lim g
• lim[kf] = k·lim f
• lim[f·g] = lim f · lim g
• lim[f/g] = lim f / lim g (denominator ≠ 0)
• lim[f(x)]^n = [lim f(x)]^n

Differentiation — core definitions and rules:
• Derivative definition: f'(x) = lim_{h→0} [f(x+h) − f(x)]/h (first principles)
• Power rule: d/dx[x^n] = n·x^(n−1)
• Constant rule: d/dx[c] = 0
• Sum/Difference rule: d/dx[f±g] = f' ± g'
• Product rule: d/dx[uv] = u'v + uv'
• Quotient rule: d/dx[u/v] = (u'v − uv')/v²
• Chain rule: d/dx[f(g(x))] = f'(g(x))·g'(x)

Standard derivatives frequently used:
• d/dx[sin x] = cos x; d/dx[cos x] = −sin x
• d/dx[tan x] = sec²x; d/dx[cot x] = −csc²x
• d/dx[e^x] = e^x; d/dx[a^x] = a^x·ln a
• d/dx[ln x] = 1/x; d/dx[log_a x] = 1/(x·ln a)

Higher-order derivatives:
• Second derivative: f''(x) = d/dx[f'(x)]
• Used in checking maxima/minima: f'(x)=0 and f''(x)<0 → maximum; f''(x)>0 → minimum

Implicit differentiation: when y is defined implicitly by an equation involving x and y, differentiate both sides w.r.t. x, treating y as a function of x (apply chain rule to y terms), then solve for dy/dx.

Logarithmic differentiation is useful for functions of the form y = [f(x)]^{g(x)} or products/quotients with many factors: take ln of both sides first, then differentiate implicitly.

7. Integral Calculus

Integration is the reverse process of differentiation. If d/dx[F(x)] = f(x), then ∫f(x)dx = F(x) + C, where C is the constant of integration.

Standard indefinite integrals:
• ∫x^n dx = x^(n+1)/(n+1) + C, n ≠ −1
• ∫(1/x)dx = ln|x| + C
• ∫e^x dx = e^x + C
• ∫a^x dx = a^x/ln a + C
• ∫sin x dx = −cos x + C
• ∫cos x dx = sin x + C
• ∫sec²x dx = tan x + C
• ∫csc²x dx = −cot x + C
• ∫sec x tan x dx = sec x + C
• ∫csc x cot x dx = −csc x + C
• ∫1/√(1−x²) dx = arcsin x + C
• ∫1/(1+x²) dx = arctan x + C
• ∫1/(x√(x²−1)) dx = arcsec|x| + C

Integration techniques:
• Substitution (u-substitution): let u = g(x), du = g'(x)dx; replace and integrate in u.
• Integration by parts: ∫u dv = uv − ∫v du (choose u by LIATE rule: Logarithmic, Inverse trig, Algebraic, Trig, Exponential — highest priority becomes u).
• Partial fractions: decompose rational functions into simpler fractions when denominator factors into linear or irreducible quadratic terms.

Definite integrals:
• ∫_a^b f(x) dx = F(b) − F(a), where F is antiderivative of f
• Properties: ∫_a^b f(x)dx = −∫_b^a f(x)dx; ∫_a^a f(x)dx = 0; ∫_a^b f(x)dx = ∫_a^c f(x)dx + ∫_c^b f(x)dx
• ∫_a^b f(x)dx = ∫_a^b f(a+b−x)dx (very useful symmetry property)
• If f is even, ∫_{−a}^a f(x)dx = 2∫_0^a f(x)dx; if f is odd, integral = 0

Applications in business:
• Consumer surplus: area under demand curve minus total expenditure = ∫_0^{Q} [D(Q) − P] dQ
• Producer surplus: total revenue minus area under supply curve = PQ − ∫_0^{Q*} S(Q) dQ
• Net present value calculations use definite integrals with continuous discounting: NPV = ∫_0^T R(t)e^{−rt} dt

8. Probability — Fundamentals

Probability measures the likelihood of an event occurring. P(A) = n(A)/n(S) for equally likely outcomes, where S is the sample space.

Axioms of probability:
• 0 ≤ P(A) ≤ 1 for any event A
• P(S) = 1
• For mutually exclusive events A and B: P(A ∪ B) = P(A) + P(B)

Key formulas:
• Addition theorem: P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
• For complementary events: P(A') = 1 − P(A)
• Mutually exclusive: P(A ∩ B) = 0, so P(A ∪ B) = P(A) + P(B)
• Exhaustive events: their union is the entire sample space
• Independent events: P(A ∩ B) = P(A)·P(B); independence implies mutual exclusivity only when at least one event has probability 0

Conditional probability:
• P(A|B) = P(A ∩ B)/P(B), provided P(B) > 0
• Multiplication theorem: P(A ∩ B) = P(A|B)·P(B) = P(B|A)·P(A)
• For independent events: P(A|B) = P(A), so P(A∩B) = P(A)P(B)

Bayes' theorem:
P(A_i|B) = P(B|A_i)·P(A_i) / Σ P(B|A_j)·P(A_j)
Used extensively when posterior probabilities are needed after observing new evidence. Always identify the prior probabilities P(A_i) and the likelihoods P(B|A_i) correctly before substituting.

Expected value of a random variable X: E(X) = Σ x_i · P(x_i)
Variance: Var(X) = E(X²) − [E(X)]² = Σ (x_i − μ)² · P(x_i)
Standard deviation: σ = √Var(X)

9. Measures of Central Tendency

Measures of central tendency identify the centre or typical value of a data set. Three principal measures: mean, median, mode.

Mean (Arithmetic Mean):
• Raw/ungrouped data: x̄ = Σx_i / n
• Grouped/frequency data: x̄ = Σf_i x_i / Σf_i
• Short-cut method (assumed mean A): x̄ = A + Σf_i d_i / Σf_i, where d_i = x_i − A
• Step-deviation method: x̄ = A + h · Σf_i u_i / Σf_i, where u_i = (x_i − A)/h
• Properties: algebraic sum of deviations from mean is zero; mean is affected by every value; combining two groups: x̄_combined = (n₁x̄₁ + n₂x̄₂)/(n₁+n₂)
• Geometric mean (for ratios/rates): GM = (Π x_i)^(1/n); useful for average rates of change
• Harmonic mean: HM = n / Σ(1/x_i); used for average speeds and rates

Median:
The middle value when data is ordered. Robust to extreme values.
• Ungrouped odd n: median = value at position (n+1)/2
• Ungrouped even n: median = average of values at positions n/2 and (n/2+1)
• Grouped data: Median = l + [(N/2 − cf)/f] × h
where l = lower boundary of median class, N = Σf, cf = cumulative frequency before median class, f = frequency of median class, h = class width
• Relation for moderately symmetric distributions: Mode ≈ 3×Median − 2×Mean

Mode:
The most frequently occurring value.
• Ungrouped: value with highest frequency
• Grouped data: Mode = l + [f₁−f₀)/(2f₁−f₀−f₂)] × h
where f₁ = frequency of modal class, f₀ = frequency of class before modal class, f₂ = frequency of class after modal class

Comparison and usage:
• Mean uses all data but is sensitive to outliers.
• Median is preferred for skewed distributions.
• Mode is the only measure applicable to nominal (categorical) data.
• For open-ended classes, median and mode are preferred over mean.

10. Measures of Dispersion

Measures of dispersion quantify the spread or variability of data around a central value.

Range: Range = Maximum − Minimum. Simple but ignores internal distribution.

Quartile Deviation (Semi-interquartile Range):
• Q1 (lower quartile): value at position (n+1)/4 in ordered data
• Q3 (upper quartile): value at position 3(n+1)/4
• For grouped data: Q1 = l₁ + [(n/4 − cf₁)/f_{Q1}] × h₁; Q3 = l₂ + [(3n/4 − cf₂)/f_{Q3}] × h₂
• Quartile Deviation = (Q3 − Q1)/2
• Coefficient of Quartile Deviation = (Q3 − Q1)/(Q3 + Q1)

Mean Deviation (MD):
• MD about mean = Σf_i|x_i − x̄| / Σf_i
• MD about median = Σf_i|x_i − M| / Σf_i (usually smaller than MD about mean)
• Coefficient of MD = MD / central tendency measure used

Variance and Standard Deviation (most important measures):
• Population variance σ² = Σ(x_i − μ)²/N = Σx_i²/N − μ²
• Sample variance s² = Σ(x_i − x̄)²/(n−1) (used in inferential statistics)
• Grouped: σ² = [Σf_i x_i²/Σf_i] − (x̄)²
• Short-cut: σ² = Σf_i d_i²/Σf_i − (Σf_i d_i/Σf_i)², where d_i = x_i − A
• Standard deviation σ = √variance (same units as original data)
• Coefficient of Variance (CV) = (σ/x̄)×100% — dimensionless, used for comparing variability across different units

Properties:
• Adding/subtracting a constant does not change SD or variance.
• Multiplying/dividing by constant k: SD becomes |k|σ, variance becomes k²σ².
• Combined SD for two groups: σ²_combined = [(n₁(σ₁²+d₁²)+(n₂(σ₂²+d₂²)]/(n₁+n₂), where dᵢ = x̄ᵢ − x̄_combined

Dispersion choice guide:
• CV for comparing spread across datasets with different units or vastly different means.
• SD for further statistical computations.
• QD when distribution has open-ended classes or extreme outliers.

11. Correlation and Regression

Correlation measures the strength and direction of linear association between two variables X and Y.

Pearson's correlation coefficient (r):
• r = Σ(x_i − x̄)(y_i − ȳ) / √[Σ(x_i − x̄)² · Σ(y_i − ȳ)²]
• Also: r = [nΣxy − ΣxΣy] / √[(nΣx²−(Σx)²)(nΣy²−(Σy)²)]
• For grouped/bivariate data: r = Σf_{ij}(x_i − x̄)(y_j − ȳ) / [√Σf_{i.}(x_i−x̄)² · √Σf_{.j}(y_j−ȳ)²]
• Properties: −1 ≤ r ≤ 1; r = +1 perfect positive linear; r = −1 perfect negative linear; r = 0 no linear correlation
• Unit-free: invariant to change of origin and scale

Spearman's rank correlation (for ranked/ordinal data):
• r_s = 1 − [6Σd_i²]/[n(n²−1)], where d_i = difference in ranks
• Use when data cannot be measured precisely but can be ranked; apply correction for tied ranks if many ties exist

Regression lines:
• Regression of Y on X: y − ȳ = b_{yx}(x − x̄), where b_{yx} = r(σ_y/σ_x) = Σ(x_i−x̄)(y_i−ȳ)/Σ(x_i−x̄)²
• Regression of X on Y: x − x̄ = b_{xy}(y − ȳ), where b_{xy} = r(σ_x/σ_y)
• Both lines pass through (x̄, ȳ)
• Angle between regression lines: tan θ = [(1−r²)/r]·[σ_x σ_y/(σ_x²+σ_y²)]
• If r = ±1, lines coincide; if r = 0, lines are perpendicular

Key relationships:
• r² = coefficient of determination — proportion of variation in Y explained by X
• b_{yx} · b_{xy} = r² (both slopes positive → r positive; both negative → r negative)
• |r| = √(b_{yx} · b_{xy}); sign of r matches sign of slopes
• r lies between the two regression coefficients in magnitude (when expressed as ratios)

Interpretation in business context:
• r close to ±1 indicates strong predictive relationship; r close to 0 suggests weak linear relationship.
• Regression enables forecasting — predict Y for given X using the fitted line.

12. Index Numbers and Time Series

Index numbers measure relative change in a variable (or group of variables) over time, usually expressed as a percentage of a base period value.

Simple aggregative method:
P₀₁ = Σp₁/Σp₀ × 100
(where p₁ = current prices, p₀ = base year prices)

Weighted aggregative methods:
• Laspeyres index (base-year quantities as weights): L = Σ(p₁q₀)/Σ(p₀q₀) × 100
• Paasche index (current-year quantities as weights): P = Σ(p₁q₁)/Σ(p₀q₁) × 100
• Fisher's ideal index (geometric mean of L and P): F = √(L × P)
F satisfies both time-reversal test and factor-reversal test — making it theoretically superior

Consumer Price Index (CPI):
• Unadjusted: CPI = Σ(I_w × W)/ΣW, where I_w is price relative for item w and W is its weight
• Base-shifted: CPI_new = CPI_old × (New base index/Old base index)
• Real wages = Nominal wages/CPI × 100

Time Series Analysis decomposes observations Y_t into four components:
• Trend (T): long-term direction (upward/downward/stable)
• Seasonal variation (S): regular periodic fluctuations within a year
• Cyclical variation (C): wave-like fluctuations longer than a year (business cycles)
• Irregular/random variation (I): unpredictable noise
• Additive model: Y = T + S + C + I
• Multiplicative model: Y = T × S × C × I (more common in business — components proportional to trend level)

Moving averages smooth out irregular fluctuations:
• Even-order moving average (e.g., MA of 4): center by taking a 2-period MA of the MA values
• Odd-order moving average (e.g., MA of 3): directly centred on the middle period
• MA of n periods replaces each value with average of n consecutive values

Trend estimation:
• Semi-averages: split data into two halves, compute means, draw line through means
• Least squares method: fit Y = a + bX where b = [nΣXY − ΣXΣY]/[nΣX² − (ΣX)²], a = Ȳ − bX̄
For time series, assign X values symmetrically (…, −2, −1, 0, 1, 2, …) so ΣX = 0

Important facts

  • De Morgan's Laws: (A∪B)' = A'∩B' and (A∩B)' = A'∪B'. These are foundational for set-problem proofs.
  • Discriminant D = b²−4ac determines nature of roots: D>0 real & distinct, D=0 equal, D<0 complex.
  • Binomial theorem general term T_{r+1} = C(n,r)·a^(n−r)·b^r. Middle term depends on whether n is even or odd.
  • Matrix multiplication is NOT commutative. (AB)^{-1} = B^{-1}A^{-1}, order reverses.
  • Circular permutation of n distinct items = (n−1)! due to rotational symmetry.
  • For GP with |r|<1: S_∞ = a/(1−r). This formula fails if |r|≥1.
  • AM ≥ GM ≥ HM for positive numbers, with equality iff all numbers are equal.
  • Chain rule in differentiation: d/dx[f(g(x))] = f'(g(x))·g'(x). Apply repeatedly for nested functions.
  • In integration by parts, follow LIATE rule to choose u: Logarithmic > Inverse trig > Algebraic > Trig > Exponential.
  • Fisher's ideal index satisfies both time-reversal and factor-reversal tests; Laspeyres tends to overstate, Paasche tends to understate.
  • Correlation coefficient r is unit-free and invariant to change of origin and scale.
  • r² (coefficient of determination) represents the proportion of variation in Y explained by X.
  • For combined SD: σ²_combined uses within-group variances plus between-group variance (d² terms).
  • In regression, both lines pass through (x̄, ȳ). When r = ±1, the two regression lines coincide.
  • Moving averages of even order require a second averaging step to centre the values properly.
  • Conditional probability: P(A|B) = P(A∩B)/P(B). Independence means P(A|B) = P(A).

Formulas and relationships

n(A∪B) = n(A) + n(B) − n(A∩B); n(A∪B∪C) = n(A)+n(B)+n(C)−n(A∩B)−n(B∩C)−n(A∩C)+n(A∩B∩C)
Quadratic roots: x = [−b ± √(b²−4ac)]/2a; Sum of roots = −b/a; Product of roots = c/a
Binomial general term: T_{r+1} = C(n,r)·a^(n−r)·b^r; C(n,r) = n!/[r!(n−r)!]
Inverse of matrix: A^{-1} = adj(A)/|A|; |AB| = |A|·|B|; (AB)^{-1} = B^{-1}·A^{-1}

Common mistakes

  • Applying n(A∪B)=n(A)+n(B) without subtracting n(A∩B), causing double counting of intersection elements.
  • Assuming AB=O implies A=O or B=O — this is false for singular/non-zero matrices.
  • Writing (AB)^{-1} = A^{-1}B^{-1} instead of B^{-1}A^{-1}; the order of inversion reverses.
  • Using P(n,r) when the problem requires selection without regard to order (should use C(n,r)).
  • Confusing circular permutation with linear permutation — circular is (n−1)!, not n!.
  • Forgetting that infinite GP sum S_∞ = a/(1−r) applies ONLY when |r|<1; using it when |r|≥1 gives wrong/negative results.
  • Applying differentiation product rule incorrectly as (uv)' = u'v' instead of u'v + uv'.
  • Omitting the constant of integration (+C) in indefinite integrals — a persistent mark deduction.
  • Treating P(A∩B)=P(A)P(B) as the definition of conditional probability rather than the condition for independence.
  • Computing CV without multiplying by 100 to express as percentage, or confusing CV with standard deviation.
  • Using the median class formula with cumulative frequency of the median class itself instead of the cumulative frequency BEFORE the median class.
  • Computing mode for grouped data with the wrong f₀ and f₂ — f₀ is freq of PRECEDING class, f₂ is freq of SUCCEEDING class.
  • Confusing Laspeyres index (uses base-year quantities) with Paasche index (uses current-year quantities).
  • Assuming correlation implies causation — a high |r| means strong linear association, not necessarily that one variable causes the other.
  • Using the additive time-series model when the data shows growing seasonal amplitude (multiplicative model is more appropriate).
  • Not adjusting moving averages of even order by a second averaging step to properly centre them on time periods.
  • Applying Bayes' theorem without identifying which event is the 'given' event (the conditioning event goes in the denominator's P(B)).
  • Forgetting that for combined SD, both within-group variances and between-group mean differences contribute to the overall variance.
