Quick Revision: Fundamentals of Business Mathematics and Statistics — CMA Foundation

CMAEnglishQuick Revision

Definitions

  • Permutation: An arrangement of objects in a definite order. The number of permutations of n distinct items taken r at a time is denoted by nPr = n! / (n - r)!.
  • Combination: A selection of objects where order does not matter. The number of combinations of n distinct items taken r at a time is nCr = n! / [r!(n - r)!]. Note that nCr = nC(n-r).
  • Arithmetic Progression (AP): A sequence in which the difference between any two consecutive terms is constant. This constant is called the common difference d. The nth term is a + (n-1)d, and the sum of n terms is S_n = n/2[2a + (n-1)d] = n/2(a + l), where l is the last term.
  • Geometric Progression (GP): A sequence in which the ratio of any term to its preceding term is constant. This constant is called the common ratio r. The nth term is a·r^(n-1). For r ≠ 1, S_n = a(r^n - 1)/(r - 1). If |r| < 1, the infinite sum converges to S∞ = a/(1 - r).
  • Logarithm: If a^x = N, then x is called the logarithm of N to the base a, written as x = log_a N. Common bases are 10 (common log, log) and e (natural log, ln). Key properties: log(ab) = log a + log b; log(a/b) = log a - log b; log(a^n) = n log a.
  • Matrix: A rectangular array of numbers arranged in rows and columns. An m × n matrix has m rows and n columns. Special types include row matrix (1×n), column matrix (m×1), square matrix (m = n), diagonal matrix (non-zero elements only on main diagonal), identity matrix I (diagonal elements all 1), and zero/null matrix (all elements 0).
  • Determinant: A scalar value associated with a square matrix. For a 2×2 matrix [[a,b],[c,d]], det = ad - bc. For a 3×3 matrix, expansion is done along any row or column using cofactors. A matrix is singular if its determinant is zero; non-singular otherwise.
  • Inverse of a Matrix: For a non-singular square matrix A, the inverse A^(-1) satisfies A·A^(-1) = A^(-1)·A = I. It is computed as A^(-1) = adj(A) / det(A), where adj(A) is the adjoint (transpose of the cofactor matrix). Inverse exists only for square non-singular matrices.
  • Limit: The value that a function f(x) approaches as x approaches some value a. Written lim_(x→a) f(x) = L. Standard limits include: lim_(x→0) sin x/x = 1; lim_(x→0) (e^x - 1)/x = 1; lim_(x→0) log(1+x)/x = 0; lim_(x→a) (x^n - a^n)/(x - a) = n·a^(n-1).
  • Derivative: The derivative of f(x) at x is defined as f'(x) = lim_(h→0) [f(x+h) - f(x)]/h, also denoted dy/dx or df/dx. It represents the instantaneous rate of change of y with respect to x. Standard derivatives: d/dx(x^n) = nx^(n-1); d/dx(e^x) = e^x; d/dx(a^x) = a^x · ln a; d/dx(sin x) = cos x; d/dx(cos x) = -sin x; d/dx(tan x) = sec²x; d/dx(log x) = 1/x.
  • Integral (Antiderivative): The process of finding a function whose derivative is the given function. ∫x^n dx = x^(n+1)/(n+1) + C (n ≠ -1); ∫e^x dx = e^x + C; ∫sin x dx = -cos x + C; ∫cos x dx = sin x + C; ∫(1/x) dx = log|x| + C; ∫sec²x dx = tan x + C.
  • Definite Integral: ∫_a^b f(x)dx = F(b) - F(a), where F is an antiderivative of f. It represents the net area under the curve y = f(x) between x = a and x = b.
  • Mean (Arithmetic Mean): The sum of all observations divided by the number of observations. For ungrouped data: X̄ = Σx_i / n. For grouped data: X̄ = Σf_i x_i / Σf_i.
  • Median: The middle value when data is arranged in ascending order. For odd n, Median = ((n+1)/2)th term. For even n, Median = average of (n/2)th and (n/2 + 1)th terms. For grouped data: Median = l + [(n/2 - cf)/f]·h, where l = lower class boundary, cf = cumulative frequency before median class, f = frequency of median class, h = class width.
  • Mode: The value that occurs most frequently in a data set. For grouped data: Mode = l + [(f1 - f0)/(2f1 - f0 - f2)]·h, where f1 = modal class frequency, f0 = frequency of class preceding modal class, f2 = frequency of class succeeding modal class.
  • Range: The difference between the largest and smallest observation. Range = Max - Min.
  • Variance: The average of squared deviations from the mean. For population: σ² = Σ(x_i - X̄)²/n. For sample: s² = Σ(x_i - X̄)²/(n-1). An alternative formula: σ² = Σx_i²/n - (Σx_i/n)².
  • Standard Deviation: The positive square root of variance. σ = √(Σ(x_i - X̄)²/n). It measures the dispersion of data around the mean in the same units as the data.
  • Mean Deviation: The average of absolute deviations from a central value (mean or median). MD = Σ|x_i - A|/n. It is less sensitive to extreme values than standard deviation but ignores algebraic signs.
  • Coefficient of Variation (CV): A relative measure of dispersion: CV = (σ / X̄) × 100%. It is used to compare the variability of two or more data sets with different units or widely different means.
  • Correlation Coefficient (r): A measure of linear association between two variables x and y. r = Σ(x_i - X̄)(y_i - ȳ) / √[Σ(x_i - X̄)² · Σ(y_i - ȳ)²]. Also r = [nΣxy - ΣxΣy] / √{[nΣx² - (Σx)²][nΣy² - (Σy)²]}. Values range from -1 to +1: +1 perfect positive, -1 perfect negative, 0 no linear correlation.
  • Regression Line of y on x: The line that best fits the data in the least-squares sense. Equation: y - ȳ = b_yx(x - X̄), where b_yx = r·(σ_y/σ_x) = [nΣxy - ΣxΣy]/[nΣx² - (Σx)²]. This line is used to predict y for a given x.
  • Regression Line of x on y: Equation: x - X̄ = b_xy(y - ȳ), where b_xy = r·(σ_x/σ_y) = [nΣxy - ΣxΣy]/[nΣy² - (Σy)²].
  • Index Number: A statistical measure that shows changes in a variable or group of related variables over time relative to a base period. Types include price index, quantity index, and value index. Laspeyres Index uses base-year quantities as weights: P_L = Σ(p_t/q_0) / Σ(p_0/q_0) × 100. Paasche Index uses current-year quantities: P_P = Σ(p_t/q_t) / Σ(p_0/q_t) × 100.
  • Time Series: A sequence of data points indexed in time order. Components: Trend (T) — long-term direction; Seasonal variation (S) — regular periodic fluctuations within a year; Cyclical variation (C) — wave-like fluctuations over several years; Irregular/random variation (I) — unpredictable noise. Models: Additive Y = T + S + C + I; Multiplicative Y = T × S × C × I.
  • Marginal Cost: The rate of change of total cost with respect to output. MC = dC/dq. It represents the additional cost of producing one more unit of output.
  • Marginal Revenue: The rate of change of total revenue with respect to output. MR = dR/dq.
  • Marginal Profit: MP = dP/dq = MR - MC. Profit is maximized when MR = MC (i.e., dP/dq = 0 and d²P/dq² < 0).
  • Elasticity of Demand: Measures the responsiveness of quantity demanded to a change in price. E_d = (dq/dp) × (p/q). If |E_d| > 1, demand is elastic; if |E_d| < 1, inelastic; if |E_d| = 1, unit elastic.

Key concepts

  • Permutations vs Combinations: Use permutation when ORDER matters (arrangements, seating, word formation). Use combination when ORDER does not matter (selection, forming committees, choosing cards). Key distinction: ABC and BCA are different permutations but the same combination.
  • Factorial Properties: n! = n × (n-1) × (n-2) × ... × 1. By convention 0! = 1 and 1! = 1. Important identities: n! = n × (n-1)!; nPr = n × (n-1)P(r-1); nCr = n-1Cr-1 + n-1Cr.
  • AP-GP Relationships: In an AP, consecutive differences are equal. In a GP, consecutive ratios are equal. Important result: If a, b, c are in AP then b = (a+c)/2. If a, b, c are in GP then b² = ac. Harmonic Progression (HP): reciprocals form an AP; the nth term is 1/[a + (n-1)d].
  • Logarithm Base Conversion: log_a N = log_b N / log_b a. This is essential for converting between natural and common logs. Also: log_a a = 1, log_a 1 = 0, log_a(a^x) = x, a^(log_a x) = x.
  • Matrix Operations Rules: Matrix addition/subtraction requires same dimensions. Matrix multiplication: (AB)≠BA generally (non-commutative). (AB)^(-1) = B^(-1)·A^(-1). (AB)^T = B^T·A^T. det(AB) = det(A)·det(B). |kA| = k^n|A| for n×n matrix.
  • Cramer's Rule for Systems: For ax + by = e and cx + dy = f, let D = ad-bc, Dx = ed-bf, Dy = af-ec. Then x = Dx/D, y = Dy/D, provided D ≠ 0. This is directly applicable for solving cost accounting equations with multiple variables.
  • Differentiation Techniques: Product rule: d(uv)/dx = u·dv/dx + v·du/dx. Quotient rule: d(u/v)/dx = [v·du/dx - u·dv/dx]/v². Chain rule: d/dx[f(g(x))] = f'(g(x))·g'(x). These are essential for cost-revenue optimization problems.
  • Second Derivative Test for Maxima/Minima: If f'(c) = 0 and f''(c) < 0, then f has a local maximum at c. If f''(c) > 0, local minimum. If f''(c) = 0, test is inconclusive. For profit maximization: check MR = MC and d²π/dq² < 0.
  • Integration by Substitution: Used when the integrand contains a composite function. Set u = g(x), then du = g'(x)dx. Example: ∫2x·e^(x²)dx, put u = x², du = 2x dx, giving ∫e^u du = e^u + C = e^(x²) + C.
  • Definite Integral for Area: Area bounded by y = f(x), x-axis, x = a, x = b is ∫_a^b f(x)dx (if f(x) ≥ 0). If f(x) crosses the axis, compute absolute areas separately and add.
  • Three Measures of Central Tendency Relationship: For moderately skewed distributions, Mode ≈ 3×Median - 2×Mean. This empirical relationship is useful for checking consistency of calculated values.
  • Properties of Deviation: Σ(x_i - X̄) = 0. Changing origin (subtracting constant) does not affect variance or SD. Changing scale (multiplying by constant k) multiplies SD by |k| and variance by k². CV is dimensionless, enabling comparison across different units.
  • Interpretation of Correlation: r = +0.7 to +1.0: strong positive; r = +0.3 to +0.7: moderate positive; r = 0 to ±0.3: weak or no correlation; r = -0.7 to -1.0: strong negative. Remember: correlation does NOT imply causation.
  • Regression vs Correlation: Correlation measures degree of linear association (symmetric — r_xy = r_yx). Regression measures how one variable changes with another (asymmetric — two different lines: y on x and x on y). If r = ±1, the two regression lines coincide. If r = 0, the lines are perpendicular.
  • Index Number Construction Steps: (1) Select the item/category to be measured. (2) Choose base year. (3) Collect price/quantity data. (4) Compute individual price relatives (p_t/p_0 × 100). (5) Apply appropriate weighting and averaging method. Fisher's Ideal Index = √(Laspeyres × Paasche), satisfying both time reversal and factor reversal tests.
  • Moving Averages for Trend: Simple moving averages smooth out irregular fluctuations. A 3-year MA centered at year t is (Y_(t-1) + Y_t + Y_(t+1))/3. Even-numbered MAs require a second centering step. Moving averages help isolate the underlying trend component.
  • Cost Accounting Applications: Marginal analysis (MC = MR for profit max/min) is heavily tested. Total Cost C(q) = Fixed Cost + Variable Cost. Revenue R(q) = price × quantity. Profit π(q) = R(q) - C(q). Differentiate to find optimal output. Integration is used to recover total cost from marginal cost: C(q) = ∫MC dq + constant.
  • Common Exam Patterns: Multiple-choice questions frequently ask for the nth term of AP/GP, sum of series, determinant value, matrix inverse, derivative/application, integral, central tendency, standard deviation, correlation coefficient, and index number computation.

Important facts

  • nPr calculation shortcut: 5P3 = 5 × 4 × 3 = 60; 6C2 = 15; 8C4 = 70. Memorize factorials up to 10!: 1!=1, 2!=2, 3!=6, 4!=24, 5!=120, 6!=720, 7!=5040, 8!=40320, 9!=362880, 10!=3628800.
  • For GP sum: if a = 1, r = 2, then S_10 = 2^10 - 1 = 1023. Common trap: confusing sum formula for finite GP with infinite GP formula. Always check |r| < 1 before using S∞ = a/(1-r).
  • Sarrus' rule for 3×3 determinant: copy first two columns to the right. Sum of products of downward diagonals minus sum of products of upward diagonals. Works ONLY for 3×3, not for higher orders.
  • Elementary row operations preserve the determinant's value when used for simplification: (1) Interchanging two rows multiplies det by -1. (2) Multiplying a row by k multiplies det by k. (3) Adding a multiple of one row to another leaves det unchanged — this is the key simplification technique.
  • Adjoint properties: A · adj(A) = adj(A) · A = |A| · I. For 2×2 matrix [[a,b],[c,d]], adj(A) = [[d,-b],[-c,a]] (swap diagonal, change sign of off-diagonal).
  • Standard derivative results frequently tested: d/dx(sinh x) = cosh x; d/dx(cosh x) = sinh x; d/dx(tan⁻¹x) = 1/(1+x²); d/dx(sin⁻¹x) = 1/√(1-x²); d/dx(e^(ax)) = a·e^(ax); d/dx(log(ax+b)) = a/(ax+b).
  • Integration formulas needing attention: ∫sec x dx = log|sec x + tan x| + C; ∫cosec x dx = log|cosec x - cot x| + C; ∫1/√(a²-x²) dx = sin⁻¹(x/a) + C; ∫1/(a²+x²) dx = (1/a)tan⁻¹(x/a) + C.
  • Key statistical constants to remember: For a data set with n observations, mean deviation about mean ≤ standard deviation. For symmetric distributions, mean = median = mode. For a discrete uniform distribution on {1,2,...,n}, mean = (n+1)/2.
  • Correlation coefficient bounds: -1 ≤ r ≤ 1. Also |r| ≤ root mean square of the two regression coefficients: |r| ≤ √(b_yx · b_xy). If b_yx = 2 and b_xy = 8, then r² ≤ 16, so |r| ≤ 1 (check consistency).
  • Fisher's Ideal Index satisfies two tests: Time Reversal Test: P_01 × P_10 = 1. Factor Reversal Test: P_01 × Q_01 = V_01 (value index). Only Fisher's index satisfies both simultaneously among major index number formulas.
  • Index number applications in cost accounting: Wholesale Price Index (WPI) and Consumer Price Index (CPI) are used to adjust cost figures for inflation. Real cost = Nominal cost / (Index/100). Wage index adjustments use the formula: Adjusted wage = Original wage × (Current index/Base index).
  • Business mathematics highlights: The break-even point occurs where Total Revenue = Total Cost, i.e., profit = 0. In calculus terms, it is where R(q) = C(q). Marginal analysis at break-even: MR = MC is a necessary but not sufficient condition for profit maximization — the second-order condition must also hold.
  • CMA Foundation emphasis: Questions on business mathematics typically carry 25-30% of the chapter marks. Statistics questions focus on computation (mean, SD, correlation, index numbers) and interpretation. Both subjects are scoring with practice.
  • Quick computational shortcuts: For AP sum, pair first with last, second with second-last, etc. For quick SD calculation, use the coding method: take an assumed mean A, find d_i = x_i - A, then σ = √[Σf_i d_i²/n - (Σf_i d_i/n)²].
  • Matrix rank: The rank of a matrix is the order of the largest non-vanishing minor. For a 2×2 matrix, rank is 2 if det ≠ 0, rank is 1 if all elements are proportional, rank is 0 only for zero matrix.
  • Limit evaluation techniques: For 0/0 indeterminate forms, use factorization, rationalization, or L'Hôpital's rule (differentiate numerator and denominator separately). For ∞/∞, divide numerator and denominator by the highest power of x.
  • In time series decomposition using multiplicative model, the seasonal index for each month averages to 12 (or 4 for quarters). If the sum of seasonal indices ≠ 12 (or 4), they must be adjusted proportionally.
  • Special case in probability (often mixed with math): P(A ∪ B) = P(A) + P(B) - P(A ∩ B). If A and B are mutually exclusive, P(A ∩ B) = 0. If independent, P(A ∩ B) = P(A)·P(B).

Memory aids

  • AP/GP memory aid: AP adds a constant difference (like walking equal steps); GP multiplies by a constant ratio (like copying a document and doubling each time). Mnemonic: 'A' for Addition (AP), 'G' for Growth/multiplication (GP).
  • Permutation vs Combination: 'P' stands for排列 ( Pai-lie = Arrangement) in Chinese mnemonic — order matters. Or remember: Committee = Combination (pick people, no order); Seating = Permutation (who sits where matters).
  • Matrix inverse shortcut: 'AI = IA = Determinant times Identity' — A times its inverse equals the determinant times the identity matrix. Formula: A^(-1) = adj(A)/|A|. Mnemonic: 'A-invert = A-adj divided by A-determinant.'
  • Differentiation rules: 'UC' for product rule — U times dV + V times dU. 'QU' for quotient rule — Lower d-High minus High d-Lower, over Lower squared. For chain rule: 'Inside-Out' — differentiate the outside, then multiply by derivative of the inside.
  • Integration memory: 'Power goes up, bring down former power as coefficient' — integrate x^n by increasing power to n+1 and dividing by new power. Reverses the derivative rule. Remember: 'Integral of 1/x is log x' is the EXCEPTION to the power rule.
  • Correlation interpretation: 'Roses are red, correlations are too — positive means up together, negative means opposite flow. Zero means no linear relation, don't confuse with no relation at all.'
  • Regression lines: 'Y on X predicts Y from X' — use when you know X and want Y (like predicting cost from output). 'X on Y predicts X from Y' — reverse prediction. Remember: 'Demand on Price' gives quantity from price.
  • Index numbers: 'Laspeyres uses Base quantities (L for Last/base), Paasche uses Current quantities (P for Present), Fisher is the Ideal compromise.' Also: 'L-P-F: Laspeyres-Paasche-Fisher — the index trio.'
  • Central tendency hierarchy: 'Mean is pulled by extremes (takes every value into account), Median is resistant (middle position), Mode is peak (most frequent).' In right-skewed data: Mode < Median < Mean.
  • Cramer's Rule mnemonic: 'D for Denominator (determinant of coefficients), Dx replaces x-column, Dy replaces y-column. Answers are Dx/D and Dy/D.'
  • Limit standard results: 'Sin x over x goes to one, as x gets small; e to the x minus one over x also one; log of one plus x over x shrinks to zero.' For polynomial limits: 'Highest power wins when x grows huge.'
  • Marginal analysis: 'Marginal means additional — MC is extra cost, MR is extra revenue. Maximize profit where they meet, then check the second derivative is negative to confirm a peak not a valley.'

Exam tips

  • For permutation-combination questions, always first decide: does ORDER matter? If YES → permutation. If NO → combination. Practice identifying this in the first 5 seconds of reading the question. Typical permutation words: arrange, seat, form (words/numbers), order. Typical combination words: select, choose, form (committee/group), distribute equally.
  • When computing determinants, ALWAYS simplify using row/column operations before expanding. Making zeros in a row or column reduces computation from 6 products to 2 or 3. Look for common factors in rows/columns — factor them out before expanding.
  • For matrix inverse problems, verify your answer by computing A·A^(-1). If the result is not the identity matrix, you made an error. This 30-second check catches most calculation mistakes and can save time in descriptive papers by avoiding reworking from scratch.
  • In differentiation, recognize standard forms immediately. If you see e^(ax), sin(ax), or log(ax+b), write the derivative directly without deriving from first principles. Practice until these 15-20 standard derivatives are automatic recall.
  • For integration, look for substitution opportunities first: if the integrand contains f(g(x))·g'(x), set u = g(x). Common substitutions: u = ax+b, u = sin x, u = e^x, u = x². After integrating, substitute back and DON'T forget + C.
  • In statistics problems, organize data in a table before calculating. For grouped data, create columns for f, x, fx, fx² (or d, fd, fd² using coding method). This systematic approach prevents missing terms and makes verification easy.
  • For correlation and regression, compute Σx, Σy, Σx², Σy², Σxy first — these five totals feed directly into ALL formulas. Make sure your arithmetic on these is correct; a single error here cascades through every subsequent calculation.
  • Index number questions: draw a clear table with columns p_0, p_t, q_0, q_t, p_t/q_0, p_0/q_0, etc. Label every column. Laspeyres needs Σp_t q_0 and Σp_0 q_0. Paasche needs Σp_t q_t and Σp_0 q_t. Keeping these straight prevents swapping weights.
  • For time series questions, remember: moving averages REDUCE the number of data points. A 3-year MA on 10 years gives 8 values (centered). A 4-year MA on 10 years requires a second centering step to align with years. Draw diagrams to track positions.
  • In marginal analysis problems, always state the economic interpretation after finding the critical point. 'At q = 50 units, profit is maximized' is worth more marks than just writing 'q = 50'. Check second derivative to confirm maximum vs minimum.
  • Quick-check for probability-style questions embedded in math: probabilities must lie between 0 and 1. If you get P(A) = 1.3 or P(A) = -0.2, you definitely made an error. This sanity check catches many calculation mistakes.
  • For AP/GP word problems, carefully identify what is given and what is asked. Common pattern: 'the 3rd term is 7 and 7th term is 19' → set up two equations: a + 2d = 7 and a + 6d = 19, then solve simultaneously. Write equations explicitly before substituting.
  • In descriptive papers, show all steps clearly. Even if the final answer is wrong, partial marks are awarded for correct method. For matrix problems, show the cofactor calculation for each element. For integration, show the substitution step. Never skip algebraic steps.
  • Time management: In objective sections, spend no more than 2 minutes per question. If stuck, mark and move on. Mathematics and statistics questions should collectively take about 25-30 minutes in a typical 3-hour paper. Practice with a timer to build speed.
  • Common numerical patterns to recognize quickly: nPr where r = n-1 gives n!/1! = n!; nCr where r = 1 gives n; nCr where r = 2 gives n(n-1)/2; (n+1)!/n! = n+1; n!/[(n-1)!·1!] = n. These shortcuts save crucial seconds.

Common traps

  • Confusing nPr with nCr: nPr = n!/(n-r)! while nCr = n!/[r!(n-r)!]. Always check whether order matters. A common error is using permutation when combination is required, yielding an answer larger by a factor of r!. Check: if selecting a committee of 3 from 8, answer is 8C3 = 56, NOT 8P3 = 336.
  • Infinite GP sum without checking |r| < 1: Using S∞ = a/(1-r) when |r| ≥ 1 gives incorrect or nonsensical results. Example: a=1, r=2 → S∞ = 1/(1-2) = -1, which is absurd for positive terms. Always verify convergence condition first.
  • Sign errors in determinant expansion: When expanding along a row, the signs follow the checkerboard pattern (+ - + / - + - / + - +). Missing the alternating sign on cofactors is a very frequent error. For element a_ij, the sign is (-1)^(i+j).
  • Matrix multiplication order confusion: Assuming AB = BA. Matrix multiplication is NOT commutative. In cost accounting applications involving simultaneous equations, multiplying by the inverse on the wrong side gives wrong results. Always write A^(-1)·A·X = A^(-1)·B correctly.
  • Logarithm domain errors: log(a + b) ≠ log a + log b. log(a/b) ≠ log a / log b. These are extremely common algebra mistakes. Remember: log properties apply only to products, quotients, and powers of a SINGLE argument, never to sums or differences inside the log.
  • Mean Deviation vs Standard Deviation confusion: MD uses absolute deviations |x_i - X̄| while SD uses squared deviations (x_i - X̄)². MD ignores sign and is simpler but less mathematically tractable. SD is preferred because it gives more weight to larger deviations and has desirable theoretical properties.
  • Correlation coefficient calculation sign error: Forgetting that r can be negative. If high x values correspond to low y values, r should be negative. A common trap: computing Σ(xy) correctly but missing the sign in the final formula, especially when covariance is negative.
  • Confusing regression coefficients: b_yx ≠ b_xy. b_yx = r(σ_y/σ_x) and b_xy = r(σ_x/σ_y). They are reciprocals only when σ_x = σ_y. Swapping them changes the predicted value. Remember: 'b_yx regresses y on x' — y is the dependent variable.
  • Index number base year error: Mixing up base year and current year prices in Laspeyres vs Paasche. Laspeyres: base quantities q_0 as weights (prices change, quantities fixed at base). Paasche: current quantities q_t as weights. Forgetting which year's quantities serve as weights flips the answer.
  • Integration constant omission: Writing ∫f(x)dx = F(x) without '+ C' for indefinite integrals. This is a fundamental error that costs marks in descriptive answers. The constant C represents the family of all antiderivatives.
  • Break-even vs profit maximization confusion: Break-even is where TR = TC (profit = 0). Profit maximization is where MR = MC (dπ/dq = 0). These are different conditions. A student might solve MR = MC and claim it gives break-even, which is wrong.
  • Limit evaluation at discontinuity: Assuming lim_(x→a) f(x) exists just because f(a) is defined. The limit depends on values approaching a, not the value at a. For piecewise functions, check left-hand limit and right-hand limit separately; they must be equal.
  • Standard deviation scaling error: If every observation is multiplied by k, the new SD is |k| times the old SD, NOT k² times. The variance becomes k² times. Students often confuse the SD scaling with variance scaling. Similarly, adding a constant to all observations does NOT change SD.
  • Cramer's Rule denominator zero: When D = 0, the system either has no solution or infinitely many solutions. Stating 'x = Dx/D' without checking D ≠ 0 first leads to division by zero errors. Always verify the determinant first.
  • Mode calculation for grouped data error: Using class mid-points instead of class boundaries in the mode formula. The correct formula uses l (lower class boundary), not the lower limit. Also, the modal class must have the HIGHEST frequency, not just any class.
  • Confusing arithmetic and geometric means: AM ≥ GM is true, with equality only when all numbers are equal. But students sometimes apply GM where AM is required (e.g., averaging percentages or rates) or vice versa. For average rate of growth, use GM; for average value, use AM.
