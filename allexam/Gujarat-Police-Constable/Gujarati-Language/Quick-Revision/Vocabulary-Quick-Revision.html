Definitions

  • Samansarthak Shabdon (સમાનાર્થી શબ્દો): એવા શબ્દો જેમનો અર્થ સમાન કે લગભગ સમાન હોય. ઉદા. સુન્દર = રૂપવંત = કાન્તિમાન.
  • Viparit Arthak Shabdon (વિપરીતાર્થી શબ્દો): એવા શબ્દો જેમનો અર્થ વિરુદ્ધ હોય. ઉદા. દિવસ ↔ રાત્રિ, ઉષા ↔ અન્ધકાર.
  • Mukta Shabd / Ek Shabd Prayog (મુક્તશબ્દ / એકશબ્દ પ્રયોગ): જટિલ અથવા લાંબા અર્થને ટૂંકા એક શબ્દમાં દર્શાવવાનો ભાષાકીય પ્રયોગ. ઉદા. 'જ્ઞાની વ્યક્તિ' માટે = મહાજ્ઞાની, 'સૌથી વધુ પ્રેમ કરનારો' = પરમભક્ત.
  • Mushkil Shabdon Ke Saral Arth (મુશ્કિલ શબ્દોના સાદા અર્થ): શાસ્ત્રીય, ગ્રંથસિદ્ધ કે વ્યવહારઉપરાંતના શબ્દોના સરળ દૈનિક અર્થ. ઉદા. 'અસંખ્ય' = અણગણતી, 'અતિશય' = અતિવધુ.
  • Sandhi Vibhajan (સંધિ વિભાજન): બે શબ્દો મિલિત થઈને જે નવો શબ્દ બને છે, તેને તોડીને મૂળ શબ્દો કાઢવા. ઉદા. દર્પણ = દર્પ + અણ.

Key concepts

  • સમાનાર્થી શબ્દોની મહત્વની યાદી: ધનવાન = ઐશ્વર્યવાન = ધનિક = સમૃદ્ધ; સ્વચ્છ = પવિત્ર = દિવ્ય; બલિષ્ઠ = પ્રબળ = શક્તિશાળી = શકતિમંત; સાધુ = પવિત્રાત્મા = ઋષિ; વિદ્વાન = પंडિત = મહાપંડિત; ચપલ = ચાંચળ = ચપળ; શીઘ્ર = ઝડપી = વેગવંત; નિરર્થક = વ્યર્થ = બેકાર; મરણ = મૃત્યુ = પરલોક; સ્વર્ગ = સુવર્ગ = જન્મભૂમિ (સંદર્ભઅનુસાર).
  • વિપરીતાર્થી શબ્દોની મહત્વની યાદી: અગ્નિ ↔ જળ; ઉષા ↔ અન્ધકાર/રાત્રિ; સુખ ↔ દુઃખ; મિત્ર ↔ શત્રુ; પ્રકાશ ↔ અંધકાર; સત્ય ↔ અસત્ય; વિજય ↔ પરાજય; જીવન ↔ મૃત્યુ; ઉત્તર ↔ ખોટું; દયા ↔ ಕ્રોધ; આશા ↔ નિરાશા; સકરારાત્મક ↔ નકારાત્મક; ગર્વ ↔ વિનય; ક્રોધ ↔ શાંતિ; મૂર્ખ ↔ બુદ્ધિમાન.
  • એકશબ્દ પ્રયોગ (મહત્વના): 'વિશ્વના અધિપતિ' = પરમेश્વર; 'જેની કોઈ ઇચ્છા ન હોય' = નિરાસક્ત; 'વિદ્વાન વ્યક્તિ' = મહાજ્ઞાની; 'બધાનો મિત્ર' = સર્વમિત્ર; 'જેણે બધાને જાણ્યા હોય' = સર્વજ્ઞ; 'ત્રણે વિદ્યાર્થીઓ' = ત્રિવેદી; 'બે દિવસ' = દ્વિદિવસ; 'આજ' = અનુદિવસ; 'સાડા ચાર' = ચતુષ્કંડ; 'ચાર જણીયો સમૂહ' = ચતુષ્ટય; 'સૌથી વધુ પાપી' = મહાપાપી; 'ભયંકર રોગ' = અતિસાર/મહામારી (સંદર્ભ); 'અત્યંત શોક' = પરમવિશોક; 'સદાય રહેતો' = નિત્ય; 'જ્ઞાનથી યુક્ત' = વિદુષી; 'કોઈપણ નહીં' = અકલ્પિત.
  • મુશ્કિલ શબ્દોના સરળ અર્થ: અનુકંપા = દયા; ઉપકાર = લાભ/ફાયદો; ક્રિયાપત્તિ = કીધેલું કામ; સંકલ્પ = મનોમંથન/ઇચ્છા; વિલક્ષણ = અનોખો; અદ્ભુત = અળગો/આશ્ચર્યજનક; અસહ્ય = અતિવેદના; ઉદ્દેશ્ય = લક્ષ્ય; નિષ્ઠા = ભક્તિ/અડગતા; શ્રદ્ધા = ધાર્મિક વિશ્વાસ; સ્ફૂર્તિ = ઊર્જા/તેજ; પરિશ્રમ = મહેનત; સમર્પણ = અર્પણ; આત્મચિંતન = સ્વચિંતન; મૈત્રી = સંગત; વિનંતિ = પ્રાર્થના; પ્રતિભા = કળા/ક્ષમતા.
  • શબ્દજોડી અને અર્થસંબંધ: 'પ્રત્યક્ષ' = સીધું જોવામાં આવેલું; 'રેખાંકિત' = નાડીબંધ; 'સંધ્યા' = સાંજ; 'ભાસ્કર' = સૂર્ય; 'મંડલ' = ચક્ર; 'પ્રાણી' = ચેતન; 'લક્ષ્મી' = સંપદ; 'ચંદ્રમા' = ચંદ્ર; 'વાજક' = વાદક; 'પાદપ' = વૃક્ષ; 'દિશા' = દિશ; 'મહી' = ભૂમિ/પૃથ્વી.
  • પ્રાચીન અને વડીલગાળ શબ્દોના આધુનિક અર્થ: 'જલ' = પાણી; 'અનલ' = અગ્નિ; 'પવન' = હવા/વાયુ; 'ચન્દ્ર' = ચંદ્ર; 'સૂર્ય' = સૂર્ય; 'ગગન' = આકાશ; 'નકshত্র' = તારો; 'ગગનતલ' = આકાશ; 'વેદ' = પવિત્ર ગ્રંથ; 'મંદિર' = દેવાલય; 'સ્નાન' = ગંગાશુદ્ધિ; 'વન' = જંગલ; 'પર્વત' = પહાડ.

Important facts

  • Gujarat Police Constable (LRC) પરીક્ષામાં શબ્દાવલી ભાગમાં મુખ્યત્વે સમાનાર્થી, વિપરીતાર્થી અને એકશબ્દ પ્રયોગના પ્રશ્ન આવે છે. સામાન્ય રીતે આ વિભાગમાં 5-8 પ્રશ્ન શબ્દાવલીના હોય છે.
  • પરીક્ષાના સંદર્ભમાં એકશબ્દ પ્રયોગમાં 'વિશેષણ + નામ'ના રૂપે પ્રશ્નો પૂછાય છે: જેમ કે 'પરમ + ધનિક' = પરમધનિક, 'નિરતર + પરિશ્રમ' = નિરતરપરિશ્રમી.
  • વિપરીતાર્થી શબ્દોમાં એવા શબ્દો પણ આવે છે જે સંદર્ભબદ્ધ બદલાય છે: ઉદા. 'ઉષા' નો વિપરીત અર્થ સંદર્ભ મુજબ 'અન્ધકાર' અથવા 'રાત્રિ' હોઈ શકે.
  • મહત્વનું: 'અંત' શબ્દનો વિપરીતાર્થી 'આરંભ' છે; 'અંતર' શબ્દનો વિપરીતાર્થી 'બાહ્ય' છે — આ બે શબ્દો ગૂંચવણ ઊભી કરી શકે છે.
  • ગુજરાતી પરીક્ષાઓમાં ઘણીવાર 'વિશેષ અર્થ ધરાવતા શબ્દો' પણ આવે છે: જેમ કે 'કમલ' = પદ્મ/કમળ, 'કુંભ' = ઘટ/કળશ, 'તારક' = તારો, 'અરવિંદ' = કમળ.
  • મુક્તશબ્દ (one-word substitution) પ્રશ્નોમાં ગ્રંથ, વ્યક્તિ, ભાવ, ગુણ — આ ચારેય વિભાગોમાંથી પ્રશ્ન આવે છે.
  • શબ્દાવલીમાં 'સંધિ' શબ્દો પણ સામેલ હોઈ શકે છે: અકસ્માત = અ + કસ્માત, વિદ્યાલય = વિદ્યા + આલય, શિક્ષક = શિક્ષ + અ.

Memory aids

  • સમાનાર્થી યાદ રાખવા માટે વિષયવિભાજન તકનીક: એક જ વિષયના શબ્દો એકઠા કરો — જેમ કે 'પ્રકાશ સંબંધી': ભાસ્કર, દિવકર, ઇન્દુ, ચંદ્ર, સૂર્ય — એક જ વિષય હોવાથી યાદ રાખવા સરળ.
  • વિપરીતાર્થી શબ્દોના યુગલો (pairs) માં યાદ કરો: દરેક શબ્દનો વિરુદ્ધ જોડીવાર રાખો — દિવસ-રાત્રિ, સુખ-દુઃખ, મિત્ર-શત્રુ, સત્ય-અસત્ય, જીવન-મૃત્યુ. આ રીતે બે તરીકે યાદ રહે છે.
  • એકશબ્દ પ્રયોગ માટે 'વિષય-ઉદાહરણ' મેમરી પેડ: જેમ કે 'વ્યક્તિ ગુણ' વિભાગ — મહાજ્ઞાની (વિદ્વાન), પરમભક્ત (બધાને પ્રેમ કરનાર), નિરાસક્ત (નિસ્વાર્થ). વિભાગીય યાદગારી.
  • મુશ્કિલ શબ્દો માટે 'અર્થ-સંબંધ' તકનીક: જે શબ્દ સંસ્કૃતમાંથી આવેલો હોય તેનો અર્થ સંસ્કૃત મૂળ સાથે જોડીને યાદ કરો. ઉદા. 'અનુકમ્પા' = અનુ + કંપા = દયા; 'ઉપકાર' = ઉપ + કૃ = લાભ.
  • શબ્દજોડી યાદ કરવા માટે 'કાવ્ય-રચના': એક નાનું વાક્ય બનાવો જ્યાં બધા શબ્દો આવે — ઉદા. 'પ્રકાશ = ભાસ્કર = ચંદ્રમા = સૂર્ય' ને એક વાક્યમાં રજૂ કરો.
  • શબ્દોના મૂળ સંસ્કૃત અર્થની યાદદાસ્ત માટે ટૂંકા સૂત્ર: 'જલ = પાણી, અનલ = અગ્નિ, પવન = હવા, ચન્દ્ર = ચંદ્ર, સૂર્ય = સૂર્ય' — આ મૂળ શબ્દો નિયમિત પુનરાવર્તનમાં આવે છે.

Exam tips

  • શબ્દાવલીના પ્રશ્નોમાં પ્રથમ દૃષ્ટિકોણ: પહેલા સ્પષ્ટ વિપરીતાર્થી/સમાનાર્થી શબ્દ ઓળખો, જે તમારી પાસે હોય તે જ પસંદ કરો. અજ્ઞાત શબ્દોને છોડી દો.
  • ગુજરાતી લિપિમાં શબ્દો વાંચતા સંસ્કૃત મૂળ યાદ કરો: જો શબ્દ સંસ્કૃત દેખાય તેમ હોય (જેમ કે 'ધન્ય', 'પૂજ્ય', 'વંદ્ય'), તો તેનો અર્થ સંસ્કૃત રીતે વિચારો.
  • પરીક્ષામાં 'સાચો જવાબ' શોધવા માટે વિકલ્પોમાંથી અસંગત શબ્દ કાઢી દો: ત્રણ વિકલ્પો એક જ અર્થના હોય અને એક અલગ હોય, તો એ અલગ શબ્દ સાચો હોઈ શકે છે.
  • મહત્વનું: Gujarat Police Constable ગુજરાતી શબ્દાવલી પ્રશ્નોમાં 70-80% શબ્દો અત્યંત સામાન્ય હોય છે — 'પ્રકાશ', 'પાણી', 'અગ્નિ', 'મિત્ર', 'શત્રુ' જેવા મૂળભૂત. આધારભૂત શબ્દો પર ધ્યાન આપો.
  • એકશબ્દ પ્રયોગના પ્રશ્નોમાં વિકલ્પો વચ્ચે સૂક્ષ્મ અંતર હોય છે. 'વિદ્વાન' માટે 'મહાજ્ઞાની' અને 'પંડિત' બંને યોગ્ય લાગે, પણ પરીક્ષાના પાઠ્યપુસ્તક મુજબ એક ચોક્કસ જવાબ હોય છે.
  • શબ્દાવલીનો વિસ્તાર સીમિત છે — મહત્વના 100-150 શબ્દોનો સમૂહ બનાવીને તેને યાદ કરવો. અમુક વિષયજન્ય શબ્દો (જેમ કે પ્રકાશ, જળ, અગ્નિ સંબંધી) વારંવાર આવે છે.

Common traps

  • ગૂંચવણભર્યા શબ્દો: 'અંત' અને 'અંતર' અલગ અર્થ ધરાવે છે. 'અંત' = છેડો/末 (મૃત્યુ), 'અંતર' = વચ્ચે/અંતરાલ. બંનેનો વિપરીતાર્થ પણ અલગ છે.
  • સમાનાર્થી શબ્દોમાં સૂક્ષ્મ અર્થભેદ: 'સ્વચ્છ' અને 'પવિત્ર' બંને શુદ્ધતા દર્શાવે છે પણ 'પવિત્ર' માં ધાર્મિક શુદ્ધિનો ભાવ વધુ હોય છે.
  • એકશબ્દ પ્રયોગમાં 'વિશેષણ vs નામ': 'મહાજ્ઞાની' એ 'વિદ્વાન વ્યક્તિ' માટે છે, પણ 'મહાજ્ઞાન' એ 'વિશાળ જ્ઞાન' માટે. આ ગૂંચવણ ટાળવી.
  • વિપરીતાર્થી પ્રશ્નોમાં એકથી વધુ સાચો જવાબ: 'સત્ય' નો વિપરીત 'અસત્ય', 'ભ્રાંત', 'અનૃત' — બધા સંભવિત છે પણ પરીક્ષામાં એક જ ચોક્કસ જવાબ હોય છે જે 'સૌથી યોગ્ય' હોય.
  • શબ્દોના સંદર્ભબદ્ધ અર્થ: 'ઉષા' શબ્દનો અર્થ સંદર્ભ મુજબ 'ભોલો', 'પ્રભાત', અથવા 'સવાર' હોઈ શકે. પણ વિપરીતાર્થી તરીકે 'અન્ધકાર' યોગ્ય છે.
  • ગ્રંથસિદ્ધ શબ્દોના ભ્રાંત અર્થ: 'અસંખ્ય' નો અર્થ 'અણગણતી' છે, 'અણગણ' નહીં. 'અતિશય' નો અર્થ 'અતિવધુ' છે, 'અતિમહાન' નહીં.
