ગુજરાતી શબ્દકોશ — સંપૂર્ણ નોટ (ગુજરાત પોલીસ કોન્સ્ટેબલ)

Gujarat Police ConstableGujaratiNotes

૧. શબ્દકોશનો પરિચય અને મહત્વ

ગુજરાત પોલીસ કોન્સ્ટેબલ ભરતી પરીક્ષામાં ગુજરાતી ભાષા વિભાગ હેઠળ શબ્દકોશને લગતા પ્રશ્નો સીધી રટ્ટા-મૂળના હોય છે — સમાનાર્થી, વિરોધાભાસી, એક-શબ્દ-પ્રત્યાસદ, રૂઢિપ્રવાહ, લોકોકતિ અને વ્યાકરણબદ્ધ ભૂલો. આ વિષય પરીક્ષામાં સામાન્ય રીતે ૫ થી ૮ નંબર ધરાવે છે. શબ્દકોશની તૈયારી કરતી વખતે વિદ્યાર્થીએ આ પાંચ મુખ્ય શ્રેણીઓ સ્પષ્ટ રીતે જાણવી જોઈએ: (અ) સમાનાર્થી શબ્દ — એક જ અર્થ ધરાવતા બે કે વધુ શબ્દો; (આ) વિરોધાભાસી શબ્દ — એકબીજાના વિરુદ્ધ અર્થ ધરાવતા શબ્દો; (ઇ) એક-શબ્દ-પ્રત્યાસદ — લાંબો અર્થ/વાક્ય પડે તેવો અર્થ એક જ શબ્દમાં દર્શાવે તે; (ઇ) રૂઢિપ્રવાહ અને લોકોકતિ — સમૂહ અર્થ ધરાવતાં વાક્યાંશ; (ઉ) વ્યાકરણબદ્ધ ભૂલો / અધિકરણ — ખોટું લખાયેલું શબ્દ, ખોટું સાધુશબ્દ અથવા વપરાશ-અનુરૂપ ન હોય તેવો શબ્દ. આ પાંચો શ્રેણી શબ્દકોશનો મૂળ સ્તંભ છે અને પરીક્ષામાં દરેકનો કોઈ na કોઈ પ્રશ્ન ફક્ત જરૂરી આવે છે.

૨. સમાનાર્થી શબ્દો — મૂળભૂત સિદ્ધાંત અને મહત્વના ઉદાહરણો

સમાનાર્થી શબ્દો એવા શબ્દો છે જેનો અર્થ એક હોય પણ ઉચ્ચાર/વ્યુત્પત્તિ અલગ હોય. ગુજરાતીમાં સાધુ (સાહિત્યિક) અને ભાષા (બોલચાલના) શબ્દો બંનેના સમાનાર્થી શબ્દો શીખવા જરૂરી છે.

મહત્વના ઉદાહરણો:
• સૂર્ય = સુર્ય, દિવાકર, ભાસ્કર, આદિત્ય, સવિતૃ, દિનમણિ, ઉષાકર, રવિ, વરુણ, મેધાતિથિ
• ચંદ્ર = ચન્દ્ર, શશિ, શંકર, ચંદ્રકાંત, સોમ, અહિયા, તમોહર
• યુવરાજ = રાજકુમાર, તનય, પ્રતાપ, ગુણિતા, અગ્રજ (સંદર્ભ મુજબ)
• રાત્રિ = નિશા, ઇશિયા, ભરતા, ભરતી, શ્યામા, ઝકાળ, અધિરાત્રિ
• દિવસ = અહો, અહોબ્દર, ભાસ્કરદિવસ, હેમંત, હેમંતિક
• ગગન = આકાશ, અંતરિક્ષ, નભ, વીજનભ, વિશ્વ, ભુવન, ખગોળ
• જળ = પાણી, અબ, અમૃત, સીમંત, નદીનિમ્ન, તરંગ, વારિ
• અગ્નિ = જ્વાલા, વિષ્ણુ, તપન, ક્રૂરાગ્નિ, પાવક, હુતવહન
• શસ્ત્ર = અસ્ત્ર, ધમણ, પરશુ, ખડ્ગ, તલવાર, ભૈરવ
• માનવ = મનુષ્ય, જન, મનીષા, પુરુષ, નર
• સુન્દર = રૂપવંત, વેણી, વિભૂષિત, પ્રિયદર્શન, મનીષા, સુરૂપ, ચિત્રવત્
• વિદ્વાન = પંડિત, મહાત્મા, શાસ્ત્રવેત્તા, ગ્રંથિગ્રાહક, કવિવર, બુદ્ધિમાન

નાણાંકીય/પ્રશ્નોત્તરી દૃષ્ટિકોણ: સમાનાર્થી શબ્દોમાં કેટલીકવાર 'વાચક' અને 'વાચ્ય' શબ્દ વચ્ચેનો તફાવત પરીક્ષામાં પૂછવામાં આવે છે. ઉદા: 'સિંહ' — વાચ્યશબ્દ = પશુ; 'સિંહરિપુ' = હંસ. આવા પ્રશ્નોમાં વિદ્યાર્થીએ શબ્દની વ્યુત્પત્તિ પણ ધ્યાનમાં રાખવી જોઈએ.

૩. વિરોધાભાસી શબ્દો — મૂળભૂત સિદ્ધાંત અને મહત્વના ઉદાહરણો

વિરોધાભાસી શબ્દો એવા શબ્દો છે જેનો અર્થ એકબીજાથી વિપરીત હોય. પરીક્ષામાં ઘણીવાર જોડાણો આપીને કોણ-કઈ જોડી વિરોધી નથી તે પૂછવામાં આવે છે.

મહત્વની જોડીઓ:
• યુદ્ધ — શાંતિ / સૂર્ય — ચંદ્ર / દિવસ — રાત્રિ / સુખ — દુઃખ
• ઊંચો — નીચો / કાળો — સફેદ / શુક્ર — શની (ગ્રહોમાં વિરોધ નથી — આ જોડીની પરીક્ષામાં હાનિ કરે છે)
• સત્ય — અસત્ય / સૂર — મૃદુ / ઉષ્ણ — શીત / ગ્રહણ — મંગળ (ગ્રહણ-મંગળ એકબીજાના વિરોધી નથી)
• આરંભ — અંત / ઉત્થાન — પતન / જન્મ — મૃત્યુ / પ્રકાશ — અંધકાર
• શુભ — અશુભ / કલ્યાણ — કલહ / સદ્ગુણ — દુર્ગુણ / મિત્ર — શત્રુ
• સ્વજન — પરજન / પૂર્વ — ઉત્તર / દક્ષિણ — ઉત્તર / દૈન્ય —ૌદાર્ય
• સત્ત્વ — રજ – તમ (ત્રિગુણ) / સર્વ — કશ્ચિત / અહં — પર

મહત્વની વાત: 'ગ્રહ' અને 'નક્ષત્ર' એકબીજાના વિરોધી નથી — બંને ખગોળ વસ્તુ છે. 'શુક્ર' અને 'શની' એ પૃથક્કરણ કરતા ગ્રહો છે. આવા 'ઘોંઘાટ પાડતી' જોડીઓ પરીક્ષામાં ઘણી વાર આવે છે. વિરોધાભાસી શબ્દોમાં જ્યાં શબ્દની વ્યુત્પત્તિ જાણીતી હોય ત્યાં શબ્દની માધ્યમી પણ ધ્યાનમાં લેવી.

૪. એક-શબ્દ-પ્રત્યાસદ — વ્યાખ્યા, શ્રેણીઓ અને મહત્વના ઉદાહરણો

એક-શબ્દ-પ્રત્યાસદ એટલે કે કોઈપણ વિશેષ અર્થ, પ્રક્રિયા, વ્યક્તિ, સ્થળ, વસ્તુ કે ગુણનો વર્ણનાત્મક અર્થ એક જ શબ્દમાં દર્શાવવો. પરીક્ષામાં સામાન્ય રીતે આવા પ્રશ્નો સીધા અર્થ આપે અને સાચો શબ્દ પસંદ કરવાનો હોય છે.

મહત્વના ઉદાહરણો:
• લોકોને યોગ્ય રાહદારી આપનાર = નેતા / નેતૃ / પરિચારક
• યુદ્ધ કરનાર = યોદ્ધા / સેનાપતિ / યુક્ત
• સમસ્ત પૃથ્વીનો રાજા = ચક્રવર્તી / સમ્રાટ / મહારાજાધિરાજ
• જેણે કોઈ પણ વસ્તુ ખરીદી હોય = ખરીદદાર / મલિક
• જેને ભય ન હોય = અભય / બેફિકર / સ્વતંત્ર
• જે જન્મ સિદ્ધ જ્ઞાન ધરાવતું હોય = અજ્ઞાત / અવતાર
• જેણે કોઈ વસ્તુનું નામ રાખ્યું હોય = નામદાર / નામધારી
• જ્ઞાનવાન વ્યક્તિ = વિદ્વાન / પંડિત / જ્ઞાની
• લોકોની સેવા કરનાર = સેવક / સેવાભાવી / માનવસેવક
• જે વસ્તુ બદલાતી હોય = પરિવર્તનશીલ / અચળ ન હોય
• જે કોઈ પણ વસ્તુનો નાશ કરે = નાશક / પ્રલયંકર / વિનાશક
• જે શત્રુથી ભયભીત ન હોય = અજરાઅમર
• કલિયુગમાં આયુધધારી = કલિકાલ / કલિયુગી
• ભાષાનું માહિત્ય = ભાષાંતર / વ્યાકરણ / શબ્દકોશ
• જેના અનુકૂળ હોય = પ્રસંગોપાત / સાધુ / અનુકૂળ

નોંધ: કેટલાક એક-શબ્દ-પ્રત્યાસદ પાશ્ચાત્ય બૌદ્ધિક શબ્દો પર આધારિત હોય છે, જેમ કે 'પર્યાવરણ', 'ગૃહપ્રેમ', 'સ્વદેશી', 'વિદેશી', 'માનવહિત', 'ગુણવાન'. આવા શબ્દોમાં 'પ્રત્યય' (પ્રતિ+આ+સદ) ની સમજ હોવી જોઈએ.

૫. રૂઢિપ્રવાહ, લોકોકતિ અને પ્રવાહી વાક્યાંશો

રૂઢિપ્રવાહ એટલે એવા વાક્યાંશો જેનો સાદો અર્થ કરતાં કોઈ વ્યંગાત્મક અથવા ગાઢ અર્થ હોય. લોકોકતિ એટલે જનસામાન્યમાં લોકપ્રિય થયેલા વચનો.

મહત્વના રૂઢિપ્રવાહ:
• 'કાચાના બોતલમાં સૂરજ —' = બિનજરૂરી કામ;
• 'ચાંદીની ચોકલી ચાવવી' = નિષ્ફળ પ્રયત્ન;
• 'ઘોડી પરથી ઉતરવું' = મૃત્યુ અથવા હારમાનવવી;
• 'હાથમાં લાવવું' = મિલકત બનાવવી;
• 'કાન પકડવા' = નુકસાન કરવું / ધ્યાન ખેંચવું;
• 'ગળામાં દોરી ફેરવી' = નિયંત્રણમાં લેવું;
• 'માથા પર ચઢી જવું' = અતિશય હરકત કરવી;
• 'લાંગ વાળવું' = મદદ કરવી;
• 'પાણી પીણું આપવું' = સંભાળવું;
• 'ચાર ચાબુક ચલાવવી' = ધમકી આપવી;
• 'ઘરની બાબત' = નિજસ્વાર્થ;
• 'એક ને એક' = ચોક્કસ રીતે;
• 'ફાવટમાં' = બિનજરૂરી;
• 'માથા પર માતળી' = શીર્ષ પરનું ભારે દુઃખ;
• 'રોજ રાતે જાગે' = કોઈ કાર્ય માટે સતત તૈયાર રહેવું.

મહત્વની લોકોકતિઓ:
• 'ઠંડા પાણીમાં ઉતરવું' = આકસ્મિક સંકટમાં ફસાવવા;
• 'ચૂંદડી વડે ચાકુ કાઢવો' = નિષ્ફળ પ્રયત્ન;
• 'ચાંદાની ચોકલી ચાવવી' = અકામ્ય કામ;
• 'બારીએ માછલી' = વહેમ;
• 'એકાદ વાતનું નામ કરવું' = કોઈ વિશેષ મહત્વનો ઉલ્લેખ;
• 'ઘણી વાર ઝાડનાં બાળક' = સતત આરામ;
• 'ઘર-અઘર' = સ્વજન/પરજન સહિતનાં લોકો.

પરીક્ષામાં ઘણીવાર 'રૂઢિપ્રવાહ + સાચો અર્થ' ની જોડી આપીને ભૂલની શોધ કરવાની હોય છે. એટલે બધાની સાચી-ખોટી જોડી યાદ રાખવી જરૂરી છે.

૬. અધિકરણ / ભૂલો — શબ્દોની સાચી રચના અને વપરાશ

અધિકરણ એટલે એવા શબ્દો કે જે ઘોંઘાટ પાડે અથવા સાચા પ્રમાણમાં વપરાતા ન હોય. પરીક્ષામાં ઘણીવાર સાચું/ખોટું શબ્દ પસંદ કરવાનો પ્રશ્ન આવે છે.

મહત્વની અધિકરણો:
• 'જાહેર' (સાચું) ≠ 'જોહર' (ખોટું)
• 'આરામ' (સાચું) ≠ 'આરામ' માં અઁહુમ
• 'ગ્રહણ' (સાચું) ≠ 'ગ્રહ' (અલગ અર્થ)
• 'તેમજ' (સાચું) ≠ 'તેમર' / 'તેમ' (ખોટું)
• 'સ્વાભાવિક' (સાચું) ≠ 'સ્વાભાવિક' મધ્યે અન્ય પ્રાયોગિક ભૂલો
• 'શુભ' (સાચું) ≠ 'શુદ્ધ' (અલગ અર્થ)
• 'પ્રામાણિક' (સાચું) ≠ 'પ્રામાણિક' ની વચ્ચે નોંધ
• 'સામાન્ય' (સાચું) ≠ 'સામાન્ય' નો વિકલ્પ
• 'અભ્યાસ' (સાચું) ≠ 'અભ્યાસ' નું ભૂલપૂર્વક અન્ય અર્થ
• 'અહીં' (સાચું) ≠ 'અહીં' ની બદલે 'અહીં' નું અન્ય પ્રયોગ

મહત્વના સાધુ શબ્દો:
• 'સંકેત' → ન્યૂનતા નહિ (અલગ અર્થ)
• 'વિભાગ' → વિભાગ = ભાગ;
• 'ઉદ્ધાર' ≠ 'ઉધાર' (એક ઋણ; બીજો રક્ષણ);
• 'અસંભવ' ≠ 'અશક્ય' (બંનેમાં અર્થલક્ષ્મી)
• 'સ્વચ્છંદ' ≠ 'સ્વયંસિદ્ધ' (અલગ અર્થ)
• 'સમય' (સાચું) ≠ 'સમય' માં અન્ય પ્રયોગ

પરીક્ષામાં એક શબ્દ આપેલો હોય અને ચારમાંથી સાચો અર્થ/સાચું પ્રયોગ પસંદ કરવાનો હોય છે. 'અધિકરણ' પ્રશ્નોમાં વિદ્યાર્થીએ બહુચર્ચિત 'જોડાણ' પ્રશ્નો પર ધ્યાન આપવું જોઈએ.

૭. પ્રાચીન/સંસ્કૃત મૂળના શબ્દો અને તેમનો ગુજરાતીમાં ઉપયોગ

ગુજરાતી શબ્દકોશમાં સંસ્કૃત મૂળના શબ્દોનો ઘણો ઉપયોગ છે. આ શબ્દો પરીક્ષામાં ઘણી વાર આવે છે. તેમના સમાનાર્થી, વિરોધી અને એક-શબ્દ-પ્રત્યાસદ રૂપે પણ પ્રશ્નો આવે છે.

મહત્વના સંસ્કૃત-મૂળના શબ્દો:
• અહંકાર → ગર્વ / આત્મગર્વ
• અહિંસા → અપાતપાત / નિર્દોષતા
• અભ્યુદય → ઉન્નતિ / કલ્યાણ
• અભિલાષા → ઇચ્છા / ઈષ્ટ
• અમૃત → અક્ષય / નિર્વાણ
• અવતાર → દર્શન / રૂપ
• આદર્શ → ઉત્તમ / શ્રેષ્ઠ
• ઈંદ્રિય → પંચ ઇંદ્રિયો
• ઉપદેશ → શિક્ષા / ધરતી
• ઉત્સવ → તહેવાર
• ઋણ → કૃતજ્ઞતા / દેણું
• કરુણા → દયા / મૃદુતા
• કલ્પના → અધ્યારોપ
• ક્ષમા → ક્ષમા / અક્ષય
• ગુરુ → શિક્ષક / આચાર્ય
• સત્ય → યથાર્થ / ઇંદ્રજાળ
• સંસ્કૃતિ → પરંપરા / શિષ્ટાચાર

આ શબ્દોના સમાનાર્થી, વિરોધી અને એક-શબ્દ-પ્રત્યાસદના પ્રશ્નોમાં 'ભાષા', 'ભાષાંતર', 'ભાષાકોશ' અને 'ભાષાશાસ્ત્ર' વિશે પણ પ્રશ્નો આવે છે. આ વિભાગમાં વિદ્યાર્થીએ વ્યુત્પત્તિ પણ ધ્યાનમાં રાખવી જોઈએ.

૮. શબ્દકોશની તૈયારીની રણનીતિ અને પરીક્ષા દૃષ્ટિએ મહત્વના અંશો

ગુજરાત પોલીસ કોન્સ્ટેબલ પરીક્ષામાં શબ્દકોશના પ્રશ્નો મુખ્યત્વે દેખાડી દેવાતી ક્ષમતા જોવા માટેના હોય છે, કોઈ ગાઢ વિશ્લેષણ હોતું નથી. તેથી તૈયારીનો માર્ગ સીધો અને કાર્યક્ષમ હોવો જોઈએ.

પ્રભાવશાળી તૈયારી માર્ગદર્શન:
1. સરળ સૂચિ તૈયાર કરો — સમાનાર્થી, વિરોધી, એક-શબ્દ-પ્રત્યાસદની પોતાની ચારણી બનાવો.
2. દરરોજ ૧૦-૧૫ શબ્દો મનોહર રીતે રટો અને સાંજે પાછા વાંચો.
3. રૂઢિપ્રવાહ અને લોકોકતિઓને જોડીના સ્વરૂપમાં યાદ કરો.
4. અધિકરણ શબ્દોની યાદી ઘડો — ખોટા પ્રયોગોને અલગ સૂચિમાં યાદ કરો.
5. પૂર્વવર્તી પરીક્ષાઓના પ્રશ્નો ઉકેલો — અહીં PYQ-STYLE PRACTICE ફાઈલ વપરાય છે.
6. ચાર વિકલ્પોમાંથી સાચો પસંદ કરવાની તકનીક શીખો — ભૂલ ભરેલા વિકલ્પોને દૂર કરો.
7. 'જોડી શોધ' પ્રશ્નોમાં જ્યાં બે જોડી આપી હોય ત્યાં ચકાસણી કરો.
8. સંસ્કૃત મૂળના શબ્દોની વ્યુત્પત્તિ ધ્યાનમાં રાખો.
9. સમયબંધ પ્રશ્નો ઉકેલો — અડધા ઘંટામાં ૩૦ શબ્દો યાદ કરવાનો અભ્યાસ કરો.
10. મોટે ભાગે 'સંકલ્પ' પ્રશ્નોમાં જોડાણો હોય છે — 'સાચી જોડી' અને 'ખોટી જોડી' બંને પ્રકાર યાદ કરો.

પરીક્ષાના સમયે ધ્યાન રાખવું:
• જ્યાં બે વિકલ્પો એકસરખા દેખાતા હોય ત્યાં બંનેને દૂર કરી શકાય.
• 'એક-શબ્દ-પ્રત્યાસદ' માં અર્થ યોજાયેલો હોય તો બિંદુએ શબ્દ પસંદ કરો.
• રૂઢિપ્રવાહમાં અર્થ યોજાયેલો હોય તો વ્યંગ અર્થ યાદ કરવો.

Important facts

  • શબ્દકોશમાં પાંચ મુખ્ય શ્રેણીઓ હોય છે: સમાનાર્થી, વિરોધાભાસી, એક-શબ્દ-પ્રત્યાસદ, રૂઢિપ્રવાહ/લોકોકતિ અને અધિકરણ.
  • સમાનાર્થી શબ્દોમાં સાધુ અને ભાષા બંને પ્રકારના શબ્દોનો સમાવેશ થાય છે; 'સૂર્ય'ના ૧૦+ સમાનાર્થી શબ્દો યાદ રાખવા જોઈએ.
  • વિરોધાભાસી શબ્દોમાં 'ગ્રહણ-મંગળ' અને 'શુક્ર-શની' જેવી ઘોંઘાટ પાડતી જોડીઓ ધ્યાનમાં રાખવી જરૂરી છે.
  • એક-શબ્દ-પ્રત્યાસદમાં 'ચક્રવર્તી', 'યોદ્ધા', 'અભય', 'નાશક' વગેરે સૌથી વધુ આવતા શબ્દો છે.
  • રૂઢિપ્રવાહનો સાદો અર્થ નહિં પણ વ્યંગાત્મક/ગાઢ અર્થ યાદ રાખવો; 'ચાંદીની ચોકલી ચાવવી' = નિષ્ફળ પ્રયત્ન.
  • અધિકરણ પ્રશ્નોમાં 'જાહેર≠જોહર', 'ઉદ્ધાર≠ઉધાર' જેવી જોડીઓ ઘણી આવે છે.
  • સંસ્કૃત મૂળના શબ્દોની વ્યુત્પત્તિ અને તેમના સમાનાર્થી વિરોધી શબ્દો યાદ રાખવા પડે છે.
  • પરીક્ષામાં 'જોડી શોધ' પ્રશ્નો વધુ આવે છે — સ્પષ્ટ જોડીઓ યાદ રાખવી જરૂરી છે.
  • શબ્દકોશની તૈયારી દરરોજ નિયમિત ૧૦-૧૫ શબ્દોના અભ્યાસથી સરળ બને છે.
