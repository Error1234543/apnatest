ગુજરાતી વ્યાકરણ - સંપૂર્ણ અધ્યયન નોટ્સ

1. અક્ષર અને તેના ભેદ (અક્ષર મહત્વનો વિષય)

ગુજરાતી ભાષામાં કુલ ૪૮ અક્ષરો છે જે બે પ્રકારના હોય છે:

• સ્વર અક્ષરો (૧૧): આ (આ), ઇ (ઇ), ઉ (ઉ), એ (એ), ઐ (ઐ), ઓ (ઓ), ઔ (ઔ), અઽ (અં), અઃ (અઃ). આ ઉપરાંત અ (અ) સ્વાભાવિક સ્વર ગણાય છે.
• વ્યંજન અક્ષરો (૩૭):
- અક્ષરમહેલ: ક, ખ, ગ, ઘ, ઙ (ક-વર્ગ)
- ચ અક્ષરમહેલ: ચ, છ, જ, ઝ, ઞ (ચ-વર્ગ)
- ટ અક્ષરમહેલ: ટ, ઠ, ડ, ઢ, ણ (ટ-વર્ગ)
- ત અક્ષરમહેલ: ત, થ, દ, ધ, ન (ત-વર્ગ)
- પ અક્ષરમહેલ: પ, ફ, બ, ભ, મ (પ-વર્ગ)
- ય બધ્દ અક્ષરમહેલ: ય, ર, લ, વ, શ (ય-વર્ગ)
- સ અર્ધઅક્ષરમહેલ: સ, હ, ળ, ઼ (શ્રી)

મહત્વની વાતો:
- પ્રાચીન ગુજરાતીમાં અનુસ્વાર (અં) અને વિસર્ગ (અઃ) નો ઉપયોગ વધુ હતો.
- ગુજરાતીમાં હ્રસ્વ અને દીર્ઘ સ્વરોનો ભેદ સ્પષ્ટ છે.
- 'અ' સ્વર સર્વ પ્રાકૃત અને સંસ્કૃતના શબ્દોમાં સ્વાભાવિક રીતે આવે છે.

2. સંધિ (પ્રકારો અને ઉદાહરણો)

બે અથવા વધુ અક્ષરોના સંગમેથી નવું અક્ષર ઉત્પન્ન થવાને સંધિ કહે છે. સંધિ મુખ્યત્વે ત્રણ પ્રકારની હોય છે:

૧. સ્વરસંધિ:
- ગુણસંધિ: આ + એ = ઝેડ (ઉદા: દીપ+એળ=દીપેળ)
- વૃદ્ધિસંધિ: આ + આ = આ (ઉદા: પા + આ = પાઆ)
- દીર્ઘસંધિ: અ + આ = આ, એ + એ = એ (ઉદા: રથ+ઇન્દ્ર = રથિન્દ્ર)
- દ્વિત્વસંધિ: અ + અ = અ (ઉદા: તત્ + અહમ્ = તત્અહમ્)
- જટિલસંધિ: ઉ + ઋ = ઊર્ (ઉદા: પુરુષ + ઋષિ = પુરુષર્ષિ)

૨. વ્યંજનસંધિ:
- વિઘાતસંધિ: વિ + ઘાત = વિઘાત
- ઋત્ સંધિ: સ + ત = સ્ત (ઉદા: વિ + તર્ક = વિતર્ક)
- અકારાદિ સંધિ: અ + ક = અક (ઉદા: દેશ + ક = દેશક)

૩. ભાષાંગ સંધિ:
- પ્ વિકાર: તું + પ = તુપ્
- ણિ સંધિ: પા + ણિ = પાણિ
- જશા સંધિ: દે + જ = દેશ
- શઃ સંધિ: કામ + શઃ = કામશઃ
- મ્બ્ સંધિ: ગત + મ્બ્ = ગંભીર

સંધિ કરવાની રીત:
1. વિભક્તિ પ્રત્યયો જોડતા પહેલાં સંધિ કરવી પડે છે.
2. ઋકાર + અકાર = ઊકાર (ઉદા: દુર્ + અભિષેક = દુર્ભિષેક)
3. જ્ઞ વ્યંજન જોડતાં વિઘાત સંધિ થાય છે.
4. સંધિ વિશેષતઃ સંસ્કૃત શબ્દોમાં વધુ જોવા મળે છે.

3. સમાસ (બીજો સૌથી મહત્વનો વિષય)

બે અથવા વધુ શબ્દોના સમૂહમાંથી એક શબ્દ બને તેને સમાસ કહે છે. સમાસ ચાર મુખ્ય પ્રકારના છે:

૧. કર્મધાયી સમાસ:
- ઇતર વિભક્તિ: અર્થાત્ 'જે સમાસમાં પૂર્વપદ સમાસબીજ હોય અને ઉત્તરપદ તેનું વિધેય હોય'
- ઉપપદ તત્પુરુષ: દાદાભાઈ (દાદા + ભાઈ)
- દ્વિગુ: રામ + લક્ષ્મણ = રામાલક્ષ્મણ
- ભાવ સમાસ: ગતિ + ભાવ = ગતિભાવ

૨. તત્પુરુષ સમાસ:
- પહેલાં વિભક્તિ: દેવતુંષ્ય (દેવ + તુષ્ય)
- દ્વિતીયા: નગરવ્યાપાર (નગર + વ્યાપાર)
- ત્રીતીયા: ગાયત્રીમંત્ર (ગાયત્રી + મંત્ર)
- ચતુર્થી: યુદ્ધાયણ (યુદ્ધ + આયણ)
- પંચમી: ગૃહસ્થ (ગૃહ + સ્થ)
-ષષ્ઠી: પુરુષોತ್ತમ (પુરુષ + ઉત્તમ)
- સપ્તમી: ડાકબંગલો (ડાક + બંગલો)

૩. અવ્યयीભાવ સમાસ:
- પ્રાચીન સ્થિતિ: આગળથી જવાબ (આગળ +થી)
- સ્થળસમાસ: બહારથી આવો (બહાર +થી)
- પરિમાણ: ધારાસૂત્ર (ધારા + સૂત્ર)
- સાધન: અક્ષરે લખવું (અક્ષર + એ)

૪. બહુવ્રીહી સમાસ:
- ધનુષ્કાંત (ધનુષ + કાંત)
- જ્યોતિર્લિંગ (જ્યોતિ + લિંગ)
- રક્તપંખ (રક્ત + પંખ)
- પૃથુફળ (પૃથુ + ફળ)

ઉપયોગી યાદરૂપ:
- કારક + વિભક્તિ = સમાસનો પ્રકાર
- તત્પુરુષમાં તત્પુરુષ શબ્દો વધુ પ્રચલિત છે
- બહુવ્રીહીમાં સમાસબીજ સાધારણ રીતે વર્ણનાર્થ હોય છે

4. કારક અને વિભક્તિ

કારક: કોઈ શબ્દના અર્થથી જોડાયેલું સંબંધ દર્શાવતું પદ કારક કહે છે.

કારકના ૭ પ્રકાર:

૧. કર્તૃકારક: જે કાર્ય કરે છે તે કર્તા હોય છે.
ઉદા: રામ ગયો. (રામ = કર્તૃ)

૨. કર્મકારક: જે ઉપર કૃત્ય થાય છે તે કર્મ હોય છે.
ઉદા: રામે ફળ ખાધું. (ફળ = કર્મ)

૩. કર્તાવધારણ કારક: કર્તા સાથે જોડાયેલું અવભાસન કારક.
ઉદા: રામ ગયો હતો.

૪. કાળકારક: સમય દર્શાવતું કારક.
ઉદા: ગઈકાલે તે આવ્યો હતો.

૫. સાધનકારક: કૃત્ય માટે વપરાતું સાધન.
ઉદા: ખલિયો કાતરીથી કાપ્યો.

૬. સમ્બંધકારક: સંબંધ દર્શાવતું કારક.
ઉદા: પુસ્તક બહાર છે.

૭. અધિકરણકારક: સ્થળ દર્શાવતું કારક.
ઉદા: મેજ ઉપર પુસ્તક છે.

વિભક્તિ: વિભક્તિ પ્રત્યયના ચાર પ્રકાર:
- પ્રથમા: અ, ને (સમાસમાં)
- દ્વિતીયા: ને, એ (કર્મ દર્શાવે છે)
- ત્રીતીયા: એ, દ્વારા, સાથે (કારક દર્શાવે છે)
- ચતુર્થી: ને (લક્ષ્ય દર્શાવે છે)
- પંચમી: થી (ઉત્પત્તિ/કારણ)
- ષષ્ઠી: નું, ની, ના (સંબંધ)
- સપ્તમી: માં, પર, ઉપર (સ્થળ)

મહત્વની વાત: કારક અને વિભક્તિમાં ઘણો સંબંધ છે. કારક દર્શાવતો પદ વિભક્તિ પ્રત્યય ધરાવે છે.

5. પ્રત્યય (પ્રકારો અને ઉદાહરણો)

પ્રત્યય શબ્દમાં જોડાઈને નવો અર્થ આપે છે. ગુજરાતીમાં પ્રત્યય મુખ્યત્વે બે પ્રકારના હોય છે:

૧. નામ પ્રત્યય (અધ્યાહરો):
- પુત્રી (પુત્ર + ઈ = વહુ)
- સુંદરતા (સુંદર + તા = ગુણ)
- રામણિયો (રામ + ણિયો = સંબંધ)
- ગાઢત (ગાઢ + ત = ધાતુ)
- પ્રેમી (પ્રેમ + ઈ = વ્યક્તિ)
- વિક્રેતા (વિક્રે + તા = કર્તા)
- સહકારી (સહ + કાર + ઈ)

૨. ક્રિયા પ્રત્યય (વિશેષણ પ્રત્યય):
- કરે છે (કર + છે)
- કરી રહ્યો (કર + ઈ + રહ્યો)
- કર્યું (કર + યું)
- કરવું (કર + વું)

અધિક પ્રત્યયો:
- પાકતો = પાક + તો (કર્તા)
- બાંધ્યો = બાંધ + યો (ભૂતકાળ)
- ભાંગી ગયો = ભાંગી + ગયો (વિભક્તિ)

મહત્વના પ્રત્યયો અને તેના અર્થ:
- ઈ (સ્ત્રીલિંગ): સુંદરી, ગાયિકા
- તા (ભાવ): સુંદરતા, ગાયિકા
- ણો (કર્તા): ભાવ ણો, પાક ણો
- ત્ર (કર્તૃ): કર્તૃ, વિક્રેતા
- પત્ર (પત્ર): વાર્તા, ગાથા

મિશ્ર પ્રત્યયો:
- ઘેર + આવ્યો = ઘેરથી આવ્યો
- શહેર + જવું = શહેરવું

નિયમ: પ્રત્યય જોડતાં શબ્દાંતનું અકાર આગળ ઋકાર હોય તો સંધિ થાય છે.
ઉદા: દે + ણ = દેણ

6. શબ્દબદલી અને સમાસના અન્ય પ્રકારો

શબ્દબદલી: એક શબ્દમાંથી બીજો શબ્દ બનાવવાની પ્રક્રિયા શબ્દબદલી કહે છે.

મુખ્ય શબ્દબદલીના પ્રકારો:
- પરોક્ષ શબ્દબદલી: ઉદા. અગરબત્તી (અગર + બત્તી)
- સમુદાય શબ્દબદલી: ઉદા. દાદાભાઈ (દાદા + ભાઈ)

અન્ય મહત્વના વિષયો:

અલંકારો (સાહિત્યમાં):
- ઉત્પ્રેક્ષા: વરસાદના કાળમાં ઘરમાં રહીને ખુશ થવું
- રૂપક: ચંદ્રાવતાર = ચંદ્ર જેવો
- ઉપમા: સુંદર ચહેરો (ચંદ્ર જેવો)
- રસ: શૃંગાર, કરુણ, વીર, રાસ, અદ્ભુત, ભયંકર, વીભત્સ, શાંત

શબ્દપ્રકારો:
- સરળ શબ્દ: જેમાં કોઈ પ્રત્યય ન હોય
- સંયુક્ત શબ્દ: બે કે વધુ શબ્દોનો સમૂહ
- સંધિ શબ્દ: સંધિ દ્વારા બન્યો શબ્દ
- વિભક્ત શબ્દ: વિભક્તિ પ્રત્યય ધરાવતો શબ્દ

વાક્ય પ્રકારો:
- સરળ વાક્ય: એક ક્રિયાપદ ધરાવતું
- સંયુક્ત વાક્ય: બે કે વધુ સરળ વાક્યનો સમૂહ
- સંકીર્ણ વાક્ય: એક આધીન વાક્ય + એક સ્વતંત્ર વાક્ય

વિશેષતાઓ:
- સામાન્ય રીતે ગુજરાતીમાં વિશિષ્ટા પ્રયોગ વધુ હોય છે.
- અનુક્રમણિકા પ્રકારે શબ્દોનું વિભાજન કરી શકાય છે.
- પ્રત્યયો જોડતાં ધ્યાન રાખવું: પ્રત્યયોની ઉચ્ચારણા અને અર્થ

7. સરબદ્ધ પ્રકારો અને સાદૃશ્ય પ્રકારો

સરબદ્ધ પ્રકારો:

સરબદ્ધ એટલે બે અથવા વધુ શબ્દોના સંયોગથી બનતો સમાસ.

૧. કર્મધાઇ સરબદ્ધ:
- પૂર્વ પદ સમાસબીજ અને ઉત્તર પદ વિધેય:
ઉદા: રામાલક્ષ્મણ (રામ + લક્ષ્મણ = રામને લક્ષ્મણ)

૨. વિશેષણ સરબદ્ધ:
- ઉત્તર પદ સમાસબીજ:
ઉદા: રાત્રિભર (રાત્રિ + ભર = સમગ્ર રાત્રિ)

૩. તત્પુરુષ સરબદ્ધ:
- ઉત્તર પદ સમાસબીજ અને પૂર્વ પદ વિધેય:
ઉદા: નગરવ્યાપાર (નગર + વ્યાપાર = નગરનો વ્યાપાર)

૪. અવ્યयीભાવ સરબદ્ધ:
- પ્રાચીન સ્થિતિ દર્શાવે છે:
ઉદા: આગળથી (આગળ +થી)

સાદૃશ્ય પ્રકારો:

૧. સમાન સાદૃશ્ય:
- શબ્દોની ઉચ્ચારણા સમાન હોય:
ઉદા: ગાંધી - ગાંડી

૨. વિષમ સાદૃશ્ય:
- શબ્દોની ઉચ્ચારણા વિષમ હોય:
ઉદા: કાળું - કાળી

૩. અર્થ સાદૃશ્ય:
- શબ્દોના અર્થમાં સમાનતા હોય:
ઉદા: સ્વચ્છ - પવિત્ર

મહત્વની યાદ અંગે:
- સરબદ્ધમાં સંધિનિયમોનું પાલન કરવું આવશ્યક છે.
- સાદૃશ્ય શબ્દોમાં શબ્દાંતનો ભેદ જાળવવો જોઈએ.

8. વ્યાકરણના મહત્વના નિયમો

શબ્દની સરળતા:
ગુજરાતીમાં શબ્દોની સરળતાના મુખ્ય નિયમો:

૧. સ્વરસંધિ નિયમ:
- અકાર + અકાર = ઍકાર (ઉદા: રથ + ઇન્દ્ર = રથિન્દ્ર)
- ઉકાર + ઋકાર = ઊકાર (ઉદા: પુરુષ + ઋષિ = પુરુષર્ષિ)
- એકાર + અકાર = ઐકાર (ઉદા: ગાય + એક = ગાયેક)

૨. વ્યંજન સંધિ નિયમ:
- ઱કાર આગળ તકાર = સ્ત (ઉદા: વિ + તર્ક = વિતર્ક)
- જકાર આગળ ક = ઙ (ઉદા: દે + જ = દેશ)
- નકાર આગળ નકાર = ન્ણ (ઉદા: ગત + ન = ગન્ન)

૩. સમાસ નિયમો:
- કર્મધાઇ સમાસમાં: પૂર્વ પદ સમાસબીજ, ઉત્તર પદ વિધેય
- તત્પુરુષ સમાસમાં: ઉત્તર પદ સમાસબીજ, પૂર્વ પદ વિધેય
- અવ્યयीભાવ સમાસમાં: પ્રાચીન સ્થિતિ દર્શાવે
- બહુવ્રીહી સમાસમાં: સમાસબીજ વર્ણનાર્થ

૪. કારક નિયમો:
- કર્તાકારક: કાર્ય કરનાર
- કર્મકારક: કૃત્યના ઉપર
- સાધનકારક: કૃત્ય માટે સાધન
- કાળકારક: સમય દર્શાવે
- સમ્બંધકારક: સંબંધ દર્શાવે
- અધિકરણકારક: સ્થળ દર્શાવે

૫. વિભક્તિ નિયમો:
- પ્રથમા: અ, ને (સમાસમાં)
- દ્વિતીયા: ને, એ (કર્મ)
- ત્રીતીયા: એ, દ્વારા, સાથે (કારક)
- ચતુર્થી: ને (લક્ષ્ય)
- પંચમી: થી (ઉત્પત્તિ)
- ષષ્ઠી: નું, ની, ના (સંબંધ)
- સપ્તમી: માં, પર, ઉપર (સ્થળ)

મહત્વની વાત:
- સંધિ કરતાં ધ્યાન રાખવું કે અકારાંત શબ્દોમાં અકાર લોપ થાય છે.
- સમાસમાં સંધિ વિના પણ શબ્દો જોડી શકાય છે.
- કારક-વિભક્તિ સાથે ક્રિયાપદનો સંબંધ જોવો જરૂરી છે.

9. અનુવાદ અને ભાષાંતર

અનુવાદ: અંગ્રેજી અથવા સંસ્કૃતમાંથી ગુજરાતીમાં અથવા વિપરીત અનુવાદ કરવાની કૌશલ્ય.

મહત્વના નિયમો:

૧. શબ્દભેદ:
- અંગ્રેજી -> ગુજરાતી: શબ્દોનો અર્થ સાચવવો અને ગુજરાતી શબ્દ પ્રયોગ કરવો.
- ઉદા: Library -> પુસ્તકાલય

૨. વાક્ય રચના:
- ગુજરાતીમાં વાક્યની રચના અલગ હોય છે: કર્તા + કર્મ + ક્રિયા
- અંગ્રેજીમાં: Subject + Object + Verb

૩. સામાન્ય ભૂલો:
- સંસ્કૃત શબ્દોનો ગુજરાતી અનુવાદ કરતી વખતે શબ્દોની ઉચ્ચારણામાં ભૂલ.
- વિગ્રહ શબ્દોનો અનુવાદ કરતી વખતે અર્થભંગ.

ઉદાહરણો:
- English: He is reading a book. -> ગુજરાતી: તે પુસ્તક વાંચી રહ્યો છે.
- English: The boy is playing in the garden. -> ગુજરાતી: છોકરો બગીચામાં રમી રહ્યો છે.

અનુવાદની વ્યવસ્થા:
1. મૂળ શબ્દો સમજો.
2. સાચો ગુજરાતી શબ્દ શોધો.
3. વાક્ય રચના સાચી રાખો.
4. અર્થમાં ભંગ ન આવે તે ધ્યાન રાખો.

સંસ્કૃત->ગુજરાતી:
- सूर्य = સૂર્ય (અર્થ: સૂર્ય)
- चन्द्र = ચંદ્ર (અર્થ: ચંદ્ર)
- पुस्तक = પુસ્તક (અર્થ: પુસ્તક)

10. મહત્વની વ્યાકરણ ભૂલો અને ત્રુટિઓ

સામાન્ય ભૂલો:

૧. સંધિ ભૂલો:
- અકારાંત શબ્દોમાં અકાર લોપ ન થવો.
ઉદા: દે + મંદિર = દેમંદિર (સાચું), દે + મંદિર = દેમંદિર (ખોટું)

૨. સમાસ ભૂલો:
- કારક-વિભક્તિનું ધ્યાન ન રાખવું.
ઉદા: રામનાં પુસ્તક (ખોટું), રામનું પુસ્તક (સાચું)

૩. વિભક્તિ ભૂલો:
- ક્રિયાપદ સાથે વિભક્તિ મેળ ન ખાવો.
ઉદા: તે જાય છે (સાચું), તે જાય (ખોટું)

૪. પ્રત્યય ભૂલો:
- પ્રત્યય જોડતાં અકાર લોપ ન થવો.
ઉદા: પુત્રી (સાચું), પુત્રી (ખોટું - પુત્ર + ઈ = પુત્રી)

૫. સરબદ્ધ ભૂલો:
- સમાસમાં વિગ્રહ ન કરવો.
ઉદા: ગાયક (સાચું), ગાય (ખોટું - ગા + યક = ગાયક)

મહત્વની યાદ અંગે:
- સંધિ: અકારાંત શબ્દોમાં અકાર લોપ થાય છે.
- સમાસ: વિગ્રહ કરીને સમાસનો પ્રકાર શોધવો.
- વિભક્તિ: કારક મુજબ વિભક્તિ પ્રત્યય યોગ્ય હોય.
- પ્રત્યય: પ્રત્યય જોડતાં શબ્દાંતમાં ફેરફાર થાય છે.
- સરબદ્ધ: વિગ્રહ કરીને અર્થ સમજવો.

Important facts

  • ગુજરાતીમાં કુલ ૪૮ અક્ષરો: ૧૧ સ્વર + ૩૭ વ્યંજન
  • સંધિ ત્રણ પ્રકારની: સ્વરસંધિ, વ્યંજનસંધિ, ભાષાંગ સંધિ
  • સમાસ ચાર પ્રકારના: કર્મધાઇ, તત્પુરુષ, અવ્યयीભાવ, બહુવ્રીહી
  • કારક સાત પ્રકારના: કર્તૃ, કર્મ, કાળ, સાધન, સમ્બંધ, અધિકરણ, કર્તાવધારણ
  • વિભક્તિ સાત પ્રકારની: પ્રથમા, દ્વિતીયા, ત્રીતીયા, ચતુર્થી, પંચમી, ષષ્ઠી, સપ્તમી
  • પ્રત્યય બે પ્રકારના: નામ પ્રત્યય અને ક્રિયા પ્રત્યય
  • પ્રાચીન સંધિમાં ઋકાર + અકાર = ઊકાર થાય છે
  • કર્મધાઇ સમાસમાં પૂર્વ પદ સમાસબીજ અને ઉત્તર પદ વિધેય હોય છે
  • તત્પુરુષ સમાસમાં ઉત્તર પદ સમાસબીજ અને પૂર્વ પદ વિધેય હોય છે
  • બહુવ્રીહી સમાસમાં સમાસબીજ વર્ણનાર્થ હોય છે
  • શબ્દબદલીમાં વિગ્રહ શબ્દોનો અનુવાદ કરતી વખતે અર્થભંગ ન થાય તે ધ્યાન રાખવું
  • ગુજરાતી વ્યાકરણમાં ક્રિયાપદ કર્તા સાથે મેળ ખાવું આવશ્યક છે
