Blood Relations — ધોરણેરી મિત્રતા (ગુજરાતી)

Gujarat Police ConstableGujaratiNotes

મૂળભૂત પરિચય અને સંબંધ શબ્દાવલી

Blood Relations (ધોરણેરી મિત્રતા) એ તર્કશક્તિના એક મહત્વપૂર્ણ અધ્યાય છે, જેમાં ઉમેડવારને કોઈ વ્યક્તિ અથવા પાત્ર વિશે આપેલા વિવરણો પરથી તે વ્યક્તિનું આપણી સાથેનું સંબંધ શોધવાનું હોય છે. આ પ્રકારના પ્રશ્નો સરળ દેખાતા હોય છે, પણ ગંભીરતાથી ધ્યાન અને પદ્ધતિ જરૂરી છે.

સંબંધ શબ્દોની ચોકસાઈ:
• પિતૃ (Father) — પિતા
• માતૃ (Mother) — માતા
• પુત્ર (Son) — પુત્ર
• પુત્રી (Daughter) — પુત્રી
• ભાઈ (Brother) — ભાઈ (પુરુષ)
• બહેન (Sister) — બહેન (સ્ત્રી)
• પતિ (Husband) — પતિ
• પત્ની (Wife) — પત્ની
• મામા (Mother's brother) — મામા
• કાકા (Father's brother) — કાકા
• પિતરો (Father's father) — પિતામહ / નાના
• માતાશ્રી (Mother's mother) — માતામહી / આવી
• મاما (Mother's husband) — મમા (મામાનો પતિ)
• સાસુ (Husband's mother) — સાસુ
• સસરા (Husband's father) — સસરા
• નણંદ (Husband's sister) — નણંદ
• દેવર (Wife's brother) — દેવર
• ભાભી (Brother's wife) — ભાભી
• સાસુ (Wife's mother) — સાસુ
• ચચેર ભાઈ / બહેન (Cousin) — ચચેર ભાઈ / બહેન
• પોતીયો (Son's son) — પોતે / પૌત્ર
• પોતીયું (Son's daughter) — પોતીયું / પૌત્રી
• નણન્દ (Brother's daughter) — નણન્દ
• ભત્રીજો (Sister's/Mother's son) — ભત્રીજો
• ભત્રીજી (Sister's/Mother's daughter) — ભત્રીજી
• દોહિત્રો (Daughter's son) — દોહિત્રો
• દોહિત્રી (Daughter's daughter) — દોહિત્રી

મહત્વનું: 'પિતામહ' = પિતાના પિતા; 'પિતામહી' = પિતાની માતા; 'માતામહ' = માતાના પિતા; 'માતામહી' = માતાની માતા. આ યાદ રાખવું ખૂબ જરૂરી છે.

સંબંધ સમસ્યાઓના પ્રકાર

ગુજરાત પોલીસ કોન્સ્ટેબલ પરીક્ષામાં Blood Relations ના પ્રશ્નો મુખ્યત્વે બે પ્રકારના આવે છે:

1. સીધા સંબંધ પ્રશ્નો (Direct Relationship Questions):
ઉદાહરણ: "A છે B નો પુત્ર. B છે C ની પત્ની. A, C નું શું છે?"
ઉકેલ: A, C નો પુત્ર છે. જવાબ: A છે C નો પુત્ર.
આ પ્રશ્નોમાં માત્ર સીધા સંબંધો સાબિત કરવાના હોય છે.

2. સંકેતીય / કોડિંગ પ્રશ્નો (Coded Blood Relation Questions):
ઉદાહરણ: 'A + B' નો અર્થ A છે B નો પુત્ર, 'A − B' નો અર્થ A છે B ની પત્ની. 'A × B' નો અર્થ A છે B નો ભાઈ. P + Q − R × S એટલે શું?"
આ પ્રશ્નોમાં સંકેતોને અનુવાદિત કરવાના અને ત્યારબાદ સંબંધ શોધવાના હોય છે.

3. પરિવાર વૃક્ષ (Family Tree) પ્રશ્નો:
એક વધુ સંરચિત પ્રશ્ન હોય છે જેમાં કંઈક એક વ્યક્તિનું વર્ણન હોય છે, જેમ કે: "એક વ્યક્તિ કહે છે કે મારા પિતાની એકલી પુત્રી મારી માતા છે. મારા પિતાનું શું નામ છે?" આ પ્રકારના પ્રશ્નોમાં પગલું-દર-પગલું વિચારવું જરૂરી છે.

ઉકેલ પદ્ધતિઓ અને સ્પાર્ટ ટેક્નિક

Blood Relations પ્રશ્નો ઉકેલવા માટેની મુખ્ય પદ્ધતિઓ:

પદ્ધતિ 1: પરિવાર વૃક્ષ (Family Tree) બનાવવું:
• દરેક વ્યક્તિને ચિહ્નથી દર્શાવો — પુરુષ માટે □ અને સ્ત્રી માટે ○
• સંબંધ દર્શાવવા માટે તીરો અને રેખાઓ બધા.
• સાવચેત રહો: ભાઈ-બહેન દર્શાવવા માટે સમાંતર રેખા અને સ્ત્રી/પુરુષ ચિહ્ન ધ્યાનથી.

ઉદાહરણ: A છે B નો પુત્ર, B છે C ની પત્ની. A, C નું શું?
→ C → (માતા) → B → (પુત્ર) → A → તેથી A છે C નો પુત્ર.

પદ્ધતિ 2: પ્રશ્નમાંથી વ્યક્તિનું લક્ષણ જાણવું:
• ઘણીવાર પ્રશ્ન એક ચોક્કસ વ્યક્તિ પરથી શરૂ થાય છે. જેમ: "A કહે છે કે..." — તેથી A ને કેન્દ્ર માનીને આગળ વધવું.
• પ્રશ્નમાં જો "મને લાગે છે કે..." હોય તો પણ આ પ્રકારના પ્રશ્નોમાં સીધું જવાબ લખી શકાય.

સ્પાર્ટ ટેક્નિક:
• મહિલા-પુરુષ સંબંધોને ધ્યાનમાં લો — જવાબમાં લિંગ (પુરુષ/સ્ત્રી) સાચું હોવું જોઈએ.
• ઘણા પ્રશ્નોમાં 'એકમાત્ર પુત્ર/એકમાત્ર પુત્રી' જેવા શબ્દો હોય છે, જેનો અર્થ થાય છે કે અન્ય કોઈ ભાઈ/બહેન નથી.
• 'પિતરો', 'કાકા', 'મામા', 'મમા' વચ્ચેનો તફાવત યાદ રાખો.

મહત્વપૂર્ણ નોટ્સ — સંબંધ શબ્દોના વિસ્તૃત અર્થ

અહીં પ્રત્યેક મહત્વપૂર્ણ સંબંધ શબ્દનો વિગતવાર અર્થ આપ્યો છે:

પિતૃ સંબંધ:
• પિતાના ભાઈ = કાકા (Chacha)
• પિતાની બહેન = પિતાની બહેન = તایی / તાઈ (Mami / Phupha)
• કાકાનું પત્ની = કાકી
• તૈયનું પતિ = તાઈ / મમા

માતા સંબંધ:
• માતાના ભાઈ = મામા
• માતાની બહેન = ખાલુ / મاما (Tata / Kaka)
• મામાનું પત્ની = મમા
• ખાલુનું પતિ = ખાલા

પાછલા સંબંધ:
• પોતે (Son's son) = પૌત્ર
• પોતીયું (Son's daughter) = પૌત્રી
• દોહિત્રો (Daughter's son) = દોહિત્રો
• દોહિત્રી (Daughter's daughter) = દોહિત્રી
• ભત્રીજો (Sister's son) = ભત્રીજો
• ભત્રીજી (Sister's daughter) = ભત્રીજી

અન્ય સંબંધ:
• નણંદ (Brother's wife) = ભાભી
• દેવર (Wife's brother) = સાળો
• સાળી (Wife's sister) = નણંદ
• ચચેર ભાઈ/બહેન = પિતરો/કાકો/મામા/ખાલુનો પુત્ર/પુત્રી

વ્યાયામ અને ઉદાહરણો

ઉદાહરણ 1: A છે B નો પુત્ર. B છે C ની પત્ની. C છે D નો પિતા. D છે E નો પુત્ર. A, E નું શું છે?
ઉકેલ: E → D → (પિતા) → C → (પત્ની) → B → (પુત્ર) → A. તેથી A, E નો ભત્રીજો / પુત્ર છે. જવાબ: A છે E નો પુત્ર.

ઉદાહરણ 2: X ને Y ની પત્ની છે. Z છે Y નો પુત્ર. W છે Z ની માતા. W, X નું શું છે?
ઉકેલ: W → (માતા) → Z → (પત્ની) → Y → (પતિ) → X. તેથી W, X ની સાસુ છે.

ઉદાહરણ 3: એક વ્યક્તિ કહે છે કે "મારા પિતાના પુત્રની પત્ની મારી નણંદ છે." તે વ્યક્તિનું શું છે?
ઉકેલ: પિતાના પુત્ર = ભાઈ. ભાઈની પત્ની = ભાભી. વ્યક્તિ કહી રહ્યો છે કે તેની નણંદ ભાભી છે → તે પોતે પતિ છે. તેથી વ્યક્તિ પતિ છે.

ઉદાહરણ 4: પૂર્વી કહે છે, "આ છોકરાનો પિતા મારા પિતાનો એકમાત્ર પુત્ર છે." આ છોકરાનો પિતા કોણ છે?
ઉકેલ: પૂર્વીના પિતાનો એકમાત્ર પુત્ર = પૂર્વીનો ભાઈ. છોકરાનો પિતા = પૂર્વીનો ભાઈ. તેથી છોકરો પૂર્વીનો ભત્રીજો છે. જવાબ: પૂર્વીનો ભત્રીજો.

ઉદાહરણ 5: A + B = A છે B નો પુત્ર. A − B = A છે B ની પત્ની. A × B = A છે B નો ભાઈ. P + Q − R × S એટલે શું?
ઉકેલ: Q − R → Q છે R ની પત્ની. P + Q → P છે Q નો પુત્ર. R × S → R છે S નો ભાઈ. તેથી P, Q નો પુત્ર, Q, R ની પત્ની, R, S નો ભાઈ. P, S નો પૌત્ર છે (ભાભીનો પુત્ર).

સામાન્ય ભૂલો અને ટાળવાની વાતો

Blood Relations માં ઉમેડવારો જે ભૂલો કરે છે:

1. સંબંધ શબ્દોના અર્થમાં ગૂંચવણ:
• 'પિતરો' અને 'માતાશ્રી' વચ્ચેનો તફાવત ન યાદ રાખવો.
• 'કાકા' અને 'મામા' વચ્ચેનો તફાવત ભૂલવો.

2. લિંગ (પુરુષ/સ્ત્રી) નું ધ્યાન ન રાખવું:
• ઉદાહરણ: જો જવાબ 'પુત્ર' હોય, પણ વિકલ્પમાં 'પુત્રી' હોય તો પણ વિકલ્પ પસંદ કરી નાખવો.

3. 'એકમાત્ર' શબ્દને અવગણવો:
• જો પ્રશ્નમાં 'એકમાત્ર પુત્ર' હોય તો તેનો અર્થ એ છે કે ભાઈ/બહેન નથી. આ વાત ધ્યાનમાં લેવી.

4. 'અન્ય' સંબંધો ભૂલવો:
• નણંદ, દેવર, સાસુ, સસરા, ભાભી, સાળો, સાળી — આ બધા શબ્દોનો અર્થ સ્પષ્ટ હોવો જોઈએ.

5. પરિવાર વૃક્ષમાં લિંગ ચિહ્નો ભૂલવા:
• પુરુષ માટે □ અને સ્ત્રી માટે ○ — આ ચિહ્નો સાચા રાખવા. જો ભૂલથી ઉલટું કરી દે તો જવાબ ખોટો આવે.

6. કોડિંગ પ્રશ્નોમાં સંકેતોનો ક્રમ ભૂલવો:
• દરેક સંકેતને અનુવાદિત કર્યા પછી જ વિચારવો.

7. પ્રશ્નના અંતમાં 'શું છે?' પૂછે છે તો પણ જવાબમાં 'છે' ન લખવું — માત્ર સંબંધ જણાવવો.

મહત્વના મુદ્દા અને પરીક્ષા-કેન્દ્રિત નોટ્સ

પરીક્ષાના દૃષ્ટિકોણથી ધ્યાનમાં રાખવા worthy મુદ્દા:

• સરવાળો સમય: પ્રશ્નો 1-2 મિનિટમાં ઉકેલવા. તેથી પરિચય ઝડપી હોવો જોઈએ.
• 3-4 પ્રશ્નો આ અધ્યાય પરથી આવે છે.
• સૌથી વધુ આવતા સંબંધો: મામા, કાકા, નણંદ, ભાભી, સાસુ, સસરા, પૌત્ર, પૌત્રી, ભત્રીજો, ભત્રીજી.
• કોડિંગ પ્રશ્નોમાં સૌથી વધુ +, −, × સંકેતો વાપરવામાં આવે છે.
• પરિવાર વૃક્ષ બનાવવાની પદ્ધતિ સૌથી વધુ ફાયદાકારક છે.
• 'એકમાત્ર' અને 'ફક્ત' જેવા શબ્દો પર ખાસ ધ્યાન રાખવું.
• પરીક્ષામાં આંકડાકીય રીતે 85%+ પ્રશ્નો સીધા આવે છે — વધુ સરળ.
• ગુજરાત પોલીસ કોન્સ્ટેબલ પરીક્ષામાં પદ્ધતિઓ અને સંબંધો પર આધારિત પ્રશ્નો 15-20% વિસ્તાર ધરાવે છે.

વિદ્યાર્થીઓ માટે સૂચનો અને તૈયારીની ર્ણામત્મક યોજના

Blood Relations માં સારા અંક મેળવવા માટેની યોજના:

1. શબ્દાવલી યાદ કરવી:
• દરરોજ 10-15 સંબંધ શબ્દોનો અર્થ યાદ કરો.
• કાગળ પર પરિવાર વૃક્ષ બનાવીને અભ્યાસ કરો.

2. રોજિંદી વ્યાયામ:
• દરરોજ 5-10 પ્રશ્નો ઉકેલો.
• વિવિધ પ્રકારના પ્રશ્નો (સીધા, કોડિંગ, પરિવાર વૃક્ષ) ઉકેલો.

3. ઝડપ વધારવી:
• સમયમર્યાદામાં પ્રશ્નો ઉકેલવાનો પ્રયાસ કરો.
• સંકેતો અને ચિહ્નો યાદ કરવાનો અભ્યાસ કરો.

4. ભૂલો ઓળખવી અને સુધારવી:
• ખોટા જવાબો પર વિચાર કરો.
• કયા પ્રકારના પ્રશ્નોમાં ભૂલ થાય છે તે નોંધો.

5. પરીક્ષા પૂર્વ:
• તમામ સંબંધ શબ્દોની યાદી તૈયાર રાખો.
• 20-30 પ્રશ્નો ઉકેલીને તૈયારી કરો.
• મુખ્યત્વે કોડિંગ પ્રશ્નો પર ધ્યાન આપો.

6. સંપૂર્ણ તૈયારી:
• પૂર્વ પરીક્ષાઓ ઉકેલો.
• સમયમર્યાદામાં ઉકેલવાનો અભ્યાસ કરો.
• વધુ સંકટ પ્રશ્નો ઉકેલો.

Important facts

  • પિતાના ભાઈ = કાકા; માતાના ભાઈ = મામા; પિતાની બહેન = તૈય; માતાની બહેન = ખાલુ.
  • પોતે = પુત્રનો પુત્ર (પૌત્ર); પોતીયું = પુત્રની પુત્રી (પૌત્રી).
  • દોહિત્રો = પુત્રીનો પુત્ર; દોહિત્રી = પુત્રીની પુત્રી.
  • નણંદ = ભાઈની પત્ની (ભાભી); દેવર = પત્નીનો ભાઈ (સાળો).
  • સાસુ = પતિની માતા; સસરા = પતિના પિતા.
  • કોડિંગ પ્રશ્નોમાં સંકેતોને અનુવાદિત કરીને પરિવાર વૃક્ષ બનાવવું.
  • 'એકમાત્ર પુત્ર' = ભાઈ/બહેન નથી; 'એકમાત્ર પુત્રી' = ભાઈ/બહેન નથી.
  • પરીક્ષામાં Blood Relations થી 3-4 પ્રશ્નો આવે છે, મુખ્યત્વે સીધા અને કોડિંગ પ્રકારના.
  • લિંગ (પુરુષ/સ્ત્રી) નું ધ્યાન રાખવું — જવાબમાં લિંગ સાચું હોવું જોઈએ.
  • ગુજરાત પોલીસ કોન્સ્ટેબલ પરીક્ષામાં આ વિષય પર 15-20% પ્રશ્નો આવે છે.
