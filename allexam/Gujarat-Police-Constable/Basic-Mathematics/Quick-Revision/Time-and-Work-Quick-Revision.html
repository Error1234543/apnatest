સમય અને કાર્ય - ક્વિક રિવિઝન

Gujarat Police ConstableGujaratiQuick Revision

Definitions

  • કાર્ય (Work): કાર્ય એટલે કરવાની કુલ હિલચાલ અથવા સફળતાપૂર્વક પૂરું કરેલું કામ. સામાન્ય રીતે એક યોજના કે પ્રોજેક્ટ ને 1 એકમ કાર્ય ગણવામાં આવે છે.
  • સમય (Time): કાર્ય પૂર્ણ કરવામાં લાગતો કુલ સમય. આંતરરાષ્ટ્રીય એકમ કલાક (hour) અથવા દિવસ (day) છે, પણ પ્રશ્ન મુજબ તાસ, મિનિટ, વર્ષ પણ વપરાઈ શકે.
  • કાર્યનો દર / વેગ (Rate of Work / Velocity of Work): એક એકમ સમયમાં થતું કાર્ય. જો કોઈ વ્યક્તિ n દિવસમાં કાર્ય પૂરું કરે, તો તેના એક દિવસનું કાર્ય = 1/n થાય. દરને ઘણીવાર કુશળતા (efficiency) સાથે સંબંધિત ગણવામાં આવે છે.
  • કુશળતા (Efficiency): કાર્ય કરવાની ક્ષમતાનો માપ. જો A, B કરતાં x ગણું વધુ કુશળ હોય, તો A અને B નો કાર્યદરનો ગુણોત્તર x : 1 હોય, અને લીધેલા સમયનો ગુણોત્તર 1 : x હોય.

Key concepts

  • મૂળભૂત સૂત્ર: કાર્ય = દર × સમય (W = R × T): ['કાર્ય, દર અને સમય વચ્ચેનો સંબંધ ત્રિકોણ સમાન છે. જો દર (R) એકમ સમયમાં થતું કાર્ય હોય, તો કુલ કાર્ય (W) = દર × સમય (T).', 'ઉદાહરણ: જો કોઈ કારીગર પ્રતિ કલાક 5 ભાગ કામ કરે અને 8 કલાક કામ કરે, તો કુલ કાર્ય = 5 × 8 = 40 ભાગ થાય.']
  • દર અને સમયનો વ્યસ્ત સંબંધ: ['જો કોઈ વ્યક્તિ એક કાર્ય n દિવસમાં પૂરું કરે, તો તેનો દર = 1/n (પ્રતિ દિવસ કાર્ય). જો બીજી વ્યક્તિ m દિવસમાં પૂરું કરે, તો તેનો દર = 1/m.', 'આમ, દર અને સમય પરસ્પર વ્યસ્ત પ્રમાણમાં હોય છે: જેટલો વધુ દર, તેટલો ઓછો સમય અને વ્યુત્क्रमે.', 'ગુણોત્તરનો નિયમ: જો A અને B નો કુશળતાનો ગુણોત્તર a : b હોય, તો તેઓ કાર્ય પૂરું કરવામાં લેતા સમયનો ગુણોત્તર b : a થાય.']
  • સંયુક્ત કાર્ય (Combined Work): ['જો A એકલો a દિવસમાં અને B એકલો b દિવસમાં કાર્ય પૂરું કરે, તો તેઓ સાથે મળીને કાર્ય પૂરું કરવામાં લેતા સમય = (a × b) / (a + b) દિવસ.', 'આ સૂત્ર વ્યસ્ત દરોના સરવાળા પરથી મેળવવામાં આવે છે: 1/a + 1/b = (a+b)/(ab), તેથી સંયુક્ત દર = (a+b)/(ab), અને સમય = ab/(a+b).', 'જો ત્રણ વ્યક્તિઓ A, B, C હોય જેઓ અનુક્રમે a, b, c દિવસમાં કાર્ય પૂરું કરે, તો સંયુક્ત સમય = 1 / (1/a + 1/b + 1/c).']
  • કુશળતાનો ગુણોત્તર અને સમયનો ગુણોત્તર: ['જો A, B કરતાં x ગણું વધુ કુશળ હોય, તો A નો દર = x × B નો દર. અતः, સમયનો ગુણોત્તર A:B = 1:x થાય (કારણ કે દર અને સમય વ્યસ્ત છે).', 'ઉદાહરણ: A, B કરતાં 3 ગણું વધુ કુશળ છે. તેથી A:B દર = 3:1. જો B એકલો 12 દિવસમાં કામ પૂરું કરે, તો A ને 4 દિવસ લાગે (કારણ કે દર 3 ગણો, સમય 1/3).', 'આ સિદ્ધાંતનો ઉપયોગ ઘણા પ્રશ્નોમાં કુશળતા આપીને સમય શોધવા માટે થાય છે.']
  • નળ અને ખાપડ (Pipes and Cisterns) – ભરવું અને ખાલી કરવું: ['નળ (Inlet): અખાડો ભરે છે. જો નળ x કલાકમાં અખાડો ભરે, તો 1 કલાકમાં 1/x ભાગ ભરાય.', 'ખાપડ (Outlet): અખાડો ખાલી કરે છે. જો ખાપડ y કલાકમાં અખાડો ખાલી કરે, તો 1 કલાકમાં 1/y ભાગ ખાલી થાય.', 'જો બંને એકસાથે ખોલવામાં આવે, તો net દર = (1/x – 1/y) (જો x < y, તો અખાડો ભરશે; જો x > y, તો ખાલી થશે).', 'અખાડો ભરાવાનો સમય = 1 / (1/x – 1/y) = xy/(y – x) કલાક (જ્યારે x < y).']
  • કાર્યનો સમય ગણતરીના મુખ્ય સૂત્રો: ['સૂત્ર 1: કાર્ય (W) = દર (R) × સમય (T). જ્યાં R એકમ સમયમાં કાર્ય.', 'સૂત્ર 2: જો A, B કરતાં x ગણું વધુ કુશળ હોય, તો A લેશે સમય = (બાકી સમય) / x.', 'સૂત્ર 3: (M₁D₁H₁)/W₁ = (M₂D₂H₂)/W₂ — જ્યારે કાર્ય, દિવસો, કામદારો અને કલાકો ફેરવાતા હોય.', 'સૂત્ર 4: સામાન્ય રીતે કુલ કાર્યને LCM(સમયો) ની સરળતાથી ગણી શકાય (LCM પદ્ધતિ). ઉદા. A 10 દિવસમાં, B 15 દિવસમાં → કુલ કાર્ય = 30 એકમ, A નો દર = 3 એકમ/દિવસ, B નો દર = 2 એકમ/દિવસ.']
  • વૈવિધ્યપૂર્ણ પ્રકારો: વિસંગત કાર્ય, વારાવાર કામ, વેતન વિતરણ: ['વિસંગત કાર્ય: જ્યારે કોઈ વ્યક્તિ કામ ચાલુ કરે અને વચ્ચે રોકાઈ જાય, અથવા બીજી વ્યક્તિ ઉમેરાય. દરેક જણે આપેલા સમય દરમિયાન થયેલ કાર્યનો સરવાળો કુલ કાર્ય થાય.', 'વારાવાર કામ (Alternate Days): જો A અને B વારાફરતી કામ કરતાં હોય, તો પ્રતિ દિવસનો દર બદલાય. સામાન્ય રીતે બે દિવસનો ચક્ર ગણી કુલ કાર્ય શોધવું.', 'વેતન વિતરણ: કાર્યના દરના ગુણોત્તર મુજબ વેતન વહેંચવામાં આવે છે. દા.ત., A અને B નો દર 3:5 હોય, તો કુલ વેતનને 3:5 ના ગુણોત્તરમાં વહેંચવું.']
  • પ્રમાણબદ્ધતાનો ઉપયોગ: ['સીધું પ્રમાણ: જો દિવસો વધે, તો કાર્ય વધે; જો કામદારો વધે, તો કાર્ય વધે.', 'વ્યસ્ત પ્રમાણ: જો દિવસો વધે, તો દર ઘટે; જો કામદારો વધે, તો દર ફેરવણી થાય પણ કુલ કાર્ય સમાન રહે.', 'મુખ્ય સૂત્ર: M₁ × D₁ × H₁ / W₁ = M₂ × D₂ × H₂ / W₂, જ્યાં M = કામદારો, D = દિવસો, H = કલાકો/દિવસ, W = કાર્ય.']

Important facts

  • કોઈ વ્યક્તિ n દિવસમાં કાર્ય પૂરું કરે, તો તેનું એક દિવસનું કાર્ય 1/n થાય. — આમૂળ ગણતરીનો આધાર છે.
  • જો A, B કરતાં x ગણું વધુ કુશળ હોય, તો A:B સમય = 1:x (કુશળતા વ્યસ્ત પ્રમાણમાં સમય). — પ્રશ્નોમાં સીધો ઉપયોગ થાય છે.
  • બે વ્યક્તિઓ સાથે કામ કરે, તો કુલ સમય = (a×b)/(a+b) દિવસ, જ્યાં a અને b એ એકલા લેતા સમય છે. — સૌથી સામાન્ય પ્રકાર.
  • નળ અને ખાપડ સાથે, ભરાતો દર = 1/نળ – 1/ખાપડ, અને ખાલી થતો દર = 1/ખાપડ – 1/نળ (જો ખાપડ પ્રથમ હોય). — પાણીના પ્રશ્નોમાં વારંવાર આવે છે.
  • કાર્ય = દર × સમય, જેમાં દર એકમ સમયમાં થતું કાર્ય છે. — મૂળભૂત સમીકરણ.
  • લઘુત્તમ સામાન્ય અવયવ (LCM) પદ્ધતિ: કુલ કાર્યને બધા સમયના LCM તરીકે ગણી, દરને પૂર્ણાંકમાં બદલવો ગણતરી સરળ બનાવે છે. — સાધન સમય ઘટાડે છે.
  • વેતન વિતરણ કાર્યદરના ગુણોત્તર મુજબ થાય છે, સમયના નહીં. — બહુ આવતા પ્રશ્નો.
  • જો કોઈ વ્યક્તિ A દિવસમાં કામ કરે અને B દિવસમાં કામ કરે, તો તેઓ સાથે (AB)/(A+B) દિવસમાં પૂરું કરશે. — મુખ્ય સૂત્ર.

Memory aids

  • "કાર્ય = દર × સમય" → ત્રિકોણની કલ્પના: ઉપર કાર્ય, નીચે દર અને સમય. જો કાર્ય અને દર જાણીતો હોય, તો સમય = કાર્ય/દર. — visual_mnemonic
  • "કુશળતા વધે, સમય ઘટે" → કુશળતા અને સમય વ્યસ્ત પ્રમાણમાં, તેથી A:B કુશળતા = a:b તો A:B સમય = b:a. — phrase
  • "સાથે કામ: અંશ ગુણાકાર, છેદ સરવાળો" → સમય = (a×b)/(a+b). એટલે કે, બે સમયોનો ગુણાકાર ભાગલા સરવાળા. — rhyme
  • "LCM પદ્ધતિ: કુલ કાર્ય = LCM(દિવસો), દર = LCM/દિવસ" → ઉદા. 10 અને 15 માટે LCM = 30, દર અનુક્રમે 3 અને 2. — procedure
  • "નળ અને ખાપડ: ભરવાનો દર ધન, ખાલી કરવાનો દર ઋણ" → net દર = (1/نળ) – (1/ખાપડ). — conceptual

Exam tips

  • જયારે પણ "કુશળતા" શબ્દ આવે, તરત જ દર અને સમયનો વ્યસ્ત સંબંધ યાદ રાખો: દર ∝ 1/સમય. — પ્રશ્નોમાં સીધો ઉપયોગ થાય છે, ખાસ કરીને ગુણોત્તર પ્રશ્નો.
  • સંયુક્ત કાર્યના પ્રશ્નોમાં LCM પદ્ધતિ અપનાવો: કુલ કાર્ય = બધા સમયનો LCM, દર = LCM/દિવસ. ગણતરી પૂર્ણાંકમાં થાય. — ઘણા પ્રશ્નોમાં ભિન્નોથી ગણતરી કરવી મુશ્કેલ હોય, LCM પદ્ધતિ ઝડપી બનાવે. — A 10 દિવસ, B 15 દિવસ → LCM=30, દર A=3, B=2, સાથે દર=5, સમય=30/5=6 દિવસ.
  • નળ-ખાપડ પ્રશ્નમાં net દર = (1/نળ) – (1/ખાપડ) નો સીધો ઉપયોગ કરો અને સમય = 1/net દર. — જો नळ ખાલી કરતો હોય, તો ખાલી થવાનો સમય શોધો. — જો ખાપડનો સમય નળ કરતાં ઓછો હોય, તો અખાડો ખાલી થશે.
  • "x ગણું વધુ કુશળ" એટલે દર x ગણો, સમય 1/x ગણો. ગણતરીમાં ધ્યાન રાખો: A નો સમય = (B નો સમય)/x. — ઉદા. A, B કરતાં 4 ગણું વધુ કુશળ, B એકલો 20 દિવસ → A ને 5 દિવસ. — ખોટો અર્થ: A ને 80 દિવસ લાગે તેમ માનવું (ખોટું).
  • વેતન વિતરણ પ્રશ્નોમાં, પહેલા દરનો ગુણોત્તર શોધો, ત્યારે જ કુલ રકમ વિભાજિત કરો. સમયનો ગુણોત્તર નહીં. — A અને B નો દર 2:3 હોય, કુલ વેતન ₹5000 → A નું વેતન = (2/5)×5000 = ₹2000. — કદાચ સમય ગુણોત્તર 3:2 લઈ લેવાય (ખોટું).
  • ગણતરીમાં એકમો (કલાક, દિવસ) સુસંગત રાખો. જો આપેલ સમય કલાકમાં હોય અને દર દિવસમાં, તો રૂપાંતર કરો (1 દિવસ = 24 કલાક). — ઘણા પ્રશ્નોમાં એકમ ભેળવવાથી ભૂલ થાય છે. — A 8 કલાકમાં, B 12 કલાકમાં → net દર = (1/8+1/12)=5/24 કાર્ય/કલાક → સમય = 24/5 = 4.8 કલાક.
  • તેજીથી ઉકેલવા માટે LCM પદ્ધતિ શીખો અને વારંવાર પ્રેક્ટિસ કરો. આ પદ્ધતિ ભિન્નોથી ગણતરી કરતાં ઝડપી અને ચોકસાઈપૂર્વક હોય છે. — આ ખાસ કરીને સમય મર્યાદાવાળા પરીક્ષામાં ફાયદાકારક છે. — કુલ 20-30 પ્રશ્નોની LCM પદ્ધતિથી ગણતરી કરો.

Common traps

  • કુશળતાનો ગુણોત્તર સીધો સમયનો ગુણોત્તર સમજી લેવો. — કુશળતાનો ગુણોત્તર a:b હોય, તો સમયનો ગુણોત્તર b:a થાય. દર અને સમય વ્યસ્ત પ્રમાણમાં છે.
  • "x ગણું વધુ કુશળ" નો અર્થ "x ગણો સમય લે" સમજવો. — x ગણું વધુ કુશળ એટલે દર x ગણો, સમય 1/x ગણો. ઉદા. 3 ગણું વધુ કુશળ → સમય 1/3.
  • નળ અને ખાપડના પ્રશ્નમાં ખાલી કરનારા નળને ભરવાનો દર સમજી લેવો. — ખાપડ (outlet) એ ઋણ દર છે. net દર = ભરવાનો દર – ખાલી કરવાનો દર.
  • સંયુક્ત કાર્યનું સૂત્ર (a+b)/(ab) ઉલટું લખવું. — સંયુક્ત દર = 1/a + 1/b = (a+b)/(ab). સમય = 1/દર = ab/(a+b).
  • વેતન વિતરણમાં સમયના ગુણોત્તર મુજબ વિભાગવું. — વેતન કાર્યદરના ગુણોત્તર મુજબ વિભાગે, સમયના નહીં. કાર્યદરનો ગુણોત્તર શોધો, ત્યારે જ વહેંચો.
  • એકમોની અવગણના – દિવસ/કલાક/મિનિટ ભેળવી દેવું. — દરેક પ્રશ્નમાં એકમો ચકાસો. જો સમય કલાકમાં અને દર દિવસમાં હોય, તો રૂપાંતરણ કરો.
  • LCM પદ્ધતિ વપરાતી નથી, તો યાદૃચ્છિક સંખ્યા લઈ ગણતરી કરવી. — જ્યાં સમય આપેલ હોય, ત્યાં LCM પદ્ધતિ સૌથી ઝડપી છે. બીજી રીતે ભિન્નોમાં ગણતરી કરવી પડે.
