Definitions

  • સરેરાશ (Average) એટલે આપેલ બધા મૂલ્યોના સરવાળાને તેમની સંખ્યા વડે ભાગતાં મળતું ફલિત.
  • સરેરાશ = બધા મૂલ્યોનો સરવાળો / મૂલ્યોની કુલ સંખ્યા
  • જો n સંખ્યાઓ હોય અને તેમનો સરવાળો S હોય, તો સરેરાશ A = S/n થાય.
  • સરેરાશ હંમેશા સૌથી નાના અને સૌથી મોટા મૂલ્યની વચ્ચે હોય છે (બધી સંખ્યાઓ સમાન હોય ત્યાં સુધી).
  • જો કોઈ પણ સંખ્યામાં c ઉમેરવામાં આવે તો નવી સરેરાશ = (પૂર્વ સરવાળો + c) / (નવી સંખ્યા)
  • જો કોઈ સંખ્યામાંથી d બાદ કરવામાં આવે તો નવી સરેરાશ = (પૂર્વ સરવાળો - d) / (નવી સંખ્યા)

Key concepts

  • મૂળભૂત સૂત્ર: સરેરાશ = સરવાળો ÷ સંખ્યા | વિપરીત: સરવાળો = સરેરાશ × સંખ્યા | આ બે સૂત્ર પર પાયાની દરેક સમસ્યા ઊભી રહે છે.
  • યુગ્મ પ્રાકૃતિક સંખ્યાઓ 1 થી n સુધીની સરેરાશ = (n+1)/2. ઉદા. 1 થી 100 સુધીની સરેરાશ = 50.5
  • અયુગ્મ પ્રાકૃતિક સંખ્યાઓ 1 થી n સુધીની સરેરાશ = (n+1)/2 જ (સંખ્યા અયુગ્મ હોવા છતાં). ઉદા. 1,3,5,7,9 → સરેરાશ = 5
  • p સંખ્યાઓની સરેરાશ A1 અને q સંખ્યાઓની સરેરાશ A2 હોય, તો કુલ (p+q) સંખ્યાઓની સરેરાશ = (p×A1 + q×A2)/(p+q). આ 'મિશ્રણ સૂત્ર' છે.
  • ઉમેર/બાદ કરવાથી સરેરાશમાં ફેરફાર: જો n સંખ્યાઓની સરેરાશ A હોય અને તેમાં x ઉમેરવાથી નવી સરેરાશ A' થાય, તો x = n(A'-A) + A'. સરળ રીતે: વધારો = (નવી સરેરાશ - જૂની સરેરાશ) × (નવી સંખ્યા).
  • સરેરાશના ગુણધર્મો: (1) બધી સંખ્યાઓ સમાન હોય તો સરેરાશ પણ તેટલી જ. (2) જો દરેક સંખ્યામાં k ઉમેરો/બાદ કરો તો નવી સરેરાશ = જૂની સરેરાશ ± k. (3) જો દરેક સંખ્યાને k વડે ગુણો/ભાગો તો નવી સરેરાશ = જૂની સરેરાશ ×k / k.
  • આયુ સંબંધિત: v વર્ષ પહેલાં વ્યક્તિની ઉંમર a વર્ષ હતી, તો હાલની ઉંમર = a + v. v વર્ષ બાદ ઉંમર = a + v. બે વ્યક્તિઓની ઉંમરનો ગુણોત્તર v વર્ષ પહેલાં/બાદ સમાન રહેતો નથી.
  • ચાલુ/થંભી રહેલી વસ્તુ: જો કોઈ વસ્તુ સરેરાશ ગતિએ ચાલે અને મધ્યમાં ક્યાંક થંભી જાય, તો કુલ સમય = અંતર/સરેરાશ ગતિ + થંભાટનો સમય. સામાન્ય રીતે 'સરેરાશ' પ્રશ્નોમાં ધ્યાન રાખો કે સરેરાશ ગતિ = કુલ અંતર/કુલ સમય (મધ્યગતિ નહીં).
  • અંકો સંબંધિત: દ્વિ-અંકની સંખ્યા ab = 10a+b. તેના અંકો બદલતાં બનતી સંખ્યા ba = 10b+a. તફાવત = 9(a-b). સરવાળો = 11(a+b). આ ગુણધર્મો સરેરાશ પ્રશ્નોમાં મદદગાર છે.
  • ચતુષ્કોણ/બહુકોણની આંતરિક ખૂણાઓનો સરવાળો = (n-2)×180°. તેથી સરેરાશ આંતરિક ખૂણો = (n-2)×180°/n. ઉદા. ષટ્કોણ (n=6) માટે = 720/6 = 120°.

Important facts

  • 1 થી n સુધીની પ્રાકૃતિક સંખ્યાઓનો સરવાળો = n(n+1)/2, તેથી સરેરાશ = (n+1)/2.
  • 1 થી n સુધીની વિષમ પ્રાકૃતિક સંખ્યાઓનો સરવાળો = n², સરેરાશ = n.
  • 1 થી n સુધીની સમ પ્રાકૃતિક સંખ્યાઓનો સરવાળો = n(n+1), સરેરાશ = n+1.
  • ગુણોત્તર શ્રેણી: a, ar, ar², ..., ar^(n-1). સરવાળો = a(r^n-1)/(r-1). સરેરાશ = સરવાળો/n.
  • અંતરાલની સરેરાશ: p થી q સુધીની એકધારી વધતી સંખ્યાઓ (અંતર d હોય) ની સરેરાશ = (પ્રથમ + અંતિમ)/2.
  • સરેરાશની એકમ: જો સંખ્યાઓ 'રૂપિયા'માં હોય તો સરેરાશ પણ રૂપિયામાં જ હોય; 'વર્ષ'માં હોય તો વર્ષમાં.
  • લઘુત્તમ સંભવ્ય સરેરાશ: બધી સંખ્યાઓ સમાન હોય ત્યારે, તેથી જ્યારે પૂછાય કે 'ન્યૂનતમ મહત્તમ સરેરાશ' તો બધી સંખ્યાઓ સમાન ધરો.
  • વધુતમ સંભવ્ય સરેરાશ: એક સંખ્યા શક્ય તેટલી મોટી અને બાકીની શક્ય તેટલી નાની હોય.
  • પાંચ સંખ્યાઓની સરેરાશ 27 છે, તો સરવાળો 135. જો એક સંખ્યા છોડતાં સરેરાશ 25 થાય, તો છોડેલી સંખ્યા = 135 - 4×25 = 35. આ પ્રકારનો પ્રશ્ન GUJCET/Police માં વારંવાર આવે છે.
  • સરેરાશ સમસ્યાઓમાં ડેટા નિર્બંધ (data sufficiency) પ્રશ્નો પણ આવે છે: બે કે ત્રણ વિધાનમાંથી જવાબ મેળવી શકાય કે નહીં તે તપાસવું.

Memory aids

  • સરેરાશ = સરવાળો ÷ સંખ્યા → સૂત્રનું રૂપ: 'સરે' = 'સરવાળા' ને 'અંક' વડે 'ભાગીએ' (અંક = count).
  • 'સર-અંશ' = સરવાળાનો અંશ, 'અંશ' = સંખ્યા. સર = સરવાળા/અંશ.
  • મિશ્રણ સૂત્ર યાદ રાખવા: 'કુલ સરવાળો = બધાનો સરવાળો' → pA1 + qA2, કુલ સંખ્યા = p+q.
  • ઉમેર-બાદનો નિયમ: નવી સંખ્યા × ફેરફાર = સરેરાશ ફેરફાર × નવી સંખ્યા. 'જોડી યાદ રાખો: નવી સંખ્યા, નવી સરેરાશ.'
  • 1 થી n સુધીની સરેરાશ (n+1)/2 → 'n+1ને 2 વડે ભાગો'. યુગ્મ-અયુગ્મ બંને માટે લાગુ.
  • વિષમ સંખ્યાઓનો સરવાળો n², સરેરાશ n → 'સંખ્યા બરાબર સરેરાશ' માત્ર વિષમ સંખ્યાઓ માટે.
  • સમ સંખ્યાઓનો સરવાળો n(n+1), સરેરાશ n+1 → 'એક વધારે સરેરાશ'.
  • સરેરાશ ગતિ = કુલ અંતર ÷ કુલ સમય → 'સમયનો ખ્યાલ જરૂરી'. વિશ્રાંતિનો સમય પણ કુલ સમયમાં સામેલ.
  • અંક બદલવાનો તફાવત 9(a-b) → '9 વડે વિભાજ્ય', અંકોનો સરવાળો 11(a+b) → '11 વડે વિભાજ્ય.'
  • n સંખ્યાઓની સરેરાશ A હોય, જો દરેકમાં k ઉમેરો → નવી સરેરાશ A+k. યાદ રાખો: 'જોડાણ એ જ જોડાણ.'
  • બહુકોણની સરેરાશ આંતરિક ખૂણો = (n-2)×180°/n → 'બહુ-કોણ = (n-2)×સુધારો.'
  • સરેરાશ શબ્દનો અર્થ: 'સર = સરવાળા' એ ભાષાનો ઉપયોગ કરી શકાય — 'સર = સરવાળા, રાશ = રાશિ.'
  • આયુ પ્રશ્નો: v વર્ષ પહેલાં = a → હાલ = a+v. v વર્ષ બાદ = a → હાલ = a-v. 'અગાઉ + v = હાલ; હાલ + v = ભવિષ્ય.'
  • છોડેલી સંખ્યા શોધવા: n સંખ્યાઓ, સરેરાશ A → સરવાળો nA. n-1 સંખ્યાઓ, સરેરાશ A' → સરવાળો (n-1)A'. છોડેલી = nA - (n-1)A'.
  • સરેરાશની તુલના: જો n સંખ્યાઓનો સરવાળો s હોય અને m સંખ્યાઓનો સરવાળો t હોય, તો કુલ સરેરાશ = (s+t)/(n+m).
  • સરેરાશ પ્રશ્ન માટેનો સામાન્ય કોયડો: 'સરેરાશ શું બદલાય?' → જવાબ: 'સાપેક્ષ તફાવત' — કુલ સરવાળો બદલાય, સંખ્યા બદલાય, તેથી સરેરાશ બદલાય.

Exam tips

  • પ્રશ્નમાં 'સરેરાશ શોધો' અથવા 'છોડેલી સંખ્યા શોધો' — આ બે પ્રકાર સૌથી વધુ આવે છે. પહેલા સરવાળો શોધો, પછી અંતિમ સરેરાશ વડે ગણતરી.
  • જ્યારે સંખ્યા ઉમેરાય/બાદ થાય ત્યારે 'નવી સંખ્યા' સીધી ઉપયોગ કરો. પૂર્વ સંખ્યા વડે ભાગવું નથી.
  • મિશ્રણ પ્રશ્ન: (pA1+qA2)/(p+q) — યાદ રાખો p અને q ની હુડંગ-ઢાલ બદલવી નહીં.
  • સમય ઊંડાણ નથી: GUJCET/Police Constable માં સરેરાશના સીધા સૂત્ર પર આધારિત પ્રશ્નો આવે છે. ખૂબ જટિલ અંકગણિત માંગતા નથી.
  • જવાબ ચકાસણી: સરેરાશ સંખ્યાઓની વચ્ચે હોય જોઈએ. જો તમારો જવાબ સૌથી નાની અથવા સૌથી મોટી સંખ્યા કરતાં ઓછો/વધારે આવે, તો ગણતરીમાં ભૂલ.
  • આયુ પ્રશ્ન: v વર્ષ પહેલાં/બાદ બધા માટે v ઉમેરવો/બાદ કરવો — વ્યક્તિગત નહીં, બધા માટે સમાન.
  • અંકોના પ્રશ્ન: 9 અને 11 સાથે સંબંધિત ગુણધર્મ યાદ રાખો, કારણ કે ઘણી વાર તે જવાબ તરફ દોરે છે.
  • સમય મર્યાદામાં: પ્રશ્ન સમજીને 1-2 મિનિટમાં ઉકેલવાનું ટ્રેઇન કરો. સરવાળો શોધવો પહેલાં, પછી સરેરાશ. એક જ રૂપમાં ગણતરી.
  • કમ્પ્યુટેશનલ ટીપ: n(n+1)/2, n², n(n+1) જેવા સૂત્રો યાદ હોય તો પ્રશ્ન ઝડપી. 1 થી 50 સુધીનો સરવાળો = 50×51/2 = 1275, સરેરાશ = 25.5.
  • ગુજરાત પોલીસ કોન્સ્ટેબલ પ્રશ્નોમાં 'સરેરાશ' એક મહત્વપૂર્ણ વિષય છે — 2-4 પ્રશ્નો બેઠકમાં આવે છે. સૂત્ર યાદ રાખો અને ઝડપી ગણતરી કરો.

Common traps

  • કુલ સંખ્યામાં ફેરફાર થયા બાદ પણ જૂની સંખ્યા વડે ભાગવું. ઉદા. 5 સંખ્યાઓની સરેરાશ 20, એક છોડતાં 4 સંખ્યાઓની સરેરાશ 18 થાય, તો છોડેલી સંખ્યા = 5×20 - 4×18 = 34, નહીં કે 5×20 - 5×18.
  • મિશ્રણ સૂત્રમાં (p+q) વડે ભાગવું બદલે પછી પણ p×A1 + q×A2 હીસાબમાં ભૂલ. ગુણાકાર પહેલાં જ ભાગાકાર કરવો.
  • સરેરાશ ગતિ = કુલ અંતર ÷ કુલ સમય (મધ્યગતિ નહીં). મધ્યગતિ સામાન્ય રીતે અલગ અને ઓછી વપરાય છે.
  • દ્વિ-અંકની સંખ્યાનો અંકોનો સરવાળો = 11(a+b) એ અવશ્ય ગુણધર્મ છે, પણ સંખ્યા a+b નહીં — ઘણી વાર વિદ્યાર્થીઓ સંખ્યા જ વાપરી દે છે.
  • v વર્ષ પહેલાં ઉંમર અલગ છે તો ગુણોત્તર v વર્ષ બાદ પણ તેટલો જ રહે તેવું માનવું. ગુણોત્તર બદલાય છે — ફક્ત સંખ્યા ઉમેરાય/બાદ થાય.
  • ચતુષ્કોણની આંતરિક ખૂણાઓનો સરવાળો 360° છે એ યાદ રાખી, ષટ્કોણ માટે પણ 360° ધારી લેવું. સૂત્ર (n-2)×180° વાપરવું.
  • 1 થી n સુધીની વિષમ સંખ્યાઓનો સરવાળો n² — ઘણા વિદ્યાર્થીઓ n(n+1)/2 લાગુ કરી દે છે. અંતિમ સંખ્યા m હોય, તો વિષમ સંખ્યાઓની સંખ્યા = (m+1)/2.
  • ઉમેર-બાદ પ્રશ્નમાં નવી સંખ્યા ગણતરીમાં રાખવી જોઈએ, પણ જૂની સંખ્યા વડે સરેરાશ ગણી લેવી.
  • અંતરાલ d ની સંખ્યાઓની સરેરાશ = (પ્રથમ + અંતિમ)/2 — આ માત્ર સમાન અંતર સુધી જ લાગુ, અન્યથા સૂત્ર wrong.
  • સરેરાશ શબ્દની ભૂલ: સરેરાશ ≠ મધ્યક. અહીં બંને સમાન છે, પણ કેટલાક પ્રશ્નોમાં 'મધ્યક' અને 'સરેરાશ' વચ્ચે ફરક બતાવે છે — પ્રશ્નનું શબ્દતઃ ધ્યાન રાખો.
