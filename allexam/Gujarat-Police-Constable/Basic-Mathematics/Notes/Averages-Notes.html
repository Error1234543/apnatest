1. સરેરાશની મૂળભૂત વ્યાખ્યા અને સૂત્ર

['સરેરાશ એટલે કે કોઈ પણ આપેલી સંખ્યાઓના સરવાળાને તે સંખ્યાઓની કુલ સંખ્યા વડે ભાગતા જે પરિણામ મળે છે તે પૂરી ટોળકીનો સરેરાશ ગણાય છે.', 'મુખ્ય સૂત્ર: સરેરાશ = આપેલી સંખ્યાઓનો સરવાળો ÷ સંખ્યાઓની કુલ ગણતરી', "જો 'n' સંખ્યાઓનો સરેરાશ 'A' હોય, તો તે નવું સૂત્ર બને: સરવાળો = સરેરાશ × ગણતરી (Sum = Average × Count)", 'આ સૂત્રનો ઉપયોગ વારંવાર પ્રશ્નોમાં ગુમાવેલી સંખ્યા શોધવા માટે થાય છે.', 'ઉદાહરણ: 5 સંખ્યાઓનો સરેરાશ 24 છે, તો તેમનો સરવાળો = 24 × 5 = 120 થાય.']

2. સરેરાશ શોધવાની પદ્ધતિઓ

['પરંપરાગત પદ્ધતિ: બધી સંખ્યાઓનો સરવાળો કરીને કુલ ગણતરી વડે ભાગવો.', 'આસન્ન મૂલ્ય પદ્ધતિ (Assumed Mean Method): જ્યારે સંખ્યાઓ મોટી હોય ત્યારે એક આસન્ન સરેરાશ લઈને તેનાથી વિચલનો શોધવા.', 'સરેરાશ = ધારેલો સરેરાશ + (વિચલનોનો સરવાળો ÷ કુલ સંખ્યાઓ)', 'ઉદાહરણ: 48, 52, 56, 44, 50 નો સરેરાશ શોધવા. ધારો કે ધારેલો સરેરાશ = 50, વિચલનો: -2, +2, +6, -6, 0. વિચલનોનો સરવાળો = 0, તેથી સરેરાશ = 50 + 0/5 = 50.', 'જ્યારે સંખ્યાઓ ચોક્કસ પેટર્નમાં હોય (જેમ કે ક્રમિક સંખ્યાઓ, સમ અથવા વિષમ સંખ્યાઓ) ત્યારે સીધું સૂત્ર લાગુ પડે છે.']

3. વિશેષ સંખ્યાઓનો સરેરાશ — સૂત્રો

['પ્રથમ n પ્રકૃત સંખ્યાઓનો સરેરાશ = (n+1)/2', 'ઉદાહરણ: પ્રથમ 10 પ્રકૃત સંખ્યાઓનો સરેરાશ = (10+1)/2 = 5.5. સિદ્ધિ: 1+2+...+10 = 55, સરેરાશ = 55/10 = 5.5', 'પ્રથમ n સમ સંખ્યાઓનો સરેરાશ = n+1', 'ઉદાહરણ: પ્રથમ 10 સમ સંખ્યાઓ (2,4,6,...,20) નો સરેરાશ = 10+1 = 11. સિદ્ધિ: સરવાળો = 2+4+...+20 = 110, સરેરાશ = 110/10 = 11', 'પ્રથમ n વિષમ સંખ્યાઓનો સરેરાશ = n', 'ઉદાહરણ: પ્રથમ 8 વિષમ સંખ્યાઓ (1,3,5,...,15) નો સરેરાશ = 8. સિદ્ધિ: સરવાળો = 64, સરેરાશ = 64/8 = 8', 'k ક્રમિક સંખ્યાઓનો સરેરાશ હંમેશા મધ્યમ સંખ્યા જ હોય છે જો k विषम હોય, અને બે મધ્યમ સંખ્યાનો સરેરાશ જો k સમ હોય.', 'ઉદાહરણ: 5 ક્રમિક સંખ્યાઓ 8,9,10,11,12 નો સરેરાશ = 10 (મધ્યમ સંખ્યા). 6 ક્રમિક સંખ્યાઓ 7,8,9,10,11,12 નો સરેરાશ = 9.5 (8+10/2? નહીં, 9+10/2 = 9.5).']

4. સરેરાશ પર ફેરફારોનો અસર — મહત્વના ગુણધર્મો

['જો દરેક સંખ્યામાં સમાન રકમ ઉમેરવામાં આવે, તો સરેરાશ પણ તેટલી જ રકમ વધે છે.', 'ઉદા: સંખ્યાઓનો સરેરાશ 20 છે. દરેકમાં 5 ઉમેરતા નવો સરેરાશ = 25 થાય.', 'જો દરેક સંખ્યામાંથી સમાન રકમ घटाવવામાં આવે, તો સરેરાશ પણ તેટલી જ રકમ ઘટે છે.', 'જો દરેક સંખ્યાને સમાન સંખ્યાથી ગુણવામાં આવે, તો સરેરાશ પણ તેટલા ગુણક વડે ગુણાય છે.', 'જો દરેક સંખ્યાને સમાન સંખ્યાથી ભાગવામાં આવે, તો સરેરાશ પણ તેટલા વડે ભાગાય છે.', 'જો k સંખ્યાઓનો સરેરાશ A1 અને m સંખ્યાઓનો સરેરાશ A2 હોય, તો બધી (k+m) સંખ્યાઓનો સંયુક્ત સરેરાશ = (k×A1 + m×A2)/(k+m) થાય. આ ગુરુત્વયુક્ત સરેરાશ (Weighted Average) કહેવાય છે.', 'ઉદાહરણ: 5 છાત્રોનો સરેરાશ અંક 72 અને 3 છાત્રોનો સરેરાશ અંક 84 હોય, તો 8 છાત્રોનો સરેરાશ = (5×72 + 3×84)/(5+3) = (360+252)/8 = 612/8 = 76.5', 'સરેરાશ હંમેશા સૌથી ખૂબસૂરત અને સૌથી નાની સંખ્યાની વચ્ચે જ હોય છે — સરેરાશ ક્યારેય સૌથી મોટી સંખ્યાથી મોટી કે સૌથી નાની સંખ્યાથી નાની હોતી નથી.']

5. ગુમાવી ગઈ સંખ્યા શોધવી

['આ પ્રકારના પ્રશ્નોમાં કેટલીક સંખ્યાઓ આપેલી હોય છે અને સરેરાશ આપેલો હોય છે, પણ એક અથવા વધુ સંખ્યાઓ ગુમાવી ગઈ હોય છે.', 'ઉકેલ પદ્ધતિ: કુલ સરવાળો = સરેરાશ × કુલ સંખ્યાઓ. આપેલી સંખ્યાઓનો સરવાળો શોધો. વ્યતિક્રમ (અંતર) = કુલ સરવાળો − આપેલી સંખ્યાઓનો સરવાળો — આ જ ગુમાવેલી સંખ્યા/સંખ્યાઓ છે.', 'ઉદાહરણ: 6 સંખ્યાઓનો સરેરાશ 35 છે. પાંચ સંખ્યાઓ 28, 32, 40, 38, 33 છે. છઠ્ઠી સંખ્યા શોધો. કુલ સરવાળો = 35×6 = 210. આપેલી 5 સંખ્યાઓનો સરવાળો = 28+32+40+38+33 = 171. છઠ્ઠી સંખ્યા = 210−171 = 39.', 'જ્યારે બે થી વધુ સંખ્યાઓ ગુમાવી હોય, ત્યારે સામાન્યત: વધારાની શરત આપેલી હોય છે (જેમ કે બે ગુમાવેલી સંખ્યાઓનો અંતર કે સંબંધ).', 'ધ્યાન રાખો: જો એક સંખ્યા બદલાઈ જાય, તો સરેરાશમાં થતો ફેરફાર = (નવી સંખ્યા − જૂની સંખ્યા) ÷ કુલ સંખ્યાઓ.']

6. ઉંમર સંબંધી સમસ્યાઓ

['ઉંમરના પ્રશ્નોમાં સરેરાશનો ઉપયોગ ખૂબ જ સામાન્ય છે. સામાન્ય રીતે પિતા-માતા-બાળકો કે સંઘટિત પરિવારના સરેરાશ ઉંમર શોધવાના પ્રશ્નો આવે છે.', 'પદ્ધતિ: સરેરાશ ઉંમર × વ્યક્તિઓની ગણતરી = કુલ ઉંમર. પછી જરૂરી વ્યક્તિઓની ઉંમર શોધવા માટે બાકીની વ્યક્તિઓના સરવાળાથી બાદ કરો.', 'ઉદાહરણ: એક પરિવારમાં 5 સભ્યોનો સરેરાશ ઉંમર 20 વર્ષ છે. તેમાંથી 3 સભ્યોની ઉંમર યથાક્રમે 18, 22, 20 વર્ષ છે. બાકીના 2 સભ્યોનો સરેરાશ ઉંમર શોધો. કુલ ઉંમર = 20×5 = 100 વર્ષ. 3 સભ્યોની કુલ ઉંમર = 18+22+20 = 60 વર્ષ. બાકીના 2 ની કુલ ઉંમર = 100−60 = 40 વર્ષ. તેમનો સરેરાશ = 40/2 = 20 વર્ષ.', "ભવિષ્ય/ભૂતકાળ સંબંધી પ્રશ્ન: જો 'p' વર્ષ પહેલા કે પછી સરેરાશ ઉંમર શોધવાની હોય, તો દરેક વ્યક્તિની ઉંમરમાં p વર્ષ ઉમેરો કે બાદ કરો, અને સરવાળામાં (n×p) નો ફેરફાર થાય છે.", 'બાળકના જન્મ પછી સરેરાશ ઉંમરમાં ઘટાડો કેમ થાય છે તે સમજવું જરૂરી છે — કુલ ઉંમરમાં બાળકની ઉંમર ઉમેરાય છે પણ વ્યક્તિઓની ગણતરી વધે છે.']

7. મિશ્રણ અને સરેરાશ (અનુપાત/અલ્ગેઝેશન પદ્ધતિ)

['જ્યારે બે અથવા વધુ મિશ્રણોને મिलाવવામાં આવે અને નવા મિશ્રણનો સરેરાશ શોધવો હોય, ત્યારે અલ્ગેઝેશન પદ્ધતિ ઉપયોગી છે.', 'મૂળભૂત સૂત્ર: જો A સરેરાશ w1 પ્રમાણ અને B સરેરાશ w2 પ્રમાણમાં મિશ્રિત થાય, તો મિશ્રણનો સરેરાશ = (w1×A + w2×B)/(w1+w2).', 'અલ્ગેઝેશન નિયમ: જો બે વસ્તુઓના સરેરાશ m1 અને m2 હોય અને મિશ્રણનો સરેરાશ M હોય, તો તેમનું પ્રમાણ = (m2−M) : (M−m1) થાય.', 'ઉદાહરણ: 15 kg ચાની કિંમત પ્રતિ kg ₹40 અને 25 kg ચાની કિંમત પ્રતિ kg ₹60 હોય. મિશ્રણની કિંમત શોધો. મિશ્રણનો સરેરાશ ભાવ = (15×40 + 25×60)/(15+25) = (600+1500)/40 = 2100/40 = ₹52.50 પ્રતિ kg.', 'અલ્ગેઝેશનથી પણ: (60−52.50) : (52.50−40) = 7.50 : 12.50 = 3:5, જે 15:25 = 3:5 સાથે મેળ ખાય છે.']

8. વિદ્યાર્થી/ખેલાડી/કर्मચારી સંબંધી સમસ્યાઓ

['આ પ્રકારની સમસ્યાઓમાં શ્રેણી, સરાસરી વેગ, સરાસરી ગતિ, સરાસરી આવક વગેરેના પ્રશ્નો આવે છે.', 'ગતિ (Velocity) નો સરેરાશ: જો એકસરખી અંતર ધરાવતી બે માર્ગો પર ગતિ v1 અને v2 હોય, તો સરાસરી ગતિ = 2v1v2/(v1+v2) — આ મહત્વપૂર્ણ સૂત્ર છે જે ઘણીવાર ભૂલથી v1+v2/2 લખવામાં આવે છે.', 'ઉદાહરણ: કોઈ વ્યક્તિ 40 km/h ની ગતિએ કોઈ સ્થળે જાય છે અને 60 km/h ની ગતિએ પરત ફરે છે. સરાસરી ગતિ = 2×40×60/(40+60) = 4800/100 = 48 km/h. ખોટો જવાબ 50 km/h થઈ શકે છે.', 'ખેલાડીના રન અથવા ગોલના સરાસરી: શરૂઆતના k મેચોમાં સરેરાશ A, પછી n-k મેચોમાં સરેરાશ B હોય, તો n મેચોનો સરેરાશ = (kA + (n-k)B)/n.', 'કર્મચારીઓની સરાસરી આવક: કેટલાક વ્યક્તિઓની સાપેક્ષિક આવક અને અન્યોની આવક આપેલી હોય, તો કુલ સમૂહની સરાસરી આવક શોધવા માટે વજનયુક્ત સરેરાશ વાપરો.']

9. સરેરાશ સંબંધી સામાન્ય ભૂલો અને ચોકસાઈ

['સૌથી સામાન્ય ભૂલ: સરાસરી ગતિના પ્રશ્નમાં v1+v2/2 લખી દેવું. સાચું સૂત્ર 2v1v2/(v1+v2) છે.', 'બીજી ભૂલ: સરવાળો શોધતી વખતે સંખ્યાઓની ગણતરી (count) ભૂલી જવી — સરવાળો = સરેરાશ × count, પણ count ખોટી ગણાઈ જાય તો જવાબ ખોટો આવે.', 'ત્રીજી ભૂલ: જ્યારે સંખ્યાઓમાંથી એક બદલાઈ જાય ત્યારે સરેરાશમાં થતો ફેરફાર = (બદલાયેલી સંખ્યા − મૂળ સંખ્યા)/કુલ સંખ્યાઓ — આ સૂત્ર યાદ રાખવું જરૂરી છે.', 'ચોથી ભૂલ: સરેરાશની કિંમત સૌથી મોટી સંખ્યાથી મોટી કે સૌથી નાની સંખ્યાથી નાની હોઈ શકે છે — આ અશક્ય છે, આ વાત યાદ રાખવી.', 'પાંચમી ભૂલ: ઋણ સંખ્યાઓના સરેરાશમાં નિશાની (sign) ભૂલી જવી. ઉદાહરણ: −5, −3, −10, −2, −7 નો સરેરાશ = −25/5 = −5 થાય, ન કે 5.', 'છઠ્ઠી ભૂલ: શૂન્ય સહિતની સંખ્યાઓનો સરેરાશ શોધતી વખતે શૂન્યનો ઉપયોગ ભૂલી જવો. ઉદા: 0, 5, 10, 15, 20 નો સરેરાશ = 50/5 = 10.']

10. પ્રતિસ્પર્ધી પરીક્ષા માટે ઉચ્ચ-મહત્વના આંકડા અને ટિપ્સ

['Gujarat Police Constable પરીક્ષામાં સરેરાશના વિભાગમાં સામાન્ય રીતે 2-4 પ્રશ્નો આવે છે, જેમાં મુખ્યત્વે ગણતરી અને સીધા પ્રયોગ પ્રશ્નો આવે છે.', 'તાકીદના સૂત્રો યાદ રાખો: (a) સરેરાશ = સરવાળો/ગણતરી (b) પ્રથમ n પ્રકૃત સંખ્યાઓનો સરેરાશ = (n+1)/2 (c) પ્રથમ n સમ સંખ્યાઓનો સરેરાશ = n+1 (d) પ્રથમ n વિષમ સંખ્યાઓનો સરેરાશ = n (e) સરાસરી ગતિ = 2ab/(a+b).', 'ઝડપી ગણતરી માટે: જો સરેરાશ આસન્ન પૂર્ણાંક હોય તો પહેલા તેને ધારીને વિચલન પદ્ધતિ વાપરો, કારણ કે સીધો સરવાળો કરતા ઝડપી અને ઓછી ભૂલવાળું.', 'અંકગણિતની કૌશલ્ય: 25/100 = 1/4, 33⅓/100 = 1/3, 16⅔/100 = 1/6 જેવા ભાગાકાર જાણવા — આ સરેરાશના પ્રશ્નોમાં વારંવાર મદદ કરે છે.', "વર્કિંગ ટિપ્સ: ગુમાવેલી સંખ્યા શોધવા માટે પ્રથમ કુલ સરવાળો શોધો, પછી આપેલી સંખ્યાઓનો સરવાળો બાદ કરો. ઉંમરના પ્રશ્નોમાં 'વર્ષ' ની ચોકસાઈ ધ્યાનમાં રાખો — કેટલાક પ્રશ્નોમાં 'હજુ થયા' અને 'હજુ ન થયા' વચ્ચે તફાવત હોય છે.", 'પરીક્ષામાં ઘડિયાળ સામે જોઈને પ્રશ્ન પસંદ કરો: સરેરાશના મોટા પ્રશ્નોમાં જ્યાં બહુ મોટી સંખ્યાઓ હોય ત્યાં અંદાજિત ગણતરીથી પણ સાચો વિકલ્પ શોધી શકાય છે.']

Important facts

  • સરેરાશ = આપેલી સંખ્યાઓનો સરવાળો ÷ સંખ્યાઓની કુલ સંખ્યા — આ પાયાનું સૂત્ર છે.
  • સરવાળો = સરેરાશ × સંખ્યાઓની ગણતરી — આ સૂત્રથી ગુમાવેલી સંખ્યા શોધાય છે.
  • પ્રથમ n પ્રકૃત સંખ્યાઓનો સરેરાશ = (n+1)/2; પ્રથમ n સમ સંખ્યાઓનો સરેરાશ = n+1; પ્રથમ n વિષમ સંખ્યાઓનો સરેરાશ = n.
  • k સંખ્યાઓનો સરેરાશ A1 અને m સંખ્યાઓનો સરેરાશ A2 હોય, તો સંયુક્ત સરેરાશ = (kA1+mA2)/(k+m).
  • સરાસરી ગતિ (સમાન અંતર માટે) = 2v1v2/(v1+v2) — v1+v2/2 નહીં!
  • જો દરેક સંખ્યામાં c ઉમેરવામાં આવે, તો સરેરાશમાં પણ c વધે છે; c વડે ગુણતા સરેરાશ પણ c વડે ગુણાય છે.
  • એક સંખ્યા બદલાઈ જાય ત્યારે સરેરાશમાં ફેરફાર = (નવી સંખ્યા − જૂની સંખ્યા) ÷ કુલ સંખ્યાઓ.
  • સરેરાશ હંમેશા મહત્તમ અને લઘુત્તમ મૂલ્યની વચ્ચે જ હોય છે.
  • Gujarat Police Constable પરીક્ષામાં આ વિભાગેથી 2-4 સીધા ગણતરી પ્રશ્નો આવે છે, તેથી સૂત્રોની મજબૂત યાદદાસ્ત જરૂરી છે.
  • અલ્ગેઝેશન પ્રમાણ સૂત્ર: (m2−M):(M−m1) = પહેલા પ્રમાણ : બીજા પ્રમાણ

Formulas and relationships

મૂળ સૂત્ર: સરેરાશ = (x₁ + x₂ + ... + xₙ) / n = સરવાળો / ગણતરી
ગુમાવેલી સંખ્યા: ગુમાવેલી સંખ્યા = (સરેરાશ × n) − (આપેલી બાકીની સંખ્યાઓનો સરવાળો)
પ્રથમ n પ્રકૃત સંખ્યાઓનો સરેરાશ: (n+1)/2
પ્રથમ n સમ સંખ્યાઓનો સરેરાશ: n+1
પ્રથમ n વિષમ સંખ્યાઓનો સરેરાશ: n
સંયુક્ત/વજનયુક્ત સરેરાશ: (w₁A₁ + w₂A₂ + ...) / (w₁ + w₂ + ...)
સરાસરી ગતિ (સમાન અંતર): 2v₁v₂ / (v₁ + v₂)
વિચલન પદ્ધતિ: સરેરાશ = ધારેલો સરેરાશ + (વિચલનોનો સરવાળો / n)
સંખ્યા બદલાવાથી સરેરાશ ફેરફાર: Δસરેરાશ = (નવી સંખ્યા − જૂની સંખ્યા) / n
અલ્ગેઝેશન પ્રમાણ: પ્રથમ : બીજું = (m₂ − M) : (M − m₁)

Common mistakes

  • સરાસરી ગતિ માટે v₁+v₂/2 લખી દેવું — સાચું સૂત્ર 2v₁v₂/(v₁+v₂) છે. આ સૌથી વધુ થતી ભૂલ છે.
  • ગુમાવેલી સંખ્યા શોધતી વખતે કુલ સંખ્યાઓની ગણતરી (n) ઓછી લખી દેવી — જેમ કે 6 સંખ્યાઓમાંથી 5 આપેલી હોય તો n=6 લેવું, 5 નહીં.
  • ક્રમિક સંખ્યાઓના સરેરાશમાં n/(n+1) અથવા (n+1)/n જેવું વ્યસ્ત લખી દેવું — યાદ રાખો: પ્રથમ n પ્રકૃત સંખ્યાઓનો સરેરાશ = (n+1)/2.
  • ઋણ સંખ્યાઓનો સરેરાશ શોધતી વખતે નિશાની (sign) ને અવગણી દેવી — (-5+-3+-10)÷3 = -6 થાય, +6 નહીં.
  • વજનયુક્ત સરેરાશમાં ગુણક (weights) ગડબડી જવા — જેના તત્વો વધુ હોય તેનાનું વજન વધુ રાખવું.
  • ઉંમરના પ્રશ્નમાં ભૂતકાળ/ભવિષ્ય માટે સબ્ત્રાશ / વ્યક્તિઓની ગણતરી વડે ગુણાકાર ન કરવો — દરેક વ્યક્તિની ઉંમરમાં ફેરફાર થાય છે, તેથી કુલ ફેરફાર = ફેરફાર × વ્યક્તિઓની સંખ્યા.
  • શૂન્ય સહિતની સંખ્યાઓનો સરેરાશ શોધતી વખતે શૂન્યને અવગણી દેવો — શૂન્ય પણ સરવાળામાં શામેલ છે અને ગણતરીમાં પણ.
  • આસન્ન મૂલ્ય પદ્ધતિમાં વિચલનોના ધન-ઋણ ચિહ્નોની ગેરહાજરીમાં ભૂલ — દરેક વિચલનની નિશાની સાચી રીતે લખવી.
