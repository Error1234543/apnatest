1. ગુણોત્તર અને અનુપાત — મૂળભૂત વ્યાખ્યાઓ

ગુણોત્તર અને અનુપાત એ ગણિતના બે પરસ્પર જોડાયેલા વિચારો છે જે વિષયવસ્તુઓની તુલના કરવા માટે વપરાય છે.

ગુણોત્તર (Ratio): જ્યારે બે અથવા વધુ રાશિઓની સાપેક્ષ તુલના કરવી હોય ત્યારે ગુણોત્તરનો ઉપયોગ થાય છે. a : b એટલે a/b. અહીં a ને અનુપાતી (antecedent) અને b ને રાશી (consequent) કહેવાય છે. ગુણોત્તર એક એકમરહિત સંખ્યા છે.

અનુપાત (Proportion): જ્યારે બે ગુણોત્તર સમાન હોય ત્યારે તેમને અનુપાત કહે છે. a : b = c : d ને a : b :: c : d તરીકે પણ દર્શાવવામાં આવે છે. આ સંદર્ભમાં b અને c ને 'મધ્ય પદો' અને a અને d ને 'અનુપાતી પદો' કહેવાય છે.

મૂળભૂત સિદ્ધાંત: પ્રૉપોર્શનમાં, મધ્ય પદોનો ગુણાકાર = અનુપાતી પદોનો ગુણાકાર. એટલે કે, a × d = b × c. આ સિદ્ધાંતનો ઉપયોગ જ્યારે પણ ગુણોત્તર અથવા અનુપાતના સમીકરણો ઉકેલવાના હોય ત્યારે થાય છે.

ઉદાહરણ: જો 3 : x = 6 : 12 હોય, તો 3 × 12 = 6 × x → 36 = 6x → x = 6.

2. ગુણોત્તરના પ્રકારો અને સાદુરૂપ

સાદુરૂપ: ગુણોત્તરનું સાદુરૂપ એટલે તેને LCM અથવા HCF વડે ભાગીને શ્રેષ્ઠ સ્વરૂપમાં લખવું. ઉદા: 18 : 24 → 3 : 4 (HCF = 6).

ગુણોત્તરના પ્રકારો:
- સરખો ગુણોત્તર: જ્યારે બે રાશિઓ સમાન હોય તો 1 : 1.
- વ્યસ્ત ગુણોત્તર: જો a : b = x : y હોય, તો વ્યસ્ત ગુણોત્તર b : a = y : x.
- અનુક્રમણ ગુણોત્તર (Composite Ratio): બે અથવા વધુ ગુણોત્તરોના ગુણાકારથી મળતો ગુણોત્તર. ઉદા: (2:3) અને (4:5) નો અનુક્રમણ ગુણોત્તર = (2×4) : (3×5) = 8 : 15.
- સમગુણોત્તર (Duplicate Ratio): a² : b².
- વિગુણોત્તર (Sub-Duplicate Ratio): √a : √b.
- ત્રિગુણોત્તર (Triplicate Ratio): a³ : b³.

મહત્વનું નિયમ: ગુણોત્તરમાં અંશ અને છેદ બંને સમાન સંખ્યાએ ગુણતા કે ભાગતા ગુણોત્તર બદલાતું નથી. આ વિધિનો ઉપયોગ ગુણોત્તર સાદુરૂપ આપવા માટે કરવામાં આવે છે.

પરીક્ષા ટિપ: ગુણોત્તર સાદુરૂપ આપવા HCF શોધવાની પ્રક્રિયા ઝડપી હોવી જોઈએ. ઉદા: 48 : 72 → HCF = 24 → 2 : 3.

3. અનુપાતના ગુણધર્મો

જો a : b = c : d = e : f = ... = k (સમાન ગુણોત્તર) હોય, તો નીચેના ગુણધર્મો લાગુ પડે છે:

1. સંયોજન ગુણધર્મ (Componendo): જો a/b = c/d હોય, તો (a + b)/b = (c + d)/d.
2. વિયોજન ગુણધર્મ (Dividendo): જો a/b = c/d હોય, તો (a − b)/b = (c − d)/d.
3. સંયોગ-વિયોગ ગુણધર્મ (Componendo et Dividendo): જો a/b = c/d હોય, તો (a + b)/(a − b) = (c + d)/(c − d).
4. ભાગફળ ગુણધર્મ (Addendo): જો a/b = c/d = e/f, તો (a + c + e)/(b + d + f).
5. વ્યસ્ત ગુણધર્મ (Invertendo): a/b = c/d ⇒ b/a = d/c.
6. વિપરીત ગુણધર્મ (Alternendo): a/b = c/d ⇒ a/c = b/d.

આ ગુણધર્મોનો ઉપયોગ ચોક્કસ પ્રકારના પ્રશ્નોમાં ગુણોત્તરના અજ્ઞાત પદ શોધવા માટે થાય છે. આપઘાતી પ્રશ્નોમાં વિશેષ કરીને Compo-Dividendoનો ઉપયોગ કરવો પડે છે.

ઉદાહરણ: જો (3x + 5)/(2x − 3) = 8/5 હોય, તો Compo-Dividendo વાપરીને x શોધો. (3x+5)/(2x−3) = 8/5 → (3x+5+2x−3)/(3x+5−2x+3) = 8/1 → (5x+2)/(x+8) = 8 → 5x+2 = 8x+64 → 3x = −62 → x = −62/3.

4. અનુપાતમાં વિભાજન

વિભાજનનો અર્થ: કોઈ રાશિને બે અથવા વધુ ભાગોમાં આપેલ ગુણોત્તર મુજબ વિભાજિત કરવી.

દ્વિભાજન: જો R મુદ્દતને a : b ગુણોત્તરમાં વિભાજિત કરવી હોય, તો:
- પ્રથમ ભાગ = a/(a+b) × R
- દ્વિતીય ભાગ = b/(a+b) × R

ત્રિભાજન: જો R મુદ્દતને a : b : c ગુણોત્તરમાં વિભાજિત કરવી હોય, તો:
- પ્રથમ ભાગ = a/(a+b+c) × R
- દ્વિતીય ભાગ = b/(a+b+c) × R
- તૃતીય ભાગ = c/(a+b+c) × R

ઉદાહરણ: ₹840 ને 3 : 4 : 5 ગુણોત્તરમાં વિભાજિત કરો.
સરવાળો = 3+4+5 = 12
પ્રથમ ભાગ = 3/12 × 840 = ₹210
દ્વિતીય ભાગ = 4/12 × 840 = ₹280
તૃતીય ભાગ = 5/12 × 840 = ₹350

ઉલટું વિભાજન: જ્યારે એક ભાગ આપેલ હોય અને ગુણોત્તર મુજબ બાકીના ભાગ શોધવાના હોય.

પરીક્ષા ટિપ: વિભાજનના પ્રશ્નોમાં ધ્યાન આપો કે ગુણોત્તરનો ક્રમ કયા ક્રમમાં વિભાજન કરવાનું છે.

5. મિશ્રણ અને અલ્લીગેશન (Alligation)

અલ્લીગેશનનો ઉપયોગ: જ્યારે બે અથવા વધુ પદાર્થોને મિશ્રિત કરીને નવા મિશ્રણની કિંમત/ગુણધર્મ શોધવાની હોય ત્યારે અલ્લીગેશન પદ્ધતિ વપરાય છે.

મૂળભૂત સૂત્ર: જો બે પદાર્થોની એકમ કિંમત क्रमશः p અને q હોય અને તેમનું મિશ્રણ a : b ગુણોત્તરમાં હોય, તો:
(a × p + b × q)/(a + b) = મિશ્રણની એકમ કિંમત

અલ્લીગેશન નિયમ: જો બે પદાર્થોની કિંમત क्रमशः m અને n હોય અને તેમનું મિશ્રણ r હોય, તો:
(મિશ્રણ : પ્રથમ પદાર્થ) / (મિશ્રણ : દ્વિતીય પદાર્થ) = (n − r) : (r − m)

ઉદાહરણ: ₹40/કેજી અને ₹60/કેજી ના ચાવલાનું મિશ્રણ ₹48/કેજી ની કિંમતે વેચાય છે. ગુણોત્તર શોધો.
પદ્ધતિ: (60−48) : (48−40) = 12 : 8 = 3 : 2

ગુણાત્મિક મિશ્રણ: જ્યારે બે પ્રવાહીનું મિશ્રણ કરીને નવા ગુણોત્તરમાં ગર્ભિત પદાર્થોનું પ્રમાણ શોધવું હોય ત્યારે મિશ્રણના ગુણોત્તરોનો સરવાળો/અંશ કરીને કામ કરવું પડે છે.

વિશેષ સ્થિતિ: જ્યારે કોઈ પદાર્થ બીજા પદાર્થ સાથે પ્રક્રિયા કરે અને પરિણામે ઘનत्व બદલાય, ત્યારે અલ્લીગેશનનો ઉપયોગ વજન/ઘનत्वના અનુપાતમાં થાય છે.

6. સમાંસરિક પ્રગતિ (A.P.) અને ગુણોત્તર પ્રગતિ (G.P.)

સમાંસરિક પ્રગતિ (A.P.): એવી શ્રેણી જ્યાં દરેક પદ પાછલા પદમાંથી સમાન રાશિ ઉમેરવાથી મળે. સામાન્ય ભેદ d = a₂ − a₁.

સમાન ગુણોત્તર (Common Difference) d = a₂ − a₁ = a₃ − a₂ = ...
nમું પદ: aₙ = a₁ + (n − 1)d
પહેલા n પદોનો સરવાળો: Sₙ = n/2 [2a₁ + (n − 1)d]

ગુણોત્તર પ્રગતિ (G.P.): એવી શ્રેણી જ્યાં દરેક પદ પાછલા પદ સાથે ગુણાકાર કરવાથી મળે. સામાન્ય ગુણોત્તર r = a₂/a₁.

nમું પદ: aₙ = a₁ × rⁿ⁻¹
પહેલા n પદોનો સરવાળો:
- જો r < 1: Sₙ = a₁(1 − rⁿ)/(1 − r)
- જો r > 1: Sₙ = a₁(rⁿ − 1)/(r − 1)
અનંત G.P.નો સરવાળો (|r| < 1): S∞ = a₁/(1 − r)

G.P. અને A.P. વચ્ચેનો સંબંધ: જો a, b, c G.P. માં હોય, તો b² = a × c (સામાન્ય ગુણોત્તર r = b/a = c/b).

ઉદાહરણ (A.P.): પ્રથમ પદ 5, સામાન્ય ભેદ 3 હોય તો 10મું પદ = 5 + 9×3 = 32.
ઉદાહરણ (G.P.): પ્રથમ પદ 2, સામાન્ય ગુણોત્તર 3 હોય તો 5મું પદ = 2 × 3⁴ = 162.

7. સીધું અને વ્યસ્ત પ્રમાણ

સીધું પ્રમાણ (Direct Proportion): જ્યારે એક રાશિ વધે ત્યારે બીજી રાશિ પણ વધે અથવા ઓછી થાય ત્યારે બીજી ઓછી થાય. xy = constant.

ઉદાહરણ: જો 5 કિમી માટે 2 લીટર ઇંધણ લાગે, તો 15 કિમી માટે કેટલા ઇંધણ? (5/2 = 15/x → x = 6 લીટર)

વ્યસ્ત પ્રમાણ (Inverse Proportion): જ્યારે એક રાશિ વધે ત્યારે બીજી ઓછી થાય અથવા ઓછી થાય ત્યારે બીજી વધે. xy = k (constant).

ઉદાહરણ: 12 લોકો કામ 10 દિવસમાં કરે, તો 15 લોકો કેટલા દિવસમાં કરશે? (12 × 10 = 15 × x → x = 8 દિવસ)

મિશ્ર પ્રમાણ: જ્યારે ત્રણ રાશિઓનો સંબંધ હોય — બે રાશિઓ સીધી અને એક વ્યસ્ત હોય.

ઉદાહરણ: જો m માણસો n દિવસમાં p મીટરનું કામ કરે, તો q માણસો r દિવસમાં કેટલું કામ કરશે?
સૂત્ર: (m × n)/p = (q × r)/x, જ્યાં x એ નવું કામ છે.

પરીક્ષા ટિપ: સીધા પ્રમાણમાં a/b = c/d; વ્યસ્ત પ્રમાણમાં a×b = c×d.

8. ચતુર્થ પ્રમાણ (Fourth Proportional) અને સમાંસર પ્રમાણ (Mean Proportional)

ચતુર્થ પ્રમાણ: જો a : b = c : d હોય, તો d એ a, b, c નું ચતુર્થ પ્રમાણ છે. d = b×c/a.

ઉદાહરણ: 4, 6, 10 નું ચતુર્થ પ્રમાણ શોધો. 4:6::10:x → x = 6×10/4 = 15.

સમાંસર પ્રમાણ (Mean Proportional): જો a : x = x : b હોય, તો x એ a અને b નું સમાંસર પ્રમાણ છે. x² = a×b → x = √(a×b).

ઉદાહરણ: 4 અને 9 નું સમાંસર પ્રમાણ = √(36) = 6.

તૃતીય પ્રમાણ (Third Proportional): જો a : b = b : c હોય, તો c એ a અને b નું તૃતીય પ્રમાણ છે. c = b²/a.

ઉદાહરણ: 4 અને 6 નું તૃતીય પ્રમાણ = 36/4 = 9.

તાર્કિક પ્રશ્નો: કોઈ ચાર સંખ્યાઓનો સરવાળો 120 છે. પ્રથમ બેનો ગુણોત્તર 2:3, તૃતીય અને ચોથાનો ગુણોત્તર 3:5 છે. બીજી સંખ્યા કેટલી?
સેટઅપ: પ્રથમ બે 2x અને 3x. તૃતીય અને ચોથો 3y અને 5y. ગુણોત્તર જોડાણ: 3x = 3y → x = y. સરવાળો: 2x + 3x + 3x + 5x = 13x = 120. x ≈ 9.23 (આ જોડાણ ગુણોત્તર પ્રશ્ન છે).

9. મહત્વપૂર્ણ સૂત્રો અને યાદ રાખવાની વસ્તુઓ

મુખ્ય સૂત્રો:
1. સાદુરૂપ: a : b = a÷hcf : b÷hcf
2. સમાંસર પ્રમાણ: √(a×b)
3. ચતુર્થ પ્રમાણ: b×c/a
4. તૃતીય પ્રમાણ: b²/a
5. અનુપાતના નિયમો: a×d = b×c
6. Compo-Dividendo: (a+b)/(a−b) = (c+d)/(c−d)

યાદ રાખવાની વસ્તુઓ:
- ગુણોત્તર એકમરહિત છે
- a : b = b : a ન હોય (તફાવત છે)
- a² : b² એ duplicate ratio છે
- સરવાળાના ગુણોત્તરોના નિયમો સરળતાથી લાગુ પડે છે
- a/b = c/d હોય તો (a+c)/(b+d) પણ સમાન ગુણોત્તર ધરાવે છે

પરીક્ષા માટેની ટિપ્સ:
- અલ્લીગેશનનો નિયમ યાદ રાખો: (મધ્યમ મૂલ્ય − ઓછું મૂલ્ય) : (ઊંચું મૂલ્ય − મધ્યમ મૂલ્ય)
- વિભાજન પ્રશ્નોમાં સાદુરૂપ કરવાનું ભૂલો નહીં
- A.P. અને G.P. ના સૂત્રો યાદ રાખો
- સીધા/વ્યસ્ત પ્રમાણમાં ગુણાકાર/ભાગાકાર ખ્યાલ સાચો રાખો

10. સામાન્ય ભૂલો અને એક્ઝામ ટિપ્સ

સામાન્ય ભૂલો:
1. ગુણોત્તરનું સાદુરૂપ કર્યા વિના આગળ વધવું
2. ચતુર્થ પ્રમાણમાં અંશ/છેદ ઉલટાવી દેવો — યાદ રાખો: d = b×c/a, a નીચે છે
3. સમાંસર પ્રમાણ માટે વર્ગમૂળ લેવાનું ભૂલી જવું
4. વિભાજન પ્રશ્નોમાં ગુણોત્તરનો સરવાળો કર્યા વિના ઉત્તર આપવો
5. અલ્લીગેશનમાં ઓછી અને ઊંચી કિંમત ગૂંચવી ફેરવી દેવી
6. A.P./G.P. ના સૂત્રોમાં n અને n−1 ગૂંચવણ

એક્ઝામ ટિપ્સ:
- સાદુરૂપ કરો: HCF શોધીને તરત સાદું રૂપ આપો
- અલ્લીગેશન ડાયાગ્રામ બનાવો: ઉપરની કિંમતો, મધ્યમાં મિશ્રણ, નીચે તફાવત ગણો
- વિભાજનમાં પ્રથમ કુલ ભાગ શોધો, પછી દરેક ભાગનો ગુણોત્તર લાગુ કરો
- Compo-Dividendo વાપરો જ્યારે સીધું સૂત્ર લાગુ પડતું ન હોય
- અંતિમ સરવાળો/સરવાળો તપાસો — તમામ ભાગોનો સરવાળો અસલ રકમ આવવી જોઈએ

અનુશીલન સૂચના: દરેક પ્રકારના પ્રશ્નમાં કમોંત 10-15 પ્રશ્નોનો અભ્યાસ કરો. અલ્લીગેશન અને વિભાજનના પ્રશ્નો વિશેષ રીતે પસંદ કરો કારણ કે તે ગુજરાત પોલીસ કોન્સ્ટેબલ પરીક્ષામાં વારંવાર આવે છે.

Important facts

  • ગુણોત્તર એકમરહિત છે — a : b = a/b.
  • અનુપાતમાં મધ્ય પદોનો ગુણાકાર = અનુપાતી પદોનો ગુણાકાર: a×d = b×c.
  • ચતુર્થ પ્રમાણ: a:b::c:d ⇒ d = bc/a.
  • સમાંસર પ્રમાણ: a:x::x:b ⇒ x = √(ab).
  • તૃતીય પ્રમાણ: a:b::b:c ⇒ c = b²/a.
  • અલ્લીગેશન: (મિશ્રણ−ઓછું):(ઊંચું−મિશ્રણ) = વિરોધી ગુણોત્તર.
  • સીધું પ્રમાણ: x₁/x₂ = y₁/y₂. વ્યસ્ત પ્રમાણ: x₁×y₁ = x₂×y₂.
  • A.P. nમું પદ: aₙ = a + (n−1)d. સરવાળો: Sₙ = n/2[2a+(n−1)d].
  • G.P. nમું પદ: aₙ = arⁿ⁻¹. સરવાળો: Sₙ = a(rⁿ−1)/(r−1).
  • Componendo et Dividendo: a/b = c/d ⇒ (a+b)/(a−b) = (c+d)/(c−d).

Formulas and relationships

સાદુરૂપ: a : b → (a÷HCF) : (b÷HCF)
અનુપાતનો મૂળભૂત નિયમ: a×d = b×c
ચતુર્થ પ્રમાણ: d = b×c/a
સમાંસર પ્રમાણ: x = √(a×b)
તૃતીય પ્રમાણ: c = b²/a
Componendo: (a+b)/b = (c+d)/d
Dividendo: (a−b)/b = (c−d)/d
Componendo et Dividendo: (a+b)/(a−b) = (c+d)/(c−d)
વિભાજન: R ને a:b માં → પ્રથમ = aR/(a+b), દ્વિતીય = bR/(a+b)
અલ્લીગેશન: (r−m):(n−r) = પ્રથમ:દ્વિતીય ભાગ
A.P. nમું પદ: aₙ = a₁ + (n−1)d
A.P. સરવાળો: Sₙ = n/2[2a₁+(n−1)d]
G.P. nમું પદ: aₙ = a₁×rⁿ⁻¹
G.P. સરવાળો: Sₙ = a₁(rⁿ−1)/(r−1) જો r>1, Sₙ = a₁(1−rⁿ)/(1−r) જો r<1
અનંત G.P. સરવાળો: S∞ = a₁/(1−r) જો |r|<1
Addendo ગુણધર્મ: a/b=c/d=e/f ⇒ (a+c+e)/(b+d+f)

Common mistakes

  • ગુણોત્તર સાદુરૂપ કર્યા વિના આગળ વધવું — હંમેશા HCF શોધીને સાદું રૂપ આપો.
  • ચતુર્થ પ્રમાણમાં b×c/a ને અથવાa/b×c કહી ચૂકી કરવી — યાદ રાખો d = bc/a.
  • અલ્લીગેશનમાં ઓછી અને ઊંચી કિંમત ગૂંચવી ફેરવી દેવી — ઓછી કિંમત ઊંચી તરફ, ઊંચી કિંમત ઓછી તરફ મૂકવી.
  • વિભાજન પ્રશ્નમાં ગુણોત્તરનો સરવાળો કર્યા વિના ને સીધો ઉત્તર આપી દેવો.
  • G.P. ના સૂત્રમાં n અને n−1 વચ્ચે ગૂંચવણ — nમું પદ a₁rⁿ⁻¹ (n−1) અને સરવાળો (rⁿ−1).
  • સમાંસર પ્રમાણ માટે vર્ગમૂળ લેવાનું ભૂલી જવું — x = √(ab).
  • Compo-Dividendo વાપરવાની જરૂરિયાત ન રહેતાં સીધું લાગુ કરી દેવું.
  • A.P. સરવાળાના સૂત્રમાં (n−1) ને બદલે n મૂકી દેવો.
  • વ્યસ્ત પ્રમાણમાં સીધા પ્રમાણનું સૂત્ર લાગુ કરી દેવું — યાદ રાખો: x₁y₁ = x₂y₂.
  • જ્યારે ગુણોત્તરમાં ત્રણ રાશિ હોય ત્યારે ભૂલથી બે જ રાશિ લઈ લેવી — દરેક રાશિ યોગ્ય સ્થાને મૂકવી.
