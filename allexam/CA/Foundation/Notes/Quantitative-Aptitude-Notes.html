1. Business Mathematics — Sets, Relations, and Functions

Sets form the foundation of modern mathematics and are essential for understanding relations, functions, probability, and statistics.

• A set is a well-defined collection of distinct objects. Sets can be represented as roster form (listing elements) or set-builder form (describing properties).
• Types of sets: finite, infinite, empty/null set, singleton set, equal sets, equivalent sets, subset, proper subset, universal set, power set.
• Operations on sets: Union (A ∪ B), Intersection (A ∩ B), Difference (A − B), Complement (A'), Symmetric Difference.
• De Morgan's Laws: (A ∪ B)' = A' ∩ B' and (A ∩ B)' = A' ∪ B'.
• Number of elements: n(A ∪ B) = n(A) + n(B) − n(A ∩ B). For three sets: n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A ∩ B) − n(B ∩ C) − n(C ∩ A) + n(A ∩ B ∩ C).

Relations: A relation R from set A to set B is a subset of A × B. Types include reflexive, symmetric, transitive, and equivalence relations. An equivalence relation partitions a set into disjoint equivalence classes.

Functions: A function f: A → B assigns each element of A exactly one element of B. Types: one-one (injective), onto (surjective), bijective (both). Composite functions: (f ∘ g)(x) = f(g(x)). Inverse function exists only for bijections.
• Logarithmic function: log_b(x), exponential function: b^x. Properties of logarithms: log(MN) = log M + log N, log(M/N) = log M − log N, log M^n = n log M.

2. Matrices and Determinants

Matrices are rectangular arrays of numbers arranged in rows and columns. They are fundamental tools in business mathematics for solving systems of linear equations.

• Order of matrix: m × n means m rows and n columns.
• Types: row matrix, column matrix, square matrix, diagonal matrix, scalar matrix, identity matrix, zero matrix, symmetric matrix (A' = A), skew-symmetric matrix (A' = −A), orthogonal matrix (AA' = I).
• Operations: Addition (same order required), Scalar multiplication, Matrix multiplication (not commutative: AB ≠ BA generally), Transpose (A').
• Properties: (A+B)' = A' + B', (AB)' = B'A', (A')' = A, k(AB) = (kA)B = A(kB).
• Minors and Cofactors: Minor M_ij is the determinant obtained by deleting row i and column j. Cofactor C_ij = (−1)^(i+j) · M_ij.
• Determinant of a square matrix A: |A|. For 2×2: |A| = ad − bc. For 3×3, expand along any row or column.
• Properties of determinants: |A'| = |A|, |kA| = k^n|A| for n×n matrix, |AB| = |A|·|B|, if any two rows/columns are identical then |A| = 0.
• Adjoint and Inverse: Adj(A) is the transpose of the cofactor matrix. Inverse A^(-1) = Adj(A)/|A|, exists only if |A| ≠ 0.
• System of equations: AX = B. If |A| ≠ 0, X = A^(-1)B (unique solution). If |A| = 0 and (Adj A)B ≠ 0, no solution (inconsistent). If |A| = 0 and (Adj A)B = 0, infinite solutions.
• Cramer's Rule: For system ax + by = e, cx + dy = f, x = D_x/D, y = D_y/D where D is the coefficient determinant.

3. Commercial Arithmetic — Compound Interest, Annuities, and Depreciation

These concepts are vital for financial decision-making in business and accounting contexts.

Compound Interest: Amount A = P(1 + r/100)^n where P = principal, r = rate per period (%), n = number of periods.
For compounding half-yearly: A = P(1 + r/200)^(2n). For quarterly: A = P(1 + r/400)^(4n).
Compound Interest CI = A − P.
Rate equivalent: If amount doubles in n years, approximate rate ≈ 72/n percent (Rule of 72).

Annuity: A series of equal payments made at regular intervals.
• Future Value of Ordinary Annuity: FV = R[(1 + i)^n − 1]/i, where R = periodic payment, i = interest rate per period, n = number of periods.
• Present Value of Ordinary Annuity: PV = R[1 − (1 + i)^(-n)]/i.
• Annuity Due (payments at beginning): Multiply ordinary annuity value by (1 + i).
• Perpetuity: PV = R/i (infinite series).

Sinking Fund: Periodic deposit to accumulate a future sum. R = S·i/[(1 + i)^n − 1], where S is the target amount.

Depreciation: Reduction in asset value over time.
• Straight Line Method: Annual depreciation = (Cost − Salvage Value)/Useful Life. Book Value = Cost − Accumulated Depreciation.
• Diminishing Balance (Reducing Balance) Method: Book Value = P(1 − r/100)^n, where r is the depreciation rate per annum.
• Capital Recovery Factor: A/P,i,n = i(1+i)^n/[(1+i)^n − 1].

4. Trigonometry

Trigonometry deals with relationships between angles and sides of triangles and is widely used in engineering and geometry-based problems.

Basic Ratios: sin θ = Perpendicular/Hypotenuse, cos θ = Base/Hypotenuse, tan θ = Perpendicular/Base. Reciprocals: csc θ = 1/sin θ, sec θ = 1/cos θ, cot θ = 1/tan θ.

Fundamental Identities:
• sin²θ + cos²θ = 1
• 1 + tan²θ = sec²θ
• 1 + cot²θ = csc²θ

Standard Values: sin 0°=0, sin 30°=1/2, sin 45°=1/√2, sin 60°=√3/2, sin 90°=1. Similar values for cos and tan.

Trigonometric Equations:
• sin θ = sin α ⇒ θ = nπ + (−1)^n α
• cos θ = cos α ⇒ θ = 2nπ ± α
• tan θ = tan α ⇒ θ = nπ + α

General Solutions of Common Equations:
• sin θ = 0 ⇒ θ = nπ
• cos θ = 0 ⇒ θ = (2n+1)π/2
• tan θ = 0 ⇒ θ = nπ

Product-to-Sum and Sum-to-Product Formulas:
• sin C + sin D = 2sin[(C+D)/2]cos[(C−D)/2]
• sin C − sin D = 2cos[(C+D)/2]sin[(C−D)/2]
• cos C + cos D = 2cos[(C+D)/2]cos[(C−D)/2]
• cos C − cos D = −2sin[(C+D)/2]sin[(C−D)/2]

Properties of Triangles (Law of Sines, Cosines, Tangents):
• a/sin A = b/sin B = c/sin C = 2R (where R is circumradius)
• a² = b² + c² − 2bc cos A
• (b − c)cos(A/2) = a sin[(B−C)/2], etc.
• Area = ½bc sin A = √[s(s−a)(s−b)(s−c)] (Heron's formula), s = semi-perimeter.
• Projection formula: a = b cos C + c cos B.

5. Calculus — Limits, Continuity, Differentiation, and Integration

Calculus is the study of change and is divided into differential calculus and integral calculus.

Limits:
• lim(x→a) [f(x) ± g(x)] = lim f(x) ± lim g(x)
• lim(x→a) [f(x)·g(x)] = lim f(x) · lim g(x)
• lim(x→a) [f(x)/g(x)] = lim f(x) / lim g(x), provided lim g(x) ≠ 0
• Standard limits: lim(x→0) sin x/x = 1, lim(x→0) (1−cos x)/x = 0, lim(x→0) (e^x − 1)/x = 1, lim(x→0) log(1+x)/x = 1, lim(x→a) (x^n − a^n)/(x − a) = na^(n−1)
• Indeterminate forms: 0/0, ∞/∞, 0·∞, ∞−∞, 0⁰, 1^∞, ∞⁰. Use L'Hôpital's rule for 0/0 and ∞/∞.

Continuity: f is continuous at x = a if lim(x→a) f(x) = f(a). A function is continuous on an interval if it is continuous at every point in that interval.

Differentiation:
• Power rule: d/dx(x^n) = nx^(n−1)
• Product rule: d/dx[u·v] = u'v + uv'
• Quotient rule: d/dx[u/v] = (u'v − uv')/v²
• Chain rule: d/dx[f(g(x))] = f'(g(x)) · g'(x)
• Standard derivatives: d/dx(e^x) = e^x, d/dx(a^x) = a^x ln a, d/dx(sin x) = cos x, d/dx(cos x) = −sin x, d/dx(tan x) = sec²x, d/dx(log x) = 1/x, d/dx(sinh x) = cosh x, d/dx(cosh x) = sinh x
• Logarithmic differentiation: For y = u^v, take ln both sides: ln y = v ln u, then differentiate implicitly.
• Implicit differentiation: Differentiate both sides w.r.t. x, treating y as a function of x.
• Second derivative: d²y/dx². Used for concavity and maxima/minima tests.
• Rolle's Theorem and Mean Value Theorem (Lagrange): Essential theoretical results.

Integration:
• ∫x^n dx = x^(n+1)/(n+1) + C, n ≠ −1
• ∫e^x dx = e^x + C, ∫a^x dx = a^x/ln a + C
• ∫sin x dx = −cos x + C, ∫cos x dx = sin x + C
• ∫sec²x dx = tan x + C, ∫cosec²x dx = −cot x + C
• ∫1/x dx = ln|x| + C
• ∫1/√(a²−x²) dx = sin^(-1)(x/a) + C
• ∫1/(a²+x²) dx = (1/a)tan^(-1)(x/a) + C
• ∫1/(x√(x²−a²)) dx = (1/a)sec^(-1)(x/a) + C
• Integration by parts: ∫u dv = uv − ∫v du
• Definite integral: ∫_a^b f(x)dx = F(b) − F(a), where F is antiderivative of f.

6. Linear Programming Problem (LPP)

Linear Programming is a mathematical technique for optimizing (maximizing or minimizing) a linear objective function subject to linear constraints.

Key Terms:
• Decision variables: Variables (x, y, ...) that determine the outcome.
• Objective function: Linear function Z = ax + by + ... to be maximized or minimized.
• Constraints: Linear inequalities or equations restricting decision variables.
• Feasible region: Region satisfying all constraints simultaneously.
• Feasible solution: Any point within the feasible region.
• Optimal solution: Best feasible solution maximizing or minimizing the objective function.

Methods of Solution:
• Graphical Method (for 2 variables): Plot all constraint lines, identify feasible region (shaded area), find corner points, evaluate Z at each corner point. The optimum occurs at a corner point (or along an edge if multiple optima exist).
• Corner Point Theorem: If the feasible region is bounded, the optimal value of Z occurs at a corner point. If unbounded, check if the open half-plane defined by ax + by > Z₀ (for max) or ax + by < Z₀ (for min) has no intersection with the feasible region.
• Simplex Method (for ≥ 2 variables): Uses tabular method with slack, surplus, and artificial variables. Introduces Big M or Two-Phase method for constraints requiring artificial variables.

Standard Form Requirements:
• All constraints as equations (using slack/surplus variables)
• All variables ≥ 0
• Objective function to be maximized (minimization converted by negating Z)

Common Mistakes:
• Forgetting non-negativity constraints
• Misidentifying feasible region direction (above/below line)
• Evaluating Z at wrong points
• Not checking unbounded cases separately

7. Measures of Central Tendency — Mean, Median, Mode

Central tendency measures describe the center or typical value of a data distribution.

Arithmetic Mean (AM):
• Simple mean: x̄ = Σx_i/n for raw data; x̄ = Σf_i x_i/Σf_i for frequency data
• Short-cut method: x̄ = A + Σf_i d_i/Σf_i where d_i = x_i − A (assumed mean)
• Step-deviation method: x̄ = A + h·[Σf_i u_i/Σf_i] where u_i = (x_i − A)/h
• For grouped data with class intervals, use mid-values as x_i
• Merits: Rigidly defined, easy to understand, least affected by sampling fluctuation
• Demerits: Affected by extreme values, cannot be computed for open-ended distributions easily

Median:
• Positional average: middle value when data is arranged in order
• For individual data (n odd): Median = value of ((n+1)/2)th item; (n even): average of n/2th and (n/2+1)th items
• For discrete series: Locate cumulative frequency just ≥ N/2; Median = corresponding value
• For continuous series: Median = l + [(N/2 − cf)/f]·h where l = lower boundary of median class, cf = cumulative freq before median class, f = freq of median class, h = class width
• Merits: Not affected by extreme values, can be located graphically, suitable for open-ended classes

Mode:
• Most frequent value; value with highest frequency
• For grouped data: Mode = l + [(f_1 − f_0)/(2f_1 − f_0 − f_2)]·h where l = lower limit of modal class, f_1 = freq of modal class, f_0 = freq of preceding class, f_2 = freq of succeeding class
• Relation among mean, median, mode for moderately skewed distributions: Mode ≈ 3 Median − 2 Mean
• Merits: Easy to understand, not affected by extreme values, can be located by inspection

8. Measures of Dispersion — Range, Variance, Standard Deviation, Coefficient of Variation

Dispersion measures describe the spread or variability of data around central tendency.

Range: Largest value − Smallest value. Simple but ignores most data.

Mean Deviation (MD):
• MD = Σ|x_i − x̄|/n (raw data); MD = Σf_i|x_i − x̄|/Σf_i (frequency data)
• From median: MD_med = Σ|x_i − Med|/n
• MD is less affected by extreme values than range but ignores algebraic signs.

Variance and Standard Deviation:
• Variance σ² = Σ(x_i − x̄)²/n for population; s² = Σ(x_i − x̄)²/(n−1) for sample
• Computational formula: σ² = Σx_i²/n − (x̄)²
• Shortcut: σ² = Σd_i²/n − (Σd_i/n)² where d_i = x_i − A
• Step-deviation: σ = h·√[Σu_i²/n − (Σu_i/n)²]
• For grouped data with frequencies: σ² = Σf_i(x_i − x̄)²/Σf_i
• Standard Deviation SD = √Variance. It is the most important measure of dispersion.
• Merits of SD: Rigidly defined, based on all observations, capable of algebraic treatment, small sampling fluctuations.

Coefficient of Variation (CV):
• CV = (σ/x̄) × 100%
• Used to compare variability between two or more datasets with different units or significantly different means.
• Higher CV = more dispersed; Lower CV = more consistent.
• Important in quality control and finance for risk assessment.

Quartile Deviation (Semi-Interquartile Range):
• QD = (Q₃ − Q₁)/2; CV_QD = (Q₃ − Q₁)/(Q₃ + Q₁) × 100%

9. Correlation and Regression Analysis

Correlation measures the strength and direction of linear relationship between two variables. Regression provides equations for prediction.

Karl Pearson's Coefficient of Correlation (r):
• r = Σ(x_i − x̄)(y_i − ȳ) / √[Σ(x_i − x̄)² · Σ(y_i − ȳ)²]
• Computational form: r = [nΣxy − Σx·Σy] / √[{nΣx² − (Σx)²}{nΣy² − (Σy)²}]
• Step-deviation form: r = [nΣuv − Σu·Σv] / √[{nΣu² − (Σu)²}{nΣv² − (Σv)²}] where u = (x−A)/h, v = (y−B)/k
• Properties: −1 ≤ r ≤ +1; r = +1 perfect positive correlation; r = −1 perfect negative correlation; r = 0 no linear correlation.
• r is independent of origin and scale.

Spearman's Rank Correlation:
• Used for qualitative/ordinal data
• D_s = 1 − [6Σd²/(n(n²−1))] where d = difference in ranks
• Apply when data is ranked or when correlation is needed for subjective qualities.

Regression Lines:
• Regression line of y on x: y − ȳ = b_yx(x − x̄), where b_yx = r·(σ_y/σ_x) = Cov(x,y)/Var(x)
• Regression line of x on y: x − x̄ = b_xy(y − ȳ), where b_xy = r·(σ_x/σ_y) = Cov(x,y)/Var(y)
• Both lines pass through (x̄, ȳ)
• If r = ±1, the two regression lines coincide
• If r = 0, the lines are perpendicular
• b_yx · b_xy = r²
• Important: r² gives the coefficient of determination (percentage of variation explained)

Finding r from regression coefficients:
r = ±√(b_yx · b_xy). Sign of r = sign of regression coefficients.

10. Probability Theory and Discrete Probability Distributions

Probability quantifies uncertainty and is foundational for statistical inference and risk analysis in business.

Basic Concepts:
• Experiment: Process with well-defined outcomes. Event: Subset of outcomes.
• Sample space S: Set of all possible outcomes.
• Probability P(E) = n(E)/n(S) for equally likely outcomes.
• axioms: 0 ≤ P(E) ≤ 1; P(S) = 1; P(∅) = 0
• P(E') = 1 − P(E)
• P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
• For mutually exclusive events: P(A ∪ B) = P(A) + P(B)
• Conditional probability: P(A|B) = P(A ∩ B)/P(B), P(B|A) = P(A ∩ B)/P(A)
• Independent events: P(A ∩ B) = P(A)·P(B)
• Bayes' Theorem: P(A_i|B) = P(A_i)·P(B|A_i) / ΣP(A_j)·P(B|A_j)

Discrete Probability Distributions:
• Binomial Distribution: X ~ B(n, p), P(X=r) = ^nC_r · p^r · q^(n−r), where q = 1−p
– Mean = np, Variance = npq, SD = √(npq)
– Used for binary outcomes (success/failure) with constant probability
• Poisson Distribution: X ~ Poi(λ), P(X=r) = e^(-λ) · λ^r/r!, λ > 0
– Mean = λ, Variance = λ, SD = √λ
– Used for rare events over fixed interval/time
– Approximation to binomial when n is large, p is small, np = λ is moderate
• Normal Distribution: X ~ N(μ, σ²), continuous distribution
– Symmetric about mean μ, bell-shaped curve
– Standard normal: Z = (X − μ)/σ ~ N(0, 1)
– Key probabilities: P(μ−σ < X < μ+σ) ≈ 0.6827, P(μ−2σ < X < μ+2σ) ≈ 0.9545
– Used extensively in statistical inference and quality control

Properties of Expectation:
• E(aX + b) = aE(X) + b
• Var(aX + b) = a²·Var(X)
• E(X ± Y) = E(X) ± E(Y)

11. Index Numbers

Index numbers measure relative changes in variables like prices, production, or wages over time.

Types:
• Price Index: Measures change in price level ( CPI, Wholesale Price Index, Retail Price Index)
• Quantity Index: Measures change in physical output
• Value Index: Combines price and quantity changes

Methods of Construction:
• Simple Aggregate Method: P₀₁ = ΣP₁/ΣP₀ × 100
• Simple Average of Price Relatives: P₀₁ = (1/n)·Σ[(P₁/P₀)×100]
• Weighted Aggregate Method: P₀₁ = Σ(P₁·W)/Σ(P₀·W) × 100
• Weighted Average of Price Relatives: P₀₁ = Σ[(P₁/P₀)×100 · W]/ΣW

Fisher's Ideal Index:
• P_F = √[ΣP₁Q₀/ΣP₀Q₀ × ΣP₁Q₁/ΣP₀Q₁] × 100
• Combines Laspeyres and Paasche; satisfies Time Reversal Test and Factor Reversal Test
• Laspeyres: P_L = ΣP₁Q₀/ΣP₀Q₀ × 100 (base year quantities as weights)
• Paasche: P_P = ΣP₁Q₁/ΣP₀Q₁ × 100 (current year quantities as weights)

Test of Index Numbers:
• Time Reversal Test: P₀₁ × P₁₀ = 1 (Fisher's satisfies)
• Factor Reversal Test: P₀₁ × Q₀₁ = V₀₁ (value ratio) — Fisher's satisfies
• Circular Test: P₀₁ × P₁₂ × P₂₀ = 1

Adjustment for Base Year Change:
• New index = Old index × (New base value/Old base value)

12. Time Series Analysis

Time series data consists of observations recorded at successive time intervals. Analysis helps identify patterns and forecast future values.

Components of Time Series:
• Secular Trend (T): Long-term upward or downward movement (years/decades)
• Seasonal Variation (S): Regular periodic fluctuations within a year (monthly/quarterly patterns)
• Cyclical Variation (C): Wave-like movements lasting several years (business cycles: prosperity, recession, depression, recovery)
• Irregular/Random Variation (I): Unpredictable, non-repeating fluctuations (natural disasters, strikes, wars)
• Model: Y = T × S × C × I (multiplicative) or Y = T + S + C + I (additive)

Measuring Trend:
• Free-hand Drawing Method: Draw a smooth curve through plotted points
• Least Squares Method: Fit Y = a + bX where b = Σ(X−X̄)(Y−Ȳ)/Σ(X−X̄)², a = Ȳ − bX̄
– For equal-time intervals, take origin at middle year: ΣX = 0, a = Ȳ, b = ΣXY/ΣX²
– Y = a + bX gives trend values; deviations from trend give combined S×C×I
• Moving Average Method: Smooth out irregular fluctuations
– Odd-order MA: Place at center (3-year, 5-year MA)
– Even-order MA: Centered moving average (e.g., 4-year MA is averaged pairwise)
– MA eliminates seasonal and irregular components, leaving trend-cyclical component

Seasonal Index Calculation:
• Method of Percentages from Moving Average: Calculate trend values, compute (Actual/Trend)×100 for each season, average by season across years, normalize to total 400 (quarterly) or 1200 (monthly).

Important facts

  • De Morgan's Laws: (A∪B)'=A'∩B' and (A∩B)'=A'∪B' — frequently tested in set theory questions.
  • For matrices, AB≠BA in general. The property (AB)^T = B^T·A^T is essential and often confused.
  • In compound interest, always match the rate period with the compounding period. Half-yearly rate = annual rate/2, number of periods = years×2.
  • Annuity due differs from ordinary annuity by a factor of (1+i) — payments at beginning vs. end of period.
  • For trigonometric equations, the general solution contains integer n. Always check for extraneous solutions.
  • L'Hôpital's Rule applies ONLY to 0/0 or ∞/∞ indeterminate forms. Do not apply to other forms directly.
  • In LPP, the optimal solution always lies at a corner point of the feasible region (if one exists). For unbounded regions, verify by checking the objective function direction.
  • Mode ≈ 3(Median) − 2(Mean) holds for moderately skewed distributions, not for highly skewed or bimodal ones.
  • Coefficient of Variation is unitless and allows comparison of variability across datasets with different units or widely different means.
  • If both regression coefficients are positive, r is positive; if both negative, r is negative. r² = byx × bxy.
  • For Binomial: variance < mean (since npq < np when q<1). For Poisson: variance = mean. For Normal: symmetric, mean = median = mode.
  • Fisher's Ideal Index is the only index that satisfies both Time Reversal and Factor Reversal tests.
  • In time series, multiplicative model is used when seasonal variation increases with the level of the series; additive model when seasonal variation is constant.
  • Standard normal table gives P(Z ≤ z). Remember symmetry: P(Z ≤ −z) = P(Z ≥ z) = 1 − P(Z ≤ z).

Formulas and relationships

Compound Amount: A = P(1 + r/100)^n; CI = A − P. For half-yearly: A = P(1 + r/200)^(2n). For quarterly: A = P(1 + r/400)^(4n).
Future Value of Ordinary Annuity: FV = R[(1+i)^n − 1]/i. Present Value: PV = R[1 − (1+i)^(-n)]/i. Perpetuity PV = R/i.
Straight Line Depreciation: Annual = (Cost − Salvage)/Life. Diminishing Balance: BV = P(1 − r/100)^n.
Determinant (2×2): |A| = ad − bc. Adjoint inverse: A^(-1) = Adj(A)/|A|. Cramer's Rule: x = Dx/D, y = Dy/D.
Trig Identity: sin²θ + cos²θ = 1; 1+tan²θ = sec²θ; 1+cot²θ = csc²θ. Law of Sines: a/sinA = b/sinB = c/sinC = 2R.
Limit: lim(x→0) sin x/x = 1; lim(x→0) (e^x−1)/x = 1; lim(x→0) log(1+x)/x = 1. L'Hôpital's Rule for 0/0 and ∞/∞.
Derivatives: d/dx(x^n)=nx^(n−1); d/dx(e^x)=e^x; d/dx(sin x)=cos x; d/dx(log x)=1/x. Product: (uv)'=u'v+uv'. Chain: [f(g(x))]'=f'(g(x))·g'(x).
Integrals: ∫x^n dx=x^(n+1)/(n+1)+C; ∫e^x dx=e^x+C; ∫sin x dx=−cos x+C; ∫1/x dx=ln|x|+C; ∫1/(a²+x²)dx=(1/a)tan⁻¹(x/a)+C.
Integration by Parts: ∫u dv = uv − ∫v du.
Arithmetic Mean (raw): x̄ = Σxᵢ/n. (grouped): x̄ = Σfᵢxᵢ/Σfᵢ. Short-cut: x̄ = A + Σfᵢdᵢ/Σfᵢ.
Median (continuous): Med = l + [(N/2 − cf)/f]·h. Mode: Mod = l + [(f₁−f₀)/(2f₁−f₀−f₂)]·h.
Variance: σ² = Σ(xᵢ−x̄)²/n. SD: σ = √(Σ(xᵢ−x̄)²/n). CV: CV = (σ/x̄)×100%.
Correlation (Pearson): r = [nΣxy−Σx·Σy]/√[{nΣx²−(Σx)²}{nΣy²−(Σy)²}]. Spearman: Ds = 1−6Σd²/[n(n²−1)].
Regression y on x: y−ȳ = b_yx(x−x̄), b_yx = r·σ_y/σ_x. Regression x on y: x−x̄ = b_xy(y−ȳ), b_xy = r·σ_x/σ_y. r² = b_yx·b_xy.
Probability: P(A∪B) = P(A)+P(B)−P(A∩B). Conditional: P(A|B)=P(A∩B)/P(B). Bayes: P(Aᵢ|B)=P(Aᵢ)P(B|Aᵢ)/ΣP(Aⱼ)P(B|Aⱼ).
Binomial: P(X=r)=ⁿCᵣ·pʳ·q⁽ⁿ⁻ʳ⁾; Mean=np; Var=npq. Poisson: P(X=r)=e⁻λ·λʳ/r!; Mean=λ; Var=λ.

Least Squares Trend: Y = a + bX, b=Σ(X−X̄)(Y−Ȳ)/Σ(X−X̄)², a = Ȳ−bX̄. For centered X: a=Ȳ, b=ΣXY/ΣX².

Common mistakes

  • Confusing annuity due with ordinary annuity — forgetting to multiply by (1+i) for payments at the beginning of each period.
  • Using simple interest formula for compound interest problems, especially when the compounding frequency is not annually.
  • Applying L'Hôpital's rule to indeterminate forms other than 0/0 and ∞/∞ (e.g., 1^∞, 0⁰, ∞⁰) without first converting them.
  • Taking the absolute value incorrectly when simplifying trigonometric expressions involving even powers.
  • Forgetting that matrix multiplication is not commutative — assuming AB = BA in determinant or adjoint calculations.
  • In LPP, including the interior of the feasible region as candidate for optimum instead of checking only corner points.
  • For unbounded feasible regions in LPP, assuming an optimum always exists without verifying whether the objective function's open half-plane intersects the feasible region.
  • Using the mode formula for grouped data when the distribution has no clear modal class (e.g., uniform or bimodal with equal peak frequencies).
  • Computing correlation coefficient using raw scores without subtracting the mean, leading to computational errors. Prefer the computational or step-deviation formula.
  • Taking the positive square root for r without considering the sign of the regression coefficients. The sign of r must match the sign of b_yx and b_xy.
  • Mixing up the regression coefficients: confusing b_yx (=r·σ_y/σ_x) with b_xy (=r·σ_x/σ_y).
  • In probability, multiplying P(A) and P(B) to find P(A∩B) without first verifying that A and B are independent.
  • Applying the binomial distribution formula when trials are not independent or probability changes from trial to trial (hypergeometric situation).
  • For Fisher's index, using current year quantities as weights for both Paasche and Laspeyres, which defeats the purpose of the geometric mean.
  • In time series, applying even-order moving averages without centering, resulting in trend values that do not align with actual time periods.
  • Calculating seasonal indices without normalizing them so their sum equals 400 (quarterly) or 1200 (monthly).
  • For variance of a linear transformation: writing Var(aX+b) = a·Var(X)+b instead of the correct a²·Var(X).
  • Using the arithmetic mean when the data has open-ended classes, where median or mode is more appropriate.
