Card 1

Complex Number – Basic Operations Simplify: (3 + 4i) + (2 − 6i) (3 + 4i)(2 − 6i) (3 + 4i)/(2 − 6i)

Addition: (3+4i)+(2−6i) = 5 − 2i Multiplication: (3+4i)(2−6i) = 6 − 18i + 8i − 24i² = 6 − 10i + 24 = 30 − 10i Division: Multiply numerator & denominator by conjugate (2+6i): (3+4i)(2+6i)/(4+36) = (6+18i+8i+24i²)/40 = (6+26i−24)/40 = (−18+26i)/40 = −9/20 + 13i/20 🔑 Key: i² = −1; conjugate of (a+bi) = (a−bi)

Card 2

Quadratic Equation – Discriminant & Nature of Roots ax² + bx + c = 0, Δ = b² − 4ac Δ > 0, Δ perfect square → two distinct real rational roots Δ > 0, Δ not perfect square → two distinct real irrational roots Δ = 0 → two equal real roots Δ < 0 → two complex conjugate roots Example: 2x² − 7x + 3 = 0. Find roots.

Δ = (−7)² − 4(2)(3) = 49 − 24 = 25 > 0, perfect square → two distinct rational roots. x = [7 ± √25]/4 = (7±5)/4 x₁ = 12/4 = 3, x₂ = 2/4 = ½ 🔑 Remember: Sum of roots = −b/a, Product = c/a (3 + ½) = 7/2 ✓, (3)(½) = 3/2 ✓

Card 3

Logarithm – Key Properties & Rules 1. logₐ(mn) = logₐm + logₐn 2. logₐ(m/n) = logₐm − logₐn 3. logₐ(mⁿ) = n·logₐm 4. logₐa = 1, logₐ1 = 0 5. logₐm = 1/(logₘa) — Change of base 6. a^(logₐx) = x If log₁₀2 = 0.3010, find log₁₀8.

log₁₀8 = log₁₀(2³) = 3·log₁₀2 = 3 × 0.3010 = 0.9030 ⚠️ Common Mistake: log(m + n) ≠ log m + log n ❌ Only applies to PRODUCT and QUOTIENT, not SUM/DIFFERENCE. Another frequent error: 2·log x ≠ log(x²) only when x < 0. But for CA Foundation, x is assumed positive unless stated otherwise.

Card 4

Matrices – Addition, Multiplication & Transpose Rules: • A + B defined only if same order (m×n) • AB defined only if columns of A = rows of B • Matrix multiplication is NOT commutative: AB ≠ BA generally • (AB)ᵀ = BᵀAᵀ • (Aᵀ)ᵀ = A If A = [1 2; 3 4], B = [0 1; 1 0], find AB and BA.

AB = [1 2; 3 4] × [0 1; 1 0] = [1×0+2×1 1×1+2×0; 3×0+4×1 3×1+4×0] = [2 1; 4 3] BA = [0 1; 1 0] × [1 2; 3 4] = [0×1+1×3 0×2+1×4; 1×1+0×3 1×2+0×4] = [3 4; 1 2] ✅ Confirmed: AB ≠ BA (non-commutative) 🔑 Note: If AB = BA, matrices are called COMMUTATIVE.

Card 5

Determinant – Sarrus Rule & Properties For 3×3 matrix: |A| = a(ei−fh) − b(di−fg) + c(dh−eg) Key Properties: • |Aᵀ| = |A| • |kA| = kⁿ|A| (n = order) • |AB| = |A| · |B| • |A⁻¹| = 1/|A| if |A| ≠ 0 Find determinant of [2 1 3; 1 0 2; 3 1 1].

|A| = 2(0×1 − 2×1) − 1(1×1 − 2×3) + 3(1×1 − 0×3) = 2(−2) − 1(1−6) + 3(1) = −4 + 5 + 3 = 4 Since |A| = 4 ≠ 0, A is NON-SINGULAR and invertible. |A⁻¹| = 1/4 ⚠️ Common Error: Expanding along wrong row/column changes sign of terms. Always follow: + − + pattern for first row expansion.

Card 6

Permutation – Arrangement Formula Number of arrangements of r objects from n distinct objects: P(n,r) = n!/(n−r)! Special cases: • Linear arrangements: n! • Circular arrangements (distinct items): (n−1)! • Circular arrangements (with identical items): (n−1)!/product of factorials of identical counts In how many ways can 5 people sit around a circular table?

Circular arrangement (all distinct): = (5 − 1)! = 4! = 24 ways Why (n−1)!? Because in a circle, rotating all positions doesn't create a new arrangement — so we fix one person's position and arrange the remaining (n−1). ⚠️ Circular permutation with identical objects (e.g., beads on a necklace): = (n−1)! / 2 (because flipping also gives same arrangement) 📌 P(n,n) = n!

Card 7

Combination – Selection Formula C(n,r) = n!/[r!(n−r)!] Also written as ⁿCᵣ or "n choose r" Key Identity: C(n,r) = C(n,n−r) Difference from Permutation: • Combination → selection only (order doesn't matter) • Permutation → selection + arrangement (order matters) From 8 players, select a team of 5. How many ways?

C(8,5) = 8!/(5! × 3!) = (8×7×6)/(3×2×1) = 56 ways To verify: C(8,5) = C(8,3) = 56 ✓ (symmetry identity) ⚠️ Common Trap: "Select 2 from 6 AND arrange them" = P(6,2), NOT C(6,2) C(6,2) = 15 (just selection) P(6,2) = 30 (selection + arrangement) 🔑 Always ask: Does ORDER matter? Yes → Permutation. No → Combination.

Card 8

Binomial Theorem – General & Middle Term (a + b)ⁿ = Σ(k=0 to n) ⁿCₖ · aⁿ⁻ᵏ · bᵏ General term: T_{r+1} = ⁿCᵣ · aⁿ⁻ʳ · bʳ Finding middle term(s): • n even → 1 middle term: T_{n/2 + 1} • n odd → 2 middle terms: T_{(n+1)/2} and T_{(n+3)/2} Find the coefficient of x⁴ in (2x − 3)⁶.

General term: T_{r+1} = ⁶Cᵣ · (2x)⁶⁻ʳ · (−3)ʳ Need power of x to be 4: 6−r = 4 → r = 2 T₃ = ⁶C₂ · (2x)⁴ · (−3)² = 15 × 16x⁴ × 9 = 2160 x⁴ Coefficient = 2160 ⚠️ Don't forget to include the coefficient from (2x)⁴ = 16x⁴ and (−3)² = 9! 🔑 Also remember: Coefficient of xʳ in (1+x)ⁿ = ⁿCᵣ (when a=1). This is frequently tested.

Card 9

Arithmetic Progression (AP) – Key Formulas nth term: Tₙ = a + (n−1)d Sum of n terms: Sₙ = n/2[2a + (n−1)d] = n/2(a + l) where a = first term, d = common difference, l = last term Property: If a,b,c are in AP → 2b = a + c Find sum of first 20 terms of AP: 3, 7, 11, 15, ...

a = 3, d = 4, n = 20 S₂₀ = 20/2[2(3) + (20−1)(4)] = 10[6 + 76] = 10 × 82 = 820 Verification – last term: a₂₀ = 3 + 19×4 = 79 S₂₀ = 20/2(3+79) = 10×82 = 820 ✓ ⚠️ Confusion Alert: Sₙ = n/2(a+l) is easier when last term is known; use the full formula when it isn't.

Card 10

Geometric Progression (GP) – Key Formulas nth term: Tₙ = arⁿ⁻¹ Sum of n terms: Sₙ = a(rⁿ − 1)/(r − 1) for r ≠ 1 Infinite GP (|r| < 1): S∞ = a/(1−r) Product property: If a,b,c in GP → b² = ac First term = 4, r = 1/2. Find S∞.

S∞ = a/(1−r) = 4/(1 − 1/2) = 4/(1/2) = 8 ⚠️ Critical Condition: Infinite GP sum exists ONLY when |r| < 1. If |r| ≥ 1, the sum diverges → no finite S∞. Also check: T₅ = ar⁴ = 4 × (1/2)⁴ = 4/16 = ¼ Terms: 4, 2, 1, ½, ¼,... decreasing toward 0 ✓ 🔑 If r > 1: use Sₙ = a(rⁿ − 1)/(r−1) If r < 1: use Sₙ = a(1 − rⁿ)/(1−r) (same result, different form)

Card 11

Measures of Central Tendency – Mean, Median, Mode Mean (x̄) = Σxᵢ/n (for ungrouped) Median: Middle value when data is ordered. • Odd n → (n+1)/2 th term • Even n → average of (n/2)th and (n/2+1)th terms Mode: Most frequently occurring value For grouped data: Median = l + [(N/2 − cf)/f] × h Mode = l + [(f₁−f₀)/(2f₁−f₀−f₂)] × h Find median of: 12, 15, 8, 20, 15, 25, 30.

Step 1: Arrange in ascending order: 8, 12, 15, 15, 20, 25, 30 n = 7 (odd) → Median = (7+1)/2 = 4th term = 15 Mode = 15 (appears twice, most frequent) Mean = (8+12+15+15+20+25+30)/7 = 125/7 ≈ 17.86 Empirical relation (rough approximation): Mode ≈ 3(Median) − 2(Mean) = 3(15) − 2(17.86) = 45 − 35.72 = 9.28 This only holds approximately for moderately skewed distributions.

Card 12

Measures of Dispersion – Range, Variance, SD Range = Maximum − Minimum Mean Deviation (MD) = Σ|xᵢ − x̄|/n Variance (σ²) = Σ(xᵢ − x̄)²/n Standard Deviation (σ) = √Variance Coefficient of Variation (CV) = (σ/x̄) × 100% For grouped data: σ = √[Σf(x−x̄)²/N] Data: 4, 6, 8, 10, 12. Find SD and CV.

x̄ = (4+6+8+10+12)/5 = 40/5 = 8 Deviations: −4, −2, 0, 2, 4 Squared deviations: 16, 4, 0, 4, 16 Variance σ² = (16+4+0+4+16)/5 = 40/5 = 8 SD σ = √8 = 2√2 ≈ 2.83 CV = (σ/x̄) × 100 = (2.83/8) × 100 ≈ 35.35% 📌 Interpretation: Higher CV means more relative variability. ⚠️ CA Foundation frequently asks: Which series is more variable? Compare CVs of two series.

Card 13

Correlation Coefficient (r) – Pearson's Formula r = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)² · Σ(yᵢ−ȳ)²] Alternative: r = [nΣxy − ΣxΣy] / √[(nΣx²−(Σx)²)(nΣy²−(Σy)²)] Properties: • −1 ≤ r ≤ 1 • r = +1: perfect positive linear • r = −1: perfect negative linear • r = 0: no linear correlation Given: Σx=40, Σy=80, Σxy=540, Σx²=360, Σy²=1100, n=10. Find r.

r = [10(540) − (40)(80)] / √[(10×360 − 40²)(10×1100 − 80²)] Numerator = 5400 − 3200 = 2200 Denominator = √[(3600−1600)(11000−6400)] = √[2000 × 4600] = √9,200,000 = √(92 × 10⁵) = √(920 × 10⁴) ≈ 3033.15 r = 2200/3033.15 ≈ 0.725 ✅ Positive moderate correlation. ⚠️ Must check units cancel in r — it is DIMENSIONLESS.

Card 14

Regression Lines & Regression Coefficients Regression line of y on x: y − ȳ = byx(x − x̄) Regression line of x on y: x − x̄ = bxy(y − ȳ) byx = r(σy/σx), bxy = r(σx/σy) Product: byx · bxy = r² → |r| ≤ 1 always Both lines intersect at (x̄, ȳ) If byx = 0.8 and bxy = 0.5, find r.

r² = byx × bxy = 0.8 × 0.5 = 0.40 r = ±√0.40 ≈ ±0.632 Sign of r = sign of regression coefficients. Both positive → r = +0.632 ⚠️ Critical CA Foundation Point: • If byx > bxy → σy > σx • If byx < bxy → σy < σx • If byx = bxy → σy = σx and r = ±1 🔑 The regression line of y on x is used to PREDICT y from x. The regression line of x on y predicts x from y.

Card 15

Probability – Addition & Conditional Rules P(A ∪ B) = P(A) + P(B) − P(A ∩ B) If A, B mutually exclusive: P(A ∪ B) = P(A) + P(B) Conditional: P(A|B) = P(A∩B)/P(B), P(B) > 0 Independent events: P(A∩B) = P(A)·P(B) A coin tossed twice. P(at least one head)?

Sample space: {HH, HT, TH, TT}, n(S)=4 Let A = event with at least one head = {HH, HT, TH} P(A) = 3/4 Using complement: P(at least one H) = 1 − P(no H) P(no H) = P(TT) = 1/4 P(at least one H) = 1 − 1/4 = 3/4 ✓ 🔑 "At least one" → always use 1 − P(none). Faster than listing all favorable cases. ⚠️ "At least one head in 3 tosses" = 1 − (½)³ = 7/8. Pattern: 1 − (½)ⁿ.

Card 16

Bayes' Theorem & Total Probability Total Probability: P(A) = Σ P(A|Bᵢ)·P(Bᵢ) Bayes' Theorem: P(Bᵢ|A) = P(A|Bᵢ)·P(Bᵢ) / Σ[P(A|Bⱼ)·P(Bⱼ)] Bag I: 3 red, 2 blue. Bag II: 1 red, 4 blue. One bag chosen at random, one ball drawn → Red. P(it came from Bag I)?

P(B₁) = P(B₂) = 1/2 P(R|B₁) = 3/5, P(R|B₂) = 1/5 P(R) = P(R|B₁)P(B₁) + P(R|B₂)P(B₂) = (3/5)(1/2) + (1/5)(1/2) = 3/10 + 1/10 = 4/10 = 2/5 P(B₁|R) = (3/5 × 1/2) / (2/5) = (3/10)/(2/5) = 3/10 × 5/2 = 3/4 🔑 Step-by-step approach: 1. Identify all mutually exclusive causes (B₁, B₂...) 2. Write P(Bᵢ) for each 3. Write P(A|Bᵢ) — likelihood of event given each cause 4. Apply formula directly ⚠️ Common mistake: forgetting to multiply by prior P(Bᵢ).

Card 17

DE MOIVRE'S THEOREM & COMPLEX ROOTS De Moivre's: [r(cos θ + i sin θ)]ⁿ = rⁿ(cos nθ + i sin nθ) nth roots of unity: zⁿ = 1 → z = cos(2kπ/n) + i sin(2kπ/n), k = 0,1,...,n−1 Sum of nth roots of unity = 0 Product = (−1)ⁿ⁺¹ Find cube roots of unity and verify their sum.

z³ = 1 → z = cos(2kπ/3) + i sin(2kπ/3), k = 0,1,2 k=0: z₀ = cos 0 + i sin 0 = 1 k=1: z₁ = cos(2π/3) + i sin(2π/3) = −½ + i√3/2 = ω k=2: z₂ = cos(4π/3) + i sin(4π/3) = −½ − i√3/2 = ω² Roots: 1, ω, ω² Sum: 1 + ω + ω² = 1 − ½ + i√3/2 − ½ − i√3/2 = 0 ✓ Key properties: ω³ = 1, 1 + ω + ω² = 0 ω² = ω̄ (complex conjugate) 🔑 For any polynomial zⁿ = 1, the roots form vertices of a regular n-gon on the unit circle.

Card 18

QUICK REVISION – Must-Memorize Formulas 1. Quadratic formula: x = [−b ± √(b²−4ac)]/2a 2. P(n,r) = n!/(n−r)!, C(n,r) = n!/[r!(n−r)!] 3. (a+b)ⁿ general term: T_{r+1} = ⁿCᵣ · aⁿ⁻ʳ · bʳ 4. AP: Tₙ = a+(n−1)d, Sₙ = n/2[2a+(n−1)d] 5. GP: Tₙ = arⁿ⁻¹, Sₙ = a(rⁿ−1)/(r−1), S∞ = a/(1−r) 6. σ² = Σ(x−x̄)²/n, CV = (σ/x̄)×100 7. r = Σ(xy)−n(x̄)(ȳ) / √[(Σx²−nx̄²)(Σy²−nȳ²)] 8. P(A∪B) = P(A)+P(B)−P(A∩B) 9. Bayes: P(B|A) = P(A|B)·P(B)/P(A) 10. byx = r(σy/σx), bxy = r(σx/σy)

All 10 formulas above are HIGH-YIELD for CA Foundation. ⚡ Exam Tips: • Memorize factorials up to 10!: 10! = 3,628,800 • Know: 5! = 120, 6! = 720, 7! = 5040 • For SD calculation, use shortcut: σ = √[Σx²/n − (Σx/n)²] • In regression problems, always verify: byx · bxy = r² ≤ 1 • For correlation, r is always between −1 and +1 — if answer exceeds this, there's an arithmetic error. ⚠️ Most frequently tested topics in order: 1. Logarithm properties → 2. Permutation/Combination 3. AP/GP → 4. Mean, SD, Correlation 5. Probability (especially Bayes') → 6. Regression lines

Card 19

COMMON MISTAKES & TRAPS – CA Foundation QA ❌ Mistake 1: C(n,r) = n!/r! — Forgot (n−r)! in denominator ✅ Correct: C(n,r) = n!/[r!(n−r)!] ❌ Mistake 2: S∞ for GP when |r| > 1 ✅ Infinite sum only for |r| < 1 ❌ Mistake 3: log(m+n) = log m + log n ✅ Only log(mn) = log m + log n ❌ Mistake 4: P(A or B) = P(A) + P(B) always ✅ Only for MUTUALLY EXCLUSIVE events ❌ Mistake 5: r > 1 in correlation ✅ r must satisfy −1 ≤ r ≤ 1 ❌ Mistake 6: Matrix AB = BA always ✅ Matrix multiplication is NOT commutative ❌ Mistake 7: Using SD formula without squaring deviations ✅ σ² requires (xᵢ−x̄)² — never forget the square

These traps appear EVERY year in CA Foundation exams. Additional important points: • Standard Deviation is always non-negative (σ ≥ 0) • Variance has same units squared; SD restores original units • When finding median of EVEN data: average the TWO middle values, not just pick one • In permutations with repetition: n!/(p!·q!·r!) where p,q,r are counts of identical items • For Bayes' theorem problems: always draw a tree diagram first • In regression: the angle between the two regression lines is zero only when r = ±1 • Mean Deviation uses ABSOLUTE deviations; SD uses SQUARED deviations → SD is more sensitive to outliers
