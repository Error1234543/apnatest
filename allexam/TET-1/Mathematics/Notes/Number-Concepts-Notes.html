TET-1GujaratiNotes

૧. સંખ્યા પદ્ધતિનો પરિચય (Introduction to Number System)

ગણિતની મૂળભૂત પાયા પર સંખ્યા પદ્ધતિ રચાયેલ છે. પ્રારંભિક વર્ગો (૧-૫) માટે વિદ્યાર્થીઓને નીચે મુજબના સંખ્યા પ્રકારો સમજાવવામાં આવે છે:

• કુદરતી સંખ્યાઓ (Natural Numbers): ૧ થી શરૂ થતી ધન પૂર્ણ સંખ્યાઓ — ૧, ૨, ૩, ૪, ... . બરાફકર (0) કુદરતી સંખ્યા નથી.

• પૂર્ણ સંખ્યાઓ (Whole Numbers): ૦ સહિતની સંખ્યાઓ — ૦, ૧, ૨, ૩, ... . દરેક કુદરતી સંખ્યા પૂર્ણ સંખ્યા છે, પણ ૦ કુદરતી સંખ્યા નથી.

• પૂર્ણાંક સંખ્યાઓ (Integers): ધન, ઋણ અને શૂન્ય સંખ્યાઓ — ..., -૨, -૧, ૦, ૧, ૨, ... .

• યુગ્મ સંખ્યા (Even Numbers): ૨ વડે ભાગી શકાય તેવી સંખ્યાઓ (૦, ૨, ૪, ૬, ...).

• અયુગ્મ સંખ્યા (Odd Numbers): ૨ વડે ભાગી શકાતી નથી (૧, ૩, ૫, ૭, ...).

• અવિભાજ્ય સંખ્યા (Prime Numbers): ૧ સિવાય બીજો કોઈ ગુણક નહીં ધરાવતી સંખ્યા — ૨, ૩, ૫, ૭, ૧૧, ... . ૨ એકમાત્ર યુગ્મ અવિભાજ્ય સંખ્યા છે.

• ભાજ્ય સંખ્યા (Composite Numbers): ૧ અને તે સંખ્યા સિવાયના અવયવ ધરાવતી સંખ્યા — ૪, ૬, ૮, ૯, ૧૦, ...

TET-1 વિદ્યાર્થીઓએ આ શ્રેણીઓના તફાવતો અને તેમના ગુણધર્મો જાણતા હોવા જોઈએ.

૨. સ્થાનક કિંમત અને સામાન્ય કિંમત (Place Value and Face Value)

કોઈ પણ સંખ્યામાંના અંકોની મૂલ્ય સમજવી ગણિતની મહત્વપૂર્ણ કુશળતા છે.

• સામાન્ય કિંમત (Face Value): અંકની તેની નિષ્પક્ષ કિંમત. ઉદા. ૫૭૩૨ માં ૭ ની સામાન્ય કિંમત = ૭.

• સ્થાનક કિંમત (Place Value): અંકનો જ્યાંનો હિસ્સો. આધાર ૧૦ ની પાવર મુજબ:
- એકમ (Units) = ૧૦⁰ = ૧
- દશક (Tens) = ૧૦¹ = ૧૦
- શતક (Hundreds) = ૧૦² = ૧૦૦
- હજાર (Thousands) = ૧૦³ = ૧૦૦૦
- દશ હજાર (Ten Thousands) = ૧૦⁴ = ૧૦૦૦૦
- લાખ (Lakhs) = ૧૦⁵ = ૧૦૦૦૦૦
- દશ લાખ (Ten Lakhs) = ૧૦⁶ = ૧૦૦૦૦૦૦

ઉદાહરણ: ૬૪૫,૩૨૭ માં
- ૬ ની સ્થાનક કિંમત = ૬ × ૧૦૦૦૦૦ = ૬૦૦,૦૦૦
- ૪ ની સ્થાનક કિંમત = ૪ × ૧૦૦૦૦ = ૪૦,૦૦૦
- ૫ ની સ્થાનક કિંમત = ૫ × ૧૦૦ = ૫૦૦

ગુજરાતી અંક પદ્ધતિ: ૧,૦૦,૦૦,૦૦૦ (એક કરોડ) = ૧૦⁷. આ ભારતીય સંખ્યા પદ્ધતિ છે જે TET-1 માં વપરાય છે.

શૂન્ય (૦) ની સ્થાનક કિંમત હંમેશા શૂન્ય હોય છે, ભલે તે કોઈપણ સ્થાનમાં હોય.

૩. સંખ્યાઓ પરની મૂળભૂત વિક્રિયાઓ (Basic Operations on Numbers)

ચાર મૂળભૂત વિક્રિયાઓ અને તેમના ગુણધર્મો:

• સંયોજન (Addition):
- ક્રમ વિનિમય ગુણધર્મ: a + b = b + a
- સાહચર્ય ગુણધર્મ: (a + b) + c = a + (b + c)
- તટસ્થ તત્વ: a + 0 = a

• વ્યવકલન (Subtraction):
- ક્રમ વિનિમય નથી: a - b ≠ b - a
- તટસ્થ તત્વ: a - 0 = a

• ગુણાકાર (Multiplication):
- ક્રમ વિનિમય: a × b = b × a
- સાહચર્ય: (a × b) × c = a × (b × c)
- તટસ્થ તત્વ: a × 1 = a; a × 0 = 0
- વિતરણ ગુણધર્મ: a × (b + c) = a×b + a×c

• ભાગાકાર (Division):
- a ÷ b = q (ભાગફળ) અને r (શેષ), જ્યાં r < b
- ક્રમ વિનિમય નથી: a ÷ b ≠ b ÷ a
- કોઈપણ સંખ્યા શૂન્ય વડે ભાગી શકાતી નથી (अपरિभाषિત)
- શૂન્ય ÷ અશૂન્ય = 0

પ્રારંભિક શિક્ષણમાં વિદ્યાર્થીઓને વિક્રિયાઓ સમજાવવા માટે હાથે મિલે ચીજો (મારબલ, બટુઆ) નો ઉપયોગ કરવો જોઈએ.

૪. અવયવો અને ગુણિત (Factors and Multiples)

• અવયવ (Factor): જો 'a', 'b' વડે બિનશેષ ભાગાય તો 'a' એ 'b' નો અવયવ કહેવાય. ઉદા. ૧૨ ના અવયવો: ૧, ૨, ૩, ૪, ૬, ૧૨.

• ગુણિત (Multiple): ૧૨ ના ગુણિત: ૧૨, ૨૪, ૩૬, ૪૮, ૬૦, ...

• અવયવો શોધવાની પદ્ધતિ:
- ગુણન કોઠાનો ઉપયોગ કરો
- અવયવ જોડી તરકીબ: ૧×૧૨, ૨×૬, ૩×૪

• પરિપૂર્ણ સંખ્યા (Perfect Number): જે સંખ્યાના અવયવોનો સરવાળો (તે સંખ્યા સિવાય) તે સંખ્યા બરાબર હોય. ઉદા. ૬ = ૧+૨+૩.

• સંયુક્ત અવયવ પદ્ધતિ (Prime Factorization): કોઈ પણ સંખ્યાને અવિભાજ્ય સંખ્યાઓના ગુણિત તરીકે દર્શાવવી.
ઉદા. ૬૦ = ૨ × ૨ × ૩ × ૫ = ૨² × ૩ × ૫
ડેન્ડ્રમ (Tree) પદ્ધતિ વડે પણ આ શોધી શકાય.

૫. લ.સા.અ. અને મ.સા.અ. (LCM and HCF)

• લ.સા.અ. (Least Common Multiple): બે કે વધુ સંખ્યાઓના સામાન્ય ગુણિતમાંનું સૌથી નાનું ગુણિત.

• મ.સા.અ. (Highest/Common Factor): બે કે વધુ સંખ્યાઓના સામાન્ય અવયવમાંનું સૌથી મોટું અવયવ.

પદ્ધતિઓ:

અ) વિભાજ્યતા પદ્ધતિ (Division Method for LCM):
સંખ્યાઓને સામાન્ય અવિભાજ્ય અવયવ વડે ભાગતા રહો જ્યાં સુધી આખરી ભાગફળ ૧ ન થાય. LCM = બધા અવયવોનું ગુણાકાર.

ઉદા. ૧૨ અને ૧૮:
૨ | ૧૨, ૧૮ → ૬, ૯
૩ | ૬, ૯ → ૨, ૩
| ૨, ૩ → ૨, ૧
LCM = ૨ × ૩ × ૨ × ૧ = ૧૨ × ૩ = ૩૬?
સાચી ગણતરી: ૨ × ૩ × ૨ × ૩ = ૩૬ ✓

બ) અવયવીકરણ પદ્ધતિ:
૧૨ = ૨² × ૩
૧૮ = ૨ × ૩²
LCM(૧૨, ૧૮) = ૨² × ૩² = ૩૬
HCF(૧૨, ૧૮) = ૨ × ૩ = ૬

ગુણધર્મ: LCM(a,b) × HCF(a,b) = a × b

• શૂન્ય અને એક સંખ્યાઓ માટે:
HCF(૦, a) = a
LCM(૦, a) = ૦
HCF(૧, a) = ૧
LCM(૧, a) = a

૬. વિભાજ્યતાના નિયમો (Divisibility Rules)

નાની સંખ્યાઓની વિભાજ્યતા ચકાસવાના નિયમો:

• ૨ વડે વિભાજ્ય: અંક એકમ સ્થાને યુગ્મ (૦,૨,૪,૬,૮) હોય.

• ૩ વડે વિભાજ્ય: અંકોનો સરવાળો ૩ વડે વિભાજ્ય હોય.
ઉદા. ૧૫૩: ૧+૫+૩=૯ → ૯÷૩=૩ → વિભાજ્ય ✓

• ૪ વડે વિભાજ્ય: છેલ્લા બે અંકો ૪ વડે વિભાજ્ય હોય.
ઉદા. ૧૨૪ → ૨૪÷૪=૬ ✓

• ૫ વડે વિભાજ્ય: અંક એકમ સ્થાને ૦ અથવા ૫ હોય.

• ૬ વડે વિભાજ્ય: ૨ અને ૩ બંને વડે વિભાજ્ય હોય.

• ૮ વડે વિભાજ્ય: છેલ્લા ત્રણ અંકો ૮ વડે વિભાજ્ય હોય.

• ૯ વડે વિભાજ્ય: અંકોનો સરવાળો ૯ વડે વિભાજ્ય હોય.

• ૧૦ વડે વિભાજ્ય: અંક એકમ સ્થાને ૦ હોય.

• ૧૧ વડે વિભાજ્ય: વિષમ સ્થાનના અંકોનો સરવાળો અને સમ સ્થાનના અંકોનો સરવાળો વચ્ચેનો તફાવત ૧૧ વડે વિભાજ્ય હોય (અથવા શૂન્ય).
ઉદા. ૧૩૩૧: (૧+૩)=૪, (૩+૧)=૪, તફાવત ૦ → વિભાજ્ય ✓

TET-1 માં વિભાજ્યતાના નિયમો ઘણીવાર સંકલિત પ્રશ્નોમાં ઉપયોગમાં લેવાય છે.

૭. અવિભાજ્ય સંખ્યાઓ અને તેમના ગુણધર્મો (Prime Numbers and Properties)

• ૧ થી ૧૦૦ સુધીની અવિભાજ્ય સંખ્યાઓ:
૨, ૩, ૫, ૭, ૧૧, ૧૩, ૧૭, ૧૯, ૨૩, ૨૯, ૩૧, ૩૭, ૪૧, ૪૩, ૪૭, ૫૩, ૫૯, ૬૧, ૬૭, ૭૧, ૭૩, ૭૯, ૮૩, ૮૯, ૯૭.

• અવિભાજ્ય સંખ્યાઓના મહત્વના ગુણધર્મો:
- ૨ સિવાયની દરેક અવિભાજ્ય સંખ્યા અયુગ્મ હોય છે.
- ૨ અને ૩ બંને અવિભાજ્ય સંખ્યાઓ છે.
- કોઈ પણ બે ક્રમિક અવિભાજ્ય સંખ્યાઓ ૨ અને ૩ સિવાય સાંસગિક અવિભાજ્ય (coprime) હોય છે.
- n > 1 માટે, n! + 2 થી n! + n સુધીની બધી સંખ્યાઓ ભાજ્ય હોય છે (એટલે કે k અવિભાજ્ય સંખ્યાઓની શ્રેણી શક્ય છે).

• સાંસગિક અવિભાજ્ય સંખ્યાઓ (Coprime Numbers):
જો બે સંખ્યાઓનો HCF ૧ હોય તો તે સાંસગિક અવિભાજ્ય કહેવાય. ઉદા. ૮ અને ૯ (HCF=૧).

• અવિભાજ્ય અવયવીકરણ પ્રમેય (Fundamental Theorem of Arithmetic):
દરેક પૂર્ણાંક > ૧ ને અવિભાજ્ય સંખ્યાઓના ગુણિત તરીકે દર્શાવી શકાય અને આ દર્શન ક્રમ સિવાય અદ્વિતીય છે.

ઉદા. ૨૪ = ૨³ × ૩ (આ ક્રમમાં જ દર્શાવી શકાય).

૮. સંખ્યા રેખા પર સંખ્યાઓ (Numbers on Number Line)

• સંખ્યા રેખા એ સરળ રેખા છે જેમાં ધન, શૂન્ય અને ઋણ સંખ્યાઓ ઓળખી શકાય.

• ધન સંખ્યાઓ શૂન્યની જમણી બાજુ અને ઋણ સંખ્યાઓ ડાબી બાજુ દર્શાવાય.

• સંખ્યા રેખા પર મોટી સંખ્યા હંમેશા જમણી બાજુએ હોય છે.

ઉદાહરણો:
- ૫ > ૩ (૫, ૩ ની જમણે છે)
- -૨ < ૨ (-૨, ૨ ની ડાબી બાજુ છે)
- -૪ < -૧ (-૪, -૧ ની ડાબી બાજુ છે)

• સંખ્યા રેખા પર સરવાળો/વ્યવકલન:
- a + b: a થી b એકમ જમણી બાજુ ચાલો
- a - b: a થી b એકમ ડાબી બાજુ ચાલો

પ્રારંભિક વર્ગોમાં સંખ્યા રેખા વિદ્યાર્થીઓને સંખ્યાઓના ક્રમ અને તુલના સમજવામાં મદદરૂપ થાય છે. ગ્રાફિકલ રીતે સમજાવવું વધુ અસરકારક છે.

૯. ભિન્ન અને દશાંશ સંખ્યાઓ (Fractions and Decimals)

• ભિન્ન (Fraction): a/b સ્વરૂપ, જ્યાં b ≠ ૦.
- સાદું ભિન્ન (Proper Fraction): અંશ < છેદ (૩/૫, ૨/૭)
- અસાદું ભિન્ન (Improper Fraction): અંશ ≥ છેદ (૭/૩, ૫/૫)
- મિશ્ર સંખ્યા (Mixed Number): પૂર્ણાંક + સાદું ભિન્ન (૧ ૨/૩)

• ભિન્નના સમાન વર્ગ:
સમાન છેદવાળા ભિન્નની સરવાળો/વ્યવકલન:
a/c + b/c = (a+b)/c
ઉદા. ૩/૭ + ૨/૭ = ૫/૭

• લ.સા.અ. પદ્ધતિથી અસમાન છેદના ભિન્ન:
ઉદા. ૧/૩ + ૧/૪: LCM(૩,૪)=૧૨
૧/૩ = ૪/૧૨, ૧/૪ = ૩/૧૨
૪/૧૨ + ૩/૧૨ = ૭/૧૨

• દશાંશ સંખ્યા (Decimal):
- ૦.૫ = ૫/૧૦ = ૧/૨
- ૦.૭૫ = ૭૫/૧૦૦ = ૩/૪
- દશાંશ જોડવા: સમાન દશાંશ સ્થળો બનાવી સરવાળો/વ્યવકલન કરો.

• દશાંશ → ભિન્ન: દશાંશને ૧૦, ૧૦૦, ૧૦૦૦ વડે ગુણી સાદું કરો.
• ભિન્ન → દશાંશ: અંશ ÷ છેદ કરો.

૧૦. સંખ્યા સ્વરૂપ અને રચના (Number Forms and Patterns)

• સામાન્ય સ્વરૂપ (Expanded Form):
૩૪૫૬ = ૩×૧૦૦૦ + ૪×૧૦૦ + ૫×૧૦ + ૬×૧
= ૩૦૦૦ + ૪૦૦ + ૫૦ + ૬

• શબ્દ સ્વરૂપ:
૩૪૫૬ = ત્રણ હજાર ચારસો પચીસ.

• સંખ્યા પેટર્નો:
- સમાંતર શ્રેણી (Arithmetic): ૨, ૫, ૮, ૧૧, ... (પ્રતિ પદ ૩ એકમ વધે)
- ગુણોત્તર શ્રેણી (Geometric): ૨, ૬, ૧૮, ૫૪, ... (પ્રતિ પદ ૩ વડે ગુણાઈ)
- ત્રિકોણીય સંખ્યા: ૧, ૩, ૬, ૧૦, ૧૫, ... (૧, ૧+૨, ૧+૨+૩, ...)
- વર્ગ સંખ્યા: ૧, ૪, ૯, ૧૬, ૨૫, ... (n²)
- પરિપૂર્ણ સંખ્યા: ૬, ૨૮, ૪૯૬, ...

• સંખ્યા રચના:
ઉદા. ૪૬૭૨ ની રચના: હજાર=૪, સો=૬, દશક=૭, એકમ=૨
પાંચ સ્થાનક સંખ્યા: ૧૦,૦૦૦ થી ૯૯,૯૯૯
છ સ્થાનક સંખ્યા: ૧,૦૦,૦૦૦ થી ૯૯,૯૯,૯૯૯

૧૧. પ્રાથમિક સંખ્યા સમસ્યાઓ અને તેના ઉકેલ (Elementary Number Problems)

TET-1 માં સંખ્યા સમસ્યાઓના પ્રકારો:

૧. બે સંખ્યાઓનો સરવાળો અને તફાવત આપેલ હોય:
a + b = S, a - b = D
a = (S+D)/2, b = (S-D)/2
ઉદા. સરવાળો=૫૦, તફાવત=૧૦ → મોટી સંખ્યા = (૫૦+૧૦)/૨ = ૩૦

૨. એક સંખ્યા અન્ય સંખ્યા કરતાં N ગણી છે અને તેમનો સરવાળો S છે:
Chhoti = S/(N+1), Bari = S×N/(N+1)

૩. લ.સા.અ. / મ.સા.અ. આધારિત પ્રશ્નો:
ઉદા. બે સંખ્યાઓનો ગુણાકાર ૧૦૮૦ છે અને તેમનો LCM ૧૮૦ છે. HCF શોધો?
HCF = (a × b) / LCM = ૧૦૮૦ / ૧૮૦ = ૬

૪. અવિભાજ્ય અવયવીકરણ આધારિત:
ઉદા. ૨૫૨૦ નું અવિભાજ્ય અવયવીકરણ: ૨૫૨૦ = ૨² × ૩ × ૫ × ૪૨?
સાચું: ૨૫૨૦ = ૨ × ૧૨૬૦ = ૨² × ૬૩૦ = ૨³ × ૩૧૫ = ૨³ × ૩ × ૧૦૫ = ૨³ × ૩² × ૩૫ = ૨³ × ૩² × ૫ × ૭

૫. શ્રેણી સંબંધિત:
પ્રથમ n કુદરતી સંખ્યાઓનો સરવાળો = n(n+૧)/૨
પ્રથમ n સમ સંખ્યાઓનો સરવાળો = n(n+૧)
પ્રથમ n અયુગ્મ સંખ્યાઓનો સરવાળો = n²

૧૨. શિક્ષકો માટે શૈક્ષણિક સૂચનો (Pedagogical Notes for Teachers)

• પ્રારંભિક વર્ગો (૧-૨) માં:
- હાથે મિલે ચીજો (મારબલ, બટુઆ, પર્ણો) નો ઉપયોગ કરી સંખ્યાઓ શીખવો.
- સંખ્યા રેખાનો વિઝ્યુઅલ ઉપયોગ.
- સંખ્યાઓ લખવા-પ્રતિલીપિ કરવાની અભ્યાસ.

• વર્ગ ૩-૪ માં:
- સ્થાનક કિંમત માટે અનંદ પટ્ટિ (place value chart) નો ઉપયોગ.
- ભિન્ન સમજાવવા માટે પાયથાગોસિયન (fraction circle/square) ટૂલ્સ.
- વિભાજ્યતા નિયમો ક્રિયાશીલ (activity-based) રીતે શીખવો.

• વર્ગ ૫ માં:
- LCM/HCF ની સમસ્યાઓ અનુવર્તિત (application) પ્રકારે.
- ભિન્ન અને દશાંશ વચ્ચે સંબંધ સમજાવવો.
- અવિભાજ્ય અવયવીકરણ ડેન્ડ્રમ/ટી પદ્ધતિ.

• સામાન્ય ભૂલો (Common Mistakes):
- વિદ્યાર્થીઓ ઘણીવાર સ્થાનક કિંમત અને સામાન્ય કિંમતમાં ગૂંચવણ કરે છે.
- LCM અને HCF વચ્ચેનો તફાવત સમજવો મુશ્કેલ હોય છે.
- દશાંશ સરવાળામાં દશાંશ ચિન્હ સરગણી ન કરવું.
- અવિભાજ્ય સંખ્યા અને ભાજ્ય સંખ્યા વચ્ચેનો તફાવત.

• મૂલ્યાંકન સૂચન:
- ઔપચારિક MCQ સાથે પ્રશ્નો.
- સંખ્યા રેખા પર દર્શાવવાના પ્રશ્નો.
- વિભાજ્યતા ચકાસવાના પ્રશ્નો.
- સંખ્યા પેટર્ન પૂર્ણ કરવાના પ્રશ્નો.

Important facts

  • ૨ એકમાત્ર યુગ્મ અવિભાજ્ય સંખ્યા છે.
  • 1 એ અવિભાજ્ય અથવા ભાજ્ય બંને નથી — તે વિશિષ્ટ સ્થિતિ ધરાવે છે.
  • LCM(a,b) × HCF(a,b) = a × b
  • n > 1 માટે n! + 2 થી n! + n સુધીની બધી સંખ્યાઓ ભાજ્ય છે.
  • પ્રથમ n કુદરતી સંખ્યાઓનો સરવાળો = n(n+1)/2
  • પ્રથમ n અયુગ્મ સંખ્યાઓનો સરવાળો = n²
  • ૦ પૂર્ણ સંખ્યા છે પણ કુદરતી સંખ્યા નથી.
  • દરેક અવિભાજ્ય સંખ્યા ૨ સિવાય અયુગ્મ હોય છે.
  • ગુજરાતી અંક પદ્ધતિમાં ૧ કરોડ = ૧૦⁷ = ૧,૦૦,૦૦,૦૦૦
  • સાંસગિક અવિભાજ્ય સંખ્યાઓનો HCF = ૧
  • ભિન્ન a/b માં b ≠ ૦ હોવો જોઈએ.
  • કોઈ પણ સંખ્યા ૦ વડે ભાગી શકાતી નથી (અપરિભાષિત).

Formulas and relationships

પ્રથમ n કુદરતી સંખ્યાઓનો સરવાળો: S = n(n+1)/2
પ્રથમ n સમ સંખ્યાઓનો સરવાળો: S = n(n+1)
પ્રથમ n અયુગ્મ સંખ્યાઓનો સરવાળો: S = n²
જો a + b = S અને a - b = D, તો a = (S+D)/2, b = (S-D)/2
જો બે સંખ્યાઓનો ગુણો N હોય અને સરવાળો S હોય, તો નાની સંખ્યા = S/(N+1), મોટી સંખ્યા = S×N/(N+1)
LCM(a,b) × HCF(a,b) = a × b
સ્થાનક કિંમત = અંક × ૧૦^સ્થાનક સૂચકાંક
સામાન્ય સ્વરૂપ: સંખ્યા = અંક₁×૧૦ⁿ + અંક₂×૧૦ⁿ⁻¹ + ... + અંકₙ×૧૦⁰
પ્રથમ n સમ સંખ્યાઓ: ૨, ૪, ૬, ..., ૨n (nમી પદ = ૨n)
પ્રથમ n અયુગ્મ સંખ્યાઓ: ૧, ૩, ૫, ..., ૨n-૧ (nમી પદ = ૨n-૧)

Common mistakes

  • સ્થાનક કિંમત અને સામાન્ય કિંમતમાં ગૂંચવણ: ૭૫૩માં ૫ ની સામાન્ય કિંમત ૫ છે પણ સ્થાનક કિંમત ૫૦ છે.
  • LCM અને HCF ની વ્યવસ્થા બદલવી: LCM = લ.સા.અ., HCF = મ.સા.અ.
  • અવિભાજ્ય સંખ્યા શોધવામાં ૧ ને ગણતરીમાં લેવી: ૧ અવિભાજ્ય નથી.
  • ૦ ની વિભાજ્યતા: ૦ દરેક અશૂન્ય સંખ્યા વડે વિભાજ્ય છે, પણ કોઈ પણ સંખ્યા ૦ વડે વિભાજ્ય નથી.
  • દશાંશ સરવાળામાં દશાંશ ચિન્હ ગૂંચવણ: સ્થાનકો સરગણી કર્યા વિના સરવાળો કરવો.
  • વિભાજ્યતા નિયમ ૧૧ માં વિષમ-સમ સ્થાનકો ગૂંચવણ: ડાબી બાજુથી એકમ સ્થાનકથી ગણવા.
  • લ.સા.અ. અને ગુણાકાર વચ્ચેનો તફાવત: LCM(૪,૬) = ૧૨, પણ ૪×૬ = ૨૪.
  • અવયવોની યાદીમાં અવિભાજ્યતા ચકાસી ન શકવી: ઉદા. ૯ અવિભાજ્ય નથી (૩×૩).
  • સંખ્યા રેખા પર ઋણ સંખ્યાઓની ક્રમ ગૂંચવણ: -૫, -૩, -૧, ૦, ૧, ૩, ૫ (ડાબીએ નાની, જમણીએ મોટી).
  • અવિભાજ્ય અવયવીકરણમાં ભૂલ: ૩૦ = ૨×૩×૫ (૪×૭.૫ નહીં).
