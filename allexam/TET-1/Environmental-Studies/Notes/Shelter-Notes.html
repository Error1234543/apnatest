1. ઘરનું મહત્વ અને પરિચય

બાળકના વિકાસમાં ઘરનો આધારભૂત ભાગ છે. શૈક્ષણિક દૃષ્ટિએ 'ઘર' એ ફક્ત માટી-લોha-કાષ્ઠનું ઇમારત નથી; તે એક સુરક્ષિત પર્યાવરણ છે જ્યાં બાળક ભૌતિક, માનસિક અને સાંસ્કૃતિક રીતે વિકસે છે.

ઘરની મૂળભૂત જરૂરિયાતો:
• સુરક્ષા — કુદરતી આફતો (જોરદાર પવન, વરસાદ, તડકો, શીત પ્રદેશો) થી રક્ષણ.
• આરામ — ઉપયોગી જગ્યા, હવામાન અનુકૂળ વાતાવરણ.
• સાંસ્કૃતિક પરિચય — બાળકને પોતાની સંસ્કૃતિ, પરંપરા અને સ્થાનિક શિલ્પકલાનો પરિચય કરાવે.
• સાર્વത്રિકતા — ભારતમાં વિવિધ પ્રદેશોમાં ઘરોની રચના ભિન્ન છે, તેથી 'ઘર' એક લવચીક ખ્યાલ છે.

TET-1ની દૃષ્ટિએ: ઘર વિષય પર 2-4 પ્રશ્નો આવે છે. મુખ્યત્વે સ્થળ-અનુરૂપ ઘરો, નિર્માણ સામગ્રી, ક્લાયમેટ સાથેનો સંબંધ અને પર્યાવરણ પ્રદૂષણના પાસાઓ પર પ્રશ્નો પૂછવામાં આવે છે.

2. ભારતમાં વિવિધ પ્રદેશોના ઘરો

ઘરો રચના મુખ્યત્વે ચાર પરિબળો પર આધારિત છે: (i) જલવાયુ, (ii) ઉપલબ્ધ કચરા સામગ્રી, (iii) સંસ્કૃતિ/સામાજિક રીતીઓ, (iv) ઐતિહાસિક શિલ્પકલા.

અ) હિમાલયી પ્રદેશ (ઉત્તરાખંડ, હિમાચલ, જમ્મુ-કાશ્મીર):
• બંધ/ચોકઠા ઘર — જાડા પથ્થરના દીવાલો, લાકડાના છોતાં, ઢાળવાળી છત (બરફ ઊતરી જાય તેટલું).
• ડેરા / બંગલા — ગિરિપ્રદેશમાં પ્રચલિત.
• ગરમી ટકાવી રાખવા માટે નાની ખિડકીઓ અને જાડી દીવાલો.

અ) ગુજરાત (પાલીતાણા, કચ્છ, રાજકોટ, સૌરાષ્ટ્ર):
• કચ્છ – બોધ્રા / અગ્રો ઘર (કાંકર-સિમેન્ટના દીવાલ, મટકા-છત — બસારા ઘરો).
• સાઉથ ગુજરાત – વાડી (વડાળા / બંગલા સ્વરૂપ).
• રાજકોટ / સૌરાષ્ટ્ર – સખત ઇમારતો, જમીન ઉપરિ ભાગે.
• ગ્રામીણ વિસ્તારોમાં મટકાના છપ્પર, ધાનના કાણાંનો ઉપયોગ.

અ) ઉત્તર ભારત (પંજાબ, હરિયાણા, ઉત્તર પ્રદેશ):
• મુખ્યત્વે પિંડ/બંગલા શૈલી.
• બાંધકામમાં લાકડું, કાંકર, મટકાનું સંયોજન.
• છત પર ધાનની બાફ / મટકાની સ્તરો.

અ) દક્ષિણ ભારત (તમિલનાડુ, કેરળ, કર્ણાટક, આંધ્ર):
• વરસાદી પ્રદેશોમાં ઢળકીને હોય તેવી છત.
• કેરળ – ચેપલ્લકાડુ (લાકડાના સમુચ્ચય), વાડી.
• મધ્ય ભારત – જાડી દીવાલો, ઓછી ખિડકી.

અ) દરિયાકિનારો / તટીય પ્રદેશ (ગોવા, મહારાષ્ટ્ર કિનારો, કર્ણાટક):
• જાડા લાકડાની ઇમારતો, સૂર્ય + તોફાનનો સામનો.
• ઘણીવાર લાકડાની બાંધણી અને સિમેન્ટ / ઝાડ પત્તા.

અ) વિશેષ ઘરો:
• બારામઝી (કેરળ) — વિશાળ લાકડાનું ઘર.
• ડોંગા (લાડાખ) — બંધ કચરા / પથ્થરના ઘર.
• યાક પિન્ટુ (હિમાચલ) — ચરવા પ્રદેશ.
• માટીના ઘરો (બિહાર, ઝારખંડ, મધ્ય પ્રદેશ)
— રઝડ / માટીના ઘર.
• માલબાર / સંત્રાણઘરો (કેરળ)
• માટી / તોરડા / મટકા ઘરો (ગુજરાત, રાજસ્થાન).
• દરિયાઈ પ્રદેશો — ઘોડીયાળી મશીનરી / લોડબોટ.

શૈક્ષણિક ટિપ્પણી: વિદ્યાર્થીઓને સ્થાનિક ઘરની બાંધકામ સામગ્રી અને જલવાયુ વચ્ચેનો સંબંધ સમજાવવો જરૂરી છે — આ કોણ પ્રશ્નોનો મુખ્ય વિષય છે.

3. ઘરની મૂળભૂત રચના (બંધારણ)

કોઈ પણ ઘરના મુખ્ય ઘટકો નીચે મુજબ:

અ) પાયા / પાયાભૂમિ:
• ઘરનું સૌથી નીચલું ભાગ જમીન પર.
• પાયામાં જમીન ઠેસ, પથ્થર, કોંગ્રીટ ની ઉપયોગ.
• કચરા / કાંકરનો ઉપયોગ પાયામાં થાય છે (જેમ કે ગુજરાતમાં).

અ) દીવાલો:
• ઊભી રચના જે ઘરની અંદરનું અવકાશ ઘોરે છે.
• સામગ્રી: માટી, કાંકર, લાકડું, સિમેન્ટ, મટકા.
• દીવાલો ની જાડાઈ જલવાયુ પર આધારિત (ઠંડા પ્રદેશોમાં જાડી, ગરમ પ્રદેશોમાં પાતળી).

અ) છત / ટોચ:
• જળ પ્રવેશીત થાય એ ન રાખવા માટે ઢાળવાળી છત (વરસાદી પ્રદેશોમાં).
• સમતલ છત (રાજસ્થાન, ગુજરાતના ગ્રામીણ વિસ્તારો).
• મટકાનું છત / ધાનનું છત.

અ) ખિડકીઓ અને દરવાજા:
• હવા અને પ્રકાશ પ્રવેશ માટે.
• ખિડકી નું સ્થાન અને કદ જલવાયુ પર આધારિત (ઠંડા પ્રદેશોમાં નાની, ઉષ્ણ પ્રદેશોમાં મોટી).

અ) ભૂમિ અને માળા:
• એક માળા / બે માળા ઘરો.
• ગ્રામીણ વિસ્તારોમાં મુખ્યત્વે એક માળા.
• શહેરી વિસ્તારોમાં બે+ માળા.

અ) વિશેષ ભાગો:
• મહેલ / કક્ષ — રાંધવાનું કોઠું.
• ઓરડા / શયનકક્ષ.
• બાથરૂમ / સ્નાન કક્ષ.
• વરાળ / ધૂમાડો નિકાલ (ચુલું / ચૂલો).

TET-1ની દૃષ્ટિએ: વિદ્યાર્થીઓને ઘરના ઘટકોનાં નામ, તેમનો ઉપયોગ અને જલવાયુ સાથેનો સંબંધ સમજાવવો. આધુનિક ઘરોની तुलना સ્થાનિક ઘરો સાથે કરાવી શકાય છે.

4. નિર્માણ સામગ્રી — પારંપરિક અને આધુનિક

અ) પારંપરિક સામગ્રી:
• માટી (clay) — દીવાલો અને છત માટે. સ્થાનિક, સસ્તું, પરંતુ વરસાદમાં નુકસાન.
• લાકડું — ઢાંચો, ડોરી, છત, ખિડકી. બળતણમાં પણ ઉપયોગ.
• કાંકર / રેતી — પાયો, દીવાલ, છત. ગુજરાતમાં ખૂબ પ્રચલિત.
• મટકા / કોબરા — છત, દીવાલ. ગરમી અટકાવે છે.
• ધાન / ભૂસા — છત પર પૂરવારો.
• બાંસ — સસ્તું ઢાંચો.
• તોરડા / ઝાડ પત્તા — છત.

અ) આધુનિક સામગ્રી:
• સિમેન્ટ / કોંગ્રીટ — સતત, સખત, લાંબી આયુ.
• બાજરી / ઈંટ — દીવાલો.
• ધાતુ (આયર્ન / સ્ટીલ) — ઢાંચો, દરવાજા.
• પ્લાસ્ટિક, ફાઇબર, બેકલાઈટેડ પેનલ.

અ) તુલનાત્મક માહિતી:
• પારંપરિક — સસ્તું, સ્થાનિક, પર્યાવરણનુસાર, પરંતુ નબળું ટકાઉ.
• આધુનિક — પકડપાત્ર, દીર્ઘકાલીન, પરંતુ ખર્ચાળ, પર્યાવરણ પર ઝડપી અસર.

અ) પર્યાવરણીય દૃષ્ટિએ:
• પારંપરિક સામગ્રી વધુ પર્યાવરણ મિત્ર છે.
• સિમેન્ટ ઉત્પાદન CO2 મુક્ત કરે છે.
• પ્રકૃતિથી મળતી સામગ્રી ઓછો ઊર્જા ખર્ચ.

TET-1ના સંદર્ભમાં: બાળકને દૈનિક જીવન સાથે જોડીને શીખવું. ગુજરાતના સ્થાનિક ઘરોની ચર્ચા કરો. પાઠ્યપુસ્તકમાં રહેલા ચિત્રો અને કાર્યક્રમોનો ઉપયોગ કરો.

5. જલવાયુ અને ઘર — પરસ્પર સંબંધ

અ) ઉષ્ણ + ભેજવાળા પ્રદેશો (કેરળ, મહારાષ્ટ્ર કિનારો):
• વરસાદી પ્રદેશોમાં ઢળકીને છત જરૂરી.
• હવા નીકળવા માટે મોટી ખિડકીઓ.
• લાકડાની ઇમારત (મોસાઈ / બંધ).
• ઘરની આસપાસ છાંયડો પડે તેવા વૃક્ષો.

અ) શુષ્ક + ગરમ પ્રદેશો (રાજસ્થાન, ગુજરાતના ગ્રામીણ):
• જાડી દીવાલો (માટી + કાંકર) ગરમી ધીમી કરે છે.
• નાની ખિડકી.
• સમતલ છત — રાત્રે ઉપયોગમાં લેવાય.
• છત પર મટકા / ધાનનું કવચ.

અ) ઠંડા + પર્વતીય પ્રદેશો (હિમાલયી):
• જાડા દીવાલો, નાની ખિડકી.
• ઢાળવાળી છત — બરફ / વરસાદ ઊતરી જાય.
• ચુલા / સ્ટવ ગરમી માટે.
• લાકડાના ઢાંચો.

અ) દરિયાઈ પ્રદેશો:
• હવામાનમાં વધઘટ.
• તોફાનથી રક્ષણ.
• જાડા લાકડા + આયર્ન.
• ઘર નીચે ઉંચું (ફ્લડર).

અ) શૈક્ષણિક મહત્વ:
• બાળકને દર્શાવો કે કેવી રીતે 'ઘર જલવાયુ સાથે સંકળાયેલું છે'.
• વિદ્યાર્થીઓ પોતાના વિસ્તારના ઘરોનું અવલોકન કરાવો.
• 'તારા ઘરનું જલવાયુ અનુરૂપ કઈ ફેરફારો છે?' એ પ્રશ્ન પૂછો.

આ પાઠ્યક્રમનો સૌથી વધુ પુછાતો વિષય છે.

6. ઘર અને પર્યાવરણ — પરસ્પર અસર

અ) ઘરની રચના પર્યાવરણ પર અસર કરે છે:
• વૃક્ષો કાપવા — હવામંડળ પર અસર, ભૂખંડનું ખોરડું.
• કાંકર / બાજરી ઉત્ખનન — નદી / સિંચાઈ પર અસર.
• સિમેન્ટ ઉત્પાદન — CO2, ધૂળ.
• રાંધણી ભઠ્ઠી — ધૂમાડો, હવા પ્રદૂષણ.
• કચરા નિવારણ — પાણી પ્રદૂષણ.

અ) પર્યાવરણ ઘર પર અસર કરે છે:
• વરસાદ — માટીના ઘર ઢળી પડે.
• સૂર્યપ્રકાશ — રંગ / ઇમારતને નુકસાન.
• પવન — ઢળકી પડેલી છત.
• ધરતીકંપ — ઇમારત ધરાશાયી.
• ચોપડા / જમીન ધોવાઈ.

અ) ટકાઉ ઘર (Sustainable Shelter):
• પ્રકૃતિમાંથી મળતી સામગ્રી — માટી, બાંસ, ધાન.
• પવન + સૂર્ય ઊર્જાનો ઉપયોગ.
• પાણી સંરક્ષણ (વરસાદનું પાણી એકઠું કરવું).
• કચરા નિવારણ અને પુનઃઉપયોગ.
• ઘરની ડિઝાઇનમાં પ્રાકૃતિક હવા / પ્રકાશનો સમાવેશ.

અ) શૈક્ષણિક માર્ગદર્શન:
• બાળકોને ઘર અને પર્યાવરણના સંબંધ વિશે જાગૃત કરો.
• પ્રયોગો: માટીનું ઘર અને સિમેન્ટના ઘરની તુલના.
• બાળકો પોતાના ઘરના કચરાનું અવલોકન કરાવો.
• 'ઘર શુદ્ધ કરો' કાર્યક્રમ.

TET-1 માં આ પાસાઓ સાથે સંકળાયેલા પ્રશ્નો આવે છે.

7. ઘર અને પરિવાર — સામાજિક + સ્વાસ્થ્ય સંબંધ

અ) પરિવાર અને ઘર:
• ઘર એ પરિવારની પહેલચિહ્ન છે.
• પરિવારના સદસ્યો વચ્ચેના સંબંધો ઘરમાં બને છે.
• બાળકનું સામાજીકરણ (Socialization) ઘર શિક્ષણ પર આધારિત.

અ) શારીરિક + માનસિક સ્વાસ્થ્ય:
• શુદ્ધ પાણી, સ્વચ્છતા, વેન્ટિલેશન — સ્વાસ્થ્ય માટે જરૂરી.
• ઘરની રચનામાં પ્રકાશ + હવા ન હોય તો રોગો ફેલાય.
• ઘરની સ્થિતિ (ઊંચી / નીચી જમીન, બાધા હોય તેવી જગ્યા) ગૃહસ્થાને અસર કરે છે.

અ) શૈક્ષણિક દૃષ્ટિએ:
• બાળકોને તેમના ઘરની પરિક્રમા કરાવો.
• ઘરના દરેક કક્ષનું નામ + તેનો ઉપયોગ શીખવો.
• 'મારા ઘરની નકશો દોરો' જેવા કાર્યો કરાવો.
• પરિવારના સદસ્યોના કાર્ય વિશે ચર્ચા.

અ) વિચારણા પ્રશ્નો (TET-1):
• ઘર અને પરિવારનો સંબંધ શું છે?
• ઘરનું શુદ્ધિકરણ શા માટે જરૂરી છે?
• ઘરમાં હવા + પ્રકાશ શા માટે જરૂરી છે?
• ઘરની ડિઝાઇનમાં પરિવારની જરૂરિયાતો કેવી રીતે અનુરૂપ હોવી જોઈએ?

8. સ્થાનિક ઘરો — ગુજરાતના ઉદાહરણો

અ) ગુજરાતના પ્રચલિત ઘરો:
• કચ્છ – બોધ્રા ઘર, અગ્રો ઘર (કાંકર + માટી).
• સૌરાષ્ટ્ર – મટકા + માટીનું ઘર.
• પાલીતાણા – વાડી / બંગલા શૈલી.
• રાજકોટ – મિશ્રિત ઇમારતો.
• દક્ષિણ ગુજરાત – લાકડા + મટકા.
• ગ્રામીણ વિસ્તારો – ધાનના છપ્પર / મટકા છત.

અ) ઔદ્યોગિક શહેરો (અમદાવાદ, સુરત, વડોદરા):
• બહુમતી ઇમારતો / ઍપાર્ટમેન્ટ.
• સિમેન્ટ, બાજરી, આયર્ન ઢાંચો.
• એકીકૃત યોજના, બધા ફળિયા / વેરાંડા.

અ) શૈક્ષણિક કાર્યક્રમો:
• વિદ્યાર્થીઓ પોતાના ગામ / શહેરના ઘરોનો અભ્યાસ કરાવો.
• તસ્વીરો / માળખાકીય આકૃતી એકઠી કરાવો.
• 'મારા ઘરનું નકશો' — ભૂમિતિ + EVS નું સંકલન.
• 'સ્થાનિક અને આધુનિક ઘર — તુલનાત્મક અભ્યાસ'.

અ) મહત્વના શબ્દો:
• બોધ્રા, અગ્રો, વાડી, મટકા છત, ધાન છપ્પર, ફળિયો, ઍપાર્ટમેન્ટ, બહુમાળી ઇમારત.

9. શિક્ષણમાં ઘર વિષય — શૈક્ષણિક પદ્ધતિ

અ) શીખવાની પદ્ધતિઓ:
• અવલોકન — વિદ્યાર્થીઓ પોતાના ઘરનું અવલોકન કરે.
• વાર્તાલાપ — પરિવાર સાથે ચર્ચા.
• કાર્યક્રમ — નકશો દોરવો, મોડેલ બનાવવું.
• માળખાકીય પ્રશ્નો — જલવાયુ, સામગ્રી, ઘટકો.

અ) પ્રયોગો / પ્રવૃત્તિઓ:
• વિવિધ પ્રદેશોના ઘરોની તસ્વીરો એકઠી કરવી.
• માટી, કાંકર, લાકડું, મટકા — નમૂનાઓ એકઠા કરવા.
• 'ઘર બનાવો' — કચરા સામગ્રીથી મોડેલ.
• 'મારા ઘરની યાત્રા' — સ્થળિક અભ્યાસ.

અ) સંકલિત અભ્યાસ:
• ભૂગોળ — જલવાયુ અને ઘર.
• ઇતિહાસ — પારંપરિક શિલ્પકલા.
• ગણિત — નકશો, માપ, વિસ્તાર.
• કલા — ઘરની આકૃતિ, રંગ.

અ) મૂલ્યાંકન:
• વસ્તુવાદી પ્રશ્નો.
• વિશ્લેષણાત્મક પ્રશ્નો.
• કાર્યક્રમ આધારિત મૂલ્યાંકન.
• પોર્ટફોલિયો — વિદ્યાર્થીના કાર્યો.

TET-1 માં શૈક્ષણિક પદ્ધતિના પ્રશ્નો પણ આવે છે.

10. મહત્વના પ્રશ્નો અને સામાન્ય ભૂલો

અ) ઉચ્ચ-મહત્વના પ્રશ્નો:
• ભારતના વિવિધ પ્રદેશોના ઘરો અને તેમનો જલવાયુ સાથેનો સંબંધ.
• પારંપરિક અને આધુનિક ઘરોની તુલના.
• ઘરની મુખ્ય રચના (દીવાલ, છત, ખિડકી, પાયો).
• ઘર અને પર્યાવરણનો પરસ્પર સંબંધ.
• ગુજરાતના સ્થાનિક ઘરો.
• ઘરનું શુદ્ધિકરણ અને સ્વાસ્થ્ય.
• ઘર અને પરિવારનો સંબંધ.

અ) સામાન્ય ભૂલો:
• ઘર = માત્ર ઇમારત માની લેવું — 'ઘર' સંસ્કૃતિક, સામાજિક અને માનસિક પરિમાણો ધરાવે છે.
• જલવાયુ અને ઘર વચ્ચેનો સંબંધ અવગણવો.
• ગુજરાતના સ્થાનિક ઘરો વિશે માહિતીનો અભાવ.
• આધુનિક સામગ્રીને હંમેશા શ્રેષ્ઠ માનવી.
• પર્યાવરણ પર ઘરની અસરને ગંભીરતાથી ન લેવી.
• બાળકની અનુભવ-આધારિત શીખવતમાં અવગણના.

અ) ટીપ્સ:
• પ્રત્યેક પ્રદેશના ઘરની મુખ્ય સവിશેષતા યાદ કરો.
• જલવાયુ ↔ ઘર સંબંધ ચિત્ર રૂપે યાદ રાખો.
• ગુજરાતના ઘરોની ચોક્કસ ઉદાહરણો યાદ રાખો.
• શૈક્ષણિક પદ્ધતિ અને મૂલ્યાંકન પાસાઓ પણ તૈયાર રાખો.

Important facts

  • ઘર ફક્ત ભૌતિક રચના નથી; તે સુરક્ષા, આરામ, સાંસ્કૃતિક પરિચય અને સામાજીકરણનું માધ્યમ છે.
  • ઘરોની રચના મુખ્યત્વે જલવાયુ, સ્થાનિક સામગ્રી, સંસ્કૃતિ અને ઐતિહાસિક શિલ્પકલા પર આધારિત છે.
  • હિમાલયી પ્રદેશમાં જાડી દીવાલો, નાની ખિડકી, ઢાળવાળી છત — બરફ + ઠંડક અટકાવવા.
  • કચ્છ + સૌરાષ્ટ્રમાં બોધ્રા / અગ્રો / મટકા ઘરો — કાંકર + માટી + મટકા.
  • ઉષ્ણ + ભેજવાળા પ્રદેશોમાં ઢળકીને છત, મોટી ખિડકી, લાકડાનું ઢાંચો.
  • શુષ્ક + ગરમ પ્રદેશોમાં જાડી દીવાલો, નાની ખિડકી, સમતલ છત.
  • પારંપરિક સામગ્રી (માટી, કાંકર, લાકડું, મટકા) પર્યાવરણ મિત્ર છે.
  • આધુનિક સામગ્રી (સિમેન્ટ, બાજરી, આયર્ન) ટકાઉ પણ ઊર્જા ખર્ચાળ.
  • ઘર નિર્માણ પર્યાવરણ પર અસર કરે છે (વૃક્ષ કપાઈ, CO2, કચરો).
  • ઘર પર્યાવરણ પર પણ અસરગ્રસ્ત છે (વરસાદ, સૂર્ય, તોફાન, ધરતીકંપ).
  • ગુજરાતના પ્રચલિત ઘર: કચ્છમાં બોધ્રા/અગ્રો, સૌરાષ્ટ્રમાં મટકા ઘર, દક્ષિણ ગુજરાતમાં લાકડા + મટકા, શહેરી વિસ્તારમાં ઍપાર્ટમેન્ટ.
  • ઘર અને પરિવારનો ગાઢ સંબંધ છે — સામાજીકરણ, માનસિક સ્વાસ્થ્ય, શારીરિક સ્વાસ્થ્ય.
  • શૈક્ષણિક પદ્ધતિ: અવલોકન, વાર્તાલાપ, કાર્યક્રમ (નકશો, મોડેલ), પ્રયોગ, સંકલિત અભ્યાસ (ભૂગોળ, ઇતિહાસ, ગણિત, કલા).
  • ટકાઉ ઘર (Sustainable Shelter) — પ્રકૃતિ સામગ્રી, ઊર્જા કાર્યક્ષમ, પાણી સંરક્ષણ, કચરા નિવારણ.
  • TET-1 માં 'ઘર' વિષય પર 2-4 પ્રશ્નો આવે છે — મુખ્યત્વે જલવાયુ-ઘર સંબંધ, સ્થાનિક ઘરો, નિર્માણ સામગ્રી, પર્યાવરણીય અસર.

Common mistakes

  • ઘર = માત્ર ભૌતિક ઇમારત. સંસ્કૃતિક, સામાજિક, માનસિક પરિમાણોનો સમાવેશ ન કરવો.
  • જલવાયુ અને ઘર વચ્ચેનો સંબંધ અવગણવો — ઉદા: હિમાલયી પ્રદેશમાં ઢાળવાળી છત શા માટે જરૂરી છે તે સમજવું.
  • ગુજરાતના સ્થાનિક ઘરો વિશે માહિતીનો અભાવ — બોધ્રા, અગ્રો, વાડી, મટકા છત વિશે પૂરતી તૈયારી ન હોવી.
  • આધુનિક સામગ્રી (સિમેન્ટ) હંમેશા શ્રેષ્ઠ માની લેવી — પારંપરિક સામગ્રીના પર્યાવરણીય ફાયદા અવગણવા.
  • ઘરની રચનામાં 'પાયો, દીવાલ, છત, ખિડકી, દરવાજો' એમ મુખ્ય ઘટકો ભૂલવા.
  • ઘર અને પર્યાવરણ વચ્ચેના પરસ્પર સંબંધને એકમુખી માની લેવો — બંને પરસ્પર અસર કરે છે.
  • શૈક્ષણિક પદ્ધતિ (અવલોકન, કાર્યક્રમ, પ્રયોગ) ને અવગણીને માત્ર રટંત વિદ્યાર્થીને શીખવવું.
  • ઘરનું નકશો દોરવાના કાર્યમાં વિદ્યાર્થીઓને દિશાનિર્દેશ ન આપવો — અસ્પષ્ટ કાર્ય.
  • 'ઘર' વિષયને વિસ્તૃત રીતે લેવાને બદલે સંક્ષિપ્તમાં રાખવો — TET-1 માં આ વિષયથી ઘણા પ્રશ્નો આવે છે.
  • સ્થાનિક + આધુનિક ઘરોની તુલનાત્મક અભ્યાસ ન કરાવવો — તુલનાથી વિદ્યાર્થી ગાઢ સમજ ધરાવે છે.
