Error Spotting — PYQ-STYLE PRACTICE (Part 1 of 30)

BankingHindiPYQ

Banking exams (IBPS PO/Clerk, SBI PO/Clerk) contain a dedicated Error Spotting section in both Prelims and Mains. Each question gives a sentence with three underlined parts (A, B, C) and a fourth option D. You must identify which part contains the grammatical error; if there is no error, mark D. This is a practice set — not real previous-year questions. Read carefully and choose the best answer.
