Quadratic Equations — Complete Notes (Banking: IBPS/SBI)

BankingHindiNotes

1. परिचय और मानक रूप

Quadratic Equation (द्विघात समीकरण) वह समीकरण होता है जिसमें चर (variable) की उच्चतम घात 2 होती है। इसका मानक रूप (standard form) है:

ax² + bx + c = 0, जहाँ a ≠ 0 और a, b, c वास्तविक संख्याएँ हैं।

Banking exam में सबसे अधिक पूछे जाने वाले प्रश्नों का स्वरूप: दो द्विघात समीकरण दिए जाते हैं — एक x के लिए और एक y के लिए — और उत्तराधिकारी (candidate) को दोनों को हल करके x और y के बीच संबंध (relation) निर्धारित करना होता है। विकल्प आमतौर पर ये होते हैं:
• x > y
• x < y
• x = y या संबंध नहीं स्थापित किया जा सकता
• x ≥ y
• x ≤ y

इस टॉपिक की मुख्य कौशल: समीकरणों को तेजी से factoring द्वारा हल करना, गुणनखंडन की विधि में चूक से बचना, और अंत में सभी मामलों की सही तुलना करके संबंध निकालना।

2. समाधान की विधियाँ

Banking exams के लिए केवल दो विधियाँ व्यावहारिक हैं:

विधि 1 — मध्यपद भंजन (Middle Term Splitting / Factorisation):
सबसे आम और सबसे तेज़ विधि। ax² + bx + c = 0 में दो ऐसी संख्याएँ m और n ढूँढनी हैं कि:
m × n = a × c
m + n = b
फिर: ax² + mx + nx + c = 0 लिखकर factoring करें।

उदाहरण: x² + 7x + 12 = 0
7x के पदों को 3x + 4x में बाँटें (क्योंकि 3×4=12 और 3+4=7)
x(x+3) + 4(x+3) = 0
(x+3)(x+4) = 0
x = -3, -4

विधि 2 — सूत्र विधि (Quadratic Formula):
x = [-b ± √(b² - 4ac)] / 2a
यह विधि तब उपयोगी होती है जब मध्यपद भंजन सीधा न हो (जैसे अंक बड़े हों या दशमलव हों)। हालाँकि banking exam में समय कम होता है इसलिए सूत्र का उपयोग केवल तभी करें जब factorisation असंभव लगे।

विधि 3 — शुद्ध द्विघात (Pure Quadratic):
ax² + c = 0 → x² = -c/a → x = ±√(-c/a)
जैसे: 2x² - 18 = 0 → x² = 9 → x = ±3

3. discriminant (विवेचक) और मूलों की प्रकृति

Discriminant D = b² - 4ac

D की स्थिति और मूलों का प्रकार:
• D > 0: दो भिन्न वास्तविक मूल (two distinct real roots)
- यदि D पूर्ण वर्ग है → मूल rational (परिमेय)
- यदि D पूर्ण वर्ग नहीं → मूल irrational (अपरिमेय)
• D = 0: दो समान वास्तविक मूल (equal/repeated root) → x = -b/2a
• D < 0: काल्पनिक (complex) मूल — banking exam में प्रायः नहीं आते

व्यावहारिक महत्व: जब D पूर्ण वर्ग हो तो factorisation आसान होती है क्योंकि मूल rational आते हैं। banking exam में लगभग सभी प्रश्नों में D पूर्ण वर्ग या धनात्मक असंयुक्त वर्ग ही होता है ताकि मूल सरल integers या सरल भिन्नें आएँ।

उदाहरण: x² - 5x + 6 = 0
D = 25 - 24 = 1 (पूर्ण वर्ग)
मूल: (5±1)/2 = 3, 2

4. मूलों और गुणांकों के बीच संबंध

यदि α और β द्विघात समीकरण ax² + bx + c = 0 के मूल हैं, तो:

• मूलों का योग: α + β = -b/a
• मूलों का गुणनफल: αβ = c/a

ये संबंध सीधे तौर पर factorisation की जाँच के लिए काम आते हैं — अक्सर आपको केवल y का मान खोजने के लिए α+β और αβ का उपयोग करना होता है बिना विस्तृत factoring किए।

व्युत्पत्ति (Derivation) — संक्षिप्त:
ax² + bx + c = a(x-α)(x-β)
= a[x² - (α+β)x + αβ]
= ax² - a(α+β)x + aαβ
अतः -a(α+β) = b → α+β = -b/a
और aαβ = c → αβ = c/a

उपयोग: यदि आपको पता है कि योग = -7 और गुणनफल = 12, तो मूल -3 और -4 होंगे (क्योंकि (-3)+(-4)=-7 और (-3)×(-4)=12)। यह shortcut बहुत काम आता है।

5. x और y वाले प्रश्न — संबंध कैसे निर्धारित करें

Banking exam का सबसे सामान्य प्रश्न प्रकार: दो समीकरण दें और x-y संबंध पूछें।

चरण-दर-चरण रणनीति:

Step 1: पहले समीकरण को factorize कर x के दोनों मूल निकालें।
Step 2: दूसरे समीकरण को factorize कर y के दोनों मूल निकालें।
Step 3: दोनों मूलों को number line पर चिन्हित करें।
Step 4: सभी 4 संयोजनों (pairs) की तुलना करें:
- यदि हर जोड़े में x > y → उत्तर x > y
- यदि हर जोड़े में x < y → उत्तर x < y
- यदि हर जोड़े में x = y → उत्तर x = y
- यदि कुछ जोड़ों में x > y और कुछ में x < y, लेकिन कभी भी equal नहीं → 'x = y or relation cannot be established'
- यदि कुछ जोड़ों में x > y, कुछ में x < y और कुछ में x = y → उत्तर x ≥ y या x ≤ y

महत्वपूर्ण सावधानी: जब भी x और y के मूलों में कोई overlap हो (यानी कुछ cases में x=y आ जाये), तो उत्तर हमेशा ≥ या ≤ होना चाहिए, कभी भी > या < नहीं।

उदाहरण:
x² - 5x + 6 = 0 → x = 2, 3
y² - 7y + 12 = 0 → y = 3, 4

तुलना:
x=2, y=3 → x < y
x=2, y=4 → x < y
x=3, y=3 → x = y
x=3, y=4 → x < y

अतः उत्तर: x ≤ y

6. worked examples

Example 1 (समान गुणांक वाला सरल प्रश्न):
I. x² - 9x + 20 = 0
II. y² - 11y + 30 = 0

हल:
I: x² - 5x - 4x + 20 = 0 → x(x-5) - 4(x-5) = 0 → (x-5)(x-4) = 0 → x = 5, 4
II: y² - 6y - 5y + 30 = 0 → y(y-6) - 5(y-6) = 0 → (y-6)(y-5) = 0 → y = 6, 5

तुलना:
x=5, y=6 → x < y
x=5, y=5 → x = y
x=4, y=6 → x < y
x=4, y=5 → x < y
उत्तर: x ≤ y

Example 2 (ऋणात्मक मूल वाले):
I. 2x² + 7x + 6 = 0
II. 3y² + 8y + 5 = 0

हल:
I: 2x² + 4x + 3x + 6 = 0 → 2x(x+2) + 3(x+2) = 0 → (2x+3)(x+2) = 0 → x = -3/2, -2
II: 3y² + 3y + 5y + 5 = 0 → 3y(y+1) + 5(y+1) = 0 → (3y+5)(y+1) = 0 → y = -5/3, -1

तुलना:
x=-1.5, y=-1.67 → x > y
x=-1.5, y=-1 → x < y
x=-2, y=-1.67 → x < y
x=-2, y=-1 → x < y
उत्तर: x ≤ y (क्योंकि केस x=-1.5, y=-1.67 में x>y और अन्य तीन में x<y; लेकिन x=y कहीं नहीं — wait, recheck: none equal, some x>y some x<y, so relation cannot be established)

सुधार: x > y केवल एक case में, x < y तीन cases में, और x=y कहीं नहीं → उत्तर: संबंध स्थापित नहीं किया जा सकता

Example 3 (गुणांक अलग):
I. 6x² + 7x + 2 = 0
II. 4y² + 4y + 1 = 0

हल:
I: 6x² + 4x + 3x + 2 = 0 → 2x(3x+2) + 1(3x+2) = 0 → (2x+1)(3x+2) = 0 → x = -1/2, -2/3
II: (2y+1)² = 0 → y = -1/2 (दोहरा मूल)

तुलना:
x=-0.5, y=-0.5 → x = y
x=-0.67, y=-0.5 → x < y
उत्तर: x ≤ y

7. विशेष मामले और shortcuts

Shortcut 1 — समान पद देखकर factoring:
यदि दोनों समीकरणों में कोई गुणनखंड समान हो (जैसे ऊपर Example 3 में (2x+1) और (2y+1)), तो मूल तुलना बहुत आसान हो जाती है।

Shortcut 2 — शुद्ध द्विघात प्रश्न:
x² = 16 → x = ±4
y² = 25 → y = ±5
तुलना में 4 संयोजन बनेंगे, और उत्तर आमतौर पर 'relation cannot be established' आएगा (क्योंकि x=4 vs y=-5 → x>y, और x=-4 vs y=5 → x<y)।

Shortcut 3 — अंकों के योग/गुणन से त्वरित जाँच:
किसी द्विघात समीकरण के मूलों का योग = -b/a और गुणनफल = c/a है। यदि a=1 (सरलीकृत), तो योग = -b और गुणनफल = c। अक्सर परीक्षा में ऐसे प्रश्न आते हैं जहाँ c छोटा हो (जैसे 6, 12, 20) और b भी ज्ञात हो — तब तुरंत जोड़ी याद आ जाती है।

| गुणनफल (c) | संभावित मूल जोड़े |
|------------|-------------------|
| 6 | 2,3 या -2,-3 |
| 12 | 3,4 या -3,-4 |
| 20 | 4,5 या -4,-5 |
| 30 | 5,6 या -5,-6 |
| 56 | 7,8 या -7,-8 |
| 72 | 8,9 या -8,-9 |

Shortcut 4 — संकर प्रश्न (mixed coefficients):
जब a ≠ 1 हो, तो mn = ac और m+n = b की शर्त से जोड़ी चुनें।
उदा: 6x² + 13x + 6 = 0 → ac = 36, b = 13 → जोड़ी 4 और 9 → 6x² + 9x + 4x + 6 = 0

8. ग्राफ़िकल दृष्टिकोण (Graphical Approach)

dvighat samikaran ka graph ek parabola hota hai:
• Agar a > 0: parabola upar ki taraf khulta hai (opens upward), minimum point hota hai.
• Agar a < 0: parabola neeche ki taraf khulta hai (opens downward), maximum point hota hai.

Roots woh points hain jahan graph x-axis ko kaat-ta hai.

Banking exam mein graphical approach rarely asked directly, lekin ye concept help karta hai understand karne mein ki:
• Jab D > 0 ho: graph x-axis ko do jagah kaat-ta hai → do real roots
• Jab D = 0 ho: graph x-axis ko ek jagah touch karta hai → ek repeated root
• Jab D < 0 ho: graph x-axis ko nahi kaat-ta → no real roots

Graph se ye bhi samajh mein aata hai ki kyun negative coefficient wale questions mein roots negative aate hain: agar a>0, b>0, c>0 to both roots negative honge (kyunki sum = -b/a < 0, product = c/a > 0).

9. Banking exam ke liye important patterns

Banking prelims mein quadratic equations se normally 5-10 questions aate hain har set mein. Patterns ye hain:

Pattern A (Sabse common): Do equations, x aur y ke liye, relation find karo.
Solution time target: 30-45 seconds per pair.

Pattern B (Assertion-Reason type):
Assertion: x² - 7x + 12 = 0 ke roots 3 aur 4 hain.
Reason: Factorisation method se mid term split karte hain.
Dono sach hain aur Reason Assertion ko sahi se explain karta hai.

Pattern C (Numerical value based):
x² - 5x + 6 = 0 aur y² - 3y + 2 = 0 → (x+y) ka man nikalo.
x = 2,3; y = 1,2 → possible sums: 3,4,4,5 → options mein se match karo.

Pattern D (Inequality combination):
kuch sawalon mein equation ke saath inequality di jaati hai, jaise:
x² - 4x + 3 < 0, y² - 5y + 6 > 0
Ye thoda advanced level ka hai (SBI PO Mains mein kabhi-kabhi). Isme interval notation ka use hota hai:
x²-4x+3<0 → (x-1)(x-3)<0 → 1 < x < 3
y²-5y+6>0 → (y-2)(y-3)>0 → y < 2 ya y > 3

Exam weightage note: Quadratic Equations banking prelims ka regular part hai — har set mein 5-10 questions milte hain. Isliye speed aur accuracy dono par dhyan dena zaroori hai.

10. Common mistakes aur tips

Sabse common galtiyan (Common Mistakes):

1. Sign error in factoring: x² - 5x + 6 = 0 mein log -2 aur -3 le lete hain (yaद्वारा mistake), jabki sahi joड़ी +2 और +3 है (because sum = +5 not -5). Yaad rakhein: product positive, sum positive → दोनों positive. Product positive, sum negative → दोनों negative.

2. Relation check遗漏: Sirf दो case dekhte hain aur conclusion nikal lete hain. हमें सभी 4 combinations check karne hote hain.

3. x = y case overlook करना: Jab कहीं भी x = y आता है, तो answer ≥ या ≤ hi hoga, कभी > या < नहीं।

4. Discriminant की गणना गलत करना: D = b² - 4ac mein 4ac ka sign भूल जाना। जब c negative हो तो -4a×(negative) = +positive बन जाता है।

5. a ≠ 1 वाली equations में factorisation miss करना: जब a = 6 हो, तो ac = 6c होना चाहिए, सिर्फ c नहीं।

6. Decimal/root values की तुलना में गलत: x = -3/2 = -1.5 और y = -5/3 ≈ -1.67 → -1.5 > -1.67 (क्योंकि -1.5, -1.67 से दाईं ओर है number line पर)। Negative numbers की तुलना में अक्सर गलती होती है।

Tips for speed:
• Factor pairs of small numbers (upto 100) याद रखें — इससे 50% সময় बचेगा।
• पहले समीकरण के मूल निकालते ही उन्हें number line पर mark कर लें, फिर दूसरा समीकरण हल करें — इससे comparison आसान होगा।
• जब ac बड़ा हो, तो पहले b² - 4ac check करें — अगर perfect square नहीं है तो factorisation मुश्किल होगी और formula method बेहतर रहेगा।

Important facts

  • द्विघात समीकरण का मानक रूप: ax² + bx + c = 0, जहाँ a ≠ 0
  • मूलों का योग = -b/a, गुणनफल = c/a
  • विवेचक D = b² - 4ac; D > 0 → दो भिन्न वास्तविक मूल, D = 0 → समान मूल, D < 0 → काल्पनिक मूल
  • Banking exam में x-y संबंध प्रश्नों के लिए सभी 4 संयोजनों की तुलना अनिवार्य है
  • Agar kisi case mein x = y aaye, to answer ≥ ya ≤ hoga, never > ya <
  • Negative roots ki comparison mein dhyan rahe: -1.5 > -1.67 (number line ke daayein side bada hota hai)
  • Product positive, sum positive → dono roots positive; Product positive, sum negative → dono roots negative
  • Pure quadratic (ax² + c = 0) mein x = ±√(-c/a)

Formulas and relationships

ax² + bx + c = 0 (Standard form, a ≠ 0)
x = [-b ± √(b² - 4ac)] / 2a (Quadratic formula)
D = b² - 4ac (Discriminant)
α + β = -b/a (Sum of roots)
αβ = c/a (Product of roots)
x² + (p+q)x + pq = 0 → roots are -p and -q (Factorised insight for quick solving when a=1)

Common mistakes

  • Sign error in factoring: product aur sum dono ke signs galat chun lena — especially jab dono negative roots hon
  • Incomplete comparison: sirf 2-3 cases check karna instead of all 4 combinations of x and y roots
  • Overlooking x = y case: jab kisi pairing mein x = y aata hai, answer ≥ ya ≤ hota hai, > ya < nahi
  • Discriminant calculation error: -4ac mein c ke negative sign ko bhool jana
  • Decimal/negative comparison confusion: -3/2 vs -5/3 ki sahi ordering na kar paana
  • Ignoring coefficient a in factoring: a≠1 hone par bhi ac ki jagah sirf c ko consider kar lena
  • Assuming always x > y when x roots are numerically larger without checking sign and number line position
