Internet and Networking — Quick Revision (Banking Exam)

BankingHindiQuick Revision

Definitions

  • इंटरनेट: विश्वव्यापी कंप्यूटर नेटवर्कों का वह संग्रह जो TCP/IP प्रोटोकॉल के माध्यम से एक-दूसरे से जुड़ा होता है। यह किसी एक संगठन की नहीं, बल्कि लाखों स्वतंत्र नेटवर्कों का इंटरकनेक्शन है।
  • नेटवर्क: दो या अधिक कंप्यूटर/डिवाइस का परस्पर जुड़ाव ताकि डेटा और संसाधन साझा किए जा सकें। बैंकिंग परीक्षाओं में नेटवर्क का अर्थ प्रायः कंप्यूटर नेटवर्क ही होता है।
  • LAN (Local Area Network): एक सीमित भौगोलिक क्षेत्र जैसे एक कमरा, इमारत या परिसर तक सीमाबद्ध नेटवर्क। गति उच्च होती है और त्रुटि दर न्यूनतम।
  • MAN (Metropolitan Area Network): एक शहर या महानगर की सीमा में फैला नेटवर्क; LAN से बड़ा पर WAN से छोटा। cable TV नेटवर्क इसका उदाहरण है।
  • WAN (Wide Area Network): संपूर्ण देश या विश्व स्तर पर फैला नेटवर्क। इंटरनेट ही सबसे बड़ा WAN है। दूरस्थ स्थानों को जोड़ने के लिए leased lines, satellite Links आदि उपयोग होते हैं।
  • PAN (Personal Area Network): एक व्यक्ति की निजी डिवाइसों के बीच की सीमित दूरी की कनेक्टिविटी (जैसे Bluetooth, USB)। कार्यक्षेत्र लगभग कुछ मीटर तक सीमित।
  • IP Address: नेटवर्क पर किसी भी डिवाइस की अद्वितीय पहचान संख्या। IPv4 में 32-bit (जैसे 192.168.1.1) और IPv6 में 128-bit एड्रेस होते हैं।
  • URL (Uniform Resource Locator): किसी वेब पेज या संसाधन का पता दर्शाने वाला पाठ स्वरूप। उदाहरण: https://www.bankname.com/login
  • DNS (Domain Name System): इंसान-अनुकूल डोमेन नाम (जैसे www.sbi.co.in) को मशीन-अनुकूल IP पते में बदलने वाला वितरित डेटाबेस प्रणाली। बिना DNS के वेब ब्राउज़िंग असंभव होगी।
  • Protocol: कंप्यूटर के बीच संचार के नियमों एवं मानकों का समूह। बैंकिंग में TCP, IP, HTTP, HTTPS, FTP, SMTP, POP3, IMAP जैसे प्रोटोकॉल मुख्य हैं।

Key concepts

  • नेटवर्क श्रेणी (Topology-based classification):
    • Bus Topology: सभी नोड्स एक ही मुख्य केबल (backbone) से जुड़े। किफायती, लेकिन backbone टूटने पर पूरा नेटवर्क बंद।
    • Star Topology: सभी नोड्स केंद्रीकृत डिवाइस (hub/switch) से जुड़े। एक नोड खराब होने पर बाकी चलते रहते हैं। आज के अधिकांश ऑफिस नेटवर्क इसी प्रकार के हैं।
    • Ring Topology: नोड्स एक वलय (ring) में जुड़े; डेटा एक ही दिशा में घूमता है। Token Ring इसका प्रमुख उदाहरण।
    • Mesh Topology: हर नोड दूसरे हर नोड से प्रत्यक्ष/परोक्ष जुड़ा हो। सबसे अधिक विश्वसनीय, पर लागत बहुत अधिक।
    • Hybrid Topology: उपरोक्त में से दो या अधिक का मिश्रण। बड़ी संस्थाएं इसी का उपयोग करती हैं।
  • नेटवर्क उपकरण (Network Devices) — परीक्षा-मुख्य:
    • Hub: बहु-पोर्ट repeater; डेटा broadcast करता है। Layer-1 उपकरण। सुरक्षा और प्रदर्शन दोनों कमजोर।
    • Switch: MAC पते देखकर डेटा केवल संबंधित पोर्ट पर भेजता है। Layer-2 उपकरण। आधुनिक LANs में hub की जगह switch ही चलाता है।
    • Router: विभिन्न नेटवर्कों को आपस में जोड़ता है; IP पते देखकर पथ चुनता है (Layer-3)। इंटरनेट कनेक्टिविटी के लिए अनिवार्य।
    • Bridge: दो LAN segments को जोड़करcollision domain को विभाजित करता है (Layer-2)। प्रायः switch द्वारा प्रतिस्थापित।
    • Repeater: कमजोर सिग्नल को पुनः प्रसारित/प्रबल करता है (Layer-1)।
    • Gateway: अलग-अलग प्रोटोकॉल ढांचों वाले नेटवर्कों के बीच अनुवाद करने वाला उपकरण। Layer-4 से Layer-7 तक संचालित हो सकता है।
  • OSI Model (7 Layers) — स्मरण क्रम: All People Seem To Need Data Processing
    • Physical Layer (Layer-1): केबल, कनेक्टर, बिट स्ट्रीम, Hubs, Repeaters.
    • Data Link Layer (Layer-2): framing, MAC address, Switches, Bridges, Error detection.
    • Network Layer (Layer-3): IP addressing, Routers, Packet routing.
    • Transport Layer (Layer-4): TCP/UDP, segmentation, end-to-end delivery.
    • Session Layer (Layer-5): connection establishment, maintenance, termination.
    • Presentation Layer (Layer-6): encryption/decryption, data translation/compression.
    • Application Layer (Layer-7): user-facing protocols — HTTP, FTP, SMTP, DNS.
    बैंकिंग परीक्षा में layer-wise device और कार्य संबंधी प्रश्न आवर्ती हैं।
  • TCP/IP Model (4 Layers) — व्यावहारिक मॉडल:
    • Network Access (Link) Layer: hardware addressing व physical signaling।
    • Internet Layer: IP, ICMP, routing — Layer-3 के तुल्य।
    • Transport Layer: TCP (विश्वसनीय), UDP (तीव्र पर अविश्वसनीय)।
    • Application Layer: HTTP, FTP, SMTP, DNS आदि।
    ध्यान दें: OSI 7 layers वाला सैद्धांतिक ढांचा है जबकि TCP/IP व्यावहारिक इंटरनेट का आधार। परीक्षा में दोनों की तुलनात्मक जानकारी पूछी जाती है।
  • मुख्य प्रोटोकॉल एवं उनके port/nature:
    • HTTP (HyperText Transfer Protocol): web pages transfer, port 80, unencrypted।
    • HTTPS: encrypted HTTP; TLS/SSL से सुरक्षित; port 443। बैंकिंग लेनदेन हमेशा HTTPS पर होते हैं।
    • FTP (File Transfer Protocol): file upload/download; port 21।
    • SMTP (Simple Mail Transfer Protocol): email send; port 25।
    • POP3 (Post Office Protocol v3): email retrieve locally; port 110।
    • IMAP (Internet Message Access Protocol): email sync across devices; port 143।
    • TCP: connection-oriented, reliable, ordered delivery।
    • UDP: connectionless, fast, no guarantee। streaming/DNS queries में उपयोग।
  • IPv4 vs IPv6:
    • IPv4: 32-bit, लगभग 4.3 अरब unique addresses; decimal-dot notation (192.168.1.1)। address exhaustion के कारण ही IPv6 लाया गया।
    • IPv6: 128-bit, colon-hexadecimal notation (2001:0db8::1); लगभग 3.4×10^38 addresses; header simplified; built-in security (IPsec सहयोग)।
    बैंकिंग में IPv6 transition, dual-stack, tunneling जैसे अवधारणात्मक प्रश्न भी आए हैं।
  • Web technologies और banking relevance:
    • Browser: वेब पेज render करने वाला सॉफ्टवेयर (Chrome, Firefox, Edge, Safari आदि)।
    • Web Server: HTTP requests receive करके HTML/content return करता है (Apache, Nginx, IIS)।
    • Domain Name: human-readable name; DNS द्वारा IP में convert।
    • URL structure: protocol://hostname/path?query#fragment। HTTPS का प्रयोग banking में mandate है।
    • HTTP Methods: GET (डेटा fetching), POST (डेटा submitting), PUT, DELETE आदि। Banking APIs में POST/PUT/DELETE का महत्व।
  • Cybersecurity basics (नेटवर्क-संबंधी):
    • Firewall: नेटवर्क traffic को predefined rules पर आधारित filter करने वाला सुरक्षा उपकरण/सॉफ्टवेयर। packet inspection, stateful inspection, application-level firewall types।
    • Virus/Malware/Worm/Trojan: virus file से attached, worm self-replicating और network-independent, Trojan disguise करके enters।
    • Phishing: fraudulent email/link द्वारा confidential information churana। banking fraud का प्रमुख माध्यम।
    • Encryption: plaintext → ciphertext (encryption), ciphertext → plaintext (decryption)। Symmetric (एक key) vs Asymmetric (public/private key pair)।
    • SSL/TLS: HTTPS का underlying secure protocol; certificate-based authentication।
  • Wireless & mobile networking basics:
    • Wi-Fi: IEEE 802.11 family; home/office wireless LAN।
    • Bluetooth: PAN के लिए short-range wireless (≈10m)।
    • Cellular networks: 3G/4G/5G; mobile banking apps इन्हीं के माध्यम से connect।
    • RFID/NFC: Near Field Communication — contactless card payments में उपयोग। UPI, contactless debit cards की तकनीकी नींव।
  • Important numerical facts ( rote memory):
    • Default gateway: home/router ka IP जो local network ko external network (internet) से जोड़ता है।
    • Subnet mask: IP address के network portion vs host portion को अलग करने वाली value; classful में A=255.0.0.0, B=255.255.0.0, C=255.255.255.0।
    • Private IP ranges (RFC 1918): 10.0.0.0–10.255.255.255, 172.16.0.0–172.31.255.255, 192.168.0.0–192.168.255.255।
    • Public vs Private IP: private local use, public internet-visible। NAT (Network Address Translation) इन दोनों के बीच bridge है।

Important facts

  • इंटरनेट की शुरुआत ARPANET (1969, USA) से हुई; ARPANET DARPA द्वारा विकसित। आधुनिक इंटरनेट का मूल TCP/IP protocol suite Vint Cerf ও Bob Kahn द्वारा विकसित।
  • W3C (World Wide Web Consortium) का निर्माण Tim Berners-Lee द्वारा 1994 में किया गया था; उन्होंने World Wide Web का आविष्कार भी किया।
  • HTTP प्रोटोकॉल का विकास 1990 में Tim Berners-Lee द्वारा किया गया था; वर्तमान stable version HTTP/2 और HTTP/3 हैं।
  • ISP (Internet Service Provider): ऐसा संगठन जो व्यक्तियों/संस्थाओं को इंटरनेट कनेक्टिविटी प्रदान करता है। भारत में प्रमुख ISP — BSNL, Jio, Airtel, MTNL आदि।
  • IRC (Internet Relay Chat): real-time text messaging protocol; banking context में प्रासंगिक नहीं लेकिन competitive exam में पूछा गया है।
  • WWW ≠ Internet: Internet infrastructure (networks + protocols) है; WWW उसका ही एक application (web pages + HTTP + HTML) है। परीक्षा में यह distinction अक्सर trap के रूप में आता है।
  • URL में 'https://' का मतलब है कि communication encrypted है; 'http://' plain text — अतः online banking में केवल HTTPS URL ही सुरक्षित माना जाता है।
  • IP Class A: first octet 1-126, default subnet mask 255.0.0.0; Class B: 128-191, mask 255.255.0.0; Class C: 192-223, mask 255.255.255.0। Loopback address 127.0.0.1 हमेशा Class A range में आता है।
  • SMTP केवल email भेजने के लिए; प्राप्त करने के लिए POP3 या IMAP। अक्सर पूछा जाता है: 'Mail send करने वाला कौन सा protocol है?' उत्तर — SMTP।
  • Modem (Modulator-Demodulator): analog signal को digital में और vice versa convert करता है; dial-up internet के समय central device था। आज fiber/cable/DSL dominant हैं।
  • NAT (Network Address Translation): private IPs को public IP पर map करता है ताकि multiple devices एक ही public IP से internet access कर सकें। домашний/office路由器 का primary कार्य NAT+routing दोनों।
  • LAN speed standards: 10 Mbps → 100 Mbps (Fast Ethernet) → 1 Gbps → 10 Gbps। banking branch LAN प्रायः 1 Gbps backbone use करता है।
  • Wi-Fi प्रमाणपत्र: IEEE 802.11a/b/g/n/ac/ax। ax = Wi-Fi 6 (उच्च गति, कम latency, dense environments के लिए बेहतर)।

Memory aids

  • OSI layers याद रखें: "All People Seem To Need Data Processing" → Application, Presentation, Session, Transport, Network, Data Link, Physical।
  • TCP/IP model 4-layer याद रखें: "Please Do Not Throw Sausage Pizza Away" → Physical, Data Link, Internet, Transport (या Upper-level Application)। परीक्षा में प्रायः 4-layer version पूछा जाता है।
  • Port numbers mnemonic: HTTP=80, HTTPS=443, FTP=21, SSH=22, DNS=53, SMTP=25, POP3=110, IMAP=143, Telnet=23, MySQL=3306।
  • IP Class boundaries: "A for Apple (1-126), B for Banana (128-191), C for Cherry (192-223)" — रेंज की प्रथम digit याद रखें।
  • Private IP ranges याद रखें: "10 is home, 172 is office, 192.168 is apartment" — तीन सामान्य private ranges का first octet याद करें।
  • Top-level domains: .com (commercial), .org (organization), .net (network), .in (India), .gov (government), .edu (education), .mil (military)।
  • Firewall type distinction: Packet filtering (Layer-3/4), Stateful inspection (tracks connections), Application-level (proxy, Layer-7) — simple mapping याद रखें।

Exam tips

  • Banking Computer Knowledge में Internet/Networking से प्रति सेट 3-6 प्रश्न आते हैं — Mostly direct fact और conceptual recognition। अतः port numbers, OSI layers, device roles, protocol functions की स्पष्ट धारणा रखें।
  • Assertion-Reason प्रश्नों में TCP vs UDP, HTTP vs HTTPS, IPv4 vs IPv6 के differences पर विशेष ध्यान दें; दोनों कथन सही हो सकते हैं पर reason wrong explanation दे सकता है।
  • Matching-type प्रश्न सामान्यतः Protocol ↔ Port, Layer ↔ Device, Abbreviation ↔ Full form में आते हैं; याद रखने के लिए mnemonic बनाकर दोहराएं।
  • Negative marking (अधिकतर IBPS/SBI में 0.25) के कारण अस्पष्ट प्रश्नों पर अनुमान से बचें; elimination technique से कम از कम दो विकल्प निकालकर ही उत्तर दें।
  • Current banking context में UPI, NPCI, digital payment security (2FA, OTP, token) तथा cybersecurity awareness से जुड़े प्रश्न बढ़ रहे हैं — इसलिए firewall, phishing, encryption की definitions स्पष्ट रखें।
  • Prelims में Computer Knowledge section 30-40 minute में attempt करें; इस section की तैयारी fast recall पर आधारित है — daily 15-20 minutes quick revision से long-term retention बनाए रखें।
  • Mock test में networking प्रश्नों का error log रखें; repeated trap patterns (जैसे "SMTP receive करता है" जैसा विकल्प) की पहचान से ही next attempt में mark बचते हैं।

Common traps

  • Trap: "WWW = Internet" — गलत; WWW इंटरनेट पर चलने वाला एक application मात्र है; इंटरनेट में email, FTP, VoIP, gaming भी शामिल हैं।
  • Trap: "HTTP भी सुरक्षित है" — गलत; केवल HTTPS encrypted है। banking questions में सावधानी बरतें।
  • Trap: "SMTP email receive करता है" — गलत; SMTP send करता है; receive POP3/IMAP करते हैं। मिश्रण प्रश्न अक्सर trap होते हैं।
  • Trap: "Hub smart device है" — गलत; Hub dumb device है जो broadcast करता है; Switch smart device है जो MAC address देखकर targeted delivery करता है।
  • Trap: "IP Address = Mac Address" — गलत; IP logical address (software/configurable) है, MAC physical address (hardware/burned-in) है; दोनों alag层次 पर काम करते हैं।
  • Trap: "Class D/E addresses mainstream networking में regularly use होते हैं" — गलत; Class D multicast, Class E experimental/reserved हैं; ordinary hosts Class A/B/C में assign होते हैं।
  • Trap: "IPv6 के 128 bits में से केवल 64 bits ही global routing ke liye" — आधा सही, आधा गलत; IPv6 में 64-bit prefix + 64-bit interface identifier (EUI-64) सामान्य रूप है, पर exception संभव हैं। सरलता से 128-bit total याद रखें।
  • Trap: "Modem और Router एक ही device है" — गलत; modem signal convert करता है, router traffic route करता है। Home broadband unit प्रायः二者合一, पर 개념적 distinction परीक्षा में पूछी जाती है।
