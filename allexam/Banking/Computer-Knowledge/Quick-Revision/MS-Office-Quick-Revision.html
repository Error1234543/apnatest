MS Office - Quick Revision | Banking Computer Knowledge

BankingHindiQuick Revision

Definitions

  • MS Office: Microsoft का सॉफ़्टवेयर पैकेज जिसमें Word, Excel, PowerPoint, Outlook आदि शामिल हैं।
  • MS Word: टाइपोग्राफी और डॉक्यूमेंट निर्माण हेतु वर्ड प्रोसेसर।
  • MS Excel: स्प्रेडशीट एप्लिकेशन जो डेटा संग्रह, विश्लेषण एवं गणितीय गणनाओं के लिए उपयोग होता है।
  • MS PowerPoint: प्रेज़ेंटेशन बनाने हेतु इमेज, टेक्स्ट, वीडियो आदि संयोजन टूल।
  • File: कंप्यूटर में संग्रहीत जानकारी का बेसिक यूनिट, जिसका एक्सटेंशन उसकी प्रकार बताता है।
  • Folder: एक डिरेक्टरी जो फाइलों व अन्य फोल्डर्स को व्यवस्थित करती है।
  • Ribbon: MS Office में टूल्स व कमांड्स को कैटेगरी में व्यवस्थित करने वाला टूलबार।
  • Cell: Excel में स्तंभ (Column) व पंक्ति (Row) के इंटरसेक्शन पर स्थित सबसे छोटी इकाई।
  • Formula: समीकरण जो डेटा पर गणितीय कार्य करता है, जिसका आरंभ (=) से होता है।
  • Function: पूर्वनिर्मित सूत्र (जैसे SUM, AVERAGE), जिसे तुरंत उपयोग किया जा सकता है।
  • Shortcut Key: एक या अधिक कुंजी का संयोजन जो किसी कार्य को तेज़ी से सम्पादित करता है।
  • Default Extension: फाइल का मूल रूप; .docx (Word), .xlsx (Excel), .pptx (PowerPoint)।

Key concepts

  • MS Office का परिचय: Microsoft Office एक ऑफ़िस स्यूट है जिसमें कई ऐप्स शामिल हैं। Banking कंप्यूटर विषय में मुख्यतः Word, Excel, PowerPoint और उनके शॉर्टकट, फ़ंक्शन तथा फ़ाइल हैंडलिंग पर ध्यान दिया जाता है। प्रत्येक एप्लिकेशन की अपनी विशिष्ट भूमिका है: Word — टेक्स्ट प्रोसेसिंग; Excel — डेटा विश्लेषण व गणना; PowerPoint — प्रेज़ेंटेशन निर्माण।
  • MS Word – मुख्य अवधारणाएँ: • शब्दांश (Word Processing): टेक्स्ट लिखने, संपादित करने, प्रारूपित करने की प्रक्रिया।\n• पेज सेटअप: मार्जिन, ओरिएंटेशन (पोर्ट्रेट/लैंडस्केप), साइज (A4 आदि)।\n• फ़ॉन्ट व पैराग्राफ़: बोल्ड, इटैलिक, अंडरलाइन, स्पेलिंग चेक, ग्रेमर चेक, क्विक एक्सेस टूलबार।\n• टूलबार: होम, इंज़र्ट, लेआउट, रिफ़रेंसेज, मेलिंग, व्यू आदि।\n• टेबल: ग्रिड द्वारा डेटा प्रस्तुत करना। Tab + T से तेज़ सेल निर्माण।
  • MS Excel – मुख्य अवधारणाएँ: • स्प्रैडशीट संरचना: Column (A, B, C...), Row (1, 2, 3...), Cell (A1, B2...)।\n• Formula व Function: =SUM(), =AVERAGE(), =COUNT(), =MAX(), =MIN(), =IF(), =VLOOKUP(), =CONCATENATE()।\n• Relative vs Absolute Reference: relative ($A$1 नहीं), absolute ($A$1), mixed (A$1, $A1)। F4 कुंजी से टॉगल।\n• Formatting: number format (General, Currency, Percentage, Date)। Conditional formatting।\n• Charting: बार, लाइन, पाई चार्ट आदि डेटा दृश्य बनाने हेतु।\n• Sorting & Filtering: क्रमबद्ध/अ क्रमबद्ध व शर्तवार देखना।
  • MS PowerPoint – मुख्य अवधारणाएँ: • Slide: एक व्यक्तिगत प्रस्तुति पृष्ठ।\n• Template व Theme: पूर्व निर्मित डिज़ाइन।\n• Transition व Animation: स्लाइड बदलाव व ऑब्जेक्ट गति।\n• Presenter View: प्रेज़ेंटेशन चलते समय नोट्स व अगली स्लाइड देखना।\n• Export: PDF, Video, Presentation (.pptx) में निर्यात।
  • File Management Basics: • Create: Ctrl+N (नया), Ctrl+S (सहेजना), F12 (Save As)।\n• Open: Ctrl+O।\n• Close: Ctrl+W (फ़ाइल बंद), Alt+F4 (एप बंद)।\n• Shortcut: Ctrl+C (कॉपी), Ctrl+V (पेस्ट), Ctrl+X (कट), Ctrl+Z (Undo), Ctrl+Y (Redo)।\n• Save As vs Overwrite: Save As नया नाम/स्थान देकर सेव करता है, मूल फ़ाइल अपरिवर्तित रहती है।
  • Important Keyboard Shortcuts (Common): • Ctrl+B → Bold, Ctrl+I → Italic, Ctrl+U → Underline।\n• Ctrl+E → Align Center, Ctrl+L → Left Align, Ctrl+R → Right Align।\n• Ctrl+F → Find, Ctrl+H → Replace, Ctrl+G → Go To।\n• Ctrl+D → Fill Down, Ctrl+Arrow → Jump to edge।\n• Alt+Shift+D → Insert Date, Alt+Shift+T → Insert Time।\n• F2 → Edit cell, F5 → Go To dialog, F12 → Save As।\n• Ctrl+Shift+& → Apply border, Ctrl+Shift~- → Remove border।

Excel फ़ंक्शन व सूत्र (विशेषतः SUM, AVERAGE, COUNT, IF, VLOOKUP)\n3. File extension (.docx, .xlsx, .pptx, .pdf)\n4. Ribbon, Toolbar, Menu का नाम\n5. Default save location व path\n6. Print setup, Page margins, Orientation\n7. Undo/Redo, Copy/Paste, Cut।

Important facts

  • MS Office द्वारा Microsoft Corporation विकसित किया गया है।
  • MS Excel में एक sheet में 1,048,576 rows और 16,384 columns होते हैं (2007+)।
  • MS Word 2007+ की मानक फ़ाइल एक्सटेंशन .docx है; .doc पुराना फ़ॉर्मैट है।
  • MS Excel की default फ़ाइल एक्सटेंशन .xlsx है; .xls पुराना।
  • MS PowerPoint की default एक्सटेंशन .pptx है।
  • F2 कुंजी Excel में cell edit mode में जाती है।
  • Ctrl+M (PowerPoint) नई स्लाइड बनाता है।
  • Ctrl+P (Word/Excel) प्रिंट डायलॉग खोलता है।
  • Alt+F4 किसी भी ऐप को बंद करता है।
  • Ctrl+Shift+N (Word) नया डॉक्यूमेंट बनाता है (कुछ संस्करणों में)।
  • Ctrl+9, Ctrl+Shift+9 से row height/column width reset होती है।
  • Alt+F1 → Embedded chart, F11 → Chart on new sheet (Excel)।
  • Ctrl+K hyperlink insert करता है।
  • Ctrl+W फ़ाइल बंद करता है, Ctrl+F4 भी फ़ाइल बंद करता है (Window)।
  • Print Preview: Ctrl+F2 (Word)।
  • Page Setup: Ctrl+P (Print dialog), मा़इजिन: Layout tab में Pagesize > Margins > Custom Margins।

Memory aids

  • F12 = Save As, F2 = Edit cell, F5 = Go To, F1 = Help। ये क्रम याद रखने के लिए: 'Help (F1), Edit (F2), Go (F5), SaveAs (F12)'—एक sequence जैसा।
  • Bold (Ctrl+B), Italic (Ctrl+I), Underline (Ctrl+U)—B/I/U अक्षरों का प्रयोग आसान।
  • Alt+Enter (cell में line break), Shift+Tab (पिछले cell), Tab (अगला cell)।
  • Ctrl+Z undo, Ctrl+Y redo—Z को 'undo' के लिए 'z' जो उलटा दिशा, Y 'redo' forward दिशा।
  • F4 = Toggle Absolute/Relative reference; F4 कुंजी की स्थिति (फंक्शन पंक्ति के निकट) याद रखें।
  • MS Office ribbon में टैब क्रम: Home → Insert → Page Layout → Formulas → Data → Review → View।

Exam tips

  • Banking कंप्यूटर में MS Office से 4–6 प्रश्न आते हैं; अधिकांश shortcut व function base होते हैं।
  • Shortcut याद करें जबकि hands-on practice करें; keyboard layout याद रखें।
  • Excel functions में VLOOKUP, SUMIF, COUNTIF जैसे महत्वपूर्ण फ़ंक्शन हाई-वाइट हैं।
  • File extension के प्रश्न में .docx/.xlsx/.pptx/.pdf/.txt याद रखें।
  • Print setup, margins, page orientation जैसे प्रश्न आते हैं—Page Layout टैब में सब कुछ मिलता है।
  • Shortcuts याद करने के लिए flashcard बनाएं; एक ही समय में 5–6 shortcuts रिवीज करें।
  • Formula में equal sign (=) जरूर लगे, बिना इसके formula नहीं माना जाएगा।
  • Assertion-Reason type प्रश्न में दोनों statement सही हो सकते हैं पर Reason galat explanation दे सकता है।
  • Caselet में कभी-कभी real scenario में shortcut पूछा जाता है—apply करें, rote नहीं।
  • Ribbon tab के नाम याद रखें; question में ‘Insert tab में क्या नहीं होगा?’ जैसे।

Common traps

  • Ctrl+V vs Ctrl+Shift+V — Ctrl+V paste करता है, Ctrl+Shift+V ‘Paste Special’ या ‘Keep Text Only’ कुछ ऐप में। Banking में paste केवल Ctrl+V पूछा जाता है।
  • Save vs Save As — Save (Ctrl+S) मौजूदा फ़ाइल को update करता है; Save As (F12) नया नाम/स्थान देकर कॉपी बनाता है।
  • Absolute vs Relative Reference — =A1$B$2 vs =A1*B2—absolute में $ चिन्ह होता है। Formula copy करते समय relative change होता है, absolute नहीं।
  • F2 vs F5 vs F12 confusion — F2 edit, F5 go-to, F12 save-as; परीक्षा में अक्सर mix करवाए जाते हैं।
  • .docx बनाम .doc, .xlsx बनाम .xls — .doc/.xls Microsoft Office 2003 तक; .docx/.xlsx 2007+; question में version पूछ सकते हैं।
  • Ctrl+O vs Ctrl+P — Ctrl+O Open, Ctrl+P Print—दोनों मिलकर confuse हो सकते हैं।
  • Chart types — Line chart trend, Bar chart comparison, Pie chart proportion—हर chart का उपयोग अलग है, question में application पूछ सकता है।
  • Undo Redo direction — Ctrl+Z एक step पीछे, Ctrl+Y एक step आगे; कभी-कभी Ctrl+Y redo बजाय दूसरी action भी करता है, पर banking में redo मानें।
