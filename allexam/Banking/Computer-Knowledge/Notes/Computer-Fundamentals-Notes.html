Important facts

  • Charles Babbage को 'Father of Computer' कहा जाता है; Ada Lovelace पहली programmer हैं।
  • ENIAC (1946) पहला electronic general-purpose computer था; vacuum tubes का उपयोग; 18,000 vacuum tubes, 30 tons weight।
  • Computer की 5 पीढ़ियाँ: 1st (Vacuum Tube, 1940-56), 2nd (Transistor, 1956-63), 3rd (IC, 1964-71), 4th (VLSI, 1971-present), 5th (AI/ULSI)।
  • 1 Byte = 8 Bits; 1 KB = 1024 Bytes; 1 MB = 1024 KB; 1 GB = 1024 MB; 1 TB = 1024 GB।
  • CPU तीन मुख्य हिस्से: ALU (arithmetic + logic), CU (control + coordinate), Registers (temporary storage)।
  • RAM volatile है (power off पर data Gone), ROM non-volatile है; BIOS ROM में stored होता है।
  • Cache Memory CPU के बहुत करीब, SRAM (cache) और DRAM (main RAM) में अंतर: SRAM faster, more expensive, no refresh needed; DRAM slower, cheaper, needs periodic refresh।
  • MICR (Magnetic Ink Character Recognition) cheques पढ़ने के लिए; OCR text recognition; OMR sheets पढ़ने के लिए; Bar Code Reader retail/banking inventory के लिए।
  • TCP/IP internet का foundational protocol suite है; DNS hostname को IP में बदलता है; HTTPS SSL/TLS encryption use करता है।
  • Firewall network security filter है; Antivirus malware detect/remove करती है; Phishing fake communication द्वारा credentials चुराना है; Trojan हानिकारक program जो useful दिखकर install होता है।
  • Common Shortcuts: Ctrl+C (Copy), Ctrl+V (Paste), Ctrl+X (Cut), Ctrl+Z (Undo), Ctrl+A (Select All), Ctrl+S (Save), Alt+F4 (Close), Ctrl+N (New), Ctrl+P (Print), Del (Delete), Backspace (erase backward)।
  • Compiler whole program एक साथ machine code में बदलता है; Interpreter line by line; Assembler assembly language → machine code।
  • IPv4 32-bit address देता है (~4.3 billion); IPv6 128-bit; IP address uniquely identify करता है each device on network।
  • LAN: local, MAN: city, WAN: wide/internet, PAN: personal, SAN: storage-focused; bank branch internal = LAN; interbranch = MAN/WAN।
  • BIOS POST (Power On Self Test) run करता है boot time पर; CMOS battery BIOS settings maintain करती है; UEFI modern BIOS replacement है।

Common mistakes

  • KB = 1000ではなく 1024 Bytes होता है (binary convention); exam में binary value मानें unless specified decimal (1000)।
  • RAM volatile, ROM non-volatile — inverse करना बहुत आम mistake है; RAM断电后数据消失, ROM remains।
  • Compiler vs Interpreter confusion: compiler एकदम से पूरा code convert करता है (error पहले ही मिलते हैं); interpreter line-by-line (runtime error आसानी से पकड़ता है)।
  • IP Address class confusion: Class A (1-126), B (128-191), C (192-223), D (multicast 224-239), E (reserved 240-255)। Private IP: 10.x.x.x, 172.16-31.x.x, 192.168.x.x — यह fact याद रखें।
  • Number system base mix-up: binary digits केवल 0,1; octal 0-7; hex 0-9,A-F। Hex में G,H,I,J,K,L,M,N,O,P गलत हैं।
  • Shortcut keys के letters याद रखते समय position confuse होना: C=C (copy), V=V (very close vowel to copy paste flow), X=cut (symbol like cut)।
  • LAN vs WAN definition reversed करना; LAN छोटा area, WAN बड़ा area — simple rule।
  • Antivirus ≠ Firewall distinction: antivirus infected files check करती है; firewall incoming/outgoing traffic filter करती है। दोनों अलग-अलग कार्य।
  • Phishing vs Spam: phising malicious credential theft है, spam बस unwanted bulk email है —混淆 करना गलत है।
  • MICR, OCR, OMR में भेद: MICR magnetic ink characters (bank cheques); OCR general paper text; OMR bubble sheet (exam scanning) — अलग-अलग用途।
  • BIOS stored in ROM (non-volatile), CMOS battery-powered RAM (volatile) जो BIOS settings hold करती है; BIOS ≠ CMOS confusion न करें।
  • Server ≠ Client distinction: server resource provide करता है; client request करता है; banking में Customer internet banking client side, Bank backend server side है।
