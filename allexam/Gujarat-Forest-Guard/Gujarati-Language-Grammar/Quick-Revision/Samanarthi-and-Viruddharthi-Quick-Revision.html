સમોર્થી અને વિરુદ્ધાર્થી — ઝડપી પુનરાવર્તન

Gujarat Forest GuardGujaratiQuick Revision

Definitions

  • સમોર્થી (Synonym): એક જ શબ્દના અર્થ ધરાવતા બે અથવા વધુ શબ્દોને સમોર્થી શબ્દો કહે છે. ઉદા. 'સુંદર' અને 'સુન્દર', 'ગમ્ભીર' અને 'ગંભીર'.
  • વિરુદ્ધાર્થી (Antonym): જે શબ્દોના અર્થમાં પરસ્પર વિરોધ હોય એવા શબ્દોને વિરુદ્ધાર્થી શબ્દો કહે છે. ઉદા. 'સુખ'–'દુઃખ', 'પ્રકાશ'–'અંધકાર', 'ઉષા'–'રાત્રિ'.
  • સમાનાર્થી શબ્દોના બે મુખ્ય પ્રકાર: (૧) સંપૂર્ણ સમોર્થી — જેનો અર્થ દરેક સંદર્ભમાં સમાન હોય. (૨) આંશિક સમોર્થી — જેનો અર્થ કેટલાક સંદર્ભોમાં જ સમાન હોય.
  • વિરુદ્ધાર્થી શબ્દોના ત્રણ પ્રકાર: (૧) સાપેક્ષ વિરુદ્ધ (Relative opposites) — 'મોટું' vs ' chhota', (૨) સંપૂર્ણ વિરુદ્ધ (Absolute opposites) — 'જીવંત' vs 'મૃત', (૩) ગ્રેડલેસ વિરુદ્ધ — જેમ 'સૂર્ય' અને 'ચંદ્ર' (એકબીજા વિરુદ્ધ નથી પણ વિરોધાભાસી છે).

Key concepts

  • સમોર્થી શબ્દોની પસંદગીમાં સંદર્ભ માહિતી महत्त्वની છે — કેટલાક શબ્દો ફક્ટ મિલે પણ ખાસ સંદર્ભમાં વધુ યોગ્ય હોય છે.
  • ગુજરાતીમાં સમોર્થી બનાવવા માટે પરિમાણો: લિંગ, વચન, વિભક્તિ, આચારિક ભેદ. ઉદા. 'ગાય' અને 'ઉભય' (ગૌ) સમોર્થી છે પણ 'ગાય' સામાન્ય, 'ઉભય' સાહિત્યિક.
  • વિરુદ્ધાર્થી જોડમાં પ્રામાણિક ભાષાશાસ્ત્રીય પરીક્ષા (Purushartha) નો વિચાર કરવો — ધર્મ, અર્થ, કામ, મોક્ષમાંથી કોઈ એકનો વિરોધી ખોટો નથી હોતો પણ ભાવનાત્મક વિરોધ હોય છે.
  • સામાન્ય ગુજરાતી પરીક્ષાઓમાં સમોર્થી/વિરુદ્ધાર્થી પ્રશ્નોમાં ચાર શબ્દોમાંથી ત્રણ સમોર્થી છે તો ચોથો પસંદ કરવો, અથવા 'નીચેનામાંથી કયા શબ્દનો સમોર્થી નથી?' પ્રકારના પ્રશ્નો આવે છે.
  • અંગ્રેજી-ગુજરાતી અનુવાદમાં આવતા ભ્રમ: 'fast' = 'ઝડપી' પણ 'ઝડપ' નહીં; 'high' = 'ઊંચો' પણ 'ઊંચાઈ' નહીં. આ પ્રકારની મૂંઝવણ ટાળવી.

Important facts

  • સમોર્થી શબ્દોના મહત્વપૂર્ણ જૂથ:
  • સૌંદર્ય: સુંદર / સુન્દર / રમણીય / ઝડપી / તરુણ / કુંતલ
  • ગમ્ભીરતા: ગમ્ભીર / ગંભીર / ઊંડાણપૂર્વક / ભારે
  • બલ: બલવાન / શક્તિશાળી / બલવાન / પ્રબળ / દ્વિજ
  • પ્રકાશ: પ્રકાશ / જ્યોતિ / તેજ / રેખા / દીપ્તિ
  • અંધકાર: અંધકાર / તમ / કાળ / કાંતિહીન / નિરાકર
  • સુખ: સુખ / શાંતિ / આનંદ / મોદ / હર્ષ
  • દુઃખ: દુઃખ / સંતાપ / વિલાપ / કલહ / દાઝ
  • વિરુદ્ધાર્થી જોડીના મહત્વપૂર્ણ ઉદાહરણો:
  • ઉષા (પ્રभाત) ↔ રાત્રિ (નિશા)
  • સૂર્ય ↔ ચંદ્ર / તારો
  • જીવંત ↔ મૃત / મૃત્યુ
  • ગરમ ↔ ઠંડા
  • ઉચ્ચ ↔ નીચા
  • સ્ત્રી ↔ પુરુષ
  • આગ ↔ પાણી
  • આકાશ ↔ પૃથ્વી
  • વૃક્ષ ↔ અનન્ય (બિનવૃક્ષી)
  • મૈત્રી ↔ શત્રુતા
  • શાંતિ ↔ યુદ્ધ / કલહ
  • આયુષ ↔ મૃત્યુ / અવસાન
  • સફળતા ↔ પરાજય / નિષ્ફળતા
  • સત્ય ↔ અસત્ય / મિથ્યા
  • ધન ↔ ઘાટા / ભિક્ષા / ગરીબી

Memory aids

  • સમોર્થી શબ્દોને ગ્રુપમાં યાદ કરો: ઉદાહરણ તરીકે 'પ્રકાશ'નું જૂથ — પ્રકાશ, જ્યોતિ, તેજ, દીપ્તિ, ભાસ્કર — આ શબ્દો એકબીજાની જગ્યાએ વપરાય છે.
  • વિરુદ્ધાર્થી જોડીને જોડીમાં યાદ કરો: 'ઉષા-રાત્રિ', 'સૂર્ય-ચંદ્ર', 'જીવંત-મૃત' — આવી જોડીઓ યાદ રહેવામાં મદદ કરે છે.
  • સંસ્કૃત મૂળ ઓળખો: 'સુ' (ભલું) + 'ન્દર' = સુંદર; 'ભય' (ડર) + 'ન્ક' = ભયંકર — મૂળ અર્થ ઓળખાય તો સમોર્થી સમજવામાં મદદ મળે.
  • 'ઉષા' અને 'રાત્રિ' વિરુદ્ધ છે તે મૂળભૂત ભાષાશાસ્ત્રીય વિરોધ છે — આવી મૂળભૂત જોડીઓ પ્રથમ યાદ કરો.

Exam tips

  • Forest Guard (Vanrakshak) ભરતી પરીક્ષામાં ગુજરાતી ભાગમાં સમોર્થી/વિરુદ્ધાર્થીના પ્રશ્નો સીધા આવે છે. ૨-૪ નંબરના પ્રશ્નોમાંથી ૧-૨ પ્રશ્નો આ વિષયમાંથી આવી શકે છે.
  • પ્રશ્ન પંક્તિમાં 'નીચેનામાંથી કયા શબ્દનો સમોર્થી નથી?' પ્રકારના પ્રશ્ન અચૂક આવે છે. આ પ્રકારના પ્રશ્નમાં ત્રણ સમોર્થી હોય છે અને એક અલગ હોય છે — એ અલગ શબ્દ પસંદ કરવો.
  • વિરુદ્ધાર્થી પ્રશ્નમાં 'નીચેનામાંથી કયા શબ્દનો વિરુદ્ધાર્થી શબ્દ નથી?' પ્રકાર પણ આવે છે. અહીં ત્રણ જોડી સાચી હોય છે, એક ખોટી.
  • અંગ્રેજી મધ્યસ્થી ધરાવતા વિદ્યાર્થીઓએ ગુજરાતી શબ્દોના અર્થ સમજીને જ જોડીઓ બનાવવી, કારણ કે સીધો અનુવાદ ત્રુટિ પેદા કરી શકે છે.
  • પરિક્ષામાં સમય મર્યાદા ઓછી હોવાથી ઝડપી વાંચન અને યાદગાર જોડીઓ (ઉષા-રાત્રિ, સૂર્ય-ચંદ્ર) વડે જવાબ આપવો.

Common traps

  • ત્રુટિ ૧: 'સુંદર' અને 'સુન્દર' બંને એક જ શબ્દ છે — આ બંને સમોર્થી નથી પણ એક જ શબ્દના વિકલ્પી રૂપ છે.
  • ત્રુટિ ૨: 'મોટું' અને 'ચھોટું' સાપેક્ષ વિરુદ્ધ છે — 'મોટું' નો વિરુદ્ધ ફક્ત 'ચھોટું' જ નથી, 'નીચા', 'સામાન્ય' પણ થઈ શકે.
  • ત્રુટિ ૩: 'શ્વેત' અને 'શ્વેત' (બિલકુલ સફેદ) તથા 'શ્વેત' (શ્વેત = સફેદ રંગ) — સંદર્ભ મુજબ અર્થ બદલાય છે.
  • ત્રુટિ ૪: 'આકાશ' અને 'અગ્નિ' વિરુદ્ધાર્થી નથી — આ બંને પ્રકૃતિના તત્વો છે પણ એકબીજા વિરુદ્ધ નથી.
  • ત્રુટિ ૫: 'મૈત્રી' અને 'શત્રુતા' વિરુદ્ધાર્થી છે પણ 'મૈત્રી' અને 'દુશ્મની' પણ સમોર્થી છે — આવી બહુવિધતા ધ્યાનથી વાંચવી.
