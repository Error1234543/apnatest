Definitions

  • શબ્દભંડોળ એટલે ચોક્કસ ભાષામાં વપરાતા મૂળભૂત શબ્દો, તેમના અર્થ, સમાનાર્થી, વિરોધી અને એક-શબ્દ પ્રતિસ્થાપનોનો સંગ્રહ. ગુજરાતી પરીક્ષાઓમાં શબ્દભંડોળ પર્યાયશબ્દો, વિરોધાભાસી શબ્દો, સમાસોના ભેદ, કઠોર-કરોડી ભિન્નતાઓ, સાદા અને વ્યાવહારિક ઉપયોગનો સમાવેશ થાય છે.
  • સમાનાર્થી શબ્દો: અર્થમાં સમાન અથવા લગભગ સમાન અર્થ ધરાવતા વિવિધ શબ્દો. ઉદા. — આકાશ = ગગન = નભ = દિવ્ય = વિમાન.
  • વિરોધી (વિપરીત) શબ્દો: એકબીજાના વિરુદ્ધ અર્થ ધરાવતા શબ્દો. ઉદા. — ઊગવું : મુક્કવું; પ્રકાશ : અંધારું; સુખ : દુઃખ.
  • એક-શબ્દ પ્રતિસ્થાપન: એક શબ્દમાં એકથી વધુ શબ્દોનો અર્થ વ્યક્ત કરે તેવા શબ્દો. ઉદા. — ભૂગોળ = પૃથ્વીનું વર્ણન કરતું વિષય; અંધશ્રદ્ધા = બિનકારણ വിശ્વાસ.
  • અલંકાર: ભાષાની શોભા વધારતી રચનાઓ — ઉત્પ્રેક્ષા, રૂપક, ઉપમા, અતિશયોક્તિ, વ્યંજના, સમાસ, મેક, સ્ફોટક, તુકાબ, ઉલ્લેખ, દ્વિતિ, હાસ્યરસ, કારુણ્યરસ વગેરે.
  • વિભક્તિ અને વિશેષણ: ગુજરાતીમાં સામાન્ય રીતે ૬ વિભક્તિઓ (પ્રથમા-ષષ્ઠી) અને વ્યાકરણાત્મક વિશેષણો (ગુણવિશેષણ, માત્રા વિશેષણ, સંખ્યા વિશેષણ, પ્રશ્ન વિશેષણ)નો સમાવેશ થાય છે.

Key concepts

  • • સમાનાર્થી શબ્દોના મુખ્ય ભાગ:
    - યથાર્થ સમાનાર્થી: સંપૂર્ણ સમાન અર્થ (દા.ત. — મન = ચિત્ત)
    - અર્ધસમાનાર્થી: નજીકનો અર્થ (દા.ત. — કોમલ = મૃદુ, મંદ)
    - સંદર્ભસિદ્ધ સમાનાર્થી: સંદર્ભ પર આધારિત (દા.ત. — જળ = પાણી, ઝંઝાવાતમાં 'જળ' = વરસાદનો પડો)

    • વિરોધી શબ્દોના પ્રકાર:
    - પ્રત્યયજ વિરોધ: -તું/-તું પ્રત્યયથી બનતા (સુંદર : અસુંદર)
    - ધાતુજ વિરોધ: સંપૂર્ણપણે અલગ ધાતુ (પ્રકાશ : અંધારું)
    - સંસ્કૃતજ વિરોધ: સંસ્કૃત ધાતુથી (ઉત્તમ : અધમ)

    • એક-શબ્દ પ્રતિસ્થાપન (પર્યાય શબ્દ):
    - વ્યક્તિ સંબંધી: વૃદ્ધાંગ = વૃદ્ધ વ્યક્તિ, નવીન = નવો vyakti
    - ભૂગોળ સંબંધી: વૈજ્ઞાનિક = વિજ્ઞાનનો અભ્યાસ કરનાર, ઐહિક = ભૌતિક જગતનો
    - કૃતિ સંબંધી: કવિ = કાવ્ય રચનારો, નટ = રંગભૂમિ પર નાટક કરનાર
    - ગુણ સંબંધી: મહાન = મોટો ગુણવાન, ગંભીર = ગંભીર સ્વભાવવાળો

    • સામાન્ય ઉપયોગમાં આવતા મહત્વના શબ્દો અને તેમના સમાનાર્થી/વિરોધી:
    - યશ = કીર્તિ, ખ્યાતિ, છાયા | વિરોધ = અપયશ, અખ્યાતિ
    - દુઃખ = શોક, વેદના, તાપ | વિરોધ = સુખ, ખૈહું, પ્રિય
    - બલિદાન = ત્યાગ, અર્પણ, ઉત્સર્ગ | વિરોધ = લાભ, સુખ
    - મિત્ર = સાથી, હમનિષ્ઠ, જનમિત્ર | વિરોધ = શત્રુ, દ્વેષી
    - સૂર્ય = દિવાકર, તપન, ભાસ્કર, અરુણ | વિરોધ = ચંદ્ર
    - ચંદ્ર = શશી, કેતુ, નાગ, અમૃતબિંબ | વિરોધ = સૂર્ય
    - શિવ = ગિરીશ, મહાદેવ, ભોલેનાથ, હર | વિરોધ = જગનાથ નહીં; પરંતુ શિવ-પાર्वતી જોડી

    • વ્યાકરણ સંબંધી મુખ્ય શબ્દભંડોળ:
    - સંધિ: વિસ્તૃત સંધિના નામ — અણુ સંધિ, દીર્ઘ સંધિ, ગુણ સંધિ, અચગુણ સંધિ, જરા સંધિ, યગણ સંધિ, વિકાર સંધિ, સમાસ સંધિ.
    - સંધિ વિચ્છેદ: જટિલ શબ્દોનું વિભાજન (દા.ત. — ભવ્ય = ભ + વ્ય)
    - સમાસ: ઇન્દ્રવિભાવસના ભેદો — દ્વંદ્વ, તત્પુરુષ, ಕર્મધારય, બહુવ્રીહિ, અવ્યयीભાવ, દ્વિગુ.
    - સંદેહાત્મક શબ્દો: સામાન્ય રીતે ભ્રમજનક લાગતા શબ્દો જેમ કે — કાર્ય / કાર્ય, વિશેષ / વિશેષ, સુધી / સુધી, ભાષા / ભાષા.

    • ભાષાશુદ્ધિ અને ઉચ્ચાર સંબંધી મુખ્ય મુદ્દાઓ:
    - વિકૃત શબ્દો: સ્થિર = સ્થિર, શાંત = શાંત, સ્નેહ = સ્નેહ, શરણ = શરણ.
    - અધિકારીકરણ: ગુજરાતીમાં આંશિક રૂપે પ્રાચીન અને નવીન સ્વરૂપો વચ્ચે ઝંઝાળ ચાલુ છે.

    • ભૂત, વર્તમાન, ભવિષ્ય કાલના પ્રતિયોગી અર્થ:
    - ભૂતકાળ: -તો/-ઈ/-યા પ્રત્યયો (આયો, ગઈ, જતાં)
    - વર્તમાનકાળ: -તો/-ઈ/-તાં પ્રત્યયો
    - ભવિષ્યકાળ: -શે/-શેના પ્રત્યયો (આવશે, જશે)
