1. શબ્દ-અર્થ અને શબ્દોના વર્ગીકરણ

ગુજરાતી ભાષામાં શબ્દો મુખ્યત્વે બે પ્રકારના હોય છે: તત્સમ અને તદ્ભવ. તત્સમ શબ્દો એવા છે જે સંસ્કૃતથી પ્રાપ્ત થયા હોય અને મૂળ સ્વરૂપમાં રહ્યા હોય, જ્યારે તદ્ભવ શબ્દો સંસ્કૃતના ફેરફાર પછીના સ્વરૂપો છે. ઉદા. તત્સમ: કુમાર, પ્રાપ્ત, વિદ્યા; તદ્ભવ: કાર, પાપ્યું, વીધ.

આગળ ચાર ભાષાઈ સ્તરે શબ્દોનો વર્ગીકરણ થાય છે:
• સ્થાનિક/દેશી શબ્દો: ગામ, ધરતી, ખેતર — આ શબ્દો આદિદેશી હોય છે અને ગુજરાતીની શુદ્ધ પરંપરા સાથે જોડાયેલા છે.
• ઉર્દૂ-પર્શી શબ્દો: ઈશ્ક, દુનિયા, હુન્નર, કેહેવા, સિવાય — આ શબ્દો મુખ્યત્વે મઘ્યયુગીન સાહિત્યમાં આવે છે.
• આંધ્ર/દ્રાવડીય શબ્દો: માથો, કાન, કપાળ, ચાલ, દેહ — સંસ્કૃત-સંબંધી ન હોવા છતાં આ શબ્દો ગુજરાતીમાં સ્થાપિત છે.
• અંગ્રેજી શબ્દો: બસ, ટ્રેન, ઓફિસ, સ્કૂલ — આધુનિક ગુજરાતીમાં સામાન્ય રીતે વપરાય છે.

2. સમાનાર્થી (પર્યાયવાચક શબ્દો)

સમાન અર્થ ધરાવતા શબ્દોને 'સમાનાર્થી' કે 'પર્યાયવાચક' કહીએ છીએ. પરિક્ષામાં દરેક વસ્તુ/વ્યક્તિના યોગ્ય પર્યાય શબ્દ જાણવા જરૂરી છે.

સૂર્ય/અહર્વડતના પર્યાય: આદિત્ય, ભાસ્કર, વિશ્વાલ, કિરણપ્રવર, દિવાકર, અરુણ, નમકી, દિવકર, ગૌરીપતિ, તપન, સૂર્ય, પ્રભાકર.
ચંદ્ર/શશિના પર્યાય: ચંદ્ર, શશિ, નંદન, શેષાશ્વી, પર્ણશાલ, બિંબુ, હેમાંગદીપ, સંભુ, ઝરણુ, શીતળકર.
અગ્નિના પર્યાય: અગ્નિ, જ્વાળા, પાવક, વહ્નિ, હવન, તેજોવર, અનલ, દહન, તૃણાશ, ભસ્મિયાંશ.
વાણી/ભાષાના પર્યાય: વાણી, ભાષા, વચન, તત્ત્વ, લેખા, વાણી, વિદર્બ, દ્વીભાષા, અભિરામ, વાર્તા.
મનુષ્ય/જગતના પર્યાય: માનવ, જગત, સત્તર, સ્થાવર, મહી, પૃથ્વી, ધરતી, ઋષભ, અંબરજ, નભ.
ગંગાનું પર્યાય: ગંગા, ભગીરથિ, નીલકંથ, પાપવાહિની, જહ્નવી, પંચગંગા, ત્રિગર્તા, ભગીરથિ.

ઉપરોક્ત પર્યાયોનો પરિક્ષામાં સીધો પ્રશ્ન આવે છે — 'ચંદ્રના કેટલાક પર્યાય શબ્દો કયા છે?' જેવા વિકલ્પોમાંથી યોગ્ય જોડી પસંદ કરાવવામાં આવે છે.

3. વિરુદ્ધાર્થી (વિપરીતાર્થી શબ્દો)

વિરુદ્ધ અર્થ ધરાવતા શબ્દોને 'વિરુદ્ધાર્થી' કહીએ છીએ. એક જ શબ્દના કેટલાક પ્રસિદ્ધ વિરુદ્ધાર્થી:

• જીવન / મૃત્યુ
• પ્રકાશ / અંધકાર
• સુખ / દુઃખ
• ઉત્તર / દક્ષિણ
• ઉત્તર / નિષ્ક્રિય (વિરુદ્ધ)
• વૃદ્ધ / યુવાન
• સ્થિર / ગતિશીલ
• શુભ / અશુભ
• સાચું / ખોટું
• પ્રકાશ / અંધકાર
• યુદ્ધ / શાંતિ
• હીંગ / મીઠું (એક સાહિત્યિક યોજના)

આગળ ઘણા બોધપ્રદ શ્લોકોના શબ્દોમાં વિરુદ્ધાર્થીના ઘણા જોડાણો આવે છે. પ્રશ્નના સ્વરૂપ મુજબ 'નીચેનામાંથી કયા શબ્દજોડાણ વિરુદ્ધાર્થી નથી?' તેવા પ્રકારના પ્રશ્નો પણ આવે છે.

ખાસ ધ્યાન રાખવા જેવી જોડી:
• ઉન્માદ / સ્મૃતિ
• સ્નેહ / ષ્ટિ
• માયા / વસ્તુ
• સુવર્ણ / કાંસ્ય નહીં; સુવર્ણ વિરુદ્ધ ઔરસ/નિકૃષ્ટ હોય.

4. લક્ષણવિહીન શબ્દો (એકવચનમાં વર્ણવવામાં આવે તેવા શબ્દો)

એક શબ્દથી વિસ્તૃત અર્થ દર્શાવતા શબ્દોને લક્ષણવિહીન કહીએ છીએ. પરિક્ષામાં ઘણી વાર 'ચંદ્રના એક શબ્દમાં અર્થ કયો?' કે 'આપનાર શબ્દ' જેવા પ્રશ્નો આવે છે.

ઉદાહરણો:
• ચંદ્રના એકવચન અર્થ: શશિ, નંદન, શીતળકર, પર્ણશાલ.
• સૂર્યના એકવચન અર્થ: આદિત્ય, વિશ્વાલ, ભાસ્કર, દિવકર.
• અગ્નિના એકવચન અર્થ: પાવક, જ્વાળા, વહ્નિ.
• ગંગાના એકવચન અર્થ: ભગીરથિ, જહ્નવી.
• વૃક્ષનો એકવચન અર્થ: તરુ, વટ, ઊર્ધ્વગ.
• પંક્તિના એકવચન અર્થ: કંથન, સર્પિલ.
• હિંદુ ધર્મનો એકવચન અર્થ: સનાતન, ધર્મશાસ્ત્ર, ગૌતમસૂત્ર.
• અધિકારીનું વાચક: અધિપતિ, સર્વેક્ષક, અધ્યક્ષ.
• અંગ્રેજી શબ્દોની ગુજરાતી કિંમત: Computer → કંપ્યુટર, Mobile → મોબાઈલ.

આ શબ્દોનો પ્રશ્નો 'નીચેનામાંથી કઈ જોડી સ્થિર/સ્થાયી નથી?' કે 'નીચેનામાંથી કયો શબ્દ લક્ષણવિહીન નથી?' કે 'અગ્નિ એટલે શું?' જેવા પ્રકારે આવે છે.

5. મુહાવરા અને એકવચન અર્થ

મુહાવરા એટલે કેટલાક શબ્દોનું સંયોજન જેનો સામાન્ય સીધો અર્થ ન હોય પણ અંદરનો અર્થ અલગ હોય.

પ્રસિદ્ધ મુહાવરા:
• આંખે જોયું = નજરે ચઢવું
• ઠમકા ઉડાવવા = ગર્વ કરવો / પોતાનું મર્યાદા દર્શાવવું
• કાન પકડવા = ધમકી આપવી
• હાથ જોડવા = વિનંતિ કરવી
• પગ મૂકવા = કોઈ ઠેકાણે પહોંચવું
• પાણી ચઢવું = ગુસ્સામાં આવવું
• ઘા ઊતરવો = આરોપી સાબિત થવું
• છાતી ફુલવી = આત્મગર્વ કરવો
• દાંત દીપવવા = મારવાનો ઉદ્દેશ્ય રાખવો
• ગળી દેવું = રાજી રાખવું / પાળવું
• હાવ ભાવ = રૂપ અને લક્ષણ
• બે પગથિયાં = બે રસ્તે / બે ચરણે
• ઠેકાણે મૂકવું = સ્થિર કરવું
• વાત સીધી કરવી = સત્ય કહેવું
• ઝાઝો ગર્વ = નષ્ટની શરૂઆત
• પાંચ નોટની પેટી = ગરીબીનો રસ્તો
• આકાશ ફાટવું = અત્યંત ચકિત થવું
• કાંટો મૂકવો = અંતરાય ઉભો કરવો
• વાતનાં વીણવા = વાત કરવી
• દીવો કરવો = અંધાપું દૂર કરવું
• માથું ધરણવું = સર્વગ્રાહી થવું / નિર્ણય લેવો

પ્રશ્નોમાં મુહાવરાનો અર્થ, મુહાવરા સાથેના શબ્દોની જોડી, અને મુહાવરાનો ઉપયોગ યોગ્ય છે કે નહીં તેવા પ્રકારના પ્રશ્નો આવે છે.

6. સમાસ

સમાસ એટલે બે કે તેથી વધુ શબ્દોનું સંયોજન થઈને એક જ શબ્દ બનવો.

કારક સમાસ (કર્તા + ક્రిયા): રામ + લક્ષ્મણ = રામલક્ષ્મણ (દ્વંદ), રાજા + વચન = રાજવચન (મધ્યપદલોપી), રાત્રિ + વસંત = રાત્રીવસંત (કર્મધારાય).

તત્પુરુષ સમાસ: આત્મા + અર્થ = આત્માર્થ (કર્તા તત્પુરુષ); નગર + પાલ = નગરપાલ (કર્મ તત્પુરુષ); અગ્નિ + પાણી = અગ્નિપાણી (અધિકરણ તત્પુરુષ).

બહુવ્રીહી સમાસ: જેના લોમડા હોય = લોમહંસ (બહુવ્રીહી). આ પ્રકારનો શબ્દ જ્યાં સમાસનું વાચ્ય ન હોય પણ અન્ય કોઈ વ્યક્તિ/વસ્તુ દર્શાવતો હોય.

અવ્યયીભાવ સમાસ: નિરંતર + પદ = અનંતપદ; અધીર + ઉત્સાહ = અધીરોત્સાહ.

દ્વંદ સમાસ: રાજા + પ્રજા = રાજપ્રજા; જળ + અગ્નિ = જળાગ્નિ.

મધ્યપદલોપી: સૂર્ય + ચંદ્રના પ્રકાશ = સૌરચંદ્ર; દેવ + મુનિ = દેવમુનિ.

પ્રશ્નોમાં સામાન્યતઃ સમાસની પ્રકાર પોચતા આવે છે: 'નીચેનામાંથી કયો સમાસ બહુવ્રીહી છે?', 'આ કયો સમાસ છે?'. યોગ્ય તર્ક સાથે જવાબ આપવો જરૂરી છે.

7. અલંકાર

અલંકાર એટલે ભાષાને શોભા યુક્ત બનાવતી શબ્દ/અર્થની વિશેષતા.

ઉપમેય-ઉપમા અલંકાર: ઉપમા + ઉપમેયના આધાર + ઉપમાન + સાધારણ ધર્મ હોય. ઉદા. 'તારા જેવા મુખરા' (ઉપમાન: તારા, ઉપમેય: મુખરા, સાધારણ ધર્મ: ચમકતું).

અન્યારોપ અલંકાર: કોઈ વસ્તુનું નામ લઈને અન્ય વસ્તુ દર્શાવવી. ઉદા. 'સંધ્યાએ નેત્રરંજક વાદળછાયું'.

રૂપક અલંકાર: ઉપમા સિવાયના આધાર વિના સીધો સંબંધ સ્થાપિત કરવો. ઉદા. 'તું જ મારું આકાશ'.

વ્યંજના અલંકાર: શબ્દના મુખ્ય અર્થ સિવાય અન્ય અર્થની સૂચના. ઉદા. 'પિયૂષની ધારા'.

અતિશયોક્તિ: વાસ્તવિકતાથી ઘણી ઉપર ઊંચકીને દર્શાવવી. ઉદા. 'આખો વીર્ય પીએ'.

વીર રસ અને હાસ્ય રસના અલંકાર પણ જોડાયેલા છે. પ્રશ્નમાં 'નીચેનામાંથી કયા અલંકારનો પ્રયોગ છે?' અથવા 'અલંકારનો પ્રકાર નક્કી કરો' જેવા પ્રશ્નો આવે છે.

8. વાચ્ય-અર્થ અને અર્થઘટન

ગુજરાતી ભાષામાં શબ્દના અનેક અર્થ થાય છે: મુખ્ય (વાચ્ય), લક્ષ્ય, અને વ્યંગ્ય.
• વાચ્ય અર્થ: શબ્દનો સીધો, સ્પષ્ટ અર્થ. ઉદા. 'ઘર' = રહેવાની જગ્યા.
• લક્ષ્ય અર્થ: વાચ્ય અર્થ સિવાયનો અર્થ, જે સંદર્ભથી સૂચાય. ઉદા. 'નદી' = જળનો પ્રવાહ; પણ કોઈ વ્યક્તિના મુખની ચમક માટે પણ વપરાય.
• વ્યંગ્ય અર્થ: સીધો અર્થ ન હોય પણ અંતર્ગત અર્થ સૂચિત થતો હોય. ઉદા. 'આ ગામમાં અગ્નિ લાગી ગઈ' = દુર્દિન આવ્યું.

અર્થઘટન પ્રશ્નોમાં સામાન્યતઃ કોઈ પંક્તિ/વાક્યમાં કયા પ્રકારનો અર્થ છે તે નક્કી કરવાનું હોય છે.

ઉપરાંત, શબ્દના બહુઅર્થિતા (polysemy) પણ જોવા મળે છે: 'કાંટો' = (1) છરી (2) દુઃખ (3) તીક્ષ્ણ વસ્તુ.

પ્રશ્નોમાં આ વર્ગીકરણના આધારે 'આ વાક્યમાં કયો અર્થ છે?' અથવા 'વ્યંગ્ય અર્થ ધરાવતો શબ્દ કયો?' જેવા પ્રશ્નો આવે છે.

9. વ્યંજના અને અનુપ્રાસ

વ્યંજના અલંકાર: શબ્દના પ્રચલિત અર્થ સિવાય બીજો અર્થ સૂચિત થતો હોય. ઉદા. 'તારા' = તારા ગ્રહ + ચંદ્રિકા જેવું ચમકતું મુખ.

અનુપ્રાસ: એક જ વર્ણનું નિરંતર પુનરાવર્તન. ઉદા. 'અરુણ ઝરણુ અર્ધચંદ્રે...' અહીં 'અ' વર્ણનો અનુપ્રાસ છે.

યમક: સમાન શબ્દોની વારંવાર રચના જેનો અર્થ અલગ હોય. ઉદા. 'ન વાણી વાણી ન શબ્દ વાણી' — અહીં 'વાણી' શબ્દનો વિવિધ અર્થ.

શ્લેષ: એક શબ્દ એકાધિક અર્થ ધરાવતો હોય. ઉદા. 'રાત જાગૃત થઇને હું તારી રાત જોઉં છું' — અહીં 'રાત' એક સાથે સમય અને ઘટના બંને દર્શાવે છે.

પ્રશ્નોમાં ઘણીવાર 'નીચેનામાંથી કયું ઉદાહરણ અનુપ્રાસ છે?', 'શ્લેષ શોધો' કે 'યમક કયું છે?' એવા પ્રશ્નો આવે છે.

10. વ્યાકરણ-આધારિત પ્રશ્નો અને સામાન્ય શબ્દકોશ

ગુજરાતી વ્યાકરણના મહત્વના પ્રશ્નોના સ્વરૂપ:
• સાચો વિકલ્પ શોધવાનો: 'નીચેનામાંથી કયો શબ્દ સંદર્ભમાં યોગ્ય છે?'
• શબ્દ-અર્થની જોડી: 'અંગ્રેજી શબ્દ — ગુજરાતી અર્થ' જોડીને સાચો ઉત્તર પસંદ કરવાનો.
• વિરોધાભાસી શબ્દો: 'નીચેનામાંથી વિરુદ્ધાર્થી ન હોય તેવા શબ્દની જોડી ઓળખો.'
• શબ્દ સંબંધ: 'A : B :: C : ?' પ્રકારના પ્રશ્નો.
• અક્ષર-વર્ણનું સ્થાન: શબ્દમાં કેટલા સ્થાનિક વર્ણ/સ્વર છે તેના પ્રશ્નો પણ આવે છે.

માહિતીપ્રદ શબ્દકોશ સૂચિ:
• ઋતુઓ: શિયાળું, વસંત, વર્ષા, ગરમી — દરેક ઋતુના લક્ષણો.
• દિશાઓ: ઉત્તર, દક્ષિણ, પૂર્વ, પશ્ચિમ.
• પ્રકૃતિના અંગો: હૃદય, પ્તક, ચક્ષુ, નાસિકા, કર્ણ.
• વનસ્પતિ શબ્દ: ક્ષીર, તરુ, લતિકા, પક્ષી.
• જંતુ-પંખી શબ્દ: પક્ષી, ચકવ, કોકિલા, શારિકા.

આ વિભાગમાં શબ્દોની વારંવાર આવતી પરિક્ષામાં 'શબ્દોનો અર્થ મિલાવો', 'શબ્દ-જોડી ઓળખો', અને 'યોગ્ય વાક્ય પસંદ કરો' જેવા પ્રશ્નો આવે છે.

Important facts

  • તત્સમ શબ્દો સંસ્કૃતથી પ્રાપ્ત અને મૂળ સ્વરૂપ ધરાવે છે; તદ્ભવ શબ્દો સંસ્કૃતના પ્રાકૃત/અપભ્રંશ સ્વરૂપો છે.
  • સમાનાર્થી શબ્દોના પર્યાય ગણતરીથી યાદ રાખવા — ચંદ્રના 12+ પર્યાય, સૂર્યના 10+ પર્યાય.
  • વિરુદ્ધાર્થી શબ્દોની જોડી પ્રશ્નોમાં 'સાચી ન હોય તેવી જોડી' આકારે આવે છે.
  • લક્ષણવિહીન શબ્દો એક શબ્દમાં અધિક અર્થ પ્રદાન કરે છે — ચંદ્ર=શશિ, સૂર્ય=આદિત્ય.
  • મુહાવરાનો અર્થ યાદ કરવો જરૂરી છે; મુહાવરા સાથે શબ્દની સમાનતા પ્રશ્નો આવે છે.
  • સમાસના 6 મુખ્ય પ્રકાર: દ્વંદ, તત્પુરુષ, બહુવ્રીહી, અવ્યયીભાવ, કર્મધારાય, મધ્યપદલોપી.
  • અલંકારના પ્રકાર: ઉપમા, અન્યારોપ, રૂપક, વ્યંજના, અતિશયોક્તિ.
  • વાચ્ય-લક્ષ્ય-વ્યંગ્ય અર્થમાં તફાવત સ્પષ્ટ હોવો જોઈએ.
  • અનુપ્રાસ = સમાન વર્ણનું પુનરાવર્તન; શ્લેષ = એક શબ્દ એકાધિક અર્થ; યમક = સમાન શબ્દો સ્થાન બદલાય.
