૧. સંધિ — પરિચય, પ્રકાર અને સંધિ વિગ્રહ

ગુજરાતી વ્યાકરણમાં 'સંધિ' એ બે અથવા વધુ અક્ષરો/અવાજોના સંયોગથી સર્જાતો ફેરફાર છે. જ્યારે બે શબ્દો એકબીજા સાથે જોડાય છે ત્યારે તેમની આખરી અને શરૂઆતની ધ્વનિઓ વચ્ચે જે સંસ્કાર/ફેરફાર થાય છે તેને સંધિ કહે છે.

સંધિના બે મુખ્ય પ્રકાર:
• સંધિ વિગ્રહ (વિઘટન): સંધિબદ્ધ શબ્દને મૂળભૂત રૂપમાં વિભાજિત કરવો. ઉદા. 'વનસ્પતિ' = વન + સ્પતિ નહીં, પણ 'વન + અ + સ્પતિ' → 'વન' + 'અસ્પતિ'.
• સંધિ ભંગ (ઉત્પાદન): મૂળ શબ્દોના સંયોગથી નવો સંધિબદ્ધ શબ્દ બનાવવો.

ગુજરાતી સંધિના ઐતિહાસિક મૂળ આખર અને આગળના અક્ષરોના સ્પર્શ/સંયોગ પર આધારિત છે. પરીક્ષામાં સંધિ વિગ્રહ ખૂબ આવે છે — સંધિબદ્ધ શબ્દ આપી તેને કાઢી મૂળ શબ્દ શોધવા. ઉદા. 'કૃપાળુ' → 'કૃપા + આળુ', 'સંધિ' → 'સં + ધિ'.

વ્યાકરણના કાળમાં સંધિ ચાર પ્રકારની ગણાય: સ્વર સંધિ, વ્યંજન સંધિ, યાણ સંધિ અને અવ્યય સંધિ.

૨. સ્વર સંધિ

જ્યારે સંધિ થતી વેળાએ આખરે સ્વર હોય અને આગળ પણ સ્વર હોય ત્યારે સ્વર સંધિ થાય છે.

સ્વર સંધિના નિયમ:
• અ અથવા આ પછી ઇ/ઈ આવીને એ બને: ન + ઇતર = નેતર (ઉદા: ગુજરાતીમાં 'ગુજરાત + ਇੱ' → 'ગુજરાਤੇ')
• અ અથવા આ પછી ઉ/ઊ આવે ત્યારે ઓ બને: સુ + ઉત્તમ = સુઓત્તમ
• અ અથવા આ પછી ઋ આવે ત્યારે અર્થાત્ ર્ + સ્વર બને: સુ + ર્ગુણ = સુર્ગુણ
• એ/ઐ પછી ઇ/ઈ આવે તો ऐ बने (દિવ + ઈવસ = દિવેવસ)
• ઓ/ઔ પછી ઉ/ઊ આવે તો औ बने
• આ સિવાય ઉદાહરણો: અ + અ = ા (રામ + અર્પણ = રામાર્પણ), અ + ઈ = એ (પુ + ઈત = પુite), અ + ઊ = او (સુ + ઊત્તમ = સુઉત્તમ નહીં, પણ 'સુ + ઊત્તમ' = 'સુઉત્તમ' એ પુસ્તકીય રૂપ છે; વ્યવહારુ 'સુઉત્તમ' નહીં)

સંક્ષિપ્ત સાર:
• અ/આ + ઇ/ઈ = એ
• અ/આ + ઉ/ઊ = ઓ
• અ/આ + ઋ = અર્
• એ/ઐ + ઇ/ઈ = ઐ
• ઓ/ઔ + ઉ/ઊ = ઔ

આ નિયમોની યાદદાસ્ત માટે પરીક્ષામાં 'શબ્દકોશ-આધારિત પ્રશ્નો' આવે છે.

૩. વ્યંજન સંધિ અને યાણ સંધિ

વ્યંજન સંધિ:
જ્યારે આખરે વ્યંજન હોય અને આગળ પણ વ્યંજન હોય ત્યારે વ્યંજન સંધિ થાય છે. આ સંધિમાં મૂળ વ્યંજનોમાં નાનો ફેરફાર થાય છે અથવા તેમનો સંયોગ થાય છે.

ઉદાહરણો:
• ગ + ચ = ગ્ચ (અનુગ + ચાર = અનુગ્ચાર — સામાન્ય રૂપ 'અનુચાર' ને બદલે 'અનુગ્ચાર' એ યોગ્ય ગણાય)
• જ + ત = જ્ત (મહા + ત્વીર = મહાત્વીર)
• ભ + દ = ભ્દ (સહ + દેહ = સહ્દેહ)

સામાન્ય રીતે ગુજરાતીમાં વ્યંજન સંધિ ઓછી સક્રિય છે, પરંતુ ઉચ્ચ ગુજરાતી અને સંસ્કૃતમૂળક શબ્દોમાં ઘણી વાર આવે છે.

યાણ સંધિ:
આખરે વ્યંજન હોય અને આગળ સ્વર હોય ત્યારે 'યાણ' (y/a/i/u/ṛ) નો ઉપયોગ થાય છે.
• જો આખરે 'ન' હોય અને આગળ સ્વર હોય, તો 'ના' ઉમેરવામાં આવે છે: દાન + આરાધના = દાનારાધના
• જો આખરે 'મ' હોય, તો 'મા': સર્વ + અંગ = સર્વાંગ નહીં, પણ 'સર્વાંગ' = સર્વ + અંગ (અહીં યાણ નથી)
• સામાન્ય નિયમ: આખરનું વ્યંજન અને આગળનો સ્વર યોગ્ય રીતે મળે તે માટે વચ્ચે 'ઇ/ઈ/ઉ/ઊ' જેવો મધ્યસ્થ વ્યંજન-સ્વરનો ઉપયોગ થાય છે. ઉદા. અનુ + ઉત્તમ = અનુઉત્તમ નહીં, પણ 'અનુ + ઊત્તમ' = 'અનુઉત્તમ' એ પુસ્તકીય રૂપ છે.

યાણ સંધિનો મુખ્ય મંતવ્ય શબ્દો વચ્ચેનો સ્પર્શ સરળ બનાવવાનો છે.

૪. અવ્યય અને તેના પ્રકાર

અવ્યય એ શબ્દભેદ છે જેનાં લક્ષણો:
• તેનું કોઈ નિશ્ચિત અર્થ નથી હોતો
• તે સ્ત્રી/પુરુષ, વચન, કારકથી બદલાતું નથી
• તે પોતે સાર્થક શબ્દ નથી હોતો, પણ અન્ય શબ્દોની વાતને પૂર્ણ/સંદર્ભિત કરે છે

અવ્યયના પ્રકાર:
૧. જોરવાચક અવ્યય — અનંત, આમ, ઓહો, અરે, વગેરે
૨. પ્રશ્નવાચક અવ્યય — કોઈ, શું, કેમ, ક્યારે, કેવું, કયાં, કેવી
૩. સંદેહવાચક અવ્યય — હો, કે, કશું, કદાચ, શું, નહીં, ખરું
૪. સમાસવાચક અવ્યય — પણ, પરંતુ, તેથી, આથી, તેમ, અને, અથવા, પણ, તો, છતાં, ફરીથી
૫. વિધિવાચક અવ્યય — હવે, ત્યારે, અત્રે, અત્યંત, અગાઉ, પછી, ત્યારબાદ, સદાય

અવ્યયની પરીક્ષાકીય મહત્વ:
• પ્રશ્નવાચક અવ્યયમાં 'કેમ' (કારણ), 'ક્યારે' (સમય), 'કેવું' (ગુણ), 'ક્યાં' (સ્થળ) — એકબીજાથી અલગ જોઈએ.
• વિધિવાચક અવ્યય સાથે 'હવે', 'ત્યારે' નો ભ્રમ ટાળવો.
• અવ્યયના પ્રકાર યાદ રાખવા — આ પ્રશ્નો સીધા જ આવે છે.

૫. સ્ત્રી-પુરુષ લિંગ (Gender)

ગુજરાતીમાં લિંગ પ્રધાનતઃ બે પ્રકારનું છે — સ્ત્રીલિંગ અને પુરુષલિંગ. કોઈક સ્થળે નપુંસકલિંગ પણ જોવા મળે છે.

સ્ત્રીલિંગના લક્ષણો:
• મૂળ શબ્દની આખરે 'ા' (અચ્) હોય તો તે સામાન્ય રીતે સ્ત્રીલિંગ: દુધ (નપુ.), પણ 'લીલા' (સ્ત્રી), 'સંજના' (સ્ત્રી)
• 'ઈ/ી', 'એ', 'ઊ', 'ઑ' આખરે હોય ત્યારે પણ સ્ત્રીલિંગ:
• વિશેષણો: સુંદર (પુ.) → સુંદરી (સ્ત્રી), મોટો (પુ.) → મોટી (સ્ત્રી), નાનો (પુ.) → નાની (સ્ત્રી)

પુરુષલિંગના લક્ષણો:
• મૂળ શબ્દની આખરે 'ો' હોય ત્યારે તે પુરુષલિંગ: રામ, કુંવર, છોકરો
• 'અ' આખરે હોય તે પણ પુરુષલિંગ: રાક્ષસ (પુ.)

વિશેષ યાદ રાખવા જેવું:
• કેટલાક શબ્દો રૂપથી સ્ત્રી લાગે પણ પુરુષ હોય: 'ચાચો' (પુરુષ), 'અક્કલ' (સ્ત્રી, પણ 'અક્કલમંદ' = પુરુષ લિંગ)
• 'છોકરી' — સ્ત્રીલિંગ, 'છોકરો' — પુરુષલિંગ
• 'મનુષ્ય' (પુરુષ), 'નારી' (સ્ત્રી), 'સ્ત્રી' (સ્ત્રી)
• નપુંસકલિંગ શબ્દો: 'ફળ' (નપુ.), 'પાણી' (નપુ.), 'ગામ' (નપુ.)

વિશેષણ-શબ્દ સંબંધ:
• પુરુષ: સુંદર + છોકરો = સુંદર છોકરો / સુંદરો છોકરો
• સ્ત્રી: સુંદર + છોકરી = સુંદર છોકરી / સુંદરી છોકરી (અહીં વિશેષણ 'સુંદર' ફેરવાય છે)

લિંગ બદલવાની પરીક્ષાકીય રીતો:
• પુરુષ → સ્ત્રી: છેલ્લો 'ો' કાઢીને 'ી' મૂકવી (રામો → રામી નહીં; સામાન્ય રીતે 'ઓ' → 'ી')
• કેટલાક શબ્દો પર અલગ પ્રત્યય લાગે છે: પિતા → માતા

૬. એકવચન અને બહુવચન (Number)

ગુજરાતીમાં વચન બે પ્રકારનું છે: એકવચન અને બહુવચન.

એકવચન:
• એક જ વ્યક્તિ/વસ્તુ/પ્રાણી માટે: રામ, છોકરો, ગાય, કૂતરો
• પુરુષલિંગમાં 'ો' આખરે હોય છે: રામો, કુંવરો, બાળકો
• સ્ત્રીલિંગમાં 'ી/આ' આખરે હોય છે: રામી, ગાયી, છોકરી, દીકરી

બહુવચન:
• એકથી વધુ વ્યક્તિ/વસ્તુ/પ્રાણી માટે:
• પુરુષલિંગ બહુવચન: 'ઓ' આખરે હોય છે — રામો → રામા (વધુ કિસ્સામાં 'ઓ' જ રહે છે, પરંતુ 'લાકો', 'છોકરાઓ' એ બહુવચન)
• વાસ્તવિક બહુવચન પ્રત્યય: 'ઓ' પછી 'ઓ' એ 'ઓઓ' બને છે (છોકરાઓ) કેટલાક કિસ્સામાં 'આઓ'
• સ્ત્રીલિંગ બહુવચન: 'ી' પછી 'ઓ' → 'ઓ' એ 'ઓઓ' બને છે: છોકરી → છોકરીઓ, ગાયી → ગાયીઓ

બહુવચનના માત્રાબદ્ધ રૂપ:
• 'લાકો' (લાક + ઓ)
• 'છોકરાઓ' (છોકરા + ઓ)
• 'ગાયીઓ' (ગાયી + ઓ)
• 'પક્ષીઓ' (પક્ષી + ઓ)
• 'રૂપાઓ' (રૂપા + ઓ) — આ બધા બહુવચન સૂચક છે

પરીક્ષામાં ધ્યાન રાખવું:
• 'છોકરા' એ એકવચન, 'છોકરાઓ' એ બહુવચન
• 'લાક' એ એકવચન, 'લાકો' એ બહુવચન
• કેટલાક શબ્દો એકવચન-બહુવચનમાં સમાન રહે છે: 'પાણી' એકવચન/બહુવચન બંને

૭. કારક (Cases) — ષષ્ઠી, સપ્તમી, તૃતીયા, ચતુર્થી, પંચમી

ગુજરાતીમાં કારકો એ શબ્દોની વચ્ચેના સંબંધો દર્શાવે છે. આ કારકો આકારે અને પ્રત્યયથી ઓળખાય છે.

૧. કર્તૃ કારક:
• પ્રશ્ન: કોણ? શું?
• પ્રત્યય: -એ (ઘણા કિસ્સામાં પ્રકટ રૂપ)
• ઉદા.: રામ-એ ફળ ખાધું. (અહીં 'રામે' = કર્તા)

૨. કર્મ કારક:
• પ્રશ્ન: કી? શું?
• પ્રત્યય: -ને
• ઉદા.: રામે ફળને ખાધું.

૩. સાધન કારક:
• પ્રશ્ન: કેવાથી? કેટલાથી?
• પ્રત્યય: -થી
• ઉદા.: હરીએ છરીથી શાક કાપ્યું.

૪. અધિકરણ કારક:
• પ્રશ્ન: ક્યાં? ક્યારે?
• પ્રત્યય: -મા, -માં, -ને, -ઉપર, -પર
• ઉદા.: પુસ્તક મેઝ ઉપર છે. / બાળક રૂમમાં રમતું હતું.

૫. સંબંધ કારક (ષષ્ઠી):
• પ્રશ્ન: કા? કો? શું?
• પ્રત્યય: -નું, -ની, -નો
• ઉદા.: રામનો પુસ્તક. / ગામના લોકો.

૬. પંચમી કારક:
• પ્રશ્ન: કો? કેટલું? / ક્યાંથી?
• પ્રત્યય: -થી, -ની, -ના
• ઉદા.: મેં રાહથી ચાલ્યો. / પુસ્તકમાંથી માહિતી મળી.

કારક ચિહ્નો યાદ રાખવા:
• -એ → કર્તૃ
• -ને → કર્મ
• -થી → સાધન/પંચમી
• -માં/ઉપર/પર → અધિકરણ
• -નું/ની/નો → સંબંધ

પરીક્ષામાં કારક ઓળખવા પ્રશ્નો:
'રામે પુસ્તક ખાલી કાગળ પર મૂક્યું.' — 'રામે' (કર્તૃ), 'પુસ્તક' (કર્મ), 'કાગળ પર' (અધિકરણ)

૮. સમાસ (Compound Words)

સમાસ એ બે કે વધુ શબ્દોનું એક શબ્દમાં સંયોજન છે. ગુજરાતી સમાસ આઠ પ્રકારના છે, આ મુજબ:

૧. દ્વંદ સમાસ:
• બે સમાન અર્થ/સંબંધ ધરાવતા શબ્દોનો સંયોગ
• ઉદા.: 'રામા-કૃષ્ણ', 'મા-બાપ', 'દુઃખ-સુખ', 'લોક-લક્ષણ', 'હાથ-પગ'
• અહીં સંયોજક અર્થ (અને/અથવા) સ્પષ્ટ રહે છે.

૨. તત્પુરુષ સમાસ:
• પ્રથમ પદ દ્વિતીયાદિ કારક સમ્બંધ ધરાવે છે
• ઉદા.: 'ગંગાજલ' (ગંગાનું જલ), 'નગરપાલિકા' (નગરની પાલિકા), 'રાજપુત્ર' (રાજાનો પુત્ર), 'વિદ્યાલય' (વિદ્યાનું આલય)

૩. બહુવ્રીહિ સમાસ:
• યોગ્યપદ ન બની બીજા શબ્દનો વિશેષણ બને છે
• ઉદા.: 'લાલવાટ' (જેની વાટ લાલ હોય), 'મોટા હાથી' નહીં, પણ 'મોટાહાથી' એ અલગ સમાસ છે

૪. અવ્યયીભાવ સમાસ:
• પ્રથમ પદ અવ્યયનો અર્થ ધરાવે છે
• ઉદા.: 'અગમ્ય' (અ + ગમ્ય = જે ગમતું નથી), 'સમક્ષ' (સ + અક્ષ), 'અન્ને' (અ + અન્ને)

૫. કર્મધારય સમાસ:
• પૂર્વપદ વિશેષણ અને પશ્ચાત્પદ વિશેષ્ય
• ઉદા.: 'કાળો પથારી' → 'કાળોપથારી', 'મોટો ઘર' → 'મોટોઘર' (વિશેષણ-વિશેષ્ય સંબંધ)

૬. દ્વિગુ સમાસ:
• સંખ્યાબંધ શબ્દોનો સમાસ
• ઉદા.: 'ત્રિફળ' (ત્રણ ફળ), 'પંચપાંડવ', 'દ્વિભાષી'

૭. તત્પુરુષના ઉપભેદ:
• પ્રકરણ તત્પુરુષ: ગંગાજલ
• કેવત્થ તત્પુરુષ: દૂધપાણી

૮. કર્મધારયના ઉપભેદ:
• કર્મધારય સમાસ: નીલો વાદળ

પરીક્ષામાં સમાસ ઓળખવા માટે:
• પદો વચ્ચેનું વિરામ/અંતર જોવું
• પ્રશ્નો પૂછવા: 'કા?' (સંબંધ), 'કેવું?' (વિશેષણ)
• દ્વંદ: 'અને' સંકેત
• તત્પુરુષ: માલક-માલિક સંબંધ

૯. ક્રિયાપદ, ક્રિયાવિશેષણ અને યોગ્ય પ્રત્યય

ક્રિયાપદ:
ક્રિયાપદ એ શબ્દભેદ છે જે કોઈ ક્રિયા, હાલત અથવા ભાવ દર્શાવે છે. ગુજરાતી ક્રિયાપદનું સંયોજન:
• આધાર (ક્રિયાપદ મૂળ): જા, આવ, કર, હો, આ
• પશ્ચાત્ પ્રત્યય: -તો, -તા, -ઈ, -શે, -યો, -ઈ

ક્રિયાપદના સ્વરૂપો:
• વર્તમાન: હું જાઉં છું / તે જાય છે
• ભૂતકાળ: તે ગયો / તે ગઈ
• ભવિષ્યકાળ: તે જશે / તે જવાની છે

ક્રિયાવિશેષણ:
ક્રિયાપદને સંબંધિત વિગતો આપે છે — કેવી રીતે, ક્યારે, ક્યાં, કેટલી વાર, કેમ?
ઉદા.: 'જલદી જવું', 'અહીં આવીશ', 'આજે જશું', 'વારંવાર પૂછવું'

વિશેષણ પ્રકારો:
૧. વિશેષણ (Adjective) — નામ/ક્રિયાપદને વર્ણવે છે: 'મોટું ઘર', 'સુંદર છોકરી'
૨. ક્રિયાવિશેષણ (Adverb) — ક્રિયાપદને વર્ણવે છે: 'જલદી જવું', 'અહીં આવીશ'

યોગ્ય પ્રત્યય:
પ્રત્યયો એ શબ્દની આખરે લાગતા અવયવો છે જે અર્થ/ભૂમિકા બદલે છે:
• કારક પ્રત્યય: -એ, -ને, -થી, -માં, -નાં, -નો, -ની
• વિશેષણ પ્રત્યય: -ણું, -ણો, -ણી, -વાળો, -વાળી
• સમાસ પ્રત્યય: -ક, -કાર, -પાલ, -વાહ, -ગૃહ

પ્રત્યય-ઓળખના ઉદાહરણો:
• 'દર્શક' = દૃશ્ય + ક (જે જુએ છે)
• 'કર્તા' = કર + તા (જે કરે છે)
• 'ગ્રાહક' = ગ્ર + હ્ + ક (જે લે છે)
• 'પ્રવાસી' = પ્ર + વાસ + ઈ (જે પ્રવાસ કરે છે)

પ્રત્યયનો ઉપયોગ પરીક્ષામાં શબ્દ-બંધ બનાવવામાં થાય છે.

૧૦. વાક્ય અને તેના પ્રકાર

વાક્ય એ શબ્દોનો સમૂહ છે જે એક સંપૂર્ણ અર્થ આપે છે. ગુજરાતી વ્યાકરણમાં વાક્ય ચાર પ્રકારના છે:

૧. સરળ વાક્ય:
• એક સુત્ર (કર્તૃ-ક્રિયા) ધરાવતું વાક્ય
• ઉદા.: 'રામ આવે છે.' / 'પક્ષી ઊડે છે.' / 'બાળક રમે છે.'

૨. મિશ્ર વાક્ય:
• બે સરળ વાક્યોનું સંયોજન જોડણી શબ્દથી
• ઉદા.: 'રામ આવે છે અને ક્રિશ્ણ જાય છે.'
• જોડણી શબ્દો: અને, પણ, અથવા, પરંતુ, તેથી, જો...તો

૩. યોગ વાક્ય:
• એક સુત્ર મુખ્ય અને બીજું ઉપસુત્ર
• ઉપસુત્ર સામાન્ય રીતે 'જે', 'જેણે', 'જેમ' વગેરેથી શરૂ થાય છે
• ઉદા.: 'જે છોકરો રમે છે તે મારો ભાઈ છે.'

૪. સંયુક્ત વાક્ય (Complex):
• એક કામ કરતાં બીજું આવે તેવો અર્થ
• ઉદા.: 'જ્યારે રામ આવ્યો ત્યારે અમે ખુશ થયા.'

વાક્યના પરિચયકાંડ પ્રશ્નો:
• કર્તા શોધો — કોણ? શું?
• કર્મ શોધો — કી? શું?
• કારક શોધો — ક્યાં? ક્યારે? કેવેથી?
• વાક્યનો પ્રકાર નક્કી કરો

પરીક્ષા-ટૂંકા નિયમો:
• સરળ વાક્ય = ૧ સુત્ર
• મિશ્ર વાક્ય = ૨ સરળ વાક્યનો જોડાણ
• યોગ = 'જે/જેણે/જેમ' સાથે ઉપવાક્ય
• યોગ્ય/સંયુક્ત વાક્ય = 'જ્યારે/જો' સહિત

૧૧. પરીક્ષા-મહત્વના વ્યાકરણ નિયમો — સારાંશ

ગુજરાતી વ્યાકરણ પરીક્ષામાં નીચેના અધ્યયનો મુખ્યતાથી આવે છે:

૧. સંધિ વિગ્રહ — સૌથી વધુ આવે છે. આપેલ સંધિબદ્ધ શબ્દને વિભાજિત કરી મૂળ શબ્દ શોધવા.
• સ્વર સંધિ નિયમો યાદ રાખવા
• સામાન્ય ભૂલો: 'આ' + 'અ' = 'આ' નહીં, પણ 'આ' + 'અ' = 'આઅ' નહીં! (પ્રકટ રૂપમાં 'આ' + 'અ' = 'આઅ' નથી, પણ 'આ' + 'અ' = 'આ' એ યોગ્ય નથી; વાસ્તવમાં 'અ' + 'અ' = 'અ' અથવા 'આ' એ બંને બિંદુઓ પર ધ્યાન રાખવું)

૨. કારક ઓળખ — નક્કી કરો કે આપેલ શબ્દ કયા કારકમાં છે.
• -એ → કર્તૃ, -ને → કર્મ, -થી → સાધન/પંચમી, -માં/પર/ઉપર → અધિકરણ, -નું/ની/નો → સંબંધ

૩. સમાસ ઓળખ — સમાસના પ્રકાર જાણવા.
• દ્વંદ: 'અને' સંકેત, સમાન પદો
• તત્પુરુષ: માલક-માલિક, પ્રશ્ન 'કા?'
• કર્મધારય: વિશેષણ-વિશેષ્ય
• અવ્યયીભાવ: અવ્યયમૂળક પૂર્વપદ

૪. સ્ત્રી-પુરુષ લિંગ અને એકવચન-બહુવચન
• 'ઓ' આખરે = પુરુષ, 'ી/આ' = સ્ત્રી
• 'ઓઓ/આઓ' = બહુવચન

૫. અવ્યય પ્રકાર — જોરવાચક, પ્રશ્નવાચક, સંદેહવાચક, વિધિવાચક

૬. વાક્ય પ્રકાર — સરળ, મિશ્ર, યોગ

૭. પ્રત્યય ઓળખ — કારક પ્રત્યય, વિશેષણ પ્રત્યય

પરીક્ષા રણનીતિ:
• સંધિ વિગ્રહ પ્રશ્નમાં 'શબ્દકોશ' વાપરવાનો પ્રયત્ન કરો
• કારક પ્રશ્નમાં પ્રત્યય ઓળખો — તે સીધો જવાબ આપે છે
• સમાસમાં 'પ્રશ્નો' પૂછો: 'કા?' = સંબંધ, 'કેવું?' = વિશેષણ

Important facts

  • સંધિ એ બે/વધુ શબ્દોના સંયોગથી થતો ધ્વનિ-સ્વરૂપ ફેરફાર છે.
  • સ્વર સંધિમાં અ/આ+ઇ/ઈ=એ, અ/આ+ઉ/ઊ=ઓ, એ/ઐ+ઇ/ઈ=ઐ, ઓ/ઔ+ઉ/ઊ=ઔ.
  • કર્તૃ કારક → -એ, કર્મ કારક → -ને, સાધન/પંચમી → -થી, અધિકરણ → -માં/પર/ઉપર, સંબંધ → -નું/ની/નો.
  • અવ્યય ચાર પ્રકારના: જોરવાચક, પ્રશ્નવાચક, સંદેહવાચક, વિધિવાચક.
  • સમાસ આઠ પ્રકારના: દ્વંદ, તત્પુરુષ, બહુવ્રીહિ, અવ્યયીભાવ, કર્મધારય, દ્વિગુ અને તેમના ઉપભેદ.
  • વાક્ય ચાર પ્રકારના: સરળ, મિશ્ર, યોગ, સંયુક્ત.
  • લિંગ: 'ો' આખરે = પુરુષ, 'ી/આ' = સ્ત્રી; બહુવચનમાં 'ઓઓ/આઓ' પ્રત્યય.
  • પ્રત્યયો કારક, વિશેષણ, સમાસ વગેરે બનાવવા ઉપયોગી છે: -તો, -ઈ, -શે, -યા, -ક, -ણું, -વાળો.
  • સંધિ વિગ્રહ એ ગુજરાતી વ્યાકરણ પરીક્ષાનો સૌથી મહત્વનો વિભાગ છે.
