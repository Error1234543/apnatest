Definitions

  • વાતાવરણીય દૂષણ : વાતાવરણમાં અનિચ્છનીય પદાર્થોનું પ્રવેશ થવાને કારણે તેની ગુણવત્તામાં થતો થાપ, જે જીવજંતુઓ, માનવ આરોગ્ય અને પારિસ્થિક તંત્રને નુકસાન પહોંચાડે છે.
  • જળ દૂષણ : જલ સ્રોતોમાં (નાળા, નદી, તળાવ, ભૂગર્ભજળ, સાગર) રાસાયણિક અથવા જૈવિક પ્રદૂષકોના પ્રવેશથી જલની શુદ્ધતા બગડવી.
  • માટીનું દૂષણ : ખેતીમાં ખાતર-કીટનાશકોનો અતિ ઉપયોગ, ઉદ્યોગિક/ઘરેલૂ કચરો, ઇલેક્ટ્રોનિક કચરાના વિલયને કારણે માટીના ઉપયોગિતા અને સંતુલનમાં થતો તબડો.
  • શબ્દ દૂષણ : અનિચ્છનીય અથવા હાનિકારક ધ્વનિ સ્તર (વોટ્સ/ડેસિબલ) ને કારણે મનુષ્ય અને પ્રાણીઓના સ્વાસ્થ્ય પર પડતી અસર.
  • કાર્યાગ્રહણ અસર (Greenhouse Effect) : વાતાવરણમાં મોજુદ ગ્રીનહાઉસ વાયુઓ (CO₂, CH₄, N₂O, CFCs, H₂O વરાળ) દ્વારા પૃથ્વી પરથી નિકળતી ઉષ્મા的一部分ને પાછી પૃથ્વી તરફ વાળી મુકવી, જે કુદરતી રીતે પૃથ્વીને ગરમ રાખે છે.
  • વૈશ્વિક ઉષ્ણાયન (Global Warming) : માનવ પ્રવૃત્તિઓને કારણે ગ્રીનહાઉસ વાયુઓના વધેલા ઉત્સર્જનને કારણે પૃથ્વીની સરેરાશ ઉષ્ણતામાં થતો વધારો.
  • કાલ્હાંગિક પરિવર્તન (Climate Change) : દાયકાઓ કે શતકોની અવધિમાં તાપમાન, વરસાદ, પવન અને અન્ય હવામાન તત્વોમાં થતું ફેરફાર.
  • ઓજોન આવરણ : વાતાવરણના સ્ટ્રેટોસ્ફિયર (15–35 km) માં આવેલો ઓજોન (O₃) નો સ્તર, જે પૃથ્વીને પરોક્ષ કિરણો (UV-B) માંથી સંરક્ષણ આપે છે.
  • BOD (જૈવિક ઑક્સિજન માંગ) : પાણીનાં નમૂનાને એક ચોક્કસ તાપમાને (20°C) એક ચોક્કસ સમય (5 દિવસ) સુધી રાખતાં, તેમાં રહેલા ઓક્સિજન-ખાણ બેક્ટેરિયા દ્વારા વપરાતા ડિસોલ્વ્ડ ઑક્સિજનની માત્રા. BOD વધારે = વધારે જૈવિક પ્રદૂષણ.
  • COD (રાસાયણિક ઑક્સિજન માંગ) : પાણીના કાર્બનિક પ્રદૂષકોને રાસાયણિક રીતે ઑક્સિડાઇઝ કરવા માટે જરૂરી ઑક્સિજનની માત્રા. COD ≥ BOD.

Key concepts

  • વાતાવરણીય દૂષકોની પ્રક્રિયા:
    • પ્રાથમિક પ્રદૂષકો – સીધા ઉત્સર્જન થતા (SO₂, NOₓ, CO, PM, વાયુ પ્રવાહ)
    • દ્વિતીયક પ્રદૂષકો – વાતાવરણમાં પ્રતિક્રિયા કરીને બનતા (ઓઝોન, H₂SO₄, HNO₃ વરાળ, ફોટોકેમિકલ ધુમાડો)
    • SO₂ → વર્ષામાં H₂SO₄ બની અમ્લ વર્ષા;
    • NOₓ + VOC + પ્રકાશ → ફોટોકેમિકલ ઓઝોન (Ground-level O₃).
    • CO, Pb, PM2.5 / PM10 માનવ સ્વાસ્થ્ય પર સીધી અસર.

Important facts

  • ICAR / MOEFCC ની જાહેરાત મુજબ, ગુજરાતનું વન વિસ્તાર લગભગ 8% થી થોડું વધુ છે (વન સર્વેક્ષણ ભારત અહેવાલ).
  • વૈશ્વિક સરેરાશ તાપમાનમાં 1°C નો વધારો (ઇન્ડસ્ટ્રિયલાઇઝેશન પહેલાં સમયથી). આંતરરાષ્ટ્રીય લક્ષ્ય: 1.5°C થી નીચે રાખવાનું.
  • CO₂ નું વાયુ વાતાવરણમાં લગભગ ~420 ppm (2020ના દાયકામાં); CH₄ અને N₂O પણ વધી રહ્યાં છે.
  • ક્યોટો પ્રોટોકોલ (1997, અમલ 2005) – વિકસિત દેશો (Annex-I)ને ગ્રીનહાઉસ ઉત્સર્જન ઘટાડવાનું બંધન.
    • ક્યાપિટલ મિકેનિઝમ, CDM.
  • પેરિસ કરાર (2015, અમલ 2016) – 196 તરફેણકારોએ 1.5–2°C લક્ષ્ય સ્વીકારી; પ્રત્યેક દેશ NDC (Nationally Determined Contributions) સબમિટ કરે છે.
  • ઓજોન સંબંધિત ઐતિહાસિક તારીખો:
    • 1987 – મોન્ટ્રીઅલ પ્રોટોકોલ (CFCs/HCFCs ની હ્રાસ)
    • 1989 – અંતરરાષ્ટ્રીય ઓઝોન દિવસ (16 સપ્ટેમ્બર)
    • 1996 – ઉત્તર ધ્રુવ પાસે ઓઝોન છિદ્રનો ચાર્ટ.
  • આઈપીસીसी (IPCC) – જળવાયુ પરિવર્તન પર ફ્રેમવર્ક સમિતિ, 1988 માં સ્થાપના. IPCC AR6 (2021–2023) ના અહેવાલોમાં સ્પષ્ટ થયું કે માનવ પ્રવૃત્તિ 'સાફ-સાફ' કારણ છે.
  • સ્વચ્છ ભારત અભિયાન (2014) – શહેરી અને ગ્રામીણ કચરા પ્રબંધન.
    • આયુષ ગતિ (2018) – EV અને ઊર્જા કુષળતા.
    • પંચગંગા અભિયાન (2016) – ગંગા અને 4 સહાયક નદીઓ શુદ્ધિ.
  • ગુજરાતમાં વાયુ પ્રદૂષણ મુખ્યત્વે સેવરાજ, ધોધર, અને અમદાવાદ-રાજકોટ-ભાવનગર ઔદ્યોગિક વલયોમાં.
    • સૂક્ષ્મ કણો (PM2.5) અને SO₂/NOₓ પ્રબળ છે.
  • જળ પ્રદૂષણ માટે મુખ્ય સ્રોતો:
    • ઉદ્યોગિક અપવ્યય (કાગળ, રસાયણ, ટેક્સટાઇલ, પેટ્રોકેમિકલ)
    • ખેતીય ડ્રેનેજ (નાઈટ્રેટ, ફોસ્ફેટ, કીટનાશક)
    • શહેરી સેવેજ.

Memory aids

  • CDM, CDM, CDMM — સુદ્ધા ચિત્રો સાથે:
    C = Carbon, D = dioxide, M = Methane, D = Dioxide, C = Chlorofluorocarbon, M = ? Not applicable. Simplest:
    GHG = 4 મુખ્ય — CO₂, CH₄, N₂O, CFCs. 'CMNC' યાદ રાખો: C (CO₂), M (CH₄), N (N₂O), C (CFCs).
  • ઓઝોન સ્તર ક્યાં છે? — 'STRA-to-SHIELD': સ્ટ્રેટોસ્ફિયર = બચાવકારક આવરણ. ટ્રોપોસ્ફિયર = ઝેરી ઓઝોન (ground-level).
  • BOD > COD? ના, COD ≥ BOD. BOD = માત્ર જૈવિક; COD = બધું.
  • ગુજરાતનું વન વિસ્તાર ≈ 8% — 'Aam Nav Gaj' (આમ છતાં નવ ગુજરાત) જેવું યાદ રાખો: GJ કુલ રાજ્ય વિસ્તારનો લગભગ 8% વન.
  • ક્યોટો vs પેરિસ:
    ક્યોટો = બંધનકર્તા, વિકસિત દેશો પર ભાર;
    પેરિસ = સ્વૈચ્છિક NDC, સર્વસામાન્ય.

Exam tips

  • વધુ પડતા નાના પ્રશ્નો સીધા 'કયો વાયુ કયા પ્રદૂષણ/કારણ?' રૂપમાં આવે છે — CO, SO₂, NOₓ, O₃, CO₂, CH₄ ની અલગ-અલગ અસરો યાદ રાખો.
  • મોન્ટ્રીઅલ પ્રોટોકોલ, ક્યોટો, પેરિસ — તારીખો અને ટોચના મુદ્દા જોડો.
  • ગુજરાત સંબંધિત વન વિસ્તાર, મુખ્ય વાયુ પ્રદૂષણ વિસ્તારો, જળ પ્રદૂષણ સ્રોતો વિશેનું જ્ઞાન ઉપયોગી.
  • BOD/COD ક્યારેક સંખ્યાત્મક પ્રશ્નમાં આવે છે — સમજવું કે COD ≥ BOD.
  • વૈશ્વિક અને ભારત સ્તરના યોજનાઓ (સ્વચ્છ ભારત, પંચગંગા, સ્વાસ્થ્ય/વન્યજીવન સંરક્ષણ) નામ યાદ રાખો.

Common traps

  • ઓઝોન છિદ્ર = વૈશ્વિક ઉષ્ણાયન નથી. બંને અલગ સમસ્યાઓ છે, પરંતુ ક્યોટોમાં બંનેને જોડી દેવામાં આવ્યાં.
    • ઓઝોન છિદ્ર માટે CFCs જવાબદાર;
    • વૈશ્વિક ઉષ્ણાયન માટે CO₂, CH₄, N₂O જવાબદાર.
  • Flood, cyclone, drought બધા જળવાયુ પ્રભાવ છે; પરંતુ 'climate change' માત્ર વૃદ્ધિશીલ પ્રવૃત્તિ છે, દરેક હવામાન ઘટના નથી.
  • BOD = ઓક્સિજન માંગ છે, ઓક્સિજન નથી. BOD વધારે = ઓછું DO (Dissolved Oxygen) = મચ્છી મૃત્યુ.
  • PM2.5 અને PM10 માં ફરક:
    PM2.5 < 2.5 μm — ઊંડા પ્રત્યક્ષ શ્વાસ અને રક્તપ્રવાહમાં પ્રવેશે;
    PM10 < 10 μm — મુખ્યત્વે ઉપલી શ્વાસનો માર્ગ.
  • ક્યોટો પ્રોટોકોલ (1997) → અમલ (2005); પેરિસ કરાર (2015) → અમલ (2016). બંને જૂદા સમય અને જૂદા રૂપમાં છે.
  • IPCC એ ઔદ્યોગિક સંસ્થા નથી; તે વિજ્ઞાન અને નીતિ સમિતિ છે. તે કોઈ કરાર/પ્રોટોકોલ કરતી નથી, પરંતુ સંશોધન/અહેવાલ આપે છે.
