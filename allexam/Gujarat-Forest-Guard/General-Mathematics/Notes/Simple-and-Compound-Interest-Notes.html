પરિચય: વ્યાજ એટલે શું?

જ્યારે કોઈ વ્યક્તિ બીજા વ્યક્તિ પાસેથી પૈસા ઉborrow લે છે કે ત્યારે તેણે નક્કી સમયબાદ પૈસા પર જથ્થાત્મક ચુકવણી કરવી પડે છે, જેને 'વ્યાજ' કહેવાય છે. મૂળ રકમને 'મૂલધન' (Principal) કહે છે. વ્યાજની ગણતરી બે પ્રકારની હોય છે: (1) સરળ વ્યાજ (Simple Interest - S.I.) અને (2) ચક્રવર્તી વ્યાજ (Compound Interest - C.I.). ગુજરાત વનરક્ષક પરીક્ષામાં આ વિષય ખૂબ મહત્વનો છે અને અંદાજે 3-5 પ્રશ્નો પૂછવામાં આવે છે.

સરળ વ્યાજ (Simple Interest)

જ્યારે વ્યાજ મૂલધન પર આધાર રાખીને અનિર્ધારિત સમય માટે ગણાય, પણ મૂલધન બદલાતું નથી, ત્યારે તેને સરળ વ્યાજ કહે છે.

• વ્યાજ સૂત્ર: S.I. = (P × R × T) / 100
- P = મૂલધન (Principal)
- R = વાર્ષિક વ્યાજ દર (%)
- T = સમય (વર્ષોમાં)

• કુલ રકમ (Amount): A = P + S.I. = P(1 + RT/100)

• મહત્વના સંબંધો:
- જો વ્યાજ મળે તો: P = (S.I. × 100) / (R × T)
- દર શોધવા: R = (S.I. × 100) / (P × T)
- સમય શોધવા: T = (S.I. × 100) / (P × R)

• એકમ પરિવર્તન:
- સમય મહિનામાં હોય તો: T(વર્ષ) = મહિનાઓ / 12
- સમય દિવસમાં હોય તો: સામાન્ય રીતે વર્ષ 365 દિવસ ગણાય
- દર ઘણીવાર વાર્ષિક હોય છે

સરળ વ્યાજ - ઉદાહરણો

ઉદાહરણ 1: ₹5000 નું 3 વર્ષ માટે 10% વાર્ષિક દરે સરળ વ્યાજ શોધો.
ઉકેલ: S.I. = (5000 × 10 × 3)/100 = ₹1500
કુલ રકમ = 5000 + 1500 = ₹6500

ઉદાહરણ 2: કોઈ રકમ પર 4 વર્ષ માટે 8% વાર્ષિક વ્યાજ ₹960 મળે. મૂલધન શોધો.
ઉકેલ: P = (960 × 100)/(8 × 4) = 96000/32 = ₹3000

ઉદાહરણ 3: કોઈ રકમ 2 વર્ષમાં સરળ વ્યાજે 2 ગણી થાય છે. દર શોધો.
ઉકેલ: S.I. = P (કારણ કે કુલ રકમ 2P થાય), એટલે P = (P × R × 2)/100
⇒ R = 50%

ઉદાહરણ 4: ₹8000 નું 6 મહિના માટે વાર્ષિક 12% દરે સરળ વ્યાજ શોધો.
ઉકેલ: T = 6/12 = 0.5 વર્ષ
S.I. = (8000 × 12 × 0.5)/100 = ₹480

ચક્રવર્તી વ્યાજ (Compound Interest)

ચક્રવર્તી વ્યાજમાં, દર્યાદ્ઘ સમયે વ્યાજની ગણતરી કર્યાબાદ, મળેલ વ્યાજ મૂલધનમાં ઉમેરાય છે અને પછીનો વ્યાદ્ઘ ગણતરી આ નવા મૂલધન પર થાય છે. આમ, 'વ્યાજ પર વ્યાજ' મળે છે.

• સૂત્ર: A = P(1 + R/100)^n
જ્યાં n = વર્ષોની સંખ્યા

• ચક્રવર્તી વ્યાજ: C.I. = A - P = P[(1 + R/100)^n - 1]

• કેસઝ:
(1) સામાન્ય કેસ: n વર્ષ માટે ઉપરનું સૂત્ર
(2) અર્ધવર્ષીય ચક્રવર્તી: R → R/2%, n → 2n
A = P(1 + R/200)^(2n)
(3) ત્રૈમાસિક ચક્રવર્તી: R → R/4%, n → 4n
(4) અપૂર્ણ વર્ષ: જો n વર્ષ + k મહિના હોય,
A = P(1 + R/100)^n × (1 + kR/(100×12))
(5) દર વર્ષે અલગ દર હોય: A = P(1 + R₁/100)(1 + R₂/100)...(1 + Rₙ/100)

ચક્રવર્તી વ્યાજ - ઉદાહરણો

ઉદાહરણ 1: ₹10000 નું 2 વર્ષ માટે 10% વાર્ષિક ચક્રવર્તી વ્યાજ શોધો.
ઉકેલ: A = 10000(1 + 10/100)² = 10000 × (1.1)² = 10000 × 1.21 = ₹12100
C.I. = 12100 - 10000 = ₹2100

ઉદાહરણ 2: ₹5000 નું 1.5 વર્ષ માટે 8% વાર્ષિક અર્ધવર્ષીય ચક્રવર્તી વ્યાજ શોધો.
ઉકેલ: R = 8/2 = 4%, n = 1.5 × 2 = 3
A = 5000(1 + 4/100)³ = 5000 × (1.04)³ = 5000 × 1.124864 ≈ ₹5624.32
C.I. ≈ ₹624.32

ઉદાહરણ 3: ₹8000 નું 3 વર્ષ માટે વાર્ષિક 5%, 10%, 15% દરે ચક્રવર્તી વ્યાજ શોધો.
ઉકેલ: A = 8000 × 1.05 × 1.10 × 1.15 = 8000 × 1.32825 = ₹10626
C.I. = 10626 - 8000 = ₹2626

સરળ અને ચક્રવર્તી વ્યાજ વચ્ચેનો તફાવત

• તફાવતની રકમ: n વર્ષ બાદ સરળ અને ચક્રવર્તી વ્યાજ વચ્ચેનો તફાવત:
દ્વિવર્ષ માટે: C.I. - S.I. = P(R/100)²
ત્રિવર્ષ માટે: C.I. - S.I. = P(R/100)²(3 + R/100)

• જો ચોથું વર્ષ બાદ તફાવત જાણીતો હોય, તેનો ઉપયોગ P શોધવા માટે થાય છે.

• સરળ વ્યાજે 2 વર્ષમાં રકમ X થાય, ચક્રવર્તી વ્યાજે 2 વર્ષમાં Y થાય. તો:
P = (Y - X) × (X/ (X²/Y - 1)) — આ પ્રકારના પ્રશ્નો ઘણીવાર આવે છે.

• મહત્વપૂર્ણ માહિતી:
- સરળ વ્યાજ હંમેશા ચક્રવર્તી વ્યાજ કરતા ઓછું કે સમાન હોય છે (એક જ દર અને સમયે)
- જો દર 0% હોય, બંને સમાન
- ચક્રવર્તી વ્યાજ વધુ લાભદાયી છે

• ઉપયોગી ટૂંકા માર્ગો:
- 2 વર્ષ માટે S.I. = 2PR/100
- 3 વર્ષ માટે C.I. ≈ S.I. + પ્રથમ વર્ષનું વ્યાજ × R/100

વ્યાજ-સંબંધી મહત્વપૂર્ણ ટૂંકા માર્ગો અને શોર્ટકટ્સ

• ટૂંકા સમય માટે ચક્રવર્તી વ્યાજ:
- 1 વર્ષ: A = P(1+R/100)
- 2 વર્ષ: A = P(1 + 2R/100 + R²/10000)
- 3 વર્ષ: A = P(1 + 3R/100 + 3R²/10000 + R³/1000000)

• વ્યાજ દર પ્રતિશતમાંથી ડિગ્રીમાં બદલવો:
- 5% = 1/20, 10% = 1/10, 12.5% = 1/8, 20% = 1/5
- આ ઉપયોગથી ગણતરી સરળ બને છે

• 'મૂલધન અને સમય' શોધવાના ઝડપી રસ્તા:
- જો S.I. અને C.I. બંને આપેલા હોય, તો P = (C.I. - S.I.) × 10000/R² (2 વર્ષ માટે)

• ગુણોત્તર રીત:
- જો 2 વર્ષમાં રકમ a ગણી થાય અને b ગણી થાય, તો વ્યાજદરનો ગુણોત્તર શોધી શકાય

• યાદ રાખવાના અંકો:
- (1.05)² = 1.1025, (1.10)² = 1.21, (1.10)³ = 1.331
- (1.02)⁴ ≈ 1.0824, (1.04)³ ≈ 1.1249

પરીક્ષામાં પૂછાતા મહત્વપૂર્ણ પ્રકારો

પરીક્ષામાં નીચેના પ્રકારના પ્રશ્નો આવે છે:

1. 'કોઈ રકમ કેટલા સમયમાં X ગણી થાય?' - સમય શોધવાનો પ્રશ્ન
ઉદા: ક્યારે રકમ 3 ગણી થાય? → T = (200/R) વર્ષ

2. 'S.I. અને C.I. નો તફાવત આપેલ હોય' - મૂલધન કે દર શોધવાનો
ઉદા: 2 વર્ષે તફાવત ₹50, દર 10% → P = 50 × 10000/100 = ₹5000

3. 'અર્ધવર્ષીય/ત્રૈમાસિક ચક્રવર્તી' - n અને R બદલવાના

4. 'દર વર્ષે અલગ દર' - બહુવર્ષીય અલગ દર

5. 'ચક્રવર્તી વ્યાજે r% દરે n વર્ષમાં A રકમ, S.I.એ K રકમ' - સરખામણી પ્રકાર

6. 'મૂલધનનો ભાગ' - મૂલધનના વિવિધ ભાગો પર અલગ દરે વ્યાજ

7. 'વર્ષે વાર્ષિક માસિક ચક્રવર્તી' - વિશેષ અવસ્થા

સામાન્ય ભૂલો અને પરહેજી

1. સમયનો એકમ: મહિના/દિવસ સીધા સૂત્રમાં મૂકી દેવાની ભૂલ - સૌપ્રથમ વર્ષમાં ફેરવો.

2. ચક્રવર્તીમાં n અને R બંને બદલવા: અર્ધવર્ષીય હોય તો R/2 અને n×2, પણ ઘણા વિદ્યાર્થીઓ એક જ બદલે છે.

3. C.I. અને A માં ભેદ: C.I. એ વ્યાજ છે, A એ કુલ રકમ છે. પ્રશ્નમાં કયાનો પૂછે છે તે જોવું જરૂરી છે.

4. S.I. નું સૂત્ર: (P×R×T)/100 માં 100 ભૂલી જવાય છે.

5. તફાવતનું સૂત્ર: 2 વર્ષ માટે C.I.-S.I. = P(R/100)² - આ સૂત્ર યાદ રાખવું ફાયદાકારક છે.

6. સમય શોધતી વેળા: જવાબ વર્ષમાં આવે છે, પણ પ્રશ્ન મહિનામાં માંગતું હોય તો રૂપાંતરિત કરવું.

7. દરની ગણતરી: શેકડા (%) ની કિંમત 100 વડે ભાગવાની ભૂલ.

8. 'ગણી' થવાનો પ્રશ્ન: X ગણી થાય તો S.I. = P(X-1)

Important facts

  • સરળ વ્યાજ: S.I. = (P × R × T) / 100, કુલ રકમ A = P + S.I.
  • ચક્રવર્તી વ્યાજ: A = P(1 + R/100)^n, C.I. = A - P
  • અર્ધવર્ષીય ચક્રવર્તી: A = P(1 + R/200)^(2n)
  • 2 વર્ષે C.I. - S.I. = P(R/100)²
  • જો કોઈ રકમ T વર્ષમાં X ગણી થાય, તો S.I. = P(X-1)
  • સમય મહિનામાં હોય તો T = મહિના/12 વર્ષ
  • દર વર્ષે અલગ દર: A = P(1+R₁/100)(1+R₂/100)...
  • ચક્રવર્તી વ્યાજ હંમેશા સરળ વ્યાજ કરતા વધુ કે સમાન હોય છે

Formulas and relationships

સરળ વ્યાજ: S.I. = (P × R × T) / 100
કુલ રકમ (સરળ): A = P + S.I. = P(1 + RT/100)
ચક્રવર્તી વ્યાજ: A = P(1 + R/100)^n
ચક્રવર્તી વ્યાજ રકમ: C.I. = P[(1 + R/100)^n - 1]
અર્ધવર્ષીય ચક્રવર્તી: A = P(1 + R/200)^(2n)
2 વર્ષે તફાવત: C.I. - S.I. = P(R/100)²
મૂલધન (S.I. જાણીતો હોય): P = (S.I. × 100) / (R × T)
દર (S.I. જાણીતો હોય): R = (S.I. × 100) / (P × T)
સમય (S.I. જાણીતો હોય): T = (S.I. × 100) / (P × R)
