વિભાગ ૧: સંખ્યા પદ્ધતિ અને મૂળભૂત શબ્દો (Number System)

સંખ્યાઓની વર્ગીકરણ:

• કુલ સંખ્યાઓ (Natural Numbers): પ્રકૃત સંખ્યાઓ {1, 2, 3, ...} — આ એકમથી શરૂ થાય છે.
• પૂર્ણ સંખ્યાઓ (Whole Numbers): {0, 1, 2, 3, ...} — પ્રકૃત સંખ્યાઓમાં 0 ઉમેરવાથી.
• પૂર્ણાંકો (Integers): {..., -3, -2, -1, 0, 1, 2, 3, ...} — ધન અને ઋણ સંખ્યાઓ સાથે 0.
• પરમાણુ સંખ્યા (Rational Numbers): p/q સ્વરૂપની, જ્યાં q ≠ 0 (દા.ત. 3/4, -2/5, 7, 0).
• અપરિમેય સંખ્યા (Irrational Numbers): દશાંશમાં અવધાર રહેતી અને સ્વરૂપ p/q માં ન મળતી (√2, π, e).
• પરાકાર સંખ્યાઓ (Real Numbers): તમામ પરમાણુ + અપરિમેય સંખ્યાઓનો સમૂહ.

મહત્વના ગુણધર્મો:
• બે સરવાળા પછીનો પરિણામ હંમેશા સંખ્યા હોય છે (સંવૃત્ત ગુણધર્મ).
• કોઈ પણ સંખ્યા × 0 = 0; કોઈ પણ સંખ્યા + 0 = તે જ સંખ્યા.
• યોગ્ય (Proper Fraction): અંશ < છેદ (દા.ત. 3/5); અયોગ્ય (Improper Fraction): અંશ ≥ છેદ.
• સમાંગ વિભાજ્યતા: સંખ્યા સમાન જોડાયેલી હોય ત્યારે ક્રમ બદલવો ગણતરીને સરળ બનાવે છે.

મોટા પ્રમાણમાં પરિકલ્પના (Gujarat Forest Guard level):
• અડધી-એકમ પદ્ધતિ (Unit digit method) — માત્ર છેલ્લો આંકડો યાદ રાખીને ગણતરી.
• ભાગફળ અને શેષ (Dividend, Divisor, Quotient, Remainder) સંબંધ: Dividend = Divisor × Quotient + Remainder.
• ધન અને ઋણ સંખ્યાઓનો સરવાળો/ગુણાકાર: ઋણ × ઋણ = ધન, ધન × ઋણ = ઋણ.

વિભાગ ૨: વિભાજ્યતા નિયમો (Divisibility Rules)

મહત્વપૂર્ણ વિભાજ્યતા નિયમો (આવર્તન ઊંચા):

• 2: છેલ્લો આંકડો 0, 2, 4, 6, 8 હોય તો.
• 3: આંકડાઓનો સરવાળો 3થી વિભાજ્ય હોય તો.
• 4: છેલ્લા બે આંકડા 4થી વિભાજ્ય હોય તો.
• 5: છેલ્લો આંકડો 0 અથવા 5 હોય તો.
• 6: 2 અને 3 — બંનેના નિયમો પૂરા થાય તો.
• 8: છેલ્લા ત્રણ આંકડા 8થી વિભાજ્ય હોય તો.
• 9: આંકડાઓનો સરવાળો 9થી વિભાજ્ય હોય તો.
• 10: છેલ્લો આંકડો 0 હોય તો.
• 11: જોડ પوزિશનના આંકડાઓનો સરવાળો અને બે પોઝિશનના આંકડાઓનો સરવાળો વચ્ચેનો તફાવત 0 અથવા 11નો ગુણક હોય તો.

ઉપયોગી તથ્યો:
• LCM(2,3,4,5,6,8,9,10,11,12) નો ગુણક 7920 છે.
• બે સંખ્યાઓના ગુણાકાર = HCF × LCM (બે સંખ્યાઓ માટે).
• વિભાજ્યતા ચકાસવા માટે મોટી સંખ્યાઓને હરોળબદ્ધ અવયવોમાં વિભાજિત કરવી સરળ બનાવે છે.
• કોઈ પણ સંખ્યાનો છેલ્લો આંકડો (unit digit) શોધવા માટે ફક્ત છેલ્લો આંકડો જ લો અને પુનરાવર્તિત ગુણાકાર કરો.

મિસ્ટેક પરિસ્થિતિ:
• વિદ્યાર્થીઓ ઘણીવાર 6થી વિભાજ્યતાનો નિયમ 2 અથવા 3 એકલા લાગુ પડે છે, પરંતુ બંને જરૂરી છે.
• 11નો નિયમ ભ્રમણાથી ઉલટો વાપરે છે — જોડ-બે પદાવલિને બદલે ગોઠવણી ખોટી લાગુ કરે છે.

વિભાગ ૩: LCM અને HCF (લ.સા.અ. અને મ.સા.ગુ.)

વ્યાખ્યાઓ:
• HCF (Highest Common Factor) — મહત્તમ સામાન્ય અવયવ; બે કે વધુ સંખ્યાઓમાંથી સૌથી મોટો સામાન્ય ભાગાકર્તા.
• LCM (Least Common Multiple) — લઘુત્તમ સામાન્ય અવયવ; બે કે વધુ સંખ્યાઓની સૌથી નાની સામાન્ય ગુણી.

પદ્ધતિઓ:
1. અવયવ પદ્ધતિ (Prime Factorization):
– દરેક સંખ્યાને મૂળ અવયવોમાં વિભાજિત કરો.
– HCF = તમામ સંખ્યાઓમાં સામાન્ય મૂળ અવયવોનો ન્યૂનતમ ઘાત ગુણાકાર.
– LCM = તમામ મૂળ અવયવોનો મહત્તમ ઘાત ગુણાકાર.

2. લંબ પદ્ધતિ (Common Division Method):
– સંખ્યાઓને સામાન્ય અવયવથી વારંવાર ભાગતા રોકો.
– HCF = તમામ ભાગાકર્તાઓનો ગુણાકાર; LCM = તમામ ભાગાકર્તાઓ × શેષ અવશેષોનો ગુણાકાર.

મહત્વપૂર્ણ સૂત્ર:
– HCF × LCM = સંખ્યા A × સંખ્યા B (માત્ર બે સંખ્યાઓ માટે)

ઉદાહરણ:
HCF(36, 48):
36 = 2² × 3²
48 = 2⁴ × 3
HCF = 2² × 3 = 12
LCM = 2⁴ × 3² = 144
(ચકાસણી: 12 × 144 = 1728; 36 × 48 = 1728 ✓)

પરિક્ષામાં આવનારા પ્રશ્ન:
• રસ્તા પર ઝાડ વાવવા — LCM નો પ્રશ્ન.
• સાયકલ બે વાર મળે તે સમય — LCM.
• સૌથી નાની સંખ્યા જે ત્રણેયથી શેષ 1 છોડે — LCM(3,4,5)+1.
• સૌથી નાની સંખ્યા જે ત્રણેયથી 2, 3, 4 શેષ છોડે — LCM-અનુક્રમ.

વિભાગ ૪: ટકાવારી (Percentage)

મૂળભૂત સૂત્રો:
• ટકાવારી = (ભાગ / કુલ) × 100
• ટકાવારીમાંથી મૂલ્ય = (ટકાવારી / 100) × કુલ
• વધારો/ઘટાડો (%) = [(નવું – જૂનું) / જૂનું] × 100

મહત્વપૂર્ણ તથ્યો:
• 1/2 = 50%, 1/3 ≈ 33.33%, 1/4 = 25%, 1/5 = 20%, 1/6 ≈ 16.67%, 1/8 = 12.5%, 1/10 = 10%, 1/11 ≈ 9.09%, 1/16 = 6.25%, 1/20 = 5%, 1/25 = 4%, 1/50 = 2%, 1/100 = 1%.
• વધુ/ઘટાડો પછીનું મૂલ્ય = મૂળ × (1 ± ટકા/100).
• સતત ટકાવારી બદલાવ: પહેલા ઘટાડો x%, પછી વધારો y% → શુદ્ધ બદલાવ = x + y – (xy/100).

ઉદાહરણો:
1. 800 નું 35% = 280.
2. 500માં 20% વધારો પછી 10% ઘટાડો = 500×1.2×0.9 = 540.
3. એક સંખ્યાનું 40% 240 હોય તો સંખ્યા = 240/(0.40) = 600.

પરિક્ષા-વિશેષ:
• ગુજરાત વન રક્ષક પરીક્ષામાં ટકાવારીના સીધા પ્રશ્નો આવે છે (દા.ત., વનક્ષેત્રમાં વૃક્ષોની વધારો/ઘટાડો).
• % પર % (દા.ત., 20% ઘટાડો પછી ફરી 10% વધારો) પ્રશ્નો ધ્યાનમાં.
• વસન્ત ઋતુમાં વૃક્ષોનાં નવું પહોંચવું/કચડાવું વગેરે સંદર્ભમાં લાગુ.

વિભાગ ૫: લાભ અને નુકસાન (Profit and Loss)

મૂળભૂત શબ્દો:
• વજ્જન કિંમત (Cost Price, CP): ખરીદ મૂળ કિંમત.
• વિક્રય કિંમત (Selling Price, SP): વેચાણ મૂળ કિંમત.

સૂત્રો:
• લાભ = SP – CP (જ્યારે SP > CP)
• નુકસાન = CP – SP (જ્યારે CP > SP)
• લાભ % = (લાભ / CP) × 100
• નુકસાન % = (નુકસાન / CP) × 100
• SP = CP × (100 + લાભ%) / 100
• CP = SP × 100 / (100 + લાભ%)

મહત્વના બિંદુઓ:
• 2 વસ્તુ એકસરખી SP પર વેચાય — એક પર x% લાભ, બીજા પર x% નુકસાન → કુલ નુકસાન = x²/100 %.
• ડિસ્કાઉન્ટ (છૂટ) એગ્રીમેન્ટ મૂળ નિશાની કિંમત પર લાગુ પડે છે.
• માર્કડ કિંમત (Marked Price, MP): ટેગ કરેલી કિંમત; ડિસ્કાઉન્ટ % = [(MP – SP)/MP] × 100.
• SP = MP × (100 – ડિસ્કાઉન્ટ%) / 100.

ઉદાહરણ:
CP = ₹400, લાભ% = 25% → SP = 400 × 1.25 = ₹500.

મિસ્ટેક પરિસ્થિતિ:
• લાભ/નુકસાન % હંમેશા CP પર ગણવામાં આવે, SP પર નહીં.
• ડિસ્કાઉન્ટ % હંમેશા MP પર લાગુ પડે, SP પર નહીં.
• 2-વસ્તુ સમસ્યામાં x²/100 નુકસાન યાદ રાખો.

વિભાગ ૬: સાદું અને ચક્રવૃધ્ધી વ્યાજ (Simple and Compound Interest)

સાદું વ્યાજ (SI):
• SI = (P × R × T) / 100
– P = મૂળધન, R = વાર્ષિક દર (%), T = સમય (વર્ષ)
• કુલ રકમ A = P + SI = P(1 + RT/100)

ચક્રવૃધ્ધી વ્યાજ (CI):
• A = P(1 + R/100)ⁿ જ્યાં n = કુલ આવર્તનો
• જો અર્ધવાર્ષિક: n = 2T, R → R/2
• જો ત્રિમાસિક: n = 4T, R → R/4
• CI = A – P = P[(1+R/100)ⁿ – 1]

મહત્વપૂર્ણ સૂત્ર:
• એક જ વર્ષમાં CI – SI = P(R/100)²
• બે વર્ષમાં CI – SI = P(R/100)²[1 + (R/100)]

ઉદાહરણ:
P = ₹1000, R = 10%, T = 2 વર્ષ:
SI = (1000×10×2)/100 = ₹200
CI = 1000[(1.1)² – 1] = 1000[1.21 – 1] = ₹210
CI – SI = ₹10 = 1000 × 0.01 ✓

પરિક્ષા-વિશેષ:
• સામાન્ય રીતે 1, 2, 3 વર્ષની CI/SI સીધા પ્રશ્નો.

Important facts

  • LCM(2,3,4,5,6,8,9,10,11,12) = 7920 — આ મૂલ્ય ઝડપી ગણતરીમાં મદદરૂપ.
  • બે સંખ્યાઓ માટે: HCF × LCM = સંખ્યા A × સંખ્યા B.
  • ટકાવારી રૂપાંતરણ: 1/2=50%, 1/3≈33.33%, 1/4=25%, 1/5=20%, 1/8=12.5%, 1/16=6.25%, 1/20=5%, 1/25=4%, 1/50=2%, 1/100=1%.
  • 2 વસ્તુ સમાન SP પર x% લાભ + x% નુકસાન → કુલ નુકસાન = x²/100 %.
  • સાદા વ્યાજ: SI = PRТ/100; ચક્રવૃધ્ધી: A = P(1+R/100)^n.
  • CI – SI (એક વર્ષ) = P(R/100)²; બે વર્ષ = P(R/100)²[1+(R/100)].
  • વધુ/ઘટાડો પછીનું મૂલ્ય = મૂળ × (1 ± ટકા/100).
  • 11ની વિભાજ્યતા: જોડ પોઝિશનના આંકડાનો સરવાળો અને બે પોઝિશનનો સરવાળો વચ્ચેનો તફાવત 0 અથવા 11નો ગુણક હોય તો.
  • ગુજરાત વન રક્ષક પરીક્ષામાં અંકગણિત ભાગનો દર આસપાસ 12.5% છે.

Formulas and relationships

હિસાબી: લાભ% = (લાભ / CP) × 100; નુકસાન% = (નુકસાન / CP) × 100; SP = CP × (100 + %)/100; CP = SP × 100/(100 + %)
ટકાવારી: ટકા = (ભાગ/કુલ) × 100; વધારો/ઘટાડો % = ([(નવું–જૂનું)/જૂનું] × 100); સતત બદલાવ = x + y – xy/100
સાદું વ્યાજ (SI): SI = PRТ/100; A = P + SI = P(1 + RT/100)
ચક્રવૃધ્ધી વ્યાજ (CI): A = P(1 + R/100)^n; CI = P[(1+R/100)^n – 1]
LCM/HCF: HCF × LCM = A × B (બે સંખ્યાઓ માટે)
SP = MP × (100 – ડિસ્કાઉન્ટ%)/100; ડિસ્કાઉન્ટ% = (MP – SP)/MP × 100

Common mistakes

  • લાભ/નુકસાન % હંમેશા CP પર ગણવામાં આવે છે, SP પર નહીં — વિદ્યાર્થીઓ ઘણીવાર SP પર ગણે છે.
  • ડિસ્કાઉન્ટ % હંમેશા MP પર લાગુ પડે છે, SP પર નહીં.
  • 2-વસ્તુ સમાન SP પર x% લાભ + x% નુકસાન → x²/100 % નુકસાન (સીધું નાણાંકીય નુકસાન, ટકા).
