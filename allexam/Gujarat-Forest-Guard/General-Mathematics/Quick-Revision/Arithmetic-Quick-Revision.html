Arithmetic — Quick Revision (ગણિતના અંકગણિત વિભાગ)

Definitions

  • અંકગણિત (Arithmetic): સંખ્યાઓની મૂળભૂત ચાર ક્રિયાઓ (જોડ, બાદ, ગુણ, ભાગ) અને તેમની લાગુ પડતી યોજનાઓનો અભ્યાસ.
  • અપૂર્ણાંક (Fraction): બે સંખ્યાઓનો ભાગાકાર જે 'a/b' સ્વરૂપે લખાય, જ્યાં b ≠ 0. અંશ (numerator) ઉપર, છેદ (denominator) નીચે.
  • દશાંશ (Decimal): છેદ 10 ની કોઈ પણ ઘાત હોય તેવા અપૂર્ણાંકનું રૂપાંતર. જેમ કે 0.75 = 75/100.
  • HCF (મ.અ.બ.) / GCD: બે કે વધુ પૂર્ણાંકોના સામાન્ય અવયવોમાં સૌથી મોટો અવયવ.
  • LCM (લ.અ.બ.): બે કે વધુ પૂર્ણાંકોના સામાન્ય ગુણિતકોમાં સૌથી નાનો ગુણિતક.
  • સરેરાશ (Average/Mean): આપેલી સંખ્યાઓનો સરવાળો તેમની ગણતરી (count) વડે ભાગવાથી મળતી કિંમત.
  • લાભ/નુકસાન (%): ખરીદકિંમત (CP) અને વિક્રયકિંમત (SP) વચ્ચેનો તફાવત; જો SP > CP → લાભ, જો SP < CP → નુકસાન.
  • ચક્રવૃદ્ધિ સરકાર (Compound Interest): મૂળધન પર દર વર્ષે મળતો વ્યાજ પછલા વર્ષના મૂળધન + વ્યાજ પર ગણાય.
  • સમય-વેગ (Time-Speed-Distance): S = D/T, D = S × T, T = D/S; એકમ રૂપાંતર: km/h → m/s = × 5/18, m/s → km/h = × 18/5.
  • કામ-સમય (Work-Time): જો A એકલા X દિવસમાં કામ કરે, તો તેનો 1 દિવસનો ભાગ = 1/X.

Key concepts

  • અપૂર્ણાંકના ગુણધર્મો: (i) અંશ અને છેદ બંનેને同一个 સંખ્યાથી ગુણતા/ભાગતા ભિન્ન સમાન રહે. (ii) અપૂર્ણાંકોના ગુણાકારમાં અંશ×અંશ અને છેદ×છેદ. (iii) ભાગાકાર = ઉલટો અપૂર્ણાંક વડે ગુણાકાર.
  • HCF શોધવાની પદ્ધતિઓ: (i) અવયવ પદ્ધતિ – દરેક સંખ્યાના મૂળ અવયવો લઈ સામાન્ય માંથી ન્યૂનતમ ઘાત લેવી. (ii) કુલંબ પદ્ધતિ – મોટી સંખ્યાને નાનીથી ભાગી, શેષ મળતો રહે ત્યાં સુધી જારી રાખવી; છેલ્લો શેષ-હીન ભાજક HCF છે. (iii) LCM × HCF = a × b (બે સંખ્યા માટે).
  • LCM શોધવાની પદ્ધતિ: અવયવ પદ્ધતિમાં દરેક અવયવની તેની વધુમાં વધુ ઘાત લેવી. ઉદા. 12=2²×3¹, 18=2¹×3² → LCM=2²×3²=36.
  • BODMAS/બ્રેકેટનો નિયમ: (B)racek(ક) → (O)rder(ઘાત/સૂચકાંક) → (D)ivision(ભાગાકાર) → (M)ultiplication(ગુણાકાર) → (A)ddition(જોડ) → (S)ubtraction(બાદ). સાંકળમાં કોઈ બે ક્રિયા સમાન હોય તો ડાબીથી જમણી ક્રમ.
  • દશાંશ રૂપાંતર: પુનરાવર્તી દશાંશ નિયમ – xy.xyxy... = (xy – x)/99; z.zzz... = z/9. ઉદા. 0.3636... = 36/99 = 4/11.
  • સરેરાશના સૂત્રો: (i) સરેરાશ = સરવાળો / ગણતરી. (ii) સતત N સંખ્યાઓની સરેરાશ = (પહેલી + છેલ્લી)/2. (iii) જો n સંખ્યાઓની સરેરાશ A હોય, અને ત્યાં k સંખ્યાઓ ઉમેરવા/કાઢવા, તો નવી સરેરાશ શોધવા ત્રુટિ પદ્ધતિ વાપરો.
  • લાભ/નુકસાનના મહત્વના સૂત્રો: (i) લાભ% = (લાભ/CP)×100. (ii) નુકસાન% = (નુકસાન/CP)×100. (iii) SP = CP×(1 ± লাভ%/100). (iv) જો બે ચીજો એકસરખા દाम પર વેચાતી હોય, એક પર x% લાભ અને બીજી પર x% નુકસાન હોય, તો કુલ ટકાવારી = –(x²/100)% (એટલે નુકસાન).
  • છૂટ (Discount): MP (ટ્રેડ મૂલ્ય) પર from ટકાવારી છૂટ → SP = MP×(1 – D%/100). ધ્યાન રાખો: છૂટ હંમેશા MP પર ગણાય, CP પર નહીં.
  • સાદો વ્યાજ (Simple Interest): I = P×R×T/100, A = P + I. T એ સમય વર્ષમાં; R = દર/વર્ષ.
  • ચક્રવૃદ્ધિ સરકાર (Compound Interest): A = P(1 + R/100)^n જો વાર્ષિક. A = P(1 + R/100)^nt જો t વર્ષમાં n વાર ચક્રવાર. CI = A – P. આંતરવર્ષીય દરના ફરકને કારણે CI > SI હોય છે (P,R,T>0 માટે).
  • સમય-વેગ-અંતર: (i) S=D/T. (ii) એકમ બદલ: km/h × 5/18 = m/s. (iii) આગળ પાછળ વેગ અદલાબદલ: જો અંતર સમાન હોય અને વેગ a,b હોય, તો સરેરાશ વેગ = 2ab/(a+b). (iv) પ્રવાહમાં: સ્ટ્રીમ વેગ v, બોટ વેગ b → ઉપર (against) = b–v, નીચે (with) = b+v.
  • કામ-સમય: (i) Jodgani kaam: 1/A + 1/B. (ii) A એકલો X din, B એકલો Y din → jodya = XY/(X+Y) din. (iii) kaam khatam na thay to fraction kaam: kaam = samay × shramik.
  • સંખ્યા પરીક્ષા: (i) સમ સંખ્યા = 2n, વિષમ = 2n+1. (ii) ક્રમિક સંખ્યાઓનો સરવાળો = n(n+1)/2. (iii) પૂર્ણ વર્ગ: 1,4,9,16,25,36,49,64,81,100,121,144,... (iv) મૂળ અવયવનું કોઈ પણ અવયવ 100 માં વર્ગ નહોતો હોય, તે પૂર્ણ વર્ગ નથી.
  • શરતો અને નિયમો: (i) જો કોઈ સંખ્યા 2થી ભાગ્યે 0 શેષ હોય તો સમ, નહીં તો વિષમ. (ii) 3થી ભાગાય તો અંકોનો સરવાળો 3થી ભાગ્યો જોઈએ. (iii) 11થી: સરવાળો(બેક અને ઓડ પોઝિશન અંકો)નો તફાવત 0 અથવા 11નો ગુણિતક.
  • સાપેક્ષ ગતિ (Relative Speed): એક જ દિશાએ = |S1–S2|, વિરુદ્ધ દિશાએ = S1+S2. ટ્રેન પ્લેટફોર્મ પરથી પસાર થાય: અંતર = ટ્રેન લંબાઈ. બીજી ટ્રેન સરખાણી પાર: અંતર = L1+L2.
  • શ્રેણી (Series): અંકગણિત શ્રેણીનો nમો પદ = a+(n–1)d, સરવાળો = n/2[2a+(n–1)d]. ગુણોત્તર શ્રેણીનો nમો પદ = ar^(n–1), સરવાળો = a(r^n–1)/(r–1) જો r≠1.
  • મિશ્રણ અને અનુપાત (Alligation): માધ્યમિક દર = (m1a1+m2a2)/(m1+m2). ઝડપી રીત: (ધાર મૂલ્ય – સસ્તો) : (મોંઘો – ધાર મૂલ્ય) = મોંઘા:સસ્તાનો ગુણોત્તર.

Important facts

  • HCF(LCM) ના મૂળભૂત સંબંધ: a × b = HCF(a,b) × LCM(a,b) (ફક્ત બે સંખ્યા માટે).
