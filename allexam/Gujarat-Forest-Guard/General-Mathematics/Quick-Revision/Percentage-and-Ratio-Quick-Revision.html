Definitions

  • ટકાવારી (Percentage): કોઈ પણ સંખ્યાને 'શતક' (100) ના આધારે દર્શાવવાની પ્રક્રિયા. 'ટકા' નો અર્થ થાય છે 'સે.' ઉદા. 25% = 25/100 = 0.25
  • ગુણોત્તર (Ratio): બે કે વધુ એકમો વચ્ચેનો સંબંધ દર્શાવતી તુલના. જો a અને b હોય, તો ગુણોત્તર a:b અથવા a/b એમ દર્શાય. ઉદા. 3:5 એટલે 3/5
  • અનુપાત (Proportion): જ્યારે બે ગુણોત્તર સમાન હોય ત્યારે તેને અનુપાત કહે. a:b = c:d અથવા a/b = c/d, જેનો અર્થ ab = cd (ક્રોસ મલ્ટિપ્લિકેશન)
  • ચતુર્થ પ્રમાણ (Fourth Proportional): a:b = c:x હોય તો x એ ચતુર્થ પ્રમાણ કહેવાય. x = (b×c)/a
  • તૃતીય પ્રમાણ (Third Proportion): a:b = b:x હોય તો x એ તૃતીય પ્રમાણ. x = b²/a
  • મધ્યસ્થ પ્રમાણ (Mean Proportional): √(ab) એ a અને b નું મધ્યસ્થ પ્રમાણ. a:x = x:b

Key concepts

  • ટકાવારી → ભિન્નમાં રૂપાંતર: x% = x/100. ઉદા. 37.5% = 37.5/100 = 3/8
  • ભિન્ન → ટકાવારીમાં રૂપાંતર: (a/b)×100%. ઉદા. 5/8 = (5×100)/8 = 62.5%
  • શતકમાં ફેરફાર: વધારો = [(નવી - પૂર્વ)]/પૂર્વ ×100%. ઘટાડો = [(પૂર્વ - નવી)]/પૂર્વ ×100%
  • સામાન્ય ભિન્ન-ટકાવારી જોડ (જરૂરી): 1/2=50%, 1/3=33.33%, 1/4=25%, 1/5=20%, 1/6=16.67%, 1/7=14.29%, 1/8=12.5%, 1/9=11.11%, 1/10=10%, 1/11=9.09%, 1/12=8.33%, 1/15=6.67%, 1/16=6.25%, 1/20=5%, 1/25=4%, 1/50=2%, 1/100=1%
  • ગુણોત્તરના ગુણધર્મો: a:b = ka:kb (સમાન ગુણોત્તર). a²:b² = duplicate ratio. √a:√b = subduplicate ratio
  • પ્રતિભાવ ગુણોત્તર (Reciprocal): a:b નો પ્રતિભાવ = b:a
  • ત્રિઘાત ગુણોત્તર (Compound Ratio): a:c અને b:d નો સંયુક્ત ગુણોત્તર = ab : cd
  • સંયુક્ત પ્રમાણ (Compound Proportion): જો a:b = c:d, તો a+c : b+d = a : b (અંશ-છેદનો સરવાળો)
  • મિશ્રણનો ગુણોત્તર: બે પદાર્થને m:n ના ગુણોત્તરમાં મિશ્રિત કરતા, સંયુક્ત મૂલ્ય = (m×A + n×B)/(m+n)

Important facts

  • ટકાવારી શબ્દ લેટિન 'per centum' માંથી આવ્યો છે, જેનો અર્થ 'શતક પ્રતિ' થાય છે.
  • ટકાવારીનાં ચિહ્ન '%' નો ઉપયોગ પ્રથમ વખત 1600ના દશકમાં અંગ્રેજ ગણિતજ્ઞો દ્વારા થયો હતો.
  • આઠમાં ધોરણથી લાવેલા જ્ઞાન મુજબ, વન વિભાગની પરીક્ષામાં ટકાવારી-ગુણોત્તર પ્રકારના પ્રશ્નો સામાન્ય રીતે 3-5 ટકાવારી ગણિતના અંકોમાં આવે છે.
  • ટકાવારી અને ધન-ઋણ ગણતરીઓમાં ચિહ્નની ભૂલ સૌથી વધુ સામાન્ય જોવા મળે છે.
  • ગુણોત્તરમાં સ્થાન બદલતાં (a:b → b:a) પરિણામ 100/a બદલાય છે — આ ભૂલ ઘણીવાર પરીક્ષામાં થાય છે.

Memory aids

  • ટકાવારી → 100 વાળા મિત્ર: 'ટકા' = 'ટક' (શૈલી) + 'આ' → શું? 100 ની વાત! તેથી % એટલે 100 પર ભાગવું.
  • મહત્વના ભિન્ન-ટકાવારી જોડ યાદ કરવા: 'એક-દસ-બીજા' (1/2=50%, 1/3=33%, 1/4=25%) ગોળ-ગપ્પો રચના.
  • વધારો-ઘટાડો યાદ રાખવા: 'નવી - પૂર્વ ÷ પૂર્વ × 100' → 'નવી-પૂર્વનો તફાવત, પૂર્વેથી ભાગે, શતક દોડે.'
  • ચતુર્થ પ્રમાણ: a:b=c:x → x=bc/a (ત્રણો ગુણાકાર ÷ આગળ).

Exam tips

  • વનરક્ષક પરીક્ષામાં ટકાવારી-ગુણોત્તર પ્રશ્નો સામાન્ય રીતે સીધા ગણિત પર આધારિત હોય છે — ઝડપી ગણતરી માટે 1/7, 1/11, 1/13 જેવા ભિન્ન-ટકાવારી જોડ યાદ રાખો.
  • વિકલ્પો ચકાસો: જવાબ 48 છે, તો 50 ની નજીક કોઈ વિકલ્પ હોય તો તે સાચો હોઈ શકે છે — અંદાજ ગણતરીથી તપાસો.
  • મિશ્રણ પ્રશ્નોમાં રેખીય ગુણોત્તર નિયમ (Rule of Alligation) યાદ રાખો: મિશ્રણનો ગુણોત્તર = (મૂલ્ય_b − સરેરાશ) : (સરેરાશ − મૂલ્ય_a).
  • ટકાવારી શતક ફેરફારના પ્રશ્નમાં 'લગાતાર' શબ્દ આવી ગયો તો પહેલા વધારો ગણો, પછી નવા મૂલ્ય પર ઘટાડો — એકસાથે ન ગણો.
  • ગુણોત્તર પ્રશ્નોમાં 'સાદું રૂપ' માંગવામાં આવે તો HCF વડે ભાગો — ઉદા. 45:60 = 3:4 (HCF=15).

Common traps

  • પ્રશ્નમાં '% વધારો' અને 'વધુ '% ' વચ્ચેનો તફાવત ન મોજવવો — બંને અલગ અલગ સંખ્યાઓ પર ગણાય છે. ઉદા. 20% વધારો પછી ફરી 20% વધારો એ 44% નહીં, પણ 44% નજીક જાય (1.2×1.2=1.44).
  • ગુણોત્તરમાં a:b અને b:a એ બે અલગ વસ્તુઓ છે — ક્રમ બદલી ન શકાય.
  • ટકાવારીમાં 'A એ B કરતા x% વધારે' એટલે (A-B)/B ×100, પણ 'B એ A કરતા x% ઓછું' એટલે (A-B)/A ×100 — છેદ બદલાય છે!
  • મિશ્રણ પ્રશ્નોમાં ગુણોત્તરનો ક્રમ (p:q vs q:p) ખોટો રાખવો સામાન્ય ભૂલ છે.
  • શતકમાં ફેરફાર દરમિયાન ઋણ ચિહ્ન ભૂલી જવું — ઘટાડો હોય તો ઋણ આવવો જોઈએ.
