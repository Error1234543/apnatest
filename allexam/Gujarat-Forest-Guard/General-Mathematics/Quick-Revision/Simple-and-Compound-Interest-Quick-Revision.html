સાદા અને ચક્રવૃદ્ધિ વ્યાજ - ઝડપી રિવિઝન

Gujarat Forest GuardGujaratiQuick Revision

Definitions

  • સાદું વ્યાજ (Simple Interest - SI): જ્યારે પ્રતિ વર્ષ વ્યાજ ગણતરી માટેનો મૂળધન સamesો રહે, ત્યારે જે વ્યાજ મળે છે તે સાદું વ્યાજ કહેવાય. વ્યાજ હંમેશા મૂળધન પર ગણાય છે.
  • ચક્રવૃદ્ધિ વ્યાજ (Compound Interest - CI): જ્યારે દરેક ચક્રબાદ મળેલું વ્યાજ આગળના મૂળધનમાં ઉમેરાઈ જાય (મૂડી બને), ત્યારે જે વ્યાજ મળે છે તે ચક્રવૃદ્ધિ વ્યાજ કહેવાય. એટલે કે વ્યાજ પર વ્યાજ મળે છે.
  • મૂડી (Principal - P): એ રકમ જેને આપણે બેંકમાં મૂકીએ અથવા આપણને ધીરાવામાં આવે.
  • સમય (Time - T): તે કાળ જેના માટે પૈસાની અદાવત થાય છે (સામાન્ય રીતે વર્ષોમાં).
  • વ્યાજદર (Rate of Interest - R): દર વર્ષે મળતા અથવા ચુકવનારા વ્યાજનું ટકાવારી દર.
  • ક્ષયગુણક / Amount (A): મૂળધન અને ચક્રવૃદ્ધિ વ્યાજનો સરવાળો = મૂડી + CI.

Key concepts

  • સાદા વ્યાજનું મૂળભૂત સૂત્ર: SI = (P × R × T) / 100. અહીં P = મૂડી (રૂ.), R = વાર્ષિક દર (%), T = સમય (વર્ષોમાં). આ સૂત્રમાંથી તમે P, R કે T શોધી શકો છો.
  • સાદા વ્યાજમાં કુલ મૂડી (Amount with SI): A = P + SI = P + (P×R×T/100) = P(1 + RT/100). આ સૂત્ર ઘણી સમસ્યાઓમાં કુલ પૈસા શોધવા માટે કામ આવે છે.
  • ચક્રવ૜દ્ધિ વ્યાજનું મૂળભૂત સૂત્ર: A = P(1 + R/100)^n, જ્યાં n = વાર્ષિક રીતે ચક્રબંધાતા હોય ત્યારે વર્ષોની સંખ્યા. CI = A - P = P[(1 + R/100)^n - 1].
  • અડધાવાર ચક્રબંધાતા (Half-yearly): જો વ્યાજ અડધાવાર માંગવામાં આવે તો n = 2T (ચાર્જ ફ્રીક્વન્સી બમણી) અને R બદલાઈને R/2 થાય. ત્યારે A = P(1 + (R/2)/100)^(2T) = P(1 + R/200)^(2T).
  • ત્રિમાસિક ચક્રબંધાતા (Quarterly): n = 4T, R બદલાઈને R/4 થાય. A = P(1 + R/400)^(4T). દરેક ક્વાર્ટરમાં વ્યાજ ગણાય છે.
  • બિંદુ (Fractional) સમય: જો T = 3 વર્ષ 4 માસ હોય, તો T = 3 + 4/12 = 19/3 વર્ષ. તદરોપ SI = (P × R × 19) / (100 × 3). ધ્યાન રાખો કે T એ હંમેશા વર્ષોમાં હોવું જોઈએ.
  • ત્રણ-ચાર વર્ષોમાં CI: CI માટે n = 4 લઈએ તો A = P(1+R/100)^4. ઘણીવાર પ્રશ્નોમાં આ રૂપે CI નક્કી કરવું પડે છે.
  • CI અને SI નો તફાવત પહેલા vર્ષે: જો R% દરે vર્ષ માટે CI અને SI ગણવામાં આવે, તો CI - SI = P(R/100)^v. ખાસ કરીને v = 2 માટે: CI - SI = P(R²/100²). આ સૂત્ર ખૂબ જ ઉપયોગી છે.
  • CI અને SI નો તફાવત બીજા vર્ષે: CI - SI માટેનું સામાન્ય સૂત્ર = P × (R/100)^v. ઉદા. 2 વર્ષે તફાવત = P(R²/10000); 3 વર્ષે = P(R³/1000000) + આડા વર્ષો માટેનું વિસ્તરણ.

Important facts

  • SI દરેક વર્ષે સamesો રહે છે (સમાન મૂડી પરથી) જ્યારે CI દરેક વર્ષે વધતું જાય છે (મૂડી વધતી હોય તેથી).
  • SI માં T વર્ષ પછી કુલ મૂડી = P(1 + RT/100); CI માં T વર્ષ પછી કુલ મૂડી = P(1 + R/100)^T.
  • જો કોઈ મૂડી v વર્ષમાં SI ના દરે બમણી થાય, તો તેને v વર્ષમાં 8 ગણી થાય? તો SI માં: v વર્ષ = 7P વ્યાજ, 8 ગણી = 7v વર્ષ.
  • ચક્રવૄદ્ધિ વ્યાજમાં સમય ગણતરી: જો R% દરે 2 વર્ષે પૈસા 4 વખત વધે → A/P = 4 = (1+R/100)^2 → (1+R/100) = 2 → R = 100%. તેવી જ રીતે.
  • જો કોઈ મૂડી ચક્રવૃદ્ધિ પર v વર્ષમાં A બને, તો (v+k) વર્ષમાં A × (1+R/100)^k બને. એટલે કે CI માં આગળના k વર્ષ માટે પણ સames ઝડપથી વધે છે.
  • બેંકીકરણ પક્ષે: જો દરોરુપે ચોખ્ખાણું (Net Interest Rate) માં વધારો થાય તો CI વધુ, તો SI એમ.
  • વ્યાજગણતરીમાં ધ્યાન રાખવાની બાબતો: વર્ષ → માસ / 12; માસ → વર્ષ / 12; દિવસ → વર્ષ / 365 (કેટલાક પ્રશ્નોમાં /360 પણ રાખવામાં આવે છે; પ્રશ્ન પરથી નક્કી કરો).
  • કેટલાક ઝડપી ગણતરીના ટ્રિક્સ: SI = (P×R×T)/100 માં 100 સાથે P નો ભાગાકાર પહેલાં કરવો સહેલો રાખે છે. CI માં (1+R/100)^n ની ગણતરી માટે R ના મૂલ્ય પરથી 1.05, 1.10, 1.125, 1.20, 1.25 વગેરે તાકાતો જાણવી ફાયદાકારક છે.
  • Gujarat Forest Guard level માટે: સામાન્ય રીતે 2–4 પ્રશ્નો આ વિષયના આવે છે. ત્યાં મુખ્યત્વે SI અને CI ના સીધા સૂત્રના, તફાવતના, અને મૂડી/દર/સમય શોધવાના પ્રશ્નો પૂછાય છે.

Memory aids

  • SI નું સૂત્ર યાદ રાખવા માટે: 'SI = PRT / 100' → 'પ્રતિ વર્ષે સames વ્યાજ!' કલ્પના: એક જ બેકમાં સames પૈસા મળે છે, તેથી 'સાદું' (=સames).
  • CI નું સૂત્ર: A = P(1 + R/100)^n → 'પ્રતિ વર્ષે મૂડીમાં વધારો થાય!' કલ્પના: સ્નેક્શની જેમ વધુ પડતો વ્યાજ વધતો જાય છે, તેથી 'ચક્રવૃદ્ધિ'.
  • CI - SI (v=2) = P(R/100)²: 'બે વર્ષે તફાવત = મૂડી × દરનો વર્ગ' → સરળ રીતે યાદ રાખો.
  • અડધાવાર ચક્રબંધાતા: n બમણો, R અડધો. 'આડી વાર્ષિક' → સમય બમણો, દર અડધો. સારી રીતે યાદ રાખો.
  • SI અને CI નો તફાવત ઝડપથી: CI હંમેશા SI કરતા વધુ (જો R > 0 અને T > 1). એટલે CI > SI (T≥1 હોય ત્યારે).
  • કોઈ મૂડી v વર્ષમાં k વખત વધે: M^(1+R/100)^v = kM → (1+R/100)^v = k. કોઈ પણ જાતના પ્રશ્નમાં આ રીતે R શોધો.

Exam tips

  • Forest Guard (Vanrakshak/Vanpal) level માં SI અને CI પરના પ્રશ્નો સામાન્ય રીતે સીધા સૂત્રના હોય છે. SI નું સૂત્ર = PRT/100 અને CI નું સૂત્ર = P(1+R/100)^n - P. આ બે સૂત્રો મુખ્યત્વે યાદ કરીએ.
  • જ્યારે પ્રશ્નમાં 'કેટલાક વર્ષોમાં બમણી/ત્રિગુણit થાય' આવે, ત્યારે SI માટે સુત્ર: Time = (k-1)×100/R, જ્યાં k = ગુણોત્તર. ઉદા. બમણી થાય તો k=2, T = 100/R.
  • અડધાવાર ચક્રબંધાતા: આ પ્રશ્નોમાં n = 2T અને R → R/2 લેવાનું. 'અડધાવાર' એટલે '2 ચક્ર/વર્ષ'. આનો ખ્યાલ જરૂરી છે.
  • SI અને CI નો તફાવત: T = 2 વર્ષ માટે CI - SI = P(R/100)². આ સૂત્ર ઝડપથી ઉકેલ આપે છે, ખાસ કરીને B选项中 પરીક્ષામાં.
  • જો પ્રશ્નમાં 'ચક્રવૃદ્ધિ વ્યાજ સામે સાદું વ્યાજ' કે 'મૂડી શોધો' આવે, તો SI = PRT/100 → P = (SI × 100)/(R × T) લાગુ પાડો.
  • ઘણીવાર પ્રશ્નોમાં 'વર્ષ' અને 'માસ' બંને મળેલા હોય. T = (અંકો / 12) વર્ષ રૂપે રાખવું. દા.ત. 18 માસ = 1.5 વર્ષ, 27 માસ = 2.25 વર્ષ.
  • પરીક્ષામાં 2–4 પ્રશ્નો આ વિષયથી આવે છે. સામાન્ય રીતે SI ના સીધા પ્રશ્ન, CI ના સીધા પ્રશ્ન, SI vs CI તફાવતનો પ્રશ્ન, અને કોઈ એક પ્રશ્નમાં બદલાયેલી મૂડી દર વર્ષે હોય છે.
  • ગણતરીની ઝડપ માટે: R = 10% થી CI માં (1.1)^n ના વર્ગ-તાકાતો યાદ રાખો: (1.1)²=1.21, (1.1)³=1.331, (1.1)⁴=1.4641. આ સંખ્યાઓ જ્ઞાન પરીક્ષામાં સમય બચાવે છે.

Common traps

  • SІ માં સમય યુનિટ ભૂલ: પ્રશ્નમાં '3 વર્ષ 6 માસ' લખેલું હોય તો T = 3 + 6/12 = 3.5 વર્ષ લેવું. બને તેટલા સરળ અપૂર્ણાંકમાં રાખો.
  • CI માં n ની કિંમત: 'વાર્ષિક' હોય તો n = T; 'અડધાવાર' હોય તો n = 2T; 'ત્રિમાસિક' હોય તો n = 4T. n ની યોગ્ય કિંમત લેવી.
  • SI અને CI નો તફાવત: CI - SI માટેનું સૂત્ર = P(R/100)^v ફક્ત v ≥ 2 માટે જ ચાલે. v = 1 હોય તો SI અને CI સames જ હોય છે → તફાવત = 0.
  • મૂડી શોધવામાં ભૂલ: SI = PRT/100 → P = (SI × 100)/(R × T). ક્યારેક વિદ્યાર્થીઓ P × R × T = SI × 100 લખી નાખે છે; ધ્યાન રાખો: P = SI × 100 ÷ (R × T).
  • ચક્રવૃદ્ધિમાં 'કુલ મૂડી' (Amount) અને 'ચક્રવૃદ્ધિ વ્યાજ' (CI) વચ્ચેનો તફાવત: A ≠ CI. A = P + CI. પ્રશ્ન માંગે છે તો બંનેમાં ફેરફાર થાય છે.
  • અડધાવાર / ત્રિમાસિકમાં દર બદલાય છે, પણ સમય નહીં: આ રીતે પ્રશ્નોમાં R/2 અથવા R/4 લેવાનો છે, પણ T બદલાતું નથી – n બદલાય છે. ઘણા વિદ્યાર્થીઓ R/2 અને n = T જ કરી દે છે, જે ખોટું છે.
  • ઋણ વ્યાજદરનો ભય: પ્રશ્નોમાં 'ઋણ વ્યાજ' ક્યારેય આપતું નથી, પણ જો R < 0 હોય તો પણ SI = PRT/100 અને A = P(1+R/100)^n લાગુ પડે; અહીં 'ઋણ' ન હોય તે જોઈને ગણતરી કરવી.
  • પરીક્ષામાં વિકલ્પોમાંથી ગણતરી કરવાની ભૂલ: કેટલાક પ્રશ્નોમાં SI ≈ CI હોય અને વિદ્યાર્થીઓ 'સાર્વત્રિક' વિકલ્પની પસંદગી કરે. દરેક પ્રશ્ન માટે આપેલી સંખ્યાઓને ચકાસી જોવી.
