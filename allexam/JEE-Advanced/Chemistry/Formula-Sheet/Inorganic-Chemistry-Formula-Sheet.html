JEE AdvancedEnglishFormula Sheet
BE = (N + C)/2

Symbols: BE = Bond Order, N = number of electrons in molecular orbitals (bonding minus antibonding), C = number of covalent bonds

Unit: dimensionless

When to use: Bond order calculation from MO theory; BE > 0 implies stable molecule, BE = 0 implies no bond formed

Conditions: Applies to diatomic and polyatomic species using MO diagram method

Common mistake: Counting electrons in antibonding MOs as positive — they must be subtracted

IP = hν₀ = hc/λ₀

Symbols: IP = ionization potential (energy), h = Planck's constant, ν₀ = threshold frequency, λ₀ = threshold wavelength

Unit: Joules or eV (1 eV = 96.485 kJ/mol)

When to use: Calculating ionization energy from photoelectric data or wavelength; interconversion between Rydberg units and eV

Conditions: Valid for hydrogen-like atoms where IEₙ = 13.6 Z²/n² eV

Common mistake: Forgetting that IE of He⁺ uses Z=2, not Z=1; confusing wavelength in Å with SI units

rₙ = 0.529 n²/Z Å (Bohr radius)

Symbols: rₙ = orbital radius, n = principal quantum number, Z = atomic number

Unit: Angstrom (Å) or pm

When to use: Calculating orbital radii and comparing sizes of H-like species (H, He⁺, Li²⁺)

Conditions: Only valid for one-electron (hydrogen-like) systems

Common mistake: Applying to multi-electron atoms without screening correction; confusing with empirical atomic radii

Eₙ = -13.6 Z²/n² eV

Symbols: Eₙ = energy of nth orbit, Z = nuclear charge, n = principal quantum number

Unit: eV or kJ/mol

When to use: Energy of electron in H-like atoms; transition energy ΔE = 13.6 Z²(1/n₁² - 1/n₂²)

Conditions: Hydrogen-like (one electron) species only

Common mistake: Sign errors when computing ΔE for emission vs absorption; forgetting Z² factor for ions

μ_s = √[n(n+2)] BM

Symbols: μ_s = spin-only magnetic moment, n = number of unpaired electrons, BM = Bohr Magneton

Unit: Bohr Magneton (BM)

When to use: Magnetic moment of transition metal complexes from unpaired electrons; identifying high-spin vs low-spin

Conditions: Neglects orbital contribution; valid for 3d series where orbital contribution is largely quenched

Common mistake: Using total electrons instead of unpaired electrons; applying to 4d/5d without considering orbital contribution

μ_eff = √[4S(S+1) + L(L+1)] BM

Symbols: μ_eff = effective magnetic moment, S = total spin quantum number, L = total orbital quantum number

Unit: Bohr Magneton (BM)

When to use: When orbital contribution is significant (e.g., first-row transitions with unquenched L, Gd³⁺, Dy³⁺)

Conditions: More accurate than spin-only; needed for ions with non-zero L where spin-orbit coupling matters

Common mistake: Assuming spin-only always applies — fails for Gd³⁺ (S=7/2, L=0 actually works) but fails for Tb³⁺, Dy³⁺

CFSE = [-0.4x + 0.6y]Δₒ (octahedral); [-0.6x + 0.4y]Δₜ (tetrahedral)

Symbols: CFSE = Crystal Field Stabilization Energy, x = #electrons in t₂g, y = #in eg (oct); Δₒ = octahedral splitting, Δₜ ≈ 4/9 Δₒ

Unit: cm⁻¹ or kJ/mol or Δₒ units

When to use: Comparing stability of high-spin vs low-spin configurations; explaining Irving-Williams series

Conditions: For octahedral and tetrahedral fields; add P (pairing energy) if pairing occurs beyond Hund's rule

Common mistake: Forgetting pairing energy penalty when comparing HS vs LS; using wrong sign convention

Δₜ ≈ (4/9)Δₒ

Symbols: Δₜ = tetrahedral crystal field splitting, Δₒ = octahedral crystal field splitting

Unit: same as Δₒ (cm⁻¹)

When to use: Explaining why tetrahedral complexes are almost always high-spin (Δₜ < P for almost all 3d metals)

Conditions: Approximation; holds for same metal, same ligand, similar geometry comparisons

Common mistake: Using Δₜ = Δₒ/2; confusing with square planar splitting which is different

f = 2S + 1 (Spin multiplicity)

Symbols: f = spin multiplicity, S = total spin quantum number (= sum of individual ms values)

Unit: dimensionless

When to use: Determining term symbols; identifying ground state multiplicity using Hund's rules

Conditions: S = Σms for all unpaired electrons; used with L to write terms like ²D, ⁵D

Common mistake: Using number of electrons instead of total spin S; confusing multiplicity with number of unpaired electrons

d¹/d⁹: E₁(E_g) = -0.6Δₒ, E₂(T₂g) = -0.4Δₒ ; d⁴(donor): E₁ = +0.6Δₒ, E₂ = -0.4Δₒ

Symbols: E₁, E₂ = energies of electronic transitions in Tanabe-Sugano diagrams for d¹ and high-spin d⁴ octahedral

Unit: cm⁻¹ or Δₒ units

When to use: Assigning UV-Vis absorption bands for d¹ (e.g., Ti³⁺) and d⁴ (e.g., Cr²⁺) octahedral complexes

Conditions: Only for weak-field (high-spin) octahedral d¹ and d⁴; single transition band observed

Common mistake: Applying to low-spin d⁴ or other configurations where multiple transitions occur

ns²np¹⁻⁶ : Octet rule ; ns² : Inert pair effect (heavy p-block)

Symbols: ns, np = valence shell orbitals; inert pair effect strongest in Tl, Pb, Bi

Unit: qualitative concept

When to use: Predicting stable oxidation states; explaining why Tl⁺ more stable than Tl³⁺, Pb²⁺ more stable than Pb⁴⁺

Conditions: Increases down a group; greatest for 6p elements (Tl, Pb, Bi)

Common mistake: Applying to 3rd period elements where inert pair effect is negligible

Fajan's Rules: Covalent character ∝ (small cation size, large anion size, high cation charge, pseudo-noble config)

Symbols: Polarizing power ∝ charge/radius; Polarizability ∝ size/electron cloud looseness

Unit: qualitative trend

When to use: Predicting ionic vs covalent character; explaining solubility, melting point deviations

Conditions: Applies to bonds with partial covalent character; Be²⁺, Al³⁺ show maximum polarization

Common mistake: Forgetting that Cu⁺ (18e⁻) polarizes more than K⁺ (8e⁻) despite same charge and similar size

Pauling electronegativity: χ_A-B = (χ_A + χ_B)/2 + 0.18|χ_A - χ_B|

Symbols: χ = electronegativity; bond polarity increases with |χ_A - χ_B|

Unit: Pauling scale (dimensionless)

When to use: Estimating ionic character % = 1 - exp[-0.25(χ_A-χ_B)²] × 100

Conditions: Empirical; most useful for main group compounds

Common mistake: Using to predict exact bond type; it's a guide, not a law

VSEPR: Steric No. = (V + M - C + A)/2 ; lone pairs = SN - bond pairs

Symbols: V = valence electrons of central atom, M = monovalent atoms attached, C = cation charge, A = anion charge

Unit: dimensionless count

When to use: Predicting molecular geometry: SN=2 linear, 3 trigonal planar/pyramidal, 4 tetrahedral/pyramidal/bent, 5 trigonal bipyramidal, 6 octahedral/seesaw

Conditions: Works well for main group hydrides/halides; less reliable for transition metal complexes

Common mistake: Counting double bonds as one 'M'; forgetting to adjust for charge on ion

SN = 5 (TBP): ax-bx repulsion > eq-eq > ax-eq ; lone pair occupies equatorial position

Symbols: ax = axial, eq = equatorial positions in trigonal bipyramidal geometry

Unit: qualitative

When to use: Predicting structure of PCl₅, SF₄, ClF₃, XeF₂; lone pairs prefer equatorial to minimize 90° repulsions

Conditions: Applies to molecules with steric number 5

Common mistake: Placing lone pair at axial position; forgetting that 90° interactions dominate geometry choice

Bent's Rule: More s-character in orbital directed toward electropositive substituent

Symbols: s-character distributes unevenly based on substituent electronegativity

Unit: qualitative trend

When to use: Explaining bond angles in molecules like CH₃F, SF₄, XeO₃F₂; more EN substituent → less s-character in that bond

Conditions: Complements VSEPR; most useful when VSEPR alone gives ambiguous predictions

Common mistake: Confusing with hybridization conservation — total s + p + d must still equal available orbitals

λ = h/mv = h/p (De Broglie wavelength)

Symbols: λ = wavelength, h = Planck's constant, m = mass, v = velocity, p = momentum

Unit: meters (SI)

When to use: Wave-particle duality calculations; electron microscopy principle

Conditions: Applies to all matter; significant only for microscopic particles

Common mistake: Using relativistic mass when v approaches c; forgetting to convert mass to kg

Δx · Δp ≥ h/4π (Heisenberg uncertainty)

Symbols: Δx = uncertainty in position, Δp = uncertainty in momentum, h = Planck's constant

Unit: J·s (same as h)

When to use: Quantum mechanical foundation; explains why orbits don't exist (only orbitals)

Conditions: Fundamental limit, not measurement error; applies universally

Common mistake: Treating it as experimental limitation rather than fundamental principle

IUPAC Oxidation State: OS = charge after removing ligands as their closed-shell ions

Symbols: Ligands removed as: Cl⁻, Br⁻, I⁻, O²⁻, S²⁻, H⁻ (hydride), NH₃ (neutral), H₂O (neutral)

Unit: integer (positive/negative/zero)

When to use: Naming coordination compounds; determining metal oxidation state in complexes

Conditions: Standard IUPAC convention; remember H in metal hydrides is -1, not +1

Common mistake: Treating NH₃ or H₂O as charged ligands; forgetting peroxo (O₂²⁻) and superoxo (O₂⁻) give different OS

Effective Atomic Number (EAN) = Z - OS + 2×CN

Symbols: Z = atomic number of metal, OS = oxidation state, CN = coordination number

Unit: dimensionless (electron count)

When to use: 18-electron rule check for stability; EAN = noble gas config implies extra stability

Conditions: Most applicable to low-spin d⁶ octahedral carbonyls and nitrosyls; many real complexes violate it

Common mistake: Forgetting that CN counts donor pairs (each CO = 2e, each Cl⁻ = 2e); confusing with total valence electrons

Werner's Coordination: Primary (ionizable, = OS) + Secondary (non-ionizable, = CN)

Symbols: Primary valency satisfied by anions outside coordination sphere; secondary by ligands inside

Unit: qualitative

When to use: Writing structural formulas of coordination compounds; distinguishing ionizable vs non-ionizable halides

Conditions: Foundation of coordination chemistry; modern notation uses square brackets for coordination sphere

Common mistake: Confusing which halides precipitate with AgNO₃ — only those outside the bracket do

Isomerism in Coordination Compounds: Structural (ionization, hydrate, linkage, coordination) + Stereo (geometrical, optical)

Symbols: Ionization: exchange of ligand and counter ion; Hydrate: water inside vs outside sphere; Linkage: ambidentate ligand binding through different atom; Geometrical: cis/trans or fac/mer

Unit: qualitative classification

When to use: Identifying all possible isomers for a given complex formula

Conditions: Square planar [Ma₂b₂]: cis/trans only; Octahedral [Ma₄b₂]: cis/trans; [Ma₃b₃]: fac/mer; [M(ab)₃] type: optical active

Common mistake: Thinking square planar complexes show optical isomerism (they don't, due to plane of symmetry)

Ambidentate ligands: NO₂⁻ (nitro-N / nitrito-O), SCN⁻ (thiocyanato-S / isothiocyanato-N), CN⁻ (cyano-C / isocyano-N)

Symbols: Linkage isomerism occurs when ambidentate ligand binds through different donor atoms

Unit: qualitative

When to use: Writing linkage isomers; [Co(NH₃)₅(NO₂)]²⁺ (red, nitro) vs [Co(NH₃)₅(ONO)]²⁺ (yellow, nitrito)

Conditions: Both isomers must be isolable; hard/soft acid-base theory predicts binding preference

Common mistake: Confusing linkage isomerism with ionization isomerism

Hard-Soft Acid-Base (HSAB): Hard-hard and soft-soft combinations are more stable

Symbols: Hard acids: H⁺, Na⁺, Al³⁺, BF₃; Soft acids: Ag⁺, Pt²⁺, Hg²⁺; Hard bases: F⁻, H₂O, NH₃; Soft bases: I⁻, CO, PR₃

Unit: qualitative principle

When to use: Predicting stability of complexes; solubility trends (AgF soluble, AgI insoluble); biological metal transport

Conditions: Guideline, not a law; enthalpy-driven for hard-hard, covalent for soft-soft

Common mistake: Using HSAB to predict kinetics rather than thermodynamics; it explains stability, not reaction rates

Crystal Field Theory: e_g set raises by +0.4Δₒ, t₂g set lowers by -0.4Δₒ (octahedral); reverse for tetrahedral

Symbols: e_g = dₓ²₋ᵧ², d_z²; t₂g = d_xy, d_yz, d_xz; center of gravity preserved

Unit: cm⁻¹ or energy units

When to use: Calculating CFSE; predicting color, magnetism, geometry of transition metal complexes

Conditions: Pure electrostatic model; neglects covalent character captured by LFT

Common mistake: Forgetting that total energy change sums to zero (3×(-0.4) + 2×(+0.4) = 0)

Spectrochemical Series: I⁻ < Br⁻ < S²⁻ < SCN⁻ < Cl⁻ < NO₃⁻ < F⁻ < OH⁻ < C₂O₄²⁻ < H₂O < NCS⁻ < CH₃CN < NH₃ < en < bipy < phen < NO₂⁻ < PPh₃ < CN⁻ < CO

Symbols: Left = weak field (high-spin preferred); Right = strong field (low-spin preferred) for 3d metals

Unit: qualitative ordering

When to use: Predicting high-spin vs low-spin; Δₒ magnitude; color shifts in complexes

Conditions: Series is approximate; ordering can shift slightly with different metal/oxidation state

Common mistake: Forgetting that CO and CN⁻ are the strongest field ligands; misplacing H₂O vs NH₃

Irving-Williams Series (divalent 3d M²⁺): Mn²⁺ < Fe²⁺ < Co²⁺ < Ni²⁺ < Cu²⁺ > Zn²⁺

Symbols: Stability of complexes increases to Cu²⁺ then drops for Zn²⁺

Unit: qualitative stability trend

When to use: Comparing formation constants of M²⁺ complexes with same ligand; explains why Cu²⁺ forms most stable 3d complexes

Conditions: Applies to end-on ligands (not macrocyclic); reflects combination of ΔH_CFSE + ionic size trend

Common mistake: Including Zn²⁺ in the increasing part — it has zero CFSE so stability drops sharply

Moses' Rule / Fajan's: Small highly charged cation + large polarizable anion → covalent character ↑

Symbols: Polarizing power ∝ Z⁺/r⁺; Polarizability ∝ r⁻/electron count

Unit: qualitative

When to use: Explaining why BeCl₂ is covalent (polymeric), AlCl₃ exists as dimer, SnCl₄ is liquid while SiCl₄ hydrolyzes readily

Conditions: Useful for p-block halides and comparing ionic/covalent character within a group

Common mistake: Applying to transition metals where CFSE dominates over polarization effects

Lanthanoid Contraction: Decrease in M³⁺ radius across La→Lu ≈ 1 pm per element (total ~15 pm)

Symbols: Caused by poor shielding of 4f electrons; affects all subsequent elements in periodic table

Unit: pm (picometers)

When to use: Explaining Zr-Hf, Nb-Ta, Mo-W similarity; density increase in 5d series; affecting basicity of hydroxides

Conditions: Most significant for post-lanthanide elements; also affects 5d vs 4d transition metals

Common mistake: Thinking it affects lanthanoid chemistry itself primarily — main consequence is on 5d elements

Basic strength of M(OH)₃ (lanthanoids): La(OH)₃ > ... > Lu(OH)₃ (decreases across series)

Symbols: Larger M³⁺ → more ionic M-O bond → stronger base; smaller M³⁺ → more covalent → weaker base

Unit: qualitative trend

When to use: Separation of lanthanoids by fractional precipitation; explaining solubility differences

Conditions: Applies to trivalent hydroxides; opposite trend for fluoride solubility (CeF₄ least soluble)

Common mistake: Reversing the trend; larger lanthanoid = stronger base, not weaker

Zeise's Salt: K[PtCl₃(C₂H₄)]·H₂O ; μ-backbonding: Pt→C₂H₄ π* donation strengthens M-C bond

Symbols: Pt oxidation state = +2; C₂H₄ is η²-coordinated through π electrons

Unit: qualitative

When to use: Example of π-acid ligand bonding; foundational organometallic compound

Conditions: Requires d⁸ metal with filled dπ orbitals for back-donation

Common mistake: Thinking C₂H₄ bonds through σ-donation only; the π-backbond is essential for stability

18-Electron Rule: Stable organometallics often have 18 valence e⁻ around metal

Symbols: Count: metal group no. + ligand e⁻ donation + charge; CO=2e, Cl=2e, H=1e, Cp=5e, C₂H₄=2e

Unit: electron count

When to use: Predicting stability of metal carbonyls, ferrocene, metal clusters

Conditions: Works best for low-spin d-block complexes with strong π-acceptor ligands; many exceptions exist

Common mistake: Counting Cp as 6e (it's 5e); forgetting that neutral Fe in Fe(CO)₅ contributes 8e

Ferrocene: Fe(C₅H₅)₂ ; Fe²⁺ (d⁶) + 2 Cp⁻ (6e each) = 18e⁻ ; sandwich structure, aromatic

Symbols: Fe oxidation state +2; each η⁵-C₅H₅⁻ donates 6 electrons; total = 8 + 6 + 6 = 20? No — Fe(0)d⁸ + 2×Cp•(5e) = 18e

Unit: qualitative

When to use: Classic metallocene; undergoes electrophilic substitution (acetylation, Friedel-Crafts) on ring

Conditions: 18e rule satisfied; Cp rings can rotate freely (fluxional behavior)

Common mistake: Getting Fe oxidation state wrong in ferrocene derivatives; confusing hapticity

Nickel Carbonyl: Ni(CO)₄ ; tetrahedral, sp³, diamagnetic, 18e⁻ (Ni⁰ d¹⁰ + 4×2e from CO)

Symbols: Ni oxidation state = 0; Mond process purification relies on this compound's volatility

Unit: qualitative

When to use: Mond process for nickel purification; example of metal carbonyl with zero oxidation state

Conditions: Toxic, pyrophoric; decomposes at ~180°C to deposit pure Ni

Common mistake: Thinking Ni is +2 in Ni(CO)₄; CO is neutral ligand so Ni remains 0

Brown Ring Test: [Fe(H₂O)₅(NO)]²⁺ ; Fe²⁺ + NO → Fe(NO)²⁺ (brown); NO acts as 3e⁻ donor (NO⁺ formalism)

Symbols: Iron oxidation state: Fe(I) formally (d⁷) or Fe(II)-NO⁺ description; nitrosyl ligand is linear

Unit: qualitative

When to use: Detecting nitrate ions; classic qualitative analysis test

Conditions: Freshly prepared FeSO₄ required; concentrated H₂SO₄ added carefully along wall

Common mistake: Not knowing whether Fe is +1 or +2; the NO⁺ formalism gives Fe(I)d⁷, while neutral NO gives Fe(II)d⁶

Permanganate titration: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O (E° = +1.51 V) in acidic medium

Symbols: n-factor of KMnO₄ in acid = 5; in neutral/weak alkaline: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻ (n=3)

Unit: standard electrode potential

When to use: Redox titrations (Mohr's salt, Fe²⁺, oxalate, H₂O₂); calculating equivalent weight = Molar mass/5

Conditions: Must use H₂SO₄ not HCl (Cl⁻ gets oxidized) or HNO₃ (oxidizing itself)

Common mistake: Using HCl with KMnO₄ — Cl⁻ is oxidized to Cl₂, giving wrong titre; or using HNO₃ which is itself an oxidant

Potassium Dichromate: Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O (E° = +1.33 V); n-factor = 6

Symbols: K₂Cr₂O₇ is primary standard; equivalent weight = Molar mass/6

Unit: standard electrode potential

When to use: Redox titrations (Mohr's salt, Fe²⁺); iodometric estimation of oxidizing agents

Conditions: Can use HCl medium (unlike KMnO₄); orange → green color change

Common mistake: Forgetting that dichromate in alkaline converts to chromate (yellow); wrong n-factor in basic medium

Wagner's Thermite: Fe₂O₃ + 2Al → 2Fe + Al₂O₃ + heat (ΔH very negative, exothermic)

Symbols: Al is stronger reducing agent than Fe at high temperature; Ellingham diagram confirms ΔG crosses zero

Unit: qualitative (highly exothermic)

When to use: Welding railway tracks; reduction of metal oxides where metal is less reactive than Al

Conditions: Requires ignition mixture (Mg strip + KClO₃); reaction self-sustains once started

Common mistake: Thinking any metal oxide can be reduced by Al — only those below Al in Ellingham diagram

Ellingham Diagram: ΔG vs T; lower ΔG line = more stable oxide; crossover point = reduction temperature

Symbols: Slope = -ΔS; C(s) + O₂ → CO₂ has near-zero slope; 2C + O₂ → 2CO has negative slope

Unit: kJ/mol O₂

When to use: Predicting feasibility of metallurgical reductions; choosing reducing agent for ore extraction

Conditions: Only thermodynamically valid; kinetics may prevent reaction even when ΔG < 0

Common mistake: Reading ΔG directly without considering per mole O₂ basis; confusing with ΔH diagram

Bergius Process: C(s) + H₂O(g) → CO + H₂ (water gas); then CO + 3H₂ → CH₄ + H₂O (methanation)

Symbols: High pressure (200-300 atm), catalyst (Ni/Fe); produces synthetic natural gas

Unit: qualitative industrial process

When to use: Coal liquefaction; producing hydrocarbon fuels from coal

Conditions: Requires high temp and pressure; iron oxide catalyst initially, then switched to Ni

Common mistake: Confusing with Haber process conditions; different catalyst and purpose

Contact Process: 2SO₂ + O₂ ⇌ 2SO₃ (V₂O₅ catalyst, 450°C, 1-2 atm); SO₃ + H₂SO₄ → H₂S₂O₇ (oleum)

Symbols: V₂O₅ reduced to V₂O₄ by SO₂, then reoxidized by O₂; actual active species is vanadyl pyrosulfate

Unit: qualitative industrial process

When to use: Manufacturing H₂SO₄ (most produced chemical worldwide); key intermediate is oleum

Conditions: Moderate temp (compromise between rate and equilibrium); excess O₂ shifts equilibrium right

Common mistake: Dissolving SO₃ directly in water — causes violent mist formation; must absorb in conc. H₂SO₄ first

Haber Process: N₂ + 3H₂ ⇌ 2NH₃ (Fe catalyst, 450°C, 200 atm); ΔH = -92 kJ/mol

Symbols: Promoters: K₂O, MoO₃, SiO₂; Fe provides surface for N₂ dissociation (rate-determining step)

Unit: qualitative industrial process

When to use: NH₃ manufacture for fertilizers; Le Chatelier principle application (high P favors product)

Conditions: High pressure favors yield but expensive; moderate temp compromises rate vs equilibrium

Common mistake: Thinking very high temp improves yield — it actually decreases equilibrium yield (exothermic)

Ostwald Process: 4NH₃ + 5O₂ → 4NO + 6H₂O (Pt-Rh gauze, 800°C); 2NO + O₂ → 2NO₂; 3NO₂ + H₂O → 2HNO₃ + NO

Symbols: Pt-Rh alloy catalyst (pure Pt softens at high temp); NO recycled

Unit: qualitative industrial process

When to use: HNO₃ manufacture; nitrogen fixation for fertilizers and explosives

Conditions: First step is rate-limiting; high temp needed for kinetics despite exothermic overall

Common mistake: Forgetting that NO is a by-product recycled back; writing wrong stoichiometry for NO₂ absorption

Downs Cell: Molten NaCl + CaCl₂ (lowering mp to ~600°C); Na⁺ + e⁻ → Na(l) at cathode; 2Cl⁻ → Cl₂ + 2e⁻ at anode

Symbols: Na collected under oil; Fe gauze separator prevents Na-Cl₂ recombination; Ca formed but stays molten

Unit: qualitative electrolytic process

When to use: Commercial Na and Cl₂ production; why CaCl₂ is added (melting point depression)

Conditions: Must keep Na and Cl₂ separated — they react explosively if mixed

Common mistake: Expecting Ca to deposit at cathode — Na⁺ discharges preferentially despite Ca being more reactive (concentration effect)

Hall-Héroult Process: Al₂O₃ + 3C → 2Al + 3CO (cryolite Na₃AlF₆ solvent, 950°C, graphite electrodes)

Symbols: Cathode: Al³⁺ + 3e⁻ → Al(l); Anode: 2O²⁻ + C → CO₂ + 4e⁻ (graphite consumed)

Unit: qualitative electrolytic process

When to use: Commercial aluminium production; cryolite lowers mp from 2072°C to ~950°C and increases conductivity

Conditions: Bauxite purified to Al₂O₃ (Hall's process) before electrolysis; anodes consumed continuously

Common mistake: Thinking AlCl₃ is electrolyzed — it's covalent and doesn't conduct; must use oxide in cryolite

Bessemer Converter: Pig iron + silica + air → steel; Si, Mn, C oxidized first; P removed as Ca₃(PO₄)₂ slag

Symbols: Air blown from bottom; exothermic oxidation maintains molten state; process ~20-30 min

Unit: qualitative metallurgical process

When to use: Steel manufacture from cast iron; removing impurities (Si, P, C) by oxidation

Conditions: Cannot remove S (acidic lining); lined with acidic silica — basic slags can't be used

Common mistake: Thinking Bessemer can produce high-quality steel throughout — carbon control is difficult, later replaced by open hearth/EAF

Zone Refining: Impure rod rotated under induction heater; impurities concentrate in molten zone; repeated passes → ultra-pure metal

Symbols: Based on difference in solubility of impurity in solid vs liquid phase (k = C_s/C_l ≠ 1)

Unit: qualitative purification technique

When to use: Semiconductor grade Si, Ge, In, Ga purification to 99.9999%+

Conditions: Effective only when k ≠ 1; best for impurities present in small amounts

Common mistake: Thinking it removes all impurities equally — those with k≈1 are hardest to remove

van Arkel-de Boer Process: Impure Ti + 2I₂ → TiI₄(g); TiI₄(g) → Ti(pure) + 2I₂ (on W filament at ~1500K)

Symbols: Volatilization followed by thermal decomposition; iodide intermediate transports Ti

Unit: qualitative purification technique

When to use: Producing ultra-pure Ti, Zr, Hf, Th; also used for Cr, Nb

Conditions: Metal must form volatile iodide that decomposes at higher temperature

Common mistake: Confusing with Mond process for Ni — same principle but different metal and temperature

Amylodextrin test for starch: I₂/KI → blue complex (helical amylose traps I₃⁻);加热褪色，冷却复原

Symbols: I₃⁻ ions fit inside amylose helix; charge-transfer interaction causes blue color

Unit: qualitative analytical test

When to use: Detecting starch; demonstrating carbohydrate structure

Conditions: Cold solution gives blue; heating breaks helix → colorless; cooling restores

Common mistake: Thinking it's a chemical reaction — it's actually an inclusion complex (physical)

Nessler's Reagent: K₂HgI₄ (alkaline); detects NH₃/NH₄⁺ → brown precipitate (Nessler's base: Hg₂NI·H₂O)

Symbols: HgI₄²⁻ + NH₃ + OH⁻ → Hg₂NI·H₂O (brown) + I⁻ + H₂O

Unit: qualitative analytical test

When to use: Detecting trace ammonia in water/soil; confirming NH₄⁺ in qualitative analysis

Conditions: Must be alkaline; interfering ions: heavy metal cations, sulfide

Common mistake: Using acidic medium — reaction won't proceed; confusing with Tollens' reagent (both contain Hg/Ag)

Tollens' Reagent: [Ag(NH₃)₂]⁺ (ammoniacal AgNO₃); R-CHO → R-COO⁻ + Ag(s) (silver mirror)

Symbols: Ag⁺ reduced to Ag⁰; aldehyde oxidized to carboxylate; ketones do not react (except α-hydroxy ketones)

Unit: qualitative analytical test

When to use: Distinguishing aldehydes from ketones; reducing sugar test

Conditions: Must be freshly prepared; AgNH₂ (fulminating silver) explosive if allowed to dry

Common mistake: Using old Tollens' reagent — forms explosive Ag₃N; confusing with Fehling's (Cu²⁺ based, only for aliphatic aldehydes)

Fehling's Test: Cu²⁺ (tartrate complex, alkaline) + R-CHO → Cu₂O (red ppt) + R-COOH

Symbols: Fehling A: CuSO₄; Fehling B: KOH + NaK tartrate; mixed before use

Unit: qualitative analytical test

When to use: Distinguishing aliphatic aldehydes (positive) from aromatic aldehydes (negative) and ketones

Conditions: Only aliphatic aldehydes reduce Fehling's; aromatic aldehydes and ketones don't (except α-hydroxy)

Common mistake: Thinking all aldehydes give positive Fehling's — benzaldehyde does NOT

Lucas Test: R-OH + HCl(anhy.) + ZnCl₂ → R-Cl + H₂O; turbidity appearance time: 3° < 2° < 1°

Symbols: ZnCl₂ is Lewis acid catalyst; carbocation stability determines rate: 3° > 2° > 1°

Unit: qualitative analytical test

When to use: Distinguishing 1°, 2°, 3° alcohols by rate of SN1 substitution

Conditions: Room temp; tert-butanol immediate turbidity, secondary ~5 min, primary no reaction at RT

Common mistake: Applying to phenols (don't react) or allylic/benzylic alcohols (react fast due to stable carbocation)

Iodoform Test: CH₃CO- or CH₃CH(OH)- + I₂/NaOH → CHI₃ (yellow ppt) + carboxylate

Symbols: Requires methyl ketone (CH₃-C=O) or methyl carbinol (CH₃-CH-OH); I₂ in NaOH generates NaOI (hypoiodite)

Unit: qualitative analytical test

When to use: Detecting acetaldehyde, acetone, ethanol, isopropanol, methyl ketones

Conditions: Negative for methanol, primary alcohols without CH₃CH(OH)-, all ketones without CH₃CO-

Common mistake: Thinking all alcohols give iodoform — only ethanol and secondary alcohols with CH₃CH(OH)- group

Carius Method: Organic compound + fuming HNO₃ + AgNO₃ → AgX ppt; halogen % = (108×wtAgX×100)/(AgX_mw×wt_sample)

Symbols: X = halogen; AgX = AgCl/AgBr/AgI; 108 = atomic mass of Ag

Unit: percentage calculation

When to use: Quantitative estimation of halogen in organic compound

Conditions: Must oxidize all halogen to halide; AgI soluble in excess NH₄OH (distinguishes from AgCl/AgBr)

Common mistake: Forgetting to account for molecular weight of AgX in denominator; using wrong atomic mass

Duma's Method: N in organic compound → N₂ gas (collected over KOH); %N = (28×V_N₂×100)/(22400×wt_sample) (STP)

Symbols: V_N₂ = volume of N₂ at STP; 28 = M(N₂); 22400 = molar volume at STP

Unit: percentage calculation

When to use: Quantitative estimation of nitrogen in organic compounds

Conditions: Compound must contain only C,H,N,O,X; nitrogen converts to N₂ gas

Common mistake: Not correcting for water vapor pressure if collected over water; using wrong molar volume

Kjeldahl's Method: N → NH₄⁺ (H₂SO₄ digestion) → NH₃ (distilled with NaOH) → absorbed in excess HCl → back-titrated

Symbols: %N = (M₁V₁-HCl_excess × M₂V₂-NaOH × 14 × 100) / (wt_sample × 1000)

Unit: percentage calculation

When to use: Estimating N in proteins, fertilizers, organic compounds (NOT in nitro, azo, heterocyclic N)

Conditions: Fails for N in -NO₂, -N=N-, pyridine, etc. (these N not converted to NH₄⁺ by H₂SO₄)

Common mistake: Applying to all nitrogen compounds — nitro and azo compounds give incorrect results

Hund's Rules: (1) Maximize S (maximum multiplicity); (2) For same S, maximize L; (3) J = |L-S| for <半满, J=L+S for >半满

Symbols: Rule 1: highest spin multiplicity lowest energy; Rule 2: largest L for that S; Rule 3: ground state J value

Unit: quantum numbers (S, L, J)

When to use: Determining ground state term symbol for dⁿ configurations (e.g., d⁵: ⁶S_{3/2}, d⁸: ³F₄)

Conditions: Applies to free ions; spin-orbit coupling determines J splitting

Common mistake: Applying Rule 3 incorrectly — remember: less than half-filled → minimum J, more than half → maximum J

Mossbauer Effect:⁵⁷Fe γ-resonance absorption; isomer shift δ relates to s-electron density at nucleus; quadrupole splitting reveals electric field gradient

Symbols: δ = [(rs²-rd²)/rs²] × constant; ΔE_Q = eQV_zz/2 × √(1+η²/3)

Unit: mm/s (velocity scale)

When to use: Determining Fe oxidation state, spin state, symmetry in coordination compounds and minerals

Conditions: Requires Mössbauer-active nucleus (⁵⁷Fe, ¹¹⁹Sn, ¹²¹Sb); sample usually at cryogenic temps

Common mistake: Confusing isomer shift with quadrupole splitting; IS gives oxidation/spin state, QS gives symmetry

Jahn-Teller Theorem: Non-linear molecule in degenerate electronic state undergoes geometric distortion to remove degeneracy

Symbols: Strong distortion: d⁹ (Cu²⁺), high-spin d⁴ (Cr²⁺); weak: low-spin d⁷ (Co²⁺); absent: d³, d⁸ octahedral (regular)

Unit: qualitative prediction

When to use: Explaining elongated/compressed octahedra; EPR spectra of Cu²⁺; color splitting in d⁹ complexes

Conditions: Only for electronically degenerate states (E or T terms); d³ and d⁸ have ⁴A₂g ground term (no JT)

Common mistake: Applying to all octahedral complexes — only those with asymmetrically filled eg or t₂g sets show JT distortion
