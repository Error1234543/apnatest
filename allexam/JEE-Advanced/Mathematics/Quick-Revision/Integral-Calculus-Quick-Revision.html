Definitions

  • Antiderivative (Indefinite Integral): A function F(x) such that F'(x) = f(x) for all x in an interval. Written as ∫f(x)dx = F(x) + C, where C is an arbitrary constant called the constant of integration.
  • Definite Integral: The limit of a Riemann sum ∫ₐᵇ f(x)dx = lim(n→∞) Σᵢ f(xᵢ*)Δx, representing the net signed area between the curve y = f(x), the x-axis, and the vertical lines x = a and x = b.
  • Fundamental Theorem of Calculus (Part 1): If f is continuous on [a,b] and F(x) = ∫ₐˣ f(t)dt, then F'(x) = f(x). This establishes the inverse relationship between differentiation and integration.
  • Fundamental Theorem of Calculus (Part 2): If f is continuous on [a,b] and F is any antiderivative of f, then ∫ₐᵇ f(x)dx = F(b) - F(a). Used to evaluate definite integrals without computing limits of sums.
  • Improper Integral: An integral where either the interval of integration is infinite or the integrand has an unbounded discontinuity within the interval. Evaluated as a limit: e.g., ∫ₐ^∞ f(x)dx = lim(t→∞) ∫ₐᵗ f(x)dx.
  • Leibniz Rule for Differentiation Under the Integral Sign: If F(x) = ∫_{g(x)}^{h(x)} f(x,t)dt, then dF/dx = f(x,h(x))·h'(x) - f(x,g(x))·g'(x) + ∫_{g(x)}^{h(x)} ∂f/∂x dt. Critical for JEE Advanced problems.
  • Beta Function: B(m,n) = ∫₀¹ x^{m-1}(1-x)^{n-1}dx = Γ(m)Γ(n)/Γ(m+n), defined for m>0, n>0. Essential for evaluating certain definite integrals of algebraic forms.
  • Gamma Function: Γ(n) = ∫₀^∞ x^{n-1}e^{-x}dx, defined for n>0. Key properties: Γ(n+1) = nΓ(n), Γ(n) = (n-1)! for positive integers, Γ(1/2) = √π.

Key concepts

  • Memorise and apply these without fail — JEE Advanced frequently combines several in one problem:

    • ∫x^n dx = x^{n+1}/(n+1) + C, n ≠ -1
    • ∫(1/x) dx = ln|x| + C
    • ∫e^x dx = e^x + C
    • ∫a^x dx = a^x/ln(a) + C, a > 0, a ≠ 1
    • ∫sin x dx = -cos x + C; ∫cos x dx = sin x + C
    • ∫sec²x dx = tan x + C; ∫csc²x dx = -cot x + C
    • ∫sec x tan x dx = sec x + C; ∫csc x cot x dx = -csc x + C
    • ∫tan x dx = ln|sec x| + C; ∫cot x dx = ln|sin x| + C
    • ∫sec x dx = ln|sec x + tan x| + C; ∫csc x dx = ln|csc x - cot x| + C
    • ∫dx/√(a²-x²) = sin⁻¹(x/a) + C
    • ∫dx/√(x²+a²) = ln|x + √(x²+a²)| + C = sinh⁻¹(x/a) + C
    • ∫dx/√(x²-a²) = ln|x + √(x²-a²)| + C = cosh⁻¹(x/a) + C
    • ∫dx/(a²+x²) = (1/a)tan⁻¹(x/a) + C
    • ∫dx/(a²-x²) = (1/2a)ln|(a+x)/(a-x)| + C = (1/a)tanh⁻¹(x/a) + C (|x|<a)
    • ∫dx/(x²-a²) = (1/2a)ln|(x-a)/(x+a)| + C
    • ∫√(a²-x²) dx = (x/2)√(a²-x²) + (a²/2)sin⁻¹(x/a) + C
    • ∫√(x²±a²) dx = (x/2)√(x²±a²) ± (a²/2)ln|x+√(x²±a²)| + C
  • Used when integrand contains a composite function or an expression whose derivative appears elsewhere in the integrand.

    • Direct substitution: Let u = g(x), du = g'(x)dx. E.g., ∫2x·cos(x²)dx → u = x².
    • Trigonometric substitution for radical forms:
    - √(a²-x²): let x = a sin θ
    - √(a²+x²): let x = a tan θ
    - √(x²-a²): let x = a sec θ
    • Rationalising substitution: For integrals involving √((ax+b)/(cx+d)), let t = √((ax+b)/(cx+d)).
    • Reciprocal substitution: x = 1/t useful for integrals like ∫dx/(x²√(ax²+b)).
    • Euler substitutions for ∫R(x, √(ax²+bx+c))dx — three types depending on sign of 'a' and nature of roots.
  • ∫u dv = uv - ∫v du. Choose u using ILATE priority: Inverse trigonometric, Logarithmic, Algebraic, Trigonometric, Exponential.

    • ∫x·sin x dx (I = sin⁻¹x type? No — A precedes T): u = x, dv = sin x dx → x(-cos x) - ∫(-cos x)dx = -x cos x + sin x + C
    • ∫ln x dx: u = ln x, dv = dx → x ln x - x + C
    • ∫tan⁻¹x dx: u = tan⁻¹x, dv = dx → x tan⁻¹x - ½ln(1+x²) + C
    • Repeated by parts needed for ∫eˣ[f(x)+f'(x)]dx = eˣf(x) + C and ∫eˣ[f(x)+f'(x)+f''(x)]dx = eˣ[f(x)+f'(x)] + C.
    • Tabular method for ∫P(x)·e^{mx}dx or ∫P(x)·sin^n x dx where P is polynomial — alternate signs rapidly.
  • Decompose rational functions P(x)/Q(x) where deg P < deg Q (use division first if deg P ≥ deg Q).

    • Distinct linear factors: P(x)/[(x-a)(x-b)] = A/(x-a) + B/(x-b)
    • Repeated linear factors: P(x)/[(x-a)^n] = A₁/(x-a) + A₂/(x-a)² + ... + Aₙ/(x-a)^n
    • Irreducible quadratic factor: A x + B / (x²+px+q)
    • Repeated irreducible quadratic: similar extension
    • Cover-up method (Heaviside): Plug in root values directly for distinct linear factors.
    • Example: ∫(3x+5)/(x²-x-2)dx → (3x+5)/[(x-2)(x+1)] = A/(x-2)+B/(x+1), find A=11/3, B=-2/3.
  • • ∫dx/(ax²+bx+c): Complete the square in denominator, reduce to standard form.
    • ∫R(sin x, cos x)dx (Rational function of sin and cos):
    - Universal substitution: t = tan(x/2), sin x = 2t/(1+t²), cos x = (1-t²)/(1+t²), dx = 2dt/(1+t²)
    - When powers are odd/even, use sin²x+cos²x=1 identities strategically
    • ∫sin^n x dx and ∫cos^n x dx: Use reduction formulas;
    I_n = ∫sin^n x dx = -sin^{n-1}x cos x/n + (n-1)/n · I_{n-2}
    • ∫e^{αx}(a cos βx + b sin βx)dx = e^{αx}/(α²+β²)[aα+bβ + (bα-aβ)tan?] — use complex exponential or formula.
    • Weierstrass substitution (t = tan(x/2)) is the most powerful general method for trigonometric rational functions.
  • These properties are extensively tested in JEE Advanced — know each with its condition:

    • ∫ₐᵇ f(x)dx = ∫ₐᵇ f(t)dt (dummy variable property)
    • ∫ₐᵇ f(x)dx = -∫ᵇₐ f(x)dx
    • ∫ₐᵃ f(x)dx = 0
    • ∫ₐᵇ f(x)dx = ∫ₐᶜ f(x)dx + ∫ᶜᵇ f(x)dx (additivity over intervals)
    • ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a-x)dx (King's Property — extremely important)
    • If f(2a-x) = f(x): ∫₀^{2a} f(x)dx = 2∫₀ᵃ f(x)dx
    • If f(2a-x) = -f(x): ∫₀^{2a} f(x)dx = 0
    • If f(-x) = f(x) (even): ∫_{-a}^{a} f(x)dx = 2∫₀ᵃ f(x)dx
    • If f(-x) = -f(x) (odd): ∫_{-a}^{a} f(x)dx = 0
    • ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b-x)dx (generalised King's property)
  • • Reduction formula derivation example:
    I_m = ∫₀^{π/2} sin^m x cos^n x dx (Wallis-type)
    I_m,n = [(m-1)/(m+n)]·I_{m-2,n} = [(n-1)/(m+n)]·I_{m,n-2}
    Special case Wallis: ∫₀^{π/2} sin^n x dx = ∫₀^{π/2} cos^n x dx
    = [(n-1)!!/n!!]·(π/2) if n is even, (n-1)!!/n!! if n is odd.

    • Gamma function key values:
    Γ(n) = (n-1)! for n ∈ ℕ
    Γ(1/2) = √π
    Γ(n+1/2) = [(2n)!/4^n n!]√π
    Γ(1) = 1, Γ(2) = 1, Γ(3) = 2

    • Beta-Gamma relation: B(m,n) = Γ(m)Γ(n)/Γ(m+n)
    • Convert integral to Beta form: ∫₀¹ x^{p-1}(1-x)^{q-1}dx = B(p,q)
    • Also: B(m,n) = 2∫₀^{π/2} sin^{2m-1}θ cos^{2n-1}θ dθ — very useful for trigonometric definite integrals.
  • • Area between y = f(x) and x-axis from a to b: A = ∫ₐᵇ |f(x)|dx
    • Area between two curves y = f(x) and y = g(x): A = ∫ₐᵇ |f(x)-g(x)|dx, where a,b are intersection points.
    • Area bounded by parabola y² = 4ax and line x = h: A = (2/3)·h·√(4ah) = (4/3)h√(ah)
    • Area bounded by ellipse x²/a² + y²/b² = 1: A = πab (full ellipse)
    • Area bounded by hyperbola x²/a² - y²/b² = 1 between x = a and x = h: use integral of b√(x²/a²-1)
    • For parametric curves x = f(t), y = g(t): A = ∫ y dx = ∫ g(t)f'(t)dt over appropriate t-interval.
    • Symmetry simplification: Always check for symmetry about axes before integrating — halves/doubles the computation.
  • Convert infinite series sums into definite integrals:

    • General form: lim(n→∞) (1/n) Σ f(r/n) = ∫₀¹ f(x)dx
    • If coefficient is k/n: lim(n→∞) (k/n) Σ f(r/n) = k∫₀¹ f(x)dx
    • For limits other than 0 to 1: adjust via substitution. lim(n→∞) (1/n) Σ f(a + r·h/n) = ∫ₐ^{a+h} f(x)dx
    • Common patterns tested:
    - lim(n→∞) Σ 1/(n+k) = ln 2 → converts to ∫₀¹ dx/(1+x)
    - lim(n→∞) Σ n/(n²+r²) = π/4 → converts to ∫₀¹ dx/(1+x²)
    - lim(n→∞) Σ 1/√(n²-r²) → diverges pattern, check carefully
    • Key insight: The term inside sum must be expressible as f(r/n) multiplied by 1/n for the conversion to work cleanly.
  • • If f is continuous on [a,b], then F(x) = ∫ₐˣ f(t)dt is differentiable on (a,b) and F'(x) = f(x).
    • If f has a jump discontinuity at x₀, then F(x) is still continuous at x₀ but not differentiable there (corner point).
    • If f has removable discontinuity, F is differentiable after defining f at that point.
    • Leibniz rule application: If upper/lower limits are functions of x, chain rule applies.
    • Example: d/dx[∫_{x²}^{x³} sin(t²)dt] = sin(x⁶)·3x² - sin(x⁴)·2x
    • Continuity of F at endpoints: F(a)=0, F(b)=∫ₐᵇ f(t)dt.
    • JEE Advanced frequently combines FTC with continuity questions: 'If F(x)=∫₀ˣ f(t)dt is continuous everywhere, what can you say about f?' — answer involves boundedness.
  • JEE Advanced often requires combining multiple concepts in one problem:

    • Substitution followed by by-parts: e.g., ∫x²·eˣ dx → parts twice.
    • Definite integral with symmetry: Evaluate ∫_{-π/2}^{π/2} x·cos²x dx. Here x is odd, cos²x is even → integrand is odd → integral = 0.
    • Combination of properties: ∫₀¹ ln(1+x)/(1+x²)dx — use x = tan θ substitution then King's property.
    • Parametric differentiation under integral: Differentiate ∫₀^∞ e^{-ax}sin x/x dx w.r.t. a.
    • Comparison of integrals: Show ∫₀¹ x^n e^x dx decreases as n increases.
    • Integral equations: Solve ∫₀ˣ f(t)dt = f(x) → f'(x) = f(x) → f(x) = Ce^x.

Important facts

  • ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b-x)dx is called the King's Property and is the single most-used definite integral identity in JEE Advanced.
  • For ∫₀^{π/2} sin^n x dx (Wallis): If n is odd, result = (n-1)!!/n!!; if n is even, result = (n-1)!!/n!! × π/2.
  • Γ(n)Γ(1-n) = π/sin(nπ) — reflection formula, useful for negative argument gamma evaluations.
  • B(m,n) = B(n,m) — Beta function is symmetric in its arguments.
  • ∫₀^∞ x^{n}/(1+x^m)dx = π/[m·sin(nπ/m)] for 0<n<m — standard result frequently used.
  • The integral ∫₀¹ x^m(1-x)^n dx = B(m+1, n+1) = m!n!/(m+n+1)! for integer m,n ≥ 0.
  • Leibniz rule special case: d/dx ∫₀ˣ f(x,t)dt = f(x,x) + ∫₀ˣ ∂f/∂x dt — the first term comes from the upper limit.
  • For even function f(x): ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx. For odd function: integral = 0. These are tested with composite arguments too.
  • ∫₀^{2π} sin^n x dx = 0 for odd n; = 4∫₀^{π/2} sin^n x dx for even n. Similar results hold for cos^n x.
  • Standard result: ∫₀^∞ e^{-ax}dx = 1/a for a>0; ∫₀^∞ xe^{-ax}dx = 1/a²; ∫₀^∞ x^n e^{-ax}dx = n!/a^{n+1}.

Memory aids

  • ILATE mnemonic for choosing u in integration by parts: Inverse trig → Logarithmic → Algebraic → Trigonometric → Exponential. Always pick the earlier function as u.
  • Memory trick for King's property: 'Replace x with (a+b-x) and the integral stays the same' — think of it as flipping the interval about its midpoint.
  • For substitution: 'Find the inner function and see if its derivative (or a multiple of it) appears outside.' The pattern match is key.
  • Remember: ∫sec x dx = ln|sec x + tan x| — both terms contain 's' and 't', the first letters of sec and tan.
  • Gamma function: Γ(n) = (n-1)! is off-by-one from factorial. Picture: Γ(1) = 0! = 1, not 1!.
  • Wallis formula shortcut: Odd powers → product of odds over evens; Even powers → same product times π/2. Memory: 'Odd gives rational, even gets π.'

Exam tips

  • In JEE Advanced, definite integral questions often combine 2-3 properties. Scan for symmetry first (even/odd, King's property) before attempting direct integration — this alone eliminates 60% of hard-looking integrals.
  • For 'evaluate without computing' type questions, the intended path is almost always symmetry or substitution. If you're setting up a full integration, re-examine the bounds and integrand for hidden symmetry.
  • Master the reduction formula for ∫sin^n x dx and ∫cos^n x dx by deriving it once from integration by parts — this derivation is a common short-answer question itself.
  • For partial fraction decomposition, always verify your result by substituting specific x-values or comparing coefficients. An arithmetic error here cascades through the entire answer.
  • Leibniz rule appears in both MCQ and numerical answer type. Practice with variable limits like ∫_{sin x}^{cos x} e^{t²}dt to build speed.
  • When an integrand contains √(a²±x²), √(x²-a²), or 1/√(a²±x²), immediately consider trigonometric substitution rather than algebraic manipulation.
  • For Gamma-Beta function questions, memorise: B(m,n)=Γ(m)Γ(n)/Γ(m+n), the trigonometric form B(m,n)=2∫₀^{π/2}sin^{2m-1}θcos^{2n-1}θdθ, and Γ(1/2)=√π. These three connect all such problems.
  • Practice 5-6 problems of converting infinite series sums to definite integrals — the pattern recognition (identifying f(r/n) and the 1/n factor) becomes mechanical with practice.
  • Area under curves questions in JEE Advanced sometimes involve absolute value: sketch the curve, identify where it crosses the axis, and split the integral at those points.
  • Always check whether the answer to a definite integral question is positive, negative, or zero based on the graph's position relative to the x-axis — this serves as a quick verification.

Common traps

  • Forgetting the constant of integration (+C) in indefinite integrals — always required unless specified otherwise.
  • Misapplying the power rule ∫x^n dx for n = -1. The formula x^{n+1}/(n+1) fails here; the correct result is ln|x| + C.
  • Incorrect sign when integrating negative powers or subtracting functions: ∫(f-g)dx ≠ ∫f dx - ∫g dx only if both converge separately — in definite integrals this is fine but students sometimes drop signs on limits.
  • Applying even/odd properties without verifying the interval is symmetric about origin: ∫ₐᵇ f(x)dx only halving works when a = -b.
  • In King's property ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a-x)dx, students sometimes write f(a+x) instead — the argument must map the interval [0,a] onto itself reversed.
  • Confusing Γ(n+1/2) formula: It equals [(2n)!/4^n n!]√π, NOT [(2n-1)!!/2^n]√π in simplified form — expand carefully.
  • Applying partial fractions without first ensuring the degree of numerator is less than denominator — always perform polynomial division first if needed.
  • In Leibniz rule, forgetting the derivative of the limits: d/dx ∫_{g(x)}^{h(x)} f(t)dt = f(h(x))h'(x) - f(g(x))g'(x). Missing h' and g' is a frequent error.
  • For ∫dx/(x²-a²), the result is (1/2a)ln|(x-a)/(x+a)| — note the order in absolute value matters for sign correctness.
  • When converting a sum to an integral, the sum must have exactly n terms with step 1/n — miscounting the number of terms leads to wrong limits.
