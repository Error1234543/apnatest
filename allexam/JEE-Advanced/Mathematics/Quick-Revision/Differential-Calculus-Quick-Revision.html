JEE Advanced — Differential Calculus | Quick Revision

JEE AdvancedEnglishQuick Revision

Definitions

  • A function f from set A to set B assigns exactly one element of B to each element of A. Domain = {x : f(x) is defined}, Range = {f(x) : x ∈ Domain}. Codomain is the target set B.
  • Composite function: (g∘f)(x) = g(f(x)). Its domain is {x ∈ Domain(f) : f(x) ∈ Domain(g)}. Note (g∘f) ≠ (f∘g) generally.
  • Inverse function: f is invertible iff it is one-one (injective) and onto (surjective). f⁻¹(y) = x ⇔ f(x) = y.
  • Even function: f(−x) = f(x) for all x. Odd function: f(−x) = −f(x). If f is odd and continuous at x=0, then f(0) = 0.
  • Periodic function: f(x+T) = f(x) for all x. Fundamental period = smallest positive T satisfying this. Period of sin(nx) or cos(nx) is 2π/n; tan(nx) is π/n.
  • Derivative of f at x₀: f′(x₀) = limₕ→₀ [f(x₀+h) − f(x₀)] / h, provided the limit exists. Alternative form: limₓ→ₓ₀ [f(x) − f(x₀)] / (x − x₀).
  • Left and right derivatives: f′₋(x₀) = limₕ→₀⁻ [f(x₀+h) − f(x₀)] / h and f′₊(x₀) = limₕ→₀⁺ [f(x₀+h) − f(x₀)] / h. f is differentiable at x₀ iff both exist and are equal.
  • Continuity at x₀: limₓ→ₓ₀ f(x) = f(x₀), i.e., left limit = right limit = function value. If any fails, the point is a discontinuity.
  • Types of discontinuity: (i) Removable — limit exists but ≠ f(x₀) or f(x₀) undefined. (ii) Jump — left and right limits exist but ≠ each other. (iii) Infinite — limit is ±∞. (iv) Oscillatory — limit does not exist even as ±∞.
  • Fundamental relation: Differentiability ⇒ Continuity. The converse is FALSE; e.g., f(x)=|x| is continuous at 0 but not differentiable there.

Key concepts

  • Basic Derivatives: d/dx[xⁿ]=nxⁿ⁻¹; d/dx[eˣ]=eˣ; d/dx[aˣ]=aˣ·ln(a); d/dx[ln x]=1/x; d/dx[sin x]=cos x; d/dx[cos x]=−sin x; d/dx[tan x]=sec²x; d/dx[cot x]=−csc²x; d/dx[sec x]=sec x·tan x; d/dx[csc x]=−csc x·cot x.
  • Inverse Trig Derivatives: d/dx[sin⁻¹x] = 1/√(1−x²), |x|<1. d/dx[cos⁻¹x] = −1/√(1−x²). d/dx[tan⁻¹x] = 1/(1+x²). d/dx[cot⁻¹x] = −1/(1+x²). d/dx[sec⁻¹x] = 1/(|x|√(x²−1)), |x|>1. d/dx[csc⁻¹x] = −1/(|x|√(x²−1)).
  • Hyperbolic Derivatives: d/dx[sinh x]=cosh x; d/dx[cosh x]=sinh x; d/dx[tanh x]=sech²x. Inverse hyperbolic: d/dx[sinh⁻¹x]=1/√(1+x²); d/dx[cosh⁻¹x]=1/√(x²−1), x>1; d/dx[tanh⁻¹x]=1/(1−x²), |x|<1.
  • Product Rule: d/dx[uv] = u′v + uv′. Quotient Rule: d/dx[u/v] = (u′v − uv′)/v². Chain Rule: d/dx[f(g(x))] = f′(g(x))·g′(x). These combine for nested/multiple products.
  • Logarithmic Differentiation: When f(x) = [u(x)]^{v(x)} or complicated products/quotients, take ln of both sides: ln f = v·ln u, then differentiate implicitly to get f′/f = v′·ln u + v·u′/u, hence f′ = f·[v′·ln u + v·u′/u].
  • Implicit Differentiation: For F(x,y)=0, differentiate both sides w.r.t. x treating y as a function of x: d/dx[F(x,y)] = ∂F/∂x + ∂F/∂y · dy/dx = 0, solve for dy/dx. Example: x³+y³=3axy → dy/dx = (ay−x²)/(y²−ax).
  • Parametric Differentiation: If x=g(t), y=h(t), then dy/dx = (dy/dt)/(dx/dt) provided dx/dt ≠ 0. Second derivative: d²y/dx² = [d/dt(dy/dx)] / (dx/dt). Higher derivatives follow iteratively.
  • Leibniz Theorem (nth derivative of product): If y = uv, then y_n = Σ_{k=0}^n C(n,k)·u^{(n-k)}·v^{(k)}. This is extremely useful for finding nth derivative of products like x²·sin(ax) or x·eˣ·sin x.
  • Mean Value Theorem (MVT): If f is continuous on [a,b] and differentiable on (a,b), then ∃ c ∈ (a,b) such that f′(c) = [f(b)−f(a)]/(b−a). Geometrically: the tangent at c is parallel to the chord joining (a,f(a)) and (b,f(b)).
  • Rolle's Theorem: Special case of MVT when f(a)=f(b); then ∃ c ∈ (a,b) with f′(c)=0. Key application: proving existence of roots of f′(x) between given points without computing f′ explicitly.
  • MVT Corollary 1: If f′(x) > 0 on (a,b), then f is strictly increasing on [a,b]. If f′(x) < 0, f is strictly decreasing. If f′(x) = 0 everywhere on (a,b), f is constant.
  • MVT Corollary 2 (Generalized): If f and g satisfy MVT hypotheses, then ∃ c ∈ (a,b) such that [f(b)−f(a)]·g′(c) = [g(b)−g(a)]·f′(c). Used to compare growth rates.
  • First Derivative Test for Extrema: At a critical point x₀ where f′(x₀)=0 or f′ is undefined: if f′ changes from + to − at x₀ → local maximum; if − to + → local minimum; no sign change → neither (may be inflection).
  • Second Derivative Test: At critical point x₀ with f′(x₀)=0: if f′′(x₀) < 0 → local max; f′′(x₀) > 0 → local min; f′′(x₀) = 0 → test inconclusive, revert to first derivative test. For higher orders: if first non-zero derivative at x₀ is of odd order → extremum; even order → not an extremum.
  • Taylor's Theorem: If f is (n+1)-times differentiable near a, then f(x) = f(a) + f′(a)(x−a) + f′′(a)(x−a)²/2! + … + f⁽ⁿ⁾(a)(x−a)ⁿ/n! + Rₙ, where Rₙ = f⁽ⁿ⁺¹⁾(c)(x−a)⁽ⁿ⁺¹⁾/(n+1)! for some c between a and x.
  • Maclaurin Series (Taylor at a=0): sin x = x − x³/3! + x⁵/5! − …; cos x = 1 − x²/2! + x⁴/4! − …; eˣ = 1 + x + x²/2! + x³/3! + …; ln(1+x) = x − x²/2 + x³/3 − …, |x|≤1, x≠−1.
  • Tangent and Normal: Tangent to y=f(x) at (x₀,y₀): y − y₀ = f′(x₀)(x − x₀). Normal: y − y₀ = −1/f′(x₀)·(x − x₀). Length of tangent = |y₀·√(1+[f′(x₀)]²)/f′(x₀)|. Length of normal = |y₀·√(1+[f′(x₀)]²)|. Subtangent = |y₀/f′(x₀)|. Subnormal = |y₀·f′(x₀)|.
  • Linear Approximation: f(x) ≈ f(a) + f′(a)(x−a) for x near a. Error bound: |error| ≤ M·|x−a|²/2 where M = max|f′′(ξ)| on interval.
  • Differentiability of Composite/Special Functions: f(x)=|x| not diffble at 0. f(x)=x·sin(1/x) for x≠0, f(0)=0: continuous at 0 but not diffble. f(x)=x²·sin(1/x) for x≠0, f(0)=0: differentiable at 0 (f′(0)=0) but f′ is not continuous at 0.

Important facts

  • limₓ→₀ sin x/x = 1; limₓ→₀ (1−cos x)/x² = 1/2; limₓ→₀ tan x/x = 1; limₓ→₀ (eˣ−1)/x = 1; limₓ→₀ ln(1+x)/x = 1.
  • limₓ→∞ (1+1/x)ˣ = e; limₓ→₀ (1+x)^(1/x) = e; limₓ→₀ x·ln x = 0.
  • L'Hôpital's Rule applies ONLY to 0/0 or ∞/∞ forms. Rewrite other forms first: 0·∞ → convert to fraction, ∞−∞ → combine fractions, 0⁰/1^∞/∞⁰ → take ln first.
  • When applying L'Hôpital repeatedly: after each differentiation check again whether the result is still indeterminate before applying again.
  • For limits involving x^n·e^x, x^n·ln x, x^x type, always use exponential-log transformation: rewrite as e^{ln f(x)} first.
  • If f is differentiable at x₀, then f(x) = f(x₀) + f′(x₀)(x−x₀) + ε(x)·(x−x₀) where ε(x)→0 as x→x₀. This linearization is the foundation of all approximation formulas.
  • At an interior local extremum of a differentiable function, f′(x₀)=0 (Fermat's Theorem). Boundary extrema require comparison with interior critical points.
  • Inflection point: where concavity changes, i.e., f′′ changes sign. f′′(x₀)=0 is necessary but NOT sufficient for an inflection point.
  • Oscillatory discontinuity example: f(x) = sin(1/x) for x≠0 has no limit at 0 even though |f(x)|≤1. Multiplying by xᵃ (a>0) makes it continuous at 0.
  • JEE Advanced frequently combines continuity-differentiability of piecewise functions: find parameters making a piecewise f continuous, then check differentiability at the junction point by equating left and right derivatives.
  • For f(x) = max{g(x), h(x)}, the function is continuous if g and h are continuous, but may fail to be differentiable where g(x)=h(x) unless g′(x)=h′(x) at that point.
  • Common Maclaurin series (memorize up to x⁶ for sin, cos, eˣ): these are used in limit evaluations where L'Hôpital would be tedious (e.g., finding coefficient of xⁿ in expansion).

Memory aids

  • Derivative sign ↔ function behavior: positive derivative → going uphill (increasing); negative → going downhill (decreasing); zero → flat peak/valley (critical point).
  • L'Hôpital shortcut phrase: 'If zero over zero or infinite over infinite, differentiate top and bottom.' For 0·∞: rewrite as numerator/denominator first.
  • Chain rule mnemonic: 'Inside derivative stays outside, multiply by derivative of the inside.' For parametric: 'dy/dx = (dy/dt) ÷ (dx/dt)' like converting compound units.
  • Rolle's theorem visual: 'Start and end at same height, somewhere in between you must have a flat spot (horizontal tangent).'
  • MVT generalization: the secant slope equals the instantaneous slope somewhere in between — 'average rate = instantaneous rate somewhere.'
  • For first vs second derivative test: First test checks sign CHANGE of f′ (more reliable); second test checks sign of f′′ (faster but can fail when f′′=0).
  • Taylor series memory: 'function ≈ polynomial built from derivatives at a point.' Each term adds one more derivative, divided by factorial to account for repeated differentiation of (x−a)ⁿ.
  • Differentiable functions are 'smooth' — no corners, cusps, or jumps. Absolute values, sharp corners in graphs, and vertical tangents signal non-differentiable points.

Exam tips

  • For JEE Advanced limit problems: try substitution first, then factorization/rationalization, then series expansion, and reserve L'Hôpital for the last resort — especially when the limit involves composition of transcendental functions.
  • When asked to prove an equation has a root or f′(x)=0 has a root: think Rolle's/MVT first. Construct an auxiliary function F(x) whose derivative gives the target expression. Common trick: multiply by integrating factor.
  • For continuity+differentiability of piecewise functions: first enforce continuity at boundary (match function values), then enforce differentiability (match left/right derivatives). This gives conditions on unknown parameters.
  • JEE Advanced loves questions combining Taylor series with limits: find the lowest degree non-zero term in the expansion to determine the order of vanishing, which decides the limit.
  • For monotonicity problems on closed intervals: check endpoints too. Global max/min can occur at boundaries even if f′≠0 there.
  • Second derivative test failure case (f′′=0): immediately apply the first derivative test or check the first non-vanishing higher derivative. If the first non-zero derivative at x₀ is of odd order n≥1, it's an extremum; if even order, it's not.
  • Graph sketching checklist: domain → intercepts → symmetry → asymptotes → first derivative (increasing/decreasing, extrema) → second derivative (concavity, inflection) → plot key points → draw smooth curve.
  • For tangent-normal problems: remember that if two curves intersect orthogonally, the product of their slopes at the intersection is −1. Use this to find unknown parameters.
  • Small error/approximation: Δy ≈ f′(x)·Δx. If Δx is small, the relative error in y is approximately (f′(x)/f(x))·Δx. Apply when asking 'what is the approximate change in y when x changes by δ.'
  • For inverse function derivative: (f⁻¹)′(y₀) = 1/f′(x₀) where y₀=f(x₀). JEE Advanced often asks this without naming f⁻¹ explicitly — look for phrases like 'derivative of the inverse function at...'
  • When a question says 'for all x in ℝ' or 'for every interval': the condition must hold universally. A single counterexample invalidates it. This is common in questions about injectivity/surjectivity of differentiable functions.
  • JEE Advanced frequently embeds a limit problem inside a continuity question: find limₓ→₀ f(x) first, then set it equal to f(0) to find the parameter. Watch for cases where the limit itself requires careful evaluation (trig limits, exponential forms).

Common traps

  • Assuming continuity implies differentiability. Counterexample: f(x)=|x−2| is continuous at x=2 but not differentiable (corner). Always check left and right derivatives separately.
  • Applying L'Hôpital's rule to non-indeterminate forms like 1/0 or 0/1. This gives wrong answers. Always verify the form first.
  • For f(x)=x²·sin(1/x), f is differentiable at 0 with f′(0)=0, but f′ is NOT continuous at 0. Don't assume differentiability everywhere just because it holds at one point.
  • Treating f′′(x₀)=0 as sufficient for inflection point. Need sign change of f′′ around x₀. Example: f(x)=x⁴ has f′′(0)=0 but no inflection — it's a minimum.
  • In parametric differentiation, forgetting to divide by dx/dt again when finding d²y/dx². d²y/dx² ≠ d/dt(dy/dx); it equals [d/dt(dy/dx)] / (dx/dt).
  • For implicit differentiation of equations like x²+y²=r², treating y as independent of x. Remember to apply chain rule: d/dx[y²] = 2y·dy/dx.
  • Confusing d/dx[sin⁻¹x] with 1/√(1−x²) vs d/dx[cos⁻¹x] = −1/√(1−x²). The negative sign is easy to miss — memorize together: sin⁻¹x + cos⁻¹x = π/2 ⇒ derivatives sum to zero.
  • Domain errors with ln(f(x)): must have f(x)>0. With log base a: f(x)>0 and a>0, a≠1. With √(f(x)): f(x)≥0. JEE Advanced loves testing domain restrictions.
  • Using AM-GM or inequalities to find extrema without verifying equality condition is attainable within the domain. The critical point must lie in the feasible region.
  • For Leibniz theorem, confusing C(n,k) indexing. The k-th term uses v^(k) (kth derivative of v) paired with u^(n-k) ( (n-k)th derivative of u). K goes from 0 to n.
  • When checking differentiability of |g(x)| at g(x₀)=0: f is differentiable there only if g′(x₀)=0. Otherwise there's a corner/cusp. Quick test: sign of g changes across x₀ AND g′(x₀)≠0 → non-differentiable.
  • In mean value theorem applications, assuming c is unique. There can be multiple c values satisfying the conclusion. The theorem guarantees AT LEAST ONE, not exactly one.
