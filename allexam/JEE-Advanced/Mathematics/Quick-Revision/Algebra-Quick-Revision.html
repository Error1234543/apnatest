JEE Advanced Mathematics — Algebra: Quick Revision

JEE AdvancedEnglishQuick Revision

Definitions

  • Complex Number: A number of the form z = a + ib, where a, b are real numbers and i = sqrt(-1). The set of complex numbers is denoted by C.
  • Conjugate of z = a + ib is z_bar = a - ib. Product z·z_bar = a² + b² = |z|².
  • Modulus of z = a + ib is |z| = sqrt(a² + b²). Properties: |z₁·z₂| = |z₁|·|z₂|, |z₁/z₂| = |z₁|/|z₂|, |z₁ + z₂| ≤ |z₁| + |z₂| (triangle inequality).
  • Argand Plane: Geometric representation of complex numbers as points (a, b) on a 2D plane with real axis (x-axis) and imaginary axis (y-axis).
  • Amplitude (Argument) of z: The angle θ that oz makes with the positive real axis, where z = r(cosθ + i·sinθ). Principal value: θ ∈ (-π, π].
  • De Moivre's Theorem: (cosθ + i·sinθ)^n = cos(nθ) + i·sin(nθ) for any integer n.
  • Cubic Roots of Unity: Solutions of z³ = 1 are 1, ω, ω² where ω = (-1 + i√3)/2, ω² = (-1 - i√3)/2. Properties: 1 + ω + ω² = 0, ω³ = 1.
  • Quadratic Equation: An equation of the form ax² + bx + c = 0, a ≠ 0. Roots are x = [-b ± sqrt(b² - 4ac)]/(2a).
  • Discriminant: D = b² - 4ac. Determines nature of roots: D > 0 (real distinct), D = 0 (real equal), D < 0 (complex conjugate).
  • Matrix: A rectangular array of numbers arranged in rows and columns. An m×n matrix has m rows and n columns.
  • Determinant: A scalar value associated with a square matrix. For 2×2: |A| = ad - bc for A = [[a,b],[c,d]].
  • Permutation: An arrangement of objects in a definite order. P(n,r) = n!/(n-r)!.
  • Combination: A selection of objects where order does not matter. C(n,r) = n!/(r!(n-r)!).
  • Binomial Theorem: (a+b)^n = Σ(r=0 to n) C(n,r)·a^(n-r)·b^r.
  • AP (Arithmetic Progression): A sequence where each term differs from the previous by a constant d. nth term: a_n = a + (n-1)d. Sum: S_n = n/2[2a + (n-1)d].
  • GP (Geometric Progression): A sequence where each term is obtained by multiplying the previous by a constant r. nth term: a_n = a·r^(n-1). Sum: S_n = a(1-r^n)/(1-r) for r ≠ 1.
  • HP (Harmonic Progression): A sequence whose reciprocals form an AP. nth term: a_n = 1/[a + (n-1)d].
  • Adjoint of a Matrix: The transpose of the cofactor matrix of A, denoted adj(A). Property: A·adj(A) = adj(A)·A = |A|·I.
  • Inverse of a Matrix: A⁻¹ exists iff |A| ≠ 0, and A⁻¹ = adj(A)/|A|. Property: A·A⁻¹ = A⁻¹·A = I.

Key concepts

  • Equation |z - z₁| = r represents a circle with centre z₁ and radius r. Equation Re(z) = c is a vertical line; Im(z) = c is a horizontal line. Equation arg(z - z₁) = θ represents a ray from z₁ making angle θ with positive real axis. Locus |z - z₁| = |z - z₂| is the perpendicular bisector of segment joining z₁ and z₂. Locus |z - z₁|/|z - z₂| = k (k ≠ 1) is a circle (Apollonius circle). If z₁, z₂, z₃ are vertices of a triangle, its area = (1/2)|Im(z₁(bar z₂ - z₃) + z₂(bar z₃ - z₁) + z₃(bar z₁ - z₂))|. Rotating vector (z₂ - z₁) by angle θ gives z₃ - z₁ = (z₂ - z₁)·e^(iθ). Midpoint of chord joining z₁ and z₂ is (z₁+z₂)/2; centroid of triangle is (z₁+z₂+z₃)/3.
  • z + 1/z = 2cosθ if |z| = 1. z - 1/z = 2isinθ if |z| = 1. If a+bi = (p+iq)^(m+n)·(p-iq)^(m-n), then a²+b² = (p²+q²)^(2m). If x = p+iq and x^(1/3) + x̄^(1/3) = 2cosα, then x + x̄ = 2cos(3α). The equation z^n = 1 has n roots equally spaced on the unit circle — these are the nth roots of unity. sum of nth roots of unity = 0 (for n ≥ 2). Product of non-zero nth roots of unity = (-1)^(n-1).
  • For f(x) = ax² + bx + c with real coefficients: Both roots greater than k iff (i) D ≥ 0, (ii) ak + b > 0, (iii) f(k) > 0. Both roots less than k iff (i) D ≥ 0, (ii) ak + b < 0, (iii) f(k) > 0. One root in (k₁, k₂) and other outside iff f(k₁)·f(k₂) < 0. Both roots lie in (k₁, k₂) iff (i) D ≥ 0, (ii) ak₁ + b > 0, (iii) ak₂ + b < 0, (iv) f(k₁) > 0, (v) f(k₂) > 0. Roots of ax²+bx+c=0 and px²+qx+r=0 have one common root α iff (cq-ar)/(ap-pa) ... Actually: common root condition is (ca₁-a₁c₁)(a₁b₂-a₂b₁) = (b₁c₂-b₂c₁)². If coefficients are rational and one root is p+sqrt(q), other is p-sqrt(q). If one root is a+ib, other is a-ib.
  • For f(x) = ax² + bx + c: If a > 0 and D < 0, then f(x) > 0 for all real x. If a > 0 and D ≥ 0, then f(x) ≥ 0 for x outside the roots (and f(x) ≤ 0 between roots). f(x) > 0 for all x ∈ (α, β) (where α<β) iff a < 0 and D < 0, or a < 0, D ≥ 0 and both roots lie outside (α, β). The inequality ax²+bx+c > 0 holds for x ∈ (-∞, α) ∪ (β, ∞) when a>0, D>0 with roots α<β. For a(x-α)(x-β) type problems, always check the sign of 'a'.
  • Types: Row matrix (1×n), Column matrix (m×1), Square matrix (m=n), Diagonal matrix (off-diagonal entries zero), Scalar matrix (diagonal matrix with equal entries), Identity matrix I (scalar matrix with diagonal = 1), Zero/Null matrix (all entries zero), Symmetric matrix (A^T = A), Skew-symmetric matrix (A^T = -A, diagonal entries must be 0), Orthogonal matrix (A·A^T = I), Singular matrix (|A| = 0), Non-singular matrix (|A| ≠ 0). Operations: (A+B)^T = A^T + B^T, (AB)^T = B^T · A^T, (A^n)^T = (A^T)^n. For skew-symmetric A of odd order: |A| = 0 (singular). Every square matrix can be expressed as sum of symmetric and skew-symmetric: A = (A+A^T)/2 + (A-A^T)/2.
  • If two rows/columns are interchanged, determinant changes sign. If two rows/columns are identical, determinant = 0. If a row/column is multiplied by k, determinant is multiplied by k. If A is singular, |A| = 0, and A·adj(A) = 0 (zero matrix). The determinant of product: |AB| = |A|·|B|. Cramer's Rule: For system Ax = B, if |A| ≠ 0, then x = A⁻¹B, and each variable = |Aᵢ|/|A| where Aᵢ replaces i-th column of A by B. Rank of matrix = order of largest non-vanishing minor. For homogeneous system Ax = 0: non-trivial solutions exist iff |A| = 0.
  • P(n,r) = n!/(n-r)!. C(n,r) = n!/(r!(n-r)!). P(n,r) = r! · C(n,r). C(n,r) = C(n,n-r). Key identities: C(n,r-1) + C(n,r) = C(n+1,r); r·C(n,r) = n·C(n-1,r-1); C(n,r)/C(n,r-1) = (n-r+1)/r. Arrangements of n distinct objects: n!. Selection of r objects from n: C(n,r). Number of ways to divide n distinct objects into groups of sizes p,q,r where p+q+r=n is n!/(p!·q!·r!). Circular permutations of n distinct objects = (n-1)!.
  • Words with repetition: arrangements of n items where p are alike of one kind, q of another, r of third = n!/(p!·q!·r!). Round table: (n-1)! clockwise; if direction doesn't matter = (n-1)!/2. Rings/necklaces: (n-1)!/2. Selection of at least one item from n distinct objects = 2^n - 1. Distribution of m distinct objects into r distinct boxes = r^m. Distribution of m identical objects into r distinct boxes (each box can be empty) = C(m+r-1, r-1). Distribution of m identical objects into r distinct boxes (each box non-empty) = C(m-1, r-1).
  • General term: T_{r+1} = C(n,r)·a^(n-r)·b^r. Middle term(s): if n is even, middle term is T_{n/2+1}; if n is odd, two middle terms are T_{(n+1)/2} and T_{(n+3)/2}. Coefficient of x^r in (1+x)^n is C(n,r). Sum of binomial coefficients: C(n,0)+C(n,1)+...+C(n,n) = 2^n. Alternating sum: C(n,0)-C(n,1)+...+(-1)^n·C(n,n) = 0. sum of odd-indexed coefficients = sum of even-indexed coefficients = 2^(n-1). Largest coefficient: if n even, C(n,n/2) is largest; if n odd, C(n,(n-1)/2) = C(n,(n+1)/2) are largest. Ratio of consecutive coefficients: C(n,r)/C(n,r-1) = (n-r+1)/r.
  • Important expansions: (1+x)^n, (1-x)^n, (a+b)^n, (a-b)^n. Key identities: C(n,0)²+C(n,1)²+...+C(n,n)² = C(2n,n). [C(n,0)]² - [C(n,1)]² + [C(n,2)]² - ... = (-1)^n·C(n,n/2) for even n. C(n,0)·C(n,r) + C(n,1)·C(n,r-1) + ... + C(n,r)·C(n,0) = C(2n,r). Expansion of (1+x)^n + (1-x)^n = 2[C(n,0) + C(n,2)x² + C(n,4)x⁴ + ...]. Expansion of (1+x)^n - (1-x)^n = 2[C(n,1)x + C(n,3)x³ + C(n,5)x⁵ + ...]. For negative index: (1+x)^(-n) = 1 - nx + n(n+1)x²/2! - n(n+1)(n+2)x³/3! + ... convergent for |x| < 1.
  • Sum of first n natural numbers: S = n(n+1)/2. Sum of squares: S = n(n+1)(2n+1)/6. Sum of cubes: S = [n(n+1)/2]². sum of (2r-1) for r=1 to n = n². sum of r·r! = (n+1)! - 1. sum of C(n,r) = 2^n. sum of r·C(n,r) = n·2^(n-1). sum of r²·C(n,r) = n(n+1)·2^(n-2). Geometric series: a + ar + ar² + ... = a/(1-r) for |r|<1. Arithmetico-geometric series sum formula: S = a/(1-r) + dr/(1-r)² for infinite series with first term a, common ratio r, and common difference d.
  • telescoping series: sum of [f(r) - f(r+1)] telescopes to f(1) - f(n+1). Series 1/(1·2) + 1/(2·3) + ... + 1/(n(n+1)) = n/(n+1). Series 1/(1·2·3) + 1/(2·3·4) + ... = 1/4. Method of differences: when term is product of k linear factors, write as [F(r) - F(r+1)]/(k-1) times appropriate constant. Waring's formula: sums of powers can be expressed in terms of elementary symmetric polynomials. Leibniz test for convergence: alternating series with decreasing magnitude terms converges.

Important facts

  • De Moivre's theorem applies to integer powers; for fractional powers, use polar form directly with all possible roots.
  • For z^n = w, there are exactly n distinct complex roots equally spaced on a circle of radius |w|^(1/n).
  • The cube roots of unity form an equilateral triangle on the unit circle in the Argand plane.
  • Four complex numbers z₁,z₂,z₃,z₄ are concyclic or collinear iff (z₁-z₃)(z₂-z₄)/((z₁-z₄)(z₂-z₃)) is real.
  • Condition for three complex numbers to be collinear: (z₃-z₁)/(z₂-z₁) is real.
  • If z₁+z₃ = 2z₂, then z₁,z₂,z₃ are in AP (as complex numbers).
  • For quadratic ax²+bx+c=0 with a,b,c rational: irrational roots occur in conjugate pairs (p±sqrt(q)); complex roots in conjugate pairs (p±iq).
  • Euler's formula: e^(iθ) = cosθ + i·sinθ. Also: e^(iπ) + 1 = 0 (Euler's identity).
  • Logarithm of complex number: log z = ln|z| + i(arg z + 2kπ), k ∈ Z (multi-valued).
  • For matrix A: (A^{-1})^T = (A^T)^{-1}, (kA)^{-1} = A^{-1}/k, (AB)^{-1} = B^{-1}·A^{-1}.
  • det(kA) for n×n matrix = k^n · det(A). det(A^n) = (det(A))^n.
  • A matrix is orthogonal iff its rows (and columns) form an orthonormal set. Then A^{-1} = A^T.
  • For symmetric matrix A: A·adj(A) = |A|·I still holds. A is invertible iff all eigenvalues are non-zero.
  • In P&C, always distinguish between arrangement (permutation) and selection (combination) — the question stem determines which.
  • For distributing distinct items into identical boxes: use Stirling numbers of second kind. For identical items into distinct boxes: stars and bars.
  • Binomial coefficient C(n,r) is maximum at r = n/2 (for even n) or r = (n±1)/2 (for odd n).
  • In AP: if a₁,a₂,...,aₙ are in AP, then ka₁+b, ka₂+b, ... are also in AP with same difference kd.
  • In GP: if a₁,a₂,...,aₙ are in GP, then a₁^k, a₂^k, ... are in GP with common ratio r^k. Also reciprocals form GP.
  • AM ≥ GM ≥ HM for positive reals: (a+b)/2 ≥ sqrt(ab) ≥ 2ab/(a+b). Equality holds iff a = b.

Memory aids

  • Cube roots of unity: 'One omega omega squared, add them up equals nada' → 1+ω+ω²=0. Multiply by ω: ω+ω²+ω³=0 → since ω³=1: ω+ω²+1=0 again.
  • De Moivre: 'Die MoreV' → pronounce like 'De More Vee' to remember (cosθ+isinθ)^n = cos(nθ)+isin(nθ).
  • Pascal's triangle identity: C(n,r-1)+C(n,r)=C(n+1,r) — 'add your neighbours to get the next row'.
  • Binomial sum trick: put x=1 in (1+x)^n to get 2^n. Put x=-1 to get 0. Put x=i to separate real/imaginary parts.
  • Matrix inverse mnemonic: 'A inverse is adj over det' → A⁻¹ = adj(A)/|A|. Adjoint = AdJoint = transpose of cofactor.
  • Circular permutation: fix one person, arrange the rest → (n-1)! instead of n!.
  • Telescoping series: think of a telescope collapsing — most intermediate terms disappear, only first and last remain.
  • AM-GM-HM chain: 'Always Great Money Helps Many' → AM≥GM≥HM.
  • Stars and bars: 'm stars, r-1 bars to make r groups' → C(m+r-1, r-1) for non-negative distribution.
  • Common root of quadratics: 'cross multiply and subtract diagonally' — (c₁a₂-c₂a₁)x + (a₁b₂-a₂b₁) = 0 gives the common root value.
  • Determinant property: 'swap two rows, flip the sign' — easy to remember with a simple 2×2 example.
  • Sine/cosine addition: 'SAOB' = sin(A+B) = sinA·cosB+cosA·sinB. 'COAA' = cos(A+B) = cosA·cosB-sinA·sinB.

Exam tips

  • JEE Advanced frequently tests complex numbers through geometry: prove concyclic points, find locus, or determine shape from complex vertices. Practice converting geometric conditions to algebraic equations.
  • Multi-correct questions on quadratic equations often mix conditions: e.g., 'both roots positive' requires D≥0, sum>0, product>0 simultaneously. Write all three conditions before answering.
  • Matrix determinant problems in JEE Advanced often involve factorisation patterns: (a-b)(b-c)(c-a) type results. Recognise these by substituting a=b to see the determinant vanishes.
  • Binomial theorem questions frequently combine with combinatorics: e.g., find the coefficient of x^5 in (1+x)^n given some condition on n. Solve the condition first, then compute.
  • For sequence and series: JEE Advanced loves telescoping sums and series involving products of consecutive integers. Learn to decompose 1/[f(r)·f(r+1)] using partial fractions.
  • In P&C, the phrase 'at least one' always means total minus 'none': 2^n - 1 for selecting from n distinct items. This appears frequently.
  • Questions on common roots of two quadratics may require elimination: solve one equation and substitute into the other, OR use the cross-multiplication method.
  • For matrices, remember: (A+B)² ≠ A²+2AB+B² unless A and B commute. This trap appears in multi-correct statements.
  • In binomial expansions, the sum of coefficients (put x=1) and alternating sum (put x=-1) are powerful tools for solving coefficient-related questions without expanding fully.
  • For AM-GM-HM applications: always verify the positivity condition before applying. The inequality fails for negative numbers.
  • JEE Advanced loves questions combining multiple concepts: e.g., complex numbers + geometry (locus problems), or matrices + determinants + systems of equations. Practice such integrated problems.
  • When checking if three points form a right angle using complex numbers: (z₃-z₁)/(z₂-z₁) should be purely imaginary.
  • For AP/GP/HP mixed problems: convert everything to the base sequence (AP for HP, GP ratios) before applying formulas.
  • In determinant problems involving variables: try factoring by substitution. If setting a=b makes the determinant zero, then (a-b) is a factor.

Common traps

  • Forgetting that ω and ω² are both non-real cube roots of unity — questions often ask about expressions in ω, and candidates miss that ω³=1 is crucial for simplification.
  • Applying De Moivre's theorem directly to find nth roots without considering all n branches — z^(1/n) has n values, not one.
  • Using |z₁+z₂| = |z₁|+|z₂| as a general identity — this is only true when z₁ and z₂ have the same argument (collinear and same direction).
  • Confusing P(n,r) with C(n,r) — permutation includes ordering, combination does not. Always check if arrangement matters.
  • For circular permutation with reflections allowed (bracelets/necklaces): answer is (n-1)!/2, not (n-1)!. Questions about 'key rings' or 'garlands' imply reflection symmetry.
  • For the general term T_{r+1} in binomial expansion: the subscript is r+1, not r. The power of b is r, not r+1.
  • When finding the middle term: for even n there is ONE middle term; for odd n there are TWO. Don't assume only one.
  • Assuming every square matrix has an inverse: only non-singular matrices (|A|≠0) are invertible. Singular matrices have no inverse.
  • When applying Cramer's rule: if |A| = 0, the system either has no solution or infinitely many — Cramer's rule is NOT applicable.
  • Confusing the sum of GP with r>1: S_n = a(r^n-1)/(r-1) not a(1-r^n)/(1-r) — both are equivalent but sign errors are common.
  • Treating HP terms directly without taking reciprocals: always convert HP to AP first by taking 1/a_n.
  • For inequality f(x) > 0 for all x: forgetting to check D < 0 AND a > 0. If D > 0, the parabola crosses the x-axis and takes negative values between roots.
  • Location of roots problems: forgetting the condition 'ak+b has same sign as a' — this ensures the axis of symmetry is on the correct side of k.
  • Determinant expansion errors: sign pattern is +−+ / −+− / +−+ starting from top-left. Missing a minus sign is the #1 calculation error.
  • In product rules for determinants: |AB| = |A||B| holds for square matrices of SAME order. Cannot apply to rectangular matrices.
