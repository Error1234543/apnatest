sin(A ± B) = sin A cos B ± cos A sin B

Symbols: A, B = any angles

Unit: dimensionless (ratio)

When to use: Expanding or condensing sine of compound angles; essential for solving equations and proving identities

Conditions: Valid for all real A, B

Common mistake: Forgetting the sign change between the two terms; writing sin(A-B)=sinAcosB+cosAsinB

cos(A ± B) = cos A cos B ∓ sin A sin B

Symbols: A, B = any angles

Unit: dimensionless

When to use: Expanding/condensing cosine of compound angles; frequently used in product-to-sum conversions

Conditions: Valid for all real A, B

Common mistake: Swapping signs — the first term has the SAME sign as the original operation, the second has OPPOSITE sign

tan(A ± B) = (tan A ± tan B)/(1 ∓ tan A tan B)

Symbols: A, B = angles where all tangents are defined

Unit: dimensionless

When to use: Simplifying expressions involving tan(A±B); key for solving equations and JEE numerical-type questions

Conditions: tan A, tan B, tan(A±B) must be defined (i.e., cos A≠0, cos B≠0, cos(A±B)≠0)

Common mistake: Forgetting that if A+B=π/2 then tanA·tanB=1, making denominator zero

sin 2A = 2 sin A cos A = 2tan A/(1+tan²A)

Symbols: A = any angle

Unit: dimensionless

When to use: Double angle formula for sine; widely used in integration, equation solving, and simplification

Conditions: All forms valid where functions are defined

Common mistake: Confusing sin 2A with (sin A)²; also forgetting that sin 2A ≠ 2 sin A

cos 2A = cos²A − sin²A = 2cos²A − 1 = 1 − 2sin²A = (1−tan²A)/(1+tan²A)

Symbols: A = any angle

Unit: dimensionless

When to use: Multiple equivalent forms used depending on the problem context — choosing the right form simplifies JEE problems significantly

Conditions: Each form valid where the involved functions are defined

Common mistake: Using wrong form when tan-based expression is present (leads to unnecessary complexity); confusing cos 2A with (cos A)²

tan 2A = 2tan A/(1 − tan²A)

Symbols: A = angle where tan A and tan 2A are defined

Unit: dimensionless

When to use: Double angle for tangent; crucial when equations involve tan 2A and tan A together

Conditions: tan A ≠ ±1 (denominator ≠ 0), cos A ≠ 0, cos 2A ≠ 0

Common mistake: Missing the restriction tan A ≠ ±1 which corresponds to 2A = π/2 + nπ where tan 2A is undefined

sin 3A = 3sin A − 4sin³A

Symbols: A = any angle

Unit: dimensionless

When to use: Triple angle identity for sine; useful in equation solving and polynomial reduction

Conditions: None

Common mistake: Mixing up with cos 3A formula; sign errors in derivation

cos 3A = 4cos³A − 3cos A

Symbols: A = any angle

Unit: dimensionless

When to use: Triple angle identity for cosine; important for solving cubic trigonometric equations

Conditions: None

Common mistake: Sign confusion — easy to write 3cos A − 4cos³A by mistake

tan 3A = (3tan A − tan³A)/(1 − 3tan²A)

Symbols: A = angle where tan A, tan 3A defined

Unit: dimensionless

When to use: Triple angle for tangent; applied in complex equation solving

Conditions: tan A ≠ ±1/√3 (denominator ≠ 0)

Common mistake: Denominator sign error; not checking where tan 3A is undefined

sin²A = (1 − cos 2A)/2, cos²A = (1 + cos 2A)/2

Symbols: A = any angle

Unit: dimensionless

When to use: Power-reduction formulas; essential for integrating powers of sin and cos, and for simplifying JEE expressions

Conditions: None

Common mistake: Forgetting the factor of 1/2 or swapping the signs between the two formulas

sin A + sin B = 2 sin((A+B)/2) cos((A−B)/2)

Symbols: A, B = any angles

Unit: dimensionless

When to use: Sum-to-product conversion; very useful in simplifying sums/differences of sines and in solving trig equations

Conditions: None

Common mistake: Reversing (A+B)/2 and (A−B)/2 positions

cos A + cos B = 2 cos((A+B)/2) cos((A−B)/2)

Symbols: A, B = any angles

Unit: dimensionless

When to use: Sum-to-product for cosines; often paired with the sine version

Conditions: None

Common mistake: Writing sin instead of cos in the product, or sign errors in the arguments

sin A − sin B = 2 cos((A+B)/2) sin((A−B)/2)

Symbols: A, B = any angles

Unit: dimensionless

When to use: Difference-to-product for sines

Conditions: None

Common mistake: Confusing which function (sin or cos) goes with which argument

cos A − cos B = −2 sin((A+B)/2) sin((A−B)/2)

Symbols: A, B = any angles

Unit: dimensionless

When to use: Difference-to-product for cosines

Conditions: None

Common mistake: Forgetting the negative sign in front

tan A + tan B = sin(A+B)/(cos A cos B)

Symbols: A, B = angles where all terms defined

Unit: dimensionless

When to use: Compact form useful in JEE Advanced problems involving products of cosines in denominators

Conditions: cos A ≠ 0, cos B ≠ 0

Common mistake: Not recognizing this identity when it appears hidden in a problem

tan A − tan B = sin(A−B)/(cos A cos B)

Symbols: A, B = angles where all terms defined

Unit: dimensionless

When to use: Similar application to tan A + tan B

Conditions: cos A ≠ 0, cos B ≠ 0

Common mistake: Same as above — failing to spot the pattern

sin(A+B)sin(A−B) = sin²A − sin²B = cos²B − cos²A

Symbols: A, B = any angles

Unit: dimensionless

When to use: Product-difference identity; extremely useful in simplifying products of sines/cosines

Conditions: None

Common mistake: Writing sin²B − sin²A instead of sin²A − sin²B

cos(A+B)cos(A−B) = cos²A − sin²B = cos²B − sin²A

Symbols: A, B = any angles

Unit: dimensionless

When to use: Product identity for cosines; complements the sine version above

Conditions: None

Common mistake: Sign errors when converting between the equivalent forms

sin A sin B cos C + cos A sin B sin C + cos A cos B sin C = sin A cos B cos C + cos A sin B cos C + cos A cos B sin C (when A+B+C = π)

Symbols: A, B, C = angles of a triangle (A+B+C = π)

Unit: dimensionless

When to use: Key identity for triangle trigonometry in JEE Advanced

Conditions: A + B + C = π

Common mistake: Not applying it under the constraint A+B+C=π

If A + B + C = π: sin 2A + sin 2B + sin 2C = 4 sin A sin B sin C

Symbols: A, B, C = angles with A+B+C=π

Unit: dimensionless

When to use: Standard triangle trigonometric identity used extensively in geometry-trig problems

Conditions: A + B + C = π

Common mistake: Forgetting the factor of 4 or writing + instead of × on RHS

If A + B + C = π: cos 2A + cos 2B + cos 2C = −1 − 4 cos A cos B cos C

Symbols: A, B, C = angles with A+B+C=π

Unit: dimensionless

When to use: Triangle identity for double angles of cosine

Conditions: A + B + C = π

Common mistake: Sign errors — easy to miss the negative sign

If A + B + C = π: tan A + tan B + tan C = tan A · tan B · tan C

Symbols: A, B, C = angles of a triangle, none equal π/2

Unit: dimensionless

When to use: One of the most frequently tested identities in JEE Advanced triangle trigonometry

Conditions: A, B, C ≠ π/2 + nπ (tangents must be defined)

Common mistake: Forgetting this holds ONLY when A+B+C=π; also misapplying it when one angle is π/2

a/sin A = b/sin B = c/sin C = 2R

Symbols: a,b,c = sides opposite angles A,B,C; R = circumradius

Unit: length for sides and R

When to use: Sine rule; fundamental for solving triangles in JEE geometry problems

Conditions: Valid for any triangle ABC

Common mistake: Mismatching side-angle pairs; confusing 2R with R

a² = b² + c² − 2bc cos A (and cyclic permutations)

Symbols: a,b,c = sides; A,B,C = opposite angles

Unit: length squared

When to use: Cosine rule; used to find unknown sides/angles in any triangle

Conditions: Valid for any triangle ABC

Common mistake: Sign error (writing +2bc cos A instead of −); mismatching the angle with its opposite side

tan((B−C)/2) = ((b−c)/(b+c)) · cot(A/2)

Symbols: a,b,c = sides; A,B,C = opposite angles; r = inradius, R = circumradius

Unit: dimensionless

When to use: Napier's analogy (tangent rule); powerful for solving triangles given two sides and included angle or vice versa

Conditions: b+c ≠ 0, A ≠ π

Common mistake: Writing tan instead of cot for A/2, or mixing up numerator/denominator

Area = (1/2)bc sin A = (1/2)ca sin B = (1/2)ab sin C = abc/(4R) = rs = √[s(s−a)(s−b)(s−c)]

Symbols: s = semi-perimeter = (a+b+c)/2; r = inradius; R = circumradius

Unit: square length units

r₁ = 4R sin(A/2)cos(B/2)cos(C/2) = s·tan(A/2), similarly r₂, r₃

When to use: Exradii formulas; JEE Advanced often asks relations like 1/r₁ + 1/r₂ + 1/r₃ = 1/r

Common mistake: Writing it as r = r₁ + r₂ + r₃ (wrong)

R = abc/(4Δ), where Δ = area

Unit: radians

cos⁻¹x = tan⁻¹(√(1−x²)/x) for x ∈ (0, 1]

Symbols: x ∈ (0, 1]

Unit: radians

When to use: Converting arccos to arctan form

Conditions: x ∈ (0, 1]

tan⁻¹x + tan⁻¹y = tan⁻¹((x+y)/(1−xy)) if xy < 1

Symbols: x, y = real numbers

Unit: radians

When to use: Addition formula for arctan; JEE frequently tests cases based on xy vs 1

Conditions: xy < 1 for principal value

Common mistake: Not checking xy < 1 condition; for xy > 1 need to add/subtract π

tan⁻¹x + tan⁻¹y = tan⁻¹((x+y)/(1−xy)) + π if xy > 1 and x,y > 0

Symbols: x, y > 0

When to use: Correct branch when xy > 1 and both positive

Conditions: x > 0, y > 0, xy > 1

Common mistake: Forgetting to add π; giving answer in wrong quadrant

tan⁻¹x + tan⁻¹y = tan⁻¹((x+y)/(1−xy)) − π if xy > 1 and x,y < 0

Conditions: x < 0, y < 0, xy > 1

2tan⁻¹x = sin⁻¹(2x/(1+x²)) = cos⁻¹((1−x²)/(1+x²)) = tan⁻¹(2x/(1−x²))

Symbols: x ∈ ℝ with appropriate domain restrictions per formula

Conditions: For sin⁻¹ form: |2x/(1+x²)| ≤ 1 (always true); for tan⁻¹ form: x² ≠ 1

Symbols: α = any particular solution; n = integer

Unit: radians or degrees

When to use: Finding all solutions of sin θ = k; fundamental for solving trig equations

Conditions: |k| ≤ 1

Common mistake: Writing nπ + α only (missing the (−1)ⁿ factor)

General solution of cos θ = cos α: θ = 2nπ ± α, n ∈ ℤ

Unit: radians or degrees

When to use: Finding all solutions of cos θ = k

Conditions: |k| ≤ 1
