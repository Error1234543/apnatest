f'(x) = lim_{h->0} [f(x+h) - f(x)] / h

Symbols: h: infinitesimal increment; f'(x): derivative of f at x

Unit: None (dimensionless ratio)

When to use: Fundamental definition of derivative; used when direct differentiation rules cannot be applied

Conditions: Limit must exist; f must be defined in a neighborhood of x

Common mistake: Forgetting that h approaches 0 from both sides; confusing limit notation with simple substitution

d/dx[x^n] = n·x^{n-1}

Symbols: n: any real number; x: variable

Unit: NA

When to use: Power rule for polynomial and rational expressions

Conditions: x > 0 when n is not an integer; valid for all real x when n is a non-negative integer

Common mistake: Writing n·x^n instead of n·x^{n-1}; applying power rule to functions like sin(x) directly

d/dx[uv] = u'v + uv'

Symbols: u, v: differentiable functions of x; u', v': their derivatives

Unit: NA

When to use: Product rule for differentiation of product of two functions

Conditions: Both u and v must be differentiable at the point of interest

Common mistake: Writing u'v' instead of u'v + uv'; forgetting to differentiate both u and v

d/dx[u/v] = (u'v - uv') / v^2

Symbols: u, v: differentiable functions of x; v ≠ 0

Unit: NA

When to use: Quotient rule for differentiation of a ratio of two functions

Conditions: v(x) ≠ 0 at the point of differentiation

Common mistake: Sign error: writing (u'v + uv')/v^2 instead of minus; misplacing the order as (uv' - u'v)/v^2

d/dx[f(g(x))] = f'(g(x)) · g'(x)

Symbols: f, g: differentiable functions; g(x): inner function; f'(g(x)): derivative of outer evaluated at inner

Unit: NA

When to use: Chain rule for composition of functions

Conditions: g must be differentiable at x and f must be differentiable at g(x)

Common mistake: Forgetting to multiply by g'(x); differentiating only the outer or only the inner function

d/dx[e^x] = e^x

Symbols: e: Euler's number ≈ 2.71828; x: real variable

Unit: NA

When to use: Derivative of natural exponential function

Conditions: Valid for all real x

Common mistake: Confusing e^x with a^x (which has derivative a^x · ln(a)); treating e as a constant coefficient rather than the base

d/dx[a^x] = a^x · ln(a)

Symbols: a: positive constant ≠ 1; x: variable; ln: natural logarithm

Unit: NA

When to use: Derivative of general exponential function with base a

Conditions: a > 0, a ≠ 1

Common mistake: Forgetting the ln(a) factor; writing just a^x; confusing with log_a(x) derivative

d/dx[ln(x)] = 1/x

Symbols: x: positive real variable; ln: natural logarithm

Unit: NA

When to use: Derivative of natural logarithm

Conditions: x > 0

Common mistake: Writing 1/x for ln|ax+b| without chain rule adjustment; confusing with d/dx[log_a(x)] = 1/(x·ln(a))

d/dx[sin(x)] = cos(x)

Symbols: x: angle in radians

Unit: NA

When to use: Derivative of sine function

Conditions: x must be in radians

Common mistake: Applying this formula when x is in degrees without converting to radians first

d/dx[cos(x)] = -sin(x)

Symbols: x: angle in radians

Unit: NA

When to use: Derivative of cosine function

Conditions: x must be in radians

Common mistake: Missing the negative sign; writing +sin(x) instead

d/dx[tan(x)] = sec^2(x)

Symbols: x: angle in radians; sec(x) = 1/cos(x)

Unit: NA

When to use: Derivative of tangent function

Conditions: cos(x) ≠ 0, i.e., x ≠ (2n+1)π/2 for integer n

Common mistake: Writing tan^2(x) or sec(x)·tan(x) instead of sec^2(x)

d/dx[cot(x)] = -csc^2(x)

Symbols: x: angle in radians; csc(x) = 1/sin(x)

Unit: NA

When to use: Derivative of cotangent function

Conditions: sin(x) ≠ 0, i.e., x ≠ nπ for integer n

Common mistake: Forgetting the negative sign; confusing with tan derivative

d/dx[sec(x)] = sec(x)·tan(x)

Symbols: x: angle in radians

Unit: NA

When to use: Derivative of secant function

Conditions: cos(x) ≠ 0

Common mistake: Writing sec^2(x) instead; omitting either factor

d/dx[csc(x)] = -csc(x)·cot(x)

Symbols: x: angle in radians

Unit: NA

When to use: Derivative of cosecant function

Conditions: sin(x) ≠ 0

Common mistake: Forgetting the negative sign

d/dx[arcsin(x)] = 1/√(1-x^2)

Symbols: x: variable in [-1, 1]; arcsin: inverse sine

Unit: NA

When to use: Derivative of inverse sine (principal branch)

Conditions: -1 < x < 1 (open interval for differentiability)

Common mistake: Writing √(1+x^2) in denominator; confusing with arccos derivative which has a negative sign

d/dx[arccos(x)] = -1/√(1-x^2)

Symbols: x: variable in [-1, 1]; arccos: inverse cosine

Unit: NA

When to use: Derivative of inverse cosine

Conditions: -1 < x < 1

Common mistake: Omitting the negative sign; using with x outside (-1,1)

d/dx[arctan(x)] = 1/(1+x^2)

Symbols: x: any real number; arctan: inverse tangent

Unit: NA

When to use: Derivative of inverse tangent

Conditions: Valid for all real x

Common mistake: Confusing with 1/√(1+x^2); mixing up with arcsin/arccos forms

d/dx[arccot(x)] = -1/(1+x^2)

Symbols: x: any real number; arccot: inverse cotangent

Unit: NA

When to use: Derivative of inverse cotangent

Conditions: Valid for all real x

Common mistake: Forgetting the negative sign

d/dx[arcsec(x)] = 1/(|x|√(x^2-1)), |x|>1

Symbols: x: real with |x| > 1; arcsec: inverse secant

Unit: NA

When to use: Derivative of inverse secant

Conditions: |x| > 1

Common mistake: Omitting the absolute value on x; writing just x instead of |x|

d/dx[log_a(x)] = 1/(x·ln(a))

Symbols: a: positive constant ≠ 1; x > 0; log_a: logarithm base a

Unit: NA

When to use: Derivative of logarithm with arbitrary base a

Conditions: a > 0, a ≠ 1, x > 0

Common mistake: Forgetting the ln(a) in denominator when base is not e

d/dx[u(x)^{v(x)}] = u^v · [v'/u + v·u'/u · ln(u)] (for u>0)

Symbols: u(x), v(x): differentiable positive functions of x

Unit: NA

When to use: Differentiation of variable base raised to variable exponent (logarithmic differentiation)

Conditions: u(x) > 0 for the logarithm to be defined

Common mistake: Trying to apply power rule and exponential rule simultaneously; missing the v'/u term; incorrect sign

y' = dy/dx = -(∂F/∂x)/(∂F/∂y) (implicit differentiation from F(x,y)=0)

Symbols: F(x,y): implicitly defining y as function of x

Unit: NA

When to use: Finding dy/dx when y is defined implicitly by an equation

Conditions: ∂F/∂y ≠ 0

Common mistake: Treating y as a constant during partial differentiation with respect to x; forgetting that d/dx[y] = y'

(d^n/dx^n)[x^n] = n!

Symbols: n: non-negative integer; d^n/dx^n: nth derivative

Unit: NA

When to use: nth derivative of x^n gives factorial

Conditions: n is a non-negative integer

Common mistake: Writing n^n or forgetting that lower powers vanish after sufficient differentiation

(d^n/dx^n)[sin(ax+b)] = a^n · sin(ax + b + nπ/2)

Symbols: a, b: constants; n: non-negative integer

Unit: NA

When to use: nth derivative of sin(ax+b)

Conditions: a, b are real constants

Common mistake: Using nπ instead of nπ/2; forgetting to multiply by a^n

(d^n/dx^n)[cos(ax+b)] = a^n · cos(ax + b + nπ/2)

Symbols: a, b: constants; n: non-negative integer

Unit: NA

When to use: nth derivative of cos(ax+b)

Conditions: a, b are real constants

Common mistake: Same phase-shift error as sin; sign confusion between sin and cos patterns

(d^n/dx^n)[e^{ax}] = a^n · e^{ax}

Symbols: a: constant; n: non-negative integer

Unit: NA

When to use: nth derivative of exponential function

Conditions: a is any real constant

Common mistake: Writing (ax)^n instead of a^n; forgetting the exponential remains unchanged

(d^n/dx^n)[1/(x+a)] = (-1)^n · n! / (x+a)^{n+1}

Symbols: a: constant; n: positive integer

Unit: NA

When to use: nth derivative of reciprocal linear function

Conditions: x ≠ -a

Common mistake: Getting the sign pattern wrong; writing (-1)^{n+1}; incorrect factorial or power exponent

Leibniz Rule: (uv)_n = Σ_{k=0}^{n} C(n,k) · u^{(n-k)} · v^{(k)}

Symbols: u^{(k)}: kth derivative of u; v^{(k)}: kth derivative of v; C(n,k): binomial coefficient

Unit: NA

When to use: nth derivative of product of two functions

Conditions: Both u and v must be n-times differentiable

Common mistake: Wrong binomial coefficient indexing; swapping u and v derivatives; miscalculating C(n,k)

L'Hôpital's Rule: If lim f/g → 0/0 or ±∞/±∞, then lim f/g = lim f'/g' (when RHS exists)

Symbols: f(x), g(x): differentiable near c (possibly except at c)

Unit: NA

When to use: Evaluating indeterminate limits by successive differentiation

Conditions: Form must be truly indeterminate (0/0 or ∞/∞); derivatives' limit must exist or be ±∞

Common mistake: Applying L'Hôpital when form is not indeterminate (e.g., 1/0); differentiating numerator and denominator separately but then dividing incorrectly; applying repeatedly without checking conditions each time

f is continuous at x=a iff lim_{x→a^-} f(x) = lim_{x→a^+} f(x) = f(a)

Symbols: a: point in domain of f; left/right limits must equal function value

Unit: NA

When to use: Checking continuity of a function at a point

Conditions: All three one-sided and functional values must exist and match

Common mistake: Only checking the two-sided limit without verifying f(a) is defined; confusing continuity with differentiability

If f is differentiable at x=a, then f is continuous at x=a (converse not necessarily true)

Symbols: a: point where differentiability is asserted

Unit: NA

When to use: Logical relationship between differentiability and continuity

Conditions: Differentiability implies continuity; discontinuity implies non-differentiability

Common mistake: Assuming continuity implies differentiability; example: |x-a| is continuous but not differentiable at x=a

f'(a) = lim_{h→0} [f(a+h) - f(a)] / h = lim_{x→a} [f(x) - f(a)] / (x - a)

Symbols: h = x - a; equivalent forms of derivative definition

Unit: NA

When to use: Alternative formulations for computing derivatives from first principles

Conditions: Limit must exist

Common mistake: Using the wrong substitution variable; confusing h→0 with h→constant

d/dx[f(g(x))] via parametric: If x = φ(t), y = ψ(t), then dy/dx = (dy/dt)/(dx/dt), dx/dt ≠ 0

Symbols: t: parameter; φ, ψ: differentiable functions of t

Unit: NA

When to use: Differentiation of parametric equations

Conditions: dx/dt ≠ 0

Common mistake: Forgetting to divide by dx/dt; computing d²y/dx² as (d²y/dt²)/(d²x/dt²) — second derivative requires extra terms

d²y/dx² = [ (d/dt)(dy/dx) ] / (dx/dt) for parametric curves

Symbols: dy/dx already computed as (ψ'(t))/(φ'(t))

Unit: NA

When to use: Second derivative in parametric form

Conditions: All first and second derivatives must exist; dx/dt ≠ 0

Common mistake: Directly taking d²y/dt² divided by d²x/dt² — incorrect formula

Logarithmic differentiation: If y = [f(x)]^{g(x)}, then ln(y) = g(x)·ln(f(x)), hence y'/y = g'·ln(f) + g·f'/f

Symbols: f(x) > 0, g(x) differentiable

Unit: NA

When to use: Simplifying differentiation of complicated powers, products, or quotients

Conditions: f(x) > 0 for ln(f(x)) to be defined

Common mistake: Forgetting to multiply by y at the end to get y'; taking log before simplifying the expression

d/dx[sinh(x)] = cosh(x), d/dx[cosh(x)] = sinh(x), d/dx[tanh(x)] = sech²(x)

Symbols: sinh(x) = (e^x - e^{-x})/2; cosh(x) = (e^x + e^{-x})/2; sech(x) = 1/cosh(x)

Unit: NA

When to use: Hyperbolic function derivatives

Conditions: All hyperbolic functions defined for all real x

Common mistake: Confusing signs with trigonometric derivatives (hyperbolic derivatives have no negatives in basic forms)

d/dx[arcsinh(x)] = 1/√(1+x^2), d/dx[arccosh(x)] = 1/√(x^2-1), x>1, d/dx[arctanh(x)] = 1/(1-x^2), |x|<1

Symbols: Inverse hyperbolic function derivatives with respective domains

Unit: NA

When to use: Derivatives of inverse hyperbolic functions

Conditions: Domain restrictions must be respected for each function

Common mistake: Swapping the forms with circular inverse trig derivatives; missing absolute values or domain constraints
