z = a + ib = r(cos θ + i sin θ) = re^{iθ}

Symbols: r = |z| = sqrt(a² + b²), θ = arg(z) = tan⁻¹(b/a), a = Re(z), b = Im(z)

Unit: Dimensionless

When to use: Representation of complex numbers in Cartesian, trigonometric, and exponential forms

Conditions: z ≠ 0 for polar form; r ≥ 0 always

Common mistake: Forgetting that arg(z) is defined up to 2nπ; principal value lies in (-π, π]

|z₁z₂| = |z₁||z₂| ; arg(z₁z₂) = arg(z₁) + arg(z₂)

Symbols: z₁, z₂ are complex numbers

Unit: N/A

When to use: Multiplication properties of modulus and amplitude

Conditions: None additional beyond z₁, z₂ being complex

Common mistake: Confusing arg(z₁/z₂) = arg(z₁) - arg(z₂) — sign error in division

conjugate: z̄ = a - ib ; z · z̄ = |z|² = a² + b²

Unit: N/A

When to use: Simplifying expressions, finding modulus, rationalizing denominators

Conditions: z is any complex number

Common mistake: Writing z + z̄ = 2ib instead of 2a; confusing which part gets negated
