Integral Calculus — Formula Sheet (JEE Advanced)

JEE AdvancedEnglishFormula Sheet
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ −1

Symbols: x: variable of integration; n: real exponent; C: constant of integration

Unit: N/A

When to use: Power rule for indefinite integration; foundational for all polynomial and rational integrals.

Conditions: n ≠ −1. For n = −1, ∫ x⁻¹ dx = ln|x| + C.

Common mistake: Applying this formula when n = −1 instead of using the logarithmic result.

∫ eˣ dx = eˣ + C

Symbols: e: Euler’s number ≈ 2.718; x: real variable; C: constant.

Unit: N/A

When to use: Basic exponential integral. Frequently combined with substitution or parts.

Conditions: None beyond x being real.

Common mistake: Forgetting the +C in indefinite integrals, or forgetting to apply chain rule when the exponent is a function of x.

∫ aˣ dx = aˣ / ln(a) + C, a > 0, a ≠ 1

Symbols: a: positive base not equal to 1; x: variable; C: constant.

Unit: N/A

When to use: Integrating general exponential functions. Special case a = e gives eˣ.

Conditions: a > 0 and a ≠ 1. If a ≤ 0, the expression is not defined over reals.

Common mistake: Writing ∫ aˣ dx = aˣ/x or omitting the ln(a) denominator.

∫ sin x dx = −cos x + C; ∫ cos x dx = sin x + C

Symbols: x: angle in radians; C: constant.

Unit: N/A

When to use: Fundamental trigonometric integrals used repeatedly in composite and reduction problems.

Conditions: x measured in radians.

Common mistake: Sign confusion: the integral of sin x is −cos x (negative), not +cos x.

∫ sec²x dx = tan x + C; ∫ csc²x dx = −cot x + C; ∫ sec x tan x dx = sec x + C; ∫ csc x cot x dx = −csc x + C

Symbols: x: angle in radians; C: constant.

Unit: N/A

When to use: Standard derivative pairs reversed. Essential for trigonometric integrals.

Conditions: x must avoid points where sec, tan, csc, cot are undefined.

Common mistake: Sign error on csc² → −cot, and confusion between sec x tan x vs sec²x integrals.

∫ sec x dx = ln|sec x + tan x| + C = ln|tan(x/2 + π/4)| + C

Symbols: x: angle; C: constant.

Unit: N/A

When to use: High-yield integral appearing frequently in JEE Advanced. Both forms are useful.

Conditions: x ≠ (2n+1)π/2.

Common mistake: Omitting absolute value bars, writing just ln(sec x + tan x) without modulus.

∫ csc x dx = ln|csc x − cot x| + C = ln|tan(x/2)| + C

Symbols: x: angle; C: constant.

Unit: N/A

When to use: Parallel to sec x integral. Both results follow from multiplying numerator and denominator by conjugate.

Conditions: x ≠ nπ.

Common mistake: Confusing the sign: it is csc x − cot x, not csc x + cot x.

∫ tan x dx = ln|sec x| + C = −ln|cos x| + C; ∫ cot x dx = ln|sin x| + C

Symbols: x: angle; C: constant.

Unit: N/A

When to use: Used when integrands reduce to tan/cot via substitution. The ln|sec x| form is more common in answers.

Conditions: cos x ≠ 0 for tan, sin x ≠ 0 for cot.

Common mistake: Writing ln(tan x) or forgetting absolute values.

∫ 1/(x²+a²) dx = (1/a) arctan(x/a) + C

Symbols: a: nonzero constant; x: variable; C: constant.

Unit: N/A

When to use: One of the most standard forms. Directly yields arctan after completing the square.

Conditions: a ≠ 0. If a² < 0 (i.e., negative), switch to partial fractions with difference of squares.

Common mistake: Dropping the factor 1/a, or confusing with the arctan formula that has (x²−a²) in denominator.

∫ 1/√(x²+a²) dx = ln|x + √(x²+a²)| + C

Symbols: a: nonzero constant.

Unit: N/A

When to use: Inverse hyperbolic sine form: = sinh⁻¹(x/a) + C. Appears in JEE Advanced especially after completing the square.

Conditions: √(x²+a²) > 0 always (real domain).

Common mistake: Confusing this with ∫ 1/(x²+a²) dx which gives arctan. Missing absolute value inside log.

∫ 1/√(x²−a²) dx = ln|x + √(x²−a²)| + C

Symbols: a: nonzero constant.

Unit: N/A

When to use: Yields cosh⁻¹(x/a) + C for x > a. Both √(x²±a²) log-forms look identical but differ in condition.

Conditions: |x| > |a| for real output.

Common mistake: Treating the plus and minus versions identically without checking domain; applying outside valid domain.

∫ 1/(x²−a²) dx = (1/2a) ln|(x−a)/(x+a)| + C

Symbols: a: nonzero constant.

Unit: N/A

When to use: Partial fraction decomposition result. Key alternative form for rational functions.

Conditions: x ≠ ±a.

Common mistake: Forgetting the 1/(2a) factor, or writing arctan instead of log.

∫ 1/(a²−x²) dx = (1/2a) ln|(a+x)/(a−x)| + C

Symbols: a: nonzero constant.

Unit: N/A

When to use: Another high-yield rational integral. Related to inverse hyperbolic tangent.

Conditions: |x| < |a|.

Common mistake: Swapping numerator and denominator inside log, giving wrong sign.

∫ 1/√(a²−x²) dx = arcsin(x/a) + C = −arccos(x/a) + C

Symbols: a: nonzero constant.

Unit: N/A

When to use: Standard arcsin form. Crucial for integrals reducible to this after completing the square.

Conditions: |x| ≤ |a|.

Common mistake: Writing arcsin(ax) or dropping the division by a inside arcsin.

∫ 1/(x√(x²−a²)) dx = (1/a) sec⁻¹|x/a| + C

Symbols: a: nonzero constant.

Unit: N/A

When to use: Less commonly memorized but appears when the integrand has x multiplied by a radical.

Conditions: |x| ≥ |a|, x ≠ 0.

Common mistake: Using arcsin or arccos instead of sec⁻¹.

Integration by Parts: ∫ u dv = uv − ∫ v du

Symbols: u: differentiable function chosen as 'first'; v: function whose differential dv is identified; du, dv: their differentials.

Unit: N/A

When to use: Core technique for products of functions. ILATE rule guides choice of u.

Conditions: Both u and v must be differentiable on the interval.

Common mistake: Choosing u incorrectly (ignoring ILATE), or failing to recognize when repeated parts application leads to solvable equation.

ILATE Rule: I = Inverse trig, L = Logarithmic, A = Algebraic, T = Trigonometric, E = Exponential (choose u as leftmost higher-priority type)

Symbols: Order determines which factor becomes u in ∫ u·v dx.

Unit: N/A

When to use: Decision rule to maximise simplification in parts. Example: ∫ x·eˣ dx → u = x (A before E).

Conditions: Not an absolute law; exceptions exist (e.g., ∫ eˣ(f(x)+f'(x)) dx works directly). Apply judgement.

Common mistake: Always picking the first function as u regardless of type; e.g., making eˣ the u when x is present.

∫ eˣ[f(x) + f'(x)] dx = eˣ f(x) + C

Symbols: f: any differentiable function; f': its derivative.

Unit: N/A

When to use: Shortcut for specific integrand structure. Very frequently asked in JEE Advanced.

Conditions: The integrand must be exactly eˣ times (f + f').

Common mistake: Forcing the form when it doesn't match; missing the simplification eˣ(sin x + cos x) = eˣ·√2 sin(x+π/4).

∫ eᵃˣ[f(x) + (1/a)f'(x)] dx = eᵃˣ f(x)/a + C

Symbols: a: nonzero constant.

Unit: N/A

When to use: Generalisation of the above for eᵃˣ. Useful when extracting a common exponential factor.

Conditions: a ≠ 0.

Common mistake: Forgetting the 1/a factor in the result.

Partial Fractions — distinct linear: P(x)/[(x−a)(x−b)] = A/(x−a) + B/(x−b), A = P(a)/(a−b), B = P(b)/(b−a)

Symbols: P(x): polynomial of degree less than denominator; a, b: distinct roots.

Unit: N/A

When to use: Decomposing rational functions into integrable terms. The cover-up method gives coefficients rapidly.

Conditions: Degree of numerator < degree of denominator (divide first if not).

Common mistake: Using cover-up on repeated factors without adjustment; missing the need for polynomial division first.

Partial Fractions — repeated linear: P(x)/(x−a)ⁿ = A₁/(x−a) + A₂/(x−a)² + ... + Aₙ/(x−a)ⁿ

Symbols: n: positive integer ≥ 2; Aᵢ: constants to determine.

Unit: N/A

When to use: Each power of the repeated factor gets its own term. All must be integrated separately.

Conditions: Same degree condition as above.

Common mistake: Including only one term for a repeated factor instead of summing all powers up to n.

Partial Fractions — irreducible quadratic: P(x)/[(x²+bx+c)(…)] includes term (Mx+N)/(x²+bx+c)

Symbols: M, N: constants; x²+bx+c: discriminant < 0.

Unit: N/A

When to use: Quadratic factors that cannot be split into real linear factors require a linear numerator.

Conditions: Discriminant b²−4c < 0 for irreducibility over reals.

Common mistake: Writing a constant numerator instead of Mx+N, yielding an unsolvable system.

Substitution: ∫ f(g(x))·g'(x) dx = ∫ f(u) du, where u = g(x), du = g'(x) dx

Symbols: g: differentiable function; f: continuous function.

Unit: N/A

When to use: First-principles method: recognise derivative inside to reduce integrand.

Conditions: g must be differentiable and f integrable in u.

Common mistake: Forgetting to replace dx with du/g'(x) factor; not adjusting limits for definite integrals.

King's Property: ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx

Symbols: a, b: limits of integration; f: integrable function.

Unit: N/A

When to use: Transform integrand to exploit symmetry, often combining with original to simplify evaluation.

Conditions: None beyond integrability on [a,b].

Common mistake: Applying the property then failing to add the two forms to eliminate the transformed part.

Symmetry: If f is even, ∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx; if f is odd, ∫₋ₐᵃ f(x) dx = 0

Symbols: a > 0; f even means f(−x)=f(x); f odd means f(−x)=−f(x).

Unit: N/A

When to use: Powerful time-saver in definite integrals, especially with sin, cos, polynomials.

Conditions: Interval must be symmetric about 0.

Common mistake: Misidentifying parity of composite functions like sin(x²) (even!) vs x·sin(x) (even!). Always test f(−x) explicitly.

∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx combined with ∫ₐᵇ f(x) dx = ∫ₐᵇ f(2a−x) dx (shifted symmetry about a)

Symbols: a, b: limits.

Unit: N/A

When to use: Generalised King property when limits are not symmetric about 0 but about some point.

Conditions: Useful for evaluating definite integrals with trigonometric denominators.

Common mistake: Confusing the reflection axis; the correct reflection about midpoint is a+b−x, not a−x.

∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx ⇒ adding gives 2I = ∫ₐᵇ [f(x)+f(a+b−x)] dx

Symbols: I = ∫ₐᵇ f(x) dx.

Unit: N/A

When to use: Standard trick: if f(x)+f(a+b−x) simplifies to a constant, the integral is trivial.

Conditions: Must recognise the simplification pattern.

Common mistake: Stopping after one transformation instead of exploiting the sum.

∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx (special case of King's property with a=0 lower limit)

Symbols: a: upper limit.

Unit: N/A

When to use: Most frequently encountered special form. Substitute x → a−x to reveal simplifications.

Conditions: None beyond integrability.

Common mistake: Failing to spot when f(a−x) produces a complementary form that cancels or adds simply.

Reduction formula for Iₙ = ∫ sinⁿx dx: Iₙ = −(1/n) sinⁿ⁻¹x cos x + ((n−1)/n) Iₙ₋₂

Symbols: n: positive integer ≥ 2.

Unit: N/A

When to use: Reduces power of sin by 2 each step. Derive via parts with u=sinⁿ⁻¹x.

Conditions: n ≥ 2. For n=0: I₀=x+C; n=1: I₁=−cos x+C.

Common mistake: Sign errors in the boundary term; forgetting the (n−1)/n coefficient on the reduced integral.

Reduction formula for Iₙ = ∫ cosⁿx dx: Iₙ = (1/n) cosⁿ⁻¹x sin x + ((n−1)/n) Iₙ₋₂

Symbols: n: positive integer ≥ 2.

Unit: N/A

When to use: Parallel to sin reduction. Sign of boundary term is opposite due to derivative of cos.

Conditions: n ≥ 2. I₀=x+C, I₁=sin x+C.

Common mistake: Copying the sin reduction formula verbatim with wrong sign on boundary term.

Reduction formula for Iₙ = ∫ tanⁿx dx: Iₙ = tanⁿ⁻¹x/(n−1) − Iₙ₋₂, n ≠ 1

Symbols: n: positive integer ≠ 1.

Unit: N/A

When to use: Uses tan²x = sec²x − 1 to peel off powers. Very clean recurrence.

Conditions: n ≠ 1. I₁ = ln|sec x| + C.

Common mistake: Missing the division by (n−1) on the first term.

Reduction formula for Iₙ = ∫ secⁿx dx: Iₙ = (secⁿ⁻²x tan x)/(n−1) + ((n−2)/(n−1)) Iₙ₋₂, n > 1

Symbols: n: integer > 1.

Unit: N/A

When to use: Standard reduction. Derived via parts with u = secⁿ⁻²x, dv = sec²x dx.

Conditions: n > 1. Base cases: I₀=x+C, I₁=ln|sec x+tan x|+C.

Common mistake: Inverting the coefficient ratio (n−2)/(n−1) in wrong position.

Gamma Function: Γ(n) = ∫₀^∞ xⁿ⁻¹ e⁻ˣ dx; Γ(n+1) = n! for positive integer n; Γ(1/2) = √π

Symbols: n: real/complex parameter with Re(n) > 0.

Unit: N/A

When to use: Connects factorials to integrals. Used in substitution-heavy improper integrals.

Conditions: Re(n) > 0 for convergence. Recurrence: Γ(n+1)=nΓ(n).

Common mistake: Confusing Γ(n) with n! (it is Γ(n+1)=n!); misreading the xⁿ⁻¹ exponent versus xⁿ.

Beta Function: B(m,n) = ∫₀¹ xᵐ⁻¹(1−x)ⁿ⁻¹ dx = Γ(m)Γ(n)/Γ(m+n), m,n > 0

Symbols: m, n: positive real parameters.

Unit: N/A

When to use: Useful for integrals of the form ∫₀¹ xᵖ(1−x)q dx and related substitutions.

Conditions: m > 0, n > 0.

Common mistake: Writing Γ(m+n) in the numerator instead of denominator.

Alternate Beta form: B(m,n) = 2∫₀^(π/2) sin²ᵐ⁻¹θ cos²ⁿ⁻¹θ dθ = ∫₀¹ tᵐ⁻¹(1−t)ⁿ⁻¹ dt via t=sin²θ

Symbols: θ: angular variable; m, n > 0.

Unit: N/A

When to use: Converts trigonometric integrals to Beta/Gamma forms. High-yield for JEE Advanced.

Conditions: m, n > 0 for convergence at endpoints.

Common mistake: Mismatching the exponents: 2m−1 and 2n−1 must correspond to sin and cos powers respectively.

Limit definition of definite integral (Riemann sum): ∫ₐᵇ f(x) dx = lim_{n→∞} Σᵢ₌₁ⁿ f(xᵢ*) Δx, where Δx = (b−a)/n

Symbols: Δx: width of subinterval; xᵢ*: sample point in i-th subinterval.

Unit: N/A

When to use: Converting limits of sums to definite integrals. JEE often asks for exact values of such limits.

Conditions: f must be Riemann-integrable on [a,b].

Common mistake: Not identifying a and b from the sum limits; misreading Σ(n/(n+k))² as having limits 1 to 1 rather than 0 to 1.

Common Riemann-sum → integral pattern: lim_{n→∞} (1/n) Σ f(k/n) = ∫₀¹ f(x) dx

Symbols: k: index from 1 to n; f: continuous on [0,1].

Unit: N/A

When to use: Fastest way to convert limit-of-sum problems. Replace k/n by x and 1/n by dx.

Conditions: Sum must be expressible purely as function of k/n divided by n.

Common mistake: Ignoring the factor outside the sum; forcing the pattern when terms involve (n+k) in denominator.

Leibniz Rule: d/dx ∫_{g(x)}^{h(x)} f(t) dt = f(h(x))·h'(x) − f(g(x))·g'(x)

Symbols: g, h: differentiable functions; f: continuous function.

Unit: N/A

When to use: Differentiating an integral with variable limits. Used in solving integral equations and limit problems.

Conditions: f continuous on the range; g, h differentiable.

Common mistake: Forgetting the chain-rule derivatives h'(x) and g'(x), or applying sign incorrectly to the lower-limit term.

Fresnel integrals: ∫₀^∞ sin(x²) dx = ∫₀^∞ cos(x²) dx = √(π/8)

Symbols: x: real variable.

Unit: N/A

When to use: Special improper integrals. Connected to Gaussian integral via complex substitution.

Conditions: Convergence is conditional; requires oscillatory cancellation.

Common mistake: Assuming these equal zero because sin(x²) is 'odd-like' over infinite domain.

Gaussian integral: ∫₋∞^∞ e^{−x²} dx = √π; ∫₀^∞ e^{−x²} dx = √π/2

Symbols: x: real variable.

Unit: N/A

When to use: Foundational for probability, physics, and substitution-based integral evaluations.

Conditions: Standard result derived via squaring and polar coordinates.

Common mistake: Confusing e^{−x²} with e^{−x}; the latter integrates to −e^{−x}, completely different.

Property: ∫ₐᵇ f(x) dx = −∫ᵇᵃ f(x) dx; ∫ₐᵃ f(x) dx = 0; ∫ₐᵇ f(x) dx = ∫ₐᶜ f(x) dx + ∫ᶜᵇ f(x) dx

Symbols: a, b, c: real numbers, c arbitrary.

Unit: N/A

When to use: Basic manipulation rules for definite integrals.

Conditions: All applicable whenever integrals exist.

Common mistake: Forgetting the sign flip when reversing limits in intermediate steps.

Periodicity property: If f(x+T) = f(x), then ∫ₐᵃ⁺ᵀ f(x) dx is independent of a; ∫₀^{nT} f(x) dx = n∫₀ᵀ f(x) dx

Symbols: T: period of f; n: positive integer.

Unit: N/A

When to use: Simplifies integrals of periodic functions over full periods.

Conditions: f must be integrable and T-periodic.

Common mistake: Applying to non-periodic composites like sin(x²); period applies to argument, not the whole function.

Properties combining f(x) and f(a+b−x): If f(a+x)+f(a−x) = 2f(a), then ∫ₐ₋ᵦᵃ⁺ᵦ f(x) dx = 2β·f(a)

Symbols: a: center of symmetry; β: half-width.

Unit: N/A

When to use: Generalised even-function property for non-zero-centred intervals.

Conditions: f must satisfy the stated symmetry about x=a.

Common mistake: Applying when the symmetry condition is not met; assuming all functions have this property.

If f(2a−x) = f(x), then ∫₀^{2a} f(x) dx = 2∫₀ᵃ f(x) dx

Symbols: a: midpoint of interval [0, 2a].

Unit: N/A

When to use: Special symmetry used in evaluating definite integrals where substitution about a reveals equality.

Conditions: f must satisfy this symmetry exactly.

Common mistake: Stating the result as 2∫ₐ^{2a} without verifying the symmetry holds.

∫₀^{π/2} sinⁿx dx = ∫₀^{π/2} cosⁿx dx = Wₙ, where Wₙ = [(n−1)/n]·[(n−3)/(n−2)]·…×(π/2 if n even else 1)

Symbols: n: positive integer; … denotes continuing reduction to base case.

Unit: N/A

When to use: Wallis-type formulas give direct values without performing integration. Very high yield for JEE.

Conditions: n ≥ 0 integer.

Common mistake: Using the wrong base case: odd n ends at 1, even n ends at π/2; mixing them up gives wrong answer.

∫₀^{π/2} sinᵖx cosʳx dx = (1/2) B((p+1)/2, (r+1)/2) = [Γ((p+1)/2)Γ((r+1)/2)]/[2Γ((p+r+2)/2)]

Symbols: p, r: real numbers > −1.

Unit: N/A

When to use: Most general form combining sine/cosine powers. Direct link to Beta function.

Conditions: p, r > −1 for convergence.

Common mistake: Applying Wallis formula (only for integer powers) when p or r are non-integers.

Integration of absolute value: ∫ₐᵇ |f(x)| dx splits at zeros of f(x) in [a,b]

Symbols: Zeros of f(x): points where f(x)=0 inside [a,b].

Unit: N/A

When to use: Removing absolute value by dividing interval at roots.

Conditions: Find all roots in [a,b], evaluate each piece with correct sign.

Common mistake: Integrating |f(x)| as ∫f(x) dx directly, ignoring sign changes across roots.

Fractional part function: {x} = x − ⌊x⌋. ∫₀ⁿ {x} dx = n/2 for positive integer n

Symbols: n: positive integer; ⌊x⌋: floor function.

Unit: N/A

When to use: Periodic sawtooth behaviour; integral over full periods is simple.

Conditions: Pattern repeats every unit interval with area 1/2 per period.

Common mistake: Treating {x} as constant; integrating over partial periods without accounting for truncation.

Greatest integer function property: ∫₀ⁿ ⌊x⌋ dx = n(n−1)/2 for positive integer n

Symbols: n: positive integer.

Unit: N/A

When to use: Sum of areas of rectangles: 0·1 + 1·1 + … + (n−1)·1.

Conditions: n must be integer for closed form; otherwise sum truncation applies.

Common mistake: Writing n²/2 instead of n(n−1)/2; forgetting the floor is constant between integers.

Definite integral with symmetric limits and odd/even integrand: ∫₋ₐᵃ x·g(x²) dx = 0 for any integrable g

Symbols: a > 0; g: any integrable function.

Unit: N/A

When to use: x is odd, g(x²) is even (since x² is even), product is odd → integral zero.

Conditions: Interval must be symmetric about 0.

Common mistake: Assuming any function of x² is even without checking; forgetting the odd × even = odd rule.

Substitution for ∫ dx/(x√(x²−a²)): let x = a sec θ, result = (1/a) sec⁻¹(x/a) + C

Symbols: a: nonzero constant.

Unit: N/A

When to use: Trigonometric substitution method. Also works: x = a cosh t for hyperbolic route.

Conditions: |x| ≥ |a|.

Common mistake: Choosing x = a tan θ (wrong substitution for this form); using sec without accounting for dx = a sec θ tan θ dθ.

∫ dx/√(a²−x²) = arcsin(x/a)+C; ∫ dx/√(x²−a²) = ln|x+√(x²−a²)|+C; ∫ dx/√(x²+a²) = ln|x+√(x²+a²)|+C

Symbols: a: nonzero constant.

Unit: N/A

When to use: Three canonical radical forms memorised together for quick recognition after completing the square.

Conditions: Domain restrictions apply: |x|≤|a|, |x|≥|a|, all x respectively.

Common mistake: Giving arcsin for both √(a²−x²) and √(x²−a²); all three look similar but only the first gives arcsin.

∫ xⁿ eˣ dx = xⁿ eˣ − n∫ xⁿ⁻¹ eˣ dx (reduction via parts, u=xⁿ)

Symbols: n: positive integer.

Unit: N/A

When to use: Repeated integration by parts formula. Can be applied n times to reduce to eˣ.

Conditions: n ≥ 1 integer.

Common mistake: Applying parts once and stopping instead of iterating; sign errors accumulating.

∫ xⁿ ln x dx = xⁿ⁺¹ ln x/(n+1) − xⁿ⁺¹/(n+1)² + C, n ≠ −1

Symbols: n: real ≠ −1.

Unit: N/A

When to use: Single application of parts with u = ln x, dv = xⁿ dx.

Conditions: x > 0 (for ln x defined).

Common mistake: Forgetting the extra 1/(n+1) factor on the second term.

∫ sin⁻¹x dx = x sin⁻¹x + √(1−x²) + C

Symbols: x ∈ [−1, 1].

Unit: N/A

When to use: Standard integral of inverse trig function, obtained via parts with u=sin⁻¹x.

Conditions: |x| ≤ 1.

Common mistake: Writing x sin⁻¹x − √(1−x²) with wrong sign; missing the radical term entirely.

∫ cos⁻¹x dx = x cos⁻¹x − √(1−x²) + C

Symbols: x ∈ [−1, 1].

Unit: N/A

When to use: Parallel to arcsin integral. Sign differs because d/dx(cos⁻¹x) = −1/√(1−x²).

Conditions: |x| ≤ 1.

Common mistake: Writing the same answer as arcsin integral; not flipping the sign on the radical.

∫ tan⁻¹x dx = x tan⁻¹x − (1/2)ln(1+x²) + C

Symbols: x ∈ ℝ.

Unit: N/A

When to use: Parts with u=tan⁻¹x, dv=dx. Very frequently tested form.

Conditions: None beyond real x.

Common mistake: Writing ln(1+x) instead of ln(1+x²); missing the 1/2 factor.

∫ sec⁻¹x dx = x sec⁻¹x − ln|x+√(x²−1)| + C, |x| ≥ 1

Symbols: x: real with |x| ≥ 1.

Unit: N/A

When to use: Result from parts with u=sec⁻¹x. The log term comes from ∫ 1/(x√(x²−1)) dx.

Conditions: |x| ≥ 1.

Common mistake: Writing arcsin or arccos form instead; sign error on the log term.

∫ csc⁻¹x dx = x csc⁻¹x + ln|x+√(x²−1)| + C, |x| ≥ 1

Symbols: x: real with |x| ≥ 1.

Unit: N/A

When to use: Parallel to sec⁻¹. Sign of log term differs because derivative of csc⁻¹x has opposite sign.

Conditions: |x| ≥ 1.

Common mistake: Copying the sec⁻¹ answer without flipping sign on the logarithmic term.

∫ (1/(x±√(x²±1))) dx: rationalise to get ∫(±x∓√(x²±1)) dx

Symbols: Four sign combinations produce integrable elementary forms.

Unit: N/A

When to use: Recognising reciprocal-radical forms simplifies via rationalisation.

Conditions: Domain determined by radical.

Common mistake: Trying substitution instead of rationalising first; creating unnecessary complexity.
