Complex Numbers: Definition, Algebraic Operations, and Geometric Representation

A complex number is written as z = x + iy, where x and y are real numbers and i = sqrt(-1). The real part is Re(z) = x and the imaginary part is Im(z) = y.

Algebraic Operations:
- Addition: (a+bi)+(c+di) = (a+c)+i(b+d)
- Subtraction: (a+bi)-(c+di) = (a-c)+i(b-d)
- Multiplication: (a+bi)(c+di) = (ac-bd)+i(ad+bc)
- Division: (a+bi)/(c+di) = [(a+bi)(c-di)]/(c^2+d^2), rationalise by conjugate
- Conjugate: If z = x+iy, then z̄ = x-iy. Key properties: z+z̄ = 2Re(z), z-z̄ = 2iIm(z), z·z̄ = |z|², |z| = sqrt(x²+y²)
- Powers of i: i¹=i, i²=-1, i³=-i, i⁴=1, cycle repeats every 4. In general iⁿ = i^(n mod 4)

Modulus and Argument:
- |z| = sqrt(x²+y²). Properties: |z₁z₂| = |z₁||z₂|, |z₁/z₂| = |z₁|/|z₂|, |z₁+z₂| ≤ |z₁|+|z₂| (triangle inequality), |z₁-z₂| ≥ ||z₁|-|z₂||
- Am(z) = θ where tan θ = y/x. Principal value lies in (-π, π]. Careful with quadrant adjustments.

Polar/Cauchy Form: z = r(cosθ + i sinθ) = r·cisθ, where r = |z|, θ = arg(z)
- De Moivre's Theorem: [r·cisθ]ⁿ = rⁿ·cis(nθ) = rⁿ(cos nθ + i sin nθ). Valid for integer n.
- Multiplication in polar form: z₁·z₂ has modulus product and argument sum. Division: modulus quotient, argument difference.

Geometric Representation: Argand plane with real axis (x-axis) and imaginary axis (y-axis).
- |z-z₁| = constant → circle centre z₁ radius constant
- |z-z₁| = |z-z₂| → perpendicular bisector of segment joining z₁ and z₂
- |z-z₁| + |z-z₂| = constant (> |z₁-z₂|) → ellipse with foci z₁, z₂
- |z-z₁| - |z-z₂| = constant → hyperbola branch
- Re(z) = c → vertical line; Im(z) = c → horizontal line
- arg((z-z₁)/(z-z₂)) = constant → arc of circle
- |z-z₁| = k|z-z₂| (k≠1) → Apollonius circle; k=1 → straight line (perpendicular bisector)

Roots of Unity, Cube Roots of Unity, and Their Properties

nth Roots of Unity: The equation zⁿ = 1 has exactly n distinct roots given by z = cis(2kπ/n), k = 0, 1, 2, ..., n-1. These form a geometric progression with common ratio ω = cis(2π/n).

Cube Roots of Unity: Solving z³ = 1 gives z³ - 1 = 0 → (z-1)(z²+z+1) = 0. The roots are:
- 1, ω = cis(2π/3) = -½+i√3/2, ω² = cis(4π/3) = -½-i√3/2

Key Properties of ω:
- 1 + ω + ω² = 0
- ω³ = 1
- ω⁴ = ω, ω⁵ = ω² (cycle of 3)
- 1/ω = ω², 1/ω² = ω
- ω² is the complex conjugate of ω (since ω̄ = ω²)
- For non-real cube roots: z³ = 1 implies z ≠ 1 → z²+z+1 = 0

nth Roots of a Complex Number: To solve zⁿ = w where w = r·cisφ:
- z_k = r^(1/n) · cis[(φ + 2kπ)/n], k = 0, 1, ..., n-1
- These n roots are equally spaced on a circle of radius r^(1/n), forming a regular n-gon.

Equilateral Triangle with Cube Roots: The points 1, ω, ω² form an equilateral triangle inscribed in the unit circle.

Condition for Collinearity: Three points z₁, z₂, z₃ are collinear if (z₃-z₁)/(z₂-z₁) is real.

Rotation Theorem: Rotating z about z₀ by angle θ counterclockwise gives z' = z₀ + (z-z₀)·cisθ.

Quadratic Equations: Formation, Nature of Roots, and Relationship Between Roots and Coefficients

Standard Form: ax²+bx+c = 0, a ≠ 0. The quadratic formula: x = [-b ± sqrt(b²-4ac)]/(2a)

Discriminant D = b²-4ac determines the nature of roots:
- D > 0, perfect square → two distinct real rational roots
- D > 0, not perfect square → two distinct real irrational roots
- D = 0 → two equal real roots (repeated root) x = -b/(2a)
- D < 0 → two complex conjugate roots α, ᾱ

Sum and Product of Roots (α, β):
- α + β = -b/a
- αβ = c/a
- (α-β)² = D/a², so |α-β| = sqrt(D)/|a|
- α²+β² = (α+β)²-2αβ = b²/a² - 2c/a
- α³+β³ = (α+β)³-3αβ(α+β) = -b³/a³ + 3bc/a²
- 1/α + 1/β = -b/c, 1/αβ = a/c

Construction from Roots: x²-(α+β)x+αβ = 0, i.e., x²-(-b/a)x+(c/a) = 0 → ax²+bx+c = 0 ✓

Reciprocal Equation: If roots are reciprocals, c = a. Biquadratic ax⁴+bx²+c = 0 can be reduced to quadratic in x².

Common Root Condition: If αx²+βx+γ = 0 and a₁x²+b₁x+c₁ = 0 share a root α, then:
- (αβ₁-α₁β)·γ = (αγ₁-α₁γ)·β₁ (cross-multiplication result)
- Alternatively: (βγ₁-β₁γ)/(γ α₁-γ₁α) = (αβ₁-α₁β)/(α γ₁-α₁γ) ...

Condition for Both Roots Greater Than k: D≥0, f(k) has same sign as a, and vertex x = -b/(2a) > k (for a>0: D≥0, f(k)>0, -b/(2a)>k)

Location of Roots: Sign Changes, Interval Conditions, and Graphical Interpretation

Let f(x) = ax²+bx+c, a ≠ 0. To locate roots relative to a number k:

Both Roots Greater Than k:
1. D ≥ 0 (real roots exist)
2. f(k) has the same sign as a (i.e., a·f(k) > 0)
3. Vertex -b/(2a) > k

Both Roots Less Than k:
1. D ≥ 0
2. a·f(k) > 0
3. Vertex -b/(2a) < k

One Root Greater Than k and One Less Than k: a·f(k) < 0 (this alone guarantees it, regardless of D)

Roots in Interval (k₁, k₂):
1. D ≥ 0
2. a·f(k₁) > 0
3. a·f(k₂) > 0
4. k₁ < -b/(2a) < k₂

One Root in (k₁,k₂) and Other Outside: a·f(k₁)·a·f(k₂) < 0 (guarantees a root between k₁ and k₂)

Equal Roots: D = 0, root at x = -b/(2a)

Sign Chart Approach: For a>0, f(x) opens upward. f(x) < 0 between the roots (if real), f(x) > 0 outside. For a<0, reverse.

Important Warning: These conditions assume real coefficients and real roots. Always verify D ≥ 0 first when requiring real roots in a specific interval.

Quadratic Expressions: Maximum/Minimum Value and Inequalities

Vertex Form: f(x) = ax²+bx+c = a[x + b/(2a)]² + (4ac-b²)/(4a) = a(x-h)²+k, where h = -b/(2a), k = (4ac-b²)/(4a) = -D/(4a)

Maximum/Minimum Value:
- If a > 0 (parabola opens up): minimum value = k = -D/(4a) at x = -b/(2a). No maximum.
- If a < 0 (parabola opens down): maximum value = k = -D/(4a) at x = -b/(2a). No minimum.

Sign of Quadratic Expression:
- a > 0, D < 0: f(x) > 0 for all real x (always positive)
- a > 0, D = 0: f(x) ≥ 0 for all real x
- a > 0, D > 0: f(x) > 0 outside roots, f(x) < 0 between roots
- a < 0, D < 0: f(x) < 0 for all real x (always negative)
- a < 0, D = 0: f(x) ≤ 0 for all real x
- a < 0, D > 0: f(x) < 0 outside roots, f(x) > 0 between roots

Solution of Quadratic Inequalities: Solve ax²+bx+c > 0 (or < 0, ≥ 0, ≤ 0) by finding roots and testing intervals.
- (x-α)(x-β) > 0 with α < β: solution is x ∈ (-∞, α) ∪ (β, ∞)
- (x-α)(x-β) < 0 with α < β: solution is x ∈ (α, β)
- For a < 0, multiply through by -1 and reverse the inequality sign.

Rational Inequalities: For P(x)/Q(x) > 0, find zeros of numerator and denominator, make sign chart, exclude denominator zeros. Wavy curve method applies.

Important Identity: (x²+px+q)(x²+rx+s) expansion used in factorisation of biquadratics.

Arithmetic Progression (AP): nth Term, Sum, and Properties

Definition: A sequence where the difference between consecutive terms is constant. This constant is called the common difference d.

nth Term: aₙ = a + (n-1)d, where a = first term, d = common difference.

Sum of n Terms: Sₙ = n/2[2a + (n-1)d] = n/2(a + l), where l = last term = aₙ.

Key Properties of AP:
- If a₁, a₂, ..., aₙ are in AP, then ka₁+b, ka₂+b, ..., kaₙ+b are also in AP (common difference = kd)
- Sum of terms equidistant from ends is constant: a₁+aₙ = a₂+aₙ₋₁ = ... = 2×(middle term if n odd)
- Three numbers in AP: a-d, a, a+d (sum = 3a)
- Four numbers in AP: a-3d, a-d, a+d, a+3d (sum = 4a)
- If f(n) is linear in n, then the sequence is AP. If Sₙ is quadratic in n with zero constant term, sequence is AP.
- Arithmetic Mean: A = (a+b)/2 is the AP mean between a and b.

Important Formulae:
- Σn = n(n+1)/2
- Σn² = n(n+1)(2n+1)/6
- Σn³ = [n(n+1)/2]²

Application: In problems involving partial sums, if Sₙ = An²+Bn, then the sequence is AP with d = 2A and a = A+B.

Geometric Progression (GP): nth Term, Sum, Infinite GP, and Properties

Definition: A sequence where the ratio of consecutive terms is constant. This constant is called the common ratio r.

nth Term: aₙ = a·rⁿ⁻¹, where a = first term.

Sum of n Terms:
- If r ≠ 1: Sₙ = a(rⁿ-1)/(r-1) = a(1-rⁿ)/(1-r)
- If r = 1: Sₙ = na
- If |r| < 1 and n→∞: S∞ = a/(1-r)

Key Properties of GP:
- If a₁, a₂, ..., aₙ are in GP with ratio r, then ka₁, ka₂, ..., kaₙ are in GP with same ratio r. Also a₁ᵖ, a₂ᵖ, ..., aₙᵖ are in GP with ratio rᵖ.
- If a₁, a₂, ..., aₙ are in GP, then log(a₁), log(a₂), ..., log(aₙ) are in AP.
- Three numbers in GP: a/r, a, ar (product = a³)
- Four numbers in GP: a/r³, a/r, ar, ar³ (product = a⁴)
- Geometric Mean: G = sqrt(ab) is the GP mean between positive a and b.

Important Formulae:
- Σrⁿ = r(rⁿ-1)/(r-1) for r ≠ 1
- Σxⁿ = x(xⁿ-1)/(x-1)
- Product of GP terms: P = aⁿ·rⁿ⁽ⁿ⁻¹⁾/²

Infinite GP with |r| < 1: Sum converges to a/(1-r). Used heavily in recurring decimals and series problems.

Arithmetico-GP Series: Series where terms are product of AP and GP terms. Use the standard method: multiply by r, subtract from original, get telescoping form.

Harmonic Progression (HP) and Mean Value Theorems for Progressions

Harmonic Progression: A sequence is in HP if the reciprocals of its terms form an AP.
- nth term: aₙ = 1/[a+(n-1)d], where a, d come from the reciprocal AP.
- Sum of HP has no simple closed form (unlike AP/GP).

Three Means Between Two Numbers a and b:
- Arithmetic Mean: A = (a+b)/2
- Geometric Mean: G = sqrt(ab) (for positive a, b)
- Harmonic Mean: H = 2ab/(a+b)

Relation Between Means: For positive a ≠ b: A > G > H, and G² = A·H.

If m arithmetic means, n geometric means, p harmonic means are inserted between a and b:
- The common differences/ratios relate to the number of means inserted.
- For m AMs: d = (b-a)/(m+1)
- For n GMs: r = (b/a)^(1/(n+1))
- For p HMs: work through reciprocals as AP with d' = (1/b-1/a)/(p+1)

Important Results:
- AM ≥ GM for positive reals (equality iff all numbers equal)
- GM ≥ HM for positive reals (equality iff all numbers equal)
- Therefore AM ≥ GM ≥ HM
- For any finite set of positive real numbers, these inequalities hold strictly unless all numbers are equal.

Cauchy-Schwarz and Hölder are often tested alongside these mean inequalities in JEE Advanced.

Permutations: Fundamental Principle, Formula Derivation, and Restricted Arrangements

Fundamental Counting Principle: If event A has m outcomes and event B has n outcomes, then A followed by B has m×n outcomes. This extends to any number of sequential events.

Factorial: n! = n×(n-1)×...×2×1, with 0! = 1.

Permutation (Ordered Selection): P(n,r) = n!/(n-r)!, the number of ways to arrange r objects selected from n distinct objects.
- P(n,n) = n!
- P(n,0) = 1, P(n,1) = n
- P(n,r) = n×(n-1)×...×(n-r+1) — r consecutive descending factors
- Relation: P(n,r) = n × P(n-1,r-1)

Restricted Arrangement — Certain Items Always Together: Treat the bundled items as one super-object. If k items must be together: arrange (n-k+1) objects in (n-k+1)! ways, then arrange k items within bundle in k! ways. Total = k!×(n-k+1)!.

Restricted Arrangement — Certain Items Never Together: Total arrangements - arrangements where they are together = n! - k!×(n-k+1)!.

Circular Permutations:
- n distinct objects around a round table: (n-1)! (relative positions matter, no fixed starting point)
- If direction matters (clockwise ≠ anticlockwise): (n-1)!/2
- Necklace/bracelet problems: (n-1)!/2 since flipping is allowed

Repeated Elements: If n objects have p identical of one type, q of another, etc.: n!/(p!·q!·r!·...)

Combinations: Formula, Properties, and Applications in Selection Problems

Combination (Unordered Selection): C(n,r) = ⁿCᵣ = n!/[r!(n-r)!], the number of ways to select r objects from n without regard to order.
- C(n,0) = 1, C(n,n) = 1, C(n,1) = n
- C(n,r) = C(n,n-r) (symmetry property)
- C(n,r) = C(n-1,r-1) + C(n-1,r) (Pascal's identity — prove by factoring)
- r! × C(n,r) = P(n,r)

Key Properties:
- C(n,r) + C(n,r+1) = C(n+1,r+1)
- C(n,r-1) + C(n,r) = C(n+1,r)
- Σᵣ₌₀ⁿ C(n,r) = 2ⁿ
- C(n,r)/C(n,r-1) = (n-r+1)/r
- C(2n,r) expansion related to central binomial coefficients

Selection Problems:
- From n distinct items, select r: C(n,r)
- With at least one: 2ⁿ - 1
- With at least p: C(n,p)+C(n,p+1)+...+C(n,n)
- Dividing n items into groups of sizes p,q,r: n!/(p!q!r!) if groups are distinguishable

Distribution Problems:
- Distributing n distinct items into r distinct boxes (each box may be empty): rⁿ
- Distributing n distinct items into r distinct boxes (none empty): r!×S₂(n,r) where S₂ is Stirling number of second kind
- Guaranteeing at least one item per box uses inclusion-exclusion principle

Important: Always determine whether order matters (permutation) or not (combination) before applying formulas. This is the most common error source.

Binomial Theorem: General Term, Middle Terms, and Coefficient Properties

Binomial Theorem: (a+b)ⁿ = Σᵣ₌₀ⁿ ⁿCᵣ·aⁿ⁻ʳ·bʳ = ⁿC₀aⁿ + ⁿC₁aⁿ⁻¹b + ... + ⁿCₙbⁿ

General Term (r+1)th term: Tᵣ₊₁ = ⁿCᵣ·aⁿ⁻ʳ·bʳ
- For (a-x)ⁿ: Tᵣ₊₁ = (-1)ʳ·ⁿCᵣ·aⁿ⁻ʳ·xʳ
- For (x+a)ⁿ: same as (a+x)ⁿ

Middle Terms:
- If n is even: middle term is (n/2+1)th term, r = n/2. Single middle term.
- If n is odd: two middle terms — (n+1)/2 th and (n+3)/2 th terms, r = (n-1)/2 and r = (n+1)/2.

Binomial Coefficient Properties:
- ⁿC₀ + ⁿC₁ + ... + ⁿCₙ = 2ⁿ
- ⁿC₀ - ⁿC₁ + ⁿC₂ - ... + (-1)ⁿⁿCₙ = 0 (for n ≥ 1)
- ⁿC₀ + ⁿC₂ + ⁿC₄ + ... = ⁿC₁ + ⁿC₃ + ⁿC₅ + ... = 2ⁿ⁻¹
- Sum of coefficients with odd indices equals sum with even indices = 2ⁿ⁻¹
- ⁿCᵣ is maximum when r = n/2 (n even) or r = n/2 and (n-1)/2 (n odd)

Important Expansions:
- (1+x)⁻ⁿ = 1 - nx + n(n+1)/2! ·x² - n(n+1)(n+2)/3! ·x³ + ... (infinite series for |x|<1)
- (1-x)⁻ⁿ = 1 + nx + n(n+1)/2! ·x² + ...
- eˣ = Σ xⁿ/n!, ln(1+x) = x - x²/2 + x³/3 - ..., sin x = x - x³/3! + x⁵/5! - ...

Binomial Theorem: Independent Term, Ratio Method, and Special Expansions

Finding the Independent Term (Term Free of x): Set the power of x in the general term Tᵣ₊₁ to zero and solve for r. Then substitute back.
- For (xᵃ + b/xᶜ)ⁿ: Tᵣ₊₁ = ⁿCᵣ·xᵃ⁽ⁿ⁻ʳ⁾·bʳ·x⁻ᶜʳ = ⁿCᵣ·bʳ·xᵃ⁽ⁿ⁻ʳ⁾⁻ᶜʳ. Set exponent = 0.
- Must verify that the solved r is a non-negative integer ≤ n.

Ratio Method for Greatest Term: For (1+x)ⁿ with x > 0:
- Tᵣ/Tᵣ₋₁ = [(n-r+1)/r]·x
- If ratio > 1, terms are increasing; if ratio < 1, decreasing.
- Maximum term occurs when Tₖ/Tₖ₋₁ ≥ 1 and Tₖ₊₁/Tₖ ≤ 1.
- Solving: k ≤ (n+1)|x|/(1+|x|). If (n+1)|x|/(1+|x|) is integer m, then Tₘ and Tₘ₊₁ are both greatest.

Special Expansions Frequently Tested:
- (1+x)ᵖ where p is rational: infinite series valid for |x|<1. General term involves falling factorial.
- (1-x)⁻¹ = 1+x+x²+..., (1-x)⁻² = 1+2x+3x²+...
- Coefficient of xʳ in (1+x)ⁿ(1+x)ᵐ = coefficient of xʳ in (1+x)ⁿ⁺ᵐ = ⁿ⁺ᵐCᵣ
- Coefficient of xʳ in (1+x)ⁿ·(1+1/x)ᵐ requires careful bookkeeping.

Number of Terms:
- In (a+b)ⁿ: n+1 terms (finite)
- In (1+x)⁻ⁿ: infinite terms (but only first few needed for approximation)

Matrices: Order, Types, Addition, Scalar Multiplication, and Transpose

Matrix Definition: A rectangular array of m×n elements arranged in m rows and n columns. Denoted A = [aᵢⱼ]ᵣₓₛ.

Types of Matrices:
- Row matrix: 1×n, Column matrix: m×1
- Square matrix: m = n. Diagonal elements are aᵢᵢ.
- Null/Zero matrix: all elements zero.
- Scalar matrix: diagonal matrix with all diagonal entries equal (kI).
- Identity matrix I: diagonal entries = 1, off-diagonal = 0.
- Upper triangular: aᵢⱼ = 0 for i > j. Lower triangular: aᵢⱼ = 0 for i < j.
- Symmetric: A' = A (aᵢⱼ = aⱼᵢ). Skew-symmetric: A' = -A (diagonal entries must be 0).
- Orthogonal: A·A' = A'·A = I.
- Singular: |A| = 0. Non-singular: |A| ≠ 0.

Operations:
- Addition: A+B element-wise. Commutative: A+B=B+A. Associative: (A+B)+C=A+(B+C).
- Scalar multiplication: kA multiplies every element by k.
- Transpose: A' swaps rows and columns. (A')' = A, (kA)' = kA', (A+B)' = A'+B', (AB)' = B'A'
- Note: (AB)' ≠ A'B'. The order reverses.

Key Identity: A+A' is always symmetric. A-A' is always skew-symmetric. Every square matrix can be expressed as A = ½(A+A') + ½(A-A') (symmetric + skew-symmetric parts).

Matrix Multiplication, Properties, and Inverse of a Matrix

Matrix Multiplication: AB exists when number of columns of A = number of rows of B. If A is m×n and B is n×p, then AB is m×p.
- (AB)ᵢⱼ = Σₖ aᵢₖ·bₖⱼ
- Matrix multiplication is NOT commutative: AB ≠ BA generally.
- BUT: AB = O does NOT imply A = O or B = O (zero divisors exist for matrices).
- Associative: (AB)C = A(BC)
- Distributive: A(B+C) = AB+AC, (B+C)A = BA+CA
- (AB)' = B'A' (order reversal in transpose)
- (AB)⁻¹ = B⁻¹A⁻¹ (when both invertible)

Inverse of a Matrix:
- A⁻¹ exists iff |A| ≠ 0 (non-singular). For singular matrices, inverse does not exist.
- AA⁻¹ = A⁻¹A = I
- (A⁻¹)⁻¹ = A, (A')⁻¹ = (A⁻¹)', (kA)⁻¹ = (1/k)A⁻¹
- Adjoint method: A⁻¹ = adj(A)/|A|
- Gauss-Jordan elimination is alternative method for computing inverse.

Elementary Row Operations (for finding inverse): Apply to [A|I]; when A becomes I, right side becomes A⁻¹.

Rank of a Matrix: Maximum order of non-zero minor. Determined by reducing to row echelon form. Rank(A) ≤ min(m,n). Rank(AB) ≤ min(Rank(A), Rank(B)).

Determinants: Expansion, Properties, and Area Applications

Second Order: |a b; c d| = ad-bc

Third Order (Sarrus' Rule): For 3×3 matrix, expand along any row or column:
|a₁ b₁ c₁; a₂ b₂ c₂; a₃ b₃ c₃| = a₁(b₂c₃-b₃c₂) - b₁(a₂c₃-a₃c₂) + c₁(a₂b₃-a₃b₂)

Key Properties:
- |A'| = |A| (transpose doesn't change determinant)
- |kA| = kⁿ|A| for n×n matrix
- If any row/column is all zeros, determinant = 0
- If two rows/columns are identical, determinant = 0
- Interchanging two rows changes sign of determinant
- Multiplying a row by k multiplies determinant by k
- Adding a multiple of one row to another leaves determinant unchanged
- |AB| = |A|·|B|

Applications:
- Area of triangle with vertices (x₁,y₁),(x₂,y₂),(x₃,y₃) = ½|x₁(y₂-y₃)+x₂(y₃-y₁)+x₃(y₁-y₂)|
= ½|det[[x₁,y₁,1],[x₂,y₂,1],[x₃,y₃,1]]|
- Three points are collinear iff area = 0
- System of equations: AX = B. If |A|≠0, unique solution X = A⁻¹B.
If |A|=0 and (adj A)B ≠ 0: no solution (inconsistent).
If |A|=0 and (adj A)B = 0: infinitely many solutions.

Cramer's Rule: For system a₁x+b₁y=c₁, a₂x+b₂y=c₂: x = Δₓ/Δ, y = Δᵧ/Δ where Δ is coefficient determinant.

Adjoint and Inverse Using Adjoint: Step-by-Step Procedure

Cofactor: Cᵢⱼ = (-1)ⁱ⁺ʲ·Mᵢⱼ, where Mᵢⱼ is the minor (determinant after deleting row i and column j).

Adj(A): adj(A) = matrix of cofactors transposed. adj(A)ᵢⱼ = Cⱼᵢ (note the index swap).

Fundamental Property: A·adj(A) = adj(A)·A = |A|·I

Inverse via Adjoint: A⁻¹ = adj(A)/|A|, valid only when |A| ≠ 0.

Step-by-step procedure for 3×3 matrix:
1. Compute all 9 minors Mᵢⱼ (delete row i, col j, compute 2×2 determinant)
2. Apply sign pattern (+-+/-+-/+ -+) to get cofactors Cᵢⱼ
3. Transpose the cofactor matrix to get adj(A)
4. Compute |A|
5. A⁻¹ = adj(A)/|A|

Key Results:
- |adj(A)| = |A|ⁿ⁻¹ for n×n matrix. For 3×3: |adj(A)| = |A|²
- adj(adj(A)) = |A|ⁿ⁻² · A. For 3×3: adj(adj(A)) = |A|·A
- If A is orthogonal, adj(A) = |A|·A⁻¹ = ±A'

Verification: Always check A·A⁻¹ = I after computing inverse.

Elementary Transformations and Solving Linear Systems Using Matrices

Elementary Row Operations (Three Types):
1. interchange: Rᵢ ↔ Rⱼ
2. scaling: Rᵢ → kRᵢ (k ≠ 0)
3. replacement: Rᵢ → Rᵢ + kRⱼ

Elementary Column Operations are analogous and similarly preserve rank/determinant properties (up to sign for interchange).

Solving AX = B:
- Case 1: |A| ≠ 0 → unique solution X = A⁻¹B
- Case 2: |A| = 0 → system is either inconsistent or has infinitely many solutions
- Compute adj(A)·B
- If adj(A)·B ≠ 0: inconsistent, no solution
- If adj(A)·B = 0: may have infinitely many solutions; use rank method

Rank Method (Kronecker-Capelli):
- Augmented matrix [A:B]
- Reduce both A and [A:B] to row echelon form
- If Rank(A) ≠ Rank([A:B]): no solution
- If Rank(A) = Rank([A:B]) = n (number of variables): unique solution
- If Rank(A) = Rank([A:B]) = r < n: infinitely many solutions with (n-r) free parameters

Gauss Elimination: Reduce [A:B] to upper triangular form, then back-substitute.

Gauss-Jordan: Reduce A to reduced row echelon form (identity), reading solution directly.

Theory of Equations: Polynomial Roots, Factor Theorem, and Remainder Theorem

Polynomial: P(x) = a₀xⁿ + a₁xⁿ⁻¹ + ... + aₙ, degree n, leading coefficient a₀.

Factor Theorem: (x-α) is a factor of P(x) if and only if P(α) = 0.

Remainder Theorem: When P(x) is divided by (x-a), the remainder is P(a).
- When divided by (ax+b), remainder is P(-b/a)
- When divided by (x-a)(x-b), remainder is linear: Rx+S where R=a and R=b give two equations.

Division Algorithm: P(x) = Q(x)·D(x) + R(x), where deg(R) < deg(D).

Number of Roots: A polynomial of degree n has exactly n roots (counting multiplicity) in the complex plane (Fundamental Theorem of Algebra). Real roots are a subset.

Rational Root Theorem: If P(x) = aₙxⁿ+...+a₀ with integer coefficients, then any rational root p/q (in lowest terms) satisfies: p divides a₀ and q divides aₙ.

Descartes' Rule of Signs:
- Number of positive real roots ≤ number of sign changes in P(x), differing by an even number.
- Number of negative real roots ≤ sign changes in P(-x), differing by an even number.

Relationship Between Roots and Coefficients (for ax³+bx²+cx+d=0 with roots α,β,γ):
- α+β+γ = -b/a
- αβ+βγ+γα = c/a
- αβγ = -d/a

Transformation of Equations: Shifting Roots, Reciprocal Roots, and Scale Changes

Shifting Roots by h: To find equation whose roots are (α+h),(β+h),... replace x by (x-h) in original equation. Example: roots increased by 2 → replace x by (x-2).

Multiplying Roots by k: Replace x by x/k. Roots become kα, kβ, ...

Reciprocal Roots: Replace x by 1/x and multiply through by xⁿ. Roots become 1/α, 1/β, ...

Squares of Roots: If y = x², substitute x = √y. For equation with roots α², β², ..., γ²: replace x by √y in P(x)=0, rearrange to remove radicals, then square again if needed.

Equation with Roots (α+β),(β+γ),(γ+α) for cubic:
For ax³+bx²+cx+d=0 with roots α,β,γ:
- s₁ = α+β+γ = -b/a
- (α+β) = s₁-γ, etc.
- New equation has roots s₁-α, s₁-β, s₁-γ
- Substitute x = s₁-t (i.e., t = s₁-x) in original to get equation in t, then rename t as x.

Common Root of Two Equations: If α is common root of P(x)=0 and Q(x)=0, then α satisfies both. For quadratics, use cross-multiplication method. For higher degrees, compute GCD of P and Q.

Location of Roots of Polynomials: Sign Analysis and Intermediate Value Application

Intermediate Value Theorem (for polynomials): If P(x) is continuous (all polynomials are) and P(a)·P(b) < 0, then there exists at least one real root in (a,b).

Sign Chart for Polynomial Roots:
- Find all real roots (exact or approximate)
- Plot on number line
- Test sign in each interval using a test point
- Odd multiplicity roots cross the axis; even multiplicity roots touch and turn back

Number of Real Roots:
- A polynomial of odd degree has at least one real root (limits at ±∞ have opposite signs)
- A polynomial of even degree may have 0 real roots
- Maximum number of real roots = degree n

Using Derivatives for Root Location:
- Between any two real roots of P(x)=0, there is at least one root of P'(x)=0 (Rolle's Theorem)
- If P'(x) has no real roots, P(x) has at most one real root
- Critical points of P(x) give local extrema; sign changes of P at these points indicate roots

Descartes' Rule Refinement:
- Sign changes in P(x) gives upper bound on positive real roots
- Sign changes in P(-x) gives upper bound on negative real roots
- Difference from actual count is always even

Example: For P(x) = x³-6x²+11x-6, check P(0)=-6, P(1) = -1+ -6+11-6 = -2, P(2)=8-24+22-6=0, so x=2 is a root. Factor out (x-2) to continue.

Linear Inequalities: Solving, Number Line Representation, and System of Inequalities

Single Linear Inequality: ax+b > 0 (or <, ≥, ≤)
- Solution is always an interval on the number line.
- When multiplying/dividing by negative number, reverse inequality sign.
- Critical point: x = -b/a (where expression equals zero)

Quadratic Inequality: ax²+bx+c > 0
- Find roots α, β (assume α < β, a > 0)
- x²+bx+c > 0: solution x ∈ (-∞,α)∪(β,∞) (outside roots)
- x²+bx+c < 0: solution x ∈ (α,β) (between roots)
- Include endpoints for ≥ and ≤ respectively
- If discriminant < 0 and a > 0: always positive, solution is all real numbers for >0

System of Linear Inequalities:
- Graph each inequality on same coordinate plane
- Solution region is intersection (shaded overlap) of all half-planes
- For 2-variable systems, feasible region is polygonal (possibly unbounded)
- Check corner points for optimisation (linear programming)

Absolute Value Inequalities:
- |x| < a: -a < x < a (for a > 0)
- |x| > a: x < -a or x > a (for a > 0)
- |x-a| < |x-b|: distance from a is less than distance from b; solution depends on position relative to midpoint (a+b)/2

Set Theory Fundamentals: Union, Intersection, Complement, and Venn Diagrams

Set Definitions:
- Union: A∪B = {x : x∈A or x∈B}
- Intersection: A∩B = {x : x∈A and x∈B}
- Complement: A' = U\A = {x∈U : x∉A}
- Difference: A\B = A∩B' = {x : x∈A and x∉B}
- Symmetric Difference: A Δ B = (A\B)∪(B\A) = (A∪B)\(A∩B)

Key Laws:
- Commutative: A∪B=B∪A, A∩B=B∩A
- Associative: (A∪B)∪C=A∪(B∪C), (A∩B)∩C=A∩(B∩C)
- Distributive: A∪(B∩C)=(A∪B)∩(A∪C), A∩(B∪C)=(A∩B)∪(A∩C)
- De Morgan's: (A∪B)' = A'∩B', (A∩B)' = A'∪B'
- Idempotent: A∪A=A, A∩A=A
- Identity: A∪∅=A, A∩U=A
- Complement: A∪A'=U, A∩A'=∅

Cardinality Formulas:
- n(A∪B) = n(A)+n(B)-n(A∩B)
- n(A∪B∪C) = n(A)+n(B)+n(C)-n(A∩B)-n(B∩C)-n(C∩A)+n(A∩B∩C)
- n(A\B) = n(A)-n(A∩B)
- For universal set U: n(A') = n(U)-n(A)

Subset Relations: A⊆B means every element of A is in B. A⊂B means proper subset (A⊆B and A≠B).

Relations and Functions: Domain, Range, Composition, and Inverse Functions

Relation: Subset of A×B. Domain = set of all first components; Range = set of all second components.

Function: A relation where each element of domain maps to exactly one element of codomain.
f: A→B, each a∈A has unique f(a)∈B.

Types of Functions:
- Injective (one-to-one): f(a₁)=f(a₂)→a₁=a₂. Horizontal line test.
- Surjective (onto): Range = Codomain. Every element of B is mapped to.
- Bijective: both injective and surjective. Has a well-defined inverse.
- Constant: f(x) = c for all x.
- Identity: f(x) = x.
- Polynomial, rational, trigonometric, exponential, logarithmic functions.

Composition: (fog)(x) = f(g(x)). Not commutative generally. (fog)∘h = fo(g∘h).

Inverse Function: f⁻¹ exists iff f is bijective. f⁻¹(f(x)) = x and f(f⁻¹(x)) = x. Graphically, f⁻¹ is reflection of f across y=x.
- To find f⁻¹: set y=f(x), solve for x in terms of y, then swap x and y.
- (fog)⁻¹ = g⁻¹∘f⁻¹ (reverse order)

Domain and Range Rules:
- Even root: radicand ≥ 0
- Logarithm: argument > 0, base > 0 and ≠ 1
- Rational function: denominator ≠ 0
- Square root in denominator: radicand > 0

Exponential and Logarithmic Functions: Properties, Equations, and Graphs

Exponential Function: f(x) = aˣ, a > 0, a ≠ 1
- Domain: ℝ, Range: (0, ∞)
- f(x) > 0 for all x
- a > 1: increasing; 0 < a < 1: decreasing
- a⁰ = 1 always. Passes through (0,1).
- Horizontal asymptote: y = 0 (as x→-∞ for a>1)

Logarithmic Function: f(x) = logₐx, inverse of exponential
- Domain: (0, ∞), Range: ℝ
- logₐ1 = 0, logₐa = 1
- a > 1: increasing; 0 < a < 1: decreasing
- Vertical asymptote: x = 0
- Natural log: ln x = logₑx, e ≈ 2.71828

Logarithm Properties:
- log(xy) = log x + log y
- log(x/y) = log x - log y
- log(xⁿ) = n·log x
- Change of base: logₐx = log_b x / log_b a
- logₐb · log_b a = 1
- log_a(aˣ) = x, a^(log_a x) = x
- Common logs (base 10): log₁₀ x = log x

Solving Exponential Equations:
- Same base method: a^(f(x)) = a^(g(x)) → f(x) = g(x)
- Substitution: a^(2x) + p·aˣ + q = 0 → let y = aˣ, solve quadratic
- Taking log both sides when bases differ

Solving Logarithmic Equations:
- Combine logs using properties, convert to exponential form
- Always check domain restrictions (arguments must be positive)
- Extraneous solutions are common

Common mistakes

  • Assuming AB = BA for matrices — matrix multiplication is NOT commutative
  • Forgetting to verify D ≥ 0 before claiming roots are real in a quadratic
  • Using AP formulas directly on HP terms instead of converting to AP via reciprocals
  • In binomial theorem, using r instead of (r+1) for the term number — general term is Tᵣ₊₁ not Tᵣ
  • When finding the independent term in binomial expansion, forgetting to check that the computed r is a non-negative integer
  • In permutation problems with restrictions, calculating only the 'together' cases and forgetting to subtract from total when asked for 'never together'
  • Circular permutation: writing n! instead of (n-1)! — rotationally equivalent arrangements are counted as one
  • For complex numbers: computing arg(z) as tan⁻¹(y/x) without considering the correct quadrant
  • In quadratic inequalities: forgetting to reverse the inequality sign when the leading coefficient a < 0
  • Assuming AB = O implies A = O or B = O for matrices — this is false (zero divisors exist)
  • In logarithmic equations: accepting extraneous solutions without checking the domain (argument must be positive)
  • Confusing C(n,r) with P(n,r) — combinations ignore order, permutations respect it
  • In the relation between roots and coefficients for cubic: sign errors — sum of roots = -b/a, sum of pairs = c/a, product = -d/a
  • When computing adj(A), forgetting to transpose the cofactor matrix — adj(A) is the TRANSPOSE of the cofactor matrix
  • In GM/HM problems: applying formulas to negative numbers — GM and HM are only defined for positive reals
  • For the triangle inequality with complex numbers: writing |z₁+z₂| = |z₁|+|z₂| always — equality holds only when z₁/z₂ is a positive real
