1. Indefinite Integrals: Definitions, Standard Results and Fundamental Idea

An indefinite integral ∫f(x)dx represents the family of antiderivatives of f(x), written as F(x) + C where F'(x) = f(x). JEE Advanced expects fluency with every standard result and the ability to manipulate them creatively.

Basic power rule: ∫x^n dx = x^(n+1)/(n+1) + C for n ≠ -1. The exception at n = -1 leads to the logarithmic form ∫(1/x)dx = ln|x| + C.

Exponential forms: ∫e^x dx = e^x + C; ∫a^x dx = a^x/ln(a) + C for a > 0, a ≠ 1. These are frequently combined with chain-rule reversed versions: ∫e^(ax+b) dx = e^(ax+b)/a + C.

Trigonometric forms you must recall instantly: ∫sin x dx = -cos x + C; ∫cos x dx = sin x + C; ∫sec²x dx = tan x + C; ∫csc²x dx = -cot x + C; ∫sec x tan x dx = sec x + C; ∫csc x cot x dx = -csc x + C. For reciprocal squares: ∫sec x dx = ln|sec x + tan x| + C = ln|tan(x/2 + π/4)| + C; ∫csc x dx = ln|csc x - cot x| + C = ln|tan(x/2)| + C. These log forms appear constantly in reduction and partial fraction work.

Other key results: ∫tan x dx = -ln|cos x| + C = ln|sec x| + C; ∫cot x dx = ln|sin x| + C; ∫sec x / (sec x + tan x) dx and similar algebraic trig simplifications often reduce to these forms. Inverse-trig integrals include ∫1/√(1-x²) dx = arcsin x + C and ∫1/(1+x²) dx = arctan x + C, valid on |x| < 1 and all ℝ respectively. Note carefully that ∫1/√(x²+a²) dx = ln|x + √(x²+a²)| + C — this is NOT an inverse sine but a logarithmic form, a distinction JEE regularly tests by putting it alongside similar-looking expressions in MCQs.

2. Integration by Substitution: Patterns, Tricks and Complete Coverage

Substitution is the first tool for any non-trivial integral. The choice of substitution must simplify the integrand structurally, not just mechanically. JEE Advanced tests the pattern-recognition skill behind picking the right substitution.

Type 1 — Linear inside nonlinear: ∫f(ax+b) dx. Substitute u = ax+b, du = a dx. Simple but often disguised inside products or fractions. Common trap: forgetting to divide by 'a'.

Type 2 — Rational functions of the form P(x)/√(quadratic): Use Euler substitutions. For √(a²-x²), substitute x = a sin θ or x = a cos θ. For √(x²-a²), substitute x = a sec θ or x = a cosh t. For √(x²+a²), substitute x = a tan θ or x = a sinh t. Each substitution converts the radical into a single trigonometric/hyperbolic function that cancels cleanly.

Type 3 — Exponential-logarithmic mix: If the integrand contains both e^x and functions of e^x, substitute t = e^x. If it contains ln x with algebraic terms, substitute t = ln x. For mixed forms like x^x or x^(x+1), recognize that d/dx[x^x] = x^x(1 + ln x), which often guides the reverse direction.

Type 4 — Trigonometric rational functions R(sin x, cos x): When the integrand is a rational function of sin x and cos x, use t = tan(x/2). Then sin x = 2t/(1+t²), cos x = (1-t²)/(1+t²), dx = 2dt/(1+t²). This converts any such integral into a rational function of t, guaranteed to be solvable by partial fractions.

Type 5 — Symmetry substitutions: For integrals like ∫f(x)dx over symmetric limits or ∫₀^π xf(sin x)dx, use the property ∫₀^a f(x) dx = ∫₀^a f(a-x) dx. Also ∫₀^(π/2) f(sin x, cos x) dx = ∫₀^(π/2) f(cos x, sin x) dx when both limits are present.

Type 6 — Reciprocal-type substitution: For integrals involving √(x² ± a²) with x in numerator and radical in denominator, try x = 1/t, dx = -1/t² dt. This sometimes flips a difficult form into a simpler one.

Type 7 — Conjugate multiplication: For integrands containing √(x+a) ± √(x+a), multiply numerator and denominator by the conjugate first, then substitute.

Type 8 — Parametric integrals: If x = f(t), y = g(t), then ∫h(x,y) dx = ∫h(f(t),g(t)) · f'(t) dt. Common in arc-length and area problems later.

3. Integration by Parts: Formula, LIATE Rule, Reductions and Worked Cases

Integration by parts derives from the product rule: ∫u dv = uv - ∫v du. The success depends entirely on choosing u and dv correctly. JEE Advanced tests deep mastery here — not just the first application but chains of them.

LIATE rule for choosing u: Logarithmic, Inverse trigonometric, Algebraic, Trigonometric, Exponential. The function appearing earlier in LIATE becomes u. This is a heuristic, not a law — always verify that ∫v du is simpler than the original.

Standard worked cases:
- ∫ln x dx = x ln x - x + C (u = ln x, dv = dx).
- ∫arcsin x dx = x arcsin x + √(1-x²) + C.
- ∫arctan x dx = x arctan x - (1/2)ln(1+x²) + C.
- ∫e^x[f(x) + f'(x)] dx = e^x f(x) + C. This is extremely high-yield. When you see e^x multiplied by a sum of a function and its derivative, the answer is immediate. Also ∫e^x[f(x) - f'(x)] dx = e^x f(x) + C requires a minus sign.
- ∫x^n e^x dx: Apply parts n times, each time reducing the power of x. The pattern gives e^x·[x^n - n x^(n-1) + n(n-1)x^(n-2) - ... + (-1)^n n!].
- ∫x^n sin x dx and ∫x^n cos x dx: Similar repeated-parts approach. Table method (tabular integration) is fastest for n ≥ 2.
- ∫sinⁿx dx and ∫cosⁿx dx: Reduction formulas. Let I_n = ∫sinⁿx dx. Then I_n = -sin^(n-1)x·cos x/n + (n-1)/n · I_(n-2). Similarly for cosine with a sign change. These work for both indefinite and definite integrals.
- ∫secⁿx dx: Let I_n = ∫secⁿx dx. Then I_n = sec^(n-2)x·tan x/(n-1) + (n-2)/(n-1)·I_(n-2).
- ∫e^(ax)sin(bx) dx = e^(ax)[a sin(bx) - b cos(bx)]/(a²+b²) + C. Apply parts twice and solve algebraically for the integral.
- ∫e^(ax)cos(bx) dx = e^(ax)[a cos(bx) + b sin(bx)]/(a²+b²) + C.
- Wallis formula for definite integrals: ∫₀^(π/2) sinⁿx dx = ∫₀^(π/2) cosⁿx dx. For even n=2m: (2m-1)!!/(2m)!! · π/2. For odd n=2m+1: (2m)!!/(2m+1)!!. Double factorial notation: n!! = n·(n-2)·... down to 1 or 2.

Pitfall: In ∫x·e^x dx, choosing u = e^x (wrong) gives ∫e^x dx = e^x, which doesn't help. Always choose the function that simplifies on differentiation as u.

4. Partial Fractions and Special Integral Forms

Partial fraction decomposition is essential whenever the integrand is a rational function P(x)/Q(x) with deg(P) < deg(Q). If deg(P) ≥ deg(Q), perform polynomial division first.

Type A — Distinct linear factors: Q(x) = (x-a₁)(x-a₂)...(x-aₙ). Then P/Q = A₁/(x-a₁) + A₂/(x-a₂) + ... + Aₙ/(x-aₙ). Solve for constants by equating numerators or substituting root values.

Type B — Repeated linear factors: (x-a)ᵐ contributes m terms: A₁/(x-a) + A₂/(x-a)² + ... + Aₘ/(x-a)ᵐ. Each term integrates to a logarithm (for power 1) or a negative-power formula (for higher powers).

Type C — Irreducible quadratic factors: (x²+bx+c)ᵏ where discriminant < 0. Each power contributes a linear numerator: (Ax+B)/(x²+bx+c) + (Cx+D)/(x²+bx+c)² + .... Complete the square in the denominator and use substitution to reduce to standard forms ∫1/√(a²-u²) du = arcsin(u/a) and ∫1/(a²+u²) du = (1/a)arctan(u/a).

Type D — Improper rational functions (deg P ≥ deg Q): Divide first. The quotient is a polynomial (easy to integrate). The remainder has lower degree.

Special forms frequently tested:
- ∫dx/(x²-a²) = (1/2a)ln|(x-a)/(x+a)| + C.
- ∫dx/(a²-x²) = (1/2a)ln|(a+x)/(a-x)| + C.
- ∫dx/(x²+a²) = (1/a)arctan(x/a) + C.
- ∫dx/√(x²±a²) = ln|x + √(x²±a²)| + C.
- ∫dx/√(a²-x²) = arcsin(x/a) + C.
- ∫dx/(x√(x²±a²)) = -(1/a)ln|(a+√(x²±a²))/x| + C.

Tricks for specific rational integrals: For ∫dx/((x²+1)(x²+4)), use the identity 1/((x²+1)(x²+4)) = (1/3)[1/(x²+1) - 1/(x²+4)] after partial fractions. For ∫(x²+1)/(x⁴+1) dx, divide numerator and denominator by x² to get ∫(1+1/x²)/(x²+1/x²) dx, then substitute t = x - 1/x, converting denominator to t²+2.

Beta and Gamma functions appear in JEE Advanced occasionally:
- Beta function: B(m,n) = ∫₀¹ x^(m-1)(1-x)^(n-1) dx = Γ(m)Γ(n)/Γ(m+n).
- Gamma function: Γ(n) = ∫₀^∞ x^(n-1)e^(-x) dx. Key results: Γ(n) = (n-1)! for positive integer n; Γ(1/2) = √π; Γ(n+1) = n·Γ(n).
- Symmetry: B(m,n) = B(n,m). Use substitution x = sin²θ to convert trig integrals to Beta form.

5. Definite Integrals: Properties, FTC and Applications

The Fundamental Theorem of Calculus connects differentiation and integration: if F is continuous on [a,b] and F' = f on (a,b), then ∫ₐᵇ f(x) dx = F(b) - F(a). JEE Advanced tests deep understanding through properties rather than mechanical evaluation.

Key properties (assume f is integrable on the interval):
- ∫ₐᵇ f(x) dx = -∫ᵇₐ f(x) dx.
- ∫ₐᵃ f(x) dx = 0.
- ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b-x) dx. This is the most frequently used symmetry property. It swaps f(x) with f(a+b-x), often revealing simplifications.
- ∫₀ᵃ f(x) dx = ∫₀ᵃ f(a-x) dx (special case above).
- If f is even (f(-x) = f(x)): ∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx. If f is odd: ∫₋ₐᵃ f(x) dx = 0.
- ∫₀^(2a) f(x) dx: If f(2a-x) = f(x), the integral equals 2∫₀ᵃ f(x) dx. If f(2a-x) = -f(x), the integral is zero. Combines even/odd logic with reflection about x = a.
- Splitting: ∫ₐᵇ f(x) dx = ∫ₐᶜ f(x) dx + ∫ᶜᵇ f(x) dx for any c in [a,b].

Periodicity property: If f has period T, then ∫ₐᵃ⁺ᵀ f(x) dx is independent of a, and ∫ₐᵇ f(x) dx = ∫ₐ₊ₙTᵇ₊ₙT f(x) dx for any integer n. For integer periods of sin/cos, this often reduces complicated limits.

Piecewise integrands: Break the interval at points of discontinuity or definition change. Be careful with absolute values: ∫|f(x)| dx requires finding where f changes sign and splitting accordingly.

Nondifferentiable integrands: If f has jump discontinuities, the FTC still applies on each continuous piece. At a jump point c, ∫ₐᵇ f dx = ∫ₐᶜ f dx + ∫ᶜᵇ f dx using one-sided limits.

Fresnel-type integrals: ∫₀^∞ sin(x²) dx = ∫₀^∞ cos(x²) dx = √(π/8). These are evaluation-type results often asked as standalone MCQs.

Common pitfall: Using substitution blindly without checking continuity of the antiderivative across the interval. For example, ∫₋₁¹ 1/x² dx diverges — you cannot apply FTC directly because 1/x² has a non-integrable singularity at x = 0.

6. Area Under Curves: Methods, Standard Regions and Case Analysis

Area calculations in JEE Advanced go beyond simple ∫ₐᵇ f(x) dx. The exam tests your ability to set up correct bounds, handle multiple regions, and work with implicit curves.

Basic principle: The area bounded by y = f(x), x = a, x = b and the x-axis is A = |∫ₐᵇ f(x) dx|. Always take absolute value — signed area can be negative if the curve dips below the axis.

Area between two curves: If f(x) ≥ g(x) on [a,b], then A = ∫ₐᵇ [f(x) - g(x)] dx. Find intersection points by solving f(x) = g(x); these give the limits of integration. If curves cross within [a,b], split the integral at crossing points and take absolute values separately.

Standard regions frequently appearing:
- Parabola y² = 4ax and line x = a: Area = (4/3)a².
- Circle x²+y²=a² in first quadrant: A = πa²/4.
- Ellipse x²/a² + y²/b² = 1: Total area = πab; first-quadrant area = πab/4.
- Cardioid r = a(1+cos θ): Area = (3/2)πa².
- Lemniscate r² = a²cos(2θ): Area = a².
- Astroid x^(2/3)+y^(2/3)=a^(2/3): Area = (3/16)πa².
- Cycloid x = a(θ-sin θ), y = a(1-cos θ) for one arch (θ: 0 to 2π): Area = 3πa².

Parametric curves: If x = f(t), y = g(t), then A = ∫ y dx = ∫ g(t)·f'(t) dt. Change limits to t-values corresponding to x-limits.

Polar curves: A = (1/2)∫ₐᵇ r² dθ. For closed curves, use symmetry and find appropriate angular bounds.

Absolute value in area problems: To find area between y = |x²-1| and y = 1, first locate where x²-1 = ±1, giving x = 0, ±√2. Split the integral at these points since the expression inside the modulus changes behavior.

Locus-based areas: Sometimes the region is defined by a locus equation (e.g., region satisfying |x|+|y| ≤ 1). Sketch the region — it may be a polygon rather than a smooth curve. For |x|+|y|≤1, the region is a square with vertices at (1,0),(0,1),(-1,0),(0,-1); area = 2.

7. Higher-Order Techniques: Reduction, Symmetry and Advanced Substitutions

JEE Advanced regularly includes questions requiring sophisticated integration techniques beyond routine substitution and parts.

Tabular integration (advanced parts): For ∫xⁿ·eˣ dx or ∫xⁿ·sin x dx, create two columns. Left column: differentiate xⁿ repeatedly until zero. Right column: integrate eˣ (or sin x) repeatedly. Draw diagonal arrows from each left entry to the next right entry, alternating signs (+,-,+,...). Sum the products.

Sophie Germain-type trick: ∫f(x)dx where f(x)+f(a+b-x) simplifies. For example, ∫₀^π x·f(sin x) dx = (π/2)∫₀^π f(sin x) dx. Proof uses the substitution x → π-x and averages the two forms.

Double integral conversion: Some difficult single integrals become tractable when expressed as iterated double integrals. Example: ∫₀^∞ (sin x)/x dx = π/2, derived by writing 1/x = ∫₀^∞ e^(-xy) dy and swapping order of integration.

Differentiation under the integral sign (Feynman's trick): If I(α) = ∫f(x,α) dx, then dI/dα = ∫∂f/∂α dx. Choose parameter α so that the differentiated integral is easier, solve the resulting ODE, and recover I(α) using initial conditions.

Example: Evaluate I = ∫₀^∞ e^(-x²) dx by considering I(a) = ∫₀^∞ e^(-ax²) dx, differentiating with respect to a, or more elegantly by squaring: I² = ∫∫ e^(-(x²+y²)) dx dy over first quadrant, converting to polar coordinates to get I² = π/4, hence I = √π/2.

Contour integration (occasional JEE Advanced): For integrals like ∫₀^∞ x^(a-1)/(1+x) dx = π/sin(aπ), 0<a<1, residues provide elegant proof. Knowledge of basic residue theorem helps but is supplementary.

Frullani integrals: ∫₀^∞ [f(ax)-f(bx)]/x dx = [f(0)-f(∞)]ln(b/a), valid when f is continuous and limits exist. Useful for logarithmic-integral combinations.

Landau-type integrals: ∫₀^∞ sin(x)/x dx, ∫₀^∞ sin²x/x² dx = π/2, ∫₀^∞ sin⁴x/x² dx = π/4. These are standard results worth memorizing.

8. Exam Weightage, Common Mistakes and Revision Checklist

Weightage analysis for JEE Advanced Mathematics:
- Integral Calculus consistently carries 2-4 questions per paper, often including 1 numerical-value type. Combined with Differential Calculus, integration-related topics form roughly 10-15% of the Mathematics section.
- High-weightage sub-topics in order: Definite integral properties and evaluation (most frequent), Area under curves (steady), Integration by parts chains (moderate-high), Substitution tricks (moderate), Reduction formulas and special integrals (moderate).
- Numerical-value questions on integrals typically involve evaluating a definite integral that simplifies to an integer or simple fraction through clever property use rather than brute-force computation.

Most common mistakes:
- Forgetting the constant of integration C in indefinite integrals (loses marks in numerical-answer questions where format matters).
- Wrong sign in substitution: ∫f(g(x))g'(x)dx = F(g(x))+C but if du = -g'(x)dx instead, sign flips.
- Applying FTC across discontinuities (especially with 1/x, sec x, tan x over intervals containing asymptotes).
- Incorrect partial fraction decomposition: forgetting that irreducible quadratics need linear numerators (Ax+B, not just A).
- Mixing up ∫sec x dx formulas: some remember ln|sec x+tan x|, others mistakenly write ln|sec x-tan x| (which equals ln|cos x|, wrong sign).
- Confusion between sin⁻¹ and (sin)⁻¹ notation: sin⁻¹x means arcsin x, not 1/sin x.
- Sign error in Wallis formula: for even powers, multiply by π/2; for odd powers, no π/2 factor.
- Absolute value omission when computing area: area is always non-negative, so ∫ₐᵇ f(x)dx must be taken in absolute value if f changes sign.

Revision checklist — ensure you can do each item without reference:
□ Integrate all basic forms from memory (trig, exponential, logarithmic, inverse trig)
□ Apply substitution in at least 6 distinct pattern types
□ Execute 3+ consecutive integration-by-parts steps using tabular method
□ Decompose rational functions with all four partial-fraction types
□ Evaluate definite integrals using at least 4 symmetry properties
□ Set up and compute areas for parabola-line, circle-ellipse, and parametric regions
□ Recognize and apply reduction formulas for sinⁿx, cosⁿx, secⁿx
□ Identify when Feynman's trick or Beta/Gamma functions apply
□ Handle improper integrals and identify convergence/divergence

Important facts

  • ∫e^x[f(x)+f'(x)]dx = e^x·f(x)+C and ∫e^x[f(x)-f'(x)]dx = e^x·f(x)+C — the e^x sum/difference shortcut.
  • LIATE rule orders priority for choosing u in integration by parts: Logarithmic > Inverse trig > Algebraic > Trigonometric > Exponential.
  • t = tan(x/2) substitution converts any rational function of sin x and cos x into a rational function of t.
  • Wallis formula: ∫₀^(π/2)sinⁿx dx = ∫₀^(π/2)cosⁿx dx; even n=2m gives (2m-1)!!/(2m)!!·π/2; odd n=2m+1 gives (2m)!!/(2m+1)!!.
  • Key definite integral properties: ∫ₐᵇf(x)dx = ∫ₐᵇf(a+b-x)dx; for even f, ∫₋ₐᵃf(x)dx=2∫₀ᵃf(x)dx; for odd f over [-a,a], integral is 0.
  • Gamma-Beta connection: B(m,n)=Γ(m)Γ(n)/Γ(m+n), Γ(n)=(n-1)! for integers, Γ(1/2)=√π.
  • Gaussian integral: ∫₀^∞e^(-x²)dx = √π/2. Fresnel integrals: ∫₀^∞sin(x²)dx = ∫₀^∞cos(x²)dx = √(π/8).
  • Area under y²=4ax between x=0 and x=a is (4/3)a². Area of ellipse x²/a²+y²/b²=1 is πab.
  • Standard improper integral: ∫₀^∞sin x/x dx = π/2 (Dirichlet integral). ∫₀^∞sin²x/x² dx = π/2.
  • Common partial fraction pattern: 1/((x²+1)(x²+4)) = (1/3)[1/(x²+1)-1/(x²+4)] after decomposition.

Common mistakes

  • Forgetting constant C in indefinite integrals — loses marks in numerical-answer formats expecting exact form.
  • Applying FTC ∫ₐᵇf(x)dx=F(b)-F(a) when f has a discontinuity in [a,b] (e.g., 1/x² at x=0) — the integral diverges and FTC is invalid.
  • Wrong sign when integrating sec x: ln|sec x+tan x| is correct; ln|sec x-tan x| is incorrect (that equals ln|cos x| with wrong sign).
  • In partial fractions with irreducible quadratic denominator, using constant numerator A instead of linear numerator Ax+B.
  • Confusing arcsin x with 1/sin x: sin⁻¹x denotes the inverse function (arcsin), not the reciprocal (csc x).
  • Missing the absolute value in ln|x|: ∫(1/x)dx = ln|x|+C, not ln x + C. The domain of 1/x includes negative reals.
  • Using substitution u=g(x) without checking if g is monotonic on the interval for definite integrals — can produce wrong bounds.
  • Incorrect sign in Wallis formula: the π/2 factor appears only for even powers of sin/cos, not odd.
  • Sign errors in repeated integration by parts: each diagonal in tabular method alternates sign; miscounting leads to wrong final answer.
  • Forgetting to split ∫ₐᵇ|f(x)|dx at points where f(x) changes sign — area requires absolute value of each signed region.
  • Confusing ∫secⁿx reduction sign: the recursive term is +(n-2)/(n-1)·I_(n-2), not minus.
  • Not performing polynomial division before partial fractions when deg(num) ≥ deg(denom).
