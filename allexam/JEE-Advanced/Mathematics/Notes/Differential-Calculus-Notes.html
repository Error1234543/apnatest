1. Fundamentals: Limit, Continuity and Differentiability

['A function f(x) is said to have a limit L as x approaches a if, for every ε > 0, there exists a δ > 0 such that |f(x) − L| < ε whenever 0 < |x − a| < δ. This is written as lim_{x→a} f(x) = L.', 'Left-hand limit (LHL) = lim_{x→a^-} f(x) = lim_{h→0} f(a−h). Right-hand limit (RHL) = lim_{x→a^+} f(x) = lim_{h→0} f(a+h). The limit exists iff LHL = RHL and both are finite.', 'Standard limits (must be memorised):', '• lim_{x→0} sin x / x = 1', '• lim_{x→0} (1 − cos x) / x² = 1/2', '• lim_{x→0} tan x / x = 1', '• lim_{x→0} (e^x − 1) / x = 1', '• lim_{x→0} ln(1 + x) / x = 1', '• lim_{x→∞} (1 + 1/x)^x = e', '• lim_{x→0} (a^x − 1) / x = ln a', 'Continuity at x = a: f is continuous at a if f(a) exists, lim_{x→a} f(x) exists, and lim_{x→a} f(x) = f(a). A function can be continuous but not differentiable (e.g., |x| at 0). Differentiability implies continuity, but the converse is false.', 'Types of discontinuity: removable (limit exists but ≠ f(a) or f(a) undefined), jump (LHL ≠ RHL), infinite (function blows up), oscillatory (limit does not exist due to oscillation).']

2. Definition and Geometric Meaning of Derivative

["The derivative of f at x = a is defined as f'(a) = lim_{h→0} [f(a+h) − f(a)] / h, provided the limit exists. This is also denoted dy/dx or D_x y.", "Geometrically, f'(a) is the slope of the tangent to the curve y = f(x) at the point (a, f(a)). The tangent line equation: y − f(a) = f'(a)(x − a). The normal line (perpendicular to tangent) has slope −1/f'(a) (if f'(a) ≠ 0); equation: y − f(a) = −[1/f'(a)](x − a).", 'Physical interpretation: If s(t) denotes position, then v(t) = ds/dt is velocity, a(t) = dv/dt = d²s/dt² is acceleration. For any rate of change quantity, derivative gives instantaneous rate.', 'Differentiability conditions at a point x = c:', '• f must be continuous at c.', '• Left-hand derivative (LHD) = lim_{h→0} [f(c−h) − f(c)]/(−h) must equal right-hand derivative (RHD) = lim_{h→0} [f(c+h) − f(c)]/h.', 'If either LHD or RHD does not exist or they are unequal, f is not differentiable at c.']

3. Rules of Differentiation

['Power rule: d/dx [x^n] = n x^{n−1} for any real n (including fractional, negative).', "Sum/Difference: d/dx [f ± g] = f' ± g'.", "Constant multiple: d/dx [c·f(x)] = c·f'(x).", "Product rule: d/dx [u·v] = u'v + uv'. For three functions: d/dx [uvw] = u'vw + uv'w + uvw'.", "Quotient rule: d/dx [u/v] = (u'v − uv') / v², provided v ≠ 0.", "Chain rule: If y = f(g(x)), then dy/dx = f'(g(x)) · g'(x). More generally, for nested functions, differentiate from outermost to innermost and multiply by derivatives of all intermediate functions.", 'Implicit differentiation: When y is defined implicitly by an equation involving x and y, differentiate both sides with respect to x, treating y as a function of x (apply chain rule to terms with y). Solve for dy/dx.', "Parametric differentiation: If x = φ(t), y = ψ(t), then dy/dx = (dy/dt) / (dx/dt) = ψ'(t)/φ'(t), provided dx/dt ≠ 0.", "Logarithmic differentiation: Useful when both base and exponent are variables (y = [f(x)]^{g(x)}). Take natural log: ln y = g(x) ln f(x), then differentiate implicitly to get y'/y = g'(x) ln f(x) + g(x) f'(x)/f(x), so y' = y [ ... ]."]

4. Derivatives of Standard Functions

['Algebraic: d/dx(x^n)=nx^{n-1}; d/dx(√x)=1/(2√x); d/dx(1/x)=−1/x².', 'Trigonometric: d/dx(sin x)=cos x; d/dx(cos x)=−sin x; d/dx(tan x)=sec² x; d/dx(cot x)=−csc² x; d/dx(sec x)=sec x tan x; d/dx(csc x)=−csc x cot x.', 'Inverse trigonometric: d/dx(arcsin x)=1/√(1−x²); d/dx(arccos x)=−1/√(1−x²); d/dx(arctan x)=1/(1+x²); d/dx(arccot x)=−1/(1+x²); d/dx(arcsec x)=1/(|x|√(x²−1)); d/dx(arccsc x)=−1/(|x|√(x²−1)). Note the absolute value in arcsec/arccsc derivatives.', 'Exponential & logarithmic: d/dx(e^x)=e^x; d/dx(a^x)=a^x ln a; d/dx(ln x)=1/x; d/dx(log_a x)=1/(x ln a).', 'Hyperbolic functions: d/dx(sinh x)=cosh x; d/dx(cosh x)=sinh x; d/dx(tanh x)=sech² x; d/dx(coth x)=−csch² x; d/dx(sech x)=−sech x tanh x; d/dx(csch x)=−csch x coth x.', 'Inverse hyperbolic: d/dx(sinh^{-1} x)=1/√(x²+1); d/dx(cosh^{-1} x)=1/√(x²−1) for x>1; d/dx(tanh^{-1} x)=1/(1−x²) for |x|<1.', 'Leibniz’s theorem for nth derivative of product: (uv)^{(n)} = Σ_{k=0}^{n} C(n,k) u^{(n−k)} v^{(k)}, where u^{(k)} denotes kth derivative.']

5. Monotonicity and Critical Points

['A function f is increasing on an interval I if for any x₁ < x₂ in I, f(x₁) ≤ f(x₂) (non‑strict) or f(x₁) < f(x₂) (strict). It is decreasing if the inequalities reverse.', "First derivative test: If f'(x) > 0 on an interval, f is strictly increasing there; if f'(x) < 0, f is strictly decreasing. Points where f'(x) = 0 or f'(x) does not exist are called critical points.", 'At a critical point c:', "• If f'(x) changes sign from + to − at c, then f has a local maximum at c.", "• If f'(x) changes sign from − to + at c, then f has a local minimum at c.", "• If f'(x) does not change sign (e.g., remains positive on both sides), c is a point of inflection (stationary point of inflection), not an extremum.", "Second derivative test (when f''(c) exists): If f'(c)=0 and f''(c)<0 → local max; if f'(c)=0 and f''(c)>0 → local min; if f''(c)=0 the test is inconclusive – revert to first derivative test or higher‑order derivative test.", "Higher‑order derivative test: Suppose f'(c)=f''(c)=…=f^{(n−1)}(c)=0 and f^{(n)}(c)≠0. If n is even, f has a local extremum at c (max if f^{(n)}(c)<0, min if >0). If n is odd, c is a point of inflection."]

6. Maxima and Minima (Global and Local)

['Local (relative) extremum: f(c) is a local maximum if f(c) ≥ f(x) for all x in some open interval around c; similarly for minimum.', 'Global (absolute) extremum on a closed interval [a,b]: The largest (smallest) value attained by f on that interval. By the Extreme Value Theorem, a continuous function on a closed bounded interval always attains both a global maximum and a global minimum.', 'Procedure to find global extrema on [a,b]:', "1. Find all critical points inside (a,b) where f'(x)=0 or f'(x) does not exist.", '2. Evaluate f at each critical point and at the endpoints a and b.', '3. The greatest among these values is the global maximum; the least is the global minimum.', 'For open intervals or unbounded domains, check behaviour as x → boundaries and as |x| → ∞; global extrema may not exist.', 'JEE Advanced frequently combines these ideas with piecewise‑defined functions, absolute‑value functions, and functions involving parameters. Always verify continuity and differentiability at points where the formula changes.']

7. Mean Value Theorems

["Rolle’s Theorem: If f is continuous on [a,b], differentiable on (a,b), and f(a)=f(b), then there exists at least one c ∈ (a,b) such that f'(c)=0. Geometrically, there is a horizontal tangent somewhere between a and b.", "Lagrange’s Mean Value Theorem (MVT): If f is continuous on [a,b] and differentiable on (a,b), then ∃ c ∈ (a,b) such that f'(c) = [f(b)−f(a)]/(b−a). This generalises Rolle’s theorem (shift the function so that endpoints match).", "Cauchy’s MVT (generalised): For f,g continuous on [a,b] and differentiable on (a,b), with g'(x)≠0 on (a,b), ∃ c ∈ (a,b) such that [f(b)−f(a)]/[g(b)−g(a)] = f'(c)/g'(c).", 'Important corollaries and applications:', "• If f'(x)=0 for all x in an interval, then f is constant on that interval.", "• If f'(x)≥0 on [a,b], then f is non‑decreasing; strict positivity gives strict increase except possibly at isolated points.", '• MVT is used to prove inequalities, estimate errors, and establish properties of functions.', 'Note: The hypotheses cannot be weakened arbitrarily – failure of continuity at an endpoint or differentiability inside the interval can make the conclusion false.']

8. Indeterminate Forms and L’Hospital’s Rule

['The five basic indeterminate forms are: 0/0, ∞/∞, 0·∞, ∞−∞, 0⁰, 1^∞, ∞⁰. The first two are handled directly by L’Hospital; the others require algebraic manipulation to convert them into 0/0 or ∞/∞.', "L’Hospital’s Rule (for 0/0 or ∞/∞): If lim_{x→c} f(x) = lim_{x→c} g(x) = 0 or ±∞, and lim_{x→c} f'(x)/g'(x) exists (or is ±∞), then lim_{x→c} f(x)/g(x) = lim_{x→c} f'(x)/g'(x). The rule can be applied repeatedly as long as the new limit remains indeterminate.", "Conditions: f and g must be differentiable near c (except possibly at c), and g'(x)≠0 near c. Also, the limit of the quotient of derivatives must exist (finite or infinite); if it does not exist, L’Hospital gives no information.", 'Converting other forms:', '• 0·∞ : rewrite as f·g = f/(1/g) or g/(1/f) to obtain 0/0 or ∞/∞.', '• ∞−∞ : combine into a single fraction or use conjugate multiplication.', '• 0⁰, 1^∞, ∞⁰ : take natural logarithm, obtain a product form, then exponentiate the result.', 'Examples of tricky applications involve trigonometric functions, exponentials, and logarithms mixed together. Always verify that the original limit is indeed indeterminate before applying the rule.']

9. Tangents, Normals and Approximations

["Equation of tangent at (x₀,y₀) on y=f(x): y − y₀ = f'(x₀)(x − x₀).", "Equation of normal: y − y₀ = −[1/f'(x₀)](x − x₀), provided f'(x₀)≠0. If f'(x₀)=0, the normal is vertical (x = x₀). If f'(x₀) is undefined (vertical tangent), the normal is horizontal (y = y₀).", "Lengths: Length of tangent segment from point of contact to the x‑axis = |y₀√(1+[f'(x₀)]²)/f'(x₀)|. Length of normal segment = |y₀√(1+[f'(x₀)]²)|. Subtangent = |y₀/f'(x₀)|. Subnormal = |y₀ f'(x₀)|.", "Linear approximation (differentials): For small Δx, f(x₀+Δx) ≈ f(x₀) + f'(x₀)Δx. The differential dy = f'(x)dx approximates the change in y.", "Error estimation: If x is measured with error dx, then error in y ≈ dy = f'(x)dx. Relative error in y ≈ (f'(x)/f(x)) dx.", 'JEE Advanced often asks for the angle between two curves (angle between their tangents at intersection) or conditions for orthogonality of families of curves.']

12. Common Mistakes and Confusion Points

['• Assuming differentiability implies continuity is correct (true), but forgetting that continuity does NOT imply differentiability. Counterexample: f(x)=|x| at x=0 is continuous but not differentiable.', '• Applying L’Hospital’s rule when the limit is not indeterminate. Always check the form first.', '• Forgetting the absolute value in derivatives of arcsec and arccsc. The correct forms involve |x| in the denominator.', "• Treating a point where f'(c)=0 as automatically an extremum. It could be a saddle/inflection point (e.g., f(x)=x³ at x=0).", "• Misusing the second derivative test when f''(c)=0. The test is inconclusive; revert to the first derivative test.", '• Ignoring the domain restrictions of the original function when simplifying expressions before differentiating (e.g., cancelling factors that are zero at the point of interest).', '• Forgetting that Rolle’s theorem requires f(a)=f(b); if the endpoint values differ, the theorem does not apply directly.', '• In parametric differentiation, forgetting that dy/dx = (dy/dt)/(dx/dt) only when dx/dt ≠ 0. Also, higher‑order parametric derivatives require careful application of quotient rule.', "• Confusing concavity with convexity: f''(x)>0 means concave up (convex), f''(x)<0 means concave down (concave). Terminology varies across textbooks; understand both.", '• Overlooking that a function can be differentiable everywhere except at isolated points (e.g., piecewise functions); always check differentiability at the junction points separately.']

Important facts

  • Differentiability ⇒ continuity, but continuity ⇏ differentiability.
  • A function can be continuous at a point yet not differentiable there (e.g., corner, cusp, vertical tangent).
  • Critical points are where f'(x)=0 or f'(x) does not exist; not all critical points are extrema.
  • Rolle’s theorem is a special case of Lagrange’s MVT with f(a)=f(b).
  • L’Hospital’s rule applies only to 0/0 or ∞/∞ forms; other indeterminate forms must be converted.
  • For monotonicity, sign of f' determines increasing/decreasing intervals; f'=0 alone is insufficient to conclude an extremum.
  • The second derivative test fails when f''(c)=0; use first derivative test or higher‑order derivatives.
  • Global extrema on a closed interval occur either at critical points inside the interval or at the endpoints.
  • Tangent slope = derivative; normal slope = negative reciprocal (provided tangent slope is finite and non‑zero).
  • Leibniz’s theorem for nth derivative of a product is frequently tested in JEE Advanced.

Formulas and relationships

Quotient rule: (u/v)' = (u'v − uv')/v²

Implicit: differentiate both sides w.r.t. x, collect dy/dx terms
Parametric: dy/dx = (dy/dt)/(dx/dt)

Common mistakes

  • Assuming that f'(c)=0 guarantees a local maximum or minimum; it could be a stationary point of inflection.
  • Applying L’Hospital’s rule to limits that are not in an indeterminate form.
  • Forgetting to check differentiability at points where the function definition changes (piecewise functions).
  • Mixing up the signs in derivatives of inverse trigonometric functions (e.g., arcsin vs arccos).
  • Ignoring domain restrictions when simplifying expressions before differentiation.
  • Using the second derivative test when f''(c)=0 without falling back to the first derivative test.
  • Treating continuity as sufficient for differentiability.
  • Incorrectly applying the chain rule to composite functions with more than two layers.
  • Overlooking that Rolle’s theorem requires the function to be differentiable on the open interval and continuous on the closed interval.
  • In parametric differentiation, forgetting to divide by dx/dt when computing dy/dx.
