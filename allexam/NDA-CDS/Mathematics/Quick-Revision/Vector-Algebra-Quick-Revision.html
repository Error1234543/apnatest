Vector Algebra — Quick Revision for NDA & CDS

NDA & CDSEnglishQuick Revision

Definitions

  • Scalar: A quantity having only magnitude (e.g., speed, mass, temperature). No direction involved.
  • Vector: A quantity having both magnitude and direction (e.g., displacement, velocity, force). Represented by an arrow or bold letter.
  • Zero vector (null vector): A vector with zero magnitude and arbitrary direction; denoted by 0⃗. Its initial and terminal points coincide.
  • Unit vector: A vector of magnitude 1 in the direction of a given vector a⃗. Denoted by â = a⃗/|a⃗|.
  • Position vector: The vector from the origin O to a point P(x, y, z), written as r⃗ = xi + yj + zk.
  • Free vector: A vector whose effect is independent of its point of application; only magnitude and direction matter.
  • Localised vector: A vector fixed at a particular initial point.
  • Like and unlike vectors: Like vectors have same direction; unlike have opposite directions.
  • Collinear vectors: Two or more vectors parallel to the same line; a⃗ = λb⃗ for some scalar λ.
  • Coplanar vectors: Three or more vectors lying in the same plane. Three vectors a⃗, b⃗, c⃗ are coplanar iff a⃗ = lb⃗ + mc⃗ for scalars l, m.
  • Direction cosines: The cosines of angles α, β, γ made by a vector with positive x, y, z axes. Denoted by l, m, n where l²+m²+n²=1.
  • Direction ratios: Any three proportional numbers (a, b, c) to direction cosines; i.e., l = ka, m = kb, n = kc.

Key concepts

  • A vector is represented by a directed line segment AB⃗, where A is initial point and B is terminal point. Magnitude |AB⃗| is its length. In component form, if A = (x₁,y₁,z₁) and B = (x₂,y₂,z_z), then AB⃗ = (x₂-x₁)i + (y₂-y₁)j + (z₂-z₁)k. Often written as ai + bj + ck. Unit vectors along coordinate axes: î, ĵ, k̂ with î·î=ĵ·ĵ=k̂·k̂=1 and all cross dot products zero.
  • Triangle Law: If OA⃗ = a⃗ and AB⃗ = b⃗, then resultant OB⃗ = a⃗ + b⃗. Parallelogram Law: If two vectors are adjacent sides of a parallelogram, diagonal from common point gives sum a⃗ + b⃗. Component-wise addition: (a₁i+a₂j+a₃k)+(b₁i+b₂j+b₃k) = (a₁+b₁)i + (a₂+b₂)j + (a₃+b₃)k. Subtraction: a⃗ - b⃗ = a⃗ + (-b⃗), where -b⃗ has same magnitude but opposite direction. Key property: Vector addition is commutative (a⃗+b⃗ = b⃗+a⃗) and associative ((a⃗+b⃗)+c⃗ = a⃗+(b⃗+c⃗)).
  • Scalar multiplication: If λ is a scalar, then λa⃗ has magnitude |λ||a⃗| and direction along a⃗ if λ>0, opposite if λ<0. Properties: λ(μa⃗)=(λμ)a⃗, (λ+μ)a⃗=λa⃗+μa⃗, λ(a⃗+b⃗)=λa⃗+λb⃗. Section formula: Point P dividing AB⃗ internally in ratio m:n has position vector p⃗ = (na⃗ + mb⃗)/(m+n). For external division: p⃗ = (na⃗ - mb⃗)/(m-n). Midpoint: p⃗ = (a⃗+b⃗)/2.
  • Definition: a⃗ · b⃗ = |a⃗||b⃗|cosθ, where θ is angle between a⃗ and b⃗ (0≤θ≤π). Component form: a⃗·b⃗ = a₁b₁ + a₂b₂ + a₃b₃. Properties: Commutative; a⃗·a⃗ = |a⃗|²; î·î=ĵ·ĵ=k̂·k̂=1, cross terms =0. Applications: Finding angle: cosθ = (a⃗·b⃗)/(|a⃗||b⃗|). Perpendicularity condition: a⃗·b⃗ = 0 iff a⃗⊥b⃗ (for non-zero vectors). Work done: W = F⃗ · d⃗. Projection of a⃗ on b⃗: (a⃗·b⃗/|b⃗|) b̂ = [(a⃗·b⃗)/|b⃗|²] b⃗. Scalar projection: |a⃗|cosθ = (a⃗·b⃗)/|b⃗|.
  • Definition: a⃗ × b⃗ = |a⃗||b⃗|sinθ n̂, where n̂ is unit vector perpendicular to plane containing a⃗ and b⃗, following right-hand rule. Magnitude equals area of parallelogram with adjacent sides a⃗, b⃗. Component form: a⃗×b⃗ = (a₂b₃-a₃b₂)i + (a₃b₁-a₁b₃)j + (a₁b₂-a₂b₁)k. Can be remembered via determinant: |î ĵ k̂; a₁ a₂ a₃; b₁ b₂ b₃|. Properties: Anti-commutative (a⃗×b⃗ = -(b⃗×a⃗)); not associative. a⃗×b⃗ = 0 iff a⃗ and b⃗ are parallel (or one is zero). |a⃗×b⃗| = area of parallelogram; area of triangle with sides a⃗,b⃗ = ½|a⃗×b⃗|.
  • Scalar Triple Product: a⃗·(b⃗×c⃗) = [a⃗ b⃗ c⃗] = volume of parallelepiped formed by a⃗,b⃗,c⃗. Also equal to b⃗·(c⃗×a⃗) = c⃗·(a⃗×b⃗) = cyclic permutations. Value unchanged under cyclic permutation; changes sign on interchange of any two vectors. Geometrically, if value = 0, vectors are coplanar. Vector Triple Product: a⃗×(b⃗×c⃗) = (a⃗·c⃗)b⃗ - (a⃗·b⃗)c⃗ (BAC-CAB rule — 'back minus cab'). Note order matters: (a⃗×b⃗)×c⃗ ≠ a⃗×(b⃗×c⃗) generally. (a⃗×b⃗)×c⃗ = (a⃗·c⃗)b⃗ - (b⃗·c⃗)a⃗.
  • If vector r⃗ = xi + yj + zk makes angles α, β, γ with positive x, y, z axes respectively: l = cosα = x/|r⃗|, m = cosβ = y/|r⃗|, n = cosγ = z/|r⃗|. Fundamental relation: l² + m² + n² = 1. Direction ratios (DRs) are any three numbers a, b, c such that l=a/√(a²+b²+c²), m=b/√(a²+b²+c²), n=c/√(a²+b²+c²). For line joining P(x₁,y₁,z₁) and Q(x₂,y₂,z₂), DRs are (x₂-x₁), (y₂-y₁), (z₂-z₁). Angle between two lines with DRs (a₁,b₁,c₁) and (a₂,b₂,c₂): cosθ = (a₁a₂+b₁b₂+c₁c₂)/√(a₁²+b₁²+c₁²)√(a₂²+b₂²+c₂²).
  • Projection of a⃗ on b⃗ (scalar): comp_b(a⃗) = (a⃗·b⃗)/|b⃗| = |a⃗|cosθ. Vector projection: proj_b(a⃗) = [(a⃗·b⃗)/|b⃗|²] b⃗. Resolving a⃗ along and perpendicular to b⃗: a⃗ = [(a⃗·b̂)b̂] + [a⃗ - (a⃗·b̂)b̂], first part parallel, second part perpendicular. If three mutually perpendicular unit vectors î,ĵ,k̂, then a⃗ = (a⃗·î)î + (a⃗·ĵ)ĵ + (a⃗·k̂)k̂. This decomposition is unique and fundamental for component methods.
  • Area of triangle with vertices A,B,C: ½|AB⃗ × AC⃗|. Volume of tetrahedron with vertices at origin and position vectors a⃗,b⃗,c⃗: ⅙|[a⃗ b⃗ c⃗]|. Condition for four points A,B,C,D to be coplanar: (b⃗-a⃗)·[(c⃗-a⃗)×(d⃗-a⃗)] = 0. Shortest distance between two skew lines can be found using cross and dot products (covered in 3D geometry section). Normal to a plane containing vectors a⃗ and b⃗ is n⃗ = a⃗×b⃗.

Important facts

  • i⃗×j⃗=k⃗, j⃗×k⃗=i⃗, k⃗×i⃗=j⃗. Reverse order gives negative.
  • i⃗×i⃗=j⃗×j⃗=k⃗×k⃗=0⃗.
  • |a⃗×b⃗|² + (a⃗·b⃗)² = |a⃗|²|b⃗|² (Lagrange's identity).
  • Three non-zero vectors a⃗,b⃗,c⃗ are coplanar ⇔ [a⃗ b⃗ c⃗] = 0.
  • For unit vectors â, b̂: |â+b̂| = 2cos(θ/2); |â-b̂| = 2sin(θ/2).
  • The angle between diagonals of a parallelogram with adjacent sides a⃗,b⃗: cosφ = |(a⃗+b⃗)·(a⃗-b⃗)|/(|a⃗+b⃗||a⃗-b⃗|) = |a⃗|²-|b⃗|² / (...).
  • If a⃗+b⃗+c⃗=0⃗, then a⃗×b⃗ = b⃗×c⃗ = c⃗×a⃗.
  • a⃗×(b⃗+c⃗) = a⃗×b⃗ + a⃗×c⃗ (distributive law holds for cross product).

Memory aids

  • Dot product mnemonic: 'a·b is small' (commutative, gives scalar — smaller than vector). Cross product: 'a×b is extra' (gives new perpendicular vector).
  • CAB-BAC rule for vector triple product: 'A cross (B cross C) = (A·C)B minus (A·B)C.' Say 'back minus cab' — the first and last letters of BAC spell the formula.
  • Right-hand screw rule for cross product: curl fingers from a⃗ toward b⃗ through smaller angle; thumb points along a⃗×b⃗.
  • For direction cosines: remember 'LMS' (l, m, n correspond to x, y, z). l²+m²+n²=1 like Pythagoras in 3D.
  • Determinant memory for a⃗×b⃗: write î ĵ k̂ on first row, components of a⃗ on second, b⃗ on third. Expand along first row — this avoids sign errors.

Exam tips

  • NDA/CDS frequently test: finding angle between vectors, verifying collinearity/coplanarity, computing projections, and area/volume applications. Practice these numericals thoroughly.
  • When asked to prove vectors are coplanar, compute [a⃗ b⃗ c⃗] and show it equals zero. Always write final value clearly.
  • For questions involving unit vectors, convert all vectors to unit vectors first using â = a⃗/|a⃗| before applying formulas.
  • In MCQs, eliminate options by checking dimensions: dot product answers are scalars (no i,j,k), cross product answers have i,j,k components.
  • Speed tip: use component method for dot/cross products rather than computing magnitudes and angles separately. Component arithmetic is faster and less error-prone.
  • Remember key special cases: if a⃗·b⃗ = |a⃗||b⃗| then θ=0 (same direction); if a⃗·b⃗ = -|a⃗||b⃗| then θ=π (opposite). If |a⃗×b⃗|=|a⃗||b⃗| then θ=90°.
  • For CDS, assertion-reason type questions may appear on vector properties. Read carefully whether the reason correctly explains the assertion.
  • Quick check: if a question gives position vectors of triangle vertices and asks for area, use ½|AB⃗ × AC⃗|. Set up vectors from one vertex to the other two.
  • Direction cosine problems: if a line makes equal angles with axes, then l=m=n and since l²+m²+n²=1, each equals 1/√3. This is a common NDA fact.

Common traps

  • Confusing dot and cross product: dot gives scalar, cross gives vector. Always check what the question asks for.
  • Assuming (a⃗×b⃗)×c⃗ = a⃗×(b⃗×c⃗). Cross product is NOT associative. These are generally different vectors.
  • Forgetting that a⃗×b⃗ = 0⃗ includes the case when either vector is a zero vector, not just parallelism.
  • Using wrong order in cross product: a⃗×b⃗ ≠ b⃗×a⃗; they are opposite. Answer choices often exploit this sign error.
  • Mixing up scalar projection (a scalar) with vector projection (a vector). Scalar projection = (a⃗·b⃗)/|b⃗|; vector projection = [(a⃗·b⃗)/|b⃗|²]b⃗.
  • In section formula, confusing internal (m+n in denominator) with external (m-n). External division often gives a wrong-sign answer choice.
  • For coplanarity: writing a⃗·(b⃗×c⃗)=0 but forgetting to check that vectors are non-zero.
  • Direction ratios are NOT unique — any multiple works. Only direction cosines are unique (up to sign convention).
  • Sign error in determinant expansion for cross product: middle term (ĵ) gets negative sign.
  • Taking θ as acute angle always. For dot product, θ∈[0,π]; cosθ can be negative giving obtuse angles.
