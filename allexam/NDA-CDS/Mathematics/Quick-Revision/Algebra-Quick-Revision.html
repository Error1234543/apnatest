Definitions

  • Quadratic Equation: An equation of the form ax² + bx + c = 0 where a ≠ 0, having two roots given by the quadratic formula x = [-b ± √(b²-4ac)] / 2a.
  • Polynomial: An expression of the form aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀ where n is a non-negative integer and coefficients are real numbers.
  • Remainder Theorem: If a polynomial P(x) is divided by (x - a), the remainder equals P(a).
  • Factor Theorem: (x - a) is a factor of P(x) if and only if P(a) = 0.
  • HCF (Highest Common Factor): The greatest algebraic expression that divides each of the given expressions exactly.
  • LCM (Least Common Multiple): The least algebraic expression that is exactly divisible by each of the given expressions.
  • Surds: Irrational numbers of the form √n where n is not a perfect square; expressions containing root signs whose value cannot be exactly found.
  • Logarithm: If aˣ = N, then x = log_a(N); the exponent to which base 'a' must be raised to obtain N.
  • Permutation: An arrangement of objects in a definite order; the number of permutations of n distinct things taken r at a time is nPr = n!/(n-r)!.
  • Combination: A selection of objects where order does not matter; nCr = n!/[r!(n-r)!].
  • Binomial Theorem: (a+b)ⁿ = Σ(nCr × aⁿ⁻ʳ × bʳ) for r = 0 to n, valid for any positive integer n.
  • Arithmetic Progression (AP): A sequence where the difference between consecutive terms is constant (common difference d); nth term = a + (n-1)d.
  • Geometric Progression (GP): A sequence where the ratio of consecutive terms is constant (common ratio r); nth term = a·rⁿ⁻¹.
  • Harmonic Progression (HP): A sequence whose reciprocals form an AP; nth term = 1/[a + (n-1)d].
  • Set: A well-defined collection of distinct objects; subsets, union (∪), intersection (∩), and complement (A') are fundamental operations.

Important facts

  • n! = n×(n-1)×...×2×1; 0! = 1 by definition.
  • For quadratic equation, if one root is α and other is β, equation is x²-(α+β)x+αβ=0.
  • In AP: aₘ + aₙ = aₚ + a_q if m+n = p+q.
  • In GP: aₘ × aₙ = aₚ × a_q if m+n = p+q.
  • Sum of first n natural numbers: n(n+1)/2.
  • Sum of squares: n(n+1)(2n+1)/6.
  • Sum of cubes: [n(n+1)/2]².
  • Number of subsets of a set with n elements = 2ⁿ; proper subsets = 2ⁿ - 1.
  • log_a(M) = log_b(M) / log_b(a) — change of base formula, extremely useful for computation without tables.
  • If aˣ = bʸ = cᶻ and b² = ac, then x, y, z are in AP (taking logarithms).
  • For binomial (1+x)ⁿ, sum of coefficients = 2ⁿ; alternate sum = 0 when n ≥ 1.
  • nCr = nC(n-r) — complementary property, simplifies calculation for large r.
  • In HP, AM × HM = GM² is NOT generally true; only for two numbers: (AM)(HM) = GM².
  • Condition for lines a₁x+b₁y+c₁=0 and a₂x+b₂y+c₂=0 to be concurrent with a third line can be checked by determinant method.

Memory aids

  • Quadratic formula: 'Negative b, plus or minus root, over two a' — mirrors the standard form coefficients directly.
  • Sum and product of roots: 'Minus b over a' and 'c over a' — think 'sum is negative, product is positive' when both roots positive.
  • Permutation vs Combination: 'Permutation = Position matters (PHONE)' ; 'Combination = Choice matters (CHOICE)'.
  • AP sum: 'n/2(first + last)' — average of first and last multiplied by count, like finding average height.
  • GP sum infinite: 'a/(1-r)' — remember this is only when r is between -1 and 1, otherwise series diverges.
  • De Morgan's: 'Break the bar, change the sign' — complement of union becomes intersection and vice versa.
  • AM-GM-HM chain: 'A Merry Goat Hurries' — always AM ≥ GM ≥ HM for positive quantities.
  • Log power rule: 'The exponent comes down as a multiplier' — visualize the power moving in front.
  • Factor theorem: 'Plug in to check, zero means it factors' — simple substitution test.
  • Binomial coefficients symmetry: Pascal's triangle is symmetric — nC0=nCn, nC1=nC(n-1).

Exam tips

  • NDA Maths Algebra section tests speed. Memorize standard results (sum/product of roots, nCr properties, AP/GP formulas) to save time during the exam.
  • For equal roots problems: set discriminant D = 0 — this is the fastest route to find unknown constants in quadratic equations.
  • In permutation-combination questions, first identify whether order matters. Keywords: 'arranged/ordered' → permutation; 'selected/grouped' → combination.
  • When solving log equations, always check domain: arguments of logarithms must be positive. Reject solutions that make log argument ≤ 0.
  • For HP questions, convert to AP by taking reciprocals first — this is the standard and quickest approach.
  • In binomial theorem, use symmetry nCr = nC(n-r) to reduce calculation workload for larger r values.
  • Set theory numericals: draw Venn diagrams for 2-3 set problems to avoid miscounting; label each region separately.
  • Remember: AM ≥ GM ≥ HM. Use this to quickly eliminate impossible answer options in inequality-based MCQs.
  • For simultaneous equations with parameters, use the condition of consistency: a₁/a₂ ≠ b₁/b₂ for unique solution.
  • Quick check for polynomials: if P(1) = 0, then (x-1) is a factor; if P(-1) = 0, then (x+1) is a factor. These are common shortcuts.
  • In NDA, algebra carries significant weight in the Mathematics paper. Practice at least 30-40 problems from each sub-topic for speed.
  • When asked for the number of terms in expansion of (a+b)ⁿ, the answer is always n+1 — this is a guaranteed-mark question type.

Common traps

  • Confusing nPr with nCr: permutations include ordering, combinations do not. Using nCr where nPr is required undercounts; using nPr overcounts.
  • Forgetting a ≠ 0 in quadratic equation: if coefficient of x² becomes zero, equation is linear, not quadratic, and quadratic formula does not apply.
  • Sign error in sum of roots: α + β = -b/a, not +b/a. This is the most frequent mistake.
  • Applying GP sum formula S∞ = a/(1-r) when |r| ≥ 1: the formula is invalid; series diverges.
  • Treating log(M+N) = log M + log N: logarithms do NOT distribute over addition; only over multiplication.
  • Forgetting that 0! = 1: leads to wrong permutation/combo values.
  • In HP problems: taking reciprocal incorrectly or forgetting that HP nth term = 1/[a+(n-1)d].
  • Confusing (a+b)² with a²+b²: missing the 2ab term — binomial expansion mistake.
  • In set theory: assuming A∪B = A+B numerically without subtracting intersection; double-counting elements.
  • Assuming log_a(M-N) = log_a M - log_a N: false; only quotient rule applies.
  • For circular permutation: using n! instead of (n-1)! — fixing one person removes rotational symmetry.
  • In Surds: assuming √(a+b) = √a + √b: false; radicals do not distribute over addition.
