Quick Revision: Matrices and Determinants — NDA & CDS

NDA & CDSEnglishQuick Revision

Definitions

  • Matrix: A rectangular array of numbers (real or complex) arranged in rows and columns. An m×n matrix has m rows and n columns.
  • Square Matrix: A matrix with equal number of rows and columns (n×n).
  • Determinant: A scalar value associated with a square matrix, denoted |A| or det(A), computed only for square matrices.
  • Row Matrix: A matrix with a single row (1×n). Example: [2 5 −3].
  • Column Matrix: A matrix with a single column (m×1). Example: [[1],[4],[−2]].
  • Null/Zero Matrix: All entries are zero, denoted O.
  • Row Vector: Another name for a row matrix; Column Vector: another name for a column matrix.
  • Transpose (Aᵀ): The matrix obtained by interchanging rows and columns of A. If A is m×n, then Aᵀ is n×m.
  • Symmetric Matrix: A square matrix where Aᵀ = A, i.e., aᵢⱼ = aⱼᵢ for all i,j.
  • Skew-Symmetric Matrix: A square matrix where Aᵀ = −A, i.e., aᵢⱼ = −aⱼᵢ. All diagonal elements must be zero.
  • Diagonal Matrix: A square matrix where all non-diagonal entries are zero.
  • Scalar Matrix: A diagonal matrix where all diagonal entries are equal (kI).
  • Identity Matrix (I): A scalar matrix with all diagonal entries equal to 1.
  • Singular Matrix: A square matrix whose determinant is zero (|A| = 0).
  • Non-Singular Matrix: A square matrix whose determinant is non-zero (|A| ≠ 0).
  • Adjoint of A (adj A): The transpose of the cofactor matrix of A.
  • Inverse of A (A⁻¹): A matrix such that AA⁻¹ = A⁻¹A = I. Exists only if |A| ≠ 0. A⁻¹ = (1/|A|)·adj(A).
  • Element Matrix (Eᵢⱼ): A matrix having 1 at position (i,j) and 0 elsewhere.
  • Order of a Matrix: The pair (m,n) indicating m rows and n columns.

Key concepts

  • Two matrices A and B are equal (A = B) if and only if:
    • They have the same order (same number of rows and columns).
    • Corresponding entries are equal: aᵢⱼ = bᵢⱼ for all i,j.

    NDA/CDS frequently tests this in equation form: If [[a+b, a−b],[2c+d, c−d]] = [[6,2],[9,3]], solve for a,b,c,d.
    → Equate corresponding elements pairwise. This generates a system of linear equations.
  • Addition: A + B is defined only when both matrices have the same order. Add corresponding entries: (A+B)ᵢⱼ = aᵢⱼ + bᵢⱼ.

    Subtraction: A − B = A + (−B), same order requirement.

    Scalar Multiplication: kA multiplies every entry by k: (kA)ᵢⱼ = k·aᵢⱼ.

    Matrix Multiplication: AB is defined only when columns of A = rows of B. If A is m×n and B is n×p, then AB is m×p.
    The (i,j)-th entry of AB = sum of (row i of A)·(column j of B).

    CRITICAL: Matrix multiplication is NOT commutative in general. AB ≠ BA.
    Counter-example always works: take two 2×2 matrices and verify AB ≠ BA.

    Properties:
    • Associative: (AB)C = A(BC)
    • Distributive: A(B+C) = AB + AC and (A+B)C = AC + BC
    • k(AB) = (kA)B = A(kB)
    • AI = IA = A (identity acts as multiplicative identity)
    • AA⁻¹ = A⁻¹A = I (when inverse exists)
  • For matrices A and B (of compatible orders):
    • (Aᵀ)ᵀ = A (double transpose returns original)
    • (A + B)ᵀ = Aᵀ + Bᵀ
    • (kA)ᵀ = k·Aᵀ
    • (AB)ᵀ = Bᵀ·Aᵀ ← VERY IMPORTANT: reverse the order
    • |Aᵀ| = |A| → Determinant unchanged under transposition

    Application: To prove a matrix is symmetric, show Aᵀ = A. To prove skew-symmetric, show Aᵀ = −A.
  • Theorem 1: For any square matrix A, both (A + Aᵀ) and (A − Aᵀ) are defined.
    • (A + Aᵀ) is always symmetric.
    • (A − Aᵀ) is always skew-symmetric.

    Theorem 2: Every square matrix A can be expressed uniquely as:
    A = ½(A + Aᵀ) + ½(A − Aᵀ)
    where the first part is symmetric and the second is skew-symmetric.

    Theorem 3: If A is symmetric, then Aⁿ is symmetric for every positive integer n.
    If A is skew-symmetric and n is odd, Aⁿ is skew-symmetric; if n is even, Aⁿ is symmetric.

    NDA/CDS trap: The product of two symmetric matrices is symmetric ONLY IF they commute (AB = BA). Do not assume symmetry of AB without checking commutativity.
  • For a 2×2 matrix A = [[a, b],[c, d]]: |A| = ad − bc.

    For a 3×3 matrix A = [[a₁₁, a₁₂, a₁₃],[a₂₁, a₂₂, a₂₃],[a₃₁, a₃₂, a₃₃]]:
    |A| = a₁₁(a₂₂a₃₃ − a₂₃a₃₂) − a₁₂(a₂₁a₃₃ − a₂₃a₃₁) + a₁₃(a₂₁a₃₂ − a₂₂a₃₁)
    Expand along any row or column. The sign pattern for cofactors follows:
    + − +
    − + −
    + − +
    (Check: aᵢⱼ's cofactor sign is (−1)ⁱ⁺ʲ.)

    Key rule: Expanding along the row/column with most zeros reduces computation time significantly.
  • P1. |Aᵀ| = |A|
    P2. Interchanging any two rows (or columns) changes the sign of the determinant.
    P3. If two rows (or columns) are identical, |A| = 0.
    P4. If a row (or column) is all zeros, |A| = 0.
    P5. Multiplying a row (or column) by k multiplies the determinant by k: |kA| = kⁿ|A| for an n×n matrix.
    P6. If two rows (or columns) are proportional, |A| = 0.
    P7. If entries of one row are sums of two terms, the determinant splits into sum of two determinants.
    P8. Operating Rᵢ → Rᵢ + kRⱼ (adding a multiple of one row to another) does NOT change the value of the determinant.
    P9. |AB| = |A|·|B|
    P10. For an n×n matrix: |A⁻¹| = 1/|A| (when A is non-singular)
    P11. |Aᵐ| = (|A|)ᵐ
  • Minor Mᵢⱼ of element aᵢⱼ: The determinant obtained by deleting the i-th row and j-th column from A.
    Cofactor Aᵢⱼ of element aᵢⱼ: Aᵢⱼ = (−1)ⁱ⁺ʲ · Mᵢⱼ.

    Expansion formula (Laplace expansion):
    |A| = aᵢ₁Aᵢ₁ + aᵢ₂Aᵢ₂ + aᵢ₃Aᵢ₃ (+ve for row i)
    or
    |A| = a₁ⱼA₁ⱼ + a₂ⱼA₂ⱼ + a₃ⱼA₃ⱼ (+ve for column j)

    Key property: The sum aᵢ₁Aⱼ₁ + aᵢ₂Aⱼ₂ + aᵢ₃Aⱼ₃ = 0 when i ≠ j (expansion using wrong row/column gives zero).
  • Adjoint of A (adj A): Transpose of the cofactor matrix. Compute all cofactors Aᵢⱼ, form the cofactor matrix, then transpose it.

    For 2×2: If A = [[a,b],[c,d]], then adj(A) = [[d, −b],[−c, a]].
    For 3×3: Compute 9 cofactors, arrange as cofactor matrix, then transpose.

    Inverse (when |A| ≠ 0):
    A⁻¹ = (1/|A|)·adj(A)

    Existence condition: A⁻¹ exists if and only if A is non-singular (|A| ≠ 0).

    Properties:
    • (A⁻¹)ᵀ = (Aᵀ)⁻¹
    • (AB)⁻¹ = B⁻¹A⁻¹ (reverse order again!)
    • (A⁻¹)⁻¹ = A
    • (kA)⁻¹ = (1/k)A⁻¹ for k ≠ 0
    • A·adj(A) = adj(A)·A = |A|·I
    • adj(adj A) = |A|ⁿ⁻² · A (for n×n matrix)
    • |adj A| = |A|ⁿ⁻¹
  • Write the system AX = B where:
    A = coefficient matrix, X = variable column matrix, B = constant column matrix.

    Case 1: |A| ≠ 0 (non-singular)
    → Unique solution exists.
    → X = A⁻¹B.
    Compute A⁻¹ using adj(A)/|A|, then multiply by B.

    Case 2: |A| = 0 (singular)
    → Compute (adj A)·B.
    If (adj A)·B ≠ O → System is INCONSISTENT (no solution).
    If (adj A)·B = O → System may be consistent with infinite solutions.
    (Need to check rank conditions for full classification, but NDA/CDS mainly tests Case 1 and inconsistency in Case 2.)

    NDA/CDS shortcut: When |A| = 0, compute (adj A)B. If result is non-zero vector → no solution. If zero vector → infinite solutions (check by substitution).
  • Area of triangle with vertices (x₁,y₁), (x₂,y₂), (x₃,y₃):
    Area = ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|

    Or in determinant form:
    Area = ½ |det([[x₁, y₁, 1],[x₂, y₂, 1],[x₃, y₃, 1]])|

    Important corollary: Three points are COLLINEAR if and only if the area of triangle formed by them is zero, i.e., the determinant equals zero.

    NDA/CDS frequently asks: Find k so that points (a, b+c), (b, c+a), (c, a+b) are collinear → answer is a+b+c = 0 or a=b=c type conditions depending on exact setup.
  • Three types of elementary row operations (analogous for columns):
    R1. interchange: Rᵢ ↔ Rⱼ
    R2. scaling: Rᵢ → kRᵢ, k ≠ 0
    R3. replacement: Rᵢ → Rᵢ + kRⱼ

    These operations are used to find the inverse of a matrix:
    [A | I] → (row reduce) → [I | A⁻¹]

    Also used to simplify determinants before evaluation:
    Apply Rᵢ → Rᵢ + kRⱼ to create zeros, then expand along the zero-rich row/column.

    Key point: Row replacement operations (R3) do not change the determinant's value.
  • • If A is singular, then |A| = 0 → A⁻¹ does not exist.
    • |kA| = kⁿ|A| for n×n matrix. (Many students mistakenly write k|A|.)
    • For orthogonal matrix Q: QᵀQ = QQᵀ = I → |Q| = ±1.
    • For any square matrix A: A·adj(A) = |A|·I.
    • det(A + B) ≠ det(A) + det(B) generally (do NOT distribute determinant over addition).
    • For 2×2 matrix, finding inverse is direct. For 3×3, use adj/det method.
    • In NDA/CDS MCQs, substitute special values (like A = I or diagonal matrices) to quickly eliminate wrong options in abstract matrix questions.

Important facts

  • Number of elements in an m×n matrix = m×n. Possible orders for 12 elements: 1×12, 2×6, 3×4, 4×3, 6×2, 12×1 and their reverses (total 6 ordered pairs).
  • For a 3×3 matrix, the number of distinct determinants obtainable by rearranging nine given distinct digits (each used once) is at most 9! = 362880, but the question typically asks: how many determinants are possible from digits 1–9 each used once.
  • Any square matrix A can be written as sum of a symmetric matrix and a skew-symmetric matrix: A = ½(A+Aᵀ) + ½(A−Aᵀ). This decomposition is UNIQUE.
  • In a skew-symmetric matrix of odd order, the determinant is always zero (since |A| = |−A| = (−1)ⁿ|A| = −|A| when n is odd, implying |A| = 0).
  • If A is invertible, then adj(A) = |A|·A⁻¹.
  • det(AB) = det(A)·det(B) holds for square matrices of same order.
  • For orthogonal matrix A: A⁻¹ = Aᵀ and |A| = ±1.
  • If A and B are invertible matrices of same order, then (AB)⁻¹ = B⁻¹A⁻¹, NOT A⁻¹B⁻¹.
  • Three points (x₁,y₁), (x₂,y₂), (x₃,y₃) are collinear iff x₁(y₂−y₃)+x₂(y₃−y₁)+x₃(y₁−y₂)=0.
  • If Ax = 0 (homogeneous system) and |A| ≠ 0, then x = 0 (trivial solution only). If |A| = 0, non-trivial solutions exist.
  • For 2×2 matrix [[a,b],[c,d]]: eigenvalues satisfy λ² − (a+d)λ + (ad−bc) = 0. Trace = a+d, determinant = ad−bc. (Relevant for CDS advanced level.)
  • If |A| = 5 and A is 3×3, then |adj A| = |A|³⁻¹ = 25 and |3A| = 3³·5 = 135.

Memory aids

  • Transpose reversal: Think of putting on socks then shoes — to reverse, you remove shoes then socks. (AB)ᵀ = BᵀAᵀ. Same for inverse: (AB)⁻¹ = B⁻¹A⁻¹.
  • Singular = 'Sin-gular' → like a solo act that collapses (det = 0). Non-singular = full ensemble (det ≠ 0, inverse exists).
  • Skew-symmetric diagonal trick: Diagonal entries of skew-symmetric matrix must satisfy aᵢᵢ = −aᵢᵢ → 2aᵢᵢ = 0 → aᵢᵢ = 0. All diagonals are zero.
  • Odd-order skew-symmetric determinant = 0: Remember 'Odd Skew = Zero' as a mantra. Because |A| = |Aᵀ| = |−A| = (−1)ⁿ|A| = −|A|, forcing |A| = 0.
  • |kA| = kⁿ|A|: Count the dimension n as the exponent. For 3×3 matrix scaled by 2, determinant scales by 2³ = 8.
  • Adjoint mnemonic: 'Adj' sounds like 'addjacent' → find cofactors (adjacent minors), then transpose (flip). Adj(A) = (Cofactor Matrix)ᵀ.
  • Area of triangle formula: Write vertices in order around the triangle, add the cross-products going down-right (x₁y₂ + x₂y₃ + x₃y₁) and subtract cross-products going up-right (y₁x₂ + y₂x₃ + y₃x₁), halve the absolute value.
  • Unique decomposition: Any matrix = (symmetric part) + (skew-symmetric part). The ½ factor appears because you're splitting A into two equal halves along symmetry.
  • Collinearity test: Zero area = straight line = collinear. Visualize three points forming a 'flat' triangle with no height.

Exam tips

  • NDA/CDS often includes 2–4 direct questions from Matrices and Determinants per paper. Practice 3×3 determinant evaluation by hand within 90 seconds.
  • When a question gives an abstract matrix equation (e.g., A² = A, find A⁻¹), test with A = I and A = O to quickly eliminate options.
  • For 'find k' questions involving singularity, set up |A| = 0 and solve. These appear almost every year.
  • Memorize the 2×2 inverse formula cold: [[a,b],[c,d]]⁻¹ = (1/(ad−bc))[[d,−b],[−c,a]]. For 3×3, use adj/det method systematically.
  • In MCQs asking about properties of symmetric/skew-symmetric matrices, remember: product of symmetric matrices is symmetric IFF they commute.
  • Use the property |adj A| = |A|ⁿ⁻¹ and |kA| = kⁿ|A| to solve numerical questions without computing the full matrix.
  • For collinearity questions, directly apply the determinant form of area = 0. Set up the 3×3 determinant with the given points and solve for the unknown.
  • If asked to express a matrix as sum of symmetric and skew-symmetric parts, compute A+Aᵀ and A−Aᵀ directly and apply the formulas. No need for long derivations.
  • Chapter weightage in NDA Mathematics: approximately 8–12 marks from this topic across both matrix and determinant questions combined. High ROI topic — master it.
  • For CDS (Elementary Mathematics), determinant questions sometimes involve solving simultaneous equations or finding consistency — practice both types thoroughly.
  • When evaluating a determinant with variables, look for common factors in rows/columns before expanding. Factoring out (a+b), (b−c), etc. simplifies computation dramatically.
  • Remember: rank-based classification of systems (consistent/inconsistent/infinite solutions) may appear at slightly deeper level in CDS; focus on the |A|=0 case with adj(A)B test for NDA.

Common traps

  • Assuming AB = BA: Matrix multiplication is NOT commutative. Always verify with a counterexample if asked generally.
  • Writing |A + B| = |A| + |B|: Determinant does NOT distribute over addition. This is one of the most common errors.
  • Computing |kA| = k|A|: Wrong! It is |kA| = kⁿ|A| where n is the order. For 3×3, |2A| = 8|A|, not 2|A|.
  • Finding inverse of a singular matrix: If |A| = 0, A⁻¹ DOES NOT EXIST. Division by zero is undefined. Check |A| first.
  • Sign error in cofactor expansion: The sign pattern is +−+ / −+− / +−+. Mixing up signs gives wrong determinant.
  • Confusing adj(A) with A⁻¹: adj(A) is a matrix of cofactors (transposed); A⁻¹ = adj(A)/|A|. They differ by the scalar 1/|A|.
  • Forgetting to transpose when computing adj(A): adj(A) = (cofactor matrix)ᵀ, not just the cofactor matrix.
  • Applying row operations that change the determinant: Swapping rows flips the sign; scaling a row by k multiplies det by k. Only Rᵢ → Rᵢ + kRⱼ preserves the determinant.
  • Saying AB = O implies A = O or B = O: False. Two non-zero matrices can multiply to give zero matrix (zero divisors exist in matrix algebra).
  • Assuming (A + B)⁻¹ = A⁻¹ + B⁻¹: This is FALSE. No such simplification exists for inverse of a sum.
  • Treating matrix division as valid: There is no matrix division. 'Dividing by A' means multiplying by A⁻¹, which requires |A| ≠ 0.
  • In area-of-triangle problems: Forgetting the absolute value and the ½ factor. Also, the order of vertices does not matter for area (due to absolute value), but sign changes with orientation.
