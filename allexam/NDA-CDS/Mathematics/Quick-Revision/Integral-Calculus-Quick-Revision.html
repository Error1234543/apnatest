Integral Calculus — Quick Revision for NDA & CDS

NDA & CDSEnglishQuick Revision

Definitions

  • Integral (Indefinite): An integral that produces a family of functions differing by a constant of integration C. Written as ∫f(x)dx = F(x) + C, where F'(x) = f(x). It is the inverse process of differentiation.
  • Integral (Definite): A limit of a sum representing the net area under a curve between two fixed limits. Written as ∫[a to b] f(x)dx = F(b) − F(a), provided f is continuous on [a, b]. This yields a numerical value, not a function.
  • Geometric Interpretation: The definite integral ∫[a to b] f(x)dx equals the algebraic area between y = f(x), the x-axis, and the vertical lines x = a and x = b. Areas above the x-axis are positive; areas below are negative.
  • Antiderivative / Primitive: Any function F such that dF/dx = f. The set of all primitives is written F(x) + C. NDA/CDS questions frequently ask for a specific primitive satisfying an initial condition.

Key concepts

  • Standard Integrals (must memorize cold):
  • • ∫x^n dx = x^(n+1)/(n+1) + C, for n ≠ −1
  • • ∫(1/x) dx = ln|x| + C
  • • ∫e^x dx = e^x + C
  • • ∫a^x dx = a^x/ln(a) + C, a > 0, a ≠ 1
  • • ∫sin x dx = −cos x + C
  • • ∫cos x dx = sin x + C
  • • ∫sec²x dx = tan x + C
  • • ∫csc²x dx = −cot x + C
  • • ∫sec x tan x dx = sec x + C
  • • ∫csc x cot x dx = −csc x + C
  • • ∫sec x dx = ln|sec x + tan x| + C
  • • ∫csc x dx = ln|csc x − cot x| + C
  • • ∫tan x dx = ln|sec x| + C = −ln|cos x| + C
  • • ∫cot x dx = ln|sin x| + C
  • • ∫sec x tan x dx = sec x + C; ∫csc x cot x dx = −csc x + C
  • • ∫dx/√(a² − x²) = sin⁻¹(x/a) + C
  • • ∫dx/(a² + x²) = (1/a)tan⁻¹(x/a) + C
  • • ∫dx/(x√(x² − a²)) = (1/a)sec⁻¹(x/a) + C
  • • ∫dx/√(x² ± a²) = ln|x + √(x² ± a²)| + C
  • Substitution Method: When the integrand contains a composite expression, substitute u = g(x) so that du = g'(x)dx. The goal is to reduce the integral to a standard form. Classic NDA/CDS examples: ∫f(ax+b)dx, integrands containing √(a²−x²), √(x²+a²), or expressions like sin²x·cos x.
  • Integration by Parts: Based on the product rule: ∫u dv = uv − ∫v du. Choose u using the ILATE rule (Inverse trigonometric, Logarithmic, Algebraic, Trigonometric, Exponential) — the function that appears earlier in ILATE is taken as u. For NDA/CDS, common patterns include ∫x·sin x dx, ∫x·e^x dx, ∫e^x(f(x)+f'(x))dx = e^x·f(x)+C.
  • Partial Fractions: Used when integrating a rational function P(x)/Q(x) where degree(P) < degree(Q). Decompose Q(x) into linear or irreducible quadratic factors, then express the fraction as a sum of simpler fractions whose numerators are constants (for linear factors) or linear terms (for irreducible quadratics). Solve for unknown coefficients by equating numerators. NDA/CDS often features denominators like (x−1)(x+2), (x−1)²(x+3), or (x²+1)(x−2).
  • Definite Integral Properties (high-yield for NDA/CDS):
  • • ∫[a to b] f(x)dx = ∫[a to b] f(a+b−x)dx (useful for symmetry)
  • • ∫[0 to a] f(x)dx = 0 if f is odd about x=a/2; otherwise not generally zero.
  • • ∫[−a to a] f(x)dx = 2∫[0 to a] f(x)dx if f is even; = 0 if f is odd.
  • • ∫[a to b] f(x)dx = −∫[b to a] f(x)dx
  • • ∫[a to b] f(x)dx = ∫[a to c] f(x)dx + ∫[c to b] f(x)dx
  • • ∫[0 to π] x·f(sin x)dx = (π/2)∫[0 to π] f(sin x)dx
  • • ∫[0 to 2π] f(sin x)dx = 2∫[0 to π] f(sin x)dx (if f(sin x) has period π)
  • Special Forms Frequently Appearing in NDA/CDS:
  • • ∫e^x[f(x)+f'(x)]dx = e^x·f(x)+C
  • • ∫[f(x)+x·f'(x)]dx = x·f(x)+C
  • • ∫√(a²−x²) dx = (x/2)√(a²−x²) + (a²/2)sin⁻¹(x/a) + C
  • • ∫√(x²+a²) dx = (x/2)√(x²+a²) + (a²/2)ln|x+√(x²+a²)| + C
  • • ∫√(x²−a²) dx = (x/2)√(x²−a²) − (a²/2)ln|x+√(x²−a²)| + C
  • • ∫dx/(x²−a²) = (1/2a)ln|(x−a)/(x+a)| + C
  • • ∫dx/(a²−x²) = (1/2a)ln|(a+x)/(a−x)| + C
  • Area Under a Curve: The area bounded by y=f(x), the x-axis, and lines x=a and x=b is A = ∫[a to b] f(x)dx. For regions between two curves y₁ and y₂, A = ∫[a to b]|y₁−y₂|dx. In NDA/CDS, problems typically involve parabolas, circles, ellipses, and straight lines. Symmetry is often used to simplify computation.

Important facts

  • NDA and CDS Mathematics papers each carry significant weight from Integral Calculus — approximately 8–12 direct questions in NDA and similar in CDS Elementary Mathematics.
  • The most frequently tested topics in order of frequency are: standard integrals and basic substitution, integration by parts (especially e^x[f(x)+f'(x)] pattern), definite integral properties (even/odd, ∫[0 to a] and ∫[0 to π] tricks), and area under curves.
  • NDA questions on integrals are primarily of moderate difficulty; a few are application-based but do not require advanced techniques beyond the syllabus.
  • CDS Elementary Mathematics integral calculus questions tend to be slightly more procedural than NDA, often testing step-by-step ability rather than trick-based shortcuts.
  • Standard results must be recalled with correct signs and constants. A single sign error (e.g., confusing the result of ∫sin x with ∫cos x, or forgetting the negative in ∫csc²x) leads to elimination of answer choices.
  • The constant of integration C is required only in indefinite integrals, never in definite integrals.
  • For ∫dx/√(a²−x²), the result is sin⁻¹(x/a)+C, not cos⁻¹(x/a)+C. These differ by a constant, but the standard textbook answer expected in exams is the arcsine form.
  • For ∫dx/√(x²+a²), the result is ln|x+√(x²+a²)|+C. This is sometimes written as sinh⁻¹(x/a)+C but the logarithmic form is the one tested.
  • In partial fractions, always check whether the given rational function is proper (degree of numerator < degree of denominator). If improper, perform polynomial division first.
  • When using the property ∫[0 to a] f(x)dx = ∫[0 to a] f(a−x)dx, replace every occurrence of x with (a−x) throughout the integrand before simplifying. This property converts many difficult trigonometric integrals into solvable forms.

Memory aids

  • ILATE Rule for Integration by Parts: Inverse → Logarithmic → Algebraic → Trigonometric → Exponential. The leftmost function in ILATE should always be chosen as u.
  • Mnemonic for Trig Integrals: "Some Students Cheat And Fail At College" → Sin→−Cos, SecTan→Sec, Tan→ln|Sec|, Cos→Sin, CosecCot→−Csc, Cot→ln|Sin|.
  • Standard Arc Functions: "Sin inverse needs minus inside root, Tan inverse needs plus inside root" — i.e., ∫dx/√(a²−x²) gives sin⁻¹, while ∫dx/(a²+x²) gives tan⁻¹.
  • Even/Odd Shortcut: For definite integrals, immediately check parity. Even functions double the half-interval; odd functions over symmetric limits give zero. This eliminates calculation entirely.
  • Memory Hook for ∫e^x[f(x)+f'(x)]dx = e^x·f(x)+C: Think "ex times f plus derivative stays ex times f" — differentiating e^x·f(x) gives exactly e^x[f(x)+f'(x)].
  • Formula Sheet Anchor: Write down all 18 standard integrals on a single sheet and practice recalling them daily until they are automatic.

Exam tips

  • In NDA, spend no more than 2 minutes on a single integral calculus question during the first pass. If a problem requires partial fractions with three unknowns, consider skipping and returning later.
  • CDS has less time pressure per question than NDA but demands accurate step execution. Practice writing at least the first two steps of integration by parts on your rough sheet to avoid sign cascades.
  • When facing ∫[0 to π] sin²x dx or ∫[0 to π] cos²x Dx, recall immediately: the result is π/2. This is a direct consequence of the property involving ∫[0 to π] f(sin x)dx.
  • For area problems, sketch the region first. Identifying intersection points between a parabola and a line saves minutes and prevents setting wrong limits.
  • Use symmetry aggressively. If an integral is over [−a to a], classify f as even/odd before calculating anything else.
  • Memorize the five special definite integral properties listed above — they appear almost every year in NDA and CDS. A single application can solve a problem in seconds that would otherwise take several minutes.
  • For multiple-choice questions on integrals, differentiate each option quickly. Since NDA/CDS gives four options, the correct antiderivative will differentiate back to the integrand. This reverse-check technique is often faster than integrating from scratch.
  • In area-of-region questions, verify your answer's units and sign. Area is always non-negative. If your computed integral yields a negative value, you have likely reversed the upper and lower curves or the limits.
  • Practice at least 30 mixed integral problems covering substitution, parts, partial fractions, and definite integral properties before the exam. Speed and accuracy come from recognizing patterns, not re-deriving from first principles.

Common traps

  • Forgetting the constant C in indefinite integrals. Every indefinite integral without bounds requires +C. This is the most commonly lost easy mark.
  • Confusing ∫sec x dx and ∫csc x dx results. Remember: sec gives ln|sec+tan|, csc gives ln|csc−cot|.
  • Sign errors with ∫csc²x dx = −cot x + C and ∫cot x dx = ln|sin x| + C. The negative sign is easy to miss.
  • Applying the power rule ∫x^n dx = x^(n+1)/(n+1) when n = −1. This formula fails at n = −1; the correct result is ln|x|.
  • Mixing up the formulas for ∫dx/(a²−x²) versus ∫dx/(x²−a²). The former gives ln|(a+x)/(a−x)|/(2a); the latter gives ln|(x−a)/(x+a)|/(2a). The arguments inside the logs are reciprocals of each other.
  • Not checking whether a rational function is proper before applying partial fractions. Applying partial fractions directly to an improper fraction yields incorrect coefficients.
  • Using the property ∫[−a to a] f(x)dx = 2∫[0 to a] f(x)dx without verifying that f is even. This property is false for odd or non-symmetric functions and leads to wrong answers.
  • Confusing ∫[0 to π] x·f(sin x)dx with ∫[0 to π] f(sin x)dx. The correct identity includes the factor (π/2), not 1.
  • Forgetting absolute value bars in logarithmic integral results. ∫(1/x)dx = ln|x|+C, not simply ln x + C. While many NDA/CDS multiple-choice options omit this subtlety, it is still good practice.
  • Errors in area calculations by not taking the absolute value when curves cross the x-axis or each other within the interval. The integral alone gives signed area; you must split the integral at intersection points to compute actual geometric area.
