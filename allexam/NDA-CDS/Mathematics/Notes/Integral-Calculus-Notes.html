Indefinite Integration: Basic Formulas and Standard Results

Integration is the inverse process of differentiation. If d/dx[f(x)] = g(x), then ∫g(x)dx = f(x) + C, where C is the constant of integration.

Power Rule: ∫xⁿ dx = xⁿ⁺¹/(n+1) + C, for n ≠ -1
Special case: ∫(1/x)dx = ln|x| + C

Exponential Functions:
• ∫eˣ dx = eˣ + C
• ∫aˣ dx = aˣ/ln(a) + C, where a > 0, a ≠ 1
• ∫eᵃˣ dx = eᵃˣ/a + C

Trigonometric Functions:
• ∫sin x dx = -cos x + C
• ∫cos x dx = sin x + C
• ∫sec²x dx = tan x + C
• ∫cosec²x dx = -cot x + C
• ∫sec x tan x dx = sec x + C
• ∫cosec x cot x dx = -cosec x + C

Inverse Trigonometric Derivatives (as integrals):
• ∫1/√(1-x²) dx = sin⁻¹x + C = -cos⁻¹x + C
• ∫1/(1+x²) dx = tan⁻¹x + C
• ∫1/(x√(x²-1)) dx = sec⁻¹x + C

Logarithmic Forms:
• ∫1/x dx = ln|x| + C
• ∫f'(x)/f(x) dx = ln|f(x)| + C
• ∫1/(x²-a²) dx = (1/2a)ln|(x-a)/(x+a)| + C
• ∫1/(a²-x²) dx = (1/2a)ln|(a+x)/(a-x)| + C
• ∫1/(x²+a²) dx = (1/a)tan⁻¹(x/a) + C
• ∫1/√(a²-x²) dx = sin⁻¹(x/a) + C
• ∫1/√(x²+a²) dx = ln|x + √(x²+a²)| + C
• ∫1/√(x²-a²) dx = ln|x + √(x²-a²)| + C

Hyperbolic Functions:
• ∫sinh x dx = cosh x + C
• ∫cosh x dx = sinh x + C
• ∫sech²x dx = tanh x + C
• ∫csch²x dx = -coth x + C

Methods of Integration: Substitution and Partial Fractions

Substitution Method (Change of Variable):
When the integrand contains a composite function, substitute to simplify.

Standard substitutions:
• For ∫f(ax+b)dx: put ax+b = t, so dx = dt/a
• For ∫f(√x)dx: put √x = t, so x = t² and dx = 2tdt
• For ∫f(x/√(1-x²))dx: put x = sin θ or x = cos θ
• For ∫f(√(a²-x²))dx: put x = a sin θ or x = a cos θ
• For ∫f(√(x²-a²))dx: put x = a sec θ or x = a cosh t
• For ∫f(√(a²+x²))dx: put x = a tan θ or x = a sinh t
• For irrational forms like ∫dx/(p + q√(ax+b)): put ax+b = t²

Example: ∫x√(1-x²)dx
Put 1-x² = t², then -2xdx = 2tdt, so xdx = -tdt
∫x√(1-x²)dx = ∫t(-tdt) = -∫t²dt = -t³/3 + C = -(1-x²)^(3/2)/3 + C

Partial Fraction Decomposition:
Used when integrating rational functions P(x)/Q(x) where degree of P < degree of Q.

Case 1: Distinct Linear Factors
If Q(x) = (x-a₁)(x-a₂)...(x-aₙ)
Then P(x)/Q(x) = A₁/(x-a₁) + A₂/(x-a₂) + ... + Aₙ/(x-aₙ)
Find constants by equating numerators or substituting convenient values.

Case 2: Repeated Linear Factors
If Q(x) = (x-a)ᵐ(x-b)...
Then include terms: A₁/(x-a) + A₂/(x-a)² + ... + Aₘ/(x-a)ᵐ

Case 3: Irreducible Quadratic Factors
If Q(x) contains (ax²+bx+c) where b²-4ac < 0:
Include term (Ax+B)/(ax²+bx+c) for each occurrence.

Example: ∫(3x+5)/(x²+3x+2) dx
Factor denominator: x²+3x+2 = (x+1)(x+2)
Write: (3x+5)/[(x+1)(x+2)] = A/(x+1) + B/(x+2)
3x+5 = A(x+2) + B(x+1)
Put x = -1: 2 = A, so A = 2
Put x = -2: -1 = -B, so B = 1
∫[2/(x+1) + 1/(x+2)]dx = 2ln|x+1| + ln|x+2| + C

Case 4: Improper Fractions (degree P ≥ degree Q)
First perform polynomial division, then decompose the remainder.

Integration by Parts and Reduction Formulas

Integration by Parts (LIATE Rule):
Based on product rule of differentiation:
∫u·v dx = u∫v dx - ∫(du/dx · ∫v dx)dx

Choose u according to LIATE precedence:
L - Logarithmic functions (ln x, log x)
I - Inverse trigonometric functions (sin⁻¹x, tan⁻¹x)
A - Algebraic functions (x, x², polynomials)
T - Trigonometric functions (sin x, cos x)
E - Exponential functions (eˣ, aˣ)

Common pairings:
• Polynomial × trigonometric: u = polynomial
• Polynomial × exponential: u = polynomial
• Inverse trig × algebraic: u = inverse trig
• Logarithmic × algebraic: u = logarithmic

Examples:
∫x sin x dx: u = x, dv = sin x dx
= x(-cos x) - ∫1·(-cos x)dx = -x cos x + sin x + C

∫x eˣ dx: u = x, dv = eˣ dx
= x·eˣ - ∫eˣ dx = xeˣ - eˣ + C = eˣ(x-1) + C

∫sin⁻¹x dx: u = sin⁻¹x, dv = dx
= x sin⁻¹x - ∫x/√(1-x²)dx = x sin⁻¹x + √(1-x²) + C

∫ln x dx: u = ln x, dv = dx
= x ln x - ∫x·(1/x)dx = x ln x - x + C = x(ln x - 1) + C

Reduction Formulas (for repeated integration):
Involving powers:
• Iₙ = ∫sinⁿx dx = -(1/n)sinⁿ⁻¹x cos x + ((n-1)/n)Iₙ₋₂
• Iₙ = ∫cosⁿx dx = (1/n)cosⁿ⁻¹x sin x + ((n-1)/n)Iₙ₋₂
• Iₙ = ∫tanⁿx dx = tanⁿ⁻¹x/(n-1) - Iₙ₋₂
• Iₙ = ∫secⁿx dx = secⁿ⁻²x tan x/(n-1) + (n-2)/(n-1)Iₙ₋₂

Exponential-trigonometric reduction:
• Iₙ = ∫xⁿeˣ dx = xⁿeˣ - nIₙ₋₁
• Jₙ = ∫xⁿeᵃˣ dx = xⁿeᵃˣ/a - n/a·Jₙ₋₁

Important base cases:
∫sin²x dx = x/2 - (sin 2x)/4 + C
∫cos²x dx = x/2 + (sin 2x)/4 + C
∫sec⁴x dx = tan x + tan³x/3 + C
∫cosec⁴x dx = -cot x - cot³x/3 + C

Definite Integrals: Properties and Evaluation

Definition: ∫₀ᵃ f(x)dx represents the area under curve y = f(x) from x = 0 to x = a, computed as F(a) - F(0) where F'(x) = f(x).

Key Properties:
1. ∫ₐᵇ f(x)dx = -∫ᵇₐ f(x)dx (limits reversal changes sign)
2. ∫ₐᵇ f(x)dx = ∫ₐᵇ f(t)dt (variable of integration is dummy)
3. ∫ₐᵇ f(x)dx = ∫ₐᶜ f(x)dx + ∫ᶜᵇ f(x)dx (splitting interval)
4. ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b-x)dx (reflection property)
5. ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a-x)dx (special case of property 4)
6. If f(2a-x) = f(x): ∫₀²ᵃ f(x)dx = 2∫₀ᵃ f(x)dx
7. If f(2a-x) = -f(x): ∫₀²ᵃ f(x)dx = 0

Even-Odd Function Properties (symmetric limits):
• If f(-x) = f(x) (even): ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx
• If f(-x) = -f(x) (odd): ∫₋ₐᵃ f(x)dx = 0

Useful shortcut results:
• ∫₀ᵃ f(x)dx + ∫₀ᵃ f(a-x)dx = 2∫₀ᵃ f(x)dx when f(x) = f(a-x)
• ∫₀^π x·f(sin x)dx = π/2 · ∫₀^π f(sin x)dx
• ∫₀^π f(sin x)dx = 2∫₀^{π/2} f(sin x)dx
• ∫₀^{π/2} f(sin x, cos x)dx = ∫₀^{π/2} f(cos x, sin x)dx
• Wallis Formula: ∫₀^{π/2} sinⁿx dx = ∫₀^{π/2} cosⁿx dx
= (n-1)/n · (n-3)/(n-2) · ... × π/2 (if n even)
= (n-1)/n · (n-3)/(n-2) · ... × 1 (if n odd)

Example using properties:
Evaluate ∫₀¹ x√(1-x)dx
Using property 4: put x → 1-x
∫₀¹ (1-x)√x dx = ∫₀¹ (√x - x^(3/2))dx
= [2x^(3/2)/3 - 2x^(5/2)/5]₀¹ = 2/3 - 2/5 = 4/15
Adding both: 2I = ∫₀¹ √(1-x)dx = 2/3
So I = 1/3

Evaluation technique: Always check for symmetry before direct integration. Use substitution x → a-x or split intervals to exploit properties.

Applications: Area Under Curves and Between Curves

Area Between Curve and X-axis:
For y = f(x) from x = a to x = b:
Area = |∫ₐᵇ f(x)dx|
Take absolute value since area is always positive.

If curve crosses x-axis, split at intercepts:
Area = |∫ₐᶜ f(x)dx| + |∫ᶜᵇ f(x)dx|

Area Between Two Curves:
If f(x) ≥ g(x) on [a,b]:
Area = ∫ₐᵇ [f(x) - g(x)]dx

Always identify upper and lower curves by testing a point in the region.

Standard Areas:
• Parabola y² = 4ax bounded by x = h: Area = (2/3)h√(4ah)
• Circle x² + y² = r²: Area = πr²
• Ellipse x²/a² + y²/b² = 1: Area = πab
• Asteroid x^(2/3) + y^(2/3) = a^(2/3): Area = (3πa²)/8
• Cardioid r = a(1+cos θ): Area = (3πa²)/2

Worked Example - Area enclosed by y = x² and y = x:
Intersection: x² = x → x(x-1) = 0 → x = 0, 1
On [0,1]: x ≥ x², so upper curve is y = x
Area = ∫₀¹ (x - x²)dx = [x²/2 - x³/3]₀¹ = 1/2 - 1/3 = 1/6 sq units

Worked Example - Area between y = sin x and x-axis from 0 to π:
Area = ∫₀^π sin x dx = [-cos x]₀^π = -(-1) - (-1) = 2 sq units

Worked Example - Area bounded by y = eˣ, x = 0, x = 1, x-axis:
Area = ∫₀¹ eˣ dx = [eˣ]₀¹ = e - 1 ≈ 1.718 sq units

Area using y as function of x is simpler when curves are vertical; use x = g(y) for horizontal strips.

For polar curves r = f(θ), area = (1/2)∫α^β r²dθ

NDA/CDS frequently tests: area of circle segments, parabola portions, and intersection regions of standard curves.

Differential Equations: Formation and Classification

A differential equation relates an unknown function with its derivatives.

Formation of Differential Equations:
Given family of curves with arbitrary constants, differentiate enough times to eliminate constants.

Example: y = mx + c (one parameter m, one parameter c → 2nd order DE)
Differentiate once: dy/dx = m
Differentiate again: d²y/dx² = 0
This is the required DE.

Example: y = Aeˣ + Be⁻ˣ
dy/dx = Aeˣ - Be⁻ˣ
d²y/dx² = Aeˣ + Be⁻ˣ = y
DE: d²y/dx² - y = 0

Order: Highest derivative present.
• dy/dx = x → order 1
• d²y/dx² + dy/dx = 0 → order 2
• d³y/dx³ + y = 0 → order 3

Degree: Power of highest derivative (when DE is polynomial in derivatives).
• (dy/dx)² + y = 0 → degree 2
• d²y/dx² + sin(dy/dx) = 0 → degree undefined (not polynomial in derivatives)

Classification:
• Linear: dy/dx + P(x)y = Q(x) — degree 1 in y and all derivatives, no products
• Non-linear: any DE not satisfying linearity
• Homogeneous: can be written as dy/dx = f(y/x)
• Exact: M(x,y)dx + N(x,y)dy = 0 with ∂M/∂y = ∂N/∂x

Standard forms tested in NDA/CDS:
1. Separable: dy/dx = f(x)g(y) → dy/g(y) = f(x)dx
2. Linear first-order: dy/dx + Py = Q
3. Homogeneous: dy/dx = f(y/x)
4. Clairaut's form: y = px + f(p) where p = dy/dx

Solving First-Order Differential Equations

Separable Equations:
dy/dx = f(x)·g(y)
Integrate: ∫dy/g(y) = ∫f(x)dx + C

Example: dy/dx = x/y
y dy = x dx → y²/2 = x²/2 + C → y² - x² = 2C (hyperbola)

Linear Equations: dy/dx + P(x)y = Q(x)
Integrating Factor: IF = e^(∫P dx)
Multiply through: d/dx[y·IF] = Q·IF
Solution: y·IF = ∫Q·IF dx + C

Example: dy/dx + y·cos x = sin x cos x
IF = e^(∫cos x dx) = e^(sin x)
y·e^(sin x) = ∫sin x cos x·e^(sin x) dx
Put sin x = t, cos x dx = dt
= ∫t·eᵗ dt = teᵗ - eᵗ + C = eᵗ(t-1) + C
Solution: y = (sin x - 1) + Ce^(-sin x)

Homogeneous Equations: dy/dx = f(y/x)
Substitute y = vx, so dy/dx = v + x(dv/dx)
v + x(dv/dx) = f(v)
x(dv/dx) = f(v) - v
∫dv/[f(v)-v] = ∫dx/x = ln|x| + C

Example: dy/dx = (y²+x²)/(xy)
= y/x + x/y = v + 1/v where y = vx
v + x(dv/dx) = v + 1/v
x(dv/dx) = 1/v → v dv = dx/x
v²/2 = ln|x| + C → y²/(2x²) = ln|x| + C

Bernoulli Equation: dy/dx + P(x)y = Q(x)yⁿ
Divide by yⁿ, substitute z = y¹⁻ⁿ to convert to linear form.

Exact Equations: Mdx + Ndy = 0
Check: ∂M/∂y = ∂N/∂x
If exact, find ψ such that ∂ψ/∂x = M and ∂ψ/∂y = N
Solution: ψ(x,y) = C

Second-Order Linear Differential Equations with Constant Coefficients

Standard Form: a·d²y/dx² + b·dy/dx + cy = 0

Auxiliary (Characteristic) Equation:
a·m² + b·m + c = 0

Three Cases based on discriminant Δ = b² - 4ac:

Case 1: Real and Distinct Roots (Δ > 0)
Roots m₁, m₂ (m₁ ≠ m₂)
Solution: y = A·e^(m₁x) + B·e^(m₂x)

Example: d²y/dx² - 5dy/dx + 6y = 0
m² - 5m + 6 = 0 → (m-2)(m-3) = 0
m₁ = 2, m₂ = 3
Solution: y = Ae²ˣ + Be³ˣ

Case 2: Real and Equal Roots (Δ = 0)
Root m (repeated)
Solution: y = (A + Bx)·e^(mx)

Example: d²y/dx² - 4dy/dx + 4y = 0
(m-2)² = 0 → m = 2, 2
Solution: y = (A + Bx)e²ˣ

Case 3: Complex Conjugate Roots (Δ < 0)
Roots m = α ± iβ
Solution: y = e^(αx)[A·cos(βx) + B·sin(βx)]

Example: d²y/dx² + 4dy/dx + 5y = 0
m² + 4m + 5 = 0 → m = (-4±√(16-20))/2 = -2±i
Solution: y = e^(-2x)[A·cos x + B·sin x]

Particular Solutions (finding A and B):
Given initial conditions y(x₀) = y₀ and y'(x₀) = y'₀, substitute to get two equations.

Non-Homogeneous: ay'' + by' + cy = R(x)
General solution: y = Complementary Function (C.F.) + Particular Integral (P.I.)
C.F. found from homogeneous part as above.
P.I. methods: undetermined coefficients or variation of parameters.

NDA/CDS typically focuses on homogeneous equations with constant coefficients and finding general/particular solutions.

Important facts

  • Integration is the inverse of differentiation; every indefinite integral includes an arbitrary constant C.
  • The power rule ∫xⁿdx = xⁿ⁺¹/(n+1)+C applies only when n ≠ -1; the special case n=-1 gives ln|x|+C.
  • Substitution method transforms complex integrands into standard forms; choose substitution to eliminate radicals or simplify compositions.
  • Partial fraction decomposition handles rational functions by expressing them as sums of simpler fractions with linear or quadratic denominators.
  • Integration by parts uses the LIATE rule to choose u; apply repeatedly when one factor reduces upon differentiation.
  • Definite integral properties, especially ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a-x)dx, often provide shortcuts avoiding direct computation.
  • Wallis formula gives quick evaluation of ∫₀^{π/2} sinⁿx dx and ∫₀^{π/2} cosⁿx dx without antiderivatives.
  • Area computations require identifying upper/lower curves and splitting at intersection points where sign changes.
  • Differential equation order equals the highest derivative; degree equals the power of that derivative when polynomial in derivatives.
  • Linear first-order DE has solution y·IF = ∫Q·IF dx + C where IF = e^(∫P dx).
  • Homogeneous DE dy/dx = f(y/x) uses substitution y = vx to separate variables.
  • Second-order linear DE with constant coefficients uses auxiliary equation am²+bm+c=0; three root cases give distinct solution forms.
  • Complex roots α±iβ in the auxiliary equation produce oscillatory solutions e^(αx)[A cos βx + B sin βx].
