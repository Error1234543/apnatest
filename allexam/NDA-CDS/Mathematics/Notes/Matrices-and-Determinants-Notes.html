Matrices and Determinants — Complete Notes for NDA & CDS Mathematics

NDA & CDSEnglishNotes

1. Matrix: Definition, Order and Types

['A matrix is a rectangular array of numbers (real or complex) arranged in rows and columns, enclosed within brackets or parentheses. If A has m rows and n columns, its order is m × n, and it contains mn elements. Each entry aᵢⱼ denotes the element in the i-th row and j-th column.', 'Row matrix: 1 × n, e.g., [2 −1 5 3]. Column matrix: m × 1, e.g., [4; −2; 7]. Square matrix: m = n, having equal rows and columns. Diagonal matrix: a square matrix where all off-diagonal entries are zero, e.g., diag(2, 5, −3). Scalar matrix: a diagonal matrix with all diagonal entries equal, e.g., 4I₃. Identity (unit) matrix Iₙ: a square matrix with 1s on the diagonal and 0 elsewhere. Zero (null) matrix Oₘₓₙ: every entry is 0.', 'Upper triangular matrix: all entries below the main diagonal are zero. Lower triangular matrix: all entries above the main diagonal are zero. Symmetric matrix: Aᵀ = A, so aᵢⱼ = aⱼᵢ for all i, j. Skew-symmetric matrix: Aᵀ = −A, implying aᵢⱼ = −aⱼᵢ and all diagonal entries must be 0. Singular matrix: a square matrix whose determinant is 0. Non-singular matrix: determinant ≠ 0. Orthogonal matrix: A·Aᵀ = Aᵀ·A = I.']

2. Operations on Matrices — Addition, Subtraction and Scalar Multiplication

['Two matrices can be added or subtracted only if they have the same order. The operation is performed entry-wise: (A ± B)ᵢⱼ = aᵢⱼ ± bᵢⱼ. Matrix addition is commutative (A + B = B + A) and associative ((A + B) + C = A + (B + C)). The zero matrix acts as the additive identity, and every matrix A has an additive inverse −A such that A + (−A) = O.', 'Scalar multiplication: if k is a scalar, then (kA)ᵢⱼ = k · aᵢⱼ. Properties: k(A + B) = kA + kB, (k + l)A = kA + lA, k(lA) = (kl)A, and 1·A = A. Note that A + B = B + A does NOT imply AB = BA; matrix multiplication is generally not commutative.', 'Important caveat for NDA/CDS: if AB = O, it does NOT follow that A = O or B = O. Two non-zero matrices can multiply to give the zero matrix. This is because matrices have zero divisors, unlike real numbers. Similarly, AB = AC does NOT imply B = C even when A ≠ O.']

3. Matrix Multiplication

['If A is of order m × n and B is of order n × p, then the product AB is defined and has order m × p. The element in the i-th row and j-th column of AB is obtained by taking the dot product of the i-th row of A with the j-th column of B: (AB)ᵢⱼ = Σₖ aᵢₖ · bₖⱼ. For CADET (Common Algebra for Defenders and Aspirants Test), remember: inner dimensions must match, outer dimensions give the result.', 'Key properties of matrix multiplication: Associative: A(BC) = (AB)C. Distributive: A(B + C) = AB + AC and (A + B)C = AC + BC. Scalar compatibility: (kA)B = k(AB) = A(kB). However, multiplication is NOT commutative: AB ≠ BA in general. AB = BA is possible only in special cases (e.g., when A and B are both diagonal matrices, or one is the identity).', 'Adjoint property: For square matrices A and B of the same order, adj(AB) = adj(B) · adj(A) — note the reverse order. Also, |AB| = |A| · |B|. For an n × n matrix A, |kA| = kⁿ|A|. This frequently appears in NDA/CDS MCQs: if A is 3 × 3 and |A| = 5, then |2A| = 2³ × 5 = 40, NOT 10.', 'Worked example: If A = [[1, 2], [3, 4]] and B = [[0, 1], [−1, 0]], then AB = [[−2, 1], [−4, 3]] and BA = [[3, 4], [−1, −2]]. Clearly AB ≠ BA.']

4. Transpose, Conjugate and Hermitian Matrices

['Transpose Aᵀ: interchange rows and columns. If A is m × n, then Aᵀ is n × m, with (Aᵀ)ᵢⱼ = aⱼᵢ. Properties: (Aᵀ)ᵀ = A, (A + B)ᵀ = Aᵀ + Bᵀ, (kA)ᵀ = kAᵀ, and (AB)ᵀ = Bᵀ · Aᵀ — again, the reverse order is critical.', 'Conjugate ᴀ̅: replace each element by its complex conjugate. Conjugate transpose A (or ᴀ̅ᵀ): take the conjugate and then transpose. These are important for advanced properties but at NDA/CDS level, focus mainly on transpose properties.', 'Hermitian matrix: A = A (equal to its own conjugate transpose). Real symmetric matrices (Aᵀ = A with real entries) are a special case of Hermitian matrices. Skew-Hermitian matrix: A* = −A. A real skew-symmetric matrix is a special case of a skew-Hermitian matrix. In NDA/CDS, you may be asked to classify a given matrix or prove that A + Aᵀ is symmetric while A − Aᵀ is skew-symmetric.']

5. Elementary Row and Column Operations

['Elementary operations are used to simplify matrices (especially for finding inverses) and come in three types: Row operations (denoted Rᵢ ↔ Rⱼ, Rᵢ → kRᵢ, Rᵢ → Rᵢ + kRⱼ) and corresponding column operations (Cᵢ ↔ Cⱼ, Cᵢ → kCᵢ, Cᵢ → Cᵢ + kCⱼ). Any finite sequence of these is called an elementary transformation.', 'Two matrices are said to be equivalent if one can be obtained from the other by a finite number of elementary row and/or column operations. If A and B are equivalent, then rank(A) = rank(B). Elementary operations do NOT change the rank of a matrix.', 'To find the inverse using elementary operations: write A = IA (for left multiplication by rows) or A = AI (for right multiplication by columns). Apply row operations on both sides simultaneously to convert A into I; the same operations on I yield A⁻¹. That is, if R₁, R₂, …, Rₖ reduce A to I, then Rₖ…R₂R₁·A = I and Rₖ…R₂R₁ = A⁻¹, so A⁻¹ = Rₖ…R₂R₁·I.']

6. Determinant of a Square Matrix — Definition and Expansion

['For a square matrix A of order n, the determinant det(A) or |A| is a scalar value computed from the entries. For order 2: |[[a,b],[c,d]]| = ad − bc. For order 3, expand along any row or column. For a 3 × 3 matrix A = [aᵢⱼ], expanding along the i-th row: |A| = aᵢ₁Aᵢ₁ + aᵢ₂Aᵢ₂ + aᵢ₃Aᵢ₃, where Aᵢⱼ = (−1)ⁱ⁺ʲMᵢⱼ is the cofactor and Mᵢⱼ is the minor (determinant of the submatrix obtained by deleting row i and column j).', "Sarrus' Rule for 3 × 3: duplicate the first two columns to the right, sum the products of the three downward diagonals and subtract the sum of the upward diagonals. Useful for quick calculation in exams.", 'Fundamental theorem of determinants: The determinant of a matrix equals the determinant of its transpose, i.e., |Aᵀ| = |A|. Therefore, any property of determinants proved for rows is automatically valid for columns as well. This doubles the useful property set without extra proof.']

7. Properties of Determinants

['Property 1 (Row/Column interchange): Interchanging two rows (or two columns) reverses the sign of the determinant. Property 2 (Repeated row/column): If two rows or two columns are identical (or proportional), the determinant equals zero. Property 3 (Scaling a row/column): Multiplying every element of a single row or column by k multiplies the determinant by k. Property 4 (Linearity): If elements of a row are sums of two terms, the determinant splits into the sum of two determinants.', 'Property 5 (Row addition invariant): Adding a multiple of one row (or column) to another row (or column) does NOT change the value of the determinant. This is the most-used property for simplifying determinants in NDA/CDS questions. Property 6: For square matrices A and B of the same order, |AB| = |A| · |B|.', 'Property 7: If A is n × n, then |kA| = kⁿ|A|. Property 8: |adj(A)| = |A|ⁿ⁻¹ for an n × n non-singular matrix. Property 9: A · adj(A) = adj(A) · A = |A| · Iₙ.', 'These properties are indispensable. For instance, to evaluate a 3 × 3 determinant with complicated entries, first use Property 5 (row operations) to create zeros, then expand along the row/column with the most zeros.']

8. Minors, Cofactors and the Adjoint Matrix

['Minor Mᵢⱼ of element aᵢⱼ in an n × n matrix is the determinant of the (n−1) × (n−1) matrix obtained by deleting the i-th row and j-th column. Cofactor Aᵢⱼ = (−1)ⁱ⁺ʲ · Mᵢⱼ. The sign pattern for a 3 × 3 matrix is: + − + / − + − / + − + (like a chessboard).', 'Adjoint of A, denoted adj(A), is the transpose of the cofactor matrix. That is, the (i,j)-th entry of adj(A) is the cofactor Aⱼᵢ (note the swapped indices due to the transpose). For a 2 × 2 matrix [[a,b],[c,d]], adj([[a,b],[c,d]]) = [[d,−b],[−c,a]]. This simple result is worth memorising.', 'Key relationship: A · adj(A) = adj(A) · A = |A| · Iₙ. From this, if |A| ≠ 0, then A⁻¹ = adj(A)/|A|. This formula is central to NDA/CDS problems on matrix inversion and solving linear systems. Also, adj(adj(A)) = |A|ⁿ⁻² · A for n ≥ 2. For n = 2, adj(adj(A)) = A.']

9. Inverse of a Matrix

['A square matrix A is invertible (non-singular) if and only if |A| ≠ 0. When invertible, there exists a unique matrix A⁻¹ such that A · A⁻¹ = A⁻¹ · A = I. If |A| = 0, A is singular and has no inverse.', 'Formula: A⁻¹ = adj(A) / |A|. Steps to find the inverse: (1) Compute |A|. If |A| = 0, stop — no inverse exists. (2) Find all cofactors Aᵢⱼ. (3) Form the cofactor matrix and take its transpose to get adj(A). (4) Divide by |A|. Alternatively, use the elementary row operation method described in Section 5.', 'Worked example: Find the inverse of A = [[1, 2], [3, 4]]. |A| = (1)(4) − (2)(3) = −2 ≠ 0, so inverse exists. adj(A) = [[4, −2], [−3, 1]]. Therefore A⁻¹ = (1/−2) · [[4, −2], [−3, 1]] = [[−2, 1], [3/2, −1/2]]. Verification: A · A⁻¹ = [[1,2],[3,4]] · [[−2,1],[3/2,−1/2]] = [[−2+3, 1−1],[−6+6, 3−2]] = [[1,0],[0,1]] = I. ✓', 'NDA/CDS tip: If asked whether a matrix is invertible, just check the determinant. For integer-entry matrices with small entries, |A| is often easy to compute. Watch out for the sign in A⁻¹ = adj(A)/|A| — errors here are common.']

10. Rank of a Matrix and Consistency of Linear Equations

['The rank of a matrix A, denoted ρ(A), is the order of the highest-order non-zero minor, equivalently the maximum number of linearly independent rows (or columns). To find the rank: reduce the matrix to row-echelon form using elementary row operations; the rank equals the number of non-zero rows in the echelon form.', 'For a system of linear equations represented in matrix form as AX = B (where A is m × n): Let ρ(A) be the rank of the coefficient matrix, and ρ([A : B]) be the rank of the augmented matrix. The system is CONSISTENT (has at least one solution) if and only if ρ(A) = ρ([A : B]). If ρ(A) ≠ ρ([A : B]), the system is INCONSISTENT (no solution).', 'When consistent: if ρ(A) = ρ([A : B]) = n (number of unknowns), the solution is UNIQUE. If ρ(A) = ρ([A : B]) < n, there are infinitely many solutions (the system is dependent). Special case — homogeneous system AX = O is ALWAYS consistent (X = 0 is the trivial solution). It has a non-trivial solution if and only if |A| = 0 (when A is square). This fact is very frequently tested.', "Cramer's Rule (for n equations in n unknowns with |A| ≠ 0): xᵢ = |Aᵢ| / |A|, where Aᵢ is the matrix obtained by replacing the i-th column of A by the constant column B. Useful for quick answers when determinants are simple."]

11. Applications of Determinants — Area of Triangle and Geometry

['Area of a triangle with vertices (x₁, y₁), (x₂, y₂), (x₃, y₃): Area = ½ |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|. This can also be written as a determinant: Area = ½ |det([[x₁, y₁, 1], [x₂, y₂, 1], [x₃, y₃, 1]])|. NDA/CDS frequently asks for the area using the determinant form or to find an unknown coordinate given the area.', 'Collinearity condition: Three points (x₁,y₁), (x₂,y₂), (x₃,y₃) are collinear if and only if the area of the triangle they form is zero, i.e., det([[x₁, y₁, 1], [x₂, y₂, 1], [x₃, y₃, 1]]) = 0. This is one of the most commonly tested results. Worked example: Points (1,2), (3,4), (k,6) are collinear. Set up: 1(4−6) + 3(6−2) + k(2−4) = 0 → −2 + 12 − 2k = 0 → k = 5.', 'Condition for concurrency of three lines a₁x + b₁y + c₁ = 0, a₂x + b₂y + c₂ = 0, a₃x + b₃y + c₃ = 0: The lines are concurrent if and only if the determinant |[[a₁, b₁, c₁], [a₂, b₂, c₂], [a₃, b₃, c₃]]| = 0.']

12. Important Identities and Formulae for Quick Revision

['|Aᵀ| = |A|. |AB| = |A| · |B|. |kA| = kⁿ|A| for n × n matrix A. A · adj(A) = adj(A) · A = |A| · Iₙ. A⁻¹ = adj(A)/|A| (if |A| ≠ 0). |adj(A)| = |A|ⁿ⁻¹. adj(adj(A)) = |A|ⁿ⁻² · A. (A⁻¹)ᵀ = (Aᵀ)⁻¹. (AB)⁻¹ = B⁻¹ · A⁻¹. (AB)ᵀ = Bᵀ · Aᵀ. (A⁻¹)⁻¹ = A.', 'For skew-symmetric matrix of odd order: |A| = 0 (hence singular). Proof sketch: |A| = |Aᵀ| = |−A| = (−1)ⁿ|A|; for odd n, |A| = −|A| ⇒ |A| = 0. For orthogonal matrix: |A| = ±1. For singular matrix: no inverse exists.', "Common mistakes to avoid: (1) Assuming AB = BA — always verify. (2) Dividing by a matrix — matrix division is undefined; use multiplication by inverse instead. (3) Forgetting that |kA| = kⁿ|A|, not k|A|. (4) Forgetting the sign flip in (AB)⁻¹ = B⁻¹A⁻¹ and (AB)ᵀ = BᵀAᵀ. (5) Assuming AB = O implies A = O or B = O. (6) Confusing adj(A) with A⁻¹ — they differ by the factor 1/|A|. (7) Using Cramer's rule when |A| = 0 — it fails then."]

Important facts

  • A matrix has an inverse if and only if it is non-singular (determinant ≠ 0). Singular matrices have no inverse.
  • Matrix multiplication is NOT commutative: AB ≠ BA in general. But (AB)⁻¹ = B⁻¹A⁻¹ and (AB)ᵀ = BᵀAᵀ.
  • For n × n matrix A, |kA| = kⁿ|A|. For a 3×3 matrix with |A| = 5, |2A| = 40, not 10.
  • A · adj(A) = adj(A) · A = |A| · Iₙ. This is the key identity connecting a matrix, its adjoint, and its determinant.
  • |adj(A)| = |A|ⁿ⁻¹. For a 3×3 matrix, |adj(A)| = |A|².
  • Any real skew-symmetric matrix of odd order is always singular (determinant = 0).
  • Three points are collinear iff the determinant of their coordinates with a column of 1s equals zero.
  • For homogeneous system AX = O with A square: non-trivial solutions exist iff |A| = 0.
  • The system AX = B is consistent iff ρ(A) = ρ([A:B]). Unique solution if ρ(A) = n; infinite solutions if ρ(A) < n.
  • For orthogonal matrix A: Aᵀ = A⁻¹, hence |A| = ±1. For unitary matrix: A* = A⁻¹.

Formulas and relationships

Determinant of 2×2: |[[a,b],[c,d]]| = ad − bc
3×3 determinant expansion along row i: |A| = aᵢ₁Aᵢ₁ + aᵢ₂Aᵢ₂ + aᵢ₃Aᵢ₃ where Aᵢⱼ = (−1)ⁱ⁺ʲMᵢⱼ
Matrix inverse: A⁻¹ = adj(A) / |A| (valid only when |A| ≠ 0)
Adjoint relation: A · adj(A) = adj(A) · A = |A| · Iₙ
Determinant of scalar multiple: |kA| = kⁿ|A| for n×n matrix A
Determinant of adjoint: |adj(A)| = |A|ⁿ⁻¹
Inverse of product: (AB)⁻¹ = B⁻¹ · A⁻¹
Transpose of product: (AB)ᵀ = Bᵀ · Aᵀ
Double adjoint: adj(adj(A)) = |A|ⁿ⁻² · A for n ≥ 2
Area of triangle: ½|x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)| = ½|det([[x₁,y₁,1],[x₂,y₂,1],[x₃,y₃,1]])|
Cramer's rule: xᵢ = |Aᵢ| / |A| where Aᵢ replaces column i of A with the constant column
Collinearity condition: det([[x₁,y₁,1],[x₂,y₂,1],[x₃,y₃,1]]) = 0
Concurrency of three lines: det([[a₁,b₁,c₁],[a₂,b₂,c₂],[a₃,b₃,c₃]]) = 0

Common mistakes

  • Assuming AB = BA for all matrices. In reality, matrix multiplication is non-commutative; only special pairs (like powers of the same matrix, or diagonal matrices) commute.
  • Writing |kA| = k|A|. The correct formula is |kA| = kⁿ|A| where n is the order of the square matrix. Forgetting the exponent n is extremely common.
  • Believing AB = O implies A = O or B = O. Two non-zero singular matrices can multiply to give the zero matrix.
  • Confusing adj(A) with A⁻¹. They are related by A⁻¹ = adj(A)/|A|; they are equal only when |A| = 1.
  • Reversing the order in (AB)⁻¹ = A⁻¹B⁻¹. The correct formula is (AB)⁻¹ = B⁻¹A⁻¹. Same for transpose: (AB)ᵀ = BᵀAᵀ.
  • Applying Cramer's rule when |A| = 0. Cramer's rule requires a unique solution (|A| ≠ 0); when the determinant is zero, the system is either inconsistent or has infinitely many solutions.
  • Forgetting that a skew-symmetric matrix of odd order is always singular. Its determinant is necessarily zero, so it has no inverse.
  • In the row-reduction method for finding A⁻¹, applying operations only to A and not to the identity matrix on the other side. Both sides must undergo the same operations simultaneously.
  • Sign errors in cofactor expansion: Aᵢⱼ = (−1)ⁱ⁺ʲMᵢⱼ. Missing the alternating sign pattern leads to incorrect determinants.
  • Assuming that every square matrix is invertible. Only non-singular matrices (|A| ≠ 0) have inverses; singular matrices do not.
