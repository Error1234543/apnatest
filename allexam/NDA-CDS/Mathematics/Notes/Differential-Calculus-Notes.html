1. Limits: Concept, Types and Standard Limits

A limit describes the behaviour of a function f(x) as x approaches a certain value a. Formally, lim_{x→a} f(x) = L means that as x gets arbitrarily close to a (from either side), f(x) gets arbitrarily close to L. The limit may exist even if f(a) is undefined.

Standard one-sided limits that must be memorised for NDA/CDS:
• lim_{x→0} sin x / x = 1
• lim_{x→0} (1 − cos x) / x² = 1/2
• lim_{x→0} tan x / x = 1
• lim_{x→0} (e^x − 1)/x = 1
• lim_{x→0} log_e(1 + x)/x = 1
• lim_{x→∞} (1 + 1/x)^x = e
• lim_{x→0} (a^x − 1)/x = log_e a (for a > 0)

Indeterminate forms arise when direct substitution yields expressions such as 0/0, ∞/∞, 0·∞, ∞−∞, 0⁰, 1^∞, ∞⁰. These require special treatment using algebraic simplification, series expansion, or L'Hospital's Rule (see Section 2).

Key facts tested in NDA/CDS:
• If lim_{x→a⁻} f(x) ≠ lim_{x→a⁺} f(x), the two-sided limit does not exist.
• A limit describes trend, not value at the point: f(a) may differ from the limit.
• For polynomial P(x), lim_{x→a} P(x) = P(a). This is immediate substitution.
• lim_{x→∞} (ax^n + bx^{n-1}+…)/(cx^m + …) = a/c if n=m, 0 if n<m, ∞ (or undefined sign) if n>m.

2. Continuity and Discontinuity

A function f(x) is continuous at x = a if three conditions hold simultaneously:
(1) f(a) is defined;
(2) lim_{x→a} f(x) exists (i.e., left-hand limit = right-hand limit);
(3) lim_{x→a} f(x) = f(a).

Types of discontinuity at x = a:
• Removable discontinuity: limit exists but ≠ f(a) or f(a) undefined. Can be repaired by redefining f(a).
• Jump discontinuity: left-hand limit ≠ right-hand limit (finite). Example: step functions.
• Infinite discontinuity: at least one one-sided limit is ±∞. Common with vertical asymptotes (e.g., 1/(x−a)).
• Oscillatory discontinuity: function oscillates without settling. Example: sin(1/x) at x = 0.

Important theorems:
• Every polynomial is continuous everywhere on R.
• Every rational function P(x)/Q(x) is continuous wherever Q(x) ≠ 0.
• Composite of continuous functions is continuous (where defined).

NDA/CDS high-yield tip: Questions often ask the value of k that makes a piecewise function continuous at a point. Set lim_{x→a⁻} f(x) = lim_{x→a⁺} f(x) = f(a) and solve for k.

Common mistake: assuming continuity implies differentiability. A function can be continuous but NOT differentiable (e.g., |x| at x = 0 — the graph has a sharp corner).

3. Differentiability and Its Relation to Continuity

The derivative of f at x = a is defined as:
f'(a) = lim_{h→0} [f(a+h) − f(a)] / h, provided the limit exists.

If the limit exists, f is said to be differentiable at x = a. Differentiability at a point implies continuity at that point, but the converse is FALSE.

Geometric meaning: f'(a) equals the slope of the tangent to the curve y = f(x) at x = a.

Points where differentiability fails even though the function may be continuous:
• Sharp corners / cusps: |x − a| is continuous at a but not differentiable there.
• Vertical tangent: f(x) = x^(1/3) at x = 0 — the slope becomes infinite.
• Discontinuities: any discontinuous point is automatically non-differentiable.

Quick check for differentiability of |g(x)| at g(a) = 0: f is differentiable there only if g'(a) = 0 as well (the graph is smooth through the root).

NDA/CDS frequently tests: "If f is differentiable at x = a, then which of the following must be true?" Correct answer: f is continuous at a. Incorrect options often reverse the implication.

4. Rules of Differentiation

Let u and v be functions of x, and c be a constant. The fundamental rules are:

[Power Rule]
d/dx (x^n) = n · x^(n−1)
Applies for any real n (including fractions and negatives).

[Sum / Difference Rule]
d/dx [u ± v] = du/dx ± dv/dx

[Constant Multiple Rule]
d/dx [c·u] = c · du/dx

[Product Rule]
d/dx (u·v) = u·dv/dx + v·du/dx
Use whenever two or more functions are multiplied together.

[Quotient Rule]
d/dx (u/v) = [v·du/dx − u·dv/dx] / v²
Mnemonic: "Low d-High minus High d-Low, over Low squared."

[Chain Rule] — THE MOST IMPORTANT RULE:
d/dx [f(g(x))] = f'(g(x)) · g'(x)
Or in Leibniz notation: dy/dx = (dy/du) · (du/dx)
Apply the chain rule EVERY time you see a function inside another function (composition). Common compositions tested:
sin(x²), e^(3x), log(sin x), (2x+1)⁵, √(1+x³)

Worked example (chain rule):
Find dy/dx if y = sin(x² + 3x).
Outer function: sin(u), inner function: u = x² + 3x.
dy/dx = cos(x² + 3x) · (2x + 3).

Worked example (product + chain):
Find dy/dx if y = x² · e^(3x).
dy/dx = x² · 3e^(3x) + e^(3x) · 2x = e^(3x)(3x² + 2x).

5. Derivatives of Standard Functions

The following derivatives must be known by heart for NDA/CDS:

[Trigonometric]
d/dx (sin x) = cos x
d/dx (cos x) = −sin x
d/dx (tan x) = sec²x
d/dx (cot x) = −cosec²x
d/dx (sec x) = sec x · tan x
d/dx (cosec x) = −cosec x · cot x

[Inverse Trigonometric]
d/dx (sin⁻¹x) = 1/√(1−x²), |x| < 1
d/dx (cos⁻¹x) = −1/√(1−x²), |x| < 1
d/dx (tan⁻¹x) = 1/(1+x²)
d/dx (cot⁻¹x) = −1/(1+x²)
d/dx (sec⁻¹x) = 1/(|x|√(x²−1)), |x| > 1
d/dx (cosec⁻¹x) = −1/(|x|√(x²−1)), |x| > 1

[Exponential and Logarithmic]
d/dx (e^x) = e^x
d/dx (a^x) = a^x · log_e a
d/dx (log_e x) = 1/x
d/dx (log_a x) = 1/(x · log_e a)
d/dx (ln x) = 1/x

Key observations:
• The derivatives of cos⁻¹x and sin⁻¹x sum to zero (since sin⁻¹x + cos⁻¹x = π/2).
• tan⁻¹x and cot⁻¹x also sum to π/2; their derivatives have opposite signs.
• Remember to apply the chain rule when the argument is not simply x, e.g. d/dx[sin⁻¹(2x)] = 2/√(1−4x²).
• d/dx[e^{f(x)}] = e^{f(x)} · f'(x). This appears frequently in NDA questions.

6. Implicit, Parametric and Logarithmic Differentiation

[Implicit Differentiation]
Used when y cannot be isolated easily from an equation like x² + y² = r² or xy + sin y = x.
Method: differentiate both sides w.r.t. x, treating y as a function of x (apply chain rule to every y term, yielding dy/dx). Then solve for dy/dx.
Example: x² + y² = 25 → 2x + 2y(dy/dx) = 0 → dy/dx = −x/y.

[Parametric Differentiation]
When x = f(t) and y = g(t), find dy/dx using:
dy/dx = (dy/dt) / (dx/dt), provided dx/dt ≠ 0.
Higher derivatives follow similarly: d²y/dx² = d/dt(dy/dx) / (dx/dt).
Example: x = a cos t, y = a sin t → dy/dx = (a cos t)/(−a sin t) = −cot t.

[Logarithmic Differentiation]
Useful for functions of the form y = [f(x)]^{g(x)} (variable base AND variable exponent).
Take ln of both sides: ln y = g(x) · ln f(x), then differentiate implicitly.
Example: y = x^x → ln y = x ln x → (1/y)·dy/dx = ln x + 1 → dy/dx = x^x (ln x + 1).
General formula: if y = u^v where u, v depend on x, then
dy/dx = y [v/u · du/dx + ln u · dv/dx].

NDA/CDS tip: Implicit differentiation questions often combine with finding the equation of tangent. Always simplify dy/dx fully before substituting the point.

7. Successive Differentiation and Second Derivative Tests

If y = f(x), then:
First derivative: dy/dx = f'(x)
Second derivative: d²y/dx² = f''(x) = d/dx[f'(x)]
Third derivative: d³y/dx³ = f'''(x)
In general, the nth derivative is denoted dⁿy/dxⁿ or f⁽ⁿ⁾(x).

Common second derivatives tested:
• y = sin ax → d²y/dx² = −a² sin ax
• y = cos ax → d²y/dx² = −a² cos ax
• y = e^{ax} → d²y/dx² = a² e^{ax}
• y = x^n → d²y/dx² = n(n−1)x^{n−2}

Second Derivative Test (for maxima/minima — covered in detail in Section 9):
At a critical point where f'(c) = 0:
• If f''(c) < 0 → local maximum
• If f''(c) > 0 → local minimum
• If f''(c) = 0 → test inconclusive; use first derivative test or higher-order derivative test.

Leibniz's Theorem (nth derivative of product):
If y = u·v, then the nth derivative is given by a binomial-type expansion:
y⁽ⁿ⁾ = Σ_{k=0}^{n} C(n,k) · u⁽ⁿ⁻ᵏ⁾ · v⁽ᵏ⁾
This is occasionally asked in CDS. Remember: u⁽ᵐ⁾ denotes the mth derivative of u.

Pattern recognition for repeated differentiation:
• sin(ax) cycles: sin → a·cos → −a²·sin → −a³·cos → a⁴·sin …
• e^{ax}·P(x): each differentiation brings down another factor of a via product rule; look for a pattern.

8. Mean Value Theorems (Rolle's and Lagrange's)

[Rolle's Theorem]
Statement: If f is (i) continuous on [a,b], (ii) differentiable on (a,b), and (iii) f(a) = f(b), then there exists at least one c ∈ (a,b) such that f'(c) = 0.

Geometric interpretation: between two points at the same height on a smooth curve, there is at least one horizontal tangent.

Verification steps (NDA/CDS style question):
1. Check continuity on [a,b] — usually true for polynomials, trig, exp.
2. Check differentiability on (a,b) — same, except watch for absolute values or fractional powers.
3. Check f(a) = f(b).
4. Solve f'(c) = 0 for c and verify a < c < b.

Example: f(x) = x² − 4x + 3 on [1,3]. f(1)=0, f(3)=0. f'(x)=2x−4=0 → x=2. Since 1<2<3, Rolle's theorem holds with c = 2.

[Lagrange's Mean Value Theorem — MVT]
Statement: If f is continuous on [a,b] and differentiable on (a,b), then there exists c ∈ (a,b) such that:
f'(c) = [f(b) − f(a)] / (b − a)

Geometric interpretation: there is a point where the tangent is parallel to the chord joining (a,f(a)) and (b,f(b)).

Note: Rolle's theorem is a special case of Lagrange's MVT (when f(a)=f(b), the RHS becomes 0).

NDA/CDS often asks to find the value of c. The procedure: compute [f(b)−f(a)]/(b−a), set equal to f'(c), solve for c, and check it lies strictly between a and b.

9. Applications — Tangents, Normals, Maxima and Minima

[Equation of Tangent and Normal at a Point]
Given y = f(x) and a point (x₁, y₁) on the curve:
• Slope of tangent: m = f'(x₁)
• Equation of tangent: y − y₁ = f'(x₁)(x − x₁)
• Slope of normal: m_normal = −1/f'(x₁) (negative reciprocal, provided f'(x₁) ≠ 0)
• Equation of normal: y − y₁ = [−1/f'(x₁)](x − x₁)
Special cases:
– Horizontal tangent: f'(x₁) = 0.
– Vertical tangent: f'(x₁) → ∞ (derivative undefined, e.g., at a cusp or via dy/dx approach).

[Maxima and Minima — First Derivative Test]
Critical points: solutions of f'(x) = 0 or points where f'(x) does not exist.
• If f' changes from + to − at x = c → local maximum.
• If f' changes from − to + at x = c → local minimum.
• If f' does not change sign → neither (point of inflection possibly).

[Maxima and Minima — Second Derivative Test]
At f'(c) = 0:
• f''(c) < 0 → local maximum (curve concave down).
• f''(c) > 0 → local minimum (curve concave up).
• f''(c) = 0 → inconclusive; revert to first derivative test.

Absolute (global) extrema on [a,b]: compare all local extrema inside (a,b) with f(a) and f(b).

NDA/CDS frequently tests: find the tangent at a given point, or find k such that a line is tangent to a curve. In the latter case, equate the line's slope to f'(x) and the line's equation to the tangent formula simultaneously.

10. Rates of Change, Approximations and Differentials

[Rate of Change]
The derivative dy/dx gives the instantaneous rate of change of y with respect to x. If y = f(x,t) depends on two variables, partial derivatives ∂y/∂x and ∂y/∂t are used (occasionally in CDS).

Related rates problems (word problems): express all quantities as functions of a common variable (usually time t), differentiate implicitly, and substitute known values. Example: water filling a cone — relate volume V to height h, then dV/dt = (dV/dh)(dh/dt).

[Linear Approximation / Differentials]
For a small change Δx ≈ dx:
Δy ≈ dy = f'(x) · dx
This gives the approximate change in y.

Approximation formula:
f(x + dx) ≈ f(x) + f'(x)·dx
Common numerical approximations asked in NDA:
• √(a² + ε) ≈ a + ε/(2a) for small ε.
• (1 + x)^n ≈ 1 + nx for small x (binomial approximation).
• sin x ≈ x, tan x ≈ x, log(1+x) ≈ x near x = 0.

Error propagation (conceptual): if y = f(x) and x has an error δx, then the error in y is approximately δy = f'(x)·δx.

Percentage error: (δy/y) × 100% ≈ [f'(x)·δx / f(x)] × 100%.

NDA/CDS tip: Approximation questions give a nearby perfect-square or cube root and ask for the value using differentials. Identify x₀ (perfect root) and dx (small difference), compute f'(x₀), then apply the formula.

11. Curve Tracing Essentials and Important Results

Curve tracing for NDA/CDS focuses on identifying key features rather than drawing from scratch. For a function y = f(x), determine:

[Domain and Range]
Identify where f(x) is defined. For rational functions, exclude zeros of the denominator. For even roots, ensure the radicand ≥ 0.

[Intercepts]
• x-intercepts: solve f(x) = 0.
• y-intercept: evaluate f(0).

[Symmetry]
• Even function: f(−x) = f(x) → symmetric about y-axis.
• Odd function: f(−x) = −f(x) → symmetric about origin.

[Asymptotes]
• Vertical asymptote: x = a where f(x) → ±∞ as x → a (denominator = 0).
• Horizontal asymptote: lim_{x→±∞} f(x) = L → y = L.
• Slant asymptote: occurs when degree of numerator = degree of denominator + 1.

[Increasing / Decreasing Intervals]
Solve f'(x) > 0 (increasing) and f'(x) < 0 (decreasing).

[Concavity and Points of Inflection]
f''(x) > 0 → concave up (holds water). f''(x) < 0 → concave down (spills water). A point of inflection occurs where concavity changes, i.e., f''(x) = 0 and changes sign.

Standard curves to recognise:
• y = x³: inflection at origin, no extrema.
• y = x⁴: minimum at origin (flatter than x²).
• y = 1/x: hyperbola, asymptotes at x = 0 and y = 0.
• y = e^{−x²}: bell-shaped, max at origin.

12. L'Hospital's Rule and Advanced Limit Techniques

[L'Hospital's Rule]
Applies ONLY to indeterminate forms 0/0 or ∞/∞.
If lim_{x→a} f(x) = 0 and lim_{x→a} g(x) = 0 (or both ±∞), then:
lim_{x→a} f(x)/g(x) = lim_{x→a} f'(x)/g'(x), provided the RHS limit exists.

Important cautions:
• Do NOT apply L'Hospital's Rule to forms like 1/0, 0/1, or 0·∞ directly. Rewrite into 0/0 or ∞/∞ first.
• May need to apply the rule repeatedly if the new limit is still indeterminate.
• For forms 0⁰, 1^∞, ∞⁰, take natural log first to convert to 0·∞, then to 0/0 or ∞/∞.

Worked example: lim_{x→0} (e^x − 1 − x)/x²
Direct substitution → 0/0. Apply L'Hospital once: lim (e^x − 1)/(2x) → still 0/0.
Apply again: lim e^x/2 = 1/2.

Worked example (1^∞ form): lim_{x→∞} (1 + 2/x)^x
Let y = (1 + 2/x)^x → ln y = x·ln(1 + 2/x).
As x→∞, ln(1+2/x) ~ 2/x, so x·ln(1+2/x) → 2. Hence y → e².

[Series expansion method]
For some limits, Taylor/Maclaurin series give faster results:
sin x = x − x³/3! + x⁵/5! − …
cos x = 1 − x²/2! + x⁴/4! − …
e^x = 1 + x + x²/2! + x³/3! + …
log(1+x) = x − x²/2 + x³/3 − … (|x| < 1)
Near x = 0, keep only the leading non-zero term to find the limit ratio.

Important facts

  • Differentiability at a point implies continuity there, but continuity does not imply differentiability (counterexample: |x| at x = 0).
  • L'Hospital's Rule applies exclusively to 0/0 and ∞/∞ forms. All other indeterminate forms (0·∞, ∞−∞, 0⁰, 1^∞, ∞⁰) must be transformed first.
  • The product rule d(uv)/dx = u·dv/dx + v·du/dx is frequently confused with (du/dx)·(dv/dx); remember the sum, not the product of derivatives.
  • Chain rule misapplication is the most common calculation error: always identify outer and inner functions clearly and multiply by the derivative of the inner function.
  • Rolle's Theorem requires f(a) = f(b); without this condition, only Lagrange's MVT applies.
  • For inverse trigonometric derivatives, always check the domain restriction (e.g., |x| < 1 for sin⁻¹x and cos⁻¹x).
  • The second derivative test is inconclusive when f''(c) = 0; fall back to the first derivative test.
  • Standard limit lim_{x→0} (1−cos x)/x² = 1/2 is frequently confused with lim_{x→0} (1−cos x)/x = 0; the former requires the x² denominator.
  • At a point of inflection, f''(x) = 0 AND changes sign; merely having f''(x) = 0 is insufficient.
  • For parametric differentiation, dx/dt must be non-zero at the point of evaluation; otherwise dy/dx is undefined.

Formulas and relationships

f'(a) = lim_{h→0} [f(a+h) − f(a)] / h — Definition of derivative
d/dx(x^n) = n·x^{n−1} — Power rule
d/dx(uv) = u·dv/dx + v·du/dx — Product rule
d/dx(u/v) = [v·du/dx − u·dv/dx] / v² — Quotient rule
d/dx[f(g(x))] = f'(g(x))·g'(x) — Chain rule
d/dx(sinkx) = k·cos(kx); d/dx(cos kx) = −k·sin(kx); d/dx(tan kx) = k·sec²(kx)
d/dx(e^{kx}) = k·e^{kx}; d/dx(a^{kx}) = k·a^{kx}·log_e a
d/dx(ln kx) = 1/x; d/dx(log_a kx) = 1/(x·log_e a)
d/dx(sin⁻¹x) = 1/√(1−x²); d/dx(cos⁻¹x) = −1/√(1−x²); d/dx(tan⁻¹x) = 1/(1+x²)
dy/dx = (dy/dt)/(dx/dt) — Parametric differentiation
Rolle's Theorem: if f continuous on [a,b], diff on (a,b), and f(a)=f(b), then ∃c∈(a,b) with f'(c)=0
Lagrange's MVT: ∃c∈(a,b) with f'(c) = [f(b)−f(a)]/(b−a)
Tangent: y − y₁ = f'(x₁)(x − x₁); Normal: y − y₁ = [−1/f'(x₁)](x − x₁)
Linear approximation: f(x+dx) ≈ f(x) + f'(x)·dx
L'Hospital's Rule: lim f/g = lim f'/g' (for 0/0 or ∞/∞ forms)
dⁿ(uv)/dxⁿ = Σ C(n,k)·u^{(n−k)}·v^{(k)} — Leibniz's theorem

Common mistakes

  • Confusing the quotient rule with the product rule; the quotient rule has a subtraction in the numerator and v² in the denominator, unlike the product rule.
  • Forgetting the chain rule multiplier when differentiating composite functions like sin(3x), e^{x²}, or log(x³+1).
  • Applying L'Hospital's Rule to non-indeterminate forms (e.g., 1/0 or 2/3), which gives wrong answers.
  • Writing d/dx[sin⁻¹x] = 1/√(1−x²) without noting the restriction |x| < 1; the formula fails at the endpoints.
  • Assuming f'(c) = 0 guarantees a maximum or minimum; it could be a point of inflection (e.g., y = x³ at x = 0).
  • In parametric differentiation, computing dy/dx = dy/dt · dx/dt instead of dividing; the correct operation is division, not multiplication.
  • Using the second derivative test without first confirming f'(c) = 0; the test is invalid at non-critical points.
  • Treating ln(x²) as 2·ln x without the absolute value; the correct identity is ln(x²) = 2·ln|x|.
  • Mixing up degrees and radians when differentiating trigonometric functions; the standard derivatives assume radian measure.
  • In curve tracing, forgetting to check behavior at boundaries and infinity before declaring extrema as absolute.
