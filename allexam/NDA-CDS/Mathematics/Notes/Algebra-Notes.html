1. Sets, Relations and Functions

A set is a well-defined collection of distinct objects, called elements. Sets are typically denoted by capital letters and their elements by small letters; x ∈ A means x is an element of A.

Major types of sets:
• Empty/Null set: ∅ = { }, cardinality n(∅) = 0.
• Finite set: has a definite number of elements.
• Infinite set: has uncountable or countably infinite elements, e.g., ℕ.
• Singleton set: contains exactly one element.
• Universal set U: contains all objects under consideration.
• Equal sets: same elements regardless of order.

Standard number systems:
• ℕ = {1, 2, 3, …}
• W = {0, 1, 2, 3, …}
• ℤ = {…, −2, −1, 0, 1, 2, …}
• ℚ = {p/q : p, q ∈ ℤ, q ≠ 0}
• ℝ = ℚ ∪ irrational numbers

Key set operations and identities (Venn diagram backed):
• Union: A ∪ B = {x : x ∈ A or x ∈ B}
• Intersection: A ∩ B = {x : x ∈ A and x ∈ B}
• Complement: A' = {x ∈ U : x ∉ A}
• Difference: A − B = A ∩ B'

Fundamental identities:
• (A ∪ B)' = A' ∩ B' (De Morgan’s Law)
• (A ∩ B)' = A' ∪ B' (De Morgan’s Law)
• A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
• A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
• A − B = A − (A ∩ B)
• A ∪ B = A ∪ (B − A), A ∩ B ⊆ A

Cardinality formulas (crucial for NDA/CDS):
• n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
• n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A ∩ B) − n(B ∩ C) − n(C ∩ A) + n(A ∩ B ∩ C)
• n(A − B) = n(A) − n(A ∩ B)
• Minimum possible n(A ∪ B) = max(n(A), n(B))
• Maximum possible n(A ∪ B) = min(n(U), n(A) + n(B))

Relation R from A to B is a subset of A × B. Domain = first components of ordered pairs; Range = second components.

Types of relations on a set A:
• Reflexive: (a, a) ∈ R ∀a ∈ A
• Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R
• Transitive: (a, b) ∈ R and (b, c) ∈ R ⇒ (a, c) ∈ R
• Equivalence relation: reflexive + symmetric + transitive
• Partial order: reflexive + antisymmetric + transitive

Function f : A → B assigns each element of A exactly one element of B.
• One-one (injective): f(x₁) = f(x₂) ⇒ x₁ = x₂
• Onto (surjective): Range = Codomain
• Bijective: both one-one and onto; inverse f⁻¹ exists.

Composition: (f ∘ g)(x) = f(g(x)); note that f ∘ g ≠ g ∘ g in general. If f : A → B and g : B → A are bijections, then (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹.

2. Real Numbers and the Number System

Every real number is either rational or irrational.

Rational numbers: expressible as p/q, q ≠ 0, p, q ∈ ℤ. Their decimal expansions are either terminating or non-terminating recurring. Rational numbers are closed under +, −, × but not under division by zero.

Irrational numbers: non-terminating, non-recurring decimals. Examples: √2, √3, π, e.

Important properties for NDA/CDS calculations:
• Product of a rational and an irrational (non-zero rational) is always irrational.
• Sum/difference of two irrationals may be rational (e.g., √2 + (−√2) = 0) or irrational (e.g., √2 + √3).
• Any point on the number line represents a unique real number; between any two distinct reals there exist infinitely many rationals and irrationals.

Euclid's Division Lemma: For positive integers a and b, there exist unique integers q and r such that a = bq + r, where 0 ≤ r < b. This is the basis for finding HCF.

HCF and LCM relationship (for two numbers only):
HCF(a, b) × LCM(a, b) = a × b
Note: This product relation does NOT generalize directly to three or more numbers.

Polynomial division algorithm: For polynomials p(x) and g(x) ≠ 0, there exist unique q(x) and r(x) such that p(x) = g(x)·q(x) + r(x), where r(x) = 0 or deg r(x) < deg g(x).

If α, β, γ are roots of a cubic equation ax³ + bx² + cx + d = 0, then:
• α + β + γ = −b/a
• αβ + βγ + γα = c/a
• αβγ = −d/a
This is the foundation of the theory of equations tested in NDA/CDS.

3. Quadratic Equations

A quadratic equation is an equation of the form ax² + bx + c = 0, where a, b, c ∈ ℝ and a ≠ 0.

Solutions via the quadratic formula (Sridharacharya):
x = [−b ± √(b² − 4ac)] / 2a

Discriminant D = b² − 4ac governs the nature of roots:
• D > 0, perfect square, rational coefficients: two distinct real rational roots.
• D > 0, not perfect square: two distinct real irrational roots.
• D = 0: two equal real roots (x = −b/2a); graph touches the x-axis at one point.
• D < 0: two complex conjugate roots [−b ± i√|D|]/2a; graph does not intersect x-axis.
• If one root is α + iβ, the other root must be α − iβ (conjugate pair theorem for real-coefficient quadratics).

Sum and product of roots (Vieta's formulas):
Let α, β be roots. Then:
• S = α + β = −b/a
• P = αβ = c/a
The quadratic equation can be written directly as:
x² − Sx + P = 0

Conditions for common scenarios:
• Both roots positive: D ≥ 0, S > 0, P > 0 (i.e., −b/a > 0 and c/a > 0)
• Both roots negative: D ≥ 0, S < 0, P > 0 (i.e., −b/a < 0 and c/a > 0)
• Roots of opposite sign: P < 0 (c/a < 0)
• One root zero: c = 0; both roots zero: b = c = 0
• Roots reciprocals of each other: a = c
• Roots reciprocals of equation px² + qx + r = 0: rx² + qx + p = 0
• Common root between ax² + bx + c = 0 and a'x² + b'x + c' = 0: (b² − 4ac)(b'² − 4a'c') = (ab' − a'b)²; the common root is (bc' − b'c)/(ac' − a'c)

Quadratic inequality ax² + bx + c > 0:
• If a > 0 and D < 0: true for all x ∈ ℝ
• If a > 0 and D > 0 with roots α < β: solution is x ∈ (−∞, α) ∪ (β, ∞) for > 0; x ∈ (α, β) for < 0
Always ensure the coefficient of x² is positive before writing the interval; flip the inequality if a < 0.

Expression value at a point: If f(x) = ax² + bx + c and α is a root, then f(α) = 0.

4. Progressions: AP, GP, HP and Their Means

Arithmetic Progression (AP): Each term differs from the preceding term by a fixed constant d (common difference).
nth term: aₙ = a + (n − 1)d = l (where l is last term)
Sum of n terms:
Sₙ = n/2 [2a + (n−1)d] = n/2 (first + last)
If terms are in AP, they can be taken symmetrically: for 3 terms use a−d, a, a+d; for 4 terms use a−3d, a−d, a+d, a+3d.

Geometric Progression (GP): Each term is obtained by multiplying the previous term by a fixed constant r (common ratio).
nth term: aₙ = arⁿ⁻¹
Sum of n terms:
• If r ≠ 1: Sₙ = a(rⁿ − 1)/(r − 1) for r > 1; Sₙ = a(1 − rⁿ)/(1 − r) for |r| < 1
• Sₙ = a(1 − rⁿ)/(1 − r)
Infinite GP (|r| < 1): S∞ = a/(1 − r)
For 3 terms in GP: a/r, a, ar; for 4 terms: a/r³, a/r, ar, ar³.

Harmonic Progression (HP): Reciprocals form an AP.
nth term: aₙ = 1/[a + (n − 1)d], where a is first reciprocal term.
No simple closed-form sum formula for finite HP; convert to AP of reciprocals.

Means between two numbers a and b:
• Arithmetic mean: A = (a + b)/2; if a, A, b are in AP
• Geometric mean: G = √(ab) (valid when ab > 0); if a, G, b are in GP
• Harmonic mean: H = 2ab/(a + b); if a, H, b are in HP
Key identity (for two positive numbers): G² = AH and A ≥ G ≥ H.

Relationship: A − G ≥ G − H and A − H = 2(G − H).

Practical shortcut: If sum of a finite GP with integer terms is given and one must find the number of terms, recall sums like 1 + 2 + 4 + 8 + … + 2ⁿ⁻¹ = 2ⁿ − 1.

5. Permutations and Combinations

Fundamental counting principles:
• Multiplication principle: If task A can be done in m ways and task B in n ways, both together can be done in m × n ways.
• Addition principle: If task A can be done in m ways and task B in n ways, either can be done in m + n ways (mutually exclusive tasks).

Factorial: n! = n × (n−1) × … × 2 × 1; 0! = 1.

Permutation (ordered selection): P(n, r) = n!/(n − r)!
• Arrangements of r objects chosen from n distinct objects.
• Special case: circular arrangement of n distinct objects = (n − 1)!
• Circular arrangement with clockwise/anticlockwise indistinguishable = (n − 1)!/2
• Arrangements of n objects where p are alike of one kind, q of another, r of third = n!/(p! · q! · r!)

Combination (unordered selection): C(n, r) = n!/[r!(n − r)!] = ⁿCᵣ
• Selection of r objects from n distinct objects.
• Key identities:
– ⁿCᵣ = ⁿC₍ₙ₋ᵣ₎ (symmetry)
– ⁿCᵣ₋₁ + ⁿCᵣ = ⁿ⁺¹Cᵣ (Pascal's rule)
– r · ⁿCᵣ = n · ⁿ⁻¹Cᵣ₋₁
– ⁿC₀ + ⁿC₁ + … + ⁿCₙ = 2ⁿ
– ⁿC₀ − ⁿC₁ + … + (−1)ⁿ ⁿCₙ = 0
– Sum of odd binomial coeffs = Sum of even binomial coeffs = 2ⁿ⁻¹

Common counting patterns for NDA/CDS:
• Grouping: Dividing mn things into m equal groups of n each: (mn)!/(n!)ᵐ · m!
• Selection: Selecting at least one from n distinct objects = 2ⁿ − 1
• Selection with identical items: If there are p alike of one kind, q alike of another, r alike of third, total selections = (p+1)(q+1)(r+1) − 1
• With repetition allowed, ordered selection of r things from n = nʳ
• With repetition allowed, unordered selection of r things from n = C(n + r − 1, r)

6. Binomial Theorem

For any positive integer n and real numbers x, y:
(x + y)ⁿ = Σᵣ₌₀ⁿ ⁿCᵣ · xⁿ⁻ʳ · yʳ

General term (R+1)th term: Tᵣ₊₁ = ⁿCᵣ · xⁿ⁻ʳ · yʳ

Key properties:
• Total number of terms = n + 1
• Sum of exponents of x and y in each term = n
• Coefficients follow symmetry: ⁿC₀, ⁿC₁, …, ⁿCₙ are palindromic
• Sum of all binomial coefficients = 2ⁿ
• Sum of odd-positioned coefficients = Sum of even-positioned coefficients = 2ⁿ⁻¹

Middle term(s):
• If n is even: middle term is T₍ₙ/₂₎₊₁ with r = n/2
• If n is odd: two middle terms are T₍ₙ₊₁₎/₂ and T₍ₙ₊₃₎/₂ with r = (n−1)/2 and r = (n+1)/2

Binomial coefficients as function of r increase up to the middle then decrease.
Maximum coefficient:
• n even: maximum is ⁿCₙ/₂ (single)
• n odd: two maxima are ⁿC₍ₙ₋₁₎/₂ and ⁿC₍ₙ₊₁₎/₂ (equal)

Important derived results:
• (1 + x)ⁿ = 1 + ⁿC₁x + ⁿC₂x² + … + ⁿCₙxⁿ, valid for all x when n is a positive integer
• (1 − x)ⁿ = 1 − ⁿC₁x + ⁿC₂x² − … + (−1)ⁿ ⁿCₙxⁿ
• (1 + x)ⁿ + (1 − x)ⁿ = 2[ⁿC₀ + ⁿC₂x² + ⁿC₄x⁴ + …]
• (1 + x)ⁿ − (1 − x)ⁿ = 2[ⁿC₁x + ⁿC₃x³ + …]

For finding a specific coefficient: rewrite the expression to match the standard binomial form, identify the power needed, and use the general term formula.

7. Logarithms

If aˣ = N, then x = logₐN, read as 'logarithm of N to the base a'. Here a > 0, a ≠ 1, and N > 0.

Fundamental laws (NDA/CDS high-yield):
• logₐ(MN) = logₐM + logₐN
• logₐ(M/N) = logₐM − logₐN
• logₐ(Mᵖ) = p · logₐM
• logₐa = 1; logₐ1 = 0
• a^(logₐN) = N

Change of base formula:
logₐN = log_bN / log_ba = 1 / log_N a
Commonly used bases: 10 (common log, log), e (natural log, ln), 2 (binary log, lg)

Reciprocal property: logₐb · log_ba = 1
Cyclic property: logₐb · log_b c · log_c a = 1

Numerical constants frequently needed:
• log₁₀2 ≈ 0.3010
• log₁₀3 ≈ 0.4771
• log₁₀5 ≈ 0.6990 (since log 5 = 1 − log 2)
• log₁₀7 ≈ 0.8451

Logarithmic inequalities: If logₐf(x) > logₐg(x):
• For a > 1: f(x) > g(x) (inequality direction unchanged)
• For 0 < a < 1: f(x) < g(x) (inequality reverses)
Always consider the domain: arguments of all logarithms must be strictly positive.

Series involving logarithms:
• log₁₀(1·2·3·…·n) = log₁₀ n!
• Telescoping sums: log(n/(n+1)) + log((n+1)/(n+2)) + … collapses by cancellation.
• If log x, log y, log z are in AP: xz = y².

8. Complex Numbers and Quadratic Equations in Complex Domain

A complex number is z = x + iy, where x, y ∈ ℝ and i = √(−1) (i² = −1). x is the real part Re(z); y is the imaginary part Im(z).

Conjugate: z̄ = x − iy. Properties:
• z + z̄ = 2x; z − z̄ = 2iy
• z · z̄ = x² + y² = |z|² (a non-negative real)
• |z| = √(x² + y²) is the modulus
• |z₁z₂| = |z₁||z₂|; |z₁/z₂| = |z₁|/|z₂|; |zⁿ| = |z|ⁿ

Algebraic operations:
• Addition: (a+bi) + (c+di) = (a+c) + i(b+d)
• Subtraction: (a+bi) − (c+di) = (a−c) + i(b−d)
• Multiplication: (a+bi)(c+di) = (ac−bd) + i(ad+bc)
• Division: multiply numerator and denominator by conjugate of denominator

Polar form: z = r(cos θ + i sin θ) = r·cis θ, where r = |z|, θ = arg(z)
• Argument θ lies in (−π, π] or [0, 2π); principal value in (−π, π]
• arg(z₁z₂) = arg(z₁) + arg(z₂) (mod 2π)
• arg(z₁/z₂) = arg(z₁) − arg(z₂) (mod 2π)

De Moivre's Theorem:
(cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ), n ∈ ℤ
This is essential for computing powers and roots of complex numbers.

nth roots of unity: zⁿ = 1 has roots 1, ω, ω², …, ωⁿ⁻¹ where ω = cis(2π/n)
Properties: 1 + ω + ω² + … + ωⁿ⁻¹ = 0; ωⁿ = 1; ω³ = 1 when n = 3.

Quadratic equation with complex coefficients ax² + bx + c = 0 still uses the discriminant D = b² − 4ac. If D < 0 (with real coefficients), roots are complex conjugates. The quadratic formula remains valid in the complex domain.

9. Matrices

A matrix is a rectangular array of numbers arranged in m rows and n columns, denoted as an m × n matrix.

Types of matrices:
• Row matrix: 1 × n; Column matrix: m × 1
• Square matrix: m = n
• Diagonal matrix: non-diagonal entries are zero
• Identity (unit) matrix Iₙ: diagonal entries = 1, others = 0; AI = IA = A
• Zero matrix: all entries are 0
• Scalar matrix: diagonal matrix with all diagonal entries equal
• Upper/lower triangular matrix: entries below/above diagonal are zero
• Symmetric: A' = A; Skew-symmetric: A' = −A (diagonal entries = 0)
• Singular: det(A) = 0; Non-singular: det(A) ≠ 0
• Orthogonal: A'A = AA' = I
• Idempotent: A² = A

Operations:
• Addition/subtraction: defined only for matrices of same order; element-wise
• Scalar multiplication: k·A multiplies every element by k
• Matrix multiplication AB: defined when columns of A = rows of B; (AB)ᵢⱼ = Σₖ aᵢₖbₖⱼ
– Not commutative: AB ≠ BA in general
– Associative: (AB)C = A(BC)
– Distributive: A(B+C) = AB + AC
– If AB = 0, it does NOT imply A = 0 or B = 0 (zero divisors exist for matrices)

Transpose properties:
• (A')' = A
• (kA)' = kA'
• (A + B)' = A' + B'
• (AB)' = B'A'

Determinant of a 2×2 matrix: |A| = ad − bc for A = [[a,b],[c,d]]
Determinant of a 3×3 matrix: expand along any row/column using cofactors.
|A| = a₁₁C₁₁ + a₁₂C₁₂ + a₁₃C₁₃

Adjoint and inverse:
• Adj(A): transpose of cofactor matrix
• A⁻¹ = Adj(A)/|A|, exists iff |A| ≠ 0
• A · Adj(A) = Adj(A) · A = |A|·I
• (AB)⁻¹ = B⁻¹A⁻¹
• (A')⁻¹ = (A⁻¹)'
• |A⁻¹| = 1/|A|; |kA| = kⁿ|A| for n×n matrix

Elementary row/column transformations preserve the determinant's value (up to sign/scalar factor) and are used to find the inverse.

10. Determinants

For a square matrix A of order n, the determinant det(A) or |A| is a scalar value computed from its entries.

Properties of determinants:
• |A'| = |A|
• Interchanging two rows (or columns) changes the sign of the determinant
• If two rows (or columns) are identical, |A| = 0
• If a row (or column) is all zeros, |A| = 0
• Multiplying a row (column) by k multiplies the determinant by k
• If a row (column) is a sum of two terms, the determinant splits into two
• Adding a multiple of one row to another does not change the determinant
• |AB| = |A||B|

Cofactor expansion (Laplace expansion):
|A| = aᵢ₁Cᵢ₁ + aᵢ₂Cᵢ₂ + aᵢ₃Cᵢ₃ (along row i)
|A| = aⱼ₁C₁ⱼ + aⱼ₂C₂ⱼ + aⱼ₃C₃ⱼ (along column j)
where Cᵢⱼ = (−1)ⁱ⁺ʲMᵢⱼ and Mᵢⱼ is the minor.

Product of a row with cofactors of another row gives zero: aᵢ₁Cⱼ₁ + aᵢ₂Cⱼ₂ + aᵢ₃Cⱼ₃ = 0 for i ≠ j.

Sarrus' rule (3×3 only): cross-multiply diagonals; sum of downward products minus sum of upward products.

Applications:
• Area of triangle with vertices (x₁,y₁), (x₂,y₂), (x₃,y₃):
Area = ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|
• Three points are collinear iff the area determinant equals zero.
• Cramer's rule for system of linear equations:
x = Dx/D, y = Dy/D, z = Dz/D where D is coefficient determinant.
• System has unique solution if D ≠ 0; no solution or infinite solutions if D = 0 (check consistency separately).

11. Theory of Equations and Polynomial Identities

Fundamental Theorem of Algebra: Every polynomial equation of degree n with complex coefficients has exactly n roots (counting multiplicity) in the complex number system.

Remainder Theorem: If p(x) is divided by (x − a), the remainder is p(a).
Factor Theorem: (x − a) is a factor of p(x) if and only if p(a) = 0.

Vieta's formulas for a quartic ax⁴ + bx³ + cx² + dx + e = 0 with roots α, β, γ, δ:
• α + β + γ + δ = −b/a
• αβ + αγ + αδ + βγ + βδ + γδ = c/a
• αβγ + αβδ + αγδ + βγδ = −d/a
• αβγδ = e/a

Descartes' Rule of Signs:
• Number of positive real roots ≤ number of sign changes in p(x); differs by an even non-negative integer.
• Number of negative real roots ≤ number of sign changes in p(−x).
Useful for estimating the nature of roots without solving.

Polynomial identities frequently used:
• a³ + b³ + c³ − 3abc = (a+b+c)(a²+b²+c²−ab−bc−ca)
If a + b + c = 0, then a³ + b³ + c³ = 3abc
• a³ + b³ = (a+b)³ − 3ab(a+b)
• (a+b+c)² = a²+b²+c²+2(ab+bc+ca)
• (a+b+c)³ = a³+b³+c³+3(a+b)(b+c)(c+a)
• aⁿ − bⁿ is divisible by (a − b) for all positive integers n
• aⁿ − bⁿ is divisible by (a + b) when n is even
• aⁿ + bⁿ is divisible by (a + b) when n is odd

12. Linear Inequalities and Absolute Value

A linear inequality in one variable has the form ax + b > 0, ax + b ≥ 0, ax + b < 0, or ax + b ≤ 0, with a ≠ 0.

Solution rules (identical to equation rules except):
• Adding/subtracting the same quantity on both sides preserves inequality.
• Multiplying/dividing both sides by a POSITIVE number preserves inequality.
• Multiplying/dividing both sides by a NEGATIVE number REVERSES the inequality sign.
• Solving a system of inequalities requires intersection of individual solution sets.

Quadratic inequality ax² + bx + c > 0 (a > 0):
• Find roots using discriminant; then test intervals.
• Solution regions depend on whether roots are real and distinct, equal, or complex.

Absolute value (modulus):
|x| = x if x ≥ 0; |x| = −x if x < 0
Properties:
• |xy| = |x||y|
• |x/y| = |x|/|y|, y ≠ 0
• |x|² = x²
• |x| < a (a > 0) ⇔ −a < x < a
• |x| > a (a > 0) ⇔ x < −a or x > a
• |x − a| represents distance between x and a on number line
• Triangle inequality: |x + y| ≤ |x| + |y|; |x − y| ≥ ||x| − |y||

Linear inequality in two variables ax + by ≤ c: graph the boundary line ax + by = c (solid for ≤ or ≥, dashed for < or >), shade the half-plane containing test point (usually origin if it satisfies the inequality).
Compound inequalities must satisfy all parts simultaneously.

13. Mathematical Induction and Basic Number Theory Applications

Principle of Mathematical Induction (PMI) — used to prove statements P(n) true for all natural numbers n ≥ n₀:
Step 1 (Base case): Verify P(n₀) is true, usually n₀ = 1.
Step 2 (Inductive hypothesis): Assume P(k) is true for some arbitrary k ≥ n₀.
Step 3 (Inductive step): Using the assumption, prove P(k + 1) is true.
Conclusion: By PMI, P(n) is true for all n ≥ n₀.

Classic results proved by induction (NDA/CDS favourites):
• 1 + 2 + 3 + … + n = n(n+1)/2
• 1² + 2² + … + n² = n(n+1)(2n+1)/6
• 1³ + 2³ + … + n³ = [n(n+1)/2]²
• a + ar + ar² + … + arⁿ⁻¹ = a(rⁿ−1)/(r−1) for r ≠ 1
• 7ⁿ − 2ⁿ is divisible by 5 for all n ∈ ℕ
• 3²ⁿ − 1 is divisible by 8 for all n ∈ ℕ
• n³ + 11n is divisible by 6 for all n ∈ ℕ

Divisibility rules tested:
• 2: last digit even; 4: last two digits divisible by 4; 8: last three digits divisible by 8
• 3: sum of digits divisible by 3; 9: sum of digits divisible by 9
• 5: last digit 0 or 5; 10: last digit 0
• 11: (sum of odd-place digits) − (sum of even-place digits) is 0 or multiple of 11

Congruence basics (occasionally tested):
• a ≡ b (mod m) means m divides (a − b)
• Properties: if a ≡ b (mod m) and c ≡ d (mod m), then a+c ≡ b+d and ac ≡ bd (mod m)

Important facts

  • NDA Mathematics carries 300 marks out of 900 total; Algebra typically contributes 20–30 questions (approximately 20% of the paper)
  • CDS (II) Elementary Mathematics paper carries 100 marks with 120 questions, 2 minutes per question average
  • D = b² − 4ac completely determines root nature in quadratic equations; D = 0 implies equal roots
  • For a quadratic with real coefficients, non-real roots always occur in conjugate pairs
  • In GP, the product of equidistant terms from beginning and end is constant
  • In HP, the harmonic mean of two numbers a and b is H = 2ab/(a+b); never confuse with arithmetic or geometric mean formulas
  • nCk = nC(n−k); nCr + nC(r−1) = n+1Cr are Pascal identities tested repeatedly
  • For (1+x)ⁿ, sum of odd binomial coefficients equals sum of even binomial coefficients, each equal to 2^(n−1)
  • log_a(b) · log_b(c) · log_c(a) = 1; log_a(b) = 1/log_b(a)
  • De Moivre's theorem: (cos θ + i sin θ)ⁿ = cos nθ + i sin nθ; apply for powers and roots
  • Matrix multiplication AB is defined when columns of A = rows of B; AB ≠ BA generally
  • A⁻¹ exists if and only if |A| ≠ 0; A · Adj(A) = |A|·I
  • Cramer's rule solves linear systems using ratios of determinants: x = Dx/D, y = Dy/D, z = Dz/D
  • Triangle vertices are collinear iff the determinant formed by their coordinates is zero
  • a³ + b³ + c³ − 3abc = (a+b+c)(a²+b²+c²−ab−bc−ca); if a+b+c=0, then a³+b³+c³=3abc
  • nCr is always an integer; nCr divides n! for all valid r
  • |x| < a ⇔ −a < x < a; |x| > a ⇔ x < −a or x > a
  • In induction proofs, always verify the base case explicitly; skipping it loses marks
  • HCF × LCM = product of two numbers only for a pair; extend cautiously for three or more numbers

Common mistakes

  • Writing the sum of GP as a(rⁿ−1)/(r−1) without checking r ≠ 1; the formula fails when r = 1
  • Using A = (a+b)/2 and G = √(ab) interchangeably in HP problems — HP involves reciprocals, not direct terms
  • Forgetting that |x| < a implies −a < x < a; students often write x < a or x > −a instead
  • Assuming AB = 0 implies A = 0 or B = 0 for matrices; matrix rings have zero divisors
  • Applying HCF × LCM = product of numbers for three or more numbers; the relation holds only for two numbers
  • Choosing the wrong middle term in binomial expansion — for odd n there are TWO middle terms, not one
  • Reversing the inequality sign when multiplying/dividing by a negative number during inequality solving
  • Forgetting that the discriminant condition D ≥ 0 is required before claiming real roots exist
  • Confusing nPr with nCr — permutations count arrangements, combinations count selections only
  • Writing log(M + N) = log M + log N — logarithms do not distribute over addition
  • Treating complex modulus as algebraic: |z₁ + z₂| ≠ |z₁| + |z₂| in general; only triangle inequality holds
  • Not checking domain restrictions for logarithmic equations (arguments must be > 0, bases > 0 and ≠ 1)
  • Assuming determinant of sum equals sum of determinants: |A+B| ≠ |A| + |B| generally
  • Using (n−1)! instead of (n−1)!/2 for circular arrangements when reflection symmetry matters
  • Forgetting that in PMI, the inductive step must use the hypothesis P(k) to prove P(k+1), not assume both independently
  • Misapplying De Moivre's theorem for non-integer exponents; it is valid for all integers n only in this basic form
  • Writing (a+b)ⁿ = aⁿ + bⁿ — binomial expansion has n+1 terms, not 2; this error wipes out entire binomial questions
