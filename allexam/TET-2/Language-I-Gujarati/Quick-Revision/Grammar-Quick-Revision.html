ગુજરાતી વ્યાકરણ -ક્વિક રિવિઝન | TET-2 (ભાષા-I)

TET-2GujaratiQuick Revision

Definitions

  • સ્વર: અ, આ, ઇ, ઈ, ઉ, ઊ, એ, ઐ, ઓ, ઔ – ગુજરાતીમાં ૧૦ સ્વરઅક્ષરો.
  • વ્યાજન: ક ખ ગ ઘ ઙ / ચ છ જ ઝ ઞ / ટ ઠ ડ ઢ ણ / ત થ દ ધ ન / પ ફ બ ભ મ / ય ર લ વળ શ ષ સ હ ળ – ગુજરાતીમાં ૩૪ વ્યાજનઅક્ષરો.
  • સંઘ્યા (Sandhi): બે અથવા તેથી વધુ શબ્દો જોડાતાં આવતો ધ્વનિ ફેરફાર = સંઘ્યા.
  • સમાસ (Compound): બે અથવા વધુ શબ્દોના સંયોગથી બનતો એક નવો શબ્દ = સમાસ.
  • લિંગ (Gender): નામવાચક પદનો પુલિંગ/સ્ત્રીલિંગમાં વિભાગ = લિંગ.
  • વચન (Number): પદનો એકવચન/બહુવચનમાં વિભાગ = વચન.
  • વિભક્તિ (Case): વાક્યમાં પદોનાં કારકસૂચક સંબંધો દર્શાવતાં ૮ વિભક્તિઓ.
  • સર્વનામ (Pronoun): નામની જગ્યાએ વપરાતું પદ = સર્વનામ (પ્રથમ પુરુષ, બીજો પુરુષ, ત્રીજો પુરુષ, સાર્વત્રિક, પ્રશ્નાર્થક, સંદિગ્ધ, સર્વનામેય).
  • વિશેષણ (Adjective): નામ/સર્વનામના ગુણ, પરિમાણ, સંખ્યા, પ્રમાણ દર્શાવતું પદ.
  • ક્રિયાપદ (Verb): વ્યક્તિ, સમય, પુરુષ, વચન દર્શાવતું મુખ્ય પદ જે વાત/ભાવ/અવસ્થા જાહેર કરે છે.
  • કારક (Case Role): વાક્યમાં ક્રિયાપદ સાથે સંબંધ ધરાવતા પદનું વ્યાકરણસરનું કામ (કર્તર, કર્મ, સાધન, સંપ્રદાન, અધિકરણ, ફલ, સાથિ).
  • સમાસપદ: સમાસમાં પ્રધાનપદ અને અધિકરણપદ.
  • ઉત્તરપદ: સમાસના પરિણામે બનતો નવો શબ્દ જે સમક્ષી રીતે મૂળ શબ્દોની વ્યાખ્યા ન આપે.
  • વાક્યપ્રકાર: બાંધકામ મુજબ તટસ્થ, પ્રશ્નાર્થક, આજ્ઞાર્થક, અલંકારિક; વ્યુત્પત્તિ મુજબ સરલ, સંયુક્ત, સંકીર્ણ.

Key concepts

  • ['સંઘ્યાના મુખ્ય ભેદ:', 'અ) સ્વરસંઘ્યા: સ્વર + સ્વરના મિલનથી થતો ફેરફાર.', '• અ/આ + અ/આ = આ (ગાય + અહો = ગાયહો > ગાયહો, રામા + ઈશ = રામેશ)', '• ઇ/ઈ + અ/આ = ઈ (કવિ + અહો = કવઈ > કવી)', '• ઊ + અ/આ = ઊ (સુત + અહો = સૂહો)', '• ઋ + અ/આ = રી (પણી + અહો = પાણી)', '• એ/ઐ + અ = ઈ/એ (વાદલ + અહો = વાદલ > વાદલ)', '• ઓ/ઔ + અ = ઔ (નાદ + અહો = નાદ્યો > નાદ્યો)', 'બ) વ્યાજનસંઘ્યા: સ્વર+વ્યાજન અથવા વ્યાજન+વ્યાજનનું મિલન.', '• ન + દ = ન્દ, ત + થ = ત્થ, ક +ષ = ક્ષ (મહા + ત્મા = મહત્મા)', '• અનુસ્વાર અને વિસર્ગ પણ વ્યાજનસંઘ્યાનું પરિણામ (જ્ઞાન, વિદ્યા).', 'ગ) દ્રશ્ય/અદ્રશ્ય સંઘ્યા: ઉચ્ચારમાં દેખાતો અથવા અદ્રશ્ય ફેરફાર.', '• આદેશસંઘ્યા: નવો આદેશ લાગે (ન + ડ = ન્ડ; રામ + ડ = રાવડ).', '• દૃઢસંઘ્યા: અક્ષરનું વિકલ્પ બદલાય પણ દેખાય (કુલ + હ = કૂલ્ય).', "સંઘ્યા નિયમોમાં 'હલંત' અને 'સ્વરંત' પદોનો સંયોગ, અનુનાસિકતા, સ્થાનસંઘ્યા વિગેરે પણ TET-2 માં આવે છે."]
  • ['સમાસના પ્રકારો અને દરેકનાં ઉદાહરણો:', 'અ) દ્વંદ્વ સમાસ: સમૂહ/બંધારણ દર્શાવતો સમાસ. પ્રકારો:', '• સમુહાર્થક: પિતામત (માતા+પિતા) – મિલન દર્શાવે.', '• વિકલ્પાર્થક: રામાલક્ષ્મણ (રામા કે લક્ષ્મણ).', '• વિભાવાર્થક: માતાપિત્રો (માતા અને પિત્રો બંને).', '• અન્યોદ્દિષ્ટ: ચંદ્રસૂર્યો.', 'બ) તત્પુરુષ સમાસ (કર્મધાય): બીજું પદ પ્રધાન, પહેલું અધિકરણ.', '• બૃહદ્વૃક્ષ (મોટું ઝાડ), ગંગાજલ (ગંગાનું જળ).', '• પાંચ પ્રકારો: કર્મ (રાજપુત્ર), અધિકરણ (ગૃહસ્થ), કર્તા (કંધકર્તરૂ), ભાવ (સુખી), સાધન (સુવર્ણમય).', 'ગ) બહુવ્રીહિ સમાસ: બાહ્ય અર્થ જણાવે, ઉત્તરપદ નિરુક્ત.', '• લાલચૂડ (જેનાં લાલ ચૂડાં હોય); લોહીલોચન (જેના આંખો લોહી જેવી).', 'દ) ઉપપદ તત્પુરુષ (મર્યાદા): સંબંધ સાધક.', '• ઉત્તરકુમાર (ઉત્તરનો કુમાર); ગૌરક્ષક (ગાયની રક્ષા કરનાર).', 'અન્ય પ્રકારો: યશગાથા, નિષ્પાદ્ય, સાધારણ, યોગ ક્ષેપક.', 'E) કર્મધાચ (Samas-type): વિશેષણ + નામ જેથી વિશેષણ અર્થ ધરાવે.', '• લલનમસ્તક (લાડનું માથું = મોઢું).', 'ઉદાહરણો સાથે અભ્યાસ કરવો જરૂરી.']

  • ['ગુજરાતીમાં સર્વનામનાં મુખ્ય પ્રકારો:', 'અ) પ્રથમ પુરુષ (ઉત્તરપુરુષ): મੈં, હું, આપણે, આપણો, આપણી, આપણાં.', 'બ) બીજો પુરુષ: તું, તે, તેણે, તેઓ, તમે, એ.', 'ગ) ત્રીજો પુરુષ (સંદર્ભ): તે, એ, તેણે, તેઓ – વિશેષણ/સંજ્ઞાની જગ્યાએ.', 'દ) સાર્વત્રિક સર્વનામ: કોઈ પણ, બધાં, કેટલાક, દરેક.', 'ઇ) પ્રશ્નાર્થક સર્વનામ: કોણ? શું? ક્યાં? ક્યારે? કેમ? કેવું? કેટલું?', 'ઉ) સંદિગ્ધ/અશ્રુત સર્વનામ: કેવું, કેટલું, અધરું (અશ્રુત).']

Important facts

  • ગુજરાતીમાં સ્વરઅક્ષરો ૧૦ છે, વ્યાજનઅક્ષરો ૩૪ છે.
  • ગુજરાતીમાં ૮ વિભક્તિઓ છે, દરેકનાં ચિન્હો અને ઉદાહરણો યાદ રાખવાં.
  • સમાસનાં મુખ્ય ૫ પ્રકાર: દ્વંદ્વ, તત્પુરુષ, બહુવ્રીહિ, ઉપપદ તત્પુરુષ, કર્મધાચ.
  • સંઘ્યાના પ્રકાર: સ્વરસંઘ્યા, વ્યાજનસંઘ્યા, આદેશસંઘ્યા, દૃઢસંઘ્યા, અન્યોદ્દિષ્ટ.
  • કારકો ૭ છે: કર્તર, કર્મ, સાધન, સંપ્રદાન, અપાદન, અધિકરણ, સાથિ.
  • પ્રશ્નાર્થક સર્વનામો: કોણ? શું? ક્યાં? ક્યારે? કેમ? કેવું? કેટલું?
  • લિંગભેદ અને વચન-ભેદ સમાસ અને પ્રત્યયો દ્વારા નક્કી થાય છે.

Memory aids

  • વિભક્તિ યાદ રાખવા: 'પ્રદત્ત-ચપત-પંચ-ષષ્ટ-સપ્ત-સંબોધ' – પ્રથમ, દ્વિતીયા, તૃતીયા, ચતુર્થી, પંચમી, ષષ્ઠી, સપ્તમી, સંબોધન.
  • સમાસ યાદ: 'દ્વંદ્વ-તપુરુષ-બહુવ્રીહિ-ઉપપદ-કર્મધાચ' – પાંચ પ્રકાર.
  • કારક-વિભક્તિ મેળ: 'કર્તા-પ્રથમ, કર્મ-દ્વિતીયા, સાધન-તૃતીયા, સંપ્રદાન-ચતુર્થી, સંબંધ-ષષ્ઠી, અધિકરણ-સપ્તમી.'
  • સંઘ્યા ઉદાહરણ: 'રામ + અહો = રાહમ > રામા' – સ્વરસંઘ્યા.
  • લિંગ યાદ: 'પુલિંગ-ઓ/આણું, સ્ત્રીલિંગ-ઈ/ની' – સામાન્ય પ્રત્યયો.

Exam tips

  • વિભક્તિચિન્હ પર ધ્યાન: પ્રથમ વિભક્તિમાં કોઈ પ્રત્યય નથી, દ્વિતીયામાં -ને/-એ, તૃતીયામાં -થી/-ને, ષષ્ઠીમાં -નાં/-ની.
  • સમાસ પ્રશ્નોમાં ઉત્તરપદ શોધવું: દ્વંદ્વમાં ઉત્તરપદ સમૂહબોધક, તત્પુરુષમાં પ્રધાનપદ.
  • કારક પ્રશ્નોમાં વાક્યના કર્તાર્થ/કર્માર્થ સંબંધ જોવા – દા.ત. 'રામે કલમથી લખ્યું' → કર્તા=રામ, સાધન=કલમથી, કર્મ=લખ્યું.
  • સંઘ્યા પ્રશ્નોમાં બે પદો તોડીને દર્શાવવું: દા.ત. 'અહોભાવ' → અ + હોભાવ, 'વિદ્યા' → વિ + દ્યા.
  • લિંગ-વચન પ્રશ્નોમાં સમાસ અને પ્રત્યય બંને જોવા – બહુવચનમાં -ઓ, -એ, -નાં.
  • TET-2 માં વ્યાકરણ ૧૦-૧૨ પ્રશ્નો જેટલા આવે છે; સંઘ્યા, સમાસ, વિભક્તિ-કારક મુખ્ય વિષયો છે.

Common traps

  • વિભક્તિ અને કારકને ગડબડાવી દેવું – વિભક્તિ ચિન્હ જોઈને કારક નક્કી કરવું, પણ વાક્યમાં ક્રિયા-સંબંધ પણ જોવો.
  • સમાસના પ્રકારમાં ગલતી – દ્વંદ્વ vs તત્પુરુષની સ્પષ્ટતા: દ્વંદ્વમાં સમુહ/વિકલ્પ, તત્પુરુષમાં પહેલું અધિકરણ.
  • લિંગભેદમાં અટકી જવું – 'ગરબડું' vs 'ગરબી', 'સાહેબ' (પુલિંગ) vs 'સાહેબી' (સ્ત્રીલિંગ).
  • સંઘ્યાના નિયમોમાં બેઠો રાખવો – આદેશસંઘ્યામાં નવો આદેશ, દૃઢસંઘ્યામાં સ્થાનબદલી.
  • વચનની ગલતી – 'છોકરાઓ' (બહુવચન) vs 'છોકરો' (એકવચન).
  • સર્વનામમાં પુરુષ-વચન-લિંગ મેળ ન જોવો – તું(એક/પ્રથમ), તે(એક/ત્રીજો), તેઓ(બહુ/ત્રીજો).
