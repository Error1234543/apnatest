ગણિત: સંખ્યા પદ્ધતિ, બીજગણિત, ભૂમિતિ, માપનકાળ અને ગણિત શિક્ષણશાસ્ત્ર — પૂર્ણ અભ્યાસધોરણ નોટ્સ

TET-2GujaratiNotes

1. સંખ્યા પદ્ધતિ — પ્રાથમિકથી ઉચ્ચ સુધીની આવરણ

સંખ્યા પદ્ધતિ એ ગણિતના ધોરણ 6 થી 8 ના મૂળભૂત હિસ્સામાં છે અને TET-2 માં સીધા ગણિતિક પ્રશ્નો તથા શિક્ષણશાસ્ત્ર રૂપે બંને પરથી આવે છે.

1.1 સંખ્યાવ્યવસ્થાનો વિસ્તરણ ક્રમ
- પ્રাকૃતિક સંખ્યાઓ (N): 1, 2, 3, ... — શૂન્ય સમાવિત નથી.
- પૂર્ણ સંખ્યાઓ (W): 0, 1, 2, 3, ... — પ્રાકૃતિક સંખ્યા + શૂન્ય.
- પૂર્ણાંકો (Z): ..., –3, –2, –1, 0, 1, 2, 3, ... — ઋણ પૂર્ણાંકો પણ.
- પૂર્ણાંકોના ગુણધર્મો:
* જોડવાની (a+b = b+a) અને ગુણવાની (ab = ba) ચાલકતા.
* જોડવાની અને ગુણવાની સંયોજકતા: (a+b)+c = a+(b+c), (ab)c = a(bc).
* તટસ્થ સંખ્યાઓ: 0 (જોડ), 1 (ગુણ).
* વ્યુતક્રમ: પૂર્ણાંકનો જોડ વ્યુતક્રમ પૂર્ણાંક હોતો નથી (ઉદા. –3 નો જોડ વ્યુતક્રમ –1/3 છે, પૂર્ણાંક નહિ); ગુણ વ્યુતક્રમ માત્ર 1 અને –1 માટે પૂર્ણાંક છે.
- ભિન્ન ( Rational numbers, Q): p/q રૂપે, j્યાં q ≠ 0, p તથા q પૂર્ણાંક.
* દશાંશ રૂપ: સમાપક અથવા આવર્તી.
* સમાપક ભિન્ન: છેદનો અવયવ સિવાય 2 તથા 5 ન હોય ત્યારે જ.
- અપૂર્ણાંક (Irrational numbers): √2, π, e જેવી સંખ્યાઓ; દશાંશ અસમાપક + અઆવર્તી.
- વાસ્તવિક સંખ્યાઓ (R): ભિન્ન + અપૂર્ણાંક;
* સંખ્યા રેખા પર દરેક વાસ્તવિક સંખ્યાની એક મૂલ્ય અને પ્રત્યેક બિંદુ એક વાસ્તવિક સંખ્યા.

1.2 HCF અને LCM
- HCF (મ.સા.અ.): બે કે તેથી વધુ સંખ્યાઓના સામાન્ય અવયવોમાં સૌથી મોટો.
- LCM (લ.સા.અ.): બે કે તેથી વધુ સંખ્યાઓના સામાન્ય ગુણકોમાં સૌથી નાનો.
- ગુણધર્મ: HCF × LCM = પહોળું સંખ્યાઓનો ગુણાકાર (જો બે સંખ્યાઓ હોય). ત્રણ કે વધુ સંખ્યાઓ માટે આ સીધું કામ કરતું નથી; સીધું વિભાજન/અવયવીકરણ પદ્ધતિ વાપરવી.
- ઉદાહરણ: 36 = 2²×3², 84 = 2²×3×7 → HCF = 2²×3 = 12, LCM = 2²×3×7 = 84.

1.3 પદ્ધતિઓ
- અવયવીકરણ પદ્ધતિ (ફેક્ટરાઇઝેશન): પ્રાથમિક અવયવો દ્વારા LCM/HCF શોધવું.
- વિભાજન પદ્ધતિ (Divisiion algorithm): લઘુત્તમ સામાન્ય યોગ્ય પદ્ધતિ.
- Euklid's division lemma: a = bq + r, 0 ≤ r < b.

1.4 ઘાતાંક અને ઘાત
- a^m × a^n = a^(m+n); a^m ÷ a^n = a^(m−n); (a^m)^n = a^(mn);
- a^0 = 1 (a ≠ 0); a^(−n) = 1/a^n.
- વૈજ્ઞાનિક સંકેતલિપી: મોટી/નાની સંખ્યાઓ, દા.ત. 1 km = 10³ m.

1.5 યોગ્ય પ્રશ્નો / TET માટે ઉપયોગી
- √3 × √12 = ? → 6 (પૂર્ણાંક).
- (√5)² = 5.
- 2³ × 2⁴ = 2⁷ = 128.

2. ભિન્ન અને દશાંશ — ગણિત અને શિક્ષણ શાસ્ત્ર

ધોરણ 6 માં ભિન્નનો પ્રવેશ અને ધોરણ 7-8 માં દશાંશ સાથે સંબંધ.

2.1 ભિન્ન પ્રકારો
- સાદા (Proper): અંશ < છેદ.
- અસાદા (Improper): અંશ ≥ છેદ.
- મિશ્ર (Mixed): પૂર્ણાંક + સાદો ભિન્ન.
- સમરૂપ (Like): સમાન છેદ; અસમરૂપ (Unlike): વિષમ છેદ.

2.2 ક્રિયાઓ
- કિયો: છેદ સમાન → અંશોનો સરવાળો/બાદબાકી.
- ગુણાકાર: અંશ × અંશ, છેદ × છેદ.
- ભાગાકાર: દ્વિતીય ભિન્ન ઉલટાવો (reciprocal) અને ગુણો.
- LCM/HCF સાથે જોડાણ: અસમરૂપ ભિન્નોનો સરવાળો = LCM(છેદો) → સમરૂપ ભિન્ન.

2.3 દશાંશ સંબંધ
- ભિન્ન ↔ દશાંશ: 1/4 = 0.25, 1/8 = 0.125, 3/5 = 0.6.
- આવર્તી દશાંશ: 1/3 = 0.333..., 1/6 = 0.1666...
- દશાંશની ક્રિયાઓ: સરવાળો/બાદબાકી માટે દશાંશ ચિહ્ન સંરેખિત; ગુણાકારમાં કુલ દશાંશ સ્થાનો; ભાગાકારમાં છેદને પૂર્ણાંક બનાવવો.

2.4 શિક્ષણશાસ્ત્ર — સામાન્ય ભૂલો
- વિદ્યાર્થીઓ પ્રાયઃ છેદો ઉમેરતાં અંશો પણ ઉમેરે છે (1/3 + 1/4 ≠ 2/7).
- દશાંશ ગુણાકારમાં યાદ્ઘૃત જગ્યા ઓળંગાય છે.
- પ્રતિક્રિયા: સંદર્ભિત માપકો (fraction wall, number line, base-10 blocks) વડે અનુભવી શીખવું.

2.5 TET-મહત્વના પ્રશ્નો
- (–3/4) × (–2/5) = 3/10.
- 0.25 + 0.125 = 0.375.
- 2.4 ÷ 0.6 = 4.

3. બીજગણિત — પદાવલી, સમીકરણ, પરિમાણીય

3.1 પદાવલી શબ્દો
- ચલ (variable): x, y, a, b ...
- અચળ (constant): 5, –3, 2π ...
- પદ (term): a × xⁿ જેવું એકમ.
- સદિશ (monomial): એક પદ; દ્વિપદી (binomial): બે પદ; ત્રિપદી (trinomial): ત્રણ પદ; બહુપદી (polynomial): n પદો.

3.2 બહુપદી પ્રકાર
- એકચલ બહુપદી: f(x) = ax² + bx + c.
- અચલ (degree 0): f(x) = k ≠ 0.
- રેખીય (degree 1): ax + b.
- દ્વિઘા (degree 2): ax² + bx + c.
- ત્રિઘા (degree 3): ax³ + bx² + cx + d.
- શૂન્ય બહુપદી: 0.

3.3 બહુપદીના મૂળ (zeros)
- f(a) = 0 ⇒ a એ મૂળ.
- રેખીય ax + b નું મૂળ –b/a.
- બહુપદીનું મૂળ બનાવનાર ઉત્પાદક પ્રમેય: જો f(a) = 0 ⇒ (x – a) એ ઉત્પાદક.
- degree n ની બહુપદી ઘણા મતે n મૂળ ધરાવે (વાસ્તવિક/સંકીર્ણ).

3.4 સૂત્રો / પદ્ધતિઓ
- (a+b)² = a² + 2ab + b².
- (a–b)² = a² – 2ab + b².
- a² – b² = (a+b)(a–b).
- (a+b)³ = a³ + 3a²b + 3ab² + b³.
- a³ – b³ = (a–b)(a² + ab + b²).
- a³ + b³ = (a+b)(a² – ab + b²).

3.5 સમીકરણો
- સરળ રેખીય: ax + b = c → x = (c–b)/a.
- બે ચલોનું જોડકું: substitution, elimination, graphing.
- અસમતા: x < a, x > a, |x| < a ⇒ –a < x < a.

3.6 પ્રમેયો
- પ્રમેય 1: જો f(x) ને (x – a) ભાગે તો શેષ f(a).
- શેષ પ્રમેય: f(x) ÷ (x – a) → શેષ f(a).
- ગુણાકાર પ્રમેય: f(a) = 0 ⇒ (x – a) ઉત્પાદક.

3.7 યોગ્ય ઉદાહરણો
- f(x) = x³ – 3x² + x – 3, f(3) = 27 – 27 + 3 – 3 = 0 ⇒ (x – 3) ઉત્પાદક.
- 2x + 3y = 12, 4x – 3y = 6 → ઉકેલ: x = 3, y = 2.

3.8 શિક્ષણશાસ્ત્ર
- વિદ્યાર્થીઓ પદાવલીના ગુણાકારમાં 2x × 3x = 6x² ભૂલી જાય (ચલના સૂચકાંકો ઉમેરવા ન ભૂલતા).
- સંજ્ઞાઓ પ્રત્યે અનુભવી સમજૂતિ: ધન/ઋણના નિયમો પ્રયોગોથી.

4. પ્રક્રિયાઓ અને સંબંધો — ગુણોત્તર, ટકા, લાભ/હાનિ

4.1 ટકા (Percentage)
- % એ હજારદાન છે: 25% = 25/100 = 0.25.
- ટકાબદલ: (part/whole) × 100.
- ટકામાં ફેરફાર: [(new – old)/old] × 100.
- વ્યાજ: ચક્રવૃદ્ધિ A = P(1+r/100)^t; સરળ ચક્રવૃદ્ધિ SI = P×r×t/100.

4.2 લાભ / હાનિ (Profit/Loss)
- લાભ = વેચાણ કિંમત – ખરીદ કિંમત.
- હાનિ = ખરીદ કિંમત – વેચાણ કિંમત.
- ટકા લાભ = (લાભ/CP)×100.
- ખોટો વિકલ્પો: વેચાણ કિંમત = CP×(1 ± %/100).

4.3 ગુણોત્તર અને અનુપાત
- a : b એ a/b છે.
- સમજૂતી: જો 3 : 5 છે તો 3k, 5k.
- ચાલકતા:
* અનુલોમ (direct proportion): x/y = constant.
* વિલોમ (inverse proportion): xy = constant.

4.4 ચલિત ગુણોત્તર
- સમય + કામ + વેગ / અંતર.
- દર: પાણી ભરે છે → ડબલ વેગ → અડધો સમય.

4.5 ઉદાહરણો
- ₹500 નું 10% વધારો અને 10% ઘટાડો: 500×1.10 = 550; 550×0.90 = 495. અંતિમ 495 (5% હાનિ).
- જો x:y = 2:3 અને y:z = 5:7 તો x:z = 10:21.

4.6 શિક્ષણશાસ્ત્ર
- વિદ્યાર્થીઓ ટકા બદલવામાં ઇન્વર્ટ ક્રમ ભૂલે છે (10% ઘટાડો પછી 10% વધારો ≠ મૂળ).
- અનુપાત માટે માપન સાધનો: પ્રોપોર્શનલ રેખાઓ, સમાનતા ત્રિકોણ, ગ્રાફ.

5. ભૂમિતિ — બિંદુ, રેખા, ખૂણા, ત્રિકોણ, ચતુષ્કોણ

5.1 મૂળભૂત રૂપરેખાઓ
- બિંદુ, રેખા, અર્ધરેખા, રેખાખંડ, સમરેખ બિંદુઓ.
- ખૂણો: લઘુકોણ (< 90°), સમકોણ (90°), મૂર્ધ્ય (obtuse) (90–180°), સરળરેખીય (180°).
- સંયુક્ત ખૂણાં:
* સંલગ્ન (adjacent), સમપરિપૂરક (supplementary, બેનો સરવાળો 180°), પરસ્પર પૂરક (complementary, સરવાળો 90°).
- રેખાઓ:
* સમાંતર (parallel): બંને એક જ સમતલમાં, અપ્રત્યક્ષ.
* તિરછી (transversal): બે સમાંતર રેખાઓને મળે ત્યારે:
- સંયુક્ત કોણ (alternate interior) સમાન.
- સંબંધિત કોણ (corresponding) સમાન.
- અಂತઃ સંલગ્ન કોણોનો સરવાળો 180°.

5.2 ત્રિકોણના ગુણધર્મો
- ત્રણ ખૂણાંનો સરવાળો = 180°.
- બાહ્ય ખૂણો = અન્નત કોણોનો સરવાળો.
- બાજુઓનો સંબંધ: કોઈ બે બાજુઓનો સરવાળો ત્રીજીથી મોટો;
|a – b| < c < a + b.
- પ્રકાર:
* બાજુ: સમબાજુ, સમદ્વિબાજુ, વિષમબાજુ.
* ખૂણા: લઘુકોણ, સમકોણ, મૂર્ધ્ય.
- વિશેષ રેખાઓ:
* ત્રિભુજાંત (median): શિરોબિંદુથી વિરુદ્ધ બાજુના મધ્યબિંદુ સુધી;
ત્રણેય મધ્યગા એક બિંદુ (centroid) પર મળે.
* ઉચ્ચતા (altitude): શિરોબિંદુથી વિરુદ્ધ બાજુ પર લંબ;
ત્રણેય orthocenter પર.
* કોણસમદ્ભાજક: ખૂણા બેસમાન બનાવે;
અંતઃકેન્દ્ર (incenter) પર.
* લંબસમદ્ભાજક: બાજુના મધ્યબિંદુથી લંબ;
પરિકેન્દ્ર (circumcenter) પર.

5.3 ત્રિકોણ સર્વસમતા (Congruence)
- SSS: ત્રણેય બાજુ.
- SAS: બે બાજુ + તેમની વચ્ચેનો ખૂણો.
- ASA/AAS: બે ખૂણા + બાજુ.
- RHS (直角三角形): કાટખૂણા ત્રિકોણમાં કર્ણ + એક બાજુ.

5.4 ત્રિકોણ અસમતા પ્રમેય
- મોટી બાજુ = મોટો ખૂણો.
- બહારનો ખૂણો > કોઈ પણ આંતરિક ખૂણો.

5.5 ચતુષ્કોણ
- ચતુષ્કોણના ચારેય ખૂણાંનો સરવાળો = 360°.
- પ્રકાર અને ગુણધર્મો:
* સમાંતરબાજુ ચતુષ્કોણ: સામસામેની બાજુ સમાંતર તથા સમાન, સામસામેના ખૂણા સમાન, વિકર્ણો એકબીજાને સમભાજિત.
* આયત (rectangle): બધા ખૂણા 90°, વિકર્ણ સમાન.
* લંબચોર (square): બધા ખૂણા 90°, બધી બાજુ સમાન, વિકર્ણ સમાન + લંબ.
* રઝમ્બસ (rhombus): બધી બાજુ સમાન, વિકર્ણો લંબ + સમભાજક.
* સમલંબ (trapezium): એક જુની બાજુ સમાંતર.
* સમદ્વિબાજુ સમલંબ: સમાન સરતા બાજુઓ.

5.6 શિક્ષણશાસ્ત્ર
- વિદ્યાર્થીઓ «સમાંતર» તથા «સમાંતરબાજુ» વચ્ચે ભ્રમણા ધરાવે છે.
- ખૂણાં માપનમાં પ્રોટ્રેક્ટર રાખવાની યોગ્ય પદ્ધતિ: બિંદુ, રેખા, સ્કેલ.
- વિશ્વાસપાત્ર પ્રવેશ: કાગળ_fold_ કરી ખૂણાં શોધવા.

5.7 ઉદાહરણો
- ત્રિકોણ ABC માં ∠A = 70°, ∠B = 60°, ∠C = ? → 50°.
- સમાંતરબાજુ ચતુષ્કોણમાં બાજુ 6 cm અને 8 cm હોય તો પરિમિતિ = 2(6+8) = 28 cm.

6. ચક્ર — ચાપ, ચુંબક, પઘું, કેન્દ્રીય/વૃત્તખંડ, સંબંધો

6.1 મૂળભૂત પરિભાષા
- વ્યાસ (diameter): કેન્દ્રમાંથી પસાર થતો સૌથી લાંબો જીવા.
- જીવા (chord): બે બિંદુઓને જોડતો રેખાખંડ.
- અર્ધવૃત: વ્યાસ દ્વારા બનતો ભાગ.
- ચાપ (arc): વર્તુળનો વક્ર ભાગ.
- વૃત્તખંડ (segment): જીવા + ચાપ વચ્ચેનું વિસ્તાર.
- વૃત્તખંડ (sector): કેન્દ્રીય ખૂણો દ્વારા બનતો વિસ્તાર.
- કેન્દ્ર (O), ત્રિજ્યા (r).

6.2 ગુણધર્મો
- બાહ્ય બિંદુથી દોરેલા સ્પર્શકો લંબાયમાં સમાન.
- સ્પર્શક ⊥ ત્રિજ્યા સ્પર્શબિંદુએ.
- સમાન જીવાઓ = સમાન અંતર (કેન્દ્રથી).
- કેન્દ્રથી નજીકની જીવા વધુ લાંબી.
- કેન્દ્રીય ખૂણો = 2 × પરિઘીય ખૂણો (અ એખાડા ચાપ પર).
- એક જ ચાપના તમામ પરિઘીય ખૂણા સમાન.
- અર્ધવૃતમાં પરિઘીય ખૂણો = 90°.
- સમચક્રી ચતુષ્કોણ: સામસામેના ખૂણાઓનો સરવાળો 180°.

6.3 માપન સૂત્રો
- પરિઘ (circumference) = 2πr = πd.
- વૃત્તખંડનું ક્ષેત્રફળ = (θ/360) × πr².
- ચાપની લંબાઈ = (θ/360) × 2πr.
- વૃત્તખંડનું ક્ષેત્રફળ = (r²/2)(θ_rad – sin θ_rad).

6.4 ભાગી શકાય તેવા પંચભુજ, નિયમિત બહુഭુજ
- નિયમિત બહુભુજ: બધી બાજુઓ + ખૂણા સમાન.
- n-બાજુ ધરાવતા નિયમિત બહુભુજનો આંતરિક ખૂણો = (n−2)×180/n.
- બાહ્ય ખૂણો = 360/n.

6.5 શિક્ષણશાસ્ત્ર
- વિદ્યાર્થીઓ θ માં degrees vs radians ભૂલે છે;
પ્રથમકક્ષામાં θ નો એકમ સ્પષ્ટ.
- વૃત્ત વિભાજન માટે પંચાયત રેખા (string method) + fold પદ્ધતિ.
- પ્રવેગક ગણતરી: પ્રાયોગિક માપન સંગ્રહ.

6.6 ઉદાહરણો
- r = 7 cm → પરિઘ ≈ 44 cm.
- વ્યાસ 14 cm = 2r = 14 → r = 7, πr² ≈ 154 cm².

7. ત્રિઘન — ઘન, પ્યુરામિડ, સિલિન્ડર, કોન, ગોળા

7.1 ઘન (Cube)
- બાજુ a.
- પૃષ્ઠક્ષેત્રફળ (TSA) = 6a².
- પાർશ્વપૃષ્ઠ (LSA) = 4a².
- ઘનફળ (V) = a³.

7.2 ઘનાකાર (Cuboid)
- લંબાઈ l, પહોળાઈ w, ઊંચાઈ h.
- TSA = 2(lw + wh + hl).
- LSA = 2h(l + w).
- વિકર્ણ = √(l² + w² + h²).
- V = lwh.

7.3 બેઝ (Cylinder)
- ત્રિજ્યા r, ઊંચાઈ h.
- LSA = 2πrh.
- TSA = 2πr(r + h).
- V = πr²h.

7.4 શંકુ (Cone)
- ત્રિજ્યા r, ઊંચાઈ h, પિરવલય (slant height) l = √(r² + h²).
- LSA = πrl.
- TSA = πr(r + l).
- V = (1/3)πr²h.

7.5 ગોળો (Sphere)
- ત્રિજ્યા r.
- પૃષ્ઠક્ષેત્રફળ = 4πr².
- ઘનફળ = (4/3)πr³.

7.6 અર્ધગોળા (Hemisphere)
- ટોચ પર LSA = 2πr².
- TSA = 3πr².
- V = (2/3)πr³.

7.7 બેઝ / ટેપર (Frustum)
- શંકુ/બેઝનું કાપેલું ભાગ;
V = (1/3)πh(R² + Rr + r²).
LSA = π(R + r)l, j્યાં l = √((R–r)² + h²).

7.8 યોગ્ય પદ્ધતિઓ
- બધા પદાર્થોના V એકમ cm³ / m³;
ક્ષેત્રફળ એકમ cm² / m².
- 1 L = 1000 cm³; 1 m³ = 10⁶ cm³ = 1000 L.

7.9 ઉદાહરણો
- r = 3 cm, h = 4 cm → Cone l = 5 cm;
LSA = π×3×5 = 15π cm².
- Sphere V = (4/3)π×7³ ≈ 1437 cm³.

7.10 શિક્ષણશાસ્ત્ર
- વિદ્યાર્થીઓ (1/3) અને 2/3 ભૂલે છે;
પાત્રો ભરી ખાલી કરી પ્રાયોગિક દૃશ્ય.
- Surface Area vs Volume અલગ સમજાવવી.

8. માપનકાળ — પરિમિતિ, ક્ષેત્રફળ, ઘનફળ

8.1 પરિમિતિ (Perimeter)
- ચતુષ્કોણ: P = 2(l + w).
- સમબાજુ: P = 4a.
- સમદ્વિબાજુ ત્રિકોણ: P = 2a + b.
- વિષમબાજુ: P = a + b + c.

8.2 ત્રિકોણ ક્ષેત્રફળ
- A = (1/2)bh.
- હીરોનના સૂત્રથી:
s = (a+b+c)/2;
A = √[s(s-a)(s-b)(s-c)].

8.3 ચતુષ્કોણ ક્ષેત્રફળ
- આયત: l × w.
- સમાંતરબાજુ: બાજુ × લંબ ઊંચાઈ.
- લંબચોર: l × w.
- વજ્ર (Rhombus): (d1 × d2)/2.
- સમલંબ: (a + b)/2 × h.

8.4 બહુભુજ ક્ષેત્રફળ
- નિયમિત n-બાજુ: (1/2) × Perimeter × apothem.
- સમબાજુ ત્રિકોણ: (√3/4)a².

8.5 જટિલ આકૃતિઓ
- રચનાબદ્ધ ક્ષેત્રફળ = સરવાળો.
- ખાલી ટાંકણી = બૃહત્ત – આંતરિક.

8.6 યુનિટ રૂપાંતરણ
- 1 m = 100 cm; 1 km = 1000 m.
- 1 m² = 10⁴ cm²; 1 ha = 10⁴ m² = 1 km².
- 1 L = 1000 cm³.

8.7 ઉદાહરણો
- Rhombus d1 = 10 cm, d2 = 24 cm → A = 120 cm².
- Trapezium a = 8, b = 12, h = 5 → A = 50 cm².

8.8 શિક્ષણશાસ્ત્ર
- વિદ્યાર્થીઓ ક્ષેત્રફળ ↔ પરિમિતિ ભ્રમણા ધરાવે છે;
એકસમાન પરિમિતિ ધરાવતી આકૃતિઓના ક્ષેત્રફળ અલગ;
ઉદા. 4×4 વર્ગ = 16, 2×6 = 12.
- યુનિટ રૂપાંતરણ માટે વર્ગમૂળ / ઘનનો સંબંધ સ્પષ્ટ.

9. સંભાવના અને આંકડાશાસ્ત્ર — માધ્ય, મધ્યસ્થ, મોડ

9.1 આંકડાકીય મૂળભૂત
- માહિતી સંગ્રહ: અવલોકનો, વિચલનો.
- શ્રેણી (range) = મહત્તમ – લઘુત્તમ.

9.2 કેન્દ્રિય પ્રવૃત્તિ
- માધ્ય (Mean): Σx/n.
- મધ્યસ્થ (Median):
* n વિષમ: (n+1)/2 ઘટક.
* n સમાન: n/2 + n/2+1 ઘટકોનો સરવાળો ÷ 2.
- મોડ (Mode): સૌથી વધુ આવર્તન ધરાવતું મૂલ્ય.

9.3 આવર્તન વિતરણ
- સરળ / સમૂહિત.
- મધ્યબિંદુ = (upper + lower)/2.

9.4 સંભાવના (Probability)
- P(E) = Favorable outcomes / Total outcomes.
- 0 ≤ P ≤ 1.
- P(complement) = 1 – P(E).

9.5 પ્રયોગો
- સિક્કો: H/T; P(H) = 1/2.
- પાસો: 1–6; P(k) = 1/6.
- કાર્ડ્સ: 52, face cards 12, aces 4.

9.6 TET-મહત્વ
- «સરેરાશ» અને «મધ્યસ્થ» વચ્ચેનું તફાવત:
સંવેદનશીલ મૂલ્યો મધ્યસ્થ પર અસર નથી કરતા.

9.7 ઉદાહરણો
- 2, 3, 5, 5, 7 → Mean = 22/5 = 4.4, Median = 5, Mode = 5.
- પાસા: P(≥4) = 3/6 = 1/2.

9.8 શિક્ષણશાસ્ત્ર
- વિદ્યાર્થીઓ «સરેરાશ = બધાનો સરવાળો» એવું ભ્રમણા ધરાવે છે;
મધ્યસ્થ અને મોડ માટે પ્રયોગો.

10. ગણિત શિક્ષણશાસ્ત્ર — NCF, CBSE, GSEB સંદર્ભ

Common mistakes

  • Adding denominators directly when adding fractions: 1/3+1/4 ≠ 2/7.
  • Assuming HCF×LCM equals product of any number of integers; holds only for two.
  • Mixing up degree-zero polynomial: constant function f(x)=c has degree 0 unless c=0 (zero polynomial is undefined).
  • Applying quadratic formula blindly without checking discriminant.
  • Confusing corresponding angles with alternate interior angles in parallel lines.
  • Believing same perimeter implies same area for different shapes.
  • Using 2πr for area or πr² for circumference.
  • Forgetting factor 1/3 in cone/frustum volumes vs cylinder.
  • Treating 10% decrease followed by 10% increase as net zero.
  • Mixing up mean, median, mode usage; using mean with extreme values incorrectly.
  • Assuming probability of even/odd on dice is not 1/2 each.
  • Computing segment area as sector minus wrong triangle.
  • Applying cyclic quad property to non-cyclic quadrilaterals.
  • Using slant height as vertical height in cone problems.
  • Adding exponents when multiplying unlike bases: 2³×3² ≠ 6⁵.
  • Drawing perpendicular from a vertex to opposite side without ensuring foot lies on side extension for obtuse triangles.
