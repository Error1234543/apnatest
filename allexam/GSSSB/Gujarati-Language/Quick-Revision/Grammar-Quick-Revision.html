Definitions

  • સંધિ : બે સ્વતંત્ર શબ્દો મળીને જ્યારે એક જ બને છે ત્યારે તે સંધિ કહેવાય. ઉદા. વિદ્યા + અભ્યાસ = વિદ્યાભ્યાસ
  • સમાંસ : બે અથવા વધુ શબ્દો મળીને જે નવો શબ્દ બનાવે અને તેનો અર્થ સ્પષ્ટ થાય તે સમાંસ છે. ઉદા. મહા + આત્મા = મહાત્મા
  • પદ પ્રકાર : ગુજરાતી ભાષામાં પદોના પ્રકારો — નામપદ, વિશેષણપદ, સર્વનામ, ક્રિયાપદ, સંબંધબોધક, વિભક્તિબોધક, સમાસબોધક, વિસ્મયબોધક અને અવ્યય
  • લિંગ : ગુજરાતીમાં બે લિંગ — પુલ્લિંગ અને સ્ત્રીલિંગ. ઉદા. દૂધ (નપુંસક), છોકરો (પુલ્લિંગ), છોકરી (સ્ત્રીલિંગ)
  • વચન : ગુજરાતીમાં બે વચન — એકવચન અને બહુવચન. બહુવચનના ચાર રૂપ — અમા પુરુષ, તમા પુરુષ, યા પુરુષ, આ પુરુષ
  • પુરુષ : વાણીપ્રયોગ અનુસાર ત્રણ પુરુષ — પ્રથમ પુરુષ (ઉત્તમપુરુષ/હું-આપણે), દ્વિતીય પુરુષ (મધ્યમપુરુષ/તું-આપ), તૃતીય પુરુષ (અધમપુરુષ/તે-તેઓ)
  • કારક : વાક્યમાં ક્રિયાપદ સાથેના શબ્દો વચ્ચેનો સંબંધ દર્શાવનારા વિભક્તિબોધક પરિબળને કારક કહે. ઉદા. કર્તૃકારક, કર્મકારક, સંબંધકારક
  • અલંકાર : ભાષાને શોભાવનારા શબ્દિક અને વાચ્ય અલંકારો. મુખ્ય શબ્દિક — રૂપક, ઉપમા, હસ્તપ્રસન્ન, દિગ્ગજ, અતિશયોક્ટિ; વાચ્ય — રસ, વાયન, અનુપ્રાસ

Key concepts

  • સંધિના પ્રકારો : માગમ સંધિ (સ્વર+સ્વર), અયામાં સંધિ (વ્યંજન+વ્યંજન), યુક્ત સંધિ, દીર્ઘ સંધિ, ગુણ સંધિ, વૃદ્ધિ સંધિ, અદેહ સંધિ. વિદ્યા+ઈશ = વિદ્યાઈશ (ગુણ સંધિ), પ્રકાશ+ઇંદ્ર = પ્રકાશિંદ્ર (દીર્ઘ સંધિ)
  • સમાંસના પ્રકારો : બહુવ્રીહ (મહાભાગ્ - જેનો ભાગ મહાન હોય), તત્પુરુષ (રાજપુત્ર - રાજાનો પુત્ર), દ્વંદ્વ (રામ-શ્વેતા - રામ અને શ્વેતા), અવ્યાઈભાવી (પૂર્વાહ્ન - પૂર્વ + અહ્નનું એકીભાવ), વર્તમાન સમાંસ
  • સમાંસ લક્ષણો : બહુવ્રીહ સમાંસમાં પ્રથમ પદ નપુંસક લિંગ અને એકવચનમાં આવે છે, અંતિમ પદનું લિંગ-વચન અનુસાર સાધ્યપદ બંધાય છે. ઉદા. ધ્રુવતારક = જે ધ્રુવ તારો છે તે સ્ત્રી (ચાંદની)
  • વિભક્તિના પ્રકારો : ગુજરાતીમાં સામાન્ય રીતે 8 વિભક્તિઓ — પ્રથમા(નેટા), દ્વિતીયા(ને), તૃતીયા(થી), ચતુર્થી(ને), પંચમી(થી),ષષ્થી(ના), સપ્તમી(માં), સંબોધન. વિભક્તિ પ્રત્યય : -એ, -ને, -થી, -માં, -નો/-ની/-નું
  • ક્રિયાપદના વિધાન : સતત, સંપૂર્ણ, સામાન્ય, સાહચર્ય. ઉદા. ફરતો હતો (સતત), ફર્યો (સંપૂર્ણ), ફરે છે (સામાન્ય), ફરી રહ્યો છે (સાહચર્ય)
  • કારકના નિર્ણય : કર્તૃકારક - વિભક્તિ બોધક 'એ' અથવા કર્તા હોય; કર્મકારક - વિભક્તિ બોધક 'ને'; સંબંધકારક - વિભક્તિ બોધક 'ના'; સાધનકારક - વિભક્તિ બોધક 'થી'; કર્તા-ક્રિયા સંબંધ સ્પષ્ટ હોય તો કર્તૃકારક
  • અલંકાર પહચાણ : રૂપક - શબ્દની વાત બીજી શબ્દ સાથે સમાન હોય (કમળ - ચહેરો); ઉપમા - ઉપમા સજ્જન હોય (ચાંદવડો ચહેરો); અતિશયોક્ટિ - અતિશય વર્ણન (આંસુઓનો સિંધુ); અનુપ્રાસ - અક્ષરોનું પુનરાવર્તન (ચંદ્રકાન્ત)
  • પદ મિશ્રણના ધ્યાન રાખવાં : વિ + અભ્યાસ = વિભ્યાસ (મિત્ર સંધિ); પ્રકાશ + અંધકાર = પ્રકાશંધકાર; રામ + એવ = રಾಮેવ (વાફ સંધિ); ગંગા + આટ = ગંગાટ (આકાર સંધિ)

Important facts

  • સંધિમાં માગમ સંધિનો નિયમ : 'ઋ, લ઼, ળ' એવા વર્ણો 'અ' સાથે મળીને 'અર્, અલ઼, અળ' બનાવે છે. ઉદા. કૃત + અન્ = કર્તાન્
  • સમાંસના બહુવ્રીહમાં આગળનું પદ હંમેશા નપુંસક લિંગના એકવચનમાં જ હોય છે. ઉદા. કપિશિર = કપિ જેમું માથું છે તે (પુલ્લિંગ)
  • ગુજરાતીમાં નપુંસક લિંગ : 'દૂધ, પાણી, ધુમાળો' જેવા શબ્દો નપુંસક લિંગમાં ગણાય. મળતું નામ પછી નપુંસક લિંગ લાગે.
  • બહુવચનના રૂપો : હું=મैं, તું=તમે, તે=તેઓ; આપણે=આપ, તમે=તમે, તેઓ=તેઓ. પ્રથમ પુરુષના બહુવચનમાં 'આપણે, તમે, તેઓ' પ્રયોગ થાય.
  • વિભક્તિ બોધકની યાદ : કાગળ - લખે છે (કર્મ), કલમ - લખે છે (સાધન), મારા ખાતે (સંબંધ), મારા પાસે (સંબંધ)
  • અતિશયોક્ટિ અલંકારમાં ક્રિયા કે વસ્તુનું અતિશય વર્ણન હોય. ઉદા. 'ચંદ્ર તેના ચરણોમાં જમી' - ચંદ્રનું અતિશય વર્ણન
  • રૂપક અલંકારમાં ઉપમા શબ્દનો અભાવ હોય. ઉદા. 'મુખ ચંદ્ર' (ચંદ્ર સમાન મુખ), જ્યારે 'મુખ ચંદ્રવડું' ઉપમા થાય
  • સમાંસમાં તત્પુરુષ સમાંસની સંખ્યા સૌથી વધુ છે. રાજપુત્ર, ગંગાજળ, પુસ્તકખાતા, અગ્નિકુંડ - આ બધા તત્પુરુષ છે
  • ગુજરાતીમાં સમાસના અંત્ય પરિમાણ : તત્પુરુષમાં બીજા પદનું રૂપ બદલાઈ શકે. ઉદા. પાણીનો સર = પાણીસર
  • સ્ત્રીલિંગ માટે પ્રમાણભૂત પ્રત્યયો : -ા, -ી, -લી. ઉદા. છોકરી, દીકરી, બહેન. પરંતુ કેટલાક શબ્દો પુલ્લિંગમાં પણ હોય. ઉદા. માવડી (પુલ્લિંગ)

Memory aids

  • સંધિ યાદ કરવા : 'મ-અ-યુ-દી-ગુ-વૃ-અદ' - માગમ, અયામાં, યુક્ત, દીર્ઘ, ગુણ, વૃદ્ધિ, અદેહ
  • સમાંસ યાદ કરવા : 'બા-તા-અ-વ-અ' - બહુવ્રીહ, તત્પુરુષ, દ્વંદ્વ, અવ્યાઈભાવી, વર્તમાન
  • કારક યાદ કરવા : 'કર-કર્મ-સંબંધ-સાધન-અધિકરણ-સાથે-ઉપલક્ષ' - કર્તૃકારક, કર્મકારક, સંબંધકારક, સાધનકારક, અધિકરણકારક, સાહચર્યકારક, ઉપલક્ષકારક
  • અલંકાર યાદ કરવા : 'રૂ-ઉપ-અત-અનુ' - રૂપક, ઉપમા, અતિશયોક્ટિ, અનુપ્રાસ. ઉપમામાં 'વડો, સમાન' જેવા શબ્દો આવે
  • વિભક્તિ યાદ કરવા : '1-એ, 2-ને, 3-થી, 4-ને, 5-થી, 6-ના, 7-માં, સં-ઓ' - પ્રથમથી સંબોધન સુધી
  • લિંગ યાદ કરવા : 'મિત્ર, યુવક, સિંહ, ભાઈ, પુત્ર' પુલ્લિંગ; 'મિત્રા, યુવતી, સિંહી, બહેન, દુહિતર' સ્ત્રીલિંગ
  • વચન યાદ કરવા : એકવચનમાં 'હું, તું, તે'; બહુવચનમાં 'આપણે, તમે, તેઓ' - પ્રથમ, દ્વિતીય, તૃતીય પુરુષ
  • પદ પ્રકાર યાદ કરવા : 'ન-વિ-સ-ક્રિ-સ-વિ-વ-વ-અ' - નામપદ, વિશેષણપદ, સર્વનામ, ક્રિયાપદ, સંબંધબોધક, વિભક્તિબોધક, વિસ્મયબોધક, અવ્યય

Exam tips

  • સંધિ પ્રશ્નોમાં પહેલા શબ્દોને તોડીને જુઓ. વિદ્યાભ્યાસ = વિદ્યા + અભ્યાસ. બે શબ્દોની વચ્ચેનો ભંગાણ શોધો
  • સમાંસ પ્રશ્નોમાં અંતિમ પદનું લિંગ-વચન જોઈને બહુવ્રીહ ઓળખો. નપુંસક+એકવચન = બહુવ્રીહ
  • કારક પ્રશ્નોમાં ક્રિયાપદની દિશા જુઓ. કર્તૃકારકમાં 'એ' વિભક્તિ બોધક, કર્મકારકમાં 'ને', સંબંધકારકમાં 'ના'
  • અલંકાર પ્રશ્નોમાં ઉપમા શબ્દ ('વડો', 'સમાન') હોય તો ઉપમા, ન હોય તો રૂપક. અતિશયોક્ટિમાં અતિશય શબ્દો
  • વિભક્તિ પ્રશ્નોમાં પદની ભૂમિકા જુઓ. કેસ બોધક -ની રીતે ઉપયોગ : 'ને' = કર્મ, 'થી' = સાધન/પંચમી
  • લિંગ-વચન પ્રશ્નોમાં સામાન્ય નિયમ યાદ રાખો : -ા, -ી, -લી = સ્ત્રીલિંગ; -ો, -ા, -ું = પુલ્લિંગ/નપુંસક
  • પદ મિશ્રણ પ્રશ્નોમાં સંધિ અને સમાંસ વચ્ચેનો તફાવત યાદ રાખો : સંધિ = બે શબ્દોએક, સમાંસ = બે શબ્દોથી નવો અર્થ
  • પૂર્ણ પ્રશ્નોમાં વાક્યની રચના જુઓ. કર્તૃ-કર્મ-ક્રિયાનો ક્રમ સાચો હોવો જોઈએ. ગુજરાતીમાં ક્રિયા છેલ્લે આવે છે
  • સાચા ઉત્તરની ચોક્કસપણે યાદ કરો : વિદ્યા+ઈશ્વર = વિદ્યાઈશ્વર (ગુણ સંધિ), પ્રકાશ+ઇંદ્ર = પ્રકાશિંદ્ર (દીર્ઘ સંધિ)
  • સમય વહેંચણી : 40 પ્રશ્નોમાં 40-45 મિનિટ. ઝડપી સંધિ/સમાંસ પ્રશ્નો પહેલા, પછી મુશ્કેલ કારક/અલંકાર

Common traps

  • સંધિ ઓળખવામાં ભ્રમ : 'વિદ્યા + અભ્યાસ = વિદ્યાભ્યાસ' માં 'અ' એકલો નથી, પણ 'અભ્યાસ' ના શરૂઆતનો 'અ' સંધિ પામે છે. વિદ્યા + અભ્યાસ = વિદ્યાભ્યાસ, વિદ્યા + આભાર = વિદ્યાભાર
  • સમાંસમાં બહુવ્રીહ અને તત્પુરુષ ઓળખ : બહુવ્રીહમાં આગળનું પદ નપુંસક લિંગમાં હોય અને પાછળનું પદ સાધ્ય હોય. તત્પુરુષમાં પ્રથમ પદ કર્તૃ/કર્મ હોય. ઉદા. રાજપુત્ર(તત્પુરુષ) vs રાજા(પુરુષ)(બહુવ્રીહ)
  • કારક નક્કી કરવામાં ભૂલ : 'લड़के ने किताब पढ़ी' માં 'लड़के' કર્તૃકારક, 'किताब' કર્મકારક. ગુજરાતીમાં 'છોકરાએ' = કર્તૃકારક, 'પુસ્તક' = કર્મકારક
  • અલંકાર ઓળખવામાં ભૂલ : 'ચંદ્રવડો ચહેરો' = ઉપમા (ઉપમા શબ્દ 'વડો' છે); 'ચંદ્ર ચહેરો' = રૂપક (ઉપમા શબ્દનો અભાવ). આ બે વચમાં તફાવત સમજવો જરૂરી
  • વિભક્તિ ઓળખવામાં ભૂલ : 'માં' વિભક્તિ શબ્દની અંદર હોય તો ચતુર્થી/પંચમી? 'ગھرમાં' = સપ્તમી, 'ઘરથી' = પંચમી. અર્થ અને વિભક્તિ બંને જોવા
  • લિંગ ઓળખવામાં ભૂલ : 'બેડroom' જેવા શબ્દો નપુંસક લિંગમાં ગણાય, 'છોકરો' પુલ્લિંગ. કેટલાક શબ્દો બંને લિંગમાં હોય: 'મિત્ર' (પુ), 'મિત્રા' (સ્ત્રી)
  • સંધિ વિભાજનમાં ભૂલ : 'વિદ્યાભ્યાસ' = વિદ્યા + અભ્યાસ, 'મહાત્મા' = મહા + આત્મા. બે શબ્દો વચ્ચેનો ભંગાણ સાચો હોવો જોઈએ
  • પદ મિશ્રણમાં અર્થ બદલાવ : 'મન + ઈશ્વર = મનીશ્વર' (સંધિ), 'મન+ઈશ્વર = મનીશ્વર' (ભેદ). સંધિ અને સમાંસ વચ્ચેનો તફાવત સમજવો
