શબ્દભંડોળ - મૂળભૂત જ્ઞાન અને પ્રશ્નો

GSSSBGujaratiNotes

શબ્દભંડોળની આવશ્યકતા અને મહત્વ

ગુજરાતી ભાષાના શબ્દભંડોળનો અભ્યાસ ગ્રામ્ય સેવા પસંદગી બોર્ડ (GSSSB) સહિતની તમામ પ્રતિસ્પર્ધી પરીક્ષાઓમાં ગુજરાતી વિષયનો મહત્વનો ભાગ છે. શબ્દભંડોળ એટલે ભાષામાં ઉપયોગમાં લેવાતા શબ્દોનો ભંડાર કે સંગ્રહ. ગુજરાતી સાહિત્ય અને ભાષાના અભ્યાસમાં શબ્દભંડોળના નિમ્નલિખિત પાસાઓનો અભ્યાસ કરવો જરૂરી છે: સમાનાર્થી શબ્દો (પર્યાયવાચી શબ્દો), વિરોધી શબ્દો (વિપરીતાર્થક શબ્દો), એક શબ્દમાં પ્રગાશ (એક પદ માટે યોગ્ય વાક્ય), વ્યુત્પન્ન શબ્દો (મૂળ શબ્દ અને તેનાથી બનેલા શબ્દો), લોકભાષિક શબ્દો, ઉપસર્ગ-પ્રત્યય જાણવા અને અંગ્રેજી શબ્દોના ગુજરાતી રૂપ. આ બધું જ જાણીતું હોય તો કોઈ પણ પ્રકારનો પ્રશ્ન સરળતાથી ઉકેલી શકાય છે.

સમાનાર્થી શબ્દો (પર્યાયવાચી શબ્દો)

સમાનાર્થી શબ્દો એવા શબ્દો છે જે એક જ અર્થ દર્શાવે છે. આ શબ્દો ઘણીવાર પદની વિવિધતા જાળવવા માટે અથવા વ્યાખ્યાયિત કરવા માટે ઉપયોગમાં લેવાય છે.

ધરતી - પૃથ્વી, ખંડ, ધ્રુવ, ગૌરી, ધરા, ભૂમિ, જમીન, અક્ષરા
સૂર્ય - અરુણ, દિવાકર, ભાસ્કર, દિવકર, તેજોરાશિ, તપન, વરુણ, વિરાટ
ચંદ્ર - ચંદ્રમા, શેષાશ, અમૃતકલશ, ઈષુ, હરણ, ચાન્દ, શિવ, સિંધુ,
જળ - પાણી, ભીમ, સરિત્, નદી, વરૂણ, અબ્ધિ, ઊર, અમીર,
અગ્નિ - અનલ, તપન, વહ્નિ, સમીપ, હુતવહ્ન, ઝવણિયો,
ચંદ્રિકા - ચંદ્રકલ્યાણી, ચંદ્રા, ડોલ, પારિજાતક,
અશ્વ - ગંધર્વ, કુરંગ, તુરંગ, શેર, રથંગ,
પક્ષી - પખ્ષી, વાયસ, પખ્ષજાત, ચાતક, હંસ,
મનુષ્ય - મનુષ્ય, માનવ, નર, વ્યક્તિ, જન,
સ્ત્રી - નારી, રમણી, ભાગિની, ગર્ભિણી, મહિલા
આમ ગ્રહીતા અને વિદ્વાન વિચારકોએ આ શબ્દોનું પ્રયોગ કરવું જોઈએ.

શ્વસન - શ્વાસ, શ્વાસ-પ્રશ્વાસ, નાસિકા, નાસિકાકંદ, નાસિકાગર્ભ
પ્રકાશસંશ્લેષણ - પ્રકાશસંશ્લેષણ, પ્રકાશસંશ્લેષણ, પ્રકાશસંશ્લેષણ, પ્રકાશસંશ્લેષણ, પ્રકાશસંશ્લેષણ

વ્યુત્પન્ન શબ્દો (Root Words and Derived Words)

વ્યુત્પન્ન શબ્દો એટલે કે એક મૂળ શબ્દમાંથી બનતા શબ્દો. આ શબ્દોની રચના સમજવી ખૂબ જરૂરી છે.

મૂળ શબ્દ: ઘર -> વ્યુત્પન્ન શબ્દો: ઘરણું, ઘરવાળા, ઘરવહુ, ઘરબાર, ઘરપોરી, ઘરગત્તુ
મૂળ શબ્દ: હાથ -> વ્યુત્પન્ન શબ્દો: હાથા, હાથડા, હાથવર, હાથે-હાથે, હાથવોડા
મૂળ શબ્દ: મુખ -> વ્યુત્પન્ન શબ્દો: મુખડું, મુખવાળું, મુખાકૃતિ, મુખરા, મુખજ,
મૂળ શબ્દ: નેત્ર -> વ્યુત્પન્ન શબ્દો: નેત્રડું, નેત્રવાળા, નેત્રસેવક, નેત્રગોચર
મૂળ શબ્દ: કર્ણ -> વ્યુત્પન્ન શબ્દો: કર્ણાળું, કર્ણપાસ, કર્ણસેવક, કર્ણગોચર
મૂળ શબ્દ: ચક્ષુ -> વ્યુત્પન્ન શબ્દો: ચક્ષુષ્માન, ચક્ષુમતી, ચક્ષુષી, ચક્ષુષ્યા,
મૂળ શબ્દ: દંત -> વ્યુત્પન્ન શબ્દો: દંતકલ્પ, દંતચ્છાદન, દંતસેવક, દંતગોચર
મૂળ શબ્દ: નાસા -> વ્યુત્પન્ન શબ્દો: નાસાભરણ, નાસાપાશ, નાસાસેવક, નાસાગોચર
મૂળ શબ્દ: વાક્ -> વ્યુત્પન્ન શબ્દો: વાક્પ્રવાહ, વાક્ચાતુર્ય, વાક્ચેષ્ટા, વાક્ચાતુર્ય
મૂળ શબ્દ: અક્ષર -> વ્યુત્પન્ન શબ્દો: અક્ષરભંગ, અક્ષરગણ, અક્ષરવ્યાકરણ, અક્ષરશઃ

પ્રત્યયો:
-તા (સ્ત્રીલિંગ): ગુરુ + તા = ગુરુતા
-ત્વ (ભાવ): ગુરુ + ત્વ = ગુરુત્વ
-ક (કર્તાર્થે): ગુરુ + ક = ગુરુક
-ઈન (સંબંધ): ગુરુ + ઈન = ગુરુઈન
-ય (કર્મ): ગુરુ + ય = ગુરુય

ઉપસર્ગો:
-પર (અતિશય): પર+ગમન = પરગમન
-પ્ર (સામने): પ્ર+કાશ = પ્રકાશ
-અધિ (શ્રેષ્ઠ): અધિ+ગમન = અધિગમન
-અનુ (પાછળ): અનુ+ગમન = અનુગમન
-ઉત્ (ઉત્તર): ઉત્+ગમન = ઉત્ગમન

ઉપસર્ગ અને પ્રત્યયની ભૂમિકા

ગુજરાતી ભાષામાં શબ્દોની રચના ઉપસર્ગ અને પ્રત્યયથી થાય છે. આનો અભ્યાસ શબ્દભંડોળ માટે ખૂબ મહત્વપૂર્ણ છે.

ઉપસર્ગો (Prefixes):
- 'પ્ર' પ્રત્યય: પ્રકાશ, પ્રવેશ, પ્રગતિ, પ્રગલ્લ, પ્રતિષ્ઠા, પ્રમાણ
- 'અનુ' પ્રત્યય: અનુગામી, અનુભવ, અનુપ્રવેશ, અનુસરણ
- 'પર' પ્રત્યય: પરગમન, પરચ્છાદન, પરિમાણ, પરિણામ
- 'ઉત્' પ્રત્યય: ઉત્પાદન, ઉત્ક્રાંતિ, ઉત્સવ, ઉત્સર્જન
- 'અધિ' પ્રત્યય: અધિગમન, અધિકાર, અધિવેશ, અધિરાજ્ય
- 'નિ' પ્રત્યય: નિર્માણ, નિર્ગમન, નિષ્ફળ, નિર્ધારિત
- 'સહ' પ્રત્યય: સહિત, સહાય, સહભાગી, સહચર
- 'સમ' પ્રત્યય: સમગ્ર, સમાન, સમય, સમસ્ત

પ્રત્યયો (Suffixes):
- 'તા' પ્રત્યય: ગુરુ + તા = ગુરુતા, હલકું + તા = હલકતા
- 'ત્વ' પ્રત્યય: ગુરુ + ત્વ = ગુરુત્વ, ઝડપ + ત્વ = ઝડપત્વ
- 'ઈન' પ્રત્યય: ગુરુ + ઈન = ગુરુઈન, ગીત + ઈન = ગીતીન
- 'ક' પ્રત્યય: ગુરુ + ક = ગુરુક, ગીત + ક = ગીતક
- 'ન' પ્રત્યય: ગુરુ + ન = ગુરુન, ગીત + ન = ગીતન
- 'ય' પ્રત્યય: ગુરુ + ય = ગુરુય, ગીત + ય = ગીતય

સમાસ (Samasa - Compound Words)

સમાસ એટલે બે અથવા ત્રણ થી વધુ શબ્દોનો એકમાં સમાવેશ. સમાસની પ્રક્રિયા શબ્દભંડોળનો મહત્વનો ભાગ છે.

તત્પુરુષ સમાસ (Tatpurusha Samasa):
- દેશ + પાણી = દેશપાણી (દેશનું પાણી)
- રાજા + પુત્ર = રાજાપુત્ર (રાજાનો પુત્ર)
- ગૃહ + પતિ = ગૃહપતિ (ગૃહનો પતિ)
- પુસ્તક + પાઠ = પુસ્તકપાઠ (પુસ્તકનો પાઠ)
- ગાય + દુધ = ગાયદુધ (ગાયનું દુધ)
- ગૌરવ + ચક્ષુ = ગૌરવચક્ષુ (ગૌરવનું ચક્ષુ)

બહુવ્રીહી સમાસ (Bahuvrihi Samasa):
- ગૌ + ચાર્ય = ગૌચાર્ય (ગૌમાં ગૃહવાળું)
- રાજ + કુંભ = રાજકુંભ (રાજાનું કુંભ)
- હસ્ત + પત્ર = હસ્તપત્ર (હસ્તનું પત્ર)
- મણિ + ઘટ = મણિઘટ (મણિથી ભરેલું)
- સૂર્ય + કાન્તિ = સૂર્યકાન્તિ (સૂર્ય જેવી કાન્તિ ધરાવતું)

અવ્યયીભાવ સમાસ (Avyayibhava Samasa):
- સંગ્રહ + પ્રવર્તે = સંગ્રહપ્રવર્તે (સંગ્રહમાં)
- ઉત્પાદન + પ્રવર્તે = ઉત્પાદનપ્રવર્તે (ઉત્પાદનમાં)
- વિદ્યા + અભ્યાસ = વિદ્યાભ્યાસ (વિદ્યામાં અભ્યાસ)
- સત્ય + અનુવાદ = સત્યાનુવાદ (સત્યનું અનુવાદ)

દ્વંદ્વ સમાસ (Dvandva Samasa):
- માતા + પિતા = માતાપિતા
- ભાઈ + બહેન = ભાઈબહેન
- સ્ત્રી + પુરુષ = સ્ત્રીપુરુષ
- જળ + અગ્નિ = જળાગ્નિ
- દિવસ + રાત્રિ = દિવસરાત્રિ

પરીક્ષા માટેની ટિપ્સ અને તૈયારીની રીત

શબ્દભંડોળની તૈયારી માટે કેટલીક મહત્વની ટિપ્સ:

1. દરરોજ 20-30 શબ્દો જુઓ અને તેમના સમાનાર્થી, વિરોધી શબ્દો અને એક શબ્દમાં પ્રગાશ યાદ કરો.

2. ઉપસર્ગ અને પ્રત્યયના નિયમો સમજો અને ઘણા ઉદાહરણો સાથે અભ્યાસ કરો.

3. સમાસની રચના સમજો અને દરેક પ્રકારના સમાસના ઉદાહરણો યાદ કરો.

4. લોકભાષિક શબ્દો અને તેમના સાહિત્યિક સ્વરૂપો યાદ કરો.

5. અંગ્રેજી શબ્દોના ગુજરાતી અર્થ મોઢે મોઢે રાખો.

6. વ્યુત્પન્ન શબ્દોનો અભ્યાસ કરો કેવી રીતે નવ શબ્દો બને છે.

7. પુસ્તકોમાંથી શબ્દો ઉતારો અને તેમનો અર્થ સમજો.

8. ગૂઢ અર્થ ધરાવતા શબ્દોની યાદી બનાવો.

9. નિયમિત રીતે પરાલોચના અને પ્રશ્નોનો અભ્યાસ કરો.

10. શબ્દકોશનો ઉપયોગ કરીને નવા શબ્દો શીખો.

11. મોટાભાગના પ્રશ્નો એક-બે વાર આવે છે, તેથી સ્થાયી જ્ઞાન મેળવો.

12. પ્રશ્નોના ઉત્તર સ્પષ્ટ અને સટીક હોવા જોઈએ.

Important facts

  • શબ્દભંડોળ એટલે ભાષામાં ઉપયોગમાં લેવાતા શબ્દોનો સંગ્રહ
  • સમાનાર્થી શબ્દો એવા શબ્દો છે જે એક જ અર્થ દર્શાવે છે
  • વિરોધી શબ્દો એવા શબ્દો છે જે એક બીજાના વિરુદ્ધ અર્થ ધરાવે છે
  • એક શબ્દમાં પ્રગાશ એટલે આપેલા શબ્દ માટે એક શબ્દમાં પર્યાય શોધવો
  • વ્યુત્પન્ન શબ્દો એક મૂળ શબ્દમાંથી બનતા શબ્દો છે
  • ઉપસર્ગ શબ્દની પ્રથમ ભાગમાં લાગે છે, પ્રત્યય પછી ભાગમાં લાગે છે
  • સમાસ એટલે બે અથવા ત્રણ થી વધુ શબ્દોનો એકમાં સમાવેશ
  • તત્પુરુષ, બહુવ્રીહી, અવ્યયીભાવ, દ્વંદ્વ એ સમાસના ચાર મુખ્ય પ્રકાર છે
