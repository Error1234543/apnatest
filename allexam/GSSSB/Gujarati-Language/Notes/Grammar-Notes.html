૧. સંધિ

સંધિ એ બે અથવા તેથી વધુ શબ્દો મળવાથી થતી ગુણવાન્યવદ્ધિ (પરિવર્તન) છે. સંધિમાં મુખ્યત્વે ત્રણ પ્રકાર આવે છે:

અ) વ્યંજન સંધિ: અન્ત્ય ак્ષર વ્યંજન હોય અને તેના પછીનો શબ્દ વ્યંજન સાથે શરૂ થાય ત્યારે થતી સંધિ.
- દા.ત.: વિદ્યા + આશ્રમ = વિદ્યાશ્રમ, નગર + ઇંદ્ર = નગેંદ્ર.

આ) અક્ષર સંધિ: અન્ત્ય akshar અનુસ્વાર / વिसર્ગ હોય અને પછીનો શબ્દ વ્યંજન સાથે શરૂ થાય ત્યારે.
- દા.ત.: દેહ + આત્મા = દેહાત્મા, નઋ + અન્ને = ન઱ેન્દ્ર.

ઇ) સ્વર સંધિ: આ સૌથી મહત્વપૂર્ણ અને બહુવિધ છે:
- અ+અ = આ (કલર+અનેક = કલાનેક)
- અ+આ = આ (બલ+આહા = બલાહા)
- અ+ઇ = ઈ (બલ+ઇન્દ્ર = બલેંદ્ર)
- અ+ઈ = એ (દેશ+ઈશ = દેશેશ)
- અ+ઉ = ઓ (બલ+ઉજ્જવલ = બલોજ્જવલ)
- અ+ઊ = ઔ (કલ+ઊર્મિ = કલૌર્મિ)
- આ+અ = આ (કલા+અનેક = કલાનેક)
- આ+આ = આ (કલા+આશ્રમ = કલાશ્રમ)
- આ+ઇ = ઈ (કલા+ઇન્દ્ર = કલાઈન્દ્ર)
- ઇ+અ = એ (વીણ+અકાર = વીણેકાર)
- ઈ+ઇ = ઈ (વીણા+ઇંદ્ર = વીણેંદ્ર)
- ઊ+અ = ઔ (કુંભ+અકાર = કુંભકાર → સંધિના નિયમો અનુસાર ઊ+અ=ઔ)
- ઔ+અ = ઔ
- ઋ+અ = રિ/રી (સુકൃત+અ = સુકૃત્ત/સુકૃત)
- એ+અ = એ (પ્રેમ+અભિમત = પ્રેમાભિમત)
- એ+ઇ = એઈ
- ઐ+અ = ઐ
- ઔ+અ = ઔ
- અ/આ+અનેક,અ/આ+ઇ=એ,અ/આ+ઈ=એ વગેરે.

ઉચ્ચાર સંધિ (અનુસ્વાર/વિસર્ગની સંધિ): અનુસ્વાર સામેના વ્યંજનના વર્ગમાં સ્પર્શ/અનુસ્વાર થાય છે.
- દા.ત.: દેહ + ઇન્દ્ર = દેહિંદ્ર → દેહિંદ્ર / નઋ + અન્ને = ન઱ેન્દ્ર.

સંધિ વિચ્છેદનો નિયમ: સંધિ પછી શબ્દોની વ્યાકરણ-યોગ્ય વિભાજન કરતા જાણો. ઉદા. 'વિદ્યાશ્રમ' = વિદ્યા + આશ્રમ.

૨. સમાસ (સરણી)

બે અથવા વધુ શબ્દો મળીને જે નવો અર્થ ધરાવતો તૃતીય શબ્દ બને તેને સમાસ કહે છે. સમાસમાં પ્રત્યય (દા.ત. -તા, -ત્વ, -પણ) નથી આવતો.

સમાસના પ્રકાર અને તેમના નિયમ:

૧. દ્વંદ સમાસ: બે અથવા વધુ શબ્દો સમાન અર્થ/સંબંધથી જોડાય; 'અને' ભાવ સૂચવે. વ્યાકરણ મુજબ દ્વંદ ચાર પ્રકારના:
- સેવી દ્વંદ: અગ્રપદ નાસ્તિક, ઉત્તરપદ નાસ્તિક (પુરુષ+પુરુષ)
- વિભાવ દ્વંદ: અગ્રપદ નર, ઉત્તરપદ સ્ત્રી → નર+સ્ત્રી = નરસત્રી
- સહુવય દ્વંદ: અગ્રપદ અને ઉત્તરપદ સમાન વચન/લિંગમાં હોય; 'અને' ભાવ સૂચવે. દા.ત.: રામા-શ્યામા, ગ્રામ-પંચાયત, પુરુષ-સ્ત્રી.
- અજ્જલ્ય દ્વંદ: શબ્દોની સંખ્યા ૩ કે તેથી વધુ હોય. દા.ત.: દેવ-મુનિ-ર્ષિ-પ્રધાન.

૨. કર્મધારય સમાસ (વિશેષણ-વિશેષ્ય): અગ્રપદ વિશેષણ, ઉત્તરપદ વિશેષ્ય. આખો સમાસ વિશેષ્યપદ થાય.
- દા.ત.: વટાળો (વટ+આળો = ઉત્તમ ટાટ), સુন্দર+કાંત = સુકાંત, ગ્રામ+નિવાસી = ગ્રામવાસી.

૩. તત્પુરુષ સમાસ (વિશેષણ-વિશેષ્ય, પણ કોઈ વાચ્ય-ભાવ હોય):
- અધિકરણ તત્પુરુષ: સ્થાન/સમય સૂચક. દા.ત.: ગૃહ + નિવાસ = ગૃહનિવાસ (ગૃહમાં નિવાસ).
- કર્તૃ તત્પુરુષ: કર્તૃ સૂચક. દા.ત.: રામા + નિવાસ = રામનિવાસ (રામાએ નિવાસ કરેલ).
- કર્મ તત્પુરુષ: કર્મ સૂચક. દા.ત.: ગાય + પ્રેમ = ગાયપ્રેમ.
- સપ્રદાન તત્પુરુષ: પ્રત્યય/પ્રતિપાદક. દા.ત.: પતિ + ભક્ત = પતિભક્ત.
- ભાવ તત્પુરુષ: ભાવ/ભાવક. દા.ત.: આગ + પ્રકાશ = આગપ્રકાશ.
- સપ્રદાન (આપત્તિ/પાત્ર): દા.ત.: વાણી + ભૂષણ = વાણીભૂષણ.

૪. બહુવ્રીહ સમાસ: સમાસનું પરિણામી શબ્દ બાહ્ય વસ્તુ/વ્યક્તિ સૂચવે. દા.ત.: કર્ણકુન્તલવાન = સુગ્રીવ (જેના કાનમાં કુન્તલ છે). અગ્રપદ વિશેષણ જેવા છે, પણ સમાસપદ અધિક બાહ્ય વસ્તુ.
- દા.ત.: મુખકમળ, શિરશ્ચંદ્ર, ભુજબળી, નેત્રકમળ.

૫. અવ્યયીભાવ સમાસ: અગ્રપદ અવ્યય/અવ્યય જેવું, પણ સમાસમાં અગ્રપદ અવ્યય નથી બનતું. દા.ત.: અર્ધચંદ્ર, ઉપરાજા, અક્ષપાણી, સાત્મ્યોદય.

શોધવિધિ: સમાસનો પ્રકાર શોધવા: વિચ્છેદન કરો → અગ્રપદ અને ઉત્તરપદનો ભાવ જુઓ → વિશેષણ-વિશેષ્ય, કર્મ, અવ્યયીભાવ, બહુવ્રીહ ઓળખો.

ગૂઢ સમાસ (સંસ્કૃત સમાસના આધારે ગુજરાતી):
- દા.ત.: ગંગાજળ (કર્મધારય), ગ્રામવાસી (કર્મ), ગ્રામીણ (તત્પુરુષ).

સામાન્ય ભૂલો: તત્પુરષ અને કર્મધારય વચ્ચેનો તફાવત સ્પષ્ટ: કર્મધારયમાં અગ્રપદ વિશેષણ, ઉત્તરપદ વિશેષ્ય, બંને બંધાયેલા. તત્પુરષમાં ઉત્તરપદ વ્યાકરણ રીતે કર્તૃ/કર્મ/સ્થાન સૂચવે છે.

૩. પ્રત્યય

પ્રત્યય એ શબ્દના અંતે બેસી નવો અર્થ અથવા નવું પદ સર્જે છે. પ્રત્યય વિશેષ કરીને આ પ્રકારનાં હોય છે:

૧. ભાવવાચક પ્રત્યય: ધાતુ/પ્રાચીન શબ્દમાં બેસી ભાવ/ક્રિયા સૂચવે. દા.ત.: -તા (ચાલ-તા = ચાલતા), -ત્વ (માનવ-ત્વ = માનવત્વ), -પણ (મનુષ્ય-પણ = મનુષ્યપણ), -ઈ (શીખ-ઈ = શીખી).

૨. કર્તૃવાચક પ્રત્યય: ક્રિયા કરનાર પાત્ર સૂચવે. દા.ત.: -કર (પૂજ-કર = પૂજક), -તારક (બચાવ-તારક = બચાવકારક).

૩. વિશેષણ/વિશેષ્ય રૂપક પ્રત્યય:
- -મય (પાણી+મય = પાન્યમય)
- -ઈન (ગુજરાત+ઈન = ગુજરાતી)
- -વાન (બળ+વાન = બળવાન)
- -પૂર્ણ (જ્ઞાન+પૂર્ણ = જ્ઞાનપૂર્ણ)

૪. સમાસ-ઉત્પન્ન પ્રત્યય (સમાસજ):
- -કાર (કલશ+કાર = કલશકાર)
- -પાલ (ગોપ+પાલ = ગોપાલ)
- -હાર (પતન+હાર = પતનાહાર)

૫. અન્ય પ્રત્યય:
- પ્રતિ + -યોગ્ય = પ્રતિયોગ્ય
- સં + -ઈપ = સંસીપ

મહત્વનો અંતર: પ્રત્યય-અવયવ અને સમાસ-અવયવ વચ્ચેનો તફાવત જાણવો: પ્રત્યય શબ્દના અંતે બેસે છે અને નવો પદાર્થ આપે છે; સમાસના અવયવો શબ્દો જુદા જુદા રહે છે પણ એક જ અર્થ બને.

પ્રત્યયની યોગ્યતા: પ્રત્યય સાચો છે કે સમાસ-અવયવ સાચો, તેની ઓળખ માટે: પ્રત્યય બાદ શબ્દનો સંપૂર્ણ અર્થ ન બનતો હોય તો સમાસ, અને પ્રત્યય બાદ નવું પદ બને તો પ્રત્યય.

૪. વિભક્તિઓ અને કર્તા-કર્મ-કર્ણ

ગુજરાતી વ્યાકરણમાં નામપદના છ વિભક્તિ બંધારણ હોય છે. દરેક વિભક્તિ એક અથવા તેથી વધુ સાર્થક બંધારણ ધરાવે છે.

પ્રથમ વિભક્તિ (મુલાકબાદ): કોણ? શું?
- ઉદા. રામ આવે છે. ગાય ખાએ છે.

દ્વિતીય વિભક્તિ (કર્મ): કિસે કયામાં? / શું?
- ઉદા. રામે ગાય ખવડાવી. મેં ફળ ખાધું.

તૃતીય વિભક્તિ (કર્ણ/કારણ): કોના દ્વારા? શું દ્વારા?
- ઉદા. રામ દ્વારા કામ થયું. લોહીના ડમ્બ થઈ રહ્યું છે.

ચતુર્થી વિભક્તિ (સમ્પર્ક/અધિકરણ): કયાં? કયા દિશામાં?
- ઉદા. રામ મંદિરે ગયો. લોકો રસ્તા પર ચાલ્યા.

પંચમી વિભક્તિ (ઉપલક્ષિત/તુલના): કોનાથી? શેનાથી?
- ઉદા. રામ ગઈ. મેં તેને પહેલેથી જોયું.

ષષ્ઠી વિભક્તિ (અધિકરણ સંબંધ): કોનું? શેનું?
- ઉદા. રામનો ગૃહ. ગાયનું દૂધ.

સપ્તમી વિભક્તિ (સ્થિતિ/મર્યાદા): ક્યાં? કયા સમયે?
- ઉદા. ગાયના પાસે બેસ્યો. હવેની વાત.

કર્તા-કર્મ-કર્ણ મહત્વ:
- કર્તા: પ્રથમ વિભક્તિના નામમાં જોડાયો. દા.ત. 'રામ' (પ્રથમ વિભક્તિ).
- કર્મ: દ્વિતીય વિભક્તિના નામ. દા.ત. 'ગાય' (દ્વિતીય).
- કર્ણ: તૃતીય વિભક્તિ. દા.ત. 'રામ દ્વારા' (તૃતીય).

વિભક્તિ સંબંધિત યાદ રાખવાપાત્ર: વિભક્તિ પ્રત્યય (પ્રથમ->ખંડ/કોઈ નહીં, દ્વિતીય->એ/ને, તૃતીય->દ્વારા/તરફથી, ચતુર્થી->ને/માં, પંચમી->તેથી, ષષ્ઠી->નો/ની/નું, સપ્તમી->માં/પર).

સામાન્ય ભૂલ: 'માં/પર' એ વિભક્તિના પરિણામી સ્વરૂપ છે; ત્રુટિ એ છે કે 'કર્મ'ની વ્યાખ્યા સાથે ઊડે છે — કર્મ હંમેશા દ્વિતીય વિભક્તિનું નામ છે, 'કર્મ' શબ્દનો અર્થ સમજવો જરૂરી છે.

૫. ક્રિયાપદ

ક્રિયાપદ એ ગુજરાતી વ્યાકરણનું મુખ્ય રચનાત્મક ઘટક છે. ક્રિયાપદના મુખ્ય ભાગો નીચે મુજબ:

અ) સમય અને વિભાજન:
- વર્તમાન: હું જાઉ છું.
- ભૂતકાળ: હું ગયો.
- ભવિષ્ય: હું જાઉં.
- સાપેક્ષ કાળ: હું જઈ ચૂક્યો, હું જતો હતો.

બ) પુરુષ અને વચનના વિભાજન:
- ઉત્તમ પુરુષ: હું, આપણે, તું, તમે, તેઓ, તે. આપ-ચિહ્ન: આપ + છું = આપ છું.
- મધ્યમ પુરુષ: તું, તમે, તેઓ, તે.
- અધમ પુરુષ: તે, તેણે, તેણે.
- વચન: એકવચન અને બહુવચન.

સ) રૂપો/આકારો:
- સાર્વજનિક ક્રિયા: હું જાઉં છું.
- સાંકેતિક ક્રિયા: હું જતો હતો.
- સંકલ્પ (આદર/નમ્રતા): હું જાઉં.

ડ) વાક્ય પ્રકાર મુજબ ક્રિયાપદ:
- સાધારણ વાક્ય: કર્તા + કર્મ + ક્રિયા.
- પ્રશ્ન વાક્ય: કર્તા ક્રિયા પૂછાતો.
- નાસ્તિક વાક્ય: નાસ્તિકતા સૂચવતો ક્રિયા.

ઈ) સહાયક ક્રિયાપદ: છે, હોય છે, થાય છે.
- દા.ત.: ગાઉ છે (કાર્ય).

ઉ] અપ્રવાહીક ક્રિયાપદ: કર્યા, કર્યો, કર્યું.

ઐ) સમાસિક ક્રિયાપદ: કરે છે, કરતા હોય છે.

ઔ) ક્રિયાવાચક ધાતુ + પ્રત્યય: ગા+તા=ગાતો, જા+ઈ=ગઈ.

મહત્વનો નિયમ: કર્તાનું પુરુષ અને વચન ક્રિયાપદમાં ઊભરે છે.

સામાન્ય ભૂલ: બહુવચન અને એકવચન, તથા પુરુષો વચ્ચે ક્રિયાપદની યોગ્યતા ભૂલ થાય છે — ઉત્તમ, મધ્યમ, અધમના વ્યાકરણ-અનુસાર સાચું રૂપ વાપરવું.

ઉદાહરણ:
- કર્તા (રામ) + કર્મ (ફળ) + ક્રિયા(ખાવા)= રામે ફળ ખાધું.
- સહાયક: કર્મ (ફળ) + ક્રિયા (ખવા) = ફળ ખાવાની વાત.

ક્રિયાપદનાં પ્રકાર: આદેશક, પ્રશ્નાર્થક, સંકલ્પ, ઇષ્ટ, નિયત, સંભાવ્યા, વાસ્તવિક અને ઇરાદા.

વ્યંજન + સ્વર યોગ્યતા: ક્રિયાપદનાં રૂપોમાં સંધિ જોજો — ગાઉ + ઈ = ગાઈ.

૬. અલંકાર

અલંકાર એ ગુજરાતી કાવ્ય અને પ્રબંધ સાહિત્યનો શોભાકારક અંગ છે. તેના મુખ્ય પ્રકાર નીચે મુજબ:

૧. શબ્દાલંકાર:
- અનુપ્રાસ: વર્ણસમાનતા. દા.ત.: મધુર મુખડું માધવ મધુરું.
- યમક: એક જ શબ્દ બે અર્થમાં. દા.ત.: 'ચાલી' એક ચાલી + ચાલી.
- પ્રતિપાત: વિરોધી અર્થમાં શબ્દોનો ઉપયોગ. દા.ત.: 'સુંદર દર્શન'.
- શ્રુત્યાન: શબ્દોનું મુખરણ-વિન્યાસ. દા.ત.: કવિતામાં શબ્દોનું ક્રમ.
- વિશેષ વિભાગ: અવ્યય-અર્થ, અવ્યય-વર્ગ.

૨. વાક્યાલંકાર:
- ઉત્પ્રેક્ષા: વાસ્તવિકતાથી વધુ પ્રતિબિંબ. દા.ત.: 'અંધકારમાં ચમકતું ચંદ્રમ ઊગતું'.
- રૂપક: સરખામણી કરતાં સીધી. દા.ત.: 'ચંદ્રમુખ'.
- સદૃશ્ય: સમાનતા દર્શાવતો. દા.ત.: 'ચંદ્ર જેવો ચમકે'.
- અતિશયોક્તિ: વાસ્તવિકતાથી વધુ કહેવાતો. દા.ત.: 'સમુદ્ર જેવો મન'.
- વિરોધાભાસ: વિરોધી ભાવ. દા.ત.: 'ચૂપચાપ ખડખડ'.
- અલંકાર (અભિવ્યક્તિ): ભાવનો અભિવ્યક્તિ. દા.ત.: 'ચમકતું ચંદ્રમ'.
- મંદ્રક: મંદ્ર રૂપ. દા.ત.: 'સુંદર સ્વર'.

મહત્વનો નિયમ: અલંકારના પ્રકાર અને તેમના ઉદાહરણો યાદ રાખવા માટે વ્યાખ્યાઓ અને ઉદાહરણો જોડીને જુઓ. પ્રશ્નોમાં સીધી ઓળખ + અલંકારનું નામ + ઉદાહરણ.

સામાન્ય ભૂલો: ઉત્પ્રેક્ષા અને રૂપક વચ્ચેનો તફાવત સ્પષ્ટ ન હોય તો ભૂલ થાય છે — ઉત્પ્રેક્ષામાં વાસ્તવિકતા વિનાનો વિસ્તાર, રૂપકમાં તુલનાનો સીધો ઉલ્લેખ.

૭. શબ્દભેદ અને સંસ્કૃત/તદ્ભવ શબ્દો

ગુજરાતી ભાષામાં શબ્દોના ઉત્પત્તિ સ્થાન મુજબ તેમનાં વર્ગીકરણ થાય છે. મુખ્યત્વે ત્રણ પ્રકારના શબ્દો:

૧. તત્સમ શબ્દ: સંસ્કૃત ભાષામાંથી મળેલા, મૂળ સંસ્કૃત રૂપ સાથે નજીકના જોડાયેલા. દા.ત.: ગૃહ, મંદિર, સંતોષ, આનંદ, પુસ્તક, વિદ્યા.

૨. તદ્ભવ શબ્દ: સંસ્કૃત શબ્દોના ગુજરાતી ઊર્જિત-રૂપાંતરણ. દા.ત.: ઘર (ગૃહ), મંદિર (મંદિર→મંદિર), મોટો (મહાન), ચંદ્રમા (ચન્દ્ર), કાજલ (કાજલ).

૩. દેશજ શબ્દ: ભારતીય-સ્થાનિક ભાષાઓમાંથી મળેલા. દા.ત.: ગાડી, બાળક, મોબાઈલ, રોડ, પાવર.

૪. વિદેશજ શબ્દ: અન્ય ભારતીય/પશ્ચિમી ભાષાઓમાંથી આયાત. દા.ત.: બુક (Book), કોમ્પ્યુટર, ટેલિફોન.

મહત્વના તફાવતો:
- તત્સમ એ મૂળ સંસ્કૃત સ્વરૂપ ધરાવે છે; તદ્ભવ એ ગુજરાતી ઉચ્ચારાત્મક પરિવર્તિત રૂપ.
- શબ્દભેદની યાદ રાખવી: સ્થાનિક શબ્દોમાં ઉદા. 'હાથ' (તત્સમ 'હસ્ત'), 'પગ' (તત્સમ 'પાદ').

મહત્વના ઉદાહરણો:
- તત્સમ: પુસ્તક, ચંદ્રમા, ગૃહ,
- તદ્ભવ: પુસ્ત, ચંદરમ, ઘર,
- દેશજ: ટીપો, બાળક, મોબાઈલ
- વિદેશજ: સર્વર, પ્રોગ્રામ

પરિક્ષા ટિપ્સ: સંસ્કૃત-ગુજરાતી શબ્દોની યાદદાસ્ત માટે નકલ-રૂપો બનાવો અને તફાવતો નોંધો.

૮. સ્ત્રીલિંગ રૂપો અને વિશેષણ

ગુજરાતી ભાષામાં વિશેષણ અને સ્ત્રીલિંગના નિયમો સમજવા આવશ્યક છે.

સ્ત્રીલિંગ રૂપોના નિયમો:
- -ો / -ા પ્રત્યય સાથેના પુરુષ પદોમાં સ્ત્રીલિંગ બનાવવા માટે:
- પુરુષ પદ + ઇ = સ્ત્રીલિંગ. દા.ત.: કાકો → કાકી, દોસો → દોસી, રામા → રામી.
- -ણું પ્રત્યય વાળા: દા.ત.: નાનું → નાની.
- -તું / -દું પ્રત્યય: સ્ત્રીલિંગમાં -તી/-દી. દા.ત.: ચંડતું → ચંડતી.
- મિશ્ર પ્રત્યયો: -વાન → -વાન, -પર → -પરી.

પુરુષ / સ્ત્રીલિંગ વિશેષણો:
- પુરુષ વિશેષણ: જેણે કાર્ય કર્યું (વિશેષણ).
- સ્ત્રીલિંગ વિશેષણ: જેણે કાર્ય કર્યું (સ્ત્રીલિંગ સૂચક).

ઉદાહરણો:
- રામ = રામો (પુ), રામી (સ્ત્રી)
- દોસો = દોસી
- ગાયક = ગાયકી (પુ/સ્ત્રી)
- વિદ્યાર્થી = વિદ્યાર્થિની (સ્ત્રી)

સામાન્ય ભૂલો: ઘણા વિદ્યાર્થીઓ સ્ત્રીલિંગ રૂપોમાં પ્રત્યય યોગ્ય નહીં મૂકે, જેમ કે 'રામા' -> 'રામી' નહીં પણ 'રામીઓ' કરે છે, જે વ્યાકરણની દષ્ટિએ ભૂલ છે.

૯. શબ્દાવલિ (પ્રાપ્તિ)

GSSSB ના ગુજરાતી ભાષા પ્રશ્નોમાં શબ્દાવલિ (synonyms, antonyms, idioms) મહત્વનો ભાગ રોકે છે.

સમાનાર્થી શબ્દો:
- ગ્રાહ્ય = સ્વીકાર્ય, ગ્રહણ = કેત્રણ
- સુંદર = કાંતિમાન, સુન્દર = સુચિત્ર
- શીઘ્ર = ઝડપી, ઝટપટ

વિરોધી શબ્દો:
- શુભ = અશુભ, સુખ = દુઃખ
- જ્ઞાન = અજ્ઞાન, સાચો = ખોટો

કડવો શબ્દો:
- ઘણા વ્યાકરણ પદો અને અર્થોની યાદ કરવી.

આદર્શ ઉદાહરણો:
- પ્રવચન = આદર્શ વાત
- રહસ્ય = ગૂઢ ભાવ

૧૦. ત્રુટિશોધ અને વ્યાકરણ સુધારો

GSSSB માં વ્યાકરણ યોગ્યતા અને ત્રુટિશોધ પ્રશ્નો આવે છે.

સામાન્ય ત્રુટિઓ:
- કર્તા-ક્રિયા વિચ્છેદન ભૂલ: રામ + ગયાં (ભૂલ) → રામ + ગયો (સાચું).
- વિભક્તિ ભૂલ: 'રામને' કર્મ હોવું જોઈએ, 'રામ' કર્તા.
- પ્રત્યય ભૂલ: સ્ત્રીલિંગમાં -ઈ બાદ 'ઓ' ન લાગે.
- સંધિ ભૂલ: સ્વર સંધિની યોગ્યતા ન ચાલે તેવો. દા.ત. 'ગાય+ઈંદ્ર' = 'ગાયેંદ્ર'.
- શબ્દભેદ ભૂલ: તત્સમ/તદ્ભવ ભેદ ગૂંચવણ.
- અલંકાર ભૂલ: ઉત્પ્રેક્ષા/રૂપક/અતિશયોક્તિ ભેદ ગૂંચવણ.

ત્રુટિશોધ પદ્ધતિ:
૧. કર્તા-ક્રિયા જોડો.
૨. વિભક્તિ સૂચક પ્રત્યય યોગ્ય છે.
૩. સંધિ/સમાસ યોગ્ય છે.
૪. સ્ત્રીલિંગ રૂપો યોગ્ય છે.
૫. અલંકાર યોગ્ય છે.

ઉદાહરણ:
- 'ગાયે જમણ' = 'ગાયે જમ્યું' (ભૂલ: કર્મ-ક્રિયા)
- 'રામા ગયો' = 'રામ ગયો' (ભૂલ: કર્તા પ્રત્યય)

Important facts

  • સંધિના મુખ્ય ત્રણ પ્રકાર: વ્યંજન સંધિ, અક્ષર સંધિ, સ્વર સંધિ — સ્વર સંધિના નિયમો ૨૦+ યાદ રાખવા.
  • સમાસના પાંચ પ્રકાર: દ્વંદ, કર્મધારય, તત્પુરુષ, બહુવ્રીહ, અવ્યયીભાવ — દરેકની વ્યાખ્યા અને ઉદાહરણ.
  • વિભક્તિઓની ૬ સાર્થક બંધારણ: પ્રથમ (મુલ), દ્વિતીય (કર્મ), તૃતીય (કર્ણ), ચતુર્થી (સમ), પંચમી (ઉપ), ષષ્ઠી (સંબંધ), સપ્તમી (સ્થિતિ).
  • ક્રિયાપદના પુરુષ (ઉત્તમ/મધ્યમ/અધમ) અને વચનના વિભાજન — ઉત્તમ પુરુષ 'આપ' + છું = આપ છું.
  • અલંકારના બે વર્ગ: શબ્દાલંકાર (અનુપ્રાસ, યમક, શ્રુત્યાન) અને વાક્યાલંકાર (રૂપક, ઉત્પ્રેક્ષા, અતિશયોક્તિ).
  • તત્સમ, તદ્ભવ, દેશજ, વિદેશજ શબ્દોનો ભેદ અને ઉદાહરણો.
  • સ્ત્રીલિંગ રૂપોના નિયમો: -ો/-ા પુરુષ -> -ી સ્ત્રી; -તું/-દું પુરુષ -> -તી/-દી સ્ત્રી.
  • શબ્દભેદ (સમાનાર્થી, વિરોધી) અને કડવો શબ્દોની યાદદાસ્ત.
