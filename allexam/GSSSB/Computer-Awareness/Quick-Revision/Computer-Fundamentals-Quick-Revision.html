Definitions

  • કોમ્પ્યુટર: ઇલેક્ટ્રોનિક મશીન જે માહિતી (input) લઈને પ્રોસેસ કરે છે અને પરિણામ (output) આપે છે. તે સચોટ, ઝડપી અને વિશ્વસનીય ગણતરી/પ્રક્રિયા કરી શકે છે.
  • સિંગલ-પ્રોસેસર કોમ્પ્યુટર: એક જ CPU વડે એક વખતે એક જ કાર્ય કરતું કોમ્પ્યુટર.
  • મલ્ટી-પ્રોસેસિંગ સિસ્ટમ: એક સાથે એકથી વધુ પ્રોસેસ ચલાવી શકતું, બહુ-CPU ધરાવતું કોમ્પ્યુટર.
  • માઇક્રોકોન્ટ્રોલર: કોમ્પ્યુટર, RAM, ROM અને I/O પોર્ટસ એક જ ચિપમાં સમાવેશ થયેલું નાનું એકમ, જે ઉપકરણોને નિયંત્રિત કરે છે (embedded systems).
  • માઇક્રોકોમ્પ્યુટર: સ્વાયત રીતે કામ કરી શકે તેવું, ઓછા ભાગોવાળું કોમ્પ્યુટર; વ્યક્તિગત વપરાશ માટેનું.
  • હેફ-કોમ્પ્યુટર (Mainframe): એકાએક એકથી વધુ ઉપયોગકર્તાઓને સરભર કરી શકતું, વિશાળ डेटા પ્રોસેસિંગ કરી શકતું શક્તિશાળી કોમ્પ્યુટર.
  • મિની કોમ્પ્યુટર: મેઇનફ્રેમની તુલનામાં નાનું પણ મલ્ટીયુઝર સપોર્ટ કરે તેવું મધ્યમ કદનું કોમ્પ્યુટર (અત્યારે ઓછું ઉપયોગમાં).
  • વર્કસ્ટેશન/પર્સનલ કોમ્પ્યુટર: એક વપરાશકર્તા માટેનું શક્તિશાળી કોમ્પ્યુટર, સામાન્ય રીતે CAD, GIS જેવા કાર્યો માટે.
  • સ્માર્ટ કોમ્પ્યુટર: AI-આધારિત, જે શીખી શકે, અનુકૂલન કરી શકે અને સ્વયં સંકલ્પ લઈ શકે (શોધાયેલ/વિકસીત સ્તર).

Key concepts

  • પ્રથમ દરજ્જો (First Generation, 1940-1956): વેક્યુમ ટ્યુબ (Vacuum Tube) આધારિત. ENIAC (1946), EDVAC, UNIVAC-I. ખૂબ મોટા કદ, વધુ ઉષ્મા, ઓછી વિશ્વસનીયતા. મેમોરી: Mercury delay lines, CR tubes.
  • બીજો દરજ્જો (Second Generation, 1956-1963): ટ્રાન્ઝિસ્ટર. આઇબીએમ 1401, 7090. કદ ઘટ્યું, વિશ્વસનીયતા વધી. પ્રોગ્રામિંગ: FORTRAN, COBOL, LISP.
  • ત્રીજો દરજ્જો (Third Generation, 1964-1971): સંકિર્ણ ઈંતેગ્રિટેડ સર્કિટ (IC - Integrated Circuit). આઇબીએમ 360 સিরિઝ. Keyboard/Monitorનો ઉપયોગ શરૂ. OS આવ્યા.
  • ચોથો દરજ્જો (Fourth Generation, 1971-વર્તમાન): VLSI (Very Large Scale Integration). માઇક્રોપ્રોસેસરનું આગમન. વ્યક્તિગત કોમ્પ્યુટર, GUI, ઓછું કદ વધુ શક્તિ. Pentium, Core series.
  • પંચમો દરજ્જો (Fifth Generation, વર્તમાન/ભવિષ્ય): ULSI, AI, parallel processing, quantum computingની શોધ. સ્માર્ટ ઉપકરણો, voice recognition.
  • CPU (Central Processing Unit): કોમ્પ્યુટરનો 'મગજ'. ALU (aritmetic/logic unit), CU (control unit), registers બનાવે છે. મુખ્ય ભાગો: Arithmetic Logic Unit, Control Unit, Register File, Cache (L1/L2/L3).
  • મધ્યમ પડ (Bus System): Data bus, Address bus, Control bus. Data busની જોકો કોમ્પ્યુટરની word size નક્કી કરે. Address busની જોકો maximum addressable memory નક્કી કરે.
  • ROM: Read Only Memory — non-volatile, પ્રોગ્રામ હંમેશા stored રહે. BIOS/CMOS આ ROMમાં હોય છે. MROM, PROM, EPROM, EEPROM/RAM typesમાં વહેંચાય.
  • RAM: Random Access Memory — volatile, ડાઠું બનતા data ખોવાઈ જાય. SRAM (fast, expensive), DRAM (common, need refresh).
  • ROM vs RAM મુખ્ય તફાવત: ROM non-volatile, programm/read-only; RAM volatile, read/write. BIOS માહિતી ROMમાં, ચાલતો પ્રોગ્રામ RAMમાં.
  • કેશ મેમોરી (Cache): CPU-અને- RAM વચ્ચેનું fast buffer. L1 cache CPU chip પર, L2 અને L3 બહાર પણ હોઈ શકે.越小 જલ્દી.
  • બાહ્ય મેમોરી (Secondary Storage): HDD (mechanical disk), SSD (solid-state, fast), optical (CD/DVD/Blu-ray), magnetic tape. Non-volatile, સ્થાયી.
  • માઉસ (Mouse): pointing device, optical/લેઝર. ડિવાઇસી ડિસ્ટલ્યુશન DPIમાં. Trackball, touchpad વિવિધ પ્રકાર.
  • કીબોર્ડ: QWERTY layout, PS/2 અને USB connectors. 101/104 keys. Function keys, modifier keys (Shift, Ctrl, Alt).
  • મોનિટર/ડિસ્પ્લે: CRT (purano), LCD/LED, IPS, OLED. resolution, refresh rate (Hz), pixel pitch.
  • પ્રિન્ટર: Inkjet, Laser, Dot-matrix. DPI (dots per inch), ppm (pages per minute).
  • સ્કેનર: Optical Scanner, CIS, CCD. Resolution dpiમાં. Flatbed, sheet-fed, handheld પ્રકાર.
  • USB: Universal Serial Bus. Versions: 1.1 (12 Mbps), 2.0 (480 Mbps), 3.0/3.1 (5 Gbps+), 3.2, Type-C. Plug-and-play, hot-swappable.
  • FireWire (IEEE 1394): high-speed serial, video camcorders માટે. USB પહેલા વપરાયું.
  • PCMCIA/CardBus: laptop expansion (memory cards, modems). Aba ઓછું ઉપયોગ.
  • BIOS: Basic Input-Output System. POST (Power-On Self Test) જવાબદાર. CMOS setup માં settings સ્ટોર થાય. CMOS battery (CR2032).
  • CPU parameters: clock speed (GHz), cores (Dual/Quad/Hexa/Octa), thread count, cache size (L1/L2/L3), TDP (wattage), socket type.
  • Operating System: System software that manages resources. Types: single-user/single-task, single-user/multi-task, multi-user, real-time (RTOS), network OS. Common: Windows, Linux, macOS, Android, iOS.
  • Software categories: System software, application software, programming software (compilers, interpreters, assemblers).
  • Programming language generations: Machine language (1GL, binary), Assembly (2GL), High-level (3GL — C, Java, Python), Very-high-level (4GL), Natural-language/AI (5GL).
  • Number systems: Binary (base-2, digits 0-1), Octal (base-8, digits 0-7), Decimal (base-10, digits 0-9), Hexadecimal (base-16, digits 0-9,A-F).
  • Conversion: Decimal→Binary (repeat division by 2), Binary→Decimal (powers of 2), Octal↔Hex via Binary (group 3/4 bits).
  • Memory units: bit → nibble (4 bits) → byte (8 bits) → KB (1024 bytes) → MB → GB → TB → PB → EB → ZB → YB.
  • ASCII: American Standard Code for Information Interchange. 7-bit (128 chars) or extended 8-bit (256 chars). Unicode (16-bit min, UTF-8), ASCII ને cover કરે.
  • Instruction cycle: Fetch → Decode → Execute → Store (Fetch-Decode-Execute cycle). Cycle time = clock period × cycles per instruction.
  • Computer architecture types: Von Neumann (stored program, shared memory for instructions & data), Harvard (separate buses/memory for instructions & data). Modern CPUs often modified Harvard with unified caches.

Important facts

  • ENIAC — world's first general-purpose electronic digital computer, built 1943-1946 at University of Pennsylvania. Used ~18,000 vacuum tubes, weighed ~30 tons. Designed by Mauchly & Eckert. Input: punched cards.
  • UNIVAC-I — first commercial computer delivered to US Census Bureau (1951). Vacuum tube, used mercury delay-line memory.
  • Hopper invented COBOL (1959) and coined 'debugging' after removing a moth from relay of Mark II (1947).
  • Charles Babbage — 'Father of Computer', designed Analytical Engine (1837) with Arithmetical Logic Unit, Control Flow, Memory. Ada Lovelace wrote first algorithm for it.
  • Transistor invented 1947 by Bardeen, Brattain, Shockley at Bell Labs. Replaced vacuum tubes, reduced size and heat.
  • Jack Kilby (Texas Instruments) integrated circuit (1958); Robert Noyce (Fairchild) developed planar IC (1959).
  • Intel 4004 (1971) — first microprocessor (4-bit). Intel 8080 (1974) led to personal computer revolution.
  • First PC: IBM 5150 (1981) with Microsoft DOS. Apple Macintosh introduced GUI (1984).
  • Intel Core i-series naming: i3 (budget), i5 (mid), i7 (high), i9 (enthusiast). AMD uses Ryzen 3/5/7/9 series.
  • Modern SSDs use NAND flash memory; no moving parts → silent, shock-resistant, faster than HDD.
  • CMOS battery (CR2032) lasts 3-5 years; depletion causes BIOS settings loss, system clock reset.
  • Motherboard chipset: Northbridge (handled CPU-RAM-GPU) + Southbridge (handled I/O, SATA, USB). Modern CPUs integrate Northbridge functions into the CPU itself.
  • POST runs every boot; beep codes indicate hardware status. Different motherboards have different beep patterns.
  • Cache memory is measured in KB/MB per core. Typical desktop CPU: 256KB–1MB L1, 2–16MB L3.
  • Word length (architecture size): 8-bit, 16-bit, 32-bit, 64-bit. Determines max RAM addressable and register size.
  • Input devices: mouse, keyboard, scanner, barcode reader, OCR, MICR, light pen, digitizer, joystick, touchscreen, webcam, microphone.
  • Output devices: monitor, printer, plotter, speaker, projector, VR headset.
  • Printer PPM (Pages Per Minute) measures laser printer speed; Inkjet measured in CPS (characters per second) historically.
  • Network interface card (NIC): MAC address (48-bit), IP address assignment (DHCP/static). Ethernet standards: 10/100/1000 Mbps (Fast/Gigabit Ethernet).
  • Wi-Fi standards: 802.11b (11 Mbps), g (54 Mbps), n (300+ Mbps), ac (Wi-Fi 5, up to 1 Gbps), ax (Wi-Fi 6, 9.6 Gbps theoretical).
  • Storage technologies: IDE/PATA (old, ribbon cable), SATA (modern, thin cable, 6 Gbps), NVMe/PCIe (fastest for SSDs).
  • RAM module types: SIMM (old), DIMM (desktop), SO-DIMM (laptop). DDR generations: DDR (2000), DDR2, DDR3, DDR4 (current mainstream), DDR5 (latest).
  • Cache coherency protocols: MESI ensures consistency between multiple CPU caches.
  • Firmware: embedded software stored in non-volatile memory (EEPROM/Flash). BIOS, UEFI are firmware examples.
  • UEFI: modern replacement for legacy BIOS. Supports GUI, large drives (>2TB), secure boot, faster boot times.
  • Bit: smallest unit of data (0 or 1). Byte = 8 bits. Nibble = 4 bits.
  • ASCII code for 'A' = 65, 'a' = 97, '0' = 48 (decimal values).
  • ALU operations: addition, subtraction, multiplication, division, AND, OR, NOT, XOR, shift, compare.
  • CU operations: directs data flow, decodes instructions, coordinates timing, controls peripherals via control signals.
  • Interrupt: signal to CPU to pause current task and handle higher priority event. Can be hardware (I/O request) or software (system call).
  • Polling vs Interrupt: Polling continuously checks device; interrupt signals when ready. Interrupt is more efficient.
  • Clock speed (GHz): how many cycles per second CPU performs. Not sole determinant of performance — core count, architecture, cache matter too.
  • TDP (Thermal Design Power): max heat CPU can dissipate. Measured in watts. Important for cooling solutions.
  • Overclocking: increasing CPU clock speed beyond rated value. Increases performance but also heat and power consumption, may void warranty.
  • S.No. in history: UNIVAC I (first commercial), ENIAC (first electronic), EDVAC (stored-program concept), BINAC (first programmable electronic computer, 1949).
  • Computer viruses: first created 1983 (Fred Cohen). First widespread PC virus: Brain (1986, Pakistan). Worms spread independently; viruses need host file.
  • Key file extensions: .exe (executable), .dll (dynamic link library), .sys (driver), .txt (text), .doc/.docx (Word), .pdf (Adobe), .mp3/.wav (audio), .mp4/.avi (video).
  • Operating system functions: process management, memory management, file management, device management, security, user interface. Kernel is core component.
  • Linux distributions for exams: Ubuntu (most popular), Red Hat (enterprise), Debian, CentOS, Fedora, Kali (security). Source: C language.
  • Windows versions: 95/98/XP/Vista/7/8/10/11 (chronological). NT kernel, GUI-based, closed source (Microsoft).
  • DOS (Disk Operating System): command-line based, single-user, single-task. MS-DOS, PC-DOS. Replaced by Windows.
  • Real-time OS (RTOS): guarantees response within strict time constraints. Used in medical devices, aircraft, industrial control. Examples: VxWorks, QNX, FreeRTOS.

Memory aids

  • બરફ → ટ્રાન્ઝિસ્ટર → IC → VLSI → ULSI sequence યાદ રાખો: 'Bitter Tomatoes In Cold Vaults Under Lighting Illumination' (1st-5th gen shorthand).
  • CPU શબ્દકોશ: ALU = ગણતરીનું હાર્ટ, CU = મગજનું બ્રેઇન. 'Control Unloads instructions, ALU Does calculations.'
  • ROM-RAM diff: 'ROM = R only Memory (રેકોર્ડેડ), RAM = રીસાઇકલ થાય તે (volatile)'.
  • બસ જોકો યાદ: 'Data 64, Address 40, Control 16' — common desktop bus widths.
  • Memory hierarchy pyramid: Registers → Cache → RAM → SSD/HDD → Optical/Tape. 'ઉપર જલ્દી, નીચે સસ્તું/વધુ ક્ષમતા.'
  • ASCII mnemonic: 'A=65, a=97' → 'Capital A is at 65 because capital letters come first (lower numbers). Lowercase starts at 97 (after 32 space + 10 digits = 42, plus uppercase 26 = 68... close enough — remember 97 as anchor point).
  • Instructon cycle: 'Finds Data, Decodes Task, Executes Action, Stores Result' (FDDS).
  • USB version progression યાદ: '1.1 ધીમો, 2.0 વેગવાન, 3.0 ઝડપી, Type-C બધું' → સંક્ષિપ્ત મેમોરી.
  • BIOS vs UEFI: 'BIOS = purano, UEFI = nuro'; 'BIOS is Blue (legacy BIOS screen), UEFI is colorful (graphical).
  • Number systems conversion trick: Binary ↔ Octal (groups of 3), Binary ↔ Hex (groups of 4). 'ઓક્ટલ → 3-બિટ જૂથ, હેક્સ → 4-બિટ જૂથ.'
  • RAM types: 'S Static (ફાસ્ટ, મોંઘો), D Dynamic (ડીફાઉલ્ટ, સસ્તો)' — SRAM vs DRAM.
  • Clock speed note: 'GHz નો રેટ, પણ ડબલ કોર + કેશ = મોટો ફેર.' Performance is multi-factor.
  • Peripheral types grouping: Input = 'માહિતી અંદર'; Output = 'માહિતી બહાર'; Storage = 'માહિતી રાખે'; Communication = 'કonektિવિટી'.

Exam tips

  • GSSSB computer questions mostly test basic definitions, generations, device types, number system conversions, and simple hardware concepts. Focus on one-line fact accuracy.
  • Number system conversion questions (dec→bin, bin→dec, oct→hex) are almost guaranteed — practice 5-10 of each daily.
  • Memory hierarchy (Registers > Cache > RAM > Secondary Storage) ordering question regularly asked.
  • Input/Output device classification — know whether each listed device is input, output, both, or storage.
  • Be prepared to match device with its interface type (e.g., printer → parallel/USB, monitor → VGA/HDMI/DisplayPort, NIC → RJ-45).
  • BIOS/CMOS related questions: CMOS battery role, POST, BIOS function. Know that CMOS stores settings and needs battery backup.
  • USB version speeds order: USB 1.1 < 2.0 < 3.0. Type-C is form factor, not speed standard — watch this trap carefully.
  • Always read the question stem fully: 'વર્તમાન વપરાશમાં નથી' vs 'વપરાશમાં છે', 'નોન-વોલેટાઇલ' vs 'વોલેટાઇલ'.
  • For OS questions, know basic functions of OS (resource management) and distinguish between system/app software simply.
  • Shortcuts: Ctrl+C (copy), Ctrl+V (paste), Ctrl+X (cut), Ctrl+Z (undo), Ctrl+A (select all), Alt+F4 (close window), Ctrl+N (new). Very frequently asked.
  • Resolution terms: 1920×1080 = Full HD, 3840×2160 = 4K UHD, 1280×720 = HD. These numbers are standard.
  • Know that 1 KB = 1024 bytes (not 1000) in binary-based memory measurement (exams use this convention).
  • Generation dates order: 1st (vacuum tube, 1940s), 2nd (transistor, 1950s-60s), 3rd (IC, 1960s-70s), 4th (VLSI, 1970s-90s), 5th (AI/Ultra, 2000s+).
  • CPU terminology traps: 'multi-core' ≠ 'multi-threaded' (hyperthreading simulates multiple cores but isn't identical).
  • For questions on number systems, always verify answer by converting back to decimal. This prevents silly mistakes.
  • GSSSB pattern focuses on 'which is NOT' type questions — practice elimination strategy.

Common traps

  • RAM vs ROM: RAM non-volatile નથી; ROM volatile નથી. ઘણા વિદ્યાર્થીઓ ઉલટું યાદ રાખે છે.
  • Clock speed (GHz) એ alone performance નક્કી કરતું નથી. Core count, cache, IPC (instructions per clock) પણ મહત્વના.
  • CPU word size (32-bit vs 64-bit) ≠ storage size. 64-bit CPU 64-bit data વ્યવહાર કરે.
  • USB Type-A vs Type-C: Type-A rectangular, Type-C oval/reversible. Type-C ≠ faster automatically (depends on version).
  • RAM容量 ≠ Storage capacity. RAM is volatile working memory; Storage (HDD/SSD) is permanent.
  • Processor names: Intel Core i3/i5/i7/i9 are different product lines, not different models within same line. AMD: Athlon, Ryzen 3/5/7/9, EPYC.
  • ASCII 7-bit (128 chars) vs Extended ASCII 8-bit (256 chars). Unicode ≠ ASCII; Unicode covers far more characters (all world scripts).
  • FireWire ≠ USB. FireWire (IEEE 1394) was separate standard, faster than USB 2.0 but lost market to USB 3.0+.
  • HDD vs SSD: HDD has moving parts, SSD has none. SSD is faster but more expensive per GB.
  • Monitor resolution ≠ screen size. 24-inch monitor can have 1080p or 4K resolution. Pixel density matters.
  • BIOS ≠ UEFI. Legacy BIOS uses 16-bit code; UEFI uses 32/64-bit, supports larger drives, Secure Boot, graphical UI.
  • Single-cycle vs Multi-cycle CPU: Single-cycle executes one instruction per clock (rare); most modern CPUs are multi-cycle pipelines.
  • Virtual memory uses hard drive space as 'fake RAM'. Not actually faster than RAM — it slows down when overused.
  • POST beep codes vary by manufacturer. Award, AMI, Phoenix have different patterns — never memorize specific beep patterns across brands.
  • Register ≠ Cache ≠ RAM. Registers are inside CPU, fastest; cache is outside CPU but on board; RAM is on motherboard slots.
  • Instruction set architecture (ISA): x86 (Intel/AMD), ARM (mobile, Apple Silicon), MIPS, RISC-V. Different ISAs not binary-compatible.
  • Compiler ≠ Interpreter. Compiler translates entire program before execution; interpreter translates line-by-line during execution.
  • File extensions: .exe = executable (runs programs), .dll = shared library (used by multiple programs), .sys = system driver.
  • OS ≠ Application software. Windows/Linux are OS; Word/Excel are applications running ON the OS.
  • RAM modules: DIMM (desktop, larger), SO-DIMM (laptop, smaller). Not interchangeable without adapter.
  • CPU socket types differ (LGA 1200, AM4, LGA 1700). Processor must match motherboard socket — they are NOT universal.
