MS Office - Quick Revision (GSSSB)

Definitions

  • MS Office એ મઈક્રોસોફ્ટ દ્વારા વિકસાવેલો ઑફિસ સ્યુટ (Office Suite) છે, જેમાં ડોક્યુમેન્ટ બનાવવા, ડેટા મેનેજ કરવા, પ્રઝેન્ટેશન તૈયાર કરવાના પ્રોગ્રામનો સમાવેશ થાય છે.
  • Microsoft Word: ટેક્સ્ટ-આધારિત ડોક્યુમેન્ટ બનાવવા અને સંપાદિત કરવા માટેનો પ્રોગ્રામ છે. ફાઇલ એક્સ્ટેન્શન .doc અને .docx છે.
  • Microsoft Excel: સ્પ્રેડશીટ અનુપ્રયોગ (Spreadsheet Application) છે, જ્યાં ડેટા કોષ (Cell) ના રૂપમાં ગ્રિડમાં સંગ્રહિત થાય છે. ફાઇલ એક્સ્ટેન્શન .xls અને .xlsx છે.
  • Microsoft PowerPoint: પ્રઝેન્ટેશન તૈયાર કરવા માટેનો પ્રોગ્રામ છે. સ્લાઇડ આધારિત પ્રઝેન્ટેશન બનાવવામાં આવે છે. ફાઇલ એક્સ્ટેન્શન .ppt અને .pptx છે.
  • રિબન (Ribbon): MS Office 2007 થી શરૂ થયેલ ટૂલબાર ઇન્ટરફેસ છે, જે ટેબ્સ અને જુથો (Groups) માં વિભાજિત હોય છે.
  • કોષ (Cell): Excel માં રો (Row) અને કોલમ (Column) નાછેદબિંદુ પર બનતો નાની ખાના, જે ડેટા સંગ્રહિત કરે છે. ઉદાહરણ: A1, B5.
  • સ્લાઇડ (Slide): PowerPoint માં વ્યક્તિગત પેજ જે પ્રઝેન્ટેશનનું એક પૃષ્ઠ બનાવે છે.

Important facts

  • Microsoft Excel શ્રેષ્ઠ સ્પ્રેડશીટ સોફ્ટવેર ગણાય.
  • MS Word ફાઇલ એક્સ્ટેન્શન .docx છે.
  • MS Excel ફાઇલ એક્સ્ટેન્શન .xlsx છે.
  • MS PowerPoint ફાઇલ એક્સ્ટેન્શન .pptx છે.
  • Ctrl+C → Copy, Ctrl+V → Paste, Ctrl+X → Cut.
  • Ctrl+Z → Undo, Ctrl+Y → Redo.
  • F2 → Excelમાં કોષ સંપાદન мод (Edit Mode).
  • F4 → પુનરાવર્તન અથવા $લૉક (Absolute Reference).
  • F5 → પ્રઝેન્ટેશન શરૂ (PowerPoint).
  • F7 → Spelling check.
  • Ctrl+F2 → Print Preview.
  • Alt+F4 → Application બંધ કરે.
  • Ctrl+G → Go To dialog (Excel/Word).
  • Ctrl+Shift+& → Hidden sheet દેખાડે (Excel).
  • Ctrl+9 → Hidden row (Excel), Ctrl+0 → Hidden column.
  • Ctrl+1 → Format Cells dialog (Excel).
  • Ctrl+L → ડેટા Table બનાવે છે (Excel).
  • AutoSum બટન → =SUM() ઇન્સર્ટ કરે.
  • Word-wrap: ટેક્સ્ટને Multi-line કોષમાં દેખાડે (Excel).
  • Wrap Text એ Excelમાં ડેટાને એક જ કોષમાં અનેક પંક્તિમાં બતાવે.
  • Merge & Center: બહુ કોષો એક કરી કેન્દ્રમાં લખે.
  • Flash Fill (Ctrl+E): પેર્ટર્ન પારખી ડેટા ભરે (Excel 2013+).
  • Excelમાં default Sheet નામ: Sheet1, Sheet2, Sheet3.
  • Maximum rows in modern Excel: 1,048,576; Maximum columns: 16,384 (XFD).
  • PPT માં Slide Sorter View (View tab) — બધી સ્લાઇડ્સ એકસાથે દેખાય.
  • Notes Page View (Word) — નોંધ સાથેનો ડોક્યુમેન્ટ પ્રિન્ટ કરી શકાય.
  • Read Mode (Word/Office): Full-screen, પેજ જોવા માટેનો સરળ દૃશ્ય.
  • Task Pane = ડાબી/જમણી બાજુમાં ખુલ્લો રહેતો પેનલ જેમાં options મળે.
  • Dialog Box Launcher = નાનો ચેપ્પર ચિહ્ન જે રિબનના જુથના છેડે હોય.
  • Quick Access Toolbar = ઉપર ડાબે સ્થિત, customisable toolbar.

Memory aids

  • Shortcut mnemonic: C = Copy (ઉભી C), V = Paste (▼ નીચે ઉતરે), X = Cut (ખાડો/ત્રાટકી). Z = Undo (પાછળ), Y = Redo (આગળ).
  • Excel formula = સાથે શરૂ, જેમ =SUM(A1:A5).
  • 'P' for PowerPoint Presentation, 'X' for eXtended spreadsheet (modern Excel), 'W' for Word (no common shortcut but WYSIWYG).
  • F-keys sequence: F2=Edit, F4=Repeat/Lock, F5=Show, F7=Spell.
  • Ctrl+9 = Row Hide, Ctrl+0 = Column Hide (9+0=9 rows/columns, એકદમ યાદ રાખવા જેવું).
  • C-X-C-V order: Cut, Copy, Copy, Paste — આ યાદ રાખો.

Exam tips

  • GSSSB માં MS Office પ્રશ્નો મોટાભાગે Shortcut keys, File extensions, Ribbon tabs, Basic terms પરથી આવે છે.
  • આપણે Ctrl+X/C/V, Ctrl+Z/Y, F2/F4/F5/F7 જેવી કીઓ બરાબર યાદ કરવી.
  • File format પ્રશ્ન: .docx vs .xlsx vs .pptx — સરળ પણ સાવચેત.
  • Excel reference પ્રશ્ન: $A$1 vs A1 vs $A1 — Absolute/Mixed/Relative સમજવું.
  • Ribbon tab → functionality જોડાણ પરથી પ્રશ્ન આવે: Insert=Shape/Table, View=Macros/Panes, etc.
  • પ્રશ્નમાં 'wrong statement' પૂછે તો ગેરમાન્ય વિકલ્પ શોધવો; ગૂંચવણ ટાળવી.
  • F-key પ્રશ્નો કોન્ફ્યુઝન કરાવે છે — F2/F4/F5/F7/F11/F12 સ્પષ્ટ યાદ રાખો.
  • Excel max rows/columns, Default sheet count જેવા numeric facts ચોક્કસ રાખવા.
  • Slide Master / Transition / Animation વચ્ચેનો તફાવત સમજવો.

Common traps

  • કિદ્દા: Ctrl+C = Cut ગેરમાન્ય છે; Ctrl+C = Copy છે, Ctrl+X = Cut છે.
  • કિદ્દા: F5 = Spelling check ગેરમાન્ય છે; F7 = Spelling, F5 = Slide Show.
  • કિદ્દા: .pdf MS Office નો native ફોર્મેટ નથી.
  • કિદ્દા: Excel માં $A$1 એ Absolute reference છે; જો ફક્ત $A1 એ Mixed છે (કોલમ lock, row relative).
  • કિદ્દા: Rows = હોરિઝોન્ટલ (આડી), Columns = વર્ટિકલ (ઊભી) — ઉલટું ન લેવું.
  • કિદ્દા: Word માં Ctrl+Enter = Page Break છે, Section Break નહીં.
  • કિદ્દા: Ctrl+Z એક વાર પress કરવું Undo એક જ ક્રિયા પાછી કરે, સતત press કરવાથી ઘણી પાછી.
  • કિદ્દા: Merge & Center એ ડેટા ધરાવતા બધા કોષો (ખાલી સિવાય) કપાઈ જાય; માત્ર upper-left નો ડેટા રહે.
  • કિદ્દા: AutoFit ≠ Auto Fill; AutoFit = content મુજબ width/height બદલે, Auto Fill = series ભરે.
  • કિદ્દા: Print Preview (Ctrl+F2) અને Print (Ctrl+P) અલગ છે.
