મિક્રોસોફ્ટ ઓફિસનું પરિચય

મિક્રોસોફ્ટ ઓફિસ (Microsoft Office) એ મિક્રોસોફ્ટ કર્પોરેશન દ્વારા વિકસાવેલ ઓફિસ સ્યુટ (Office Suite) છે, જે વિવિધ પ્રકારના દસ્તાવેજો બનાવવા, સંબંધિત ડેટાને રજૂ કરવા, પ્રેઝન્ટેશન તૈયાર કરવા અને ડેટા ટ્રેક કરવા માટેની ઉપકરણો ધરાવે છે.

મુખ્ય ઘટકો:
• Word Processor (શબ્દ સંભાળક) — Microsoft Word: લેખન, હસ્તાક્ષર સંપાદન, દસ્તાવેજ સ્રાવ અને છાપનું કાર્યક્ષમ પ્લેટફોર્મ.
• Spreadsheet (ફાળવણી-પત્ર) — Microsoft Excel: આંકડાકીય ગણતરી, આલેખન, ડેટા વ્યવસ્થાપન અને ફંક્શન.
• Presentation — Microsoft PowerPoint: સલાહકાર પ્રસ્તુતિઓ, સ્લાઇડ શો, એનિમેશન.
• Data/Reference — Microsoft Access: સંબંધિત ડેટાબેઝ (Relationship Database).
• Others — Outlook (ઈમેલ/કેલેન્ડર), OneNote (નોંધ), Publisher (પબ્લિકેશન).

Office સંસ્કરણો: Office 2003, 2007, 2010, 2013, 2016, 2019, 2021 અને Microsoft 365 (નવું નામ: Office 365). 2007 સુધી ડેટા-ફાઈલો .doc, .xls, .ppt સ્વરૂપમાં હતા; 2007 થી .docx, .xlsx, .pptx સ્વરૂપ (ZIP પાયબેઝ).

ગૂરુત્વ: GSSSB પરીક્ષામાં MS Office એ 'Computer Awareness' વિભાગનો મહત્વપૂર્ણ ભાગ છે — Word, Excel, PowerPoint ના મૂળભૂત ઉપયોગ, શોર્ટકટ કી, મેનૂ, ફંક્શન અને ફાઈલ સ્વરૂપોથી સંબંધિત પ્રશ્નો આવે છે.

Microsoft Word — સંપૂર્ણ અભ્યાસ

Microsoft Word એ શબ્દ પ્રક્રિયાક (Word Processor) છે. તે દસ્તાવેજ (Document) બનાવવા, સંપાદિત કરવા અને પ્રકાશન માટે વપરાય છે.

मुख्य विशेषताઓ:
• ટેક્સ્ટ એન્ટ્રી, ફોન્ટ સ્તર, ચહ્ન, રંગ.
• પેરાગ્રાફ સ્ટાઇલ: સોડાવણી (Indentation), જગ્યા, ક્રમ (Bullets/Numbering).
• ટેબલ સમાવિષ્ટ.
• હેડર/ફૂટર, પેજ નંબર, ગુંચવણ (Header/Footer).
• Mail Merge: એક સ્રોત ડેટામાંથી અનેક સરનામું પત્ર.
• Spelling & Grammar Check.
• Find & Replace, Go To.
• Headers, Footers, Watermark, Page Setup (Size, Margin, Orientation, Columns).
• Tables: Insert Table, Merge/Split Cells, Sort Data, Convert Text to Table.
• Styles and Themes.

માઉસ સૂચક:
• ઊંચો વીંધી (I-beam) — ટેક્સ્ટ બિંદુ.
• ઝાંખો બ્લોક — પસંદગી (Selection).
• ચતુષ્ફલક (Arrow) — સામાન્ય.

.doc (पुरानो), .docx (नवें), .rtf (Rich Text Format), .pdf, .txt, .odt (OpenDocument Text), .html.

• File format મહત્વનું.
• Mail Merge, Table, Header/Footer, Page Setup પરીક્ષામાં આવે છે.

Microsoft Excel — સંપૂર્ણ અભ્યાસ

Microsoft Excel એ સ્પ્રેડશીટ (ફાળવણી-પત્ર) છે, જે ડેટાને rows અને columns માં સંગ્રહિત કરે છે. પ્રતિ ચાવરસને કોષ (Cell) કહે છે, જે Column Letter + Row Number વડે ઓળખાય છે (દ.ઉ. A1, B5).

મૂળભૂત શબ્દો:
• Workbook: Excel ફાઈલ.
• Worksheet: Workbook નો એક પેજ.
• Cell: Intersection of row and column.
• Range: કોષોનો સમૂહ, દ.ઉ. A1:D10.
• Row: આડી પંક્તિ (numbered).
• Column: ઊભી પંક્તિ (lettered).
• Formula: =ચલનાથી શરૂ થતી ગણતરી.
• Function: પૂર્વવ્યાખ્યાયિત ગણતરી, દ.ઉ. SUM, AVERAGE.
• Reference: Cell reference (સાપેક્ષ / નિરપેક્ષ).

સાપેક્ષ/નિરપેક્ષ સંદર્ભ (Relative/Absolute Reference):
• A1 — સાપેક્ષ (Relative): સ્વયં ચાલુ.
• $A$1 — નિરપેક્ષ (Absolute): બંધ.
• A$1 — ભાગશ: Column સ્વતંત્ર, Row અચળ.
• $A1 — ભાગશ: Column અચળ, Row સ્વતંત્ર.
F4 કી દ્વારા સંદર્ભ બદલાય છે: A1 → $A$1 → A$1 → $A1 → A1.

મુખ્ય Functions:
• COUNT(A,B,...): ડિજિટલ કોષોની સંખ્યા.
• COUNTA(A,B,...): ખાલી નહીં હોય તેવા કોષો.
• COUNTBLANK: ખાલી કોષો.
• SUM(A1:A10): સરવાળો.
• AVERAGE(A1:A10): સરેરાશ.
• MAX/A MIN: મહત્તમ/લઘુત્તમ.
• IF(Condition, Value_if_true, Value_if_false):
• ROUND(number, n):
• LEFT/RIGHT/MID: substring.
• LEN(text): લંબાઈ.
• CONCATENATE ( ya & ): જોડો.
• VLOOKUP(table_array, col_index, [range_lookup]):
• HLOOKUP:
• COUNTIF(range, criteria):
• SUMIF(range, criteria, [sum_range]):
• TODAY(): આજની તારીખ.
• NOW(): તારીખ+સમય.

Formulas લખવાના નિયમો:
• સદા = (સમાન) થી શરૂ.
• કોષ અથવા range હોઈ શકે.
• ગાણિતિક ચિહ્નો: +, -, *, /, ^ (power), %.
• Parentheses () નો ઉપયોગ.

File formats:
.xlsx (નવું, 2007+), .xls (પુરાતન), .csv (comma separated), .xlsm (macro-enabled).

ગ્રાફ/ચાર્ટ:
Column, Bar, Line, Pie, Scatter, XY, Area.
Insert Chart → પસંદગી → Data → Style.

ચોક્કસતા:
• Excel માં ગણતરીઓ સૂક્ષ્મ છે.
• Function names ઇંગ્લિશમાં જ (ભલે UI ભારતીય ભાષામાં હોય).
• Relative/Absolute reference મહત્વનું.

Microsoft PowerPoint — સંપૂર્ણ અભ્યાસ

Microsoft PowerPoint એ પ્રસ્તુતિ (Presentation) સોફ્ટવેર છે. તે સ્લાઇડ્સ, ટેક્સ્ટ, તસવીરો, આલેખ, એનિમેશન, ટ્રાંઝિશન અને ઓડિયો/વિડિયોનો સમાવેશ કરે છે.

મૂળભૂત શબ્દો:
• Slide: પ્રસ્તુતિનો એક પેજ.
• Master Slide / Slide Master: પેટર્ન/ડિઝાઇન સ્લેડ.
• Notes: પ્રસ્તોતાની નોંધ.
• Animation: Object ને ગતિ.
• Transition: એક સ્લાઇડમાંથી બીજા સ્લાઇડમાં જવાની અસર.
• Rehearse Timings: પ્રસ્તુતિ સમય.

તારણ કીઓ:
F5 — પ્રસ્તુતિ શરૂ (પ્રથમ સ્લાઇડથી)
Shift+F5 — પ્રસ્તુતિ ચાલુ (વર્તમાન સ્લાઇડથી)
Esc — પ્રસ્તુતિ બંધ.
Ctrl+M — નવી સ્લાઇડ.
Ctrl+D — સ્લાઇડ ડ્યુપ્લિકેટ.
Ctrl+C/X/V — Copy/Cut/Paste.
Ctrl+B/I/U — Bold/Italic/Underline.
Ctrl+G — Group.
Ctrl+Shift+G — Ungroup.
Delete — Object દૂર.
Backspace — Object દૂર.
N/Space/Right Arrow — આગળ.
P/Left Arrow — પાછળ.
B — black screen during show (press B again return).
H — hide cursor.

Slide layouts:
Title Slide, Title and Content, Section Header, Two Content, Comparison, Blank, Picture with Caption, etc.

Animation types:
Entrance (Appear, Fly In, Float In, etc.), Emphasis (Change color, Grow/Shrink), Exit (Fly Out, Disappear).

Transition types:
Fade, Push, Wipe, Split, Zoom, Morph (નવું).

File formats:
.pptx (નવું), .ppt (પુરાતન), .ppsx (સ્લાઇડ શો), .pdf, .png/jpg (તસવીરો).

સારાંશ:
• F5, Shift+F5, Esc કી જાણવી.
• Animation vs Transition અલગ છે.
• Slides, Layouts, Masters.

Important facts

  • Microsoft Office એ Microsoft Corporation દ્વારા વિકસિત ઓફિસ સ્યુટ છે. 2007 સુધી .doc/.xls/.ppt ફાઈલો હતા; 2007 થી .docx/.xlsx/.pptx (OOXML/XML-based).
  • Word: Word Processor (શબ્દ પ્રક્રિયાક). Excel: Spreadsheet (ફાળવણી-પત્ર). PowerPoint: Presentation.
  • Word shortcuts: Ctrl+C (Copy), Ctrl+X (Cut), Ctrl+V (Paste), Ctrl+Z (Undo), Ctrl+S (Save), Ctrl+A (Select All), Ctrl+B (Bold), Ctrl+I (Italic), Ctrl+U (Underline), Ctrl+P (Print), Ctrl+F (Find), Ctrl+H (Replace).
  • Excel shortcuts: F2 (Edit cell), F4 (Loop references: A1→$A$1→A$1→$A1), Ctrl+Arrow (jump), Ctrl+Shift+Arrow (select to end).
  • PowerPoint shortcuts: F5 (Start from first slide), Shift+F5 (Start from current slide), Esc (Stop presentation), Ctrl+M (New slide).
  • Excel Function: SUM, AVERAGE, COUNT, COUNTA, COUNTBLANK, MAX, MIN, IF, ROUND, LEFT, RIGHT, MID, LEN, CONCATENATE, VLOOKUP, HLOOKUP, COUNTIF, SUMIF, TODAY, NOW.
  • Excel relative reference A1, absolute $A$1, mixed $A1/A$1. F4 key toggles between reference types.
  • Word Mail Merge: Main document + Source data + Layout. Steps: Mailings → Start Mail Merge → Select Recipients → Insert Merge Fields → Preview → Finish & Merge.
  • PowerPoint Animation vs Transition: Animation = Object movement; Transition = Between slides effect.
  • File extensions: .doc/.docx (Word), .xls/.xlsx (Excel), .ppt/.pptx (PowerPoint), .accdb/.mdb (Access), .xlsx/.xlsm (Excel macro).
  • VBA = Visual Basic for Applications. Used in all Office apps. Access from Developer tab.
  • AutoCorrect = typo fix. AutoComplete = completion suggestion. Track Changes = markup changes.
  • Ribbon tabs: Home, Insert, Page Layout, References, Mailings, Review, View (in Word).
  • Global Windows shortcuts: Ctrl+Shift+Esc = Task Manager, Win+L = Lock, Win+E = Explorer, Win+D = Desktop, Alt+F4 = Close/Shut down.
  • Browser shortcuts: Ctrl+T = New Tab, Ctrl+W = Close Tab, Ctrl+L = Address bar, Ctrl+D = Bookmark, Ctrl+H = History, Ctrl+Shift+N = Incognito.
