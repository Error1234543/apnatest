1. કોમ્પ્યુટર ની પરિભાષા અને વ્યાખ્યા

કોમ્પ્યુટર એક ઇલેક્ટ્રોનિક ઉપકરણ છે જે ડેટા (Data) ને પ્રોસેસ કરી માહિતી (Information) માં ફેરવે છે. 'Computer' શબ્દ લેટિન ભાષાના 'Computare' શબ્દથી આવ્યો છે, જેનો અર્થ થાય છે 'ગણના કરવું'. આધુનિક કોમ્પ્યુટર જર્મન ગણિતજ્ઞ કોન્રાડ ઝૂસેએ 1941માં બનાવેલ કોમ્પ્યુટર Z3 ને પ્રથમ પ્રોગ્રામાબલ કોમ્પ્યુટર માનવામાં આવે છે. મુખ્ય ગુણધર્મો: (૧) કોમ્પ્યુટર ઝડપી ગણતરી કરી શકે છે, (૨) તે ચોકસાઈપૂર્વક Kaam કરે છે, (૩) તે મોટા પ્રમાણમાં ડેટા સંગ્રહી શકે છે, (૪) તે કોઈ પણ પ્રકારની નિર્ણય પ્રક્રિયા કરી શકે છે, (૫) તે સતત Kaam કરી શકે છે કોઈથી થાકતું નથી. GSSSB પરીક્ષામાં અक्सર પૂછાતું: કોમ્પ્યુટરના જન્મદાતા કોણ? - ચાર્લ્સ બેબેજ (Charles Babbage). તેમને 'કોમ્પ્યુટરના પિતા' (Father of Computer) તરીકે ઓળખવામાં આવે છે. બેબેજે 1822માં 'ડિફરન્સ એન્જિન' અને પછી 'એનાલિટિકલ એન્જિન' બનાવ્યું હતું.

2. કોમ્પ્યુટરનો વિકાસ અને પરીપક્ષ (Generations)

કોમ્પ્યુટરનો વિકાસ 5 પરીપક્ષમાં થયો છે:

પ્રથમ પરીપક્ષ (1940-1956): વિલ્વ ટ્યુબ (Vacuum Tube) નો ઉપયોગ. સૌથી મોટું કોમ્પ્યુટર ENIAC (1946) - જોન મોકર્લી અને જોન્પર્ટી એકી બનાવેલ. એટલા મોટા કે એક સંપૂર્ણ રૂમ પકડતું. 18,000 વિલ્વ ટ્યુબ, 30 ટન વજન. ગરમી વધુ થતી અને ખરાબી વધુ.

દ્વિતીય પરીપક્ષ (1956-1963): ટ્રાન્ઝિસ્ટર (Transistor) નો ઉપયોગ. ટિઆરટે એજી (Jerry) અને વોલ્ટર બ્રાટઇન (Walter Brattain) ટ્રાન્ઝિસ્ટરનું નિર્માણ કર્યું. વિલ્વ ટ્યુબ કરતાં નાની, ઓછી ગરમી, ઓછી ઉર્જા.

તૃતીય પરીપક્ષ (1963-1971): સંકિર્ણ આरेख (Integrated Circuit - IC) નો ઉપયોગ. દસો ટ્રાન્ઝિસ્ટર એક CHIP પર. આર્કિટેક્ટ કોમ્પ્યુટર - IBM 360.

ચોથો પરીપક્ષ (1971-વર્તમાન): માઇક્રોપ્રોસેસર (Microprocessor) નો ઉપયોગ. ઇન્ટેલ 4004 (1971) પ્રથમ માઇક્રોપ્રોસેસર. સેંકડો IC એક CHIP પર. આધુનિક કોમ્પ્યુટર આ જ પરીપક્ષમાં આવે છે.

પંચમ પરીપક્ષ (Future): AI (Artificial Intelligence), Quantum Computing. કૃત્રિમ બુદ્ધિ પર આધારિત કોમ્પ્યુટર. હાલમાં વિશ્વવ્યાપી સંશોધન ચાલુ છે.

GSSSB માટે મહત્વનું: પ્રથમ પ્રોગ્રામાબલ કોમ્પ્યુટર - Z3 (1941), પ્રથમ ઈલેક્ટ્રોનિક કોમ્પ્યુટર - ENIAC (1946), પ્રથમ માઇક્રોપ્રોસેસર - Intel 4004 (1971).

3. કોમ્પ્યુટરની શ્રેણીઓ (Classification)

કોમ્પ્યુટરનો વર્ગીકરણ કાર્યક્ષમતા અને પ્રકાર મુજબ:

(A) પ્રકાર મુજબ:
- એનાલોગ કોમ્પ્યુટર: સતત (Continuous) માપન કરે છે. જેમ - તાપમાન, દબાણ, વેગ. વૈજ્ઞાનિક પ્રયોગો માટે ઉપયોગી.
- ડિજિટલ કોમ્પ્યુટર: બિનરિ (Binary) સંખ્યાઓ 0 અને 1 માં Kaam કરે છે. આજકાલના બધા જ કોમ્પ્યુટર ડિજિટલ છે.
- હાઇબ્રિડ કોમ્પ્યુટર: એનાલોગ અને ડિજિટલ બંનેના ગુણધર્મો ધરાવે. મેડિકલ ફીલ્ડમાં ઉપયોગ.

(B) કાર્યક્ષમતા મુજબ:
- સુપર કોમ્પ્યુટર (Supercomputer): સૌથી ઝડપી, કરોડો ઇન્સ્ટ્રક્શન પ્રતિ સેકન્ડ. ઉदा. PARAM, Cray. મોશણની ગણતરી, હવામાન ભવિષ્યવાણી, પરમાણુ સંશોધન માટે.
- મેઈનફ્રેમ કોમ્પ્યુટર (Mainframe): ઘણા ઉપયોગદાતાઓને Ek સાથે જોડી શકે. બેંક, રેલવે, સરકારી કાર્યક્રમો.
- મિની કોમ્પ્યુટર (Minicomputer): મેઈનફ્રેમ કરતાં નાનો, સ્મોલ એન્ટરપ્રાઇઝ માટે.
- મைક્રો કોમ્પ્યુટર (Microcomputer/P个人 computer): એક વ્યક્તિ માટે. Desktop, Laptop, Tablet, Smartphone.

(GSSSB માં અक्सર પૂછાય: સુપર કોમ્પ્યુટરનો ઉપયોગ ક્યાં થાય? - હવામાન સંશોધન, પરમાણુ વૉર્સ, SPACE રિસર્ચ.)

4. કોમ્પ્યુટરનું સ્ટ્રક્ચર - H/W અને S/W

કોમ્પ્યુટર બે મુખ્ય ભાગોનો બનેલ છે:

(A) હાર્ડવેર (Hardware):
કોમ્પ્યુટરના દૃશ્યમાન, સ્પર્શીય ભાગો. ચાર મુખ્ય એકમો:
- ઇનપુટ એકમ: ડેટા કોમ્પ્યુટરમાં મોકલે છે. ઉદા. કીબોર્ડ, માઉસ, સ્કેનર, મايicrophone, વેબકેમ.
- આઉટપુટ એકમ: પ્રોસેસ કરેલી માહિતી વપરાશકને આપે છે. ઉદા. મોનિટર, પ્રિન્ટર, સ્પીકર, પ્રોજેક્ટર.
- CPU (Central Processing Unit): કોમ્પ્યુટરનું મગજ. બે ભાગ: ALU (Арithmetic Logic Unit) અને CU (Control Unit).
- મેમરી/સ્ટોરેજ: ડેટા અને પ્રોગ્રામ સંગ્રહી રાખે છે.

(B) સોફ્ટવેર (Software):
કોમ્પ્યુટરના અદૃશ્ય દિશાઓ, પ્રોગ્રામ અને ઇન્સ્ટ્રક્શન. મુખ્ય પ્રકાર:
- સિસ્ટમ સોફ્ટવેર: OS (Operating System) - Windows, Linux, macOS, Android, iOS.
- એપ્લિકેશન સોફ્ટવેર: MS Office, Adobe Photoshop, Web Browser, Games.
- પ્રોગ્રામિંગ સોફ્ટવેર: Compilers, Interpreters, Assemblers (C, Python, Java વગેરે).

હાર્ડવેર અને સોફ્ટવેર એકબીજા વિના અધૂરા છે. H/W સિંગલ ગમે તે શક્તિશાળી હોય, S/W વિના તેKaam નહીં કરે.

5. માઇક્રોપ્રોસેસર અને CPU

માઇક્રોપ્રોસેસર એ એક ચિપ છે જે CPU ના બધા જ ફંક્શન એક સાથે કરે છે. તેને 'મઇક્રોપ્રોસેસર' કહેવાય કારણ કે તે ડેટા પ્રોસેસિંગનો કેન્દ્રબિંદુ છે.

CPU ના મુખ્ય ભાગો:
- ALU (Arithmetic Logic Unit): બધી ગાણિતિક (જોડ, ઘટાડો, ગુણાકાર, ભાગાકાર) અને લોજિકલ (AND, OR, NOT, Comparison) Kaam કરે છે.
- CU (Control Unit): બધા ઉપકરણો વચ્ચે ડેટાનું નિયંત્રણ કરે છે. ઇનપુટ/ઓઉટપુટ નક્કી કરે છે. PC (Program Counter) અને IR (Instruction Register) CU નો ભાગ છે.
- Registers: ઝડપી સ્ટોરેજ જે CPU ખૂબ જ ઝડપી ડેટા સંગ્રહી રાખે છે. ഉदा. AC (Accumulator), SP (Stack Pointer), PC (Program Counter).

CPU ની ગતિ MHz અથવા GHz માં માપવામાં આવે છે. આધુનિક કોમ્પ્યુટરની ગતિ 2-5 GHz છે.

જનરેશન મુજબ CPU:
- Intel 4004 (1971) - 2,300 TRANSISTORS, 740 kHz
- Intel 8086 (1978) - 29,000 TRANSISTORS, 5-10 MHz
- આજકાલના CPU - અબજો TRANSISTOR, 3-5 GHz

GSSSB માટે મહત્વનું: CPU ની સૌથી નાની એકમ - Bit (Binary Digit). 1 Bit = 0 અથવા 1. 8 Bit = 1 Byte. 1024 Byte = 1 KB. 1024 KB = 1 MB. 1024 MB = 1 GB. 1024 GB = 1 TB. 1024 TB = 1 PB (Petabyte).

6. મેમરી પ્રકારો (Memory Types)

કોમ્પ્યુટર મેમરી બે મુખ્ય પ્રકારની હોય છે:

(A) પ્રાથમિક મેમરી (Primary Memory / Main Memory):
CPU સીધી પહોંચી શકે. બે પ્રકાર:
- RAM (Random Access Memory): વોલેટાઇલ મેમરી. પાવર ઊડી જાય તો ડેટા મળે છે. વાંચી અને લખી શકાય. SRAM (Static RAM - ઝડપી, મોંઘી) અને DRAM (Dynamic RAM - ધીમી, સસ્તી, main memory માટે).
- ROM (Read Only Memory):Non-volatile. પાવર ઊડી જાય તો પણ ડેટા સંગ્રહી રાખે. માત્ર વાંચી શકાય (મૂળભૂત રીતે). BIOS માં ઉપયોગ. PROM, EPROM, EEPROM પ્રકાર.

(B) દ્વિતીયક મેમરી (Secondary Memory):
CPU સીધી પહોંચી શકે નહીં. Non-volatile. મોટી સ્ટોરેજ. ઉદા. HDD (Hard Disk Drive), SSD (Solid State Drive - ઝડપી, મોશણ), USB Pendrive, Optical Disc (CD, DVD, Blu-ray).

(C) કેશ મેમરી (Cache Memory):
CPU અને Main Memory વચ્ચેની ખૂબ જ ઝડપી મેમરી. L1, L2, L3 Cache. CPU ની ગતિ વધારે છે.

ક્રમ (ઝડપ મુજબ): Register > Cache > RAM > Secondary Storage.

મહત્વનાં રૂપાંતરણ:
- 1 Byte = 8 Bits
- 1 KB = 1024 Bytes
- 1 MB = 1024 KB
- 1 GB = 1024 MB
- 1 TB = 1024 GB
- 1 PB = 1024 TB

7. ઇનપુટ અને આઉટપુટ ઉપકરણો

(A) ઇનપુટ ઉપકરણો (Input Devices):
- કીબોર્ડ: 101-105 keys. QWERTY layout સૌથી સામાન્ય.Function keys (F1-F12), Ctrl, Alt, Shift, Enter, Spacebar.
- માઉસ: Pointing device. Left click, right click, scroll wheel. Optical, Laser, Wireless માઉસ.
- સ્કેનર: કાગળ પરના ડૉક્યુમેન્ટને ડિજિટલમાં ફેરવે. DPI (Dot Per Inch) એ સ્કેનિંગ રિઝોલ્યુશન.
- માઇક્રોફોન: ધ્વનિ ઇનપુટ.
- વેબકેમ: વિડિઓ ઇનપુટ.
- બારકોડ રીડર: બારકોડ વાંચે. Supermarket, Library માં.
- Touchscreen: સ્પર્શથી ઇનપુટ. Smartphone, ATM.

(B) આઉટપુટ ઉપકરણો (Output Devices):
- Mоnitor/Display: CRT ( Cathode Ray Tube - જૂનું), LCD, LED, Flat panel.
- પ્રિન્ટર: Dot Matrix (અવાજવધારે, સસ્તું), Inkjet (રંગીન પ્રિન્ટ), Laser (ઝડપી, ગુણવત્તાવાળું).
- સ્પીકર: ધ્વનિ આઉટપુટ.
- પ્રોજેક્ટર: મોટી સ્ક્રીન પર પ્રદર્શિત કરે.
- પ્લોટર: વાઇસીરેખીય ડ્રોઇંગ માટે (Engineering drawing).

GSSSB માટે મહત્વનું:打印机માં 'पेज पर सेकंड' (PPS) એ પ્રિન્ટિંગ ગતિ. Inkjet પ્રિન્ટરમાં ink cartridge, Laser માં toner cartridge.

8. કોમ્પ્યુટર ભાષાઓ (Computer Languages)

કોમ્પ્યુટરને સમજાવા માટે પ્રોગ્રામિંગ ભાષાઓની જરૂર પડે છે:

- Machine Language: 0 અને 1 માં. કોમ્પ્યુટર સીધી સમજે. સૌથી ઝડપી. પરંતુ લખવી મુશ્કેલ.
- Assembly Language: Machine language નું માનવ-અનુકૂળ સ્વરૂપ. Symbolic representation.Assembler દ્વારા machine language માં ફેરવે છે.
- High-Level Language: માનવ-અનુકૂળ. COBOL, FORTRAN, C, C++, Java, Python. Compiler અથવા Interpreter દ્વારા machine language માં ફેરવે છે.

Compiler અને Interpreter વચ્ચેનો તફાવત:
- Compiler: સમગ્ર પ્રોગ્રામ એકવારમાં machine code માં ફેરવે. ઝડપી execution. (C, C++)
- Interpreter: એક-એક લાઇન ફેરવે. સમસ્યા શોધવામાં સરળ. (Python, BASIC)

Popüler પ્રોગ્રામિંગ ભાષાઓ અને તેમના પ્રકાર:
- C (1972 - Dennis Ritchie): Structured programming
- C++ (Bjarne Stroustrup): Object-Oriented
- Java (James Gosling - 1995): Platform independent ('Write Once, Run Anywhere')
- Python (Guido van Rossum - 1991): High-level, Easy syntax
- COBOL: Business applications
- FORTRAN: Scientific calculations

GSSSB: માહિતી તકનીકીમાં સૌથી વધુ ઉપયોગમાં લેવાતી ભાષા કઈ? - C ભાષા. તેને 'Mother of all languages' કહેવાય છે.

9. OS અને સોફ્ટવેર

ઓપરેટિંગ સિસ્ટમ (OS) એ સોફ્ટવેરનો તે પ્રકાર છે જે હાર્ડવેર અને ઉપયોગકર્તા વચ્ચેનો સેતુ છે.

મુખ્ય OS:
- Windows: Microsoft દ્વારા. સૌથી વધુ ઉપયોગમાં. (Windows 10, 11)
- Linux: Open source. Ubuntu, CentOS, Fedora. સરકારી યોજનાઓમાં ઉપયોગ.
- macOS: Apple કંપની. Mac કોમ્પ્યુટરમાં.
- Android: Google. Mobile devices માં સૌથી વધુ ઉપયોગ.
- iOS: Apple. iPhone માં.

OS ના કાર્યો:
- Resource Management (CPU, Memory, Devices નું નિયંત્રણ)
- File Management
- User Interface (GUI/CLI)
- Security Management
- Process Management

GUI (Graphical User Interface): Picture, Icon, Menu, Window. Windows, macOS.
CLI (Command Line Interface): Commands દ્વારા. Command Prompt, Terminal.

મહત્વના શોર્ટકટ કીઝ (Windows):
- Ctrl+C: Copy, Ctrl+V: Paste, Ctrl+X: Cut, Ctrl+Z: Undo
- Alt+F4: Close program, Ctrl+A: Select All, Ctrl+S: Save
- Windows Key + D: Desktop, Windows Key + E: File Explorer
- Delete键:永久删除(Shift+Delete)
- F2: Rename, F5: Refresh

GSSSB માટે: OS નું મુખ્ય કાર્ય - Resource Management. Linux open source OS છે. Windows Explorer file management માટે.

10. MS Office અને ઉપયોગ

(A) MS Word: Word Processing software. ડૉક્યુમેન્ટ બનાવવા, સંપાદિત કરવા, પ્રિન્ટ કરવા. ફાઇલ એક્સ્ટેન્શન: .docx. Shorcut: Ctrl+N (New), Ctrl+O (Open), Ctrl+P (Print).

(B) MS Excel: Spreadsheet software. ગણતરી, ડેટા વિશ્લેષણ, ચાર્ટ, ગ્રાફ. Row (અંક), Column (અક્ષર), Cell ( intersection). ફાઇલ એક્સ્ટેન્શન: .xlsx. Formula = સમયથી શરૂ થાય.

(C) MS PowerPoint: Presentation software. Slides બનાવી પ્રસ્તુતી આપવી. ફાઇલ એક્સ્ટેન્શન: .pptx.

(D) MS Access: Database management software. Queries, Forms, Reports બનાવવા.

(E) Notepad: Plain text editor. ફાઇલ એક્સ્ટેન્શન: .txt. No formatting.

(F) Paint: Graphics editing. ફાઇલ એક્સ્ટેન્શન: .bmp, .jpg, .png.

(GSSSB) માટે મહત્વનું:
- સૌથી વધુ ઉપયોગમાં લેવાતો Office software: MS Word
- Excel માં સૌથી ડાબે ઉપરની cell: A1

Formulas and relationships

1 Byte = 8 Bits (મૂળભૂત રૂપાંતરણ)
1 KB = 1024 Bytes (2^10)
1 MB = 1024 KB = 1024 × 1024 Bytes (2^20)
1 GB = 1024 MB = 1024 × 1024 × 1024 Bytes (2^30)
1 TB = 1024 GB (2^40 bytes)
1 Nibble = 4 Bits
CPU Speed (clock speed) = GHz અથવા MHz માં (1 GHz = 10^9 Hz)
Data Transfer Rate (printing) = PPS (Pages Per Second)
Scanner Resolution = DPI (Dots Per Inch)
Resolution (pixels) = Width × Height

Common mistakes

  • RAM ને Non-volatile મેમરી માનવી - RAM વોલેટાઇલ છે, પાવર ઊડી જાય તો ડેટા નષ્ટ થાય. ROM Non-volatile છે.
  • 1 KB = 1000 Bytes માનવું - સાચું 1 KB = 1024 Bytes છે (2^10). 1000 Bytes = 1 KB સિક્યોરિટી/Storage manufacturer ના ગણતરીમાં.
  • CPU = Computer Unit માનવું - CPU = Central Processing Unit. તે કોમ્પ્યુટરનું મગજ છે.
  • Compiler અને Interpreter નો તફાવત લઈ ન શકવો - Compiler સમગ્ર પ્રોગ્રામ ફેરવે છે, Interpreter એક-એક લાઇન.
  • ROM માં ડેટા રાઇટ થઈ શકે એમ માનવું - ROM રીડ-ઓનલી છે (PROM, EPROM, EEPROM સિવાય). મુખ્યત્વે વાંચવા માટે.
  • MS Excel ને Word Processing માનવું - Excel Spreadsheet software છે. Word Word Processing છે.
  • કીબોર્ડ ને આઉટપુટ ઉપકરણ માનવું - કીબોર્ડ ઇનપુટ ઉપકરણ છે.
  • Monitor ને ઇનપુટ ઉપકરણ માનવું - Monitor આઉટપુટ ઉપકરણ છે (Touchscreen સિવાય).
  • Bit અને Byte નો તફાવત ન જાણવો - 1 Byte = 8 Bits. Bit એ સૌથી નાની એકમ.
  • Windows Key + D શોર્ટકટ ભૂલવો - Windows Key + D = Show Desktop. Windows Key + E = File Explorer.
