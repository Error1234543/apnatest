Definitions

  • શતકડો (Percentage): કોઈ પણ રાશિનો સદીમાં (100 માં) ભાગ. ગાણિતિક રીતે, x% = x/100. ઉદાહરણ: 45% = 45/100 = 0.45. શતકડો એકમરહિત (dimensionless) હોય છે.
  • અપૂર્ણાંકથી શતકડામાં: a/b = (a/b)×100%. ઉદાહરણ: 3/8 = 37.5%, 5/7 ≈ 71.43%.
  • શતકડામાંથી અપૂર્ણાંક: x% = x/100. સાદું રૂપ આપો. ઉદાહરણ: 20% = 1/5, 12.5% = 1/8.
  • સરેરાશ (Average/Mean): આપેલા મૂલ્યોના સરવાળાને તેમની સંખ્યા વડે ભાગતા મળતું મૂલ્ય. Formula: સરેરાશ = (બધા મૂલ્યોનો સરવાળો) ÷ (મૂલ્યોની સંખ્યા).
  • સરેરાશનો મૂળભૂત ગુણધર્મ: જો n સંખ્યાઓની સરેરાશ A હોય, તો તેમનો સરવાળો = n × A.
  • ચાલીને (Change) અને શતકડા ફેરફાર: નવું મૂલ્ય - પાછલા મૂલ્ય = ચાલી. % ફેરફાર = (ચાલી ÷ મૂળ મૂલ્ય) × 100%.
  • પુનઃ (Reversal) શતકડો: જો k દ્વારા વધારો થાય, તો પાછો ફરવા % ઘટાડો = [k÷(100+k)]×100%. ઉદાહરણ: 20% વધારો → પાછો ફરવો = 20/120×100 = 16.67%.

Key concepts

  • શતકડા, દશાંશ, અપૂર્ણાંક વચ્ચે રૂપાંતરણ ખૂબ મહત્વનું છે. GSSSB માં ઘણીવાર સીધું રૂપાંતરણ જોવા મળે છે.

    • 1% = 0.01 = 1/100
    • 10% = 0.10 = 1/10
    • 20% = 0.20 = 1/5
    • 25% = 0.25 = 1/4
    • 33⅓% = 1/3
    • 40% = 0.40 = 2/5
    • 50% = 0.50 = 1/2
    • 60% = 0.60 = 3/5
    • 75% = 0.75 = 3/4
    • 80% = 0.80 = 4/5
    • 90% = 0.90 = 9/10

    મહત્વનો ગુણ: x% of y = y% of x. ઉદા. 8% of 25 = 25% of 8 = 2.
  • જ્યારે કોઈ મૂલ્યમાં ફેરફાર થાય ત્યારે:

    • વધારો = (nવ) − (મૂળ)
    • ઘટાડો = (મૂળ) − (નવું)
    • % વધારો/ઘટાડો = (ચાલી÷મૂળ) × 100%

    મહત્વની બાબત: % ફેરફાર હંમેશા મૂળ મૂલ્ય સાપેક્ષે ગણાય. જો કિંમત 100માંથી 120 થાય, તો % વધારો = 20%, પણ જો 120માંથી 100 થાય, તો % ઘટાડો = 20/120×100 = 16.67%.

    નમૂના પ્રશ્ન: કૉપીનો ભાવ 1500માંથી 1800 થાય. % વધારો? ચાલી = 300, % વધારો = 300/1500×100 = 20%.
  • જ્યારે એક પછી એક બે કે વધુ શતકડા ફેરફાર થાય, ત્યારે કુલ % ફેરફાર:

    Formula: % net change = a + b + (ab/100), જ્યાં a અને b બે ક્રમિક ફેરફાર છે.

    ઉદાહરણ: ભાવમાં 10% વધારો અને પછી 20% ઘટાડો થાય. a = +10, b = -20.
    Net change = 10 + (-20) + (10×(-20)/100) = 10 - 20 - 2 = -12% (કુલ 12% ઘટાડો).

    ત્રણ ફેરફારો માટે: p, q, r લો. પહેલા p અને q નો net શોધો, પછી પરિણામ + r.

    જો ત્રણ વાર એકસરખો ફેરફાર 'r%' થાય, તો % net = 3r + 3r²/100 + r³/10000.
  • • લાભ = બિક્રી કિંમત − ક્રય કિંમત (જો વેચાણ > ક્રય)
    • મૂડિયું = ક્રય કિંમત − બિક્રી કિંમત (જો ક્રય > વેચાણ)
    • લાભ % = (લાભ ÷ ક્રય કિંમત) × 100
    • મૂડિયું % = (મૂડિયું ÷ ક્રય કિંમત) × 100

    જો SP = CP×(1 + Profit%), જો SP = CP×(1 - Loss%), CP = SP÷(1±%)

    સામાન્ય જાળ: લાભ/મૂડિયું હંમેશા CP પર ગણાય છે. કેટલાક વિદ્યાર્થીઓ SP પર ગણે છે — એ ભૂલ છે.

    સવાલ: કોઈ વસ્તુ 80% લાભે વેચાય. CP = 100, SP = 180. જો ડિસ્કાઉન્ટ 10% આપે, તો % લાભ? SP = 180×0.90 = 162, લાભ = 62%.
  • બે પદ્ધતિઓ છે:

    પદ્ધતિ 1: પ્રમાણભૂત (Standard Method)
    સરેરાશ = (આપેલી બધી સંખ્યાઓનો સરવાળો) ÷ (સંખ્યાઓની સંખ્યા)

    ઉદાહરણ: 12, 15, 18, 20, 25 ની સરેરાશ = (12+15+18+20+25)/5 = 90/5 = 18.

    પદ્ધતિ 2: ધારણ પદ્ધતિ (Assumed Mean Method) — બड़ी સંખ્યાઓ માટે ઉપયોગી
    ધારો કે સરેરાશ A = 18
    અંતરો: 12−18=−6, 15−18=−3, 18−18=0, 20−18=+2, 25−18=+7
    સરેરાશ = A + (અંતરોનો સરવાળો)÷n = 18 + (−6−3+0+2+7)/5 = 18 + 0 = 18.

    આ પદ્ધતિ GSSSB માં ઝડપી ઉકેલ માટે ખૂબ ઉપયોગી છે.
  • જ્યારે સરેરાશ લેવી હોય ત્યારે દરેક મૂલ્યને અલગ અલગ 'વજન' (વારંવાર આવે તેટલી સંખ્યા) મળે.

    Formula: વજનદાર સરેરાશ = (w₁x₁ + w₂x₂ + ... + wₙxₙ) ÷ (w₁ + w₂ + ... + wₙ)

    ઉદાહરણ: કલાસમાં 20 વિદ્યાર્થીઓની સરેરાશ 60 અને 30 વિદ્યાર્થીઓની સરેરાશ 70 છે. કુલ સરેરાશ?
    વજનદાર સરેરાશ = (20×60 + 30×70) ÷ (20+30) = (1200+2100)/50 = 3300/50 = 66.

    GSSSB માં બે જૂથના મિશ્રણ પ્રશ્નો વારંવાર આવે છે.
  • 1. સરેરાશ હંમેશા સૌથી નાની અને સૌથી મોટી સંખ્યાની વચ્ચે હોય.
    2. જો દરેક સંખ્યામાં સમાન સંખ્યા ઉમેરો/કાઢો, તો સરેરાશ પણ તેટલા જ વધે/ઘટે.
    3. જો દરેક સંખ્યાને s વડે ગુણો/ભાગો, તો સરેરાશ પણ તેટલા જ વધે/ઘટે.
    4. સમાન સંખ્યાઓની સરેરાશ = તે સંખ્યા જ.
    5. જો n સંખ્યાઓની સરેરાશ A હોય, તો નવી સંખ્યા ઉમેરતાં જૂની સરેરાશમાં થતો ફેરફાર = (નવી સંખ્યા − A)/(n+1).

    ઉદા: 5 સંખ્યાઓની સરેરાશ 20 છે. 6મી સંખ્યા 50 ઉમેરતાં નવી સરેરાશ?
    જૂનો સરવાળો = 100, નવો સરવાળો = 150, n = 6, નવી સરેરાશ = 150/6 = 25.
  • GSSSB માં સરેરાશ અને શતકડો મળીને પ્રશ્નો આવે છે:

    ઉદા: ત્રણ સંખ્યાઓની સરેરાશ 40 છે. પ્રથમ બેની સરેરાશ 35 છે. ત્રીજી સંખ્યા શોધો.
    સરવાળો (3) = 120, સરવાળો (2) = 70, ત્રીજી = 120 − 70 = 50.

    ઉદા: એક વ્યક્તિની ત્રણ વખત કચડાની સરેરાશ 50, 60, 40 છે. ચોથું વખત કેટલું કાઢવું પડે જેથી 4 વખતની સરેરાશ 55 થાય?
    ચારમાં સરવાળો = 55×4 = 220, ત્રણમાં = 150, ચોથું = 220−150 = 70.

    ઉદા: શતકડા સાથે: B ની આવક A કરતાં 20% વધુ. B = A×1.20, A = B÷1.20 = B×(5/6) ≈ B×0.833. એટલે A, B કરતાં ~16.67% ઓછી.
  • શતકડા ↔ અપૂર્ણાંક:
    • 1% = 1/100
    • 2½% = 1/40
    • 5% = 1/20
    • 6¼% = 1/16
    • 8⅓% = 1/12
    • 12½% = 1/8
    • 16⅔% = 1/6
    • 20% = 1/5
    • 25% = 1/4
    • 33⅓% = 1/3
    • 37½% = 3/8
    • 40% = 2/5
    • 50% = 1/2
    • 60% = 3/5
    • 66⅔% = 2/3
    • 75% = 3/4
    • 80% = 4/5
    • 90% = 9/10

    આ ટેબલ યાદ હોય તો શતકડાની ગણતરી ખૂબ ઝડપી થાય.

Important facts

  • શતકડો એકમરહિત છે — તેની સાથે '%', 'pct', અથવા કોઈ ભૌતિક એકમ ન હોય.
  • લાભ/મૂડિયું % હંમેશા C P (ક્રય મૂલ્ય) પર ગણાય છે, S P નહીં. આ સૌથી સામાન્ય ભૂલ છે.
  • Successive changes માટે '+', '−' નિશાની સાથે a, b મૂકો — અવગણવાથી ખોટું જવાબ.
  • વજનદાર સરેરાશમાં વજનો (વારંવાર આવવાની સંખ્યા) ને ધ્યાનમાં લો, ફક્ત મૂલ્યો નહીં.
  • ધારણ પદ્ધતિએ (Assumed Mean) ગણતરી ચાલુ રાખો ત્યાં સુધી ભૂલ ન થાય. તપાસ કરવી જરૂરી.
  • GSSSB ગણિતમાં શતકડો અને સરેરાશ પરથી 3-5 પ્રશ્નો આવે છે — આથી આ ટોપિકમાં સ્કોર કરવો એક્સામ માટે મહત્વનો છે.
  • શતકડાના પ્રશ્નમાં 'અંતિમ મૂલ્ય' શોધવાનો છે ત્યારે ફક્ત % ફેરફાર નહીં, પણ નવું મૂલ્ય જ પૂછે છે. બંને જવાબ ફરજિયાત નક્કી કરો.
  • સરેરાશનો સરવાળો = સરેરાશ × સંખ્યા. આ સૂત્ર વિનાના પ્રશ્નો ઘણા હોય છે.

Memory aids

  • શતકડાના રૂપાંતરણ માટે યાદ રાખો: '25 = 1/4, 20 = 1/5, 50 = 1/2, 75 = 3/4' — આ ચાર મૂળભૂત. બાકીના આમાંથી બનાવી શકાય.
  • Successive change: 'a + b + ab/100' → 'Add, Add, Add product'. આ શબ્દાંશ યાદ રાખો.
  • Profit/Loss sign rule: 'Gain' = +, 'Loss' = −. SP = CP(1 ± %). જો Gain હોય તો +, Loss હોય તો −.
  • સરેરાશનો ગુણધર્મ: 'જેટલા ઉમેરો, સરેરાશમાં પણ તેટલું'. આ સરળ ભાષામાં યાદ રાખો.
  • વજનદાર સરેરાશ: 'વજન દરેક મૂલ્યનું યોગદાન નક્કી કરે'.
  • શતકડા ↔ દશાંશ: '% ચિન્હ દૂર કરો, 100 વડે ભાગો'. અથવા 'દશાંશ બિંદુ બે સ્થાન ડાબી તરફ સરકાવો'.

Exam tips

  • GSSSB ગણિતમાં 40-50 પ્રશ્નો હોય છે, તેમાં 3-5 પ્રશ્નો શતકડો અને સરેરાશ પરથી આવે છે. આ ભાગમાં સ્કોર કરવો અત્યંત મહત્વનો છે કારણ કે આ સીધા સૂત્રાત્મક છે.
  • પરિક્ષામાં શતકડા પ્રશ્ન આવે તો સૌ પ્રથમ 'મૂળ મૂલ્ય' (base) શોધો — ઘણીવાર પ્રશ્નમાં મૂળ મૂલ્ય સીધું નથી આપેલું.
  • વજનદાર સરેરાશ પ્રશ્નમાં 'સરેરાશ' અને 'કુલ સરવાળો' વચ્ચેનો સંબંધ યાદ રાખો. 80% પ્રશ્નો આ જ સંબંધ પર આધારિત છે.
  • લાભ/મૂડિયું પ્રશ્નોમાં CP અને SP ની અદલાબદલી ન કરવી. CP હંમેશા મૂળ, SP હંમેશા અંતિમ.
  • ધારણ પદ્ધતિની વાપરો જ્યારે સંખ્યાઓ મોટી હોય અથવા દશાંશમાં હોય — આ સમય બચાવે છે.
  • અંતિમ મૂલ્ય શોધવાનો પ્રશ્ન હોય તો પ્રથમ % change શોધો, પછી મૂળ × (1 ± net%).
  • ગણતરી સમયે ઇન્ડિયન સિસ્ટમ (લાખ, કરોડ) અને I.P.S. (lakhs, millions) — GSSSB માં સામાન્ય રીતે ઇન્ડિયન સિસ્ટમ વપરાય છે, પણ પ્રશ્ન ધ્યાનથી વાંચો.
  • સમય મર્યાદામાં રહેવું: શતકડો + સરેરાશ પ્રશ્નને 45-60 સેકન્ડમાં ઉકેલવાનું અભ્યાસ કરો. આ પ્રશ્નો 'Easy Marks' છે.

Common traps

  • શતકડા ફેરફારમાં % ની ગણતરી બંને વખતે different base પર થાય. પહેલા ફેરફાર CP પર, બીજા (નાતું SP) પર. આ ધ્યાનમાં લેવાય તો જ સાચો જવાબ મળે.
  • સરેરાશની ગણતરીમાં સંખ્યાઓની સંખ્યા ગણતી વખતે અંતરેલી સંખ્યાઓ ગણવી — ઉદા: '1 વર્ષ, 3 વર્ષ, 5 વર્ષ' એ 3 સંખ્યા, 5 નહીં.
  • વજનદાર સરેરાશમાં વજનોના સરવાળા વડે ભાગવું ભૂલવું. ઘણા વિદ્યાર્થીઓ ફક્ત વજનદાર સરવાળો લખી જવાબ આપે છે.
  • Profit % અને Loss % ને મિશ્ર કરીને કોઈ મૂળભૂત સૂત્રનો ઉપયોગ કરવો. દરેક પ્રશ્ન અલગ ગણો.
  • successive % માં net change શોધ્યા બાદ તેનો ઉપયોગ કરવાના બદલે અલગ અલગ ગણતરી કરવી. time wastage.
  • ધારણ પદ્ધતિમાં ઋણ (negative) અંતરોને ધ્યાનમાં લેવા નહીં. ઉદા: −6, −3 ને +6, +3 માની ગણતરી કરવી.
  • શતકડામાં 'of' નો અર્થ ગુણાકાર સમજવો. '20% of 300' = 20/100 × 300. અનેક વિદ્યાર્થીઓ ભાગાકાર કરી દે છે.
