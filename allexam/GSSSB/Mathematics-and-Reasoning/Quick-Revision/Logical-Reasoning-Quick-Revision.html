Definitions

  • સરખામણી (Analogy): બે વસ્તુઓ અથવા વ્યક્તિઓ વચ્ચેનો સંબંધ ઓળખીને તે જ સંબંધ સાથે ત્રીજી વસ્તુ/વ્યક્તિ સાથે ચોથી વસ્તુનો જોડાણ કરવાની પ્રક્રિયા.
  • કોડિંગ-ડિકોડિંગ (Coding-Decoding): શબ્દો, અક્ષરો અથવા સંખ્યાઓને કોઈ ચોક્કસ નિયમ મુજબ ફેરવવા (કોડિંગ) અને તે ફેરફારને પાછો લાવવા (ડિકોડિંગ)ની કળા.
  • રક્ત સંબંધ (Blood Relation): પરિવારના સભ્યો વચ્ચેના આપ્ત સંબંધોનો અભ્યાસ. દા.ત. પિતા, માતા, ભાઈ, બહેન, દાદા, દાદી, ચાચા, મاما, મામા, ભત્રીજો, ભાતીજો વગેરે.
  • દિશા જાણ (Direction Sense): ઉત્તર, દક્ષિણ, પૂર્વ, પશ્ચિમ અને તેમના વચ્ચેના કોણોના આધારે સ્થાન/દિશા નક્કી કરવી.
  • શ્રેણી/ક્રમબद्धતા (Ranking/Ordering): કોઈ પણ ગણમાં એક ચોક્કસ સ્થાન નક્કી કરવું અથવા આપેલો ક્રમ જાળવવો.
  • વિધાન અને નિષ્કર્ષ (Statement and Conclusion): વિધાન (પ્રસ્તાવ) માંથી તાર્કિક રીતે સાચો નિષ્કર્ષ કાઢવો, જે વિધાન પર આધારિત હોય.
  • તર્કશાસ્ત્ર (Syllogism): બે વિધાન (પ્રમેય) પરથી તૃતીય વિધાન (નિષ્કર્ષ) પ્રાપ્ત કરવાની પ્રક્રિયા — જનરલી 'બધા A, B છે; બધા B, C છે; તેથી બધા A, C છે' આ સ્વરૂપ.
  • પાસો અને ઘન (Dice and Cube): પાસાના વિવિધ સ્થિતિઓમાં વિરુદ્ધ અને આસપાસની સંખ્યાઓ નક્કી કરવી અને ઘન (Cube) ના ટુકડા થાય તેવી ગણતરી કરવી.
  • શ્રેણી પૂર્ણ કરવી (Series Completion): અંક શ્રેણી, અક્ષર શ્રેણી, મિશ્ર શ્રેણીમાં લુપ્ત પદ શોધવું.
  • બેઠક ગોઠવણી (Seating Arrangement): લોકોને વૃત્તાકાર/આયતાકાર/સીધી લાઇનમાં બેસાડવાની શરતો આપેલ હોય, તો તેમની ચોક્કસ ગોઠવણી શોધવી.

Key concepts

  • સરખામણી (Analogy): સરખામણીમાં બે પદો વચ્ચેનો સંબંધ શોધવો અને તે જ સંબંધ અન્ય પદ સાથે લાગુ કરવો. સામાન્ય સંબંધ પ્રકારો:

    • કાર્ય-કારણ સંબંધ: દા.ત. બીમારી : હોસ્પિટલ :: શિક્ષક : શાળા
    • ઉત્પાદક-ઉત્પાદન: દા.ત. ખેડૂત : અનાજ :: કારીગર : વસ્ત્ર
    • ભાગ-ખંડ સંબંધ: દા.ત. પૂલ : ઝરંગા :: પંખો : પાખુડા
    • સાધન-કામ: દા.ત. મેપ : ભૂગોળ :: પાઠ્યપુસ્તક : વિદ્યા
    • વિરોધી/સહચર સંબંધ: દા.ત. ગરમી : સરમો :: કાળું : સફેદ
    • સંખ્યા સંબંધ: દા.ત. 4 : 16 :: 6 : 36 (વર્ગ સંબંધ)

    ઉકેલ પ્રક્રિયા: મૂળ જોડીનો સંબંધ સમજો → વિધેય શોધો → વિકલ્પમાં મૂકીને તપાસો.
  • કોડિંગ-ડિકોડિંગ (Coding-Decoding): કોડિંગ-ડિકોડિંગમાં શબ્દના અક્ષરોની જગ્યા બદલવી, સામેનું અક્ષર લખવું, વર્ણમાળા સ્થાન ઉમેરવું/કાઢવું જેવા નિયમો લાગુ પડે છે.

    મુખ્ય પ્રકારો:
    • સામસામું અક્ષર (Opposite Letter): A↔Z, B↔Y, C↔X... (EZRA QCJ અનુક્રમે Y, B, M...)
    • અક્ષર આગળ/પાછળ: દા.ત. COMPUTER → DPNQVFQS (એક આગળ)
    • અક્ષર ગણતરી: દા.ત. CAT = 3+1+20 = 24
    • જોડાણ/સંયોજન કોડ: SHARP → RAHSP (પ્રથમ અક્ષર છેલ્લે, બીજું પ્રથમ)
    • સંખ્યા કોડિંગ: દા.ત. A=1, B=2... then word sum/average/product

    મહત્વની ટિપ્સ:
    • કોડ શોધવા માટે પ્રથમ અને છેલ્લા અક્ષર સાથે શરૂઆત કરો.
    • કોઈ એક નિયમ બધા અક્ષરો પર લાગુ પડે છે કે અલગ અલગ?
    • ડિકોડિંગમાં ઊલટું પ્રયાસ કરો: શબ્દમાંથી કોડ બનાવો.
  • રક્ત સંબંધ (Blood Relations): રક્ત સંબંધ પ્રશ્નોમાં માહિતી આપેલી હોય છે અને સંબંધ પૂછાય છે. ઉકેલવા માટે વંશાવળી/પરિવાર વૃક્ષ (Family Tree) બનાવવું શ્રેષ્ઠ.

    પરિચિત સંબંધો:
    • પિતાનો પિતા = દાદા / માતાનો પિતા = નાના/મોટા દાદા
    • પિતાની માતા = દાદી / માતાની માતા = નાની/મોટી દાદી
    • પિતાનો ભાઈ = કાકા (ચાચો) / માતાનો ભાઈ = મમા/મમાશા
    • પિતાની બહેન = ચાચી / માતાની બહેન = મમાઈ
    • પુત્રનો પુત્ર = પોત્ર / પુત્રની પુત્રી = પોતી
    • ભાઈનો પુત્ર = ભત્રીજો / બહેનનો પુત્ર = ભાતીજો

    ઉકેલ સૂત્ર:
    • માહિતી શરૂ કરો → સૌથી દૂરનો સંબંધ શોધો → વંશાવળીમાં ઉતરો/ચડો
    • 'વનું' = ઉપરની તરફ (વાળક), 'વાળાનું' = નીચેની તરફ
    • 'અવર' = એટલે 'કે જે'

    ઉદાહરણ: A, B નો પુત્ર છે. B, C ની પુત્રી છે. A, C નું શું?
    → B, C નો પુત્ર = A, B નો પુત્ર = A, C નો પૌત્ર
  • દિશા જાણ (Direction Sense): ચાર મૂળભૂત દિશાઓ: ઉત્તર (N), દક્ષિણ (S), પૂર્વ (E), પશ્ચિમ (W). તેમની વચ્ચેના કોણો અને દિશા ફેરફાર.

    મૂળભૂત નિયમો:
    • જમણી બાજુ = પૂર્વ તરફ (ઉત્તર મુખી હોય)
    • ડાબી બાજુ = પશ્ચિમ તરફ (ઉત્તર મુખી હોય)
    • સામે મુખી = વિરુદ્ધ દિશા
    • જો માથું ઉત્તર તરફ હોય, તો જમણો હાથ = પૂર્વ, ડાબો હાથ = પશ્ચિમ

    મહત્વની ટિપ્સ:
    • આકૃતિ/ચિત્ર બનાવો → દિશા ચિહ્નિત કરો
    • 'કેમ' પૂછાય તો પ્રારંભિક દિશા ધ્યાનમાં રાખો
    • પાવલ સંખ્યા × દિશા = યોગ્ય વિકલ્પ
    • જ્યારે વ્યક્તિ ઉત્તર તરફથી જમણું ફરે → પૂર્વ, પાછળ → દક્ષિણ, ડાબું → પશ્ચિમ

    સમસ્યા: એક વ્યક્તિ ઉત્તર તરફ 10 m ચાલે, જમણું ફરે 5 m, પાછું ફરીને 10 m. તે પ્રારંભથી કેટલા મેટર દૂર?
    → પાયથાગોરસ: √(10²+5²) = √125 ≈ 11.18 m (પશ્ચિમ તરફ)
  • શ્રેણી અને ક્રમ (Series & Ranking): શ્રેણી પ્રશ્નો: પ્રવાહમાં લુપ્ત પદ શોધવું. સંખ્યા શ્રેણીના પ્રકારો:
    • સમ આગળ: દા.ત. 2, 5, 8, 11, ? → +3 → 14
    • સમ પાછળ: દા.ત. 20, 17, 14, 11, ? → -3 → 8
    • ગુણોત્તર: દા.ત. 3, 6, 12, 24, ? → ×2 → 48
    • વર્ગ શ્રેણી: દા.ત. 1, 4, 9, 16, ? → n² → 25
    • વર્ગ મિશ્ર: દા.ત. 2, 5, 10, 17, ? → n²+1 → 26
    • ત્રિકોણીય: દા.ત. 1, 3, 6, 10, ? → +2,+3,+4 → 15
    • અક્ષર શ્રેણી: દા.ત. A, C, F, J, ? → +2,+3,+4 → O (+5)

    ક્રમ/શ્રેણી સૂત્ર:
    • કુલ વ્યક્તિ = A ને આગળ + A ને પાછળ - 1
    • જો A ને આગળ m અને પાછળ n હોય: કુલ = m + n + 1
    • A ને આગળ X અને પાછળ Y (કુલ N): X = N-Y+1
  • વિધાન અને નિષ્કર્ષ (Statement & Conclusion): વિધાન (Statement) માં આપેલી માહિતીથી નિષ્કર્ષ (Conclusion) નક્કી કરવા.

    નિયમો:
    • સાચું વિધાન → જે નિષ્કર્ષ તાર્કિક રીતે follows કરે છે તે સાચો.
    • જાહેરાત/પ્રશ્નમાં જમણી બાજુનું વિધાન સત્ય ધારો, ભલે યુક્તિસર ન લાગે.
    • 'કદાચ', 'શક્ય છે' જેવા શબ્દો સામાન્યે શક્ય નિષ્કર્ષ તરફ સૂચવે છે.
    • અતિશયોક્તિ (overstatement) ટાળો — વિધાનમાં ન હોય તેવું નિષ્કર્ષમાં ન આવે.

    ઉદાહરણ:
    વિધાન: બધા વિદ્યાર્થીઓ ગુજરાતી બોલે છે. કેટલાક વિદ્યાર્થીઓ હિન્દી પણ બોલે છે.
    નિષ્કર્ષ I: બધા ગુજરાતીઓ હિન્દી બોલે છે. → ❌
    નિષ્કર્ષ II: કેટલાક ગુજરાતીઓ હિન્દી બોલે છે. → ✅
  • સાધારણ તર્કશાસ્ત્ર / સિલોજિઝમ (Syllogism): સિલોજિઝમમાં વિધાન અને નિષ્કર્ષ જોવાના.

    પ્રકાર:
    • બધા A, B છે (Universal Affirmative)
    • કોઈ A, B નથી (Universal Negative)
    • કેટલાક A, B છે (Particular Affirmative)
    • કેટલાક A, B નથી (Particular Negative)

    વેન આકૃતિ (Venn Diagram) નિયમ:
    • બધા A, B છે → A નો વર્તુળ B ની અંદર
    • કોઈ A, B નથી → બે અલગ વર્તુળ
    • કેટલાક A, B છે → બે વર્તુળ છેદે

    નાની યાદ રાખો:
    • બધા + બધા = બધા (પહેલું અને છેલ્લું)
    • બધા + કોઈ નથી = કોઈ નથી
    • બધા + કેટલાક = કેટલાક
    • બંને વિશેષ (Some) → નિષ્કર્ષ નથી
    • બંને ઋણ → નિષ્કર્ષ નથી
    • એક ઋણ, એક વિશેષ → બધા + વિશેષ = વિશેષ
  • પાસો અને ઘન (Dice and Cube): પાસા (Dice) ના નિયમો:
    • સામાન્ય પાસો: વિરુદ્ધ બાજુઓનો સરવાળો = 7 (1+6, 2+5, 3+4)
    • જો બે પાસા સમાન હોય અને એક સામાન્ય સંખ્યા હોય, તો બાકી બે સંખ્યાઓ વિરુદ્ધ હોય.
    • જો એક સંખ્યા સમાન હોય, તો બાકીની બાજુઓ વિરુદ્ધ હોય.

    ઘન (Cube) ના ટુકડા:
    • n×n×n ઘનને k×k×k ટુકડામાં વિભાજીત કરવો:
    - કુલ ટુકડા = n³
    - 3 બાજુ રંગાયેલા = 8 (સૌથી વધુ)
    - 2 બાજુ રંગાયેલા = 12(n-2)
    - 1 બાજુ રંગાયેલા = 6(n-2)²
    - રંગ નહિથી ટુકડા = (n-2)³

    ઉદાહરણ: 4×4×4 ઘન → 4³=64 ટુકડા, 3-બાજુ=8, 2-બાજુ=12(2)=24, 1-બાજુ=6(4)=24, 0-બાજુ=8
  • બેઠક ગોઠવણી (Seating Arrangement): બેઠક ગોઠવણી પ્રકારો:
    • સીધી રેખા (Straight Line): L/R, વમન/દક્ષિણ, સામે મુખી
    • વૃત્તાકાર (Circular): અંદર/બહાર મુખી, સમૂહ
    • આયતાકાર/ચોરસ

    મહત્વની શરતો:
    • 'A, B ની ડાબે બેસે છે' = A, B ની ડાબી બાજુ
    • 'A, B ને સામે મુખી' = A બહાર, B અંદર (અથવા ઉલ્ટું)
    • બેઠક દૃષ્ટિએ: વ્યક્તિ જે તરફ જોઈ રહી હોય તે દિશા ગણવી.

    ઉકેલ રીત:
    1. પહેલા સૌથી અમુક યોગ્ય મહત્વની સ્થિતિ મૂકો.
    2. એક-એક શરત લાગુ કરો.
    3. વિરોધાભાસ ચકાસો.
    4. વિકલ્પ સાથે મેળવો.

Important facts

  • A=1, B=2, ... Z=26. વિષમ સ્થાન (B,D,F,H,J,L,N,P,R,T,V,X,Z) અને સમ સ્થાન (A,C,E,G,I,K,M,O,Q,S,U,W,Y).
    • EZRA QCJ = Y B M (સામસામું અક્ષર): A↔Z, B↔Y, C↔X...
  • વર્ગ સંખ્યાઓ: 1,4,9,16,25,36,49,64,81,100; વર્ગમૂળ: √1=1,√4=2,√9=3,√16=4,√25=5,√36=6,√49=7,√64=8,√81=9,√100=10.
  • પાસા પર વિરુદ્ધ બાજુઓનો સરવાળો હંમેશા 7. ઘનના ટુકડા: 3-બાજુ રંગાયેલા = 8; 2-બાજુ = 12(n-2); 1-બાજુ = 6(n-2)²; રંગ નહિ = (n-2)³.
  • રક્ત સંબંધ: પિતાનો પિતા = દાદા; માતાનો પિતા = નાના/મોટા દાદા; પિતાનો ભાઈ = કાકા(ચાચો); માતાનો ભાઈ = મમા; પિતાની બહેન = ચાચી; માતાની બહેન = મમાઈ.
  • વિધાન-નિષ્કર્ષ: જાહેરાત/પ્રશ્નમાં અંતર્ગત વિધાન સત્ય ધારવું. જો વિધાન સત્ય હોય, તો નિષ્કર્ષ તાર્કિક રીતે follow થાય તો સાચો. અતિશયોક્તિ ટાળો.
  • સિલોજિઝમ: બધા A B છે; બધા B C છે → બધા A C. બધા A B; કોઈ B C નથી → કોઈ A C નથી. બધા A B; કેટલાક B C → કેટલાક A C. બે વિશેષ/બે ઋણ → નિષ્કર્ષ નથી.
  • દિશા જાણ: ઉત્તર → જમણું → પૂર્વ; ઉત્તર → ડાબું → પશ્ચિમ; ઉત્તર → પાછળ → દક્ષિણ. પાવલ સંખ્યા × દિશા = યોગ્ય માર્ગ.
  • શ્રેણી પ્રકારો: સમઆગળ(+), સમપાછળ(-), ગુણોત્તર(×), વર્ગ(n²), વર્ગમિશ્ર(n²±k), ત્રિકોણીય. અક્ષર શ્રેણી: +2,+3,+4... શૃંખલા.

Memory aids

  • અક્ષર કોડ: EZRA QCJ → YBHM 'જમણું કોઈ નથી' એ યાદ રાખો (EZRA→DYCE? No— સામસામું: E→V, Z→A, R→I, A→Z; QCJ→XZI). સાચો: વર્ણમાળા સામસામી જોડ: A↔Z, B↔Y, C↔X, D↔W, E↔V, F↔U, G↔T, H↔S, I↔R, J↔Q, K↔P, L↔O, M↔N. મંત્ર: 'AT BG CH DI EJ FK GL HM IN' — આ રીતે યાદ રાખો.
  • વર્ગ સંખ્યાઓ યાદ: 'એક ચાર નવ સોળ, પચાવી, બાવીસ, એકવીસ, છપ્પન, અઠ્ઠ્યાણસ, સો' — 1,4,9,16,25,36,49,64,81,100.
  • રક્ત સંબંધ: 'દાદા દાદી — માતા-પિતા; કાકા ચાચી — માતા-પિતા; મમા મમાઈ — માતા-પિતા; ભત્રીજો ભાતીજો — પિતૃ/માતૃ.' પિતૃ પક્ષ = કાકા/ચાચી, માતૃ પક્ષ = મમા/મમાઈ. ભત્રીજો = ભાઈનો પુત્ર, ભાતીજો = બહેનનો પુત્ર.
  • પાસો-ઘન: 'આઠ સોળ છ્હત્તર' = 3-બાજુ 8, 2-બાજુ 12(n-2), 1-બાજુ 6(n-2)². ઘન ટુકડા યાદ: n³ કુલ, (n-2)³ રંગ વગર.
  • સિલોજિઝમ મંત્ર: 'બધા બધા બધા; બધા-નેગેટિવ નેગેટિવ; બધા કેટલાક કેટલાક. બે કેટલાક કે બે નેગેટિવ — નિષ્કર્ષ નહીં!'

Exam tips

  • GSSSB પ્રશ્નોમાં સરખામણી, કોડિંગ, રક્ત સંબંધ, દિશા જાણ અને શ્રેણી સૌથી વધુ આવે. આ તમામની પુનરાવર્તિત પ્રેક્ટિસ ફરજિયાત.
  • રક્ત સંબંધ પ્રશ્નોમાં વંશાવળી કાગળ પર બનાવો — માથે માતા-પિતા, નીચે બાળકો. આંખે જોઈ શકશો અને ખોટા જવાબ ટાળશો.
  • કોડિંગ-ડિકોડિંગમાં પ્રથમ અક્ષર અને છેલ્લા અક્ષર સાથે શરૂઆત કરો. સામસામું અક્ષર (Opposite) સૌથી સામાન્ય છે — EZRA MCJ યાદ રાખો.
  • પાસા-ઘનમાં સૂત્ર યાદ રાખો: 3-બાજુ=8, 2-બાજુ=12(n-2), 1-બાજુ=6(n-2)², 0-બાજુ=(n-2)³. n=4 માટે આ યાદ કરો.
  • સિલોજિઝમ માટે વેન આકૃતિ (Venn Diagram) સૌથી વિશ્વસનીય રીત. પ્રશ્નમાં આકૃતિ બનાવો, સીધો જવાબ મળી જાય છે.
  • વિધાન-નિષ્કર્ષ પ્રશ્નમાં વિધાનનું પૂર્ણ અર્થઘટન કરો. વિધાનમાંથી સાચો નિષ્કર્ષ કાઢો, અનુમાન ન લગાડો.
  • દિશા જાણમાં ચિત્ર બનાવો — ઉત્તર ઉપર, દક્ષિણ નીચે, પૂર્વ જમણી, પશ્ચિમ ડાબી. રેખા દોરીને માપ કરો.
  • શ્રેણી પ્રશ્નમાં પહેલું પદ દૂર કરી બાકીના તફાવત જુઓ. વિકલ્પમાં મૂકીને ચકાસો — ઝડપી અને ચોક્કસ.
  • GSSSB માં આપને ઘણા પ્રશ્નો 'ઓછામાં ઓછો પ્રયાસ' વલણ ધરાવે છે. દરેક પ્રશ્ન બાદ ચકાસણી કરો — ખોટા જવાબ માટે નકારાત્મક અંક (if any) હોય.

Common traps

  • સરખામણીમાં વિકલ્પ A,B,C,D માં બધા જ સંબંધ લાગે તેમ લાગે — સૌથી ચોક્કસ અને ચોખ્ખો સંબંધ શોધો. વિરોધી/સહચર સંબંધને સામાન્ય ઉત્પાદક સંબંધ સમજી મોટી ગંદગી કરવી.
  • રક્ત સંબંધ પ્રશ્નમાં 'તારા પિતાના ભાઈનો પુત્ર' = તમારો કાકો/ચાચો; 'તારી માતાના ભાઈનો પુત્ર' = તમારો મમાશા. ખોટી જોડણી: કાકા અને મમા એક જ માનવી.
  • દિશા જાણમાં 'જમણું' 'ડાબું' કોણના જમણે/ડાબે એવી ગૂંચવણ. હંમેશા વ્યક્તિના મુખ તરફની દિશાથી જમણે/ડાબે ફરવું.
  • વિધાન-નિષ્કર્ષમાં વિકલ્પ I અને II બંને સાચા લાગે પણ નિષ્કર્ષ વિધાનથી બહાર થાય. વિધાનમાં નહીં હોય તેવું નિષ્કર્ષમાં આવે તો ખોટું.
  • સિલોજિઝમમાં બે 'કેટલાક' (Some-All, Some-Some) મિશ્રણમાં નિષ્કર્ષ નીકળતો નથી પણ આપણે નીકળતો માની લઈએ છીએ. બે ઋણ પ્રમેય પણ નિષ્કર્ષ આપતા નથી.
  • પાસા પ્રશ્નમાં વિરુદ્ધ બાજુઓનો સરવાળો 7 હોય છે — પણ આ નિયમ સંપૂર્ણપણે સાચો નથી જ્યારે પાસો માર્કિંગ અલગ હોય. તેથી યોગ્ય રીતે ચકાસવું જરૂરી.
  • શ્રેણીમાં +,×, વર્ગ મિશ્ર લાગુ પડે છે પણ અંતિમ પદ શોધવા માટે વિકલ્પમાં મૂકીને ચકાસવું આવશ્યક. નિરાધાર અનુમાન થાય છે.
  • રક્ત સંબંધ 'કોણ' પૂછે છે તો 'કે?' સામેથી જવાબ આપવો — 'તારો કાકો' નહીં 'કાકો' લખવું.
