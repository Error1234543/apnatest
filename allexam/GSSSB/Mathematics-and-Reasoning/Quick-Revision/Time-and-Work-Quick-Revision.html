સમય અને કાર્ય — ગેરિયા ગાઈડ (Quick Revision)

GSSSBGujaratiQuick Revision

Definitions

  • કાર્ય (Work): કોઈ પણ કામ પૂરું કરવાની માત્રા. સામાન્ય રીટે 1 એકમ કાર્ય (પૂરું કામ) લેવામાં આવે છે.
  • દર/ક્ષમતા (Rate/Efficiency): એક વ્યક્તિ કે જૂથ દ્વારા એકમ સમયમાં કરવાતું કાર્ય. ઉદાહરણ: A 10 દિવસમાં કામ પૂરું કરે → દૈનિક ક્ષમતા = 1/10.
  • સમય (Time): કામ પૂરું કરવા માટે જરૂરી દિવસો/કલાકો.
  • કાર્ય = દર × સમય (W = R × T): સૌથી મૂળભૂત સંબંધ. જો 1 એકમ કાર્ય હોય તો સમય = 1/દર.
  • MDH સૂત્ર: M₁D₁H₁E₁/W₁ = M₂D₂H₂E₂/W₂, જ્યાં M = મજૂરો, D = દિવસો, H = દૈનિક કલાકો, E = ક્ષમતા પ્રતિશત.

Key concepts

  • • 1 વ્યક્તિ n દિવસમાં કામ પૂરું કરે → તેનો દૈનિક ભાગ = 1/n.
    • A, B સ્વતંત્ર રીતે a અને b દિવસમાં કામ પૂરું કરે → સાથે કામ કરે તો દિવસો = ab/(a+b).
    • A, B સાથે c દિવસમાં કામ પૂરું કરે. A સિંગલ a દિવસમાં કરે → B નો સમય = ac/(a-c).
    • ત્રણ લોકો A, B, C અનુક્રમે a, b, c દિવસમાં કરે → સાથે = abc/(ab+bc+ca).
    • સાવચેત: 'એકલા' શબ્દનો અર્થ સિંગલ રેટ થાય, 'સાથે' એટલે સરવાળો.
  • • ક્ષમતા સમપ્રમાણમાં કાળજીકામ / સમય હોય છે.
    • જો A, B ની ક્ષમતાનો ગુણોત્તર p:q હોય → કામ પૂરું કરવાનો સમયનો ગુણોત્તર q:p થાય.
    • પગારનો ભાગ = દરેકનો યોગદાન દ્વારા નક્કી થાય (સમાન સમય સરખામણીએ કામ પ્રમાણમાં).
    • ઉદા: A 10 દિવસે, B 15 દિવસે → ગુણોત્તર 3:2, કુલ ₹500 માં A = ₹300, B = ₹200.
  • • A, B સાથે a દિવસમાં પૂરું કરે. B એકલો b દિવસમાં કરે. જો A જોડાય પહેલા c દિવસે છૂટો પડે → A ના કાળજીકાળનો ભાગ = c/a, બાકી (a-c)/a B કરે → B ને લાગતો સમય = (a-c)/a × b.
    • વ્યસ્ત રીતે પણ ઉકેલ શકાય: A નો દર = 1/a - 1/b, પછી સામાન્ય R = 1/a.
    • સામાન્ય ભૂલ: A/B નો દર wrong રીતે add કરવો અથવા બાદબાકી કરવી.
  • • A દર રવિવારે, B દર સોમવારે કામ કરે. એક ચક્ર (2 દિવસ) માં કાર્ય = 1/a + 1/b.
    • કુલ કાર્ય N હોય, તો ચક્રની સંખ્યા = N/(1/a+1/b). બાકીનો કામ એક દિવસમાં કોઈ એક કરે.
    • ગમે તે દિવસે શરૂ થાય તો આગળનો રિપિટિંગ પેટર્ન સાથે મૂકો.
    • સામાન્ય પ્રશ્ન: A=20 દિવસ, B=30 દિવસ. એક ચક્ર=1/20+1/30=1/12. કુલ 12 ચક્ર=24 દિવસ. આ 24 દિવસે કામ પૂરું (અહીં ચક્રની વહેંચણીને કારણે).
  • • ભરનાર (Inlet): પાણી ભરે → દર ધન.
    • ખાલી કરનાર (Outlet): પાણી ખાલી કરે → દર ઋણ.
    • A a કલાકમાં ભરે, B b કલાકમાં ખાલી કરે → સાથે ભરાઈ: 1/(1/a - 1/b) = ab/(b-a).
    • શરત: b > a (ખાલી કરનાર અડધો વારો લાગે). નહીંતર ક્યારેય ભરાશે નહીં.
    • ત્રણ નળ: A(a), B(b) ભરે, C(c) ખાલી કરે → ભરાઈ = 1/(1/a+1/b-1/c).
  • • મૂળભૂત સૂત્ર: M₁D₁H₁E₁/W₁ = M₂D₂H₂E₂/W₂.
    • જો બધું સમાન (સમાન કામ, સમાન શક્તિ) → M₁D₁ = M₂D₂.
    • દૈનિક કલાક બદલાય તો H પણ ગણતરીમાં લો.
    • ઉદા: 10 લોકો 8 કલાક/દિવસે 15 દિવસ = 1200 MDH. 15 લોકો 6 કલાક → D = 1200/(15×6) = 13.33 દિવસ.
  • • A સમયે નિશ્ચિત સમય માટે કામ કરે, પછી અંતરાલ ગુમાવે. ઉદા: 4 કલાક કામ, 1 કલાક બ્રેક. 24 કલાકમાં 4 પૂર્ણ ચક્ર + બાકી. ચક્ર = 5 કલાક, દરેકમાં 4 કલાક કામ. 24/5=4 ચક્ર, બાકી 4 કલાક. કુલ કાળજી = 4×4+4=20 કલાક કાર્ય.
    • આવા પ્રશ્નોમાં 'કાળજીકાળ vs નિશ્ચિત કલાક' અલગ ગણો.
  • • 1 એકમ કામ લેવાને બદલે LCM પદ્ધતિ વાપરો: A=a દિવસ, B=b દિવસ → કુલ કામ = LCM(a,b). દરો = કામ/a અને કામ/b. આથી તમામ ગણતરી પૂર્ણાંકમાં રહે.
    • ઉદા: a=10, b=15 → LCM=30 એકમ કામ. Aનો દર=3, Bનો=2. સાથે=5 એકમ/દિવસ → 30/5=6 દિવસ.
    • આ પદ્ધતિ બ્રેક, યોગદાન, B દ્વારા કરવામાં આવેલો ભાગ બધા માટે સરળ બનાવે છે.

Important facts

  • A સિંગલ a, B સિંગલ b દિવસે → સાથે c = ab/(a+b) દિવસ. આ સૌથી વધુ આવતો સૂત્ર.
  • A, B સાથે c દિવસે, A સિંગલ a દિવસે → B સિંગલ = ac/(a-c) દિવસ. (a>c હોવો જોઈએ.)
  • A, B, C અનુક્રમે a, b, c દિવસે → સાથે = abc/(ab+bc+ca) દિવસ.
  • ક્ષમતા ગુણોત્તર p:q → સમય ગુણોત્તર q:p (વ્યસ્ત સંબંધ).
  • પગાર વહેંચણી = કાળજીકામ/સમય પ્રમાણ (જો સમય સમાન હોય તો દર પ્રમાણ, નહીંતર કાળજીકાળ પ્રમાણ).
  • વાહક/નાળી: સમાન કલાકમાં A a કલાકે ભરે, B b કલાકે ખાલી કરે → ભરાઈ = ab/(b-a).
  • A+B સાથે c દિવસે, B+C સાથે d દિવસે, C+A સાથે e દિવસે → A+B+C સાથે = 2cde/(2(cd+de+ec)) ? નહીં, સાચો માર્ગ: દરોનો સરવાળો લઈ એકસાથે ઉકેલો.
  • એકત્ર કાળજીકાળ (Total Person-days) = શ્રમિકો × દિવસો. આ એકમ કામ માટે સ્થિર રહે છે.
  • Bએ કરેલો ભાગ = (Bનો દર) × (સાથે કામ કરેલા દિવસો).
  • લીકેજ (વાહકમાં સોંઠો): A a કલાકમાં ભરે, L l કલાકમાં ખાલી કરે → ભરાઈ = al/(l-a). l≤a હોય તો ભરાશે નહીં.

Memory aids

  • "સાથેનો સમય = a×b/(a+b)" — બે અંકોનો ગુણાકાર, સરવાળાથી ભાગો. "જોડાઈ/કપાઈ જાય છે એટલે નીચે ગુણો, ઉપર સરવાળો."
  • "LCM લે, દર શોધ, ફરી ભાગ" — ત્રણ પગલાની યાદ: LCM(કામ) → દર → સમય. આ પદ્ધતિથી તમામ પ્રકારના પ્રશ્નો આપોઆપ પૂર્ણાંકમાં ઉકલાય છે.
  • "ક્ષમતા વધે, સમય ઘટે" — ગુણોત્તર ઉલટાઈ જાય. p:q → q:p. યાદ રાખો: 'સીધો ગુણોત્તર → ક્ષમતા, વ્યસ્ત ગુણોત્તર → સમય.'
  • "વાહક/નાળી: નીચે b-a, ઉપર a×b" — ખાલી કરનારનો સમય મોટો હોવો જોઈએ (b>a). નહીંતર ઋણ/અર્થહીન.
  • "Bએ કરેલો ભાગ = (Bનો દર) × (A,B સાથે કામ કરેલા દિવસ)" — A છૂટો પડે ત્યારે B એકલો ચાલુ રહે, Bનો ભાગ = 1 - Aનો ભાગ.
  • "MDH વેબ" = M×D×H. તફાવતો D માં મૂકો, M/H બાદમાં વાપરો.

Exam tips

  • GSSSB માં Time & Work પ્રશ્નો સામાન્ય રીતે સીધા, એક-પગલાની અથવા બે-પગલાની ગણતરી ધરાવે છે. LCM પદ્ધતિ (30/20=1.5 etc.) વાપરો, તો ગાણિતિક ભૂલ ઓછી થાય.
  • "A leaves early" પ્રશ્નમાં બે ભાગ કરો: (1) A અને B સાથે કામ, (2) A ગયા પછી B એકલો. બંને ભાગનો ભાગાકાર અલગ કરીને બાદમાં જવાબ લો.
  • દરેક પ્રશ્નમાં પહેલા 'કયું મૂળભૂત સૂત્ર લાગે?' એ નક્કી કરો — 90% પ્રશ્નો 'સાથે = ab/(a+b)' પરથી ઉકલાય છે.
  • MDH પ્રશ્નમાં બધા 4 ચલ (M, D, H, E) નો ઉપયોગ તપાસો. એક પણ ચૂકાવો તો જવાબ ખોટો.
  • જવાબ તપાસો: A નો દર + B નો દર = સાથેનો દર. દરોનો સરવાળો ચકાસી લો.
  • ક્ષમતા/પગાર પ્રશ્ન: ક્ષમતાનો ગુણોત્તર યાદ રાખો, સમય નહીં. જવાબ ચકાસો: A+B નો પગાર કુલ રકમ બરાબર હોવો જોઈએ.
  • વાહક પ્રશ્ન: outlet > inlet હોવું જોઈએ (એટલે b > a, જ્યાં b = outlet time). જવાબ ધન આવે તો જ ચકાસો.
  • "A, B સાથે c દિવસે, A સિંગલ a દિવસે" — B = ac/(a-c). આ સૂત્ર બહુ આવે છે, યાદ રાખો.
  • જો અંકમાં 'દરરોજ 4 કલાક' લખ્યું હોય તો MDH માં H=4 લખવું. ઘણા વિદ્યાર્થીઓ તે અવગણી દે છે.
  • જવાબ ચકાસણીનો મંત્ર: 'દર × સમય = કાળજીકાળ'. દરોનો સરવાળો ચકાસો. જેટલું સરળ, તેટલો ઝડપી.

Common traps

  • "A અને B સાથે c = a+b" — શૂન્ય! સાચો જવાબ ab/(a+b). ઘણા વિદ્યાર્થીઓ add કરી દે છે.
  • "B એકલો b/dિવસે" — જ્યારે A, B સાથે c દિવસે કરે, A સિંગલ a દિવસે → B નો દર = 1/c - 1/a = (a-c)/ac → B સિંગલ = ac/(a-c). ઘણા 1/a - 1/c ગણે (વ્યસ્ત ગણે).
  • "Pipes: ભરાઈ = 1/(1/a+1/b)" — ખાલી કરનારનો દર ઋણ લેવો જોઈએ: 1/a - 1/b.
  • "Bએ કરેલો ભાગ = Bનો દર × કુલ દિવસ" — ખોટું! Bએ તે જ દિવસો કામ કર્યું જેટલો A સાથે કામ કર્યું; A છૂટા પડ્યા પછી B એકલો, પણ Aનો દર Bના ભાગાકારમાં આવે છે કે неતો.
  • "વાહકમાં leakage: સામાન્ય ભૂલ a અને b બંને ભરનારા ધોઈ લેવા. b એટલે ખાલી કરનાર, તેનો દર ઋણ છે."
  • "ગુણોત્તરનો ઉલટાવાડ – 3:5 ક્ષમતા → 5:3 સમય. ઘણા 3:5 hi રાખે."
  • "અંતિમ જવાબમાં એકમ ન લખવો" — દિવસ, કલાક, રૂપિયા યોગ્ય એકમ સાથે.
  • "દિવસ-દર vs સમય-દરની ગંદગી" — દર = કાળજીકાળ, સમય = 1/દર. ગંદગી ન કરો.
