૧. સંખ્યા પદ્ધતિ (Number System)

ગણિતના મૂળભૂત ઘટકો સંખ્યાઓ છે. આ ખંડમાં સંખ્યા પ્રકારો, તેમના ગુણધર્મો અને BODMAS નિયમ પર વિગતવાર ચર્ચા કરવામાં આવી છે.

■ સંખ્યા પ્રકારો:
• કુદરતી સંખ્યાઓ (Natural Numbers): ૧, ૨, ૩, ... — શૂન્ય સહિત નથી. અનંત સંખ્યામાં હોય છે. મહત્તમ કુદરતી સંખ્યા ન હોય.
• પૂર્ણ સંખ્યાઓ (Whole Numbers): ૦, ૧, ૨, ૩, ... — કુદરતી સંખ્યાઓ + શૂન્ય. કુદરતી સંખ્યાઓ પૂર્ણ સંખ્યાઓની ઉપસમૂહ છે, પણ પૂર્ણ સંખ્યાઓ કુદરતી સંખ્યાઓ નથી.
• પૂર્ણાંકો (Integers): ..., -૩, -૨, -૧, ૦, ૧, ૨, ૩, ... — ઋણ અને ધન સંખ્યાઓ સહિત શૂન્ય.
•યુગ્મ સંખ્યા (Even Number): ૨ વડે ભાગી શકાય એવી પૂર્ણ સંખ્યા. ઉદા: ૨, ૪, ૬, ૮...
•અયુગ્મ સંખ્યા (Odd Number): ૨ વડે ભાગી ન શકાય. ઉદા: ૧, ૩, ૫, ૭...
•અવિભાજ્ય સંખ્યા (Prime Number): ૧ અને પોતાને સિવાય કોઈથી ભાગી ન શકાય. ઉદા: ૨, ૩, ૫, ૭, ૧૧, ૧૩, ૧૭, ૧૯...
•સંયુક્ત સંખ્યા (Composite Number): ૧ અને પોતાને સિવાય પણ અન્ય અવયવ ધરાવતી સંખ્યા. ઉદા: ૪, ૬, ૮, ૯, ૧૦...
•શુદ્ધ સંખ્યા (Pure Number): દશાંશમાં અપૂર્ણાંશ ભાગ ન હોય. ઉદા: ૪૦૦, ૭૨૦૦
•અશુદ્ધ સંખ્યા (Impure Number): દશાંશમાં અપૂર્ણાંશ ભાગ હોય. ઉદા: ૪૫.૬૭, ૭૨.૮૯

■ સંખ્યાના ગુણધર્મો:
• બે યુગ્મ સંખ્યાનો ગુણોત્તર હંમેશા યુગ્મ હોય છે.
• એક યુગ્મ અને એક અયુગ્મનો ગુણાકાર હંમેશા યુગ્મ જ હોય છે.
• બે અયુગ્મ સંખ્યાઓનો ગુણાકાર હંમેશા અયુગ્મ હોય છે.
• કોઈ પણ વાસ્તવિક સંખ્યા x માટે: |x| ≥ 0. |x| = x જો x ≥ 0, અને |x| = -x જો x < 0.

■ BODMAS નિયમ (સરળીકરણ માટે):
B — સંબંધિત (Brackets)
O — ઘાત/વર્ગમૂળ (Orders)
D — ભાગાકાર (Division)
M — ગુણાકાર (Multiplication)
A — જોડ (Addition)
S — બાદ (Subtraction)

ઉદાહરણ: ૧૨ + [૮ - {૬ - (૪ - ૨)}] = ?
સમાધાન: ૪ - ૨ = ૨ → ૬ - ૨ = ૪ → ૮ - ૪ = ૪ → ૧૨ + ૪ = ૧૬

■ યાદ રાખવાના મહત્વપૂર્ણ તથ્યો:
• ૧ એ અવિભાજ્ય સંખ્યા નથી.
• ૨ એ એકમાત્ર યુગ્મ અવિભાજ્ય સંખ્યા છે.
• ૧ થી ૧૦૦ સુધીમાં ૨૫ અવિભાજ્ય સંખ્યાઓ છે.
• બે ક્રમિક અવિભાજ્ય સંખ્યાઓ ૨ અને ૩ તફાવત ઉપરાંત ક્યારેય હોતી નથી.

૨. લ.સા.અ અને ગ.સા.અ (LCM and HCF)

લ.સા.અ અને ગ.સા.અ અંકગણિતના સૌથી વધુ ઉપયોગી ભાગ છે, ખાસ કરીને ગતિસંબંધી પ્રશ્નો, સાપેક્ષ ગતિ અને ટાઇમ-એન્ડ-વર્ક પ્રકારના પ્રશ્નોમાં તેમનો ઉપયોગ થાય છે.

■ વ્યાખ્યાઓ:
• લ.સા.અ (LCM - Least Common Multiple): બે કે તેથી વધુ સંખ્યાઓની સામાન્ય ગુણિત સંખ્યાઓ પૈકી સૌથી નાની સંખ્યા. તે બધા જ સંખ્યાઓ વડે સંપૂર્ણ ભાગી શકાય.
• ગ.સા.અ (HCF - Highest Common Factor): બે કે તેથી વધુ સંખ્યાઓની સામાન્ય અવયવો પૈકી સૌથી મોટી સંખ્યા.

■ ગ.સા.અ શોધવાની પદ્ધતિઓ:
પદ્ધતિ ૧ — વિભાજ્ય અવયવ પદ્ધતિ:
ઉદા. ૧૨, ૧૮ અને ૨૪ નું ગ.સા.અ શોધો.
૨) ૧૨, ૧૮, ૨૪
૨) ૬, ૯, ૧૨
૩) ૩, ૯, ૬
૧, ૩, ૨
ગ.સા.અ = ૨ × ૨ × ૩ = ૧૨

પદ્ધતિ ૨ — સમ્પૂર્ણ અવયવ પદ્ધતિ:
૧૨ = ૨² × ૩
૧૮ = ૨ × ૩²
ગ.સા.અ = ૨ × ૩ = ૬

■ લ.સા.અ શોધવાની પદ્ધતિઓ:
પદ્ધતિ ૧ — વિભાજ્ય અવયવ પદ્ધતિ:
ઉદા. ૧૨, ૧૮ અને ૩૦ નું લ.સા.અ શોધો.
૨) ૧૨, ૧૮, ૩૦
૩) ૬, ૯, ૧૫
૩) ૨, ૩, ૫
૨, ૧, ૫
લ.સા.અ = ૨ × ૩ × ૩ × ૨ × ૫ = ૧૮૦

પદ્ધતિ ૨ — સમ્પૂર્ણ અવયવ પદ્ધતિ:
૧૨ = ૨² × ૩
૧૮ = ૨ × ૩²
૩૦ = ૨ × ૩ × ૫
લ.સા.અ = ૨² × ૩² × ૫ = ૧૮૦

■ મહત્વનાં સૂત્રો:
• બે સંખ્યાઓ માટે: a × b = લ.સા.અ(a,b) × ગ.સા.અ(a,b)
• જો બે સંખ્યાઓ પરસ્પર અવિભાજ્ય (coprime) હોય, તો તેમનો ગ.સા.અ ૧ થાય.
• ગ.સા.અ હંમેશા એકંદર સંખ્યાઓના લ.સા.અ કરતા નાનું કે બરાબર હોય છે.
• જો a, b, c ને α ને β વડે ભાગતા ફેર 1, 2, 3 આવે, તો લ.સા.અ = K × α × β × γ, જ્યાં K = ફેરનો ગુણોત્તર (અહીં સામાન્ય રીતે K=1).

■ ઉપયોગિતા:
• કોઈ પણ સંખ્યા જે α, β, γ વડે ભાગતા બરાબર ફેર 1, 2, 3 આપે તે સંખ્યાનું લ.સા.અ = (α×β×γ×K) + શેષ
• જ્યારે α, β, γ વડે ભાગતા અવશેષ સમાન r આવે, તો માગેલ સંખ્યા = (લ.સા.અ(α,β,γ)) + r

૩. દશાંશ અને ભિન્ન (Decimals and Fractions)

દશાંશ અને ભિન્ન અંકગણિતના મહત્વના વિભાગ છે. GSSSB માં ઘણા પ્રશ્નો સીધા આ વિભાગ પરથી આવે છે.

■ ભિન્નના પ્રકારો:
• સાદું ભિન્ન (Simple Fraction): અંશ < છેદ, ઉદા: ૩/૫, ૭/૯
• અશુદ્ધ ભિન્ન (Improper Fraction): અંશ > છેદ, ઉદા: ૯/૪, ૧૫/૭
• મિશ્ર સંખ્યા (Mixed Fraction): પૂર્ણાંક + સાદું ભિન્ન, ઉદા: ૨ ૩/૪
• સમભિન્ન (Like Fractions): એકસરખા છેદવાળા, ઉદા: ૩/૭, ૫/૭
• વિષમભિન્ન (Unlike Fractions): અલગ અલગ છેદવાળા, ઉદા: ૩/૪, ૫/૬
• સમવર્તી ભિન્ન (Vulgar Fraction): છેદમાં ૧૦, ૧૦૦, ૧૦૦૦ ન હોય. દશાંશ તરફ વાળવા.

■ ભિન્ન પર સરવાળો-બાદ:
સાદા ભિન્નો: અંશોનો સરવાળો/બાદ (જો છેદ સમાન હોય)
ઉદા: ૩/૭ + ૨/૭ = ૫/૭
વિષમભિન્નો: લ.સા.અ શોધી, સમાન છેદ બનાવીએ. ઉદા: ૩/૪ + ૫/૬
લ.સા.અ(૪,૬) = ૧૨
૩/૪ = ૯/૧૨, ૫/૬ = ૧૦/૧૨
સરવાળો = ૧૯/૧૨

■ ભિન્ન પર ગુણાકાર-ભાગાકાર:
ગુણાકાર: અંશ × અંશ / છેદ × છેદ
ઉદા: (૩/૪) × (૨/૫) = ૬/૨૦ = ૩/૧૦
ભાગાકાર: પ્રથમ ભિન્નને પ્રથમ ભિન્નના વ્યસ્ત વડે ગુણો.
ઉદા: (૩/૪) ÷ (૨/૫) = (૩/૪) × (૫/૨) = ૧૫/૮

■ દશાંશ સાથે સંબંધિત ગુણધર્મો:
• દશાંશ સંખ્યાને ૧૦, ૧૦૦, ૧૦૦૦ વડે ગુણતાં દશાંશ ચિન્હ જમણી તરફ ૧, ૨, ૩ સ્થાન ખસે છે.
• દશાંશ સંખ્યાને ૧૦, ૧૦૦, ૧૦૦૦ વડે ભાગતાં દશાંશ ચિન્હ ડાબી તરફ ખસે છે.
• જો અંશ અને છેદ બંનેને એક જ સંખ્યા વડે ગુણીએ/ભાગીએ તો ભિન્નનું મૂલ્ય બદલાતું નથી.

■ દશાંશ ભિન્નને પરસ્પર રૂપાંતર:
દશાંશ → ભિન્ન: દશાંશ ચિન્હ પછીની અંકોની સંખ્યા મુજબ છેદમાં ૧ બાદમાં એટલી શૂન્યો લખો.
ઉદા: ૦.૬૪ = ૬૪/૧૦૦ = ૧૬/૨૫
ભિન્ન → દશાંશ: છેદને ૧૦, ૧૦૦, ૧૦૦૦ બનાવો. ઉદા: ૩/૪ = ૭૫/૧૦૦ = ૦.૭૫

■ નોંધ:
• આવર્તી દશાંશ (Recurring Decimal): ૧/૩ = ૦.૩૩૩... = ૦.૩̅
• સંપૂર્ણ આવર્તી દશાંશ: ૧/૭ = ૦.૧૪૨૮૫૭... = ૦.૧૪૨૮૫૭̅ (૬ અંકનો આવર્ત)
• કોઈ પણ ભિન્નને દશાંશ સ્વરૂપમાં લખી શકાય.

૪. સાપેક્ષતા અને ગુણોત્તર (Ratio and Proportion)

ગુણોત્તર (Ratio) અને અનુપાત (Proportion) GSSSB માં ખૂબ જ મહત્વના વિષય છે.

■ ગુણોત્તર (Ratio) ની વ્યાખ્યા:
બે સમાન એકમોની સંખ્યાઓનું તુલનાત્મક સંબંધ. દ્વિધામાં લખાય છે: a : b અથવા a/b
ઉદા: ૩ લોકો અને ૫ લોકો → ગુણોત્તર ૩:૫

■ ગુણોત્તરના પ્રકારો:
• સમગુણોત્તર (Duplicate Ratio): a:b નો ગુણોત્તર a²:b²
ઉદા: ૨:૩ નો સમગુણોત્તર ૪:૯
• વિપરીત ગુણોત્તર (Sub-Duplicate Ratio): a:b નો વિપરીત ગુણોત્તર √a : √b
ઉદા: ૧૬:૮૧ નો વિપરીત ગુણોત્તર ૪:૯
• તૃતીય ગુણોત્તર (Third Proportional): a:b = b:c ⇒ c = b²/a
• ચતુર્થ ગુણોત્તર (Fourth Proportional): a:b = c:d ⇒ d = bc/a

■ અનુપાત (Proportion):
જ્યારે બે ગુણોત્તર સમાન હોય: a:b = c:d ⇒ a/b = c/d
આમાં: a અને d બાહ્ય અનુપાતી, b અને c અંતઃ અનુપાતી.
મૂળભૂત નિયમ: a × d = b × c (બાહ્ય ગુણન = અંતઃ ગુણન)

■ ચલ ગુણોત્તર (Continued Proportion):
a:b = b:c ⇒ b² = a×c (b એ a અને c નો મધ્ય ગુણોત્તર)

■ વિપરીત ગુણોત્તર:
જો A માં વધારો થાય તો B માં ઘટાડો થાય અથવા A માં ઘટાડો થાય તો B માં વધારો થાય. આને વિપરીત ગુણોત્તર કહે.
ઉદા: ૪ કામಗીર ૧૦ દિવસમાં કામ પૂર્ણ કરે, તો ૫ કામગીર કેટલા દિવસમાં કરશે?
જવાબ: ૪×૧૦/૫ = ૮ દિવસ

■ મિશ્ર ગુણોત્તર (Compound Ratio):
(a:b) અને (c:d) નો મિશ્ર ગુણોત્તર = ac : bd
ઉદા: (૨:૩) અને (૪:૫) નો મિશ્ર ગુણોત્તર = ૮:૧૫

■ ગુણોત્તર માટે યાદ રાખવાના ગુણધર્મો:
• અનુપાતનો સ્વભાવ: a/b = c/d ⇒ a/b = c/d = (a+c)/(b+d) (સંયોજન)
• a/b = c/d ⇒ (a-b)/b = (c-d)/d (વિચ્છેદ)
• a/b = c/d ⇒ (a+b)/(a-b) = (c+d)/(c-d) (સંયોગ-વિચ્છેદ)

૫. ભાગફળ અને મિશ્રણ (Profit/Loss and Mixture & Alligation)

GSSSB માં ભાગફળ-ઘાટા અને મિશ્રણ-અલગીકરણ વિભાગોમાં ઘણા પ્રશ્નો આવે છે.

■ ભાગફળ અને ઘાટા (Profit and Loss):
તરકીબી કિંમત (CP - Cost Price): સામાન ખરીદતી વખતે ચૂકવેલ મૂલ્ય.
વિક્રી કિંમત (SP - Selling Price): સામાન વેચતી વખતે મળેલ મૂલ્ય.
\nજ્યારે SP > CP → ભાગફળ (Profit)
ભાગફળ = SP - CP
ભાગફળ % = (ભાગફળ/CP) × ૧૦૦
\nજ્યારે SP < CP → ઘાટો (Loss)
ઘાટો = CP - SP
ઘાટો % = (ઘાટો/CP) × ૧૦૦
\nCP શોધવા:
જો ભાગફળ % આપેલ હોય: CP = SP × 100/(100 + %પ્રોફિટ)
જો ઘાટો % આપેલ હોય: CP = SP × 100/(100 - %ઘાટો)
\nSP શોધવા:
જો ભાગફળ %: SP = CP × (100 + %પ્રોફિટ)/100
જો ઘાટો %: SP = CP × (100 - %ઘાટો)/100

■ મિશ્રણ અને અલગીકરણ (Mixture and Alligation):
આ પદ્ધતિનો ઉપયોગ એવા પ્રશ્નોમાં થાય છે જ્યાં બે કે તેથી વધુ વસ્તુઓને મિશ્રિત કરીને મધ્યસ્થ કિંમત શોધવી હોય.
\nઅલગીકરણનું સૂત્ર:
જો R1 રૂપિયા પ્રતિ કિલોની વસ્તુ (પ્રમાણ Q1) અને R2 રૂપિયા પ્રતિ કિલોની વસ્તુ (પ્રમાણ Q2) નું મિશ્રણ કરીને મધ્યસ્થ કિંમત R હોય, તો:
(Q1/Q2) = (R2 - R)/(R - R1)
\nઉદાહરણ: ૪૦ રૂપિયા/કિલો અને ૬૦ રૂપિયા/કિલોના ચાવલાનું મિશ્રણ કેટલા ગુણોત્તરમાં કરવું કે મિશ્રણની કિંમત ૫૦ રૂપિયા/કિલો આવે?
(Q1/Q2) = (૬૦ - ૫૦)/(૫૦ - ૪૦) = ૧૦/૧૦ = ૧:૧
\nમિશ્રણના મૂળભૂત ગુણધર્મો:
• જો ૧મી વસ્તુનું પ્રમાણ a હોય અને બીજી વસ્તુનું પ્રમાણ b હોય, તો મિશ્રણની કિંમત = (a×R1 + b×R2)/(a+b)
• જો વસ્તુને b કે જગ્યાએ વેચીએ તો ખરડાં/ફાયદા માટે: (a+b)×CP = a×SP + b×SP (ગુણોત્તર મુજબ)

■ સરળતા માટે વિશેષ કિસ્સા:
• જો બે માલિકોએ ભાગફળ/ઘાટા વિશે માહિતી આપે, તો CP શોધવા માટે: (SP1 - SP2) = (ભાગફળ1 + ઘાટો2) = CP × (%પ્રોફિટ1 + %ઘાટો2)/100
• એક જ વસ્તુ બે માલિકોએ અલગ અલગ ભાગફળ/ઘાટા % વેચી હોય, તો CP શોધો: CP = (S1 - S2) × 100/(p1 + p2), જ્યાં p1 અને p2 ભાગફળ/ઘાટા % છે.

■ GSSSB માટે ઉપયોગી ઝડપી સૂત્રો:
• જો મૂળ કિંમત ૧૦૦ હોય, તો ભાગફળ = વિક્રી કિંમત - ૧૦૦
• જો વિક્રી કિંમત = મૂળ કિંમત, તો ભાગફળ % = ૦
• ભાગફળ અને ઘાટો % સમાન હોય, અને CP = SP હોય, તો કોઈ નફો-નાફો નથી.

૬. શતકડા (Percentage)

શતકડા અંકગણિતનો સૌથી મહત્વનો વિષય છે. તેનું મૂળભૂત અર્થ ગુણોત્તર છે, પરંતુ ગણિતની બધી શાખાઓમાં તેનો ઉપયોગ થાય છે.

■ શતકડા વ્યાખ્યા:
કોઈ સંખ્યાનું ૧૦૦માં ભાગે છે તેને શતકડા કહે છે. % ચિન્હ દ્વારા દર્શાવવામાં આવે છે.
ઉદા: ૫૦% = ૫૦/૧૦૦ = ૦.૫૦ = ૧/૨

■ શતકડા રૂપાંતર:
શતકડા → ભિન્ન: /૧૦૦ ભાગો. ઉદા: ૭૫% = ૭૫/૧૦૦ = ૩/૪
ભિન્ન → શતકડા: ×૧૦૦. ઉદા: ૩/૪ = ૩/૪ × ૧૦૦ = ૭૫%
દશાંશ → શતકડા: ×૧૦૦. ઉદા: ૦.૮ = ૦.૮ × ૧૦૦ = ૮૦%
શતકડા → દશાંશ: /૧૦૦. ઉદા: ૮૦% = ૮૦/૧૦૦ = ૦.૮૦

■ શતકડાના મહત્વના ભાગ:
વધારો/ઘટાડો: જો કોઈ સંખ્યામાં p% વધારો થાય, તો નવી સંખ્યા = મૂળ સંખ્યા × (100+p)/100
જો q% ઘટાડો થાય, તો નવી સંખ્યા = મૂળ સંખ્યા × (100-q)/100
બંને વારંવાર થાય, તો શુદ્ધ ફેરફાર = p + q + pq/100

ઉદા: એક સંખ્યામાં પહેલા ૨૦% વધારો, তারপরে ૧૦% ઘટાડો. શુદ્ધ ફેરફાર = ૨૦ + (-૧૦) + (૨૦ × -૧૦)/૧૦૦ = ૨૦ - ૧૦ - ૨ = ૮% વધારો.

■ મૂળ સંખ્યા શોધવી:
જો k સંખ્યાનું p% મળે, તો મૂળ સંખ્યા = k × 100/p
ઉદા: જો ૪૦ સંખ્યાનું ૨૦% ૮ થાય, તો સંખ્યા = ૪૦ × ૧૦૦/૨૦ = ૪૦૦

■ ગતિમાં ફેરફાર:
જો ગતિ v માં p% વધારો થાય, તો સમય t માં ઘટાડો જરૂરી = p/(100+p) × 100% ઘટાડો.
જો v માં p% ઘટાડો થાય, તો t માં વધારો જરૂરી = p/(100-p) × 100% વધારો.

■ ઉપરાક્ષેપણ (Approximation) ટેકનિક:
નીપટ શતકડા ઉપયોગી છે:
૧% = ૦.૦૧, ૨% = ૦.૦૨, ૫% = ૦.૦૫, ૧૦% = ૦.૧૦, ૨૦% = ૦.૨૦, ૨૫% = ૦.૨૫, ૩૩.૩૩% = ૧/૩, ૫૦% = ૦.૫૦, ૬૬.૬૬% = ૨/૩, ૭૫% = ૦.૭૫, ૧૦૦% = ૧

■ શતકડા પાછળથી બીજા શતકડા શોધવા:
જો A, B ના m% છે, તો B, A નું કેટલું% છે?
B = A × m/100 → A = B × 100/m
ઉદા: જો A, B ના ૪૦% છે, તો B, A નું કેટલું%? B = A × ૪૦/૧૦૦ → A = B × ૧૦૦/૪૦ = B × ૨.૫ = B નું ૨૫૦%

■ પાણી-બેરણી સમસ્યા (Water Addition):
જો k લીટર પાણી ઉમેરતાં મિશ્રણનું % બદલાય, તો નવા પ્રમાણમાં બદલાવ શોધવા.
ઉદા: ૪૦ લીટર મિશ્રણમાં ૨૦% પાણી હોય. ૧૦ લીટર પાણી ઉમેરતાં કુલ પાણીનું % કેટલું?
મૂળ પાણી = ૪૦ × ૨૦/૧૦૦ = ૮ લીટર
કુલ પાણી = ૮ + ૧૦ = ૧૮ લીટર
કુલ મિશ્રણ = ૫૦ લીટર
પાણીનું % = ૧૮/૫૦ × ૧૦૦ = ૩૬%

૭. સરેરાશ (Average)

સરેરાશ (Mean) એ આંકડાશાસ્ત્રનો મૂળભૂત ખ્યાલ છે અને GSSSB માં ઘણા પ્રશ્નો આ પરથી આવે છે.

■ સરેરાશ વ્યાખ્યા:
કોઈપણ આંકડાકીય મૂલ્યોનો સરવાળો કેટલાક મૂલ્યોની સંખ્યા વડે ભાગતા જે મળે તે સરેરાશ (Average/Mean) કહે છે.
સરેરાશ = (કુલ સરવાળો) / (મૂલ્યોની સંખ્યા)

■ સાદી સરેરાશ:
ઉદા: ૫ વિદ્યાર્થીઓના અંક ૭૫, ૮૦, ૯૦, ૬૦, ૮૫ હોય, તો સરેરાશ = (૭૫+૮૦+૯૦+૬૦+૮૫)/૫ = ૩૯૦/૫ = ૭૮

■ ભારિત સરેરાશ (Weighted Average):
જો વિવિધ મૂલ્યોનાં વજન અલગ અલગ હોય, તો ભારિત સરેરાશ:
ભારિત સરેરાશ = (w₁x₁ + w₂x₂ + ... + wₙxₙ) / (w₁ + w₂ + ... + wₙ)
ઉદા: ૫ કલાક ૮૦ km/h અને ૩ કલાક ૬૦ km/h ની ગતિએ ગયા, તો સરેરાશ ગતિ = (૫×૮૦ + ૩×૬૦)/(૫+૩) = (૪૦૦+૧૮૦)/૮ = ૫૮૦/૮ = ૭૨.૫ km/h

■ સરેરાશ અને કુલ સંબંધ:
જો n મૂલ્યોની સરેરાશ A હોય, તો કુલ સરવાળો = n × A
જો મૂલ્યોમાં n માંથી k મૂલ્યો કાઢી નાખીએ અને બાકીની n-k મૂલ્યોની સરેરાશ A' હોય, તો કાઢેલી k મૂલ્યોની સરેરાશ = (nA - (n-k)A')/k

■ સરેરાશ-આધારિત પ્રશ્નો માટે ટેકનિક:
વિચલન પદ્ધતિ (Deviation Method):
1. કોઈ પણ સરળ મૂલ્ય (approximate mean) લો.
2. દરેક મૂલ્યની વિચલન = મૂલ્ય - અંદાજિત સરેરાશ
3. વિચલનોનો સરવાળો કરો.
4. સરેરાશ = અંદાજિત સરેરાશ + (વિચલનોનો સરવાળો)/n
ઉદા: ૧૦૨, ૧૦૪, ૯૮, ૧૦૫, ૯૬ ની સરેરાશ શોધો.
અંદાજિત સરેરાશ = ૧૦૦
વિચલનો: +૨, +૪, -૨, +૫, -૪
વિચલનોનો સરવાળો = +૫
સરેરાશ = ૧૦૦ + ૫/૫ = ૧૦૦ + ૧ = ૧૦૧

■ સરેરાશના વિશેષ ગુણધર્મો:
• જો દરેક મૂલ્યમાં સમાન સંખ્યા ઉમેરવામાં આવે, તો સરેરાશમાં પણ સમાન સંખ્યા ઉમેરાય.
• જો દરેક મૂલ્યમાં સમાન સંખ્યા બાદ કરવામાં આવે, તો સરેરાશમાં પણ સમાન સંખ્યા બાદ થાય.
• જો દરેક મૂલ્યને સમાન સંખ્યા વડે ગુણવામાં આવે, તો સરેરાશ પણ સમાન સંખ્યા વડે ગુણાય.
• જો દરેક મૂલ્યને સમાન સંખ્યા વડે ભાગવામાં આવે, તો સરેરાશ પણ સમાન સંખ્યા વડે ભાગાય.
• પ્રથમ n કુદરતી સંખ્યાઓની સરેરાશ = (n+૧)/૨
• પ્રથમ n યુગ્મ સંખ્યાઓની સરેરાશ = n+૧
• પ્રથમ n અયુગ્મ સંખ્યાઓની સરેરાશ = n

■ સરેરાશ-સંબંધિત પ્રશ્નો માટે ટેકનિક:
પરિવર્તન પદ્ધતિ: જો n મૂલ્યોની સરેરાશ શરૂઆતમાં A હોય અને k મૂલ્યો બદલાતાં સરેરાશ A' થાય, તો કુલ ફેરફાર = n(A' - A). આ ફેરફાર k મૂલ્યોમાં જ છે.

૮. જોડાણ (Partnership)

જોડાણ પ્રકરણ GSSSB માં સરળ અને સીધા પ્રશ્નો આપે છે.

■ જોડાણ વ્યાખ્યા:
બે કે તેથી વધુ વ્યક્તિઓએ કોઈ કામ કરવા માટે રૂપિયા જમા કરીને સાથે કામ કરવું એ જોડાણ છે.

■ સરળ જોડાણ:
બધા સાથીદારોએ એક જ સમયગાળા માટે રોકાણ કર્યું હોય, તો તે સરળ જોડાણ છે.
ભાગફળના ભાગ ફગ્ગારાના ગુણોત્તર મુજબ હોય છે.
કુલ રોકાણના ગુણોત્તર = રકમનો ગુણોત્તર

ઉદા: A, B, C એક સાથે વ્યવસાય શરૂ કરે. A = ૪૦,૦૦૦ રૂપિયા, B = ૫૦,૦૦૦ રૂપિયા, C = ૬૦,૦૦૦ રૂપિયા. વાર્ષિક ભાગફળ ૨૮,૦૦૦ રૂપિયા. દરેકનો ભાગ શોધો.
ગુણોત્તર = ૪૦:૫૦:૬૦ = ૪:૫:૬
કુલ ભાગ = ૪+૫+૬ = ૧૫
A નો ભાગ = ૨૮,૦૦૦ × ૪/૧૫ = ૭,૪૬૭ (આસન્ન)
B નો ભાગ = ૨૮,૦૦૦ × ૫/૧૫ = ૯,૩૩૩ (આસન્ન)
C નો ભાગ = ૨૮,૦૦૦ × ૬/૧૫ = ૧૧,૨૦૦

■ મિશ્ર જોડાણ (Time-Weighted Partnership):
જ્યારે વિવિધ સાથીદારોએ અલગ અલગ સમયગાળા માટે રોકાણ કર્યું હોય, તો મિશ્ર જોડાણ.
રોકાણ × સમયનો ગુણોત્તર લેવો પડે.

ઉદા: A એ ૩,૦૦,૦૦૦ રૂપિયા ૧૨ મહિના માટે અને B એ ૪,૦૦,૦૦૦ રૂપિયા ૬ મહિના માટે રોક્યું. ભાગફળ ૯,૦૦,૦૦૦ રૂપિયા. દરેકનો ભાગ?
A નું સમયગુણિત રોકાણ = ૩,૦૦,૦૦૦ × ૧૨ = ૩૬,૦૦,૦૦૦
B નું સમયગુણિત રોકાણ = ૪,૦૦,૦૦૦ × ૬ = ૨૪,૦૦,૦૦૦
ગુણોત્તર = ૩૬:૨૪ = ૩:૨
કુલ ભાગફળ = ૯,૦૦,૦૦૦
A નો ભાગ = ૯,૦૦,૦૦૦ × ૩/૫ = ૫,૪૦,૦૦૦
B નો ભાગ = ૯,૦૦,૦૦૦ × ૨/૫ = ૩,૬૦,૦૦૦

■ સામાન્ય શરતો:
• જો સમયગાળો સમાન હોય, તો ગુણોત્તર = રોકાણનો ગુણોત્તર.
• જો રોકાણ સમાન હોય, તો ગુણોત્તર = સમયનો ગુણોત્તર.
• બધા સમયગાળો અને રોકાણ અલગ હોય, તો ગુણોત્તર = (રોકાણ × સમય)નો ગુણોત્તર.

■ નાણાકીય અંદાજિત પ્રશ્નો માટેની ટેકનિક:
જો સમયગાળાનો ગુણોત્તર m:n:h અને રોકાણનો ગુણોત્તર p:q:r હોય, તો ગુણોત્તર = mp:nq:hr
આ ગુણોત્તર વડે કુલ ભાગફળના ભાગ નક્કી કરો.

૯. સંખ્યા પરિચય અને સંકલન (Number Properties)

સંખ્યાના ગુણધર્મો અંકગણિતમાં મહત્વપૂર્ણ છે. આ ભાગમાં વિવિધ સંખ્યાઓના ગુણધર્મો અને તેમના સંકલન પદ્ધતિઓ દર્શાવવામાં આવી છે.

■ વિભાજ્યતાના નિયમો:
• ૨ વડે ભાગી શકાય: જો છેલ્લી અંક યુગ્મ હોય (0,2,4,6,8)
• ૩ વડે ભાગી શકાય: જો અંકોનો સરવાળો ૩ વડે ભાગી શકાય
• ૪ વડે ભાગી શકાય: જો છેલ્લી બે અંકો ૪ વડે ભાગી શકે
• ૫ વડે ભાગી શકાય: જો છેલ્લી અંક ૦ અથવા ૫ હોય
• ૬ વડે ભાગી શકાય: જો ૨ અને ૩ બંને વડે ભાગી શકાય
• ૮ વડે ભાગી શકાય: જો છેલ્લી ત્રણ અંકો ૮ વડે ભાગી શકે
• ૯ વડે ભાગી શકાય: જો અંકોનો સરવાળો ૯ વડે ભાગી શકાય
• ૧૦ વડે ભાગી શકાય: જો છેલ્લી અંક ૦ હોય
• ૧૧ વડે ભાગી શકાય: જો યુગ્મ સ્થાનના અંકોનો સરવાળો અને અયુગ્મ સ્થાનના અંકોનો સરવાળો વચ્ચેનો તફાવત ૦ અથવા ૧૧ વડે ભાગી શકાય

■ સંખ્યાઓના સંકલન:
• પ્રથમ n કુદરતી સંખ્યાઓનો સરવાળો = n(n+1)/2
ઉદા: ૧ થી ૧૦૦ સુધીનો સરવાળો = ૧૦૦×૧૦૧/૨ = ૫૦૫૦
• પ્રથમ n કુદરતી સંખ્યાઓનો વર્ગ સરવાળો = n(n+1)(2n+1)/6
ઉદા: ૧²+૨²+...+૧૦² = ૧૦×૧૧×૨૧/૬ = ૩૮૫
• પ્રથમ n કુદરતી સંખ્યાઓનો ઘન સરવાળો = [n(n+1)/2]²
ઉદા: ૧³+૨³+...+૧૦³ = (૧૦×૧૧/૨)² = ૫૫² = ૩૦૨૫

■ અંકોની સંખ્યા શોધવી:
કોઈ પણ ધન પૂર્ણાંક N માટે અંકોની સંખ્યા = ⌊log₁₀N⌋ + 1
ઉદા: ૧૨૩૪ → log₁₀1234 ≈ 3.09 → અંકો = 3+1 = 4

■ સંખ્યાઓના ગુણધર્મો:
• શૂન્ય: ધન અથવા ઋણ નથી. સૌથી નાની પૂર્ણ સંખ્યા.
• ૧: સૌથી નાની કુદરતી સંખ્યા, અવિભાજ્ય નથી.
• ૨: એકમાત્ર યુગ્મ અવિભાજ્ય સંખ્યા.
• ૯: સૌથી નાની બે-અંકીય અવિભાજ્ય સંખ્યા.
• ૧૧: સૌથી નાની બે-અંકીય અવિભાજ્ય સંખ્યા.
• સૌથી નાનું ત્રણ-અંકીય અવિભાજ્ય સંખ્યા = ૧૦૧
• સૌથી મોટું બે-અંકીય અવિભાજ્ય સંખ્યા = ૯૭

■ ઘાત અને મૂળ:
કોઈ પણ સંખ્યા a નો m ઘાત એટલે a^m = a × a × ... × a (m વાર)
વિશિષ્ટ ગુણધર્મો:
• a⁰ = 1 (જ્યાં a ≠ 0)
• a¹ = a
• a⁻ⁿ = 1/aⁿ
• aᵐ × aⁿ = a^(m+n)
• aᵐ ÷ aⁿ = a^(m-n)
• (aᵐ)ⁿ = a^(m×n)
• √a = a^(1/2)
• ³√a = a^(1/3)

■ પરિવર્તી ગુણધર્મો:
જો a, b, c, d પાંચ કુદરતી સંખ્યાઓ હોય અને a < b < c < d, તો:
(a+b+c+d)/4 = a + (b-a) + (c-b) + (d-c))/4 (સરેરાશ ગણતરી)

૧૦. ગતિ, સમય અને અંતર (Speed, Time and Distance)

ગતિ-સમય-અંતર અંકગણિતનો એક મહત્વનો વિભાગ છે. GSSSB માં ઘણા પ્રશ્નો આ વિભાગ પરથી આવે છે.

■ મૂળભૂત સૂત્રો:
ગતિ (v) = અંતર (d) / સમય (t)
અંતર (d) = ગતિ (v) × સમય (t)
સમય (t) = અંતર (d) / ગતિ (v)

■ યુનિટ રૂપાંતરણ:
૧ km/hr = ૫/૧૮ m/s
૧ m/s = ૧૮/૫ km/hr = ૩.૬ km/hr

ઉદા: ૩૬ km/hr = ૩૬ × ૫/૧૮ = ૧૦ m/s

■ સરેરાશ ગતિ:
જો કોઈ વસ્તુ એક રસ્તે v1 ગતિએ અને પાછળ v2 ગતિએ આવે, તો સરેરાશ ગતિ:
સરેરાશ ગતિ = ૨v₁v₂/(v₁+v₂)
(એક જ અંતર માટે)

જો કોઈ વસ્તુ v1, v2, v3 ગતિએ અલગ અલગ અંતર ચાલે, તો:
સરેરાશ ગતિ = કુલ અંતર / કુલ સમય

■ સાપેક્ષ ગતિ (Relative Speed):
એક જ દિશામાં: સાપેક્ષ ગતિ = v₁ - v₂ (વધુ ગતિવાળી વસ્તુની ગતિ ઘટાડો)
વિરુદ્ધ દિશામાં: સાપેક્ષ ગતિ = v₁ + v₂

ઉદા: એક ટ્રેન ૬૦ km/hr ની ગતિએ ચાલે છે. એક વ્યક્તિ ૧૦ km/hr ની ગતિએ same direction માં ચાલે છે. ટ્રેન વ્યક્તિને ક્ષણમાં પાર કરશે? ટ્રેનની ગતિ = ૬૦-૧૦ = ૫૦ km/hr.

■ ટ્રેન પ્રકારના પ્રશ્નો:
• ટ્રેન લંબાઈ l અને પ્લેટફોમ લંબાઈ l₁ હોય, તો ટ્રેન પ્લેટફોમ પરથી પસાર થવાનો સમય = (l + l₁) / v
• ટ્રેન ઊભી વ્યક્તિને પાર કરવાનો સમય = l / v (ટ્રેનની લંબાઈ)
• બે ટ્રેનો વિરુદ્ધ દિશાએ: પાર થવાનો સમય = (l₁ + l₂) / (v₁ + v₂)
• બે ટ્રેનો એક જ દિશાએ: પાર થવાનો સમય = (l₁ + l₂) / (v₁ - v₂)

■ પ્રવાહ અને કેન્ટિલ શક્તિ (Stream Problems):
વહેતા પ્રવાહમાં:
• ધારો કે પ્રવાહની ગતિ u હોય અને નૌકાની ગતિ v હોય.
• ઉપર (upstream) ગતિ = v - u
• નીચે (downstream) ગતિ = v + u

ઉદા: નૌકાની ગતિ પ્રવાહ વિના ૮ km/hr અને પ્રવાહની ગતિ ૨ km/hr. ઉપર અને નીચે ગતિ શોધો.
ઉપર ગતિ = ૮ - ૨ = ૬ km/hr
નીચે ગતિ = ૮ + ૨ = ૧૦ km/hr

■ સરેરાશ ગતિ શોધવા માટે ટેકનિક:
જો સમાન અંતર માટે બે અલગ ગતિઓ v1 અને v2 હોય, તો સરેરાશ ગતિ હંમેશા ૨v₁v₂/(v₁+v₂) થાય છે.
આ સૂત્ર યાદ રાખવું ખૂબ જ ઉપયોગી છે.

■ ડાયરેક્ટ રીતે ઉકેલવા માટે વિચાર:
જો v = d/t → t = d/v
જો દૂરતા સમાન હોય, તો સમય ગતિના વિપરીત ગુણોત્તરમાં હોય છે.
જો ગતિ વધે, તો સમય ઘટે. આથી સાપેક્ષ ગતિનો વિપરીત ગુણોત્તર લેવાનો.

Important facts

  • ૧ એ અવિભાજ્ય સંખ્યા નથી. આ પ્રશ્ન GSSSB માં ખૂબ આવે છે.
  • ૨ એ એકમાત્ર યુગ્મ અવિભાજ્ય સંખ્યા છે.
  • લ.સા.અ ≤ ગ.સા.અ હંમેશા સાચું નથી — ગ.સા.અ ≤ લ.સા.અ હંમેશા સાચું છે.
  • ભાગફળ % = (ભાગફળ/CP) × 100 — ધ્યાન રાખો કે CP છે, SP નહીં.
  • ઘાટો % = (ઘાટો/CP) × 100 — ઘાટો પણ CP પર ગણાય છે.
  • મિશ્ર ગુણોત્તર (a:b) × (c:d) = ac : bd.
  • અલગીકરણ સૂત્ર: Q1/Q2 = (R2-R)/(R-R1) — ઉપયોગમાં સરળ, પણ દરેક વારંતવું.
  • જો ભાગફળ અને ઘાટો સમાન હોય, અને CP = SP, તો કોઈ નફો-નાફો નથી.
  • પ્રથમ n કુદરતી સંખ્યાઓનો સરવાળો = n(n+1)/2 — આ સૂત્ર હંમેશા પ્રશ્નોમાં ઉપયોગી છે.
  • સરેરાશ ગતિ = કુલ અંતર / કુલ સમય — સૌથી મહત્વનું સૂત્ર.
  • વિપરીત ગુણોત્તર: jyu ek sankhya badhe te para dusri ghate. This is inverse proportion.
  • BODMAS નો નિયમ ગણતરીમાં અનિવાર્ય છે.
  • પાણી-બેરણી સમસ્યામાં: પાણીનું પ્રમાણ = મૂળ પાણી + ઉમેરેલું પાણી.
  • જો a:b = c:d, તો a×d = b×c (અંતઃગુણન = બાહ્યગુણન).
  • ગુણોત્તર માટે વિસંગત (invert) કરવું: a/b = c/d → b/a = d/c.
