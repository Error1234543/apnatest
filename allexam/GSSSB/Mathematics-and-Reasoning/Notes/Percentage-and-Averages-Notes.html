ટકાવારી અને સામગ્રી — સંપૂર્ણ નોટ્સ (GSSSB)

GSSSBGujaratiNotes

૧. ટકાવારીની મૂળભૂત વ્યાખ્યા અને પરિભાષા

શબ્દ 'ટકાવારી' લેટિનના 'per centum' થી આવ્યો છે, જેનો અર્થ છે 'શતકોમાં'. ટકાવારી એ એક ગુણોત્તર છે જેમાં છેદ હંમેશા ૧૦૦ લેવામાં આવે છે. પ્રતીક % છે.

• ટકાવારી = (જોતા રકમ / આપેલી રકમ) × ૧૦૦
• ટકાવારી દ્વારા કોઈ પણ સંખ્યા શોધવી = (ટકાવારી / ૧૦૦) × સંખ્યા
• ટકાવારીની વાર્તા: જ્યારે કોઈ રાશિ B ની સાપેક્ષે A નો સંબંધ શોધવો હોય, ત્યારે B એકમ માન્યો જાય છે. ઉદાહરણ તરીકે, 'A એ B કરતાં X% વધારે' એટલે (A−B)/B × ૧૦૦.

મહત્વની બાબત:
• % નીચે રહેલા છેદવાળા ભિન્નને ટકાવારીમાં ફેરવવા હોય તો અંશને ૧૦૦ વડે ગુણો અને છેદને પણ ૧૦૦ વડે ગુણવા માટે પ્રમાણભૂત પદ્ધતિ વાપરો.
• GSSSB માં 'શાહી/છૂટ' જેવા શબ્દો ટકાવારીની ગણતરી સાથે જોડાયેલા હોય છે.
• ટકાવારીમાં ફેરફાર શોધતી વખતે સૂત્ર છે: % ફેરફાર = [(નવી રાશિ − જૂની રાશિ)/જૂની રાશિ] × ૧૦૦. અહીં જૂની રાશિ હંમેશા છેદમાં રહે છે.

ઉદાહરણ: કોઈ વસ્તુનું મૂલ્ય ૨૫૦ થી વધીને ૩૦૦ થાય. % વધારો = [(૩૦૦−૨૫૦)/૨૫૦]×૧૦૦ = (૫૦/૨૫૦)×૧૦૦ = ૨૦%.

૨. ભિન્ન, દશાંશ અને ટકાવારીનું પરસ્પર રૂપાંતર

ટકાવારી સિધ્ધાંતની ગતિ ગણતરી માટે ભિન્ન તથા દશાંશ સાથેનું રૂપાંતર જાણવું અત્યંત જરૂરી છે.

અંકગણિતીય ભિન્ન → ટકાવારી:
• ભિન્નના અંશને ૧૦૦ વડે ગુણો અને છેદને સમાન ગુણકથી ૧૦૦ બનાવો, અથવા સીધું (અંશ/છેદ)×૧૦૦ કરો.
• ૧/૪ = ૨૫%, ૧/૫ = ૨૦%, ૧/૮ = ૧૨.૫%, ૧/૩ = ૩૩.૩૩%

ટકાવારી → ભિન્ન:
• ટકાવારીને ૧૦૦ વડે ભાગીને સરળ બનાવો.
• ૬૦% = ૬૦/૧૦૦ = ૩/૫; ૩૭.૫% = ૩૭.૫/૧૦૦ = ૩/૮

ટકાવારી → દશાંશ:
• ટકાવારીના ચિહ્નેક (%) દૂર કરીને ૧૦૦ વડે ભાગો. ૪૫% = ૦.૪૫.

દશાંશ → ટકાવારી:
• ૧૦૦ વડે ગુણો. ૦.૭૫ = ૭૫%.

આમૂલ રૂપાંતરણ કોષ્ટક (GSSSB માટે ખૂબ ઉપયોગી):
• ૧/૨ = ૫૦%, ૧/૩ ≈ ૩૩.૩૩%, ૧/૪ = ૨૫%, ૧/૫ = ૨૦%, ૧/૬ ≈ ૧૬.૬૭%, ૧/૭ ≈ ૧૪.૨૮%, ૧/૮ = ૧૨.૫%, ૧/૯ ≈ ૧૧.૧૧%, ૧/૧૦ = ૧૦%.
• ૨/૩ ≈ ૬૬.૬૭%, ૩/૪ = ૭૫%, ૩/૫ = ૬૦%, ૪/૫ = ૮૦%, ૫/૮ = ૬૨.૫%, ૭/૮ = ૮૭.૫%, ૯/૨૦ = ૪૫%.

ટાઇપિંગ-અજ્ઞાન ટાળવા: GSSSB માં ઘણી વાર ઉત્તરો દશાંશ સ્વરૂપે હોય છે; તેથી દશાંશ + ટકાવારી બંને રૂપમાં પ્રતિક્રિયા આપી શકો તેવી તૈયારી રાખો.

૩. ટકાવારીની ગણતરીના પ્રકાર અને ઉકેલ પદ્ધતિઓ

ગણતરીના પ્રકારો નીચે મુજબ છે.

(૧) ટકાવારી શોધવી:
રકમ B માંથી રકમ A કેટલા % છે? → (A/B)×૧૦૦.
ઉદા: ૪૦ એ ૨૦૦ નું કેટલા %? → (૪૦/૨૦૦)×૧૦૦ = ૨૦%.

(૨) ટકાવારીમાંથી મૂલ્ય શોધવું:
કોઈ સંખ્યાનું X% શોધવું હોય → (X/૧૦૦)×સંખ્યા.
ઉદા: ૩૬૦ ના ૧૫% → ૦.૧૫×૩૬૦ = ૫૪.

(૩) પ્રતિશત વધારો/ઘટાડો:
વધારો = મૂળ × (% વધારા/૧૦૦). નવી કિંમત = મૂળ + વધારો.
ઘટાડો = મૂળ × (% ઘટાડા/૧૦૦). નવી કિંમત = મૂળ − ઘટાડો.

(૪) સાપેક્ષ ટકાવારી પ્રશ્ન:
'A એ B કરતાં X% વધારે' એટલે A = B(૧ + X/૧૦૦).
'B એ A કરતાં X% ઓછા' એટલે B = A(૧ − X/૧૦૦).

(૫) સાચા વ્યાજ vs ચક્રવૃદ્ધિ વ્યાજમાં ટકાવારી:
ચક્રવૃદ્ધિ માટે A = P(૧ + R/૧૦૦)^T.
ટકાવારીના વિષયમાં સામાન્ય રીતે પ્રતિશત વધારો-ઘટાડાના સંયુક્ત પરિણામનો ઉપયોગ થાય છે.

(૬) બે સતત ટકાવારી ફેરફારોનું એકત્રિત પ્રભાવ:
ક્રમશઃ a% વધારો અને b% ઘટાડો પછી કુલ % ફેરફાર = a + b + (ab/૧૦૦).
ઉદા: ૨૦% વધારો અને ૧૦% ઘટાડો → ૨૦ − ૧૦ + (૨૦×(−૧૦)/૧૦૦) = ૧૦ − ૨ = ૮% વધારો.

(૭) વસ્તુના ભાવમાં ટકાવારી ફેરફાર → ખર્ચમાં પરિણામ:
જો ખર્ચ સમાન રાખવો હોય, તો માંગમાં પ્રતિશત ઘટાડો = [a/(૧૦૦+a)] × ૧૦૦ જ્યારે ભાવ a% વધે.

૪. ગુણોત્તર, લાભ-નુકસાન અને ટકાવારી

આભાર-નુકસાનના સંબંધમાં ટકાવારીનો ઉપયોગ પ્રત્યક્ષ રીતે થાય છે.

• લાભ = વેચાણ મૂલ્ય − ખરેડ મૂલ્ય.
• નુકસાન = ખરેડ મૂલ્ય − વેચાણ મૂલ્ય.
• લાભ % = (લાભ/ખરેડ મૂલ્ય)×૧૦૦.
• નુકસાન % = (નુકસાન/ખરેડ મૂલ્ય)×૧૦૦.

વપરાતા સૂત્રો:
• ખરેડ મૂલ્ય = ૧૦૦/(૧૦૦+લાભ%) × વેચાણ મૂલ્ય.
• વેચાણ મૂલ્ય = ખરેડ મૂલ્ય × (૧ + લાભ%/૧૦૦).

વિશેષ સ્થિતિઓ:
• બે વસ્તુઓ એક જ ભાવે વેચાય, એકને P% લાભ અને બીજાને P% નુકસાન થાય, તો કુલ લાભ/નુકસાન % = (P/૧૦)² નુકસાન.
• છૂટ અને મૂલ્ય: છૂટ હંમેશા લેબલ/માર્કેડ ભાવ પરથી ગણાય છે; શાહી/વાહક ભાવ અલગ હોય છે.

ઉદાહરણ:
કોઈ વસ્તુના ખરેડ ભાવ પર ૨૦% લાભ મેળવવા માટે વેચાણ ભાવ કેટલો હોવો જોઈએ?
જો ખરેડ = ૧૦૦ હોય, તો વેચાણ = ૧૨૦.

GSSSB માં ઘણી વાર કિસ્સાઓમાં વધારાના ઊડતરી (સ્ટાફ, ટૉક્સ) પણ ઉમેરાય છે; તે સમજીને ગણતરી કરવી.

૫. ટકાવારીમાં બરાબર ગણતરી — સામાન્ય ભૂલો

(૧) % ઘટાડો અને % વધારો એ એકબીજાનો વિરોધી છે પણ સમાન નથી. ૨૦% વધારો પછી ૨૦% ઘટાડો કરવાથી મૂળ માત્રા પાછી ન આવે; ૪% ઘટાડો થાય.
(૨) 'A, B કરતાં ૨૫% વધારે' એટલે B = A/(૧.૨૫), ન કે A × ૦.૭૫. આ બે બાબતો અલગ છે.
(૩) ટકાવારી શોધતી વખતે છેદ હંમેશા 'આધાર' (reference) રાશિ હોય છે — તેને ખોટો લેવાની ભૂલ સામાન્ય છે.
(૪) બે ટકાવારી ફેરફારોનો સરવાળો સીધો કરવો (દા.ત. ૨૦% + ૩૦% = ૫૦%) ખોટો છે; ગુણાકાર ટર્મ ab/૧૦૦ ઉમેરવી પડે.
(૫) પ્રશ્નમાં 'ક્રમશઃ' (successive) શબ્દ હોય ત્યારે દરેક ફેરફાર પૂર્વની રાશિ પર લાગુ પડે છે.
(૬) ગણતરીમાં સંખ્યા બાદમાં ૧૦૦ વડે ભાગતી વખતે દશાંશ કોણ ધ્યાનમાં રાખો.
(૭) ભાગફળની ચોકસાઈ: GSSSB માં સામાન્ય રીતે ચાર વિકલ્પોમાંથી પસંદગી હોય છે; દશાંશ સ્થાનના ભ્રમણા ટાળવા.

૬. સામગ્રી (Average) ની વ્યાખ્યા અને મૂળભૂત સૂત્રો

સામગ્રી એ ચોક્કસ સંખ્યામાં રાશિઓના સરવાળાને તેમની સંખ્યા વડે ભાગવાથી મળતી સમાંગ રાશિ છે.

મૂળ સૂત્ર:
• સામગ્રી = (બધી રાશિઓનો સરવાળો) / (રાશિઓની સંખ્યા)
• સરવાળો = સામગ્રી × સંખ્યા
• સંખ્યા = સરવાળો / સામગ્રી

વ્યાખ્યા:
સામગ્રી એ એક કાલ્પનિક સમાંગ મૂલ્ય છે જેથી જો દરેક રાશિ આ મૂલ્યની બરાબર હોત, તો સરવાળો સમાન રહે.

ઉપયોગી કળાઓ:
• જો n એવો સંખ્યાઓનો સરવાળો S હોય, તો નવી રાશિ ઉમેરતાં % ફેરફાર શોધવા માટે સામગ્રી બદલાય તે યાદ રાખો.
• બે સમૂહની સામગ્રી જાણીતી હોય, તો સંયુક્ત સામગ્રી = (n₁·x̄₁ + n₂·x̄₂)/(n₁+n₂).

ઉદાહરણ:
૪૦, ૫૦, ૬૦, ૭૦, ૮૦ ની સામગ્રી = (૪૦+૫૦+૬૦+૭૦+૮૦)/૫ = ૩૦૦/૫ = ૬૦.

ગુણાત્મક મહત્વ:
• સામગ્રી હંમેશા ન્યૂનતમ અને મહત્તમ મૂલ્યની વચ્ચે હોય છે.
• GSSSB માં સામગ્રીના પ્રશ્નો ઘણીવાર જૂથોના સરવાળાનો સંબંધ સાથે આવે છે.

૭. સામગ્રીના પ્રકારો અને ઉકેલ પદ્ધતિઓ

(૧) સરળ સામગ્રી:
સરવાળો/Sંખ્યા. ઉદા: ૧૦, ૨૦, ૩૦ ની સામગ્રી = ૨૦.

(૨) સંયુક્ત (Weighted) સામગ્રી:
જો બે અથવા વધુ ગ્રુપ્સ હોય, તો દરેક ગ્રુપનું આદાન-પ્રદાન તેના સદસ્યોના આધારે થાય છે.
સંયુક્ત સામગ્રી = (n₁·x̄₁ + n₂·x̄₂ + ... ) / (n₁ + n₂ + ...).

(૩) બદલાતી સામગ્રી:
કોઈ એક રાશિ ઉમેરવી અથવા બદલવી હોય, તો નવી સામગ્રી = [(pૂર્વ સરવાળો ± ફેરફાર)/કુલ સંખ્યા].

(૪) સરેરાશનો ઉપયોગ:
ગાઉલેટ પદ્ધતિ (Deviation Method): પસંદગીનો અંદાજિત મધ્યબિંદુ (Assumed Mean) લો; તબક્કાવાર ગણતરી કરીને સાચું મૂલ્ય કાઢો. GSSSB માં આ પદ્ધતિ ઝડપી ગણતરી માટે ખૂબ ઉપયોગી છે.

ઉદાહરણ (ગાઉલેટ):
રાશિઓ: ૪૬, ૫૪, ૫૮, ૬૨. ધારો કે Assumed Mean = ૫૦.
અનુપાતનો તફાવત: ૪, ૪, ૮, ૧૨.
સરવાળો = ૨૮; ૪/૪ = ૭. તેથી સામગ્રી = ૫૦ + ૭ = ૫૭.

(૫) બે ગ્રુપની સામગ્રી:
ગ્રુપ A: n₁ સદસ્યો, x̄₁ સામગ્રી; ગ્રુપ B: n₂ સદસ્યો, x̄₂ સામગ્રી.
સંયુક્ત = (n₁x̄₁ + n₂x̄₂)/(n₁+n₂).

(૬) વાસ્તવિક જીવનની ઉદાહરણો:
• વર્ગની સરેરાશ ઉમર, એક્ટરીના સરેરાશ માસિક ધોરણ, વાર્ષિક મુસાફરીનો સરેરાશ ખર્ચ.

૮. ઉંમર અને સામગ્રી સંબંધિત પ્રશ્નો

ઉંમરના સવાલો GSSSB માં આવતા રહે છે. તેમાં સામગ્રીનો ઉપયોગ થાય છે.

મહત્વના સિદ્ધાંતો:
• હાલની સરેરાશ ઉંમર = કુલ ઉંમર / સંખ્યા.
• X વર્ષ પહેલાં કુલ ઉંમર = (વર્તમાન સરેરાશ × સંખ્યા) − (X × સંખ્યા).
• Y વર્ષ પછી કુલ ઉંમર = (વર્તમાન સરેરાશ × સંખ્યા) + (Y × સંખ્યા).
• જો કોઈ વ્યક્તિ જોડાઈ હોય અથવા છૂટી હોય, તો નવી સરેરાશ = [(પૂર્વ સરવાળો ± નવી વ્યક્તિની ઉંમર)/નવી સંખ્યા].

ઉદાહરણ:
૫ વ્યક્તિઓની વર્તમાન સરેરાશ ઉંમર ૩૦ વર્ષ છે. ૨ વર્ષ પહેલાં કુલ ઉંમર કેટલી? ૩૦×૫ = ૧૫૦. ૨ વર્ષ પહેલાં દરેક ૨ વર્ષ ઓછું — કુલ ૧૫૦ − ૧૦ = ૧૪૦.

આ પ્રકારના પ્રશ્નોમાં સંખ્યાત્મક અવધાન અને તર્કશક્તિ બંનેની જરૂર હોય છે. સામાન્ય રીતે ચોકસાઈ અને ઝડપ બંને જરૂરી છે.

૯. સામાન્ય ભૂલો અને પરીક્ષા ઉકેલ કળાઓ

સામગ્રી અને ટકાવારીમાં સામાન્ય ભૂલો:
(૧) સરવાળો અને સરેરાશ વચ્ચેનો તફાવત ન સમજવો. સામગ્રી ≠ સરવાળો.
(૨) સંયુક્ત સામગ્રીમાં સદસ્યોની સંખ્યાનો ભાગ ભૂલી જવો.
(૩) ઉંમરના પ્રશ્નોમાં X વર્ષ પહેલાં/પછી નક્કી કરતી વખતે કુલ ઉંમરમાં સ્થિરાંકનો ગુણાકાર ન કરવો.
(૪) ટકાવારી ફેરફારમાં ગણતરીનો ક્રમ બદલવો (જેમ કે ૨૦% વધારો અને ૨૦% ઘટાડોને સરવાળા તરીકે જોવો).

પરીક્ષા ટાઇમ મેનેજમેન્ટ:
• દરેક પ્રશ્નને પહેલા સરળ રીતે ઉકેલવાનો પ્રયત્ન કરો.
• જો સીધું સૂત્ર ન લાગુ પડતું હોય, તો ધારો કે P = ૧૦૦ લઈને ચકાસણી કરો (Option Back Calculation).
• ઘણા પ્રશ્નોમાં વિકલ્પો જોયા પછી જોડીને ઝડપી ગણતરી કરી શકાય છે.
• ભૂલો ટાળવા: છેદ/અંશ ચકાસો, એકમો ચકાસો, અંકગણિતીય ગણતરી ચકાસો.

GSSSB માટે ખાસ સૂચન:
• ટકાવારી + સામગ્રી મિશ્ર પ્રશ્નો પણ આવે છે — આવા સવાલોમાં આધાર રાશિને યોગ્ય રીતે ઓળખવી જરૂરી છે.
• ગાઉલેટ પદ્ધતિ ઝડપી બની શકે છે, પરંતુ તેમાં ચોકસાઈ જાળવવી.

૧૦. ગુજરાતી-ઇંગ્લિશ પરિભાષા અને અનુવાદ

નોંધપાત્ર પરિભાષા (Gujarati ↔ English):
• ટકાવારી = Percentage
• સામગ્રી / સરેરાશ = Average / Mean
• ભાગ = Part
• સરવાળો = Sum / Total
• સંખ્યા = Number / Count
• વધારો = Increase
• ઘટાડો = Decrease
• ખરેડ મૂલ્ય = Cost Price (CP)
• વેચાણ મૂલ્ય = Selling Price (SP)
• લાભ = Profit
• નુકસાન = Loss
• ઇનક્રીબલ ગણતરી = Incremental Calculation
• મૂળભૂત = Basic
• આધાર = Base / Reference
• ગુણોત્તર = Ratio
• દશાંશ = Decimal
• ભિન્ન = Fraction
• સમાનતા = Equality
• વ્યાખ્યા = Definition
• પરિણામ = Result
• યોજના = Plan
• ચલ = Variable
• સમીકરણ = Equation
• સૂત્ર = Formula

આ શબ્દાવલી GSSSB માં પ્રશ્ન ભાષા અને ગણતરીને સમજવામાં મદદરૂપ થાય છે.

Important facts

  • ટકાવારી = (ભાગ/કુલ) × ૧૦૦. % નો અર્થ હંમેશા 'પ્રતિ ૧૦૦' છે.
  • સામગ્રી = સરવાળો / સંખ્યા. સરેરાશ હંમેશા ન્યૂનતમ અને મહત્તમ વચ્ચે હોય છે.
  • બે સતત ટકાવારી ફેરફાર a અને b માટે કુલ % ફેરફાર = a + b + (ab/૧૦૦).
  • જો a% વધારો અને a% ઘટાડો પછી મૂળ રકમ પાછી ન આવે; net ફેરફાર = −(a²/૧૦૦)% (નુકસાન).
  • સંયુક્ત સામગ્રી = (n₁x̄₁ + n₂x̄₂)/(n₁ + n₂).
  • પ્રતિશત ફેરફાર = [(નવી − જૂની)/જૂની] × ૧૦૦. છેદ હંમેશા જૂની (આધાર) રાશિ હોય છે.
  • લાભ % = (લાભ/CP)×૧૦૦; નુકસાન % = (નુકસાન/CP)×૧૦૦.
  • સામગ્રીમાં ગાઉલેટ પદ્ધતિ (Assumed Mean) એ ઝડપી ગણતરી માટે ઉપયોગી છે.
  • ઉંમરના પ્રશ્નોમાં X વર્ષ પહેલાં/પછી કુલ ઉંમરમાં X×સંખ્યા ઉમેરવું/ઘટાડવું પડે છે.
  • ૨૦% વધારો અને ૨૦% ઘટાડો એકસાથે કરવાથી ૪% નુકસાન થાય છે, મૂળ રકમ પાછી ન આવે.

Formulas and relationships

ટકાવારી = (ભાગ/કુલ) × ૧૦૦
પ્રતિશત ફેરફાર = [(નવી − જૂની)/જૂની] × ૧૦૦
બે સતત ટકાવારી ફેરફાર a,b માટે કુલ % ફેરફાર = a + b + (ab/૧૦૦)
સામગ્રી = સરવાળો / સંખ્યા
સરવાળો = સામગ્રી × સંખ્યા
સંયુક્ત સામગ્રી = (n₁·x̄₁ + n₂·x̄₂)/(n₁ + n₂)
લાભ % = (લાભ/ખરેડ મૂલ્ય) × ૧૦૦
નુકસાન % = (નુકસાન/ખરેડ મૂલ્ય) × ૧૦૦
ખરેડ મૂલ્ય = ૧૦૦/(૧૦૦+લાભ%) × વેચાણ મૂલ્ય
વેચાણ મૂલ્ય = ખરેડ મૂલ્ય × (૧ + લાભ%/૧૦૦)
અંતર્ગત ફેરફાર: જો ભાવ a% વધે અને ખર્ચ સમાન રાખવું હોય, તો માંગમાં % ઘટાડો = [a/(૧૦૦+a)] × ૧૦૦
ગાઉલેટ પદ્ધતિ: સરેરાશ = A.M + (શિથિલતાના સરવાળા/સંખ્યા)

Common mistakes

  • ટકાવારી ફેરફારમાં છેદમાં જૂની રાશિ મૂકવી જરૂરી છે; ખોટી રાશિ લેવી એ સૌથી સામાન્ય ભૂલ છે.
  • ૨૦% વધારો પછી ૨૦% ઘટાડો કરવાથી મૂળ રાશિ પાછી આવી જાય તેવું માનવું ભૂલભર્યું છે; નું net ફેરફાર ઋણ આવે છે.
  • સંયુક્ત સામગ્રીમાં નાના ગ્રુપની સંખ્યાને અવગણી દેવી અથવા ગુણાકારમાં ભૂલ કરવી.
  • ઉંમરના પ્રશ્નોમાં X વર્ષ પહેલાં/પછી કુલ ઉંમરનો ફેરફાર X×સંખ્યા લખવો એ ભૂલથી ચૂકી જવો.
  • ટકાવારીના રૂપાંતરણમાં ૧/૩ = ૩૩.૩૩% ને સંપૂર્ણ ૩૩% લખવું ભૂલભર્યું છે; પુનરાવર્તિત દશાંશ ધ્યાનમાં લેવો.
  • લાભ-% અને નુકસાન-% ની ગણતરીમાં છેદ હંમેશા CP હોય છે; SP નહીં.
  • આધાર રાશિ શોધતી વખતે 'કરતાં' શબ્દનો અર્થ કરવો જરૂરી છે: 'A, B કરતાં ૨૫% વધારે' એટલે A/B > ૧.
