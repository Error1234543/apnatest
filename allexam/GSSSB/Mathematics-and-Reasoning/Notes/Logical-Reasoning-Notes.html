૧. તુલના (Analogy)

તુલનામાં બે શબ્દો/વસ્તુઓ વચ્ચેનો સંબંધ જણાવવામાં આવે છે અને આ સંબંધને આધારે ત્રીજા પદ સાથે સમાન સંબંધ ધરાવતું ચોથું પદ શોધવું પડે છે.

સામાન્ય સંબંધના પ્રકારો:
• કાર્ય-કારણ: દા.ત., અગ્નિ : ધુમ્મસ — આગથી ધુમ્મસ થાય છે.
• ઉપકરણ-કાર્ય: દા.ત., કેલ્ક્યુલેટર : ગણતરી — કેલ્ક્યુલેટર વડે ગણતરી કરવામાં આવે છે.
• વસ્તુ-ગુણધર્મ: દા.ત., પાણી : ભેજ — પાણીમાં ભેજનો ગુણ હોય છે.
• ભાગ-આખા: દા.ત., પંખો : બ્લેડ — બ્લેડ પંખાનો એક ભાગ છે.
• વ્યાપ-વ્યાપક: દા.ત., ફળ : ડેલિઆ — ડેલિઆ એક પ્રકારનું ફળ છે.
• વિરુદ્ધ અર્થ: દા.ત., દહીં : દૂધ — સંબંધ વિરુદ્ધ બની શકે.
• રંગ-વસ્તુ: દા.ત., કાળું : ચોર — ચોર સામાન્ય રીતે કાળો ગણાય.
• દેશ-ભાષા: દા.ત., ભારત : હિન્દી — ભારતની પ્રધાન ભાષા.
• પ્રાણી-બચ્ચું: દા.ત., સિંહ : શુનક — સિંહનું બચ્ચું શુનક.
• અક્ષર-અંક ગણતરી: દા.ત., A=1, B=2, તો CE=? — C=3, E=5, જોડ=8.

GSSSB માં સામાન્ય રીતે ૨-૩ તુલનાના પ્રશ્ન આવે છે. સંબંધ સમજ્યા પછી ઓપ્શનમાંથી યોગ્ય જોડી શોધવી હોય છે.

૨. શ્રેણી (Series — સંખ્યા અને અક્ષર)

શ્રેણીમાં આપેલા ક્રમમાંથી છુપાયેલું નિયમ શોધી પાછું ફરતી / આગળની સંખ્યા / ગુમ થયેલી સંખ્યા શોધવી પડે છે.

સંખ્યા શ્રેણીના મુખ્ય પ્રકારો:
• સરળ વધઘટ: દા.ત., 2, 5, 8, 11, ___ — દરેકમાં +3; ઉત્તર 14.
• વર્ગ શ્રેણી: દા.ત., 1, 4, 9, 16, 25, ___ — n²; ઉત્તર 36.
• ઘન શ્રેણી: દા.ત., 1, 8, 27, 64, 125, ___ — n³; ઉત્તર 216.
• અંતર બદલાતી શ્રેણી: દા.ત., 2, 3, 5, 8, 13, ___ — અંતર +1,+2,+3,+5 (ફિબોનાક્લી).
• અંકોનો સરવાળો: દા.ત., 12 (1+2=3), 21 (2+1=3), 30 (3+0=3) — બધાનો અંકગણિત સરવાળો 3.
• ભાગફળ શ્રેણી: દા.ત., 100, 50, 25, 12.5, ___ — દરેકને 2 વડે ભાગતા.
• બે વૈકલ્પિક શ્રેણી: દા.ત., 2, 5, 4, 8, 6, 11, ___ — બીજી જગ્યાએ +3, ત્રીજી જગ્યાએ +2;
ઉત્તર: ૮.

અક્ષર શ્રેણી:
• સીધો ક્રમ: A, C, E, G, I, ___ — +2; ઉત્તર K.
• વૈકલ્પિક અક્ષર: ACE, BDF, CEG, ___ — દરેક વારસા +1; ઉત્તર DFH.
• વિરુદ્ધ ક્રમ: Z, X, V, T, R, ___ — -2; ઉત્તર P.
• જોડી શ્રેણી: AB, CD, EF, GH, ___ — +2 અક્ષર;
ઉત્તર IJ.
• અંતરમાં ફેરફાર: A, D, G, J, ___ — +3, +3, +3;
ઉત્તર M.

GSSSB માટે વર્ગ (1²-20²) અને ઘન (1³-12³) યાદ રાખવા જરૂરી છે.

૩. કોડિંગ-ડિકોડિંગ (Coding-Decoding)

કોડિંગ-ડિકોડિંગમાં શબ્દ/અક્ષરોને અનુક્રમમાં કોઈ નિયમ મુજબ બદલીને કોડ તૈયાર કરવામાં આવે છે. તે કોડ શોધવો અથવા કોડ તોડવો.

અક્ષર કોડિંગના પ્રકારો:
• સીધો વિપરીત: A→Z, B→Y (અક્ષરનું પૂરક જોડ)
દા.ત., CAT → XZG (C→X, A→Z, T→G)
• એક આગળ/પાછળ: દા.ત., F→G, O→P (દરેક અક્ષર +1)
RAIN → SBJO
• દરેક બદલીને: AB→BA, CD→DC
• અંતર આધારિત: A→C (+2), B→D (+2) — સમાન અંતર.
• હિન્દી/ગુજરાતી અક્ષર કોડિંગ: અ→ઍ, આ→ક્રે — સમાન નિયમ લાગુ પડે.

અંક કોડિંગ:
• શબ્દના અક્ષરોનું અનુક્રમ નંબર મૂકવો: F=6, O=15, R=18, E=5, S=19 → 6 15 18 5 19.
• અંકોનો સરવાળો/અંતર.

શબ્દ કોડિંગ:
• દા.ત., 'MANGO' = 31275, 'PAPAYA' = 516154
A=1, P=5, M=3, N=7, G=2, O=6
તેથી 'GOAPE' = 62151.

મહત્વનું: કોડિંગમાં વર્ણમાળાના ક્રમ (1-26) અને વિપરીત (A-Z, B-Y...) હંમેશા યાદ રાખવા.

પૂરક જોડી યાદ કરવાની રીત: A+Z=26, B+Y=26, … M+N=26.

૪. રક્તસંબંધ (Blood Relations)

રક્તસંબંધ પ્રશ્નોમાં આપેલા વ્યક્તિઓ વચ્ચેના સંબંધોની મદદથી બીજા વ્યક્તિ સાથેનો સંબંધ શોધવો પડે છે.

મૂળભૂત પરિભાષા:
• પિતા/માતા → બાળક : માતાપિતાના સંબંધ.
• પુત્ર/પુત્રી → માતાપિતા.
• ભાઈ/બહેન : સમાન માતાપિતા અથવા એક માતાપિતા.
• સાસુ/સસરા : પતિ/પત્નીના માતાપિતા.
• સાસરો/સાસુવહુ : પતિના માતાપિતા / પત્ની.
• મاما/ખાળો/મસાણો: માતાનો ભાઈ/બહેનનો પતિ/પત્ની.
• મમતા: માતાની બહેન.
• કકા: પિતાનો ભાઈ.
• ફુપ્પો: પિતાની બહેન.
• ફૈઝા: કકાની પત્ની.
• ભત્રીજો/ભત્રીજી: ભાઈ/બહેનનું પુત્ર/પુત્રી.
• નાતિનયો/નાતિની: પુત્ર/પુત્રીનું પુત્ર/પુત્રી.

સંકેત રીત:
• A + B = A is husband of B
• A – B = A is wife of B
• A × B = A is brother of B
• A ÷ B = A is sister of B
• A $ B = A is father of B
• A © B = A is mother of B
• A @ B = A is son of B
• A % B = A is daughter of B

સંકેત યોજવાની રીત: સમીકરણને ડાબેથી જમણે તોડીને ચકાસો. સંબંધ શોધીને જવાબ પસંદ કરો.

GSSSB માં ૧-૨ પ્રશ્ન આવે છે. ડાયરાગ્રામ બનાવવો સરળ બનાવે છે.

૫. દિશા અને દૂરત્વ (Direction Sense)

દિશા પ્રશ્નોમાં વ્યક્તિ કઈ દિશામાં ગયો અને તે કેટલી દૂર છે તે શોધવું.

મૂળભૂત દિશાઓ:
• ઉત્તર (N), દક્ષિણ (S), પૂર્વ (E), પશ્ચિમ (W)
• આંતરદિશાઓ: ઉત્તર-પૂર્વ (NE), ઉત્તર-પશ્ચિમ (NW), દક્ષિણ-પૂર્વ (SE), દક્ષિણ-પશ્ચિમ (SW)

ભૂમિતિય સૂત્રો:
• સમકોણ ત્રિકોણ માટે પાઇથાગોરસ: AC² = AB² + BC²
• સામાન્ય ૩-૪-૫, ૬-૮-૧૦, ૫-૧૨-૧૩, ૮-૧૫-૧૭ આધારિત પ્રશ્નો આવે છે.

ઘડિયાળ સૂત્ર:
• વસ્તુ/છાયા ઉત્તર-દક્ષિણ દિશામાં હોય ત્યારે:
- પ્રાતઃકાળ: ઉત્તર તરફ
- બપોરે: દક્ષિણ તરફ
- સાંજે: પૂર્વ તરફ
• વિરુદ્ધ દિશામાં ઊભા રહેતા વ્યક્તિઓમાં છાયા ઊલટી થાય.

સામાન્ય પદ્ધતિ:
1. શરૂઆતની દિશા નક્કી કરો.
2. દરેક વળાંકને અનુસરીને ડાયરેક્શન બનાવો.
3. અંતિમ સ્થાનેથી શરૂઆત સુધી સીધો રસ્તો દોરો.
4. કાટકોણ ત્રિકોણનો ઉપયોગ કરીને અંતર શોધો.

ઉદાહરણ: વ્યક્તિ ઉત્તર તરફ ૫ કિમી ચાલે, જમણે મોડી (પૂર્વ) ૩ કિમી, ફરી જમણે (દક્ષિણ) ૫ કિમી. અંતિમ સ્થાન શરૂઆતથી કેટલા કિમી દૂર?
ઉત્તર: પાઇથાગોરસથી √(5²+3²)=√34≈૫.૮૩ કિમી, દિશા: ઉત્તર-પૂર્વ.

GSSSB માં ૧-૨ પ્રશ્ન આવે છે.

૬. મોર્યા અને ક્રમ (Ranking and Ordering)

મોર્યા પ્રશ્નોમાં વ્યક્તિઓના ક્રમ અને સ્થાન શોધવાના હોય છે.

મૂળભૂત સૂત્રો:
• કુલ = ડાબેથી મોર્ય + જમણેથી મોર્ય – ૧
• જો વ્યક્તિ Nમી હોય, તો ડાબેથી = કુલ – N + 1, જમણેથી = કુલ – N + 1
• વ્યક્તિ વચ્ચેની વ્યક્તિઓ = (મોર્ય1 + મોર્ય2 – કુલ – 1)

ઉદાહરણ: ૩૦ બાળકોની હરોળમાં રાહુલ ડાબેથી ૧૫મો અને જમણેથી કોણ?
જવાબ: ૩૦ – ૧૫ + ૧ = ૧૬મો.

ઉદાહરણ: ૩૫ બાળકોની હરોળમાં સાની ડાબેથી ૨૦મી છે, તેની પાછળ ૧૦ બાળકો છે. કુલ કેટલા બાળકો?
જવાબ: ૨૦ + ૧૦ = ૩૦ + (જમણેથી મોર્ય – ૧). જમણેથી = ૬મી, કુલ = ૨૦ + ૬ – ૧ = ૨૫.

ઉપર-નીચે ક્રમ:
• ઊંચાઈ મુજબ: શ્રેષ્ઠથી ૫મો, જૂઠાથી ૩મો. કુલ = ?
• જો શ્રેષ્ઠ + જૂઠા = કુલ + 1 હોય, તો શક્ય નથી.

GSSSB માં ૧-૨ પ્રશ્ન આવે છે.

૭. સિલોજિઝમ (Syllogism)

સિલોજિઝમમાં કેટલાક નિવેદનો આપે છે અને તર્કસંગત નિષ્કર્ષ શોધવાના હોય છે. વેન ડાયગ્રામ દ્વારા ઉકેલવું સૌથી સરળ છે.

મૂળભૂત નિવેદનો અને ડાયગ્રામ:
• બધા A B છે → A સંપૂર્ણપણે B માં હોય (A ⊆ B)
• કેટલાક A B છે → A અને B નો સંપર્ક છે (A ∩ B ≠ ∅)
• કોઈ A B નથી → A અને B અલગ (A ∩ B = ∅)
• કેટલાક A B નથી → A ના કેટલાક ભાગ B માં નથી

સંભવિત નિષ્કર્ષો:
• બધા A B, બધા B C → બધા A C (શક્ય)
• બધા A B, કોઈ B C નથી → કોઈ A C નથી (શક્ય)
• કેટલાક A B, બધા B C → કેટલાક A C (શક્ય)
• બધા A B, કેટલાક B C → A ને C સાથે સંબંધ નક્કી ન કરી શકાય

તાર્કિક નિયમ:
• કોઈ પણ 'બધા' વિનાનું નિવેદન હોય તો નિષ્કર્ષ ન આપે.
• બે 'કોઈ ... નથી' હોય તો કોઈ નિષ્કર્ષ ન આવે.
• વિરોધાભાસી જોડી માટે 'અથવા' (either/or) નિષ્કર્ષ.

ઉદાહરણ:
નિવેદનો:
• બધા પક્ષી ઉડે છે.
• કેટલાક પક્ષી કાળા છે.
નિષ્કર્ષો:
• I. કેટલાક પક્ષી કાળા છે અને ઉડે છે. (સત્ય)
• II. બધા કાળા પક્ષીઓ ઉડે છે. (અનિર્ધારિત)

GSSSB માં ૨-૩ પ્રશ્ન આવે છે. વેન ડાયગ્રામ વડે ઉકેલવા.

મહત્વની નોંધ: નિષ્કર્ષમાં 'બધા', 'કેટલાક', 'કોઈ ... નથી' શબ્દોનું ધ્યાન રાખો.

૮. મેટ્રિક્સ અને ચાર્ટ (Matrix and Chart)

મેટ્રિક્સ પ્રશ્નોમાં આપેલા કોષ્ટકમાંથી માહિતી વાંચી જવાબ આપવાના હોય છે.

ચાર પ્રકારના મેટ્રિક્સ પ્રશ્નો:
• અક્ષર મેટ્રિક્સ: અક્ષરોનો ક્રમ શોધો.
• અંક મેટ્રિક્સ: અંકોનો સંબંધ શોધો.
• આકાર મેટ્રિક્સ: આકારોમાં કોઈ યોગ્ય પસંદગી કરો.
• સંકલન મેટ્રિક્સ: કોષ્ટકમાં ખાલી સ્થાન ભરો.

ઉદાહરણ: નીચેના કોષ્ટકમાં ખાલી કોષ્ટક શોધો.

| 2 | 4 | 8 |
| 3 | 6 | 18 |
| 4 | 8 | ? |

નિયમ: પ્રથમ સ્તંભ × બીજો સ્તંભ = ત્રીજો.
તેથી 4 × 8 = 32.

ચાર્ટ પ્રશ્ન:
• વિદ્યાર્થીઓના સમૂહો (વર્ગ ૧-૧૦).
• સંખ્યાઓ માં વિભાજકતા આધારિત.
• કોષ્ટકીય ડેટા વાંચી જવાબ.

GSSSB માં ૧-૨ પ્રશ્ન આવે છે.

૯. રમત-આધારિત તર્ક (Games and Tournaments)

રમત-આધારિત પ્રશ્નોમાં ટૂર્નામેન્ટ, ગ્રાઉન્ડ, અને વિવિધ ઘટનાઓના આધારે પૂછવામાં આવે છે.

લીગ પ્રણાલી:
• n ટીમો હોય તો કુલ મેચ = n(n-1)/2.
• બધાએ બધા સામે રમવાના હોય તો પ્રત્યેક ટીમ (n-1) મેચ રમે.

કપ પ્રણાલી (Elimination):
• n ટીમો હોય તો વિજેતા નક્કી કરવા માટે (n-1) મેચ જરૂરી.
• અડધી મેચ બાદ બાકી રહી જાય.

ગ્રાઉન્ડ પ્રશ્નો:
• n વ્યક્તિઓ રમતમાં ભાગ લે તેમાંથી ૨ વ્યક્તિઓ પસંદ કરવાની રીતો = nC2.
• ૩ વ્યક્તિઓ પસંદ કરવાની રીતો = nC3.

ઉદાહરણ: ૧૦ ટીમોની લીગ મેચમાં કુલ મેચ = ૧૦×૯/૨ = ૪૫.
ઉદાહરણ: ૧૬ ટીમોના કપ ટૂર્નામેન્ટમાં વિજેતા નક્કી કરવા ૧૫ મેચ જરૂરી.

GSSSB માં ૧ પ્રશ્ન આવે છે.

૧૦. નકશા અને પદાર્થ સંબંધ (Map and Figure Based)

આ પ્રકારના પ્રશ્નોમાં ચિત્રો, આકૃતિઓ અને પદાર્થો વચ્ચેના સંબંધો શોધવાના હોય છે.

આકૃતિ સંબંધ:
• ત્રિકોણ-ચોરસ-વૃત્ત વચ્ચેનો સંબંધ.
• ઉદાહરણ: કાળો વર્તુળ = રાજકારણી, લાલ વર્તુળ = સરકારી કર્મચારી, ત્રિકોણ = ભારતીય.
• ત્રિકોણ-વર્તુળ = ભારતીય સરકારી રાજકારણી.

પદાર્થોની મૂલ્ય શોધો:
• નકશામાં દૂરત્વ ગણતરી.
• મૂલ્ય ગણતરી.

ઉદાહરણ: ૪ વ્યક્તિઓના સમૂહમાંથી ૨ પસંદ કરવાની રીતો = ૬.

GSSSB માં ૧ પ્રશ્ન આવે છે.

૧૧. ગાણિતિક વિધાન (Mathematical Operations)

ગાણિતિક વિધાનમાં ચિહ્નો બદલીને સમીકરણો ઉકેલવાના હોય છે.

ચિહ્ન બદલીને પ્રશ્નો:
• '+', '-', '×', '÷' ને બદલીને સમીકરણ ઉકેલો.
• ઉદાહરણ: '+' ને '−', '−' ને '×', '×' ને '÷', '÷' ને '+' કરો.

કૌંસ અને ક્રમ:
• સૌ પ્રથમ કૌંસમાંથી કાઢો.
• ભાગાકાર/ગુણાકાર પછી ઉમેરો/બાદબાકી.
• BODMAS નિયમ મુજબ ગણતરી કરો.

ઉદાહરણ: (15 + 5) − 3 × 2 = 20 − 6 = 14.

૧૨. પરિકલ્પના અને તર્કશક્તિ (Statement and Assumption / Conclusion)

વિધાન આપે છે અને તેના આધારે પરિકલ્પના કે નિષ્કર્ષ શોધવાના હોય છે.

વિધાન અને પરિકલ્પના:
• વિધાન: કોઈ માહિતી આપે છે.
• પરિકલ્પના: વિધાનમાંથી નિર્ધારિત હોય.
• નિષ્કર્ષ: વિધાન અને પરિકલ્પના પરથી નીકળે.

નિયમો:
• પરિકલ્પના હંમેશા વિધાનથી મળતી હોવી જોઈએ.
• નિષ્કર્ષ હંમેશા વિધાન અને પરિકલ્પનાથી મળવો જોઈએ.
• પરિકલ્પના 'અનિશ્ચિત' હોય તો નિષ્કર્ષ મળતો નથી.

ઉદાહરણ:
વિધાન: બધા વિદ્યાર્થીઓ માફક છે.
પરિકલ્પના: તેથી હું પણ વિદ્યાર્થી છું.
નિષ્કર્ષ: હું માફક છું.

GSSSB માં ૧-૨ પ્રશ્ન આવે છે.

Important facts

  • સમીકરણનો નિયમ: BODMAS → Brackets, Orders, Division, Multiplication, Addition, Subtraction
  • અક્ષર ક્રમ: A=1, B=2, ..., M=13, N=14, ..., Z=26
  • પૂરક જોડી: A+Z=26, B+Y=26, C+X=26, D+W=26, E+V=25, F+U=21, G+T=20, H+S=19, I+R=18, J+Q=17, K+P=16, L+O=15, M+N=14
  • સંખ્યા શ્રેણીમાં વર્ગ (1-20): 1,4,9,16,25,36,49,64,81,100,121,144,169,196,225,256,289,324,361,400
  • ઘન (1-12): 1,8,27,64,125,216,343,512,729,1000,1331,1728
  • ત્રિકોણ આંકડો: ૩-૪-૫, ૬-૮-૧૦, ૫-૧૨-૧૩, ૮-૧૫-૧૭
  • રક્તસંબંધમાં: પિતા → માતાબાળક, માતા → બાળક, ભાઈ → ભાઈ, બહેન → બહેન, ચચેરો → ચચેરો, મમાશું → મમાશું
  • મોર્યા સૂત્ર: કુલ = ડાબેથી + જમણેથી - 1
  • ટૂર્નામેન્ટ: n ટીમો = n(n-1)/2 મેચ (લીગ), n-1 મેચ (કપ)
  • વેન ડાયગ્રામ: બધા A B → A B ના અંદર; કેટલાક A B → A અને B નો સંપર્ક

Formulas and relationships

સંખ્યા શ્રેણી: nમો પદ = પ્રથમ પદ + (n-1)×અંતર
અંતર શ્રેણી: અંતરોનો સરવાળો = શ્રેણીના મોટા ભાગના સંયોજનો
રક્તસંબંધ: માતાપિતા + બાળક = પિતા/માતા
મોર્યા: જમણેથી મોર્ય = કુલ - ડાબેથી મોર્ય + 1
કપ ટૂર્નામેન્ટ: n ટીમો માટે (n-1) મેચ
લીગ ટૂર્નામેન્ટ: n ટીમો માટે n(n-1)/2 મેચ
વર્ગ શ્રેણી: n², ઘન શ્રેણી: n³, સંયોજન: nC2=n(n-1)/2, nC3=n(n-1)(n-2)/6

Common mistakes

  • અક્ષર ક્રમમાં યાદ રાખવામાં ભૂલ: B=2, N=14, M=13 — આ સંખ્યાઓ ગલત લખવી.
  • મોર્યામાં 1 બાદ કરવામાં ભૂલ: કુલ = ડાબેથી + જમણેથી - 1 ની બદલે +1 કરવું.
  • સિલોજિઝમમાં 'બધા' અને 'કેટલાક' વચ્ચે તફાવત ન પડવો.
  • કોડિંગમાં અક્ષરને +1 કરવાની બદલે -1 કરવું અથવા ઉલટું.
  • રક્તસંબંધમાં સંબંધ ઓળખવામાં ભૂલ: પિતાનો ભાઈ = કકા, માતાનો ભાઈ = મમાશું.
  • દિશા પ્રશ્નોમાં ઉત્તર-દક્ષિણ બદલી નાખવા.
  • શ્રેણીમાં વર્ગ/ઘન યાદ ન રાખવાથી ભૂલ.
  • પરિકલ્પનામાં વિધાનથી અલગ મતલબ લેવો.
  • BODMAS નિયમ ભૂલવો — ઉમેરો/બાદબાકી પહેલાં ભાગાકાર/ગુણાકાર કરવો જોઈએ.
  • વેન ડાયગ્રામમાં 'બધા' ને 'કેટલાક' માની લેવું.
