बीजगणित — पूर्ण अध्याय नोट्स (SSC Quantitative Aptitude)

SSCHindiNotes

प्रस्तावना और SSC में बीजगणित का महत्त्व

SSC परीक्षाओं (CGL, CHSL, MTS, CPO आदि) के टायर-1 में गणितीय कुशलता (Quantitative Aptitude) सेक्शन के अंतर्गत बीजगणित का भार लगभग 5-8 प्रश्नों का होता है। ये प्रश्न मुख्यतः बीजगणितीय सर्वसमिकाओं के अनुप्रयोग, व्युत्क्रम संबंधित समस्याएँ, गुणनखंडन, हल विधियाँ और निम्न कोटि के बहुपद समीकरणों पर आधारित होते हैं। SSC में बीजगणित के प्रश्न अक्सर 'मान ज्ञात कीजिए' प्रकार के होते हैं जहाँ सीधे सूत्र याद रखने से ज्यादा प्रतिस्थापन तकनीक (Substitution Method), x + 1/x रूप वाले व्यंजकों से निकालने वाले परिणाम, और त्रिवार सर्वसमिका a³+b³+c³−3abc के अनुप्रयोग पर बल दिया जाता है। किसी भी बीजगणितीय सर्वसमिका को केवल याद करने से काम नहीं चलता; उसकी शर्तें (जैसे a+b+c=0 रखने पर a³+b³+c³=3abc का उपयोग) स्पष्ट होनी चाहिए। इस अध्याय में हम मूल सर्वसमिकाओं से लेकर उन्नत अनुप्रयोग तक सभी प्रकार कवर करेंगे ताकि कोई भी प्रश्न अज्ञात न रहे।

मुख्य बीजगणितीय सर्वसमिकाएँ

नीचे दी गई सभी सर्वसमिकाएँ SSC में नियमित रूप से पूछी जाती हैं और इन्हें मस्तिष्क में स्थापित करना अनिवार्य है:

1. (a + b)² = a² + 2ab + b²
2. (a − b)² = a² − 2ab + b²
3. a² − b² = (a + b)(a − b)
4. (a + b)³ = a³ + b³ + 3ab(a + b)
5. (a − b)³ = a³ − b³ − 3ab(a − b)
6. a³ + b³ = (a + b)(a² − ab + b²)
7. a³ − b³ = (a − b)(a² + ab + b²)
8. (a + b + c)² = a² + b² + c² + 2(ab + bc + ca)
9. a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)

अतिरिक्त उपयोगी सर्वसमिकाएँ:
10. यदि a + b + c = 0, तो a³ + b³ + c³ = 3abc
11. (x + a/x)² = x² + a²/x² + 2a
12. (x − a/x)² = x² + a²/x² − 2a

ये सर्वसमिकाएँ बीजगणित के लगभग 70% प्रश्नों के लिए आधार बनती हैं। विशेषकर सर्वसमिका #9 और #10 SSC में अत्यंत महत्वपूर्ण हैं क्योंकि x + 1/x संबंधित प्रश्नों में इनका प्राथमिक उपयोग होता है।

x + 1/x और x − 1/x संबंधित प्रश्न — मूलभूत तकनीक

SSC में बीजगणित का सबसे स्थिर हिस्सा x + 1/x या x − 1/x से शुरू होकर xⁿ + 1/xⁿ या xⁿ − 1/xⁿ का मान ज्ञात करना है।

मुख्य चरण (Step-by-step तकनीक):
- यदि x + 1/x = k दिया हो, तो
x² + 1/x² = k² − 2
x³ + 1/x³ = k³ − 3k
x⁴ + 1/x⁴ = (x² + 1/x²)² − 2
- यदि x − 1/x = k दिया हो, तो
x² + 1/x² = k² + 2
x³ − 1/x³ = k³ + 3k

उदाहरण 1: यदि x + 1/x = 3 हो, तो x³ + 1/x³ ज्ञात कीजिए।
हल: x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 27 − 9 = 18।

उदाहरण 2: यदि x − 1/x = 5 हो, तो x² + 1/x² ज्ञात कीजिए।
हल: x² + 1/x² = (x − 1/x)² + 2 = 25 + 2 = 27।

उदाहरण 3: यदि x + 1/x = 2 हो, तो x⁶ + 1/x⁶ ज्ञात कीजिए।
हल: x + 1/x = 2 → x² + 1/x² = 4 − 2 = 2 → x³ + 1/x³ = 8 − 6 = 2 → x⁶ + 1/x⁶ = (x³ + 1/x³)² − 2 = 4 − 2 = 2।

ध्यान दें: जब x + 1/x = 2, तो x = 1 होता है। ऐसे विशेष मामलों में सीधे मान रखकर भी जाँच की जा सकती है। SSC में 'कठिन' दिखने वाले प्रश्न अक्सर इसी तकनीक से कुछ कदम आगे बढ़ाए जाते हैं।

प्रतिस्थापन विधि (Substitution / Value Method)

प्रतिस्थापन विधि SSC में समय बचाने वाली सबसे लोकप्रिय तकनीक है, खासकर जब प्रश्न में विकल्प दिए हों। इसमें दिए गए व्यंजक में a, b, c के ऐसे मान रख दिए जाते हैं जो सबसे गणना को सरल बना दें, बशर्ते उन मानों से प्रश्न की शर्तें संतुष्ट हों।

उदाहरण: यदि a + b + c = 0, तो सिद्ध कीजिए कि a³ + b³ + c³ = 3abc, और उसके बाद यदि a + b + c = 5 और ab + bc + ca = 10 हो, तो a³ + b³ + c³ − 3abc का मान ज्ञात कीजिए।
हल (प्रतिस्थापन): a + b + c = 0 ⇒ a³ + b³ + c³ = 3abc (सर्वसमिका से)
अब a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)
a² + b² + c² = (a + b + c)² − 2(ab + bc + ca) = 25 − 20 = 5
⇒ a³ + b³ + c³ − 3abc = 5 × (5 − 10) = 5 × (−5) = −25।

सरल प्रतिस्थापन उदाहरण: यदि x = 2 हो, तो x³ − 3x² + 3x − 1 का मान ज्ञात कीजिए।
हल: (x − 1)³ = x³ − 3x² + 3x − 1; x = 2 रखने पर (2 − 1)³ = 1। प्रतिस्थापन विधि से तुरंत उत्तर मिल जाता है।

सावधानी: प्रतिस्थापन विधि तभी लागू होती है जब दिए गए व्यंजक का मान स्वतंत्र अंकन (independent of specific values) होकर भी एक निश्चित रूप ले ले। यदि प्रश्न किसी विशिष्ट संबंध को तोड़ रहा हो, तो सामान्य बीजगणितीय विधि अपनाएँ।

गुणनखंडन — सामान्य विधियाँ और SSC प्रश्न

गुणनखंडन SSC में 2-3 प्रश्नों के लिए आवश्यक है। नीचे दी गई विधियाँ याद रखें:

1. उभयनिष्ठ गुणनखंड:
ax + ay + bx + by = a(x + y) + b(x + y) = (a + b)(x + y)

2. द्विघात त्रिपद का गुणनखंड:
x² + (a + b)x + ab = (x + a)(x + b)
उदाहरण: x² + 7x + 12 = (x + 3)(x + 4)

3. अंतर वर्ग:
a² − b² = (a + b)(a − b)
उदाहरण: 4x² − 9y² = (2x + 3y)(2x − 3y)

4. वर्ग त्रिपद (पूर्णवर्ग):
a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²

5. योग/अंतर घन:
a³ + b³ = (a + b)(a² − ab + b²)
a³ − b³ = (a − b)(a² + ab + b²)

6. सामूहिक गुणनखंडन द्वारा उच्च कोटि के बहुपद:
उदाहरण: x³ − 3x² + 3x − 1 का गुणनखंड:
यह (x − 1)³ है, क्योंकि (x − 1)³ = x³ − 3x² + 3x − 1।

7. गुणनखंडन मेंremainder theorem अनुप्रयोग:
यदि f(x) = x³ − 6x² + 11x − 6, तो x = 1 रखने पर f(1) = 0, अतः (x − 1) एक गुणनखंड है। भाग देने पर f(x) = (x − 1)(x − 2)(x − 3)।

SSC में गुणनखंडन वाले प्रश्न अक्सर द्विघात या घनात्मक व्यंजकों को सरल बनाकर हल किए जाते हैं, इसलिए उपरोक्त साँचो को पहचानना मुख्य कौशल है।

रैखिक समीकरण जोड़े और द्विघात समीकरण

SSC में रैखिक समीकरणों का युग्म और द्विघात समीकरणों के मूल एक निश्चित पैटर्न में पूछे जाते हैं।

रैखिक समीकरण युग्म का हल:
a₁x + b₁y + c₁ = 0
a₂x + b₂y + c₂ = 0

क्रेसन नियम (Cross-multiplication method):
x / (b₁c₂ − b₂c₁) = y / (c₁a₂ − c₂a₁) = 1 / (a₁b₂ − a₂b₁)

यदि a₁/a₂ ≠ b₁/b₂ हो, तो समीकरण युग्म का एक ही हल होगा।
यदि a₁/a₂ = b₁/b₂ = c₁/c₂ हो, तो अनंत हल होंगे।
यदि a₁/a₂ = b₁/b₂ ≠ c₁/c₂ हो, तो कोई हल नहीं होगा।

द्विघात समीकरण:
ax² + bx + c = 0
मूल = (−b ± √(b² − 4ac)) / 2a

मूलों के बीच संबंध:
मूलों का योग (α + β) = −b/a
मूलों का गुणनफल (αβ) = c/a

विविक्तकर (Discriminant):
D = b² − 4ac
यदि D > 0: दो भिन्न वास्तविक मूल
यदि D = 0: दो समान वास्तविक मूल
यदि D < 0: सम्मिश्र मूल (बिल्कुल वास्तविक नहीं)

SSC में अक्सर m के मान ज्ञात करने के लिए D = 0 या D > 0 की शर्त लगाकर प्रश्न पूछे जाते हैं। उदाहरण: x² + mx + 9 = 0 के मूलों के समान होने के लिए m = ?
हल: D = m² − 36 = 0 → m = ±6।

बहुपद, शेषफल प्रमेय और अवयव प्रमेय (Remainder & Factor Theorem)

बहुपद के शेषफल और अवयव प्रमेय SSC में समय समय पर पूछे जाते हैं।

शेषफल प्रमेय:
यदि बहुपद p(x) को (x − a) से भाग दिया जाए, तो शेषफल p(a) होता है।
उदाहरण: p(x) = x³ − 6x² + 11x − 6 को x − 2 से भाग देते समय शेषफल = p(2) = 8 − 24 + 22 − 6 = 0।

अवयव प्रमेय:
यदि p(a) = 0, तो (x − a) बहुपद p(x) का एक अवयव (factor) है।
उपरोक्त उदाहरण में p(2) = 0 था, अतः (x − 2) p(x) का अवयव है।

दोहरे अवयव ज्ञात करना:
p(x) = x³ − 6x² + 11x − 6 में x = 1, 2, 3 रखने पर क्रमशः 0 आया, अतः
p(x) = (x − 1)(x − 2)(x − 3)।

SSC प्रश्न पैटर्न:
- यदि बहुपद (x − a) और (x − b) दोनों से निःशेष भाज्य हो, तो p(a) = 0 और p(b) = 0 लिखकर a व b ज्ञात किए जाते हैं।
- मिलाकर a व b के मान रखकर अज्ञात गुणांक ज्ञात किए जाते हैं।

उदाहरण: यदि (x − 1) और (x + 2) दोनों p(x) = x³ + ax² + bx + 6 के अवयव हैं, तो a + b ज्ञात कीजिए।
हल: p(1) = 1 + a + b + 6 = 0 → a + b = −7
p(−2) = −8 + 4a − 2b + 6 = 0 → 4a − 2b = 2 → 2a − b = 1
a + b = −7, 2a − b = 1 ⇒ 3a = −6 ⇒ a = −2, b = −5, a + b = −7।

a³ + b³ + c³ − 3abc और अत्यधिक उपयोगी सर्वसमिकाएँ

a³ + b³ + c³ − 3abc सबसे अधिक पूछी जाने वाली सर्वसमिका है, खासकर जब a + b + c = 0 जैसी शर्त दी हो।

मूल सर्वसमिका:
a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)

विशेष मामला:
यदि a + b + c = 0, तो a³ + b³ + c³ = 3abc

SSC प्रश्न पैटर्न:
प्रश्न: यदि a + b + c = 9 और ab + bc + ca = 26 हो, तो a³ + b³ + c³ − 3abc ज्ञात कीजिए।
हल: a² + b² + c² = (a + b + c)² − 2(ab + bc + ca) = 81 − 52 = 29
a³ + b³ + c³ − 3abc = 9 × (29 − 26) = 9 × 3 = 27।

सबसे बारंबार पूछा जाने वाला प्रश्न:
यदि a + b + c = 0, तो (a + b)³ + (b + c)³ + (c + a)³ = ?
चूँकि a + b = −c, b + c = −a, c + a = −b,
अतः (a + b)³ + (b + c)³ + (c + a)³ = (−c)³ + (−a)³ + (−b)³ = −(a³ + b³ + c³) = −3abc।
यह तथ्य SSC में अक्सर 'कठिन' रूप में आता है, लेकिन बुनियादी सर्वसमिकाओं को समझने पर इसे तुरंत सुलझाया जा सकता है।

एक और महत्वपूर्ण सर्वसमिका:
यदि abc = 1, तो
(1 + a + 1/a)(1 + b + 1/b)(1 + c + 1/c) = ?
यह जटिल लगता है, लेकिन abc = 1 रखकर और सरलीकरण करके मान ज्ञात किया जा सकता है। SSC में ऐसी समस्याएँ दुर्लभ होती हैं, लेकिन यदि पूछी जाएं तो प्रतिस्थापन विधि सहायक होती है।

बहुपद के मूल और उनसे संबंधित समीकरण निर्माण

यदि किसी द्विघात समीकरण ax² + bx + c = 0 के मूल α और β हों, तो मूलों के योग और गुणनफल का उपयोग करके समीकरण पुनः निर्मित किया जा सकता है।

नया समीकरण बनाना:
यदि नए मूल α + β और αβ दिए हों, तो समीकरण
x² − (योग)x + (गुणनफल) = 0

SSC प्रश्न पैटर्न:
प्रश्न: यदि समीकरण x² − 5x + 6 = 0 के मूल α और β हैं, तो (α + 1)(β + 1) का मान ज्ञात कीजिए।
हल: α + β = 5, αβ = 6
(α + 1)(β + 1) = αβ + α + β + 1 = 6 + 5 + 1 = 12。

प्रश्न: यदि x² − 7x + 12 = 0 के मूल α, β हैं, तो α² + β² ज्ञात कीजिए।
हल: α + β = 7, αβ = 12
α² + β² = (α + β)² − 2αβ = 49 − 24 = 25。

अतिरिक्त उन्नत:
α³ + β³ = (α + β)³ − 3αβ(α + β)
α⁴ + β⁴ = (α² + β²)² − 2α²β²

ये सूत्र SSC में बार-बार पूछे जाते हैं और इन्हें द्विघात समीकरण के मूलों से संबंधित प्रश्नों में तेज़ी से हल करने के लिए अपनाना चाहिए।

समीकरणों में भिन्नात्मक बीजीय व्यंजक और असीम गुणोत्तर श्रेणी (अधिक उपयोगी)

SSC में कभी-कभी भिन्नात्मक बीजीय व्यंजक वाले प्रश्न पूछे जाते हैं, विशेषकर जब x + 1/x संबंधित व्यंजक भिन्न रूप में दिए हों।

मुख्य रूप:
यदि x² + 1/x² = k, तो x + 1/x और x − 1/x निकालने के लिए:
(x + 1/x)² = k + 2
(x − 1/x)² = k − 2

उदाहरण: यदि x² + 1/x² = 14 हो, तो x + 1/x ज्ञात कीजिए।
हल: (x + 1/x)² = 14 + 2 = 16 → x + 1/x = ±4।

भिन्न हल में एक और प्रकार:
यदि x + 1/y = 1, y + 1/z = 1, z + 1/x = 1 हो, तो xyz का मान ज्ञात कीजिए।
हल: प्रतिस्थापन विधि से x = y = z = φ (स्वर्णिम अनुपात) जैसी स्थिति बनेगी; SSC में ऐसे प्रश्न दुर्लभ हैं परंतु यदि आएँ तो सममिति (symmetry) और प्रतिस्थापन की सहायता लें।

ध्यान दें: ये प्रश्न अत्यंत दुर्लभ हैं; मुख्य ध्यान सर्वसमिकाएँ, प्रतिस्थापन, शेषफल/अवयव प्रमेय और द्विघात मूलों के अनुप्रयोग पर रखें, जो निश्चित रूप से आते हैं।

SSC में बारंबार पूछे जाने वाले प्रश्न प्रकार — सारांश

SSC में बीजगणित के प्रश्न मुख्यतः निम्नलिखित प्रकारों में आते हैं:

1. सर्वसमिका सीधी अनुप्रयोग:
(a + b)², (a − b)², a³ + b³, a³ − b³, a³ + b³ + c³ − 3abc आदि का प्रत्यक्ष उपयोग।

2. x + 1/x या x − 1/x आधारित:
x + 1/x = k दिया हो, xⁿ + 1/xⁿ ज्ञात करना।

3. प्रतिस्थापन विधि:
विकल्पों में से मान रखकर उत्तर निकालना।

4. शेषफल और अवयव प्रमेय:
बहुपद को (x − a) से भाग देने पर शेषफल या अवयव ज्ञात करना।

5. द्विघात समीकरण के मूल:
मूलों के योग-गुणनफल, मूलों से संबंधित व्यंजकों का मान निकालना।

6. रैखिक समीकरण युग्म:
क्रेसन विधि से x व y का मान ज्ञात करना।

7. गुणनखंडन:
व्यंजक को गुणनखंडित कर सरल रूप में लিখना。

प्रत्येक प्रकार के कम से कम 2-3 उदाहरण हल किए जा चुके हैं। SSC में समय प्रबंधन के लिए प्रतिस्थापन विधि को प्राथमिकता दें जब विकल्प उपलब्ध हों, अन्यथा सर्वसमिका अनुप्रयोग से हल करें।

Important facts

  • SSC CGL/CHSL में बीजगणित से औसतन 5-8 प्रश्न पूछे जाते हैं जो सर्वसमिकाओं, व्युत्क्रम संबंधों, गुणनखंडन एवं द्विघात/रैखिक समीकरणों पर आधारित होते हैं।
  • यदि a + b + c = 0, तो a³ + b³ + c³ = 3abc यह सर्वसमिका SSC में सबसे अधिक बार पूछी जाती है।
  • x + 1/x = k के लिए: x² + 1/x² = k² − 2; x³ + 1/x³ = k³ − 3k; x⁴ + 1/x⁴ = (x² + 1/x²)² − 2 यह चरणबद्ध सूत्र अभिन्न है।
  • शेषफल प्रमेय: p(x) को (x − a) से भाग देने पर शेषफल p(a) होता है; यदि p(a) = 0, तो (x − a) अवयव है।
  • द्विघात समीकरण ax² + bx + c = 0 के मूल α, β के लिए: α + β = −b/a, αβ = c/a।
  • a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca); यदि a + b + c = 0 तो यह व्यंजक शून्य होता है और a³ + b³ + c³ = 3abc बचता है।
  • प्रतिस्थापन विधि (Substitution Method) SSC में समय बचाने के लिए सर्वोत्तम है, परंतु केवल तभी लागू होती है जब प्रश्न की शर्त संतुष्ट हो।
  • क्रेष्ण विधि (Cross-multiplication) दो रैखिक समीकरणों के हल के लिए सीधा सूत्र देती है: x/(b₁c₂−b₂c₁) = y/(c₁a₂−c₂a₁) = 1/(a₁b₂−a₂b₁)।

Formulas and relationships

(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
a² − b² = (a + b)(a − b)
(a + b)³ = a³ + b³ + 3ab(a + b)
(a − b)³ = a³ − b³ − 3ab(a − b)
a³ + b³ = (a + b)(a² − ab + b²)
a³ − b³ = (a − b)(a² + ab + b²)
(a + b + c)² = a² + b² + c² + 2(ab + bc + ca)
a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)
यदि a + b + c = 0, तो a³ + b³ + c³ = 3abc
x + 1/x = k ⇒ x² + 1/x² = k² − 2
x + 1/x = k ⇒ x³ + 1/x³ = k³ − 3k
x − 1/x = k ⇒ x² + 1/x² = k² + 2
x − 1/x = k ⇒ x³ − 1/x³ = k³ + 3k
द्विघात मूल: x = (−b ± √(b² − 4ac)) / 2a
मूलों का योग: α + β = −b/a
मूलों का गुणनफल: αβ = c/a
विविक्तकर: D = b² − 4ac
शेषफल प्रमेय: p(x) ÷ (x − a) का शेषफल = p(a)
अवयव प्रमेय: यदि p(a) = 0, तो (x − a) प(x) का अवयव है
x² + 1/x² = k ⇒ (x + 1/x)² = k + 2, (x − 1/x)² = k − 2

Common mistakes

  • x + 1/x = k से x² + 1/x² निकालते समय कभी-कभी छात्र k² + 2 लिख देते हैं जबकि सही सूत्र k² − 2 है। यह गलती अक्सर तब होती है जब चिन्ह भ्रमित हो।
  • a³ + b³ + c³ − 3abc के लिए a + b + c = 0 मानते समय छात्र 3abc को याद रखना भूल जाते हैं और सीधे शून्य मान लेते हैं; वास्तव में a³ + b³ + c³ = 3abc होता है, शून्य नहीं।
  • द्विघात समीकरण में m का मान ज्ञात करते समय विविक्तकर D = 0 रखना आवश्यक है, परंतु कुछ छात्र D > 0 रखकर संतुलित समीकरण बना देते हैं जिससे दो अलग-अलग मान प्राप्त हो जाते हैं जबकि प्रश्न समान मूल माँग रहा होता है।
  • प्रतिस्थापन विधि में गलत मान रख देना जैसे a + b + c = 0 हो तो a = 1, b = −1, c = 0 रखना उचित है, परंतु कई बार छात्र a = 0, b = 0, c = 0 रखकर उत्तर शून्य बना देते हैं जबकि सामान्य सूत्र से 3abc ≠ 0 हो सकता है; इससे चूक होती है।
  • शेषफल प्रमेय में p(a) की गणना करते समय धनात्मक-ऋणात्मक चिन्ह की गलती करना, विशेषकर जब x = −a हो।
  • x³ + 1/x³ = k³ − 3k सूत्र को x³ − 1/x³ के लिए ghalat लगू करना। वास्तव में x³ − 1/x³ = k³ + 3k होता है जब x − 1/x = k हो।
  • गुणनखंडन में द्विघात त्रिपद x² + (a+b)x + ab के गुणनखंडन के दौरान a और b का चिन्ह भूल जाना, जिससे (x − a)(x − b) को (x + a)(x + b) लिख दिया जाता है।
  • रैखिक समीकरण युग्म में cross-multiplication के हर में a₁b₂ − a₂b₁ लिखते समय चिन्ह की गलती करना, जिससे x व y के मान उल्टे आ जाते हैं।
