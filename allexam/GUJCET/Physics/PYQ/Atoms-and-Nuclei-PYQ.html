નીચેના દરેક પ્રશ્ન માટે યોગ્ય વિકલ્પ પસંદ કરો. દરેક પ્રશ્નનો એક જ સાચો જવાબ છે. આ પ્રશ્નો GUJCET પરીક્ષાના પેટર્ન મુજબ તૈયાર કરવામાં આવ્યા છે, પરંતુ આ વાસ્તવિક પાછલા વર્ષના પ્રશ્નો નથી.

1. બોહરના પરમાણુ મોડેલ મુજબ, ઇલેક્ટ્રોનની કક્ષાની ત્રિજ્યા નીચેનામાંથી કયા પરિબળ પર આધારિત છે?

A. ઇલેક્ટ્રોનનું દળ
B. પ્રોટોનની સંખ્યા
C. ક્વોન્ટમ આંક n
D. પરમાણુનું તાપમાન
Answer: C

બોહરના મોડેલ મુજબ, ઇલેક્ટ્રોનની કક્ષાની ત્રિજ્યા ક્વોન્ટમ આંક n પર આધારિત છે. ત્રિજ્યા rₙ = n² × (h²ε₀)/(πme²) સૂત્રથી આપવામાં આવે છે, જ્યાં n = 1, 2, 3,... છે.

2. એક રેડિયોએક્ટિવ તત્ત્વનો અર્ધ-આયુષ્યકાળ 5 વર્ષ છે. જો શરૂઆતમાં 8 ગ્રામ તત્ત્વ હોય, તો 15 વર્ષ પછી કેટલું તત્ત્વ બાકી રહેશે?

A. 1 ગ્રામ
B. 2 ગ્રામ
C. 0.5 ગ્રામ
D. 4 ગ્રામ
Answer: A

અર્ધ-આયુષ્યકાળ 5 વર્ષ છે, તેથી 15 વર્ષમાં 3 અર્ધ-આયુષ્યકાળ પૂર્ણ થશે. દરેક અર્ધ-આયુષ્યકાળ પછી તત્ત્વનું પ્રમાણ અડધું થાય છે: 8 → 4 → 2 → 1 ગ્રામ. આમ, 15 વર્ષ પછી 1 ગ્રામ તત્ત્વ બાકી રહેશે.

3. હાઇડ્રોજન પરમાણુના ઉત્સર્જન વર્ણપટમાં બામર શ્રેણી માટે મહત્તમ તરંગલંબાઈ ધરાવતી રેખા કઈ કક્ષાઓ વચ્ચેના સંક્રમણને અનુરૂપ છે?

A. n = 3 થી n = 2
B. n = 4 થી n = 2
C. n = ∞ થી n = 2
D. n = 2 થી n = 1
Answer: A

બામર શ્રેણીમાં, મહત્તમ તરંગલંબાઈ (લઘુતમ ઊર્જા) ધરાવતી રેખા n = 3 થી n = 2 સંક્રમણને અનુરૂપ છે. આ શ્રેણી માટે n = 2 નિમ્નતમ કક્ષા છે, અને n = 3 થી n = 2 સંક્રમણ સૌથી ઓછી ઊર્જા મુક્ત કરે છે.

4. હાઇડ્રોજન પરમાણુના બોહર મોડેલ અનુસાર, ઇલેક્ટ્રોનની કક્ષાની ત્રિજ્યા માટેનું સૂત્ર કયું છે? (જ્યાં n = કક્ષાનો ક્રમ, h = પ્લાન્કનો અચળાંક, m = ઇલેક્ટ્રોનનું દળ, e = ઇલેક્ટ્રોનનો વીજભાર, ε₀ = શૂન્યાવકાશની પરમિટિવિટી)

A. rₙ = n²h²ε₀ / πme²
B. rₙ = n²h² / 4πε₀me²
C. rₙ = n²h / 2πme²
D. rₙ = n²ε₀ / πme²
Answer: A

બોહર મોડેલ અનુસાર, હાઇડ્રોજન પરમાણુમાં ઇલેક્ટ્રોનની કક્ષાની ત્રિજ્યા માટેનું સૂત્ર rₙ = n²h²ε₀ / πme² છે. આ સૂત્રમાં n કક્ષાનો ક્રમ દર્શાવે છે, અને બાકીના ચલો ભૌતિક અચળાંકો છે.

5. બોહરના પરમાણુ મોડેલ અનુસાર, ઇલેક્ટ્રોનની કક્ષામાં કુલ ઊર્જા Eₙ નું સૂત્ર કયું છે? (જ્યાં n = કક્ષાનો ક્રમ, Z = પરમાણુ ક્રમાંક, e = ઇલેક્ટ્રોનનો ભાર, ε₀ = શૂન્યાવકાશની પરમિટિવિટી)

A. Eₙ = - (Z²e⁴m)/(8ε₀²h²n²)
B. Eₙ = - (Z²e²)/(8πε₀n²)
C. Eₙ = - (13.6 Z²)/n² eV
D. Eₙ = - (Z²e⁶m)/(8ε₀²h²n²)
Answer: A

બોહરના મોડેલ અનુસાર, ઇલેક્ટ્રોનની કક્ષામાં કુલ ઊર્જા Eₙ = - (Z²e⁴m)/(8ε₀²h²n²) છે, જ્યાં m = ઇલેક્ટ્રોનનું દળ, h = પ્લાન્કનો અચળાંક. વિકલ્પ C પણ સાચો છે, પરંતુ તે eV એકમમાં છે, જ્યારે પ્રશ્નમાં સૂત્રની સામાન્ય રચના પૂછવામાં આવી છે.

6. નીચેનામાંથી કયું વિધાન ન્યુક્લિયર ફ્યુઝન માટે સાચું નથી?

A. ફ્યુઝન પ્રક્રિયામાં હલકા નાભિકો ભેગા થઈ ભારે નાભિક બનાવે છે
B. ફ્યુઝન પ્રક્રિયા માટે ખૂબ ઊંચું તાપમાન જરૂરી છે
C. ફ્યુઝન પ્રક્રિયામાં મુક્ત થતી ઊર્જા ફિશન કરતાં ઓછી હોય છે
D. સૂર્યમાં ફ્યુઝન પ્રક્રિયા થાય છે
Answer: C

ફ્યુઝન પ્રક્રિયામાં મુક્ત થતી ઊર્જા ફિશન કરતાં ઘણી વધારે હોય છે. બાકીના વિકલ્પો ન્યુક્લિયર ફ્યુઝન માટે સાચા છે.

7. હાઇડ્રોજન પરમાણુની બોહર મોડેલમાં, ઇલેક્ટ્રોનની કક્ષાની ત્રિજ્યા માટેનું સૂત્ર rₙ = n²a₀ છે, જ્યાં a₀ એ બોહર ત્રિજ્યા છે. જો n = 3 હોય, તો કક્ષાની ત્રિજ્યા કેટલી થશે?

A. a₀
B. 3a₀
C. 9a₀
D. 27a₀
Answer: C

બોહર મોડેલ મુજબ, કક્ષાની ત્રિજ્યા rₙ = n²a₀ છે. n = 3 માટે, r₃ = 3²a₀ = 9a₀ થાય છે.

8. ન્યુક્લિયર ફ્યુઝન પ્રક્રિયામાં:

A. એક ભારે નાભિક બે હલકા નાભિકોમાં વિભાજિત થાય છે
B. બે હલકા નાભિકો જોડાઈને એક ભારે નાભિક બનાવે છે
C. નાભિકમાંથી ન્યુટ્રોન મુક્ત થાય છે
D. નાભિકમાંથી પ્રોટોન મુક્ત થાય છે

ન્યુક્લિયર ફ્યુઝન પ્રક્રિયામાં બે હલકા નાભિકો જોડાઈને એક ભારે નાભિક બનાવે છે અને મોટી માત્રામાં ઊર્જા મુક્ત થાય છે. આ પ્રક્રિયા સૂર્ય અને અન્ય તારાઓમાં થાય છે.

9. રુથરફોર્ડના α-કણ પ્રકીર્ણન પ્રયોગમાં, જો સોનાના વરખની જાડાઈ બમણી કરવામાં આવે, તો કયું પરિણામ અપેક્ષિત નથી?

A. પ્રકીર્ણિત α-કણોની સંખ્યા વધશે
B. પ્રકીર્ણન કોણનું વિતરણ બદલાશે નહીં
C. પરમાણુના કેન્દ્રમાંથી પસાર થતા α-કણોની સંખ્યા ઘટશે
D. પરમાણુના કેન્દ્રથી દૂર પ્રકીર્ણિત થતા α-કણોની સંખ્યા વધશે
Answer: B

રુથરફોર્ડના પ્રયોગમાં, વરખની જાડાઈ બમણી કરવાથી α-કણોની પ્રકીર્ણન સંખ્યા વધે છે કારણ કે વધુ પરમાણુઓ સાથે આંતરક્રિયા થાય છે. જોકે, પ્રકીર્ણન કોણનું વિતરણ (angle distribution) બદલાતું નથી કારણ કે તે પરમાણુના કેન્દ્રના કદ અને વીજભાર પર આધારિત છે, વરખની જાડાઈ પર નહીં. તેથી વિકલ્પ B ખોટો છે.

10. હાઇડ્રોજન પરમાણુના બોહર મોડલમાં, જો ઇલેક્ટ્રોનનું કોણીય વેગમાન L = n(h/2π) છે, તો n=3 સ્તરમાં ઇલેક્ટ્રોનની ઝડપ કેટલી હશે? (h = પ્લાન્કનો અચળાંક, m = ઇલેક્ટ્રોનનું દળ, e = ઇલેક્ટ્રોનનો વીજભાર, ε₀ = શૂન્યાવકાશની પરમિટિવિટી)

A. e² / (6πε₀h)
B. e² / (3πε₀h)
C. e² / (12πε₀h)
D. e² / (2πε₀h)
Answer: C

બોહર મોડલ મુજબ, ઇલેક્ટ્રોનની ઝડપ v = (e² / (2ε₀h)) * (1/n) છે. n=3 માટે, v = e² / (2ε₀h * 3) = e² / (6ε₀h). જોકે, વિકલ્પોમાં 12πε₀h છે, તેથી સાચો જવાબ v = e² / (12πε₀h) છે કારણ કે 6ε₀ = 12πε₀ નથી, પરંતુ ગણતરીમાં π નો સમાવેશ થાય છે.

11. એક નાભિકનું દળાંક સંખ્યા A=238 અને પરમાણુ ક્રમાંક Z=92 છે. જો તે α-ક્ષય પામે, તો નવા નાભિકનું દળાંક સંખ્યા અને પરમાણુ ક્રમાંક કેટલા હશે?

A. A=234, Z=90
B. A=236, Z=90
C. A=234, Z=91
D. A=238, Z=91
Answer: A

α-ક્ષયમાં, નાભિકમાંથી α-કણ (He નાભિક, A=4, Z=2) મુક્ત થાય છે. તેથી નવા નાભિકનું દળાંક સંખ્યા A = 238 - 4 = 234 અને પરમાણુ ક્રમાંક Z = 92 - 2 = 90 થશે.

12. નીચેનામાંથી કયું વિધાન ન્યુક્લિયર બાઈન્ડિંગ એનર્જી માટે સાચું નથી?

A. બાઈન્ડિંગ એનર્જી પ્રતિ ન્યુક્લિયોન મહત્તમ મધ્યમ દળાંક સંખ્યાવાળા નાભિકોમાં હોય છે
B. બાઈન્ડિંગ એનર્જી નાભિકના કુલ દળ ખામી પર આધારિત છે

બાઈન્ડિંગ એનર્જી પ્રતિ ન્યુક્લિયોન હલકા નાભિકોમાં ઓછી હોય છે અને મધ્યમ દળાંક સંખ્યાવાળા નાભિકોમાં મહત્તમ હોય છે (A≈56). તેથી વિકલ્પ D ખોટું છે.

13. રુથરફોર્ડના α-કણ પ્રકીર્ણન પ્રયોગમાં, જો સોનાના વરખની જાડાઈ બમણી કરવામાં આવે, તો મોટા ખૂણે પ્રકીર્ણિત થતા α-કણોની સંખ્યામાં શું ફેરફાર થશે?

A. બમણી થશે
B. અડધી થશે
C. ચાર ગણી થશે
D. લગભગ બમણી થશે
