આદર્શ વાયુ સમીકરણ

📖 આદર્શ વાયુ સમીકરણ

આદર્શ વાયુની વ્યાખ્યા

આદર્શ વાયુ એવો વાયુ છે જેના કણો વચ્ચે કોઈ આંતરઅણુ બળ નથી અને જેના કણોનો કદ શૂન્ય ગણવામાં આવે છે. આ વાયુ બોયલ, ચાર્લ્સ અને ગેઈ-લ્યુસાકના નિયમોનું પાલન કરે છે.

  • આદર્શ વાયુમાં કણો વચ્ચે કોઈ આકર્ષણ અથવા અપાકર્ષણ બળ નથી.
  • કણોનો કદ વાયુના કુલ કદની સરખામણીએ નગણ્ય છે.
  • આદર્શ વાયુ સંપૂર્ણપણે પુનરાવર્તિત (reversible) પ્રક્રિયાઓ માટે વપરાય છે.
  • વાસ્તવિક વાયુઓ ઉચ્ચ તાપમાન અને નીચા દબાણે આદર્શ વાયુ જેવું વર્તન દર્શાવે છે.

વાયુ નિયમો

બોયલનો નિયમ (PV = કોણસ્થ), ચાર્લ્સનો નિયમ (V ∝ T), અને ગેઈ-લ્યુસાકનો નિયમ (P ∝ T) એ આદર્શ વાયુના મૂળભૂત નિયમો છે. આ ત્રણેય નિયમોને એકસાથે આદર્શ વાયુ સમીકરણમાં સંકલિત કરવામાં આવ્યા છે.

  • બોયલનો નિયમ: દબાણ અને કદ વચ્ચે વ્યસ્ત પ્રમાણ (P₁V₁ = P₂V₂).
  • ચાર્લ્સનો નિયમ: કદ અને તાપમાન વચ્ચે સીધું પ્રમાણ (V₁/T₁ = V₂/T₂).
  • ગેઈ-લ્યુસાકનો નિયમ: દબાણ અને તાપમાન વચ્ચે સીધું પ્રમાણ (P₁/T₁ = P₂/T₂).
  • આ નિયમો માત્ર સ્થિર દળ માટે લાગુ પડે છે.
🧠 Trick: BCG: Boyles (P↓V↑), Charles (T↑V↑), Gay-Lussac (T↑P↑)

આદર્શ વાયુ સમીકરણ

આદર્શ વાયુ સમીકરણ PV = nRT છે, જ્યાં P = દબાણ, V = કદ, n = મોલની સંખ્યા, R = વાયુ અચળાંક (8.314 J/mol·K), અને T = નિરપેક્ષ તાપમાન (K).

  • PV = nRT એ આદર્શ વાયુનું સાર્વત્રિક સમીકરણ છે.
  • Rનો મૂલ્ય 8.314 J/mol·K અથવા 0.0821 L·atm/mol·K હોય છે.
  • તાપમાન હંમેશા કેલ્વિન (K)માં લેવું જોઈએ (K = °C + 273).
  • n = દળ / મોલર દળ (m/M) વડે મોલની સંખ્યા શોધી શકાય છે.
🧠 Trick: PV = nRT → 'Puri Vaat nahi Rati Toh' (પૂરી વાત નહીં રાત તો)

વાયુ અચળાંક (R)

R એ સાર્વત્રિક વાયુ અચળાંક છે જે આદર્શ વાયુ સમીકરણમાં ઉપયોગી થાય છે. તેની કિંમત એકમો પર આધાર રાખે છે, જેમ કે J/mol·K, L·atm/mol·K, અથવા cal/mol·K.

  • R = 8.314 J/mol·K (SI એકમ)
  • R = 0.0821 L·atm/mol·K (વાયુ સમીકરણ માટે વપરાય)
  • R = 1.987 cal/mol·K (ઊર્જા એકમમાં)
  • R = k × N_A જ્યાં k = બોલ્ટ્ઝમેન અચળાંક અને N_A = એવોગેડ્રોની સંખ્યા.

ડાલ્ટનનો આંશિક દબાણનો નિયમ

મિશ્રણમાં કોઈ એક વાયુનું આંશિક દબાણ એટલે તે વાયુ દ્વારા એકલા કબજે કરેલા કદ અને તે જ તાપમાને તે જ કદ માટે લાગુ પડતું દબાણ. આદર્શ વાયુઓ માટે, કુલ દબાણ = આંશિક દબાણોનો સરવસું.

  • P_total = P₁ + P₂ + P₃ + ... (આદર્શ વાયુ મિશ્રણ માટે)
  • આંશિક દબાણ = (મોલ પ્રમાણ) × કુલ દબાણ.
  • ડાલ્ટનનો નિયમ માત્ર આદર્શ વાયુઓ માટે લાગુ પડે છે.
  • વાસ્તવિક વાયુઓમાં આ નિયમ નિર્દોષ રીતે લાગુ પડતો નથી.

આદર્શ વાયુ સમીકરણના ઉપયોગો

આદર્શ વાયુ સમીકરણનો ઉપયોગ વાયુના દબાણ, કદ, તાપમાન અથવા મોલની સંખ્યા શોધવા માટે થાય છે. તે રાસાયણિક પ્રક્રિયાઓ, વાયુ મિશ્રણો અને થર્મોડાયનેમિક્સમાં મહત્વપૂર્ણ છે.

  • વાયુના અજ્ઞાત પરિમાણ (P, V, T, n) શોધવા માટે વપરાય છે.
  • રાસાયણિક પ્રક્રિયાઓમાં વાયુના ઉત્પાદનો અને પ્રતિક્રિયાકારકોના ગુણધર્મો નક્કી કરવા માટે.
  • થર્મોડાયનેમિક્સમાં એન્ટ્રોપી, એન્થાલ્પી વગેરે ગણતરીઓ માટે.
  • વાયુ મિશ્રણોના ગુણધર્મોનું વિશ્લેષણ કરવા માટે.

વાસ્તવિક વાયુ vs આદર્શ વાયુ

વાસ્તવિક વાયુઓમાં કણો વચ્ચે આંતરઅણુ બળ હાજર હોય છે અને કણોનો કદ શૂન્ય નથી. ઉચ્ચ દબાણ અને નીચા તાપમાને વાસ્તવિક વાયુઓ આદર્શ વાયુથી વિચલન દર્શાવે છે.

  • વાસ્તવિક વાયુઓમાં કણો વચ્ચે આકર્ષણ/અપાકર્ષણ બળ હોય છે.
  • વાસ્તવિક વાયુઓનો કદ શૂન્ય નથી.
  • વેન ડર વાલ્સ સમીકરણ (P + an²/V²)(V - nb) = nRT વાસ્તવિક વાયુઓ માટે વપરાય છે.
  • આદર્શ વાયુ સિદ્ધાંત ઉચ્ચ T અને નીચા P પર વાસ્તવિક વાયુઓ માટે લાગુ પડે છે.

⚡ Quick Revision

  • આદર્શ વાયુ = કોઈ આંતરઅણુ બળ + કણોનો કદ શૂન્ય.
  • બોયલ: PV = કોણસ્થ, ચાર્લ્સ: V ∝ T, ગેઈ-લ્યુસાક: P ∝ T.
  • આદર્શ વાયુ સમીકરણ: PV = nRT (R = 8.314 J/mol·K).
  • તાપમાન હંમેશા કેલ્વિન (K = °C + 273)માં લેવું.
  • ડાલ્ટનનો નિયમ: P_total = Σ P_આંશિક.
  • વાસ્તવિક વાયુઓમાં આદર્શ વાયુથી વિચલન ઉચ્ચ P અને નીચા T પર થાય છે.
  • વેન ડર વાલ્સ સમીકરણ વાસ્તવિક વાયુઓ માટે વપરાય છે.
  • n = દળ / મોલર દળ (m/M).
  • Rનો મૂલ્ય એકમો પર આધાર રાખે છે (J/mol·K, L·atm/mol·K).
  • આદર્શ વાયુ મિશ્રણમાં કુલ દબાણ = આંશિક દબાણોનો સરવસું.
🎯 Exam Tip: પરીક્ષામાં PV = nRT સમીકરણમાં એકમોની સુસંગતતા તપાસો: P (atm), V (L), n (mol), R (0.0821 L·atm/mol·K), T (K). એકમો મેળ ખાતા ન હોય તો Rનો યોગ્ય મૂલ્ય પસંદ કરો.
