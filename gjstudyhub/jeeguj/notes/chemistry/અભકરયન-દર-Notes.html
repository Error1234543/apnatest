અભિક્રિયાનો દર

📖 અભિક્રિયાનો દર

અભિક્રિયાનો દર: મૂળભૂત પરિભાષા

અભિક્રિયાનો દર એટલે એકમ સમયમાં અભિકારકોના સાંદ્રતામાં થતો ફેરફાર અથવા ઉત્પાદનોની રચના. તે મોલ/લીટર/સેકન્ડમાં વ્યક્ત કરવામાં આવે છે. દરની ગણતરી સાંદ્રતાના ફેરફારના પરિમાણથી થાય છે, જેમ કે Δ[R]/Δt અથવા Δ[P]/Δt.

  • દર = -Δ[R]/Δt = Δ[P]/Δt (R=અભિકારક, P=ઉત્પાદન)
  • એકમ: mol L⁻¹ s⁻¹ અથવા M s⁻¹
  • તીવ્રતાને આધારે અભિક્રિયા ઝડપી અથવા ધીમી હોય છે.
  • સંકલિત દર (Instantaneous rate) એ સમયના અત્યંત નાના અંતરાલનો દર હોય છે.

દર નક્કી કરતા પરિબળો

અભિક્રિયાનો દર સાંદ્રતા, તાપમાન, દબાણ (ગેસ માટે), ઉત્પ્રેરક, અભિકારકોની પ્રકૃતિ અને પૃથક્કરણની સપાટીના ક્ષેત્રફળ પર આધાર રાખે છે. સાંદ્રતા વધારવાથી અભિક્રિયાનો દર વધે છે, પરંતુ ઉત્પાદનની સાંદ્રતા વધવાથી દર ઘટે છે.

  • સાંદ્રતા ↑ → દર ↑ (પહેલા ક્રમની અભિક્રિયા માટે)
  • તાપમાન ↑ → દર ↑ (Arrhenius સમીકરણ મુજબ)
  • ઉત્પ્રેરક → દર ↑ (સક્રિયણ ઊર્જા ઘટાડે છે)
  • દબાણ ↑ (ગેસ) → દર ↑ (અણુઓની સંખ્યા વધે છે)
  • પૃથક્કરણ → દર ↑ (સપાટી ક્ષેત્રફળ વધે છે)
🧠 Trick: CATS: Concentration, Temperature, Catalyst, Surface area

દરનો ક્રમ અને અભિક્રિયા વેગ અચળાંક (k)

દરનો ક્રમ અભિકારકોની સાંદ્રતાના આધારે નક્કી થાય છે. શૂન્ય ક્રમ (k), પહેલા ક્રમ (k[A]), બીજા ક્રમ (k[A]²) અને ત્રીજા ક્રમ (k[A]³) હોય છે. અભિક્રિયા વેગ અચળાંક (k) તાપમાન પર આધાર રાખે છે અને Arrhenius સમીકરણ k = A e^(-Ea/RT) દ્વારા વ્યક્ત કરવામાં આવે છે.

  • શૂન્ય ક્રમ: દર = k (સાંદ્રતા પર આધાર નહીં)
  • પહેલા ક્રમ: દર = k[A] (半જીવન T₁/₂ = ln2/k)
  • બીજા ક્રમ: દર = k[A]² (T₁/₂ = 1/k[A]₀)
  • k નું એકમ ક્રમ પર આધાર રાખે (ઉદા. s⁻¹, L mol⁻¹ s⁻¹)
  • Arrhenius સમીકરણ: k ∝ e^(-Ea/RT)
🧠 Trick: શૂન્ય-સ્થિર, પહેલા-રેખીય, બીજા-વર્ગ

Arrhenius સમીકરણ અને સક્રિયણ ઊર્જા

Arrhenius સમીકરણ k = A e^(-Ea/RT) અભિક્રિયાની સક્રિયણ ઊર્જા (Ea) અને તાપમાન (T) સાથે સંબંધ સ્થાપે છે. Ea જેટલી ઓછી હોય, અભિક્રિયા એટલી ઝડપી થાય છે. A એ આણ્વિક અથડામણોનો આંકડાકીય પરિબળ (Frequency factor) હોય છે.

  • Ea = સક્રિયણ ઊર્જા (J mol⁻¹)
  • R = વાયુ અચળાંક (8.314 J mol⁻¹ K⁻¹)
  • T = તાપમાન (K)
  • ln(k₂/k₁) = (Ea/R)(1/T₁ - 1/T₂) (દર તાપમાન પર આધાર)
  • ઉત્પ્રેરક Ea ઘટાડીને દર વધારે છે.
🧠 Trick: Ea નીચે → દર ઉપર

અભિક્રિયા યાંત્રિકી (Mechanism) અને દર-નિયામક પગલો

બહુપગલીય અભિક્રિયામાં દર-નિયામક પગલો (Rate-determining step) સૌથી ધીમો પગલો હોય છે. અભિક્રિયાની કુલ દર આ પગલાના દર પર આધાર રાખે છે. ઉદા. SN1 અભિક્રિયામાં કાર્બોકેટાયનનું નિર્માણ દર-નિયામક પગલો હોય છે.

  • દર-નિયામક પગલો = સૌથી ધીમો પગલો
  • કુલ દર = દર-નિયામક પગલાનો દર
  • સંક્રમણ અવસ્થા (Transition state) ઊર્જા સૌથી ઊંચી હોય છે.
  • અભિક્રિયા યાંત્રિકી મુજબ પગલાઓનો ક્રમ નક્કી કરવામાં આવે છે.
🧠 Trick: ધીમો પગલો = બોસ પગલો

ઉત્પ્રેરક અને અભિક્રિયાનો દર

ઉત્પ્રેરક અભિક્રિયાનો દર વધારે છે પરંતુ સંતુલન સ્થિતિ બદલતો નથી. તે સક્રિયણ ઊર્જા ઘટાડીને નવા રસ્તા પૂરા પાડે છે. ઉત્પ્રેરકની સક્રિય સપાટી પર અભિકારકો અડીને સક્રિય સંકલન (Activated complex) બને છે.

  • ઉત્પ્રેરક → Ea ↓ → દર ↑
  • સંતુલન સ્થિતિ અચળ રહે છે.
  • ઉત્પ્રેરકની ક્રિયા વિશિષ્ટ હોય છે (ઉદા. એન્ઝાઇમ્સ)
  • ઉત્પ્રેરકની સાંદ્રતા ↑ → દર ↑ (પરંતુ મર્યાદિત)
  • ઉત્પ્રેરક વિષ (Catalyst poison) દર ઘટાડે છે.
🧠 Trick: ઉત્પ્રેરક = દરનો મિત્ર, સંતુલનનો શત્રુ નહીં

દરની ગણતરી અને પ્રાયોગિક પદ્ધતિઓ

દરની ગણતરી સાંદ્રતા, દબાણ, વોલ્યુમ અથવા વજનના ફેરફાર દ્વારા થાય છે. પ્રાયોગિક રીતે, ટાઈટ્રેશન, કલરિમીટ્રી, ગેસ ક્રોમેટોગ્રાફી અથવા વીજચુંબકીય પદ્ધતિઓ વાપરવામાં આવે છે.

  • ટાઈટ્રેશન: સમય સાથે અભિકારકની સાંદ્રતા માપવી
  • કલરિમીટ્રી: રંગના ફેરફાર દ્વારા દર માપવો
  • ગેસ ક્રોમેટોગ્રાફી: ગેસની સાંદ્રતા માપવી
  • વીજચુંબકીય પદ્ધતિઓ: સ્પેક્ટ્રોસ્કોપી દ્વારા દર માપવો
  • દર = Δn/Δt (n = મોલની સંખ્યા)
🧠 Trick: ટાઈટ્રેશન = ટાઈમ + ટેસ્ટ

  • દર-નિયામક પગલો = સૌથી ધીમો પગલો
  • સંતુલન સ્થિતિ ઉત્પ્રેરકથી બદલાતી નથી

🎯 Exam Tip: JEE Main માં અભિક્રિયાનો દર અને Arrhenius સમીકરણ પર પ્રશ્નો વારંવાર પૂછાય છે. ક્રમ અને અચળાંક (k) ના એકમો યાદ રાખો, અને દર-નિયામક પગલોની ઓળખ કરવા માટે અભિક્રિયા યાંત્રિકી સમજો.
