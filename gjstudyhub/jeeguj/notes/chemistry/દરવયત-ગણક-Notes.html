દ્રાવ્યતા ગુણાંક

📖 દ્રાવ્યતા ગુણાંક

પરિભાષા અને સૂત્ર

દ્રાવ્યતા ગુણાંક એટલે એક ગ્રામ દ્રાવ્ય પદાર્થને દ્રાવણમાં સંપૂર્ણપણે દ્રાવવા માટે જરૂરી દ્રાવકની ન્યૂનતમ જરૂરિયાત. સૂત્ર: મોલર દ્રાવ્યતા (S) = (દ્રાવ્યના મોલની સંખ્યા) / (દ્રાવણનો કદ લિટરમાં).

  • દ્રાવ્યતા ગુણાંકનો એકમ: mol L⁻¹ અથવા M (મોલરિટી)
  • તાપમાન અને દબાણ પર આધાર રાખે છે
  • દ્રાવ્ય અને દ્રાવકની પ્રકૃતિ પર નિર્ભર છે
  • ગેંસ માટે: કોઈ પણ તાપમાને દ્રાવ્યતા ગુણાંક અમર્યાદિત હોય છે

તાપમાનનો પ્રભાવ

ઘન અને પ્રવાહી દ્રાવ્યો માટે તાપમાન વધારે તો દ્રાવ્યતા વધે છે (ઊર્જા-શોષક પ્રક્રિયા). વાયુ માટે તાપમાન વધારે તો દ્રાવ્યતા ઘટે છે (લે ચેટેલિયરનું સિદ્ધાંત).

  • ઘન/પ્રવાહી: તાપમાન ↑ → દ્રાવ્યતા ↑
  • વાયુ: તાપમાન ↑ → દ્રાવ્યતા ↓
  • ઉત્કલન બિંદુ પાસે દ્રાવ્યતા સૌથી વધારે હોય છે
  • ΔH_dissolution > 0 → તાપમાન વધારે તો દ્રાવ્યતા વધે
🧠 Trick: ઘન-પ્રવાહી: 'ગરમ પાણીમાં મીઠું જલ્દી ઓગળે', વાયુ: 'ગરમ પાણીમાં ઓક્સિજન ઓછું ઓગળે'

દબાણનો પ્રભાવ (વાયુ માટે)

હેનરીનો નિયમ: વાયુની દ્રાવ્યતા (C) તેના આંશિક દબાણ (P) સાથે સીધો સમપ્રમાણમાં હોય છે, C = k_H * P. જ્યાં k_H = હેનરી અચળાંક.

  • હેનરીનો નિયમ: C ∝ P (નિશ્ચિત તાપમાને)
  • k_H નાનો = વાયુ વધારે દ્રાવ્ય (ઉદા. NH₃)
  • k_H મોટો = વાયુ ઓછો દ્રાવ્ય (ઉદા. O₂, N₂)
  • દબાણ ↑ → વાયુ દ્રાવ્યતા ↑ (લે ચેટેલિયર)
🧠 Trick: HENRY: High Pressure → High Solubility (for gases)

દ્રાવ્યતા ગુણાંક અને સંતૃપ્ત દ્રાવણ

સંતૃપ્ત દ્રાવણમાં દ્રાવ્યતા ગુણાંક મહત્તમ હોય છે. આ દ્રાવણમાં દ્રાવ્ય અને અદ્રાવ્ય સ્વરૂપ વચ્ચે સંતુલન સ્થાપિત થાય છે. દ્રાવ્યતા ગુણાંક = સંતૃપ્ત દ્રાવણની મોલર સાંદ્રતા.

  • સંતૃપ્ત દ્રાવણ = મહત્તમ દ્રાવ્યતા
  • સંતુલન: દ્રાવ્ય (s) ⇌ દ્રાવ્ય (aq)
  • દ્રાવ્યતા ગુણાંક = [દ્રાવ્ય] સંતૃપ્ત દ્રાવણમાં
  • અતિસંતૃપ્ત દ્રાવણ અસ્થિર હોય છે

દ્રાવ્યતા ગુણાંક પર દ્રાવકનો પ્રભાવ

પોલર દ્રાવ્ય પોલર દ્રાવકમાં (ઉદા. NaClમાં પાણી) અને અપોલર દ્રાવ્ય અપોલર દ્રાવકમાં (ઉદા. આયોડિનમાં CCl₄) સારી રીતે દ્રાવે છે. 'સમરૂપ દ્રાવે સમરૂપને' નો નિયમ લાગુ પડે છે.

  • પોલર-પોલર: ઉચ્ચ દ્રાવ્યતા (ઉદા. ક્લોરાઇડ લવણ પાણીમાં)
  • અપોલર-અપોલર: ઉચ્ચ દ્રાવ્યતા (ઉદા. બેન્ઝીનમાં નેફ્થલીન)
  • પોલર-અપોલર: નીચી દ્રાવ્યતા (ઉદા. ઓઇલ પાણીમાં)
  • હાઇડ્રોજન બંધો દ્રાવ્યતામાં મહત્વની ભૂમિકા ભજવે છે
🧠 Trick: પોલર પાણી પોલર મીઠું ઓગળે, અપોલર ઓઇલ અપોલર બેન્ઝીન ઓગળે

દ્રાવ્યતા ગુણાંક અને સ્ફટિકીકરણ

દ્રાવ્યતા ગુણાંકનો ઉપયોગ સ્ફટિકીકરણ પ્રક્રિયામાં થાય છે. જ્યારે દ્રાવણને ગરમ કરીને સંતૃપ્ત બનાવીને ઠંડુ પાડવામાં આવે ત્યારે દ્રાવ્ય પદાર્થ સ્ફટિક સ્વરૂપે અલગ પડે છે.

  • સ્ફટિકીકરણ = દ્રાવ્યતા ગુણાંકમાં ફેરફાર દ્વારા શુદ્ધિકરણ
  • તાપમાન ઘટાડો → દ્રાવ્યતા ↓ → સ્ફટિકો બને
  • શુદ્ધ પદાર્થોના સ્ફટિકો મળે છે
  • ઔદ્યોગિક રીતે મીઠું, શેકર અને દવાઓ બનાવવા ઉપયોગી

દ્રાવ્યતા ગુણાંક અને વાન્ટ હોફ અચળાંક

વાન્ટ હોફ અચળાંક (i) દ્રાવ્યના આયનીકરણ પર આધાર રાખે છે. દ્રાવ્યતા ગુણાંક પર i નો પ્રભાવ: S = i * (દ્રાવ્યના મોલ) / (દ્રાવણનો કદ). ઉદા. NaCl માટે i ≈ 2.

  • i = 1 (અવિભાજ્ય દ્રાવ્ય, ઉદા. ગ્લુકોઝ)
  • i = 2 (NaCl, CaCl₂ માટે i ≈ 3)
  • દ્રાવ્યતા ગુણાંક = i * મોલર દ્રાવ્યતા
  • આયની દ્રાવ્યો માટે દ્રાવ્યતા ગુણાંક વધારે હોય છે
🧠 Trick: NaCl → 2 આયન → i=2 → દ્રાવ્યતા બમણી

⚡ Quick Revision

  • દ્રાવ્યતા ગુણાંક = મોલર સાંદ્રતા (mol L⁻¹)
  • ઘન/પ્રવાહી: તાપમાન ↑ → દ્રાવ્યતા ↑
  • વાયુ: તાપમાન ↑ → દ્રાવ્યતા ↓, દબાણ ↑ → દ્રાવ્યતા ↑ (હેનરીનો નિયમ)
  • પોલર દ્રાવ્ય પોલર દ્રાવકમાં ઓગળે ('સમરૂપ દ્રાવે સમરૂપને')
  • સંતૃપ્ત દ્રાવણ = મહત્તમ દ્રાવ્યતા ગુણાંક
  • વાન્ટ હોફ અચળાંક (i) આયનીકરણ પર આધાર રાખે છે
  • સ્ફટિકીકરણમાં દ્રાવ્યતા ગુણાંકનો ઉપયોગ થાય છે
  • હાઇડ્રોજન બંધો દ્રાવ્યતામાં મહત્વની ભૂમિકા ભજવે છે
🎯 Exam Tip: JEE Main માં દ્રાવ્યતા ગુણાંકના પ્રશ્નો માટે હેનરીનો નિયમ, તાપમાન અને દબાણનો પ્રભાવ, અને વાન્ટ હોફ અચળાંક પર ધ્યાન કેન્દ્રિત કરો. ગણિતીય પ્રશ્નો માટે સૂત્રો યાદ રાખો: S = k_H * P (વાયુ), S = i * (મોલ/લિટર) (આયની દ્રાવ્ય).
