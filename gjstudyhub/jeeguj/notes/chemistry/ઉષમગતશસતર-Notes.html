ઉષ્માગતિશાસ્ત્ર

📖 ઉષ્માગતિશાસ્ત્ર (Thermodynamics)

ઉષ્માગતિશાસ્ત્રની મૂળભૂત સંકલ્પના

ઉષ્માગતિશાસ્ત્ર એ ઉર્જાના સ્વરૂપો, તેના રૂપાંતરણ અને ઉર્જાના વહનનો અભ્યાસ કરે છે. તે મુખ્યત્વે ઉષ્મા, કામ અને આંતરિક ઉર્જા વચ્ચેના સંબંધો પર ધ્યાન કેન્દ્રિત કરે છે. NEET/JEE માટે થર્મોડાયનેમિક્સના ચાર નિયમો મહત્વપૂર્ણ છે.

  • ઉર્જા સંરક્ષણનો નિયમ (પહેલો નિયમ): ΔU = Q - W
  • ઉત્ક્રાંતિનો નિયમ (બીજો નિયમ): એન્ટ્રોપી હંમેશા વધે છે
  • શૂન્યમા નિયમ: તાપમાન સંતુલનની વ્યાખ્યા
  • તૃતીય નિયમ: શૂન્ય કેલ્વિન પર એન્ટ્રોપી શૂન્ય હોય છે
🧠 Trick: પહેલો નિયમ: 'Q-W = U' (ક્યૂ મીનસ ડબલ્યુ એટલે યુ)

પદાર્થની અવસ્થા અને અવસ્થા ચલ

પદાર્થની અવસ્થા (સોલિડ, લિક્વિડ, ગેસ) તેના દબાણ, કદ અને તાપમાન પર આધારિત હોય છે. આદર્શ વાયુ સમીકરણ PV = nRT મહત્વપૂર્ણ છે. કામ કરવા માટે વાયુ દ્વારા અથવા વાયુ પર થતું કામ W = ∫P dV દ્વારા ગણવામાં આવે છે.

  • આદર્શ વાયુ સમીકરણ: PV = nRT
  • કામનું સૂત્ર: W = ∫P dV
  • અવસ્થા ચલ: દબાણ (P), કદ (V), તાપમાન (T)
  • આદર્શ વાયુ માટે આંતરિક ઉર્જા માત્ર તાપમાન પર આધારિત હોય છે
🧠 Trick: PV = nRT → 'પીવી એન આર ટી' (પદાર્થની અવસ્થા યાદ રાખવા)

પહેલો નિયમ અને તેની એપ્લિકેશન

પહેલો નિયમ ΔU = Q - W ઉર્જા સંરક્ષણ દર્શાવે છે. અહીં ΔU આંતરિક ઉર્જામાં ફેરફાર, Q ઉષ્મા વહન, અને W કામ છે. આ નિયમના આધારે અવસ્થા પરિવર્તન (ઇસોથર્મલ, ઇસોબેરિક, ઇસોકોરિક, એડિયાબેટિક) સમજાય છે.

  • ઇસોથર્મલ પ્રક્રિયા: ΔU = 0, Q = W
  • ઇસોબેરિક પ્રક્રિયા: Q = ΔU + PΔV
  • ઇસોકોરિક પ્રક્રિયા: W = 0, ΔU = Q
  • એડિયાબેટિક પ્રક્રિયા: Q = 0, ΔU = -W
🧠 Trick: ઇસોથર્મલ: 'તાપમાન સરખું' (T = constant)

બીજો નિયમ અને એન્ટ્રોપી

બીજો નિયમ કહે છે કે એન્ટ્રોપી (સ્વાભાવિક વિકાર) હંમેશા વધે છે. એન્ટ્રોપી એ અવ્યવસ્થાની માપ છે. આ નિયમ હીટ એન્જિન અને રેફ્રિજરેટરની કાર્યક્ષમતા સમજાવે છે. કાર્નોટ એન્જિન માટે η = 1 - T2/T1.

  • એન્ટ્રોપી (S) એ અવ્યવસ્થાની માપ છે
  • કાર્નોટ એન્જિનની કાર્યક્ષમતા: η = 1 - T_cold/T_hot
  • બીજો નિયમ: ΔS ≥ 0 (સ્વતઃસ્ફૂર્ત પ્રક્રિયા માટે)
  • હીટ એન્જિન માટે Q1 = Q2 + W
🧠 Trick: કાર્નોટ એન્જિન: 'એટા = 1 - ટી2/ટી1' (η = 1 - T2/T1)

તૃતીય નિયમ અને શૂન્યમા નિયમ

તૃતીય નિયમ અનુસાર, શૂન્ય કેલ્વિન તાપમાને શુદ્ધ પદાર્થની એન્ટ્રોપી શૂન્ય હોય છે. શૂન્યમા નિયમ અનુસાર, જો બે પદાર્થો તાપમાન સંતુલનમાં હોય તો તેઓ ત્રીજા પદાર્થ સાથે પણ સંતુલનમાં હશે.

  • તૃતીય નિયમ: S → 0 જ્યારે T → 0K
  • શૂન્યમા નિયમ: A અને B સંતુલનમાં, B અને C સંતુલનમાં → A અને C સંતુલનમાં
  • શૂન્ય કેલ્વિન પ્રાપ્ત થઈ શકતું નથી (અનુમાનિત)
  • તાપમાન એ ઉષ્મા વહનની દિશા નક્કી કરે છે
🧠 Trick: શૂન્યમા નિયમ: 'A=B અને B=C → A=C' (તાપમાન સંતુલન)

હીટ એન્જિન અને રેફ્રિજરેટર

હીટ એન્જિન ઉષ્મા ઉર્જાને યાંત્રિક કામમાં રૂપાંતરિત કરે છે, જ્યારે રેફ્રિજરેટર યાંત્રિક કામ વડે ઉષ્મા સ્થાનાંતરિત કરે છે. કાર્યક્ષમતા η = W/Q1 અને COP (Coefficient of Performance) = Q2/W.

  • હીટ એન્જિન: η = W/Q1 = (Q1 - Q2)/Q1
  • રેફ્રિજરેટર: COP = Q2/W
  • કાર્નોટ એન્જિન સૌથી વધુ કાર્યક્ષમ છે
  • હીટ પંપ: COP = Q1/W = Q1/(Q1 - Q2)
🧠 Trick: હીટ એન્જિન: 'એટા = (ક્યૂ1 - ક્યૂ2)/ક્યૂ1' (η = (Q1 - Q2)/Q1)

મુક્ત ઉર્જા અને ઉર્જા રૂપાંતરણ

ગિબ્સ મુક્ત ઉર્જા (G = H - TS) અને હેલ્મહોલ્ટ્ઝ મુક્ત ઉર્જા (A = U - TS) પ્રક્રિયાની સ્વતઃસ્ફૂર્તતા નક્કી કરે છે. જ્યારે ΔG < 0 ત્યારે પ્રક્રિયા સ્વતઃસ્ફૂર્ત હોય છે.

  • ગિબ્સ મુક્ત ઉર્જા: ΔG = ΔH - TΔS
  • ΔG < 0 → સ્વતઃસ્ફૂર્ત પ્રક્રિયા
  • ΔG = 0 → સંતુલન અવસ્થા
  • ΔG > 0 → અસ્વતઃસ્ફૂર્ત પ્રક્રિયા
🧠 Trick: ગિબ્સ મુક્ત ઉર્જા: 'ડેલ્ટા જી = ડેલ્ટા એચ - ટી ડેલ્ટા એસ' (ΔG = ΔH - TΔS)

⚡ Quick Revision

  • ઉષ્માગતિશાસ્ત્ર ઉર્જાના રૂપાંતરણ અને વહનનો અભ્યાસ છે
  • પહેલો નિયમ: ΔU = Q - W (ઉર્જા સંરક્ષણ)
  • બીજો નિયમ: એન્ટ્રોપી હંમેશા વધે છે (ΔS ≥ 0)
  • આદર્શ વાયુ સમીકરણ: PV = nRT
  • કાર્નોટ એન્જિનની કાર્યક્ષમતા: η = 1 - T2/T1
  • હીટ એન્જિન: η = (Q1 - Q2)/Q1
  • રેફ્રિજરેટર: COP = Q2/W
  • ગિબ્સ મુક્ત ઉર્જા: ΔG = ΔH - TΔS
  • શૂન્યમા નિયમ: તાપમાન સંતુલનની વ્યાખ્યા
  • તૃતીય નિયમ: 0K પર એન્ટ્રોપી શૂન્ય
🎯 Exam Tip: પ્રશ્નોમાં આદર્શ વાયુ સમીકરણ અને થર્મોડાયનેમિક્સના નિયમોને લાગુ પાડવા માટે પ્રક્રિયાનો પ્રકાર (ઇસોથર્મલ, ઇસોબેરિક વગેરે) ઓળખી લો. કાર્નોટ એન્જિન અને મુક્ત ઉર્જા પર ધ્યાન આપો.
