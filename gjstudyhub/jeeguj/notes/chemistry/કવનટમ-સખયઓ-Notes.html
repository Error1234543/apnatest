ક્વોન્ટમ સંખ્યાઓ

📖 ક્વોન્ટમ સંખ્યાઓ

ક્વોન્ટમ સંખ્યાઓનો પરિચય

ક્વોન્ટમ સંખ્યાઓ ઇલેક્ટ્રોનની ઊર્જા, સ્થાન અને ચુંબકીય ગુણધર્મોનું વર્ણન કરે છે. બોહર મોડલ અને ક્વોન્ટમ મિકેનિક્સ અનુસાર, ઇલેક્ટ્રોન નિશ્ચિત ઊર્જાસ્તરોમાં જ રહી શકે છે, જેને ક્વોન્ટમ સંખ્યાઓ વડે દર્શાવાય છે. આ સંખ્યાઓ પરમાણુની ઇલેક્ટ્રોનિક રચના અને રાસાયણિક ગુણધર્મો સમજવામાં મદદરૂપ છે.

  • 4 પ્રકારની ક્વોન્ટમ સંખ્યાઓ: n, l, mₗ, mₛ
  • n = મુખ્ય ક્વોન્ટમ સંખ્યા (ઊર્જાસ્તર)
  • l = કોણીય વેગમાન ક્વોન્ટમ સંખ્યા (ઉપકોષ)
  • mₗ = ચુંબકીય ક્વોન્ટમ સંખ્યા (કક્ષકનું દિશા-નિર્દેશન)
  • mₛ = સ્પિન ક્વોન્ટમ સંખ્યા (±½)
🧠 Trick: નલી મસ (n, l, mₗ, mₛ) – નલી મસ્ત છે!

મુખ્ય ક્વોન્ટમ સંખ્યા (n)

મુખ્ય ક્વોન્ટમ સંખ્યા (n) ઇલેક્ટ્રોનનું ઊર્જાસ્તર અને પરમાણુમાં તેનું સરેરાશ અંતર દર્શાવે છે. n = 1, 2, 3,... હોય છે. n વધે તેમ ઊર્જા અને કક્ષાનું કદ વધે છે. બોહર મોડલમાં nને કક્ષા તરીકે ઓળખવામાં આવે છે.

  • n = 1 → K-કોષ, n = 2 → L-કોષ, વગેરે
  • ઇલેક્ટ્રોનની મહત્તમ સંખ્યા = 2n²
  • n = 1માં 2, n = 2માં 8 ઇલેક્ટ્રોન સમાય
🧠 Trick: 1K, 2L, 3M – કલમ લખો!

કોણીય વેગમાન ક્વોન્ટમ સંખ્યા (l)

કોણીય વેગમાન ક્વોન્ટમ સંખ્યા (l) ઉપકોષનું આકાર અને ઇલેક્ટ્રોનનું કોણીય વેગમાન દર્શાવે છે. l = 0 થી (n-1) સુધીના પૂર્ણાંક મૂલ્યો ધરાવે છે. l = 0 → s, l = 1 → p, l = 2 → d, l = 3 → f ઉપકોષ દર્શાવે છે.

  • l = 0 → ગોળાકાર (s) કક્ષક
  • l = 1 → ડમ્બેલ આકાર (p) કક્ષક
  • l = 2 → ક્લોવર આકાર (d) કક્ષક
  • lનું મૂલ્ય n પર આધારિત (l < n)
🧠 Trick: s પડી (0), p ઉભી (1), d દોડી (2), f ફરી (3)!

ચુંબકીય ક્વોન્ટમ સંખ્યા (mₗ)

ચુંબકીય ક્વોન્ટમ સંખ્યા (mₗ) કક્ષકનું ચુંબકીય ક્ષેત્રમાં દિશા-નિર્દેશન દર્શાવે છે. mₗ = -l થી +l સુધીના પૂર્ણાંક મૂલ્યો ધરાવે છે. દા.ત., l = 1 માટે mₗ = -1, 0, +1 (ત્રણ p-કક્ષકો).

  • mₗ કક્ષકોની સંખ્યા દર્શાવે છે (2l + 1)
  • l = 0 → 1 s-કક્ષક
  • l = 1 → 3 p-કક્ષકો (pₓ, pᵧ, p_z)
  • l = 2 → 5 d-કક્ષકો
🧠 Trick: મીનસ લથી પ્લસ લ (mₗ = -l થી +l)

સ્પિન ક્વોન્ટમ સંખ્યા (mₛ)

સ્પિન ક્વોન્ટમ સંખ્યા (mₛ) ઇલેક્ટ્રોનનું સ્પિન (ભ્રમણ) દર્શાવે છે. તે માત્ર બે મૂલ્યો ધરાવે છે: +½ (અપ-સ્પિન) અને -½ (ડાઉન-સ્પિન). પાઉલીનો નિષેધ સિદ્ધાંત અનુસાર, એક કક્ષકમાં બે ઇલેક્ટ્રોન વિરુદ્ધ સ્પિન ધરાવે છે.

  • mₛ = +½ (↑) અથવા -½ (↓)
  • પાઉલીનો નિયમ: એક કક્ષકમાં બે ઇલેક્ટ્રોન વિરુદ્ધ સ્પિન
  • હુન્ડનો નિયમ: સમાન ઊર્જાવાળી કક્ષકોમાં એકલ ઇલેક્ટ્રોન સમાન સ્પિન ધરાવે છે
🧠 Trick: અપ-ડાઉન સ્પિન – ઉપર-નીચે!

ક્વોન્ટમ સંખ્યાઓ અને ઇલેક્ટ્રોનિક રચના

ક્વોન્ટમ સંખ્યાઓનો ઉપયોગ કરીને પરમાણુની ઇલેક્ટ્રોનિક રચના લખી શકાય છે. ઓફબાઉ સિદ્ધાંત અનુસાર, ઇલેક્ટ્રોન નિમ્ન ઊર્જાવાળી કક્ષકોમાં પહેલા ભરાય છે. દા.ત., કાર્બન (Z=6)ની ઇલેક્ટ્રોનિક રચના: 1s² 2s² 2p².

  • ઓફબાઉ સિદ્ધાંત: (n + l) નિયમ (નિમ્ન ઊર્જા પહેલા)
  • હુન્ડનો નિયમ: સમાન ઊર્જાવાળી કક્ષકોમાં એકલ ઇલેક્ટ્રોન પહેલા ભરાય
  • પાઉલીનો નિષેધ: એક કક્ષકમાં બે ઇલેક્ટ્રોન વિરુદ્ધ સ્પિન
🧠 Trick: ઓફબાઉ: ઓછી (n+l) પહેલા – ઓછી ઊર્જા!

⚡ Quick Revision

  • n = ઊર્જાસ્તર (1, 2, 3,...), l = ઉપકોષ (0 થી n-1)
  • l = 0 → s, 1 → p, 2 → d, 3 → f
  • mₗ = -l થી +l (કક્ષકોની સંખ્યા = 2l + 1)
  • mₛ = +½ અથવા -½ (સ્પિન)
  • પાઉલી: એક કક્ષકમાં બે ઇલેક્ટ્રોન વિરુદ્ધ સ્પિન
  • હુન્ડ: સમાન ઊર્જાવાળી કક્ષકોમાં એકલ ઇલેક્ટ્રોન સમાન સ્પિન
  • ઓફબાઉ: (n + l) નિયમથી ઊર્જાક્રમ નક્કી થાય
  • n = 1 → 2, n = 2 → 8 ઇલેક્ટ્રોન સમાય
🎯 Exam Tip: ક્વોન્ટમ સંખ્યાઓના પ્રશ્નોમાં (n + l) નિયમ યાદ રાખો – ઓછી (n + l) મૂલ્યવાળી કક્ષક પહેલા ભરાય. જો (n + l) સમાન હોય, તો નિમ્ન nવાળી કક્ષક પહેલા ભરાય. દા.ત., 3d (n+l=5) કરતાં 4s (n+l=4) પહેલા ભરાય.
