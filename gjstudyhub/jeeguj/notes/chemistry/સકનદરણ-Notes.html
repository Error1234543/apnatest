સંકેન્દ્રણ

📖 સંકેન્દ્રણ (Concentration)

સંકેન્દ્રણની વ્યાખ્યા અને પ્રકાર

સંકેન્દ્રણ એ દ્રાવણમાં દ્રાવ્ય પદાર્થની માત્રાનું દ્રાવણના કુલ કદ અથવા દળ પ્રમાણે ગુણોત્તર છે. રાસાયણિક વિજ્ઞાનમાં, તે મોલરિટી, મોલાલિટી, નોર્મલિટી, વજન પ્રમાણ, કદ પ્રમાણ વગેરે રૂપે વ્યક્ત થાય છે.

  • સંકેન્દ્રણ = દ્રાવ્ય પદાર્થ / દ્રાવણ (કદ અથવા દળ)
  • મોલરિટી (M) = દ્રાવ્યના મોલ / દ્રાવણનું લીટર
  • મોલાલિટી (m) = દ્રાવ્યના મોલ / દ્રાવકનું કિલોગ્રામ
  • નોર્મલિટી (N) = ગ્રામ સમતુલ્ય / દ્રાવણનું લીટર
  • વજન પ્રમાણ (w/w%) = (દ્રાવ્ય દળ / દ્રાવણ દળ) × 100
🧠 Trick: મોલરિટી મોલ/લીટર, મોલાલિટી મોલ/કિલો

મોલરિટી અને મોલાલિટીનો તફાવત

મોલરિટી દ્રાવણના કદ પર આધારિત છે, જ્યારે મોલાલિટી દ્રાવકના દળ પર આધારિત છે. તાપમાન બદલાતા મોલરિટી બદલાય છે, પરંતુ મોલાલિટી સ્થિર રહે છે.

  • મોલરિટી = તાપમાન-આધારિત (કદ પરિવર્તન)
  • મોલાલિટી = તાપમાન-સ્વતંત્ર (દળ પરિવર્તન)
  • મોલરિટીનો ઉપયોગ રાસાયણિક પ્રક્રિયાઓમાં, મોલાલિટીનો ઉપયોગ ભૌતિક ગુણધર્મો (જેમ કે ક્વથનાંક ઉત્કલન)માં
  • મોલરિટી માટે જરૂરી: દ્રાવણનું કદ, મોલાલિટી માટે: દ્રાવકનું દળ
🧠 Trick: મોલર = લીટર, મોલાલ = કિલો

નોર્મલિટી અને તેની ગણતરી

નોર્મલિટી એ દ્રાવણની સાંદ્રતા છે જે ગ્રામ સમતુલ્ય (equivalent) પર આધારિત છે. તે એસિડ-બેઇઝ ટાઇટ્રેશન અને રેડોક્સ પ્રક્રિયાઓમાં ઉપયોગી છે.

  • નોર્મલિટી (N) = મોલરિટી × n (n = H⁺, OH⁻, અથવા ઇલેક્ટ્રોનની સંખ્યા)
  • 1 N H₂SO₄ = 0.5 M (કારણ કે n=2)
  • 1 N NaOH = 1 M (કારણ કે n=1)
  • ટાઇટ્રેશનમાં: N₁V₁ = N₂V₂ (સમતોલનનો નિયમ)
🧠 Trick: N = M × n (n = સમતુલ્ય સંખ્યા)

સંકેન્દ્રણની ગણતરી માટેના સૂત્રો

દ્રાવણની સાંદ્રતા ગણતરી માટે વજન પ્રમાણ, કદ પ્રમાણ, અને મોલ પ્રમાણ જેવા સૂત્રો ઉપયોગી છે. આ સૂત્રો દ્રાવ્ય અને દ્રાવકના પ્રમાણને સરળતાથી વ્યક્ત કરે છે.

  • વજન પ્રમાણ (w/w%) = (દ્રાવ્ય દળ / દ્રાવણ દળ) × 100
  • કદ પ્રમાણ (v/v%) = (દ્રાવ્ય કદ / દ્રાવણ કદ) × 100
  • મોલ પ્રમાણ (x) = દ્રાવ્યના મોલ / કુલ મોલ (દ્રાવ્ય + દ્રાવક)
  • પીપીએમ (ppm) = (દ્રાવ્ય દળ / દ્રાવણ દળ) × 10⁶

સંકેન્દ્રણ અને દ્રાવણના ભૌતિક ગુણધર્મો

સંકેન્દ્રણ દ્રાવણના ક્વથનાંક ઉત્કલન, હિમાંક અવસાદન, પરાસરપણ દબાણ, અને વિશિષ્ટ વાહકતા જેવા ભૌતિક ગુણધર્મોને અસર કરે છે. આ ગુણધર્મો દ્રાવ્ય કણોની સંખ્યા પર આધારિત છે.

  • ક્વથનાંક ઉત્કલન (ΔTb) = Kb × m (m = મોલાલિટી)
  • હિમાંક અવસાદન (ΔTf) = Kf × m
  • પરાસરપણ દબાણ (π) = CRT (C = મોલર સાંદ્રતા, R = ગેસ અચળાંક, T = તાપમાન)
  • વિશિષ્ટ વાહકતા (κ) = સાંદ્રતા × મોલર વાહકતા (Λm)
🧠 Trick: ΔTb = Kb×m, ΔTf = Kf×m, π = CRT

સંકેન્દ્રણના પ્રયોગિક ઉપયોગો

સંકેન્દ્રણનો ઉપયોગ રાસાયણિક ઉદ્યોગો, દવાઓની તૈયારી, અને જૈવરાસાયણિક પ્રક્રિયાઓમાં થાય છે. ઉદાહરણ તરીકે, દવાઓની સાંદ્રતા નિર્ધારિત કરવા માટે મોલરિટી અને નોર્મલિટીનો ઉપયોગ થાય છે.

  • દવાઓમાં સક્રિય ઘટકની સાંદ્રતા નિર્ધારિત કરવા
  • ટાઇટ્રેશન પ્રયોગોમાં એસિડ-બેઇઝ પ્રક્રિયાઓની ગણતરી
  • ખેતીમાં ખાતરના દ્રાવણની સાંદ્રતા નિયંત્રિત કરવા
  • જૈવરાસાયણિક પ્રયોગશાળામાં પ્રોટીન અને DNAના દ્રાવણો તૈયાર કરવા

સંકેન્દ્રણ અને તાપમાનની અસર

તાપમાન બદલાતા દ્રાવણના કદમાં ફેરફાર થાય છે, જે મોલરિટીને અસર કરે છે. પરંતુ મોલાલિટી તાપમાન પર આધારિત નથી, કારણ કે તે દ્રાવકના દળ પર આધારિત છે.

  • તાપમાન વધે તો દ્રાવણનું કદ વધે → મોલરિટી ઘટે
  • તાપમાન ઘટે તો દ્રાવણનું કદ ઘટે → મોલરિટી વધે
  • મોલાલિટી તાપમાન પર આધારિત નથી
  • નોર્મલિટી પણ તાપમાન પર આધારિત છે (મોલરિટી જેવી)
🧠 Trick: તાપમાન ↑ → કદ ↑ → મોલરિટી ↓

⚡ Quick Revision

  • સંકેન્દ્રણ = દ્રાવ્ય / દ્રાવણ (કદ અથવા દળ)
  • મોલરિટી (M) = મોલ / લીટર, મોલાલિટી (m) = મોલ / કિલો
  • નોર્મલિટી (N) = M × n (n = સમતુલ્ય સંખ્યા)
  • વજન પ્રમાણ (w/w%) = (દ્રાવ્ય દળ / દ્રાવણ દળ) × 100
  • ક્વથનાંક ઉત્કલન (ΔTb) = Kb × m
  • હિમાંક અવસાદન (ΔTf) = Kf × m
  • પરાસરપણ દબાણ (π) = CRT
  • ટાઇટ્રેશનમાં N₁V₁ = N₂V₂
  • તાપમાન ↑ → મોલરિટી ↓, મોલાલિટી સ્થિર
  • પીપીએમ (ppm) = (દ્રાવ્ય દળ / દ્રાવણ દળ) × 10⁶
🎯 Exam Tip: સંકેન્દ્રણના પ્રશ્નોમાં એકમો પર ધ્યાન આપો: મોલરિટી (લીટર), મોલાલિટી (કિલો), અને નોર્મલિટી (સમતુલ્ય) વચ્ચેનો તફાવત સમજો. ટાઇટ્રેશનમાં N₁V₁ = N₂V₂નો ઉપયોગ કરો.
