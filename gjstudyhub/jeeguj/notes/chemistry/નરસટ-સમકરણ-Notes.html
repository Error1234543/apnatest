નર્સ્ટ સમીકરણ

📖 નર્સ્ટ સમીકરણ

પરિભાષા અને મૂળભૂત સંકલ્પના

નર્સ્ટ સમીકરણ વીજરાસાયણિક કોષના વિદ્યુતવાહક બળ (EMF) અને સાંદ્રતા સાથેના સંબંધને વ્યાખ્યાયિત કરે છે. તે સ્ટાન્ડર્ડ વિદ્યુતવાહક બળ (E°) અને આયનની સાંદ્રતાને ધ્યાનમાં લે છે. સમીકરણ એન્ટ્રોપી અને ગિબ્સ મુક્ત ઉર્જાના સિદ્ધાંત પર આધારિત છે.

  • નર્સ્ટ સમીકરણ: E = E° - (RT/nF) ln(Q)
  • E° = સ્ટાન્ડર્ડ વિદ્યુતવાહક બળ (Vમાં)
  • R = વાયુ અચળાંક (8.314 J/mol·K)
  • T = તાપમાન (Kમાં)
  • n = ઇલેક્ટ્રોનનું મોલ સંખ્યા
  • F = ફેરેડે અચળાંક (96485 C/mol)
  • Q = પ્રતિક્રિયા ભાગફળ (Reaction Quotient)

સમીકરણની ઉત્પત્તિ

નર્સ્ટ સમીકરણ ગિબ્સ મુક્ત ઉર્જા (ΔG = ΔG° + RT ln(Q)) અને વિદ્યુતવાહક બળ વચ્ચેના સંબંધ પરથી મેળવવામાં આવે છે. ΔG = -nFE અને ΔG° = -nFE° વાપરીને, સમીકરણ મેળવી શકાય છે.

  • ΔG = -nFE (વીજરાસાયણિક પ્રણાલી માટે)
  • ΔG° = -nFE° (સ્ટાન્ડર્ડ પરિસ્થિતિમાં)
  • નર્સ્ટ સમીકરણ: E = E° - (0.0591/n) log(Q) (25°C પર)
  • log(Q) = લોગરિધમિક ભાગફળ

સમીકરણના ઉપયોગો

નર્સ્ટ સમીકરણનો ઉપયોગ કોષના વિદ્યુતવાહક બળની ગણતરી, સાંદ્રતા કોષના વિદ્યુતવાહક બળની ગણતરી, અને સંતુલન અચળાંક (K)ની ગણતરી માટે થાય છે. તે વીજરાસાયણિક કોષની કાર્યક્ષમતાનું મૂલ્યાંકન કરવામાં પણ મદદ કરે છે.

  • કોષના E અને E°ની ગણતરી
  • સાંદ્રતા કોષ (Concentration Cell) માટે Eની ગણતરી
  • સંતુલન અચળાંક K = e^(nFE°/RT)
  • પ્રતિક્રિયાની દિશા નક્કી કરવા માટે

સાંદ્રતા કોષ (Concentration Cell)

જ્યારે બે અર્ધકોષમાં એક જ ધાતુની આયનની ભિન્ન સાંદ્રતા હોય ત્યારે સાંદ્રતા કોષ બને છે. નર્સ્ટ સમીકરણ વાપરીને તેના વિદ્યુતવાહક બળની ગણતરી કરવામાં આવે છે. E = (0.0591/n) log([C]_cathode / [C]_anode).

  • સાંદ્રતા કોષમાં E° = 0 (એક જ ધાતુ હોવાથી)
  • E = (0.0591/n) log([C]_cathode / [C]_anode)
  • વીજધ્રુવ (Anode) નીચી સાંદ્રતા વાળો હોય છે
  • ધનધ્રુવ (Cathode) ઉચ્ચ સાંદ્રતા વાળો હોય છે
🧠 Trick: સાંદ્રતા કોષમાં, ઉચ્ચ સાંદ્રતા ધનધ્રુવ, નીચી સાંદ્રતા વીજધ્રુવ

તાપમાનનો પ્રભાવ

નર્સ્ટ સમીકરણમાં તાપમાન (T)નો પ્રભાવ સીધો હોય છે. તાપમાન વધારવાથી (RT/nF)નો ગુણાંક વધે છે, જેના કારણે વિદ્યુતવાહક બળ (E) પર અસર પડે છે. 25°C (298 K) પર સમીકરણ સરળ બને છે: E = E° - (0.0591/n) log(Q).

  • તાપમાન વધારવાથી (RT/nF) વધે છે
  • 25°C પર 0.0591/nનો ગુણાંક વાપરવામાં આવે છે
  • તાપમાન બદલાય ત્યારે સમીકરણમાં Tનો મૂલ્ય અપડેટ કરવો
  • વીજરાસાયણિક કોષની કાર્યક્ષમતા તાપમાન પર આધાર રાખે છે

પ્રતિક્રિયાની દિશા અને સંતુલન

નર્સ્ટ સમીકરણ વાપરીને પ્રતિક્રિયાની દિશા નક્કી કરી શકાય છે. જો E > 0 હોય તો પ્રતિક્રિયા સ્વત:સ્ફૂર્તિ (spontaneous) છે. સંતુલન પર Q = K હોય છે, અને E = 0 થાય છે. આથી, E° = (0.0591/n) log(K).

  • E > 0 → સ્વત:સ્ફૂર્તિ પ્રતિક્રિયા
  • E < 0 → અસ્વત:સ્ફૂર્તિ પ્રતિક્રિયા
  • સંતુલન પર E = 0 અને Q = K
  • E° = (0.0591/n) log(K) (25°C પર)
🧠 Trick: E પોઝિટિવ, પ્રતિક્રિયા સ્પોન્ટેનિયસ

જીવવિજ્ઞાનમાં ઉપયોગ (બાયોઇલેક્ટ્રોકેમિસ્ટ્રી)

નર્સ્ટ સમીકરણનો ઉપયોગ જીવવિજ્ઞાનમાં પણ થાય છે, જેમ કે કોષીય શ્વસન અને પ્રકાશસંશ્લેષણ દરમિયાન થતી વીજરાસાયણિક પ્રક્રિયાઓના અભ્યાસમાં. તે આયન ચેનલ અને કોષીય ઝરણાનું મૂલ્યાંકન કરવામાં મદદ કરે છે.

  • કોષીય શ્વસનમાં ઇલેક્ટ્રોન પરિવહન શૃંખલા (ETC)નું મૂલ્યાંકન
  • પ્રકાશસંશ્લેષણમાં થાયલેકોઇડ ઝરણાનું અભ્યાસ
  • આયન ચેનલની કાર્યપદ્ધતિનું મોડેલિંગ
  • બાયોએનર્જેટિક્સમાં ઉર્જા પરિવહનનો અભ્યાસ

⚡ Quick Revision

  • નર્સ્ટ સમીકરણ: E = E° - (RT/nF) ln(Q)
  • 25°C પર: E = E° - (0.0591/n) log(Q)
  • E° = સ્ટાન્ડર્ડ વિદ્યુતવાહક બળ, R = 8.314 J/mol·K, F = 96485 C/mol
  • સાંદ્રતા કોષમાં E = (0.0591/n) log([C]_cathode / [C]_anode)
  • E > 0 → સ્વત:સ્ફૂર્તિ પ્રતિક્રિયા, E = 0 → સંતુલન
  • સંતુલન અચળાંક K = e^(nFE°/RT)
  • તાપમાન વધારવાથી (RT/nF) વધે છે
  • પ્રતિક્રિયા ભાગફળ Q = [પ્રોડક્ટ્સ]/[રિએક્ટન્ટ્સ]
🎯 Exam Tip: પરીક્ષામાં નર્સ્ટ સમીકરણના પ્રશ્નો માટે, સૌપ્રથમ Qની ગણતરી કરો, પછી સમીકરણમાં મૂકીને Eની ગણતરી કરો. સાંદ્રતા કોષના પ્રશ્નોમાં E° = 0 યાદ રાખો.
