આણ્વિક આકાર

📖 આણ્વિક આકાર (Molecular Geometry)

વેધન સિદ્ધાંત (VSEPR Theory)

આણ્વિક આકાર નક્કી કરવા માટે VSEPR થિયરી વપરાય છે, જેમાં ઇલેક્ટ્રોન જૂથો (બંધન જૂથ અને એકાકી જૂથ) વચ્ચેના વિકર્ષણને આધારે આકાર નિશ્ચિત થાય છે. ઇલેક્ટ્રોન જૂથો વચ્ચેનો કોણ ૯૦° થી ૧૨૦° સુધી હોઈ શકે છે.

  • VSEPR = Valence Shell Electron Pair Repulsion
  • બંધન જૂથ (Bonding Pair) અને એકાકી જૂથ (Lone Pair) વચ્ચે વિકર્ષણ થાય છે
  • એકાકી જૂથ વધુ જગ્યા ઘેરે છે → કોણ ઘટે છે
  • AX₂ → રેખીય, AX₃ → ત્રિકોણીય સમતલ, AX₄ → ટેટ્રાહેડ્રલ
🧠 Trick: લોન પેર = લડાઈ કરે → કોણ ઘટે (Lone Pair Repels More → Angle Decreases)

હાઇબ્રિડાઇઝેશન (Hybridization)

આણ્વિક આકાર સ્પષ્ટ કરવા હાઇબ્રિડાઇઝેશન મહત્વનું છે. sp, sp², sp³ હાઇબ્રિડાઇઝેશન સામાન્ય રીતે JEEમાં પૂછાય છે. હાઇબ્રિડ ઓર્બિટલ્સની સંખ્યા અને જ્યોમેટ્રી આકાર નક્કી કરે છે.

  • sp → રેખીય (180°), sp² → ત્રિકોણીય સમતલ (120°)
  • sp³ → ટેટ્રાહેડ્રલ (109.5°), dsp³ → ટ્રાયગોનલ બાઇપિરામિડલ
  • હાઇબ્રિડાઇઝેશન = સંકરણ (મિશ્રણ) ઓર્બિટલ્સનું
🧠 Trick: sp = 2 લેયર (રેખીય), sp² = 3 લેયર (ત્રિકોણ), sp³ = 4 લેયર (ટેટ્રા)

બંધન કોણ (Bond Angle)

બંધન કોણ આણ્વિક આકાર અને ધ્રુવીયતાને અસર કરે છે. એકાકી જૂથની હાજરીથી બંધન કોણ ઘટે છે. ઉદા. NH₃માં 107° (sp³ + 1 એકાકી જૂથ) જ્યારે CH₄માં 109.5° (sp³).

  • એકાકી જૂથ → કોણ ઘટે (NH₃ = 107°, H₂O = 104.5°)
  • બધા બંધન જૂથ → કોણ સમાન (CH₄ = 109.5°)
  • વિકર્ષણ: એકાકી-એકાકી > એકાકી-બંધન > બંધન-બંધન
🧠 Trick: લોન પેર વધુ → કોણ ઓછું (More Lone Pairs → Smaller Angle)

આણ્વિક ધ્રુવીયતા (Molecular Polarity)

આણ્વિક આકાર અને બંધન ધ્રુવીયતાને આધારે આણ્વિક ધ્રુવીયતા નક્કી થાય છે. અસમમિત આકાર ધરાવતા અણુઓ ધ્રુવીય હોય છે (ઉદા. H₂O, NH₃).

  • સમમિત આકાર (CO₂, CH₄) → અધ્રુવીય
  • અસમમિત આકાર (H₂O, NH₃) → ધ્રુવીય
  • બંધન ધ્રુવીયતા + આકાર → આણ્વિક ધ્રુવીયતા
🧠 Trick: સમ = સરળ (Non-Polar), અસમ = અઘરું (Polar)

સામાન્ય આણ્વિક આકાર (Common Molecular Shapes)

JEEમાં પૂછાતા આકાર: રેખીય (CO₂), ત્રિકોણીય સમતલ (BF₃), ટેટ્રાહેડ્રલ (CH₄), ટ્રાયગોનલ પિરામિડલ (NH₃), બેન્ટ (H₂O), ટ્રાયગોનલ બાઇપિરામિડલ (PCl₅).

  • AX₂ → રેખીય (CO₂, BeCl₂)
  • AX₃ → ત્રિકોણીય સમતલ (BF₃, SO₃)
  • AX₄ → ટેટ્રાહેડ્રલ (CH₄, NH₄⁺)
  • AX₅ → ટ્રાયગોનલ બાઇપિરામિડલ (PCl₅)

વિશિષ્ટ કેસ: PCl₅ અને SF₆

PCl₅માં sp³d હાઇબ્રિડાઇઝેશન અને ટ્રાયગોનલ બાઇપિરામિડલ આકાર હોય છે. SF₆માં sp³d² હાઇબ્રિડાઇઝેશન અને ઓક્ટાહેડ્રલ આકાર હોય છે. આ કેસ JEEમાં વારંવાર પૂછાય છે.

  • PCl₅ → sp³d → ટ્રાયગોનલ બાઇપિરામિડલ
  • SF₆ → sp³d² → ઓક્ટાહેડ્રલ
  • d-ઓર્બિટલ્સનો ઉપયોગ થાય છે
🧠 Trick: PCl₅ = 5 બંધન → 5 કોર (Trigonal Bipyramidal), SF₆ = 6 બંધન → 8 કોર (Octahedral)

⚡ Quick Revision

  • VSEPR થિયરી: ઇલેક્ટ્રોન જૂથો વચ્ચે વિકર્ષણ → આકાર નક્કી
  • હાઇબ્રિડાઇઝેશન: sp, sp², sp³, dsp³, sp³d²
  • બંધન કોણ: એકાકી જૂથ → કોણ ઘટે
  • ધ્રુવીયતા: અસમમિત આકાર → ધ્રુવીય
  • રેખીય: AX₂ (CO₂), ત્રિકોણીય: AX₃ (BF₃)
  • ટેટ્રાહેડ્રલ: AX₄ (CH₄), પિરામિડલ: AX₃E (NH₃)
  • PCl₅ → ટ્રાયગોનલ બાઇપિરામિડલ, SF₆ → ઓક્ટાહેડ્રલ
🎯 Exam Tip: VSEPR અને હાઇબ્રિડાઇઝેશનને એકસાથે યાદ રાખો — JEEમાં આ બંને પરથી પ્રશ્નો પૂછાય છે. ઉદા. 'CH₄નો આકાર અને હાઇબ્રિડાઇઝેશન જણાવો'.
