આલ્કોહોલ

📖 આલ્કોહોલ

આલ્કોહોલની વ્યાખ્યા અને વર્ગીકરણ

આલ્કોહોલ એ હાઇડ્રોક્સિલ સમૂહ (-OH) ધરાવતા કાર્બનિક યોગિકો છે. જ્યારે -OH સમૂહ સીધા જ કાર્બન પર જોડાયેલ હોય ત્યારે તેને આલ્કોહોલ કહેવાય. આલ્કોહોલને મોનોહાઇડ્રિક, ડાયહાઇડ્રિક અને ટ્રાયહાઇડ્રિકમાં વર્ગીકૃત કરવામાં આવે છે.

  • -OH સમૂહ ધરાવતા યોગિકોને આલ્કોહોલ કહેવાય
  • મોનોહાઇડ્રિક: એક -OH સમૂહ (ઉદા. CH₃OH)
  • ડાયહાઇડ્રિક: બે -OH સમૂહ (ઉદા. C₂H₄(OH)₂)
  • ટ્રાયહાઇડ્રિક: ત્રણ -OH સમૂહ (ઉદા. C₃H₅(OH)₃)
🧠 Trick: મોનો-ડાય-ટ્રાય: એક-બે-ત્રણ -OH સમૂહ

આલ્કોહોલનું નામકરણ (IUPAC)

IUPAC નિયમો મુજબ, આલ્કોહોલનું નામ એલ્કેનના નામના અંતે 'ol' પ્રત્યય ઉમેરીને આપવામાં આવે છે. -OH સમૂહની સ્થિતિ નિર્ધારિત કરવા માટે કાર્બન ક્રમાંકનો ઉપયોગ થાય છે.

  • એલ્કેનના નામ + 'ol' પ્રત્યય (ઉદા. Ethane → Ethanol)
  • -OH સમૂહની સ્થિતિ માટે નીચેની ક્રમાંકનો ઉપયોગ
  • જો બહુવિધ -OH હોય તો 'di', 'tri' પ્રત્યય વાપરો
  • પ્રાથમિક, દ્વિતીય, તૃતીય આલ્કોહોલની ઓળખ

આલ્કોહોલના ભૌતિક ગુણધર્મો

આલ્કોહોલ હાઇડ્રોજન બંધનને કારણે ઉચ્ચ ક્વથનાંક ધરાવે છે. નીચા કાર્બન ધરાવતા આલ્કોહોલ પાણીમાં દ્રાવ્ય હોય છે, જ્યારે ઉચ્ચ કાર્બન ધરાવતા આલ્કોહોલ અદ્રાવ્ય હોય છે.

  • H-બંધનને કારણે ઉચ્ચ ક્વથનાંક
  • CH₃OH, C₂H₅OH પાણીમાં દ્રાવ્ય
  • C₄H₉OH અને તેનાથી ઉચ્ચ કાર્બનવાળા અદ્રાવ્ય
  • આલ્કોહોલનું ઘનત્વ પાણી કરતાં ઓછું
  • વિધુતના અવલોકનમાં નિષ્ક્રિય
🧠 Trick: ઓછા કાર્બન = દ્રાવ્ય, વધુ કાર્બન = અદ્રાવ્ય

આલ્કોહોલના રાસાયણિક ગુણધર્મો

આલ્કોહોલ મેટલ સાથે પ્રક્રિયા કરી આલ્કોક્સાઇડ બનાવે છે. તે ઓક્સિડેશનથી એલ્ડિહાઇડ, કીટોન અથવા કાર્બોક્સિલિક એસિડમાં રૂપાંતરિત થાય છે. ડિહાઇડ્રેશનથી આલ્કીન બનાવે છે.

  • Na સાથે પ્રક્રિયા: 2ROH + 2Na → 2RONa + H₂
  • પ્રાથમિક આલ્કોહોલ → એલ્ડિહાઇડ → કાર્બોક્સિલિક એસિડ
  • દ્વિતીય આલ્કોહોલ → કીટોન
  • તૃતીય આલ્કોહોલ ઓક્સિડેશનથી કેટલાક કીટોન બનાવે છે
  • ડિહાઇડ્રેશન: R-CH₂-CH₂-OH → R-CH=CH₂ + H₂O
🧠 Trick: Na સાથે H₂ ગેસ, ઓક્સિડેશનથી એસિડ

આલ્કોહોલનું ઉત્પાદન

આલ્કોહોલનું ઉત્પાદન ફર્મેન્ટેશન, હાઇડ્રોલિસિસ, અને હાઇડ્રેશન દ્વારા થાય છે. ઇથેનોલનું ઉત્પાદન સ્ટાર્ચ અથવા શર્કરાના ફર્મેન્ટેશન દ્વારા થાય છે.

  • ફર્મેન્ટેશન: C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂ (યીસ્ટ દ્વારા)
  • હાઇડ્રોલિસિસ: આલ્કિલ હેલાઇડ + NaOH → આલ્કોહોલ
  • હાઇડ્રેશન: આલ્કીન + H₂O → આલ્કોહોલ (H⁺ ઉત્પ્રેરક)
  • ગ્રિગ્નાર્ડ અભિક્રિયા: RMgX + HCHO → R-CH₂OH
🧠 Trick: ફર્મેન્ટેશન = યીસ્ટ + શર્કરા → ઇથેનોલ

આલ્કોહોલના ઉપયોગો

ઇથેનોલનો ઉપયોગ પીણા, ઇંધણ, અને ઉદ્યોગમાં થાય છે. મિથેનોલનો ઉપયોગ ફોર્મલિન, પ્લાસ્ટિક, અને ઇંધણમાં થાય છે. આલ્કોહોલનો ઉપયોગ દવા અને કોસ્મેટિક્સમાં પણ થાય છે.

  • ઇથેનોલ: પીણા, ઇંધણ (બાયોઇથેનોલ), સોલ્વેન્ટ
  • મિથેનોલ: ફોર્મલિન, પ્લાસ્ટિક, પેઇન્ટ
  • આયસોપ્રોપાઇલ આલ્કોહોલ: રબિંગ આલ્કોહોલ, ડિસિન્ફેક્ટન્ટ
  • ગ્લિસરોલ: કોસ્મેટિક્સ, દવા

આલ્કોહોલના જૈવિક મહત્વ

ઇથેનોલ માનવ શરીરમાં મેટાબોલિઝમ દ્વારા ઉર્જા ઉત્પન્ન કરે છે. આલ્કોહોલનો અતિરેક માદક પદાર્થ તરીકે કામ કરે છે અને યકૃતને નુકસાન પહોંચાડે છે.

  • ઇથેનોલ મેટાબોલિઝમથી એસિટલડિહાઇડ અને એસિટિક એસિડમાં રૂપાંતરિત થાય
  • યકૃતમાં આલ્કોહોલ ડિહાઇડ્રોજિનેઝ ઉત્સેચક દ્વારા તોડવામાં આવે
  • અતિરેકથી યકૃત સિરોસિસ થાય
  • માદક પદાર્થ તરીકે કામ કરે છે
🧠 Trick: ઇથેનોલ → એસિટલડિહાઇડ → એસિટિક એસિડ

⚡ Quick Revision

  • આલ્કોહોલ = -OH સમૂહ ધરાવતા કાર્બનિક યોગિકો
  • મોનો, ડાય, ટ્રાયહાઇડ્રિક આલ્કોહોલ
  • IUPAC નામ: એલ્કેન + 'ol' પ્રત્યય
  • H-બંધનને કારણે ઉચ્ચ ક્વથનાંક
  • Na સાથે પ્રક્રિયા: 2ROH + 2Na → 2RONa + H₂
  • ફર્મેન્ટેશન: શર્કરા → ઇથેનોલ + CO₂
  • ઓક્સિડેશન: પ્રાથમિક → એલ્ડિહાઇડ → એસિડ
  • ડિહાઇડ્રેશન: આલ્કોહોલ → આલ્કીન
  • ઇથેનોલ: પીણા, ઇંધણ, સોલ્વેન્ટ
  • મિથેનોલ: ફોર્મલિન, પ્લાસ્ટિક
🎯 Exam Tip: આલ્કોહોલના રાસાયણિક ગુણધર્મો અને પ્રક્રિયાઓ (ઓક્સિડેશન, ડિહાઇડ્રેશન) પર ધ્યાન કેન્દ્રિત કરો, કારણ કે JEEમાં આ પ્રશ્નો વારંવાર પૂછવામાં આવે છે.
