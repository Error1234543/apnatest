પલાયન વેગ

📖 પલાયન વેગ

પરિભાષા અને મૂળભૂત સમજ

પલાયન વેગ એટલે વસ્તુની સપાટી પરથી અણુઓનો બાષ્પમાં પરિવર્તન થવાની પ્રક્રિયાનો વેગ. તે તાપમાન, સપાટીનું ક્ષેત્રફળ, વાયુના પ્રવાહ અને અણુઓની પ્રકૃતિ પર આધાર રાખે છે. JEEમાં આને કિનેટિક થિયરી અને થર્મોડાયનેમિક્સ સાથે જોડીને પૂછવામાં આવે છે.

  • પલાયન વેગ = (વરાળ દબાણ) / (તાપમાન + 273)ના વર્ગમૂળના સમપ્રમાણમાં
  • તાપમાન વધે ત્યારે પલાયન વેગ વધે (અરેથિયસ સિદ્ધાંત)
  • સપાટીનું ક્ષેત્રફળ વધે ત્યારે પલાયન વેગ વધે
  • વાયુનો પ્રવાહ પલાયન વેગને વધારે છે
🧠 Trick: ટીવી એસક્યુર (T√V) - તાપમાન (T) અને વરાળ દબાણ (V)ના વર્ગમૂળ (√) પર આધાર

કિનેટિક થિયરી અનુસાર સમજૂતી

કિનેટિક થિયરી મુજબ, અણુઓની ગતિજ ઉર્જા તાપમાન સાથે વધે છે. જ્યારે અણુઓની ઉર્જા દ્રવના આંતરિક બળોને ઓળંગે છે, ત્યારે પલાયન થાય છે. પલાયન વેગ એ અણુઓની સરેરાશ ગતિજ ઉર્જા અને સપાટી પરથી નીકળતા અણુઓની સંખ્યા પર આધાર રાખે છે.

  • પલાયન વેગ ∝ √(T) (કેલ્વિનમાં)
  • અણુઓની સરેરાશ ગતિજ ઉર્જા = (3/2)kT
  • પલાયન વેગ = (1/√(2πMRT)) * e^(-λ/RT) (મેક્સવેલ-બોલ્ટઝમેન સૂત્ર)
  • λ = પલાયનની ઉર્જા (J/mol)

થર્મોડાયનેમિક્સ અને પલાયન વેગ

પલાયન પ્રક્રિયા એ એક એન્ડોથર્મિક પ્રક્રિયા છે, જેમાં ΔG > 0, ΔH > 0, અને ΔS > 0. ક્લૉસિયસ-ક્લાપેયરન સમીકરણ (ln(P2/P1) = -ΔHvap/R (1/T2 - 1/T1)) પલાયન વેગ અને તાપમાન વચ્ચેનો સંબંધ આપે છે.

  • પલાયન એ એન્ડોથર્મિક પ્રક્રિયા (ΔH > 0)
  • ક્લૉસિયસ-ક્લાપેયરન સમીકરણ પલાયન એન્થાલ્પી (ΔHvap) શોધવા ઉપયોગી
  • તાપમાન વધે ત્યારે Pvap વધે, જેથી પલાયન વેગ વધે
  • પલાયન એન્ટ્રોપી (ΔS) હમેશા ધન હોય છે
🧠 Trick: ક્લૉસિયસ ક્લાપેયરન = લોગ(P) = -ΔH/R (1/T)

રૉલ્ટનો નિયમ અને પલાયન વેગ

રૉલ્ટનો નિયમ મુજબ, દ્રાવણમાં દ્રાવ્ય પદાર્થની મોલ ભાગીદારી જેટલી ઓછી હોય, પલાયન વેગ એટલો જ ઓછો હોય. આને પલાયન વેગમાં ઘટાડો (ΔP = P° * X_solute) તરીકે વ્યાખ્યાયિત કરવામાં આવે છે.

  • રૉલ્ટનો નિયમ: ΔP = P° * X_solute
  • P° = શુદ્ધ દ્રાવકનો વરાળ દબાણ
  • X_solute = દ્રાવ્યની મોલ ભાગીદારી
  • પલાયન વેગમાં ઘટાડો = (ΔP / P°) * 100%
🧠 Trick: રૉલ્ટ = P° * X (રાશી ઓછી લેતા ટકા)

પલાયન વેગના પ્રયોગિક ઉપયોગો

પલાયન વેગનો ઉપયોગ શુદ્ધ પદાર્થોના મોલર દળ શોધવા, મિશ્રણોનું વિભાજન (જેમકે નિષ્કર્ષણ), અને વાતાવરણમાં પાણીના ચક્રમાં થાય છે. JEEમાં આને સંકર મિશ્રણો અને કોલિગેટિવ ગુણધર્મો સાથે જોડીને પૂછવામાં આવે છે.

  • મોલર દળ = (2 * R * T * w) / (ΔP * A) (વિક્ટર મેયર પદ્ધતિ)
  • નિષ્કર્ષણમાં પલાયન વેગનો ઉપયોગ થાય છે
  • કોલિગેટિવ ગુણધર્મો (પલાયન વેગમાં ઘટાડો, ક્વથનાંક વૃદ્ધિ, હિમાંક અવકાશ) પર આધારિત
  • વાતાવરણમાં પાણીનો ચક્ર પલાયન વેગ પર આધાર રાખે છે

પલાયન વેગ અને વાયુમિશ્રણો

વાયુમિશ્રણોમાં પલાયન વેગ ડાલ્ટનના આંશિક દબાણના નિયમ પર આધાર રાખે છે. દરેક વાયુનો પલાયન વેગ તેના આંશિક દબાણના સમપ્રમાણમાં હોય છે. આને વરાળ દબાણ અને ગ્રહણશીલતા સાથે જોડીને સમજાવવામાં આવે છે.

  • ડાલ્ટનનો નિયમ: P_total = P1 + P2 + ... + Pn
  • પલાયન વેગ ∝ આંશિક દબાણ (Pi)
  • ગ્રહણશીલતા (S) = (વરાળ દબાણ) / (તાપમાન)
  • હેનરીનો નિયમ: C = k * P (વાયુની દ્રાવ્યતા)
🧠 Trick: ડાલ્ટન = દબાણોનો સરવાળો

⚡ Quick Revision

  • પલાયન વેગ = તાપમાનના વર્ગમૂળના સમપ્રમાણમાં
  • રૉલ્ટનો નિયમ: ΔP = P° * X_solute
  • ક્લૉસિયસ-ક્લાપેયરન: ln(P2/P1) = -ΔHvap/R (1/T2 - 1/T1)
  • પલાયન એ એન્ડોથર્મિક પ્રક્રિયા (ΔH > 0)
  • મોલર દળ = (2RTw)/(ΔP * A)
  • પલાયન વેગ વાયુના પ્રવાહથી વધે છે
  • ડાલ્ટનનો નિયમ: P_total = ΣPi
  • પલાયન વેગ ∝ સપાટીનું ક્ષેત્રફળ
  • કિનેટિક થિયરી: પલાયન વેગ ∝ √T
  • કોલિગેટિવ ગુણધર્મો પલાયન વેગ સાથે સંબંધિત છે
🎯 Exam Tip: JEEમાં પલાયન વેગના પ્રશ્નો રૉલ્ટના નિયમ, ક્લૉસિયસ-ક્લાપેયરન સમીકરણ, અને કિનેટિક થિયરી સાથે જોડીને પૂછવામાં આવે છે. તાપમાન અને દબાણના એકમોને કેલ્વિન અને પાસ્કલમાં રૂપાંતરિત કરવાનું ભૂલશો નહીં.
