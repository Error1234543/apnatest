Pro Notes

સ્પ્રિંગ

📖 સ્પ્રિંગ (Spring) - ભૌતિકવિજ્ઞાન (Physics) - JEE Main સિલેબસ

સ્પ્રિંગનું પરિભાષિત અને પ્રકારો

સ્પ્રિંગ એ લવચીક પદાર્થનો બનેલો વસ્તુ છે જે તેના આકારમાં પરિવર્તન લાવી શકે છે અને પુનઃસ્થાપિત શક્તિ ઉત્પન્ન કરે છે. મુખ્ય પ્રકારો: ૧) સરળ હેલિકલ સ્પ્રિંગ (તાણ/દબાણ), ૨) સ્પાયરલ સ્પ્રિંગ, ૩) લીફ સ્પ્રિંગ, ૪) ટોર્શન સ્પ્રિંગ.

  • હુકનો નિયમ (F = -kx) સ્પ્રિંગની લવચીકતા વર્ણવે છે.
  • k = સ્પ્રિંગ નિયતાંક (N/m), x = વિસ્થાપન.
  • સરળ હેલિકલ સ્પ્રિંગ સૌથી સામાન્ય પ્રકાર છે.
  • ટોર્શન સ્પ્રિંગ ટોર્ક લાગુ પાડે છે.

હુકનો નિયમ અને લવચીક શક્તિ

હુકનો નિયમ અનુસાર, સ્પ્રિંગ દ્વારા લાગુ પડતી પુનઃસ્થાપિત બળ F = -kx છે, જ્યાં k સ્પ્રિંગ નિયતાંક અને x વિસ્થાપન છે. લવચીક શક્તિ ઉર્જા (PE) = ½kx² છે.

  • F = -kx (નેગેટિવ ચિહ્ન દિશા દર્શાવે છે).
  • PE = ½kx² (સ્પ્રિંગમાં સંગ્રહિત ઉર્જા).
  • k નું મૂલ્ય સ્પ્રિંગના પદાર્થ અને જાડાઈ પર આધાર રાખે છે.
  • હુકનો નિયમ લીનિયર ઇલાસ્ટિસિટી માટે લાગુ પડે છે.
🧠 Trick: F = kx ને 'ફોર્સ કિક્સ એક્સ' તરીકે યાદ રાખો.

સ્પ્રિંગનો સરળ આંદોલન (SHM)

સ્પ્રિંગ-માસ સિસ્ટમ સરળ આંદોલન (SHM) કરે છે જ્યારે તેને વિસ્થાપિત કરી મુક્ત કરવામાં આવે. આંદોલનનો સમયગાળો T = 2π√(m/k) છે, જ્યાં m દળ અને k સ્પ્રિંગ નિયતાંક છે.

  • SHM માટે વેગ a = -ω²x, જ્યાં ω = √(k/m).
  • અવર્તન કંપવિસ્તાર (Amplitude) પર આધાર રાખતું નથી.
  • સમયગાળો T = 2π√(m/k).
  • ઊર્જા સંરક્ષણ: KE + PE = નિયત.
🧠 Trick: T = 2π√(m/k) ને 'ટૂ પાઈ રૂટ મી ઓવર કે' તરીકે યાદ રાખો.

સ્પ્રિંગની શ્રેણી અને સમાંતર જોડણી

સ્પ્રિંગની શ્રેણી જોડણીમાં, સમતુલ્ય સ્પ્રિંગ નિયતાંક k_eq = 1/(1/k₁ + 1/k₂ + ...). સમાંતર જોડણીમાં, k_eq = k₁ + k₂ + ... છે.

  • શ્રેણીમાં k_eq < કોઈ પણ એક k.
  • સમાંતરમાં k_eq > કોઈ પણ એક k.
  • શ્રેણીમાં વિસ્થાપન સરખું વહેંચાય છે.
  • સમાંતરમાં બળ વહેંચાય છે.
🧠 Trick: શ્રેણી = 1/k, સમાંતર = k + k.

સ્પ્રિંગમાં ઉર્જા અને કાર્ય

સ્પ્રિંગ દ્વારા કરવામાં આવતું કાર્ય W = ½k(x₂² - x₁²) છે. સ્પ્રિંગમાં સંગ્રહિત ઉર્જા તેના વિસ્થાપનના વર્ગના સમપ્રમાણમાં હોય છે.

  • કાર્ય = ΔPE = ½k(Δx)².
  • સ્પ્રિંગ દ્વારા કરેલ કાર્ય નેગેટિવ હોય છે જ્યારે તે સંકોચાય છે.
  • ઉર્જા સંરક્ષણનો નિયમ લાગુ પડે છે.
  • સ્પ્રિંગની મહત્તમ ઉર્જા મહત્તમ વિસ્થાપન (Amplitude) પર હોય છે.

સ્પ્રિંગના અનુપ્રયોગો

સ્પ્રિંગનો ઉપયોગ વાહનના સસ્પેન્શન, ઘડિયાળ, બંદૂકના ટ્રિગર, અને મશીનરીમાં થાય છે. તે યાંત્રિક ઉર્જાનું સંગ્રહણ અને મુક્તિ કરવા માટે ઉપયોગી છે.

  • વાહનના સસ્પેન્શનમાં શોક અબ્ઝોર્બર તરીકે.
  • ઘડિયાળમાં સમયની ગણતરી માટે.
  • બંદૂકમાં ગોળી છોડવા માટે.
  • મશીનરીમાં ગતિ નિયંત્રણ માટે.

⚡ Quick Revision

  • સ્પ્રિંગ હુકના નિયમ F = -kx અનુસરે છે.
  • લવચીક શક્તિ ઉર્જા PE = ½kx² છે.
  • SHMનો સમયગાળો T = 2π√(m/k) છે.
  • શ્રેણી જોડણીમાં k_eq = 1/(1/k₁ + 1/k₂).
  • સમાંતર જોડણીમાં k_eq = k₁ + k₂.
  • સ્પ્રિંગ દ્વારા કરેલ કાર્ય W = ½k(x₂² - x₁²) છે.
  • સ્પ્રિંગની મહત્તમ ઉર્જા મહત્તમ વિસ્થાપન પર હોય છે.
  • હુકનો નિયમ લીનિયર ઇલાસ્ટિસિટી માટે લાગુ પડે છે.
  • સ્પ્રિંગ-માસ સિસ્ટમ SHM કરે છે.
  • સ્પ્રિંગનો ઉપયોગ યાંત્રિક ઉર્જા સંગ્રહણ માટે થાય છે.
🎯 Exam Tip: હુકના નિયમ અને SHMના સૂત્રોને યાદ રાખો, અને સ્પ્રિંગની જોડણીના પ્રશ્નોમાં k_eqની ગણતરી કરવા માટે શ્રેણી અને સમાંતરના સૂત્રોનો ઉપયોગ કરો.
