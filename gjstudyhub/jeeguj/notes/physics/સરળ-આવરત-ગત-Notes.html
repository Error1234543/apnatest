સરળ આવર્ત ગતિ

📖 સરળ આવર્ત ગતિ (Simple Harmonic Motion - SHM)

પરિભાષા અને મૂળભૂત સંકલ્પના

સરળ આવર્ત ગતિમાં કણ સંતુલન સ્થાન આસપાસ સરળ રેખામાં ગતિ કરે છે, જ્યાં પુનઃસ્થાપક બળ સ્થાનાંતરના સમપ્રમાણમાં અને વિરુદ્ધ દિશામાં હોય છે. F = -kx (હૂકનો નિયમ), જ્યાં k = બળ અચળાંક, x = સ્થાનાંતર. આ ગતિ આવર્ત, દોલનાત્મક અને સરળ હોય છે.

  • F = -kx (હૂકનો નિયમ)
  • સંતુલન સ્થાન આસપાસની ગતિ
  • પુનઃસ્થાપક બળ સ્થાનાંતરના વ્યસ્ત પ્રમાણમાં
  • દોલનાત્મક અને આવર્ત ગતિ
🧠 Trick: SHM = સદા હૂક મુજબ મળે

વિસ્થાપન, વેગ અને પ્રવેગ

વિસ્થાપન x = A sin(ωt + φ), જ્યાં A = આયામ, ω = કોણીય વેગ, φ = કળા અચળાંક. વેગ v = ω√(A² - x²), પ્રવેગ a = -ω²x. મહત્તમ વેગ v_max = Aω (સંતુલન સ્થાને), મહત્તમ પ્રવેગ a_max = Aω² (ચરમ સ્થાને).

  • x = A sin(ωt + φ)
  • v = ω√(A² - x²)
  • a = -ω²x
  • v_max = Aω (સંતુલન સ્થાને)
  • a_max = Aω² (ચરમ સ્થાને)
🧠 Trick: સિન વેગ પ્રવેગ = સિન, વેલો, એક્સેલરેશન

આવર્ત કાળ અને આવૃત્તિ

આવર્ત કાળ T = 2π/ω = 2π√(m/k) (સ્પ્રિંગ-માસ સિસ્ટમ માટે). આવૃત્તિ f = 1/T = ω/2π. કોણીય વેગ ω = √(k/m). આવર્ત કાળ કંપનના આયામ પર આધાર રાખતો નથી (આઇસોક્રોનિઝમ).

  • T = 2π√(m/k)
  • f = 1/T
  • ω = √(k/m)
  • T આયામ પર આધારિત નથી
🧠 Trick: ટી એમ/કે ના વર્ગમૂળ

ઊર્જા સરળ આવર્ત ગતિમાં

કુલ યાંત્રિક ઊર્જા E = 1/2 kA² (અચળ). ગતિઊર્જા KE = 1/2 mv² = 1/2 k(A² - x²). સ્થિતિઊર્જા PE = 1/2 kx². ચરમ સ્થાને PE મહત્તમ, KE શૂન્ય; સંતુલન સ્થાને KE મહત્તમ, PE શૂન્ય.

  • E = 1/2 kA² (અચળ)
  • KE = 1/2 k(A² - x²)
  • PE = 1/2 kx²
  • ચરમ સ્થાને PE મહત્તમ, KE = 0
  • સંતુલન સ્થાને KE મહત્તમ, PE = 0
🧠 Trick: એનર્જી = કેપી + કેઈ = કેપી એ સ્ક્વેર

સરળ લોલક અને તેની ગતિ

સરળ લોલકનો આવર્ત કાળ T = 2π√(L/g), જ્યાં L = લંબાઈ, g = ગુરુત્વપ્રવેગ. આ ગતિ SHM હોય છે જ્યારે કોણ θ ખૂબ જ નાનો હોય (θ ≈ sinθ). લોલકની ગતિ માટે પુનઃસ્થાપક બળ mg sinθ ≈ mgθ હોય છે.

  • T = 2π√(L/g)
  • θ નાનો હોય ત્યારે SHM
  • પુનઃસ્થાપક બળ ≈ mgθ
  • g નક્કી કરવા લોલક ઉપયોગી
🧠 Trick: લોલક ટી = ટુ પાઇ રૂટ એલ ઓવર જી

સરળ આવર્ત ગતિ અને વર્તુળ ગતિનો સંબંધ

SHM એ વર્તુળ ગતિની પ્રક્ષેપણ છે. જ્યારે કણ વર્તુળ ગતિ કરે છે, ત્યારે તેના પ્રક્ષેપણ (x અથવા y દિશામાં) SHM થાય છે. વર્તુળ ગતિની કોણીય વેગ ω SHM ની કોણીય આવૃત્તિ બરાબર હોય છે.

  • SHM = વર્તુળ ગતિનું પ્રક્ષેપણ
  • વર્તુળ ગતિની ω = SHM ની ω
  • x = A cos(ωt), y = A sin(ωt)
🧠 Trick: વર્તુળ શેડો SHM

અનુપ્રયોગિક ઉદાહરણો

સ્પ્રિંગ-માસ સિસ્ટમ, સરળ લોલક, U-ટ્યુબમાં દ્રવનો દોલન, વિદ્યુત ચુંબકીય દોલન (LC પરિપથ). આ બધા SHM ના ઉદાહરણો છે જ્યાં પુનઃસ્થાપક બળ F = -kx ના રૂપમાં હોય છે.

  • સ્પ્રિંગ-માસ સિસ્ટમ
  • સરળ લોલક
  • U-ટ્યુબ દોલન
  • LC પરિપથ

⚡ Quick Revision

  • SHM = F = -kx (હૂકનો નિયમ)
  • x = A sin(ωt + φ), v = ω√(A² - x²), a = -ω²x
  • T = 2π√(m/k) (સ્પ્રિંગ-માસ), T = 2π√(L/g) (લોલક)
  • E = 1/2 kA² (કુલ ઊર્જા અચળ)
  • ચરમ સ્થાને PE મહત્તમ, KE = 0; સંતુલન સ્થાને KE મહત્તમ, PE = 0
  • SHM = વર્તુળ ગતિનું પ્રક્ષેપણ
  • આવર્ત કાળ આયામ પર આધારિત નથી
  • સરળ લોલક માટે θ નાનો હોય ત્યારે SHM
  • LC પરિપથમાં વિદ્યુત દોલન SHM છે
  • પુનઃસ્થાપક બળ સ્થાનાંતરના વ્યસ્ત પ્રમાણમાં
🎯 Exam Tip: SHM ના પ્રશ્નોમાં હંમેશા હૂકનો નિયમ (F = -kx) અને આવર્ત કાળના સૂત્ર (T = 2π√(m/k) અથવા T = 2π√(L/g)) યાદ રાખો. ઊર્જા અને વેગ-પ્રવેગના સંબંધો પર ધ્યાન આપો.
