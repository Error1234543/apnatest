તાપમાન

📖 તાપમાન

તાપમાનની વ્યાખ્યા અને મહત્વ

તાપમાન એ પદાર્થના કણોની સરેરાશ ગતિજ ઉર્જાનું માપ છે. તે ઉષ્મા સ્થાનાંતરણની દિશા નક્કી કરે છે — ઉચ્ચ તાપમાનથી નીચા તાપમાન તરફ ઉષ્મા પ્રવાહિત થાય. JEEમાં તાપમાનની સંકલ્પના ફરજિયાત છે કેમ કે તે ઉષ્માગતિશાસ્ત્ર, ગેસના નિયમો અને થર્મોડાયનેમિક્સના મૂળભૂત સિદ્ધાંતો સાથે જોડાયેલી છે.

  • તાપમાન = કણોની સરેરાશ ગતિજ ઉર્જાનું માપ
  • ઉષ્મા હંમેશા ઉચ્ચ તાપમાનથી નીચા તરફ વહે
  • તાપમાન એ સ્કેલર રાશિ છે, દિશા ધરાવતી નથી
  • ઉષ્માગતિશાસ્ત્રનો પાયો તાપમાન પર આધારિત છે

તાપમાનના માપન પદ્ધતિઓ

તાપમાન માપવા માટે સેલ્સિયસ, ફેરનહીટ અને કેલ્વિન સ્કેલ વપરાય છે. કેલ્વિન સ્કેલ વૈજ્ઞાનિક કામગીરીમાં પ્રાથમિક છે કેમ કે તે મૂળભૂત રાશિ છે અને 0 K એ પરમ શૂન્ય તાપમાન દર્શાવે છે જ્યાં કણોની ગતિ શૂન્ય થાય છે. સેલ્સિયસ સ્કેલમાં 0°C એ બરફનો ગલનબિંદુ અને 100°C એ પાણીનો ઉત્કલનબિંદુ છે.

  • કેલ્વિન (K) = સેલ્સિયસ (C) + 273.15
  • ફેરનહીટ (F) = (9/5)C + 32
  • 0 K = પરમ શૂન્ય, કણોની ગતિ શૂન્ય
  • JEEમાં કેલ્વિન સ્કેલનો ઉપયોગ ગેસના નિયમો માટે ફરજિયાત
🧠 Trick: કેલ્વિન = સેલ્સિયસ + 273 (કેફી સોનાની 273)

તાપમાન અને ગેસના નિયમો

આદર્શ ગેસના નિયમોમાં તાપમાન મહત્વની ભૂમિકા ભજવે છે. બોયલનો નિયમ (PV = કોણસ્થ, T કોણસ્થ), ચાર્લ્સનો નિયમ (V ∝ T, P કોણસ્થ) અને ગેઈ-લ્યુસેકનો નિયમ (P ∝ T, V કોણસ્થ) તાપમાન પર આધારિત છે. આદર્શ ગેસ સમીકરણ PV = nRTમાં T હંમેશા કેલ્વિનમાં લેવામાં આવે.

  • બોયલનો નિયમ: PV = કોણસ્થ (T કોણસ્થ)
  • ચાર્લ્સનો નિયમ: V/T = કોણસ્થ (P કોણસ્થ)
  • ગેઈ-લ્યુસેકનો નિયમ: P/T = કોણસ્થ (V કોણસ્થ)
  • PV = nRTમાં T = કેલ્વિનમાં જ લેવું
  • આદર્શ ગેસ સમીકરણમાં R = 8.314 J/mol·K
🧠 Trick: PV = nRT → પીવી એન આર ટી (પરીક્ષામાં યાદ રાખો T = K)

તાપમાન અને ઉષ્મા વહન

ઉષ્મા વહનની ત્રણ પદ્ધતિઓ — ચાલન, સંવહન અને વિકિરણ — તાપમાનના તફાવત પર આધારિત છે. ચાલનમાં ઉષ્મા સીધી સંપર્કથી વહે છે, સંવહનમાં પ્રવાહી અથવા વાયુના પ્રવાહ દ્વારા થાય છે, અને વિકિરણમાં ઉર્જા વિદ્યુતચુંબકીય તરંગો દ્વારા પ્રસરે છે.

  • ચાલન: ઉષ્મા સીધી સંપર્કથી વહે (ઉદા. લોખંડની છડી)
  • સંવહન: પ્રવાહી/વાયુના પ્રવાહ દ્વારા (ઉદા. પાણી ગરમ થવું)
  • વિકિરણ: વિદ્યુતચુંબકીય તરંગો દ્વારા (ઉદા. સૂર્યની ઉર્જા)
  • તાપમાનનો તફાવત વિના ઉષ્મા વહન થતું નથી
🧠 Trick: ચાલન-સંપર્ક, સંવહન-પ્રવાહ, વિકિરણ-તરંગ

તાપમાન અને થર્મોડાયનેમિક્સ

થર્મોડાયનેમિક્સના પહેલા નિયમ મુજબ, ΔU = Q - W, જ્યાં ΔU એ આંતરિક ઉર્જામાં ફેરફાર, Q એ ઉષ્મા અને W એ કામ છે. તાપમાન આંતરિક ઉર્જા સાથે સીધો સંબંધ ધરાવે છે. થર્મોડાયનેમિક્સના શૂન્યમાના નિયમ મુજબ, જો બે પદાર્થો ત્રીજા પદાર્થ સાથે ઉષ્મીય સંતુલનમાં હોય, તો તેઓ એકબીજા સાથે પણ સંતુલનમાં હશે.

  • ΔU = Q - W (થર્મોડાયનેમિક્સનો પહેલો નિયમ)
  • શૂન્યમાનો નિયમ: A અને B સંતુલનમાં, B અને C સંતુલનમાં → A અને C સંતુલનમાં
  • તાપમાન એ ઉષ્મીય સંતુલનનું માપ છે
  • થર્મોડાયનેમિક્સમાં તાપમાન હંમેશા કેલ્વિનમાં લેવું
🧠 Trick: ΔU = Q - W → દુ:ખ (ΔU) = કમ (Q) - કામ (W)

તાપમાન અને કેપેસિટી

ઉષ્મા કેપેસિટી (C) એ પદાર્થને ગરમ કરવા માટે જરૂરી ઉષ્માની માત્રા છે, જ્યારે વિશિષ્ટ ઉષ્મા કેપેસિટી (c) એ એક ગ્રામ પદાર્થને 1°C ગરમ કરવા માટે જરૂરી ઉર્જા છે. Q = mcΔT સૂત્ર દ્વારા ઉષ્મા, દળ, વિશિષ્ટ ઉષ્મા કેપેસિટી અને તાપમાન ફેરફાર વચ્ચેનો સંબંધ દર્શાવે છે.

  • Q = mcΔT (ઉષ્મા સૂત્ર)
  • વિશિષ્ટ ઉષ્મા કેપેસિટી (c) = ઉર્જા/(દળ × ΔT)
  • ઉષ્મા કેપેસિટી (C) = mc
  • પાણીની વિશિષ્ટ ઉષ્મા કેપેસિટી = 4.18 J/g·°C
🧠 Trick: Q = m c ΔT → ક્યુ એમ સી ડેલ્ટા ટી (કમ સી ડેલ્ટા ટી)
