સ્થિર તરંગો

📖 સ્થિર તરંગો

પરિભાષા અને ઉદ્ભવ

સ્થિર તરંગો એ ટ્રાવેલિંગ તરંગોના સુપરપોઝિશન દ્વારા ઉત્પન્ન થતા તરંગો છે, જ્યારે બે સરખી આવૃત્તિ અને વેગવાળા તરંગો વિપરીત દિશામાં ગતિ કરે છે. આ તરંગોમાં કણોના કંપનની દિશા અને તરંગના પ્રસારની દિશા લંબરૂપ હોય છે.

  • સ્થિર તરંગો = ટ્રાવેલિંગ તરંગોનું સુપરપોઝિશન (વિપરીત દિશા, સરખી આવૃત્તિ, સરખો આંપ્લિટ્યુડ)
  • કણોના કંપન અને તરંગ પ્રસારની દિશા લંબરૂપ હોય છે
  • ઊર્જાનો પ્રસાર થતો નથી, પરંતુ કણો ઊર્જા ધરાવે છે
  • સ્થિર તરંગોમાં નોડ (N) અને એન્ટીનોડ (A) બિંદુઓ બને છે
🧠 Trick: સ્થિર = સ્થાને રહે, નોડ-એન્ટીનોડ = ના-હા

નોડ અને એન્ટીનોડ

નોડ એ સ્થિર તરંગના બિંદુઓ છે જ્યાં કણોનું વિસ્થાપન શૂન્ય હોય છે, જ્યારે એન્ટીનોડ એ બિંદુઓ છે જ્યાં કણોનું વિસ્થાપન મહત્તમ હોય છે. નોડ વચ્ચેનું અંતર λ/2 હોય છે, જ્યારે નોડ અને એન્ટીનોડ વચ્ચેનું અંતર λ/4 હોય છે.

  • નોડ (N): વિસ્થાપન = 0, કંપન = 0
  • એન્ટીનોડ (A): વિસ્થાપન = મહત્તમ, કંપન = મહત્તમ
  • નોડ-નોડ અંતર = λ/2
  • નોડ-એન્ટીનોડ અંતર = λ/4
  • એન્ટીનોડ-એન્ટીનોડ અંતર = λ/2
🧠 Trick: નોડ = ના (નહીં હલે), એન્ટીનોડ = હા (હલે મહત્તમ)

સ્થિર તરંગોના પ્રકાર

સ્થિર તરંગો બે પ્રકારના હોય છે: 1) ખુલ્લા છેડાવાળા તારમાં (બંને છેડા મુક્ત) અને 2) બંધ છેડાવાળા તારમાં (એક છેડો બંધ, એક મુક્ત). ખુલ્લા છેડાવાળા તારમાં એન્ટીનોડ બને છે, જ્યારે બંધ છેડાવાળા તારમાં નોડ બને છે.

  • ખુલ્લા છેડા: એન્ટીનોડ બને (વિસ્થાપન મહત્તમ)
  • બંધ છેડા: નોડ બને (વિસ્થાપન 0)
  • ખુલ્લા-ખુલ્લા તાર: લંબાઈ L = nλ/2 (n=1,2,3...)
  • બંધ-ખુલ્લા તાર: L = (2n-1)λ/4 (n=1,2,3...)
  • બંધ-બંધ તાર: L = nλ/2 (n=1,2,3...)
🧠 Trick: ખુલ્લા = હા (એન્ટીનોડ), બંધ = ના (નોડ)

આવૃત્તિ અને તરંગલંબાઇ

સ્થિર તરંગોની આવૃત્તિ તારની લંબાઈ, તણાવ અને દળ પ્રતિ એકમ લંબાઈ પર આધારિત હોય છે. મૂળ આવૃત્તિ (f₀) એ સૌથી નીચી આવૃત્તિ હોય છે, જ્યારે હાર્મોનિક્સ એ મૂળ આવૃત્તિના પૂરક હોય છે (fₙ = nf₀).

  • મૂળ આવૃત્તિ f₀ = v/(2L) (ખુલ્લા-ખુલ્લા તાર)
  • હાર્મોનિક્સ: fₙ = nf₀ (n=1,2,3...)
  • તણાવ T અને દળ પ્રતિ લંબાઈ μ: v = √(T/μ)
  • બંધ-ખુલ્લા તાર: fₙ = (2n-1)f₀/2 (n=1,2,3...)
  • તરંગલંબાઇ λ = v/f

ઊર્જા અને શક્તિ

સ્થિર તરંગોમાં ઊર્જાનો પ્રસાર થતો નથી, પરંતુ કણો પાસે ગતિ ઊર્જા અને સ્થિતિ ઊર્જા હોય છે. એન્ટીનોડ પર ગતિ ઊર્જા મહત્તમ અને સ્થિતિ ઊર્જા શૂન્ય હોય છે, જ્યારે નોડ પર સ્થિતિ ઊર્જા મહત્તમ અને ગતિ ઊર્જા શૂન્ય હોય છે.

  • સ્થિર તરંગોમાં ઊર્જાનો પ્રસાર થતો નથી
  • એન્ટીનોડ: ગતિ ઊર્જા = મહત્તમ, સ્થિતિ ઊર્જા = 0
  • નોડ: સ્થિતિ ઊર્જા = મહત્તમ, ગતિ ઊર્જા = 0
  • કુલ ઊર્જા સ્થિર રહે છે (સંરક્ષણનો નિયમ)
  • ઊર્જા ઘનતા એન્ટીનોડ પર મહત્તમ હોય છે
🧠 Trick: એન્ટીનોડ = ગતિ (હલે), નોડ = સ્થિતિ (ઠરે)

ઉદાહરણો અને અપલિકેશન્સ

સ્થિર તરંગોના ઉદાહરણોમાં ગિટારના તાર, ઓર્ગન પાઇપ્સ, અને રેડિયો એન્ટેનાનો સમાવેશ થાય છે. આ તરંગોનો ઉપયોગ સંગીત વાદ્યો, ટેલિકોમ્યુનિકેશન અને સોનાર ટેક્નોલોજીમાં થાય છે.

  • ગિટારના તાર: ખુલ્લા-ખુલ્લા તાર જેવા સ્થિર તરંગો
  • ઓર્ગન પાઇપ્સ: બંધ-ખુલ્લા અથવા બંધ-બંધ તરંગો
  • રેડિયો એન્ટેના: સ્થિર તરંગો દ્વારા સિગ્નલ ટ્રાન્સમિશન
  • સોનાર: પાણી અંદર સ્થિર તરંગો દ્વારા અંતર માપવું
  • માઇક્રોવેવ ઓવન: સ્થિર તરંગો દ્વારા ખોરાક ગરમ કરવો

⚡ Quick Revision

  • સ્થિર તરંગો = ટ્રાવેલિંગ તરંગોનું સુપરપોઝિશન (વિપરીત દિશા, સરખી આવૃત્તિ)
  • નોડ = વિસ્થાપન 0, એન્ટીનોડ = વિસ્થાપન મહત્તમ
  • નોડ-નોડ અંતર = λ/2, નોડ-એન્ટીનોડ અંતર = λ/4
  • ખુલ્લા છેડા = એન્ટીનોડ, બંધ છેડા = નોડ
  • મૂળ આવૃત્તિ f₀ = v/(2L) (ખુલ્લા-ખુલ્લા તાર)
  • હાર્મોનિક્સ: fₙ = nf₀ (n=1,2,3...)
  • બંધ-ખુલ્લા તાર: L = (2n-1)λ/4
  • એન્ટીનોડ: ગતિ ઊર્જા મહત્તમ, નોડ: સ્થિતિ ઊર્જા મહત્તમ
  • ઊર્જાનો પ્રસાર થતો નથી, પરંતુ કણો ઊર્જા ધરાવે છે
  • વેગ v = √(T/μ) (તણાવ T, દળ પ્રતિ લંબાઈ μ)
🎯 Exam Tip: સ્થિર તરંગોના પ્રશ્નોમાં નોડ અને એન્ટીનોડની સ્થિતિ, આવૃત્તિ અને તરંગલંબાઇના સંબંધો, તેમજ તારની લંબાઈ અને હાર્મોનિક્સના સંબંધો પર ધ્યાન આપો. ગણતરીમાં λ/2 અને λ/4ના અંતરો યાદ રાખો.
