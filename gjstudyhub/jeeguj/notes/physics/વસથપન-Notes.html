વિસ્થાપન

📖 વિસ્થાપન

વિસ્થાપનની મૂળભૂત સમજ

વિસ્થાપન એ વસ્તુ દ્વારા કાપેલા મૂળ બિંદુથી અંતિમ બિંદુ સુધીના સીધા રેખામાંના અંતરને કહે છે. તે એક સદિશ રાશિ છે, જેમાં પરિમાણ અને દિશા બંને હોય છે. તે સમય સાથે બદલાતું નથી, ફક્ત પ્રારંભિક અને અંતિમ સ્થાન પર આધાર રાખે છે.

  • વિસ્થાપન એ સદિશ રાશિ છે (પરિમાણ + દિશા).
  • તે મૂળ બિંદુથી અંતિમ બિંદુ સુધીનો સીધો અંતર છે.
  • વિસ્થાપનનું મૂલ્ય કાપેલા પથની લંબાઈ કરતાં ઓછું અથવા સમાન હોઈ શકે.
  • જો વસ્તુ પોતાની મૂળ સ્થિતિએ પાછી આવે તો વિસ્થાપન શૂન્ય હોય છે.
🧠 Trick: વિસ્થાપન = અંતિમ - પ્રારંભિક (સ્થાન સદિશ)

વિસ્થાપન અને અંતરમાં તફાવત

અંતર એ કાપેલા પથની કુલ લંબાઈ છે, જ્યારે વિસ્થાપન એ પ્રારંભિક અને અંતિમ બિંદુ વચ્ચેનો સીધો અંતર છે. અંતર હમેશા ધન હોય છે, જ્યારે વિસ્થાપન ધન, ઋણ અથવા શૂન્ય હોઈ શકે.

  • અંતર = કાપેલા પથની કુલ લંબાઈ (અદિશ રાશિ).
  • વિસ્થાપન = સીધો અંતર (સદિશ રાશિ).
  • અંતર ≥ વિસ્થાપનનું પરિમાણ.
  • અંતર ક્યારેય ઋણ નથી, વિસ્થાપન ઋણ હોઈ શકે.
🧠 Trick: અંતર = પથ, વિસ્થાપન = સીધું

વિસ્થાપનનો ગણિતી સ્વરૂપ

વિસ્થાપન સદિશ રૂપે Δr = r_f - r_i તરીકે વ્યાખ્યાયિત થાય છે, જ્યાં r_f અંતિમ સ્થાન સદિશ અને r_i પ્રારંભિક સ્થાન સદિશ છે. દ્વિપરિમાણમાં, Δr = Δx i + Δy j તરીકે લખી શકાય છે.

  • Δr = r_f - r_i (સદિશ સ્વરૂપ).
  • દ્વિપરિમાણમાં: Δr = √(Δx² + Δy²).
  • ત્રિપરિમાણમાં: Δr = √(Δx² + Δy² + Δz²).
  • દિશા θ = tan⁻¹(Δy/Δx) થી નક્કી થાય છે.

વિસ્થાપન-સમય આલેખ

વિસ્થાપન-સમય આલેખમાં, x-અક્ષ પર સમય અને y-અક્ષ પર વિસ્થાપન દર્શાવવામાં આવે છે. આ આલેખની ઢાળ ગતિના વેગને દર્શાવે છે. સરળ રેખીય ગતિ માટે, આ આલેખ સીધી રેખા હોય છે.

  • x-અક્ષ: સમય (t), y-અક્ષ: વિસ્થાપન (s).
  • ઢાળ = વેગ (v = ds/dt).
  • સરળ રેખીય ગતિ માટે આલેખ સીધી રેખા હોય છે.
  • ઢાળ ધન = વેગ ધન દિશામાં, ઢાળ ઋણ = વેગ ઋણ દિશામાં.
🧠 Trick: ઢાળ = વેગ, સીધી રેખા = સરળ ગતિ

વિસ્થાપન અને વેગનો સંબંધ

વેગ એ વિસ્થાપનના ફેરફારનો દર છે. v = Δs/Δt અથવા v = ds/dt. જો વિસ્થાપન સમય સાથે રેખીય રીતે બદલાતું હોય, તો વેગ સ્થિર હોય છે.

  • વેગ = વિસ્થાપનનો ફેરફાર / સમયનો ફેરફાર.
  • v = Δs/Δt (સરેરાશ વેગ).
  • a = dv/dt (પ્રવેગ).
  • સ્થિર વેગ માટે વિસ્થાપન-સમય આલેખ સીધી રેખા હોય છે.
🧠 Trick: વેગ = Δવિસ્થાપન / Δસમય

વિસ્થાપન અને પ્રવેગનો સંબંધ

પ્રવેગ એ વેગના ફેરફારનો દર છે. જો પ્રવેગ સ્થિર હોય, તો વિસ્થાપન સમયના વર્ગ સાથે બદલાતું હોય છે (s = ut + ½at²). વિસ્થાપન-સમય આલેખની ઢાળમાં ફેરફાર પ્રવેગને દર્શાવે છે.

  • પ્રવેગ = વેગનો ફેરફાર / સમયનો ફેરફાર.
  • s = ut + ½at² (સ્થિર પ્રવેગ માટે).
  • વિસ્થાપન-સમય આલેખની ઢાળમાં ફેરફાર = પ્રવેગ.
  • જો પ્રવેગ ધન હોય, તો ઢાળ વધે છે; જો પ્રવેગ ઋણ હોય, તો ઢાળ ઘટે છે.
🧠 Trick: s = ut + ½at² (સૂત્ર યાદ રાખો)

વિસ્થાપનના પ્રયોગિક ઉદાહરણો

વાસ્તવિક જીવનમાં, વિસ્થાપનના ઉદાહરણો જેમ કે વાહનની ગતિ, પ્રક્ષેપણની ગતિ, અથવા કોઈ વસ્તુની ગુરુત્વાકર્ષણ હેઠળ ગતિ જોવા મળે છે. આમાં વિસ્થાપન, વેગ અને પ્રવેગના સંબંધોનો ઉપયોગ થાય છે.

  • વાહનની ગતિમાં વિસ્થાપન = પ્રારંભિક સ્થાનથી અંતિમ સ્થાન સુધીનો સીધો અંતર.
  • પ્રક્ષેપણ ગતિમાં વિસ્થાપન = ક્ષેત્રીય અને ઉદ્ધવ દિશામાં.
  • ગુરુત્વાકર્ષણ હેઠળ ગતિમાં વિસ્થાપન = ઉદ્ધવ દિશામાં ઋણ પ્રવેગ સાથે.
  • વિસ્થાપનનો ઉપયોગ પથની લંબાઈ ગણતરી કરવા માટે થતો નથી.

⚡ Quick Revision

  • વિસ્થાપન એ સદિશ રાશિ છે (પરિમાણ + દિશા).
  • વિસ્થાપન = અંતિમ સ્થાન - પ્રારંભિક સ્થાન.
  • અંતર ≥ વિસ્થાપનનું પરિમાણ.
  • Δr = √(Δx² + Δy² + Δz²) (ત્રિપરિમાણમાં).
  • વિસ્થાપન-સમય આલેખની ઢાળ = વેગ.
  • વેગ = Δs/Δt, પ્રવેગ = Δv/Δt.
  • સ્થિર પ્રવેગ માટે s = ut + ½at².
  • જો વસ્તુ મૂળ સ્થાને પાછી આવે, વિસ્થાપન શૂન્ય.
  • વિસ્થાપન હમેશા પ્રારંભિક અને અંતિમ બિંદુ વચ્ચેનો સીધો અંતર હોય છે.
  • વિસ્થાપન-સમય આલેખની ઢાળમાં ફેરફાર = પ્રવેગ.
🎯 Exam Tip: વિસ્થાપન અને અંતર વચ્ચેનો તફાવત સ્પષ્ટ કરો. પરીક્ષામાં આ બંને શબ્દોનો ઉપયોગ સાવચેતીથી કરો, કારણ કે તેના પર અગણિત પ્રશ્નો આધારિત હોય છે.
