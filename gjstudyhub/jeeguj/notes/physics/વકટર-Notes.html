વેક્ટર

📖 વેક્ટર (Vector)

વેક્ટરની વ્યાખ્યા અને પ્રકાર

વેક્ટર એ સદિશ રાશિ છે જેને પરિમાણ અને દિશા બંને હોય છે. તેને ભૌતિક રાશિઓ જેવી કે વેગ, બળ, વિસ્થાપન વગેરે દર્શાવવા વપરાય છે. વેક્ટર બે પ્રકારના હોય છે: મુક્ત વેક્ટર (Free Vector) અને બંધાયેલ વેક્ટર (Bound Vector).

  • વેક્ટર = પરિમાણ + દિશા
  • મુક્ત વેક્ટરનો આરંભ બિંદુ કોઈપણ હોઈ શકે
  • બંધાયેલ વેક્ટરનો આરંભ બિંદુ નિશ્ચિત હોય છે
  • સદિશ રાશિનું ઉદાહરણ: વેગ, બળ, વિરોધ
🧠 Trick: વેક્ટર = વેગ + દિશા (વ + દ)

વેક્ટરનું પ્રતિનિધિત્વ

વેક્ટરને ગ્રાફિકલી તીરની મદદથી દર્શાવવામાં આવે છે જ્યાં તીરની લંબાઈ પરિમાણ અને તીરની દિશા દિશા દર્શાવે છે. ગાણિતિક રીતે, વેક્ટરને **A = |A| * n̂** તરીકે લખી શકાય છે જ્યાં |A| પરિમાણ અને n̂ એકમ વેક્ટર છે.

  • તીરની લંબાઈ = પરિમાણ
  • તીરની દિશા = વેક્ટરની દિશા
  • એકમ વેક્ટર (n̂)નું પરિમાણ 1 હોય છે
  • વેક્ટર A = |A| * n̂

વેક્ટરના મૂળભૂત કાયદા

વેક્ટરના સરવળમાં ત્રિકોણ નિયમ અને સમાન્તર ચતુષ્કોણ નિયમ મહત્વના છે. ત્રિકોણ નિયમ અનુસાર, બે વેક્ટરના સરવળ માટે પહેલા વેક્ટરનો અંત બિંદુ બીજા વેક્ટરના આરંભ બિંદુ સાથે જોડવો. સરવળ વેક્ટર પહેલા વેક્ટરના આરંભ બિંદુથી બીજા વેક્ટરના અંત બિંદુ સુધી હોય છે.

  • ત્રિકોણ નિયમ: A + B = C (A અને B ના સરવળ)
  • સમાન્તર ચતુષ્કોણ નિયમ: A + B = R (રાશિ અને દિશા)
  • વિજાતીય વેક્ટરનો સરવળ શૂન્ય હોઈ શકે
  • વેક્ટર સરવળ કમ્યુટેટિવ હોય છે (A + B = B + A)
🧠 Trick: ત્રિકોણ + ચતુષ્કોણ = સરવળ

વેક્ટરનું વિયોજન

કોઈપણ વેક્ટરને તેના ઘટકોમાં વિયોજિત કરી શકાય છે. સામાન્ય રીતે, વેક્ટરને X, Y, અને Z અક્ષ પર વિયોજિત કરવામાં આવે છે. વેક્ટર A = A_x î + A_y ĵ + A_z k̂ તરીકે લખી શકાય છે જ્યાં A_x, A_y, A_z તેના ઘટકો છે.

  • વેક્ટર = A_x î + A_y ĵ + A_z k̂
  • A_x = |A| cosθ_x (X-અક્ષ સાથેનો ખૂણો)
  • વેક્ટરના ઘટકો પાયથાગોરસ પ્રમેયથી શોધી શકાય
  • 3D વેક્ટરમાં ત્રણ ઘટકો હોય છે
🧠 Trick: X-Y-Z = î-ĵ-k̂

વેક્ટરનો સ્કેલર અને વેક્ટર ગુણાકાર

સ્કેલર ગુણાકારમાં વેક્ટરને સ્કેલર રાશિથી ગુણવામાં આવે છે, જ્યારે વેક્ટર ગુણાકારમાં બે વેક્ટર વચ્ચે ડોટ પ્રોડક્ટ અથવા ક્રોસ પ્રોડક્ટ લેવામાં આવે છે. ડોટ પ્રોડક્ટ સ્કેલર રાશિ આપે છે જ્યારે ક્રોસ પ્રોડક્ટ વેક્ટર રાશિ આપે છે.

  • સ્કેલર ગુણાકાર: k*A (k = સ્કેલર, A = વેક્ટર)
  • ડોટ પ્રોડક્ટ: A·B = |A||B|cosθ (θ = વચ્ચેનો ખૂણો)
  • ક્રોસ પ્રોડક્ટ: A×B = |A||B|sinθ n̂ (n̂ = લંબ દિશા)
  • ડોટ પ્રોડક્ટ શૂન્ય હોય તો વેક્ટર લંબ હોય છે
🧠 Trick: ડોટ = કોસ, ક્રોસ = સાઇન

વેક્ટર અને સ્કેલર રાશિઓ વચ્ચેનો તફાવત

સ્કેલર રાશિઓમાં ફક્ત પરિમાણ હોય છે જ્યારે વેક્ટર રાશિઓમાં પરિમાણ અને દિશા બંને હોય છે. ઉદાહરણ તરીકે, દળ (માસ) સ્કેલર છે જ્યારે બળ વેક્ટર છે.

  • સ્કેલર = ફક્ત પરિમાણ (ઉદા: દળ, તાપમાન)
  • વેક્ટર = પરિમાણ + દિશા (ઉદા: વેગ, બળ)
  • સ્કેલર રાશિઓનો સરવળ સાદો હોય છે
  • વેક્ટર રાશિઓનો સરવળ નિયમો અનુસાર થાય છે
🧠 Trick: સ્કેલર = સરળ, વેક્ટર = વેગવાન

વેક્ટરના અનુપ્રયોગો

વેક્ટરનો ઉપયોગ ભૌતિકશાસ્ત્ર, ગણિત અને અભિયાંત્રિકીમાં થાય છે. ભૌતિકશાસ્ત્રમાં વેક્ટરનો ઉપયોગ વેગ, ત્વરણ, બળ વગેરે દર્શાવવા માટે થાય છે. ગણિતમાં વેક્ટરનો ઉપયોગ જ્યોમેટ્રી અને કેલ્ક્યુલસમાં થાય છે.

  • ભૌતિકશાસ્ત્ર: વેગ, બળ, ત્વરણ
  • ગણિત: જ્યોમેટ્રી, કેલ્ક્યુલસ
  • અભિયાંત્રિકી: સ્થાનિક અને દિશાત્મક ગણતરીઓ
  • વેક્ટરનો ઉપયોગ 3D ગ્રાફિક્સમાં પણ થાય છે

  • વેક્ટર રાશિ = પરિમાણ + દિશા

🎯 Exam Tip: વેક્ટરના પ્રશ્નોમાં ગ્રાફિકલ અને ગાણિતિક પદ્ધતિઓ બંનેનો અભ્યાસ કરો. ડોટ અને ક્રોસ પ્રોડક્ટના ફોર્મ્યુલા યાદ રાખો અને તેનો ઉપયોગ કરતી વખતે ખૂણાનું ધ્યાન રાખો.
