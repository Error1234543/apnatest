Pro Notes

વિદ્યુત પ્રવાહ

📖 વિદ્યુત પ્રવાહ

વિદ્યુત પ્રવાહની વ્યાખ્યા અને એકમ

વિદ્યુત પ્રવાહ એ વહનશીલ કણો (ઇલેક્ટ્રોન, આયન)ની ગતિના દરને કહે છે. તેને અવરોધમાંથી પસાર થતાં વહનશીલ કણોના વહન દર તરીકે વ્યાખ્યાયિત કરવામાં આવે છે. SI એકમ એમ્પિયર (A) છે, જ્યાં 1 A = 1 C/s.

  • વિદ્યુત પ્રવાહ (I) = ΔQ/Δt
  • એમ્પિયર (A) એ પ્રવાહનો SI એકમ છે
  • પ્રવાહની દિશા ધન વહનશીલ કણોની ગતિની દિશામાં હોય છે
  • ઇલેક્ટ્રોનની ગતિ પ્રવાહની દિશાની વિરુદ્ધ હોય છે
🧠 Trick: A = C/s (એમ્પિયર = કુલંબ/સેકન્ડ)

વિદ્યુત પ્રવાહના પ્રકાર

વિદ્યુત પ્રવાહ બે પ્રકારના હોય છે: દિશ્ત પ્રવાહ (DC) અને પ્રત્યાવર્તી પ્રવાહ (AC). DCમાં પ્રવાહની દિશા સ્થિર હોય છે, જ્યારે ACમાં પ્રવાહની દિશા સમય સાથે બદલાતી રહે છે.

  • દિશ્ત પ્રવાહ (DC): બેટરી, કોષમાંથી મળે છે
  • પ્રત્યાવર્તી પ્રવાહ (AC): ઘરગથ્થુ વપરાશ માટે વપરાય છે
  • ACની આવર્તન (f) હર્ટઝ (Hz)માં માપવામાં આવે છે
  • DCનો ઉપયોગ ઇલેક્ટ્રોનિક્સ અને ચાર્જિંગમાં થાય છે
🧠 Trick: DC = Direct Current (સીધો), AC = Alternating Current (અટક-અટક)

ઓહમનો નિયમ

ઓહમનો નિયમ કહે છે કે, સ્થિર તાપમાને, વાહકમાંથી પસાર થતો વિદ્યુત પ્રવાહ (I) તેના બંને છેડા વચ્ચેના વિદ્યુત પોટેન્શિયલ તફાવત (V)ના સીધા પ્રમાણમાં હોય છે. V = IR, જ્યાં R એ અવરોધ છે.

  • V = IR (V = પોટેન્શિયલ તફાવત, I = પ્રવાહ, R = અવરોધ)
  • ઓહમનો નિયમ માત્ર ઓહમિક અવરોધો માટે લાગુ પડે છે
  • તાપમાન બદલાશે તો અવરોધ બદલાય છે
  • Rની એકમ ઓહમ (Ω) છે
🧠 Trick: VIR (V = I × R)

વિદ્યુત અવરોધ અને અવરોધકતા

વાહકનો અવરોધ (R) તેની લંબાઈ (L), કાપચી ક્ષેત્રફળ (A) અને અવરોધકતા (ρ) પર આધાર રાખે છે. R = ρL/A. અવરોધકતા એ પદાર્થની અંતર્ગત ગુણધર્મ છે જે તાપમાન પર આધાર રાખે છે.

  • R ∝ L (લંબાઈના સીધા પ્રમાણમાં)
  • R ∝ 1/A (કાપચી ક્ષેત્રફળના વ્યસ્ત પ્રમાણમાં)
  • ρ (રોપ) એ અવરોધકતાનો SI એકમ છે
  • તાપમાન વધે ત્યારે ધાતુઓનો અવરોધ વધે છે
🧠 Trick: R = ρL/A (રામ લખે અક્ષર)

વિદ્યુત શક્તિ અને ઉર્જા

વિદ્યુત શક્તિ (P) એ વિદ્યુત ઉર્જાનો વપરાશનો દર છે. P = VI = I²R = V²/R. વિદ્યુત ઉર્જા (E) એ શક્તિ અને સમયનો ગુણાકાર છે, E = Pt.

  • P = VI (વોલ્ટ × એમ્પિયર)
  • P = I²R (પ્રવાહનો વર્ગ × અવરોધ)
  • P = V²/R (વોલ્ટેજનો વર્ગ / અવરોધ)
  • વિદ્યુત ઉર્જાની એકમ kWh (કિલોવોટ-કલાક) છે

કિરચોફના નિયમો

કિરચોફના પ્રથમ નિયમ (જંકશન નિયમ) અનુસાર, કોઈપણ જંકશન પર આવતા પ્રવાહોનો સરવાળો જતા પ્રવાહોના સરવાળા જેટલો હોય છે. દ્વિતીય નિયમ (લૂપ નિયમ) અનુસાર, કોઈપણ બંધ લૂપમાં વોલ્ટેજનો અલજબ્રિક સરવાળો શૂન્ય હોય છે.

  • પ્રથમ નિયમ: ΣI_in = ΣI_out
  • દ્વિતીય નિયમ: ΣV = 0 (લૂપમાં)
  • લૂપ નિયમ ઓહમના નિયમ સાથે મળીને પરિપથો ઉકેલવા વપરાય છે
  • જંકશન નિયમ પ્રવાહના સંરક્ષણ પર આધારિત છે
🧠 Trick: KVL: કુલ વોલ્ટેજ લૂપમાં શૂન્ય, KCL: કુલ પ્રવાહ જંકશન પર સમાન

વિદ્યુત પ્રવાહના ચુંબકીય પ્રભાવ

વિદ્યુત પ્રવાહથી ચુંબકીય ક્ષેત્ર ઉત્પન્ન થાય છે. એમ્પિયરનો નિયમ અને બાયો-સેવાર્ટ નિયમ ચુંબકીય ક્ષેત્રની ગણતરી માટે વપરાય છે. પ્રવાહવાહક તારની આસપાસ ચુંબકીય ક્ષેત્રના વલયો બને છે.

  • એમ્પિયરનો નિયમ: ∮B·dl = μ₀I
  • બાયો-સેવાર્ટ નિયમ: dB = (μ₀/4π)(I dl sinθ)/r²
  • પ્રવાહની દિશા અને ચુંબકીય ક્ષેત્રની દિશા ડાબા હાથના નિયમથી નક્કી કરો
  • સોલેનોઈડમાં ચુંબકીય ક્ષેત્ર એકસમાન હોય છે
🧠 Trick: ડાબો હાથ, અંગૂઠો પ્રવાહ, આંગળીઓ ચુંબકીય ક્ષેત્ર

⚡ Quick Revision

  • વિદ્યુત પ્રવાહ = ΔQ/Δt, એકમ એમ્પિયર (A)
  • DC અને AC એ પ્રવાહના બે પ્રકાર છે
  • ઓહમનો નિયમ: V = IR
  • અવરોધ R = ρL/A
  • વિદ્યુત શક્તિ P = VI = I²R = V²/R
  • કિરચોફનો પ્રથમ નિયમ: ΣI_in = ΣI_out
  • કિરચોફનો દ્વિતીય નિયમ: ΣV = 0 (લૂપમાં)
  • એમ્પિયરનો નિયમ: ∮B·dl = μ₀I
  • ડાબા હાથનો નિયમ ચુંબકીય ક્ષેત્રની દિશા બતાવે છે
  • વિદ્યુત ઉર્જા E = Pt, એકમ kWh
🎯 Exam Tip: પરીક્ષામાં ઓહમના નિયમ અને કિરચોફના નિયમોનો ઉપયોગ કરીને પરિપથો ઉકેલવા પર ધ્યાન આપો. સરળતાથી ગણતરીઓ કરવા માટે એકમો અને સૂત્રો યાદ રાખો.
