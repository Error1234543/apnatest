ધારિતા

📖 ધારિતા (Capacitance)

ધારિતાની મૂળભૂત સમજ

ધારિતા એ વીજભાર સંગ્રહવાની ક્ષમતા છે. કેપેસિટર (સંધારિત્ર) એ બે ચાલક પ્લેટ્સ વચ્ચે ડાયલેક્ટ્રિક (પારાવૈદ્યુત) પદાર્થ રાખી બનાવેલ સરળ સાધન છે. ધારિતા C = Q/V થી વ્યાખ્યાયિત થાય, જ્યાં Q = ભાર, V = વોલ્ટેજ.

  • ધારિતા એ સ્કેલર રાશિ છે.
  • SI એકમ: ફેરેડ (F).
  • 1 F = 1 C/V.
  • કેપેસિટરમાં ભાર સંગ્રહાય છે, વીજઊર્જા સંગ્રહાય છે.
🧠 Trick: C = Q/V → 'ચાર્જ વોલ્ટેજને ભાગે'

કેપેસિટરના પ્રકારો

સમતલ પ્લેટ કેપેસિટર, ગોલાકાર કેપેસિટર, અને સિલિન્ડ્રિકલ કેપેસિટર એ મુખ્ય પ્રકારો છે. સમતલ પ્લેટ કેપેસિટર માટે C = ε₀A/d, જ્યાં A = પ્લેટનું ક્ષેત્રફળ, d = પ્લેટ વચ્ચેનું અંતર, ε₀ = મુક્ત અવકાશની પારાવૈદ્યુતતા.

  • સમતલ પ્લેટ: C ∝ A, C ∝ 1/d.
  • ડાયલેક્ટ્રિક ધરાવતો કેપેસિટર: C = κε₀A/d (κ = ડાયલેક્ટ્રિક અચળાંક).
  • ગોલાકાર કેપેસિટર: C = 4πε₀R₁R₂/(R₂ - R₁).
🧠 Trick: A ↑, d ↓ → C ↑ (પ્લેટ મોટી, અંતર ઓછું = ધારિતા વધે)

કેપેસિટરનું શ્રેણી અને સમાંતર જોડાણ

શ્રેણી જોડાણમાં 1/C_eq = 1/C₁ + 1/C₂ + ... + 1/Cₙ, સમાંતર જોડાણમાં C_eq = C₁ + C₂ + ... + Cₙ. શ્રેણીમાં વોલ્ટેજ વહેંચાય છે, સમાંતરમાં ભાર વહેંચાય છે.

  • શ્રેણી: વોલ્ટેજ વહેંચણી, સરખો ભાર.
  • સમાંતર: ભાર વહેંચણી, સરખું વોલ્ટેજ.
  • શ્રેણી C_eq < નાની C, સમાંતર C_eq > મોટી C.
🧠 Trick: શ્રેણી = 1/C, સમાંતર = C + C

કેપેસિટરમાં ઊર્જા

કેપેસિટરમાં સંગ્રહિત ઊર્જા U = ½CV² = ½QV = Q²/2C. આ ઊર્જા વીજક્ષેત્રમાં સંગ્રહિત થાય છે.

  • ઊર્જા વીજક્ષેત્રમાં સંગ્રહિત.
  • U ∝ C, U ∝ V².
  • કેપેસિટર ડિસ્ચાર્જ થતાં ઊર્જા ઉષ્મા રૂપે બહાર પડે.
🧠 Trick: U = ½ C V² → 'અડધી કેપેસિટી વોલ્ટેજ સ્ક્વેર'

ડાયલેક્ટ્રિક અને ધ્રુવણ

ડાયલેક્ટ્રિક પદાર્થ કેપેસિટરની ધારિતા વધારે છે. ડાયલેક્ટ્રિક અચળાંક κ = C'/C₀, જ્યાં C' = ડાયલેક્ટ્રિક સાથેની ધારિતા, C₀ = વગર ડાયલેક્ટ્રિકની ધારિતા. ડાયલેક્ટ્રિક ધ્રુવણથી વીજક્ષેત્ર કમજોર પડે છે.

  • κ > 1 હોવું જોઈએ.
  • ડાયલેક્ટ્રિક ધ્રુવણ: અણુઓ વીજક્ષેત્રની દિશામાં ગોઠવાય.
  • વીજક્ષેત્ર E = E₀/κ (E₀ = મુક્ત અવકાશનું ક્ષેત્ર).
🧠 Trick: κ → કેપેસિટર બૂસ્ટ કરે

RC પરિપથ અને ટાઇમ કૉન્સ્ટન્ટ

RC પરિપથમાં કેપેસિટર ચાર્જ/ડિસ્ચાર્જ થવાનો સમય ટાઇમ કૉન્સ્ટન્ટ τ = RC પર આધાર રાખે છે. τ એ સમય છે જ્યારે ભાર Q₀(1 - e⁻¹) થાય અથવા વોલ્ટેજ V₀(1 - e⁻¹) થાય.

  • τ = RC (ઓહમ × ફેરેડ = સેકન્ડ).
  • ચાર્જિંગ: Q(t) = Q₀(1 - e⁻ᵗ/τ).
  • ડિસ્ચાર્જિંગ: Q(t) = Q₀e⁻ᵗ/τ.
🧠 Trick: τ = RC → 'રેઝિસ્ટન્સ કેપેસિટર ટાઇમ'

વ્યાવહારિક ઉપયોગો

કેપેસિટરનો ઉપયોગ ફિલ્ટર પરિપથ, ઓસિલેટર, ટ્યુનિંગ પરિપથ, અને ઊર્જા સંગ્રહમાં થાય છે. મોબાઇલ, કમ્પ્યુટર, અને ઇલેક્ટ્રોનિક સાધનોમાં તે અગત્યનો છે.

  • ફિલ્ટર પરિપથ: ACને બ્લોક કરે, DC પસાર કરે.
  • ઓસિલેટર: ફ્રીક્વન્સી નિયંત્રણ.
  • ટ્યુનિંગ: રેડિયો ફ્રીક્વન્સી સેલેક્શન.

⚡ Quick Revision

  • ધારિતા C = Q/V, એકમ: ફેરેડ (F).
  • સમતલ પ્લેટ કેપેસિટર: C = ε₀A/d.
  • ડાયલેક્ટ્રિક સાથે: C = κε₀A/d.
  • શ્રેણી જોડાણ: 1/C_eq = Σ(1/C).
  • સમાંતર જોડાણ: C_eq = ΣC.
  • ઊર્જા: U = ½CV².
  • RC પરિપથ: τ = RC.
  • ડાયલેક્ટ્રિક ધ્રુવણ વીજક્ષેત્ર કમજોર કરે.
  • ચાર્જિંગ/ડિસ્ચાર્જિંગ: એક્સપોનેન્શિયલ વર્તન.
  • વ્યાવહારિક ઉપયોગ: ફિલ્ટર, ઓસિલેટર, ટ્યુનિંગ.
🎯 Exam Tip: ધારિતા અને RC પરિપથના પ્રશ્નોમાં સૂત્રો યાદ રાખો અને એકમોની ચકાસણી કરો (F = C/V, τ = RC → ઓહમ × ફેરેડ = સેકન્ડ).
