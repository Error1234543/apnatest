પ્રકાશનું અપવર્તન

📖 પ્રકાશનું અપવર્તન

અપવર્તનની મૂળભૂત સંકલ્પના

પ્રકાશનું અપવર્તન એટલે પ્રકાશકિરણનું એક માધ્યમથી બીજા માધ્યમમાં જતાં તેની દિશામાં થતો ફેરફાર. સ્નેલનો નિયમ (n₁sinθ₁ = n₂sinθ₂) અપવર્તન આંકના આધારે કોણની ગણતરી કરે છે, જ્યાં n માધ્યમનો અપવર્તનાંક છે.

  • સ્નેલનો નિયમ: n₁sinθ₁ = n₂sinθ₂
  • અપવર્તનાંક (n) = c/v (પ્રકાશની ઝડપ વેક્યૂમમાં / માધ્યમમાં)
  • ઘટ્ટ માધ્યમથી પાતળા માધ્યમ તરફ જતાં કિરણ દૂર થાય (θ₂ > θ₁)
  • પાતળા માધ્યમથી ઘટ્ટ તરફ જતાં કિરણ નજીક આવે (θ₂ < θ₁)
🧠 Trick: GHAT-PAT: ઘટ્ટ→પાતળ (દૂર), પાતળ→ઘટ્ટ (નજીક)

ક્રાંતિક કોણ અને પૂર્ણ આંતરિક પરાવર્તન

જ્યારે પ્રકાશ ઘટ્ટ માધ્યમથી પાતળા તરફ જાય અને આંતરિક કોણ ક્રાંતિક કોણ (θ_c) કરતાં મોટો હોય, ત્યારે પૂર્ણ આંતરિક પરાવર્તન થાય. θ_c = sin⁻¹(n₂/n₁), જ્યાં n₁ > n₂.

  • ક્રાંતિક કોણ: θ_c = sin⁻¹(n₂/n₁)
  • પૂર્ણ આંતરિક પરાવર્તનની શરત: θ_i > θ_c અને n₁ > n₂
  • ઓપ્ટિકલ ફાઇબર અને મણકામાં ઉપયોગ
  • મણકામાં પ્રકાશનો માર્ગ વક્રીભવન દર્શાવે છે
🧠 Trick: C > i → TIR (Critical > incidence → Total Internal Reflection)

લેન્સ અને અપવર્તન

લેન્સમાં અપવર્તનને કારણે પ્રકાશકિરણો એકબીજા તરફ અથવા દૂર થાય છે. ઉત્તલ લેન્સ (convex) કિરણોને એકત્ર કરે, જ્યારે અવતલ લેન્સ (concave) કિરણોને ફેલાવે છે. લેન્સના ફોકલ લંબાઈ (f) અને અપવર્તનાંક (n) વચ્ચે સંબંધ છે.

  • લેન્સમાળાનો સૂત્ર: 1/f = (n-1)(1/R₁ - 1/R₂)
  • ઉત્તલ લેન્સ: f > 0, અવતલ લેન્સ: f < 0
  • લેન્સની શક્તિ (P) = 1/f (ડાયોપ્ટરમાં)
  • પ્રતિબિંબની સ્થિતિ અને કદ લેન્સ સૂત્ર વડે નક્કી કરવામાં આવે

પ્રિઝમ અને વિક્ષેપણ

પ્રિઝમમાં પ્રકાશનું અપવર્તન અને વિક્ષેપણ થાય છે. વિક્ષેપણ એટલે શ્વેત પ્રકાશના રંગોનું વિભાજન, જે અલગ અલગ તરંગલંબાઇને કારણે થાય છે. પ્રિઝમનો વિક્ષેપણ કોણ (δ) પ્રિઝમના કોણ (A) અને અપવર્તનાંક પર આધાર રાખે છે.

  • વિક્ષેપણ: λ₁ < λ₂ ⇒ n₁ > n₂ ⇒ δ₁ > δ₂ (લાલ રંગ સૌથી ઓછું વિક્ષેપિત)
  • પ્રિઝમ સૂત્ર: n = sin[(A + δ_m)/2] / sin(A/2)
  • ન્યૂનતમ વિક્ષેપણ (δ_m) એ પ્રિઝમ કોણ A પર આધાર રાખે
  • રેઇનબોનું નિર્માણ વિક્ષેપણને કારણે થાય
🧠 Trick: VIBGYOR: વાયોલેટ (સૌથી વધુ વિક્ષેપણ) થી રેડ (સૌથી ઓછું)

કોમ્પાઉન્ડ માઇક્રોસ્કોપ અને ટેલિસ્કોપ

કોમ્પાઉન્ડ માઇક્રોસ્કોપ અને ટેલિસ્કોપમાં લેન્સના સંયોજન વડે પ્રતિબિંબનું વડું અને સ્પષ્ટ દર્શન મેળવવામાં આવે છે. માઇક્રોસ્કોપમાં વસ્તુ લેન્સ અને આંખ લેન્સનો ઉપયોગ થાય છે, જ્યારે ટેલિસ્કોપમાં વસ્તુ લેન્સ અને આંખ લેન્સ વચ્ચે ફોકલ લંબાઈનો તફાવત મહત્વનો છે.

  • માઇક્રોસ્કોપની વડાશ: m = m₁ × m₂ (વસ્તુ લેન્સ × આંખ લેન્સ)
  • ટેલિસ્કોપની વડાશ: m = fₒ / fₑ (વસ્તુ લેન્સ / આંખ લેન્સ)
  • ટેલિસ્કોપમાં પ્રકાશ એકત્ર કરવાની ક્ષમતા લેન્સના વ્યાસ પર આધાર રાખે
  • માઇક્રોસ્કોપમાં પ્રકાશનું પરાવર્તન અને અપવર્તન મહત્વનું

અપવર્તનાંક અને તરંગલંબાઇનો સંબંધ

અપવર્તનાંક (n) તરંગલંબાઇ (λ) પર આધાર રાખે છે. સામાન્ય રીતે, તરંગલંબાઇ ઘટતાં અપવર્તનાંક વધે છે (સીમા પ્રકાશ માટે n વધુ). આ કારણે પ્રિઝમમાં વિક્ષેપણ થાય છે, જ્યાં લાલ રંગ સૌથી ઓછું અને વાયોલેટ સૌથી વધુ વિક્ષેપિત થાય છે.

  • n ∝ 1/λ (લગભગ સંબંધ)
  • કૌશિક સૂત્ર: n = A + B/λ² (A, B અચળ)
  • વેક્યૂમમાં n = 1, હવા માટે n ≈ 1.0003
  • પાણી માટે n ≈ 1.33, કાચ માટે n ≈ 1.5

⚡ Quick Revision

  • સ્નેલનો નિયમ: n₁sinθ₁ = n₂sinθ₂
  • ક્રાંતિક કોણ: θ_c = sin⁻¹(n₂/n₁), પૂર્ણ આંતરિક પરાવર્તન માટે θ_i > θ_c
  • લેન્સમાળાનો સૂત્ર: 1/f = (n-1)(1/R₁ - 1/R₂)
  • લેન્સની શક્તિ: P = 1/f (ડાયોપ્ટર)
  • પ્રિઝમ સૂત્ર: n = sin[(A + δ_m)/2] / sin(A/2)
  • વિક્ષેપણ: VIBGYOR (વાયોલેટ થી રેડ)
  • માઇક્રોસ્કોપ વડાશ: m = m₁ × m₂
  • ટેલિસ્કોપ વડાશ: m = fₒ / fₑ
  • કૌશિક સૂત્ર: n = A + B/λ²
  • ઘટ્ટ માધ્યમથી પાતળા તરફ: કિરણ દૂર થાય
🎯 Exam Tip: પૂર્ણ આંતરિક પરાવર્તન અને ક્રાંતિક કોણના પ્રશ્નોમાં હંમેશા n₁ > n₂ની શરત ચકાસો, નહીં તો ગેરમાર્ગે જશો.
