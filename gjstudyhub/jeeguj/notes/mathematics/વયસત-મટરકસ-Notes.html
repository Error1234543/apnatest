વ્યસ્ત મેટ્રિક્સ

📖 વ્યસ્ત મેટ્રિક્સ (Inverse Matrix)

વ્યસ્ત મેટ્રિક્સની વ્યાખ્યા

વ્યસ્ત મેટ્રિક્સ એ વાસ્તવિક વર્ગ મેટ્રિક્સ Aની એવી મેટ્રિક્સ B છે કે જેથી AB = BA = I (એકમ મેટ્રિક્સ) થાય. વ્યસ્ત મેટ્રિક્સને A⁻¹ વડે દર્શાવવામાં આવે છે. વ્યસ્ત મેટ્રિક્સ અસ્તિત્વમાં ત્યારે જ હોય જ્યારે મેટ્રિક્સનો ડેટર્મિનન્ટ શૂન્ય ન હોય (non-singular મેટ્રિક્સ).

  • A⁻¹ અસ્તિત્વમાં હોય તો |A| ≠ 0
  • AB = I ⇒ B = A⁻¹
  • વ્યસ્ત મેટ્રિક્સ યુનિક હોય છે
  • વ્યસ્ત મેટ્રિક્સ ફક્ત વર્ગ મેટ્રિક્સ માટે જ વ્યાખ્યાયિત થાય છે

વ્યસ્ત મેટ્રિક્સના ગુણધર્મો

વ્યસ્ત મેટ્રિક્સના મહત્વપૂર્ણ ગુણધર્મો JEE માટે અત્યંત ઉપયોગી છે. આ ગુણધર્મો મેટ્રિક્સના ગણિતીય સંબંધોને સરળ બનાવે છે. ઉદાહરણ તરીકે, (AB)⁻¹ = B⁻¹A⁻¹ અને (Aᵀ)⁻¹ = (A⁻¹)ᵀ. વ્યસ્ત મેટ્રિક્સનો ઉપયોગ રેખીય સમીકરણોના સિસ્ટમને ઉકેલવા માટે થાય છે.

  • (AB)⁻¹ = B⁻¹A⁻¹
  • (A⁻¹)⁻¹ = A
  • (kA)⁻¹ = (1/k)A⁻¹, k ≠ 0
  • (Aᵀ)⁻¹ = (A⁻¹)ᵀ
  • A⁻¹A = AA⁻¹ = I
🧠 Trick: વ્યસ્તનો વ્યસ્ત મૂળ મેટ્રિક્સ

2×2 મેટ્રિક્સનો વ્યસ્ત

2×2 મેટ્રિક્સ A = [a b; c d]નો વ્યસ્ત A⁻¹ = (1/|A|) [d -b; -c a] થાય છે, જ્યાં |A| = ad - bc. આ ફોર્મ્યુલા JEEમાં વારંવાર ઉપયોગમાં લેવાય છે અને તેને ઓળખીને તરત જ લખી શકાય છે.

  • A = [a b; c d] ⇒ A⁻¹ = (1/ad-bc)[d -b; -c a]
  • |A| = ad - bc ≠ 0
  • સહગુણક મેટ્રિક્સનો ઉપયોગ
  • ડાયગોનલ મેટ્રિક્સનો વ્યસ્ત: ડાયગોનલ એલિમેન્ટ્સના વ્યસ્ત લો
🧠 Trick: સ્વેપ, ચેંજ સાઇન, ડિવાઇડ બાય ડેટર્મિનન્ટ

3×3 મેટ્રિક્સનો વ્યસ્ત

3×3 મેટ્રિક્સનો વ્યસ્ત શોધવા માટે સહગુણક મેટ્રિક્સ અને ડેટર્મિનન્ટનો ઉપયોગ કરવામાં આવે છે. A⁻¹ = (1/|A|) adj(A), જ્યાં adj(A) એ સહગુણક મેટ્રિક્સનો ટ્રાન્સપોઝ હોય છે. સહગુણક મેટ્રિક્સ શોધવા માટે દરેક એલિમેન્ટનો સહગુણક કાઢીને તેની સાઇન ચેંજ કરીને ટ્રાન્સપોઝ કરવું.

  • A⁻¹ = (1/|A|) adj(A)
  • adj(A) = સહગુણક મેટ્રિક્સનો ટ્રાન્સપોઝ
  • સહગુણક = (-1)^(i+j) * M_ij (M_ij = માઇનર)
  • |A| ≠ 0
🧠 Trick: કોફેક્ટર, ટ્રાન્સપોઝ, ડિવાઇડ બાય ડેટર્મિનન્ટ

વ્યસ્ત મેટ્રિક્સનો ઉપયોગ રેખીય સમીકરણોમાં

રેખીય સમીકરણોના સિસ્ટમ AX = Bને ઉકેલવા માટે X = A⁻¹B લખી શકાય છે. આ પદ્ધતિ ત્યારે ઉપયોગી થાય જ્યારે મેટ્રિક્સ Aનો વ્યસ્ત સરળતાથી શોધી શકાય. JEEમાં આ પ્રશ્નો અવારનવાર પૂછવામાં આવે છે.

  • AX = B ⇒ X = A⁻¹B
  • A વ્યસ્તયોગ્ય હોવી જરૂરી
  • ગાઉસિયન એલિમિનેશન પણ ઉપયોગી
  • ક્રેમરનો નિયમ પણ વિકલ્પ છે

વ્યસ્ત મેટ્રિક્સ અને ડેટર્મિનન્ટ વચ્ચેનો સંબંધ

વ્યસ્ત મેટ્રિક્સ અને ડેટર્મિનન્ટ વચ્ચેનો સંબંધ મહત્વપૂર્ણ છે. |A⁻¹| = 1/|A| અને |AB| = |A||B|. આ ગુણધર્મો ડેટર્મિનન્ટ અને વ્યસ્ત મેટ્રિક્સના પ્રશ્નોને ઉકેલવામાં મદદરૂપ થાય છે.

  • |A⁻¹| = 1/|A|
  • |AB| = |A||B|
  • |kA| = kⁿ|A| (n = મેટ્રિક્સનો ઓર્ડર)
  • ડેટર્મિનન્ટ શૂન્ય હોય તો વ્યસ્ત અસ્તિત્વમાં નથી

વ્યસ્ત મેટ્રિક્સના પ્રશ્નો માટેની ટિપ્સ

JEEમાં વ્યસ્ત મેટ્રિક્સના પ્રશ્નો માટે તમે ડાયરેક્ટ ફોર્મ્યુલા અથવા સહગુણક મેટ્રિક્સનો ઉપયોગ કરી શકો. 2×2 મેટ્રિક્સ માટે ફોર્મ્યુલા યાદ રાખો અને 3×3 માટે સહગુણક પદ્ધતિ વાપરો. ડેટર્મિનન્ટ શૂન્ય ન હોય તેની ખાતરી કરો.

  • 2×2 માટે ફોર્મ્યુલા યાદ રાખો
  • 3×3 માટે સહગુણક પદ્ધતિ
  • ડેટર્મિનન્ટ ચેક કરો
  • વ્યસ્ત અસ્તિત્વ માટે |A| ≠ 0

  • AX = B ⇒ X = A⁻¹B
  • વ્યસ્ત મેટ્રિક્સ યુનિક હોય છે

  • સહગુણક મેટ્રિક્સનો ટ્રાન્સપોઝ એ adj(A) હોય છે
