સંકુલ સંખ્યાઓ પર ક્રિયાઓ

📖 સંકુલ સંખ્યાઓ પર ક્રિયાઓ

સંકુલ સંખ્યાનું પ્રમાણભૂત સ્વરૂપ

સંકુલ સંખ્યા z = a + ib સ્વરૂપે લખાય છે, જ્યાં a અને b વાસ્તવિક સંખ્યાઓ છે અને i = √(-1) છે. a ને વાસ્તવિક ભાગ (Re(z)) અને b ને કાલ્પનિક ભાગ (Im(z)) કહે છે. સંકુલ સંખ્યાનું આ સ્વરૂપ NCERTમાં પ્રમાણભૂત ગણાય છે અને ક્રિયાઓ માટે આધારભૂત છે.

  • z = a + ib (a = Re(z), b = Im(z))
  • i² = -1, i³ = -i, i⁴ = 1 (ચક્રીય ગુણધર્મ)
  • સંકુલ સંખ્યાનું આલેખન: આર્ગન્ડ સમતલ પર (a,b) બિંદુ તરીકે
🧠 Trick: RIP: Real + Imaginary = Plane (આર્ગન્ડ સમતલ પર દર્શાવો)

સરવાળો અને બાદબાકી

બે સંકુલ સંખ્યાઓ z₁ = a + ib અને z₂ = c + id નો સરવાળો/બાદબાકી તેમના વાસ્તવિક અને કાલ્પનિક ભાગોને અલગથી કરવામાં આવે છે. z₁ ± z₂ = (a ± c) + i(b ± d). આ ક્રિયા સદિશોના સરવાળા જેવી જ છે.

  • વાસ્તવિક ભાગોનો સરવાળો/બાદબાકી → નવો વાસ્તવિક ભાગ
  • કાલ્પનિક ભાગોનો સરવાળો/બાદબાકી → નવો કાલ્પનિક ભાગ
  • આર્ગન્ડ સમતલ પર સમાંતરબાજુ ચતુષ્કોણના નિયમથી દર્શાવી શકાય
🧠 Trick: R + R, I + I (Real + Real, Imaginary + Imaginary)

ગુણાકાર

z₁ = a + ib અને z₂ = c + id નો ગુણાકાર (a + ib)(c + id) = (ac - bd) + i(ad + bc) થાય છે. i² = -1 નો ઉપયોગ કરીને વિસ્તરણ કરવું. ગુણાકાર ક્રમવિનિમય (commutative) અને જૂથન (associative) ગુણધર્મ ધરાવે છે.

  • FOIL પદ્ધતિ: First, Outer, Inner, Last
  • i² = -1 નો ઉપયોગ કરીને સાદુંરૂપ આપો
  • |z₁z₂| = |z₁||z₂| અને arg(z₁z₂) = arg(z₁) + arg(z₂)
🧠 Trick: FOIL: ફૂલ (First), બહાર (Outer), અંદર (Inner), છેલ્લું (Last)

ભાગાકાર

z₁/z₂ શોધવા માટે અંશ અને છેદને z₂ ના સહગુણક (c - id) વડે ગુણીને છેદને વાસ્તવિક સંખ્યા બનાવવામાં આવે છે. z₁/z₂ = (z₁ * z̄₂)/(z₂ * z̄₂) = [(ac + bd) + i(bc - ad)]/(c² + d²). આ પદ્ધતિને 'સંકરણ દ્વારા છેદનું વાસ્તવિકીકરણ' કહે છે.

  • છેદનું સંકરણ (conjugate) વડે ગુણાકાર કરો
  • છેદ = c² + d² (વાસ્તવિક સંખ્યા)
  • arg(z₁/z₂) = arg(z₁) - arg(z₂)
🧠 Trick: Conjugate se Divide (સંકરણ વડે ભાગાકાર)

સંકરણ (Conjugate) અને મોડ્યુલસ

સંકુલ સંખ્યા z = a + ib નું સંકરણ z̄ = a - ib છે. મોડ્યુલસ |z| = √(a² + b²) છે, જે z નું મૂળથી અંતર દર્શાવે છે. સંકરણના ગુણધર્મો: z + z̄ = 2Re(z), z - z̄ = 2iIm(z), z * z̄ = |z|².

  • z̄ = a - ib (કાલ્પનિક ભાગનું ચિહ્ન બદલાય)
  • |z| = √(a² + b²) (પાયથાગોરસ પ્રમેય)
  • |z₁z₂| = |z₁||z₂|, |z₁/z₂| = |z₁|/|z₂|
🧠 Trick: Conjugate = Mirror (આયનામાં પ્રતિબિંબ જેવું)

ધ્રુવીય સ્વરૂપ અને ડી મોઇવરનો પ્રમેય

સંકુલ સંખ્યા z = r(cosθ + i sinθ) ધ્રુવીય સ્વરૂપે લખાય છે, જ્યાં r = |z| અને θ = arg(z). ડી મોઇવરનો પ્રમેય: [r(cosθ + i sinθ)]ⁿ = rⁿ(cos nθ + i sin nθ). આ પ્રમેય ઘાત અને મૂળ શોધવા માટે ઉપયોગી છે.

  • z = r(cosθ + i sinθ) = re^(iθ) (ઇયુલરનું સૂત્ર)
  • arg(z) = θ = tan⁻¹(b/a) (ચરણ નક્કી કરવું જરૂરી)
  • z નું nમૂળ: r^(1/n)[cos((θ+2kπ)/n) + i sin((θ+2kπ)/n)], k = 0,1,...,n-1
🧠 Trick: De Moivre: Power = Radius^Power, Angle × Power

⚡ Quick Revision

  • z = a + ib (a = Re(z), b = Im(z), i² = -1)
  • સરવાળો/બાદબાકી: વાસ્તવિક અને કાલ્પનિક ભાગો અલગથી કરો
  • ગુણાકાર: FOIL પદ્ધતિ + i² = -1 નો ઉપયોગ
  • ભાગાકાર: સંકરણ વડે છેદનું વાસ્તવિકીકરણ
  • સંકરણ z̄ = a - ib, મોડ્યુલસ |z| = √(a² + b²)
  • z * z̄ = |z|² (મહત્વપૂર્ણ ગુણધર્મ)
  • ધ્રુવીય સ્વરૂપ: z = r(cosθ + i sinθ), r = |z|, θ = arg(z)
  • ડી મોઇવર: [r(cosθ + i sinθ)]ⁿ = rⁿ(cos nθ + i sin nθ)
  • nમૂળ: r^(1/n)[cos((θ+2kπ)/n) + i sin((θ+2kπ)/n)]
  • આર્ગન્ડ સમતલ પર સંકુલ સંખ્યાનું ભૌમિતિક અર્થઘટન
