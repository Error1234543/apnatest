સીધી રેખા (3D)

📖 સીધી રેખા (3D)

સીધી રેખાની વ્યાખ્યા અને સમીકરણ

ત્રિપરિમાણીય જગ્યામાં સીધી રેખા એ દિશા વેક્ટર અને બિંદુ દ્વારા વ્યાખ્યાયિત થાય છે. તેનું વેક્ટર સમીકરણ **r = a + λb** છે, જ્યાં **a** એ રેખા પરનું બિંદુ, **b** દિશા વેક્ટર અને λ પરામીટર છે.

  • રેખાનું વેક્ટર સમીકરણ: **r = a + λb**
  • કાર્ટેશિયન સમીકરણ: (x-x₁)/a = (y-y₁)/b = (z-z₁)/c = λ
  • દિશા વેક્ટર **b = (a, b, c)** રેખાની દિશા નક્કી કરે છે
  • રેખા પરના બિંદુ **a = (x₁, y₁, z₁)**

રેખાની દિશા કોણ અને દિશા કોસાઇન

દિશા વેક્ટરના ઘટકો દિશા કોસાઇન દ્વારા વ્યક્ત થાય છે: l = a/|b|, m = b/|b|, n = c/|b|. દિશા કોણ એ X, Y, Z અક્ષ સાથેના ખૂણાઓ છે.

  • દિશા કોસાઇન: l = cosα, m = cosβ, n = cosγ
  • l² + m² + n² = 1 (મહત્વનો સૂત્ર)
  • દિશા કોણ α, β, γ એ ક્રમશ: X, Y, Z અક્ષ સાથેના ખૂણા
  • દિશા વેક્ટરની લંબાઈ |b| = √(a² + b² + c²)
🧠 Trick: LMN = 1 (લગભગ 'લગન મન નહીં' વાળી યાદ રાખવા)

રેખાનું સિમેટ્રિક અને પરામીટ્રિક સ્વરૂપ

સિમેટ્રિક સ્વરૂપ (x-x₁)/a = (y-y₁)/b = (z-z₁)/c છે. પરામીટ્રિક સ્વરૂપમાં x = x₁ + aλ, y = y₁ + bλ, z = z₁ + cλ લખાય છે.

  • સિમેટ્રિક સ્વરૂપ: (x-x₁)/a = (y-y₁)/b = (z-z₁)/c
  • પરામીટ્રિક સ્વરૂપ: x = x₁ + aλ, y = y₁ + bλ, z = z₁ + cλ
  • λ એ પરામીટર છે, જે રેખા પરના બિંદુઓને વ્યાખ્યાયિત કરે છે
  • જો a, b, cમાંથી કોઈ શૂન્ય હોય તો સિમેટ્રિક સ્વરૂપ લાગુ પડતું નથી

રેખા અને બિંદુ વચ્ચેનું અંતર

બિંદુ P(x₀, y₀, z₀) અને રેખા r = a + λb વચ્ચેનું અંતર **d = |(P - a) × b| / |b|** દ્વારા મળે છે. આ ક્રોસ પ્રોડક્ટ અને મેગ્નિટ્યુડ પર આધારિત છે.

  • અંતરનું સૂત્ર: d = |(P - a) × b| / |b|
  • ક્રોસ પ્રોડક્ટ (P - a) × b વેક્ટરનું મૂલ્ય લેવું
  • |b| એ દિશા વેક્ટરની લંબાઈ
  • જો બિંદુ રેખા પર હોય તો d = 0

રેખા અને રેખા વચ્ચેનો ખૂણો

દો રેખાઓના દિશા વેક્ટર **b₁** અને **b₂** હોય તો વચ્ચેનો ખૂણો θ એ **cosθ = |b₁ · b₂| / (|b₁||b₂|)** દ્વારા મળે છે. ડોટ પ્રોડક્ટનો ઉપયોગ થાય છે.

  • ખૂણાનું સૂત્ર: cosθ = |b₁ · b₂| / (|b₁||b₂|)
  • ડોટ પ્રોડક્ટ b₁ · b₂ = a₁a₂ + b₁b₂ + c₁c₂
  • θ = 0° થી 90° વચ્ચે હોય છે
  • જો b₁ · b₂ = 0 તો રેખાઓ લંબ છે

રેખા અને સમતલ વચ્ચેનો ખૂણો

રેખાની દિશા વેક્ટર **b** અને સમતલના અભિલંબ વેક્ટર **n** વચ્ચેનો ખૂણો φ એ **sinφ = |b · n| / (|b||n|)** દ્વારા મળે છે. ખૂણો રેખા અને સમતલ વચ્ચેનો તીવ્ર ખૂણો છે.

  • ખૂણાનું સૂત્ર: sinφ = |b · n| / (|b||n|)
  • φ એ રેખા અને સમતલ વચ્ચેનો તીવ્ર ખૂણો
  • જો b · n = 0 તો રેખા સમતલને સમકોણે છેદે છે
  • જો b અને n સમાંતર હોય તો રેખા સમતલને સમાંતર છે

રેખાનું પ્રક્ષેપણ (Projection)

રેખાનું પ્રક્ષેપણ એટલે તેને કોઈ અક્ષ અથવા સમતલ પર પ્રક્ષેપિત કરવી. દાખલા તરીકે, X-Y સમતલ પર પ્રક્ષેપણ માટે z-ઘટકને 0 ગણવું.

  • X-Y સમતલ પર પ્રક્ષેપણ: z = 0
  • Y-Z સમતલ પર પ્રક્ષેપણ: x = 0
  • X-Z સમતલ પર પ્રક્ષેપણ: y = 0
  • પ્રક્ષેપણ દ્વારા 3D રેખાને 2Dમાં દર્શાવી શકાય

⚡ Quick Revision

  • સીધી રેખાનું વેક્ટર સમીકરણ: r = a + λb
  • કાર્ટેશિયન સ્વરૂપ: (x-x₁)/a = (y-y₁)/b = (z-z₁)/c
  • દિશા કોસાઇન: l² + m² + n² = 1
  • બિંદુ અને રેખા વચ્ચેનું અંતર: d = |(P - a) × b| / |b|
  • રેખાઓ વચ્ચેનો ખૂણો: cosθ = |b₁ · b₂| / (|b₁||b₂|)
  • રેખા અને સમતલ વચ્ચેનો ખૂણો: sinφ = |b · n| / (|b||n|)
  • પરામીટ્રિક સ્વરૂપ: x = x₁ + aλ, y = y₁ + bλ, z = z₁ + cλ
  • સિમેટ્રિક સ્વરૂપ લાગુ પડે નહીં જો દિશા વેક્ટરનો કોઈ ઘટક શૂન્ય હોય
  • રેખાનું પ્રક્ષેપણ સમતલ પર કરવા માટે સંબંધિત ઘટકને 0 ગણો
  • ડોટ પ્રોડક્ટ શૂન્ય હોય તો રેખાઓ લંબ છે
🎯 Exam Tip: 3D રેખાના પ્રશ્નોમાં દિશા વેક્ટર અને બિંદુને સ્પષ્ટ રીતે ઓળખો. ક્રોસ પ્રોડક્ટ અને ડોટ પ્રોડક્ટના સૂત્રો યાદ રાખો, કારણ કે તે અંતર અને ખૂણા માટે મહત્વના છે.
