ફંક્શનના પ્રકાર

📖 ફંક્શનના પ્રકાર (Types of Functions)

એક-એક ફંક્શન (One-One Function / Injective)

જ્યારે ફંક્શનના ડોમેનના દરેક ભિન્ન ઇનપુટને કોડોમેનના ભિન્ન આઉટપુટ સાથે જોડવામાં આવે ત્યારે તેને એક-એક ફંક્શન કહેવાય. એટલે કે, f(a) = f(b) ⇒ a = b. ઉદા. f(x) = 2x + 3.

  • ડોમેનના દરેક યુનિક ઇલેમેન્ટ માટે કોડોમેનમાં યુનિક ઇમેજ હોવી જોઈએ.
  • હોરિઝોન્ટલ લાઇન ટેસ્ટ પાસ કરે છે.
  • ઉદા. f(x) = x³, f(x) = eˣ
🧠 Trick: એક ઇનપુટ → એક જ આઉટપુટ (One Input → One Output)

અવરજવ (Onto Function / Surjective)

જ્યારે ફંક્શનના કોડોમેનના દરેક ઇલેમેન્ટને ડોમેનના કોઈ ના કોઈ ઇલેમેન્ટ સાથે જોડવામાં આવે ત્યારે તેને અવરજવ ફંક્શન કહેવાય. એટલે કે, રેન્જ = કોડોમેન.

  • કોડોમેનના દરેક ઇલેમેન્ટ માટે ડોમેનમાં પ્રિમેજ હોવું જરૂરી છે.
  • f: A → B અવરજવ હોવા માટે, B ⊆ f(A).
  • ઉદા. f(x) = x (જ્યારે ડોમેન = કોડોમેન = ℝ)
🧠 Trick: સરવૈયો કોડોમેન (Surjective = Cover All Codomain)

બાયેક્ટિવ ફંક્શન (Bijective Function)

જે ફંક્શન એક-એક અને અવરજવ બંને હોય તેને બાયેક્ટિવ ફંક્શન કહેવાય. એટલે કે, તે ઇન્જેક્ટિવ અને સર્જેક્ટિવ બંને છે. ઉદા. f(x) = x (ડોમેન = કોડોમેન = ℝ).

  • એક-એક + અવરજવ = બાયેક્ટિવ.
  • અસ્તિત્વમાં હોવો માટે ડોમેન અને કોડોમેનની કેપેસિટી સરખી હોવી જોઈએ.
  • ઉદા. f(x) = 2x (ડોમેન = ℝ, કોડોમેન = ℝ)
🧠 Trick: બે-એક (Bi = Two: Injective + Surjective)

સ્થિર ફંક્શન (Constant Function)

જ્યારે ફંક્શનના ડોમેનના દરેક ઇલેમેન્ટને કોડોમેનના એક જ ઇલેમેન્ટ સાથે જોડવામાં આવે ત્યારે તેને સ્થિર ફંક્શન કહેવાય. ઉદા. f(x) = 5.

  • ડોમેનના તમામ x માટે f(x) = c (સ્થિર).
  • રેન્જમાં ફક્ત એક જ ઇલેમેન્ટ હોય છે.
  • ગ્રાફ એ કોડોમેનના અક્ષને સમાંતર રેખા હોય છે.
🧠 Trick: સરખું જ રહે (Always the Same)

ઓળખ ફંક્શન (Identity Function)

જ્યારે ફંક્શનના ડોમેનના દરેક ઇલેમેન્ટને તેના જ જ કોડોમેનમાં જોડવામાં આવે ત્યારે તેને ઓળખ ફંક્શન કહેવાય. ઉદા. f(x) = x.

  • f(x) = x માટે ડોમેન = કોડોમેન.
  • ગ્રાફ એ y = x રેખા હોય છે.
  • એક-એક અને અવરજવ (બાયેક્ટિવ) હોય છે.
🧠 Trick: જે તે (Same as Input)

પોલીનોમીયલ ફંક્શન (Polynomial Function)

જે ફંક્શનને p(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀ રૂપે વ્યક્ત કરવામાં આવે તેને પોલીનોમીયલ ફંક્શન કહેવાય. ઉદા. f(x) = 3x² + 2x + 1.

  • n એ નોન-નેગેટિવ ઇન્ટિજર હોય છે.
  • ડિગ્રી n વાળા પોલીનોમીયલને n-ડિગ્રી પોલીનોમીયલ કહેવાય.
  • ગ્રાફ સતત અને સ્મૂથ હોય છે.

વ્યસ્ત ફંક્શન (Inverse Function)

જે ફંક્શન f ને ઉલટાવીને f⁻¹ બનાવે, જ્યાં f⁻¹(f(x)) = x અને f(f⁻¹(x)) = x, તેને વ્યસ્ત ફંક્શન કહેવાય. વ્યસ્ત ફંક્શન અસ્તિત્વમાં હોવા માટે f બાયેક્ટિવ હોવું જરૂરી છે.

  • ફક્ત બાયેક્ટિવ ફંક્શનના જ વ્યસ્ત ફંક્શન અસ્તિત્વમાં હોય છે.
  • f⁻¹ ના ડોમેન = f ની રેન્જ.
  • f⁻¹ ની રેન્જ = f નો ડોમેન.
🧠 Trick: ઉલટાવો તો મળે (Reverse to Get Inverse)

⚡ Quick Revision

  • એક-એક ફંક્શન = ઇનપુટ અને આઉટપુટ વચ્ચે એક-એક મેપિંગ.
  • અવરજવ ફંક્શન = કોડોમેનના તમામ ઇલેમેન્ટ કવર થાય.
  • બાયેક્ટિવ = એક-એક + અવરજવ.
  • સ્થિર ફંક્શન = તમામ ઇનપુટ માટે એક જ આઉટપુટ.
  • ઓળખ ફંક્શન = f(x) = x.
  • પોલીનોમીયલ ફંક્શન = aₙxⁿ + ... + a₀.
  • વ્યસ્ત ફંક્શન = ફક્ત બાયેક્ટિવ ફંક્શનના જ અસ્તિત્વમાં હોય.
  • હોરિઝોન્ટલ લાઇન ટેસ્ટ = એક-એક ફંક્શન ચકાસવા માટે.
  • વર્ટિકલ લાઇન ટેસ્ટ = ફંક્શન ચકાસવા માટે.
  • રેન્જ = કોડોમેન માટે અવરજવ ફંક્શન હોવું જરૂરી છે.
🎯 Exam Tip: ફંક્શનના પ્રકારને ઓળખવા માટે હંમેશા ડોમેન, કોડોમેન, અને રેન્જની વ્યાખ્યા સ્પષ્ટ રાખો. બાયેક્ટિવ ફંક્શન માટે વ્યસ્ત ફંક્શન અસ્તિત્વમાં હોવું જરૂરી છે — આ JEEમાં વારંવાર પૂછવામાં આવે છે.
