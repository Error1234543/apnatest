રેખીય સમીકરણો

📖 રેખીય સમીકરણો

રેખીય સમીકરણનો પરિચય

રેખીય સમીકરણ એ એક બીજગણિતીય સમીકરણ છે જેમાં ચલોની ઉચ્ચતમ ઘાત 1 હોય છે. આ સમીકરણોનો ઉપયોગ ભૌમિતિક રેખાઓ, આર્થિક મોડેલ્સ અને ભૌતિકશાસ્ત્રમાં થાય છે. રેખીય સમીકરણનું સામાન્ય સ્વરૂપ ax + by + c = 0 છે, જ્યાં a, b, c અચળાંકો છે.

  • રેખીય સમીકરણમાં ચલોની ઘાત હંમેશા 1 હોય છે.
  • સામાન્ય સ્વરૂપ: ax + by + c = 0
  • રેખા દર્શાવવા માટે વપરાય છે.
  • a અને b એકસાથે શૂન્ય ન હોવા જોઈએ.
🧠 Trick: લાઇન = લીનિયર = ઘાત 1

રેખીય સમીકરણના પ્રકારો

રેખીય સમીકરણોને આધારે વર્ગીકૃત કરવામાં આવે છે: એક ચલવાળા, બે ચલવાળા અને ત્રણ ચલવાળા. એક ચલવાળા સમીકરણ (ax + b = 0) એક બિંદુ દર્શાવે છે. બે ચલવાળા (ax + by + c = 0) રેખા દર્શાવે છે. ત્રણ ચલવાળા (ax + by + cz + d = 0) ત્રિપરિમાણીય અવકાશમાં સપાટી દર્શાવે છે.

  • એક ચલ: ax + b = 0 → બિંદુ
  • બે ચલ: ax + by + c = 0 → રેખા
  • ત્રણ ચલ: ax + by + cz + d = 0 → સપાટી
  • ચલોની સંખ્યા અનુસાર આકાર બદલાય છે.
🧠 Trick: 1ચલ=બિંદુ, 2ચલ=રેખા, 3ચલ=સપાટી

રેખીય સમીકરણનું ગ્રાફ પ્લોટ કરવું

બે ચલવાળા રેખીય સમીકરણનું ગ્રાફ પ્લોટ કરવા માટે, x અને y અક્ષ પર બિંદુઓ શોધી, તેમને જોડી રેખા દોરો. ઉદાહરણ: 2x + 3y = 6 માટે, x=0 ત્યારે y=2 અને y=0 ત્યારે x=3. આ બિંદુઓ જોડી રેખા મળે છે.

  • x-અંતર્ખંડ: y=0 મૂકી x શોધો
  • y-અંતર્ખંડ: x=0 મૂકી y શોધો
  • બે બિંદુઓ જોડી રેખા દોરો
  • રેખા સીધી હોય છે
🧠 Trick: X કાપો Y કાપો, જોડો તો રેખા થાય

રેખીય સમીકરણ જોડણીનો નિયમ

બે રેખીય સમીકરણોની જોડણીના ત્રણ શક્ય પરિણામો: 1) અનન્ય ઉકેલ (રેખાઓ છેદે છે), 2) અસંખ્ય ઉકેલ (રેખાઓ સમાન છે), 3) કોઈ ઉકેલ નહીં (રેખાઓ સમાનાંતર છે). આ નક્કી કરવા માટે a1/a2, b1/b2, c1/c2 ના ગુણોત્તરો તપાસો.

  • a1/a2 ≠ b1/b2 ≠ c1/c2 → અનન્ય ઉકેલ
  • a1/a2 = b1/b2 = c1/c2 → અસંખ્ય ઉકેલ
  • a1/a2 = b1/b2 ≠ c1/c2 → કોઈ ઉકેલ નહીં
  • ગુણોત્તર પદ્ધતિ વાપરો
🧠 Trick: સરખા ગુણોત્તર = અસંખ્ય, અડધા સરખા = કોઈ નહીં

રેખીય સમીકરણમાં અંતર

બિંદુ (x0, y0) થી રેખા ax + by + c = 0 નું અંતર |ax0 + by0 + c| / √(a² + b²) થાય છે. બે સમાનાંતર રેખાઓ વચ્ચેનું અંતર |c1 - c2| / √(a² + b²) થાય છે, જ્યાં રેખાઓ ax + by + c1 = 0 અને ax + by + c2 = 0 હોય.

  • બિંદુ થી રેખા અંતર: |ax0 + by0 + c| / √(a² + b²)
  • સમાનાંતર રેખાઓ અંતર: |c1 - c2| / √(a² + b²)
  • સૂત્ર યાદ રાખવા જરૂરી છે
  • અંતર હંમેશા ધન હોય છે.

રેખીય સમીકરણના અનુપ્રયોગો

રેખીય સમીકરણોનો ઉપયોગ આર્થિકશાસ્ત્રમાં માગણ-પુરવઠા વક્રો, ભૌતિકશાસ્ત્રમાં ગતિના સમીકરણો અને કમ્પ્યુટર ગ્રાફિક્સમાં થાય છે. રેખીય પ્રોગ્રામિંગમાં પણ આ સમીકરણો મહત્વના છે.

  • માગણ-પુરવઠા વક્રો માટે વપરાય છે
  • ગતિના સમીકરણોમાં ઉપયોગી
  • કમ્પ્યુટર ગ્રાફિક્સમાં રેખાઓ દોરવા
  • રેખીય પ્રોગ્રામિંગનું આધાર છે

રેખીય સમીકરણ અને જીવવિજ્ઞાનમાં ઉપયોગ

જીવવિજ્ઞાનમાં, રેખીય સમીકરણોનો ઉપયોગ ઉત્સેચક ક્રિયા-વેગ ( enzyme kinetics) ના મોડેલ્સ જેવા કે માઇકલિસ-મેન્ટન સમીકરણમાં થાય છે. આ ઉપરાંત, જનીન અભ્યાસમાં પણ રેખીય મોડેલ્સ વપરાય છે.

  • માઇકલિસ-મેન્ટન સમીકરણ રેખીય સ્વરૂપે લખી શકાય
  • ઉત્સેચક ક્રિયા-વેગના અભ્યાસમાં ઉપયોગી
  • જનીન અભ્યાસમાં રેખીય મોડેલ્સ
  • બાયોકેમિસ્ટ્રીમાં રેખીય નિર્ણય લેવા

⚡ Quick Revision

  • રેખીય સમીકરણ = ઘાત 1
  • સામાન્ય સ્વરૂપ: ax + by + c = 0
  • એક ચલ = બિંદુ, બે ચલ = રેખા, ત્રણ ચલ = સપાટી
  • ગુણોત્તર પદ્ધતિ વાપરી જોડણીનો નિયમ શોધો
  • બિંદુ થી રેખા અંતર: |ax0 + by0 + c| / √(a² + b²)
  • સમાનાંતર રેખાઓ અંતર: |c1 - c2| / √(a² + b²)
  • x-અંતર્ખંડ અને y-અંતર્ખંડ વાપરી ગ્રાફ દોરો
  • માઇકલિસ-મેન્ટન સમીકરણ રેખીય સ્વરૂપે લખી શકાય
  • રેખીય પ્રોગ્રામિંગનું આધાર છે
  • અનન્ય ઉકેલ = રેખાઓ છેદે છે
🎯 Exam Tip: રેખીય સમીકરણની જોડણીના પ્રશ્નો માટે ગુણોત્તર પદ્ધતિનો ઉપયોગ કરો અને હંમેશા a, b, c ની કિંમતો ચકાસો.
