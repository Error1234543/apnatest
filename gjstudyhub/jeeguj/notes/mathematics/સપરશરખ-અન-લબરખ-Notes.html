સ્પર્શરેખા અને લંબરેખા

📖 સ્પર્શરેખા અને લંબરેખા (JEE Main - ગણિત)

સ્પર્શરેખા: મૂળભૂત પરિભાષા

સ્પર્શરેખા એ વક્રની એવી રેખા છે જે વક્રને એક જ બિંદુએ સ્પર્શે અને તે બિંદુની આસપાસ વક્રના આકારને અનુકૂળ હોય. વક્ર y = f(x) માટે બિંદુ (a, f(a)) એ સ્પર્શરેખાનો ઢાળ f'(a) હોય છે.

  • સ્પર્શરેખા વક્રને એક બિંદુએ સ્પર્શે છે.
  • સ્પર્શરેખાનો ઢાળ = વક્રનો ઢાળ તે બિંદુએ
  • સ્પર્શરેખા વક્રના આકારને અનુકૂળ હોય છે.
  • વક્ર y = f(x) માટે સ્પર્શરેખા: y = f'(a)(x - a) + f(a)
🧠 Trick: સ્પર્શે એક બિંદુ, ઢાળ f'(a) યાદ રાખ!

લંબરેખા: પરિભાષા અને ગુણધર્મો

લંબરેખા એ સ્પર્શરેખાની લંબરૂપે ખેંચેલી રેખા છે. જો સ્પર્શરેખાનો ઢાળ m હોય, તો લંબરેખાનો ઢાળ -1/m હોય છે. લંબરેખા વક્રને કાપતી નથી, પરંતુ તે સ્પર્શરેખા સાથે 90° ખૂણો બનાવે છે.

  • લંબરેખા સ્પર્શરેખા પર લંબ હોય છે.
  • લંબરેખાનો ઢાળ = -1/(સ્પર્શરેખાનો ઢાળ)
  • લંબરેખા વક્રને કાપતી નથી.
  • સ્પર્શરેખા અને લંબરેખા વચ્ચેનો ખૂણો 90° હોય છે.
🧠 Trick: લંબરેખા = -1/m, 90° ખૂણો યાદ રાખ!

વર્તુળ માટે સ્પર્શરેખા અને લંબરેખા

વર્તુળ x² + y² = r² માટે બિંદુ (x₁, y₁) એ સ્પર્શરેખા x₁x + y₁y = r² હોય છે. લંબરેખા કેંદ્ર (0,0) અને બિંદુ (x₁, y₁)ને જોડતી રેખા હોય છે, જેનો ઢાળ y₁/x₁ હોય છે.

  • વર્તુળની સ્પર્શરેખા: x₁x + y₁y = r²
  • વર્તુળની લંબરેખા કેંદ્ર અને બિંદુને જોડે છે.
  • લંબરેખાનો ઢાળ = y₁/x₁
  • સ્પર્શરેખા અને લંબરેખા લંબ હોય છે.
🧠 Trick: વર્તુળ સ્પર્શરેખા: x₁x + y₁y = r²

પરવલય માટે સ્પર્શરેખા અને લંબરેખા

પરવલય y² = 4ax માટે બિંદુ (at², 2at) એ સ્પર્શરેખા ty = x + at² હોય છે. લંબરેખા -t y = x - a(t² + 1) હોય છે, જે સ્પર્શરેખા પર લંબ હોય છે.

  • પરવલય y² = 4ax માટે સ્પર્શરેખા: ty = x + at²
  • લંબરેખા: -t y = x - a(t² + 1)
  • સ્પર્શરેખા અને લંબરેખા લંબ હોય છે.
  • પરવલયની સ્પર્શરેખા અને લંબરેખા બિંદુ (at², 2at) એ સંપર્કે છે.
🧠 Trick: પરવલય સ્પર્શરેખા: ty = x + at²

દ્વિઘાત વક્ર માટે સ્પર્શરેખા

દ્વિઘાત વક્ર ax² + 2hxy + by² + 2gx + 2fy + c = 0 માટે બિંદુ (x₁, y₁) એ સ્પર્શરેખા ax₁x + h(x₁y + y₁x) + by₁y + g(x + x₁) + f(y + y₁) + c = 0 હોય છે.

  • દ્વિઘાત વક્રની સ્પર્શરેખા: ax₁x + h(x₁y + y₁x) + by₁y + g(x + x₁) + f(y + y₁) + c = 0
  • સ્પર્શરેખા બિંદુ (x₁, y₁) એ સંપર્કે છે.
  • દ્વિઘાત વક્ર માટે સ્પર્શરેખા શોધવા માટે સૂત્ર યાદ રાખો.

સ્પર્શરેખા અને લંબરેખા વચ્ચેનો ખૂણો

સ્પર્શરેખા અને લંબરેખા વચ્ચેનો ખૂણો હંમેશા 90° હોય છે. જો સ્પર્શરેખાનો ઢાળ m₁ અને લંબરેખાનો ઢાળ m₂ હોય, તો m₁ * m₂ = -1.

  • સ્પર્શરેખા અને લંબરેખા વચ્ચેનો ખૂણો 90° હોય છે.
  • m₁ * m₂ = -1
  • લંબરેખા સ્પર્શરેખા પર લંબ હોય છે.
🧠 Trick: 90° ખૂણો, m₁ * m₂ = -1

⚡ Quick Revision

  • સ્પર્શરેખા વક્રને એક બિંદુએ સ્પર્શે છે.
  • સ્પર્શરેખાનો ઢાળ = વક્રનો ઢાળ તે બિંદુએ
  • લંબરેખા સ્પર્શરેખા પર લંબ હોય છે.
  • લંબરેખાનો ઢાળ = -1/(સ્પર્શરેખાનો ઢાળ)
  • વર્તુળની સ્પર્શરેખા: x₁x + y₁y = r²
  • પરવલય y² = 4ax માટે સ્પર્શરેખા: ty = x + at²
  • દ્વિઘાત વક્રની સ્પર્શરેખા સૂત્ર યાદ રાખો.
  • સ્પર્શરેખા અને લંબરેખા વચ્ચેનો ખૂણો 90° હોય છે.
  • m₁ * m₂ = -1 લંબરેખા અને સ્પર્શરેખા માટે
  • લંબરેખા કેંદ્ર અને બિંદુને જોડે છે (વર્તુળ માટે)
🎯 Exam Tip: JEE Mainમાં સ્પર્શરેખા અને લંબરેખા વચ્ચેનો સંબંધ અને તેમના ઢાળનો ગુણાકાર (-1) હોવો જરૂરી છે, તે યાદ રાખો. વર્તુળ અને પરવલય માટે સ્પર્શરેખા અને લંબરેખાના સૂત્રો કંઠસ્થ કરો.
