મોડ્યુલસ અને આર્ગ્યુમેન્ટ

📖 મૉડ્યુલસ અને આર્ગ્યુમેન્ટ (સંકર સંખ્યાઓ)

સંકર સંખ્યાનો પરિચય

સંકર સંખ્યા એ વાસ્તવિક સંખ્યા અને કાલ્પનિક સંખ્યાનો સરવાળો છે, જેને z = a + ib સ્વરૂપે લખવામાં આવે છે, જ્યાં a અને b વાસ્તવિક સંખ્યાઓ છે અને i = √(-1) છે. મૉડ્યુલસ અને આર્ગ્યુમેન્ટ સંકર સંખ્યાના ધ્રુવીય સ્વરૂપ માટે મૂળભૂત છે.

  • સંકર સંખ્યા z = a + ib નું કાર્તેઝિયન સ્વરૂપ
  • i² = -1 (કાલ્પનિક એકમ)
  • a = વાસ્તવિક ભાગ (Re(z)), b = કાલ્પનિક ભાગ (Im(z))
🧠 Trick: RIP: Real + Imaginary = Polar (મૉડ્યુલસ-આર્ગ્યુમેન્ટ)

મૉડ્યુલસ (r)ની વ્યાખ્યા અને ગણતરી

સંકર સંખ્યા z = a + ib નો મૉડ્યુલસ એ તેનું મૂળથી અંતર છે, જેને |z| = √(a² + b²) વડે દર્શાવાય છે. તે હંમેશા બિન-ઋણ વાસ્તવિક સંખ્યા હોય છે અને સંકર સંખ્યાનું 'કદ' દર્શાવે છે.

  • |z| = √(a² + b²) (પાયથાગોરસ પ્રમેય)
  • |z₁z₂| = |z₁||z₂| (મૉડ્યુલસ ગુણાકાર નિયમ)
  • |z| ≥ 0, |z| = 0 ⇔ z = 0
🧠 Trick: MOD = MOve Distance (મૂળથી અંતર)

આર્ગ્યુમેન્ટ (θ)ની વ્યાખ્યા અને મુખ્ય મૂલ્ય

સંકર સંખ્યા z = a + ib નો આર્ગ્યુમેન્ટ એ ધન વાસ્તવિક અક્ષ સાથે બનતો ખૂણો છે, જેને θ = tan⁻¹(b/a) વડે દર્શાવાય છે. મુખ્ય આર્ગ્યુમેન્ટ (-π, π] અથવા [0, 2π) ની રેન્જમાં લેવાય છે.

  • θ = tan⁻¹(b/a) (પરંતુ ચરણ નક્કી કરવું જરૂરી)
  • મુખ્ય આર્ગ્યુમેન્ટ: -π < θ ≤ π અથવા 0 ≤ θ < 2π
  • z = 0 માટે આર્ગ્યુમેન્ટ અવ્યાખ્યાયિત
🧠 Trick: ARG = Angle from Real axis to Graph (વાસ્તવિક અક્ષથી ખૂણો)

ધ્રુવીય સ્વરૂપ અને રૂપાંતરણ

સંકર સંખ્યાનું ધ્રુવીય સ્વરૂપ z = r(cosθ + i sinθ) છે, જ્યાં r = |z| અને θ = arg(z). કાર્તેઝિયનથી ધ્રુવીય રૂપાંતર માટે r = √(a² + b²) અને θ = tan⁻¹(b/a) (ચરણ સાથે) વપરાય છે.

  • z = r(cosθ + i sinθ) = re^(iθ) (ઓઇલરનું સૂત્ર)
  • a = r cosθ, b = r sinθ (ધ્રુવીયથી કાર્તેઝિયન)
  • r = √(a² + b²), θ = tan⁻¹(b/a) ± π (ચરણ મુજબ)
🧠 Trick: Polar = Power (r) + Phase (θ)

મૉડ્યુલસ અને આર્ગ્યુમેન્ટના ગુણધર્મો

મૉડ્યુલસ અને આર્ગ્યુમેન્ટના મહત્વના ગુણધર્મો: |z̄| = |z|, arg(z̄) = -arg(z), |z₁/z₂| = |z₁|/|z₂|, arg(z₁/z₂) = arg(z₁) - arg(z₂). આ ગુણધર્મો સંકર સંખ્યાના ગુણાકાર/ભાગાકાર માટે ઉપયોગી છે.

  • |z̄| = |z|, arg(z̄) = -arg(z)
  • |z₁z₂| = |z₁||z₂|, arg(z₁z₂) = arg(z₁) + arg(z₂)
  • |zⁿ| = |z|ⁿ, arg(zⁿ) = n arg(z) (ડી મોઇવરનું પ્રમેય)
🧠 Trick: MAM: Multiply Modulus, Add Arguments

જટિલ સમતલમાં ભૌમિતિક અર્થઘટન

સંકર સંખ્યા z = a + ib ને જટિલ સમતલમાં બિંદુ (a,b) તરીકે દર્શાવાય છે. મૉડ્યુલસ એ મૂળથી અંતર છે, જ્યારે આર્ગ્યુમેન્ટ એ ધન વાસ્તવિક અક્ષ સાથે બનતો ખૂણો છે. આ ભૌમિતિક અર્થઘટન વર્તુળ, રેખા અને અન્ય આકૃતિઓના સમીકરણ માટે ઉપયોગી છે.

  • z = a + ib → બિંદુ (a,b) જટિલ સમતલમાં
  • |z - z₀| = r → વર્તુળ (કેન્દ્ર z₀, ત્રિજ્યા r)
  • arg(z - z₀) = θ → કિરણ (z₀ થી θ ખૂણે)
🧠 Trick: GAP: Geometry = Argand Plane (આર્ગેન્ડ સમતલ)

⚡ Quick Revision

  • મૉડ્યુલસ |z| = √(a² + b²) એ મૂળથી અંતર છે
  • આર્ગ્યુમેન્ટ θ = tan⁻¹(b/a) (ચરણ સાથે) એ વાસ્તવિક અક્ષ સાથે ખૂણો છે
  • ધ્રુવીય સ્વરૂપ: z = r(cosθ + i sinθ) = re^(iθ)
  • |z₁z₂| = |z₁||z₂|, arg(z₁z₂) = arg(z₁) + arg(z₂)
  • |z̄| = |z|, arg(z̄) = -arg(z)
  • z = 0 માટે મૉડ્યુલસ 0, આર્ગ્યુમેન્ટ અવ્યાખ્યાયિત
  • મુખ્ય આર્ગ્યુમેન્ટ: -π < θ ≤ π અથવા 0 ≤ θ < 2π
  • જટિલ સમતલમાં |z - z₀| = r એ વર્તુળ દર્શાવે છે
  • ડી મોઇવરનું પ્રમેય: (cosθ + i sinθ)ⁿ = cos(nθ) + i sin(nθ)
  • ઓઇલરનું સૂત્ર: e^(iθ) = cosθ + i sinθ
🎯 Exam Tip: JEE Main માં મૉડ્યુલસ-આર્ગ્યુમેન્ટના પ્રશ્નોમાં ચરણ (quadrant) નક્કી કરવું ખૂબ જરૂરી છે. tan⁻¹(b/a) નું મૂલ્ય મેળવ્યા પછી હંમેશા ચકાસો કે z કયા ચરણમાં છે અને તે મુજબ θ માં ±π ઉમેરો/ઘટાડો કરો. આ ભૂલ 50% ઉમેદવારો કરે છે!
