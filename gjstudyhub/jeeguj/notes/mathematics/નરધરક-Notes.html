Pro Notes

નિર્ધારક

📖 નિર્ધારક (Determinants) - JEE Main (NTA) મેટ્રિક્સ અને સદિશ વિશ્લેષણ

નિર્ધારકની મૂળભૂત વ્યાખ્યા

નિર્ધારક એ n x n કોઠા (matrix) નું એક સ્કેલર મૂલ્ય છે જે તેના સદિશ સ્તંભો (વા હાર) ની રેખીય આશ્રિતતા (linear dependence) નું માપ આપે છે. જો નિર્ધારક શૂન્ય હોય, તો સદિશો રેખીય આશ્રિત છે. તે વેક્ટર કોષ્ટકના આયતન (volume) નું પ્રમાણ પણ દર્શાવે છે.

  • n x n કોઠા માટે નિર્ધારક વ્યાખ્યાયિત થાય છે
  • શૂન્ય નિર્ધારક = રેખીય આશ્રિત સદિશો
  • 2x2 કોઠા માટે: |a b| = ad - bc
  • 3x3 કોઠા માટે સર્રસ નિયમ (Sarrus rule) વાપરી શકાય

2x2 અને 3x3 નિર્ધારકની ગણતરી

2x2 કોઠા |a b| માટે નિર્ધારક = ad - bc. 3x3 કોઠા માટે સર્રસ નિયમ અથવા લાપ્લાસ વિસ્તરણ (Laplace expansion) વાપરો. લાપ્લાસમાં કોઈપણ હાર અથવા સ્તંભ પસંદ કરી, તેના તત્ત્વોને cofactor સાથે ગુણો.

  • 2x2: |a b| = ad - bc
  • 3x3: સર્રસ નિયમ = a(ei − fh) − b(di − fg) + c(dh − eg)
  • Laplace expansion: કોઈપણ હાર/સ્તંભ પર વિસ્તરણ
  • Cofactor = (-1)^(i+j) * minor
🧠 Trick: Sarrus: 'ટોચ-નીચે ગુણો, વચ્ચે કાપો, બાદ કરો'

નિર્ધારકના ગુણધર્મો (Properties)

નિર્ધારકના મહત્વના ગુણધર્મો જાણવા જરૂરી છે: હાર/સ્તંભનો બદલો, સ્કેલર ગુણાકાર, બે કોઠાના ગુણાકારનો નિર્ધારક, અને ત્રિકોણીય કોઠાનો નિર્ધારક. આ ગુણધર્મો ગણતરીમાં સરળતા લાવે છે.

  • હાર ⇄ સ્તંભ બદલવાથી નિર્ધારકનો ચિહ્ન બદલાય
  • કોઈ હાર/સ્તંભને k વડે ગુણવાથી નિર્ધારક k ગણો થાય
  • |AB| = |A||B| (બે કોઠાના ગુણાકાર)
  • ત્રિકોણીય કોઠાનો નિર્ધારક = કર્ણ પરના તત્ત્વોનો ગુણાકાર

નિર્ધારકના ઉપયોગ: રેખીય સમીકરણોની સિસ્ટમ

ક્રેમરના નિયમ (Cramer's Rule) મુજબ, n ચલવાળા n સમીકરણોની સિસ્ટમનો ઉકેલ નિર્ધારકો વડે મેળવી શકાય. જો કોઠાનો નિર્ધારક શૂન્ય હોય, તો સિસ્ટમમાં અનંત ઉકેલ અથવા કોઈ ઉકેલ નહીં હોય.

  • ક્રેમરના નિયમ: x_i = |A_i| / |A|
  • |A| = 0 ⇒ કોઈ ઉકેલ અથવા અનંત ઉકેલ
  • સમીકરણોની સિસ્ટમ માટે કોઠો A બનાવો
  • A_i = Aમાં iમો સ્તંભ બદલીને ઉકેલ સ્તંભ મૂકો
🧠 Trick: Cramer: 'નિર્ધારક શૂન્ય નહીં તો ઉકેલ મળે'

નિર્ધારક અને કોઠાનો વ્યસ્ત (Inverse of Matrix)

કોઠાનો વ્યસ્ત અસ્તિત્વમાં હોય તો અને તો જ તેનો નિર્ધારક અશૂન્ય હોય. વ્યસ્ત કોઠો = (1/|A|) * adj(A), જ્યાં adj(A) એ અધિશોષી કોઠો (adjugate) છે.

  • A^-1 અસ્તિત્વમાં ⇔ |A| ≠ 0
  • A^-1 = (1/|A|) * adj(A)
  • adj(A) = cofactor કોઠાનો transposed
  • |A^-1| = 1/|A|

નિર્ધારક અને સદિશોની રેખીય આશ્રિતતા

ત્રણ સદિશો a, b, c રેખીય આશ્રિત હોય તો [a b c] = 0. આ ત્રિપરિમાણીય જગ્યામાં સદિશોની સહતલીયતા (coplanarity) દર્શાવે છે. સદિશ ચતુષ્ટય (scalar quadruple product) પણ નિર્ધારક વડે વ્યાખ્યાયિત થાય છે.

  • [a b c] = 0 ⇔ a, b, c સહતલીય
  • સદિશ ચતુષ્ટય = [a b c d] = a·(b × c)·d
  • 4 સદિશો રેખીય આશ્રિત ⇔ ચતુષ્ટય = 0

નિર્ધારકના અનુપ્રયોગ: આંકડાશાસ્ત્ર અને ભૌતિકશાસ્ત્ર

નિર્ધારકનો ઉપયોગ વેક્ટર કોષ્ટકના આયતન, રેખીય રૂપાંતરણ (linear transformation) ના ગુણધર્મો, અને ક્વોન્ટમ મેકેનિક્સમાં વેવ ફંક્શનની નોર્મલાઇઝેશનમાં થાય છે. JEEમાં મુખ્યત્વે ગણિત અને ભૌતિકમાં પ્રશ્નો પૂછાય છે.

  • વેક્ટર કોષ્ટકનું આયતન = |a·(b × c)|
  • રેખીય રૂપાંતરણનો નિર્ધારક = આયતન સ્કેલિંગ ફેક્ટર
  • ક્વોન્ટમ મેકેનિક્સ: વેવ ફંક્શન માટે નોર્મલાઇઝેશન
  • JEEમાં 2x2, 3x3 નિર્ધારક પર પ્રશ્નો

⚡ Quick Revision

  • નિર્ધારક = કોઠાનું સ્કેલર મૂલ્ય, રેખીય આશ્રિતતાનું માપ
  • 2x2 નિર્ધારક = ad - bc
  • 3x3 નિર્ધારક: સર્રસ નિયમ અથવા લાપ્લાસ વિસ્તરણ
  • શૂન્ય નિર્ધારક = રેખીય આશ્રિત સદિશો અથવા કોઈ વ્યસ્ત કોઠો નહીં
  • ક્રેમરના નિયમ: x_i = |A_i| / |A|
  • |A^-1| = 1/|A|
  • સહતલીય સદિશો ⇔ [a b c] = 0
  • હાર ⇄ સ્તંભ બદલવાથી નિર્ધારકનો ચિહ્ન બદલાય
  • ત્રિકોણીય કોઠાનો નિર્ધારક = કર્ણ પરના તત્ત્વોનો ગુણાકાર
  • કોઠાના ગુણાકારનો નિર્ધારક = નિર્ધારકોનો ગુણાકાર
🎯 Exam Tip: JEE Mainમાં નિર્ધારકના પ્રશ્નો મોટાભાગે 2x2 અથવા 3x3 કોઠા પર આધારિત હોય છે. સર્રસ નિયમ અને લાપ્લાસ વિસ્તરણ યાદ રાખો. ક્રેમરના નિયમ અને કોઠાના વ્યસ્તના પ્રશ્નો પર ધ્યાન આપો.
