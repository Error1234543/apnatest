અવકલ સમીકરણો

📖 અવકલ સમીકરણો (Differential Equations)

અવકલ સમીકરણનો પરિચય

અવકલ સમીકરણ એવું સમીકરણ છે જેમાં અજ્ઞાત વિધેય અને તેના વિકલિત (derivatives)નો સમાવેશ થાય છે. તેનો ઉપયોગ ભૌતિકશાસ્ત્ર, રસાયણશાસ્ત્ર અને જીવવિજ્ઞાનમાં પ્રક્રિયાઓના મોડેલિંગ માટે થાય છે, જેમ કે વસ્તી વૃદ્ધિ, રેડિયોએક્ટિવ ક્ષય અને ઉષ્મા વહન.

  • અવકલ સમીકરણ = વિધેય + તેના વિકલિત
  • ક્રમ (Order) = ઉચ્ચતમ વિકલિતનો ક્રમ
  • ઘાત (Degree) = ઉચ્ચતમ વિકલિતની ઘાત (જો બહુપદી હોય તો)
🧠 Trick: ક્રમ-ઘાત યાદ રાખો: 'ક્રમ પહેલા, ઘાત પછી' (Order before Degree)

પ્રથમ ક્રમના અવકલ સમીકરણોના પ્રકાર

પ્રથમ ક્રમના અવકલ સમીકરણોને ત્રણ મુખ્ય પ્રકારમાં વર્ગીકૃત કરવામાં આવે છે: ચલો અલગ કરી શકાય તેવા (Variables Separable), સજાતીય (Homogeneous), અને રેખીય (Linear). દરેક પ્રકારની પોતાની ચોક્કસ ઉકેલ પદ્ધતિ હોય છે.

  • ચલો અલગ કરી શકાય તેવા: dy/dx = f(x)g(y) → ∫dy/g(y) = ∫f(x)dx
  • સજાતીય: dy/dx = f(y/x) → y = vx અવેજી કરો
  • રેખીય: dy/dx + P(x)y = Q(x) → સંકલન અવયવ (IF) = e^∫P(x)dx
🧠 Trick: ચલ-સજા-રેખા: 'ચલો અલગ, સજાતીય vx, રેખીય IF'

ચલો અલગ કરી શકાય તેવા સમીકરણો

જ્યારે સમીકરણને dy/dx = f(x)g(y) સ્વરૂપમાં લખી શકાય, ત્યારે ચલોને અલગ કરીને સંકલન કરવામાં આવે છે. આ પ્રકારના સમીકરણોનો ઉપયોગ વસ્તી ગતિશાસ્ત્ર અને રાસાયણિક પ્રક્રિયાઓમાં થાય છે.

  • dy/g(y) = f(x)dx સ્વરૂપમાં ફેરવો
  • બંને બાજુ સંકલન કરો
  • સંકલન અચળાંક (C) ઉમેરવાનું ભૂલશો નહીં
🧠 Trick: ચલો અલગ = સંકલન અલગ

સજાતીય અવકલ સમીકરણો

સજાતીય અવકલ સમીકરણને dy/dx = f(y/x) સ્વરૂપમાં લખી શકાય છે. તેને ઉકેલવા માટે y = vx અવેજીનો ઉપયોગ કરવામાં આવે છે, જે સમીકરણને ચલો અલગ કરી શકાય તેવા સ્વરૂપમાં ફેરવે છે.

  • y = vx → dy/dx = v + x(dv/dx)
  • સમીકરણને v અને xના પદમાં ફેરવો
  • ચલો અલગ કરીને સંકલન કરો
🧠 Trick: સજાતીય માટે 'vx ટ્રિક'

રેખીય અવકલ સમીકરણો

રેખીય અવકલ સમીકરણ dy/dx + P(x)y = Q(x) સ્વરૂપમાં હોય છે. તેનો ઉકેલ સંકલન અવયવ (IF) = e^∫P(x)dxનો ઉપયોગ કરીને મેળવવામાં આવે છે. આ પ્રકારના સમીકરણોનો ઉપયોગ વિદ્યુત પરિપથ અને યાંત્રિક પ્રણાલીઓમાં થાય છે.

  • IF = e^∫P(x)dx ગણો
  • y × IF = ∫(Q(x) × IF)dx + C
  • ઉકેલ માટે y = (∫(Q × IF)dx + C)/IF
🧠 Trick: રેખીય માટે 'IF યાદ રાખો'

અનુભૂતિ અને પ્રારંભિક મૂલ્ય સમસ્યાઓ

અનુભૂતિ (General Solution) એ અચળાંક C ધરાવતો ઉકેલ છે, જ્યારે વિશિષ્ટ ઉકેલ (Particular Solution) પ્રારંભિક શરતોનો ઉપયોગ કરીને મેળવવામાં આવે છે. પ્રારંભિક મૂલ્ય સમસ્યાઓમાં, સમય t=0 અથવા સ્થાન x=0 પર વિધેયનું મૂલ્ય આપવામાં આવે છે.

  • અનુભૂતિ ઉકેલમાં અચળાંક C હોય છે
  • પ્રારંભિક શરતોનો ઉપયોગ કરીને C શોધો
  • y(x₀) = y₀ જેવી શરતો આપવામાં આવે છે
🧠 Trick: પ્રારંભિક શરત = C શોધો

⚡ Quick Revision

  • અવકલ સમીકરણ = વિધેય + વિકલિત
  • ક્રમ = ઉચ્ચતમ વિકલિતનો ક્રમ, ઘાત = તેની ઘાત
  • ચલો અલગ કરી શકાય તેવા: dy/g(y) = f(x)dx → સંકલન
  • સજાતીય: y = vx અવેજી → ચલો અલગ કરો
  • રેખીય: dy/dx + P(x)y = Q(x) → IF = e^∫P(x)dx
  • અનુભૂતિ ઉકેલમાં C હોય, પ્રારંભિક શરતથી C શોધો
  • NCERTમાં પ્રથમ ક્રમના સમીકરણો પર ધ્યાન કેન્દ્રિત કરો
  • JEEમાં ચલો અલગ અને રેખીય સમીકરણો વધુ પૂછાય છે
🎯 Exam Tip: JEEમાં અવકલ સમીકરણોના પ્રશ્નોમાં પહેલા સમીકરણનો પ્રકાર ઓળખો (ચલો અલગ/સજાતીય/રેખીય), પછી તે પ્રકારની પ્રમાણિત પદ્ધતિ લાગુ કરો. પ્રારંભિક શરતો આપેલી હોય તો અંતમાં C શોધવાનું ભૂલશો નહીં.
