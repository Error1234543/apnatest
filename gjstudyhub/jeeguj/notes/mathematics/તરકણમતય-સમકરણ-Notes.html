ત્રિકોણમિતીય સમીકરણો

📖 ત્રિકોણમિતીય સમીકરણો

પાયાની સમજ અને સામાન્ય ઉકેલ

ત્રિકોણમિતીય સમીકરણોમાં sinθ, cosθ, tanθ જેવા ત્રિકોણમિતીય વિધેયોનો સમાવેશ થાય છે. આ સમીકરણોનો સામાન્ય ઉકેલ θ = nπ + α અથવા θ = 2nπ ± α સ્વરૂપમાં મળે છે, જ્યાં n પૂર્ણાંક છે અને α મુખ્ય ઉકેલ છે. ઉદાહરણ તરીકે, sinθ = 1/2 નો સામાન્ય ઉકેલ θ = nπ + (-1)ⁿ π/6 છે.

  • સામાન્ય ઉકેલ: θ = nπ + α અથવા 2nπ ± α
  • sinθ = 0 ⇒ θ = nπ
  • cosθ = 0 ⇒ θ = (2n+1)π/2
  • tanθ = 0 ⇒ θ = nπ
  • મુખ્ય ઉકેલ શોધવા માટે પ્રથમ ચરણનો ઉપયોગ કરો
🧠 Trick: સાઇન-પાઇ, કોસ-અડધું-પાઇ, ટેન-પાઇ (sin-nπ, cos-(2n+1)π/2, tan-nπ)

સમીકરણોનું સરળીકરણ અને પરિવર્તન

સમીકરણોને સરળ બનાવવા માટે ત્રિકોણમિતીય નિત્યસમો અને પરિવર્તનોનો ઉપયોગ કરો. ઉદાહરણ તરીકે, sin²θ + cos²θ = 1, 1 + tan²θ = sec²θ, 1 + cot²θ = cosec²θ. સમીકરણમાં એક જ વિધેય રાખવા માટે આ નિત્યસમોનો ઉપયોગ કરો.

  • sin²θ + cos²θ = 1 (મૂળભૂત નિત્યસમ)
  • 1 + tan²θ = sec²θ
  • 1 + cot²θ = cosec²θ
  • સમીકરણને એક જ વિધેયમાં ફેરવો
  • ઉદાહરણ: sinθ = cosθ ⇒ tanθ = 1
🧠 Trick: સાઇન-કોસનો વર્ગ-જોડો-એક (sin² + cos² = 1)

વિશિષ્ટ કોણોના મૂલ્યો અને ઉકેલ

0°, 30°, 45°, 60°, 90° જેવા વિશિષ્ટ કોણોના ત્રિકોણમિતીય મૂલ્યો યાદ રાખો. આ મૂલ્યોનો ઉપયોગ કરીને સમીકરણોનો ઉકેલ સરળતાથી મેળવી શકાય છે. ઉદાહરણ તરીકે, sinθ = √3/2 ⇒ θ = π/3 અથવા 2π/3.

  • sin(π/6) = 1/2, cos(π/6) = √3/2
  • sin(π/4) = cos(π/4) = 1/√2
  • sin(π/3) = √3/2, cos(π/3) = 1/2
  • tan(π/3) = √3, tan(π/6) = 1/√3
  • વિશિષ્ટ કોણોના મૂલ્યો યાદ રાખો
🧠 Trick: 1-2-3 સૂત્ર: sin(π/6)=1/2, sin(π/4)=1/√2, sin(π/3)=√3/2

સંયુક્ત કોણોના સમીકરણો

સંયુક્ત કોણોના સમીકરણો જેવા કે sin(A±B), cos(A±B), tan(A±B) ના સૂત્રોનો ઉપયોગ કરીને ઉકેલ મેળવો. ઉદાહરણ તરીકે, sin(θ + π/4) = 1/2 ⇒ θ + π/4 = nπ + (-1)ⁿ π/6 ⇒ θ = nπ + (-1)ⁿ π/6 - π/4.

  • sin(A±B) = sinAcosB ± cosAsinB
  • cos(A±B) = cosAcosB ∓ sinAsinB
  • tan(A±B) = (tanA ± tanB)/(1 ∓ tanAtanB)
  • સંયુક્ત કોણોને અલગ કરીને ઉકેલો
  • ઉદાહરણ: sin2θ = √3/2 ⇒ 2θ = nπ + (-1)ⁿ π/3
🧠 Trick: સાઇન-કોસ-કોસ-સાઇન, કોસ-કોસ-સાઇન-સાઇન (sin(A+B) = sinAcosB + cosAsinB)

ગુણક અને ઉપગુણક કોણોના સમીકરણો

ગુણક કોણો જેવા કે sin2θ, cos2θ, tan2θ અને ઉપગુણક કોણો જેવા કે sin(θ/2), cos(θ/2) ના સમીકરણો ઉકેલવા માટે યોગ્ય સૂત્રોનો ઉપયોગ કરો. ઉદાહરણ તરીકે, cos2θ = 1/2 ⇒ 2θ = 2nπ ± π/3 ⇒ θ = nπ ± π/6.

  • sin2θ = 2sinθcosθ
  • cos2θ = cos²θ - sin²θ = 2cos²θ - 1 = 1 - 2sin²θ
  • tan2θ = 2tanθ/(1 - tan²θ)
  • sin(θ/2) = ±√[(1 - cosθ)/2]
  • cos(θ/2) = ±√[(1 + cosθ)/2]
🧠 Trick: ડબલ-સાઇન-ડબલ-સાઇન-કોસ, ડબલ-કોસ-કોસ-માઇનસ-સાઇન (sin2θ = 2sinθcosθ, cos2θ = cos²θ - sin²θ)

સમીકરણોનું રેખીય સ્વરૂપ અને ઉકેલ

asinθ + bcosθ = c સ્વરૂપના સમીકરણોને રેખીય સ્વરૂપમાં ફેરવીને ઉકેલો. આ માટે Rsin(θ + α) અથવા Rcos(θ - α) સ્વરૂપમાં ફેરવો, જ્યાં R = √(a² + b²) અને tanα = b/a. ઉદાહરણ તરીકે, √3sinθ + cosθ = 2 ⇒ 2sin(θ + π/6) = 2 ⇒ sin(θ + π/6) = 1.

  • asinθ + bcosθ = Rsin(θ + α), જ્યાં R = √(a² + b²)
  • tanα = b/a
  • ઉકેલ માટે Rsin(θ + α) = c ⇒ sin(θ + α) = c/R
  • c/R ≤ 1 હોવું જરૂરી (ઉકેલ અસ્તિત્વમાં હોવા માટે)
  • ઉદાહરણ: sinθ + √3cosθ = 2 ⇒ 2sin(θ + π/3) = 2
🧠 Trick: R-સાઇન-થીટા-પ્લસ-આલ્ફા (Rsin(θ + α))

⚡ Quick Revision

  • સામાન્ય ઉકેલ: θ = nπ + α અથવા 2nπ ± α
  • sin²θ + cos²θ = 1 (મૂળભૂત નિત્યસમ)
  • વિશિષ્ટ કોણોના મૂલ્યો યાદ રાખો (0°, 30°, 45°, 60°, 90°)
  • સંયુક્ત કોણોના સૂત્રો: sin(A±B), cos(A±B), tan(A±B)
  • ગુણક કોણો: sin2θ = 2sinθcosθ, cos2θ = cos²θ - sin²θ
  • ઉપગુણક કોણો: sin(θ/2) = ±√[(1 - cosθ)/2]
  • રેખીય સ્વરૂપ: asinθ + bcosθ = Rsin(θ + α), R = √(a² + b²)
  • tanα = b/a (રેખીય સ્વરૂપ માટે)
  • ઉકેલ માટે c/R ≤ 1 હોવું જરૂરી
  • મુખ્ય ઉકેલ શોધવા માટે પ્રથમ ચરણનો ઉપયોગ કરો
🎯 Exam Tip: ત્રિકોણમિતીય સમીકરણો ઉકેલતી વખતે હંમેશા સામાન્ય ઉકેલ લખવાનું ભૂલશો નહીં. પરીક્ષામાં મુખ્ય ઉકેલ સાથે સામાન્ય ઉકેલ લખવાથી પૂરા ગુણ મળે છે. ઉપરાંત, સમીકરણને એક જ વિધેયમાં ફેરવીને ઉકેલવાનો પ્રયાસ કરો, જેથી ઉકેલ સરળ બને.
