મેટ્રિક્સ પર ક્રિયાઓ

📖 મેટ્રિક્સ પર ક્રિયાઓ

મેટ્રિક્સની મૂળભૂત પરિભાષા

મેટ્રિક્સ એ આડી અને ઉભી હરોળોમાં ગોઠવાયેલા અંકોનું આયોજન છે. તેને m×n ક્રમનો મેટ્રિક્સ કહેવાય જ્યાં m = હરોળોની સંખ્યા અને n = સ્તંભોની સંખ્યા. મેટ્રિક્સનો ઉપયોગ રેખીય બીજગણિત, ભૌતિકશાસ્ત્ર અને રસાયણશાસ્ત્રમાં થાય છે.

  • મેટ્રિક્સ = આડી અને ઉભી હરોળોનું આયોજન
  • m×n ક્રમનો મેટ્રિક્સ: m હરોળો, n સ્તંભો
  • મેટ્રિક્સના અવયવોને a_ij વડે દર્શાવાય છે
  • શૂન્ય મેટ્રિક્સના તમામ અવયવો શૂન્ય હોય છે

મેટ્રિક્સના પ્રકાર

મેટ્રિક્સના વિવિધ પ્રકારો જેવા કે વર્ગ મેટ્રિક્સ, દીર્ઘ મેટ્રિક્સ, એકમ મેટ્રિક્સ, ત્રિકોણીય મેટ્રિક્સ અને સમમિત મેટ્રિક્સનો અભ્યાસ કરવો જરૂરી છે. વર્ગ મેટ્રિક્સમાં હરોળો અને સ્તંભોની સંખ્યા સરખી હોય છે.

  • વર્ગ મેટ્રિક્સ: m = n (જેવા કે 2×2, 3×3)
  • દીર્ઘ મેટ્રિક્સ: m ≠ n (જેવા કે 2×3, 3×4)
  • એકમ મેટ્રિક્સ (I): મુખ્ય વિકર્ણ પર 1, બાકી 0
  • સમમિત મેટ્રિક્સ: A = A^T (ટ્રાન્સપોઝ)
  • વિકર્ણ મેટ્રિક્સ: બધા અવયવો શૂન્ય સિવાય મુખ્ય વિકર્ણ પર
🧠 Trick: વર્ગ = સરખી હરોળ-સ્તંભ, એકમ = I, સમમિત = A=A'T

મેટ્રિક્સના સરવાળા અને બાદબાકી

બે મેટ્રિક્સનો સરવાળો અથવા બાદબાકી ત્યારે જ શક્ય છે જ્યારે તેઓ એકસરખા ક્રમના હોય. સરવાળામાં અવયવોનું સરવાળો અને બાદબાકીમાં અવયવોનું બાદબાકી કરવામાં આવે છે.

  • A + B = B + A (ક્રમવિહીન)
  • A + (B + C) = (A + B) + C (સંગ્રહી)
  • A + 0 = A (તટસ્થ અવયવ)
  • A - A = 0 (શૂન્ય મેટ્રિક્સ)
  • સરવાળા માટે ક્રમ સરખા હોવા જરૂરી

મેટ્રિક્સનું ગુણાકાર

મેટ્રિક્સ A (m×n) અને B (n×p)નું ગુણાકાર AB (m×p) ક્રમનો મેટ્રિક્સ આપે છે. ગુણાકાર ક્રમસૂચક નથી, એટલે કે AB ≠ BA. ગુણાકાર માટે પહેલા મેટ્રિક્સના સ્તંભોની સંખ્યા બીજા મેટ્રિક્સની હરોળોની સંખ્યા જેટલી હોવી જોઈએ.

  • AB ≠ BA (ક્રમસૂચક નથી)
  • A(BC) = (AB)C (સંગ્રહી)
  • A(I) = A (તટસ્થ અવયવ)
  • ગુણાકાર માટે Aના સ્તંભો = Bની હરોળો
  • સ્કેલર ગુણાકાર: kA = kને Aના તમામ અવયવો સાથે ગુણવું
🧠 Trick: AB = Aની હરોળ × Bના સ્તંભ

મેટ્રિક્સનું ટ્રાન્સપોઝ

મેટ્રિક્સનું ટ્રાન્સપોઝ એટલે હરોળો અને સ્તંભોની અદલાબદલી કરવી. A^T એ Aનું ટ્રાન્સપોઝ દર્શાવે છે. ટ્રાન્સપોઝના ગુણધર્મો જેવા કે (A^T)^T = A, (A+B)^T = A^T + B^T, અને (AB)^T = B^T A^T મહત્વપૂર્ણ છે.

  • (A^T)^T = A
  • (A + B)^T = A^T + B^T
  • (AB)^T = B^T A^T
  • સમમિત મેટ્રિક્સ માટે A^T = A
  • વિકર્ણ મેટ્રિક્સનું ટ્રાન્સપોઝ = મૂળ મેટ્રિક્સ
🧠 Trick: ટ્રાન્સપોઝ = હરોળ ⇄ સ્તંભ

મેટ્રિક્સનો વ્યસ્ત (Inverse)

વર્ગ મેટ્રિક્સ Aનો વ્યસ્ત A^-1 એવો મેટ્રિક્સ છે કે A * A^-1 = I. વ્યસ્ત અસ્તિત્વમાં હોય ત્યારે જ મેટ્રિક્સને વ્યસ્તયોગ્ય કહેવાય. વ્યસ્ત શોધવા માટે કોફેક્ટર પદ્ધતિ અથવા રોઇટર પદ્ધતિ વાપરવામાં આવે છે.

  • A * A^-1 = I
  • વ્યસ્ત અસ્તિત્વમાં હોય ત્યારે det(A) ≠ 0
  • વ્યસ્તયોગ્ય મેટ્રિક્સ = non-singular
  • (AB)^-1 = B^-1 A^-1
  • (A^T)^-1 = (A^-1)^T
🧠 Trick: વ્યસ્ત = 1/det(A) × adj(A)

મેટ્રિક્સનો ઉપયોગ રેખીય સમીકરણોમાં

રેખીય સમીકરણોના સિસ્ટમને મેટ્રિક્સ સ્વરૂપે લખી શકાય છે: AX = B, જ્યાં A = ગુણાંક મેટ્રિક્સ, X = અજ્ઞાત મેટ્રિક્સ, B = અચળ મેટ્રિક્સ. આને ઉકેલવા માટે વ્યસ્ત પદ્ધતિ અથવા ક્રેમરનો નિયમ વાપરવામાં આવે છે.

  • AX = B, X = A^-1 B (જો A વ્યસ્તયોગ્ય હોય)
  • ક્રેમરનો નિયમ: x_i = det(A_i)/det(A)
  • હોમોજિનિયસ સિસ્ટમ: AX = 0, ઉકેલ X = 0 અથવા અનંત ઉકેલો
  • નોન-હોમોજિનિયસ: AX = B, એકમાત્ર ઉકેલ અથવા કોઈ ઉકેલ નહીં
  • રેંક પદ્ધતિ: રેંક(A) = રેંક([A|B]) = n (એકમાત્ર ઉકેલ)
🧠 Trick: AX=B → X=A^-1B

⚡ Quick Revision

  • મેટ્રિક્સ = m×n કોષ્ટક, a_ij અવયવો
  • વર્ગ મેટ્રિક્સ: m=n, એકમ મેટ્રિક્સ I
  • સરવાળા/બાદબાકી: એકસરખા ક્રમ જરૂરી
  • ગુણાકાર: A(m×n) × B(n×p) = AB(m×p)
  • ટ્રાન્સપોઝ: A^T = હરોળ ⇄ સ્તંભ
  • વ્યસ્ત: A^-1 અસ્તિત્વમાં હોય ત્યારે det(A)≠0
  • રેખીય સમીકરણો: AX=B, X=A^-1B
  • ક્રેમરનો નિયમ: x_i = det(A_i)/det(A)
  • સમમિત મેટ્રિક્સ: A=A^T
  • શૂન્ય મેટ્રિક્સ: તમામ અવયવો 0
🎯 Exam Tip: મેટ્રિક્સના ગુણાકાર અને વ્યસ્ત પર પ્રશ્નો વારંવાર પૂછાય છે, તો ગુણધર્મો અને સૂત્રો યાદ રાખો. ક્રેમરનો નિયમ અને વ્યસ્ત પદ્ધતિનો અભ્યાસ કરો.
