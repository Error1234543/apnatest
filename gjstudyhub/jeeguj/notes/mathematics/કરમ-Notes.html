ક્રમ

📖 ક્રમ (Series)

ક્રમનો પરિચય

ક્રમ એ એક ક્રમબદ્ધ ગણિતીય અવધારણા છે જેમાં સંખ્યાઓ અથવા પદો એક પછી એક ગોઠવાયેલા હોય છે. તે અંકગણિતીય, ગુણોત્તર, અને અન્ય પ્રકારના ક્રમોના રૂપમાં આવી શકે છે. JEEમાં ક્રમના સરવાળા, અસરકારક પદ, અને અસીમિત ક્રમની અભિસરણતા મહત્વના વિષયો છે.

  • ક્રમ એ પદોનો ક્રમબદ્ધ ગણ છે.
  • ક્રમને અંકગણિતીય (AP), ગુણોત્તર (GP), અને હરમોનિક (HP)માં વર્ગીકૃત કરવામાં આવે છે.
  • ક્રમનો સરવાળો અને અસરકારક પદ પરીક્ષામાં વારંવાર પૂછાય છે.

અંકગણિતીય ક્રમ (Arithmetic Progression - AP)

APમાં દરેક પદ અને તેના પૂર્વવર્તી પદ વચ્ચેનો તફાવત સરખો હોય છે, જેને સામાન્ય તફાવત (d) કહેવાય છે. nમા પદનું સૂત્ર aₙ = a₁ + (n-1)d છે. APના પહેલા n પદોના સરવાળાનું સૂત્ર Sₙ = n/2 [2a₁ + (n-1)d] અથવા Sₙ = n/2 (a₁ + aₙ) છે.

  • સામાન્ય તફાવત d = aₙ - aₙ₋₁
  • nમા પદનું સૂત્ર: aₙ = a₁ + (n-1)d
  • સરવાળાનું સૂત્ર: Sₙ = n/2 [2a₁ + (n-1)d]
  • APમાં મધ્ય પદ = (a + b)/2
🧠 Trick: APમાં 'A' એ 'Addition' માટે: દરેક પદમાં d ઉમેરો.

ગુણોત્તર ક્રમ (Geometric Progression - GP)

GPમાં દરેક પદ અને તેના પૂર્વવર્તી પદના ગુણોત્તર સરખો હોય છે, જેને સામાન્ય ગુણોત્તર (r) કહેવાય છે. nમા પદનું સૂત્ર aₙ = a₁ * r^(n-1) છે. GPના પહેલા n પદોના સરવાળાનું સૂત્ર Sₙ = a₁ (rⁿ - 1)/(r - 1) (જ્યારે r ≠ 1) છે.

  • સામાન્ય ગુણોત્તર r = aₙ / aₙ₋₁
  • nમા પદનું સૂત્ર: aₙ = a₁ * r^(n-1)
  • સરવાળાનું સૂત્ર: Sₙ = a₁ (rⁿ - 1)/(r - 1)
  • અસીમિત GPનો સરવાળો S = a₁ / (1 - r), જ્યારે |r| < 1
🧠 Trick: GPમાં 'G' એ 'Growth' માટે: દરેક પદ r વડે ગુણાય છે.

હરમોનિક ક્રમ (Harmonic Progression - HP)

HP એ એવો ક્રમ છે જેમાં દરેક પદના વ્યસ્તો AP બનાવે છે. HPના પદો a₁, a₂, a₃, ... હોય તો 1/a₁, 1/a₂, 1/a₃, ... AP બનાવે છે. HPનો સરવાળો સીધો સૂત્ર નથી, પરંતુ તેને APના વ્યસ્તો તરીકે ગણી શકાય છે.

  • HPના વ્યસ્તો AP બનાવે છે.
  • HPનું nમું પદ: aₙ = 1 / [a₁ + (n-1)d]
  • HPનો સરવાળો ગણવા માટે APના વ્યસ્તોનો ઉપયોગ કરો.
🧠 Trick: HP એ 'Harmonic' છે, જેમ કે સંગીતના સુર: વ્યસ્તો AP બનાવે છે.

ક્રમના સરવાળાના મહત્વના સૂત્રો

AP, GP, અને HPના સરવાળાના સૂત્રો ઉપરાંત, કેટલાક મહત્વના સરવાળા જેમ કે કુદરતી સંખ્યાઓનો સરવાળો (n(n+1)/2), સમ સંખ્યાઓનો સરવાળો (n(n+1)), અને વર્ગોનો સરવાળો (n(n+1)(2n+1)/6) પણ JEEમાં મહત્વના છે.

  • કુદરતી સંખ્યાઓનો સરવાળો: Σn = n(n+1)/2
  • સમ સંખ્યાઓનો સરવાળો: Σ2n = n(n+1)
  • વર્ગોનો સરવાળો: Σn² = n(n+1)(2n+1)/6
  • ઘનોનો સરવાળો: Σn³ = [n(n+1)/2]²

અસીમિત ક્રમ (Infinite Series)

અસીમિત ક્રમ એ એવો ક્રમ છે જેમાં પદોની સંખ્યા અસીમિત હોય છે. અસીમિત GPનો સરવાળો S = a₁ / (1 - r) હોય છે, જ્યારે |r| < 1. અસીમિત ક્રમની અભિસરણતા માટે |r| < 1 હોવું જરૂરી છે.

  • અસીમિત GPનો સરવાળો: S = a₁ / (1 - r), જ્યારે |r| < 1
  • જ્યારે |r| ≥ 1, અસીમિત GP અભિસરિત થતો નથી.
  • અભિસરણતાની શરત: |r| < 1
🧠 Trick: અસીમિત GPમાં 'r' એ 'Ratio' છે, અને તે 1 કરતાં ઓછો હોવો જોઈએ.

ક્રમના અરજીય પ્રશ્નો

JEEમાં ક્રમના પ્રશ્નો સરવાળા, અસરકારક પદ, અથવા ક્રમની અભિસરણતા પર આધારિત હોય છે. કેટલાક પ્રશ્નો ક્રમના ગુણધર્મોનો ઉપયોગ કરીને સરળ બનાવી શકાય છે, જેમ કે AP અને GPના મિશ્રણ વાળા પ્રશ્નો.

  • AP અને GPના મિશ્રણ વાળા પ્રશ્નો મહત્વના છે.
  • ક્રમના ગુણધર્મોનો ઉપયોગ કરીને પ્રશ્નો સરળ બનાવો.
  • અસીમિત ક્રમની અભિસરણતા પર ધ્યાન આપો.
