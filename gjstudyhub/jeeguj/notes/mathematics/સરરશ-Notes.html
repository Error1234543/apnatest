સરેરાશ

📖 સરેરાશ (Average)

સરેરાશની વ્યાખ્યા

સરેરાશ એટલે એકથી વધુ સંખ્યાઓ અથવા મૂલ્યોનો સરવાળો તેની સંખ્યાથી ભાગીને મેળવેલું મૂલ્ય. ગણિતમાં, તે કેન્દ્રીય પ્રવૃત્તિનું મૂળભૂત માપ છે. ભૌતિકશાસ્ત્ર અને રસાયણશાસ્ત્રમાં, તે વેગ, તાપમાન, દબાણ વગેરે જેવા ભૌતિક રાશિઓના મૂલ્યોને સરળતાથી વ્યક્ત કરવા ઉપયોગી છે.

  • સરેરાશ = (સરવાળો) / (સંખ્યા)
  • કેન્દ્રીય પ્રવૃત્તિનું માપ (ગણિત)
  • ભૌતિક રાશિઓના મૂલ્યોને સરળતાથી વ્યક્ત કરે
  • એકથી વધુ મૂલ્યોના સરવાળાનું સરળીકરણ

સરેરાશના પ્રકાર

સરેરાશ ત્રણ પ્રકારના હોય છે: (1) અંકગણિતીય સરેરાશ (Arithmetic Mean), (2) ભૌમિતિક સરેરાશ (Geometric Mean), (3) હરમોનિક સરેરાશ (Harmonic Mean). અંકગણિતીય સરેરાશ સૌથી સામાન્ય છે અને મોટાભાગના પ્રશ્નોમાં ઉપયોગી છે.

  • અંકગણિતીય સરેરાશ = (a₁ + a₂ + ... + aₙ) / n
  • ભૌમિતિક સરેરાશ = n√(a₁ × a₂ × ... × aₙ)
  • હરમોનિક સરેરાશ = n / (1/a₁ + 1/a₂ + ... + 1/aₙ)
  • અંકગણિતીય સરેરાશ સૌથી વધુ વપરાતો પ્રકાર
🧠 Trick: અભહ: અંકગણિતીય, ભૌમિતિક, હરમોનિક

અંકગણિતીય સરેરાશના ગુણધર્મો

અંકગણિતીય સરેરાશમાં કોઈપણ સખત સંખ્યાને ઉમેરવા અથવા બાદ કરવાથી સરેરાશમાં ફેરફાર થતો નથી. જો બધી જ સંખ્યાઓને કોઈ સખત અચળ વડે ગુણવામાં આવે, તો સરેરાશ પણ તે જ અચળ વડે ગુણાય છે.

  • સખત સંખ્યા ઉમેરવા/બાદ કરવાથી સરેરાશ અચળ રહે
  • બધી સંખ્યાઓને અચળ વડે ગુણવાથી સરેરાશ પણ તે વડે ગુણાય
  • સરેરાશ હંમેશા મૂલ્યોની શ્રેણીમાં જ હોય છે
  • સરેરાશ મૂલ્યોની સંખ્યાથી સ્વતંત્ર નથી

ભૌતિકશાસ્ત્રમાં સરેરાશનો ઉપયોગ

ભૌતિકશાસ્ત્રમાં, સરેરાશ વેગ, સરેરાશ પ્રવેગ, સરેરાશ શક્તિ વગેરેનો ઉપયોગ થાય છે. ઉદાહરણ તરીકે, સરેરાશ વેગ = કુલ અંતર / કુલ સમય. આ રાશિઓનો ઉપયોગ ગતિ, ઉર્જા અને શક્તિના અભ્યાસમાં થાય છે.

  • સરેરાશ વેગ = કુલ અંતર / કુલ સમય
  • સરેરાશ પ્રવેગ = વેગમાં ફેરફાર / સમય
  • સરેરાશ શક્તિ = કુલ કામ / કુલ સમય
  • ભૌતિક રાશિઓના મૂલ્યોને સરળતાથી વ્યક્ત કરે
🧠 Trick: વેપ્રશ: વેગ, પ્રવેગ, શક્તિ

રસાયણશાસ્ત્રમાં સરેરાશનો ઉપયોગ

રસાયણશાસ્ત્રમાં, સરેરાશ આણ્વીય દળ, સરેરાશ આણ્વીય વેગ વગેરેનો ઉપયોગ થાય છે. ઉદાહરણ તરીકે, વાયુના અણુઓનું સરેરાશ આણ્વીય દળ તેના ઘનતા અને દબાણના આધારે નક્કી થાય છે.

  • સરેરાશ આણ્વીય દળ = કુલ દળ / અણુઓની સંખ્યા
  • સરેરાશ આણ્વીય વેગ = કુલ વેગ / અણુઓની સંખ્યા
  • વાયુના ગુણધર્મોને સરળતાથી વ્યક્ત કરે
  • રાસાયણિક પ્રક્રિયાઓના અભ્યાસમાં ઉપયોગી

સરેરાશ અને પ્રમાણિત વિચલન

સરેરાશ સાથે પ્રમાણિત વિચલનનો ઉપયોગ ડેટાની વિસ્તૃતિને માપવા માટે થાય છે. પ્રમાણિત વિચલન જેટલું ઓછું હોય, ડેટા સરેરાશની આસપાસ જેટલું વધુ કેન્દ્રિત હોય છે. આ ગણિત અને સાંખ્યિકીમાં મહત્વપૂર્ણ છે.

  • પ્રમાણિત વિચલન = √(વેરિયન્સ)
  • વેરિયન્સ = સરેરાશ (xᵢ - સરેરાશ)²
  • ઓછું પ્રમાણિત વિચલન = ડેટા સરેરાશની આસપાસ કેન્દ્રિત
  • સાંખ્યિકી અને ગણિતમાં મહત્વપૂર્ણ

JEE Main માટે મહત્વપૂર્ણ સૂત્રો

JEE Mainમાં સરેરાશ સંબંધિત પ્રશ્નો માટે અંકગણિતીય, ભૌમિતિક અને હરમોનિક સરેરાશના સૂત્રો યાદ રાખવા જરૂરી છે. સાથે જ, ભૌતિક અને રસાયણશાસ્ત્રમાં સરેરાશના ઉપયોગને સમજવો જરૂરી છે.

  • અંકગણિતીય સરેરાશ = Σxᵢ / n
  • ભૌમિતિક સરેરાશ = (Πxᵢ)^(1/n)
  • હરમોનિક સરેરાશ = n / Σ(1/xᵢ)
  • સરેરાશ વેગ = Δx / Δt
🧠 Trick: અભહ: અંકગણિતીય, ભૌમિતિક, હરમોનિક
