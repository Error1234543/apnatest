જોડી સીધી રેખાઓ

📖 જોડી સીધી રેખાઓ (Pair of Straight Lines)

પાયાની સમજણ

જોડી સીધી રેખાઓ એ બે સીધી રેખાઓનું સંયોજન છે જે એક જ સમીકરણ વડે દર્શાવી શકાય છે. આ સમીકરણ સામાન્ય રીતે દ્વિઘાત સમીકરણ (ax² + 2hxy + by² + 2gx + 2fy + c = 0) સ્વરૂપે હોય છે. જો h² > ab હોય, તો આ સમીકરણ જોડી સીધી રેખાઓ દર્શાવે છે.

  • દ્વિઘાત સમીકરણ દ્વારા દર્શાવાય છે: ax² + 2hxy + by² + 2gx + 2fy + c = 0
  • શરત: h² ≥ ab (જો h² = ab, તો રેખાઓ સમાંતર હોય છે)
  • જો c = 0, તો રેખાઓ ઉદ્ગમબિંદુમાંથી પસાર થાય છે
🧠 Trick: HAB નિયમ: h² ≥ ab યાદ રાખો, જોડી રેખા માટે જરૂરી શરત!

જોડી રેખાઓનું વ્યક્તિગત સમીકરણ

જો જોડી રેખાઓનું સંયુક્ત સમીકરણ ax² + 2hxy + by² = 0 હોય, તો તેને બે રેખાઓમાં વિભાજિત કરી શકાય: y = m₁x અને y = m₂x, જ્યાં m₁ અને m₂ એ (h² - ab) = 0 ના ઉકેલ છે. આ માટે દ્વિઘાત સૂત્રનો ઉપયોગ થાય છે.

  • સંયુક્ત સમીકરણ: ax² + 2hxy + by² = 0
  • વિભાજન: (y - m₁x)(y - m₂x) = 0
  • m₁ + m₂ = -2h/b, m₁m₂ = a/b
🧠 Trick: M-SUM: m₁ + m₂ = -2h/b, M-PRODUCT: m₁m₂ = a/b

રેખાઓ વચ્ચેનો ખૂણો

બે રેખાઓ વચ્ચેનો તીક્ષ્ણ ખૂણો θ નું સૂત્ર tanθ = |2√(h² - ab)/(a + b)| છે. જો a + b = 0 હોય, તો રેખાઓ પરસ્પર લંબ હોય છે. આ ખૂણો શોધવા માટે દ્વિઘાત સમીકરણના ગુણાંકોનો ઉપયોગ થાય છે.

  • tanθ = |2√(h² - ab)/(a + b)|
  • લંબ રેખાઓ માટે શરત: a + b = 0
  • સમાંતર રેખાઓ માટે શરત: h² = ab
🧠 Trick: AB-ZERO: a + b = 0 ⇒ લંબ રેખાઓ

ઉદ્ગમબિંદુથી અંતર

જો જોડી રેખાઓનું સમીકરણ ax² + 2hxy + by² + 2gx + 2fy + c = 0 હોય, તો ઉદ્ગમબિંદુથી દરેક રેખાનું અંતર શોધવા માટે સમીકરણને રેખીય સ્વરૂપમાં ફેરવવું પડે. આ માટે સમીકરણને (lx + my + n)(lx + my + n') = 0 સ્વરૂપમાં લખી શકાય છે.

  • અંતર સૂત્ર: d = |n|/√(l² + m²) (એક રેખા માટે)
  • સંયુક્ત સમીકરણને વિભાજિત કરવું જરૂરી
  • ઉદ્ગમબિંદુથી અંતર માટે c ≠ 0 હોવું જોઈએ

જોડી રેખાઓનું કેન્દ્રબિંદુ

જો જોડી રેખાઓનું સમીકરણ ax² + 2hxy + by² + 2gx + 2fy + c = 0 હોય, તો તેમનું કેન્દ્રબિંદુ (જ્યાં બંને રેખાઓ છેદે છે) શોધવા માટે ∂f/∂x = 0 અને ∂f/∂y = 0 નો ઉપયોગ થાય છે. આનાથી મળતું બિંદુ (x₀, y₀) એ કેન્દ્રબિંદુ છે.

  • કેન્દ્રબિંદુ: x₀ = (hf - bg)/(ab - h²), y₀ = (hg - af)/(ab - h²)
  • ∂f/∂x = 2ax + 2hy + 2g = 0
  • ∂f/∂y = 2hx + 2by + 2f = 0
🧠 Trick: CROSS-H: કેન્દ્ર માટે hf - bg અને hg - af યાદ રાખો

જોડી રેખાઓનું સમીકરણ નિર્માણ

જો બે રેખાઓનાં સમીકરણો L₁ = a₁x + b₁y + c₁ = 0 અને L₂ = a₂x + b₂y + c₂ = 0 હોય, તો તેમનું સંયુક્ત સમીકરણ L₁ × L₂ = 0 થાય. આ દ્વિઘાત સમીકરણ જોડી રેખાઓનું પ્રમાણભૂત સ્વરૂપ છે.

  • સંયુક્ત સમીકરણ: (a₁x + b₁y + c₁)(a₂x + b₂y + c₂) = 0
  • વિસ્તરણ કરતાં દ્વિઘાત સમીકરણ મળે છે
  • ઉદાહરણ: (x + y - 1)(2x - y + 3) = 0
🧠 Trick: L1 × L2 = 0: બે રેખાઓનું ગુણાકાર જોડી રેખાનું સમીકરણ

⚡ Quick Revision

  • જોડી રેખાઓનું સમીકરણ દ્વિઘાત સ્વરૂપે: ax² + 2hxy + by² + ... = 0
  • શરત: h² ≥ ab (h² = ab ⇒ સમાંતર રેખાઓ)
  • ખૂણો શોધવા tanθ = |2√(h² - ab)/(a + b)|
  • લંબ રેખાઓ માટે a + b = 0
  • કેન્દ્રબિંદુ શોધવા ∂f/∂x = 0 અને ∂f/∂y = 0 ઉકેલો
  • બે રેખાઓનું સંયુક્ત સમીકરણ: (L₁)(L₂) = 0
  • ઉદ્ગમબિંદુથી અંતર માટે સમીકરણને રેખીય સ્વરૂપમાં ફેરવો
  • m₁ + m₂ = -2h/b, m₁m₂ = a/b (ઢાળ માટે)
🎯 Exam Tip: જોડી રેખાઓના પ્રશ્નોમાં પહેલા h² ≥ ab શરત ચકાસો. જો શરત પૂરી ન થાય, તો સમીકરણ જોડી રેખાઓ દર્શાવતું નથી. ખૂણો અને કેન્દ્રબિંદુના પ્રશ્નોમાં સૂત્રો યાદ રાખીને સીધા લાગુ કરો — સમય બચાવશે!
