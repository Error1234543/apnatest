ત્રિ-આયામી ભૂમિતિ

📖 ત્રિ-આયામી ભૂમિતિ

ત્રિ-આયામી નિર્દેશાંક પદ્ધતિ

ત્રણ પરસ્પર લંબ આયામો X, Y, Z વડે બનેલી પદ્ધતિ. કોઈ બિંદુનું સ્થાન (x, y, z) ત્રિપદી રૂપે દર્શાવાય છે. Z-અક્ષ યથાર્થ અથવા કાલ્પનિક હોવાને આધારે જમણી-હાથ અથવા ડાબી-હાથ પદ્ધતિ વપરાય છે.

  • X, Y, Z અક્ષો પરસ્પર લંબ અને એકબીજાને કાપે છે
  • બિંદુ (x, y, z) ના x, y, z ને ક્રમશઃ X, Y, Z અક્ષ પરના અંતર તરીકે ઓળખાય
  • જમણી-હાથ પદ્ધતિમાં Z-અક્ષ X થી Y તરફ વળતી દિશામાં હોય છે
  • ડાબી-હાથ પદ્ધતિમાં Z-અક્ષ X થી Y તરફ વળતી દિશાની વિરુદ્ધ હોય છે
🧠 Trick: XYZ: X-આગળ, Y-જમણી, Z-ઉપર (જમણી-હાથ)

બિંદુઓ વચ્ચેનું અંતર

બે બિંદુઓ P(x₁, y₁, z₁) અને Q(x₂, y₂, z₂) વચ્ચેનું અંતર d = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²]. આ સૂત્ર પાયથાગોરસ પ્રમેયનું ત્રિ-આયામી રૂપ છે.

  • અંતર સૂત્ર પાયથાગોરસ પ્રમેયનું વિસ્તરણ છે
  • ત્રણેય આયામોના ફેરફારના વર્ગોનો સરવાળો વર્ગમૂળ લેવાય છે
  • જો z₁ = z₂ = 0, તો સૂત્ર 2D અંતરમાં રૂપાંતરિત થાય છે

રેખાનું સમીકરણ

રેખાને બે બિંદુઓ અથવા એક બિંદુ અને દિશા સદિશ વડે વ્યાખ્યાયિત કરાય છે. દિશા કોસાઇન l, m, n વડે રેખાનું સમીકરણ (x-x₁)/l = (y-y₁)/m = (z-z₁)/n રૂપે લખાય છે.

  • દિશા કોસાઇન l = cosα, m = cosβ, n = cosγ, જ્યાં α, β, γ ક્રમશઃ X, Y, Z અક્ષ સાથેના ખૂણાઓ છે
  • l² + m² + n² = 1 હંમેશા સંતોષાય છે
  • રેખાનું સિમેટ્રિક રૂપ (x-x₁)/a = (y-y₁)/b = (z-z₁)/c, જ્યાં a, b, c દિશા સદિશના ઘટકો છે
🧠 Trick: LMN: l=X, m=Y, n=Z (દિશા કોસાઇન)

તલનું સમીકરણ

તલને અવકાશમાં એક સપાટી તરીકે વ્યાખ્યાયિત કરાય છે. સામાન્ય રૂપ Ax + By + Cz + D = 0. તલના લંબ અંતર અને દિશા સદિશની ગણતરી થઈ શકે છે.

  • તલનું સામાન્ય સદિશ (A, B, C) હોય છે
  • બિંદુ (x₀, y₀, z₀) થી તલનું લંબ અંતર |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²)
  • બે તલો વચ્ચેનો ખૂણો cosθ = |A₁A₂ + B₁B₂ + C₁C₂| / (√(A₁²+B₁²+C₁²) * √(A₂²+B₂²+C₂²))

સદિશો પર કાર્યવાહી

સદિશોનો સરવાળો, બાદબાકી, સ્કેલર ગુણાકાર, ડોટ પ્રોડક્ટ અને ક્રોસ પ્રોડક્ટ ત્રિ-આયામી ભૂમિતિમાં મહત્વના છે. ક્રોસ પ્રોડક્ટનો પરિણામ સદિશ લંબ દિશામાં હોય છે.

  • ડોટ પ્રોડક્ટ A·B = |A||B|cosθ, સ્કેલર પરિણામ
  • ક્રોસ પ્રોડક્ટ A×B = |A||B|sinθ n̂, સદિશ પરિણામ (n̂ લંબ એકમ સદિશ)
  • A×B ની દિશા જમણી-હાથના નિયમ અનુસાર નક્કી થાય છે
  • |A×B| = ક્ષેત્રફળ (પેરાલેલોગ્રામ)
🧠 Trick: ડોટ = સ્કેલર, ક્રોસ = સદિશ

ઘન અને પૃષ્ઠના કદ અને ક્ષેત્રફળ

ત્રિ-આયામી આકૃતિઓ જેવી કે ઘન, ગોળો, શંકુ, સિલિન્ડરના કદ અને પૃષ્ઠક્ષેત્રની ગણતરી માટે સૂત્રો ઉપયોગી છે. ઘનના કદ = લંબાઈ × પહોળાઈ × ઊંચાઈ.

  • ગોળાનું કદ = (4/3)πr³, પૃષ્ઠક્ષેત્ર = 4πr²
  • શંકુનું કદ = (1/3)πr²h, પૃષ્ઠક્ષેત્ર = πr(r + l) (l = તિર્યક ઊંચાઈ)
  • સિલિન્ડરનું કદ = πr²h, પૃષ્ઠક્ષેત્ર = 2πr(r + h)

ત્રિ-આયામી ભૂમિતિમાં ખૂણા

રેખા-રેખા, રેખા-તલ, તલ-તલ વચ્ચેના ખૂણાની ગણતરી દિશા સદિશ અથવા દિશા કોસાઇન વડે કરાય છે. રેખા અને તલ વચ્ચેનો ખૂણો 90° - રેખા અને તલના લંબ વચ્ચેનો ખૂણો હોય છે.

  • રેખા-રેખા વચ્ચેનો ખૂણો cosθ = |a₁a₂ + b₁b₂ + c₁c₂| / (√(a₁²+b₁²+c₁²) * √(a₂²+b₂²+c₂²))
  • રેખા-તલ વચ્ચેનો ખૂણો sinφ = |Aa + Bb + Cc| / (√(A²+B²+C²) * √(a²+b²+c²))
  • બે તલો વચ્ચેનો ખૂણો તેમના સામાન્ય સદિશો વચ્ચેનો ખૂણો હોય છે
🧠 Trick: રેખા-તલ ખૂણો = 90° - લંબ ખૂણો

⚡ Quick Revision

  • ત્રિ-આયામી નિર્દેશાંક (x, y, z) ત્રણ લંબ આયામો વડે વ્યાખ્યાયિત
  • બિંદુઓ વચ્ચેનું અંતર = √[(Δx)² + (Δy)² + (Δz)²]
  • રેખાનું સમીકરણ: (x-x₁)/l = (y-y₁)/m = (z-z₁)/n
  • તલનું સમીકરણ: Ax + By + Cz + D = 0
  • ડોટ પ્રોડક્ટ = સ્કેલર, ક્રોસ પ્રોડક્ટ = સદિશ
  • ગોળાનું કદ = (4/3)πr³, પૃષ્ઠક્ષેત્ર = 4πr²
  • રેખા-રેખા ખૂણો: દિશા સદિશો વડે ગણાય છે
  • રેખા-તલ ખૂણો = 90° - લંબ ખૂણો
  • દિશા કોસાઇનનો સરવાળો l² + m² + n² = 1
  • ક્રોસ પ્રોડક્ટની દિશા જમણી-હાથના નિયમ અનુસાર
🎯 Exam Tip: ત્રિ-આયામી ભૂમિતિમાં દિશા કોસાઇન અને સદિશ કાર્યવાહી પર પ્રશ્નો વારંવાર પૂછાય છે — સૂત્રો અને નિયમો કંઠસ્થ કરો!
