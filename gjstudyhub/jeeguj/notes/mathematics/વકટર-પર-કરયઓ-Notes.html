વેક્ટર પર ક્રિયાઓ

📖 વેક્ટર પર ક્રિયાઓ

વેક્ટરની વ્યાખ્યા અને પ્રકાર

વેક્ટર એ મહત્ત્વ અને દિશા ધરાવતું ભૌતિક રાશિ છે. તેને ગ્રાફિકલી તીરની મદદથી દર્શાવવામાં આવે છે. વેક્ટર બે પ્રકારના હોય છે: સદિશ (પોઝિટિવ દિશા) અને વિદિશ (નેગેટિવ દિશા).

  • વેક્ટર = મહત્ત્વ + દિશા
  • સદિશ વેક્ટર: દિશા ધરાવે છે (ઉદા. વેગ, બળ)
  • વિદિશ વેક્ટર: દિશા નથી (ઉદા. દળ, તાપમાન)
  • ગ્રાફિકલ રજૂઆત: તીરની લંબાઈ = મહત્ત્વ, તીરની દિશા = વેક્ટરની દિશા
🧠 Trick: સદિશ = સરખી દિશા, વિદિશ = વિના દિશા

વેક્ટરનું સદિશ રૂપાંતરણ

વેક્ટરને સદિશ રૂપમાં લખવા માટે તેના મહત્ત્વ અને દિશાનો ઉપયોગ કરવામાં આવે છે. ઉદા. **A** = A * î (x-દિશામાં), **B** = B * ĵ (y-દિશામાં).

  • સદિશ રૂપ: **A** = A_x î + A_y ĵ + A_z k̂
  • î, ĵ, k̂ એ એકમ વેક્ટર છે
  • A_x, A_y, A_z એ વેક્ટરના ઘટકો છે
  • મહત્ત્વ = √(A_x² + A_y² + A_z²)
🧠 Trick: î = x, ĵ = y, k̂ = z

વેક્ટરનો સરવાળો

વેક્ટરનો સરવાળો ત્રિકોણ નિયમ અથવા સમલંબ નિયમ દ્વારા કરવામાં આવે છે. સરવાળાનું પરિણામી વેક્ટર બંને વેક્ટરના મહત્ત્વ અને દિશાનું સરવાળું હોય છે.

  • ત્રિકોણ નિયમ: **A** + **B** = **R** (જ્યાં **R** એ પરિણામી વેક્ટર)
  • સમલંબ નિયમ: **A** + **B** = √(A² + B² + 2ABcosθ)
  • θ એ બંને વેક્ટર વચ્ચેનો ખૂણો છે
  • સરવાળો કોમ્યુટેટિવ છે: **A** + **B** = **B** + **A**
🧠 Trick: ત્રિકોણ + સમલંબ = સરવાળો

વેક્ટરનો બાદબાકી

વેક્ટરનો બાદબાકી એ સરવાળાનું વિરુદ્ધ છે. **A** - **B** = **A** + (-**B**), જ્યાં -**B** એ **B**નો વિરુદ્ધ વેક્ટર છે.

  • બાદબાકી = સરવાળો + વિરુદ્ધ વેક્ટર
  • **A** - **B** = √(A² + B² - 2ABcosθ)
  • θ એ **A** અને **B** વચ્ચેનો ખૂણો છે
  • બાદબાકી એ કોમ્યુટેટિવ નથી
🧠 Trick: બાદબાકી = સરવાળો + વિરુદ્ધ

વેક્ટરનો સ્કેલર ગુણાકાર

વેક્ટરનો સ્કેલર ગુણાકાર એ વેક્ટરના મહત્ત્વને સ્કેલર રાશિથી ગુણવાથી મળે છે. પરિણામે વેક્ટરની દિશા બદલાય નહીં, પરંતુ મહત્ત્વ બદલાય છે.

  • k**A** = k * A (મહત્ત્વ)
  • દિશા: જો k > 0 તો દિશા સમાન, જો k < 0 તો દિશા વિરુદ્ધ
  • સ્કેલર ગુણાકાર એ કોમ્યુટેટિવ છે
🧠 Trick: k > 0 = સમાન દિશા, k < 0 = વિરુદ્ધ દિશા

વેક્ટરનો ડોટ ગુણાકાર (સ્કેલર ગુણાકાર)

ડોટ ગુણાકાર એ બે વેક્ટરના ગુણાકારનો સ્કેલર પરિણામ આપે છે. **A** · **B** = |**A**||**B**|cosθ, જ્યાં θ એ બંને વેક્ટર વચ્ચેનો ખૂણો છે.

  • **A** · **B** = A_x B_x + A_y B_y + A_z B_z
  • ડોટ ગુણાકાર એ કોમ્યુટેટિવ છે
  • **A** · **B** = 0 ⇒ વેક્ટર લંબરૂપ છે
  • ડોટ ગુણાકાર એ ડિસ્ટ્રિબ્યુટિવ છે
🧠 Trick: ડોટ = સ્કેલર, કોસ = ખૂણો

વેક્ટરનો ક્રોસ ગુણાકાર (સદિશ ગુણાકાર)

ક્રોસ ગુણાકાર એ બે વેક્ટરના ગુણાકારનો વેક્ટર પરિણામ આપે છે. **A** × **B** = |**A**||**B**|sinθ * n̂, જ્યાં n̂ એ **A** અને **B**ને લંબ દિશામાં એકમ વેક્ટર છે.

  • **A** × **B** = (A_y B_z - A_z B_y)î + (A_z B_x - A_x B_z)ĵ + (A_x B_y - A_y B_x)k̂
  • ક્રોસ ગુણાકાર એ એન્ટી-કોમ્યુટેટિવ છે: **A** × **B** = -(**B** × **A**)
  • **A** × **B** = 0 ⇒ વેક્ટર સમાન દિશામાં છે
  • ક્રોસ ગુણાકાર એ ડિસ્ટ્રિબ્યુટિવ છે
🧠 Trick: ક્રોસ = વેક્ટર, સિન = ખૂણો

⚡ Quick Revision

  • વેક્ટર = મહત્ત્વ + દિશા
  • સદિશ રૂપ: **A** = A_x î + A_y ĵ + A_z k̂
  • સરવાળો: ત્રિકોણ નિયમ અથવા સમલંબ નિયમ
  • બાદબાકી: **A** - **B** = **A** + (-**B**)
  • સ્કેલર ગુણાકાર: k**A** = k * A (મહત્ત્વ)
  • ડોટ ગુણાકાર: **A** · **B** = |**A**||**B**|cosθ
  • ક્રોસ ગુણાકાર: **A** × **B** = |**A**||**B**|sinθ * n̂
  • **A** · **B** = 0 ⇒ લંબરૂપ વેક્ટર
  • **A** × **B** = 0 ⇒ સમાન દિશામાં વેક્ટર
  • ક્રોસ ગુણાકાર એ એન્ટી-કોમ્યુટેટિવ છે
🎯 Exam Tip: ડોટ અને ક્રોસ ગુણાકારના સૂત્રો અને તેમના ભૌતિક અર્થ (લંબરૂપતા, સમાન દિશા) યાદ રાખો — આ JEEમાં વારંવાર પૂછાય છે.
