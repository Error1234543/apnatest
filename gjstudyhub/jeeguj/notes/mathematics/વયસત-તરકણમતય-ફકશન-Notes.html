વ્યસ્ત ત્રિકોણમિતીય ફંક્શન

📖 વ્યસ્ત ત્રિકોણમિતીય ફંક્શન (Inverse Trigonometric Functions)

પરિચય અને વ્યાખ્યા

વ્યસ્ત ત્રિકોણમિતીય ફંક્શન એ મૂળ ત્રિકોણમિતીય ફંક્શનના વ્યસ્ત છે, જે કોણ શોધવા માટે ઉપયોગી છે. જો y = sin(x) હોય, તો x = sin⁻¹(y) અથવા arcsin(y) લખાય છે. આ ફંક્શનનો ડોમેઇન અને રેન્જ મર્યાદિત હોય છે જેથી તે એક-એક અને વ્યાપક બને.

  • sin⁻¹(x) નો ડોમેઇન: [-1, 1], રેન્જ: [-π/2, π/2]
  • cos⁻¹(x) નો ડોમેઇન: [-1, 1], રેન્જ: [0, π]
  • tan⁻¹(x) નો ડોમેઇન: R, રેન્જ: (-π/2, π/2)
  • વ્યસ્ત ફંક્શન માટે મૂળ ફંક્શન એક-એક હોવું જરૂરી
🧠 Trick: સાઇન-પાઇ/2, કોસ-પાઇ, ટેન-પાઇ/2 (ડોમેઇન અને રેન્જ યાદ રાખવા)

મુખ્ય મૂલ્યો અને ગ્રાફ

વ્યસ્ત ત્રિકોણમિતીય ફંક્શનના મુખ્ય મૂલ્યો તેમના રેન્જમાં આવે છે. ગ્રાફ દોરીને સમજવું જરૂરી છે: sin⁻¹(x) અને tan⁻¹(x) વધતું ફંક્શન છે, જ્યારે cos⁻¹(x) ઘટતું ફંક્શન છે. ગ્રાફની સમમિતિ અને અસિમ્પ્ટોટ્સ પર ધ્યાન આપો.

  • sin⁻¹(x) + cos⁻¹(x) = π/2 (x ∈ [-1, 1])
  • tan⁻¹(x) + cot⁻¹(x) = π/2 (x ∈ R)
  • sin⁻¹(-x) = -sin⁻¹(x), cos⁻¹(-x) = π - cos⁻¹(x)
  • tan⁻¹(-x) = -tan⁻¹(x)
🧠 Trick: સાઇન-ઓડ, કોસ-ઇવન (sin⁻¹ અને tan⁻¹ ઓડ ફંક્શન, cos⁻¹ ઇવન ફંક્શન નહીં)

સૂત્રો અને ઓળખ

વ્યસ્ત ત્રિકોણમિતીય ફંક્શન માટેના મહત્વપૂર્ણ સૂત્રો અને ઓળખ JEE Main માં વારંવાર પૂછાય છે. આ સૂત્રોનો ઉપયોગ સમીકરણ ઉકેલવા, અભિવ્યક્તિ સરળ કરવા અને પ્રમેય સાબિત કરવા થાય છે.

  • sin⁻¹(x) + sin⁻¹(y) = sin⁻¹(x√(1-y²) + y√(1-x²)) જો x² + y² ≤ 1
  • cos⁻¹(x) + cos⁻¹(y) = cos⁻¹(xy - √[(1-x²)(1-y²)]) જો x + y ≥ 0
  • tan⁻¹(x) + tan⁻¹(y) = tan⁻¹[(x+y)/(1-xy)] જો xy < 1
  • 2tan⁻¹(x) = sin⁻¹(2x/(1+x²)) = cos⁻¹((1-x²)/(1+x²)) = tan⁻¹(2x/(1-x²))
🧠 Trick: સાઇન-સરવાળો: x-રૂટ + y-રૂટ, કોસ-સરવાળો: xy - રૂટ

વ્યુત્પન્ન અને સંકલન

વ્યસ્ત ત્રિકોણમિતીય ફંક્શનના વ્યુત્પન્ન અને સંકલનના સૂત્રો કેલ્ક્યુલસમાં મહત્વપૂર્ણ છે. આ સૂત્રો યાદ રાખવા અને તેમનો ઉપયોગ વિવિધ પ્રકારના પ્રશ્નોમાં કરવો જરૂરી છે.

  • d/dx [sin⁻¹(x)] = 1/√(1-x²)
  • d/dx [cos⁻¹(x)] = -1/√(1-x²)
  • d/dx [tan⁻¹(x)] = 1/(1+x²)
  • ∫1/√(1-x²) dx = sin⁻¹(x) + C
  • ∫1/(1+x²) dx = tan⁻¹(x) + C
🧠 Trick: સાઇન-વ્યુત્પન્ન: 1/રૂટ, કોસ-વ્યુત્પન્ન: -1/રૂટ, ટેન-વ્યુત્પન્ન: 1/(1+x²)

સમીકરણ અને અસમતા

વ્યસ્ત ત્રિકોણમિતીય ફંક્શનના સમીકરણ અને અસમતા ઉકેલવા માટે ડોમેઇન અને રેન્જની મર્યાદાઓને ધ્યાનમાં લેવી જરૂરી છે. મૂળ ફંક્શનનો ઉપયોગ કરીને કોણ શોધવો અને પછી વ્યસ્ત ફંક્શનના રેન્જમાં મર્યાદિત કરવો.

  • sin⁻¹(x) = θ ⇒ x = sin(θ) અને θ ∈ [-π/2, π/2]
  • cos⁻¹(x) = θ ⇒ x = cos(θ) અને θ ∈ [0, π]
  • tan⁻¹(x) = θ ⇒ x = tan(θ) અને θ ∈ (-π/2, π/2)
  • sin⁻¹(x) > cos⁻¹(x) ⇒ x ∈ [-1, 1/√2)
🧠 Trick: સમીકરણ ઉકેલતી વખતે રેન્જ યાદ રાખો: સાઇન-પાઇ/2, કોસ-પાઇ, ટેન-પાઇ/2

ઉપયોગ અને પ્રશ્નોના પ્રકાર

JEE Main માં વ્યસ્ત ત્રિકોણમિતીય ફંક્શનના પ્રશ્નો મુખ્યત્વે સૂત્રોના ઉપયોગ, સમીકરણ ઉકેલવા, અભિવ્યક્તિ સરળ કરવા, વ્યુત્પન્ન અને સંકલન પર આધારિત હોય છે. પ્રશ્નોને ઝડપથી ઓળખવા અને યોગ્ય સૂત્ર લાગુ કરવું જરૂરી છે.

  • સૂત્રોનો ઉપયોગ કરીને અભિવ્યક્તિ સરળ કરવી
  • સમીકરણ ઉકેલવા માટે ડોમેઇન અને રેન્જની મર્યાદા ધ્યાનમાં લેવી
  • વ્યુત્પન્ન અને સંકલનના પ્રશ્નોમાં યોગ્ય સૂત્ર લાગુ કરવું
  • અસમતા ઉકેલવા માટે ગ્રાફ અને મૂલ્યોનો ઉપયોગ
  • પ્રત્યક્ષ અને પરોક્ષ પ્રશ્નો ઓળખવા
