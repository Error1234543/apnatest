અવકલન

📖 અવકલન (Differentiation)

અવકલનનો મૂળ ખ્યાલ

અવકલન એ ગણિતની એક મૂળભૂત પ્રક્રિયા છે જે ફંક્શનના ફેરફારના દરને માપે છે. જો y = f(x) હોય, તો અવકલન dy/dx અથવા f'(x) વડે દર્શાવાય છે, જે x ના સંદર્ભમાં y નો તાત્કાલિક ફેરફાર દર્શાવે છે. ભૌતિકશાસ્ત્રમાં વેગ, પ્રવેગ અને રાસાયણિક પ્રક્રિયાનો દર શોધવા માટે ઉપયોગી છે.

  • અવકલન = ફંક્શનનો તાત્કાલિક ફેરફાર દર
  • dy/dx = lim (Δx→0) [f(x+Δx) - f(x)]/Δx
  • સ્પર્શક રેખાનો ઢાળ = f'(x)
  • અચળ સંખ્યાનું અવકલન શૂન્ય
🧠 Trick: DIFF → Δy/Δx → ફેરફારનો દર

અવકલનના મૂળ નિયમો

NCERTમાં આપેલા મૂળભૂત નિયમો: સરવાળાનો નિયમ (u+v)' = u' + v', ગુણાકારનો નિયમ (uv)' = u'v + uv', અને ભાગાકારનો નિયમ (u/v)' = (u'v - uv')/v². આ નિયમો બહુપદી, ત્રિકોણમિતીય અને ઘાતાંકીય ફંક્શનના અવકલન માટે જરૂરી છે.

  • સરવાળો: (u+v)' = u' + v'
  • ગુણાકાર: (uv)' = u'v + uv'
  • ભાગાકાર: (u/v)' = (u'v - uv')/v²
  • શૃંખલા નિયમ: dy/dx = dy/du × du/dx
🧠 Trick: UV નિયમ: ઉંદર વડે ઉંદર + વડ વડે ઉંદર

સામાન્ય ફંક્શનના અવકલન

xⁿ નું અવકલન nxⁿ⁻¹, eˣ નું eˣ, aˣ નું aˣ ln a, ln x નું 1/x, sin x નું cos x, અને cos x નું -sin x થાય છે. આ સૂત્રો JEE Mainમાં સૌથી વધુ પૂછાતા પ્રશ્નો માટે મૂળભૂત છે.

  • xⁿ → nxⁿ⁻¹
  • eˣ → eˣ
  • aˣ → aˣ ln a
  • ln x → 1/x
  • sin x → cos x
  • cos x → -sin x
🧠 Trick: eˣ નું અવકલન એ જ રહે, sin-cos નું ચક્ર યાદ રાખો

અવકલનના ભૌતિક અને રાસાયણિક ઉપયોગ

ભૌતિકશાસ્ત્રમાં સ્થાન-સમયના ફંક્શનનું અવકલન વેગ આપે છે, અને વેગ-સમયનું અવકલન પ્રવેગ આપે છે. રસાયણશાસ્ત્રમાં પ્રક્રિયાનો દર = -d[R]/dt અથવા d[P]/dt વડે દર્શાવાય છે, જે સાંદ્રતાના ફેરફારનો દર છે.

  • વેગ = ds/dt
  • પ્રવેગ = dv/dt = d²s/dt²
  • પ્રક્રિયાનો દર = ±d[સાંદ્રતા]/dt
  • ઊર્જા-સમયનું અવકલન = પાવર
🧠 Trick: DSDT → ડિસ્પ્લેસમેન્ટ સ્પીડ ટાઈમ

અંતર્ગત અવકલન (Implicit Differentiation)

જ્યારે y ને x ના સ્પષ્ટ ફંક્શન તરીકે દર્શાવી ન શકાય (દા.ત. x² + y² = r²), ત્યારે બંને બાજુઓનું x ના સંદર્ભમાં અવકલન કરવામાં આવે છે. dy/dx શોધવા માટે y ને પણ x ના ફંક્શન તરીકે ગણીને શૃંખલા નિયમ લાગુ કરવામાં આવે છે.

  • બંને બાજુઓનું x ના સંદર્ભમાં અવકલન કરો
  • y ને x ના ફંક્શન તરીકે ગણો (dy/dx ઉમેરો)
  • dy/dx માટે ઉકેલો
  • વર્તુળનું સમીકરણ: dy/dx = -x/y
🧠 Trick: XY નું અવકલન: X ને સાદું, Y ને ડોટ લગાવો

ઉચ્ચ ક્રમના અવકલન

પ્રથમ ક્રમનું અવકલન f'(x) હોય, તો બીજા ક્રમનું અવકલન f''(x) = d²y/dx² થાય છે. ભૌતિકશાસ્ત્રમાં પ્રવેગ = d²s/dt² અને જર્ક = d³s/dt³ વડે દર્શાવાય છે. રસાયણશાસ્ત્રમાં પ્રક્રિયાના દરના ફેરફાર માટે ઉપયોગી છે.

  • f''(x) = d/dx (f'(x))
  • પ્રવેગ = d²s/dt²
  • જર્ક = d³s/dt³
  • ઉચ્ચ ક્રમના અવકલન = ફેરફારના દરનો ફેરફાર
🧠 Trick: ડબલ ડેરિવેટિવ = ડબલ ડોટ

લઘુત્તમ અને મહત્તમ મૂલ્યો (Maxima-Minima)

ફંક્શનના લઘુત્તમ/મહત્તમ બિંદુઓ શોધવા માટે f'(x) = 0 ઉકેલીને ક્રાંતિક બિંદુઓ મેળવવામાં આવે છે. બીજા ક્રમના અવકલન પરીક્ષણ વડે: f''(x) > 0 → લઘુત્તમ, f''(x) < 0 → મહત્તમ. આર્થિક અને ઔદ્યોગિક સમસ્યાઓમાં ઉપયોગી છે.

  • f'(x) = 0 → ક્રાંતિક બિંદુઓ
  • f''(x) > 0 → લઘુત્તમ
  • f''(x) < 0 → મહત્તમ
  • f''(x) = 0 → પરીક્ષણ નિષ્ફળ
🧠 Trick: પોઝિટિવ ડબલ ડેરિવેટિવ = ખાડો (લઘુત્તમ)

🎯 Exam Tip: JEE Mainમાં અવકલનના પ્રશ્નોમાં સૌથી વધુ ગુણાકાર અને ભાગાકારના નિયમો પર આધારિત પ્રશ્નો પૂછાય છે. UV નિયમ યાદ રાખીને પ્રેક્ટિસ કરો, અને સમય બચાવવા માટે સૂત્રોને તરત ઓળખો.
