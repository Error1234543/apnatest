પરમ્યુટેશન

📖 પરમ્યુટેશન (Permutation)

પરમ્યુટેશનનો મૂળ ખ્યાલ

પરમ્યુટેશન એ વસ્તુઓના ક્રમબદ્ધ ગોઠવણીનો અભ્યાસ છે. જ્યારે આપણે કોઈ વસ્તુઓને ચોક્કસ ક્રમમાં ગોઠવીએ, ત્યારે તેને પરમ્યુટેશન કહે છે. ઉદાહરણ તરીકે, અક્ષરો A, B, C ને 3! = 6 રીતે ગોઠવી શકાય. પરમ્યુટેશનનો ઉપયોગ સંખ્યાઓ, અક્ષરો, અથવા કોઈપણ વસ્તુઓની ગોઠવણી માટે થાય છે.

  • પરમ્યુટેશન = ક્રમપૂર્વક ગોઠવણી
  • n વસ્તુઓની ગોઠવણી = n!
  • જો વસ્તુઓ પુનરાવર્તિત થાય, તો સૂત્ર બદલાય છે
🧠 Trick: પ-ર-મ = પહેલાં રાખો મહત્વ ક્રમનું

પરમ્યુટેશનનું સૂત્ર (Permutation Formula)

જો n અલગ વસ્તુઓમાંથી r વસ્તુઓ પસંદ કરીને ગોઠવવાની હોય, તો પરમ્યુટેશનની સંખ્યા P(n, r) = n! / (n-r)! થાય. આ સૂત્રનો ઉપયોગ ત્યારે થાય જ્યારે ક્રમ મહત્વનો હોય. ઉદાહરણ: 5 અક્ષરોમાંથી 2 અક્ષરોની ગોઠવણી = P(5,2) = 5! / 3! = 20.

  • P(n, r) = n! / (n-r)!
  • ક્રમ મહત્વનો હોય ત્યારે P(n, r) વપરાય
  • P(n, n) = n! (બધી વસ્તુઓ ગોઠવવી)
🧠 Trick: પ-ર = પસંદ કરી રાખો ક્રમ

પુનરાવર્તિત વસ્તુઓનું પરમ્યુટેશન

જો કોઈ વસ્તુઓ પુનરાવર્તિત થતી હોય, તો પરમ્યુટેશનનું સૂત્ર બદલાય છે. જો n વસ્તુઓમાં p વસ્તુઓ એકસમાન, q વસ્તુઓ એકસમાન હોય, તો પરમ્યુટેશન = n! / (p! × q!). ઉદાહરણ: MISSISSIPPI શબ્દમાં અક્ષરોની ગોઠવણી = 11! / (4! × 4! × 2!).

  • પુનરાવર્તિત વસ્તુઓ માટે: n! / (p! × q! × ...)
  • એકસમાન વસ્તુઓના ફેક્ટોરિયલ વડે ભાગાકાર
  • ઉદાહરણ: AABC = 4! / 2! = 12
🧠 Trick: પુ-ન-રા = પુનરાવર્તન રોકવા ફેક્ટોરિયલ વડે ભાગો

વર્તુળાકાર પરમ્યુટેશન (Circular Permutation)

જ્યારે વસ્તુઓ વર્તુળમાં ગોઠવવાની હોય, ત્યારે પરમ્યુટેશનનું સૂત્ર બદલાય છે. n વસ્તુઓની વર્તુળાકાર ગોઠવણી = (n-1)!. આનું કારણ એ છે કે એક વસ્તુને સ્થિર રાખીને બાકીની ગોઠવણી કરવામાં આવે છે. ઉદાહરણ: 4 વ્યક્તિઓને ગોળ ટેબલ પર ગોઠવવી = (4-1)! = 6 રીતે.

  • વર્તુળાકાર ગોઠવણી = (n-1)!
  • એક વસ્તુ સ્થિર રાખીને ગણતરી
  • જો ઘડિયાળની દિશા મહત્વની ન હોય, તો (n-1)! / 2
🧠 Trick: વ-ર-તુ = વર્તુળમાં રાખો એકને તુર્ત જ સ્થિર

પરમ્યુટેશન અને સંયોજન વચ્ચેનો તફાવત

પરમ્યુટેશનમાં ક્રમ મહત્વનો હોય છે, જ્યારે સંયોજનમાં ક્રમ મહત્વનો હોતો નથી. ઉદાહરણ: અક્ષરો A, B, C માંથી 2 પસંદ કરવા: પરમ્યુટેશન = AB, BA, AC, CA, BC, CB (6 રીતે), સંયોજન = AB, AC, BC (3 રીતે). સંયોજનનું સૂત્ર C(n, r) = n! / (r! × (n-r)!).

  • પરમ્યુટેશન = ક્રમ મહત્વનો
  • સંયોજન = ક્રમ મહત્વનો નહીં
  • P(n, r) = C(n, r) × r!
🧠 Trick: પ-સ = પરમ્યુટેશનમાં સીરિયલ નંબર મહત્વનો

પરમ્યુટેશનના પ્રાયોગિક ઉપયોગો

પરમ્યુટેશનનો ઉપયોગ વિવિધ વાસ્તવિક સમસ્યાઓમાં થાય છે, જેમ કે પાસવર્ડની ગોઠવણી, રમતોના ક્રમ, સીટિંગ અરેન્જમેન્ટ, અને કોડિંગ સમસ્યાઓ. ઉદાહરણ: 4 અંકોનો પિન કોડ = 10^4 = 10000 રીતે (પુનરાવર્તન સાથે), પરંતુ જો પુનરાવર્તન ન હોય તો P(10,4) = 5040 રીતે.

  • પાસવર્ડ/પિન કોડ ગોઠવણી
  • સીટિંગ અરેન્જમેન્ટ
  • રમતોના ક્રમની ગોઠવણી
  • કોડિંગ અને ક્રિપ્ટોગ્રાફી
🧠 Trick: પ-ર-મ = પાસવર્ડ રચવા માટે મહત્વનું

⚡ Quick Revision

  • પરમ્યુટેશન = ક્રમપૂર્વક ગોઠવણી
  • P(n, r) = n! / (n-r)!
  • પુનરાવર્તિત વસ્તુઓ માટે: n! / (p! × q! × ...)
  • વર્તુળાકાર પરમ્યુટેશન = (n-1)!
  • પરમ્યુટેશન vs સંયોજન: ક્રમ મહત્વનો vs નહીં
  • P(n, n) = n! (બધી વસ્તુઓ ગોઠવવી)
  • સંયોજન C(n, r) = P(n, r) / r!
  • પાસવર્ડ/પિન કોડમાં પરમ્યુટેશનનો ઉપયોગ
  • એક વસ્તુ સ્થિર રાખીને વર્તુળાકાર ગોઠવણી
  • પ્રશ્નમાં ક્રમ મહત્વનો છે કે નહીં તે ઓળખો
🎯 Exam Tip: પરમ્યુટેશનના પ્રશ્નોમાં સૌથી પહેલાં ઓળખો કે ક્રમ મહત્વનો છે કે નહીં. જો ક્રમ મહત્વનો હોય, તો P(n, r) વાપરો; નહીં તો C(n, r) વાપરો. પુનરાવર્તિત વસ્તુઓ હોય તો ફેક્ટોરિયલ વડે ભાગાકાર કરવાનું ભૂલશો નહીં.
