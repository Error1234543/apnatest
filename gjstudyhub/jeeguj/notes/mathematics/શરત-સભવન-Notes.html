શરતી સંભાવના

📖 શરતી સંભાવના

પરિભાષા અને મૂળભૂત સંકલ્પના

શરતી સંભાવના એટલે એક ઘટનાની સંભાવના જે બીજી ઘટના ઘટી ચૂકી હોવાની શરત હેઠળ ગણવામાં આવે. તેને P(A|B) વડે દર્શાવવામાં આવે છે, જ્યાં A અને B બે ઘટનાઓ છે. શરતી સંભાવનાનો ઉપયોગ નિર્ણાયક ઘટનાઓ વચ્ચેના સંબંધને સમજવા માટે થાય છે.

  • શરતી સંભાવના P(A|B) = P(A ∩ B) / P(B)
  • P(B) > 0 હોવું જરૂરી છે
  • A અને B સ્વતંત્ર હોવાનું ઉદાહરણ: P(A|B) = P(A)
  • શરતી સંભાવના સંમેળનના નિયમ પર આધારિત છે

શરતી સંભાવનાનો સૂત્ર

શરતી સંભાવના ગણતરી માટેનો મૂળભૂત સૂત્ર છે P(A|B) = P(A ∩ B) / P(B). આ સૂત્રનો ઉપયોગ કરવા માટે ઘટના Bની સંભાવના શૂન્ય ન હોવી જોઈએ. જો ઘટનાઓ સ્વતંત્ર હોય, તો P(A|B) = P(A).

  • P(A|B) = P(A ∩ B) / P(B)
  • P(B|A) = P(A ∩ B) / P(A)
  • સ્વતંત્ર ઘટનાઓ માટે P(A|B) = P(A)
  • સૂત્રનો ઉપયોગ નિર્ભરતા ચકાસવા માટે થાય છે
🧠 Trick: બે ઘટનાઓના છેદમાં ભાગીને શરતી સંભાવના મેળવો

બેઝનો થિયરમ (Bayes' Theorem)

બેઝનો થિયરમ શરતી સંભાવનાનું વિસ્તૃત સ્વરૂપ છે, જે પૂર્વ સંભાવના (Prior Probability) અને પોસ્ટરિયર સંભાવના (Posterior Probability) વચ્ચેનો સંબંધ દર્શાવે છે. તેનો ઉપયોગ મેડિકલ ટેસ્ટિંગ, મશીન લર્નિંગ અને અન્ય ક્ષેત્રોમાં થાય છે.

  • P(A|B) = [P(B|A) * P(A)] / P(B)
  • P(B) = P(B|A)P(A) + P(B|¬A)P(¬A) (સંપૂર્ણ સંભાવનાનો નિયમ)
  • બેઝનો થિયરમ પૂર્વ અને પોસ્ટરિયર સંભાવના વચ્ચે પુલ બનાવે છે
  • મેડિકલ ડાયગ્નોસિસમાં ઉપયોગી
🧠 Trick: પૂર્વ પોસ્ટરિયર માટે બેઝનો થિયરમ

સ્વતંત્ર અને અસ્વતંત્ર ઘટનાઓ

સ્વતંત્ર ઘટનાઓ એવી ઘટનાઓ છે જ્યાં એક ઘટનાનું પરિણામ બીજી ઘટના પર અસર કરતું નથી. અસ્વતંત્ર ઘટનાઓમાં એક ઘટનાનું પરિણામ બીજી ઘટના પર અસર કરે છે. શરતી સંભાવના અસ્વતંત્ર ઘટનાઓ માટે મહત્વની છે.

  • સ્વતંત્ર ઘટનાઓ: P(A ∩ B) = P(A) * P(B)
  • અસ્વતંત્ર ઘટનાઓ: P(A ∩ B) ≠ P(A) * P(B)
  • શરતી સંભાવના અસ્વતંત્ર ઘટનાઓ માટે અલગ હોય છે
  • સ્વતંત્રતા ચકાસવા P(A|B) = P(A) તપાસો
🧠 Trick: સ્વતંત્ર = સરખું, અસ્વતંત્ર = અલગ

શરતી સંભાવનાનાં ઉદાહરણો

શરતી સંભાવનાનાં ઉદાહરણો જીવવિજ્ઞાન અને ભૌતિકવિજ્ઞાનમાં જોવા મળે છે. ઉદાહરણ તરીકે, જો એક વ્યક્તિને કોઈ રોગ હોય તો તેના લક્ષણો દેખાડવાની સંભાવના શરતી સંભાવના છે.

  • જીવવિજ્ઞાન: રોગની હાજરીમાં લક્ષણોની સંભાવના
  • ભૌતિકવિજ્ઞાન: કણની હાજરીમાં કોઈ ઘટનાની સંભાવના
  • ગણિત: પાસાની ફેંકણીમાં ચોક્કસ નંબર આવવાની સંભાવના
  • ઉદાહરણો શરતી સંભાવનાનો વ્યવહારિક ઉપયોગ દર્શાવે છે

શરતી સંભાવના અને સંમેળનના નિયમ

શરતી સંભાવના સંમેળનના નિયમ સાથે નિકટતાથી જોડાયેલી છે. સંમેળનના નિયમ મુજબ, બે ઘટનાઓનો સંમેળ P(A ∪ B) = P(A) + P(B) - P(A ∩ B) હોય છે. શરતી સંભાવનાનો ઉપયોગ સંમેળનના નિયમને વિસ્તૃત કરવા માટે થાય છે.

  • P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
  • શરતી સંભાવના સંમેળનના નિયમને વ્યાખ્યાયિત કરે છે
  • સંમેળન અને છેદ વચ્ચેનો સંબંધ શરતી સંભાવનામાં મહત્વનો છે
  • સંમેળનનો નિયમ શરતી સંભાવનાનો આધાર છે

શરતી સંભાવનાનાં અનુપ્રયોગો

શરતી સંભાવનાનો ઉપયોગ મશીન લર્નિંગ, આંકડાશાસ્ત્ર, મેડિકલ ડાયગ્નોસિસ અને જીનેટિક્સમાં થાય છે. ઉદાહરણ તરીકે, જીનેટિક્સમાં, વંશાનુક્રમિક રોગોની સંભાવના ગણવા માટે શરતી સંભાવનાનો ઉપયોગ થાય છે.

  • મશીન લર્નિંગ: ક્લાસિફિકેશન અને પ્રિડિક્શન
  • મેડિકલ ડાયગ્નોસિસ: રોગની સંભાવના ગણતરી
  • જીનેટિક્સ: વંશાનુક્રમિક રોગોની સંભાવના
  • આંકડાશાસ્ત્ર: ડેટા એનાલિસિસ અને પૂર્વાનુમાન

🎯 Exam Tip: શરતી સંભાવના અને બેઝનો થિયરમના સૂત્રો યાદ રાખો, અને ઉદાહરણો દ્વારા તેનો ઉપયોગ કેવી રીતે થાય છે તે સમજો. પરીક્ષામાં સૂત્રો લખવાની સાથે સાથે તેનો વ્યવહારિક ઉપયોગ પણ દર્શાવો.
