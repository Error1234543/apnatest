બહુલક

📖 બહુલક (Polymers)

બહુલકની વ્યાખ્યા અને વર્ગીકરણ

બહુલક એટલે અણુઓની લાંબી શૃંખલા ધરાવતા ઉચ્ચ અણુભારવાળા કાર્બનિક સંયોજનો. NCERT અનુસાર, તેને કુદરતી (પ્રોટીન, સેલ્યુલોઝ) અને કૃત્રિમ (પોલિથિન, નાયલોન)માં વર્ગીકૃત કરવામાં આવે છે. આધારભૂત એકમોને મોનોમર કહે છે, જ્યારે બહુલકને પોલિમર કહે છે.

  • બહુલક = મોનોમરની પુનરાવર્તિત શૃંખલા
  • કુદરતી: સેલ્યુલોઝ, સ્ટાર્ચ, પ્રોટીન
  • કૃત્રિમ: પોલિઇથિલીન, PVC, નાયલોન-6,6
  • હોમોપોલિમર (એક જ મોનોમર) vs કોપોલિમર (બહુ મોનોમર)
  • લીનિયર, શાખાયુક્ત, જાળીય રચના
🧠 Trick: કુદરતી કૃત્રિમ કહો, સેલ્યુલોઝ પોલિથિન જાણો

બહુલકીકરણની પદ્ધતિઓ

બહુલકીકરણ બે મુખ્ય રીતે થાય: ૧) સંયોજન બહુલકીકરણ (Addition Polymerisation) - અલ્કીન/ડાયનમાં ડબલ/ટ્રિપલ બોન્ડ તૂટી શૃંખલા બને (ઉદા. ઇથિલીન → પોલિઇથિલીન). ૨) સંકલન બહુલકીકરણ (Condensation Polymerisation) - બે વિવિધ મોનોમર વચ્ચે પાણી/હાઇડ્રોજન ક્લોરાઇડ જેવા નાના અણુ નીકળે (ઉદા. હેક્ઝામિથિલીન ડાયએમીન + એડિપિક એસિડ → નાયલોન-6,6).

  • સંયોજન: ડબલ/ટ્રિપલ બોન્ડ વાળા મોનોમર
  • સંકલન: વિવિધ મોનોમર + નાના અણુ નીકળે
  • ઉદા. સંયોજન: પોલિઇથિલીન, પોલિપ્રોપિલીન
  • ઉદા. સંકલન: નાયલોન-6,6, ટેરિલીન (ડેક્રોન)
  • કોપોલિમર: બ્યુના-S (સ્ટાયરિન + બ્યુટાડાયન)
🧠 Trick: સંયોજન = સરળ શૃંખલા, સંકલન = સાંકળો કાપી નીકળે

મહત્વપૂર્ણ કૃત્રિમ બહુલક અને તેમના ઉપયોગ

પોલિઇથિલીન (LDPE/HDPE): પ્લાસ્ટિક બેગ, બોટલ. PVC: પાઇપ, ઇલેક્ટ્રિક ઇન્સ્યુલેશન. ટેફ્લોન (PTFE): નોન-સ્ટિક કુકવેર. નાયલોન-6,6: કપડા, રસ્સા. પોલીસ્ટર (ટેરિલીન): કપડા, બોટલ. બકેલાઇટ: ઇલેક્ટ્રિક સ્વિચ, હેન્ડલ.

  • LDPE: નરમ, લવચીક (બેગ)
  • HDPE: કઠોર (બોટલ, ટોય)
  • PVC: ક્લોરિન યુક્ત, ટકાઉ
  • ટેફ્લોન: ઉચ્ચ તાપમાન સહનશીલ
  • બકેલાઇટ: પ્રથમ કૃત્રિમ બહુલક (1907)
🧠 Trick: પોલી-ઇથી-લીન બેગ, નાયલોન કપડા, ટેફ્લોન કડાઈ

બાયોડિગ્રેડેબલ બહુલક

પર્યાવરણ અનુકૂળ બહુલક જે સૂક્ષ્મજીવો દ્વારા વિઘટિત થાય. ઉદા. PHBV (પોલી-β-હાઇડ્રોક્સીબ્યુટાઇરેટ-કો-વેલેરેટ), નાયલોન-2-નાયલોન-6. આ બહુલકો કૃત્રિમ બહુલકના પર્યાય રૂપે વિકસાવવામાં આવે છે.

  • PHBV: બેક્ટેરિયા દ્વારા ઉત્પાદિત
  • નાયલોન-2-નાયલોન-6: ગ્લાઇસિન + કેપ્રોલેક્ટમ
  • વિઘટન માટે સૂક્ષ્મજીવોની જરૂર
  • ઉપયોગ: મેડિકલ ઇમ્પ્લાન્ટ, પેકેજિંગ
  • પર્યાવરણ મિત્ર

બહુલકની ભૌતિક ગુણધર્મો

બહુલકની ગુણધર્મો તેમની શૃંખલા લંબાઈ, શાખા, આંતરઅણુ બળો અને સ્ફટિકીયતા પર આધાર રાખે. ઉચ્ચ અણુભાર → ઉચ્ચ ગલનબિંદુ, ટણકાઈ. લીનિયર શૃંખલા → ઉચ્ચ ઘનતા (HDPE). જાળીય રચના → અદ્રાવ્ય, કઠોર (બકેલાઇટ).

  • લીનિયર > શાખાયુક્ત (ટણકાઈ)
  • સ્ફટિકીય > અસ્ફટિક (ગલનબિંદુ)
  • આંતરઅણુ બળ: H-બોન્ડ > વાન ડર વાલ્સ
  • પોલાર ગ્રુપ → પાણીમાં દ્રાવ્યતા વધે
  • પ્લાસ્ટિસાઇઝર: લવચીકતા વધારે
🧠 Trick: લીનિયર લાંબું, શાખા નરમ

બહુલક અને પર્યાવરણ

કૃત્રિમ બહુલકોનો નિકાલ પર્યાવરણ માટે મોટો પડકાર છે. તે બિન-બાયોડિગ્રેડેબલ હોવાથી મૃત્યુપ્રાય થાય છે. રીસાયક્લિંગ, બાયોડિગ્રેડેબલ બહુલકનો ઉપયોગ અને પ્લાસ્ટિકના વપરાશમાં ઘટાડો એ મુખ્ય ઉકેલો છે.

  • પ્લાસ્ટિક પ્રદૂષણ: મહાસાગર, જમીન
  • રીસાયક્લિંગ: PET, HDPE
  • બાયોડિગ્રેડેબલ: PHBV, PLA
  • માઇક્રોપ્લાસ્ટિક: સૂક્ષ્મ કણોનો ખતરો
  • 3R: Reduce, Reuse, Recycle
🧠 Trick: પ્લાસ્ટિક કચરો, રીસાયકલ કરો

JEE Main માટે મહત્વપૂર્ણ સૂત્રો અને સંજ્ઞાઓ

બહુલકીકરણની ડિગ્રી (n) = (M_p / M_m), જ્યાં M_p = પોલિમરનો અણુભાર, M_m = મોનોમરનો અણુભાર. કોપોલિમરમાં મોનોમર ગુણોત્તર મહત્વપૂર્ણ. ઉદા. નાયલોન-6,6માં હેક્ઝામિથિલીન ડાયએમીન અને એડિપિક એસિડ 1:1 ગુણોત્તરમાં હોય છે.

  • ડિગ્રી ઓફ પોલિમરાઇઝેશન (n) = M_p / M_m
  • કોપોલિમરમાં મોનોમર ગુણોત્તર જાણવું
  • નાયલોન-6,6: 1:1 (ડાયએમીન:ડાયકર્બોક્સિલિક એસિડ)
  • બકેલાઇટ: ફિનોલ + ફોર્મલડિહાઇડ (1:1)
  • પોલિઇથિલીન: n(CH2=CH2) → (-CH2-CH2-)n
🧠 Trick: n = પોલિમર / મોનોમર

⚡ Quick Revision

  • બહુલક = મોનોમરની લાંબી શૃંખલા
  • સંયોજન vs સંકલન બહુલકીકરણ
  • LDPE/HDPE: નરમ/કઠોર પ્લાસ્ટિક
  • નાયલોન-6,6: કોપોલિમર (1:1 ગુણોત્તર)
  • ટેફ્લોન: PTFE, ઉચ્ચ તાપમાન સહનશીલ
  • બાયોડિગ્રેડેબલ: PHBV, PLA
  • ડિગ્રી ઓફ પોલિમરાઇઝેશન = M_p / M_m
  • પર્યાવરણ માટે 3R: Reduce, Reuse, Recycle
  • બકેલાઇટ: પ્રથમ કૃત્રિમ બહુલક
  • પોલીસ્ટર: ટેરિલીન (ડેક્રોન)
🎯 Exam Tip: બહુલકીકરણની પદ્ધતિ અને મોનોમરને યાદ રાખવા માટે ઉદાહરણો સાથે કોષ્ટક બનાવો. JEE Mainમાં બહુલકના નામ, મોનોમર અને ઉપયોગ પર પ્રશ્ન પૂછાય છે.
