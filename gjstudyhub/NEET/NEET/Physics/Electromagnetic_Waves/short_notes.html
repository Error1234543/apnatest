વિદ્યુતચુંબકીય તરંગો (Electromagnetic Waves)

🩺 NEET UG — Gujarati • Physics • Electromagnetic Waves

📘 વ્યાખ્યાઓ

  • વિદ્યુતચુંબકીય તરંગ: ઋજુગતિમાં સ્થાનાંતરિત થતા પ્રવેગિત વીજભાર દ્વારા ઉત્પન્ન થતું, જેમાં વિદ્યુત અને ચુંબકીય ક્ષેત્ર એકબીજાને લંબરૂપે આવર્તન કરે છે.
  • સ્થાનાંતરણ પ્રવાહ (Displacement Current): બદલાતી વિદ્યુતચુંબકીય અવસ્થાને કારણે મળતો કલ્પિત પ્રવાહ; આયરનના નિયમને સુધારવા માટે મેક્સવેલે પરિચય આપેલ.
  • વીજચુંબકીય શક્તિ પ્રવાહઘનતા: વિદ્યુત ક્ષેત્રના ફેરફારની દર સાથેના ગુણાકાર પરથી મળતી રાશિ, જેનો એકમ પ્રવાહ/ક્ષેત્રફળ જેટલો જ હોય છે.
  • પ્રકાશની ઝડપ: શૂન્યાવકાશમાં વિદ્યુતચુંબકીય તરંગની ગતિ; આ ε₀ અને μ₀ પર આધારિત છે.

⚡ સૂત્રો

  • સ્થાનાંતરણ પ્રવાહ I_d = ε₀ × dΦ_E/dt (જ્યાં Φ_E = વિદ્યુત ફ્લક્સ)
  • મેક્સવેલ-આયરનનો નિયમ: ∮ B·dl = μ₀(I_c + I_d) = μ₀I_c + μ₀ε₀(dΦ_E/dt)
  • પ્રકાશની ઝડપ c = 1/√(μ₀ε₀) ≈ 3 × 10⁸ m/s
  • E₀ = cB₀ અથવા E = cB (કણિકાઓનો સંબંધ)
  • તરંગદૈર્ઘ્ય અને આવર્તનનો સંબંધ: c = νλ
  • સરેરાશ ઉર્જા ઘનતા u = ½ε₀E₀² (અથવા u_E = u_B, કુલ u = ε₀E₀²)

⭐ મુખ્ય તથ્યો

  • વિદ્યુત અને ચુંબકીય ક્ષેત્રો એકબીજાને લંબરૂપ હોય છે અને પ્રસરણ દિશાને પણ લંબરૂપ હોય છે — તરંગ અનુપ્રસ્થ (Transverse) પ્રકારનું છે.
  • શૂન્યાવકાશમાં તમામ વિદ્યુતચુંબકીય તરંગો સમાન ઝડપ c from પ્રવાહિત થાય છે.
  • મેક્સવેલે 1865માં ભૌતિકશાસ્ત્રમાં વિદ્યુતચુંબકીય તરંગોના અસ્તિત્વનો સૈદ્ધાંતિક અનુમાન કર્યું હતું.
  • હેન્રીખ હર્ટ્ઝ પ્રયોગાત્મક રીતે વિદ્યુતચુંબકીય તરંગોની સೃષ્ટિનું પરામર્શ આપનાર પ્રથમ વ્યક્તિ હતા.
  • રેડિયો તરંગોનું ઉત્પાદન એન્ટેનામાં વિચલન પામતા ઇલેક્ટ્રોન દ્વારા થાય છે.
  • ઇન્ફ્રારેડ તરંગો ઉષ્માજનક પ્રભાવ ધરાવે છે; આ તરંગોને 'ઉષ્મા તરંગો' પણ કહે છે.
  • દ્રષ્ટિ પ્રકાશ (Visible Light) નું તરંગદૈર્ઘ્ય 400 nm થી 700 nmની વચ્ચે હોય છે.
  • અલ્ટ્રાવાયોલેટ કિરણો પારજાંબલી પ્રકાશ છે; જૈવિક ઉત્સેચકોને કારણે વિટામિન D નું સંશ્લેષણ થાય છે.
  • X-રેનું તરંગદૈર્ઘ્ય અત્યંત નાનું (~0.01–10 nm) હોય છે; ક્ષય રોગ (TB) અને કैंसर નિદાનમાં ઉપયોગી.
  • ગામા કિરણોનું તરંગદૈર્ઘ્ય 10⁻³ nm થી ઓછું હોય; કિરણચિકિત્સા અને પરમાણુ પ્રક્રિયાઓમાં મહત્વપૂર્ણ.
  • ઓઝોન સ્તર UV કિરણોમાંથી ખાસ કરીને UV-B અને UV-C શોષી લે છે.
  • ગ્લોબલ વોર્મિંગ (ભૂગોળીય ઊષ્મા વધારો) માં ઇન્ફ્રારેડ તરંગોનું મહત્વપૂર્ણ ફરજિયાત છે.

⚠️ સામાન્ય ભૂલો

  • બતાવવું કે વિદ્યુતચુંબકીય તરંગો અનુદৈર્ઘ્ય (Longitudinal) નથી — તે અનુપ્રસ્થ (Transverse) છે.
  • સ્થાનાંતરણ પ્રવાહ માત્ર ધારાવાહિક પ્રવાહ નથી; તે વિદ્યુત ફ્લક્સના ફેરફારથી ઉત્પન્ન થાય છે.
  • ε₀ અને μ₀ ના મૂલ્યો શૂન્યાવકાશ માટે જ લાગુ પડે છે; માધ્યમમાં અલગ મૂલ્યો હોય છે.
  • u_E = u_B હોય છે — ઉર્જા બંને ક્ષેત્રોમાં સમાન રીતે વિતરિત થાય છે.
  • E અને B એકસાથે શૂન્ય નથી થતા; તેઓ એકબીજાથી 90° ફેઝમાં હોય છે.
  • પ્રકાશની ઝડપ c = νλ માં λ તરંગદૈર્ઘ્ય m માં લેવું જરૂરી છે.
  • તમામ EM તરંગો શૂન્યાવકાશમાં સમાન ઝડપે ગતિ કરે છે — આવર્તન અથવા તરંગદૈર્ઘ્યથી ઝડપ બદલાતી નથી.
  • માધ્યમમાં પ્રવેશતાં તરંગની આવર્તન સ્థિર રહે છે, પણ ઝડપ અને તરંગદૈર્ઘ્ય બદલાય છે.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • c = 1/√(μ₀ε₀) સૂત્રથી પ્રકાશની ઝડપ શૂન્યાવકાશના ઈલેક્ટ્રિક સ્થિરાંક અને ચુંબકીય સુસંવાદિતા પર આધારિત છે તે યાદ રાખો.
  • E₀/B₀ = c સંબંધ NEET માં ઘણી વાર પૂછાય છે.
  • સ્થાનાંતરણ પ્રવાહનું મહત્વ: સમાનંત પેલેટ કેપેસિટરની વચ્ચે પણ ચુંબકીય ક્ષેત્ર ઉત્પન્ન થાય છે.
  • EM વર્ણપટનો ક્રમ (નાના તરંગદૈર્ઘ્યથી મોટા તરંગદૈર્ઘ્ય સુધી): γ < X < UV < દૃશ્ય < IR < મائیک્રો < રેડિયો.
  • ઇન્ફ્રારેડ તરંગો પાણીના અણુઓ સાથે પ્રત્યાવર્તન કરી ઉષ્મા ઉત્પન્ન કરે છે.
  • O₃ (ઓઝોન) + UV → O₂ + O; આ પ્રક્રિયા UV નું શોષણ કરે છે.
  • કોઈપણ EM તરંગ માટે E તથા B એકબીજાને લંબરૂપ હોય છે અને પ્રસરણ દિશાને પણ લંબરૂપ હોય છે — E × B ની દિશા પ્રસરણ દિશા હોય છે.
  • એન્ટેનાની લંબાઈ λ/4 હોવી જોઈએ અથવા λ/2 જેટલી હોવી જોઈએ તેથી અદ્યતન કાર્યક્ષમતા મળે છે.
