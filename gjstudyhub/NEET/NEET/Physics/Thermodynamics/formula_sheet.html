ઉષ્माગતિશાસ્ત્ર (Thermodynamics) — સૂત્ર કૌશલ્ય પત્રિકા

🩺 NEET UG — Gujarati • Physics • Thermodynamics

⚡ સૂત્રો

ઉષ્માગતિશાસ્ત્રનું પ્રથમ નિયમ (First Law of Thermodynamics): Q = ΔU + W
Q = તણમાં આપવામાં આવેલી ઉષ્મા, ΔU = આંતરિક ઊર્જામાં ફેરફાર, W = તણ દ્વારા થયેલું કાર્ય · SI: Joule (J) · બંધ પદ્ધતિ (closed system) માટે સુસંગત
આંતરિક ઊર્જા ફેરફાર (Change in Internal Energy): ΔU = Q − W
ΔU = આંતરિક ઊર્જામાં ફેરફાર, Q = સિસ્ટમ દ્વારા શોષાયેલી ઉષ્મા, W = સિસ્ટમ દ્વારા થયેલું બાહ્ય કાર્ય · SI: Joule (J) · કોઈપણ ઉષ્માગતિશાસ્ત્ર પ્રક્રિયા માટે
સમદાબ તાપમાન પ્રક્રિયા (Isothermal Process) – વાયુ દ્વારા થતું કાર્ય: W = nRT ln(V₂/V₁) અથવા W = 2.303 nRT log₁₀(V₂/V₁)
n = મોલની સંખ્યા, R = સામાન્ય વાયુ અચળાંક, T = નિરપેક્ષ તાપમાન (K), V₁ અને V₂ = પ્રારંભિક અને અંતિમ કદ · SI: Joule (J) · આદર્શ વાયુ, T = અચળ
સમદાબ તાપમાન પ્રક્રિયા – દબાણ-કદ સંબંધ: PV = અચળ
P = દબાણ, V = કદ · SI: Pa·m³ અથવા J · આદર્શ વાયુ, T = અચળ
સમકઠિન પ્રક્રિયા (Isochoric Process) – કાર્ય: W = 0
W = થયેલું કાર્ય · SI: Joule (J) · કદ અચળ (ΔV = 0)
સમકઠિન પ્રક્રિયા – ઉષ્મા અને આંતરિક ઊર્જા: Q = ΔU = nC_VΔT
n = મોલ સંખ્યા, C_V = સમકઠિન વોલ્યુમ રૂઢ ઉષ્માધારિતા, ΔT = તાપમાનમાં ફેરફાર · SI: Joule (J) · વોલ્યુમ અચળ
સમદબાણ પ્રક્રિયા (Isobaric Process) – કાર્ય: W = PΔV
P = અચળ દબાણ, ΔV = કદમાં ફેરફાર · SI: Joule (J) · દબાણ અચળ
સમદબાણ પ્રક્રિયા – ઉષ્મા અને આંતરિક ઊર્જા: Q = nC_PΔT, ΔU = nC_VΔT
C_P = સમદબાણ રૂઢ ઉષ્માધારિતા, C_V = સમકઠિન રૂઢ ઉષ્માધારિતા · SI: Joule (J) · દબાણ અચળ
મેયરનું સૂત્ર (Mayer's Relation): C_P − C_V = R
C_P = સમદબાણ મોલર ઉષ્માધારિતા, C_V = સમકઠિન મોલર ઉષ્માધારિતા, R = વાયુ અચળાંક · SI: J mol⁻¹ K⁻¹ · આદર્શ વાયુ માટે
ઉષ્માધારિત ગુણોત્તર (Adiabatic Index / Heat Capacity Ratio): γ = C_P / C_V
γ = ઉષ્માધારિત ગુણોત્તર, C_P અને C_V = મોલર ઉષ્માધારિતાઓ · SI: અત્યાંશીય (dimensionless) · આદર્શ વાયુ
ઓસ્તિલિયાદી પ્રક્રિયા (Adiabatic Process) – પુનઃસ્થાપક સંબંધો: PV^γ = અચળ, T V^(γ−1) = અચળ, P^(1−γ) T^γ = અચળ
P = દબાણ, V = કદ, T = તાપમાન, γ = ઉષ્માધારિત ગુણોત્તર · SI: વિવિધ (SI એકમોનો યોગ્ય સંયોગ) · ઉસ્તિલાદી પ્રક્રિયા: ઉષ્માનિર્મળ (Q = 0), ધીમી ગતિથી, પુનઃસ્થાપક
ઓસ્તિલિયાદી પ્રક્રિયા – થતું કાર્ય: W = (P₁V₁ − P₂V₂) / (γ − 1)
P₁, V₁ = પ્રારંભિક દબાણ અને કદ, P₂, V₂ = અંતિમ દબાણ અને કદ · SI: Joule (J) · ઓસ્તિલાદી પ્રક્રિયા, આદર્શ વાયુ
એન્ડ્રેટ ચક્રનો ઉષ્માગતિશાસ્ત્રીય કાર્યક્ષમતા (Efficiency of Heat Engine): η = W / Q₁ = 1 − (Q₂ / Q₁)
η = કાર્યક્ષમતા, W = થયેલું કાર્ય, Q₁ = ઉચ્ચ તાપમાન સ्रोતમાંથી લેવામાં આવતી ઉષ્મા, Q₂ = નીચા તાપમાન સિંકમાં મુક્ત થતી ઉષ્મા · SI: અત્યાંશીય (દશાંશ અથવા %) · કોઈપણ ઉષ્મા ઇંજિન
કાર્નોટ ચક્રની કાર્યક્ષમતા: η = 1 − (T₂ / T₁) = (T₁ − T₂) / T₁
T₁ = ઉચ્ચ તાપમાન સ्रोતનું નિરપેક્ષ તાપમાન (K), T₂ = નીચા તાપમાન સિંકનું નિરપેક્ષ તાપમાન (K) · SI: અત્યાંશીય · કાર્નોટ ઇંજિન, પુનઃસ્થાપક ચક્ર
ઉષ્મા પંપ / રેફ્રિજરેટરની પ્રભાવક સંખ્યા (Coefficient of Performance): COP = Q₂ / W = Q₂ / (Q₁ − Q₂)
COP = પ્રભાવક સંખ્યા, Q₂ = સિંકમાંથી લેવામાં આવતી ઉષ્મા, W = થયેલું કાર્ય, Q₁ = સ्रोતમાં મુક્ત થતી ઉષ્મા · SI: અત્યાંશીય · ઉષ્મા પંપ અથવા રેફ્રિજરેટર
કાર્નોટ રેફ્રિજરેટરની COP: COP = T₂ / (T₁ − T₂)
T₁ = ઉચ્ચ તાપમાન (K), T₂ = નીચું તાપમાન (K) · SI: અત્યાંશીય · કાર્નોટ ચક્ર પર કાર્યરત રેફ્રિજરેટર
ઉષ્માગતિશાસ્ત્રનું દ્વિતીય નિયમ (કિલ્વિન્-પ્લાંકક કથન): ઉષ્માને સંપૂર્ણપણે કાર્યમાં પરિવર્તિત કરતું એકલા પ્રમાણિક ચક્ર શક્ય નથી.
સંકેતલક્ષી · SI: અવકાશિત · ઉષ્મા ઇંજિનના સિદ્ધાંત
ઉષ્માગતિશાસ્ત્રનું તૃતીય નિયમ: T = 0 K સુધી શૂન્ય એન્ટ્રોપી પ્રાપ્ત કરવી અશક્ય છે.
T = નિરપેક્ષ તાપમાન · SI: Kelvin (K) · પરિપૂર્ણ સ્ફટિક માટે

🔗 સંબંધો

  • કાર્યક્ષમતા η = 1 − (T₂/T₁) દર્શાવે છે કે સიંકનું તાપમાન ઘટાડવાથી અથવા સ्रोતનું તાપમાન વધારવાથી ઇંજિનની કાર્યક્ષમતા વધે છે.
  • ઓસ્તિલાદી પ્રક્રિયામાં Q = 0 હોવાથી ΔU = −W; ગેસના વિસ્તરણથી તેના તાપમાનમાં ઘટાડો થાય છે.
  • C_P − C_V = R એ આદર્શ વાયુ માટેનો મૂળભૂત સંબંધ છે, જે C_P > C_V સૂચવે છે.
  • આદર્શ વાયુ માટે C_V = fR/2 અને C_P = (f+2)R/2, જ્યાં f = સ્વતંત્રતાની માત્રા (degrees of freedom).
  • કાર્નોટ ચક્રની કાર્યક્ષમતા માત્ર સ्रोત અને સિંકના તાપમાન પર આધારિત છે, ચક્રના આકાર પર નહીં.
  • બર્નૉલીના સમીકરણના ઉષ્માગતિશાસ્ત્ર સ્વરૂપ વાયુઓની ઝડપ અને દબાણ વચ્ચેનો સંબંધ સ્થાપિત કરે છે.

🎯 ટ્રિક્સ

સમદાબ તાપમાન પ્રક્રિયામાં T અચળ હોવાથી ΔU = 0; તેથી Q = W. એટલે કે શોષાયેલી ઉષ્માનું સંપૂર્ણ રૂપાંતર કાર્યમાં થાય છે.
સમકઠિન પ્રક્રિયામાં કાર્ય શૂન્ય (W = 0) હોવાથી Q = ΔU — ઉષ્મા સીધી આંતરિક ઊર્જા વધારે છે.
ઓસ્તિલાદી પ્રક્રિયામાં PV^γ = અચળ હોવાથી P-V આલેખનો ઢાલ સમદાબ પ્રક્રિયા કરતાં વધારે હોય છે.
એન્ડ્રેટ ચક્રમાં કાર્યક્ષમતા η = (T₁ − T₂)/T₁ = 1 − T₂/T₁ સ્વરૂપમાં યાદ રાખવાથી ઉલટું ભાગવીને શક્ય નથી.
COP = T₂/(T₁ − T₂) એ રેફ્રિજરેટરની કાર્યક્ષમતા સાથે સીધો સંબંધ ધરાવે છે; COP > 1 હોઈ શકે છે.
ગેસનું મોલર દળ M અને વિશિષ્ટ ઉષ્માધારિતા c_p, c_v વચ્ચેનો સંબંધ: c_p − c_v = R/M (પરમાણ્વીય દળ એકમોમાં).

⚠️ ભૂલો

Q = ΔU + W અને ΔU = Q − W વચ્ચેના ચિહ્ન વિષયક ભ્રમ: વાયુએ બાહ્ય કાર્ય કર્યું હોય તો W ધન ગણાય છે; કેટલાંક પુસ્તકો W ને સિસ્ટમ પર થયેલા કાર્ય તરીકે પણ લે છે, તેથી સંજ્ઞા વિષયક સ્પષ્ટતા જરૂરી છે.
સમદાબ તાપમાન પ્રક્રિયામાં η = 100% સિદ્ધ કરવાની ભૂલ: η = 1 − T₂/T₁ અનુસાર T₂ ≠ 0 K ત્યાં સુધી કાર્યક્ષમતા 1 થઈ શકે નહીં.
ઓસ્તિલાદી પ્રક્રિયામાં PV = અચળ લાગુ પાડવાની ભૂલ: ઓસ્તિલાદી માટે PV^γ = અચળ સાચું છે, PV = અચળ નહીં.
C_P અને C_V નો ઉપયોગ સમદબાણ અને સમકઠિન પ્રક્રિયાઓમાં સ્થાન ભેળવવાની ભૂલ.
T₂/T₁ ની ગણતરીમાં તાપમાન કેલ્વિનમાં રૂપાંતરિત કર્યા વિના સીધું ડિગ્રી સેલ્સિયસ લાગુ પાડવાની ભૂલ.
ઉષ્મા પંપની COP ની ગણતરીમાં Q₁ અને Q₂ ને અદલાબદલી કરવાની ભૂલ: COP = Q₂/W, Q₁ નહીં.
γ = C_P/C_V ને બદલે C_V/C_P લખવાની ભૂલ. સાચું મૂલ્ય γ > 1 હોય છે.
આદર્શ વાયુનો C_P − C_V = R સંબંધ વાસ્તવિક વાયુઓ પર લાગુ પાડવાની ભૂલ.
એન્ડ્રેટ ચક્રમાં ચાર પ્રક્રિયાઓ (બે સમદાબ, બે ઓસ્તિલાદી) હોવા છતાં મધ્યવર્તી પ્રક્રિયાઓનું વિસ્મરણ કરી કાર્યક્ષમતાની ગણતરી કરવાની ભૂલ.
