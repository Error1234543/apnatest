🎯 પરીક્ષા ટ્રિક્સ

આધાર-પરિણામ યાદ રાખવા માટેનું 'બાયો-સેવર્ટ' મનોચિત્ર: જ્યારે પ્રવાહ વહેતો ત્યારે કાંટાળું હાથ ધરાવો — બોલડ અંગૂઠો = પ્રવાહ દિશા, વળેલા આંગળીઓ = ચુંબકીય ક્ષેત્ર રેખા. આ ક્રોસ પ્રડક્ટ (B ∝ I×dl×sinθ) ને ઓળખવામાં મદદ કરે છે.
જ્યારે Biot-Savart Law ની દિશા / સૂત્રની યાદ અસ્પષ્ટ હોય કે પછી ભ્રમણાભરી કૉન્ફ્યુઝન થતી હોય.
દા.ત.: સીધા તારમાં ઉપર તરફ પ્રવાહ હોય તો ચુંબકીય ક્ષેત્ર કલાકદિશામાં (clockwise) નહીં, પણ ગડિયાળ દિશામાં (anticlockwise) હોય છે તે તરત ઓળખી શકાય.
સેલેનોઇડ અને ટોઇડના B માટેના સૂત્રોમાં n (વ્હોંડ પ્રતિ એકમ લંબાઈ) અને N (કુલ વ્હોંડ) નું સંગઠન યાદ રાખો: સેલેનોઇડ → B = μ₀nI, ટોઇડ → B = μ₀NI/(2πr). 'ન' (n) ના સૂત્રમાં l (લંબાઈ) છે, 'ત્રિજ્યા' (r) ટોઇડમાં છે — આ સાદી યાદદાશથી ગૂંચવણ દૂર થાય.
જ્યારે વિકલ્પોમાં nI / NI / 2πr જેવા સમાન દેખાતા વિકલ્પો હોય અને ઝડપથી સાચો સૂત્ર ઓળગવું હોય.
દા.ત.: પ્રશ્નમાં કહેવાય કે 'ટોઇડની ત્રિજ્યા r છે' — તો સૂત્રમાં 2πr આવશે, n આવી શકે નહીં. જો 'સેલેનોઇડની લંબાઈ l અને કુલ વ્હોંડ N' હોય તો n = N/l મૂકતાં B = μ₀NI/l થાય.
પ્રવાહવાહક તાર પર લાગતું બળ F = BIl sinθ — જ્યારે તાર ચુંબકીય ક્ષેત્રની સમાંતર હોય (θ = 0°), તો F = 0. જ્યારે લંબ હોય (θ = 90°), તો F = BIl (મહત્તમ). આ ખાલી એક શરત યાદ રાખવાથી આધારિત કોઈ પણ પ્રશ્ન ઝડપથી ઉકેલાય છે.
જ્યારે તાર પર લાગતું ચુંબકીય બળ શૂન્ય કે મહત્તમ હોવાની શરત પૂછવામાં આવતી હોય.
દા.ત.: કોઈ તાર ઉત્તર-દક્ષિણ દિશામાં રાખેલો હોય અને ચુંબકીય ક્ષેત્ર પણ એ જ દિશામાં હોય, તો બળ શૂન્ય → વિકલ્પ (અ) સીધો પસંદ.
ક્ષેત્રીય ચુંબકમાં ગતિ કરતી આધારિત કણના માર્ગના વર્તણૂકનો નિયમ: જો v ⟂ B હોય તો વર્તુળ (radius r = mv/qB), જો v ∥ B હોય તો સીધી રેખા, જો v અને B વચ્ચે θ હોય તો સ્પ્રેલિક્સ. આ ત્રણેય પરિણામ એક જ સૂત્ર r = mv/(qB) માંથી આવે છે — એક સૂત્ર યાદ રાખી ત્રણેય કિસ્સા બાહોળી શકાય.
જ્યારે આધારિત કણ (ઇલેક્ટ્રોન, પ્રોટોન, α-કણ) ના માર્ગ વિશે પૂછાય અને ત્રણેય પ્રકારના વિકલ્પો હોય.
દા.ત.: ઇલેક્ટ્રોનને v = 10⁶ m/s થી ખેંચવામાં આવે અને B = 0.1 T ⟂ v હોય, તો r = mv/qB = (9.1×10⁻³¹ × 10⁶)/(1.6×10⁻¹⁹ × 0.1) ≈ 5.7×10⁻⁴ m. તેથી વર્તુળાકાર માર્ગ — વિકલ્પ પસંદ.
બે સમાંતર પ્રવાહવાહક તાર વચ્ચેનો બળ પ્રતિ એકમ લંબાઈ: F/l = μ₀I₁I₂/(2πd). જો પ્રવાહ સમાન દિશામાં → આકર્ષણ, વિરુદ્ધ દિશામાં → વિખેડ. આ એક કલ્પના યાદ રાખો: 'એક જ દિશા = એક જ કુટુંબ (આકર્ષણ), વિરુદ્ધ દિશા = લડાઈ (વિખેડ).'
જ્યારે બે પ્રવાહવાહક તાર વચ્ચેના બળની દિશા અથવા મૂલ્ય શોધવાનું હોય.
દા.ત.: બે તારમાં 5 A પ્રવાહ સમાન દિશામાં વહે છે અને અંતર 0.1 m છે → F/l = (4π×10⁻⁷ × 5 × 5)/(2π × 0.1) = 5×10⁻⁵ N/m (આકર્ષણ).
ગેલેવોમીટરનું CCE (Current Sensitivity) ∝ NBA/R અને વોલ્ટેજ સંવેદનશીલતા ∝ NBA/(R + r). આ બંનેમાં NBA ભાગ સામાન્ય છે. એક જ ગૂંચવણ: CCE માં નાની R હોય તો સંવેદનશીલતા વધે, પરંતુ VSE માં R વધારતાં VSE ઘટે છે. આ વિરોધાભાસ યાદ રાખો!
ગેલેવોમીટરની સંવેદનશીલતા વધારવા/ઘટાડવાવાળા પ્રશ્નોમાં.
દા.ત.: ગેલેવોમીટરની વોલ્ટેજ સંવેદનશીલતા વધારવી હોય તો R ઘટાડવું, CCE વધારવી હોય તો B, N, A વધારવા અથવા R ઘટાડવું — બંનેમાં B, N, A વધારવું હંમેશા ઉપયોગી.
વેલેન્સ ગેલેવોમીટર (Moving Coil Galvanometer) માં ટોર્ક τ = NIBA sinθ. ચુંબકીય વિકલ્પ (magnetic moment) m = NA I યાદ રાખો. આથી τ = mB sinθ. આ એક જ સૂત્ર બંને દૃષ્ટિએ કામ કરે છે — ચલન અને ક્રાંતિકોણ બંને માટે.
જ્યારે પ્રશ્નમાં 'ચુંબકીય વિકલ્પ' અને 'ટોર્ક' બંને પૂછવામાં આવ્યા હોય અથવા વિકલ્પોમાં g (ગેલેવોમીટર અચળાંક) નો સંબંધ જોવા મળે.
દા.ત.: જો g = C/NA બતાવવું હોય, તો τ = NIBl² sinθ = NA B (I/g) sinθ → g = C/(NA) સીધું મળે.
ઓલ્ટોમીટર અને એમીટરનું રૂપાંતર: એમીટર બનાવવાને બદલે શંટ R_s = G/(n-1) અને વોલ્ટમીટર બનાવવાને બદલે શ્રેણીમાં R = (n-1)G મૂકો. n = ગુણક (multiplier). આ સૂત્રો સામાન્ય રીતે એકજ યાદ રાખી શકાય: નાના R → એમીટર, મોટા R → વોલ્ટમીટર.
જ્યારે ગેલેવોમીટરથી એમીટર કે વોલ્ટમીટર બનાવવાના પ્રશ્ન આવે.
દા.ત.: ગેલેવોમીટર R = 50 Ω અને I_g = 0.01 A. 5 A એમીટર બનાવવા: R_s = 50/(5/0.01 - 1) = 50/499 ≈ 0.1 Ω. એટલે ખૂબ જ નાનો R શંટ તરીકે.
માર્ગના ક્ષેત્રમાં કણનું આવર્તકાળ T = 2πm/(qB) — આ આવર્તકાળ વેગ (v) પર આધારિત નથી! એટલે જેટલો ઝડપી કણ હોય તેટલું મોટું વર્તુળ પણ એટલું જ સમય લે છે. આ ખાસ તથ્ય યાદ રાખો અને પ્રશ્નમાં તરત લાગુ કરો.
જ્યારે પ્રશ્નમાં કણનું આવર્તકાળ કે કોણીય આવૃત્તિ (cyclotron frequency) પૂછવામાં આવે.
દા.ત.: ઇલેક્ટ્રોન અને પ્રોટોન સમાન B માં સમાન કોણીય વેગથી ફરે છે, પરંતુ પ્રોટોનનું વર્તુળ વધુ મોટું હોય છે (r ∝ m). આવર્તકાળ T = 2πm/qB માં પ્રોટોનનું T > ઇલેક્ટ્રોનનું T.
એમ્પિયરના પરિભ્રમણ સમીકરણ (Ampere's Circuital Law) માટે Amperian loop પસંદ કરવાનો નિયમ: સંમિતિ (symmetry) જોતાં loop એવું પસંદ કરો કે જેથી ∮B·dl માં B અચળ હોય. સીધા તાર માટે વર્તુળ, સેલેનોઇડ માટે આયત, ટોઇડ માટે વર્તુળ — આ ત્રણેય loop યાદ રાખો.
જ્યારે B નું સૂત્ર તારવવાનું હોય અથવા પ્રશ્નમાં Ampere's Law ની લાગૂઆત પૂછવામાં આવે.
દા.ત.: સેલેનોઇડની અંદર B = μ₀nI તારવવા માટે આયતಾકાર loop લો જેનો ek બાજુ તારની અંદર અને બીજી બહાર હોય → B(l) = μ₀(nl)I → B = μ₀nI.
ચુંબકીય ડાયપોલના B નું સૂત્ર: અક્ષ પર B_axial = (μ₀/4π)(2m/r³), લંબદંડ પર B_equatorial = (μ₀/4π)(m/r³). એક જ સૂત્ર યાદ રાખો: axial = 2 × equatorial (સમાન અંતરે). આ સંબંધ ઝડપી ઉત્તર આપવા મદદરૂપ.
જ્યારે ચુંબકીય ડાયપોલના અક્ષ અને ભુજ પરના ક્ષેત્રની તુલના પૂછવામાં આવે.
દા.ત.: જો r = 10 cm પર axial B = 2 × 10⁻⁴ T હોય, તો સમાન અંતરે equatorial B = 1 × 10⁻⁴ T — સીધો ગુણોત્તર 2:1.
પેરોમેટરિક પદાર્થો અને ડાયમેટરિક પદાર્થોમાં ચુંબકીય ક્ષેત્રની રેખાઓનો આચરણ: ડાયમેટરિક → બહાર ફેંકી દે છે (B ઘટે છે), પેરોમેટરિક → અંદર ખેંચે છે (B વધે છે). યાદ રાખો: 'ಡાય = દૂર, પેરો = પાસ' (Diamagnetic = away, Paramagnetic = towards).
જ્યારે પદાર્થની ચુંબકીય પ્રકૃતિ અથવા ચુંબકીય રેખાઓના વર્તણૂક વિશે પૂછવામાં આવે.
દા.ત.: જો કોઈ પદાર્થ ચુંબકીય રેખાઓને પોતાની અંદર ખેંચે અને χ > 0 (સૂક્ષ્મ, ધન) હોય, તો તે પેરોમેટરિક — પાતાળ, એલ્યુમિનિયમ.
પૃથ્વીના ચુંબકીય ક્ષેત્રના ઘટકો: B_H = B cosδ અને B_V = B sinδ. δ = ઢાળ (dip angle). ખાસ કેસ: ધ્રુવ પર δ = 90° (B_V મહત્તમ, B_H = 0), ભૂમધ્ય પર δ = 0° (B_H મહત્તમ, B_V = 0). આ બે ચરમ સ્થિતિઓ યાદ રાખીને બાકીનાં બધાં ગણતરીઓ સરળ બને.
પૃથ્વીના ચુંબકીય ક્ષેત્રના ઘટકો શોધવા કે δ મેળવવાના પ્રશ્નોમાં.
દા.ત.: જો B = 4 × 10⁻⁵ T અને δ = 30° હોય, તો B_H = 4×10⁻⁵ × cos30° = 3.46×10⁻⁵ T, B_V = 4×10⁻⁵ × sin30° = 2×10⁻⁵ T.
ચુંબકીય ક્ષેત્રની એકમ (Tesla) ની યાદદાશ: 1 T = 1 Wb/m² = 1 N/(A·m). વિકલ્પોમાં એકમો હોય તો સીધો તપાસી શકાય: જો વિકલ્પ Wb·m માં હોય તો ગલત, Wb/m² માં હોય તો સાચો. એનું ક્રોસ-ચેક હંમેશા થાય.
જ્યારે ચુંબકીય ક્ષેત્રનું એકમ કે SI એકમો વિશે પ્રશ્ન આવે.
દા.ત.: વિકલ્પ (અ) Wb·m, (બ) Wb/m², (ક) N/A·m, (ડી) બંને (બ) અને (ક) — જવાબ (ડી) કારણ Wb/m² = N/(A·m) બંને સાચા એકમો છે.
સેલેનોઇડની અંદર B = μ₀nI અને બહાર B ≈ 0 — આ ખાસ તથ્ય યાદ રાખો. પ્રશ્નમાં સેલેનોઇડની બહારનું ક્ષેત્ર પૂછાય તો સીધું 'શૂન્ય' વિકલ્પ પસંદ કરો. આમ જ ઘણા પ્રશ્નોમાં ભ્રામક વિકલ્પો હોય છે પણ ઉત્તર શૂન્ય જ હોય છે.
જ્યારે પ્રશ્નમાં સેલેનોઇડની બહાર ચુંબકીય ક્ષેત્ર વિશે પૂછવામાં આવે અથવા અનંત લાંબા સેલેનોઇડનો સંદર્ભ હોય.
દા.ત.: પ્રશ્ન: અનંત લાંબા સેલેનોઇડની બહાર B કેટલું? જવાબ: શૂન્ય → વિકલ્પ (અ).
