૧. પરિચય — ચુંબકત્વ અને વિદ્યુતપ્રવાહ
જ્યારે કોઈવાહકમાંથી વિદ્યુતપ્રવાહ વહે છે ત્યારે તેની આસપાસ ચુંબકીય ક્ષેત્ર ઉભું થાય છે.
ચુંબકીય ક્ષેત્ર એ સદિશ રાશિ છે; તેની દિશા ચુંબકીય ડાંટીના ઉત્તર ધ્રુવ પર લાગતા બળની દિશા મુજબ નક્કી કરવામાં આવે છે.
વિદ્યુત અને ચુંબકત્વ — આ બંને પરસ્પર સંકળાયેલા હોય છે : વિદ્યુતપ્રવાહ → ચુંબકીય ક્ષેત્ર અને બદલાતું ચુંબકીય ક્ષેત્ર → વિદ્યુતક્ષેત્ર.
📝 NEET માં ચુંબકીય ક્ષેત્રની દિશા શોધવાના નિયમો ખૂબ જરાજરૂરી છે.
૨. ઓરેડસનો પ્રયોગ
૧૮૨૦માં ડાનિઅલ ઓરેડસે દર્શાવ્યું કે વિદ્યુતપ્રવાહ વહન કરતા તારની નજીક મૂકેલો કોમ્પાસ针 વભ્રમણ પામે છે.
આ પ્રયોગે સાબિત કર્યું કે વિદ્યુતપ્રવાહ ચુંબકીય ક્ષેત્ર પેદા કરે છે.
કોમ્પાસ针 નું વળાંકતારની આસપાસ ચુંબકીય ક્ષેત્રની હસ્તી
જો વિદ્યુતપ્રવાહની દિશા ફેરવવામાં આવે તો针ની વિચ્યુતિ પણ વિરુદ્ધ દિશામાં થાય છે.
ઓરેડસનો પ્રયોગ ચુંબકીય પ્રભાવના અસ્તિત્વનું પ્રથમ પ્રાયોગિક પુરાવો છે.
૩. બાયો-સેવર્ટનો નિયમ (Biot–Savart Law)
કરંટ ઇલિમેન્ટ I.dl દ્વારા બિંદુ P પર ઉભું થતું ચુંબકીય ક્ષેત્ર dB ની તીવ્રતા : dB = (μ₀ / 4π) · (I dl sinθ) / r²
dB = (μ₀ / 4π) · (I dl × r̂) / r²
μ₀ = ચુંબકીય પરિવাহિતતા ( permeability of free space ) = 4π × 10⁻⁷ T·m/A
θ એ dl અને r વચ્ચેનો ખૂણો છે; r એ ઇલિમેન્ટથી બિંદુ P નું અંતર છે.
dB → dl ની દિશાથી r બરાબર l (perpendicular) હોય ત્યારે મહત્તમ થાય છે.
📝 બાયો-સેવર્ટ નિયમ વિદ્યુતસ્થિતિ વિજ્ઞાનના કુલંબના નિયમ સાથે સરખાવી શકાય.
૪. સીધા પ્રવાહવાહક તારનું ચુંબકીય ક્ષેત્ર
B = (μ₀ I) / (2π r) (અનંત સીધા તાર માટે)
B માં પ્રવાહ I સાથે સમપ્રમાણ અને અંતર r સાથે વ્યસ્ત પ્રમાણ છે.
ચુંબકીય ક્ષેત્રરેખાઓ તારની આસપાસ સાંકડી વર્તુળાકાર છે.
ક્ષેત્રરેખાઓ વર્તુળાકારમધ્યમાં ક્ષેત્ર સૌથી વધુ, હોવાવાટી બહાર ઘટતી જાય
દક્ષિણાંગુળિયાનો નિયમ (Right-hand thumb rule) : અંગૂઠો પ્રવાહ દિશામાં, અંગુઠાની ફરતે લંબાવેલી એંઠિયા દિશા ક્ષેત્રરેખા દર્શાવે છે.
૫. વર્તુળાકાર કરંટ લૂપનું ચુંબકીય ક્ષેત્ર
B_center = (μ₀ N I) / (2 R) (વર્તુળ કેન્દ્ર પર)
N એ લૂપની ફેરોની સંખ્યા છે, R ત્રિજ્યા છે.
અક્ષ પર અંતર x પર બિંદુએ : B = (μ₀ N I R²) / (2 (R² + x²)^(3/2))
x = 0 હોય ત્યારે આ સૂત્ર ક્ષેત્ર કેન્દ્રના સૂત્ર સાથે સુસંગત બને છે.
વર્તુળાકાર લૂપની અક્ષ પર ક્ષેત્રરેખાઓ સીધી હોય છે; વર્તુળની ફરતે તે વક્ર હોય છે.
📝 Helmholtz coil : બે સમાંતર વર્તુળાકાર લૂપ જે અક્ષ પર લગભગ સમાન ક્ષેત્ર પેદા કરે છે.
૬. સોલેનોઇડ (Solenoid)
B = μ₀ n I (અનંત સોલેનોઇડના આંતરિક ભાગમાં)
n = N/L એ એકમ લંબાઈનાં ફેરાની સંખ્યા છે.
સોલેનોઇડની અંદર ક્ષેત્રરેખાઓ સમાંતર અને સમાન અંતરે રહે છે → ક્ષેત્ર એકસમાન (uniform) હોય છે.
સોલેનોઇડની બહાર ક્ષેત્ર નગણ્ય (શૂન્યની નજીક) ગણી શકાય.
સોલેનોઇડ → વિદ્યુતચુંબક (electromagnet) તરીકે વર્તે છે; આંતરમાં લોહકore મૂકતાં B ઘણી વધે છે.
સોલેનોઇડમાં કોર મૂકવીચુંબકીય ક્ષેત્ર તીવ્રતા ↑
૭. એમ્પિરનો પરિવલય નિયમ (Ampere's Circuital Law)
∮ B·dl = μ₀ I_enclosed
કોઈ પણ બંધ વલય પર ચુંબકીય ક્ષેત્રનું રેખા સંકલન એ વલય વડા ઘેરાયેલા પ્રવાહના ગુણક μ₀I જેટલું હોય છે.
આ નિયમનો ઉપયોગ સોલેનોઇડ અને સીધા તારનું ક્ષેત્ર શોધવા માટે સરળતાથી કરી શકાય છે.
એમ્પિરનો નિયમ ફેરાડેના વિદ્યુતચુંબકીય પ્રેરણાના વિપરીત સમમિતિ પ્રદર્શિત કરે છે.
📝 NEET : એમ્પિરના નિયમમાં B·dl નું ચિહ્ન ધ્યાન રાખવું — જો પ્રવાહ વલયની દિશામાં હોય તો ધન.
૮. ચુંબકીય ક્ષેત્રમાં ગતિમાન આભાર (Charge)
F = q v B sinθ અથવા F = q (v × B)
લોરેન્ઝ બળ એ વેગ અને ક્ષેત્ર બંનેને લંબરૂપે લાગે છે; તે ગતિની દિશા બદલે છે પણ કાર્ય શૂન્ય કરે છે.
જો v ∥ B હોય તો F = 0; જો v ⊥ B હોય તો F_max = qvB.
ચુંબકીય બળ કદી પણ આભાર પર કાર્ય કરતું નથી → ગતિઙ્જળમાં ફેરફાર નથી આવતો, માત્ર દિશા બદલાય છે.
v ⊥ Bવર્તુળાકાર પથ (Circular path)
v ∥ Bસીધી રેખા ગતિ
📝 F = q(E + v × B) એ સંપૂર્ણ લોરેન્ઝ બળ સૂત્ર છે.
૯. વર્તુળાકાર પથની ત્રિજ્યા અને આવર્તકાળ
r = mv / (qB)
કેન્દ્રલબ્ધિ બળ તરીકે ચુંબકીય બળ લાગે છે : qvB = mv²/r.
T = 2πm / (qB) વ આવર્તકાળ
આવર્તકાળ v અને r પર આધારિત નથી — માત્ર m, q, B પર આધાર રાખે છે.
સમાન B માં ભિન્ન વેગ ધરાવતા કણો પણ સમાન આવર્તકાળથી ફરે છે.
૧૦. સાયક્લોટ્રોન (Cyclotron)
સાયક્લોટ્રોન ઋણાત્મક અથવા ધનાત્મક આભારિત કણોને વેગવર્ધક સાધન છે.
બે D-આકારના તમા (Dees) વચ્ચે ઉચ્ચ આવૃત્તિનું AC વોલ્ટેજ લગાડવામાં આવે છે.
સમાન ચુંબકીય ક્ષેત્ર કણોને D-આંતરમાં વર્તુળાકાર પથ પર ફેરવે છે; જ્યારે કણ Dee વચ્ચેના અંતરમાંથી પસાર થાય છે ત્યારે વિદ્યુતક્ષેત્ર વેગ વધારે છે.
K_max = (q² B² R²) / (2m)
R એ Deeની ત્રિજ્યા છે; મહત્તમ ગતિઙ્જળ Deeની ત્રિજ્યા પર આધારિત છે.
Cyclotron frequency : f = qB / (2πm) — આ આવૃત્તિ AC વોલ્ટેજ સાથે સદૃશ (resonance) હોવી જોઈએ.
📝 NAAT પરીક્ષામાં સાયક્લોટ્રોનની મર્યાદાઓ (પ્રકાશની ગતિની નજીક ગતિએ કણનું દળ વધે છે) વિશે પ્રશ્ન આવી શકે છે.
૧૧. સંપાતી પ્રવાહવાહક તારો વચ્ચેનું બળ
F/L = (μ₀ I₁ I₂) / (2π d)
બે સમાંતર તારોમાં સમાન દિશામાં પ્રવાહ → આકર્ષણ; વિરુદ્ધ દિશામાં પ્રવાહ → વિખેરણ.
આ આકર્ષણ/વિખેરણ બળ એ બંને તારોના ચુંબકીય ક્ષેત્રોનો પરિણામ છે.
1 એમ્પિર પ્રવાહ વહન કરતા બે સમાંતર તારો વચ્ચે 1 m અંતરે 2×10⁻⁷ N/m બળ લાગે છે.
📝 એમ્પિયરની વ્યાખ્યા આ જ ઘટના પર આધારિત છે.
૧૨. પ્રવાહવાહક તાર પર ચુંબકીય બળ
F = I (l × B) અથવા F = I l B sinθ
ધન આભારની ગતિ દિશા પ્રવાહની દિશા છે; F ની દિશા FBI ના નિયમ (Fleming's left-hand rule) મુજબ મળે છે.
θ = 0° અથવા 180° હોય તો F = 0; θ = 90° હોય તો F = IlB.
FBI નો ડાબો હાથનો નિયમતરંગાંતર : તેરલું બુરજી = B, બીજું બુરજી = I, મુખરંગુલ = F
આ નિયમ ઈલેક્ટ્રિક મોટરના સિદ્ધાંતનો આધાર છે.
૧૩. વેળાવટ ચલની ગાલ્વેનોમીટર (Moving Coil Galvanometer)
આંતરિક દૃઢ કોઇલ પર પ્રવાહ વહન કરતાં ચુંબકીય બળ જોડાતાં ટોર્ક ઉત્પન્ન થાય છે.
τ_deflecting = N I A B (radial field માં)
સ્પ્રિંગ પરતું ટોર્ક : τ_restoring = k φ, જ્યાં k વિસ્તારાંક (torsion constant) છે અને φ કોણીય વિચ્યુતિ.
I = (k / NANB) · φ = φ / (sensitivity constant)
આંતરિક સૂત્ર મુજબ : I = (k φ) / (N A B) — પ્રવાહ ફળિતકોણના સમપ્રમાણમાં છે, તેથી માપન રેખીય (linear) મળે છે.
વેળાવટ ચલની સંવેદનશીલતા : θ/I = NANB / k (મોટું N, A, B અને નાનો k હોય તો વધુ સંવેદનશીલ).
૧૪. વેળાવટ ચલનો પ્રવાહમાપક (Ammeter) અને વોલ્ટમાપક (Voltmeter) માં રૂપાંતર
પ્રવાહમાપક બનાવવા : ગાલ્વેનોમીટરને સમાંતર (parallel) ચારેશ (shunt) R_sh મૂકવામાં આવે છે.
R_sh = (I_g · G) / (I − I_g) જ્યાં G = ગાલ્વેનોમીટર પ્રતિબાધ
વોલ્ટમાપક બનાવવા : ગાલ્વેનોમીટરને ક્રમશઃ (series) મોટી પ્રતિબાધ R_s જોડવી પડે છે.
R_s = (V / I_g) − G
આદર્શ અમીટરની પ્રતિબાધ શૂન્ય હોવી જોઈએ; આદર્શ વોલ્ટમીટરની પ્રતિબાધ અનંત હોવી જોઈએ.
📝 NEET માં shunt ની ગણતરી અને R_s ની ગણતરી — બંને પ્રકારના પ્રશ્નો સતત આવે છે.
૧૫. સ્થાયી ચુંબક (Permanent Magnets)
કોઈ પણ ચુંબકના બે ધ્રુવ હોય છે — ઉત્તર (N) અને દક્ષિણ (S); એકધારો ધ્રુવ અસ્તિત્વમાં નથી.
સ્થાયી ચુંબકનું ચુંબકીય ક્ષેત્ર ગાલ્વેનોમીટર જેવા ઉપકરણોમાં Radial magnetic field પેદા કરવા માટે વપરાય છે.
ચુંબકીય ડાઈપોલ મોમેન્ટ : m = N I A (દિશા સમતલને લંબરૂપ સમતલમાં હોય છે.)
ચુંબકીય ડાઈપોલ મોમેન્ટનું SI એકમ : A·m² અથવા J/T.
📝 ચુંબકીય ક્ષેત્રરેખાઓ હંમેશાં S થી N તરફ બાહ્ય ભાગમાં અને N થી S તરફ આંતરિક ભાગમાં લંબરૂપ ચાલે છે.
૧૬. ધરતીનું ચુંબકીય ક્ષેત્ર (Earth's Magnetism)
ધરતી એક વિશાળ ચુંબકની જેમ વર્તે છે; તેનો ચુંબકીય ધ્રુવ ભૌગોલિક ધ્રુવ સાથે મળતો નથી.
ચુંબકીય દિષ્ટાંત (Declination) : ભૌગોલિક ઉત્તર-દક્ષિણ રેખા અને ચુંબકીય ઉત્તર-દક્ષિણ રેખા વચ્ચેનો ખૂણો.
વક્રતા (Dip) : કોઈ બિંદુએ ધરતીના ચુંબકીય ક્ષેત્રની ક્રિયાકારી રેખા અને આડી સપાટી વચ્ચેનો ખૂણો.
B_H = B cosδ ; B_V = B sinδ જ્યાં δ = વક્રતા
સમચુંબકીય રેખા (Magnetic equator) : અહીં δ = 0°, B_V = 0, B = B_H.
ચુંબકીય ધ્રુવ : અહીં δ = 90°, B_H = 0, B = B_V.
ચુંબકીય ક્ષેત્રનું કુલ મૂલ્ય B = √(B_H² + B_V²) થાય.
📝 NEET માં B_H, B_V, δ વચ્ચેના સંબંધો પર સીધા પ્રશ્નો આવે છે.
