🧠 યાદ રાખો

રઞ્ધૂફોર્ડના અલ્ફા-ખંડ પ્રક્ષેપણ પ્રયોગમાં મોટા ખૂણે વિચ્યુત થતું કણો નાભિકની ધન વીજભારિત ઉપસ્થિતિ દર્શાવે છે.
બોહ્રના પરમાણુ મોડેલમાં કક્ષાનો કોણીય વેગમાન ક્વોન્ટાયઝડ હોય છે: L = nħ, જ્યાં n = 1, 2, 3…
બોહ્ર ત્રિજ્યા r_n ∝ n²/Z; બોહ્ર ત્રિજ્યા પ્રഥમ કક્ષા (n=1) માટે ≈ 0.529 Å.
બોહ્ર ઊર્જા સૂત્ર E_n = −13.6 Z²/n² eV; n=1 માટે H પરમાણુની ઊર્જા −13.6 eV.
લાઈમેન, બાલમેર, પેશન, બ્રាកેટ, પુંડ સpekt્રમ શ્રેણીઓ અનુક્રમે n₁ = 1,2,3,4,5 તરફ સંક્રમણ સાથે સંબંધિત છે.
ડी-બ્રોગ્લી તરંગલંબાઈ λ = h/mv = h/√(2mK); વેગવિભવ V થાઈત વેગીત કણની λ = h/√(2meV).
નાભિકીય બંધન ઊર્જા B.E. = Δm × 931.5 MeV, જ્યાં Δm = [Zm_p + Nm_n − M_nucleus].
આવૃત્તિ શ્રેણી (α, β, γ) માં γ કિરણોની ભેદન શક્તિ સૌથી વધુ, α ની સૌથી ઓછી (2–10 cm હવામાં).
બીટા ક્ષયમાં n → p + e⁻ + ν̄_e (β⁻) અથવા p → n + e⁺ + ν_e (β⁺); પ્રમાણભૂત મોડેલ મુજબ ન્યુટ્રિનો/એન્ટીન્યુટ્રિનો ઉત્પન્ન થાય છે.
અર્ધ-આયુ t½ = ln2/λ; N = N₀e^(−λt); સક્રિયતા A = λN.

⚡ ઝડપી સૂત્રો

E_n = −13.6 Z²/n² eV; ΔE = 13.6 Z²(1/n_f² − 1/n_i²) eV
r_n = 0.529 n²/Z Å; v_n = 2.18×10⁶ Z/n m/s
1/λ = RZ²(1/n₁² − 1/n₂²); R ≈ 1.097×10⁷ m⁻¹
B.E. = [Zm_p + Nm_n − M(A,Z)]c² = Δm × 931.5 MeV
તરીકો શ્રેણીબદ્ધ નાભિકીય પ્રતિક્રિયા: A → B + C; Q = (m_A − m_B − m_C)c²
n = n₀e^(−λt), t½ = 0.693/λ, સરેરાશ આયુ τ = 1/λ
ડી-બ્રોગ્લી: λ = h/p; K.E. માંથી λ = h/√(2mK)
ફિશન: n + ²³⁵U → ¹⁴¹Ba + ⁹²Kr + 3n + ~200 MeV
ફ્યુઝન: ²H + ³H → ⁴He + n + 17.6 MeV

✅ વન-લાઈનર્સ

બોહ્રના મોડેલ મુજબ ઈલેક્ટ્રોન સ્થિર કક્ષામાં ઘૂમે છે પણ ઊર્જા વિકિરણ કરતો નથી (સ્ટેશનરી સ્ટેટ્સ).
રઞ્ધૂફોર્ડના પ્રયોગથી નાભિકનું કદ ~10⁻¹⁵ m અને પરમાણુનું કદ ~10⁻¹⁰ m એમ આવશ્યક કક્ષા મળે છે.
બોહ્રનો મતે ઈલેક્ટ્રોન n_i → n_f સંક્રમણ દરમિયાન ફોટોન શોષે કે ઉત્સર્જિત કરે છે: hν = E_i − E_f.
હાઇડ્રોજન જેવા પરમાણુઓ માટે બોહ્રનું સૂત્ર ચોકસાઈથી પાળે છે; બહુ-ઈલેક્ટ્રોન પરમાણુઓ માટે તે અનુમાનીકરણજ રહે છે.
નાભિકીય ઘનતા લગભગ સતત (~2.3×10¹⁷ kg/m³) હોય છે; નાભિકીય ત્રિજ્યા R = R₀A^(1/3), R₀ ≈ 1.2 fm.
α કણ = ⁴He નાભિક (+2e), β⁻ કણ = ઉચ્ચ ઊર્જા ઇલેક્ટ્રોન, β⁺ = પોઝિટ્રોન; γ = ઉચ્ચ આવૃત્તિ EM તરંગ.
ફોટોઈલેક્ટ્રિક અસરમાં K_max = hν − φ; પ્રમાણભૂત હાઇડ્રોજન ઉત્સર્જનમાં સૌથી ઓછી λ લાઈમેન શ્રેણીમાં મળે છે.
બંધન ઊર્જા પ્રતિ ન્યુક્લિયોન (B.E./A) નો ગ્રાફ Fe-56 આસપાસ મહત્તમ (~8.8 MeV) દર્શાવે છે.
ફિશન અને ફ્યુઝન બંનેમાં B.E./A વધે છે; તેથી ઊર્જા મુક્ત થાય છે.
નેટ્રોન દ્વારા ઉત્તેજિત યુરેનિયમ-235 નું વિભાજન ચેઇન રિએક્શન સ્વીકારે છે અને ન્યુક્લિયર રિએક્ટરમાં બળતણ પૂરું પાડે છે.
