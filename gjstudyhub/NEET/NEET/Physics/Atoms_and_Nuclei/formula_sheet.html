⚡ સૂત્રો

બોહ્રની કક્ષાની ત્રિજ્યા (Hydrogen-like atom): r_n = (n^2 * h^2 * eps0) / (pi * m * e^2 * Z) or r_n = 0.529 * (n^2 / Z) A
r_n = n-મંથા કક્ષાની ત્રિજ્યા, n = મુખ્ય ક્વોન્ટમ અંક, h = પ્લાન્ક અચળાંક, eps0 = શૂન્યાવકાશની પરમિટિવિટી, m = ઇલેક્ટ્રોનનું દળ, e = મૂળભૂત આભાર, Z = પરમાણુ ક્રમાંક, A = એંગસ્ટ્રોમ · SI: મીટર (m) · બોહ્રના પરમાણુ મોડેલ માટે લાગુ પડે છે; Hydrogen (Z=1) અને hydrogen-like ions (He+, Li2+ વગેરે)
કક્ષાનો વેગ: v_n = (e^2) / (2 * eps0 * h) * (Z / n) or v_n = 2.188 * 10^6 * (Z / n) m/s
v_n = n-મંથા કક્ષામાં ઇલેક્ટ્રોનનો વેગ, Z = પરમાણુ ક્રમાંક, n = મુખ્ય ક્વોન્ટમ અંક · SI: મીટર/સેકન્ડ (m/s) · Hydrogen-like परमाणુઓ માટે
કક્ષાનો કોણીય વેગ: omega_n = v_n / r_n
omega_n = કોણીય વેગ, v_n = રેખીય વેગ, r_n = કક્ષાની ત્રિજ્યા · SI: રેડિયન/સેકન્ડ (rad/s) · વર્તુળાકાર કક્ષા માટે
કક્ષા આવર્તકાળ: T_n = (2 * pi * r_n) / v_n
T_n = આવર્તકાળ, r_n = ત્રિજ્યા, v_n = વેગ · SI: સેકન્ડ (s) · વર્તુળાકાર કક્ષા માટે
ઇલેક્ટ્રોનની ગતિજ ઊર્જા: K_n = (m * e^4) / (8 * eps0^2 * h^2) * (Z^2 / n^2) or K_n = 13.6 * (Z^2 / n^2) eV
K_n = ગતિજ ઊર્જા, m = ઇલેક્ટ્રોન દળ, e = આભાર, Z = પરમાણુ ક્રમાંક, n = મુખ્ય ક્વોન્ટમ અંક · SI: જૂલ (J) અથવા eV · બોહ્ર મોડેલ હેઠળ
સ્થિતિજ ઊર્જા: U_n = - (m * e^4) / (4 * eps0^2 * h^2) * (Z^2 / n^2) or U_n = -27.2 * (Z^2 / n^2) eV
U_n = સ્થિતિજ ઊર્જા, અન્ય પ્રતીકો ઉપર મુજબ · SI: જૂલ (J) અથવા eV · કુલંબ આકર્ષણ બળ માટે
કુલ ઊર્જા: E_n = - (m * e^4) / (8 * eps0^2 * h^2) * (Z^2 / n^2) or E_n = -13.6 * (Z^2 / n^2) eV
E_n = કુલ ઊર્જા, Z = પરમાણુ ક્રમાંક, n = મુખ્ય ક્વોન્ટમ અંક · SI: જૂલ (J) અથવા eV · બંધાયેલ પ્રણાલી માટે ઋણ ચિહ્ન; ground state n=1
ઊર્જાનું રૂપાંતરણ (eV થી J): 1 eV = 1.602 * 10^-19 J
eV = ઇલેક્ટ્રોન-વોલ્ટ, J = જૂલ · SI: જૂલ (J) · કોઈ પણ ઊર્જાને eV માંથી J માં ફેરવવા માટે
ફોટોનની આવૃત્તિ (સંક્રમણ દરમિયાન): nu = (E_i - E_f) / h or nu = R*c*(1/n_f^2 - 1/n_i^2)
nu = આવૃત્તિ, E_i અને E_f = પ્રારંભિક અને અંતિમ ઊર્જા levels, h = પ્લાન્ક અચળાંક, R = રિડબર્ગ અચળાંક, c = પ્રકાશનો વેગ · SI: હર્ટઝ (Hz) · જ્યારે ઇલેક્ટ્રોન ઉચ્ચ ઊર્જા સ્તરથી નીચે ઊર્જા સ્તરમાં સંક્રમણ કરે
તરંગલંબાઈ (Rydberg સૂત્ર): 1/lambda = R * Z^2 * (1/n_f^2 - 1/n_i^2)
lambda = તરંગલંબાઈ, R = રિડબર્ગ અચળાંક (1.097*10^7 m^-1), Z = પરમાણુ ક્રમાંક, n_f < n_i · SI: મીટર (m) · Hydrogen અને hydrogen-like spectra
Lyman શ્રેણી (Transition to n=1): 1/lambda = R * (1 - 1/n_i^2), n_i = 2,3,4,...
lambda = તરંગલંબાઈ, R = રિડબર્ગ અચળાંક · SI: મીટર (m) · અલ્ટ્રાવાયોલેટ વિસ્તાર
Balmer શ્રેણી (Transition to n=2): 1/lambda = R * (1/4 - 1/n_i^2), n_i = 3,4,5,...
lambda = તરંગલંબાઈ, R = રિડબર્ગ અચળાંક · SI: મીટર (m) · દૃશ્યમાન પ્રકાશ વિસ્તાર
Paschen, Brackett, Pfund શ્રેણી: Paschen: 1/lambda = R*(1/9 - 1/n^2); Brackett: 1/lambda = R*(1/16 - 1/n^2); Pfund: 1/lambda = R*(1/25 - 1/n^2)
n = ઉચ્ચ સ્તર (4,5,6...) · SI: મીટર (m) · ઇન્ફ્રારેડ વિસ્તાર
સ્રાવનો દર (Activity): A = lambda * N or A = -dN/dt
A = સ્રાવનો દર (Activity), lambda = ક્ષય અચળાંક, N = કિરણોત્સર્ગી ન્યુક્લિયસની સંખ્યા · SI: બેક્વેરલ (Bq) · કિરણોત્સર્ગી ક્ષયના નિયમ માટે
કિરણોત્સર્ગી ક્ષયનો નિયમ: N = N0 * e^(-lambda*t)
N = t સમયે બાકી રહેલા ન્યુક્લિયસ, N0 = પ્રારંભિક ન્યુક્લિયસ, lambda = ક્ષય અચળાંક, t = સમય · SI: એકમ વિહીન (સંખ્યા) · રેડિયોએક્ટિવ ક્ષય માટે
સ્રાવ (Activity) સમય સાથે: R = R0 * e^(-lambda*t)
R = t સમયે સ્રાવ, R0 = પ્રારંભિક સ્રાવ, lambda = ક્ષય અચળાંક, t = સમય · SI: Bq અથવા Ci · કિરણોત્સર્ગી સ્રાવ માટે
અર્ધઆયુ (Half-life): T_(1/2) = ln(2) / lambda or T_(1/2) = 0.693 / lambda
T_(1/2) = અર્ધઆયુ, lambda = ક્ષય અચળાંક · SI: સેકન્ડ (s) · કિરણોત્સર્ગી પદાર્થ માટે
સરેરાશ આયુ (Mean lifetime): tau = 1 / lambda or tau = T_(1/2) / ln(2)
tau = સરેરાશ આયુ, lambda = ક્ષય અચળાંક · SI: સેકન્ડ (s) · સરેરાશ જીવનકાળ માટે
Becquerel અને Curie એકમ: 1 Ci = 3.7 * 10^10 Bq
Ci =Curie, Bq=Becquerel · SI: Bq (SI) · એકમ રૂપાંતરણ માટે
માસ ડિફેક્ટ (Mass Defect): Delta m = Z*m_p + (A-Z)*m_n - M
Delta m = માસ ડિફેક્ટ, Z = પ્રોટોન સંખ્યા, A = દળ સંખ્યા, m_p = પ્રોટોન દળ, m_n = ન્યુટ્રોન દળ, M = ન્યુક્લિયસનું વાસ્તવિક દળ · SI: kg અથવા u · ન્યુક્લિયસ બનતાં દળહ્રાસ માટે
બાઈન્ડિંગ ઊર્જા (Binding Energy): B.E. = Delta m * c^2 or B.E. = Delta m (in u) * 931.5 MeV
B.E. = બાઈન્ડિંગ ઊર્જા, Delta m = માસ ડિફેક્ટ, c = પ્રકાશનો વેગ, 1 u = 931.5 MeV/c^2 · SI: J અથવા MeV · ન્યુક્લિયર બાઈન્ડિંગ ઊર્જા માટે
બાઈન્ડિંગ ઊર્જા per nucleon: B.E./A = [Z*m_p + (A-Z)*m_n - M] * c^2 / A
B.E./A = પ્રતિ ન્યુક્લિઓન બાઈન્ડિંગ ઊર્જા, A = દળ સંખ્યા · SI: MeV/nucleon · ન્યુક્લિયસની સ્થિરતા માપવા માટે
નોટ્રોન-પ્રોટોન ગુણોત્તર (Stability): N/Z = (A-Z)/Z
N = ન્યુટ્રોન સંખ્યા, Z = પ્રોટોન સંખ્યા, A = દળ સંખ્યા · SI: એકમ વિહીન · સ્થિર ન્યુક્લિયસ માટે N/Z >= 1 (ભારે તત્વો માટે ~1.5)
ન્યુક્લિયસની ત્રિજ્યા: R = R0 * A^(1/3)
R = ન્યુક્લિયસની ત્રિજ્યા, R0 = 1.2 fermi (1.2*10^-15 m), A = દળ સંખ્યા · SI: મીટર (m) · બધા ન્યુક્લિયસ માટે અંદાજિત
ન્યુક્લિયર ઘનફળ અને અચળ ઘનતા: Volume = (4/3) * pi * R^3;rho = constant
R = ન્યુક્લિયસની ત્રિજ્યા, rho = ન્યુક્લિયર ઘનતા (~2.3*10^17 kg/m^3) · SI: kg/m^3 · ન્યુક્લિયર ઘનતા ન્યુક્લિયસના કદ પર આધારિત નથી
ન્યુક્લિયર પ્રતિક્રિયા - Energy Released (Q-value): Q = (M_reactants - M_products) * c^2
Q = મુક્ત થતી ઊર્જા, M_reactants = પ્રતિક્રિયકોનું કુલ દળ, M_products = નીપજોનું કુલ દળ · SI: J અથવા MeV · ઉષ્માક્ષેપક (exothermic) પ્રતિક્રિયાઓ માટે Q > 0
Chain Reaction - Neutron multiplication: N = N0 * k^n
N = અંતિમ ન્યુટ્રોન સંખ્યા, N0 = પ્રારંભિક સંખ્યા, k = ગુણાકાર અચળાંક, n = સ્તર સંખ્યા · SI: એકમ વિહીન · શૃંખલા પ્રતિક્રિયા માટે; k>1 માટે exponential growth
કણોનું વિકિરણ - Alpha: X_Z^A -> Y_(Z-2)^(A-4) + He_2^4 + Q
He_2^4 = alpha કણ, Q = મુક્ત ઊર્જા · SI: MeV · Alpha ક્ષય દરમિયાન
કણોનું વિકિરણ - Beta minus: n -> p + e^- + anti-nu_e + Q
anti-nu_e = એન્ટિન્યુટ્રિનો, e^- = બીટા કણ · SI: MeV · Beta minus (β-) ક્ષય
કણોનું વિકિરણ - Beta plus: p -> n + e^+ + nu_e + Q
nu_e = ન્યુટ્રિનો, e^+ = પોઝિટ્રોન · SI: MeV · Beta plus (β+) ક્ષય
Beta maximum kinetic energy: (K_e)_max = Q
Q = ક્ષય ઊર્જા, (K_e)_max = ઉત્સર્જિત ઇલેક્ટ્રોનની ન્યૂનતમ ઊર્જા not Maximum; here max kinetic energy · SI: MeV · Beta spectrum માં maximum energy
Gamma emission: X* -> X + gamma + Q
X* = ઉત્તેજિત ન્યુક્લિયસ, gamma = ગામા કિરણ · SI: MeV · ન્યુક્લિયસ ઉત્તેજિત અવસ્થામાંથી_ground state_ માં આવે

🔗 સંબંધો

  • બોહ્ર ત્રિજ્યા n^2 સમપ્રમાણ અને Z ને વ્યસ્ત સમપ્રમાણ છે: r_n ∝ n^2/Z.
  • કુલ ઊર્જા ધન ન્યુક્લિયસની ત્રિજ્યા v_n ∝ Z/n અને ઋણ છે, તેથી E_n ∝ -Z^2/n^2.
  • કક્ષાની ગતિજ ઊર્જા ધન છે અને કુલ ઊર્જાના મોડ્યુલસ જેટલી છે: K = |E|. સ્થિતિજ ઊર્જા ઋણ છે અને 2K જેટલી છે: U = -2K.
  • અર્ધઆયુ T_(1/2) અને ક્ષય અચળાંક lambda વચ્ચેનો સંબંધ T_(1/2) = 0.693/lambda છે; ક્ષય અચળાંક જેટલો વધુ, તેટલી ઝડપી ક્ષય.
  • સ્રાવ A અને અર્ધઆયુ વચ્ચે વ્યસ્ત સંબંધ: જેટલી ટૂંકી અર્ધઆયુ, તેટલો વધુ સ્રાવ.
  • ન્યુક્લિયસની ઘનતા અંદાજે તમામ ન્યુક્લિયસ માટે અચળ છે, એટલે કે ન્યુક્લિયર ઘનતા દળ સંખ્યા A પર આધારિત નથી.
  • બાઈન્ડિંગ ઊર્જા per nucleon (B.E./A) ઊર્ધ્વગામી વલણ ધરાવે છે અને લગભગ A=56 (Iron) પાસે મહત્તમ (~8.8 MeV) હોય છે.
  • પૃથક્કરણ (Fission) અને સંલયન (Fusion) બંનેમાં B.E./A વધે છે અને પરિણામે ઊર્જા મુક્ત થાય છે.

🎯 ટ્રિક્સ

Hydrogen જેવા systems માટે ઝડપી ગણતરી: E_n = -13.6 * Z^2 / n^2 eV; આ સૂત્ર ખૂબ જ ઉપયોગી છે.
જો કોઈ નમૂનો t = n * T_(1/2) સમયગાળામાં રહે, તો બાકી રહેલો ભાગ (1/2)^n થાય છે, એટલે કે N/N0 = (1/2)^n.
રૂપાંતરણ સમયમાં ન્યૂનતમ સમય શોધવા માટે n = t/T_(1/2) લઈને N = N0*(1/2)^n વાપરો.
Lambda અને અર્ધઆયુ વચ્ચેનો ગુણોત્તર 0.693 હંમેશા સ્થિર છે; એટલે T_(1/2) * lambda ≈ 0.693.
દળ ડિફેક્ટને MeV માં ફેરવવા માટે 1 u = 931.5 MeV/c^2 નો ગુણાકાર કરવો, જે ગણતરી સરળ બનાવે છે.
