Q1. રદરફોર્ડના સ્વર્ણ વર્કા (Gold Foil) પ્રયોગ પરથી કઈ ભૂલપૂર્વકની ધારણા સિદ્ધ થઈ?
A. પરમાણુનું અંતરિક્ષમાં ધન આભાર કેન્દ્રિત હોય છે.
B. ઇલેક્ટ્રોન ન્યુક્લિયસની બહાર રહેતા નથી.
C. પરમાણુનો વ્યાસ ~10⁻¹⁰ m જેટલો હોય છે.
D. સક્રિય મૂલ્ય એ પરમાણુ સંખ્યાની બરાબર હોય છે.
✅ A — રદરફોર્ડના પ્રયોગ દરમિયાન સ્વાર્ણ વર્કામાંથી અલ્ફા કણો વિચલિત થતા હતા, જે સાબિત કરે છે કે પરમાણુનું ધન આભાર અને દળ એક very small કેન્દ્ર (ન્યુક્લિયસ) માં કેન્દ્રિત છે.
Q2. બોહરના પરમાણુ મોડેલ મુજબ, nમી કક્ષામાં ઇલેક્ટ્રોનનું કોણીય વેગમાન કેવું હોય છે?
A. n × h / 2π
B. h / n
C. n² × h / 2π
D. h / 2πn²
✅ A — બોહરની બીજી ધારણા મુજબ ઇલેક્ટ્રોનનું કોણીય વેગમાન L = nh/2π હોય છે, જ્યાં n એ યોગ્ય પૂર્ણાંક અને h પ્લાન્કનો સ્થિરાંક છે.
Q3. ન્યુક્લિયસની ત્રિજ્યા R અને દળ સંખ્યા A વચ્ચેનો સંબંધ શું છે?
A. R = R₀ A^(1/3)
B. R = R₀ A
C. R = R₀ / A
D. R = R₀ A²
✅ A — ન્યુક્લિયસની ત્રિજ્યા R = R₀ × A^(1/3) સૂત્ર દ્વારા મળે છે, જ્યાં R₀ ≈ 1.2 fm (ફર્મી) અને A દળ સંખ્યા છે. આ સૂત્ર ન્યુક્લિયસ અચળ ઘનતા ધરાવે છે તે દર્શાવે છે.
Q4. કોઈ સક્રિય આઇસોટોપની અર્ધ-આયુ 5 દિવસ છે. 20 દિવસ પછી મૂળ જથ્થાનો કેટલો ભાગ બાકી રહેશે?
A. 1/16
B. 1/8
C. 1/4
D. 1/32
✅ A — અર્ધ-આયુ = 5 દિવસ, કુલ સમય = 20 દિવસ → n = 20/5 = 4 અર્ધ-આયુ. બાકી રહેતો જથ્થો = (1/2)^4 = 1/16.
Q5. બેરિલિયમ-7 (⁷Be) ન્યુક્લિયસની બંધન ઊર્જા પ્રતિ ન્યુક્લિયોન (MeV માં) શોધો. (આપેલ છે: પ્રોટોન દળ = 1.0073 u, ન્યુટ્રોન દળ = 1.0087 u, Be-7 નું પરમાણુ દળ = 7.0169 u; 1 u = 931.5 MeV/c²)
A. ≈ 5.6 MeV
B. ≈ 7.1 MeV
C. ≈ 3.2 MeV
D. ≈ 9.0 MeV
✅ A — Be-7 માં 4 પ્રોટોન + 3 ન્યુટ્રોન = 7 ન્યુક્લિયોન. દળ ક્ષતિ Δm = (4×1.0073 + 3×1.0087) − 7.0169 = 0.0421 u. બંધન ઊર્જા = 0.0421 × 931.5 ≈ 39.2 MeV. પ્રતિ ન્યુક્લિયોન = 39.2/7 ≈ 5.6 MeV.
Q6. હાઈડ્રોજન પરમાણુમાં n=2 કક્ષામાં રહેલા ઇલેક્ટ્રોનની ગતિજ ઊર્જા (Kinetic Energy) કેટલી હોય? (હાઈડ્રોજન પરમાણુની આયનીકરણ ઊર્જા 13.6 eV છે.)
A. 13.6 eV
B. 6.8 eV
C. 3.4 eV
D. 1.7 eV
✅ C — બોહર મોડેલ મુજબ, nમી કક્ષામાં ઇલેક્ટ્રોનની કુલ ઊર્જા E_n = -13.6/n² eV. n=2 માટે E_2 = -3.4 eV. ગતિજ ઊર્જા K = |E_n| = 3.4 eV.
Q7. ફોટોઇલેક્ટ્રિક અસર દરમિયાન ધાતુથી ઉત્સર્જિત થતા ફોટોઇલેક્ટ્રોનની મહત્તમ ગતિજ ઊર્જા કઈ રાશિ પર આધાર રાખે છે?
A. અપાતી પ્રકાશની તીવ્રતા
B. અપાતી પ્રકાશની આવૃત્તિ
C. ધાતુનું પૃષ્ઠ ક્ષેત્રફળ
D. ધાતુનું તાપમાન
✅ B — આઈન્સ્ટાઈનના ફોટોઇલેક્ટ્રિક સમીકરણ મુજબ, K_max = hν - φ, જ્યાં ν એ પ્રકાશની આવૃત્તિ છે. તેથી મહત્તમ ગતિજ ઊર્જા પ્રકાશની આવૃત્તિ પર આધારિત છે, તીવ્રતા પર નહીં.
Q8. ન્યુક્લિયર બંધન ઊર્જા પ્રતિ ન્યુક્લિયોન વક્ર (Binding Energy per Nucleon Curve) અનુસાર નીચેનામાંથી કયું વિકલ્પ સાચું છે?
A. હલકા ન્યુક્લિયસનું વિખંડન (Fission) થઈને ભારે ન્યુક્લિયસ બને છે, જેમાં ઊર્જા મુક્ત થાય છે.
B. ભારે ન્યુક્લિયસનું વિખંડન થઈને હલકા ન્યુક્લિયસ બને છે, જેમાં ઊર્જા મુક્ત થાય છે.
C. હલકા ન્યુક્લિયસનું સંલયન (Fusion) થઈને ભારે ન્યુક્લિયસ બને છે, જેમાં ઊર્જા શોષાય છે.
D. ભારે ન્યુક્લિયસનું સંલયન થઈને હલકા ન્યુક્લિયસ બને છે, જેમાં ઊર્જા શોષાય છે.
✅ B — બંધન ઊર્જા પ્રતિ ન્યુક્લિયોન વક્ર દર્શાવે છે કે મધ્યમ દળ વાળા ન્યુક્લિયસ સૌથી સ્થિર હોય છે. ભારે ન્યુક્લિયસનું વિખંડન થવાથી મધ્યમ ન્યુક્લિયસ બને છે અને ઊર્જા મુક્ત થાય છે. હલકા ન્યુક્લિયસનું સંલયન થવાથી પણ ઊર્જા મુક્ત થાય છે, શોષાતી નથી.
Q9. હાઈડ્રોજન પરમાણુના સ્પેક્ટ્રમમાં લાાયમેન શ્રેણી (Lyman Series) ની સૌથી લાંબી તરંગલંબાઈ કઈ હોય? (રિડબર્ગ સ્થિરાંક R છે.)
A. 1/R
B. 4/(3R)
C. 9/(7R)
D. 16/(15R)
✅ B — લાાયમેન શ્રેણી માટે n1 = 1. સૌથી લાંબી તરંગલંબાઈ માટે n2 = 2 (ન્યૂનતમ ઊર્જા અંતર). રિડબર્ગ સૂત્ર મુજબ 1/λ = R(1/1² - 1/2²) = R(1 - 1/4) = 3R/4. તેથી λ = 4/(3R).
Q10. રેડિયોએક્ટિવ ક્ષય માટે ક્ષય સ્થિરાંક (Decay Constant) λ અને અર્ધ-આયુ (Half-life) T½ વચ્ચેનો સંબંધ કયો સાચો છે?
A. λ = T½ / ln 2
B. λ = ln 2 / T½
C. λ = T½ × 2.303
D. λ = T½ / 2.303
✅ B — રેડિયોએક્ટિવ ક્ષય નિયમ મુજબ, N = N0 e^(-λt). અર્ધ-આયુની વ્યાખ્યા મુજબ t = T½ પર N = N0/2. આથી N0/2 = N0 e^(-λT½) → 1/2 = e^(-λT½) → ln 2 = λT½ → λ = (ln 2)/T½.
