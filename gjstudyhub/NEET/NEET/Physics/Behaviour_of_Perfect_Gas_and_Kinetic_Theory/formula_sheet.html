આદર્શ ગેસનો વ્યવહાર અને અણુગતિજ સિદ્ધાંત — સૂત્ર પૂર્ણાહાર

⚡ સૂત્રો

બોયલના નિયમ ( Boyle's Law ): P × V = અચળ ( stT ),
P = દબાણ, V = ઘનફળ, T = નિરપેક્ષ તાપમાન; stT = અચળ તાપમાને. · SI: P : Pa, V : m³ · અચળ તાપમાને આદર્શ ગેસ માટે.
ચાર્લ્સના નિયમ ( Charles's Law ): V / T = અચળ ( stP ),
V = ઘનફળ, T = નિરપેક્ષ તાપમાન; stP = અચળ દબાણે. · SI: V : m³, T : K · અચળ દબાણે આદર્શ ગેસ માટે.
ગે-લુસ્સાકનો નિયમ ( Gay-Lussac's Law ): P / T = અચળ ( stV ),
P = દબાણ, T = નિરપેક્ષ તાપમાન; stV = અચળ ઘનફળ. · SI: P : Pa, T : K · અચળ ઘનફળે આદર્શ ગેસ માટે.
એવોગેડ્રોનો નિયમ ( Avogadro's Law ): V / n = અચળ ( stP, stT ),
V = ઘનફળ, n = મોલની સંખ્યા. · SI: V : m³, n : mol · અચળ દબાણ-તાપમાને બધા આદર્શ ગેસો માટે.
આદર્શ ગેસ સમીકરણ ( Ideal Gas Equation ): P V = n R T
P = દબાણ, V = ઘનફળ, n = મોલ, R = સાર્વત્રિક વાયુ અચળાંક ( ≈ 8.314 J mol⁻¹ K⁻¹ ), T = નિરપેક્ષ તાપમાન. · SI: Pa·m³ = J · આદર્શ ગેસ માટે સર્વસામાન્ય.
બંધારણ કિસ્સાનું સૂત્ર ( Combined Gas Law ): ( P₁ V₁ ) / T₁ = ( P₂ V₂ ) / T₂
અવસ્થા 1 અને અવસ્થા 2 માટે; n અચળ હોય. · SI: PV/T : J/K · ગેસનું પદાર્થક્ષેત્ર (n) અચળ હોય ત્યારે.
Boltzmann અચળાંક રૂપ ( Boltzmann form ): P V = N k_B T
N = અણુઓની કુલ સંખ્યા, k_B = Boltzmann અચળાંક ( ≈ 1.38 × 10⁻²³ J/K ); k_B = R / N_A. · SI: k_B : J K⁻¹ · આદર્શ ગેસમાં અણુસંખ્યાના સ્વરૂપમાં.
ગેસના દબાણનું અણુગતિજ સૂત્ર ( Kinetic Theory Pressure ): P = (1/3) × (N m v_rms²) / V
N = અણુઓની સંખ્યા, m = એક અણુનું દળ, v_rms = વર્ગમાધ્ય ગતિ, V = ઘનફળ. · SI: P : Pa · આદર્શ ગેસ માટે અણુગતિજ સિદ્ધાંત પરથી.
ઊર્જા સમાનરૂપ ( PV રૂપ ): P V = (1/3) N m v_rms²
ઉપરના સૂત્રનો જ ફરીથી લિખિત રૂપ. · SI: PV : J · આદર્શ ગેસ માટે.
વર્ગમાધ્ય ગતિ ( RMS Speed ): v_rms = √(3 R T / M) = √(3 k_B T / m)
R = વાયુ અચળાંક, T = નિરપેક્ષ તાપમાન, M = મોલર દળ (kg/mol), k_B = Boltzmann અચળાંક, m = એક અણુનું દળ. · SI: v_rms : m/s · આદર્શ ગેસના અણુઓ માટે.
સરાશ ગતિ ( Mean / Average Speed ): v_avg = √(8 R T / (π M)) = √(8 k_B T / (π m))
π = 3.1416..., અન્ય ચલો ઉપર મુજબ. · SI: v_avg : m/s · Maxwell ગતિ વિતરણ મુજબ આદર્શ ગેસ માટે.
સર્વાધિક સંભવિત ગતિ ( Most Probable Speed ): v_mp = √(2 R T / M) = √(2 k_B T / m)
અન્ય ચલો ઉપર મુજબ. · SI: v_mp : m/s · Maxwell વિતરણના શીર્ષબિંદુ પર.
ત્રણેય ગતિઓનો ગુણોત્તર ( Speed Ratio ): v_mp : v_avg : v_rms = √2 : √(8/π) : √3 ≈ 1 : 1.128 : 1.224
વર્ગમાધ્ય > સરાશ > સર્વાધિક સંભવિત. · SI: ગુણોત્તર અમિત એકમનો. · સૌ આદર્શ ગેસો માટે સમાન.
અણુની સરાશ ગતિજ ઊર્જા ( Translational KE per molecule ): KE_avg = (3/2) k_B T = (1/2) m v_rms²
k_B = Boltzmann અચળાંક, T = નિરપેક્ષ તાપમાન, m = અણુ દળ. · SI: KE : J · એકલા પરમાણ્વીય (monatomic) આદર્શ ગેસમાં.
n મોલ ગેસની કુલ સ્થાનાંતરી ગતિજ ઊર્જા ( Total Translational KE ): KE_total = (3/2) n R T = (3/2) N k_B T
n = મોલ, R = વાયુ અચળાંક, N = અણુસંખ્યા, k_B = Boltzmann અચળાંક. · SI: KE : J · કોઈ પણ આદર્શ ગેસ માટે સ્થાનાંતરી ભાગ.
એક મોલ ગેસની કુલ ગતિજ ઊર્જા ( Total KE per mole ): E = (f/2) R T
f = સ્વતંત્રતાની માત્રા (degrees of freedom); પરમાણ્વીય f=3, દ્વિપરમાણ્વીય f=5, ત્રિપરમાણ્વીય f=6 (સામાન્ય તાપમાને). · SI: E : J mol⁻¹ · સમાન વિભાજન પ્રમેય મુજબ.
સ્વતંત્રતાની માત્રા - પરમાણ્વીય ગેસ ( Monatomic ): f = 3 (કેવળ સ્થાનાંતરી)
x, y, z દિશામાં ત્રણ સ્થાનાંતરી. · SI: f : અમિત. · He, Ne, Ar, Xe વગેરે.
સ્વતંત્રતાની માત્રા - દ્વિપરમાણ્વીય ગેસ ( Diatomic, સામાન્ય તાપમાને ): f = 5 (3 સ્થાનાંતરી + 2 પરિભ્રમણ)
બંધન અક્ષ ફરતું પરિભ્રમણ નગણ્ય માનવામાં આવે. · SI: f : અમિત. · H₂, N₂, O₂, CO વગેરે (300 K ની આસપાસ).
સ્વતંત્રતાની માત્રા - બહુપરમાણ્વીય ગેસ ( Polyatomic, non-linear ): f = 6 (3 સ્થાનાંતરી + 3 પરિભ્રમણ) — સામાન્ય તાપમાને
રેખીય બહુપરમાણ્વીય માટે f=5. · SI: f : અમિત. · H₂O, CH₄ વગેરે (સામાન્ય તાપમાને).
સમાન વિભાજન પ્રમેય (Law of Equipartition of Energy): દરેક સ્વતંત્રતા માત્રા માટે સરાશ ઊર્જા = (1/2) k_B T પ્રતિ અણુ = (1/2) R T પ્રતિ મોલ
ટ્રાન્સલેશનલ, როტაციული და (სწორი პირობებში) ვიბრაციული თავისუფლების ხარისხებისთვის. · SI: ઊર્જા : J · ઉષ્માસંતુલનમાં સામાન્ય તાપમાને.
અચોકળ આયતન પર મોલર ઉષ્માધારિત્વ (Cv) — પરમાણ્વીય ગેસ: C_v = (3/2) R
f=3, C_v = f/2 × R. · SI: C_v : J mol⁻¹ K⁻¹ · પરમાણ્વીય આદર્શ ગેસ.
અચોકળ આયતન પર મોલર ઉષ્માધારિત્વ (Cv) — દ્વિપરમાણ્વીય ગેસ: C_v = (5/2) R
f=5, C_v = f/2 × R. · SI: C_v : J mol⁻¹ K⁻¹ · દ્વિપરમાણ્વીય આદર્શ ગેસ, સામાન્ય તાપમાને.
અચોકળ આયતન પર મોલર ઉષ્માધારિત્વ (Cv) — બહુપરમાણ્વીય ગેસ ( f=6 ): C_v = (6/2) R = 3 R
f=6 માટે. · SI: C_v : J mol⁻¹ K⁻¹ · બહુપરમાણ્વીય, સ્થિર તાપમાને.
અચાપક દબાણ પર મોલર ઉષ્માધારિત્વ (Cp): C_p = C_v + R
Mayer relation ; R = સાર્વત્રિક વાયુ અચળાંક. · SI: C_p : J mol⁻¹ K⁻¹ · કોઈ પણ આદર્શ ગેસ માટે.
Cp માટે ચોખ્ખા આંકડા ( Numerical Cp values ): પરમાણ્વીય : C_p = (5/2) R | દ્વિપરમાણ્વીય : C_p = (7/2) R | બહુપરમાણ્વીય : C_p = 4 R
ક્રમશઃ C_v + R મુજબ. · SI: C_p : J mol⁻¹ K⁻¹ · આદર્શ ગેસો માટે.
એડિયાબેટિક ગુણોત્તર ( Adiabatic Index / Gamma ): γ = C_p / C_v
γ = સરમાનુપાત; f=3 → γ=5/3≈1.67; f=5 → γ=7/5=1.4; f=6 → γ=4/3≈1.33. · SI: γ : અમિત. · આદર્શ ગેસો માટે.
એડિયાબેટિક પ્રક્રિયા સંબંધ ( Adiabatic Relation ): P V^γ = અચળ , T V^(γ-1) = અચળ , P^(1-γ) T^γ = અચળ
γ = C_p/C_v; આ ત્રણેય સમીકરણો એકબીજાથી મેળવી શકાય. · SI: પ્રત્યેક પક્ષ અચળ છે. · ધીમા દરે (quasi-static) એડિયાબેટિક પ્રક્રિયા, આદર્શ ગેસ.
સાપેક્ષ ઉષ્માધારિત્વ ( Specific Heat Capacity ): c_v = C_v / M_molar ; c_p = C_p / M_molar
M_molar = મોલર દળ; c = વિશિષ્ટ ઉષ્મા. · SI: c : J kg⁻¹ K⁻¹ · પદાર્થના દળ મુજબ જરૂર પડે.
ગેસનું ઊર્જાસ્તર / અન્તર્ગત ઊર્જા ( Internal Energy ): U = n C_v T = (f/2) n R T
f = સ્વતંત્રતા માત્રા; U એ અન્તર્ગત ઊર્જા. · SI: U : J · આદર્શ ગેસ; U માત્ર T પર આધારિત.
ધાર્ષિક ઊર્જા / ગતિજ ઊર્જા ( Kinetic Energy from motion ): KE = (1/2) m v² પ્રતિ અણુ
m = અણુ દળ, v = અણુની ગતિ. · SI: KE : J · સામાન્ય.
અવકાશીય દબાણ સૂત્ર ( Pressure in terms of density ): P = (1/3) ρ v_rms²
ρ = ગેસનું દ્રવ્યમાન ઘનતા (kg/m³). · SI: P : Pa · આદર્શ ગેસ માટે.
માધ્યમ ગતિ ( Mean Free Path ): λ = 1 / (√2 π d² n_v) = k_B T / (√2 π d² P)
d = અણુનો વ્યાસ, n_v = અણુ સંખ્યા ઘનતા (N/V), P = દબાણ. · SI: λ : m · ગોળાકાર અણુઓ અને નિયમિત અણુગતિજ ધારણા.
માધ્યમ મુક્ત પથ પરથી સરેરાશ અથડામણ આવૃત્તિ ( Collision Frequency ): Z = v_avg / λ
v_avg = સરાશ ગતિ, λ = માધ્યમ મુક્ત પથ. · SI: Z : s⁻¹ · આદર્શ ગેસ.
ગ્રાહામનો ફેલાવો નિયમ ( Graham's Law of Effusion/Diffusion ): r₁ / r₂ = √(M₂ / M₁) = √(ρ₂ / ρ₁)
r = ફેલાવો દર, M = મોલર દળ, ρ = ઘનતા. · SI: ર : અમિત ગુણોત્તર. · એકસમાન P, T પર બે ગેસોનો તુલનાત્મક ફેલાવો.
કિરણોત્સર્ગી દબાણ ( Radiation Pressure reference — નહિ ): N/A
અહીં લાગુ નથી. · SI: — · આ અધ્યાયનો વિષય નથી.
R અને k_B વચ્ચેનો સંબંધ: k_B = R / N_A
N_A = એવોગેડ્રો સંખ્યા (≈ 6.022 × 10²³ mol⁻¹). · SI: k_B : J K⁻¹ · સૌ આદર્શ ગેસ સંબંધોમાં.

🔗 સંબંધો

  • P V = n R T અને P V = (1/3) N m v_rms² => v_rms = √(3 P / ρ) પણ મેળવી શકાય, જ્યાં ρ = ઘનતા.
  • v_mp : v_avg : v_rms = √2 : √(8/π) : √3 — ત્રણેય ગતિઓ T^½ ના સમપ્રમાણ છે.
  • v_rms ∝ √T/M — ગેસની વર્ગમાધ્ય ગતિ તાપમાનના વર્ગમૂળના સમપ્રમાણ અને મોલર દળના વર્ગમૂળના વ્યસ્ત પ્રમાણમાં.
  • γ = C_p/C_v = (f+2)/f — સ્વતંત્રતા માત્રા f અને એડિયાબેટિક ઇન્ડેક્સ વચ્ચેનો સીધો સંબંધ.
  • C_p − C_v = R (Mayer relation) — દરેક આદર્શ ગેસ માટે સતત.
  • દ્વિપરમાણ્વીય ગેસ માટે T વધે ત્યારે કંપન સક્રિય થતાં f=5 → f=6→7 થાય અને γ ઘટે છે.
  • માધ્યમ મુક્ત પથ λ ∝ T/P — તાપમાન વધે તો λ વધે, દબાણ વધે તો λ ઘટે.

🎯 ટ્રિક્સ

v_rms : v_avg : v_mp = √3 : √(8/π) : √2 ≈ 1.225 : 1.128 : 1 — યાદ રાખવા: 'root-3, root-8-over-pi, root-2'.
f=3 → γ=5/3≈1.67; f=5 → γ=7/5=1.40; f=6 → γ=4/3≈1.33 — આ ત્રણેય મૂલ્ય NEET માટે સ્મરણીય.
C_p અને C_v મેળવવા: C_v = f/2 × R, આપમેળે C_p = C_v + R મુકો; તરત જ γ = (f+2)/f નો સૂત્ર સૂત્રસિદ્ધ થાય.
એડિયાબેટિક P-V દેખાવમાં V નો ઘાતાંક γ ≥ 1.4 હોય છે, તેથી isotherm કરતાં steep (તીવ્ર) હોય છે — આંકડાકીય સવાલમાં મદદરૂપ.
ગ્રાહામના નિયમમાં ગેસ A અને B ના ફેલાવોનો ગુણોત્તર √(M_B/M_A) થાય — 'ભારે ગેસ ધીમો', એ સ્મરણ રાખો.
વર્ગમાધ્ય ગતિનો ઉપયોગ કરીને KE = ½ m v_rms² = (3/2) k_B T — આ રસ્તે KE સીધું T સાથે જોડાય છે.
R ≈ 8.314 J mol⁻¹ K⁻¹, k_B ≈ 1.38 × 10⁻²³ J/K — આ બે સંખ્યાઓ સુચ્છ બાકી રાખો; 8.314 / 6.022×10²³ ≈ 1.38×10⁻²³ બરાબર થાય છે.

⚠️ ભૂલો

C_v ને ભુલથી C_p ની બદલે ગણી દેવું — સવાલમાં 'અચળ આયતન' કે 'અચળ દબાણ' ગણવું જરૂરી છે; C_p = C_v + R છે.
γ = C_v/C_p લખી દેવું — સાચું γ = C_p/C_v છે (હંમેશા 1 થી મોટું).
v_rms = √(R T / M) લખી દેવું — સાચું v_rms = √(3 R T / M) છે; 3 આવતા નહીં તે બહુ સામાન્ય ભુલ છે.
દ્વિપરમાણ્વીય ગેસમાં f = 4 લેવું — સામાન્ય તાપમાને f = 5 (3 સ્થાનાંતરી + 2 પરિભ્રમણ); f = 4 કોઈપણ પ્રમાણિત કેસમાં નથી.
કંપન સ્વતંત્રતા માત્રાને 1 ગણી લેવું — દરેક કંપન મોડ માટે ઊર્જા બે ભાગો (ગતિજ + સ્થિતિજ) હોય છે, તેથી ફરિયાદ f માં 2 ઉમેરાય.
આદર્શ ગેસ સમીકરણમાં T ને °C માં મૂકવું — હંમેશા K (Kelvin) માં વાપરો; T(K) = T(°C) + 273.15.
માધ્યમ મુક્ત પથ λ માં √2 ભુલી જવો — λ = 1/(√2 π d² n_v); √2 ન મૂકતાં જવાબ √2 વખોડો.
ગ્રાહામના નિયમમાં M₁ અને M₂ નો ક્રમ ઉલટાવવો — r₁/r₂ = √(M₂/M₁), એટલે ગેસ-1 નો દર ગેસ-2 કરતાં વધુ જો તે હળવો હોય.
એડિયાબેટિક પ્રક્રિયામાં P V = અચળ લખી દેવું — એડિયાબેટિક માટે P V^γ = અચળ; ઇસોથર્મલ P V = અચળ.
