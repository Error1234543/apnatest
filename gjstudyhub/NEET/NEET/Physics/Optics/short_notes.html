પ્રકાશશાસ્ત્ર (Optics) — ઝડપી મુહાવરા

🩺 NEET UG — Gujarati • Physics • Optics

📘 વ્યાખ્યાઓ

  • અવતલ દર્પણ (Concave mirror): અંદરની તરફ વળેલો પરવલયી અરીસો જે પ્રકાશને એક બિંદુએ કેન્દ્રિત કરે છે.
  • ઉત્તલ દર્પણ (Convex mirror): બહારની તરફ ઉબરાયેલો અરીસો જે પ્રકાશને અપસારી બનાવે છે.
  • વક્રીભવન (Refraction): પ્રકાશનું એક સમદૃશ્ય માધ્યમમાંથી બીજા માધ્યમમાં જતાં માર્ગબદ્ધ થવું.
  • સંપૂર્ણ આંતરિક પરાવર્તન (Total internal reflection): ઘન માધ્યમથી વિરળ માધ્યમમાં જતાં પ્રકાશનું પૂરું પરાવર્તન.
  • ક્રાંતિક ખૂણો (Critical angle): વક્રીભવન ખૂણો 90° થાય તેવો આપાત ખૂણો, જ્યાં sin C = 1/n.
  • લેન્સ (Lens): પારદર્શક માધ્યમનું સપાટ અથવા વક્ર પૃષ્ઠોવાળું રચનાત્મક ઘટક.
  • પ્રિઝમ (Prism): ત્રણ સપાટ પૃષ્ઠોવાળો પારદર્શક ઘટક જે પ્રકાશનું વિખેરણ કરે છે.

⚡ સૂત્રો

  • 1/f = 1/v + 1/u (દર્પણ સૂત્ર)
  • f = R/2 (દર્પણનું કેન્દ્રઅંતર-વક્રતાત્રિજ્યા સંબંધ)
  • g = -v/u (દર્પણ મોટવણ; ઋણ → ઉલટું પ્રતિબિંબ)
  • n = sin i / sin r (સ્નેલનો નિયમ)
  • n = c/v (વક્રીભવનાંકની વ્યાખ્યા; v = c/n)
  • 1/f = (μ-1)(1/R₁ - 1/R₂) (લેન્સમેકર સૂત્ર)
  • P = 1/f (લેન્સની ઘાત; f મીટરમાં, P ડાયોપ્ટરમાં)
  • 1/v - 1/u = 1/f (પાતળા લેન્સ સૂત્ર; ચિહ્ન પરંપરા મુજબ)
  • g = v/u (પાતળા લેન્સ મોટવણ)
  • 1/F = 1/f₁ + 1/f₂ (લેન્સની જોડી; P = P₁ + P₂)
  • n = sin[(A+δ_m)/2] / sin(A/2) (પ્રિઝમ; ન્યૂનતમ વિચલન δ_m)
  • ω = (μ_v - μ_r)/μ_y (પ્રિઝમનું વિખેરણ ક્ષમતા)
  • m = f_o/f_e (ટેલિસ્કોપનું કોણીય મોટવણ)
  • d = u + v, g = v/u (મિcroસ્કોપ માટે મૂળભૂત સંબંધ)
  • sin C = 1/n (ક્રાંતિક ખૂણો)

⭐ મુખ્ય તથ્યો

  • અવતલ દર્પણમાં વસ્તુ અનંત પર હોય તો પ્રતિબિંબ કેન્દ્ર F પર, વાસ્તવિક, સંક્ષિપ્ત બિંદુ-આકારનું.
  • ઉત્તલ દર્પણમાં પ્રતિબિંબ હંમેશા સીધું, સુદૃશ્ય અને સંક્ષિપ્ત હોય છે.
  • વસ્તુ F અને P વચ્ચે (અવતલ દર્પણ) → સુદૃશ્ય, સીધું, વર્ધિત પ્રતિબિંબ.
  • સપાટ દર્પણમાં મોટવણ સदैव 1 હોય છે; પ્રતિબિંબ સુદૃશ્ય અને ઉલટું હોય છે.
  • પાતળા લેન્સનો ઉપયોગ ઘન (converging) → ઉત્તલ લેન્સ; અપસારી (diverging) → અવતલ લેન્સ.
  • લેન્સની ઘાત ધન → ઉત્તલ (અભિસારી); ઘાત ઋણ → અવતલ (અપસારી).
  • આંખનું નજીક બિંદુ ≈ 25 cm (સામાન્ય વ્યક્તિ માટે).
  • પ્રિઝમમાં વાદળી પ્રકાશ લાલ કરતાં વધુ વળે છે; δ_v > δ_r.
  • ફાઇબર ઓપ્ટિક્સમાં પ્રકાશનું SIRT થઈને વહન થાય છે.
  • હ્યુજેન્સના સિદ્ધાંત મુજબ શૈક્ષણિક મુખ પરનું દરેક બિંદુ નવા ગૌણ તરંગમુખોનો સ્રોત છે.

⚠️ સામાન્ય ભૂલો

  • દર્પણ સૂત્ર 1/v + 1/u = 1/f છે, લેન્સ સૂત્ર 1/v - 1/u = 1/f — બંનેમાં ગુણાકાર ચિહ્ન ફરક છે.
  • મોટવણ g = -v/u (દર્પણ); g = v/u (લેન્સ) — ચિહ્ન ભૂલથી ગણવું.
  • લેન્સમેકર સૂત્રમાં R₁, R₂ નું ચિહ્ન યોગ્ય રીતે લેવું; ઉત્તલ લેન્સ માટે f ધન.
  • સંપૂર્ણ આંતરિક પરાવર્તન ત્યારે જ થાય જ્યારે પ્રકાશ ઘન→વિરળ માધ્યમમાં જાય.
  • v, u, f નું ચિહ્ન ગૌસિયન પરંપરા મુજબ લેવું; કેન્દ્રની આગળ ધન, પાછળ ઋણ.
  • પ્રિઝમમાં ન્યૂનતમ વિચલન δ_m ત્યારે જ થાય જ્યારે i = e અને r₁ = r₂.
  • બે લેન્સની જોડીમાં 1/F = 1/f₁ + 1/f₂, સીધું f₁ + f₂ નહીં.
  • વક્રીભવનાંક n એકમહીન છે; તે માધ્યમ-નિર્ભર પણ તરંગલંબાઈ-આધારિત હોય છે.
  • લેન્સને માધ્યમ બદલીએ તો તેનું વર્તન બદલાઈ શકે (પાણીમાં ઉત્તલ લેન્સ અપસારી બની શકે).

🔥 હાઈ-યીલ્ડ મુદ્દા

  • અવતલ દર્પણમાં વસ્તુ C પાર ન જાય તો પ્રતિબિંબ વાસ્તવિક-ઉલટું; C પાર જાય તો સુદૃશ્ય-સીધું.
  • સ્નેલનો નિયમ: n₁ sinθ₁ = n₂ sinθ₂ — પ્રત્યેક ગણતરીનો પાયો.
  • લેન્સ ઘાત P(డायోప్টার) = 1/f(m) — NEET માં ઘણી ગણતરીઓ આ પરથી.
  • નજીક બિંદુ 25 cm અને અનંત બિંદુ — આંખની રચનાના પ્રશ્નોમાં આવે છે.
  • દર્પણ અને લેન્સ બંને માટે ચિહ્ન પરંપરા એકસમાન: આપાત દિશામાં ધન, વિરુદ્ધમાં ઋણ.
  • વિખેરણ (dispersion): વાદળી ≥ લાલ; PRISM → મોટેરંગ સ્પેક્ટ્રમ.
  • સંપૂર્ણ આંતરિક પરાવર્તન → ફાઇબર ઓપ્ટિક્સ, હીરાની ચમક, દીવાલ પર પાણીના સપાટીનો દર્પણપણ.
  • બે લેન્સની જોડી: P_total = P₁ + P₂, f_eq = f₁f₂/(f₁+f₂).
  • અવતલ લેન્સ ક્યાંય વાસ્તવિક પ્રતિબિંબ બનાવતું નથી; હંમેશા સુદૃશ્ય-સંક્ષિપ્ત.
  • ટેલિસ્કોપ: લંબાઈ = f_o + f_e, મોટવણ = f_o/f_e; મિcroસ્કોપ: મોટવણ ≈ (L/f_o)(D/f_e).
