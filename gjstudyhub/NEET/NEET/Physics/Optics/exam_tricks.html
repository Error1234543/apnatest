પ્રકાશશાસ્ત્ર (Optics) — NEET UG નિષ્ણત ટ્રિક્સ

🎯 પરીક્ષા ટ્રિક્સ

પોવરની ચિહ્નવાળી ઓળખ (Power Sign Convention Shortcut): કન્વેક્સ લેન્સનું ફોકસ દૂરધિ ગણાય છે (+f), એટલે P = +ve; કન્કેવ લેન્સનું f આભાસી (−) → P = −ve. અરીસામાં ઉલટું: ઉત્તલ (convex) અરીસો +f, અંતર્ગોળ (concave) અરીસો −f. બહુવિકલ્પ પ્રશ્નમાં તરત સંભવિત જવાબ નિકાળવા ઉપયોગી.
જ્યારે લેન્સ/અરીસો મિશ્રિત પદ્ધતિ (combination) માં સમાન યાંત્રિક ચિહ્નવ્યવસ્થા ધરાવતો વિકલ્પ પસંદ કરવાનો હોય કે પછી P1+P2+… દ્વારા t=0 પર સમતુલ્ય ફોકસ શોધવાનો હોય.
દા.ત.: કન્વેક્સ લેન્સ (f=+20 cm, P=+5 D) અને કન્કેવ લેન્સ (f=−50 cm, P=−2 D) સંપર્કમાં હોય. t=0 પર Peq = +5 − 2 = +3 D → f_eq = 100/3 cm ≈ +33.3 cm. (વિકલ્પ B)
સમતલ અરીસા પર પરિભ્રમણ ટ્રિક: જો સમતલ અરીસો θ કોણથી ঘુરે, તો પરાવર્તિત કિરણ 2θ કોણથી घુમે. આથી વિચલન (deviation) δ = 180° − 2i, જ્યાં i અપતિ કોણ છે.
જ્યારે પ્રશ્નમાં અરીસાના પરિભ્રમણથી પરિણામી કિરણનો ખૂણો કે વિચલન પૂછવામાં આવે, ગણતરી કરતાં ઝડપી.
દા.ત.: અરીસો 10° પરિભ્રમિત થાય → પરાવર્તિત કિરણ 20° घුમે. જો અપતિ કિરણ સ્થિર હોય, તો નવો વિચલન δ' = 180° − 2(i ± 10°); તફાવત 20° નો હોય.
કૃત્રિમ પ્રકાશસ્રોત (virtual object) માટે અરીસા/લેન્સ સૂત્ર: જો v ઋણ હોય (કૃત્રિમ વસ્તુ), તો 1/v ઋણ મૂલ્ય લે; પરિણામે u અને f ના મૂલ્યોમાંથી સાચો ચિહ્ન પસંદ કરવા ઝડપી.
જ્યારે પ્રથમ પ્રણાલી (લેન્સ/અરીસો) બનતો પ્રતિબિંબ બીજી પ્રણાલી માટે 'વસ્તુ' બને અને તે પ્રણાલીની વાસ્તવિક બાજુએ હોય → virtual object. ચિહ્ન સીધું ઉડાડી શકાય.
દા.ત.: અંતર્ગોળ અરીસા આગળ કૃત્રિમ વસ્તુ u = −30 cm, f = −15 cm. 1/v = 1/f − 1/u = −1/15 − (−1/30) = −1/30 → v = −30 cm (વાસ્તવિક પ્રતિબિંબ અરીસાની આગળ).
પ્રિઝમનું ન્યૂનતમ વિચલન (Minimum Deviation): δm પર r1 = r2 = A/2 અને i = e. આથી μ = sin[(A+δm)/2] / sin(A/2). યાદ રાખો: 'રૅન્ડમ' કિસ્સામાં δ = i+e−A, પણ δm પર સંમિતિ મળે.
જ્યારે પ્રશ્ન 'Minimum deviation' પૂછતો હોય કે μ શોધવું હોય — A અને δm આપેલા હોય તો ચોક્કસ સૂત્ર લાગુ કરો; કોણો ગુમાવ્યા વિના.
દા.ત.: પ્રિઝમ A = 60°, δm = 40°. μ = sin(50°)/sin(30°) = 0.7660/0.5 ≈ 1.532. (અંદાજિત કાચ)
કુલ આંતરિક પરાવર્તન (TIR) માટે ક્રાંતિકોણનું વેગવિહિન સૂત્ર: sin θc = 1/μ (જ્યારે બે માધ્યમોમાંથી એક હવા/નિર્વાત હોય). ઊંચા μ → નાનો θc. દ્વિ-વિકલ્પ પ્રશ્નમાં μ1 > μ2 → ક્રાંતિકોણ માત્ર માધ્યમ 2 માટે બનશે.
જ્યારે TIR થાય છે કે નહીં તે નક્કી કરવાનું હોય, અથવા ક્રાંતિકોણ શોધવાનો હોય — વિકલ્પોમાં μ ના ક્રમ પ્રમાણે તરત નિકાલ કરી શકાય.
દા.ત.: પાણી (μ=1.33) → હવા: sin θc = 1/1.33 → θc ≈ 48.8°. જો પ્રકાશ પાણીમાંથી હવામાં જાય તો θ > θc → TIR; હવામાંથી પાણીમાં → TIR શક્ય નથી.
લેન્સમેકર્સનું સૂત્ર — ત્રિજ્યાચિહ્ન ટ્રિક (Radius Sign Trick): પ્રકાશ દિશામાં, સપાટીનો કેન્દ્રબિંદુ પ્રકાશની દિશામાં હોય તો R > 0; વિરુદ્ધ દિશામાં હોય તો R < 0. બેઉ બહારની તરફ વળેલી (બિ-કન્વેક્સ) માટે R1>0, R2<0 → 1/f > 0 (એકત્વકારી). બેઉ અંદર વળેલી (બિ-કન્કેવ) માટે R1<0, R2>0 → 1/f < 0 (વિખેરકારી).
જ્યારે લેન્સનો પ્રકાર (એકત્વકારી/વિખેરકારી) કાગળ વિના જ નક્કી કરવાનો હોય, અથવા μ અને ત્રિજ્યા આપેલી હોય તો f ની ગણતરી ઝડપી કરવી હોય.
દા.ત.: બિ-કન્વેક્સ લેન્સ: R1=+10 cm, R2=−10 cm, μ=1.5. 1/f=(0.5)(1/10 − 1/(−10))=(0.5)(0.2)=0.1 → f=+10 cm (એકત્વકારી).
આભાસી/વાસ્તવિક પ્રતિબિંબ ટ્રિક (Sign of v): અરીસા/લેન્સ સૂત્રમાં v > 0 → વાસ્તવિક (પ્રકાશની વિરુદ્ધ બાજુએ), v < 0 → આભાસી (પ્રકાશની જ બાજુએ). m = −v/u: m ઋણ = ઉલટું/વાસ્તવિક, m ધન = સીધું/આભાસી. ઝડપી નિષ્કર્ષ માટે તરત વાપરો.
જ્યારે પ્રશ્નમાં પ્રતિબિંબ પ્રકાર (વાસ્તવિક/આભાસી, સીધું/ઉલટું, મોટું/નાનું) પૂછ્યું હોય અને v, u કેળવી શકાય.
દા.ત.: અંતર્ગોળ અરીસો: f=−10 cm, u=−15 cm. 1/v = −1/10 − (−1/15) = −1/30 → v=−30 cm (આભાસી, u સાથે જ બાજુ). m=−v/u=−(−30)/(−15)=−2 → ઉલટું, 2× મોટું (અહીં v ઋણ છતાં m ઋણ — ચિહ્ન વ્યવસ્થા યાદ રાખો).
બે અરીસા વચ્ચે પ્રતિબિંબની સંખ્યા: n = 360/θ. જો 360/θ પૂર્ણાંક even હોય → n = (360/θ) − 1. જો odd હોય → n = 360/θ (પરંતુ અસમાન કોણ પર વસ્તુ મૂકી હોય તો પણ odd કિસ્સામાં −1 ઉમેરવો).
જ્યારે બે સમતલ અરીસાઓ θ કોણે મૂકેલા હોય અને પ્રતિબિંબ સંખ્યા પૂછતો પ્રશ્ન હોય — સૂત્ર તરત લાગુ કરો.
દા.ત.: θ = 60° → 360/60 = 6 (even) → n = 6 − 1 = 5 પ્રતિબિંબો. θ = 90° → 360/90 = 4 (even) → n = 3.
યાંગના દ્વિ-સ્લિટ પ્રયોગ — મેક્સિમા/મિનિમાનું સ્થળ: વાસ્તવિક મેક્સિમા mλ = d sin θ ≈ dy/D, મિનિમા (2m−1)λ/2 = dy/D. ફ્રિંજ વિડ્થ β = λD/d. જો λ બમણું → β બમણું; જો d અડધું → β બમણું.
જ્યારે પ્રશ્નમાં ફ્રિંજ વિડ્થ, ડાર્ક/લાઇટ બેન્ડનું સ્થાન, અથવા λ/d/D માં ફેરફારની અસર પૂછતો હોય — ગણતરી વગર સંબંધ સાથે જવાબ.
દા.ત.: β = λD/d. λ=600 nm, D=1 m, d=0.5 mm → β = 600×10⁻⁹ × 1 / 5×10⁻⁴ = 1.2 mm. જો λ બમણું → β=2.4 mm (તરત જવાબ).
એકલ-સ્લિટ ડિફ્રેક્શન — કેન્દ્રીય મેક્સિમાની પહોળાઈ: મધ્યમ ડાર્ક (પ્રથમ મિનિમા) a sin θ = λ. કેન્દ્રીય ઉજ્જવળ ભાગની કોણીય પહોળાઈ ≈ 2λ/a, રેખીય પહોળાઈ ≈ 2λD/a. λ વધે → કેન્દ્રીય મેક્સિમા પહોળું; a વધે → સંકુચિત.
જ્યારે પ્રશ્ન એકલ-સ્લિટ પેટર્નમાં કેન્દ્રીય મેક્સિમા/મિનિમાનો કોણ કે પહોળાઈ પૂછતો હોય — બે ગુણક યાદ રાખો.
દા.ત.: a = 0.1 mm, λ = 500 nm, D = 1 m. કેન્દ્રીય મેક્સિમા પહોળાઈ = 2λD/a = 2×5×10⁻⁷×1/(10⁻⁴) = 0.01 m = 1 cm. (પ્રથમ ડાર્ક 0.5 cm પર.)
બ્રૂસ્ટરનો નિયમ (Brewster's Law): ધ્રુવીભવન કોણ iB પર પરાવર્તિત અને અપવર્તિત કિરણો પરસ્પર લંબ હોય છે. tan iB = μ. આથી iB ને જાણીને μ તરત મળે, અને iB + r = 90° હોય છે.
જ્યારે પ્રશ્નમાં બ્રૂસ્ટર કોણ કે μ આપેલો હોય અને પરસ્પર સંબંધ પૂછતો હોય — iB + r = 90° તરત વાપરો.
દા.ત.: μ = √3 ≈ 1.732 → iB = arctan(1.732) = 60°. તપાસ: r = 90° − 60° = 30°; sin60/sin30 = (√3/2)/(1/2) = √3 = μ ✓.
અંતર્ગોળ અરીસાની વિશેષ સ્થિતિઓ (Special Object Positions): u = ∞ → v = f (વાસ્તવિક, બિંદુવત); u = 2f → v = 2f (એકસરખું, ઉલટું); u = f → v = ∞ (અનંત); f < u < 2f → v > 2f (મોટું, ઉલટું); u < f → v અૃણ, આભાસી, સીધું, મોટું (વર્ધક અરીસો).
જ્યારે વસ્તુનું સ્થાન આ સામાન્ય મૂલ્યો પૈકીનું હોય — સૂત્ર વગર તરત પ્રતિબિંબનો પ્રકાર, સ્થાન અને આકાર નક્કી કરવા.
દા.ત.: u = 2f = −20 cm (f = −10 cm). 1/v = −1/10 − (−1/20) = −1/20 → v = −20 cm. m = −v/u = −(−20)/(−20) = −1 → સમાન કદ, ઉલટું, વાસ્તવિક. (ચિત્ર દોર્યા વિના જવાબ.)
