વિદ્યુત પ્રવાહ (Current Electricity)

🩺 NEET UG — Gujarati • Physics • Current Electricity

વિદ્યુત પ્રવાહ (Electric Current)
જ્યારે વિદ્યુતભારની વ્યવસ્થિત ગતિ થાય છે ત્યારે વિદ્યુત પ્રવાહ ઉદ્ભવે છે.
ધાત્વતારોમાં મુક્ત ઇલેક્ટ્રૉનની ગતિથી પ્રવાહ સ્રોત મળે છે.
I = Q/t અથવા I = dq/dt (એમપીયર, A)
પ્રવાહ એ અદિશ રાશિ છે — દિશા હોવા છતાં સદિશ ગુણધર્મો ધરાવતો નથી.
📝 એમપીયર એ SI એકમ છે. વૈકલ્પિક એકમ: એબીએમપીયર (AB ampere).
વિદ્યુત પ્રવાહની ઘનતા (Current Density)
કોઈપણ ચોકઠાના અભેદી વિસ્તાર દીઠ પ્રવાહની માત્રાને પ્રવાહ ઘનતા કહે છે.
J = I/A (એકમ: A/m²)
પ્રવાહ (I)પ્રવાહ ઘનતા (J) → ચોકઠાના અભેદી વિસ્તાર સાથે સંબંધિત
વિદ્યુતક્ષેત્ર E લાગુ પડે ત્યારે J = n e v_d હોય છે.
v_d = ડ્રિફ્ટ વેગ (તરંગવેગ નહિ!) — સરેરાશ દિશાત્મક ઝડપ.
ડ્રિફ્ટ વેગ અને રಿલેટિવિટી
ઇલેક્ટ્રૉન અવરોધક (wire) માં યાદૃચ્છિક ગતિ કરે છે; વિદ્યુતક્ષેત્ર લાગુ પડતા સદિશ ઝડપ ઉમેરાય છે — આ ડ્રિફ્ટ વેગ v_d છે.
v_d = eEτ/m = μE
τ = મુક્ત વીત કાળ (Relaxation Time)
μ = ગતિશીલતા (Mobility), એકમ: m²/V·s
📝 v_d ખૂબ જ નાનું (~mm/s) હોય છે; વિદ્યુતક્ષેત્ર પ્રકાશવેગની ગતિએ ફેલાય છે.
ઓહ્મનો નિયમ (Ohm's Law)
સ્થિર તાપમાને ચાલકના બે સરઘાટ વચ્ચેનો વિભવ તફાવત V અને પ્રવાહ I વચ્ચેનો સંબંધ: V = IR
V = I × R (R = અવરોધ, ઓહ્મ Ω)
ઓહ્મનો નિયમ ઉષ્મા અને દબાણ સ્થિર રહે ત્યારે જ લાગુ પડે છે. સેમિકન્ડક્ટર, ડાયોડ, ટ્રાન્ઝિસ્ટર પર લાગુ નથી.
📝 અહોમિક (ohmic) વિરુદ્ધ અનહોમિક (non-ohmic) ઉપકરણોને ઓળખો.
અવરોધ (Resistance)
R = ρL/A
L = લંબાઈ, A = ક્રોસ-સેક્શનલ વિસ્તાર, ρ = વિશિષ્ટ અવરોધ (Resistivity)
અવરોધ તારની આકૃતિ પર આધાર રાખે છે; વિશિષ્ટ અવરોધ પદાર્થની પ્રકૃતિ પર.
ચાલકની લંબાઈ બમણી કરતાં અવરોધ બમણો; ત્રિજ્યા બમણી કરતાં અવરોધ ¼
📝 રેઝિસ્ટરનું ચિહ્ન: ખપુ (jagged line) અથવા આયત (rectangle).
વિશિષ્ટ અવરોધ (Resistivity / Specific Resistance)
ρ એ પદાર્થનો આંતરિક ગુણધર્મ છે; તાપમાન સાથે બદલાય છે.
ρ = m/(ne²τ) = ER/J
એકમ: Ω·m (ઓહ્મ-મીટર)
ધાતુઓમાં τ નું મહત્વ — તાપમાન વધે તો τ ઘટે, તેથી ρ વધે.
📝 અર્ધવાહકોમાં ρ તાપમાન વધવાથી ઘટે છે — વિરુદ્ધ વર્તણૂક!
વિદ્યુતવાહકતા (Conductance & Conductivity)
G = 1/R (એકમ: Sievert = S અથવા Ω⁻¹)
σ = 1/ρ = n e² τ / m (વિદ્યુતવાહકતા, S/m)
R વધારે →G ઓછી; ρ વધારે → σ ઓછું
તડકાતો ચાલક (Superconductor): T_c થી નીચે ρ = 0, R = 0.
📝 S = Siemens = Ω⁻¹ = mho
તાપમાનનું અવરોધ પર અસર
R_t = R_0(1 + αΔT) અથવા R₂ = R₁[1 + α(T₂ – T₁)]
α = અવરોધ તાપમાન ગુણાંક (Temperature Coefficient of Resistance), એકમ: K⁻¹
ધાતુઓ: α > 0 (તાપમાન ↑ → R ↑) | અર્ધવાહકો: α < 0 (તાપમાન ↑ → R ↓)
📝 અતિવાહકતા: કેટલાક પદાર્થો T_c (Critical Temperature) પર R = 0.
શ્રેણી જોડાણ (Series Combination)
R_s = R₁ + R₂ + R₃ + ... + R_n
શ્રેણીમાં: (1) સમાન પ્રવાહ, (2) વિભવ તફાવત વહેંચાયેલું
V = V₁ + V₂ + V₃ ; I = I₁ = I₂ = I₃
વધુ રેઝિસ્ટન્સ શ્રેણીમાં મૂકવાથી કુલ અવરોધ વધે છે.
📝 બલ્બ શ્રેણીમાં — એક ફાટયું તો બધા બંધ.
સમાંતર જોડાણ (Parallel Combination)
1/R_p = 1/R₁ + 1/R₂ + 1/R₃ + ... + 1/R_n
સમાંતરમાં: (1) સમાન વિભવ તફાવત, (2) પ્રવાહ વહેંચાયેલું
V = V₁ = V₂ = V₃ ; I = I₁ + I₂ + I₃
2 સમાંતર રેઝિસ્ટન્સ: R_p = R₁R₂/(R₁+R₂) — સરળ સૂત્ર!
📝 સમાંતર જોડાણમાં કુલ અવરોધ સૌથી નાના અવરોધ કરતાં પણ ઓછો.
કિરાહોફના નિયમો (Kirchhoff's Laws)
પ્રથમ નિયમ (KCL): જંકશન (node) પર આવતા પ્રવાહોનો સરવાળો = નીકળતા પ્રવાહોનો સરવાળો
Σ I_in = Σ I_out અથવા Σ I = 0
કિરાહોફનો પ્રથમ નિયમ ચાર્જ સંરક્ષણ પર આધારિત છે.
દ્વિતીય નિયમ (KVL): બંધ પરિપથમાં વિભવ તફાવતનો સરવાળો શૂન્ય
Σ V = 0 અથવા Σ IR = Σ EMF
KVL — એનર્જી સંરક્ષણ નિયમ પર આધારિત. દરેક બંધ માટે ધન/ઋણ ચિહ્ન નક્કી કરો.
📝 ચિહ્ન નિયમ: પ્રવાહની દિશામાં R×I ધન, EMF ધ્રુવ વિરુદ્ધ દિશામાં ઋણ.
વીટસ્ટોન બ્રિજ (Wheatstone Bridge)
સંતુલન અવસ્થા: galvanometer માં કોઈ પ્રવાહ ન ચાલે (I_g = 0)
R₁/R₂ = R₃/R₄ (અથવા R₁/R₃ = R₂/R₄)
વીટસ્ટોન બ્રિજ અજ્ઞાત અવરોધ માપવા માટે ઉપયોગી છે.
📝 સંતુલન શરત: P/Q = R/S — યાદ રાખો!
મીટર બ્રિજ (Meter Bridge)
ઓગસ્ટસ્ટીન બેરનું પ્રયોગોત્તર (Playfair's method) પર આધારિત.
R/X = l/(100 – l) અથવા R = X·l/(100 – l)
l = સંતુલન બિંદુનું S (સેમી) માં અંતર
મીટર બ્રિજ એક વીટસ્ટોન બ્રિજ જ છે — તાર લંબાઈ 100 cm છે.
📝 તડકાતો બ્રિજ (Null point): જ્યાં galvanometer શૂન્ય વિચલન બતાવે.
પોટેન્શિયોમીટર (Potentiometer)
પોટેન્શિયોમીટર એક પરિપથ છે જે EMF, વિભવ તફાવત અને આંતરિક અવરોધના માપન માટે ઉપયોગ થાય છે.
V ∝ l (સંતુલન લંબાઈ l પર)
k = V/l = ε/L (ગ્રેડિંગ અચળાંક, potential gradient)
પોટેન્શિયોમીટર અનંત અવરોધ ધરાવે છે — પ્રવાહ ખેંચતું નથી, તેથી સાચું માપન.
📝 गॅल्वेनોमीटर કરતાં પોટેન્શિયોમીટર વધુ ચોકસાઈપૂર્વક EMF માપે છે.
પોટેન્શિયોમીટરના ઉપયોગો
(1) બેટરીનું EMF માપવા:
ε₁/ε₂ = l₁/l₂
(2) આંતરિક અવરોધ r માપવા:
r = R(l₁ – l₂)/l₂ જ્યાં R = બાહ્ય અવરોધ
l₁ = ખુલ્લા સર્કિટ (EMF) પર સંતુલન લંબાઈ | l₂ = બંધ સર્કિટ (terminal V) પર.
📝 સંવેદનશીલતા વધારવા તાર લંબાવો અથવા shunt રેઝિસ્ટન્સ ઘટાડો.
EMF અને આંતરિક અવરોધ (Internal Resistance)
EMF (ε): કોષ દીઠ રાસાયણિક ઊર્જા → વિદ્યુત ઊર્જા
V = ε – Ir (બંધ પરિપથમાં terminal voltage)
I = ε/(R + r) ; V = IR = εR/(R+r)
r = 0 (આદર્શ કોષ) → V = ε. r વધે તો V ઘટે.
📝 આંતરિક અવરોધ એlectrolyte, electrode materials પર આધારિત છે.
કોષોનું સંયોજન (Combination of Cells)
શ્રેણી જોડાણ: n સમાન કોષો (ε, r) શ્રેણીમાં
ε_eq = nε ; r_eq = nr ; I = nε/(R + nr)
સમાંતર જોડાણ: n સમાન કોષો સમાંતરમાં
ε_eq = ε ; r_eq = r/n ; I = ε/(R + r/n)
શ્રેણી: R >> r હોય તો ફાયદો. સમાંતર: R << r હોય તો.
📝 વિરોધાભાસી જોડાણ (Opposite polarity): ε_eq = ε₁ – ε₂
જાઉલનું ઉષ્મા નિયમ (Joule's Heating Law)
H = I²Rt = VIt = V²t/R
H એ ઉષ્મા (જૂલ), I પ્રવાહ (એમપીયર), R અવરોધ (Ω), t સમય (s)
વધુ પ્રવાહ, વધુ અવરોધ → વધુ ઉષ્મા. આથી તાર ગરમ થાય છે.
📝 ફ્યુઝ વાયર: ઊંચા ρ, ઓછા ઓગળવા બિંદુ — અતિભારથી રક્ષણ.
વિદ્યુત શક્તિ (Electrical Power)
P = VI = I²R = V²/R
એકમ: વોટ (W) = J/s. 1 kW = 1000 W.
ઉર્જા: E = P × t (Wh અથવા kWh)
kWh = 1 યુનિટ બિજલી = 3.6 × 10⁶ J
📝 વોટ્સ = V × I → રેઝિસ્ટર: P = I²R → ઉષ્મા બને છે.
રેઝિસ્ટિવિટીનું શૂન્ય તાપમાન (T_c) અને અતિવાહકતા
અતિવાહક (Superconductor): ચોક્કસ તાપમાન T_c નીચે ρ = 0, R = 0.
T_c થી નીચે જતાં જ ρ તરત શૂન્ય થાય છે.
બેરિયમ-લેડ-કપર-ઓક્સાઈડ: T_c ≈ 125 K (ઉચ્ચ-તાપમાન અતિવાહક).
📝 MRI, particle accelerators માં અતિવાહકોનો ઉપયોગ.
રેઝિસ્ટરોની રંગ કોડ (Color Code)
ચાર-રંગ રેઝિસ્ટર: (1) પ્રથમ અંક, (2) દ્વિતીય અંક, (3) ગુણક, (4) સહનશીલતા
કાળો=0, બ્રાઉન=1, લાલ=2, નારંગી=3, પીળો=4, લાલ=5, વાદળી=6, બુંદલો=7, ધાતુ=8, સફેદ=9
📝 રંગ કોડ અનુસાર મૂલ્ય: બ્રાઉન-લાલ-લાલ = 12 × 10² Ω = 1.2 kΩ.
વાહકતાની તુલના: ધાતુ, અર્ધવાહક, વિદ્યુતવિચ્છેદ્ય
ધાતુ: ρ ~ 10⁻⁸ Ω·m ; તાપ ↑ → ρ ↑
અર્ધવાહક (સિલિકોન): ρ ~ 10³ Ω·m ; તાપ ↑ → ρ ↓
વિદ્યુતવિચ્છેદ્ય: ρ ~ 10² Ω·m (આયનીય વાહકતા)
અતિવાહક: ρ = 0 — સંપૂર્ણ વિના અવરોધ.
📝 વાહકતાનો ગુણોત્તર: θ (theta) ≈ 10²² (ધાતુ vs અર્ધવાહક).
વિદ્યુતક્ષેત્ર અને પ્રવાહ
વાહકની અંદર વિદ્યુતક્ષેત્ર E હોય છે, જે ડ્રિફ્ટ વેગ આપે છે.
E = ρJ (મাইકલ્સન સ્વરૂપ, Ohm's Law નું સૂક્ષ્મ સ્વરૂપ)
વાહકની સપાટી પર E સપાટીને લંબરૂપ હોય છે.
આદર્શ વાહકમાં E = 0 (સ્થિર અવસ્થામાં). આથી ચાલક અંદર F_net = 0.
