મૃતિકાના ગુણધર્મો (Properties of Bulk Matter) — સૂત્ર શિટ

🩺 NEET UG — Gujarati • Physics • Properties of Bulk Matter

⚡ સૂત્રો

અભિલંબ પ્રતિબળ (Normal Stress): σ = F / A
σ = પ્રતિબળ, F = લંબ બળ, A = ક્ષેત્રફળ · SI: પાસ્કલ (Pa) અથવા N/m² · સમાન રીતે વિતરિત લંબ બળ માટે
સ્પર્શીય પ્રતિબળ (Shear Stress): τ = F / A
τ = સ્પર્શીય પ્રતિબળ, F = સ્પર્શીય બળ, A = પૃષ્ઠફળ · SI: પાસ્કલ (Pa) અથવા N/m² · સ્પર્શીય બળ લાગે ત્યારે
અભિલંબ પ્રતિવિકૃતિ (Longitudinal Strain): ε = ΔL / L
ε = પ્રતિવિકૃતિ, ΔL = લંબાઈમાં ફેરફાર, L = મૂળ લંબાઈ · SI: મતલહીન (dimensionless) · અભિલંબ ખેંચાણ અથવા દબાણ માટે
અનુપ્રસ્થ પ્રતિવિકૃતિ (Lateral Strain): ε_t = Δd / d
ε_t = અનુપ્રસ્થ પ્રતિવિકૃતિ, Δd = વ્યાસમાં ફેરફાર, d = મૂળ વ્યાસ · SI: મતલહીન (dimensionless) · ખેંચાણ દરમિયાન ત્રિજ્યામાં થતા ફેરફાર માટે
કદ પ્રતિવિકૃતિ (Volumetric Strain): ε_v = ΔV / V
ε_v = કદ પ્રતિવિકૃતિ, ΔV = કદમાં ફેરફાર, V = મૂળ કદ · SI: મતલહીન (dimensionless) · દ્રવ્યના દબાણથી કદ ફેરફાર માટે
હૂકનો નિયમ (Hooke's Law): σ ∝ ε અથવા σ = Y · ε
σ = પ્રતિબળ, ε = પ્રતિવિકૃતિ, Y = યંગ ગુણાંક · SI: Pa (બંને ભાજકો) · સ્થિતિસ્થાપક સીમા (elastic limit) સુધી
યંગ ગુણાંક (Young's Modulus): Y = σ / ε = (F · L) / (A · ΔL)
Y = યંગ ગુણાંક, F = બળ, L = મૂળ લંબાઈ, A = ક્ષેત્રફળ, ΔL = લંબાઈમાં વધારો/ઘટાડો · SI: પાસ્કલ (Pa) અથવા N/m² · રેખીય સ્થિતિસ્થાપકતા દરમિયાન, લંબ પ્રતિબળ માટે
લાંબાઈમાં ફેરફાર (ધાર અને સિકોડા): ΔL = (F · L) / (A · Y)
ΔL = લંબાઈ ફેરફાર, F = લંબ બળ, L = મૂળ લંબાઈ, A = ક્ષેત્રફળ, Y = યંગ ગુણાંક · SI: મીટર (m) · સ્થિતિસ્થાપક સીમામાં રહે તેવું બળ
બલ્ક ગુણાંક (Bulk Modulus of Elasticity): K = -σ_v / ε_v = -P / (ΔV / V) = -(P · V) / ΔV
K = બલ્ક ગુણાંક, P = દ્રવચાપ (પ્રતિબળ), ΔV = કદ ફેરફાર, V = મૂળ કદ · SI: પાસ્કલ (Pa) અથવા N/m² · આયત્તિક દબાણ (uniform hydraulic pressure) માટે
કદ સંપીડનતા (Compressibility): β = 1 / K = ΔV / (P · V)
β = સંપીડનતા, K = બલ્ક ગુણાંક, P = દ્રવચાપ, ΔV = કદ ફેરફાર, V = મૂળ કદ · SI: Pa⁻¹ અથવા m²/N · દ્રવ અને સખત પદાર્થો માટે
શિયર મોડ્યુલસ / કાટખોલ ગુણાંક (Shear Modulus / Rigidity Modulus): η = τ / γ = (F / A) / (Δx / L) = (F · L) / (A · Δx)
η = શિયર મોડ્યુલસ, τ = સ્પર્શીય પ્રતિબળ, γ = કૂણ પ્રતિવિકૃતિ (shear strain), F = સ્પર્શીય બળ, A = ક્ષેત્રફળ, Δx = સ્પર્શીય સરણી, L = મૂળ લંબાઈ · SI: પાસ્કલ (Pa) અથવા N/m² · સ્પર્શીય બળ લાગતા પદાર્થો માટે
પુઆસનનો ગુણોત્તર (Poisson's Ratio): ν = - (Δd / d) / (ΔL / L) = - (અનુપ્રસ્થ પ્રતિવિકૃતિ) / (અભિલંબ પ્રતિવિકૃતિ)
ν = પુઆસનનો ગુણોત્તર, Δd/d = અનુપ્રસ્થ પ્રતિવિકૃતિ, ΔL/L = અભિલંબ પ્રતિવિકૃતિ · SI: મતલહીન (dimensionless) · એકઅક્ષીય ખેંચાણ અથવા દબાણ સ્થિતિ માટે; સામાન્ય મૂલ્ય 0–0.5
Y, K, η વચ્ચેનો સંબંધ (isotropic material): Y = 3K(1 - 2ν) અથવા Y = 2η(1 + ν)
Y = યંગ ગુણાંક, K = બલ્ક ગુણાંક, η = શિયર મોડ્યુલસ, ν = પુઆસન ગુણોત્તર · SI: Pa (બધા) · સમદિગ્ધર્મી (isotropic) સ્થિતિસ્થાપક પદાર્થો માટે
સ્થિતિસ્થાપક સ્થિતિજ ઊર્જા (Elastic Potential Energy) – સિકોડા/તાર: U = ½ F · ΔL = ½ σ · ε · (A · L) = ½ (Y · ε²) · (A · L)
U = સ્થિતિસ્થાપક ઊર્જા, F = બળ, ΔL = લંબાઈ ફેરફાર, σ = પ્રતિબળ, ε = પ્રતિવિકૃતિ, A = ક્ષેત્રફળ, L = મૂળ લંબાઈ · SI: જૂલ (J) · સ્થિતિસ્થાપક સીમામાં, હૂકના નિયમનું પાલન કરતું વિકૃતિ
એકમ કદ દીઠ સ્થિતિસ્થાપક ઊર્જા (Elastic Energy Density): u = U / (A·L) = ½ σ · ε = ½ Y · ε² = ½ σ² / Y
u = એકમ કદ ઊર્જા, σ = પ્રતિબળ, ε = પ્રતિવિકૃતિ, Y = યંગ ગુણાંક · SI: J/m³ અથવા Pa · સમાન પ્રતિવિકૃતિ ધરાવતા પદાર્થ માટે
સ્ટોકસનો નિયમ (Stokes' Law) – શ્યેષ્ઝવેગ બળ: F = 6 π η r v
F = સান્દ્રતા બળ (viscous drag), η = સાર્વત્રિક સંસૃતિ ગુણક (viscosity), r = ગોળાની ત્રિજ્યા, v = વેગ · SI: N (બળ) · સાદા ગોળાકાર પદાર્થ પર ધીમા વેગે (લેમિનર પ્રવાહ) ગતિ કરતો હોય ત્યારે
શ્યેષ્ઝવેગ (Terminal Velocity): v_t = (2 r² g (ρ_s - ρ_f)) / (9 η)
v_t = શ્યેષ્ઝવેગ, r = ગોળાની ત્રિજ્યા, g = ગુરુત્વાકર્ષણ પ્રવેગ, ρ_s = ઘન પદાર્થનો ઘનત્વ, ρ_f = પ્રવાહીનો ઘનત્વ, η = સાર્વત્રિક સંસૃતિ ગુણક · SI: m/s · ઘન ગોળો પ્રવાહીમાં સમાન વેગે ડૂબતો હોય ત્યારે (ત્રણેય બળોનું સંતુલન)
દ્રવ્યનું સંસૃતિ ગુણક (Coefficient of Viscosity): η = F / (A · dv/dx)
η = સંસૃતિ ગુણક, F = સ્પર્શીય બળ, A = સંપર્ક ક્ષેત્રફળ, dv/dx = વેગ પ્રવણતા (velocity gradient) · SI: Pa·s અથવા N·s/m² (એકમ: poise = 0.1 Pa·s) · સ્તરીય પ્રવાહ (laminar flow) માટે
પૃષ્ઠતણ (Surface Tension): T = F / l
T = પૃષ્ઠતણ, F = પૃષ્ઠપર દાબતું બળ, l = તે બળ લાગતી રેખાની લંબાઈ · SI: N/m · દ્રવના મુક્ત પૃષ્ઠ પર એકમ લંબાઈ દીઠ લાગતું બળ
પૃષ્ઠઊર્જા (Surface Energy): E = T · ΔA
E = પૃષ્ઠઊર્જા, T = પૃષ્ઠતણ, ΔA = પૃષ્ઠફળમાં વધારો · SI: જૂલ (J) · દ્રવના પૃષ્ઠફળ વધારવા માટે જરૂરી કાર્ય
બિંદુવાળા કંટાકાર દ્રવબિંદુ (Liquid Drop) માટે વધારાનું દબાણ: ΔP = 2T / R
ΔP = અતિરિક્ત દબાણ (internal excess pressure), T = પૃષ્ઠતણ, R = બિંદુની ત્રિજ્યા · SI: Pa · એક પૃષ્ઠ ધરાવતા દ્રવ બિંદુ માટે (હવામાં)
સાબુના ફપ્પા (Soap Bubble) માટે વધારાનું દબાણ: ΔP = 4T / R
ΔP = અતિરિક્ત દબાણ, T = પૃષ્ઠતણ, R = ફપ્પાની ત્રિજ્યા · SI: Pa · બે મુક્ત પૃષ્ઠ ધરાવતા સાબુના ફપ્પા માટે
વાયુકોષ (Air Bubble) માટે વધારાનું દબાણ: ΔP = 2T / R
ΔP = અતિરિક્ત દબાણ, T = પૃષ્ઠતણ, R = વાયુકોષની ત્રિજ્યા · SI: Pa · દ્રવની અંદર બનેલો એક પૃષ્ઠ ધરાવતો વાયુકોષ
કેપિલરી ઉન્નયન (Capillary Rise): h = (2T cosθ) / (r · ρ · g)
h = ઉન્નયન ઊંડાઈ, T = પૃષ્ઠતણ, θ = સંપર્ક કોણ, r = કેપિલરી નળાકારની અંદરની ત્રિજ્યા, ρ = પ્રવાહીનો ઘનત્વ, g = ગુરુત્વાકર્ષણ પ્રવેગ · SI: m · સૂક્ષ્મ નળાકાર (capillary tube) માં પ્રવાહીનું ઉન્નયન/અધોગતિ
સંપર્ક કોણ (Angle of Contact): cosθ = (Adhesive force / Cohesive force) અથવા સંતુલન સ્થિતિએ T_sg cosθ = T_sl + T_lg cosα
θ = સંપર્ક કોણ, T_sg = ઘન-વાયુ પૃષ્ઠતણ, T_sl = ઘન-દ્રવ પૃષ્ઠતણ, T_lg = દ્રવ-વાયુ પૃષ્ઠતણ · SI: કોણ (° અથવા rad) · ત્રિપૃષ્ઠતણ સંતુલન સ્થિતિમાં

🔗 સંબંધો

  • પ્રતિબળ (stress) અને પ્રતિવિકૃતિ (strain) સીધા સમપ્રમાણમાં હોય છે – હૂકનો નિયમ – સ્થિતિસ્થાપક સીમા સુધી.
  • યંગ ગુણાંક (Y), બલ્ક ગુણાંક (K), શિયર મોડ્યુલસ (η) અને પુઆસન ગુણોત્તર (ν) એકબીજા સાથે સંકળાયેલા છે: Y = 3K(1-2ν) અને Y = 2η(1+ν).
  • ઘન પદાર્થોનો યંગ ગુણાંક પ્રવાહીઓ અને વાયુઓ કરતાં ઘણો વધારે હોય છે, તેથી ઘન પદાર્થોનું આકૃતિ ફેરફાર માટે અવરોધ વધુ હોય છે.
  • પુઆસન ગુણોત્તર ν નું મૂલ્ય 0 થી 0.5 ની વચ્ચે હોય છે; 0.5 એ અસંપીડ્ય (incompressible) પદાર્થ માટે છે.
  • સ્થિતિસ્થાપક ઊર્જા ઘનતા u = ½σ·ε = ½Yε² = ½σ²/Y — ત્રણેય સમતુલ્ય રૂપો.
  • શ્યેષ્ઝવેગ v_t ∝ r² — મોટા કણોની શ્યેષ્ઝવેગ વધુ હોય છે; v_t ∝ (ρ_s - ρ_f) — ઘનપદાર્થ જંદ્ર પ્રવાહી કરતાં ભારે હોય તો જ ડૂબે.
  • સ્ટોકસ બળ F = 6π η r v → શ્યેષ્ઝવેગે ગુરુત્વાકર્ષણ બળ = સ્થિતિસ્થાપક ઉત್પલાયન બળ + સંસૃતિ બળ.
  • સાબુના ફપ્પામાં બે મુક્ત પૃષ્ઠ હોવાથી અતિરિક્ત દબાણ ΔP = 4T/R; બિંદુમાં એક પૃષ્ઠ હોવાથી ΔP = 2T/R.
  • કેપિલરી ઉન્નયન h ∝ T / (r ρ g); ત્રિજ્યા ઓછી હોય તેવી નળીમાં પ્રવાહી વધુ ઊંચકાય છે.
  • પૃષ્ઠતણનું એકમ N/m = J/m² છે — પૃષ્ઠતણ એ એકમ લંબાઈનું બળ અને એકમ ક્ષેત્રફળ દીઠ પૃષ્ઠઊર્જા બંને રૂપે અર્થબોધિત છે.
  • સંપર્ક કોણ θ < 90° હોય તો પ્રવાહી ભીંજવું ધનાત્મક (wetting); θ > 90° હોય તો ઋણ (non-wetting).
  • દ્રવચાપ વધતાં બલ્ક ગુણાંક K વધે છે; વાયુઓનો K પ્રવાહીઓ કરતાં ઘણો ઓછો હોય છે.

🎯 ટ્રિક્સ

F = k ΔL તરીકે સ્પ્રિંગની રીતે યાદ રાખો: k = YA/L; એટલે ΔL = FL/(YA). આ સૂત્ર યાદ રાખવા સરળ છે.
સ્ટોકસ બળ અને શ્યેષ્ઝવેગ: v_t = (2r²g/9η)(ρ_s - ρ_f) — r² હોવાથી ત્રિજ્યા બમણી કરીએ તો શ્યેષ્ઝવેગ 4 ગણો થાય.
ફપ્પા vs બિંદુ: ફપ્પાને '4T/R' (બે પૃષ્ઠ) અને બિંદુને '2T/R' (એક પૃષ્ઠ) — 4 અને 2 યાદ રાખો.
કેપિલરી સૂત્ર h = 2Tcosθ/(rρg): θ=0 (જલન પ્રવાહી-શેશમ) માટે h = 2T/(rρg); θ=90° માટે h = 0 (કોઈ ઉન્નયન નથી).
Y = 3K(1-2ν) → જો ν = 0.5 (અસંપીડ્ય) તો Y = 0; એટલે ν = 0.5 એ સંપૂર્ણ અસંપીડ્યતા દર્શાવે છે.
સ્થિતિસ્થાપક ઊર્જા U = ½ F ΔL (સ્પ્રિંગની ઊર્જા જેવું જ); F = YAΔL/L મૂકીને U = ½(YAΔL²/L) પણ મળે.

પુઆસન ગુણોત્તર ν = - (અનુપ્રસ્થ પ્રતિવિકૃતિ)/(અભિલંબ પ્રતિવિકૃતિ) — ઋમારા ચિહ્ન યાદ રાખવું જરૂરી છે જેથી ν ધનાત્મક મળે.
