EM Induction and AC — Exam Tricks

🩺 NEET UG — Gujarati • Physics • Electromagnetic Induction and Alternating Currents

🎯 પરીક્ષા ટ્રિક્સ

લેન્ઝનો નિયમ યાદ રાખવાનું સરળ સૂત્ર: "પરિણામ વિરુદ્ધ કારણની દિશામાં" — ફ્લક્સ વધે તો વિરોધી ચુંબકધ્રુવ, ઘટે તો આકર્ષક. ઉમેદવાર એક જ વાક્ય યાદ રાખી શકે છે.
દિશા પ્રશ્નો જ્યારે ચુંબકધ્રુવ/કરંટની દિશા પૂછાય અને વિકલ્પો ભ્રામક હોય.
દા.ત.: જો ચુંબકને સોલેનોઇડમાં દૂર ખેંચીએ તો ફ્લક્સ ઘટે; લેન્ઝ મુજબ સોલેનોઇડ એ દિશાએ અનુકૂળ કરશે → ધ્રુવો આકર્ષક. આથી કરંટની દિશા સામાન્ય રીતે પ્રતિબંધી બનશે.
આંશિક વિકલનો (partial derivatives) વગર, ફેરાડેના નિયમ માટે: "બિગ ફ્લક્સ તરફ ગમે તો વહન ઋણ, નાનો ફ્લક્સ તરફ ગમે તો વહન ધન" — આથી વિકલ્પો દૂર કરી શકાય.
ફેરાડેના નિયમ આધારિત પ્રશ્નમાં ક્ષણિક વોલ્ટેજનો સંકેત (sign) પૂછાય.
દા.ત.: સમય t₂ પર F(t) ઘટે છે → dФ/dt < 0 → EMF = −dФ/dt > 0. તેથી વિકલ્પ જે ઋણ સંકેત આપે તે હٹાવો.
ભ્રમણશીલ છड़ (rod) માં પ્રેરિત EMF: e = ½ B ω L². યાદ રાખવાનું સૂત્ર: ½ × B × ω × L². જ L બમણું કરીએ તો EMF ચાર ગણું.
સોલેનોઇડ અથવા ભ્રમણામાંથી પસાર થતી તારનો પ્રશ્ન જ્યાં B ⟂ ω થાય.
દા.ત.: B = 0.4 T, ω = 400 rad/s, L = 0.5 m → e = ½ × 0.4 × 400 × (0.5)² = 20 V. જ L = 1 m → e = 80 V (ચાર ગણું, ન કે બમણું).
સ્વયં પ્રેરકતા L ∝ N²A/l — N બમણું, L 4×; l બમણું, L ½. આથી ગણતરી વગર પણ સંબંધ શોધી શકાય.
પ્રશ્નમાં સોલેનોઇડની વિકૃતિ (જેમ N બમણું, લંબાઈ અડધી) પૂછાય.
દા.ત.: N → 2N, l → l/2, A → A: L_new ∝ (2N)²·A/(l/2) = 4N²·A·2/l = 8L. જવાબ 8×.
LCR શ્રેણી સર્કિટમાં φ નો સંકેત: X_L > X_C → પ્રવાહ વિલંબિત (inductive); X_C > X_L → પ્રવાહ અગ્રગામી (capacitive). resonance પર φ = 0.
φ /_power factor_ માં કોણનો સંકેત અને પ્રવાહ પ્રકાર પૂછાય.
દા.ત.: V_L = 80 V, V_C = 50 V, V_R = 60 V → X_L > X_C → પ્રવાહ વિલંબિત → cos φ = V_R/V_total = 60/√(60²+(80−50)²) = 60/67 ≈ 0.89 lagging.
resonance(f₀) પર: X_L = X_C → ઇમ્પિડન્સ Z = R, પ્રવાહ 최대, cos φ = 1. પ્રશ્નમાં "resonance" = "purely resistive" એક જ સમજો.
resonance પર પ્રશ્નો કે જેમ Z, I_max, power factor પૂછે.
દા.ત.: લક્ષણી આવૃત્તિ f₀ = 1/(2π√LC) → resonance પર પ્રવાહ I_max = V/R, power = V²/R, અને Q_factor = ω₀L/R.
transformerમાં V_s/V_p = N_s/N_p = I_p/I_s (આદર્શ). પૂછાતું સીધું વીજગણિત — N બદલાય તો V સમપ્રમાણ, I વિપરીત પ્રમાણ.
Step-up/step-down transformer ના પ્રશ્નો જ્યાં N, V, I માંથી કોઈ બે આપેલ હોય.
દા.ત.: N_p:N_s = 1:10 → V_s = 10 V_p, I_s = I_p/10. જો વિકલ્પોમાં V_s < V_p સાથે I_s > I_p હોય તે ખોટું છે (contradiction).
ACમાં V_rms = V₀/√2, I_rms = I₀/√2. √2 ≈ 1.4. V₀ = 141 V ≈ 100√2 → V_rms = 100 V — યાદ રાખો: 141 ≈ 100×√2.
RMS મૂલ્ય વીજગણિત વગર નક્કી કરવું હોય.
દા.ત.: V₀ = 282 V → V_rms ≈ 200 V (282/1.41 ≈ 200). વિકલ્પોમાં 200 V છે તો તરત ચકાસો.
Eddy current ના નુકસાન ઘટાડવા: લામિનેટેડ આયર્ન કores, પাতળી પાતળી શીટ. નોંધ: એકમાત્ર પ્રક્રિયા resistance વધારે + ફ્લક્સ ઘટાડે → I_eddy ∝ 1/ρ → high ρ materials નુકસાન ઓછું.
Eddy currents અને ઊર્જા loss ઘટાડવાના ઉपाय પૂછાય.
દા.ત.: Transformersમાં લામિનેશન ઉપયોગનો ઉદ્દેશ્ય: eddy current paths ના લંબાઈ વધારવી અને cross-section ઘટાડવું → I_eddy ↓ → I²R loss ↓.
Mutual inductance M = k√(L₁L₂), 0≤k≤1. k=1 એટલે complete coupling. જ k શોધવું હોય: M_max = √(L₁L₂) — આ upper limit યાદ રાખો.
M, k, L₁, L₂ માંથી કોઈ એક પૂછાય.
દા.ત.: L₁=4 H, L₂=9 H, M=3 H → k = M/√(L₁L₂) = 3/√36 = 3/6 = 0.5.
Inductor માં સંગ્રહિત ઊર્જા U = ½LI². Capacitor માં U = ½CV². જ L 4× અને I ½× → U unchanged (4×¼ = 1).
ઉર્જા ફેરફાર પ્રશ્નો જ્યાં L, I બદલાય.
દા.ત.: L → 2L, I → I/√2 → U' = ½·2L·(I²/2) = ½LI² = U → same. ઉર્જા અપરિવર્તિત.
LC oscillation ની આવૃત્તિ: f = 1/(2π√LC). જ C 4× → f halved. જ L 9× → f ⅓. Product LC ∝ 1/f² — inverse square relationship યાદ રાખો.
LC circuit frequency changes પ્રશ્નો.
દા.ત.: C → 4C: f' = f/2. L → L/4: f' = 2f. બંને: C→4C, L→L/4 → f' = f·(2)(½) = f.
Choke coil: high L, low R → acts as inductor, blocks AC but passes DC. ડીસી માટે R ખૂબ ઓછું →几乎 short circuit.
Choke coil ના કાર્ય અને DC vs AC behavior પૂછાય.
દા.ત.: DC: X_L = 0, choke just a wire → full current. AC: X_L = ωL, large → current limited. આથી fluorescent lampમાં choke AC limit કરે પણ DC pass થાય.
Power in AC circuit: P = VI cos φ = I²R. વિકલ્પોમાં જ P ≠ I²R હોય તો ખોટો — R સિવાય બીજા પર power dissipated થતી નથી.
Average power / real power પ્રશ્નો.
દા.ત.: Series LCR: V_total ≠ V_R + V_L + V_C (phasor sum). P = I_rms²·R only. જો કોઈ વિકલ્પ P = V_rms·I_rms without cos φ → wrong for reactive circuits.
Quality factor Q = ω₀L/R = 1/(ω₀RC). Higher Q → sharper resonance peak → better selectivity. Q ∝ 1/R → کم resistance = sharp peak.
Q-factor, resonance sharpness, selectivity પ્રશ્નો.
દા.ત.: જ R doubling → Q halves → resonance curve broadens (less sharp). જ L doubled → Q doubles → sharper peak.
