વિદ્યુતચુંબકીય પ્રેરણ અને વૈકલ્પિક પ્રવાહ

🩺 NEET UG — Gujarati • Physics • Electromagnetic Induction and Alternating Currents

વિદ્યુતચુંબકીય પ્રેરણ – પરિચય
જ્યારે કોઈ બંધ પરિભ્રમણક્ષેત્રમાંથી ચુંબકીય ફ્લક્સ બદલાય છે ત્યારે તેમાં વિદ્યુતચુંબકીય પ્રેરણ બળ ઉત્પન્ન થાય છે.
ફેરાડેના નિયમ મુજબ: પ્રેરિત EMF = -dΦ/dt (ચુંબકીય ફ્લક્સના ફેરફારની દર).
ε = -N(dΦ/dt)
📝 NEET Tip: Φ = BA cosθ એ સૂત્ર યાદ રાખો.
ચુંબકીય ફ્લક્સ
ચુંબકીય ફ્લક્સ એ બળરેખાઓની સંખ્યા છે જે કોઈ પૃષ્ઠમાંથી પસાર થાય છે.
Φ = B·A = BA cosθ
SI એકમ: વેબર (Wb). 1 Wb = 1 T·m².
ચુંબકીય ઇન્ડક્શન Bફ્લક્સ Φ સંબંધિત
ફેરાડેના પ્રથમ અને દ્વિતીય નિયમો
પ્રથમ નિયમ: જ્યારે પરિભ્રમણક્ષેત્રમાંથી ચુંબકીય ફ્લક્સ બદલાય છે ત્યારે EMF પ્રેરિત થાય છે.
દ્વિતીય નિયમ: પ્રેરિત EMF નું મૂલ્ય ફ્લક્સ ફેરફારના દરને સમપ્રમાણ છે.
ε ∝ dΦ/dt → ધ્યાન રાખો કે EMF ફ્લક્સ પર નહીં, ફ્લક્સ ફેરફાર દર પર આધારિત છે.
લેન્ઝનો નિયમ
પ્રેરિત પ્રવાહની દિશા એવી હોય છે કે તે ખુદ ઉત્પન્ન થતા ફ્લક્સ ફેરફારનો વિરોધ કરે.
ε = -dΦ/dt (ઋણ ચિહ્ન લેન્ઝના નિયમ દર્શાવે છે)
ઋણ ચિહ્ન એнерgetic સંરક્ષણના નિયમ પર આધારિત છે.
📝 Exam Alert: MCQ માં પ્રવાહની દિશા પૂછે તો લેન્ઝનો નિયમ યાદ રાખો.
વિદ્યુતચુંબકીય પ્રેરણ અને શક્તિ સંરક્ષણ
લેન્ઝનો નિયમ એ ઉર્જા સંરક્ષણ નિયમનું જ પ્રતિનિધિત્વ કરે છે.
જો પ્રેરિત પ્રવાહ વિરોધ ન કરે તો અનંત ઉર્જા ઉત્પન્ન થાય – જે અશક્ય છે.
લેન્ઝનો નિયમઉર્જા સંરક્ષણનો નિયમ
ગતિજ પ્રેરણ (Motional EMF)
જ્યારે પ્રવાહવાહક તાર ચુંબકીય ક્ષેત્રમાં ગતિ કરે છે ત્યારે EMF પ્રેરિત થાય છે.
ε = Blv (જ્યારે B, l, v પરસ્પર લંબરૂપ હોય)
l = તારની લંબાઈ, v = વેગ, B = ચુંબકીય ક્ષેત્ર.
આ અવસ્થામાં ફ્લક્સ ફેરફાર તાર દ્વારા ઘેરાતા ક્ષેત્રફળમાં થાય છે.
સ્વપ્રેરણ (Self-Induction)
જ્યારે સોલેનોઇડમાં પ્રવાહ બદલાય છે ત્યારે તેમાં જ પ્રેરિત EMF ઉત્પન્ન થાય છે.
Φ = LI (સ્વપ્રેરણ ગુણાંક L)
ε = -L(dI/dt)
L નું SI એકમ હેનરી (H) છે.
📝 સોલેનોઇડ માટે: L = μ₀n²Al
પરપ્રેરણ (Mutual Induction)
બે નજીક આવેલા સોલેનોઇડમાં, એકમાં પ્રવાહ બદલાવાથી બીજામાં EMF પ્રેરિત થાય છે.
Φ₂ = M I₁ → ε₂ = -M(dI₁/dt)
M = પરસ્પર પ્રેરણ ગુણાંક, એકમ = H.
પરપ્રેરણટ્રાન્સફોર્મર કામગીરી
સ્થિતિમાન ઉર્જા સંગ્રહ (Inductor)
U = ½ L I²
ઇન્ડક્ટરમાં ચુંબકીય ક્ષેત્ર સ્વરૂપે ઉર્જા સંગ્રહિત થાય છે.
આ ઉર્જા પ્રવાહ બંધ કરતી વખતે ઇન્ડક્ટરમાંથી મુક્ત થાય છે.
વૈકલ્પિક પ્રવાહ (AC) – પરિચય
જે પ્રવાહ નિયમિત અંતરાલે દિશા બદલે છે તેને AC કહે છે.
I = I₀ sin(ωt)
I₀ = શીર્ષ પ્રવાહ, ω = ਕੋણીય આવૃત્તિ.
AC વીજળી પૂરવઠો ઘરેલુ અને ઔદ્યોગિક ક્ષેત્રે વ્યાપકપણે વપરાય છે.
AC જનરેટર (Alternative Current Generator)
યાંત્રિક ઉર્જાને વિદ્યુત ઉર્જામાં બદલતું ઉપકરણ.
ε = NBAω sin(ωt)
SLIP rings અને બ્રશીઝ પ્રવાહને બહાર લાવે છે.
📝 DC જનરેટર અને AC જનરેટર વચ્ચેનો તફાવત યાદ રાખો.
રીઝિસ્ટરમાં AC
RI પોટન્શિયલ ડ્રોપ વોલ્ટેજ સાથે જ Phase માં હોય છે.
I = I₀ sin(ωt), V = V₀ sin(ωt)
રીઝિસ્ટરમાં પાવર ફેક્ટર = 1.
ઇન્ડક્ટરમાં AC
ઇન્ડક્ટરમાં પ્રવાહ વોલ્ટેજ કરતા π/2 પાછળ રહે છે.
X_L = ωL (ઇન્ડક્ટિવ રિએક્ટન્સ)
આવૃત્તિ વધે તો X_L વધે છે.
ઇન્ડક્ટરLagging current
કેપેસિટરમાં AC
કેપેસિટરમાં પ્રવાહ વોલ્ટેજ કરતા π/2 આગળ હોય છે.
X_C = 1/(ωC) (કેપેસિટિવ રિએક્ટન્સ)
આવૃત્તિ વધે તો X_C ઘટે છે.
📝 Lead current = C, Lag = L.
RLC શ્રેણી સર્કિટ
R, L, C શ્રેણીમાં જોડાયેલી હોય છે.
Z = √[R² + (X_L - X_C)²] (ઇમ્પીડન્સ)
V_rms = I_rms × Z.
tanφ = (X_L - X_C)/R
φ = વોલ્ટેજ અને પ્રવાહ વચ્ચેનો Phase કોણ.
રેઝોનન્સ (અનુનાદ)
જ્યારે X_L = X_C ત્યારે સર્કિટ રેઝોનન્સ પર હોય છે.
ω₀ = 1/√(LC)
રેઝોનન્સ પર Z = R (ન્યૂનતમ), પ્રવાહ મહત્તમ.
Quality factor Q = ω₀L/R.
📝 MCQ માં Often: resonance frequency formula.
ફેઝર ડાયાગ્રામ
વોલ્ટેજ અને પ્રવાહને સદિશ સ્વરૂપે દર્શાવવામાં આવે છે.
આર્ગાનમેટ્રિક રીતે Phase તફાવત સમજવામાં મદદરૂપ.
ફેઝર ડાયાગ્રામRLC સર્કિટ વિશ્લેષણ
AC પાવર અને પાવર ફેક્ટર
P = V_rms I_rms cosφ
cosφ = પાવર ફેક્ટર.
Pure R સર્કિટમાં P = VI, pure L/C માં P = 0.
📝 Power factor એકમહીીન હોવો જોઈએ.
ટ્રાન્સફોર્મર – પરિચય
AC વોલ્ટેજની ડિગ્રી બદલતું ઉપકરણ.
V_s/V_p = N_s/N_p = I_p/I_s
Step-up: V_s > V_p, Step-down: V_s < V_p.
ટ્રાન્સફોર્મર માત્ર AC માટે કામ કરે છે.
ટ્રાન્સફોર્મરના નુકસાનો
સંદર્ભ લોસ: સોલેનોઇડના તારના અવરોધને કારણે ઉષ્મા.
Eddy current loss: ચુંબકીય ક્ષેત્ર બદલાવાથી અંદરના ધાતુકણોમાં પ્રવાહ.
Flux leakage: બધું ચુંબકીય ફ્લક્સ સેકન્ડરી સોલેનોઇડ સુધી પહોંચતું નથી.
Hysteresis loss: કર્લ સોફ્ટ આયર્ન લાગુ પાડીને ઘટાડો.
Eddy Currents (એડી પ્રવાહો)
બદલાતા ચુંબકીય ક્ષેત્રમાં ધાતુના બ્લોકમાં લૂપ પ્રવાહો પ્રેરિત થાય છે.
ઉપયોગ: ઇન્ડક્શન ચુળા, ઇન્ડક્શન મોટર, ઇલેક્ટ્રિક બ્રેક્સ.
Eddy current ઘટાડવા લેમિનેટેડ કેર લાગુ કરવામાં આવે છે.
📝 NEET Important: Eddy currentsના ઉપયોગો અને નુકસાન.
સ્વપ્રેરણ અને પરપ્રેરણની તુલના
સ્વપ્રેરણ: એક જ સોલેનોઇડમાં પ્રવાહ ફેરફારથી પ્રેરણ.
પરપ્રેરણ: બે પાડોશી સોલેનોઇડ વચ્ચે પ્રેરણ.
સ્વપ્રેરણ Lએકમ H (हेनरी)
પરપ્રેરણ Mએકમ H (हेनरी)
પ્રેરક અને કેપેસિટરનો સરવાળો (LC oscillations)
LC સર્કિટમાં ઉર્જા એકવાર L માં અને એકવાર C માં સંગ્રહિત થાય છે.
ω = 1/√(LC)
આવર્તન આવૃત્તિ f = 1/(2π√LC).
📝 Lossless oscillation concept important.
વૈકલ્પિક પ્રવાહના માપદંડ
RMS મૂલ્ય: I_rms = I₀/√2.
Average મૂલ્ય શૂન્ય (પૂર્ણ ચક્રમાં).
AC મીટર RMS મૂલ્ય જ દર્શાવે છે.
V_rms = V₀/√2
સંક્ષિપ્ત સૂત્ર સંગ્રહ
EMF: ε = -N(dΦ/dt)
Motional EMF: ε = Blv
Self-inductance: ε = -L(dI/dt)
Mutual inductance: ε = -M(dI/dt)
Resonance: ω₀ = 1/√LC
Impedance: Z = √[R² + (ωL - 1/ωC)²]
Transformer: V_s/V_p = N_s/N_p
