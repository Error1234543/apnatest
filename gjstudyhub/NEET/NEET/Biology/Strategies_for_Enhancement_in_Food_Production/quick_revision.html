🧠 યાદ રાખો

આલ્ફા-અમીલેઝ (α-amylase) વાયુ ઉત્પન્ન કરે છે → બ્રેડમાં છિદ્રો.
હેપ્ટોસોમ (Haplosoe) = 7 સૂત્રરજ્જુવાળું દ્વિ-કોષકીય કેન્દ્ર (બંધ-અંડકોષ + કેન્દ્રિકા).
સોમાક્લોનલ વ્યત્ય (Somaclonal variation) = ટિશ્યૂ કલ્ચરમાં જનીનિક વિવિધતા.
ઇન્બ્રીડિંગથી હોમોઝાયગોસિટી વધે, પરંતુ ઇન્બ્રીડિંગ ડિપ્રેશન (inbreeding depression) પણ થાય.
એક્સોટિક રજેન્ડ્સ × ભારતીય રજેન્ડ્સ = હિમાલયન ગાય × જર્મન સાઈલિંગ = સહ્યાન ( Sahiwal × Holstein-Friesian ).
એન્જાયમિક ઓક્સિડેશન (Enzymatic browning) સેબ/આલુમાં → પોલીફેનોલિક ઓક્સિડેઝ.
મૅરિસ્ટમ કલ્ચર (Apex + Nucl.) → વિરામહીન અભિવૃદ્ધિ શૃંગ;
વિરામીન કલ્ચર (Basal) → જડ પાદપો.

✅ વન-લાઈનર્સ

પ્લાન્ટ બ્રીડિંગ : નવી જાતોમાં ચાહેલે ગુણો મેળવવાની પ્રક્રિયા છે.
ટોમેટો : Flavr Savr → anti-sense RNAથી pectinaseનું નિયંત્રણ.
સુગરકેન : Ucan1226 × Co422 → ઉર્ટી + ગળાં + ઉપજ.
મધુમક્ખી વ્યવસાય : એપિકલ્ચર; Apis indica vs Apis mellifera.
એપિકલ્ચરથી મધ + પરાગ + દીપો.
આકરિક વ્યવસ્થા : માછલીના સંગ્રહનો તારો.
માછલીની સંવર્ધન : અક્ષરસહ + ખારા પાણી + સમુદ્ર-માછલી.
ઓક્સોડ્રોમ + સિલિસિયમ : સિન્થેટિક હોર્મોન્સ.
સોમાક્લોનલ વ્યતિ : ટિશ્યૂ કલ્ચરમાં જનીનિક વિવિધતા.
વિરામી + અગ્રીય કલ્ચર : માત્ર મૃતકોષકેન્દ્રીમાંથી વૃદ્ધિ.
બાયોફોર્ટિફિકેશન : કષ્ટયુક્ત પોષકતત્વોનો ઉમેરો (Zn, Fe, Vitamin A).
એન્જાયમિક ઓક્સિડેશન : પોલીફેનોલિક ઓક્સિડેઝ → બ્રાઉનીંગ.
ઇન્બ્રીડિંગ : સંબંધી વચ્ચે પ્રજનન → હોમોઝાયગોસિટી વધારે.
આઉટબ્રીડિંગ : સંબંધિત ન હોય તેવા પ્રાણીઓ વચ્ચે.
ક્રોસબ્રીડિંગ : બે ભિન્ન પ્રજાતિઓ વચ્ચે.
હિમાલયન ગાય × જર્મન સાઈલિંગ → સહ્યાન.
એસીપી : એકકોષીય પ્રોટીન (સાયનોબેક્ટેરિયા, બદામ).
માથા-મચ્છી : મેરીકલ્ચર.
વિરામી કલ્ચર : શૂંખી વૃદ્ધિ.
ઠેકડો (Callus) : વિભાજીત કોષોનો ગુચ્છ.
સમાધાન : પૂર્ણાંગ પ્લાન્ટ.
જનીન ઇંજનિયરિંગ : વધારાના ગુણો.
