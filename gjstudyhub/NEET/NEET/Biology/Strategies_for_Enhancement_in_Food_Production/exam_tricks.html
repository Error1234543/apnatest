🎯 પરીક્ષા ટ્રિક્સ

MOET યોજનામાં વપરાતી હોર્મોન્સ સંબંધિત પ્રશ્નોમાં — 'M' નું અર્થ 'Multiple' (બહુગર્ભાશયીકરણ) અને 'E' નો ઉલ્લેખ 'Embryo' (ગર્ભસ્થાપન) થાય છે. પહેલા PMSG (લક્ષ્મી હોર્મોન) અને પછી FSH (ફોલિકલ પ્રોત્સાહક હોર્મોન) આપવામાં આવે છે. એક જ ફરિયાદ: 'PMSG → FSH' ક્રમ યાદ રાખો.
જ્યારે MOET પ્રક્રિયાના ક્રમ, વપરાતી હોર્મોન્સ અથવા ઘોડા/ગાયના પ્રજનન દરવારનો પ્રશ્ન આવે.
દા.ત.: MOETમાં ગર્ભસ્થાપન પહેલાં કઈ હોર્મોન વડે ઇંડાણ ઉત્પાદન વધારવામાં આવે છે? → PMSG (પશુચિકિત્સામાં લક્ષ્મીની ભૂમિકા યાદ રાખો).
આંતરવિષયક સંಕર (Interspecific hybridization)થી બનતા પ્રાણીઓમાં સર્વાઈવલ શક્તિ ઓછી અથવા બંધ્ય (sterile) હોય છે — મૂલ (Mule) એ ખચ્છર અને ગાંડાનું સંકર છે જે બંધ્ય છે. તેથી 'આંતરવિષયક સંકર = બંધ્યતા' એ નિયમ યાદ રાખો.
જ્યારે સંકરપ્રજનન (Hybridisation) વિષયક પ્રશ્નોમાં બંધ્ય પ્રાણીઓ અથવા યોગ્ય સંકર જોડી પૂછાય.
દા.ત.: કઈ જોડીનું સંકર બંધ્ય સંતતિ આપે છે? → ઘોડો × ગાંડું = મૂલ (Sterile).
એપિકલ્ચર (Apiculture)માં મધમાખીની ચાર જાતોમાંથી ફક્ત Apis mellifera (Italian strains) જ વ્યાવસાયિક મધઉત્પાદન માટે યોગ્ય ગણાય. અન્ય ત્રણ (Apis cerana, Apis dorsata, Apis florae) મધુપાલનમાં ઓછી યોગ્ય છે.
જ્યારે મધમાખીની જાતો અને મધઉત્પાદન ક્ષમતા વિષયક પ્રશ્ન આવે.
દા.ત.: કઈ મધમાખી જાત વ્યાવસાયિક મધઉત્પાદન માટે ઉપયોગી છે? → Apis mellifera (Italian strain).
એપિકલ્ચર (આંગળીથી 'F' = Farm/Fagara) યાદ કરવા માટે: 'F' અક્ષર = Italian bees (Fagara). ગુજરાતીમાં 'ફ' અક્ષરથી યાદ રાખો: ફોટોગ્રાફીમાં F = Fast = Italian bees.
જ્યારે Apis મેલિફેરા અને Fagara (Italian bee) વચ્ચેનો સંબંધ પૂછાય.
દા.ત.: Italian strains of honeybee એ કઈ જાત છે? → Apis mellifera (Fagara/Farm type bee).
કોષસંયોજન (Somatic hybridisation)માં પ્રોટોપ્લાસ્ટનું સંયોજન કરવા માટે કોષભિત્તિ દૂર કરવી પડે છે — તે માટે પેક્ਟિનેઝ (pectinase) અને સેલ્યુલેઝ (cellulase) એન્ઝાઇમો વપરાય છે. 'PeC' = Pectinase + Cellulase → Protoplast extraction.
જ્યારે પ્રોટોપ્લાસ્ટ નિષ્કર્ષણ અથવા સોમેટિક હાઈબ્રિડાઈઝેશન પ્રક્રિયા વિષયક પ્રશ્ન આવે.
દા.ત.: પ્રોટોપ્લાસ્ટ મેળવવા માટે કયા એન્ઝાઇમો વપરાય છે? → Pectinase + Cellulase.
પ્લાન્ટ બ્રેડિંગના યોગ્ય ક્રમને યાદ રાખવા માટે 'C-R-E-S-P-D' શબ્દપ્રયોગ વાપરો: Collection → Reproduction (selection) → Evaluation → Selection → Testing → Dissemination. ટૂંકમાં: 'સંગ્રહ → પસંદગી → મૂલ્યાંકન → સીડ પેરાડેન્ટ → ફેલાવો'.
જ્યારે પ્લાન્ટ બ્રેડિંગની યોજનાનો યોગ્ય ક્રમ પૂછાય.
દા.ત.: પ્લાન્ટ બ્રેડિંગની યોજનાનો પ્રથમ સોપાન કયો? → Characterisation (લક્ષણલક્ષણીકરણ / સંગ્રહ).
ઉચ્ચ પ્રોટીનવાળા સૂક્ષ્મજીવો (SCP) નામ દ્વારા યાદ રાખો: 'SC' = Single Cell, 'P' = Protein. સ્પાયરુલિના (Spirulina) SCPનો સૌથી સામાન્ય પ્રશ્ન છે. 'S' = Super food → Spirulina rich in protein.
જ્યારે SCP અથવા સ્પાયરુલિના વિષયક પ્રશ્ન આવે.
દા.ત.: કઈ સૂક્ષ્મજીવ SCPનો સરોત છે? → Spirulina (એકકોષીય પ્રોટીનમાં સમૃદ્ધ).
જનીનિક પ્રવેશ (Genetic engineering) દ્વારા કાંદા/ખાંડના ઝેરીવાયરસથી બચાવ માટે Bt cotton (Bacillus thuringiensis) ની યાદ રાખો. Bt = બેસિલસ → Cry પ્રોટીન → જંતુનાશક. 'Bt' શબ્દનો અર્થ 'Biological toxin' પણ કહી શકાય.
જ્યારે Bt cotton અથવા જનીનિક પ્રવેશ દ્વારા રોગપ્રતિકારક છોડ બનાવવા વિષયક પ્રશ્ન આવે.
દા.ત.: Bt cottonમાં Cry પ્રોટીન કયા ઉત્પાદનથી મળે છે? → Bacillus thuringiensis.
આંતરિક પ્રજનન (Inbreeding) નો નકારાત્મક પ્રભાવ 'inbreeding depression' છે. ડિપ્રેશન = ઘટાડો (કર્ષણ). યાદ રાખો: 'Inbreeding = Inferior offspring'.
જ્યારે પ્રજનન યોજનાઓના ફાયદા/નુકસાન વિષયક પ્રશ્ન આવે.
દા.ત.: આંતરિક પ્રજનનથી શું થાય છે? → Inbreeding depression (સંતતિની ફિટનેસ ઘટે છે).
બેક્ટેરિયલ મ્યુટેશન (Mutation breeding) માટે X-rays અને UV rays બંને વપરાય છે — પરંતુ કેમિકલ મ્યુટેજન્સમાં EMS (Ethyl methanesulfonate) અને NaN₃ (Sodium azide) નો ઉલ્લેખ સામાન્ય છે. 'EMS = Ethylated mutation'.
જ્યારે મ્યુટેશન બ્રેડિંગમાં વપરાતી ઊર્જા અથવા રાસાયણિક પદાર્થો વિષયક પ્રશ્ન આવે.
દા.ત.: કઈ રાસાયણિક પદાર્થો મ્યુટેજન તરીકે વપરાય છે? → EMS અને Sodium azide.
આઉટક્રોસિંગ (Outcrossing)માં સમાન જાતિના પરંતુ વિભિન્ન વ્યક્તિઓ વચ્ચે પ્રજનન કરવામાં આવે છે — આથી સંતતિમાં વધુ વૈવિધ્ય આવી શકે છે. યાદ રાખો: 'Out = બહાર, Same breed, Different individual'.
જ્યારે આઉટક્રોસિંગ અને આઉટબ્રીડિંગ વચ્ચેનો તફાવત પૂછાય.
દા.ત.: આઉટક્રોસિંગમાં કઈ જોડી વચ્ચે પ્રજનન કરવામાં આવે છે? → Same breed, different individuals.
હાપ્લોઈડ (Haploid)કોષો એકમાત્ર ગેમેટિક રંગસૂત્ર સંખ્યા ધરાવે છે — તે મુખ્યત્વે એન્ટરકલ્ચર (Anther culture) દ્વારા મેળવવામાં આવે છે. યાદ રાખો: 'Anther → Haploid' એકમત્રી સંબંધ.
જ્યારે હાપ્લોઈડ સંસ્કૃતિ અથવા એન્ટરકલ્ચર વિષયક પ્રશ્ન આવે.
દા.ત.: હાપ્લોઈડ છોડ મેળવવા માટે કઈ પદ્ધતિ વપરાય છે? → Anther culture (એન્ટરકલ્ચર).
પશુપાલનમાં ઘોડાની જાતોમાંથી 'મૂલ' (Mule) બંધ્ય છે — આ પ્રશ્નમાં સૌથી મોટી ટ્રિક: Mule = стерile = Infertile offspring. જો પ્રશ્નમાં 'બંધ્ય સંતતિ' શબ્દ જોવા મળે તો તરત જ Mule ઉત્તર મળી જાય.
જ્યારે પ્રજનન યોજનાઓ અથવા આંતરવિષયક સંકરથી બનતી બંધ્ય સંતતિ વિષયક પ્રશ્ન આવે.
દા.ત.: કયું પ્રાણી બંધ્ય સંતતિ છે? → Mule (Sterile hybrid of Horse × Donkey).
મધમાખીમાં રાણી, શ્રામિક (worker) અને નર (drone) — ત્રણ જાતિઓ. યાદ રાખો: 'Queen = રાણી (અંડજનેત્રી)', 'Worker = શ્રામિક (બંધિર), 'Drone = નર (અંડજનેત્રી નહિ)'. Drone એકમાત્ર નર છે જે અંડજનેત્રી નથી.
જ્યારે મધમાખી સમાજ અને તેના સભ્યો વિષયક પ્રશ્ન આવે.
દા.ત.: મધમાખી સમાજમાં કઈ જાતિ અંડજનેત્રી નથી? → Drone (નર માખી).
રક્તદાન પ્રણાલીમાં ABO રક્તસમૂહના યુગ્મબંધ (genotype-phenotype) સંબંધનું સરળ સૂત્ર: 'O = ii (homozygous recessive)', 'AB = I^A I^B (codominant)'. યાદ રાખો: 'O is Universal Donor, AB is Universal Recipient.'
જ્યારે RBC પ્રજનન અથવા ABO સમૂહ વિષયક પ્રશ્ન આવે (જોકે આ ઉન્નતિકરણ પ્રકરણ સાથે સંકળાયેલું નથી પરંતુ NEET પેટર્નમાં ઉલ્લેખ મળી શકે).
દા.ત.: કયું રક્તસમૂહ સાર્વત્રિક દાતા (Universal donor) છે? → O group (ii genotype).
