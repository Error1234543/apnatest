🎯 પરીક્ષા ટ્રિક્સ

જ્યારે પ્રશ્નમાં 'વરસાદ/માછલીના મૃત્યુ' અને 'ડુંગળી વાસ્તવિક કચરો (Raw sewage)' એકસાથે હોય, ત્યારે જવાબ લગભગ હંમેશા 'બાયોકેમિકલ ઓક્સિજન ડિમાન્ડ (BOD)' ઉંચકાઈ હોવાનો હોય છે. BOD ↑ = પાણીમાં ઓગળેલો ઓક્સિજન ↓ = પ્રાણીઓનું મૃત્યુ.
જળ પ્રદૂષણ (Water Pollution) ની સમસ્યાઓમાં, ખાસ કરીને Eutrophication/BOD વાળા પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: પ્રદૂષિત નદીમાં માછલીઓનું જથ્થાબંધ મૃત્યુ શા માટે થાય? → જવાબ: ઓગળેલા ઓક્સિજનનો અભાવ (અને તદનુસાર BOD વધારો).
ઓઝોન સ્તરના ક્ષય માટેનું હંમેશાનું જવાબ: 'CFCs (ક્લોરોફ્લોરોકાર્બન)'. જ્યારે પણ પ્રશ્નમાં સ્ટ્રેટોસ્ફિયર/ઓઝોન છિદ્ર/સૂર્યપ્રકાશનું UV-B કિરણો વધવાનું હોય, ત્યારે CFCs સિવાય બીજો વિકલ્પ ગેરંટી ગિમેટ છે.
ઓઝોન સ્તર ક્ષય (Ozone Layer Depletion) સંબંધિત દરેક પ્રશ્નમાં.
દા.ત.: પ્રશ્ન: ઓઝોન સ્તરમાં થતો ઘટાડો મુખ્યત્વે કોના કારણે થાય છે? → જવાબ: CFCs.
ઉષ્મીય પ્રદૂષણ (Thermal Pollution) માટે એકમંત્ર: 'તાપમાન ↑ = OH⁻ ઓક્સિજન ઘટે'. જર્મનાઈટ્સ (Germicides/કૃમિનાશક) પાણીમાં નાખવાથી જલચર જીવોને નુકસાન થાય છે — આ હંમેશા ઉષ્મીય પ્રદૂષણના પ્રશ્નમાં સાચો વિકલ્પ હોય છે.
જળ પ્રદૂષણની જુદી જુદી પ્રકારો વચ્ચે ભેદ કરવાના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: થર્મલ પ્લેન્ટથી નિકળતા ગરમ પાણીના પ્રવાહથી કેવા પ્રકારનું પ્રદૂષણ થાય? → જવાબ: ઉષ્મીય પ્રદૂષણ.
ECOBLEED (Eco-friendly) ટેક્નોલોજી શોધવી હોય તો — વિકલ્પોમાં 'Biogas plant', 'Recycling', 'Composting' હોય તો તે સાચા જવાબો હોઈ શકે; 'Incineration' કેટલીકવાર સાચું પણ હોય છે. પરંતુ જ્યારે પ્રશ્નમાં 'કુદરતી રીતે વિઘટન પામતો' (biodegradable) શબ્દ હોય, ત્યારે કાગળ/કાપડ/વ્યર્થ ખાદ્ય પદાર્થો જેવા વિકલ્પો પસંદ કરો.
કચરા નિર્માણ અને Eco-friendly ઉકેલો સંબંધિત પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: નીચેનામાંથી કયા પ્રદૂષક ઝડપથી જૈવવિઘટિત (biodegrade) થઈ શકે? → જવાબ: કાગળ/કાપડ જેવા સામગ્રી, પ્લાસ્ટિક નહીં.
વાયુ પ્રદૂષણમાં 'PM2.5 અને PM10' — જો પ્રશ્નમાં હવામાન પ્રદૂષણના કારકો પૈકી 'કણાકાર પદાર્થો'નો પ્રશ્ન હોય, તો ધૂળ, સોપાન, અને સિગારેટ ધૂમ્રપાનના જવાબો સાચા હોય. 'પ્રદૂષક' પદાર્થોમાં: SO₂, NOₓ, CO, O₃, PM હંમેશા આવે છે.
વાયુ પ્રદૂષણ (Air Pollution) ના પ્રદૂષકોના પ્રકારો અને સ્રોતો શોધવાના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: નીચેનામાંથી કયો વાયુ પ્રદૂષક છે? → વિકલ્પો: SO₂, CO, NO₂, O₃ બધા સાચા; જો 'બધા' વિકલ્પ હોય તો પસંદ કરો.
BIOLOGICAL MAGNIFICATION: જ્યારે પ્રશ્નમાં કોઈ રાસાયણિક પદાર્થ 'ખોરાક શૃંખલા (food chain) માં ઉપર તરફ જતાં વધતો જાય' — તે સામગ્રી હંમેશા 'DDT' હોય છે. પરિણામ: શિкар ખાતર પક્ષીઓના અંડાના ખાલ પાતળા થઈ જવું (eggshell thinning).
જૈવિક સંચય (Biomagnification) સંબંધિત કોઈપણ પ્રશ્નમાં, ખાસ કરીને DDT/BHC.
દા.ત.: પ્રશ્ન: DDTનું ਜૈવસંચયણ (biomagnification) ખોરાક શૃંખલામાં શા માટે વધારો થાય છે? → જવાબ: DDT લીપિડમાં દ્રાવ્ય અને જૈવવિઘટનરહિત હોવાથી.
ગ્રીનહાઉસ ગેસનો 'સૌથી મોટો ફાળો': વૈશ્વિક উષ્ણતા (Global Warming) માં CO₂ નો સૌથી વધુ ફાળો છે. CH₄ અને N₂O પણ ગ્રીનહાઉસ ગેસ છે. જો પ્રશ્નમાં 'સૌથી વધુ પ્રમાણમાં' પૂછાય તો CO₂, જો 'સૌથી વધુ ઉષ્મા શોષક' (highest GWP) પૂછાય તો CH₄ અથવા N₂O — પરંતુ વૈશ્વિક તાપમાન વધારામાં CO₂ મુખ્ય છે.
ગ્રીનહાઉસ અસર અને વૈશ્વિક ઉષ્ણતા ગ્રીનહાઉસ ગેસોની ભૂમિકા પૂછતા પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: વૈશ્વિક ઉષ્ણતા માટે સૌથી વધુ દાયી ગેસ કઈ છે? → જવાબ: કાર્બન ડાયોક્સાઈડ (CO₂).
યુટ્રોફિકેશન (Eutrophication) માટેની ચাবી: 'PO₄³⁻ (ફૉસ્ફેટ) અને NO₃⁻ (નાઇટ્રેટ) > ફાઇટોપ્લેન્કટનની વૃદ્ધિ > ઓક્સિજન અભાવ > મૃત્યુ'. જો પ્રશ્નમાં 'પોષક તત્ત્વો' (nutrient pollution) નો ઉલ્લેખ હોય, તો જવાબ 'યુટ્રોફિકેશન' જ હોય છે.
જળ પ્રદૂષણ અને ઇકોસિસ્ટમ અસરો સંબંધિત પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: સેવેજ (raw sewage) અને ખાતર પ્રવાહથી તળાવમાં થતી ઘટના? → જવાબ: યુટ્રોફિકેશન.
પ્રદૂષણ નિયંત્રણ ઉપકરણો: 'Scrubber' → gaseous પ્રદૂષકો (SO₂, HCl) દૂર કરે છે; 'Electrostatic Precipitator (ESP)' → particulate matter (PM) દૂર કરે છે; 'Catalytic Converter' → વાહનોમાં NOₓ/CO/Hydrocarbons રૂપાંતરિત કરે છે. યાદ રાખો: Scrubber = સ્વિચ (gas), ESP = કણ (particulate), Catalytic = વાહન.
વાયુ પ્રદૂષણ નિયંત્રણ ઉપકરણો અને તેમનું કાર્યક્ષેત્ર પૂછતા પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: નીચેનામાંથી કયું ઉપકરણ ઉદ્યોગોમાંથી નીકળતા PM ને દૂર કરે છે? → જવાબ: Electrostatic Precipitator.
નોઇઝ પ્રદૂષણ (Noise Pollution) માટેની સંખ્યા: 85 dB (ડેસિબલ) થી વધુ શબ્દ પ્રદૂષક ગણાય. સામાન્ય વાતચીત ≈ 60 dB, ટ્રાફિક ≈ 80 dB, પ્લાન / જતા ≈ 140 dB (ઝડપી યાદ: ટ્રક > 80, પ્લાન ≈ 140). 120 dB થી વધુ તાત્કાલિક નુકસાન કરે.
શબ્દ પ્રદૂષણની તીવ્રતા અને તેની અસરો સંબંધિત પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: કયા ડેસિબલ સ્તરે આંતરિક કાનને ટકાઉ નુકસાન થાય છે? → જવાબ: 85 dB થી વધુ.
કાર્બન મોનોક્સાઇડ (CO) ની હાનિકારકતા: CO લાલ રક્તકણોમાં હીમેગ્લોબિન સાથે O₂ કરતા ~200 ગણી વધુ બંધન કરે છે (Carboxyhemoglobin બનાવે છે). એટલે O₂ વહન થતું અટકી જાય છે → હીપોક્સિયા. જ્યારે પણ પ્રશ્નમાં CO વિષબળ હોય, તો 'હીમેગ્લોબિન સાથે બંધન' જવાબ હોય છે.
વાયુ પ્રદૂષકો CO ની અસરો સંબંધિત પ્રશ્નમાં.
દા.ત.: પ્રશ્ન: CO શ્વાસોચ્છ્વાસના તંત્રને કેવી રીતે નુકસાન પહોંચાડે છે? → જવાબ: તે હીમેગ્લોબિન સાથે મજબૂત બંધન કરી O₂ વહન અટકાવે છે.
પેડ્રિયલ (Particulate) પ્રદૂષણને રોકવા માટેનું યાંત્રિક સાધન ESP છે. જો પ્રશ્નમાં 'વાયુ પ્રદૂષણને નિયંત્રિત કરવા' નું એકમાત્ર પ્રક્રિયા હોય — 'Wet Scrubber' = SO₂/acid gases, 'ESP' = dust/particulate, 'Cyclone' = large particles. ચોક્કસ પ્રદૂષક પ્રકાર મુજબ સાધન પસંદ કરો.
પ્રદૂષણ નિયંત્રણ તકનીકો (Control technologies) સંબંધિત પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: થર્મલ પ્લાન્ટમાંથી નીકળતા કણાકાર પ્રદૂષકો દૂર કરવા માટે કયું ઉપકરણ વપરાય? → જવાબ: Electrostatic Precipitator (ESP).
જૈવિક રંગસૂત્ર (Biological Indicator) યાદ રાખો: 'Lichen' એ H₂S/SO₂ પ્રદૂષણ માટેનું સંકેત (indicator) છે. જ્યાં SO₂ વધુ હોય ત્યાં Lichen બિલકુલ વધતું નથી. જો પ્રશ્નમાં 'હવા પ્રદૂષણ માટે જૈવ સંકેતક' પૂછાય, તો 'Lichen' જવાબ છે.
જૈવિક સંકેતકો (Biological Indicators) સંબંધિત પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: નીચેનામાંથી કયો સજીવ હવા પ્રદૂષણ (विशेष કરી SO₂) નો સંકેત આપે છે? → જવાબ: Lichen.
નિષ્ક્રિય તાપમાન (Inversion Temperature) + ધૂમ્રપ્રદૂષણ (Smog): Smog બે પ્રકારના — (1) London type (cold + fog + SO₂ + particles, early morning), (2) Los Angeles type (photochemical, warm + sunlight + NOₓ + VOCs). પ્રશ્નમાં 'photochemical smog' હોય તો O₃/ PAN સામેલ છે, 'London smog' હોય તો SO₂ + fog સામેલ છે.
ધૂમ્રપ્રદૂષણ (Smog) ના પ્રકાર અને તેના રાસાયણિક ઘટકો પૂછતા પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: Los Angeles type smog માં કયા રાસાયણિક ઘટકો સામેલ છે? → જવાબ: NOₓ + O₃ + PAN (Photochemical oxidants).
કાચ (Glass) અને હાઈડ્રોક્સાઇડ પ્રદૂષણ: જ્યારે પ્રશ્નમાં 'Solid Waste Management' ના પગલાં પૂછાય તો 5R નું ક્રમ યાદ રાખો: Reduce → Reuse → Recycle → Recover (energy) → Rot (compost). કચરાના ઉપચારણ માટે 'Composting' = organic waste, 'Incineration' = medical/infectious waste. જવાબમાં જ્યારે 'વૈકલ્પિક' (alternative) શબ્દ હોય તો composting/recycling પસંદ કરો.
ઘન કચરા વ್ಯવસ્થાપન (Solid Waste Management) ના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: ઘરેલું જૈવિક કચરાનું ઉપયોગી વ્યવસ્થાપન કયું છે? → જવાબ: કોમ્પોસ્ટિંગ (Composting).
