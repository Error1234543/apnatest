🎯 પરીક્ષા ટ્રિક્સ

મોબાઇલ તત્વોના ઘાટપણના લક્ષણો પહેલાં પુરાણા પર્ણો પર દેખાય છે, કારણ કે મોબાઇલ તત્વો વૃદ્ધ પર્ણોમાંથી નવા ભાગો તરફ ખસેડાઈ જાય છે. ઇમમોબાઇલ તત્વોના લક્ષણો નવા પર્ણો/શિખર પર દેખાય છે.
જ્યારે પ્રશ્નમાં ઘાટપણના લક્ષણો કયા પર્ણો પર દેખાય છે તે પૂછવામાં આવે.
દા.ત.: N, P, K, Mg મોબાઇલ છે → પુરાણા પર્ણો પર ઘાટપણ. Fe, Ca, S ઇમમોબાઇલ છે → નવા પર્ણો પર ઘાટપણ.
મૈક્રોન્યુટ્રિઅન્ટ્સની યાદ રાખવા માટે 'CN OP K Mg S' — આ ૮ તત્વો મૈક્રોન્યુટ્રિઅન્ટ્સ છે. બાકીના બધા માઇક્રોન્યુટ્રિઅન્ટ્સ છે.
જ્યારે પ્રશ્નમાં મૈક્રો/માઇક્રો તત્વોની ઓળખ કરાવવામાં આવે.
દા.ત.: C, N, O, P, K, Mg, S + Ca = ૮ મૈક્રોન્યુટ્રિઅન્ટ્સ. Fe, Mn, Zn, Cu, B, Mo, Cl = માઇક્રોન્યુટ્રિઅન્ટ્સ.
નાઇટ્રોજન સ્થાપન (Nitrogen fixation) માટે Mo એકમાત્ર માઇક્રોન્યુટ્રિઅન્ટ છે જે N₂→NH₃ પ્રક્રિયામાં સીધો સહાયક છે. પ્રશ્નમાં 'નાઇટ્રોજેનેઝ' સાથે સંકળાયેલ માઇક્રો તત્વ પૂછે તો Mo જ જવાબ.
જ્યારે નાઇટ્રોજેનેઝ એન્ઝાઇમ અથવા નાઇટ્રોજન સ્થાપનમાં ભૂમિકા ધરાવતા તત્વ વિશે પૂછવામાં આવે.
દા.ત.: નાઇટ્રોજેનેઝ (Nitrogenase) → Fe + Mo. નાઇટ્રેટ રિડક્ટેઝ → Mo. બંનેમાં Mo સામાન્ય છે.
લિગ્હિમોગ્લોબિન (Leghaemoglobin) હંમેશા રાઇઝોબિયમ-ફલકૂલ વચ્ચેના સંબંધમાં જ જોવા મળે છે. પ્રશ્નમાં 'લિગ્હિમોગ્લોબિનનું કાર્ય' પૂછે → O₂ ને વિષાળુ બનાવવું (scavenge) જેથી નાઇટ્રોજેનેઝને O₂ નું ઑક્સિડેશન ન થાય.
જ્યારે રાઇઝોબિયમ સહજીવન અથવા લિગ્હિમોગ્લોબિન વિશે પ્રશ્ન આવે.
દા.ત.: લિગ્હિમોગ્લોબિન O₂ ને બાંધી લે છે → નાઇટ્રોજેનેઝ (jo Fe-S ક્લસ્ટર ધરાવે છે) નું O₂થી નષ્ટ થવું અટકે છે.
B (બોરોન) એકમાત્ર એવું માઇક્રોન્યુટ્રિઅન્ટ છે જે કોષભિત્તિ (cell wall) ની રચના અને ગ્લાયકોપ્રોટીન સંશ્લેષણ માટે જવાબદાર છે. પ્રશ્નમાં 'કોષભિત્તિ' + 'માઇક્રો તત્વ' → B જ.
જ્યારે કોષભિત્તિ રચના અથવા પરાગરજ અંકુરણ સાથે સંકળાયેલ તત્વ પૂછવામાં આવે.
દા.ત.: Bની ઘાટપણ → પરાગરજ અંકુરણ બંધ, શિખર મૃત્યુ (apical death). B = પરાગરજ અંકુરણ + કોષભિત્તિ.
પાણીના વિભાજન (Photolysis of water) માટે Mn ની ભૂમિકા છે. પ્રશ્નમાં 'પ્રકાશસંશ્લેષણ + માઇક્રો તત્વ' → Mn. Cl પણ photolysis માટે જરૂરી છે પણ Mn પ્રાથમિક છે.
જ્યારે પ્રકાશસંશ્લેષણના પ્રકાશ-આધારિત પ્રક્રિયામાં ભૂમિકા ધરાવતા તત્વ વિશે પૂછવામાં આવે.
દા.ત.: Mn → PS-II માં પાણીના વિભાજન માટે જરૂરી. Cl → Cl- આયન તરીકે પણ photolysis માટે.
ઝિંક (Zn) → IAA (ઇન્ડોલ એસિટિક એસિડ / ઓક્સિન) ના સંશ્લેષણ માટે જરૂરી. પ્રશ્નમાં 'હોર્મોન સંશ્લેષણ + માઇક્રો તત્વ' → Zn.
જ્યારે વૃદ્ધિ હોર્મોન સંશ્લેષણ સાથે સંકળાયેલ માઇક્રો તત્વ પૂછવામાં આવે.
દા.ત.: Znની ઘાટપણ → 'રોસ્સેટ' (small leaf syndrome), ઓક્સિન સંશ્લેષણ બંધ.
હાઇડ્રોપોનિક્સ (Hydroponics) માં ઉપયોગી તત્વોની યાદ રાખવા માટે: 'Ca અને Fe સૌથી વધુ સમસ્યા ઊભી કરે છે' — Ca ઇમમોબાઇલ છે અને Fe ચીલેટ (chelate) સ્વરૂપે જ શોષાય છે.
જ્યારે હાઇડ્રોપોનિક્સ અથવા પોષક દ્રાવણમાં તત્વોની ઉપલબ્ધતા વિશે પ્રશ્ન આવે.
દા.ત.: Fe → Fe-EDTA ચીલેટ સ્વરૂપે. Ca → Ca(NO₃)₂ સ્વરૂપે. બંનેની ઉપલબ્ધતા pH પર આધારિત.
ઘાટપણના લક્ષણોનો ઝડપી સંબંધ: ઘાટપણ (Chlorosis) = પર્ણ પીળાં પડે (K, Mg, N, S, Fe, Mn, Zn, Cl). નેક્રોસિસ (Necrosis) = પર્ણના ભાગ મૃત થાય (N, K, Ca, Mg, Cu). યાદ રાખો: 'N, K, Ca, Mg → નેક્રોસિસ પણ કરે છે.'
જ્યારે ઘાટપણ vs નેક્રોસિસ કરતા તત્વોની ઓળખ કરાવવામાં આવે.
દા.ત.: Nની ઘાટપણ → બંને (chlorosis + necrosis). Kની ઘાટપણ → નેક્રોસિસ + કિનારી સુકાવી. Fe → માત્ર chlorosis (ઇમમોબાઇલ).
નાઇટ્રેટ રિડક્ટેઝ એન્ઝાઇમ → Mo અને Fe બંને જરૂરી. પ્રશ્નમાં 'NO₃⁻ → NO₂⁻' રૂપાંતરણ → Mo. 'NO₂⁻ → NH₃' રૂપાંતરણ → Fe (ફેરિડોક્સિન).
જ્યારે નાઇટ્રોજન ચક્રના ચોક્કસ પગલાંમાં ભૂમિકા ધરાવતા તત્વો વિશે પૂછવામાં આવે.
દા.ત.: NO₃⁻ → NO₂⁻ (નાઇટ્રેટ રિડક્ટેઝ) → Mo. NO₂⁻ → NH₃ (નાઇટ્રાઇટ રિડક્ટેઝ) → Fe (ફેરિડોક્સિન).
સલ્ફર (S) એકમાત્ર મૈક્રોન્યુટ્રિઅન્ટ છે જે પ્રોટીનમાં સલ્ફરયુક્ત અમિનો એસિડ (મેથિઓનિન, સિસ્ટીન) બનાવે છે. પ્રશ્નમાં 'પ્રોટીન + મૈક્રો તત્વ' → S.
જ્યારે પ્રોટીન રચના અથવા સલ્ફરયુક્ત સંયોજનો સાથે સંકળાયેલ તત્વ પૂછવામાં આવે.
દા.ત.: S → મેથિઓનિન, સિસ્ટીન (disulfide bond). Sની ઘાટપણ → પુરાણા પર્ણો પર chlorosis (મોબાઇલ).
Arnon અને Stewardના મૂળભૂત માપદંડ: તત્વ 'અનિવાર્ય' ત્યારે જ જ્યારે તે વિના સજીવ જીવનચક્ર પૂરું ન કરી શકે. આ માપદંડનો ઉપયોગ 'કયું તત્વ અનિવાર્ય છે?' પ્રશ્નમાં સીધો કરો.
જ્યારે તત્વની અનિવાર્યતા (essentiality) વિશે પ્રશ્ન આવે.
દા.ત.: Si — બેરિલ્સ (graminae) માટે અનિવાર્ય પણ બધા સજીવો માટે નહીં. Na — કેટલાક સજીવો માટે ઉપયોગી પણ અનિવાર્ય નહીં.
રિડક્સિંગ એજન્ટ તરીકે ફેરિડોક્સિન (Fe-S પ્રોટીન) કાર્ય કરે છે. પ્રશ્નમાં 'ઇલેક્ટ્રોન વહન + માઇક્રો તત્વ' → Fe.
જ્યારે પ્રકાશસંશ્લેષણ અથવા ચયાપચયમાં ઇલેક્ટ્રોન વહન સાથે સંકળાયેલ તત્વ પૂછવામાં આવે.
દા.ત.: ફેરિડોક્સિન (Fe) → PS-I માં ઇલેક્ટ્રોન વહન. નાઇટ્રાઇટ રિડક્ટેઝ પ્રક્રિયામાં પણ ફેરિડોક્સિન જરૂરી.
કોપર (Cu) → પ્લાસ્ટોસિયાનિન (plastocyanin) માં જરૂરી છે જે PS-I અને સાયટોક્રોમ f680 વચ્ચે ઇલેક્ટ્રોન વહન કરે છે. પ્રશ્નમાં 'ઇલેક્ટ્રોન વહન + Cu' → પ્લાસ્ટોસિયાનિન.
જ્યારે પ્રકાશસંશ્લેષણના ઇલેક્ટ્રોન વહન શૃંખલામાં ભૂમિકા ધરાવતા તત્વ વિશે પૂછવામાં આવે.
દા.ત.: Cu → પ્લાસ્ટોસિયાનિન. Fe → ફેરિડોક્સિન. બંને PS-I સાથે સંકળાયેલ.
વનસ્પતિમાં ખનિજ શોષણનો મુખ્ય રસ્તો: સક્રિય પરિવહન (active transport). નિષ્ક્રિય શોષણ (passive) પણ થાય છે પણ મુખ્ય રસ્તો સક્રિય છે. પ્રશ્નમાં 'ખનિજ શોષણની પ્રક્રિયા' → સક્રિય પરિવહન.
જ્યારે ખનિજ શોષણની પ્રક્રિયા અથવા તેના માટે ઊર્જાની જરૂરિયાત વિશે પૂછવામાં આવે.
દા.ત.: ખનિજ આયનો → સક્રિય પરિવહન દ્વારા મૂળ કક્ષમાં પ્રવેશે. ATP ખર્ચ થાય છે. સાંદ્રતા ગ્રેડિઅન્ટ વિરુદ્ધ.
