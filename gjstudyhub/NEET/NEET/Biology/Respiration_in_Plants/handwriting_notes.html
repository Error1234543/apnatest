પ્રાણીઓમાં શ્વસન

🩺 NEET UG — Gujarati • Biology • Respiration in Plants

પ્રાણીઓમાં શ્વસન — પ્રસ્તાવના
શ્વસન એ એક બાયોકેમિકલ પ્રક્રિયા છે જેમાં સંયોજિત કાર્બનિક પદાર્થો (જેમ કે ગ્લૂકોઝ) નું વિઘટન થાય છે અને ઊર્જા મુક્ત થાય છે.
કુલ શ્વસન પ્રક્રિયાનું સામાન્ય સમીકરણ: C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + ઊર્જા
⚡ યાદ રાખો: શ્વસન ખૂબ જ મહત્વની પ્રક્રિયા છે, કારણ કે તે કોષને ATP સ્વરૂપે ઉપયોગી ઊર્જા પૂરી પાડે છે.
📝 📌 NEET Tip: 'શ્વસન' એટલે હવાનો આદાન–પ્રદાન નહીં, પણ કોષીય મેટાબોલિક પ્રક્રિયા.
ગ્લાયકોલિસિસ (Glycolysis)
ગ્લાયકોલિસિસ પટળી પ્રક્રિયા છે, જેમાં ગ્લૂકોઝ (૬-કાર્બન) નું વિઘટન થઈ પાઇરુવેટ (૩-કાર્બન) બને છે.
આ પ્રક્રિયા કોષરસ (Cytoplasm) માં થાય છે; તેથી તેને 'અંતઃકોષરસીય શ્વસન' પણ કહે છે.
ગ્લાયકોલિસિસ દરમ્યાન ગ્લૂકોઝનું ઓક્સિડેશન થાય છે અને નિરપેક્ષ રીતે ૨ અણુ ATP અને ૨ અણુ NADH₂ ની લાભ થાય છે.
ગ્લૂકોઝ + 2 NAD⁺ + 2 ADP + 2 Pi → 2 પાઇરુવેટ + 2 NADH + 2 H⁺ + 2 ATP
ગ્લાયકોલિસિસ એ 'એરોબિક' પણ હોઈ શકે અને 'એનારોબિક' પણ હોઈ શકે છે.
🔑 મહત્વ: ગ્લાયકોલિસિસ એટલે શૂન્ય ઑક્સિજન વિના પણ થતી પ્રક્રિયા (એનારોબિક).
📝 📌 NEET Tip: ગ્લાયકોલિસિસમાં 'સબસ્ટ્રેટ લેવલ ફોસ્ફોરાઇલેશન' થાય છે.
પાઇરુવેટનું રૂપાંતરણ
એરોબિક સ્થિતિમાં પાઇરુવેટ માઇટોકોન્ડ્રિયામાં પ્રવેશે છે અને 'પાયરુવેટ ડિહાઇડ્રોજનેઝ' (PDH) કોમ્પ્લેક્સ દ્વારા એસિટાઇલ CoA માં રૂપાંતરિત થાય છે.
પાઇરુવેટ + CoA + NAD⁺ → એસિટાઇલ CoA + CO₂ + NADH + H⁺
આ પ્રક્રિયામાં પાઇરુવેટના ૩ કાર્બન પરમાણુમાંથી ૧ CO₂ મુક્ત થાય છે.
📝 📌 NEET Tip: PDH કોમ્પ્લેક્સ માઇટોકોન્ડ્રિયલ મેટ્રિક્સમાં વધુ સક્રિય હોય છે.
પાઇરુવેટ (કોષરસમાં)એસિટાઇલ CoA (મેટ્રિક્સમાં) → ક્રેબ્સ ચક્રમાં પ્રવેશ
ક્રેબ્સ ચક્ર (Krebs Cycle)
ક્રેબ્સ ચક્ર મેટ્રિક્સમાં થાય છે અને તેને 'સિટ્રિક એસિડ ચક્ર' અથવા 'TCA ચક્ર' પણ કહે છે.
એસિટાઇલ CoA (૨-કાર્બન) અને ઑક્સેલોએસિટેટ (૪-કાર્બન) મળી સાયટ્રેટ (૬-કાર્બન) બનાવે છે.
ચક્ર દરમ્યાન કુલ ૩ નાઇટ્રોજન યુક્ત સમસ્થાનિકો (α-ketoglutarate) દ્વારા ૨ CO₂ મુક્ત થાય છે.
એસિટાઇલ CoA + 3 NAD⁺ + FAD + GDP + Pᵢ + 2H₂O → 2 CO₂ + 3 NADH + 3 H⁺ + FADH₂ + CoA + GTP
ક્રેબ્સ ચક્ર એક વખત થતાં ૧ GTP (અથવા ૧ ATP), ૩ NADH, ૧ FADH₂ અને ૨ CO₂ મળે છે.
🔬 ઉલ્લેખનીય: ક્રેબ્સ ચક્રમાં 'સબસ્ટ્રેટ લેવલ ફોસ્ફોરાઇલેશન' થાય છે (Succinyl-CoA → Succinate).
📝 📌 NEET Tip: પ્રતિ એસિટાઇલ CoA એટલે શ્વસન ભાગાકાર 1.0 છે.
ઇલેક્ટ્રોન ટ્રાન્સપોર્ટ સિસ્ટમ (ETS)
ETS માઇટોકોન્ડ્રિયાની આંતરિક પટલ (Inner membrane) પર ગોઠવાયેલી પ્રોટીન જટિલતાઓ હોય છે.
NADH અને FADH₂ પરમાણુઓ ઇલેક્ટ્રોન ETS ને આપે છે.
સંકીર્ણ I → Coenzyme Q → સંકીર્ણ III → Cytochrome c → સંકીર્ણ IV → O₂ (અંતિમ ઇલેક્ટ્રોન સ્વીકારક).
ઇલેક્ટ્રોનના વહન સાથે H⁺ આયનો મેટ્રિક્સમાંથી અಂತઃપટલ અવકાશમાં પંપ થાય છે.
⚡ યાદ રાખો: ઑક્સિજન હંમેશા અંતિમ ઇલેક્ટ્રોન સ્વીકારક છે અને તે હાઇડ્રોજન સાથે મળી પાણી બનાવે છે.
½ O₂ + 2 H⁺ + 2 e⁻ → H₂O
📝 📌 NEET Tip: ETS નું બીજું નામ 'સાંસ્કૃતિક યાત્રા' નથી — ETS એ માત્ર ઇલેક્ટ્રોન વહન છે.
ઓક્સિડેટિવ ફોસ્ફોરાઇલેશન (Oxidative Phosphorylation)
ETS દ્વારા ઉત્પન્ન પ્રોટોન ગ્રેડિન્ટ H⁺ ને ATP સિન્થેઝ (Complex V) માંથી પસાર થતો કરે છે.
આ પ્રક્રિયાને 'ઍડેનોસિન ટ્રાયફોસ્ફેટ' (ATP) નું સંશ્લેષણ કહેવાય છે.
ADP + Pi + H⁺ ગ્રેડિન્ટ ઊર્જા → ATP + H₂O
પ્રતિ NADH માંથી લગભગ ૩ ATP અને પ્રતિ FADH₂ માંથી લગભગ ૨ ATP મળે છે.
🔑 મહત્વ: આ પ્રક્રિયા 'કેમિઓસ્મોસિસ' (Chemiosmosis) સિદ્ધાંત પર આધારિત છે.
📝 📌 NEET Tip: 1 ગ્લૂકોઝમાંથી કુલ ~30–32 ATP મળે છે (આધુનિક ગણતરી).
એનારોબિક શ્વસન (Anaerobic Respiration)
જ્યારે ઑક્સિજનની ઉપલબ્ધતા ન હોય ત્યારે ગ્લાયકોલિસિસ બાદ પાઇરુવેટનું વિઘટન વિવિધ રીતે થાય છે.
એનારોબિક શ્વસન દરમ્યાન મેળવેલી ઊર્જા એરોબિક શ્વસન કરતાં ઓછી હોય છે.
પાઇરુવેટ (ગ્લાયકોલિસિસ)એનારોબિક શ્વસન → ફર્મેન્ટેશન (Alcoholic / Lactic acid)
એલકોહોલિક ફર્મેન્ટેશન
પાઇરુવેટ → પાયરુવેટ ડિકાર્બોક્સીલેઝ દ્વારા એસિટેડિહાઇડ → એલકોહોલ ડિહાઇડ્રોજનેઝ દ્વારા ઇથેનોલ.
C₃H₄O₃ (પાઇરુવેટ) → CH₃CHO (એસિટેડિહાઇડ) + CO₂
CH₃CHO + NADH + H⁺ → C₂H₅OH (ઇથેનોલ) + NAD⁺
⚡ યાદ રાખો: બેકરીમાં રોટલી બનાવવા અને દહેજમાં મદદ કરવા માટે ઇથેનોલ ફર્મેન્ટેશન થાય છે.
📝 📌 NEET Tip: ફર્મેન્ટેશનમાં NAD⁺ પુનર્જન્મ થાય છે જે ગ્લાયકોલિસિસ ચાલુ રાખે છે.
લેક્ટિક એસિડ ફર્મેન્ટેશન
પાઇરુવેટ → લેક્ટેટ ડિહાઇડ્રોજનેઝ દ્વારા લેક્ટિક એસિડમાં રૂપાંતરિત થાય છે.
પાઇરુવેટ + NADH + H⁺ → લેક્ટેટ + NAD⁺
આ પ્રક્રિયા માંસપેશી કોષોમાં તીવ્ર વ્યાયામ સમયે થાય છે, જ્યારે ઑક્સિજનની ઘટતી હોય.
🔬 ઉલ્લેખનીય: લેક્ટિક એસિડ ધસારો પેશીઓમાં થાક લાવે છે.
📝 📌 NEET Tip: દૂધમાં દહીં બનાવવાની પ્રક્રિયા લેક્ટિક એસિડ બેક્ટેરિયા દ્વારા થાય છે.
પેન્ટોઝ ફોસ્ફેટ માર્ગ (Pentose Phosphate Pathway)
આ માર્ગ ગ્લાયકોલિસિસની બહારનો વૈકલ્પિક માર્ગ છે.
પ્રતિક્રિયા ગ્લૂકોઝ-૬-ફોસ્ફેટના ઑક્સિડેશન દ્વારા NADPH અને પેન્ટોઝ શર્કરા (રિબોઝ) નો ઉત્પાદન થાય છે.
ગ્લૂકોઝ-૬-ફોસ્ફેટ + NADP⁺ → રિબુલોઝ-૫-ફોસ્ફેટ + CO₂ + NADPH
NADPH લિપિડ, સ્ટેરોઇડ હોર્મોન્સ અને ન્યુક્લિક એસિડના સંશ્લેષણ માટે વપરાય છે.
🔑 મહત્વ: PPUPathway એ 'હેક્સોઝ મોનોફોસ્ફેટ શંકા' પણ કહેવાય છે.
📝 📌 NEET Tip: RBC માં આ માર્ગ ખૂબ સક્રિય હોય છે કારણ કે RBC માં માઇટોકોન્ડ્રિયા નથી.
શ્વસન ભાગાકાર (Respiratory Quotient — RQ)
શ્વસન ભાગાકાર એ ગળવામાં આવેલા CO₂ ના ઘનફળ અને ગ્રહણ કરેલા O₂ ના ઘનફળનો ગુણોત્તર છે.
RQ = ઉત્પન્ન થયેલો CO₂ / ગ્રહણ કરેલો O₂
કાર્બોહાઇડ્રેટ્સ માટે RQ ≈ ૧.૦ (ઉદા. ગ્લૂકોઝ).
ચરબી (Fats) માટે RQ ≈ ૦.૭, કારણ કે તેમના ઑક્સિડેશનમાં વધુ O₂ની જરૂર પડે છે.
પ્રોટીન માટે RQ ≈ ૦.૮ – ૦.૯ છે.
ગ્લૂકોઝ: C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O ⇒ RQ = 6/6 = 1.0
સ્ટિઅરિક એસિડ (ચરબી): C₁₈H₃₆O₂ + 26O₂ → 18CO₂ + 18H₂O ⇒ RQ = 18/26 ≈ 0.69
⚡ યાદ રાખો: RQ > 1 એટલે એનારોબિક શ્વસન ચાલુ છે (વધુ CO₂ ઉત્પન્ન થાય છે).
📝 📌 NEET Tip: તમાકૂના દાનાના અંકુરણમાં ચરબીનું શ્વસન થાય છે, તેથી RQ < 1.
એકંદરે — શ્વસન કોષમાં કેવી રીતે થાય છે?
એરોબિક શ્વસન: ગ્લાયકોલિસિસ → પાઇરુવેટ ઑક્સિડેશન → ક્રેબ્સ ચક્ર → ETS → ઑક્સિડેટિવ ફોસ્ફોરાઇલેશન.
એનારોબિક શ્વસન: ગ્લાયકોલિસિસ → ફર્મેન્ટેશન (ઇથેનોલ અથવા લેક્ટેટ).
ગ્લાયકોલિસિસ બધા કોષોમાં થાય છે; ક્રેબ્સ ચક્ર અને ETS માઇટોકોન્ડ્રિયામાં.
🔬 ઉલ્લેખનીય: શ્વસન એ 'કોષીય ઊર્જા નિર્માણ' નો મુખ્ય માર્ગ છે.
📝 📌 NEET Tip: શ્વસન અને પ્રકાશસંશ્લેષણ એ પરસ્પર વિરોધી પ્રક્રિયાઓ છે.
મહત્વનાં નામ અને વિદ્યાર્થીઓ માટે યાદ રાખવાનાં
ગ્લાયકોલિસિસ શોધી: ગોલ્ડબર્ગ અને એમ્બ્રોન.
ક્રેબ્સ ચક્ર શોધ્યું: હાન્સ ક્રેબ્સ (nobel prize).
કેમિઓસ્મોસિસ સિદ્ધાંત:彼得 Mitchell.
ગ્લાયકોલિસિસમાં પ્રથમ ઉત્પન્ન થયેલ ATP: પ્રોસેસ Nucleotide ૧,૩-બિસ્ફોસ્ફોગ્લિસરેટ.
