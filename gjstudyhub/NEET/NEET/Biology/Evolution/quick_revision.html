વિકાસ (Evolution) — ક્વિક રીવિઝન

🩺 NEET UG — Gujarati • Biology • Evolution

🧠 યાદ રાખો

જીવોમાં ફેરફાર એક પેઢીમાં થતો નથી; વંશાગત ફેરફારો સમય સાથે જમા થાય છે → તેને 'વિકાસ' કહીએ.
હેર્ટલ ઓગસ્ટ શૂઝનર (Haeckel) નો 'ઓન્ટોજેનીસીસ ફાઈલોજેનીસીસ ને રીક્ષ્ટી' નિયમ હવે સંપૂર્ણ સ્વીકૃત નથી, પણ ભ્રૂણિકા દલીલ તરીકે ઉપયોગી છે.
સમઘાટ અંગો (Homologous) → સામાન્ય મૂળ, વિભિન્ન કાર્ય → વિચલન વિકાસ; ઉદા: પક્ષીનું ડાડું અને માનવીનું હાથ.
સમવૃત્ત અંગો (Analogous) → વિભિન્ન મૂળ, સમાન કાર્ય → અભિસારી વિકાસ; ઉદા: પતંગનું ડાડું અને પક્ષીનું ડાડું.
હેર્ડી-વેઇનબર્ગ સંતુલન: જનીન આવૃત્તિ સ્થિર રહે તો જનસંખ્યા વિકાસિત થતી નથી.
જેનેટિક ડ્રિફ્ટ એ બે રીતે થાય: બોટલનેક અસર (જનસંખ્યા ઘટવાથી) અને ફાઉન્ડર અસર (જરા ગુણધર્મો ધરાવતી સહી બેસીને નવી વસ્તી શરૂ કરે).
ડાર્વિનના ફિન્ચ પક્ષીઓ (ગેલાપાગોસ ટાપુઓ) → સમય અને પર્યાવરણ અનુસાર ચોકઠિયા (Beak) પ્રકારોના વિચલનનો શ્રેષ્ઠ નમૂનો.
માઇલર-યુરી પ્રયોગ (1953): CH₄, NH₃, H₂, જળબાષ્પ → વિદ્યુત વિસ્ફોટ → એમિનો એસિડનું નિર્માણ → મૂળ જીવોની રાસાયણિક ઉત્પત્તિનો પ્રયોગાત્મક પુરાવો.
પ્રાચીનતમ ફોસ્સિલ: સાયানોબેક્ટેરિયા (સ્ટромેટોલાઇટ્સ, ~3.5 અરબ વર્ષ પહેલાં).
RNA વિશ્વ હાઇપોથિસીસ: આરએનએ એ પ્રારંભિક આनुવંશિક દ્રવ્ય તથા ઉત્પ્રેરક બંને હોઈ શક્યું.

⚡ ઝડપી સૂત્રો

હેર્ડી-વેઇનબર્ગ: p² + 2pq + q² = 1 (જનીન પ્રકાર આવૃત્તિ)
p + q = 1 (એલીલ આવૃત્તિ; p = પ્રબળ એલીલ આવૃત્તિ, q = પ્રચ્છન્ન એલીલ આવૃત્તિ)
વિકૃતિ દર μ = ફેરફાર પામેલા જનીનો / કુલ જનીનો (સામાન્ય રીતે ~10⁻⁵ થી 10⁻⁶)
આણ્વીય ઘડિયાળ: જનીનિક અંતર = એલીલિક તફાવત × વિકૃતિ દર (સાપેક્ષ સમય ગણતરી)

✅ વન-લાઈનર્સ

જીવોની ઉત્પત્તિ વિશેનો પ્રારંભિક સિદ્ધાંત: 'સ્વયંભૂ ઉત્પાદન' (Spontaneous Generation) → લુઇ પાસ્ચરએ તેને ખંડિત કર્યું.
ઓપેરિન-હેલડેન મત: પ્રારંભિક પૃથ્વીના બાષ્પરાશિ વાતાવરણમાં અજૈવિક અણુઓથી જૈવિક અણુઓ બન્યા.
ડાર્વિનના સમાધાનવાદ (Natural Selection) ના મુખ્ય તત્વો: વૃદ્ધિશીલ પ્રजनन, વ્યક્તિગત ભિન્નતા, અર્થપૂર્ણ ટકાઉપણું, વंશાગતતા.
પુરોહગ અંગો (Vestigial organs): કિરણ પાચક (Appendix), છિદ્રાશય, ગોળ અસ્થિ — વિકાસ દરમિયાન કાર્ય ગુમાવેલાં પણ યાદગાર રહેલાં અંગો.
ફોસ્સિલ તારીખ ગણતરી: યુરેનિયમ-સીસા પદ્ધતિ (~અરબો વર્ષ), કાર્બન-14 પદ્ધતિ (~50,000 વર્ષ સુધી).
આદિમ માનવ વંશાવળી: ઓસ્ટ્રેલોપિથેકસ → હોમો હેબિલિસ → હોમો એરેક્ટસ → હોમો સેપિયન્સ.
હોમો સેપિયન્સનું નિર્માણ આશરે 3.5 લાખ વર્ષ પહેલાં થયું; આધુનિક માણસ ~30,000 વર્ષ પહેલાં વિશ્વભરમાં ફેલાયો.
પેશીબિંદુ રોગ (Sickle-cell anaemia): હેટરોજાઇગોટ ફાયદો — મેલેરિયા પ્રતિકાર, એટલે HbS અને HbA બંને એલીલો વસાહતમાં ચાલુ રહે છે.
જનીન પ્રવાહ (Gene Flow): એક વસ્તીમાંથી બીજી વસ્તીમાં એલીલોનો આदान-પ્રદાન → વંશાગત ભિન્નતા ઊભી કરે.
અનિયાત્રિક જોડાણ (Non-random mating): સંબંધી જોડાણથી સમયૂપગમન વધે છે → આनुવંશિક બિમારીઓ જોડાણ વધારે.
હેટરોખ્રોની (Heterochrony): પૂર્વજની તુલનાએ પૂર્વજ પીઠના વિકાસ ગતિ બદલાવાથી નવી પ્રજાતિઓ.
અવિકસિત (Atavism): કેટલાક જનીનો પ્રચ્છન્ન રહીને પછીથી સક્રિય બનવાથી પૂર્વજી લક્ષણો દેખાય.
બાયોજેનેસિસ (Biogenesis) સિદ્ધાંત: 'જીવન માત્ર પહેલાંથી વિદ્યમાન જીવનમાંથી જ પેદા થાય છે.' — લુઇ પાસ્ચર.
આણ્વીય સ્તરે પુરાવો: સર્વજીવી હીમોગ્લોબિન અને સાયટોક્રોમ C નું સમાન બનાવટ સર્વ યુકેરીયોટ્સમાં સામાન્ય પૂર્વજનો પુરાવો છે.
ઉત્પ્રેરક RNA (Ribozyme): રાસાયણિક વિકાસમાં RNA એ આनुવંશિક માહિતી અને ઉત્પ્રેરક બંને હોઈ શકે તેવો વિચાર છે.
