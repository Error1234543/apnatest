🎯 પરીક્ષા ટ્રિક્સ

પુષ્પ આંકડા (Floral Formula) માં B = Zygomorphic, K = Calyx, C = Corolla, A = Androecium, G = Gynoecium. જ્યારે G ની ઉપર રેખા હોય તો Superior ovary, નીચે રેખા હોય તો Inferior ovary સીધી યાદ કરો.
પુષ્પનાં ગોઠવણી અને અંતસ્થ પૂંડ (Ovary position) સંબંધિત પ્રશ્નોમાં.
દા.ત.: Fabaceae: ⚥ K(5) C5 A(9)+1 G(1) → zygomorphic, superior ovary. બ્રેકેટમાં (5) = fused calyx.
Monochlamydeous = માત્ર એક વર્તુળ (અથવા both whorls present but identical). Liliaceae (વિષુવર્તુળી), Asphodelaceae — આ ફૂલોમાં Perianth એકસમાન થાય (Terrate). ટૂંકમાં: Monochlamydeous = Tepals (Perigon).
જ્યારે પ્રશ્નમાં પુષ્પ આવરણ (Perianth) વિશે પૂછે, કયા કુળ Monochlamydeous છે તે પસંદગીમાં.
દા.ત.: ଲିଲି (Lily) → Monocot, Tepals = 6, Perianth એકસમાન. Calyx અને Corolla વચ્ચે ભેદ નથી.
Placentation ટ્રિક: Axile = બહુકોષક (multilocular) + મધ્યમાં; Parietal = એક કોષક (unilocular) + સીમા પર; Free central = unilocular but middle में (after septa disappear); Basal = બીજ એક, નીચે; Marginal = એક જ કોષક, કાંઠે (Fabaceae).
અંડકોષ (Ovule) ની ગોઠવણી પૂછતો પ્રશ્ન, ખાસ કરીને Fabaceae vs Liliaceae અલગ કરવા.
દા.ત.: Fabaceae → Marginal placentation. Peas (મटर) માં એક જ રેખા પર બીજ ગોઠવાય. Liliaceae → Axile.
Phyllotaxy ટ્રિક: Alternate → એક પत्ती/ગાંઠ (single leaf per node) + spirally arranged. Opposite → બે પत्ती/ગાંઠ (pair) + decussate. Whorled → 3+ પत्ती/ગાંઠ. Oxstead (Opposite superposed) → pairs at same level (Cassia).
પર્વચ્છેદ (Leaf arrangement) શોધતો પ્રશ્ન. Cassia vs Gardenia અલગ કરવા.
દા.ત.: Calotropis → Opposite (decussate) phyllotaxy. Mango (આમ) → Alternate.
Root modifications: Tuberous root = સોજો (swollen storage), નવું છોડ નહિ બنے. Stilt root =支撑 (prop support), Sugarcane, Maize. Pneumatophore =呼吸 roots upward, Rhizophora (mangrove). Veiny root (Prop root) = banyan.
મૂળભેદ (Root modification) પ્રશ્ન. દરેક modification નો વಾસ્તવિક ઉદાહરણ જોડીએ.
દા.ત.: Pneumatophore → Rhizophora (symbiont plant in mangrove). Tuber → sweet potato (not stem!).
Stem modifications: Bulbil (Allium) = fleshy bud replacement. Thorn (Bougainvillea) = axillary, sharp. Sucker (Mint) = underground horizontal branch. Runner = above ground horizontal (strawberry). Corm = short, vertical, swollen base (Colocasia). Tuber = potato (eye = bud).
કાંડભેદ (Stem modification) પ્રશ્ન, ખાસ potato vs sweet potato ગૂઢતા ટાળવી.
દા.ત.: Potato = Tuber (stem), Sweet potato = Tuberous root (root). Both edible but different origin!
Inflorescence ટ્રિક: Racemose = main axis continues growing (indeterminate). Cymose = main axis ends in flower (determinate). Simple vs compound differentiate. Spike = sessile flowers, Catkin = drooping raceme.
પુષ્પાંગ (Inflorescence) પ્રકાર શોધવા. Racemose vs Cymose તરત જ ઓળખવા.
દા.ત.: Mustard (શરિયા) → Racemose (terminal bud keeps growing). Solanum → Cymose.
Aestivation types: Valvate = edges touch, no overlap (Calotropis). Imbricate = irregular overlap (Cassia). Vexillary = one large petal (standard) overlapping others (Fabaceae) = 특수 imbricate. Bidetal = two petals folded together (Canavalia).
પુષ્પદળ ગોઠવણી (Aestivation) પ્રશ્ન. Fabaceae વૈક્ષેલરી સીધી યાદ.
દા.ત.: Pea (મटर) → Vexillary aestivation (banner, wings, keel). Calotropis → Valvate.
Floret/Lemma/Palea: Gramineae (Poaceae) फूलમાં Lemma = lower bract, Palea = upper bract.这两个 protect the floret. Glume = basal bract at inflorescence base.
Grass family (Poaceae) પુષ્પ structure પૂછતો પ્રશ્ન. Lemma-Palea confusion ટાળવી.
દા.ત.: Wheat (ગહુ) floret: outer bract = lemma, inner bract = palea. Both form protective envelope.
Fruit types quick ID: Dehiscent (开裂): Legume (Fabaceae), Capsule (mustard), Silique (Brassicaceae long). Indehiscent (બંધ): Achene (sunflower), Caryopsis (grain = wheat), Nut (walnut). Berry = fleshy, many seeds (tomato).
ફળ પ્રકાર (Fruit type) પ્રશ્ન. Dehiscent vs indehiscent તરત જ અલગ.
દા.ત.: Brassicaceae → Silique (longer than wide). Fabaceae → Legume (fruit splits along two sutures).
Seed vs Fruit distinction: Seed = mature ovule. Fruit = mature ovary. Endosperm = nourishment tissue (triple fusion 2 polar + 1 sperm = 3n). Embryo = zygote (2n). Testa = seed coat from integument.
બીજ સંરચના (Seed anatomy) પ્રશ્ન. Triple fusion resulting in endosperm ploidy પૂછે.
દા.ત.: Double fertilization: 1 sperm + egg → zygote (2n). Other sperm + 2 polar nuclei → primary endosperm nucleus (3n).
Family key characters: Fabaceae = legume fruit, vexillary aestivation, marginal placentation, bisexual. Solanaceae = bicarpellary gynoecium, placenta swollen (axile), often edible fruit (berry). Brassicaceae = tetradynamous stamens (4 long + 2 short), silique fruit.
કુળની ઓળખ (Family identification) પ્રશ્ન. Three families often mixed in options.
દા.ત.: Brassica (રાપીય) → 6 stamens: 4 long + 2 short = tetradynamous. Fabaceae (મटर) → 10 stamens diadelphous (9+1).
Perianth terms: Perigone = both calyx and corolla similar (monochlamydeous). Perianth = collective term for non-sexual floral parts. Sepaloid = sepal-like. Petaloid = petal-like. Both describe tepals in Liliaceae.
पुष्पावरण (Perianth) terminology પ્રશ્ન, especially when asked about Liliaceae or monocots.
દા.ત.: Lily (લિલી) → Perigone with 6 tepals (undifferentiated into sepals and petals).
Flower symmetry: Actinomorphic (radial) = can be divided equally in any vertical plane. Zygomorphic (bilateral) = single plane only. Asymmetric = no plane. Most dicots actinomorphic; Fabaceae ( zygomorphic ).
પુષ્પ સંમિતિ (Flower symmetry) પ્રશ્ન. Zygomorphic examplesจำ.
દા.ત.: Datura → Actinomorphic. Pea (મटर) → Zygomorphic. Canna → Zygomorphic (rare for monocot).
