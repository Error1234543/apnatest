🎯 પરીક્ષા ટ્રિક્સ

પિનલ મોળું = પ્રિયોઝાઇન → ઉપેચ (Melatonin) → નિદ્રા ચક્ર. જો વિકલ્પમાં 'પિનલ + બારીક/નિદ્રા' હોય તો તરત સાચો જવાબ પસંદ કરો.
જ્યારે પ્રશ્ન પિનલ મોળું અથવા ઉપેચ વિશે પૂછે.
દા.ત.: પિનલ ગ્રંથિ કયા હોર્મોનનો સ્રાવ કરે છે? (A) થાયરોક્સિન (B) ઉપેચ (C) INSULIN (D) ACTH → B
ATHY (Adenohypophysis = Purvabhag Pituitary) = 6 હોર્મોન્સ: GH, TSH, ACTH, FSH, LH, Prolactin. ORTHY (Neurohypophysis = Uttarbhag Pituitary) = 2: ADH, Oxytocin. YAD RAKHO = ATHY > ORTHY.
જ્યારે પિન્યુટરી (મસ્તિષ્કગ્રંથિ)ના ભાગો અને તેમના હોર્મોન્સ વિશે પ્રશ્ન આવે.
દા.ત.: ન્યુરોહાયપોફિઝિસ દ્વારા સ્રાવિત થતાં હોર્મોન્સ કયા છે? → ADH અને ઑક્સિટોસિન.
PTH (પારાથાયરોઇડ) = રક્તમાં Ca²⁺ ↑. Calcitonin = Ca²⁺ ↓. એક ખાલી શબ્દ: P = Pathway for raising calcium. જો પ્રશ્નમાં 'રક્તક્ષાર કેલ્શિયમ વધારનારું હોર્મોન' પૂછે → PTH.
કેલ્શિયમ સંતુલન અથવા પારાથાયરોઇડ/થાયરોઇડ સંબંધી પ્રશ્ન.
દા.ત.: કયું હોર્મોન હાડકાંમાંથી Ca²⁺ મુક્ત કરે છે? (A) Calcitonin (B) INSULIN (C) PTH (D) Cortisol → C
Addison's = Adrenal cortex નિષ્ફળતા → melanin વધુ → કાળા ધબ્બા. જો વિકલ્પમાં 'તાંડવું મેલેનિન' અથવા 'કાળા ધબ્બા' હોય અને વિકારનું નામ ન હોય → Addison's જવાબમાંથી પસંદ કરો.
એડ્રિનલ ગ્રંથિ સંબંધી રોગોના પ્રશ્ન.
દા.ત.: ચમડી પર ઘોરા ધબ્બાઓ દેખાય તેવો રોગ: → Addison's રોગ.
Cushing's = Cortisol વધારો → Moon face, Buffalo hump. jODDI = Corticosteroids વધુ. જો પ્રશ્નમાં 'Cortisol અધિક' હોય → Cushing's, જો 'Cortisol ઓછો' → Addison's. બંને વિરુદ્ધ.
એડ્રિનલ કોર્ટેક્સના રોગો અલગ પાડવા.
દા.ત.: કયો રોગ સ્ટેરોઇડ હોર્મોન્સના અતિસ્રાવથી થાય? → Cushing's syndrom.
Diabetes Insipidus = ADH की कमी → पेशाब में पानी ज्यादा, शर्करा नहीं. Diabetes Mellitus = INSULIN की कमी → पेशाब में शर्करा. ट्रिक: 'Insipidus → इंसुलिन नहीं, बस पानी!' और 'Mellitus → मीठा (शर्करा).'
મધુમેહ (Diabetes) પ્રકારોને ઓળખવા.
દા.ત.: પ્રમેહમાં જેમાં મૂત્રમાં ચીની હોય પણ ADH સામાન્ય હોય → Diabetes Mellitus.
Steroid hormones (Sex hormones, Cortisol, Aldosterone) → lipid-soluble → cell membrane easily cross → bind to INTRACELLULAR receptor → gene activation. Non-steroid (Protein/peptide like INSULIN, GH, ADH) → bind to SURFACE receptor → cAMP second messenger. Yadya 'intracellular receptor' dikhe → steroid hi hota hai.
હોર્મોન ક્રિયા પદ્ધતિ (mechanism) સંબંધી પ્રશ્ન.
દા.ત.: કયું હોર્મોન કોષદ્રવ્યમાં રિસેપ્ટર સાથે જોડાય છે? (A) INSULIN (B) Glucagon (C) Testosterone (D) ADH → C (Steroid)
HPA Axis (Hypothalamus-Pituitary-Adrenal) = Cortisol/ACTH pathway. જો પ્રશ્નમાં 'તણાવ (stress)' નો ઉલ્લેખ હોય → Cortisol/Adrenal medulla. 'Fight-or-flight' = Adrenal medulla (Epinephrine/Norepinephrine).
તણાવ સંબંધી પ્રશ્ન અથવા એડ્રિનલ મેડુલા વિશે.
દા.ત.: શરીરમાં 'ફાઇટ અથવા ફ્લાઇટ' રિએક્શન માટે જવાબદાર હોર્મોન્સ: → Epinephrine + Norepinephrine.
Thymosins = Thymus gland → T-lymphocyte differentiation → immunity. જો પ્રશ્નમાં 'રક્તક્ષાર પ્રતિરક્ષા' અથવા 'T-cells' આવે → Thymus. Thymus વય સાથે萎缩 (退化) થાય છે — elderly માં thymus小さું થાય.
થાયમસ ગ્રંથિ સંબંધી પ્રશ્ન.
દા.ત.: કયો ગ્રંથિ રોગપ્રતિકારક તંત્રને નિયંત્રિત કરે છે? → થાયમસ.
Heart → ANF (Atrial Natriuretic Factor) → BP ↓ (Na⁺ excretion વધારે → પાણી પણ બહાર). kidney → Erythropoietin → RBC synthesis. GI tract → Secretin, CCK, Gastrin. જો 'BP ઘટાડો' + 'heart' → ANF.
હૃદય, વૃક્ષ, AJĀMANદ્રી સંબંધી અત્યાધુનિક હોર્મોન્સ.
દા.ત.: રક્તદબાણ ઘટાડનાર હોર્મોન કયું? (A) ANF (B) Renin (C) ADH (D) Aldosterone → A
Goitre (ગોઇટર) = Thymoxin deficiency (Iodine ki kami) → thyroid gland badh jati hai (goonth). Simple goitre = iodine ki kami. Hyperthyroidism = Graves' disease. Hypothyroidism = Myxoedema (adults), Cretinism (children). Yaad rakh: 'Cre-tin = bachcha, Myxo = bade.'
થાયરોઇડ સંબંધી વિકારો.
દા.ત.: બાળકોમાં થાયરોઇડ અસ્વસ્થતાથી કયો રોગ થાય? → Cretinism.
APOPITARY (Purvabhag) ko hypothalamus control karta hai portal system se. Uttarbhag (Posterior) directly neural control. Prashn mein 'portal circulation' ya 'hypothalamic regulating' dikhe → Adenohypophysis. 'Neural connection' dikhe → Neurohypophysis.
પિન્યુટરીના સંયોજન અને નિયંત્રણ સંબંધી પ્રશ્ન.
દા.ત.: પિન્યુટરીનો પૂર્વભાગ કયા દ્વારા નિયંત્રિત થાય છે? → હાઇપોથેલેમસ (Portal system દ્વારા).
Second Messenger System: Non-steroid hormone → receptor on membrane → G-protein → Adenylate cyclase → ATP → cAMP → Protein kinase → Response. Yeh path GH, INSULIN, Glucagon, ADH sabke liye common hai. Jaise 'cAMP' option mein ho → non-steroid hormone ka mechanism.
હોર્મોનના સેકન્ડ મેસેન્જર તરીકે કાર્ય સંબંધી પ્રશ્ન.
દા.ત.: cAMP_second messenger द्वारा कार्य करने वाला हार्मोन: (A) Testosterone (B) Cortisol (C) INSULIN (D) Thyroxine → C
Pancreatic hormones: INSULIN = beta cells → glucose ↓. Glucagon = alpha cells → glucose ↑. Somatostatin = delta cells → both inhibit. Question mein 'glucose kam kare' = INSULIN, 'ghada kare' = Glucagon. Yaad rakh: 'InSuLin = Sugar Less (कम).'
અંગ્રેજી ગ્રંથિના હોર્મોન્સ અને તેમનું કાર્ય.
દા.ત.: રક્તશર્કરા ઘટાડનાર હોર્મોન: (A) Glucagon (B) Cortisol (C) INSULIN (D) Adrenaline → C
Negative feedback = most hormone systems ka basic rule. Jaise Thyroxin → TH negative feedback on TSH. Cortisol → negative feedback on ACTH. Prashn mein 'negative feedback' dikhe → hormone apne producer ko regulate karta hai. Positive feedback = rare (oxytocin during labour, milk ejection).
હોર્મોન નિયંત્રણ અને ફીડબેક યંત્ર સંબંધી પ્રશ્ન.
દા.ત.: થાયરોક્સિનનું નિયંત્રણ કયા તંત્ર દ્વારા થાય છે? → ऋणात्मक फीडबैक (Negative feedback).
