🎯 પરીક્ષા ટ્રિક્સ

રબોઝોમના S મૂલ્ય યાદ રાખવાની 'વર્ગીકરણ' પદ્ધતિ: પ્રોકેરીયોટિક = 70S, યુકેરીયોટિક = 80S. માઇટોકોન્ડ્રિયા અને ક્લોરોપ્લાસ્ટમાં પણ 70S રબોઝોમ હોય છે — આ બંને અર્ધસ્વતંત્ર (semi-autonomous) છે તે ભાગ્યે જ પૂછાય છે, પણ ખાતરી માટે યાદ રાખો.
જ્યારે પ્રશ્નમાં રબોઝોમનો પ્રકાર, સ્થળ, કે S મૂલ્ય પૂછવામાં આવ્યું હોય અથવા 'અર્ધસ્વતંત્ર કોષાંગ' વિશે પૂછે.
દા.ત.: માઇટોકોન્ડ્રિયામાં કઈ રબોઝોમ હોય? → 70S (પ્રોકેરીયોટિક પ્રકારનું). વિકલ્પમાં 80S હોય તો તરત નિકાલ.
S મૂલ્યો બેઝરોજોડાતા નથી: 50S + 30S = 80S નહિ, 70S થાય. આ ભ્રામક ગણિત ઘણા વિદ્યાર્થીઓને પકડે છે. યાદ રાખો: S મૂલ્ય કદ-આધારિત છે, સરવાળો નહિ.
જ્યારે પ્રશ્નમાં 70S રબોઝોમની રચના (50S મોટી એકમ + 30S નાની એકમ) અંગે ગણતરી કે શબ્દચૂક પરિકલ્પના આવે.
દા.ત.: '70S રબોઝોમ બે 80S એકમોથી બને છે' — ખોટું. સાચું: 50S + 30S = 70S (સંયોજન મૂલ્ય નહિ).
કોષદીવાલનું સામગ્રી ઝડપથી ઓળખો: સક્ષુધાનો (Plantae) = સેલ્યુલોઝ, ફંજી = કાઇટિન, બેક્ટેરિયા = પેપ્ટિડોગ્લાઇકન. પ્રશ્નમાં 'કોષદીવાલ' શબ્દ આવે તો તરત ડેટાબેઝ યાદ કરો.
કોષદીવાલની રચના, ભિન્ન જીવો વચ્ચે તફાવત, કે વિષમ પદાર્થો ધરાવતા સમૂહ પસંદ કરવાના પ્રશ્નોમાં.
દા.ત.: સકૃપ્ટોફાઇટ્સની કોષદીવાલ કઈ સામગ્રીની બનેલી? → કાઇટિન. સેલ્યુલોઝ/પેપ્ટિડોગ્લાઇકન વિકલ્પો તરત નિકાલ.
અંતઃકોષિક પટલપ્રણાલી (Endomembrane System) માં રબોઝોમ અને માઇટોકોન્ડ્રિયા/ક્લોરોપ્લાસ્ટ — આ બંનેનો સમાવેશ થતો નથી. કારણ: રબોઝોમ પટલરહિત છે, માઇટોકોન્ડ્રિયા સ્વતંત્ર ઉત્પત્તિ ધરાવે છે.
જ્યારે પ્રશ્ન પૂછે કે 'કઈ પટલપ્રણાલીનો ભાગ નથી?' અથવા 'બહારનાં' કોષાંગો પસંદ કરવા હોય.
દા.ત.: નોસોલોબ્યુલા, રબોઝોમ, માઇટોકોન્ડ્રિયા — કઈ બહાર? → બધા! રબોઝોમ પટલરહિત, બાકીના સ્વતંત્ર ઉત્પન્ન થતા.
પટલની સંખ્યા યાદ કરો: દ્વિ-પટલીય (double membrane) = કોષકેન્દ્ર, માઇટોકોન્ડ્રિયા, ક્લોરોપ્લાસ્ટ. એક-પટલીય (single membrane) = રેટિક્યુલમ, ગોલ્ગી શરીર, લાયસોઝોમ, વેસિકલ્સ. પટલરહિત = રબોઝોમ, સેન્ટ્રિયોલ, સાયટોસ્કેલેટન.
કોષાંગોને તેમની પટલ સંખ્યા દ્વારા વર્ગીકૃત કરવા, 'પટલરહિત' પ્રશ્નોમાં, કે ભ્રામક જોડીઓ ઓળખવા.
દા.ત.: લાયસોઝોમ, ગોલ્ગી, રબોઝોમ — કયાં પટલરહિત? → રબોઝોમ જ. અન્ય બે એક-પટલીય છે.
સનગર અને નિકોલસન (1972) = પ્રવાહી મોઝેક મોડલ (Fluid Mosaic Model). કોષપટલમાં પ્રોટીન-લિપિડ-પ્રોટીન (પ્રોટીન સંમેલન/અંતર્ગત) રચના છે. 'પ્રવાહી' શબ્દનો અર્થ: લિપિડ ઍસિડ-પ્રવાહી ગતિશીલ; 'મોઝેક' શબ્દનો અર્થ: પ્રોટીન વિવિધતા.
કોષપટલના મોડલ, નિરીક્ષકો, અને રચનાના ગુણધર્મો અંગે પ્રશ્નોમાં.
દા.ત.: કોષપટલનું મોડલ કેણે મૂક્યું? → સનગર અને નિકોલસન. 1959 (જોરાહેલ) નો રેવરસ પૂછાય તો ધ્યાનથી વાંચો: તેઓ ઈલેક્ટ્રોન માઈક્રોસ્કોપથી ત્રિ-પટલ દેખાડ્યું હતું.
લાઇપોસોમ (Liposome) = આંતર-જલીય ખાલીપન ધરાવતું દ્વિ-પરતીય (bilayer) કોષક. પ્રશ્નમાં 'ખાલીપન' / 'અંદરનું જલીય માધ્યમ' વાળો પ્રશ્ન હોય તો લાઇપોસોમ = ખાલી, એક્સોસોમ = ખાલી નહિ.
વેસિકલ પ્રકારો (લાઇપોસોમ, એક્સોસોમ, એન્ડોસોમ) વચ્ચેનો તફાવત, ખાસ કરીને અંદરનું ખાલીપન અંગે.
દા.ત.: કઈ વેસિકલમાં અંદર જલીય ખાલીપન હોય? → લાઇપોસોમ. એક્સોસોમમાં બહારના મોલેક્યુલ્સ હોય.
માઇટોકોન્ડ્રિયા અને ક્લોરોપ્લાસ્ટ — બંને અર્ધસ્વતંત્ર છે કારણ કે તેમના પોતાના DNA, રબોઝોમ (70S), અને દ્વિ-પટલીય ઝાંકુ ધરાવે છે. પણ કોષકેન્દ્ર (Nucleus) અર્ધસ્વતંત્ર નથી! એનો DNA કોષકેન્દ્રીય છે, રબોઝોમ નથી.
'અર્ધસ્વતંત્ર કોષાંગ' પ્રશ્નોમાં. કોષકેન્દ્રને અહીં ઉભો કરવાની ટોચની ચાલાકી છે.
દા.ત.: કયું કોષાંગ અર્ધસ્વતંત્ર નથી? → કોષકેન્દ્ર. માઇટોકોન્ડ્રિયા અને ક્લોરોપ્લાસ્ટ અર્ધસ્વતંત્ર છે.
પ્રોકેરીયોટિક કોષમાં ન્યુક્લિઓન્ડ (nucleoid) = વર્તુળાકાર, પટલરહિત DNA; યુકેરીયોટિક = રેખીય DNA + હિસ્ટોન પ્રોટીન. 'ઇંડકોટોપ્લાઝમ' (mesosome) = પ્લાઝ્મા પટલનું અંદરની તરફનું ગુચ્છ — પ્રોકેરીયોટ્સમાં માત્ર, યુકેરીયોટ્સમાં નહિ.
પ્રોકેરીયોટ vs યુકેરીયોટ, મેસોઝોમ/ઇંડકોટોપ્લાઝમ અંગે તફાવત.
દા.ત.: પ્લાઝ્મા પટલનું અંદરની તરફ ગુચ્છ? → ઇંડકોટોપ્લાઝમ. યુકેરીયોટિક કોષમાં તે નહિ મળે.
ઓસ્મોસિસ vs Diffusion: ઓસ્મોસિસમાં ફક્ત દ્રાવક (water) પસાર થાય, પરંતુ વિકલ્પમાં 'જલીય દ્રાવણ' શબ્દ આવે તો ધ્યાનથી — ઓસ્મોસિસ = માત્ર પાણી. ડિફ્યુઝનમાં દ્રાવ્ય અણુઓ પણ હરકત કરે.
દ્રવ્યના પસાર થવાના પ્રકાર, અપ઼સ્મોસિસ/પ્લાઝમોલિસિસ પ્રશ્નોમાં.
દા.ત.: 'સંવેદનશીલ પટલ દ્વારા દ્રાવકનું ચાલન' — કયો પ્રક્રિયા? → ઓસ્મોસિસ. ડિફ્યુઝનમાં દ્રાવ્ય પણ હરકત કરે.
કોષની સૌથી નાની એકમ = લાક્ષણિક કોષ (约1-10 μm). સૌથી મોટું પ્રોકેરીયોટ = થિઓબેસ્ટિયર (Thiobacillus). સૌથી મોટું યુકેરીયોટિક કોષ = પક્ષીઓનું ઇંડું (ઓવો). ઇંડાના કદને 'સૌથી મોટું કોષ' તરીકે ઓળખો.
કોષના કદ, કણ-આદર્શ કદ, વિશિષ્ટ રેકોર્ડ-ધરાવતા કોષો અંગેના પ્રશ્નોમાં.
દા.ત.: સૌથી મોટું કોષ? → પક્ષીઓનું ઇંડું (ઓવો). સૂક્ષ્મજીવોનાં નાના કોષો અલગ વિકલ્પમાં હોય તો ધ્યાન રાખો.
કોષદીવાલ ધરાવતા પણ પટલ-રહિત કોષકેન્દ્ર ધરાવતા જીવ = બેક્ટેરિયા (પ્રોકેરીયોટ્સ). કોષદીવાલ + કોષકેન્દ્ર = સક્ષુધાનો/ફંજી (યુકેરીયોટ્સ). આ ડબલ-ક્રિટિરિયા ટેકનિકથી શીઘ્ર નિયંત્રણ.
ક્લાસિફિકેશન પ્રશ્નો, 'કઈ વર્ગમાં આવે?' પ્રકારના પ્રશ્નોમાં.
દા.ત.: કઈ સમૂહમાં કોષદીવાલ + પટલ-રહિત કોષકેન્દ્ર હોય? → બેક્ટેરિયા. અન્ય વિકલ્પો તરત નિકાલ.
કેન્દ્રીય (Nucleolus) = rRNAનું સંશ્લેષણ કેન્દ્ર; karyoplasm = કેન્દ્રિકામાંના દ્રવ્ય (ન્યુક્લિયોપ્લાઝમ); ન્યુક્લિયોપોર્સ = કેન્દ્રીય પટલના છિદ્રો જે પોલારી મોલેક્યુલ્સ પસાર થવા દે છે.
કોષકેન્દ્રના સ્થળો અને કાર્યો, rRNA સંશ્લેષણ, કેન્દ્રીય છિદ્રો અંગેના પ્રશ્નોમાં.
દા.ત.: rRNAનું સંશ્લેષણ ક્યાં થાય? → કેન્દ્રીય (Nucleolus). રબોઝોમનો ઉદ્ભવ પણ અહીંથી.
લાઇસોઝોમ = 'આત્મઘાતી થેલી' (Suicidal bag). જ્યારે કોષને ફાટી જવું હોય ત્યારે લાઇસોઝોમ પોતે ફાટી જાય છે. પરંતુ તે બહારના ફેગોસોમમાં રહેલા પદાર્થોનું પાચન પણ કરે છે.
લાઇસોઝોમનું વિશેષણ, તેના કાર્યો, કે વિષમ વિકલ્પોમાંથી પસંદગી.
દા.ત.: 'આત્મઘાતી થેલી' કઈ? → લાઇસોઝોમ. જો વિકલ્પમાં પેરોક્સિઝોમ હોય તો તે પેરોક્સાઇડઝનો નાશ કરે છે, આત્મઘાતી નથી.
સંયોજનમાં બેક્ટેરિયાની કોષદીવાલ = પેપ્ટિડોગ્લાઇકન (NAM + NAG). ફંજી = કાઇટિન (N-acetylglucosamine). સક્ષુધાનો = સેલ્યુલોઝ. આ ત્રણેયના મોનોમર એકસરખા નથી — બેક્ટેરિયાના NAM+NAG, ફંજીના NAG-માત્ર, સક્ષુધાનના ગ્લૂકોઝ-માત્ર.
કોષદીવાલની સામગ્રી, રાસાયણિક રચના, અને મોનોમર જાણવા પ્રશ્નોમાં.
દા.ત.: બેક્ટેરિયાની કોષદીવાલમાં કયું શર્કરા જોડાયેલ છે? → NAM + NAG. ફંજીમાં ફક્ત NAG.
