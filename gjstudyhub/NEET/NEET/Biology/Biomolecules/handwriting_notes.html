જૈવ અણુઓ (Biomolecules)

🩺 NEET UG — Gujarati • Biology • Biomolecules

જૈવ અણુઓ: પરિચય
જૈવ અણુઓ એ જીવંત સજીવોમાં જોવા મળતા રાસાયણિક પદાર્થો છે, જે જૈવિક પ્રક્રિયાઓમાં મહત્વની ભૂમિકા ભજવે છે.
તેઓ કાર્બન, હાઇડ્રોજન, ઓક્સિજન, નાઇટ્રોજન, ફોસ્ફરસ અને સલ્ફર જેવા તત્વો ધરાવે છે.
જૈવ અણુઓને મુખ્યત્વે ચાર વર્ગોમાં વહેંચી શકાય: કાર્બોદિતો, પ્રોટીન, ચરબી અને ન્યુક્લિક એસિડ.
📝 NEETમાં આ વર્ગીકરણ યાદ રાખવું અગત્યનું છે!
કાર્બોદિતો (Carbohydrates)
કાર્બોદિતો એ પોલિહાઇડ્રોક્સી એલ્ડિહાઇડ અથવા કિટોન છે, જે Cₙ(H₂O)ₘ સૂત્ર ધરાવે છે.
સામાન્ય સૂત્ર: Cₙ(H₂O)ₘ
તેઓ સજીવોના શરીરમાં ઉર્જાનો મુખ્ય સ્રોત છે.
વર્ગીકરણ: મોનોસેકેરાઇડ (ગ્લુકોઝ, ફ્રક્ટોઝ), ડાઇસેકેરાઇડ (સુક્રોઝ, લેક્ટોઝ), પોલિસેકેરાઇડ (સ્ટાર્ચ, સેલ્યુલોઝ, ગ્લાઇકોજન).
ગ્લુકોઝ (C₆H₁₂O₆) એ સૌથી મહત્વપૂર્ણ મોનોસેકેરાઇડ છે.
📝 સ્ટાર્ચ અને ગ્લાઇકોજન એ પોલિસેકેરાઇડ છે, જે ઉર્જાનું સંગ્રહ સ્વરૂપ છે.
મોનોસેકેરાઇડડાઇસેકેરાઇડ
ડાઇસેકેરાઇડપોલિસેકેરાઇડ
પ્રોટીન (Proteins)
પ્રોટીન એ એમિનો એસિડના પોલિમર છે, જે પેપ્ટાઇડ બંધ (Peptide bond) દ્વારા જોડાયેલા હોય છે.
પેપ્ટાઇડ બંધ: -CO-NH-
એમિનો એસિડમાં એમિનો સમૂહ (-NH₂) અને કાર્બોક્સિલ સમૂહ (-COOH) હોય છે.
પ્રોટીનની રચના: પ્રાઇમરી (અનુક્રમ), સેકન્ડરી (આલ્ફા-હેલિક્સ, બીટા-પ્લીટેડ શીટ), ટર્શિયરી (3D આકાર), ક્વોટરનરી (બહુવિધ પોલિપેપ્ટાઇડ શૃંખલાઓ).
પ્રોટીનની કાર્યે: એન્ઝાઇમ, હોર્મોન, રક્ષણાત્મક પ્રોટીન (એન્ટિબોડી), રચનાત્મક પ્રોટીન (કોલેજન, કેરેટિન).
📝 NEETમાં એન્ઝાઇમની ભૂમિકા મહત્વપૂર્ણ છે!
ચરબી (Lipids)
ચરબી એ હાઇડ્રોફોબિક જૈવ અણુઓ છે, જે ફેટી એસિડ અને ગ્લિસરોલ અથવા અન્ય આલ્કોહોલના એસ્ટર છે.
વર્ગીકરણ: સરળ ચરબી (ટ્રાઇગ્લિસરાઇડ), જટિલ ચરબી (ફોસ્ફોલિપિડ, ગ્લાઇકોલિપિડ), સ્ટેરોઇડ (કોલેસ્ટરોલ).
ટ્રાઇગ્લિસરાઇડ: ગ્લિસરોલ + 3 ફેટી એસિડ
ફોસ્ફોલિપિડ એ કોષપટલ (Cell membrane) ની રચનામાં મહત્વપૂર્ણ છે.
📝 સ્ટેરોઇડ એ હોર્મોન અને કોષપટલના ઘટકો છે.
ન્યુક્લિક એસિડ (Nucleic Acids)
ન્યુક્લિક એસિડ એ ન્યુક્લિયોટાઇડના પોલિમર છે, જે આનુવંશિક માહિતીનું સંચાલન કરે છે.
ન્યુક્લિયોટાઇડની રચના: નાઇટ્રોજનયુક્ત ક્ષાર (પ્યુરિન અથવા પિરિમિડિન), પેન્ટોઝ શર્કરા (રાઇબોઝ અથવા ડિઓક્સીરાઇબોઝ), ફોસ્ફેટ સમૂહ.
DNA: ડિઓક્સીરાઇબોઝ + ફોસ્ફેટ + (A, T, C, G)
RNA: રાઇબોઝ + ફોસ્ફેટ + (A, U, C, G)
DNA એ ડબલ હેલિક્સ (Double Helix) રચના ધરાવે છે, જ્યારે RNA એ સિંગલ સ્ટ્રેન્ડેડ હોય છે.
DNA એ આનુવંશિક માહિતીનું સંગ્રહણ કરે છે, જ્યારે RNA એ પ્રોટીન સંશ્લેષણમાં મદદ કરે છે.
📝 NEETમાં DNA અને RNAની રચના યાદ રાખવી અગત્યની છે!
એન્ઝાઇમ (Enzymes)
એન્ઝાઇમ એ જૈવ ઉત્પ્રેરક (Biological catalyst) છે, જે જૈવિક પ્રક્રિયાઓની ગતિ વધારે છે.
તેઓ પ્રોટીન અથવા RNA (રાઇબોઝાઇમ) હોઈ શકે છે.
એન્ઝાઇમની વિશિષ્ટતા: એન્ઝાઇમ એક વિશિષ્ટ સબસ્ટ્રેટ સાથે જ પ્રક્રિયા કરે છે (Lock and Key Model, Induced Fit Model).
એન્ઝાઇમ + સબસ્ટ્રેટ → એન્ઝાઇમ-સબસ્ટ્રેટ કોમ્પ્લેક્સ → ઉત્પાદન + એન્ઝાઇમ
એન્ઝાઇમની કાર્યપદ્ધતિ પર તાપમાન, pH, અને ઉત્પ્રેરકની સાંદ્રતા અસર કરે છે.
📝 એન્ઝાઇમની ક્રિયા પર તાપમાન અને pH નો પ્રભાવ NEETમાં પૂછાય છે!
જૈવ અણુઓની શોધ અને અભ્યાસ
જૈવ અણુઓની શોધમાં મહત્વપૂર્ણ વૈજ્ઞાનિકો: ફ્રેડરિક વિલિયમ કેકુલે (કાર્બન શૃંખલા), જેમ્સ વોટસન અને ફ્રાન્સિસ ક્રિક (DNA રચના).
DNAની રચનાનો મોડેલ વોટસન અને ક્રિક દ્વારા 1953માં પ્રસ્તાવિત કરવામાં આવ્યો હતો.
📝 NEETમાં વૈજ્ઞાનિકોના નામ અને તેમના યોગદાન યાદ રાખવા જરૂરી છે!
જૈવ અણુઓ અને ઉર્જા
કાર્બોદિતો અને ચરબી એ ઉર્જાના મુખ્ય સ્રોત છે.
ATP (એડિનોસિન ટ્રાઇફોસ્ફેટ) એ કોષીય ઉર્જાનું સરળ સ્વરૂપ છે.
ATP → ADP + Pᵢ + ઉર્જા (ΔG = -30.5 kJ/mol)
ATP એ ઉર્જાનું 'કોષીય ચલણ' કહેવાય છે.
📝 ATP અને ADP વચ્ચેના રૂપાંતરને NEETમાં સમજવું અગત્યનું છે!
જૈવ અણુઓની જૈવિક મહત્વ
કાર્બોદિતો: ઉર્જાનો સ્રોત, રચનાત્મક સમર્થન (સેલ્યુલોઝ).
પ્રોટીન: એન્ઝાઇમ, હોર્મોન, રક્ષણ, પરિવહન, રચના.
ચરબી: ઉર્જાનો સંગ્રહ, કોષપટલની રચના, હોર્મોનનો પૂરવઠો.
ન્યુક્લિક એસિડ: આનુવંશિક માહિતીનું સંચાલન, પ્રોટીન સંશ્લેષણ.
જૈવ અણુઓ વગર જીવન શક્ય નથી!
📝 NEETમાં જૈવ અણુઓની જૈવિક ભૂમિકા સમજવી અગત્યની છે!
