🎯 પરીક્ષા ટ્રિક્સ

ઇન્ટરફેઝમાં સૌથી વધુ સમય — આ યાદ રાખો: 'IA' = Interphase is Always longest (~90% cell cycle). સામેની વિકલ્પો જો વિકલ્પોમાં Prophase/Metaphase જેવા કોઈ ફેઝનો સમય ઇન્ટરફેઝ કરતા વધારો હોય તેમ લાગે, તો فوراً બહાર કાઢી દેવું.
જ્યારે પ્રશ્નમાં પૂછવામાં આવે કે કોષચક્રના કેટલા ટકા સમયમાં કયા ફેઝમાં વિતાવે છે અથવા કયો ફેઝ સૌથી લાંબો છે.
દા.ત.: પ્રશ્ન: કોષચક્રનો સૌથી લાંબો સમય કયા ફેઝમાં વિતાવે છે? → જવાબ: Interphase. વિકલ્પોમાં G1/S/G2 અલગ-અલગ આપેલા હોય તો 'કોઈ પણ એક નહિ, બધા મળીને Interphase' એ યાદ રાખવું.
ક્રોમોઝોમ ગતિ યાદ કરવા માટે CPMA તાક — Chromosome Progression Mnemonic: C (Condense/Pack in Prophase) → P (Align at Plate in Metaphase) → M (Move apart in Anaphase) → D (Decondense in Telophase). જો પ્રશ્નમાં ફેઝ મુજબ ક્રોમોઝોમની ગતિ પૂછે, તો આ એકમથી فوراً ક્રમ મળી જાય.
જ્યારે પ્રશ્નમાં કોઈ વિશિષ્ટ ફેઝમાં ક્રોમોઝોમ શું કરે છે તે પૂછવામાં આવે.
દા.ત.: પ્રશ્ન: Metaphase માં ક્રોમોઝોમ ક્યા હોય છે? → CPMA માં P = Align at Plate (સમભાગ રેખા પર). જવાબ: Metaphase plate પર ગોઠવાયેલા.
ક્રોમોઝોમ આકાર → Anaphase ની ઓળખ: Anaphase માં જ સીસ્ટર ક્રોમેટિડ અલગ થાય છે, તેથી ક્રોમોઝોમ V, J અથવા I આકારના દેખાય. જો વિકલ્પમાં 'V-આકારના ક્રોમોઝોમ' જોવા મળે તો فوراً Anaphase નિર્ધારિત. Metaphase માં ક્રોમોઝોમ હંમેશા metaphase plate પર લંબરૂપ (perpendicular) ગોઠવાય છે.
જ્યારે પ્રશ્નમાં ફેઝની ઓળખ કરાવે (દૃશ્ય આધારિત) અથવા ક્રોમોઝોમ આકારને આધારે ફેઝ શોધવો હોય.
દા.ત.: પ્રશ્ન: V-આકારના ક્રોમોઝોમ કયા ફેઝમાં જોવા મળે? → Anaphase. જવાબ: Metaphase પર L/V નહિ, Anaphase માં V/J/I.
કેન્ડ્રીઓપોલર ફાઇબર vs કાયનેટોક ફાઇબર: Anaphase A = kinetochore fibers contraction (chromosomes toward pole); Anaphase B = polar fibers elongation (poles move apart). યાદ રાખો: 'A-kinetochore, B-bulk'. જો પ્રશ્નમાં પૂછે કે કયો ફાઇબર ક્રોમોઝોમને પોલ તરફ ખેંચે છે → Answer: Kinetochore (Anaphase A).
જ્યારે Anaphase ના અંતર્ગત fiber types અને તેમની ક્રિયા વિશે પ્રશ્ન આવે.
દા.ત.: પ્રશ્ન: કયા ફાઇબર ક્રોમોઝોમના કાયનેટોકોર સાથે જોડાયેલા છે અને પોલ તરફ ખેંચે છે? → Kinetochoor fibers (Anaphase A). Polar/spindle fibers જુદા.
Plant vs Animal Cytokinesis ઓળખ: Plant = Cell plate (મધ્યથી બાહર તરફ), Animal = Cleavage furrow (બાહરથી મધ્ય તરફ). યાદ રાખો: 'Plant Plate, Animal Pinch'. Gulkhand (ગુલાબ) અથવા 'P-A = Plate-Animal' સમજો. વિકલ્પોમાં જો 'Cell plate' શબ્દ હોય → Plant; 'Cleavage furrow' હોય → Animal.
જ્યારે પ્રશ્નમાં કણિકા વિભાજન (Cytokinesis) ના પ્રકાર કે રચના પૂછવામાં આવે.
દા.ત.: પ્રશ્ન: ઉદ્ભિદ કોષમાં Cytokinesis કઈ રીતે થાય છે? → Cell plate (ફ્રેગ્મોપ્લાસ્ટ). વિકલ્પમાં Cleavage furrow હોય તો فوراً ખોટો.
બંધન તથ્ય: Metaphase I માં Homologous chromosomes (Bivalent/Tetrad) બે સ્તરમાં plate પર ગોઠવાય છે; Metaphase માં Individual chromosomes એક સ્તરમાં ગોઠવાય છે. યાદ રાખો: 'MI = 2 layers, M = 1 layer'. જો પ્રશ્નમાં '2n chromosomes at plate' અથવા 'Tetrads aligned' — Metaphase I; જો 'n bivalents' — Metaphase I; 'n chromosomes singly' — Metaphase.
જ્યારે Meiosis I vs Mitosis ના Metaphase વચ્ચે ભેદ કરવાનો હોય અથવા Chromosome arrangement પૂછવામાં આવે.
દા.ત.: પ્રશ્ન: Homologous chromosomes ના tetrads metaphase plate પર ગોઠવાય છે — કયા ફેઝ? → Metaphase I. જવાબ: Meiosis I.
અર્ધસૂત્રણ (Meiosis) માં Crossing-over ફક્ત Pachytene (Prophase I) માં જ થાય છે. આ ખાસ તથ્ય છે — ડિપ્લોટીન, ઝાયગોટીન કે ડિસ્કોન્ટીનમાં નહિ. જો પ્રશ્નમાં 'કયા સ્ટેજમાં Crossing over?' → જવાબ Pachytene. આમને બધા જ વિકલ્પોમાંથી અન્ય Prophase I સ્ટેજ્સ બહાર કાઢી દેવા.
જ્યારે Meiosis I ના Prophase I ના સ્ટેજ્સ વિશે પૂછાય અથવા Crossing over / Recombination નો સ્ટેજ પૂછાય.
દા.ત.: પ્રશ્ન: Non-sister chromatids વચ્ચે Crossing over કયા સ્ટેજમાં થાય છે? → Pachytene. વિકલ્પોમાં Leptotene/Zygotene/Diplotene હોય તો બધા ખોટા.
ઝાયગોટીન (Zygotene) = Synapsis → Synaptonemal complex બને છે. ડિપ્લોટીન (Diplotene) = Synaptonemal complex દૂર થાય છે, Chiasmata દેખાય છે. યાદ રાખો: 'ZY = Zygote pairing (Synapsis); DP = Disappearance (SY complex vanishes) + Diplotene chiasmata'. જો પ્રશ્નમાં 'Synaptonemal complex' હોય → Zygotene; 'Chiasmata' હોય → Diplotene.
જ્યારે Prophase I ના સ્ટેજ્સ અને તેમના લક્ષણો વિશે પ્રશ્ન આવે.
દા.ત.: પ્રશ્ન: Synaptonemal complex કયા સ્ટેજમાં રચાય છે? → Zygotene. Diplotene માં તે ઓગળી જાય છે, Chiasmata જ બાકી રહે.
Meiosis I નું મુખ્ય પરિણામ: Chromosome संख्या અડધી ( Reductional division ) — 2n → n. Meiosis II = Equational (mitosis જેવું): n → n. યાદ રાખો: 'MI = Make fewer (happen reduction); MII = Mirrors mitosis (equational)'. જો પ્રશ્નમાં 'Reduction division' → Meiosis I; 'Equational division' → Meiosis II.
જ્યારે Meiosis I અને Meiosis II ના પ્રકાર (Reductional vs Equational) અથવા પરિણામો વિશે પ્રશ્ન આવે.
દા.ત.: પ્રશ્ન: કયો અર્ધસૂત્રણ વિભાજન Reductional છે? → Meiosis I. Meiosis II માં ક્રોમેટિડ અલગ થાય છે, chromosome count same રહે.
Dictyate = prolonged Diplotene stage (ઓપરેટિવ记忆: 'Dictate' = long pause, મધ્યમ સમય સુધી રહેવાનું). Oocytes માં આ સ્ટેજ લાંબો થાય છે. જો પ્રશ્નમાં 'Stage of prolonged Diplotene' અથવા 'Dictyate stage' હોય → Diplotene.
જ્યારે Prophase I ના કોઈ વિશિષ્ટ સ્ટેજના લક્ષણો વિશે પ્રશ્ન આવે, ખાસ કરીને Dictyate/Diapause અંગે.
દા.ત.: પ્રશ્ન: Dictyate stage કયા Prophase I સ્ટેજનું વિસ્તૃત રૂપ છે? → Diplotene. જવાબ: Diplotene.
કોષચક્રના checkpoints યાદ કરો: G1 checkpoint (Restriction point/R) = તમામ પરિસ્થિતિ જોય; G2 checkpoint = DNA replication check; M checkpoint (Spindle assembly) = chromosomes attach to spindle. યાદ રાખો: 'R-G2-M' = 'Real Good Move' (Checklist of life decisions). G1માં R point છે તે યાદ રાખો: 'Restriction = Go/No-go decision at G1'.
જ્યારે细胞周期 checkpoints અથવા Regulatory proteins(Cyclins, CDKs) વિશે પ્રશ્ન આવે.
દા.ત.: પ્રશ્ન: કયો checkpoint પ્રોટીન સંશ્લેષણ, ATP નiveau અને DNADamage check કરે છે? → G1/R checkpoint. જવાબ: G1 phase.
Cyclin-CDK નો સંબંધ: Cyclin = regulatory subunit (concentration oscillates — બને છે અને તૂટે છે); CDK = catalytic subunit (constant amount). યાદ રાખો: 'Cyclin cycles, CDK stays'. જો પ્રશ્નમાં 'Which protein level oscillates?' → Cyclin. 'Which is constant?' → CDK.
જ્યારે Cell cycle regulation, Cyclin-CDK complexes અથવા MPF(M-phase promoting factor) વિશે પ્રશ્ન આવે.
દા.ત.: પ્રશ્ન: MPF(ki formation માં કયું protein constant amount ધરાવે છે? → CDK. Cyclin concentration ઊંચક-ઉતર કરે છે.
G0 phase = Quiescent stage — active division કરતો નથી, પણ viable રહે છે (ત્યાં સુધી સુધી સિગ્નલ આવે). હેપ્લોઈડ સોમાટિક કોષ — ઉદાહરણ: અંગ્રેજીમાં 'haploid somatic cells' એ Mistake છે. Plantમાં haploid અંગો (ગોળા, સ્પોર) થાય, પણ animalમાં somatic cell હંમેશા diploid. યાદ રાખો: 'G0 = Not dead, just resting' અને 'Haploid somatic = rare (plants only like male gametophyte in angiosperms)'.
જ્યારે G0 phase અથવા haploid/diploid somatic cells વિશે પ્રશ્ન આવે.
દા.ત.: પ્રશ્ન: G0 phase વિશે કયું વિધાન સાચું છે? → 'Cells are metabolically active but not dividing.' (Dead નહિ, Resting છે.)
Mitosis માં Centrosome duplication G2 માં થાય છે, Microtubule organizing center(MTOC)/Centrosome migration to poles Prophase માં થાય છે. યાદ રાખો: 'Duplication in G2, Migration in Prophase'. જો પ્રશ્નમાં Centrosome duplication问时 → G2; Centromere division问时 → Anaphase.
જ્યારે કોષ વિભાજનમાં organelle duplication અને structural events નો સમય પૂછવામાં આવે.
દા.ત.: પ્રશ્ન: Centrosome duplication કયા સમયે થાય છે? → G2 phase. Prophase માં તે poles તરફ migrate થાય છે.
કોષ વિભાજનમાં કોષકેન્દ્ર( nucleus ) અને કોષકેન્દ્રિકા( nucleolus ) નું વર્તન: Prophase = Nuclear membrane disintegrates + Nucleolus disappears; Telophase = Nuclear membrane reforms + Nucleolus reappears. યાદ રાખો: 'PM = Perish in Prophase, Return in Telophase'. જો પ્રશ્નમાં 'Nuclear envelope breakdown' → Prophase; 'Reformation' → Telophase.
જ્યારે Prophase અને Telophase માં nuclear events વિશે પ્રશ્ન આવે.
દા.ત.: પ્રશ્ન: Nuclear membrane and nucleolus કયા ફેઝમાં ગાયબ થાય છે? → Prophase. Telophase માં पुनः appear થાય.
