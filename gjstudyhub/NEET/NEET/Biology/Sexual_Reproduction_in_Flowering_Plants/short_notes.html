📘 વ્યાખ્યાઓ

  • ફૂલ : સ્પોરાંજિયા ધરાવતું સંક્ષિપ્ત અક્ષ, જેની ઇચ્છા જૈવિક પ્રજનન છે.
  • પરાગણ : પરોગ્રાહી (પરાગરજ) ના સ્ત્રીબીજાણુદંડ (અંડકોષ) પર ઉતરાણ પ્રક્રિયા.
  • નિષેચન : પુરૂષ અને માદા ગેમેટના સંયોગથી ઝાયગોટ બનવાની પ્રક્રિયા.
  • દ્વિ-નિષેચન : એક пурষ સ્પર્મનું અંડકોષ સાથે, બીજો пурष સ્પર્મનું દ્વિધ્રુવીય કેન્દ્ર સાથે સંયોગ.
  • સમગ્રનિષેચન : ત્રણ ધ્રુવીય કેન્દ્ર + એક пурষ સ્પર્મ → ત્રિગુણક (3n) અંતઃસ્તર એન્ડોસ્પર્મ.
  • અર્ધગ્રંથીનિષેચન : ત્રણ ધ્રુવીય કેન્દ્ર + пурષ સ્પર્મ → ટ્રાયપ્લોઇડ એન્ડોસ્પર્મ; બીજકોષ + пурષ સ્પર્મ → ડિપ્લોઇડ ઝાયગોટ.
  • અંડાશય : સ્ત્રીપ્રજનનાંગ (ગાયનોસીઅમ) નો ફૂલ્લભાગ, જ્યાં અંડકોષોનું નિર્માણ થાય છે.
  • અંડકોષ : સ્ત્રીગેમેટોફાઇટ, સામાન્ય રીતે 7-કોષીય 8-ન્યુક્લિયસ યુક્ત.
  • સહાયક કોષ : અંડાશયની મીસલિયલ ટર્મિનસ પર આવેલા બે કોષ, પરાગકણ માર્ગદર્શનમાં મદદ કરે છે.
  • ધ્રુવીય કોષ : મીસલિયલ ટર્મિનસની તળિયે આવેલા બે કોષ, દ્વિ-નિષેચનમાં ભાગ લે છે.
  • એન્ટ્રોજની (એન્ડોસ્પર્મ) : નિષેચન પછી અંડાશયમાં બનતો પોષક કોષીય ભંડોળ.
  • એકોટિલેડન (એકબીજપત્રી) : એક લીફેટ (સીડકોટ) ધરાવતું બીજ, જેમ કે દાંડિયો.
  • ડાયકોટિલેડન (દ્વિબીજપત્રી) : બે લીફેટ ધરાવતું બીજ, જેમ કે રાઈ.
  • અપાઈમિક્સિસ : નિષેચન વિના બીજનો વિકાસ, એટલેકે અલિંગી પ્રજનન જેવી પ્રક્રિયા.
  • પોલીએમ્બ્રાયોની : એક બીજમાં એક કરતાં વધુ ઇમ્બ્રાયોનો વિકાસ.

⚡ સૂત્રો

  • દ્વિ-નિષેચન : સ્પર્મ₁ + અંડકોષ (n+n) → ઝાયગોટ (2n) ; સ્પર્મ₂ + 2 ધ્રુવીય કેન્દ્ર (n+2n) → ત્રિગુણક એન્ડોસ્પર્મ (3n)
  • ઉપર્યક્ત એન્ડોસ્પર્મ સૂત્ર : (n + n + n) = 3n
  • અંડકોષ સંખ્યા (monosporic) = 1 ; બેઝલ ધ્રુવીય કોષ સંખ્યા = 2
  • અંડાશય → ફળ ; અંડકોષ → બીજ ; અંતઃસ્તર → એન્ડોસ્પર્મ
  • પરાગકણ બાહ્યકોષ ( екзિન ) : સ્पोરોપોલેનિન, પ્રતિકૂલ પરિસ્થિતિઓમાં અનાવરક

⭐ મુખ્ય તથ્યો

  • પરોગ્રાહી એકલિંગી (monoecious) અથવા દ્વિલિંગી (dioecious) હોઈ શકે છે.
  • અંડકોષમાં સામાન્ય રીતે 3 ધ્રુવીય, 2 સહાયક, 1 અંડકોષ અને 3 કોષકાંઠા કોષ હોય છે.
  • પરાગકણ બે કોષીય અથવા ત્રિકોષીય હોઈ શકે છે; સમયે આધાર રાખે છે.
  • અંતઃસ્તર (endosperm) અન્નદ્રવ્યરૂપે બીજમાં સંગ્રહિત થાય છે.
  • પરાગકણ બાહ્યકોષ (экзिન) સ્पोરોપોલેનિનનું બનેલું હોય છે, જે અત્યંત પ્રતિકૂલ છે.
  • પરાગકણ અંકુરણ માટે નમ્રતા અને ઊષ્મા આવશ્યક છે.
  • અંડકોષનું અંતઃસ્તર સૂત્ર (7+8 સંરચના) સૌથી સામાન્ય 'પોલિમોરફ' પ્રકાર છે.
  • પરાગકણ-અંડકોષની ચોક્કસ અંગતતા (specificity) દ્વારા સંતતિની ગુણવત્તા નક્કી થાય છે.
  • અંડકોષનું ઝાયગોટ વિકાસ પામીને ઇમ્બ્રાયો બનાવે છે.
  • અંડકોષમાંથી અંતઃસ્તર બનાવે છે, જે બીજમાં પોષક તત્વોનો ભંડાર છે.
  • અંડાશય દીવાલ → ફળછાલ (pericarp) બને છે.
  • અંડકોષ આચ્છાદન (tegmen) → બીજછાલનો અંતઃસ્તર, બહિસ્તર → બીજછાલનો બહિસ્તર.
  • અંતઃસ્તરના વિભાજન (AP) : પ્રથમ વિભાજન પછી પણ 3n સ્તર જળવાઈ રહે છે.
  • પેરીએન્થ (બાહ્યપત્ર તથા અંતઃપત્ર) પરાગકણને આકર્ષે છે અને સંરક્ષણ પૂરું પાડે છે.
  • પરોગ્રાહીની રચના : પરાગરજ, પરાગદંડ, અંડકોષ, અંડાશય, ડંડું — બધા જ સમાવિષ્ટ છે.
  • સ્પોરાઇસ (sporopollenin) એ પરાગકણના બાહ્યકોષનું મુખ્ય ઘટક છે.
  • અંડકોષમાં 8 ન્યુક્લિયસ હોય છે, જે 7 કોષોમાં વિભાજિત થયા છે.
  • અંડકોષના મીસલિયલ ટર્મિનસ પર 2 સહાયક કોષ, 1 અંડકોષ અને 3 કોષકાંઠા કોષ આવેલા હોય છે.
  • અંડકોષના અન્ય ટર્મિનસ પર 3 ધ્રુવીય કોષ હોય છે.
  • પરોગ્રાહીમાં પરાગકણ અને અંડકોષ એકસાથે વિકસે છે, પરંતુ સમયગાળો અલગ હોઈ શકે છે.
  • અંડકોષનું ઝાયગોટ 8-કોષીય પાંચકોષીય (8-nucleate) અવસ્થામાંથી વિકસે છે.
  • અંડકોષ વિકાસ દરમિયાન સાઇટોપ્લાઝમ વિભાજન થાય છે, ન્યુક્લિયસ વિકાસ પામે છે.
  • પરોગ્રાહીમાં સ્ત્રી-પુરુષ ગેમેટોફાઇટ વચ્ચે રચનાત્મક સંબંધ હોય છે.
  • અંડકોષનું મીસલિયલ ટર્મિનસ સામાન્ય રીતે અંડાશયની તળિયે હોય છે.

⚠️ સામાન્ય ભૂલો

  • અંડકોષ એ ઝાયગોટ નથી; ઝાયગોટ અંડકોષમાંથી બને છે.
  • એન્ડોસ્પર્મ ત્રિગુણક (3n) હોય છે, બેગુણક (2n) નહીં.
  • અંડકોષ એકકોષીય ગેમેટ છે, સહાયક કોષો ગેમેટ નથી.
  • પરાગકણ સ્પોરોપોલેનિનથી રક્ષિત છે, નાસ્પોરોપોલેનિનથી નહીં.
  • અંડકોષ 7-કોષીય છે, 7-ન્યુક્લિયસ નહીં — 8 ન્યુક્લિયસ છે.
  • અંડકોષ એ સ્ત્રીગેમેટોફાઇટ છે, અંડકોષ નહીં.
  • અંડકોષના અન્ય ટર્મિનસ પર 3 ધ્રુવીય કોષ હોય છે, સહાયક કોષ નહીં.
  • પરાગકણ પરાગદંડ પર વિકસે છે, અંડકોષ અંડાશયમાં.
  • અંડકોષમાંથી અંતઃસ્તર બને છે, બીજથી નહીં.
  • અંડકોષનો ઝાયગોટ ડિપ્લોઇડ (2n) છે, એન્ડોસ્પર્મ ત્રિગુણક (3n).
  • અંડકોષ માત્ર એક જ પરાગકણ દ્વારા નિષેચિત થઈ શકે છે.
  • અંડકોષના અન્ય ટર્મિનસ પર 3 ધ્રુવીય કોષ હોય છે, સહાયક કોષ નહીં.
  • અંડકોષ એકકોષીય ગેમેટ છે, સહાયક કોષો ગેમેટ નથી.
  • પરાગકણ સ્पोरोपોલેનિનથી રક્ષિત છે, નાસ્पोરополининથી નહીં.
  • અંડકોષ 7-કોષીય છે, 7-ન્યુક્લિયસ નહીં — 8 ન્યુક્લિયસ છે.
