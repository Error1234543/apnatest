🧠 યાદ રાખો

કશેરુક સ્તંભમાં: કંડરાયુ = 7, મૂર્ધન્ય = 1, શીર્ષા = 1, ત્રિક = 5, પૂંછડી = 4; કુલ = 26.
સ્તનધારીઓમાં હાડકાંની કુલ સંખ્યા = ૨૦૬.
લઘુગ્રંથિ ગોળા (Pectoral girdle): ક્લેવિકલ + સ્કેપ્યુલા; મહાગ્રંથિ ગોળા (Pelvic girdle): આઈલિયમ + ઇશિયમ + અપ્પટાઇસ.
ઉગમેન્ટ = હાડકું-હાડકું જોડે છે; લિગામેન્ટ = અસ્થિ + અસ્થિ જોડે છે; તંતુકાર પટલ = કાર્ટિલેજ.
હાયલિન કાર્ટિલેજ જોડાણના સંયોજનમાં (ઉદા. જમ્પુ સામે), ફાઇબર કાર્ટિલેજ ડિસ્કમાં.
મહાગ્રંથિ ગોળો અંગાથની યુગ્મ હાડકાંથી બનેલો છે.
સ્નાયુની સંકોચનકારી એકમ = સારકોમેર; Z-રેખા થી Z-રેખા વચ્ચેનો વિસ્તાર.

⚡ ઝડપી સૂત્રો

સારકોમેર ક્રમ: A-બેન્ડ + I-બેન્ડ + H-ઝોન.
સ્નાયુ સંકોચન સમયે: H-ઝોન ઘટે/લુપ્ત થાય, I-બેન્ડ ઘટે, Z-રેખાઓ નજીક આવે; A-બેન્ડની લંબાઈ અચળ.

✅ વન-લાઈનર્સ

હાડકાં મુખ્યત્વે K₃(PO₄)₃ કેલ્શિયમ ફોસ્ફેટ સ્વરૂપે હોય છે; ઓર્ગેનિક ઘટક = ઓસ્ટિઓઇડ (કોલેજન).
ક્રેનિયમના 8 ઉપલા (મેનિન્જિયલ) + 6 તળિયાના (Facial) હાડકાં.
કોષ્ટકવિવરણ (Sternum): પ્રોપ્રાયેટર્સ (Manubrium) + કોર્પસ + Xyphoid — કુલ 3 ભાગ.
પૂંછડીવાળા સસ્તન પ્રાણીમાં કશેરુક (Coccyx) = 4 સંલગ્ન હોય છે.
સ્તનધારીમાં દંતકલ્લ (Dental calyx) = દ્વિધરાટી / દ્વિચક્રી દંતવ્યવસ્થા.
જોડાણ પ્રકાર: ચાલુ (Synarthrosis), અર્ધચાલુ (Amphiarthrosis), સંપૂર્ણ ચાલુ (Diarthrosis / Synovial).
બાંધેલી (Ball and socket) જોડાણ: ઊંઠ-બાજુ (Shoulder); કંડરાયુ-પાર્શ્વ જોડાણ; ઘૂંટણ (Knee) = કટિગ્નિતા (Hinge).
સ્નાયુ તંતુ પર સ્નાયુપટલ (Sarcolemma), સાइटોપ્લાઝમ = સારકોપ્લાઝમ, SER = સારકોપ્લાઝમિક રેટિક્યુલમ.
Sarcofilament: Thinnin (Actin) = I-બેન્ડ + A-બેન્ડનો મધ્યભાગ; Thick (Myosin) = A-બેન્ડ.
Sarcofilamentની વચ્ચે Myosin શીર્ષ હશે જે ATPase એન્ઝાઇમ ધરાવે છે — આથી Sarcoplasmic Reticulum માં Ca²⁺ મુક્ત કરે છે.
સ્નાયુ સંકોચન મુખ્યત્વે Sliding Filament Theory દ્વારા થાય છે; H-Zone ઘટે છે, I-Band ઘટે છે, A-Band અચળ રહે છે.
સંકોચન માટે ATP + Ca²⁺ + Troponin સંક્રમણ જરૂરી છે.
Troponin → Actin પર Ca²⁺ બંધાય છે; Tropomyosin છૂટું પડે છે અને Myosin શીર્ષ Actin સાથે મિલે છે.
Muscle tone = શારીરિક સ્થિર સંકોચન; Rigor mortis = મૃત્યુ પછી Ca²⁺ મુક્તિને કારણે સ્નાયુ સખ્ત થઈ જાય છે.
Osteoporosis = હાડકાંમાં કેલ્શિયમ ઘટી જતાં ભંગુરતા; Gout (Gouty arthritis) = Yuric acid ના ટાકના કારણે.
Myasthenia gravis = Autoimmune રોગ જ્યાં Neuromuscular junction પર Acetylcholine receptors તૂટે છે.
