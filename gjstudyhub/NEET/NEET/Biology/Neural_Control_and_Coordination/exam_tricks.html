🎯 પરીક્ષા ટ્રિક્સ

Na⁺ વધારે → શુન્યબિંદુ ઉપર; K⁺ વધારે → શુન્યબિંદુ નીચે — બંનેનો પ્રભાવ વિપરીત છે.
જ્યારે પ્રશ્નમાં બહિઃકોષીય Na⁺ અથવા K⁺ સાંદ્રતા બદલાઈ હોય ત્યારે વિરામ સ્થિતિપOTential (Resting Potential) પર થતા ફેરફારનું વિશ્લેષણ કરવું હોય.
દા.ત.: બહિઃકોષીય Na⁺ ઘટાડવાથી રેસ્ટિંગ પોટેન્શિયલ -70 mVથી વધુ ઋણ (ઉદા. -75 mV) થાય છે કારણ કે Na⁺નું અંદર આવવાનું ઝઠકું ઓછું થાય.
ઉત્તેજનાનું દળ (Intensity) → એક્શન પોટેન્શિયલની આવૃત્તિ વધારે, પણ આયનોનું પ્રમાણ વધતું નથી — 'All-or-None' નિયમ કડક.
જ્યારે પ્રશ્ન પૂછે કે 'તીવ્ર ઉત્તેજનાથી એક્શન પોટેન્શિયલનું આયન પ્રવાહ વધે છે?' ત્યારે તરત નકારી શકાય.
દા.ત.: તીવ્ર ઉત્તેજનામાં એક્શન પોટેન્શિયલની સંખ્યા (frequency) વધે, પણ દરેક APમાં Na⁺/K⁺નું પ્રમાણ સમાન રહે છે.
માયલિન યુક્ત તંતુઓમાં σ (સેગમેન્ટ) લંબાઈ + 1 = રેહેહોડ નોડની સંખ્યા; σ = 1 મીમી માટે 200 ગુણ ગતિ.
જ્યારે પ્રશ્નમાં માયલિન યુક્ત/અમાયલિન તંતુઓના વાહન વેગનું સરખામણી પૂછવામાં આવે અને ગણતરી જોઈતી હોય.
દા.ત.: 100 મીમી લાંબા માયલિન યુક્ત તંતુમાં રેહેહોડ નોડ ≈ 100/1 + 1 = 101; અમાયલિન તંતુમાં વાહન વેગ ~1 m/s, માયલિન યુક્ત ~100 m/s.
ક્ષારક વિષમકોષ (Chemoreceptor) → CO₂ વધારો → CSF pH ઘટે → શ્વસન કેન્દ્ર પ્રેરિત; O₂ સીધું અસર કરતું નથી.
જ્યારે શ્વસન પર CO₂ vs O₂ની અસર વિશે પ્રશ્ન આવે અને વિદ્યાર્થી ગડबड અનુભવે.
દા.ત.: રક્તમાં CO₂ વધવાથી શ્વસન વધે છે, પણ O₂ ઘટવાથી સીધું શ્વસન કેન્દ્ર પ્રભાવિત થતું નથી; O₂ ચેમોરીસેપ્ટર્સ દ્વારા સંકેત મોકલે છે.
પ્રતિવર્ત (Reflex) → સેન્ટ્રલ નર્વસ સિસ્ટમમાંથી અસંયોજિત; પ્રતિવર્ત દોરડું (Arc) → સેન્સર, મોટર, ઇન્ટરનીયોન.
જ્યારે પ્રતિવર્તની પ્રકૃતિ અથવા પ્રતિવર્ત દોરડાના ખંડો વિશે પ્રશ્ન આવે.
દા.ત.: પટક પ્રતિવર્ત (Knee-jerk) એકસિનાપ્ટિક છે; કામખાત પ્રતિવર્ત (Withdrawal) ઇન્ટરનીયોન ધરાવે છે, તેથી ધીમો.
મગજના વિસ્તારનો કાર્ય-નક્કીકરણ: હાયપોથેલામસ → ભાવના/ઉષ્મા; સેરિબેલમ → સંતુલન/સ્નાયુ સહકાર; બ્રેઈનસ્ટેમ → જીવનરક્ષક.
જ્યારે મગજના વિવિધ ભાગોના કાર્યો મિશ્રિત હોય અને વિદ્યાર્થી ભ્રમિત થઈ જાય.
દા.ત.: હાયપોથેલામસ શરીરના તાપમાનનું નિયંત્રણ કરે છે; સેરિબેલમ હાવી/પગની ચાલમાં સંતુલન રાખે છે; બ્રેઈનસ્ટેમ શ્વસન/હૃદય ગતિ નિયંત્રિત કરે છે.
લિમ્બિક સિસ્ટમ → ભાવનાત્મક ચિત્રણ; હિપ્પોકૉમ્પસ → સ્મૃતિ રચના. 'લિમ્બિક' શબ્દનો અર્થ 'કંધ' (border).
જ્યારે ભાવના તથા સ્મૃતિ સંબંધિત પ્રશ્નો આવે.
દા.ત.: હિપ્પોકૉમ્પસની ઈજાથી નવી સ્મૃતિ બનાવી શકાતી નથી, પણ જૂની સ્મૃતિઓ રહે છે.
પ્રેરાક (Excitatory) સાઈનેપ્સ → Na⁺ અંદર; દમનકારી (Inhibitory) → Cl⁻ અંદર અથવા K⁺ બહાર. બંનેનો વિપરીત પ્રભાવ.
જ્યારે સાઈનેપ્ટિક સંચારમાં ઈOnChange neurotransmitterની અસર વિશે પ્રશ્ન હોય.
દા.ત.: GABA (inhibitory) Cl⁻ ચેનલ ખોલે છે → ક્લાઈડિંગ પોટેન્શિયલ; Glutamate (excitatory) Na⁺ ચેનલ ખોલે છે → ડિપોલાઇઝેશન.
મંથન (Eye) — અંતઃપટલ (Retina) માં શંકુ (Cones) → રંગ/તીક્ષ્ણ દર્શન; યષ્ટિકા (Rods) → કોમળ/રાત્રિ. 'સીધો' = શંકુ, 'ચેપરો' = યષ્ટિકા.
જ્યારે આંખની રચના તથા દર્શન વિશે પ્રશ્ન આવે અને વિદ્યાર્થી શંકુ/યષ્ટિકા સમજે નહીં.
દા.ત.: રાત્રિમાં દર્શન યષ્ટિકાઓ પર; દિવસે તથા રંગ દર્શન શંકુઓ પર. ફોવિયામાં શંકુઓ જ હોય છે, યષ્ટિકાઓ નથી.
કર્ણ (Ear) — સ્કેલા ટેક્ટોરિયાલ તરલ (Tectorial membrane) → Cilia સparsh → Na⁺ અંદર → ઉત્તેજના. 'સ્કેલા' = શ્વાસ (sound).
જ્યારે કર્ણમાં ધ્વનિ રૂપાંતરણ (Transduction) વિશે પ્રશ્ન આવે.
દા.ત.: ધ્વનિ તરંગોથી Cochleaમાં બેસિલર પટલની કંપન → hair cellsના Cilia સ્કેલા ટેક્ટોરિયાલ સાથે રગડાય → Na⁺ પ્રવેશ → પ્રેરક પોટેન્શિયલ.
