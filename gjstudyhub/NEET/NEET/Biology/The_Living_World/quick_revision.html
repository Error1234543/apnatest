જીવંત સ્વર્લોક — કુિક રિવિઝન શીટ (NEET UG)

🩺 NEET UG — Gujarati • Biology • The Living World

🧠 યાદ રાખો

જીવંત સજીવોની પ્રમુખ લક્ષણો: વૃદ્ધિ (_growth_), પ્રજનન, ચયાપચય, કોષીય સંરચના અને આત્મચેતના.
અકોષિક (Non-cellular) જીવંત એકમ: વિષાણુ (Virus); કોષ ગઠનનો એકમાત્ર એકમ.
વૃદ્ધિ માત્ર જીવંતમાં જ દેખાય છે; બહિર્વૃદ્ધિ (આસંચન) અજીવમાં જોવા મળે છે.
પ્રજનન પણ જીવંતનું લક્ષણ છે, પણ તે વૃદ્ધિ નથી.
ચયાપચય (Metabolism) એ તમામ જીવંતનો સર્વસાધારણ લક્ષણ છે.
ICBN = International Code of Botanical Nomenclature — છોડોના નામકરણનો આંતરરાષ્ટ્રીય કોડ.
ICZN = International Code of Zoological Nomenclature — પ્રાણીઓના નામકરણનો આંતરરાષ્ટ્રીય કોડ.
કેરોલસ લિનિયસ (Carolus Linnaeus) ને 'ટૉક્સોનોમીના પિતા' ગણાય છે.
ટૉક્સોનોમેટ્રિક ગુણક્રમ: રાષ્ટ્ર (Kingdom) → ડિવિઝન/વાર્ગ (Phylum/Division) → વર્ગ (Class) → ક્રમ (Order) → પરિવાર (Family) → ગણ (Genus) → પ્રજાતિ (Species).
પ્રજાતિ (Species) એ ટૉક્સોનોમિક કક્ષાની સૌથી ઘટીયા (fundamental) એકમ છે.
પ્રત્યેક ગણ (Genus) એક કરતાં વધુ પ્રજાતિઓ ધરાવી શકે છે; પણ પ્રત્યેક પ્રજાતિ ફકત એક જ ગણમાં હોય છે.
ટૉક્સોનોમિક સહાયક સાધનો: હર્બેરિયમ, બોટેનિકલ ગાર્ડન, મ્યુઝિયમ,ઝૂલોજિકલ પાર્ક, સૂત્ર (Key), ફ્લોરા, હેન્ડબુક અને મોનોગ્રાફ્સ.

⚡ ઝડપી સૂત્રો

બાયનોમિયલ નામકરણ સૂત્ર: Genus (વડું અક્ષર) + specific epithet (હીનાક્ષર) — ઉદા. Mangifera indica.
ટૉક્સોનોમિક કક્ષાઓનો ગુણક્રમ (ઉપરથી નીચે): Kingdom → Phylum/Division → Class → Order → Family → Genus → Species.

✅ વન-લાઈનર્સ

હર્બેરિયમમાં સૂકવેલા છોડોના નમૂના (Specimens) સંગ્રહિત કરવામાં આવે છે.
બોટેનિકલ ગાર્ડનમાં જીવંત છોડોનું સંગ્રહણ થાય છે — ઉદા. કેવી (Kew) બોટેનિકલ ગાર્ડન, કોલકતા.
મ્યુઝિયમમાં સ્કેલિંગ, અસ્થિપંજર, ભક્ષણ કરેલા નમૂના અને પ્રાણીઓના નમૂના (જિપ્સી/સ્ટ્રક્ચર્ડ) સંગ્રહિત થાય છે.
ઝૂલોજિકલ પાર્ક (Zoological Park) માં જીવંત પ્રાણીઓને મુક્ત પરિસરમાં રાખવામાં આવે છે — ઉદા. ઝૂલોજિકલ સર્વે ઓફ ઇન્ડિયા (ZSI).
સૂત્ર (Key) એ જોડિયા લક્ષણોના આધારે સજીવોને ઓળખવાની રચના છે.
ફ્લોરા પુસ્તકોમાં કોઈ પણ પ્રદેશના સ્થાનિક છોડોની માહિતી હોય છે.
માનવ શરીરમાં પ્રત્યેક ક્ષણે ∼100 કરોડ ચયાપચયીય પ્રક્રિયાઓ ચાલુ હોય છે.
જૈવવૈવિધ્ય (Biodiversity) એ ધરતી પરના તમામ જીવંત સજીવોની વિવિધતાનું કુલ નામ છે.
શ્રેણીવિભાજન (Classification) એ સજીવોમાં સામાન્ય અને ભિન્ન લક્ષણોના આધારે વર્ગીકરણ છે.
ટૉક્સોનોમી શબ્દ પ્રથમ વાર એન્જલર્ટ અને પ્રૅટિટ્સ (Engler & Prantl) દ્વારા વપરાયો હતો.
