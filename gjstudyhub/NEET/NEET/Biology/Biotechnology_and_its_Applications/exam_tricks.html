🩺 NEET UG — Gujarati • Biology • Biotechnology and its Applications

🎯 પરીક્ષા ટ્રિક્સ

Bt = Bacillus thuringiensis → Cry પ્રોટીન → બોલવર્મ/બીટલ વિરોધી. 'Bt' શબ્દ જો દેખાય, તો તરત 'Cry પ્રોટીન' અને 'બેસિલસ થ્યુરિન્જિએન્સિસ' સાથે જોડો.
જ્યારે પ્રશ્નમાં Bt પાક, Bt કોટન અથવા Bt ટોક્સિન વિશે પૂછવામાં આવે.
દા.ત.: Bt કોટન કયા કીટક વિરુદ્ધ સક્રિય છે? → બોલવર્મ (bollworm). વિકલ્પોમાં 'stem borer' હોય તો તે ખોટું છે.
Cry પ્રોટીન અક્રિયાશીલ 'protoxin' રૂપે બેક્ટેરિયામાં હોય છે; કીટકના ક્ષારકીય (alkaline) આંતરવાહિનીમાં સક્રિય થાય છે. યાદ રાખો: 'Protoxin → Alkaline gut → Active toxin'.
જ્યારે પ્રશ્ન Cry પ્રોટીનની સક્રિયકરણ પ્રક્રિયા અથવા protoxin વિશે પૂછે.
દા.ત.: Cry પ્રોટીન ક્યાં સક્રિય થાય? → કીટકની આંતરવાહિની (midgut) માં, ક્ષારકીય pH પર.
RNAi = RNA interference = જનીન મૂકવું (gene silencing) = સંપૂરક mRNA સાથે બંધાય છે. યાદ રાખો: 'RNAi → small RNA → mRNA block → no protein'.
જ્યારે RNAi, જનીન મૂકવું, અથવા nematode વિરોધી પાક વિશે પ્રશ્ન આવે.
દા.ત.: RNAi દ્વારા કઈ નેમેટોડ વિરુદ્ધ સંયોજક પાક બનાવવામાં આવ્યો? → Meloidogyne incognita (tobacco root-knot nematode) વિરુદ્ધ તંબાકુ.
Agrobacterium tumefaciens = Ti plasmid = plant genetic engineering નો મુખ્ય વેક્ટર. 'Ti' = Tumor-inducing. યાદ રાખો: 'Agro → Ti → gene gun નહીં, plasmid vector'.
જ્યારે transgenic plant બનાવવાના વેક્ટર અથવા Agrobacterium વિશે પૂછવામાં આવે.
દા.ત.: કયો જીવ પાદપ જનીન ઇજનેરીમાં વેક્ટર તરીકે વપરાય? → Agrobacterium tumefaciens (Ti plasmid).
ELISA = Enzyme-Linked Immunosorbent Assay = antigen/antibody શોધ. PCR = polymerase chain reaction = DNA amplification. બંનેમાં 'enzyme' છે પણ કામ અલગ: ELISA = immunology, PCR = DNA copy.
જ્યારે molecular diagnostics અથવા diagnostic techniques વિશે પ્રશ્ન આવે અને ELISA vs PCR ભ્રમ થાય.
દા.ત.: HIV શોધવા માટે કઈ પદ્ધતિ? → ELISA (antibody/antigen detection). DNA copy કરવા માટે? → PCR.
Insulin (Humulin) = recombinant E. coli માં બને. A અને B 체ઇન અલગ અલગ પ્લાઝમિડમાં બનાવી પછી જોડી. યાદ રાખો: 'Insulin → E. coli → recombinant → A+B chain'.
જ્યારે insulin ના ઉત્પાદન અથવા recombinant insulin વિશે પ્રશ્ન આવે.
દા.ત.: Humulin ક્યાંથી મળે? → recombinant E. coli માં A અને B 체ઇન અલગ બનાવી disulfide bond વડે જોડી.
PCR ના 3 સ્ટેપ: Denaturation (94°C) → Annealing (54°C) → Extension (72°C). યાદ રાખો: '94-54-72 = Denature-Anneal-Extend'. Taq polymerase = Thermus aquaticus માંથી.
જ્યારે PCR cycles, temperature અથવા Taq polymerase વિશે પ્રશ્ન આવે.
દા.ત.: Taq polymerase કયા જીવમાંથી મળે? → Thermus aquaticus. Extension step નું તાપમાન? → 72°C.
Bt કોટન = bollworm વિરુદ્ધ; Bt ધાન = stem borer વિરુદ્ધ. 'Cotton → boll, Rice → stem' યાદ રાખો.
જ્યારે વિવિધ Bt પાક અને તેમના લક્ષ્ય કીટકો વિશે પ્રશ્ન આવે.
દા.ત.: Bt ધાન કયા કીટક વિરુદ્ધ સંયોજક છે? → Stem borer. Bt કોટન? → Bollworm.
Gene therapy = જનીન ચિકિત્સા = defective gene ને functional gene વડે બદલવો. પ્રથમ ક્લિનિકલ ટ્રાયલ = SCID (Severe Combined Immunodeficiency) પર 1990 માં. યાદ રાખો: 'Gene therapy → SCID → 1990 → first clinical trial'.
જ્યારે gene therapy ની શરૂઆત અથવા તેના અનુપ્રયોગો વિશે પ્રશ્ન આવે.
દા.ત.: પ્રથમ gene therapy ક્લિનિકલ ટ્રાયલ કયા રોગ પર થયો? → SCID (adenosine deaminase deficiency).
Biopiracy = દેશી જૈવિક સંસાધનો/પરંપરાગત જ્ઈાન પર બિન-દેશી કંપનીઓ દ્વારા પેટન્ટ. યાદ રાખો: 'Biopiracy = theft of bio-resources by foreign entities'. ઇન્ડિયન બાસમેટી રાઇસ અને નિમ્બુ ઉદાહરણો.
જ્યારે biopiracy, patent અથવા જૈવિક ચોરી વિશે પ્રશ્ન આવે.
દા.ત.: બાસમેટી રાઇસ પર અમેરિકન કંપનીએ પેટન્ટ લીધું — આ કઈ ઘટના છે? → Biopiracy.
Bt toxin નો કાર્યપદ્ધતિ: protoxin → alkaline gut → active toxin → bind to midgut epithelial cells → pore formation → cell swelling & lysis → insect death. યાદ રાખો: 'Protoxin → Alkaline → Pore → Lysis'.
જ્યારે Bt toxin ની કાર્યપદ્ધતિ (mode of action) વિશે વિગતવાર પ્રશ્ન આવે.
દા.ત.: Bt toxin કીટકની કઈ કોષિકાને નુકસાન પહોંચાડે? → Midgut epithelial cells (પોર બનાવે છે).
Transgenic animals = તેજસ્વી પ્રાણી (fluorescent protein) અથવા disease model. યાદ રાખો: 'Transgenic mouse → disease model; Transgenic fish → glow'.
જ્યારે transgenic animals અને તેમના ઉદાહરણો વિશે પ્રશ્ન આવે.
દા.ત.: Transgenic mouse કયા ઉદ્દેશ્યથી બનાવવામાં આવે? → Disease model (કેન્સર, cystic fibrosis વગેરે અભ્યાસ).
Cry પ્રોટીનના પ્રકાર: CryAc = bollworm, CryIb = corn borer, CryII = armyworm. 'Ac → Cotton boll, Ib → Corn' યાદ રાખો.
જ્યારે વિવિધ Cry પ્રોટીન અને તેમના લક્ષ્ય કીટકો વિશે પ્રશ્ન આવે.
દા.ત.: CryAc પ્રોટીન કયા કીટક વિરુદ્ધ સક્રિય? → Bollworm (પાટલી વર્મ).
Molecular diagnostics: PCR = DNA amplification, ELISA = antigen/antibody detection, Southern blot = DNA, Northern blot = RNA, Western blot = protein. યાદ રાખો: 'DNA→PCR/Southern, RNA→Northern, Protein→Western, Immune→ELISA'.
જ્યારે different molecular diagnostic techniques વચ્ચે ભેદ કરવાનો પ્રશ્ન આવે.
દા.ત.: કઈ પદ્ધતિ RNA શોધે? → Northern blot. કઈ protein શોધે? → Western blot.
Bt પાકમાં Cry જનીન Agrobacterium દ્વારા પાદપમાં દાખલ કરવામાં આવે. યાદ રાખો: 'Bt gene → Agro vector → plant cell → transgenic plant'.
જ્યારે transgenic plant બનાવવાની પ્રક્રિયા અથવા Bt પાક તૈયારી વિશે પ્રશ્ન આવે.
દા.ત.: Bt કોટન બનાવવા માટે કયો વેક્ટર વપરાય? → Agrobacterium tumefaciens (Ti plasmid).
