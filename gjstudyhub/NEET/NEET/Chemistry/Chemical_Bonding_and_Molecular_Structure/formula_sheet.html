⚡ સૂત્રો

આયનીય બંધની ઇલેક્ટ્રોન વિન્યાસ પ્રક્રિયા: M → M⁺ + e⁻ ; X + e⁻ → X⁻ ; M⁺ + X⁻ → MX
M = ધાતુ પરમાણુ ; X = અધાતુ પરમાણુ ; e⁻ = ઇલેક્ટ્રોન · SI: N/A · જ્યારે ઇલેક્ટ્રોન્હદર (EN) તફાવત > ૧.૭ હોય
બંધ એન્થાલ્પી (Bond Enthalpy): ΔH_rxn = Σ D(bonds broken) − Σ D(bonds formed)
D = બંધ વિયોજન ઉર્જા (kJ/mol) ; બંધ તૂટતા પડે તે ઉર્જા ધન ; નવા બંધ બનતા ઉર્જા મુક્ત થાય · SI: kJ mol⁻¹ અથવા J mol⁻¹ · ગેસ-તબક્કાની પ્રક્રિયાઓ માટે, STP પાસે
બંધ ક્રમ (Bond Order) — આણ્વીય કક્ષક સિદ્ધાંત મુજબ: BO = (N_b − N_a) / 2
N_b = બંધકારક કક્ષકમાં ઇલેક્ટ્રોન્સની સંખ્યા ; N_a = વિપ્રકર્ષક (એન્ટીબંડિંગ) કક્ષકમાં ઇલેક્ટ્રોન્સની સંખ્યા · SI: મુક્ત એકમ · MO સિદ્ધાંત લાગુ પડતું હોય ત્યારે, બધા આણ્વો/આયનો
બંધ ક્રમ અને બંધ લંબાઈનો સંબંધ: બંધ લંબાઈ ∝ 1 / BO
BO વધે તો બંધ લંબાઈ ઘટે છે ; BO = 1 : એકલ બંધ ; BO = 2 : દ્વિબંધ ; BO = 3 : ત્રિબંધ · SI: pm અથવા Å · સમાન પ્રકારના પરમાણુઓ વચ્ચેના બંધનો સરખામણી કરતી વખતે
બંધ ક્રમ અને અણુની સ્થિરતા: જો BO > 0 → અણુ સ્થિર ; જો BO = 0 → અણુ અસ્થિર / અસ્તિત્વ નાખી શકાય
BO = બંધ ક્રમ · SI: — · MO સિદ્ધાંત મુજબ અણુઓ/આયનોની સ્થિરતા આગાહી કરવા
બંધ ક્રમ અને ચુંબકીય ગુણધર્મ: અયુગ્મિત ઇલેક્ટ્રોન存在 → કુચુંબકીય (paramagnetic) ; બધા ઇલેક્ટ્રોનયુગ્મિત → પ્રતિકુચુંબકીય (diamagnetic)
અયુગ્મિત ઇલેક્ટ્રોન = unbonded electron in MO · SI: — · MO આલેખન પરથી ચુંબકીય ગુણધર્મ નક્કી કરવા
અઆવર્તકતા (Percent Ionic Character) — પોલીંગ સૂત્ર (EN તફાવત પરથી): % Ionic character = [1 − exp(−(Δχ)² / 4)] × 100
Δχ = બે પરમાણુઓ વચ્ચેનો વિદ્યુતઋણતા તફાવત (Pauling scale) ; e = પ્રાકૃતિક લઘુગણકનો આધાર (~2.718) · SI: શતકડા (%) · પોલીંગનું અંદાજિત સૂત્ર, સામાન્ય ઉપયોગ માટે
અઆવર્તકતા — હેની-સ્મિથ (Hannay-Smyth) સૂત્ર: % Ionic character = 16·|Δχ| + 3.5·(Δχ)²
Δχ = વિદ્યુતઋણતા તફાવત · SI: શતકડા (%) · વધુ ચોકસાઈવાળું અંદાજ, Δχ > 0 માટે
આચરણ મુહૂર્ત (Observed Dipole Moment) અને સૈદ્ધાંતિક મુહૂર્ત વચ્ચે અઆવર્તકતા: % Ionic character = (μ_obs / μ_calc) × 100
μ_obs = પ્રાયોગિક/આચરણ મુહૂર્ત ; μ_calc = સંપૂર્ણ આયનીય બંધ ધારીને ગણતરી કરેલ મુહૂર્ત = e × d (e = 1.602×10⁻¹⁹ C, d = બંધ લંબાઈ m માં) · SI: Cm અથવા Debye (D) ; 1 D = 3.336 × 10⁻³⁰ Cm · દ્વિ-પરમાણ્વીય અણુ માટે
વિદ્યુતદ્વિધ્રુવ મુહૂર્ત (Dipole Moment): μ = q × d
q = વિદ્યુતભાર (C) ; d = ભાર કેન્દ્રો વચ્ચેનું અંતર (m) · SI: Cm (કુલોમ·મીટર) ; રૂપાંતરણ: 1 D = 3.336 × 10⁻³⁰ Cm · કોઈપણ ધ્રુવીય બંધ/અણુ માટે
અણુનું કુલ વિદ્યુતદ્વિધ્રુવ મુહૂર્ત (વેક્ટર સરવાળો): μ_total = √[μ₁² + μ₂² + 2μ₁μ₂cosθ]
μ₁, μ₂ = બે બંધ મુહૂર્તો ; θ = બંધો વચ્ચેનો ખૂણો · SI: D અથવા Cm · બે ધ્રુવીય બંધ ધરાવતા ત્રિ-પરમાણ્વીય/અણુ માટે
સમમિત બે ધ્રુવીય બંધ — સાદુરૂપ (ખાસ કેસ): μ_total = 2μ cos(θ/2)
μ₁ = μ₂ = μ ; θ = બંધો વચ્ચેનો ખૂણો · SI: D અથવા Cm · જ્યારે બંને બંધ મુહૂર્તોનું માન સમાન હોય (ઉદા. H₂O, θ = 104.5°)
બોન્ડ એન્જલ (Bond Angle) — VSEPR આધારિત: આદર્શ ज्यामिति પરથી: ચતુષ્ફલકીય = 109.5° ; સમતલીય ત્રિકોણીય = 120° ; રેખીય = 180° ; અष्टफलकીय = 90°
VSEPR મોડેલ મુજબ ઇલેક્ટ્રોન યુગ્મો વચ્ચેનો ન્યૂનતમ અપાકર્ષણ ખૂણો · SI: ડિગ્રી (°) · બધા ઇલેક્ટ્રોન યુગ્મો સમાન હોય ત્યારે; અયુગ્મિત યુગ્મ (LP) હોય તો LP-BP અપાકર્ષણ → ખૂણો ઘટે
અયુગ્મિત યુગ્મ પ્રભાવ (VSEPR ખૂણા ઘટાડો): ખૂણા ઘટાડો: BP-BP < LP-BP < LP-LP (અપાકર્ષણ ક્રમ)
BP = બંધકારક યુગ્મ ; LP = અયુગ્મિત યુગ્મ · SI: — · અયુગ્મિત યુગ્મ હોય ત્યારે આદર્શ ખૂણા કરતા ખૂણો ઘટે છે
હybridકરણ (Hybridization) અને કક્ષકો: sp: 1s + 1p → 2 sp કક્ષક (180°) ; sp²: 1s + 2p → 3 sp² (120°) ; sp³: 1s + 3p → 4 sp³ (109.5°) ; sp³d: 5 કક્ષક (TBP) ; sp³d²: 6 કક્ષક (OCT)
કક્ષક સંખ્યા = સિગ્મા બંધ + અયુગ્મિત યુગ્મની સંખ્યા (સ્ટેરિક નંબર) · SI: — · VSEPR સ્ટેરિક નંબર (SN) પરથી hybridકરણ નક્કી કરવા
SN (સ્ટેરિક નંબર) પરથી hybridકરણ: SN = 2 → sp ; SN = 3 → sp² ; SN = 4 → sp³ ; SN = 5 → sp³d ; SN = 6 → sp³d²
SN = (σ બંધોની સંખ્યા) + (કેન્દ્રીય પરમાણુ પરના અયુગ્મિત ઇલેક્ટ્રોન યુગ્મો) · SI: — · VSEPR/ hybridકરણ નક્કી કરવા
π બંધો અને σ બંધોની ગણતરી (MO સિદ્ધાંત): એકલ બંધ = 1 σ ; દ્વિબંધ = 1 σ + 1 π ; ત્રિબંધ = 1 σ + 2 π
σ = સિગ્મા બંધ ; π = પાય (પાઇ) બંધ · SI: — · લુઈસ રચના/MO આલેખન પરથી બંધ ગણતરી
દ્વિધ્રુવ મુહૂર્ત અને ધ્રુવીયતા (પોલારિટી): μ = 0 → અધ્રુવીય અણુ ; μ > 0 → ધ્રુવીય અણુ
μ = વિદ્યુતદ્વિધ્રુવ મુહૂર્ત · SI: D અથવા Cm · અણુની સંમિતિ અને બંધ મુહૂર્તોના વેક્ટર સરવાળા પર આધારિત
એન્જલ ઘટાડો — અયુગ્મિત યુગ્મની અસર (VSEPR અંદાજ): CH₄ (sp³, બધા BP) = 109.5° ; NH₃ (sp³, 1 LP) ≈ 107° ; H₂O (sp³, 2 LP) ≈ 104.5°
અયુગ્મિત યુગ્મ વધુ અપાકર્ષણ આપે → બંધ ખૂણો ઘટે · SI: ડિગ્રી (°) · ચતુષ્ફલકીય ज्यामिતિમાં અયુગ્મિત યુગ્મ હોય ત્યારે
MO સૂત્ર — H₂⁺ (દ્વિ-પરમાણ્વીય): H₂⁺: σ1s¹ , BO = (1−0)/2 = 0.5 ; H₂: σ1s² , BO = 1 ; H₂⁻: σ1s² σ*1s¹ , BO = 0.5 ; He₂⁺: BO = 0.5 ; He₂: BO = 0 (અસ્થિર)
σ1s = બંધકારક કક્ષક ; σ*1s = વિપ્રકર્ષક કક્ષક · SI: — · 1s કક્ષક ધરાવતા પ્રથમ પંક્તિના તત્વો
MO સૂત્ર — Li₂ અને Be₂ (પ્રથમ પંક્તિ): Li₂: (σ1s)²(σ*1s)²(σ2s)² , BO = (6−2)/2 = 2→BO=1 ; Be₂: (σ1s)²(σ*1s)²(σ2s)²(σ*2s)² , BO = 0 (અસ્થિર)
કુલ ઇલેક્ટ્રોન મુજબ ભરતી કક્ષકો ગોઠવો · SI: — · પ્રથમ પંક્તિના દ્વિ-પરમાણ્વીય અણુઓ
MO સૂત્ર — B₂ થી Ne₂ (14 થી 20 ઇલેક્ટ્રોન): B₂: KK(σ2s)²(σ*2s)²(π2p_x¹)(π2p_y¹) , BO = 2 , કુચુંબકીય (2 અયુગ્મિત e⁻) ; C₂: π2p_x² π2p_y² , BO = 2 ; N₂: π2p⁴ σ2p_z² , BO = 3
KK = (σ1s)²(σ*1s)² ; π2p < σ2p_z બંધકારક કક્ષકો (B₂,C₂,N₂ માટે ઊર્જા ક્રમ ઉલટો) · SI: — · Z ≤ 7 (B,C,N) માટે π2p ઊર્જા < σ2p ; Z ≥ 8 (O,F,Ne) માટે σ2p < π2p
MO ઊર્જા ક્રમ — Z ≤ 7 vs Z ≥ 8: Z≤7: σ2s < σ*2s < π2p_x = π2p_y < σ2p_z < π*2p_x = π*2p_y < σ*2p_z ; Z≥8: σ2s < σ*2s < σ2p_z < π2p_x = π2p_y < π*2p_x = π*2p_y < σ*2p_z
Z = કેન્દ્રીય પરમાણુનો પરમાણુ ક્રમાંક · SI: — · સમાન પરમાણુઓ ધરાવતા દ્વિ-પરમાણ્વીય અણુઓ માટે
પ્રતિધ્રુવીકરણ (Polarization) — ફાયંસના નિયમ: પ્રતિધ્રુવીકરણ ક્ષમતા ∝ (ધન આયનનો વિદ્યુતભાર / ત્રિજ્યા²) ∝ (电荷 / r²)
ધન આયનનું પ્રમાણ > ૨, ત્રિજ્યા < હોય તો પ્રતિધ્રુવીકરણ વધુ ; ઋણ આયનની વિભાજ્યતા (polarizability) પણ મહત્વની · SI: — · આયનીય બંધમાં સહસંયોજક ગુણધર્મ અંશે પ્રતિધ્રુવીકરણ જોવા
Fajansના નિયમ મુજબ સહસંયોજકતા વધારો: સહસંયોજક ગુણધર્મ: નાનું ધન આયન > મોટું ધન આયન ; उच्च charge > નીચું charge ; મોટું ઋણ આયન વિભાજ્ય → વધુ પ્રતિધ્રુવીકરણ
Fajans rule: આયનીય બંધમાં પ્રતિધ્રુવીકરણ દ્વારા સહસંયોજકતા આવે છે · SI: — · આયનીય સંયોજનોની ભૌતિક ગુણધર્મો (દ્રવણ બિંદુ, વીજવહન) સમજવા
રેઝોનન્સ (પ્રતિધ્રુવ) સ્થિરતા: રેઝોનન્સ કર્ણ સંખ્યા ∝ સ્થિરતા ; વધુ તટસ્થ રચના > વિદ્યુતભારિત રચનાઓ ; સમાન વિદ્યુતભાર વિતરણ > અસમાન
રેઝોનન્સ હાઇબ્રિડ = વાસ્તવિક રચના · SI: — · O₃, CO₃²⁻, NO₃⁻, બેન્ઝીન વગેરે સંયોજનો

🔗 સંબંધો

  • બંધ ક્રમ (BO) વધે તો બંધ લંબાઈ ઘટે અને બંધ એન્થાલ્પી વધે છે — ત્રિબંધ > દ્વિબંધ > એકલ બંધ
  • અઆવર્તકતા વધે તો વિદ્યુતદ્વિધ્રુવ મુહૂર્ત (μ) વધે છે; μ = q × d
  • અયુગ્મિત ઇલેક્ટ્રોનની સંખ્યા વધે તો બંધક્રમ ઘટે અને અણુની સ્થિરતા ઘટે (MO સિદ્ધાંત)
  • hybridકરણ સ્વરૂપ → બંધ ખૂણો નક્કી કરે: sp (180°) > sp² (120°) > sp³ (109.5°); અયુગ્મિત યુગ્મ હોય તો ખૂણો આદર્શ કરતા ઓછો
  • વિદ્યુતઋણતા તફાવત (Δχ) વધે → બંધમાં આયનીય ગુણધર્મ વધે → અણુ વધુ ધ્રુવીય બને
  • દ્વિધ્રુવ મુહૂર્ત વેક્ટર સરવાળો શૂન્ય થાય તો અણુ અધ્રુવીય બને (ઉદા. CO₂ રેખીય, બંધ મુહૂર્તો વિરોધી દિશામાં)
  • Fajanના નિયમ મુજબ ધન આયનની પ્રતિધ્રુવીકરણ ક્ષમતા વધે → આયનીય બંધમાં સહસંયોજક ગુણધર્મ વધે
  • H₂O, NH₃, CH₄ બધા sp³ hybridકરણ ધરાવે પણ અયુગ્મિત યુગ્મ વધતા બંધ ખૂણો ઘટે છે: 109.5° → 107° → 104.5°

🎯 ટ્રિક્સ

BO = (Nb − Na)/2 : Nb = bonding electrons, Na = antibonding electrons. યાદ રાખો: 'B'onding minus 'A'ntibonding, ભાગવા 2 — simple!
sp³ sp² sp hybridકરણ ઓળખવા: σ બંધ + LP = 4 → sp³, = 3 → sp², = 2 → sp. ઇલેક્ટ્રોન યુગ્મ ગણતરી કરો, hybridકરણ મળી જશે.
O₂ કુચુંબકીય છે તે MO સિદ્ધાંત દ્વારા જ સમજાય — Lewis રચના કહી શકે નહીં. યાદ રાખો: O₂ માં 2 અયુગ્મિત e⁻ π* કક્ષકમાં.
Δχ = 0 → 0% આયનીય; Δχ ≥ 1.7 → આયનીય બંધ ગણી શકાય. વચચે → ધ્રુવીય સહસંયોજક.
CO₂ (રેખીય, 180°) અધ્રુવીય છે કારણ કે બે C=O મુહૂર્તો વિરોધી દિશામાં રદ થાય છે. H₂O (104.5°) ધ્રુવીય છે — ખૂણો 180° નથી.
He₂ અસ્થિર છે કારણ કે BO = 0, પરંતુ He₂⁺ BO = 0.5 → અસ્તિત્વ ધરાવે. યાદ રાખો: અયુગ્મિત ઇલેક્ટ્રોન HO નક્કી કરે!
ડાબેથી જમણે (period 2): BO ઘટતા → સ્થિરતા ઘટે. N₂ (BO=3) સૌથી સ્થિર, O₂ (BO=2), F₂ (BO=1), Ne₂ (BO=0).
અયુગ્મિત યુગ્મ (LP) વધુ → બંધ ખૂણો ઓછો: CH₄ (0 LP) > NH₃ (1 LP) > H₂O (2 LP).

⚠️ ભૂલો

BO = (Na − Nb)/2 લખવું (બિંદુ ઉલટું). સાચું: BO = (Nb − Na)/2. Na > Nb હોય તો BO ઋણ આવે જે અશક્ય છે — સૂત્ર ખોટું.
CO₂ ને ધ્રુવીય માની લેવું. સાચું: CO₂ રેખીય હોવાથી બંધ મુહૂર્તો રદ થાય, μ = 0.
He₂ અસ્તિત્વ ધરાવે છે એવી ધારણા. સાચું: He₂ નું BO = 0, તે અસ્થિર અને અસ્તિત્વમાં નથી.
બધા જ સંયોજનો σ અને π બંધ ગણતરીમાં C=O ને એક જ બંધ ગણવું. સાચું: દ્વિબંધ = 1 σ + 1 π; ત્રિબંધ = 1 σ + 2 π.
અયુગ્મિત ઇલેક્ટ્રોન માટે O₂ ને પ્રતિકુચુંબકીય માની લેવું. સાચું: O₂ માં 2 અયુગ્મિત e⁻ (π* કક્ષકમાં) હોવાથી તે કુચુંબકીય છે.
Δχ < 1.7 હોવા છતાં આયનીય બંધ માની લેવું. સામાન્ય રીતે Δχ < 1.7 = સહસંયોજક; 1.7–2.0 = ધ્રુવીય સહસંયોજક; > 2.0 = આયનીય.
VSEPR માં અયુગ્મિત યુગ્મનો ખૂણા પરનો પ્રભાવ ભૂલવો. LP-BP અપાકર્ષણ BP-BP કરતા વધુ હોવાથી ખૂણો ઘટે છે.
