જીવાણુતત્વો (Biomolecules) — સંપૂર્ણ નોટ્સ

🩺 NEET UG — Gujarati • Chemistry • Biomolecules

1. પ્રસ્તાવના
જીવંત સજીવોમાં મળતા કાર્બનિક સંયોજનોને જીવાણુતત્વો (Biomolecules) કહે છે.
આ મુખ્યત્વે ચાર પ્રકારનાં હોય છે: કર્કાશરસાયણ (Carbohydrates), પ્રોટીન, ન્યુક્લિિક એસિડ અને લિપિડ્સ.
NEET માટે યાદ રાખો: જીવાણુતત્વો શરીરની વૃદ્ધિ, પોષણ, ઉર્જા અને આનુવંશિકતા માટે આવશ્યક છે.
📝 Biomolecule = જીવંત શરીરમાં બનતું મહત્વનું અણુ.
2. કર્કાશરસાયણ (Carbohydrates)
કર્કાશરસાયણ એ પોલીહાઈડ્રોક્સી એલ્ડિહાઈડ અથવા પોલીહાઈડ્રોક્સી કેટોન અથવા જે પદાર્થો આથી બનેલાં હોય તેવાં જટિલ સંયોજનો છે.
આને 'કાર્બન + પાણી' (Carbo-hydrate) તરીકે પણ ઓળખીએ છીએ; સામાન્ય સૂત્ર Cx(H₂O)y હોય છે.
સામાન્ય સૂત્ર: Cₓ(H₂O)ᵧ — જ્યાં x અને y સમાન અથવા ભિન્ન હોઈ શકે.
કર્કાશરસાયણનું વર્ગીકરણ ચાર મુખ્ય શ્રેણીઓમાં થાય છે: મોનોસેકેરાઈડ, ઓલિગોસેકેરાઈડ, પોલીસેકેરાઈડ અને ડિહેડ્રેટેડ કેલ્કોહાઈડ્રેટ.
મોનોસેકેરાઈડ એ સાદા શર્કરા છે જે હાઈડ્રોલિસિસથી વધુ સરળ શર્કરા નથી આપતા.
ત્રણ કાર્બન ધરાવતા મોનોસેકેરાઈડને ત્રિશર્કરા (Triose), પાંચ કાર્બન ધરાવતાને પેન્ટોઝ અને છ કાર્બન ધરાવતાને હેક્સોઝ કહે છે.
ગ્લુકોઝ (C₆H₁₂O₆) એ એક અલ્ડિહાઈડિક હેક્સોઝ છે. ફ્રુક્ટોઝ પણ C₆H₁₂O₆ છે પરંતુ કેટોનિક હેક્સોઝ છે.
ગ્લુકોઝ: CH₂OH—(CHOH)₄—CHO | ફ્રુક્ટોઝ: CH₂OH—CO—(CHOH)₃—CH₂OH
ગ્લુકોઝ અને ફ્રુક્ટોઝ પરસ્પર આઇસોમર (Isomers) છે — અણુસૂત્ર સમાન પણ રચના બદલાયેલી.
D-glucoseL-glucose — બંને એનાઉટિઓમર્સ છે
📝 રસાયણશાસ્ત્રી એલિઝાબેથ ફિશરે D/L આધારિત સ્ટેરિઓઆઇસોમરનો આધાર મૂક્યો.
ઓલિગોસેકેરાઈડમાં 2 થી 10 મોનોસેકેરાઈડ એકમો હોય છે. ડાયસેકેરાઈડ ( Disaccharide ) એ 2 એકમોનું બનેલું સંયોજન છે.
સેકરોઝ (ચીनी) — ગ્લુકોઝ + ફ્રુક્ટોઝ, ગ્લાયકોસિડિક બંધ દ્વારા જોડાયેલા.
મલ્ટોઝ — ગ્લુકોઝ + ગ્લુકોઝ, સાંકળિત સ્ટાર્ચના વિઘટનથી મળે છે.
લેક્ટોઝ — ગ્લુકોઝ + ગેલેક્ટોઝ, સ્તનધાતુમાં મળે છે.
ગ્લાયકોસિડિક બંધ = એક મોનોસેકેરાઈડનો એનોમેરિક कार्बन બીજા મોનોસેકેરાઈડના —OH સાથે જળઅપસારણ દ્વારા જોડાય છે. H₂O ની ખોટ પડે છે.
સેકરોઝનું જળવિભાજન: C₁₂H₂₂O₁₁ + H₂O → C₆H₁₂O₆(ગ્લુકોઝ) + C₆H₁₂O₆(ફ્રુક્ટોઝ)
જળવિભાજન પામેલા મિશ્રણને 'ઇન્વર્ટ શર્કરા' કહે છે કારણ કે આ મિશ્રણનું પ્રકાશિક ઘૂર્ણન ઋણ બને છે.
પોલીસેકેરાઈડમાં સોયો કરતાં વધુ મોનોસેકેરાઈડ એકમો હોય છે. સ્ટાર્ચ, ગ્લાયકોજેન અને સેલ્યુલોઝ પ્રમુખ પોલીસેકેરાઈડ છે.
સ્ટાર્ચ — શાકાહારી ખોરાકમાં મુખ્ય કાર્બોહાઈડ્રેટ; અમિલોઝ (રેખીય) અને એમિલોપેક્ટિન (શાખાકાર) બનેલું હોય છે.
ગ્લાયકોજેન — પ્રાણીઓમાં સંગ્રહિત શર્કરા; જકઝમ ( liver ) અને સ્નાયુઓમાં મળે છે.
સેલ્યુલોઝ — સૂત્ર (C₆H₁₀O₅)n, પેદાકોષક દીવાલમાં મળે છે; β-ગ્લાયકોસિડિક બંધ ધરાવે છે.
સેલ્યુલોઝ એ α-કર્કાશરસાયણ નથી; ઈન્સાનના શરીરમાં સેલ્યુલોઝ પાચાતું નથી.
📝 સેલ્યુલોઝ vs સ્ટાર્ચ: બંને (C₆H₁₀O₅)n છે પણ β vs α બંધ ધરાવે છે — આથી ગુણધર્મોમાં તફાવત.
3. પ્રોટીન (Proteins)
પ્રોટીન એ આલ્ફા-એમિનો એસિડના પોલિમર છે. પ્રોટીન એટલે 'મૂળભૂત જીવન તત્વ'.
20 પ્રકારનાં પ્રાથમિક એમિનો એસિડ જીવંત શરીરમાં મળે છે. બધાં એમિનો એસિડમાં એક આલ્ફા-કાર્બન, એક —NH₂, એક —COOH, એક —H અને એક R-જૂથ હોય છે.
સામાન્ય સૂત્ર: H₂N—CHR—COOH
જ્યારે બે એમિનો એસિડ પરસ્પર જોડાઈએ ત્યારે પેપ્ટાઈડ બંધ (Peptide bond) बनે છે. આ એક —CO—NH બંધ છે.
ડાયપેપ્ટાઈડ = 2 એમિનો એસિડ, ટ્રાઈપેપ્ટાઈડ = 3, પોલિપેપ્ટાઈડ = અનેક એમિનો એસિડ.
પ્રોટીનની ચાર પડખી રચના હોય છે: પ્રાથમિક, દ્વિતીયક, તૃતીયક અને ચતુર્થક.
પ્રાથમિક રચના = પેપ્ટાઈડ બંધ દ્વારા એમિનો એસિડનું ક્રમ (Sequence).
દ્વિતીયક રચના = α-હેલિક્સ અને β-પ્લીટેડ શીટ. આ હાઈડ્રોજન બંધથી સ્થિર રહે છે.
તૃતીયક રચના = પોલિપેપ્ટાઈડ શૃંખલાનું ત્રિ-પરિમાણીય (3D) મ fold થવું.
ચતુર્થક રચના = બે અથવા વધુ પોલિપેપ્ટાઈડ શૃંખલાઓનું એકમુખ્ય (Multimeric) સંયોજન.
ડીનેચરિંગ (Denaturation): ઉષ્મા, pH અથવા રાસાયણિક અસરથી પ્રોટીનની દ્વિતીયક/તૃતીયક રચના નષ્ટ થાય છે. પ્રાથમિક રચના અકબંધ રહે છે.
ડીનેચરિંગનાં ઉદાહરણો: ઇંડાનું પડદું સખત થવું, સ્ટીમથી પ્રોટીન ગલિત થવું.
📝 ENZYME પ્રોટીન છે — ડીનેચરિંગથી એન્ઝાઇમની ક્રિયાશીલતા નષ્ટ થાય છે.
4. એન્ઝાઇમ (Enzymes)
એન્ઝાઇમ પ્રોટીન પ્રકારનાં જૈવ-ઉત્પ્રેરક (Biocatalysts) છે જે જૈવરાસાયણિક પ્રક્રિયાઓનો દર વધારે છે.
એન્ઝાઇમનું સક્રિય સ્થળ (Active site) એ સબસ્ટ્રેટ સાથે બંધાય છે અને પ્રક્રિયાને અનુકૂળ બનાવે છે.
એન્ઝાઇમ વર્ગીકરણ: ઓક્સિડોરીડક્ટેઝ, ટ્રાન્સફરેઝ, હાઈડ્રોલેઝ, લાયેઝ, ઈસોમેરેઝ અને લિગેઝ.
એન્ઝાઇમ + સબસ્ટ્રેટ → એન્ઝાઇમ-સબસ્ટ્રેટ જટિલ → ઉત્પાદન + એન્ઝાઇમ (પુનઃપ્રાપ્ત).
📝 એન્ઝાઇમ ન્યૂનતમ activation energy પૂરી પાડે છે.
5. ન્યુક્લિક એસિડ (Nucleic Acids)
ન્યુક્લિક એસિડ એ ન્યુક્લિઓટાઇડ્સના પોલિમર છે. બે પ્રકાર: DNA અને RNA.
ન્યુક્લિઓટાઇડ = પેન્ટોઝ શર્કરા + નાયટ્રોજનસ બેઝ + ફોસ્ફેટ ગ્રૂપ.
DNA માં ડિઓક્સીરીબોઝ અને RNA માં રાઇબોઝ શર્કરા મળે છે.
નાયટ્રોજનસ બેઝ: પ્યુરિન (એડેનિન A, ગ્વાનિન G) અને પાયરિમિડિન (થાઇમિન T, યુરેસિલ U, સાયટોઝિન C).
DNA માં T મળે છે, RNA માં U મળે છે. બંનેમાં A, G, C સામાન્ય છે.
Chargaff નો નિયમ: [A] = [T] અને [G] = [C]; Purine = Pyrimidine
Watson અને Crick મોડલ: DNA ડબલ હેલિક્સ છે, બે શૃંખલાઓ વિপরિત દિશામાં (Antiparallel).
A=T વચ્ચે 2 હાઈડ્રોજન બંધ અને G≡C વચ્ચે 3 હાઈડ્રોજન બંધ હોય છે.
📝 mRNA, tRNA, rRNA — ત્રણ પ્રકારના RNA; બધા પ્રોટીન સંશ્લેષણમાં ભાગ લે છે.
6. વિટામિન (Vitamins)
વિટામિન એ જરૂરી ઓર્ગેનિક અણુઓ છે જે શરીરમાં ન્યૂનતામાં હોય છે પણ જરૂરી કાર્યો કરે છે.
વિટામિનનું વર્ગીકરણ: જલીય દ્રાવ્ય (Water-soluble) અને ચર્બી દ્રાવ્ય (Fat-soluble).
જલીય દ્રાવ્ય: B-ગ્રુપ વિટામિન અને Vitamin C.
ચર્બી દ્રાવ્ય: A, D, E, K.
Vitamin B₁ (થેલામિન) — ન્યૂનતાથી પેલગ્રા (Pellagra)? નાં! B₁ ની ઓછાપણે Beriberi થાય છે; B₃ (Niacin) માં Pellagra થાય છે.
Vitamin C (Ascorbic acid) — ન્યૂનતાથી Scurvy. પ્રાણીઓમાં Vitamin C સંશ્લેષિત થતું નથી.
Vitamin A (Retinol) — ન્યૂનતાથી Xerophthalmia અને રાત્રિ ધૂંધળાપણું (Night blindness).
Vitamin D — ન્યૂનતાથી Rickets (શिशુઓમાં હાડકાં નરમ પડે).
Vitamin E (Tocopherol) — પ્રજનન અને પ્રતિકારક શક્તિ માટે મહત્વપૂર્ણ.
Vitamin K — લોહીના ઝડપી જમાવટ (Blood clotting) માટે જરૂરી.
📝 NEET tip: Fatsoluble Vitamins A,D,E,K — યાદ રાખો: 'ADEK'.
7. હોર્મોન્સ (Hormones)
હોર્મોન્સ એ અંતઃસ્ત્રાવી ગ્રંથિઓ દ્વારા સ્રાવિત થતાં રસાયણિક સંદેશવાહકો છે.
પ્રોટીન/પેપ્ટાઇડ હોર્મોન્સ: ઈન્સુલિન, ગ્લુકાગોન, GH.
સ્ટેરોઇડ હોર્મોન્સ: टेस्टोस्टेरोन, એસ્ટ્રોજેન, કોર્ટિસોલ.
અમિનો એસિડ derived હોર્મોન્સ: থাইરોક્સિન (T₄), એડ્રિનાલિન.
ઈન્સુલિન લિવર અને પેનક્રિયાસમાંથી — glucose નું ગ્લાયકોજેનમાં રૂપાંતર કરે છે.
8. લિપિડ્સ (Lipids) — સંક્ષિપ્ત
લિપિડ્સ એ બળગર પાણીમાં અદ્રાવ્ય જૈવઅણુઓ છે જે મુખ્યત્વે ગ્લિસરોલ અને ચર્બી એસિડના બનેલા હોય છે.
ટ્રાયગ્લિસરાઈડ = 3 ચર્બી એસિડ + 1 ગ્લિસરોલ. એસ્ટર બંધ દ્વારા જોડાયેલા.
ગ્લિસરોલ + 3 फैटी એसिड → ट्राइग्लिसराઈड + 3H₂O
સનયુક્ત (Saturated) vs અસનયુક્ત (Unsaturated) ચર્બી એસિડ — double bond ની ગણતરી જરાયે ન કરવી.
📝 Membrane lipid bilayer — Phospholipid main component of cell membrane.
9. મહત્વપૂર્ણ સામગ્રી અને પ્રયોગો
Molisch test — કર્કાશરસાયણની ચકાસણી: α-naphthol + H₂SO₄ → લાલ-બુરંજી ring.
Fehling test / Benedict test — reducing sugar ચકાસણી. રેડ્યુસિંગ શર્કરા Cu²⁺ ને Cu₂O (ટાંબે રંગનો沉淀) માં બદલે છે.
Iodine test — starch ની ચકાસણી: iodine + starch → મીઠી વાદળી (Blue-black) રંગ.
Biuret test — peptide bond ની ચકાસણી:CuSO₄ + NaOH + protein → વાયલેટ (Violet) રંગ.
📝 All sugars with free anomeric carbon are reducing sugars. Sucrose non-reducing છે.
10. સંક્ષિપ્ત નિષ્કર્ષ
Biomolecules એટલે જીવનનાં રસાયણીય આધારતત્વો — Carbohydrate, Protein, Nucleic acid, Lipid અને Vitamins.
NEET માટે મહત્વનાં: Glucose/Fructose structure, Peptide bond, DNA base pairing, Vitamin deficiency diseases, Enzyme classification, Denaturation.
Repeat these: Purine=AG, Pyrimidine=TCU | A=T (2H-bond), G≡C (3H-bond) | Fat-soluble=ADEK.
📝 Make sure you can draw Glucose, Fructose, DNA base pairs, and Peptide bond by hand — NEET frequently asks structural questions.
