⚡ સૂત્રો

સામાન્ય શર્કરા સૂત્ર (વ્યાખ્યા): Cn(H2O)n
n = કાર્બન અણુઓની સંખ્યા; આ સૂત્રથી 'કાર્બોહાઈડ્રેટ' શબ્દનો ઉદભવ થયો · SI: — · આમંત્રિત મોનોસેકેરિડ્સ માટે લાગુ; હેક્સોઝ (n=6) અને પેન્ટોઝ (n=5) સામાન્ય રૂપ
ક્ષારકિત ભ્રમણ / ચોક્કસ ભ્રમણ (Specific Rotation): [α] = α_observed / (l × c)
[α] = ચોક્કસ ભ્રમણ (deg·mL·dm⁻¹·g⁻¹); α_observed = પ્રયોગમાં જોવાયેલું ભ્રમણ (°); l = પ્રકાશ માર્ગની લંબાઈ (dm માં); c = સાંદ્રતા (g/mL માં) · SI: deg·mL·dm⁻¹·g⁻¹ (વાત્તાવરણિક) · ધ્રુવીભૂત પ્રકાશ વલયમાં ફેરવાતા સંયોજનના ભ્રમણને પ્રમાણભૂત કરવા માટે; તાપમાન અને તરંગલંબાઈ નોંધવી જરૂરી
મ્યુટારોટેશન / વિશિષ્ટ ભ્રમણનું સમય-આધારિત પરિવર્તન: [α]t = [α]∞ + ([α]0 − [α]∞) e^(−kt)
[α]t = t સમયે ભ્રમણ; [α]0 = પ્રારંભિક ભ્રમણ; [α]∞ = સંતુલન ભ્રમણ; k = દર અચળાંક · SI: s⁻¹ (k નું એકમ) · α-D-ગ્લુકોઝ ([α]=+112°) કે β-D-ગ્લુકોઝ ([α]=+18.7°) નું જଳમાં દ્રાવણ મળે ત્યારે સંતુલન પર +52.7° પહેંચે તે અનુસરીનું વર્ણન
ગ્લાઇકોસિડિક બંધનો પ્રકાર (શર્કરામાં): R−O−R′ (O-ગ્લાઇકોસિડિક બંધ) અથવા R−NH−R′ (N-ગ્લાઇકોસિડિક બંધ)
R,R′ = શર્કરા ભાગ; O = ઓક્સિજન/નાઈટ્રોજન એટમે દ્વારા બે શર્કરા જોડાયેલી · SI: — · દ્વિશર્કરા કે બહુશર્કરા રચના માટે; α-1,4, β-1,4, α-1,2 બંધોનો સમાવેશ
એમિનો એસિડ સામાન્ય સૂત્ર (α-એમિનો એસિડ): H2N−CH(R)−COOH
R = પાશ્ર્વ સાંખળ; α-કાર્બન પર એમાઇન અને કાર્બોક્સિલિક એસિડ બંને જોડાયેલા · SI: — · સર્વ પ્રોટીન બનનારા 20 પ્રાથમિક α-એમિનો એસિડ માટે લાગુ
પેપ્ટાઇડ બંધ રચના: −CO−NH− (CONH ગાંઠ)
કાર્બોક્સિલ સમૂહ −COOH અને એમાઇન સમૂહ −NH2 વચ્ચે જળવાયુ નિકાલથી બનતો અમિડ બંધ · SI: — · પ્રોટીન/પેપ્ટાઇડની પ્રાથમિક રચનામાં દરેક એમિનો એસિડ વચ્ચે
પ્રોટીન અણુભાર અંદાજ (પેપ્ટાઇડ બંધ સંખ્યા): M_protein ≈ n × M_aa − (n−1) × 18
n = એમિનો એસિડ એકમોની સંખ્યા; M_aa = સરેરાશ એમિનો એસિડ અણુભાર (~110 Da); 18 = જળઅણુ (H2O) નો અણુભાર જે દરેક પેપ્ટાઇડ બંધ બનતો નીકળે છે · SI: Da અથવા g/mol · રેખીય પોલીપેપ્ટાઇડ શૃંખલાના અણુભારનો અંદાજ; પ્રોટીનમાં શાખા/ભંડોળ હોય તો સુધારો જરૂરી
ચારગૉફનો નિયમ (DNA માટે): A = T, G = C (અથવા A+G = T+C = પ્યુરિન = પાયરિડિન)
A = એડેનાઇન; T = થાઇમિન; G = ગ્વાનીન; C = સાયટોસિન — નાઈટ્રોજન બેઝની પરિમાણ સંખ્યા · SI: — · બે-સ્તરવાળા (double-stranded) DNA માટે; RNA માટે U થાઇમિનને બદલે
નાઈટ્રોજન બેઝ યોગ્યતાનું પ્રમાણ: purine/pyrimidine = (A+G)/(T+C) = 1
A,G = પ્યુરિન; T,C = પાયરિમિડિન; બે-સ્તર DNA માટે ગુણોત્તર 1 હોય · SI: — · બે-સ્તરવાળા DNA માટે; એક-સ્તરવાળા RNA/વૈકલ્પિક રચના માટે લાગુ નહીં
ન્યુક્લિઓટાઇડ સૂત્ર: ન્યુક્લિયોસાઇડ + Pn (ફોસ્ફેટ સમૂહો)
ન્યુક્લિયોસાઇડ = શર્કરા (રિબોઝ/ડીಆક્સિરાઇબોઝ) + નાઈટ્રોજન બેઝ; Pn = 1–3 ફોસ્ફેટ; AMP, ADP, ATP અનુક્રમે · SI: — · DNA/RNA બિલ્ડિંગ બ્લોક, ATP (શક્તિ વાહક) અને ન્યુક્લિક એસિડ શૃંખલા માટે
ATP માં બંધ-ઉર્જા અંદાજ (મૌલિક): ATP + H2O → ADP + Pi + ~30.5 kJ/mol (પ્રમાણભૂત)
ATP = એડેનોસિન ટ્રાયફોસ્ફેટ; ADP = એડેનોસિન ડાયફોસ્ફેટ; Pi = અજૈવિક ફોસ્ફેટ · SI: kJ/mol · ફોસ્ફોએસ્ટર બંધના જળવાયુ વિભાજન દરમિયાન મુક્ત થતી ઉર્જા; કોષીય પ્રક્રિયાઓને સંચાલિત કરે
પ્રોટીન બંધારણ સ્તરોની ગણના: peptide_bonds = n_amino_acids − 1 (રેખીય એક શૃંખલા)
n_amino_acids = એમિનો એસિડ એકમોની સંખ્યા; ડાઈસલ્ફાઇડ-બંધ, હાઈડ્રોજન બંધ, હાઈડ્રોફોબિક ક્રિયા-પ્રતિક્રિયા બંધારણ-સ્તર નક્કી કરે · SI: — · મોનોમેરિક રેખીય પોલીપેપ્ટાઇડ; બહુ-ઉપઅંગી/બંધ સંક્રાંતિ હોય તો વધારાની ગણતરી

🔗 સંબંધો

  • ચોક્કસ ભ્રમણ [α] એ પ્રાયોગિક ભ્રમણ α_observed ને લંબાઈ (dm) અને સાંદ્રતા (g/mL) વડે વિભાજિત કરતા મળે છે; આથી વિવિધ પ્રયોગ પરિસ્થિતિઓના પરિણામો સરખાવી શકાય.
  • D/L વિન્યાસ ઇનોસિટોલ/ગ્લಿಸરલ્ડહાઇડ સાથે સંબંધિત છે: ગ્લુકોઝનું છેલ્લું ચિરાલ કાર્બન (C-5) પર OH જમણી તરફ હોય તો D-ગ્લુકોઝ; ડાબી તરફ હોય તો L-ગ્લુકોઝ.
  • મ્યુટારોટેશનમાં α અને β એનોમર વચ્ચે ભંડોળ થાય છે અને અંતિમ સંતુલન ભ્રમણ +52.7° (ગ્લુકોઝ) મળે છે; આથી શુદ્ધ એનોમરનું પરમાણુ માત્ર દ્રાવણમાં અસ્થિર હોય છે.
  • પ્રોટીનના પ્રાથમિક બંધારણ (પેપ્ટાઇડ બંધ) → દ્વિતીયક (α-હેલિક્સ/β-પ્લીટેડ શીટ, હાઈડ્રોજન બંધ દ્વારા) → તૃતીયક (ડાઈસલ્ફાઇડ, હાઈડ્રોફોબિક, આયનીય) → ચતુર્થક (એક થી વધુ પોલીપેપ્ટાઇડ શૃંખલા)
  • DNA માં A=T (2 હાઈડ્રોજન બંધ) અને G≡C (3 હાઈડ્રોજન બંધ); તેથી G-C વિભાગ ધરાવતું DNA વધુ સ્થિર (ઉચ્ચ ગલનબિંદુ) હોય છે.
  • ગ્લાઇકોસિડિક બંધનો પ્રકાર (α-1,4 vs β-1,4) એ સ્ટાર્ચ (α-બંધ→મેંધાકાર) અને સેલ્યુલોઝ (β-બંધ→રેખીય) વચ્ચેનો રચનાત્મક તફાવત સમજાવે છે.
  • એમિનો એસિડની ઐઝોઇલેક્ટ્રિક બિંદુ (pI) એ એમના આઝોટ્રોપિક અવસ્થાનું મૂલ્ય છે: pI = (pKa1 + pKa2)/2 (સરળ α-એમિનો એસિડ માટે).
  • ATP માં ત્રણ ફોસ્ફેટના ઇન્ટરફોસ્ફેટ બંધ (-PO3-PO3-) ઉચ્ચ-ઉર્જા બંધ હોય છે; જળવાયુ વિભાજન થતાં આ ઉર્જા મુક્ત થાય છે.

🎯 ટ્રિક્સ

ચોક્કસ ભ્રમણના પ્રશ્નમાં l (dm માં) અને c (g/mL માં) એકમો તપાસો; જો l cm માં હોય તો 10 વડે ભાગો (1 dm = 10 cm), જો c g/100mL માં હોય તો 100 વડે ગુણો/ભાગો એમ સુધારો કરવો.
D/L વિન્યાસ યાદ રાખવાનું સૂત્ર: "D = Декстр" (જમણું), "L = Лев" (ડાબું); ગ્લુકોઝમાં C-5 પર OH જમણી તરફ → D, ડાબી તરફ → L (ફિશેર પ્રક્ષેપણમાં).
Glycosidic bond type ઓળખવા: સ્ટાર્ચ = α-1,4; સેલ્યુલોઝ = β-1,4; મેલ્ટોઝ = α-1,4; લેક્ટોઝ = β-1,4; સુક્રોઝ = α-1,β-2; આ ચાર-અક્ષરની મેમોનિક યાદ રાખો.
Protein secondary structure: α-helix → H-bond between CO(i) and NH(i+4); β-pleated sheet → H-bond between adjacent strands; આ inter-residue spacing યાદ રાખો.
Chargaff's rule quick check: A+G = T+C = 50% total bases in dsDNA; જો A=20% → T=20%, G=C=30% (સરવાળો 100%).
Peptide bond count shortcut: n amino acids joined linearly → (n−1) peptide bonds; if m chains, then n−m peptide bonds total.
Mutarotation numerical trick: pure α-glucose [α]=+112°, pure β-glucose [α]=+18.7°, equilibrium = +52.7°. Fraction of α at equilibrium can be estimated: f_α ≈ (52.7−18.7)/(112−18.7).
ATP energy per bond hydrolysis: each terminal phosphate cleavage releases ~30.5 kJ/mol under standard conditions; this is the same order for ADP→AMP step.

⚠️ ભૂલો

Specific rotation માં l ને cm માં લેતાં સૂત્ર ખોટું પડે છે; l હંમેશા dm માં લેવું. અંતરાલ 10 ગણું ત્રુટિ આપે છે.
Mutarotation સમયે [α]t શૂન્ય તરફ જાય છે એમ માનવું; સાચું: it approaches the equilibrium value (+52.7° for glucose), not zero.
α-D-ગ્લુકોઝ અને β-D-ગ્લુકોઝ એ એકબીજાના enantiomer નથી; તેઓ anomers (C-1 stereoisomers) છે, D/L enantiomer nahi.
D-ગ્લુકોઝ → dextrorotatory (+) છે પણ D-લેબલ એ optical rotation સાથે સીધું સંબંધિત નથી; D/L એ config નો સંદર્ભ, (+)/(-) એ observed rotation.
Peptide bond સંખ્યા ગણતી વખતે disulfide bond ને peptide bond ગણી લેવા; disulfide bond (−S−S−) અલગ type નો છે.
Chargaff's rule માં A=G, T=C એમ ગલતીથી લખવું; સાચું: A=T, G=C (complementary base pairing).
RNA માં Thymine (T) હોય છે એમ માનવું; RNA માં Uracil (U) થાય, T નહીં.
Nucleoside ને Nucleotide સાથે ભેળવવું; Nucleoside = sugar+base (no phosphate); Nucleotide = nucleoside + phosphate group(s).
β-1,4-glycosidic bond (cellulose) માનવ શરીર digestion કરી શકતું નથી કારણ કે cellulase enzyme અછત; starch (α-1,4) digestive enzymes દ્વારા પાਚી શકાય.
ATP hydrolysis માં ΔG°′ ≈ −30.5 kJ/mol એ standard conditions છે; cellular conditions માં实际 ΔG වધુ negative હોઈ શકે છે, પરંતુ exam માં standard value જ વપરો.
