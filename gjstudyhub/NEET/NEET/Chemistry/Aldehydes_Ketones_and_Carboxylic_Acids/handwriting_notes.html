અધ્યાય પરિચય અને કાર્યાત્મક સમૂહ
આ અધ્યાયમાં કાર્બનિક સંયોજનોના ત્રણ મુખ્ય શ્રેણીઓનો અભ્યાસ કરવામાં આવે છે: ઇલ્ડિહાઇડ્સ, કેટોન્સ અને કાર્બોક્સિલિક એસિડ્સ.
સبધિયું: ત્રણેય વર્ગના સંયોજનો C=O (કાર્બોનિલ) ગ્રૂપ ધરાવે છે. કાર્બોક્સિલિક એસિડમાં આ ગ્રૂપ —COOH સ્વરૂપમાં હોય છે.
📝 NEET પરીક્ષા માટે: C=O બંધની ધ્રુવીયતા અને ન્યુક્લિયોફિલિક ઉમેરાની પ્રવૃત્તિ અત્યંત મહત્વની છે.
ઇલ્ડિહાઇડ: R–CHO | કેટોન: R–CO–R' | કાર્બોક્સિલિક એસિડ: R–COOH
આઇ.يو.ਪી.એસી. નામકરણ (IUPAC Nomenclature)
ઇલ્ડિહાઇડ્સના નામકરણમાં મૂળ શબ્દ પછી '-અલ' પ્રત્યય ઉમેરવામાં આવે છે. ઉદાહરણ: CH₃CHO → ઇથેનલ.
કેટોન્સના નામકરણમાં મૂળ શબ્દ પછી '-ઓન' પ્રત્યય લાગે છે. ઉદાહરણ: CH₃COCH₃ → પ્રોપેનોન (સામાન્ય ભાષામાં એસિટોન).
કાર્બોક્સિલિક એસિડ્સમાં '-ઓઇક એસિડ' પ્રત્યય ઉમેરવામાં આવે છે. ઉદાહરણ: CH₃COOH → ઇથેનોઇક એસિડ (એસિટિક એસિડ).
ધ્યાન રાખો: C₁ થી C₃ સુધીના ઇલ્ડિહાઇડ્સ અને કેટોન્સ સામાન્ય નામોથી વધુ જાણીતા છે (ફોર્મલ્ડિહાઇડ, એસિટલ્ડિહાઇડ, એસિટોન).
📝 નામકરણના નિયમો સ્ટેટિક છે; પરિક્ષામાં ઘણીવાર આઇ.यो.પી.એસી. નામ આપવાની કે નામ પરથી સૂત્ર લખવાની ક્વેશ્ચન આવે છે.
સામાન્ય સૂત્ર: ઇલ્ડિહાઇડ્સ/કેટોન્સ માટે CₙH₂ₙO (એક ડબલ બોન્ડ ઇક્વિવેલન્ટ). કાર્બોક્સિલિક એસિડ્સ માટે પણ CₙH₂ₙO₂.
ઇલ્ડિહાઇડ્સ અને કેટોન્સની તૈયારી પદ્ધતિઓ
પ્રાઇમરી એલ્કોહોલની આંશિક ઓક્સિડેશનથી ઇલ્ડિહાઇડ્સ મળે છે. ઉદા: CH₃CH₂OH + [O] → CH₃CHO + H₂O.
સેકન્ડરી એલ્કોહોલની ઓક્સિડેશનથી કેટોન્સ મળે છે. ઉદા: CH₃CH(OH)CH₃ + [O] → CH₃COCH₃.
ઑઝોનોલિસિસ (Ozonolysis) દ્વારા આલ્કિનો વિઘટન કરી ઇલ્ડિહાઇડ્સ/કેટોન્સ પ્રાપ્ત કરી શકાય. Zn/H₂O હાજરીમાં.
ગેરોક પ્રતિક્રિયા: એલ્કિન + O₃ → ઑઝોનાઇડ → Zn/H₂O → આલ્ડિહાઇડ/કેટોન. આ પ્રતિક્રિયા C=C બોન્ડને તોડે છે.
📝 ઇલ્ડિહાઇડ્સ એસિડિક ઓક્સિડેન્ટથી ઓક્સિડાઈને કાર્બોક્સિલિક એસિડ બનાવે છે; કેટોન્સ સામાન્ય રીતે મજબૂત ઓક્સિડેન્ટ વગર ઓક્સિડાઈ શકતા નથી.
R–CH=CH–R' + O₃ → (ઝેન સહિત) → R–CHO + R'–CHO
કાર્બોક્સિલિક એસિડ્સની તૈયારી
પ્રાઇમરી એલ્કોહોલ કે આલ્ડિહાઇડની પ્રબળ ઓક્સિડેશનથી કાર્બોક્સિલિક એસિડ મળે છે. KMnO₄ અથવા K₂Cr₂O₇ વપરાય છે.
નાઈટ્રાઇલ્સ (R–CN) ની જલીય હાઈડ્રોલિસિસથી કાર્બોક્સિલિક એસિડ મળે છે. R–CN + 2H₂O → R–COOH + NH₃.
ગ્રિગ્નાર્ડ પ્રક્રિયા: R–MgX + CO₂ → R–COO⁻MgX⁺ → H₃O⁺ → R–COOH.
મહત્વ: બેન્ઝોઇક એસિડની તૈયારીમાં ટોલ્યુઇનનું KMnO₄ વડે ઓક્સિડેશન કરવામાં આવે છે.
📝 કાર્બોક્સિલિક એસિડ્સની તૈયારીની ઘણી પદ્ધતિઓ છે; NEET માં ગ્રિગ્નાર્ડ અને હાઈડ્રોલિસિસ પદ્ધતિઓ પર પ્રશ્નો આવે છે.
R–CH₂OH → [O] → R–CHO → [O] → R–COOH
ભૌતિક ગુણધર્મો
ઇલ્ડિહાઇડ્સ અને કેટોન્સના નીચલા સદસ્યો પાણીમાં ભલે દ્રાવ્ય હોય છે, કારણ કે તેઓ પાણી સાથે હાઈડ્રોજન બોન્ડ બનાવી શકે છે.
કાર્બોક્સિલિક એસિડ્સના નીચલા સદસ્યો પાણીમાં સહજ દ્રાવ્ય છે; ઉચ્ચ સદસ્યો (C₅+) માં દ્રાવ્યતા ઘટે છે.
ઇલ્ડિહાઇડ્સ અને કેટોન્સના ઉત્કલન બિંદુ એલ્કોહોલ કરતાં ઓછા હોય છે, પરંતુ અનુરૂપ એલ્કેન કરતાં વધુ હોય છે.
કાર્બોક્સિલિક એસિડ્સના ઉત્કલન બિંદુ ખૂબ ઊંચા હોય છે, કારણ કે તેઓ દ્વિસ્તરીય ડાયમર બનાવે છે.
📝 ઉત્કલન બિંદુનો ક્રમ: કાર્બોક્સિલિક એસિડ > આલ્ડિહાઇડ/કેટોન > એલ્કેન (સમાન આણ્વીય દળ માટે).
બે કાર્બોક્સિલિક એસિડ અણુઓ વચ્ચે બનેલો હાઈડ્રોજન બોન્ડ: R–COOH···HOOC–R (ડાયમર)
ઇલ્ડિહાઇડ્સ અને કેટોન્સની રાસાયણિક પ્રવૃત્તિ
કાર્બોનિલ કાર્બન ધન આંશિક વીજભાર ધરાવે છે, જેના કારણે ન્યુક્લિયોફિલિક ઉમેરણ પ્રતિક્રિયાઓ થાય છે.
HCN નું ઉમેરણ: RCHO + HCN → RCH(OH)CN (ઍલ્ડોન). આ પ્રક્રિયા CN⁻ દ્વારા આગળ વધે છે.
Grignard અભિકારકો સાથે પ્રતિક્રિયા: RCHO + R'MgX → આલ્કોહોલ; કેટોન + R'MgX → તૃતીયક આલ્કોહોલ.
ન્યુક્લિયોફિલિક ઉમેરણની પ્રવૃત્તિ ક્રમ: ઇલ્ડિહાઇડ્સ > કેટોન્સ (સ્ટેરિક અને ઇલેક્ટ્રોનિક કારણોસર).
📝 ન્યુક્લિયોફિલિક ઉમેરણમાં સૌ પ્રથમ ન્યુક્લિયોફાઇલ કાર્બોનિલ કાર્બન પર હુમલો કરે છે, પછી પ્રોટોન ઉમેરાય છે.
R–CHO + HCN → R–CH(OH)–CN | R–CO–R' + NaHSO₃ → R–C(OH)(SO₃Na)–R'
ઓક્સિડેશન અને રિડક્શન પ્રતિક્રિયાઓ
ઇલ્ડિહાઇડ્સ સહેલભાવે ઓક્સિડાઈને કાર્બોક્સિલિક એસિડ બનાવે છે: RCHO + [O] → RCOOH.
કેટોન્સ મજબૂત ઓક્સિડેન્ટની હાજરીમાં C–C બોન્ડ તૂટીને મિશ્ર એસિડો બનાવે છે (વેલ્ડન્ડિંગ પ્રતિક્રિયા).
ઇલ્ડિહાઇડ્સની ચୟનાત્મક ઓક્સિડેશન: એસિડ ઓક્સિડાઈને એસિડ બને છે, કેટોનના મિશ્રણમાં ઓક્સિડેશન થતું નથી.
કેટલોડ રિડક્શન (Clemmensen): R–CO–R' + Zn(Hg)/ conc. HCl → R–CH₂–R' (કેટોન → એલ્કેન).
📝 વોલ્ફ-ક્ષીરનર રિડક્શન: R–CHO → R–CH₂OH (NaBH₄ અથવા LiAlH₄ વડે). બંને પદ્ધતિઓ NEET માટે મહત્વની છે.
R–CHO + H₂/Ni → R–CH₂OH | R–CO–R' + H₂/Ni → R–CH(OH)–R'
આલ્ડોલ સંલગ્નન અને ક્રેન્ઝ રિડક્શન
આલ્ડોલ સંલગ્નન: બે અણુઓ જેમાં α- H હોય તેઓ ડાઈલ્યુટ આલ્કલીની હાજરીમાં પ્રતિક્રિયા કરી β-હાઈડ્રોક્સિ આલ્ડિહાઇડ/કેટોન બનાવે છે.
આલ્ડોલ ઉત્પાદન ગરماવવા પર પાણી ગુમાવી α,β-અસંતૃષ્ટ આલ્ડિહાઇડ/કેટોન આપે છે (આલ્ડોલ વિઘટન).
ક્રેન્ઝ રિડક્શન: બેનઝાલ્ડિહાઇડ જેવા સંયોજનોમાં α-H ન હોવાથી આલ્ડોલ સંલગ્નન થતું નથી; તેઓ બેઝ વડે વિષમવર્તી રિડોક્સ પ્રતિક્રિયા આપે છે.
ક્રેન્ઝ પ્રતિક્રિયામાં એક અણુ ઓક્સિડાઈને એસિડ બને છે અને બીજો અણુ રિડ્યુસ થઈને આલ્કોહોલ બને છે.
📝 α-હાઇડ્રોજન ધરાવતા આલ્ડિહાઇડ/કેટોન જ આલ્ડોલ સંલગ્નન આપી શકે છે. આ ચોખવટી NEET માટે ખૂબ જરૂરી છે.
2CH₃CHO →(dil. NaOH)→ CH₃CH(OH)CH₂CHO (પ્રોપેનલ આલ્ડોલ) →(warm)→ CH₃CH=CHCHO (બ્યુટ-2-ઈનલ)
કાર્બોક્સિલિક એસિડ્સના ગુણધર્મો
કાર્બોક્સિલિક એસિડ્સ પ્રબળ એસિડ છે (pKₐ ≈ 4-5). તેઓ બેઈકાર્બોનેટ સાથે પ્રતિક્રિયા કરી CO₂ મુક્ત કરે છે.
એસિડિક ગુણધર્મ: RCOOH + NaHCO₃ → RCOONa + H₂O + CO₂. આ પ્રતિક્રિયા આલ્ડિહાઇડ/કેટોનથી એસિડ અલગ કરવા વપરાય છે.
એસ્ટરિફિકેશન: એસિડ + આલ્કોહોલ → એસ્ટર + પાણી. સંલગ્નન H₂SO₄ વડે પ્રરંભિત થાય છે.
રેસોનેન્સ કારણે carboxylate આયન (RCOO⁻) સ્થિર હોય છે, જે એસિડિક ગુણધર્મને સમજાવે છે.
📝 એસિડિક પ્રબળતા પર સ્થાનાંતરકાઓની અસર: –I ગ્રુપ એસિડિટી વધારે છે, +M ગ્રુપ એસિડિટી ઘટાડે છે.
RCOOH + R'OH ⇌ RCOOR' + H₂O (conc. H₂SO₄, ગરમ) | RCOOH + NaOH → RCOONa + H₂O
કાર્બોક્સિલિક એસિડ્સનાં વ્યુત્પન્નો
એસિડ ક્લોરાઇડ: RCOOH + SOCl₂ → RCOCl + SO₂ + HCl. SOCl₂ સૌથી વધુ વપરાય છે કારણ કે ઉપજ ઉત્પાદનો વાયુ સ્વરૂપે બહાર નીકળે છે.
એસિડ આનાઇડ: 2RCOOH → (P₂O₅) → (RCO)₂O + H₂O. P₂O₅ પાણી શોષક છે.
એસિડ એમાઇડ: RCOOH + NH₃ → RCOONH₄ → (ગરમ) → RCONH₂ + H₂O.
એસિડ વ્યુત્પન્નોની પ્રવૃત્તિ ક્રમ: એસિડ ક્લોરાઇડ > એસિડ આનાઇડ > એસ્ટર > એમાઇડ.
📝 એસિડ ક્લોરાઇડ સૌથી પ્રવૃત્ત વ્યુત્પન્ન છે, કારણ કે Cl⁻ સારો લીવિંગ ગ્રુપ છે.
RCOCl + R'OH → RCOOR' + HCl | RCOCl + NH₃ → RCONH₂ + HCl
મહત્વની ચતુર્ધ પ્રતિક્રિયાઓ (Tollens, Fehling, Iodoform)
ટોલેન્સ પ્રયોગ: ઇલ્ડિહાઇડ્સ Ag⁺ ને Ag માં ઘટાડે છે, ચાંદીનું આરીસું બનાવે છે. કેટોન્સ (methyl ketone ઉપર્યુક્ત) આ પ્રતિક્રિયા આપતા નથી.
ફેહલિંગ પ્રયોગ: ઇલ્ડિહાઇડ્સ Cu²⁺ (વાદળી) ને Cu₂O (લીલા-લોહીત) માં ઘટાડે છે. કેટોન્સ આ પ્રતિક્રિયા આપતા નથી.
આયોડોફોર્મ પ્રતિક્રિયા: CH₃CO– અથવા CH₃CH(OH)– સમૂહ ધરાવતા સંયોજનો I₂/NaOH વડે જેલેબર્ડ સંયોજન આપે છે.
આયોડોફોર્મ (CHI₃) પીળું અવક્ષેપ છે. આ પ્રતિક્રિયા ફક્ત મિથાઇલ કેટોન્સ અને એથેનોલ માટે સુવિશેષ છે.
📝 ટોલેન્સ અને ફેહલિંગ બંને ઇલ્ડિહાઇડ્સને કેટોન્સથી અલગ પાડે છે, પરંતુ ટોલેન્સ સૂંઘવાળા એલ્ડિહાઇડ્સ (બેન્ઝાલ્ડિહાઇડ) સાથે પણ કામ કરે છે.
RCHO + 2[Ag(NH₃)₂]⁺ + 3OH⁻ → RCOO⁻ + 2Ag↓ + 4NH₃ + 2H₂O | RCOCH₃ + 3I₂ + 4NaOH → CHI₃↓ + RCOONa + 3NaI + 3H₂O
ઇલ્ડિહાઇડ્સ અને કેટોન્સના વિશિષ્ટ પ્રતિક્રિયાઓ
એમ્મોનિયાનાં વ્યુત્પન્નો: હાઈડ્રોક્સિલામાઇન, હાઇડ્રેઝીન, સેડોઝીન સાથે પ્રતિક્રિયા કરી અનુક્રમે ઑક્સિમ, હાઇડ્રેઝોન, સેડાઝોન બનાવે છે.
આલ્ડોલ સંલગ્નન પછીની પ્રતિક્રિયાઓ: ઉદાહરણ તરીકે, બ્યુટ-2-ઈનલનું રિડક્શન કરીને બ્યુટેનલ મળી શકે છે.
પ્રતિક્રિયાઓના માર્ગદર્શન: C=O બોન્ડમાં ન્યુક્લિયોફિલિક ઉમેરણ અને C–H બોન્ડ (α-સ્થાને) માં એસિડિક પ્રવૃત્તિ.
📝 ઇલ્ડિહાઇડ્સમાં α-H હોય તો આલ્ડોલ સંલગ્નન શક્ય બને. કેટોન્સમાં પણ આ શક્ય છે, પરંતુ ધીમું.
RCHO + NH₂OH → RCH=NOH + H₂O (ઑક્સિમ) | R₂C=O + NH₂NH₂ → R₂C=NNH₂ + H₂O (હાઇડ્રેઝોન)
કાર્બોક્સિલિક એસિડ્સના વિશિષ્ટ પ્રતિક્રિયાઓ
હાલોજેનേഷન (Հell-Volhard-Zelinsky): α-હાઈડ્રોજન પર હાલોજન ઉમેરવા માટે P (લોહિત) વડે પ્રરંભિત કરવામાં આવે છે.
કાર્બોક્સિલિક એસિડ્સનું રિડક્શન: LiAlH₄ વડે પ્રાઇમરી આલ્કોહોલમાં રિડ્યુઝ થાય છે. NaBH₄ સામાન્ય રીતે કાર્બોક્સિલિક એસિડ રિડ્યુઝ કરતું નથી.
ડિકાર્બોક્સિલેશન: સોડિયમ લવણને સોડાલાઇડ (NaOH+CaO) સાથે ગરમ કરતાં એલ્કેન મળે છે. RCOONa + NaOH → RH + Na₂CO₃.
Hoffmann degradation: RCONH₂ + Br₂ + 4NaOH → RNH₂ + Na₂CO₃ + 2NaBr + 2H₂O. આ પ્રતિક્રિયા એમાઇડને એમાઇનમાં બદલે છે.
📝 ડિકાર્બોક્સિલેશન અને Hoffmann degradation બંને NEET માટે ચોક્કસપણે યાદ રાખવા જેવો છે.
CH₃COOH + Cl₂/P → ClCH₂COOH (ક્લોરોએસિટિક એસિડ) | RCOONa + NaOH(CaO) → RH + Na₂CO₃
સંયુક્ત પ્રતિક્રિયાઓ અને NEET ટીપ્સ
ઇલ્ડિહાઇડ્સ અને કેટોન્સનું પરીક્ષણ: ટોલેન્સ, ફેહલિંગ, આયોડોફોર્મ પ્રયોગો વડે તેમની ઓળખ કરી શકાય છે.
કાર્બોક્સિલિક એસિડ્સનું પરીક્ષણ: NaHCO₃ સાથે પ્રતિક્રિયાથી CO₂ બબલ્સ મળે છે. આ પ્રતિક્રિયા ફીનોલને એસિડથી અલગ કરે છે.
ફીનોલ એસિડિક નથી, તે NaHCO₃ સાથે CO₂ આપતું નથી. આ ચેહ્મતી ભેદ NEET માં પુનરાવર્તિત થાય છે.
📝 પ્રશ્નોમાં ઘણીવાર 'પ્રતિક્રિયા શૃંખલા' (reaction sequence) આપવામાં આવે છે; દરેક પગલાની ઓળખ મહત્વની છે.
C₆H₅OH + NaHCO₃ → No reaction | CH₃COOH + NaHCO₃ → CH₃COONa + H₂O + CO₂↑
અધ્યાય સારાંશ અને પુનરાવર્તન
ઇલ્ડિહાઇડ્સ અને કેટોન્સ C=O બોન્ડ ધરાવે છે; ન્યુક્લિયોફિલિક ઉમેરણ તેમની મુખ્ય પ્રતિક્રિયા છે.
કાર્બોક્સિલિક એસિડ્સમાં –COOH સમૂહ છે; એસિડિક ગુણધર્મ, એસ્ટરિફિકેશન, વ્યુત્પન્નો બનાવવા તેમના મુખ્ય ગુણધર્મો છે.
આ અધ્યાયમાં 90% પ્રશ્નો રિએક્શન મેકેનિઝમ, પરીક્ષણ પ્રયોગો અને નામકરણ પરથી આવે છે.
📝 અભ્યાસ દરમિયાન દરેક પ્રતિક્રિયાનું સંતુલિત સમીકરણ યાદ રાખો અને α-હાઇડ્રોજનની હાજર/અસ્તિત્વ પર ધ્યાન આપો.
