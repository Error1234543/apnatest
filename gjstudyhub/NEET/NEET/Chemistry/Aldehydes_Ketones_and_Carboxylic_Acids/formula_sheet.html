ઍલડિહાઇડ્સ, કેટોન્સ અને કાર્બોક્સિલિક એસિડ — સૂત્ર પત્રક

🩺 NEET UG — Gujarati • Chemistry • Aldehydes, Ketones and Carboxylic Acids

⚡ સૂત્રો

ઍલડિહાઇડનું આયોડોફોર્મ અભિક્રિયા (ધન પરીક્ષણ): R−CHO + 3I2 + 4NaOH → RCOONa + CHI3↓ + 3NaI + 3H2O (જ્યારે R માં CH3−CO− ગ્રુપ હોય તો ધુવરા પલાળ
CH3CHO અથવા RCOCH3 + I2/NaOH પરથી CHI3 (આયોડોફોર્મ) મળે છે · SI: N/A (અભિક્રિયા) · માત્ર એસિટોન અને મીથેનલ એલડિહાઇડ જ આ ટેસ્ટ આપે છે; બીજા ઍલડિહાઇડ્સ આપતા નથી
કેટોનનું આયોડોફોર્મ અભિક્રિયા: R−CO−CH3 + 3I2 + 4NaOH → RCOONa + CHI3↓ + 3NaI + 3H2O
CH3COCH3 જેવા મીથાઇલ કેટોન્સ CHI3 આપે છે · SI: N/A · માત્ર મીથાઇલ કેટોન્સ (RCOCH3) આ અભિક્રિયા આપે છે
રોઝેનમ્યુન્ડ રિડક્શન (એસિડ ક્લોરાઇડ → ઍલડિહાઇડ): R−COCl + H2 → R−CHO + HCl (Catalyst: Pd/BaSO4 − poisoning with quinoline/sulphur)
R−COCl = એસિડ ક્લોરાઇડ; Pd/BaSO4 = પ્રેરક; H2 = હાઇડ્રોજન વાયુ · SI: N/A · એસિડ ક્લોરાઇડનું ઍલડિહાઇડમાં થતું આંશિક રિડક્શન
સ્ટેન્લી અભિક્રિયા (ઓર્ગેનિક ઝોનોલિસિસ પછી ઝિન્ક અને પાણી): Ozonide + Zn + H2O → RCHO + R'CHO + H2O2 (અથવા R2CO રચના)
ઝોનોલાઇડ → ઝિન્ક/પાણી દ્વારા ભાંગીને ઍલડિહાઇડ/કેટોન મળે છે · SI: N/A · ઍલકિનનું ઝોનોલિસિસ; ઝિન્ક ઓઝોનાઇડનું વિઘટન કરે છે
કાર્બોક્સિલિક એસિડની ઉત્પત્તિ — ઓક્સિડેશન: R−CH2OH → [O] → R−CHO → [O] → R−COOH (KMnO4/H+ અથવા K2Cr2O7/H+)
[O] = ઓક્સિડાઇઝિંગ એજન્ટ (KMnO4, K2Cr2O7); RCH2OH = પ્રાથમિક ઍલકોહોલ · SI: N/A · પ્રાથમિક ઍલકોહોલ અથવા ઍલડિહાઇડનું પ્રબળ ઓક્સિડેશન
હેટ્ઝમેન એસિડીકિડ અભિક્રિયા (પ્રાઇમેરી નાઈટ્રિલ → કાર્બોક્સિલિક એસિડ): R−CN + 2H2O + H+ (heat) → R−COOH + NH4+
R-CN = નાઈટ્રિલ; H+/heat = ઍસિડિક જલવિઘટન · SI: N/A · નાઈટ્રિલનું ઍસિડિક જલવિઘટન
કાર્બોક્સિલિક એસિડનું પ્રબળ ઘટાડો (લીડ્સ/ગ્રીનર્ડ રિએજન્ટ): R−COOH + 4[H] → R−CH2OH + H2O (LiAlH4 દ્વારા)
LiAlH4 = પ્રબળ રિડ્યુસિંગ એજન્ટ; RCOOH = કાર્બોક્સિલિક એસિડ · SI: N/A · કાર્બોક્સિલિક એસિડનું LiAlH4 દ્વારા પ્રાથમિક ઍલકોહોલમાં રિડક્શન
CDI / ક્લોરાઇડ બનાવવા માટે PCl5 અથવા SOCl2: R−COOH + PCl5 → R−COCl + POCl3 + HCl; R−COOH + SOCl2 → R−COCl + SO2 + HCl
PCl5 = ફોસ્ફરસ પેન્ટાક્લોરાઇડ; SOCl2 = થાયોનિલ ક્લોરાઇડ · SI: N/A · કાર્બોક્સિલિક એસિડને એસિડ ક્લોરાઇડમાં રૂપાંતર
સોડા લાઇમ ડિਕાર્બોક્સિલેશન: R−COONa + NaOH(soda lime) → R−H + Na2CO3
R−COONa = સોડિયમ કાર્બોક્સિલેટ; NaOH/CaO = સોડા લાઇમ · SI: N/A · સોડિયમ કાર્બોક્સિલેટ + સોડા લાઇમ → આલ્કેન (ડિકાર્બોક્સિલેશન)
હેવાર્ડ અભિક્રિયા (કેટોન + H2O2 + base → બેરિલ્લિયમ): Phenyl ketone + H2O2 → Phenolic aldehyde + CH3OH (peroxide cleavage)
C6H5COCH3 + H2O2 → C6H5CHO + CH3OH · SI: N/A · બેન્ઝોઇક અભિક્રિયા
કાર્બોક્સિલિક એસિડનું હેમિઝ્ટેટલ અભિક્રિયા (અમોનિયા સાથે): R−COOH + NH3 → R−COONH4 → heat → R−CONH2 + H2O
R−COOH = એસિડ; NH3 = અમોનિયા; R−CONH2 = એમાઇડ · SI: N/A · એસિડ + અમોનિયા → એમાઇડ
Bucherer β-ketoester synthesis / acetoacetic ester: CH3COCH2COOC2H5 → heat → CH3COCH3 + CO2 + C2H5OH
એસિટોએસિટિક એસ્ટરનું વિઘટન · SI: N/A · એસિટોએસિટિક એસ્ટર ડિસ્ટિલેશન
એલડિહાઇડ + Grignard reagent → પ્રાથમિક ઍલકોહોલ: R−CHO + R'MgX → R−CH(R')−OMgX → H2O/H+ → R−CH2−R' (primary alcohol)
R'MgX = ગ્રિગનાર્ડ રિએજન્ટ; R−CHO = ઍલડિહાઇડ · SI: N/A · ઍલડિહાઇડ + ગ્રિગનાર્ડ → પ્રાથમિક ઍલકોહોલ (HCHO → प्राथमिक with any R'), other aldehydes give secondary alcohols
કેટોન + Grignard → સેકન્ડરી/ટર્શરી ઍલકોહોલ: R−CO−R' + R''MgX → R−C(R')(R'')−OMgX → H2O/H+ → R−C(OH)(R')(R'') (tertiary alcohol)
R''MgX = ગ્રિગનાર્ડ; RCOHR' = કેટોન · SI: N/A · કેટોન + ગ્રિગનાર્ડ → ટર્શરી ઍલકોહોલ
Cannizzaro અભિક્રિયા (ગેર-એનિલડીહાઇડ્સની disproportionation): 2R−CHO (no α-H) + conc. NaOH → R−CH2OH + R−COONa
R−CHO = એલડિહાઇડ without alpha hydrogen; NaOH = conc. base · SI: N/A · α-હાઈડ્રોજન વગરના ઍલડિહાઇડ્સ (જેવા HCHO, (CH3)3C-CHO) માટે

🔗 સંબંધો

  • એલડિહાઇડ્સ ઍલ્કિલ યોગ્ય કરતાં વધુ પ્રતિક્રિયાશીલ હોય છે કારણ કે સ્ટેરિક અવરોધ ઓછો હોય છે અને ઇલેક્ટ્રોનિક અસરો.
  • કેટોન્સમાં સબ્સ્ટિટ્યુએન્ટ્સ હોવાથી સ્ટેરિક અવરોધ વધી જાય છે, તેથી ઍલડિહાઇડ્સ કરતાં ઓછી પ્રતિક્રિયાશીલ.
  • કાર્બોક્સિલિક એસિડ ઍલડિહાઇડ/કેટોન કરતાં ઓછી પ્રતિક્રિયાશીલ હોય છે કારણ કે કાર્બોનિલ કાર્બન પર સંપૂર્ણ ધન વીજભાર ઘટી જાય છે.
  • આલ્ફા-હાઈડ્રોજન ધરાવતા ઍલડિહાઇડ્ડ Cannizzaro નહીં પણ aldol condensation આપે છે; alpha-hydrogen વગરના હજુ Cannizzaro આપે છે.
  • કાર્બોક્સિલિક એસિડની એસિડિટીમાં EWG (જેવા NO2, F, Cl, CN) વધારે છે; EDG (જેવા CH3, OCH3) ઘટાડે છે.
  • કાર્બોક્સિલિક એસિડનું ઉત્તમ આબેહુબ કારણે બોઈલિંગ પોઇન્ટ ઍલડિહાઇડ/કેટોન કરતાં વધારે હોય છે.

🎯 ટ્રિક્સ

આયોડોફોર્મ ટેસ્ટ માંત્ર CH3CHO અને CH3COR પ્રકારના સંયોજનો આપે છે; બીજા ઍલડિહાઇડ્ડ/કેટોન્સ આપતાં નથી.
Cannizzaro માત્ર એવા ઍલડિહાઇડ્સમાં જ થાય છે જ્યાં alpha-hydrogen ના હોય; alpha-hydrogen હોય તો aldol condensation થાય છે.
શેવાલિઅર ટેસ્ટ માંત્ર ઍલડિહાઇડ્સ આપે છે, કેટોન્સ નહીં (Tollens and Fehling solutions only oxidize aldehydes).
કાર્બોક્સિલિક એસિડના સોડિયમ કાર્બોનેટ/બાયકાર્બોનેટ સાથે CO2 મુક્ત થાય છે — આ કાર્બોક્સિલિક એસિડનું મુખ્ય ઓળખાણ ટેસ્ટ છે.
ઍલડિહાઇડ્સની એસિડિક ઑક્સિડેશન માટે Tollens/Fehling test positive હોય છે — કેટોન્સ negative હોય છે (એસિટોન સિવાય).

⚠️ ભૂલો

બધા ઍલડિહાઇડ્સ Cannizzaro આપે છે — ખોટું; માત્ર α-hydrogen વગરના ઍલડિહાઇડ્ડ cannizzaro આપે છે.
બધા કેટોન્સ આયોડોફોર્મ આપે છે — ખોટું; માત્ર methyl ketones (RCOCH3) આપે છે.
Fehling solution બધા ઍલડિહાઇડ્સ સાથે positive આપે છે — ખોટું; Fehling માત્ર એલિફેટિક ઍલડિહાઇડ્સ સાથે positive આપે છે, બેન્ઝોઇક aldhyde negative આપે છે.
કેટોન્સ ટોલેન્સ અને ફેહલિંગ ટેસ્ટ આપે છે — ખોટું; કેટોન્સ સામાન્ય રીતે આ ટેસ્ટ negative આપે છે.
એસિડિકિડ બનાવતી વખતે PCl5 સાથે SOCl2 નો ઉપયોગ કરતાં HCl + SO2 મળે છે; PCl5 થી POCl3 + HCl મળે છે — ધ્યાન રાખો.
કાર્બોક્સિલિક એસિડનો alkali with soda lime → carboxylic acid; યાદ રાખો તે alkane બને છે (decaboxylation).
ઍલડિહાઇડ્સ અને કેટોન્સના boiling points — alkane કરતાં વધુ હોય છે પરંતુ alcohol કરતાં ઓછા હોય છે (hydrogen bonding ના હોવાથી).
