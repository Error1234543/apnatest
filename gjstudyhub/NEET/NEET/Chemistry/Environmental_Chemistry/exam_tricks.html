🎯 પરીક્ષા ટ્રિક્સ

સલ્ફર ડાયોક્સાઇડ (SO₂) અને નાઇટ્રોજન ઑક્સાઇડ્સ (NOx) સાચે જ વરસાદને ખાટો બનાવે છે — એટલે 'એસિડ રૅઇન'નો સંબંધ આ જ બે પરિવાર સાથે છે. જો વિકલ્પમાં CO₂ કે CH₄ હોય, તેઓ એસિડિટી માટે જવાબદાર નથી.
પ્રશ્ન: 'કયા પ્રદૂષકો એસિડ વરસાદનું કારણ બને છે?' અથવા 'ખાટા વરસાદ મુખ્યત્વે કોના કારણે?'
દા.ત.: પ્રશ્ન: એસિડ રૅઇનમાં ઉપસ્થિત એસિડો કયા છે? — (1) H₂SO₄ અને HNO₃ ✓ (2) H₂CO₃ અને HCl ✗
ઓઝોન સ્તરનું ક્ષયન કરનારા સામગ્રીઓની યાદ રાખવા માટે 'CFC' શબ્દનો ઉપયોગ થાય છે — Chlorofluorocarbon. CFC માંથી મુક્ત થતો Cl• મુક્ત મૂળ (free radical) ઓઝોનને તોડે છે. જવાબમાં 'CFC' જોવા મળે તો તે ઓઝોનક્ષય સાથે જોડાયેલો છે.
પ્રશ્ન: 'ઓઝોન સ્તરના ક્ષયન માટે દોષી કયો પદાર્થ છે?' અથવા 'ઓઝોન છિદ્રનું કારણ શું છે?'
દા.ત.: પ્રશ્ન: નીચેમાંથી કયો ઓઝોન સ્તરને નુકસાન પહોંચાડે છે? — (A) CFCs ✓ (B) CO₂ ✗ (C) SO₂ ✗
પ્રકાશરાસાયણિક ધૂંવાળો (Photochemical smog) → UV પ્રકાશ + NOx +HC → O₃ + PAN જેવા દ્વિતિય પ્રદૂષકો. શહેરી/ઉષ્ણકટિબંધીય વિસ્તારોમાં વધુ. તેમાં O₃ અને PAN જેવા 'ઑક્સિડેન્ટ' હોય છે. સામાન્ય ધૂંવાળો (Classical smog) → London smog = કણો + SO₂ + ભેજ (ઠંડા ભેજવાળા વાતાવરણમાં). જો પ્રશ્નમાં 'UV પ્રકાશ' દેખાય → Photochemical smog;
પ્રશ્ન: 'પ્રકાશરાસાયણિક ધૂંવાળો ક્યારે બને છે?' અથવા 'કોને 'લંડન ધૂંવાળો' કહેવાય?'
દા.ત.: પ્રશ્ન: પ્રકાશરાસાયણિક ધૂંવાળામાં કયો પ્રદૂષક સામેલ નથી? — (A) O₃ (B) PAN (C) SO₂ ✓ (સામાન્ય ધૂંવાળાનો ભાગ છે)
greenhouse effect (ઘરેલું અસર) માટે જવાબદાર વાયુઓ: CO₂, CH₄, N₂O, CFCs, O₃ — આ તમામને 'ગ્રીનહાઉસ ગેસ' તરીકે ઓળખો. O₂ અને N₂ ગ્રીનહાઉસ ગેસ નથી. જો વિકલ્પમાં O₂ હોય, તે તરત બાદ કરો.
પ્રશ્ન: 'નીચેનામાંથી કયો ગ્રીનહાઉસ ગેસ નથી?' અથવા 'ગlobal warming માટે કونસો વાયુ જવાબદાર નથી?'
દા.ત.: પ્રશ્ન: ગ્રીનહાઉસ અસરમાં ફાળો ન આપતો વાયુ: (A) CO₂ (B) CH₄ (C) O₂ ✓ (D) N₂O
Eutrophication → પોષક ધન જળ (નೈટ્રેટ/ફોસ્ફેટ વધુ) → શેવાલનો અતિવૃદ્ધિ → dissolved oxygen ઘટી જાય → માછલીઓ મૃત્યુ. આ પ્રક્રિયામાં BOD (Biochemical Oxygen Demand) વધે છે. જો પ્રશ્નમાં 'dissolved oxygen ઘટે' અથવા 'BOD વધે' દેખાય → Eutrophication નીચે આવે છે.
પ્રશ્ન: 'જળ પ્રદૂષણથી D.O. કેમ ઘટે છે?' અથવા 'Eutrophication ના અસરો કઈ છે?'
દા.ત.: પ્રશ્ન: ઇયુટ્રોફિકેશન દરમિયાન કશું થાય છે? — (A) D.O. વધે છે ✗ (B) BOD વધે છે ✓ (C) pH વધે છે ✗
બાયોમાગ્નીફિકેશન (Biomagnification) → પર્યાવરણમાં રહેલા અવિભાજ્ય (non-biodegradable) રસાયણો જેમ DDT, PCB, ભારી ધાતુઓ → ખોરાક જંત્ર (food chain) માં ઉપર જતાં સાંદ્રતા વધતી જાય. DDT ≈ 0.003 ppm → પાણી → પ્લેંકટન → માછલી → કિનારી પક્ષી → પક્ષીના ઈંડા છિદ્રાયમાન, પડી જાય. યાદ રાખો: non-biodegradable = biomagnification; biodegradable = નહીં.
પ્રશ્ન: 'Biomagnification કયા પ્રકારના પદાર્થોમાં થાય છે?' અથવા 'DDT ની આંતરિક સ્તરે સાંદ્રતા કેમ વધે છે?'
દા.ત.: પ્રશ્ન: નીચેમાંથી કયા પદાર્થનું બાયોમાગ્નીફિકેશન થાય છે? — (A) DDT ✓ (B) કાગળ ✗ (C) અનાજ ✗
Green Chemistry નો ઉદ્દેશ્ય → રસાયણો અને પ્રક્રિયાઓ એવી રીતે ડિઝાઇન કરવી કે પર્યાવરણ પર પડતો પ્રભાવ ઘટાડી શકાય. યાદ રાખો: 'Green Chemistry = prevention at source, not cleanup after.' જો વિકલ્પમાં 'કચરો ઉપાડવો' અથવા 'બાદમાં સફાઈ' હોય → તે Green Chemistry નથી.
પ્રશ્ન: 'Green Chemistry નો મુખ્ય ઉદ્દેશ્ય શું છે?' અથવા 'ગ્રીન કેમિસ્ટ્રીના સિદ્ધાંતો કયા છે?'
દા.ત.: પ્રશ્ન: Green Chemistry અનુસાર પ્રદૂષણનું નિયંત્રણ: (A) પ્લાંટ પછી સફાઈ ✗ (B) ઉત્પાદન સ્તરે રોકવું ✓ (C) પ્રદૂષકોને પાણીમાં નાખવા ✗
CO (કાર્બન મોનોક્સાઇડ) → હીમોગ્લોબિન સાથે O₂ કરતાં ~200–250 ગુણ વધુ આસક્તિ (affinity) ધરાવે છે → Carboxyhemoglobin બને → ઑક્સિજન પહોંચાડવાની ક્ષમતા ઘટે. જવાબમાં 'Hb with CO' જોવા મળે → CO વધુ મજબૂતીથી જોડાય છે.
પ્રશ્ન: 'CO હીમોગ્લોબિન સાથે કેમ જોડાય છે?' અથવા 'CO విషપૂર્ણ કેમ છે?'
દા.ત.: પ્રશ્ન: CO હીમોગ્લોબિન સાથે Kaffinity O₂ કરતાં કેટલી ગણી વધુ? — (A) 200–250 ગણી ✓ (B) 10 ગણી ✗ (C) 1 ગણી ✗
particulate matter (PM) ના પ્રકાર: PM2.5 ≤ 2.5 μm (કિડવીમાં પ્રવેશે, મૃત્યુ કારક), PM10 ≤ 10 μm (શ્વાસનાળામાં અટકે). જો પ્રશ્નમાં 'શ્વાસ લેવાની મુશ્કેલી' અથવા 'કિડવીમાં પ્રવેશે' હોય → સાચો જવાબ નાનો કણ (PM2.5); 'નાક-ગળામાં અટકે' → PM10.
પ્રશ્ન: 'PM2.5 અને PM10 માં શું તફાવત છે?' અથવા 'કયો કણ કિડવીમાં પ્રવેશે છે?'
દા.ત.: પ્રશ્ન: કયો કણ હૃદય અને શ્વાસ સંબંધી રોગો માટે સૌથી જોખમી? — (A) PM10 ✗ (B) PM2.5 ✓ (C) PM100 ✗
N₂O (નાઈટ્રસ ઑક્સાઇડ) → બંને ગ્રીનહાઉસ ગેસ AND ozone-depleting substance (સطح પર Cl ઉત્પન્ન કરી શકે). એક જ વાયુ બે કાર્ય કરે → ધ્યાન રાખવું.
પ્રશ્ન: 'કયો વાયુ ગ્રીનહાઉસ પણ છે અને ઓઝોન ક્ષયન પણ કરે છે?'
દા.ત.: પ્રશ્ન: નીચેમાંથી કયો વાયુ ગ્રીનહાઉસ અને ઓઝોન ક્ષયકર્ત્ર બંને છે? — (A) CO₂ ✗ (B) N₂O ✓ (C) O₃ ✗
Industrial effluents → પ્રદૂષકો ઝડપી ઓક્સિડેશન માટે BOD (Biochemical Oxygen Demand) વધારે છે. કચરાના ગંધના પાણીમાં BOD વધારે હોય છે; સ્વચ્છ પાણીમાં ઓછું હોય છે. યાદ રાખો: BOD↑ = દુષ્ટ પાણી; BOD↓ = સ્વચ્છ પાણી.
પ્રશ્ન: 'સ્વચ્છ પાણીમાં BOD કેવી હોય?' અથવા 'BOD વધવાનો અર્થ શું?'
દા.ત.: પ્રશ્ન: દૂષિત પાણી માટે BOD નું મૂલ્ય: (A) <5 ppm ✗ (B) >5 ppm ✓ (C) 1 ppm ✗
SO₂ પ્રદૂષણ માટેનું સાધન: Electrostatic precipitator (ESP) → કણોને ચાર્જ કરીને દૂર કરે છે. Scrubber → SO₂ જેવા વાયવ્ય પ્રદૂષકોને દ્રાવણમાં ઝડપી લઈ લે છે. જો પ્રશ્નમાં 'સૂક્ષ્મ કણ' → ESP; 'વાયવ્ય પ્રદૂષક દૂર કરવો' → Scrubber.
પ્રશ્ન: 'SO₂ દૂર કરવા માટે કયો ઉપકારણ વાપરવામાં આવે છે?' અથવા 'કણ પ્રદૂષકો કેવી રીતે દૂર કરો?'
દા.ત.: પ્રશ્ન: વાયવ્ય પ્રદૂષક SO₂ શોષવા માટે કયું સાધન? — (A) ESP ✗ (B) Scrubber ✓ (C) Incinerator ✗
PAN (Peroxyacyl nitrates) → પ્રકાશરાસાયણિક ધૂંવાળાનો પ્રતિકારક પ્રદૂષક, વનસ્પતિઓ માટે એકદમ હાનિકારક, આંખને છાળ ચઢાવે. PAN = પર્યાવરણમાં સ્થિર નથી, ઝડપથી વિઘટન પામે છે. યાદ રાખો: PAN =植物危害 + 眼刺激.
પ્રશ્ન: 'PAN કયા પ્રકારનો પ્રદૂષક છે?' અથવા 'PAN ની વિશેષતાઓ કઈ છે?'
દા.ત.: પ્રશ્ન: PAN વિશે શું સાચું છે? — (A) વનસ્પતિ માટે હાનિકારક ✓ (B) સામાન્ય ધૂંવાળામાં મળે ✓ (C) સ્થિર પ્રદૂષક છે ✗
Solid waste management ના 3R નિયમ: Reduce, Reuse, Recycle. આ ઉપરાંત composting અને vermicomposting biodegradable કચરા માટે. Landfill non-biodegradable માટે. Pyrolysis incineration — both heat and reduce volume.
પ્રશ્ન: 'કચરાના નિગરણીના મૂળભૂત સિદ્ધાંતો કયા છે?' અથવા 'Biodegradable કચરો કઈ રીતે હેન્ડલ કરવો?'
દા.ત.: પ્રશ્ન: કચરાના નિગરણી માટે 3R માં કયા શબ્દો સામેલ છે? — (A) Reduce, Reuse, Recycle ✓ (B) Render, Remove, Return ✗
Domestic wastewaters → biological treatment (Primary → settling; Secondary → aerobic/anaerobic bacterial digestion → activated sludge). Activated sludge → bacterial floc (બેક્ટેરિયલ floc) → BOD ઘટાડે. જો પ્રશ્નમાં 'bacterial floc' અથવા 'activated sludge' →Secondary treatment.
પ્રશ્ન: 'વાસિષ્ઠ પાણી શુદ્ધિકરણમાં secondary treatment શું કરે છે?'
દા.ત.: પ્રશ્ન: Activated sludge process માં શું થાય છે? — (A) BOD ઘટે છે ✓ (B) BOD વધે છે ✗ (C) pH વધે છે ✗
