પર્યાવરણીય રસાયણશાસ્ત્ર — સૂત્ર શેડ

🩺 NEET UG — Gujarati • Chemistry • Environmental Chemistry

⚡ સૂત્રો

બાયોકેમિકલ ઓક્સિજન ડિમાન્ડ (BOD): BOD = (D.O. initial − D.O. final) × Dilution factor
D.O. = ઓક્સિજનની વિઘટનક્ષમતા (Dissolved Oxygen); Dilution factor = જળના નમૂનાનું તણાવ ગુણક (દૂધરોપણ અનુપાત) · SI: mg/L (માઇક્રોગ્રામ પ્રતિ લિટર) · જ્યારે જળમાં પ્રદૂષકોની જૈવિક વિઘટનક્ષમતા મપવા માટે BOD ની ગણતરી કરવી હોય; સામાન્ય રીતે 5 દિવસના 20°C તાપમાને પ્રયોગ કરવામાં આવે છે.
વરસાદના pH મર્યાદા ( એસિડ વરસાદ ): pH < 5.6 → એસિડ વરસાદ (Acid Rain)
pH = જળઅક્ષમતા સૂચક (potential of Hydrogen); 5.6 = સામાન્ય ચોખ્ખા વરસાદનો pH · SI: એકમરહિત (Dimensionless) · જ્યારે વાતાવરણીય SO₂ અને NOₓ પાણીમાં ઓગળી H₂SO₄ અને HNO₃ બનાવે છે.
CO₂ તુલ્ય ગ્રીનહાઉસ ઉત્સર્જન: CO₂-eq = માસ × GWP (Global Warming Potential)
CO₂-eq = કાર્બન ડાયોક્સાઇડ તુલ્ય ઉત્સર્જન; GWP = ગ્લોબલ વોર્મિંગ પોટેન્શિયલ; CH₄ નું GWP ≈ 25–28, N₂O નું GWP ≈ 298 · SI: kg CO₂-eq · વિવિધ ગ્રીનહાઉસ ગેસોના ઉત્સર્જનને એક સામાન્ય એકમમાં રૂપાંતરિત કરવા માટે.
ઓઝોન સ্তરની ગણતરી (ડ્યુબસન એકમ): 1 DU = 2.69 × 10¹⁶ અણુઓ/cm²
DU = ડ્યુબસન યુનિટ (Dobson Unit); O₃ નાં અણુઓની સ્તંભઘનતા દર્શાવે છે · SI: Dobson Unit (DU) · વાતાવરણમાં ઓઝોનની જાડાઈ માપવા માટે; સામાન્ય ઓઝોન સ્તર ≈ 300 DU.
એસિડ વરસાદમાં SO₂ નું રૂપાંતર: 2 SO₂ + O₂ → 2 SO₃; SO₃ + H₂O → H₂SO₄
SO₂ = સલ્ફર ડાયોક્સાઇડ; SO₃ = સલ્ફર ટ્રાયોક્સાઇડ; H₂SO₄ = સલ્ફ્યુરિક એસિડ · SI: — (રાસાયણિક સંતુલિત સમીકરણ) · વાતાવરણમાં SO₂ નું ઓક્સિડેશન થઈ એસિડ વરસાદ બનવાની પ્રક્રિયા.
એસિડ વરસાદમાં NOₓ નું રૂપાંતર: 2 NO₂ + H₂O → HNO₃ + HNO₂; 4 NO₂ + O₂ + 2 H₂O → 4 HNO₃
NOₓ = નાઇટ્રોજન ઑક્સાઇડ; HNO₃ = નાઇટ્રિક એસિડ · SI: — (રાસાયણિક સમીકરણ) · વાહનો અને ઉદ્યોગોમાંથી ઉત્પન્ન થતા NOₓ નું વરસાદમાં રૂપાંતર.
કાર્બન મોનોક્સાઇડનું શ્વસનબંધ પ્રભાવ: Hb + 4CO ⇌ Hb(CO)₄ ; K_CO/K_O₂ ≈ 210
Hb = હીમોગ્લોબિન; CO = કાર્બન મોનોક્સાઇડ; O₂ = ઓક્સિજન; K = બંધન અચળાંક · SI: — (સંબંધ) · CO નું હીમોગ્લોબિન સાથેનું બંધન O₂ કરતાં ~210 ગુણાંક વધુ પ્રબળ છે.
પાર્ટિક્યુલેટ મેટર (PM) વર્ગીકરણ: PM₁₀ ≤ 10 μm ; PM₂.₅ ≤ 2.5 μm
PM = Particulate Matter; μm = માઇક્રોમીટર · SI: μm · વાયુ પ્રદૂષકોના કણના કદ આધારે વર્ગીકરણ. PM₂.₅ શ્વાસનળીમાં ઊંડે સુધી પહોંચે છે.
વરસાદનો pH સામાન્ય મૂલ્ય: pH_normal_rain ≈ 5.6
કારણ: વાતાવરણીય CO₂ પાણીમાં ઓગળી H₂CO₃ (કાર્બોનિક એસિડ) બનાવે છે · SI: એકમરહિત · ચોખ્ખો વરસાદ; એસિડ વરસાદના pH સાથે સરખામણી માટે.
સ્મોગ પ્રકાર: કલાસિકલ સ્મોગ: SO₂ + ધૂમ્ર + ભેજ → H₂SO₄ mist ફોટોકેમિકલ સ્મોગ: NOₓ + HC + UV પ્રકાશ → O₃ + PAN
HC = હાઇડ્રોકાર્બન; PAN = પેરોક્સીએસિલ નાઈટ્રેટ; O₃ = ઓઝોન · SI: — (વાર્ણવિક સમીકરણ) · શીત અને ભીની હવામાનમાં ક્લાસિકલ સ્મોગ; ગરમ અને ધૂપયુક્ત હવામાનમાં ફોટોકેમિકલ સ્મોગ.

🔗 સંબંધો

  • BOD જેટલું ઊંચું હોય તેટલું જળ પ્રદૂષિત; સાફ જળનું BOD < 5 mg/L, પ્રદૂષિત જળનું BOD > 17 mg/L.
  • એસિડ વરસાદનો pH 5.6 થી ઓછો હોય — SO₂ અને NOₓ મુખ્ય પ્રદૂષકો કારણભૂત છે.
  • ગ્રીનહાઉસ ગેસો (CO₂, CH₄, N₂O, CFCs) નું સંયુક્ત પ્રભાવ ગ્લોબલ વોર્મિંગ માટે જવાબદાર છે.
  • CFCs (ક્લોરોફ્લોરોકાર્બન) સ્ટ્રેટોસ્ફિયરમાં UV દ્વારા Cl· મુક્ત કરે છે જે O₃ → O₂ રૂપાંતરણ કરવા દ્વારા ઓઝોન પરોળો સર્જે છે.
  • O₃ પરોળોમાં ધ્રુવીય વિસ્તાર (અંટાર્કટિક) સૌથી વધુ પ્રભાવિત છે કારણ કે ધ્રુવો પર પોલર સ્ટ્રેટોસ્ફિયર ક્લાઉડ (PSC) બને છે.
  • ઇયુટ્રોફિકેશન → જળાશયમાં P (ફોસ્ફેટ) અને N (નાઇટ્રેટ) વધારો → શૈવાળ વધુ વૃદ્ધિ → DO ઘટાડો → મચ્છી મૃત્યુ → BOD વધારો.
  • પાણીનું પ્રમાણિકપણે BOD > 100 mg/L → ગંભીર પ્રદૂષણ; વ્યક્તિ દીઠ દૈનિક BOD યોગદાન ≈ 80 g.
  • ઇલેક્ટ્રોસ્ટેટિક પ્રિસિપિટેટર (ESP) ચાર્જed પાર્ટિકલ્સને collect કરે છે — વીજભારિત પ્લેટ્સ પર ધૂળકણો જમા થાય છે.
  • કેટાલીટિક કન્વર્ટર (Catalytic Converter): Pt/Pd/Rh પ્રોત્સાહક તરીકે — CO → CO₂, NOₓ → N₂ + O₂, અઆપેટ હાઇડ્રોકાર્બન → CO₂ + H₂O.
  • સક્રિય કાર્બન (Activated Carbon) એડસોર્પ્શન દ્વારા વાસ અને ઘોળીએલા પ્રદૂષકો દૂર કરે છે.
  • વોકર પ્રક્રિયા (Waller) માં CaO/CaCO₃ નાં સ્ક્રબરથી SO₂ દૂર કરવામાં આવે છે: SO₂ + CaCO₃ → CaSO₃ + CO₂.

🎯 ટ્રિક્સ

BOD નો સીધો સંબંધ પ્રદૂષણનાં સ્તર સાથે છે: BOD ↑ → પ્રદૂષણ ↑; DO ↑ → શુદ્ધ જળ.
'O₃ પરોળો' = 'CFC → Cl· → O₃ વિઘટન'; CFC → CCl₃F/F સૂત્ર યાદ રાખો.
એસિડ વરસાદ = SO₂ + NOₓ + H₂O → H₂SO₄ + HNO₃; બંને એસિડોનું સૂત્ર યાદ: H₂SO₄ (સલ્ફ્યુરિક), HNO₃ (નાઇટ્રિક).
ડ્યુબસન એકમ (DU) = ઓઝોન સ્તરનો માપ; 300 DU = સામાન્ય, < 220 DU = ગંભીર પરોળો.
ઇયુટ્રોફિકેશન = N + P → શૈવાળ વધારો → DO ઘટાડો → BOD વધારો → મચ્છી મૃત્યુ; ક્રમ યાદ રાખો.
કેટાલીટિક કન્વર્ટર સિવાય ઇંજિનમાં: 2CO + 2NO → 2CO₂ + N₂; NOₓ → N₂, CO → CO₂.
ગ્રીનહાઉસ ગેસોનો વૃદ્ધિ ક્રમ (GWP): CH₄ > N₂O > CO₂; પરંતુ CO₂ સૌથી વધુ પ્રમાણમાં ઉત્સર્જિત થાય છે.
ESP નું મૂળભૂત સિદ્ધાંત: વિદ્યુત stathic આકર્ષણ — ચાર્જિત કણ આરોપિત પ્લેટ પર જાય છે.
PAN ફોટોકેમિકલ સ્મોગનું લક્ષણ છે — આંખ અને શ્વાસનળી ઉદ્દીપન કરે છે.

⚠️ ભૂલો

BOD અને COD (Chemical Oxygen Demand) એક જ છે — ખોટું! COD વધુ હોય છે કારણ કે અજૈવિક ઓક્સિડેશન પણ સમાવે છે.
એસિડ વરસાદનો pH 7.0 થી ઓછો હોય — ખોટું! સામાન્ય વરસાદનો pH 5.6 હોય છે; 5.6 થી ઓછો એસિડ વરસાદ છે.
CO₂ એ ગ્રીનહાઉસ ગેસ નથી — ખોટું! CO₂ મુખ્ય ગ્રીનહાઉસ ગેસ છે.
ઓઝોન સ્તર પૃથ્વીની સપાટી પર વધુ હોય છે — ખોટું! ઓઝોન સ્ટ્રેટોસ્ફિયર (15–35 km) માં છે; ટ્રોપોસ્ફિયરમાં ઓઝોન પ્રદૂષક છે.
સ્ક્રાબર CO₂ દૂર કરે છે — ખોટું! સ્ક્રાબર (Scrubber) મુખ્યત્વે SO₂ દૂર કરે છે.
ઇલેક્ટ્રોસ્ટેટિક પ્રિસિપિટેટર ગેસ દૂર કરે છે — ખોટું! તે PARTÍCULATE matter (કણીય પ્રદૂષક) દૂર કરે છે, ગેસ નહીં.
CFCs માત્ર સ્પ્રે_can માં વપરાય છે — ખોટું! CFCs refrigerator, AC, aerosol, foam બધામાં વપરાય છે.
BOD > DO એટલે શુદ્ધ જળ — ખોટું! BOD > DO એટલે DO ખૂટી જાય અને જળ પ્રદૂષિત છે.
કેટાલીટિક કન્વર્ટર SO₂ દૂર કરે છે — ખોટું! તે CO, NOₓ અને unburnt hydrocarbons દૂર કરે છે.
ઇયુટ્રોફિકેશનમાં PO₄³⁻ (ફોસ્ફેટ) ની ભૂમિકા નગણ્ય છે — ખોટું! ફોસ્ફેટ નિષ્ક્રિય સીમિતકર્તા (limiting nutrient) છે.
