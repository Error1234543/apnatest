⚡ સૂત્રો

પ્રાથમિક એમાઇનની બેઝિક પ્રતિભાવ યોગ્યતા (pKb): pKb = -log Kb
Kb એ એમાઇનના જલવિય વિઘટન સ્થિરાંક છે; pKb નીચું હોય તો પ્રબળ બેઝ · SI: પરિમાણહીન · સૌથી સામાન્ય એમાઇન સિદ્ધાંત; 25°C પર
ગરડન-બ્લર્ડ બેઝિકતા અંતરસંબંધ: R-NH2 + H2O ⇌ R-NH3+ + OH-
R એ મેથાઈલ / ઈથાઈલ / એલ્કિલ જૂથ છે; સંતુલન દર્શાવે છે · SI: પરિમાણહીન · એલ્કિલ એમાઇનની જલીય દ્રાવણમાં બેઝિક પ્રકૃતિ સમજવા માટે
એમાઇનની બેઝિકતાનો તુલનાત્મક ક્રમ (એલ્કિલ): C6H5NH2 < C2H5NH2 < (C2H5)2NH
એનીલિન < પ્રાથમિક એલ્કાઈલ એમાઇન < દ્વિતીયક એલ્કાઈલ એમાઇન (બેઝિકતા વધતી જાય) · SI: N/A · જલીય દ્રાવણમાં; -I અસર અને સોલવેશન અસર ઉપરાંત
એલ્કાઈલ એમાઇન બેઝિકતા ક્રમ (પ્રાથમિક, દ્વિતીયક, તૃતીયક): 2° > 1° > 3° (એલ્કિલ જૂથ મેથાઈલ થી મોટું થાય તેમ)
ત્રણેય પ્રકારની એમાઇન બેઝિક શક્તિનું સરખામણી · SI: N/A · પ્રાયોગિક રીતે પ્રાપ્ત થયેલ; સોલવેશન અને +I અસર ઉપરાંત
હાઈપોક્લોરાઈટ સાથે પ્રતિક્રિયા (લાસનનો પુનર્જન્મ પ્રક્રિયા): R-NH2 + NaOCl → R-N=C=O → R-NH2 (CH2OH નિષ્પન્ન)
1° એમાઇન + હાઈપોક્લોરાઈટ → આઈસોસાયનાઈટ → 1° એલકોહોલ + NH3 · SI: N/A · સીમિત પ્રમાણમાં હાઈપોક્લોરાઈટ; 1° એમાઇન માટે લાગુ
એમાઇનથી આલ્ફા-હાલોજન એમાઇન ઉત્પન્ન કરવી (હોફમાન બ્રોમિડ વિઘટન): R-NH-CO-R' + Br2 + 4NaOH → R-NH2 + Na2CO3 + 2NaBr + 2H2O
એમાઇડને બ્રોમિન/NaOH સાથે ગરમ કરવાથી 1° એમાઇન મળે છે; C નો સંખ્યા 1 ઓછો · SI: N/A · 1° એમાઇનની તૈયારી; હોફમાન બ્રોમિડ અવચય
નાઇટ્રાઈટથી એલ્કાઈલ નાઈટ્રોસો એમાઇન (2° એમાઇન): R2NH + HNO2 → R2N-N=O + H2O
2° એમાઇન + NaNO2/HCl (0-5°C) → નાઈટ્રોસો એમાઇન (પીળો તৈલ જેવો દ્રવ્ય) · SI: N/A · 2° એમાઇન પરીક્ષણ (લીટરન ટેસ્ટ)
ઝેડમેન પ્રતિક્રિયા (અપૂર્ણ એનાલાઈઝ): R-N(CH3)2 + CHCl3 + 3KOH(alc) → R-N≡C (આઈસોસાયનાઈડ) + 3KCl + 3H2O
તૃતીયક એમાઇન + ક્લોરોફોર્મ + પ્રવાહી KOH → આઈસોસાયનાઈડ (ખરાબ ગંધ) · SI: N/A · 3° એમાઇન પરીક્ષણ; ઝેડમેન વિભાજન
અજ્ઞાત એમાઇન વજન પ્રણાલી (મોલર દળ ગણતરી): M = (w × 30)/Δn જ્યાં Δn એ NH3 ના મોલ છે
w એ એમાઇનનું વજન, 30 એ NH3 નું મોલર દળ, Δn એ મુક્ત NH3 ના મોલ · SI: g mol⁻¹ · એમાઇન પ્રમાણ માપનમાં; ફ્રાન્ક્લેન્ડ પદ્ધતિ
ડાયઝોટિયમ લવણ રચના (એરોમેટિક 1° એમાઇન): ArNH2 + NaNO2 + 2HCl → ArN2+Cl− + NaCl + 2H2O
એનીલિન + સાયનિટ + HCl (0-5°C) → બેઝિયાનિયમ ક્લોરાઈડ (ડાયઝોટિયમ લવણ) · SI: N/A · 0-5°C પર; થર્મલી અસ્થિર

🔗 સંબંધો

  • એલ્કિલ એમાઇનની બેઝિકતામાં +I અસર વધારે છે; એરોમેટિક એમાઇનમાં રેઝોનન્સથી બેઝિકતા ઘટે છે.
  • ડાયઝોટિયમ લવણ 0-5°C પર સ્થિર; વધુ તાપમાને N2 મુક્ત થાય.
  • પ્રાથમિક એમાઇન સાથે નાઈટ્રાઈટ પ્રતિક્રિયાથી એલ્કાઈલ નાઈટ્રોસો એમાઇન મળે; સીધું પરિક્ષણ.
  • હેપ્ટેન અને એમાઇનની વચ્ચે હાઈડ્રોજન બંધન તફાવત: 1° અને 2° એમાઇન ઉત્તળ હોય છે.

🎯 ટ્રિક્સ

એમાઇન બેઝિકતા ક્રમ યાદ રાખવા: '2-1-3' — 2° એલ્કાઈલ > 1° > 3° (જલીય).
ડાયઝોટિયમ લવણ: 'એનીલિન + સાયનિટ + ઠંડક = સ્થિરતા'.

⚠️ ભૂલો

એરોમેટિક એમાઇનની બેઝિકતા એલ્કાઈલ એમાઇન કરતાં ઓછી હોય છે; વિપરીત લખવું નહીં.
હેપ્ટેનનું બોઇલિંગ પોઈન્ટ એમાઇન કરતાં વધારે હોય છે, તે યાદ રાખવું.
ડાયઝોટિયમ લવણનું તાપમાન 5°C કરતાં વધારે ન કરવું.
