ઉપરિષ્ઠ રસાયનશાસ્ત્ર — સૂત્ર શીટ

🩺 NEET UG — Gujarati • Chemistry • Surface Chemistry

⚡ સૂત્રો

ફ્રેન્ડલિચ અધિશોષણ આયસોથર્મ: x/m = k · P^(1/n)
x = અધિશોષિત વાયુનું દળ, m = અધિશોષકનું દળ, P = દબાણ, k અને n = અનુભવસિદ્ધ અચળાંકો (n > 1) · SI: k નું એકમ પદાર્થ-આધારિત; P એટમ દબાણ (atm); x/m એકમહીન · મધ્યમ દબાણ અને મધ્યમ તાપમાને, ભૌતિક અધિશોષણ માટે
ફ્રેન્ડલિચ સમીકરણનું લઘુગણક રૂપ (રેખીય): log(x/m) = log k + (1/n) · log P
log(x/m) = y-અક્ષ પર, log P = x-અક્ષ પર, ઢાળ = 1/n, છેદાંક = log k · SI: લઘુગણક અપરાધી હોવાથી એકમરહિત · ફ્રેન્ડલિચ આયસોથર્મની પ્રયોગિક ચકાસણી અને k, n શોધવા માટે
ફ્રેન્ડલિચ — નીચા દબાણ પર સરળ રૂપ: x/m = k · P
x, m, P = ઉપર મુજબ; આ કિસ્સામાં 1/n ≈ 1 · SI: x/m એકમહીન, P atm માં · જ્યારે દબાણ ખૂબ ઓછું હોય (P → 0)
ફ્રેન્ડલિચ — ਉચ્ચ દબાણ પર સરળ રૂપ: x/m = k
k = અચળાંક; આ કિસ્સામાં 1/n ≈ 0 · SI: એકમરહિત · જ્યારે દબાણ ખૂબ વધારે હોય (P → ઉચ્ચ, સંતૃપ્તિ તરફ)
લેંગમુઅર અધિશોષણ આયસોથર્મ: x/m = (a · P) / (1 + b · P)
a = લેંગમુઅર અચળાંક (સંબંધિત), b = અન્ય અચળાંક; બંને પદાર્થ-તથા-તાપમાન-આધારિત · SI: x/m એકમહીન, P atm માં · એક સ્તરીય (મોનોલેયર) અધિશોષણ; નીચા-મધ્યમ દબાણે સારો સંવાદ
લેંગમુઅર — નીચા દબાણ પર (bP << 1): x/m ≈ a · P
a = અચળાંક; આ રૂપ રેખીય સંબંધ આપે છે · SI: x/m એકમહીન, P atm માં · નીચા દબાણે, જ્યાં 1 + bP ≈ 1
લેંગમુઅર — ઉચ્ચ દબાણ પર (bP >> 1): x/m ≈ a/b = સ્થिरાંક
a/b = અચળ; સંતૃપ્તિ અધિશોષણ દર્શાવે છે · SI: એકમરહિત · ઉચ્ચ દબાણે, જ્યાં 1 + bP ≈ bP
લેંગમુઅર — વિકલ્પ રેખીય રૂપ: P/(x/m) = (1/a) + (b/a) · P
P/(x/m) vs P આલેખ રેખીય; ઢાળ = b/a, છેદાંક = 1/a · SI: બંને અક્ષો પર પદાર્થ-આધારિત એકમો · a અને b ના મૂલ્ય પ્રયોગથી શોધવા માટે
ઊર્જાવર્ધન (એન્થેલ્પી) માટે ફ્રેન્ડલિચ: x/m = k · P^(1/n) ; n > 1 હંમેશા
n હંમેશા 1 થી મોટું હોય છે, તેથી 1/n < 1 · SI: એકમરહિત અપરાધી · ભૌતિક અધિશોષણ હંમેશા ઉષ્માક્ષેપક (એક્ઝોથર્મિક) હોવાથી
અધિશોષણનું ગિબ્સ મુક્ત ઊર્જા બદલાવ: ΔG = ΔH - T·ΔS ; અધિશોષણ સ્વયંસ્ફુરિત, તેથી ΔG < 0
ΔH < 0 (ઉષ્માક્ષેપક), ΔS < 0 (વ્યવસ્થા ઘટે છે); T = તાપમાન (K) · SI: ΔG, ΔH : J/mol; T : K · સ્વયંસ્ફુરિત અધિશોષણ માટે
પૃષ્ઠતણ (સર્ફેસ ટેન્શન) — કેપિલરી ઉઠાણ: h = (2T·cosθ) / (r·ρ·g)
h = કેપિલરી ઉઠાણ ઊંચાઈ, T = પૃષ્ઠતણ, θ = સંપર્કકોણ, r = કેપિલરી ત્રિજ્યા, ρ = પ્રવાહી ઘનતા, g = ગુરુત્વપ્રવેગ · SI: T : N/m; h, r : m; ρ : kg/m³; g : m/s² · જ્યારે સંપર્કકોણ θ = 0 (પૂરું ભેગું થાય, cosθ = 1): h = 2T/(r·ρ·g)
પૃષ્ઠતણની ગાણિતિક વ્યાખ્યા: T = F / l
F = પૃષ્ઠ પર લાગતું બળ, l = બળ લાગતી રેખાની લંબાઈ · SI: T : N/m; F : N; l : m · સામાન્ય રચના
પૃષ્ઠતણ — બોબલ-પ્રેશર પદ્ધતિ: T = (r·ΔP) / 2
r = બોબલની ત્રિજ્યા, ΔP = અધિક ચાપ (બાહ્ય અને અંદરુનું દબાણ વચ્ચેનો તફાવત) · SI: T : N/m; r : m; ΔP : Pa · વાયુ બોબલ પ્રવાહીમાં
છોટા બોપડાનું અંદરુનું દબાણ (Young-Laplace, ગોળાકાર): P_in = P_out + (2T / r)
P_in = બોપડા અંદરુનું દબાણ, P_out = બાહ્ય દબાણ, r = બોપડાની ત્રિજ્યા, T = પૃષ્ઠતણ · SI: P : Pa; T : N/m; r : m · દ્રવ બોપડું (ગોળાકાર)
વાયુ બોપડાનું અંદરુનું દબાણ (જાડાઈ ધરાવતું): P_in = P_out + (4T / r)
4T/r — બે પૃષ્ઠ (અંદરનું અને બહારનું) હોવાથી · SI: P : Pa; T : N/m; r : m · સાબુનું બોપડું (વાયુ-પ્રવાહી-વાયુ, બે પૃષ્ઠ)
પૃષ્ઠ વિસ્તરણ પર કરવામાં આવતું કાર્ય: W = T · ΔA
W = કરવામાં આવતું કાર્ય, T = પૃષ્ઠતણ, ΔA = પૃષ્ઠફળમાં વધારો · SI: W : J; T : N/m; ΔA : m² · સમાનતા તાપમાને
પૃષ્ઠ ઊર્જા (Surface Energy): E = T · A
E = પૃષ્ઠ ઊર્જા, T = પૃષ્ઠતણ, A = પૃષ્ઠફળ · SI: E : J; T : N/m; A : m² · કુલ પૃષ્ઠ ફળ A હોય ત્યારે
ઔષધીય કોષ્ટક (Cottrell) — વિદ્યુતઅવક્ષેપન: વિદ્યુતચુંબકીય કણો ધરાવતા ધૂળ/ધુમાડાનું અવક્ષેપન
Cottrell precipitator : વિરોધી ધ્રુવવાળા પ્લેટો પર કણો આકર્ષાય અને અવક્ષેપિત થાય · SI: N/A · ઔદ્યોગિક ધૂળ સાફ કરવા (electrostatic precipitator)
હાર્ડી-શુલ્ઝે નિયમ (Hardy-Schulze Rule): Coagulation_power ∝ (valency of coagulating ion)^6
Coagulating ion નો વિદ્યુતભાર જેટલો વધારે, તેટલી જ વેગળી કરવાની શક્તિ વધારે · SI: N/A · કોલોઇડલ દ્રાવણનું સંઘનન (coagulation) કરતા આયનની શક્તિ માટે
ક્રિટિકલ કોએગ્યુલેશન કોન્સન્ટ્રેશન (CCC): CCC = ડ઼વોતક આયનનો એવી સાંદ્રતા, જે દ્રાવણના 1 ليٹر માટે જરૂરી હોય
CCC એકમ : mol/L (અથવા mM) · SI: mol/L · કોલોઇડનું સંઘનન શરૂ થાય તેની ન્યૂનતમ સાંદ્રતા
ટિન્ડલ પ્રભાવ — પ્રકાશ પ્રકીર્ણન: I ∝ N·d⁶ / λ⁴
I = પ્રકીર્ણિત પ્રકાશની તીવ્રતા, N = કણ સંખ્યા, d = કણ વ્યાસ, λ = પ્રકાશની તરંગલંબાઈ · SI: N/A · કોલોઇડલ દ્રાવણમાં ટિન્ડલ પ્રભાવ
બ્રાઉનિયન ગતિ — સરેરાશ વિસ્થાપન (Smoluchowski): <x²> = (k_B · T · t) / (3·π·η·r)
k_B = બોલ્ટઝમેન અચળાંક, T = તાપમાન (K), t = સમય, η = માધ્યમનું સંસ્રાવકતા, r = કણની ત્રિજ્યા · SI: <x²> : m²; k_B : J/K; T : K; t : s; η : Pa·s; r : m · કોલોઇડલ કણોનું બ્રાઉનિયન ગતિવિज्ञान
એમલ્સનનું સૂત્ર (Emulsion): તೈલ-દ્રવ (O/W) અથવા દ્રવ-તૈલ (W/O) પ્રકારનું મિશ્રણ
O/W = Oil in Water; W/O = Water in Oil; Emulsifying agent = સ્થિરતા આપનાર પદાર્થ · SI: N/A · બે અ મિશ્રણીય દ્રવોના વિભાજિત દ્રાવણ માટે
ઉત્પ્રેરકતા — વેગ અચળાંક અને એક્ટિવેશન ઊર્જા: k = A · e^(-Ea / (R·T))
k = વેગ અચળાંક, A = પ્રી-એક્સપોનેન્શિયલ ફેક્ટર, Ea = સક્રિયકરણ ઊર્જા, R = વાયુ અચળાંક, T = તાપમાન (K) · SI: k : mol·L⁻¹·s⁻¹ (અથવા પ્રક્રિયા-ક્રમ પર આધારિત); Ea : J/mol; R : 8.314 J·mol⁻¹·K⁻¹ · ઉત્પ્રેરક Ea ઘટાડે છે, તેથી k વધે છે
ઉત્પ્રેરકની હાર ( Catalytic Activity) સાપેક્ષ: વેગવર્ધન = k_catalyzed / k_uncatalyzed = e^[(Ea(uncat) - Ea(cat)) / (R·T)]
Ea(uncat) = બિનઉત્પ્રેરિત પ્રક્રિયાની સક્રિયકરણ ઊર્જા; Ea(cat) = ઉત્પ્રેરિત પ્રક્રિયાની · SI: અનુપાત એકમરહિત · ઉત્પ્રેરકની અસરનું માત્રાત્મક મૂલ્યાંકન

🔗 સંબંધો

  • ફ્રેન્ડલિચ આયસોથર્મમાં 1/n હંમેશા 0 અને 1 ની વચ્ચે હોય છે; જો 1/n = 1 હોય તો x/m ∝ P (રેખીય), જો 1/n = 0 હોય તો x/m = અચળ (સંતૃપ્ત)
  • લેંગમુઅર આયસોથર્મ નીચા દબાણે રેખીય (x/m ∝ P) અને ઉચ્ચ દબાણે સંતૃપ્ત (x/m = અચળ) બને છે; ફ્રેન્ડલિચ આ બંને સરહદ કિસ્સાઓ આપમેળે સમાવી લે છે
  • અધિશોષણ હંમેશા ઉષ્માક્ષેપક (exothermic) હોય છે, તેથી ΔH < 0; ΔS પણ ઋણ છે (અવ્યવસ્થા ઘટે છે), પરંતુ ઉચ્ચ તાપમાને –TΔS ધન થઈ ΔG ધન બની શકે છે, તેથી ઉષ્મા વધારવાથી અધિશોષણ ઘટે છે
  • પૃષ્ઠતણ T વધારે તો કેપિલરી ઉઠાણ h વધે; T ઘટે તો h ઘટે (તાપમાન વધારવાથી પૃષ્ઠતણ ઘટે છે)
  • સાબુનું બોપડું બે પૃષ્ઠ ધરાવે છે, તેથી અંદરુનું દબાણ P_out + 4T/r હોય છે, જ્યારે દ્રવ બોપડા માત્ર એક પૃષ્ઠ ધરાવે છે, તેથી P_out + 2T/r
  • ટિન્ડલ પ્રભાવની તીવ્રતા λ⁴ ના વ્યસ્તપ્રમાણમાં — જૂદો (નાનો) તરંગલંબાઈ વધુ પ્રકીર્ણન આપે, તેથી neelo પ્રકાશ વધુ દેખાય
  • હાર્ડી-શુલ્ઝે નિયમ મુજબ વિપરીત વિદ્યુતભાર ધરાવતા આયનનો વિદ્યુતભાર જેટલો વધારે, તેટલી coagulation power વધારે (ઉદા. Al³⁺ > Ba²⁺ > Na⁺ for negative sol)
  • કોલોઇડલ કણોનું બ્રાઉનિયન ગતિ પ્રમાણ k_BT/(3πηr) તરીકે, એટલે નાના કણો વધુ ગતિશીલ, ઊંચું તાપમાન વધુ ગતિ, ઊંચું સંસ્રાવકતા ઓછી ગતિ આપે
  • એમલ્સન માટે emulsifying agent જરૂરી — O/W માટે પ્રવાહી-પ્રિય (hydrophilic,如皂), W/O માટે તૈલ-પ્રિય (hydrophobic,如 metal soaps of divalent cations)
  • ઉત્પ્રેરક પ્રક્રિયાના વેગમાં વધારો કરે છે કારણ કે તે એક નવો માર્ગ (pathway) આપે છે જેની Ea ઓછી હોય છે, પણ ΔH અને સંતુલન અચળાંક (K_eq) બદલાતા નથી

ફ્રેન્ડલિચ log(x/m) vs log P આલેખનો ઢાળ = 1/n ; ઢાળ 0 ની નજીક → ઉચ્ચ દબાણ સંતૃપ્તિ; ઢાળ 1 ની નજીક → નીચું દબાણ રેખીય ક્ષેત્ર

સાબુનું બોપડું = 4T/r, દ્રવ બોપડું = 2T/r — યાદ રાખવા easy: ' Soap bubble has two surfaces, so double the pressure'
