⭐ મહત્વના મુદ્દા

ઇલેક્ટ્રોનની શોધ જે.જે. થોમસને કરી હતી; તેમણે કેથોડ કિરણોના દળ/આભાર અનુપાત (e/m) નો નિર્धारણ કર્યો. (Specific charge of electron)
NEET માં e/m ની કિંમત અને થોમસન મોડલ વિશે સીધા પ્રશ્નો આવે છે.
પ્રોટોનની શોધ ગોલ્ડસ્ટાઇને કરી (canal rays); ન્યૂટ્રોનની શોધ ચેડવિકે (1932) કરી.
કણોની શોધ કરનારા વૈજ્ઞાનિકો —年年 NEET માં ભૂતવર્ષિક પ્રશ્ન આવે છે.
રૂધરફોર્ડના alpha-કણ વિખેરવાના પ્રયોગમાં:绝大多数 કણો સીધા પસાર થયા → પરમાણુનો મોટાભાગનો ભાગ ખાલી છે; થોડાક વિચલિત થયા → ધન વીજભાર કેન્દ્રમાં સાંદ્રિત છે. લગભગ 1 કણ/8000 અઠવાયું.
રૂધરફોર્ડ મોડલ અને તેની નિષ્ફળતાઓ NEET નો સૌથી ગંભીર વિષય છે.
ક્લાસિકલ વિદ્યુતચુંબકીય સિદ્ધાંત મુજબ ગતિશીલ ઇલેક્ટ્રોન શક્તિ ઉત્સર્જિત કરે છે → ઊર્જા ગુમાવી કેન્દ્રમાં પડી જાય; પરંતુ પરમાણુ સ્થિર છે → રૂધરફોર્ડ મોડલ અસ્થિર છે.
રૂધરફોર્ડ મોડલની મર્યાદાઓ NEET માં年年 પ્રશ્ન આવે છે.
પ્લાંકનું ક્વોન્ટમ સિદ્ધાંત: E = hν = hc/λ; h = 6.626 × 10⁻³⁴ J·s (પ્લાંક અચળાંક).
E = hν સૂત્ર બેક-ટૂ-બેઝિક — NEET માં સંખ્યાત્મક પ્રશ્નો સીધા આવે છે.
ચુંબકીય પ્રભાવ પ્રભાવ (Photoelectric effect): ધાતુની સપાટી પરથી ઇલેક્ટ્રોનનું ઉત્સર્જન; K.E._max = hν − φ (φ = બંધન ઊર્જા); આ પ્રભાવનો તરંગ સિદ્ધાંત વડે સમજાવો શક્ય નથી.
આ પ્રશ્ન પ્રકાશ-વિદ્યુત પ્રભાવ ક્વોન્ટમ સ્વરૂપ સાબિત કરે છે — NEET માં年年 આવે છે.
ડી-બ્રોગલીના સમીકરણ મુજબ દરેક ગતિમાન કણની તરંગ લંબાઇ λ = h/(mv) = h/p. ઇલેક્ટ્રોન માટે λ = h/√(2mE).
matter wave — NEET માં numerical અને conceptual બંને પ્રકારે પ્રશ્નો આવે છે.
બોહર મોડલના પોસ્ટ્યુલેટ: (1) ઇલેક્ટ્રોન નિશ્ચિત કક્ષામાં ફરે છે (સ્થિર અવસ્થા), (2) કક્ષામાં કોણીય સંવેગ quantised: mvr = nh/2π, (3) ઉર્જા અવશોષણ/ઉત્સર્જન કક્ષા ફેરફાર દરમિયાન થાય: ΔE = hν.
બોહર મોડલ NEET નો સૌથી વધુ महत्त्वाचा વિષય; कक्षा त्रिज्या, ઉર્જા, વેગ — બધા farmaula年年 આવે છે.
બોહર મોડલ મુજબ n-મી કક્ષાની ત્રિજ્યા r_n = n²a₀/Z (a₀ = 0.529 Å, બોહર ત્રિજ્યા). ઊર્જા E_n = −13.6 Z²/n² eV.
r_n અને E_n ના farmaula NEET માં年年 numerical પ્રશ્નનો સ्रोત છે.
બોહર મોડલની મર્યાદા: એક-ઇલેક્ટ્રોન સિસ્ટમ (H, He⁺, Li²⁺) સિવાયનાં પરમાણુ/અણુ સમજાવતું નથી; fine structure સમજાવતું નથી; Heisenberg ના સિદ્ધાંત સાથે સુસંગત નથી.
બોહર મોડલની મર્યાદાઓ NEET માં年年 conceptual પ્રશ્ન આવે છે.
હાઈઝનબર્ગનો અનિશ્ચિતતા સિદ્ધાંત: Δx · Δp ≥ h/4π (અથવા Δx · Δv ≥ h/4πm). ઇલેક્ટ્રોનની સ્થિતિ અને વેગ એકસાથે ચોકસાઈથી માપી શકાતા નથી.
અનિશ્ચિતતા સિદ્ધાંત → બોહર મોડલ ખોટું: NEET માં年年 આવે છે.
ક્વોન્ટમ અંક: (1) મુખ્ય (n) → કક્ષા/ઊર્જા સ્તર, (2) બૉન્ડ (l) → ઉપકક્ષા (s,p,d,f), (3) ચુંબકીય (m_l) → કક્ષકનો અવકાશી દિશા, (4) સ્પિન (m_s) → ±½.
ચારેય ક્વોન્ટમ અંક NEET નો core વિષય; l = 0−(n−1), m_l = −l…+l —年年 આવે છે.
કક્ષક (orbital) નું આકાર: s → ગોળાકાર (1), p → dumbbell (3: p_x, p_y, p_z), d → cloverleaf (5), f → જટિલ (7). n-મી કક્ષામાં કુલ કક્ષકો = n².
કક્ષક આકાર અને સંખ્યા NEET માં年年 visual + numerical પ્રશ્ન આવે છે.
ઓફબાઉ (Aufbau) નિયમ: ઊર્જા વધતા ક્રમે કક્ષક ભરે: 1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p < 7s < 5f < 6d... Madelung (n+l) નિયમ.
电子配置 NEET માં年年 direct પ્રશ્ન — Aufbau + n+l કાયમ ચાલે છે.
પાઉલીનો અપવર્જન સિદ્ધાંત: એક કક્ષકમાં બે કરતાં વધુ ઇલેક્ટ્રોન હોઈ શકે નહીં અને ચારેય ક્વોન્ટમ અંક સમાન હોઈ શકે નહીં. એક કક્ષકમાં મહત્તમ 2 ઇલેક્ટ્રોન.
Pauli exclusion —年年 NEET માં electronic configuration પ્રશ્નોની પાછળનો સિદ્ધાંત.
હન્ડનો નિયમ: સમાન ઊર્જાની કક્ષકો (degenerate orbitals) માં ઇલેક્ટ્રોન પ્રથમ એક-એક કરીને અને સમાન સ્પિનથી ભરાય.
Hund's rule → paramagnetic/diamagnetic性质 નક્કી કરવા NEET માં年年 આવે છે.
આઇસોટોપ: સમાન Z, અલગ A (ઉદા. ¹H, ²H, ³H). આઇસોબાર: સમાન A, અલગ Z (ઉદા. ⁴⁰Ar, ⁴⁰Ca). આઇસોટોન: સમાન N, અલગ Z.
સંકલન શબ્દોની વ્યાખ્યા NEET માં年年 direct MCQ આવે છે.
H-પરમાણુ વર્ણપટ: Rydberg farmaula 1/λ = R_H [1/n₁² − 1/n₂²]; શ્રેણીઓ — Lyman (n₁=1, UV), Balmer (n₁=2, દૃશ્યમાન), Paschen (n₁=3, IR), Brackett (n₁=4), Pfund (n₁=5).
Rydberg શ્રેણીઓ અને n₁/n₂ ની કિંમતો NEET માં年年 આવે છે.
કક્ષકમાં નોડ (node):径向 નોડ = n − l − 1, સમતલીય (angular) નોડ = l, કુલ નોડ = n − 1. उદा. 3d માં径向=1, સમતલીય=2, કુલ=3.
નોડ સંખ્યા NEET માં年年 numerical પ્રશ્ન આવે છે.
d-orbital માત્ર n ≥ 3 માં exists; f-orbital માત્ર n ≥ 4 માં exists. 4f કક્ષક 7 ઇલેક્ટ્રોન ધારણ કરી શકે (14 e⁻ કુલ).
subshell capacity અને n,l સંબંધ NEET માં年年 આવે છે.
H-પરમાણુની n-મી કક્ષામાં ઇલેક્ટ્રોનની ઊર્જા E_n = −13.6/n² eV; ionization energy (n=1→∞) = 13.6 eV. He⁺ માટે E_n = −13.6×Z²/n² eV = −54.4/n² eV.
ionization energy અને Z² dependency NEET માં年年 numerical પ્રશ્ન.
ઈલેક્ટ્રોનિક વિન્યાસના अपवाद: Cr (Z=24) → [Ar] 4s¹ 3d⁵, Cu (Z=29) → [Ar] 4s¹ 3d¹⁰. આ半пол्यु满是稳定性ને કારણે.
Cr અને Cu નો अपवाद NEET માં年年 direct પ્રશ્ન આવે છે.
ઇલેક્ટ્રોનની ચુંબકીય ક્ષણ μ = √[n(n+2)] BM (n = અયુગ્મિત ઇલેક્ટ્રોન). paramagnetic = ઓછામાં ઓછું એક અયુગ્મિત e⁻; diamagnetic = તમામ યુગ્મિત.
magnetic moment formula અને spin-only 계산 NEET માં年年 આવે છે.
de Broglie ની તરંગલંબાઇ અને accelerating potential V વચ્ચેનો સંબંધ: λ = h/√(2meV) ⇒ λ ≈ 12.27/√V Å (ઇલેક્ટ્રોન માટે).
λ vs V સૂત્ર NEET માં numerical પ્રશ્નોનું frequent topic છે.
