પોલિમર (Polymers)

🩺 NEET UG — Gujarati • Chemistry • Polymers

પોલિમરની પરિભાષા અને મૂળભૂત ખ્યાલ
મોટા આણ્વીય ભાર ધરાવતા અણુઓને પોલિમર કહીએ છીએ. આ મોલેક્યુલ્સ સરળ રચના ધરાવતા એકમોના સંયોજનથી બનેલા હોય છે.
પોલિમર નામની વ્યુત્પત્તિ ગ્રીક શબ્દો 'poly' (એકાધિક) અને 'meros' (ભાગ) માંથી થઈ છે.
પુનરાવર્તિત એકમોને મોનોમર કહેવામાં આવે છે. ઉદા. એથિલીન (C₂H₄) પોલિથીનનું મોનોમર છે.
📝 પોલિમરનું સામાન્ય સૂત્ર : —(અંતઃ બંધિત એકમ)—_n_ , જ્યાં n એ બહુલગાટીની ડિગ્રી છે.
પોલિમરનું વર્ગીકરણ
પ્રાકૃતિક પોલિમરકૃત્રિમ (સંશ્લેષિત) પોલિમર
પ્રાકૃતિક પોલિમર : સ્ટાર્ચ, સેલ્યુલોઝ, પ્રોટીન, નેચરલ રબર (cis-polyisoprene), ન્યુક્લિક એસિડ.
સંશ્લેષિત પોલિમર : પોલિથીન, પોલિવિનાઇલ ક્લોરાઇડ (PVC), નાયલોન, બેકલાઇટ.
પોલિમરના ત્રણ મુખ્ય વર્ગો : સંશ્લેષિત પોલિમર, પ્રકૃતિમાં મળતા પોલિમર, અને પોલિમરની રચના પર આધારિત વર્ગીકરણ.
સંશ્લેષિત પોલિમરના ઉદાહરણો : પોલિથીન, P.T.F.E., નાયલોન-6,6, બેકલાઇટ, બ્યુના-S.
📝 ટેરેલેનોલ પોલિએસ્ટરનું મહત્વનું સંશ્લેષિત પોલિમર છે.
પોલિમરાઇઝેશનની પ્રક્રિયાઓ
મોનોમરના જથ્થાબંધ સંયોજન દ્વારા પોલિમર બનવાની પ્રક્રિયાને પોલિમરાઇઝેશન કહે છે.
એડિશન પોલિમરાઇઝેશનકન્ડેન્સેશન પોલિમરાઇઝેશન
એડિશન પોલિમરાઇઝેશન : અસંતૃપ્ત મોનોમરમાં યોગ કરીને પોલિમર બને છે. ઉદા. એથિલીનનું પોલિથીનમાં રૂપાંતર.
n CH₂=CH₂ → —(CH₂—CH₂)—_n_ (પરમાંગણીય ઇન્સેટિટિયરની હાજરીમાં)
કન્ડેન્સેશન પોલિમરાઇઝેશન : બે મોનોમર એકમો જોડાતાં નાની અણુઓ (જલ, એમોનિયા વગેરે) ની ઓછી માત્રા બહાર આવી જાય છે.
એક વધારાના સમૂહ ધરાવતા મોનોમરમાંથી સંયોજન દ્વારા પોલિમર બને છે. ઉદા. નાયલોન, ટેરેલેનોલ.
📝 બેકાઇલાઇટ એક વિભારીય રેઝિન છે જે ફોર્મેલ્ડિહાઇડ અને ફિનોલમાંથી બને છે.
કૌંસર (કેટાઇન) પોલિમરાઇઝેશન
કેટાઇન (કન્ડેન્સેશન) પોલિમરાઇઝેશનમાં મોનોમર એકમો પર બે સક્રિય યોગ્ય સમૂહો હોય છે.
HOOC-(CH₂)₄-COOH + H₂N-(CH₂)₆-NH₂ → પુનરાવર્તિત એકમ —OC-(CH₂)₄-CO-NH-(CH₂)₆-NH- + H₂O
આ પ્રક્રિયામાં પાણી, મધ્યવર્તી અણુઓ વगैरે નીપજ તરીકે મળે છે.
નાયલોન-6,6 બેકેલોક્ટિક એસિડ અને હેક્સામેથિલિન ડાયામીનમાંથી બને છે.
📝 નાયલોન-6 એ કેપ્રોલેક્ટમના એકમ રચના પરથી બને છે.
પોલિમરના ધર્મો પર પ્રભાવ
પોલિમરના ભૌતિક ગુણધર્મો તેમના મોલેક્યુલર ભાર, રેખીયતા અને શૃંખલા બંધારણ પર આધારિત છે.
ઉચ્ચ મોલેક્યુલર ભાર ધરાવતા પોલિમર વધુ મજબૂત, વધુ સ્થિર અને ઊંચા ક્ષયબિંદુ ધરાવે છે.
રેખીય પોલિમર વધુ સઘન અને શક્તિશાળી હોય છે; આડી શૃંખલા ધરાવતા પોલિમર વધુ લવચીક અને નરમ હોય છે.
પોલિમરનું આણ્વીય ભાર = n × (મોનોમરનું આણ્વીય ભાર).
📝 સિથેટિક રબર અને નેચરલ રબર વચ્ચેનો તફાવત સમજો.
પોલિમરનાં મહત્વનાં ઉદાહરણો
પોલિથીન : C₂H₄ માંથી બને છે. ઉચ્ચ પીવાયેડ પોલિથીન (HDPE) અને ઓછું પીવાયેડ પોલિથીન (LDPE).
ટેફલોન (પોલિટેટ્રાફ્લોરોઇથીલિન) : CF₂=CF₂ નું પોલિમર. ઉચ્ચ તાપમાન અને રાસાયણિક પ્રતિરોધક.
PVC (પોલિવિનાઇલ ક્લોરાઇડ) : CH₂=CHCl માંથી બને છે. પાઇપો, રબરના આઘાતોમાં વપરાય છે.
બ્યુના-S : Buta-1,3-diene અને Styreneનું સંયુક્ત પોલિમર. કાર્ટાયરમાં ઉપયોગ.
📝 પોલિમરનાં નામોમાંથી જ મોનોમર ઓળખી શકાય છે.
નાયલોન અને તેના પ્રકારો
નાયલોન-6,6 : એડિપિક એસિડ અને હેક્સામેથિલિન ડાયામીનમાંથી બને છે.
HOOC-(CH₂)₄-COOH + H₂N-(CH₂)₆-NH₂ → નાયલોન-6,6 + 2H₂O
નાયલોન-6 : કૅપ્રોલેક્ટમનું પોલિમરણથી બને છે.
નાયલોન-6,6 અને નાયલોન-6 વચ્ચેનો તફાવત ધ્યાનથી સમજો.
📝 નાયલોનનું વપરાયું સરખેરિંગ દસ્તાવેજોમાં અને વસ્ત્રોમાં.
ટેરેલેનોલ (બેકલાઇટ) – પોલિએસ્ટર
ટેરેલેનોલ : terephthalic acid અને ethylene glycol માંથી બને છે.
HOOC-C₆H₄-COOH + HO-CH₂-CH₂-OH → —OC-C₆H₄-CO-O-CH₂-CH₂-O— + 2H₂O
ટેરેલેનોલ પોલિએસ્ટર છે અને તેનું ઉપયોગ પર્દા, ચોપડા, વગેરેમાં થાય છે.
બેકલાઇટ ઉચ્ચ તાપમાન અને વિદ્યુત અવાહક ગુણધર્મ ધરાવે છે.
📝 પોલિએસ્ટર અને નાયલોન વચ્ચેનો તફાવત અવશ્ય જાણો.
સંયોજન પોલિમરો – બેકાઇલ (Bakelite)
બેકાઇલ : ફોર્મેલ્ડિહાઇડ અને phenol (ફિનોલ) માંથી બનતું ઉષ્મા સ્થિર પ્લાસ્ટિક.
આ પ્લાસ્ટિક ટેમ્પરેચર પર કઠણ અને રાસાયણિક પ્રતિરોધક હોય છે.
બેકાઇલનો ઉપયોગ ઇલેક્ટ્રિકલ સાધનો, બટનો, ફોન વગેરેમાં થાય છે.
phenol + HCHO → બેકાઇલ + H₂O (ઉષ્મા અને દબાણની હાજરીમાં)
📝 બેકાઇલ એક નોન-મુક્ત રેઝિન છે જે વારંવાર ગરમ કરી શકાતી નથી.
રબરના પ્રકારો અને વલિ કેનાઇઝેશન
નેચરલ રબર : cis-polyisoprene. તે લવચીક અને ઇલાસ્ટિક હોય છે.
સિથેટિક રબર : બ્યુના-S (SBR), બ્યુના-N (NBR), વગેરે.
વલિ કેનાઇઝેશન : સલ્ફર સાથે ગરમ કરવાથી રબરના શૃંખલા વચ્ચે S–S બંધ બને છે અને તે કઠણ બને છે.
R—S—S—R (રબર શૃંખલામાં સલ્ફર વલિ બંધ દ્વારા)
📝 વલિ કેનાઇઝેશનના કારણે રબરની ઘર્ષણ પ્રતિરોધકતા વધે છે.
પોલિમરના ઉપયોગો
પોલિથીન : પ્લાસ્ટિકના થેલા, પાણીની પાઇપો, કોટિંગ.
PVC : પાઇપો, આઉટલેટ, ફર્નિચર કવર.
ટેફલોન : નોન-સ્ટિક કોટિંગ, કૂકિંગ યુટિલિટી, ઇલેક્ટ્રિકલ આઇન્સ્યુલેશન.
નાયલોન : પહીલાં, રેપીડ, ચાદર, રોપ.
📝 પોલિમરના ઉપયોગો વ્યાપક છે અને રોજિંદા જીવનમાં તેમનું મહત્વ.
પ્રશ્નો અને મહત્વનાં પ્રશ્નો
પોલિમરના અભ્યાસ દરમિયાન નીચેના મુદ્દાઓ સ્પષ્ટ કરવા જોઈએ: મોનોમરનું નામ, પોલિમરનું સૂત્ર, તેના ઉપયોગો.
પોલિમરાઇઝેશન પ્રક્રિયાઓમાં વ્યતિરેકી અને ઉત્પ્રેરકની ભૂમિકા સમજવી જરૂરી છે.
અભ્યાસક્રમમાં પુનરાવર્તન અને ઉદાહરણો પર ધ્યાન આપવું જોઈએ.
