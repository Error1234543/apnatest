🎯 પરીક્ષા ટ્રિક્સ

માત્ર તત્વ સ્વરૂપનું ઓક્સિડેશન અંક શૂન્ય હોય છે. તેથી Na, O₂, Cl₂, H₂, P₄, S₈ આદિનું ઓક્સિડેશન અંક 0 મૂકી દો.
જ્યારે પ્રશ્નમાં સ્વતંત્ર તત્વોની વાત હોય અથવા તેમનાં ઓક્સિડેશન અંક શોધવાના હોય.
દા.ત.: O₂ માં O નું ઓક્સિડેશન અંક = 0; Na ધાતુનું Na = 0.
ફ્લોરીન (F) હંમેશા -1 ઓક્સિડેશન અંક ધરાવે છે, કારણ કે તે સૌથી વિદ્યુતઋણ તત્વ છે.
F ધરાવતાં સંયોગોમાં અન્ય તત્વનો ઓક્સિડેશન અંક શોધતી વખતે.
દા.ત.: OF₂ માં F = -1, તેથી O = +2 થાય.
હાઇડ્રોજન સામાન્ય રીતે +1 હોય છે, પરંતુ ધાતુઓના હાઇડ્રાઇડ (NaH, CaH₂) માં -1 લાગુ પડે છે.
હાઇડ્રાઇડ સંયોગોમાં ઓક્સિડેશન અંકની ગણતરી કરતી વખતે.
દા.ત.: NaH માં H = -1, તેથી Na = +1.
ઓક્સિજન સામાન્ય રીતે -2 હોય છે; પરંતુ પરોક્સાઇડ (O₂²⁻) માં -1, સુપરઓક્સાઇડ (O₂⁻) માં -½ અને OF₂ માં +2 મેળવો.
પરોક્સાઇડ/સુપરઓક્સાઇડ/OF₂ સંયોગોની ઓક્સિડેશન અંકની ગણતરી દરમિયાન.
દા.ત.: H₂O₂ માં O = -1; KO₂ માં O = -½; OF₂ માં O = +2.
પ્રથમ પેલી ( alkali ) ધાતુઓ (Na, K) નું ઓક્સિડેશન અંક હંમેશા +1 અને બીજી પેલી ( alkaline earth ) ધાતુઓ (Mg, Ca) નું હંમેશા +2 લો.
આ ધાતુ ધરાવતા સંયોગોમાં અન્ય તત્વનો ઓક્સિડેશન અંક શોધવા.
દા.ત.: KMnO₄ માં K = +1, O = -2 ⇒ Mn = +7.
અણુનો કુલ ઓક્સિડેશન અંક શૂન્ય હોય છે; આયનનો તોડ (charge) જેટલો હોય છે. ઝડપી સમીકરણ ગોઠવીને અજ્ઞાત તત્વનો ઓક્સિડેશન અંક શોધો.
કોઈ પણ સંયોગ/આયનમાં એક તત્વનો ઓક્સિડેશન અંક શોધવા.
દા.ત.: MnO₄⁻ : Mn + 4(-2) = -1 ⇒ Mn = +7.
રેડોક્સ પ્રક્રિયા ઓળખવાનો ઝડપી રસ્તો: એક તત્વનો ઓક્સિડેશન અંક વધે છે અને બીજાનો ઘટે છે એ જોઈ લો. જો બંનેમાં ફેરફાર ન હોય તો રેડોક્સ નથી.
આપેલ પ્રક્રિયા રેડોક્સ છે કે નહીં તે ચકાસવા.
દા.ત.: Zn + Cu²⁺ → Zn²⁺ + Cu: Zn 0→+2, Cu +2→0; તેથી રેડોક્સ છે.
ઓક્સિડેશન એ ઇલેક્ટ્રોન ખોવાવાનું (ઓક્સિડેશન અંક વધવો); રિડક્શન એ ઇલેક્ટ્રોન મેળવવાનું (ઓક્સિડેશન અંક ઘટવું). યાદ રાખો: 'OIL RIG'.
પ્રક્રિયામાં કઈ પ્રજાતિ ઓક્સિડાઈ રહી છે અને કઈ રિડ્યूस થઈ રહી છે તે ઝડપી રીતે નક્કી કરવા.
દા.ત.: Fe²⁺ → Fe³⁺ + e⁻ (ઓક્સિડેશન); Cu²⁺ + 2e⁻ → Cu (રિડક્શન).
જ્યારે પ્રશ્નમાં ઓક્સિડાઈંગ/રિડ્યूसિંગ એજન્ટ પૂછે, તો જે પદાર્થ ઓક્સિડાઈ રહ્યો છે તે રિડ્યूसિંગ એજન્ટ છે અને જે રિડ્યુસ થઈ રહ્યો છે તે ઓક્સિડાઈંગ એજન્ટ છે.
એજન્ટ નક્કી કરવાનો સીધો રસ્તો.
દા.ત.: 2FeCl₃ + 2HI → 2FeCl₂ + I₂ + 2HCl: I⁻ ઓક્સિડાઈને I₂ બને છે, તેથી HI રિડ્યूसિંગ એજન્ટ; Fe³⁺ રિડ્યુસ થઈ Fe²⁺ બને છે, તેથી FeCl₃ ઓક્સિડાઈંગ એજન્ટ.
સ્વયંરેડોક્સ (ડિસપ્રોપોર્શનેશન) પ્રક્રિયામાં એક જ તત્વનું એક સ્વરૂપ ઓક્સિડાઈએ અને બીજું રિડ્યુસ થાય. આ બનવા માટે તત્વની વચ્ચે ઓછામાં ઓછા ત્રણ ઓક્સિડેશન અંકો હોવા જોઈએ.
સ્વયંરેડોક્સ પ્રક્રિયા ઓળખવા.
દા.ત.: Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O: Cl⁻ (-1) અને ClO⁻ (+1). Cl₂ (0) માંથી બંને બન્યા.
સમાન અણુમાં બે સમાન તત્વો અલગ અલગ ઓક્સિડેશન અંક દર્શાવતા હોય (ઉદા. Na₂S₄O₆, Na₂S₂O₃), તો સરેરાશ ઓક્સિડેશન અંકની ગણતરી કરો પરંતુ યાદ રાખો કે વાસ્તવિક ઓક્સિડેશન અંક અલગ હોઈ શકે છે.
થાયોસલફેટ/ટેટ્રાયોનેટ જેવા સંયોગોના પ્રશ્નોમાં.
દા.ત.: Na₂S₄O₆ માં સરેરાશ S = +2.5, પરંતુ બંધારણ મુજબ મધ્યના S (0) અને છેડાના S (+5) હોય છે.
KMnO₄ નો નર્મલિટી (n‑ફેક્ટર) માધ્યમ મુજબ ફરે છે: અમ્લীয় માધ્યમમાં +7→+2 (n=5); તಟસ્થ/દુર્બળ ક્ષારક માધ્યમમાં +7→+4 (n=3); પ્રબળ ક્ષારક માધ્યમમાં +7→+6 (n=1).
KMnO₄ સાથે સંબંધિત તિત્રણ (titration) કે n-ફેક્ટરના પ્રશ્નો.
દા.ત.: અમ્લীয় માધ્યમમાં KMnO₄ નું સમતુલ્યભાર = M/5.
K₂Cr₂O₇ હંમેશા અમ્લীয় માધ્યમમાં +6→+3 બદલાય છે (n=6). તેનું સમતુલ્યભાર M/6 થાય છે.
ડાયક્રોમેટ સાથેના સમતુલ્યભાર/નર્મલિટી પ્રશ્નો.
દા.ત.: K₂Cr₂O₇ નું સમતુલ્યભાર = 294/6 = 49.
રિડોક્સ સંતુલનમાં 'સેન્દ્રિય સંયોગો' માં C નું ઓક્સિડેશન અંક શોધવા માટે દરેક C–C બંધ 0 ગણાય; C–H માટે -1, C–O/O–H માટે +1, C–X (હેલોજન) માટે +1 ગણો.
રિડોક્સમાં સેન્દ્રિય સંયોગોના ઓક્સિડેશન અંક શોધવા.
દા.ત.: CH₃OH: C + 3(+1) + (-2) + (+1) = 0 ⇒ C = -2; HCHO: C + 2(+1) + (-2) = 0 ⇒ C = 0.
જો પ્રશ્નમાં 'કઈ પ્રજાતિ શ્રેષ્ઠ ઓક્સિડાઈંગ એજન્ટ છે?' પૂછે, તો સૌથી ઊંચું સકારાત્મક પ્રમાણિત રિડક્શન વિભવ (E°) ધરાવતી પ્રજાતિ પસંદ કરો.
ઇલેક્ટ્રોકેમિસ્ટ્રી શ્રેણી/ઓક્સિડાઈંગ શક્તિના પ્રશ્નો.
દા.ત.: F₂/F⁻ (E° = +2.87 V) > MnO₄⁻/Mn²⁺ (E° = +1.51 V); તેથી F₂ શ્રેષ્ઠ ઓક્સિડાઈંગ એજન્ટ.
