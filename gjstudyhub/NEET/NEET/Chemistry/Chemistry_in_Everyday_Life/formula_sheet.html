દૈનિક જીવનમાં રસાયણશાસ્ત્ર — સૂત્ર શીટ

⚡ સૂત્રો

એસિડિટી ઘટાડવા માટેની પ્રક્રિયા (એન્ટાઇડ — તટસ્થીકરણ): Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O
Al(OH)₃ = એલ્યુમિનિયમ હાઇડ્રોક્સાઇડ (એન્ટાઇડ); HCl = પાચનરસ (સ્ટોમેચ એસિડ); AlCl₃ = એલ્યુમિનિયમ ક્લોરાઇડ; H₂O = પાણી · SI: N/A — રાસાયણિક પ્રક્રિયા · જ્યારે પાચનરસ (HCl) નું પ્રમાણ વધી જાય અને એસિડિટીની સમસ્યા થાય
મેગ્નેશિયમ હાઇડ્રોક્સાઇડ દ્વારા તટસ્થીકરણ: Mg(OH)₂ + 2HCl → MgCl₂ + 2H₂O
Mg(OH)₂ = મેગ્નેશિયમ હાઇડ્રોક્સાઇડ (તાંત્રર); HCl = સ્ટોમેચ એસિડ; MgCl₂ = મેગ્નેશિયમ ક્લોરાઇડ; H₂O = પાણી · SI: N/A — રાસાયણિક પ્રક્રિયા · તાંત્રર એક પ્રબળ બેઝ છે જે HCl ને તટસ્થ કરે છે
ઓટેપ્રાઝોલ — H⁺/K⁺ ATPase અવરોધ (સંક્ષિપ્ત): Omeprazole + H⁺/K⁺-ATPase → અવરોધ (પ્રોટોન પંપની ક્રિયા બંધ)
H⁺/K⁺-ATPase = પોટાશિયમ હાઇડ્રોજન એડેનોસાઇટ્રીફોસ્ફેટેઝ (પ્રોટોન પંપ); Omeprazole = પ્રોટોન પંપ અવરોધક દવા · SI: N/A — જૈવરાસાયણિક પ્રક્રિયા · પેપ્ટિક അൾസર અને GERD નું ચિકિત્સન કરવા માટે
રાનિટિડિન — H₂-રિસેપ્ટર અવરોધ: Ranitidine + H₂-receptor → બિન્ડિંગ + H⁡⁺ સ્રાવ અવરોધ
Ranitidine = એન્ટિ-હિસ્ટામાઇન (H₂) દવા; H₂-receptor = ગેસ્ટ્રિક ખાલિકોષ પર હિસ્ટામાઇન H₂ રિસેપ્ટર; H⁺ = હાઇડ્રોજન આયન (એસિડ) · SI: N/A — જૈવરાસાયણિક પ્રક્રિયા · પેપ્ટિક અલ્સર અને એસિડિટીના ઉપચારમાં
ફેનિલઇથાઇલમિન (આર્ટિફિશિયલ સ્વીટનર): C₆H₅CH₂NHCH₂COOCH₃ (મિથાઇલ એસ્ટર)
C₆H₅ = ફેનિલ ગ્રુપ; CH₂NH = એમાઇન લિન્ક; COOCH₃ = મિથાઇલ એસ્ટર ગ્રુપ · SI: N/A — આણ્વીય સૂત્ર · નોન-nutritive સ્વીટનર તરીકે ઉપયોગ — ખાંડ કરતા ~૫૦૦ ગુણ મીઠો
એસ્પ્રિન (એસિ્ટાઇલસેલિસાઇલિક એસિડ) — આણ્વીય સૂત્ર: C₉H₈O₄
C₉H₈O₄ = ૨-એસિટોક્સિબેન્ઝોઇક એસિડનું આણ્વીય સૂત્ર · SI: N/A — આણ્વીય સૂત્ર · નિદાન: ઓલ્ડ એસિડ + એસિટિક એનહાઇડ્રાઇડ સાથે સેલિસાઇલિક એસિડનું એસિટેશન
પેરાસિટામોલ (એસિટેમિનોફેન) — આણ્વીય સૂત્ર: C₈H₉NO₂
C₈H₉NO₂ = N-(4-હાઇડ્રોક્સિફેનિલ)એસિટામાઇડ · SI: N/A — આણ્વીય સૂત્ર · ઉષ્માઘટક અને પીડાનાશક તરીકે; પેરાસિટામોલ એ સામાન્ય ઉષ્માઘટક
બેનઝોઇક એસિડ (પ્રિઝર્વેટિવ) — આણ્વીય સૂત્ર: C₆H₅COOH
C₆H₅ = ફેનિલ ગ્રુપ; COOH = કાર્બોક્સિલિક એસિડ ગ્રુપ · SI: N/A — આણ્વીય સૂત્ર · ફળજ્યુસ, સોરબેટ, જેમનામાં પ્રિઝર્વેટિવ તરીકે ઉપયોગ
સોડિયમ બેનઝોએટ — આણ્વીય સૂત્ર: C₆H₅COONa
C₆H₅ = ફેનિલ ગ્રુપ; COO⁻Na⁺ = સોડિયમ કાર્બોક્સિલેટ · SI: N/A — આણ્વીય સૂત્ર · બેનઝોઇક એસિડનું લવણ; pH < 4.5 પર વધુ અસરકારક પ્રિઝર્વેટિવ
સોડિયમ મેટાબિસલ્ફાઇટ (પ્રિઝર્વેટિવ) — આણ્વીય સૂત્ર: Na₂S₂O₅
Na = સોડિયમ; S₂O₅ = મેટાબિસલ્ફાઇટ આયન · SI: N/A — આણ્વીય સૂત્ર · સૂક્ષ્માનુજીવોને મૃત્યુ પામવાથી અટકાવે છે; વિનાઇગર, જામ, જુસમાં ઉપયોગ
સોડિયમ બાયસલ્ફાઇટ (પ્રિઝર્વેટિવ) — આણ્વીય સૂત્ર: NaHSO₃
Na = સોડિયમ; HSO₃ = બાયસલ્ફાઇટ આયન · SI: N/A — આણ્વીય સૂત્ર · કેતરી ફળ અને જ્યુસમાં પ્રિઝર્વેટિવ તરીકે
ટેટ્રાસાયક્લિક્સ (એન્ટિબાયોટિક) — આણ્વીય સૂત્ર: C₂₂H₂₄N₂O₉
C₂₂H₂₄N₂O₉ = ટેટ્રાસાયક્લિક એન્ટિબાયોટિકનું સામાન્ય આણ્વીય સૂત્ર · SI: N/A — આણ્વીય સૂત્ર · પ્રોકેરિયોટિક કોષમાં પ્રોટીન સંશ્લેષણ અવરોધે છે (30S રાઇબોઝોમલ એકમ)
ક્લોરામફેનિકોલ (એન્ટિબાયોટિક) — આણ્વીય સૂત્ર: C₁₁H₁₂Cl₂N₂O₅
C₁₁H₁₂Cl₂N₂O₅ = 2,2-ડાઇક્લોરો-N-[1,3-ડાઇહાઈડ્રોક્સીપ્રોપાન-2-ઇલ]એસિટામાઇડ · SI: N/A — આણ્વીય સૂત્ર · ઇન્હિબિટ્સ પ્રોટીન સંશ્લેષણ 50S રાઇબોઝોમ એકમ સાથે બંધાય છે
સલ્ફાડિયોન (સલ્ફોનામાઇડ) — આણ્વીય સૂત્ર: C₁₀H₁₀N₂O₂S
C₁₀H₁₀N₂O₂S = N-(4-અમિનોફેનિલ)બેન્ઝાસલ્ફોનામાઇડ · SI: N/A — આણ્વીય સૂત્ર · p-એમિનોબેન્ઝોઇક એસિડ (PABA) નું એનાલોગ; બેક્ટેરિયાને ફોલિક એસિડ સંશ્લેષણ અટકાવે છે
પેનિસિલિન G (બેન્ઝિલપેનિસિલિન) — આણ્વીય સૂત્ર: C₁₆H₁₈N₂O₄S
C₁₆H₁₈N₂O₄S = β-લેક્ટમ રિંગ ધરાવતું એન્ટિબાયોટિક · SI: N/A — આણ્વીય સૂત્ર · કોષદીવાલ સંશ્લેષણ અવરોધે છે (પેપ્ટિડોગલાયકાઇન ક્રસ-લિંકિંગ)
ઓક્સાસિલિન (એન્ટિબાયોટિક) — આણ્વીય સૂત્ર: C₁₉H₁₈N₃NaO₅S
C₁₉H₁₈N₃NaO₅S = નેફેલિન-સ્થાનાંતરિત પેનિસિલિન · SI: N/A — આણ્વીય સૂત્ર · β-લેક્ટમેઝ રેઝિસ્ટન્ટ; સ્ટેફિલોકોકસ માટે
કોડેઇન (ઓપિયોઇડ એનાલ્જેસિક) — આણ્વીય સૂત્ર: C₁₈H₂₁NO₃
C₁₈H₂₁NO₃ = મોર્ફિનનું 3-મેથાઇલ એથર · SI: N/A — આણ્વીય સૂત્ર · હળવી મધ્યમ પીડા અને કેશ માટે; CNS ડિપ્રેસન્ટ
મોર્ફિન (ઓપિયોઇડ એનાલ્જેસિક) — આણ્વીય સૂત્ર: C₁₇H₁₉NO₃
C₁₇H₁₉NO₃ = મોર્ફિનનું આણ્વીય સૂત્ર · SI: N/A — આણ્વીય સૂત્ર · તીવ્ર પીડામાં; μ-ઓપિયોઇડ રિસેપ્ટર એગોનિસ્ટ
નોર્ફ્લોક્સાસિન (ફ્લોરોક્વિનોલોન) — આણ્વીય સૂત્ર: C₁₆H₁₈FN₃O₃
C₁₆H₁₈FN₃O₃ = 1-એથાઇલ-7-(પિપેરાઝિન-1-ઇલ)-6-ફ્લોરો-1,4-ડાઇહાઇડ્રો-1,8-નાઇથ્રાયડિન-4-ઓક્સો-3-કાર્બોક્સિલિક એસિડ · SI: N/A — આણ્વીય સૂત્ર · DNAgyrase અને topoisomerase IV અવરોધે છે; સુષ્ટિગ્રાહી (broad-spectrum)
ઝેઇલાઇન (એન્ટિહિસ્ટામાઇન) — આણ્વીય સૂત્ર: C₁₆H₁₉N₃O
C₁₆H₁₉N₃O = ઝેઇટિટિન ડાયહાઇડ્રોક્લોરાઇડનું સક્રિય મેટાબોલાઇટ · SI: N/A — આણ્વીય સૂત્ર · પહેલી પીઢી હિસ્ટામાઇન H₁ એન્ટાગોનિસ્ટ; CBT પાર કરે છે → ઊંઘ આવે છે
સેટરિઝિન (એન્ટિહિસ્ટામાઇન) — આણ્વીય સૂત્ર: C₂₁H₂₃ClN₂O₂
C₂₁H₂₃ClN₂O₂ = ફ્લુઓરોપિપેરાઝિન યુક્ત દ્વિતીય પીઢી એન્ટિહિસ્ટામાઇન · SI: N/A — આણ્વીય સૂત્ર · બીજી પીઢી H₁ એન્ટાગોનિસ્ટ; CBT ઓછું પાર કરે → ઓછી ઊંઘ આવે
ઇન્ડોમેથેસિન (NSAID) — આણ્વીય સૂત્ર: C₁₉H₁₆ClNO₄
C₁₉H₁₆ClNO₄ = 2-[(1-મેથાઇલ-1H-ઇન્ડોલ-3-ઇલ)મેથાઇલ]એમિનોફેનિક એસિડ · SI: N/A — આણ્વીય સૂત્ર · COX-1 અને COX-2 બંને અવરોધે; બળતરા, ઉષ્મા, પીડા દૂર કરે
ઈબુપ્રોફેન (NSAID) — આણ્વીય સૂત્ર: C₁₃H₁₈O₂
C₁₃H₁₈O₂ = 2-(4-આઇસોબ્યુટાઇલફેનિલ)પ્રોપિઓનિક એસિડ · SI: N/A — આણ્વીય સૂત્ર · COX એન્ઝાઇમ અવરોધે → પ્રોસ્ટાગ્લાન્ડિન સંશ્લેષણ ઘટે
નેફલેન (NSAID) — આણ્વીય સૂત્ર: C₁₃H₁₁Cl₂NO₂
C₁₃H₁₁Cl₂NO₂ = 2-(2,6-ડાઇક્લોરોફેનિલ)એમિનોફેનિક એસિડ · SI: N/A — આણ્વીય સૂત્ર · શક્તિશાળી NSAID; ઘાતક પીડા અને બળતરા માટે
એસ્પ્રિન (સેલિસિલેટ) — આણ્વીય સૂત્ર (પુનરાવર્તન ટાળવા): C₉H₈O₄ (ઉપર જુઓ)
— · SI: N/A · —
કેટોલેક (એનાલ્જેસિક) — આણ્વીય સૂત્ર: C₁₆H₁₄N₂O₄
C₁₆H₁₄N₂O₄ = 2-[(4-હાઇડ્રોક્સિફેનિલ)એમિનો]પ્રોપિઓનિક એસિડ · SI: N/A — આણ્વીય સૂત્ર · ઉષ્માઘટક; ઇબુપ્રોફેન કરતાં પ્લાઝમા અર્ધઆયુષ્ય ઓછું

🔗 સંબંધો

  • એન્ટાઇડ (Al(OH)₃ / Mg(OH)₂) એ તટસ્થ બેઝ તરીકે Ka = [H⁺][A⁻]/[HA] ને વળગીને HCl ને તટસ્થ કરે છે.
  • H₁ એન્ટાગોનિસ્ટ (એન્ટિહિસ્ટામાઇન) નું પ્રભાવ ક્ષેત્ર = હિસ્ટામાઇન-માધ્યમ એલર્જિક પ્રતિક્રિયાઓ.
  • NSAIDs (ઈબુપ્રોફેન, એસ્પ્રિન) → COX-1/COX-2 અવરોધ → પ્રોસ્ટાગ્લાન્ડિન (PGE₂) સંશ્લેષણ ઘટે → પીડા અને ઉષ્મા ઘટે.
  • ઓપિયોઇડ એનાલ્જેસિક્સ (મોર્ફિન, કોડેઇન) → μ-રિસેપ્ટર એગોનિસ્ટ → CNS ડિપ્રેશન → તીવ્ર પીડા નિવારણ.
  • પેનિસિલિન → પેપ્ટિડોગલાયકાઇન ક્રસ-લિંકિંગ અવરોધ → કોષદીવાલ નબળી → બેક્ટેરિયા લાયસિસ.
  • ટૅટ્રાસાયક્લિક/ક્લોરામફેનિકોલ → 30S/50S રાઇબોઝોમલ એકમ → પ્રોટીન સંશ્લેષણ અવરોધ → બેક્ટેરિયલ વૃદ્ધિ રોકે.
  • સલ્ફાડિયોન (PABA એનાલોગ) → DHPS અવરોધ → ફોલિક એસિડ સંશ્લેષણ બંધ → બેક્ટેરિયા મૃત્યુ.
  • નોન-ન્યુટ્રિટિવ સ્વીટનર (એસ્પાર્ટમ, સેકરિનેટ) → કેલોરી રહિત + ખાંડ કરતાં ૩૦–૧૩૦૦ ગુણ મીઠો → વજન ઘટાડવા યોગ્ય.
  • પ્રિઝર્વેટિવ્સ (સોડિયમ બેનઝોએટ, Metabisulfite) → microbe metabolism અવરોધ → ફૂડ ખરાબ થતું રોકે.
  • પ્રથમ પીઢી એન્ટિહિસ્ટામાઇન (ઝેઇલાઇન) → CBT પાર કરે → ઊંઘ આવે; બીજી પીઢી (સેટરિઝિન) → CBT ઓછું પાર કરે → ઓછી ઊંઘ.

🎯 ટ્રિક્સ

પ્રિઝર્વેટિવ યાદ રાખવા માટે સંક્ષિપ્ત: SBC = Sodium Benzoate + Carbonates/Sorbate; MSM = Metabisulfite Na₂S₂O₅. ભારતમાં SBC અને MSM બંને સામાન્ય.
NSAIDs નું અક્ષર: I = Ibuprofen, E = Aspirin (Acetyl), N = Naproxen. ત્રણેય COX અવરોધક છે — બાકીના (મોર્ફિન, ઝેઇલાઇન) અલગ.
એન્ટિબાયોટિક્સના ટાઇપ અનુસાર યાદ રાખો: P = Penicillin (કોષદીવાલ), T = Tetracycline (30S), C = Chloramphenicol (50S), S = Sulfonamide (PABA), F = Fluoroquinolone (DNA gyrase).
સ્વીટનરની તીવ્રતા ક્રમ: સેકરિનેટ > એસ્પાર્ટમ > સૂક્રોઝ > ગ્લુકોઝ. સેકરિનેટ ~૩૦૦ ગુણ મીઠો, એસ્પાર્ટમ ~૨૦૦ ગુણ મીઠો.
એન્ટાઇડનું સાદું સૂત્ર: બેઝ + એસિડ → લવણ + પાણી (તટસ્થિકરણ પ્રક્રિયા). Mg(OH)₂ 2 HCl ને તટસ્થ કરે, Al(OH)₃ 3 HCl ને તટસ્થ કરે.
બીજી પીઢી એન્ટિહિસ્ટામાઇનનું અક્ષર R = Ranitidine (H₂-બ્લોકર, એસિડ માટે), C = Cetirizine (H₁-બ્લોકર, એલર્જી માટે). બંનેનો ઉપયોગ અલગ છે.

⚠️ ભૂલો

એસ્પ્રિન અને પેરાસિટામોલ વચ્ચેનો તફાવત ભૂલવો: એસ્પ્રિન NSAID છે (પ્રોસ્ટાગ્લાન્ડિન અવરોધે), પેરાસિટામોલ NSAID નથી — તે ઉષ્માઘટક છે પણ બળતરા વિરોધી નથી.
રાનિટિડિન એ એન્ટિહિસ્ટામાઇન નથી — તે H₂-રિસેપ્ટર એન્ટાગોનિસ્ટ છે, પાચનરસ ઘટાડે. H₁ એન્ટાગોનિસ્ટ એટલે એલર્જી (ઝેઇલાઇન/સેટરિઝિન) માટે.
સલ્ફાડિયોન એન્ટિબાયોટિકનું કાર્યકારી રીતે DNAgyrase નહીં — તે PABA (dihydropteroate synthase) નો એનાલોગ છે, ફોલિક એસિડ બ્લોક કરે.
એન્ટિબાયોટિકને 'ઔષધિ' તરીકે બધી જ વાતોમાં લાગુ પડે તેવું ગણવું: એન્ટિબાયોટિક ફક્ત બેક્ટેરિયા વિરુદ્ધ, વાયરસ વિરુદ્ધ નહીં.
એસ્પ્રિનનું સૂત્ર C₉H₈O₄ છે; ઘણા વિદ્યાર્થીઓને સેલિસાઇલિક એસિડ (C₇H₆O₃) સાથે ગુંચવાય છે — એસિટેશન થયા પછી C₉H₈O₄ બને.
કેટલેક અને પેરાસિટામોલને ભેળવી દેવા: C₁₆H₁₄N₂O₄ (કેટલેક) ≠ C₈H₉NO₂ (પેરાસિટામોલ). બંને અલગ પીડાનાશક છે.
સેકરિનેટ એ C₁₀H₁₂N₂O₄S₂Na₂ છે — ઘણા છૂટા પડતા વિદ્યાર્થીઓનું સૂત્ર યાદ રહેતું નથી.
બેન્ઝોઇક એસિડ (C₆H₅COOH) અને સોડિયમ બેનઝોએટ (C₆H₅COONa) વચ્ચેનો તફાવત: એક એસિડ છે, બીજું તેનું લવણ; બંને પ્રિઝર્વેટિવ છે પરંતુ pH ની અસર અલગ.
ઈબુપ્રોફેન C₁₃H₁₈O₂ છે — ઘણા કાર્બન/હાઇડ્રોજનનું સંતુલન ગણતી વખતે ભૂલ કરે છે.
પેનિસિલિનનો β-લેક્ટમ રિંગ ભૂલી જવો — આ રિંગ જ બેક્ટેરિયા કોષદીવાલની ક્રિયાક્ષમતા બગાડે છે; રિંગ રહે તો જ એન્ટિબાયોટિક કામ કરે.
