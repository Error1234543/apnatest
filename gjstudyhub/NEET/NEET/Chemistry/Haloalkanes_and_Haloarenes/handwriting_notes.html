હેલોઆલ્કેન અને હેલોએરીન્સ — હેન્ડરાઈટિંગ સ્ટાઈલ નોટસ

🩺 NEET UG — Gujarati • Chemistry • Haloalkanes and Haloarenes

ભાગ ૧ — પ્રસ્તાવના અને પરિચય
હેલોકાર્બનિક સંયોજનો એવા કાર્બનિક સંયોજનો છે જેમાં કાર્બન શૃંખલામાં એક અથવા વધુ હેલોજન પરમાણુ (F, Cl, Br, I) જોડાયેલું હોય.
હેલોકાર્બનિક સંયોજનો બે પ્રકારના છે: હેલોઆલ્કેન (અલિપિલ) અને હેલોએરીન્સ (એરોમેટિક).
હેલોઆલ્કેન: R−X (જ્યાં X = F, Cl, Br, I) — ઉદા. ક્લોરોમીથેન (CH₃Cl), બ્રોમોએથીલ (C₂H₅Br).
હેલોએરીન્સ: Ar−X — ઉદા. બેન્ઝિનક્લોરાઇડ (C₆H₅Cl), ઓર્થો-ડાઈક્લોરોબેન્ઝીન.
સામાન્ય સૂત્ર (એક-હેલો આલ્કેન): CnH(2n+1)X
📝 NEET ટિપ: X નું પ્રકાર (F/Cl/Br/I) જાણવું મહત્વનું છે — અનુવૃત્તિ C−F > C−Cl > C−Br > C−I (બંધ મજબૂતાઈનો ક્રમ).
ભાગ ૨ — નામકરણ (Nomenclature)
IUPAC પ્રણાલી મુજબ: હેલોજનને ઉપસર્ગ તરીકે ઉપયોગમાં લે છે — ફ્લોરો-, ક્લોરો-, બ્રોમો-, આયોડો-.
ઉદાહરણ: CH₃CH₂Cl → ક્લોરોએથીલ (Chloroethane). CH₃Cl → ક્લોરોમીથેન.
જો એક કરતાં વધુ હેલોજન હોય તો di-, tri-, tetra- પ્રત્યય વપરાય છે. ઉદા. 1,2-ડાઈક્લોરોએથેન.
અભ્યાસક્રમ માટે મહત્વ: આલ્કિલ હેલાઇડ્સના ૩ પ્રકાર — પ્રાથમિક (1°), દ્વિતીયક (2°), તૃતીયક (3°). આનો SN1/SN2 પર સીધો પ્રભાવ પડે છે.
1° ક્લોરોઆલ્કેન: RCH₂−Cl | 2°: R₂CH−Cl | 3°: R₃C−Cl
સામાન્ય નામ: આલ્કાઇલ ગ્રૂપ + હેલાઇડ (ઉદા. આઇસોપ્રોપાઇલ બ્રોમાઇડ, ટર્શરી-બ્યુટાઇલ ક્લોરાઇડ).
ભાગ ૩ — C−X બંધ અને સંયોજક પ્રકૃતિ
હેલોકાર્બનિક સંયોજનોમાં C−X બંધ ધ્રુવીય હોય છે કારણ કે X (હેલોજન) કર્લોનતામાં C કરતાં વધારે હોય છે.
હેલોજનની કર્લોનતા ક્રમ: F > Cl > Br > I → તેથી C−F બંધ સૌથી વધુ ધ્રુવીય પણ સૌથી મજબૂત.
બંધ લંબાઈ ક્રમ: C−F < C−Cl < C−Br < C−I બંધ ઊર્જા ક્રમ: C−F > C−Cl > C−Br > C−I
મહત્વનું: જેમ C−X બંધ લાંબો થાય તેમ બંધ તૂટવો સહેલો બને → આયોડોઆલ્કેન સૌથી પ્રતિક્રિયાશીલ.
📝 NEET ટિપ: C−X બંધની દૃઢતા જાણીએ તો પ્રતિક્રિયાશીલતાનો અંદાજ લગાવી શકાય — 3° હેલોઆલ્કેન > 2° > 1° (SN1 માં).
ભાગ ૪ — હેલોઆલ્કેનની તૈયારી (Preparation of Haloalkanes)
૧. આલ્કોહૉલથી હેલોજન સંયોજન: ROH + HX → RX + H₂O
ROH + HCl(ZnCl₂/લૂકાર્ત રિએજન્ટ) → RCl + H₂O (સુકેનેડ્રોલ પરીક્ષણ)
3 ROH + PCl₃ → 3 RCl + H₃PO₃ ROH + PCl₅ → RCl + POCl₃ + HCl 3 ROH + PBr₃ → 3 RBr + H₃PO₃
૨. હેલોજન દ્વારા સીધું સંયોજન (મુક્ત મૂળ પ્રક્રિયા): CH₄ + Cl₂ (UV પ્રકાશ) → CH₃Cl + HCl
મફત મૂળ બદલી પ્રક્રિયા (Free radical substitution): આલ્કેન + હેલોજન → હેલોઆલ્કેન + HX. UV પ્રકાશ / ઉષ્મા જરૂરી છે.
૩. એલ્કીનમાં હેલોજનયુક્ત એસિડનું સંયોજન: હર્થ પ્રક્રિયા (Markovnikov's rule).
CH₂=CH₂ + HBr → CH₃CH₂Br CH₃CH=CH₂ + HBr → CH₃CHBrCH₃ (Markovnikov ઉત્પાદન)
એલ્કીન + HXહેલોઆલ્કેન (Markovnikovનો નિયમ લાગુ)
૪. સોક્લેટ સંગ્રાહક ( Soxhlet extractor) પદ્ધતિનો ઉપયોગ બેન્ઝીનથોલમાંથી બ્રોમોબેન્ઝીન બનાવવા કરીએ છીએ — હેલોએરીન્સ વિભાગમાં જોશું.
ભાગ ૫ — હેલોએરીન્સની તૈયારી
૧. બેન્ઝીન પર ક્લોરો/બ્રોમો સીધું સંયોજન: FeCl₃ / AlCl₃ ઉત્પ્રેરક સાથે.
C₆H₆ + Cl₂ → C₆H₅Cl + HCl (FeCl₃ ઉત્પ્રેરક) C₆H₆ + Br₂ → C₆H₅Br + HBr (FeBr₃ ઉત્પ્રેરક)
૨. આયોડોબેન્ઝીન: I₂/oxidizing agent (HNO₃ અથવા HIO₃) સાથે — I₂ સીધું પ્રતિક્રિયાતું નથી.
C₆H₆ + I₂ → C₆H₅I + HI (HNO₃ અથવા HIO₃ ઉપસ્થિતિમાં)
૩. ગાઈઝર (Gattermann) પ્રક્રિયા: એરોમેટિક એમીન + NaNO₂ + HCl (0-5°C) → ડાયઝોનિયમ લવણ → HCl/Cu પાવડર → ક્લોરોબેન્ઝીન.
C₆H₅NH₂ + NaNO₂ + 2HCl (0-5°C) → C₆H₅N₂⁺Cl⁻ + NaCl + 2H₂O C₆H₅N₂⁺Cl⁻ + HCl/Cu → C₆H₅Cl + N₂ + HCl
હેલોએરીન્સમાં C−X બંધ આંશિક દ્વિ-બંધ લક્ષણ ધરાવે છે (resonance because of lone pair on halogen with benzene ring). તેથી C−X બંધ મજબૂત અને સંયોજક પ્રક્રિયાઓ માટે ઓછો પ્રતિક્રિયાશીલ.
📝 NEET ટિપ: હેલોએરીન્સ C−X બંધ તોડવો મુશ્કેલ છે → SN પ્રક્રિયાઓમાં નિષ્ક્રિય. આ ખાસ નોંધવું. 15-20% પ્રશ્નો અહીંથી આવે છે.
ભાગ ૬ — ભૌતિક ગુણધર્મો (Physical Properties)
૧. આયનિક હેલાઇડ્સની તુલનામાં હેલોકાર્બનિક સંયોજનોના ગલનબિંદુ અને ઉત્કલનબિંદુ ઓછા હોય છે (સહસંયોજક પ્રકૃતિ).
૨. ઉત્કલનબિંદુ ક્રમ: આલ્કેન < હેલોઆલ્કેન < આલ્કોહૉલ → વધુ બાષ્પશીલ.
૩. એક જ આલ્કાઇલ સમૂહ માટે: RI > RBr > RCl > RF (भार વધવાથી Van der Waals બળ વધે).
આઇસોમરનો પ્રભાવ: શાખાયુક્ત આઇસોમરનું ઉત્કલનબિંદુ સીधा શૃંખલા કરતાં ઓછું હોય છે (કારણ કે આકાર ગોળ થાય → સપાટી ક્ષેત્રફળ ઘટે).
૪. હેલોઆલ્કેન પાણીમાં દ્રાવ્ય નથી (અદ્રાવ્ય) — હાઈડ્રોજન બંધ બનાવી શકતાં નથી. પરંતુ ધ્રુવીય દ્રાવકોમાં દ્રાવ્ય.
૫. સઘનતા: હેલોઆલ્કેનની સઘનતા પાણી કરતાં વધારે હોય છે.
📝 NEET ટિપ: હેલોઆલ્કેન-આઇસોમરનું ઉત્કલનબિંદુ શાખાયુક્ત vs સીधा આલ્કેન — સામાન્ય પ્રશ્ન.
ભાગ ૭ — ન્યુક્લિયોફીલિક બદલી પ્રક્રિયાઓ (Nucleophilic Substitution Reactions) — પ્રસ્તાવના
હેલોઆલ્કેનમાં X⁻ નું સ્થાને ન્યુક્લિયોફીલ (Nu⁻) આવે તેવી પ્રક્રિયાને ન્યુક્લિયોફીલિક બદલી પ્રક્રિયા કહે છે.
R−X + Nu⁻ → R−Nu + X⁻
કુદરતી ન્યુક્લિયોફીલ્સ: OH⁻, CN⁻, NH₃, RO⁻, NO₂⁻, HS⁻, I⁻.
સુપ્રિયમ મિત્ર: બે પ્રકારની ન્યુક્લિયોફીલિક બદલી પ્રક્રિયા છે — SN1 અને SN2. NEET માંથી સીધા પ્રશ્નો આવે છે.
R−X + Nu⁻R−Nu + X⁻ (બદલી પ્રક્રિયા — બે માર્ગ: SN1 અથવા SN2)
ભાગ ૮ — SN2 પ્રક્રિયા (Bimolecular Nucleophilic Substitution)
SN2 એક કદમની (concerted) પ્રક્રિયા છે — હુમલો અને વ્યર્થ થવું એકસાથે થાય છે.
દરની સમીકરણ: दर = k[RX][Nu⁻] (બંને સાંદ્રતા દર પર અસર કરે છે).
સંક્રાંતિ અવસ્થા (Transition state): Nu⋯R⋯X (પેન્ટા-સંયોજક કાર્બન).
દર = k[RX][Nu⁻] કાર્બન સંક્રાંતિ અવસ્થામાં sp² જેવો (ત્રિકોણીય સમતલ).
વિન્યાસ વ્યસ્તીકરણ (Inversion of configuration): Walden inversion — Nu⁻ પાછળથી હુમલો કરે છે, પરિણામે R→S (અથવા S→R) વિન્યાસ બદલાય છે.
SN2 માં પ્રતિક્રિયાશીલતા ક્રમ: 1° > 2° > 3° — because steric hindrance (અવરોધ) ઓછો. CH₃X > 1° > 2° >> 3° (3° SN2 થતું નથી).
ઉત્તમ દ્રાવક: ધ્રુવીય અપ્રોટિક દ્રાવક (acetone, DMSO, DMF) — Nu⁻ ને free રાખે છે.
📝 NEET ટિપ: SN2 પ્રક્રિયામાં વિન્યાસ વ્યસ્તીકરણ થાય છે — optical activity reverse થાય. ચિહ્ન S→R અથવા R→S.
ભાગ ૯ — SN1 પ્રક્રિયા (Unimolecular Nucleophilic Substitution)
SN2 માંથી વિપરીત: SN1 બે કદમની પ્રક્રિયા છે.
કદમ ૧ (ધીમું, દર નિયત): R−X → R⁺ + X⁻ (carbocation બને છે).
કદમ ૨ (तेज): R⁺ + Nu⁻ → R−Nu
दर = k[RX] Carbocationની સ્થિરતા: 3° > 2° > 1° > CH₃⁺
SN1 માં પ્રતિક્રિયાશીલતા ક્રમ: 3° > 2° > 1° — carbocation સ્થિરતા પર આધારિત. 3° હેલોઆલ્કેન SN1 માટે શ્રેષ્ઠ.
રેસીમિકરણ (Racemization): Nu⁺ પાસેથી અને પાછળથી બંને બાજુ હુમલો થઈ શકે → racemic mixture (d+l).
ઉત્તમ દ્રાવક: ધ્રુવીય પ્રોટિક દ્રાવક (water, alcohol) — carbocation stabilize કરે છે.
R⁺ (carbocation) stabilization: hyperconjugation + inductive effect (+I from alkyl groups)
3° haloalkane + weak nucleophileSN1 પ્રક્રિયા ( Racemization થાય)
📝 NEET ટિપ: SN1 = unimolecular, carbocation intermediate, racemization. SN2 = bimolecular, no intermediate, inversion. બંનેને અલગ પારખવું આવશ્યક.
ભાગ ૧૦ — SN1 vs SN2 — સરખામણી (Comparison)
SN1: 1° પ્રક્રિયા (first order), carbocation intermediate, racemization, weak nucleophile, protic solvent.
SN2: 2° પ્રક્રિયા (second order), no intermediate (transition state), inversion, strong nucleophile, aprotic solvent.
SN2 માટે: CH₃X > 1° > 2° >> 3° (3° પ્રતિક્રિયાતું નથી).
SN1 માટે: 3° > 2° >> 1° > CH₃X (CH₃X પ્રતિક્રિયાતું નથી — carbocation very unstable).
જો પ્રશ્નમાં Nu⁻ ძლიერი અને substrate 1° હોય → SN2. જો Nu⁻ दुर्बल અને substrate 3° હોય → SN1. આ નિયમ યાદ રાખો.
📝 NEET ટિપ: આ સરખામણીની કોષ્ટક ઘણીવાર મેચ ધરો પ્રશ્નમાં આવે છે. બંનેના mechanism step-by-step યાદ રાખો.
ભાગ ૧૧ — E1 અને E2 પ્રક્રિયાઓ (Elimination Reactions)
E2 પ્રક્રિયા: એક કદમ, concerted — Nu⁻ હાઇડ્રોજન દૂર કરે છે અને X⁻ બહાર નીકળે છે. β-હાઇડ્રોજન અને leaving group વિરુદ્ધ બાજુએ (anti-periplanar) હોવા જોઈએ.
E2 दर = k[RX][Base] (bimolecular elimination) 产物: alkene (Zaitsev નો નિયમ મુજબ વધુ substituted alkene મુખ્ય.)
Zaitsev નો નિયમ: Elimination માં તે alkene મુખ્ય જોવા મળે છે જેમાં C=C સાથે જોડાયેલા alkyl સમૂહો વધુ હોય (વધુ stable).
E1 પ્રક્રિયા: બે કદમ — પ્રથમ carbocation બને (slow), પછી base β-H દૂર કરે (fast).
E1 दर = k[RX] Carbocation → Base β-H લે → Alkene + BH⁺
E1 અને SN1 એકબીજાની પ્રતિસ્પર્ધી પ્રક્રિયાઓ છે — સામાન્ય રીતે ઉષ્મા (heat) હોય તો E1 વધુ, ઓછી ઉષ્મા હોય તો SN1 વધુ.
E2 માં પ્રતિક્રિયાશીલતા ક્રમ: 3° > 2° > 1° (base strength પણ જરૂરી). strong bulky base (t-BuOK) → Hofmann product (less substituted alkene).
📝 NEET ટિפ: Zaitsev vs Hofmann — Zaitsev = more substituted alkene (major). Hofmann = less substituted (bulky base હોય તો).
ભાગ ૧૨ — ઓરગેનોમેટલિક એજન્ટ્સ (Organometallic Compounds)
ગ્રિગનાર્ડ અભિકારક (Grignard reagent): R−Mg−X (એથર દ્રાવકમાં). આલ્કાઇલ હેલાઇડ + Mg → ગ્રિગનાર્ડ અભિકારક.
R−X + Mg (dry ether) → R−Mg−X (ગ્રિગનાર્ડ અભિકારક) R−Mg−X + C=O → adduct → H₂O/H⁺ → alcohol
ગ્રિગનાર્ડનો ઉપયોગ: formaldehyde → primary alcohol; other aldehydes → secondary; ketones → tertiary; CO₂ → carboxylic acid.
ગ્રિગનાર્ડ બનાવતી વખતે dry ether જરૂરી — moisture (H₂O) હોય તો R−Mg−X → R−H (destruction થાય).
કાર્બેન (Carbene :CH₂): dichlorocarbene (CCl₂:) નો ઉત્પાદન. CHCl₃ + KOH (alc.) → :CCl₂ (dichlorocarbene).
CHCl₃ + KOH(alc.) → :CCl₂ (dichlorocarbene) CCl₃⁻K⁺ + OH⁻ → :CCl₂ + H₂O + Cl⁻
📝 NEET ટિપ: Carbenes neutral species છે, highly reactive. Dichlorocarbene addition to alkene → cyclic product (cyclopropane derivative).
ભાગ ૧૩ — વર્ધ (Wurtz) પ્રક્રિયા
રેફેક્ટિવ સોડિયમ સાથે આલ્કાઇલ હેલાઇડની પ્રક્રિયાથી સમરૂપ આલ્કેન બને છે.
2 R−X + 2Na (dry ether) → R−R + 2NaX ઉદા. 2CH₃Br + 2Na → CH₃−CH₃ + 2NaBr
મર્યાદા: વિષમ (mixed) Wurtz પ્રક્રિયાથી three products મળે છે → single product નામ માટે સમાન આલ્કાઇલ હેલાઇડનો ઉપયોગ કરવો જોઈએ.
NEET ટિપ: સમાન આલ્કાઇલ હેલાઇડનો ઉપયોગ → single alkene/symmetric product. Mixed Wurtz unsuitable for named product.
ડી-વર્ધ પ્રક્રિયા (Freund reaction): આરોમેટિક હેલાઇડ + sodium → biaryl. ઉદા. 2C₆H₅Cl + 2Na → C₆H₅−C₆H₅ + 2NaCl.
ભાગ ૧૪ — ફ્રીઓન અને DDT (ઓઝોન સ્તર અને પર્યાવરણ)
ફ્રીઓન (CFCs): CCl₃F (Freon-11), CCl₂F₂ (Freon-12). Refrigerants, aerosols, foam-blowing agents માં ઉપયોગ.
CFCs સ્તરબાહ્ય વાતાવરણમાં UV પ્રકાશથી વિભાજિત થાય છે → Cl• મુક્ત મૂળ બને છે.
CFCl₃ (UV) → •CFCl₂ + Cl• Cl• + O₃ → ClO• + O₂ ClO• + O → Cl• + O₂ (catalytic cycle) Net: O₃ + O → 2O₂ (Ozone depletion)
Cl• radical ozone destruction કરે છે — એક Cl• પરમાણુ હજારો O₃ अणुઓને નષ્ટ કરી શકે છે (catalytic chain reaction).
DDT (डायक्लोरोडाइફિनिલट्राइक्लोरोएथेन): 1,1'- Dichloro-2,2,2-trichloroethane. Keet-naashak (insecticide).
DDT full name: 1,1,1-trichloro-2,2-bis(4-chlorophenyl)ethane Structure: ClC₆H₄−C(Cl)(CH₃)−C₆H₄Cl(p)}
DDT નું સ્થાયીકરણ જૈવિક પ્રણાલીમાં થાય (bioaccumulation) → માછલી / પક્ષીઓ / મનુષ્યમાં જમા થાય → ecological imbalance.
NEET ટિપ: CFCs → Ozone layer depletion. DDT → bioaccumulation, environmental pollutant. બંને environmental chemistry માં important.
📝 NEET ટિપ: Ozone depletion equation: O₃ + O → 2O₂ (net). Cl• catalyst છે — consume થતું નથી.
ભાગ ૧૫ — હેલોએરીન્સની રાસાયણિક પ્રક્રિયાઓ
હેલોએરીન્સ (એરોમેટિક હેલાઇડ્સ) SN પ્રક્રિયાઓમાં નિષ્ક્રિય છે — C−X bond strong due to resonance.
એકમાત્ર વૈકલ્પિક: highly reactive conditions જરૂરી — high temperature, pressure, strong base.
C₆H₅Cl + 2NaOH (623K, 300 atm) → C₆H₅ONa + NaCl + H₂O C₆H₅ONa + HCl → C₆H₅OH + NaCl (phenol formation)
ડાઉ ડાઉ પ્રક્રિયા (Dow process): chlorobenzene + NaOH (high T, P) → phenol.
હેલોએરીન્સમાં Nu⁻ હુમલો સીધો શક્ય નથી — benzene ring electron-rich હોવાથી Nu⁻ ને repel કરે છે. તોપણ benzyne intermediate દ્વારા પ્રક્રિયા શક્ય છે.
C₆H₅Cl + NaNH₂ (liq NH₃) → C₆H₅NH₂ (aniline via benzyne intermediate) Benzyne intermediate formed when strong base abstracts ortho-H and Cl leaves simultaneously.
📝 NEET ટિप: Benzyne mechanism — strong base (NaNH₂) હોય તો જ થાય. intermediate = benzyne ( triple bond વાળું cyclic).
ભાગ ૧૬ — હેલોઆલ્કેનના મહત્વના ઉપયોગ (Uses of Haloalkanes)
૧. CHCl₃ (ક્લોરોફોર્મ) — anesthetic, solvent, CHCl₃ + acetone → antiseptic (Dettol ingredient).
૨. CCl₄ (carbone tetrachloride) — fire extinguisher, non-flammable solvent.
૩. CHI₃ (આયોડોફોર્મ) — antiseptic, iodine release property.
૪. CCl₂F₂ (Freon-12) — refrigerant (halocarbons),但现在 controlled due to ozone damage.
૫. CH₂Cl₂ (મરોકોમીથેન) — solvent, paint remover.
બહુ-હેલોજન સંયોજનો: ઘણા organic solvents, pharmaceuticals, agrochemicals માં વપરાય છે. પરંતુ environmental impact ધ્યાનમાં રાખવું.
📝 NEET ટિપ: CHCl₃, CCl₄, CHI₃ ના વ્યવહારુ ઉપયોગ યાદ રાખો — direct factual question આવે છે.
