હેલોએલ્કેન્સ અને હેલોઑરેન્સ — ટૂંકા નોંધ

🩺 NEET UG — Gujarati • Chemistry • Haloalkanes and Haloarenes

📘 વ્યાખ્યાઓ

  • હેલોએલ્કેન્સ (Haloalkanes): એલ્કેનનો હિડ્રોજન અણુ હેલોજનથી બદલાય તેવા સંયોજનો; સામાન્ય સૂત્ર CnH2n+1X
  • હેલોઑરેન્સ (Haloarenes): બેન્ઝીન રિંગનો હિડ્રોજન હેલોજનથી બદલાય તેવા સંયોજનો; સામાન્ય સૂત્ર ArX
  • SN1 પ્રક્રિયા (Substitution Nucleophilic Unimolecular): એક-આણ્વીય ન્યુક્લિયોફિલિક પ્રતિસ્થાપન; બે-પગલાંની પ્રક્રિયા, વેગ સમીકરણ v = k[RX]
  • SN2 પ્રક્રિયા (Substitution Nucleophilic Bimolecular): દ્વિ-આણ્વીય ન્યુક્લિયોફિલિક પ્રતિસ્થાપન; એક-પગલાંની પ્રક્રિયા, વેગ v = k[RX][Nu]
  • વોર્ટઝ પ્રક્રિયા (Wurtz Reaction): 2RX + 2Na → R-R + 2NaX; બંને હેલોએલ્કેન્સ સમાન હોય ત્યારે ડાયએલ્કેન બને
  • ફિટીગ પ્રક્રિયા (Fittig Reaction): 2ArX + 2Na → Ar-Ar + 2NaX; બે હેલોઑરેન્સના સંયોગથી બાયફિનાઈલ બને
  • ડાયઝોનિયમ લવણ (Diazonium Salt): Ar-N₂⁺X⁻; આરોમેટિક એમાઇનમાંથી બનતું પ્રક્રિયાશીલ મધ્યવર્તી, હેલોઑરેન્સ તૈયારીમાં ઉપયોગી
  • કોન્જુગેટ ઇલેક્ટ્રોફિલિક પ્રતિસ્થાપન (SEAr): આરોમેટિક રિંગ પર ઇલેક્ટ્રોફિલ દ્વારા હિડ્રોજનનું પ્સતિસ્થાપન

⚡ સૂત્રો

  • C–X બંધ દ્રવ્યધ્રુવતા: C–F > C–Cl > C–Br > C–I (બંધ લંબાઈ વધતા ઘટે)
  • હેલોએલ્કેન્સનું ઉત્કલન બિંદુ: RI > RBr > RCl > RF (આણ્વીય ભાર વધતાં વધે)
  • સૌથી ઊંચું ઉત્કલન બિંદુ: સમાન C સંખ્યા માટે બ્રાન્ચડ < રેખીય એલ્કેન
  • SN2 વેગ: v = k[RX][Nu⁻]; SN1 વેગ: v = k[RX]
  • R-OH + HX → R-X + H₂O (લ્યુઈસ ઍસિડ ZnCl₂ સહાયક, વિશેષ કરી RCl બનાવવા)
  • R-OH + SOCl₂ → R-Cl + SO₂↑ + HCl↑ (સૌથી શ્રેષ્ઠ પદ્ધતિ; ધૂમ્રાભ ગેસ મળે)
  • 3R-OH + PX₃ → 3R-X + H₃PO₃ (PCl₃, PBr₃, PI₃)
  • R-OH + PCl₅ → R-Cl + POCl₃ + HCl
  • RN + NaNO₂ + 2HX → ArX + N₂ + NaX + 2H₂O (ગતાંપ (0–5°C)), બ્રોમિન/આयोડિન માટે CuBr/CuI સંધકારક
  • 2RX + 2Na → R-R + 2NaX (વોર્ટઝ; સૂકા એથરમાં)
  • 2ArX + 2Na → Ar-Ar + 2NaX (ફિટીગ; સૂકા એથરમાં)
  • RX + KOH(જલીય) → R-OH + KX (પ્રતિસ્થાપન); RX + KOH(અલ્કોહોલિક) → એલ્કીન + KX + H₂O (વિલોપન)
  • હેલોફોર્મ પ્રક્રિયા: CH₃COCH₃ + 3I₂ + 4NaOH → CHI₃↓(पीતल) + CH₃COONa + 3NaI + 3H₂O
  • કાર્બેન (Carbene) : :CH₂ ; CHCl₃ + KOH(અલ્કોહોલિક) → :CHCl → ક્લોરોફોર્મનું વિલયન

⭐ મુખ્ય તથ્યો

  • C–X બંધમાં sp³-C–X હેલોએલ્કેન્સમાં; sp²-C–X હેલોઑરેન્સમાં
  • હેલોએલ્કેન્સના ઉત્કલન બિંદુ તેમના એલ્કેન્સ કરતાં વધુ હોય છે
  • એલ્કેનિલ અને એરીલ હેલોએલ્કેન્સ જલીય NaOH સાથે સહેલાઈથી પ્રતિસ્થાપન નથી કરતાં
  • SN1 પ્રક્રિયામાં રેસેમીકરણ (Racemisation) થાય છે; SN2 માં સંપૂર્ણ વિપરીત રચના (Inversion) મળે છે
  • SN1 માટે સક્રિયતા: 3° > 2° > 1°; SN2 માટે: 1° > 2° > 3°
  • એલ્યુમિનિયમ હેલોજન અને બેન્ઝીન: C₆H₆ + Cl₂ → C₆H₅Cl + HCl (FeCl₃/AlCl₃ સંધકારક)
  • હેલોઑરેન્સમાં C–X બંધ મજબૂત હોય છે તેથી પ્રતિસ્થાપન અલ્પ પ્રક્રિયાશીલ
  • કર્બોકેટાયન (Carbocation) સ્થાયિત્વ: 3° > 2° > 1° > CH₃⁺ → આ SN1 નો વેગ નક્કી કરે છે
  • હેલોએલ્કેન્સમાં આલ્કીલાઈડ આયન (Alkylidene dihalide) gem-dihalide બને છે
  • એક જ C પર બે halogen હોય તો તે gem-dihalide; પાસપાસેના બે C પર હોય તો vic-dihalide
  • ફોસ્જીન (Phosgene): COCl₂; તે ક્લોરોફોર્મ હવા/સૂર્ય પ્રકાશમાં બને છે
  • ICl આયોડિન કરતાં વધુ પ્રક્રિયાશીલ છે કારણ કે I–Cl બંધ DCl કરતાં અલ્પ
  • હેલોઑરેન્સનું NaOH(જલીય) સાથે ગરમ કરતાં ફિનોલ બને છે → ઉચ્ચ તાપમાન/દબાણ જરૂરી
  • ડાયઝોનિયમ લવણના તાપીય વિઘટનમાં N₂ મુક્ત થાય છે, જે વાયુ રૂપે સહેલાઈથી બહાર નીકળે છે
  • હેલોએલ્કેન્સ ધાતુઓ સાથે: RX + 2Na + XR → R-R (વોર્ટઝ)
  • બેન્ઝોઈલ ક્લોરાઈડ (C₆H₅COCl) એ એક એસિડ હેલાઈડ છે, હેલોએલ્કેન્સ નહીં

⚠️ સામાન્ય ભૂલો

  • SN1 માં SN2 ને બદલે વિલોપન (Elimination) પ્રબળ થઈ શકે છે → આંતરિક તાપમાન અને બેઝની તીવ્રતા પર
  • હેલોઑરેન્સ SN1/SN2 કરતું નથી એમ માનવું ભૂલભરેલું; સખત પરિસ્થિતિમાં (ઉચ્ચ તાપ/દબાણ) પ્રતિસ્થાપન થાય છે
  • વોર્ટઝ પ્રક્રિયામાં બંને RX સમાન હોવા જોઈએ એમ નથી; પરંતુ વિષમ નામકરણ ઓછું વપરાય છે
  • હેલોએલ્કેન્સ સાથે KCN → R-CN (નાયટ્રાઈલ); AgCN → R-NC (આઈસોસાયનેટ) — આ ધાતુના સંયોજન પર આધારિત
  • હેલોફોર્મ (CHI₃) માત્ર CH₃CO– સમૂહ ધરાવતા સંયોજનોથી મળે છે; બધા હેલોજનયુક્ત સંયોજનથી નહીં
  • ICl પ્રક્રિયાશીલ કારણ કે I–Cl બંધ DCl કરતાં અલ્પ — I₂ એકલો ધીમો છે
  • Cl₂ + CH₄ (UV) → CH₃Cl + ... ચરગ (Free radical) પ્રક્રિયા; આલ્કેનનો સ્થાનિકરણ નહીં
  • SN1 માં રેસેમીકરણ હોય છે; તેથી પ્રક્રિયા દરમિયાન સંપૂર્ણ વિપરીત રચના મળતી નથી
  • ફોસ્જીન બનાવતી પ્રક્રિયા: 2CHCl₃ + O₂ (સૂર્યપ્રકાશ) → 2COCl₂ + 2HCl
  • C₆H₅Cl નું NaOH(જલીય) સાથે 623K અને 300 atm દબાણે પ્રક્રિયા કરાવવી પડે છે
  • હેલોએલ્કેન્સનો ક્લોરોફોર્મ બનાવવાનો પ્રશ્ન ઘણીવાર ચૂકવાય છે — આપણે ત્રણ પગલાંની પ્રક્રિયા શીખવી
  • gem-dihalide માંથી alkyn બનાવવા માટે NaNH₂ (liquid NH₃) અથવા alc. KOH (વધુ) જોઈએ

🔥 હાઈ-યીલ્ડ મુદ્દા

  • સૌથી વધુ પ્રતિસ્થાપન વેગ: 3° હેલોએલ્કેન > 2° > 1° (SN1 માટે)
  • સૌથી વધુ SN2 પ્રતિસ્થાપન: CH₃X > 1° > 2° > 3° (ત્રિ-બંધાયુક્ટ sp³ C પર steric hindrance)
  • સૌથી વધુ પ્રતિસ્થાપન: allyl/benzyl halides (SN1 + SN2 બંને માટે)
  • ડાયઝોનિયમ પ્રક્રિયા: ArNH₂ + NaNO₂ + 2HX (0–5°C) → ArN₂⁺X⁻; આગળ CuX/SnCl₂/HBF₄ સાથે વિવિધ સંયોજન બને
  • શેલ્ફોર્મ પરીક્ષણ: CHI₃ पीतल અવક્ષેપ; આલ્કોહોલ/કિટોનની ઓળખ
  • SOCl₂ પદ્ધતિ સૌથી શ્રેષ્ઠ — ઉત્પાદન શુદ્ધ અને વ્યર્થ ગૌણ ઉત્પાદન ગેસ (SO₂, HCl) બને
  • હેલોઑરેન્સનું પ્રતિસ્થાપન અલ્પ કારણ: (i) sp²-C–X બંધ લઘુ (ii) resonance સ્થાયિત્વ (iii) carbocation બનવું અશક્ય
  • SN2 માં Nu⁻ ને બેક સાઈડથી હુમલો કરવો પડે છે → Walden inversion
  • SN1 માં carbocation મધ્યવર્તી બને છે → planar sp² → Nu⁻ ઉभयतः હુમલો કરે છે → racemization
  • વિલોપન પ્રક્રિયામાં Zaitsev નિયમ લાગુ પડે છે: વધુ વિસ્થાપિત એલ્કીન મુખ્ય ઉત્પાદન
  • હેલોએલ્કેન્સના નામકરણ: IUPAC મુજબ પ્રથમ C–X બંધ ધરાવતા C નું સ્થાન લઘુમાં લઘુ
  • પોલિહેલોજન સંયોજનો: CCl₄ (ક્લોરોપ્લાસ્ટ), CHCl₃ (ક્લોરોફોર્મ), CHI₃ (હેલોફોર્મ), CCl₂F₂ (ફ્રિઓન-12)
  • ફ્રિઓન-12 નું OH મંડળને નષ્ટ કરે છે (O₃ depletion) — આ પર્યાવરણીય મુદ્દો ગુરુત્વપૂર્ણ છે
  • हेलोकार्बनिक (Organohalogen) સંયોજનો વર્ગીકરણ: primary/secondary/tertiary તેમજ sp³/sp² hybridized C પર
  • હેલોએલ્કેન્સમાં કિરણસ્फटिकતા (Optical activity): જો C* હોય તો enantiomer મળે; આ SN2 માં પ્રતિકૂળ છે
