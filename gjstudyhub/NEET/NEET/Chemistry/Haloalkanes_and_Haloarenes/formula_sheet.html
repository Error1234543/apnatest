હેલોએલકેન અને હેલોએરિન — સૂત્ર પત્રિકા

⚡ સૂત્રો

SN2 પ્રક્રિયા દર સમીકરણ (દ્વિ-આણ્વીય ન્યુક્લિયોફિલિક સ્થાનાંતરણ): Rate = k [R−X] [Nu⁻]
k = દર અચળાંક, R−X = હેલોએલકેન, Nu⁻ = ન્યુક્લિયોફિલ · SI: mol L⁻¹ s⁻¹ · જ્યારે પ્રક્રિયા SN2 ಯંત્રવિધિ અનુસાર થાય — એકધારી, બીજ-ક્રમ
SN1 પ્રક્રિયા દર સમીકરણ (એક-આણ્વીય ન્યુક્લિયોફિલિક સ્થાનાંતરણ): Rate = k [R−X]
k = દર અચળાંક, R−X = હેલોએલકેન · SI: mol L⁻¹ s⁻¹ · જ્યારે પ્રક્રિયા SN1 ยนต์વિધિ અનુસાર થાય — પ્રથમ-ક્રમ, ન્યુક્લિયોફિલ સાંદ્રતા પર આધારિત નથી
હેલોએલકેન + KOH(જલીય) → એલ્કોહોલ (પરિવર્તન પ્રક્રિયા): R−X + KOH(aq) → R−OH + KX
R = એલ્કિલ જૂથ, X = છેદક (Cl, Br, I), aq = જલીય વેન્ટ્યુ · SI: — · જલીય KOH સાથે ઉષ્મા આપતાં હેલોએલકેનનું એલ્કોહોલમાં રૂપાંતર
હેલોએલકેન + KOH(અલ્કોહોલિક) → એલ્કીન (વિઘટન પ્રક્રિયા): R−CH₂−CH₂−X + alc.KOH → R−CH=CH₂ + KX + H₂O
alc.KOH = અલ્કોહોલિક પોટેશિયમ હાઈડ્રોક્સાઈડ, છેદક X સાથે બોન્ડિંગ कार्बनમાંથી H પણ દૂર થાય છે · SI: — · અલ્કોહોલિક KOH + ઉષ્મા મળે ત્યારે દ્વિ-બંધયુક્ત એલ્કીન બને છે
વર્ટઝ પ્રક્રિયા (બે હેલોએલકેન અણુઓનો સંયોગ): 2 R−X + 2 Na → R−R + 2 NaX
Na = સોડિયમ ધાતુ, R−R = સમમિત એલ્કેન, NaX = ત્યાંથી બનતું લવણ · SI: — · શુષ્ક ઈથરમાં Na ધાતુ સાથે પ્રક્રિયા — કાર્બન પરામાણુ સંખ્યા દ્વિગણ બને છે
ફ્રાઈડલ-ક્રાફ્ટ્સ એલ્કિલેશન (અરીન સાથે હેલોએલકેન): Ar−H + R−X →[AlCl₃] Ar−R + HX
Ar−H = બેન્ઝીન/અરીનિક સયોજન, R−X = હેલોએલકેન, AlCl₃ = લીવિસ એસિડ ઉत्प्रेરક · SI: — · અનહેડ્રેટેડ AlCl₃ ઉત્પ્રેરક સાથે અરીનિક પર એલ્કિલ જૂથ જોડાય છે
ગ્રિગ્નાર્ડ અભિધાતન (Organomagnesium halide): R−X + Mg →[શુષ્ક ઈથર] R−Mg−X
R = એલ્કિલ/અરીલ જૂથ, X = Cl/Br/I, R−Mg−X = ગ્રિગ્નાર્ડ વિધાત · SI: — · શુષ્ક ઈથર દ્રાવકમાં Mg ધાતુ સાથે પ્રક્રિયા કરતાં ગ્રિગ્નાર્ડ અભિધાત બને છે
ડિહાઈડ્રોહેલોજેનિશન — સાયટ્ઝેફનો નિયમ (એલ્કીન પ્રાથમિકતા): પ્રાથમિકતા : −CH=CH− (વધુ Hવાળા कार्बन) > −C= < (ઓછા Hવાળા कार्बन)
વધુ ઉપસ્થિત બીજાંગ જૂથ ધરાવતો কার્बન જ્યાં H ઓછા હોય તે દિશાએ Double bond રચાય છે · SI: — · એલ્કિલાઈલ હેલાઇડના વિઘટન દરમિયાન એકતા-બંધિત એલ્કીન બને છે; સાયટ્ઝેફ નિયમ અનુસાર વધુ ઉપસ્થિત (substituted) એલ્કીન પ્રમાણમાં વધુ મળે છે
હેલોએલકેનમાંથી Na સાથે દ્વિ-હેલોએલકેન પ્રક્રિયા (ડાયોલિક હેલાઇડ): X−CH₂−CH₂−X + 2Na → CH₂=CH₂ + 2NaX
X = છેદક (Cl, Br, I), 1,2-ડાયહેલાઇડ સાથે Na પ્રક્રિયાથી એલ્કીન મળે છે · SI: — · 1,2-ડાયહેલોએલકેન (vicinal dihalide) સાથે Na ધાતુની પ્રક્રિયા
હેલોએલકેન + H₂/Pd → એલ્કેન (પ્રતિસ્થાપન / શમન): R−X + H₂ →[Pd/C] R−H + HX
R−X = હેલોએલકેન, Pd/C = પેલેડિયમ કાર્બન ઉત્પ્રેરક, R−H = એલ્કેન · SI: — · ઉદ્દીપક ઘટાડો (catalytic reduction) દ્વારા છેદકને H વડે બદલવામાં આવે છે
હેલોએલકેન + KCN → નાઈટ્રાઈલ (સાયનાઈડ): R−X + KCN(aq) → R−CN + KX
R−X = હેલોએલકેન, KCN = પોટેશિયમ સાયનાઈડ, R−CN = એલ્કાઈલ સાયનાઈડ/નાઈટ્રાઈલ · SI: — · જલીય KCN સાથે પ્રક્રિયા થાય છે — S_N2 પ્રકારનું પ્રતિસ્થાપન
હેલોએલકેન + AgCN → આઈસોસાયનાઈડ / નાયટ્રાઈલ: R−X + AgCN → R−NC + AgX↓
R−NC = એલ્કાઈલ આઈસોસાયનાઈડ, AgX = ચોકીદારી અવક્ષેપ · SI: — · AgCN અણુમાં સહસંયોજક બંધ હોવાથી CN સમૂહ આઈસોસાયનાઈડ આપે છે; AgX અવક્ષેપ બને છે
હેલોએલકેન + NaNO₂ (એલ્કોહોલિક) → નાયટ્રાઈટ / નાયટ્રો સયોજન: R−X + NaNO₂(alc) → R−ONO + NaX
R−ONO = એલ્કાઈલ નાયટ્રાઈટ, NaX = લવણ · SI: — · એલ્કોહોલિક સોડિયમ નાઈટ્રાઈટ સાથે પ્રક્રિયા થતાં એલ્કાઈલ નાયટ્રાઈટ બને છે
હેલોએલકેન + NaI + એસિટોન → ફ્રોન્સ પ્રક્રિયા: R−Cl/Br + NaI →[એસિટોન] R−I + NaCl/NaBr↓
R−I = એલ્કાઈલ આયોડાઈડ, NaCl/NaBr અવક્ષેપ · SI: — · ફ્રોન્સ પ્રક્રિયા — આયોડાઈડ મહાનુભાવ છેદક તરીકે Cl/Br ને બદલે છે; NaCl/NaBr અવક્ષેપિત થાય છે
હેલોએલકેન + હીટ / Zn dust → એલ્કીન (Zn-વિઘટન): R−CHBr−CH₂Br + Zn → R−CH=CH₂ + ZnBr₂
Zn = ઝિંક ધાતુ, R−CH=CH₂ = એલ્કીન, ZnBr₂ = ઝિંક બ્રોમાઈડ · SI: — · 1,2-ડાયહેલોએલકેન (vicinal dihalide) નું Zn સાથે વિઘટન થાય છે
Bredt નો નિયમ — ટૂંકું સમીકરણ: Bredt નિયમ : દ્વિબંધ નાના વલય (bicyclic) ના બ્રિજહેડ कार्बन પર રખાય નહીં
નાના બાયસાયક્લિક પદ્ધતિમાં bridgehead कार्बन પર ટ્રિપલ બંધ અશક્ય · SI: — · Bredt ના નિયમ મુજબ નાના રિંગ (bicyclo[m.n.p] σύστημα) માં દ્વિ-બંધ bridgehead પર ન રચી શકાય
હેલોએલકેન + Na (વર્ટઝ) સાથે દ્વિ-એલ્કેન રચના: R−X + R'−X + 2Na → R−R' + 2NaX (અસમમિત વર્ટઝ)
R, R' = વિભિન્ન એલ્કિલ જૂથ, R−R' = મિશ્ર એલ્કેન · SI: — · વિભિન્ન હેલોએલકેન મિશ્રણ સાથે વર્ટઝ પ્રક્રિયા થાય છે — મિશ્ર એલ્કેનનું મિશ્રણ મળે છે

🔗 સંબંધો

  • SN2 પ્રક્રિયામાં પ્રતિસ્થાપન વિપરીત ગોઠવણી (inversion of configuration) થાય છે — Walden inversion; પરિણામે R-હેલોએલકેનમાંથી S-ઉત્પાદન બને છે (અથવા વિપરીત).
  • SN1 પ્રક્રિયામાં કાર્બોકેટાયન બનવાથી racemization થાય છે — બંને સંરચના (d અને l) મળે છે.
  • હેલોએલકેનનો પ્રક્રિયાત્મક સક્રિયતા ક્રમ : RI > RBr > RCl > RF (C−X બંધ મજબૂતી RF > RCl > RBr > RI હોવાથી).
  • SN1 માં કાર્બોકેટાયન સ્થિરતા ક્રમ : 3° > 2° > 1° > CH₃⁺; આથી SN1 પ્રક્રિયાનો દર પણ આ જ ક્રમમાં હોય છે.
  • SN2 માં steric અવરોધના કારણે કાર્બનની ક્રમબદ્ધતા ઓછા થતાં દર ઘટે છે : CH₃X > 1° > 2° > 3°. 3° હેલોએલકેન SN2 માં પ્રક્રિયા કરતાં નથી.
  • ડિહાઈડ્રોહેલોજેનિશન (E2) માં પ્રબળ બેઝ (alc. KOH, NaOEt) વપરાય છે; સાયટ્ઝેફ નિયમ મુજબ વધુ-substituted એલ્કીન મુખ્ય ઉત્પાદન છે.
  • હેલોએરિન (Aryl halide) માં C−X બંધ આંશિક ડબલ બંધ લક્ષણ ધરાવે છે (resonance ને કારણે); તેથી હેલોએરિન SN પ્રક્રિયામાં ખૂબ અક્રિયાશીલ છે.
  • p-નાઈટ્રો હેલોએનિઝોલમાં −NO₂ ગ્રુપ electron-withdrawing હોવાથી C−X બંધ તૂટવામાં સહાય કરે છે; તેથી p-nitro chlorobenzene hydrolysis માં વધુ સક્રિય છે.
  • હેલોએલકેનનું ગેરમીત (boiling point) ક્રમ : RI > RBr > RCl > RF (molar mass વધવાથી van der Waals બળ વધે છે).
  • હેલોએલકેન અજળમાં અદ્રાવ્ય પરંતુ એલ્કોહોલ, ઈથર, બેન્ઝીનમાં દ્રાવ્ય છે.

🎯 ટ્રિક્સ

SN2 પ્રક્રિયામાં જો તમે કહેવું જોઈએ કે 'કઈ રચના બદલાશે?' — હંમેશા inversion (Walden) થાય છે, તેથી જવાબમાં (R) → (S) અથવા (S) → (R) લખો.
હેલોએલકેન પ્રક્રિયાત્મક ક્રમ યાદ રાખવા : 'R'I > R'Br > R'Cl' — 'I love Bombay but not Calcutta' (I > Br > Cl) એ mnemonic છે.
SN1 vs SN2 નક્કી કરવા માટેનો quick check : પ્રાથમિક (1°) = SN2, તૃતીય (3°) = SN1, મધ્યમ (2°) = બંને શક્ય — દ્રાવક અને ન્યુક્લિયોફિલ પર આધારિત.
પ્રશ્નમાં R−X + alc. KOH જોવા મળે તો વિઘટન (elimination), R−X + aq. KOH જોવા મળે તો પ્રતિસ્થાપન (substitution) યાદ રાખો.
વર્ટઝ પ્રક્રિયામાં કાર્બન સંખ્યા દ્વિગણ થાય છે — 2R−X → R−R, તેથી ઉત્પાદનના C સંખ્યા બે ગણા હોય છે; એટલે જવાબ તપાસવાનો easy trick.
ગ્રિગ્નાર્ડ અભિધાત બનાવતી વખતે ઉત્પાદનનો નિયમ : R−X + Mg → R−Mg−X, જે પાણી સાથે પ્રક્રિયા કરે તો R−H (એલ્કેન) બને છે.
ફ્રોન્સ પ્રક્રિયા : R−Cl + NaI → R−I, એટલે આયોડાઈડ બનાવવાનો સરળ રસ્તો — NaI અને એસિટોન (acetone) હંમેશા યાદ રાખો.
હેલોએરિનના પ્રતિસ્થાપન માટે ઉચ્ચ તાપમાન / દબાણ અને પ્રબળ ન્યુક્લિયોફિલ જોઈએ — સામાન્ય પરিস্থિતિમાં પ્રક્રિયા થતી નથી.

⚠️ ભૂલો

SN1 અને SN2 માં દર સમીકરણ ગૂંચવી જવું — SN2 માં Rate = k[RX][Nu], SN1 માં Rate = k[RX] (Nu સાંદ્રતા સમાવિષ્ટ નથી).
હેલોએલકેન + KOHમાં aq. vs alc. KOH સમજ્યા વિના જવાબ લખવો — aq. KOH → પ્રતિસ્થાપન (એલ્કોહોલ), alc. KOH → વિઘટન (એલ્કીન).
SN1 માં રેસેમિક્સ (racemization) થાય છે તે બીજવે ભૂલી જવું — ફક્ત inversion જ હોતું નથી.
હેલોએરિનને સ્થાનાંતર પ્રક્રિયામાં સક્રિય માનવું — આર્લાઈલ હેલાઇડ (haloarene) SN પ્રક્રિયામાં નિષ્ક્રિય છે.
વર્ટઝ પ્રક્રિયામાં Na નો ગુણાંક 2 લખવો જરૂરી છે — 2Na ને બદલે Na લખવું ભૂલ છે.
હેલોએલકેનનું ગેરમીત (bp) ક્રમ ભૂલવા — RI નું bp વધુ હોય છે કારણે તેનું molar mass વધુ છે.
AgCN થી મળતું ઉત્પાદન NaCN થી અલગ છે એ ભૂલી જવું — AgCN માં સહસંયોજક બંધ હોવાથી R−NC (આઈસોસાયનાઈડ) બને છે, R−CN નહીં.
SAYTZEFF નિયમનો ઉપયોગ E2 વિઘટનમાં કરવો જોઈએ, SN પ્રક્રિયામાં નહીં — આ બે અલગ પ્રક્રિયાઓ છે.
3° હેલોએલકેન SN2 માં પ્રક્રિયા કરે છે એવી ભૂલ — 3° કાર્બન પર steric અવરોધ હોવાથી SN2 થતું નથી.
હેલોએલકેન + Na NO₂ માં NaO-N (સોડિયમ નાયટ્રાઈટ) થી અલગ રીતે પ્રક્રિયા — NaNO₂ (alc.) માં R−ONO (નાયટ્રાઈટ) બને છે, R−NO₂ (નાયટ્રો) નહીં.
