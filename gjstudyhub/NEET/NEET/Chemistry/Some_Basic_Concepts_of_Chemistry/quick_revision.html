🧠 યાદ રાખો

1 કિ.મોલ (kmol) = 10³ mol; 1 mmol = 10⁻³ mol — એકમ રૂપાંતર ધ્યાનથી કરો.
આબોગેડ્રો સંખ્યા (Avogadro's number): N_A = 6.022 × 10²³ — દરેક ગણતરીમાં આ જ અચળાંક વપરાય છે.
મોલ = દર્શાવેલ વસ્તુમાન / મોલર દળ (mol = given mass / molar mass) — સૂત્ર હંમેશા યાદ રાખો.
STP પર 1 મોલ આદર્શ વાયુ = 22.7 L (NTA મુજબ); જૂનું 22.4 L NTP માટે — પ્રશ્નમાં શરત જુઓ.
સાર્થક અંકો (Significant figures): શૂન્યની કિસ્સાઓ ધ્યાનથી — 0.002 માં 1, 2.00 માં 3, 5.03 માં 3.
પ્રમાણભૂત પરમાણુ દળ (amu / u): 1 u = 1.6605 × 10⁻²⁷ kg = C-12 ના 1/12 ભાગના બરાબર.
સમાન પ્રમાણનો નિયમ (Gay-Lussac's law): વાયવિક પ્રક્રિયાઓમાં કદ ગુણોત્તર સાધારણ પૂર્ણાંકમાં — ઓક્સિજન + હાઇડ્રોજન = પાણી (1:2:2).
મોલર દળ = પરમાણુ દળનો સંખ્યાત્મક મૂલ્ય પણ g/mol માં — એકમ ફેરવાવાનો ભૂલ ન કરવી.
આણ્વીય સૂત્ર = (અભિભૂમિત સૂત્ર)_n — n = આણ્વીય દળ / અભિભૂમિત દળ; સંપૂર્ણ પૂર્ણાંક આવવો જોઈએ.

⚡ ઝડપી સૂત્રો

મોલ = પરમાણુ/અણુ સંખ્યા / N_A = દળ / મોલર દળ = STP પર કદ / 22.7 L
ટકાવાર ચડાવણી (%) = (તત્વનું દળ / બંધારણના કુલ દળ) × 100
અભિભૂમિત સૂત્ર શોધ: તત્વના % → mol → સાધારણ ગુણોત્તર → પૂર્ણાંક ગુણોત્તર
મોલારિટી (M) = દ્રાવ્યના મોલ / દ્રાવણનું કદ (L) — તાપમાન પર આધારિત.
મોલલિટી (m) = દ્રાવ્યના મોલ / દ્રાવકનું દળ (kg) — તાપમાનથી સ્વતંત્ર, વધુ સ્થિર.
મોલ ભિન્નતા (χ_B) = B ના મોલ / કુલ મોલ — તમામ ભિન્નતાનો સરવાળો = 1.
ટકાવજન (Mass %) = (બંધારણમાં તત્વનું દળ / આણ્વીય દળ) × 100
સ્ટોઇકિઓમેટ્રી: aA + bB → cC; A ના મોલ / a = B ના મોલ / b (સાધારણ ગુણોત્તર).

✅ વન-લાઈનર્સ

અભિમાન્ય ગરજ (Law of Conservation of Mass): લાવોઝિયર — પ્રક્રિયા પહેલાં અને પછી કુલ દળ સમાન.
અચળ ઘટક (Law of Constant Proportion): પ્રોસ્ટ — દરેક સંયોજનમાં તત્વોનું દળ ગુણોત્તર સદા સમાન.
બહુગણી ગરજ (Law of Multiple Proportions): ડલ્ટન — એક જ તત્વોના બે કે વધુ સંયોજનમાં બીજા તત્વનું દળ ગુણોત્તર સાધારણ પૂર્ણાંકમાં.
સમાન પ્રમાણનો નિયમ: વાયુઓના કદ સાધારણ પૂર્ણાંક ગુણોત્તરમાં — ઉદા. H₂ અને O₂ થી H₂O.
મિશ્રિત ગરજ (Reciprocal Proportions): રિટબર્ગ — બે તત્વ અલગ અલગ તૃતીય તત્વ સાથે જોડાય તેમનું દળ ગુણોત્તર એકબીજા સાથે જોડાણમાં પણ સાધારણ ગુણોત્તરમાં.
મોલર કદ (Molar volume): STP પર આદર્શ વાયુ = 22.7 dm³/L — સાંદ્રતા ગણતરીમાં કામ આવે છે.
સીમિત પ્રતિકારક (Limiting Reagent): જે વિક્રિયક સૌથી પહેલાં ખતમ થાય; ઉત્પાદનનો આધાર તે પર જ.
જુદા જુદા સાંદ્રતા એકમ: Molarity (મોલ/L), Molality (મોલ/kg), Normality (સમકક્ષ/L), mole fraction.
જટિલ રચના (Compound) અને મિશ્રણ (Mixture) વચ્ચેનો મુખ્ય તફાવત: મિશ્રણમાં ઘટકોનું દળ ગુણોત્તર ચડાવણી સ્વતંત્ર.
પરમાણુ દળ (Atomic mass) અને ભારે પદાર્થ દળ (Molecular mass): બંને amu/ Dalton માં, g/mol માં સંખ્યાત્મક રૂપમાં સમાન.
