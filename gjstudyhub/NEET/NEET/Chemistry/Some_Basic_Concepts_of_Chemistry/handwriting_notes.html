કેમિસ્ટ્રી : કેટલાક મૂળભૂત ખ્યાલો (Some Basic Concepts of Chemistry)

🩺 NEET UG — Gujarati • Chemistry • Some Basic Concepts of Chemistry

📌 પ્રકરણ ૧ : કેટલાક મૂળભૂત ખ્યાલો
દ્રવ્ય (Matter) એટલે જે વસ્તુ દળ અને ઘનફળ ધરાવતી હોય અને જગ્યા લેતી હોય.
દ્રવ્યશુદ્ધ પદાર્થો અને મિશ્રણોમાં વિભાજીત થાય છે
શુદ્ધ પદાર્થો (Pure Substances) : નિશ્ચિત રાસાયણિક રચના ધરાવતા પદાર્થો.
શુદ્ધ પદાર્થો બે પ્રકારના : તત્વો (Elements) અને સંયોગો (Compounds).
તત્વો : એક પ્રકારના પરમાણુઓનું બનેલું, જે રાસાયણિક પ્રક્રિયાથી સાદા પદાર્થોમાં તોડી શકાય નહીં.
સંયોગો : બે કે વધુ તત્વો નિશ્ચિત દળ પ્રમાણે જોડાયેલા હોય છે.
મિશ્રણો (Mixtures) : બે કે વધુ શુદ્ધ પદાર્થો ભૌતિક રીતે મિશ્ર થયેલા હોય છે.
📝 💡 મિશ્રણની રચના ચલ (variable) હોઈ શકે છે.
એકરૂપી મિશ્રણ (Homogeneous) : સંયોજનોનું સમાન વિતરણ, જો અંતરે પણ એકસરખું દેખાય.
વિષમરૂપી મિશ્રણ (Heterogeneous) : અંતરે ભિન્ન ભાગ દેખાય, જેમ કે રેતી-કાણું.
⚖️ રાસાયણિક સંયોજનોના નિયમો (Laws of Chemical Combination)
૧. દળ અનાવર્તનનો નિયમ (Law of Conservation of Mass) — લેવોઝિએ (Lavoisier, 1789) દર્શાવ્યો.
પ્રક્રિયકોનું કુલ દળ = ઉત્પાદોનું કુલ દળ
ઉદા. : H₂ + O₂ → H₂O માં પ્રક્રિયકોનું દળ ઉત્પાદનાના દળ બરાબર.
📝 💡 આ નિયમ ન્યુક્લિયર પ્રક્રિયાઓમાં લાગુ પડતો નથી.
૨. સ્થિર આપેક પ્રમાણનો નિયમ (Law of Definite Proportions) — પ્રોસ્ત (Proust, 1799).
કોઈ પણ શુદ્ધ સંયોગમાં તત્વો નિશ્ચિત દળ પ્રમાણે જ હોય છે.
ઉદા. : H₂O માં H અને O નું દળ પ્રમાણ સતત 1:8 હોય છે.
૩. બહુગુણી આપેક પ્રમાણનો નિયમ (Law of Multiple Proportions) — ડાલ્ટન (1803).
જ્યારે બે તત્વ A અને B બે સંયોગમાં જોડાય, તો B ના દળોનું સરળ પૂર્ણાંક ગુણોત્તર મળે.
ઉદા. : CO અને CO₂ માં C ના સમાન દળ સાથે O નું દળ પ્રમાણ 1 : 2 છે.
૪. પરસ્પર આપેક પ્રમાણનો નિયમ (Law of Reciprocal Proportions) — રોહર (Richter, 1792).
જો તત્વ A તત્વ B સાથે અને તત્વ C સાથે જોડાય, તો B અને C ના જોડાણનું પ્રમાણ સરળ હોય.
૫. ગે-લુસાકનો વાયુઓના ઘનફળનો નિયમ (Gay Lussac's Law of Gaseous Volumes).
વાયુ પ્રક્રિયામાં પ્રક્રિયકો અને ઉત્પાદોના ઘનફળોનું પ્રમાણ સરળ પૂર્ણાંક ગુણોત્તરમાં હોય.
N₂ + 3H₂ → 2NH₃ : ઘનફળ પ્રમાણ 1 : 3 : 2
⚛️ ડાલ્ટનનો પરમાણુ સિદ્ધાંત (Dalton's Atomic Theory)
ડાલ્ટને 1808 માં પરમાણુ સિદ્ધાંત આપ્યો.
માન્યતાઓ : (૧) દ્રવ્ય પરમાણુઓનું બનેલું છે. (૨) એક તત્વના તમામ પરમાણુ સમાન હોય.
(૩) રાસાયણિક પ્રક્રિયામાં પરમાણુનું સર્જન અથવા નાશ થતો નથી.
(૪) વિવિધ તત્વોના પરમાણુઓ ভિન્ન હોય.
(૫) સંયોગ બને ત્યારે પરમાણુઓ નિશ્ચિત ગુણોત્તરમાં જોડાય.
📝 💡 આધુનિક વિજ્ઞાન મુજબ કેટલીક માન્યતાઓ સુધારાઈ છે, પણ મૂળ ખ્યાલ મહત્વપૂર્ણ છે.
🔬 પરમાણ્વીય અને અણ્વીય દળ (Atomic & Molecular Masses)
C-12 આઇસોટોપના એક પરમાણુના દળના 1/12 ભાગને પરમાણ્વીય દળ એકમ (amu/u) કહે છે.
1 u = 1.6605 × 10⁻²⁷ kg
આણ્વીય દળ (Molecular Mass) : એક અણુમાં રહેલા તમામ પરમાણુઓના દળનો સરવાળો.
H₂O નું આણ્વીય દળ = 2(1) + 16 = 18 u
સૂત્ર દળ (Formula Mass) : આયનીય સંયોગો માટે એકમ કોષ (unit cell) ના દળનો સરવાળો.
ઉદા. : NaCl નું સૂત્ર દળ = 23 + 35.5 = 58.5 u
🔄 આઇસોટોપ (Isotopes)
સમાન પરમાણ્વીય ક્રમાંક પણ ભિન્ન દળાંક ધરાવતા પરમાણુઓ આઇસોટોપ છે.
ઉદા. : હાઈડ્રોજનના ત્રણ આઇસોટોપ : પ્રોટિયમ (¹H), ડ્યુટેરિયમ (²H), ટ્રિટિયમ (³H).
કાર્બનના આઇસોટોપ : ¹²C અને ¹⁴C.
સરેરાશ પરમાણ્વીય દળ = (આઇસોટોપનું દળ × તેની પ્રમાણ) નો સરવાળો.
🧮 મોલની ભાવના (The Concept of Mole)
1 મોલ = 6.022 × 10²³ કણો (એવોગેડ્રો આંક Na)
મોલ = આપેલ દળ / મોલર દળ
n = m / M (n = મોલ, m = દળ g માં, M = મોલર દળ g/mol માં)
1 mol H₂ → 2 g ; 1 mol O₂ → 32 g ; 1 mol H₂O → 18 g
વાયુઓ માટે STP (0°C, 1 atm) પર 1 મોલ વાયુનું ઘનફળ = 22.4 L
n = V(લિ.) / 22.4 (STP પર)
એવોગેડ્રો કાયદો : સમાન તાપમાન અને દબાણે સમાન ઘનફળમાં સમાન સંખ્યામાં અણુઓ હોય.
📝 💡 STP = Standard Temperature and Pressure
📊 ટકાવારી રચના (Percentage Composition)
તત્વનું ટકાવારી ઘટક = (તત્વનું કુલ દળ / સંયોગનું મોલર દળ) × 100
ઉદા. : H₂O માં H નું ટકાવારી ઘટક = (2/18) × 100 = 11.11%
O નું ટકાવારી ઘટક = (16/18) × 100 = 88.89%
📐 સંખ્યાત્મક અને આણ્વીય સૂત્ર (Empirical & Molecular Formula)
સંખ્યાત્મક સૂત્ર (Empirical Formula) : સંયોગમાં તત્વોનું સરળતમ પૂર્ણાંક ગુણોત્તર દર્શાવતું સૂત્ર.
આણ્વીય સૂત્ર (Molecular Formula) : એક અણુમાં રહેલા વાસ્તવિક પરમાણુઓની સંખ્યા.
આણ્વીય સૂત્ર = n × સંખ્યાત્મક સૂત્ર, જ્યાં n = આણ્વીય દળ / સંખ્યાત્મક સૂત્ર દળ
ઉદા. : ગ્લુકોઝ — સંખ્યાત્મક સૂત્ર CH₂O, આણ્વીય સૂત્ર C₆H₁₂O₆, n = 6
⚗️ સ્ટોઇકિયોમેટ્રી (Stoichiometry)
સ્ટોઇકિયોમેટ્રી = પ્રક્રિયા સમીકરણના સંતુલિત ગુણાંકો પર આધારિત ગણતરી.
પ્રથમ : પ્રક્રિયા સમીકરણ સંતુલિત કરો.
પછી : દળ, મોલ, ઘનફળ (વાયુ) નું રૂપાંતર કરો.
વાયુ પ્રક્રિયામાં : ઘનફળ પ્રમાણ = મોલ પ્રમાણ (સમાન T,P પર).
A + 3B → 2C માં : 1 mol A → 3 mol B → 2 mol C
⚠️ પરિબળક પ્રક્રિયક (Limiting Reagent)
જે પ્રક્રિયક પ્રક્રિયામાં સૌથી પહેલાં સમાપ્ત થાય છે તેને પરિબળક પ્રક્રિયક કહે છે.
પરિબળક પ્રક્રિયક ઉત્પાદનનો ન્યૂનતમ મોલ નક્કી કરે છે.
અન્ય પ્રક્રિયકો અવશેષ (excess) તરીકે બાકી રહે છે.
પરિબળક પ્રક્રિયક શોધવા : દરેક પ્રક્રિયકના મોલ / સંતુલિત ગુણાંક, જેના મૂલ્યનું આપેલ મોલ ગુણોત્તર ન્યૂનતમ હોય તે પરિબળક છે.
ઉદા. : N₂ + 3H₂ → 2NH₃ માં જો N₂ = 1 mol, H₂ = 2 mol હોય, તો H₂ પરિબળક છે.
H₂ નો ગુણોત્તર = 2/3 ≈ 0.667, N₂ નો = 1/1 = 1.0 — ન્યૂનતમ H₂.
📝 💡 NEET માં પરિબળક પ્રક્રિયકના પ્રશ્નો પુનરાવર્તિત થાય છે — ધ્યાન રાખો.
📘 મહત્વના મૂલ્યો અને એકમો
એવોગેડ્રો અંક (Na) = 6.022 × 10²³ mol⁻¹
STP પર વાયુનું મોલર ઘનફળ = 22.4 L mol⁻¹
1 u = 1.6605 × 10⁻²⁷ kg
1 amu = 1.66 × 10⁻²⁴ g
પ્રમાણભૂત તાપમાન = 0°C (273.15 K), પ્રમાણભૂત દબાણ = 1 atm
🧠 એકમ પ્રવાહ (One-Liner Revision)
દળ અનાવર્તન → પ્રક્રિયક દળ = ઉત્પાદ દળ | સ્થિર આપેક પ્રમાણ → નિશ્ચિત દળ પ્રમાણ | બહુગુણી આપેક પ્રમાણ → સરળ ગુણોત્તર
મોલ = દળ(g)/મોલર દળ(g/mol)
જરૂરી સૂત્રો : n = m/M , n = V/22.4 , n = N/Na
n = N / Na (N = કણોની સંખ્યા, Na = એવોગેડ્રો અંક)
સંખ્યાત્મક સૂત્ર → આણ્વીય દળ શોધો → n શોધો → આણ્વીય સૂત્ર મેળવો
સ્ટોઇકિયોમેટ્રી : પ્રક્રિયા સમીકરણ → સંતુલિત કરો → મોલ ગુણોત્તર → ગણતરી
