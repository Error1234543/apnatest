p-બ્લોક મૂળદ્રવ્યો — પરિચય
p-બ્લોકનાં મૂળદ્રવ્યોમાં ઇલેક્ટ્રોનિક વિન્યાસ ns²np¹ થી ns²np⁶ હોય છે (ગ્રુપ 13 થી 18).
આ ગ્રુપમાં ધાતુઓ, અધાતુઓ અને ઉભયસ્વભાવી (metalloid) મૂળદ્રવ્યો બંને હોય છે.
NEET માટે જરૂરી: Group 13 (Boron family) અને Group 14 (Carbon family) ના રાસાયણિક ગુણધર્મો વધુ પ્રશ્નોમાંથી આવે છે.
Group 13 — બોરા પરિવાર (Boron Family)
ગ્રુપ 13 ના મૂળદ્રવ્યો: B, Al, Ga, In, Tl. બાહ્યતમ કક્ષાનો વિન્યાસ ns²np¹ છે.
સામાન્ય ઓક્સિડેશન અવસ્થા: +3. B અને Al માં +3 સ્થિર છે; Ga, In, Tl માં +1 અવસ્થા પણ જોવા મળે છે (Inert Pair Effect).
ઈલેક્ટ્રોનિક વિન્યાસ: [He] 2s²2p¹ (B), [Ne] 3s²3p¹ (Al)
આયનીકરણ એન્થાલ્પી ક્રમ: B > Tl > Al > Ga > In (અસામાન્ય ક્રમ — d- અને f-કોంટ્રાક્શનને કારણે).
બોરાન — અધાતુએલ્યુમિનિયમ — ધાતુ (Group 13 માં ધાતુ/અધાતુ વચ્ચે સીમા)
Boron (B) એ ગ્રુપ 13 નું પ્રથમ અને અવર્ગીભૂત (anomalous) મૂળદ્રવ્ય છે — તેનું પરમાણુ કદ ખૂબ લઘુ છે.
બોરાન (Boron) — વિશેષતાઓ અને ઉત્પાદન
બોરાનની ઇલેક્ટ્રોનકણાંક્ષમાતા (electronegativity) ઉચ્ચ હોય છે; તે ઇલેક્ટ્રોનનો અભાવ ધરાવતું (electron-deficient) મૂળદ્રવ્ય છે.
ઉદ્યોગમાં બોરાનનું ઉત્પાદન: B₂O₃ નું Mg વડે રિડક્શન.
B₂O₃ + 3Mg → 2B + 3MgO (ઉચ્ચ તાપમાને)
બોરાન બે સ્વરૂપે મળે છે: સ্ફટિકીય (crystalline) અને અસ્ફટિકીય (amorphous).
સ્ફટિકીય B → કાળો, કઠોર; અસ્ફટિકીય B → ભૂરો, મિઠ્ટો.
📝 NEET tip: બોરાન ધાતુ સાથે પ્રતિક્રિયા કરી બોરાઇડ્સ બનાવે છે.
બોરાનની રાસાયણિક પ્રવૃત્તિ
ઓક્સિજન સાથે: 4B + 3O₂ → 2B₂O₃ (ઉચ્ચ તાપમાને)
હેલોજન સાથે: 2B + 3Cl₂ → 2BCl₃
સિલિકા (SiO₂) સાથે: 4B + SiO₂ → 2B₂O₃ + Si (ઉચ્ચ તાપમાને)
બોરાન NaOH સાથે: 2B + 6NaOH → 2Na₃BO₃ + 3H₂ (ગરમાગરમ)
બોરાન HNO₃ સાથે પ્રતિક્રિયા કરી H₃BO₃ બનાવે છે; H₂SO₄ અને HCl સાથે સાધારણ તાપમાને પ્રતિક્રિયા નથી કરતું.
બોરિક અમ્લ (Boric Acid — H₃BO₃)
બોરિક અમ્લ મળે છે: Borax હીટ કરીને કે B₂O₃ ને H₂O સાથે ગરમાવ્યા બાદ.
Na₂B₄O₇ + 2HCl + 5H₂O → 2NaCl + 4H₃BO₃
B₂O₃ + 3H₂O → 2H₃BO₃
ગરમાવતા H₃BO₃ → metaphosphoric acid ને બદલે metaboric acid (HBO₂) અને અંતે boric anhydride (B₂O₃) મળે છે.
H₃BO₃ (100°C) → HBO₂ + H₂O
HBO₂ (160°C) → H₂B₄O₇ → B₂O₃ + H₂O
H₃BO₃ એ weak monobasic Lewis acid છે; OH⁻ આપીને [B(OH)₄]⁻ બનાવે છે.
H₃BO₃ + H₂O ⇌ [B(OH)₄]⁻ + H⁺
📝 NEET tip: બોરિક અમ્લની વાપરશ ઐન્દ્રિયિક દવા (antiseptic) તરીકે થાય છે.
બોરેક્સ (Borax — Na₂B₄O₇·10H₂O)
બોરેક્સનું સૂત્ર: Na₂B₄O₇·10H₂O અથવા Na₂[B₄O₅(OH)₄]·8H₂O.
જલીય દ્રાવણમાં બોરેક્સ alkaline હોય છે —因为它水解产生 NaOH અને boric acid.
Na₂B₄O₇ + 7H₂O → 2NaOH + 4H₃BO₃
બોરેક્સ bead test: Cu²⁺ સાથે Cu(BO₂)₂ (نيle_blue bead); Cr³⁺ સાથે Cr(BO₂)₃ (green bead) બનાવે છે.
📝 COT Bead Test → Group 13 નો સૌથી મહત્વનો પ્રયોગ — NEET માં યાદ રાખો.
ડાઈબોરેન (Diborane — B₂H₆)
B₂H₆ એ electron-deficient સંયોજન છે; તેમાં 3 સાધારણ 2c–2e bonds અને 2 3c–2e (banana/bridge) bonds હોય છે.
2NaBH₄ + I₂ → B₂H₆ + 2NaI + H₂ (ether માં)
B₂H₆ + 6H₂O → 2H₃BO₃ + 6H₂
B₂H₆ + 3O₂ → 2B₂O₃ + 3H₂O (અત્યંત exothermic)
B₂H₆ નું structure: BH₂ બ્રિજ અને બે B-H-B 3c-2e બંધ. બંધ લંબાઈ અસમાન હોય છે (terminal vs bridge Hdifferent).
📝 NEET tip: B₂H₆ è pyrophoric છે (هواમાં self-ignites).
બોરોનના અન્ય મહત્વના સંયોજનો
બોરોન ટ્રાઇક્લોરાઇડ (BCl₃): B + Cl₂ → BCl₃ (ઉચ્ચ તાપમાને).
BCl₃ + 3H₂O → H₃BO₃ + 3HCl (hydrolysis readily occurs)
BF₃ એ strong Lewis acid છે — ફ્લોરીનની ઇલેક્ટ્રોનકણાંક્ષમાતા ઊંચી હોવાથી π-back bonding થાય છે.
BF₃ માં B-F બંધ લંબાઈ σ-only મودલ કરતા ટૂંકી છે — sp² hybridization અને pπ-pπ back bonding.
એલ્યુમિનિયમ (Aluminium) — ગુણધર્મો અને સંયોજનો
એલ્યુમિનિયમ: ચાંદી જેવો ચમકદાર, હલકો, corrosion-resistant (passivation by Al₂O₃ film).
2Al + Fe₂O₃ → Al₂O₃ + 2Fe (Thermite reaction — અત્યંત exothermic)
Al ધન હાઇડ્રોક્સાઇડ (NaOH) સાથે પ્રતિક્રિયા કરી Na[Al(OH)₄] અને H₂ બનાવે છે.
2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂
Al amphoteric છે — it dissolves in both acids and bases.
એલ્યુમિનિયમના સંયોજનો
એલ્યુમિનિયમ ક્લોરાઇડ (AlCl₃): Lewis acid, dimeric (Al₂Cl₆) vapour માં; Al сп³ hybridization.
Al₂O₃ + 3C + 3Cl₂ → 2AlCl₃ + 3CO (उच्च ताप पर)
Alum (પોટાશ ઍલમ): K₂SO₄·Al₂(SO₄)₃·24H₂O — મહત્વનો double salt.
K₂SO₄ + Al₂(SO₄)₃ + 24H₂O → K₂Al₂(SO₄)₄·24H₂O
NaAlH₄ (સોડિયમ અલ્યુમિનિયમ હાઇડ્રોક્સાઇડ) complex hydride છે — reducing agent તરીકે વપરાય છે.
Group 14 — કાર્બન પરિવાર (Carbon Family)
ગ્રુપ 14 ના મૂળદ્રવ્યો: C, Si, Ge, Sn, Pb. વિન્યાસ: ns²np² (4 valence electrons).
સામાન્ય ઓક્સિડેશન અવસ્થા: +4 અને +2. Hg, Tl જેમ +2 અવસ્થા સ્થિર બને છે (Inert Pair Effect વધુ પ્રબળ).
ઇલેક્ટ્રોનિક વિન્યાસ: C [He] 2s²2p², Si [Ne] 3s²3p²
ઇલેક્ટ્રોનકણાંક્ષમાતા C થી Pb તરફ ઘટે છે.
C, Si → non-metals / metalloidsGe, Sn, Pb → metals
Catenaation property: C > Si > Ge > Sn > Pb. કાર્બન सबसे अधिक catenaation दर्शाता है (C-C bond strong).
કાર્બન (Carbon) — સ્વરૂપો અને ગુણધર્મો
કાર્બન બે allotropes માં મળે છે: ગ્રાફાઇટ (soft, conductor) અને વજરા (hardest natural substance, insulator).
ગ્રાફાઇટ: sp² hybridization, planar layers, weak van der Waals forces between layers.
વજરા: sp³ hybridization, tetrahedral network, 3D structure.
C (graphite) → C (diamond) उच्च दाब और ताप पर (industrial process)
C का जलने पर: C + O₂ → CO₂ (पूर्ण दहन); अ incomplète combustion में CO बनता है.
કાર્બન મોનોક્સાઇડ (Carbon Monoxide — CO)
CO મળે છે: C + O₂ (અપૂરતું) → 2CO; કે C + H₂O (steam) → CO + H₂ (water gas).
C + H₂O → CO + H₂ (1000°C, water-gas reaction)
Fe₂O₃ + 3CO → 2Fe + 3CO₂ (blast furnace માં iron extraction)
CO è diamagnetic; C≡O triple bond (एक sigma, दो pi). sp hybridization.
કાર્બન ડાયોક્સાઇડ (CO₂)
CO₂ એ linear molecule છે (sp hybridization, O=C=O), non-polar.
CaCO₃ → CaO + CO₂ (heat — thermal decomposition)
C + O₂ → CO₂ (complete combustion)
CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O (lime water test — milky)
excess CO₂: CaCO₃ + H₂O + CO₂ → Ca(HCO₃)₂ (澄清)
CO₂ greenhouse gas છે; Dry ice (solid CO₂) at -78.5°C sublimates.
સિલિકાન (Silicon — Si) — ગુણધર્મો
સિલિકાન semiconductor છે; જૈવિક રીતે Si-O bond बहुत स्थिर (biological importance in plants).
Si + 2Cl₂ → SiCl₄ (heat)
SiCl₄ + 2H₂O → SiO₂ + 4HCl (hydrolysis)
SiO₂ (silica) è quartz, sand main component. Si-O bond strength उच्च (~460 kJ/mol).
Si è also forms silanes (SinH2n+2), but less stable than alkanes — Si-Si bond weaker than C-C.
સિલિકા અને સિલિકેટ્સ
સિલિકા (SiO₂) weak acid છે; bases સાથે silicate બનાવે છે.
SiO₂ + 2NaOH → Na₂SiO₃ + H₂O (fusion)
Sodium silicate (Na₂SiO₃) è water glass; silica gel (SiO₂·nH₂O)干燥剂 છે.
Zeolites (Na₁₂[(AlO₂)₁₂(SiO₂)₁₂]·27H₂O) — microporous aluminosilicates, used as catalysts and ion-exchangers.
Zeolites è shape-selective catalysis માટે प्रसिद्ध; detergent industry માં hard water去除કારક તરીકે વપરાય છે.
મોનોસિલેન (Monosilane — SiH₄)
SiH₄ è silane; Mg₂Si + 4HCl → SiH₄ + 2MgCl₂.
Mg₂Si + 4HCl → SiH₄ + 2MgCl₂
SiH₄ è pyrophoric — air میں spontaneously burns.
SiH₄ + 2O₂ → SiO₂ + 2H₂O
SiH₄ è less stable than CH₄ because Si-H bond is weaker than C-H bond.
Group 13/14 — ઇનર્ટ પેર ઇફેક્ટ (Inert Pair Effect)
Inert Pair Effect: n s² electrons participate کم થાય છે heavy elements માં → lower oxidation state стабил हो जाता है.
Tl (+1) è more stable than Tl (+3); Pb (+2) è more stable than Pb (+4).
Tl⁺ è più stabile di Tl³⁺; Pb²⁺ è più stabile di Pb⁴⁺
NEET tip: Inert Pair Effect è relativistic stabilization of s-electrons due to poor shielding by d/f electrons.
📝 Group 13: +1 stability increases down the group (Tl⁺ > In⁺ > Ga⁺ > Al⁺ > B⁺).
