🎯 પરીક્ષા ટ્રિક્સ

Ellingham આલેખમાં રેખાનો ઢાળ θ મળવાના બિંદુએ (ઘન→દ્રવ, દ્રવ→વાયુ) બદલાય છે — ઢાળ વધારે ત્રણ કરતાં ખૂબ જ જડ (કઠોર) બને છે. આ બિંદુ ધાતુના દ્રવણબિંદુ અને ઉત્કલનબિંદુ સૂચવે છે.
જ્યારે પ્રશ્નમાં θ તાપમાને ΔG vs θ આલેખમાં રેખાના ઢાળમાં અચાનક ફેરફાર વિશે પૂછવામાં આવે.
દા.ત.: Fe → Fe(l) થાય ત્યારે ΔS ઘટે છે, તેથી C/O રેખાનો ઢાળ બદલાય — આલેખમાં એવી જ રીતે Cr/Cr₂O₃ પણ સમાન વર્તન દર્શાવે.
કોબાલ્ટ (C) ની બાર (C + O₂ → CO₂) રેખા આડી (ડિફલ્ટ) હોય છે; પરંતુ C + ½O₂ → CO રેખા નકારાત્મક ઢાળ ધરાવે છે અને ઊંચા θ (≈700°C) પછી Ne, Ca, Mg, Al જેવી ધાતુઓના ઓક્સાઇડનો માર્ગ કાપે છે.
કયા ઓક્સાઇડને C વડે રિડક્શન કરી શકાય તેનો પ્રશ્ન આવે ત્યારે.
દા.ત.: Al₂O₃ ની રેખાની ઉપર CO ની રેખા ઊંચા θ તરફ હજુ પણ ઉપર રહે છે → Al₂O₃ ને C વડે રિડ્યુસ કરી શકાતું નથી (NEET માં અકસ્માત).
કોઈપણ ધાતુના ઓક્સાઇડનું CO વડે રિડક્શન શક્ય છે જો એ ધાતુ/ધાતુ-ઓક્સાઇડ રેખા CO રેખાની ઉપર હોય. ઊંચા θ વધારે ઓક્સાઇડ રિડ્યુસ કરી શકાય.
"બહુ ઉચ્ચ તાપમાને કયો ધાતુ ઓક્સાઇડ રિડ્યુસ કરી શકાય?" જેવા પ્રશ્નોમાં.
દા.ત.: ZnO ની રેખા CO રેખાની ઉપર છે, તેથી ZnO ને CO વડે રિડ્યુસ કરી શકાય; MgO ની રેખા અત્યંત નીચે છે → MgO → Mg બની શકતું નથી.
થર્મોડાયનેમિક્સ → ΔG = ΔH − TΔS. જ્યાં ΔG = 0 હોય ત્યાં θ = ΔH/ΔS (રિડક્શન શરૂ થાય તેનું લઘુત્તમ θ). બે રેખાઓ જ્યાં છેદે છે ત્યાં એક ધાતુ બીજા ધાતુના ઓક્સાઇડનું રિડક્શન કરે.
ધાતુ રિડક્શનનો ન્યૂનતમ તાપમાન કે કયા ધાતુ કયો ઓક્સાઇડ રિડ્યુસ કરે તે પૂછતાં.
દા.ત.: C/Cr₂O₃ રેખાઓ આપસમાં છેદે છે → 1270 K તરફ θ = ΔH/ΔS ≈ 1270 K; આ તાપમાનેથી ઉપર C, Cr₂O₃ ને રિડ્યુસ કરે.
ક્રાઉડોર (cryolite, Na₃AlF₆) બે કાર્ય કરે છે: (૧) Al₂O₃ નું દ્રવણબિંદુ ≈ 2323 K થી ઘટાડી ≈ 1140 K કરે, (૨) વીજવાહકતા વધારે. આમ વિદ્યુતવીજભાર (એલિમેન્ટરી) ખર્ચ ઘટે.
હૉલ-હેરોલ્ટ (Hall–Héroult) પ્રક્રિયામાં cryolite ની ભૂમિકા પૂછવામાં આવે.
દા.ત.: NEET માં પૂછાય: "આલ્યુમિનિયમ ઉત્પાદનમાં cryolite નો ઉપયોગ કેમ?" → દ્રવણબિંદુ ઘટાડવા + વીજવાહકતા વધારવા.
બ્લાસ્ટ ફર્નેસમાં મુખ્ય રિડ્યુસિંગ કારક CO છે (C નહીં). Fe₂O₃ → Fe₃O₄ → FeO → Fe એ કાદવી (stepwise) રીતે CO વડે રિડ્યુસ થાય છે. 900–1500 K મધ્યમાં આ પ્રક્રિયા મુખ્યત્વે ચાલે છે.
જ્યારે "કયો કારક લોહ (Fe) નું રિડક્શન કરે?" અથવા ફર્નેસમાં વિવિધ પ્રદેશોના તાપમાન વિશે પૂછવામાં આવે.
દા.ત.: C + O₂ → CO₂, પછી CO₂ + C → 2CO; એવું કરીને CO જ Fe₂O₃ નો રિડક્શન કરે છે. (C સીધું નહીં.)
ગલન (liquation) — મોટે ધાતુના ઓક્સાઇડ/અશુદ્ધિથી અલગ પડે તે માટે ધાતુનું ગલનબિંદુ ઓછું હોવું જોઈએ. Sn, Pb, Bi એના ઓછા ગલનબિંદુવાળા ધાતુઓ છે.
"કઈ પદ્ધતિ કયા ધાતુ માટે?" એવા પ્રશ્નોમાં. ગલનબિંદુનો તફાવત સાપેક્ષ છે.
દા.ત.: Sn (93 K, ગલનબિંદુ) અને Pb (600 K) માટે ગલન પદ્ધતિ લાગુ; Al (2343 K) કે Fe (1811 K) માટે નહીં.
વન-આર્કેલ (Van Arkel) પદ્ધતિ → અસ્થિર કોમ્પ્લેક્સ (halide) બનાવે + ઓળખાણ/ગરમ ફિલામેન્ટ પર તેનું વિઘટન. Ti, Zr, Hf, Th, U જેવા ઉચ્ચશુદ્ધિ ધાતુઓ માટે.
"ઉચ્ચ શુદ્ધિ પ્રાપ્તિ કેવી રીતે?" પૂછાય ત્યારે ધ્યાનમાં રાખો.
દા.ત.: Ti + 2I₂ → TiI₄ (અસ્થિર); TiI₄ → Ti (纯) + 2I₂ (ગરમ ફિલામેન્ટ પર, ≈1800 K).
મુંડ (Mond) પદ્ધતિ → Ni + 4CO → Ni(CO)₄ (અસ્થિર, 350 K); Ni(CO)₄ → Ni (纯) + 4CO (450 K). બધી અશુદ્ધિઓ અવશેષમાં રહે છે.
જ્યારે "નિકલ શુદ્ધિકરણ" કે "કમ્પ્લેક્સ રિડક્શન" વિશે પૂછવામાં આવે.
દા.ત.: NEET માં પૂછાય: Ni શુદ્ધિકરણની પદ્ધતિ? → મુંડ પ્રક્રિયા (Ni(CO)₄ નું વિઘટન).
વિદ્યુતશુદ્ધિકરણ (electrolytic refining) માં અશુદ્ધ ધાતુ એનોડ + શુદ્ધ ધાતુ કેathode. ઓક્સાઇડ/સલ્ફાઇડ અશુદ્ધિઓ → મૌલ્ય (anode mud). સામાન્ય તત્વો: Cu, Ag, Au.
અશુદ્ધ ધાતુના વિદ્યુતશુદ્ધિકરણ પ્રશ્નોમાં.
દા.ત.: Cu નું વિદ્યુતશુદ્ધિકરણ: બિંદુઓ (Fe, Zn, Ni) ઓક્સિડેશન પામીને વિદ્યુત દ્રાવણમાં જાય; Ag, Au અવશેષ તરીકે રહે.
ઉત્કલનશુદ્ધિકરણ (fractional distillation) — ધાતુઓના ઉત્કલનબિંદુમાં મોટો તફાવત હોય ત્યારે; ઝિંક (Zn) નો ઉત્કલનબિંદુ ઓછો છે, તેથી Zn વરાળ રૂપે બહાર નીકળે અને અલગ કરી શકાય.
"કઈ ધાતુના ઉત્કલનબિંદુના તફાવતથી શુદ્ધ કરાય?" એવા પ્રશ્નોમાં.
દા.ત.: Zn નો ઉત્કલનબિંદુ (≈907°C) એ ZnO + C ના રિડક્શન પ્રક્રિયા દરમિયાન Zn વરાળ બને છે, તેથી વિદ્યુતશુદ્ધિકરણ માટે વપરાય.
કોર્સ (correction) → પ્રોટીન/ઑક્સાઇડ/સલ્ફાઇડ વચ્ચે તફાવત: ગેલેના (PbS) → રોસ્ટિંગ (હવા + ઊંચું θ) → PbO/PbSO₄ → ફર્નેસમાં રિડક્શન. આ પ્રક્રિયા Zn, Pb, Cu બધામાં સમાન.
"કયા સલ્ફાઇડ ઓક્સાઇડમાં રૂપાંતરિત થાય છે?" પ્રશ્નોમાં.
દા.ત.: 2ZnS + 3O₂ → 2ZnO + 2SO₂ (રોસ્ટિંગ); ZnO + C → Zn + CO (રિડક્શન).
ક્ષારક (flux) નો ઉપયોગ: (૧) અશુદ્ધિઓ સાથે પ્રતિક્રિયા કરી સરળ ઓગળતો સ્લગ બનાવવો, (૨) ઓગળતું તાપમાન ઘટાડવું. સિલિકા (SiO₂) → પ્રોટિક્સ (Basic) અશુદ્ધિઓ માટે; કાઇલાઇટ (CaF₂) → એસિડિક અશુદ્ધિઓ માટે.
ક્ષારકના પ્રકાર અને તેનો ઉપયોગ પૂછતાં પ્રશ્નોમાં.
દા.ત.: બ્લાસ્ટ ફર્નેસ: લિમેસ્ટોન (CaCO₃) → CaO (ક્ષારક) + SiO₂ અશુદ્ધિ સાથે CaSiO₃ (સ્લગ). SiO₂ પ્રોટિક્સ અશુદ્ધિ છે → ક્ષારક બનાવે છે.
સોડિયમ ક્લોરાઇડ → સોડિયમ ધાતુ: ક્લોરાઇડ (NaCl) નું વિદ્યુતવિભાજન (Downs cell) કરવું જોઈએ, સલ્ફેટ/ક્લાઇડ/ઓક્સાઇડ નહીં. NaCl + CaCl₂ નું મિશ્રણ (મધ્યમ દ્રવણબિંદુ).
"કયા સંયોજનનું વિદ્યુતવિભાજન કરવું?" Na, K, Mg માટે.
દા.ત.: NaCl(l) → Na(l) + ½Cl₂(g). Downs cell માં CaCl₂ યોગથી દ્રવણબિંદુ 900 K થી ઘટી ≈ 600 K થાય છે.
ઓક્સાઇડ vs કાર્બોનેટ vs સલ્ફાઇડ: (૧) કાર્બોનેટ → ગરમ કરવાથી CO₂ નીકળી ઓક્સાઇડ બને છે (કલ્સિનેશન). (૨) સલ્ફાઇડ → હવામાં ગરમ કરવાથી SO₂ + ઓક્સાઇડ (રોસ્ટિંગ). (૩) ઓક્સાઇડ → C/CO વડે રિડક્શન.
"કયો પ્રક્રિયા કયા સંયોજન માટે?" પૂછતાં NEET પ્રશ્નોમાં.
દા.ત.: ZnCO₃ → ગરમ કરો → ZnO + CO₂ (કલ્સિનેશન). ZnO → C + ગરમ કરો → Zn + CO (રિડક્શન).
