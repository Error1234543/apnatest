ઘન અવસ્થા (Solid State) — ઝડપી પુનરાવર્તન

🩺 NEET UG — Gujarati • Chemistry • Solid State

🧠 યાદ રાખો

ઘનને બે પ્રકાર: સ્ફટિકીય (Crystalline) અને અસ્ફટિકીય (Amorphous); સ્ફટિકીય ઘનમાં નિયમિત રચના, અસ્ફટિકીયમાં અવ્યવસ્થિત રચના.
એકમ કોષ (Unit Cell) એ સ્ફટિક જાળીનો (Crystal Lattice) સૌથી નાનો એકમ છે જે કોષ્ટકની સંપૂર્ણ રચના દર્શાવે છે.
સાત સ્ફટિકીય વ્યવસ્થાઓ: ઘન (Cubic), અષ્ટફલકીય (Tetragonal), ચતુષ્ફલકીય (Orthorhombic), ત્રિકલ (Monoclinic), ત્રિષક્રી (Triclinic), હેક્સાગોનલ (Hexagonal), ચતુર્ભુજી (Rhombohedral).
14 બ્રાવેસ જાળી (Bravais Lattices) છે; ઘનમાં ત્રણ પ્રકાર: સાદો (Simple), કર્ણકેન્દ્રિત (BCC), ફલકકેન્દ્રિત (FCC).
FCC એકમ કોષમાં પરમાણુઓની સંખ્યા Z = 4; BCC માં Z = 2; સાદો ઘનમાં Z = 1.
પૂર્ણતા કાર્યક્ષમતા (Packing Efficiency): સાદો ઘન 52.4%, BCC 68%, FCC/HCP 74%.
ચતુષ્ફલકીય છિદ્ર (Tetrahedral void) ની સંખ્યા = 2N, ત્રિજ્યા અનુપાત r/R = 0.225.
અષ્ટફલકીય છિદ્ર (Octahedral void) ની સંખ્યા = N, ત્રિજ્યા અનુપાત r/R = 0.414; N એ પરમાણુ સંખ્યા.
શોટકી દોષ (Schottky defect): વેકન્સી દોષ, ઘનતા ઘટે છે; NaCl જેવા સ્ફટિકોમાં જોવા મળે છે.
ફ્રેન્કલ દોષ (Frenkel defect): આયનનો સ્થાન બદલાઈ આંતરિક અંતરાળમાં ગોઠવાય; ઘનતા બદલાતી નથી; AgCl, ZnS માં.
ઇલેક્ટ્રોનિક અર્ધવાહકો: n-પ્રકાર (ઇલેક્ટ્રોન વાહક, P-type group ના dopant), p-પ્રકાર (છિદ્ર વાહક, IIIA group ના dopant).
મેગ્નેટિક ગુણધર્મો: પરેરામેગ્નેટિક (એકલું ઇલેક્ટ્રોન, ચુંબકીય ક્ષેત્ર દ્વારા નિમ્ન આકર્ષણ), ડાયમેગ્નેટિક (બધા યુગ્મિત, નિમ્ન વિકર્ષણ), ફેરોમેગ્નેટિક (પ્રબળ આકર્ષણ, સ્થાયી ચુંબક).
ડાયમેગ્નેટિક, પરેરામેગ્નેટિક, ફેરોમેગ્નેટિક પદાર્થો વચ્ચે મુખ્ય તફાવત ઇલેક્ટ્રોન વિન્યાસ અને ચુંબકીય ક્ષેત્ર પ્રતિક્રિયામાં છે.
કેલ્ક્યુલેશનમાં ρ = ZM / (a³ × Nₐ) સૂત્રનો ઉપયોગ થાય છે; a એ એકમ કોષની ધાર, M મોલર દળ, Nₐ એવોગેડ્રો અંક.

⚡ ઝડપી સૂત્રો

ઘનતા: ρ = Z × M / (a³ × Nₐ) ; એકમ kg/m³ અથવા g/cm³
FCC માટે: 4r = √2 × a ⇒ r = (√2/4)a ; BCC માટે: 3a² = 4(2r)² ; સાદો ઘન: a = 2r
ચતુષ્ફલકીય છિદ્ર: r/R = 0.225 ; અષ્ટફલકીય છિદ્ર: r/R = 0.414
તેરિંગ ગેપ (Band Gap): ઇન્સ્યુલેટર > 3 eV ; અર્ધવાહક ~ 1–3 eV ; ચાલકોનું તેરિંગ ગેપ ≈ 0
હોકસ્ટ-ડ્રેઇસર પદ્ધતિ: ઘનતાના આધારે એકમ કોષની ધાર a શોધી શકાય છે

✅ વન-લાઈનર્સ

સ્ફટિકીય ઘન દ્રવ્યના ગલનબિંદુ નિશ્ચિત હોય છે, અસ્ફટિકીય ઘન ધીમે ધીમે નરમ પડે છે.
Isostructural ઘન એવા ઘન જે એક જ પ્રકારની જાળી ધરાવતા હોય અને સમાન રચના ધરાવતા હોય.
SiO₂ એ સહસંયોજક સ્ફટિક (Covalent Crystal) છે — ચતુષ્ફલકીય રચના ધરાવે છે.
HCP અને CCP (FCC) બંનેમાં પૂર્ણતા કાર્યક્ષમતા 74% સમાન છે.
doping એ અર્ધવાહકની ચાલકતા વધારવા માટે શુદ્ધ પદાર્થમાં અશુદ્ધિ મિશ્રણ છે.
Fe₃O₄ (Magnetite) એ એક ફેરોમેગ્નેટિક પદાર્થ છે.
લેડ (Pb) અને કેલ્સિયમ ફ્લોરાઇડ (CaF₂) નું FCC એકમ કોષ છે.
NaCl માં Na⁺ અને Cl⁻ બંને FCC જાળી બનાવે છે; તેમાં શોટકી દોષ જોવા મળે છે.
