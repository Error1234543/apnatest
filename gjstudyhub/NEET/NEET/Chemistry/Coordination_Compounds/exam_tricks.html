સંકીર્ણ સંયોજનો (Coordination Compounds) — NEET UG ગુજરાતી માટે એક્ઝામ ટ્રિક્સ

🩺 NEET UG — Gujarati • Chemistry • Coordination Compounds

🎯 પરીક્ષા ટ્રિક્સ

બ્રિજિંગ લિગન્ડની ઓળખ — જ્યારે કોઈ લિગન્ડ બે કે તેથી વધુ ધાતુ કેન્દ્રોને જોડે ત્યારે પ્રથમ 'μ-' લગાડવું. એક જ ધાતુ સાથે જોડાયેલ હોય તો μ નહિ.
નામકરણમાં જે લિગન્ડ બે ધાતુઓ વચ્ચે 'બ્રિજ' બનાવતું હોય અને પ્રશ્નમાં μ દર્શાવવાનું હોય.
દા.ત.: [Co(NH₃)₅(μ-OH)Co(NH₃)₅]⁵⁺ માં OH⁻ બંને Co કેન્દ્રોને જોડે છે → તે μ-ઓક્વો (bidentate bridging) છે.
ઓક્સિડેશન અવસ્થાનું ઝટપટ calculation: ધાતુની ઑક્સિ. અવ. = સંકીર્ણનો કુલ ચાર્જ − લિગન્ડના ચાર્જનો સરવાળો. યાદ રાખો: NH₃, H₂O, en = 0; Cl⁻, Br⁻, CN⁻, NO₂⁻, OH⁻ = −1; C₂O₄²⁻ = −2.
જ્યારે કોઈ સંકીર્ણમાં ધાતુની ઑક્સિડેશન અવસ્થા પૂછવામાં આવી હોય.
દા.ત.: [Fe(CN)₆]⁴⁻ માં: Fe + 6(−1) = −4 → Fe = +2. [Cu(NH₃)₄]²⁺ માં: Cu + 4(0) = +2 → Cu = +2.
દંતિત્વ (denticity) નું ઝટકે ઝટકે નક્કી કરવું: લિગન્ડમાં રહેલા Lone Pair ધરાવતા પરમાણુઓની ગણતરી કરો. en (Ethylene diamine) = 2, ox (Oxalate) = 2, EDTA⁴⁻ = 6, CO = 1, Cl⁻ = 1.
લિગન્ડનું દંતિત્વ કે કોઓર્ડિનેશન નંબર શોધવાનો પ્રશ્ન.
દા.ત.: EDTA⁴⁻ માં 2 N + 4 O = 6 donor atoms → hexadentate. [Co(EDTA)]⁻ માં Co નું CN = 6.
Isomerism ટ્રિક — જો સંકીર્ણમાં બેથી વધુ સમાન લિગન્ડ હોય તો Geometrical (cis/trans) શક્ય છે. [Ma₄b₂] પ્રકાર → cis-trans; [Ma₃b₃] → fac-mer. tetrahedral માં ક્યારેય geometrical isomerism નથી.
જ્યારે પૂછવામાં આવે કે કઈ સંકીર્ણ geometrical/isomerism દર્શાવે છે.
દા.ત.: [Co(NH₃)₄Cl₂]⁺ ([Ma₄b₂] પ્રકાર) → cis અને trans બંને છે. [Ni(CO)₄] (tetrahedral) → કોઈ geometrical isomerism નથી.
Optical isomerism: Δ (dextro) અને Λ (levo) ફોર્મ કોન્ફિગરેશન મેળવવા માટે બહુ-દંતિત લિગન્ડવાળા સંકીર્ણ તરફ ધ્યાન આપો. [M(en)₃]ⁿ⁺ અને cis-[M(en)₂a₂]ⁿ⁺ Optical active છે. Trans-[M(en)₂a₂] અને [Ma₃b₃] (fac) Optically inactive છે.
પ્રશ્નમાં કયું સંકીર્ણ optically active છે તે પસંદ કરવાનું હોય.
દા.ત.: [Co(en)₃]³⁺ → both Δ અને Λ forms exist, optically active. [Co(en)₂Cl₂]⁺ → cis form optically active, trans form optically inactive (plane of symmetry).
Effective Atomic Number (EAN) નું Formula: EAN = Z − Oxidation state + 2 × Coordination number. EAN = પરમાણુ ક્રમાંક (noble gas) હોય તો સંકીર્ણ stable. [Fe(CN)₆]⁴⁻: EAN = 26 − 2 + 12 = 36 (stable). Ni(CO)₄: EAN = 28 − 0 + 8 = 36 (stable).
EAN અથવા સંકીર્ણની સ્થાયિત્વ તપાસવાનો પ્રશ્ન.
દા.ત.: [Co(NH₃)₆]³⁺: EAN = 27 − 3 + 12 = 36 (Ar configuration, stable). [Cu(NH₃)₄]²⁺: EAN = 29 − 2 + 8 = 35 (not noble gas, less stable).
Ambidentate લિગન્ડ: NO₂⁻ (Nitro/Nitrito), SCN⁻ (Thiocyanato/Isothiocyanato), CN⁻ (Cyano/Iso cyano), CO₃²⁻. જો પ્રશ્નમાં linkage isomerism પૂછે તો આ જ લિગન્ડ યાદ રાખો.
Linkage isomerism શોધવા અથવા અમેબિડેન્ડેટ લિગન્ડ ઓળખવા.
દા.ત.: [Co(NH₃)₅(NO₂)]²⁺ → NO₂⁻ N દ્વારા જોડાય (nitro, મૂર્ત) અથવા O દ્વારા જોડાય (nitrito, બિનમૂર્ત) → linkage isomerism.
Magnetic moment (spin-only): μ = √[n(n+2)] BM, જ્યાં n = unpaired electrons. 3d⁶ weak field (high spin) → 4 unpaired → μ = √24 ≈ 4.90 BM. 3d⁶ strong field (low spin) → 0 unpaired → diamagnetic (μ = 0).
સંકીર્ણના ચુંબકીય ગુણધર્મ અથવા magnetic moment શોધવાનો પ્રશ્ન.
દા.ત.: [Fe(H₂O)₆]²⁺: d⁶, weak field (H₂O), 4 unpaired e⁻ → μ = √24 = 4.90 BM. [Fe(CN)₆]⁴⁻: d⁶, strong field (CN⁻), 0 unpaired → diamagnetic (μ = 0).
Crystal Field Splitting order યાદ રાખવાની ટ્રિક — 'Weak to Strong': I⁻ < Br⁻ < S²⁻ < SCN⁻ < Cl⁻ < F⁻ < OH⁻ < C₂O₄²⁻ < H₂O < NCS⁻ < CH₃CN < NH₃ < en < NO₂⁻ < CN⁻ < CO. જેટલો strong field, તેટલો મોટો Δ (splitting).
Spectrochemical series નો પ્રશ્ન અથવા low-spin/high-spin નક્કી કરવા.
દા.ત.: CN⁻ strongest field ligand → large Δ → pairing occurs → low-spin complex (e.g., [Fe(CN)₆]⁴⁻ diamagnetic). I⁻ weakest → small Δ → high-spin (e.g., [FeF₆]³⁻ paramagnetic).
Square planar (dsp²) vs Tetrahedral (sp³) ભ્રમણ (confusion) ટાળવા: જો d⁸ ધાતુ (Ni²⁺, Pd²⁺, Pt²⁺, Au³⁺) + strong field ligand → square planar (diamagnetic). જો weak field → tetrahedral (paramagnetic). Pt²⁺ હંમેશા square planar.
સંકીર્ણની hybridization અને geometry નક્કી કરવી હોય.
દા.ત.: [Ni(CN)₄]²⁻: Ni²⁺ (d⁸) + CN⁻ (strong) → dsp², square planar, diamagnetic. [Ni(Cl)₄]²⁻: Ni²⁺ (d⁸) + Cl⁻ (weak) → sp³, tetrahedral, paramagnetic (2 unpaired).
coordination number ઝટકે ઓળખો: દરેક monodentate = 1, bidentate = 2, tridentate = 3, octadentate (EDTA) = 8. જો લિગન્ડ સંખ્યા અને દંતિત્વ ગુણાકાર → CN.
સંકીર્ણનું coordination number શોધવું હોય.
દા.ત.: [Cr(ox)₃]³⁻: 3 oxalate (each bidentate) → CN = 3×2 = 6. [Co(en)₂Cl₂]⁺: 2 en (×2) + 2 Cl (×1) → CN = 4 + 2 = 6.
Jørgensen–Snellius chain (Chelate effect): બહુ-દંતિત (polydentate) લિગન્ડવાળા સંકીર્ણ monodentate કરતાં વધુ stable હોય છે. Chelate ring (5- અથવા 6-membered) સૌથી stable.
સ્થાયિત્વ અથવા stabilities ranking નો પ્રશ્ન.
દા.ત.: [Co(en)₃]³⁺ > [Co(NH₃)₆]³⁺ because en forms 5-membered chelate rings → more stable (chelate effect). [Co(ox)₃]³⁻ also very stable.
IUPAC નામકરણમાં: લિગન્ડ names अalfabetical order માં લખો (પ્રોપર્ટી નહિ, prefix નથી ગણાતો). 'bis', 'tris', 'tetrakis' ત્યારે વપારો જ્યારે લિગન્ડ name જટિલ હોય (e.g., en, ox, EDTA).
સંકીર્ણનું IUPAC name લખવું અથવા પસંદગી પ્રશ્ન.
દા.ત.: [Co(en)₃]Cl₃ → Tris(ethane-1,2-diammine)cobalt(III) chloride. [Cu(NH₃)₄]SO₄ → Tetraamminecopper(II) sulphate (en જેવું નથી તેથી 'tetra' વાપરો).
Ionisation isomerism: જ્યારે counter ion અને ligand અદલાબદલી થાય. [Co(NH₃)₅Br]SO₄ ↔ [Co(NH₃)₅SO₄]Br. AgNO₃ test: વર્ણહીન [Co(NH₃)₅Br]SO₄ → white ppt of Ag₂SO₄; [Co(NH₃)₅SO₄]Br → no ppt with AgNO₃ but yellow ppt with Ag⁺.
Ionisation isomerism ઓળખવા અથવા distinguish કરવાનો પ્રશ્ન.
દા.ત.: [Pt(NH₃)₄Cl₂]Br₂ vs [Pt(NH₃)₄Br₂]Cl₂ → Ionisation isomers. First gives AgCl precipitate; second gives AgBr precipitate with AgNO₃.
Solid-state vs Solution isomerism: Hydrate (solvate) isomerism – H₂O either inside coordination sphere (violet [Cr(H₂O)₆]Cl₃) or outside as water of crystallisation (green [Cr(H₂O)₅Cl]Cl₂·H₂O). આ બંને સ્ટેટમાં અલગ રંગ.
Hydrate isomerism અને તેના ભૌતિક ગુણધર્મો (રંગ) તપાસવાનો પ્રશ્ન.
દા.ત.: [Cr(H₂O)₆]Cl₃ (violet) vs [Cr(H₂O)₅Cl]Cl₂·H₂O (blue-green) vs [Cr(H₂O)₄Cl₂]Cl·2H₂O (dark green) — same formula but different isomers.
Valence Bond Theory (VBT) ટ્રિક: Weak field ligand → outer d-orbitals (sp³d² hybridization) → high spin, outer orbital complex. Strong field ligand → inner d-orbitals (d²sp³ hybridization) → low spin, inner orbital complex. Remember: Strong field = pairing = inner (d²sp³). Weak field = no pairing = outer (sp³d²).
Hybridization type અને inner/outer orbital complex નક્કી કરવું હોય.
દા.ત.: [CoF₆]³⁻: Co³⁺ (3d⁶), F⁻ (weak) → no pairing → sp³d² (outer orbital), paramagnetic (4 unpaired). [Co(NH₃)₆]³⁺: Co³⁺ (3d⁶), NH₃ (strong for Co³⁺) → pairing occurs → d²sp³ (inner orbital), diamagnetic.
