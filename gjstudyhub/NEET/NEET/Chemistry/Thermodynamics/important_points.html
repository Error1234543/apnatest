ઉષ્માગતિશાસ્ત્ર (Thermodynamics) — મહત્વની બિંદુઓ

🩺 NEET UG — Gujarati • Chemistry • Thermodynamics

⭐ મહત્વના મુદ્દા

ઉષ્માગતિશાસ્ત્ર એ શક્તિનું રૂપાંતરણ અને ઉર્જા સંરક્ષણના નિયમોનો અભ્યાસ છે. પ્રથમ નિયમ પરથી દર્શાય છે કે ઉર્જાને સર્જી અથવા નાશ કરી શકાતી નથી, ફક્ત એક રૂપમાંથી બીજા રૂપમાં પરિવર્તિત કરી શકાય છે.
NEET માં પ્રથમ નિયમ સીધા પ્રશ્ન આવે છે; બહુવિકલ્પ અને સાધક બંને પ્રકારના.
પ્રણાલી (System), પરિસર (Surroundings) અને સીમા (Boundary) ત્રણ મૂળભૂત ભાગો છે. ખુલી પ્રણાલી (Open), બંધ પ્રણાલી (Closed) અને અલગ પ્રણાલી (Isolated) — આ ત્રણે પ્રકારો જાણવા જોઈએ.
પ્રણાલીના પ્રકારો પર સીધો પ્રશ્ન પૂછાઈ શકે છે અને ગણતરીમાં પણ મદદરૂપ થાય છે.
અવસ્થા વિધેય (State Function) એવું વિધેય કે જેનો મૂલ્ય માત્ર પ્રારંભિક અને અંતિમ અવસ્થા પર આધારિત હોય; ઉદા. ΔU, ΔH, S, G. માર્ગ વિધેય (Path Function) હિસ્તા (q) અને કાર્ય (w) જેવાં છે.
અવસ્થા વિધેય vs માર્ગ વિધેય માં તફાવત NEET નો પ્રચલિત પ્રશ્ન છે.
આંતરિક ઉર્જા (Internal Energy, U) નું સંતુલન: ΔU = q + w (ચિહ્ન સંમેલન: પ્રણાલી પર થતું કાર્ય ધન, પ્રણાલી દ્વારા થતું કાર્ય ઋણ). સમકદ (Isochoric) પ્રક્રિયામાં w = 0, તેથી ΔU = qᵥ.
ચિહ્ન સંમેલનમાં વિદ્યાર્થીઓ ભ્રમણામાં રહે છે; NEET માં ઘણા પ્રશ્ન આ ભ્રમ પરથી આવે છે.
એન્થાલ્પી (Enthalpy, H = U + PV) નું મહત્વ સમદબાણ (Isobaric) પ્રક્રિયામાં છે: ΔH = qₚ. ΔH અને ΔU વચ્ચે સંબંધ: ΔH = ΔU + Δn_g RT, જ્યાં Δn_g = વાયુમય ઉત્પાદનોના મોલ – વાયુમય પ્રક્રિયકોના મોલ.
ΔH = ΔU + Δn_g RT સૂત્ર દરેક વર્ષે NEET માં આવે છે; Δn_g શોધવું સૌથી મહત્વનું છે.
હેસનો નિયમ (Hess's Law): પ્રક્રિયાની એન્થાલ્પી બધી મધ્યવર્તી યાત્રાઓ માટે સમાન હોય છે, કારણ કે H એ અવસ્થા વિધેય છે. ઉદા. રચના (Formation), દહન (Combustion), રૂપાંતરણ (Transformation) ઉષ્માઓની ગણતરી.
હેસનો નિયમ NEET માં ધણા ગણતરી પ્રશ્નોનો આધાર છે.
સમકદ ઉષ્મા માપન (Bomb Calorimeter): સમકદ પર ΔU અને સમદબાણ પર ΔH બંને માપી શકાય છે. દહન ઉષ્મા (Heat of Combustion) ઇંધણના ગુણવત્તા માપવા માટે વપરાય છે.
બોમ્બ કેલોરીમીટર અને દહન ઉષ્મા સીધા પ્રશ્ન આવે છે.
બંધ ઉષ્મા (Bond Enthalpy): પ્રક્રિયાની એન્થાલ્પી ≈ બંધ તૂટવાની ઉષ્મા – બંધ બનવાની ઉષ્મા. ડાયેટોમિક અણુઓના વિઘટન ઉષ્મા અને બંધ ઉષ્મા વચ્ચે સંબંધ સમજવો જરૂરી છે.
બંધ ઉષ્મા પરથી ΔH શોધવાનો પ્રશ્ન NEET માં આવે છે.
માનક રચના ઉષ્મા (Standard Enthalpy of Formation, ΔfH°): એક મોલ યૌગિકના માનક અવસ્થાના તત્વોમાંથી રચાતી પ્રક્રિયાની એન્થાલ્પી. મૂળભૂત તત્વોની ΔfH° = 0 લેવાય છે.
પ્રક્રિયાની ΔH° ગણતરી માટે ΔfH° નો ઉપયોગ થાય છે — NEET માં બહુ મહત્વનું.
કિર્ચહોફનું સમીકરણ (Kirchhoff's Equation): ΔH(T₂) = ΔH(T₁) + ∫ΔCp dT. જો ΔCp અચળ હોય, તો ΔH(T₂) = ΔH(T₁) + ΔCp(T₂ – T₁).
તાપમાન પર એન્થાલ્પી ફેરફારનો પ્રશ્ન NEET માં આવે છે; ગણતરી મહત્વની છે.
આંશિક ઉષ્માધારિતા (Heat Capacities): Cv (સમકદ) અને Cp (સમદબાણ). Cp – Cv = R (આદર્શ વાયુ માટે). મોલર ઉષ્માધારિતા અને વિશિષ્ટ ઉષ્માધારિતા વચ્ચેનો તફાવત સમજવો જોઈએ.
Cp – Cv = R સૂત્ર અને તેના ઉપયોગ પર સીધો પ્રશ્ન આવે છે.
એન્ડરોપી (Entropy, S): વ્યવસ્થાનો અભાવ અથવા બેઉપત્તિનું માપ. પ્રકૃતિમાં કુલ એન્ડરોપી હંમેશા વધે છે. ΔS = q_rev / T (સમતાપી પ્રક્રિયા માટે).
એન્ડરોપીની વ્યાખ્યા અને ગણતરી NEET માં આવે છે.
બીજો નિયમ (Second Law): કોઈ પણ સ્વયંસ્ફૂરત પ્રક્રિયા માટે બ્રહ્માંડની એન્ડરોપી વધે છે. ΔSuniv = ΔSsys + ΔSsurroundings > 0 (સ્વયંસ્ફૂરત પ્રક્રિયા માટે).
બીજો નિયમ અને સ્વયંસ્ફૂરતાનો પાઠ NEET માં ઘણો આવે છે.
ગિબ્સ મુક્ત ઉર્જા (Gibbs Free Energy, G = H – TS): ΔG = ΔH – TΔS. સ્વયંસ્ફૂરત પ્રક્રિયા માટે ΔG < 0, સંતુલન માટે ΔG = 0, અસ્વયંસ્ફૂરત માટે ΔG > 0.
ΔG નું ચિહ્ન જાણવું NEET નું સૌથી મહત્વનું પ્રશ્ન છે — દરેક વર્ષે આવે છે.
ગિબ્સ મુક્ત ઉર્જા અને વિદ્યુતરસાયણ: ΔG° = –nFE°. આ સંબંધ ગિબ્સ ઉર્જા શોધવા માટે ઉપયોગી છે.
ΔG° = –nFE° સંબંધ પરથી E° cell શોધવાના પ્રશ્ન આવે છે.
તૃતીય નિયમ (Third Law): ಶૂન્ય કેલ્વિન (0 K) તાપમાને શુદ્ધ સ્ફટિકીય ઘન પદાર્થની એન્ડરોપી શૂન્ય થાય છે: S°(0 K) = 0.
તૃતીય નિયમની વ્યાખ્યા અને તેનો ઉપયોગ NEET માં આવે છે.
ભૌતિક પરિવર્તનોમાં ΔS: વાયુનું વિસ્તરણ (ΔS > 0), ઘનન (Melting) (ΔS > 0), બાષ્પીભવન (Vaporization) (ΔS > 0), સંઘનન (Condensation) (ΔS < 0). ડિગ્રી ઓફ ફ્રીડમ અને અવ્યવસ્થા વચ્ચેનો સંબંધ સમજવો.
વિવિધ ભૌતિક પ્રક્રિયાઓમાં એન્ડરોપી ફેરફારનું ચિહ્ન જાણવું NEET માં આવે છે.
સ્વયંસ્ફૂરતાના મહત્વના સંયોજનો: (i) ΔH < 0, ΔS > 0 → હંમેશા સ્વયંસ્ફૂરત, (ii) ΔH > 0, ΔS < 0 → ક્યારેય સ્વયંસ્ફૂરત, (iii) ΔH < 0, ΔS < 0 → નીચે તાપમાને સ્વયંસ્ફૂરત, (iv) ΔH > 0, ΔS > 0 → ઊંચા તાપમાને સ્વયંસ્ફૂરત.
આ ચારેય સંયોજનો પરથી પ્રશ્ન NEET માં બહુ આવે છે — તાપમાન પર આધારિત સ્વયંસ્ફૂરતા.
સંકલન પ્રક્રિયા (Cumulative Problem): જ્યારે ΔH, ΔS આપેલ હોય ત્યારે ΔG શોધવા માટે ΔG = ΔH – TΔS વાપરવું. T = ΔH/ΔS (સંતુલન તાપમાન).
ગણતરી પ્રકારના પ્રશ્ન NEET માં આવે છે; યોગ્ય એકમ પસંદગી અને ગણતરી રણનીતિ જરૂરી છે.
ઉષ્માગતિશાસ્ત્રીય પ્રક્રિયાઓના પ્રકારો: સમતાપી (Isothermal, ΔT = 0), સમકદ (Isochoric, ΔV = 0), સમદબાણ (Isobaric, ΔP = 0), રૂધિષ (Adiabatic, q = 0), પરાવર્તનીય (Reversible) અને અપરાવર્તનીય (Irreversible) પ્રક્રિયાઓ.
દરેક પ્રક્રિયાના LCUમાં ΔU, ΔH, q, w ની કિંમતો ફરક પડે છે — NEET માં અલગ-અલગ પ્રશ્નો આવે છે.
રૂધિષ પ્રક્રિયા (Adiabatic Process): q = 0, તેથી ΔU = w. પરાવર્તનીય રૂધિષ પ્રક્રિયા માટે PV^γ = constant, જ્યાં γ = Cp/Cv. તાપમાન અને દબાણ વચ્ચેનો સંબંધ: TV^(γ–1) = constant.
રૂધિષ પ્રક્રિયાના સમીકરણો NEET માં ગણતરી પ્રશ્ન આવે છે.
પરાવર્તનીય અને અપરાવર્તનીય વિસ્તરણ કાર્ય: પરાવર્તનીય વિસ્તરણમાં મહત્તમ કાર્ય મળે છે. w_rev = –nRT ln(V₂/V₁) (સમતાપી). અપરાવર્તનીય વિસ્તરણમાં w = –P_ext ΔV.
કાર્યની ગણતરી NEET માં આવે છે — પરાવર્તનીય vs અપરાવર્તનીય વચ્ચેનો તફાવત.
તાપમાન પર એન્ડરોપી ફેરફાર: ΔS = nCp ln(T₂/T₁) (સમદબાણ પ્રક્રિયા માટે) અને ΔS = nR ln(P₁/P₂) (તાપમાન અચળ રાખીને દબાણ ફેરફાર).
તાપમાન અને દબાણ ફેરફારથી એન્ડરોપીમાં થતો ફેરફાર NEET માં ગણતરી પ્રશ્ન છે.
ΔG°, ΔE°, ΔH°, ΔS° ની વચ્ચેનો સંબંધ: ΔG° = ΔH° – TΔS°. સંતુલન સ્થિરાંક K સાથે: ΔG° = –RT ln K. આ સંબંધો ઉષ્માગતિશાસ્ત્ર અને સંતુલન બંનેનો સંબંધ દર્શાવે છે.
ΔG° = –RT ln K સંબંધ સંતુલન અધ્યાય સાથે પણ જોડાયેલો છે — NEET માં આંતર-sambandhી પ્રશ્ન આવે છે.
