ઉષ્માગતિશાસ્ત્ર (Thermodynamics) — સૂત્ર શીટ

🩺 NEET UG — Gujarati • Chemistry • Thermodynamics

⚡ સૂત્રો

પ્રથમ નિયમનો સંબંધ (First Law of Thermodynamics): ΔU = q + w
ΔU = આંતરિક ઊર્જામાં ફેરફાર; q = ઉષ્મા; w = કાર્ય · SI: જૂલ (J) · કોઈ પણ ભૌતિક કે રાસાયણિક પ્રક્રિયા માટે
સ્થિરાંત દબાણે ઉષ્મા અને એન્થાલ્પી: q_p = ΔH
q_p = સ્થિરાંત દબાણે લેવાતી/છોડાતી ઉષ્મા; ΔH = એન્થાલ્પી ફેરફાર · SI: જૂલ (J) · એકમાત્ર પ્લટો-વિસ્તરણ કાર્ય હોય તેવી પ્રક્રિયા માટે
આંતરિક ઊર્જા-એન્થાલ્પી સંબંધ: ΔH = ΔU + Δn_g RT
Δn_g = વાયુ અવસ્થાના પદાર્થોના મોલમાં ફેરફાર (અભિક્રિયાનુ -> અનુ); R = વાયુ અચળાંક; T = તાપમાન (K) · SI: ΔH, ΔU : J ; RT : J mol^-1 · વાયુઓની રાસાયણિક પ્રક્રિયાઓ માટે
વોન્ટહૉફ્ સમીકરણ (વાયુ-અચળાંક): ΔH = ΔU + R T Δn_g
R = 8.314 J K^-1 mol^-1 ; T = કેલ્વિનમાં તાપમાન · SI: J mol^-1 · સંપૂર્ણ દળમાં ફેરફાર વાળા વાયુ પ્રક્રિયાઓ માટે
ઉષ્મા ધારી (Heat Capacity): q = m s ΔT
m = દળ; s = વિશિષ્ટ ઉષ્મા ધારી; ΔT = તાપમાન ફેરફાર · SI: J · તાપમાન બદલાતું હોય ત્યારે
મોલર ઉષ્મા ધારી (Constant Volume): C_v = (∂U/∂T)_v
C_v = સ્થિરાંત કદે મોલર ઉષ્મા ધારી; ∂U/∂T = આંતરિક ઊર્જાનું તાપમાન સાપેક્ષ વિકલિત · SI: J K^-1 mol^-1 · સ્થિરાંત કદે પ્રક્રિયા માટે
મોલર ઉષ્મા ધારી (Constant Pressure): C_p = (∂H/∂T)_p
C_p = સ્થિરાંત દબાણે મોલર ઉષ્મા ધારી · SI: J K^-1 mol^-1 · સ્થિરાંત દબાણે પ્રક્રિયા માટે
મેયરનો સંબંધ (Mayer's Relation): C_p - C_v = R
R = વાયુ અચળાંક (8.314 J K^-1 mol^-1) · SI: J K^-1 mol^-1 · આદર્શ વાયુ માટે
એડિયાબેટિક પ્રક્રિયા (Adiabatic Process): q = 0 , ΔU = w
q = 0 (ઉષ્મા આપ-લે નથી); w = પરિસર પર થતું કાર્ય · SI: J · એડિયાબેટિક પ્રક્રિયા (બંધ પાત્ર, ઇન્સ્યુલેટેડ)
પ્લટો-વિસ્તરણ કાર્ય (Pressure-Volume Work): w = -P_ext ΔV
P_ext = બાહ્ય દબાણ; ΔV = કદમાં ફેરફાર · SI: J · સ્થિરાંત બાહ્ય દબાણે વિસ્તરણ/સંકોચન
વિસ્તરણ-અવિસ્તરણ કાર્ય (Expansion Work, Integral Form): w = -∫ P_ext dV
P_ext = બાહ્ય દબાણ; dV = કદનો અનંત સૂક્ષ્મ ફેરફાર · SI: J · જ્યારે દબાણ અચળ નથી હોતું
આદર્શ વાયુનો સમતાપી વિસ્તરણ કાર્ય (Isothermal Reversible Expansion): w = -nRT ln(V₂/V₁) = -2.303 nRT log(V₂/V₁)
n = મોલની સંખ્યા; V₁, V₂ = પ્રારંભિક/અંતિમ કદ · SI: J · સમતાપી (T અચળ), પરસ્પરવિરોધી વિસ્તરણ
આદર્શ વાયુનો સમતાપી વિસ્તરણ (પ્રારંભિક/અંતિમ દબાણ સંક્રમણ): w = -nRT ln(P₁/P₂) = -2.303 nRT log(P₁/P₂)
P₁, P₂ = પ્રારંભિક/અંતિમ દબાણ · SI: J · સમતાપી પરસ્પરવિરોધી વિસ્તરણ
એકમ મોલ આદર્શ વાયુની આંતરિક ઊર્જા ફેરફાર: ΔU = n C_v ΔT
C_v = સ્થિરાંત કદે મોલર ઉષ્મા ધારી; ΔT = તાપમાન ફેરફાર · SI: J · તાપમાન બદલાતી પ્રક્રિયાઓ માટે
એન્થાલ્પી ફેરફાર (તાપમાન સાથે): ΔH = n C_p ΔT
C_p = સ્થિરાંત દબાણે મોલર ઉષ્મા ધારી · SI: J · તાપમાન બદલાતી પ્રક્રિયાઓ માટે
એડિયાબેટિક પ્રક્રિયાનું સમીકરણ (Adiabatic Equation): PV^γ = અચળ , T V^(γ-1) = અચળ , P^(1-γ) T^γ = અચળ
γ = C_p/C_v (ઉષ્મા ગુણોત્તર) · SI: — · આદર્શ વાયુની એડિયાબેટિક પરસ્પરવિરોધી પ્રક્રિયા
ઉષ્મા ગુણોત્તર (Gibbs Free Energy): ΔG = ΔH - TΔS
ΔG = ગિબ્સ મુક્ત ઊર્જા ફેરફાર; ΔH = એન્થાલ્પી ફેરફાર; ΔS = એન્ટ્રોપી ફેરફાર; T = તાપમાન (K) · SI: J · સ્થિરાંત તાપમાન અને દબાણે પ્રક્રિયા
ગિબ્સ મુક્ત ઊર્જા અને સ્વયંસ્ફુર્તિ (Spontaneity Criterion): ΔG < 0 → સ્વયંસ્ફુર્તિ (Spontaneous)
ΔG < 0 : સ્વયંસ્ફુર્ત; ΔG = 0 : સંતુલન; ΔG > 0 : અસ્વયંસ્ફુર્ત · SI: J · સ્થિરાંત T, P
ગિબ્સ મુક્ત ઊર્જા અને સંતુલન અચળાંક (Gibbs-Equilibrium): ΔG° = -RT ln K = -2.303 RT log K
ΔG° = પ્રમાણિત ગિબ્સ મુક્ત ઊર્જા ફેરફાર; K = સંતુલન અચળાંક · SI: J · રાસાયણિક સંતુલન માટે
એન્ટ્રોપી ફેરફાર (સામાન્ય, Isobaric): ΔS = n C_p ln(T₂/T₁) = 2.303 n C_p log(T₂/T₁)
T₁, T₂ = પ્રારંભિક/અંતિમ તાપમાન (K) · SI: J K^-1 · સ્થિરાંત દબાણે તાપમાન ફેરફાર
એન્ટ્રોપી ફેરફાર (સમતાપી, Isobaric Gas Expansion): ΔS = nR ln(V₂/V₁) = 2.303 nR log(V₂/V₁)
V₁, V₂ = પ્રારંભિક/અંતિમ કદ · SI: J K^-1 · સમતાપી વિસ્તરણ
એન્ટ્રોપી ફેરફાર (આદર્શ વાયુ, કદ અને તાપમાન બંને બદલાય): ΔS = nC_v ln(T₂/T₁) + nR ln(V₂/V₁)
C_v = સ્થિરાંત કદે મોલર ઉષ્મા ધારી; R = વાયુ અચળાંક · SI: J K^-1 · જ્યારે તાપમાન અને કદ બંને બદલાય
કલા સંક્રમણ એન્ટ્રોપી (Phase Transition Entropy): ΔS_tr = ΔH_tr / T_tr
ΔH_tr = સંક્રમણ એન્થાલ્પી; T_tr = સંક્રમણ તાપમાન (K) · SI: J K^-1 · સંતુલન પર સંક્રમણ (દ્રવ્ય, બાષ્પીભવન, સUBLિમેશન)
દ્રવ્ય એનથાલ્પી (Enthalpy of Fusion): Δ_fusH
Δ_fusH = દ્રવ્ય એન્થાલ્પી (ઘન→द्रव) · SI: kJ mol^-1 · ગલનબિંદુએ
બાષ્પીભવન એનથાલ્પી (Enthalpy of Vaporization): Δ_vapH
Δ_vapH = બાષ્પીભવન એન્થાલ્પી (द्रव→બાષ્પ) · SI: kJ mol^-1 · કુકબિંદુએ
બાષ્પીભવન એન્ટ્રોપી: Δ_s_vapH = Δ_vapH / T_b
T_b = બોઇલિંગ પોઈન્ટ (K) · SI: J K^-1 mol^-1 · બોઇલિંગ પોઈન્ટે
રાસાયણિક પ્રક્રિયાનો પ્રમાણિત એન્થાલ્પી ફેરફાર (Standard Enthalpy of Reaction): Δ_rH° = Σ n_p Δ_fH°(ઉત્પાદનો) - Σ n_r Δ_fH°(અભિકારકો)
n_p, n_r = સ્ટોઇકિયોમેટ્રિક ગુણાંક; Δ_fH° = પ્રમાણિત બનાવટ એન્થાલ્પી · SI: kJ mol^-1 · 298 K અને 1 bar
હેસનો નિયમ (Hess's Law): Δ_rH = Σ ΔH_પગલાં
Δ_rH = કુલ એન્થાલ્પી ફેરફાર; ΔH_પગલાં = વચ્ચેના પગલાંઓની એન્થાલ્પી · SI: kJ mol^-1 · કોઈ પણ બહુ-પગલાંવાળી પ્રક્રિયા માટે, માર્ગથી સ્વતંત્ર
બંધ એન્થાલ્પી (Bond Enthalpy): Δ_rH = Σ BE(અભિકારકો) - Σ BE(ઉત્પાદનો)
BE = બંધ વિઘટન એન્થાલ્પી (Bond Dissociation Enthalpy) · SI: kJ mol^-1 · બંધ તૂટતા અને બનતા હોય
પ્રમાણિત બનાવટ એન્થાલ્પી (Standard Enthalpy of Formation): Δ_fH°
Δ_fH° = પ્રમાણિત પરિસ્થિતિએ એકમ મોલ સંયોગ બનાવવાની એન્થાલ્પી; તત્વોની Δ_fH° = 0 · SI: kJ mol^-1 · પ્રમાણિત અવસ્થામાં (298 K, 1 bar)
પ્રમાણિત દહન એન્થાલ્પી (Standard Enthalpy of Combustion): Δ_cH°
Δ_cH° = પ્રમાણિત પરિસ્થિતિએ 1 મોલ પદાર્થનું સંપૂર્ણ દહન થવાની એન્થાલ્પી · SI: kJ mol^-1 · O₂ વધુ પ્રમાણમાં હોય
પ્રમાણિત રૂપાંતરણ એન્થાલ્પી (Standard Enthalpy of Transition): Δ_trH°
Δ_trH° = એક રૂપાંતરણમાંથી બીજામાં જવાની એન્થાલ્પી (ઉદા. C(ગ્રેફાઇટ) → C(હીરા)) · SI: kJ mol^-1 · પ્રમાણિત અવસ્થા
પ્રમાણિત વિલાયત એન્થાલ્પી (Standard Enthalpy of Solution): Δ_solH°
Δ_solH° = અનંત પ્રમાણે પાણીમાં 1 મોલ પદાર્થ ગળવાની એન્થાલ્પી · SI: kJ mol^-1 · અનંત વિਲયન
ઉષ્માગતિશાસ્ત્રીય સંતુલન (Thermodynamic Equilibrium): ΔG = 0
ΔG = ગિબ્સ મુક્ત ઊર્જા ફેરફાર · SI: — · સ્થિરાંત T, P પર સંતુલન
કેલ્વિન-પ્લાન્ક ઉત્પ્રેરક (Second Law – Kelvin-Planck Statement): ઉષ્મા એન્જિનની કાર્યક્ષમતા η < 1
η = Q₁/Q_hot (કાર્ય/પ્રાપ્ત ઉષ્મા) · SI: — · વાસ્તવિક ઉષ્મા એન્જિન માટે
કાર્યક્ષમતાની ગણતરી: η = W/Q₁ = 1 - (Q₂/Q₁)
W = થયેલું કાર્ય; Q₁ = ગરમ રિઝર્વોરથી લેવાતી ઉષ્મા; Q₂ = ઠંડા રિઝર્વોરને આપવામાં આવતી ઉષ્મા · SI: — · કાર્નો્ટ એન્જિન કે સામાન્ય ઉષ્મા એન્જિન
કાર્નો્ટ એન્જિન કાર્યક્ષમતા: η = 1 - T₂/T₁ = (T₁ - T₂)/T₁
T₁ = ગરમ રિઝર્વોર તાપમાન (K); T₂ = ઠંડા રિઝર્વોર તાપમાન (K) · SI: — · કાર્નો્ટ ચક્ર
ત્રીજો નિયમ (Third Law of Thermodynamics): lim(T→0 K) S = 0 (પૂર્ણ સ્ફટિકીય ઘન માટે)
S = એન્ટ્રોપી · SI: J K^-1 mol^-1 · પૂર્ણ સ્ફટિકીય ઘન 0 K તાપમાને
તાપમાન સાથે એન્થાલ્પી ફેરફાર (Kirchhoff's Equation): Δ_rH(T₂) = Δ_rH(T₁) + Δ_rC_p (T₂ - T₁)
Δ_rC_p = C_p(ઉત્પાદનો) - C_p(અભિકારકો); Δ_rC_p અચળ હોય ત્યારે · SI: kJ mol^-1 · Δ_rC_p અચળ હોય
તાપમાન સાથે એન્થાલ્પી (વક્રીય પ્રકાર): d(Δ_rH)/dT = Δ_rC_p
Δ_rC_p = ઉત્પાદનો અને અભિકારકોની C_p વચ્ચેનો તફાવત · SI: J K^-1 mol^-1 · સામાન્ય રીતે

🔗 સંબંધો

  • પ્રથમ નિયમમાં ΔU = q + w, જ્યાં sign convention મુજબ ઉષ્મા શોષાઈ → q ધન, ઉષ્મા મુક્ત → q ઋણ; પરિસર પર કાર્ય થાય → w ધન, પરિસર દ્વારા કાર્ય થાય → w ઋણ.
  • સમાન પ્રક્રિયા માટે ΔH = ΔU + Δn_g RT; Δn_g > 0 હોય → ΔH > ΔU; Δn_g = 0 હોય → ΔH = ΔU.
  • આદર્શ વાયુ માટે C_p - C_v = R અને γ = C_p/C_v, જેથી C_p = γR/(γ-1) અને C_v = R/(γ-1).
  • ગિબ્સ મુક્ત ઊર્જા ઘટાડો કરાયેલું મહત્તમ વક્રીય કાર્ય બરાબર થાય છે: ΔG = Maximum non-expansion work.
  • ડીસોલ્યુશન અને બોન્ડ એન્થાલ્પીના સંયોજનથી Hess's Law દ્વારા કોઈ પણ પ્રક્રિયાની Δ_rH ગણી શકાય.
  • જો પ્રક્રિયા એક્સોથર્મિક (ΔH < 0) અને એન્ટ્રોપી વધતી હોય (ΔS > 0), તો દરેક તાપમાન પર ΔG < 0 (સદા સ્વયંસ્ફુર્તિ).
  • જો પ્રક્રિયા એન્ડોથર્મિક (ΔH > 0) અને એન્ટ્રોપી વધતી હોય (ΔS > 0), તો ઉંચા તાપમાને માત્ર ΔG < 0 બને છે.
  • કાર્નો્ટ એન્જિનની કાર્યક્ષમતા માત્ર T₁ અને T₂ પર આધારિત છે, અન્ય કોઈ પરિમાણ પર નહીં.

🎯 ટ્રિક્સ

Δn_g ની ગણતરી કરતી વખતે માત્ર વાયુ અવસ્થાના પદાર્થો ગણો; ઘન અને દ્રવ અવસ્થાના પદાર્થોને બાદ રાખો.
પ્રક્રિયામાં C_p અને C_v વચ્ચેનો તફાવત R થાય છે તે યાદ રાખવા: Cp → 'પ્રેશર' (P), Cv → 'વોલ્યુમ' (V); P > V નથી પણ R ઉમેરાય છે.
ΔG = ΔH - TΔS સૂત્રમાં T = 0 K પર ΔG ≈ ΔH થાય છે, એટલે શૂન્ય તાપમાને એન્ટ્રોપીનો પ્રભાવ શૂન્ય છે.
સંતુલન અચળાંક K સાથેનો સંબંધ ΔG° = -2.303 RT log K માં K > 1 હોય → ΔG° < 0 (સ્વયંસ્ફુર્તિ); K < 1 → ΔG° > 0 (અસ્વયંસ્ફુર્તિ).
બે તાપમાન વચ્ચે ΔH ફેરફાર કરવા Kirchhoff સમીકરણ વાપરો: Δ_rH(T₂) = Δ_rH(T₁) + Δ_rC_p·ΔT, જ્યાં Δ_rC_p અચળ લેવું.
એડિયાબેટિક વિસ્તરણમાં T ઘટે છે અને દબાણ ઘટે છે; T V^(γ-1) = અચળ સંબંધ વડે T₂ શોધવું સરળ છે.

⚠️ ભૂલો

ΔU = q + w માં sign convention ભૂલી જવું. NEET માં 'ઉષ્મા પ્રણાલી દ્વારા મુક્ત થાય તો q ઋણ, કાર્ય પરિસર દ્વારા થાય તો w ઋણ' એ sign convention અપનાવવામાં આવે છે.
Δn_g ની ગણતરીમાં ઘન અને દ્રવ પદાર્થોનો સમાવેશ કરી દેવો. માત્ર વાયુ મોલની ગણતરી કરવી.
C_p અને C_v નું મૂલ્ય ગૂંચવણમાં મૂકવું. Cv < C_p હોય છે (C_p = Cv + R).
એડિયાબેટિક પ્રક્રિયામાં q = 0 ભૂલથી લખવું, પરંતુ ΔU = w + q ના સ્થાને ΔU = w યાદ રાખવું.
ΔG° = -RT ln K માં ln અને log નો ભેદ ન કરી 2.303 વડે ગુણાકાર ભૂલવો.
ΔH અને ΔU વચ્ચેનો તફાવત Δn_g RT છે તેનો ઉપયોગ ઠેકાણેસરનો ન કરવો (વાયુ પ્રક્રિયાઓ માટે જ લાગુ પડે છે).
કાર્નોટ એન્જિનની કાર્યક્ષમતા η = (T₁ - T₂)/T₁ માં T₂ > T₁ હોઈ શકે નહીં, તેથી η હંમેશા 0 થી 1 ની વચ્ચે જ હોય છે.
ΔS_total = ΔS_system + ΔS_surroundings > 0 શરત ગૂંચવી નાખવી. second law મુજબ ΔS_universe ≥ 0.
