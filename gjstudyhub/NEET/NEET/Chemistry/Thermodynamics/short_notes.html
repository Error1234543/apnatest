ઉષ્માગતિવિજ્ઞાન — ઝડપી મુલ્યાંકન નોટ્સ

🩺 NEET UG — Gujarati • Chemistry • Thermodynamics

📘 વ્યાખ્યાઓ

  • સિસ્ટમ (System): અભ્યાસાધારણ માટે પસંદ કરેલ ભાગ અથવા દ્રવ્ય.
  • પરિસર (Surroundings): સિસ્ટમની બહારનો બાકીનો બ્રહ્માંડ.
  • ખુલ્લી સિસ્ટમ (Open system): દ્રવ્ય અને ઊર્જા બંને આદાન-પ્રદાન કરે.
  • બંધ સિસ્ટમ (Closed system): ઊર્જા આદાન-પ્રદાન હોય, દ્રવ્ય નહીં.
  • અવાહક સિસ્ટમ (Isolated system): દ્રવ્ય અને ઊર્જા કોઈ આદાન-પ્રદાન ન થાય.
  • અવસ્થા ફલન (State function): પ્રારંભિક અને અંતિમ અવસ્થા પર આધારિત, માર્ગથી સ્વતંત્ર.
  • માર્ગ ફલન (Path function): પ્રક્રિયાના માર્ગ પર આધારિત, અવસ્થાઓ પર સ્વતંત્ર.
  • સ્રોત (Reservoir): મર્યાદિત કદવાળું, અમર્યાદિત ઉષ્માશોષક/ઉષ્માક્ષેપક.
  • સમતાપી પ્રક્રિયા (Isothermal): સ્થિર તાપમાને ચાલતી પ્રક્રિયા, ΔT = 0.
  • રૂપાંતરણ બિંદુ (Transition point): જ્યાં બે અવસ્થાઓ સંતુલનમાં હોય.
  • એન્થાલ્પી (Enthalpy): H = U + PV, સ્થિર દબાણે ઉષ્મા ફેરફાર.
  • ગિબ્સ મુક્ત ઊર્જા (Gibbs free energy): G = H – TS, સ્વયંસ્ફુરિતતાનું માપ.

⚡ સૂત્રો

  • ΔU = q + w (ઉષ્માગતિવિજ્ઞાનનું પ્રથમ નિયમ)
  • w = –P_ext × ΔV (સ્થિર બાહ્ય દબાણે કદકાર્ય)
  • q_v = ΔU (સ્થિર કદે ઉષ્મા = આંતરિક ઊર્જા ફેરફાર)
  • q_p = ΔH (સ્થિર દબાણે ઉષ્મા = એન્થાલ્પી ફેરફાર)
  • ΔH = ΔU + Δn_g RT (વાયુ પ્રક્રિયાઓ માટે)
  • ΔH = ΣΔH_બંધ (બંધ ઉષ્માઓનો સરવાળો – કિંબલિંગ)
  • Δ_r G° = –nFE° (ઇલેક્ટ્રોકેમિકલ સંબંધ)
  • ΔG = ΔH – TΔS (ગિબ્સ-હિલબર્ન સમીકરણ)

⭐ મુખ્ય તથ્યો

  • ઉષ્મા (q) અને કાર્ય (w) એ માર્ગ ફલન છે, એન્થાલ્પી (H) અને આંતરિક ઊર્જા (U) એ અવસ્થા ફલનો છે.
  • એન્થાલ્પી ફેરફાર ΔH ઋણ હોય ત્યારે ઉષ્માક્ષેપી (Exothermic), ધન હોય ત્યારે ઉષ્માશોષી (Endothermic).
  • ઉષ્માગતિવિજ્ઞાનનો પ્રથમ નિયમ: બ્રહ્માંડની કુલ ઊર્જા અચળ; ઊર્જાનું રૂપાંતર હોઈ શકે પણ સર્જન કે વિનાશ નહીં.
  • અદળી (Reversible) પ્રક્રિયામાં સિસ્ટમ અને પરિસર બંને મૂળ અવસ્થામાં પાછા આવી શકે છે.
  • સ્વયંસ્ફુરિત (Spontaneous) પ્રક્રિયા માટે ΔG < 0, સંતુલન પર ΔG = 0.
  • એન્ટ્રોપી (S) એ અવ્યવસ્થાનું માપ છે; પ્રકૃતિમાં કુલ એન્ટ્રોપી સતત વધે છે.

⚠️ સામાન્ય ભૂલો

  • q અને w ના સંકેત બંધારણ (Sign convention) ગૂંચવીને ઋણ/ધન લખવા.
  • Δn_g = n_gas_ઉત્પાદિત – n_gas_પ્રક્રિયક માં દ્રવ/ઘનનો સમાવેશ કરવો.
  • STP અને સામાન્ય તાપમાને R ની કિંમત ગૂંચવવી (8.314 J K⁻¹ mol⁻¹ vs 0.0821 L atm K⁻¹ mol⁻¹).
  • q_p = ΔH એ ફક્ત સ્થિર દબાણે શુદ્ધ કદકાર્ય સિવાયના પ્રક્રિયાઓ માટે લાગુ પડે.
  • ઋણ ΔG એ ગતિશીલતાનો સંકેત આપતું નથી, ફક્થ ઉષ્માગતિજ સંભાવના દર્શાવે છે.
  • એન્ટ્રોપી વધારો = પ્રક્રિયા સ્વયંસ્ફુરિત, આ ભૂલપૂર્ણ તર્ક.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • પ્રથમ નિયમના આધારે કિંબલિંગ (Hess Law) અને બંધ ઉષ્મા ગણતરી પ્રશ્નો.
  • ΔH = ΔU + Δn_g RT વડે વાયુ પ્રક્રિયાઓમાં એન્થાલ્પી–આંતરિક ઊર્જા સંબંધ.
  • ગિબ્સ સમીકરણ ΔG = ΔH – TΔS વડે તાપમાન પ્રભાવ અને સંતુલન તાપમાન શોધવું.
  • એડિઅબેટિક પ્રક્રિયામાં q = 0, તેથી ΔU = w.
  • ઉષ્માગતિવિજ્ઞાનનો દ્વિતીય નિયમ: ઉષ્મા સ્વયંમેવ નીચા તાપમાને ઊંચા તાપમાને પ્રવાહિત થતી નથી.
  • સંયોજન ઉષ્મા (Δ_f H°) = મૂલક તત્વોમાંથી 1 mol સંયોજન બનતી ઉષ્મા.
