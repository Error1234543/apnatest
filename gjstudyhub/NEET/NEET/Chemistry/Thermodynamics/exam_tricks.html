રસાયણશાસ્ત્ર — ઉષ્માગતિકી (Thermodynamics) માટે પરીક્ષા ટ્રિક્સ

🩺 NEET UG — Gujarati • Chemistry • Thermodynamics

🎯 પરીક્ષા ટ્રિક્સ

ΔG = ΔH – TΔS માં, જો ΔG < 0 હોય તો પ્રક્રિયા સ્વતઃસ્ફૂર્ત (spontaneous) છે. ΔH અને ΔS ના ચિહ્નો જાણી, તાપમાન (T) ની અસર ઝડપથી કાઢો.
પ્રક્રિયાની સ્વતઃસ્ફૂર્તતા નક્કી કરવા અથવા તાપમાનની અસર જાણવા.
દા.ત.: જો ΔH = –100 kJ (બહિર્મુખી, exothermic), ΔS = +0.2 kJ/K હોય, તો ΔG = –100 – T(0.2). T < 500 K એટલે ΔG < 0 → પ્રક્રિયા સ્વતઃસ્ફૂર્ત.
ΔU = q + w માં, ગેસના પ્રસરણ (expansion) માં w = –PΔV. જો પ્રસરણ સમાપન (reversible) હોય તો w = –nRT ln(V₂/V₁).
આંતરિક ઉર્જા (ΔU) અથવા કાર્ય (w) ની ગણતરી કરવા.
દા.ત.: 1 મોલ ગેસ 1 L થી 2 L સુધી સમાપન પ્રસરણ પામે તો w = –1 × 8.314 × T × ln(2/1) = –5.76T J.
Hess ના નિયમ મુજબ, પ્રક્રિયાનું ΔH એ પગલાંઓના ΔH ના સરવાળા જેટલું જ હોય છે. પ્રક્રિયાને ઉલટ-સુલટ કરો અથવા ગુણો તો ΔH ના ચિહ્ન/મૂલ્ય બદલો.
બહુ-પગલાની પ્રક્રિયાના ΔH ની ગણતરી કરવા.
દા.ત.: A → B (ΔH = +50 kJ), B → C (ΔH = +30 kJ) → A → C નું ΔH = 50 + 30 = +80 kJ.
સમતાપી (isothermal) પ્રક્રિયામાં ΔU = 0 (આદર્શ ગેસ માટે), કારણ કે આંતરિક ઉર્જા ફક્ત તાપમાન પર આધાર રાખે છે.
આદર્શ ગેસની સમતાપી પ્રક્રિયામાં ΔU શોધવા.
દા.ત.: 1 મોલ આદર્શ ગેસ 300 K તાપમાને પ્રસરે તો ΔU = 0.
સમઘનતા (isochoric) પ્રક્રિયામાં w = 0, કારણ કે ΔV = 0. તો ΔU = q (પ્રક્રિયામાં ઉષ્મા વિનિમય = આંતરિક ઉર્જા ફેરફાર).
સમઘનતા પ્રક્રિયામાં કાર્ય અથવા ΔU શોધવા.
દા.ત.: ગેસને બંધ પાત્રમાં ગરમ કરો તો w = 0, ΔU = q.
સમદાબ (isobaric) પ્રક્રિયામાં q = ΔH = nCₚΔT, જ્યારે સમઘનતામાં q = ΔU = nCᵥΔT.
ઉષ્મા ધારિતા (Cₚ અથવા Cᵥ) વડે q અથવા ΔH/ΔU શોધવા.
દા.ત.: 2 મોલ ગેસનો તાપમાન 100 K વધારો (Cₚ = 29 J/mol·K) → q = 2 × 29 × 100 = 5800 J.
Cₚ – Cᵥ = R (આદર્શ ગેસ માટે). આથી જો Cₚ અથવા Cᵥ આપેલ હોય તો બીજી કિંમત શોધી શકાય.
ઉષ્મા ધારિતાઓ વચ્ચેનો સંબંધ શોધવા.
દા.ત.: Cᵥ = 20.8 J/mol·K → Cₚ = 20.8 + 8.314 ≈ 29.1 J/mol·K.
પ્રમાણિત એન્ટ્રોપી ફેરફાર (ΔS°) ની ગણતરી માટે ΔS° = ΣS°(પ્રોડક્ટ્સ) – ΣS°(રિએક્ટન્ટ્સ).
પ્રક્રિયાની એન્ટ્રોપી શોધવા.
દા.ત.: 2H₂(g) + O₂(g) → 2H₂O(l) માટે ΔS° = 2×S°(H₂O) – [2×S°(H₂) + S°(O₂)].
જો પ્રક્રિયા ઉલટી (reverse) હોય તો ΔH, ΔS, અને ΔG ના ચિહ્ન બદલાય છે, પરંતુ મૂલ્ય સમાન રહે છે.
ઉલટી પ્રક્રિયાના થર્મોડાયનેમિક્સ ગુણધર્મો શોધવા.
દા.ત.: A → B (ΔH = +50 kJ) → B → A (ΔH = –50 kJ).
જો પ્રક્રિયા કોઈ પગલું x ગુણા થાય તો ΔH, ΔS, અને ΔG પણ x ગુણા થાય છે.
પ્રક્રિયાને સ્કેલ કરવા (ગુણા/ભાગવા).
દા.ત.: A → B (ΔH = +50 kJ) → 2A → 2B (ΔH = +100 kJ).
બોન્ડ એનર્જી વડે ΔH ની ગણતરી: ΔH = Σ(બોન્ડ એનર્જી રિએક્ટન્ટ્સ) – Σ(બોન્ડ એનર્જી પ્રોડક્ટ્સ).
પ્રક્રિયાના ΔH ની અંદાજિત કિંમત શોધવા.
દા.ત.: H₂ + Cl₂ → 2HCl માટે ΔH = (H–H + Cl–Cl) – 2×(H–Cl).
જો પ્રક્રિયા સંતુલનમાં હોય તો ΔG = 0, અને ΔG° = –RT ln(K). આથી K = e^(–ΔG°/RT).
સંતુલન અચળાંક (K) અથવા ΔG° શોધવા.
દા.ત.: ΔG° = –5.7 kJ/mol, T = 300 K → K = e^(5700/(8.314×300)) ≈ 2.7.
ઉષ્માગતિકીના પહેલા નિયમ મુજબ, ΔU = q + w. જો સિસ્ટમ પર કાર્ય થાય (w > 0) અથવા સિસ્ટમ ઉષ્મા શોષે (q > 0) તો ΔU વધે.
આંતરિક ઉર્જાના ફેરફારની દિશા નક્કી કરવા.
દા.ત.: ગેસને દબાણ કરો (w > 0) અને ઉષ્મા આપો (q > 0) → ΔU > 0.
એન્ટ્રોપી (S) એ વ્યવસ્થાની અવ્યવસ્થા (disorder) નું માપન છે. ગેસ > દ્રાવણ > ઘન: S(g) > S(l) > S(s).
પદાર્થની એન્ટ્રોપીની તુલના કરવા.
દા.ત.: H₂O(s) → H₂O(l) → H₂O(g) માં S વધે છે.
જો પ્રક્રિયામાં ગેસના મોલની સંખ્યા ઘટે (Δn < 0) તો ΔS સામાન્ય રીતે નકારાત્મક (–ve) હોય છે.
પ્રક્રિયાની એન્ટ્રોપીની દિશા અંદાજવા.
દા.ત.: 2SO₂(g) + O₂(g) → 2SO₃(g) → Δn = 3 – 2 = –1 → ΔS < 0.
