હાઇડ્રોકાર્બન (Hydrocarbons) — NEET UG ગુજરાતી એગ્ઝામ ટ્રિક્સ

🩺 NEET UG — Gujarati • Chemistry • Hydrocarbons

🎯 પરીક્ષા ટ્રિક્સ

અલ્કેનમાં CₙH₂ₙ+₂ ફોર્મ્યુલા યાદ રાખવાની જરૂર નથી. બસ, કાર્બનની સંખ્યા n લખી, તેના દ્વિગુણ કરી 2 ઉમેરો. ઉદાહરણ: C₄ → 4×2+2=10 → C₄H₁₀.
જ્યારે અલ્કેનનો આણ્વીય સૂત્ર ઝડપથી કાઢવો હોય.
દા.ત.: C₅H₁₂ (પેન્ટેન) માટે: 5×2+2=12 → Hના અણુ = 12.
અલ્કીનમાં CₙH₂ₙ ફોર્મ્યુલા યાદ રાખવા, અલ્કેનમાંથી 2 H કાઢી નાખો. ઉદાહરણ: C₄H₁₀ (અલ્કેન) → C₄H₈ (અલ્કીન).
અલ્કીનનો સૂત્ર ઝડપથી મેળવવા.
દા.ત.: C₆H₁₂ (હેક્ઝીન) માટે: C₆H₁₄ (હેક્ઝેન)માંથી 2 H કાઢો.
અલ્કાઇનમાં CₙH₂ₙ₋₂ ફોર્મ્યુલા માટે, અલ્કેનમાંથી 4 H કાઢો. ઉદાહરણ: C₄H₁₀ → C₄H₆.
અલ્કાઇનનો સૂત્ર તરત જાણવા.
દા.ત.: C₅H₈ (પેન્ટાઇન) માટે: C₅H₁₂ (પેન્ટેન)માંથી 4 H કાઢો.
બેન્ઝિન વલયમાં કોઈપણ બે સમાન સબ્સ્ટિટ્યુટ્સ (ઉદા. -CH₃) વચ્ચેના આઇસોમરની સંખ્યા મેળવવા: n = (સબ્સ્ટિટ્યુટ્સની સંખ્યા / 2) - 1. જો સબ્સ્ટિટ્યુટ્સની સંખ્યા 2 હોય તો 1 આઇસોમર (ઓર્થો, મેટા, પેરા નહીં, કેમ કે બે સમાન હોય તો મેટા અને પેરા સરખા થાય).
બેન્ઝિનના ડાઇ-સબ્સ્ટિટ્યુશન આઇસોમરની સંખ્યા ગણતરી કરવા.
દા.ત.: ડાઇમિથાઇલબેન્ઝિન (C₆H₄(CH₃)₂) માટે: 2 સબ્સ્ટિટ્યુટ્સ → 1 આઇસોમર (મેટા અને પેરા સરખા નથી, પરંતુ ઓર્થો અલગ છે).
અલ્કીનમાં ડબલ બોન્ડની સ્થિતિ શોધવા, O₃ (ઓઝોનોલિસિસ) વડે ટૂકડા પડે છે. જો ટૂકડામાં કાર્બોનિલ ગ્રૂપ (C=O) હોય તો ડબલ બોન્ડ ત્યાં હતી.
અજ્ઞાત અલ્કીનની રચના શોધવા.
દા.ત.: CH₃-CH=CH-CH₃ + O₃ → CH₃CHO + CH₃CHO → ડબલ બોન્ડ મધ્યમાં હતી.
અલ્કાઇનમાં ટ્રિપલ બોન્ડની હાજરી શોધવા, અલ્કલાઇન KMnO₄ (પોટેશિયમ પરમેંગેનેટ) વડે ટેસ્ટ કરો. જો ટ્રિપલ બોન્ડ છેડે હોય તો CO₂ બને છે.
અલ્કાઇનની ઓળખ કરવા.
દા.ત.: CH₃-C≡CH + KMnO₄ → CH₃COOH + CO₂ (ટ્રિપલ બોન્ડ છેડે હોવાથી CO₂ બને છે).
હાઇડ્રોકાર્બનના કોમ્બસ્ટન (દહન) રિએક્શનમાં, O₂ની જરૂરીયાત ગણતરી કરવા: CₓHᵧ + (x + y/4) O₂ → x CO₂ + (y/2) H₂O.
દહન રિએક્શનમાં O₂ની માત્રા ઝડપથી કાઢવા.
દા.ત.: C₃H₈ (પ્રોપેન) → x=3, y=8 → (3 + 8/4) = 5 O₂ → C₃H₈ + 5 O₂ → 3 CO₂ + 4 H₂O.
અલ્કીનમાં એડિશન રિએક્શન (ઉદા. HBr)માં, માર્કોવનિકોવનો નિયમ લાગુ પડે છે: H+ સદા તે કાર્બન પર જાય છે જ્યાં Hની સંખ્યા વધુ હોય.
HBr એડિશન રિએક્શનના ઉત્પાદનની ભવિષ્યવાણી કરવા.
દા.ત.: CH₃-CH=CH₂ + HBr → CH₃-CHBr-CH₃ (H+ CH₂ પર જાય છે, કેમ કે ત્યાં 2 H છે).
બેન્ઝિનના નાઇટ્રેશનમાં, NO₂ ગ્રૂપ મુખ્યત્વે મેટા સ્થાને જાય છે જો સબ્સ્ટિટ્યુટ ડિએક્ટિવેટિંગ હોય (ઉદા. -NO₂, -CN).
બેન્ઝિનના નાઇટ્રેશન ઉત્પાદનની ભવિષ્યવાણી કરવા.
દા.ત.: નાઇટ્રોબેન્ઝિન (C₆H₅NO₂)નું નાઇટ્રેશન → મેટા-ડાઇનાઇટ્રોબેન્ઝિન.
અલ્કેનના હેલોજનેશનમાં, Cl₂ અથવા Br₂ વડે, રિએક્શન ફ્રી-રેડિકલ મેકેનિઝમ દ્વારા થાય છે. સૂર્યપ્રકાશ અથવા ઉષ્મા જરૂરી છે.
હેલોજનેશન રિએક્શનની શરતો યાદ રાખવા.
દા.ત.: CH₄ + Cl₂ → CH₃Cl + HCl (સૂર્યપ્રકાશમાં).
અલ્કાઇનમાં ટ્રિપલ બોન્ડની હાજરી શોધવા, અમોનિયાકલ સિલ્વર નાઇટ્રેટ (Tollens reagent) વડે ટેસ્ટ કરો. સફેદ અવક્ષેપ (Ag₂C₂) પડે છે.
ટર્મિનલ અલ્કાઇન (છેડે ટ્રિપલ બોન્ડ)ની ઓળખ કરવા.
દા.ત.: CH₃-C≡CH + AgNO₃ (NH₃) → Ag₂C₂↓ (સફેદ અવક્ષેપ).
સાયક્લોઅલ્કેનમાં, રિંગ તણાવ (ring strain)ના કારણે, નાના રિંગ (C₃, C₄)માં એડિશન રિએક્શન ઝડપથી થાય છે.
સાયક્લોઅલ્કેનની રિએક્ટિવિટી સમજવા.
દા.ત.: સાયક્લોપ્રોપેન (C₃H₆) + Br₂ → 1,3-ડાઇબ્રોમોપ્રોપેન (ઝડપથી રિએક્ટ થાય છે).
અલ્કીનમાં, જો ડબલ બોન્ડ સિમેટ્રિકલ હોય (ઉદા. CH₃-CH=CH-CH₃), તો O₃ વડે ઓઝોનોલિસિસ પછી એક જ કાર્બોનિલ યોગિક મળે છે.
ઓઝોનોલિસિસના ઉત્પાદનની ભવિષ્યવાણી કરવા.
દા.ત.: CH₃-CH=CH-CH₃ + O₃ → 2 CH₃CHO (એક જ ઉત્પાદન).
બેન્ઝિનમાં, જો સબ્સ્ટિટ્યુટ એક્ટિવેટિંગ હોય (ઉદા. -OH, -NH₂), તો નવો સબ્સ્ટિટ્યુટ ઓર્થો/પેરા સ્થાને જાય છે.
બેન્ઝિનના ઇલેક્ટ્રોફિલિક સબ્સ્ટિટ્યુશન રિએક્શનની દિશા નક્કી કરવા.
દા.ત.: ફિનોલ (C₆H₅OH)નું બ્રોમિનેશન → 2,4,6-ટ્રાઇબ્રોમોફિનોલ (ઓર્થો/પેરા સ્થાને).
