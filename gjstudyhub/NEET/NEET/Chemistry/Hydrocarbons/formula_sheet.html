⚡ સૂત્રો

આલ્કેન (Alkane) નું સામાન્ય સૂત્ર: CnH(2n+2)
n = કાર્બન પરમાણુઓની સંખ્યા; H = હાઈડ્રોજન પરમાણુઓની સંખ્યા · SI: N/A (સંયોજનનું આણ્વીય સૂત્ર) · સંપૃક્ત એકમીય હાઇડ્રોકાર્બન (સાયક્લોઅલ્કેન સિવાય)
સાયક્લોઅલ્કેન (Cycloalkane) નું સામાન્ય સૂત્ર: CnH(2n)
n = રિંગમાં રહેલા કાર્બન પરમાણુઓની સંખ્યા · SI: N/A (આણ્વીય સૂત્ર) · એક રિંગ ધરાવતા સંપૃક્ત ચક્રીય હાઇડ્રોકાર્બન
આલ્કીન (Alkene) નું સામાન્ય સૂત્ર: CnH(2n)
n = કાર્બન પરમાણુઓની સંખ્યા (n ≥ 2) · SI: N/A (આણ્વીય સૂત્ર) · એક C=C દ્વિબંધ ધરાવતો એકમીય અસંપૃક્ત હાઇડ્રોકાર્બન
આલ્કાઈન (Alkyne) નું સામાન્ય સૂત્ર: CnH(2n-2)
n = કાર્બન પરમાણુઓની સંખ્યા (n ≥ 2) · SI: N/A (આણ્વીય સૂત્ર) · એક C≡C ત્રિબંધ ધરાવતો એકમીય અસંપૃક્ત હાઇડ્રોકાર્બન
બેન્ઝીન અને સદૃશ અરોમેટિક્સનું સામાન્ય સૂત્ર: CnH(n-6) (n ≥ 6)
n = કાર્બન પરમાણુઓની સંખ્યા; તે બેન્ઝીન રિંગ + બાહ્ય શૃંખલાના કાર્બનનું કુલ છે · SI: N/A (આણ્વીય સૂત્ર) · એક બેન્ઝીન રિંગ ધરાવતો એકમીય અરોમેટિક હાઇડ્રોકાર્બન
હક્કલનો નિયમ (Hückel's Rule) — અરોમેટિસિટી: π ઇલેક્ટ્રોનની સંખ્યા = (4n + 2) જ્યાં n = 0, 1, 2, …
n = પૂર્ણાંક (0,1,2…); 4n+2 = 2, 6, 10, 14… ઇલેક્ટ્રોન · SI: N/A (ચુંબકીય પ્રબળતાનો નિયમ) · સમતલીય, વર્તુળાકાર, સાંતત્યુલન (conjugated) પદ્ધતિ માટે લાગુ; આ ઇલેક્ટ્રોન સંખ્યા ધરાવતું સંયોજન અરોમેટિક ગણાય
હાઇડ્રોજનનો અભાવ અથવા અસંતૃપ્તિ સૂચકાંક (DBE / IHD): DBE = C - (H/2) + (N/2) + 1
C = કાર્બન પરમાણુ સંખ્યા; H = હાઈડ્રોજન (અને હેલોજન) સંખ્યા; N = નાઈટ્રોજન સંખ્યા; O અને S ને અવગણો · SI: N/A (એકમહીન) · બિન-અરોમેટિક અને અરોમેટિક બંને સંયોજનો માટે; DBE = 1 એક દ્વિબંધ અથવા એક રિંગ, DBE = 4 બેન્ઝીન રિંગ (3 દ્વિબંધ + 1 રિંગ)
બંધ લંબાઈ — C–C (આલ્કેન/sp³–sp³): 1.54 Å (154 pm)
Å = એંગ્સ્ટ્રોમ; 1 Å = 10⁻¹⁰ m · SI: મીટર (m) · સામાન્ય સિંગલ બંધ, sp³–sp³ કાર્બન વચ્ચે
બંધ લંબાઈ — C=C (આલ્કીન/sp²–sp²): 1.34 Å (134 pm)
C=C = દ્વિબંધ; Å = એંગ્સ્ટ્રોમ · SI: મીટર (m) · સામાન્ય ઓલિફિનિક દ્વિબંધ
બંધ લંબાઈ — C≡C (આલ્કાઈન/sp–sp): 1.20 Å (120 pm)
C≡C = ત્રિબંધ; Å = એંગ્સ્ટ્રોમ · SI: મીટર (m) · સામાન્ય આલ્કાઈનિક ત્રિબંધ
બંધ લંબાઈ — બેન્ઝીનમાં C–C (અર્ધ-બંધ): 1.39–1.40 Å (139–140 pm)
બધા છ C–C બંધ બેન્ઝીનમાં સમાન લંબાઈના હોય છે (અનુનાદ કારણે) · SI: મીટર (m) · અરોમેટિક રિંગમાં, π ઇલેક્ટ્રોનના સંપૂર્ણ વિસ્થાનિતકરણ (delocalization) પછી
આલ્કીનની દહન પ્રક્રિયા (Combustion): CnH(2n) + (3n/2) O₂ → n CO₂ + n H₂O + ઉષ્મા
n = કાર્બન સંખ્યા; O₂ = આક્સિજન; CO₂ = કાર્બન ડાયಆક્સાઈડ; H₂O = જળ · SI: kJ/mol (ઉષ્મામાપન) · પૂર્ણ દહન; પ્રતિ મોલ આલ્કીનને (3n/2) મોલ O₂ જોઈએ
આલ્કાઈનની દહન પ્રક્રિયા: CnH(2n-2) + ((3n-1)/2) O₂ → n CO₂ + (n-1) H₂O + ઉષ્મા
n = કાર્બન સંખ્યા; O₂ = આક્સિજન · SI: kJ/mol (ઉષ્મામાપન) · પૂર્ણ દહન
માર્કોવ્નિકોનો નિયમ (Markovnikov's Rule): H⁺ પહેલાં તે C પર જોડાય જેના પર હાઈડ્રોજન વધુ હોય; દ્વિબંધ પરનો X⁺/ઇલેક્ટ્રોફાઈલ તે C પર જોડાય જે વધુ સ્થિર કાર્બોકેટાયન (_carbonium ion_) બનાવે.
CX = હેલોજનદાર સંયોજન; હાઈડ્રોજન સંખ્યા = દ્વિબંધના બંને C પર લગ્તું H · SI: N/A (નિયમ) · એકطرفા C=C ધરાવતા આલ્કીન સાથે પ્રોટિક એસિડ અથવા હેલોજનદાર સંયોજનનો સંયોજન (electrophilic addition)
પ્રતિ-માર્કોવ્નિકો સંયોજન (Anti-Markovnikov / Peroxide Effect): ROOR (પેરાઑક્સાઈડ) присутств的时候 HBr નું આલ્કીન સાથે સંયોજન → Anti-Markovnikov ઉત્પાદન
ROOR = ડાયઅલ્કાઈલ પેરાઑક્સાઈડ; HBr = હાઈડ્રોજન બ્રોમાઈડ · SI: N/A (નિયમ) · કેવલ HBr; HCl અને HI માટે પેરાઑક્સાઈડ અસર થતી નથી; તંત્ર મુક્ત-મૂળ (free-radical) ચેઇન
ઓસોનોલાઈઝિસ (Ozonolysis) — સીમા વિભાજન: C=C + O₃ → (Zwitterion) → Zn/H₂O → R-CHO અથવા R-CO-R' + HCHO
O₃ = ઓઝોન; Zn/H₂O = reducing work-up; RCHO = એલ્ડીહાઈડ; RCOR' = કેટોન · SI: N/A (પ્રક્રિયા) · સીમા બંધ તોડવા માટે; સ્પ્લિટિંગ પછી દ્વિબંધના બંને C પરના યુગ્મક અણુઓ જણાય છે
કેટોનિક પ્રક્ષયન (Keto-Enol Tautomerism): R-CH=CH-OH ⇌ R-CO-CH₃
એનોલ (Enol) ⇌ કેટોન (Keto); ⇌ = સંતુલન · SI: N/A (સંતુલન) · એસિડ અથવા પ્રતિષ્ઠાન (base) પ્રેરિત; sp² C=C-OH ધરાવતા સંયોજનમાં
ઇલેક્ટ્રોફિલિક એરોમેટિક સ્થાનાંતરણ — નાયટ્રેશન (Nitration): C₆H₆ + HNO₃ --(H₂SO₄)--> C₆H₅NO₂ + H₂O
HNO₃ = નાયટ્રિક એસિડ; H₂SO₄ = સંયુગ્મક એસિડ (કેટાલિસ્ટ); NO₂⁺ = નાયટ્રોનિયમ આયન (ઇલેક્ટ્રોફાઈલ) · SI: mol (મોલ) · સાંદ્ર H₂SO₄ વડે NO₂⁺ ઉત્પન્ન થાય છે; તાપમાન ~50–60°C
ઇલેક્ટ્રોફિલિક એરોમેટિક સ્થાનાંતરણ — સલ્ફોનેશન (Sulfonation): C₆H₆ + H₂SO₄(conc.) --(heat)--> C₆H₅SO₃H + H₂O
SO₃ = સલ્ફ્યુરિક એસિડમાંથી ઉત્પન્ન થતો ઇલેક્ટ્રોફાઈલ; SO₃H = સલ્ફોનિક એસિડ સમૂહ · SI: mol · સાંદ્ર H₂SO₄ અથવા ફ્યુમિંગ H₂SO₄ (oleum) નો ઉપયોગ
વર્ટઝ પ્રક્રિયા (Wurtz Reaction) — આલ્કેન નિર્માણ: 2 R-X + 2 Na → R-R + 2 NaX (શુષ્ક ઈથરમાં)
R = અલ્કાઈલ સમૂહ; X = હેલોજન (Cl, Br, I); Na = સોડિયમ; ઈથર = દ્રાવક · SI: mol · સમમિતિ આલ્કેનનું નિર્માણ; ઈથેન, બ્યુટેન વગેરે; R-X એકસમાન હોવું જોઈએ
ડિહાઈડ્રોહેલોજેનેશન (Dehydrohalogenation) — β-એલિમિનેશન: R-CH₂-CH₂-X + alc.KOH → R-CH=CH₂ + KX + H₂O
alc.KOH = અલ્કોહોલિક KOH; X = હેલોજન; β-H અને X પાশ્વે છેડાથી દૂર થાય છે · SI: mol · હેલોજનઅલ્કેનથી આલ્કીન બનાવવા; ઝાડળીવાળા (Zaitsev) નિયમ મુજબ વધુ સ્થિર (વધુ વિસ્થાપિત) આલ્કીન મુખ્ય ઉત્પાદન
ઝાડળીવાળા નિયમ (Zaitsev's Rule): એલિમિનેશનમાં વધુ સબ્સ્ટિટ્યુએન્ટ ધરાવતો આલ્કીન = વધુ સ્થિર = મુખ્ય ઉત્પાદન
સબ્સ્ટિટ્યુએન્ટ = अल्काइल સમૂહ; sp² C પર R ની સંખ્યા વધે તો stabilities વધે · SI: N/A (નિયમ) · β-એલિમિનેશન અને આલ્કીનની સ્થિરતા આગાહી
ઓકસિડેશન — KMnO₄ સાથે (Bayer's સૂત્ર/પરીક્ષણ): C=C + KMnO₄(aq, cold, dil.) + OH⁻ → HO-CH₂-CH₂-OH + MnO₂↓
KMnO₄ = પરમાંગनेट; cold/dilute = સીમા diol બનાવે; MnO₂ = ભૂરો沉淀 · SI: mol · ઠંડા, તંદુરસ્ત, ક્ષારક KMnO₄; C=C ને cis-diol માં પરિવર્તિત કરે; અરોમેટિક્સ સાથે ક્રિયા નથી
ઑક્સિડેશન — O₃/Zn,H₂O (ઓસોનોલાઈઝિસ) બેન્ઝીનના એકાઉન્ટ માટે: C₆H₆ → (3 CH≡CH) એલ્કાઈનની तुलना; બેન્ઝીન O₃/H₂O સાથે glyoxal (CHO-CHO) આપે
glyoxal = CHO-CHO; O₃ = ઓઝોન · SI: mol · બેન્ઝીન અરોમેટિક હોવાથી ઓઝોન સાથે easy cleavage નથી; પરંતુ harsh conditions માં glyoxal મળે
ડી-હાઈડ્રેશન (Dehydration) — આલ્કોહોલથી આલ્કીન: R-CH₂-CH₂-OH --(conc. H₂SO₄, 170°C)--> R-CH=CH₂ + H₂O
conc.H₂SO₄ = નિર્જલીકરણ એજન્ટ; તાપ ~170°C ( primary ) / ~140°C (secondary/tertiary) · SI: °C (તાપમાન) · ઘન H₂SO₄ અથવા Al₂O₃ Catalyst વડે; Zaitsev નિયમ લાગુ

🔗 સંબંધો

  • DBE (Degree of Unsaturation) = અણુમાં રિંગ + π બંધ કુલ સંખ્યા; બેન્ઝીન માટે DBE = 4 (3 π બંધ + 1 રિંગ)
  • બંધ લંબાઈનો ક્રમ: C≡C < C=C < C–C (ત્રિબંધ < દ્વિબંધ < એકબંધ); sp–sp < sp²–sp² < sp³–sp³
  • બંધ કોન: sp³ = 109.5°, sp² = 120°, sp = 180°
  • આલ્કેન → આલ્કીન → આલ્કાઈન ક્રમમાં એનથાલ્પી ઓફ હાઈડ્રોજેનશન વધે છે (more unsaturation → more heat released per mol H₂)
  • બોઇલિંગ પોઇન્ટ: મોલેક્યુલર માસ વધે તો વધે; શાખા (branching) વધે તો ઘટે
  • અરોમેટિક સ્થિરતા (Resonance Energy): બેન્ઝીન ≈ 152 kJ/mol; અનુનાદ (resonance) ને કારણે બેન્ઝીન સામાન્ય આલ્કીન કરતાં ઓછું પ્રક્રિયાશીલ છે
  • હક્કલ નિયમ 4n+2 મુજબ: n=0→2e⁻, n=1→6e⁻ (બેન્ઝીન), n=2→10e⁻ (નાપ્થાલીન), n=3→14e⁻
  • Markovnikov ઉત્પાદન = વધુ સ્થિર કાર્બોકેટાયન મધ્યમસ્થ; Anti-Markovnikov = મુક્ત-મૂળ (radical) મધ્યમસ્થ

🎯 ટ્રિક્સ

DBE શોધવાની ઝડપી રીત: H₂ ના અભાવ / 2 = DBE. ઉદા: C₆H₆ માટે H₂ = (14-6)/2 = 4; તેથી DBE = 4 (બેન્ઝીન)
Wurtz પ્રક્રિયામાં બંને R એકસમાન હોય તો જ સમમિતિ આલ્કેન Bn = 2n+2 મળે; વિષમ હોય તો મિશ્રણ
