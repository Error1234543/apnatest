સંતુલન (Equilibrium)

🩺 NEET UG — Gujarati • Chemistry • Equilibrium

સંતુલનનો પરિચય
સંતુલન એટલે જ્યારે કોઈ પ્રક્રિયામાં આગળ અને પાછળની પ્રક્રિયાઓની ગતિ સરખી થઈ જાય છે.
સંતુલન દરમિયાન પ્રક્રિયકો અને ઉત્પાદનોની સાંદ્રતા સ્થિર રહે છે.
સંતુલન દરમિયાન પ્રક્રિયા ચાલુ રહે છે, પરંતુ શુદ્ધ ફેરફાર શૂન્ય હોય છે.
📝 સંતુલન એ ગતિશીલ (Dynamic) અવસ્થા છે.
સંતુલનના પ્રકાર
રાસાયણિક સંતુલન (Chemical Equilibrium): જ્યારે પ્રક્રિયકો અને ઉત્પાદનો વચ્ચેની પ્રક્રિયા સંતુલિત થાય છે.
ભૌતિક સંતુલન (Physical Equilibrium): જ્યારે પદાર્થની ભૌતિક અવસ્થાઓ (ઘન, દ્રવ, વાયુ) વચ્ચે સંતુલન સ્થાપિત થાય છે.
ભૌતિક સંતુલનના ઉદાહરણ: બાષ્પીકરણ અને ઘનીકરણ વચ્ચેનું સંતુલન.
લે ચેટેલિયરનો સિદ્ધાંત (Le Chatelier’s Principle)
જો સંતુલન પર કોઈ બાહ્ય પરિબળ (જેવા કે સાંદ્રતા, દબાણ, તાપમાન) લાગુ પડે, તો સંતુલન તે પરિબળના પ્રભાવને ઘટાડવા માટે વળે છે.
ઉદાહરણ: N₂ + 3H₂ ⇌ 2NH₃ પ્રક્રિયામાં H₂ની સાંદ્રતા વધારવાથી NH₃ની માત્રા વધે છે.
📝 સિદ્ધાંત ફક્ત સંતુલન અવસ્થામાં જ લાગુ પડે છે.
સંતુલન અચળાંક (Equilibrium Constant)
સંતુલન અચળાંક (K) એ ઉત્પાદનોની સાંદ્રતાનો ગુણાકાર અને પ્રક્રિયકોની સાંદ્રતાનો ગુણાકારના ગુણોત્તર દર્શાવે છે.
K = [ઉત્પાદનો] / [પ્રક્રિયકો]
K નું મૂલ્ય તાપમાન પર આધાર રાખે છે.
જો K > 1, તો પ્રક્રિયા ઉત્પાદનો તરફ વળે છે. જો K < 1, તો પ્રક્રિયા પ્રક્રિયકો તરફ વળે છે.
📝 K નું મૂલ્ય સાંદ્રતા અથવા દબાણ પર આધાર રાખતું નથી.
સંતુલન અચળાંકના પ્રકાર
Kₚ (દબાણ સંતુલન અચળાંક): વાયુઓની પ્રક્રિયાઓ માટે વાપરવામાં આવે છે.
Kₚ = (P₁^a * P₂^b) / (P₃^c * P₄^d)
K_c (સાંદ્રતા સંતુલન અચળાંક): દ્રાવણમાં થતી પ્રક્રિયાઓ માટે વાપરવામાં આવે છે.
K_c = [C]^c [D]^d / [A]^a [B]^b
Kₚ અને K_c વચ્ચેનો સંબંધ: Kₚ = K_c (RT)^Δn, જ્યાં Δn = વાયુઓના મોલની સંખ્યામાં ફેરફાર.
સંતુલનમાં સાંદ્રતા, દબાણ અને તાપમાનનો પ્રભાવ
સાંદ્રતા: પ્રક્રિયકની સાંદ્રતા વધારવાથી ઉત્પાદનોની માત્રા વધે છે.
દબાણ: દબાણ વધારવાથી તે દિશામાં પ્રક્રિયા વળે છે જ્યાં વાયુઓના મોલની સંખ્યા ઓછી હોય.
તાપમાન: ઉષ્માશોષક પ્રક્રિયા (Endothermic) માટે તાપમાન વધારવાથી ઉત્પાદનોની માત્રા વધે છે.
તાપમાન ઘટાડવાથી ઉષ્માઉત્પાદક પ્રક્રિયા (Exothermic) તરફ સંતુલન વળે છે.
આયનિક સંતુલન (Ionic Equilibrium)
પાણીમાં દ્રાવ્ય આયનો ધરાવતા પદાર્થો માટે લાગુ પડે છે.
ઓસ્ટવાલ્ડનો પાતળા દ્રાવણનો સિદ્ધાંત (Ostwald’s Dilution Law): K_a = α²C / (1 - α), જ્યાં α = આયનીકરણનો ડિગ્રી.
K_w = [H⁺][OH⁻] = 10⁻¹⁴ (25°C પર)
pH = -log[H⁺], pOH = -log[OH⁻], pH + pOH = 14
📝 K_w નું મૂલ્ય તાપમાન પર આધાર રાખે છે.
એસિડ-બેઇઝ સંતુલન
બ્રોન્સ્ટેડ-લોઅરી સિદ્ધાંત: એસિડ પ્રોટોન દાતા અને બેઇઝ પ્રોટોન ગ્રાહક હોય છે.
લુઈસ સિદ્ધાંત: એસિડ ઇલેક્ટ્રોન યુગ્મ ગ્રાહક અને બેઇઝ ઇલેક્ટ્રોન યુગ્મ દાતા હોય છે.
સંયુગ્મ એસિડ-બેઇઝ જોડી (Conjugate Acid-Base Pair): એસિડ અને બેઇઝ જ્યાં એક પ્રોટોનનો ફેરફાર હોય.
K_a * K_b = K_w
બફર દ્રાવણ (Buffer Solution)
બફર દ્રાવણ એવું દ્રાવણ છે જે pHમાં થતા ફેરફારને વિરોધ કરે છે.
બફર દ્રાવણ બનાવવા માટે મજબૂત એસિડ અને તેના સંયુગ્મ બેઇઝ અથવા મજબૂત બેઇઝ અને તેના સંયુગ્મ એસિડની જરૂર પડે છે.
હેન્ડરસન-હેસલબેક સમીકરણ: pH = pK_a + log([A⁻]/[HA])
📝 બફર દ્રાવણનો ઉપયોગ રાસાયણિક પ્રયોગશાળામાં અને જૈવિક પ્રણાલીઓમાં થાય છે.
દ્રાવ્યતા સંતુલન (Solubility Equilibrium)
દ્રાવ્યતા ગુણાકાર (K_sp): અદ્રાવ્ય પદાર્થના આયનોની સાંદ્રતાનો ગુણાકાર.
K_sp = [A⁺]^m [B⁻]^n
જો આયનિક ગુણાકાર (Q) < K_sp, તો અવક્ષેપ દ્રાવણમાં દ્રાવી શકે છે.
જો Q > K_sp, તો અવક્ષેપ પડે છે.
📝 K_sp નું મૂલ્ય તાપમાન પર આધાર રાખે છે.
સંતુલનમાં ઉદાહરણો અને અભ્યાસ
હેબર પ્રક્રિયા: N₂ + 3H₂ ⇌ 2NH₃ (ઉષ્માઉત્પાદક પ્રક્રિયા)
કોન્ટેક્ટ પ્રક્રિયા: 2SO₂ + O₂ ⇌ 2SO₃ (ઉષ્માશોષક પ્રક્રિયા)
સંતુલનની ગણતરીઓ માટે સાંદ્રતા, દબાણ અને તાપમાનનો યોગ્ય ઉપયોગ કરો.
📝 પ્રયોગશાળામાં સંતુલનનો અભ્યાસ કરવા માટે રંગ પરિવર્તનનો ઉપયોગ થઈ શકે છે.
સંતુલનના મહત્વના સૂત્રો
ΔG = ΔG° + RT ln Q
ΔG° = -RT ln K
જો ΔG° < 0, તો પ્રક્રિયા સ્વત:સ્ફૂર્તિ (Spontaneous) છે.
📝 ΔG° નું મૂલ્ય સંતુલન અચળાંક K સાથે સંબંધ ધરાવે છે.
