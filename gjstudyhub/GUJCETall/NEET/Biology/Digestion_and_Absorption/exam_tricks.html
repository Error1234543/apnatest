પાચન અને શોષણ — GUJCET એક્ઝામ ટ્રિક્સ

🧪 GUJCET — Gujarati • Biology • Digestion and Absorption

🎯 પરીક્ષા ટ્રિક્સ

બહુવિકલ્પમાં 'ભાગ નહીં' પૂછે ત્યારે સૌથી મોટું / સૌથી નાનું સરળતાથી બાદ કરો: પાચનતંત્રનો સૌથી લાંબો ભાગ (છોટું આંતરડું) અને સૌથી નાનો સ્રાવગ્રંથિ (લાળ ગ્રંથિઓ) હોય છે.
જ્યારે પ્રશ્નમાં 'કયા અંગની ભૂમિકા સાચી નથી?' અથવા 'સાચું ન હોવું' પ્રકારનો પ્રશ્ન આવે.
દા.ત.: કેટલાક વિકલ્પોમાં 'લાળ ગ્રંથિ જઠરામ્લનું ઉત્પાદન કરે છે' જેવો નાસ્તોવાળો વિકલ્પ હોય છે — તે તરત બાદ કરી શકાય.
એન્ઝાઇમ — સબસ્ટ્રેટ જોડાણ યાદ રાખવા માટે અંત્યસ્થ વર્ણ (letter) સંકેત: P-Trypsin → Protein; L-Lipase → Lipid (Fat); S-Sucrase → Sucrose; M-Maltase → Maltose.
એન્ઝાઇમનું કાર્ય ઓળખવાનો પ્રશ્ન આવે, ખાસ કરીને ચુકેલા વિકલ્પોમાં ઊલટું ફેંકાયેલું હોય.
દા.ત.: જો વિકલ્પમાં 'લાઇપેઝ પ્રોટીનનું પાચન કરે છે' લખ્યું હોય તો તરત ખોટો ગણો.
કલ્લા (Bile) — 'પાચન એન્ઝાઇમ' નથી; ફક્ત 'સ્નાહિકરણ' (Emulsification) કરે છે. તે ચરબીના વડા ટીપાંને નાના ટીપાંમાં વિભાજિત કરે છે.
જ્યારે પ્રશ્ન પૂછે કે 'કલ્લો કયા પ્રકારની પાચક પ્રક્રિયા કરે છે?' અથવા 'કલ્લામાં કયો એન્ઝાઇમ હોય છે?'
દા.ત.: 'કલ્લો લિપેઝ ધરાવે છે' — આ ગલત છે; કલ્લામાં કોઈ પણ એન્ઝાઇમ હોતો નથી.
જઠર (Stomach) = પ્રોટીન પાચનનું મુખ્ય કેન્દ્ર; છોટું આંતરડું = શોષણનું મુખ્ય કેન્દ્ર. આ બે વાક્ય યાદ રાખો → 2-3 પ્રશ્નો સરળ.
પાચન / શોષણના સ્થાન સંબંધી પ્રશ્ન આવે. ઉદા. 'પ્રોટીનનું રાસાયણિક પાચન ક્યાં શરૂ થાય છે?'.
દા.ત.: 'જઠરમાં પ્રોટીનનું રાસાયણિક પાચન શરૂ થાય છે' સાચું છે. 'છોટા આંતરડામાં પ્રોટીન પાચન શરૂ થાય છે' ગલત છે — તે ત્યાં પૂરું થાય છે, શરૂ થતું નથી.
હેપેટોપેન્ક્രിયાટિક નલિકા (Hepatopancreatic duct) → ડ્યુઓડેનમમાં પ્રવેશે છે; આ યાદ રાખો: 'હેપેટો' = કબજો (Liver), 'પેન્ક્રિયાટિક' = અગ્નાશય, બંનેનો દ્રવ ડ્યુઓડેનમમાં જાય છે.
શરીરરચના સંબંધી પ્રશ્ન જેમાં નલિકાનું સ્થાન પૂછાય.
દા.ત.: 'હેપેટોપેન્ક્રીયાટિક નલિકા જઠરમાં પ્રવેશે છે' — ગલત; ડ્યુઓડેનમમાં પ્રવેશે છે.
જઠરરસમાં 'પેપ્સિન' સક્રિય રૂપે હોય છે, 'પેપ્સિનોજન' નહીં. જ્યારે અગ્ન્નાશયરસમાં 'ટ્રાયપ્સિન' સક્રિય હોય, 'ટ્રાયપ્સિનોજન' નહીં. નામના અંતે '-જન' હોય તો તે સક્રિય નથી.
એન્ઝાઇમના સક્રિય / નિષ્ક્રિય રૂપ સંબંધી પ્રશ્ન આવે.
દા.ત.: 'પેપ્સિનોજન પ્રોટીનનું પાચન કરે છે' — ગલત; તે નિષ્ક્રિય છે, HCl મળતા પેપ્સિન બને છે.
મોઢું (Buка) = શુદ્ધ તંત્રાશી પાચન; જઠર = અંશત: પ્રોટીન પાચન; છોટું આંતરડું = સંપૂર્ણ પાચન અને શોષણ. આ સ્તર-રચના યાદ રાખો.
'પાચન ક્યાં-ક્યાં થાય છે?' પ્રકારના પ્રશ્નમાં ત્વરિત નિર્ણય કરવા.
દા.ત.: 'મોઢામાં શર્કરાનું સંપૂર્ણ પાચન થાય છે' — ગલત; ફક્ત અંશતઃ (શરૂઆત) થાય છે.
વિટામિન B₁₂ અને વિટામિન A નું શોષણ 'કોઇલેક' ( ileum ) માં થાય છે — આ બે વિટામિનોના શોષણનું સ્થાન અલગ છે તે યાદ રાખવા, બધા રોગિણીકારક પ્રશ્નોમાં વપરાય છે.
શોષણના વિશિષ્ટ સ્થાન સંબંધી પ્રશ્ન આવે.
દા.ત.: 'વિટામિન B₁₂ નું શોષણ મોટા આંતરડામાં થાય છે' — ગલત; કોઇલેક (Ileum) માં થાય છે.
મોટું આંતરડું (Large intestine) = પાણી, ખનિજ લવણોનું શોષણ + ફેકેસ સંગ્રહ. તેમાં પોષકતત્વોનું મહત્વપૂર્ણ શોષણ થતું નથી.
જ્યારે વિકલ્પોમાં 'મોટા આંતરડામાં ગ્લુકોઝ / અમિનો એસિડનું શોષણ' જેવો ભ્રામક વિકલ્પ મળે.
દા.ત.: 'મોટા આંતરડામાં ગ્લુકોઝનું શોષણ થાય છે' — ગલત; તેનું શોષણ છોટા આંતરડામાં થાય છે.
ચહે (Teeth) ની સંખ્યા: ક્ષતિસ્થ (Childhood) = 20, પૂર્ણ (Adult) = 32. દાઢ (Wisdom teeth) = 4 (ચોથા મોલર્સ).
'કુલ દાઢની સંખ્યા' પ્રકારના પ્રશ્નમાં.
દા.ત.: 'પૂર્ણ વયના વ્યક્તિમાં કુલ દાઢની સંખ્યા 32 છે' સાચું છે. '36' અથવા '28' જેવા વિકલ્પો ટાળવા.
ઇન્યુમ (Enamel) = શરીરનું સૌથી કઠણ કલાલ — તમામ પ્રશ્નોમાં યાદ રાખો: કોષો ન હોય, ફક્ત ખનિજ (Calcium phosphate).
'ઇન્યુમ સંબંધી કયું વિધાન ગલત છે?' પ્રકારના પ્રશ્નમાં.
દા.ત.: 'ઇન્યુમ જીવંત કોષો ધરાવે છે' — ગલત; તે અકોષીય (non-cellular) છે.
દરેક પાચક રસ (Digestive juice) નું યાદગાર સૂત્ર: લાળ = pH ન્યૂટ્રલ ≈ 6.8; જઠરરસ = pH < 2 (અત્યંત ઝીણો); આંતરરસ = pH > 7 (ઉષ્મ).
pH સંબંધી પ્રશ્નો, ખાસ કરીને 'કયા પાચક રસનો pH સૌથી ઓછો છે?' જેવા પ્રશ્નો.
દા.ત.: 'જઠરરસનો pH 7.5 છે' — ગલત; તે 1.5-2.0 ની આસપાસ હોય છે.
પાચન સંબંધી ત્રુટિઓ: પેપ્ટિક અલ્સર = જઠર/ડ્યુઓડેનમ; બ્લેડ = કબજો (Liver); પિત્તાશયપીડા = ગેલબ્લેડર; પેન્ક્રિયાટાઇટિસ = અગ્ન્નાશય.
'કઈ રોગ કયા અંગની છે?' પ્રકારના પ્રશ્નમાં.
દા.ત.: 'બ્લેડ (Jaundice) એ પાણીનું રોગ છે' — ગલત; તે કબજા (Liver) નો રોગ છે.
કાર્ડિયક સ્ફિન્ક્તર → એસોફેગસ અને જઠર વચ્ચે; પાયલોરિક સ્ફિન્ક્તર → જઠર અને ડ્યુઓડેનમ વચ્ચે. 'કાર્ડિયક' = હૃદયની નજીક (ઉપર); 'પાયલોરિક' = પાયલોરસ (નીચે).
'સ્ફિન્ક્તરનું સ્થાન' પ્રકારનો પ્રશ્ન આવે.
દા.ત.: 'પાયલોરિક સ્ફિન્ક્તર એસોફેગસ અને જઠર વચ્ચે છે' — ગલત; તે જઠર અને ડ્યુઓડેનમ વચ્ચે છે.
મикроવિલી (Villi) = છોટા આંતરડાની આંતરિક સપાટી વધારે છે; તે 'શોષણ' માટે છે, 'પાચન' માટે નહીં. પ્રશ્નમાં 'શોષણ' અને 'પાચન' શબ્દો પર ધ્યાન આપો.
'વિલીનું કાર્ય શું છે?' પ્રકારના પ્રશ્નમાં જ્યારે વિકલ્પોમાં પાચન અને શોષણનો ભ્રમ હોય.
દા.ત.: 'વિલી પાચક એન્ઝાઇમ છૂટા કરે છે' — ગલત; વિલી ફક્ત શોષણ વધારે છે, પાચન એન્ઝાઇમ આંતરરસમાંથી મળે છે.
