Neural Control and Coordination — GUJCET Exam Tricks

🧪 GUJCET — Gujarati • Biology • Neural Control and Coordination

🎯 પરીક્ષા ટ્રિક્સ

Dendron ↔ Dendrite vs. Axon distinction: જેટલા 'ડે' અક્ષરો વધારે, તેટલું સંકેત મેળવવાનું કામ. Dendrites (વિભાજિત નાના શાખાઓ) સંકેત **સ્વીકારે**; Axon (એક લાંબો તંતુ) સંકેત **આગળ પહોંચાડે**. દૃશ્યમાં યાદ રાખો: Dendrites → 'Do Enter' (અંદર આવે); Axon → 'Away' (બહાર જાય).
જ્યારે પ્રશ્નમાં ન્યુરોનના ભાગોનું કાર્ય પૂછાય અને વિકલ્પો વચ્ચે ગૂંચવણ હોય.
દા.ત.: 'સંકેતને ન્યુરોનમાં પ્રવેશાડનાર ભાગ કયો?' → Dendrites. 'સંકેત બહાર નિકાલતા ભાગ'? → Axon.
રેસ્ટિંગ પોટેન્શિયલ (-70 mV) = 'Na⁺ બહાર, K⁺ અંદર'. સહજ સ્થિતિમાં કોષ બહાર Na⁺ વધુ અને અંદર K⁺ વધુ. આ યાદ રાખવાની ટૂંકી ચાલ: 'બહાર Na, અંદર K, બેરિંગ (Na/K pump) ચાલુ.'
રેસ્ટિંગ પોટેન્શિયલ અને Na⁺/K⁺ પંપ બંધારણ સંબંધિત પ્રશ્નોમાં.
દા.ત.: 'રેસ્ટિંગ પોટેન્શિયલ ધરાવતી દશામાં કયા આયનોનું સાંદ્રણ ગ્રેડિયન્ટ કેવું હોય?' → Na⁺ વધુ બહાર, K⁺ વધુ અંદર.
యాક્શન પોટેન્શિયલ = 'સોડિયમ દરવાઝો ખુલે → ડિપોલરાઇઝેશન → પોટેશિયમ નીકળે → રિપોલરાઇઝેશન'. અક્ષરક્રમ યાદ રાખો: **Na⁺ IN → K⁺ OUT**. ડિપોલરાઇઝેશન માટે Na⁺ અંદર, રિપોલરાઇઝેશન માટે K⁺ બહાર.
ઍક્શન પોટેન્શિયલના તબક્કા અથવા વિષમ વિકલ્પોવાળા પ્રશ્નોમાં.
દા.ત.: 'ડિપોલરાઇઝેશન દરમિયાન કયા આયનનો પ્રવાહ થાય?' → Na⁺ અંદર.
માઇલિન શીધ (Myelin sheath) = 'ઇન્સ્યુલેશન'; સોલ્ટેટરી કન્ડક્શન = 'રસ્તો બચાવો, ઝડપ વધારો'. મેશનલ ગાંઠ (Node of Ranvier) એ 'ખુલ્લી જગ્યા' જ્યાં આયન ચેનલો જમા થાય છે. ઉલટાનો યાદ રાખો: **'માઇલિન = ઝડપ, ગાંઠ = પમ્પિંગ'**, પણ સાવચેત: ગાંઠ પર પંપ હોતો નથી — Na⁺/K⁺ પંપ સમગ્ર અક્ષતંતુ પર વિસર્જાયેલો હોય છે.
માઇલિનેશન અને સોલ્ટેટરી કન્ડક્શન સંબંધિત પ્રશ્નોમાં.
દા.ત.: 'સોલ્ટેટરી કન્ડક્શન ક્યાં થાય?' → મેશનલ ગાંઠો પર. 'માઇલિન શીધની હાજરીથી શું થાય?' → વેગ વધે.
સિનેપ્સ = 'રાસાયણિક': અથડામણ = 'વિદ્યુત' (Electrical synapse = rare/special case). સામાન્ય GUJCET પ્રશ્નમાં 'સિનેપ્સ' શબ્દ આવે ત્યારે **રાસાયણિક** જ ધારો. ન્યુરોટ્રાન્સમિટર = રાસાયણિક સંદેશવાહક. યાદ રાખો: **'Chemical synapse = Cytosol + Vesicle + Receptor'** — ત્રણેય હોવા જોઈએ.
સિનેપ્સના પ્રકાર અને ન્યુરોટ્રાન્સમિટર સંબંધિત પ્રશ્નોમાં.
દા.ત.: 'રાસાયણિક સિનેપ્સમાં સંકેતનું સંચારણ કેવી રીતે થાય?' → યુગ્મક કોષિકા (Presynaptic) થી ન્યુરોટ્રાન્સમિટર મુક્ત થઈને પછીના કોષની ઝიલલી પર રિસેપ્ટર સાથે જોડાય.
સ્વયં-ઇન્દ્રિય तंत्रिका系统 = दो भाग: **Sympathetic = 'Fight or Flight' (युद्ध/प्रतिकार)**, **Parasympathetic = 'Rest and Digest' (विश्राम/पाचन)**. SYMPATHETIC → S = Stress; PARASYMPATHETIC → P = Peace. उल्टे विकल्प मिलें तो तुरंत排除 करा.
SNA ના બે ભાગો અને તેમના કાર્યો સંબંધિત પ્રશ્નોમાં.
દા.ત.: 'આંખના ગોળાનું કદ વિસ્તૃત કરનાર (dilates pupil) કયો?' → Sympathetic. 'પાચનક્રિયા ઉત્તેજિત કરનાર'? → Parasympathetic.
મગજના વિભાગોનું કાર્ય મેળવવા માટે શબ્દસંબંધ યાદ કરો: **Midbrain (મધ્યમગજ) = Reflex (પરાવર્તન) + Vision/Hearing path)**, **Hindbrain (પછાતમગજ) = Vital signs (呼吸/हृदय)**, **Forebrain (पूर्वमगज) = Higher function (चेतना/याद)/Thalamus/Hypothalamus**. Hindbrain → H = Heart & Helth (breathing).
મગજના વિભાગો અને તેમના કાર્યો પચાવવા પ્રશ્નમાં.
દા.ત.: 'શ્વસન અને હૃદયગતિનું નિયંત્રણ કયા ભાગ દ્વારા?' → Medulla oblongata (hindbrain અંતર્ગત). 'ચેતના, સ્મૃતિ, વિચાર'? → Forebrain.
સેરિબેલમ = 'સંતુલન અને સ્નેહપૂર્વક કાર્ય'. જો પ્રશ્નમાં 'શરીરના સંતુલન', 'સ્નાયુસ્થિતિ', 'તૈયારી' શબ્દો આવે → સેરિબેલમ. ઉલટું: જો 'સ્મૃતિ/બૌદ્ધિક' શબ્દો આવે → સેરિબ્રલ કોર્ટેક્સ (forebrain).
સેરિબેલમ અને સેરિબ્રલ કોર્ટેક્સ વચ્ચે સ્પષ્ટતા જોઈએ.
દા.ત.: 'ચાલવા, દોડવા, ગ્રાઉન્ડ સંતુલનનું નિયંત્રણ'? → સેરિબેલમ. 'ભાષા, ચિંતન'? → સેરિબ્રલ કોર્ટેક્સ.
આંખ: **રોડ = Light (light intensity)**, **કોન = Color**. 'રોડ' = 'Road' ની જેમ distant light pick કરે; 'કોન' = 'Contact' color with brain. GUJCET માં 'અંધારામાં દેખાય' → રોડ; 'રંગની પસંદગી' → કોન.
આંખના ફોટોરીસેપ્ટર કોષો (રોડ અને કોન) કાર્ય સંબંધિત પ્રશ્નોમાં.
દા.ત.: 'અંધારામાં વस्तુઓ જોવા માટે જવાબદાર કોષ'? → રોડ કોષ. 'તીવ્ર પ્રકાશ અને રંગ દર્શન'? → કોન કોષ.
કૉર્કિયા (Cochlea) = 'Sound'; સેમિક્યુલર કૅનલ = 'Balance'. યાદ રાખો: **Cochlea → 'K' is for 'Kinetic/Key' → Hearing**. Semi-circular canals → 'Curve' → Body orientation.
કર્ણ (ઈયર) ના આંતરિક ભાગોના કાર્યો છૂટા પાડવા પ્રશ્નોમાં.
દા.ત.: 'શ્રવણ માટે જવાબદાર રચના'? → કૉર્કિયા. 'સંતુલન માટે'? → સેમિક્યુલર કૅનલ.
પરાવર્તન ચાપ (Reflex Arc) = 5 પગલાં: **રિસેપ્ટર → સેન્સરી → સેન્ટર → મોટર → એફેક્ટર**. અક્ષર ક્રમ R-S-C-M-E. આ ક્રમ ખોટો હોય તો જવાબ ખોટો ગણવો. ઉદાહરણ: જો સેન્સરી અને મોટર ગોઠવણી ઉલટી હોય → ખોટો વિકલ્પ.
પરાવર્તન ચાપના ઘટકોની ગોઠવણી પ્રશ્નોમાં.
દા.ત.: 'પરાવર્તન ચાપનો સાચો ક્રમ'? → R → S → C → M → E. કોઈ પણ વિકલ્પમાં C (સેન્ટર/Spinal cord) સેન્સરી પહેલાં હોય → ખોટો.
ગેંગ્લિયન vs ન્યુક્લિયસ: **Peripheral → Ganglion (beyond CNS)**, **CNS (Brain/Spinal cord) → Nucleus**. Yaad rakho: 'Ganglion = Gate outside CNS; Nucleus = Nest inside CNS.'
Nervous system ના anatomical terminology પ્રશ્નોમાં.
દા.ત.: 'CNS માં ન્યુરોન શરીરોના સમૂહનું નામ'? → Nucleus. 'PNS માં એવો સમૂહ'? → Ganglion.
ગ્રે મેટર (Grey matter) vs વ્હાઇટ મેટર (White matter): **Grey = Cell body rich (અંદર)** — Spinal cord માં Grey H-shaped center, Cortex બહાર. **White = Myelinated axons (બહાર)** — Spinal cord માં White外围, Brain cortex માં Grey outer layer. વિરોધાભાસ યાદ રાખો: Spinal cord માં Grey અંદર, Brain માં Grey બહાર.
Spinal cord અને Brain ની grey/white matter ગોઠવણી પ્રશ્નોમાં.
દા.ત.: 'સ્પೈનલ કર્ડમાં ગ્રે મેટર ક્યાં?' → મધ્યમાં H-આકારે. 'બ્રેનના કોર્ટેક્સમાં'? → બહારની પરત.
ન્યુરોટ્રાન્સમિટર વિકલ્પોમાં **Acetylcholine = Skeletal muscle + Synapse propagation**, **Serotonin/Norepinephrine = Mood/Arouse**. GUJCET માં સામાન્ય રીતે ACh (Acetylcholine) પ્રશ્ન બને છે — જો 'સંકેતનું રાસાયણિક સંચારણ' હોય, તો સામાન્ય સમાધાન ACh જ. પણ ધ્યાન:兴奋性 vs निवारक (Inhibitory) તફાવત જાણો.
ન્યુરોટ્રાન્સમિટર જોડાણ પ્રશ્નોમાં.
દા.ત.: 'સામાન્ય રીતે રાસાયણિક સિનેપ્સમાં પ્રધાન ન્યુરોટ્રાન્સમિટર'? → Acetylcholine.
પ્રશ્નમાં 'ઉચ્ચકક્ષાના નિયંત્રણ' (Higher control) આવે → **Cerebral cortex / Forebrain**. 'સ્વયં-સ્પષ્ટ વિકલ્પ' (Automatic/unconscious) આવે → **Medulla / Hypothalamus / Spinal cord**. Hypothalamus = 'Homeostasis king' — શરીર તાપમાન, ભુખ, પ્યાસ, જಲ સંતુલન તમામ.
તંત્રિકા વ્યવસ્થાના વિનિયોગ પ્રશ્નોમાં વિભાગો વચ્ચે વિકલ્પ વિભાજન કરવા.
દા.ત.: 'શરીરના તાપમાન અને પ્યાસનું નિયંત્રણ'? → હાયપોથેલેમસ. 'સ્પષ્ટ ચેતના અને વિચાર'? → સેરિબ્રલ કોર્ટેક્સ.
