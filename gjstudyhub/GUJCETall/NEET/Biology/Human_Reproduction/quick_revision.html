માનવ પ્રજନન (Human Reproduction) — ઝડપી રિવિઝન

🧪 GUJCET — Gujarati • Biology • Human Reproduction

🧠 યાદ રાખો

પુરૂષ પ્રજનન પદ્ધતિ: અंडકોષાષ (Testes) — અંતઃસ્ત્રાવીય અને બાહ્યસ્ત્રાવીય દોનું કાર્ય; અંડપિંડ (Scrotum) શરીરની બહાર કેમ? → અંડકોષાષનું તાપમાન શરીરના તાપમાન કરતાં 2–2.5°C ઓછું જરૂરી છે.
અંડકોષમાં સ્પર્મીય ઉત્પાદન: સ્પર્માટાન્જિય (Seminiferous tubules) માં સ્પર્મેટોજેનેસિસ; સમર્ટોસાઇટ્સ (Sertoli cells) પોષણ + Sperm maturation માં મદદ; Leydig (Interstitial) cells from testosterone synthesis.
સ્પર્મ સ્વરૂપ: શીર્ષ (ન્યુક્લીયસ + એક્રોઝોમ), મધ્યખંડ (Mitochondria — ઉર્જા), પુછાડો (Flagellum — ગતિ).
સ્પર્મ ઉત્પાદન પ્રમાણ: દરરોજ લાખો સ્પર્મ સર્વિલિસમાં ઉત્પન્ન થાય છે; સ્પર્મેટોજેનેસિસ ~74 દિવસમાં પૂર્ણ થાય છે.
સ્ત્રી પ્રજનન પદ્ધતિ: અંડપિંડ (Ovaries) — પ્રમાણ-સ્ત્રાવીય અને બાહ્યસ્ત્રાવીય; ફેલોપિયન નાળ (Oviduct/Fallopian tube) — નિષેચન (Fertilization) સામાન્ય રીતે આમ્પુલા (Ampulla) ખંડમાં થાય છે.
ઉત્પન્ન (Menses) ચક્ર: ~28/29 દિવસ; ગર્ભાશય (Uterus) — ડર્મી (Endometrium) થાય છે; અંડકોષપાક (Ovulation) LH peak (Luteinizing Hormone Surge) દ્વારા થાય છે; અંડકોષ વિસર્જન (Ovum) ફેલોપિયનમાં જાય છે.
અંડજનન (Oogenesis): શશ્વત (Primordial germ cells) → ઑઓગોનિયા → ઑઓસાઇટ પ્રથમ ક્રમ → Meiosis I પૂર્ણ થાય છે → પ્રથમ ઍક્સિલ (First Polar body) ની રચના → Ovulation પછી Meiosis II આગળ વધે છે → બીજો ઍક્સિલ (Second polar body) બને છે.
ગર્ભધારણ (Implantation): Blastocec (Blastocyst) મૉર્ફોલોજી — ટ્રોફોબ્લાસ્ટ (Trophoblast) + એન્ટિબ્લાસ્ટોરી (Inner cell mass); ઇમ્પ્લાન્ટેશન Ovulation પછી ~6–7 દિવસે થાય છે.
પ્રેગ્નેન્સી હોર્મોન્સ: hCG (Human Chorionic Gonadotropin) — ગર્ભાશયમાં પ્રેગ્નેન્સી જાળવે છે (Corpus luteum ને સક્રિય રાખે છે); પ્રોજેસ્ટેરોન, ઇસ્ટ્રોજેન, પ્રોલેક્ટિન, Oxytocin.
સમયરેખા: 3 માસમાં અંગ પ્રારંભ (Organogenesis); 5 માસમાં ભ્રૂણના હલનચલન (Fetal movements) + માતા દ્વારા અનુભવ; 9 માસમાં સંપૂર્ણ ભ્રૂણ (Full-term fetus) પ્રસ્તુત.
પ્રજનન સંક્રમણ બિંદુઓ (Contraceptive methods) — સંક્ષિપ્ત: બેરિયર (કંડોમ/ডায়ફ્રામ), IUD (Intrauterine Device), હોર્મોનલ (ઓરલ્સ, આઇપી), સર્જિકલ (Vasectomy/Pregnancy prevention).

⚡ ઝડપી સૂત્રો

સ્પર્મેટોજેનેસિસ: Spermatogonium (2n) → Meiosis I → Two secondary spermatocytes (n) → Meiosis II → Four spermatids (n) → Spermiogenesis → Four sperms (n).
Oogenesis: Oogonium (2n) → Primary oocyte (2n) → Meiosis I → Secondary oocyte (n) + First polar body (n) → Meiosis II → Ovum (n) + Second polar body (n) + Polar bodies.
LH/FSH નિયંત્રણ: Hypothalamus → GnRH → Pituitary → FSH + LH → Gonads; Negative feedback by Inhibin (Sertoli cells) અને Estradiol/Progesterone (ovaries).
Placental hormones: hCG (Day 8–12 post-fertilization), hPL (Human placental lactogen), Progesterone, Estrogen — all from Trophoblast / Placenta.
Embryonic development milestones: Zygote → Morula (day 3–4) → Blastocyst (day 5–6) → Implantation (day 6–7) → Gastrulation → Organogenesis (weeks 3–8).

✅ વન-લાઈનર્સ

અંડકોષાષમાં સ્પર્મ જનરેટ થાય છે, પણ testosterone Leydig cells માં બને છે.
અંડપિંડમાં ઑઓસાઇટ પ્રથમ ક્રમ Meiosis I અટકેલી રહે છે અંડપાક સુધી.
ફેલોપિયન નાળમાં જ નિષેચન થાય છે, અંડપિંડમાં નહીં.
LH surge → Ovulation (અંડપાક); FSH → Follicular development અને Sertoli function.
Corpus luteum → Progesterone અને આર્ધક (maintains endometrium); જો ગર્ભધારણ ન થાય તો退化 → Menstruation.
ટ્રોફોબ્લાસ્ટ → Placentation અને hCG secretion; Inner cell mass → Embryo forms.
અંડકોષાષનું તાપમાન 2–2.5°C ઓછું — આથી અંડપિંડ શરીરની બહાર.
Spermiogenesis = Spermatid → Sperm transformation (no cell division).
Ovum ની Zein layer → Cortical reaction → Block to polyspermy.
પ્રથમ પોલાર બોડી Meiosis I માં, બીજી પોલાર બોડી Meiosis II માં બને છે.
Pituitary gland માં FSH + LH both — but only one at a time peaks in cycle.
Menstrual phase: Days 1–5; Proliferative phase: Days 6–14; Secretory phase: Days 15–28.
Placenta → Endocrine organ (होर्मोन बनाना) + Nutrient/Gas exchange.
Colostrum (přimé mléko) is rich in IgA antibodies — first milk after birth.
Vasectomy: Vas deferens cut — blocks sperm transport, but testosterone production continues.
