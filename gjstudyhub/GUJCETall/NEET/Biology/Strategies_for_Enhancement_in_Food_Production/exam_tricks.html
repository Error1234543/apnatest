GUJCET — ખોરાક ઉત્પાદનના સૂત્રો (Strategies for Enhancement in Food Production) પરિક્ષા ટ્રિક્સ

🧪 GUJCET — Gujarati • Biology • Strategies for Enhancement in Food Production

🎯 પરીક્ષા ટ્રિક્સ

"મધ" શબ્દ દેખાય ત્યારે જવાબ આપો: MRP — મધ (Honey), રાઇન, પોલન, મધમીઠું (Propolis). જોકે પોલિનેશન લેબમાં થાય છે, પરંતુ MRP નો ઉપયોગ વ્યાવસાયિક મધ ઉત્પાદનમાં થતો નથી.
જ્યારે પ્રશ્નમાં મધમાખીઓ (Apis indica/Apis mellifera) અથવા મધ ઉછેર વિશે પૂછવામાં આવે.
દા.ત.: પ્રશ્ન: 'MRP' નો કયા સાધન સમૂહનો ભાગ નથી? વિકલ્પો: A) મધ B) રાઇન C) પોલન D) મધમીઠું — જવાબ: (C) પોલન, કારણ કે મધમાખીઓ પોલિનેશન કરતી નથી (વ્યાવસાયિક રીતે નહીં).
"SCP" = Single Cell Protein — હંમેશા એક જ કોષ ધરાવતા સૂક્ષ્મજીવો (Bacillus subtilis, Spirulina, Saccharomyces) થી મળે છે. SCPના પ્રશ્નોમાં 'એક કોષ' કીવર્ડ છે. જો વિકલ્પમાં એકાણુકોષી સૂક્ષ્મજીવ હોય → SCP.
SCP અથવા એકકોષી પ્રોટીન વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'સૂક્ષ્મજીવોમાંથી મળતી પ્રોટીન' કઈ કહેવાય? → SCP (એક કોષી પ્રોટીન). બહુકોષી જીવો જેવા કે ઘઉં, સોયા બીન SCP નથી.
હોર્મોન્સની યાદ: PGT (ખેડૂત સ્વાસ્થ્ય મંદિર, દિલ્હી) ↔ ICMR (AIIMS, નવી દિલ્હી) ↔ CSIR (CCMB, હૈદરાબાદ). જો પ્રશ્ન 'ખેડૂત સ્વાસ્થ્ય' હોય → PGT; 'અન્ય' → CSIR/ICMR અનુક્રમે.
બાયોટેકનોલોજી પ્રયોગશાળાઓ અને તેમના સ્થળો વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'ખેડૂત સ્વાસ્થ્ય મંદિર, દિલ્હી' ક્યાં છે? → PGT. 'CSIR પ્રયોગશાળા' ક્યાં? → હૈદરાબાદ.
"અંતરાષ્ટ્રીય બોર્ડ ઓફ પ્લાન્ટ જિનેટિક્સ રીસોર્સીઝ" (IBPGR) = સંયુક્ત રાષ્ટ્ર સંઘ (UN) હેઠળ. IBPGR ↔ UN ↔ આંતરરાષ્ટ્રીય; ICRISAT ↔ અણપૂરું ગ્રામીણ ક્ષેત્ર (semi-arid); IRRI ↔ ચાવલ (rice).
આંતરરાષ્ટ્રીય કૃષિ સંશોધન કેન્દ્રો વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'IBPGR નો સંબંધ ક્યાંથી છે?' → UN; 'ICRISAT ક્યાં છે?' → રાજેન્દ્રનગર, પટના (અણપૂરું ગ્રામીણ); 'IRRI' → ચાવલ સંશોધન.
ઓપન-પોલિનેશન vs સ્વ-પરાગયોગ: જો વિકલ્પમાં 'બાહ્ય પરાગ' હોય → ઓપન-પોલિનેશન; 'સ્વ-પરાગ' હોય → સ્વ-પરાગયોગ. Oryza sativa (ભাত) સ્વ-પરાગયોગી છે (self-pollinating).
પરાગયોગની પ્રકાર વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'કઈ ફસલ સ્વ-પરાગયોગી છે?' → Oryza sativa (ભَات), Triticum aestivum (ગહેું); 'બાહ્ય પરાગ' → Zea mays (મેકી).
વનસ્પતિ હار્ટ (plant heart) = Callus → Organogenesis → Embryoids. જો પ્રશ્ન 'Callus' વિશે હોય → તરત 'Embryoid' યાદ રાખો. Somatic hybridization માં Callus જરૂરી છે.
ટિશ્યૂ કલ્ચર (Tissue culture) અને સોમેટિક હાઇબ્રિડાઇઝેશન વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'કોષ સંહતિ (Callus) પરથી શું બને છે?' → અંગજનન (Organogenesis) અનેEmbryoids. Somatic hybridization માં Callus વખતે બંને વનસ્પતિઓના કોષો જોડાય છે.
જ્યારે વિકલ્પોમાં 'Mule' (ગધેડું) હોય → તે બે અલગ પ્રજાતિઓ (ઘોડો × ગધેડો) નું સંતान છે, પણ સંતान બંધબેસતું નથી (sterile). આ પ્રકારની પ્રજનન પદ્ધતિ 'Crossbreeding' છે, 'Interspecific hybridization' નહીં.
પ્રાણી સંવર્ધનમાં સંકરણ પ્રકારો વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'Mule' શું છે? → Crossbreeding (ઘોડો + ગધેડો). Interspecific hybridization ≠ Crossbreeding — Interspecific = same species, different varieties.
"બાયોફોર્ટિફિકેશન" = પોષક તત્વો વધારવા માટે. Kissan (ખેડૂત) ↔ Bt cotton = કીડાનાશક ગુણ; Biofortification = વિટામિન/ખનિજ વધારો. યાદ રાખો: Bt = કીડા, Biofortification = પોષણ.
જનીન આધારિત સુધારા (Biotechnological improvements) વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'બાયોફોર્ટિફિકેશન' નો ઉદ્દેશ્ય શું છે? → વિટામિન A, લોહણ, પ્રોટીન વગેરે વધારવું. Bt cotton = કીડાથી રક્ષણ, પોષણ નહીં.
Fisheries: 'Carpfish' = કાર્પ માછલી; 'Rohu, Catla, Mrigal' = Indigenous (સ્થાનિક); 'Mrigal' = Mrigal mrigala. જો 'Indigenous' કીવર્ડ હોય → Rohu, Catla, Mrigal; 'Exotic' = Grass carp, Silver carp.
માછલી ઉછેર (Fisheries) વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'કઈ માછલી સ્થાનિક (indigenous) છે?' → Rohu (Labeo rohita), Catla (Catla catla), Mrigal (Cirrhinus mrigala). Exotic = Grass carp, Silver carp.
ICTAD = Indian Council of Agricultural Research (ICAR). ICAR ↔ અનુસંધાન (Research); NABARD ↔ વિકાસ (Development); NAARM ↔ ટ્રેનિંગ (Training).
કૃષિ સંસ્થાઓની ઓળખ અને અથવો વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'NAARM નો ભાગ છે?' → Training; 'NABARD' → Development; 'ICAR' → Research.
એન્ટિબાયોટિકસ: Penicillin = Penicillium notatum (કવક); Streptomycin = Streptomyces griseus (બેસિલસ); Chloramphenicol = Streptomyces venezuelae. 'Strepto-' શબ્દ = Streptomyces.
એન્ટિબાયોટિક્સના સ્ત્રોત વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'Streptomycin કયા સૂક્ષ્મજીવોથી મળે છે?' → Streptomyces griseus. Penicillin = Penicillium notatum (કવક).
ક્ષીરવિજ્ઞાન (Dairy science): 'Casein' = ક્ષીર પ્રોટીન; 'Lactose' = ક્ષીર શર્કરા; 'Butter fat' = ક્ષીર ચરબી. જો પ્રશ્નમાં 'પ્રોટીન' હોય → Casein; 'શર્કરા' → Lactose.
ક્ષીર ઉત્પાદનો વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'ક્ષીરમાં રહેલું પ્રોટીન?' → Casein; 'શર્કરા?' → Lactose; 'ચરબી?' → Butter fat.
Plant Breeding Steps: Selection → Hybridization → Evaluation → Release & Notification. 'Release' = છેલ્લું પગલું. જો પ્રશ્નમાં ' Release and Notification' હોય → છેલ્લું પગલું.
વનસ્પતિ સંવર્ધન (Plant breeding) ની પ્રક્રિયા વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'વનસ્પતિ સંવર્ધનનું છેલ્લું પગલું?' → Release and Notification. Hybridization બીજું, Selection પ્રથમ.
Bees (ખાસ કરીનેApis indica) = Indian honeybee; Apis mellifera = European honeybee. યાદ રાખો: 'Indica' = ભારતીય; 'Mellifera' = યુરોપીયન.
અપિકલ્ચર (Apiculture) વિશેના પ્રશ્નોમાં.
દા.ત.: પ્રશ્ન: 'Apis indica કઈ માખી છે?' → Indian honeybee; 'Apis mellifera' → European honeybee. ભારતીય પ્રજાતિ Apis indica.
