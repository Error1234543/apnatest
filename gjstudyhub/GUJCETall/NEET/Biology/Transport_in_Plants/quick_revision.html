જાંબળીય સમીક્ષા – વનસ્પતિઓમાં પરિવહન (Transport in Plants)

🧪 GUJCET — Gujarati • Biology • Transport in Plants

🧠 યાદ રાખો

પ્રસરણ (Diffusion) એ નિષ્ક્રિય પ્રક્રિયા છે; ઉચ્ચ સાંદ્રતામાંથી નીચી સાંદ્રતા તરફ.
અર્ધપારગમ્ય પટલ (Semi-permeable membrane) માંથી જળાણુનો પ્રવાહ → અવપ્રવાહ (Osmosis).
પરાઢળનું દબાણ (OP) ≥ પ્રાણીય દબાણ (TP) હોય ત્યારે પ્લાઝમોલિસિસ થાય છે.
વિપરીત પ્લાઝમોલિસિસ (Deplasmolysis) = પ્લાઝમાઇઝ્ડ કોષને તાજા પાણીમાં મૂકતા સાધારણ સ્થિતિમાં આવી જવો.
કાષ્ઠ રસવાહિની (Xylem) જળ અને ખનીજ લવણોના ઉપર-ઉપર પરિવહન કરે છે; તે મૃત કોષોની બનેલી હોય છે.
ફોઇલમ / ક્ષીરરસવાહિની (Phloem) દ્રાવ્ય પોષક તત્ત્વોના ખંડન (Translocation) કરે છે; તે જીવિત કોષોની બનેલી હોય છે.
રુહદાબ (Root pressure) એ ધન દબાણ છે જે જૂની શૃંગિકાવાહિનીઓમાં પાણી ઉપર ચઢાવે છે.
રસાયણીય સંચલન સિદ્ધાંત (Chemiosmotic / Pressure Flow Hypothesis) અન્સેલ્સેલ આપ્યું હતું.
સંચલન (Translocation) ગાળણ ગતિથી નહીં પણ સક્રિય પરિવહન દ્વારા થાય છે.
અભિગમ્યતા (Hygroscopicity) દર્શાવે છે કે પાણીને વિકર્ષતા અણુઓ કયું પ્રમાણમાં પાણી આકર્ષે છે.
કોહ્ઝન-તણાવ સિદ્ધાંત (Cohesion-Tension Theory) સ્ટીવેન્સ અને હાર્લોલ્ડ દ્વારા આપવામાં આવી.

⚡ ઝડપી સૂત્રો

પાણીનો વિભવ: Ψ = Ψs + Ψp + Ψg (જ્યાં Ψs = વિલેયન સ્થિર, Ψp = દબાણ સ્થિર, Ψg = ગુરુત્વાકર્ષણ સ્થિર).
પરાઢળનું દબાણ: OP = CRT (અંદાજિત; C = મોલાર સાંદ્રતા, R = વાયુ અચળાંક, T = તાપમાન K માં).
પરાઢળ સ્થિર: TP = OP − PP (જ્યાં PP = પ્રવાહી દબાણ / દ્રવ્ય દબાણ).
ગાઢ દબાણ: DP = OP − TP.

✅ વન-લાઈનર્સ

અભિગમ્યતા (Imbibition) ને પાણી શોષણની પ્રક્રિયા પણ કહે છે; તે ઉષ્માનું ઉત્પાદન કરે છે.
રંધ્ર (Stomata) નું મુખ્ય કાર્ય વરાયીવેગ (Transpiration) અને વાયુવિનિમય છે.
રોદ્રવેગ (Guttation) માં પાણી રંધ્ર દ્વારા નહીં પણ હિડ્રોથાઇલ્સ (Hydathodes) દ્વારા બહાર નીકળે છે.
ક્ષૌરરસવાહિનીની નળીકોષો (Tube cells) મૃત હોય છે; નિષ્ફળ જાળી (Sieve plate) માં છિદ્રો હોય છે.
આસન કોષો (Companion cells) નિષ્ફળ જાળીકોષોની ચયાપચય ક્રિયાઓમાં મદદ કરે છે.
વરાયીવેગે દ્વારા પર્ણમાંથી પાણી બાષ્પ સ્વરૂપે બહાર નીકળે છે; તે પાદપ ઠંડક પણ આપે છે.
પ્રસરણ દર તાપમાન, સાંદ્રતા ઢાળ, પટલની ભેદ્યતા અને દ્રાવ્ય પ્રકાર પર આધારિત છે.
શોષકા દ્વારા પાણીનું શોષણ થાય છે; તેની દિશા સાંદ્રતા ઢાળ પર આધારિત છે.
કોહ્ઝન (Cohesion) = એકસરખા અણુઓ વચ્ચેનું આકર્ષણ; અધિગમ્યતા (Adhesion) = વિષમ અણુઓ વચ્ચેનું આકર્ષણ.
ક્ષીરરસવાહિનીમાં AFT (Accessory Filter Tissue) મૂળભૂત રચના છે.
પાણીનો વિભવ (Water Potential) હંમેશા શૂન્યથી ઓછો અથવા સમાન હોય છે; શુદ્ધ પાણીનો Ψ = 0.
અવપ્રવાહના ત્રણ પ્રકાર: સરળ અવપ્રવાહ, સક્રિય પરિવહન, સહ-પરિવહન.
