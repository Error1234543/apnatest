GUJCET — છોડજગત (Plant Kingdom) માટે એક્ઝામ ટ્રિક્સ

🧪 GUJCET — Gujarati • Biology • Plant Kingdom

🎯 પરીક્ષા ટ્રિક્સ

"સ્પોરોફાઇટ > ગેમેટોફાઇટ" — જો પ્રશ્નમાં કોઈ છોડનો સ્પોરોફાઇટ પ્રબળ હોય તો તે બ્રાયોફાઇટ ન હોઈ શકે. બ્રાયોફાઇટ્સમાં ગેમેટોફાઇટ પ્રબળ હોય છે.
જ્યારે બ્રાયોફાઇટ્સ vs પ્ટેરિડોફાઇટ્સ વચ્ચે ભ્રમણા થતી હોય.
દા.ત.: એંગ્લોપ્ટેરિસ (Angiopteris) એ પ્ટેરિડોફાઇટ છે કારણ કે તેમાં સ્પોરોફાઇટ પ્રબળ છે; મોસ (Moss) માં ગેમેટોફાઇટ પ્રબળ છે.
"બીજ ન હોય → એન્જિયોસ્પર્મ નહીં" — જો વિકલ્પમાં 'બીજ' શબ્દ હોય તો તે એન્જિયોસ્પર્મ અથવા જિમ્નોસ્પર્મ છે; જો 'બીજ ન હોય' તો તે એલ્ગી/બ્રાયોફાઇટ/પ્ટેરિડોફાઇટ છે.
પ્રાથમિક છોડના સમૂહો વચ્ચે તરત જ ભેદ કરવા.
દા.ત.: સેકસેમ્બ્રિયોન (Cycas) માં બીજ હોય છે → જિમ્નોસ્પર્મ; ડિક્સોનિયા (Dicksonia) માં બીજ નથી → પ્ટેરિડોફાઇટ.
"ઓગ્લોફાઇટ્સ = પાણીના છોડ" — ઓગ્લોફાઇટ્સ (Oglophyta) માત્ર મીઠા પાણીમાં મળે છે. જો વિકલ્પમાં 'સમુદ્રી' અથવા 'લવણ પાણી' હોય, તો તે ઓગ્લોફાઇટ નથી.
શૈવાળની વર્ગીકરણ સંબંધિત પ્રશ્નોમાં.
દા.ત.: સ્પાયરોગાયરા (Spirogyra) મીઠા પાણીનું શૈવાળ છે; વાઈફા (Vfpa) સમુદ્રી છે → રેડ એલ્ગી.
"સ્ટ્રોબિલસ = શંકુ સમાન બંધારણ" — જો પ્રશ્નમાં 'સ્ટ્રોબિલસ' શબ્દ આવે, તો તે કોનફર (Conifer) અથવા સેકસેમ્બ્રિયોન જેવા જિમ્નોસ્પર્મ સાથે સંબંધિત છે. એન્જિયોસ્પર્મમાં સ્ટ્રોબિલસ હોતો નથી.
જિમ્નોસ્પર્મ્સના લક્ષણો સંબંધિત પ્રશ્નોમાં.
દા.ત.: પાઇનસ (Pinus) ના સ્ટ્રોબિલસ હોય છે; રોઝ (Rose) માં સ્ટ્રોબિલસ નથી.
"એકબીજપત્રી vs દ્વિબીજપત્રી — બાહ્ય આવરણ ટ્રિક" — બીજમાં એક બીજપત્ર (cotyledon) = એકબીજપત્રી (Monocot); બે બીજપત્ર = દ્વિબીજપત્રી (Dicot). વિકલ્પોમાં 'એક' આવે તો Monocot, 'દ્વિ/બે' આવે તો Dicot.
એન્જિયોસ્પર્મ્સની શ્રેણીબદ્ધતા સંબંધિત પ્રશ્નોમાં.
દા.ત.: ગોધૂળ (Wheat) માં 1 બીજપત્ર → Monocot; મગ (Bean) માં 2 બીજપત્ર → Dicot.
"પ્રોટોકોર્લ (Protocorm) = બ્રાયોફાઇટ/પ્ટેરિડોફાઇટનો સંકેત" — જો વિકલ્પમાં 'પ્રોટોકોર્લ' હોય, તો તે બ્રાયોફાઇટ અથવા પ્ટેરિડોફાઇટ છે, જિમ્નોસ્પર્મ/એન્જિયોસ્પર્મ નહીં.
જ્યારે છોડના પ્રારંભિક વિકાસકળા સંબંધિત પ્રશ્ન હોય.
દા.ત.: એન્થોસેરોસ (Anthoceros) અને સેલ્વિનિયા (Selaginella) બંનેમાં પ્રોટોકોર્લ મળે છે.
"પર્નિડિયમ (Pollen Chamber) = જિમ્નોસ્પર્મની અનન્ય લાક્ષણિકતા" — જો પ્રશ્નમાં 'પર્નિડિયમ' આવે, તો તે જિમ્નોસ્પર્મ છે. એન્જિયોસ્પર્મમાં પર્નિડિયમ હોતો નથી.
જિમ્નોસ્પર્મ્સ અને એન્જિયોસ્પર્મ્સ વચ્ચે ભેદ કરવા.
દા.ત.: પાઇનસ (Pinus) માં પર્નિડિયમ હોય છે → જિમ્નોસ્પર્મ; ઘઉંમાં નથી → એન્જિયોસ્પર્મ.
"સાયકાસ (Cycas) = 'પ્રાચીન પામ' — બે લક્ષણ યાદ રાખો: (૧) સ્તંભાકાર તණ્ડુ (trunk) (૨) સંવર્ધિત પર્ણ (coriaceous frond) — આ બેમાંથી એક પણ હોય તો Cycas નક્કી.
જિમ્નોસ્પર્મ્સમાં વિશિષ્ટ પ્રજાતિઓ સંબંધિત પ્રશ્નોમાં.
દા.ત.: Cycas અને Pinus બંને જિમ્નોસ્પર્મ છે, પણ Cycas માત્ર 'પ્રાચીન પામ' તરીકે ઓળખાય છે.
"ડાયસોનિસપોરસ (Diosporous) vs હોમોસ્પોરસ (Homosporous) — બીજ શબ્દ ટ્રિક" — 'ડાય' = બે, 'સોરસ' = બીજ/સ્પોર → બે પ્રકારના સ્પોર = ડાયસોનિસપોરસ (જિમ્નોસ્પર્મ/પ્ટેરિડોફાઇટ). 'હોમો' = સમાન = એક પ્રકારના સ્પોર (ઘણા પ્ટેરિડોફાઇટ/શૈવાળ).
સ્પોરના પ્રકાર સંબંધિત પ્રશ્નોમાં.
દા.ત.: સેલ્વિનિયા (Selaginella) ડાયસોનિસપોરસ છે; સેલ્વિનિયા (Salvinia) પણ ડાયસોનિસપોરસ છે; પ્લેગિઓરિઝા (Psilotum) હોમોસ્પોરસ છે.
"ઓફિઓગ્લોસસ (Ophioglossum) = સર્પપર્ણ — 'ઓફિઓ' = સર્પ" — જો વિકલ્પમાં 'સર્પ' અથવા '蛇' જેવો સંદર્ભ હોય, તો તે ઓફિઓગ્લોસસ છે. આ પ્ટેરિડોફાઇટનો સૌથી પ્રાચીન વંશ છે.
પ્ટેરિડોફાઇટ્સની પ્રજાતિઓ ઓળખવા.
દા.ત.: ઓફિઓગ્લોસસ (Ophioglossum) ને 'સર્પભસ્મ' પણ કહેવાય છે; તે પ્ટેરિડોફાઇટ્સમાં સૌથી પ્રાચીન ગણાય છે.
"થેલોફાઇટ્સ = સરળતમ છોડ" — થેલોફાઇટ્સ (Thallophyta) માં શરીર થેલસ (thallus) સમાન હોય છે, મૂળ/તડા/પર્ણ નથી હોતા. જો કોઈ વિકલ્પમાં 'મૂળ, તડ, પર્ણ' ન હોય, તો તે થેલોફાઇટ છે.
શૈવાળ/ફંગસ/લાઇકનને અન્ય છોડથી અલગ કરવા.
દા.ત.: સ્પાયરોગાયરા (Spirogyra) માં મૂળ-તડ-પર્ણ નથી → થેલોફાઇટ; મોસમાં તડ-પર્ણ હોય છે → બ્રાયોફાઇટ.
"એન્જિયોસ્પર્મ = 'આવૃત બીજ' — બીજ આવરી લેવાયેલું" — જો પ્રશ્નમાં 'આવૃત બીજ' અથવા 'ફળ' શબ્દ આવે, તો તે એન્જિયોસ્પર્મ છે. જિમ્નોસ્પર્મમાં 'નગ્ન બીજ' (naked seed) હોય છે.
એન્જિયોસ્પર્મ vs જિમ્નોસ્પર્મ તરત જ ઓળખવા.
દા.ત.: આમ (Mango) માં ફળ છે → એન્જિયોસ્પર્મ; પાઇન (Pine) માં નગ્ન બીજ છે → જિમ્નોસ્પર્મ.
"બ્રાયોફાઇટ્સ = 'સ્ત્રીલિંગ છોડ' — સ્ત્રીગામી (Archegonium) અને પુંગામી (Antheridium) બંને હોય છે, પણ મૂળ નથી હોતા" — જો પ્રશ્નમાં 'મૂળ નથી પણ ગામી અંગો છે' હોય, તો તે બ્રાયોફાઇટ છે.
બ્રાયોફાઇટ્સને અન્ય સમૂહોથી અલગ કરવા.
દા.ત.: એન્થોસેરોસ (Anthoceros) માં મૂળ નથી, પણ ગામી અંગો છે → બ્રાયોફાઇટ; ડિક્સોનિયા (Dicksonia) માં મૂળ હોય છે → પ્ટેરિડોફાઇટ.
"પ્ટેરિડોફાઇટ્સ = પ્રથમ સ્થળાંતરિત છોડ (vascular plants)" — જો પ્રશ્નમાં 'વાહિકા કલા' (vascular tissue) અથવા 'ખરેડા/છાંટી' (xylem/phloem) હોય, તો તે પ્ટેરિડોફાઇટ અથવા તેથી ઉચ્ચ છે. બ્રાયોફાઇટ/થેલોફાઇટમાં વાહિકા કલા નથી.
વાહિકા કલા સંબંધિત પ્રશ્નોમાં.
દા.ત.: એડિસ (Equisetum) માં વાહિકા કલા છે → પ્ટેરિડોફાઇટ; લેમ્પ્ટોગાયરા (Lampyga) માં નથી → થેલોફાઇટ.
"સાયકાસ (Cycas) માં રિવર્સ ફર્ટિલાઇઝેશન (વિપરીત ફલન) — 'સાયકાસ = સર્વોચ્ચ જિમ્નોસ્પર્મ' યાદ રાખો. જો પ્રશ્નમાં 'સર્વોચ્ચ જિમ્નોસ્પર્મ' હોય, તો જવાબ Cycas જ હોય.
જિમ્નોસ્પર્મ્સની વર્ગીકરણ સંબંધિત પ્રશ્નોમાં.
દા.ત.: Cycas માં વિપરીત ફલન (reverse fertilization) થાય છે → તે સર્વોચ્ચ જિમ્નોસ્પર્મ ગણાય છે.
