🎯 પરીક્ષા ટ્રિક્સ

"વૃદ્ધિરોકનારા" હોર્મોન → અબ્સિઝિક એસિડ (ABA) + ઇથિલીન
જ્યારે પ્રશ્નમાં 'વૃદ્ધિ રોકે છે', 'તણાવ હોર્મોન', 'શાયરતા' અથવા 'અંકુરોડધન' સ્પષ્ટ હોય.
દા.ત.: જે હોર્મોન કીટ્ટિકા સ્થિતિ (stomatal closure) લાવે અને બીજના અંકુરોડધનને ચૂસે તે ABA છે. વિકલ્પોમાં ઇથિલીન પણ વૃદ્ધિરોકક હોવાથી સાથે રાખવું.
"ફળ પાકવું અને જરખર પડવું" = ઇથિલીન
જ્યારે ફળ પાકવું, જરખર, વૃદ્ધિરોધ અથવા 'વાયુરૂપ હોર્મોન' પૂછાય.
દા.ત.: કેળાંના પાકવવાનું કામ ઇથિલીન કરે છે. આથી જ 'ગેસ હોર્મોન' એ ઇથિલીનનો સીધો સંકેત છે.
"બાહ્યપ્રેરક (Phytochrome) ની સક્રિય રૂપ PrPfr
દા.ત.:
→ લાલ પ્રકાશ Pr → Pfr (સક્રિય);远 far-red પ્રકાશ Pfr → Pr (નિષ્ક્રિય)
ફોટોપિરિયાડિઝમ / પ્રકાશ-પ્રતિક્રિયા ધરાવતા પ્રશ્નોમાં.
દા.ત.: લાલ પ્રકાશ (660 nm) મળે તો Pr બને Pfr; આથી અંતર્ગત પાંદડું લાલ પ્રકાશ હેઠળ ફુલવા માટે 'ઉત્તેજક' ગણાય.
"ક્ષુદ્ર દિવસો = લાંબી રાત" (Short-day = Long-night)
Short-day / Long-day પودાઓની ઓળખવાનું પ્રશ્ન આવે.
દા.ત.: ચિંતન (Soybean) Short-day છે. તેનો અર્થ એવો કે 'રાત્રિ સમયગાળો' નક્કી કરે છે, દિવસ લંબાઈ નહીં. તેથી દિવસ ટૂંકો હોય એટલે 'રાત લાંબી' હોય.
"વર્નલାଇઝેશન = ઠંડકથી ફુલવું", એન્ઝાઇમ 'વર્નલિન' જવાબદાર
જ્યારે 'ઠંડક આવશ્યક', 'ગ്രીષ્મકાલીન પોદાં' અથવા 'વર્નલિન' શબ્દ આવે.
દા.ત.: હેળ (Wheat) ની કેટલીક વર્ગો લાંબી ઠંડ લાગે. આ ઘટનાને વર્નલઈઝેશન કહે. પરિણામે ફુલવું વધે.
"કોષવિભાજન = સાઇટોકિનીન; મુખ્ય સ્થાન = બીજ, ફળ, પાંદડાની કોષકેન્દ્ર
જ્યારે કોષવિભાજન ઉત્તેજિત કરતું હોર્મોન પૂછાય.
દા.ત.: કોકનટ મિલ્ક (coconut milk) માં સાઇટોકિનીનનું પ્રમાણ ખૂબ વધુ હોય છે, જેથી સંસ્કૃત કોષોમાં વિભાજન વધારે છે.
"એન્જિયલિંગ (Auxin) = શિરોગ્રંથિ પ્રભુત્વ, ફોટોટ્રોપિઝમ, રૂડરોપણ
જ્યારે શિરોગ્રંથિ શાખા દમન, પ્રકાશ તરફ વળવું, અથવા રૂડરોપણ માટે પ્રશ્ન આવે.
દા.ત.: શિરોગ્રંથિ (Apex) દૂર કરતાં બાજુની કલિકાઓ વધીને શાખા પામે છે, એટલે 'શિરોગ્રંથિ પ્રભુત્વ' દૂર થયું. આ AUXINનું કાર્ય છે.
"જિબરેલિન = લંબાઈમાં વધારો, બોલ્ટિંગ, સ્ટાર્ચ → શર્કરા રૂપાંતર
જ્યારે તണ്ട് લંબાઈ, બોલ્ટિંગ અથવા બાર્લિમાં એમીલેઝ ઉત્પન્ન થવા પ્રશ્ન આવે.
દા.ત.: બાર્લિના બીજમાં જિબરેલિન લાવી અંડકોષમાં એમીલેઝ ઉત્પન્ન કરે છે, જે સ્ટાર્ચને મલ્ટોઝ/ગ્લુકોઝમાં તોડે છે. આથી અંકુરોને ઊર્જા મળે.
"સિગ્મોઇડ વૃદ્ધિ વક્ર: પ્રારંભિક = નિવચ્છ, મધ્યમ = ઝડપી, અંતિમ = સ્થિર
જ્યારે વૃદ્ધિ વક્રનો આકાર અથવા તબક્કા પૂછાાય.
દા.ત.: પ્રથમ તબક્કો (Lag phase) માં કોષવૃદ્ધિ ધીમી હોય. બીજો તબક્કો (Log phase) માં ઝડપી. ત્રીજો તબક્કો (Stationary phase) માં વૃદ્ધિ સ્થિર થાય.
"અંતઃપ્રેરક vs બાહ્યપ્રેરક = આંતરિક રાસાયણિક vs બહારનું પર્યાવરણીય ઉત્તેજન
પ્રશ્નમાં 'આંતરિક/બાહ્યપ્રેરક' પ્રશ્ન આવે.
દા.ત.: હોર્મોન્સ (Auxin, Gibberellin) અંતઃપ્રેરક છે. જ્યારે પ્રકાશ, તાપમાન, ઠંડ (vernalization) બાહ્યપ્રેરક છે.
"વિભેદન, અનુવિભેદન, પુનઃવિભેદનનો ક્રમ: સૌથી પહેલે વિકસિત → પાછા ફરવું → ફરી નવું બનવું
જ્યારે 'વિભેદન' પ્રકારોનો પ્રશ્ન આવે.
દા.ત.: અંતઃસ્થ ઉત્કલ્પ (Cambia) ને ઉદાહરણ તરીકે લો: પ્રથમ અનુવિભેદનથી ઉત્કલ્પ બને, પછી પુનઃવિભેદનથી ફેલોમ અને બેરીલેમ ઉત્પન્ન થાય.
"પ્રકાશસંશ્લેષણ + વૃદ્ધિ વચ્ચેનો સંબંધ = પ્રકાશસંશ્લેષણથી ઉત્પન્ન ભોજન વૃદ્ધિને વધારે છે
જ્યારે 'પ્રકાશસંશ્લેષણ અને વૃદ્ધિ'નો સંબંધ પૂછાય.
દા.ત.: જો પ્રકાશસંશ્લેષણ ઘટે, તો કાર્બોહાઇડ્રેટ ઓછા મળે; વૃદ્ધિ ધીમી પડે. તેથી બંને સીધા સંબંધિત છે.
