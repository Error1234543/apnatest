જૈવિક વર્ગીકરણ — ઝડપી પુનરાવર્તન

🧪 GUJCET — Gujarati • Biology • Biological Classification

🧠 યાદ રાખો

વિશ્વેના જીવોનું પાંચ-કુળ વર્ગીકરણ મહેશ્વરી (R.H. Whittaker) એ 1969માં પ્રસ્તાવિત કર્યું.
પ્રોકેરિયોટ (અણુકેન્દ્રી) : સમૂહ રાજ્ય પ્રોકેરિયોટા (બેક્ટેરિયા, સ્વાયત્ટબેરિયા, માઇકોપ્લાઝમા, સાયનોબેક્ટેરિયા).
ઇયુકેરિયોટ (અણુકેન્દ્રી) : ચાર સમૂહ — પ્રોટિસ્ટા, ફાંજી, પ્લાન્ટી, એનિમલિયા.
સાયનોબેક્ટેરિયાને 'સાયનોબેક્ટેરિયા' અથવા '蓝藻' કહીએ છીએ — તેઓ સ્વયંપોષી, ક્લોરોફિલ ધરાવે છે અને નાઇટ્રોજન સ્થાપન કરે છે.
માઇકોપ્લાઝમા — દીવાલરહિત, સૌથી સૂક્ષ્મ સ્વતંત્ર જીવ; પેથોજેનિક છે.
ડાયટમ (Diatoms) ના કોષકાઠબિયા સિલિકાના બનેલા હોય છે; 'ડાયેટમ એર્થ' જમાવે છે.
ડાયટમ અને ડાઈનોફ્લેજલેટસ સમુદ્રી પ્રકાશસંશ્લેષણના મુખ્ય કારક છે.
શ્લેષ્મકાઇન (Slime moulds) — વિશ્રાંતિ અવસ્થામાં ફકિંગલ (પાકીરસ) જેવા; ડેડ્ટ્રિટ ઘટકો.
ફાંજીના ચાર મુખ્ય સમૂહ : ઝાયગોમાઇકોટા, બેસિડિયોમાઇકોટા, એસકોમાઇકોટા, ડિટ્રિઓમાઇકોટા.
લાઇકન = સિંબાયોટિક સંબંધ : સયુગ્મી (ફાંજી) + શેરી (આલ્ગી/સાયanoબેક્ટેરિયા).
વાયરસ — અકોષીય, માત્ર જીવંત અવસ્થામાંજ પુનરઉત્પાદન કરે છે; આપણામાંજ ઇન્ફેક્શન કરી શકે છે.
વાયરિયોન (વિરાયસ) : રોગવિજ્ઞાનભર્યા RNAનું સૂક્ષ્મ કણ; TMV એક ઉદાહરણ છે.

⚡ ઝડપી સૂત્રો

પ્લાઝમોલિસિસ : P.S. > બાહ્ય દ્રાવણ → પાણીનું નિષ્કાસન → કોષદીવાલ ખેંચાણ.
વાયરસનું કદ ~ 20–300 nm; બેક્ટેરિયાનું કદ ~ 0.5–5 µm.
TMV (ટોબેકો મોઝેક વાઇરસ) : સિલિન્ડ્રાકાર, ssRNA ધરાવે છે, ~300 nm લાંબું.
લાઇકન વાર્ષિક વૃદ્ધિ ~ 1–5 mm (હવામાન પર આધારિત).

✅ વન-લાઈનર્સ

પાંચ-કુળ વર્ગીકરણ : પ્રોકેરિયોટા, પ્રોટિસ્ટા, ફાંજી, પ્લાન્ટી, એનિમલિયા.
બેક્ટેરિયાની કોષદીવાલ peptidoglycan (મ્યુરિન) ધરાવે છે.
ગ્રામ-ધન બેક્ટેરિયા : મોટી peptidoglycan પొરત; ગ્રામ-ઋણ : પાતળી પોરત + બહારેની પೊલિશર પોટલ.
નાયોજીન સ્થાપક બેક્ટેરિયા : Rhizobium (શેરડી), Cyanobacteria (Nostoc, Anabaena).
નાયકોબેક્ટેરિયા (Heterocysts) નાઇટ્રોજન સ્થાપન કરે છે;Vegetative કોષ પ્રકાશસંશ્લેષણ.
ફાંજી ભોજન પદ્ધતિ : પરોપજીવી / સડોપજીવી / સહોપજીવી.
ફાંજીના અલિંગી બીજ : સ્पोરોંગ્લિયોસ્પોર, કોન્જિયોસ્પોર, ઑઇડિયોસ્પોર.
શૈવાલોના પાંચ વિભાગ : ક્લોરોફાઈટા (લીલી), રોડોફાઈટા (લાલ), ફાયકોફાઈટા (ભુરો).
ક્લોરોફાઈટા : ક્લોરોફિલ a + b; સ્ટાર્ચ સંગ્રહ; યુગલકોષીય કીટ.
રોડોફાઈટા : ફાયકોરીથ્રિન (લાલ રંગ); સ્ટાર્ચ જેવું ફ्लॉरिडियન સ્ટાર્ચ સંગ્રહ.
ફાયકોફાઈટા : ફાયકોએರಿથ્રિન (ભુરો); કાલ્ફન સંગ્રહ; બહુકોષીય.
પ્રોટિસ્ટા : એકકોષી ઇયુકેરિયોટ; પારજીવી (Plasmodium), પ્રકાશસંશ્લેષી (Euglena).
વાયરસ ત્રણ પ્રકાર : DNA વાઇરસ, RNA વાઇરસ, રેટ્રોવાઇરસ (HIV).
લાઇકન સંવેદનશીલ પ્રદૂષક સૂચક : SO₂ પ્રદૂષણ પ્રત્યે સંવેદનશીલ.
બેક્ટેરિયાના ચાર આકાર : કોકસ (ગોળ), બેસિલસ (ડંડાકાર), વિબ્રિયો (અર્ધચંદ્ર), સ્પાયરિલ્લ (પીચકારી).
ક્લામેડોમોનસ (Chlamydomonas) એકકોષી લીલી શૈવાલ; પાયરીફોર (Pyrenoid) પ્રોટીન સંગ્રહ.
સ્પાયરોગાયરા (Spirogyra) : રિબન-આકારના ક્લોરોપ્લેસ્ટ; સૂત્રીય સંયોગથી પ્રजनन.
ફાંજીમાં mycelium મુખ્ય શરીરરચના; hyphae દ્વારા પ્રસરણ.
ક્રિપ્ટોગેમ (ગુપ્તબીજી) : શૈવાલ, બ્રાયોફાઈટા, ટેરિડોફાઈટા — બીજરહિત.
ઐતિહાસિક વર્ગીકરણ : લિનિયસ (બે-કુળ, 1753) → હક્ક્લ (છકુળ, 1866) → વિટેકર (પાંચ-કુળ, 1969).
