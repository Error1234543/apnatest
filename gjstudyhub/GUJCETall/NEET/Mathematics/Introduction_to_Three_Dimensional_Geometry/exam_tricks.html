🎯 પરીક્ષા ટ્રિક્સ

દિશા કોસાઇન (Direction Cosines) નો સરવાળો વર્ગ = 1: l² + m² + n² = 1. જો વિકલ્પોમાં આ શરત પાળતો જોડો હોય, તો તરત સાચો જવાબ પસંદ કરો.
જ્યારે દિશા કોસાઇનની ચકાસણી કરવાની હોય અથવા l, m, n માંથી એક શોધવાનો હોય.
દા.ત.: જો l = 3/5 અને m = 4/5 હોય, તો n² = 1 − (9/25 + 16/25) = 0, તેથી n = 0. આમ (3/5, 4/5, 0) સાચો જવાબ.
દિશા અનુપાત (DR) અને દિશા કોસાઇન (DC) વચ્ચેનો સંબંધ: l = a/√(a²+b²+c²). છેદમાં √(a²+b²+c²) ગણતરી કર્યા વિના, વિકલ્પોની તુલના કરીને સાચો જોડો શોધો.
DR (a, b, c) માંથી DC શોધવાના પ્રશ્નમાં.
દા.ત.: DR = (1, 2, 2) હોય, તો √(1+4+4) = 3, તેથી DC = (1/3, 2/3, 2/3). વિકલ્પોમાં આ જોડો હોય તો તરત પસંદ કરો.
બિંદુઓ P(x₁,y₁,z₁) અને Q(x₂,y₂,z₂) વચ્ચેનું અંતર = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]. ગણતરી સરળ બનાવવા: પ્રથમ તફાવત શોધો, પછી વર્ગ કરો, છેલ્લે વર્ગમૂળ.
કોઈ પણ બે બિંદુઓ વચ્ચેનું અંતર શોધવાનો પ્રશ્ન.
દા.ત.: A(1,2,3) અને B(4,6,3) વચ્ચે: √[(3)²+(4)²+(0)²] = √(9+16) = √25 = 5.
વિભાજન સૂત્ર (Section Formula): જો P બિંદુ AB ને m:n ના અનુપાતમાં વિભાજિત કરતું હોય, તો P = [(mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n)]. 'મધ્યબિંદુ' માટે m:n = 1:1 લેતાં સૂત્ર સરળ બને છે.
રેખાખંડને આપેલ અનુપાતમાં વિભાજિત કરતું બિંદુ શોધવાનું પ્રશ્ન.
દા.ત.: A(2,3,4) અને B(4,5,6) ને 1:1 માં વિભાજિત કરતું મધ્યબિંદુ = ((2+4)/2, (3+5)/2, (4+6)/2) = (3, 4, 5).
બે રેખાઓ સમાંતર (Parallel) હોય તો તેમના દિશા અનુપાત સમપ્રમાણ હોય: a₁/a₂ = b₁/b₂ = c₁/c₂. જો આ શરત પૂરી થાય, તો રેખાઓ સમાંતર છે.
બે રેખાઓ સમાંતર છે કે નહીં તે ચકાસવાનો પ્રશ્ન.
દા.ત.: રેખા 1: DR (2,3,4), રેખા 2: DR (4,6,8). અનુપાત = 2/4 = 3/6 = 4/8 = 1/2. તેથી રેખાઓ સમાંતર.
બે રેખાઓ લંબ (Perpendicular) હોય તો a₁a₂ + b₁b₂ + c₁c₂ = 0. આ એક જ ગુણાકારનો સરવાળો છે — ઝડપી ચકાસણી.
બે રેખાઓ લંબ છે કે નહીં તે તપાસવાનો પ્રશ્ન.
દા.ત.: DR (1,2,3) અને (2,−1,0): 1×2 + 2×(−1) + 3×0 = 2−2+0 = 0. તેથી રેખાઓ લંબ.
બે સમતલો વચ્ચેનું કોણ θ: cos θ = |a₁a₂+b₁b₂+c₁c₂| / [√(a₁²+b₁²+c₁²) × √(a₂²+b₂²+c₂²)]. જો અંશ = 0 હોય, તો સમતલો પરસ્પર લંબ છે (θ = 90°).
બે સમતલો વચ્ચેનું કોણ શોધવાનો અથવા લંબતા ચકાસવાનો પ્રશ્ન.
દા.ત.: સમતલ 1: x+2y+3z=0 (a₁=1,b₁=2,c₁=3), સમતલ 2: 3x+2y−z=0 (a₂=3,b₂=2,c₂=−1). અંશ = 3+4−3 = 4 ≠ 0, તેથી લંબ નથી.
સમતલનું પ્રમાણભૂત સમીકરણ: ax + by + cz = d, જ્યાં (a,b,c) સમતલના લંબ દિશા અનુપાત છે. જો સમીકરણ ax+by+cz+d=0 સ્વરૂપમાં હોય, તો લંબના દિશા અનુપાત (a,b,c) જ હોય.
સમતલના લંબના દિશા અનુપાત/કોસાઇન શોધવાના પ્રશ્નમાં.
દા.ત.: સમતલ 2x − 3y + 6z + 4 = 0 ના લંબના DR = (2, −3, 6). DC = (2/7, −3/7, 6/7).
બિંદુ (x₁,y₁,z₁) થી સમતલ ax+by+cz+d=0 નું લંબ અંતર = |ax₁+by₁+cz₁+d| / √(a²+b²+c²). અંશમાં મૂલ્ય ધન/ઋણ હોઈ શકે, પણ મોડ્યુલો લેવાનું ભૂલશો નહીં.
બિંદુથી સમતલનું લંબ અંતર શોધવાનો પ્રશ્ન.
દા.ત.: બિંદુ (1,0,−2) થી સમતલ x−y+z=1 નું અંતર: |1−0−2−1|/√(1+1+1) = |−2|/√3 = 2/√3.
રેખાનું પ્રમાણભૂત સમીકરણ: (x−x₁)/a = (y−y₁)/b = (z−z₁)/c, જ્યાં (x₁,y₁,z₁) બિંદુ અને (a,b,c) દિશા અનુપાત. વિકલ્પોમાં આ સ્વરૂપ જોવા મળે તો તરત ઓળખો.
રેખાનું સમીકરણ લખવાનો અથવા ઓળખવાનો પ્રશ્ન.
દા.ત.: બિંદુ (1,2,3) માંથી અને DR (2,−1,4) ને સમાંતર રેખા: (x−1)/2 = (y−2)/(−1) = (z−3)/4.
બે રેખાઓ સમતલીય (Coplanar) હોય તો: |x₂−x₁ y₂−y₁ z₂−z₁; a₁ b₁ c₁; a₂ b₂ c₂| = 0 (3×3 નિશ્ચાયક શૂન્ય). આ ચકાસણી ઝડપી અને ચોકસાઈપૂર્વક.
બે રેખાઓ સમતલીય છે કે નહીં તે ચકાસવાનો પ્રશ્ન.
દા.ત.: રેખા 1: બિંદુ (1,0,0), DR (1,1,0); રેખા 2: બિંદુ (0,1,0), DR (0,1,1). નિશ્ચાયક = 1(1)−1(1)+0 = 0. તેથી સમતલીય.
અક્ષો સાથેના કોણ: x-અક્ષ સાથે α, y-અક્ષ સાથે β, z-અક્ષ સાથે γ. DC = (cos α, cos β, cos γ). જો કોણ આપેલ હોય, તો DC સીધા મળે.
રેખા અક્ષો સાથે જે કોણો બનાવે છે તેના આધારે DC શોધવાનો પ્રશ્ન.
દા.ત.: રેખા x, y, z અક્ષો સાથે ક્રમે 60°, 45°, 60° બનાવે → DC = (cos60°, cos45°, cos60°) = (1/2, 1/√2, 1/2).
સમતલનું અંતઃખંડ સ્વરૂપ (Intercept form): x/a + y/b + z/c = 1, જ્યાં a, b, c અનુક્રમે x, y, z અક્ષો પરના અંતઃખંડ છે. વિકલ્પોમાં આ સ્વરૂપ જોવા મળે તો અંતઃખંડો તરત ઓળખી શકાય.
અક્ષો પરના અંતઃખંડ આપેલા હોય અથવા શોધવાના હોય.
દા.ત.: સમતલ 2x/6 + 3y/9 + 4z/12 = 1 → x/3 + y/3 + z/3 = 1. અંતઃખંડ: a=3, b=3, c=3.
રેખા-સમતલ કોણ: જો રેખાના DR (a,b,c) અને સમતલના લંબના DR (A,B,C) હોય, તો sin θ = |aA+bB+cC| / [√(a²+b²+c²) × √(A²+B²+C²)]. cos θ નહીં, sin θ યાદ રાખો!
રેખા અને સમતલ વચ્ચેનું કોણ શોધવાનો પ્રશ્ન.
દા.ત.: રેખા DR (1,2,3), સમતલ લંબ DR (2,1,0): sin θ = |2+2+0|/[√14 × √5] = 4/√70.
પ્રક્ષેપ (Projection): રેખાખંડ PQ નો x-અક્ષ પર પ્રક્ષેપ = x₂−x₁, y-અક્ષ પર = y₂−y₁, z-અક્ષ પર = z₂−z₁. લંબાઈ = √[(પ્રક્ષેપ_x)²+(પ્રક્ષેપ_y)²+(પ્રક્ષેપ_z)²].
રેખાખંડના અક્ષો પરના પ્રક્ષેપ અથવા લંબાઈ શોધવાનો પ્રશ્ન.
દા.ત.: P(1,2,3) અને Q(4,6,3): x-પ્રક્ષેપ=3, y-પ્રક્ષેપ=4, z-પ્રક્ષેપ=0. લંબાઈ = √(9+16+0) = 5.
