📄 Short Notes

ત્રિમિતીય ભૂમિતિનું પરિચય — ટૂંકા નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Introduction to Three Dimensional Geometry

📘 વ્યાખ્યાઓ

  • ત્રિમિતીય ભૂમિતિ : અવકાશમાં બિંદુઓ, રેખાઓ અને સમતલોની રચનાનું અભ્યાસ.
  • ક્ષેત્રફળ-અક્ષપદ્ધતિ (Cartesian Coordinate System) : ત્રણ પરસ્પર લંબ અક્ષો (x, y, z) પરથી અવકાશમાં કોઈ પણ બિંદુનું સ્થાન દર્શાવતી પદ્ધતિ.
  • બિંદુના निर्देशાંક (Coordinates) : (x, y, z) એકમાત્ર ત્રિક (ordered triplet) જેથી અવકાશમાં બિંદુનું સ્થાન દર્શાવાય છે.
  • અક્ષો (Axes) : x-અક્ષ, y-અક્ષ, z-અક્ષ — ત્રણેક મૂળબિંદુ O(0,0,0) પરથી પસાર થતાં અને પરસ્પર લંબ સીધી રેખાઓ.
  • સમતલો (Coordinate Planes) : xy-સમતલ (z=0), yz-સમતલ (x=0), zx-સમતલ (y=0) — બે અક્ષો પરથી પસાર થતી વિમર્શ રેખાઓ.
  • ઓક્ટન્ટ (Octant) : ત્રણેક સમતલો દ્વારા અવકાશના ભાગાકારમાં બનતી આઠ કોટિઓ (અષ્ટકો).
  • દિગ્બાહુકોણ (Direction Angles) : ધન x-, y-, z-અક્ષ સાથે રેખા દ્વારા અથવા સદિશ દ્વારા બનતા કોણ α, β, γ.
  • દિગ્બાહુ અનુપાત (Direction Ratios) : l, m, n એવા ત્રણ સંખ્યાઓ કે જે રેખાની દિશા દર્શાવે; (l,m,n) ∝ (a,b,c).
  • દિગ્બાહુ કોસાઇન (Direction Cosines) : l = cosα, m = cosβ, n = cosγ ; જ્યાં l² + m² + n² = 1.
  • દિગ્બાહુ અનુપાત (D.R.) → દિગ્બાહુ કોસાઇન : l = a/√(a²+b²+c²), m = b/√(a²+b²+c²), n = c/√(a²+b²+c²).

⚡ સૂત્રો

  • અંતર સૂત્ર : P(x₁,y₁,z₁) અને Q(x₂,y₂,z₂) વચ્ચેનું અંતર = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²].
  • મધ્યબિંદુ સૂત્ર : M = [(x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2].
  • વિભાજન સૂત્ર (અંતઃવિભાજન) : P = [(mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n)].
  • વિભાજન સૂત્ર (બાહ્યવિભાજન) : P = [(mx₂−nx₁)/(m−n), (my₂−ny₁)/(m−n), (mz₂−nz₁)/(m−n)].
  • દિગ્બાહુ કોસાઇન શોધવા : l = a/d, m = b/d, n = c/d જ્યાં d = √(a²+b²+c²).
  • રેખાનું પ્રમાણભૂત સમીકરણ : (x−x₁)/a = (y−y₁)/b = (z−z₁)/c જ્યાં (a,b,c) દિગ્બાહુ અનુપાત છે.
  • અદિશ (Cartesian) સમીકરણ : (x−x₁)/l = (y−y₁)/m = (z−z₁)/n જ્યાં l,m,n દિગ્બાહુ કોસાઇન છે.
  • સદિશ સમીકરણ (રેખા) : r⃗ = a⃗ + λb⃗, જ્યાં a⃗ આધારબિંદુ અને b⃗ દિશા દર્શાવે છે.
  • રેખાઓ વચ્ચેનો કોણ : cosθ = |l₁l₂ + m₁m₂ + n₁n₂| અથવા |a₁a₂+b₁b₂+c₁c₂|/(d₁·d₂).
  • લંબરેખા શરત : a₁a₂ + b₁b₂ + c₁c₂ = 0.

⭐ મુખ્ય તથ્યો

  • પ્રથમ ઓક્ટન્ટમાં બધા निर्देशाંક ધન હોય છે : (+,+,+).
  • xy-સમતલ પર બિંદુનું z-નિર્દેશાંક શૂન્ય હોય છે : z = 0.
  • yz-સમતલ પર x = 0 અને zx-સમતલ પર y = 0 હોય છે.
  • બિંદુ (a,b,c) નું x-અક્ષ પર લંબપાદ (a,0,0), y-અક્ષ પર (0,b,0), z-અક્ષ પર (0,0,c).
  • દિગ્બાહુ કોસાઇનનો મૂળભૂત ગુણધર્મ : l² + m² + n² = 1 હંમેશા સાચો.
  • કોઈ પણ રેખાના દિગ્બાહુ અનુપાતોમાં k(≠0) વડે ગુણતા દિશા બદલાતી નથી : (ka, kb, kc).
  • બે સમાન રેખાઓ માટે બિંદુના निर्देशाંકો સમાન હોવા જોઈએ.
  • સ્થાન સદિશ (Position Vector) : O(0,0,0) થી P(x,y,z) સુધી r⃗ = xi⃗ + yj⃗ + zk⃗.
  • રેખાના દિગ્બાહુ અનુપાતો દ્વારા લંબાઈ શોધવી : d = √(x²+y²+z²).
  • આવર્ત યોગ્ય અક્ષોની બાજુને ધ્યાનમાં લઈ ઓક્ટન્ટ નક્કી કરવા.
  • સ્પર્શક (Parametric) સ્વરૂપ : x = x₁+at, y = y₁+bt, z = z₁+ct.
  • r⃗ = a⃗ + λb⃗ સ્વરૂપમાં λ ∈ ℝ, એટલે કે λ ની કોઈ પણ વાસ્તવિક કિંમત લેઈ શકાય.

⚠️ સામાન્ય ભૂલો

  • વિભાજન સૂત્રમાં અંતઃ અને બાહ્ય કિસ્સામાં ચિન્હ બદલાય છે — સાવચેત રહો!
  • દિગ્બાહુ અનુપાતોને સીધા લંબાઈના સૂત્રમાં મૂકી શકાતા નથી; પહેલેથી કોસાઇનમાં બદલવા.
  • રેખાઓના દિગ્બાહુ અનુપાત (a,b,c) અને દિગ્બાહુ કોસાઇન (l,m,n) વચ્ચે તફાવત ગૂંચવણ પેદા કરે છે.
  • xy-સમતલ પર z = 0; yz-સમતલ પર x = 0 — આ યાદ રાખો, ઉલટું ન કરો.
  • રેખાનું સમીકરણ લખતી વખતે हर (denominator) માં દિગ્બાહુ અનુપાતો જ જુદા હોય.
  • બે રેખાઓ વચ્ચેનો કોણ શોધતી વખતે |...| લેવું જોઈએ; અદિશ ગુણાકારની ક્રમ બદલી શકાય.
  • લંબરેખા શરત a₁a₂ + b₁b₂ + c₁c₂ = 0 માં કૌણ જોડાણ ચેક કરો.
  • રેખાઓ સમાંતર હોય તો દિગ્બાહુ અનુપાતો સમપ્રમાણ હોય; l₁/l₂ = m₁/m₂ = n₁/n₂.
  • દિગ્બાહુ કોસાઇન શોધતી વખતે √(a²+b²+c²) = 0 ન લેવા જોઈએ (શૂન્ય સદિશ).
  • અંતર સૂત્રમાં બે બિંદુઓના निर्देशаंकाનાં ક્રમ બદલી શકાય; પરંતુ યોગ્ય જોડવું જરૂરી.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • અંતર સૂત્ર અને વિભાજન સૂત્રની સીધી ગણતરી GUJCET માં ચોક્કસ આવે છે.
  • દિગ્બાહુ કોસાઇન → દિગ્બાહુ અનુપાત રૂપાંતરણ હંમેશા પરીક્ષામાં આવે છે.
  • રેખાનું અદિશ અને સદિશ સમીકરણ — બંને સ્વરૂપ પ્રમાણમાં લખવું આવશ્યક.
  • બે રેખાઓ વચ્ચેનો કોણ અને લંબરેખા શરત — અંકો ઘણા આવે છે.
  • xy, yz, zx સમતલો પરના બિંદુઓના নির্দেশाંક શૂન્ય યાદ કરો.
  • ઓક્ટન્ટ પ્રમાણે ચિન્હો ચેક કરવાની કળા અંગે ધ્યાન રાખો.
  • બિંદુને અક્ષ પર પ્રક્ષેપિત કરવાના ફળિત મૂળબિંદુઓ યાદ રાખો.
  • રેખાના સમીકરણમાં a,b,c (દિગ્બાહુ અનુપાત) અને l,m,n (દિગ્બાહુ કોસાઇન) વચ્ચે સંબંધ સ્પષ્ટ રાખો.
  • રેખાઓ સમાંતર, લંબ, કે અન્ય અવસ્થા તપાસવી એ GUJCET હાઈ-યીલ્ડ પ્રશ્ન છે.
