સંબંધ અને ફંક્શન (Relations and Functions) — GUJCET પરીક્ષા ટ્રિક્સ

🧪 GUJCET — Gujarati • Mathematics • Relations and Functions

🎯 પરીક્ષા ટ્રિક્સ

ફંક્શન એ સંબંધનો વિશેષ પ્રકાર છે. જ્યારે પ્રત્યેક ઇનપુટ (x) માટે એક જ આઉટપુટ (y) હોય ત્યારે તે ફંક્શન કહેવાય. સદિશ રીતે, જો કોઈ સંબંધમાં પ્રથમ ઘટકની પુનરાવૃત્તિ થાય તો તે ફંક્શન નથી.
સંબંધ ફંક્શન છે કે નહીં તે ચકાસવા માટે.
દા.ત.: R = {(1,2), (1,3), (2,4)} — અહીં 1 ની સાથે 2 અને 3 બંને જોડાયેલ છે, માટે R ફંક્શન નથી.
વ્યાખ્યાત્ર (Domain) અને પ્રતિચય (Range) યાદ રાખવા માટે: વ્યાખ્યાત્ર = x ના મૂલ્યો, પ્રતિચય = y ના મૂલ્યો. ફંક્શનના પ્રતિચયને 'કોડોમેન' (Codomain) સાથે ગોઠવી શકાતો નથી.
વ્યાખ્યાત્ર અને પ્રતિચય શોધવા માટે.
દા.ત.: f(x) = x², વ્યાખ્યાત્ર = ℝ, પ્રતિચય = [0, ∞).
એક-એક (Injective) ફંક્શન ચકાસવા માટે: જો f(a) = f(b) ⇒ a = b, તો ફંક્શન એક-એક છે. ગ્રાફ પર, કોઈ પણ horizontal line ટચે નહીં.
ફંક્શન એક-એક છે કે નહીં તે જાણવા.
દા.ત.: f(x) = 2x + 3 એક-એક છે કારણ કે f(a) = f(b) ⇒ 2a + 3 = 2b + 3 ⇒ a = b.
આચ્છાદક (Surjective/Onto) ફંક્શન ચકાસવા માટે: પ્રતિચય = કોડોમેન. જો કોડોમેનમાં દરેક y માટે કોઈ x અસ્તિત્વ ધરાવે કે f(x) = y, તો ફંક્શન આચ્છાદક છે.
ફંક્શન આચ્છાદક છે કે નહીં તે ચકાસવા.
દા.ત.: f: ℝ → ℝ, f(x) = x³ આચ્છાદક છે કારણ કે દરેક y ∈ ℝ માટે x = ∛y અસ્તિત્વ ધરાવે છે.
દ્વિએક-દ્વિઆચ્છાદક (Bijective) ફંક્શન = એક-એક + આચ્છાદક. જો ફંક્શન બંને ગુણધર્મો ધરાવે તો તે દ્વિએક-દ્વિઆચ્છાદક છે.
ફંક્શન દ્વિએક-દ્વિઆચ્છાદક છે કે નહીં તે જાણવા.
દા.ત.: f: ℝ → ℝ, f(x) = x³ દ્વિએક-દ્વિઆચ્છાદક છે.
ફંક્શનના પ્રકારો યાદ રાખવા: સરળ રેખીય (Linear), દ્વિઘાત (Quadratic), ઘાતાંકીય (Exponential), લૉગેરિથમિક (Logarithmic), ત્રિકોણમિતીય (Trigonometric).
ફંક્શનના પ્રકાર ઓળખવા.
દા.ત.: f(x) = 3x + 2 → સરળ રેખીય ફંક્શન.
સમમિત સંબંધ (Symmetric Relation): જો (a,b) ∈ R ⇒ (b,a) ∈ R. સરળ રીતે, સંબંધ મેળવી શકાય છે કે કેમ તે ચકાસો.
સંબંધ સમમિત છે કે નહીં તે ચકાસવા.
દા.ત.: R = {(1,2), (2,1), (3,3)} સમમિત છે.
સંક્રમણીય સંબંધ (Transitive Relation): જો (a,b) ∈ R અને (b,c) ∈ R ⇒ (a,c) ∈ R. સાંકેતિક રીતે, 'a ~ b અને b ~ c ⇒ a ~ c'.
સંબંધ સંક્રમણીય છે કે નહીં તે ચકાસવા.
દા.ત.: R = {(1,2), (2,3), (1,3)} સંક્રમણીય છે.
તુલ્યતા સંબંધ (Equivalence Relation) = પ્રતિબિંબી (Reflexive) + સમમિત (Symmetric) + સંક્રમણીય (Transitive).
સંબંધ તુલ્યતા સંબંધ છે કે નહીં તે ચકાસવા.
દા.ત.: R = {(1,1), (2,2), (3,3), (1,2), (2,1)} તુલ્યતા સંબંધ નથી કારણ કે (1,3) અથવા (3,1) નથી.
ફંક્શનનું સંયોજન (Composition of Functions): (f ∘ g)(x) = f(g(x)). ક્રમ મહત્વપૂર્ણ છે, f ∘ g ≠ g ∘ f હોવાનું શક્ય છે.
ફંક્શનનું સંયોજન શોધવા.
દા.ત.: f(x) = 2x, g(x) = x + 1 ⇒ (f ∘ g)(x) = f(x + 1) = 2(x + 1) = 2x + 2.
વિલોમ ફંક્શન (Inverse Function): જો f: A → B દ્વિએક-દ્વિઆચ્છાદક હોય, તો f⁻¹: B → A અસ્તિત્વ ધરાવે છે અને f(f⁻¹(x)) = x.
ફંક્શનનું વિલોમ શોધવા.
દા.ત.: f(x) = 2x + 3 ⇒ f⁻¹(x) = (x - 3)/2.
ફંક્શનની રેખીયતા ચકાસવા: જો f(ax + by) = a f(x) + b f(y), તો ફંક્શન રેખીય (Linear) છે.
ફંક્શન રેખીય છે કે નહીં તે ચકાસવા.
દા.ત.: f(x) = 3x રેખીય છે કારણ કે f(ax + by) = 3(ax + by) = a(3x) + b(3y) = a f(x) + b f(y).
દ્વિઘાત ફંક્શન (Quadratic Function) નો ગ્રાફ પરવલય (Parabola) હોય છે. જો a > 0, તો પરવલય ઉપર તરફ ખુલે છે; જો a < 0, તો નીચે તરફ ખુલે છે.
દ્વિઘાત ફંક્શનના ગ્રાફની દિશા જાણવા.
દા.ત.: f(x) = x² - 4x + 4 → a = 1 > 0, માટે પરવલય ઉપર તરફ ખુલે છે.
ફંક્શનના શૂન્ય (Zeros/Roles) શોધવા માટે f(x) = 0 ઉકેલો. દ્વિઘાત ફંક્શન માટે, શૂન્ય શોધવા ક્વોડ્રેટિક ફોર્મ્યુલા વાપરો: x = [-b ± √(b² - 4ac)] / (2a).
ફંક્શનના શૂન્ય શોધવા.
દા.ત.: f(x) = x² - 5x + 6 = 0 ⇒ x = [5 ± √(25 - 24)] / 2 ⇒ x = 2 અથવા x = 3.
