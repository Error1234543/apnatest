ત્રિકોણમિતીય ફંક્શન્સ

🧪 GUJCET — Gujarati • Mathematics • Trigonometric Functions

ત્રિકોણમિતીનો પરિચય
ત્રિકોણમિતી એ ભૂજા અને ખૂણાઓ વચ્ચેના સંબંધનો અભ્યાસ છે.
ત્રિકોણમિતીય ફંક્શન્સ (Trigonometric Functions) એ કોઈ ખૂણાને આધારે પરિભાષિત થાય છે.
મુખ્ય ત્રિકોણમિતીય ફંક્શન્સ: સાઇન (sin), કોસાઇન (cos), ટેનજન્ટ (tan), કોસેકન્ટ (cosec), સેકન્ટ (sec), કોટેનજન્ટ (cot).
📝 યાદ રાખો: sinθ = 1/cosecθ, cosθ = 1/secθ, tanθ = 1/cotθ.
ત્રિકોણમિતીય ફંક્શન્સની પરિભાષા
લંબકોણ ત્રિકોણ (Right-Angled Triangle)માં, ખૂણા θ માટે:
sinθ = સામેની ભૂજા / કર્ણ (Opposite / Hypotenuse)
cosθ = આડી ભૂજા / કર્ણ (Adjacent / Hypotenuse)
tanθ = સામેની ભૂજા / આડી ભૂજા (Opposite / Adjacent)
cosecθ = 1/sinθ, secθ = 1/cosθ, cotθ = 1/tanθ
📝 ફંક્શન્સની કિંમતો હંમેશા ખૂણા પર આધાર રાખે છે.
ત્રિકોણમિતીય ફંક્શન્સના લક્ષણો
સાઇન અને કોસાઇન ફંક્શન્સની કિંમતો -1 થી 1 વચ્ચે હોય છે.
ટેનજન્ટ અને કોટેનજન્ટ ફંક્શન્સની કિંમતો -∞ થી +∞ સુધી હોઈ શકે છે.
sin²θ + cos²θ = 1 (મૂળભૂત ઓળખ)
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ
📝 આ ઓળખોને પાયથાગોરસ ઓળખ કહેવાય છે.
ત્રિકોણમિતીય ફંક્શન્સના ચિહ્નો (Signs of Trigonometric Functions)
પહેલા ચરણ (0° < θ < 90°): બધા ફંક્શન્સ ધન (Positive) હોય છે.
બીજા ચરણ (90° < θ < 180°): સાઇન અને કોસેકન્ટ ધન, બાકી ઋણ (Negative) હોય છે.
ત્રીજા ચરણ (180° < θ < 270°): ટેનજન્ટ અને કોટેનજન્ટ ધન, બાકી ઋણ હોય છે.
ચોથા ચરણ (270° < θ < 360°): કોસાઇન અને સેકન્ટ ધન, બાકી ઋણ હોય છે.
યાદ રાખવા માટે: 'ASTC' (All, Sin-Tan, Cos-Cot, Sin-Tan)
📝 ચરણોની યાદી: 1લો - A, 2જો - S, 3જો - T, 4થો - C.
ત્રિકોણમિતીય ફંક્શન્સના સરવાળા અને તફાવતના સૂત્રો
sin(A ± B) = sinA cosB ± cosA sinB
cos(A ± B) = cosA cosB ∓ sinA sinB
tan(A ± B) = (tanA ± tanB) / (1 ∓ tanA tanB)
સરવાળા માટે +, તફાવત માટે - ચિહ્ન લાગુ પડે છે.
📝 આ સૂત્રો એંગલના સરવાળા/તફાવત માટે ઉપયોગી છે.
દ્વિગુણ ખૂણાના સૂત્રો (Double Angle Formulas)
sin(2θ) = 2 sinθ cosθ
cos(2θ) = cos²θ - sin²θ = 2cos²θ - 1 = 1 - 2sin²θ
tan(2θ) = 2tanθ / (1 - tan²θ)
કોસાઇનના દ્વિગુણ સૂત્રના ત્રણ સ્વરૂપો યાદ રાખો.
📝 આ સૂત્રો દ્વિગુણ ખૂણાના ગણિતમાં ઉપયોગી છે.
ત્રિકોણમિતીય સરવાળાનાં ફેરફાર સૂત્રો (Sum to Product)
sinA + sinB = 2 sin((A+B)/2) cos((A-B)/2)
sinA - sinB = 2 cos((A+B)/2) sin((A-B)/2)
cosA + cosB = 2 cos((A+B)/2) cos((A-B)/2)
cosA - cosB = -2 sin((A+B)/2) sin((A-B)/2)
📝 ફેરફાર સૂત્રો સરવાળા અને તફાવતને ગુણાકારમાં રૂપાંતરિત કરે છે.
ત્રિકોણમિતીય ગુણાકારનાં ફેરફાર સૂત્રો (Product to Sum)
sinA sinB = [cos(A-B) - cos(A+B)] / 2
cosA cosB = [cos(A-B) + cos(A+B)] / 2
sinA cosB = [sin(A+B) + sin(A-B)] / 2
cosA sinB = [sin(A+B) - sin(A-B)] / 2
📝 ગુણાકારને સરવાળા અને તફાવતમાં રૂપાંતરિત કરવા ઉપયોગી.
ત્રિકોણમિતીય ફંક્શન્સના વ્યસ્ત ફંક્શન્સ (Inverse Trigonometric Functions)
વ્યસ્ત ફંક્શન્સ એ ખૂણાને શોધવા માટે વપરાય છે જ્યારે ફંક્શનની કિંમત આપેલ હોય.
મુખ્ય વ્યસ્ત ફંક્શન્સ: arcsin (sin⁻¹), arccos (cos⁻¹), arctan (tan⁻¹).
sin⁻¹x = θ ⇒ x = sinθ, જ્યાં -π/2 ≤ θ ≤ π/2
cos⁻¹x = θ ⇒ x = cosθ, જ્યાં 0 ≤ θ ≤ π
tan⁻¹x = θ ⇒ x = tanθ, જ્યાં -π/2 < θ < π/2
વ્યસ્ત ફંક્શન્સના ડોમેઇન અને રેન્જ યાદ રાખો.
📝 arcsin, arccos, arctan એ વ્યસ્ત ફંક્શન્સના નામ છે.
ત્રિકોણમિતીય સમીકરણો (Trigonometric Equations)
ત્રિકોણમિતીય સમીકરણો એ એવા સમીકરણો છે જેમાં ત્રિકોણમિતીય ફંક્શન્સનો સમાવેશ થાય છે.
ઉદાહરણ: sinθ = 1/2, cos2θ = 0, tanθ = √3.
ઉકેલ મેળવવા માટે, ફંક્શનની કિંમત અને તેના ચિહ્નનો ઉપયોગ કરો.
સામાન્ય ઉકેલ: θ = nπ ± α, જ્યાં α એ મૂળ ઉકેલ છે અને n એ પૂર્ણાંક છે.
📝 સમીકરણનો ઉકેલ હંમેશા ડિગ્રી અથવા રેડિયનમાં આપો.
ત્રિકોણમિતીય ફંક્શન્સના આલેખ (Graphs of Trigonometric Functions)
sinθ અને cosθના આલેખ લહેર જેવા (Sine Wave) હોય છે.
tanθનો આલેખ આવર્તી (Periodic) છે અને તેમાં અસીમપણા (Asymptotes) હોય છે.
sinθ અને cosθની આવર્તી (Period) 2π રેડિયન (360°) હોય છે.
tanθ અને cotθની આવર્તી π રેડિયન (180°) હોય છે.
આલેખ દોરતી વખતે, મહત્તમ, લઘુતમ અને શૂન્ય બિંદુઓ નોંધો.
📝 sinθ અને cosθના આલેખ વચ્ચે π/2 રેડિયનનો તફાવત હોય છે.
