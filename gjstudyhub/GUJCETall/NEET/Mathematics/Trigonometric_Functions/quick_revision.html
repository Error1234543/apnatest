ત્રિકોણમિતિ વિધેયો — ક્વિક રીવિઝન શીટ

🧠 યાદ રાખો

1 ચક્ર = 360° = 2π રેડિયન; 180° = π રેડિયન હંમેશા યાદ રાખો.
θ = (nπ/180) રેડિયન (જ્યાં n અંશમાં છે); n = θ × (180/π) રેડિયન.
ચતુર્થાંશ મુજબ ASTC નિયમ: I બધા ધન, II ત્રિકોણમિતિ (sin, cosec) ધન, III સ્પર્શક/કોસપર્શક ધન, IV cos, sec ધન.
θ ઋણ હોય તો: sin(–θ) = –sinθ, tan(–θ) = –tanθ (રોગ), cos(–θ) = cosθ (યુગ્મ).
विशेष કોણના મૂલ્યો: sin 30°=½, cos 30°=√3/2, tan 30°=1/√3; sin 45°=cos 45°=1/√2, tan 45°=1; sin 60°=√3/2, cos 60°=½, tan 60°=√3.
પરિઘ લંબાઈ S = rθ (θ રેડિયનમાં), વૃત્તખંડનો વાળ સંબંધ: 1° = π/180 રેડિયન ≈ 0.01745.

⚡ ઝડપી સૂત્રો

møળભૂત નિત્યસમ: sin²θ + cos²θ = 1 → 1 + tan²θ = sec²θ → 1 + cot²θ = cosec²θ
સંયુક્ત કોણ: sin(A±B) = sinA cosB ± cosA sinB | cos(A±B) = cosA cosB ∓ sinA sinB | tan(A±B) = (tanA ± tanB)/(1 ∓ tanA tanB)
દ્વિકોણ સૂત્રો: sin 2θ = 2sinθ cosθ | cos 2θ = cos²θ – sin²θ = 2cos²θ – 1 = 1 – 2sin²θ | tan 2θ = 2tanθ/(1 – tan²θ)
અર્ધકોણ સૂત્રો: sin θ/2 = ±√[(1 – cosθ)/2] | cos θ/2 = ±√[(1 + cosθ)/2] | tan θ/2 = ±√[(1 – cosθ)/(1 + cosθ)] = sinθ/(1+cosθ) = (1-cosθ)/sinθ
પરિવર્તન સૂત્રો: sin(nπ ± θ), cos(nπ ± θ), sin(π/2 ± θ) યાદ રાખો — odd multiple of π/2 હોય તો sin↔cos, even multiple of π હોય તો ચિહ્ન જાળવો.
પૂરક કોણ: sin(90°–θ)=cosθ, cos(90°–θ)=sinθ, tan(90°–θ)=cotθ; સમાન રેડિયનમાં પણ લાગુ.

✅ વન-લાઈનર્સ

સામાન્ય ઉકેલ: sinθ = sinα ⇒ θ = nπ + (–1)ⁿα, n ∈ ℤ (અનેક સૌથી મહત્વપૂર્ણ).
સામાન્ય ઉકેલ: cosθ = cosα ⇒ θ = 2nπ ± α, n ∈ ℤ.
સામાન્ય ઉકેલ: tanθ = tanα ⇒ θ = nπ + α, n ∈ ℤ.
sinθ = 0 ⇒ θ = nπ | cosθ = 0 ⇒ θ = (2n+1)π/2 | tanθ = 0 ⇒ θ = nπ.
sinθ = 1 ⇒ θ = (4n+1)π/2 | cosθ = 1 ⇒ θ = 2nπ.
સૂક્ષ્મ કોણ (θ ખૂબ નાનો): sinθ ≈ θ, tanθ ≈ θ, cosθ ≈ 1 (θ રેડિયનમાં).
sin(nx) + sin((n+2)x) = 2sin((n+1)x)cos x; આ શિત્તિ સૂત્ર ઝડપી ઉકેલમાં કામ આવે છે.
જો sinθ + cosθ = a હોય તો sinθ cosθ = (a²–1)/2; સમાન પ્રકારના પ્રશ્નો ગણતરી ઝડપી બનાવે છે.
દ્વિકોણ/અર્ધકોણ ઉપયોગ: sin²θ = (1–cos2θ)/2, cos²θ = (1+cos2θ)/2 — ઘાત ઘટાડવા માટે આવશ્યક.
θ = A + B, AB = C જણાતું હોય તો sinA·sinB, cosA·cosB, tanA+tanB વડે સમીકરણ બનાવી શકાય.
