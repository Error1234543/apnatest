ત્રિકોણમિતીય ફંક્શન્સ - ટૂંક નોંધ (GUJCET)

🧪 GUJCET — Gujarati • Mathematics • Trigonometric Functions

📘 વ્યાખ્યાઓ

  • ત્રિકોણમિતી: ત્રિકોણના કોણ અને બાજુઓ વચ્ચેના સંબંધનો અભ્યાસ.
  • કોણ (Angle): બે કિરણોના મૂળબિંદુ પર મળીને બનતો ખૂણો, માપન એ ડિગ્રી અથવા રેડિયનમાં થાય.
  • રેડિયન (Radian): એવો કોણ જ્યારે ચાપની લંબાઈ = ત્રિજ્યા, 1 રેડિયન ≈ 57.2958°.
  • ત્રિકોણમિતીય ફંક્શન (Trigonometric Function): કોણના મૂલ્ય પર આધારિત ફંક્શન, જેમ કે sin, cos, tan, cot, sec, cosec.
  • એકમ વર્તુળ (Unit Circle): ત્રિજ્યા 1 એવું વર્તુળ, જ્યાં કોણના ત્રિકોણમિતીય ફંક્શનના મૂલ્યો સરળતાથી મેળવી શકાય.
  • પરિમાણિક કોણ (Standard Angle): મૂળબિંદુ પર શરૂ થતો અને x-અક્ષ સાથે બનતો કોણ.
  • સહ-ફંક્શન (Co-function): sin(90°-θ) = cosθ, cos(90°-θ) = sinθ વગેરે જેવા સંબંધો ધરાવતાં ફંક્શન્સ.
  • ત્રિકોણમિતીય ઓળખ (Trigonometric Identity): કોઈપણ કોણ માટે સત્ય એવું સમીકરણ, જેમ કે sin²θ + cos²θ = 1.
  • અવકલનીય કોણ (Reference Angle): કોઈપણ કોણનો નજીકનો x-અક્ષ સાથે બનતો ઝીંગા કોણ, જ્યાં ત્રિકોણમિતીય ફંક્શનના મૂલ્યો સરખા હોય.
  • ચક્રીય ફંક્શન (Periodic Function): એવું ફંક્શન જેમાં નિયત અંતરાલ (Period) પછી મૂલ્યો પુનરાવર્તિત થાય, જેમ કે sin અને cos નો પીરિયડ 2π રેડિયન છે.
  • વિપરિત ત્રિકોણમિતીય ફંક્શન (Inverse Trigonometric Function): ત્રિકોણમિતીય ફંક્શનના વિપરિત, જેમ કે sin⁻¹x, cos⁻¹x, જ્યાં x ફંક્શનનું મૂલ્ય અને પરિણામ કોણ હોય.
  • ત્રિકોણમિતીય સમીકરણ (Trigonometric Equation): ત્રિકોણમિતીય ફંક્શન ધરાવતું સમીકરણ, જેમ કે sinθ = 0.5.

⚡ સૂત્રો

  • sinθ = પાસેની બાજુ / કર્ણ (Opposite / Hypotenuse)
  • cosθ = આડી બાજુ / કર્ણ (Adjacent / Hypotenuse)
  • tanθ = પાસેની બાજુ / આડી બાજુ = sinθ / cosθ
  • cotθ = આડી બાજુ / પાસેની બાજુ = 1 / tanθ
  • secθ = કર્ણ / આડી બાજુ = 1 / cosθ
  • cosecθ = કર્ણ / પાસેની બાજુ = 1 / sinθ
  • sin²θ + cos²θ = 1
  • 1 + tan²θ = sec²θ
  • 1 + cot²θ = cosec²θ
  • sin(A ± B) = sinAcosB ± cosAsinB
  • cos(A ± B) = cosAcosB ∓ sinAsinB
  • tan(A ± B) = (tanA ± tanB) / (1 ∓ tanAtanB)
  • sin2θ = 2sinθcosθ
  • cos2θ = cos²θ - sin²θ = 2cos²θ - 1 = 1 - 2sin²θ
  • tan2θ = 2tanθ / (1 - tan²θ)
  • sin3θ = 3sinθ - 4sin³θ
  • cos3θ = 4cos³θ - 3cosθ

⭐ મુખ્ય તથ્યો

  • sin(0°) = 0, cos(0°) = 1, tan(0°) = 0
  • sin(30°) = 1/2, cos(30°) = √3/2, tan(30°) = 1/√3
  • sin(45°) = cos(45°) = √2/2, tan(45°) = 1
  • sin(60°) = √3/2, cos(60°) = 1/2, tan(60°) = √3
  • sin(90°) = 1, cos(90°) = 0, tan(90°) અવ્યાખ્યાયિત (Undefined)
  • sin(180°-θ) = sinθ, cos(180°-θ) = -cosθ, tan(180°-θ) = -tanθ
  • sin(180°+θ) = -sinθ, cos(180°+θ) = -cosθ, tan(180°+θ) = tanθ
  • sin(360°-θ) = -sinθ, cos(360°-θ) = cosθ, tan(360°-θ) = -tanθ
  • sin(-θ) = -sinθ, cos(-θ) = cosθ, tan(-θ) = -tanθ
  • sinθ અને cosθ ના મૂલ્યો -1 થી 1 વચ્ચે હોય છે.
  • tanθ અને cotθ ના મૂલ્યો -∞ થી +∞ વચ્ચે હોય છે.
  • secθ અને cosecθ ના મૂલ્યો (-∞, -1] ∪ [1, +∞) વચ્ચે હોય છે.

⚠️ સામાન્ય ભૂલો

  • tanθ = sinθ / cosθ મા ભૂલથી tanθ = sinθ * cosθ લખવું.
  • sin(A + B) મા ભૂલથી sinA + sinB લખવું.
  • cos(A - B) મા ભૂલથી cosA - cosB લખવું.
  • 2sinθcosθ = sin2θ ને ભૂલથી sinθ + cosθ લખવું.
  • ત્રિકોણમિતીય ફંક્શનના ડોમેન અને રેન્જને ભૂલી જવું, જેમ કે sin⁻¹x નો ડોમેન [-1,1] છે.
  • રેડિયન અને ડિગ્રી વચ્ચેના રૂપાંતરણમાં ભૂલ કરવી, જેમ કે π રેડિયન = 180°.
  • કોણના ચોથા ક્વોડ્રન્ટમાં tanθ નું ચિહ્ન ભૂલી જવું (tanθ = -ve).
  • ત્રિકોણમિતીય ઓળખોનો ઉપયોગ ન કરવો જ્યારે સમીકરણ સરળ બનાવી શકાય.
  • સહ-ફંક્શન સંબંધો ભૂલી જવા, જેમ કે sin(90°-θ) = cosθ.
  • પીરિયડિક ફંક્શનના પીરિયડને ભૂલી જવું, જેમ કે tanθ નો પીરિયડ π રેડિયન છે.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • ત્રિકોણમિતીય ફંક્શનના ગ્રાફ્સ અને તેમના આકારને સમજવું અગત્યનું છે.
  • એકમ વર્તુળનો ઉપયોગ કરીને ત્રિકોણમિતીય ફંક્શનના મૂલ્યો શોધવા સરળ છે.
  • ત્રિકોણમિતીય ઓળખોનો ઉપયોગ સમીકરણો અને અસમીકરણો ઉકેલવા માટે થાય છે.
  • વિપરિત ત્રિકોણમિતીય ફંક્શનના ડોમેન અને રેન્જ યાદ રાખવા.
  • ત્રિકોણમિતીય ફંક્શનના સરવાળા અને તફાવતના ફોર્મ્યુલા યાદ રાખવા.
  • દ્વિગુણ કોણના ફોર્મ્યુલા (Double Angle) યાદ રાખવા.
  • ત્રિગુણ કોણના ફોર્મ્યુલા (Triple Angle) યાદ રાખવા.
  • ત્રિકોણમિતીય ફંક્શનના ગ્રાફ્સના આકાર અને તેમના પીરિયડ, એમ્પ્લિટ્યુડ, અને ફેઝ શિફ્ટ સમજવું.
  • કોઇપણ કોણ માટે ત્રિકોણમિતીય ફંક્શનના મૂલ્યો શોધવા માટે રેફરન્સ કોણનો ઉપયોગ કરવો.
  • ત્રિકોણમિતીય સમીકરણો ઉકેલવા માટે જનરલ સોલ્યુશન (General Solution) શોધવું અગત્યનું છે.
