ત્રિ-પરિમાણ ભૂમિતિ — સંપૂર્ણ નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Three Dimensional Geometry

ત્રિ-પરિમાણ ભૂમિતિ એ ગણિતની એવી શાખા છે જ્યાં આપણે બિંદુઓ, રેખાઓ, સમતલો અને તેમના મધ્યનાં સંબંધોને ત્રણ પરિમાણો (x, y, z) ની મદદથી અભ્યાસ કરીએ છીએ. GUJCET માં આ અધ્યાયનું મહત્વ ખૂબ છે કારણ કે તે વેક્ટરજ્ઞાન અને રેખીય બીજગણિતના સંયોજન સાથે પ્રશ્નો પૂછે છે. અહીં તમે અક્ષો, સમતલો, દિક્કોસાઇન, રેખા અને સમતલના સમીકરણો, તેમનાં મધ્યના કોણ અને લંબાઈ જેવા મુખ્ય વિષયો મેળવશો. આ નોટ્સ તમને પૂર્ણ આચરણ અને પ્રશ્ન સમાધાનમાં મદદરૂપ થશે.

ત્રિ-પરિમાણ અવકાશ અને ધ્રુવ યામપદ્ધતિ (Cartesian Coordinate System in 3D)

ત્રિ-પરિમાણ અવકાશ (Three-dimensional space) ત્રણ પરસ્પર લંબ અક્ષો x-અક્ષ, y-અક્ષ અને z-અક્ષ ધરાવે છે, જે મૂળબિંદુ O(0,0,0) પર છેદે છે. હરેક બિંદુ P ને (x, y, z) આ રીતે દર્શાવવામાં આવે છે, જ્યાં x, y, z અનુક્રમે અક્ષો પરના પ્રક્ષેપ છે. અક્ષો બે સમતલો બનાવે છે: xy-સમતલ (z=0), yz-સમતલ (x=0), zx-સમતલ (y=0). આ સમતલો અવકાશને 8 ભાગમાં વહેંચે છે, જેને ઓક્ઝન્ટ (octants) કહીએ છીએ. ઉદાહરણ તરીકે, (+,+,+) ઓક્ઝન્ટમાં તમામ યામ ધન હોય છે. આ યામપદ્ધતિ રેખા, સમતલ અને તેમનાં સમીકરણો લખવાની પાયદાળ છે. GUJCET માં યામોની ચિહ્ન પરિવર્તન, ઓક્ઝન્ટ સંબંધી પ્રશ્નો પણ આવે છે.

દિક્કોસાઇન (Direction Cosines) અને દિશાઅનુપાત

કોઈ રેખા અથવા સદિશ માટે, તે અક્ષો સાથે બનાવતો કોણ α, β, γ હોય છે. આ કોણના કોસાઇન cos α, cos β, cos γ ને તે રેખા/સદિશના દિક્કોસાઇન (Direction Cosines) કહીએ છીએ. જો દિશાઅનુપાત l : m : n હોય, તો દિક્કોસાઇન મેળવવા માટે સૌપ્રથમ પ્રમાણકર્તા k શોધો: l = ka, m = kb, n = kc, જ્યાં a,b,d દિશાઅનુપાત છે. પછી l² + m² + n² = 1 શરત વડે k શોધી કોસાઇન મેળવો. ઉદાહરણ: જો દિશાઅનુપાત 2 : -1 : 2 હોય, તો k = 1/√(4+1+4) = 1/3, તેથી દિક્કોસાઇન 2/3, -1/3, 2/3. ગુજરાતી માધ્યમ પાઠ્યપુસ્તકમાં આ વિભાગ બહુ મહત્વનો છે અને એના પરથી રેખાના સમીકરણો મેળવવામાં આવે છે.

ધરમસંબંધ
દિક્કોસાઇનl = cos α, m = cos β, n = cos γ
મૂળભૂત સર્વસમકામl² + m² + n² = 1
દિશાઅનુપાતથી દિક્કોસાઇનl = a/√(a²+b²+c²), ...

બે બિંદુઓ વચ્ચેનું અંતર અને વિભાજન સૂત્ર

ત્રિ-પરિમાણમાં બે બિંદુઓ P(x₁,y₁,z₁) અને Q(x₂,y₂,z₂) વચ્ચેનું અંતર PQ = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²] થાય. આ દ્વિ-પરિમાણના અંતર સૂત્રનો સાધારણીકરણ છે. બિંદુ P અને Q ને m:n અનુપાતમાં વિભાજિત કરતું બિંદુ R ના યામ [(mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n)] મળે. જો R, PQ નું મધ્યબિંદુ હોય (m=n=1), તો R = [(x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2]. આ સૂત્રો વેક્ટર પદ્ધતિથી પણ મેળવી શકાય. પ્રત્યેક વિભાગીય પ્રશ્નમાં યામોના ચિહ્ન અને અનુપાતની દિશા (અંદર/બહાર) ધ્યાનથી જોવી જોઈએ. GUJCET માં વિભાજન સૂત્રનો ઉપયોગ સંયોજક પ્રશ્નોમાં થાય છે.

રેખાનું સમીકરણ — સદિશ રૂપ (Vector Form)

જો રેખા B બિંદુમાંથી પસાર થતી હોય અને ડિરેક્શન વેક્ટર b સાથે હોય, તો તેનું સદિશ સમીકરણ r = a + λb છે, જ્યાં a એ B સ્થાન સદિશ છે અને λ ∈ R. જો રેખા બે બિંદુઓ A(a) અને B(b) માંથી પસાર થતી હોય, તો દિશાઅનુપાત (b-a) મળે અને સમીકરણ r = a + λ(b-a) થાય. λ એ પરિમાણ છે જે રેખા પરના દરેક બિંદુને દર્શાવે છે. સદિશ સમીકરણનું કાર્ટેઝીય રૂપ મેળવવા માટે r = xi + yj + zk, a = x₁i + y₁j + z₁k, b = b₁i + b₂j + b₃k મૂકીને સરખાવવામાં આવે છે. આ પદ્ધતિ ખૂબ ઉપયોગી છે જ્યારે પ્રશ્નમાં સદિશ જવાબ માંગવામાં આવે.

રેખાનું સમીકરણ — કાર્ટેઝીય રૂપ (Cartesian Form)

રેખાનો (x₁,y₁,z₁) બિંદુમાંથી પસાર થતો અને દિશાઅનુપાત a, b, c ધરાવતો હોય, તો કાર્ટેઝીય સમીકરણ છે: (x - x₁)/a = (y - y₁)/b = (z - z₁)/c. આ રૂપને 'સymmetrical form' પણ કહે છે. જો રેખા બે બિંદુઓ (x₁,y₁,z₁) અને (x₂,y₂,z₂) માંથી પસાર થતી હોય, તો દિશાઅનુપાત (x₂-x₁):(y₂-y₁):(z₂-z₁) લઈને સમીકરણ લખાય. અહીં a, b, c શૂન્ય હોઈ શકે નહીં; જો કોઈ એક શૂન્ય હોય, તો અનુરૂપ અંશ શૂન્ય લઈને અને છેદમાં દિશાઅનુપાત લઈને લખાય (ઉદા. x = x₁). આ સમીકરણનો ઉપયોગ રેખા-રેખા, રેખા-સમતલ મધ્યના કોણ શોધવા માટે થાય છે. GUJCET માં આ રૂપનું રૂપાંતરણ અને સમીકરણ મેળવવાના પ્રશ્નો બહુ આવે છે.

સામાન્ય રૂપ(x - x₁)/a = (y - y₁)/b = (z - z₁)/c
બે બિંદુઓ વડે(x-x₁)/(x₂-x₁) = (y-y₁)/(y₂-y₁) = (z-z₁)/(z₂-z₁)

સમતલનું સમીકરણ — સદિશ રૂપ

સમતલનું સદિશ સમીકરણ બે પ્રકારનું હોય છે: (1) જો સમતલના લંબ સદિશ n અને સમતલ પરનું બિંદુ a હોય, તો (r - a) · n = 0, એટલે r · n = a · n. (2) જો સમતલ ત્રણ બિંદુઓ a, b, c માંથી પસાર થતું હોય, તો (r - a) · [(b-a) × (c-a)] = 0. અહીં n એ સમતલનો લંબ સદિશ છે. સદિશ સમીકરણના ઉપયોગો: સમતલ પરનું બિંદુ તપાસવું, સમતલ સમાંતર/લંબ હોવું તપાસવું, અને અન્ય રેખા/સમતલ સાથે સંબંધ શોધવો. GUJCET માં વેક્ટર પદ્ધતિથી સમીકરણ લખવાના પ્રશ્નો પણ આવે છે, તેથી આ રૂપ મજબૂત રીતે સમજવો જોઈએ.

સમતલનું સમીકરણ — કાર્ટેઝીય રૂપ

સમતલનું સામાન્ય કાર્ટેઝીય સમીકરણ Ax + By + Cz + D = 0 હોય છે, જ્યાં (A, B, C) સમતલના લંબ દિશાઅનુપાત છે. જો સમતલના લંબના દિક્કોસાઇન l, m, n હોય અને મૂળબિંદુથી લંબ દૂરી p હોય, તો પ્રમાણિત રૂપ lx + my + nz = p મળે. સમતલ (x₁,y₁,z₁) બિંદુમાંથી પસાર થતું હોય અને લંબ દિશઅનુપાત (a,b,c) હોય, તો સમીકરણ a(x-x₁)+b(y-y₁)+c(z-z₁)=0 થાય. બે બિંદુઓ અને લંબ દિશ મળે ત્યારે પણ આ સમીકરણ ઉપયોગી બને છે. આ રૂપ સાથે રેખા-સમતલ, સમતલ-સમતલ મધ્યના કોણ અને દૂરી શોધવી સરળ બને છે. પ્રત્યેક પ્રશ્નમાં A, B, C ના ચિહ્ન ધ્યાનથી લેવાં જોઈએ.

લંબ દિશઅનુપાત સાથેa(x-x₁)+b(y-y₁)+c(z-z₁)=0
નૉર્મલ ફોર્મlx + my + nz = p

રેખા અને સમતલ વચ્ચેનું કોણ

રેખાનો દિશ સદિશ b અને સમતલનો લંબ સદિશ n હોય, તો રેખા અને સમતલ વચ્ચેનો કોણ θ એ b અને n વચ્ચેના કોણ φ નો પૂરક કોણ હોય છે: sin θ = |b·n|/(|b||n|). જો રેખા (x-x₁)/a = (y-y₁)/b = (z-z₁)/c હોય અને સમતલ Ax+By+Cz+D=0 હોય, તો sin θ = |Aa+Bb+Cc|/(√(A²+B²+C²)√(a²+b²+c²)). જો b·n = 0 હોય, તો રેખા સમતલ સમાંતર હોય (અથવા સમતલમાં હોય). જો b અને n સંપાતી હોય, તો રેખા સમતલ પર લંબ હોય. આ સૂત્ર GUJCET માં અત્યંત આવર્તક પ્રશ્નો આપે છે, તેથી સૂત્ર અને તેનો ઉપયોગ સારી રીતે અભ્યાસ કરવો.

બે સમતલ વચ્ચેનું કોણ અને સમાંતર/લંબતા શરત

બે સમતલોના લંબ સદિશ n₁ અને n₂ વચ્ચેનો કોણ જ બે સમતલ વચ્ચેનો કોણ θ હોય છે. cos θ = |n₁·n₂|/(|n₁||n₂|). જો n₁·n₂ = 0 હોય, તો સમતલો પરસ્પર લંબ હોય. જો n₁ અને n₂ સંપાતી હોય (એકબીજાના સ્કેલિંગ), તો સમતલો સમાંતર હોય. કાર્ટેઝીય રૂપમાં, સમતલ A₁x+B₁y+C₁z+D₁=0 અને A₂x+B₂y+C₂z+D₂=0 માટે, લંબતા શરત A₁A₂+B₁B₂+C₁C₂=0 અને સમાંતરતા શરત A₁/A₂ = B₁/B₂ = C₁/C₂. ધ્યાન રાખો કે સમાંતર સમતલોના D ના ગુણોત્તર સમાન હોવા જોઈએ નહીં, નહીંતર સમતલો અભિસારી (coincident) થાય. આ બિંદુ GUJCET માં પકડી લેવા જેવો છે.

લંબતાA₁A₂+B₁B₂+C₁C₂=0
સમાંતરતાA₁/A₂ = B₁/B₂ = C₁/C₂

બિંદુથી સમતલ અને રેખાથી સમતલ પરની લંબ દૂરી

બિંદુ (x₁,y₁,z₁) માંથી સમતલ Ax+By+Cz+D=0 પરની લંબ દૂરી d = |Ax₁+By₁+Cz₁+D|/√(A²+B²+C²). મૂળબિંદુ માટે d = |D|/√(A²+B²+C²). સમતલના નૉર્મલ ફોર્મ lx+my+nz=p માટે, બિંદુ P(x₁,y₁,z₁) માંથી દૂરી |lx₁+my₁+nz₁-p|. રેખા (x-x₁)/a = (y-y₁)/b = (z-z₁)/c અને સમતલ Ax+By+Cz+D=0 વચ્ચેનો કોણ શૂન્ય હોય ત્યારે લંબ દૂરી શૂન્ય થાય (એટલે રેખા સમતલ પર હોય). જો રેખા સમતલ સમાંતર હોય, તો રેખા પરનું કોઈ પણ બિંદુ લઈને તેની દૂરી શોધો. આ પ્રકારના પ્રશ્નો GUJCET માં પાંચ/ચાર અંકના જવાબ આપે છે.

બિંદુ-સમતલ દૂરીd = |Ax₁+By₁+Cz₁+D|/√(A²+B²+C²)
મૂળબિંદુ દૂરીd = |D|/√(A²+B²+C²)

રેખા-રેખા વચ્ચેનું લઘુત્તમ અંતર અને કોણ

બે રેખાઓ r = a₁ + λb₁ અને r = a₂ + μb₂ લો. તેમના મધ્યનો લંબ સદિશ b₁ × b₂ હોય છે. જો બે રેખાઓ અભિછેદી (intersecting) હોય, તો (a₂-a₁) · (b₁×b₂) = 0. જો શૂન્ય ન હોય, તો તેઓ વિષમરેખા (skew lines) છે. વિષમરેખાઓ વચ્ચેનું લઘુત્તમ અંતર d = |(a₂-a₁)·(b₁×b₂)| / |b₁×b₂|. બે રેખાઓ વચ્ચેનો કોણ θ એ તેમના દિશ સદિશો વચ્ચેનો કોણ છે: cos θ = |b₁·b₂|/(|b₁||b₂|). જો b₁·b₂=0, તો રેખાઓ પરસ્પર લંબ. આ વિષમરેખા પ્રકરણ GUJCET માં મહત્વપૂર્ણ છે અને અંકાઈ પ્રશ્નો આપે છે.

સમતલ-સમતલ અને રેખા-સમતલ સંબંધી ખાસ કિસ્સાઓ

જ્યારે સમતલો સમાંતર હોય, ત્યારે તેમના મધ્યે અચળ દૂરી હોય છે. જ્યારે રેખા સમતલમાં હોય, ત્યારે રેખાના બિંદુએ સમતલ સમીકરણ સંતોષે અને રેખાનો દિશ સદિશ સમતલના લંબ સદિશને લંબ હોય. જ્યારે રેખા સમતલ પર લંબ હોય, ત્યારે રેખાનો દિશ સદિશ સમતલના લંબ સદિશના સમાંતર હોય. બે સમતલોના સમાકલનથી રેખા મળે, જેનો દિશઅનુપાત n₁×n₂ હોય. આવા ખાસ કિસ્સાઓ પ્રત્યેક પ્રશ્નમાં પ્રથમ તપાસવા જોઈએ. GUJCET માં 'શરતો' પર આધારિત પ્રશ્નો આવે છે, જેમાં ઉપરોક્ત તર્કનો ઉપયોગ થાય છે. આ ભાગમાં તોડફોડ કર્યા વિના સમીકરણો તપાસવાની કળા શીખવી જોઈએ.

⚡ સૂત્રો

બે બિંદુઓ વચ્ચેનું અંતર: PQ = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²]
વિભાજન સૂત્ર: R = [(mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n)]
મધ્યબિંદુ: [(x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2]
દિક્કોસાઇન સર્વસમકામ: l² + m² + n² = 1
રેખાનું સદિશ સમીકરણ: r = a + λb
રેખાનું કાર્ટેઝીય સમીકરણ: (x-x₁)/a = (y-y₁)/b = (z-z₁)/c
સમતલનું સદિશ સમીકરણ: r · n = a · n
સમતલનું કાર્ટેઝીય સમીકરણ: Ax + By + Cz + D = 0
સમતલનું નૉર્મલ ફોર્મ: lx + my + nz = p
રેખા-સમતલ કોણ: sin θ = |b·n|/(|b||n|)
બે સમતલ વચ્ચેનો કોણ: cos θ = |n₁·n₂|/(|n₁||n₂|)
બિંદુ-સમતલ લંબ દૂરી: d = |Ax₁+By₁+Cz₁+D|/√(A²+B²+C²)
વિષમરેખાઓ વચ્ચે લઘુત્તમ અંતર: d = |(a₂-a₁)·(b₁×b₂)| / |b₁×b₂|
બે રેખાઓ વચ્ચેનો કોણ: cos θ = |b₁·b₂|/(|b₁||b₂|)
રેખા-રેખા અભિછેદ શરત: (a₂-a₁)·(b₁×b₂) = 0

⭐ મહત્વના મુદ્દા

  • ત્રિ-પરિમાણ અવકાશ ત્રણ લંબ અક્ષો x, y, z ધરાવે છે.
  • દરેક બિંદુને (x,y,z) એક અનન્ય યામ ત્રય વડે દર્શાવી શકાય.
  • દિક્કોસાઇન હંમેશા l²+m²+n²=1 શરત સંતોષે છે.
  • રેખાનું સદિશ સમીકરણ r = a + λb ઘણા પ્રકારના પ્રશ્નોમાં પહેલું પગલું છે.
  • સમતલનો લંબ સદિશ (A,B,C) કાર્ટેઝીય સમીકરણમાંથી મળે છે.
  • બે સમતલ લંબ હોય જો A₁A₂+B₁B₂+C₁C₂=0.
  • રેખા સમતલ સમાંતર હોય જો b·n = 0.
  • રેખા સમતલ પર લંબ હોય જો b ∥ n.
  • વિષમરેખાઓ એવી રેખાઓ છે જે ન તો સમાંતર છે ન તો છેદે છે.
  • GUJCET માં સમીકરણના રૂપાંતરણ (વેક્ટર ↔ કાર્ટેઝીય) નિયમિત આવે છે.

⚠️ સામાન્ય ભૂલો

દિક્કોસાઇન શોધતી વખતે l²+m²+n²=1 શરતનો ઉપયોગ ભૂલી જવો.
રેખાના કાર્ટેઝીય સમીકરણમાં છેદ શૂન્ય લઈ લેવો.
બિંદુ-સમતલ દૂરીના સૂત્રમાં ચિહ્ન ઉમેરવું ભૂલી જવું (નિરપેક્ષ મૂલ્ય લેવું જરૂરી છે).
સમતલના લંબ દિશઅનુપાતને રેખાના દિશઅનુપાત સાથે ગેરસમજી લેવા.
વિષમરેખા માટે (a₂-a₁)·(b₁×b₂) શૂન્ય હોય તો અભિછેદી માની લેવા, પણ ગણતરી ભૂલવી.
રેખા-સમતલ કોણ માટે cos θ નો ઉપયોગ કરી લેવો, જ્યારે sin θ સાચું છે.
બે સમતલ સમાંતર હોય ત્યારે D ના ગુણોત્તર પણ સમાન હોવા જોઈએ એ ભૂલી જવા.
ઓક્ઝન્ટની ગણતરીમાં ચિહ્નોની ભૂલ કરવી.
વિભાજન સૂત્રમાં m:n ની દિશા ઉલટી મૂકવી.
સમીકરણની વેક્ટર/કાર્ટેઝીય રૂપાંતરણ દરમિયાન i,j,k એકમ સદિશો ભૂલી જવા.
