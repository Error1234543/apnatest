ત્રિપરિમાણ ભૂમિતિ (Three Dimensional Geometry) — GUJCET એક્ઝામ ટ્રિક્સ

🧪 GUJCET — Gujarati • Mathematics • Three Dimensional Geometry

🎯 પરીક્ષા ટ્રિક્સ

દિશા કોસાઇન (Direction Cosines) નો મૂળભૂત ગુણધર્મ: l² + m² + n² = 1. વિકલ્પોમાંથી આ શરત પાળતો જવાબ તરત ઓળખી શકાય.
જ્યારે પ્રશ્નમાં દિશા કોસાઇન આપેલા હોય અથવા પૂછવામાં આવ્યા હોય.
દા.ત.: જો દિશા કોસાઇન (l, m, n) = (1/√3, 1/√3, 1/√3) હોય, તો l² + m² + n² = 1/3 + 1/3 + 1/3 = 1 → સાચો. જો કોઈ વિકલ્પમાં સરવાળો 1 ન આવે, તો તે ખોટો છે.
બે બિંદુઓ A(x₁,y₁,z₁) અને B(x₂,y₂,z₂) વચ્ચેની દિશા અનુપાત (Direction Ratios) = (x₂−x₁, y₂−y₁, z₂−z₁). આ સીધું બાદબાકીથી મળે.
રેખાના દિશા અનુપાત શોધવાના હોય.
દા.ત.: A(1,2,3) અને B(4,0,−1) વચ્ચે DR = (4−1, 0−2, −1−3) = (3, −2, −4).
બે રેખાઓ લંબ (Perpendicular) હોય તો: a₁a₂ + b₁b₂ + c₁c₂ = 0 (દિશા અનુપાતના ગુણાકારનો સરવાળો શૂન્ય).
રેખાઓ વચ્ચેનો ખૂણો 90° છે કે નહીં તે તપાસવા.
દા.ત.: રેખા 1: DR = (2,3,−1), રેખા 2: DR = (1,−2,4). સરવાળો = 2(1)+3(−2)+(−1)(4) = 2−6−4 = −8 ≠ 0 → લંબ નથી.
બે રેખાઓ સમાંતર (Parallel) હોય તો: a₁/a₂ = b₁/b₂ = c₁/c₂. ત્રણેય ગુણોત્તર સમાન હોવા જોઈએ.
રેખાઓ સમાંતર છે કે નહીં તે ચકાસવા.
દા.ત.: રેખા 1: DR = (2,−3,4), રેખા 2: DR = (−4,6,−8). ગુણોત્તર: 2/(−4) = −1/2, −3/6 = −1/2, 4/(−8) = −1/2 → ત્રણેય સમાન → સમાંતર.
અંતરાલ સૂત્ર (Section Formula) યાદ રાખવાની ટ્રિક: 'બાહ્ય ગુણાકાર + આંતરિક ગુણાકાર'. m:n ગુણોત્તરમાં P બિંદુ = ((mx₂+n x₁)/(m+n), (my₂+n y₁)/(m+n), (mz₂+n z₁)/(m+n)). મધ્યબિંદુ માટે m=n=1 મૂકો.
રેખાખંડને નિશ્ચિત ગુણોત્તરમાં વિભાજિત કરતું બિંદુ શોધવા.
દા.ત.: A(2,−1,3), B(4,1,5) ને 1:2 ગુણોત્તરમાં વિભાજિત કરતું બિંદુ: x = (1×4+2×2)/3 = 8/3, y = (1×1+2×(−1))/3 = −1/3, z = (1×5+2×3)/3 = 11/3.
સમતલનું અંતઃછેદ સ્વરૂપ (Intercept Form): x/a + y/b + z/c = 1, જ્યાં a, b, c અક્ષો પરના છેદબિંદુઓ છે. આ સ્વરૂપમાંથી સીધું સમીકરણ લખી શકાય.
જ્યારે સમતલ અક્ષોને ક્રમશઃ a, b, c પર છેદતું હોય.
દા.ત.: જો સમતલ x, y, z અક્ષોને ક્રમશઃ 2, 3, 4 પર છેદતું હોય, તો સમીકરણ: x/2 + y/3 + z/4 = 1 → 6x + 4y + 3z = 12.
બિંદુ (x₁,y₁,z₁) થી સમતલ ax+by+cz+d=0 નું લંબ અંતર: |ax₁+by₁+cz₁+d| / √(a²+b²+c²). અંશમાં ચિહ્ન અવગણો (modulus).
બિંદુ-સમતલ અંતર શોધવા.
દા.ત.: બિંદુ (1,2,3) થી સમતલ 2x−y+2z+4=0 નું અંતર = |2(1)−1(2)+2(3)+4| / √(4+1+4) = |2−2+6+4|/3 = 10/3.
બે સમતલો વચ્ચેનો ખૂણો = તેમના લંબ સદિશો વચ્ચેનો ખૂણો. cos θ = |a₁a₂+b₁b₂+c₁c₂| / (√(a₁²+b₁²+c₁²)·√(a₂²+b₂²+c₂²)).
બે સમતલો વચ્ચેનો ખૂણો શોધવા.
દા.ત.: સમતલ 1: x+2y+3z=0, સમતલ 2: 2x−y+z=5. cos θ = |1(2)+2(−1)+3(1)| / (√14·√6) = |2−2+3|/√84 = 3/√84.
લંબ સમતલનું સમીકરણ: જો રેખાના DR (a,b,c) હોય અને તે સમતલ પર લંબ હોય, તો સમતલનું સમીકરણ a(x−x₀)+b(y−y₀)+c(z−z₀)=0, જ્યાં (x₀,y₀,z₀) સમતલ પરનું બિંદુ.
રેખાને લંબરૂપે છેદતું સમતલ શોધવા.
દા.ત.: બિંદુ (1,0,−2) થી પસાર થતું અને DR (2,3,−1) ને લંબ સમતલ: 2(x−1)+3(y−0)−1(z+2)=0 → 2x+3y−z=4.
સમરેખ બિંદુઓ (Collinear Points) ની શરત: ત્રણ બિંદુઓ A, B, C સમરેખ હોય તો AB અને BC ના DR સમાંતર હોવા જોઈએ (ગુણોત્તર સમાન).
ત્રણ બિંદુઓ સમરેખ છે કે નહીં તપાસવા.
દા.ત.: A(1,2,3), B(2,3,5), C(4,5,9). AB DR = (1,1,2), BC DR = (2,2,4). 1/2 = 1/2 = 2/4 → સમાંતર → સમરેખ.
દિશા અનુપાત (DR) થી દિશા કોસાઇન (DC) માં રૂપાંતર: DC = (a/√(a²+b²+c²), b/√(a²+b²+c²), c/√(a²+b²+c²)). છેદ સમાન રહે છે.
DR આપેલ હોય અને DC જોઈતું હોય.
દા.ત.: DR = (2,−1,2). √(4+1+4) = 3. DC = (2/3, −1/3, 2/3). ચકાસણી: 4/9+1/9+4/9 = 1 ✓
સમતલનું પ્રમાણ્ય સ્વરૂપ (Normal Form): lx + my + nz = p, જ્યાં (l,m,n) દિશા કોસાઇન છે અને p મૂળબિંદુથી લંબ અંતર. આ સ્વરૂપમાં p સીધું અંતર આપે છે.
મૂળબિંદુથી સમતલનું લંબ અંતર શોધવા અથવા સમતલને પ્રમાણ્ય સ્વરૂપમાં ફેરવવા.
દા.ત.: સમતલ 3x+4y+12z=12 ને પ્રમાણ્ય સ્વરૂપમાં: √(9+16+144) = 13. l=3/13, m=4/13, n=12/13, p=12/13. મૂળબિંદુથી અંતર = 12/13.
જો સમતલનું સમીકરણ ax+by+cz=d હોય, તો તેના દિશા અનુપાત (a,b,c) હોય છે — સહગુણકો જ DR બને. આ ઝડપી ઓળખ ટ્રિક છે.
સમતલના DR તરત જાણવા.
દા.ત.: સમતલ 5x−3y+2z=7 ના DR = (5,−3,2). સહગુણકો જ DR છે.
બે સમાંતર સમતલો ax+by+cz=d₁ અને ax+by+cz=d₂ વચ્ચેનું અંતર = |d₁−d₂| / √(a²+b²+c²). સહગુણકો સમાન હોવા જોઈએ.
બે સમાંતર સમતલો વચ્ચેનું અંતર શોધવા.
દા.ત.: સમતલ 2x+3y−6z=5 અને 2x+3y−6z=17 વચ્ચે અંતર = |5−17|/√(4+9+36) = 12/7.
