ત્રિ-પરિમાણીય ભૂમિતિ (Three Dimensional Geometry) — સૂત્ર પત્રિકા

🧪 GUJCET — Gujarati • Mathematics • Three Dimensional Geometry

⚡ સૂત્રો

બે બિંદુઓ વચ્ચેનું અંતર: PQ = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
P(x₁,y₁,z₁), Q(x₂,y₂,z₂) — ત્રણેય અક્ષો પરનું અંતર · SI: એકમ (unit) · જ્યારે બંને બિંદુઓનું સ્થાન કાર્ટેઝિયન નિર્દેશાંક પદ્ધતિમાં આપેલું હોય
અંતઃખંડન સૂત્ર (આંતર વિભાજન): R = [(mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n)]
P(x₁,y₁,z₁), Q(x₂,y₂,z₂) — R, PQ ને m:n ના અનુપાતે આંતરિક રીતે વિભાજિત કરે છે · SI: એકમ (unit) · m+n ≠ 0; રેખાખંડ PQ ની અંદર બિંદુ આવે
બાહ્યખંડન સૂત્ર (બાહ્ય વિભાજન): R = [(mx₂−nx₁)/(m−n), (my₂−ny₁)/(m−n), (mz₂−nz₁)/(m−n)]
P(x₁,y₁,z₁), Q(x₂,y₂,z₂) — R, PQ ને m:n ના અનુપાતે બાહ્ય રીતે વિભાજિત કરે છે · SI: એકમ (unit) · m ≠ n; મૂળભૂત રેખાખંડની બહાર બિંદુ આવે
મધ્યબિંદુ સૂત્ર: M = [(x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2]
M — રેખાખંડ P(x₁,y₁,z₁)Q(x₂,y₂,z₂) નું મધ્યબિંદુ · SI: એકમ (unit) · m = n = 1 હોય ત્યારે અંતઃખંડન સૂત્રનું વિશેષ રૂપ
દિશા સહઅનુપાતો (Direction Ratios): રેખાના દિશા સહઅનુપાતો (a, b, c) જ્યાં a, b, c એ સંખ્યાઓ છે જે રેખાની દિશા દર્શાવે છે
a, b, c — રેખાના દિશા સહઅનુપાતો (Direction Ratios / દિશા સહઅનુપાતો) · SI: શૂન્ય · રેખાનું દિશા સંબંધિત ગુણધર્મ દર્શાવે છે; શૂન્ય સાથે સંબંધિત હોઈ શકે
દિશા કોસાઈન (Direction Cosines): l = a/√(a²+b²+c²), m = b/√(a²+b²+c²), n = c/√(a²+b²+c²)
l, m, n — દિશા કોસાઈન (Direction Cosines); a, b, c — દિશા સહઅનુપાતો (DR) · SI: શૂન્ય (વાસ્તવિક સંખ્યા) · DR અનંત જોડાયેલા હોઈ શકે, પરંતુ DC એકમ જોડી છે
DC ની મૂળભૂત શરત: l² + m² + n² = 1
l, m, n — દિશા કોસાઈન · SI: શૂન્ય · કોઈ પણ રેખા/દિશા માટે હંમેશા સાચું
બે બિંદુઓ જોડતી રેખાના DC: l = (x₂−x₁)/d, m = (y₂−y₁)/d, n = (z₂−z₁)/d, જ્યાં d = √[(x₂−x₁)²+(y₂−y₁)²+(z₂−z₁)²]
l,m,n — DC; (x₁,y₁,z₁),(x₂,y₂,z₂) — બિંદુઓ; d — અંતર · SI: શૂન્ય · બે બિંદુઓ જોડતી રેખા માટે
રેખાનું સદિશ સમીકરણ (Vector Equation): r⃗ = a⃗ + λb⃗
r⃗ — રેખા પરનું સ્થિતિ સદિશ; a⃗ — રેખા પરનું જ्ञાત બિંદુ; b⃗ — દિશા સદિશ; λ — સદિશ ચલ · SI: એકમ (unit) · રેખા a⃗માંથી પસાર થાય અને b⃗ સમાંતર હોય
રેખાનું કાર્ટેઝિયન સમીકરણ (Cartesian Equation): (x−x₁)/a = (y−y₁)/b = (z−z₁)/c
(x₁,y₁,z₁) — રેખા પરનું બિંદુ; a,b,c — દિશા સહઅનુપાતો · SI: એકમ (unit) · રેખા (x₁,y₁,z₁) માંથી પસાર થાય અને દિશા સહઅનુપાતો (a,b,c) લે
રેખાના દિશા કોસાઈન: l = a/√(a²+b²+c²), m = b/√(a²+b²+c²), n = c/√(a²+b²+c²)
l,m,n — DC; a,b,c — દિશા સહઅનુપાતો (સિમેટ્રિક ફોર્મના છેદક) · SI: શૂન્ય · (x−x₁)/a = (y−y₁)/b = (z−z₁)/c સ્વરૂપમાંથી
બે રેખાઓ વચ્ચેનું કોણ: cos θ = |a₁a₂ + b₁b₂ + c₁c₂| / [√(a₁²+b₁²+c₁²) · √(a₂²+b₂²+c₂²)]
θ — રેખાઓ વચ્ચેનું કોણ; (a₁,b₁,c₁), (a₂,b₂,c₂) — ક્રમશઃ દિશા સહઅનુપાતો · SI: ડિગ્રી (°) અથવા રેડિયન (rad) · બંને રેખાઓના DR આપેલ હોય
સમાંતર રેખાઓની શરત: a₁/a₂ = b₁/b₂ = c₁/c₂
aᵢ, bᵢ, cᵢ — ક્રમશઃ રેખા 1 અને રેખા 2 ના દિશા સહઅનુપાતો · SI: — · રેખાઓ સમાંતર હોય ત્યારે
લંબ રેખાઓની શરત: a₁a₂ + b₁b₂ + c₁c₂ = 0
aᵢ, bᵢ, cᵢ — દિશા સહઅનુપાતો · SI: — · બે રેખાઓ પરસ્પર લંબ હોય ત્યારે
બે વિષમરેખાઓ વચ્ચેનું લઘુત્તમ અંતર (Symmetric Form): SD = |(b⃗₁ × b⃗₂) · (a⃗₂ − a⃗₁)| / |b⃗₁ × b⃗₂|
b⃗₁, b⃗₂ — દિશા સદિશો; a⃗₁, a⃗₂ — બિંદુ સદિશો; × — વિધાન ગુણાકાર; · — અદિશ ગુણાકાર · SI: એકમ (unit) · રેખા 1: r⃗ = a⃗₁ + λb⃗₁; રેખા 2: r⃗ = a⃗₂ + μb⃗₂; b⃗₁ × b⃗₂ ≠ 0
લઘુત્તમ અંતર — DR સ્વરૂપમાં: SD = |(b₁b₂ − b₂b₁)(c₁z₀ − c₃z₁) − (c₁a₂ − c₂a₁)(b₁x₀ − b₃x₁) + (a₁b₂ − a₂b₁)(a₁z₀ − a₃z₁)| / √[(b₁c₂−b₂c₁)²+(c₁a₂−c₂a₁)²+(a₁b₂−a₂b₁)²]
(a₁,b₁,c₁): પ્રથમ રેખાના DR; (a₂,b₂,c₂): બીજી રેખાના DR; (x₀,y₀,z₀): પ્રથમ રેખા પરનું બિંદુ; (x₁,y₁,z₁): બીજી રેખા પરનું બિંદુ · SI: એકમ (unit) · રેખાઓ વિષમરેખા (Skew Lines) હોય ત્યારે
સમતલનું સામાન્ય સ્વરૂપ (General Form): Ax + By + Cz + D = 0
A,B,C — સમતલના લંબના દિશા સહઅનુપાતો; D — અચળાંક · SI: એકમ (unit) · A,B,C બંને શૂન્ય ન હોય
સમતલનું સદિશ સમીકરણ (Notation Form): r⃗ · n̂ = d
r⃗ — સમતલ પરનું સ્થિતિ સદિશ; n̂ — એકમ લંબ સદિશ; d — ઉગમબિંદુથી સમતલનું લંબ અંતર · SI: એકમ (unit) · n̂ એકમ સદિશ હોય અને d ≥ 0
સમતલનું કાર્ટેઝિયન સમીકરણ (લંબ સ્વરૂપ): lx + my + nz = d
l,m,n — લંબના દિશા કોસાઈન; d — ઉગમબિંદુથી લંબ અંતર · SI: એકમ (unit) · d ≥ 0, l²+m²+n² = 1
બિંદુ અને દિશા આપેલ હોય ત્યારે સમતલ: a(x−x₁) + b(y−y₁) + c(z−z₁) = 0
(x₁,y₁,z₁) — સમતલ પરનું બિંદુ; (a,b,c) — સમતલના લંબની દિશા સહઅનુપાતો · SI: એકમ (unit) · લંબની દિશા જ्ञાત હોય
ઈન્ટરસેપ્ટ રૂપ (Intercept Form): x/a + y/b + z/c = 1
a — x-અક્ષ પરનું છેદ (intercept); b — y-અક્ષ પરનું છેદ; c — z-અક્ષ પરનું છેદ · SI: એકમ (unit) · સમતલ ત્રણેય અક્ષોને અનુક્રમે a, b, c માં કાપે છે
ત્રણ બિંદુઓમાંથી પસાર થતા સમતલનું સમીકરણ: | x−x₁ y−y₁ z−z₁ | | a₁ b₁ c₁ | = 0 | x−x₂ y−y₂ z−z₂ | | a₂ b₂ c₂ |
(x₁,y₁,z₁),(x₂,y₂,z₂),(x₃,y₃,z₃) — સમતલ પરના ત્રણ બિંદુઓ; (a₁,b₁,c₁) = (x₂−x₁, y₂−y₁, z₂−z₁); (a₂,b₂,c₂) = (x₃−x₁, y₃−y₁, z₃−z₁) · SI: — · ત્રણેય બિંદુઓ સરળરેખીય (collinear) ન હોય
બે સમતલો વચ્ચેનું કોણ: cos θ = |A₁A₂ + B₁B₂ + C₁C₂| / [√(A₁²+B₁²+C₁²) · √(A₂²+B₂²+C₂²)]
θ — સમતલો વચ્ચેનું કોણ; (A₁,B₁,C₁),(A₂,B₂,C₂) — સમતલોના લંબના DR · SI: ડિગ્રી (°) અથવા રેડિયન (rad) · સમતલો A₁x+B₁y+C₁z+D₁=0 અને A₂x+B₂y+C₂z+D₂=0
સમાંતર સમતલોની શરત: A₁/A₂ = B₁/B₂ = C₁/C₂
Aᵢ,Bᵢ,Cᵢ — સમતલ i ના સહગુણક · SI: — · બે સમતલો સમાંતર હોય ત્યારે
લંબ સમતલોની શરત: A₁A₂ + B₁B₂ + C₁C₂ = 0
Aᵢ,Bᵢ,Cᵢ — સમતલ i ના સહગુણક (લંબના DR) · SI: — · બે સમતલો પરસ્પર લંબ હોય ત્યારે
બિંદુથી સમતલનું લંબ અંતર (Point-to-Plane Distance): d = |Ax₁ + By₁ + Cz₁ + D| / √(A²+B²+C²)
(x₁,y₁,z₁) — બિંદુ; Ax+By+Cz+D=0 — સમતલ · SI: એકમ (unit) · સમતલ સામાન્ય સ્વરૂપમાં હોય
ઉગમબિંદુથી સમતલનું અંતર: d = |D| / √(A²+B²+C²)
D — સમતલ Ax+By+Cz+D=0 માં અચળાંક · SI: એકમ (unit) · બિંદુ ઉગમબિંદુ (0,0,0) હોય
ઉગમબિંદુથી સમતલનું અંતર (લંબ સ્વરૂપમાં): d = |p|, જ્યાં સમતલ lx+my+nz=p
l,m,n — DC; p — ઉગમબિંદુથી લંબ અંતર · SI: એકમ (unit) · સમતલ લંબ સ્વરૂપમાં (Normal Form) હોય
બિંદુ P નું સમતલ π પર પ્રક્ષેપ બિંદુ S: S = (x₁ − a·t₀, y₁ − b·t₀, z₁ − c·t₀), જ્યાં t₀ = (Ax₁+By₁+Cz₁+D)/(A²+B²+C²)
P(x₁,y₁,z₁) — બિંદુ; Ax+By+Cz+D=0 — સમતલ; (a,b,c) = (A,B,C) — લંબના DR · SI: એકમ (unit) · PS સમતલને લંબ હોય
બિંદુ P નું સમતલ π પ્રત્યેનું પ્રતિબિંબ Q: Q = (x₁ + 2a·t₀, y₁ + 2b·t₀, z₁ + 2c·t₀), જ્યાં t₀ = (Ax₁+By₁+Cz₁+D)/(A²+B²+C²)
P(x₁,y₁,z₁) — મૂળ બિંદુ; Q — પ્રતિબિંબ; S — પ્રક્ષેપ બિંદુ; (a,b,c)=(A,B,C) — લંબના DR · SI: એકમ (unit) · સમતલ π, PQ નું મધ્યબિંદુ S પર છે
રેખા-સમતલ પ્રત્યેનું કોણ: sin α = |aA + bB + cC| / [√(a²+b²+c²) · √(A²+B²+C²)]
α — રેખા અને સમતલ વચ્ચેનું કોણ; (a,b,c) — રેખાના DR; (A,B,C) — સમતલના લંb ના DR · SI: ડિગ્રી (°) અથવા રેડિયન (rad) · રેખાનું કાર્ટેઝિયન સમીકરણ અને સમતલનું સામાન્ય સમીકરણ જ्ञાત હોય
સમતલ દ્વારા વિભાજિત થયેલ રેખાખંડનો ગુણોત્તર: k = −(ax₁+by₁+cz₁+d) / (ax₂+by₂+cz₂+d)
(x₁,y₁,z₁),(x₂,y₂,z₂) — રેખાખંડના સંથા બિંદુઓ; ax+by+cz+d=0 — સમતલ · SI: — · રેખાખંડ સમતલ દ્વારા આંતરિક રીતે વિભાજિત થાય

🔗 સંબંધો

  • જો રેખા (x−x₁)/a = (y−y₁)/b = (z−z₁)/c સમતલ Ax+By+Cz+D=0 ને મળે, તો છેદન બિંદુ માટે λ મેળવવા બિંદુ (x₁+aλ, y₁+bλ, z₁+cλ) ને સમતલ સમીકરણમાં મૂકવું પડે છે.
  • બે રેખાઓ l₁ = r⃗₁ + λb⃗₁ અને l₂ = r⃗₂ + μb⃗₂ એક જ સમતલમાં હોય તેવી શરત: (b⃗₁ × b⃗₂) · (a⃗₂ − a⃗₁) = 0 (એટલે કે લઘુત્તમ અંતર શૂન્ય).
  • રેખા-સમતલ વચ્ચેનું કોણ θ જ्ञાત હોય, તો સમતલના લંબ અને રેખાના દિશા સદિશ વચ્ચેનું કોણ = 90° − θ.
  • સમતલ x/a + y/b + z/c = 1 નું કદ્ઘનફલ (Tetrahedron) OABC નું ઘનફળ = |abc|/6 છે.
  • બિંદુ P(x₁,y₁,z₁) અને Q(x₂,y₂,z₂) ના મધ્યબિંદુનું સમતલ Ax+By+Cz+D=0 પર પ્રક્ષેપ લેવા માટે પ્રથમ મધ્યબિંદુ શોધવું, પછી પ્રક્ષેપ સૂત્ર લાગુ પાડવું.
  • લઘુત્તમ અંતર શૂન્ય હોય, તો રેખાઓ સમતલીય (Concurrent/Coplanar) હોય છે.

🎯 ટ્રિક્સ

લઘુત્તમ અંતર (SD) શૂન્ય હોય, તો રેખાઓ એક જ સમતલમાં હોય — (b⃗₁ × b⃗₂) · (a⃗₂ − a⃗₁) = 0 શરત ચકાસો.
રેખા-સમતલ કોણના સૂત્રમાં sin α વાપરો (અને cos θ નહીં) — કારણ કે રેખા અને સમતલ વચ્ચેનું કોણ લંબ સાથેનું પૂરક કોણ છે.
દિશા કોસાઈન શોધવા માટે DR ને તેના પરીમાણ (magnitude) વડે ભાગો: l=a/√(a²+b²+c²).
રેખા-સમતલ છેદન બિંદુ શોધવા માટે: રેખાના બિંદુને (x₁+aλ, y₁+bλ, z₁+cλ) સ્વરૂપે લખો, સમતલમાં મૂકો, λ મેળવો, પછી બિંદુ શોધો.
બિંદુનું પ્રતિબિંબ શોધતાં: સૌપ્રથમ પ્રક્ષેપ બિંદુ S શોધો (S, PQ નું મધ્યબિંદુ છે), પછી Q = 2S − P.
સમાંતર સમતલો vચચે અંતર = |D₁ − D₂|/√(A²+B²+C²) જ્યારે બંને સમીકરણોમાં A,B,C સમાન હોય.
બે રેખાઓના DR (a₁,b₁,c₁) અને (a₂,b₂,c₂) હોય, તો સમાંતર માટે a₁/a₂ = b₁/b₂ = c₁/c₂; લંબ માટે a₁a₂+b₁b₂+c₁c₂=0 — બંને યાદ રાખવા માટે 'અંશ સરખા' vs 'ગુણાકારનું સરવાળું શૂન્ય'.

⚠️ ભૂલો

રેખા-સમતલ વચ્ચેનું કોણ શોધતી વખતે cos θ નું સૂત્ર વાપરવાને બદલે sin α નું સૂત્ર વાપરવું જોઈએ — સામાન્ય ભૂલ: cos θ = |b⃗·n⃗|/(|b⃗||n⃗|) લે છે, જે રેખા અને લંb વચ્ચેનું કોણ આપે છે, રેખા-સમતલ કોણ nહીં.
લઘુત્તમ અંતરના સૂત્રમાં (a⃗₂−a⃗₁) ને (a⃗₁−a⃗₂) થી બદલી દેવામાં આવે છે — ક્રમ મહત્વનો છે; પરંતુ માદ ક્ષેત્રફળ (modulus) હોવાથી અંતિમ પરિણામ સમાન આવે.
અંતઃખંડન સૂત્રમાં m:n ને બદલે n:m મૂકી દેવા — (mx₂+nx₁)/(m+n) માં x₂ સાથે m જોડાયેલો છે, x₁ સાથે n.
સમતલના ઈન્ટરસેપ્ટ રૂપ x/a+y/b+z/c=1 માં a,b,c ને ધન ગણવા — છેદ ઋણ પણ હોઈ શકે.
દિશા કોસાઈન (l,m,n) ને દિશા સહઅનુપાતો (DR) સાથે ગૂંચવી દેવા — DC માં l²+m²+n²=1 હોય; DR માં આ શરત હોતી nહીં.
બિંદુથી સમતલનું અંતરના સૂત્રમાં અંશ (numerator) માં અબ્રાકેટ (absolute value) ભૂલી જવું — અંતર હંમેશા ધન હોય.
સમતલના સામાન્ય સમીકરણ Ax+By+Cz+D=0 માં D ની ચિન્હ (sign) ચકાસવું ભૂલી જવું.
રેખાખંડને સમતલ દ્વારા વિભાજિત કરતો ગુણોત્તર શોધતી વખતે k = −(ax₁+...)/(ax₂+...) માં ઋણ ચિન્હ ભૂલી જવું.
