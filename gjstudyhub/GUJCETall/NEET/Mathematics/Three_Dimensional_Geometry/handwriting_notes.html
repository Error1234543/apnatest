ત્રિપરિમાણીય ભૂમિતિ (Three Dimensional Geometry)

🧪 GUJCET — Gujarati • Mathematics • Three Dimensional Geometry

📐 પ્રસ્તાવના
દ્વિપરિમાણ ભૂમિતિમાં આપણે X અને Y અક્ષોનો ઉપયોગ કરીએ છીએ.
ત્રિપરિમાણીય ભૂમિતિમાં ત્રણ યામ અક્ષો — X, Y અને Z — હોય છે જે એકબીજાને લંબરૂપ છે.
⚡ ત્રણેય અક્ષો પરસ્પર લંબ હોવાથી તેમને પરસ્પર લંબ યામ અક્ષો કહે છે.
📝 📌 3D માં બિંદુને (x, y, z) સ્વરૂપે દર્શાવવામાં આવે છે.
🔵 યામ પદ્ધતિ (Coordinate System)
ત્રણ વાસ્તવિક સંખ્યાઓને અનુરૂપ બિંદુ O મૂળબિંદુ (Origin) કહે છે.
અક્ષોના ધન દિશા: X-અક્ષ, Y-અક્ષ, Z-અક્ષ એકબીજાથી જમણા હાથના નિયમ મુજબ ગોઠવાયેલા હોય છે.
યામ સિસ્ટમ: બિંદુ P = (x, y, z)
આઠ અષ્ટકોણના શિરોબિંદુઓ: (±a, ±b, ±c) સ્વરૂપે હોય છે.
⚡ 8 ચતુર્થાંશ (Octants) હોય છે — દરેક ચતુર્થાંશમાં (x,y,z) ના ચિન્હો અલગ હોય છે.
📝 📌 ચતુર્થાંશ 1: (+,+,+) → બધા ધન
📏 અંતર સૂત્ર (Distance Formula)
બે બિંદુઓ P(x₁, y₁, z₁) અને Q(x₂, y₂, z₂) વચ્ચેનું અંતર:
PQ = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
મૂળબિંદુ O(0,0,0) થી P(x,y,z) નું અંતર:
OP = √(x² + y² + z²)
⚡ આ સૂત્ર પાયથાગોરસના પ્રમેયને 3D સુધી વિસ્તારે છે.
📝 📌 યાદ રાખો: પદ્ધતિ સમાન પણ ત્રણ પદો ઉમેરાય છે.
📊 ભાગીદારી સૂત્ર (Section Formula)
બિંદુ P(x₁,y₁,z₁) અને Q(x₂,y₂,z₂) ને m:n ગુણોત્તરમાં આંતરિક રીતે વિભાજિત કરતું બિંદુ:
R = ( (mx₂+nx₁)/(m+n) , (my₂+ny₁)/(m+n) , (mz₂+nz₁)/(m+n) )
બહિર્વિભાજન માટે બિંદુ R' = ( (mx₂-nx₁)/(m-n) , ... ) સ્વરૂપે મળે છે.
⚡ મધ્યબિંદુનું સૂત્ર: m=n=1 મૂકતાં મધ્યબિંદુ = ((x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2)
📝 📌 એક્ઝામમાં મધ્યબિંદુવાળા પ્રશ્નો ઘણા આવે છે!
➡️ દિશા સમગુણો અને દિશા કોસાઈન (Direction Ratios & Cosines)
જો પદ્ધતિ R(r) માં રેખા AB હોય, તો દિશા સમગુણો l,m,n એ રેખાના ગુણાંકો છે.
દિશા કોસાઈન α, β, γ એ યામ અક્ષો સાથે રેખા બનાવતી ખુણાના કોસાઈન છે.
l = cos α, m = cos β, n = cos γ
l² + m² + n² = 1
જો દિશા સમગુણો a,b,c હોય, તો દિશા કોસાઈન:
l = a/√(a²+b²+c²), m = b/√(a²+b²+c²), n = c/√(a²+b²+c²)
⚡ l² + m² + n² = 1 સર્વસમિકા ખૂબ મહત્વની છે — એક્ઝામમાં સતત ઉપયોગ થાય છે.
📝 📌 DR = Direction Ratios, DC = Direction Cosines
દિશા સમગુણોદિશા કોસાઈન = DR / |DR|
↩️ બે રેખાઓ વચ્ચેનો ખુણો
જો દિશા કોસાઈન l₁,m₁,n₁ અને l₂,m₂,n₂ હોય:
cos θ = |l₁l₂ + m₁m₂ + n₁n₂|
બે રેખાઓ સમાંતર હશે જો: l₁/l₂ = m₁/m₂ = n₁/n₂
બે રેખાઓ લંબ હશે જો: l₁l₂ + m₁m₂ + n₁n₂ = 0
⚡ સમાંતર ↔ અનુપાત સમાન; લંબ ↔ અદિશ ગુણનફળ શૂન્ય
📝 📌 cos θ = 0 ⇒ θ = 90° (લંબરૂપ)
📐 સદિશ સમીકરણ — રેખા (Vector Equation of a Line)
રેખાનું સદિશ સમીકરણ: r⃗ = a⃗ + λb⃗
જ્યાં a⃗ = સ્થિર બિંદુનું સ્થિતિ સદિશ, b⃗ = દિશા સદિશ, λ ∈ ℝ
જો રેખા બિંદુ A(a⃗) અને B(b⃗) માંથી પસાર થાય, તો:
r⃗ = a⃗ + λ(b⃗ − a⃗)
⚡ λ = 0 → A બિંદુ, λ = 1 → B બિંદુ
📝 📌 r⃗ = a⃗ + λb⃗ એ રેખાનું પ્રમાણભૂત સમીકરણ છે.
✏️ લંબાઈ સ્વરૂપ — રેખા (Cartesian Form of a Line)
(x − x₁)/a = (y − y₁)/b = (z − z₁)/c
જ્યાં (x₁,y₁,z₁) રેખા પરનું બિંદુ અને a,b,c દિશા સમગુણો છે.
આ સમીકરણમાં દરેક ભાગ સમાન હોય છે જે λ બરાબર હોય છે.
⚡ l,m,n દિશા કોસાઈન લઈએ તો: (x−x₁)/l = (y−y₁)/m = (z−z₁)/n
📝 📌 આકૃતિમાં a,b,c એ ધ્રુવીય સ્વરૂપના હર છે.
📐 સદિશ સમીકરણ — સમતલ (Vector Equation of a Plane)
r⃗ · n̂ = d
જ્યાં n̂ એ સમતલના લંબ દિશાત્મક એકમ સદિશ છે અને d એ મૂળબિંદુ થી લંબ અંતર છે.
જો સમતલ બિંદુ A(a⃗) માંથી પસાર થાય અને n̂ ને લંબ હોય, તો:
(r⃗ − a⃗) · n̂ = 0 ⇒ r⃗ · n̂ = a⃗ · n̂
⚡ n̂ એમ સમજો કે તે સમતલને લંબરૂપ છે — એટલે r⃗ · n̂ = અચળ.
📝 📌 r⃗ · n̂ = d સમીકરણ સૌથી વધુ ઉપયોગી છે.
✏️ પ્રમેય સ્વરૂપ — સમતલ (Cartesian Equation of a Plane)
Ax + By + Cz + D = 0
જ્યાં A,B,C સમતલના દિશા સમગુણો સમાન પ્રમાણમાં હોય છે.
લંબ સ્વરૂપ: lx + my + nz = p (જ્યાં l,m,n એ દિશા કોસાઈન છે)
જો સમતલ મૂળથી ન હોય, તો A,B,C પાસાંઓના દિશા સમગુણો તરીકે.
⚡ lx + my + nz = p: l²+m²+n²=1 અને p ≥ 0
📝 📌 Ax+By+Cz=D સ્વરૂપ ઘણીવાર યોગ્ય રીતે ઉકેલે છે.
🔀 સમતલ વચ્ચેનો ખુણો
સમતલ N₁ = Ax+By+Cz+D₁=0 અને N₂ = ax+by+cz+d₂=0 વચ્ચેનો ખુણો:
cos θ = |Aa + Bb + Cc| / √(A²+B²+C²) · √(a²+b²+c²)
સમાંતર સમતલો: A/a = B/b = C/c
લંબ સમતલો: Aa + Bb + Cc = 0
⚡ બે સમતલો વચ્ચેનો ખુણો = તેમના લંબ સદિશો વચ્ચેનો ખુણો.
📝 📌 θ = 90° માટે અદિશ ગુણન શૂન્ય થવું જરૂરી છે.
📌 રેખા અને સમતલ વચ્ચેનો ખુણો
રેખા (x−x₁)/a = (y−y₁)/b = (z−z₁)/c અને સમતલ Ax+By+Cz+D=0 વચ્ચેનો ખુણો φ:
sin φ = |Aa + Bb + Cc| / √(A²+B²+C²) · √(a²+b²+c²)
⚡ યાદ રાખો: sin φ (cos નહીં!) — કારણ કે ખુણો રેખા અને સમતલના લંબ વચ્ચેનો નહીં પણ રેખા અને સમતલ પોતે વચ્ચેનો છે.
રેખા સમતલ પર લંબ હશે જો: A/a = B/b = C/c
રેખા સમતલમાં હોય તો: Aa+Bb+Cc = 0 AND Ax₁+By₁+Cz₁+D = 0
📝 📌 sin φ ≠ cos φ — ખૂબ જ સાવચેતી!
🔗 સ્કેલર અને વેક્ટર સ્વરૂપોનું સંબંધ
r⃗ = a⃗ + λb⃗(x−x₁)/a = (y−y₁)/b = (z−z₁)/c
r⃗ · n̂ = dlx + my + nz = p
b⃗ = ai⃗+bj⃗+ck⃗દિશા સમગુણો a,b,c
સ્કેલર સ્વરૂપ માં b⃗ ના સહગુણકો અનુક્રમે a,b,c (દિશા સમગુણો) છે.
લંબ સદિશ n⃗ = Ai⃗+Bj⃗+Ck⃗ સમતલના સમીકરણના ગુણાંકો છે.
⚡ દિશા સમગુણો = લંબ સદિશના ઘટકો
🎯 મહત્વના નિયમો અને અવલોકનો
રેખા બિંદુ P(x₁,y₁,z₁) માંથી અને દિશા a⃗ હોય, તો બિંદુ Q(x,y,z) રેખા પર હોય તો:
(x−x₁)/a = (y−y₁)/b = (z−z₁)/c = λ
જમણા હાથના નિયમ (Right Hand Rule) અનુસાર ધન દિશાઓ નક્કી થાય છે.
દિશા કોસાઈન માત્ર એક જ રીતે રહે છે: l² + m² + n² = 1 હંમેશા સાચું.
⚡ 3D માં રેખા/સમતલનું સમીકરણ — લંબાઈ સ્વરૂપમાં 3 સરખા ભાગ હોય છે.
📝 📌 દરેક યામ (x,y,z) નું અલગ સમીકરણ છે.
📝 એક્ઝામ ફોકસ વિષયો (Exam Focus Topics)
અંતર સૂત્ર અને ભાગીદારી સૂત્રના સીધા પ્રશ્નો.
દિશા કોસાઈન કાઢવાના પ્રશ્નો — DR → DC મેળવવું.
બે રેખાઓ વચ્ચેનો ખુણો શોધવો (cos θ સૂત્ર).
બે સમતલો વચ્ચેનો ખુણો શોધવો.
રેખા અને સમતલ વચ્ચેનો ખુણો શોધવો — sin φ (ખૂબ મહત્વનું!).
⚡ સૌથી વધુ પસંદગી પામતો વિષય: રેખા-સમતલ ખુણો અને સમતલ-સમતલ ખુણો.
📝 📌 GUJCET માં એક અથવા બે પ્રશ્નો ચોક્કસ આવે છે.
🧮 મુખ્ય સૂત્રોનું સંગ્રહ
અંતર = √[(x₂−x₁)²+(y₂−y₁)²+(z₂−z₁)²]
લંબ સ્વરૂપ સમતલ: lx + my + nz = p
રેખા-સમતલ ખુણો: sin φ = |Aa+Bb+Cc| / (√(A²+B²+C²)·√(a²+b²+c²))
સમતલ-સમતલ: cos θ = |Aa+Bb+Cc| / (√(A²+B²+C²)·√(a²+b²+c²))
રેખા સમીકરણ: r⃗ = a⃗ + λb⃗
⚡ sin φ vs cos θ — બંને વચ્ચેનો તફાવત યાદ રાખો!
📝 📌 રેખા-સમતલ = sin; સમતલ-સમતલ = cos
✅ ટૂંકી યાદદાસ્ત (Quick Revision)
3D માં ત્રણ યામ અક્ષો: X, Y, Z એકબીજાથી લંબ.
ORIGIN = (0, 0, 0)
l² + m² + n² = 1 (દિશા કોસાઈન સર્વસમિકા)
રેખા-રેખા: cos θ = l₁l₂+m₁m₂+n₁n₂
સમતલ-સમતલ: cos θ = (AA'+BB'+CC')/(...) સમાન સૂત્ર.
રેખા-સમતલ: sin φ = (same numerator)/(product of magnitudes)
⚡ અંતર સૂત્ર + ભાગીદારી સૂત્ર + કોઈ પણ ખુણો શોધવો — આ ત્રણેય ઘણા આવે છે.
