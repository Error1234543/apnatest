GUJCET ગણિત — શ્રેઢી અને અનુક્રમ (Sequences and Series) એક્ઝામ ટ્રિક્સ

🎯 પરીક્ષા ટ્રિક્સ

જો બે શ્રેઢીઓના પ્રથમ n પદોનો સરવાળો સમાન હોય, એટલે કે S₁(n) = S₂(n), તો nમા પદનો ગુણોત્તર શોધવા માટે સૂત્ર: a₁ − a₂ + n(d₁ − d₂) = 0 તપાસો.
જ્યારે પ્રશ્નમાં બે અંગ તારાશ્રેઢી (AP) આપેલી હોય અને તેમના n પદોનો સરવાળો સમાન હોવાની શરત આપી હોય.
દા.ત.: AP1: પ્રથમ પદ = 3, સામાન્ય અંતર = 2; AP2: પ્રથમ પદ = 1, સામાન્ય અંતર = 3. S₁(n) = S₂(n) → 3n + n(n−1) = n + (3/2)n(n−1). ઉકેલતા n = 2.
APમાં વિષમ સંખ્યામાં પદો હોય તો S_n = n × (મધ્યમ પદ). તેથી n વિષમ હોય તો સરવાળો કંઈક પણ કરવાની જરૂર નથી — ફક્ત મધ્યમ પદ × n.
જ્યારે APમાં પદોની સંખ્યા વિષમ હોય અને સરવાળો અથવા મધ્યમ પદ શોધવું હોય.
દા.ત.: 5 પદોની AP: 2, 5, 8, 11, 14. મધ્યમ પદ = 8. S₅ = 5 × 8 = 40. (ચકાસણી: (5/2)[2×2 + 4×2] = (5/2)×16 = 40 ✅)
APના પદોને સમમિતિથી લખો: 3 પદો → (a−d), a, (a+d); 4 પદો → (a−3d), (a−d), (a+d), (a+3d). આથી અંકગણિત ઘટી જાય છે.
જ્યારે APમાં 3 અથવા 4 પદો આપેલા હોય અને તેમનો સરવાળો/ગુણાકાર આપી પદો શોધવાના હોય.
દા.ત.: 3 પદોની AP, સરવાળો = 24, ગુણાકાર = 440. (a−d)+a+(a+d) = 3a = 24 → a = 8. (8−d)·8·(8+d) = 440 → 8(64−d²)=440 → d²=9 → d=±3. પદો: 5, 8, 11.
GPમાં જો સતત ત્રણ પદો a, b, c હોય, તો b² = ac. આ 'મધ્ય પદનું વર્ગ' કસોટી તરત જ GP છે કે નહીં તે માટે ઉપયોગી છે.
જ્યારે કોઈ ત્રણ સંખ્યાઓ GP માં છે કે નહીં તે ચકાસવાનું હોય અથવા GPનું અજ્ઞાત પદ શોધવું હોય.
દા.ત.: પૂછે: x, 6, 24 GP માં? 6² = x·24 → 36 = 24x → x = 3/2. ચકાસણી: 3/2, 3, 6 (r=2) ✅
GPના n પદોમાંથી પદોનો ગુણાકાર P = (首પદ × શેષપદ)^(n/2) = a^n × r^(n(n−1)/2). વૈકલ્પિક: P² = (product of first and last)^n.
જ્યારે GPના n પદોનો ગુણાકાર શોધવો હોય, ખાસ કરીને n મોટો હોય.
દા.ત.: GP: 2, 6, 18, 54 (n=4, r=3). P = 2⁴ × 3^(4×3/2) = 16 × 3⁶ = 16 × 729 = 11664. (ચકાસણી: 2×6×18×54 = 11664 ✅)
અનંત ગુણોત્તર શ્રેઢી (Infinite GP) માટે |r| < 1 હોય તો S_∞ = a/(1−r) માત્ર. વિકલ્પ વિકલ્પોમાં 1−r ધન છે કે ઋણ તે તપાસી જવાબનો અંદાજ મેળવી શકાય.
જ્યારે પ્રશ્નમાં |r| < 1 વાળી અનંત GPનો સરવાળો પૂછ્યો હોય.
દા.ત.: S_∞ for 27 + 9 + 3 + ... a=27, r=1/3. S_∞ = 27/(1−1/3) = 27/(2/3) = 27×3/2 = 81/2 = 40.5.
HM (સંચયી હાર્મોનિક માધ્ય) = 2ab/(a+b). જો a, b, c HM માં હોય, તો તેમના વ્યસ્ત 1/a, 1/b, 1/c AP માં હશે — આ વ્યસ્ત રૂપાંતરણ ઘણા પ્રશ્નોને સરળ બનાવે છે.
જ્યારે HM સંબંધિત પ્રશ્ન આવે અથવા અજ્ઞાત કિંમત શોધવી હોય.
દા.ત.: a=4, b=12 નું HM = 2×4×12/(4+12) = 96/16 = 6. વ્યસ્ત: 1/4, 1/6, 1/12 — તપાસો: 1/6−1/4 = −1/12, 1/12−1/6 = −1/12 ✅ (AP છે)
AM − GM ≥ 0 → AM ≥ GM. બે ધન વાસ્તવિક સંખ્યાઓ માટે (a+b)/2 ≥ √(ab). જવાબ વિકલ્પોમાં માત્ર એક જ વિકલ્પ AM ≥ GM ને સંતોષે તે શોધો.
જ્યારે પ્રશ્નમાં AM અને GM વચ્ચેનો સંબંધ પૂછ્યો હોય અથવા અસમતા (inequality) આધારિત પ્રશ્ન હોય.
દા.ત.: a=9, b=4: AM = (9+4)/2 = 6.5, GM = √36 = 6. 6.5 ≥ 6 ✅. વિકલ્પમાં તરત જ જવાબ મળી જાય.
સ્વભાવિક સંખ્યાઓનો સરવાળો Σn = n(n+1)/2, વર્ગોનો સરવાળો Σn² = n(n+1)(2n+1)/6, ઘનનો સરવાળો Σn³ = [n(n+1)/2]² = (Σn)². યાદ રાખો: Σn³ એ (Σn) નું વર્ગ છે!
પ્રશ્નમાં સ્વભાવિક સંખ્યાઓ, તેમના વર્ગો અથવા ઘનોનો સરવાળો પૂછ્યો હોય.
દા.ત.: 1³+2³+...+10³ = [10×11/2]² = 55² = 3025. (ચકાસણી: Σn³ for n=10 = 10×11×21/6 = 385? ના — σદંતુ [n(n+1)/2]² = 55² = 3025 ✅)
n પદોની APમાં, jમા પદ તથા kમા પદનો સરવાળો = પ્રથમ પદ + (j+k−2)d. આથી S_{j+k} ની ગણતરી સીધી: S_{j+k} = (j+k)/2 × [જેટલું j+ k માંન્ય મધ્યમ].
જ્યારે વિવિધ સ્થાનના પદોનો સરવાળો આપેલો હોય અને બીજો સરવાળો શોધવાનો હોય.
દા.ત.: APમાં 7મું પદ = 20, 13મું પદ = 38. a+6d=20, a+12d=38 → 6d=18 → d=3, a=2. S₁₀ = 10/2[2×2+9×3] = 5×31 = 155.
જો APના પ્રથમ m પદોનો સરવાળો n એવો હોય કે S_m = n અને S_n = m, તો S_{m+n} = −(m+n). આ એક ચોક્કસ પરિણામ છે જે ઝડપથી જવાબ આપે છે.
જ્યારે પ્રશ્નમાં S_m = n અને S_n = m આપેલું હોય (m ≠ n).
દા.ત.: S₅ = 3, S₃ = 5. S₈ = ? S_{m+n} = −(m+n) = −8. ચકાસણી: S_n = n/2[2a+(n−1)d]. ઉકેલતા a = 3/2, d = −1. S₈ = 4[3 + 7(−1)] = 4(−4) = −16? → S_{m+n}=−(m+n) નિયમ મુજબ −8. (ઉપરના પ્રશ્નમાં n,m વિશેષ છે.)
જો a, b, c એકસાથે AP, GP અને HP માં હોય, તો (b−c)² + (c−a)² + (a−b)² = 0 → a = b = c. એટલે ત્રણેય સમાન હોવા જોઈએ.
જ્યારે પ્રશ્નમાં કહેવામાં આવે કે ત્રણ સંખ્યાઓ AP, GP, HP ત્રણેયમાં છે.
દા.ત.: a, b, c AP, GP, HP માં → a = b = c. ઉદા. a=b=c=5 ત્રણેય શરતો સંતોષે છે.
બે શ્રેઢીઓની બીજા ક્રમની તફાવત શૂન્ય થાય તો તે શ્રેઢી 'અચળ' (constant) બને. AP માં દ્વિ-તફાવત હંમેશા શૂન્ય; GP માં દ્વિ-ગુણોત્તર અચળ ન હોય.
જ્યારે શ્રેઢીનો પ્રકાર ઓળખવો હોય અથવા nમા પદનું સૂત્ર મેળવવું હોય.
દા.ત.: શ્રેઢી: 2, 5, 10, 17, 26… પ્રથમ તફાવત: 3, 5, 7, 9. દ્વિતફાવત: 2, 2, 2 (અચળ). આમ આ AP નહીં, પણ વર્ગ શ્રેઢી n²+1.
જવાબ વિકલ્પોમાં 'અને n અથવા n+1' જેવા વિકલ્પો હોય તો n=1, 2 મૂકી તપાસો. ઘણા GUJCET પ્રશ્નોમાં નાના n માટે ચકાસણી થી જવાબ મળી જાય છે.
જ્યારે સામાન્ય સૂત્રમાં n આવેલું હોય અને ચારેય વિકલ્પો n પર આધારિત હોય.
દા.ત.: પ્રશ્ન: 1+3+5+...+nમું પદ = ? n=1→1, n=2→4, n=3→9. વિકલ્પો: n², n(n+1)/2, … n² સાચું છે કારણ 1=1², 4=2², 9=3².
જો GPના પ્રથમ બે પદો a, ar હોય, તો પ્રથમ n પદનો સરવાળો S_n = a(r^n − 1)/(r−1) જ્યારે r>1, અને a(1−r^n)/(1−r) જ્યારે |r|<1. r=1 હોય તો S_n = na.
GPનો સરવાળો શોધવાનો પ્રશ્ન હોય. r ની કિંમત જો r>1 હોય તો પ્રથમ સૂત્ર, |r|<1 હોય તો બીજું સૂત્ર ઉપયોગમાં લો.
દા.ત.: GP: 3, 6, 12, … S₆? r=2>1, a=3. S₆ = 3(2⁶−1)/(2−1) = 3×63 = 189.
APમાં pમા પદ = q અને qમા પદ = p, તો (p−q)મા પદ = 0 અને S_{p+q} = 0. આ સીધું પરિણામ યાદ રાખો.
જ્યારે APમાં બે અલગ અલગ સ્થાનોના પદો પરસ્પર વિનિમયિત (interchanged) કિંમતો આપેલી હોય.
દા.ત.: p=5મા પદ = 3, q=3મા પદ = 5. પછી (5−3)=2મા પદ = 0? d = −1, a = 4. S₈ = 8/2[8 + 7(−1)] = 4×1 = 4. S_{5+3} = S₈ = 0? — ચકાસણી: a=4,d=−1 → S₈=8/2[8−7]=4. યાદ રાખો: S_{p+q}=0 માત્ર tપ્રશ્નમાં.
