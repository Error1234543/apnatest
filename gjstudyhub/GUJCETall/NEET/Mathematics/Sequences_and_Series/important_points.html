⭐ મહત્વના મુદ્દા

સરળ શ્રેડી (Arithmetic Progression, AP) એ આવર્ત ગણ છે જ્યાં ક્રમિક પદો વચ્ચેનું અંતર અચળ હોય છે. આ અચળ અંતરને સામાન્ય અંતર (Common Difference, d) કહે છે.
સૌથી પ્રાથમિક વ્યાખ્યા; દરેક પ્રશ્નની આધારશિલા છે.
nમું પદ શોધવાનું સૂત્ર: a_n = a + (n−1)d, જ્યાં a પ્રથમ પદ છે અને d સામાન્ય અંતર છે.
GUJCET માં સીધું સૂત્ર પ્રશ્ન આવે છે અને અન્ય વિભાગોમાં પણ વારંવાર લાગુ પડે છે.
n પદોનો સરવાળો શોધવાના સૂત્રો: S_n = n/2[2a + (n−1)d] અને S_n = n/2(a + l), જ્યાં l અંતિમ પદ છે.
પ્રશ્નોમાં 'જમા ચૂકવણી', 'સરવાળો' જેવા શબ્દો સાથે સીધી જોડાણ.
જો t_n = an + b (n નું પ્રથમ ઘાતનું સમીકરણ) હોય, તો તે શ્રેણી હંમેશા સરળ શ્રેડી બનાવે છે અને તેનું સામાન્ય અંતર d = a થાય છે.
અનેક વાર પરીક્ષામાં આ મધ્યવર્તી ગણના લાગે છે.
સરળ શ્રેડીના ત્રણ પદો a−d, a, a+d અને ચાર પદો a−3d, a−d, a+d, a+3d તરીકે લેવા, સમસ્યાઓનો સરવાળો સરળ બનાવે છે.
સંકલનની સમસ્યાઓમાં સમય બચાવે છે અને ઘણીવાર PYQ માં જોવા મળે છે.
સરળ શ્રેડીમાં, ત્રણ પદો a, b, c સમાન સરળ શ્રેડીમાં હોય તો b−a = c−b, એટલે કે 2b = a+c. આથી b એ a અને c નો સરળ મધ્યક (Arithmetic Mean, AM) હોય છે.
AM ની વ્યાખ્યા અને તેનો સીધો ઉપયોગ.
સમગુણોત્તર શ્રેડી (Geometric Progression, GP) એ આવર્ત ગણ છે જ્યાં ક્રમિક પદોનો ગુણોત્તર અચળ હોય છે. આ અચળ ગુણોત્તરને સામાન્ય ગુણોત્તર (Common Ratio, r) કહે છે.
GP ની મૂળભૂત વ્યાખ્યા, AP જેટલું જ મહત્વનું.
nમું પદ શોધવાનું સૂત્ર: a_n = a·r^(n−1), જ્યાં a પ્રથમ પદ અને r સામાન્ય ગુણોત્તર છે.
સૂત્રનો સીધો ઉપયોગ અને રૂપાંતરિત પ્રશ્નોમાં.
n પદોનો સરવાળો: S_n = a(r^n−1)/(r−1) જ્યારે r≠1; જો r=1 હોય તો S_n = na.
GP ના સરવાળાના પ્રશ્નો ફરજિયાત આવે છે.
અનંત સમગુણોત્તર શ્રેડીનો સરવાળો મળે છે જો અને માત્ર જો |r|<1 હોય, અને તે S_∞ = a/(1−r) થાય છે.
પરિમેય ભિન્નને અવિભાજ્ય અપૂર્ણાંક રૂપમાં આપવાના પ્રશ્નો આ સાથે સંકળાયેલા છે.
જો G એ a અને b નો ગુણોત્તર મધ્યક (Geometric Mean, GM) હોય, તો G² = ab અને G = √(ab).
GM ની વ્યાખ્યા અને તેની ગણતરી ફરજિયાત.
AM–GM અસમતા: ધન વાસ્તવિક સંખ્યાઓ a અને b માટે, AM ≥ GM, એટલે કે (a+b)/2 ≥ √(ab). સમાનતા ત્યારે જ જ્યારે a = b.
અસમતાના પ્રશ્નો અને મહત્તમ/ન્યૂનતમ મૂલ્ય શોધવા માટે સીધી લાગુ પડે છે.
જો a, b, c સરળ શ્રેડીમાં હોય, b, c, d સમગુણોત્તર શ્રેડીમાં હોય, અને c, d, e પુનઃ સરળ શ્રેડીમાં હોય, તો અનુપાત a : c : e = (c−d)² : cd : (c+d)² નો સંબંધ મળે છે.
મિશ્ર શ્રેડીના સંકલન પ્રશ્નોમાં વારંવાર આવે છે.
જો S_n, P_n, R_n ક્રમશઃ n પદોની સરળ શ્રેડી, સમગુણોત્તર શ્રેડી, અને તેના ઉલ્ટા પદોની સરહદનો સરવાળો હોય, તો (S_n / R_n) = (P_n / Q_n) જેવો સંબંધ ઉપયોગી છે.
ઉચ્ચ તફાવત અથવા વિશેષ પ્રશ્ન પ્રકારોમાં.
રિપીટિંગ દશાંશનું ભિન્ન રૂપ: ઉદા., 0.bar(ab) = ab/99, 0.bar(abc) = abc/999. આ રીતે બનતી શ્રેડી હંમેશા સમગુણોત્તર શ્રેડી હોય છે.
અંકગણિત અને ભાગકારની વિશેષ સમસ્યાઓમાં સીધું લાગુ પડે છે.
n પદોની સરળ શ્રેડીનો સામાન્ય તફાવત શોધવા માટે: d = (અંતિમ પદ − પ્રથમ પદ)/(n−1). જ્યારે મધ્યમાં પદો આપેલા હોય ત્યારે આ ઉલટું સૂત્ર ઉપયોગી બને છે.
n, a, અથવા d માંથી બીજું શોધવાના પ્રશ્નો.
જો સરળ શ્રેડીના n પદોનો સરવાળો S_n = An² + Bn હોય, તો સામાન્ય તફાવત d = 2A થાય છે અને પ્રથમ પદ a = A + B થાય છે.
બહુવિકલ્પી પ્રશ્નોમાં ઝડપી ગણતરી.
સમગુણોત્તર શ્રેડીમાં, કોઈ પણ પદ a_m = a_n · r^(m−n) સ્વરૂપે પણ શોધી શકાય છે, જેને બદલે a_1 અને r ની જરૂર નથી હોતી.
જ્યારે પ્રથમ પદ જણાયેલું ન હોય ત્યારે ઉપયોગી.
જો ત્રણ ધન સંખ્યાઓ a, b, c ક્રમશઃ સરળ શ્રેડી, સમગુણોત્તર શ્રેડી અને સમગુણોત્તર શ્રેડીમાં હોય, તો b² = ac અને b−a = c−b એકસાથે જોવા મળે છે.
AP અને GP ના સંયોજિત પ્રશ્નો માટે મહત્વપૂર્ણ.
સમગુણોત્તર શ્રેડીના n પદો લેવા: a/r^(n−1), a/r^(n−3), …, ar^(n−1) (jod r માં) એ ગુણાકાર સરળ બનાવે છે. અંતિમ પદો જ્યારે અંગત હોય, ત્યારે આ પદ્ધતિ ઉપયોગી છે.
સંકલન પ્રશ્નોમાં ગણતરીમાં સરળતા.
કુદરતી સંખ્યાઓનો સરવાળો 1+2+…+n = n(n+1)/2, વર્ગોનો સરવાળો n(n+1)(2n+1)/6, અને ઘનોનો સરવાળો [n(n+1)/2]² એ સરળ શ્રેડીના પરિણામો છે જે ઘણીવાર સંયોજક પ્રશ્નોમાં ઉપયોગી બને છે.
વિકલન અને સંકલનની સમસ્યાઓમાં અંકગણિત આધાર.
