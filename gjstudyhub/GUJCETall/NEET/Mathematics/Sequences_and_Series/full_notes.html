અનુક્રમો અને શ્રેઢીઓ (Sequences and Series)

🧪 GUJCET — Gujarati • Mathematics • Sequences and Series

આ પ્રકરણ અનુક્રમો અને શ્રેઢીઓના મૂળભૂત સિદ્ધાંતોનો અભ્યાસ કરે છે. તેમાં સમાંતર શ્રેઢી (A.P.) અને ગુણોત્તર શ્રેઢી (G.P.) ની વ્યાખ્યા, સામાન્ય પદ, સરવાળાના સૂત્રો અને તેમના ગુણધર્મોનો સમાવેશ થાય છે. AM-GM અસમાનતા અને વિશિષ્ટ શ્રેઢીઓના સરવાળા જેવી મહત્વપૂર્ણ વિષયવસ્તુઓ પણ આ પ્રકરણમાં આવરી લેવાઈ છે. આ વિષય ગણિતની બીજા વિભાગોમાં અને વાસ્તવિક જીવનની ઘણી સમસ્યાઓ ઉકેલવા માટે આધારભૂત છે.

1. પ્રસ્તાવના: અનુક્રમ અને શ્રેઢી શું છે?

અનુક્રમ (Sequence) એ સંખ્યાઓની ગોઠવણી છે જે ચોક્કસ નિયમ અનુસાર ગોઠવાય છે. દરેક સંખ્યાને 'પદ' કહે છે. ઉદાહરણ તરીકે, 2, 5, 8, 11, ... એ અનુક્રમ છે. જ્યારે આ પદોનો સરવાળો કરવામાં આવે છે ત્યારે તેને શ્રેઢી (Series) કહે છે. ઉદાહરણ તરીકે, 2+5+8+11+... એ શ્રેઢી છે. અનુક્રમ મર્યાદિત કે અમર્યાદિત હોઈ શકે છે. શ્રેઢી પણ મર્યાદિત અથવા અમર્યાદિત હોઈ શકે છે. આ વિષયમાં આપણે મુખ્યત્વે બે પ્રકારની શ્રેઢીઓનો અભ્યાસ કરીશું: સમાંતર શ્રેઢી (A.P.) અને ગુણોત્તર શ્રેઢી (G.P.).

2. સમાંતર શ્રેઢી (Arithmetic Progression - A.P.): વ્યાખ્યા અને સામાન્ય પદ

જ્યારે કોઈ અનુક્રમમાં પાછલા પદમાંથી સામેલ પદ બરાબર એક ધ્રુવ સંખ્યા હોય, ત્યારે તે અનુક્રમને સમાંતર શ્રેઢી કહે છે. આ ધ્રુવ સંખ્યાને 'સામાન્ય તફાવત' (Common Difference) d કહે છે. જો પ્રથમ પદ a અને સામાન્ય તફાવત d હોય, તો nમું પદ a_n = a + (n-1)d દ્વારા મળે છે. ઉદાહરણ તરીકે, 3, 7, 11, 15,... માં a=3, d=4 છે. 10મું પદ શોધવા માટે: a_10 = 3 + (10-1)*4 = 3 + 36 = 39. આ રીતે કોઈ પણ n માટે પદ શોધી શકાય છે. શ્રેઢીનો ક્રમ મહત્વપૂર્ણ છે; દરેક પદ પહેલાના પદમાં d ઉમેરીને મળે છે.

પદસરવાળો
પ્રથમ પદ (a_n)a
સામાન્ય તફાવત (d)સ્થિર
nમું પદ (a_n)a + (n-1)d

3. સમાંતર શ્રેઢીનો સરવાળો

મર્યાદિત સમાંતર શ્રેઢીના n પદોનો સરવાળો S_n શોધવા માટે બે સૂત્રો છે. પ્રથમ સૂત્ર: S_n = n/2 [2a + (n-1)d], જ્યાં a પ્રથમ પદ અને d સામાન્ય તફાવત છે. બીજું સૂત્ર: S_n = n/2 [a + l], જ્યાં l છેલું પદ છે. ઉદાહરણ તરીકે, 2+4+6+...+20 માટે a=2, d=2, છેલું પદ l=20. n શોધવા: 20 = 2 + (n-1)*2 => n=10. સરવાળો: S_10 = 10/2 [2*2 + (10-1)*2] = 5[4+18] = 110. અથવા S_10 = 10/2 [2+20] = 5*22 = 110. આ સૂત્રોનો ઉપયોગ વિવિધ સમસ્યાઓમાં થાય છે.

4. સમાંતર શ્રેઢીના ગુણધર્મો

સમાંતર શ્રેઢીના કેટલાક મહત્વપૂર્ણ ગુણધર્મો નીચે મુજબ છે: (i) જો દરેક પદમાં sthir સંખ્યા ઉમેરવી, બાદ કરવી, ગુણવી અથવા ભાગવી, તો પરિણામી અનુક્રમ પણ A.P. હોય છે. (ii) ત્રણ સંખ્યાઓ a, b, c એ A.P. માં હોય તો 2b = a+c. (iii) A.P. ના સરવાળાનું સૂત્ર S_n = An^2+Bn ની રચાણમાં હોય છે, જ્યાં A અને B નියતા છે. (iv) જો a, b, c, d, e એ A.P. માં હોય, તો a+e = b+d = c+c. આ ગુણધર્મો સમસ્યા ઉકેલવામાં સહાયક થાય છે.

5. ગુણોત્તર શ્રેઢી (Geometric Progression - G.P.): વ્યાખ્યા અને સામાન્ય પદ

જ્યારે કોઈ અનુક્રમમાં પાછલા પદને સામેલ પદે વહેંચતા એક ધ્રુવ અપૂર્ણાંક મળે, ત્યારે તે અનુક્રમને ગુણોત્તર શ્રેઢી કહે છે. આ ધ્રુવ અપૂર્ણાંકને 'સામાન્ય ગુણોત્તર' (Common Ratio) r કહે છે. જો પ્રથમ પદ a અને સામાન્ય ગુણોત્તર r હોય, તો nમું પદ a_n = a * r^(n-1) દ્વારા મળે છે. ઉદાહરણ: 2, 6, 18, 54,... માં a=2, r=3 છે. 5મું પદ: a_5 = 2 * 3^(4) = 2*81 = 162. r ની કિંમત પર આધાર રાખી શ્રેઢી વધતી કે ઘટતી હોઈ શકે છે.

પદસરવાળો
પ્રથમ પદ (a)અનુક્રમનું પ્રથમ સંખ્યા
સામાન્ય ગુણોત્તર (r)સ્થિર
nમું પદ (a_n)a * r^(n-1)

6. ગુણોત્તર શ્રેઢીનો સરવાળો (મર્યાદિત)

ગુણોત્તર શ્રેઢીના n પદોનો સરવાળો S_n નીચેના સૂત્ર દ્વારા મળે છે: જો r ≠ 1 હોય, તો S_n = a(r^n - 1)/(r-1) અથવા S_n = a(1-r^n)/(1-r). ઉદાહરણ: 1+2+4+...+256 માટે a=1, r=2. છેલું પદ a_n = 256 = 1*2^(n-1) => n=9. સરવાળો: S_9 = 1*(2^9 - 1)/(2-1) = 511. જો r=1 હોય, તો S_n = na. આ સૂત્રનો ઉપયોગ ગણિત અને વિજ્ઞાનમાં થાય છે.

7. અનંત ગુણોત્તર શ્રેઢી (Infinite Geometric Series)

જ્યારે સામાન્ય ગુણોત્તર r ની કિંમત -1 < r < 1 હોય (એટલે કે |r| < 1), ત્યારે અનંત ગુણોત્તર શ્રેઢીનો સરવાળો અસ્તિત્વ ધરાવે છે. આ સરવાળો S_∞ = a/(1-r) દ્વારા મળે છે. ઉદાહરણ: 1 + 1/2 + 1/4 + 1/8 + ... માં a=1, r=1/2. સરવાળો S_∞ = 1/(1-1/2) = 2. જો |r| ≥ 1 હોય, તો શ્રેઢી વિષમપ્રાપ્ત (divergent) હોય છે અને તેનો સરવાળો અનંત હોય છે. આ વિષય અર્ધ-અનંત શ્રેઢીઓ માટે મહત્વપૂર્ણ છે.

8. AM અને GM (સમાંતર અને ગુણોત્તર માધ્ય)

કોઈ પણ બે ધન વાસ્તવિક સંખ્યાઓ a અને b માટે, સમાંતર માધ્ય (A.M.) A = (a+b)/2 અને ગુણોત્તર માધ્ય (G.M.) G = √(ab) વચ્ચે AM-GM અસમાનતા લાગુ પડે છે: A ≥ G, એટલે કે (a+b)/2 ≥ √(ab). સમાનતા ત્યારે જ જોડાય છે જ્યારે a = b. આ અસમાનતા સમસ્યાઓના ઉકેલ માટે ઉપયોગી છે. ઉદાહરણ: જો a + b = 10 હોય, તો ab નું મહત્તમ મૂલ્ય શોધવા માટે AM-GM વાપરીએ. A = 5, તેથી G ≤ 5, એટલે √(ab) ≤ 5 => ab ≤ 25. આમ, ab નું મહત્તમ મૂલ્ય 25 છે.

9. વિશિષ્ટ શ્રેઢીઓના સરવાળા

કેટલીક વિશેષ શ્રેઢીઓના સરવાળાના સૂત્રો નીચે મુજબ છે: (1) પ્રથમ n સ્વાભાવિક સંખ્યાઓનો સરવાળો: 1+2+...+n = n(n+1)/2. (2) પ્રથમ n સંખ્યાઓના વર્ગોનો સરવાળો: 1²+2²+...+n² = n(n+1)(2n+1)/6. (3) પ્રથમ n સંખ્યાઓના ઘનનો સરવાળો: 1³+2³+...+n³ = [n(n+1)/2]². આ સૂત્રો અનુભવ અથવા ગાણિતિક આગમન દ્વારા સાબિત થઈ શકે છે. ઉદાહરણ: પ્રથમ 10 સંખ્યાઓના વર્ગોનો સરવાળો = 10*11*21/6 = 385. આ સૂત્રો પરીક્ષામાં સીધાં આવે છે.

10. શ્રેઢીના સરવાળાની અન્ય પદ્ધતિઓ

કેટલીક શ્રેઢીઓના સરવાળા માટે વ્યસ્ત પદ્ધતિ (Telescoping) અને અંશ-છેદ વિભાજનનો ઉપયોગ થાય છે. ઉદાહરણ: 1/(1*2) + 1/(2*3) + 1/(3*4) + ... + 1/(n(n+1)). દરેક પદને 1/k - 1/(k+1) તરીકે લખી શકાય. સરવાળો: (1 - 1/2) + (1/2 - 1/3) + ... + (1/n - 1/(n+1)) = 1 - 1/(n+1) = n/(n+1). આ રીતે સામાન્ય રીતે જટિલ શ્રેઢીઓને સરળ બનાવી શકાય છે.

11. A.P. અને G.P. વચ્ચેનો સંબંધ

જો a, b, c એ A.P. માં હોય, તો 2b = a+c. જો a, b, c એ G.P. માં હોય, તો b² = ac. જો બે સંખ્યાઓની A.P. અને G.P. આપેલી હોય, તો તેઓ મળીને સમીકરણો બનાવે છે. ઉદાહરણ: જો બે સંખ્યાઓનો સરવાળો 10 અને ગુણાકાર 21 હોય, તો તેઓ x અને y હોય તો x+y=10 અને xy=21. A.M. = 5, G.M. = √21 ≈ 4.58. આ સંબંધો સમસ્યાઓ ઉકેલવામાં મદદ કરે છે.

12. ઉદાહરણો અને લાગુ પાડવા

ઉદાહરણ 1: એક A.P. નું પ્રથમ પદ 5 અને સામાન્ય તફાવત 3 છે. 20મું પદ શોધો. ઉકેલ: a_20 = 5 + (20-1)*3 = 5 + 57 = 62. ઉદાહરણ 2: એક G.P. નું પ્રથમ પદ 2 અને સામાન્ય ગુણોત્તર 1/2 છે. પ્રથમ 6 પદોનો સરવાળો શોધો. ઉકેલ: a=2, r=1/2, n=6. S_6 = 2((1/2)^6 - 1)/((1/2)-1) = 2(1/64 - 1)/(-1/2) = 2(-63/64)/(-1/2) = 2 * (63/64) * 2 = 126/32 = 3.9375. આ પ્રકારના ઉદાહરણો પરીક્ષામાં આવે છે.

⚡ સૂત્રો

A.P. નું nમું પદ: a_n = a + (n-1)d
A.P. નો n પદોનો સરવાળો: S_n = n/2 [2a + (n-1)d]
A.P. નો સરવાળો છેલ્લા પદ સાથે: S_n = n/2 [a + l]
G.P. નું nમું પદ: a_n = a * r^(n-1)
G.P. નો n પદોનો સરવાળો: S_n = a(r^n - 1)/(r-1), r ≠ 1
અનંત G.P. નો સરવાળો: S_∞ = a/(1-r), જ્યાં |r| < 1
AM-GM અસમાનતા: (a+b)/2 ≥ √(ab) for a,b > 0
પ્રથમ n સ્વાભાવિક સંખ્યાઓનો સરવાળો: n(n+1)/2
પ્રથમ n સંખ્યાઓના વર્ગોનો સરવાળો: n(n+1)(2n+1)/6
પ્રથમ n સંખ્યાઓના ઘનનો સરવાળો: [n(n+1)/2]^2

⭐ મહત્વના મુદ્દા

  • સમાંતર શ્રેઢીમાં સામાન્ય તફાવત d સતત રહે છે.
  • ગુણોત્તર શ્રેઢીમાં સામાન્ય ગુણોત્તર r સતત રહે છે.
  • જો r = 1 હોય, તો G.P. નો સરવાળો S_n = na હોય છે.
  • AM-GM અસમાનતા仅 માત્ર ધન સંખ્યાઓ માટે લાગુ પડે છે.
  • A.P. અને G.P. ના મિશ્રણમાં કેટલીક સમસ્યાઓ ઉકેલી શકાય છે.
  • વ્યસ્ત પદ્ધતિ (Telescoping) થી શ્રેઢીના સરવાળા સરળ બને છે.

⚠️ સામાન્ય ભૂલો

A.P. ના સરવાળા માટે S_n = n/2 [a + l] સૂત્રમાં l એ છેલ્લું પદ હોવાનું ભૂલી જવું.
G.P. માં r = 1 હોય ત્યારે S_n = a(r^n -1)/(r-1) સૂત્ર વાપરવું (સૂત્ર અવૈધ હોય છે).
AM-GM અસમાનતા ઋણ સંખ્યાઓ પર લાગુ પાડવી.
અનંત G.P. માટે |r| ≥ 1 હોય ત્યારે S_∞ = a/(1-r) સૂત્ર વાપરવું (શ્રેઢી વિષમપ્રાપ્ત હોય છે).
પદનો ક્રમ ખોટો સમજવો (ઉદા. nમું પદ vs nથી nમું પદ).
સામાન્ય તફાવત d ની કિંમત ધન કે ઋણ ગણવી.

🎯 પરીક્ષા ટિપ્સ

A.P. અને G.P. ના સૂત્રો મનસ્તોર કરો અને તેમનો ઉપયોગ કરવાની પ્રેક્ટિસ કરો.
AM-GM અસમાનતાનો ઉપયોગ મહત્તમ/ન્યૂનતમ મૂલ્ય શોધવામાં થાય છે.
વિશિષ્ટ શ્રેઢીઓના સરવાળાના સૂત્રો યાદ રાખો.
સમસ્યાઓમાં A.P. કે G.P. ઓળખવા માટે પદો વચ્ચેનો સંબંધ તપાસો.
વ્યસ્ત પદ્ધતિ (Telescoping) ની ઓળખ રાખો.
ગણતરીમાં ચોકસાઈ રાખો અને એકમો યોગ્ય રીતે લખો.
પરીક્ષામાં સમયની બચત માટે સૂત્રોનો સીધો ઉપયોગ કરો.

📌 સારાંશ

આ પ્રકરણે અનુક્રમો અને શ્રેઢીઓના મૂળભૂત સિદ્ધાંતો ઢાંક્યા છે. સમાંતર શ્રેઢી (A.P.) અને ગુણોત્તર શ્રેઢી (G.P.) ની વ્યાખ્યા, સામાન્ય પદ, સરવાળાના સૂત્રો અને ગુણધર્મો શીખ્યા. AM-GM અસમાનતા અને વિશિષ્ટ શ્રેઢીઓના સરવાળા પણ આવરી લેવાયા. અન્ય પદ્ધતિઓ જેવી કે વ્યસ્ત પદ્ધતિ શ્રેઢીઓના સરવાળા સરળ બનાવે છે. આ પ્રકરણ ગણિતની બીજી વિષયવસ્તુઓ અને વાસ્તવિક જીવનની સમસ્યાઓ ઉકેલવા માટે આધારભૂત છે. સૂત્રો અને અસમાનતાઓ યાદ રાખવી અને અભ્યાસ કરવો જરૂરી છે.
