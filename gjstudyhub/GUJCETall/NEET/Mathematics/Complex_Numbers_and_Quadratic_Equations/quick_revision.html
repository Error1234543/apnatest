કોમ્પ્લેક્સ નંબર્સ અને ક્વોડ્રેટિક ઇક્વેશન્સ - ક્વિક રિવિઝન

🧪 GUJCET — Gujarati • Mathematics • Complex Numbers and Quadratic Equations

🧠 યાદ રાખો

કોમ્પ્લેક્સ સંખ્યાનું સામાન્ય રૂપ: z = a + bi, જ્યાં a, b વાસ્તવિક સંખ્યાઓ અને i = √(-1) (Imaginary unit)
કોમ્પ્લેક્સ સંખ્યાનો મોડ્યુલસ (Modulus): |z| = √(a² + b²)
કોમ્પ્લેક્સ સંખ્યાનો આર્ગ્યુમેન્ટ (Argument): θ = tan⁻¹(b/a), જ્યાં z = a + bi
કોમ્પ્લેક્સ સંખ્યાઓનો સરવાળો અને બાદબાકી: (a + bi) ± (c + di) = (a ± c) + (b ± d)i
કોમ્પ્લેક્સ સંખ્યાઓનો ગુણાકાર: (a + bi)(c + di) = (ac - bd) + (ad + bc)i
કોમ્પ્લેક્સ સંખ્યાનો વ્યસ્ત (Reciprocal): 1/(a + bi) = (a - bi)/(a² + b²)
કોમ્પ્લેક્સ સંખ્યાનો સંયુગ્મી (Conjugate): z̄ = a - bi જ્યાં z = a + bi

⚡ ઝડપી સૂત્રો

કોમ્પ્લેક્સ સંખ્યાનું ધ્રુવીય રૂપ (Polar form): z = r(cosθ + i sinθ) = r e^(iθ) (ઓયલરનું સૂત્ર)
ડી મોઇવ્રેનું પ્રમેય (De Moivre’s Theorem): [r(cosθ + i sinθ)]^n = r^n (cos nθ + i sin nθ)
કોમ્પ્લેક્સ સંખ્યાના મૂળ: n-માત્રા કોમ્પ્લેક્સ સંખ્યાના n મૂળો હશે, જેઓ એકબીજાથી 2π/n કોણે અલગ પડે
ક્વોડ્રેટિક ઇક્વેશન ax² + bx + c = 0 ના મૂળો: x = [-b ± √(b² - 4ac)] / (2a)
વિભેદક (Discriminant) D = b² - 4ac: D > 0 → બે વાસ્તવિક અને ભિન્ન મૂળ; D = 0 → એક વાસ્તવિક મૂળ (બેજ મૂળ); D < 0 → બે કોમ્પ્લેક્સ સંયુગ્મી મૂળ

✅ વન-લાઈનર્સ

કોમ્પ્લેક્સ સંખ્યાઓ વાસ્તવિક સંખ્યાઓનો વિસ્તાર છે.
કોમ્પ્લેક્સ સંખ્યાનો મોડ્યુલસ હંમેશા નોન-નેગેટિવ હોય છે.
કોમ્પ્લેક્સ સંખ્યાનો આર્ગ્યુમેન્ટ -π થી π વચ્ચે હોય છે.
કોમ્પ્લેક્સ સંખ્યાઓનો ગુણાકાર ધ્રુવીય રૂપમાં સરળ બને છે.
ક્વોડ્રેટિક ઇક્વેશનના મૂળોના સરવાળો = -b/a અને ગુણાકાર = c/a (વિયેટા પ્રમેય)
જો કોમ્પ્લેક્સ સંખ્યાનો મોડ્યુલસ 1 હોય, તો તે યુનિટ સર્કલ પર સ્થિત છે.
કોમ્પ્લેક્સ સંખ્યાનો સંયુગ્મી તેના અક્ષ પર પ્રતિબિંબિત કરે છે.
