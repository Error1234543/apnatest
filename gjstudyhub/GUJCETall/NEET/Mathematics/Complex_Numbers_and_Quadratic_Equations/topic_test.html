Q1. i નું મૂલ્ય શું છે?
A. −1
B. 1
C. √(−1)
D. 0
✅ C — i એ એકમ કાલ્પનિક અંક (Imaginary unit) છે, જે i² = −1 સંતોષે છે. તેથી i = √(−1).
Q2. આબાસી સંખ્યા (Complex number) z = 3 + 4i માં વાસ્તવિક ભાગ (Real part) શોધો.
A. 4
B. −3
C. 3
D. 7
✅ C — જો z = a + bi હોય, તો વાસ્તવિક ભાગ a અને કાલ્પનિક ભાગ b થાય. અહીં z = 3 + 4i માં વાસ્તવિક ભાગ 3 છે.
Q3. x² + 9 = 0 આ સમીકરણનાં મૂળ શું છે?
A. 3, −3
B. ±3i
C. ±9i
D. 9, −9
✅ B — x² + 9 = 0 ⇒ x² = −9 ⇒ x = ±√(−9) = ±3i. જ્યારે વિવેચક (Discriminant) ઋણ હોય ત્યારે મૂળ કાલ્પનિક મળે છે.
Q4. z₁ = 2 + 3i અને z₂ = 1 − i હોય તો z₁ + z₂ શોધો.
A. 3 + 2i
B. 1 + 4i
C. 3 + 4i
D. 2 − i
✅ A — વાસ્તવિક ભાગનો સરવાળો: 2 + 1 = 3. કાલ્પનિક ભાગનો સરવાળો: 3i + (−i) = 2i. તેથી z₁ + z₂ = 3 + 2i.
Q5. દ્વિઘાત સમીકરણ ax² + bx + c = 0 નું વિવેચક (Discriminant) શું થાય?
A. b² − 4ac
B. b² + 4ac
C. a² − 4bc
D. 2b − 4ac
✅ A — દ્વિઘાત સમીકરણનું વિવેચક Δ = b² − 4ac થાય. વિવેચકના આધારે મૂળનું સ્વરૂપ (વાસ્તવિક/કાલ્પનિક) નક્કી થાય છે.
Q6. જટિલ સંખ્યા z = 3 − 4i નું કોંજુગેટ (Complex conjugate) શું થશે?
A. 3 + 4i
B. −3 + 4i
C. −3 − 4i
D. 3 − 4i
✅ A — જટિલ સંખ્યા z = a + bi નું કોંજુગેટ z̄ = a − bi થાય. તેથી z = 3 − 4i નું કોંજુગેટ 3 + 4i છે.
Q7. જટિલ સંખ્યાઓ z₁ = 2 + i અને z₂ = 1 − 2i હોય, તો z₁ · z₂ નું મૂલ્ય શું થશે?
A. 4
B. 4 + 3i
C. 4 − 3i
D. 3 + 4i
✅ A — z₁ · z₂ = (2 + i)(1 − 2i) = 2 − 4i + i − 2i² = 2 − 3i − 2(−1) = 2 − 3i + 2 = 4. અહીં i² = −1 લેતાં પરિણામ 4 આવે છે.
Q8. d्वિઘાत સમીકરણ x² − 6x + 13 = 0 નાં મૂળ શું છે?
A. 3 ± 2i
B. 6 ± 2i
C. −3 ± 2i
D. 3 ± 4i
✅ A — વિવેચક D = b² − 4ac = (−6)² − 4·1·13 = 36 − 52 = −16. મૂળ = (6 ± √−16)/2 = (6 ± 4i)/2 = 3 ± 2i.
Q9. જટિલ સંખ્યા z = 1 + i√3 નું ક્ષેત્રીય સ્વરૂપ (Polar form) શું થશે?
A. 2(cos 60° + i sin 60°)
B. 2(cos 30° + i sin 30°)
C. √2(cos 45° + i sin 45°)
D. 4(cos 60° + i sin 60°)
✅ A — |z| = √(1² + (√3)²) = √4 = 2. θ = tan⁻¹(√3/1) = 60°. તેથી z = 2(cos 60° + i sin 60°).
Q10. બિન્સના પ્રમેય (De Moivre's theorem) અનુસાર (cos 30° + i sin 30°)⁶ નું મૂલ્ય શું થશે?
A. 1
B. −1
C. i
D. −i
✅ A — બિન્સના પ્રમેય મુજબ [cos θ + i sin θ]ⁿ = cos(nθ) + i sin(nθ). અહીં n = 6, θ = 30° લેતાં cos 180° + i sin 180° = −1 + 0i = −1. તેથી સાચો જવાબ B છે — પરંતુ મૂળ ગણતરી: cos 180° = −1, sin 180° = 0, પરિણામ −1.
