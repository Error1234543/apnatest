કોમ્પ્લેક્સ નંબર અને દ્વિઘાત સમીકરણો

🧪 GUJCET — Gujarati • Mathematics • Complex Numbers and Quadratic Equations

કોમ્પ્લેક્સ નંબરની પરિભાષા અને રચના
કોમ્પ્લેક્સ નંબર a + bi રૂપે લખાય છે, જ્યાં a અને b વાસ્તવિક નંબર (real numbers) છે અને i = √(-1) કાલ્પનિક એકમ (imaginary unit) છે.
i² = -1
aને વાસ્તવિક ભાગ (real part) અને bને કાલ્પનિક ભાગ (imaginary part) કહેવાય છે.
📝 કોમ્પ્લેક્સ નંબરને z = a + bi અથવા z = (a, b) રૂપે દર્શાવી શકાય.
કોમ્પ્લેક્સ નંબરનો સરખામણી અને સરવલક્ષણ
બે કોમ્પ્લેક્સ નંબર z₁ = a + bi અને z₂ = c + di સરખા હોવાના માટે a = c અને b = d હોવા જરૂરી છે.
કોમ્પ્લેક્સ નંબરનો મોડ્યુલસ (modulus) |z| = √(a² + b²) થી વ્યાખ્યાયિત થાય છે.
|z| = √(a² + b²)
કોમ્પ્લેક્સ નંબરનો કોણીય ભાગ (argument) θ = tan⁻¹(b/a) થી વ્યાખ્યાયિત થાય છે, જ્યાં a ≠ 0.
θ = arg(z) = tan⁻¹(b/a)
📝 મોડ્યુલસ હંમેશા નોન-નેગેટિવ હોય છે.
કોમ્પ્લેક્સ નંબરની બીજગણિતીય ક્રિયાઓ
સરવાળો: (a + bi) + (c + di) = (a + c) + (b + d)i
z₁ + z₂ = (a + c) + (b + d)i
બાદબાકી: (a + bi) - (c + di) = (a - c) + (b - d)i
z₁ - z₂ = (a - c) + (b - d)i
ગુણાકાર: (a + bi)(c + di) = (ac - bd) + (ad + bc)i
z₁ × z₂ = (ac - bd) + (ad + bc)i
ભાગાકાર: (a + bi)/(c + di) = [(ac + bd) + (bc - ad)i] / (c² + d²)
z₁ / z₂ = [(ac + bd) + (bc - ad)i] / (c² + d²)
📝 ભાગાકાર માટે છેદને રેશનલાઇઝ (rationalize) કરવો પડે છે.
કોમ્પ્લેક્સ નંબરનો સંગ્યા (Conjugate)
z = a + bi નો સંગ્યા (conjugate) z̄ = a - bi થાય છે.
z̄ = a - bi
z × z̄ = a² + b² = |z|²
📝 સંગ્યાનો મોડ્યુલસ z અને z̄ સમાન હોય છે.
કોમ્પ્લેક્સ નંબરનો ધ્રુવીય રૂપ (Polar Form)
z = r(cosθ + i sinθ), જ્યાં r = |z| અને θ = arg(z)
z = r(cosθ + i sinθ)
ઓયલરના સૂત્ર (Euler’s formula) મુજબ: e^(iθ) = cosθ + i sinθ
e^(iθ) = cosθ + i sinθ
ધ્રુવીય રૂપમાં ગુણાકાર અને ભાગાકાર સરળ બને છે.
📝 ધ્રુવીય રૂપમાં rને મેગ્નિટ્યુડ (magnitude) અને θને આર્ગ્યુમેન્ટ (argument) કહેવાય છે.
ડી મોઇવ્રેનું પ્રમેય (De Moivre’s Theorem)
(cosθ + i sinθ)^n = cos(nθ) + i sin(nθ) માટે કોઈપણ પૂર્ણાંક n માટે સત્ય છે.
(cosθ + i sinθ)^n = cos(nθ) + i sin(nθ)
આ પ્રમેય કોમ્પ્લેક્સ નંબરની ઘાતને શોધવામાં ઉપયોગી છે.
📝 n નેગેટિવ અથવા ભિન્ન હોવાના કિસ્સામાં પણ પ્રમેય લાગુ પડે છે.
કોમ્પ્લેક્સ નંબરના મૂળ (Roots of Complex Numbers)
કોમ્પ્લેક્સ નંબર z ના n મૂળો n વાર ગુણાકાર કરવાથી z મળે છે.
z^(1/n) = r^(1/n) [cos((θ + 2kπ)/n) + i sin((θ + 2kπ)/n)], k = 0, 1, 2, ..., n-1
કોમ્પ્લેક્સ નંબરના n મૂળો એક સર્પિલ (circle) પર સમાન અંતરે સ્થિત હોય છે.
📝 મૂળોની સંખ્યા હંમેશા n હોય છે.
દ્વિઘાત સમીકરણ (Quadratic Equations)
દ્વિઘાત સમીકરણનો સામાન્ય રૂપ: ax² + bx + c = 0, જ્યાં a ≠ 0.
ax² + bx + c = 0
મૂળો (roots) શોધવા માટે વિશ્લેષણ સૂત્ર (quadratic formula) વાપરવામાં આવે છે.
x = [-b ± √(b² - 4ac)] / (2a)
વિશ્લેષણ (discriminant) D = b² - 4ac મૂળોની પ્રકૃતિ નક્કી કરે છે.
📝 D > 0: બે વાસ્તવિક અને ભિન્ન મૂળો. D = 0: એક વાસ્તવિક મૂળ (બે સરખા મૂળો). D < 0: બે કોમ્પ્લેક્સ સંગ્યા મૂળો.
વિશ્લેષણ અને મૂળોની પ્રકૃતિ
જો D > 0: મૂળો x₁ = [-b + √D]/(2a) અને x₂ = [-b - √D]/(2a) વાસ્તવિક અને ભિન્ન હોય છે.
જો D = 0: મૂળ x = -b/(2a) વાસ્તવિક અને દ્વિગુણિત (repeated) હોય છે.
જો D < 0: મૂળો x₁ = [-b + i√|D|]/(2a) અને x₂ = [-b - i√|D|]/(2a) કોમ્પ્લેક્સ સંગ્યા હોય છે.
D < 0 હોવાના કિસ્સામાં મૂળો કોમ્પ્લેક્સ અને એકબીજાના સંગ્યા હોય છે.
📝 કોમ્પ્લેક્સ મૂળો હંમેશા સંગ્યા જોડીમાં મળે છે.
દ્વિઘાત સમીકરણના મૂળો અને ગુણધર્મો
મૂળોનો સરવાળો: x₁ + x₂ = -b/a
x₁ + x₂ = -b/a
મૂળોનો ગુણાકાર: x₁ × x₂ = c/a
x₁ × x₂ = c/a
આ ગુણધર્મો વિયેટના સૂત્ર (Vieta’s formulas) તરીકે ઓળખાય છે.
📝 વિયેટના સૂત્ર દ્વિઘાત સમીકરણના મૂળો વચ્ચેના સંબંધને દર્શાવે છે.
દ્વિઘાત સમીકરણની રચના
જો x₁ અને x₂ મૂળો હોય, તો દ્વિઘાત સમીકરણ (x - x₁)(x - x₂) = 0 રૂપે લખી શકાય.
x² - (x₁ + x₂)x + x₁x₂ = 0
આ રૂપમાં સમીકરણના ગુણાંકો મૂળોના સરવાળા અને ગુણાકાર પર આધારિત હોય છે.
📝 આ પદ્ધતિને મૂળો પરથી સમીકરણ રચવા માટે વાપરવામાં આવે છે.
કોમ્પ્લેક્સ નંબર અને દ્વિઘાત સમીકરણ વચ્ચેનો સંબંધ
કોમ્પ્લેક્સ નંબરદ્વિઘાત સમીકરણના કોમ્પ્લેક્સ મૂળો
દરેક દ્વિઘાત સમીકરણના મૂળો કોમ્પ્લેક્સ નંબર હોઈ શકે છે, પરંતુ તે હંમેશા વાસ્તવિક નહીં હોય.
કોમ્પ્લેક્સ નંબરના સિદ્ધાંત દ્વારા દ્વિઘાત સમીકરણના બધા જ મૂળો શોધી શકાય છે.
📝 આ સિદ્ધાંત ફંડામેન્ટલ થિયોરેમ ઓફ આલજેબ્રા (Fundamental Theorem of Algebra) નું એક પરિણામ છે.
