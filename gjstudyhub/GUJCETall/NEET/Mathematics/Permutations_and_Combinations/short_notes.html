પ્રમેય અને સંયોજન — શૈક્ષણિક ટૂંકા નોંધો

🧪 GUJCET — Gujarati • Mathematics • Permutations and Combinations

📘 વ્યાખ્યાઓ

  • ફેક્ટોરિયલ (Factorial): n! = 1 × 2 × 3 × ... × n; 0! = 1 સ્વીકારેલું છે.
  • ક્રમચય (Permutation): n માંથી r ભિન્ન વસ્તુઓનો ક્રમ ગોઠવવાની રીતोंની સંખ્યા nPr.
  • સંયોજન (Combination): n માંથી r ભિન્ન વસ્તુઓ પસંદ કરવાની રીતोंની સંખ્યા nCr (ક્રમ માને નહિ).
  • મૂળભૂત ગણનાનો નિયમ (Fundamental Principle of Counting): જો કામ A m રીતે અને કામ B n રીતે થઈ શકે, તો ક્રમિક રીતે A અને B એકસાથે mn રીતે થાય.
  • પુનરાવર્તિત ક્રમચય: જો vસ્થાને p પ્રકારની પુનરાવર્તિત વસ્તુઓ હોય, તો કુલ ગોઠવણી = n!/(p!·q!·r!·...).

⚡ સૂત્રો

  • nPr = n!/(n-r)! ; જ્યાં 0 ≤ r ≤ n.
  • nCr = n!/[r!(n-r)!] ; જ્યાં 0 ≤ r ≤ n.
  • nPr = nCr × r! ; ક્રમચય = સંયોજન × વસ્તુઓનો ક્રમ.
  • nC0 + nC1 + nC2 + ... + nCn = 2^n.
  • nC0 + nC2 + nC4 + ... = nC1 + nC3 + nC5 + ... = 2^(n-1).
  • nCx = nCy ⇒ x = y અથવા x + y = n (સંમિતિ ગુણધર્મ).
  • nCr = n-1Cr-1 + n-1Cr (પાસ્કલનું સૂત્ર).
  • n+1Cr = nCr + nCr-1 + nCr-1 ?
  • n×n-1×...×(n-r+1) = n(n-1)(n-2)...(n-r+1) — r પદોનો ગુણાકાર.
  • nPk × k! = n!/(n-k)! જે nPk = nPk.
  • r × nCr = n × n-1Cr-1.
  • nCr/nC(r-1) = (n-r+1)/r.

⭐ મુખ્ય તથ્યો

  • nPr > nCr હંમેશા s (જ્યારે r ≥ 1), કારણ nPr = nCr × r! અને r! ≥ 1.
  • nCr ની મહત્તમ કિંમત r = n/2 આગળ (જો n સમ હોય) અથવા (n±1)/2 આગળ (જો n વિષમ હોય).
  • પુનરાવર્તન વિનાની ક્રમચય સંખ્યા = n!, જ્યારે દરેક વસ્તુ બરાબર એકવાર આવે.
  • પુનરાવર્તન સાથે: n પ્રકારની વસ્તુઓમાંથી r સ્થાન ભરવા → n^r રીતો.
  • r સમાન વસ્તુઓ અને (n-r) ભિન્ન વસ્તુઓ માટે, વિભાજન પછી ક્રમચય = n!/r!.
  • વર્તુળાકાર ગોઠવણી: n ભિન્ન વસ્તુઓનો વર્તુળાકાર ક્રમચય = (n-1)!.
  • વર્તુળાકારમાં જો દિશા સમાન માનવામાં આવતી ન હોય (ઉલટાવી શકાય), તો ગોઠવણી = (n-1)!/2.
  • કોઈ પણ વિભાજન સમસ્યામાં 'પહેલાં ભાગવું' અને 'પછી ગોઠવવું' — બે પગલાંનો ક્રમ જરૂરી છે.
  • nPr નું મૂલ્ય સદા ધન અને પૂર્ણાંક હોય છે.
  • જો n વિષમ હોય, તો મધ્યસ્થ બે સંયોજનો nC(n-1)/2 અને nC(n+1)/2 સમાન અને મહત્તમ હોય.

⚠️ સામાન્ય ભૂલો

  • ક્રમચય અને સંયોજનમાં ગેરસમજ: જવાબ માગે છે 'ચૂંટણી' તો nCr, 'ગોઠવણી' તો nPr.
  • 0! = 0 સમજવું — ખોટું; 0! = 1 છે.
  • nCr માં r > n મૂકવાથી પરિણામ ખોટું આવે છે; nCr એવું અસ્તિત્વ રાખતું નથી.
  • વર્તુળાકાર ગોઠવણીમાં n! લખવું — ખોટું; સાચો જવાબ (n-1)! છે.
  • પુનરાવર્તન ધ્યાનમાં લીધા વગર n! વાપરવું.
  • "ઓછામાં ઓછા" / "વધુમાં વધુ" પ્રકારના પ્રશ્નમાં સીધો nCr લાગુ પાડવો.
  • સમાન વસ્તુઓની ગોઠવણીમાં ભિન્ન વસ્તુઓ મની લેવી.
  • nCx = nCy માંથી ફક્ત x = y લેવું — x + y = n પણ શક્ય છે.
  • રોકાણ/અવરોધ સમસ્યાઓમાં વસ્તુઓની ગોઠવણી પહેલાં પસંદગી કરવાનું ભૂલી જવું.
  • મૂળભૂત ગણના નિયમનો ઉપયોગ 'અથવા' (OR) કિસ્સામાં કરવો — તે 'અને' (AND) માટે છે, OR માટે વધારો.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • nPr અને nCr નું બીજગણિતીય સંબંધ nPr = nCr·r! હંમેશા યાદ રાખો.
  • પાસ્કલનું સૂત્ર nCr = n-1Cr-1 + n-1Cr એ પરીક્ષામાં બહુવિધ ઉપયોગી છે.
  • Σ nCr = 2^n એ ગણનાના પ્રશ્નોમાં ઝડપી માર્ગ છે.
  • પુનરાવર્તિત ક્રમચયનું સૂત્ર n!/(p!·q!·r!·...) પ્રત્યેક પરીક્ષામાં આવે છે.
  • વર્તુળાકાર ક્રમચય: (n-1)! અને દિશાને ધ્યાનમાં લેતા (n-1)!/2.
  • રોકાણ ધરાવતા પ્રશ્નમાં: રોકાયેલી વસ્તુઓને એક ઘટક માની ગોઠવવી પછી બાકીની વસ્તુઓ ગોઠવવી.
  • વિભાજન પ્રકાર: 2 વંશોમાં a અને b સદસ્યો —nCા × mCબ / (વંશો ભિન્ન હોય તો ભાગવાની જરૂર નથી, સમાન હોય તો 2! વડે ભાગવું).
  • r × nCr = n × n-1Cr-1 અને nCr/nC(r-1) = (n-r+1)/r એ ગણતરી ઘટાડે છે.
  • પુનરાવર્તન ધરાવતી ગોઠવણી: n પ્રકારની વસ્તુઓમાંથી r સ્થાન પર → n^r રીતો.
  • ગોઠવણીમાં કોઈ પણ ચોક્કસ સ્થાને ચોક્કસ વસ્તુ આવવી જોઈએ — તે વસ્તુને સ્થિર કરી બાકીની (n-1)Pr-1 ગોઠવો.
  • n કે n+1 માંથી વિષમ/સમ પસંદગીની પ્રશ્નોમાં nCr ના ગુણધર્મોનો લાભ લો.
  • ક્રમચય-સંયોજન સંબંધિત સાબિતી પ્રશ્નોમાં બંને બાજુનું સાદુરૂપ n!/(r!(n-r)!) મારફતે કરવું અનુકૂળ છે.
