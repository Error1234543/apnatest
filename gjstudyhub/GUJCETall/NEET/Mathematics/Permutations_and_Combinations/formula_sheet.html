ક્રમચય અને સંયોજન (Permutations and Combinations) — સૂત્ર શીટ

🧪 GUJCET — Gujarati • Mathematics • Permutations and Combinations

⚡ સૂત્રો

ક્રમચય (nPr): nPr = n! / (n - r)!
n = કુલ તત્વોની સંખ્યા, r = ચૂંટાણ કરવાની સંખ્યા (r ≤ n), ! = ફેક્ટોરિયલ (દા.ત. 5! = 5×4×3×2×1), 0! = 1 · SI: કોઈ એકમ નથી (એક ગણતરી છે) · આવર્તન મંજૂર ન હોય અને ક્રમ મહત્વનો હોય (ક્રમચય = ગોઠવણ)
સંયોજન (nCr): nCr = n! / [r! × (n - r)!]
n = કુલ તત્વોની સંખ્યા, r = યોજાણમાં લેવાની સંખ્યા (r ≤ n), ! = ફેક્ટોરિયલ · SI: કોઈ એકમ નથી · આવર્તન મંજૂર ન હોય અને ક્રમ મહત્વનો ન હોય (ચૂંટણી)
પ્રથમ બંધારણીય સૂત્ર (સંબંધ): nPr = nCr × r!
nPr = ક્રમચય, nCr = સંયોજન, r! = r નો ફેક્ટોરિયલ · SI: કોઈ એકમ નથી · રૂઢિચુસ્ત ક્રમચય/સંયોજન માટે
સંયોજનનો સમપ્રમાણ ગુણધર્મ: nCr = nC(n - r)
n = કુલ તત્વો, r = પસંદગીનો આંકડો · SI: કોઈ એકમ નથી · 0 ≤ r ≤ n
ચાઈન-રાસી ઇડેન્ટિટી (રચનાત્મક સૂત્ર): nCr + nC(r + 1) = (n + 1)C(r + 1)
n અને r ≥ 0; પાસેની બે સંયોજનોનો સરવાળો · SI: કોઈ એકમ નથી · સંયોજનની ગણતરીમાં સામાન્ય રીતે ઉપયોગી
પુનરાવર્તિત ક્રમચય (બધા તત્વો અલગ): k = n! / (p! × q! × r! ...)
n = કુલ વસ્તુઓની સંખ્યા, p, q, r... = સમાન પ્રકારની વસ્તુઓની સંખ્યા · SI: કોઈ એકમ નથી · શબ્દોની ગોઠવણ / અક્ષરોની ગોઠવણ જેમાં કેટલાક અક્ષરો સમાન હોય
પુનરાવર્તિત ક્રમચય (પુનરાવર્તન મંજૂર હોય): k = n^r
n = સંભવિત વિકલ્પોની સંખ્યા, r = યોગ્ય સ્થાનો/પસંદગીઓ · SI: કોઈ એકમ નથી · જ્યારે પુનરાવર્તન મંજૂર હોય (દા.ત. PIN કોડ, સંખ્યા ગોઠવણ)
બહુપદી પ્રમેયનો સહગુણક: તથ્ય (a + b + c)^n માં a^p b^q c^r નો સહગુણક = n! / (p! q! r!), જ્યાં p + q + r = n
n = ઘાત, p, q, r = અલગ અલગ ચલોના ઘાતાંક · SI: કોઈ એકમ નથી · બહુપદીનું વિસ્તરણ જ્યારે બધા સહગુણકો ધન પૂર્ણાંક હોય
નચ્છેદ વિધિ (Inclusion–Exclusion) — ઓછામાં ઓછું 1 લક્ષણ: નક્કી = C(n,1)×(n-1)^r − C(n,2)×(n-2)^r + C(n,3)×(n-3)^r − ...
n = ક્ષેત્રો/પાત્રોની સંખ્યા, r = વસ્તુઓ/બોલ્સની સંખ્યા · SI: કોઈ એકમ નથી · દરેક બોક્સમાં ઓછામાં ઓછી 1 વસ્તુ હોય અને વસ્તુઓ અલગ હોય
સરખી સંયોજન (નચ્છેદ) — દરેક સ્થાને ઓછામાં ઓછું 1: n^n − C(n,1)(n−1)^n + C(n,2)(n−2)^n − C(n,3)(n−3)^n + ...
n = કુલ વિભિન્ન સ્થાનો/પાત્રો · SI: કોઈ એકમ નથી · વિભિન્ન બોલને વિભિન્ન કટોરામાં એ રીતે મૂકવા કે કોઈ પણ ખાલી ન રહે
વર્તુળાકાર ક્રમચય (બધી વસ્તુઓ અલગ): (n − 1)!
n = વર્તુળમાં બેસનારા લોકો/વસ્તુઓ · SI: કોઈ એકમ નથી · કક્ષાબદ્ધ ગોઠવણ જ્યારે દિશા એકસરખી હોય
વર્તુળાકાર ક્રમચય (જો બેઠક પ્રતિબિંબ/ઉલટું માનવામાં આવે): (n − 1)! / 2
n = લોકો/વસ્તુઓ · SI: કોઈ એકમ નથી · દા.ત. હાર, ટોપી, રાઉન્ડ ટેબલ જ્યાં ડાબી-જમણી બાજુ મહત્વનું નથી
ગોળાકાર ગોઠવણ — સરખા અને વિભિન્ન કુલ મિશ્રણ: જો k સમાન અને (n − k) અલગ હોય, તો કુલ = (n − 1)! / k!
n = કુલ તત્વો, k = સમાન તત્વો · SI: કોઈ એકમ નથી · સમાન અને વિભિન્ન બંને ધરાવતી વર્તુળાકાર ગોઠવણ
દિશામાં બેઠક (Circle — અનિશ્ચિત ક્રમ): (n − 1)! / 2
n = લોકો · SI: કોઈ એકમ નથી · જ્યારે દિશા (કલાકદિશા/વિરુદ્ધ કલાકદિશા) પણ સમાન ગણાય
પરિમિતિ (આંશિક સંચય) — પુનરાવર્તન મંજૂર: n^r
n = ચેર/સ્થાનો, r = પદાર્થો/લોકો · SI: કોઈ એકમ નથી · પુનરાવર્તન (સરખા પદાર્થો/અક્ષરો) મંજૂર હોય
સરવાળો (પૂર્ણ સંચય): nC0 + nC1 + nC2 + ... + nCn = 2^n
n = કુલ તત્વો · SI: કોઈ એકમ નથી · સર્વગ્રાહી સંયોજનોનો સરવાળો
વિકલ્પી સંયોજનોનો સરવાળો: nC0 − nC1 + nC2 − nC3 + ... = 0 (n ≥ 1 હોય ત્યારે)
n ≥ 1 · SI: કોઈ એકમ નથી · જો n ≥ 1, વૈકલ્પિક સંયોજનોનો સરવાળો શૂન્ય
બે સમાન જૂથમાં વિભાજન: ન = C(2n, n) / 2
n = દરેક જૂથમાં વસ્તુઓ · SI: કોઈ એકમ નથી · 2n તત્વોને બે સમાન જૂથમાં વિભાજીત કરવા
રંગ કરવાની સમસ્યા (3 રંગ, n ના સમબાજુ બહુભુજ): કુલ = (3^n − 3)/3 + 2 × (−1)^n
n = બહુભુજની બાજુઓ/કોણો · SI: કોઈ એકમ નથી · સમબાજુ n-ભુજને 3 રંગો વડે રંગવા, પરિભ્રમણથી સમાન ગણાય
બહુપદી ગુણાકારમાં સહગુણક: (1 + x)^m × (1 + x)^n = (1 + x)^(m+n); x^r નો સહગુણક = Cm+r,r
m, n = ઘાતાંક, r = ઇચ્છિત ઘાત · SI: કોઈ એકમ નથી · બે બેઈનોમિયલનો ગુણાકાર

🔗 સંબંધો

  • ક્રમચય અને સંયોજન વચ્ચે: nPr = nCr × r! — સંયોજનને r! વડે ગુણતા ક્રમચય મળે છે.
  • nCr = nC(n − r): r વસ્તુઓ પસંદ કરવી એ (n − r) વસ્તુઓ અપનાવવા સમાન છે.
  • પાસેના બે સંયોજનોનો સરવાળો (ચાઈન-રાસી): nCr + nC(r+1) = (n+1)C(r+1).
  • કુલ સંયોજનોનો સરવાળો: Σ(nCr) = 2^n — દરેક તત્વ પસંદ અથવા અપનાવવું.
  • પુનરાવર્તિત ક્રમચય n^r: પુનરાવર્તન મંજૂર હોય ત્યારે સ્થાન પ્રતિ શૂન્ય સંખ્યાની મર્યાદા હોતી નથી.

🎯 ટ્રિક્સ

સીધો જવાબ: nCr = nC(n − r) નો ઉપયોગ કરીને મોટા r ને બદલે નાનો (n − r) વાપરો (દા.ત. C(20,18) = C(20,2)).
અંશ-છેદ સાદુંરૂપ: nPr / nPr−1 = n − r + 1; nCr / nC(r−1) = (n − r + 1) / r.
ક્રમચય vs સંયોજન: શબ્દ 'ગોઠવણ', 'સામૂહિક બેઠક', 'સ્થાન' → ક્રમચય; શબ્દ 'ચૂંટણી', 'સમૂહ', 'જૂથ' → સંયોજન.
વાર્તુળાકાર ગોઠવણ: (n − 1)! — વર્તુળમાં એક સ્થાન સ્થિર કરીને ગોઠવો (પરિભ્રમણથી સમાન ગણાય).
વિકલ્પી યુગ્મ: r = 0,2,4,... લેવા માટે C(n,0) + C(n,2) + ... = 2^(n−1) (n ≥ 1 હોય ત્યારે).

⚠️ ભૂલો

ક્રમચય/સંયોજન ગૂંચવણ: ક્રમ માન્ય હોય તો nPr, ન હોય તો nCr — ગૂંચવણમાં nCr નો ઉપયોગ કરવા.
(n − r)! નો સાચો અંતર ગણતરી છૂટી જાય છે (ઉદા. n = 6, r = 4; (6 − 4)! = 2!, નહિતર 4!).
રૂઢિચુસ્ત કિસ્સામાં nPr ને nCr વડે ગુણીને પુનઃ ગોઠવવા (મહત્વપૂર્ણ ક્રમ વારંવાર ગુમાવવો).
પુનરાવર્તન મંજૂર હોય ત્યારે nPr નો ઉપયોગ કરવો — સાચો ફોર્મ્યુલા n^r છે.
વર્તુળાકાર ક્રમચયમાં સીધો n! લખવો — સાચો જવાબ (n − 1)! છે (પરિભ્રમણથી સમાન ગણાય).
ગોળાકાર ગોઠવણમાં સરખા તત્વોનું વિભેદન છોડી દેવું — n!/k! નો હર (કુલ અવયવો) છોડવો.
બહુપદી સહગુણકમાં p + q + r ≠ n હોય તો પણ n!/(p!q!r!) લખી દેવું — શરત p + q + r = n જરૂરી છે.
નચ્છેદની ગણતરીમાં ચિહ્નનો ભ્રમ: (+)−(+)+(−)... એલોરિધમ બગાડવું.
સંકલન સૂત્ર (2^n) માં nCr નો સરવાળો g = 0 થી n સુધી થાય છે — r નું બાઉન્ડry છોડવું.
