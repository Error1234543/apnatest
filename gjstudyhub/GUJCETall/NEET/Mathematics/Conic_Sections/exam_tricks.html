GUJCET ગાણિત – અભ્યાસક્રમ: દર્શકવિભાગ (Conic Sections) માટે તરત ઉપયોગી પરીક્ષા ટ્રિક્સ

🧪 GUJCET — Gujarati • Mathematics • Conic Sections

🎯 પરીક્ષા ટ્રિક્સ

ઘોડિયાળની ઓળખ – સામાન્ય સમીકરણ પરથી દર્શક પ્રકાર નક્કી કરો સમીકરણ Ax² + Bxy + Cy² + Dx + Ey + F = 0 માં, Δ = B² − 4AC જુઓ: • Δ < 0 ⇒ લંબવૃત્ત અથવા બિંદુ / ખાલી સમીકરણ • Δ = 0 ⇒ પરવલય • Δ > 0 ⇒ અતિપરાબોલા આ ટ્રિકથી ગણતરી પહેલાં જ વિકલ્પો સાચા છે કે નહીં તેની જલદી ચોકસાઈ કરી શકાય.
જ્યારે પ્રશ્નમાં ફક્ત એક સામાન્ય બીજઘાત સમીકરણ આપેલ હોય અને તે કેવા દર્શકવિભાગનું છે તે પૂછતું હોય. ગણતરી ઓછી કરવા કાગળનો સમય બચે છે.
દા.ત.: 3x² − 4xy + 3y² + 5x − 7y + 2 = 0 માં A=3, B=−4, C=3. Δ = (−4)² − 4·3·3 = 16 − 36 = −20 < 0 ⇒ લંબવૃત્ત (અથવા ખાસ સ્થિતિ). તેથી પરવલય / અતિપરાબોલા વિકલ્પો તરત નકારી શકાય.
વૃત્તની સ્પર્શક માટેની ઝટપટ શરત y = mx + c રેખા x² + y² = r² ને સ્પર્શે છે જો અને માત્ર જો c² = r²(1 + m²) થાય. આ સૂત્ર યાદ રાખો; વિસંવાદિત ચતુર્ભુજ (discriminant) શૂન્ય કરવાની જરૂર પડતી નથી.
જ્યારે વૃત્ત અને રેખા સ્પર્શક/છેદક/બહિષ્ઠ હોય તે નક્કી કરવાનું હોય, અથવા અજ્ઞાત c / m શોધવાનું હોય. સામાન્ય વિધિ કરતાં 3–4 ગણું ઝડપી.
દા.ત.: x² + y² = 25 અને રેખા y = (4/3)x + c સ્પર્શક છે તો c શોધો. c² = 25·(1 + 16/9) = 25·(25/9) ⇒ c = ±25/3. એક ક્ષણમાં જવાબ મળે છે.
વૃત્તનું સમીકરણ – વ્યાસના સિરોડાં આપેલ હોય ત્યારે ડાયલેટ સૂત્ર જો વ્યાસના છેડા A(x₁,y₁) અને B(x₂,y₂) હોય, તો વૃત્તનું સમીકરણ: (x − x₁)(x − x₂) + (y − y₁)(y − y₂) = 0 આ સીધું ઉકેલ આપે છે; કેન્દ્ર/ત્રિજ્યા વિચારવાની જરૂર નથી.
જ્યારે પ્રશ્નમાં વ્યાસના અંત્યબિંદુઓ આપેલ હોય અને સમીકરણ લખવાનું હોય. કેન્દ્ર શોધીને પછી ત્રિજ્યા કરવી ગમે તો વધુ સમય લે છે.
દા.ત.: A(1,2), B(5,6) વ્યાસના છેડા. સમીકરણ: (x−1)(x−5) + (y−2)(y−6) = 0 ⇒ x²−6x+5 + y²−8y+12 = 0 ⇒ x²+y²−6x−8y+17=0. તરત જ કાર્ટેઝિયન સ્વરૂપ મળે.
પરવલયના લેટસ લેક્ટમ (જીવાન્તર) = 4a યાદ રાખો y² = 4ax પ્રકારનું પરવલય હોય તો લેટસ લેક્ટમ = 4a. જો સમીકરણ સંરૂપમાં ન હોય, પહેલાં a શોધો (ઉદા. 2y² = 8x ⇒ y² = 4x ⇒ a=1 ⇒ LL=4). વિકલ્પોમાંથી 4a સાથે મેળ ખાતો વિકલ્પ પસંદ કરો.
જ્યારે પરવલયનું લેટસ લેક્ટમ પૂછ્યું હોય અથવા બીજી કોઈ માહિતીમાં 4a આવતું હોય. પરવલયની વ્યાખ્યા પર આધારિત, ગણતરી ઓછી.
દા.ત.: 5y² = 20x ⇒ y² = 4x ⇒ 4a=4 ⇒ a=1. લેટસ લેક્ટમ = 4a = 4. જવાબ તરત મળે.
પરવલય પરનું સ્થિત બિંદુ (at², 2at) યાદ કરો y² = 4ax પરનું સામાન્ય બિંદુ (at², 2at) લખી શકાય. આથી કોઈ પણ સમય t મૂકીને બિંદુ યાદગાર બનાવી શકાય; સ્પર્શક: ty = x + at² ; અભિલંબ: y + tx = 2at + at³.
જ્યારે પરવલય પરનું કોઈ ચોક્કસ બિંદુ, તે સ્થાને સ્પર્શક/અભિલંબનું સમીકરણ, અથવા લેટસ લેક્ટમના અંત્યબિંદુઓ પૂછવામાં આવે. સીધું મૂલ્ય મૂકીને ઉકેલ થાય છે.
દા.ત.: y² = 8x માટે a=2. t=1 લો ⇒ બિંદુ (2,4). ત્યાં સ્પર્શક: 1·y = x + 2·1 ⇒ y = x + 2. અભિલંબ: y + x = 4 + 8 = 12 ⇒ x + y = 12. બંને સમીકરણો એક ક્ષણમાં.
પરવલયના ફોકસ થી નીલંબ જીવા (latus rectum chord) ના અંત્યબિંદુઓ y² = 4ax માટે: (a, ±2a). જવાબ સીધો યાદ કરી લો. જો પરવલય U-આકારનું હોય તો X-અક્ષની પરિમાણમાં ફોકસ (a,0); Y-અક્ષમાં (0,a) બદલાય.
જ્યારે લેટસ લેક્ટમના છેડા અથવા ફોકસથી લંબરૂપ જીવાના બિંદુઓ પૂછવામાં આવે. ફોકસ અને FD (દિઘાવૃત્તિ) યાદ રાખવાની જરૂર રહેતી નથી.
દા.ત.: x² = 12y ⇔ (y−0)=¼x²? પરંતુ પ્રમાણિત સ્વરૂપ x² = 4ay, અહીં 4a=12 ⇒ a=3. ફોકસ (0,3). લેટસ લેક્ટમના અંત્યબિંદુઓ: (±2a, a) = (±6, 3). વિકલ્પમાં (6,3) તરત પસંદગી.
ઉપવલયનું સમીકરણ જોતાં જ a, b, c, e શોધવાનું ઝટપટ અનુમાન x²/a² + y²/b² = 1 (a>b): • ઉન્મિત (eccentricity) e = √(1 − b²/a²) • ફોકસ (±ae, 0), અભિદિઘાવૃત્તિ x = ±a/e • લેટસ લેક્ટમ = 2b²/a આ બધા સામાન્ય પ્રશ્નોમાં સીધા આવે છે.
જ્યારે ઉપવલયનું પ્રમાણિત સમીકરણ આપેલ હોય અને ફોકસ / ઉન્મિતિ / અભિદિઘાવૃત્તિ / લેટસ લેક્ટમ પૂછવામાં આવે. સૂત્રો યાદ રાખવાથી 20–30 વિકલ્પો ઝડપથી નકારી શકાય.
દા.ત.: x²/25 + y²/9 = 1 ⇒ a²=25, b²=9. e = √(1−9/25) = √(16/25)=4/5. ફોકસ (±ae,0)=(±4,0). લેટસ લેક્ટમ = 2·9/5 = 18/5. વિકલ્પ-ચકાસણીમાં આ સંખ્યાઓ તરત મળે.
ઉપવલયની વ્યાખ્યાપ્રયુક્ત ઉકેલ – ફોકસથી અંતર + FD અંતર = 2a ઉપવલય પરનું કોઈ પણ બિંદુ P માટે PF₁ + PF₂ = 2a. જો બે ફોકસ અને મહત્તમ/bિંદુ આપેલ હોય તો 2a શોધી શકાય.
જ્યારે ઉપવલયનો આકાર અથવા અક્ષની લંબાઈ પૂછવામાં આવે, પણ સમીકરણ સીધું ન હોય. વ્યાખ્યાનો ઉપયોગ કરીને ગણતરી ઓછી કરી શકાય.
દા.ત.: ઉપવલયના ફોકસ (3,0), (−3,0) અને શીર્ષ (5,0) હોય તો 2a = અંતર(F₁,F₂)? ના, શીર્ષથી ફોકસ સુધીનું અંતર a−ae? અહીં a=5, ae=3 ⇒ e=3/5. 2a=10. ફોકસ થી FD દૂરી a/e = 25/3. આ બધું વ્યાખ્યાથી તરત મળે.
અતિપરાબોલાની મુખ્ય ચાપ / અશ્મભુજ લંબાઈ તૂતકરમ અતિપરાબોલા x²/a² − y²/b² = 1 માટે: • ઉન્મિતિ e = √(1 + b²/a²) • ફોકસ (±ae, 0), અભિદિઘાવૃત્તિ x = ±a/e • લેટસ લેક્ટમ = 2b²/a ઉપવલય કરતાં e > 1, b² = a²(e²−1) યાદ રાખો.
જ્યારે અતિપરાબોલાના ફોકસ, ઉન્મિતિ અથવા લેટસ લેક્ટમ જોઈતા હોય. ઉપવલય સૂત્રો સાથે ભ્રમણા ન પડે તે સુનિશ્ચિત કરો.
દા.ત.: x²/16 − y²/9 = 1 ⇒ a=4, b=3. e = √(1+9/16) = √(25/16)=5/4. ફોકસ (±5,0). લેટસ લેક્ટમ = 2·9/4 = 9/2. વિકલ્પ સાથે તરત મેળ.
જોગ્ગલ્સ / ડાયગોનલ ઓરિએન્ટેશન – અક્ષનું ધ્યાન રાખો જો x² પદનું અચળાંક મોટું હોય તો મુખ્ય અક્ષ X-અક્ષ પર; y² મોટું હોય તો Y-અક્ષ પર. પરવલયમાં y² = 4ax ⇒ સમમિતિ અક્ષ X-અક્ષ, શિરોબિંદુ (0,0). x² = 4ay ⇒ Y-અક્ષ. આ ઓળખ વડે ગેરમાર્ગેના વિકલ્પો તરત નકારી શકાય.
જ્યારે સમીકરણની દિશા, શિરોબિંદુ અથવા સમમિતિ અક્ષ પૂછવામાં આવે. સામાન્ય ભૂલ: x² = 4ay બદલાઈને y² = 4ax ગણી લેવા.
દા.ત.: y² = 12x ⇒ 4a=12, a=3. શિરોબિંદુ (0,0), ફોકસ (3,0), FD x=−3. જો x² = 12y હોત તો શિરોબિંદુ (0,0), ફોકસ (0,3) બનત; વિકલ્પોમાં આ બંનેમાંથી એક સાચો હોય.
વૃત્તની જીવાનું મધ્યબિંદુ M(h,k) હોય તો સ્પર્શક / જીવાનું સમીકરણ TT₁ = S₁ પ્રકારનું ટૂલ: S ≡ x²+y²=r², M(h,k) માટે જીવાનું સમીકરણ: xh + yk = h²+k². આથી જીવાનું સમીકરણ તરત લખી શકાય; ઢાળ અને અંતર વડે પુનઃગણતરીની જરૂર નથી.
જ્યારે વૃત્તની કોઈ જીવાનું મધ્યબિંદુ આપેલ હોય અને તે જીવાનું સમીકરણ શોધવાનું હોય. ઝડપી અને પ્રમાણિત.
દા.ત.: x²+y²=25 અને જીવાનું મધ્યબિંદુ M(3,4): જીવાનું સમીકરણ: 3x + 4y = 3²+4² = 25 ⇒ 3x+4y=25. ઢાળ −3/4. M થી કેન્દ્ર (0,0) નો ઢાળ 4/3; ગુણनफल = −1 ⇒ L ⊥ OM. ચોકસાઈ ચકાસાઈ.
આપેલ બે બિંદુઓ થી દાઝદર્શક (tangents) ના સંબંધમાં લઘુત્તમ ગણતરી વૃત્ત x²+y²=r² માટે બિંદુ P(x₁,y₁) થી સ્પર્શક: xx₁+yy₁=r² (જો P વૃત્ત પર હોય). જો P બહાર હોય, તો SP·S'P' માધ્યમથી ઝટપટ ઝરૂખાં શોધો.
જ્યારે વૃત્ત પરનું બિંદુ આપેલ હોય અને ત્યાં સ્પર્શકનું સમીકરણ જોઈતું હોય. ગ્રેડિયંટ + અંતરાલ પદ્ધતિ કરતાં ઘણું ઝડપી.
દા.ત.: વૃત્ત x²+y²=16 પર બિંદુ (4cosθ,4sinθ) લો. સ્પર્શક: 4xcosθ+4ysinθ=16 ⇒ xcosθ+y sinθ=4. જો θ=π/3, સ્પર્શક: x·½ + y·√3/2 =4 ⇒ x+√3 y=8. પસંદગીમાં તરત ઓળખી શકાય.
