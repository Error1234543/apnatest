વિકલ સમીકરણો (Differential Equations) — સૂત્ર તાલિકા

🧪 GUJCET — Gujarati • Mathematics • Differential Equations

⚡ સૂત્રો

વિકલ સમીકરણની ડિગ્રી (Degree): જ્યારે વિકલ સમીકરણ બહુપદી સ્વરૂપમાં હોય, ત્યારે સૌથી ઉચ્ચ ક્રમના વિકલજ પરનો ઘાત ડિગ્રી થાય.
ડિગ્રી = ઉચ્ચતમ વિકલજનો ઘાતાંક · SI: અવિમાપક (Dimensionless) · સમીકરણ ઘનિષ્ઠ બહુપદી સ્વરૂપમાં હોવું જોઈએ
વિકલ સમીકરણનો ક્રમ (Order): સમીકરણમાં રહેલા ઉચ્ચતમ ક્રમના વિકલજનો ક્રમ.
ક્રમ = highest derivative order · SI: અવિમાપક · શૂન્યેતર, ધન પૂર્ણાંક
વિકલ સમીકરણનું સામાન્ય સમાધાન (General Solution): y = φ(x, C₁, C₂, ..., Cₙ) જ્યાં n = order(વિકલ સમીકરણ)
Cᵢ = સ્વૈચ્છિક અચળાંકો, n = ક્રમ · SI: અચળાંકના એકમો · કોઈ પ્રારંભિક/સીમા શરત ન આપેલી હોય
વિકલ સમીકરણનું વિશેષ સમાધાન (Particular Solution): Cᵢ ના નિશ્ચિત મૂલ્યો વડે સામાન્ય સમાધાનમાં યોગ્ય Cᵢ મૂકવું.
Cᵢ = પ્રારંભિક/સીમા શરતો પરથી મળે છે · SI: — · પ્રારંભિક કિંમતો (Initial Conditions) આપેલી હોય
ઘટક સંખ્યા (Family of Curves) અને સમીકરણ: f(x, y, C) = 0 → x ની સંદર્ભે વિકલન કરી C દૂર કરવું.
C = ઘટક સંખ્યાનો પરિમાણ · SI: — · એક અથવા વધુ ઘટકોને કારણે વક્ર પરિવાર
ચલ-પૃથક્કરણ પદ્ધતિ (Separable Form): dy/dx = g(x)h(y) → ∫ dy/h(y) = ∫ g(x)dx + C
h(y) ≠ 0, g, h સતત ફલનો · SI: — · સમીકરણનો v型 (separable) વિસ્તાર શક્ય હોય
સಮघાતીય વિકલ સમીકરણ (Homogeneous DE) — પ્રથમ પ્રકાર: dy/dx = F(y/x). y = vx મૂકી, v + x(dv/dx) = F(v).
v = y/x, x(dv/dx) = F(v) − v · SI: — · P(x,y), Q(x,y) સમાન ઘાતના સમઘાત બહુપદીઓ
સમઘાત પદાવલી ઓળખ: M(x,y)dx + N(x,y)dy = 0 જ્યાં M, N ઘાત n ના સમઘાત.
M(tx,ty)=tⁿM(x,y); N(tx,ty)=tⁿN(x,y) · SI: — · બંને પદ એક જ ઘાતના
રૂપ-3: dx/dy = (ax+by+c)/(a'x+b'y+c'): X=x−h, Y=y−k; (ah+bk+c=0, a'h+b'k+c'=0) ઉકેલી h,k મેળવવા. ત્યબાદ dY/dX = समघाતીય.
h,k = સ્રોત શિફ્ટના બિંદુ · SI: — · a/b ≠ a'/b' (સમાંતર નહિ)
રૂપ-4: બિંદુ સાથેનું સમીકરણ (Specific Point Form): dy/dx = f((y−y₁)/(x−x₁)); Y=y−y₁, X=x−x₁.
Y=vX મૂકવું · SI: — · f ચોક્કસ રૂપમાં
રૂપ-5: અનુકલન અવયવ પદ્ધતિ (Integrating Factor – I.F.): dy/dx + P(x)y = Q(x) → I.F. = e^(∫P dx); સમાધાન: y·(I.F.) = ∫Q·(I.F.)dx + C
P, Q = x ના ફલનો; I.F. = સંકલન અવયવ · SI: — · પ્રથમ ક્રમ, રેખીય સ્વરૂપ
અનુકલન અવયવ — x ની દૃષ્ટિએ: dx/dy + P(y)x = Q(y) → I.F. = e^(∫P dy); x·(I.F.) = ∫Q·(I.F.)dy + C
P, Q = y ના ફલનો · SI: — · x ને સ્વાભાવિક ચલ ગણી
આવર્ત (Bernoulli) સમીકરણનું રૂપાંતર: dy/dx + Py = Qyⁿ → y⁻ⁿdy/dx + Py⁻ⁿ⁺¹ = Q. v=y¹⁻ⁿ મૂકવું, પ્રથમ-ક્રમ રેખીય બને.
v = y^(1−n), dv/dx = (1−n)y^(−n)dy/dx · SI: — · n ≠ 1
ચલ-પરિવર્તન: M(x)dx + N(y)dy = 0: ∫M(x)dx + ∫N(y)dy = C (જો હર અચળ હોય)
M, N = અલગ અલગ ચલના ફલન · SI: — · પૃથક્કરણ સીધું શક્ય
સમીકરણનું સમાધાન: y = mx + c (સ્પર્શક ઝડપ): જો dy/dx = f((y−mx)/(x)) તો y = mx + c → v = c constant; dv/dx = 0.
m = ઝડપાંશ, c = અચળ અંતઃખંડ · SI: — · વિશેષ રૂપાંતરણ
બીજું ક્રમ સુધીનું સમીકરણ: y'' = f(x,y') — u મૂકવું: u = dy/dx → du/dx = y'' → ∫du = ∫f(x,u)dx
u = પ્રથમ વિકલજ · SI: — · y સીધું હાજર ન હોય
યોગ્ય વિકલ સમીકરણ (Exact DE): M dx + N dy = 0 જો ∂M/∂y = ∂N/∂x. તો ψ_x=M, ψ_y=N; ψ(x,y)=C.
ψ = સંભાવના ફલન (potential function) · SI: — · યોગ્યતા પરીક્ષણ સંતોષાય
યોગ્યતા સુધારો (Exactness Correction): M dx + N dy = 0 જરૂરી ન હોય તો I.F. μ(x) અથવા μ(y) શોધવું: μ = e^∫f(x)dx જ્યાં f(x)=(M_y−N_x)/N (એકમાત્ર x પર આધારિત હોય).
μ = સંકલન અવયવ, I.F. · SI: — · M_y≠N_x પરંતુ ઉપરનું અંશ-છેદ x-માત્ર હોય

🔗 સંબંધો

  • વિકલ સમીકરણનો ક્રમ અને ડિગ્રી સ્વતંત્ર ધારણાઓ છે; ક્રમ વિકલજનું સ્તર દર્શાવે, ડિગ્રી તે વિકલજનો ઘાત.
  • સમાન ડિગ્રી સંખ્યા (n) = સ્વૈચ્છિક અચળાંકોની સંખ્યા સામાન્ય સમાધાનમાં.
  • સમઘાતીય સમીકરણમાં y=xv મૂકવાથી ચલ-પૃથક્કરણ-સ્વરૂપ મળે છે.
  • રેખીય પ્રથમ-ક્રમ સમીકરણમાં અનુકલન અવયવ (I.F.) = e^(∫P dx) એ સુસંગત રૂપાંતરણ પામેલું છે.
  • યોગ્ય વિકલ સમીકરણ અને સંભાવના ફલન ψ વચ્ચે ∇ψ = (M,N) સંબંધ છે.

🎯 ટ્રિક્સ

પરિણામી સમાધાનમાં y=xv મૂક્યા પછી v+ x dv/dx સ્વરૂપ મળે — આ ભૂલથી યાદ રાખવા માટે: 'વિકલ જોડે ચલ પણ આવે' → આંતરિક ગુણાકાર નિયમનો પ્રતિબિંબ.
I.F. = e^(∫P dx) નો ઘાતાંક ધન હોય તો સમીકરણ 'કમજોર' (stable) અને ઋણ હોય તો 'વિકસિત' (unstable) પ્રવૃત્તિ દર્શાવે.
પરીક્ષામાં M_y − N_x નો અંશ-છેદ અચાનક x અથવા y પર આધારિત મળે તો તરત જ μ(x) અથવા μ(y) માટેનો I.F. સૂત્ર લાગુ પાડો.
સમઘાતીય બહુપદી M, N માટે ઘાત n સમાન હોય તો y=xv ચલ-પરિવર્તન હંમેશા પૃથક્કરણ તરફ દોરી જાય છે.

⚠️ ભૂલો

I.F. ની ગણતરી કરતા ∫P dx માં dv = P dx લઈ ડેરીવેટિવ ભૂલથી છોડવા.
y = vx મૂકીને dx/dx = 1 એ ધારણા કરી વિકલન ભૂલથી ગણવું.
dy/dx = (ax+by+c)/(a'x+b'y+c') માં h,k શોધતી વખતે સમાન દ્વિરેખીય સમીકરણ લખવાને બદલે ભૂલથી અસમાન રાખવા.
બીજા ક્રમનું સમીકરણ ઊંચા ક્રમ ગણી ભૂલ પકડવી.
સમાધાનમાં C સ્વૈચ્છિક અચળાંક ભૂલી જવો અથવા બે અચળાંકો યોગ્ય સ્થળે મૂકવામાં ખોટો પ્રયાસ.
રેખીય સ્વરૂપની પચાવતી વખતે P ની ચિન્હભૂલ (ઘટાડો vs વધારો).
