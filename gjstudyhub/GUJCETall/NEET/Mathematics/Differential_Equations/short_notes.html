વિકલ સમીકરણો — ઝડપી સમીક્ષા નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Differential Equations

📘 વ્યાખ્યાઓ

  • વિકલ સમીકરણ (Differential Equation): સ્વતંત્ર ચલ, આધિન ચલ અને તેમના વિકલજો ધરાવતું ગાણિતિક સમીકરણ
  • માપદંડ (Order): વિકલ સમીકરણમાં ઉપસ્થિત ઉચ્ચતમ ક્રમનો વિકલજ
  • ડિગ્રી (Degree): માપદંડ પ્રાપ્ત કર્યા પછી ઉચ્ચતમ વિકલજની ઘાત (પૂર્ણાંક હોવી જોઈએ)
  • રેખીય વિકલ સમીકરણ (Linear DE): પ્રથમ માપદંડનું સમીકરણ જે y અને dy/dx માં પ્રથમ ડિગ્રીનું હોય
  • ચલ-પૃથક્કરણીય સમીકરણ (Separable DE): f(x)dx = g(y)dy સ્વરૂપમાં લખી શકાય તેવું સમીકરણ
  • સમઘાત વિકલ સમીકરણ (Homogeneous DE): M(x,y)dx + N(x,y)dy = 0 જ્યાં M અને N સમાન ઘાતના સમઘાતીય ફલન છે
  • સામાન્ય ઉકેલ (General Solution): મુક્ત અચળાંકો ધરાવતો ઉકેલ, જેના અચળાંકોની સંખ્યા માપદંડ બરાબર હોય
  • વિશિષ્ટ ઉકેલ (Particular Solution): સામાન્ય ઉકેલમાં મુક્ત અચળાંકની નિશ્ચિત કિંમત મૂકીને મળતો ઉકેલ
  • સંકલન અચળાંક (Constant of Integration): સંકલન દરમિયાન ઉત્પન્ન થતો મુક્ત અચળ P
  • પ્રારંભિક શરત (Initial Condition): ઉકેલમાં મુક્ત અચળાંક નક્કી કરવા માટે આપેલ (x₀,y₀) જોડ

⚡ સૂત્રો

  • સમીકરણ સ્વરૂપ: dⁿy/dxⁿ + a₁·dⁿ⁻¹y/dxⁿ⁻¹ + ... + aₙy = Q(x,y)
  • રેખીય સમીકરણ (પ્રથમ ક્રમ): dy/dx + P(x)y = Q(x)
  • ચલ-પૃથક્કરણ: ∫f(x)dx = ∫g(y)dy
  • સમઘાત પદ્ધતિ: y = vx સંકલ્પ કરતાં dy/dx = v + x·dv/dx
  • સંકલન અવયવ (I.F.): e^(∫P dx)
  • રેખીય સમીકરણનો ઉકેલ: y·(I.F.) = ∫Q·(I.F.)dx + C
  • પરિવારના વક્રોનું વિકલ સમીકરણ: મુક્ત અચળાંકની સંખ્યા n = ઉકેલમાં અચળાંકોની સંખ્યા
  • n-ક્રમના સમીકરણમાં n મુક્ત અચળાંકો; n=1 માટે 1 અચળાંક P
  • dy/dx = f(x,y)/g(x,y) → જો f,g સમાન ઘાતના સમઘાતીય હોય તો સમઘાત

⭐ મુખ્ય તથ્યો

  • માપદંડ ≤ 1 ને રેખીય ધરવી જોઈએ; માપદંડ ≥ 2 ને સಾಮાન્ય રીતે રેખીય કહેવાતું નથી
  • ડિગ્રી હંમેશા પૂર્ણાંક હોવી જોઈએ; sin(dy/dx) વડું સમીકરણ વાસ્તવિક ડિગ્રી દર્શાવતું નથી
  • સમીકરણની ડિગ્રી મેળવવા માટે યોગ્ય રીતે વિકલજોના અપૂર્ણાંક/વર્ગમૂળ દૂર કરવા પડે
  • ચલ-પૃથક્કરણ પદ્ધતિમાં ઘાતાંકીય, બહુપદી, ત્રિકોણમિતિય સંકલનો સામાન્ય રીતે આવે છે
  • સમઘાત પદ્ધતિમાં y/vx સંકલપ બાદ પૃથક્કરણ શક્ય બને છે
  • dy/dx = -M/N સ્વરૂપમાં M dx + N dy = 0 લખી શકાય; N ≠ 0 હોવું જરૂરી
  • સમાન દર સમીકરણ (Equation of same slope): dy/dx = dy₁/dx₁ → ઉકેલ વક્ર પરસ્પર સમાંતર હોય
  • વક્રોના પરિવારનું વિકલ સમીકરણ શોધવા અચળાંક દૂર કરવા માટે સમીકરણને વિકલિત કરવું
  • ઉકેલમાં અચળાંકોની સંખ્યા = માપદંડ (order)
  • સમીકરણોનો ઉકેલ તપાસવો: dy/dx ની કિંમત મૂળ સમીકરણમાં મૂકી તપાસો

⚠️ સામાન્ય ભૂલો

  • dy/dx ને dy÷dx તરીકે ભંગાવી સંકલન કરવું — ખોટું; v=dv/dx સંકલ્પમાં સાવધ રહેવું
  • સંકલન અવયવ lnav નો ઉપયોગ કરતી વખતે +C ભૂલી જવું
  • સમઘાત સમીકરણમાં M,N ની ઘાત સમાન ન હોય તો પણ y=vx સંકલપ કરી દેવું
  • I.F. = e^(∫P dx) માં ∫P dx સંકલન બાદ +C મૂકવો ન જોઈએ (વાપસી ઉકેલમાં દૂર થઈ જાય છે)
  • ડિગ્રી શોધતી વખતે sqrt(dy/dx) = cos x જેવા સમીકરણમાં ડિગ્રી 1 કહેવા બેસવું — પહેલાં સમીકરણને રેખીય બનાવવું જોઈએ
  • ચલ-પૃથક્કરણમાં x = 0 કે y = 0 માટેની ઉકેલશૂન્ય શાખાઓ ભૂલી જવી
  • dy/dx = F(y/x) એ સમઘાત છે, પણ dy/dx = F(y+x) / F(y-x) નહીં
  • સમીકરણને y' + Py = Q રૂપમાં ન લખી શકાય તેવું સમીકરણ રેખીય ધરી લેવું
  • ઉકેલ સમીકરણમાં P = ln|y|+C મૂકીને |y| ની ચિહ્નને ભૂલી જવું
  • સમીકરણમાં dx/dy આપેલું હોય તો x ને આધિન અને y ને સ્વતંત્ર ધરી લેવું

🔥 હાઈ-યીલ્ડ મુદ્દા

  • પ્રથમ ક્રમ-પ્રથમ ડિગ્રી રેખીય સમીકરણ dy/dx + Py = Q ઉકેલનું સૂત્ર ગણતરીમાં ઘણા વાર આવે છે
  • ચલ-પૃથક્કરણીય સમીકરણોમાં ઘાતાંકીય + બહુપદી + ત્રિકોણમિતિય મિશ્ર સંકલન — ધ્યાન રાખવું
  • સમઘાત સમીકરણોમાં y=vx સંકલપ → (v+xv')dx+... સરળતાથી પૃથક્કરણીય બને છે
  • વક્રોના પરિવારનું વિકલ સમીકરણ: ઉદા. વર્તુળ x²+y²=r² → x+yy'=0
  • અચળાંક દૂર કરવાની પદ્ધતિ: n અચળાંક હોય તો n-1 વાર વિકલિત કરવા
  • dy/dx = f(x,y) સ્વરૂપે લખી શકાય તેવું બધું જ પ્રથમ ક્રમનું સમીકરણ ચલ-પૃથક્કરણીય બની શકે તેવું નથી
  • મુક્ત અચળાંક P માટે વિશિષ્ટ ઉકેલ મેળવવા સૌથી પ્રથમ આપેલ પ્રારંભિક શરતનો ઉપયોગ કરવો
  • સમાન દર સમીકરણનો ઉકેલ: આપેલ સમીકરણના વિકલજનું મૂલ્ય ધ્રુવ બરાબર મૂકીને ઉકેલવો
