વિકલ સમીકરણો — હાથે લખેલી નોંધો

🧪 GUJCET — Gujarati • Mathematics • Differential Equations

ભાગ ૧ — વિકલ સમીકરણનું પરિચય
જ્યારે કોઈ સમીકરણમાં અજ્ઞાત રાશિનું એક અથવા એકથી વધુ વિકલિત સમાવિષ્ટ હોય, ત્યારે તે સમીકરણને 'વિકલ સમીકરણ' કહે છે.
✔ વિકલ સમીકરણ = અજ્ઞાત ફલન + તેના વિકલિતો (એકલ/આંશિક)
ઉદાહરણ : dy/dx = 2x, d²y/dx² + 5(dy/dx) + 6y = 0, ∂z/∂x = x + y
📝 📌 વાસ્તવિક જીવનમાં વિકલ સમીકરણો વડે વૃદ્ધિ-ક્ષય, ગરમીનું પ્રવાહ, વીજ પ્રવાહ વગેરે મોડેલ કરવામાં આવે છે.
ભાગ ૨ — ક્રમ (Order) અને ઘાત (Degree)
વિકલ સમીકરણનો ક્રમ = તેમાં presenza ઊંચાતમ વિકલિતનો ક્રમ.
ક્રમ : દ.ઉ. dy/dx + sin(y'') = 0 → ક્રમ = 2 (ઊંચાતમ વિકલિત y'' છે)
વિકલ સમીકરણની ઘાત = સમીકરણમાંના ઊંચાતમ વિકલિતની ઘાત (જ્યારે સમીકરણ બહુપદી રૂપમાં લખાય).
⚠ ઘાત માત્ર ત્યારે જ વ્યાખ્યાયિત થાય જ્યારે વિકલ સમીકરણ બહુપદી સ્વરૂpe હોય — અચળાંકો, ગુણાંકો, વિકલિતો બધા બહુપદી હોવા જોઈએ.
d²y/dx² + sin(dy/dx) = x → ઘાત વ્યાખ્યાયિત નહિ (sin માં dy/dx છે, બહુપદી નથી)
(d²y/dx²)² + (dy/dx)³ + y = 0 → ક્રમ = 2, ઘાત = 2
બહુપદી ન હોય તેવા વિકલ સમીકરણની ઘાત શોધવી હોય તો સૌ પ્રથમ ત્રિકોણમિતીય/ઘાતાંકીય પદો દૂર કરી બહુપદી રૂપ બનાવવું.
📝 📌 exam tip : સૌથી પહેલા ક્રમ શોધો, પછી ઘાત. ઘાત ન હોય તો સ્પષ્ટ ઉલ્લેખ કરો — 'ઘાત વ્યાખ્યાયિત નથી'.
ભાગ ૩ — રચનાની મુખ્ય વાસ્તવિકતાઓ
n-ક્રમનું વિકલ સમીકરણનો સામાન્ય ઉકેલમાં n સ્વતંત્ર સંયોજક (constants / સંમેલનો) હોય છે.
✔ સામાન્ય ઉકેલ (General Solution) : n અજ્ઞાત સંમેલનો સાથેનું હલ — દ.ઉ. y = Ce^{2x}
અમુક ચોક્કસ સંમેલન મૂલ્યો મુકતા 'વિશેષ ઉકેલ' (Particular Solution) મળે છે.
dy/dx = 2x → y = x² + C (સામાન્ય ઉકેલ, C સ્વૈચ્છિક અચળાંક)
જો y(0) = 3 હોય, તો 3 = 0 + C → C = 3 → y = x² + 3 (વિશેષ ઉકેલ)
📝 📌 પ્રારંભિક શરત (Initial Condition) એકમુલ્ય સાથે C શોધવામાં આવે છે.
ભાગ ૪ — ચલ વિભાજ્ય રૂપ (Variable Separable Form)
જો વિકલ સમીકરણને f(y)·dy = g(x)·dx સ્વરૂpeમાં ફેરવી શકાય, તો તેને 'ચલ વિભાજ્ય' રૂપ કહે છે.
✔ સૌસરળ પદ્ધતિ — બંને બાજુ સંકલન કરો : ∫f(y) dy = ∫g(x) dx + C
dy/dx = xy → (1/y)dy = x dx → ln|y| = x²/2 + C → y = Ae^(x²/2)
dy/dx = cos²y → sec²y dy = dx → tan y = x + C
સામાન્ય પ્રકારો : (i) dy/dx = g(x)h(y), (ii) મુક્ત ચલો અલગ પડે તેવા સમીકરણો.
📝 📌 note : h(y) = 0 વાળા બિંદુઓ (equilibrium solutions) ચકાસવા.
ભાગ ૫ — સમઘાતીય વિકલ સમીકરણ (Homogeneous DE)
F(x,y)/G(x,y) સ્વરૂપનું વિકલ સમીકરણ, જ્યાં F અને G બંને સમાન ઘાતના સમઘાતીય બહુપદીઓ હોય, તેને સમઘાતીય કહે છે.
✔ સંકલન : y = vx મૂકતા dy/dx = v + x(dv/dx) — આ બદલાવ વડે ચલ વિભાજ્ય બનાવવામાં આવે છે.
dy/dx = (x² + y²)/(xy) → y = vx મૂકો → dv/(1+v²) = dx/x → v = tan(ln|x|+C)
y = vx મૂક્યા પછીના પગલાંઓ : (૧) dy/dx = v + x·dv/dx લખો, (૨) સમીકરણ સરળ બનાવો, (૩) ચલ વિભાજ્ય કરો, (૪) સંકલન કરો, (૫) v = y/x મૂકી પાછું લખો.
📝 📌 homog. ફલન : f(tx, ty) = t^n · f(x,y). ઘાત n સમાન હોય તો સમઘાતીય.
ભાગ ૬ — રેખીય વિકલ સમીકરણ (Linear DE) — પ્રથમ ક્રમ
રેખીય વિકલ સમીકરણનું પ્રમાણભૂત રૂપ : dy/dx + P(x)·y = Q(x)
✔ ઇન્ટિગ્રેટિંગ ફેક્ટર (I.F.) = e^(∫P dx) — આ પદ્ધતિ વડે ઉકેલ મળે છે.
ઉકેલ : y · (I.F.) = ∫ Q · (I.F.) dx + C → y · e^(∫P dx) = ∫ Q · e^(∫P dx) dx + C
ઉદા. : dy/dx + (1/x)y = x → I.F. = e^(∫1/x dx) = e^(ln x) = x → y·x = ∫x·x dx = x³/3 + C → y = x²/3 + C/x
જો P અને Q અચળ હોય, તો I.F. = e^(Px) થાય અને ઉકેલ સીધો મળે છે.
📝 📌 P(x), Q(x) માત્ર x-ના ફલન હોવા જોઈએ. dy/dx + Py = Q સ્વરૂપમાં લખો.
ભાગ ૭ — બીજા ક્રમના રેખીય સમઘાતીય વિકલ સમીકરણ
d²y/dx² + P·dy/dx + Q·y = 0 (P, Q અચળ હોય)
✔ આ સમીકરણનો ઉકેલ 'સહાયક સમીકરણ' (Auxiliary Equation) vડે મળે છે : m² + Pm + Q = 0
સહાયક સમીકરણ : m² + Pm + Q = 0 (m ના બે મૂલ્યો α, β મળે)
કાંડી : (i) વાસ્તવિક અને ભિન્ન મૂલ્યો α ≠ β હોય → y = C₁e^(αx) + C₂e^(βx) (ii) વાસ્તવિક અને સમાન મૂલ્યો α = β → y = (C₁ + C₂x)e^(αx) (iii) સંકર (Complex) મૂલ્યો α ± iβ → y = e^(αx)[C₁cos βx + C₂sin βx]
ઉદા.(i) : y'' - 5y' + 6y = 0 → m²-5m+6=0 → m=2,3 → y = C₁e^(2x) + C₂e^(3x)
ઉદા.(iii) : y'' + y = 0 → m²+1=0 → m=±i (α=0, β=1) → y = C₁cos x + C₂sin x
📝 📌 non-homog. વિકલ સમીકરણ માટે particular integral પણ શોધવું પડે છે — P.I. + H.F. = સામાન્ય ઉકેલ.
ભાગ ૮ — સમીકરણો રચવાની પ્રક્રિયા
આપેલ સમીકરણ (વક્ર/પરિવાર) માંથી વિકલ સમીકરણ બનાવવા માટે સંમેલનોની સંખ્યા જેટલી વાર વિકલન કરવું.
✔ પદ્ધતિ : (૧) આપેલ સમીકરણનું x-સંદર્ભે વિકલન કરો, (૨) સંમેલનો દૂર કરો, (૩) વિકલ સમીકરણ મેળવો.
y = Ax + B/A → dy/dx = A → x·y'' + y' = 0 (A, B દૂર થયા)
વક્રના પરિવારનું વિકલ સમીકરણ બનાવતી વખતે પ્રારંભિક સમીકરણમાં n સંમેલનો હોય તો n વાર વિકલન કરતાં સંમેલનો દૂર થાય.
📝 📌 round exam : એક સંમેલન = ૧ વિકલન, બે સંમેલન = ૨ વિકલન.
ભાગ ૯ — વિકલ સમીકરણોના અનુપ્રયોગ
વસ્તુના તાપમાનમાં ફેરફાર : Newton's Law of Cooling dT/dt = -k(T - Tₛ)
ઉકેલ : T(t) = Tₛ + (T₀ - Tₛ)e^(-kt)
વસ્તુની વૃદ્ધિ-ક્ષય : દ.ઉ. રેડિયોએક્ટિવ ક્ષય, વ્યાજની ગણતરી dN/dt = kN
ઉકેલ : N(t) = N₀e^(kt) (k > 0 : વૃદ્ધિ, k < 0 : ક્ષય)
✔ વાસ્તવિક દૃશ્યોમાં વિકલ સમીકરણોનો ઉપયોગ ભૌતિકશાસ્ત્ર, રસાયણશાસ્ત્ર, આર્થિકશાસ્ત્ર, જીવવિજ્ઞાનમાં થાય છે.
જલીય દ્રાવણનું ઘનતામાં ફેરફાર, વિદ્યુત પરિપથ (LC, RL circuits) પણ આ રૂપમાં મળે છે.
