નિશ્ચાયક (Determinants) — મહત્વની બાબતો

🧪 GUJCET — Gujarati • Mathematics • Determinants

⭐ મહત્વના મુદ્દા

નિશ્ચાયક એ સાર્વત્રિક (Square) શ્રેણિકનો જોડાયેલ અદીપ (Scalar) રાશિ છે. ૨×૨ અને ૩×૩ નિશ્ચાયકોની ગણતરીના નિયમો યાદ હોવા જરૂરી છે.
GUJCET માં આધારભૂત પ્રશ્નો તથા આગળના તમામ ગુણધર્મોનો આ પરથી જન્મ થાય છે.
૨×૨ નિશ્ચાયક: |a b; c d| = ad − bc. ડાબી ઊભા કાટઝૂર (Main diagonal) નો ગુણાકાર − જમણી ઊભા કાટઝૂરનો ગુણાકાર.
સીધો પ્રશ્ન આવે છે; ૩×૩ નું વિસ્તરણ કરતી વખતે પણ આ સાંકળીને મદદરૂપ થાય છે.
૩×૩ નિશ્ચાયકનું વિસ્તરણ પ્રথম પંક્તિ (અથવા કોઈ પણ પંક્તિ/સ્તંભ) મુજબ કરવામાં આવે છે. ચિન્હ પેટર્ન + − + / − + − / + − + છે.
ગણતરીમાં ચિન્હ ભૂલ સૌથી સામાન્ય ભૂલ છે; ચિન્હ પેટર્ન સ્પષ્ટ હોવી જરૂરી છે.
એક જ પંક્તિ અથવા સ્તંભની બધી દોરો (Entries) શૂન્ય હોય તો નિશ્ચાયકનું મૂલ્ય શૂન્ય થાય.
શૂન્ય નિશ્ચાયક ઓળખવો ઝડપી ગણતરી અને સિંગ્યુલર શ્રેણિક નક્કી કરવામાં મદદરૂપ થાય છે.
જો નિશ્ચાયકની કોઈ બે પંક્તિઓ અથવા સ્તંભો સમાન (અથવા સમપ્રમાણ) હોય, તો નિશ્ચાયકનું મૂલ્ય શૂન્ય થાય.
આ ગુણધર્મ સીધા પ્રશ્નોમાં કે પગલાંવાર સાબિતીમાં વારંવાર વપરાય છે.
નિશ્ચાયકની કોઈ પણ પંક્તિ/સ્તંભના દરેક દોરોમાં સમાન અચળાંક (Constant) k વડે ગુણતાં, નિશ્ચાયકનું મૂલ્ય k વડે ગુણાય છે. ૩×૩ માટે Δ' = k³Δ.
ગુણાકાર ગુણધર્મની સમજણ વિના પ્રશ્નો ખોટા ઉકેલાય છે; k³ વાળો ભાગ ખાસ ધ્યાનમાં લેવો.
જો નિશ્ચાયકની કોઈ પંક્તિ/સ્તંભના દોરો બીજી પંક્તિ/સ્તંભના દોરોના સમપ્રમાણ (કોઈ અચળાંક વડે ગુણી) હોય, તો નિશ્ચાયક શૂન્ય થાય.
આ 'સંરેખિત' (Proportional rows/columns) નો ગુણધર્મ છે — સિંગ્યુલરિટી ઓળખવા માટે અત્યંત મહત્વપૂર્ણ.
કોઈ પણ પંક્તિ/સ્તંભના દોરોમાં કોઈ અચળાંક વડે બીજી પંક્તિ/સ્તંભના અનુરૂપ દોરો ઉમેરતાં (અથવા બાદ કરતાં) નિશ્ચાયકનું મૂલ્ય અકબંધ રહે છે.
આ ગુણધર્મ વડે વિસ્તરણ સરળ બનાવવામાં આવે છે; ગણતરીના પ્રશ્નોમાં પ્રથમ પગલું.
બે ૩×૩ નિશ્ચાયકોનો ગુણાકાર: |A| · |B| = |AB|. એટલે કે, બે શ્રેણિકોના નિશ્ચાયકોનો ગુણાકાર તેમના ગુણાકાર શ્રેણિકના નિશ્ચાયક બરાબર થાય.
આ ગુણધર્મ સિધ્ધાંત-આધારિત પ્રશ્નોમાં વારંવાર આવે છે; સાબિતી સહિત પઢવો.
વિલયન (Minor) M_ij : i-મી પંક્તિ અને j-મો સ્તંભ દૂર કરતાં મળતો નિશ્ચાયક. સહવિલયન (Cofactor) A_ij = (−1)^(i+j) · M_ij.
સહવિલયન એ_adjunct અને પ્રતિલોમ શ્રેણિકની ગણતરીનું આધારસ્તંભ છે; ચિન્હ +/− શૈલી સ્પષ્ટ હોવી જોઈએ.
k-મી પંક્તિના સહવિલયનો સાથે k-મી પંક્તિના દોરોનો ગુણાકાર + l-મી પંક્તિના સહવિલયનો સાથે k-મી પંક્તિના દોરોનો ગુણાકાર = 0 (જ્યારે k ≠ l).
આ ગુણધર્મ adjunct શ્રેણિક AA* = |A|I સાબિત કરવામાં કેન્દ્રીય ભૂમિકા ભજવે છે; સિદ્ધાંત પ્રશ્નોમાં આવે છે.
શ્રેણિક A નો એડજોઇન્ટ (Adjoint) A* એ સહવિલયનોના આઘૂર્ણ (Transpose) છે: (A*)_{ij} = A_ji.
Adjoint बिना प्रतिलोम શ્રેણિક શક્ય નથી; GUJCET માં સીધો પ્રશ્ન આવે છે.
જો |A| ≠ 0 હોય, તો A નું પ્રતિલોમ શ્રેણિક A^(−1) = (1/|A|) · A*. જો |A| = 0 હોય, તો A પ્રતિલોમરાહિત (Singular) છે.
Inverse શોધવો એ અત્યંત મહત્વપૂર્ણ કૌશલ્ય છે; singular/non-singular ની વ્યાખ્યા પણ આ જ પરથી.
સમપૂર્ણ રેખીય સમીકરણ જોડ (System AX = B): જો |A| ≠ 0 હોય, તો ઉકેલ X = A^(−1)B એક અને અદ્વૈત (Unique) છે. જો |A| = 0 અને (adj A)·B ≠ 0 હોય, તો ઉકેલ અસ્તિત્વે નથી.
Consistency/inconsistency ના પ્રશ્નો GUJCET માં નિયમિત આવે છે; ત્રણ પ્રકારના અવસ્થાઓ યાદ હોવી જોઈએ.
જો |A| = 0 અને (adj A)·B = 0 હોય, તો સમીકરણ જોડમાં અનંત ઉકેલો છે. આ અવસ્થામાં પંક્તિઓ સંરેખિત (Proportional) હોય છે.
ત્રણમાંથી ત્રીજી અવસ્થા — many students forget this case; exam માં full marks માટે જરૂરી.
ત્રણ બિંદુઓ (x₁,y₁), (x₂,y₂), (x₃,y₃) સરેખ (Collinear) હોય તે શરત: |x₁ y₁ 1; x₂ y₂ 1; x₃ y₃ 1| = 0.
Collinearity નો આ ગુણધર્મ GUJCET માં સીધો પ્રશ્ન તરીકે આવે છે; બહુ મહત્વનો.
ત્રણ બિંદુઓ શિરોબિંદુ રાખતું ત્રિકોણનું ક્ષેત્રફળ = ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|. આ નિશ્ચાયક સ્વરૂપે પણ લખી શકાય.
ક્ષેત્રફળ શોધવાના પ્રશ્નો ઘણા આવે છે; નિશ્ચાયક રૂપે લખવો એ પद्धति ઝડપી છે.
વૃહત્તમ (Maximum) શક્ય નિશ્ચાયક મૂલ્ય: જો દરેક દોરો ∈ {−1, +1} હોય, તો ૩×૩ નિશ્ચાયકનું મહત્તમ મૂલ્ય ૪ છે.
આ એક સુંદર પરિણામ છે; competitive exams માં આધારભૂત પ્રશ્ન તરીકે આવે છે.
સ્નેલન (Sarrus) નિયમ માત્ર ૩×૩ નિશ્ચાયક માટે: ડાબી ઊભી ત્રણ કાટઝૂરોનો ગુણાકાર + જમણી ઊભી ત્રણ કાટઝૂરોનો ગુણાકાર − (ઉલટા ક્રમમાં ગણાય).
૩×૩ ની ઝડપી ગણતરી માટે Sarrus નિયમ ઉપયોગી છે, પરંતુ ફક્ત ૩×૩ સુધી સીમિત છે.
એકમ શ્રેણિક (Identity) I નો નિશ્ચાયક |I| = 1. વ્યસ્ત શ્રેણિકનો નિશ્ચાયક: |A^(−1)| = 1/|A|.
આ બે સૂત્રો નિશ્ચાયકના ગુણધર્મો પરથી સીધા મળે છે; નાના પ્રશ્નોમાં સીધા વપરાય છે.
શ્રેણિક A નો નિશ્ચાયક |A| = 0 હોય તો A ને 'સિંગ્યુલર' (Singular) અને |A| ≠ 0 હોય તો A ને 'નોન-સિંગ્યુલર' (Non-singular) કહેવાય છે.
સિંગ્યુલર/નોન-સિંગ્યુલર શબ્દાવલી અન્ય તમામ ગુણધર્મો (પ્રતિલોમ, consistency) માટે આધાર છે.
જો A સમમિત્ર (Symmetric) હોય, તો |A| = |A^T|; સામાન્ય રીતે કોઈ પણ વર્ગ શ્રેણિક માટે |A| = |A^T| હોય છે.
Transpose લેતાં નિશ્ચાયક બદલાય નહીં — આ ગુણધર્મ ચિન્હ/પંક્તિ સ્વરૂપ બદલવામાં વાપર્યો.
દ્વિઘાત સમીકરણ ax² + bx + c = 0 ના મૂળો β, γ હોય તો, n-મો ઘાત સુધીનું સૂત્ર નિશ્ચાયક સ્વરૂપે પણ દર્શાવી શકાય છે — પરંતુ GUJCET માં આ મર્યાદિત રીતે વપરાય છે.
આ ઉన్నત સંબંધ છે; મુખ્ય મુદ્દો નિશ્ચાયકની રચના જાળવવી તે છે.
