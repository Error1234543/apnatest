નિશ્ચાયક – ક્વિક રિવિઝન

🧪 GUJCET — Gujarati • Mathematics • Determinants

🧠 યાદ રાખો

નિશ્ચાયક એ સદિશ (matrix) નથી; તે એક સંખ્યા છે. તેની તુલના મેટ્રિક્સ સાથે કરવામાં આવે છે.
દ્વિઘાત મેટ્રિક્સ માટે જ નિશ્ચાયકની વ્યાખ્યા શક્ય બને છે. અદ્વિધાતી મેટ્રિક્સનો નિશ્ચાયક થતો નથી.
મૂળભૂત ગુણધર્મો: હાર (row) કે સ્તંભ (column) અદલાબદલીથી નિશ્ચાયકનું ચિહ્ન બદલાય છે.
જો નિશ્ચાયકમાં કોઈ એક હાર કે સ્તંભના બધા પદ શૂન્ય હોય, તો નિશ્ચાયકનું મૂલ્ય શૂન્ય થાય છે.
જો બે સમાન હારો કે સ્તંભો હોય, તો નિશ્ચાયકનું મૂલ્ય શૂન્ય થાય છે.
અનુરૂપ (adjoint) A⁻¹ = adj(A)/|A| — આ સૂત્ર માત્ર ત્યારે લાગુ પડે જ્યારે |A| ≠ 0 હોય.
AB = BA છે, પણ adj(AB) ≠ adj(A) × adj(B) — ખબર રાખવી!
|kA| = kⁿ|A|, જ્યાં n એ n×n મેટ્રિક્સનો ક્રમ છે.

⚡ ઝડપી સૂત્રો

2×2: |A| = ad - bc, જ્યાં A = [[a,b],[c,d]]
3×3: Sarrus નિયમ અથવા વિસ્તરણ પદ્ધતિથી મૂલ્ય શોધવું
મિનર (Minor): Mᵢⱼ = aᵢⱼ નો ઉપાંત્રીય નિશ્ચાયક
અનુરૂપ અવયવ (Cofactor): Aᵢⱼ = (-1)^(i+j) × Mᵢⱼ
adj(A) = (Aᵢⱼ)ᵀ — અનુરૂપ અવયવોનું સદિશ
A × adj(A) = adj(A) × A = |A| · Iₙ
ઉલ્ટા મેટ્રિક્સ: A⁻¹ = adj(A)/|A| જો |A| ≠ 0
ત્રિકોણના ક્ષેત્રફળ = ½ |x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂)|

✅ વન-લાઈનર્સ

શૂન્ય નિશ્ચાયક → singular matrix; શૂન્યેતર નિશ્ચાયક → non-singular matrix.
Sarrus નિયમ માત્ર 3×3 નિશ્ચાયક માટે જ લાગુ પડે છે.
જો |A| = 0, તો A⁻¹ અસ્તિત્વ ધરાવતો નથી.
સ્તંભ-ક્રિયા દ્વારા નિશ્ચાયકનું મૂલ્ય શૂન્ય બનાવી શકાય છે.
સમોદ્બીધ (homogeneous) સમીકરણો AX = 0 ના અનુનાદી ઉકેલ માટે |A| = 0.
અનૈકરૂપ (non-homogeneous) સમીકરણો AX = B નો ઉકેલ: X = A⁻¹B જો |A| ≠ 0.
ક્રામે નિયમ (Cramer's Rule): x = Dₓ/D, y = Dᵧ/D, જ્યાં D ≠ 0.
બે રેખાઓ છેદક હોય તો ઉકેલ એકલાયત; સમાંતર હોય તો ઉકેલ નહિ.
દિશા અચળ (row/column) સંયોજનથી નિશ્ચાયકનું મૂલ્ય બદલાતું નથી.
