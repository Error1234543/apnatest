⚡ સૂત્રો

2×2 નિશ્ચાયક: |A| = ad - bc જ્યાં A = [[a,b],[c,d]]
a,b,c,d એ 2×2 શ્રેષ્ઠમાનના પદો છે · SI: અપ્રસ્તુત · શ્રેષ્ઠમાન વર્ગાકાર (square matrix) હોય
3×3 નિશ્ચાયક — વિસ્તરણ (પ્રથમ પંક્તિ મુજબ): |A| = a11(a22·a33 - a23·a32) - a12(a21·a33 - a23·a31) + a13(a21·a32 - a22·a31)
a_ij એ i-મી પંક્તિ અને j-મી સ્તંભનો પદ છે · SI: અપ્રસ્તુત · A એ 3×3 વર્ગાકાર શ્રેષ્ઠમાન છે
નિશ્ચાયકની કોઈ પણ પંક્તિ/સ્તંભ મુજબ વિસ્તરણ: |A| = a_r1·C_r1 + a_r2·C_r2 + a_r3·C_r3 (ર-મી પંક્તિ માટે) |A| = a_1c·C_1c + a_2c·C_2c + a_3c·C_3c (c-મો સ્તંભ માટે)
C_ij = (-1)^(i+j)·M_ij (સહગુણક / Cofactor), M_ij = ઉપનિશ્ચાયક (Minor) · SI: અપ્રસ્તુત · વર્ગાકાર શ્રેષ્ઠમાન A
ઉપનિશ્ચાયક (Minor) M_ij: M_ij = તે નિશ્ચાયક જે મળે i-મી પંક્તિ અને j-મો સ્તંભ કાઢી નાખતાં
M_ij એ a_ij નો ઉપનિશ્ચાયક છે · SI: અપ્રસ્તુત · i ≠ j અથવા i = j, કોઈ પણ પદ માટે
સહગુણક (Cofactor) C_ij: C_ij = (-1)^(i+j) · M_ij
C_ij = સહગુણક, M_ij = ઉપનિશ્ચાયક · SI: અપ્રસ્તુત · બધા i, j માટે
મ્યુલ્ટિપ્લિકેટિંગ પ્રોડક્ટ પ્રમેય (સંબંધ 1): a_i1·C_j1 + a_i2·C_j2 + a_i3·C_j3 = |A| જો i = j |A| = 0 જો i ≠ j
a_ij = મૂળ શ્રેષ્ઠમાનનો પદ, C_ij = સહગુણક · SI: અપ્રસ્તુત · k_ij પ્રમેય (Key Identity)
મ્યુલ્ટિપ્લિકેટિંગ પ્રોડક્ટ પ્રમેય (સ્તંભ સ્વરૂપ): a_1j·C_1i + a_2j·C_2i + a_3j·C_3i = |A| જો i = j |A| = 0 જો i ≠ j
a_ij = મૂળ શ્રેષ્ઠમાનનો પદ, C_ij = સહગુણક · SI: અપ્રસ્તુત · સ્તંભ-આધારિત વિસ્તરણ
અડ્જોઇન્ટ શ્રેષ્ઠમાન (Adjoint Matrix): adj(A) = [C_ij]^T (સહગુણકોનો ટ્રાન્સપોઝ)
adj(A) = અડ્જોઇન્ટ, C_ij = a_ij નો સહગુણક · SI: અપ્રસ્તુત · A એ વર્ગાકાર શ્રેષ્ઠમાન
અડ્જોઇન્ટ અને મૂળ શ્રેષ્ઠમાનનો સંબંધ: A · adj(A) = adj(A) · A = |A| · I_n જ્યાં I_n એ n×n એકમ શ્રેષ્ઠમાન છે
I_n = એકમ શ્રેષ્ઠમાન (Identity matrix), |A| = નિશ્ચાયક · SI: અપ્રસ્તુત · A એ n×n વર્ગાકાર શ્રેષ્ઠમાન
ઉલટાણ શ્રેષ્ઠમાન (Inverse Matrix): A^(-1) = (1/|A|) · adj(A) જો |A| ≠ 0
A^(-1) = વ્યસ્ત શ્રેષ્ઠમાન, adj(A) = અડ્જોઇન્ટ, |A| ≠ 0 · SI: અપ્રસ્તુત · A એ અવૈધ (non-singular) વર્ગાકાર શ્રેષ્ઠમાન
નિશ્ચાયકનો ગુણધર્મ 1 — ટ્રાન્સપોઝ: |A^T| = |A| અથવા |adj(A)| = |A|^n (n×n શ્રેષ્ઠમાન માટે)
A^T = ટ્રાન્સપોઝ, adj(A) = અડ્જોઇન્ટ, n = ક્રમ · SI: અપ્રસ્તુત · A વર્ગાકાર શ્રેષ્ઠમાન હોય
નિશ્ચાયકનો ગુણધર્મ 2 — પંક્તિ/સ્તંભનો ગુણાકાર: |kA| = k^n · |A| (n×n શ્રેષ્ઠમાન માટે)
k = અચળાંક, n = શ્રેષ્ઠમાનનો ક્રમ, |A| = નિશ્ચાયક · SI: અપ્રસ્તુત · A એ n×n વર્ગાકાર શ્રેષ્ઠમાન
નિશ્ચાયકનો ગુણધર્મ 3 — ગુણાકાર પ્રમેય: |AB| = |A| · |B|
A, B એ સમાન ક્રમના વર્ગાકાર શ્રેષ્ઠમાન · SI: અપ્રસ્તુત · A અને B એ n×n વર્ગાકાર શ્રેષ્ઠમાન
નિશ્ચાયકનો ગુણધર્મ 4 — એક સંયોજિત પંક્તિ/સ્તંભ: જો R_i → R_i + k·R_j (અથવા C_i → C_i + k·C_j) તો |A'| = |A|
R_i, R_j = પંક્તિઓ; C_i, C_j = સ્તંભો; k = અચળાંક · SI: અપ્રસ્તુત · એક જ શ્રેષ્ઠમાનમાં પંક્તિ/સ્તંભ પર સંયોજન
નિશ્ચાયકનો ગુણધર્મ 5 — બે સમાન પંક્તિ/સ્તંભ: જો બે પંક્તિઓ અથવા બે સ્તંભો સમાન હોય, તો |A| = 0
A માં R_i = R_j અથવા C_i = C_j · SI: અપ્રસ્તુત · ઓછામાં ઓછા બે પંક્તિઓ/સ્તંભો સમાન હોય
નિશ્ચાયકનો ગુણધર્મ 6 — શૂન્ય પંક્તિ/સ્તંભ: જો કોઈ પંક્તિ અથવા સ્તંભના બધા પદો શૂન્ય હોય, તો |A| = 0
A માં કોઈ R_i = 0 અથવા C_j = 0 · SI: અપ્રસ્તુત · કોઈ પણ એક પંક્તિ/સ્તંભના બધા પદો શૂન્ય
નિશ્ચાયકનો ગુણધર્મ 7 — પ્રમાણબદ્ધ પંક્તિ/સ્તંભ: જો R_i = k·R_j (અથવા C_i = k·C_j) તો |A| = 0
k = અચળાંક, R_i, R_j = પંક્તિઓ; C_i, C_j = સ્તંભો · SI: અપ્રસ્તુત · બે પંક્તિઓ/સ્તંભો પરસ્પર પ્રમાણબદ્ધ હોય
નિશ્ચાયકનો ગુણધર્મ 8 — પંક્તિ/સ્તંભનો ગુણાકાર: જો R_i → k·R_i (અથવા C_i → k·C_i) તો નવો નિશ્ચાયક = k·|A|
k = અચળાંક, R_i/Pંક્તિ, C_i/સ્તંભ · SI: અપ્રસ્તુત · એક જ પંક્તિ/સ્તંભને k વડે ગુણતાં
નિશ્ચાયકનો ગુણધર્મ 9 — સરવાળા સ્વરૂપ: જો i-મી પંક્તિના દરેક પદ બે પદોનો સરવાળો હોય, તો |A| = |A_1| + |A_2|
a_ij = α_ij + β_ij, તો A = A_1 + A_2 સ્વરૂપે વિભાજિત શકાય · SI: અપ્રસ્તુત · ફક્ત એક જ પંક્તિ/સ્તંભનો સરવાળો
નિશ્ચાયકનો ગુણધર્મ 10 — શ્રેષ્ઠમાન ગુણાકાર: જો B = A·C, તો |B| = |A| · |C|
A, C = સમાન ક્રમના વર્ગાકાર શ્રેષ્ઠમાન · SI: અપ્રસ્તુત · શ્રેષ્ઠમાન ગુણાકાર અર્થપૂર્ણ હોય
ત્રિકોણનું ક્ષેત્રફળ નિશ્ચાયક વડે: क्षेत्रफल = (1/2) · | x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2) | અથવા | x1 y1 1 | | x2 y2 1 | = 0 | x3 y3 1 |
(x1,y1),(x2,y2),(x3,y3) = શીરોબિંદુઓ,क्षेत्रफल = square units · SI: વર્ગ એકમ (sq. units) · ત્રણ બિંદુઓ અભિલંબ (collinear) ન હોય તો ক্ষেত্রফळ > 0; collinear હોય તો = 0
બંધ સંહિતા (System of Equations) — અવકાશ (Consistency): AX = B માટે: |A| ≠ 0 → એક માત્ર ઉકેલ (unique solution) |A| = 0, adj(A)·B ≠ 0 → ઉકેલ નહિ̱ (no solution) |A| = 0, adj(A)·B = 0 → અનંત ઉકેલ (infinite solutions)
A = गुणाંક શ્રેષ્ઠમાન, X = ચલ શ્રેષ્ઠમાન, B = અચળાંક શ્રેષ્ઠમાન · SI: અપ્રસ્તુત · n સંખ્યામાં n રેખીય સમીકરણો
ક્રેમારના નિયમ મુજબ ઉકેલ: x = Dx/D , y = Dy/D , z = Dz/D જ્યાં D = |A|, Dx = D બદલ B, Dy = D બદલ B, Dz = D બદલ B
D = મૂળ શ્રેષ્ઠમાન, Dx = x-સ્તંભ B વડે બદલેલ, Dy, Dz = તેમ · SI: અપ્રસ્તુત · D ≠ 0 (એક માત્ર ઉકેલ)
શૂન્ય-રેખીય સમીકરણો માટે સુસંગતતા: AX = 0 માટે: |A| ≠ 0 → શૂન્ય ઉકેલ (trivial: x=y=z=0) |A| = 0 → અશૂન્ય ઉકેલ (non-trivial solutions અનંત)
X = (x,y,z)^T, A = गुणाંક શ્રેષ્ઠમાન · SI: અપ્રસ્તુત · શૂન્ય-રેખીય સમીકરણ પ્રણાલી
નિશ્ચાયકનો ગુણધર્મ — પંક્તિ વિનિમય: જો R_i ↔ R_j બદલાવો તો નિશ્ચાયકનું ચિહ્ન બદલાય: |A'| = -|A|
R_i, R_j = કોઈ પણ બે પંક્તિઓ · SI: અપ્રસ્તુત · બે પંક્તિઓની અદલાબદલી
વિખંડન પ્રમેય — પંક્તિ પ્રક્રિયા દ્વારા સાદુંરૂપ: પંક્તિ સંયોજન R_i → R_i + k·R_j + m·R_k વડે શૂન્ય પદો મેળવી નિશ્ચાયકની ગણતરી સરળ બનાવી શકાય, તેથી |A| = (કંઈક પંક્તિ) × (કંઈક પંક્તિ)...
પંક્તિ પ્રક્રિયાઓ વડે નિશ્ચાયકનું મૂલ્ય બદલાતું નથી (ગુણાકાર/વિનિમય સિવાય) · SI: અપ્રસ્તુत · ગુણાત્મક પરીક્ષણ (row reduction method)

🔗 સંબંધો

  • A · adj(A) = adj(A) · A = |A| · I → આ સંબંધ પરથી A^(-1) = adj(A)/|A| મળે છે.
  • |adj(A)| = |A|^(n-1) → n×n શ્રેષ્ઠમાન માટે અડ્જોઇન્ટનો નિશ્ચાયક મૂળ નિશ્ચાયકની (n-1)-ઘાત બરાબર.
  • |A^(-1)| = 1/|A| → વ્યસ્ત શ્રેષ્ઠમાનનો નિશ્ચાયક મૂળના વ્યસ્ત બરાબર.
  • (adj(A))^T = adj(A^T) → અડ્જોઇન્ટનું ટ્રાન્સપોઝ, શ્રેષ્ઠમાનના ટ્રાન્સપોઝના અડ્જોઇન્ટ બરાબર.
  • k·adj(A) = adj(k·A) જ્યારે n = 2; n ≠ 2 માટે આ સાચું નથી.
  • |A| ≠ 0 હોય તો શ્રેષ્ઠમાન અવૈધ (non-singular); |A| = 0 હોય તો સિંગ્યુલર (singular).
  • જો AB = AC અને |A| ≠ 0, તો B = C → અવૈધ શ્રેષ્ઠમાન માટે રદ્દીકરણ શક્ય છે.
  • D ≠ 0 હોય તો રેખીય સમીકરણ પ્રણાલી AX = B નો એક માત્ર ઉકેલ; D = 0 અને adj(A)·B ≠ 0 હોય તો ઉકેલ નહિ̱; D = 0 અને adj(A)·B = 0 હોય તો અનંત ઉકેલ.

🎯 ટ્રિક્સ

3×3 નિશ્ચાયક Sarrus નિયમ: પ્રથમ બે પંક્તિઓ નીચે ફરીથી લખો; વિಕર્ણોનો સરવાળો - ડાબા-ઉજ્જડ વિકર્ણોનો ગુણાકાર = નિશ્ચાયક.
જો નિશ્ચાયકમાં કોઈ પંક્તિ/સ્તંભના બધા પદો સમાન અચળાંકના ગુણક હોય, તો તે અચળાંક બહાર કાઢો: |k·A| = k^n·|A|.
પંક્તિ સંયોજન દ્વારા શૂન્ય પદો મેળવ્યા બાદ, એક જ પંક્તિ/સ્તંભ મુજબ વિસ્તરણ કરો — ગણતરી 70% સરળ બને છે.
જો સમીકરણ પ્રણાલીમાં t દ્વારા પરિમાણીય ઉકેલ જોઈતો હોય, તો |A| = 0 મૂકી t ની કિંમત શોધો (અનંત ઉકેલ માટે).
ત્રિકોણના क्षेત્રફળ શૂન્ય હોય, તે બિંદુઓ અભિલંબ (collinear) છે — આ ચકાસણી ઝડપી છે.
સંમિત (symmetric) નિશ્ચાયકમાં P → Q સ્થાન બદલવું ચિહ્ન બદલે છે, પણ પદો સમાન રહે છે.
જો ત્રણેય પંક્તિઓ/સ્તંભો પરસ્પર સમપ્રમાણ (proportional) હોય, તો નિશ્ચાયક શૂન્ય છે — તરત જ જવાબ મળી જાય છે.

⚠️ ભૂલો

|A + B| = |A| + |B| માની લેવું — આ સામાન્યત: ખોટું છે; નિશ્ચાયક રೇખીય (linear) નથી.
A^(-1) = adj(A)/|A| માં |A| = 0 હોય તો પણ વ્યસ્ત શ્રેષ્ઠમાન મેળવવાની હિંમત કરવી — અવૈધ શ્રેષ્ઠમાનનું વ્યસ્ત અસ્તિત્વ ધરાવતું નથી.
k×k શ્રેષ્ઠમાન માટે |kA| = k|A| માની લેવું — સાચું સૂત્ર |kA| = k^k·|A|. દા.ત., 3×3 માટે |3A| = 27|A|.
nિશ્ચાયકના વિસ્તરણમાં સહગુણકના ચિહ્નો (+/-) ભૂલથી ઉપયોગ કરવા — ચેસબોર્ડ પેટર્ન (+ - + / - + - / + - +) યાદ રાખો.
સંહિતા AX = B માં D = 0 અને adj(A)·B = 0 હોય તો ઉકેલ 'નહિ̱' માની લેવો — ખરેખર અનંત ઉકેલ હોઈ શકે છે.
શૂન્ય-રેખીય પ્રણાલી AX = 0 માટે D = 0 હોય ત્યારે 'શૂન્ય ઉકેલ' જવાબ આપવો — D = 0 હોય તો અશૂન્ય ઉકેલ (non-trivial) મળે છે.
નિશ્ચાયકમાં P → Q પંક્તિ અદલાબદલી કરીને ચિહ્ન ન બદલવું — દરેક અદલાબદલી ચિહ્ન બદલે છે (-1).
અડ્જોઇન્ટ શ્રેષ્ઠમાન બનાવતી વખતે સહગુણકોની અદલાબદલી ભૂલવી — adj(A) માં C_ij એ a_ij ની જગ્યાએ જવું જોઈએ, ટ્રાન્સપોઝ ભૂલવું.
ત્રિકોણના क्षेત્રफળમાં 1/2 નો ગુણક ભૂલી જવો — सूत्रમાં 1/2 આવશ્યક છે.
નિશ્ચાયકના ગુણધર્મોનો ઉપયોગ કરતી વખતે પંક્તિ/સ્તંભ શૂન્ય કર્યા બાદ વિસ્તરણ કર્યા વિના જ મૂળ નિશ્ચાયક લખી દેવો.
