GUJCET — આંકડાશાસ્ત્ર (Statistics): પરીક્ષા ટ્રિક્સ અને ટૂંકા રસ્તા

🧪 GUJCET — Gujarati • Mathematics • Statistics

🎯 પરીક્ષા ટ્રિક્સ

પ્રથમ n પ્રાકૃતિક સંખ્યાઓનું મધ્યક = (n + 1)/2
જ્યારે પ્રશ્નમાં કહેવાય કે '1 થી n સુધીની પ્રાકૃતિક સંખ્યાઓના ગણ', ત્યારે સરવાળો કરવાના બદલે સીધું સૂત્ર લાગુ પાડો.
દા.ત.: 1 થી 10 સુધીની સંખ્યાઓનું મધ્યક = (10 + 1)/2 = 5.5. આગલા વિકલ્પોમાં 5 અથવા 5.5 હોય તો તરત જ 5.5 પસંદ કરો.
સમાન અંતરે આવેલી સંખ્યાઓનો મધ્યક = મધ્યમ પદ (સમપ્રમાણ ગણ)
જ્યારે આપેલ ડેટા સમાંતર શ્રેઢિ (AP) માં હોય અથવા બધા પદો સમાન અંતરે હોય.
દા.ત.: 2, 5, 8, 11, 14 → આપણે સરવાળો ન કરીએ; મધ્યમ પદ 8 છે. તેથી મધ્યક = 8.
આપેલ મૂલ્યોમાંથી દરેકમાં સમાન સંખ્યા ઉમેરતા — મધ્યક badલાય, પણ પ્રસરણ (dispersion) બદલાતું નથી.
વિકલ્પોમાંથી કઈ રાશિ બદલાશે / નહીં એ પૂછે એવા પ્રશ્ન.
દા.ત.: આપણે દરેક સંખ્યામાં 5 ઉમેરતા, મધ્યક 5 વધશે, પણ સરેરાશ વિચલન, પ્રમાણિત વિચલન, ચરમપ્રાપ્તિ — બધા સમાન રહેશે. તેથી એવા વિકલ્પને 'બદલાશે નહીં' તરીકે પસંદ કરો.
દરેક મૂલ્યને સમાન સંખ્યાથી ગુણતા — મધ્યક ગુણક બરાબર ગુણાશે, પણ પ્રમાણિત વિચલન પણ તે જ ગુણકથી ગુણાય.
જ્યારે પ્રશ્નમાં 'દરેક પદ k વડે ગુણતા' એવું હોય અને SD કે MD માંગતા હોય.
દા.ત.: SD = 3 હતું, દરેક પદ 4 વડે ગુણતા — નવું SD = 3 × 4 = 12. મધ્યક પણ 4 વડે ગુણાશે.
સર્વસમ વિતરણમાં (symmetric distribution): મધ્યક = મધિષ્ઠક = બहुલક
જ્યારે આપેલ વિતરણ સંપૂર્ણ સંમિત હોય (ઉદા. સામાન્ય વિતરણ અથવા સરખી પસંદગીવાળો ફ્રીક્વન્સી ગ્રાફ).
દા.ત.: જો વિતરણ સંમિત હોય અને મધ્યક 50 આપ્યો હોય, તો બહુલક પણ 50 જ હશે — સરવાળો/ગણતરી વગર જ વિકલ્પ પસંદ કરો.
આંકડાકીય રીતે અંદાજિત સંબંધ: મધ્યક − બહુલક ≈ 3(મધ્યક − મધિષ્ઠક)
એક પણ બહુલક / મધિષ્ઠક નહીં આપ્યું હોય, પણ બીજા બે જાણીતા હોય — MCQ માં અંદાજિત મૂલ્ય પસંદ કરવા.
દા.ત.: મધ્યક = 70, મધિષ્ઠક = 65 → મધ્યક − બહુલક ≈ 3(70 − 65) = 15 → બહુલક ≈ 70 − 15 = 55. 55 વિકલ્પ હોય તો તરત પસંદ કરો.
બહુલકનું સૂત્ર (સંદત્ત વિતરણ માટે): બહુલક = L + [ (f₁−f₀)/(2f₁−f₀−f₂) ] × h
જ્યારે વિતરણ આપેલ હોય અને બહુલક શોધવાનો પ્રશ્ન હોય — f₁ = બહુલક પૂર્વ વર્ગની વિશ્લેષણ, f₀ = પછીનું, f₂ = પછીનું, h = વર્ગ અંતરાલ.
દા.ત.: L=20, h=10, f₁=50, f₀=30, f₂=40 → બહુલક = 20 + [(50−30)/(2×50−30−40)]×10 = 20 + (20/30)×10 = 26.67. મેરી જવાબ મળે.
ઓગ્યુ (Ogive) ના ક્ષેત્રફળની જરૂર નથી — નીચલી / વધતી ઓગ્યુ નું છેદનબિંદુ X-અક્ષ પર મધિષ્ઠક આપે છે.
ઓગ્યુ ગ્રાફ આપેલ હોય અને મધિષ્ઠક પૂછતો પ્રશ્ન હોય.
દા.ત.: નીચલા અને વધતા ઓગ્યુનું છેદનબિંદુ X-અક્ષ પર 45 આપે → મધિષ્ઠક = 45. કોઈ ગણતરી નથી.
મધિષ્ઠક વર્ગ શોધવા માટે n/2 < CF પહેલાનો વર્ગ જ મધિષ્ઠક વર્ગ.
સંદત્ત વિતરણમાં મધિષ્ઠક શોધતી વખતે.
દા.ત.: n = 100, n/2 = 50. જે વર્ગનો સંચयी આવૃત્તિ પહેલીવાર 50 થી વધારે થાય, તે વર્ગ મધિષ્ઠક વર્ગ. સૂત્રમાં લ Ag = તેનો નીચલો સીમાંક, CF = તેના પહેલા વર્ગનો સંચयी આવૃત્તિ.
બહુલક, મધિષ્ઠક, મધ્યકનું ક્રમ: સકારાત્મક વિકર્ણતા (+skewed) માં — મધ્યક > મધિષ્ઠક > બહુલક; ઋણ વિકર્ણતા માં — બહુલક > મધિષ્ઠક > મધ્યક.
ક્રમ પૂછતો પ્રશ્ન હોય અથવા વિતરણનું પ્રકાર નક્કી કરવો હોય.
દા.ત.: મધ્યક = 60, મધિષ્ઠક = 55, બહુલક = 50 → 60 > 55 > 50 = સકારાત્મક વિકર્ણતા. તેથી જવાબ: મધ્યક > મધિષ્ઠક > બહુલક.
પ્રમાણિત વિચલન (SD) ≥ શ્રેણિક વિચલન (MD) ≈ (4/5) × SD (સામાન્ય વિતરણ માટે).
MCQ માં MD અને SD ના સંબંધ પર આધારિત પ્રશ્ન, અથવા વિકલ્પોમાં ગેરવાજબી કિંમતો હોય ત્યારે અપવર્જન કરવા.
દા.ત.: જો SD = 10 હોય, તો MD ~ 8 (4/5 × 10). જો વિકલ્પમાં MD = 12 હોય તો તે અશક્ય છે — તરત અપવર્જન કરો.
ચરમપ્રાપ્તિ (Range) = મહત્તમ − લઘુત્તમ; ચરમપ્રાપ્તિ ગુણાંક = (મહત્તમ − લઘુત્તમ)/(મહત્તમ + લઘુત્તમ)
ચરમપ્રાપ્તિ ગુણાંક પૂછેલ હોય — મહત્તમ/લઘુત્તમ ને જોડી સાધારણ કરો.
દા.ત.: મહત્તમ = 80, લઘુત્તમ = 20 → ચરમપ્રાપ્તિ = 60, ગુણાંક = 60/100 = 0.6.
વૈવિધ્ય ગુણાંક (Coefficient of Variation) = (SD / મધ્યક) × 100 — એકમરહિત, બે જૂથોની તુલના કરવા.
બે વિતરણોમાં કયું વધુ સ્થિર/અસ્થિર છે એ પૂછેલ હોય.
દા.ત.: A નું CV = 15%, B નું CV = 20% → B વધુ વિખેરાયેલું (વધુ અસ્થિર). નીચું CV = વધુ સ્થિરતા.
પદ્ધતિ પસંદગી: 'પદવિચલન' (Step-deviation) પદ્ધતિ ત્યારે વાપરો જ્યારે X ની કિંમતો મોટા પદાંકની હોય અથવા સમાન અંતરે હોય — ગણતરી સરળ બને.
સંદત્ત વિતરણના SD મેળવવા માટે X_values = 50, 60, 70, 80, 90 જેવી મોટી સંખ્યા હોય.
દા.ત.: a = 70, h = 10. u = (X − 70)/10. હવે u ની કિંમતો: −2, −1, 0, 1, 2. SD = h × √[Σfu²/N − (Σfu/N)²]. સરળ ગણતરી.
જો ડેટામાં દરેક સમાન મૂલ્ય હોય, તો SD = 0 અને CV ની વ્યાખ્યા મુજબ CV = 0.
વિકલ્પોમાં 0 હોય અને પ્રશ્નમાં 'સમાન કિંમતો' અથવા 'કોઈ વિચલન નથી' એવું સૂચન હોય.
દા.ત.: ડેટા: 5, 5, 5, 5, 5 → SD = 0. તરત જ જવાબ 0.
