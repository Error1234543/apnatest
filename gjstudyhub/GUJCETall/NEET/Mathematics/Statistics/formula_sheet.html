આંકડાશાસ્ત્ર — સૂત્ર પત્રિકા (Statistics — Formula Sheet)

🧪 GUJCET — Gujarati • Mathematics • Statistics

⚡ સૂત્રો

અવર્ગીકૃત ડેટાનો મધ્યક (Mean of Ungrouped Data): x̄ = Σxᵢ / n
x̄ = મધ્યક, xᵢ = i-મું મૂલ્ય, n = મૂલ્યોની સંખ્યા · SI: ડેટાનું એકમ (unit of data) · જ્યારે ડેટા અવર્ગીકૃત (અવશિષ્ટ સ્વરૂપમાં) હોય
વર્ગીકૃત ડેટાનો મધ્યક — સીધી પદ્ધતિ (Direct Method): x̄ = Σ(fᵢ · xᵢ) / Σfᵢ
fᵢ = i-મા વર્ગની આવૃત્તિ, xᵢ = i-મા વર્ગનું મધ્યબિંદુ (midpoint) · SI: ડેટાનું એકમ · વર્ગીકૃત વિતરણ માટે, જ્યારે xᵢ ના મૂલ્યો Chota (નાના) હોય
વર્ગીકૃત ડેટાનો મધ્યક — અંદાજિત મધ્યક પદ્ધતિ (Assumed Mean Method): x̄ = a + Σ(fᵢ · dᵢ) / Σfᵢ, જ્યાં dᵢ = xᵢ − a
a = અંદાજિત મધ્યક (assumed mean), dᵢ = xᵢ માંથી a નું વિચલન, xᵢ = મધ્યબિંદુ, fᵢ = આવૃત્તિ · SI: ડેટાનું એકમ · જ્યારે xᵢ ના મૂલ્યો મોટા હોય — ગણતરી સરળ બને તે માટે
વર્ગીકૃત ડેટાનો મધ્યક — સ્ટેપ ડિવિએશન પદ્ધતિ (Step-deviation Method): x̄ = a + [Σ(fᵢ · uᵢ) / Σfᵢ] × h, જ્યાં uᵢ = (xᵢ − a)/h
a = અંદાજિત મધ્યક, h = વર્ગ અંતરાલ (class width), uᵢ = અનુપાતિક વિચલન · SI: ડેટાનું એકમ · જ્યારે બધા xᵢ સમાન અંતરાલ h માં વિભાજ્ય હોય અને મૂલ્યો મોટા હોય
વર્ગનું મધ્યબિંદુ (Midpoint of a Class): xᵢ = (ઉપરલી સીમા + નીચલી સીમા) / 2
xᵢ = મધ્યબિંદુ, ઉપરલી/નીચલી સીમા = વર્ગની સીમાઓ · SI: ડેટાનું એકમ · દરેક વર્ગ માટે, મધ્યકની ગણતરી કરતી વખતે
અવર્ગીકૃત ડેટાનો મધ્યસ્થ (Median of Ungrouped Data): જો n અજોડ હોય: M = (n+1)/2 -મું મૂલ્ય; જો n સમ હોય: M = [(n/2)-મું મૂલ્ય + (n/2 + 1)-મું મૂલ્ય] / 2
M = મધ્યસ્થ, n = નિરીક્ષણોની કુલ સંખ્યા · SI: ડેટાનું એકમ · ડેટા ક્રમબદ્ધ (ordered) હોવો જોઈએ
વર્ગીકૃત ડેટાનો મધ્યસ્થ (Median of Grouped Data): M = l + [(N/2 − C_f) / f] × h
l = મધ્યસ્થ વર્ગની નીચલી સીમા, N = કુલ આવૃત્તિ (Σfᵢ), C_f = મધ્યસ્થ વર્ગ પહેલાંના વર્ગની સंचयी આવૃત્તિ (cumulative frequency), f = મધ્યસ્થ વર્ગની આવૃત્તિ, h = વર્ગ અંતરાલ · SI: ડેટાનું એકમ · વર્ગીકૃત વિતરણ, N/2 એ M.F. (મધ્યસ્થ વર્ગ) માં પડતું હોય
અવર્ગીકૃત ડેટાનો બહુલક (Mode of Ungrouped Data): એવું મૂલ્ય jો બાકીના તમામ મૂલ્યોમાં સૌથી વધુ વાર આવતું હોય
બહુલક = સૌથી વધુ આવૃત્તિ ધરાવતું મૂલ્ય · SI: ડેટાનું એકમ · ડેટા અવર્ગીકૃત હોય; એક કરતાં વધુ બહુલક (bimodal/multimodal) પણ શક્ય છે
વર્ગીકૃત ડેટાનો બહુલક (Mode of Grouped Data): Z = l + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h
l = બહુલક વર્ગની નીચલી સીમા, f₁ = બહુલક વર્ગની આવૃત્તિ, f₀ = બહુલક વર્ગ પહેલાંના વર્ગની આવૃત્તિ, f₂ = બહુલક વર્ગ બાદના વર્ગની આવૃત્તિ, h = વર્ગ અંતરાલ · SI: ડેટાનું એકમ · બહુલક વર્ગ એટલે સૌથી વધુ આવૃત્તિ વાળો વર્ગ
અવર્ગીકૃત ડેટાનું વિચલન ચતુષ્ક (Range of Ungrouped Data): R = માંડ (maximum) − લઘુત્તમ (minimum)
R = વિચલન ચતુષ્ક (range) · SI: ડેટાનું એકમ · વિસ્તરણનું સૌથી સરળ માપ
વર્ગીકૃત ડેટાનું વિચલન ચતુષ્ક (Range of Grouped Data): R = ઉચ્ચતમ વર્ગની ઉપરલી સીમા − ન્યૂનતમ વર્ગની નીચલી સીમા
R = વિચલન ચતુષ્ક · SI: ડેટાનું એકમ · વર્ગીકૃત ડેટા માટે
ચતુષ્ક વિચલન (Quartile Deviation / Semi-interquartile Range): QD = (Q₃ − Q₁) / 2
Q₁ = પ્રથમ ચતુષ્ક (first quartile), Q₃ = તૃતીય ચતુષ્ક (third quartile) · SI: ડેટાનું એકમ · વિચલન ચતુષ્કની બીજી માપ છે
અવર્ગીકૃત ડેટાનો Q₁ અને Q₃ (Quartiles of Ungrouped Data): Q₁ = (n+1)/4 -મું મૂલ્ય; Q₃ = 3(n+1)/4 -મું મૂલ્ય
Q₁ = પ્રથમ ચતુષ્ક, Q₃ = તૃતીય ચતુષ્ક, n = નિરીક્ષણોની સંખ્યા · SI: ડેટાનું એકમ · ડેટા ક્રમબદ્ધ હોય
વર્ગીકૃત ડેટાનો Q₁ (First Quartile of Grouped Data): Q₁ = l + [(N/4 − C_f) / f] × h
l = Q₁ વર્ગની નીચલી સીમા, N = કુલ આવૃત્તિ, C_f = Q₁ વર્ગ પહેલાંની સંચयी આવૃત્તિ, f = Q₁ વર્ગની આવૃત્તિ, h = વર્ગ અંતરાલ · SI: ડેટાનું એકમ · N/4 સંચयी આવૃત્તિ કોઈ વર્ગમાં આવે તેવો Q₁ વર્ગ શોધો
વર્ગીકૃત ડેટાનો Q₃ (Third Quartile of Grouped Data): Q₃ = l + [(3N/4 − C_f) / f] × h
l = Q₃ વર્ગની નીચલી સીમા, N = કુલ આવૃત્તિ, C_f = Q₃ વર્ગ પહેલાંની સંચयी આવૃત્તિ, f = Q₃ વર્ગની આવૃત્તિ, h = વર્ગ અંતરાલ · SI: ડેટાનું એકમ · 3N/4 સંચयी આવૃત્તિ કોઈ વર્ગમાં આવે તેવો Q₃ વર્ગ શોધો
મધ્યક વિચલન (Mean Deviation) — અવર્ગીકૃત: MD = Σ|xᵢ − x̄| / n
MD = મધ્યક વિચલન, xᵢ = i-મું મૂલ્ય, x̄ = મધ્યક, n = નિરીક્ષણોની સંખ્યા · SI: ડેટાનું એકમ · દરેક મૂલ્યનો મધ્યકથી વિચલન લઈ વ્યક્તિગત પરિમાણનો સરવાળો
મધ્યક વિચલન (Mean Deviation) — વર્ગીકૃત: MD = Σ[fᵢ · |xᵢ − x̄|] / Σfᵢ
fᵢ = i-મા વર્ગની આવૃત્તિ, xᵢ = i-મા વર્ગનું મધ્યબિંદુ, x̄ = મધ્યક · SI: ડેટાનું એકમ · વર્ગીકૃત વિતરણ માટે
આવૃત્તિ-સરેખા વિચલન ચોરસ (Variance) — અવર્ગીકૃત: σ² = Σ(xᵢ − x̄)² / n
σ² = પ્રમાણભૂત વિચલનનો વર્ગ (variance), xᵢ = i-મું મૂલ્ય, x̄ = મધ્યક, n = નિરીક્ષણોની સંખ્યા · SI: (ડેટાના એકમ)² — વિસ્તૃત એકમ · સંપૂર્ણ વસ્તી માટે (population); n-1 નહીં, n લઈએ GUJCET માં
આવૃત્તિ-સરેખા વિચલન ચોરસ (Variance) — વર્ગીકૃત: σ² = Σ[fᵢ · (xᵢ − x̄)²] / Σfᵢ
fᵢ = i-મા વર્ગની આવૃત્તિ, xᵢ = i-મા વર્ગનું મધ્યબિંદુ, x̄ = મધ્યક · SI: (ડેટાના એકમ)² · વર્ગીકૃત વિતરણ માટે
વિચલન ચોરસ — સરળ પદ્ધતિ (Shortcut Method for Variance): σ² = [Σ(fᵢ · xᵢ²)/Σfᵢ] − (x̄)²
fᵢ = આવૃત્તિ, xᵢ = મધ્યબિંદુ, x̄ = મધ્યક · SI: (ડેટાના એકમ)² · ગણતરી સરળ બને તે માટે
વિચલન ચોરસ — અંદાજિત મધ્યક પદ્ધતિ (Variance via Assumed Mean): σ² = [Σ(fᵢ · dᵢ²)/Σfᵢ] − [Σ(fᵢ · dᵢ)/Σfᵢ]², જ્યાં dᵢ = xᵢ − a
a = અંદાજિત મધ્યક, dᵢ = xᵢ − a, fᵢ = આવૃત્તિ, xᵢ = મધ્યબિંદુ · SI: (ડેટાના એકમ)² · અંદાજિત મધ્યક પદ્ધતિ સાથે ગણતરી કરતી વખતે
વિચલન ચોરસ — સ્ટેપ ડિવિએશન પદ્ધતિ (Variance via Step-deviation): σ² = h² × {[Σ(fᵢ · uᵢ²)/Σfᵢ] − [Σ(fᵢ · uᵢ)/Σfᵢ]²}, જ્યાં uᵢ = (xᵢ − a)/h
h = વર્ગ અંતરાલ (class width), a = અંદાજિત મધ્યક, uᵢ = અનુપાતિક વિચલન, fᵢ = આવૃત્તિ · SI: (ડેટાના એકમ)² · જ્યારે વર્ગ અંતરાલ સમાન હોય અને મૂલ્યો મોટા હોય
પ્રમાણભૂત વિચલન (Standard Deviation): σ = √(σ²)
σ = પ્રમાણભૂત વિચલન (standard deviation), σ² = વિચલન ચોરસ (variance) · SI: ડેટાનું એકમ (same as data) · વિચલન ચોરસ મળ્યા બાદ, તેનો વર્ગમૂળ લેવું
વ્યક્તિગત વિચલન ગુણાંક (Coefficient of Variation): CV = (σ / x̄) × 100%
σ = પ્રમાણભૂત વિચલન, x̄ = મધ્યક · SI: કોઈ એકમ નથી (ટકાવારી) · બે કે તેથી વધુ વિતરણોની વિષમતા (dispersion) સરખાવવા માટે
સંચयी આવૃત્તિ (Cumulative Frequency): Cfᵢ = f₁ + f₂ + … + fᵢ = Σ(fⱼ), j = 1 થી i
Cfᵢ = i-મા વર્ગ સુધીની સંચयी આવૃત્તિ, fⱼ = j-મા વર્ગની આવૃત્તિ · SI: એકમરહિત (કાઉન્ટ) · વર્ગીકૃત વિતરણમાં દરેક વર્ગ માટે

🔗 સંબંધો

  • મધ્યક, મધ્યસ્થ અને બહુલક એ ત્રણેય વિતરણના કેન્દ્રીય વલનના માપ છે; સમમિત (symmetric) વિતરણમાં આ ત્રણેય સમાન હોય છે.
  • વ્યક્તિગત વિચલન ગુણાંક (CV) વિના એકમનો ગુણોત્તર છે — જેથી વિવિધ એકમ ધરાવતા વિતરણોની વિષમતાની સરખામણી થઈ શકે.
  • પ્રમાણભૂત વિચલન (σ) = √(વિચલન ચોરસ); પ્રમાણભૂત વિચલનનું એકમ મૂળ ડેટા જેવું જ રહે છે, વિચલન ચોરસનું નહીં.
  • જો બધા મૂલ્યોમાં સ્થિર અંક (constant) c ઉમેરવો/કાઢવો, તો મધ્યક બદલાય પણ પ્રમાણભૂત વિચલન અને CV બદલાતા નથી.
  • જો બધા મૂલ્યોને c વડે ગુણવા/ભાગવા, તો પ્રમાણભૂત વિચલન પણ c ગણું થાય, પણ CV અપરિવર્તિત રહે છે.
  • Q₃ − Q₁ = વિચલન ચતુષ્ક (interquartile range) — મધ્ય 50% ડેટાનું વિસ્તરણ દર્શાવે છે, ચરમ મૂલ્યોના પ્રભાવથી મુક્ત.
  • વર્ગીકૃત વિતરણમાં મધ્યસ્થ અને Q₁/Q₃ નું સૂત્ર સમાન રચના ધરાવે છે — બંને 'લ + [( Position − C_f ) / f ] × h' આકારનું છે.

🎯 ટ્રિક્સ

અવર્ગીકૃત ડેટાના મધ્યકની ગણતરીમાં: જો બધા મૂલ્યો જોડીયું હોય, તો કોઈપણ એક મૂલ્ય પસંદ કરી dᵢ = xᵢ − a લેવાથી સરવાળો ઝડપી થાય છે.
વર્ગીકૃત ડેટામાં મધ્યક શોધતી વખતે: મધ્યસ્થ વર્ગ મેળવવા N/2 જેટલી સંચयी આવૃત્તિ ધરાવતો પ્રથમ વર્ગ શોધો — તે ગ્રાફિકલ રીતે Ogive વક્રથી પણ શક્ય છે.
સ્ટેપ-ડિવિએશન પદ્ધતિમાં uᵢ ના મૂલ્યો ઘણીવાર -2, -1, 0, 1, 2 જેવા નાના પૂર્ણાંક બને છે — ગુણાકાર અને વર્ગ કરવા સરળ.
બહુલકનું સૂત્ર યાદ રાખવા: Z = l + [(f₁−f₀)/(2f₁−f₀−f₂)] × h → 'l + (પરપડોળ/સરવાળો) × h' — જ્યાં પરપડોળ = ફરક, સરવાળો = 2f₁ − f₀ − f₂.
વિચલન ચોરસની સરળ પદ્ધતિ σ² = (Σfᵢxᵢ²/Σfᵢ) − (x̄)² — જ્યારે xᵢ ના વર્ગોના સરવાળા ઉપલબ્ધ હોય ત્યારે ઝડપી ગણતરી.
CV ની તુલના: CV > 15–20% એટલે વિતરણ વધુ વિષમ (dispersed); CV < 10–15% એટલે ડેટા એકસરખો છે (homogeneous).

⚠️ ભૂલો

મધ્યકની ગણતરીમાં મધ્યબિંદુ (xᵢ) ને બદલે વર્ગની સીમા (lower/upper boundary) મૂકી દેવી — સીમા નહીં, મધ્યબિંદુ લેવું.
વર્ગીકૃત ડેટાના મધ્યસ્થ/ચતુષ્કના સૂત્રમાં C_f (સંચयी આવૃત્તિ) ને મધ્યસ્થ વર્ગની આવૃત્તિ જ ભાન કરી લેવું — C_f એ 'મધ્યસ્થ વર્ગ પહેલાં' ની સંચयी આવૃત્તિ છે.
વિચલન ચોરસ (σ²) નું એકમ (ડેટાના એકમ)² હોય છે, પ્રમાણભૂત વિચલન (σ) નું એકમ ડેટા જેવું જ હોય છે — ગુણોત્તર (CV) માં σ અને x̄ બંનેનું એકમ સમાન હોવાથી એકમ રદ્દ થાય છે.
બહુલક વર્ગની નીચલી સીમા (l) લેવામાં ભૂલ — દરેક વર્ગની નીચલી સીમા જ l હોય, ઉપરલી નહીં.
સ્ટેપ-ડિવિએશન પદ્ધતિમાં σ² = h² × [...] માં h² બાકી રાખી દેવું — h² ભૂલશું ન બેસાડવું.
CV (%) ગણતરીમાં અંતે × 100% ભૂલી જવું — CV એ ટકાવારી છે, શૂન્યાંક ગુણોત્તર નહીં.
અવર્ગીકૃત ડેટામાં m -મું મૂલ્ય શોધવા માટે m = (n+1)/2 વડે સ્થાન કાઢી, પછી તે મૂલ્ય લેવું — m = n/2 નહીં (n અજોડ હોય તો ભૂલ થાય).
વિચલન ચોરસના સૂત્રમાં (xᵢ − x̄)² ને બદલે (xᵢ − a)² નો ઉપયોગ કરી દેવો, જ્યાં a અંદાજિત મધ્યક છે — અંદાજિત મધ્યક પદ્ધતિમાં ફરક લેવો પડે છે.
બહુલક વર્ગ પસંદગીમાં: ફક્ત સૌથી મોટી આવૃત્તિ ધરાવતો વર્ગ જ બહુલક વર્ગ નથી; બહુલક વર્ગ એટલે જેની આવૃત્તિ પડોશી બંને વર્ગો કરતાં વધુ હોય.
પ્રમાણભૂત વિચલન શોધતી વખતે વિચલન ચોરસનો વર્ગમૂળ ભૂલી જવો — વિચલન ચોરસ અને પ્રમાણભૂત વિચલન અલગ છે, બંનેનો ઉપયોગ કરવો જોઈએ.
