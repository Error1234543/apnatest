🧠 યાદ રાખો

આંકડાશાસ્ત્ર છે — આપલે માહિતીનો સંગ્રહ, સंगઠન, વિશ્લેષણ અને વ્યાખ્યાયન.
અસ્પષ્ટ (Raw) સંપૂર્ણાંક → ક્રમબદ્ધ (Ordered) → આવર્તણ વિતરણ કોષ્ટક.
ચાર બાજુઓની કોઈ પણ ચોકસાઈએ (ઉદા. ૩.૫–૪.૫) → ખરી મર્યાદા મળશે: નીચલી મર્યાદા − ૦.૫ અને ઉપલી મર્યાદા + ૦.૫.
લક્ષ્ય (Class) અંતર h = ઉપલી મર્યાદા − નીચલી મર્યાદા = f_મર્યાદાની પહોળાઈ.
યુનિયન જેક પદ્ધતિ — મધ્યમાં મધ્યસ્થ / મધ્યમ મૂલ્ય, ડાબી બાજુ '−' અને જમણી બાજુ '+' ચિન્હો રાખવાં; ઝડપી gણતર માટે શ્રેષ્ઠ.
ગુરુત્વ કેન્દ્ર (Mean) બદલાતાં (shift) પણ દૂર નથી થતું, પણ બદલાતાં (scale) સમપ્રમાણમાં બદલાય છે.
મધ્યસ્થ (Median) માટે n સંખ્યાઓ ક્રમબદ્ધ હોવી જરૂરી; e (n યુગ્મ) હોય તો n/2 અને n/2+1 વાળા પદોનો સરેરાશ.
મધ્યસ્થ (Mode) — સૌથી વધુ આવર્ત ધરાવતું મૂલ્ય; સતત વિતરણ માટે: Mode = l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h
આવર્તન (f) × આવર્તન સેતુ (m) = fx એટલે કે, સેતુની ડાબી બાજુનો પૂર્ણાંક ભાગ.
અચળ k નું પ્રમાણિત વિચલન (SD) હંમેશા શૂન્ય — કારણ કે કોઈ વિચલન જ નથી.
જો દરેક મૂલ્યને a વડે ગુણવાય અને b ઉમેરવાય, તો SD માત્ર a વડે ગુણાશે (b નો અસર નહિ).
વિકલન ગુણાંક (CV) = (SD / Mean) × 100 — એકમરહિત, વિતરણોની સરખામણી માટે શ્રેષ્ઠ સાધન.
નિરપેક્ષ વિચલન (Mean Deviation) ≤ પ્રમાણિત વિચલન (Standard Deviation), હંમેશા.
સંયુક્ત SD માટે: σ_c = √[(n₁σ₁² + n₂σ₂² + n₁(d₁)² + n₂(d₂)²) / (n₁+n₂)], જ્યાં d = દૂરિયાં.

⚡ ઝડપી સૂત્રો

સરેરાશ (Mean, x̄) = Σfx / Σf (આવર્ત વિતરણ) અથવા Σxᵢ / n (વ્યક્તિગત)
ગણના સરળતા: uᵢ = (xᵢ − A)/h, જ્યાં A = નમૂના મધ્યબિંદુ (Assumed Mean); x̄ = A + h·(Σfuᵢ/Σf)
મધ્યસ્થ (Median): ક્રમબદ્ધ લક્ષ્ય માટે l + [(N/2 − C.f)/f] × h; l=નીચલી મર્યાદા, C.f=પૂર્વલાભ આવર્તન, f=લક્ષ્ય આવર્તન
મધ્યસ્થ (Mode): l + [(f₁−f₀)/(2f₁−f₀−f₂)] × h; l=મોડલ લક્ષ્યની નીચલી મર્યાદા, f₁=f(f_મોડલ), f₀=પાછલા, f₂=આગળનું
σ = √[Σ(xᵢ − x̄)²/n] અથવા σ = √[(Σf(xᵢ−A)²)/Σf − (Σfuᵢ/Σf)² × h²]
u_i સૂત્ર સાથે: σ = h × √[(Σfuᵢ²/N) − (Σfuᵢ/N)²]
વિકલન ગુણાંક (C.V.) = (σ / x̄) × 100%
સરેરાશ મૂલ્યનું ગુણિત: a·x̄ + b (અચળ ઉમેરે કે ઘટાડે SD બદલાતું નથી)
હાર્મોનિક મધ્યસ્થ (H.M.) = n / Σ(1/xᵢ) — સમય/વાહનની સરેરાશ ઝડપ શોધવા ઉપયોગી
જિયોમેટ્રિક મધ્યસ્થ (G.M.) = (x₁·x₂·...·xₙ)^(1/n) — વ્યાજદર/વૃદ્ધિ દર શોધવા ઉપયોગી

✅ વન-લાઈનર્સ

દોષાંતર (Range) = મહત્તમ − ન્યૂનતમ મૂલ્ય — વિતરણનું પહોળું.
આવર્તન સેતુ (Class Mark) m = (નીચલી મર્યાદા + ઉપલી મર્યાદા)/2.
યુનિયન જેક — મધ્યમાં A, ડાબી બાજુ (A − d) +, જમણી બાજુ (A + d) −; ખૂબ ઝડપી ગણતરી.
સરેરાશ, મધ્યસ્થ, મોડ — ત્રણેય એકસરખાં: સંમિત વિતરણ (Symmetric) માં.
વિકલન ગુણાંક (C.V.) નો ઉપયોગ: બે વિતરણોમાંથી કયામાં વધુ વિખેરણ છે તે જાણવા.
જો બધા જ મૂલ્યો સમાન હોય → SD = 0, CV = 0.
લક્ષ્ય (Class) ફરકને યોગ્ય રીતે લેવા: સતત વિતરણમાં l અને u મર્યાદાઓ સીધી રાખવી.
Mean < Median < Mode — ઋણ skewness; જો Mean > Median > Mode — ધન skewness.
સંયુક્ત વિતરણનું SD હંમેશા વ્યક્તિગત SD કરતાં મોટું હોય છે (જો મધ્યસ્થો અલગ હોય).
આવર્તન પરથી ગ્રાફ: ઓગમેન્ટ (Ogive) — N/2 વાળું બિંદુ મધ્યસ્થ (Median) આપે છે.
