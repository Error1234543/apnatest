GUJCET ગણ સિદ્ધાંત અધ્યાય – મહત્વની એક્ઝામ ટ્રિક્સ

🧪 GUJCET — Gujarati • Mathematics • Sets

🎯 પરીક્ષા ટ્રિક્સ

બે ગણના સંયોજનમાં દ્વિગુણ ગણાયેલા તત્વોની ખામી ટાળો: n(A ∪ B) = n(A) + n(B) – n(A ∩ B). ઉપરાંત, જો n(A ∪ B) = n(A) + n(B) હોય, તો A અને B પરસ્પર વિકલપ ગણ (Disjoint Set) છે.
જ્યારે પ્રશ્નમાં બે ગણનો સંયોજન અથવા છેદન આપેલું હોય અને તમે સામાન્ય રીતે કુલ પેટર્ન શોધવા માંગતા હો.
દા.ત.: n(A) = 15, n(B) = 20, n(A ∩ B) = 5 માટે n(A ∪ B) = 15 + 20 – 5 = 30 થાય.
નિયંત્રિત ગણનો ઉપગણ (Subset) ની સંખ્યા = 2ⁿ, જ્યાં n = તત્વોની સંખ્યા. જો પ્રશ્નમાં 'કુલ કેટલા ઉપગણ' પૂછતો હોય, તો 2ⁿ મૂલ્ય ગણી લો અને વિકલ્પોમાંથી તે જ શોધો.
જ્યારે પ્રશ્નમાં કોઈ ગણના કુલ ઉપગણોની સંખ્યા પૂછવામાં આવે.
દા.ત.: P = {a, b, c} માટે કુલ ઉપગણો 2³ = 8 થશે. વિકલ્પોમાં 8 હોય તો તે સાચો છે.
ખાલી ગણ (∅) બધા જ ગણનો ઉપગણ હોય છે અને કોઈ પણ ગણના છેદનમાંથી ∅ મળે તો પરિણામ ∅ જ મળે. આથી, એકમ વિકલ્પમાં '∅' હોય અને 'તમામ ગણનો ઉપગણ' લખ્યું હોય તો તે સાચું છે.
જ્યારે ખાલી ગણ સંબંધિત વિધાનો અથવા સંયોજન/છેદનના પ્રશ્નોમાં ભ્રમણા ઉભી કરતો હોય.
દા.ત.: A = {1, 2} માટે A ∩ ∅ = ∅ અને ∅ ⊂ A, એ બંને સાચા છે.
A – B = A ∩ B′ (એટલે કે A માંથી B ના તત્વો કાઢી દેવા). જો વિકલ્પોમાં A – B અને A ∩ B′ બંને હોય, તો બંને એકસરખા છે અને સાચો જવાબ એ જ છે.
ગણના તફાવત (Set Difference) શોધવાની જગ્યાએ વિયોજનના વિકલ્પો આપેલ હોય.
દા.ત.: A = {1,2,3,4}, B = {3,4,5} માટે A – B = {1,2}. આ જ A ∩ B′ થાય.
જો n(A) > n(B) હોય, તો B એ A નો પરિપૂર્ણ ઉપગણ (Proper Subset) ન બની શકે. આ સીધી તર્કશક્તિથી વિકલ્પો દૂર કરવામાં મદદરૂપ થાય છે.
જ્યારે ગણના કદ સંબંધિત વિધાનમાંથી સાચું/ખોટું પસંદ કરવાનું હોય.
દા.ત.: n(A)=6, n(B)=4 હોય તો B ⊂ A હોઈ શકે, પણ n(B) > n(A) હોય તો A ⊂ B ન હોય.
A ∪ ∅ = A અને A ∩ ∅ = ∅. આ બે પ્રમેયો મુખ્યત્વે ઝડપી નિષ્કર્ષ માટે, ખાસ કરીને MCQ વિધાનોમાં, ઉપયોગી છે.
જ્યારે ખાલી ગણ સાથે સંયોજન અથવા છેદન સંબંધિત કોઈ વિધાન આપેલું હોય.
દા.ત.: A = {p,q,r} માટે A ∪ ∅ = {p,q,r} = A.
જો A ⊆ B હોય, તો n(A) ≤ n(B) અને A ∪ B = B, A ∩ B = A. આથી, A ઉપગણ B હોય તો સંયોજન અને છેદનમાંથી એક જ ગણ બાકી રહે.
ઉપગણ-સંબંધિત પ્રશ્નોમાં જ્યારે સંયોજન અથવા છેદન પૂછવામાં આવ્યું હોય.
દા.ત.: A = {1,2}, B = {1,2,3} માટે A ⊆ B. તેથી A ∪ B = B = {1,2,3}.
કોઈપણ ગણ A માટે A ∪ A′ = U અને A ∩ A′ = ∅. આથી, જો પ્રશ્નમાં A અને તેના પૂરકનો સંયોજન અથવા છેદન પૂછતું હોય, તો જવાબ Kુલ ગણ અથવા ખાલી ગણ જ હોય.
પૂરક ગણ (Complement) નો ઉપયોગ કરતાં પ્રશ્નોમાં જ્યારે સંયોજન/છેદન પૂછાય.
દા.ત.: U = {1,2,3,4,5}, A = {1,2} માટે A′ = {3,4,5}. A ∪ A′ = U, A ∩ A′ = ∅.
A Δ B = (A – B) ∪ (B – A) અથવા A Δ B = (A ∪ B) – (A ∩ B). સંમેય અંતર શોધવા માટે આ સૂત્ર વાપરો; જો કોઈ એક વિકલ્પમાં (A – B) ∪ (B – A) લખ્યું હોય, તો તે સાચો જવાબ છે.
જ્યારે સંમેય અંતર (Symmetric Difference) નો પ્રશ્ન આવે.
દા.ત.: A={1,2,3}, B={2,3,4} માટે A Δ B = {1,4}.
બે સરખા ગણો માટે A = B ⇒ n(A Δ B) = 0, કારણ કે A – B = ∅ અને B – A = ∅. જો પ્રશ્નમાં n(A Δ B) = 0 આપેલ હોય, તો A = B છે તે સીધું લખી શકાય.
સંમેય અંતર શૂન્ય હોય ત્યારે ગણોની સમાનતા ચકાસવા.
દા.ત.: A={x,y}, B={y,x} માટે A=B; તેથી A Δ B=∅, n(A Δ B)=0.
જો n(A ∪ B) = n(A) + n(B), તો A ∩ B = ∅. આમ, સંયોજનનું કદ સીધું સરવાળા જેટલું હોય તો છેદન શૂન્ય છે.
વિકલ્પોમાં સીધું ગણન હોય અને તમે તરત જ વિશ્લેષણ કરવું હોય.
દા.ત.: n(A)=10, n(B)=7, n(A∪B)=17 હોય તો A અને B વિકલપ છે.
ત્રણ ગણના સંયોજન માટેનું સૂત્ર: n(A ∪ B ∪ C) = n(A)+n(B)+n(C) – n(A∩B) – n(B∩C) – n(A∩C) + n(A∩B∩C). આ સૂત્ર યાદ રાખો અને વેન ચિત્રવાળા પ્રશ્નોમાં કોઈ પણ વિભાગ શોધવા માટે વાપરો.
ત્રણ ગણોના સંયોજન, છેદન અને તફાવત સંબંધિત સંખ્યાત્મક પ્રશ્નોમાં.
દા.ત.: n(A)=50, n(B)=45, n(C)=40, n(A∩B)=15, n(B∩C)=10, n(A∩C)=12, n(A∩B∩C)=5. તો n(A∪B∪C)=50+45+40–15–10–12+5=103.
વેન ચિત્રમાં ફક્ત A માટેનું વિસ્તાર (ફક્ત A, B ના કે C ના નથી) શોધવા: n(A) – n(A∩B) – n(A∩C) + n(A∩B∩C). આ સૂત્ર ઝડપથી ફક્ત એક ગણના આંકડાકીય વિભાગ માટે ઉપયોગી છે.
ત્રણ ગણો વાળા પ્રશ્નમાં 'ફક્ત A' અથવા 'ફક્ત B' વગેરે પૂછવામાં આવે.
દા.ત.: ઉપરોક્ત ઉદાહરણમાં ફક્ત A = 50 – 15 – 12 + 5 = 28.
પૂરક ગણનો નિયમ: (A ∪ B)′ = A′ ∩ B′ અને (A ∩ B)′ = A′ ∪ B′ (ડી મોર્ગન નિયમ). જો પ્રશ્નમાં કોઈના પૂરકનો સંયોજન/છેદન આવે, તો આ નિયમ વાપરીને સરળ બનાવી શકાય.
પૂરક સાથે સંયોજન અથવા છેદન મિશ્રિત પ્રશ્નોમાં.
દા.ત.: A′ ∩ B′ નો અર્થ (A ∪ B)′ થાય; આથી A અને B બંનેનો સંયોજન બહારનું ભાગ મળે.
ઉપગણ (Subset) vs પરિપૂર્ણ ઉપગણ (Proper Subset): પરિપૂર્ણ ઉપગણમાં મૂળ ગણનો તત્વ સમાવિષ્ટ નથી હોતો; તેથી n(A) ≥ n(B) અને B ≠ A. જો n(B) = n(A) હોય, તો B પરિપૂર્ણ ઉપગણ નથી બની શકતું.
જ્યારે પ્રશ્નમાં 'પરિપૂર્ણ ઉપગણ' અથવા 'સાચો ઉપગણ' નો ઉલ્લેખ હોય.
દા.ત.: A={1,2} માટે ઉપગણો: ∅,{1},{2},{1,2}; પરિપૂર્ણ ઉપગણો: ∅,{1},{2} કુલ 3 (જે 2²–1).
