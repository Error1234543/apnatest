સંહિતા – સૂત્ર પત્ર (Sets — Formula Sheet)

⚡ સૂત્રો

ખાલી સંહિતા (શૂન્ય સંહિતા): φ અથવા { }
φ = ખાલી સંહિતા; કોઈ સભ્ય ધરાવતી ન હોય તેવી સંહિતા · SI: — · જ્યારે સંહિતામાં કોઈ પણ પૂર્વધારિત સભ્યઓ હોય નહીં
એકલી સંહિતા: {a}
a = સંહિતાનો એક જ સભ્ય · SI: — · સંહિતામાં માત્ર એક જ સભ્ય હોય
પ્રતિસમ સંહિતા: A ⊆ B (અથવા B ⊇ A)
A ⊆ B = A, B ની પ્રતિસમ સંહિતા છે; અર્થતઃ A ના દરેક સભ્ય B માં પણ હોય · SI: — · A ના સમસ્ત સભ્યઓ B માં સમાવિષ્ટ હોય ત્યારે
યથાર્થ પ્રતિસમ સંહિતા (Proper Subset): A ⊂ B (અથવા B ⊃ A)
A ⊂ B = A, B ની યથાર્થ પ્રતિસમ સંહિતા છે; A ≠ B · SI: — · A ⊆ B હોય અને A ≠ B હોય, એટલે કે A ના ઓછામાં ઓછો એક સભ્ય B માં ન હોય
બે સંહિતાના સંઘાત (Union): A ∪ B = {x : x ∈ A અથવા x ∈ B}
A ∪ B = A અને B ના સૌ સભ્યોનો સંઘાત; x ∈ A અથવા x ∈ B · SI: — · જ્યારે બે સંહિતા A અને B આપેલી હોય
બે સંહિતાનું છેદન (Intersection): A ∩ B = {x : x ∈ A અને x ∈ B}
A ∩ B = A અને B ના સામાન્ય સભ્યો; x ∈ A અને x ∈ B બંને · SI: — · જ્યારે બે સંહિતા A અને B આપેલી હોય
બે સંહિતાનો તફાવત: A − B = {x : x ∈ A અને x ∉ B}
A − B = A ના એવા સભ્યો જે B માં ન હોય; B − B = φ · SI: — · જ્યારે બે સંહિતા A અને B આપેલી હોય
પૂરક સંહિતા (Complement): A' = U − A = {x : x ∈ U અને x ∉ A}
A' = A ની પૂરક સંહિતા; U = સર્વસંહિતા; A' માં U ના એવા સભ્યો જે A માં ન હોય · SI: — · U સર્વસંહિતા હોય અને A ⊆ U હોય
ન્યૂનતમ સંહિતા ગણતરી (n(A ∪ B)): n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
n(A ∪ B) = A ∪ B માં સભ્યોની સંખ્યા; n(A) = A માં સભ્યો; n(B) = B માં સભ્યો; n(A ∩ B) = સામાન્ય સભ્યો · SI: — · A અને B કોઈ પણ બે પરિમિત સંહિતાઓ હોય; A ∩ B = φ હોય તો n(A ∪ B) = n(A) + n(B)
ત્રણ સંહિતાઓનો સંઘાત: n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A∩B) − n(B∩C) − n(C∩A) + n(A∩B∩C)
A, B, C = ત્રણ પરિમિત સંહિતાઓ; A∩B = A અને B ના સામાન્ય સભ્યો; A∩B∩C = ત્રણેયના સામાન્ય સભ્યો · SI: — · A, B, C ત્રણેય પરિમિત સંહિતાઓ હોય
બે સંહિતાઓનો તફાવત (અંતર્ગત): n(A − B) = n(A) − n(A ∩ B)
n(A − B) = A માં હોય પણ B માં ન હોય તેવા સભ્યોની સંખ્યા; n(A) = A ના સભ્યો; n(A ∩ B) = સામાન્ય સભ્યો · SI: — · A અને B પરિમિત સંહિતાઓ હોય
બે સંહિતાઓના તફાવતનો કુલ સંઘાત: n(A ∪ B) = n(A − B) + n(B − A) + n(A ∩ B)
n(A − B) = A માત્રના સભ્યો; n(B − A) = B માત્રના સભ્યો; n(A ∩ B) = સામાન્ય સભ્યો · SI: — · A અને B પરિમિત સંહિતાઓ હોય
એકલી સંહિતાનું સૂત્ર (સિવાય B ના): n(A − B) = n(A) − n(A ∩ B) અને n(B − A) = n(B) − n(A ∩ B)
n(A − B) = A માત્ર સભ્યો; n(B − A) = B માત્ર સભ્યો · SI: — · A અને B પરિમિત સંહિતાઓ હોય
પ્રતિસમ સંહિતાઓનું છેદન: n(A ∩ B) = n(A) + n(B) − n(A ∪ B)
n(A ∩ B) = સામાન્ય સભ્યો; ઉપરોકત સૂત્રથી શોધી શકાય · SI: — · n(A), n(B), n(A ∪ B) જાણીતી હોય
કુલ સંભવિત પ્રતિસમ સંહિતાઓની સંખ્યા: P(A) ના સભ્યો = 2^n, જ્યાં n = n(A)
P(A) = A ની પ્રતિસમ સંહિતાઓની સંહિતા (Power Set); n = A માં સભ્યોની સંખ્યા · SI: — · A પરિમિત સંહિતા હોય
યાથાર્થ પ્રતિસમ સંહિતાઓ: યાથાર્થ પ્રતિસમ સંહિતાઓ = 2^n − 1
2^n − 1 = A ની યથાર્થ પ્રતિસમ સંહિતાઓની સંખ્યા; φ (ખાલી સંહિતા) ગણતરીમાં લાવતાં 2^n માં થાય છે પણ યથાર્થ પ્રતિસમમાં φ સમાવી શકાતો નથી · SI: — · A પરિમિત સંહિતા હોય અને n ≥ 0
De Morgan નું પ્રથમ નિયમ: (A ∪ B)' = A' ∩ B'
(A ∪ B)' = A ∪ B ની પૂરક; A' ∩ B' = A ની પૂરક અને B ની પૂરકનું છેદન · SI: — · A, B ⊆ U (સર્વસંહિતા)
De Morgan નું દ્વિતીય નિયમ: (A ∩ B)' = A' ∪ B'
(A ∩ B)' = A ∩ B ની પૂરક; A' ∪ B' = A ની પૂરક અને B ની પૂરકનો સંઘાત · SI: — · A, B ⊆ U (સર્વસંહિતા)
સમાન સંહિતા: n(A) = n(B) ⇒ A અને B સમાન સંહિતાઓ (Equivalent Sets)
n(A) = A માં સભ્યો; n(B) = B માં સભ્યો; સમાન સંહિતા = સમાન સભ્યસંખ્યા ધરાવતી સંહિતા · SI: — · બે સંહિતાનાં સભ્યોની સંખ્યા સમાન હોય
સર્વસંહિતાની ભૂમિ: n(U') = 0 ; n(φ') = n(U)
n(U') = સર્વસંહિતાની પૂરકમાં શૂન્ય સભ્ય; n(φ') = ખાલી સંહિતાની પૂરક = U · SI: — · A ⊆ U
A ∪ A' = U અને A ∩ A' = φ: A ∪ A' = U ; A ∩ A' = φ
A ∪ A' = A અને તેની પૂરકનો સંઘાત = U; A ∩ A' = A અને તેની પૂરકનું છેદન = φ · SI: — · A ⊆ U
આંતરિક સંહિતાઓ (Disjoint Sets): A ∩ B = φ ⇒ n(A ∪ B) = n(A) + n(B)
A ∩ B = φ = આંતરિક સંહિતાઓ; n(A ∪ B) = A અને B નો સંઘાત · SI: — · A અને B આંતરિક સંહિતાઓ હોય

🔗 સંબંધો

  • જો A ⊆ B હોય, તો A ∪ B = B અને A ∩ B = A
  • જો A ⊆ B હોય, તો B' ⊆ A' (પૂરક પ્રતિસમનો ઊલટો સંબંધ)
  • n(A − B) = n(A) − n(A ∩ B) અને n(B − A) = n(B) − n(A ∩ B)
  • n(A ∪ B) = n(A − B) + n(B − A) + n(A ∩ B) — ત્રણેય ભાગોનો સરવાળો સંઘાત આપે
  • De Morgan ના નિયમો જોડી બની છે: (A ∪ B)' ↔ A' ∩ B' અને (A ∩ B)' ↔ A' ∪ B'
  • n(A) = n(B) હોય તો A અને B સમાન (Equivalent) થાય, પણ સામાન્ય સભ્યો સમાન હોવા જરૂરી નથી
  • P(A) = A ની પ્રતિસમ સંહિતાઓની સંહિતા; |P(A)| = 2^n(A)
  • A − B = A ∩ B', એટલે તફાવત = છેદન અને પૂરકનો સંયોગ

🎯 ટ્રિક્સ

ચાર સભ્યો ધરાવતી સંહિતાની કુલ પ્રતિસમ સંહિતાઓ = 2^4 = 16; યથાર્થ = 16 − 1 = 15
n(A ∪ B) શોધવાનું સૂત્ર 'જોડ + બાદ = છેદન' — n(A) + n(B) − n(A ∩ B); કણખીર યાદ રાખવા 'Jod badh chhed'
A − B માં A ના બધા સભ્યો લો અને A ∩ B મેળવો; A માંથી તે બાદ કરો — સીધું પ્લટ કરી શકાય
De Morgan ના નિયમો યાદ રાખવા: સંઘાતનો પૂરક = પૂરકોનું છેદન; છેદનનો પૂરક = પૂરકોનો સંઘાત — બંને વચન 'પૂરક બદલાય, બીજું બદલાય'
આંતરિક સંહિતાઓ (Disjoint) માટે n(A ∪ B) = n(A) + n(B) — આંતરિક સંહિતા હોય તો છેદન = 0, તેથી સરળ બને
જો n(A) = p, n(B) = q, n(A ∪ B) = r, તો n(A ∩ B) = p + q − r — પાંચમાંથી ચાર જાણીતા હોય તો છોટતો ગાણિતિક રાહ જોવાય

⚠️ ભૂલો

n(A ∪ B) = n(A) + n(B) લખવું — આ ફક્ત ત્યારે જ સાચું છે જ્યારે A ∩ B = φ (આંતરિક સંહિતા)
A − B = B − A ધારી લેવું — તફાવત ક્રમચ્યુત (Commutative) નથી હોતો; સામાન્ય રીતે A − B ≠ B − A
પ્રતિસમ (⊆) અને યથાર્થ પ્રતિસમ (⊂) વચ્ચેનો તફાવત ભૂલવો — ⊆ માં A = B હોઈ શકે, ⊂ માં નહીં
De Morgan ના નિયમોમાં (A ∪ B)' = A' ∪ B' લખી દેવું — સાચું સૂત્ર (A ∪ B)' = A' ∩ B' છે; છેદન અને સંઘાત બંને બદલાય છે
2^n − 1 = યથાર્થ પ્રતિસમ સંહિતાઓ ગણતરીમાં φ (ખાલી સંહિતા) ને યથાર્થ પ્રતિસમ તરીકે ગણવાની ભૂલ
n(A − B) = n(A) − n(B) લખી દેવું — સાચું સૂત્ર n(A − B) = n(A) − n(A ∩ B) છે, n(B) નહીં
સંહિતાના છેદન (Intersection) અને સંઘાત (Union) ને જોડી રહેલી સંખ્યા ગણવાનું ભૌતિક સંયોજન કહી દેવું
શૂન્ય સંહિતા (φ) સ્વયં પણ સંહિતા છે અને તે દરેક સંહિતાની પ્રતિસમ સંહિતા છે, એ ભૂલી જવું
A ⊆ B અને A ⊂ B વચ્ચેનો તફાવત સમજ્યા વિના પ્રશ્ન ઉકેલવાનો પ્રયત્ન
પૂરક સંહિતાની ગણતરીમાં સર્વસંહિતા (U) ને ધ્યાનમાં લેવાની ભૂલ — A' હંમેશા U નાં સંદર્ભે જ વ્યાખ્યાયિત થાય
