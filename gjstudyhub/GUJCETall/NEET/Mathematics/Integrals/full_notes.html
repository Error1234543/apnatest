ઇંટિગ્રલ્સ એ ગણિતના એક મૂળભૂત અને અત્યંત ઉપયોગી વિભાગ છે જે અવકલન (ડિફરન્સિએશન) નો વ્યસ્ત સંકલ્પના રજૂ કરે છે. આ અધ્યાય વિદ્યાર્થીઓને ચલની ફંક્શનના સંકલનની પદ્ધતિઓ, અનિર્ધારિત અને નિશ્ચિત ઇંટિગ્રલ્સ, અને તેમના વિવિધ ગુણધર્મોની સમજ આપે છે. ઇંટિગ્રલ્સની મદદથી વક્રો હેઠળનું ક્ષેત્રફળ, ઘનફળ અને અન્ય ભૌતિક રાશિઓની ગણતરી કરી શકાય છે, જે GUJCET સહિત સ્પર્ધાત્મક પરીક્ષાઓમાં મહત્વની ભૂમિકા ભજવે છે. આ અધ્યાયમાં અવયવીકરણ, પ્રતિસ્થાપન, આંશિક ભિન્ન અને વિરિયન સંકલન જેવી પદ્ધતિઓ શીખવામાં આવે છે, જે રૂઢિગત સંકલનોની શ્રેણીનો વિસ્તાર કરે છે.

ઇંટિગ્રેશન એ અવકલનનો વ્યસ્ત સંકલ્પના

અવકલન અને સંકલન એ ગણિતમાં પરસ્પર વિરોધી પ્રક્રિયાઓ છે. જો આપણે કોઈ ફંક્શનનું અવકલન (ડેરિવેટિવ) કરીએ અને પછી તે પરિણામનું સંકલન કરીએ, તો આપણને મૂળ ફંક્શન મળે છે, સંકલન constant ઉમેરવામાં આવે છે. આ પ્રક્રિયાને 'ઇન્ટિગ્રેશન' કહે છે, જે અવકલનનો વિરુદ્ધ સંકલ્પના છે. ઉદાહરણ તરીકે, જો f(x) = x^2 નું અવકલન કરીએ તો 2x મળે, અને 2x નું સંકલન કરીએ તો x^2 + C મળે, જ્યાં C એ સંકલન constant છે. આ સંકલનની પદ્ધતિઓ મૂળભૂત રીતે અવકલનના સૂત્રોને ઉલટાવીને મેળવી શકાય છે. ઉદાહરણ તરીકે, dx/dx = 1 થી સીધું સંકલન કરતાં x + C મળે છે. આ મૂળભૂત સંબંધ આપણને ઇંટિગ્રેશનના અભ્યાસ માટે પાયાનું પાદરક્ષણ પૂરું પાડે છે.

પ્રાંતિક અવકલન અને સંયોગ

પ્રાંતિક અવકલન એ અવકલનની એક પદ્ધતિ છે જેમાં કોઈ ફંક્શનને રચનાત્મક રીતે અવયવોમાં વિભાજિત કરવામાં આવે છે, જેથી સંકલન સરળ બની શકે. આ પદ્ધતિમાં અવકલન કરેલ પદોના સંયોગ દ્વારા મૂળ ફંક્શન મેળવવામાં આવે છે. ઉદાહરણ તરીકે, d/dx[ƒ(x)g(x)] = ƒ'(x)g(x) + ƒ(x)g'(x) સૂત્રનો ઉપયોગ કરીને, કેટલાક સંકલનોને સરળ રીતે ઉકેલી શકાય છે. આ પદ્ધતિ અલગ-અલગ સંયોજનો માટે અનુકૂળ છે અને ઘણીવાર ખાસ કરીને ત્યારે ઉપયોગી બને છે જ્યારે સીધું સંકલન મુશ્કેલ હોય. પ્રાંતિક અવકલનથી મળતા સૂત્રોનું જ્ઞાન ગણતરીમાં સમય બચાવે છે અને ભુલો ઘટાડે છે.

ઇંટિગ્રેશનની પદ્ધતિઓ: અવયવીકરણ

અવયવીકરણ પદ્ધતિમાં કોઈ પણ ઇંટિગ્રલને તેના અવયવોમાં વિભાજિત કરવામાં આવે છે, જેથી સંકલન સરળ બની શકે. આ પદ્ધતિ મુખ્યત્વે બહુપદી ફંક્શન અને ત્રિકોણમિતિય સંકલનો માટે ઉપયોગી છે. ઉદાહરણ તરીકે, ∫(x² + 2x)dx ને અવયવીકરણ કરતાં ∫x²dx + ∫2xdx મળે છે, જે સરળતાથી ઉકેલી શકાય છે. આ પદ્ધતિ સરળ સંકલનોમાં વારંવાર ઉપયોગમાં લેવામાં આવે છે. ધ્યાન રાખવું જરૂરી છે કે દરેક પદ અલગ અલગ સંકલિત કરવું પડે છે અને છેલ્લે constant ઉમેરવો પડે છે. આ પદ્ધતિનો ઉપયોગ ખાસ કરીને રાખરખાવ કરતા ઘણા સંકલનો માટે કરવામાં આવે છે.

ઇંટિગ્રેશનની પદ્ધતિઓ: પ્રતિસ્થાપન

પ્રતિસ્થાપન પદ્ધતિ એ ઇંટિગ્રેશનની એક મહત્વની પદ્ધતિ છે જેમાં ચલને બદલીને સંકલન સરળ બનાવવામાં આવે છે. આ પદ્ધતિમાં, જો ઇંટિગ્રલ ∫f(g(x))g'(x)dx હોય, તો u = g(x) પ્રતિસ્થાપન કરીને, du = g'(x)dx લઈને સંકલન ∫f(u)du માં ફેરવી શકાય છે. ઉદાહરણ તરીકે, ∫2x cos(x²)dx માં, u = x² લેતાં du = 2x dx મળે, જેથી ઇંટિગ્રલ ∫cos(u)du બની જાય, જેનો ઉકેલ sin(u) + C છે. પ્રતિસ્થાપન પદ્ધતિ ખાસ કરીને તે જ્યારે ઉપયોગી થાય છે જ્યારે ઇંટિગ્રલના રૂપમાં kોઈ એક બીજાનું અવકલન જોવા મળે. આ પદ્ધતિનો ઉપયોગ ઘણીવાર ભુલોથી પણ થઈ શકે છે, તેથી સાવચેતી રાખવી જરૂરી છે.

ઇંટિગ્રેશનની પદ્ધતિઓ: આંશિક ભિન્ન

આંશિક ભિન્ન પદ્ધતિએ ખાસ કરીને રેશનલ ફંક્શનના ઇંટિગ્રલ્સને ઉકેલવા માટે વપરાય છે. આ પદ્ધતિમાં, કોઈ પણ રેશનલ ફંક્શનને સરળ આંશિક ભિન્નોના સરવાળા તરીકે દર્શાવવામાં આવે છે, જેથી દરેક ભિન્નનું સંકલન સરળ બની શકે. ઉદાહરણ તરીકે, (3x+5)/(x²-x-2) ને આંશિક ભિન્નમાં વિભાજિત કરતાં, A/(x-2) + B/(x+1) મળે છે, જ્યાં A અને B ની કિંમત શોધવામાં આવે છે. આ પદ્ધતિ મુખ્યત્વે તે જ્યારે ઉપયોગી બને છે જ્યારે ઇંટિગ્રેન્ડનું છેદબહુપદી ઉત્તરાધિકારીય સમીકરણો ધરાવતું હોય. આ પદ્ધતિ માટે સમીકરણો ઉકેલવાની ક્ષમતા અને અલગ-અલગ કેસોની સમજ જરૂરી છે.

ઇંટિગ્રલ્સના સંયોગ અને ગુણધર્મો

ઇંટિગ્રલ્સ કેટલાક મહત્વપૂર્ણ ગુણધર્મો ધરાવે છે જે ગણતરીને સરળ બનાવે છે. સૌ પ્રથમ, સંકલન સમરૂપી છે: ∫[f(x) ± g(x)]dx = ∫f(x)dx ± ∫g(x)dx. બીજો, ધ્રુવક (constant) ને ઇંટિગ્રલ સ્કેલર ગુણાંક તરીકે લઈ શકાય: ∫k·f(x)dx = k∫f(x)dx. ત્રીજો, ∫dx = x + C. આ ગુણધર્મો ઇંટિગ્રલ્સની ગણતરીમાં મહત્વપૂર્ણ સહાયક છે. ઉદાહરણ તરીકે, ∫(3x² + 2x)dx = 3∫x²dx + 2∫xdx = x³ + x² + C. આ ગુણધર્મોનો ઉપયોગ કરીને જટિલ ઇંટિગ્રલ્સને સરળ ભાગોમાં વિભાજિત કરી શકાય છે. ધ્યાન રાખવું જરૂરી છે કે આ ગુણધર્મો માત્ર મૂળભૂત ઇંટિગ્રલ્સ પર લાગુ પડે છે, અને ખાસ પદ્ધતિઓ જરૂરી હોય છે.

વિશિષ્ટ ઇંટિગ્રલ્સ અને તેમના પરિણામો

કેટલાક ઇંટિગ્રલ્સના પરિણામો વિશિષ્ટ રીતે યાદ રાખવા જેવા છે. મુખ્ય પરિણામોમાં ∫xⁿ dx = xⁿ⁺¹/(n+1) + C (જ્યારે n ≠ -1), ∫eˣ dx = eˣ + C, ∫aˣ dx = aˣ/ln(a) + C, ∫sin x dx = -cos x + C, ∫cos x dx = sin x + C, ∫sec²x dx = tan x + C, ∫cosec²x dx = -cot x + C, ∫sec x tan x dx = sec x + C, ∫cosec x cot x dx = -cosec x + C, ∫1/x dx = ln|x| + C, ∫√x dx = (2/3)x^(3/2) + C, ∫1/√x dx = 2√x + C, ∫e^(ax) dx = (1/a)e^(ax) + C, ∫sin(ax) dx = -(1/a)cos(ax) + C, ∫cos(ax) dx = (1/a)sin(ax) + C. આ પરિણામોનું સચોટ જ્ઞાન ઇંટિગ્રેશનની ગણતરીમાં ખૂબ જ મહત્વપૂર્ણ છે.

વિરિયન સંકલન પદ્ધતિ

વિરિયન સંકલન પદ્ધતિએ ઇંટિગ્રલ્સને ઉકેલવા માટે વપરાતી એક શક્તિશાળી પદ્ધતિ છે, જેમાં ∫u dv = uv - ∫v du સૂત્રનો ઉપયોગ થાય છે. આ પદ્ધતિ ખાસ કરીને બે ફંક્શનના ગુણાકારના ઇંટિગ્રલ્સ માટે ઉપયોગી છે, જ્યાં એક ફંક્શનનું સીધું સંકલન સરળ હોય અને બીજાનું અવકલન સરળ હોય. ઉદાહરણ તરીકે, ∫x cos x dx માં, u = x અને dv = cos x dx લઈને, du = dx અને v = sin x મળે છે. ત્યારબાદ સૂત્ર મુજબ ∫x cos x dx = x sin x - ∫sin x dx = x sin x + cos x + C. આ પદ્ધતિમાં u અને dv ની પસંદગી ખૂબ જ મહત્વપૂર્ણ છે, કારણ કે ખોટી પસંદગીથી ગણતરી વધુ જટિલ બની શકે છે.

નિશ્ચિત ઇંટિગ્રલ્સની પરિભાષા

નિશ્ચિત ઇંટિગ્રલ એ સંકલનનો એક વિશેષ સંકલ્પના છે જેમાં ઇંટિગ્રેન્ડને ચોક્કસ સીમાઓમાં સંકલિત કરવામાં આવે છે. જો F(x) એ f(x) નું પ્રાંતિક અવકલન હોય, તો ∫ₐᵇ f(x) dx = F(b) - F(a). આ સૂત્રને 'ફોунડામેન્ટલ થિયરમ ઓફ કેલ્ક્યુલસ' કહે છે. નિશ્ચિત ઇંટિગ્રલનો ઉપયોગ વક્ર હેઠળનું ક્ષેત્રફળ, ઘનફળ અને અન્ય ભૌતિક રાશિઓની ગણતરી માટે થાય છે. ઉદાહરણ તરીકે, y = x² વક્ર હેઠળ x=0 થી x=1 સુધીનું ક્ષેત્રફળ ∫₀¹ x² dx = [x³/3]₀¹ = 1/3 છે. નિશ્ચિત ઇંટિગ્રલના મૂલ્યને ધન, ઋણ કે શૂન્ય પણ હોઈ શકે છે, જે સીમાઓ પર આધાર રાખે છે.

નિશ્ચિત ઇંટિગ્રલ્સના ગુણધર્મો

નિશ્ચિત ઇંટિગ્રલ્સના કેટલાક મહત્વપૂર્ણ ગુણધર્મો છે: (1) ∫ₐᵇ f(x)dx = -∫ᵇₐ f(x)dx, (2) ∫ₐᵃ f(x)dx = 0, (3) ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b-x)dx, (4) ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a-x)dx, (5) ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx, જો f(-x)=f(x) હોય, (6) ∫₋ₐᵃ f(x)dx = 0, જો f(-x)=-f(x) હોય. આ ગુણધર્મો નિશ્ચિત ઇંટિગ્રલ્સની ગણતરીને સરળ બનાવે છે. ઉદાહરણ તરીકે, ∫₋₁¹ x³ dx = 0, કારણ કે x³ એ વિષમ ફંક્શન છે. આ ગુણધર્મોનો ઉપયોગ ખાસ કરીને સંમિત સીમાઓવાળા ઇંટિગ્રલ્સમાં ફાયદાકારક થાય છે.

વક્રો હેઠળનું ક્ષેત્રફળ

ઇંટિગ્રલ્સનો ઉપયોગ વક્રો હેઠળનું ક્ષેત્રફળ શોધવા માટે થાય છે. જો y = f(x) એ x=a અને x=b વચ્ચેનો વક્ર હોય, તો વક્ર અને x-અક્ષ વચ્ચેનું ક્ષેત્રફળ A = |∫ₐᵇ f(x)dx| થાય. જો વક્ર x-અક્ષની ઉપર હોય, તો સીધું સંકલન કરતાં ધન ક્ષેત્રફળ મળે; જો નીચે હોય, તો ઋણ ક્ષેત્રફળ મળે, જેથી દરેક અંશાત્ ક્ષેત્રફળ લેવા માટે absolute value લેવી પડે. ઉદાહરણ તરીકે, y=x² અને y=0, x=1 વચ્ચેનું ક્ષેત્રફળ ∫₀¹ x² dx = 1/3 છે. જ્યારે બે વક્રો y=f(x) અને y=g(x) વચ્ચેનું ક્ષેત્રફળ શોધવું હોય, તો A = ∫ₐᵇ |f(x)-g(x)|dx સૂત્ર વાપરવામાં આવે છે.

વિકલ સમીકરણોનો ઉકેલ

ઇંટિગ્રલ્સનો ઉપયોગ પ્રથમ ક્રમના અને પ્રથમ ડિગ્રીના વિકલ સમીકરણોનો ઉકેલ મેળવવા માટે થાય છે. સામાન્ય રીતે, vિકલ સમીકરણોને અલગ કરી શકાય તેવા રૂપમાં લખીને, બંને બાજુનું સંકલન કરવામાં આવે છે. ઉદાહરણ તરીકે, dy/dx = 2x એક વિકલ સમીકરણ છે, જેને dy = 2x dx તરીકે લખી શકાય. બંને બાજુ સંકલન કરતાં, ∫dy = ∫2x dx ⇒ y = x² + C, જે સામાન્ય ઉકેલ છે. આ પદ્ધતિ પ્રથમ ક્રમના વિકલ સમીકરણો માટે અનુરૂપ છે. ઉચ્ચ ક્રમના વિકલ સમીકરણો માટે અન્ય પદ્ધતિઓનો ઉપયોગ થાય છે, પણ મૂળભૂત સંકલન જ્ઞાન જરૂરી છે.

ઇંટિગ્રેશનની અન્ય પદ્ધતિઓ

ઇંટિગ્રેશનની કેટલીક અન્ય પદ્ધતિઓ પણ છે જે GUJCET સિલેબસમાં આવે છે. તેમાં ટ્રિગોનોમેટ્રિક પ્રતિસ્થાપન (જેમ કે x = a tan θ), ઉપયોગિતાવાદી ઇંટિગ્રલ્સ (જેમ કે ∫eˣ[f(x)+f'(x)]dx = eˣf(x)+C), અને ઘાતાંકીય ફંક્શનના ઇંટિગ્રલ્સ આવે છે. ટ્રિગોનોમેટ્રિક પ્રતિસ્થાપન ખાસ કરીને √(a²-x²), √(a²+x²), √(x²-a²) જેવા પદો ધરાવતા ઇંટિગ્રલ્સ માટે ઉપયોગી છે. ઉદાહરણ તરીકે, ∫dx/√(a²-x²) માં x = a sin θ લેતાં, ઇંટિગ્રલ સરળ બને છે. આ પદ્ધતિઓનું સચોટ જ્ઞાન જટિલ ઇંટિગ્રલ્સ ઉકેલવામાં મદદરૂપ થાય છે.

⭐ મહત્વના મુદ્દા

  • ઇંટિગ્રેશન એ અવકલનનો વ્યસ્ત સંકલ્પના છે, જેમાં constant ઉમેરાય છે.
  • અવયવીકરણ પદ્ધતિમાં ઇંટિગ્રલને અલગ-અલગ પદોમાં વિભાજિત કરવામાં આવે છે.
  • પ્રતિસ્થાપન પદ્ધતિમાં ચલ બદલીને ઇંટિગ્રલ સરળ બનાવવામાં આવે છે.
  • આંશિક ભિન્ન પદ્ધતિ રેશનલ ફંક્શનના ઇંટિગ્રલ્સ ઉકેલવા માટે વપરાય છે.
  • વિરિયન સંકલન પદ્ધતિ ∫u dv = uv - ∫v du સૂત્ર પર આધારિત છે.
  • નિશ્ચિત ઇંટિગ્રલની કિંમત ધન, ઋણ કે શૂન્ય હોઈ શકે છે.
  • સમ ફંક્શન માટે ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx થાય છે.
  • વિષમ ફંક્શન માટે ∫₋ₐᵃ f(x)dx = 0 થાય છે.
  • વક્ર હેઠળનું ક્ષેત્રફળ ઇંટિગ્રલનો મુખ્ય ઉપયોગ છે.
  • વિકલ સમીકરણોનો ઉકેલ સંકલન દ્વારા મેળવી શકાય છે.
