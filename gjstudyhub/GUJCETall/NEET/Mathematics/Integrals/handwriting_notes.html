સંકલન (Integrals) — પ્રવિધેયોનું સંકલન

🧪 GUJCET — Gujarati • Mathematics • Integrals

પ્રસ્તાવના: સંકલન શું છે?
સંકલન એ વિકલનનો વિपरીત ક્રિયા (Antiderivative / Inverse of Differentiation) છે.
જો d/dx [F(x)] = f(x) હોય, તો ∫f(x) dx = F(x) + C. આ C અચળાંક સંકલન અચળ (Constant of Integration) છે.
∫f(x) dx = F(x) + C, જ્યાં F'(x) = f(x)
📝 📝 યાદ રાખો: સંકલન કરતી વખતે હંમેશા '+C' ઉમેરો — વિસરી જશો તો નંબર ઘટશે!
વિકલનસંકલન — વિપરીત પ્રક્રિયા
મૂળભૂત સંકલન સૂત્રો (Standard Integration Formulas)
∫xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ −1
∫x⁻¹ dx = ∫(1/x) dx = ln|x| + C
∫eˣ dx = eˣ + C
∫aˣ dx = aˣ/ln(a) + C, a > 0, a ≠ 1
∫sin x dx = −cos x + C અને ∫cos x dx = sin x + C
∫sec²x dx = tan x + C
∫cosec²x dx = −cot x + C
∫sec x tan x dx = sec x + C
∫cosec x cot x dx = −cosec x + C
∫sec x dx = ln|sec x + tan x| + C ∫cosec x dx = ln|cosec x − cot x| + C
∫tan x dx = ln|sec x| + C = −ln|cos x| + C
∫sin⁻¹x dx = x sin⁻¹x + √(1−x²) + C ∫cos⁻¹x dx = x cos⁻¹x − √(1−x²) + C
∫1/√(1−x²) dx = sin⁻¹x + C ∫1/(1+x²) dx = tan⁻¹x + C
∫1/(x√(x²−1)) dx = sec⁻¹x + C ∫1/(x√(x²−1)) dx = cosec⁻¹x + C
∫1/√(x²−a²) dx = ln|x + √(x²−a²)| + C
∫1/√(a²−x²) dx = sin⁻¹(x/a) + C
∫1/(a²+x²) dx = (1/a) tan⁻¹(x/a) + C
📝 📝 આ સૂત્રો યાદ રાખવી બહુ જરૂરી છે — GUJCET માં 40%+ સીધા સૂત્ર પર આધારિત પ્રશ્નો આવે છે.
વિકલન સૂત્રોસંકલન સૂત્રો — દરેક વિકલન સૂત્રનું વિપરીત સૂત્ર યાદ કરો
સંકલનના ગુણધર્મો (Properties of Integration)
∫[f(x) ± g(x)] dx = ∫f(x) dx ± ∫g(x) dx
∫k·f(x) dx = k ∫f(x) dx, k અચળાંક છે
સંકલન રેખીય (Linear) છે — સામેલ/ઘટાડો અને અચળાંક બહાર કાઢી શકાય.
∫f'(x)/f(x) dx = ln|f(x)| + C
∫f'(x)·[f(x)]ⁿ dx = [f(x)]ⁿ⁺¹/(n+1) + C, n ≠ −1
📝 📝 આ ગુણધર્મો વડે જટિલ પ્રવિધેયોને સાદા રૂપમાં ફેરવી શકાય છે.
પદ્ધતિ ૧: આવર્તન પદ્ધતિ (Substitution Method)
જ્યારે ∫f(g(x))·g'(x) dx જેવું સ્વરૂપ મળે, ત્યારે u = g(x) લઈએ છીએ.
u = g(x) ધારો → du = g'(x) dx → ∫f(u) du = F(u) + C → પછી u ની જગ્યાએ g(x) મૂકો.
સૌથી વધુ વપરાતી પદ્ધતિ! ગુજરાતી માધ્યમના પ્રશ્નોમાં 50%+ પ્રશ્નો આ પદ્ધતિથી ઉકેલાય છે.
∫2x·cos(x²) dx → u = x², du = 2x dx → ∫cos u du = sin u + C = sin(x²) + C
∫x·√(x²+1) dx → u = x²+1 → (1/2)∫u^(1/2) du = (1/2)·(2/3)u^(3/2) + C = (1/3)(x²+1)^(3/2) + C
∫e^(sin x)·cos x dx → u = sin x → ∫e^u du = e^u + C = e^(sin x) + C
📝 📝 u = ax+b, u = sin x, u = e^x, u = log x વગેરે પસંદગી સૂત્રો યાદ રાખો.
Chain Rule (વિકલન)Substitution (સંકલન) — Chain Rule નું વિપરીત
પદ્ધતિ ૨: કુત્તક (ILATE) નિયમ વડે ભાગેર સંકલન (Integration by Parts)
∫u·v dx = u∫v dx − ∫(du/dx · ∫v dx) dx — આ સૂત્ર 'ભાગેર સંકલન' (Integration by Parts) કહેવાય છે.
ILATE નિયમ: u પસંદ કરતી વખતે આ ક્રમ મુજબ પહેલી આવતી પ્રવિધેય પસંદ કરો: I (Inverse Trig) > L (Logarithmic) > A (Algebraic) > T (Trigonometric) > E (Exponential)
∫x·eˣ dx = x·eˣ − eˣ + C = eˣ(x−1) + C
∫x·sin x dx = −x·cos x + sin x + C
∫x²·eˣ dx = eˣ(x² − 2x + 2) + C
∫log x dx = x log x − x + C
∫sin⁻¹x dx = x sin⁻¹x + √(1−x²) + C
📝 📝 ILATE વડે u અને v ની સાચી પસંદગી કરો — ખોટી પસંદગીથી સંકલન વધુ જટિલ બને!
Product Rule (વિકલન)Integration by Parts (સંકલન) — Product Rule નું વિપરીત
પદ્ધતિ ૩: અપૂર્ણ ભાગશાહી પદ્ધતિ (Partial Fractions)
જ્યારે પ્રવિધેય rational function (અપૂર્ણાંક) હોય અને છેદના અવયવો સરળ હોય, ત્યારે આ પદ્ધતિ ઉપયોગી થાય છે.
પ્રકાર ૧: છેદના અવયવો વાસ્તવિક અને અલગ હોય → A/(x−a) + B/(x−b)
પ્રકાર ૨: છેદમાં પુનરાવર્તિત અવયવ હોય → A/(x−a) + B/(x−a)²
પ્રકાર ૩: છેદ અવિભાજ્ય દ્વિઘાત (irreducible quadratic) હોય → (Ax+B)/(ax²+bx+c)
p(x)/[(x−a)(x−b)] = A/(x−a) + B/(x−b) → A = p(a)/(a−b), B = p(b)/(b−a)
∫1/(x²−a²) dx = (1/2a) ln|(x−a)/(x+a)| + C → આ અપૂર્ણ ભાગશાહી વડે વ્યુત્પન્ન થાય છે.
અપૂર્ણ ભાગશાહી પહેલાં જરૂરી છે કે અંશની ડિગ્રી < છેદની ડિગ્રી હોય. નહીંતર સૌ પ્રથમ ભાગાકાર કરો.
📝 📝 અપૂર્ણ ભાગશાહીના 3 પ્રકાર યાદ રાખો — GUJCET માં 1-2 પ્રશ્નો ફક્ત આ પરથી આવે છે.
વિશિષ્ટ સંકલન (Special Integrals — યાદ રાખવા જેવા)
∫1/√(x²±a²) dx = ln|x + √(x²±a²)| + C
∫√(x²±a²) dx = (x/2)√(x²±a²) ± (a²/2)ln|x + √(x²±a²)| + C
∫√(a²−x²) dx = (x/2)√(a²−x²) + (a²/2)sin⁻¹(x/a) + C
∫√(tan x) dx અને ∫√(cot x) dx — આ પ્રશ્નો GUJCET માં આવે છે, t² = tan x ધરી ઉકેલો.
∫(f(x) ± f'(x))eˣ dx = eˣ[f(x) ± f'(x)] + C → આ એક ખાસ સૂત્ર છે, યાદ રાખો!
∫(f(x) + x·f'(x)) dx = x·f(x) + C
📝 📝 આ વિશિષ્ટ સંકલનો GUJCET માં સીધા અથવા પરોક્ષ રીતે પૂછાયા છે — ઉદાહરણો સાથે પ્રॅक्टિસ કરો.
નિશ્ચિત સંકલન (Definite Integral)
જો F(x) એ f(x) નું પ્રતિઅવકલન (antiderivative) હોય, તો: ∫ₐᵇ f(x) dx = F(b) − F(a) — આ ન્યૂટન-લેઇબનિઝ સૂત્ર (Newton-Leibniz Theorem) છે.
∫ₐᵇ f(x) dx = F(b) − F(a), જ્યાં F'(x) = f(x)
નિશ્ચિત સંકલનનું પરિણામ એક ચોક્કસ સંખ્યા (number) છે — અચળાંક C નહીં!
∫ₐᵇ f(x) dx = ∫ₐᵇ f(t) dt — ચલ (variable) નું નામ બદલવાથી મૂલ્ય બદલાતું નથી.
📝 📝 નિશ્ચિત સંકલનમાં '+C' લખવું ન પડે — ફક્ત F(b) − F(a) જ ગણો.
નિશ્ચિત સંકલનના ગુણધર્મો (Properties of Definite Integrals)
∫ₐᵇ f(x) dx = −∫ᵦₐ f(x) dx
∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx — સૌથી મહત્વપૂર્ણ ગુણધર્મ!
∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx → ઉદા: ∫₀ᵖ sin x/(sin x + cos x) dx = π/4
∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx
સમ પ્રવિધેય (Even): ∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx, જો f(−x) = f(x) વિષમ પ્રવિધેય (Odd): ∫₋ₐᵃ f(x) dx = 0, જો f(−x) = −f(x)
સમ/વિષમ ગુણધર્મ (Even/Odd Property) GUJCET માં ખૂબ વારંવાર આવે છે — ∫₋ₐᵃ ન જોતાની સાથે જ f(−x) ચકાસો!
∫ₐᵇ f(x) dx = ∫ₐᶜ f(x) dx + ∫ᶜᵇ f(x) dx, અહીં c એ any real number
∫₀²ᵃ f(x) dx = ∫₀ᵃ [f(x) + f(2a−x)] dx
∫₀²ᵃ f(x) dx = 2∫₀ᵃ f(x) dx, જો f(2a−x) = f(x) (even about x=a) ∫₀²ᵃ f(x) dx = 0, જો f(2a−x) = −f(x) (odd about x=a)
📝 📝 f(a+b−x) ગુણધર્મ સૌથી વધુ ઉપયોગી — લંબાઈ વાળા પ્રશ્નો 30 સેકન્ડમાં ઉકેલાય!
f(x) + f(a−x)∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx
વિકલન અને સંકલન વચ્ચેનો સંબંધ
∫f(x) dx = ∫f(u) du જ્યાં u = g(x) અને du = g'(x) dx.
d/dx [∫f(x) dx] = f(x) ∫f'(x) dx = f(x) + C
d/dx [∫ₐˣ f(t) dt] = f(x) — Fundamental Theorem of Calculus ( ભાગ ૧ )
જો F(x) = ∫ₐˣ f(t) dt, તો F'(x) = f(x). આ સંબંધ ઉલટાક્રમે પણ વાપરો.
📝 📝 Fundamental Theorem of Calculus બે ભાગમાં છે — GUJCET માં ભાગ ૧ વધુ વપરાય છે.
GUJCET માટે મહત્વના ઉદાહરણો
∫dx/(sin x · sin(x+α)) = (1/sin α) ln|sin(x+α)/sin x| + C
∫1/(a cos x + b sin x) dx — t = tan(x/2) લઈને ઉકેલો (Weierstrass substitution).
∫1/(a + b sin x) dx અને ∫1/(a + b cos x) dx — આ પણ t = tan(x/2) પદ્ધતિથી ઉકેલાય.
∫1/(1+cos x) dx = tan(x/2) + C ∫1/(1−cos x) dx = −cot(x/2) + C
∫1/(1+sin x) dx = −cot(x/2 + π/4) + C = tan(x/2 − π/4) + C
∫sin²x dx = x/2 − (sin 2x)/4 + C ∫cos²x dx = x/2 + (sin 2x)/4 + C → sin²x = (1−cos 2x)/2, cos²x = (1+cos 2x)/2
∫sin³x dx = −cos x + (cos³x)/3 + C ∫cos³x dx = sin x − (sin³x)/3 + C
