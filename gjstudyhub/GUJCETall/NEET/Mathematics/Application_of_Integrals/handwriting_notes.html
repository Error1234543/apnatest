સંકલનના પ્રયોગો (Application of Integrals)

🧪 GUJCET — Gujarati • Mathematics • Application of Integrals

પ્રસ્તાવના (Introduction)
જ્યારે આપણે વક્ર, અક્ષો અને ઉભી રેખાઓ દ્વારા ઘેરાયેલા ક્ષેત્રફળની ગણતરી કરવી હોય, ત્યારે સંકલનનો ઉપયોગ થાય છે.
📝 યાદ રાખો: સંકલન એ વિલોમી પ્રક્રિયા છે, જે પરીમાણના સર્વાંગીણીકરણની પ્રક્રિયા દર્શાવે છે.
વક્રનું સમીકરનક્ષેત્રફળ શોધવા માટે સંકલનનો ઉપયોગ
વક્ર દ્વારા ઘેરાયેલું ક્ષેત્રફળ = ∫[a,b] f(x) dx — જ્યાં y = f(x) એ વક્ર છે અને a, b એ યામ અક્ષ પરની મર્યાદાઓ છે.
A = ∫ₐᵇ y dx
વક્ર દ્વારા ઘેરાયેલું ક્ષેત્રફળ (Area Under the Curve)
જ્યારે વક્રનો આલેખ દોરીએ, ત્યારે તે x-અક્ષ, y-અક્ષ અને મર્યાદા રેખાઓ વચ્ચે ઘેરાયેલું વિસ્તાર શોધી શકાય છે.
જો વક્ર x-અક્ષ ઉપર હોય, તો ક્ષેત્રફળ ધન અને જો નીચે હોય તો ઋણ ગણવામાં આવે છે, પણ ભૌમિતિક દ્રષ્ટિએ ક્ષેત્રફળ હંમેશા ધન જ ગણાય.
x-અક્ષ અને વક્ર y = f(x) વચ્ચેનું ક્ષેત્રફળ = ∫ₐᵇ f(x) dx
A = ∫ₐᵇ y dx = ∫ₐᵇ f(x) dx
📝 GUJCET Tip: જ્યારે f(x) >= 0 હોય, ત્યારે સીધું સંકલન કરવાનું. જો f(x) < 0 હોય, તો |f(x)| લેવું.
y-અક્ષ સંદર્ભે ક્ષેત્રફળ (Area with respect to y-axis)
જો વક્રને y ના ફલનરૂપે પेश કર્યો હોય, એટલે કે x = g(y), તો ક્ષેત્રફળ y-અક્ષ પર ગણી શકાય.
A = ∫𝒸ᵈ x dy = ∫𝒸ᵈ g(y) dy
y-અક્ષ અને વક્ર x = g(y) વચ્ચેનું ક્ષેત્રફળ = ∫ₑᶠ g(y) dy
જ્યારે વક્ર y-અક્ષની આસપાસ સંકલન કરવાનું હોય, ત્યારે ડેટા y મર્યાદાઓમાં બદલાય છે.
📝 બંને રીતે ગણતરી શક્ય છે — x ના સંદર્ભે અથવા y ના સંદર્ભે.
સરળ રેખા અને વક્ર વચ્ચેનું ક્ષેત્રફળ
બે વક્રો y = f(x) અને y = g(x) વચ્ચેનું ક્ષેત્રફળ = ∫ₐᵇ |f(x) - g(x)| dx
क्षेत्रफल = ∫ₐᵇ (ઉપરનું વક્ર - નીચેનું વક્ર) dx
જો f(x) ≥ g(x) for all x ∈ [a, b], then Area = ∫ₐᵇ [f(x) - g(x)] dx
પ્રથમ રેખા અને વક્રનો છેદબિંદુ શોધી, પછી સંકલનની મર્યાદાઓ નક્કી કરવી પડે.
📝 GUJCET Tip: છેદબિંદુ શોધવા માટે f(x) = g(x) ઉકેલો.
સામાન્ય વક્રો: સીધી રેખાઓ (Straight Lines)
y = mx + c પ્રકારની રેખા અને x-અક્ષ વચ્ચે ઘેરાયેલું ત્રિકોણાકાર ક્ષેત્રફળ સરળતાથી શોધી શકાય છે.
A = ∫ₐᵇ (mx+c) dx = [½ m x² + c x]ₐᵇ
આ પ્રકારના પ્રશ્નોમાં રેખા અને અક્ષો વચ્ચે રચાતા ત્રિકોણનું ક્ષેત્રફળ શોધવાનું કહેવાય છે.
ત્રિકોણનું ક્ષેત્રફળ = ½ × ભૂમિ × ઊંચાઈ પણ ચકાસણી તરીકે વાપરી શકાય.
વર્તુળ (Circle) નું ક્ષેત્રફળ
vrttḷuñce sāmīkaraṇam x² + y² = r², jṇāḍe kṣetraphaḷa shodhvaḍe saṅkalanprayoḍog kāmalā.
A = ∫₋ᵣʳ y dx = ∫₋ᵣʳ √(r² - x²) dx = πr²
સંપૂર્ણ વર્તુળનું ક્ષેત્રફળ πr² મળે છે. અંશશ: પ્રથમ ચતુર્થાંશનું ક્ષેત્રફળ શોધી, 4 ગુણાવતા સમગ્ર ક્ષેત્રફળ મળે.
Quarter circle = (1/4) × πr²
📝 vrttḷuṇa kṣetraphaḷa eka siddhānta che: A = πr². Samīkaraṇa vartṭula the sīdhāntaka śikhyo chhe.
પરવલય (Parabola) નું ક્ષેત્રફળ
પરવલયનો મૂળભૂત આકાર y² = 4ax અથવા x² = 4ay છે.
y² = 4ax → y = ±2√(ax); kṣetraphaḷa = ∫₂√(ax) dx
પરવલય અને સરળ રેખા દ્વારા ઘેરાયેલું ક્ષેત્રફળ શોધવા માટે છેદબિંદુઓ શોધી સંકલન કરવું પડે છે.
paravala aur sidha rekha no gherayelō kṣetrapahalam sabase adhik puchchhano jato che.
📝 GUJCET Tip: સીધી રેખા સાથે ઘેરાયેલા વિસ્તારમાં ત્રિકોણ/વર્તુળના અંશ જેવું વિસ્તાર હોય છે.
લંબોત્તલ (Ellipse) નું ક્ષેત્રફળ
લંબોત્તલનું પ્રમાણભૂત સમીકરણ x²/a² + y²/b² = 1 છે.
A = ∫₋ₐᵃ b√(1 - x²/a²) dx = πab
લંબોત્તલ એ એક વિસ્તૃત વક્ર છે, જે બંને અક્ષો પર સમમિત ધરાવે છે.
Ellipse area = π × major semi-axis × minor semi-axis = πab
📝 vrttḷu eka dhikarak ellipta che jathā a = b hota.
અધિસ્તંભ (Hyperbola) નું ક્ષેત્રફળ
હાયપરબોલાનું પ્રમાણભૂત સમીકરણ x²/a² - y²/b² = 1 છે.
A = ∫ₐˣ b√(x²/a² - 1) dx, pache pramanit ankan upyog karavu.
Hyperbola એ વક્ર છે જે બે શાખા ધરાવે છે, અને ક્ષેત્રફળની ગણતરી માટે ઉચ્ચ સ્તરનું સંકલન જરૂરી છે.
📝 Hyperbola no area calculate karva mate logarithmic function no upyog thaye chhe.
પરવલય, લંબોત્તલ અને અધિસ્તંભમાં તફાવત (Difference)
Parabola એક જ શાખા ધરાવે છે, Ellipse બંધ વક્ર છે, અને Hyperbola ની બે અનંત શાખાઓ છે.
Parabola: y² = 4ax, Ellipse: x²/a² + y²/b² = 1, Hyperbola: x²/a² - y²/b² = 1
Discriminant-based identification B² - 4AC < 0 (Ellipse), = 0 (Parabola), > 0 (Hyperbola)
Exam me in te pratitekno graph niveshan karvu jaruri che.
📝 Differentiation by curves is based on geometry and integration limits.
સંયુક્ત વક્રોનું ક્ષેત્રફળ (Combined Areas)
બે કે વધુ વક્રો વચ્ચે ઘેરાયેલું ક્ષેત્રફળ શોધવા માટે, પહેલા તેમના છેદબિંદુઓ શોધવા પડે.
A = ∫ₐᵇ [f(x) - g(x)] dx, where f(x) ≥ g(x) in [a,b]
બે વક્રો વચ્ચેનું ક્ષેત્રફળ = ઉપરનું ક્ષેત્રફળ - નીચેનું ક્ષેત્રફળ
જ્યારે વક્રો અક્ષને છેદે, ત્યારે વિભાગીય સંકલન (piecewise integration) કરવું પડે.
📝 GUJCET Tip: Graph draw kare, intersection points find karo, phir integrate.
કેલિબ્રેટેડ ડેટાથી ક્ષેત્રફળ (Numerical Methods)
Jada prashnona data tabella rup ma delu hote, trayapiyo, simpson's rule ya trapezoidal rule no upyog karva ma aave che.
Trapezoidal Rule: A ≈ (h/2)[y₀ + yₙ + 2(y₁ + y₂ + ... + yₙ₋₁)]
Trapezoidal approximation is faster and often sufficient for multiple-choice questions.
simpson's rule more accurate but needs even number of intervals.
📝 Numerical methods are useful when exact integration is complicated.
પ્રતિકલ્પિત ઉદાહરણો (Illustrative Examples)
Example 1: y = x², 0 ≤ x ≤ 2 નીચેનું ક્ષેત્રફળ = ∫₀² x² dx = 8/3 sq units.
Example 2: y = 2x + 3, x=0 to x=4 નીચેનું ક્ષેત્રફળ = ∫₀⁴ (2x+3)dx = 40 sq units.
ઉદાહરણો માટે ગ્રાફ દોરવો અને યોગ્ય સીમાઓ શોધવી ઘણી જરૂરી છે.
Area under line y = mx + c from x=a to x=b = (m/2)(b²-a²) + c(b-a)
GUJCET માટે મહત્વના વિષયો
પ્રત્યેક પ્રશ્નમાં વક્રનું સમીકરણ, યોગ્ય અક્ષ, અને મર્યાદાઓ ઓળખવી પડે છે.
સામાન્ય ભૂલો: ખોટી સીમાઓ, વક્રની ગેરહાજરી, ઋણ ક્ષેત્રફળ ગણવું.
📝 Always double-check whether the region lies above or below the axis.
સારાંશ (Summary)
સંકલનનો ઉપયોગ વક્ર દ્વારા ઘેરાયેલા ક્ષેત્રફળ શોધવા માટે થાય છે.
x-અક્ષ અને y-અક્ષ બંને માટે સૂત્રો અલગ છે પણ સરળ છે.
Area = ∫ y dx (x-axis) || Area = ∫ x dy (y-axis)
વર્તુળ, પરવલય, લંબોત્તલ અને અધિસ્તંભ — આ બધાના ક્ષેત્રફળની પદ્ધતિ સમાન છે.
