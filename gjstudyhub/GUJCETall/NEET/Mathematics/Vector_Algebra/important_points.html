સદિશ બીજગણિત — મહત્વના બિંદુઓ

🧪 GUJCET — Gujarati • Mathematics • Vector Algebra

⭐ મહત્વના મુદ્દા

અદિશ રાશિ અને સદિશ રાશિ વચ્ચેનો તફાવટ સ્પષ્ટ રાખો. દૃષ્ટાંત: દળ (અદિશ) વિરુદ્ધ બળ (સદિશ).
GUJCET માં MCQ અને કલન પ્રકારના પ્રશ્નો આધારથી આવે છે.
એકમ સદિશ (Unit vector) નો ગુણોત્તર સ્વરૂપ: એકમ સદિશ = સદિશ / |સદિશ|, એટલે કે ê = r⃗ / |r⃗|. i⃗, j⃗, k⃗ એ અનુક્રમે x, y, z અક્ષો પરના એકમ સદિશો છે.
આ મૂળભૂત પરિભાષા પ્રત્યેક વર્ષે પરીક્ષામાં હાજર રહે છે.
સ્થାନ સદિશ (Position vector): કોઈ પણ બિંદુ P(x, y, z) નો મૂળબિંદુ O થી સ્થាន સદિશ OP⃗ = xi⃗ + yj⃗ + zk⃗.
બહુપ્રાય કોઓર્ડિનેટ ભૂમિતિના પ્રશ્નોનો આધાર.
બે બિંદુઓ A અને B ને જોડતો સદિશ AB⃗ = b⃗ - a⃗, જ્યાં a⃗ અને b⃗ અનુક્રમે A અને B ના સ્થાન સદિશો છે.
રેખાના સદિશ સમીકરણ માટે આ પરિણામ অপরিહાર્ય છે.
સદિશોનો સરવાળો: ત્રિભુજ નિયમ (AB⃗ + BC⃗ = AC⃗) અને સમાંતરબાજુ ચતુષ્કોણ નિયમ. ઉપરાંત, સદિશ સરવાળો કોમ્યુટેટિવ (a⃗ + b⃗ = b⃗ + a⃗) અને એસોસિએટિવ (a⃗ + (b⃗ + c⃗) = (a⃗ + b⃗) + c⃗) છે.
પ્રવાહી સ્વરૂપના પ્રશ્નો અને ગતિ-સંબંધી પ્રશ્નોમાં આવે છે.
સદિશનો ગુણાકાર અદિશથી: λ(a⃗ + b⃗) = λa⃗ + λb⃗ અને (λ + μ)a⃗ = λa⃗ + μa⃗. |λa⃗| = |λ||a⃗|.
અદિશ ગુણાકારના ગુણધર્મો MCQ માં સીધા પૂછાયા છે.
બે સદિશોનો ડૉટ ગુણાકાર (Dot Product): a⃗ · b⃗ = |a⃗||b⃗|cos θ, જ્યાં θ એ બે સદિશો વચ્ચેનો ખૂણો છે. તેનું મૂલ્ય અદિશ રાશિ છે. i⃗·i⃗ = j⃗·j⃗ = k⃗·k⃗ = 1 અને i⃗·j⃗ = j⃗·k⃗ = k⃗·i⃗ = 0.
એ ખૂબ જ મહત્વનું — ખૂણો શોધવા, લંબતા check કરવા, પ્રક્ષેપ શોધવા તમામમાં ડૉટ ગુણાકાર વપરાય છે.
ડૉટ ગુણાકારની સ્વરૂપ: જો a⃗ = a₁i⃗ + a₂j⃗ + a₃k⃗ અને b⃗ = b₁i⃗ + b₂j⃗ + b₃k⃗, તો a⃗ · b⃗ = a₁b₁ + a₂b₂ + a₃b₃.
અંકગણિતીય ગણતરીવાળા પ્રશ્નો માટે આ સૂત્ર સૌથી વધુ વપરાય છે.
બે સદિશો લંબ (Perpendicular) હશે જો a⃗ · b⃗ = 0. બે સદિશો સમાંતર (Parallel) હશે જો a⃗ × b⃗ = 0⃗ અથવા a⃗ = λb⃗.
લંબતા અને સમાંતરતા શોધવાના પ્રશ્નો વારંવાર પૂછાય છે.
ખૂણો શોધવાનું સૂત્ર: cos θ = (a⃗ · b⃗) / (|a⃗||b⃗|). કોઈપણ બે સદિશો વચ્ચેનો ખૂણો શોધવા આ સૂત્રનો ઉપયોગ થાય છે.
આ એકમી ગણતરી પ્રકારનો પ્રશ્ન GUJCET માં અનિવાર્ય છે.
સદિશ a⃗ નો સદિશ b⃗ પર પ્રક્ષેપ (Projection): a⃗ નો b⃗ પર અભિલંબ પ્રક્ષેપ = (a⃗ · b⃗ / |b⃗|), અને b⃗ નો a⃗ પર અભિલંબ પ્રક્ષેપ = (a⃗ · b⃗ / |a⃗|).
પ્રક્ષેપ સંબંધી પ્રશ્નો અને પાયાની કલન શૈલીના પ્રશ્નો માટે મહત્વપૂર્ણ.
બે સદિશોનો ક્રોસ ગુણાકાર (Cross Product): a⃗ × b⃗ = |a⃗||b⃗|sin θ n̂, જ્યાં n̂ એ a⃗ અને b⃗ પર લંબ એકમ સદિશ છે. ક્રોસ ગુણાકારનું ફળ સદિશ છે.
વેગ, બળ, ટોર્ક જેવી ભૌતિક રાશિઓ સદિશ ગુણાકાર સાથે સંકળાયેલી છે.
ક્રોસ ગુણાકારની ગણતરી: a⃗ × b⃗ = |i⃗ j⃗ k⃗; a₁ a₂ a₃; b₁ b₂ b₃| (નિશ્ચાયક સ્વરૂપે). i⃗×i⃗ = j⃗×j⃗ = k⃗×k⃗ = 0⃗, i⃗×j⃗ = k⃗, j⃗×k⃗ = i⃗, k⃗×i⃗ = j⃗.
ક્રોસ ગુણાકારની ગણતરી MCQ અને કલન બંને પ્રકારમાં આવે છે.
બે સદિશો a⃗ અને b⃗ વડે બનતા સમાંતરબાજુ ચતુષ્કોણનું ક્ષેત્રફળ = |a⃗ × b⃗|. સદિશ a⃗ અને b⃗ વડે બનતા ત્રિકોણનું ક્ષેત્રફળ = ½|a⃗ × b⃗|.
ક્ષેત્રફળના પ્રશ્નો GUJCET માં ઘણીવાર આવે છે, ખાસ કરીને 2D અને 3D માં.
દિશા કોસાઇન (Direction Cosines): જો સદિશ r⃗ = xi⃗ + yj⃗ + zk⃗ હોય, તો તેની દિશા કોસાઇન l = x/r, m = y/r, n = z/r, જ્યાં r = √(x² + y² + z²) અને l² + m² + n² = 1.
દિશા કોસાઇન અને દિશા અનુપાત (Direction Ratios) ની વ્યુત્પત્તિ પ્રત્યેક વર્ષે પૂછાય છે.
સદિશ ગુણાકારના ગુણધર્મો: a⃗ × b⃗ ≠ b⃗ × a⃗ (એન્ટિ-કોમ્યુટેટિવ), a⃗ × (b⃗ + c⃗) = a⃗ × b⃗ + a⃗ × c⃗ (વિતરણ નિયમ).
ગુણધર્મો પર આધારિત MCQ પ્રશ્નો સીધા પૂછાયા છે.
સદિશ ત્રિગુણ ગુણાકાર (Vector Triple Product): a⃗ × (b⃗ × c⃗) = (a⃗ · c⃗)b⃗ - (a⃗ · b⃗)c⃗ (BAC − CAB નિયમ). આને 'મહાન સદિશ ત્રિગુણ ગુણાકાર' કહેવાય છે.
આ સૂત્ર ગુજરાત યુનિવર્સિટી અને GUJCET બંનેમાં પ્રાયઃ આવે છે.
અદિશ ત્રિગુણ ગુણાકાર (Scalar Triple Product): [a⃗ b⃗ c⃗] = a⃗ · (b⃗ × c⃗) = |a₁ a₂ a₃; b₁ b₂ b₃; c₁ c₂ c₃| (નિશ્ચાયક સ્વરૂપે). તે અદિશ રાશિ છે.
આ બે સદિશો અને એક અદિશ (અથવા ત્રણ સદિશો) વચ્ચેનો સંબંધ શોધવાનો મુખ્ય સાધન છે.
ત્રણેકો સદિશોનિન સમતલીય (Coplanar) હશે જો [a⃗ b⃗ c⃗] = 0 હોય. બેકો સદિશો સરખેખર (Collinear) હશે જો a⃗ × b⃗ = 0⃗ હોય.
સમતલીયતા અને સરખેખરતાના પ્રશ્નો GUJCET માં પ્રાયઃ પૂછાય છે.
વિભાજન સૂત્ર (Section Formula) સદિશ સ્વરૂપે: જો P બિંદુ રેખાખંડ AB ને m:n ના ગુણોત્તરમાં વિભાજિત કરતું હોય, તો OP⃗ = (nb⃗ + ma⃗)/(m+n).
આ સૂત્ર બિંદુની સ્થિતિ શોધવા અને ભૂમિતિ પ્રશ્નોમાં મહત્વનું છે.
ત્રિકોણ ABC નું ક્ષેત્રફળ = ½|AB⃗ × AC⃗| = ½|b⃗ × c⃗|, જ્યાં A(b⃗) અને C(c⃗) ના સ્થાન સદિશો છે. આ સૂત્રથી ત્રિકોણના ક્ષેત્રફળની ગણતરી સરળ બને છે.
ભૂમિતિ સંબંધી ગણતરી પ્રશ્નોમાં આ પ્રકારનો પ્રશ્ન હંમેશા આવે છે.
પ્રવેગ (Work Done) W = F⃗ · d⃗, એટલે કે બળ અને વિસ્થાપનનો ડૉટ ગુણાકાર. આ ડૉટ ગુણાકારનો એક મહત્વપૂર્ણ ભૌતિક પ્રયોગ છે.
ભૌતિકશાસ્ત્ર સાથેનો સંબંધ ગણતરી પ્રકારના પ્રશ્નમાં આવે છે.
સદિશોના સ્થાનાંતરણ (Translation) સમયે a⃗ + b⃗ - b⃗ - a⃗ = 0⃗ જેવી પરિચિત ઓળખો યાદ રાખો. સાથે જ, |a⃗ + b⃗| ≤ |a⃗| + |b⃗| (ત્રિકોણ અસમતા).
સાચું/ખોટું પ્રકારના પ્રશ્નોમાં આ ઓળખો મહત્વની બને છે.
બે સદિશો a⃗ અને b⃗ વચ્ચેનો ખૂણો સમતલમાં: જો a⃗ = a₁i⃗ + a₂j⃗ અને b⃗ = b₁i⃗ + b₂j⃗ હોય, તો θ = cos⁻¹(a⃗ · b⃗ / (|a⃗||b⃗|)).
રેખાઓ વચ્ચેનો ખૂણો શોધવાનું આ પ્રમાણભૂત રીતિ GUJCET માં અગત્યનું છે.
