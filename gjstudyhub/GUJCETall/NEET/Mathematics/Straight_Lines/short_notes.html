સરળ રેખાઓ — ટૂંકા નોંધ (પુનરાવર્તન)

🧪 GUJCET — Gujarati • Mathematics • Straight Lines

📘 વ્યાખ્યાઓ

  • ઢાળ (Slope): રેખાનું ઉપર-નીચેનું વિસ્થાપન અને આડું વિસ્થાપનનો ગુણોત્તર, m = Δy / Δx.
  • ઢાળ: રેખાનું ખૂણાત્મક નતિત્વ, m = tan θ, જ્યાં θ x-અક્ષ સાથેનું ધન દિશામાંનું ખૂણો છે.
  • અવચ્છેદક (Intercept): રેખા x-અક્ષને છેદે તે બિંદુનું x-નિરાંક (a) અથવા y-અક્ષને છેદે તે બિંદુનું y-નિરાંક (b).
  • સમાંતર રેખાઓ: એક જ સપાટી પર કદી મળતી નહીં અને સમાન ઢાળ ધરાવતી બે રેખાઓ.
  • લંબ રેખાઓ: એકબીજા સાથે 90° ખૂણો બનાવતી બે રેખાઓ, જેમના ઢાળનો ગુણાકાર −1 થાય.
  • સરખરેખીય બિંદુઓ: બે કે તેથી વધુ બિંદુઓ એક જ સરળ રેખા પર સ્થિત હોય.

⚡ સૂત્રો

  • ઢાળ સૂત્ર: m = (y₂ − y₁) / (x₂ − x₁) (બે બિંદુઓ (x₁,y₁) અને (x₂,y₂) દ્વારા પસાર થતી રેખા).
  • ઢાળ અને ખૂણો: m = tan θ, જ્યાં θ એ રેખા અને ધન x-અક્ષ વચ્ચેનું ઘડિયાળદિશામાં માપેલો ખૂણો.
  • ઢાળ–અવતરણ સ્વરૂપ: y = mx + c, જ્યાં m ઢાળ અને c y-અવચ્છેદક.
  • ઢાળ–બિંદુ સ્વરૂપ: y − y₁ = m(x − x₁).
  • બે-બિંદુ સ્વરૂપ: (y − y₁)/(x − x₁) = (y₂ − y₁)/(x₂ − x₁).
  • અવચ્છેદક સ્વરૂપ: x/a + y/b = 1, જ્યાં a x-અવચ્છેદક અને b y-અવચ્છેદક.
  • સામાન્ય સ્વરૂપ: Ax + By + C = 0, જ્યાં A અને B એકસાથે શૂન્ય ન હોય.
  • સમાંતર શરત: બે રેખાઓ સમાંતર હોય તો m₁ = m₂.
  • લંબ શરત: બે રેખાઓ લંબ હોય તો m₁ · m₂ = −1.
  • બે રેખાઓ વચ્ચેનો ખૂણો: tan θ = | (m₁ − m₂) / (1 + m₁m₂) |.
  • બિંદુ–થી–રેખા અંતર: d = | Ax₁ + By₁ + C | / √(A² + B²).
  • સમાંતર રેખાઓ વચ્ચે અંતર: d = |C₁ − C₂| / √(A² + B²), જ્યારે રેખાઓ Ax+By+C₁=0 અને Ax+By+C₂=0.
  • ત્રિકોણનું ક્ષેત્રફળ: Area = ½ | x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂) |.
  • વિભાજન સૂત્ર: (x,y) = ( (mx₂+x₁)/(m+1) , (my₂+y₁)/(m+1) ) જ્યારે બિંદુ P રેખાખંડ AB ને m:1 ના ગુણોત્તરમાં વિભાજિત કરે.
  • ભુજા (Projection): રેખાખંડ AB ની x-અક્ષ પર લંબ પ્રક્ષેપ = |x₂−x₁|; y-અક્ષ પર લંબ પ્રક્ષેપ = |y₂−y₁|.

⭐ મુખ્ય તથ્યો

  • x-અક્ષ સંપર્કિત રેખાનો ઢાળ 0 હોય છે.
  • y-અક્ષ સંપર્કિત રેખાનો ઢાળ અવ્યાખ્યાયિત (અનંત) હોય છે; તેનું સમીકરણ x = constant.
  • સમાંતર રેખાઓનો ઢાળ સમાન હોય છે, પણ અવચ્છેદક અલગ હોઈ શકે.
  • લંબ રેખાઓના ઢાળના ગુણાકારનું મૂલ્ય −1 હોય છે (જ્યારે બંને ઢાળ વાસ્તવિક હોય).
  • ત્રણ બિંદુઓ સરખરેખીય હોય તો તેમનાથી બનતા ત્રિકોણનું ક્ષેત્રફળ શૂન્ય હોય.
  • રેખાનું સામાન્ય સ્વરૂપ Ax+By+C=0 માં A, B, C વાસ્તવિક સંખ્યાઓ હોય છે અને A અને B એકસાથે શૂન્ય ન હોય.
  • m = tan θ માં θ નું માપ x-અક્ષની ધન દિશાથી ઘડિયાળદિશામાં હોય છે.
  • રેખાના અવચ્છેદક a અને b હોય, તો રેખાનો અવચ્છેદક સ્વરૂપ x/a + y/b = 1 સ્વીકારે છે.
  • બિંદુ (x₁,y₁) થી રેખા Ax+By+C=0 સુધીનું અંતર શૂન્ય હોય તો બિંદુ રેખા પરનું છે.
  • રેખાખંડના મધ્યબિંદુનું સૂત્ર: ( (x₁+x₂)/2 , (y₁+y₂)/2 ).
  • રેખાનું સામાન્ય સ્વરૂપ અને ઢાળ–અવતરણ સ્વરૂપ વચ્ચે સીધું રૂપાંતરણ: y = (−A/B)x − (C/B).
  • θ = 45° હોય તો |m| = 1; θ = 0° હોય તો m = 0; θ = 90° હોય તો ઢાળ અવ્યાખ્યાયિત.

⚠️ સામાન્ય ભૂલો

  • ढાળના સૂત્રમાં છેદ x₂−x₁ = 0 હોય તો રેખા લંબ હોય છે; ઢાળ અસ્તિત્વ ધરાવતી નથી — આ કિસ્સામાં y = mx+c સ્વીકારતી નથી.
  • લંબ શરત m₁·m₂ = −1 માત્ર ત્યારે લાગુ પડે છે જ્યારે બંને રેખાઓનો ઢાળ વ્યાખ્યાયિત હોય; લંબ/ક્ષિતિજ રેખાઓ માટે અલગ તર્ક જોઈએ.
  • અંતર સૂત્રમાં |Ax₁+By₁+C| નું માનાંક લેવું જરૂરી છે; ચિહ્ન ભૂલથી હટાવવું નહીં.
  • સમાંતર રેખાઓ વચ્ચેનું અંતર સૂત્ર માત્ર ત્યારે લાગુ પડે જ્યારે A અને B સમાન હોય; અલગ હોય તો પહેલાં સ્વરૂપ સમાન બનાવવું.
  • વિભાજન સૂત્રમાં m:1 નો ગુણોત્તર સ્પષ્ટ રીતે લેવો; m = −1 હોય તો સૂત્ર અવ્યાખ્યાયિત થાય છે.
  • ક્ષેત્રફળ સૂત્રમાં બિંદુઓના ક્રમથી ચિહ્ન બદલાય છે, પણ માનાંક લેવાથી ધન મૂલ્ય મળે છે.
  • θ = arctan|…| લેતાં 0 ≤ θ ≤ 90° મળે; પ્રશ્ન મુજબ લઘુ/સ્થૂળ ખૂણો પૂછે તો અલગ તપાસ કરવી.
  • A, B, C ના મૂલ્યો સામાન્ય સ્વરૂપમાં લખતી વખતે Rationaize / Simplify ભૂલશો.
  • બે રેખાઓના સમીકરણો સમાન બનાવીને m₁ = m₂ તપાસવું જોઈએ; છેદ સામાન્ય લેવામાં ભૂલ.
  • ઢાળની ગણતરીમાં બિંદુઓના સંકરણ (order) નું પાલન કરવું; ઉપર/નીચે બદલવું નહીં.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • રેખાના વિવિધ સ્વરૂપો (ઢાળ–અવતરણ, અવચ્છેદક, સામાન્ય) વચ્ચે રૂપાંતરણ શીખવું.
  • સરખરેખીયતાની શરત: બે જોડીકા ઢાળ સમાન હોય અથવા ત્રિકોણનું ક્ષેત્રફળ શૂન્ય.
  • બિંદુ–થી–રેખા અંતરનું સૂત્ર અન્ય પ્રશ્નોમાં મધ્યબિંદુ, પરિધિ, સમાંતર રેખાઓના અંતર જેવા પ્રશ્નોમાં કામ આવે.
  • સમાંતર અને લંબ રેખાઓ શોધવાના પ્રશ્નો ઘણી વાર પૂછાય છે; m₁=m₂ અને m₁m₂=−1 શરતો સ્પષ્ટ રીતે ઉપયોગમાં લેવી.
  • બે રેખાઓ વચ્ચેનો ખૂણો શોધવાનો પ્રશ્ન GUJCET માં સામાન્ય છે; tan θ સૂત્રનો ઉપયોગ કરવો.
  • વિભાજન સૂત્રનો ઉપયોગ ભુજા (midpoint), અનુપાત, અને પ્રતિબિંબ પ્રશ્નોમાં થાય છે.
  • ત્રિકોણનું ક્ષેત્રફળ શૂન્ય હોવું એ ત્રણ બિંદુઓ સરખરેખીય હોવાનું પ્રમાણ છે.
  • રેખાના અવચ્છેદક a, b શોધવા માટે y=0 અને x=0 મૂકીને ઉકેલવું.
  • રેખાનું સમીકરણ શોધવા માટે કોઈ પણ બે અનુચિત માહિતી (ઢાળ+બિંદુ, બે બિંદુ, અવચ્છેદક+ઢાળ) પૂરતાં હોય છે.
  • ઢાળ–બિંદુ સ્વરૂપ અને બે-બિંદુ સ્વરૂપ વચ્ચેનો તફાવત સમજવો અને તેને અનુરૂપ ઉપયોગ કરવો.
