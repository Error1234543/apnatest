સરળ રેખાઓ (Straight Lines)

🧪 GUJCET — Gujarati • Mathematics • Straight Lines

પ્રવેશ — સ્થિતાંક જ્યોમિતીમાં રેખા
બિંદુ, રેખા અને સમતલની વાસ્તવિક દુનિયામાં રેખાનો વિચાર યાદ કરો.
અહીં આપણે સમતલ પર રહેલી સીधी રેખાઓ (Straight Lines) ના ગાણિતિક સ્વરૂપનો અભ્યાસ કરીશું.
⚡ રેખાનો ઢાળ (Slope) એ સૌથી મહત્વનું માન્યું — એ જ રેખાને ચિતરે છે.
ઢાળ (Slope) — સ્વાભાવિક અર્થ
કોઈ પણ રેખા x-અક્ષની ધન દિશા સાથે જે ખૂણો θ બનાવે છે, તેના સ્પર્શકને ઢાળ કહે છે.
m = tan θ (જ્યાં θ ≠ 90°)
જો θ = 0° હોય, તો m = 0 — રેખા x-અક્ષને સમાંતર છે.
જો θ = 90° હોય, તો ઢાળ વ્યાખ્યાયિત નથી — રેખા y-અક્ષને સમાંતર છે.
⚡ ઢાળ ધન હોય → રેખા ઉપરની તરફ જાય (acute angle). ઢાળ ઋણ હોય → રેખા નીચેની તરફ જાય (obtuse angle).
📝 📝 યાદ રાખો: tan θ = ઢાળ m
બે બિંદુઓ પરથી ઢાળ શોધવો
આપેલ બે બિંદુઓ P(x₁, y₁) અને Q(x₂, y₂) માંથી પસાર થતી રેખાનો ઢાળ:
m = (y₂ – y₁) / (x₂ – x₁) , જ્યાં x₂ ≠ x₁
આ સૂત્ર y-અક્ષની દિશામાં ફેરફાર (ઉંચાઈ) / x-અક્ષની દિશામાં ફેરફાર (લંબાઈ) તરીકે યાદ રાખો.
⚡ x₁ = x₂ હોય, તો રેખા શિરોલંબ (vertical) છે અને ઢાળ વ્યાખ્યાયિત નથી.
📝 📝 ઢાળ બિંદુઓના ક્રમ પર આધારિત નથી — ગણતરી બેside પણ સમાન આવે.
દو રેખાઓ વચ્ચેનો ખૂણો
જો m₁ અને m₂ બે રેખાઓના ઢાળ હોય, તો તેમની વચ્ચેનો ખૂણો φ:
tan φ = | (m₂ – m₁) / (1 + m₁·m₂) |
જો 1 + m₁·m₂ = 0, એટલે કે m₁·m₂ = –1, તો φ = 90° — રેખાઓ લંબ છે.
⚡ lંબતાની શરત: m₁ · m₂ = –1 — આ પ્રશ્નોમાં ખૂબ સામાન્ય છે.
સમાન રેખા માટે m₁ = m₂ થાય, તો φ = 0°.
📝 📝 લંબતાની શરત યાદ રાખો: m₁·m₂ = –1
બિંદુ-ઢાળ સ્વરૂપ (Point-Slope Form)
બિંદુ (x₁, y₁) માંથી પસાર થતી અને ઢાળ m ધરાવતી રેખા:
y – y₁ = m (x – x₁)
આ સૌથી બેસિક સ્વરૂપ છે — બીજા બધા સ્વરૂપો આમાંથી મેળવવામાં આવે છે.
⚡ જો બિંદુ અને ઢાળ આપેલ હોય, તો તરત આ સૂત્ર લાગુ કરો.
પ્રવણતા-આડછેદ સ્વરૂપ (Slope-Intercept Form)
જો રેખાનો ઢાળ m હોય અને y-અક્ષ પર છેદાંક c હોય, તો:
y = mx + c
y-અક્ષ પર છેદાંક = c, એટલે રેખા બિંદુ (0, c) માંથી પસાર થાય છે.
જો c = 0 હોય, તો રેખા મૂળબિંદુ (0, 0) માંથી પસાર થાય છે.
⚡ y = mx + c માં m = ઢાળ, c = y-અક્ષ પર છેદાંક.
બિંદુ-બિંદુ સ્વરૂપ (Two-Point Form)
બિંદુઓ (x₁, y₁) અને (x₂, y₂) માંથી પસાર થતી રેખા:
y – y₁ = [(y₂ – y₁)/(x₂ – x₁)] (x – x₁)
આ સ્વરૂપનો ઉપયોગ ત્યારે થાય છે જ્યારે બે બિંદુઓ આપેલ હોય.
⚡ જો x₁ = x₂ હોય, તો રેખા x = x₁ (શિરોલંબ રેખા).
📝 📝 બે બિંદુઓથી સીધો ઢાળ શોધો, પછી point-slope form વાપરો.
અક્ષ-છેદાંક સ્વરૂપ (Intercept Form)
જો રેખા x-અક્ષ પર a એકમ અને y-અક્ષ પર b એકમ છેદતી હોય, તો:
x/a + y/b = 1
અહીં a = x-અક્ષ પર છેદાંક, b = y-અક્ષ પર છેદાંક.
⚡ a અને b શૂન્ય ન હોવા જોઈએ (રેખા બંને અક્ષોને છેદે તેવી શરત).
📝 📝 છેદાંક શોધવા માટે y = 0 મૂકો → x = a; x = 0 મૂકો → y = b
સામાન્ય સ્વરૂપ (General Form)
રેખાનું સૌથી સામાન્ય સ્વરૂપ:
Ax + By + C = 0
A અને B એકસાથે શૂન્ય ન હોવા જોઈએ.
આ સ્વરૂપમાંથી ઢાળ m = –A/B અને y-અક્ષ છેદાંક c = –C/B મળે.
⚡ બધા સ્વરૂપોને Ax + By + C = 0 ના સ્વરૂપમાં લખી શકાય છે.
સમાંતર રેખાઓ (Parallel Lines)
બે રેખાઓ સમાંતર હોય તો તેમના ઢાળ સમાન હોય છે.
m₁ = m₂ ⟹ રેખાઓ સમાંતર
શિરોલંબ રેખાઓ (x = a અને x = b) પણ સમાંતર ગણાય.
⚡ સમાંતર રેખાઓનો ખૂણો 0° છે — એકબીજાને છેદતી નથી.
લંબ રેખાઓ (Perpendicular Lines)
બે રેખાઓ લંબ હોય તો તેમના ઢાળનો ગુણાકાર –1 થાય.
m₁ · m₂ = –1 ⟹ રેખાઓ લંબ
જો એક રેખા શિરોલંબ (undef slope) હોય, તો બીજી સમાંતર (slope = 0) હોય.
⚡ lંબતાની શરત m₁·m₂ = –1 પ્રવર્તક ગણનામાં ઘણી વાર આવે.
બિંદુ પરથી રેખાનું અંતર
બિંદુ (x₁, y₁) પરથી રેખા Ax + By + C = 0 નું લંબ અંતર:
d = | Ax₁ + By₁ + C | / √(A² + B²)
d શૂન્ય હોય તો બિંદુ રેખા પર છે.
⚡ અંતર હંમેશા ધન અથવા શૂન્ય હોય — એટલે નિરપેક્ષ મૂલ્ય.
📝 📝 મૂળબિંદુથી રેખાનું અંતર: d = |C| / √(A² + B²)
સમાંતર રેખાઓ વચ્ચેનું અંતર
બે સમાંતર રેખાઓ Ax + By + C₁ = 0 અને Ax + By + C₂ = 0 વચ્ચેનું અંતર:
d = |C₁ – C₂| / √(A² + B²)
આ સૂત્ર માત્ર ત્યારે લાગુ પડે જ્યારે A અને B બંને સમાંતર રેખાઓમાં સમાન હોય.
⚡ સૌપ્રથમ એકસમાન સ્વરૂપમાં લાવો, પછી સૂત્ર લાગુ કરો.
📝 📝 જો Coefficients અલગ હોય, તો પહેલા સામાન્ય બનાવો.
ત્રિજ્યાબિંદુ પરથી રેખા — વિશેષ સ્થિતિઓ
કેટલાક વિશેષ કેસો યાદ રાખો:
x-અક્ષ પરનું સમીકરણ: y = 0 (ઢાળ = 0, છેદાંક = 0)
y-અક્ષ પરનું સમીકરણ: x = 0 (ઢાળ વ્યાખ્યાયિત નથી)
x-અક્ષને સમાંતર રેખા: y = k (constant)
y-અક્ષને સમાંતર રેખા: x = h (constant)
⚡ x = k રેખાનું x-અક્ષ પર અંતર = k નથી, પરંતુ x-અક્ષ પર છેદાંક = k
ત્રિભુજના બાજુઓની રેખાઓ
ત્રિભુજના બે શિરોબિંદુઓ આપેલ હોય, તો તેમને જોડતી બાજુની રેખાનું સમીકરણ શોધી શકાય.
બિંદુ-બિંદુ સ્વરૂપ વાપરો અને સામાન્ય સ્વરૂપમાં લાવો.
⚡ ત્રિભુજની શિખરો (A, B, C) હોય, તો AB, BC, CA એ ત્રણે રેખાઓના સમીકરણો જરૂરી બને.
ત્રિકોણમિતિ સંબંધ
ધન x-દિશા સાથે રેખાનો ખૂણો θ હોય, તો ઢાળ m = tan θ.
θ = arctan(m)
જો m > 0 → θ સૂક્ષ્મખૂણો (0° < θ < 90°)
જો m < 0 → θ વિકટખૂણો (90° < θ < 180°)
⚡ 180° અને 0° વચ્ચેનો ખૂણો લેવાનો છે — રેખાનો ઢાળ ભૌમિતિક ખૂણા સાથે સીધો સંબંધ ધરાવે છે.
ઉચ્ચ બહુજની બાજુઓ
ચતુષ્કોણ કે ઉચ્ચ બહુભુજની દરેક બાજુ એક રેખા છે.
દરેક બાજુ માટે બે શિરોબિંદુઓ લઈને રેખાનું સમીકરણ મેળવો.
⚡ ચતુષ્કોણની 4 બાજુઓ = 4 રેખાઓના સમીકરણો જરૂરી.
મધ્યબિંદુ અને વિભાજન
બિંદુ P(x₁, y₁) અને Q(x₂, y₂) નું મધ્યબિંદુ M = ((x₁+x₂)/2, (y₁+y₂)/2).
P અને Q ને m:n ગુણોત્તરમાં વિભાજિત કરતું બિંદુ:
R = ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n))
⚡ આ સૂત્ર ઘણી વાર રેખાના સમીકરણ સાથે જોડીને વપરાય છે.
📝 📝 મધ્યબિંદુ એ 1:1 વિભાજન છે.
રેખાઓનો સમૂહ (Family of Lines)
બે રેખાઓ L₁ = 0 અને L₂ = 0 નો સમૂહ: L₁ + λL₂ = 0 (λ ∈ ℝ).
આ સમૂહની દરેક રેખા L₁ અને L₂ ના છેદનબિંદુમાંથી પસાર થાય છે.
⚡ λ ની કોઈ પણ કિંમત રેખા આપે — અને L₂ ની કોઈ પણ રેખા આ સમૂહમાં નથી (પરંતુ L₁ હા)
📝 📝 λ = 0 લેતા L₁ મળે, λ → ∞ લેતા L₂ મળે.
લંબ પાદબિંદુ (Foot of Perpendicular)
બિંદુ P પરથી રેખા L પર લંબ દોરતા જે બિંદુ મળે તેને લંબપાદબિંદુ કહે છે.
પદ્ધતિ: લંબની રેખાનો ઢાળ = –1/m (જો L નો ઢાળ m હોય). પછી છેદનબિંદુ શોધો.
⚡ lંબપાદબિંદુ શોધવા માટે બે રેખાઓના સમીકરણો ઉકેલો.
📝 📝 લંબપાદબિંદુ = બે રેખાઓનું છેદનબિંદુ.
બિંદુનું સમમિત બિંદુ (Image of Point)
બિંદુ P નું રેખા L પરનું સમમિત બિંદુ Q એવું હોય કે L એ PQ નું લંબસમદ્ભાજક હોય.
પદ્ધતિ: L પર લંબપાદબિંદુ M શોધો, પછી M એ PQ નું મધ્યબિંદુ છે.
⚡ Q શોધવા માટે M = (P + Q)/2 સમીકરણ વાપરો.
📝 📝 સમમિત બિંદુ ≠ લંબપાદબિંદુ. M મધ્યબિંદુ છે, Q સમમિત બિંદુ છે.
ચતુષ્કોણનું ક્ષેત્રફળ (રેખા સમીકરણોથી)
ચતુષ્કોણની ચારેય બાજુઓના રેખા સમીકરણો આપેલ હોય, તો ચારેય શિરોબિંદુઓનું છેદનબિંદુ શોધીએ.
ત્રિકોણોમાં વિભાજન કરીને ક્ષેત્રફળ શોધી શકાય.
⚡ શિરોબિંદુઓ શોધ્યા પછી, કોઈ પણ રેખાના સમીકરણનો ઉપયોગ કરીને ત્રિકોણ બનાવી શકાય.
રેખાઓની સંખ્યા અને તેમનો ગુણોત્તર
સરખા ઢાળ ધરાવતી રેખાઓ એકબીજાને સમાંતર છે.
વિરુદ્ધ ઢાળ ધરાવતી રેખાઓ (m અને –m) સમાન મહત્વ ધરાવે છે પણ વિપરીત દિશામાં.
⚡ ઢાળનો વિરુદ્ધ ક્રમ = સમાન ખૂણો પણ વિરુદ્ધ દિશામાં.
રેખા અને વૃત્ત
રેખા અને વૃત્ત વચ્ચેનો સંબંધ શોધવા બિંદુ-રેખા અંતર સૂત્ર વાપરો.
જો અંતર < ત્રિજ્યા → રેખા છેદરેખા છે (secant).
જો અંતર = ત્રિજ્યા → રેખા સ્પર્શક છે (tangent).
જો અંતર > ત્રિજ્યા → રેખા અને વૃત્ત વચ્ચે કોઈ સામાન્ય બિંદુ નથી.
⚡ स्पर्शक હોય, તો અંતર = ત્રિજ્યા r. આ શરત પ્રશ્નોમાં વારંવાર આવે.
📝 📝 d = r ⇔ રેખા स्पर्शक છે.
રેખા સમીકરણોના પ્રકારો — સંક્ષિપ્ત સારાંશ
1. બિંદુ-ઢાળ સ્વરૂપ: y – y₁ = m(x – x₁)
2. પ્રવણતા-આડછેદ સ્વરૂપ: y = mx + c
3. બિંદુ-બિંદુ સ્વરૂપ: y – y₁ = [(y₂–y₁)/(x₂–x₁)](x – x₁)
4. અક્ષ-છેદાંક સ્વરૂપ: x/a + y/b = 1
5. સામાન્ય સ્વરૂપ: Ax + By + C = 0
6. શિરોલંબ સ્વરૂપ: x = h
7. સમાંતર સ્વરૂપ: y = k
⚡ ઉપરના તમામ સ્વરૂપો એકબીજામાંથી મેળવી શકાય. A+By+C=0 સૌથી સામાન્ય છે.
