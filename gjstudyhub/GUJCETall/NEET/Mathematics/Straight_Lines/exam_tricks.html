સમીકરણો દ્વારા સરળ રેખા (Straight Lines) — પરીક્ષા ટ્રિક્સ અને ટૂંકી રીતો

🧪 GUJCET — Gujarati • Mathematics • Straight Lines

🎯 પરીક્ષા ટ્રિક્સ

લંબરૂપ (Slope-Intercept) સ્વરૂપ યાદ રાખો: y = mx + c. જ્યાં m = ઢાળ = tan θ અને c = y-અંતઃખંડ. પ્રશ્નમાં શરતો આપેલ હોય ત્યારે સીધું મૂકો અને m કે c શોધો.
જ્યારે રેખાનો ઢાળ અને y-અંતઃખંડ જાણીતો હોય અથવા શરતોમાંથી બે outમાંથી એક મળતો હોય.
દા.ત.: રેખાનો ઢાળ 2 છે અને y-અંતઃખંડ −3 છે → y = 2x − 3 → 2x − y − 3 = 0.
બિંદુ-અંતઃખંડ સ્વરૂપ (Intercept Form): x/a + y/b = 1. જો x-અંતઃખંડ a અને y-અંતઃખંડ b આપેલા હોય, તો સીધું આ સ્વરૂપ લખો અને સાદું રૂપ આપો.
જ્યારે પ્રશ્નમાં અક્ષો પરના અંતઃખંડો આપેલા હોય.
દા.ત.: x-અંતઃખંડ 4, y-અંતઃખંડ −2 → x/4 + y/(−2) = 1 → x − 2y = 4.
બે બિંદુઓમાંથી રેખાનું સમીકરણ — વિસ્તાર (Determinant) રીત: |x y 1; x₁ y₁ 1; x₂ y₂ 1| = 0. આ પદ્ધતિ ગણતરી ઝડપી કરે છે અને ભૂલ ઓછી થાય છે.
જ્યારે બે બિંદુઓ (x₁,y₁) અને (x₂,y₂) આપેલા હોય.
દા.ત.: (1,2) અને (3,4): x(2−4) − y(1−3) + 1(4−6) = 0 → −2x + 2y − 2 = 0 → x − y + 1 = 0.
ઈંચ-ઇલિમિનેશન (Option Elimination): વિકલ્પોમાંથી દરેક બિંદુ રેખા પર છે કે નહીં તે તપાસવા માટે x, y ની કિંમતો સમીકરણમાં મૂકો. સાચો વિકલ્પ સમીકરણને સંતોષે.
MCQમાં 'પછી કયું બિંદુ રેખા પર આવે છે?' પ્રકારનો પ્રશ્ન.
દા.ત.: રેખા 3x + 4y = 12. વિકલ્પ: (4,0) → 3(4)+4(0)=12 ✓; (0,3) → 3(0)+4(3)=12 ✓; (1,1) → 7≠12 ✗.
સમાંતર રેખાઓ વચ્ચેનું અંતર: |c₁ − c₂| / √(a² + b²). બંને સમીકરણો ax + by + c = 0 સ્વરૂપે લાવો, પછી સૂત્ર મૂકો.
જ્યારે બે સમાંતર રેખાઓ આપેલી હોય અને તેમની વચ્ચેનું લંબ અંતર માંગવામાં આવે.
દા.ત.: 3x + 4y = 9 અને 9x + 12y = 7 → પ્રથમ: 3x+4y−9=0, બીજીને 3 વડે ભાગતા: 3x+4y−7/3=0. અંતર = |−9 − (−7/3)|/5 = |−20/3|/5 = 4/3.
બિંદુ-આલેખીય (Point-Slope) સ્વરૂપ: y − y₁ = m(x − x₁). જો ઢાળ અને એક બિંદુ આપેલ હોય, તો સીધું મૂકો. ઝડપી અને સીધું ઉતરે છે.
ઢાળ m અને બિંદુ (x₁, y₁) જાણીતું હોય.
દા.ત.: m = −1/2, બિંદુ (3, −2) → y + 2 = −½(x − 3) → 2y + 4 = −x + 3 → x + 2y + 1 = 0.
લંબ રેખાનો ઢાળ: m₁ × m₂ = −1, એટલે કે m₂ = −1/m₁. પ્રશ્નમાં લંબ શરત હોય તો ઢાળનું ચિહ્ન ફેરવીને વ્યસ્ત લો.
જ્યારે રેખા A સાથે લંબ હોય તેવી રેખા શોધવાની હોય.
દા.ત.: રેખા 2x − 3y = 5 નો ઢાળ 2/3. તેના લંબ રેખાનો ઢાળ = −3/2.
ત્રિભુજનું ક્ષેત્રફળ — શિરોબિંદુ (x₁,y₁),(x₂,y₂),(x₃,y₃) માટે: ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|. આ સૂત્ર બહુ ઝડપી છે અને ભૂલ ઓછી કરે છે.
ત્રણ બિંદુઓ એકસરખા (collinear) છે કે નહીં તપાસવા અથવા ક્ષેત્રફળ શોધવા.
દા.ત.: (1,2),(3,−1),(5,4): ½|1(−1−4)+3(4−2)+5(2−(−1))| = ½|−5+6+15| = ½×16 = 8 વર્ગએકમ.
ભાગફલા (Section Formula) ટ્રિક: બિંદુ P(rèખા AB ને m:n ના અનુપાતમાં ભાગે છે → P = (mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n). વિધાન ચકાસવા માટે વિકલ્પોમાંથી m:n મૂકીને તપાસો.
જ્યારે રેખાખંડને નિશ્ચિત અનુપાતમાં ભાગતું બિંદુ શોધવું હોય.
દા.ત.: A(2,3), B(8,7). AB ને 2:3માં ભાગતું બિંદુ = ((2×8+3×2)/5, (2×7+3×3)/5) = (22/5, 23/5).
ત્રિભુજનું પરિકેન્દ્ર (Circumcenter) શોધવા: બે લંબ દ્વિભાજકોના સમીકરણ મૂકો અને તેમનું છેદનબિંદુ શોધો. વૈકલ્પિક રીતે, શિરોબિંદુઓથી સમાન અંતર ધરાવતા બિંદુ (h,k) માટે PA² = PB² = PC² પરથી બે સમીકરણો બનાવો.
પરિકેન્દ્ર શોધવાનું હોય.
દા.ત.: A(0,0), B(6,0), C(0,8). PB²=PA² → (h−6)²+k²=h²+k² → h=3. PC²=PA² → h²+(k−8)²=h²+k² → k=4. પરિકેન્દ્ર = (3,4).
ત્રિકોણમિતિય ઢાળ: θ = 135° હોય તો m = tan 135° = −1; θ = 60° હોય તો m = √3. ખૂણાના કિસ્સામાં સીધો tan કિંમત યાદ રાખો.
જ્યારે રેખા અક્ષ સાથે નિશ્ચિત ખૂણો બનાવતી હોય.
દા.ત.: રેખા ધન x-અક્ષ સાથે 45° નો ખૂણો બનાવે → m = tan 45° = 1.
સમીકરણોને સરખામણી કરી ઢાળ/અંતઃખંડ મેળવો: ax + by + c = 0 માં ઢાળ = −a/b, y-અંતઃખંડ = −c/b. પ્રશ્નમાં ઢાળ કે અંતઃખંડ માંગતા હોય તો સીધું −a/b અને −c/b મૂકો.
રેખાનું સામાન્ય સમીકરણ આપેલ હોય અને ઢાળ/અંતઃખંડ માંગવામાં આવે.
દા.ત.: 4x − 3y + 7 = 0 → ઢાળ = −4/(−3) = 4/3, y-અંતઃખંડ = −7/(−3) = 7/3.
કર્ણ/લાંબી બાજુ ટ્રિક: જો ત્રિભુજના શિરોબિંદુઓમાંથી બેનું x-અથવા y-નિરક્ષર સમાન હોય, તો તે બાજુ અનુક્રમે x-અથવા y-અક્ષને સમાંતર છે → અંતર સીધું |x₁−x₂| અથવા |y₁−y₂|. ક્ષેત્રફળ = ½ × આધાર × ઊંચાઈ ઝડપી મળે.
જ્યારે બે શિરોબિંદુઓનું એક coordinate સમાન હોય.
દા.ત.: A(2,5), B(2,−3), C(7,5). AB ઊભી રેખા, લંબાઈ = |5−(−3)| = 8. C થી AB સુધીનું લંબ અંતર = |7−2| = 5. ક્ષેત્રફળ = ½×8×5 = 20 વર્ગએકમ.
