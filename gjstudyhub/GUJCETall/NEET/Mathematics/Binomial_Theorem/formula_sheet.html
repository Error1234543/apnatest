બહુપદી પ્રમેય (Binomial Theorem) — સૂત્ર પુસ્તિકા

🧪 GUJCET — Gujarati • Mathematics • Binomial Theorem

⚡ સૂત્રો

સામાન્ય બહુપદી પ્રમેય (પૂર્ણાંક ઘાતાંક): (a + b)^n = Σ(r=0 ને n) ^nC_r · a^(n−r) · b^r = ^nC_0·a^n + ^nC_1·a^(n−1)b + ^nC_2·a^(n−2)b^2 + ... + ^nC_n·b^n
a, b = વાસ્તવિક સંખ્યાઓ; n = ધન પૂર્ણાંક ઘાતાંક; r = પદ સૂચક (0 થી n); ^nC_r = સંયોજન કોએફિશિયન્ટ = n! / [r!(n−r)!] · SI: અપ્રસ્તુત · જ્યારે n એ ધન પૂર્ણાંક હોય
આપત્તિ સાથેનું વિસ્તરણ: (a − b)^n = Σ(r=0 ને n) (−1)^r · ^nC_r · a^(n−r) · b^r
a, b = વાસ્તવિક સંખ્યાઓ; n = ધન પૂર્ણાંક; r = પદ સૂચક · SI: અપ્રસ્તુત · જ્યારે n એ ધન પૂર્ણાંક હોય
(a + b)^n + (a − b)^n: (a + b)^n + (a − b)^n = 2[ ^nC_0·a^n + ^nC_2·a^(n−2)b^2 + ^nC_4·a^(n−4)b^4 + ... ]
n = ધન પૂર્ણાંક; જમણી બાજુમાં ફક્ત સમ પદાવલિઓ રહે છે · SI: અપ્રસ્તુત · n ધન પૂર્ણાંક હોય
(a + b)^n − (a − b)^n: (a + b)^n − (a − b)^n = 2[ ^nC_1·a^(n−1)b + ^nC_3·a^(n−3)b^3 + ^nC_5·a^(n−5)b^5 + ... ]
n = ધન પૂર્ણાંક; જમણી બાજુમાં ફક્ત વિષમ પદાવલિઓ રહે છે · SI: અપ્રસ્તુત · n ધન પૂર્ણાંક હોય
સામાન્ય પદ (General Term): T_(r+1) = ^nC_r · a^(n−r) · b^r
T_(r+1) = (r+1)-મું પદ; r = 0, 1, 2, ..., n; ^nC_r = n!/[r!(n−r)!] · SI: અપ્રસ્તુત · n ધન પૂર્ણાંક હોય
મધ્યમ પદ(ો) — n સમ હોય ત્યારે: મધ્યમ પદો = T_(n/2) અને T_((n/2)+1) / અથવા ^nC_(n/2) · a^(n/2) · b^(n/2)
n = સમ ધન પૂર્ણાંક; કુલ પદો = n + 1 (સમ), તેથી બે મધ્યમ પદો · SI: અપ્રસ્તુત · n સમ (even) પૂર્ણાંક હોય
મધ્યમ પદ — n વિષમ હોય ત્યારે: મધ્યમ પદ = T_((n+1)/2) = T_((n+3)/2) / અથવા ^nC_((n−1)/2) · a^((n+1)/2) · b^((n−1)/2)
n = વિષમ (odd) ધન પૂર્ણાંક; કુલ પદો = n + 1 (વિષમ), તેથી એક જ મધ્યમ પદ · SI: અપ્રસ્તુત · n વિષમ (odd) પૂર્ણાંક હોય
બહુપદી ગુણાંકોનો સરવાળો: ^nC_0 + ^nC_1 + ^nC_2 + ... + ^nC_n = 2^n
n = ધન પૂર્ણાંક; ડાબી બાજુના દરેક ^nC_r એ બહુપદી ગુણાંક (Binomial Coefficient) છે · SI: અપ્રસ્તુત · n ધન પૂર્ણાંક હોય; (a = b = 1 મૂકતા મળે છે)
વૈકલ્પિક ગુણાંક સરવાળો: ^nC_0 − ^nC_1 + ^nC_2 − ^nC_3 + ... + (−1)^n · ^nC_n = 0
n ≥ 1 ધન પૂર્ણાંક · SI: અપ્રસ્તુત · n ≥ 1 ધન પૂર્ણાંક; (a = 1, b = −1 મૂકતા મળે છે)
સમ-અને વિષમ-સ્થાનના ગુણાંકોનો સરવાળો: ^nC_0 + ^nC_2 + ^nC_4 + ... = ^nC_1 + ^nC_3 + ^nC_5 + ... = 2^(n−1)
n ≥ 1 ધન પૂર્ણાંક; સમ સૂચકવાળા અને વિષમ સૂચકવાળા ગુણાંકોનો સરવાળો સમાન · SI: અપ્રસ્તુત · n ધન પૂર્ણાંક હોય
પાસકલનું નિત્યસમ (Pascal's Identity): ^nC_r + ^nC_(r−1) = ^(n+1)C_r
0 < r ≤ n; ^nC_r = n!/[r!(n−r)!] · SI: અપ્રસ્તુત · r પૂર્ણાંક, 1 ≤ r ≤ n
બહુપદી ગુણાંકોની સંમિતિ (Symmetry): ^nC_r = ^nC_(n−r)
0 ≤ r ≤ n; એટલે કે પ્રથમ અને છેલ્લા પદના ગુણાંક સમાન · SI: અપ્રસ્તુત · n ધન પૂર્ણાંક, 0 ≤ r ≤ n
ક્રમિક ગુણાંકોનો ગુણોત્તર: ^nC_r / ^nC_(r−1) = (n − r + 1) / r
1 ≤ r ≤ n; આ સૂત્ર પરથી મહત્તમ ગુણાંક શોધી શકાય · SI: અપ્રસ્તુત · r ≥ 1, n ધન પૂર્ણાંક
મહત્તમ બહુપદી ગુણાંક: જો n સમ હોય → મહત્તમ ગુણાંક = ^nC_(n/2); જો n વિષમ હોય → મહત્તમ ગુણાંક = ^nC_((n−1)/2) = ^nC_((n+1)/2)
n = ધન પૂર્ણાંક; ^nC_r જ્યારે r નું મૂલ્ય મધ્યમ હોય ત્યારે મહત્તમ · SI: અપ્રસ્તુત · n ધન પૂર્ણાંક
ઋણ/ભિન્ન ઘાતાંકનું વિસ્તરણ (પ્રથમ ચાર પદો): (1 + x)^n = 1 + nx + [n(n−1)/2!]x^2 + [n(n−1)(n−2)/3!]x^3 + ..., જ્યાં |x| < 1
n = કોઈ પણ વાસ્તવિક સંખ્યા (ઋણ/ભિન્ન); x = chhota ચલ; |x| < 1 અનંત શ્રેણીનું અભિસરણ (convergence) માટે · SI: અપ્રસ્તુત · |x| < 1; જરૂરી n ધન પૂર્ણાંક નહીં
(1 − x)^(-1) નું વિસ્તરણ: (1 − x)^(−1) = 1 + x + x^2 + x^3 + x^4 + ..., |x| < 1
x = ચલ; અનંત શ્રેણી · SI: અપ્રસ્તુત · |x| < 1
(1 − x)^(-2) નું વિસ્તરણ: (1 − x)^(−2) = 1 + 2x + 3x^2 + 4x^3 + 5x^4 + ..., |x| < 1
x = ચલ; સહગુણકો ક્રમિક પ્રાકૃતિક સંખ્યાઓ · SI: અપ્રસ્તુત · |x| < 1
બહુપદી વિસ્તરણમાં x^r નો સહગુણક: (a + bx)^n માં x^r નો સહગુણક = ^nC_r · a^(n−r) · b^r
a, b = અચળ; n = ધન પૂર્ણાંક; r = 0, 1, ..., n · SI: અપ્રસ્તુત · n ધન પૂર્ણાંક
દ્વિપદી વિસ્તરણમાં સ્વતંત્ર પદ (અચળ પદ): x નું ઘાતાંક 0 કરીને T_(r+1) માં x^(n−r)·x^r અથવા સંબંધિત ઘાત શૂન્ય કહી r નું મૂલ્ય શોધવું; સ્વતંત્ર પદ = ^nC_r · a^(n−r) · b^r
જો વિસ્તરણ (a + bx)^n સ્વરૂપનું હોય તો r = 0 માટે સ્વતંત્ર પદ = ^nC_0 · a^n; જટિલ પદાવલિ માટે x ની ઘાતનું સમીકરણ ઉકેલવું · SI: અપ્રસ્તુત · સ્વતંત્ર પદ શોધવાનું હોય
બીજા પ્રકારનું મધ્યમ પદ નક્કી કરવું (x^k નું પદ): T_(r+1) = ^nC_r · a^(n−r) · b^r માં x ની ઘાત = k મૂકીને r નું મૂલ્ય શોધવું, फिर T_(r+1) શોધવું
k = આપેલ ઘાત; r = ઉકેલાયેલ સંખ્યા · SI: અપ્રસ્તુત · k-મું પદ અથવા x^k વાળું પદ શોધવું હોય
સંયોજન નિત્યસમ (Combinatorial Identity): ^mC_r · ^nC_0 + ^mC_(r−1)·^nC_1 + ^mC_(r−2)·^nC_2 + ... + ^mC_0·^nC_r = ^(m+n)C_r
m, n, r = ધન પૂર્ણાંક; ^mC_r = m!/[r!(m−r)!] · SI: અપ્રસ્તુત · r ≤ m, r ≤ n

🔗 સંબંધો

  • દ્વિપદી પ્રમેયના કુલ પદોની સંખ્યા = n + 1 (જ્યાં n ઘાતાંક છે)
  • બહુપદી ગુણાંક ^nC_r = n! / [r!(n−r)!], જે સંયોજન (Combination) C(n,r) ની સમાન છે
  • પ્રથમ અને છેલ્લા પદના બહુપદી ગુણાંકો સમાન હોય છે: ^nC_0 = ^nC_n = 1
  • બહુપદી ગુણાંકો સમમિતિ ધરાવે છે: ^nC_r = ^nC_(n−r), એટલે કે વિપરીત સ્થાનના ગુણાંકો સમાન
  • બધા બહુપદી ગુણાંકોનો સરવાળો 2^n થાય છે, જે (1+1)^n = 2^n પરથી મળે છે
  • સમ અને વિષમ સ્થાનના બહુપદી ગુણાંકોનો સરવાળો સમાન (દરેક 2^(n−1)) હોય છે
  • જ્યારે n સમ હોય ત્યારે મધ્યમ પદ એક જ હોય છે, જ્યારે n વિષમ હોય ત્યારે બે મધ્યમ પદો હોય છે
  • ક્રમિક બહુપદી ગુણાંકોનો ગુણોત્તર ^nC_r/^nC_(r−1) = (n−r+1)/r થાય છે, જે મહત્તમ ગુણાંક શોધવામાં ઉપયોગી છે
  • ઋણ/ભિન્ન ઘાતાંક માટેનું વિસ્તરણ અનંત શ્રેણી આપે છે, જે |x| < 1 હોય ત્યારે જ અભિસારી બને છે
  • બહુપદી પ્રમેય (a+b)^n માં a અને b ની વ્યાખ્યા મુજબ કોઈ પણ પદ T_(r+1) = ^nC_r · a^(n−r) · b^r મળે છે

🎯 ટ્રિક્સ

બહુપદી ગુણાંકોનો સરવાળો 2^n મેળવવા માટે (a+b)^n માં a = b = 1 મૂકો → (1+1)^n = 2^n
વૈકલ્પિક ગુણાંક સરવાળો શૂન્ય મેળવવા માટે (a+b)^n માં a = 1, b = −1 મૂકો → (1−1)^n = 0^n = 0
મહત્તમ બહુપદી ગુણાંક શોધવા ^nC_r/^nC_(r−1) ≥ 1 રાખો → r ≤ (n+1)/2; જો n સમ હોય r = n/2, જો n વિષમ હોય r = (n±1)/2
કોઈ પણ પદ બીજા પદ સાથે સરખાવવા T_(r+1)/T_r = ^nC_r·b / [^nC_(r−1)·a] = [(n−r+1)/r]·(b/a) નું સૂત્ર વાપરો
x^r નો સહગુણક શોધવા ^nC_r·a^(n−r)·b^r માં r નું મૂલ્ય શોધીને મૂકો — સીધું સૂત્ર
(1+x)^n અને (1−x)^n નું વિસ્તરણ ઉપયોગ કરીને (1+x)^n+(1−x)^n માં વિષમ પદો કેન્સલ થઈ જાય છે અને (1+x)^n−(1−x)^n માં સમ પદો કેન્સલ થાય છે
બહુપદી ગુણાંકોની સંમિતિ ^nC_r = ^nC_(n−r) વડે ઝટપટ ચકાસણી કરી શકાય — પહેલા અને પાછલા પદ સમાન

⚠️ ભૂલો

સામાન્ય પદ T_(r+1) = ^nC_r · a^(n−r) · b^r માં a અને b ને ગલત રીતે અદલાબદલી કરવા — a એ ^nC_r પાસે (n−r) ઘાત મેળવે છે, b એ r ઘાત
(a−b)^n ના વિસ્તરણમાં (−1)^r ને ભૂલી જવા અથવા ગલત ઘાત મૂકવી
મધ્યમ પદ શોધતી વખતે n સમ છે કે વિષમ તે ચકાસવું ભૂલી જવા — n સમ હોય તો એક, n વિષમ હોય તો બે મધ્યમ પદો હોય છે
બહુપદી ગુણાંક ^nC_r ની ગણતરી કરતી વખતે r! અને (n−r)! ના ગુણાકારમાં ભૂલ કરવી
બહુપદી પ્રમેય કોઈ પણ ઘાતાંક (ઋણ/ભિન્ન) માટે લાગુ પડે છે તેટલું વિસ્તરણ અનંત શ્રેણી છે — |x| < 1 ની શરત ભૂલી જવી
x^r નો સહગુણક શોધવા ^nC_r · a^(n−r) · b^r માં a = 1, b = x મૂકતા રૂઢિગત ભૂલ — a અને b વાસ્તવિક પદાવલિ હોય છે
બહુપદી ગુણાંકોનો સરવાળો 2^n સમજવો પણ (1−1)^n = 0 નો પરિણામ ગલત તારણ કાઢવું
ક્રમિક ગુણાંકોનો ગુણોત્તર ^nC_r/^nC_(r−1) = (n−r+1)/r યાદ રાખવામાં સૂત્રની ઉલટચાલ કરવી
નવા પ્રકારના પ્રશ્નોમાં (ax + b)^n જેવા વિસ્તરણમાં a^n અને b^n ને ગુણાંક તરીકે મૂકવા ભૂલી જવા
બહુપદી વિસ્તરણનું કુલ પદો = n+1 તે યાદ રાખવામાં n+1 ને બદલે n સમજી લેવું
