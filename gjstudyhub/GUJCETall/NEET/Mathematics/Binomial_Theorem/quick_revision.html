🧠 યાદ રાખો

b^n શ્રેણીના પદોની સંખ્યા = n+1 હોય છે.
સહગુણકોનો કુલ સરવાળો: C₀ + C₁ + … + Cₙ = 2ⁿ
સમાન અંતરે આવેલા સહગુણકો: C_r = C_{n−r}
C₀ − C₁ + C₂ − … + (−1)ⁿ Cₙ = 0
સમ સ્થાનના સહગુણકોનો સરવાળો = વિષમ સ્થાનના સહગુણકોનો સરવાળો = 2^{n−1}
p અને q સમાન ચિહ્ન ધરાવતા હોય, તો સ્વતંત્ર પદ માટે r = n/2 આવશ્યક છે.

⚡ ઝડપી સૂત્રો

સામાન્ય પદ: T_{r+1} = ^nC_r · a^{n−r} · b^r, જ્યાં r = 0,1,…,n
બાયનોમિયલ સહગુણકો: C_r = ^nC_r = n! / [r!(n−r)!]
ક્રમિક સહગુણકોનો ગુણોત્તર: C_r / C_{r−1} = [(n−r+1)/r] · (q/p)
m નું મૂલ્ય મેળવવા: ^nC_m / ^nC_{m+1} અને ^nC_{m+1} / ^nC_{m+2} પરથી m શોધો.
જો T_{r+1} સ્વતંત્ર હોય, તો n·p − r(p+q) = 0 → r = np/(p+q)

✅ વન-લાઈનર્સ

મધ્યમ પદ: n સમ હોય તો T_{n/2+1}, n વિષમ હોય તો T_{(n+1)/2} અને T_{(n+3)/2}.
x ના ઘાતાંક સમાન રીતે ફેરવાય છે: a નો ઘાત ઘટે, b નો ઘાત વધે છે.
વિસ્તરણ (a+b)^n માં બધા પદોનો સરવાળો મેળવવા a=1, b=1 મૂકો.
(1−x)^{−n} = 1 + nx + [n(n+1)/2!]x² + … (અનંત શ્રેણી).
સૌથી મોટો સહગુણક: n સમ હોય તો r = n/2, n વિષમ હોય તો r = (n±1)/2.
^nC₀² + ^nC₁² + … + ^nC_n² = ^(2n)C_n
જો px અને qx એકસમાન હોય, તો સ્વતંત્ર પદ માટે r = n/2 લો.
વિસ્તરણમાં પદોની સંખ્યા હંમેશા પૂર્ણાંક અને ધન હોય છે.
