વ્યસ્ત ત્રિકોણમિતિય વિધેયો — ટૂંકા નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Inverse Trigonometric Functions

📘 વ્યાખ્યાઓ

  • વ્યસ્ત ત્રિકોણમિતિય વિધેય: જો y = sin x તો x = sin⁻¹ y, જેને વક્ષમ કોણ તરીકે પણ ઓળખાય છે.
  • પ્રધાન મૂલ્ય શાખા (Principal Value Branch): દરેક વ્યસ્ત ત્રિકોણમિતિય વિધેય માટે એવો વિશેષ અંતરાલ જ્યાં વિધેય એક-એક અને પરિપુરણ બને છે.
  • sin⁻¹ ની પ્રધાન મૂલ્ય શાખા: [−π/2, π/2]
  • cos⁻¹ ની પ્રધાન મૂલ્ય શાખા: [0, π]
  • tan⁻¹ ની પ્રધાન મૂલ્ય શાખા: (−π/2, π/2)
  • cot⁻¹ ની પ્રધાન મૂલ્ય શાખા: (0, π)
  • sec⁻¹ ની પ્રધાન મૂલ્ય શાખા: [0, π] − {π/2}
  • cosec⁻¹ ની પ્રધાન મૂલ્ય શાખા: [−π/2, π/2] − {0}

⚡ સૂત્રો

  • sin⁻¹(−x) = −sin⁻¹ x (બધા x ∈ [−1, 1])
  • cos⁻¹(−x) = π − cos⁻¹ x (બધા x ∈ [−1, 1])
  • tan⁻¹(−x) = −tan⁻¹ x (બધા x ∈ R)
  • sin⁻¹ x + cos⁻¹ x = π/2 (બધા x ∈ [−1, 1])
  • tan⁻¹ x + cot⁻¹ x = π/2 (બધા x ∈ R)
  • sec⁻¹ x + cosec⁻¹ x = π/2 (બધા |x| ≥ 1)
  • tan⁻¹ x + tan⁻¹ y = tan⁻¹[(x+y)/(1−xy)], જો xy < 1
  • tan⁻¹ x + tan⁻¹ y = tan⁻¹[(x+y)/(1−xy)] + π, જો xy > 1 અને x, y > 0
  • tan⁻¹ x + tan⁻¹ y = tan⁻¹[(x+y)/(1−xy)] − π, જો xy > 1 અને x, y < 0
  • 2 tan⁻¹ x = sin⁻¹[2x/(1+x²)], જો |x| ≤ 1
  • 2 tan⁻¹ x = cos⁻¹[(1−x²)/(1+x²)], જો x ≥ 0
  • 2 tan⁻¹ x = tan⁻¹[2x/(1−x²)], જો |x| < 1
  • sin⁻¹ x = tan⁻¹[x/√(1−x²)], |x| < 1
  • cos⁻¹ x = tan⁻¹[√(1−x²)/x], x > 0
  • tan⁻¹(√(1+x²)−1)/x = sin⁻¹(x/√(2+x²))
  • sin⁻¹[sin θ] = θ, જો θ ∈ [−π/2, π/2]; નહીંતર પ્રધાન મૂલ્ય શાખા મુજબ રૂપાંતર કરવું પડે.

⭐ મુખ્ય તથ્યો

  • sin⁻¹ નું વ્યાપ્તિ (Domain): [−1, 1] અને પ્રતિબિંબ (Range): [−π/2, π/2]
  • cos⁻¹ નું વ્યાપ્તિ: [−1, 1] અને પ્રતિબિંબ: [0, π]
  • tan⁻¹ નું વ્યાપ્તિ: R અને પ્રતિબિંબ: (−π/2, π/2)
  • cot⁻¹ નું વ્યાપ્તિ: R અને પ્રતિબિંબ: (0, π)
  • sec⁻¹ નું વ્યાપ્તિ: (−∞, −1] ∪ [1, ∞) અને પ્રતિબિંબ: [0, π] − {π/2}
  • cosec⁻¹ નું વ્યાપ્તિ: (−∞, −1] ∪ [1, ∞) અને પ્રતિબિંબ: [−π/2, π/2] − {0}
  • sin⁻¹ x, cos⁻¹ x, tan⁻¹ x ના ગ્રાફો યામતલ પર સમાન મૂળવિંદુની સાપેક્ષે સમપ્રમાણ હોય છે.
  • sin⁻¹(sin θ) = θ હંમેશા સાચું નથી; θ ને પ્રધાન મૂલ્ય શાખામાં લાવીને સાદુંરૂપ આપવું પડે.
  • cos⁻¹(cos θ) = θ હંમેશા સાચું નથી; θ ને પ્રધાન મૂલ્ય શાખા [0, π]માં હોવું જરૂરી છે.
  • tan⁻¹(tan θ) = θ હંમેશા સાચું નથી; θ ∈ (−π/2, π/2) હોવું જરૂરી છે.
  • tan⁻¹ x નો ગ્રાફ યામમૂળ પર પ્રતિસામ્ય (odd symmetry) દર્શાવે છે.
  • sin⁻¹ x નો ગ્રાફ y = x રેખા પર પ્રતિબિંબિત છે, કારણ કે તે sin x નું વ્યસ્ત છે.
  • sin⁻¹ x + sin⁻¹ y = sin⁻¹[x√(1−y²) + y√(1−x²)], જો x² + y² ≤ 1
  • sin⁻¹ x − sin⁻¹ y = sin⁻¹[x√(1−y²) − y√(1−x²)], જો x² + y² ≤ 1
  • tan⁻¹ x − tan⁻¹ y = tan⁻¹[(x−y)/(1+xy)], જો xy > −1

⚠️ સામાન્ય ભૂલો

  • sin⁻¹(2) લખવું અશક્ય છે; 2 એ વ્યાપ્તિ [−1, 1] બહાર છે — આ પ્રશ્નોમાં 'અસ્તિત્વ નથી' જવાબ સૂચવે છે.
  • tan⁻¹(1) + tan⁻¹(2) + tan⁻¹(3) = π છે; ખોટો જવાબ −π ન મેળવવા માટે xy > 1 નિયમ ધ્યાનમાં લેવો.
  • sin⁻¹(sin 2) = 2 લખવું ભૂલભરેલું છે; 2 ∉ [−π/2, π/2], તેથી sin⁻¹(sin 2) = π − 2 થાય.
  • cos⁻¹(−x) = −cos⁻¹ x ન લખવું; સાચું સૂત્ર cos⁻¹(−x) = π − cos⁻¹ x છે.
  • sin⁻¹ x + cos⁻¹ x = π/2 હંમેશા લાગુ પડે છે, પણ x ∈ [−1, 1] શરત ચકાસવી જરૂરી છે.
  • 2 tan⁻¹ x = sin⁻¹[2x/(1+x²)] માત્ર |x| ≤ 1 માટે સાચું છે; x > 1 માટે અલગ મૂલ્ય મળે.
  • sin⁻¹(−1) = −π/2, પણ cos⁻¹(−1) = π; આ બે મૂળભૂત મૂલ્યો યાદ રાખવાં.
  • sin⁻¹ x = cosec⁻¹(1/x) એટલું જ સાચું છે જ્યારે |x| ≥ 1; ખોટી શરતે આ સમીકરણ અસ્પષ્ટ બને છે.
  • tan⁻¹ x + tan⁻¹ y = tan⁻¹[(x+y)/(1−xy)] માત્ર t્યારે જ લાગુ પડે જ્યારે xy < 1 હોય.
  • cot⁻¹(−1) = 3π/4 લખવું, π/4 નહીં; પ્રતિબિંબ (0, π) છે.
  • sin⁻¹ x / cos⁻¹ x નું મૂલ્ય શોધતી વખતે x = 0 અને x = 1 ની સીમાઓ ચકાસવી.
  • વૈકલ્પિક પ્રતિબિંબ શાખા લેવાથી જવાબ ખોટો આવે છે; હંમેશા પ્રધાન મૂલ્ય શાખાનો ઉપયોગ કરવો.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • sin⁻¹ x + cos⁻¹ x = π/2, tan⁻¹ x + cot⁻¹ x = π/2, sec⁻¹ x + cosec⁻¹ x = π/2 — આ ત્રણ મુખ્ય નિત્યસમ સંપૂર્ણ અંતરાલમાં સાચા.
  • tan⁻¹ x ના ત્રણ રૂપાંતરો (sin⁻¹, cos⁻¹, અને ઘન સૂત્ર) સ્પષ્ટ રીતે યાદ રાખવાં.
  • sin⁻¹(sin θ), cos⁻¹(cos θ), tan⁻¹(tan θ) નું સાદુંરૂપ — પ્રત્યેક માટે θ ને પ્રધાન શાખામાં લઈ જવું.
  • સીમા શોધ: sin⁻¹ x ની વધુથી વધુ કિંમત −π/2 અને ઓછીથી ઓછી π/2 — આધારે મહત્તમ/ન્યૂનતમ શોધવાના પ્રશ્નો આવે છે.
  • tan⁻¹ x + tan⁻¹ y + tan⁻¹ z = π માટે શરત xy + yz + zx = 1 આવે છે; યાદ રાખવું.
  • sin⁻¹ x નો ગ્રાફ પરોક્ષ રીતે y-axis પર પ્રતિસામ્ય (સમ વિધેય) નથી; tan⁻¹ x જ પરોક્ષ રીતે y-axis પર પ્રતિસામ્ય છે.
  • ધન અને ઋણ બંને m માટે atan(m) + atan(−m) = 0; આ ગુણધર્મ ગણતરીમાં વધુ ગતિ આપે છે.
  • મોટાભાગના GUJCET પ્રશ્નો sin⁻¹ x + cos⁻¹ x = π/2 ને આધારે રચાય છે; તેની ચોકસાઈથી ચર્ચા કરવી.
  • sin⁻¹[√(1−x²)/x] = cos⁻¹(√(1−x²)) જેવું રૂપાંતર x > 1 માટે લાગુ પડે છે.
  • tan⁻¹(√(1+x²)−1)/x = (1/2)sin⁻¹(x²/(1+x²)) જો x ≠ 0 — આ પ્રકારના પ્રશ્નો પુનરાવર્તિત થાય છે.
