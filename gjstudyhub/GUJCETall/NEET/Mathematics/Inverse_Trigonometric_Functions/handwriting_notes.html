વિપરિત ત્રિકોણમિતીય ફંક્શન (Inverse Trigonometric Functions)

🧪 GUJCET — Gujarati • Mathematics • Inverse Trigonometric Functions

પરિચય (Introduction)
ત્રિકોણમિતીય ફંક્શનના વિપરિત ફંક્શનને વિપરિત ત્રિકોણમિતીય ફંક્શન કહેવામાં આવે છે.
આ ફંક્શનનો ઉપયોગ કોણ (θ) શોધવા માટે થાય છે જ્યારે ત્રિકોણમિતીય મૂલ્ય આપેલ હોય.
વિપરિત ત્રિકોણમિતીય ફંક્શનના ડોમેન અને રેન્જને સ્પષ્ટ રીતે સમજવું જરૂરી છે.
📝 GUJCETમાં આ પ્રકરણમાંથી 1-2 પ્રશ્નો પૂછાય છે.
મૂળભૂત વિપરિત ત્રિકોણમિતીય ફંક્શન (Basic Inverse Trigonometric Functions)
1. arcsin(x) અથવા sin⁻¹(x): સાઇન ફંક્શનનો વિપરિત ફંક્શન.
2. arccos(x) અથવા cos⁻¹(x): કોસાઇન ફંક્શનનો વિપરિત ફંક્શન.
3. arctan(x) અથવા tan⁻¹(x): ટેનજન્ટ ફંક્શનનો વિપરિત ફંક્શન.
4. arccot(x) અથવા cot⁻¹(x): કોટેનજન્ટ ફંક્શનનો વિપરિત ફંક્શન.
5. arcsec(x) અથવા sec⁻¹(x): સેકન્ટ ફંક્શનનો વિપરિત ફંક્શન.
6. arccsc(x) અથવા csc⁻¹(x): કોસેકન્ટ ફંક્શનનો વિપરિત ફંક્શન.
y = sin⁻¹(x) ⇔ x = sin(y), જ્યાં y ∈ [-π/2, π/2]
y = cos⁻¹(x) ⇔ x = cos(y), જ્યાં y ∈ [0, π]
y = tan⁻¹(x) ⇔ x = tan(y), જ્યાં y ∈ (-π/2, π/2)
📝 ડોમેન અને રેન્જ યાદ રાખવા મહત્વપૂર્ણ છે.
ડોમેન અને રેન્જ (Domain and Range)
arcsin(x) અને arccos(x)નો ડોમેન: [-1, 1]
arctan(x) અને arccot(x)નો ડોમેન: ℝ (વાસ્તવિક સંખ્યાઓ)
arcsec(x) અને arccsc(x)નો ડોમેન: (-∞, -1] ∪ [1, ∞)
arcsin(x)નો રેન્જ: [-π/2, π/2]
arccos(x)નો રેન્જ: [0, π]
arctan(x)નો રેન્જ: (-π/2, π/2)
ડોમેન અને રેન્જની ખોટી સમજથી ગણતરીમાં ભૂલ થાય છે.
વિપરિત ત્રિકોણમિતીય ફંક્શનની ગુણધર્મો (Properties)
sin⁻¹(x) + cos⁻¹(x) = π/2, જ્યાં x ∈ [-1, 1]
tan⁻¹(x) + cot⁻¹(x) = π/2, જ્યાં x ∈ ℝ
sec⁻¹(x) + csc⁻¹(x) = π/2, જ્યાં |x| ≥ 1
sin⁻¹(-x) = -sin⁻¹(x)
cos⁻¹(-x) = π - cos⁻¹(x)
tan⁻¹(-x) = -tan⁻¹(x)
📝 આ ગુણધર્મોનો ઉપયોગ ઓળખીને પ્રશ્નો સરળતાથી ઉકેલી શકાય છે.
વિપરિત ત્રિકોણમિતીય ફંક્શનનું સરવલીકરણ (Simplification)
sin⁻¹(x) + sin⁻¹(y) = sin⁻¹(x√(1-y²) + y√(1-x²)), જ્યાં x² + y² ≤ 1 અથવા x, y ∈ [-1, 1]
cos⁻¹(x) + cos⁻¹(y) = cos⁻¹(xy - √(1-x²)√(1-y²)), જ્યાં x + y ≥ 0 અથવા x, y ∈ [-1, 1]
tan⁻¹(x) + tan⁻¹(y) = tan⁻¹((x + y)/(1 - xy)), જ્યાં xy < 1
tan⁻¹(x) - tan⁻¹(y) = tan⁻¹((x - y)/(1 + xy))
સરવલીકરણના નિયમો લાગુ પાડતી વખતે શરતો ધ્યાનમાં રાખો.
વિપરિત ત્રિકોણમિતીય ફંક્શન અને ત્રિકોણમિતીય ફંક્શન વચ્ચેનો સંબંધ (Relationship)
sin(sin⁻¹(x)) = x, જ્યાં x ∈ [-1, 1]
cos(cos⁻¹(x)) = x, જ્યાં x ∈ [-1, 1]
tan(tan⁻¹(x)) = x, જ્યાં x ∈ ℝ
sin⁻¹(sin(θ)) = θ, જ્યાં θ ∈ [-π/2, π/2]
cos⁻¹(cos(θ)) = θ, જ્યાં θ ∈ [0, π]
📝 આ સંબંધોનો ઉપયોગ ઓળખીને પ્રશ્નો ઉકેલવા મદદરૂપ થાય છે.
વિપરિત ત્રિકોણમિતીય ફંક્શનના ગ્રાફ (Graphs)
arcsin(x)નો ગ્રાફ: [-1, 1] ડોમેન અને [-π/2, π/2] રેન્જ સાથે વક્ર રેખા.
arccos(x)નો ગ્રાફ: [-1, 1] ડોમેન અને [0, π] રેન્જ સાથે વક્ર રેખા.
arctan(x)નો ગ્રાફ: ℝ ડોમેન અને (-π/2, π/2) રેન્જ સાથે વક્ર રેખા.
ગ્રાફ દોરતી વખતે ડોમેન અને રેન્જની હદો ધ્યાનમાં રાખો.
વિપરિત ત્રિકોણમિતીય સમીકરણો (Inverse Trigonometric Equations)
સમીકરણો ઉકેલતી વખતે ડોમેન અને રેન્જની હદો ધ્યાનમાં રાખવી જરૂરી છે.
ઉદાહરણ: sin⁻¹(x) = π/4 ⇒ x = sin(π/4) = √2/2
ઉદાહરણ: cos⁻¹(x) = π/3 ⇒ x = cos(π/3) = 1/2
tan⁻¹(√3) = π/3
📝 સમીકરણો ઉકેલતી વખતે ગુણધર્મોનો ઉપયોગ કરો.
વિપરિત ત્રિકોણમિતીય ફંક્શનના અનુપ્રયોગ (Applications)
કોણ શોધવા માટે વિપરિત ત્રિકોણમિતીય ફંક્શનનો ઉપયોગ થાય છે.
ભૌમિતિક સમસ્યાઓમાં કોણની ગણતરી કરવા માટે ઉપયોગી.
ફિઝિક્સ અને એન્જિનિયરિંગમાં વેગ, ત્વરણ, અને દિશા શોધવા માટે ઉપયોગી.
અનુપ્રયોગો સમજવાથી પ્રશ્નોની સમજ વિકસે છે.
