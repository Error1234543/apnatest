વ્યસ્ત ત્રિકોણમિતિય વિધેયો — સંપૂર્ણ નોંધો

🧪 GUJCET — Gujarati • Mathematics • Inverse Trigonometric Functions

આ વિભાગમાં આપણે વ્યસ્ત ત્રિકોણમિતિય વિધેયોનું સર્વપ્રથમ પરિચય મેળવીશું. ત્રિકોણમિતિય વિધેયો એકપરિમાણીય ન હોવાથી તેઓ ઉલટાવી શકાય તેવી નથી, તેથી તેમની ક્ષેત્રફળ અને શાખાઓને અમુક રીતે સીમિત કરીને વ્યસ્ત વિધેયો વ્યાખ્યાયિત કરવામાં આવે છે. આ વિધેયો ગણિત, ભૌતિકશાસ્ત્ર અને ઇજનેરીમાં ખૂબ જ ઉપયોગી છે, ખાસ કરીને ખૂણાઓ શોધવા અને સમીકરણો ઉકેલવા માટે.

વ્યસ્ત ત્રિકોણમિતિય વિધેયોની પૂર્વજરૂરિયાતો અને વ્યાખ્યા

ત્રિકોણમિતિય વિધેયો, જેવા કે sin, cos, tan, cot, sec અને cosec, બધા જ સામાન્ય રીતે એકપરિમાણીય નથી અને તેથી તેમનું વ્યસ્ત વિધેય સીધું વ્યાખ્યાયિત કરી શકાતું નથી. આથી આપણે દરેક ત્રિકોણમિતિય વિધેયની ક્ષેત્રફળનો એવો વિસ્તાર પસંદ કરીએ છીએ જ્યાં તે વિધેય એકપરિમાણીય અને ઉપરના (surjective) બંને બનશે. ઉદાહરણ તરીકે, y = sin x માટે આપણે [–π/2, π/2] લઈએ છીએ, કારણ કે આ અંતરાલમાં sin x એકપરિમાણીય અને 1 થી –1 સુધીના બધા મૂલ્યો પ્રાપ્ત કરે છે. આ રીતે વ્યાખ્યાયિત થયેલ વ્યસ્ત વિધેયને sin⁻¹ x કહેવાય છે. આ જ પ્રક્રિયા અન્ય ત્રિકોણમિતિય વિધેયો માટે પણ લાગુ પડે છે. વ્યસ્ત વિધેયોના ડોમેન અને રેન્જનું સહી રીતે ધ્યાન રાખવું જરૂરી છે, કારણ કે ખોટી શાખા પસંદ કરવાથી ઉકેલો બદલાઈ શકે છે.

વ્યસ્ત ત્રિકોણમિતિય વિધેયોની મુખ્ય મૂલ્ય શાખાઓ

દરેક વ્યસ્ત ત્રિકોણમિતિય વિધેયની એક ચોક્કસ મુખ્ય મૂલ્ય શાખા હોય છે, જે તે વિધેયનો પ્રચલિત પરિપથ તરીકે સ્વીકારવામાં આવે છે. આ શાખાઓ નીચે મુજબ છે: sin⁻¹x નો પરિપથ [–π/2, π/2] છે, cos⁻¹x નો [0, π] છે, tan⁻¹x નો (–π/2, π/2) છે, cot⁻¹x નો (0, π) છે, sec⁻¹x નો [0, π] – {π/2} છે અને cosec⁻¹x નો [–π/2, π/2] – {0} છે. આ મૂલ્ય શાખાઓ પસંદ કરવા પાછળનું કારણ એ છે કે દરેક વિધેય માટે એકપરિમાણીય અને સતત રહે તેવો યોગ્ય અંતરાલ મળી શકે. જ્યારે કોઈ પ્રશ્નમાં ચોક્કસ કોણ માંગવામાં આવે છે, ત્યારે આ મુખ્ય મૂલ્ય શાખામાંથી જ ઉત્તર લેવામાં આવે છે. બીજા બધા મૂલ્યો મેળવવા માટે સامान્ય સૂત્રોનો ઉપયોગ કરી શકાય છે, પરંતુ પરીક્ષામાં મુખ્ય મૂલ્ય શાખાનું પાલન અનિવાર્ય છે.

વ્યસ્ત ત્રિકોણમિતિય વિધેયોના ડોમેન અને રેન્જનું પઠન

ડોમેન એટલે વિધેયમાં મૂકી શકાય તેવા x ના કોઈ પણ વાસ્તવિક મૂલ્યોનો સમૂહ, જ્યારે રેન્ज એટલે વિધેય દ્વારા પ્રાપ્ત થતાં y ના મૂલ્યોનો સમૂહ. vYastrikonmitiya vidheyona mate, domain ane range ne sahi roope samajvu bahut avashyak ache. Sin⁻¹x no domain [–1, 1] ane range [–π/2, π/2] cho bharathi keval vadharela mathi pravarthti kare. Cos⁻¹x ni domain [–1, 1] che parantu range [0, π] re karyashila rakhse. Tan⁻¹x na mate domain purnavastav sankhyao (all real numbers) che, ane range (–π/2, π/2) re khali jay. Cosecant, Secant aane Cotangent mate domain ane range vistaritu chhe. વ્યસ્ત ત્રિકોણમિતિય વિધેયોના આલેખ

વ્યસ્ત ત્રિકોણમિતિય વિધેયોના આલેખ મૂળ ત્રિકોણમિતિય વિધેયોના આલેખની પરિમાણો અને મુખ્ય મૂલ્ય શાખાઓ પરથી મળે છે. sin⁻¹ x નો આલેખ y = sin x ના આલેખનો x = y રેખા પ્રત્યે પ્રતિબિંબ છે, પરંતુ ફક્ત [–π/2, π/2] અંતરાલ સુધી મર્યાદિત. આ આલેખ બિંદુ (–1, –π/2) થી (1, π/2) સુધીનો સતત વક્ર બતાવે છે. cos⁻¹ x નો આલેખ ઘટતો વક્ર છે, જે બિંદુ (–1, π) થી (1, 0) સુધી જાય છે. tan⁻¹ x નો આલેખ બે સમાંતર સમાંતર રેખાઓ x = –π/2 અને x = π/2 ને અનુલક્ષી (asymptotic) હોય છે, અને તે મૂળ બિંદુ વડે પસાર થાય છે. આ આલેખો સમજવાથી વિધેયના ગુણધર્મો, સતતતા અને મૂલ્યોની ચેતવણી મજબૂત બને છે.

વ્યસ્ત ત્રિકોણમિતિય વિધેયોના મૂળભૂત સૂત્રો

વ્યસ્ત ત્રિકોણમિતિય વિધેયોના મૂળભૂત સૂત્રોની મદદથી આપણે જટિલ પદાવલીઓને સરળ બનાવી શકીએ છીએ. ઉદાહરણ તરીકે, sin⁻¹(–x) = –sin⁻¹ x, cos⁻¹(–x) = π – cos⁻¹ x, અને tan⁻¹(–x) = –tan⁻¹ x. આ સામાન્ય તત્ત્વોનો ઉપયોગ કરીને આપણે ઋણ યુક્તિઓને ધનમાં પરિવર્તિત કરી શકીએ છીએ. આ સૂત્રો વ્યસ્ત વિધેયોની સમમિતિ અને ચિહ્ન નિયંત્રણ માટે ખૂબ જ ઉપયોગી છે. ઉપરાંત, sin⁻¹ x + cos⁻¹ x = π/2, tan⁻¹ x + cot⁻¹ x = π/2 અને sec⁻¹ x + cosec⁻¹ x = π/2 જેવા સંબંધો પણ આપણે યાદ રાખવા પડે છે. આ બધા જ સૂત્રોનો ઉપયોગ પ્રશ્નો ઉકેલવામાં, વિશ્લેષણ કરવામાં અને પરીક્ષાના બહુવિકલ્પ પ્રશ્નોમાં ઝડપથી ચૂક કરવામાં મદદરૂપ થાય છે.

વ્યસ્ત ત્રિકોણમિતિય વિધેયોના સંયોજનો અને વિસ્તરણ

વ્યસ્ત ત્રિકોણમિતિય વિધેયોના સંયોજનો એટલે બે અથવા વધુ વ્યસ્ત વિધેયોનો સરવાળો, અથવા તો અંતરાલ જાણીને મૂલ્ય શોધવું. ઉદાહરણ તરીકે, tan⁻¹ 1 + tan⁻¹ 2 + tan⁻¹ 3 = π નું પ્રમાણ દર્શાવવાનું છે. આવા પ્રશ્નોમાં sin⁻¹, cos⁻¹ અને tan⁻¹ માટેના વિસ્તરણ સૂત્રોનો ઉપયોગ કરવામાં આવે છે. જ્યારે a અને b અંતરાલ [–1, 1] માં હોય, ત્યારે sin⁻¹ a + sin⁻¹ b = sin⁻¹(a√(1–b²) + b√(1–a²)) જેવા સૂત્રો લાગુ પડે છે. આ જ પ્રમાણે cos⁻¹ અને tan⁻¹ માટે પણ અલગ અલગ સૂત્રો છે. આ સૂત્રોનો ઉપયોગ કરતી વખતે આપણે સંજ્ઞા (sign) અને ડોમેનની સાવચેતી રાખવી પડે છે. પ્રશ્ન ઉકેલવા માટે આપણે પગલાંબદ્ધ રીતે ગણતરી કરવી જોઈએ.

વ્યસ્ત ત્રિકોણમિતિય સમીકરણોનો ઉકેલ

વ્યસ્ત ત્રિકોણમિતિય સમીકરણો એવા સમીકરણો છે જેમાં વ્યસ્ત ત્રિકોણમિતિય વિધેયો સમાવિષ્ટ હોય. ઉદાહરણ તરીકે, sin⁻¹ x = π/6 નો ઉકેલ x = 1/2 આવે છે. કોઈ પણ પ્રકારનું સમીકરણ ઉકેલવા માટે આપણે બંને બાજુએ સમાન વિધેય લાગુ કરીને ચલને અલગ કરવો પડે છે. જ્યારે સમીકરણમાં બે અથવા વધુ વ્યસ્ત વિધેયો હોય, ત્યારે તેમના સંયોજન અને વિસ્તરણ સૂત્રોનો ઉપયોગ કરવો પડે છે. ઉકેલના બધા મૂલ્યો ડોમેનમાં હોવા જોઈએ અને મુખ્ય મૂલ્ય શાખાનું પાલન કરવું જરૂરી છે. કેટલાક વખતે એક કરતાં વધુ ઉકેલો મળી શકે છે, પરંતુ બધા જ ઉકેલો વાસ્તવિક અને ડોમેનમાં હોવા જોઈએ. આ પ્રકારના સમીકરણો ઘણી વાર GUJCET પરીક્ષામાં પૂછવામાં આવે છે.

વ્યસ્ત ત્રિકોણમિતિય વિધેયોના કિંમતી ગુણધર્મો અને પ્રમેયો છે. પ્રથમ ગુણધર્મ એ છે કે આ વિધેયો મુખ્ય મૂલ્ય શાખાઓમાં સતત અને વિકલનીય છે. બીજો ગુણધર્મ એ છે કે તેઓ કેટલાક અંતરાલોમાં સમ અથવા વિષમ હોય છે. ઉદાહરણ તરીકે, sin⁻¹ x અને tan⁻¹ x સમ વિધેયો છે, જ્યારે cos⁻¹ x અને cot⁻¹ x વિષમ નથી. ત્રીજો મહત્વનો ગુણધર્મ એ છે કે તેમનો ઉપયોગ કરીને ઘણા ગાણિતિક પ્રમેયો સાબિત કરી શકાય છે, જેમ કે sin⁻¹ x + cos⁻¹ x = π/2 નું પ્રમેય. આ પ્રમેયોનો ઉપયોગ ઉકેલમાં સરળતા અને ઝડપ લાવે છે. વધુમાં, આ વિધેયોના પ્રવક્તિ અને મૂલ્ય શ્રેણી સમજવી યોગ્ય ગણતરી માટે આવશ્યક છે.

પ્રયોગાત્મક ઉદાહરણો અને વ્યાખ્યાન

આ વિભાગમાં આપણે વ્યસ્ત ત્રિકોણમિતિય વિધેયો પર આધારિત કેટલાક પ્રયોગાત્મક ઉદાહરણો જોઈશું. ઉદાહરણ તરીકે, tan⁻¹(√3) = π/3, sin⁻¹(–1/2) = –π/6, cos⁻¹(–1/2) = 2π/3. આ બધા જ ઉદાહરણોમાં મુખ્ય મૂલ્ય શાખાનો સમાવેશ થાય છે. વધુમાં, sin⁻¹(1/√2) + cos⁻¹(1/√2) = π/2 જેવા સંયુક્ત ઉદાહરણો પણ વર્તન સમજાવે છે. આ ઉદાહરણોનો ઉપયોગ વિદ્યાર્થીઓને સૂત્રોની વાસ્તવિક યોગ્યતા સમજાવવા માટે થાય છે. આ ઉદાહરણોની સાથે સાથે આપણે કેટલાક ગ્રાફિકલ ઉદાહરણો પણ જોઈશું, જેથી વિધેયનું વર્તન સ્પષ્ટ થાય. ઉદાહરણો દ્વારા વિદ્યાર્થીઓ પરીક્ષાના પ્રશ્નોનો ઉકેલ શીખી શકે છે.

GUJCET માટે વિશેષ સૂચનો અને તૈયારી રણનીતિ

GUJCET પરીક્ષામાં વ્યસ્ત ત્રિકોણમિતિય વિધેયો પ્રશ્નો સામાન્ય રીતે પ્રતિબિંબ, મુખ્ય મૂલ્ય શાખા, સંયોજનો અને ડોમેન પર આધારિત હોય છે. તૈયારી દરમિયાન વિદ્યાર્થીએ દરેક વિધેયનું મૂળભૂત સૂત્ર, મુખ્ય મૂલ્ય શાખા અને ડોમેન/રેન્જ રટી લેવો જોઈએ. પ્રશ્નો ઉકેલતી વખતે ચોક્કસપણે મુખ્ય મૂલ્ય શાખામાં જવાબ લખવો, કારણ કે બહુવિકલ્પોમાં ગેરમાર્ગદર્શક વિકલ્પો હોઈ શકે છે. ગ્રાફ સમજવો, પ્રતિબિંબ નિયમો અપનાવવા અને વિસ્તરણ સૂત્રોનો ઉપયોગ કરવાની અભ્યાસ પ્રણાલી રાખવી. ઘણા પ્રશ્નો માત્ર યાદગરી અને સૂત્રના સમજ પર આધારિત હોય છે. આથી સતત અભ્યાસ, નોંધ લખવી અને ઉદાહરણોનું પુનરાવર્તન કરવું અનિવાર્ય છે.

⭐ મહત્વના મુદ્દા

  • સૌથી અગત્યનું તત્ત્વ એ છે કે વ્યસ્ત ત્રિકોણમિતિય વિધેયોની મુખ્ય મૂલ્ય શાખા પ્રમાણે જ ઉકેલ લખવામાં આવે છે.
  • sin⁻¹ x, tan⁻¹ x અને cosec⁻¹ x સમ વિધેયો છે; cos⁻¹ x, cot⁻¹ x અને sec⁻¹ x વિષમ નથી.
  • sin⁻¹ x + cos⁻¹ x = π/2, tan⁻¹ x + cot⁻¹ x = π/2, sec⁻¹ x + cosec⁻¹ x = π/2.
  • tan⁻¹ x નો ડોમેન બધી વાસ્તવિક સંખ્યાઓ છે અને રેન્જ (–π/2, π/2) છે.
  • cos⁻¹ x નો ડોમેન [–1, 1] છે અને રેન્જ [0, π] છે.
  • sin⁻¹(–x) = –sin⁻¹ x, cos⁻¹(–x) = π – cos⁻¹ x, tan⁻¹(–x) = –tan⁻¹ x.
  • વ્યસ્ત વિધેયોના આલેખ મૂળ ત્રિકોણમિતિય વિધેયોના x = y રેખા પ્રત્યે પ્રતિબિંબ છે.

⚠️ સામાન્ય ભૂલો

વ્યસ્ત ત્રિકોણમિતિય વિધેયનો ઉકેલ લખતી વખતે મુખ્ય મૂલ્ય શાખાને બદલે બીજી કોઈ પણ શાખા લખવી.
sin⁻¹ x + sin⁻¹ y = sin⁻¹(x+y) માનવું, જે ખોટું છે.
ડોમેનની ચેતવણી વિના વ્યસ્ત વિધેયોનો ઉપયોગ કરવો.
tan⁻¹ x નું મૂલ્ય π/2 અથવા –π/2 લેવું, જે તેની રેન્જમાં નથી.
cos⁻¹(–x) = –cos⁻¹ x માનવું, જ્યારે સાચું સૂત્ર cos⁻¹(–x) = π – cos⁻¹ x છે.
સંયોજન સૂત્રોનો ઉપયોગ કરતી વખતે xy < 1 જેવી શરતનો અભાવ.

🎯 પરીક્ષા ટિપ્સ

દરેક વ્યસ્ત ત્રિકોણમિતિય વિધેયની મુખ્ય મૂલ્ય શાખા રટી લો અને તેનો ઉપયોગ હંમેશા ચોક્કસપણે કરો.
સંયોજન સૂત્રો લાગુ પાડતી વખતે xy < 1, xy > –1 વગેરે શરતોનું પાલન કરો.
ડોમેન અને રેન્જની કોઈ પણ પ્રશ્નમાં ધ્યાન રાખો, કારણ કે ખોટો ડોમેન બહુવિકલ્પોમાંથી ઓળખવામાં મદદ કરે છે.
આલેખ સમજવાથી વિધેયના વર્તન વિશે ઝડપી માહિતી મળે છે, જે પ્રતિસ્પર્ધાત્મક પરીક્ષામાં સમય બચાવે છે.
સૂત્રોની તપાસ કરતી વખતે કિંમતો મૂકીને ચકાસણી કરો અને ગણતરીની ભૂલો ટાળો.
