🧠 યાદ રાખો

અસમતાના બંને બાજુએ સમાન વાસ્તવિક સંખ્યા જોડવા કે બાદ કરવાથી અસમતાનો ચિહ્ન (symbol) બદલાતો નથી.
અસમતાના બંને બાજુએ ધન સંખ્યાથી ગુણવા કે ભાગવાથી ચિહ્ન ફેરવાતું નથી.
અસમતાના બંને બાજુએઋણ સંખ્યાથી ગુણવા કે ભાગવાથી અસમતાનું ચિહ્ન ઉલટાઈ જાય છે.
આપેલ અસમતાનું મૂળ (root) એવી સંખ્યા છે જે મૂળ સમીકરણમાં મૂકતાં અસમતા સત્ય થાય.
સંકલ્પિત અસમતાની જાવચી સંખ્યાઓનો સંગ્રહ મૂળ ટૂંકડાનો ઉપ-સંગ્રહ હોય છે.
બે અથવા વધુ રેખીય અસમતાઓનો સામાન્ય ઉકેલ તેમના ક્ષેત્રફળનું છેદક (intersection) હોય છે.
રેખીય અસમતા (linear inequality) માં ઓછામાં ઓછી એક ચલ હોય છે અને બધા પદો ડિગ્રી 1ના હોય છે.
અવિકલ્પિત ક્ષેત્ર (feasible region) એ સામાન્ય ઉકેલોનો અવકલ્પિત ટાઇટ પ્રદેશ હોય છે.

⚡ ઝડપી સૂત્રો

ax + b > 0 ⟹ x > −b/a (જ્યારે a > 0)
ax + b < 0 ⟹ x < −b/a (જ્યારે a > 0)
અભિન્ન રેખા: y = mx + c (સમાનતા મર્યાદા માટે વાપરવી)
ખુલ્લો/બંધ વલય: ખુલ્લો વલય = બિંદુ સામેલ નથી ( dashed ), બંધ વલય = સામેલ છે ( solid )
કોન બિંદુ (corner point): અવિકલ્પિત પ્રદેશના શિરોબિંદુઓ, જે અસમતાઓની રેખાઓના છેદનબિંદુઓ છે

✅ વન-લાઈનર્સ

એક ચલવાળી રેખીય અસમતાનું સમાधान સંખ્યારેખા પર એક અંતરાલ તરીકે દર્શાવવામાં આવે છે.
બે ચલવાળી રેખીય અસમતા ax + by ≤ c નો ગ્રાફ: પહેલા રેખા ax + by = c દોરી, પછી મૂળબિંદુ (0,0) તપાસીને કયો અર્ધતલ ભરવો તે નક્કી કરવું.
અક્ષોની મૂળભૂત અસમતાઓ: x ≥ 0 (જમણી તરફ), y ≥ 0 (ઉપરની તરફ).
સામાન્ય ઉકેલ (general solution): બધી અસમતાઓને એકસાથે સંતોષતી બિંદુઓની જાવચી.
અવિકલ્પિત પ્રદેશ હંમેશા ઉત્તલ (convex) બહુભુજ હોય છે — અથવા અનંત ખુલ્લો પ્રદેશ.
રેખીય કાર્ય (linear objective function) Z = px + qy નું મહત્તમ/ઓછામાં ઓછું મૂલ્ય હંમેશા કોન બિંદુએ મળે છે.
અવિકલ્પિત પ્રદેશ બંધ અને સીમિત હોય તો મહત્તમ અને ન્યૂનતમ બંને અસ્તિત્વ ધરાવે છે.
અવિકલ્પિત પ્રદેશ અનંત હોય તો મહત્તમ/ન્યૂનતમ ન હોઈ પણ શકે; કોન બિંદુઓ પર Z ની કિંમત તપાસવી.
અસમતાના ચિહ્નનું ઉલટાવું: −2x > 6 ⟹ x < −3 (−2 ની ઉપર ભાગતાં ચિહ્ન ઉલટાયું).
અંતરાલ સંકેત: [a,b] = બંધ, (a,b) = ખુલ્લો, [a,b) = ડાબી બાજુ બંધ, જમણી ખુલ્લી.
રેખીય અસમતા પદ્ધતિ (LPP): અવિકલ્પિત પ્રદેશ શોધવો → કોન બિંદુઓ લખવા → Z ની કિંમતો સરખાવવી → મહત્તમ/ન્યૂનતમ પસંદ કરવું.
