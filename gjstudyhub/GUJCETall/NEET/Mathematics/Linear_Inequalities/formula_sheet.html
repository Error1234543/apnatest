સુરેખ અસમતાઓ — સૂત્ર પત્રક (Linear Inequalities — Formula Sheet)

🧪 GUJCET — Gujarati • Mathematics • Linear Inequalities

⚡ સૂત્રો

એક ચલવાળી સુરેખ અસમતાનો સામાન્ય રૂપ: ax + b < 0 (અથવા ≤, >, ≥)
a, b = અચળાંકો; x = ચલ (અજ્ઞાત); a ≠ 0 · SI: નો (અસમતા કોઈ ભૌતિક એકમ ધરાવતી નથી) · જ્યારે a, b વાસ્તવિક સંખ્યા હોય અને x એ વાસ્તવિક રેખા પરના તમામ મૂલ્યો લઈ શકે.
બે ચલવાળી સુરેખ અસમતાનો સામાન્ય રૂપ: ax + by < c (અથવા ≤, >, ≥)
a, b, c = વાસ્તવિક અચળાંકો; a અને b એક સાથે શૂન્ય નહીં; x, y = ચલો · SI: નો · x અને y ની બધી જોડિયાં ( ordered pairs ) (x, y) એક સમતલ પર અર્ધસમતલ (half-plane) બનાવે છે.
સમાન અસમતાગુણધર્મ ( Addition Property ): જો p < q હોય, તો p + r < q + r (દરેક વાસ્તવિક r માટે)
p, q, r = વાસ્તવિક સંખ્યાઓ; < એ ઘટતી સંબંધ સૂચક છે · SI: નો · r કોઈ પણ વાસ્તવિક સંખ્યા હોઈ શકે (ધન, ઋણ કે શૂન્ય).
વિયોગ ગુણધર્મ ( Subtraction Property ): જો p < q હોય, તો p − r < q − r
p, q, r = વાસ્તવિક સંખ્યાઓ · SI: નો · રિવર્સ જોડાણ (inversion) આ ગુણધર્મમાં થતું નથી; દિશા બદલાતી નથી.
ધન સંખ્યા વડે ગુણાકાર ગુણધર્મ: જો p < q અને r > 0, તો pr < qr
p, q, r = વાસ્તવિક સંખ્યાઓ; r > 0 (ધન) · SI: નો · r ધન વાસ્તવિક સંખ્યા હોવી જોઈએ; અસમતાની દિશા સમાન રહે છે.
ઋણ સંખ્યા વડે ગુણાકાર ગુણધર્મ: જો p < q અને r < 0, તો pr > qr
p, q, r = વાસ્તવિક સંખ્યાઓ; r < 0 (ઋણ) · SI: નો · r ઋણ હોય ત્યારે અસમતાનું ચિહ્ન Uલ્ટાઈ જાય છે (direction reverses).
ધન સંખ્યા વડે ભાગાકાર ગુણધર્મ: જો p < q અને r > 0, તો p/r < q/r
p, q = વાસ્તવિક સંખ્યાઓ; r = ધન વાસ્તવિક સંખ્યા (r ≠ 0) · SI: નો · ભાજક r > 0 હોય, તો અસમતાની દિશા સમાન રહે છે.
ઋણ સંખ્યા વડે ભાગાકાર ગુણધર્મ: જો p < q અને r < 0, તો p/r > q/r
p, q = વાસ્તવિક સંખ્યાઓ; r = ઋણ વાસ્તવિક સંખ્યા · SI: નો · r < 0 હોય તો અસમતાનું ચિહ્ન Uલ્ટાઈ જાય છે.
સંક્રામક ગુણધર્મ (Transitive Property): જો p < q અને q < r, તો p < r
p, q, r = વાસ્તવિક સંખ્યાઓ; અહીં < ને બદલે ≤, >, ≥ પણ લાગુ પડે. · SI: નો · બે ચિહ્નો સમાન પ્રકારના હોય ત્યારે સંક્રામકતા લાગુ પડે.
દ્વિધા અસમતાનો ઉકેલ સંહિતાર્થ (Intersection / AND): {x : x < a} ∩ {x : x > b} = {x : b < x < a} (જો b < a)
∩ = સંહિતાર્થ (intersection); AND શબ્દ બંનેને એકસાથે સંતોષતું x શોધે છે. · SI: નો · AND સંકેત (વાક્યમાં "અને") હોય, તો બંને અસમતાઓ સાથે સંતોષાય તેવું x નું વિસ્તાર મળે.
સંહિતાર્થનો ઉકેલ વિસ્તાર (AND case, closed form): b < x < a (બંધિત અંતરાલ (b, a))
(b, a) = ખુલ્લો અંતરાલ; x એ b થી મોટું અને a થી નાનું. · SI: નો · b < a હોવું આવશ્યક છે; વિકલ્પે શૂન્ય સેટ ઊભું થાય.
ઉપયોગ અસમતાનો ઉકેલ સંહિતાર્થ (Union / OR): {x : x < a} ∪ {x : x > b} = {x : x < a માટે} ∪ {x : x > b માટે}
∪ = સંહિતાર્થ (union); OR શબ્દ કોઈ પણ એક સંતોષે તેવું x શોધે છે. · SI: નો · OR શબ્દ હોય, તો બંનેમાંથી કોઈ એક સત્ય હોય તેવું x નું વિસ્તાર મળે.
સંહિતાર્થનો ઉકેલ વિસ્તાર (OR case, combined): (−∞, a) ∪ (b, ∞)
−∞, ∞ = અનંતતા; ∪ = સંહિતાર્થ. બંને વિસ્તારોને ખાલી જોડ કરે છે. · SI: નો · a < b હોય ત્યારે વધુ સ્પષ્ટ રીતે જોવાય છે.
ન્યૂનતમ/અધિકતમ રૂપ (Minimum / Maximum boundary): x ≥ max(a, b) અથવા x ≤ min(a, b)
max(a,b) = મહત્તમ; min(a,b) = ન્યૂનતમ · SI: નો · AND શબ્દવાળી અસમતામાં અંતરાલની સીમા (boundary) max/a minima વડે નક્કી કરે છે.
સુરેખ અસમતાનો આલેખી ઉકેલ (Graphical method – line test): ax + by = c → સીમા રેખા; ax + by < c → અર્ધસમતલ
ax+by=c = સીમા રેખા (boundary line); ચિહ્ન પરથી રંગ (shading) નક્કી થાય છે. · SI: નો · < કે > હોય તો રેખા ખાલી (dashed), ≤ કે ≥ હોય તો ભરેલી (solid) રેખા દોરે.
બિંદુ પરીક્ષણ (Test-point method): M(0,0) નો ઉપયોગ કરી, a·0 + b·0 < c ? : તપાસો.
M = મૂળબિંદુ; યોગ્ય બાજુ રંગોળી કરો. · SI: નો · જ્યારે 0,0 એ સીમા રેખા પર ન હોય ત્યારે પરીક્ષણબિંદુ તરીકે ઉપયોગી.
બંધ અંતરાલ (Closed interval) પ્રતિનિધિત્વ: [l, u] = {x ∈ ℝ : l ≤ x ≤ u}
l, u = ડાબું/જમણું અંત; ≤ = અંત સમાવે છે. · SI: નો · ઉકેલમાં સમાનતા સહિતની સીમાઓ હોય.
ખુલ્લો અંતરાલ (Open interval) પ્રતિનિધિત્વ: (l, u) = {x ∈ ℝ : l < x < u}
l, u = ડાબું/જમણું અંત; < = સીમા બાહર છે. · SI: નો · સખત અસમતા (<, >) હોય.
અંતરાલ દર્શન નિશાનીઓ (Interval notation summary): ]l,u[ = (l,u); [l,u] ; ]l,u] = (l,u]; [l,u[ = [l,u)
[, ] = અંત સમાવે છે; (, ) = અંત બાહર છે. · SI: નો · GUJCET માં ( ) અને [ ] નિશાનીઓ વપરાય છે.

🔗 સંબંધો

  • આલેખી રીતે બે ચલવાળી સુરેખ અસમતાનો ઉકેલ હંમેશા સમતલ પરનું અર્ધસમતલ (half-plane) હોય છે.
  • AND શબ્દવાળી સંયુક્ત અસમતાનો ઉકેલ વ્યક્તિગત ઉકેલ વિસ્તારોનો સંહિતાર્થ (intersection) હોય છે.
  • OR શબ્દવાળી સંયુક્ત અસમતાનો ઉકેલ વ્યક્તિગત ઉકેલ વિસ્તારોનું સંહિતાર્થ (union) હોય છે.
  • અસમતાના ડાબા અને જમણા બાજુના પદનો સરવાળો કરવા અથવા બાદબાકી કરવાથી દિશા બદલાતી નથી.
  • અસમતાના બંને બાજુ ધન સંખ્યા વડે ગુણતા/ભાગતા દિશા સમાન રહે છે; ઋણ સંખ્યા વડે ગુણતા/ભાગતા દિશા ઉલટાય છે.
  • સીમા રેખા પરનું પ્રત્યેક બિંદુ ≤ કે ≥વાળી અસમતાનો ઉકેલ બિંદુ છે, જ્યારે < કે >વાળીમાં તે બિંદુ ઉકેલમાં સામેલ નથી.

🎯 ટ્રિક્સ

ઋણ સંખ્યા વડે ગુણતા/ભાગતા ચિહ્ન Uલ્ટાય: 'કાળો ઘોડો દોડ્યો' (negative flips sign) — સંક્ષિપ્ત યાદ રાખવા માટે આ નિયમને 'ઋણ-પલટા' (negative-flip) કહી શકાય.
AND અસમતામાં બંને શરતોનું 'સામાન્ય ભાગ' શોધો: ડાબી સીમા max, જમણી સીમા min લો.
OR અસમતામાં બંને વિસ્તારોનું 'જોડાણ' કરો: ડાબી સીમા સૌથી ડાબી અને જમણી સીમા સૌથી જમણી રાખો.
આલેખી ઉકેલમાં પ્રથમ સીમા રેખા=ax+by=c દોરીને મૂળબિંદુ (0,0) ટેસ્ટ-પોઇન્ટ તરીકે તપાસો: જો (0,0) અસમતા સંતોષે, તો તે બાજુ રંગોળી કરો.
બે ચલની સુરેખ અસમતાનો ઉકેલ ભૂગોળી (geometric) રીતે અનંત ક્ષેત્રફળ ધરાવતું વિસ્તાર હોય છે; ગણનીય ઉકેલ બિંદુઓ નહીં પણ અવિરામ (continuous) વિસ્તાર હોય છે.
ખાલી અંતરાલ (∅) ત્યારે મળે જ્યારે AND શબ્દ હોય અને ડાબી સીમા જમણી સીમા કરતા મોટી હોય (e.g., 7 < x < 3).

⚠️ ભૂલો

અસમતાના બંને બાજુ ઋણ સંખ્યા વડે ગુણતા અથવા ભાગતા ચિહ્ન ઉલટાવવાનું ભૂલવું — એ સૌથી સામાન્ય ભૂલ છે.
AND અને OR વચ્ચેનો તફાવત સમજ્યા વિના ગણીને 'સંહિતાર્થ' (union) ને 'સંયોજન' (intersection) માની લેવું.
સીમા રેખા ખાલી (dashed) દોરવામાં આવવી જોઈએ (< કે > હોય) પણ ખોટી રીતે ભરેલી (solid) દોરવામાં આવે છે અથવા ઉલટું.
અંતરાલ નિશાનીઓમાં ( અને ) નો ગમતાનો ઉપયોગ કરવો — ખુલ્લા/બંધ અંતરાલમાં ભેદ સમજવો આવશ્યક છે.
મૂળબિંદુ (0,0) પ્રત્યક્ષ તપાસ કરતાં પહેલાં રેખા પર હોય છે, તેવું ચકાસ્યા વિના ધારી લેવું — તે કેસમાં બીજું કોઈ ટેસ્ટ-બિંદુ લેવું પડે.
બે ચલવાળી અસમતામાં રંગોળીની બાજુ ખોટી પસંદ કરવી — ધન-ઋણ ચિહ્ન યોગ્ય રીતે નક્કી ન કરવું.
ઉકેલને 'ઉકેલ કિંમત' (single value) માની લેવો — સુરેખ અસમતાનો ઉકેલ હંમેશા અંતરાલ અથવા વિસ્તાર હોય છે, એક જ આંકડો નહીં.
