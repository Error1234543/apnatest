સીમાઓ અને વિકલિતો (Limits and Derivatives)

🧪 GUJCET — Gujarati • Mathematics • Limits and Derivatives

⭐ મહત્વના મુદ્દા

સીમા (Limit) ની વ્યાખ્યા: જ્યારે x, a ની નજીક જાય ત્યારે f(x) નું મૂલ્ય L ની નજીક જાય, ત્યારે lim(x→a) f(x) = L. આને પ્રાથમિક વ્યાખ્યા તરીકે યાદ રાખવી.
GUJCET માં સીમાની વ્યાખ્યા પર સીધા પ્રશ્ન આવે છે.
ડાબી બાજુની સીમા (Left Hand Limit - LHL): lim(x→a⁻) f(x) અને જમણી બાજુની સીમા (Right Hand Limit - RHL): lim(x→a⁺) f(x). જો LHL = RHL હોય તો જ સીમા અસ્તિત્વ ધરાવે છે.
LHL અને RHL ની શરત GUJCET માં ઘણીવાર પસંદગી પ્રશ્ન તરીકે આવે છે.
સીમાના મૂળભૂત નિયમો: lim(x→a)[f(x) ± g(x)] = lim f(x) ± lim g(x); lim(x→a)[f(x)·g(x)] = lim f(x)·lim g(x); lim(x→a)[f(x)/g(x)] = lim f(x)/lim g(x) (જો હર શૂન્ય ન હોય).
આ નિયમોનો ઉપયોગ સીમા શોધવા માટે નિયમિતપણે થાય છે.
મહત્વપૂર્ણ પ્રમાણિત સીમાઓ: lim(x→0) sin x / x = 1; lim(x→0) tan x / x = 1; lim(x→0) (1 - cos x)/x = 0; lim(x→0) (e^x - 1)/x = 1; lim(x→0) log(1+x)/x = 0.
આ પ્રમાણિત સીમાઓ GUJCET માં સૌથી વધુ પુનરાવર્તન પામતી વિષયવસ્તુ છે.
lim(x→∞) (1 + 1/x)^x = e; lim(x→0) (1 + x)^(1/x) = e — આ બે સીમાઓ અનંત સ્વરૂપ (indeterminate forms) ની સમજ માટે મહત્વપૂર્ણ છે.
આ સીમાઓ GUJCET માં સીધા પ્રશ્ન તરીકે આવે છે.
અનંત સ્વરૂપ (Indeterminate Forms): 0/0, ∞/∞, 0·∞, ∞−∞, 0⁰, 1^∞, ∞⁰. આવા સ્વરૂપોને L'Hôpital ના નિયમ અથવા બીજા ગાણિતિક પદ્ધતિઓથી ઉકેલવા પડે છે.
અનંત સ્વરૂપ ઓળખવું અને ઉકેલવું GUJCET માં અત્યંત મહત્વપૂર્ણ છે.
L'Hôpital નો નિયમ: જો lim(x→a) f(x)/g(x) સ્વરૂપ 0/0 અથવા ∞/∞ હોય, તો lim f(x)/g(x) = lim f'(x)/g'(x) (જો હદ મર્યાદિત હોય).
L'Hôpital નો નિયમ GUJCET માં સીમા શોધવાની સૌથી વધુ વપરાતી પદ્ધતિ છે.
વિકલિત (Derivative) ની વ્યાખ્યા: f'(x) = lim(h→0) [f(x+h) − f(x)] / h. આને પ્રથમ સિદ્ધાંત (First Principle) મુજબ વિકલિત શોધવાની પદ્ધતિ કહેવાય છે.
પ્રથમ સિદ્ધાંત પરથી વિકલિત શોધવાના પ્રશ્ન GUJCET માં આવે છે.
ઘાતાંક નિયમ: d/dx(x^n) = n·x^(n−1). આ નિયમ બહુપદીના વિકલન માટે મૂળભૂત છે.
આ નિયમ GUJCET માં સૌથી વધુ વપરાતો નિયમ છે.
ત્રિકોણમિતિય વિધેયોના વિકલન: d/dx(sin x) = cos x; d/dx(cos x) = −sin x; d/dx(tan x) = sec²x; d/dx(cot x) = −csc²x; d/dx(sec x) = sec x tan x; d/dx(csc x) = −csc x cot x.
ત્રિકોણમિતિય વિકલન GUJCET માં નિયમિતપણે આવે છે.
ઘાતાંકીય અને લઘુગણક વિધેયોના વિકલન: d/dx(e^x) = e^x; d/dx(a^x) = a^x · log a; d/dx(log x) = 1/x; d/dx(ln x) = 1/x.
આ વિકલન સૂત્રો GUJCET માં ઘણીવાર પૂછાતા હોય છે.
ગુણાકાર નિયમ (Product Rule): d/dx[f(x)·g(x)] = f'(x)·g(x) + f(x)·g'(x).
ગુણાકાર નિયમ GUJCET માં બહુપદી અને ત્રિકોણમિતિય વિધેયોના વિકલનમાં વપરાય છે.
ભાગાકાર નિયમ (Quotient Rule): d/dx[f(x)/g(x)] = [f'(x)·g(x) − f(x)·g'(x)] / [g(x)]².
ભાગાકાર નિયમ GUJCET માં અપૂર્ણાંક વિધેયોના વિકલન માટે મહત્વપૂર્ણ છે.
શૃંખલા નિયમ (Chain Rule): જો y = f(g(x)) હોય, તો dy/dx = f'(g(x)) · g'(x). આ નિયમ સંયુક્ત વિધેયોના વિકલન માટે આવશ્યક છે.
શૃંખલા નિયમ GUJCET માં સૌથી વધુ મહત્વનો નિયમ છે.
વ્યસ્ત ત્રિકોણમિતિય વિધેયોના વિકલન: d/dx(sin⁻¹x) = 1/√(1−x²); d/dx(cos⁻¹x) = −1/√(1−x²); d/dx(tan⁻¹x) = 1/(1+x²); d/dx(cot⁻¹x) = −1/(1+x²); d/dx(sec⁻¹x) = 1/(|x|√(x²−1)); d/dx(csc⁻¹x) = −1/(|x|√(x²−1)).
વ્યસ્ત ત્રિકોણમિતિય વિકલન GUJCET માં નિયમિતપણે પૂછાતા હોય છે.
આંશિક વિકલન (Partial Derivative): જો z = f(x,y) હોય, તો ∂z/∂x માં y ને અચળ ધારી x ની સાપેક્ષે વિકલન કરવું; ∂z/∂y માં x ને અચળ ધારી y ની સાપેક્ષે વિકલન કરવું.
આંશિક વિકલન GUJCET માં બહુચલ વિધેયોના પ્રશ્નોમાં આવે છે.
દ્વિતીય ક્રમનું વિકલન (Second Derivative): d²y/dx² = d/dx(dy/dx). જો y = f(x) હોય, તો f''(x) શોધવું.
દ્વિતીય વિકલિત GUJCET માં મહત્વપૂર્ણ વિષય છે.
લગાતુ વિધેય (Continuous Function): f(x) બિંદુ x = a પર લગાતુ છે જો lim(x→a) f(x) = f(a). વિકલનીય વિધેય હંમેશા લગાતુ હોય છે, પરંતુ લગાતુ વિધેય હંમેશા વિકલનીય હોતું નથી (ઉદા. |x| at x=0).
લગાતુપણું અને વિકલનીયતા વચ્ચેનો સંબંધ GUJCET માં મહત્વપૂર્ણ છે.
વિકલનીયતા (Differentiability): f(x) બિંદુ x = a પર વિકલનીય છે જો lim(h→0) [f(a+h)−f(a)]/h અસ્તિત્વ ધરાવતું હોય. સર્વસમિકોણ બિંદુ (Cusps) અને ખૂણાવાળા બિંદુઓ પર વિધેય વિકલનીય નથી હોતા.
વિકલનીયતાની શરતો GUJCET માં પસંદગી પ્રશ્ન તરીકે આવે છે.
સાપેક્ષ વિકલન (Implicit Differentiation): જો y ને x ના સ્પષ્ટ વિધેય તરીકે લખી શકાય નહીં, તો સમીકરણના બંને બાજુ x ની સાપેક્ષે વિકલન કરી y' શોધવું. ઉદા. x² + y² = r² → 2x + 2y·y' = 0 → y' = −x/y.
ગુપ્ત વિકલન GUJCET માં અવકાશીય રેખા અને સ્પર્શકના પ્રશ્નોમાં આવે છે.
લઘુગણક વિકલન (Logarithmic Differentiation): જો y = [f(x)]^{g(x)} હોય, તો બંને બાજુ લઘુગણક લઈ y' શોધવું: log y = g(x)·log f(x) → y'/y = g'(x)·log f(x) + g(x)·f'(x)/f(x).
લઘુગણક વિકલન ઘાતાંકીય-ત્રિકોણમિતિય મિશ્ર વિધેયો માટે GUJCET માં ઉપયોગી છે.
વિકલિતનો ભૌમિતિક અર્થ: f'(a) એ વક્ર y = f(x) પર બિંદુ (a, f(a)) પરના સ્પર્શકનો ઢાળ (slope) દર્શાવે છે. સ્પર્શકનું સમીકરણ: y − f(a) = f'(a)(x − a).
સ્પર્શક અને લંબનું સમીકરણ GUJCET માં નિયમિત પ્રશ્ન છે.
અચળ વિધેયનું વિકલન: d/dx(c) = 0; d/dx(x) = 1; d/dx(k) = 0 (k અચળ). આ મૂળભૂત પરિણામો યાદ રાખવા જરૂરી છે.
આ મૂળભૂત વિકલન સૂત્રો GUJCET માં સીધા પ્રશ્નોમાં આવે છે.
વિકલનના રેખીય ગુણધર્મો: d/dx[f(x) ± g(x)] = f'(x) ± g'(x); d/dx[k·f(x)] = k·f'(x) (k અચળ). આ ગુણધર્મો જટિલ વિધેયોના વિકલનમાં મદદરૂપ થાય છે.
રેખીય ગુણધર્મો GUJCET માં વિકલન સરળ બનાવે છે.
ઉચ્ચ ક્રમના વિકલિતો: d³y/dx³, d⁴y/dx⁴ વગેરે. GUJCET માં સામાન્ય રીતે પ્રથમ અને દ્વિતીય ક્રમના વિકલિતો પૂછાતા હોય છે.
ઉચ્ચ ક્રમના વિકલિતો GUJCET માં દ્વિતીય વિકલન સુધી મર્યાદિત પ્રશ્નોમાં આવે છે.
