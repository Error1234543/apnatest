ચાલુકત્વ અને વિકલનીયતા (Continuity and Differentiability)

🧪 GUJCET — Gujarati • Mathematics • Continuity and Differentiability

📘 વ્યાખ્યાઓ

  • ચાલુકત્વ (Continuity): f એ x = a પર ચાલુ છે જો lim(x→a) f(x) = f(a) હોય.
  • વામચાલુકત્વ (Left-hand continuity): lim(x→a⁻) f(x) = f(a) હોય તો f, x = a પર ડાબે ચાલુ છે.
  • દક્ષિણચાલુકત્વ (Right-hand continuity): lim(x→a⁺) f(x) = f(a) હોય તો f, x = a પર જમણે ચાલુ છે.
  • વિકલનીયતા (Differentiability): f એ x = a પર વિકલનીય છે જો f'(a) અસ્તિત્વમાં હોય, એટલે lim(h→0) [f(a+h) - f(a)] / h મર્યાદિત હોય.
  • વામઅવકલન (Left derivative): f'_-(a) = lim(h→0⁻) [f(a+h) - f(a)] / h
  • દક્ષિણઅવકલન (Right derivative): f'_+(a) = lim(h→0⁺) [f(a+h) - f(a)] / h

⚡ સૂત્રો

  • d/dx(x^n) = n·x^(n-1)
  • d/dx(sin x) = cos x
  • d/dx(cos x) = -sin x
  • d/dx(tan x) = sec²x
  • d/dx(cot x) = -csc²x
  • d/dx(sec x) = sec x · tan x
  • d/dx(cosec x) = -cosec x · cot x
  • d/dx(e^x) = e^x
  • d/dx(a^x) = a^x · log a
  • d/dx(log x) = 1/x
  • d/dx[sin⁻¹x] = 1/√(1-x²), |x| < 1
  • d/dx[cos⁻¹x] = -1/√(1-x²), |x| < 1
  • d/dx[tan⁻¹x] = 1/(1+x²)
  • d/dx[cot⁻¹x] = -1/(1+x²)
  • d/dx[sec⁻¹x] = 1/(|x|√(x²-1)), |x| > 1
  • d/dx[cosec⁻¹x] = -1/(|x|√(x²-1)), |x| > 1
  • ગુણन ફોર્મ્યુલા: d/dx[u·v] = u·dv/dx + v·du/dx
  • ભાગફળ ફોર્મ્યુલા: d/dx[u/v] = (v·du/dx - u·dv/dx)/v²
  • શૃંખલા નિયમ (Chain rule): d/dx[f(g(x))] = f'(g(x)) · g'(x)
  • લઘુગણકીય વિકલન (Logarithmic differentiation): y = u^v લેતા, dy/dx = y[v/u · du/dx + v'·ln u]
  • અનુરૂપ ચલ વિકલન (Parametric): dx/dt = α, dy/dt = β હોય તો dy/dx = β/α

⭐ મુખ્ય તથ્યો

  • દરેક વિકલનીય વિધેય ચાલુ પણ હોય છે, પરંતુ દરેક ચાલુ વિધેય વિકલનીય હોવું જરૂરી નથી.
  • f(x) = |x| એ x = 0 પર ચાલુ છે પણ વિકલનીય નથી કારણ કે f'_-(0) ≠ f'_+(0).
  • બહુપદી વિધેયો સૌવિધેયો પર ચાલુ અને વિકલનીય હોય છે.
  • ત્રિકોણમિતીય વિધેયો sin x, cos x, e^x, log x તેમના પ્રાધાન્ય ક્ષેત્રમાં ચાલુ અને વિકલનીય હોય છે.
  • f(x) = [x] (મહત્તમ પૂર્ણાંક વિધેય) એ દરેક પૂર્ણાંક x પર અસંતત છે.
  • f(x) = |x - a| એ x = a પર ચાલુ છે પણ વિકલનીય નથી.
  • દ્વિ-ઘાતીય વિકલજ: d²y/dx² = d/dx(dy/dx)
  • Lagrange મધ્યમ પ્રમેય (Mean Value Theorem): f એ [a,b] પર ચાલુ અને (a,b) પર વિકલનીય હોય તો ∃ c ∈ (a,b) such that f'(c) = (f(b)-f(a))/(b-a).
  • Rolle's Theorem: MVT નું વિશેષ રૂપ જ્યાં f(a) = f(b) ⇒ f'(c) = 0.
  • y = [x] એ x = 0, ±1, ±2, ... આગળ અસંતત છે અને ત્યાં વિકલનીય પણ નથી.
  • y = {x} (ફલક部分) વિધેય દરેક પૂર્ણાંક બિંદુએ અસંતત છે.
  • શૃંખલા નિયમનો ઉપયોગ જ્યારે વિધેય સંયોજિત (composite) હોય ત્યારે કરવો પડે.

⚠️ સામાન્ય ભૂલો

  • ચાલુકત્વ અને વિકલનીયતામાં ગેરસમજ: x = 0 પર f(x) = |x| ચાલુ છે પણ વિકલનીય નથી — આ સામાન્ય ભૂલ છે.
  • d/dx[sin⁻¹x] માં √(1-x²) નિઃશ્શેષ (absolute value) લેવાનું ભૂલી જવાય છે.
  • શૃંખલા નિયમમાં બાહ્ય અને આંતરિક વિધેયને ઓળખવામાં ભૂલ થાય છે.
  • લઘુગણકીય વિકલનમાં ln(u) નું વિકલન કરતી વખતે u/(du/dx) વિચારી લેવાય છે — ખોટું: સાચું v'/u · du/dx નહીં.
  • d/dx[a^x] માં log a આવે છે, ln a નહીં — a સંખ્યા હોય તો log a આવે.
  • અનુરૂપ ચલમાં dy/dx = (dy/dt)/(dx/dt) એ dx/dt ≠ 0 હોવું જોઈએ.
  • Rolle's theorem ની શરતો તપાસ્યા વગર જ f'(c) = 0 લખી દેવાય છે — પ્રથમ ચાલુકત્વ અને વિકલનીયતા તપાસવી.
  • MVT માં c શોધતી વખતે (a,b) વિવૃત અંતરાલ યાદ રાખવું — a અને b બિંદુઓ બાદ કરવા.
  • f(x) = x·|x| નું x = 0 પર વિકલન શોધતી વખતે પ્રારંભિક વ્યાખ્યા વાપરવી પડે.
  • sin⁻¹x + cos⁻¹x = π/2 એ તથ્યમાંથી વિકલજ શૂન્ય મળે છે — આગે આંખે રાખવું.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • f એ x = a પર ચાલુ છે ⇔ f(a⁻) = f(a) = f(a⁺) — આ ત્રણેય સમાન હોવા જોઈએ.
  • વિકલનીયતા તપાસવા માટે f'_-(a) = f'_+(a) હોવું જરૂરી અને પૂરતું છે.
  • y = sin⁻¹x નું વિકલન મેળવવા f(y) = x ⇒ cos y · y' = 1 ⇒ y' = 1/cos y = 1/√(1-x²).
  • Implicit differentiation: xy = 1 ⇒ y + x·dy/dx = 0 ⇒ dy/dx = -y/x.
  • y = (sin x)^x નું વિકલન: log લેતા log y = x·log(sin x), તયાગુત્તર વિકલન કરવું.
  • f(x) = x³ - 3x + 2 પર Rolle's theorem લાગુ પડે: f(-2) = f(1) = 0, તેથી ∃ c ∈ (-2,1) with f'(c) = 0.
  • f(x) = x² on [0,2] માટે MVT: f'(c) = (4-0)/(2-0) = 2 ⇒ 2c = 2 ⇒ c = 1 ∈ (0,2).
  • દ્વિ-ઘાતીય વિકલજ: y = x² ⇒ dy/dx = 2x ⇒ d²y/dx² = 2.
  • y = e^(sin x) માટે: dy/dx = e^(sin x)·cos x; d²y/dx² = e^(sin x)(cos²x - sin x).
  • ગુણન નિયમ: d/dx[x·sin x] = sin x + x·cos x — યાદ રાખો.
  • f(x) = x|x| નું x = 0 પર વિકલન: f'_-(0) = 0, f'_+(0) = 0 ⇒ f'(0) = 0 (વિકલનીય છે!).
  • y = tan⁻¹[(√1+x²-1)/x] માટે પદ્ધતિ: x = tan θ મૂકતા સાદુંરૂપ મળે છે.
