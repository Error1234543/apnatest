સતતતા તથા વિકલનીયતા (Continuity and Differentiability)

🧪 GUJCET — Gujarati • Mathematics • Continuity and Differentiability

⭐ મહત્વના મુદ્દા

વિધેય f(x) એ x = a બિંદુએ સતત છે તેટલું જોતાં: (i) f(a) અસ્તિત્વ ધરાવતું હોવું જોઈએ, (ii) lim x→a f(x) અસ્તિત્વ ધરાવતું હોવું જોઈએ, (iii) lim x→a f(x) = f(a) હોવું જોઈએ. આ ત્રણેય શરતોનો સામૂહિક અભાવ અસતતતા દર્શાવે છે.
સતતતાની વ્યાખ્યાનો આધાર છે; GUJCET માં અనేક MCQ અને numerical પ્રશ્નો આ ત્રણેય શરતોના પરීક્ષણ પર આધારિત હોય છે.
અંતરાલ (α, β) માં વિધેય સતત છે એટલું કે તે દરેક બિંદુએ સતત છે. વિરોધી રીતે, અંતરાલ [α, β] માટે ડાબી પ્રান্তિકા (left-endpoint) x = α પર જમણી બાજુથી અને જમણી પ્રાયંતિકા x = β પર ડાબી બાજુથી સતત હોવી જરૂરી છે.
સતતતાનું ક્ષેત્ર (domain) નક્કી કરવા અને પ્રાયંતિકાઓ પરની સતતતા સમજવા માટે આવશ્યક છે; ગ્રાફ પરથી ચકાસણી પ્રશ્નો આવે છે.
જો f(x) અને g(x) બંને x = a બિંદુએ સતત હોય, તો f ± g, fg, f/g (જ્યાં g(a) ≠ 0) પણ x = a એ સતત હશે. તેમજ, સંયોજિત વિધેય f ∘ g (composition) માં જો g continuous at a and f continuous at g(a), તો f ∘ g at a સતત હશે.
સંયુક્ત વિધેયોની સતતતા ચકાસવાનો આ નિયમ GUJCET માં frequently tested algebraic property છે.
બહુપદી વિધેયો (polynomial functions) સર્વત્ર સતત હોય છે. ત્રિકોણમિતિ વિધેયો sin x, cos x સર્વત્ર સતત, જ્યારે tan x, sec x, cosec x, cot x તેમના અનિર્ધારિત બિંદુઓ (જ્યાં હર (denominator) શૂન્ય) બાદ સર્વત્ર સતત હોય છે.
વિધેયની સતતતા ચકાસતા પહેલાં જાણીતી વિધેયોના પ્રકાર યાદ હોવા જરૂરી છે; MCQ માં સીધો પ્રશ્ન આવે છે.
વિકલનીયતાની વ્યાખ્યા: f(x) એ x = a બિંદુએ વિકલનીય છે જો f'(a) = lim h→0 [f(a+h) - f(a)]/h અસ્તિત્વ ધરાવતું હોય. અંતરાલ (α, β) માં વિકલનીય એટલે દરેક બિંદુએ વિકલનીય હોવું.
વિકલનીયતાનો મૂળભૂત સંકલન (limit definition) સમજવો આવશ્યક છે; પ્રારંભિક બિંદુ પદ્ધતિના પ્રશ્નો આ વ્યાખ્યા પર આધારિત છે.
વિકલનીયતા ⇒ સતતતા, પરંતુ સતતતા ⇒ વિકલનીયતા નહીં. ઉદા. f(x) = |x - 1| એ x = 1 બિંદુએ સતત પણ વિકલનીય નથી, કારણ કે ડાબું અને જમણું વિકલન અલગ છે.
આ મહત્વપૂર્ણ અવકલન સાધન છે; GUJCET માં True/False પ્રકારના અને વિધેય-ગુણધર્મ પ્રશ્નો બંને આવે છે.
વિકલનીયતા માટેની આવશ્યક અને પૂરતી શરત: f'(a⁺) = f'(a⁻) (ડાબું અને જમણું વિકલ સમાન હોવું). આ બંને સીમાઓ અસ્તિત્વ ધરાવતી અને સમાન હોવી જોઈએ.
વિરલ બિંદુ (critical point) પર વિકલનીયતા ચકાસવાનો આ સીધો નિયમ છે; |x| પ્રકારના પ્રશ્નોમાં આવર્તન છે.
પ્રારંભિક બિંદુ પદ્ધતિ (First Principle Method): f'(x) = lim h→0 [f(x+h) - f(x)]/h. વજનદાર વિધેયોના વિકલન પ્રશ્નોમાં આ પદ્ધતિનો ઉપયોગ થાય છે, ખાસ કરીને વર્ગમૂળ, ભિન્ન રૂપ અને ત્રિકોણમિતિ વિધેયો માટે.
प्रारंभिक बिन्दु પદ્ધતિ પરનો પ્રશ્ન GUJCET માં નિશ્चित રૂપે આવે છે; સૂત્ર યાદ રાખવું અને સાબિતી લખવી આવશ્યક છે.
મૂળભૂત વિકલન સૂત્રો: d/dx (x^n) = n·x^(n-1); d/dx (c) = 0; d/dx (sin x) = cos x; d/dx (cos x) = -sin x; d/dx (tan x) = sec²x; d/dx (e^x) = e^x; d/dx (log x) = 1/x.
સામાન્ય રીતે દરેક પ્રશ્નના આધારે આ સૂત્રોનો ઉપયોગ થાય છે; સૂત્રોની મહત્વપૂર્ણ યાદદાસ્ત GUJCET માટે અનિવાર્ય છે.
ગુણન નિયમ (Product Rule): d/dx [u·v] = u'·v + u·v'. ભાગાકાર નિયમ (Quotient Rule): d/dx [u/v] = [u'·v - u·v'] / v² (જ્યાં v ≠ 0).
બે અથવા તેથી વધુ પદો વાળા વિધેયોના વિકલનમાં આ નિયમોનો સીધો ઉપયોગ થાય છે; numerical પ્રશ્નોમાં mandatory છે.
શૃંખલા નિયમ (Chain Rule): જો y = f(u) અને u = g(x) હોય, તો dy/dx = (dy/du)·(du/dx). ઉદા. d/dx [sin(x²)] = cos(x²)·2x.
સંયોજિત વિધેયો (composite functions) ના વિકલન માટે Chain Rule અત્યંત મહત્વપૂર્ણ છે; GUJCET માં maximum occurrences વાળો નિયમ છે.
વ્યસ્ત ત્રિકોણમિતિ વિધેયોના વિકલન: d/dx [sin⁻¹x] = 1/√(1-x²), |x| < 1; d/dx [cos⁻¹x] = -1/√(1-x²); d/dx [tan⁻¹x] = 1/(1+x²).
આ નિયમો અંતર્ગત (inverse trigonometric) પ્રશ્નોમાં frequently tested છે અને Chain Rule સાથે મળીને hybrid પ્રશ્નો બને છે.
ઘાતાંકીય અને લઘુગણક વિધેયોના વિકલન: d/dx [a^x] = a^x · log a; d/dx [e^{g(x)}] = e^{g(x)} · g'(x); d/dx [log_a x] = 1/(x · log a); d/dx [log(g(x))] = g'(x)/g(x).
આ સૂત્રો exponential/logarithmic functions પરના પ્રશ્નો માટે essential છે; chain rule સાથે joint appearance common છે.
અવ્યક્ત રીતે વિકલન (Implicit Differentiation): જો f(x,y) = 0 હોય, તો y ને x નું વિધેય માનીને બંને બાજુ x ની સાપેક્ષે વિકલન કરતાં dy/dx મળે છે. ઉદા. x² + y² = r² માટે dy/dx = -x/y.
અવ્યક્ત વિધેયોના વિકલન પ્રશ્નો GUJCET માં standard type છે; implicit differentiation નો માધ્યમ સમજવો જરૂરી છે.
આપેલ વિધેય f(x) = √(x² - 1) નું વિકલનીયતા પ્રદેશ (domain of differentiability): |x| > 1, કારણ કે x = ±1 બિંદુએ radical વિધેય non-differentiable છે. સામાન્ય રીતે, સતત પરંતુ sharp corner/vertical tangent ધરાવતી જગ્યાએ વિધેય વિકલનીય હોતું નથી.
વિકલનીયતા પ્રદેશ શોધવાના પ્રશ્નો GUJCET માં recurring type છે; graph visualization skill required છે.
વિકલનનો ભૌમિતિક અર્થ: f'(a) એ વक्र (curve) y = f(x) ના x = a બિંદુએ સ્પર્શકનું ઢાળ (slope) દર્શાવે છે. સ્પર્શકનું સમીકરણ: y - f(a) = f'(a)(x - a).
સ્પર્શક-લંબ (tangent-normal) પ્રશ્નો GUJCET માં numerical પ્રકારે આવે છે; derivative નો geometric meaning essential છે.
સાપેક્ષ વિકલન (Relative/Derivative at a point): જો f(x) = x³ - 3x² + 2, તો x = 1 બિંદુએ f'(1) = -3. આ રીતે, કોઈ પણ ચોક્કસ બિંદુએ વિકલજ શોધવા માટે પહેલાં સામાન્ય વિકલન કરીને તે બિંદુ મૂકવું.
specific point on derivative finding is very direct calculation type question that appears regularly in GUJCET.
પરિમાણો વિકલન (Parametric Differentiation): જો x = f(t) અને y = g(t) હોય, તો dy/dx = (dy/dt) / (dx/dt). ઉદા. x = a cos t, y = b sin t માટે dy/dx = -(b/a) cot t.
parametric વિધેયોના પ્રશ્નો GUJCET માં predictable pattern છે; parametric differentiation એ distinct topic છે.
વિકલનીય વિધેયોના ધર્મો: જો f વિકલનીય હોય, તો |f| વિકલનીય હોય તે જરૂરી નથી (ઉદા. f(x) = x at x = 0). વળી, f વિકલનીય અને f ≠ 0 હોય તો 1/f પણ વિકલનીય હોય છે.
આ kind of conceptual questions test deep understanding; true/false type GUJCET પ્રશ્નો માટે direct relevance છે.
મહત્વપૂર્ણ વિકલન સૂત્ર: d/dx [log x] = 1/x જ્યાં log એ natural logarithm (ln) છે. સામાન્ય આધાર a માટે: d/dx [log_a x] = 1/(x ln a). આ distinction ખૂબ મહત્વપૂર્ણ છે.
log base confusion GUJCET માં common error છે; log x vs log₁₀ x નો તફાવત clear રાખવો જરૂરી છે.
Second Derivative: f''(x) = d/dx[f'(x)]. જો f'(c) = 0 અને f''(c) > 0 હોય, તો f(c) ન્યૂનતમ (local minimum); f''(c) < 0 હોય તો વધુતમ (local maximum). આ શરતો maxima/minima શોધવામાં મદદરૂપ છે.
second derivative test એ optimization problems માટે fundamental tool છે; GUJCET માં indirect application થાય છે.
મધ્યસ્થતા પ્રમેય (Mean Value Theorem - MVT): જો f [a,b] માં સતત અને (a,b) માં વિકલનીય હોય, તો ∃ c ∈ (a,b) such that f'(c) = [f(b) - f(a)]/(b-a). MVT નું ભૌમિતિક અર્થ: curve પર એક બિંદુ જ્યાં સ્પર્શક chord ને સમાંતર હોય.
MVT એ continuity-differentiability chapter નું સૌથી મહત્વપૂર્ણ પ્રમેય છે; both theoretical и numerical प्रश্নो આવે છે.
Roland's પ્રમેય ( Rolle's Theorem ): જો f [a,b] માં સતત, (a,b) માં વિકલનીય, અને f(a) = f(b) હોય, તો ∃ c ∈ (a,b) such that f'(c) = 0. Rolle's Theorem એ MVT નું વિશેષ કિસ્સો છે.
Rolle's theorem એ standard proof-type and application-type questions માટે basis છે; MVT સાથે confused not કરવું.
વિકલનીયતા અને સતતતા સંબંધિત દૃઢ પ્રमेय: જો f સતત હોય પણ尖锐 point (sharp corner), cusp, અથવા vertical tangent ધરાવતું હોય, તો તે બિંદુએ f વિકલનીય નથી. ઉદા. f(x) = |x| at x = 0.
graph-based differentiability determination એ very common GUJCET question pattern છે; visual identification skill required છે.
મહત્વના વિશેષ વિકલન પરિણામો: d/dx [x^n] = nx^(n-1) (n કોઈ પણ વાસ્તવિક સંખ્યા); d/dx [sin⁻¹x + cos⁻¹x] = 0 (કારણ sin⁻¹x + cos⁻¹x = π/2 સતત અચળ છે); d/dx [tan⁻¹x + cot⁻¹x] = 0.
આ identity-based derivative results GUJCET માં clever shortcut questions બનાવે છે; time-saving માટે essential છે.
