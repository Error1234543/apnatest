મેટ્રિક્સ — સંપૂર્ણ અધ્યયન નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Matrices

મેટ્રિક્સ એ ગાણિતિક રચના છે જે ચોરસ કોષ્ટક સ્વરૂપે ઘટકોને ગોઠવે છે અને બહુપરીમાણીય સમસ્યાઓને સરળતાથી સંચાલિત કરવામાં મદદરૂપ થાય છે. આ અધ્યાયમાં તમે મેટ્રિક્સના વિવિધ પ્રકારો, તેમના પર સંકલન, બાદબાકી, ગુણાકાર અને પ્રસ્તાર જેવી ક્રિયાઓ અંગે અભ્યાસ કરશો. વધુમાં પ્રારંભિક રૂપાંતરો, વિલોમ મેટ્રિક્સ અને સુરેખ સમીકરણ સિસ્ટમને મેટ્રિક્સ આધારિત પદ્ધતિઓથી ઉકેલવાની રીતોનો અભ્યાસ કરવો અત્યંત મહત્વનો છે, કારણ કે આ વિષય જર્બ્રા, ઇજનેરી અને આંકડાકીય પ્રયોગોમાં સતત વપરાય છે.

મેટ્રિક્સનો પરિચય

મેટ્રિક્સ એ ચોક્કસ ગોઠવણીમાં ગોઠવાયેલા વાસ્તવિક અથવા સંકર સંખ્યાઓનો વર્ગાકાર (array) છે. મેટ્રિક્સને સામાન્ય રીતે કૌંસ [...] અથવા વલયાકાર કૌંસ () દ્વારા દર્શાવવામાં આવે છે. દરેક સંખ્યાને અવયવ અથવા ઘટક કહે છે. મેટ્રિક્સનું ક્રમ (order) હિંદુ-અરબી સંખ્યા રૂપે m × n લખાય છે, જ્યાં m સ્તંભોની સંખ્યા અને n સત્રોની સંખ્યા દર્શાવે છે. ઉદાહરણ તરીકે, બે સત્ર અને ત્રણ સ્તંભ ધરાવતો મેટ્રિક્સ 2 × 3 ક્રમનો કહેવાય. મેટ્રિક્સનું સામાન્ય પ્રતિનિધિત્વ A = [aᵢⱼ]ₘ×ₙ રૂપે કરવામાં આવે છે, જ્યાં aᵢⱼ એ i-મા સત્ર અને j-મા સ્તંભનો ઘટક છે. આ ચિહ્નો અને રચનાનું સ્પષ્ટ જ્ઞાન આગળના તમામ ગુણધર્મો સમજવા માટે અત્યંત આવશ્યક છે.

A = [aᵢⱼ]i-મો સત્ર, j-મો સ્તંભનો ઘટક

મેટ્રિક્સના પ્રકારો

મેટ્રિક્સના ઘણા પ્રકારો છે, જેનો અભ્યાસ આ અધ્યાયમાં મૂળભૂત રીતે કરવામાં આવે છે. સિંગલ્ટન (row) મેટ્રિક્સમાં ફક્ત એક જ સત્ર હોય છે, જ્યારે સ્તંભ (column) મેટ્રિક્સમાં ફક્ત એક જ સ્તંભ હોય છે. ચોરસ (square) મેટ્રિક્સ એવો મેટ્રિક્સ છે જેના સત્રો અને સ્તંભોની સંખ્યા સમાન હોય. વિકર્ણ (diagonal) મેટ્રિક્સ એવા ચોરસ મેટ્રિક્સ છે જેમાં વિકર્ણ સિવાયના બધા ઘટક શૂન્ય હોય. સ્કેલર (scalar) મેટ્રિક્સ એ વિકર્ણ મેટ્રિક્સ છે જેમાં વિકર્ણ પરના બધા ઘટક સમાન હોય. જ્યારે બધા ઘટકો શૂન્ય હોય તો તેને શૂન્ય (null/zero) મેટ્રિક્સ કહે છે. પ્રસ્તાર (transpose) મેટ્રિક્સ એવા મેટ્રિક્સ છે જેમાં સત્રો અને સ્તંભોની અદલાબદલી કરવામાં આવે. અન્ય મહત્વના પ્રકારોમાં ઉચ્ચ ત્રિકોણીય (upper triangular), નીચલ ત્રિકોણીય (lower triangular) અને વિષમ સંમિત (skew-symmetric) મેટ્રિક્સનો સમાવેશ થાય છે.

એકમ અને શૂન્ય મેટ્રિક્સ

એકમ મેટ્રિક્સ (Identity Matrix) એ એક વિશિષ્ટ ચોરસ મેટ્રિક્સ છે જેના વિકર્ણના બધા ઘટક 1 હોય છે અને અન્ય બધા ઘટક શૂન્ય હોય છે. તેને I અથવા On દ્વારા દર્શાવવામાં આવે છે. k ક્રમનો એકમ મેટ્રિક્સ Ik રૂપે લખાય છે. મૂળભૂત ગુણધર્મ એ છે કે કોઈ પણ k × k ચોરસ મેટ્રિક્સ A માટે IA = AI = A થાય છે. શૂન્ય મેટ્રિક્સ (Zero/Null Matrix) માં બધા જ ઘટકો શૂન્ય હોય છે; તેને O અથવા 0 દ્વારા દર્શાવવામાં આવે છે. શૂન્ય મેટ્રિક્સનો ક્રમ વિવિધ હોઈ શકે છે, જોકે મેટ્રિક્સ સરવાળા માટે સમાન ક્રમના શૂન્ય મેટ્રિક્સનો ઉપયોગ થાય છે. A + O = O + A = A અને OA = AO = O જેવા ગુણધર્મો વર્તે છે. આ બંને મેટ્રિક્સનું સ્પષ્ટ મહત્વ મેટ્રિક્સ બીજગણિતના આગળના વિશ્લેષણમાં જોવા મળે છે.

પ્રસ્તાર અને સંમિતિ

જ્યારે કોઈ મેટ્રિક્સના સત્રો અને સ્તંભોની અદલાબદલી કરવામાં આવે છે ત્યારે જે મેટ્રિક્સ મળે છે તેને તે મેટ્રિક્સનો પ્રસ્તાર (Transpose) કહે છે. A નો પ્રસ્તાર A' અથવા Aᵀ દ્વારા દર્શાવવામાં આવે છે. પ્રસ્તારના મૂળભૂત ગુણધર્મોમાં (A')' = A, (A + B)' = A' + B', (kA)' = kA' અને (AB)' = B'A'નો સમાવેશ થાય છે. જો A એ k × k ચોરસ મેટ્રિક્સ હોય અને A' = A હોય, તો A ને સંમિત (Symmetric) મેટ્રિક્સ કહે છે; આરજે કિસ્સામાં A' = -A હોય તો તેને વિષમ સંમિત (Skew-symmetric) મેટ્રિક્સ કહે છે. સંમિત મેટ્રિક્સમાં aᵢⱼ = aⱼᵢ હોય છે, જ્યારે વિષમ સંમિતમાં aᵢⱼ = -aⱼᵢ અને વિકર્ણ ઘટકો શૂન્ય હોય છે. આ પ્રકારના મેટ્રિક્સ ભૌતિકશાસ્ત્ર અને ઇજનેરી ક્ષેત્રે બહુપ્રયોગી હોય છે.

(A+kB)'= A'+kB'

મેટ્રિક્સનો સરવાળો અને બાદબાકી

બે મેટ્રિક્સનો સરવાળો કેવળ ત્યારે જ શક્ય છે જ્યારે તેઓ સમાન ક્રમના હોય. જો A = [aᵢⱼ] અને B = [bᵢⱼ] બંને m × n ક્રમના હોય, તો A + B = [aᵢⱼ + bᵢⱼ] રૂપે પરિણમે છે. સરવાળાના ગુણધર્મોમાં સંયોજક (associative), ક્રમચયી (commutative), તટસ્થ તત્વ (O) અને વિરોધી તત્વ (-A)નો સમાવેશ થાય છે. એટલે કે, A + B = B + A, (A + B) + C = A + (B + C), A + O = A, અને A + (-A) = O. બાદબાકી માટે પણ સમાન ક્રમની શરત લાગુ પડે છે અને A − B = A + (−B) રૂપે ગણવામાં આવે છે. આ સરળતા છતાં બે અસમાન ક્રમના મેટ્રિક્સનો સરવાળો અથવા બાદબાકી કરવી અશક્ય છે, જે વિદ્યાર્થીઓ માટે સામાન્ય ખોટનો વિષય છે. અત્યંત ધ્યાન રાખવું જરૂરી છે.

મેટ્રિક્સનો ગુણાકાર

મેટ્રિક્સનો ગુણાકાર બે પ્રકારનો હોય છે: અદિશ ગુણાકાર (Scalar Multiplication) અને મેટ્રિક્સ ગુણાકાર. અદિશ ગુણાકારમાં દરેક ઘટકને અદિશ k વડે ગુણવામાં આવે છે; kA = [k·aᵢⱼ]. મેટ્રિક્સ ગુણાકારમાં A (m × n) અને B (n × p) હોય ત્યારે જ AB શક્ય છે, અને પરિણામી મેટ્રિક્સનો ક્રમ m × p થાય. AB નો i-મો સત્ર-j-મો સ્તંભ ઘટક = Σ aᵢₖ · bₖⱼ (k = 1 થી n). મેટ્રિક્સ ગુણાકાર ક્રમચયી નથી એટલે કે AB ≠ BA સામાન્ય રીતે; કેટલાક કિસ્સાઓમાં સમાનતા મળી શકે છે, પણ સામાન્ય નિયમ નથી. ગુણાકારના ગુણધર્મોમાં સંયોજક, વિતરણાત્મક અને તટસ્થ તત્વ (I) નો સમાવેશ થાય છે: A(BC) = (AB)C, A(B+C) = AB+AC, અને AI = IA = A.

પ્રારંભિક રૂપાંતરો

પ્રારંભિક રૂપાંતર (Elementary Transformation) એ મેટ્રિક્સ પર લાગુ પડતી ત્રણ મૂળભૂત ક્રિયાઓ છે: (1) કોઈ એક સત્ર અથવા સ્તંભને અદિશ k ≠ 0 વડે ગુણવા (મુળ્ય બદલો), (2) કોઈ સત્ર અથવા સ્તંભનું અન્ય સત્ર/સ્તંભ સાથે સંયોજન કરવું, (3) બે સત્રો અથવા બે સ્તંભોની અદલાબદલી કરવી. રૉ રૂપાંતર (Row Transformation) અને કૉલમ રૂપાંતર (Column Transformation) એમ બે પ્રકારના હોય છે. આ રૂપાંતરો મેટ્રિક્સને સાધારણ રૂપમાં (Canonical Form) અથવા વિલોમ મેટ્રિક્સ શોધવા માટે ઉપયોગી થાય છે. રૂપાંતર દરમિયાન મેટ્રિક્સનો ક્રમ બદલાતો નથી, પણ મૂલ્યો બદલાય છે. વિલોમ મેટ્રિક્સની પદ્ધતિમાં I = Eₖ...E₂E₁A લખીને R પર રૂપાંતર લાગુ પાડવામાં આવે છે જેથી A → I થાય.

Rᵢ → Rᵢ + kRⱼસંયોજન કરવું

વિલોમ મેટ્રિક્સ

જો A એ ચોરસ મેટ્રિક્સ હોય અને કોઈ ચોરસ મેટ્રિક્સ B હોય કે જેથી AB = BA = I હોય, તો B ને A નો વિલોમ (Inverse) કહે છે અને B = A⁻¹ લખાય. A⁻ૃક્ષ રહેવા માટે |A| ≠ 0 હોવું આવશ્યક છે; |A| = 0 હોય તો A નિર્ગુણ્ય (Singular) કહેવાય અને તેનો વિલોમ અસ્તિત્વ ધરાવતો નથી. વિલોમ શોધવાની બે પદ્ધતિઓ છે: (1) પ્રારંભિક રૂપાંતર પદ્ધતિ, (2) Adj (Adjoint) પદ્ધતિ. Adjoint પદ્ધતિ મુજબ A⁻¹ = (1/|A|) · adj(A). અહીં adj(A) એ A ના ઘટકોના અવયવકો (cofactors) ના કોષ્ટકનો પ્રસ્તાર છે. બે વિલોમીય ચોરસ મેટ્રિક્સના ગુણાકારનો વિલોમ (AB)⁻¹ = B⁻¹A⁻¹ થાય છે. આ વિષય GUJCET માટે ખૂબ જ મહત્વપૂર્ણ છે.

સુરેખ સમીકરણોનો મેટ્રિક્સ દ્વારા ઉકેલ

બે અથવા ત્રણ ચલો ધરાવતા સુરેખ સમીકરણોના જોડાણને AX = B રૂપે લખી શકાય, જ્યાં A ગુણાંક મેટ્રિક્સ, X ચલોનો સ્તંભ મેટ્રિક્સ અને B અચળાંકનો સ્તંભ મેટ્રિક્સ છે. જો |A| ≠ 0 હોય, તો A વિલોમીય છે અને ઉકેલ X = A⁻¹B દ્વારા મળે છે, જે અનન્ય (unique) હોય છે. જો |A| = 0 હોય, તો AB (adj A)B શોધવામાં આવે છે. જો AB ≠ 0 હોય, તો સિસ્ટમ અસંગત (inconsistent) છે અને ઉકેલ નથી. જો AB = 0 હોય અને at least એક અચળ શૂન્ય ન હોય, તો સિસ્ટમ સંગત (consistent) અને સમીકરણો સાર્વત્રિક (dependent) છે; અનંત ઉકેલો મળે છે. આ પદ્ધતિ GUJCET માં સૌથી વધુ પૂછાતી પદ્ધતિ છે.

⭐ મહત્વના મુદ્દા

  • મેટ્રિક્સ સરવાળો/બાદબાકી માત્ર સમાન ક્રમના મેટ્રિક્સ માટે જ શક્ય છે.
  • મેટ્રિક્સ ગુણાકાર ક્રમચયી નથી; સામાન્ય રીતે AB ≠ BA.
  • વિલોમ મેટ્રિક્સ માટે |A| ≠ 0 હોવું અનિવાર્ય છે.
  • એકમ મેટ્રિક્સ હંમેશા વિલોમીય હોય છે અને I⁻¹ = I.
  • કોઈ પણ ચોરસ મેટ્રિક્સ A માટે A · adj(A) = adj(A) · A = |A| · I.
  • |AB| = |A| · |B| અને |A'| = |A|.
  • જો A સંમિત હોય, તો A + A' પણ સંમિત છે; A − A' વિષમ સંમિત છે.
  • શૂન્ય મેટ્રિક્સનો વિલોમ અસ્તિત્વ ધરાવતો નથી.
  • રૂપાંતર પદ્ધતિમાં મેટ્રિક્સ A ને I સાથે જોડીને A → I કરવામાં આવે છે.
