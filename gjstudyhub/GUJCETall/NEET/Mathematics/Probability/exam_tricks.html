પ્રાચલાયતા (Probability) – ગુજરાતી ઝડપી ટ્રિક્સ અને એલિમિનેશન તકનીકો

🧪 GUJCET — Gujarati • Mathematics • Probability

🎯 પરીક્ષા ટ્રિક્સ

બધા સંભવિત પરિણામોના સંયુક્ત પ્રાચલાયતાનો સરવાળો હંમેશા 1 થાય. જો વિકલ્પોમાં આ મૂલ્ય તપાસવાની જગ્યા હોય, તો 'કુલ સંભાવના = 1' નો નિયમ લાગુ કરીને ખોટો વિકલ્પ દૂર કરી શકાય.
જ્યારે પ્રશ્નમાં બહુ-વિકલ્પી પ્રશ્નમાં તમામ સંભવિત ઘટનાઓના પ્રાચલાયતાનો સરવાળો પૂછવામાં આવ્યો હોય અથવા કોઈ એક ઘટનાનો પ્રાચલાયતા મેળવવા માટે પૂરક ઘટના વાપરવી હોય.
દા.ત.: P(A) + P(A') = 1. જો P(A) = 3/7 હોય, તો P(A') = 1 - 3/7 = 4/7. જવાબમાં 4/7 ન હોય તો તે વિકલ્પ ખોટો છે.
'કમ્બિનેટોરિયલ' પદ્ધતિને બદલે સીધો 'ઉચ્ચારણ' (Outcome) ગણતરી વડે સરળ પ્રશ્નો ઉકેલો. જો n એકમો પૈકી k પસંદ કરવાના હોય, તો C(n,k) = n! / [k!(n-k)!] યાદ રાખો અને જવાબ ચકાસો.
જ્યારે પ્રશ્નમાં કાર્ડ, સિક્કો, અથવા ગોળાઓની ખેંચવણ (drawing) સંબંધિત હોય અને મળીને ગણતરી કરવી હોય.
દા.ત.: એક સામાન્ય પાસા ફેંકતા સમ (even) આવે તેવી પ્રાચલાયતા: favorable = {2,4,6} = 3, total = 6, P = 3/6 = 1/2.
બે ઘટના A અને B માટેનો 'અથવા' નિયમ: P(A∪B) = P(A) + P(B) − P(A∩B). જો A અને B પરસ્પર અસંભવ (mutually exclusive) હોય, તો P(A∩B) = 0 હોય, તેથી P(A∪B) = P(A) + P(B).
જ્યારે પ્રશ્નમાં બે ઘટનાના સંયુક્ત પ્રાચલાયતા (union) પૂછવામાં આવ્યા હોય અથવા વિકલ્પોમાંથી સાચો વિકલ્પ ઓળખવાનો હોય.
દા.ત.: P(A) = 0.4, P(B) = 0.5, P(A∩B) = 0.2 તો P(A∪B) = 0.4 + 0.5 − 0.2 = 0.7.
'કેમ ઓછામાં ઓછું એક' પ્રકારના પ્રશ્નમાં સીધી ગણતરી કરવાને બદલે પૂરક (complement) પદ્ધતિ વાપરો: P(ઓછામાં ઓછું એક) = 1 − P(કોઈ પણ ન હોય). આ પ્રશ્નનો સમય અર્ધો કરી દે છે.
જ્યારે પ્રશ્નમાં 'ઓછામાં ઓછું એક', 'કંઈક એક', 'આધાર' જેવા શબ્દો હોય.
દા.ત.: ત્રણ સિક્કા ઉછાળવામાં ઓછામાં ઓછું એક છાપ (head) આવે તેની પ્રાચલાયતા: 1 − P(બધા અંક) = 1 − (1/2)³ = 1 − 1/8 = 7/8.
સ્વતંત્ર ઘટનાઓ (Independent events) માટે ગુણાકાર નિયમ: P(A∩B) = P(A) × P(B). જો પ્રશ્નમાં 'સ્વતંત્ર' શબ્દ હોય, તો આ સીધો વપરાય. બિન-સ્થાને (without replacement) ક્ષેત્રે આ નિયમ લાગુ પડતો નથી.
જ્યારે બે કે વધુ ઘટનાઓ સ્વતંત્ર હોય અને તેમના સંયુક્ત પ્રાચલાયતા (intersection) ની પ્રાપ્તિ થતી હોય.
દા.ત.: A અને B સ્વતંત્ર છે, P(A) = 1/3, P(B) = 1/4. તો P(A∩B) = 1/3 × 1/4 = 1/12.
શરતી પ્રાચલાયતા (Conditional probability) P(A|B) = P(A∩B) / P(B). યાદ રાખો: 'B થયું તો A થવાની સંભાવના'. જો P(B) = 0 હોય તો આ શૂન્ય નિર્વચિત છે.
જ્યારે પ્રશ્નમાં 'જો ... તો' અથવા '| (vertical bar)' સંકેત હોય.
દા.ત.: P(A∩B) = 0.2, P(B) = 0.5. તો P(A|B) = 0.2 / 0.5 = 0.4.
મેન્ડેલ નોટ (Mentioned) પ્રશ્નોમાં 'બેસનું ઉદાહરણ': જો ઘટનાઓ પરસ્પર અસંભવ (mutually exclusive) હોય અને સંપૂર્ણ (exhaustive) હોય, તો દરેકનો પ્રાચલાયતા સરવાળો 1 થાય.
જ્યારે પ્રશ્નમાં A, B, C હોય અને તેઓ પરસ્પર અસંભવ + સંપૂર્ણ જણાય. આ વિકલ્પોને સરળતાથી તપાસી શકાય.
દા.ત.: P(A) = 1/5, P(B) = 2/5, P(C) = 2/5. તેમનો સરવાળો = 1. તેથી A, B, C પરસ્પર અસંભવ અને સંપૂર્ણ છે.
પ્રાચલાયતા હંમેશા 0 ≤ P ≤ 1 વચ્ચે હોય. જો કોઈ વિકલ્પ -0.2 અથવા 1.5 આવે, તો તે ચોક્કસ ખોટો છે — ઇલિમિનેશનની સૌથી ઝડપી રીત.
દરેક પ્રશ્નમાં, વિશેષ કરીને જ્યારે સીધી ગણતરી ન હોય અને વિકલ્પો તપાસવા હોય.
દા.ત.: ચાર વિકલ્પો: 1/2, -1/3, 3/4, 5/4. -1/3 અને 5/4 બંને 0–1 વચ્ચે ન હોવાથી તરત જ બાદ કરો.
જો P(A∪B) = P(A) + P(B) આપેલ હોય, તો તરત જ નિષ્કર્ષ કાઢો: P(A∩B) = 0, એટલે કે A અને B પરસ્પર અસંભવ છે.
જ્યારે પ્રશ્નમાં union નો સરવાળો સીધો સરવાળા સમાન આપવામાં આવ્યો હોય.
દા.ત.: P(A) = 0.3, P(B) = 0.5, P(A∪B) = 0.8. 0.3 + 0.5 = 0.8 = P(A∪B). તેથી P(A∩B) = 0, A અને B પરસ્પર અસંભવ.
બેઝન પ્રમેય (Bayes' theorem) નું સૂત્ર યાદ રાખો: P(Aᵢ|B) = [P(B|Aᵢ) × P(Aᵢ)] / Σ[P(B|Aⱼ) × P(Aⱼ)]. 'B થયા પછી Aᵢ હોવાની સંભાવના' = [Aᵢ માંથી B ની શક્યતા × Aᵢ ની પ્રારંભિક સંભાવના] ÷ [બધા માર્ગોથી B ની કુલ શક્યતા].
જ્યારે પ્રશ્નમાં 'પહેલાં કોણ / કયા બોક્સ / કયો સંચય' જણાડવામાં આવ્યો હોય અને બીજા પગલામાં B પ્રત્યક્ષ થયું હોય.
દા.ત.: બોક્સ 1 માં 2 કાળા + 3 સફેદ, બોક્સ 2 માં 4 કાળા + 1 સફેદ. બોક્સ 1 પસંદ કરવાની P = 1/2. બોક્સ પસંદ કરી કાળો ગોળો ખેંચાય. P(બોક્સ 1 | કાળો) = [(2/5)(1/2)] / [(2/5)(1/2) + (4/5)(1/2)] = (2/10) / (6/10) = 1/3.
પુનરાવર્તિત પ્રયોગ (Repeated trial) માં, 'સરેરાશ મૂલ્ય' (Expected value) = n × p. જો n બોલ્સ પસંદગી અને p સફળતાની પ્રાચલાયતા હોય, તો અપેક્ષિત સફળતા n×p થાય.
જ્યારે પ્રશ્નમાં 'અપેક્ષિત સંખ્યા', 'mean', અથવા 'expected number' પૂછવામાં આવે.
દા.ત.: 6 ફેંકવામાં છ આવતી અપેક્ષિત સંખ્યા = 6 × (1/6) = 1.
બિન-સ્થાને (Without replacement) ખેંચવણમાં પ્રાચલાયતા બદલાય છે. બીજી ખેંચવણ માટે denominator (કુલ પરિણામ) અને numerator (અનુકૂળ) બંને 1 ઘટાડો. ઝડપી ગણતરી: P(પહેલા A, બીજું B) = P(A) × [P(B) માટે સંશોધિત] .
જ્યારે પ્રશ્નમાં 'પહેલાં ..., પછી ...' અથવા 'બિન-સ્થાને' સ્પષ્ટ જણાય.
દા.ત.: ડબલુમાં 5 કાળા + 3 સફેદ. બિન-સ્થાને બે કાળા ખેંચવા: P = (5/8) × (4/7) = 20/56 = 5/14.
જો P(A) > P(B) અને P(A∪B) = P(A), તો B ⊂ A (B એ A નો ઉપગણ છે). આવા કિસ્સામાં P(A∩B) = P(B).
જ્યારે union અને intersection વચ્ચે સંબંધ તપાસવાનો હોય અને વિકલ્પોમાંથી ગણતરી વગર જવાબ મેળવવાનો હોય.
દા.ત.: P(A) = 0.7, P(B) = 0.3, P(A∪B) = 0.7. આમ P(A∪B) = P(A) ⇒ B ⊂ A ⇒ P(A∩B) = P(B) = 0.3.
દ્વિપદી વિતરણ (Binomial distribution) માં P(X = k) = C(n,k) × p^k × (1-p)^(n-k). જો પ્રશ્નમાં 'b 정확히 k', 'દ્વિપદી', 'n પ્રયોગ' જેવા શબ્દો હોય તો આ સૂત્ર લાગુ પડે. p = સફળતા પ્રાચલાયતા.
જ્યારે n સમાન સ્વતંત્ર પ્રયોગોમાં k સફળતા જોઈતી હોય.
દા.ત.: 4 સિક્કા ફેંકતા બરાબર 2 છાપ: C(4,2) × (1/2)² × (1/2)² = 6 × 1/16 = 3/8.
