રેખીય પ્રોગ્રામિંગ (Linear Programming) — GUJCET એક્ઝામ ટ્રિક્સ

🎯 પરીક્ષા ટ્રિક્સ

ઓપ્ટિમલ સોલ્યુશન હંમેશા કોર્નર પોઈન્ટ (શિરોબિંદુ) પર મળે છે — સમગ્ર ફીઝિબલ રીજનની અંદર કોઈ બીજી જગ્યાએ મેક્સિમમ/મિનિમમ શક્ય નથી.
જ્યારે પ્રશ્નમાં ફીઝિબલ રીજન ગ્રાફિકલ રીતે દોરવામાં આવ્યું હોય અથવા શિરોબિંદુઓ શોધવાની હોય.
દા.ત.: જો અસમતાઓના છેદનબિંદુઓ (0,0), (4,0), (3,2), (0,5) હોય અને Z = 3x + 5y હોય, તો દરેક બિંદુ મૂકો: Z(0,5)=25 મેક્સિમમ છે.
વિકલ્પોમાંથી 'સબ્સ્ટિટ્યુશન' ટ્રિક — જો ચારેય વિકલ્પો આપેલા હોય, તો દરેક વિકલ્પની કિંમતો મૂળ અસમતાઓમાં મૂકીને તપાસો; જે વિકલ્પ બધી અસમતાઓ સંતોષે અને Z નું મૂલ્ય સૌથી વધુ/કમ હોય તે જવાબ છે.
MCQ પ્રશ્નમાં ચારેય વિકલ્પો (a,b,c,d) આપેલા હોય અને ગ્રાફ દોરવાનો સમય ન હોય.
દા.ત.: x + y ≤ 4, 2x + y ≤ 6, x,y ≥ 0; Z = 3x+5y નું મહત્તમ શોધો. વિકલ્પ: (a)12 (b)18 (c)20 (d)25. (0,4) મૂકો: 0+4≤4 ✓, 0+4≤6 ✓ → Z=20. (c) સાચો.
આઈસોપ્રોફિટ લાઇન (Isoprofit Line) પદ્ધતિ — Z = ax + by ની સમીકરણ રૂપે રેખા દોરો; રેખાને ફીઝિબલ રીજનની બહારની તરફ સમાંતર ખસેડો. જે કોર્નર પોઈન્ટ છેલ્લો છૂટો રહે તે મેક્સિમમ આપે, જે સૌથી અંદર રહે તે મિનિમમ આપે.
ગ્રાફિકલ પદ્ધતિથી ઝડપથી મેક્સ/મિન શોધવાની હોય, ખાસ કરીને જ્યારે બે શિરોબિંદુઓની નજીકની કિંમતો હોય.
દા.ત.: Z = 4x + 3y. શિરોબિંદુઓ (3,0)→Z=12, (0,4)→Z=12. બંને સમાન → બંને વચ્ચેની રેખાખંડ પર અનંત ઉકેલ.
અસમતાઓના 'બંધ બિંદુ' (Boundary Points) તપાસો: x = 0 મૂકો → y-અક્ષ પરના છેદબિંદુઓ; y = 0 મૂકો → x-અક્ષ પરના છેદબિંદુઓ. આ બે સરળ ગણતરીઓથી ઘણા શિરોબિંદુઓ મળી જાય છે.
ગ્રાફ દોર્યા વિના શિરોબિંદુઓ શોધવાના હોય અથવા ઝડપી તપાસ કરવાની હોય.
દા.ત.: 2x + 3y ≤ 12, x + y ≤ 5. x=0 મૂકો: 3y≤12→y≤4, y≤5→(0,4). y=0: 2x≤12→x≤6, x≤5→(5,0). આ બે બિંદુઓ મળ્યા.
બે અસમતાઓના છેદબિંદુ માટે 'ક્રોસ-મલ્ટિપ્લિકેશન' (Cross-Multiplication) પદ્ધતિ — જો બે રેખાઓ a₁x+b₁y=c₁ અને a₂x+b₂y=c₂ હોય, તો x = (b₁c₂−b₂c₁)/(a₁b₂−a₂b₁), y = (c₁a₂−c₂a₁)/(a₁b₂−a₂b₁).
બે રેખાઓના છેદબિંદુ (ત્રીજા શિરોબિંદુ) ની ગણતરી ઝડપથી કરવાની હોય.
દા.ત.: x+y=5, 2x+3y=12. x=(3×12−3×5)/(2×3−1×3)=(36−15)/(6−3)=21/3=7? → ચકાસણી: y=5−7=−2. (7,−2) પણ ફીઝિબલ નથી (y<0).
ફીઝિબલ રીજન 'અનબાઉન્ડેડ' (Unbounded) છે કે નહીં તે તપાસવાની ટ્રિક: જો કોઈ પણ અક્ષની દિશામાં ફીઝિબલ રીજન અનંત હોય અને Z ના ગુણાંકો ધન હોય, તો મેક્સિમમ અનંત હોઈ શકે (અનબાઉન્ડેડ સોલ્યુશન).
જ્યારે પ્રશ્નમાં 'અનબાઉન્ડેડ' વિકલ્પ હોય અથવા ફીઝિબલ રીજન બંધ ન હોય.
દા.ત.: Z = 3x+2y, x−y ≥ 1, x,y ≥ 0. x અનંત જઈ શકે → Z અનંત → અનબાઉન્ડેડ મેક્સિમમ.
બહુ-ઉકેલ (Multiple Optimal Solutions) ટ્રિક: જો Z ની કિંમત બે અલગ અલગ કોર્નર પોઈન્ટ પર સમાન આવે, તો તે બે બિંદુઓને જોડતી રેખાખંડ પર અનંત ઉકેલો છે.
જ્યારે બે શિરોબિંદુઓ પર Z નું મૂલ્ય સમાન મળે.
દા.ત.: Z = 2x+4y. (0,3)→Z=12, (2,2)→Z=4+8=12. બંને સમાન → રેખાખંડ પર અનંત ઉકેલ.
ઋણ ન હોવાની શરત (x,y ≥ 0) ભૂલથી છોડી દેવાથી ખોટા શિરોબિંદુઓ મળે છે — હંમેશા પ્રથમ ચરણ (First Quadrant) માં જ ફીઝિબલ રીજન જોવું.
ગ્રાફિકલ પદ્ધતિ દરમિયાન શિરોબિંદુઓ શોધતી વખતે.
દા.ત.: x+y≤4, x−y≤2 ના છેદબિંદુ (3,1) અને (−1,5) પણ મળે; પરંતુ (−1,5) માં x<0 → અવૈધ. ફક્ત પ્રથમ ચરણના બિંદુઓ લેવા.
Z = ax + by માં a અને b ના ચિહ્ન પરથી મેક્સ/મિનની દિશા નક્કી કરો: જો a,b બંને ધન હોય, તો મેક્સિમમ x અને y બંને મોટા શિરોબિંદુ પર મળશે; મિનિમમ x,y નાના શિરોબિંદુ પર.
ઝડપથી અંદાજિત જવાબ શોધવાનો હોય, ખાસ કરીને ધન ગુણાંકોવાળા પ્રશ્નોમાં.
દા.ત.: Z = 5x+3y, શિરોબિંદુઓ (0,0),(4,0),(3,2),(0,5). મેક્સ: (0,5)→Z=15; મિન: (0,0)→Z=0.
અસમતાને 'સમીકરણ' માં ફેરવો: દરેક અસમતા a₁x+b₁y ≤ c₁ ને a₁x+b₁y = c₁ માં ફેરવીને રેખા દોરો; ફીઝિબલ બાજુ તપાસવા માટે મૂળ બિંદુ (0,0) મૂકો — જો સત્ય મળે તો (0,0) ની બાજુ ફીઝિબલ છે.
ફીઝિબલ રીજનની દિશા ઝડપથી નક્કી કરવાની હોય.
દા.ત.: 2x+3y ≤ 12: (0,0) મૂકો → 0≤12 ✓ → મૂળબિંદુની બાજુ ફીઝિબલ. 4x+y ≥ 8: (0,0) → 0≥8 ✗ → મૂળબિંદુથી વિરુદ્ધ બાજુ ફીઝિબલ.
પ્રશ્નમાં 'કુલ મિનિમમ' હોય તો Z = ax+by માં a,b ઋણ હોઈ શકે — મિનિમમ માટે x,y મોટા શિરોબિંદુ પર પણ મળી શકે. હંમેશા બધા શિરોબિંદુઓ પર Z ગણો, અંદાજે ન નક્કી કરો.
જ્યારે Z ના ગુણાંકોમાં ઋણ ચિહ્ન હોય અથવા પ્રશ્ન મિનિમમ પૂછતો હોય.
દા.ત.: Z = −3x+5y, શિરોબિંદુઓ (0,0)→0, (4,0)→−12, (0,5)→25, (3,2)→1. મિનિમમ = −12 at (4,0).
ફીઝિબલ રીજન ખાલી (Infeasible) હોય તો કોઈ ઉકેલ નથી — બે અસમતાઓની ફીઝિબલ બાજુઓ એકબીજાને છેદતી ન હોય તો તેવું થાય.
જ્યારે બે અસમતાઓ વિરોધાભાસી લાગે અથવા વિકલ્પમાં 'કોઈ ઉકેલ નથી' હોય.
દા.ત.: x+y ≤ 2 અને x+y ≥ 5: કોઈ પણ (x,y) બંનેને સંતોષી શકે નહીં → Infeasible.
