રેખીય પ્રोग્રામિંગ (Linear Programming) — ટૂંકા નોટ્સ

🧪 GUJCET — Gujarati • Mathematics • Linear Programming

📘 વ્યાખ્યાઓ

  • રેખીય અસમાનતા (Linear Inequality): x અને y માં પ્રથમ ઘાતની અસમાનતા (≤, ≥, <, >) જેમ કે ax + by ≤ c.
  • રેખીય પ્રোগ્રામિંગ સમસ્યા (LPP - Linear Programming Problem): એક રેખીય લક્ષ્ય ફલનને મહત્તમ/ન્યૂનતમ કરવાની, રેખીય બંધનો હેઠળ.
  • લક્ષ્ય ફલન (Objective Function): Z = ax + by સ્વરૂપનું રેખીય ફલન, જેનું મહત્તમ અથવા ન્યૂનતમ મૂલ્ય શોધવું હોય.
  • બંધનો (Constraints): LPP ની શરતો તરીકે મળતી રેખીય સમીકરણ/અસમાનતાઓ, સામાન્ય રીતે ax + by ≤ c સ્વરૂપની.
  • અભિગમ્ય ક્ષેત્ર (Feasible Region): બધા બંધનોને સંતોષતા બધા બિંદુઓ (x, y) નો ગણ; આલેખીય રીતે છેદછેદ.
  • અભિગમ્ય ઉકેલ (Feasible Solution): અભિગમ્ય ક્ષેત્રના કોઈ પણ બિંદુને અભિગમ્ય ઉકેલ કહે છે.
  • અનુકૂળ બિંદુ (Corner Point / Vertex): અભિગમ્ય ક્ષેત્રના સીમાબિંદુઓ, જ્યાં બે અથવા વધુ બંધન રેખાઓ切断. છેડા બિંદુ.
  • આદર્શ ઉકેલ (Optimal Solution): અભિગમ્ય ક્ષેત્રમાં તે બિંદુ જેના પર લક્ષ્ય ફલનનું મહત્તમ/ન્યૂનતમ મૂલ્ય મળે.

⚡ સૂત્રો

  • લક્ષ્ય ફલન: Z = ax + by (મહત્તમ અથવા ન્યૂનતમ).
  • મર્યાદિત બંધન: ax + by ≤ c અથવા ax + by ≥ c, x ≥ 0, y ≥ 0.
  • મહત્તમીકરણ પ્રમાણ: Maximize Z = ax + by subject to constraints ax+by≤c, x≥0, y≥0.
  • ન્યૂનતમીકરણ પ્રમાણ: Minimize Z = ax + by subject to constraints ax+by≥c, x≥0, y≥0.

⭐ મુખ્ય તથ્યો

  • અભિગમ્ય ક્ષેત્ર હંમેશા એક ઉત્તલ બહુકોણ (convex polygon) હોય છે.
  • જો અભિગમ્ય ક્ષેત્ર મર્યાદિત હોય, તો Z નું મહત્તમ/ન્યૂનતમ મૂલ્ય છેડા બિંદુ પર મળે.
  • કોઈ પણ બિંદુ (x₀,y₀) પર Z = ax₀ + by₀ ગણો, તો સૌથી વધુ/ઓછું મૂલ્ય મળશે.
  • બંધન રેખા ax + by = c એ સીમા રેખા છે; અસમાનતા દિશા બતાવે છે કયો પાસો અભિગમ્ય છે.
  • x ≥ 0, y ≥ 0 નો અર્થ પહેલા ચરણ (first quadrant) માં મર્યાદિત.
  • અનંત અભિગમ્ય ક્ષેત્ર (unbounded feasible region) માટે Z નું મહત્તમ મૂલ્ય ન હોઈ શકે / ન્યૂનતમ મૂલ્ય ન હોઈ શકે.
  • લક્ષ્ય ફલનની રેખા Z = k નો સમીપાતી (slope) -a/b હોય, જે બદલાતો નથી.
  • બધા બંધનો એકસાથે આલેખી અભિગમ્ય ક્ષેત્ર ડારી કરવું.
  • છેડા બિંદુઓ શોધવા બંધન રેખાઓના છેદબિંદુઓ શોધો (સમીકરણ જોડી ઉકેલો).

⚠️ સામાન્ય ભૂલો

  • અસમાનતાનો ચિહ्न બદલવો (≤ ને ≥ કરવો) એ ભૂલ — અભિગમ્ય ક્ષેત્ર ખોટું મળે.
  • x ≥ 0, y ≥ 0 ભૂલી જવું — ત્રીજા/ચોથા ચરણમાં ઉકેલ આવે અને ખોટો.
  • અનંત અભિગમ્ય ક્ષેત્ર માટે Z નું મૂલ્ય છેડા બિંદુ પર જ મળે એ ધારવું — ક્યારેક અસ્તિત્વ ન હોય.
  • લક્ષ્ય ફલનની રેખા બંધન રેખા સમકક્ષ (parallel) હોય ત્યારે બહુવિધ આદર્શ ઉકેલ મળે છતાં એક જ ગણવા.
  • છેડા બિંદુઓની ગણતરીમાં ભૂલ — છેદબિંદુ શોધતા બે સમીકરણ સાચી રીતે ઉકેલવાં.
  • Z = ax + by માં x, y ની કિંમત મૂકતી વખતે ગણિતની ભૂલ.
  • અભિગમ્ય ક્ષેત્રને ખુલ્લું (unbounded) સમજીને પણ મહત્તમ/ન્યૂનતમ મળ્યું એ ધારવું.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • ગ્રાફીકલ પદ્ધતિ: દરેક બંધન રેખા દોરો → અભિગમ્ય ક્ષેત્ર ડારી કરો → છેડા બિંદુઓ શોધો → Z ની કિંમત ગણો.
  • છેડા બિંદુ પદ્ધતિ (Corner Point Method): મર્યાદિત અભિગમ્ય ક્ષેત્રમાં આદર્શ ઉકેલ હંમેશા છેડા બિંદુ પર.
  • બહુવિધ આદર્શ ઉકેલ: જો Z ની રેખા બંધન રેખા સમાંતર હોય, તો તે બંધન પરના બધા બિંદુઓ આદર્શ.
  • અનંત અભિગમ્ય ક્ષેત્ર માટે: Maximize માટે Z = ax+by નું મહત્તમ મૂલ્ય ન હોઈ શકે; Minimize માટે ન્યૂનતમ મૂલ્ય ન હોઈ શકે — તપાસો ax+by < 0 કે > 0.
  • LPP પ્રસ્તુતિ: વાસ્તવિક સમસ્યાને З = ax+by અને બંધનોના સમીકરણમાં રૂપાંતરિત કરો.
  • પ્રશ્નમાં મહત્તમ કે ન્યૂનતમ તે ધ્યાનથી વાંચો — જવાબ વિપરીત ન મળે.
  • આલેખી અભિગમ્ય ક્ષેત્ર ડારી કરતી વખતે શરતોનો છેદછેદ શોધો (intersection of half-planes).
  • x ≥ 0, y ≥ 0 એ સૌથી મહત્વનું બંધન — પ્રશ્નમાં ન હોય તો પણ સામાન્ય રીતે લાગુ પડે.
