અવકલનના પ્રયોગો — સૂત્ર પત્રિકા

🧪 GUJCET — Gujarati • Mathematics • Application of Derivatives

⚡ સૂત્રો

સાપેક્ષ ઝડપ (Rate of Change): dy/dt = (dy/dx) * (dx/dt)
dy/dt = y માં સમય સાપેક્ષે ફેરફારનો દર, dx/dt = x માં સમય સાપેક્ષે ફેરફારનો દર, dy/dx = y નું x ની સાપેક્ષે વિકલિત · SI: એકમ [y]/સે · y અને x બંને સમય t ના વિધેય હોય અને બંને વિકલનીય હોય
સ્પર્શકનું સમીકરણ (Tangent Line): y - y1 = m (x - x1), જ્યાં m = f'(x1)
m = સ્પર્શકનો ઢાળ, (x1, y1) = સ્પર્શબિંદુ, f'(x1) = બિંદુએ પ્રથમ વિકલિત · SI: ઢાળનું એકમ [y]/[x] · f એ x1 પર વિકલનીય હોય
અભિલંબનું સમીકરણ (Normal Line): y - y1 = -(1/m) (x - x1), જ્યાં m = f'(x1)
-1/m = અભિલંબનો ઢાળ, m = સ્પર્શકનો ઢાળ · SI: ઢાળનું એકમ [y]/[x] · m ≠ 0 અને f એ x1 પર વિકલનીય હોય
રેખીય અંદાજ (Linear Approximation): f(x) ≈ f(a) + f'(a)(x - a)
f(a) = મૂળ ફંક્શનનું a માં મૂલ્ય, f'(a) = a બિંદુએ વિકલિત, (x-a) = a થી નાનું અંતર · SI: f ના એકમ જેટલું · x એ a ની બહુ નજીક હોય
નાના ફેરફારનો અંદાજ (Small Change Approximation): Δy ≈ f'(x) · Δx
Δy = y માં ફેરફાર, Δx = x માં નાનો ફેરફાર, f'(x) = x બિંદુએ વિકલિત · SI: [y] ના એકમમાં · Δx ખૂબ નાનું હોય (∣Δx∣ → 0)
વધતું વિધેય (Increasing Function): f'(x) > 0 ⇒ f વધતું છે
f'(x) = પ્રથમ વિકલિત, જો બધા x ∈ I માટે f'(x) > 0 હોય તો f એ I પર કડક વધતું છે · SI: - · f એ અંતરાલ I પર વિકલનીય હોય
ઘટતું વિધેય (Decreasing Function): f'(x) < 0 ⇒ f ઘટતું છે
f'(x) = પ્રથમ વિકલિત, જો બધા x ∈ I માટે f'(x) < 0 હોય તો f એ I પર કડક ઘટતું છે · SI: - · f એ અંતરાલ I પર વિકલનીય હોય
અચળ વિધેય (Constant Function): f'(x) = 0 ⇒ f અચળ છે
f'(x) = પ્રથમ વિકલિત, જો બધા x ∈ I માટે f'(x) = 0 હોય તો f એ I પર અચળ છે · SI: - · f એ અંતરાલ I પર વિકલનીય હોય
વિકલજ શૂન્ય બિંદુ (Critical Point): f'(c) = 0 અથવા f'(c) અવ્યાખ્યાયિત
c = મહત્વપૂર્ણ બિંદુ (critical point), f'(c) = c બિંદુએ વિકલિત · SI: - · f એ c પર વ્યાખ્યાયિત હોય
પ્રથમ વિકલન પરીક્ષણ (First Derivative Test): જો f'(x) એ c બિંદુ પહેલાં ધન અને પછી ઋણ થાય → સ્થાનિક મહત્તમ; જો ઋણ પછી ધન થાય → સ્થાનિક ન્યૂનતમ
f'(x) = પ્રથમ વિકલિત, c = મહત્વપૂર્ણ બિંદુ · SI: - · f'(c) = 0 અથવા f'(c) અવ્યાખ્યાયિત, અને f'(x) એ c ની આસપાસ ચિહ્ન બદલે
દ્વિતીય વિકલન પરીક્ષણ (Second Derivative Test): f''(c) > 0 ⇒ સ્થાનિક ન્યૂનતમ; f''(c) < 0 ⇒ સ્થાનિક મહત્તમ; f''(c) = 0 ⇒ પરીક્ષણ નિષ્ફળ
f''(c) = c બિંદુએ દ્વિતીય વિકલિત, f'(c) = 0 હોવું જોઈએ · SI: - · f'(c) = 0 અને f''(c) અસ્તિત્વ ધરાવતું હોય
વૃત્તાકાર ગતિમાં કેન્દ્રગામી પ્રવેગ (Centripetal Acceleration): a_c = v²/r = ω²r
a_c = કેન્દ્રગામી પ્રવેગ, v = રેખીય વેગ, r = ત્રિજ્યા, ω = કોણીય વેગ · SI: m/s² · વસ્તુ વृत्ताकार પथ પર ગતિ કરતી હોય
પરિમાણીય સ્વરૂપે વિકલન (Parametric Derivative): dy/dx = (dy/dt) / (dx/dt)
dy/dt = y નો t સાપેક્ષે વિકલિત, dx/dt = x નો t સાપેક્ષે વિકલિત · SI: [y]/[x] · dx/dt ≠ 0 અને બંને વિકલનીય હોય
પરિમાણીય દ્વિતીય વિકલન (Second Parametric Derivative): d²y/dx² = [ (d²y/dt²)(dx/dt) - (dy/dt)(d²x/dt²) ] / (dx/dt)³
d²y/dt² = y નો t ના સાપેક્ષે દ્વિતીય વિકલિત, d²x/dt² = x નો t ના સાપેક્ષે દ્વિતીય વિકલિત · SI: [y]/[x]² · dx/dt ≠ 0 અને બધા વિકલિતો અસ્તિત્વ ધરાવતા હોય
બે વક્ર વચ્ચેનો કોણ (Angle Between Two Curves): tan θ = | (m₁ - m₂) / (1 + m₁·m₂) |
m₁ = પ્રથમ વક્રનો સ્પર્શક ઢાળ, m₂ = દ્વિતીય વક્રનો સ્પર્શક ઢાળ, θ = છેદન બિંદુએ કોણ · SI: - · વક્રો છેદન બિંદુએ સ્પર્શક ઢાળ ધરાવતા હોય
વલયના સ્પર્શકનો ઢાળ (Implicit Differentiation Slope): dy/dx = - (∂F/∂x) / (∂F/∂y)
F(x,y) = 0 એ ગુપ્ત સમીકરણ, ∂F/∂x = F નું x સાપેક્ષે આંશિક વિકલિત, ∂F/∂y = F નું y સાપેક્ષે આંશિક વિકલિત · SI: - · ∂F/∂y ≠ 0 અને F વિકલનીય હોય

🔗 સંબંધો

  • સ્પર્શકનો ઢાળ અને અભિલંબનો ઢાળ પરસ્પર ઋણ વ્યસ્ત છે: m_normal = -1/m_tangent.
  • નાના ફેરફારનો અંદાજ Δy ≈ f'(x)Δx એ રેખીય અંદાજનું સાદરૂપ છે.
  • વધતું/ઘટતું વિધેયનો નિયતતા પ્રથમ વિકલિતના ચિહ્ન પર આધારિત છે.
  • મહત્તમ/ન્યૂનતમ બિંદુઓ પર પ્રથમ વિકલિત શૂન્ય અથવા અવ્યાખ્યાયિત હોય છે, પણ વિલોમ સત્ય હંમેશા સત્ય નથી.
  • કેન્દ્રગામી પ્રવેગ વેગના વર્ગના સમપ્રમાણ અને ત્રિજ્યાના વર્ગના સમપ્રમાણ છે (અથવા કોણીય વેગના વર્ગ અને ત્રિજ્યાના સમપ્રમાણ).
  • પરિમાણીય વિકલનમાં dy/dx એ dy/dt અને dx/dt ના ગુણોત્તર સમાન છે, પરંતુ d²y/dx² એ માત્ર દરેકને t ના સાપેક્ષે વિકલિત કરીને મળતું નથી.

🎯 ટ્રિક્સ

સ્પર્શકનું સમીકરણ યાદ રાખવાની રીત: 'બિંદુ-ઢાળ સ્વરૂપ', અભિલંબ માટે ઢાળનો ઋણ વ્યસ્ત લેવો.
નાના ફેરફાર માટે Δy ≈ f'(x)Δx એ 'આજુબાજુનો સરળ રેખીય અંદાજ' છે.
વધતું/ઘટતું ચકાસવા માટે વિકલિતનું ચિહ્ન જોવું: ધન = વધતું, ઋણ = ઘટતું.
દ્વિતીય વિકલન પરીક્ષણમાં: f''(c) > 0 means 'cup up' (મિનિમમ), f''(c) < 0 means 'cup down' (મેક્સિમમ).
રોલનું પ્રમેય અને મધ્યસ્થ પ્રમેય વચ્ચેનો સંબંધ: રોલનું પ્રમેય એ મધ્યસ્થ પ્રમેયનું વિશેષ કેસ છે જ્યારે f(a)=f(b).
બે વક્રો વચ્ચેનો કોણ શોધવા માટે સ્પર્શક ઢાળ મેળવીને tan θ формула लागू કરો.

⚠️ ભૂલો

સ્પર્શક અને અભિલંબના ઢાળ ગેરમાનવા: અભિલંબનો ઢાળ -1/m લેવો, m નહીં.
f'(c)=0 હોવું એ મહત્તમ/ન્યૂનતમ માટે પૂરતું નથી; તે મહત્વપૂર્ણ બિંદુ છે, પણ તે ઇન્ફલેક્શન બિંદુ પણ હોઈ શકે.
દ્વિતીય વિકલન પરીક્ષણનો ઉપયોગ f''(c)=0 હોય ત્યારે કરવો – અંશતઃ અનિશ્ચિત.
વાસ્તવિક જીવનના દરવાળા પ્રશ્નોમાં એકમો ભૂલી જવા; dy/dt નું એકમ [y]/[time] હોય છે.
પરિમાણીય સ્વરૂપે d²y/dx² શોધતી વેળા ડેનોમિનેટરમાં (dx/dt)³ લખવું, (dx/dt)² નહીં.
વધતું/ઘટતું વિધેયનું નિર્ણય કરતી વેળા f'(x)=0 મૂલ્યોને અવગણવા – તે ક્રાંતિક બિંદુઓ છે.
રોલના પ્રમેયના તમામ શરતો (સાતત્ય, વિકલનીયતા, f(a)=f(b)) ચકાસ્યા વિના નિષ્કર્ષ કાઢવો.
