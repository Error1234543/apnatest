વિકલજના ઉપયોગ — ટૂંકા નોટ્સ (રિવિઝન)

🧪 GUJCET — Gujarati • Mathematics • Application of Derivatives

📘 વ્યાખ્યાઓ

  • વિકલજ (Derivative): કોઈ ફંક્શનનો એક બિંદુએ થતો ફેરફાર દર, જે f'(x) કે dy/dx તરીકે દર્શાવાય છે.
  • સ્પર્શક (Tangent): વક્ર પરના બિંદુએ સ્પર્શતી રેખા, જેનો ઢાળ f'(a) બરાબર હોય છે.
  • અભિલંબ (Normal): સ્પર્શકને તે બિંદુએ લંબ રહેતી રેખા; તેનો ઢાળ −1/f'(a) હોય છે.
  • ઉચ્ચિત બિંદુ (Critical Point): એવું x = a જ્યાં f'(a) = 0 અથવા f'(a) અસ્તિત્વ ધરાવતું ન હોય.
  • સ્થાનિક મહત્તમ (Local Maximum): એવું f(a) જે પડોશી બિંદુઓ કરતા મોટું હોય.
  • સ્થાનિક ન્યૂનતમ (Local Minimum): એવું f(a) જે પડોશી બિંદુઓ કરતા નાનું હોય.
  • વૃદ્ધિશીલ ફંક્શન (Increasing Function): a ≤ x₁ < x₂ ≤ b માટે f(x₁) ≤ f(x₂) હોય તો vṛddhishīl;
  • હ્રાસમાન ફંક્શન (Decreasing Function): a ≤ x₁ < x₂ ≤ b માટે f(x₁) ≥ f(x₂) હોય તો hrsāman;

⚡ સૂત્રો

  • dy/dx = (dy/dt) / (dx/dt) — પરોક્ષ ચલથી વિકલન
  • સ્પર્શક: y − f(a) = f'(a)(x − a)
  • અભિલંબ: y − f(a) = [−1/f'(a)](x − a)
  • δy ≈ f'(a)·δx — નાના ફેરફારનું અંદાજિત મૂલ્ય
  • f(x) ≈ f(a) + f'(a)(x − a) — લીનિયર એપ્રોક્સિમેશન
  • f'(x) > 0 ⇒ ફંક્શન વધે છે; f'(x) < 0 ⇒ ફંક્શન ઘટે છે
  • f'(a) = 0 અને f''(a) < 0 ⇒ x = a એ સ્થાનિક મહત્તમ બિંદુ
  • f'(a) = 0 અને f''(a) > 0 ⇒ x = a એ સ્થાનિક ન્યૂનતમ બિંદુ
  • f'(a) = 0 અને f''(a) = 0 ⇒ પરીક્ષણ અનિર્ણાયક, તૃતીય વિકલજ તપાસો

⭐ મુખ્ય તથ્યો

  • જો f'(x) ≥ 0 આંતરઆવર્ત [a,b] માં હોય તો f વૃદ્ધિશીલ છે; f'(x) > 0 માત્ર અલગ-અલગ બિંદુઓ પર શૂન્ય થાય તો પણ વૃદ્ધિશીલ.
  • સમાંતર રેખાનો ઢાળ શૂન્ય → f'(a) = 0;
  • x-અક્ષને લંબ રેખાનો ઢાળ અનંત → f'(a) અસ્તિત્વ ધરાવતી નથી.
  • બિંદુ (a, f(a)) પર અભિલંબનું સમીકરણ: (y − f(a)) = −[1/f'(a)](x − a)
  • વક્ર y = f(x) પર બિંદુ (a,f(a)) થી x-અક્ષ સુધીનું લંબ અંતર = |f(a)| (અભિલંબની લંબાઈ નહીં)
  • આંતરઆવર્ત [a,b] પર સતત ફંક્શનનું મહત્તમ/ન્યૂનતમ મૂલ્ય ક્રિટિકલ બિંદુઓ અને સીમાબિંદુઓ પર તપાસવાં જરૂરી.
  • f(a) > f(x) ∀x ∈ (a−h,a+h) ⇒ સ્થાનિક મહત્તમ; f(a) < f(x) ∀x ∈ (a−h,a+h) ⇒ સ્થાનિક ન્યૂનતમ.
  • બે વક્રો પરસ્પર લંબ છે જો તેમના સ્પર્શકોનો ગુણાકાર −1 હોય (f'(a)·g'(a) = −1).
  • dy/dx અનંત હોય ત્યારે વક્રની સ્પર્શક x-અક્ષને લંબ હોય છે.
  • f(x) = x³ પર x=0 એ ક્રાન્તિ બિંદુ છે પરંતુ મહત્તમ/ન્યૂનતમ નથી (અનિવાર્ય બિંદુ).

⚠️ સામાન્ય ભૂલો

  • f'(a) = 0 મળ્યું હોય તો જરૂરી નથી કે મહત્તમ/ન્યૂનતમ મળ્યું હોય — બીજું પરીક્ષણ ફરજિયાત કરવું.
  • આંતરઆવર્ત (open/closed) અને ક્રિટિકલ બિંદુઓ વચ્ચેનો તફાવત ભૂલી જવો.
  • અભિલંબનું સમીકરણ લખતી વેળા ઋણ વ્યસ્ત ઢાળ (negative reciprocal) લખવા ભૂલવી.
  • vṛddhishīl/hrsāman ગાળો લખતી વેળા (a,b) vs [a,b] વાપરવામાં ભૂલ.
  • δx = 0 મુકીને δy શોધવાનો પ્રયાસ કરવો — અંદાજિત મૂલ્ય માટે δx ખૂબ નાનો (≠ 0) હોવો જોઈએ.
  • f''(a) = 0 મળે ત્યારે તરત જ નિષ્કર્ષ કઢાવી લેવો — ચિહ્ન બદલાય છે કે નહીં તે તપાસવું.
  • મહત્તમ/ન્યૂનતમ શોધતી વેળા સીમાબિંદુઓ (endpoints) ને અવગણી દેવા.
  • વધુ એક ચલવાળા પ્રશ્નમાં dx/dt vs dy/dt ઉલટાડી મુકવા.
  • સ્પર્શક/અભિલંબનું સમીકરણ lORF માં 'સમીકરણ' શબ્દને બદલે ફક્ત ઢાળ માંગતાં ફરજિયાત કરવું.
  • f(x) ના ન્યૂનતમ મૂલ્ય અને f'(x) ના ન્યૂનતમ મૂલ્ય વચ્ચેનો તફાવત સમજવામાં ભ્રમ.

🔥 હાઈ-યીલ્ડ મુદ્દા

  • દર એકમ સમયે ફેરફારનો દર શોધવા પ્રશ્નોમાં chain rule ફરજિયાત — ઘણા ગુજરાતી પ્રશ્નોમાં સીધો pyq આવે છે.
  • વધુ સૌથી સામાન્ય પ્રશ્ન: આપેલ ફંક્શનના વધુ/ઘટત ગાળા શોધો — સીધું f'(x) > 0 / f'(x) < 0.
  • વક્ર પર કોઈ બિંદુએ સ્પર્શક/અભિલંબનું સમીકરણ શોધવું — 3–5 નંબરનો ફિક્સ્ડ પ્રશ્ન.
  • f(x) = ax³ + bx² + cx + d ના મહત્તમ/ન્યૂનતમ શોધવાના પ્રશ્નો (vṛttis) GUJCET માં ઘણા આવે છે.
  • Approximation પ્રશ્ન: √(N±ε), sin(π/4+ε), e^(0.01) જેવા પ્રકારનાં — f(a+δx) ≈ f(a)+f'(a)δx.
  • Rate of change of volume/surface area — sphere, cube, cylinderના પ્રશ્નો પુનરાવર્તિત આવે છે.
  • Monotonicity ઓળખવા માટે f'(x) ના ચિહ્ન કોષ્ટક (sign chart) બનાવવાની આદત ધરાવવી.
  • Maximum/minimum of f(x) = xⁿ (n > 1) — સીધું f'(x)=0 → x=0 → મહત્તમ/ન્યૂનતમ ચકાસો.
  • પરોક્ષ વિકલનImplicit differentiation — vṛttis માં વધુ ગંભીર પ્રશ્નો આવે છે.
  • લઘુત્તમ સમય/મહત્તમ પ્રદેશવાળા પ્રશ્નોમાં (optimization) સંબંધ સ્થાપિત કરી એક ચલમાં ફંક્શન બનાવવું મહત્ત્વનું.
