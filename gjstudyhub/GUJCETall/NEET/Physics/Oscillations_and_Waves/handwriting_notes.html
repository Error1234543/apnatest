દોલનો અને તરંગો (Oscillations and Waves)

🧪 GUJCET — Gujarati • Physics • Oscillations and Waves

સરળ આવર્ત ગતિ (Simple Harmonic Motion)
જ્યારે કોઈ કણ સમતુલ્યતા સ્થાનની સાપેક્ષે આગળ-પાછળની દોલનચાલ કરતો હોય અને તેના પર લાગતું પુનઃસ્થાપક બળ સરકંપાકારમાં વિસ્થાપનના સમપ્રમાણમાં હોય, ત્યારે તે ગતિને સરળ આવર્ત ગતિ કહે છે.
ફરક: વિકલ સમીકરણ — a = −ω²x અથવા d²x/dt² + ω²x = 0
F = −kx → એટલે કે પુનઃસ્થાપક બળ, વિસ્થાપનના સમપ્રમાણમાં અને દિશા વિરુદ્ધ.
ω = √(k/m) | T = 2π√(m/k) | f = 1/T = ω/(2π)
વેગ v = ω√(A² − x²) , જ્યાં A = કંપનવ્યાસાર (amplitude).
પ્રવેગ a = −ω²x — પ્રવેગ હંમેશા સમતુલ્યતા સ્થાન તરફ હોય છે.
v = dx/dt = ωA cos(ωt + φ) અને x = A sin(ωt + φ)
📝 ⚡ વારંવાર પૂછાય: x = A cos(ωt) શરૂઆતમાં x = A હોય ત્યારે. y = A sin(ωt) શરૂઆતમાં x = 0 હોય ત્યારે.
સરળ આવર્ત ગતિમાં ઊર્જા
ગતિજ ઊર્જા K = ½mv² = ½mω²(A² − x²)
સ્થિતિજ ઊર્જા U = ½kx² = ½mω²x²
કુલ ઊર્જા E = K + U = ½mω²A² = અચળ
K ઉચ્ચતમ x = 0 પર (સમતુલ્યતા સ્થાન) · U ઉચ્ચતમ x = ±A પર (અંત્યબિંદુઓ)
સરેરાશ ગતિજ ઊર્જા = સરેરાશ સ્થિતિજ ઊર્જા = E/2 = ¼mω²A²
સ્પ્રિંગ-વસા કંપન
ક્ષેતિજ સ્પ્રિંગ: T = 2π√(m/k) — દ્રવ્યમાન m અને પ્રત્યાસ્થાન અંક k ધરાવતી સ્પ્રિંગ.
લંબવત સ્પ્રિંગ પણ T = 2π√(m/k) જ — ભાર ને આધારિત નહિ.
સરવાળું સ્પ્રિંગ: k_series = k₁k₂/(k₁+k₂) | k_parallel = k₁ + k₂
પરિણામી સ્પ્રિંગ અંક (series): 1/k_eq = 1/k₁ + 1/k₂
📝 ⚡ Parallel માં k વધે → T ઘટે · Series માં k ઘટે → T વધે.
લંબ દોલક (Simple Pendulum)
લંબ દોલકનું આવર્તકાળ T = 2π√(l/g) — લંબાઈ l અને ગુરુત્વપ્રવેગ g પર આધારિત.
મહત્વ: T ભાર, દળ, કંપનવ્યાસાર (chhota) પર આધારિત નથી!
T = 2π√(l/g) → g = 4π²l/T²
ગુરુત્વાકર્ષણ બળનો સ્પર્શકીય ઘટક F = −mg sinθ ≈ −mgθ (chhota θ માટે) = −mgx/l.
ω = √(g/l) | f = (1/2π)√(g/l)
📝 ⚡ વિશાળ લંબાઈ l = અર્ધવ્યાસ રાસ લગાડતા ચંદ્રકાળ વધે છે.
ઋત્તિલ (Physical) દોલક
વાસ્તવિક દોલક જ્યાં ભાર કેન્દ્ર P થી સમતુલ્યતા બિંદુ O સુધીનું અંતર d હોય.
T = 2π√(I/mgd) → I = દળભ્રમણ જડત્વ, d = P અને O વચ્ચેનું અંતર
સરળ લંબ દોલક સાથે સરખાવતા: I = md² હોય તો T = 2π√(d/g) મળે.
📝 ⚡ ઋત્તિલ દોલકનું સમતુલ્ય લંબાઈ l_eq = I/(md).
વિકલ (Damped) કંપનો
સ્પર્શરોક (resistive) બળને કારણે કંપનોનું કંપનવ્યાસાર ધીમે ધીમે ઘટે છે — આને વિકલ કંપન કહે.
F_resistance = −bv → આવર્તકાળ T = 2π/√(ω² − (b/2m)²)
b મોટું હોય તો કંપન શીઘ્ર લુપ્ત થાય — વધુ વિઘટન.
ત્રણ પ્રકાર: hringho (underdamped), krish (critically damped), ativriddh (overdamped).
બળપ્રેરિત (Driven) કંપનો અને અનુનાદ (Resonance)
બાહ્ય આવર્તક બળ F₀ sin(ω_d t) ને પ્રેરિત કંપન કહે. આવૃત્તિ ω_d.
અનુનાદ: ω_d = ω₀ (પ્રાકૃતિક આવૃત્તિ) — એમ કંપનવ્યાસાર મહત્તમ થાય છે.
અનુનાદનું ઉદાહરણ: બ્રિજનું ધડાકાથી તૂટવું, એકરથનાં કાંટાંનું કંપન.
અનુનાદ દરમિયાન બળ અને વિસ્થાપન વચ્ચેનો કલાભેદ π/2 થાય.
તરંગોનું પરિચય (Introduction to Waves)
તરંગ એવું વિષય છે જેમાં ઉર્જા અને વેગમાન એક બિંદુ થી બીજા બિંદુ પર વહન પામે છે, પણ પદાર્થનો સ્થાનિ વિસ્થાપન શૂન્ય હોય છે.
યાંત્રિક તરંગોને માધ્યમની જરૂર હોય (ધ્વનિ); વિદ્યુતચુંબકીય તરંગો માધ્યમ વિના ચાલે.
t = λ / v | v = fλ | ω = 2πf
અનુદৈર્ઘ્ય અને પ્રસ્થ તરંગો
અનુદૈર્ઘ્ય (longitudinal) તરંગ: કંપન દિશા = તરંગ દિશા. ઉદા. – ધ્વનિ.
પ્રસ્થ (transverse) તરંગ: કંપન દિશા ⊥ તરંગ દિશા. ઉદા. – રંધ્ર તરંગ, ઇલેક્ટ્રોમેગ્નેટિક.
ધ્વનિ માત્ર અનુદૈર્ઘ્ય છે · પ્રકાશ પ્રસ્થ છે — વિદ્યુતચુંબકીય તરંગ.
📝 ⚡ ઘન/પાણીમાં ધ્વનિ ઝડપી, વાયુમાં ધીમો. કારણ: ρ અને B પર આધાર.
સુસંગત પ્રસ્થ તરંગનું સમીકરણ
y(x,t) = A sin(kx − ωt + φ) (ધન x દિશામાં) · y(x,t) = A sin(kx + ωt) (ઋણ દિશામાં)
k = 2π/λ (તરંગાંક) · ω = 2πf (कोणीय आवृत्ति) · v = ω/k
તરંગ વેગ v = √(T/μ) → T = tensione, μ = rേഖીય ઘનતા (mass per length)
તરંગની વેગમાન અને ઉર્જા rસરકરો: તરંગવ્યાસ A² ના સમપ્રમાણ.
ધ્વનિ તરંગો
v_sound = √(B/ρ) → B = bulk modulus, ρ = density
સામાન્ય વાયુમાં ધ્વનિવેગ v = √(γRT/M) — γ = C_p/C_v, M = મોલર દળ.
આર્દ્રતા વધે → ધ્વનિવેગ વધે · તાપમાન વધે → ધ્વનિવેગ વધે.
ધ્વનિવેગ: હવા ~343 m/s (20°C), પાણી ~1480 m/s, લોખંડ ~5100 m/s.
તરંગની પરાવર્તન અને વક્રીભવન
પરાવર્તન: તરંગ જાડા માધ્યમ થી ઘટ્ટ માધ્યમ પર પરાવર્તિત થાય ત્યારે કલામાં π ફેરફાર આવે છે.
વક્રીભવન: તરંગ ઓછા ઘનતાવાળા માધ્યમમાં પ્રવેશે ત્યારે v बदले છે, પણ આવૃત્તિ અચળ રહે છે.
f અચળ · v değişir · λ = v/f — એટલે λ પણ બદલાય છે.
સ્થિર તરંગો (Stationary / Standing Waves)
એક જ આવૃત્તિના બે વિરુદ્ધ દિશામાં ગતિ કરતાં તરંગોના સંપરાવ બળતે સ્થિર તરંગો રચાય છે.
y = 2A sin(kx) cos(ωt) — પ્રક્ષેપો node પર sin(kx)=0, antinode પર max.
node: કંપનવ્યાસાર શૂન્ય · antinode: કંપનવ્યાસાર 2A.
ક્રમિક વિરામો (nodes) વચ્ચેનું અંતર = λ/2 · node થી પાસેના antinode સુધી = λ/4.
તાંત્રિક સ્થિર તરંગો (String Vibrations)
f_n = n·v/(2l) = n/(2l) √(T/μ) → n = 1,2,3,...
mulladh (fundamental): f₁ = v/(2l) · પ્રથમ overtone = f₂ = 2f₁.
Mendelસનનું નિયમ: f ∝ √T, f ∝ 1/l, f ∝ 1/√μ
f = (n/2l)√(T/μ) · l = √(T/μ)/(2f/n)
વાયુ સ્તંભમાં સ્થિર તરંગો (Air Columns)
બંધ (closed at one end) નળી: f_n = nv/(4l) , n = 1,3,5,... — વિષમ પ્રમાણો જ.
ખુલ્લી (open at both ends) નળી: f_n = nv/(2l) , n = 1,2,3,... — બધા પ્રમાણો.
બંધ: mulladh = v/(4l) · overtone = 3mulladh, 5mulladh...
ખુલ્લી: mulladh = v/(2l) · overtone = 2mulladh, 3mulladh...
📝 ⚡ closing નળીમાં અંત્ય ભાગમાં pressure antinode, velocity node હોય છે.
ધ્વનિની તીવ્રતા અને ધ્વનિતરલ (Loudness)
I = P/A [W/m²] — ધ્વનિતરલ (intensity level) β = 10 log₁₀(I/I₀) dB
I₀ = 10⁻¹² W/m² (ધ્વનિની પ્રમાણભૂત જાણીતી તીવ્રતા).
β વધારો 10 dB → તીવ્રતા 10 ગણી · 20 dB → 100 ગણી.
ધ્વનિતરલ શ્રાવ્ય (audible): 0 dB થી ~120 dB.
ડોપ્લર અસર (Doppler Effect)
સ્રોત કે નિરીક્ષક ગતિ કરતો હોય ત્યારે આવૃત્તિમાં પરિવર્તન — ડોપ્લર અસર.
f' = f₀ [(v ± v_o)/(v ∓ v_s)] → v = ધ્વનિવેગ, v_o = observer speed, v_s = source speed.
સ્રોત નજીક આવે → f' વધે (higher pitch) · દૂર જાય → f' ઘટે (lower pitch).
સ્રોત સ્થિર, niryakshak ગતિ: v_o ધન જો સ્રોત તરફ આવે. v_s ધન જો niryakshak થી દૂર જાય.
f_observed = f_source · (v ± v_observer) / (v ∓ v_source)
📝 ⚡ Ambulance ના સાયરનની આ ઘટના બદલાતી sound અનુભવ.
તરંગો — મુખ્ય સૂત્રોનું સારાંશ
SHM: x = A sin(ωt + φ) · v = ω√(A²−x²) · a = −ω²x.
Spring mass: T = 2π√(m/k) · Pendulum: T = 2π√(l/g).
Wave: v = fλ · y = A sin(kx ± ωt) · k = 2π/λ, ω = 2πf.
Standing wave nodes antinodes: distance between consecutive nodes = λ/2.
String: f_n = n/(2l) √(T/μ). Open pipe: f_n = nv/(2l). Closed pipe: f_n = nv/(4l).
Intensity: I = P/A, β = 10 log(I/I₀) dB.
Doppler: f' = f[(v±v_o)/(v∓v_s)].
અનુનાદ: ω_drive = ω_natural → amplitute maximum. This is very important for GUJCET.
📝 ⚡ Exam tip: SHM and waves formulas are always asked together — revise together.
