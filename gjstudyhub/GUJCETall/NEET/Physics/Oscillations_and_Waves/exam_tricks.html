🎯 પરીક્ષા ટ્રિક્સ

SHM માં સમયગાળો સિવેર ક્યારેય નક્કી કરતો નથી — વ્યાસાર્ધ (R) પર આધારિત છે કોણીય વેગ ω = √(g/R).
જ્યારે પ્રશ્નમાં કૌંસિક પિન્ડ (બબલ) અથવા તાવડ (રિંગ) નો મહત્તમ આવર્તકાળ પૂછતો હોય, પણ દળ (m) આપેલું હોય.
દા.ત.: એક ચેઇન/વાયરનું બે છેડા એક જ ઊંચાઈએ, મધ્ય ભાગ પડે તેવી રીતે લટકાવ્યો હોય. નાના કંપનોનો કાળ T = 2π√(L/2g) થાય છે. અહીં L લંબાઈ છે, પણ રૂટમાં માત્ર L/2g જ વપરાય છે.
વેગમાન સંરક્ષણથી પછી SHM નો નવો આવર્તકાળ T' = 2π√(m_new / k_eff) સીધો ગણી શકાય.
સ્પ્રિંગ-દળ પ્રણાલીમાં કોઈ ઝડપથી બ્લોક સાથે ટકરાઈને ચોંટે એવો પ્રશ્ન હોય.
દા.ત.: બ્લોક m1 પર m2 ધીમેથી રખાય → નવું દળ M = m1+m2. k સમાન રહે. T = 2π√(M/k) અને A સમાન રહે (ઝડપ શૂન્ય થાય).
સ્પ્રિંગ શ્રેણી/સમાંતર સંયોજન — ફક્ત કેવરેજ યાદ રાખો: સમાંતર: k_eff = k1 + k2 શ્રેણી: 1/k_eff = 1/k1 + 1/k2
બે સ્પ્રિંગ વડે SHM પ્રશ્ન હોય; વિતરણ (force split) ગણ્યા વગર સીધું કામ.
દા.ત.: બે સમાન સ્પ્રિંગ (k) સમાંતર લટકાવેલા બ્લોકનો T = 2π√(m/2k). શ્રેણીમાં k_eff = k/2 → T = 2π√(2m/k).
દોલનગતિની ઊર્જા–વેગ મર્યાદા E_total = ½kA² = ½mv_max², અને v = ω√(A² − x²)
ઝડપી ગણતરી જોઈતી હોય, ખાસ કરીને A, v_max, x આપેલા હોય.
દા.ત.: v_max = ωA. જો x = A/2 હોય, v = ωA·√3/2. v_max/(√3/2) થી ω અને A એકબીજા વગર મળે.
લંબુલ (સેકન્ડ પેન્ડુલમ) યાદ કરો — GUJCET માં ઘણીવાર આ જ ચલ બનાવે છે: L = 1 m → T = 2 s, f = 0.5 Hz
વિકલ્પોમાં 0.5 Hz, 2 s, g=π² વગેરે હોય, પણ કોઈ પણ એકલો સંખ્યા ગણવાની જરૂર ન પડે.
દા.ત.: પ્રશ્ન: T = 2 s મેળવવા લંબાઈ કેટલી? જવાબ 1 m. ગણતરી કાઢવાની જરૂર નથી.
તરંગ સમીકરણની દિશા ઝડપી ઓળખ y = A sin(kx ± ωt) માં x સાથેની ચિહ્નો જુઓ. જો (kx − ωt) → +x દિશામાં; જો (kx + ωt) → −x દિશામાં
દિશા પૂછતો પ્રશ્ન, પણ ગણતરી વગર.
દા.ત.: y = 0.02 sin(0.5πx − 50πt) cm → +x દિશામાં. y = 0.02 sin(0.5πx + 50πt) cm → −x દિશામાં.
તરંગ વેગની સૂત્રો ફાસ્ટ યાદ: v = fλ = ω/k = λ/T આપેલ સમીકરણમાં k અને ω શોધો → v = ω/k
સમીકરણ સ્વરૂપ આપેલ હોય, પણ f, λ અલગ ન હોય.
દા.ત.: y = 0.1 sin(4x − 200t) → k = 4, ω = 200 → v = 50 m/s. λ = 2π/4 = π/2, f = 200/2π.
અનુનાદ (resonance) ત્યારે જ થાય જ્યારે ચાલક આવૃત્તિ = પ્રણાલીની સ્વાભાવિક આવૃત્તિ, અને phase between displacement – driving force ≈ 90°
એન્ટી-નોડ, ધ્રુવ, અથવા phase પ્રશ્નો.
દા.ત.: SHM માં displacement અને velocity 90° out of phase. Resonance પર velocity maximum અને displacement zero.
પ્રસરણમાધ્યમની ઘનતા – તરંગ વેગ અપ્રભાવિત sound વેગ v = √(γP/ρ) માં ρ વધે તો v ઘટે, પણ λ = v/f માં f fixed.
વાતાવરણીય પરિસ્થિતિઓ અથવા પ્રકાશ/ધ્વનિ ભેદ પ્રશ્નો.
દા.ત.: વાયુનું તાપમાન વધે → v = √(γRT/M) વધે. f બદલાતું નથી, તેથી λ વધે.
standing wave માં nodes અને antinodes વચ્ચેનું અંતર node → node = λ/2 node → antinode = λ/4
તાર/વાયર પર કમ્પતનોલ (harmonic) પ્રશ્નો.
દા.ત.: જો L = n(λ/2) માટે પ્રથમ overtones શોધવા હોય, તો λ = 2L/n. Fundamental: n=1.
Doppler effect માં સીધું સૂત્ર: f' = f · (v ± v_o)/(v ∓ v_s) observer moving toward source → +v_o in numerator source moving toward observer → −v_s in denominator
GUJCET માં standard numerical, પણ signs યાદ ન રહે તો ચિહ્ન પદ્ધતિ વાપરો.
દા.ત.: સ્રોત પ્રેક્ષક તરફ જાય, પ્રેક્ષક સ્થિર: f' = f·v/(v−v_s). observer moving toward stationary source: f' = f·(v+v_o)/v.
તરંગોના intensity/I બે સ્રોતો વચ્ચે interference: I_total = I1 + I2 + 2√(I1I2) cos φ constructive maximum: I_max = (√I1+√I2)² destructive minimum: I_min = (√I1−√I2)²
દ્વિ-સ્લિટ અથવા કોહરેન્ટ સ્રોત પ્રશ્નો.
દા.ત.: જો I1 = 4I, I2 = I → I_max = (2√I+√I)² = 9I, I_min = (2√I−√I)² = I. Ratio max/min = 9.
