બલ્ક Matter ના ગુણધર્મો — Quick Revision

🧪 GUJCET — Gujarati • Physics • Properties of Bulk Matter

🧠 યાદ રાખો

હૂક્સના નિયમ મુજબ પ્રતિબળ સામાન્યપણે સંવિગટના સમપ્રમાણમાં હોય છે; લચીલું સીમા વટાવી જાય તો આ નિયમ લાગુ પડતો નથી.
પ્રતિબળ એકમ N/m² (પાસ્કલ) અને સંવિગટ એકમરહિત છે.
ઇંગ્સનનો મોડ્યુલસ (Y) = પ્રતિબળ / દૈર્ઘ્ય સંવિગટ — કડકાઈ માપ દર્શાવે છે.
અપ્રેશ મોડ્યુલસ (K) = પ્રતિબળ / ઘનફળ સંવિગટ; અપ્રેશની વિરુદ્ધ પ્રતિકાર ઓળખાવે છે.
દ્રઢતા મોડ્યુલસ (G) = પરસ્પર પ્રતિબળ / ક્ષેત્રીય સંવિગટ.
પોઈઝન અનુપાત (σ) = પરસ્પર સંવિગટ / દૈર્ઘ્ય સંવિગટ; તેનો મૂલ્ય 0 થી 0.5 વચ્ચે હોય છે.
ઈંગ્સન મોડ્યુલસ અને અપ્રેશ મોડ્યુલસ વચ્ચેનો સંબંધ: Y = 3K(1 − 2σ).
તણાવ ઊર્જા પ્રતિ એકમ ઘનફળ = ½ × પ્રતિબળ × સંવિગટ.

⚡ ઝડપી સૂત્રો

યંત્રિક પ્રતિબળ (σ) = F/A ; રેખીય સંવિગટ (ε) = ΔL/L ; Y = σ/ε = FL/(AΔL)
K = P/(ΔV/V) ; G = (F/A)/Δx/l
σ = Δr/r (પાર્શ્વ સંવિગટ) ; σ = (Δr/r)/(ΔL/L)
ઉર્જા ઘનતા u = ½ Y ε² = ½ (પ્રતિબળ)(સંવિગટ)
તારમાં સાચવાયેલી ઊર્જા U = ½ FΔL = ½ (YA/L)(ΔL)²
આવેળું બિંદુ: V_t = (2r²(ρ − σ_fluid)g)/(9η)
ઓછા દબાણનું અતિરિક્ત દબાણ: બોલ્ડ (દ્રવબિંદુ) → ΔP = 2T/R ; સાબુબોલ્લા → ΔP = 4T/R

✅ વન-લાઈનર્સ

સંવિગટરહિત સ્થિતિને 'પ્રતિબળ-સંવિગટ વક્ર' દર્શાવે છે; અંતિમ બિંદુ પછી દ્રવ્ય તૂટે છે.
લચકદ્રવ્ય (Elastomer) માં વળાંક મોટો હોય છે પરંતુ પ્રતિબળ ઓછું લાગે છે.
અનુવર્તીબિંદુ (Yield point) પછી દ્રવ્ય સ્થાયી રીતે વિકૃત થાય છે.
પોલીમર્સ અને રબરમાં લચીલું સીમા ખૂબંધ હોય છે.
તારની લંબાઈ બમણી કરવાથી Y બદલાતું નથી; Y ફક્ત દ્રવ્ય પર આધારિત છે.
સપાટ તણાવ T એ પ્રતિ એકમ લંબાઈનું બળ છે; એકમ N/m.
સપાટ ઊર્જા E_s = T × ΔA ; એકમ J/m², જે T ના સમાન મૂલ્ય ધરાવે છે.
સંપર્કકોણ锐利 (θ < 90°) હોય તો દ્રવ ભીંજાવે છે (જળ/કાચ); θ > 90° હોય તો ન ભીંજાવે (પારદર્શક/કાચ).
બહિર્ગોળ (Convex) સપાટી માટે અતિરિક્ત દબાણ અંદર તરફ હોય છે.
તાપમાન વધવાથી દ્રવ્ય સપાટ તણાવ ઘટે છે.
સ્ટોક્સનો નિયમ: ઘર્ષણ બળ F = 6πηrv (લેમિનર પ્રવાહ માટે).
અંતિમ વેગ V_t માં ત્રિજ્યા વર્ગના સમપ્રમાણમાં; η વધે તો V_t ઘટે છે.
રેનોલ્ડ્સ અંક Re = ρvD/η; Re < 1000 લેમિનર, Re > 2000 અરાજક (ટર્બ્યુલેન્ટ) પ્રવાહ.
જળ પ્રવાહીઓમાં ગતિએ (ઘર્ષણ) ઊર્જા વ્યય થાય છે.
