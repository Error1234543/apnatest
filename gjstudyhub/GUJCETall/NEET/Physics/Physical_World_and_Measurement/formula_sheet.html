ભૌતિક વિશ્વ અને માપન — સૂત્ર રમતીટી (Formula Sheet)

⚡ સૂત્રો

SI એકમોની મૂળભૂત પરિમાણો: લંબાઈ → [M⁰L¹T⁰], દળ → [M¹L⁰T⁰], કাল → [M⁰L⁰T¹], તાપમાન → [M⁰L⁰T⁰K¹]
દરેક મૂળ ભૌતિક રાશિનું પરિમાણ સૂત્ર · SI: દરેક રાશિનો SI એકમ · કોઈ પણ ભૌતિક રાશિના પરિમાણ નક્કી કરવા માટે
પરિમાણીય સૂત્ર (Dimensional Formula) — બળ: [F] = [MLT⁻²]
M = દળ, L = લંબાઈ, T = કાળ · SI: Newton (N) · ફારસ (F = ma) પરથી
પરિમાણીય સૂત્ર — કાર્ય / ઊર્જા / ટોર્ક: [W] = [E] = [τ] = [ML²T⁻²]
કાર્ય = બળ × વિસ્થાપન; ટોર્ક = બળ × હાથ · SI: Joule (J) · કાર્ય, ઊર્જા અને ટોર્કનું પરિમાણ સમાન છે
પરિમાણીય સૂત્ર — દબાણ: [P] = [F]/[A] = [ML⁻¹T⁻²]
દબાણ = બળ / ક્ષેત્રફળ · SI: Pascal (Pa) · કોઈ પણ પ્રવાહી અથવા સ્થિતિસ્થાપકતામાં
પરિમાણીય સૂત્ર — પૃષ્ઠતાણ: [T] = [F]/[L] = [MT⁻²]
T = પૃષ્ઠતાણ, F = બળ, L = લંબાઈ · SI: N/m · પ્રવાહીની પૃષ્ઠતાણ શક્તિ માટે
પરિમાણીય સૂત્ર — સ્નિગ્ધતા ગુણાંક (Coefficient of Viscosity): [η] = [ML⁻¹T⁻¹]
F = 6πηrv સૂત્ર પરથી · SI: Pa·s अथवा N·s/m² · સ્ટોક્સના નિયમ મુજબ
પરિમાણીય સૂત્ર — પ્લાન્કનો અચળાંક (Planck's constant): [h] = [ML²T⁻¹]
E = hν પરથી; ν નું પરિમાણ [T⁻¹] · SI: J·s · ક્વાન્ટમ મિકેનિક્સમાં
પરિમાણીય સૂત્ર — ગુરુત્વાકર્ષણ અચળાંક (G): [G] = [M⁻¹L³T⁻²]
F = Gm₁m₂/r² પરથી · SI: N·m²/kg² · ન્યૂટનના સાર્વત્રિક ગુરુત્વાકર્ષણ નિયમ માટે
પરિમાણીય સૂત્ર — રેખીય વેગભાગ (Linear Momentum): [p] = [MLT⁻¹]
p = mv · SI: kg·m/s · કોઈ પણ ગતિમાન વસ્તુ માટે
પરિમાણીય સૂત્ર — કોણીય વેગ (Angular Velocity): [ω] = [T⁻¹]
ω = θ/t, કોણ અપરિમાણીય છે · SI: rad/s · વૃત્તાકાર ગતિમાં
પરિમાણીય સૂત્ર — મહત્વપૂર્ણ રાશિઓ (અન્ય): વેગ [LT⁻¹]; પ્રવેગ [LT⁻²]; આવર્તકાળ [T]; આવૃત્તિ [T⁻¹]; દળકેન્દ્ર બળના દળ સાથે [MLT⁻²]; પરમાણુ બળ [MLT⁻²]; વિદ્યુત પ્રવાહ [A]; વિદ્યુતભાર [AT]; વિદ્યુતસ્થિતિમાન [ML²T⁻³A⁻¹]
આ તમામ મૂળભૂત પરિમાણો પરથી ઉત્પન્ન થાય છે · SI: સંબંધિત SI એકમ · GUJCET માં પુનરાવર્તન હેતુ
પરિમાણીય સૂત્ર — મહત્વપૂર્ણ વિકલ્પ (Specific Heat Capacity): [c] = [ML²T⁻²K⁻¹]
Q = mcΔT પરથી; ΔT નું પરિમાણ [K] · SI: J/(kg·K) · ઉષ્માગતિશાસ્ત્રમાં
પરિમાણીય સૂત્ર — ઉષ્મીય વાહકતા ગુણાંક (Thermal Conductivity): [k] = [MLT⁻³K⁻¹]
Q/t = kAΔT/ℓ પરથી · SI: W/(m·K) · ઉષ્મા વહનના નિયમ માટે
મૂળભૂત ત્રણ બળો (Fundamental Forces) — ગુરુત્વાકર્ષણ: F_g = G m₁m₂/r²
G = ગુરુત્વીય અચળાંક, m₁, m₂ = દળ, r = અંતર · SI: N · દરેક દળિત વસ્તુ વચ્ચે
મૂળભૂત ચાર બળો — વિद्यુતચુંબકીય બળ (Coulomb's Law): F_e = (1/4πε₀) × q₁q₂/r²
ε₀ = વિડ્યુતશૂન્યની પરછેદકતા, q = વિદ્યુતભાર · SI: N · સ્થિર વિદ્યુતભારો માટે
કુલ નિપેટ (Net Error) — જોડણ/અલગાવ (Addition/Subtraction): ΔX = ΔA + ΔB
X = A ± B; ΔA, ΔB = પરમાપિત ભૂલો · SI: મૂળ રાશિનો એકમ · જ્યારે બે રાશિનો સરવાળો અથવા તફાવત કાઢવો હોય
કુલ નિપેટ (Net Error) — ગુણાકાર/ભાગાકાર (Multiplication/Division): (ΔX/X) × 100 = [(ΔA/A) × 100 + (ΔB/B) × 100]
X = AB અથવા X = A/B; % ભૂલનો સરવાળો · SI: % · સાપેક્ષ ભૂલોનો સરવાળો
કુલ નિપેટ — ઘાત સાથે (Powers): જો X = A^p · B^q / C^r હોય, તો: (ΔX/X) × 100 = p(ΔA/A)×100 + q(ΔB/B)×100 + r(ΔC/C)×100
p, q, r = ઘાત; દરેક રાશિની સાપેક્ષ ભૂલ ઘાત ગુણાંકથી ગુણાય · SI: % · ઘાત સામેલ હોય તેવી કોઈ પણ ભૌતિક રાશિ માટે
યાદી — મહત્તમ પરિમાણ (Maximum Dimensional Error): જો X = A^p B^q C^r હોય, તો મહત્તમ % ભૂલ = |p|(ΔA/A)×100 + |q|(ΔB/B)×100 + |r|(ΔC/C)×100
બધી ભૂલોનો સરવાળો લેવામાં આવે છે · SI: % · GUJCET માં પ્રમાણભૂત પદ્ધતિ
સાપેક્ષ ભૂલ / શતાંશ ભૂલ: સાપેક્ષ ભૂલ = (પરમાપિત ભૂલ) / (અંદાજિત કિંમત); % ભૂલ = (ΔX / X) × 100
ΔX = પરમાપિત ભૂલ, X = માપેલી કિંમત · SI: % · કોઈ પણ ભૌતિક રાશિ માટે
અંતઃસ્થ ગુરુત્વાકર્ષણ સતત (g) — પૃથ્વીની સપાટી પર: g = GM/R²
G = ગુરુત્વીય અચળાંક, M = પૃથ્વીનું દળ, R = પૃથ્વીની ત્રિજ્યા · SI: m/s² · પૃથ્વીની સપાટી પર (સરેરાશ g ≈ 9.8 m/s²)
પરમાપિત અંકો (Significant Figures) — નિયમો: બધી શૂન્યેતર અંકો સાર્થક છે; અગ્રણી શૂન્યો સાર્થક નથી; અંતિમ શૂન્ય દશાંશ ચિહ્ન સાથે સાર્થક છે
ઉદા. 0.00504 → 3 સાર્થક અંકો; 5.00 → 3 સાર્થક અંકો · SI: — · મૂલ્યને કોઈ પણ રૂપાંતરણ પહેલાં
પરિમાણીય સમભાજન (Dimensional Homogeneity Principle): જો P + Q = R હોય, તો [P] = [Q] = [R]
સંયોજનો/રાશિઓનો સરવાળો ત્યાં સુધી શક્ય છે જ્યારે તેમના પરિમાણો સમાન હોય · SI: — · કોઈ પણ સમીકરણની માટે
પરિમાણીય સંતુલનની ચાકસી (Dimensional Check): ડાબી બાજુનું પરિમાણ = જમણી બાજુનું પરિમાણ
ઉદા. v = u + at → [LT⁻¹] = [LT⁻¹] + [LT⁻²][T] = [LT⁻¹] ✓ · SI: — · ગાણિતિક સમીકરણ સચોટ છે કે કેમ તે તપાસવા માટે
એકમ રૂપાંતરણ — ગુરુત્વાકર્ષણ અચળાંક (CGS → SI): 1 dyn = 10⁻⁵ N; 1 g = 10⁻³ kg; 1 cm = 10⁻² m
સંબંધિત એકમો · SI: SI અને CGS વચ્ચે · એકમ રૂપાંતરણ માટે

🔗 સંબંધો

  • ગુરુત્વાકર્ષણ બળ એ શૂન્ય અંતરે અનંત થાય છે; સ્થિર વિદ્યુતચુંબકીય બળ પણ સમાન વર્તણૂક દર્શાવે છે.
  • પરમાપિત ભૂલોનો સરવાળો હંમેશા વધારે હોય છે — તેથી વિભાજન/ગુણાકારમાં પણ પરિમાણીય ભૂલો સંયોજિત થાય છે.
  • શૂન્યની સાર્થકતા: દશાંશ ચિહ્ન બાદની અંતિમ શૂન્યો સાર્થક ગણાય છે; દશાંશ ચિહ્ન પહેલાની અગ્રણી શૂન્યો સાર્થક નથી.
  • દરેક મૂળ ભૌતિક રાશિ (લંબાઈ, દળ, કાળ, તાપમાન, પ્રવાહ)નું પરિમાણ [M], [L], [T], [K], [A] માં દર્શાવી શકાય છે.
  • સ્નિગ્ધતા ગુણાંક [η] = [ML⁻¹T⁻¹] છે, જ્યારે પૃષ્ઠતાણ [T] = [ML⁰T⁻²] છે — બંનેનો યોગ્ય ઉપયોગ ગતિશીલ પ્રવાહી માટે.
  • પ્લાન્કનો અચળાંક [h] = [ML²T⁻¹] છે, જે કોઈ પણ ઊર્જા-આવર્તન સંબંધ E = hν માં આવે છે.

🎯 ટ્રિક્સ

પરિમાણીય સમીકરણને 'સંતુલિત' તપાસવા માટે: ફક્ત સરવાળો/અલગાવની જમણી અને ડાબી બાજુના પરિમાણો સમાન હોવા જોઈએ; કોઈ પણ બાજુ ભૌતિક રાશિના પરિમાણ ભિન્ન હોય તો સમીકરણ ભૂલભર્યું છે.
ઘાત ધરાવતી રાશિનું પરિમાણ: X = [M^a L^b T^c] હોય, તો X² = [M^{2a} L^{2b} T^{2c}] — ઘાતને સીધો પરિમાણ ઘાતાંક સાથે ગુણો.
મહત્તમ % ભૂલ શોધવા માટે: દરેક રાશિની % ભૂલ અને તેની ઘાત લો; બધી % ભૂલોને ધન (મહત્તમ) રીતે લો અને સરવાળો કરો — આ GUJCET ની પ્રમાણભૂત પદ્ધતિ છે.
ગુરુત્વાકર્ષણ અચળાંક G નું પરિમાણ મેમોરીઝ કરવા માટે: F = Gm₁m₂/r² → G = Fr²/(m₁m₂) → [G] = [MLT⁻²][L²]/[M²] = [M⁻¹L³T⁻²].
પરિમાણીય રીતે સાચા અને ખોટા વિકલ્પો વચ્ચે ચોક્કસ પસંદગી: જો સમીકરણની બંને બાજુનું પરિમાણ સમાન હોય, તો તે પરિમાણીય રીતે સચોટ છે (પરંતુ અચળાંકનો મૂલ્ય ચકાસી શકાતો નથી).

⚠️ ભૂલો

અંતિમ શૂન્ય (Trailing Zeros): ઉદા. 0.00504 માં શૂન્યોને સાર્થક ગણી દેવા — પરંતુ અગ્રણી શૂન્યો સાર્થક નથી; ફક્ત 5,0,4 = 3 સાર્થક અંકો.
પરિમાણીય સમીકરણની ચાકસી: જો v = u + at બરાબર હોય, તો [LT⁻¹] = [LT⁻¹] + [LT⁻²][T] → [LT⁻¹] = [LT⁻¹] ✓; કોઈ પણ પરિમાણ ભિન્ન હોય તો ભૂલ છે.
ભૂલોનો ચિહ્ન: પરમાપિત ભૂલ હંમેશા ધન હોય છે; મહત્તમ ભૂલ શોધતી વખતે બધી ભૂલોનો સરવાળો ધન રીતે લેવાનો (ઋણ ચિહ્નનો ઉપયોગ ન કરવો).
શૂન્યનું સાર્થક: શૂન્યની કોઈ પણ સંખ્યા સાર્થક નથી, પણ 100.0 માં 100.0 ચાર સાર્થક અંકો ધરાવે છે — શૂન્ય દશાંશ પછી છે, તેથી સાર્થક છે.
પરિમાણીય રીતે ચોક્કસ હોય તેવું સમીકરણ હંમેશા ભૌતિક રીતે સચોટ નથી હોતું: ઉદા. v = u + 2at (જો પરિમાણ સમાન હોય) પણ તે ગાણિતિક રીતે ખોટું હોઈ શકે છે.
વિદ્યુતભાર [AT] અને વહન [A]: વિદ્યુતભારના પરિમાણ [AT] અને પ્રવાહના પરિમાણ [A] છે — તે એક જ નથી.
મહત્તમ ભૂલમાં ઘાત ગુણાંક: X = A²B³C⁻¹ હોય, તો % ભૂલ = 2(ΔA/A)×100 + 3(ΔB/B)×100 + 1(ΔC/C)×100 — ઋણ ઘાત હોવા છતાં મહત્તમ ભૂલના સંદર્ભમાં ઘાતને ધન રાખો.
SI એકમનો યોગ્ય ઉપયોગ: દબાણનો SI એકમ Pa છે, N/m² નહીં; પ્લાન્કનો અચળાંક J·s છે, N·s² નહીં.
પરમાપિત ભૂલનો સરવાળો: A+B માં ΔA+ΔB સાચું છે, પણ A×B માં પણ ΔA+ΔB નહીં, કારણ કે અહીં સાપેક્ષ ભૂલોનો સરવાળો લેવો પડે છે.
મૂળભૂત ત્રણ બળો: ગુરુત્વાકર્ષણ અને સ્થિર વિદ્યુત બળ બંને v ∝ 1/r² નું પાલન કરે છે, પણ તેમની તીવ્રતા ખૂબ જ ભિન્ન છે.
