ઇલેક્ટ્રોનિક ઉપકરણો — સૂત્ર શેરીટ

🧪 GUJCET — Gujarati • Physics • Electronic Devices

⚡ સૂત્રો

અર્ધચાળકમાં ઇલેક્ટ્રોન અને છિદ્રની સાંદ્રતાનો ગુણાકાર: n_e × n_h = n_i²
n_e = ઇલેક્ટ્રોન સાંદ્રતા, n_h = છિદ્ર સાંદ્રતા, n_i = અંતર્ગત (intrinsic) વાહકતા સાંદ્રતા · SI: m⁻³ (દરેક સાંદ્રતા માટે) · કોઈપણ અર્ધચાળક માટે, આંતરિક અથવા બાહ્ય (doped)
અંતર્ગત અર્ધચાળકમાં વાહકતા: n_e = n_h = n_i
n_i = અંતર્ગત વાહક સાંદ્રતા · SI: m⁻³ · કેવળ અશુદ્ધિરહિત (intrinsic) અર્ધચાળક માટે
n-પ્રકાર અર્ધચાળકમાં વાહક સાંદ્રતા: n_e ≈ N_D , n_h = n_i² / N_D
N_D = દાતા (donor) અશુદ્ધિ સાંદ્રતા, n_i = અંતર્ગત સાંદ્રતા · SI: m⁻³ · n-પ્રકાર સંયોગ (doped) અર્ધચાળક, સામાન્ય તાપમાને
p-પ્રકાર અર્ધચાળકમાં વાહક સાંદ્રતા: n_h ≈ N_A , n_e = n_i² / N_A
N_A = સ્વીકારક (acceptor) અશુદ્ધિ સાંદ્રતા, n_i = અંતર્ગત સાંદ્રતા · SI: m⁻³ · p-પ્રકાર સંયોગ અર્ધચાળક, સામાન્ય તાપમાને
વાહકતા અને વાહકતા સાંદ્રતાનો સંબંધ: σ = n_e e μ_e + n_h e μ_h
σ = વાહકતા, n_e/n_h = ઇલેક્ટ્રોન/છિદ્ર સાંદ્રતા, e = મૂળભૂત આવેશ, μ_e/μ_h = ઇલેક્ટ્રોન/છિદ્ર ચાલકતા (mobility) · SI: S m⁻¹ (Siemens per metre) · સામાન્ય અર્ધચાળક વાહકતા માટે
પીએન જંક્શન ડાયોડ પ્રવાહ સમીકરણ: I = I₀ [ exp(eV/kT) − 1 ]
I = જંક્શન પ્રવાહ, I₀ = સંતૃપ્તિ પુનઃપ્રવાહ (reverse saturation current), e = મૂળભૂત આવેશ, V = લાગુ વોલ્ટેજ, k = બોલ્ટઝમેન અચળાંક, T = તાપમાન (K) · SI: A (પ્રવાહ), V (વોલ્ટેજ), K (તાપમાન) · આગળના (forward) અથવા પાછલા (reverse) બાયસમાં, તાપમાન T પર; I₀ સ્થિર ધારી શકાય
ડાયોડનો AC અવરોધ (dynamic resistance): r_ac = ΔV / ΔI
ΔV = વોલ્ટેજમાં નિર્ધારિત ફેરફાર, ΔI = તેને અનુરૂપ પ્રવાહમાં ફેરફાર · SI: Ω (ઓમ) · આગળના બાયસ વિસ્તારમાં, VBE ≈ 0.7 V (Si) આસપાસ
ડાયોડનો DC અવરોધ: r_dc = V / I
V = ડાયોડ પરનું DC વોલ્ટેજ, I = ડાયોડમાંથી વહેતો DC પ્રવાહ · SI: Ω (ઓમ) · કોઈપણ સ્થિર બિંદુ (steady point) માટે
અર્ધતરંગ દીપક (Half-wave rectifier) — આઉટપુટ આવૃત્તિ: f_out = f_in
f_in = ઇનપુટ AC આવૃત્તિ, f_out = આઉટપુટ脈动 dc આવૃત્તિ · SI: Hz · અર્ધતરંગ દીપકમાં, માત્ર અર્ધચક્ર પસાર થાય છે
સંપૂર્ણતરંગ દીપક (Full-wave rectifier) — આઉટપુટ આવૃત્તિ: f_out = 2 f_in
f_in = ઇનપુટ AC આવૃત્તિ, f_out = દીપક આઉટપુટ આવૃત્તિ · SI: Hz · બ્રિજ અથવા કેન્ત્રભંગી-વિભાજક બ્લોક ટ્રાન્સફોર્મર ફુલવેવ રેક્ટિફાયર
અર્ધતરંગ દીપક — DC આઉટપુટ વોલ્ટેજ: V_dc = V_m / π
V_m = ઇનપુટ AC તરંગનો શિખર વોલ્ટેજ (peak voltage) · SI: V (વોલ્ટ) · અર્ધતરંગ દીપક, બેરિયર પોટેન્શિયલ અવગણ્ય હોય
અર્ધતરંગ દીપક — DC પ્રવાહ: I_dc = I_m / π
I_m = શિખર પ્રવાહ (peak current) · SI: A · અર્ધતરંગ દીપક, બારણું અવરોધ R_L
અર્ધતરંગ દીપક — RMS પ્રવાહ અને વોલ્ટેજ: I_rms = I_m / 2 , V_rms = V_m / 2
I_m = શિખર પ્રવાહ, V_m = શિખર વોલ્ટેજ · SI: A / V · અર્ધતરંગ દીપક આઉટપુટ માટે
અર્ધતરંગ દીપક — યોગ્યતા (Rectification efficiency) મહત્તમ: η_max = 40.6 %
η = અચળાંક, 40.6% = (4/π²)×100 · SI: % · ઇદેઅલ અર્ધતરંગ દીપક માટે મહત્તમ, R_L >> r (ડાયોડ અવરોધ)
સંપૂર્ણતરંગ દીપક — DC આઉટપુટ વોલ્ટેજ: V_dc = 2 V_m / π
V_m = ઇનપુટ AC શિખર વોલ્ટેજ · SI: V (વોલ્ટ) · ઇદેઅલ સંપૂર્ણતરંગ દીપક, બેરિયર પોટેન્શિયલ અવગણ્ય
સંપૂર્ણતરંગ દીપક — DC પ્રવાહ: I_dc = 2 I_m / π
I_m = શિખર પ્રવાહ · SI: A · ઇદેઅલ સંપૂર્ણતરંગ દીપક
સંપૂર્ણતરંગ દીપક — RMS પ્રવાહ અને વોલ્ટેજ: I_rms = I_m / √2 , V_rms = V_m / √2
I_m / V_m = શિખર પ્રવાહ/વોલ્ટેજ · SI: A / V · સંપૂર્ણતરંગ દીપક આઉટપુટ માટે
સંપૂર્ણતરંગ દીપક — યોગ્યતા મહત્તમ: η_max = 81.2 %
η = અચળાંક, 81.2% = (8/π²)×100 · SI: % · ઇદેઅલ સંપૂર્ણતરંગ દીપક માટે
ટ્રાન્ઝિસ્ટર — પ્રવાહ ગુણોત્તર β (base current નિયંત્રિત): β = ΔI_C / ΔI_B (V_CE સ્થિર રાખીને)
β = Common-emitter current gain, ΔI_C = કલેક્ટર પ્રવાહમાં ફેરફાર, ΔI_B = બેઝ પ્રવાહમાં ફેરફાર · SI: અંતર્હિત (dimensionless) · CE (common-emitter) વિન્યાસ, V_CE અચળ
ટ્રાન્ઝિસ્ટર — પ્રવાહ ગુણોત્તર α (emitter current નિયંત્રિત): α = ΔI_C / ΔI_E (V_CB સ્થિર રાખીને)
α = Common-base current gain, ΔI_C = કલેક્ટર પ્રવાહ ફેરફાર, ΔI_E = એમિટર પ્રવાહ ફેરફાર · SI: અંતર્હિત · CB (common-base) વિન્યાસ, V_CB અચળ
α અને β વચ્ચેનો સંબંધ: β = α / (1 − α) , α = β / (1 + β)
α = CB current gain, β = CE current gain · SI: અંતર્હિત · બંને સંબંધો ટ્રાન્ઝિસ્ટરના સામાન્ય કાર્યક્ષેત્રમાં સાચા
ટ્રાન્ઝિસ્ટર પ્રવાહ સંબંધ: I_E = I_C + I_B
I_E = એમિટર પ્રવાહ, I_C = કલેક્ટર પ્રવાહ, I_B = બેઝ પ્રવાહ · SI: A · કોઈપણ ટ્રાન્ઝિસ્ટર ਵਿਥ (BJT), સામાન્ય વિસ્તારમાં
Common-emitter વિન્યાસ — વોલ્ટેજ gain: A_v = β × (R_L / R_i)
A_v = વોલ્ટેજ gain, β = CE current gain, R_L = લોડ અવરોધ, R_i = ઇનપુટ અવરોધ · SI: અંતર્હિત (વોલ્ટેજ ગુણોત્તર) · CE વિન્યાસ, સિગ્નલ આવૃત્તિ મધ્યમ વિસ્તાર
Common-emitter વિન્યાસ — શક્તિ gain: A_p = β² × (R_L / R_i)
A_p = શક્તિ gain (power gain), β = CE current gain, R_L = લોડ અવરોધ, R_i = ઇનપુટ અવરોધ · SI: અંતર્હિત · CE વિન્યાસ
Common-base વિન્યાસ — વોલ્ટેજ gain: A_v = α × (R_L / R_i)
A_v = વોલ્ટેજ gain, α = CB current gain, R_L = લોડ અવરોધ, R_i = ઇનપુટ અવરોધ · SI: અંતર્હિત · CB વિન્યાસ, મધ્યમ આવૃત્તિ
Common-base વિન્યાસ — શક્તિ gain: A_p = α² × (R_L / R_i)
A_p = શક્તિ gain, α = CB current gain, R_L = લોડ અવરોધ, R_i = ઇનપુટ અવરોધ · SI: અંતર્હિત · CB વિન્યાસ
Common-collector વિન્યાસ — વોલ્ટેજ gain: A_v ≈ 1 (બરાબર 1 થી થોડું ઓછું)
A_v = વોલ્ટેજ gain, ઇનપુટ વોલ્ટેજ ≈ આઉટપુટ વોલ્ટેજ · SI: અંતર્હિત · CC વિન્યાસ (emitter follower), મધ્યમ આવૃત્તિ
Common-collector વિન્યાસ — પ્રવાહ gain: A_i = 1 + β
A_i = પ્રવાહ gain, β = CE current gain · SI: અંતર્હિત · CC વિન્યાસ
ટ્રાન્ઝિસ્ટર input અવરોધ (common-emitter): R_i = ΔV_BE / ΔI_B (V_CE અચળ રાખીને)
R_i = ઇનપુટ અવરોધ, ΔV_BE = બેઝ-એમિટર વોલ્ટેજમાં ફેરફાર, ΔI_B = બેઝ પ્રવાહમાં ફેરફાર · SI: Ω (ઓમ) · CE વિન્યાસ, forward-active region
ટ્રાન્ઝિસ્ટર output અવરોધ (common-emitter): R_o = ΔV_CE / ΔI_C (I_B અચળ રાખીને)
R_o = output અવરોધ, ΔV_CE = કલેક્ટર-એમિટર વોલ્ટેજ ફેરફાર, ΔI_C = કલેક્ટર પ્રવાહ ફેરફાર · SI: Ω (ઓમ) · CE વિન્યાસ
ઝેનર ડાયોડ — વિધુતક્ષેત્રીય ક્ષેત્ર / પતલું depletion region: E = V_B / W (સરેરાશ, જ્યાં V_B ≈ barrier potential)
E = વિધુતક્ષેત્રીય ક્ષેત્ર (electric field), V_B = બેરિયર પોટેન્શિયલ, W = depletion regionની પહોળાઈ · SI: V/m (volt per metre) · Heavy doping → પાતળું depletion region → પ્રબળ E-field → ઝેનર ટનલિંગ
LED — ફોટોન ઊર્જા અને તરંગલંબાઈ સંબંધ: E_g = h c / λ
E_g = બેન્ડ ગેપ ઊર્જા, h = પ્લાન્ક અચળાંક, c = પ્રકાશની ઝડપ, λ = ઉત્સર્જિત પ્રકાશની તરંગલંબાઈ · SI: J (ઊર્જા), m (તરંગલંબાઈ) · LED માં electrons-છિદ્ર પુનઃસંયોગથી ફોટોન ઉત્સર્જન
સોલાર સેલ — શોર્ટ-સર્કિટ કરंट અને 옩ન-સર્કિટ વોલ્ટેજ: I_SC (short-circuit current) જ્યારે V = 0; V_OC (open-circuit voltage) જ્યારે I = 0
I_SC = શોર્ટ-સર્કિટ કરंट, V_OC = 옩ન-સર્કિટ વોલ્ટેજ · SI: A / V · સોલાર સેલના I-V વક્ર પર મહત્તમ શક્તિ બિંદુ (MPP) આ રેખા પર મળે

🔗 સંબંધો

  • α અને β વચ્ચેનો સીધો સંબંધ: β = α/(1−α); જો α વધે તો β ઝડપથી વધે છે, અને α→1 હોય તો β→∞
  • અર્ધતરંગ દીપકની યોગ્યતા (40.6%) સંપૂર્ણતરંગ દીપકના બમણી (81.2%) કરતા ઓછી હોય છે — કારણ કે અર્ધતરંગમાં એક સંપૂર્ણ ચક્રનો અર્ધો ભાગ વેસ્ટ થાય છે
  • ત્રણેય પ્રવાહોનો સંબંધ: I_E = I_C + I_B → α = I_C/I_E અને β = I_C/I_B → I_C = α·I_E = β·I_B
  • ફુલવેવ દીપકમાં આઉટપુટ આવૃત્તિ ઇનપુટ કરતા બમણી (2f_in) હોય છે, જે ફિલ્ટરિંગને સરળ બનાવે છે અને ripple factor ઘટાડે છે
  • P-પ્રકારમાં છિદ્ર વાહક (majority) હોય છે, n-પ્રકારમાં ઇલેક્ટ્રોન વાહક; પણ બંનેમાં minority carrier પણ હોય છે (n_e·n_h = n_i²)
  • જંક્શન ડાયોડ પ્રવાહ સમીકરણમાં I₀ (reverse saturation current) તાપમાન પર આધારિત છે — T વધે તો I₀ વધે છે અને આગળના બાયસ પ્રવાહ ઝડપી વધે છે
  • CE વિન્યાસમાં V_ce અચળ રાખીને β મેળવવામાં આવે છે; CB વિન્યાસમાં V_cb અચળ રાખીને α મેળવવામાં આવે છે — બંને input/output characteristics curves પરથી

α અને β વચ્ચેનો સંબંધ યાદ રાખવાનો મંત્ર: 'beta = alpha over (1 minus alpha)' — α = 0.98 હોય તો β = 0.98/0.02 = 49

પ્રવાહ સંબંધ I_E = I_C + I_B → α = I_C/I_E હંમેશા 1 થી ઓછો, β = I_C/I_B હંમેશા 1 થી વધુ (સામાન્ય રીતે 20–500)
LED ના λ (તરંગલંબાઈ) અને E_g (બેન્ડ ગેપ) નો સંબંધ: E_g(eV) ≈ 1240/λ(nm) — ઉદા. λ = 620 nm → E_g ≈ 2.0 eV (લાલ LED)
