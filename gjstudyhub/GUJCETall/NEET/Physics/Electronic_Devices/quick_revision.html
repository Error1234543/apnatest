🧠 યાદ રાખો

અંતર્ગત અર્ધવાહકમાં n = p = n_i; Fermi સ્તર bandgap ના મધ્યબિંદુ પર.
n-પ્રકારમાં donor દૂષણ (pentavalent); પદાર્થ ચુંબકીય રીતે તટસ્થ રહે છે.
p-પ્રકારમાં acceptor દૂષણ (trivalent); હોલ્સ વાહકતાના પ્રધાન વાહકો.
ઉષ્માજન્ય વાહક સાંદ્રતા n_i ∝ T^(3/2) e^(-E_g/2kT); તાપમાન વધે → ρ ઘટે.
p-n જંકશન ફોરવર્ડ બાયસ: barrier ઘટે, પ્રવાહ વધે (exponential). રિવર્સ બાયસ: depletion પહોળો થાય, very small leakage current.
Zener diode breakdown region માં કાર્યરત; constant voltage reference / voltage regulator તરીકે.
BJT માં emitterBase forward bias; collectorBase reverse bias (active region).
CB, CE, CC માંથી CE એમ્પ્લીફાયરનું input impedance સૌથી ઓછું અને gain સૌથી વધુ.
α વડે β: β = α/(1-α); I_E = I_B + I_C (Kirchhoff's current law for BJT).
Transistor ને સ્વિચ તરીકે: saturation (ON) અને cutoff (OFF) regions.
Half-wave rectifier η_max = 40.6%; Full-wave rectifier η_max = 81.2%.
AM માં message signal ની amplitude carrier ની amplitude માં ફેરફાર કરે છે; FM માં frequency માં ફેરફાર.
માહિતી વાહકતા (information carrying capacity) ∝ bandwidth; speech ≈ 3 kHz, music ≈ 20 Hz–15 kHz, TV/video ≈ several MHz.
调制指数 μ_a = E_m/E_c = m_a; μ > 1 સેડ્યુલેશન distort થાય.

⚡ ઝડપી સૂત્રો

Intrinsic carrier: n_i = √(N_c N_v) e^(-E_g/2kT)
Conductivity: σ = n_e e μ_e + n_h e μ_h
Resistivity relation: ρ = 1/σ
Doping: n_e · n_h = n_i² (mass action law, any temp)
Half-wave rectifier: V_dc = V_m/π, I_dc = I_m/π
Full-wave rectifier: V_dc = 2V_m/π, I_dc = 2I_m/π
Efficiency: η = P_dc/P_ac × 100%
Zener regulator: R_s = (V_in - V_Z)/I_Z,max
Common-base gain: A_i = α, A_v = α·(R_C/R_E), A_p = α²·(R_C/R_E)
Common-emitter gain: A_v = β·(R_C/R_E), A_i = β, A_p = β²·(R_C/R_E)
Current gain: I_C/I_E = α, I_C/I_B = β, β = α/(1-α)
Amplitude Modulation: s(t) = [A_c + m_a A_c cos(2πf_m t)]·cos(2πf_c t)
Modulation index: μ = m_a = E_m/E_c
AM bandwidth: B = 2f_m
AM power: P_total = P_c(1 + μ²/2); upper & lower sideband powers each = P_c·μ²/4
FM bandwidth (Carson's rule): B ≈ 2(Δf + f_m)

✅ વન-લાઈનર્સ

Semiconductor નો band gap 1 eV થી 3 eV વચ્ચે; insulator ~6 eV; conductor માં band overlap.
pn-junction નો depletion region માં fixed ions હોય; અવરોધકતા સર્વોચ્ચ હોય.
Forward bias → depletion width ઘટે; reverse bias → depletion width વધે.
Zener breakdown < 5 V માં dominant; avalanche breakdown > 5 V માં dominant.
Bridge rectifier માં 4 diodes; full-wave નું ripple frequency = 2×input frequency.
Transistor oscillator માં positive feedback જરૂરી (Barkhausen criterion).
CE amplifier phase shift = 180° (output ↔ input વચ્ચે).
CC amplifier (emitter follower) નું voltage gain ≈ 1; high input, low output impedance.
Transistor સ્વિચ તરીકે: base current ઓન/ઓફ કરવાથી collector-emitter પૂર્ણ સંતૃપ્તિ/કટઓફ.
Photo-diode અને LED એ optical devices; solar cell photovoltaic effect પર.
Digital circuits માં NAND/NOR gates universal માનવામાં આવે છે.
Communication system: source → transmitter → channel → receiver → destination.
Antenna length ≈ λ/4 અથવા λ/2 હોય તેવા designs effective radiation માટે.
AM signal spectral components: f_c, f_c+f_m (USB), f_c-f_m (LSB).
Ω (ohm)-cm એ intrinsic semiconductor ની Resistivity ની SI-સરખી પ્રચલિત એકમ.
