સંચાર સિસ્ટમ (Communication Systems) — સૂત્ર પત્રિકા

🧪 GUJCET — Gujarati • Physics • Communication Systems

⚡ સૂત્રો

વોલ્ટેજ મોડ્યુલેશન ઇન્ડેક્સ: μ = E_m / E_c
E_m = સંદેશવાહક (message) સંકેતની વોલ્ટેજ વિસ્તાર, E_c = વાહક (carrier) સંકેતની વોલ્ટેજ વિસ્તાર, μ = વોલ્ટેજ મોડ્યુલેશન ઇન્ડેક્સ · SI: એકમરહિત (no unit) · અનુદૈર્ઘ્ય મોડ્યુલેશનમાં સંદેશવાહક અને વાહક સંકેતોના વોલ્ટેજ અનુપાત તરીકે; μ ≤ 1 હોવું જોઈએ
આવર્તન મોડ્યુલેશન ઇન્ડેક્સ: β = Δf / f_m
Δf = મહત્તમ આવર્તન વિચલન (maximum frequency deviation), f_m = સંદેશવાહક સંકેતનું આવર્તન, β = આવર્તન મોડ્યુલેશન ઇન્ડેક્સ · SI: એકમરહિત · આવર્તન મોડ્યુલેશન (FM) માટે; Δf = k_f · E_m, જ્યાં k_f = આવર્તન સંવેદનશીલતા
AM સંકેતનું વોલ્ટેજ સમીકરણ: e_AM = E_c[1 + μ cos(2π f_m t)] sin(2π f_c t)
E_c = વાહક વિસ્તાર, μ = મોડ્યુલેશન ઇન્ડેક્સ, f_m = સંદેશવાહક આવર્તન, f_c = વાહક આવર્તન, t = સમય · SI: E_AM, E_c : વોલ્ટ (V); f_m, f_c : હર્ટ્ઝ (Hz) · અનુદૈર્ઘ્ય મોડ્યુલેશનમાં ઉત્પન્ન થતી AM તરંગનું ચાપડ્યું
AM ના પାର્શ્વી બંધ (Sidebands): f_USB = f_c + f_m ; f_LSB = f_c − f_m
f_USB = ઉચ્ચ પાર્શ્વી બંધ આવર્તન, f_LSB = નીચું પાર્શ્વી બંધ આવર્તન, f_c = વાહક આવર્તન, f_m = સંદેશવાહક આવર્તન · SI: હર્ટ્ઝ (Hz) · AM સંકેતમાં સંદેશવાહક ફ્રિક્વન્સીના ડબલબેન્ડ તરીકે બે પાર્શ્વી બંધ ઉદ્ભવે છે
AM નું આગોતરું પટલ (Bandwidth): BW = 2 f_m
BW = AM સંકેતનું આગોતરું પટલ, f_m = સંદેશવાહક સંકેતનું મહત્તમ આવર્તન · SI: હર્ટ્ઝ (Hz) · AM સંકેતને મોકલવા માટે જરૂરી લઘુત્તમ આવર્તન શ્રેણી; પાર્શ્વી બંધો વચ્ચેનું અંતર
FM નું આગોતરું પટલ (Carson ના નિયમ મુજબ): BW = 2(Δf + f_m)
Δf = મહત્તમ આવર્તન વિચલન, f_m = સંદેશવાહક સંકેતનું મહત્તમ આવર્તન · SI: હર્ટ્ઝ (Hz) · FM સંકેતનો આગોતરો પટલ; આવર્તન મોડ્યુલેશન સાથે જોડાયેલું Carson નું સૂત્ર
AM સંકેતની કુલ શક્તિ: P_T = P_c(1 + μ²/2)
P_T = કુલ પ્રસારિત શક્તિ, P_c = વાહક શક્તિ, μ = મોડ્યુલેશન ઇન્ડેક્સ · SI: વોટ (W) · AM તરંગની કુલ શક્તિ; P_c = E_c²/(2R) જ્યાં R = પ્રતિબંધ
AM એક પાર્શ્વી બંધની શક્તિ: P_SB = μ² P_c / 4
P_SB = એક પાર્શ્વી બંધ (USB અથવા LSB) ની શક્તિ, μ = મોડ્યુલેશન ઇન્ડેક્સ, P_c = વાહક શક્તિ · SI: વોટ (W) · AM માં ઉપર અથવા નીચા પાર્શ્વી બંધ દીઠ શક્તિ; બંને પાર્શ્વી બંધની કુલ શક્તિ = μ² P_c / 2
AM પ્રસારણ કાર્યક્ષમતા: η = μ² / (2 + μ²)
η = પ્રસારણ કાર્યક્ષમતા, μ = મોડ્યુલેશન ઇન્ડેક્સ; પ્રમાણભૂત રૂપ: η × 100% = (μ²/(2+μ²))×100% · SI: પ્રતિશત (%) · AM પ્રસારણમાં પાર્શ્વી બંધ શક્તિ / કુલ શક્તિ; μ=1 માટે η_max = 33.3%
માહિતી દર અને આગોતરું પટલ (Nykui스트): BW_min = R_b / 2
BW_min = લઘુત્તમ આવશ્યક આગોતરું પટલ, R_b = બિટ દર (bits/sec) · SI: Hz (બિટ/સેકન્ડ ના સંદર્ભમાં) · ડિજિટલ સંકેત માટે Nykui斯特 ન્યૂનતમ આગોતરું પટલ; R_b = n · f_s
નમૂના દર (Sampling rate) — Nykui斯特: f_s ≥ 2 f_m
f_s = નમૂના દર (sampling frequency), f_m = મેસેજ સિગ્નલનું મહત્તમ આવર્તન · SI: હર્ટ્ઝ (Hz) · સંદેશવાહક સંકેતને સરળતાથી પુનઃપ્રાપ્ત કરવા માટે નમૂના દર ઓછામાં ઓછો સંદેશવાહક આવર્તનના બે ગણો હોવો જોઈએ
ક્વોન્ટાઇઝેશન સ્ટેપ સાઇઝ: Δ = (V_max − V_min) / L
Δ = ક્વોન્ટાઇઝેશન સ્ટેપ સાઇઝ, V_max−V_min = કુલ વોલ્ટેજ રેન્જ, L = ક્વોન્ટાઇઝેશન સ્તરોની સંખ્યા (L = 2^n) · SI: વોલ્ટ (V) · A/D રૂપાંતરણમાં દરેક સ્તર માટેનું વોલ્ટેજ પરિમાણ
કોડિંગના બિટ્સની સંખ્યા: n = log₂(L)
n = દરેક નમૂનાના કોડિંગ માટે જરૂરી બિટ્સની સંખ્યા, L = ક્વોન્ટાઇઝેશન સ્તરોની સંખ્યા · SI: બિટ્સ (એકમરહિત સંખ્યા) · ડિજિટલ સંકેતમાં A/D રૂપાંતરણ પછી દરેક સ્તરને બિટ્સમાં મૂકવા માટે
અવકાશીય રેખીય દૂર (Line-of-sight distance): d = √(2Rh_T) + √(2Rh_R)
d = મહત્તમ રેખીય દૂર, R = પૃથ્વીની ત્રિજ્યા, h_T = પ્રસારક એન્ટેનાની ઊંચાઈ, h_R = પ્રાપ્તકર્તા એન્ટેનાની ઊંચાઈ · SI: મીટર (m) · અવકાશીય તરંગ (space wave / line-of-sight) પ્રસારણ માટે; h_T, h_R << R હોય તેવો ધારણા
અવકાશીય રેખીય દૂર (જો પ્રાપ્તકર્તા જમીન પર હોય): d ≈ √(2Rh_T)
d = મહત્તમ રેખીય દૂર, R = પૃથ્વીની ત્રિજ્યા (~6.4×10⁶ m), h_T = પ્રસારક એન્ટેનાની ઊંચાઈ · SI: મીટર (m) · જ્યારે પ્રાપ્તકર્તા એન્ટેના જમીન سطح પર હોય (h_R ≈ 0); સંકેત અવકાશીય તરંગ તરીકે

🔗 સંબંધો

  • AM માં AM તરંગમાં ત્રણ ઘટકો હોય છે: વાહક (f_c), ઉપર પાર્શ્વી બંધ (f_c + f_m), અને નીચું પાર્શ્વી બંધ (f_c − f_m). કુલ આગોતરું પટલ = 2f_m
  • AM કુલ શક્તિ P_T = P_c + P_USB + P_LSB = P_c(1 + μ²/2); વાહક શક્તિ ક્યાંય બદલાતી નથી, ફક્ત પાર્શ્વી બંધોમાં શક્તિ ઉમેરાય છે
  • AM પ્રસારણ કાર્યક્ષમતા η = μ²/(2+μ²); મહત્તમ μ=1 હોય ત્યારે η_max = 1/3 ≈ 33.3%
  • FM માં મોડ્યુલેશન ઇન્ડેક્સ β = Δf/f_m; AM કરતાં FM માં વધુ આગોતરું પટલ જરૂરી પણ અવાજની ગુણવત્તા શ્રેષ્ઠ
  • Nyquist શરત: f_s ≥ 2f_m — ડિજિટલ સંચારમાં સંદેશવાહક સંકેતને યોગ્ય રીતે પુનઃનિર્માણ માટે આવશ્યક
  • AM માં P_SB (એક પાર્શ્વી બંધ) = μ²P_c/4; બંને પાર્શ્વી બંધની કુલ શક્તિ = μ²P_c/2
  • FM આગોતરું પટલ Carson ના નિયમ મુજબ BW = 2(Δf + f_m); સામાન્ય રીતે FM આગોતરું પટલ AM કરતાં 10 ગણું મોટું હોય છે
  • શક્તિ સંરક્ષણ: મોડ્યુલેશન સમયે કુલ શક્તિ સમાન રહે છે, ફક્ત વાહક શક્તિનું પાર્શ્વી બંધોમાં વિતરણ થાય છે

🎯 ટ્રિક્સ

AM માં જો μ = 1 (100% મોડ્યુલેશન) હોય, તો P_T = 1.5 P_c અને η = 33.33% — આ યાદ રાખવાનું સરળ સૂત્ર છે
AM આગોતરું પટલ = 2 × f_m; એટલે કે જરૂરી બેન્ડવિડ્થ ફક્ત સંદેશવાહક ફ્રિક્વન્સીના બે ગણી — FM કરતાં AM ઓછી બેન્ડવિડ્થ લે છે
FM મોડ્યુલેશન ઇન્ડેક્સ β = Δf/f_m — જો f_m વધે તો β ઘટે (સ્થિર Δf માટે); AM ને વિપરીત, FM માં μ નો સીધો સંબંધ E_m/E_c જેવો નથી
પાર્શ્વી બંધ શક્તિનો ગુણોત્તર: P_USB/P_LSB = 1 (બંને સમાન); તેથી બે પાર્શ્વી બંધની કુલ = μ²P_c/2
ડિજિટલ સંચારમાં n બિટ્સ = 2^n સ્તરો; ઉદા. n=8 બિટ્સ → L=256 સ્તરો
AM પ્રસારણ કાર્યક્ષમતા η = μ²/(2+μ²) — μ=0.5 હોય ત્યારે η = 0.25/2.25 = 1/9 ≈ 11.1%

⚠️ ભૂલો

AM આગોતરું પટલ BW = f_m ભૂલીને ઘણીવાર લખવામાં આવે છે; સાચું સૂત્ર BW = 2f_m છે
AM કુલ શક્તિ P_T = P_c(1+μ²) ભૂલથી લખવામાં આવે છે; સાચું P_T = P_c(1 + μ²/2) છે
μ > 1 હોય ત્યારે મોડ્યુલેશન ઓવરમોડ્યુલેશન થાય અને સંકેત વિકૃત થાય; μ ≤ 1 રાખવું જરૂરી છે — આ નિયમ યાદ રાખવો
FM નું આગોતરું પટલ BW = 2f_m ગણી ભૂલ કરવામાં આવે છે; સાચું Carson સૂત્ર BW = 2(Δf + f_m) છે
AM ની કાર્યક્ષમતા η = μ²/2 ધારી લેવામાં આવે છે; સાચું η = μ²/(2+μ²) છે
નમૂના દર f_s = f_m લખી ભૂલ કરવામાં આવે છે; સાચું Nyquist શરત f_s ≥ 2f_m છે
P_SB = μ²P_c/4 એ એક પાર્શ્વી બંધ માટેનું સૂત્ર છે; બંને પાર્શ્વી બંધની કુલ શક્તિ μ²P_c/2 થાય છે — આ બે કંઈક અલગ છે
લિનિયર લાઇ-ઓફ-સાઇટ દૂર d = 2√(2Rh) ભૂલથી લખવામાં આવે છે; સાચું દૂર d = √(2Rh_T) + √(2Rh_R) છે જ્યારે બંને એન્ટેના ઊંચા હોય
