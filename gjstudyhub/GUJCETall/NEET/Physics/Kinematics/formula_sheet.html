ચાલ ગણિત (Kinematics) — સૂત્ર પત્ર

⚡ સૂત્રો

દૂરી / અંતર (Distance): d = વેગ × સમય (આયાતી વેગ માટે)
d = અંતર (m), વેગ = ગતિની ઝડપ (m/s) · SI: મીટર (m) · જ્યારે બે બિંદુઓ વચ્ચેનું કુલ માર્ગલાંબાઈ શોધવી હોય
સ્થાનાંતર (Displacement): s = અંતિમ સ્થાન - પ્રારંભિક સ્થાન
s = સ્થાનાંતર (m), પ્રારંભિક અને અંતિમ સ્થાન સદિશ છે · SI: મીટર (m) · સदिश રાશિ; દિશા સાથે; શૂન્ય પણ થઈ શકે (વાળો માર્ગ પસાર કરીને回到起点)
દર (Speed): સરેરાશ દર = કુલ અંતર / કુલ સમય
દર (m/s), અંતર (m), સમય (s) · SI: મીટર/સેકન્ડ (m/s) · અદિશ રાશિ; દિશા વિના
વેગ (Velocity): સરેરાશ વેગ = સ્થાનાંતર / સમય
v = સરેરાશ વેગ (m/s), s = સ્થાનાંતર (m), t = સમય (s) · SI: મીટર/સેકન્ડ (m/s) · સદિશ રાશિ; દિશા સાથે
તાત્કાલિક વેગ (Instantaneous Velocity): v = ds/dt
v = તાત્કાલિક વેગ, s = સ્થાનાંતર, t = સમય · SI: મીટર/સેકન્ડ (m/s) · s-t વક્રનો સ્પર્શક ઢાળ = તાત્કાલિક વેગ
પ્રવેગ (Acceleration): a = (v - u) / t
a = પ્રવેગ (m/s²), v = અંતિમ વેગ (m/s), u = પ્રારંભિક વેગ (m/s), t = સમય (s) · SI: મીટર/સેકન્ડ² (m/s²) · એકસમાન પ્રવેગ; ધન પ્રવેગ = વેગ વધે, ઋણ પ્રવેગ (મંદન) = વેગ ઘટે
તાત્કાલિક પ્રવેગ (Instantaneous Acceleration): a = dv/dt
a = તાત્કાલિક પ્રવેગ, v = વેગ, t = સમય · SI: મીટર/સેકન્ડ² (m/s²) · v-t વક્રનો સ્પર્શક ઢાળ = તાત્કાલિક પ્રવેગ
સૂત્ર 1: વેગ-સમય સંબંધ: v = u + at
v = અંતિમ વેગ, u = પ્રારંભિક વેગ, a = પ્રવેગ, t = સમય · SI: મીટર/સેકન્ડ (m/s) · એકસમાન પ્રવેગ (constant acceleration)
સૂત્ર 2: સ્થાનાંતર-સમય સંબંધ: s = ut + (1/2)at²
s = સ્થાનાંતર (m), u = પ્રારંભિક વેગ (m/s), a = પ્રવેગ (m/s²), t = સમય (s) · SI: મીટર (m) · એકસમાન પ્રવેગ
સૂત્ર 3: વેગ-સ્થાનાંતર સંબંધ: v² - u² = 2as
v = અંતિમ વેગ (m/s), u = પ્રારંભિક વેગ (m/s), a = પ્રવેગ (m/s²), s = સ્થાનાંતર (m) · SI: — (પરિણામ m/s માં) · એકસમાન પ્રવેગ; સમય જ्ञાत ન હોય ત્યારે ઉપયોગી
ન-મા પળના સ્થાનાંતરનો સૂત્ર: S_n = u + (a/2)(2n - 1)
S_n = n-મા પળમાં થતું સ્થાનાંતર (m), u = પ્રારંભિક વેગ (m/s), a = પ્રવેગ (m/s²), n = પળનું ક્રમાંક · SI: મીટર (m) · એકસમાન પ્રવેગ; n-મા સેકન્ડના સ્થાનાંતર માટે
પતનશીલ પદાર્થ (Free Fall): અંતિમ વેગ: v = u + gt
v = અંતિમ વેગ (m/s), u = પ્રારંભિક વેગ (m/s), g = ગુરુત્વાકર્ષણ પ્રવેગ ≈ 9.8 m/s², t = સમય (s) · SI: મીટર/સેકન્ડ (m/s) · મુક્ત પતન; લંબવત ગતિ; ઉપરની દિશા ધન, નીચેની દિશા ઋણ
પતનશીલ પદાર્થ: ઊંચાઈ-સમય સંબંધ: h = ut + (1/2)gt²
h = ઊંચાઈ/સંથાનાંતર (m), u = પ્રારંભિક વેગ (m/s), g = 9.8 m/s², t = સમય (s) · SI: મીટર (m) · લંબવત ગતિ; ઉપર જતાં g ઋણ, નીચે આવતાં g ધન
પતનશીલ પદાર્થ: વેગ-ઊંચાઈ સંબંધ: v² = u² + 2gh
v = અંતિમ વેગ (m/s), u = પ્રારંભિક વેગ (m/s), g = 9.8 m/s², h = ઊંચાઈ (m) · SI: મીટર/સેકન્ડ (m/s) · લંબવત ગતિ; સમય જ्ञात ન હોય ત્યારે
મુક્ત પતન: ઊંચાઈથી પડતાં વેગ: v = √(2gh)
v = માટીએ પહોંચેલો વેગ (m/s), g = 9.8 m/s², h = ઊંચાઈ (m), u = 0 · SI: મીટર/સેકન્ડ (m/s) · ઉપરથી શૂન્ય પ્રારંભિક વેગથી પતન
ઉપર ફેંકાયેલ પદાર્થ: મહત્તમ ઊંચાઈ: H = u² / (2g)
H = મહત્તમ ઊંચાઈ (m), u = પ્રારંભિક વેગ (m/s), g = 9.8 m/s², v = 0 (શિરોબિંદુએ) · SI: મીટર (m) · લંબવત ઉપર ફેંકીએ; શિરોબિંદુએ વેગ શૂન્ય
ઉપર ફેંકાયેલ પદાર્થ: મહત્તમ ઊંચાઈ સુધીનો સમય: t_asc = u / g
t_asc = ચઢાણ સમય (s), u = પ્રારંભિક વેગ (m/s), g = 9.8 m/s² · SI: સેકન્ડ (s) · લંબવત ઉપર ફેંકીએ; શિરોબિંદુએ v = 0
લંબવત પ્રક્ષેપ્ય ગતિ: કુલ આકાશગર્ભ સમય: T = 2u / g
T = કુલ આકાશગર્ભ સમય (s), u = પ્રારંભિક લંબવત વેગ (m/s), g = 9.8 m/s² · SI: સેકન્ડ (s) · લંબવત ઉપર ફેંકીએ; ચઢાણ સમય = ઊતરણ સમય
આડી પ્રક્ષેપ્ય ગતિ: સમય: t = √(2h/g)
t = આકાશગર્ભ સમય (s), h = ઊંચાઈ (m), g = 9.8 m/s², u_y = 0 (આડી ફેંક) · SI: સેકન્ડ (s) · આડી દિશામાં ફેંકાયેલો પદાર્થ; લંબવત પ્રારંભિક વેગ શૂન્ય
આડી પ્રક્ષેપ્ય ગતિ: આડું અંતર (Range): R = u × t = u × √(2h/g)
R = આડું અંતર (m), u = આડો પ્રારંભિક વેગ (m/s), h = ઊંચાઈ (m), g = 9.8 m/s² · SI: મીટર (m) · આડી દિશામાં ફેંકાણ; u_x = u, u_y = 0
ઢાળ પર પ્રક્ષેપ્ય ગતિ: મહત્તમ ઊંચાઈ: H = (u sinθ)² / (2g)
H = મહત્તમ ઊંચાઈ (m), u = પ્રારંભિક વેગ (m/s), θ = પ્રક્ષેપણ ખૂણો (rad/°), g = 9.8 m/s² · SI: મીટર (m) · પૃથ્વીની સપાટીએથી પ્રક્ષેપણ; g નીચેની દિશામાં
પ્રક્ષેપ્ય ગતિ: ઊભું અંતર (Range): R = (u² sin2θ) / g
R = આડું અંતર (m), u = પ્રારંભિક વેગ (m/s), θ = પ્રક્ષેપણ ખૂણો, g = 9.8 m/s² · SI: મીટર (m) · સમતલભૂમિ પર; પ્રારંભિક અને અંતિમ સ્થાન એક જ ઊંચાઈએ
પ્રક્ષેપ્ય ગતિ: મહત્તમ રેન્જ: R_max = u² / g (θ = 45° પર)
R_max = મહત્તમ આડું અંતર (m), u = પ્રારંભિક વેગ (m/s), g = 9.8 m/s² · SI: મીટર (m) · θ = 45° હોય ત્યારે રેન્જ મહત્તમ
પ્રક્ષેપ્ય ગતિ: પથ સમીકરણ: y = x tanθ - (g x²) / (2u² cos²θ)
y = ઊંચાઈ (m), x = આડું અંતર (m), θ = પ્રક્ષેપણ ખૂણો, u = પ્રારંભિક વેગ, g = 9.8 m/s² · SI: મીટર (m) · પ્રક્ષેપ્ય પથ પરત્વુત (parabolic); x-y સમતલ
નિરપેક્ષ વેગ (Relative Velocity): એક જ દિશામાં: v_AB = v_A - v_B
v_AB = A ની સાપેક્ષે B નો વેગ (m/s), v_A = A નો વેગ, v_B = B નો વેગ · SI: મીટર/સેકન્ડ (m/s) · એક જ દિશામાં ગતિ; v_A > v_B હોય તો ધન
નિરપેક્ષ વેગ: વિરુદ્ધ દિશામાં: v_AB = v_A - (-v_B) = v_A + v_B
v_AB = એક બીજાની સાપેક્ષે વેગ (m/s), v_A, v_B = પદાર્થોના વેગ · SI: મીટર/સેકન્ડ (m/s) · વિરુદ્ધ દિશામાં ગતિ; મર્યાદામાં યોગ
નિરપેક્ષ વેગ: બે કણો એકબીજા સાપેક્ષે (લંબ દિશા): |v_AB| = √(v_A² + v_B²) (જ્યારે v_A ⊥ v_B)
|v_AB| = નિરપેક્ષ વેગનું મૂલ્ય (m/s), v_A, v_B = બે વેગ · SI: મીટર/સેકન્ડ (m/s) · બે વેગો એકબીજાને લંબરૂપ હોય
નિરપેક્ષ વેગ: કોઈ પણ ખૂણે (સદિશ): v_AB = v_A - v_B (સદિશ તફાવત)
v_AB = A ની સાપેક્ષે B નો વેગ (સદિશ) · SI: મીટર/સેકન્ડ (m/s) · સદિશ રાશિ; દિશા ધ્યાનમાં રાખીને ગણતરી
સમાંતર વર્તુળ ગતિ: કોણીય વેગ: ω = 2π / T = 2πf
ω = કોણીય વેગ (rad/s), T = આવર્તકાળ (s), f = આવર્તન (Hz) · SI: રેડિયન/સેકન્ડ (rad/s) · એકસમાન વર્તુળ ગતિ
રેખીય અને કોણીય વેગનો સંબંધ: v = ωr
v = રેખીય વેગ (m/s), ω = કોણીય વેગ (rad/s), r = ત્રિજ્યા (m) · SI: મીટર/સેકન્ડ (m/s) · એકસમાન વર્તુળ ગતિ
કેન્દ્ર ત્યાગી પ્રવેગ (Centripetal Acceleration): a_c = v² / r = ω²r
a_c = કેન્દ્ર ત્યાગી પ્રવેગ (m/s²), v = રેખીય વેગ (m/s), ω = કોણીય વેગ (rad/s), r = ત્રિજ્યા (m) · SI: મીટર/સેકન્ડ² (m/s²) · એકસમાન વર્તુળ ગતિ; દિશા હંમેશા કેન્દ્ર તરફ
સદિશ-અદિશ વચ્ચેનો મૂળભૂત સંબંધ: એકસમાન પ્રવેગ માટે: v_avg = (u + v) / 2
v_avg = સરેરાશ વેગ (m/s), u = પ્રારંભિક વેગ, v = અંતિમ વેગ · SI: મીટર/સેકન્ડ (m/s) · એકસમાન પ્રવેગ (constant acceleration) હોય તે જ ઉપયોગી
ગ્રાફિકલ સંબંધ: v-t ગ્રાફ: v-t ગ્રાફ નીચેનું ક્ષેત્રફળ = સ્થાનાંતર (s)
s = સ્થાનાંતર (m), v-t ગ્રાફનો ઢાળ = પ્રવેગ (m/s²) · SI: મીટર (m) · કોઈ પણ પ્રકારની રેખીય ગતિ
ગ્રાફિકલ સંબંધ: a-t ગ્રાફ: a-t ગ્રાફ નીચેનું ક્ષેત્રફળ = વેગમાં ફેરફાર (Δv)
Δv = વેગમાં ફેરફાર (m/s), a = પ્રવેગ, t = સમય · SI: મીટર/સેકન્ડ (m/s) · કોઈ પણ પ્રકારની રેખીય ગતિ

🔗 સંબંધો

  • v-t ગ્રાફનો સ્પર્શક ઢાળ = તાત્કાલિક પ્રવેગ; v-t ગ્રાફ નીચેનું ક્ષેત્રફળ = સ્થાનાંતર
  • a-t ગ્રાફ નીચેનું ક્ષેત્રફળ = વેગમાં ફેરફાર (Δv); a-t ગ્રાફ સમાંતર રેખા = સમાંતર પ્રવેગ
  • s-t ગ્રાફનો સ્પર્શક ઢાળ = તાત્કાલિક વેગ; સમાંતર પ્રવેગ માટે s-t વક્ર પરવલય (parabola) છે
  • સમાંતર પ્રવેગમાં v = u + at; જો u = 0 હોય તો v ∝ t; જો u = 0 હોય તો s ∝ t²
  • પ્રક્ષેપ્ય ગતિમાં આડો વેગ સતત રહે છે (u cosθ); લંબવત વેગ v_y = u sinθ - gt
  • જો પ્રક્ષેપણ ખૂણો θ હોય તો R ∝ sin2θ; θ અને (90°-θ) માટે રેન્જ સમાન
  • વર્તુળ ગતિમાં v = ωr અને a_c = v²/r = ω²r; આ ત્રણેય પરસ્પર સંબંધિત
