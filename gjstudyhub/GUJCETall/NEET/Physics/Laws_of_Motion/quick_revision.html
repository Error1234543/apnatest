🧠 યાદ રાખો

જડત્વ એ દ્રવ્યની ગુણધર્મ છે; જડત્વ એટલે બાહ્ય બળ લાગે ત્યાં સુધી વિશ્રાંતિ કે એકસરખું ગતિ બનાવી રાખવાની પ્રवृત્તિ.
બળ એ સંવેગનો દર છે: F = dp/dt; જથ્થાત્મક રૂપે F = ma.
ન્યૂટનનો પ્રથમ નિયમ: બાહ્ય બળ વગર વસ્તુ વિશ્રાંતિ અથવા સરળ રેખામાં એકસરખી ગતિ બનાવી રાખે છે.
ન્યૂટનનો તૃतीय નિયમ: દરેક ક્રિયાની સમાન મૂલ્ય પરંતુ વિરુદ્ધ દિશામાં પ્રતિક્રિયા હોય છે — આ બળોต่าง-વસ્તુ પર લાગે છે તેથી રદ થતાં નથી.
સંપર્ક બળો: લંબ પ્રતિક્રિયા (N), ઘર્ષણ (f), તણાવ (T). સંપર્ક વિનાનાં બળો: ગુરુત્વાકર્ષણ, વિદ્યુત, ચુંબકીય.
મુક્ત શરીર આરેખ (Free Body Diagram) માં માત્ર વસ્તુ પર લાગતા બળો દોરો; બળ જોડીનાં બંને બળ એક જ આરેખમાં આવતાં નથી.
ઘર્ષણ: f ≤ μN; સ્થિર ઘર્ષણ આંકડાકીય મર્યાદા સુધી બહોળું બદલાય છે, ગતિશીલ ઘર્ષણ લગભગ અચળ રહે છે.

⚡ ઝડપી સૂત્રો

F_net = ma
p = mv
J = Δp = F·Δt (આઘાત)
f_s(max) = μ_s N ; f_k = μ_k N
Θણ સપાટી પર: N = mg cosθ ; f = μ mg cosθ ; નીચે તરફ ગતિ: a = g(sinθ − μ cosθ)
સરળ પ્યુલી: a = (m₁ − m₂)g/(m₁ + m₂) ; T = 2m₁m₂g/(m₁ + m₂) — જોળાઈરહિત દોરડું, દળરહિત પ્યુલી
ઉર્ધ્વગામી પક્ષિપટ્ટામાં દૃશ્યમાન ભાર: R = m(g + a); અધોગામી: R = m(g − a)
વર્તુળાકાર ગતિ: F_c = mv²/r = mω²r (અભિકેન્દ્રી બળ)

✅ વન-લાઈનર્સ

દ્વિતીય નિયમનો સિદ્ધાંત: બળ નહીં, પણ અવલંબન બળની સાથે સંવેગમાં થતો ફેરફાર.
સંવેગ સંરક્ષણ: બાહ્ય બળ શૂન્ય હોય તથા બંધ પ્રણાલીમાં કુલ સંવેગ અચળ રહે છે.
ઘર્ષણ બલે હંમેશા સંપર્ક સપાટીની સ્પર્શક દિશામાં અને ગતિ/ગતિના પ્રવૃત્તિની વિરુદ્ધ દિશામાં લાગે છે.
ઢળતી સપાટી પર v = √(2gh) જેટલી અંતિમ ઝડપ મેળવે છે — ઘર્ષણ ગૌણ હોય તથા આ ઝડપ ઢાળ પર આધાર રાખતી નથી.
ત્વરિત ઉપર નીચે લિફ્ટમાં ગુરુત્વાકર્ષણ બળ બદલાતું નથી; ફક્ત દૃશ્યમાન ભાર (નર્મલ રિએક્શન) બદલાય છે.
રોપ પર ઊભા વ્યક્તિ દ્વારા ખેંચવામાં આવતું તણાવ બળ એકસમાન રહે છે — જો દોરડું દળરહિત અને પ્યુલી રસાયણરહિત હોય.
સંતુલન: જો net F = 0 તો વસ્તુ વિશ્રાંતિમાં અથવા સરળ રેખામાં એકસરખી ગતિમાં રહે છે (આઇનર્શિયલ ફ્રેમ).
