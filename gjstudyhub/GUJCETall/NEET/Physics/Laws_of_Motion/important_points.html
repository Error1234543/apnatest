ગતિના નિયમો (Laws of Motion) — મહત્વપૂર્ણ બિંદુઓ

🧪 GUJCET — Gujarati • Physics • Laws of Motion

⭐ મહત્વના મુદ્દા

ન્યૂટનનો પ્રથમ નિયમ (જડત્વનો નિયમ): બાહ્ય બળ લાગે ત્યાં સુધી વિશ્રામમાં રહેલો કણ વિશ્રામમાં રહે છે અને ગતિમાં રહેલો કણ સમચાલ ગતિ કરે છે.
GUJCET માં સીધો પરિભાષિક પ્રશ્ન આવે છે; જડત્વની વ્યાખ્યા અને નિયમની શરતો પૂછાય છે.
જડત્વ એ દ્રવ્યમાન પર આધારિત છે — જેટલું વધુ દળ, તેટલું વધુ જડત્વ.
સામાન્ય ચડ્ડી પ્રકારના પ્રશ્નોમાં 'જડત્વ કયા અવલંબને આધારિત?' એવી સીધી પૂછામ;
ન્યૂટનનો દ્વિતીય નિયમ: F = ma; બળ એ સંવેગના ફેરફારનો દર છે, F = dp/dt.
સૌથી વધુ વપરાતો સૂત્ર — સંખ્યાત્મક પ્રશ્નોમાં સીધો ઉપયોગ થાય છે; SI એકમ N (Newton) યાદ રાખવો.
અપ્રભાવી બળ (Impulse): I = F × Δt = Δp = m(v − u).
IMPULSEને લગતા પ્રશ્નો GUJCET માં નિયમિત આવે છે; I = FΔt = mv − mu સૂત્ર યાદ રાખવું.
ન્યૂટનનો તૃતીય નિયમ: ક્રિયા અને પ્રતિક્રિયા બળો સમકક્ષ, વિરુદ્ધ દિશામાં અને એક જ રેખા પર અસર કરે છે.
'ક્રિયા-પ્રતિક્રિયા સદા ક્યારેય બંધ થતા નથી' — સિદ્ધાંત આધારિત પ્રશ્નો આવે છે.
સંવેગ સંરક્ષણનો નિયમ: બાહ्य અપ્રભાવી બળ શૂન્ય હોય ત્યારે વ્યવસ્થાનો કુલ સંવેગ અચળ રહે છે.
ઘોષા/રોકેટ પ્રશ્નો અને અથડામણ (collision) સંબંધિત GUJCET પ્રશ્નોમાં આ નિયમનો ઉપયોગ થાય છે.
સંતુલન: જ્યારે કણ પર લગતા તમામ બળોનું સદિશ જોડ શૂન્ય થાય, F_net = 0, a = 0.
સંતુલનની શરત F_net = 0 અને a = 0 એ પ્રમાણભૂત પ્રશ્નનો વિષય છે.
સ્થિર ઘર્ષણ (Static friction): f_s ≤ μ_s N; ઘર્ષણ બળ હંમેશા ગતિના વિરોધમાં કાર્યરત હોય છે.
μ_s અને Nનો સંબંધ ધરાવતા પ્રશ્નો GUJCET માં આવે છે; f_s(max) = μ_s N સૂત્ર મહત્વનું છે.
ગતિશીલ ઘર્ષણ (Kinetic friction): f_k = μ_k N; સામાન્ય રીતે μ_k < μ_s.
μ_k < μ_s હોવાનું સ્મરણ રાખવું; ઘર્ષણ બળના દિશા અને મૂલ્ય સંબંધી પ્રશ્નો આવે છે.
બળના આડા બળ (Normal force): સપાટી પર લંબ દિશામાં લાગતું પ્રતિક્રિયા બળ.
ઢલान સપાટી અને લિફ્ટના પ્રશ્નોમાં N નું મૂલ્ય શોધવું આવશ્યિક છે.
ઢલान સપાટી (Inclined plane): N = mg cos θ, mg sin θ ઢલાણ દિશામાં; ghર્ષણ સાથે f = μN.
ઢલान પરની ગતિ GUJCET નો હાર્ડકોર પ્રશ્ન; N = mg cos θ અને a = g(sinθ − μcosθ) યાદ રાખવાનાં.
રોમ (Tension): દોરીમાં સમદૈશી બળ; દોરીને હલકી અને અવિસ્તારી માની શકાય તેવા પ્રશ્નોમાં T અચળ રહે છે.
જોડાયેલા દળો (connected masses) અને pulley પ્રશ્નોમાં T શોધવું આવશ્યિક છે.
લિફ્ટ (Elevator): ઉપર જતાં apparent weight = m(g + a), નીચે જતાં apparent weight = m(g − a).
લિફ્ટ પ્રશ્નો GUJCET માં ખૂબ જ આવર્તક; apparent weightના સૂત્ર યાદ રાખવાં જરૂરી.
Atwood machine (એટેવડ યંત્ર): બે દળ M > m હોય તો a = (M−m)g/(M+m), T = 2Mm g/(M+m).
અથવા અસમાન દળ ધરાવતા pulley પ્રશ્નો આવે છે; T અને a ના સૂત્ર યાદ રાખવાં.
વક્રગામી ગતિ (Circular motion): કેન્દ્રગામી બળ F_c = mv²/r = mω²r હંમેશા કેન્દ્રની દિશામાં.
સર્ક્યુલર મોશન GUJCET નો અગત્યનો વિષય; F_cના સૂત્ર યાદ રાખવાં જરૂરી.
મોટા (Banking) રોડ: આદર્શ ઝુકાવ v₀ = √(rg tan θ); ઘર્ષણ વિના.
banking angle એ GUJCET માં પુનરાવર્તિત વિષય; v₀ = √(rg tanθ) યાદ રાખવું.
માપન પડકાર: એકમની વ્યવસ્થા (SI vs CGS) સમજવી જરૂરી — F નો એકમ N = kg·m/s².
એકમ સંબંધી પ્રશ્નો GUJCET માં સીધા આવે છે.
પ્રયોગ: હાથનો ધક્કો (push) અને દોરવાનો બળ (pull) વચ્ચેનો તફાવત — બંને બળ છે પણ દિશા બદલાય છે.
બૂમો (conceptual) પ્રશ્નોમાં આ તફાવત પૂછાઈ શકે છે.
