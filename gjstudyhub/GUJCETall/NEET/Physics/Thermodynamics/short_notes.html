ઉષ્માગતિશાસ્ત્ર (Thermodynamics) — શોર્ટ નોટ

🧪 GUJCET — Gujarati • Physics • Thermodynamics

📘 વ્યાખ્યાઓ

  • ઉષ્માગતિશાસ્ત્ર: ઉષ્મા, કાર્ય અને ઊર્જા રૂપાંતરણનું વૈજ્ઞાનિક અધ્યયન.
  • તંત્ર (System): ભૌતિક રીતે વ્યાખ્યાયિત કરેલ અને અભ્યાસ હેઠળનું વિસ્તાર.
  • ચાકુ (Surroundings): તંત્રની બહારનું બધું જ પરિસર.
  • મર્યાદા (Boundary): તંત્ર અને ચાકુને વહેંચતી કલ્પિત અથવા વાસ્તવિક સીમા.
  • ખુલ્લું તંત્ર: જેમાં પદાર્થ અને ઊર્જા બંને આદાન-પ્રદાન થાય છે.
  • બંધ તંત્ર: જેમાં ઊર્જાનું આદાન-પ્રદાન થાય પણ પદાર્થનું નહીં.
  • વિવિન્ન તંત્ર: જેમાં પણ પદાર્થ કે ઊર્જાનું આદાન-પ્રદાન ન થાય.
  • અવસ્થા ચલ (State Variable): તંત્રની વર્તમાન સ્થિતિ દર્શાવતી ચલ (જેમ P, V, T).
  • પથ ફલન (Path Function): તે રાશિ જે પથ પર આધારિત હોય (ઉષ્મા q, કાર્ય w).
  • સમતાપી પ્રક્રિયા: જે પ્રક્રિયા સ્થિર તાપમાને થાય (T = constant).
  • રુદ્ધોષ્મ પ્રક્રિયા: જે પ્રક્રિયામાં ઉષ્માનો આદાન-પ્રદાન થતો નથી (q = 0).
  • સમદાબ પ્રક્રિયા: જે પ્રક્રિયા સ્થિર દબાણે થાય (P = constant).
  • સમોષ્ણ પ્રક્રિયા: જે પ્રક્રિયા સ્થિર કદે થાય (V = constant).
  • આદર્શ વાયુ સમતાપી વિસ્તરણ: તાપમાન સ્થિર રાખીને વાયુનું કદ વધારવાની પ્રક્રિયા.
  • કાર્નો્ટ એન્જિન: સૌથી વધુ કાર્યક્ષમતા ધરાવતું આદર્શ ઉષ્મા યંત્ર.
  • એન્ટ્રોપી (Entropy): તંત્રની અવ્યવસ્થા અથવા ઊર્જાના વિખેરાણનું માપ.
  • ગિબ્સ મુક્ત ઊર્જા (G): સ્વયંસ્ફૂર્તતા તપાસવા માટે用的 ઊર્જા રાશિ.
  • ઉષ્માગતિશાસ્ત્રનો પ્રથમ નિયમ: ઊર્જાનો જન્મ અથવા નાશ શક્ય નથી, ફક્ત રૂપાંતરણ શક્ય છે.
  • ઉષ્માગતિશાસ્ત્રનો તૃતીય નિયમ: સંપૂર્ણ સ્ફટિક માટે 0 K પર એન્ટ્રોપી શૂન્ય હોય છે.

⚡ સૂત્રો

  • ∆U = q + w (ઉષ્માગતિશાસ્ત્રનો પ્રથમ નિયમ)
  • w_rev = −2.303 nRT log₁₀(V₂/V₁) (સમતાપી પ્રતિવર્તી કાર્ય)
  • w_irrev = −P_ext × ∆V (સમતાપી અપ્રતિવર્તી બાહ્ય દબાણ કાર્ય)
  • w = 0 (મુક્ત વિસ્તરણ / Ischoric પ્રક્રિયામાં કાર્ય શૂન્ય)
  • PV^γ = constant (રુદ્ધોષ્મ પ્રક્રિયા – પુઅસે સમીકરણ)
  • q_p = ∆H (સમદાબ પ્રક્રિયામાં ઉષ્માપરિવર્તન = એન્થાલ્પી ફેરફાર)
  • ∆H = ∆U + P∆V (એન્થાલ્પી અને આંતરિક ઊર્જા વચ્ચેનો સંબંધ)
  • Cp − Cv = R (આદર્શ વાયુ માટે મોલર ઉષ્માધારિતા સંબંધ)
  • ∆G = ∆H − T∆S (ગિબ્સ મુક્ત ઊર્જાનું મૂળ સમીકરણ)
  • η = 1 − T₂/T₁ (કાર્નોટ એન્જિનની કાર્યક્ષમતા)
  • ∆S_total = ∆S_system + ∆S_surroundings (બ્રહ્માંડની એન્ટ્રોપી ફેરફાર)
  • ∆S = q_rev / T (પ્રતિવર્તી પ્રક્રિયા માટે એન્ટ્રોપી ફેરફાર)
  • w = −∫PdV (સામાન્ય દાબ-કદ કાર્યનું સંકલન સ્વરૂપ)

⭐ મુખ્ય તથ્યો

  • અવસ્થા ચલો (P, V, T, n) એ વર્તમાન સ્થિતિ પર આધારિત છે, પથ પર નહીં.
  • ઉષ્મા (q) અને કાર્ય (w) એ પથ ફલનો છે — તેઓ ચલો નથી પણ પ્રક્રિયા દરમિયાન ઊર્જા સ્વરૂપે હસ્તળાંચન છે.
  • પ્રતિવર્તી કાર્ય અસંપાતી (Irreversible) કાર્ય કરતાં વધુ હોય છે.
  • રુદ્ધોષ્મ પ્રક્રિયામાં તાપમાન ફેરફાર થાય છે કારણ કે q = 0 હોવાથી ∆U = w.
  • સમોષ્ણ પ્રક્રિયા (Isochoric) માં ∆U = q_v (કદ સ્થિર હોય તો ઉષ્મા = આંતરિક ઊર્જા ફેરફાર).
  • Cp હંમેશા Cv કરતાં મોટું હોય છે કારણ કે સમદાબ પ્રક્રિયામાં વાયુ વિસ્તરણ કાર્ય પણ કરે છે.
  • ∆H = ∆n_g RT જ્યારે પ્રક્રિયામાં વાયુ મોલમાં ફેરફાર થાય.
  • ગિબ્સ મુક્ત ઊર્જા ∆G < 0 હોય ત્યારે પ્રક્રિયા સ્વયંસ્ફૂર્ત (Spontaneous) હોય છે.
  • ∆G = 0 હોય ત્યારે તંત્ર ઉષ્માગતિશાસ્ત્રીય સંતુલનમાં હોય છે.
  • ∆G > 0 હોય ત્યારે પ્રક્રિયા અસ્વયંસ્ફૂર્ત (Non-spontaneous) હોય છે.
  • સંપૂર્ણ સંપીડ્ય (Perfectly Compressible) પ્રક્રિયા એક આદર્શીકરણ છે જે વાસ્તવિક ભૌતિક પ્રણાલીઓમાં શક્ય નથી.
  • કાર્નોટ એન્જિનની કાર્યક્ષમતા હંમેશા 100% કરતાં ઓછી હોય છે કારણ કે T₂ > 0 K હોય છે.
  • ઉષ્માગતિશાસ્ત્રનો તૃતીય નિયમ નિરપેક્ષ શૂન્ય તાપમાન પ્રાપ્ત કરવા અશક્યતાને દર્શાવે છે.
  • સમતાપી પ્રક્રિયામાં ∆U = 0 (આદર્શ વાયુ માટે) કારણ કે આંતરિક ઊર્જા ફક્ત તાપમાન પર આધારિત છે.
  • વર્તુળાકાર પ્રક્રિયા (Cyclic Process) માટે ∆U = 0 અને q = −w.

⚠️ સામાન્ય ભૂલો

  • q અને w ની ચિહ્ન પ્રણાલી ભુલવી: ગુજરાતી પાઠ્યપુસ્તકમાં w > 0 જ્યારે તંત્ર પર કાર્ય થાય, q > 0 જ્યારે ઉષ્મા પ્રાપ્ત થાય.
  • ∆H = ∆U + P∆V માં P∆V ને ∆n_g RT માંથી ખોટી રીતે ગણી લેવા.
  • રુદ્ધોષ્મ પ્રક્રિયામાં PV = constant લાગુ પાડવું (આ ખોટું છે; PV^γ = constant સાચું છે).
  • Cp − Cv = R નો ઉપયોગ ઘન અથવા પ્રવાહી પદાર્થો પર કરવો (આ સંબંધ ફક્ત આદર્શ વાયુ માટે).
  • ∆S_universe = 0 લેવી પ્રતિવર્તી અથવા અપ્રતિવર્તી પ્રક્રિયા માટે (ફક્ત પ્રતિવર્તી માટે ∆S_universe = 0).
  • kcal અને J વચ્ચે રૂપાંતર કરતી વખતે 1 cal = 4.184 J ને બદલે 4.2 જ લેવું (ચોકસાઈ માટે 4.184 વપરાય છે).
  • સમોષ્ણ પ્રક્રિયામાં q = 0 સમજી લેવું (આ રુદ્ધોષ્મ પ્રક્રિયાનો ગુણધર્મ છે, સમોષ્ણનો નહીં).
  • ∆G = ∆H − T∆S માં T ને °C માં મૂકી દેવું (સૂત્ર Kelvin માં લેવું જરૂરી છે).
  • સ્વયંસ્ફૂર્તતા માટે ફક્ત ∆H < 0 જ જોવું (એન્ટ્રોપી ∆S પણ જોઇ શકાય છે).
  • વર્તુળાકાર પ્રક્રિયામાં q અને w બંને શૂન્ય સમજી લેવા (ફક્ત ∆U = 0 થાય, q અને w શૂન્ય નથી હોતા).

🔥 હાઈ-યીલ્ડ મુદ્દા

  • પ્રતિવર્તી સમતાપી કાર્યનું સૂત્ર w = −2.303 nRT log(V₂/V₁) પર્યાય્ય પ્રશ્નોમાં સતત આવે છે.
  • ∆G ની ચિહ્ન પ્રણાલી અને સ્વયંસ્ફૂર્તતા — ચાર-પાસા પ્રશ્નોમાં ખૂબ આવે છે.
  • Cp − Cv = R અને γ = Cp/Cv નો સંબંધ આદર્શ વાયુના ગુણધર્મો પર ધ્યાન આપો.
  • રુદ્ધોષ્મ પ્રક્રિયાનું PV^γ = constant અને T V^(γ−1) = constant સૂત્ર પર્યાય્ય આવે છે.
  • કાર્નોટ એન્જિન કાર્યક્ષમતા η = 1 − T₂/T₁ માં T એ Kelvin માં લેવાનું.
  • ઉષ્માગતિશાસ્ત્રનો પ્રથમ નિયમ ∆U = q + w ની ચિહ્ન પ્રણાલી સમજવી અત્યંત આવશ્યક છે.
  • સમોષ્ણ, સમદાબ, સમતાપી, રુદ્ધોષ્મ — ચારેય પ્રક્રિયાના q, w, ∆U, ∆H નું મૂલ્ય ખાતરી સાથે જાણવું.
  • ∆S સંબંધિત પ્રશ્નોમાં ∆S = q_rev/T અને ∆S_universe ≥ 0 ના નિયમનો ઉપયોગ.
  • માર્ટિન પ્રશ્નો (જોડાણ પ્રકાર) માં ચારેય પ્રક્રિયાઓના ગ્રાફ (P-V આલેખ) ઓળખવા જરૂરી છે.
  • R = 8.314 J K⁻¹ mol⁻¹ અને R = 0.0821 dm³ atm K⁻¹ mol⁻¹ — એકમ મુજબ યોગ્ય R નો ઉપયોગ.
