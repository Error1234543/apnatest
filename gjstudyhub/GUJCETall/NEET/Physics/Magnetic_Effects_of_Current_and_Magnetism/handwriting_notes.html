🧲 મૅગ્નેટ અને મૅગ્નેટિક ફીલ્ડ
આયર્ન, નિકલ, કોબાલ્ટ જેવા પદાર્થોમાં ચુંબકીય ગુણધર્મ જોવા મળે છે.
દરેક ચુંબકના બે ધ્રુવો હોય છે — ઉત્તર (N) અને દક્ષિણ (S). સમાન ધ્રુવો અપાકર્ષે છે, વિષમ ધ્રુવો આકર્ષે છે.
⚡ ચુંબકીય વલયબંધ ગુણધર્મ: કોઈ પણ ચુંબકનો એકમાત્ર ધ્રુવ અલગથી મેળવી શકાય નહીં.
📝 🔍 જો ગરમ કરો કે પાડી ફેંકો તો ચુંબકતા નષ્ટ થાય!
🌀 મૅગ્નેટિક ફીલ્ડ લાઇન્સ
ચુંબકની આસપાસ કાગળ પર રાખેલા કાંજાના ટુકડાઓ દ્વારા દૃશ્યમાન થતી વળાંકાયેલી રેખાઓ.
ફીલ્ડ લાઇન્સ S થી N તરફ (ચુંબકની બહાર) અને N થી S તરફ (અંદર) જાય છે — સંવૃત વળાંકાકાર.
બે ફીલ્ડ લાઇન્સ kabhi છেદતી નથી. જ્યાં લાઇન્સની ઘનતા વધુ હોય ત્યાં ફીલ્ડ મજબૂત.
ઉત્તર ધ્રુવલાઇનો બહાર આવે છે
દક્ષિણ ધ્રુવલાઇનો અંદર પ્રવેશે છે
📝 📌 ભૂમિનો ચુંબકીય ધ્રુવ યામદંડના થોડો ખાસે ખસેલો છે.
⚡ વિદ્યુતપ્રવાહની આસપાસ મૅગ્નેટિક ફીલ્ડ
ઓરેડસ્ટેનના પ્રયોગ મુજબ: વાહકમાં વહન કરતા પ્રવાહની આસપાસ મૅગ્નેટિક ફીલ્ડ ઉત્પન્ન થાય છે.
સtraightવાહક તારની આસપાસ ફીલ્ડ લાઇન્સ વૃત્તાકાર (concentric circles) હોય છે, કેન્દ્ર તાર થાય છે.
ડાબા હાથના thumb (તરલ દિશા) અને ઉંગળીઓ (ફીલ્ડ દિશા) → મૅક્સવેલના કૉર્કસ્ક્રૂ નિયમ.
🧪 પ્રવાહ વધે તો F વધે; અંતર વધે તો F ઘટે (B ∝ I/r).
📝 💡 રાઇટ હેન્ડ થંબ રૂલ: thumb = પ્રવાહ, બેકતી ઉંગળી = B દિશા
🔄 વિદ્યુતવાહક પર બળ (F = BIL)
જ્યારે પ્રવાહવાહક તારને મૅગ્નેટિક ફીલ્ડમાં મૂકીએ તો તે પર બળ લાગે છે.
F = B · I · L · sin θ
θ = ફીલ્ડ B અને પ્રવાહ દિશા વચ્ચેનો ખૂણો. θ = 90° મહત્તમ બળ, θ = 0° શૂન્ય બળ.
⚡ Fleming's Left-Hand Rule: Thumb=F, Forefinger=B, Centre finger=I
📝 📌 B ની એકમ: Tesla (T) = N·s/(C·m)
🎯 ચાર્જ પર બળ (Lorentz Force)
ચુંબકીય ફીલ્ડમાં ગતિ કરતા વિદ્યુતભાર q પર બળ: F = qvB sin θ
F⃗ = q(v⃗ × B⃗)
ધન ચાર્જ: બજુના હાથનો thumb (v), પ્રથમ ઉંગળી (B) → મધ્ય ઉંગળી = બળની દિશા.
ચુંબકીય બળ હંમેશા વેગ લંબરૂપ હોય છે — તે કાર્ય કરતો નથી, દિશા બદલે છે, ઝડપ નહીં.
B ⊥ vવલયગત ગતિ (Radius r = mv/qB)
B ∥ vસરળરેખીય ગતિ (બળ = 0)
🔬 ચુંબકીય બળ વિરામ અવસ્થાના ભાર પર શૂન્ય છે!
🔁 વલયગત ગતિ (Circular Motion in B)
ચુંબકીય બળ કેન્દ્રમુખી બળ આપે છે: qvB = mv²/r
r = mv / (qB) અને T = 2πm / (qB)
આવર્તકાળ T પ્રવેગ ઝડપ v પર આધારિત નથી — આ સાયક્લોટ્રોનના સિદ્ધાંતનું આધાર છે.
📝 📖 B વધારવાથી વ્યાસ kછોટો થાય, T બદલાતું નથી.
🔬 સાઇક્લોટ્રોન (Cyclotron)
કણોને ઉચ્ચ ઊર્જાએ પ્રવેગિત કરવાનું સાધન — Ernest Lawrence દ્વારા શોધ્યું.
બે D-આકારની ખાલીઓ (Dees) નીચે ઊંચી આવૃત્તિનું AC વિભવ તફાવત.
માઇનસક્યુલોનેલ વલયાકાર માર્ગે ફરે છે; Dee વચ્ચેના અંતરમાં电场થી પ્રવેગ.
f = qB / (2πm) (Cyclotron frequency)
⚛️ આ આવૃત્તિ કણની ઝડપ પર આધારિત નથી — resonance થાય છે.
📝 🏆 relativistic effects મુજબ B વધુ હોય તો frequency બદલાય.
📐 ઓહ્મનો મૅગ્નેટિક ક્ષેત્રનું સૂત્ર (Biot-Savart)
ધારાવહન તત્વ dl ની આસપાસ B નું મૂલ્ય:
dB = (μ₀/4π) · (I·dl·sinθ)/r²
μ₀ = ચુંબકશીલ્યુત્તા (4π×10⁻⁷ T·m/A).
આ સૂત્રથી સtraightવાહક, વૃત્તાકાર લૂપ, સોલેનોઇડની ફીલ્ડ મેળવી શકાય.
📝 📌 બાયોટ-સવૅર્ટ નિયમ મુખ્ય સૂત્ર છે — બાકીના તેથી બન્યા.
⭕ વૃત્તાકાર લૂપ પર બળ અને ફીલ્ડ
કેન્દ્ર પર B = μ₀I / (2R) (વિદ્યુતપ્રવાહ વાળા વલયમાં)
અક્ષ પર B = μ₀IR² / (2(x²+R²)^(3/2))
લૂપનું ક્ષેત્રફળ A = πR² હોય તો: B = μ₀I / (2R)
N સ્પર્શ હોય તો B = μ₀NI/(2R). મૅગ્નેટિક મોમેન્ટ m = NIA.
🔵 લૂપ એ દ્ધ્રુવ સમાન વર્તે છે — એક બાજુ N, બીજી S.
🔩 સોલેનોઇડ
બહુત ચડાવેલા કોઇલનું સૂત્ર — આંતરિક ફીલ્ડ એકસમાન અને મજબૂત.
B = μ₀nI (આંતરે, n = N/L એકમ લંબાઈના ટર્ન)
બહાર B ≈ 0. ફીલ્ડ લાઇન્સ સtraight, સમાંતર, ઘટ્ટ — સમાન જનરલર જેવી.
સોલેનોઇડ એ વિદ્યુતચુંબક તરીકે કામ કરે છે — કોરમાં આયર્ન મૂકીએ તો B વધે.
🧲 સોલેનોઇડ = વિદ્યુતચુંબક. પ્રવાહ બંધ કરો → ચુંબકતા ગાયબ.
📝 📌 B ∝ n; B ∝ I; B ∝ μ₀. આયર્ન કોરથી B ~1000× વધે.
🍩 ટોરોઇડ
વલયાકાર સોલેનોઇડ — તારની ઘણી સ્પર્શ એક વલય આકારે.
B = μ₀nI (આંતરે, n = N/2πR)
ટોરોઇડની બહાર B ≈ 0. સંવૃત વલય હોવાથી ફીલ્ડ બહાર નથી.
મૅગ્નેટિક મોમેન્ટ શૂન્ય — બહાર કોઈ બાહ્ય ફીલ્ડ નથી.
📝 💡 Transformer અને inductor માં ટોરોઇડલ કોઇલ વપરાય છે.
📜 એમ્પિયરનો પરિભ્રમણ નિયમ
∮ B⃗·dl⃗ = μ₀I_enclosed
વૃત્તાકાર લૂપ આસપાસ B નું రેખા સંકલન = μ₀ દ્વારા ઘેરાયેલો પ્રવાહ.
સોલેનોઇડ અને ટોરોઇડની ફીલ્ડ એમ્પિયરના નિયમથી સરળતાથી મેળવી શકાય.
🔑 આ નિયમ મૅગ્નેટોસ્ટેટિક્સમાં ગૌસના નિયમ જેટલો જ મહત્વનો.
📝 📌 I_enclosed = લૂપની અંદરથી પસાર થતો net પ્રવાહ.
⚡ ગેલ્વેનોમીટર
સૂક્ષ્મ પ્રવાહ માપવાનું સાધન — moving coil galvanometer.
ચોરસ કોઇલ M ને ટેન્ડન સ્પ્રિંગથી લટકાવેલ; ચુંબકની વચ્ચે કોઇલ ફરે છે.
τ = N·I·A·B અને I = θ / K (K = torsion constant)
Current sensitivity = N·A·B / k
灵敏度 માપવાનો એકમ: div/A અથવા scale division per ampere.
⚡灵敏度 વધારવા: N, A, B વધારો કે k (સ્પ્રિંગ) ઘટાડો.
📝 🔍 આંશિકપ્રવાહ માપન માટે સંવેદનશીલતા ખૂબ જરૂરી.
🔀 ગેલ્વેનોમીટર → એમીટર / વોલ્ટમીટર
એમીટર બનાવવા: ગેલ્વેનોમીટરમાં શંટ (low resistance) સમાંતર જોડો.
S = Ig·G / (I - Ig) (Shunt resistance)
વોલ્ટમીટર બનાવવા: સીરીઝમાં ઊંચો પ્રતિબંધ (high R) જોડો.
R = V/Ig - G (Series resistance)
🔧 એમીટરનો પ્રતિબંધ ≈ 0; વોલ્ટમીટરનો ≈ ∞.
📝 📌 શંટથી વધુ પ્રવાહ shuntમાંથી જાય, ગેલ્વેનોમીટર સુરક્ષિત.
🧲 વિદ્યુતચુંબક અને મૅગ્નેટિક ડિપોલ
આયર્ન કોરવાળા સોલેનોઇડને વિદ્યુતચુંબક કહીએ. પ્રવાહ ચાલુ રાખો → ચુંબક બનો, બંધ કરો → ગાયબ.
મૅગ્નેટિક ડાયપોલ મોમેન્ટ: m = N·I·A (વલયમાં), એકમ: A·m².
બાહ્ય B માં ડાયપોલ પર ટોર્ક: τ = m × B.
τ = mB sin θ
⚡ τ મહત્તમ જ્યારે θ = 90°, શૂન્ય જ્યારે θ = 0° (સંતુલન).
📋 ચુંબકીય ક્ષેત્ર — સ્થિર વિદ્યુત vs પ્રવાહ
સ્થિર વિદ્યુતભાર → માત્ર વિદ્યુતક્ષેત્ર, ચુંબકીયક્ષેત્ર નથી.
ગતિશીલ વિદ્યુતભાર → વિદ્યુતક્ષેત્ર + ચુંબકીયક્ષેત્ર (બંને).
સ્રોતની ગતિના પ્રકાર પર B આધારિત: બિંદુ, રેખા, વલય, સોલેનોઇડ, ટોરોઇડ.
સ્થિર qE_field only
ગતિશીલ qE + B both fields
📝 🌐 ભૂમિનું ચુંબકીયક્ષેત્ર ≈ 30–60 μT (અત્યંત નિમ્ન).
🧪 પ્રયોગો અને અવલોકનો
ઓરેડસ્ટેન પ્રયોગ: તારની નીચે કમ્પાસ રાખો, પ્રવાહ પસાર કરો → સૂઈ બદલે છે.
પેરીન પ્રયોગ: વૃત્તકાર કોઇલ પર ચુંબકીય ક્ષેત્ર માપન.
Helmholtz coil: સમાન રોકાણ ધરાવતી બે સમાંતર કોઇલ — મધ્યમાં B અત્યંત સમાન.
Helmholtz: B = (4/5)^(3/2) · μ₀nI / R
🧫 Helmholtz coil પ્રયોગશાળામાં B ને એકસમાન કરવા વપરાય છે.
📝 📌 બે કોઇલ વચ્ચેનું અંતર = R (ત્રિજ્યા).
