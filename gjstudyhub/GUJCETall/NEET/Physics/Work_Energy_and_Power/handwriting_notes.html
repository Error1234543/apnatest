અધ્યાય ૧ : કાર્ય, ઊર્જા અને શક્તિ
ભૌતિકશાસ્ત્રમાં 'કાર્ય'નો અર્થ સામાન્ય બોલચાલના અર્થ કરતાં બહુદુ ભિન્ન છે — જ્યારે બળ લગાડીને કોઈ વસ્તુ સ્થાન બદલાય ત્યારે જ ભૌતિકશાસ્ત્ર મુજબ કાર્ય થયું ગણાય.
બળ + સ્થાનાંતરકાર્ય (Work)
ધ્યાન રાખો : જો વિસ્થાપન શૂન્ય હોય, તો કાર્ય શૂન્ય — ઉદા. බોલિંગની બોલને હાથે રાખીને ખસેડ્યા વિના ઊભી રહેવું, તેમાં કોઈ કાર્ય થયું નથી.
📝 📝 યુનિટ : જૂલ (J) = N·m ; પરિમાણ : [M L² T⁻²]
૧.૧ કાર્ય (Work)
જ્યારે કોઈ બળ F વસ્તુ પર લાગે અને વસ્તુ s જેટલું સ્થાનાંતર પામે, ત્યારે કાર્ય W = F · s · cosθ થાય, જ્યાં θ એ બળ અને સ્થાનાંતર વચ્ચેનો ખૂણો છે.
W = F · s · cosθ
જો બળ અને સ્થાનાંતર સમાન દિશામાં હોય (θ = 0°), તો W = Fs (ધન કાર્ય).
જો બળ અને સ્થાનાંતર વિરુદ્ધ દિશામાં હોય (θ = 180°), તો W = −Fs (ઋણ કાર્ય). ઘર્ષણ બળ હંમેશા ઋણ કાર્ય કરે છે.
જો બળ અને સ્થાનાંતર પરસ્પર લંબ હોય (θ = 90°), તો W = 0. ઉદા. કેન્દ્રગામી બળ દ્વારા કરવામાં આવતું કાર્ય શૂન્ય છે.
⭐ ઋણ કાર્યનો અર્થ : બળ વસ્તુની ગતિને રોકવા પ્રયત્ન કરે છે, એટલે વસ્તુની ગતિઊર્જા ઘટે છે.
૧.૨ ચલ બળનું કાર્ય
જ્યારે બળ અચળ ન હોય પણ સ્થાન સાથે બદલાય, ત્યારે કાર્ય શોધવા માટે સંકલનનો ઉપયોગ થાય છે.
W = ∫ F(x) dx (x₁ થી x₂ વચ્ચે)
G–V આલેખમાં (બળ-સ્થાન ગ્રાફ) વક્ર નીચેનું ક્ષેત્રફળ = કરેલું કાર્ય.
📝 📌 સુવિચાર : વક્ર હેઠળનું ક્ષેત્ર ઋણ હોય તો કાર્ય ઋણ ગણાય.
૧.૩ ચુસ્ત (સ્પ્રિંગ) બળ અને કાર્ય
હૂકના નિયમ મુજબ ચુસ્ત બળ F = −kx, જ્યાં k = ચુસ્ત અચળાંક (Spring constant).
W_spring = ½ k (x₁² − x₂²)
જ્યારે ચુસ્તને સંતુલન સ્થિતિથી x વિસ્થાપિત કરવામાં આવે, ત્યારે ચુસ્ત બળ દ્વારા થતું કાર્ય W = −½kx² હોય છે.
બાહ્ય બળ દ્વારા ચુસ્તને ખેંચવા માટે કરવું પડતું કાર્ય ધન હોય છે : W = +½kx².
⚡ ચુસ્ત બળ સંરક્ષી બળ છે — આ ઊર્જા સ્થિતિઊર્જાના રૂપે સંગ્રહિત થાય છે.
૧.૪ ગતિઊર્જા (Kinetic Energy)
ગતિમાન વસ્તુમાં જે ઊર્જા હોય છે તેને ગતિઊર્જા કહે છે.
K = ½ mv²
ગતિઊર્જા એ અદિશ રાશિ છે અને હંમેશા ધન અથવા શૂન્ય હોય છે.
ગતિઊર્જા અને વેગ વચ્ચેનો સંબંધ : K ∝ v² — વેગ દ્વિગણો કરતા ગતિઊર્જા ચાર ગણી થાય.
📝 🔑 વેગમાન p = mv થી K = p²/2m પણ લખી શકાય.
૧.૫ કાર્ય-ગતિઊર્જા પ્રમેય (Work-Energy Theorem)
કોઈ પણ વસ્તુ પર થતું નિવ્વળ કાર્ય = વસ્તુની ગતિઊર્જામાં થતો ફેરફાર.
W_net = ΔK = K_f − K_i = ½mv_f² − ½mv_i²
📐 આ પ્રમેય અચળ અને ચલ — બંને પ્રકારના બળો માટે લાગુ પડે છે.
જો W_net > 0, તો ગતિઊર્જા વધે (વેગ વધે); જો W_net < 0, તો ગતિઊર્જા ઘટે.
૧.૬ સ્થિતિઊર્જા (Potential Energy)
વસ્તુના સ્થાન અથવા ವಿન્યાસને કારણે જે ઊર્જા સંગ્રહિત થાય છે તે સ્થિતિઊર્જા U છે.
U_gravity = mgh (પૃથ્વીની સપાટી પાસે)
m = દળ, g = ગુરુત્વાકર્ષણ પ્રવેગ, h = સપાટીથી ઊંચાઈ.
સ્થિતિઊર્જા એ પણ અદિશ રાશિ છે; તેનું મૂલ્ય શૂન્ય અથવા ધન/ઋણ બંને હોઈ શકે (શૂન્ય સ્તરની પસંદગી પર આધારિત).
U_spring = ½ kx²
📍 સ્થિતિઊર્જા માત્ર બિંદુ A અને B વચ્ચેના તફાવત ΔU ઉપયોગી છે, સંપૂર્ણ મૂલ્ય U નહીં.
૧.૭ સંરક્ષી અને અસંરક્ષી બળો
સંરક્ષી બળ (Conservative force) : જે બળ પર થતું કાર્ય માર્ગથી સ્વતંત્ર હોય અને બંધ માર્ગે (closed loop) શૂન્ય હોય.
ઉદાહરણ : ગુરુત્વાકર્ષણ બળ, ચુસ્ત બળ, સ્થિર વિદ્યુત બળ.
અસંરક્ષી બળ (Non-conservative force) : જે બળ પર થતું કાર્ય માર્ગ પર આધારિત હોય.
ઉદાહરણ : ઘર્ષણ બળ, હવાના અવરોધ, શ्यानતા બળ.
સંરક્ષી બળ : ∮ F·dr = 0 | ∇ × F = 0
📝 💡 ઘર્ષણ બળ હંમેશા ઋણ કાર્ય કરે છે → યાંત્રિક ઊર્જા ઘટે છે.
૧.૮ સંરક્ષી બળ અને સ્થિતિઊર્જાનો સંબંધ
એક-પરિમાણમાં : F(x) = −dU/dx
F = −dU/dx ⟹ dU = −F dx
અર્થાત્, સ્થિતિઊર્જાનો ઢાળ ઋણ ચિહ્ન સાથે બળ બરાબર થાય.
🔹 બળ હંમેશા ઓછી સ્થિતિઊર્જા તરફ કાર્ય કરે છે — વસ્તુ સ્વભાવે ઊર્જા ઘટાડવા પ્રવણ છે.
U vs x આલેખમાં જ્યાં ઢાળ શૂન્ય (dU/dx = 0) હોય, ત્યાં બળ શૂન્ય અને સંતુલન મળે.
૧.૯ યાંત્રિક ઊર્જા સંરક્ષણનો નિયમ
જો પદ્ધતિ પર ફક્ત સંરક્ષી બળોનું પ્રભુત્વ હોય, તો યાંત્રિક ઊર્જા (K + U) અચળ રહે છે.
K_i + U_i = K_f + U_f અથવા E_mech = અચળ
અસંરક્ષી બળો (જેમ કે ઘર્ષણ) હાજર હોય, તો : ΔE_mech = W_non-conservative.
Δ(K + U) = W_nc ⟹ K_f + U_f = K_i + U_i + W_nc
⭐ યાંત્રિક ઊર્જા સંરક્ષણનો નિયમ = ઊર્જા સંરક્ષણનો વિશિષ્ટ રૂપ.
૧.૧૦ ઊર્જા સંરક્ષણનો વ્યાપક નિયમ
ઊર્જા સર્જી શકાતી નથી અને નશ્ટ પણ કરી શકાતી નથી — તેને એક રૂપમાંથી બીજા રૂપમાં રૂપાંતરિત જ કરી શકાય.
ઘર્ષણને કારણે ગુમાવાયેલી યાંત્રિક ઊર્જા ઉષ્મા (thermal energy) માં ફેરવાય છે — કુલ ઊર્જા અચળ રહે છે.
📝 📝 GUJCET માં ઘણીવાર ઘર્ષણસહિત પ્રશ્નો પૂછાય છે — યાંત્રિક ઊર્જા અચળ નથી રહેતી!
૧.૧૧ U–x આલેખ અને ગતિનું વિશ્લેષણ
U(x) વક્ર પર કોઈ બિંદુએ દોરેલ સ્પર્શકનો ઢાળ = −F આપે છે.
જો કુલ ઊર્જા E = K + U અચળ હોય, તો K = E − U ≥ 0 ⇒ વસ્તુ કેवल ત્યાં જ હોઈ શકે જ્યાં U ≤ E.
U = E બિંદુએ K = 0 ⇒ વસ્તુ પલટાના બિંદુ (turning point) પર હોય.
સંતુલન બિંદુ : dU/dx = 0
🔁 stabled equilibrium : U minima (U'' > 0) | unstable : U maxima (U'' < 0)
૧.૧૨ શક્તિ (Power)
શક્તિ = એકમ સમયમાં થતું કાર્ય અથવા ઊર્જા રૂપાંતરણ દર.
P_avg = W / Δt | P_instantaneous = dW/dt = F · v
જો બળ F અને વેગ v સમાન દિશામાં હોય, તો P = Fv.
P = F · v = F v cosθ
યુનિટ : વોટ (W) = J/s ; પરિમાણ : [M L² T⁻³]
📝 ⚡ 1 અશ્વશક્તિ (HP) ≈ 746 W (આંતરરાષ્ટ્રીય)
૧.૧૩ સરેરાશ અને તરતની શક્તિ
સરેરાશ શક્તિ P_avg = ΔW / Δt.
તરતની શક્તિ P(t) = dW/dt = F(t) · v(t).
📌 GUJCET માં સામાન્યતः અચળ વેગે કાર્ય થાય ત્યારે P = Fv એ રૂપનો ઉપયોગ થાય છે.
૧.૧૪ અથડામણ (Collision) — સંಕ್ಷિપ્ત
અથડામણ દરમિયાન વેગમાન સર્વદા સંરક્ષિત રહે છે (બાહ્ય બળ શૂન્ય હોય તો).
લવચીક અથડામણ (Elastic) : ગતિઊર્જા પણ સંરક્ષિત રહે છે.
અલવચીક અથડામણ (Inelastic) : ગતિઊર્જા સંરક્ષિત નથી રહેતી (ઉષ્મા/રૂપભંગમાં ફેરવાય).
લવચીક : m₁u₁ + m₂u₂ = m₁v₁ + m₂v₂ અને ½m₁u₁² + ½m₂u₂² = ½m₁v₁² + ½m₂v₂²
📝 🎯 દૈનંદિન જીવનમાં બધી અથડામણો અલવચીક જ હોય છે.
૧.૧૫ મહત્વના સૂત્રોનો સંગ્રહ
W = F·s·cosθ
W = ∫ F dx
W_spring = ½k(x₁² − x₂²)
K = ½mv² ; K = p²/2m
W_net = ΔK
U_g = mgh ; U_s = ½kx²
F = −dU/dx
K_i + U_i = K_f + U_f (સંરક્ષી બળો)
ΔE = W_nc (અસંરક્ષી બળો હાજર હોય)
P = W/t = F·v
📘 આ બધા સૂત્રો યાદ રાખવા — GUJCET માં સીધા સૂત્ર-આધારિત પ્રશ્નો આવે છે.
૧.૧૬ તૈયારી માટે ટિપ્સ
દરેક પ્રશ્નમાં પ્રથમ નક્કી કરો : 'યાંત્રિક ઊર્જા સંરક્ષિત છે કે નહીં?' — ઘર્ષણ/અવરોધ હોય તો નહીં.
શૂન્ય સ્તર (Reference level for U = 0) નિઃસંદેહ પસંદ કરો — સામાન્યતઃ નીચેતમ બિંદુ લેવાય છે.
ઋણ કાર્ય શોધવાનો અર્થ કાઢવો : ઘર્ષણ, ગુરુત્વાકર્ષણ (ઉપરની ગતિ દરમિયાન).
✏️ અભ્યાસ યોજના : સૌ પ્રથમ સૂત્રો યાદ કરો → ફરી સરળ ઉદાહરણો → પછી ચલ બળ/ઘર્ષણવાળા પ્રશ્નો.
