🎯 પરીક્ષા ટ્રિક્સ

ઍન્ટિબાયોટિક્સ અને સલ્ફોનામાઇડ્સ વચ્ચેનો તફાવત યાદ રાખવા માટે: 'સલ્ફ' = સલ્ફોનામાઇડ્સ (પ્રથમ સંશ્લેષિત એન્ટિબાયોટિક્સ). બેક્ટેરિયોસ્ટેટિક અને બેક્ટેરીસાઇડમાં વિભેદન માટે બેક્ટેરીઓની વૃદ્ધિ અટકાવે → સ્ટેટિક, મારી નાખે → સයිડ. ઉદા: સલ્ફોડિમ્નેઝિક એક બેક્ટેરિયોસ્ટેટિક સલ્ફોનામાઇડ છે.
જ્યારે પ્રશ્નમાં એન્ટિબાયોટિકના પ્રકાર (સંશ્લેષિત vs અર્ધ-સંશ્લેષિત), કાર્યપદ્ધતિ (બેક્ટેરિયોસ્ટેટિક/બેક્ટેરીસાઇડ), અથવા ચોક્કસ દવાનું નામ પૂછવામાં આવે.
દા.ત.: ઓક્સાસિલિસિલિન — બેક્ટેરિયોસ્ટેટિક કે બેક્ટેરીસાઇડ? ઓક્સાસિલિસિલિનનો ઉપયોગ બેક્ટેરીયલ infection માટે થાય છે → બેક્ટેરીસાઇડ. જો ઓપ્શનમાં 'બેક્ટેરિયોસ્ટેટિક' અને 'બેક્ટેરીસાઇડ' બંને હોય, તો ઓક્સાસિલિસિલિનની ચયનાત્મક પ્રવૃત્તિ (selective toxicity) ધ્યાનમાં લેવੀ.
સાબુ અને ડિટર્જન્ટની મૂળભૂત રાસાયણિક રચનાની તુલના: સાબુ = RCOO⁻ Na⁺ (કાર્બોક્સિલેટ); ડિટર્જન્ટ = RSO₃⁻ Na⁺ (સલ્ફોનેટ). યાદ રાખો: 'બ' = 'B' = base/salt of carboxylic acid; 'સ' = 'S' = sulfonate. સાબુ કઠિન જળમાં અવરલ્પ (scum) આપે છે, ડિટર્જન્ટ આપતું નથી — આ મુખ્ય તફાવત છે.
જ્યારે પ્રશ્નમાં સાબુ/ડિટર્જન્ટની રચના, ઝાંખું પડવું (scum), અથવા કઠિન જળ સાથેની પ્રક્રિયા વિશે પૂછાય.
દા.ત.: નીચેનામાંથી કયું સાબુ છે? (a) sodium dodecylbenzene sulphonate (b) sodium dodecyl sulphate (c) sodium stearate (d) linear alkyl benzene sulphonate → સાબુ = સ્ટેરિક એસિડનું સોડિયમ لવણ (c) RCOO⁻Na⁺ પ્રકારનું.
દવાઓના શ્રેણીવાર વર્ગીકરણ માટે 'પ્રથમ અક્ષર/પ્રત્યય' ટેકનિક: 'મોફિન' / 'કોઇન' પ્રત્યય ધરાવતી દવાઓ (morphine, codeine) → opiate analgesics. 'સેલેક' / 'સાબ્લે' / 'નિબ' પ્રત્યયો (celecoxib, naproxen, ibuprofen) → NSAIDs (non-steroidal anti-inflammatory drugs). 'ઓલોલ' પ્રત્યય → beta-blockers (propranolol). 'સાલિલ' પ્રત્યય → salicylates (aspirin).
જ્યારે વિકલ્પોમાં અનેક દવાઓના નામો આપેલા હોય અને તેમનો પ્રકાર ઓળખવો હોય.
દા.ત.: નિકોલસ્ ફોન રીહેમના પ્રશ્ન: કોર્ટિસોન અને એસિટોવિન કયા વર્ગમાં? બંને સ્ટીરોઇડલ anti-inflammatory agent છે — કોર્ટિસોન એડ્રિનોકોર્ટિકોસ્ટીરોડ છે.
એન્ટીપાયેટિક (ઉણસ નીચે કરનારી દવા) = paracetamol (acetaminophen). એનલ્જેસિક (વેદનાશોક) = aspirin, ibuprofen. એન્ટિડિપ્રેસન્ટ = iproniazid, valium. સ્મોગ એક ધૂમ્રપાત્ર (smoke + fog) છે — SO₂ અને ozone વડે બનતું. આ તમામ મૂળભૂત મેચિંગ પ્રશ્નોમાં સીધા કામ આવે છે.
જ્યારે જોડકું બનાવવું હોય (match the following) અથવા ચોક્કસ દવાનું પર્યાવરણ/સક્રિયતા બતાવવું હોય.
દા.ત.: કયો ઍન્ટીપાયેટિક છે? (a) aspirin (b) paracetamol (c) phenacetin (d) both (b) and (c) → (d) — બંને એન્ટીપાયેટિક છે.
પોલીમરના monomer ને ઓળખવા માટે: Teflon (PTFE) = C₂F₄ (tetrafluoroethane). Bakelite = phenol + formaldehyde. Buna-S = butadiene + styrene. Buna-N = butadiene + acrylonitrile. Neoprene = chloroprene (2-chlorobutadiene). લાઇનર LDPE નું monomer = ethylene. વિસર્જ્ય (biodegradable) પોલીમર = PHBV (poly-β-hydroxybutyrate-co-β-hydroxyvalerate).
જ્યારે પોલીમરના monomer, પુનરાવર્તિત એકમ (repeating unit), અથવા પોલીમરાઇઝેશન પ્રકાર વિશે પ્રશ્ન આવે.
દા.ત.: PHBV એ વિસર્જ્ય પોલીમર છે. કયું મોનોમર જોડી સાચી છે? → 3-hydroxybutanoic acid + 3-hydroxypentanoic acid.
કૃત્રિમ મીઠાશ જનક પદાર્થો: સાકરોઝ કરતા 30–40 ગુણા મીઠો = saccharin (C₇H₅NO₃S); 180 ગુણા = aspartame (Diet Coke માં); 3000 ગુણા = sucralose; 10,000+ ગુણા = alitame. સ્વાસ્થ્ય ખતરો ઓછો = sucralose (સાકરોઝના 3 Cl અણુઓ સાથે બનેલું). બંધબેસતા મૂલ્યો યાદ રાખો.
જ્યારે મીઠાશનો ગુણોત્તર, સ્વાસ્થ્યપ્રદ વિકલ્પ, અથવા કોઈ ચોક્કસ કૃત્રિમ મીઠાશ જનક પદાર્થનું નામ પૂછાય.
દા.ત.: Aspartame વડે બનેલી મીઠાશ વાસ્તવિક પદાર્થો સાથે કયું બને છે? → phenylalanine + aspartic acid. Aspartame ગરમ કરતાં ખરાબ સ્વાદ આપે છે — આ property ધ્યાનમાં રાખવી.
એન્ઝાઇમ પ્રક્રિયાનો ઉદાહરણ: Enzyme + Substrate → ES Complex → Enzyme + Product. Enzyme નું નામ સબસ્ટ્રેટના નામ પરથી →ase પ્રત્યય સાથે બને છે (例: sucrase, urease, zymase). Denaturation → તાપમાન/એસિડથી બીજા આકાર ખોવાય, કાર્ય રોકાય. કો-ફેક્ટર (cofactor) = non-protein part. Coenzyme = organic cofactor (NAD⁺, FAD, Vitamins).
જ્યારે એન્ઝાઇમ પ્રક્રિયા, ઉદાહરણ, denaturation, અથવા cofactor/coenzyme વિશે પ્રશ્ન આવે.
દા.ત.: કોર્ડિઓટોનિક એજન્ટ કયા પ્રકારનું છે? → Digitalis (digoxin/digitoxin) — કાર્ડિયાક ગ્લાઇકોસાઇડ, dilated cardiomyopathy અને chronic heart failure માં ઉપયોગી.
ખાદ્ય પદાર્થોમાં ઉમેરવાતા રાસાયણિકો: Preservatives (રક્ષક) = Sodium metabisulphite, sodium benzoate, BHA, BHT. Antioxidants = BHA (butylated hydroxyanisole) + BHT (butylated hydroxytoluene). Both are phenolic antioxidants. Colouring agents = tartrazine (peeli), sunset yellow. એક્ટિવ ચાર્ક (activated charcoal) = વિષ નિવારણ (poison treatment), adsorption સિદ્ધાંત પર કામ કરે છે.
જ્યારે ખાદ્ય ઉત્પાદનોમાં ઉમેરવાતા પદાર્થોના કાર્ય, નામ અથવા ઉદાહરણો વિશે પ્રશ્ન આવે.
દા.ત.: CCl₄ (carbon tetrachloride) અને chloroform (CHCl₃) બંને કયા ઔદ્યોગિક ઉપયોગો ધરાવે છે? → CCl₄ = fire extinguisher (pyrene), CHCl₃ = anaesthetic. બંનેનો વિભેદન કરી શકાય.
સોડિયમ લેવાયલ્સ (lauryl sulphate) સામે સોડિયમ ડોડેસાઇલ બેનઝીન સલ્ફોનેટ — કલ્પના કરો: 'સોડિયમ ડોડેસાઇલ સલ્ફેટ' (SDS) = detergent type (સલ્ફેટ). 'બેનઝિન સલ્ફોનેટ' = commercial detergent (લેબલેડ). આપણી સાબુની મિથિલાઇઝેશન → સોપીફિકેશન પ્રક્રિયા: ચર્બી + NaOH → soap + glycerol. Detergents ની બનેલી પ્રક્રિયા: sulfonation + neutralisation.
જ્યારે detergent ના પ્રકાર (cationic, anionic, non-ionic), soap making reaction, અથવા સૂત્ર/પ્રક્રિયા પ્રકાર વિશે પ્રશ્ન આવે.
દા.ત.: Soap નું બંધારણ: hydrophilic head (–COO⁻Na⁺) + hydrophobic tail (કાર્બન શૃંખલા). Water માં micelle બનાવે છે. Hydrophobic part oil/dirt બાંધે, hydrophilic part water સાથે → dirt ધુલવાય.
બેઝોડિલીંગ એજન્ટ્સના મુખ્ય ઘટકો: Toothpaste = sodium fluoride (dental caries રોકે છે), mild abrasive (SiO₂/Al₂O₃), detergent (SLS), flavour. Shampoo = surfactant (lauryl alcohol + ethylene oxide), electrolyte (NaCl). Body lotion = emollient (moisturizer). યાદ રાખો: NaF → caries prevention. Ca₃(PO₄)₂ → tooth enamel (hydroxyapatite).
જ્યારે toiletries ના ઘટકો, તેમના કાર્યો અથવા પ્રકારો વિશે પ્રશ્ન આવે.
દા.ત.: કયું પદાર્થ dentifrice (દાતનો પાવડર/ટૂથપેસ્ટ) માં છે? (a) fluoride ion (b) trichlorophenol (c) hexachlorophene → (a) fluoride ion. Ca₃(PO₄)₂ + acid (bacteria from sugar) → tooth decay (demineralisation).
Smoking-related substances: Nicotine = opioid alkaloid (not really — it's a stimulant/alkaloid from tobacco), adds to addiction. CO (carbon monoxide) = reduces O₂ carrying capacity of blood (binds haemoglobin more strongly than O₂). Tar = carcinogenic polymeric material. યાદ રાખો: CO + Hb → carboxyhaemoglobin (stable, 200× stronger binding than O₂).
જ્યારે ધૂમ્રપાત્રના હાનિકારક પદાર્થો, તેમની કાર્યપદ્ધતિ અથવા લક્ષણો વિશે પ્રશ્ન આવે.
દા.ત.: કયું પદાર્થ બ્લડમાં O₂ vận送 ક્ષમતા ઘટાડે છે? → CO. કારણ: CO + Hb → HbCO (carboxyhaemoglobin), O₂ ની જગ્યા લે છે.
Antipyretic drugs — 'pyre' means heat. Paracetamol (acetaminophen) = both analgesic AND antipyretic. Aspirin = analgesic, antipyretic, anti-inflammatory. Ibuprofen = NSAID. એક દવા બે ગુણધર્મ ધરાવે છે તે ખાસ યાદ રાખો: paracetamol અને aspirin. એન્ટાસિડ: Tums = calcium carbonate, Antacid = aluminium hydroxide + magnesium hydroxide, Ranitidine = H₂ blocker, Omeprazole = proton pump inhibitor.
જ્યારે દવાના dual action, class અથવા mechanism વિશે પ્રશ્ન આવે.
દા.ત.: Which is NOT an antipyretic? (a) Paracetamol (b) Aspirin (c) Penicillin (d) Both (a) and (b) → (c) penicillin = antibiotic, not antipyretic.
પ્રોબાયોટિક્સ vs પ્રીબાયોટિક્સ: પ્રોબાયોટિક્સ = live bacteria (Lactobacillus) ਜੋ gut health maintain કરે. પ્રીબાયોટિક્સ = dietary fiber (indigestible carbs) જે probiotic bacteria ને feed કરે. Probiotics → gut flora balance, immunity. Prebiotics → fiber (fructooligosaccharides). યાદ રાખો: Probiotic = organism, Prebiotic = food.
જ્યારે digestive system સાથે સંબંધિત પ્રશ્ન આવે અથવા probiotic/prebiotic distinction પૂછાય.
દા.ત.: Acidophilus અને Bifidobacterium કયા વર્ગના પ્રોબાયોટિક્સ છે? → Lactic acid bacteria. Lactobacillus acidophilus → yogurt production, gut health.
એન્ટિમાઇક્રોબાયલ દવાઓના મુખ્ય પ્રકાર: Penicillins (penicillin G/V, ampicillin, amoxicillin) — β-lactam ring, cell wall synthesis block. Cephalosporins (cephalexin) — broader spectrum. Tetracyclines (tetracycline) — broad spectrum, inhibit protein synthesis. Macrolides (erythromycin) — protein synthesis inhibition. Sulphonamides (sulphonamides) — folic acid synthesis block. Quinolones (ciprofloxacin) — DNA gyrase inhibition.
જ્યારે antibiotic ના પ્રકાર, mechanism of action, અથવા specific drug classification વિશે પ્રશ્ન આવે.
દા.ત.: Penicillin G (benzylpenicillin) નું મોનોમર/structure કયું છે? → β-lactam ring containing, amino acid derived. Penicillin G naturally produced by Penicillium notatum.
સાર્વત્રિક ગણિત (Universal Math) ટ્રિક — વર્ગીકરણ: દવાઓના ચાર મુખ્ય શ્રેણીઓ — (1) Analgesics/Antipyretics (veदना/ઉષ્મા), (2) Antibiotics (બેક્ટેરિયા), (3) Tranquilizers/Hypnotics (man/stress), (4) Antiseptics/Disinfectants (surface). Har ek category ma che, naare real exam ma match the following type aapse. Har category nu ek example yaad rakho: Analgesic = aspirin, Antibiotic = penicillin, Tranquilizer = chlordiazepoxide, Antiseptic = Dettol (chloroxylenol).
જ્યારે દવાઓના વર્ગીકરણ વિશે વિશાળ પ્રશ્ન આવે અથવા multiple options માંથી સાચો વર્ગ પસંદ કરવો હોય.
દા.ત.: Tranquilizer નું ઉદાહરણ: (a) Aspirin (b) Paracetamol (c) Chlordiazepoxide (d) Penicillin → (c) chlordiazepoxide. Barbiturate-type tranquilizers → sleep inducers (hypnotics).
એન્ટીઓક્સિડન્ટ્સ અને ફ્રી રેડિકલ્સ: BHA અને BHT = phenolic antioxidants. Vitamin C (ascorbic acid) = પાણીમાં દ્રાવ્ય antioxidant. Vitamin E (tocopherol) = ચરબીમાં દ્રાવ્ય antioxidant. Free radicals (O₂⁻, •OH) = lipid peroxidation → cell damage. Antioxidants free radicals ને neutralize કરે છે. યાદ રાખો: Vitamin C/E = endogenous antioxidants, BHA/BHT = exogenous (food additives).
