તત્ત્વોના અલગીકરણના સામાન્ય સિદ્ધાંતો

પરિચય
ધાતુઓ તેમના અયસ્ક (ores) રૂપમાં પ્રકૃતિમાં મળી આવે છે.
અયસ્કમાં ધાતુ સલ્ફાઇડ, ઓક્સાઇડ, કાર્બોનેટ અથવા હેલાઇડ સ્વરૂપે હાજર હોય છે.
ધાતુ કાઢવાની પ્રક્રિયાને ધાતુકર્મ (Metallurgy) કહેવાય છે.
📝 GUJCETમાં આ પ્રકરણમાંથી પ્રશ્નો મુખ્યત્વે અયસ્ક, સાંદ્રણ અને નિકાલન પર આધારિત હોય છે.
અયસ્ક અને ખનિજ (Ores and Minerals)
ખનિજ: પ્રકૃતિમાં મળી આવતા પદાર્થ જેમાં ધાતુ અથવા તેના યૌગિકો હાજર હોય. ઉદા. હેમેટાઇટ (Fe₂O₃), બોક્સાઇટ (Al₂O₃·2H₂O).
અયસ્ક: જ્યારે ખનિજમાંથી ધાતુ કાઢવી આર્થિક રીતે લાભદાયી હોય ત્યારે તેને અયસ્ક કહેવાય.
ગેંગ (Gangue): અયસ્ક સાથે મળી આવતા અશુદ્ધિઓ જેમકે રેતી, મૃત્તિકા વગેરે.
હેમેટાઇટ: Fe₂O₃
બોક્સાઇટ: Al₂O₃·2H₂O
અયસ્કનું સાંદ્રણ (Concentration of Ore)
સાંદ્રણની પ્રક્રિયા દ્વારા ગેંગને અયસ્કમાંથી દૂર કરવામાં આવે છે.
સાંદ્રણની પદ્ધતિઓ: ૧. હાથ વડે પસંદગી (Hand Picking), ૨. ગુરુત્વ પૃથક્કરણ (Gravity Separation), ૩. ચુંબકીય પૃથક્કરણ (Magnetic Separation), ૪. ફીણ પ્લવન (Froth Flotation).
ફીણ પ્લવન પદ્ધતિ સલ્ફાઇડ અયસ્ક માટે વપરાય છે. ઉદા. ગેલેના (PbS), સ્ફેલેરાઇટ (ZnS).
📝 ફીણ પ્લવનમાં કોલેક્ટર (જેમકે પાઇન ઓઇલ) અને ફીણ સ્થિરક (Froth Stabilizer) વપરાય છે.
ફીણ પ્લવનમાં વપરાતી રાસાયણિક પ્રક્રિયા: R-SH + M²⁺ → (R-S)₂M (ધાતુ સલ્ફાઇડ કણો ફીણ સાથે જોડાય છે)
ધાતુનું નિકાલન (Extraction of Metal)
નિકાલનની પ્રક્રિયા દરમિયાન સાંદ્રિત અયસ્કમાંથી શુદ્ધ ધાતુ મેળવવામાં આવે છે.
નિકાલનની પદ્ધતિઓ: ૧. પિરોમેટલર્જી (Pyrometallurgy), ૨. હાઇડ્રોમેટલર્જી (Hydrometallurgy), ૩. ઇલેક્ટ્રોમેટલર્જી (Electrometallurgy).
પિરોમેટલર્જીમાં ઉચ્ચ તાપમાને રાસાયણિક પ્રક્રિયાઓ થાય છે.
પિરોમેટલર્જી (Pyrometallurgy)
આ પદ્ધતિમાં અયસ્કને ઉચ્ચ તાપમાને ગરમ કરીને ધાતુ મેળવવામાં આવે છે.
મુખ્ય પગલાં: ૧. ભર્જન (Roasting), ૨. ગલન (Smelting), ૩. નિષ્કર્ષણ (Refining).
ભર્જન (Roasting): 2ZnS + 3O₂ → 2ZnO + 2SO₂
ગલન (Smelting): ZnO + C → Zn + CO
ભર્જનમાં સલ્ફાઇડ અયસ્કને ઓક્સાઇડમાં રૂપાંતરિત કરવામાં આવે છે.
📝 ગલન પ્રક્રિયામાં કાર્બન અથવા કાર્બન મોનોક્સાઇડ વપરાય છે.
હાઇડ્રોમેટલર્જી (Hydrometallurgy)
આ પદ્ધતિમાં અયસ્કને પાણી અથવા અમ્લમાં ઓગાળીને ધાતુ મેળવવામાં આવે છે.
ઉદા. કોપરનું નિકાલન: Cu₂S + 2FeCl₃ → 2CuCl + 2FeCl₂ + S
કોપર નિકાલન: CuCl + Fe → Cu + FeCl₂
હાઇડ્રોમેટલર્જી મુખ્યત્વે ઓછા પ્રમાણમાં ધાતુ ધરાવતા અયસ્ક માટે વપરાય છે.
ઇલેક્ટ્રોમેટલર્જી (Electrometallurgy)
આ પદ્ધતિમાં વિદ્યુત પ્રવાહ દ્વારા ધાતુનું નિકાલન કરવામાં આવે છે.
ઉદા. એલ્યુમિનિયમનું નિકાલન (Hall-Héroult પ્રક્રિયા).
Hall-Héroult પ્રક્રિયા: 2Al₂O₃ + 3C → 4Al + 3CO₂ (વિદ્યુત વિભાજન દ્વારા)
એલ્યુમિનિયમના નિકાલનમાં ક્રાયોલાઇટ (Na₃AlF₆) વપરાય છે.
📝 ક્રાયોલાઇટ એલ્યુમિનિયમ ઓક્સાઇડનું ગલનબિંદુ ઘટાડે છે.
ધાતુનું શુદ્ધીકરણ (Refining of Metal)
શુદ્ધીકરણની પ્રક્રિયા દ્વારા અશુદ્ધ ધાતુમાંથી શુદ્ધ ધાતુ મેળવવામાં આવે છે.
પદ્ધતિઓ: ૧. વિસ્થાપન (Displacement), ૨. વિદ્યુત શુદ્ધીકરણ (Electrolytic Refining), ૩. વાસ્પ શુદ્ધીકરણ (Vapour Phase Refining).
વિદ્યુત શુદ્ધીકરણ: Cu (અશુદ્ધ) → Cu²⁺ + 2e⁻ (એનોડ), Cu²⁺ + 2e⁻ → Cu (શુદ્ધ) (કેથોડ)
વિદ્યુત શુદ્ધીકરણમાં એનોડ અશુદ્ધ ધાતુનો અને કેથોડ શુદ્ધ ધાતુનો હોય છે.
📝 વાસ્પ શુદ્ધીકરણમાં ધાતુને વાસ્પમાં રૂપાંતરિત કરીને શુદ્ધ કરવામાં આવે છે. ઉદા. નિકલ (Mond પ્રક્રિયા).
Mond પ્રક્રિયા: Ni + 4CO → Ni(CO)₄ (330-350K), Ni(CO)₄ → Ni + 4CO (450-470K)
ધાતુકર્મમાં ઊર્જાનો ખર્ચ (Energy Considerations in Metallurgy)
ધાતુકર્મની પ્રક્રિયાઓ ઊર્જા-ગહન હોય છે.
ઊર્જાનો ખર્ચ ઘટાડવા માટે નીચેની પદ્ધતિઓ વપરાય છે: ૧. ઉચ્ચ તાપમાને પ્રક્રિયા, ૨. ઉત્કલન બિંદુ ઓછું કરવા માટે યોગ્ય દ્રાવકો, ૩. કેટલિક રીતે પ્રક્રિયા.
ઇલેક્ટ્રોલાઇસિસમાં વિદ્યુત ઊર્જાનો ખર્ચ મહત્વનો ભાગ ભજવે છે.
ધાતુકર્મ અને પર્યાવરણ (Metallurgy and Environment)
ધાતુકર્મની પ્રક્રિયાઓ પર્યાવરણ પર નકારાત્મક અસર કરે છે.
પર્યાવરણીય અસરો: ૧. હવામાં SO₂નું ઉત્સર્જન, ૨. પાણીનું પ્રદૂષણ, ૩. જમીનનું પ્રદૂષણ.
SO₂ને નિયંત્રિત કરવા માટે સ્ક્રબર (Scrubber) વપરાય છે.
📝 GUJCETમાં પર્યાવરણીય પ્રશ્નો પર ધ્યાન આપો.
મહત્વના ઉદાહરણો
લોખંડનું નિકાલન: હેમેટાઇટ (Fe₂O₃) → બ્લાસ્ટ ફર્નેસ → લોખંડ (Pig Iron).
બ્લાસ્ટ ફર્નેસ પ્રક્રિયા: Fe₂O₃ + 3CO → 2Fe + 3CO₂
એલ્યુમિનિયમનું નિકાલન: બોક્સાઇટ → બેયર પ્રક્રિયા → એલ્યુમિના (Al₂O₃) → Hall-Héroult પ્રક્રિયા → એલ્યુમિનિયમ.
બેયર પ્રક્રિયામાં સોડિયમ હાઇડ્રોક્સાઇડ (NaOH) વપરાય છે.
📝 બેયર પ્રક્રિયા: Al₂O₃·2H₂O + 2NaOH → 2NaAlO₂ + 3H₂O
