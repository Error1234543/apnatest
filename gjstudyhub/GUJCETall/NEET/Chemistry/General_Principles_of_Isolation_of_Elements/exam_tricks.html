🎯 પરીક્ષા ટ્રિક્સ

ખનિજ vs અયસ્ક — ફક્ત બે શબ્દ યાદ રાખો: ખનિજ = ધરતીમાંથી મળતું કોઈ પણ પ્રકારનું પદાર્થ; અયસ્ક = તે ખનિજનું એવું રૂપ જેમાંથી મૂલદ્રવ્ય સસ્તામાં-સસ્તું કઢાવી શકાય.
જ્યારે પ્રશ્ન પૂછે કે 'યોગ્ય અયસ્ક કયું?' અથવા ખનિજ/અયસ્ક વચ્ચેનો તફાવત પૂછાય.
દા.ત.: બોક્સાઇટ Al₂O₃·2H₂O એ એલ્યુમિનિયમનું અયસ્ક છે કારણ કે તેમાં Al નું પ્રમાણ ઊંચું છે અને તેમાંથી સરળતાથી Al કઢાવવાય છે.
સંચાયન પદ્ધતિઓ ચાર ગુણધર્મ પર આધારિત છે — ચુંબકીયતા, ભેજપ્રેમતા (હાઇડ્રોફોબિક/હાઇડ્રોફિલિક), દ્રઢતા (ઘનતા), અને રસાયણિક પ્રક્રિયાશીલતા. જે ગુણધર્મ સૂર્યમાં આવે તે જ પદ્ધતિ યાદ રાખો.
જ્યારે પ્રશ્નમાં 'કયો અયસ્ક કઈ પદ્ધતિથી સંચાયિત થાય?' પૂછવામાં આવે.
દા.ત.: ચુંબકીય અયસ્ક → ચુંબકીય પૃથક્કરણ (મેગ્નેટિક સેપરેશન); તાંબાનું પાયરાઇટ (CuFeS₂) → ફ્રૉથ ફ્લોટેશન (હેટ્રોજિનસ કોલેક્ટર વડે); લેટરિટ → રાસાયણિક નિષ્કર્ષણ (લીચિંગ).
કાલ્સિનેશન (calcination) = 'કાંતો' → તાપન જેમાં O₂ નથી; રોસ્ટિંગ (roasting) = 'સલ્ફાઇડ અયસ્કનું સળગાવવું' → O₂ ની હાજરીમાં. યાદ રાખો: ROAST = Roast in Oxygen!
જ્યારે પ્રશ્ન કહે 'ઉષ્માપ્રભાવનું પ્રકાર કયું છે?' અથવા કોઈ પ્રક્રિયા સમીકરણ બતાવે.
દા.ત.: ZnS ને હવામાં ઉષ્ણ કરવું = રોસ્ટિંગ (ZnS + O₂ → ZnO + SO₂); CaCO₃ ને O₂ વિના ગરમ કરવું = કાલ્સિનેશન (CaCO₃ → CaO + CO₂).
એલિંગહામ ડાયાગ્રામ (Ellingham diagram) માં ΔG ની ગ્રાફ રેખાની ઢાળ = –ΔS. જ્યાં ગ્રાફ નીચે હોય ત્યાં ઓક્સાઇડ વધુ સ્થિર. બે રેખાઓના છેદબિંદુ પર T = ΔH/ΔS — આ તાપમાને O₂ નો દબાણ 1 atm થાય.
જ્યારે પ્રશ્નમાં કોઈ ધાતુ-ક્ષારક (reducing agent) અન્ય ધાતુના ઓક્સાઇડને પ્રતિક્રિયાથી બાહરી કરી શકે છે કે નહીં તે પૂછે.
દા.ત.: C (ગ્રેફાઇટ) ની રેખા 2000 K થી ઉપર Mg ની રેખાની નીચે છે, તેથી 2000 K થી ઉપર C, MgO ને C કરી શકે. પણ સોનેરી અને ચાંદીની રેખા ખૂબ નીચે — તે ઓક્સાઇડ ટૂંકા સમયમાં સળગાવવાથી પણ તૂટતા નથી.
Hall–Heroult પ્રક્રિયા: Al₂O₃ ને 1200°C પર સંદ્રવિત કરવા માટે Cryolite (Na₃AlF₆) ઉમેરો છે. Cryolite → (1) ગલનબિંદુ ઘટાડે (2) વાહકતા વધારે. એનોડ (graphite) જરૂરી છે અને એનોડ ખપતો છે: C + O₂ → CO₂. ધ્રુવ (cathode) = તળિયું (ભસ્મા).
જ્યારે પ્રશ્નમાં એલ્યુમિનિયમ ઉત્પાદન પ્રક્રિયા, ઉપયોગમાં લેવાતું મધ્યસ્થ પદાર્થ, કે ઇલેક્ટ્રોડ સામગ્રી પૂછે.
દા.ત.: GUJCET માં પૂછે: 'Al₂O₃ નું વિદ્યુતવિભાજન કરવામાં ક્રાયોલાઇટ શા માટે ઉમેરે?' જવાબ: 'ગલનબિંદુ ઘટાડવા અને વિદ્યુત વાહકતા વધારવા.'
Zone refining (Zone અનુવર્તન સફાઈ) માટેના તત્વો પસંદ કરો જેના ઓગળેલા રૂપમાં અશુદ્ધિઓ વધુ દ્રાવ્ય હોય અને ઠોસ રૂપમાં ઓછી દ્રાવ્ય હોય — જેમ કે Ge, Si, B, Ga. યાદ રાખો: 'Z' = સંપૂર્ણ શુદ્ધતા (Semiconductor-grade metals).
જ્યારે પ્રશ્નમાં કોઈ તત્વને પરમાણુ-શુદ્ધ (ultra-pure) કરવા માટેની પદ્ધતિ પૂછે.
દા.ત.: Germanium ને પરમાણુ-શુદ્ધ કરવા માટે zone refining વપરાય છે. જર્મેનિયમનો ઓગળતો બિંદુ ~938°C અને અશુદ્ધિઓ (As, Sb, Ga) ઓગળેલા ભાગમાં વધુ દ્રાવ્ય હોય છે.
Mond પ્રક્રિયા = Ni સાથે CO; વેન આર્કેલ પ્રક્રિયા = Zr/Ti સાથે I₂. બંનેમાં 'વરાળ તબક્કાનું શુદ્ધિકરણ' (vapour phase refining) — ધાતુને વરાળમાં ફેરવો, તે વરાળને પૃથક્કરણ કરો, fir વાપસી કરો.
જ્યારે પ્રશ્નમાં કોઈ ધાતુનું શુદ્ધિકરણ પદ્ધતિ પૂછે કે નામથી પદ્ધતિ ઓળખવી હોય.
દા.ત.: Ni + 4CO → Ni(CO)₄ (400 K); Ni(CO)₄ → Ni + 4CO (500 K). Zr + 2I₂ → ZrI₄ (1800 K), ZrI₄ → Zr + 2I₂ (2500 K).
Blast furnace (ફુલ્લી ભઠ્ઠી) માં ઇસ્પાત બનવાની પ્રક્રિયાઓ ત્રણ પ્રદેશોમાં થાય: ઉપરનો ભાગ (~500–800 K): Fe₂O₃ → Fe₃O₄ → FeO (CO વડે અવરોધન); મધ્યમ ભાગ (~900–1500 K): FeO → Fe; નીચનો ભાગ (~1500 K): સિમેન્ટ (slag) બનવું. યાદ રાખો: 'ઉપર = ઓક્સાઇડ ઓછું; નીચે = ઓગળેલું.'
જ્યારે પ્રશ્નમાં ભઠ્ઠીના તાપમાન અને પ્રક્રિયાઓની વિગતો પૂછે.
દા.ત.: Blast furnace માં થતી મુખ્ય પ્રક્રિયા: C + O₂ → CO₂ (ઉષ્મા); CO₂ + C → 2CO; Fe₂O₃ + 3CO → 2Fe + 3CO₂.
વાયુપ્રક્રિયા (Leaching) માટે ત્રણ મુખ્ય ઉદાહરણો: (1) બોક્સાઇટ + NaOH (સંયુક્ત) → NaAlO₂; (2) સોનું + NaCN/O₂ → Na[Au(CN)₂]; (3) યુરેનિયમ + H₂SO₄/HNO₃ → UO₂²⁺. યાદ રાખો: 'Leach = લીચર = બાહ્ય દ્રાવકમાં ઓગળે.'
જ્યારે પ્રશ્નમાં કોઈ અયસ્કનું રાસાયણિક નિષ્કર્ષણ અથવા લીચિંગ પ્રક્રિયા પૂછે.
દા.ત.: બોક્સાઇટ (Al₂O₃·2H₂O) + 2NaOH + 3H₂O → 2Na[Al(OH)₄] (સોડિયમ હાઇડ્રોકસાઇડ વડે લીચિંગ).
ધાતુનો પ્રતિક્રિયાશીલતા ક્રમ યાદ રાખો: K > Na > Ca > Mg > Al > Zn > Fe > Pb > H > Cu > Ag > Au. જે ધાતુ H થી ઊંચે છે તેનું ઓક્સાઇડ સીધું ઉષ્માપ્રભાવથી ન તૂટે — તેને વિદ્યુતવિભાજન અથવા પ્રબળ ક્ષારકથી રિડક્શન કરવું પડે.
જ્યારે પ્રશ્નમાં કોઈ ધાતુ કેવી રીતે મુક્ત કરવામાં આવે છે તે પૂછે.
દા.ત.: Au (સોનું) કુદરતી અવસ્થામાં મળે છે (મુક્ત ધાતુ); Mg (ઉચ્ચ પ્રતિક્રિયાશીલ) વિદ્યુતવિભાજનથી મળે; Fe (મધ્યમ) અવરોધનથી મળે.
Ellingham ડાયાગ્રામમાં C → CO વાળી રેખા નીચે દોરે છે (ΔG ઋણ બને છે), તેથી C એ ઘણા ઓક્સાઇડનું અવરોધન કરી શકે છે. પણ C → CO₂ રેખા ઉપરની બાજુ છે, તેથી ઉચ્ચ તાપમાને C → CO જ પ્રબળ ક્ષારક બને છે.
જ્યારે પ્રશ્નમાં 'કયો ક્ષારક ઓક્સાઇડ અવરોધિત કરી શકે?' એવો પ્રશ્ન આવે.
દા.ત.: 2MgO → 2Mg + O₂ (ΔG ધન), પરંતુ 2MgO + C → 2Mg + CO₂ (ઉચ્ચ T પર યોગ્ય) — પ્રાયોગિક રીતે 2000°C+ પર C, MgO નું અવરોધન કરે છે.
સ્લૅગ (Slag) હંમેશા CaSiO₃ (કેલ્શિયમ સિલિકેટ) હોય છે — એટલે કે Silica (SiO₂, અશુદ્ધિ) + Quicklime (CaO, ફ્લક્સ) → CaSiO₃. Blastic furnace માં CaO બાસ્ત્રણમાંથી આવે છે.
જ્યારે પ્રશ્નમાં સ્લૅગનું રસાયન અથવા બ્લાસ્ટ ફર્નેસમાં ફ્લક્સનું કામ પૂછે.
દા.ત.: ગેલેના (PbS) ના રોસ્ટિંગ પછી ફ્લક્સ તરીકે CaO ઉમેરવામાં આવે છે → CaSiO₃ (સ્લૅગ) બને છે, જે હળવું હોવાથી ઓગળેલા લોહાની ઉપર તરતું રહે છે અને દૂર થાય છે.
ફ્રૉથ ફ્લોટેશન (Froth floatation) માં સંપાદક (collector, જેમ કે પોટાશિયમ એથાઇલક્સાઇલ ક્ષાર / પિનોલ) અયસ્ક સપાટી પર જમા થાય છે અને હવાના ફુગ્ગા સાથે ઉપર આવે છે. અવરોધક (depressant, જેમ કે NaCN) એ અન્ય અયસ્કને નીચે રાખે છે.
જ્યારે પ્રશ્નમાં ફ્લોટેશનની ક્રિયાવિધિ અથવા depressant/collector નું કાર્ય પૂછે.
દા.ત.: PbS અને ZnS ના મિશ્રણમાં ZnS ને NaCN વડે depress કરવામાં આવે છે (ZnS ની સપાટી પર CN⁻ આગળ આવે છે), પરંતુ PbS સપાટી પર કોલેક્ટર વડે ઉપર આવે છે.
વિદ્યુતરસાયણિક (Electrometallurgy) માં ધ્રુવ (cathode) પર ધાતુ જમા થાય છે; એનોડ (anode) ઓગળે છે અથવા O₂/Cl₂ મુક્ત થાય છે. Al વીજળીની ઘણી જરૂર છે (~15 kWh/kg) — તેનો ખર્ચ મોટો છે.
જ્યારે વિદ્યુતવિભાજન પ્રક્રિયાના ઇલેક્ટ્રોડ અથવા ઉર્જા ખર્ચ સંબંધિત પ્રશ્ન આવે.
દા.ત.: Hall–Heroult પ્રક્રિયા: Cathode (ભસ્મા) પર: Al³⁺ + 3e⁻ → Al(l); Anode (ગ્રેફાઇટ) પર: 2O²⁻ → O₂ + 4e⁻, અને C + O₂ → CO₂.
અયસ્કમાંથી અશુદ્ધિ દૂર કરવાની પદ્ધતિઓ નીચે મુજબ યાદ રાખો: — હાઇડ્રોલિક સેપરેશન (વેગમિતિય ભિન્નતા) → ઘનતા પ્રમાણે; — માગ્નેટિક → ચુંબકીય ગુણધર્મ પ્રમાણે; — ફ્રૉથ ફ્લોટેશન → જલદ્રઢતા પ્રમાણે; — લીચિંગ → રસાયણિક દ્રાવ્યતા પ્રમાણે.
જ્યારે પ્રશ્નમાં વિવિધ સંચાયન પદ્ધતિઓ અને તેમનો આધાર પૂછે.
દા.ત.: તાંબાના પાયરાઇટ (CuFeS₂) ને ફ્રૉથ ફ્લોટેશન વડે સંચાત કરવામાં આવે છે કારણ કે CuFeS₂ હાઇડ્રોફોબિક હોય છે અને હવાના ફુગ્ગા સાથે ઉપર આવે છે.
