p-બ્લોક તત્વો (GUJCET)

🧪 GUJCET — Gujarati • Chemistry • p-Block Elements

પ્રાવસ્તા : p-બ્લોક તત્વો
આધુનિક આવર્ત કોષ્ટકમાં સમૂહ 13 થી 18ના તત્વોને p-બ્લોક તત્વો કહે છે.
સામાન્ય બાહ્યતમ ઇલેક્ટ્રોનિક વિન્યાસ : ns² np¹ થી ns² np⁶
p-બ્લોકમાં ધાતુઓ, અધાતુઓ અને ઉભયગુણી (amphoteric) તત્વો ત્રણેય જાતનાં હોય છે.
સમૂહ 13 : ભાર (Boron group), સમૂહ 14 : કાર્બન સમૂહ, સમૂહ 15 : નાઇટ્રોજન સમૂહ
સમૂહ 16 : ઑક્સિજન સમૂહ, સમૂહ 17 : અલ્ગેન (Halogen) સમૂહ, સમૂહ 18 : નિષ્ક્રિય વાયુઓ
📝 GUJCET માં સમૂહ 13,14,15,17ના રાસાયણિક ગુણો પર ઘણા પ્રશ્નો આવે છે.
સમૂહ 13 : ભાર સમૂહ (B, Al, Ga, In, Tl)
બાહ્યતમ ઇલેક્ટ્રોનિક વિન્યાસ : ns² np¹
સામાન્ય ઑક્સિડેશન અવસ્થા : +3; બોરોન ઉપરાંત બધાં તત્વો ધાતુ છે.
ઇલેક્ટ્રોનિક વિન્યાસ બે મુખ્ય વ્યયતિ : Tl⁺ +3 કરતાં વધુ સ્થાયી (inert pair effect).
B: 1s² 2s² 2p¹ | Al: [Ne] 3s² 3p¹
આયનીકરણ ઉર્જા (IE) : B > Al < Ga > In < Tl
આઇનર્ટ પેર અસર (Inert Pair Effect)Tl માટે +1 અવસ્થા વધુ સ્થાયી
B₂O₃ + 3Mg → 2B + 3MgO (મેગ્નેશિયમથી B મુક્ત કરવાની પ્રક્રિયા)
આલુમિનિયમ (Al) : duralumin (Cu+Al) એ જર્મન સિલ્વર (Nickel silver).
બોરેક્સ (Na₂B₄O₇·10H₂O) નું ઉત્તાપ વિઘટન : NaBO₃ + B₂O₃ મળે છે.
Na₂B₄O₇·10H₂O --Δ--> 2NaBO₃ + 4B₂O₃ + 10H₂O
બોરોનનું લાક્ષણિક અદ્ભુત જોડાણ (Catenation) ઓછું છે.
BF₃ + NH₃ → F₃B←NH₃ (લ્યુઇસ એસિડ-બેઝ સંકુલ)
BF₃ માં B ત્રિપરમાણ્વિક (trigonal planar) છે — sp² સંકરણ.
2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑
📝 Al તત્વ ઉદ્દીપક ક્રિયા શોધનારા : ફ્રિટ્ઝ હેબર (રાસાયણિક ઐતિહાસિક ગૌરવ).
સમૂહ 14 : કાર્બન સમૂહ (C, Si, Ge, Sn, Pb)
બાહ્યતમ ઇલેક્ટ્રોનિક વિન્યાસ : ns² np² (4 જેવાં યોગ્ય તત્વો)
સામાન્ય ઑક્સિડેશન અવસ્થાઓ : +4 અને +2
અદ્ભુત જોડાણ (Catenation) નું પ્રબળતમ તત્વ : C > Si > Ge
C ના સ્ફટિક : વજ્ર (Diamond), ગ્રાફાઇટ; બિન-સ્ફટિક : કોક, ચાર્કલ
C(વજ્ર) --અચ્છા---> C(ગ્રાફાઇટ) (ઉચ્ચ દબાણે રૂપાંતર)
વાસ્તવિક રચના : ગ્રાફાઇટમાં sp², વજ્રમાં sp³ સંકરણ.
CaCO₃ --Δ--> CaO + CO₂ (શિલાખંડ ઉષ્મા વિઘટન)
Si (સિલિકોન) : [Ne] 3s² 3p² — સિલિકેટ રાસાયણીય ઉદ્યોગનો પાયો
SiO₂ + 2C --ઉચ્ચΔ--> Si + 2CO (ઉત્પાદન પદ્ધતિ)
સિલિકેટ અણુઓની મૂળભૂત એકમ : SiO₄⁴⁻ (ટેટ્રાહેડ્રલ)
સિલિકોનનું મહત્વ : સિલિકોન ચિપ્સ, સિમેન્ટ, કાચ, સિલિકોન્સ.
Si + 2Cl₂ --300°C--> SiCl₄
SiCl₄ + 4CH₃Cl --Cu---> (CH₃)₄Si (ગ્રીન્ડيار્ડ પ્રક્રિયા)
Sn (ટાઈન), Pb (લીડ) : +2 અવસ્થા વધુ સ્થાયી (ઇલેક્ટ્રોનયુગલ અસર)
PbO₂ + 4HCl(વા.) --> PbCl₂ + Cl₂ + 2H₂O
PbO₂ પ્રબળ ઑક્સિડાઇ징 એજન્ટ છે (PbCl₂ બનાવે છે).
📝 Si–O બંધ એ સૌથી મજબૂત એકલ બંધોમાંનો એક છે.
સમૂહ 15 : નાઇટ્રોજન સમૂહ (N, P, As, Sb, Bi)
બાહ્યતમ ઇલેક્ટ્રોનિક વિન્યાસ : ns² np³
નાઇટ્રોજન (N) દ્વિપરમાણ્વીય વાયુ N₂ એ વાતાવરણમાં 78% છે.
N₂ + 3H₂ ⇌ 2NH₃ --ΔH = –ve (હેબર પ્રક્રિયા)
N₂ માં N≡N ત્રિબંધ (બંધ ઉર્જા ≈ 941 kJ/mol) — અત્યંત સ્થાયી
3Mg + N₂ --Δ--> Mg₃N₂ (મેગ્નેશિયમનાઇટ્રાઇડ)
Mg₃N₂ + 6H₂O --> 3Mg(OH)₂ + 2NH₃
NH₃ નું સંકુલ લવણ બનાવે છે : [Cu(NH₃)₄]²⁺ (ગાઢ नीலો રંગ)
Cu²⁺ + 4NH₃ → [Cu(NH₃)₄]²⁺
📝 Ostwald પ્રક્રિયા : NH₃ → HNO₃ (ઉદ્યોગકારી તૈયારી).
4NH₃ + 5O₂ --Pt/Rh--> 4NO + 6H₂O
P ના સ્વરૂપો : શ્વેત Phosphorus (P₄), રક્તફેર Phosphorus
શ્વેત P₄ અસ્થિર, સ્વયંસ્ફુરણશીલ — પાણીમાં રાખવું જરૂરી.
P₄ + 5O₂ --> P₄O₁₀
H₃PO₄ (ફૉસ્ફોરિક અમ્લ) : ત્રિબળીય (tribasic) ; H₃PO₃ : દ્વિબળીય
📝 N એ ઓછામાં ઓછો પ્રવાહી તાપમાન ધરાવતું તત્વ નથી.
સમૂહ 16 : ઑક્સિજન સમૂહ (O, S, Se, Te, Po)
બાહ્યતમ ઇલેક્ટ્રોનિક વિન્યાસ : ns² np⁴
સામાન્ય ઑક્સિડેશન અવસ્થા : –2, +2, +4, +6
ઑક્સિજન (O) : વાયુ, S, Se, Te : અધાતુઓ, Po : ત્રાડી
S₈ (સામાન્ય સ્વરૂપ — રિંગ રચના)
SO₂ નું ઉત્પાદન : S + O₂ --> SO₂
2SO₂ + O₂ --V₂O₅--> 2SO₃ (કોન્ટેક્ટ પ્રક્રિયા)
H₂SO₄ નું ઉદ્યોગી ઉત્પાદન : કોન્ટેક્ટ પ્રક્રિયા dwára
SO₃ + H₂O --> H₂SO₄ (મળતું નથી, પ્રત્યક્ષ રીતે)
Ozone (O₃) : ઝાંખી વાદળી વાયુ, અસ્થિર, પ્રબળ ઑક્સિડાઇઝર
3O₂ --UV--> 2O₃
📝 O₃ ઓઝોન સ্তર સૂર્યના બધા જ UV કિરણોને શોષે છે.
PbO₂ + H₂SO₄ + H₂O₂ --> PbSO₄ + 2H₂O + O₂ (સંદર્ભ પ્રક્રિયા)
S ના સ્વરૂપો : એલ્ફા–S (મેગનમાઇટ), બીટા–S (રોમ્બિક).
સમૂહ 17 : હેલોજન (F, Cl, Br, I, At)
બાહ્યતમ ઇલેક્ટ્રોનિક વિન્યાસ : ns² np⁵
હેલોજન (Halogen) એટલે 'લવણ બનાવનારા' તત્વો
દ્રવ્યમાન ગુણધર્મ : F₂ < Cl₂ < Br₂ < I₂ (ક્વોન્ટમ જવાબદારી)
સૌથી વધુ ઇલેક્ટ્રોનઋણતા : F > O > Cl
2NaCl + MnO₂ + 2H₂SO₄ --> MnSO₄ + 2NaHSO₄ + Cl₂↑
ડિન્કણી (Deacon) પ્રક્રિયા : 4HCl + O₂ --CuCl₂/Δ--> 2Cl₂ + 2H₂O
Cl₂ + H₂O ⇌ HCl + HOCl (પ્રકાશમાં વેગવંધHOCl વિઘટન)
P₄ + 6Cl₂ --> 4PCl₃ | P₄ + 10Cl₂ --> 4PCl₅
HX ના બળ : HF > HCl > HBr > HI (બાષ્પીભવન બિંદુ અનુસાર)
📝 F₂ નું રાસાયણિક સક્રિયતમ હેલોજન છે — સ્ફટિક સંયોજનોમાં જોવા મળે.
AgNO₃ + NaCl --> AgCl↓ (શ્વેત અવક્ષેપ) + NaNO₃
AgCl પ્રકાશમાં કાળું પડે છે : AgCl → Ag + Cl₂
સમૂહ 18 : નિષ્ક્રિય વાયુઓ (He, Ne, Ar, Kr, Xe, Rn)
બાહ્યતમ ઇલેક્ટ્રોનિક વિન્યાસ : ns² np⁶ (He માત્ર 1s²)
અત્યંત સ્થાયી — ઇલેક્ટ્રોનઋણતા 0, આયનીકરણ ઉર્જા उच्च
એવોડેટ (Avogadro) નો મુળ નિયમ : સમાન તાપ/દબાણે સમાન કદમાં સમાણુ અણુઓ
Xe + PtF₆ --> Xe⁺[PtF₆]⁻ (બાર્ટલેટનું સંયોજન, 1962)
નિષ્ક્રિય વાયુઓનાં સંયોજનો : XeF₂, XeF₄, XeF₆, XeO₃
📝 નિષ્ક્રિય વાયુઓમાંથી He સૌથી ઓછું ક્વોન્ટમ બિંદુ ધરાવે છે.
XeF₄ + 2H₂O --> Xe + O₂ + 4HF
નોનમેટલિસિટીનો ક્રમ : F > O > N > Cl > Br...
p-બ્લોક તત્વોના સામાન્ય ગુણધર્મો
પરમાણ્વીય ત્રિજ્યા : સમૂહમાં ઉપરથી નીચે વધે છે
આયનીકરણ ઉર્જા : ડાબેથી જમણે વધે છે (સમૂહમાં ઉપર→નીચે ઘટે છે)
ઇલેક્ટ્રોનઋણતા (Electronegativity) : F > O > N ≈ Cl > Br
આયનીકરણ ઉર્જા બાધા : B < Be, N > O, О < F (અસામાન્ય વલણ)
સમૂહ 13–18 માં ધાતુઓ, અધાતુઓ, ઉભયગુણી તત્વોનો સમાવેશ થાય છે
📝 GUJCET માં ઇલેક્ટ્રોનઋણતા, આય.ઉ.જ. અને પ્રમાણક્રમનો ક્રમ ઘણો આવે છે.
સમૂહ 13 માં B અધાતુ, Al/Ga/In/Tl ધાતુઓ
સમૂહ 14 માં C, Si અધાતુ; Ge સેમિમેટલ; Sn,Pb ધાતુ
બોરોન (B) એ સૌથી ઓછી વીજ ધનતા ધરાવતું તત્વ નથી — તે અધાતુ છે.
