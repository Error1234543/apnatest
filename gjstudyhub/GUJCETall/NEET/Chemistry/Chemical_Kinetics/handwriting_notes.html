રસાયણ ગતિશાસ્ત્ર (Chemical Kinetics)

🧪 GUJCET — Gujarati • Chemistry • Chemical Kinetics

રસાયણ ગતિશાસ્ત્ર — પરિચય
જડિત ભૌમિતિકી (Thermodynamics) માં આપણે જોઈએ છીએ કે પ્રક્રિયા થાય છે કે નહીં — પણ તે કેટલા વેગથી થાય છે તે જોવાતું નથી.
રસાયણ ગતિશાસ્ત્ર એટલે રાસાયણિક પ્રક્રિયાઓના વેગ અને તેમને પ્રભાવિત કરતા પરિબળોનું અભ્યાસ.
🔑 યાદ રાખો: સંતુલન ભૌમિતિકી કહે છે કે પ્રક્રિયા શક્ય છે કે નહીં; ગતિશાસ્ત્ર કહે છે કે કેટલી ઝડપથી?
📝 ✨ GUJCET ટિપ: પડછાયા પ્રશ્નોમાં 'વેગ' અને 'સંતુલન' વચ્ચેનો તફાવત પૂછાય છે.
પ્રક્રિયા વેગ (Rate of Reaction)
રાસાયણિક પ્રક્રિયા દરમિયાન કોઈ પણ પ્રતિકારક અથવા ઉત્પાદનની સાંદ્રતામાં થતા ફેરફારનો દર — તેને પ્રક્રિયા વેગ કહે છે.
સરેરાશ વેગ = −Δ[પ્રતિકારક]/Δt = +Δ[ઉત્પાદન]/Δt
પ્રતિકારકની સાંદ્રતા સમય સાથે ઘટે છે, તેથી ઋણ ચિન્હ લાગુ પડે છે; ઉત્પાદનની સાંદ્રતા વધે છે તેથી ધન ચિન્હ.
વેગના એકમો: mol L⁻¹ s⁻¹ (અથવા M s⁻¹).
🔑 પ્રક્રિયા વેગ ≠ પ્રક્રિયાનો દર અચળાંક. વેગ સાંદ્રતા પર આધારિત છે, અચળાંક નહીં.
📝 ⚡ સૂક્ષ્મ: v = −d[A]/dt = −½d[B]/dt = d[C]/dt (સાધારણ પ્રક્રિયા aA + bB → cC માટે)
સરેરાશ વેગ અને તત્કાલીન વેગ
સરેરાશ વેગ = nિશ્ચિત સમય અંતરાલમાં સાંદ્રતામાં થયેલ કુલ ફેરફાર ÷ સમય અંતરાલ.
v_સરેરાશ = −(C₂ − C₁)/(t₂ − t₁)
તત્કાલીન વેગ એટલે t સમયે પ્રતિક્ષણે થતો વેગ — gફંક્શનના સ્પર્શકની ઢાળ તરીકે મળે છે.
v_તત્કાલીન = −d[A]/dt (t = t₁ પર)
🔑 વક્ર-સમય આલેખ પર તત્કાલીન વેગ એ સ્પર્શકની ઢાળ છે.
સમય બદલાતો જાય છે →પ્રક્રિયા વેગ ધીમો પડતો જાય છે (કારણ કે સાંદ્રતા ઘટે છે)
📝 ✏️ ગ્રાફિકલ પ્રશ્નોમાં સ્પર્શક દોરી ઢાળ શોધવાનો ખૂબ મહત્વ.
પ્રક્રિયા વેગને પ્રભાવિત કરતા પરિબળો
① પ્રતિકારકની સાંદ્રતા — સાંદ્રતા વધે → વેગ વધે.
② તાપમાન — તાપમાન ૧૦°C વધે → વેગ લગભગ બમણો થાય (વિશ્વવ્યાપી નિયમ).
③ ઉત્પ્રેરક (Catalyst) — સક્રિયકરણ ઊર્જા ઘટાડે → વેગ વધે; ઉત્પ્રેરક स्वयં અપરિવર્તિત રહે છે.
④ પ્રકાશની ઉપસ્થિતિ — પ્રકાશ-રાસાયણિક પ્રક્રિયાઓ (દ.ત., હાઈડ્રોજન–ક્લોરીન).
⑤ પ્રતિકારકની પ્રકૃતિ — આયનીય પ્રક્રિયાઓ ખૂબ ઝડપી; સહસંયોજક બંધ તૂટવાની પ્રક્રિયા ધીमी.
⑥ ઘન પ્રતિકારકનું કણ કદ / પૃષ્ઠફળ — પૃષ્ઠફળ વધે (બારીક ચૂર્ણ) → વેગ વધે.
🔑 તાપમાન અને ઉત્પ્રેરક બે સૌથી મહત્વના પરિબળો છે જે GUJCET માં અકસ્માતે પૂછાય છે.
📝 ⚡ યાદ રાખો: દબાણ ઘન/ઝઝવિક પ્રક્રિયામાં વેગને અસર કરતું નથી (કેવળ વાયુ પ્રક્રિયાઓમાં સાંદ્રતા બદલાય તો).
વેગ નિયમ (Rate Law) અને વેગ અચળાંક
વેગ નિયમ દર્શાવે છે કે પ્રક્રિયા વેગ પ્રતિકારકોની સાંદ્રતા પર કેવી રીતે આધારિત છે.
v = k [A]^x [B]^y
k = વેગ અચળાંક (Rate constant); x, y = પ્રયોગિક રીતે મળતા ઘાતાંક (કણસંખ્યા નહીં).
🔑 વેગ નિયમ સ્ટોકિયોમેટ્રી (સમીકરણ) પરથી નહીં, પ્રયોગથી જ મેળવી શકાય.
વેગ અચળાંક k નો એકમ: (mol L⁻¹)^(1−n) s⁻¹ જ્યાં n = પ્રક્રિયા ક્રમ.
જો n = 1 (પ્રથમ ક્રમ) → k નો એકમ = s⁻¹
જો n = 0 → k નો એકમ = mol L⁻¹ s⁻¹
📝 ⚡ k એ તાપમાન પર આધારિત છે, સાંદ્રતા પર નહીં.
પ્રક્રિયા ક્રમ (Order of Reaction)
પ્રક્રિયા ક્રમ એટલે વેગ નિયમમાં પ્રતિકારકોના સાંદ્રતા પદોના ઘાતાંકોનો સરવાળો.
n = x + y + ... (સામાન્ય રીતે પ્રથમ ક્રમ: n = 1)
શૂન્ય ક્રમ (n = 0): v = k; વેગ સાંદ્રતા પર સંપૂર્ણપણે નિર્ભર નથી.
પ્રથમ ક્રમ (n = 1): v = k[A]; સાંદ્રતાની સાથે વેગ રેખીય બદલાય.
દ્વિતીય ક્રમ (n = 2): v = k[A]² અથવા v = k[A][B].
🔑 પ્રક્રિયા ક્રમ પ્રાયોગિક મૂલ્ય છે — અણુક્રમ (Molecularity) થી અલગ.
ક્રમ (Order) ← પ્રયોગઅણુક્રમ (Molecularity) ← સૈદ્ધાંતિક
📝 ✏️ GUJCET ટિપ: ભગ્ના ભિન્ન ક્રમ પણ શક્ય છે — દા.ત., 3/2, −1.
અણુક્રમ (Molecularity of Reaction)
અણુક્રમ એટલે સંક્રમણ અવસ્થા (Transition state) માં ભાગ લેતા અણુઓ/આયનોની સંખ્યા.
એકઅણુકીય (Unimolecular, n=1): A → ઉત્પાદન (દા.ત., N₂O₅ વિઘટન).
દ્વિઅણુકીય (Bimolecular, n=2): A + B → ઉત્પાદન (સૌથી સામાન્ય).
ત્રિઅણુકીય (Termolecular, n=3): અત્યંત દુર્લભ — ત્રણ કણ એક સાથે ટકરાવે તે શક્ય નહીં જેવું.
🔑 અણુક્રમ હંમેશા ધન પૂર્ણાંક હોય છે; શૂન્ય અથવા ભગ્ના હોઈ શકે નહીં.
અણુક્રમ (શેષ) ≠ પ્રક્રિયા ક્રમ (પ્રયોગ)થાત્યંત સરળ પ્રક્રિયામાં બંને બરાબર હોઈ શકે.
📝 ⚡ અણુક્રમ માત્ર એકધારી (elementary) પ્રક્રિયાઓ માટે જ અર્થપૂર્ણ છે.
શૂન્ય ક્રમ પ્રક્રિયા (Zero Order Reaction)
વેગ = k [A]⁰ = k — વેગ પ્રતિકારકની સાંદ્રતા પર આધારિત નથી.
સંકલિત સમીકરણ: [A] = [A]₀ − kt
રેખીય સ્વરૂપ: [A] vs t આલેખ → સીધી રેખા, ઢાળ = −k
અર્ધ-આયુષ્ય (t½): [A]₀/(2k) — પ્રારંભિક સાંદ્રતાના સમપ્રમાણમાં.
t½ = [A]₀/(2k) (શૂન્ય ક્રમ માટે)
🔑 તાંબાના પાત્રની આંતરપૃષ્ઠ પર એમાનિઆનનું વિઘટન શૂન્ય ક્રમનું ઉદાહરણ છે.
[A] vs t આલેખઢાળ = −k → k = |ઢાળ|
📝 ⚡ t½ શૂન્ય ક્રમમાં [A]₀ સાથે સમપ્રમાણ — પ્રથમ ક્રમથી વિરુદ્ધ!
પ્રથમ ક્રમ પ્રક્રિયા (First Order Reaction)
વેગ = k [A] — વેગ સાંદ્રતાના સમપ્રમાણમાં.
સંકલિત સમીકરણ: ln[A] = ln[A]₀ − kt અથવા [A] = [A]₀ e^(−kt)
લઘુગુણક સ્વરૂપ: log([A]₀/[A]) = (k/2.303) × t
log [A] vs t આલેખ → સીધી રેખા, ઢાળ = −k/2.303
અર્ધ-આયુષ્ય (t½): ln2/k ≈ 0.693/k — પ્રારંભિક સાંદ્રતાથી સ્વતંત્ર!
t½ = 0.693/k (પ્રથમ ક્રમ માટે)
🔑 t½ પ્રથમ ક્રમમાં [A]₀ થી સ્વતંત્ર — આ GUJCET નો સૌથી વધુ પૂછાતો ખ્યાલ.
log([A]₀/[A]) vs tઢાળ = k/2.303 → k = 2.303 × ઢાળ
📝 ✏️ Solved: t½ = 138.6 s → k = 0.693/138.6 = 5.0 × 10⁻³ s⁻¹
N₂O₅ વિઘટન: N₂O₅ → 2NO₂ + ½O₂ — પ્રથમ ક્રમનું પ્રસિદ્ધ ઉદાહરણ.
દ્વિતીય ક્રમ પ્રક્રિયા (Second Order Reaction)
વેગ = k[A]² અથવા વેગ = k[A][B].
સંકલિત સમીકરણ (v = k[A]²): 1/[A] = 1/[A]₀ + kt
1/[A] vs t આલેખ → સીધી રેખા, ઢાળ = k.
t½ = 1/(k[A]₀) (દ્વિતીય ક્રમ માટે, જ્યારે v = k[A]²)
🔑 t½ દ્વિતીય ક્રમમાં [A]₀ ના વ્યસ્ત પ્રમાણમાં — પ્રથમ ક્રમથી હવે તફાવત સ્પષ્ટ.
📝 ⚡ t½ ગણતરીમાં [A]₀ એકમ mol L⁻¹ — જવાબનું એકમ s આવશે.
અર્ધ-આયુષ્ય (Half-life, t½)
અર્ધ-આયુષ્ય એટલે તે સમય જેમાં પ્રતિકારકની સાંદ્રતા અડધી થઈ જાય.
સામાન્ય સંબંધ: t½ ∝ 1/([A]₀)^(n−1), જ્યાં n = પ્રક્રિયા ક્રમ
n = 0: t½ = [A]₀/(2k) | n = 1: t½ = 0.693/k | n = 2: t½ = 1/(k[A]₀)
🔑 પ્રથમ ક્રમ t½ સ્થિર (constant) — કિરણોત્સર્ગી ક્ષય પણ પ્રથમ ક્રમનું!
n > 1: t½ ↓ જાય છે જતાં જાય ([A]₀ ઘટે → t½ વધે)નિષ્કર્ષ: ઊંચા ક્રમની પ્રક્રિયાઓ આગળ ધીમી પડતી જાય.
📝 ⚡ Radioactive dating (C-14) — પ્રથમ ક્રમ પ્રક્રિયાનું સુંદર ઉદાહરણ છે.
તાપમાનનું પ્રભાવ — અરહેનિયસ સમીકરણ
તાપમાન વધતા અણુઓની ગતિ ઊર્જા વધે → સક્રિય અથવા (Activated) અણુઓની સંખ્યા વધે → વેગ વધે.
k = A · e^(−Ea/RT) (અરહેનિયસ સમીકરણ)
A = આવર્તન અવયવ (Frequency factor); Ea = સક્રિયકરણ ઊર્જા; R = 8.314 J K⁻¹ mol⁻¹; T = કેલ્વિનમાં તાપમાન.
લઘુગુણક સ્વરૂપ: log k = log A − (Ea/2.303RT)
બે તાપમાને સરખામણી: log(k₂/k₁) = (Ea/2.303R) × [(T₂ − T₁)/(T₁·T₂)]
🔑 log k vs 1/T આલેખ → સીધી રેખા, ઢાળ = −Ea/2.303R → Ea મેળવી શકાય.
📝 ✏️ T એટેલિયમ (Kelvin) માં — °C + 273.15 = K
સક્રિયકરણ ઊર્જા (Activation Energy, Ea)
સક્રિયકરણ ઊર્જા એટલે પ્રતિકારક અણુઓ વચ્ચે રાસાયણિક પ્રક્રિયા થવા માટે જરૂરી લઘુત્તમ অতিরিক্ত ऊर्जा.
જો Ea ઓછી હોય → વધુ અણુઓ સક્રિય થાય → પ્રક્રિયા ઝડપી.
ઉત્પ્રેરક (Catalyst) સક્રિયકરણ ઊર્જા ઘટાડે છે — પરંતુ તે स्वयं વાપરાતું નથી.
🔑 ઉત્પ્રેરક પ્રક્રિયાને 'સરળ માર્ગ' (alternative path) બતાવે — Ea ઘટે, A બદલાતું નથી.
ઉત્પ્રેરક ઉમેરતા → Ea ઘટે→ વેગ અચળાંક k વધે → v વધે
📝 ⚡ ઋણ ઉત્પ્રેરક (Inhibitor) — વેગ ઘટાડે; પીરિયોડિક તાલિકાનો સલ્ફર Na₂S₂O₃ ના વિઘટનમાં ઋણ ઉત્પ્રેરક.
કુલિશ સિદ્ધાંત (Collision Theory)
રાસાયણિક પ્રક્રિયા માટે પ્રતિકારક અણુઓના અથડામણ જરૂરી છે.
સફળ અથડામણ માટે બે શરતો: ① યોગ્ય દિશા (Proper orientation) ② પૂરતી ઊર્જા (≥ Ea).
વેગ = P · Z · e^(−Ea/RT) (P = સ્ટીરિક ફેક્ટર, Z = અથડામણ આવર્તન)
🔑 દરરોજ ઘણા અથડામણ થાય છે પણ સફળ અથડામણ ઓછી — તેથી પ્રક્રિયા ધીમી.
