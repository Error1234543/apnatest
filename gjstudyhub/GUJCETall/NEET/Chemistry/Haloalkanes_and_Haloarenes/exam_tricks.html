🎯 પરીક્ષા ટ્રિક્સ

SN1 vs SN2 નક્કી કરવાનું ઝડપી વિચારણા ચક્ર: સ્નાયુક્લિયોફાઇલની સાન્દ્રતા — જો પ્રબળ (OH⁻, RO⁻) અને ઓછું સબસ્ટ્રેટ (3° < 2° < 1°), તો SN2; જો નિર્બળ (H₂O, ROH) અને વધુ સબસ્ટ્રેટ (3° > 2° > 1°), તો SN1. ઝડપી યાદ રાખો: 'પ્રબળ + હલકું = SN2, નિર્બળ + ભારે = SN1.'
જ્યારે પ્રશ્નમાં રિએક્શન મિકેનિઝમ કે રિએક્શન કિન્ેટિક્સ (rate law) પૂછાય.
દા.ત.: CH₃CH₂Br + OH⁻ → SN2; (CH₃)₃CBr + H₂O → SN1.
હેલોજન નિયોજન (Priority) નક્કી કરવા માટે 'ઓક્સિડેશન સ્ટેટ' નો ઉપયોગ: જે કાર્બન પર હેલોજન બંધાયેલું હોય તેના ઑક્સિડેશન નંબર જેટલો higher હશે, તેના પર હેલોજન વધુ ઇલેક્ટ્રોનેગેટિવ લાગે; પરંતુ પ્રક્રિયાત્મકતા માટે C–X બંધની શકિત જોઈએ. ઝડપી વિકલ્પ: C–I < C–Br < C–Cl < C–F (પ્રક્રિયાત્મકતા ક્રમ).
હેલોજનના પ્રક્રિયાત્મકતા અથવા સ્ટેબિલિટીનો પ્રશ્ન આવે ત્યારે.
દા.ત.: R–I સૌથી વધુ પ્રક્રિયાશીલ, R–F સૌથી ઓછું.
E1 vs E2 નક્કી કરવાની યાદ: 'ઊંચું તાપમાન + પ્રબળ બેઝ (t-BuO⁻) → E2; નીચું તાપમાન + નિર્બળ બેઝ (ROH) → E1.' આ ઉપરાંત, સબસ્ટ્રેટ 3° હોય તો E1 સરળ, 1° હોય તો E2 પ્રબળ બેઝ સાથે.
જ્યારે ડીહાઇડ્રોહેલોજિનેશન અથવા બીજા કોઈ એલિમિનેશન પ્રક્રિયાનો પ્રશ્ન આવે.
દા.ત.: (CH₃)₃CBr + NaOEt → E2 (major), t-BuOH/heat → E1.
Wurtz પ્રક્રિયા દ્વારા સિમેટ્રિકલ ઇથેર સિવાયના હેલોજન સંયોજનોની રચના: સાદો નિયમ — 'જો 2 આલ્કાઇલ હેલોડ્સ સમાન હોય, તો ડાઇઅલ્કેન મળે; જો ભિન્ન હોય, તો મિશ્ર ઉત્પાદનો બને (ઉપયોગિતા ઓછી).' આથી પ્રશ્નમાં Wurtz નો ઉપયોગ માત્ર સિમેટ્રિકલ આલ્કેન માટે જ કરવો.
જ્યારે Wurtz પ્રક્રિયાના પરિણામ અથવા ઉપયોગિતા પૂછાય.
દા.ત.: 2CH₃Br + 2Na → CH₃—CH₃ + 2NaBr (સાચો ઉપયોગ).
ગ્રિગનાર્ડ રીએજન્ટ (RMgX)ની તૈયારી અને પ્રક્રિયા: 'ઇથર દ્રાવક હોવું જોઈએ, પાણી/આર્ક્ટિક હાઇડ્રોજન યુક્ત સંયોજનો ન હોવા જોઈએ (કારણ કે RMgX તરત પ્રોટોન લઈને શાન્ત થાય). RMgX + હેડ્રોજન ડોનર → આલ્કેન; RMgX + કાર્બોનિલ → આલ્કોહોલ.' ઝડપી યાદ: 'ગ્રિગનાર્ડ એ ન્યુક્લિયોફિલિક કાર્બન છે.'
જ્યારે ગ્રિગનાર્ડ રીએજન્ટની તૈયારી, સ્ટોરેજ અથવા પ્રક્રિયા પૂછાય.
દા.ત.: CH₃MgBr + H₂O → CH₄ + Mg(OH)Br (પ્રોટોનેશન); CH₃MgBr + CH₃CHO → secondary alcohol after hydrolysis.
બોરનાલ ક્લોરાઇડ (C₆H₅Cl) અને એનાઇલીન ક્લોરાઇડ (C₆H₅Cl) વચ્ચેનો તફાવત: 'બેન્ઝિલ ક્લોરાઇડ (C₆H₅CH₂Cl) માં Cl સપાટી પર છે — તે SN1/SN2 બંને કરી શકે છે; એનાઇલીન ક્લોરાઇડ (C₆H₅Cl) માં Cl રિંગ સાથે સીધો જોડાયેલો છે — તે SN1/SN2 નથી કરી શકતું (રિઝોનાન્સ સ્થિરતાને કારણે C–Cl બંધ વધુ મજબૂત).' આ ખ્યાલ ઝડપથી પ્રક્રિયાશીલતા પૂછતા પ્રશ્નોમાં ઉપયોગી છે.
જ્યારે એરોમેટિક vs બેન્ઝિલિક હેલોજન સંયોજનોની પ્રક્રિયાત્મકતાની તુલના હોય.
દા.ત.: C₆H₅CH₂Cl + KOH(aq) → C₆H₅CH₂OH (SN1/SN2); C₆H₅Cl + KOH(aq) → no reaction under normal conditions.
ફ્રિડલ-ક્રાફ્ટ્સ એકિલાઇઝેશન / એલ્કિલેશન માટેનો નિયમ: 'આલ્કિલ હેલાઇડ + લુઈસ એસિડ (AlCl₃) → કાર્બોકેટાઇન → બેન્ઝીન રિંગ પર હુમલો. પરંતુ જો રિએજન્ટમાં ≥4 કાર્બન હોય તો રિએરેન્જમેન્ટ શક્ય છે; માત્ર મોનોએકિલેશન માટે બેન્ઝીન વધુ માત્રામાં રાખવું.' આ ટ્રિક્સ ઝડપી ચૂક પસંદગીમાં મદદરૂપ થાય છે.
જ્યારે એરોમેટિક સબસ્ટિટ્યુશન પ્રક્રિયાઓના ઉત્પાદન અથવા શરતો પૂછાય.
દા.ત.: C₆H₆ + CH₃Cl/AlCl₃ → C₆H₅CH₃ (ટોલ્યુઇન); C₆H₆ + C₄H₉Cl/AlCl₃ → રિએરેન્જમેન્ટ સાથે મિશ્ર.
હેલોએરીન્સમાં આઇસોમેરિઝમ: 'જો એક જ બેન્ઝીન રિંગ પર બે વ્યાખ્યાયિત સ્થાનો હોય (o/m/p), તો 3 સમાંતર આઇસોમેર્સ; જો બે રિંગ્સ (બાયફેનિલ) હોય તો ઓર્થો, મેટા, પેરા + એન્ટિપોઝિશનલ આઇસોમેરિઝમ ધ્યાનમાં રાખો.' GUJCET માં સામાન્ય રીતે o/m/p ત્રણ જ જોવા મળે છે.
જ્યારે હેલોએરીન્સના આઇસોમેરિઝમ અથવા સંભવિત રચનાઓ પૂછાય.
દા.ત.: C₆H₄Cl₂ → 3 isomers: ortho, meta, para.
પોલર એપ્રોટિક vs પ્રોટિક દ્રાવકની અસર: 'SN2 માટે પોલર એપ્રોટિક (DMSO, acetone) ન્યુક્લિયોફાઇલને મુક્ત રાખે, ઝડપ વધારે; SN1 માટે પોલર પ્રોટિક (H₂O, ROH) કાર્બોકેટાઇન સ્થિર કરે.' આનો ઉપયોગ પ્રશ્નમાં દ્રાવકની ભૂમિકા પૂછતાં ઝડપી યાદ કરવા માટે.
જ્યારે દ્રાવકની અસર અથવા પ્રક્રિયા દર પર દ્રાવકની અસર પૂછાય.
દા.ત.: CH₃Br + CN⁻ in DMSO → fast SN2; (CH₃)₃CBr in H₂O → fast SN1.
હેલોજનની ઑક્સિડેશન સ્થિતિ અને હેલોઍલકેન્સની પ્રક્રિયાત્મકતા: 'જો હેલોજન ઓછા ઑક્સિડેશન સ્ટેટમાં હોય (J+1 < J-1), તો પ્રક્રિયાત્મકતા વધુ; પણ હકીકતમાં C–X બંધની બંધન શક્તિનું વિઘટન જ મુખ્ય છે. ઝડપી સૂત્ર: C–F (સૌથી મજબૂત, ઉત્તેજકતા ઓછી) → C–I (સૌથી નબળું, ઉત્તેજકતા વધુ).'
જ્યારે વિવિધ હેલોજનયુક્ત સંયોજનોની પ્રક્રિયાત્મકતા સરખાવવાનો પ્રશ્ન હોય.
દા.ત.: R–I > R–Br > R–Cl > R–F in reactivity toward nucleophilic substitution.
વિકલ્પ ઘટાડવાનો નિયમ — 'જો બે વિકલ્પો એક જ રિએક્શન કિન્ેટિક્સ દર્શાવતા હોય (દા.ત. SN1 માટે first-order, SN2 માટે second-order), તો જેટલો ઓછો પગલું (step) હોય, તેટલો સરળ.' આનાથી પ્રશ્ન ઉકેલવાનો સમય ઘટે છે.
જ્યારે કિન્ેટિક્સ અથવા મિકેનિઝમનો પ્રશ્ન ઝડપથી ઉકેલવો હોય.
દા.ત.: SN2 is one-step (concerted), SN1 is two-step; hence SN2 rate depends on both substrate and nucleophile concentration.
એરોમેટિક હેલોજનેશન માટે વપરાતું ક્રિયાશીલકારક: 'Cl₂/FeCl₃ કે Br₂/FeBr₃ (લુઈસ એસિડ); I₂ ને સીધું ઉપયોગ નહિ (ઓક્સિડાઇઝર જરૂરી). F₂ અત્યંત પ્રતિક્રિયાશીલ હોવાથી સીધું ઉપયોગ ન થાય.' આથી વિકલ્પોમાં ઝડપથી નિકાલ કરી શકાય.
જ્યારે એરોમેટિક હેલોજનેશનનું ક્રિયાશીલકારક પૂછાય.
દા.ત.: Bromination of benzene uses Br₂/FeBr₃; chlorination uses Cl₂/FeCl₃.
