સંતુલન (Equilibrium) — સંપૂર્ણ મહત્વના નોટ્સ

🧪 GUJCET — Gujarati • Chemistry • Equilibrium

1. સંતુલનનું પરિચય (Introduction to Equilibrium)
જ્યારે કોઈ રાસાયણિક પ્રક્રિયાની અગ્રદિશ અને પશ્ચાતદિશ દરો સમાન થઈ જાય, ત્યારે સંતુલન પ્રાપ્ત થાય છે.
સંતુલન એ વ ગતિ સંતુલન છે — આણ્વિક સ્તરે પ્રક્રિયા અટકતી નથી, પણ શુદ્ધ ફેરફાર દેખાતો નથી.
સંતુલન સદૈવ ડાઇનેમિક (ગતિશીલ) હોય છે → સમય સાથે સાંદ્રતામાં કોઈ ફેરફાર નથી થતો.
📝 📌 EXAM TIP: સંતુલન માત્ર બંધ મુક્ત તંત્રમાં જ પ્રાપ્ત થઈ શકે.
2. ભૌતિક સંતુલન (Physical Equilibrium)
ભૌતિક પ્રક્રિયામાં પદાર્થની ભૌતિક અવસ્થા બદલાય છે પણ રાસાયણિક સંરચના બદલાતી નથી.
જળ (t) ⇌ બાષ્પ (v) → સંતૃપ્ત બાષ્પ દબાણ પ્રાપ્ત થાય છે.
ઘન-द्रावण સંતુલન: વલયક્રિયામાં દ્રાવ્યતા સંતૃપ્તિ બિંદુએ પહોંચે ત્યારે ઘન અને દ્રાવિતની વચ્ચે સંતુલન स्थापित થાય છે.
વાયુ-द्रावण સંતુલન: હેનરીના નિયમ મુજબ, પાણીમાં CO₂ નું દ્રાવ્યતા વાયુના દબાણ સમાંતર હોય છે.
ભૌતિક સંતુલનમાં Kf = Kb (આગળ અને પાછળના દર સમાન).
3. રાસાયણિક સંતુલન (Chemical Equilibrium)
સામાન્ય રાસાયણિક સંતુલન: aA + bB ⇌ cC + dD
Kc = [C]^c [D]^d / [A]^a [B]^b (સંતુલન અચળાંક — સાંદ્રતાના આધારે)
વાયુ પ્રક્રિયાઓ માટે: Kp = (pC)^c (pD)^d / (pA)^a (pB)^b (આંશિક દબાણના આધારે)
Kc અને KpKp = Kc(RT)^(Δn) સંબંધ દ્વારા જોડાયેલા
જ્યાં Δn = (ઉત્પાદનોના વાયવીય મોલોની સંખ્યા) − (પ્રક્રિયકોના વાયવીય મોલોની સંખ્યા)
Kc અને Kp એ માત્ર તાપમાન પર આધારિત છે, સાંદ્રતા કે દબાણ પર નહીં.
📝 📌 K > 10^3 → પ્રક્રિયા લગભગ પૂર્ણ, K < 10^-3 → પ્રક્રિયા નગણ્ય.
4. સંતુલન અચળાંકની લાક્ષણિકતાઓ
વ્યસ્ત પ્રક્રિયા માટે K' = 1/K (ઉલટું કરીએ તો સંતુલન અચળાંક ઉલટો થાય).
જો પ્રક્રિયાનો ગુણાંક n વડે ગુણીએ તો K_new = (K_original)^n
બહુ-પગલાં પ્રક્રિયા: K_total = K₁ × K₂ × K₃ ...
સંતુલન અચળાંકનો મૂલ્ય પ્રક્રિયાના દિશા પર આધારિત નથી, માત્ર તાપમાન પર છે.
ΔG° = −RT ln K → સંતુલન અચળાંક અને ગિબ્સ મુક્ત ઊર્જા વચ્ચેનો સંબંધ
5. પ્રક્રિયા ભાગફળ Q અને સંતુલન
કોઈ પણ મુહૂર્તે સાંદ્રતાઓ માટેનો ભાગફળ: Q = [C]^c [D]^d / [A]^a [B]^b
Q < Kપ્રક્રિયા અગ્રદિશામાં ચાલશે (ઉત્પાદન બને)
Q > Kપ્રક્રિયા પશ્ચાતદિશામાં ચાલશે (પ્રક્રિયક બને)
Q = Kપદ્ધતિ સંતુલનમાં છે
Q અને K વચ્ચેની સરખામણીથી સંતુલનની દિશાની આગાહી કરી શકાય.
6. લી ચેટેલિયરનો સિદ્ધાંત (Le Chatelier's Principle)
જો સંતુલનમાં રહેલા તંત્ર પર બાહ્ય દબાણ (તાપમાન, દબાણ, સાંદ્રતા) ફેરફાર કરવામાં આવે, તો સંતુલન એ ફેરફારને અવરોધે તે રીતે ખસી જાય છે.
લી ચેટેલિયરનો સિદ્ધાંત ફક્ત અંદાજિત છે, પરંતુ પરીક્ષામાં ઘણો મહત્વનો છે.
📝 📌 Catalyst → સંતુલન ખસાતું નથી, ફક્ત સંતુલન પ્રાપ્ત થવાનો સમય ઘટે છે.
7. સાંદ્રતાના ફેરફારની અસર
જો પ્રક્રિયક વધારીએ → સંતુલન અગ્રદિશામાં ખસે (ઉત્પાદન વધારે)
જો ઉત્પાદન કાઢી નાખીએ → સંતુલન અગ્રદિશામાં ખસે
ઉદા.: Fe³⁺(aq) + SCN⁻(aq) ⇌ FeSCN²⁺(aq) → SCN⁻ વધારતાં લાલ રંગ તીવ્ર થાય.
સાંદ્રતા ફેરફાર → Kc બદલાતો નથી, પણ સંતુલન ಸ્થાન ખસે છે.
8. દબાણ/ઘનફળના ફેરફારની અસર (વાયુ પ્રક્રિયાઓ)
Δn ≠ 0 હોય તેવી વાયુ પ્રક્રિયાઓ પર દબાણની અસર થાય.
દબાણ વધારીએ → સંતુલન ઓછા મોલો વાળી બાજુ ખસે (ઘનફળ ઘટે)
ઘનફળ વધારીએ → સંતુલન વધુ મોલો વાળી બાજુ ખસે
Δn = 0દબાણ ફેરફારથી સંતુલન પર કોઈ અસર નહિ
Haber process (N₂ + 3H₂ ⇌ 2NH₃): Δn = −2, ઊંચું દબાણ = NH₃ વધુ મળે.
📝 📌 Δn = n(products_gas) − n(reactants_gas) ગણતરી ભૂલથી ન કરશો.
9. તાપમાનના ફેરફારની અસર
ઉષ્માશોષક પ્રક્રિયા (ΔH > 0): તાપમાન વધારવાથી સંતુલન અગ્રદિશામાં ખસે (K વધે).
ઉષ્માક્ષેપક પ્રક્રિયા (ΔH < 0): તાપમાન વધારવાથી સંતુલન પશ્ચાતદિશામાં ખસે (K ઘટે).
van't Hoff equation: ln(K₂/K₁) = (ΔH°/R)(1/T₁ − 1/T₂)
તાપમાન એ Kc/Kp નું મૂલ્ય બદલી શકે તે એકમાત્ર પરિબળ છે.
10. એસિડ-બેઝ સંતુલન
બ્રોન્સ્ટેડ-લોરી સિદ્ધાંત: એસિડ = પ્રોટોન દાતા, બેઝ = પ્રોટોન ગ્રાહક.
HA ⇌ H⁺ + A⁻ ; Ka = [H⁺][A⁻] / [HA]
બળવાન એસિડ (HCl, HNO₃) → સંપૂર્ણ વિઘટન, Ka ખૂબ મોટું
દુર્બળ એસિડ (CH₃COOH, HCN) → આંશિક વિઘટન, Ka નાનું
pKa = −log Ka → pKa નાનો એસિડ बलवान्. pKa = −log Ka એ એસિડની બળતરાનું માપ છે.
11. બેઝના સંતુલન
B + H₂O ⇌ BH⁺ + OH⁻ ; Kb = [BH⁺][OH⁻] / [B]
pKb = −log Kb → pKb નાનો = બલવાન બેઝ
Ka × Kb = Kw = 1.0 × 10⁻¹⁴ (25°C) → pKa + pKb = 14
જંકાયુગમી એસિડ-બેઝ જોડી: CH₃COOH/CH₃COO⁻, NH₃/NH₄⁺
12. અપૂર્ણ એસિડ અને બેઝના pH ની ગણતરી
દુર્બળ એસિડ HA: [H⁺] = √(Ka × C) (α ≪ 1 હોય ત્યારે)
Ostwald નું વિઘટન સૂત્ર: Ka = Cα²/(1−α) ≈ Cα² (α ખૂબ નાનો હોય તો)
pH = −log[H⁺] | pOH = −log[OH⁻] | pH + pOH = 14
દુર્બળ બેઝ BOH: [OH⁻] = √(Kb × C) → pOH = −log[OH⁻]
α = વિઘટન અંશ = √(Ka/C) → સાંદ્રતા વધારે તો α ઘટે (Ostwald થિયરમ).
13. સામાન્ય આયન અસર (Common Ion Effect)
દુર્બળ એસિડના દ્રાવણમાં બળવાન એસિડ ઉમેરતાં વિઘટન અંશ α ઘટે છે.
CH₃COOH ⇌ CH₃COO⁻ + H⁺ → CH₃COONa ઉમેરતાં CH₃COO⁻ વધે, સંતુલન ડાબી બાજુ ખસે.
સામાન્ય આયન અસર → આયનીકરણ ઘટે, [H⁺] ઘટે (એસિડ દુર્બળ બને).
📝 📌 buffer solution એ આ અસર પર આધારિત છે.
14. બફર દ્રાવણ (Buffer Solution)
બફર દ્રાવણ: એવું દ્રાવણ જે pH માં ઝડપી ફેરફાર જરા ઓછો થાય તેવું બનાવે છે.
एसिड बफर: दुर्बल एसिड + त्याचा लवण (उदा. CH₃COOH + CH₃COONa)
मृदु बफर: दुर्बल बस + त्याचा लवण (उदा. NH₄OH + NH₄Cl)
Henderson-Hasselbalch: pH = pKa + log([Salt]/[Acid])
pOH = pKb + log([Salt]/[Base]) → pH = 14 − pOH
बफर क्षमता: बफर का pH बदलने की क्षमता; [Salt]=[Acid] असताना बफर क्षमता कमाल.
📝 📌 रक्ताचे pH = 7.4 (बफर प्रणाली). EXAM मध्ये हे वारंवार येते.
15. आदर्श आणि व्यावहारिक बफर
आदर्श बफर: [Salt] = [Acid] → pH = pKa
बफर क्षेत्र: pKa ± 1 या मर्यादेत बफर प्रभावीपणे काम करते.
प्रयोगशाळेत: pH = 4.75 साठी CH₃COOH/CH₃COONa वापरतात.
बफरची निवड: ज्या पदार्थाचा pKa इच्छित pH च्या जवळ असेल तो बफर योग्य.
16. जलीय विद्राव्यांचे संप्रेरक (Ksp — Solubility Product)
अ饱和 विद्राव: Ksp = [cation]^m [anion]^n (घन + द्रव संतुलनासाठी)
AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq) ; Ksp = [Ag⁺][Cl⁻]
BaSO₄(s) ⇌ Ba²⁺ + SO₄²⁻ ; Ksp = [Ba²⁺][SO₄²⁻]
AxBy(s) ⇌ xAy⁺ + yBx⁻ ; Ksp = [Ay⁺]^x [Bx⁻]^y
विघटनशीलता (s): AgCl साठी s = √Ksp ; BaSO₄ साठी s = √Ksp
Ksp < Q → अवक्षेप तयार होतो. Ksp > Q → विद्राव अतृप्त. Ksp = Q → संपृक्त.
17. सामायिक आयन असर आणि Ksp
AgCl चे द्रावणात NaCl मिसळा → Cl⁻ वाढ → Q > Ksp → AgCl अवक्षेप पडतो.
विद्राव्यता Ksp वर अवलंबून असते, सामायिक आयनमुळे विद्राव्यता कमी होते.
Ksp च्या आधारे s काढताना: उदा. PbCl₂ → Ksp = 4s³ (s = (Ksp/4)^(1/3))
📝 📌 Ksp किंमत तापमानावर अवलंबून — फक्त तापमान बदलल्यास Ksp बदलतो.
18. अवक्षेपण (Precipitation) चे निकष
Qsp > Ksp → अवक्षेप तयार
Qsp = Ksp → संपृक्त द्रावण (अवक्षेप नाही)
Qsp < Ksp → असंपृक्त द्रावण (अवक्षेप नाही)
Selective precipitation: वेगवेगळ्या Ksp असलेल्या लवणांना टप्प्याटप्प्याने वेगळे करता येते.
19. आम्ल-आम्लारी संतुलनातील अनुमापन (Titration Curves)
बलवान आम्ल + बलवान आम्लारी: equivalence point pH = 7
दुर्बल आम्ल + बलवान आम्लारी: equivalence point pH > 7
बलवान आम्ल + दुर्बल आम्लारी: equivalence point pH < 7
Half-equivalence point: pH = pKa (म्हणजे [Salt] = [Acid], बफर प्रदेश).
📝 📌 अनुमापन वक्रावर equivalence point = inflection point.
20. निर्देशक (Indicators) आणि रंग बदल
निर्देशक: दुर्बल आम्लारी असलेले संयुग, जे pH नुसार रंग बदलते.
मेथिल ऑरेंज: pH 3.1–4.4 (लाल → पिवळा)
फिनॉल्थैलीन: pH 8.0–9.6 (रंगहीन → गुलाबी)
निर्देशकाचा रंग बदल: pH = pKin + log([In⁻]/[HIn])
निर्देशकाची पदर्थनिवड: equivalence point च्या pH शी जुळणारा निर्देशक निवडा.
21. व्हान्ट हॉफ समीकरण (Van't Hoff Equation) — तापमान आणि K
ln(K₂/K₁) = (ΔH°/R) × [(T₂−T₁)/(T₁·T₂)]
ΔH° > 0 (उष्माशोषक): T वाढ → K वाढ
ΔH° < 0 (उष्माक्षेपक): T वाढ → K घट
Van't Hoff plot (ln K vs 1/T) चा उतार = −ΔH°/R → ΔH° काढता येतो.
22. राउल्टचा नियम आणि वाफ दाब (Vapour Pressure Colligative Properties)
राउल्टचा नियम: P_solution = X_solvent × P°_solvent
सहज बाष्प दाब: मिश्रणातील प्रत्येक घटकाचा आंशिक दाब = शुद्ध अवस्थेतील दाब × मोल अपूर्णांक
P_total = P_A + P_B = X_A P°_A + X_B P°_B
📝 📌 आदर्श द्रावण: राउल्टच्या नियमाचे पालन करणारे. वास्तविक द्रावण: अनियत आचरण.
23. आदर्श आणि वास्तविक द्रावणे (Ideal vs Non-Ideal Solutions)
आदर्श द्रावण: ΔH_mix = 0, ΔV_mix = 0, राउल्टचा नियम लागू
धनात्मक विचलन: P_actual > P_ideal (उदा. इथेनॉल + ॲसिटोन) — A-B आकर्षण < A-A, B-B
ऋणात्मक विचलन: P_actual < P_ideal (उदा. क्लोरोफॉर्म + ॲसिटोन) — A-B आकर्षण > A-A, B-B
अझेओट्रोप: विशिष्ट संघटना असलेले द्रावण, जे स्थिर उत्कलनांकाने उत्कलन पावते.
24. सामान्य गुण (Summary of Important Points)
संतुलन सदैव गतिशील असते.
K केवळ तापमानावर अवलंबून.
Catalyst ने K बदलत नाही, फक्त सन्तुलनापर्यंत पोहोचण्याचा वेग वाढतो.
ली चॅटेलियर सिद्धांतानुसार बॅकग्राऊंड बदल → संतुलन स्थान बदलते, K बदलत नाही (तापमान सोडून).
δn = 0 असल्यास दाब बदलली तरी संतुलन स्थानात बदल होत नाही.
25. महत्त्वाची सूत्रे — पुनरावलोकन
Kp = Kc(RT)^(Δn)
ΔG° = −RT ln K = −2.303 RT log K
pH = −log[H⁺]; pOH = −log[OH⁻]; pH + pOH = 14
pKa = −log Ka, pKb = −log Kb, pKa + pKb = pKw = 14
Ka = Cα²/(1−α), Kb = Cα²/(1−α)
pH = pKa + log([Salt]/[Acid]) — Henderson-Hasselbalch
Ksp(AgCl) = s² | Ksp(BaSO₄) = s² | Ksp(PbCl₂) = 4s³
Qsp vs Ksp: अवक्षेपाचा निकष
ln(K₂/K₁) = (ΔH°/R)[(T₂−T₁)/(T₁T₂)]

26. परीक्षा परिप्रेक्ष्यातील महत्त्वाचे मुद्दे
Kc आणि Kp यांच्यातील फरक ओळखा (Kp वारंवार विचारले जाते).
Le Chatelier चे उदाहरणे ( Haber, Contact process) लक्षात ठेवा.
Buffer ची व्याख्या, प्रकार आणि Henderson-Hasselbalch हे नक्की व्हावे.
Ksp वरून विद्राव्यता (s) काढण्याची पद्धत सराव करा.
pH गणना (बलवान/दुर्बल आम्ल/आम्लारी) — वारंवार येणारे प्रश्न.
Δn = 0 असल्यास दाबाचा परिणाम नाही — अत्यंत सामान्य प्रश्न.
