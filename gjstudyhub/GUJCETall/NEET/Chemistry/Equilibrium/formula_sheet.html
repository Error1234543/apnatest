⚡ સૂત્રો

સામાન્ય સંતુલન અચળાંક (Kc): Kc = [C]^c [D]^d / [A]^a [B]^b
[A], [B], [C], [D] = સંતુલન પર સાંદ્રતા (mol L⁻¹); a, b, c, d = સ્ટોઇકિયોમેટ્રિક ગુણાંક · SI: mol^(Δn) L^(-Δn) (જ્યાં Δn = ઉત્પાદનોના મોલ − પ્રક્રિયકોના મોલ) · સ્થિર તાપમાને સંતુલન સ્થિતિ માટે; Δn = 0 હોય તો Kc અમાત્રક (dimensionless)
આંશિક દબાણ આધારિત સંતુલન અચળાંક (Kp): Kp = (P_C)^c (P_D)^d / (P_A)^a (P_B)^b
P_A, P_B, P_C, P_D = સંતુલન પર આંશિક દબાણ (atm અથવા bar) · SI: atm^(Δn) અથવા bar^(Δn) · વાયુ અવસ્થાની પ્રક્રિયાઓ માટે; Kp = Kc(RT)^(Δn)
Kp અને Kc વચ્ચેનો સંબંધ: Kp = Kc (RT)^(Δn)
R = 0.0821 L atm K⁻¹ mol⁻¹; T = તાપમાન (K); Δn = (ઉત્પાદનના વાયુ મોલ) − (પ્રક્રિયકના વાયુ મોલ) · SI: Kp અને Kc એકમો Δn પર આધારિત · આદર્શ વાયુ વર્તણૂક ધારીને; T = K માં, R = 0.0821 L atm K⁻¹ mol⁻¹
પ્રક્રિયા ભાગફળ (Qc): Qc = [C]^c [D]^d / [A]^a [B]^b (કોઈપણ સમયે)
Qc = સંતુલન પર નહીં, પણ કોઈપણ ક્ષણે સાંદ્રતાઓ વડે ગણતરી · SI: Kc જેવું જ · સંતુલનની દિશા અનુમાનિત કરવા: Qc < Kc → આગળ; Qc > Kc → પાછળ; Qc = Kc → સંતુલન
પ્રક્રિયા ભાગફળ (Qp): Qp = (P_C)^c (P_D)^d / (P_A)^a (P_B)^b
Qp = આંશિક દબાણો વડે ગણતરી, કોઈપણ ક્ષણે · SI: Kp જેવું જ · વાયુ પ્રક્રિયાઓ માટે; Qp < Kp → આગળ; Qp > Kp → પાછળ
વિઘટન અચળાંક (Ka) — બળહીન એસિડ: Ka = [H⁺][A⁻]/[HA]
[H⁺] = H⁺ આયન સાંદ્રતા; [A⁻] = વિપરીત આયન સાંદ્રતા; [HA] = અવિઘટિત એસિડ સાંદ્રતા · SI: mol L⁻¹ · બળહીન એસિડ HA → H⁺ + A⁻; 25°C પર
બળહીન એસિડ માટે [H⁺] (Ostwald વિઘટન સૂત્ર): [H⁺] = √(Ka × C)
Ka = વિઘટન અચળાંક; C = એસિડની પ્રારંભિક મોલર સાંદ્રતા · SI: mol L⁻¹ · જ્યારે α (વિઘટન અંશ) << 1 હોય; સામાન્ય રીતે C/Ka > 100
pH સૂત્ર: pH = −log₁₀[H⁺]
[H⁺] = H⁺ આયનની મોલર સાંદ્રતા (mol L⁻¹) · SI: અમાત્રક (dimensionless) · 25°C પર તટસ્થ દ્રાવણનું pH = 7; pH < 7 = એસિડી; pH > 7 = ક્ષારકી
pOH સૂત્ર: pOH = −log₁₀[OH⁻]
[OH⁻] = OH⁻ આયનની મોલર સાંદ્રતા · SI: અમાત્રક · pH + pOH = 14 (25°C પર)
બળહીન બેઝ માટે [OH⁻]: [OH⁻] = √(Kb × C)
Kb = બળહીન બેઝનો વિઘટન અચળાંક; C = બેઝની મોલર સાંદ્રતા · SI: mol L⁻¹ · જ્યારે α << 1; બળહીન બેઝ B + H₂O → BH⁺ + OH⁻
બળહીન બેઝ માટે pOH: pOH = ½(pKb − log₁₀C)
pKb = −log₁₀Kb; C = બેઝની મોલર સાંદ્રતા · SI: અમાત્રક · α << 1 હોય ત્યારે; pH = 14 − pOH
હેન્ડરસન-હેસલબાલ્ક સમીકરણ (એસિડ બફર): pH = pKa + log₁₀([A⁻]/[HA])
pKa = −log₁₀Ka; [A⁻] = ક્ષાર (વિપરીત આયન) સાંદ્રતા; [HA] = બળહીન એસિડ સાંદ્રતા · SI: અમાત્રક · બફર દ્રાવણ માટે; [A⁻] અને [HA] સંતુલન સાંદ્રતા અથવા પ્રારંભિક સાંદ્રતા
ક્ષારકીય બફર (બેઝ બફર) — હેન્ડરસન-હેસલબાલ્ક: pOH = pKb + log₁₀([BH⁺]/[B])
pKb = −log₁₀Kb; [BH⁺] = ક્ષાર સાંદ્રતા; [B] = બળહીન બેઝ સાંદ્રતા · SI: અમાત્રક · બફર દ્રાવણ માટે; pH = 14 − pOH
બફર ક્ષમતા (Buffer Capacity): β = dn/d(pH)
β = બફર ક્ષમતા; dn = ઉમેરેલા પ્રબળ એસિડ/બેઝના મોલ; dpH = pH માં ફેરફાર · SI: mol L⁻¹ pH⁻¹ · બફરની પ્રબળ એસિડ/બેઝ સામે પ્રતિકાર ક્ષમતા; β મહત્તમ જ્યારે pH = pKa
વિઘટન અંશ (α) — બળહીન વિદ્યુતવિભાજ્ય: α = √(K/C)
K = વિઘટન અચળાંક (Ka અથવા Kb); C = મોલર સાંદ્રતા · SI: અમાત્રક · Ostwald વિઘટન સૂત્ર; α << 1 હોય ત્યારે; K = Ka અથવા Kb
Ostwald વિઘટન સૂત્ર (સામાન્ય): K = Cα²/(1−α)
K = વિઘટન અચળાંક; C = મોલર સાંદ્રતા; α = વિઘટન અંશ · SI: mol L⁻¹ · બળહીન વિદ્યુતવિભાજ્ય માટે; α નાનું હોય તો K ≈ Cα²
Kw — જળવિભાજન અચળાંક: Kw = [H⁺][OH⁻]
Kw = 1.0 × 10⁻¹⁴ (25°C પર); [H⁺] = H⁺ સાંદ્રતા; [OH⁻] = OH⁻ સાંદ્રતા · SI: mol² L⁻² · શુદ્ધ જળ અને જલીય દ્રાવણો માટે; તાપમાન વધે તો Kw વધે
Ka અને Kb વચ્ચેનો સંબંધ: Ka × Kb = Kw
Ka = બળહીન એસિડનો વિઘટન અચળાંક; Kb = તેના સંયુગ્મી બેઝનો વિઘટન અચળાંક; Kw = જળવિભાજન અચળાંક · SI: mol² L⁻² (Ka × Kb) · સંયુગ્મી એસિડ-બેઝ જોડી માટે; 25°C પર Ka × Kb = 1.0 × 10⁻¹⁴
pKa + pKb: pKa + pKb = pKw = 14 (25°C)
pKa = −log₁₀Ka; pKb = −log₁₀Kb; pKw = −log₁₀Kw · SI: અમાત્રક · સંયુગ્મી એસિડ-બેઝ જોડી માટે; તાપમાન બદલાય તો pKw બદલાય
વિઘટન અચળાંક અને ગિબ્સ મુક્ત ઊર્જા: ΔG° = −RT ln K
ΔG° = પ્રમાણિત ગિબ્સ મુક્ત ઊર્જા ફેરફાર; R = 8.314 J K⁻¹ mol⁻¹; T = તાપમાન (K); K = સંતુલન અચળાંક · SI: J mol⁻¹ · સંતુલન અચળાંક અને પ્રમાણિત ગિબ્સ ઊર્જા વચ્ચેનો સંબંધ
van't Hoff સમીકરણ: ln(K₂/K₁) = (ΔH°/R)(1/T₁ − 1/T₂)
K₁, K₂ = તાપમાન T₁, T₂ પર સંતુલન અચળાંક; ΔH° = પ્રક્રિયાનો પ્રમાણિત એન્થાલ્પી ફેરફાર; R = 8.314 J K⁻¹ mol⁻¹ · SI: અમાત્રક (ln પદ) · તાપમાન બદલાતા K માં થતા ફેરફારની ગણતરી; ΔH° > 0 (ઉષ્માશોષી) → T વધે તો K વધે
દ્રાવ્યતા ગુણાકાર અચળાંક (Ksp): Ksp = [Mⁿ⁺]^m [Xᵐ⁻]^x
[Mⁿ⁺] = ધન આયન સાંદ્રતા; [Xᵐ⁻] = ઋણ આયન સાંદ્રતા; m, x = સ્ટોઇકિયોમેટ્રિક ગુણાંક · SI: mol^(m+x) L^(-(m+x)) · અવિઘટનીય લવણ AB(s) ⇌ A⁺(aq) + B⁻(aq); Ksp = s² (1:1 પ્રકાર)
AB પ્રકાર લવણ માટે Ksp અને દ્રાવ્યતા (s): Ksp = s² → s = √Ksp
s = મોલર દ્રાવ્યતા (mol L⁻¹); Ksp = દ્રાવ્યતા ગુણાકાર અચળાંક · SI: mol L⁻¹ (s) · AB(s) ⇌ A⁺ + B⁻ પ્રકારના લવણ માટે; 1:1 આયન ગુણોત્તર
AB₂ અથવા A₂B પ્રકાર લવણ માટે Ksp અને s: Ksp = 4s³ → s = ∛(Ksp/4)
s = મોલર દ્રાવ્યતા; Ksp = દ્રાવ્યતા ગુણાકાર અચળાંક · SI: mol L⁻¹ · AB₂(s) ⇌ A²⁺ + 2B⁻ અથવા A₂B(s) ⇌ 2A⁺ + B²⁻ પ્રકાર
AB₃ પ્રકાર લવણ માટે Ksp અને s: Ksp = 27s⁴ → s = ∜(Ksp/27)
s = મોલર દ્રાવ્યતા; Ksp = દ્રાવ્યતા ગુણાકાર અચળાંક · SI: mol L⁻¹ · AB₃(s) ⇌ A³⁺ + 3B⁻ અથવા A₃B(s) ⇌ 3A⁺ + B³⁻ પ્રકાર
સામાન્ય આયન અસર (Common Ion Effect): Ksp = s(s + C) (AB પ્રકાર)
s = નવી દ્રાવ્યતા; C = સામાન્ય આયનની વધારાની સાંદ્રતા · SI: mol² L⁻² (Ksp) · જ્યારે લવણના દ્રાવણમાં પહેલેથી સામાન્ય આયન હોય; s << C હોય તો Ksp ≈ sC
લવણનું જળવિઘટન અચળાંક (Kh): Kh = Kw/Ka (શક્તિશાળી બેઝ + બળહીન એસિડ લવણ)
Kh = જળવિઘટન અચળાંક; Kw = જળવિભાજન અચળાંક; Ka = બળહીન એસિડનો વિઘટન અચળાંક · SI: અમાત્રક · શક્તિશાળી બેઝ + બળહીન એસિડના લવણ (જેમ CH₃COONa) માટે
બળહીન એસિડ + શક્તિશાળી બેઝ લવણનું pH: pH = ½(pKw + pKa + log₁₀C)
pKw = 14; pKa = −log₁₀Ka; C = લવણની મોલર સાંદ્રતા · SI: અમાત્રક · શક્તિશાળી બેઝ + બળહીન એસિડ લવણના જળવિઘટન માટે; 25°C
શક્તિશાળી એસિડ + બળહીન બેઝ લવણનું pH: pH = ½(pKw − pKb − log₁₀C)
pKw = 14; pKb = −log₁₀Kb; C = લવણની મોલર સાંદ્રતા · SI: અમાત્રક · શક્તિશાળી એસિડ + બળહીન બેઝ લવણના જળવિઘટન માટે; 25°C
બળહીન એસિડ + બળહીન બેઝ લવણનું pH: pH = ½(pKw + pKa − pKb)
pKw = 14; pKa = એસિડનો; pKb = બેઝનો; C આ સૂત્રમાં આવતું નથી · SI: અમાત્રક · બળહીન એસિડ + બળહીન બેઝ લવણ (જેમ NH₄CH₃COO) માટે; pH C પર આધારિત નથી
વિઘટન અંશ અને જળવિઘટન અચળાંક: h = √(Kh/C)
h = જળવિઘટન અંશ; Kh = જળવિઘટન અચળાંક; C = લવણની મોલર સાંદ્રતા · SI: અમાત્રક · બળહીન એસિડ + શક્તિશાળી બેઝ લવણ માટે; h << 1
સંતુલન અચળાંક અને પ્રક્રિયા ભાગફળ વચ્ચેનો સંબંધ: ΔG = ΔG° + RT ln Q
ΔG = ગિબ્સ મુક્ત ઊર્જા ફેરફાર; ΔG° = પ્રમાણિત ગિબ્સ મુક્ત ઊર્જા; Q = પ્રક્રિયા ભાગફળ · SI: J mol⁻¹ · કોઈપણ સ્થિતિ માટે; સંતુલન પર ΔG = 0 અને Q = K
Henderson-Hasselbalch — એસિડ બફર (વૈકલ્પિક સ્વરૂપ): pH = pKa + log₁₀(સાંદ્રતા_ક્ષાર/સાંદ્રતા_એસિડ)
pKa = −log₁₀Ka; ક્ષાર = વિપરીત આયન (A⁻); એસિડ = બળહીન એસિડ (HA) · SI: અમાત્રક · એસિડ બફર; [ક્ષાર] = [A⁻], [એસિડ] = [HA]
બફરનું pH — સમાન સાંદ્રતાએ: pH = pKa (જ્યારે [A⁻] = [HA])
pKa = −log₁₀Ka · SI: અમાત્રક · બફરમાં એસિડ અને તેના ક્ષારની સાંદ્રતા સમાન હોય તો; pOH = pKb જ્યારે [B] = [BH⁺]
તાપમાન અને સંતુલન અચળાંક (ઉષ્માશોષી પ્રક્રિયા): T ↑ → K ↑ (ΔH° > 0)
T = તાપમાન; K = સંતુલન અચળાંક; ΔH° > 0 = ઉષ્માશોષી · SI: — · ઉષ્માશોષી પ્રક્રિયા: તાપમાન વધારતાં સંતુલન આગળની દિશાએ; ΔH° < 0 (ઉષ્માક્ષેપી) → T ↑ → K ↓
દબાણ અને સંતુલન પર અસર (Le Chatelier): Δn_g < 0 → દબાણ વધારતાં આગળની દિશા; Δn_g > 0 → દબાણ વધારતાં પાછળની દિશા
Δn_g = વાયુ મોલમાં ફેરફાર (ઉત્પાદન − પ્રક્રિયક) · SI: — · વાયુ પ્રક્રિયાઓ માટે; દબાણ વધારતાં ઓછા વાયુ મોલવાળી દિશાએ સંતુલન ખસે

🔗 સંબંધો

  • Kp = Kc(RT)^(Δn) — આંશિક દબાણ અને સાંદ્રતા આધારિત સંતુલન અચળાંક વચ્ચેનો સંબંધ
  • Ka × Kb = Kw — સંયુગ્મી એસિડ-બેઝ જોડીના વિઘટન અચળાંકનો ગુણાકાર Kw બરાબર
  • pH + pOH = 14 (25°C) — જલીય દ્રાવણમાં H⁺ અને OH⁻ સાંદ્રતાનો ગુણાકાર Kw
  • ΔG° = −RT ln K — પ્રમાણિત ગિબ્સ ઊર્જા અને સંતુલન અચળાંક વચ્ચેનો સંબંધ
  • Q < K → પ્રક્રિયા આગળની દિશાએ; Q > K → પાછળની દિશાએ; Q = K → સંતુલન
  • બળહીન એસિડ/બેઝ માટે α = √(K/C) — વિઘટન અંશ સાંદ્રતાના વર્ગમૂળના વ્યસ્ત પ્રમાણમાં
  • બફરનું pH = pKa જ્યારે [ક્ષાર] = [એસિડ] — મહત્તમ બફર ક્ષમતા આ બિંદુએ
  • તાપમાન વધારતાં ઉષ્માશોષી પ્રક્રિયાનો K વધે, ઉષ્માક્ષેપીનો K ઘટે
  • Ksp = s² (AB પ્રકાર), Ksp = 4s³ (AB₂ પ્રકાર), Ksp = 27s⁴ (AB₃ પ્રકાર) — દ્રાવ્યતા અને Ksp વચ્ચેનો સંબંધ

🎯 ટ્રિક્સ

જો Δn = 0 હોય તો Kp = Kc — બંને સંતુલન અચળાંક સમાન, એકમ પણ સમાન
pH = pKa + log(ક્ષાર/એસિડ) — જો ક્ષાર:એસિડ = 1:1 હોય તો pH = pKa (સરળ ગણતરી)
બળહીન એસિડ માટે pH = ½(pKa − log C) — સીધું સૂત્ર, [H⁺] = √(Ka×C) માંથી
AB₂ પ્રકાર લવણની દ્રાવ્યતા AB પ્રકાર કરતાં ઓછી ગણતરી: s = ∛(Ksp/4)
જળવિઘટન અંશ h = √(Kh/C) — જો C વધે તો h ઘટે (વ્યસ્ત સંબંધ)
બળહીન એસિડ + બળહીન બેઝ લવણનું pH C પર આધારિત નથી — માત્ર pKa અને pKb પર
pOH = ½(pKb − log C) — બળહીન બેઝ માટે pH = 14 − ½(pKb − log C)
સામાન્ય આયન અસરમાં Ksp ≈ s×C (જો s << C) — દ્રાવ્યતા ઘટે છે

⚠️ ભૂલો

Kp અને Kc વચ્ચેનો સંબંધ Kp = Kc(RT)^(Δn) માં Δn = પ્રક્રિયક − ઉત્પાદન ન લખી દે (ઉત્પાદન − પ્રક્રિયક સાચું છે)
બળહીન એસિડ માટે [H⁺] = √(Ka×C) સૂત્ર ત્યારે જ લાગુ પડે જ્યારે α << 1 (C/Ka > 100)
pH = −log[H⁺] માં [H⁺] ને mol L⁻¹ માં લેવું જરૂરી; g/L અથવા અન્ય એકમમાં ન લેવું
બફર સૂત્રમાં [A⁻]/[HA] ને વ્યસ્ત ક્રમમાં મૂકી દેવાય — સાચો ક્રમ: ક્ષાર/એસિડ
Ksp ની ગણતરીમાં સ્ટોઇકિયોમેટ્રિક ગુણાંકને ઘાતમાં અને સાંદ્રતામાં બંને જગ્યાએ લાગુ પાડવા ભૂલી જાય
AB₂ પ્રકાર લવણ માટે Ksp = 4s³ લખવાને બદલે Ksp = s² લખી દેવાય (AB પ્રકારનું સૂત્ર લાગુ પાડવું)
બળહીન એસિડ + બળહીન બેઝ લવણનું pH = ½(pKw + pKa − pKb) સૂત્રમાં C (સાંદ્રતા) આવતી નથી — C મૂકી દેવાય
Le Chatelier ના સિદ્ધાંત મુજબ દબાણ વધારતાં Δn_g ધન હોય તો પણ આગળ ખસે એમ માની લેવું (ગલત)
Kw = 1.0 × 10⁻¹⁴ ફક્ત 25°C પર લાગુ; અન્ય તાપમાને Kw અલગ હોય છે
pKa + pKb = pKw = 14 એ સંયુગ્મી જોડી માટે છે, કોઈ પણ એસિડ-બેઝ જોડી માટે નહીં
જળવિઘટન અચળાંક Kh = Kw/Ka (શક્તિશાળી બેઝ + બળહીન એસિડ) માં Ka એ બળહીન એસિડનો છે, બેઝનો નહીં
Q અને K ની સરખામણી કરતી વખતે બંને એક જ એકમમાં (બંને Kc અથવા બંને Kp) હોવા જોઈએ
