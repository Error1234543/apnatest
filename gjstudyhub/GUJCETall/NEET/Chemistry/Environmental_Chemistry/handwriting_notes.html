પર્યાવરણ રસાયણશાસ્ત્ર — હસ્તલિખિત નોંધો

🧪 GUJCET — Gujarati • Chemistry • Environmental Chemistry

૧. પર્યાવરણ રસાયણશાસ્ત્ર — પરિચય
જે સંશોધન પર્યાવરણમાં રસાયણોના ફેરફારો અને તેમની અસરો અંગે માહિતી આપે છે, તે પર્યાવરણ રસાયણશાસ્ત્ર કહે છે.
પર્યાવરણ = વાયુમંડળ + જલમંડળ + પૃથ્વીસ્તર + જીવમંડળ — આ ચારોમાં રસાયણોનું ચક્ર યોગ્ય રીતે કામ કરતું હોવું જોઈએ.
પ્રદૂષણ એટલે પર્યાવરણના કોઈ પણ અંગમાં (વાયુમંડળ, જળ, મૃદા) અનિચ્છનીય પદાર્થોનો સंचય.
📝 📝 GUJCET માં 'પ્રદૂષક' vs 'પ્રદૂષણ' — બન્ને વચ્ચેનો તફાવત ધ્યાનથી વાંચો.
કુદરતી સંતુલન બગડેપર્યાવરણીય સમસ્યાઓ ઉભી થાય
પ્રદૂષણ = પ્રદૂષકોની સાંદ્રતા × સંપર્ક સમય × પ્રતિક્રિયાશીલતા
૨. પ્રદૂષકોના પ્રકાર
પ્રદૂષકો બે પ્રકારના હોય છે — (૧) જૈવિક પ્રદૂષક (Biodegradable) અને (૨) અજૈવિક પ્રદૂષક (Non-biodegradable).
જૈવિક પ્રદૂષકો છૂટકારો મેળવી શકે છે, પણ અજૈવિક પ્રદૂષકો પર્યાવરણમાં લાંબો સમય સુધી ટકી રહે છે.
ઉદા. તરીકે: ઘરેલું કચરો, મલબેજ → જૈવિક; પ્લાસ્ટિક, ભારે ધાતુઓ (Lead, Mercury) → અજૈવિક.
બીજી વર્ગીકરણ: દૂષકોને તેમની ઉત્પત્ति based પણ વિભાજિત કરી શકાય — प्राकृतिक અને मानवजन्य.
📝 ⚠️ ધ્યાન રાખો: 'પ્રદૂષક' શબ્દ સીધો પ્રવાહી/ઘન/વાયુ રૂપે ઉલ્લેખ થાય છે.
અજૈવિક પ્રદૂષકોપર્યાવરણમાં સચેતાવસ્થા (Persistent)
૩. વાતાવરણીય પ્રદૂષણ — સ્વરૂપો અને પ્રદૂષકો
વાયુમંડળીય પ્રદૂષણ મુખ્યત્વે ધુમાડો, ધૂળ, કેમિકલ ઇન્દ્રિય વાયુઓ અને દ્રવ્ય કણો (Particulate Matter) ને કારણે થાય છે.
સૂક્ષ્મ દ્રવ્ય — PM2.5 અને PM10 — શ્વાસનેગ્ર સંબંધી રોગો માટે જવાબદાર.
મુખ્ય ગૅસીય પ્રદૂષકો: CO, SO₂, NO₂, O₃, હાઇડ્રોકાર્બન (HC).
SO₂ + H₂O → H₂SO₃ → વરસાદી પ્રવાહી બને છે (એસિડ રેઈન)
CO હીમોગ્લોબિન સાથે મજબૂત બંધ બનાવે છે — કાર્બન મોનોક્સાઇડ પોઈઝનિંગની મુખ્ય કારણ.
📝 🔑 PM2.5 નું કદ ≤ 2.5 µm — ઊંડાણપૂર્વક ફેફસામાં પ્રવેશે.
વાહન ધૂમાડોNOx અને CO ની ઉત્પત્તિ
૪. ગ્રીનહાઉસ અસર અને ગ્લોબલ વોર્મિંગ
ગ્રીનહાઉસ અસર એ વાતાવરણીય વાયુઓ દ્વારા પૃથ્વીની ઉષ્મા રોકાવાની કુદરતી પ્રક્રિયા છે.
ગ્રીનહાઉસ વાયુઓ (GHG): CO₂, CH₄, N₂O, CFCs, ઓઝોન.
CO₂ ની વર્ધમાન સાંદ્રતા ગ્લોબલ વોર્મિંગનું મુખ્ય કારણ છે.
સૂર્યપ્રકાશ (Shortwave) → પૃથ્વી પર પહોંચે → પૃથ્વી દ્વારા Infrared ઉત્સર્જન → GHG દ્વારા શોષાવું.
ગ્લોબલ વોર્મિંગથી ધ્રુવીય બરફ પીગળે, સમુદ્ર سطح વધે, હવામાન પેટર્ન બદલાય છે.
📝 🌍 UN IPCC મુજબ 2050 સુધી કાર્બન એમિશન 45% ઘટાડવું આવશ્યક.
ઉદ્યોગીકરણ અને જંગલ કાપણીCO₂ વધારો
૫. ઓઝોન સ્તરની ખાલીપણું (Ozone Depletion)
ઓઝોન સ્તર (O₃) પૃથ્વીને હાનિકારક અલ્ટ્રાવાયોલેટ (UV) કિરણોમાંથી રક્ષણ આપે છે.
CFCs (ક્લોરોફ્લોરોકાર્બન) ઓઝોન સ્તરને નુકસાન કરનાર પ્રમુખ પ્રદૂષક છે.
CFCs વાતાવરણમાં પહોંચીને UV પ્રકાશથી વિઘટિત થાય છે → ક્લોરિન મુક્ત થાય છે.
CFCl₃ + UV → CFCl₂ + Cl· ; Cl· + O₃ → ClO· + O₂
આથી ઓઝોન સ્તર પાતળું થાય છે અને 'ઓઝોન હોલ' ઉત્પન્ન થાય છે.
📝 ✅ માન્ટ્રીઅલ પ્રોટોકોલ (1987) — CFC ઉત્પાદન ઘટાડવા માટેનો આંતરરાષ્ટ્રીય કરાર.
CFC નું મુક્તિઓઝોનની ક્ષય
૬. એસિડ વરસાદ (Acid Rain)
SO₂ અને NOₓ નું વાતાવરણમાં ઓગળી પ્રબળ એસિડ બનાવવાની પ્રક્રિયા એસિડ વરસાદ કહેવાય છે.
એસિડ વરસાદ pH 5.6 થી ઓછો ધરાવે છે — સામાન્ય વરસાદની તુલનામાં વધુ એસિડીયસ.
2SO₂ + O₂ + 2H₂O → 2H₂SO₄ (સલ્ફ્યુરિક એસિડ)
વૃક્ષો, સ્મારકો, इमारતો અને જળચર જીવોને એસિડ વરસાદ હાનિ કરે છે.
ફેક્ટરી અને વાહનોમાંથી નીકળતો ધૂમાડો એસિડ વરસાદનું પ્રમુખ પ્રદૂષક છે.
📝 🧪 pH માપન એસિડ વરસાદ ચકાસવાનો પ્રમાણભૂત રીત છે.
૭. જલ પ્રદૂષણ (Water Pollution)
નદી, તળાવ, સમુદ્ર અને ભૂગર્ભજળમાં અનિચ્છનીય પદાર્થોના પ્રવેશથી જલ પ્રદૂષણ થાય છે.
જલ પ્રદૂષણના પ્રમુખ સ્રોતો: ઘરેલુ વરjad, ઉદ્યોગોનું બાજી પાણી, કૃષિ રાસાયણિકો.
BOD (Biochemical Oxygen Demand) — જળ પ્રદૂષણ માપવાનો માપદંડ.
BOD = 5 દિવસમાં 20°C તાપમાને જળના નમૂનામાં ખપત થયેલ ઓક્સિજન (mg/L)
યુટ્રોફિકેશન — પોષક તત્વો (N, P) ના અતિપ્રવાહથી જળાયુમાં શૈવાલના વધુ પ્રમાણમાં વધારાનું કારણ.
📝 ⚡ ઓછો BOD = સ્વચ્છ જળ / વધારે BOD = પ્રદૂષિત જળ.
ફેકટરી બાજી પાણીધાતુ પ્રદૂષણ + BOD વધારો
૮. મૃદા પ્રદૂષણ અને પ્લાસ્ટિક પ્રદૂષણ
મૃદા પ્રદૂષણનો અર્થ છે માટીમાં અનિચ્છનીય પદાર્થો (રાસાયણિક ખાદ્યો, પ્લાસ્ટિક, ભારે ધાતુઓ)નું સંચય.
પ્લાસ્ટિક પ્રદૂષણ ખાસ કરીને non-biodegradable હોવાથી સમસ્યા બને છે.
મૃદા પ્રદૂષણથી ખેતિ ઉત્પાદન ઘટે છે અને પોષકતત્વોનું સંતુલન બગડે છે.
પ્લાસ્ટિક વિઘટન કાળ ≈ 100–500 વર્ષ (સંશ્લેષિત પોલિમર પર આધાર રાખીને)
પ્લાસ્ટિકના નાના કણો (Microplastics) જળ અને જમીન બન્નેમાં પ્રવેશે છે.
📝 ♻️ પ્લાસ્ટિક રીસાયકલિંગ અને બાયોડિગ્રેડેબલ વૈકલ્પિકનો વિકાસ જરૂરી.
૯. વનસ્પતિ અને પર્યાવરણ
વનસ્પતિ પર્યાવરણના સંતુલનમાં મહત્વની ભૂમિકા ભજવે છે — પ્રકાશસંશ્લેષણ દ્વારા CO₂ લે છે અને O₂ છોડે છે.
જંગલ કાપણી → CO₂ શોષણ ઘટે → ગ્લોબલ વોર્મિંગ વધે.
કુદરતી વનસ્પતિ પર્યાવરણના શુદ્ધિકરણ (Natural Purification) માં મદદરૂપ છે.
કેટલીક વનસ્પતિ પ્રદૂષકો શોષી શકે છે — ઉદા. ફર્ન અને સ્લાઇમ મોલ્સ SO₂ શોષે છે.
📝 🌳 વૃક્ષારોપણ = પર્યાવરણીય સંતુલન જાળવવાનું સરળ ઉपाय.
૧૦. પ્રદૂષણ નિયંત્રણ અને વ્યર્થ નિવારણ
પ્રદૂષણ નિયંત્રણ માટે ઉદ્યોગોમાં સ્કરબર્સ, કટર અને પાર્ક પ્રણાલીઓ અમાલમાં લે છે.
3R સિદ્ધાંત — Reduce, Reuse, Recycle — કચરાનો ઓછોમાં ઓછો સિવાય.
ઈધન વિકલ્પો (CNG, ઇલેક્ટ્રિક વાહન) — પ્રદૂષણ ઘટાડવા અસરકારક.
કંપ્લેટ કંબશન: C₈H₁₈ + 12.5O₂ → 8CO₂ + 9H₂O (CNG માટે પસંદગી)
ઉદ્યોગિક અગ્નિશામક અને ફિલ્ટર પ્રણાલીઓ ધૂમ્ર અને ધૂળ ઘટાડે છે.
