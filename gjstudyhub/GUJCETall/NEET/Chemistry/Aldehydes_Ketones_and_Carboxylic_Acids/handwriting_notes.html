ઍલ્ડિહાઇડ્સ, કેટોન્સ અને કાર્બોક્સિલિક એસિડ્સ

🧪 GUJCET — Gujarati • Chemistry • Aldehydes, Ketones and Carboxylic Acids

પ્રસ્તાવના અને નામકરણ
કાર્બોનિલ સંયોજનોમાં C=O બંધ હોય છે; આ બંધ ધ્રુવીય હોવાથી ન્યુક્લિયોફિલિક ઉમેરા પ્રક્રિયાઓ થાય છે.
ઍલ્ડિહાઇડ્સમાં કાર્બોનિલ સમૂહ છેડાના કાર્બન પર હોય છે (R-CHO); કેટોન્સમાં મધ્યમાં હોય છે (R-CO-R').
IUPAC નામકરણ: મૂળ એલ્કેનના નામમાં -ઇલ્ડિહાઇડ કે -ઓન પ્રત્યય ઉમેરો. ઉદા. મેથેન → મેથેનલ, ઇથેન → ઇથેનલ.
કાર્બોક્સિલિક એસિડ્સનું નામકરણ: -ઓઇક એસિડ પ્રત્યય. ઉદા. મેથેનોઇક એસિડ (HCOOH), ઇથેનોઇક એસિડ (CH₃COOH).
⚠ ધ્યાન રાખો: C=O ધ્રુવીય બંધ છે — C પર આંશિક ધન (δ+) અને O પર આંશિક ઋણ (δ−) વીજભાર હોય છે.
📝 📝 GUJCET ટિપ: નામકરણમાં સામાન્ય ભૂલ — કેટોનનો કાર્બોનિલ કાર્બન છેડો ન હોઈ શકે.
કાર્બોનિલ સમૂહની રચના
કાર્બોનિલ કાર્બન sp² સંકરિત હોય છે; ત્રણ σ બંધ અને એક π બંધ રચે છે.
C=O બંધની લંબાઈ લગભગ 122 pm અને C=O બંધ ઊર્જા લગભગ 745 kJ/mol હોય છે.
C=O બંધ: એક σ બંધ (sp²-sp²) + એક π બંધ (p-p અતિવ્યાપન)
કાર્બોનિલ સમૂહની આસપાસનો બંધકોણ લગભગ 120° હોય છે (ત્રિકોણીય સમતલીય રચના).
⚠ π બંધ નબળો હોય છે અને તૂટીને ન્યુક્લિયોફિલિક ઉમેરા પ્રક્રિયા આપે છે.
📝 📝 યાદ રાખો: C=O બંધ ધ્રુવીય છે, C-O એકલ બંધ કરતાં વધુ ધ્રુવીય.
ઍલ્ડિહાઇડ્સ અને કેટોન્સની તૈયારી
ઓક્સિડેશન: પ્રાથમિક ઍલકોહોલનું ઓક્સિડેશન કરીને ઍલ્ડિહાઇડ મળે છે.
R-CH₂OH + [O] → R-CHO + H₂O (PCC અથવા K₂Cr₂O₇/H₂SO₄)
દ્વિતીયક ઍલકોહોલનું ઓક્સિડેશન કરીને કેટોન મળે છે.
R-CHOH-R' + [O] → R-CO-R' + H₂O
ઍલ્કિલ બેન્ઝીનનું ઓક્સિડેશન: ટોલ્યુઇનનું ઓક્સિડેશન કરીને બેન્ઝોઇક એસિડ મળે છે.
C₆H₅-CH₃ + [O] → C₆H₅-COOH (KMnO₄/KOH, હીટ)
ઍસિડ ક્લોરાઇડનું હાઇડ્રોજનથી ઘટન (Rosenmund પ્રક્રિયા):
R-COCl + H₂ → R-CHO + HCl (Pd/BaSO₄, ક્ષારક)
⚠ Rosenmund પ્રક્રિયામાં Pd/BaSO₄ ક્ષારક તરીકે વપરાય છે — BaSO₄ Pd ની સક્રિયતા ઘટાડે છે.
📝 📝 GUJCET ટિપ: ઓલિફિનનું ઓઝોનોલિસિસથી પણ ઍલ્ડિહાઇડ/કેટોન મળે છે.
કાર્બોક્સિલિક એસિડ્સની તૈયારી
ઍલ્ડિહાઇડ્સ અને કેટોન્સનું ઓક્સિડેશન: KMnO₄ અથવા K₂Cr₂O₇/H₂SO₄ વડે.
R-CHO + 2[O] → R-COOH
ઍલ્કોહોલનું પ્રબળ ઓક્સિડેશન: પ્રાથમિક ઍલકોહોલ સીધું એસિડ બને છે.
R-CH₂OH + 2[O] → R-COOH + H₂O
નાઇટ્રાઇલ્સનું જળવિભાજન:
R-CN + 2H₂O + H⁺ → R-COOH + NH₄⁺
ગ્રિગ્નાર્ડ અભિકારક + CO₂:
R-MgX + CO₂ → R-COO⁻MgX⁺ → R-COOH (H₃O⁺)
⚠ કાર્બોક્સિલિક એસિડ્સમાં -COOH સમૂહ હોય છે; આ સમૂહ ધ્રુવીય હોવાથી હાઇડ્રોજન બંધ બનાવે છે.
📝 📝 યાદ રાખો: ગ્રિગ્નાર્ડ અભિકારક CO₂ સાથે પ્રક્રિયા કરીને એસિડ આપે છે.
ભૌતિક ગુણધર્મો
ઍલ્ડિહાઇડ્સ અને કેટોન્સના સૂક્ષ્મ સભ્યો પાણીમાં સરળતાથી દ્રાવ્ય હોય છે — હાઇડ્રોજન બંધ બનાવે છે.
કાર્બોક્સિલિક એસિડ્સના સભ્યો ઊંચા ક્વચળ બિંદુ ધરાવે છે — દ્વિતિયક હાઇડ્રોજન બંધ બનાવે છે.
બાષ્પ દબાણ: ઍલ્ડિહાઇડ/કેટોન > કાર્બોક્સિલિક એસિડ (હાઇડ્રોજન બંધને કારણે)
કાર્બોક્સિલિક એસિડ્સના દ્વિઅણુક બનાવે છે — બે -COOH સમૂહો વચ્ચે H-બંધ.
⚠ C₁ થી C₃ સુધીના એસિડ્સ પાણીમાં મિશ્રણીય છે; C₄ થી ઉપર દ્રાવ્યતા ઘટે છે.
📝 📝 GUJCET ટિપ: એસિડનું ક્વચળ બિંદુ ઍલ્ડિહાઇડ/કેટોન કરતાં વધુ હોય છે.
ન્યુક્લિયોફિલિક ઉમેરા પ્રક્રિયાઓ
કાર્બોનિલ સમૂહ પર ન્યુક્લિયોફિલ હમણાં જ ઉમેરાય છે કારણ કે C પર δ+ વીજભાર હોય છે.
HCN નો ઉમેરો: સાયનાઇડ આયન (CN⁻) ન્યુક્લિયોફિલ તરીકે કાર્બોનિલ કાર્બન પર હમણાં જ ઉમેરાય છે.
R-CHO + HCN → R-CH(OH)-CN (સાયનહિડ્રિન)
NaHSO₃ સાથે પ્રક્રિયા: સલ્ફાઇટ એડિશન ઉત્પાદન બને છે.
R-CHO + NaHSO₃ → R-CH(OH)-SO₃Na (સફેદ અવક્ષેપ)
અલ્કોહોલ સાથે પ્રક્રિયા: એસિટલ/કેટલ બનાવે છે.
R-CHO + 2R'OH → R-CH(OR')₂ + H₂O (એસિટલ, HCl ગેસ ઉપસ્થિતિમાં)
⚠ એસિટલ બનાવતી વખતે સૂકા HCl ગેસનો ઉપયોગ થાય છે — આ પ્રક્રિયા ઉલટાવી શકાય તેવી છે.
📝 📝 યાદ રાખો: ન્યુક્લિયોફિલિક ઉમેરા પ્રક્રિયાઓ ઍલ્ડિહાઇડ્સમાં કેટોન્સ કરતાં વધુ સરળ થાય છે.
એમિન સાથે પ્રક્રિયાઓ
પ્રાથમિક એમિન સાથે પ્રક્રિયા કરીને ઇમિન (શિફ્ફ બેઝ) બને છે.
R-CHO + R'NH₂ → R-CH=N-R' + H₂O (ઇમિન / શિફ્ફ બેઝ)
અમોનિયા સાથે પ્રક્રિયા: અસ્થિર ઇમિન બને છે જે આગળ પ્રક્રિયા કરી શકે છે.
R-CHO + NH₃ → R-CH=N-H + H₂O
⚠ ઇમિનમાં C=N બંધ હોય છે; આ પ્રક્રિયામાં પાણીનું અણુ બહાર નીકળે છે.
📝 📝 GUJCET ટિપ: ઇમિન અને ઇમિડોઝ પ્રક્રિયાઓ ઓર્ગેનિક સંશ્લેષણમાં મહત્વની છે.
ઓક્સિડેશન પ્રક્રિયાઓ
ઍલ્ડિહાઇડ્સ સરળતાથી ઓક્સિડેશન પામે છે — કેટોન્સ મુશ્કેલથી ઓક્સિડેશન પામે છે.
R-CHO + [O] → R-COOH (K₂Cr₂O₇/H₂SO₄ વડે)
ટોલેન્સ પ્રક્રિયા: ઍલ્ડિહાઇડ Ag⁺ ને Ag માં ઘટાડે છે — અરીસો બને છે.
R-CHO + 2[Ag(NH₃)₂]⁺ + 3OH⁻ → R-COO⁻ + 2Ag↓ + 4NH₃ + 2H₂O
ફેહલિંગ પ્રક્રિયા: ઍલ્ડિહાઇડ Cu²⁺ ને Cu₂O (લાલ અવક્ષેપ) માં ઘટાડે છે.
R-CHO + 2Cu²⁺ + 5OH⁻ → R-COO⁻ + Cu₂O↓ + 3H₂O
⚠ ટોલેન્સ અને ફેહલિંગ પ્રક્રિયા ફક્ત ઍલ્ડિહાઇડ્સ માટે — કેટોન્સ આ પ્રક્રિયા આપતા નથી.
📝 📝 યાદ રાખો: બેન્ઝોઇક એસિડ બનાવવા માટે ટોલ્યુઇનનું ઓક્સિડેશન થાય છે.
રિડક્શન પ્રક્રિયાઓ
ઍલ્ડિહાઇડ્સનું રિડક્શન કરીને પ્રાથમિક ઍલકોહોલ મળે છે.
R-CHO + 2[H] → R-CH₂OH (NaBH₄ અથવા LiAlH₄ વડે)
કેટોન્સનું રિડક્શન કરીને દ્વિતીયક ઍલકોહોલ મળે છે.
R-CO-R' + 2[H] → R-CHOH-R' (NaBH₄ અથવા LiAlH₄ વડે)
કેનિગ્ઝર રિડક્શન: Zn(Hg)/HCl વડે કાર્બોનિલ સમૂહને CH₂ માં ફેરવો.
R-CO-R' + 4[H] → R-CH₂-R' + H₂O (Zn(Hg)/HCl)
ક્લેમેન્સન રિડક્શન: Cd(Hg)/HCl વડે પણ કાર્બોનિલને CH₂ માં ફેરવો.
R-CO-R' + 4[H] → R-CH₂-R' + H₂O (Cd(Hg)/HCl)
⚠ કેનિગ્ઝર અને ક્લેમેન્સન રિડક્શન બંને C=O ને CH₂ માં ફેરવે છે — પરંતુ અલગ અલગ અભિકારકો વડે.
📝 📝 GUJCET ટિપ: NaBH₄ નરમ રિડ્યુસિંગ એજન્ટ છે; LiAlH₄ પ્રબળ છે.
α-હાઇડ્રોજન અને એસિડિક સ્વભાવ
કાર્બોનિલ સમૂહની બાજુમાંનો α-કાર્બન પરના H પરમાણુઓ સક્રિય હોય છે.
α-હાઇડ્રોજન એસિડિક સ્વભાવ ધરાવે છે — બેઝ દ્વારા દૂર કરી શકાય છે.
R-CH₂-CHO + B⁻ → R-CH⁻-CHO + BH (એનોનિયન બને છે)
એનોનિયન સ્થાયી થાય છે — રેઝોનન્સ દ્વારા.
R-CH⁻-CHO ↔ R-CH=C(O⁻)-O (રેઝોનન્સ સ્થાયિતા)
⚠ α-હાઇડ્રોજનની હાજરી વિના એલ્ડિહાઇડ/કેટોન એસિડિક પ્રક્રિયા આપતા નથી.
📝 📝 યાદ રાખો: α-હાઇડ્રોજન સક્રિય હોવાથી એસિડિક ગુણધર્મ દેખાય છે.
એલ્ડોલ સંયોજન
એલ્ડિહાઇડ/કેટોન જેમાં α-હાઇડ્રોજન હોય તે NaOH/KOH વડે પ્રક્રિયા કરે છે.
2R-CH₂-CHO → R-CH₂-CH(OH)-CH(R)-CHO (β-હાઇડ્રોક્સિ ઍલ્ડિહાઇડ)
ઉત્પાદનને એલ્ડોલ કહે છે — આ પ્રક્રિયાને એલ્ડોલ સંયોજન કહે છે.
એલ્ડોલનું નિર્જલીકરણ કરીને α,β-અસંતૃત ઍલ્ડિહાઇડ મળે છે.
R-CH₂-CH(OH)-CH(R)-CHO → R-CH₂-C(R)=CH-CHO + H₂O (ઉષ્મા વડે)
⚠ એલ્ડોલ સંયોજન માટે α-હાઇડ્રોજન હોવો જરૂરી છે; HCHO અને (CH₃)₃C-CHO માં α-H નથી.
📝 📝 GUJCET ટિપ: એલ્ડોલ સંયોજન C-C બંધ રચવાની મહત્વની પ્રક્રિયા છે.
કેનિગ્ઝર અને ક્લેમેન્સન રિડક્શન
કેનિગ્ઝર રિડક્શન: Zn(Hg) + conc. HCl વડે C=O ને CH₂ માં ફેરવો.
R-CO-R' + 4[H] → R-CH₂-R' + H₂O (Zn(Hg)/conc. HCl)
ક્લેમેન્સન રિડક્શન: Cd(Hg) + conc. HCl વડે પણ સમાન પરિણામ.
R-CO-R' + 4[H] → R-CH₂-R' + H₂O (Cd(Hg)/conc. HCl)
⚠ બંને રિડક્શનમાં C=O સમૂહ સંપૂર્ણપણે CH₂ માં ફેરવાય છે — આ પ્રક્રિયાઓ મહત્વની છે.
📝 📝 યાદ રાખો: કેનિગ્ઝર રિડક્શનમાં Zn(Hg) વપરાય છે; ક્લેમેન્સનમાં Cd(Hg) વપરાય છે.
કાર્બોક્સિલિક એસિડ્સના રાસાયણિક ગુણધર્મો
એસિડિક ગુણધર્મ: કાર્બોક્સિલિક એસિડ્સ બેઝ સાથે પ્રક્રિયા કરી લવણ અને પાણી બનાવે છે.
R-COOH + NaOH → R-COONa + H₂O
બાઇકાર્બોનેટ સાથે પ્રક્રિયા: CO₂ વાયુ મુક્ત થાય છે.
R-COOH + NaHCO₃ → R-COONa + H₂O + CO₂↑
એસિડ ક્લોરાઇડ બનાવવા: PCl₅ અથવા SOCl₂ વડે.
R-COOH + SOCl₂ → R-COCl + SO₂ + HCl
⚠ કાર્બોક્સિલિક એસિડ્સ બેઝ સાથે પ્રક્રિયા કરીને લવણ બનાવે છે — આ એસિડિક સ્વભાવ દર્શાવે છે.
📝 📝 GUJCET ટિપ: NaHCO₃ સાથે પ્રક્રિયાથી CO₂ ની છાણી મળે છે — આ એસિડની ઓળખ છે.
એસિડના રિડક્શન અને ઓક્સિડેશન
LiAlH₄ વડે કાર્બોક્સિલિક એસિડનું રિડક્શન કરીને પ્રાથમિક ઍલકોહોલ મળે છે.
R-COOH + 4[H] → R-CH₂OH + H₂O (LiAlH₄)
કાર્બોક્સિલિક એસિડ્સનું ઓક્સિડેશન થતું નથી — કારણ કે COOH સમૂહમાં C પર હાઇડ્રોજન નથી.
સોડા લાઇમ સાથે ગરમ કરવાથી એલ્કેન મળે છે (ડિકાર્બોક્સિલિકરણ).
R-COONa + NaOH/CaO → R-H + Na₂CO₃
⚠ ડિકાર્બોક્સિલિકરણ પ્રક્રિયામાં CO₂ બહાર નીકળે છે અને એલ્કેન બને છે.
📝 📝 યાદ રાખો: સોડા લાઇમ (NaOH + CaO) વડે ડિકાર્બોક્સિલિકરણ થાય છે.
હેલોજનિકરણ પ્રક્રિયા (હાલોજેન)
કાર્બોક્સિલિક એસિડના α-કાર્બન પર હાલોજન ઉમેરાય છે — હાલોજેનિક એસિડ બને છે.
R-CH₂-COOH + X₂ → R-CHX-COOH + HX (P પર ઉપસ્થિતિમાં)
હાલોજેનિક એસિડનું જળવિભાજન કરીને હાઇડ્રોક્સિ એસિડ મળે છે.
R-CHX-COOH + H₂O → R-CHOH-COOH + HX
⚠ હાલોજેનિકરણ પ્રક્રિયામાં P (ફોસ્ફરસ) ઉત્પ્રેરક તરીકે વપરાય છે.
📝 📝 GUJCET ટિપ: હાલોજેનિક એસિડ્સ ઓર્ગેનિક સંશ્લેષણમાં મધ્યવર્તી પદાર્થો છે.
કાર્બોક્સિલિક એસિડ્સના ઉપયોગો
ઇથેનોઇક એસિડ (એસિટિક એસિડ): સિરકા તરીકે વપરાય છે; એસિટિક એનહાઇડ્રાઇડ બનાવવા માટે.
બેન્ઝોઇક એસિડ: ખોરાક સંરક્ષક તરીકે વપરાય છે; બેન્ઝોઇલ ક્લોરાઇડ બનાવવા માટે.
ઓક્સાલિક એસિડ: ધાતુઓ સાફ કરવા અને રંગ કાઢવા માટે વપરાય છે.
સ્ટીઅરિક એસિડ અને પાલમિટિક એસિડ: સબ્બૂન અને મોમબત્તી બનાવવા માટે.
⚠ કાર્બોક્સિલિક એસિડ્સ ઔદ્યોગિક રીતે ખૂબ મહત્વના છે — પ્લાસ્ટિક, દવાઓ, સંશ્લેષિત રેસા બનાવવામાં.
📝 📝 યાદ રાખો: એસિટિક એસિડનું IUPAC નામ ઇથેનોઇક એસિડ છે.
ઍલ્ડિહાઇડ્સ અને કેટોન્સના ઉપયોગો
ફોર્મલ્ડિહાઇડ (મેથેનલ): ફોર્માલિન તરીકે વપરાય છે; પ્લાસ્ટિક અને રેઝિન બનાવવા માટે.
એસિટાલ્ડિહાઇડ (ઇથેનલ): સંશ્લેષિત રેસા અને દવાઓ બનાવવા માટે.
એસિટોન (પ્રોપેનોન): સૌથી સામાન્ય કેટોન; દ્રાવક તરીકે વપરાય છે.
બેન્ઝોઇક એસિડ: ખોરાક સંરક્ષક તરીકે; એન્ટિમાલેરિયલ દવા બનાવવા માટે.
⚠ એસિટોન પાણી, ઍલ્કોહોલ અને ઇથરમાં મિશ્રણીય છે — આ તેનું મહત્વનું ગુણધર્મ છે.
📝 📝 GUJCET ટિપ: ફોર્મલ્ડિહાઇડનું દ્રાવણ ફોર્માલિન કહેવાય છે.
મહત્વની પ્રક્રિયાઓનો સારાંશ
ન્યુક્લિયોફિલિક ઉમેરા: HCN, NaHSO₃, અલ્કોહોલ, એમિન સાથે.
ઓક્સિડેશન: ઍલ્ડિહાઇડ્સ → એસિડ; કેટોન્સ → મુશ્કેલ ઓક્સિડેશન.
રિડક્શન: ઍલ્ડિહાઇડ → પ્રાથમિક ઍલકોહોલ; કેટોન → દ્વિતીયક ઍલકોહોલ.
એલ્ડોલ સંયોજન: α-હાઇડ્રોજન ધરાવતા સંયોજનોનું બેઝ વડે સંયોજન.
કેનિગ્ઝર/ક્લેમેન્સન: C=O → CH₂ રિડક્શન.
⚠ આ પ્રક્રિયાઓ GUJCET માટે ખૂબ મહત્વની છે — દરેક પ્રક્રિયાનું નામ અને ઉત્પાદન યાદ રાખો.
📝 📝 અંતિમ ટિપ: કાર્બોનિલ સમૂહની પ્રક્રિયાઓનું મુખ્ય સિદ્ધાંત — ન્યુક્લિયોફિલિક ઉમેરા.
