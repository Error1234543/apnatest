⚡ સૂત્રો

આયનીય બંધ બનવાની પ્રક્રિયા: M → M⁺ + e⁻ (આયનીકરણ ઊર્જા), X + e⁻ → X⁻ (ઇલેક્ટ્રોન આકર્ષણતા)
M = ધાતુ પરમાણુ, X = અધાતુ પરમાણુ, e⁻ = ઇલેક્ટ્રોન · SI: kJ/mol (આયનીકરણ ઊર્જા), kJ/mol (ઇલેક્ટ્રોન આકર્ષણતા) · ધાતુ અને અધાતુ વચ્ચે ઇલેક્ટ્રોનના સ્થાનાંતરણથી
બોન્ડ લંબાઈ: r = r_A + r_B (સહસંયોજક બંધ માટે)
r = બંધ લંબાઈ, r_A = A પરમાણુની સહસંયોજક ત્રિજ્યા, r_B = B પરમાણુની સહસંયોજક ત્રિજ્યા · SI: pm (પિકોમીટર) અથવા Å (એંગસ્ટ્રોમ) · સમાણુ બંધ માટે, જ્યાં બંધ લંબાઈ બંધકારક પરમાણુઓની ત્રિજ્યાના સરવાળા બરાબર
બોન્ડ એન્થાલ્પી (બંધ વિઘટન ઊર્જા): ΔH = Σ(બંધ તૂટવાની ઊર્જા) - Σ(બંધ બનવાની ઊર્જા)
ΔH = પ્રક્રિયાનો એન્થાલ્પી ફેરફાર, બંધ તૂટવાની ઊર્જા = ધન (ઊર્જા શોષાય), બંધ બનવાની ઊર્જા = ઋણ (ઊર્જા મુક્ત) · SI: kJ/mol · બધા જ બંધો એકસમાન હોય ત્યારે, સામાન્ય તાપમાને
બોન્ડ ઓર્ડર (MO સિદ્ધાંત મુજબ): બોન્ડ ઓર્ડર = (બંધનકારક ઇલેક્ટ્રોન - વિરોધી બંધનકારક ઇલેક્ટ્રોન) / 2
બંધનકારક ઇલેક્ટ્રોન = σ અથવા π બંધનકારક કક્ષકમાં ઇલેક્ટ્રોન, વિરોધી બંધનકારક ઇલેક્ટ્રોન = σ* અથવા π* વિરોધી બંધનકારક કક્ષકમાં ઇલેક્ટ્રોન · SI: એકમરહિત (સંખ્યા) · આણ્વીય કક્ષક સિદ્ધાંત (MOT) માટે, બધા જ આણ્વો માટે
આણ્વીય ચુંબકીય ગુણધર્મ (MOT): અયુગ્મિત ઇલેક્ટ્રોનની સંખ્યા > 0 → ચુંબકીય (પેરામેગ્નેટિક), અયુગ્મિત ઇલેક્ટ્રોન = 0 → અચુંબકીય (ડાયમેગ્નેટિક)
અયુગ્મિત ઇલેક્ટ્રોન = એકલું રહેલું ઇલેક્ટ્રોન, પેરામેગ્નેટિક = ચુંબક દ્વારા આકર્ષાતું, ડાયમેગ્નેટિક = ચુંબક દ્વારા વિકર્ષાતું · SI: એકમરહિત · આણ્વીય કક્ષકોમાં ઇલેક્ટ્રોન ભરવા પછી
VSEPR — આણ્વીય આકાર નક્કી કરવાનું સૂત્ર: સ્ટેરિક નંબર = (કેન્દ્રીય પરમાણુના વેલેન્સ ઇલેક્ટ્રોન + એક પરમાણુઓની સંખ્યા - ધન આયન ચાર્જ + ઋણ આયન ચાર્જ) / 2
સ્ટેરિક નંબર = સંયોજક કક્ષકોની સંખ્યા, કેન્દ્રીય પરમાણુ = જે પરમાણુ કેન્દ્રમાં હોય, એક પરમાણુ = બંધાયેલા પરમાણુઓની સંખ્યા, ચાર્જ = આયનિક ચાર્જ · SI: એકમરહિત (પૂર્ણાંક) · VSEPR સિદ્ધાંત મુજબ આણ્વીય આકાર નક્કી કરવા
સંક્રમણ અવસ્થા (Hybridization) નક્કી કરવી: સ્ટેરિક નંબર = 2 → sp, 3 → sp², 4 → sp³, 5 → sp³d, 6 → sp³d²
sp = એક s + એક p કક્ષકનું સંક્રમણ, sp² = એક s + બે p, sp³ = એક s + ત્રણ p, sp³d = એક s + ત્રણ p + એક d, sp³d² = એક s + ત્રણ p + બે d · SI: એકમરહિત · કેન્દ્રીય પરમાણુની સંક્રમણ અવસ્થા નક્કી કરવા
બોન્ડ એંગલ (VSEPR મુજબ): sp³ → 109.5°, sp² → 120°, sp → 180° (આદર્શ), લોન પેર હોય ત્યારે બોન્ડ એંગલ ઘટે
બોન્ડ એંગલ = બે બંધ વચ્ચેનું ખૂણો, લોન પેર = અબંધનકારક ઇલેક્ટ્રોન જોડો, sp³/sp²/sp = સંક્રમણ અવસ્થા · SI: ડિગ્રી (°) · આદર્શ આણ્વીય આકાર માટે, લોન પેર હોય ત્યારે ખૂણો ઘટે છે
લોન પેર અપવર્તન ક્રમ (VSEPR): લોન-લોન અપવર્તન > લોન-બોન્ડ અપવર્તન > બોન્ડ-બોન્ડ અપવર્તન
લોન પેર = અબંધનકારક ઇલેક્ટ્રોન જોડો, બોન્ડ પેર = બંધનકારક ઇલેક્ટ્રોન જોડો, અપવર્તન = ઇલેક્ટ્રોન જોડા વચ્ચેનું વિકર્ષણ · SI: એકમરહિત (ક્રમ) · લોન પેર હોય ત્યારે બોન્ડ એંગલમાં ઘટાડો થાય
બંધ ધ્રુવીયતા (Bond Polarity): ΔEN = |EN_A - EN_B|, જો ΔEN > 0.4 → ધ્રુવીય, જો ΔEN < 0.4 → અધ્રુવીય, જો ΔEN > 1.7 → આયનીય
ΔEN = ઇલેક્ટ્રોનેગેટિવિટી તફાવત, EN_A = પરમાણુ A ની વિદ્યુતઋણતા, EN_B = પરમાણુ B ની વિદ્યુતઋણતા · SI: એકમરહિત (પાઉલિંગ સ્કેલ) · બે પરમાણુ વચ્ચેના બંધનો પ્રકાર નક્કી કરવા
આણ્વીય ધ્રુવીયતા (Dipole Moment): μ = q × d, જ્યાં q = વિદ્યુતભાર, d = ભાર કેન્દ્ર વચ્ચેનું અંતર
μ = ડાયપોલ મોમેન્ટ, q = આંશિક વિદ્યુતભાર, d = ભાર કેન્દ્ર વચ્ચેનું અંતર · SI: Debye (D), 1 D = 3.336 × 10⁻³⁰ C·m · ધ્રુવીય બંધ ધરાવતા આણ્વો માટે, સંમિત આકાર હોય તો μ = 0
રેઝોનન્સ (અનુનાદ) — સંરચનાઓની સંખ્યા: અનુનાદી સંરચનાઓ = એવા બધા લેવિસ બંધારણો જેમાં ફક્ત ઇલેક્ટ્રોનની ગતિ હોય, પરમાણુઓની ગતિ ન હોય
અનુનાદી સંરચના = રેઝોનન્સ હાયપોથેસિસ મુજબનું લેવિસ બંધારણ, ઇલેક્ટ્રોન ગતિ = π ઇલેક્ટ્રોન અથવા લોન પેરની વિસ્થાપન · SI: એકમરહિત (સંખ્યા) · જ્યારે π બંધ અને લોન પેર પાસપાસે હોય અથવા ત્રિવેલેન્સી હોય
પરમાણુ કક્ષક સંયોજન (LCAO): ψ_bonding = ψ_A + ψ_B, ψ_antibonding = ψ_A - ψ_B
ψ_bonding = બંધનકારક આણ્વીય કક્ષક, ψ_antibonding = વિરોધી બંધનકારક આણ્વીય કક્ષક, ψ_A = પરમાણુ કક્ષક A, ψ_B = પરમાણુ કક્ષક B · SI: એકમરહિત (તરંગ ફંક્શન) · બે પરમાણુ કક્ષકોના સંયોજનથી આણ્વીય કક્ષક બને
સિગ્મા (σ) અને પાય (π) બંધ: σ બંધ = s-s, s-p, p-p (અક્ષીય અધિવેશન), π બંધ = p-p (પાર્શ્વ અધિવેશન)
σ બંધ = પ્રથમ બંધ (મજબૂત), π બંધ = દ્વિતીય/તૃતીય બંધ (નબળો), અક્ષીય અધિવેશન = બંધ અક્ષ પર, પાર્શ્વ અધિવેશન = બંધ અક્ષની બહાર · SI: એકમરહિત · સહસંયોજક બંધના પ્રકારો
બોન્ડ ઓર્ડર (લેવિસ બંધારણ મુજબ): બોન્ડ ઓર્ડર = (બંધની કુલ સંખ્યા) / (બંધિત જોડીઓની સંખ્યા)
બોન્ડ ઓર્ડર = બંધની મજબૂતાઈ સૂચક, બંધની કુલ સંખ્યા = σ + π બંધો, બંધિત જોડીઓ = બે પરમાણુ વચ્ચેના બંધ · SI: એકમરહિત · લેવિસ બંધારણમાં એક જ બંધ હોય તો બોન્ડ ઓર્ડર = 1, દ્વિબંધ = 2, ત્રિબંધ = 3
આયનીય બંધની ઊર્જા (લેન્સ-કાર્પે સૂત્ર): E ∝ (Q₁ × Q₂) / r, જ્યાં Q = આયનિક ચાર્જ, r = આયનો વચ્ચેનું અંતર
E = આયનીય બંધ ઊર્જા, Q₁ = ધન આયન ચાર્જ, Q₂ = ઋણ આયન ચાર્જ, r = આયનો વચ્ચેનું અંતર · SI: kJ/mol · આયનીય ઘન પદાર્થોની લેટિસ ઊર્જા માટે
કોઓર્ડિનેટ બંધ (દંડ બંધ): A → B (જ્યાં A ઇલેક્ટ્રોન જોડો દાન કરે, B સ્વીકારે)
A = દાતા પરમાણુ (લોન પેર ધરાવતો), B = ગ્રાહક પરમાણુ (ખાલી કક્ષક ધરાવતો), → = કોઓર્ડિનેટ બંધ · SI: એકમરહિત · એક પરમાણુ પાસે લોન પેર હોય અને બીજા પાસે ખાલી કક્ષક હોય
સંક્રમણ અવસ્થા અને આણ્વીય આકાર: sp³ + 4 બંધ + 0 લોન → ચતુષ્ફલકીય (109.5°), sp³ + 3 બંધ + 1 લોન → ત્રિકોણીય પિરામિડ (107°), sp³ + 2 બંધ + 2 લોન → વક્ર આકાર (104.5°)
લોન = અબંધનકારક ઇલેક્ટ્રોન જોડો, ચતુષ્ફલકીય = Tetrahedral, ત્રિકોણીય પિરામિડ = Trigonal pyramidal, વક્ર = Bent · SI: ડિગ્રી (°) · VSEPR મુજબ આણ્વીય આકાર
MO ઊર્જા ક્રમ (O₂, F₂ માટે): σ1s < σ*1s < σ2s < σ*2s < σ2pz < π2px = π2py < π*2px = π*2py < σ*2pz
σ = સિગ્મા બંધનકારક, σ* = સિગ્મા વિરોધી બંધનકારક, π = પાય બંધનકારક, π* = પાય વિરોધી બંધનકારક, 1s/2s/2p = મુખ્ય કક્ષક · SI: એકમરહિત (ઊર્જા ક્રમ) · Z ≥ 8 (O, F, Ne) માટે
MO ઊર્જા ક્રમ (N₂, C₂ માટે): σ1s < σ*1s < σ2s < σ*2s < π2px = π2py < σ2pz < π*2px = π*2py < σ*2pz
π2px = π2py = સમાન ઊર્જા ધરાવતી કક્ષકો, σ2pz = સિગ્મા 2p_z બંધનકારક · SI: એકમરહિત (ઊર્જા ક્રમ) · Z < 8 (B, C, N) માટે
બંધ લંબાઈ અને બોન્ડ ઓર્ડર સંબંધ: બોન્ડ ઓર્ડર ↑ → બંધ લંબાઈ ↓ (વ્યસ્ત સંબંધ)
બોન્ડ ઓર્ડર = બંધની મજબૂતાઈ, બંધ લંબાઈ = બે પરમાણુ કેન્દ્ર વચ્ચેનું અંતર · SI: pm અથવા Å · એક જ પ્રકારના પરમાણુઓ વચ્ચેના બંધો માટે
બંધ ઊર્જા અને બંધ લંબાઈ સંબંધ: બંધ લંબાઈ ↑ → બંધ ઊર્જા ↓ (વ્યસ્ત સંબંધ)
બંધ ઊર્જા = બંધ તોડવા માટે જરૂરી ઊર્જા, બંધ લંબાઈ = બે પરમાણુ વચ્ચેનું અંતર · SI: kJ/mol (બંધ ઊર્જા), pm (લંબાઈ) · સમાન પ્રકારના બંધો માટે
આણ્વીય ધ્રુવીયતા (વેક્ટર સરવાળો): μ_net = μ₁ + μ₂ + μ₃ + ... (વેક્ટર સરવાળો, દિશા ધ્યાનમાં લઈ)
μ_net = કુલ ડાયપોલ મોમેન્ટ, μ₁, μ₂ = વ્યક્તિગત બંધ ડાયપોલ, વેક્ટર સરવાળો = દિશા સાથેનો સરવાળો · SI: Debye (D) · એકથી વધુ ધ્રુવીય બંધ ધરાવતા આણ્વો માટે
રેઝોનન્સ સ્થિરતા: અનુનાદી સંરચનાઓની સંખ્યા ↑ → સ્થિરતા ↑, સમાન ઊર્જાની સંરચનાઓ ↑ → સ્થિરતા વધુ
અનુનાદી સંરચના = રેઝોનન્સ હાયપોથેસિસ મુજબનું બંધારણ, સ્થિરતા = ઊર્જામાં ઘટાડો · SI: એકમરહિત · જ્યારે બે અથવા વધુ લેવિસ બંધારણો શક્ય હોય
આયનીય બંધ — ઇલેક્ટ્રોન વિન્યાસ: ધાતુ (કમ્બલ વિન્યાસ) → ઇલેક્ટ્રોન ગુમાવી → ધન આયન (નિસ્સાર્ગિક ગેસ વિન્યાસ)
કમ્બલ વિન્યાસ = વેલેન્સ કક્ષકમાં ઓછા ઇલેક્ટ્રોન, નિસ્સાર્ગિક ગેસ વિન્યાસ = ns²np⁶ (8 ઇલેક્ટ્રોન) · SI: એકમરહિત · આયનીય બંધ બનતી વખતે
સહસંયોજક બંધ — ઓક્ટેટ નિયમ: પરમાણુ = 8 વેલેન્સ ઇલેક્ટ્રોન ધરાવે (He સિવાય = 2)
ઓક્ટેટ = 8 ઇલેક્ટ્રોન, વેલેન્સ ઇલેક્ટ્રોન = બાહ્યતમ કક્ષકના ઇલેક્ટ્રોન · SI: એકમરહિત (ઇલેક્ટ્રોન સંખ્યા) · સહસંયોજક બંધ બનતી વખતે, બધા પરમાણુઓ ઓક્ટેટ પૂર્ણ કરે
હાયબ્રિડ કક્ષકોની સંખ્યા: હાયબ્રિડ કક્ષકોની સંખ્યા = સંક્રમણમાં ભાગ લેતી પરમાણુ કક્ષકોની સંખ્યા
હાયબ્રિડ કક્ષક = સંક્રમિત પરમાણુ કક્ષકોનું સંયોજન, પરમાણુ કક્ષક = s, p, d કક્ષક · SI: એકમરહિત (સંખ્યા) · સંક્રમણ અવસ્થા દરમિયાન
π બંધોની સંખ્યા (બોન્ડ ઓર્ડર મુજબ): દ્વિબંધ = 1 σ + 1 π, ત્રિબંધ = 1 σ + 2 π
σ = સિગ્મા બંધ, π = પાય બંધ, દ્વિબંધ = બે પરમાણુ વચ્ચે બે બંધ, ત્રિબંધ = ત્રણ બંધ · SI: એકમરહિત (બંધોની સંખ્યા) · બોન્ડ ઓર્ડર 2 અથવા 3 હોય ત્યારે

🔗 સંબંધો

  • બોન્ડ ઓર્ડર અને બંધ લંબાઈ વ્યસ્ત સંબંધ ધરાવે છે — બોન્ડ ઓર્ડર વધે તો બંધ લંબાઈ ઘટે છે
  • બંધ ઊર્જા અને બંધ લંબાઈ વ્યસ્ત સંબંધ ધરાવે છે — લંબાઈ ઘટે તો ઊર્જા વધે છે
  • લોન પેરની સંખ્યા વધે તો બોન્ડ એંગલ ઘટે છે (VSEPR)
  • આણ્વીય ધ્રુવીયતા બંધ ધ્રુવીયતા અને આણ્વીય આકાર બંને પર આધારિત છે — સંમિત આકાર હોય તો μ_net = 0
  • બોન્ડ ઓર્ડર વધે તો બંધ મજબૂત બને છે અને લંબાઈ ઘટે છે
  • આયનીય બંધની લેટિસ ઊર્જા આયનિક ચાર્જના ગુણાકારના સમપ્રમાણ અને આયનો વચ્ચેના અંતરના વ્યસ્ત પ્રમાણમાં હોય છે
  • સંક્રમણ અવસ્થામાં હાયબ્રિડ કક્ષકોની સંખ્યા હંમેશા મૂળ પરમાણુ કક્ષકોની સંખ્યા બરાબર હોય છે

🎯 ટ્રિક્સ

બોન્ડ ઓર્ડર ગણતરી: MOT માટે (બંધનકારક - વિરોધી બંધનકારક)/2, લેવિસ માટે સીધો બંધ ગણો
VSEPR સ્ટેરિક નંબર: (કેન્દ્રીય V.E. + એક પરમાણુ - ધન ચાર્જ + ઋણ ચાર્જ)/2 — યાદ રાખો: ધન ચાર્જ = ઇલેક્ટ્રોન ઓછા, ઋણ ચાર્જ = ઇલેક્ટ્રોન વધુ
σ બંધ = હંમેશા પ્રથમ બંધ, π બંધ = દ્વિતીય/તૃતીય — દ્વિબંધમાં 1σ+1π, ત્રિબંધમાં 1σ+2π
MO ઊર્જા ક્રમ યાદ રાખવા: N₂ સુધી π2p σ2p કરતા નીચે, O₂ થી આગળ σ2p π2p કરતા નીચે — 'N સુધી π નીચે, O થી σ નીચે'
લોન પેર અપવર્તન ક્રમ: લોન-લોન > લોન-બોન્ડ > બોન્ડ-બોન્ડ — આ ક્રમ યાદ રાખો: 'લોન વધુ અપવર્તે છે'
sp³d અને sp³d² માટે: 5 સ્ટેરિક = sp³d (ત્રિકોણીય બિપિરામિડ), 6 સ્ટેરિક = sp³d² (અષ્ટફલકીય)
આણ્વીય ધ્રુવીયતા: CO₂ (રેખીય, સંમિત) → μ=0, H₂O (વક્ર, અસંમિત) → μ≠0 — આકાર જોઈને નક્કી કરો

⚠️ ભૂલો

બોન્ડ ઓર્ડર ગણતરીમાં વિરોધી બંધનકારક ઇલેક્ટ્રોન ભૂલથી બાદ કરવાને બદલે ઉમેરી દેવા
VSEPR માં સ્ટેરિક નંબર ગણતરીમાં ધન આયન ચાર્જ ઉમેરી દેવો (ઘટાડવો જોઈએ) અથવા ઋણ ચાર્જ બાદ કરી દેવો (ઉમેરવો જોઈએ)
σ અને π બંધની સંખ્યા ગણતરીમાં દ્વિબંધને 2 σ + 1 π માની લેવો (સાચું: 1 σ + 1 π)
MO ઊર્જા ક્રમમાં N₂ અને O₂ માટે ક્રમ અલગ હોય છે તે ભૂલી જવો — બંને માટે એક જ ક્રમ લાગુ પાડવો
આણ્વીય ધ્રુવીયતા ગણતરીમાં વેક્ટર સરવાળો કર્યા વિના બંધ ધ્રુવીયતાનો સરવાળો કરી દેવો
લોન પેરની સંખ્યા ગણતરીમાં કેન્દ્રીય પરમાણુના વેલેન્સ ઇલેક્ટ્રોનમાંથી બંધ બનાવવાના ઇલેક્ટ્રોન બાદ ન કરવા
બોન્ડ એંગલમાં sp³d (ત્રિકોણીય બિપિરામિડ) માટે 90° અને 120° બંને ખૂણા હોય છે તે ભૂલી જવો
રેઝોનન્સ સંરચનાઓમાં પરમાણુઓની સ્થિતિ બદલી દેવી (ફક્ત ઇલેક્ટ્રોન જ ગતિ કરી શકે, પરમાણુ નહીં)
O₂ નું ચુંબકીય ગુણધર્મ ભૂલથી ડાયમેગ્નેટિક માની લેવું (સાચું: પેરામેગ્નેટિક — 2 અયુગ્મિત ઇલેક્ટ્રોન)
