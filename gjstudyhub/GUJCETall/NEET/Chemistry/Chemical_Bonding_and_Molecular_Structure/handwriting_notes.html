રાસાયણિક બંધ અને અણુક રચના (Chemical Bonding and Molecular Structure)

🧪 GUJCET — Gujarati • Chemistry • Chemical Bonding and Molecular Structure

પ્રસ્તાવના (Introduction)
પરમાણુઓ એકબીજા સાથે જોડાઈને અણુઓ બનાવે છે — આ જોડાણને 'રાસાયણિક બંધ' કહે છે.
બંધ બનવાનું મુખ્ય કારણ: પરમાણુઓ સ્થિરતા પ્રાપ્ત કરવા માટે નિષ્ક્રિય વાયુ જેવી ઇલેક્ટ્રોન ગોઠવણી (Octet rule) મેળવવા ઇચ્છે છે.
⚡ બંધ બનવા પાછળનો મુખ્ય ઉદ્દેશ્ય: ઓછીમાં ઓછી ઊર્જા ધરાવતો સ્થિર અણુ બનાવવો.
રાસાયણિક બંધના મુખ્ય પ્રકારો: આયનીય બંધ, સહસંયોજક બંધ, કોઓર્ડિનેટ બંધ, ધાત્વિક બંધ.
ઓક્ટેટ નિયમ (Octet Rule)
લેન્યુસ (Lewis) અને કોલરેજ (Kossel) દ્વારા પ્રસ્તાવિત: પરમાણુઓ તેમના બાહ્યતમ કક્ષકમાં 8 ઇલેક્ટ્રોન (અથવા H, He માટે 2) મેળવવા ઇચ્છે છે.
નિષ્ક્રિય વાયુઓ (Noble gases) ની ઇલેક્ટ્રોન ગોઠવણી સૌથી વધુ સ્થિર હોય છે.
⚡ ઓક્ટેટ નિયમની મર્યાદાઓ: H₂O, BF₃, PCl₅, SF₆ જેવા સંયોજનોમાં ઓક્ટેટનું ઉલ્લંઘન થાય છે.
ઇલેક્ટ્રોનની અયુગ્મિત સંખ્યા ધરાવતા અણુઓ (જેમ કે NO) માં ઓક્ટેટ પૂરો નથી થતો.
સંક્રાંતિ ધાતુઓ અને ભારે તત્વોમાં વેલેન્સ કક્ષકમાં d-કક્ષકો હોવાથી ઓક્ટેટનું ઉલ્લંઘન શક્ય બને છે.
આયનીય બંધ (Ionic Bond)
એક અથવા વધુ ઇલેક્ટ્રોનના સંપૂર્ણ સ્થાનાંતરણથી બનતો બંધ આયનીય બંધ છે.
સામાન્ય રીતે ધાતુ (ધન આયન / કેટાયન) અને અધાતુ (ઋણ આયન / એનાયન) વચ્ચે બને છે.
Na → Na⁺ + e⁻ | Cl + e⁻ → Cl⁻ | Na⁺ + Cl⁻ → NaCl
આયનીય બંધ બનવા માટે ધાતુનું આયનીકરણ વિભવ (Ionization Enthalpy) ઓછું અને અધાતુનું ઇલેક્ટ્રોન સંયોજકતા (Electron Gain Enthalpy) વધુ ઋણ હોવી જરૂરી છે.
⚡ લેટિસ ઊર્જા (Lattice Energy): આયનીય ઘનમાં ધન અને ઋણ આયનો એકમ કોષમાં એકબીજા સાથે જોડાય ત્યારે મુક્ત થતી ઊર્જા.
લેટિસ ઊર્જા ∝ (Q₁ × Q₂) / r, જ્યાં Q આયનોના વિદ્યુતભાર અને r આયનો વચ્ચેનું અંતર છે.
📝 📝 ફ્રાન્સ-કાઉલી ચક્ર (Born-Haber Cycle) દ્વારા લેટિસ ઊર્જાની ગણતરી કરી શકાય છે.
આયનીય સંયોજનોના ગુણધર્મો: ઊંચું દ્રવણ બિંદુ, ઊંચું ઉત્કલન બિંદુ, ઘન અવસ્થામાં વિદ્યુતના વાહક નહીં પણ દ્રાવણ/ગલિત અવસ્થામાં વાહક.
સહસંયોજક બંધ (Covalent Bond)
બે પરમાણુઓ વચ્ચે ઇલેક્ટ્રોન જોડીના સામાન્યીકરણ (Sharing) થવાથી બનતો બંધ સહસંયોજક બંધ છે.
ગેર-ધાતુ પરમાણુઓ વચ્ચે સહસંયોજક બંધ બને છે.
H· + ·H → H:H (H₂) | ·Cl· + ·Cl· → Cl:Cl (Cl₂)
સહસંયોજક બંધની દિશાત્મકતા (Directional nature): સહસંયોજક બંધ ચોક્કસ દિશામાં બને છે, જે અણુની આકૃતિ નક્કી કરે છે.
⚡ સહસંયોજક બંધ બે પ્રકારના: એકલ બંધ (Single), દ્વિબંધ (Double), ત્રિબંધ (Triple).
એકલ બંધ = 1 σ (સિગ્મા) બંધ, દ્વિબંધ = 1 σ + 1 π (પાઈ) બંધ, ત્રિબંધ = 1 σ + 2 π બંધ.
σ-બંધ: અક્ષીય અધિવાપન (Axial overlap) થી બને છે, વધુ મજબૂત. π-બંધ: પાર્શ્વીય અધિવાપન (Lateral overlap) થી બને છે, ઓછો મજબૂત.
📝 📝 σ-બંધ π-બંધ કરતાં વધુ મજબૂત હોય છે કારણ કે અધિવાપન વધુ હોય છે.
કોઓર્ડિનેટ બંધ (Coordinate Bond)
જ્યારે એક પરમાણુ પોતાની એકલ ઇલેક્ટ્રોન જોડી બીજા પરમાણુને દાન કરે છે, ત્યારે બનતો બંધ કોઓર્ડિનેટ બંધ છે.
બંધ દાન કરનારા પરમાણુને 'દાતા' (Donor) અને બંધ પ્રાપ્ત કરનારાને 'સ્વીકારનાર' (Acceptor) કહે છે.
NH₃ + BF₃ → H₃N→BF₃ (N દાતા, B સ્વીકારનાર)
⚡ કોઓર્ડિનેટ બંધને 'દ્વિધ્રુવીય સહસંયોજક બંધ' પણ કહે છે. બંધ દર્શાવવા → ચિહ્ન વપરાય છે.
H₃O⁺, NH₄⁺, SO₄²⁻ જેવા આયનોમાં કોઓર્ડિનેટ બંધ જોવા મળે છે.
📝 📝 કોઓર્ડિનેટ બંધ બન્યા પછી તે સામાન્ય સહસંયોજક બંધ જેવો જ વર્તે છે.
બંધ પરિમાણો (Bond Parameters)
બંધ લંબાઈ (Bond Length): બે પરમાણુઓના કેન્દ્ર વચ્ચેનું સરેરાશ અંતર.
બંધ લંબાઈ ∝ પરમાણુ કદ / બંધ ક્રમ (Bond Order) ∝ 1/બંધ શક્તિ.
બંધ ક્રમ = (બંધમાં રહેલા ઇલેક્ટ્રોનની સંખ્યા) / (બંધના પરમાણુઓની સંખ્યા)
બંધ શક્તિ (Bond Enthalpy): એક મોલ બંધ તોડવા માટે જરૂરી ઊર્જા. બંધ શક્તિ જેટલી વધારે, બંધ તેટલો મજબૂત.
⚡ બંધ લંબાઈ: N≡N < N=N < N−N | બંધ શક્તિ: N−N < N=N < N≡N
બંધ કોણ (Bond Angle): બે બંધો વચ્ચેનો કોણ. અણુની આકૃતિ નક્કી કરવામાં મહત્વપૂર્ણ.
બંધ ઘનતા (Bond Density): બે પરમાણુઓ વચ્ચે ઇલેક્ટ્રોન મળી આવવાની સંભાવના.
ધ્રુવીયતા અને વિદ્યુતઋણતા (Polarity & Electronegativity)
વિદ્યુતઋણતા (Electronegativity): પરમાણુ સહસંયોજક બંધમાં ઇલેક્ટ્રોન જોડીને પોતાની તરફ ખેંચવાની ક્ષમતા.
પોલિંગ (Pauling) સ્કેલ પર F સૌથી વધુ વિદ્યુતઋણ (4.0) અને Cs/Fr સૌથી ઓછી વિદ્યુતઋણ (~0.7).
⚡ ΔEN > 1.7 → આયનીય બંધ | 0.5 < ΔEN < 1.7 → ધ્રુવીય સહસંયોજક | ΔEN < 0.5 → અધ્રુવીય સહસંયોજક
ધ્રુવીય સહસંયોજક બંધમાં ઇલેક્ટ્રોન જોડી વિદ્યુતઋણ પરમાણુની તરફ વળે છે, જેથી આંશિક વિદ્યુતભાર (δ⁺/δ⁻) ઉત્પન્ન થાય છે.
દ્વિધ્રુવ આઘૂર્ણ (Dipole Moment, μ): μ = q × d, એકમ: Debye (D). 1 D = 3.3356 × 10⁻³⁰ C·m.
📝 📝 CO₂ માં બંધ ધ્રુવીય છે પણ અણુ અધ્રુવીય છે (રેખીય આકૃતિ → દ્વિધ્રુવ આઘૂર્ણ શૂન્ય).
લેટસ્ટર સંકેત (Lewis Structure)
લેટસ્ટર સંકેતમાં પરમાણુનું સંયોજકતા ઇલેક્ટ્રોન બિંદુઓ દ્વારા દર્શાવવામાં આવે છે.
સહસંયોજક બંધને સરલ રેખા (—) દ્વારા અને એકલ ઇલેક્ટ્રોન જોડીને બિંદુઓ દ્વારા દર્શાવવામાં આવે છે.
અનુનાદ (Resonance): જ્યારે એક જ અણુને એકથી વધુ લેટસ્ટર સંકેતથી દર્શાવી શકાય, ત્યારે વાસ્તવિક અણુ 'અનુનાદ હાઇબ્રિડ' હોય છે.
⚡ O₃ અને benzene (C₆H₆) માં અનુનાદ જોવા મળે છે. બંધ લંબાઈ સમાન હોય છે.
અનુનાદ સ્થિરતા: અનુનાદ હાઇબ્રિડ એકલ લેટસ્ટર સંકેત કરતાં વધુ સ્થિર હોય છે.
VSEPR સિદ્ધાંત (Valence Shell Electron Pair Repulsion Theory)
વેલેન્સ શેલ ઇલેક્ટ્રોન જોડીઓ એકબીજાથી દૂર રહે છે કારણ કે તેઓ ઋણ વિદ્યુતભારિત હોય છે અને પરસ્પર અપાકર્ષણ કરે છે.
ઇલેક્ટ્રોન જોડીઓ વચ્ચેનું અપાકર્ષણ ક્રમ: Lone pair–Lone pair > Lone pair–Bond pair > Bond pair–Bond pair.
Steric Number = (સંયોજકતા ઇલેક્ટ્રોન + પરમાણુઓની સંખ્યા - ધન વિદ્યુતભાર + ઋણ વિદ્યુતભાર) / 2
⚡ SN=2 → રેખીય (180°) | SN=3 → ત્રિકોણીય સમતલીય (120°) | SN=4 → ચતુષ્ફલકીય (109.5°)
H₂O: SN=4, 2 બંધ જોડી + 2 એકલ જોડી → વક્રી (Bent) આકૃતિ, બંધ કોણ ≈ 104.5°
NH₃: SN=4, 3 બંધ જોડી + 1 એકલ જોડી → ત્રિકોણીય પિરામિડ, બંધ કોણ ≈ 107°
📝 📝 એકલ જોડીનું અપાકર્ષણ વધુ હોવાથી બંધ કોણ સામાન્ય ચતુષ્ફલકીય કોણ (109.5°) કરતાં ઓછો થાય છે.
BF₃: SN=3, શુદ્ધ ત્રિકોણીય સમતલીય, બંધ કોણ 120°
CH₄: SN=4, શુદ્ધ ચતુષ્ફલકીય, બંધ કોણ 109.5°
સંકરણ (Hybridization)
સમાન અથવા નજીકની ઊર્જા ધરાવતી પરમાણુ કક્ષકોનું મિશ્રણ થઈને સમાન ઊર્જા ધરાવતા નવા સંકર કક્ષકો બનાવે છે.
સંકરણની સંખ્યા = σ-બંધની સંખ્યા + એકલ ઇલેક્ટ્રોન જોડીની સંખ્યા = Steric Number
⚡ sp³ → ચતુષ્ફલકીય (109.5°) | sp² → ત્રિકોણીય સમતલીય (120°) | sp → રેખીય (180°)
CH₄: C નું sp³ સંકરણ, 4 σ-બંધ, ચતુષ્ફલકીય આકૃતિ.
C₂H₄ (Ethene): દરેક C નું sp² સંકરણ, 1 π-બંધ + 4 σ-બંધ, ત્રિકોણીય સમતલીય.
C₂H₂ (Ethyne): દરેક C નું sp સંકરણ, 2 π-બંધ + 3 σ-બંધ, રેખીય.
NH₃: N નું sp³ સંકરણ, 3 σ-બંધ + 1 એકલ જોડી → ત્રિકોણીય પિરામિડ.
📝 📝 સંકર કક્ષકોમાં ઇલેક્ટ્રોન ઘનતા એક બાજુએ વધુ હોય છે, જેથી અધિવાપન વધુ અસરકારક બને છે.
અણુક કક્ષક સિદ્ધાંત (Molecular Orbital Theory — MOT)
જ્યારે બે પરમાણુ કક્ષકોનું અધિવાપન થાય છે ત્યારે બે અણુક કક્ષકો (Molecular Orbitals) બને છે: બંધક (Bonding) અને પ્રતિબંધક (Antibonding).
બંધ ક્રમ = (N_b − N_a) / 2, જ્યાં N_b = બંધક કક્ષકમાં ઇલેક્ટ્રોન, N_a = પ્રતિબંધક કક્ષકમાં ઇલેક્ટ્રોન
⚡ બંધ ક્રમ > 0 → અણુ સ્થિર | બંધ ક્રમ = 0 → અણુ અસ્થિર | બંધ ક્રમ જેટલો વધારે, બંધ તેટલો મજબૂત.
σ1s < σ*1s < σ2s < σ*2s < σ2p_z < π2p_x = π2p_y < π*2p_x = π*2p_y < σ*2p_z (B₂, C₂, N₂ માટે)
σ1s < σ*1s < σ2s < σ*2s < π2p_x = π2p_y < σ2p_z < π*2p_x = π*2p_y < σ*2p_z (O₂, F₂ માટે)
O₂: KK σ2s² σ*2s² σ2p_z² π2p_x² π2p_y² π*2p_x¹ π*2p_y¹ → બંધ ક્રમ = 2, ચુંબકીય: ઉત્ચુંબકીય (Paramagnetic)
N₂: KK σ2s² σ*2s² π2p_x² π2p_y² σ2p_z² → બંધ ક્રમ = 3, ચુંબકીય: પ્રતિચુંબકીય (Diamagnetic)
He₂: બંધ ક્રમ = 0 → અણુ અસ્થિર, અસ્તિત્વ નથી.
📝 📝 MOT O₂ ના ઉત્ચુંબકીય ગુણધર્મની સફળતાપૂર્વક સમજાવે છે, જે વેલેન્સ બોન્ડ થિયરી સમજાવી શકતી નથી.
હાઈડ્રોજન બંધ (Hydrogen Bond)
જ્યારે હાઈડ્રોજન પરમાણુ બે ઉચ્ચ વિદ્યુતઋણ પરમાણુઓ (F, O, N) વચ્ચે સેતુ બનીને જોડાય છે ત્યારે હાઈડ્રોજન બંધ બને છે.
⚡ હાઈડ્રોજન બંધ સહસંયોજક બંધ કરતાં ઓછો મજબૂત પણ વાન ડર વાલ્સ બળ કરતાં વધુ મજબૂત છે.
આંતર-અણુક હાઈડ્રોજન બંધ: બે અણુઓ વચ્ચે (જેમ કે HF, H₂O).
આંતર-અણુક હાઈડ્રોજન બંધ: એક જ અણુની અંદર (જેમ કે o-nitrophenol).
H₂O માં હાઈડ્રોજન બંધને કારણે બर्फ (Ice) ની ઘનતા પાણી કરતાં ઓછી હોય છે → બर्फ પાણી પર તરે છે.
📝 📝 H-F, H₂O, NH₃ માં હાઈડ્રોજન બંધ સૌથી પ્રબળ છે. HCl, H₂S, PH₃ માં હાઈડ્રોજન બંધ નથી.
હાઈડ્રોજન બંધને કારણે H₂O, HF, NH₃ ના ઉત્કલન બિંદુ અપેક્ષિત મૂલ્ય કરતાં વધુ છે.
ધાત્વિક બંધ (Metallic Bond)
ધાતુમાં ધન આયનોની જાળીમાં મુક્ત ઇલેક્ટ્રોનની સમુદ્ર (Sea of electrons) હોય છે, જે ધાત્વિક બંધ બનાવે છે.
ધાત્વિક બંધ અદિશાત્મક (Non-directional) હોય છે.
⚡ ધાત્વિક બંધને કારણે ધાતુઓ વિદ્યુત અને ઉષ્માની સારી વાહક, આકર્ષણીય (Malleable) અને તન્ય (Ductile) હોય છે.
ધાત્વિક બંધની શક્તિ ધાતુના આયનના વિદ્યુતભાર અને કદ પર આધારિત છે.
