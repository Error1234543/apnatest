જીવરસાયણો (Biomolecules) — ક્વિક રિવિઝન શીટ

🧪 GUJCET — Gujarati • Chemistry • Biomolecules

🧠 યાદ રાખો

કાર્બોહાઇડ્રેટ્સ (Carbohydrates) — C, H, O ધરાવતાં સંયોજનો, સૂત્ર (CH₂O)ₙ, ઉર્જાનો પ્રાથમિક સ્ત્રોત.
મોનોસેકેરાઇડ્સ (Monosaccharides) — સરળ શર્કરા (ગ્લુકોઝ, ફ્રક્ટોઝ), C₆H₁₂O₆ સૂત્ર.
ડાયસેકેરાઇડ્સ (Disaccharides) — સુક્રોઝ (C₁₂H₂₂O₁₁), લેક્ટોઝ, મોલ્ટોઝ — હાઇડ્રોલિસિસથી મોનોસેકેરાઇડ્સ મળે.
પોલીસેકેરાઇડ્સ (Polysaccharides) — સ્ટાર્ચ (અમાઇલોઝ + એમિલોપેક્ટિન), સેલ્યુલોઝ (β-ગ્લુકોઝ એકમો), ગ્લાઇકોજન (પ્રાણી સ્ટાર્ચ).
પ્રોટીન — અમીનો એસિડના પોલિમર, પેપ્ટાઇડ બંધ (–CO–NH–) દ્વારા જોડાયેલા.
અમીનો એસિડ — NH₂ અને COOH સમૂહ ધરાવતાં સંયોજનો, ઝ્વીટરઆયન (Zwitterion) રૂપે અસ્તિત્વ.
પ્રોટીનની રચના: પ્રાથમિક (અમીનો એસિડ ક્રમ), દ્વિતીય (α-હેલિક્સ, β-પ્લીટ), તૃતીય (3D આકાર), ચતુર્થ (સબયુનિટ્સ).
એન્ઝાઇમ્સ — જૈવ ઉત્પ્રેરક, સક્રિય સ્થાન (Active site) ધરાવે, તાપમાન અને pH પ્રત્યે સંવેદનશીલ.
લિપિડ્સ — ચરબી, તેલ, વેક્સ, ફોસ્ફોલિપિડ્સ — હાઇડ્રોફોબિક, ઉર્જા સંગ્રહ અને સેલ મેમ્બ્રેનનો ભાગ.
ન્યુક્લિક એસિડ — DNA (ડિઑક્સીરિબોઝ), RNA (રિબોઝ), ન્યુક્લિયોટાઇડ (ફોસ્ફેટ + શર્કરા + નાઇટ્રોજન બેઇઝ)ના બનેલા.
વિટામિન — A, D, E, K (ચરબીમાં દ્રાવ્ય), B, C (પાણીમાં દ્રાવ્ય) — ઉત્પ્રેરક તરીકે કામ કરતાં નથી પરંતુ જરૂરી છે.

⚡ ઝડપી સૂત્રો

ગ્લુકોઝનું આણ્વીય સૂત્ર: C₆H₁₂O₆
સુક્રોઝનું હાઇડ્રોલિસિસ: C₁₂H₂₂O₁₁ + H₂O → C₆H₁₂O₆ (ગ્લુકોઝ) + C₆H₁₂O₆ (ફ્રક્ટોઝ)
પેપ્ટાઇડ બંધ રચના: NH₂–CHR–COOH + NH₂–CHR–COOH → –CO–NH– (પાણીનું નિકાલ)
DNA ના ન્યુક્લિયોટાઇડ: ડિઑક્સીરિબોઝ + ફોસ્ફેટ + (A, T, C, G)
RNA ના ન્યુક્લિયોટાઇડ: રિબોઝ + ફોસ્ફેટ + (A, U, C, G)

✅ વન-લાઈનર્સ

સ્ટાર્ચ — વનસ્પતિમાં ઉર્જા સંગ્રહ, આયોડિન સાથે નીલો રંગ આપે.
સેલ્યુલોઝ — વનસ્પતિ કોષભિત્તિનો મુખ્ય ઘટક, માનવ પાચન તંત્ર દ્વારા પચતો નથી.
ગ્લાઇકોજન — પ્રાણીઓમાં ગ્લુકોઝનો સંગ્રહ સ્વરૂપ, યકૃત અને સ્નાયુઓમાં મળે.
પ્રોટીનની ડિનેચરલાઇઝેશન — તાપમાન, pH અથવા રાસાયણિક પદાર્થો દ્વારા આકાર ગુમાવવો.
એન્ઝાઇમ્સની ક્રિયા — સબસ્ટ્રેટ + એન્ઝાઇમ → એન્ઝાઇમ-સબસ્ટ્રેટ કોમ્પ્લેક્સ → ઉત્પાદન + એન્ઝાઇમ (અવિભાજ્ય).
વિટામિન C — સ્કર્વી રોગ અટકાવે, સિટ્રસ ફળોમાં પ્રચુર.
વિટામિન D — સૂર્યપ્રકાશથી ત્વચામાં સિંથેસ થાય, કેલ્શિયમ શોષણમાં મદદરૂપ.
