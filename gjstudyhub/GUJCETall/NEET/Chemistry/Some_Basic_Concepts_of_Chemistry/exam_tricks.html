GUJCET – Some Basic Concepts of Chemistry: Exam Tricks

🧪 GUJCET — Gujarati • Chemistry • Some Basic Concepts of Chemistry

🎯 પરીક્ષા ટ્રિક્સ

Mole = Given mass ÷ Molar mass — જ્યારે પણ પરમાણુ/આણ્વીય દળ આપેલ હોય ત્યારે mass → moles પછી જ કુદરતી રીતે અન્ય કંઈ પણ શક્ય બને છે; બધી ગણતરીઓનો આધાર આ એક અસમાનતા છે.
જ્યારે પ્રશ્નમાં કોઈ પણ પદાર્થનું દળ અને તેનું M या R મૂલ્ય આપેલ હોય, ત્યારે સૌથી પહેલાં મોલ શોધો; તેના બાદ Molarity, Volume, Number of particles, % composition કઈ પણ ગણો.
દા.ત.: 4.6 g Na (R = 23 g mol⁻¹): n = 4.6/23 = 0.2 mol. હવે 0.2 × 6.022×10²³ = 1.204×10²³ પરમાણુઓ.
Molecules → atoms easy multiplier: દરેક molecule માં એકદમ નાના અંકો (H₂O → 3, CO₂ → 3, CH₄ → 5, P₄ → 5) હોય છે, એટલે total atoms = molecules × atoms/molecule તરત જ થઈ શકે.
જ્યારે પ્રશ્ન 'X molecules of compound Y contain how many total atoms?' પૂછે. ગણતરી ઝડપી થાય.
દા.ત.: 9 g H₂O → 0.5 mol → 3.011×10²³ molecules. Each H₂O has 3 atoms. Total atoms = 9.033×10²³.
Limiting reagent shortcut: દરેક પ્રક્રિયકનો (Given moles ÷ stoichiometric coefficient) ગુણોત્તર કાઢો, જેનો ગુણોત્તર નાનો હોય તે limiting reagent છે.
જ્યારે બે અથવા વધુ પ્રક્રિયકો આપેલ હોય અને product નું દળ/moles પૂછવામાં આવ્યું હોય.
દા.ત.: 2 mol A + 3 mol B → A₂B સમીકરણ: A માટે 2/1 = 2, B માટે 3/2 = 1.5. B નો ગુણોત્તર નાનો → B limiting reagent.
Significant figures in addition/subtraction: દશાંશના પછીના સૌથી ઓછા અંકો ધરાવતી સંખ્યા જેટલા જ અંકો જવાબમાં હોવા જોઈએ. Multiplication/division માં સૌથી ઓછા significant figures ધરાવતી સંખ્યા જેટલા જ રહે.
જ્યારે મોલર mass, density, বা concentration ની ગણતરીમાં rounding નક્કી કરવી હોય.
દા.ત.: 12.11 + 0.32 + 1.245 → સૌથી ઓછા decimal places = 2 (0.32 માં). જવાબ = 13.67.
Molarity ↔ Normality quick conversion: N = M × n-factor (basicity/acidity/base sites). એકેડ-બેઝમાં n-factor એ H⁺/OH⁻ આપતા/લેતા પરમાણુઓની સંખ્યા છે.
જ્યારે પ્રશ્નમાં Molarity આપી Normality પૂછે અથવા વળતર, ખાસकर Titrations માં.
દા.ત.: 0.5 M H₂SO₄: n-factor = 2 (દो H⁺). N = 0.5 × 2 = 1.0 N. Same for Ca(OH)₂ with 2 OH⁻.
Empirical formula quick check: જો Molecular mass ÷ Empirical mass = whole number (n), તો Molecular formula = (Empirical formula)ₙ. જો n = 1 હોય તો બંને સમાન.
જ્યારે Empirical formula અને Molecular mass બંને આપેલ હોય અને Molecular formula શોધવાનું હોય.
દા.ત.: Empirical CH₂, Molecular mass = 42. Empirical mass = 14. n = 42/14 = 3. Molecular formula = C₃H₆.
Gas at STP volume shortcut: 1 mole કોઈ પણ આદર્શ વાયુ = 22.7 L at STP. Given volume ÷ 22.7 = moles; moles × 22.7 = volume. ઝડપી ગણતરી.
જ્યારે વાયુનું volume આપેલ હોય અને mass મોલ શોધવાના હોય અથવા વિપરીત.
દા.ત.: 11.35 L O₂ at STP → n = 11.35/22.7 = 0.5 mol. Mass = 0.5 × 32 = 16 g.
Percentage composition shortcut: (न्यूक्लियस mass contributed by atom × number of atoms / Molecular mass) × 100. Per atom contribution straightforward, then multiply.
જ્યારે compound માં કોઈ એક તત્વનું ટકાવારી ઘટક શોધવાનું હોય.
દા.ત.: H₂O (M = 18): %H = (2×1/18)×100 = 11.11%. %O = (16/18)×100 = 88.89%.
Density–Molar mass relation: ρ = PM/RT → M = ρRT/P. જો density (ρ) અને temperature/pressure આપેલા હોય, તો molar mass તરત જ શોધી શકાય.
જ્યારે વાયુનું density, pressure અને temperature આપેલ હોય અને molar mass શોધવાનું હોય.
દા.ત.: ρ = 1.25 g/L at STP: M = (1.25 × 0.0821 × 273)/1 ≈ 28 g/mol (N₂).
Avogadro number shortcut uses: 1 amu = 1 g/mol relation. Any atomic/molecular mass in amu નું મૂલ્ય same numerical value in g/mol. એટલે R values તરત જ યાદ.
જ્યારે atomic mass data table માં amu માં હોય પણ g/mol માં જોઈએ, અથવા reverse.
દા.ત.: C = 12.01 amu → M(C) = 12.01 g/mol. O = 16.00 amu → M(O) = 16.00 g/mol.
Molality vs Molarity distinction trick: Molality (m) = moles solute / kg solvent — temperature independent. Molarity (M) = moles solute / L solution — changes with temperature. જે પ્રશ્ન temperature change સાથે સંકળાયેલો હોય, તો molality વાપરો.
જ્યારે પ્રશ્નમાં temperature variation નો સંદર્ભ હોય અથવા colligative properties ની તૈયારી હોય.
દા.ત.: 25°C → 50°C heated: Molarity બદલાય (volume expands), but Molality unchanged. Question asks which remains constant? Answer: Molality.
Law of reciprocal proportions quick use: If A combines with B in ratio x:y and A combines with C in ratio x:z, then B combines with C in ratio y:z. Direct ratio comparison.
જ્યારે three elements A, B, C અને તેમના binary compounds ના mass ratios આપેલ હોય અને reciprocal proportion test કરવાનું હોય.
દા.ત.: N combines with H (NH₃): 14:3. N combines with O (NO₂): 14:32. So H combines with O in ratio 3:32 (from H₂O: 2:16 = 1:8 = 3:24… adjust for consistency, test holds qualitatively).
Oxidation state quick assignment: Free element = 0. Monoatomic ion = its charge. O usually –2 (except peroxides –1, OF₂ +2). H usually +1 (except metal hydrides –1). Sum = 0 for neutral, = ion charge for ions.
જ્યારે any compound માં某个 element નું oxidation number શોધવાનું હોય — especially for redox stoichiometry questions.
દા.ત.: K₂Cr₂O₇: 2(+1) + 2(x) + 7(–2) = 0 → 2 + 2x – 14 = 0 → x = +6 for Cr.
Equivalent weight = Molar mass / n-factor. For acids n-factor = basicity (replaceable H⁺). For bases n-factor = acidity (OH⁻). For salts n-factor = total positive/negative charge. For redox n-factor = electron change.
જ્યારે equivalent mass, gram equivalent, અથવા titration calculations માં નીચેનું équivalent concept लागू થાય.
દા.ત.: H₃PO₄ (M = 98): n-factor = 3 (three replaceable H⁺). Eq. wt. = 98/3 = 32.67 g eq⁻¹.
Mole fraction sum = 1: x_A + x_B + x_C + … = 1. जर दोन component चे mole fractions विचारले असतील, तर एक शोधून दुसरा = 1 – first. Double-check tool.
જ્યારે solution માં multiple components હોય અને keવળ એક mole fraction શોધવાનું હોય; અથવા answer validation માટે.
દા.ત.: x_ethanol = 0.3 → x_water = 1 – 0.3 = 0.7. Sum must equal 1; if not, calculation error.
