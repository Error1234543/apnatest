s-બ્લોક તત્વો (s-Block Elements) — સૂત્ર શીટ

🧪 GUJCET — Gujarati • Chemistry • s-Block Elements

⚡ સૂત્રો

સમૂહ ૧ (ધાત્વીય એલકલી) તત્વોની ઇલેક્ટ્રોનિક વિન્યાસ: [નિષ્ક્રિય વાયુ] ns¹
n = મુખ્ય કક્ષા સંખ્યા, s = સબશેલ · SI: — · સમૂહ ૧ (Li, Na, K, Rb, Cs, Fr) માટે
સમૂહ ૨ (એલકલાઇન એર્થ ધાતુ) તત્વોની ઇલેક્ટ્રોનિક વિન્યાસ: [નિષ્ક્રિય વાયુ] ns²
n = મુખ્ય કક્ષા સંખ્યા, s = સબશેલ · SI: — · સમૂહ ૨ (Be, Mg, Ca, Sr, Ba, Ra) માટે
આયનીકરણ એન્થાલ્પી પ્રવૃત્તિ (સમૂહમાં ઉપરથી નીચે): IE₁ (ઉપર) > IE₁ (નીચે)
IE₁ = પ્રથમ આયનીકરણ એન્થાલ્પી · SI: kJ mol⁻¹ · સમૂહમાં નીચે જતાં પરમાણુ કદ વધે છે, આદર્શ આકર્ષણ ઘટે છે
જળવિભાજન એન્થાલ્પી (Hydration Enthalpy) પ્રવૃત્તિ: ΔH_hyd ∝ 1/r² (આયની ત્રિજ્યા)
ΔH_hyd = જળવિભાજન એન્થાલ્પી, r = આયની ત્રિજ્યા · SI: kJ mol⁻¹ · નાના આયનની જળવિભાજન એન્થાલ્પી વધુ ઋણ હોય છે
સમૂહ ૧ માં જળવિભાજન એન્થાલ્પી ક્રમ: ΔH_hyd(Li⁺) > ΔH_hyd(Na⁺) > ΔH_hyd(K⁺) > ΔH_hyd(Rb⁺) > ΔH_hyd(Cs⁺)
Li⁺, Na⁺, K⁺, Rb⁺, Cs⁺ = ધાત્વીય એલકલી આયનો · SI: kJ mol⁻¹ · આયની ત્રિજ્યા વધતા જળવિભાજન એન્થાલ્પી ઘટે છે
સમૂહ ૨ માં જળવિભાજન એન્થાલ્પી ક્રમ: ΔH_hyd(Be²⁺) > ΔH_hyd(Mg²⁺) > ΔH_hyd(Ca²⁺) > ΔH_hyd(Sr²⁺) > ΔH_hyd(Ba²⁺)
Be²⁺, Mg²⁺, Ca²⁺, Sr²⁺, Ba²⁺ = એલકલાઇન એર્થ આયનો · SI: kJ mol⁻¹ · આયની ત્રિજ્યા વધતા જળવિભાજન એન્થાલ્પી ઘટે છે
દ્રવ્યમાન પ્રમાણે ઓક્સિજન સાથે પ્રક્રિયા (સોડિયમ): 2Na + O₂ → Na₂O₂ (સોડિયમ પરોક્સાઇડ)
Na = સોડિયમ, O₂ = ઓક્સિજન, Na₂O₂ = સોડિયમ પરોક્સાઇડ · SI: — · ઓક્સિજનની વધુ માત્રામાં, ઉષ્મા આપતા
સોડિયમ ક્લોરાઇડનું બ્રાવર-લંડ બેલ્સ પ્રક્રિયા (સંલેપન): NaCl + NH₃ + CO₂ + H₂O → NaHCO₃ + NH₄Cl
NaCl = સોડિયમ ક્લોરાઇડ, NH₃ = એમોનિયા, CO₂ = કાર્બન ડાયોક્સાઇડ · SI: — · સોડા-એસિડ પ્રક્રિયા (Solvay process) — પ્રથમ પગલું
સોડિયમ બાયકાર્બોનેટનું ઉષ્મીય વિઘટન: 2NaHCO₃ → Na₂CO₃ + H₂O + CO₂
NaHCO₃ = સોડિયમ બાયકાર્બોનેટ, Na₂CO₃ = સોડિયમ કાર્બોનેટ · SI: — · ગરમી આપતા (ઉષ્મીય વિઘટન)
સોડિયમ કાર્બોનેટનું જળાવશોષણ (સોડા વોશિંગ સોડા): Na₂CO₃·10H₂O
Na₂CO₃ = સોડિયમ કાર્બોનેટ, 10H₂O = ૧૦ જળ અણુઓ · SI: — · સોડિયમ કાર્બોનેટ ટેટ્રાડેકાહાઇડ્રેટ
કેલ્શિયમ કાર્બોનેટનું ઉષ્મીય વિઘટન (ચૂના પથ્થર): CaCO₃ → CaO + CO₂
CaCO₃ = કેલ્શિયમ કાર્બોનેટ, CaO = કેલ્શિયમ ઓક્સાઇડ (ચૂનું) · SI: — · ઉચ્ચ તાપમાને (કાલ્સિનેશન)
કેલ્શિયમ ઓક્સાઇડનું જળ સાથે પ્રક્રિયા: CaO + H₂O → Ca(OH)₂
CaO = કેલ્શિયમ ઓક્સાઇડ, Ca(OH)₂ = કેલ્શિયમ હાઇડ્રોક્સાઇડ · SI: — · ચૂનું પાણીમાં મિશ્ર કરતાં
કેલ્શિયમ હાઇડ્રોક્સાઇડનું CO₂ સાથે પ્રક્રિયા: Ca(OH)₂ + CO₂ → CaCO₃ + H₂O
Ca(OH)₂ = કેલ્શિયમ હાઇડ્રોક્સાઇડ, CaCO₃ = કેલ્શિયમ કાર્બોનેટ · SI: — · ચૂના પાણી (Lime water) ની પરીક્ષા
બેરિયમ ક્લોરાઇડ સાથે સલ્ફેટ આયનની પરીક્ષા: BaCl₂ + SO₄²⁻ → BaSO₄↓ + 2Cl⁻
BaCl₂ = બેરિયમ ક્લોરાઇડ, BaSO₄ = બેરિયમ સલ્ફેટ (સફેદ અવક્ષેપ) · SI: — · સલ્ફેટ આયનની ગુણાત્મક પરીક્ષા
પોટેશિયમ પરમાણુનું જળ સાથે પ્રક્રિયા: 2K + 2H₂O → 2KOH + H₂
K = પોટેશિયમ, KOH = પોટેશિયમ હાઇડ્રોક્સાઇડ, H₂ = હાઇડ્રોજન · SI: — · ધાત્વીય એલકલી જળ સાથે પ્રક્રિયા
મેગ્નેશિયમનું જળ સાથે પ્રક્રિયા (ઉત્તપ્ત જળ): Mg + 2H₂O → Mg(OH)₂ + H₂
Mg = મેગ્નેશિયમ, Mg(OH)₂ = મેગ્નેશિયમ હાઇડ્રોક્સાઇડ · SI: — · ઉત્તપ્ત જળ (Steam) સાથે પ્રક્રિયા
બેરિલિયમ અને એલ્યુમિનિયમ વચ્ચેની વિકર્ણ સંબંધ (Diagonal Relationship): Be ≈ Al (ગુણધર્મોમાં સમાનતા)
Be = બેરિલિયમ, Al = એલ્યુમિનિયમ · SI: — · વિકર્ણ સંબંધ — સમૂહ ૨ અને સમૂહ ૧૩ વચ્ચે
લિથિયમ અને મેગ્નેશિયમ વચ્ચેનો વિકર્ણ સંબંધ: Li ≈ Mg (ગુણધર્મોમાં સમાનતા)
Li = લિથિયમ, Mg = મેગ્નેશિયમ · SI: — · વિકર્ણ સંબંધ — સમૂહ ૧ અને સમૂહ ૨ વચ્ચે
સોડિયમ હાઇડ્રોક્સાઇડનું ઉદ્યોગધોરણે ઉત્પાદન (ક્લોર-એલ્કલી પ્રક્રિયા): 2NaCl + 2H₂O → 2NaOH + Cl₂ + H₂
NaCl = સોડિયમ ક્લોરાઇડ, NaOH = સોડિયમ હાઇડ્રોક્સાઇડ, Cl₂ = ક્લોરિન, H₂ = હાઇડ્રોજન · SI: — · વિદ્યુતવિભાજન (Electrolysis) — ક્લોર-એલ્કલી પ્રક્રિયા
પોટેશિયમ પરોક્સાઇડનું જળ સાથે પ્રક્રિયા: 2KO₂ + 2H₂O → 2KOH + H₂O₂ + O₂
KO₂ = પોટેશિયમ પરોક્સાઇડ, H₂O₂ = હાઇડ્રોજન પરોક્સાઇડ · SI: — · પોટેશિયમ પરોક્સાઇડ જળ સાથે પ્રક્રિયા
કેલ્શિયમ કાર્બોનેટનું હાઇડ્રોક્સિપેલાઇટમાં રૂપાંતર (દાંત): Ca₁₀(PO₄)₆(OH)₂ → હાઇડ્રોક્સિપેલાઇટ
Ca₁₀(PO₄)₆(OH)₂ = કેલ્શિયમ હાઇડ્રોક્સિપેલાઇટ (દાંત અને હાડકાંનો મુખ્ય ઘટક) · SI: — · જૈવિક મહત્વ — હાડકાં અને દાંત
Na⁺ અને K⁺ આયનોનું જૈવિક મહત્વ (સોડિયમ-પોટેશિયમ પંપ): Na⁺/K⁺-ATPase પંપ : 3Na⁺ (બહાર) ↔ 2K⁺ (અંદર)
Na⁺ = સોડિયમ આયન, K⁺ = પોટેશિયમ આયન, ATPase = ઉત્સેચક · SI: — · સ્નાયુ સંકોચન અને સ્નાયુ તંતુઓમાં
મેગ્નેશિયમ ક્લોરોફિલમાં મહત્વ: Mg²⁺ = ક્લોરોફિલ અણુનું કેન્દ્રીય આયન
Mg²⁺ = મેગ્નેશિયમ આયન, ક્લોરોફિલ = પ્રકાશસંશ્લેષણ રંગધાતુ · SI: — · જૈવિક મહત્વ — પ્રકાશસંશ્લેષણ
કેલ્શિયમ ATPase એન્જાઇમ: Ca²⁺-ATPase = સ્નાયુ સંકોચનમાં મદદગાર
Ca²⁺ = કેલ્શિયમ આયન, ATPase = ઉત્સેચક · SI: — · જૈવિક મહત્વ — સ્નાયુ સંકોચન

🔗 સંબંધો

  • સમૂહ ૧ માં પરમાણુ ત્રિજ્યા ઉપરથી નીચે જતાં વધે છે: Li < Na < K < Rb < Cs
  • સમૂહ ૨ માં પરમાણુ ત્રિજ્યા ઉપરથી નીચે જતાં વધે છે: Be < Mg < Ca < Sr < Ba
  • આયનીકરણ એન્થાલ્પી સમૂહમાં ઉપરથી નીચે જતાં ઘટે છે કારણ કે પરમાણુ કદ વધે છે
  • સમૂહ ૧ ની તત્વોની આયનીકરણ એન્થાલ્પી સમૂહ ૨ કરતાં ઓછી હોય છે
  • જળવિભાજન એન્થાલ્પી આયની ત્રિજ્યાના વર્ગના વ્યસ્ત પ્રમાણમાં હોય છે
  • સમૂહ ૧ ના તત્વોની ઘનતા ઉપરથી નીચે જતાં વધે છે (Li થી Cs સુધી)
  • સમૂહ ૨ ના તત્વોની ઘનતા પણ ઉપરથી નીચે જતાં વધે છે
  • સમૂહ ૧ ના તત્વોની દ્રવણ અને ઉત્કલન બિંદુ ઉપરથી નીચે જતાં ઘટે છે
  • સમૂહ ૨ ના તત્વોની દ્રવણ અને ઉત્કલન બિંદુ સમૂહ ૧ કરતાં વધુ હોય છે
  • સોડિયમ અને પોટેશિયમ આયનો કોષ દ્વારા Na⁺/K⁺ પંપ દ્વારા નિયંત્રિત થાય છે
  • કેલ્શિયમ આયન સ્નાયુ સંકોચન અને ચેતા સંચારમાં મહત્વપૂર્ણ ભૂમિકા ભજવે છે
  • મેગ્નેશિયમ આયન ક્લોરોફિલનું કેન્દ્રીય ઘટક છે અને પ્રકાશસંશ્લેષણ માટે આવશ્યક છે

🎯 ટ્રિક્સ

સમૂહ ૧ ના તત્વોની આયનીકરણ એન્થાલ્પી ઓછી હોવાથી તેઓ પ્રબળ રિડ્યુસિંગ એજન્ટ છે — Li સૌથી પ્રબળ રિડ્યુસિંગ એજન્ટ છે કારણ કે તેની જળવિભાજન એન્થાલ્પી સૌથી વધુ ઋણ છે
સોડા-એસિડ પ્રક્રિયામાં NaHCO₃ નું ઉષ્મીય વિઘટન યાદ રાખવાનું સૂત્ર: 'બાયકાર્બોનેટ ગરમ કરો → કાર્બોનેટ + પાણી + CO₂'
વિકર્ણ સંબંધ યાદ રાખવા માટે: 'Li-Mg અને Be-Al' — આ બે જોડીઓ સમૂહ ૧-૨ અને સમૂહ ૨-૧૩ વચ્ચે છે
સમૂહ ૧ ના તત્વો જળ સાથે પ્રક્રિયા કરીને હાઇડ્રોક્સાઇડ અને H₂ બનાવે છે — 'ધાત્વીય એલકલી + પાણી → હાઇડ્રોક્સાઇડ + હાઇડ્રોજન'
ચૂના પાણી (Ca(OH)₂) માં CO₂ પસાર કરતાં સફેદ અવક્ષેપ (CaCO₃) બને છે — આ CO₂ ની પરીક્ષા છે
સોડિયમ કાર્બોનેટ (Na₂CO₃) ને 'સોડા વોશિંગ સોડા' કહેવાય છે અને તે ૧૦ જળ અણુઓ ધરાવે છે
સમૂહ ૨ ના તત્વોની સંયોજકતા +૨ હોય છે અને તેઓ સમૂહ ૧ કરતાં ઓછી પ્રવૃત્તિ ધરાવે છે

સોડિયમ ક્લોરાઇડ (NaCl) ને સોડા-એસિડ પ્રક્રિયામાં સીધું સોડિયમ કાર્બોનેટ બનાવે છે એવું માની લેવું — વાસ્તવમાં NaHCO₃ મધ્યસ્થ ઉત્પાદન છે
સમૂહ ૧ ના તત્વોની ઘનતા હંમેશા વધતી જાય છે એવું માની લેવું — Na (0.97 g/cm³) કરતાં K (0.86 g/cm³) ની ઘનતા ઓછી છે, આ એક અપવાદ છે
Li⁺ ની જળવિભાજન એન્થાલ્પી સૌથી ઓછી છે એવું માની લેવું — વાસ્તવમાં Li⁺ ની જળવિભાજન એન્થાલ્પી સૌથી વધુ ઋણ છે કારણ કે તે સૌથી નાનું આયન છે
સમૂહ ૨ ના તત્વોની આયનીકરણ એન્થાલ્પી સમૂહ ૧ કરતાં ઓછી છે એવું માની લેવું — વાસ્તવમાં સમૂહ ૨ ની આયનીકરણ એન્થાલ્પી વધુ હોય છે
