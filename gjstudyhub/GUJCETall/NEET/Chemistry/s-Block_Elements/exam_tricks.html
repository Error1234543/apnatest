s-Block Elements — GUJCET Exam Tricks

🧪 GUJCET — Gujarati • Chemistry • s-Block Elements

🎯 પરીક્ષા ટ્રિક્સ

જલીય દ્રાવ્યતાનો નિયમ: જો હાઇડ્રેશન એનથાલ્પી > લેટિસ એનથાલ્પી હોય, તો કાર્બોનેટ/સલ્ફેટ પાણીમાં દ્રાવ્ય. Li⁺ અને Be²⁺ ની ઊંચી હાઇડ્રેશન એનથાલ્પીને કારણે Li₂CO₃ અને BeSO₄ દ્રાવ્ય છે, જ્યારે Mg/Ca/Sr/Ba ના કાર્બોનેટ અદ્રાવ્ય છે.
જ્યારે પ્રશ્નમાં કાર્બોનેટ અથવા સલ્ફેટની દ્રાવ્યતા વિશે પૂછવામાં આવે.
દા.ત.: Li₂CO₃ પાણીમાં થોડું દ્રાવ્ય છે, જ્યારે Na₂CO₃ સારું દ્રાવ્ય છે. BeSO₄ દ્રાવ્ય, BaSO₄ અદ્રાવ્ય.
ઉષ્મીય સ્થિરતાનો નિયમ: જથ્થાબંધ ધન આયન (મોટો r⁺) ઓછો પોલરાઇઝિંગ હોય છે → કાર્બોનેટ/નાઇટ્રેટ વધુ ઉષ્મીય સ્થિર. તેથી ઉષ્મીય સ્થિરતા: Be < Mg < Ca < Sr < Ba.
જ્યારે કાર્બોનેટ કે નાઇટ્રેટની ઉષ્મીય વિઘટન તાપમાન અથવા સ્થિરતા વિશે પૂછવામાં આવે.
દા.ત.: BaCO₃ સૌથી વધુ ઉષ્મીય સ્થિર, BeCO₃ સૌથી ઓછી સ્થિર. Na₂CO₃ સીધું વિઘટતું નથી, MgCO₃ ઓછા તાપમાને વિઘટે છે.
દ્રવણમાં ઘૂમર પ્રતિબાળકતા (Reducing Power) નો ક્રમ: Li > Cs > Rb > K > Na. Li⁺ ની ઊંચી હાઇડ્રેશન એનથાલ્પીને કારણે Li સૌથી પ્રબળ બીજકારક છે, ભલે તેનું આયનીકરણ ઊર્જા સૌથી ઓછું ન હોય.
જ્યારે પ્રશ્નમાં કોઈ ધાતુની બીજકારક શક્તિ અથવા ઇલેક્ટ્રોડ વિભવ (E°) વિશે પૂછવામાં આવે.
દા.ત.: Li સૌથી પ્રબળ બીજકારક છે (E° = −3.04 V), Na સૌથી ઓછું (E° = −2.71 V) alkali metals માં.
અગ્નિ પરીક્ષા (Flame Test) રંગો યાદ રાખવાનો ટૂંકો મંત્ર: "Li-લાલ, Na-સફેદ/કેસરી, K-બેંગણી, Rb-ગુલાબી, Cs-વાદળી". Be અને Mg અગ્નિ પરીક્ષામાં રંગ નથી આપતા.
જ્યારે પ્રશ્નમાં અગ્નિ પરીક્ષા રંગ અથવા કોઈ ધાતુની ઓળખ વિશે પૂછવામાં આવે.
દા.ત.: K⁺ નો અગ્નિ રંગ બેંગણી (violet) છે, જે Br₂ વાળા કાચમાંથી જોતાં વધુ સ્પષ્ટ દેખાય છે.
ડાયાગોનલ સંબંધ યાદ રાખો: Li ↔ Mg અને Be ↔ Al. આ બંને જોડીઓના ગુણધર્મો સમાન છે — આયનીય ત્રિજ્યા, વિદ્યુતઋણતા, પોલરાઇઝિંગ શક્તિ, કાર્બોનેટની ઉષ્મીય અસ્થિરતા, અને NaOH/Na₂CO₃ ના વિપરીત LiOH/Li₂CO₃ નું ઉષ્મીય વિઘટન.
જ્યારે Li અથવા Be ના વિચિત્ર ગુણધર્મો અથવા તેમના સમાનતા વિશે પૂછવામાં આવે.
દા.ત.: Li₂CO₃ ઉષ્મીય વિઘટન પામે છે (Li₂O + CO₂), જ્યારે Na₂CO₃ ન પામે — આ MgCO₃ અને CaCO₃ જેવું વર્તન Li નું છે.
BeCl₂ ની રચના: BeCl₂ સહસંયોજક છે અને સ્થિતિસ્થાપક શૃંખલા બનાવે છે. જલીય દ્રાવણમાં [Be(H₂O)₄]²⁺ બને છે અને H⁺ મુક્ત થાય છે → દ્રાવણ એસિડિક. આથી BeCl₂ નું જલીય દ્રાવણ લિટમસને લાલ કરે છે.
જ્યારે BeCl₂ ના ગુણધર્મો, રચના અથવા જલીય દ્રાવણના pH વિશે પૂછવામાં આવે.
દા.ત.: BeCl₂(H₂O)₂ + H₂O → [Be(H₂O)₄]²⁺ + 2Cl⁻; [Be(H₂O)₄]²⁺ → [Be(H₂O)₃(OH)]⁺ + H⁺ (એસિડિક દ્રાવણ).
સોલવે પ્રક્રિયા (Solvay Process) માં Na₂CO₃ બનાવવા માટે NH₃ જરૂરી છે પણ NaHCO₃ નું નિષ્કર્ષણ (precipitation) NaCl ના સંતૃપ્ત દ્રાવણમાંથી થાય છે. NH₄Cl ઉપઉત્પાદન છે. આ પ્રક્રિયા CaCO₃ → CaO + CO₂ (કાચભઠ્ઠીમાં) પરથી CO₂ મેળવે છે.
જ્યારે Na₂CO₃ ના ઉત્પાદન, સોલવે પ્રક્રિયા અથવા તેના ઉપયોગો વિશે પૂછવામાં આવે.
દા.ત.: NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl; 2NaHCO₃ → Na₂CO₃ + H₂O + CO₂ (ગરમ કરતાં).
બોરેક્સ (Na₂B₄O₇·10H₂O) નો લોહાળ ગોળ (Bead Test): Cu²⁺ + B₂O₃ → CuB₂O₄ (नीलી ગોળી), Co²⁺ + B₂O₃ → CoB₂O₄ (नीली ગોળી). આ પરીક્ષા d-બ્લોક ધાતુઓની ઓળખ માટે ઉપયોગી છે.
જ્યારે બોરેક્સ ગોળ પરીક્ષા અથવા lohaul gol (borax bead test) વિશે પૂછવામાં આવે.
દા.ત.: CuSO₄ + Na₂B₄O₇ → नीलો ગોળ (CuB₂O₄). Co²⁺ નો પણ नीलो ગોળ બને છે.
NaOH ના ઉત્પાદનમાં ક્લોર-ઍલકલી પ્રક્રિયા (Chlor-alkali process): વિદ્યુતવિભાજનથી NaCl નાં દ્રાવણમાંથી Cl₂, H₂ અને NaOH મળે છે. Hg-કેથોડ પદ્ધતિમાં NaHg બને છે જે પાણી સાથે પ્રક્રિયા કરી NaOH + H₂ આપે છે.
જ્યારે NaOH ના ઉત્પાદન અથવા વિદ્યુતવિભાજન પ્રક્રિયાઓ વિશે પૂછવામાં આવે.
દા.ત.: 2NaCl + 2H₂O → 2NaOH + Cl₂ + H₂ (ડાઉન-કેલ પ્રક્રિયા).
CaO (ચૂનાનો પથ્થર) + H₂O → Ca(OH)₂ (ચૂનપાણ/slaked lime) + ઉષ્મા. આ પ્રક્રિયા ઉષ્માક્ષેપક છે. Ca(OH)₂ નું દ્રાવણ "ચૂનપાણ (Lime water)" કહેવાય છે, જે CO₂ થી દૂધિયું સફેદ થાય છે (CaCO₃ અવક્ષેપ).
જ્યારે ચૂનાના સંયોજનો, ચૂનપાણ અથવા CO₂ ની ઓળખ વિશે પૂછવામાં આવે.
દા.ત.: Ca(OH)₂ + CO₂ → CaCO₃↓ (સફેદ) + H₂O. વધુ CO₂ મુક્ત કરતાં Ca(HCO₃)₂ બને છે → દ્રાવણ સ્પષ્ટ થાય છે.
s-બ્લોક ધાતુઓની દ્રવ્યતા: NaOH, KOH અત્યંત દ્રાવ્ય; Ca(OH)₂ અંશતઃ દ્રાવ્ય; Mg(OH)₂ અદ્રાવ્ય. દ્રાવ્યતા ક્રમ: Mg(OH)₂ < Ca(OH)₂ < Sr(OH)₂ < Ba(OH)₂ (નીચે જતાં વધે છે).
જ્યારે હાઇડ્રોક્સાઇડની દ્રાવ્યતા અથવા બેઝિક પ્રકૃતિ વિશે પૂછવામાં આવે.
દા.ત.: Ba(OH)₂ સૌથી વધુ દ્રાવ્ય અને પ્રબળ બેઝ છે; Mg(OH)₂ અદ્રાવ્ય અને નિર્બળ બેઝ છે (મિલ્ક ઑફ મેગ્નેશિયા).
Na₂O₂ (સોડિયમ પરોક્સાઇડ) પાણી સાથે પ્રક્રિયા કરી NaOH + H₂O₂ આપે છે. H₂O₂ ઓક્સિજન મુક્ત કરે છે. આથી Na₂O₂ ઓક્સિડાઇઝિંગ એજન્ટ છે અને હવામાંથી CO₂ શોષીને Na₂CO₃ + O₂ આપે છે.
જ્યારે પરોક્સાઇડની પ્રકૃતિ, O₂ નું ઉત્પાદન અથવા Na₂O₂ ના ઉપયોગો વિશે પૂછવામાં આવે.
દા.ત.: 2Na₂O₂ + 2H₂O → 4NaOH + O₂; 2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂ (બંધ જગ્યાએ O₂ પુરવઠો).
KOH સોડિયમ હાઇડ્રોક્સાઇડ કરતાં વધુ પ્રબળ બેઝ છે કારણ કે K⁺ ની હાઇડ્રેશન એનથાલ્પી ઓછી છે, તેથી K⁺–OH⁻ બંધન નબળું છે અને OH⁻ સરળતાથી મુક્ત થાય છે.
જ્યારે બેઝિક પ્રકૃતિની તુલના અથવા s-બ્લોક હાઇડ્રોક્સાઇડની પ્રબળતા વિશે પૂછવામાં આવે.
દા.ત.: KOH > NaOH > LiOH (બેઝિક પ્રકૃતિના ક્રમમાં). LiOH સૌથી નિર્બળ કારણે Li⁺ ની ઊંચી હાઇડ્રેશન એનથાલ્પી.
Mg નો ઉપયોગ "રિડ્યુસિંગ એજન્ટ" તરીકે TiCl₄ → Ti (Kroll process) માં થાય છે. Mg + 2H₂O → Mg(OH)₂ + H₂ (ઉત્કષ્ણિત પાણી સાથે). Mg ની ધાતુ ચમકદાર સફેદ છે અને તે જ્વલનમાં ઉજ્જવળ સફેદ પ્રકાશ આપે છે.
જ્યારે Mg ના ઉપયોગ, પ્રક્રિયા અથવા તેના ગુણધર્મો વિશે પૂછવામાં આવે.
દા.ત.: TiCl₄ + 2Mg → Ti + 2MgCl₂ (1100°C, Ar વાતાવરણમાં). Mg નો ઉપયોગ ધાતુ મેળવવા માટે થાય છે.
CaC₂ (કાર્બાઇડ) + H₂O → C₂H₂ (એસિટાઇલિન) + Ca(OH)₂. આ પ્રક્રિયાથી એસિટાઇલિન ગેસ મળે છે જે વેલ્ડિંગમાં ઉપયોગી છે. CaC₂ ને "લિમ સ્ટોનથી બનતો કાર્બાઇડ" કહેવાય.
જ્યારે એસિટાઇલિનનું ઉત્પાદન અથવા CaC₂ ની પ્રક્રિયાઓ વિશે પૂછવામાં આવે.
દા.ત.: CaC₂ + 2H₂O → C₂H₂↑ + Ca(OH)₂. C₂H₂ + O₂ → CO₂ + H₂O (ઉચ્ચ તાપમાને, વેલ્ડિંગ ટચ).
