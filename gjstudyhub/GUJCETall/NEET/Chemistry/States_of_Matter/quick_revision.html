🧠 યાદ રાખો

આદર્શ વાયુ સમીકરણ: PV = nRT (n = મોલ સંખ્યા, R = વાયુ અચળાંક = 0.0821 L·atm·mol⁻¹·K⁻¹)
બોયલનો નિયમ: T અચળ રાખીએ તો P ∝ 1/V → P₁V₁ = P₂V₂
ચાર્લ્સનો નિયમ: P અચળ રાખીએ તો V ∝ T → V₁/T₁ = V₂/T₂
ગે-લુસાકનો નિયમ: V અચળ રાખીએ તો P ∝ T → P₁/T₁ = P₂/T₂
સંયુક્ત વાયુ નિયમ: PV/T = અચળ → P₁V₁/T₁ = P₂V₂/T₂
ડેલ્ટનનો આંશિક દબાણનો નિયમ: P_total = P₁ + P₂ + P₃ + ...
ગ્રેહામનો વ્યુત્ક્રમણ નિયમ: r₁/r₂ = √(M₂/M₁) = √(d₂/d₁)
વાન ડર વાલ્સ સમીકરણ (1 મોલ): (P + a/V²)(V - b) = RT
ક્રાંતિક તાપમાન: T_c = 8a/(27Rb), ક્રાંતિક દબાણ: P_c = a/(27b²), ક્રાંતિક કદ: V_c = 3b
વાયુનો સાપેક્ષ કંપન વેગ: v_rms = √(3RT/M)
સૌથી વધુ સંભાવિત વેગ: v_mp = √(2RT/M)
સરેરાશ વેગ: v_avg = √(8RT/πM)
ગતિજ સમીકરણ: PV = (1/3)nmv²_rms અથવા PV = (2/3)E
ગેસના એક મોલની ગતિજ ઊર્જા: KE = (3/2)RT
વાસ્તવિક વાયુ અને આદર્શ વાયુ વચ્ચેનું વિચલન: Z = PV/nRT (Z = 1 આદર્શ, Z < 1 સંકોચન, Z > 1 વિસ્તરણ)
ક્રાંતિક તાપમાન: વાયુને જે તાપમાને દ્રવ બનાવી શકાય નહીં
વાષ્પ દબાણ તાપમાન સાથે વધે છે; ઉત્કલનબિંદુએ વાષ્પ દબાણ = બાહ્ય દબાણ
પૃષ્ઠતણ એકમ લંબાઈના ખંડ પર લાગતું બળ છે; તાપમાન વધતા પૃષ્ઠતણ ઘટે છે
સ્નિગ્ધતા એ વાયુ/દ્રવની પ્રવાહિતાનો વિરોધ છે; વાયુની સ્નિગ્ધતા તાપમાન વધતા વધે છે
માક્સવેલ-બોલ્ટ્ઝમેન વેગ વિતરણ વક્ર: તાપમાન વધતા શિખર જમણી બાજુ ખસે છે અને પહોળું થાય છે

⚡ ઝડપી સૂત્રો

PV = nRT → n = m/M → PV = (m/M)RT
બોયલ નિયમ: P₁V₁ = P₂V₂ (T, n અચળ)
ચાર્લ્સ નિયમ: V₁/T₁ = V₂/T₂ (P, n અચળ)
ગે-લુસાક નિયમ: P₁/T₁ = P₂/T₂ (V, n અચળ)
સંયુક્ત નિયમ: P₁V₁/T₁ = P₂V₂/T₂
સાથે મળીને: PV = (m/M)RT = (wRT)/M
STP પર 1 મોલ વાયુનું કદ = 22.7 L (આધુનિક પ્રમાણિત)
ગ્રેહામ: r₁/r₂ = √(M₂/M₁) = √(d₂/d₁)
ડેલ્ટન: P_total = P₁ + P₂ + P₃ + ...
વાન ડર વાલ્સ (n મોલ): (P + an²/V²)(V - nb) = nRT
T_c = 8a/(27Rb), P_c = a/(27b²), V_c = 3b
v_rms = √(3RT/M) = √(3P/ρ)
v_mp = √(2RT/M)
v_avg = √(8RT/πM)
KE (1 મોલ) = (3/2)RT
KE (n મોલ) = (3/2)nRT
Z = PV_m/RT (વાયુનું વિચલન ગુણાંક)
આદર્શ વાયુ: Z = 1; વાસ્તવિક: Z ≠ 1

✅ વન-લાઈનર્સ

વાયુ અણુઓ વચ્ચે આકર્ષણ બળ નગણ્ય હોય છે અને તેમનું કદ નગણ્ય હોય છે — આદર્શ વાયુની ધારણા.
વાસ્તવિક વાયુઓ ઊંચા દબાણ અને નીચા તાપમાને આદર્શ વર્તણૂકથી વિચલિત થાય છે.
ક્રાંતિક ગુણાંક (a, b): a વાસ્તવિક આકર્ષણ બળ દર્શાવે છે, b અણુનું કદ દર્શાવે છે.
હીલિયમનું ક્રાંતિક તાપમાન સૌથી ઓછું છે, તેથી તે સૌથી મુશ્કેલથી દ્રવ બને છે.
લિંડેની પદ્ધતિ વાયુઓના દ્રવીકરણ માટે વિસ્તરણ-સંકોચન સિદ્ધાંત પર આધારિત છે.
કેલ્વિન તાપમાન શૂન્ય (-273.15°C) એ પરમ શૂન્ય છે જ્યાં અણુઓની ગતિજ ઊર્જા શૂન્ય થાય છે.
વાષ્પ દબાણ તરલની પ્રકૃતિ અને તાપમાન પર આધારિત છે; સ્ફટિકીકરણ બિંદુ પર બાષ્પ દબાણ = બાહ્ય દબાણ.
પૃષ્ઠતણના કારણે તરલની સપાટી સંકોચાઈને ન્યૂનતમ ક્ષેત્રફળ ધારણ કરવા પ્રયત્ન કરે છે.
દ્રવ્યની ત્રણ મુખ્ય અવસ્થાઓ: ઘન, દ્રવ અને વાયુ; પ્લાઝ્મા ચોથી અવસ્થા છે.
માક્સવેલ-બોલ્ટ્ઝમેન વિતરણ વક્ર હેઠળનું ક્ષેત્રફળ કુલ અણુઓની સંખ્યા બરાબર હોય છે.
