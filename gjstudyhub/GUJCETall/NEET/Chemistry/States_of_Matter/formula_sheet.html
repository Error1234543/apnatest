પદાર્થની અવસ્થાઓ — સૂત્ર પત્રિકા

🧪 GUJCET — Gujarati • Chemistry • States of Matter

⚡ સૂત્રો

દબાણ (Pressure): P = F / A
P = દબાણ, F = લંબ બળ, A = ક્ષેત્રફળ · SI: Pa (N/m²) · સામાન્ય દબાણની વ્યાખ્યા
દબાણના એકમ રૂપાંતરણ: 1 atm = 101325 Pa = 760 mmHg = 760 torr = 1.01325 bar
atm = વાતાવરણીય દબાણ, mmHg = મર્કુરી સ્તંભ મિલીમીટર, torr = mmHg ની સમાન · SI: Pa · દબાણના વિવિધ એકમો વચ્ચે રૂપાંતર
બોઈલનો નિયમ (Boyle's Law): P1 × V1 = P2 × V2 (T, n અચળ)
P = દબાણ, V = કદ, T = તાપમાન, n = મોલ સંખ્યા · SI: Pa, m³ · સ્થિર તાપમાને અને મોલ સંખ્યાએ, દબાણ અને કદ વ્યસ્ત પ્રમાણમાં
ચાર્લ્સનો નિયમ (Charles's Law): V1 / T1 = V2 / T2 (P, n અચળ)
V = કદ, T = નિરપેક્ષ તાપમાન (K) · SI: m³, K · સ્થિર દબાણે અને મોલ સંખ્યાએ, કદ નિરપેક્ષ તાપમાનના સમપ્રમાણમાં
એવોગેડ્રોનો નિયમ (Avogadro's Law): V1 / n1 = V2 / n2 (P, T અચળ)
V = કદ, n = મોલ સંખ્યા · SI: m³, mol · સ્થિર દબાણ અને તાપમાને, કદ મોલ સંખ્યાના સમપ્રમાણમાં
ગેય-લુસાકનો નિયમ (Gay-Lussac's Law): P1 / T1 = P2 / T2 (V, n અચળ)
P = દબાણ, T = નિરપેક્ષ તાપમાન (K) · SI: Pa, K · સ્થિર કદ અને મોલ સંખ્યાએ, દબાણ નિરપેક્ષ તાપમાનના સમપ્રમાણમાં
સંયુક્ત ગેસ સમીકરણ (Combined Gas Law): P1 × V1 / T1 = P2 × V2 / T2
P = દબાણ, V = કદ, T = નિરપેક્ષ તાપમાન (K) · SI: Pa, m³, K · ગેસની માત્રા અચળ રહે તેમ દબાણ, કદ અને તાપમાન બધા બદલાય
આદર્શ ગેસ સમીકરણ (Ideal Gas Equation): P × V = n × R × T
P = દબાણ, V = કદ, n = મોલ સંખ્યા, R = ગેસ અચળાંક, T = નિરપેક્ષ તાપમાન (K) · SI: Pa, m³, mol, J/(mol·K), K · આદર્શ ગેસ માટે; R = 8.314 J/(mol·K) = 0.0821 L·atm/(mol·K)
ગેસ અચળાંક R ની મૂલ્યો: R = 8.314 J/(mol·K) = 0.0821 L·atm/(mol·K) = 1.987 cal/(mol·K)
R = સાર્વત્રિક ગેસ અચળાંક · SI: J/(mol·K) · વિવિધ એકમ પદ્ધતિઓમાં R ની મૂલ્ય
આદર્શ ગેસ — દળ સ્વરૂપ: P × V = m / M × R × T
m = ગેસનું દળ, M = મોલર દળ · SI: Pa, m³, kg, kg/mol · જ્યારે મોલ સંખ્યા n ને દળ અને મોલર દળ દ્વારા દર્શાવવી હોય
ગેસની ઘનતા (Gas Density): d = P × M / (R × T)
d = ઘનતા, P = દબાણ, M = મોલર દળ, R = ગેસ અચળાંક, T = તાપમાન · SI: kg/m³ · આદર્શ ગેસની ઘનતા; d = m/V
મોલર દળની ગણતરી (Molar Mass from Density): M = d × R × T / P
M = મોલર દળ, d = ઘનતા, P = દબાણ, R = ગેસ અચળાંક, T = તાપમાન · SI: kg/mol · ગેસની ઘનતા અને તાપમાન-દબાણથી મોલર દળ શોધવું
ડેલ્ટનનો આંશિક દબાણનો નિયમ (Dalton's Law of Partial Pressures): P_total = P1 + P2 + P3 + ...
P_total = કુલ દબાણ, P1, P2, ... = વિવિધ ગેસોના આંશિક દબાણ · SI: Pa · અક્રિયાશીલ ગેસોના મિશ્રણ માટે; દરેક ગેસ પોતાના કદમાં પૂરું દબાણ દાખવે
આંશિક દબાણ અને મોલ અંશ (Partial Pressure and Mole Fraction): P_i = X_i × P_total
P_i = i-મી ગેસનું આંશિક દબાણ, X_i = i-મી ગેસનો મોલ અંશ, P_total = કુલ દબાણ · SI: Pa · ગેસ મિશ્રણમાં કોઈ એક ગેસનું આંશિક દબાણ શોધવા
મોલ અંશ (Mole Fraction): X_i = n_i / n_total
X_i = i-મી ઘટકનો મોલ અંશ, n_i = i-મી ઘટકના મોલ, n_total = કુલ મોલ · SI: એકમરહિત · મિશ્રણમાં દરેક ઘટકનો મોલ અંશ
ગ્રેહામનો વિસરણ નિયમ (Graham's Law of Diffusion/Effusion): r1 / r2 = √(M2 / M1)
r1, r2 = ગેસ 1 અને 2 નું વિસરણ/પ્રવેગ દર, M1, M2 = તેમના મોલર દળ · SI: mol/s અથવા m³/s · સમાન તાપમાન અને દબાણે, ગેસનો વિસરણ દર તેના મોલર દળના વર્ગમૂળના વ્યસ્ત પ્રમાણમાં
ગ્રેહામનો નિયમ — સમય સ્વરૂપ: r1 / r2 = t2 / t1 = √(M2 / M1)
t1, t2 = સમાન કદ વિસરવામાં લાગતો સમય, M1, M2 = મોલર દળ · SI: s · જ્યારે વિસરણ દરને બદલે સમય આપેલો હોય
રૂટ મીન સ્ક્વેર વેગ (Root Mean Square Speed): v_rms = √(3 × R × T / M)
v_rms = વર્ગમાધ્ય મૂલ્ય વેગ, R = ગેસ અચળાંક, T = તાપમાન (K), M = મોલર દળ (kg/mol) · SI: m/s · આદર્શ ગેસના અણુઓનો વેગ; M હંમેશા kg/mol માં લેવો
સરેરાશ વેગ (Average Speed): v_avg = √(8 × R × T / (π × M))
v_avg = સરેરાશ વેગ, R = ગેસ અચળાંક, T = તાપમાન (K), M = મોલર દળ (kg/mol), π = 3.1416 · SI: m/s · આદર્શ ગેસ અણુઓનો સરેરાશ વેગ
સર્વાધિક સંભાવ્ય વેગ (Most Probable Speed): v_mp = √(2 × R × T / M)
v_mp = સર્વાધિક સંભાવ્ય વેગ, R = ગેસ અચળાંક, T = તાપમાન (K), M = મોલર દળ (kg/mol) · SI: m/s · આદર્શ ગેસ અણુઓનો સર્વાધિક સંભાવ્ય વેગ
ત્રણેય વેગોનો ગુણોત્તર: v_mp : v_avg : v_rms = √2 : √(8/π) : √3 ≈ 1 : 1.128 : 1.224
v_mp = સર્વાધિક સંભાવ્ય વેગ, v_avg = સરેરાશ વેગ, v_rms = વર્ગમાધ્ય મૂલ્ય વેગ · SI: ગુણોત્તર · એક જ તાપમાને ત્રણેય વેગોનો સરવાળાત્મક સંબંધ
ગતિજ ઊર્જા (Kinetic Energy per Mole): KE = (3/2) × R × T
KE = પ્રતિ મોલ ગતિજ ઊર્જા, R = ગેસ અચળાંક, T = તાપમાન (K) · SI: J/mol · એક પરમાણ્વીય આદર્શ ગેસ પ્રતિ મોલની ગતિજ ઊર્જા
વાન ડર્સવાલ્સ સમીકરણ (Van der Waals Equation): (P + a×n²/V²) × (V - n×b) = n×R×T
a = આકર્ષણ અચળાંક, b = બાઉન્ડ અચળાંક (વર્જિત કદ), n = મોલ, V = કદ, R = ગેસ અચળાંક, T = તાપમાન · SI: Pa, m³, mol, K · વાસ્તવિક ગેસો માટે; 1 મોલ માટે: (P + a/V²)(V - b) = RT
વાન ડર્સવાલ્સ અચળાંક a નું એકમ: a = P × V² / n² → એકમ: Pa·m⁶/mol² અથવા atm·L²/mol²
a = આંતરઆણ્વીય આકર્ષણ બળનું માપ · SI: Pa·m⁶/mol² · વાન ડર્સવાલ્સ સમીકરણમાં a નું એકમ
વાન ડર્સવાલ્સ અચળાંક b નું એકમ: b = V / n → એકમ: m³/mol અથવા L/mol
b = એક મોલ ગેસના અણુઓ દ્વારા ગ્રહણ કરેલું વર્જિત કદ · SI: m³/mol · વાન ડર્સવાલ્સ સમીકરણમાં b નું એકમ
સંકોચન્યતા ગુણાંક (Compressibility Factor): Z = P × V / (n × R × T)
Z = સંકોચન્યતા ગુણાંક, P = દબાણ, V = કદ, n = મોલ, R = ગેસ અચળાંક, T = તાપમાન · SI: એકમરહિત · Z = 1: આદર્શ ગેસ; Z < 1: સંકોચન (નિરપેક્ષ દબાણ ઓછું); Z > 1: અસંકોચન (નિરપેક્ષ દબાણ વધુ)
નિરપેક્ષ દબાણ (Absolute Pressure): P_nirpeksh = P_atmospheric + P_gauge (જ્યારે P_gauge > 0)
P_nirpeksh = નિરપેક્ષ દબાણ, P_atmospheric = વાતાવરણીય દબાણ, P_gauge = ગેજ દબાણ · SI: Pa · વાસ્તવિક દબાણની ગણતરી
ક્રાંતિક તાપમાન (Critical Temperature): T_c = 8a / (27 × R × b)
T_c = ક્રાંતિક તાપમાન, a = આકર્ષણ અચળાંક, b = વર્જિત કદ અચળાંક, R = ગેસ અચળાંક · SI: K · વાન ડર્સવાલ્સ સમીકરણ પરથી; તે તાપમાન જેથી ઉપર ગેસને કોઈ પણ દબાણે દ્રવ બનાવી શકાતી નથી
ક્રાંતિક દબાણ (Critical Pressure): P_c = a / (27 × b²)
P_c = ક્રાંતિક દબાણ, a = આકર્ષણ અચળાંક, b = વર્જિત કદ અચળાંક · SI: Pa · વાન ડર્સવાલ્સ સમીકરણ પરથી; ક્રાંતિક તાપમાને ગેસને દ્રવ બનાવવાનું લઘુત્તમ દબાણ
ક્રાંતિક કદ (Critical Volume): V_c = 3 × b
V_c = ક્રાંતિક કદ (પ્રતિ મોલ), b = વર્જિત કદ અચળાંક · SI: m³/mol · વાન ડર્સવાલ્સ સમીકરણ પરથી; ક્રાંતિક બિંદુએ પ્રતિ મોલ કદ
લેન્ડેન-જોન્સ સંબંધ (Lindemann-Jones Relation): P_c × V_c / (R × T_c) = 3/8 = 0.375
P_c = ક્રાંતિક દબાણ, V_c = ક્રાંતિક કદ, R = ગેસ અચળાંક, T_c = ક્રાંતિક તાપમાન · SI: એકમરહિત · વાન ડર્સવાલ્સ ગેસ માટે ક્રાંતિક અચળાંકો વચ્ચેનો સંબંધ
તાપમાન અને કેલ્વિન રૂપાંતરણ: T(K) = t(°C) + 273.15
T = નિરપેક્ષ તાપમાન (K), t = સેલ્સિયસ તાપમાન (°C) · SI: K · ગેસના નિયમોમાં તાપમાન હંમેશા કેલ્વિનમાં વાપરવું
STP પર મોલર કદ (Molar Volume at STP): V_m = 22.414 L/mol = 22.414 × 10⁻³ m³/mol
V_m = મોલર કદ, STP = પ્રમાણિત તાપમાન (273.15 K) અને દબાણ (1 atm = 101325 Pa) · SI: L/mol અથવા m³/mol · કોઈ પણ આદર્શ ગેસ 1 મોલનું કદ STP પર 22.414 L હોય
SATP પર મોલર કદ: V_m = 24.789 L/mol
V_m = મોલર કદ, SATP = પ્રમાણિત પર્યાવરણીય તાપમાન (298.15 K) અને દબાણ (1 bar = 10⁵ Pa) · SI: L/mol · કોઈ પણ આદર્શ ગેસ 1 મોલનું કદ SATP પર 24.789 L હોય
ગેસના અણુઓની કુલ સંખ્યા: N = n × N_A = (m / M) × N_A
N = અણુઓની કુલ સંખ્યા, n = મોલ સંખ્યા, N_A = એવોગેડ્રો અંક (6.022 × 10²³), m = દળ, M = મોલર દળ · SI: એકમરહિત (સંખ્યા) · ગેસના નમૂનામાં અણુઓની કુલ સંખ્યા શોધવી
અણુઓ વચ્ચેની સરેરાશ દૂરી (Mean Free Path): λ = 1 / (√2 × π × d² × N/V)
λ = સરેરાશ મુક્ત પથ, d = અણુ વ્યાસ, N/V = એકમ કદમાં અણુઓની સંખ્યા · SI: m · ગેસના અણુ બે અથડામણ વચ્ચે સરેરાશ કાપેલું અંતર
અથડામણ આવૃત્તિ (Collision Frequency): Z = v_avg / λ
Z = અથડામણ આવૃત્તિ (પ્રતિ સેકન્ડ), v_avg = સરેરાશ વેગ, λ = સરેરાશ મુક્ત પથ · SI: s⁻¹ · એક અણુ પ્રતિ સેકન્ડ કેટલી વાર અથડાય છે

🔗 સંબંધો

  • બોઈલનો નિયમ, ચાર્લ્સનો નિયમ અને એવોગેડ્રોનો નિયમ એકસાથે મिलाઈને આદર્શ ગેસ સમીકરણ PV = nRT આપે છે.
  • v_mp < v_avg < v_rms — એક જ તાપમાને સર્વાધિક સંભાવ્ય વેગ સૌથી ઓછો અને વર્ગમાધ્ય મૂલ્ય વેગ સૌથી વધુ હોય છે.
  • વાસ્તવિક ગેસોમાં Z < 1 હોય ત્યારે આકર્ષણ બળ પ્રબળ હોય છે (સંકોચન), Z > 1 હોય ત્યારે અપાકર્ષણ બળ પ્રબળ હોય છે (અસંકોચન).
  • તાપમાન વધારવાથી ગેસના અણુઓનો v_rms, v_avg, v_mp બધો વધે છે — બધો √T ના સમપ્રમાણમાં.
  • ગ્રેહામના નિયમ મુજબ હલકી ગેસ (ઓછું M) ભારે ગેસ કરતાં વધુ ઝડપથી વિસરે છે.
  • ક્રાંતિક અચળાંકો a અને b પરથી T_c, P_c, V_c શોધી શકાય; a વધુ હોય તો ગેસ સહેલાઈથી દ્રવ બને, b વધુ હોય તો અણુનું કદ મોટું હોય.
  • STP (1 atm, 273.15 K) અને SATP (1 bar, 298.15 K) પર મોલર કદ અલગ છે — 22.414 L vs 24.789 L.
  • ડેલ્ટનના નિયમ મુજબ દરેક ગેસનું આંશિક દબાણ P_i = X_i × P_total, જ્યાં X_i મોલ અંશ છે.

🎯 ટ્રિક્સ

v_mp : v_avg : v_rms = √2 : √(8/π) : √3 ≈ 1 : 1.128 : 1.224 — આ ગુણોત્તર યાદ રાખવાથી ત્રણેય વેગોની સરખામણીનો પ્રશ્ન તરત ઉકેલાય.
ગ્રેહામના નિયમમાં r1/r2 = √(M2/M1) — મોલર દળ વધુ હોય તે ગેસ ધીમી, ઓછું હોય તે ઝડપી; ગુણોત્તર ઉલટો લખવાની ભૂલ ન કરવી.
PV = nRT માં R ની કિંમત પસંદગી: જો દબાણ atm અને કદ L માં હોય તો R = 0.0821 લેવો, જો Pa અને m³ માં હોય તો R = 8.314 લેવો.
સંયુક્ત ગેસ સમીકરણ PV/T = constant માં T હંમેશા K માં લેવું — °C માં મૂકતાં જવાબ ખોટો આવે.
વાન ડર્સવાલ્સ સમીકરણ 1 મોલ માટે (P + a/V²)(V - b) = RT; n મોલ માટે (P + an²/V²)(V - nb) = nRT — n² અને n ધ્યાનથી લેવું.
STP પર 1 મોલ = 22.4 L — આ કિંમત યાદ રાખવાથી ગેસના કદ-મોલ રૂપાંતરણ ઝડપી થાય.
Z = PV/nRT માં Z < 1 એ સંકોચન (ગેસ આદર્શ કરતાં વધુ સંકોચાય છે), Z > 1 એ અસંકોચન — આ સૂત્ર યાદ રાખવાથી પ્રશ્નનો સીધો જવાબ મળે.
ક્રાંતિક અચળાંકોના સૂત્રો: T_c = 8a/27Rb, P_c = a/27b², V_c = 3b — બધામાં 27 અને 8 જેવી સંખ્યાઓ આવે છે, b² છેડે છે.

⚠️ ભૂલો

તાપમાન K માં ન મૂકી °C માં ગેસના નિયમો લાગુ પાડવા — હંમેશા T(K) = t(°C) + 273.15.
વાન ડર્સવાલ્સ સમીકરણમાં n ની ઘાત ભૂલ: (P + an²/V²)(V - nb) = nRT માં a સાથે n² અને b સાથે n.
ગ્રેહામના નિયમમાં મોલર દળનો ગુણોત્તર ઉલટો લખવો — r1/r2 = √(M2/M1), M2 ઉપર અને M1 નીચે.
R ની કિંમત એકમ મુજબ પસંદ ન કરવી — atm-L માં 0.0821, Pa-m³ માં 8.314.
STP ને SATP થી ગૂંચવણ — STP = 1 atm, 273.15 K; SATP = 1 bar, 298.15 K.
દબાણના એકમ રૂપાંતરણમાં 1 atm = 1.01325 bar, na keval 1 bar = 1 atm માની લેવું.
વાસ્તવિક ગેસો માટે PV = nRT લાગુ પાડવું — વાસ્તવિક ગેસો માટે વાન ડર્સવાલ્સ સમીકરણ વાપરવું.
v_rms, v_avg, v_mp ના સૂત્રમાં M ને g/mol માં મૂકવું — M હંમેશા kg/mol માં લેવું જોઈએ, નહીંતર જવાબ 1000 ગણો ખોટો આવે.
ડેલ્ટનના નિયમમાં આંશિક દબાણનો સરવાળો P_total કરતાં વધુ અથવા ઓછો લખવો — P_total = P1 + P2 + P3 + ...
સંકોચન્યતા ગુણાંક Z નો અર્થ ગૂંચવણ — Z < 1 એટલે ગેસ આદર્શ કરતાં વધુ સંકોચાય (આકર્ષણ પ્રબળ), Z > 1 એટલે અસંકોચન (અપાકર્ષણ પ્રબળ).
