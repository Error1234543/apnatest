ઘન અવસ્થા (Solid State) — GUJCET એક્ઝામ ટ્રિક્સ

🧪 GUJCET — Gujarati • Chemistry • Solid State

🎯 પરીક્ષા ટ્રિક્સ

ઘન સિસ્ટમ ઓળખવાની ટૂંકી રીત: તમામ ભુજ સમાન અને તમામ કોણ 90° હોય તો તે ઘન (Cubic) છે.
જ્યારે પ્રશ્નમાં એકમ કોષના પરિમાણો આપેલ હોય અને ક્રિસ્ટલ સિસ્ટમ પૂછી હોય.
દા.ત.: જો a = b = c અને α = β = γ = 90° હોય, તો તે સાદું ઘન, BCC કે FCC બધું જ ઘન સિસ્ટમમાં આવે છે.
એકમ કોષમાં પરમાણુઓની સંખ્યા (Z) યાદ કરો: સાદું ઘન = 1, BCC = 2, FCC = 4.
ઘનતા, પરમાણુ ત્રિજ્યા કે મોલર દળ શોધવાના પ્રશ્નોમાં વેગથી ગણતરી કરવા.
દા.ત.: FCC એલ્યુમિનિયમનો ઇડજ લંબાઈ શોધવા Z = 4 લઈને ρ = ZM/(a³Nₐ) સૂત્ર વાપરો.
પેકિંગ અંશ (Packing Efficiency) યાદ રાખો: FCC અને HCP = 74%, BCC = 68%, સાદું ઘન = 52%.
જ્યારે ખાલી જગ્યા અથવા પેકિંગ કાર્યક્ષમતા વિશે પ્રશ્ન હોય.
દા.ત.: BCC ધાતુમાં ખાલી જગ્યા = 100 – 68 = 32% હોય છે.
ત્રિજ્યા ગુણોત્તર નિયમ: r₊/r₋ 0.414–0.732 વચ્ચે હોય તો સંયોજન અંક 6 (ઉષ્ટફલકીય), 0.732–1.0 હોય તો 8 (ઘન).
આયનીય સંયોજનની રચના અથવા સંયોજન અંક આધારિત પ્રશ્નોમાં.
દા.ત.: NaCl માં r_Na⁺/r_Cl⁻ ≈ 0.52 હોવાથી સંયોજન અંક 6–6 હોય છે.
FCC માટે પરમાણુ ત્રિજ્યા અને એકમ કોષની ભુજ વચ્ચેનો સંબંધ: a = 2√2 r.
જ્યારે પરમાણુ ત્રિજ્યા આપેલ હોય અને એકમ કોષનું કદ શોધવું હોય.
દા.ત.: જો Cu ની પરમાણુ ત્રિજ્યા 128 pm હોય, તો a = 2 × 1.414 × 128 ≈ 362 pm મળે.
BCC માટે પરમાણુ ત્રિજ્યા અને એકમ કોષની ભુજ: a = 4r/√3.
BCC ગોઠવણીવાળા તત્વોની ગણતરીમાં.
દા.ત.: Fe (BCC) ની ત્રિજ્યા 124 pm હોય તો a = (4 × 124)/1.732 ≈ 286 pm.
હીટ્સનિક બળ (Schottky) દોષ ઘનતા ઘટાડે છે, ફ્રેન્કલ દોષ (Frenkel) ઘનતા બદલતો નથી.
દોષ અને ઘનતા વિશે પ્રશ્નમાંથી સાચો દોષ ઓળખવા.
દા.ત.: AgBr માં ફ્રેન્કલ દોષ હોવાથી ઘનતા બદલાતી નથી; NaCl માં હીટ્સનિક દોષથી ઘનતા ઘટે છે.
n-ટાઇપ અર્ધચાળક બનાવવા માટે ગ્રુપ 14 (Si, Ge) માં ગ્રુપ 15 (P, As) મિશ્રિત કરો; p-ટાઇપ માટે ગ્રુપ 13 (B, Al) મિશ્રિત કરો.
અર્ધચાળક ડોપિંગ અને તેના પ્રકાર વિશેના પ્રશ્નોમાં.
દા.ત.: Si માં P મિશ્રિત કરવાથી n-ટાઇપ બને; Si માં B મિશ્રિત કરવાથી p-ટાઇપ બને.
અથervિદ્યુતવાહકતા (Band Theory) માં: વાહકની ચાલકતા પટ્ટી (Conduction band) ખાલી કે આંશિક ભરાયેલી હોય છે, અવાહકમાં બેન્ડ ગેપ > 3 eV હોય છે.
તત્વોની વાહકતા/અવાહકતા/અર્ધવાહકતા પ્રકૃતિ સમજવા.
દા.ત.: ડાયામગ્નેટિક પદાર્થોમાં બધા ઇલેક્ટ્રોન જોડાયેલા હોય; paramagnetic માં અયુગ્મિત ઇલેક્ટ્રોન હોય.
HCP અને FCC માં પ્રતિ પરમાણુ ઓક્ટાહેડ્રલ વિઓડ = 1, ટેટ્રાહેડ્રલ વિઓડ = 2.
વિઓડની સંખ્યા શોધવી હોય તેવા પ્રશ્નોમાં.
દા.ત.: જો HCP એકમ કોષમાં N પરમાણુ હોય, તો ઓક્ટાહેડ્રલ વિઓડ = N, ટેટ્રાહેડ્રલ વિઓડ = 2N.
બ્રેગના સૂત્રમાં nλ = 2d sin θ નો ઉપયોગ કરીને d (સ્તરો વચ્ચેનું અંતર) શોધો.
X-ray diffraction પ્રયોગો સંબંધિત પ્રશ્નોમાં.
દા.ત.: જો λ = 154 pm, θ = 30° હોય તો d = λ/(2 sin θ) = 154/(2×0.5) = 154 pm.
ઘનતાનું સૂત્ર ρ = ZM/(a³Nₐ) માં એકમો ધ્યાનમાં લો: a pm માં હોય તો a³ cm³ માં ફેરવો (1 pm = 10⁻¹⁰ cm).
ગણતરી કરતી વખતે એકમ ભૂલ ટાળવા.
દા.ત.: a = 400 pm = 4 × 10⁻⁸ cm; a³ = 64 × 10⁻²⁴ cm³.
આયનીય ઘનમાં કેટાયન/એનિયનનું કદ છોડીને દૂર જાય તો હીટ્સનિક દોષ; આંતરિક જગ્યામાં જાય તો ફ્રેન્કલ દોષ.
કયા પ્રકારનો દોષ છે તે ઓળખવા.
દા.ત.: AgCl માં Ag⁺ આંતરિક જગ્યાએ જાય છે → ફ્રેન્કલ દોષ.
ક્રિસ્ટલ અવશોષણ (Color Centers) માં F-કેન્દ્ર એનિયન ગેપમાં ઇલેક્ટ્રોન ફસાવાથી રંગ દેખાય છે.
રંગીન ઘન અથવા F-કેન્દ્ર સંબંધિત પ્રશ્નોમાં.
દા.ત.: NaCl માં સોડિયમ વધારે ઉષ્ણ કરવાથી Cl⁻ ગેપમાં ઇલેક્ટ્રોન રહે → પીળો રંગ.
