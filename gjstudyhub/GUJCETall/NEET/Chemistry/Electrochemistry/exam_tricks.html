🧪 GUJCET — Gujarati • Chemistry • Electrochemistry

🎯 પરીક્ષા ટ્રિક્સ

કોષ પ્રક્રિયા લખતી વખતે એનોડ ઓક્સિડેશન અને કેથોડ રિડક્શન — "AN OX, Cathode RED" મેમોનિક:
જ્યારે ગેલ્વાનિક કોષની કુલ પ્રક્રિયા અને ઇલેક્ટ્રોડ ઓળખવી હોય.
દા.ત.: Zn/Cu²⁺ કોષ: એનોડ (ઋણ ધ્રુવ) પર Zn → Zn²⁺ + 2e⁻ (ઓક્સિડેશન), કેથોડ (ધન ધ્રુવ) પર Cu²⁺ + 2e⁻ → Cu (રિડક્શન).
એકમ તાપમાને (298 K) નર્નસ્ટ સમીકરણમાં 2.303RT/F = 0.059 V થાય છે — આ મૂલ્ય જમણા હાથની આંગળીએ રાખો.
ઇલેક્ટ્રોડ સ્થિતિમાન કે કોષ વિભવ ગણતરી સીધો જ મૂકીને કરવાનો હોય.
દા.ત.: E_cell = E°_cell − (0.059/n) log₁₀Q. Zn-Cu કોષ માટે n = 2, જો [Zn²⁺]=0.01 M અને [Cu²⁺]=1 M હોય: E_cell = 1.10 − (0.059/2)log(0.01) = 1.10 + 0.059 = 1.159 V.
ફેરાડે અચળાંક F ≈ 96500 C/mol, પણ ઘણી વાર પ્રશ્નમાં F/2 ≈ 48250 C પણ વપરાય છે — H₂/Cl₂ જેવા દ્વિ-પરમાણ્વીય વાયુઓની રચનામાં n=2 હોય છે.
ઈલેક્ટ્રોલાઇસિસમાં વાયુનો આયતન કે દળ શોધવાનો હોય, ખાસ કરીને H₂, O₂, Cl₂ માટે.
દા.ત.: 1 F વિદ્યુત વીજળીથી STP પર H₂ = 11.2 L, O₂ = 5.6 L, Cl₂ = 11.2 L મુક્ત થાય. એટલે 1 F → 11.2 L H₂/Cl₂, 0.5 F → 5.6 L.
કોહલ્રાઉશના નિયમમાં જ्ञાત ઇલેક્ટ્રોલાઇટ્સનો ઉપયોગ કરી અજ્ઞાત લઘુવિદારક ઇલેક્ટ્રોલાઇટ (જેમ કે CH₃COOH) λ⁰ શોધી શકાય: λ⁰(弱) = λ⁰(મજબુત) + λ⁰(મજબુત) − λ⁰(મજબુત).
દુર્બળ પ્રબળ ઇલેક્ટ્રોલાઇટનું મોલર વાહકતા λ⁰ શોધવાનું હોય.
દા.ત.: λ⁰(CH₃COOH) = λ⁰(CH₃COONa) + λ⁰(HCl) − λ⁰(NaCl). આ બેસિસનો ઉપયોગ ઝડપી જવાબ માટે સીધો મૂકી શકાય.
ΔG° = −nFE°_cell — જો E°_cell > 0 હોય તો ΔG° < 0 (સ્વયંસ્ફૂર્ત), E°_cell < 0 હોય તો પ્રક્રિયા અસ્વયંસ્ફૂર્ત.
કોષની સ્વયંસ્ફૂર્તતા તરત ચકાસવા હોય, ગણતરી સિવાય જવાબ પસંદ કરવા હોય.
દા.ત.: જો E°_cell = −0.76 V હોય → ΔG° > 0, પ્રક્રિયા અસ્વયંસ્ફૂર્ત. F = 96500 C/mol અને n = 2 હોય તો ΔG° = −2 × 96500 × (−0.76) = +146.7 kJ/mol.
mz = ZIt → t = mz/(ZI) કે I = mz/(Zt), જ્યાં Z = મોલર દળ/(n×F) — એકમોની ગંદગી ન કરો: m ગ્રામ, I એમ્પિયર, t સેકન્ડ.
ઈલેક્ટ્રોલાઇસિસ પ્રશ્નમાં સમય, પ્રવાહ અથવા જમા થયેલ દળ શોધવાનો હોય.
દા.ત.: 30 মিনিটમાં Ag નો જમા કરવાનો હોય (M = 108, n = 1): I = (m × 96500)/(108 × t). જો 1.08 g Ag જમા થાય તો I = (1.08 × 96500)/(108 × 1800) = 0.5 A.
કોષ વિભવનો વિદ્યુતચુંબકીય બળ (emf) સાહસિક રીતે ઊંચા દ્વિ-ઇલેક્ટ્રોડ સ્થિતિમાન ધરાવતો કેથોડ બને: E°_cell = E°_કેથોડ − E°_એનોડ. મોટો E° ધ્રુવ કેથોડ.
બે આપેલા ઇલેક્ટ્રોડમાંથી કેથોડ/એનોડ ઓળખવા હોય અથવા E°_cell નીચે મૂકી જવાબ આપવા હોય.
દા.ત.: E°(Cu²⁺/Cu) = +0.34 V, E°(Zn²⁺/Zn) = −0.76 V → Cu કેથોડ, Zn એનોડ, E°_cell = 0.34 − (−0.76) = 1.10 V. ઝડપી તુલનાથી જવાબ ફરી જાય.
લઘુવિદારકતા κ અને મોલર લઘુવિદારકતા Λ_m વચ્ચેનો સંબંધ: Λ_m = κ × (1000/c) j્યાં c mol/L માં — એકમ R cm² mol⁻¹ મેળવવા 1000 ગુણો.
Λ_m શોધવાનો પ્રશ્ન હોય જ્યારે κ અને સાંદ્રતા આપેલી હોય.
દા.ત.: κ = 1.25 × 10⁻³ S cm⁻¹, c = 0.01 M → Λ_m = 1.25 × 10⁻³ × (1000/0.01) = 125 S cm² mol⁻¹.
વોલ્ટેઇક કોષના ચિહ્ન લેખનમાં ડાબી બાજુ એનોડ (ઓક્સિડેશન) અને જમણી બાજુ કેથોડ (રિડક્શન): એનોડ || કેથોડ. વાયુ ઇલેક્ટ્રોડ Pt વડે દર્શાવો.
કોષનું પ્રતીકાત્મક રૂપ લખવાનું હોય અથવા ઇલેક્ટ્રોડની સામગ્રી પસંદ કરવાની હોય.
દા.ત.: Zn(s) | Zn²⁺(aq) || Cu²⁺(aq) | Cu(s). H₂ ઇલેક્ટ્રોડ: Pt(s) | H₂(g) | H⁺(aq).
બેટરી પ્રશ્નોમાં: લેડ-એકუმ્યુલેટરનું એનોડ Pb, કેથોડ PbO₂, इलेक्ट्रोलाइट H₂SO₄; ડેનિયલ કોષનું એનોડ Zn, કેથોડ Cu, इलेक्ट्रोलाइट ZnSO₄/CuSO₄.
પ્રશ્નમાં બેટરી પ્રકાર અને તેના ઘટકો પસંદ કરવાના હોય.
દા.ત.: લેડ-એકუმ્યુલેટર: એનોડ反应 Zn → Zn²⁺ + 2e⁻ નથી, પણ Pb → PbSO₄; કેથોડ PbO₂ → PbSO₄. યાદ રાખો: 'Pb એનોડ, PbO₂ કેથોડ'.
ઈલેક્ટ્રોકેમિકલ સિરીઝમાં ઊંચા E° ધરાવતો ધાતુની આયન નીચા E° ધરાવતી ધાતુને તેના આયનના દ્રાવણમાંથી સ્થાનાંતરિત કરી શકે છે.
સ્થાનાંતરણ પ્રક્રિયા શક્ય છે કે નહીં તે ઝડપી ચકાસણી કરવા હોય.
દા.ત.: Zn (E° = −0.76 V) Cu²⁺ દ્રાવણમાં મૂકતાં Zn + Cu²⁺ → Zn²⁺ + Cu સ્વયંસ્ફૂર્ત, કારણ કે E°_cell = +1.10 V > 0. વિપરીત: Cu + Zn²⁺ → નહીં.
ફ્યુઅલ સેલ (H₂−O₂) માં: એનોડ પર H₂ → 2H⁺ + 2e⁻, કેથોડ પર O₂ + 4H⁺ + 4e⁻ → 2H₂O; કુલ: 2H₂ + O₂ → 2H₂O. E°_cell ≈ 1.23 V.
ફ્યુઅલ સેલ સંબંધિત પ્રશ્નમાં ઇલેક્ટ્રોડ પ્રક્રિયાઓ કે વિભવ શોધવા હોય.
દા.ત.: E°_cell = E°_O₂/H₂O − E°_H⁺/H₂ = 1.23 − 0 = 1.23 V. O₂ ની લબ્ધિ 4e⁻, H₂ ની 2e⁻; n = 4 (કુલ).
વિદ્યુતવિભાજનમાં આયનિક સ્થાનાંતરણ વેગ (离子迁移数) t₊ + t₋ = 1 — યાદ રાખો કે જો t₊ = 0.4 હોય તો t₋ = 0.6.
离子迁移数 શોધવાનો પ્રશ્ન હોય જ્યારે એક મૂલ્ય આપેલું હોય.
દા.ત.: AgNO₃ માં t(Ag⁺) = 0.47, તેથી t(NO₃⁻) = 1 − 0.47 = 0.53. વિકલ્પોમાંથી સાચો જોડો ઝડપી તપાસી શકાય.
