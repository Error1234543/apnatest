એલ્કોહોલ, ફિનોલ અને ઇથર — ઝડપી પુનરાવર્તન

🧪 GUJCET — Gujarati • Chemistry • Alcohols, Phenols and Ethers

🧠 યાદ રાખો

એલ્કોહોલમાં –OH સમૂહ સંતૃપ્ત કાર્બન સાથે જોડાયેલો હોય છે; ફિનોલમાં –OH સીધો બેન્ઝીન રિંગના કાર્બન સાથે જોડાયેલો હોય છે.
પ્રાથમિક (1°) એલ્કોહોલ: –OH વાળો C એક જ C સાથે જોડાયેલો; દ્વિતીયક (2°): બે C સાથે; તૃતીયક (3°): ત્રણ C સાથે.
લ્યુકેસ પરીક્ષણ: 3° એલ્કોહોલ તરત ઘાટો સ્તરભેદ આપે, 2° ~5 મિનિટે, 1° સામાન્ય તાપે નહીં.
ઓક્સિડેશન: 1° એલ્કોહોલ → એલ્ડિહાઇડ → કાર્બોક્સિલિક એસિડ; 2° એલ્કોહોલ → કેટોન; 3° એલ્કોહોલ ઓક્સિડેશન સહન નથી કરતો.
ફિનોલ એથેનોલ કરતાં વધુ એસિડિક છે કારણ કે ફિનોક્સાઇડ આયન રેઝોનન્સથી સ્થિર થાય છે.
ઇથરમાં C–O–C બંધકોણ ~111.7° (બેરિલિયમ ઑક્સાઇડ જેટલો) હોય છે; આંશિક ધ્રુવીય બંધારણ ધરાવે છે.
ઇથર હવામાં ધીમે ધીમે પેરોક્સાઇડ બનાવે છે — તેથી ઇથરનો સ્ટોરેજ સાવચેતીથી કરવો.
હાઇડ્રોજન બંધને કારણે એલ્કોહોલ/ફિનોલના ઉત્કલનબિંદુ સમાન આણ્વીય દળ ધરાવતા એલ્કેન/ઇથર કરતાં ઘણાં ઉચ્ચ હોય છે.
ગ્રિગ્નાર્ડ કારક (RMgX) સાથે એલ્ડિહાઇડ/કેટોનની પ્રક્રિયા પછી જળવિભાજનથી એલ્કોહોલ મળે છે.

⚡ ઝડપી સૂત્રો

ઇથેનોલનું ઉદ્દીપક દ્વારા નિર્જલીકરણ: C₂H₅OH →(conc. H₂SO₄, 170°C)→ C₂H₄ + H₂O
ફિનોલનું બ્રોમીકરણ: C₆H₅OH + 3Br₂ → C₆H₂Br₃OH (અવતરણ) + 3HBr — સફેદ અવક્ષેપ.
કોલ-સ્મિથ પ્રક્રિયા: CH₄ + O₂ →(Cu, 523K, 100 atm)→ CH₃OH (મેથેનોલ).
ઓક્સો પ્રક્રિયા: R–CH=CH₂ + CO + H₂ →(ઉચ્ચ દબાણ, ઉદ્દીપક)→ R–CH₂CH₂CHO →(H₂/Ni)→ R–CH₂CH₂CH₂OH
ઇથરનું HBr સાથે વિભાજન: R–O–R + HBr → R–OH + R–Br
ફિનોલનું રિડક્શન: C₆H₅OH + Zn dust → C₆H₆ + ZnO
એસ્ટરિકરણ: R–OH + R'–COOH →(H⁺)→ R'–COOR + H₂O

✅ વન-લાઈનર્સ

મેથેનોલ (CH₃OH) એ સૌથી સરળ એલ્કોહોલ છે; તેને મેથાઇલ અલ્કોહોલ પણ કહેવાય છે.
ઇથેન-1-ઓલ (C₂H₅OH) એ સામાન્ય એથેનોલ છે જે મધ્યસ્થ પીણાંમાં ન હોવા છતાં ઔદ્યોગિક દ્રાવક તરીકે વપરાય છે.
પ્રોપેન-2-ઓલ (આઇસોપ્રોપાઇલ અલ્કોહોલ) 2° એલ્કોહોલ છે અને ઓઝોનના વિઘટનમાંથી પણ મળે છે.
ટર્શિયરી બ્યુટાનોલ (t-BuOH) એ 3° એલ્કોહોલ છે જે લ્યુકેસ પરીક્ષણમાં તરત પ્રતિક્રિયા આપે છે.
ફિનોલ (C₆H₅OH) એ એકોલ નથી; તે એક અલગ શ્રેણીનું યૌગિક છે જે એસિડિક ગુણધર્મ દર્શાવે છે.
ફિનોલ પિટ્ટાશુભ રંગનું સ્ફટિકીય યૌગિક છે અને તેનું ઉત્કલનબિંદુ ~181°C છે.
ઓર્થો- અને પારા-નાઇટ્રોફિનોલ કરતાં પારા-ક્લોરોફિનોલ વધુ એસિડિક છે કારણ કે –NO₂ સમૂહ –I અને –M બંને અસર દર્શાવે છે.
ઇથરનું IUPAC નામકરણ: આલ્કોક્સિ એલ્કેન (દા.ત., CH₃OCH₂CH₃ = મેથોક્સીએથેન).
વિલિયમસન સંશ્લેષણ: R–X + R'–O⁻Na⁺ → R–O–R' + NaX — આ એક સંયોજક પ્રક્રિયા છે.
એલ્કોહોલનું વિજલીવિભાજન (dehydrogenation) Cu ઉદ્દીપક પર 573K તાપે: 1° → એલ્ડિહાઇડ, 2° → કેટોન.
ફિનોલનું સોડિયમ સાથે પ્રતિક્રિયા: 2C₆H₅OH + 2Na → 2C₆H₅O⁻Na⁺ + H₂ — આ એસિડિક ગુણધર્મ સાબિત કરે છે.
ફિનોલનું સલ્ફ્યુરિક એસિડ સાથે પ્રતિક્રિયા (ઠંડુ): o-હાઇડ્રોક્સીબેન્ઝીન સલ્ફો એસિડ મળે છે.
એલ્કોહોલનું PCC (પાયરિડિનમ ક્રોમેટ) સાથે ઓક્સિડેશન એલ્ડિહાઇડ આપે છે — આગળ કાર્બોક્સિલિક એસિડ બનતું નથી.
ઇથર એક નિષ્ક્રિય દ્રાવક છે પરંતુ પ્રબળ એસિડ સાથે પ્રતિક્રિયા કરે છે.
પોલીહાઇડ્રિક એલ્કોહોલ: ઇથેન-1,2-ડાયોલ (ગ્લાઇકોલ) અને પ્રોપેન-1,2,3-ટ્રાયોલ (ગ્લિસરોલ).
