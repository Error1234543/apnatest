જૈવરાસાયણિક તત્વો (p-બ્લોક તત્વો)

🧪 GUJCET — Gujarati • Chemistry • Some p-Block Elements

ગ્રુપ 13 — બોરોન પરિવાર
ગ્રુપ 13 ના તત્વો: B, Al, Ga, In, Tl. બાહ્યતારીક ઇલેક્ટ્રોનિક કક્ષક: ns²np¹
B નું વિन्यास: 1s²2s²2p¹; Al: [Ne]3s²3p¹; Tl: [Xe]4f¹⁴5d¹⁰6s²6p¹
આયનીકરણ એન્થાલ્પી ગ્રુપમાં ઉતરતાં સામાન્ય રીતે ઘટે છે, પણ Al < B અને Tl > In જેવી અસંગતતાઓ જોવા મળે છે.
⚡ બોરોનની અપવાદીય ઇલેક્ટ્રોનેગેટિવિટી અને નાનો કદ — તેને અન્ય ધાતુઓથી અલગ પાડે છે.
ઇલેક્ટ્રોનિક રચનાના આધારે B અધાતુ, Al/Ga/In/Tl ધાતુઓ છે.
દ્રવ્યમાન વધતાં દ્રવ અને ઉત્કળનાં બિંદુઓ સામાન્ય રીતે ઘટે છે (Ga સિવાય — Ga નું દ્રવ્યાંનું તાપમાન ખૂબ નીચું છે).
અષ્ઠક (Octet) પૂરું કરવા B ઘણાં સંયોજનોમાં સહસંયોજક બંધ બનાવે છે; Al ધાતુલક્ષી બંધ પ્રદર્શિત કરે છે.
નાનું પરમાણુ કદ + ઊંચું IEઅષ્ઠક પૂર્ણ ન થતાં B લેવીસ એસિડ તરીકે વર્તે
બોરોનના રાસાયણિક ગુણધર્મો
B + 3F₂ → 2BF₃ (ઉચ્ચ તાપમાને); B + 3Cl₂ → 2BCl₃
B ધાતુઓ (NaOH) સાથે પ્રવર્તી બોરેટ્સ આપે છે: 2B + 6NaOH → 2Na₃BO₃ + 3H₂
2B + 3H₂ → 2BH₃ (Diborane, B₂H₆) — ઉત્પ્રેરક ઉપસ્થિતિએ
બોરોન હાલોજનબંધી: BF₃, BCl₃, BBr₃ — તમામ સમતલીય ત્રિકોણીય, sp² સંકર
⚡ BF₃ સૌથી ક્ષીણ લેવીસ એસિડ છે કારણ કે F માંથી B માં π-પાછું બંધ (back bonding) મજબૂત છે.
BCl₃ બાબતે: sp² સંકર, સમતલીય, ભૂખંડીય રચના, બોરોન પર ખાલી p-કક્ષક
ભૂખંડીય B (ખાલી p)લેવીસ એસિડ — નાણ્યુક્લિયોફાઈલ આકર્ષે
ડાયાગોનલ સંબંધ (B–Si)
B અને Si વચ્ચે ડાયાગોનલ સંબંધ: બંનેનું ઇલેક્ટ્રોનેગેટિવિટી લગભગ સમાન (≈2.0)
બંને ધાત્વીય હેલોજનબંધી (Covalent halides) બનાવે છે જે જળવિભાજિત થાય છે.
⚡ B અને Si બંને અષ્ઠક પૂરું કરવા પ્રવૃત્તિ દાખવે છે અને +3 આક્સિડેશન અવસ્થા પ્રદર્શિત કરે છે.
📝 📌 GUJCET TIP: Al નું દ્રવ્યાંનું તાપમાન Ga કરતાં વધારે છે — આ અપવાદ યાદ રાખો.
એલ્યુમિનિયમના ગુણધર્મો
Al + O₂ → Al₂O₃ (એલ્યુમિનિયમ ઓક્સાઈડ — અમ્ફોટેરિક)
Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O
Al₂O₃ + 2NaOH → 2NaAlO₂ (સોડિયમ એલ્યુમિનેટ) + H₂O
Al હાલોજનબંધી બનાવે છે: AlCl₃, AlBr₃ — AlCl₃ એ બાયરોમરિક (dimer) સ્વરૂપે Al₂Cl₆ રૂપે અસ્તિત્વ ધરાવે છે.
⚡ AlCl₃ માં Al sp³ સંકર થાય છે અને બ્રિજ Cl વડે બે Al આકર્ષાય છે — લેવીસ એસિડ.
Al ના સંયોજનોમાં +3 આક્સિડેશન અવસ્થા સ્થિર; Tl માં +1 અવસ્થા વધુ સ્થિર (અણિત યુગ્મ અસર).
Tl (+1 સ્થિર)Inert pair effect — 6s² ઇલેક્ટ્રોન બંધમાં ભાગ નથી લેતા
બોરોન સંયોજનો — બોરેક્સ અને બોરિક એસિડ
બોરેક્સ: Na₂B₄O₇·10H₂O (સોડિયમ ટેટ્રાબોરેટ)
બોરિક એસિડ: H₃BO₃ અથવા B(OH)₃ — નિર્બળ મોનોપ્રોટિક લેવીસ એસિડ
B(OH)₃ + 2H₂O ⇌ [B(OH)₄]⁻ + H₃O⁺ — OH⁻ સ્વીકારી એસિડ તરીકે વર્તે
H₃BO₃ → HBO₂ (મेटાબોરિક એસિડ) → B₂O₃ (બોરોન ટ્રાયોક્સાઈડ) ∆ તાપમાને
⚡ B(OH)₃ પ્રોટોન દાન કરતું નથી, OH⁻ સ્વીકારે છે — તેથી લેવીસ એસિડ.
📝 📌 Na₂B₄O₇ નું જળવિભાજન: B₄O₇²⁻ + 7H₂O → 2[B(OH)₄]⁻ + 2H₃BO₃
ડાયબોરેન (B₂H₆) — રચના
B₂H₆ માં 4 સાધારણ B–H–B સીધા બંધ અને 2 B–H–B બ્રિજ બંધ છે.
B₂H₆ માં: 3-center-2-electron (3c–2e) બંધ — બ્રિજિંગ H સહિત
ડાયબોરેન અસ્થિર છે, ઓરડાના તાપમાને જલદી જ્વલન શીલ છે: B₂H₆ + 3O₂ → B₂O₃ + 3H₂O
B₂H₆ + 6H₂O → 2B(OH)₃ + 6H₂ (જળવિભાજન)
B₂H₆ + 2NaH → 2NaBH₄ (સોડિયમ બોરોહાઈડ્રાઈડ બને છે)
⚡ 3c–2e બંધ (Bridge bond) — GUJCET માં આવશ્યક પ્રશ્ન!
બોરોન હેલાઈડ્સ અને એલ્યુમિનિયમ ક્લોરાઈડ
BF₃ + NH₃ → F₃B←NH₃ (લેવીસ એસિડ-બેઝ એડક્ટ)
BF₃, BCl₃, BBr₃ — ત્રણેય sp² સંકર, સમતલીય ત્રિકોણીય રચના.
⚡ BF₃ માં F ના lone pair → B વડે π-back bonding મજબૂત, તેથી BF₃ ની લેવીસ એસિડિટી ક્ષીણ.
AlCl₃ (dimer Al₂Cl₆): Al sp³, ચતુષ્ફલકીય. બ્રિજ Cl વડે બે Al જોડાય છે.
2Al + 6HCl → 2AlCl₃ + 3H₂↑
AlCl₃ (લેવીસ એસિડ)ફ્રીડલ-ક્રાફ્ટ્સ એસિલેશન/એલ્કાઈલેશન ઉત્પ્રેરક
ગ્રુપ 14 — કાર્બન પરિવાર
ગ્રુપ 14 તત્વો: C, Si, Ge, Sn, Pb. બાહ્યતારીક ઇલેક્ટ્રોનિક રચના: ns²np²
કેટેનાશન (Catenation) સક્મતમ C માં — C–C બંધ ઊર્જા ~348 kJ/mol.
⚡ C > Si > Ge ક્રમમાં કેટેનાશન સક્મત્તળ ઘટે છે. Si–Si બંધ ઊર્જા ~226 kJ/mol.
આક્સિડેશન અવસ્થા: +4 અને +2; ગ્રુપમાં ઉતરતાં +2 સ્થિર બને છે (અણિત યુગ્મ અસર).
Pb (+2 સ્થિર)Inert pair effect — 6s² ઇલેક્ટ્રોન બંધમાં ભાગ નથી લેતા
📝 📌 Tl(+1) અને Pb(+2) સ્થિર છે — આયનિક સ્વરૂપ મજબૂત.
કાર્બનના અલોરૂપો
વાજ્મળી (Diamond): sp³ સંકર, 3Dનેટવર્ક, અત્યંત કઠોર, વિદ્યુત અવાહક.
ગ્રેફાઈટ (Graphite): sp² સંકર, સમતલીય સ্তર, લંબરૂપ π-ઇલેક્ટ્રોન ચालक — વિદ્યુત વાહક.
C(વાજ્મળી) → C(ગ્રેફાઈટ) ∆H = −1.9 kJ/mol (ગ્રેફાઈટ વધુ સ્થિર)
ફુલરેન (C₆₀): બડી-આકાર, sp² સંકર જેવું, ગોળાકાર અણુ.
⚡ ગ્રેફાઈટના સ્તર વચ્ચે van der Waals બળ — સરકી શકે તેવા સ્તર.
કાર્બન મોનોક્સાઈડ (CO)
C + O₂ (અપૂરતું) → CO (અપૂરતું ઓક્સિજન)
CO + ½O₂ → CO₂ (જ્વલન)
CO માં C≡O ત્રિબંધ: એક σ, બે π; એક π બંધ દ્વિ-ધ્રુવીય (coordinate) પ્રકારનો.
⚡ CO હીમોગ્લોબિન સાથે મજબૂત બંધ બનાવે છે — વિષાળુ.
CO લેવીસ બેઝ તરીકે પણ વર્તે (C પર lone pair).
📝 📌 CO + PdCl₂ + H₂O → Pd↓ (કાળો) + CO₂ + 2HCl — CO ની ઓળખ.
કાર્બન ડાયઓક્સાઈડ (CO₂)
C + O₂ → CO₂ (પૂરતા ઓક્સિજનમાં દહન)
CaCO₃ → CaO + CO₂ (ઉષ્મ વિઘટન)
CO₂ રચના: O=C=O, રેખીય, sp સંકર, બે σ + બે π બંધ.
CO₂ + H₂O ⇌ H₂CO₃ (કાર્બોનિક એસિડ) — નિર્બળ એસિડ.
CO₂ + 2NaOH → Na₂CO₃ + H₂O
CO₂ + NaOH (અધિક) → NaHCO₃ (સોડિયમ બાયકાર્બોનેટ)
⚡ CO₂ વાયુ સૂકવણી માટે ઉપયોગી નથી (ક્ષારક સાથે પ્રક્રિયા).
સિલિકન અને તેના સંયોજનો
Si નું વિન્યાસ: [Ne]3s²3p². ચતુષ્ફલકીય sp³ સંકર, સિલિકા (SiO₂) નેટવર્ક.
SiO₂ + 4HF → SiF₄ + 2H₂O; SiF₄ + 2HF → H₂SiF₆ (હેક્સાફ્લોરોસિલિક એસિડ)
સિલિકોન ટેટ્રાક્લોરાઈડ (SiCl₄) જળવિભાજિત થાય: SiCl₄ + 2H₂O → SiO₂ + 4HCl
⚡ SiCl₄ નું જળવિભાજન — COCl₂ (ફોસجين) કરતાં બહુ ઝડપી.
📝 📌 COCl₂ (ફોસજિન) — કાર્બોનિલ હેલાઈડ, અત્યંત વિષાળુ વાયુ.
સિલિકેટ્સ અને સિલિકોન સંયોજનો
સિલિકેટ રચના: [SiO₄]⁴⁻ એકમો ભાગીદારી દ્વારા શૃંખલા, પ્લેટ, ત્રિપરિમાણીય જાળી બનાવે છે.
Orthosilicate: [SiO₄]⁴⁻ (ઉદા. Zn₂SiO₄); Pyrosilicate: [Si₂O₇]⁶⁻
Chain silicate (pyroxene): [SiO₃]ₙ²ⁿ⁻; Sheet silicate (mica/talc): [Si₂O₅]ₙ²ⁿ⁻
Zeolite (સિઓલાઈટ): AlSiO₄ નેટવર્ક, છિદ્રાળુ, આણ્વિક છલ્લો (molecular sieve) તરીકે.
NaAlSiO₄·nH₂O — સાધારણ સિઓલાઈટ
⚡ સિઓલાઈટ ડીટર્જન્ટમાં Ca²⁺/Mg²⁺ દૂર કરે છે — જળકઠોરતા નિવારે.
સિલિકોન્સ (Silicones)
સિલિકોન્સ — Organosilicon પોલીમર: –[R₂SiO]ₙ– રચના, સિલિકોન-ઓક્સિજન મુખ્ય શૃંખલા.
R₂SiCl₂ + H₂O → –[R₂SiO]ₙ– + 2HCl (જળવિભાજન પછી પોલીમરાઈઝેશન)
સિલિકોન્સ ઉષ્મા, ઓઝોન, રાસાયણિકો પ્રત્યે સ્થિર; જળ પ્રતિકારી; વિદ્યુત અવાહક.
⚡ સિલિકોન સિલિકોન બંધ (Si–O) ઉષ્મા સ્થિરતા આપે છે.
📝 📌 Silicone sealants, lubricants, medical implants માં વપરાય.
બોરોન અને સિલિકોનના ઉપયોગ
બોરોન: બોરોસ્લિક ગ્લાસ (Pyrex), ન્યુટ્રોન શોષક ( 핵કેંદ્રમાં), જ્વલન શીલ જહાજમાં.
બોરેક્સ: ગ્લાસ, સેરામિક, સાફાઈ ઉત્પાદનો, વેલ્ડિંગ ફ્લક્સ.
કાર્બન: વાજ્મળી (કાંટા), ગ્રેફાઈટ (લેડ, ઇલેક્ટ્રોડ), સક્રિય કાર્બન (શોષક).
સિલિકોન: ટ્રાન્ઝિસ્ટર, સોલર સેલ, સિલિકોન ઓર્ગેનિક સંયોજનો.
⚡ યાદ રાખો: બોરોન +3, કાર્બન +4/+2, સિલિકોન +4 — GUJCET માં આક્સિડેશન અવસ્થા પુછાય છે.
📝 📌 પરીક્ષા Tip: B₂H₆ રચના + 3c-2e બંધ, CO₂ રેખીય, સિલિકેટ્સના પ્રકાર — ત્રણેય GUJCET ફેવરિટ.
મહત્વના બંધ અને બંધ ઊર્જા
C–C: 348 kJ/mol; Si–Si: 226 kJ/mol; B–H: ~389 kJ/mol
C–C બંધ શક્તિ વધુ હોવાથી C એ કેટેનાશન માટે શ્રેષ્ઠ.
Si–O બંધ ઊર્જા ~452 kJ/mol — સિલિકેટ્સ સ્થિરતાનું કારણ.
⚡ Si–O બંધ મજબૂત હોવાથી સિલિકોન સંયોજનો ઉષ્મા અને રાસાયણિક સ્થિરતા ધરાવે.
મજબૂત Si–O બંધસિલિકેટ્સ/સિલિકોન્સની ઉચ્ચ સ્થિરતા
📝 📌 B₂H₆ માં B–H (સાધારણ) અને B–H–B (બ્રિજ) બંધ બંને છે.
