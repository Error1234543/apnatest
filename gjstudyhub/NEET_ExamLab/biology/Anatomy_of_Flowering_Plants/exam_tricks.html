🎯 પરીક્ષા ટ્રિક્સ

મેરિસ્ટેમેટિક vs પરમાનંત ટિશ્યુ — 'વહેતા vs સ્થાયી' નિયમ: જો કોષ વિભાજનમાં સક્રિય હોય, તો મેરિસ્ટેમેટિક; જો વિભેદિત અને કાર્યરત હોય, તો પરમાનંત. પ્રશ્નમાં 'સ્થિર'/'પરિણામી' શબ્દ આવે તો તરત પરમાનંત લખવું.
જ્યારે પ્રશ્ન પૂછે કે કઈ ટિશ્યુ કોષ વિભાજન ચાલુ રાખે છે અથવા કઈ ટિશ્યુ અંતિમ રચના ધરાવે છે.
દા.ત.: એપિકલ મેરિસ્ટમ → બંધ શાખાની વૃદ્ધિ; પેરેન્કાઇમા → ભંડારણ (ખોરાક/પાણી). જવાબમાં 'વૃદ્ધિ' આવે તો મેરિસ્ટમ, 'ભંડારણ/આધાર' આવે તો પેરેન્કાઇમા.
સાદા vs જટિલ પરમાનંત ટિશ્યુ — 'એક vs અનેક': સાદા = એક જ પ્રકારના કોષો (પેરેન્કાઇમા, કોલેન્કાઇમા, સ્ક્લેરેન્કાઇમા); જટિલ = બે+ પ્રકારના કોષો (ક્સિલમ, ફ્લોએમ). આ શબ્દથી જ જવાબ નક્કી.
વર્ગીકરણનો પ્રશ્ન આવે તો — 'સાદું પરમાનંત ટિશ્યુ કઈ છે?' તેમ જ્યારે 'ચત્તર-રચના ધરાવતું ટિશ્યુ' પૂછાય.
દા.ત.: ક્સિલમમાં ટ્રેકિઓડ, વેસેલ, ક્સિલમ પેરેન્કાઇમા, ક્સિલમ સ્ક્લેરેન્કાઇમા → બે પ્રકારના કોષો → જટિલ. ફ્લોએમમાં સુહાણ કોષ, સંગાઈ કોષ, ફ્લોએમ પેરેન્કાઇમા, ફ્લોએમ સ્ક્લેરેન્કાઇમા → જટિલ.
ઓપન vs ક્લોઝડ વેસ્ટિક્યુલર બંડલ — 'કેમ્બિયમ = ખુલ્લું': ઓપન = કેમ્બિયમ હાજર (દ્વિદળીય સ્ટેમ); ક્લોઝડ = કેમ્બિયમ ગેરહાજર (એકદળીય સ્ટેમ). જવાબમાં 'કેમ્બિયમ' જોવા મળે તો ઓપન; ન મળે તો ક્લોઝડ.
વેસ્ટિક્યુલર બંડલની પ્રકારપરિક્ષા, કયા છોડમાં બંને હોય તેવો પ્રશ્ન.
દા.ત.: દ્વિદળીય સ્ટેમ → વેસ્ટિક્યુલર બંડલ રિંગમાં ગોઠવાયેલા + મધ્યમાં કેમ્બિયમ = ઓપન. એકદળીય સ્ટેમ → છીટકાણી ગોઠવણી + કેમ્બિયમ ગેરહાજર = ક્લોઝડ.
પેરેન્કાઇમાના પ્રકાર — કાર્ય પરથી ઓળખ: 'રસધાર' = સ્ટોરેજ, 'લીલું' = ક્લોરેન્કાઇમા (પ્રકાશસંશ્લેષણ), 'વાયુપૂર્ણ' = એરેન્કાઇમા (અક્વાટિક છોડ). પ્રશ્નમાં કાર્ય આપેલ હોય તો બ્રેકેટમાં દર્શાવેલ શબ્દ સાથે જોડો.
કયા પ્રકારના પેરેન્કાઇમાના કોષોમાં વાયુકોષો છે? અથવા કાંડ/પર્ણમાં પ્રકાશસંશ્લેષણ કરે તેવી ટિશ્યુ કઈ?
દા.ત.: ઉદ્ભિદ (જળમય છોડ) માં વાયુકોષો = એરેન્કાઇમા. પર્ણના મેસોફિલમાં સ્તંભાકાર/મુક્ત પેરેન્કાઇમા = ક્લોરેન્કાઇમા. બીજ/વળાંક/કંદમાં ભંડારણ પેરેન્કાઇમા.
દ્વિદળીય મૂળ vs એકદળીય મૂળ — 'પ્રોટોક્સિલમ બહિર્મુખ': દ્વિદળીય મૂળમાં પ્રોટોક્સિલમ બહિર્મુખ (એક્ઝાર્ક) હોય છે; એકદળીય મૂળમાં પ્રોટોક્સિલમ વ્યાપક હોય (પોલિાર્ક). પ્રશ્નમાં 'એક્ઝાર્ક' શબ્દ આવે તો તરત દ્વિદળીય મૂળ જવાબ.
મૂળના બંધાણનો પ્રશ્ન — કયા છોડમાં પ્રોટોક્સિલમનું સ્થાન કેવું?
દા.ત.: દ્વિદળીય મૂળ → પોલિસ્ટેલ (ઘણા ખંડ) + એક્ઝાર્ક પ્રોટોક્સિલમ. એકદળીય મૂળ → ઘણા વૃત્તાકાર વેસ્ટિક્યુલર બંડલ + પોલિાર્ક પ્રોટોક્સિલમ.
પર્મિડર્મ (બાર્ક) — 'ફેલોજન = કોર્ટેક્સમાંથી': સેકન્ડરી વૃદ્ધિમાં ફેલોજન (કોર્ક કેમ્બિયમ) કોર્ટેક્સ પેરેન્કાઇમામાંથી ડીડિફરેન્શિએટ થાય છે. ફેલેમ = બહાર (કાંધ), ફેલોડર્મ = અંદર. જવાબમાં 'કોર્ટેક્સ' આવે તો ફેલોજનનો ઉৎપત્તિસ્થળ.
ફેલોજન ક્યાંથી બને? ફેલેમ/ફેલોડર્મ કયા દિશામાં બને તેવો પ્રશ્ન આવે.
દા.ત.: ફેલોજન → કોર્ટેક્સમાંથી (સીધો ત્યાંથી જવાબ). ફેલેમ = બાહ્ય (કાંધ બને), ફેલોડર્મ = અંતઃ (મધ્યસ્થ ટિશ્યુ બને). ઇપિડર્મિસ/પેરિસાયકલ/પાઈથોફેલ એ ખોટા વિકલ્પો છે.
સ્ટેમ vs મૂળ ક્રોસ-સેક્શન — 'કેન્ડ્રલ vs કેન્ડ્રિક': દ્વિદળીય સ્ટેમમાં વેસ્ટિક્યુલર બંડલ રિંગમાં + વ્યાસ્ટેમેર (મધ્યમાં મજ્જા) + હાઈપોડર્મિસ કોલેન્કાઇમા; દ્વિદળીય મૂળમાં સ્ટેલ સેન્ટ્રલ (કેન્ડ્રલ), પેરિસાયકલ સ્ક્લેરેન્કાઇમા, હાઈપોડર્મિસ પેરેન્કાઇમા. જવાબમાં 'રિંગ' + 'હાઈપોડર્મિસ કોલેન્કાઇમા' → સ્ટેમ; 'કેન્ડ્રલ' + 'પેરિસાયકલ સ્ક્લેરેન્કાઇમા' → મૂળ.
ક્રોસ-સેક્શન ફ્રી આપેલ હોય અને કહ્યું હોય કે આ કઈ અંગનું છે?
દા.ત.: ST 9: રિંગમાં વેસ્ટિક્યુલર બંડલ, હાઈપોડર્મિસ કોલેન્કાઇમા → દ્વિદળીય સ્ટેમ. M 5: કેન્ડ્રલ સ્ટેલ, પેરિસાયકલ સ્ક્લેરેન્કાઇમા, પોલિસ્ટેલ → દ્વિદળીય મૂળ.
પર્ણ — 'સ્ટોમેટા બે પાસે': દ્વિદળીય પર્ણમાં સ્ટોમેટા બંને બાજુએ (એપિસ્ટોમેટિક); એકદળીય પર્ણમાં ઘણીવાર ફક્ત નીચલી સપાટી પર. પણ જો પ્રશ્નમાં 'હાયપોસ્ટોમેટિક' શબ્દ આવે, તો એકદળીય પર્ણ જવાબ.
પર્ણના ક્રોસ-સેક્શનમાં સ્ટોમેટાની ગોઠવણ વિશે પૂછાય.
દા.ત.: દ્વિદળીય પર્ણ (ઉદા. ખાંડનો છોડ) → સ્ટોમેટા બંને બાજુએ. એકદળીય પર્ણ → હાયપોસ્ટોમેટિક (નીચલી સપાટીએ વધુ સ્ટોમેટા).
ક્સિલમ તત્ત્વો — 'ટ્રેકિઓડ vs વેસેલ': ટ્રેકિઓડ = નાનાં, દીવાલ પર ટેલરેટ/સ્ક્લેરોસેલ્યુલોસિસ, અંતિમ ન હોય; વેસેલ = મોટાં, દીવાલ પર લેમિનેર/રિંગ/સ્પિરલ થિકનિંગ, ખુલ્લાં સરવૈ (પરપોટા વગર). ટ્રેકિઓડ દીવાલ પર ઢાળવાળા છેડા (tapered ends); વેસેલ સીધા છેડા સાથે પાઇપ જેવા.
ક્સિલમના કઈ ઘટકો જીવંત નથી? અથવા કઈ ઘટક ગલિતાઈ ગ્રંથિ સાથે સંકળાયેલું છે?
દા.ત.: ક્સિલમ પેરેન્કાઇમા = જીવંત ઘટક (માત્ર). બાકીના ત્રણ — ટ્રેકિઓડ, વેસેલ, ક્સિલમ સ્ક્લેરેન્કાઇમા — મૃત. ડ્રાયિંગ/ઘર્ષણમાં મદદ = ક્સિલમ સ્ક્લેરેન્કાઇમા.
ફ્લોએમ — 'સુહાણ vs સંગાઈ': સુહાણ કોષ (Sieve tube) = નિષ્ક્રિય, પ્રાવસ્થામાં; સંગાઈ કોષ (Companion cell) = સક્રિય, ન્યુક્લિયસ ધરાવે. જવાબમાં 'સંગાઈ કોષ ન હોય' = એંગિયોસ્પર્મના સિવાયના (જેમ ગાઈમનોસ્પર્મ). એલ્બ્યુમિનસ કોષ = ગાઈમનોસ્પર્મમાં સંગાઈ કોષનું બદલું.
ફ્લોએમના સુહાણ કોષ સાથે સંકળાયેલો કોષ કયો? અથવા કયા છોડમાં સંગાઈ કોષ હોતા નથી?
દા.ત.: એંગિયોસ્પર્મ ફ્લોએમ → સુહાણ કોષ + સંગાઈ કોષ બંને. ગાઈમનોસ્પર્મ ફ્લોએમ → સુહાણ કોષ + એલ્બ્યુમિનસ કોષ (સંગાઈ કોષ ગેરહાજર).
એન્ડોડર્મિસ ઓળખ — 'કેસ્પેરિયન સ્ટ્રિપ': એન્ડોડર્મિસના કોષો પર સબેરિનની કેસ્પેરિયન સ્ટ્રિપ હોય છે (W-shaped/ઊંધા V આકાર). ક્રોસ-સેક્શનમાં આ પટ્ટો જોવા મળે તો એન્ડોડર્મિસ નક્કી. મૂળ અને સ્ટેમ બંનેમાં એન્ડોડર્મિસ હોય છે.
ઇપિડર્મિસ vs એન્ડોડર્મિસ વચ્ચે ભેદ કરવાનો પ્રશ્ન આવે તો.
દા.ત.: જૂજન (Endodermis) → કેસ્પેરિયન સ્ટ્રિપ + સબેરિનનો જમાવ. અન્ય વિકલ્પો: ઇપિડર્મિસ = બાહ્ય આવરણ, ટ્રાયકોમ્સ = વાળ, પેરિસાયકલ = સ્લેન્ડર પેરેન્કાઇમા.
એકદળીય vs દ્વિદળીય સ્ટેમ — 'સેન્ડવિચ': દ્વિદળીય સ્ટેમમાં વેસ્ટિક્યુલર બંડલની યોજના = પ્રોટોક્સિલમ અંદર, પ્રોટોફ્લોએમ બહાર (એન્ડાર્ક). એકદળીય સ્ટેમમાં પણ એન્ડાર્ક; પણ એકદળીયમાં બંડલ સંખ્યા ઘણાં + મજ્જા મોટી. બંડલ સંખ્યા ઓછી (5-8) + મજ્જા નાની = દ્વિદળીય.
બંને ટાઈપના સ્ટેમમાંથી પ્રકાર ઓળખવાનો પ્રશ્ન.
દા.ત.: એકદળીય સ્ટેમ → 18-30+ બંડલ, મજ્જા મોટી, કેમ્બિયમ ગેરહાજર. દ્વિદળીય સ્ટેમ → 5-8 બંડલ, મજ્જા નાની, કેમ્બિયમ હાજર (ઓપન બંડલ).
ટ્રાયકોમ્સ vs લેટિસિફર — 'એક vs બહુ': ટ્રાયકોમ્સ એકકોષીય અથવા બહુકોષીય હોય, પડદાકાર/વાળ જેવા; લેટિસિફર = બહુકોષીય, જીવંત, રસધાર ધરાવતા (દૂધીય રસ). જવાબમાં 'જીવંત' + 'લેટિસિફર' = લેટિસિફર; 'મૃત' + 'પ્રોટોક્ટિન' = ટ્રાયકોમ્સમાંથી કોઈ એક પ્રકાર.
ઇપિડર્મિસ પરના આવરી કોષો વિશે પ્રશ્ન.
દા.ત.: મલ્ટિસેલ્યુલર ટ્રાયકોમ્સ = મૃત, પ્રોટોક્ટિન ધરાવતા. સિમ્પલ ટ્રાયકોમ્સ = એકકોષીય, રોમ જેવા. લેટિસિફર = બહુકોષીય, જીવંત, દૂધીય રસ ધરાવતું (Opium poppy).
દ્વિદળીય મૂળ — 'પેરિસાયકલ': પેરિસાયકલ એન્ડોડર્મિસની અંદર + વેસ્ટિક્યુલર બંડલની બહાર = સ્ક્લેરેન્કાઇમાનું ઝાકડું (કેપ). જવાબમાં 'મેસેન્ડર્મિક સ્ક્લેરેન્કાઇમા' = પેરિસાયકલ. ફ્લોએમમાં પીથર્સ્ટેલ = નાનું, એક હોઠું.
મૂળના ક્રોસ-સેક્શનમાં પેરિસાયકલની ઓળખ અને વિસ્તાર વિશે પ્રશ્ન.
દા.ત.: પેરિસાયકલ = સ્ક્લેરેન્કાઇમાનું ઝાકડું, એન્ડોડર્મિસ અને બંડલ વચ્ચે. યોજના: એન્ડોડર્મિસ → પેરિસાયકલ (સ્ક્લેરેન્કાઇમા) → વેસ્ટિક્યુલર બંડલ.
પાંચ-બદલવાળો નિયમ — દ્વિદળીય સ્ટેમનું C.S.: (1) ઇપિડર્મિસ, (2) હાઈપોડર્મિસ (કોલેન્કાઇમા), (3) મેસોફિલ/સ્ટોન કોષ, (4) બંડલ રિંગ + કેમ્બિયમ, (5) મધ્યમાં મજ્જા. જો કોઈ પણ વિકલ્પ આ ક્રમથી હટકો હોય તો ખોટો. એકદળીયમાં બદલો: (4) છીટકાણી બંડલ, કેમ્બિયમ ગેરહાજર.
બંધાણનો ક્રમ પૂછતા પ્રશ્નમાં ઝડપથી જવાબ કાઢવો.
દા.ત.: દ્વિદળીય સ્ટેમ C.S. → ઇપિડર્મિસ → હાઈપોડર્મિસ (કોલેન્કાઇમા) → મેસોફિલ → વેસ્ટિક્યુલર બંડલ રિંગ → મજ્જા (મેડ્યુલર). ખોટો વિકલ્પ: જો હાઈપોડર્મિસ પેરેન્કાઇમા કહેવાયેલું હોય → ખોટું.
