વિન્યાસ (Analogy) — ઝડપી પુનરાવર્તન

Gujarat Police ConstableGujaratiQuick Revision

Definitions

  • વિન્યાસ (Analogy) એ બે શબ્દો/અંકો/યુગ્મો વચ્ચેના સંબંધને ઓળખીને તે જ પ્રકારનો સંબંધ રાખતા તૃતીય શબ્દ/અંક શોધવાની ક્ષમતા માપતો તર્કશાસ્ત્રનો ભાગ છે.
  • આ પ્રશ્નોમાં સામાન્ય રીતે 'A : B :: C : ?' અથવા 'A B એ C D ને સમાન છે' જેવી રચના આપવામાં આવે છે, જ્યાં ? એવા શબ્દ/અંક પસંદ કરવો હોય છે કે જે C અને ? વચ્ચેનો સંબંધ A:B જેવો જ હોય.
  • ગુજરાત પોલીસ કોન્સ્ટેબલ પરીક્ષામાં વિન્યાસ પ્રશ્નો મુખ્યત્વે સીધા, રૂઢિગત અને તકનીકી જ્ઞાન પર આધારિત હોય છે — અત્યંત જટિલ તર્ક નહીં.

Important facts

  • વિન્યાસમાં 'A : B :: C : D' માં A:B અને C:D વચ્ચેનો સંબંધ સમાન હોવો જોઈએ.
  • ગુજરાત પોલીસ કોન્સ્ટેબલ પરીક્ષામાં વિન્યાસના 3-5 પ્રશ્ન આવે છે, મુખ્યત્વે સરળ-મધ્યમ સ્તરના.
  • સંબંધ પસંદ કરતી વખતે 'સૌથી સીધો' (direct) સંબંધ પસંદ કરવો, જટિલ અર્થપૂર્વકનો નહીં.
  • વિકલ્પોમાંથી એક ખોટો વિકલ્પ સામાન્ય રીતે સંબંધની દિશા બદલે છે (જમણું/ડાબું).
  • અંકોના વિન્યાસમાં સૌથી પ્રચલિત સંબંધો: વર્ગ, અવયવ, બમણો, ત્રિગણો, યોગ, અંતર.

Memory aids

  • સંબંધ યાદ રાખવા માટે: 'સંબંધની નોકરી' — દરેક જોડકાં માટે એક વાક્ય બનાવો: 'A એ B નો ___ છે.'
  • અંકોના સંબંધ: સંખ્યાના યોગ, વજન, અંતર, વર્ગ — આ ચારેય ચેક કરો (સૌથી સામાન્ય સંબંધો છે).
  • સંકેત: 'વિન્યાસ = સમાનતાનો આધાર' — જે સમાન સંબંધ, તે જ જવાબ.

Exam tips

  • પ્રશ્નનો ઉદ્દેશ્ય સમજો: 'શું સંબંધ સમાન છે?' — વિકલ્પોમાં સૌથી સીધો જવાબ પસંદ કરો.
  • પ્રથમ તપાસો: A : B નો સંબંધ સમજો, ત્યારબાદ C સાથે જોડો.
  • અંકોના પ્રશ્ન: બધા જોડકાં એક સમાન સંખ્યાત્મક સંબંધ દર્શાવે છે — ગુણોત્તર, વર્ગ, અવયવ તપાસો.
  • સમય વ્યવસ્થાપન: વિન્યાસ પ્રશ્નો 30-45 સેકન્ડમાં ઉકેલો; વધુ સમય લઈએ તો બીજા પ્રશ્ન પર જઓ.
  • પુનરાવર્તન: રોજ 15-20 વિન્યાસ પ્રશ્નો હલ કરો — સ્પષ્ટ સંબંધો યાદ રહેશે.

Common traps

  • સંબંધની દિશા ભૂલ: A:B નો સંબંધ જમણી-ડાબી દિશામાં છે પણ C:D માં વ્યસ્ત દિશામાં લેવાય છે.
  • અત્યંત સૂક્ષ્મ સંબંધ પસંદ કરવો: વિકલ્પોમાં કોઈ એવો પણ હોઈ શકે છે જે 'વધુ અર્થપૂર્ણ' લાગે, પણ મૂળ સંબંધ જેવો ન હોય.
  • અંકગણિતમાં ભૂલ: 2 : 6 :: 3 : 9 (ગુણાકાર +1)ને 2:6::3:9 (અવયવ) વાળી ગણી દેવા.
  • એકથી વધુ વિકલ્પો સ્વીકારવા: જો બે વિકલ્પો સમાન સંબંધ દેખાડે તો મૂળ સંબંધને સૌથી વધુ નજીકનો પસંદ કરો.
  • ભારતીય સંસ્કૃતિ/સાહિત્ય આધારિત પ્રશ્નોમાં સામાન્ય ભ્રમણા: ઉદા., 'કાગડો : કકૂડ' અને 'ચમગીદર : યુવાન' જેવા વિરોધી સંબંધો.
