સીધી રેખા

📖 સીધી રેખા (Straight Line)

સીધી રેખાની મૂળભૂત સમજ

સીધી રેખા એ બે બિંદુઓ વચ્ચેનો સૌથી ટૂંકો માર્ગ છે. તેને એક-પરિમાણી (1D) ભૌમિતિક આકૃતિ ગણવામાં આવે છે. જ્યારે બે બિંદુઓની સ્થિતિ સમાન હોય ત્યારે રેખા એક બિંદુમાં સંકોચાય છે.

  • સીધી રેખા એ બે બિંદુઓ વચ્ચેનો ટૂંકો માર્ગ છે.
  • તેને એક-પરિમાણી (1D) ગણવામાં આવે છે.
  • રેખા અસીમ લંબાઈ ધરાવે છે.
  • રેખા ના કોઈ પહોળાઈ અથવા જાડાઈ હોતી નથી.

સીધી રેખાના પ્રકાર

સીધી રેખાઓને તેમની સ્થિતિ અને દિશા અનુસાર વર્ગીકૃત કરવામાં આવે છે. મુખ્યત્વે ત્રણ પ્રકાર છે: ક્ષિતિજ (Horizontal), ઉદગ્ર (Vertical) અને તિરછી (Oblique).

  • ક્ષિતિજ રેખા: X-અક્ષની સમાનાંતર ચાલે છે.
  • ઉદગ્ર રેખા: Y-અક્ષની સમાનાંતર ચાલે છે.
  • તિરછી રેખા: X અને Y અક્ષ સાથે કોણ બનાવે છે.
  • અવકાશમાં રેખા ત્રિપરિમાણી (3D) પણ હોઈ શકે છે.
🧠 Trick: ક્ષિ-ઉ-તિર (ક્ષિતિજ, ઉદગ્ર, તિરછી)

સીધી રેખાનું સમીકરણ

સીધી રેખાનું સમીકરણ y = mx + c સ્વરૂપે લખી શકાય છે, જ્યાં m એ ઢાળ (slope) અને c એ Y-અંતઃખંડ (Y-intercept) છે. આ સમીકરણ રેખાની દિશા અને સ્થિતિ નક્કી કરે છે.

  • y = mx + c એ રેખાનું સ્થાનિક સમીકરણ છે.
  • m = Δy/Δx (ઢાળ એ Yમાં ફેરફાર અને Xમાં ફેરફારનો ગુણોત્તર છે).
  • c એ Y-અંતઃખંડ છે, જ્યાં રેખા Y-અક્ષને છેદે છે.
  • જો m = 0 હોય તો રેખા ક્ષિતિજ હોય છે.
🧠 Trick: y = મિત્ર c (m = ઢાળ, c = અંતઃખંડ)

રેખાનો ઢાળ (Slope)

રેખાનો ઢાળ એ તેની તિરછાઈ નક્કી કરે છે. ઢાળનો ગુણધર્મ રેખાની દિશા અને પ્રવેગને દર્શાવે છે. જો ઢાળ ધન હોય તો રેખા ઉપર તરફ જતી હોય છે, જ્યારે ઋણ ઢાળ ધરાવતી રેખા નીચે તરફ જતી હોય છે.

  • ઢાળ (m) = tanθ, જ્યાં θ એ X-અક્ષ સાથે બનતો કોણ છે.
  • ધન ઢાળ: રેખા ઉપર તરફ જતી હોય છે.
  • ઋણ ઢાળ: રેખા નીચે તરફ જતી હોય છે.
  • શૂન્ય ઢાળ: રેખા ક્ષિતિજ હોય છે.
  • અનંત ઢાળ: રેખા ઉદગ્ર હોય છે.
🧠 Trick: ધન-ઉપર, ઋણ-નીચે (ધન ઢાળ ઉપર, ઋણ ઢાળ નીચે)

બે રેખાઓ વચ્ચેનો કોણ

બે રેખાઓ વચ્ચેનો કોણ તેમના ઢાળના ગુણધર્મ પર આધારિત હોય છે. જો બે રેખાઓના ઢાળ અનુક્રમે m1 અને m2 હોય, તો વચ્ચેનો કોણ θ = |(m2 - m1)/(1 + m1*m2)| દ્વારા મેળવી શકાય છે.

  • θ = |(m2 - m1)/(1 + m1*m2)|
  • જો m1*m2 = -1 હોય તો રેખાઓ લંબ હોય છે.
  • જો m1 = m2 હોય તો રેખાઓ સમાનાંતર હોય છે.
  • જો m1*m2 = 1 હોય તો રેખાઓ 45° કોણે છેદે છે.

રેખાનું વેક્ટર સમીકરણ

રેખાનું વેક્ટર સમીકરણ r = a + λb સ્વરૂપે લખી શકાય છે, જ્યાં a એ રેખા પરનો એક બિંદુ, b એ રેખાની દિશા વેક્ટર અને λ એ પરિમાણ છે. આ સમીકરણ 3D અવકાશમાં રેખાની સ્થિતિ વર્ણવે છે.

  • r = a + λb એ રેખાનું વેક્ટર સમીકરણ છે.
  • a એ રેખા પરનો એક બિંદુ છે.
  • b એ દિશા વેક્ટર છે.
  • λ એ કોઈ પણ વાસ્તવિક સંખ્યા હોઈ શકે છે.

રેખા અને બિંદુ વચ્ચેનો અંતર

બિંદુ (x0, y0) અને રેખા Ax + By + C = 0 વચ્ચેનો અંતર d = |Ax0 + By0 + C| / √(A² + B²) દ્વારા મેળવી શકાય છે. આ સૂત્ર JEEમાં ખૂબ ઉપયોગી છે.

  • d = |Ax0 + By0 + C| / √(A² + B²)
  • અંતર હંમેશા ધન હોય છે.
  • જો બિંદુ રેખા પર હોય તો d = 0.
  • સૂત્રને યાદ રાખવા માટે 'AB-C' ટ્રિક વાપરો.
🧠 Trick: AB-C (A x0 + B y0 + C)

⚡ Quick Revision

  • સીધી રેખા એ બે બિંદુઓ વચ્ચેનો ટૂંકો માર્ગ છે.
  • રેખાનું સમીકરણ y = mx + c છે, જ્યાં m એ ઢાળ અને c એ Y-અંતઃખંડ છે.
  • ઢાળ (m) = Δy/Δx = tanθ.
  • ધન ઢાળ વાળી રેખા ઉપર તરફ જતી હોય છે.
  • ઋણ ઢાળ વાળી રેખા નીચે તરફ જતી હોય છે.
  • બે રેખાઓ લંબ હોય ત્યારે m1*m2 = -1.
  • બે રેખાઓ સમાનાંતર હોય ત્યારે m1 = m2.
  • રેખા અને બિંદુ વચ્ચેનો અંતર d = |Ax0 + By0 + C| / √(A² + B²).
  • રેખાનું વેક્ટર સમીકરણ r = a + λb છે.
  • 3Dમાં રેખાનું સમીકરણ (x-x1)/a = (y-y1)/b = (z-z1)/c છે.
🎯 Exam Tip: JEE Mainમાં સીધી રેખાના પ્રશ્નો મોટાભાગે ઢાળ, અંતર અને કોણ પર આધારિત હોય છે. સમીકરણ અને સૂત્રોને યાદ રાખવા માટે નિયમિતપણે પ્રેક્ટિસ કરો.
