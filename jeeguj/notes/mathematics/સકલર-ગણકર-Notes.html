સ્કેલર ગુણાકાર

📖 સ્કેલર ગુણાકાર (Dot Product)

પરિચય અને વ્યાખ્યા

સ્કેલર ગુણાકાર (Dot Product) બે સદિશો વચ્ચેનો ગુણાકાર છે જે પરિણામે એક સ્કેલર મૂલ્ય આપે છે. તેને 'a · b' વડે દર્શાવાય છે. ગણિતમાં તેનો ઉપયોગ બે સદિશો વચ્ચેનો ખૂણો શોધવા, કાર્યની ગણતરી (Physics) અને પ્રક્ષેપણ (Projection) માટે થાય છે.

  • સ્કેલર ગુણાકાર = |a||b|cosθ (θ = બે સદિશો વચ્ચેનો ખૂણો)
  • જો θ = 90° → a · b = 0 (લંબ સદિશો)
  • જો θ = 0° → a · b = |a||b| (સમાંતર સદિશો)
  • કમ્યુટેટિવ ગુણધર્મ: a · b = b · a
🧠 Trick: ડોટ પ્રોડક્ટ = ડીરેક્શનનો કોસાઈન (cosθ) × મેગ્નિટ્યુડ બંનેનો

આલ્જેબ્રિક સૂત્ર (કાર્ટેશિયન સ્વરૂપ)

જો સદિશો a = (a₁, a₂, a₃) અને b = (b₁, b₂, b₃) હોય, તો સ્કેલર ગુણાકાર a · b = a₁b₁ + a₂b₂ + a₃b₃ થાય. આ સૂત્ર 2D અને 3D બંને સદિશો માટે લાગુ પડે છે.

  • 2D: a · b = a₁b₁ + a₂b₂
  • 3D: a · b = a₁b₁ + a₂b₂ + a₃b₃
  • ઋણ મૂલ્ય = ખૂણો > 90° (અથવા વિરુદ્ધ દિશા)
  • ધન મૂલ્ય = ખૂણો < 90° (સમાન દિશા)
🧠 Trick: સરવાળો કરો: પહેલા × પહેલા + બીજા × બીજા + ત્રીજા × ત્રીજા

ભૌતિકશાસ્ત્રમાં ઉપયોગ

કાર્ય (Work) ની ગણતરી માટે સ્કેલર ગુણાકારનો ઉપયોગ થાય છે: W = F · d = |F||d|cosθ. અહીં F બળ સદિશ અને d સ્થાનાંતર સદિશ છે. θ બળ અને સ્થાનાંતર વચ્ચેનો ખૂણો છે.

  • કાર્ય = બળ · સ્થાનાંતર (F · d)
  • જો F અને d લંબ → W = 0 (કાર્ય શૂન્ય)
  • જો F અને d સમાંતર → W = |F||d| (મહત્તમ કાર્ય)
  • એકમ: જૂલ (J) = ન્યૂટન-મીટર (N·m)
🧠 Trick: કાર્ય = ફોર્સ ડોટ ડિસ્પ્લેસમેન્ટ (W = F · d)

પ્રક્ષેપણ (Projection) માટે ઉપયોગ

સદિશ a નો સદિશ b પરનો પ્રક્ષેપણ (Projection) શોધવા સ્કેલર ગુણાકાર વપરાય છે. પ્રક્ષેપણનું મૂલ્ય = (a · b)/|b| અને દિશા b ની દિશામાં હોય છે. આનો ઉપયોગ ભૌતિકશાસ્ત્ર અને એન્જિનિયરિંગમાં થાય છે.

  • પ્રક્ષેપણ = (a · b)/|b| (સ્કેલર મૂલ્ય)
  • સદિશ પ્રક્ષેપણ = [(a · b)/|b|²] × b
  • જો θ = 0° → પ્રક્ષેપણ = |a| (સંપૂર્ણ પ્રક્ષેપણ)
  • જો θ = 90° → પ્રક્ષેપણ = 0 (કોઈ પ્રક્ષેપણ નહીં)
🧠 Trick: પ્રોજેક્શન = ડોટ પ્રોડક્ટ ÷ બીજા સદિશનો મેગ્નિટ્યુડ

ગુણધર્મો અને નિયમો

સ્કેલર ગુણાકારના મુખ્ય ગુણધર્મો: કમ્યુટેટિવ (a · b = b · a), ડિસ્ટ્રિબ્યુટિવ (a · (b + c) = a · b + a · c), અને સ્કેલર ગુણાકાર સાથે સુસંગત (k(a · b) = (ka) · b = a · (kb)). આ ગુણધર્મો વેક્ટર બીજગણિતમાં મહત્વપૂર્ણ છે.

  • કમ્યુટેટિવ: a · b = b · a
  • ડિસ્ટ્રિબ્યુટિવ: a · (b + c) = a · b + a · c
  • સ્કેલર ગુણાકાર: k(a · b) = (ka) · b = a · (kb)
  • a · a = |a|² (સ્વયં સાથેનો ગુણાકાર = મેગ્નિટ્યુડનો વર્ગ)
🧠 Trick: ડોટ પ્રોડક્ટના નિયમો: કમ્યુટ, ડિસ્ટ્રિબ્યુટ, સ્કેલર સાથે ફ્રેન્ડલી

JEE Main માં પ્રશ્નોના પ્રકાર

JEE Main માં સ્કેલર ગુણાકાર પર આધારિત પ્રશ્નોમાં સામાન્ય રીતે બે સદિશો વચ્ચેનો ખૂણો શોધવો, કાર્યની ગણતરી, પ્રક્ષેપણ શોધવું, અથવા ગુણધર્મોનો ઉપયોગ કરી સમીકરણ ઉકેલવું સામેલ હોય છે. ઘણીવાર આ પ્રશ્નો ભૌતિકશાસ્ત્રના સંદર્ભમાં પૂછવામાં આવે છે.

  • ખૂણો શોધો: θ = cos⁻¹[(a · b)/(|a||b|)]
  • કાર્યના પ્રશ્નો: W = F · d
  • પ્રક્ષેપણના પ્રશ્નો: (a · b)/|b|
  • ગુણધર્મોનો ઉપયોગ કરી સમીકરણ ઉકેલો
🧠 Trick: JEE માં ડોટ પ્રોડક્ટ = ખૂણો + કાર્ય + પ્રોજેક્શન

⚡ Quick Revision

  • સ્કેલર ગુણાકાર = |a||b|cosθ (સ્કેલર પરિણામ)
  • a · b = a₁b₁ + a₂b₂ + a₃b₃ (કાર્ટેશિયન સ્વરૂપ)
  • કાર્ય W = F · d (ભૌતિકશાસ્ત્રમાં ઉપયોગ)
  • પ્રક્ષેપણ = (a · b)/|b| (સદિશ b પર a નું પ્રક્ષેપણ)
  • કમ્યુટેટિવ: a · b = b · a
  • ડિસ્ટ્રિબ્યુટિવ: a · (b + c) = a · b + a · c
  • a · a = |a|² (સ્વયં સાથેનો ગુણાકાર)
  • θ = 90° → a · b = 0 (લંબ સદિશો)
  • JEE માં ખૂણો, કાર્ય, પ્રક્ષેપણ પર પ્રશ્નો આવે
  • સ્કેલર ગુણાકાર સદિશોની દિશા પર આધારિત
🎯 Exam Tip: JEE Main માં સ્કેલર ગુણાકારના પ્રશ્નોમાં પહેલા સદિશોને કાર્ટેશિયન સ્વરૂપમાં લખો, પછી a · b = a₁b₁ + a₂b₂ + a₃b₃ સૂત્ર લાગુ કરો. ભૌતિકશાસ્ત્રના પ્રશ્નોમાં θ ની કિંમત પર ધ્યાન આપો — જો θ આપેલ ન હોય, તો તેને cos⁻¹[(a · b)/(|a||b|)] વડે શોધો.
