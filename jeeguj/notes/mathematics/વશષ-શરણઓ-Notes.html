વિશેષ શ્રેણીઓ

📖 વિશેષ શ્રેણીઓ

અંકગણિતીય શ્રેણી (AP)

અંકગણિતીય શ્રેણીમાં દરેક પદ પહેલાના પદમાં અચળ તફાવત (સામાન્ય તફાવત - d) ઉમેરીને મળે છે. પ્રથમ પદ a₁ હોય તો nમું પદ aₙ = a₁ + (n-1)d થાય. પ્રથમ n પદોનો સરવાળો Sₙ = n/2 [2a₁ + (n-1)d] અથવા Sₙ = n/2 (a₁ + aₙ) થી મળે છે.

  • aₙ = a₁ + (n-1)d
  • Sₙ = n/2 [2a₁ + (n-1)d]
  • સરવાળો શોધવા માટે પદોની સંખ્યા (n) અને પ્રથમ/છેલ્લું પદ જરૂરી
  • APમાં ત્રણ ક્રમિક પદોનો સરવાળો મધ્યમ પદના ત્રણ ગણા જેટલો હોય છે
🧠 Trick: AP નો સરવાળો = પદોની સંખ્યા × સરેરાશ (પ્રથમ + છેલ્લું પદ)

ગુણોત્તર શ્રેણી (GP)

ગુણોત્તર શ્રેણીમાં દરેક પદ પહેલાના પદને અચળ ગુણોત્તર (r) વડે ગુણવાથી મળે છે. પ્રથમ પદ a હોય તો nમું પદ aₙ = a·rⁿ⁻¹ થાય. અનંત GPનો સરવાળો (|r|<1 માટે) S∞ = a/(1-r) થાય.

  • aₙ = a·rⁿ⁻¹
  • Sₙ = a(rⁿ-1)/(r-1) (r≠1)
  • ત્રણ ક્રમિક પદોનો ગુણાકાર મધ્યમ પદના ઘન જેટલો
  • અનંત GPનો સરવાળો માત્ર |r|<1 માટે શક્ય
🧠 Trick: GP નું પદ = પ્રથમ પદ × ગુણોત્તર^(પદનો ક્રમ - 1)

હરાત્મક શ્રેણી (HP)

હરાત્મક શ્રેણી એ એવી શ્રેણી છે જેના પદોના વ્યસ્ત AP બનાવે. જો a, b, c HPમાં હોય તો 2/b = 1/a + 1/c થાય. HPનો સરવાળો સીધો સૂત્ર નથી, પણ તેના વ્યસ્ત APનો સરવાળો કરી વ્યસ્ત લેવાથી મળે.

  • HPના પદોના વ્યસ્ત AP બનાવે
  • a, b, c HPમાં ⇒ 2/b = 1/a + 1/c
  • સરવાળો શોધવા માટે વ્યસ્ત APનો ઉપયોગ કરવો
  • HPમાં કોઈ પદ શૂન્ય ન હોઈ શકે
🧠 Trick: HP = AP ના વ્યસ્ત

વિશિષ્ટ શ્રેણીઓના સરવાળા

1² + 2² + ... + n² = n(n+1)(2n+1)/6, 1³ + 2³ + ... + n³ = [n(n+1)/2]². આ સૂત્રો ગાણિતિક અનુમાન દ્વારા સાબિત થાય છે. JEEમાં આ સૂત્રોનો ઉપયોગ કરીને જટિલ શ્રેણીઓના સરવાળા શોધવામાં આવે છે.

  • Σk² = n(n+1)(2n+1)/6
  • Σk³ = [n(n+1)/2]²
  • આ સૂત્રો ગાણિતિક અનુમાનથી સાબિત કરવા
  • શ્રેણીને ભાગોમાં વિભાજીત કરી સરવાળો શોધવો
🧠 Trick: વર્ગોનો સરવાળો = n(n+1)(2n+1)/6, ઘનનો સરવાળો = [n(n+1)/2]²

શ્રેણીઓનું અભિસરણ અને અપસરણ

GPમાં |r|<1 હોય તો શ્રેણી અભિસરણ કરે છે અને અનંત સરવાળો અસ્તિત્વ ધરાવે છે. |r|≥1 હોય તો અપસરણ થાય છે. અભિસરણ શ્રેણીઓના ગુણધર્મો JEEમાં મર્યાદા અને અનંત શ્રેણીઓના પ્રશ્નોમાં ઉપયોગી છે.

  • |r|<1 ⇒ GP અભિસરણ કરે
  • |r|≥1 ⇒ GP અપસરણ કરે
  • અભિસરણ શ્રેણીનો અનંત સરવાળો અસ્તિત્વ ધરાવે
  • અપસરણ શ્રેણીનો અનંત સરવાળો અનંત અથવા અવ્યાખ્યાયિત
🧠 Trick: ગુણોત્તર નાનો (|r|<1) ⇒ શ્રેણી અભિસરણ કરે

શ્રેણીઓના પ્રશ્નો ઉકેલવાની રીત

શ્રેણીના પ્રશ્નોમાં પહેલા શ્રેણીનો પ્રકાર ઓળખવો (AP/GP/HP). પછી યોગ્ય સૂત્ર લાગુ કરવું. જો શ્રેણી મિશ્ર હોય તો તેને ભાગોમાં વિભાજીત કરવી. JEEમાં ઘણીવાર શ્રેણીના પદોને બે ભાગમાં તોડીને સરવાળો શોધવામાં આવે છે.

  • શ્રેણીનો પ્રકાર ઓળખો (AP/GP/HP)
  • યોગ્ય સૂત્ર લાગુ કરો
  • મિશ્ર શ્રેણીને ભાગોમાં વિભાજીત કરો
  • પદોને બે ભાગમાં તોડીને સરવાળો શોધો
🧠 Trick: પ્રકાર ઓળખો → સૂત્ર લાગુ કરો → ભાગોમાં વિભાજીત કરો

⚡ Quick Revision

  • AP: aₙ = a₁ + (n-1)d, Sₙ = n/2 [2a₁ + (n-1)d]
  • GP: aₙ = a·rⁿ⁻¹, Sₙ = a(rⁿ-1)/(r-1), S∞ = a/(1-r) (|r|<1)
  • HP: પદોના વ્યસ્ત AP બનાવે, 2/b = 1/a + 1/c
  • Σk² = n(n+1)(2n+1)/6, Σk³ = [n(n+1)/2]²
  • |r|<1 ⇒ GP અભિસરણ કરે, અનંત સરવાળો અસ્તિત્વ ધરાવે
  • શ્રેણીનો પ્રકાર ઓળખી યોગ્ય સૂત્ર લાગુ કરવું
  • મિશ્ર શ્રેણીને ભાગોમાં વિભાજીત કરી સરવાળો શોધવો
  • APમાં ત્રણ ક્રમિક પદોનો સરવાળો = 3 × મધ્યમ પદ
  • GPમાં ત્રણ ક્રમિક પદોનો ગુણાકાર = મધ્યમ પદ³
  • HPમાં કોઈ પદ શૂન્ય ન હોઈ શકે
🎯 Exam Tip: JEEમાં શ્રેણીના પ્રશ્નોમાં પહેલા શ્રેણીનો પ્રકાર ઓળખો અને પછી યોગ્ય સૂત્ર લાગુ કરો. જો શ્રેણી મિશ્ર હોય તો તેને ભાગોમાં વિભાજીત કરી દરેક ભાગનો સરવાળો અલગથી શોધો. સમય બચાવવા માટે મૂળભૂત સૂત્રો (AP, GP, Σk², Σk³) યાદ રાખો અને ઝડપથી લાગુ કરો.
