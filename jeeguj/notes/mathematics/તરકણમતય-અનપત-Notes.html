ત્રિકોણમિતીય અનુપાત

📖 ત્રિકોણમિતીય અનુપાત

પરિચય અને વ્યાખ્યાઓ

ત્રિકોણમિતીય અનુપાત એ કાટકોણ ત્રિકોણના ખૂણાઓ અને તેની બાજુઓના ગુણોત્તર છે. sinθ, cosθ, tanθ, cosecθ, secθ અને cotθ એ મુખ્ય ત્રિકોણમિતીય અનુપાત છે. આ અનુપાતો ફક્ત કાટકોણ ત્રિકોણ માટે જ વ્યાખ્યાયિત છે, જ્યાં θ એ તીક્ષ્ણકોણ (0° < θ < 90°) છે.

  • sinθ = લંબ/કર્ણ (opposite/hypotenuse)
  • cosθ = પાયો/કર્ણ (adjacent/hypotenuse)
  • tanθ = લંબ/પાયો (opposite/adjacent)
  • cosecθ = 1/sinθ, secθ = 1/cosθ, cotθ = 1/tanθ
  • θ = 0° અને 90° માટે અનુપાતો યાદ રાખો (sin0°=0, cos0°=1, tan0°=0)
🧠 Trick: પંડિત બદ્રી પ્રસાદ હર હર બોલે (Pandit Badri Prasad Har Har Bole) → sinθ, cosθ, tanθ માટે લંબ, પાયો, કર્ણનો ક્રમ

ત્રિકોણમિતીય અનુપાતો વચ્ચેના સંબંધો

ત્રિકોણમિતીય અનુપાતો એકબીજા સાથે ગાણિતિક સંબંધ ધરાવે છે. પાયથાગોરસના નિયમ પરથી sin²θ + cos²θ = 1 મળે છે. આ સૂત્રમાંથી અન્ય ઓળખો જેમ કે 1 + tan²θ = sec²θ અને 1 + cot²θ = cosec²θ મેળવી શકાય છે.

  • sin²θ + cos²θ = 1 (મૂળભૂત ઓળખ)
  • 1 + tan²θ = sec²θ (tan અને sec વચ્ચેનો સંબંધ)
  • 1 + cot²θ = cosec²θ (cot અને cosec વચ્ચેનો સંબંધ)
  • tanθ = sinθ/cosθ, cotθ = cosθ/sinθ
  • ઓળખો યાદ રાખો: sin(90°-θ) = cosθ, cos(90°-θ) = sinθ
🧠 Trick: સાઈન-કોસાઈનનો વર્ગ ઉમેરો એક (sin²θ + cos²θ = 1)

ત્રિકોણમિતીય કોષ્ટક (0° થી 90°)

JEE માટે 0°, 30°, 45°, 60° અને 90° ના ત્રિકોણમિતીય અનુપાતો યાદ રાખવા જરૂરી છે. આ કોણો માટે sin, cos અને tan ના મૂલ્યો કંઠસ્થ હોવા જોઈએ. દા.ત., sin30° = 1/2, cos30° = √3/2, tan30° = 1/√3.

  • 0°: sin=0, cos=1, tan=0
  • 30°: sin=1/2, cos=√3/2, tan=1/√3
  • 45°: sin=1/√2, cos=1/√2, tan=1
  • 60°: sin=√3/2, cos=1/2, tan=√3
  • 90°: sin=1, cos=0, tan=∞ (અવ્યાખ્યાયિત)
🧠 Trick: 1, 2, 3 ના વર્ગમૂળના ક્રમમાં sin માટે (√1/2, √2/2, √3/2)

ત્રિકોણમિતીય અનુપાતોના ચિહ્નો (ચરણો)

ચાર ચરણોમાં ત્રિકોણમિતીય અનુપાતોના ચિહ્નો અલગ-અલગ હોય છે. પ્રથમ ચરણ (0°-90°)માં બધા અનુપાતો ધન, બીજા ચરણ (90°-180°)માં sin અને cosec ધન, ત્રીજા ચરણ (180°-270°)માં tan અને cot ધન, અને ચોથા ચરણ (270°-360°)માં cos અને sec ધન હોય છે.

  • પ્રથમ ચરણ: બધા ધન (+)
  • બીજું ચરણ: sin, cosec ધન (+)
  • ત્રીજું ચરણ: tan, cot ધન (+)
  • ચોથું ચરણ: cos, sec ધન (+)
  • ASTC નિયમ: All Students Take Calculus (પ્રથમથી ચોથા ચરણ માટે)
🧠 Trick: અસ્તક (ASTC) → All Sin Tan Cos (ચરણ પ્રમાણે ચિહ્નો)

ત્રિકોણમિતીય અનુપાતોના ગુણધર્મો

ત્રિકોણમિતીય અનુપાતોના મહત્વપૂર્ણ ગુણધર્મો જેમ કે પૂરક કોણો (complementary angles) અને પરિપૂરક કોણો (supplementary angles) માટેના સંબંધો યાદ રાખવા જરૂરી છે. દા.ત., sin(90°-θ) = cosθ, cos(180°-θ) = -cosθ, tan(180°+θ) = tanθ.

  • sin(90°-θ) = cosθ, cos(90°-θ) = sinθ
  • sin(180°-θ) = sinθ, cos(180°-θ) = -cosθ
  • tan(180°+θ) = tanθ, cot(180°+θ) = cotθ
  • sin(-θ) = -sinθ, cos(-θ) = cosθ (sin વિષમ, cos સમ)
  • સમકોણ અને વિષમકોણ ગુણધર્મો યાદ રાખો
🧠 Trick: 90° માઈનસ θ → sin-cos બદલાય (sin(90°-θ) = cosθ)

ત્રિકોણમિતીય સમીકરણો અને અસમતાઓ

ત્રિકોણમિતીય સમીકરણો ઉકેલવા માટે મુખ્ય મૂલ્યો (principal values) અને સામાન્ય ઉકેલો (general solutions) યાદ રાખવા જરૂરી છે. દા.ત., sinθ = 1/2 નો સામાન્ય ઉકેલ θ = nπ + (-1)ⁿ π/6 (n ∈ ℤ). અસમતાઓ માટે ચરણોના ચિહ્નો અને ગ્રાફનો ઉપયોગ કરવો.

  • sinθ = 0 → θ = nπ
  • cosθ = 0 → θ = (2n+1)π/2
  • tanθ = 0 → θ = nπ
  • sinθ = 1 → θ = 2nπ + π/2
  • cosθ = 1 → θ = 2nπ
  • સામાન્ય ઉકેલો યાદ રાખો: sinθ = k → θ = nπ + (-1)ⁿ α
🧠 Trick: sinθ = 0 → π ના ગુણાંક (nπ)

⚡ Quick Revision

  • sinθ = લંબ/કર્ણ, cosθ = પાયો/કર્ણ, tanθ = લંબ/પાયો
  • sin²θ + cos²θ = 1 (મૂળભૂત ઓળખ)
  • 0°, 30°, 45°, 60°, 90° ના મૂલ્યો કંઠસ્થ રાખો
  • ASTC નિયમ: ચરણ પ્રમાણે ચિહ્નો યાદ રાખો
  • sin(90°-θ) = cosθ, cos(180°-θ) = -cosθ
  • tanθ = sinθ/cosθ, cotθ = cosθ/sinθ
  • સામાન્ય ઉકેલો: sinθ = k → θ = nπ + (-1)ⁿ α
  • પ્રથમ ચરણમાં બધા અનુપાતો ધન (+)
  • sin અને cos ના મહત્તમ મૂલ્યો 1 અને લઘુત્તમ -1
  • tanθ = ∞ જ્યારે θ = 90° અથવા 270°
🎯 Exam Tip: JEE માં ત્રિકોણમિતીય અનુપાતોના પ્રશ્નોમાં મોટાભાગે 0°, 30°, 45°, 60°, 90° ના મૂલ્યો અથવા ઓળખોનો ઉપયોગ થાય છે. પ્રશ્ન વાંચીને તરત જ યોગ્ય ઓળખ અથવા મૂલ્ય લાગુ કરો. સમય બચાવવા માટે કોષ્ટક અને ઓળખો કંઠસ્થ હોવી જરૂરી છે.
