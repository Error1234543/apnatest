ફંક્શનનું સંયોજન

📖 ફંક્શનનું સંયોજન (Function Composition)

પરિચય અને વ્યાખ્યા

ફંક્શનનું સંયોજન એ બે કે તેથી વધુ ફંક્શનને જોડીને એક નવું ફંક્શન બનાવવાની પ્રક્રિયા છે. જો f: A → B અને g: B → C બે ફંક્શન હોય, તો તેમનું સંયોજન gof: A → C થાય છે, જ્યાં (gof)(x) = g(f(x)). આ પ્રક્રિયા ગણિતમાં ફંક્શનલ વિશ્લેષણ અને અલ્જેબ્રામાં મહત્વપૂર્ણ છે.

  • સંયોજન માટે ડોમેઇન અને કોડોમેઇનનું મેળ ખાવું જરૂરી છે.
  • gof ≠ fog (સંયોજન ક્રમ આધારિત છે).
  • સંયોજન એસોસિયેટિવ છે: (fog)oh = fo(goh).
🧠 Trick: ગોફ (gof) = ગ (g) પછી ફ (f) — પહેલા f પછી g લાગુ કરો.

સંયોજનના નિયમો અને ગુણધર્મો

ફંક્શન સંયોજનના મુખ્ય ગુણધર્મોમાં એસોસિયેટિવિટી, આઇડેન્ટિટી ફંક્શનનું અસ્તિત્વ અને ઇન્વર્સ ફંક્શન સાથેનો સંબંધ સામેલ છે. જો f અને g બંને એક-એક (one-one) હોય, તો gof પણ એક-એક હોય છે. તેવી જ રીતે, જો બંને onto હોય, તો gof પણ onto હોય છે.

  • એસોસિયેટિવિટી: (fog)oh = fo(goh).
  • આઇડેન્ટિટી ફંક્શન: I(x) = x ⇒ foI = If = f.
  • ઇન્વર્સ સંબંધ: (gof)⁻¹ = f⁻¹og⁻¹.
🧠 Trick: ઇન્વર્સનો ક્રમ ઉલટાવો: પહેલા g⁻¹ પછી f⁻¹.

સંયોજનના ડોમેઇન અને રેન્જ

gof નું ડોમેઇન f ના ડોમેઇન જેટલું જ હોય છે, પરંતુ તે x ને સમાવે છે જ્યાં f(x) એ g ના ડોમેઇનમાં હોય. gof ની રેન્જ g ની રેન્જનું સબસેટ હોય છે, જે f ની રેન્જ પર આધારિત છે. ડોમેઇન શોધવા માટે f(x) એ g ના ડોમેઇનમાં હોવું જરૂરી છે.

  • ડોમેઇન(gof) = {x ∈ ડોમેઇન(f) | f(x) ∈ ડોમેઇન(g)}.
  • રેન્જ(gof) ⊆ રેન્જ(g).
  • જો f: R → R અને g: R → R, તો ડોમેઇન(gof) = R.
🧠 Trick: ડોમેઇન માટે: f(x) એ g નો ખોરાક હોવો જોઈએ!

સંયોજનના પ્રકારો અને ઉદાહરણો

સંયોજનના મુખ્ય પ્રકારોમાં રેખીય ફંક્શનનું સંયોજન, બહુપદી ફંક્શનનું સંયોજન અને ત્રિકોણમિતીય ફંક્શનનું સંયોજન સામેલ છે. ઉદાહરણ તરીકે, જો f(x) = 2x + 3 અને g(x) = x², તો (gof)(x) = (2x + 3)² અને (fog)(x) = 2x² + 3.

  • રેખીય સંયોજન: fog(x) = a(bx + c) + d = abx + (ac + d).
  • બહુપદી સંયોજન: ઉચ્ચતમ ઘાતનો સરવાળો થાય છે.
  • ત્રિકોણમિતીય સંયોજન: sin(cos x) ≠ cos(sin x).
🧠 Trick: બહુપદીમાં ઘાતનો સરવાળો: f(x) = x², g(x) = x³ ⇒ fog(x) = x⁶.

સંયોજન અને ઇન્વર્સ ફંક્શન

ફંક્શનનું સંયોજન તેના ઇન્વર્સ સાથે આઇડેન્ટિટી ફંક્શન આપે છે. જો f અને g એકબીજાના ઇન્વર્સ હોય, તો fog = gof = I. ઇન્વર્સ ફંક્શન શોધવા માટે સંયોજનનો ઉપયોગ થાય છે, જેમ કે જો y = f(x), તો x = f⁻¹(y).

  • f⁻¹of = fof⁻¹ = I.
  • જો fog = I, તો g = f⁻¹ અને f = g⁻¹.
  • ઇન્વર્સ ફંક્શન માત્ર એક-એક અને onto ફંક્શન માટે અસ્તિત્વ ધરાવે છે.
🧠 Trick: ઇન્વર્સ = ક્રમ ઉલટાવો અને ફંક્શન ઉલટાવો.

JEE Main માં સંયોજનના પ્રશ્નોના પ્રકાર

JEE Main માં સંયોજન પરના પ્રશ્નોમાં ડોમેઇન/રેન્જ શોધવી, સંયોજનનું મૂલ્યાંકન, ઇન્વર્સ ફંક્શન શોધવું અને સંયોજનના ગુણધર્મોનો ઉપયોગ કરીને સમીકરણ ઉકેલવું સામેલ છે. ઘણીવાર પ્રશ્નોમાં સંયોજનને અન્ય વિષયો જેમ કે ક્રમચય-સંયોજન અથવા લઘુગણક સાથે જોડવામાં આવે છે.

  • સંયોજનનું મૂલ્યાંકન: (gof)(2) = g(f(2)).
  • ડોમેઇન શોધો: f(x) = √x, g(x) = x² ⇒ ડોમેઇન(gof) = [0, ∞).
  • ઇન્વર્સ શોધો: y = f(x) ⇒ x = f⁻¹(y).
🧠 Trick: JEE માં સંયોજન = ડોમેઇન + રેન્જ + ઇન્વર્સ.

🎯 Exam Tip: JEE Main ના પ્રશ્નોમાં સંયોજનનું મૂલ્યાંકન કરતી વખતે પહેલા ડોમેઇન ચકાસો. જો f(x) એ g ના ડોમેઇનની બહાર હોય, તો gof(x) અવ્યાખ્યાયિત છે. આ ભૂલ ટાળવા માટે હંમેશા ડોમેઇનની શરતો લખો.
