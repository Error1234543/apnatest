સમતલ

📖 સમતલ

સમતલની વ્યાખ્યા અને સમીકરણ

સમતલ એ ત્રિપરિમાણીય અવકાશમાં એક દ્વિપરિમાણીય સપાટી છે, જેને ત્રણ બિંદુઓ અથવા એક બિંદુ અને લંબ દિશા વડે વ્યાખ્યાયિત કરી શકાય. સમતલનું સામાન્ય સમીકરણ ax + by + cz + d = 0 છે, જ્યાં (a, b, c) એ સમતલનો લંબ સદિશ છે અને d અચળાંક છે.

  • સમતલનું સામાન્ય સમીકરણ: ax + by + cz + d = 0
  • લંબ સદિશ: n̂ = (a, b, c)
  • ત્રણ બિન-સંરેખ બિંદુઓ વડે સમતલ નક્કી થાય
  • બે સમાંતર સમતલોના લંબ સદિશ સમાન હોય
🧠 Trick: ABCD નિયમ: A(x) + B(y) + C(z) + D = 0, જ્યાં ABC લંબ સદિશ છે

બિંદુ અને સમતલ વચ્ચેનું અંતર

બિંદુ P(x₁, y₁, z₁) અને સમતલ ax + by + cz + d = 0 વચ્ચેનું અંતર d = |ax₁ + by₁ + cz₁ + d| / √(a² + b² + c²) દ્વારા મળે છે. આ સૂત્ર સમતલથી બિંદુનું લંબ અંતર આપે છે.

  • અંતર સૂત્ર: d = |ax₁ + by₁ + cz₁ + d| / √(a² + b² + c²)
  • અંતર હંમેશા ધન મૂલ્ય હોય
  • બિંદુ સમતલ પર હોય તો અંતર શૂન્ય
  • સમાંતર સમતલો વચ્ચેનું અંતર પણ આ સૂત્રથી શોધી શકાય
🧠 Trick: PAD નિયમ: Point-Plane Distance = |P·n̂ + d| / |n̂|

બે સમતલો વચ્ચેનો ખૂણો

બે સમતલો વચ્ચેનો ખૂણો તેમના લંબ સદિશો વચ્ચેના ખૂણા જેટલો હોય છે. જો સમતલોનાં સમીકરણો a₁x + b₁y + c₁z + d₁ = 0 અને a₂x + b₂y + c₂z + d₂ = 0 હોય, તો ખૂણો θ = cos⁻¹(|a₁a₂ + b₁b₂ + c₁c₂| / √(a₁² + b₁² + c₁²)√(a₂² + b₂² + c₂²)) થી મળે છે.

  • ખૂણો લંબ સદિશો વચ્ચેનો ખૂણો
  • cosθ = |n̂₁·n̂₂| / (|n̂₁||n̂₂|)
  • સમાંતર સમતલો માટે θ = 0° અથવા 180°
  • લંબ સમતલો માટે θ = 90°
🧠 Trick: COS નિયમ: COSine of angle = Dot product / Product of magnitudes

સમતલનું આંતરછેદ અને રેખા-સમતલ આંતરછેદ

બે સમતલોનું આંતરછેદ એક રેખા હોય છે, જેને દિશા સદિશ n̂₁ × n̂₂ વડે વ્યાખ્યાયિત કરી શકાય. રેખા અને સમતલનું આંતરછેદ બિંદુ શોધવા માટે રેખાના પ્રાચલિક સમીકરણોને સમતલના સમીકરણમાં મૂકવામાં આવે છે.

  • બે સમતલોનું આંતરછેદ: રેખા (n̂₁ × n̂₂ દિશા)
  • રેખા-સમતલ આંતરછેદ: પ્રાચલ t માટે ઉકેલ
  • સમાંતર સમતલોનું આંતરછેદ શક્ય નથી
  • રેખા સમતલને સમાંતર હોય તો આંતરછેદ ન હોય
🧠 Trick: CRP નિયમ: Cross product for Plane intersection, Replace parameter for line-Plane

સમતલનું પ્રાચલિક અને સદિશ સમીકરણ

સમતલનું સદિશ સમીકરણ r̄ = ā + λb̄ + μc̄ છે, જ્યાં ā સમતલ પરનું બિંદુ છે અને b̄, c̄ સમતલમાં રહેલા બે અસંરેખ સદિશો છે. પ્રાચલિક સમીકરણ x = x₀ + λb₁ + μc₁, y = y₀ + λb₂ + μc₂, z = z₀ + λb₃ + μc₃ દ્વારા મળે છે.

  • સદિશ સમીકરણ: r̄ = ā + λb̄ + μc̄
  • પ્રાચલ λ અને μ સમતલ પરના બિંદુઓ નક્કી કરે
  • b̄ અને c̄ અસંરેખ હોવા જોઈએ
  • સમતલનો લંબ સદિશ b̄ × c̄ થી મળે
🧠 Trick: LAMBDA-MU નિયમ: λ અને μ પ્રાચલો સમતલ પરના બિંદુઓ આપે

સમતલનું આંતરછેદ અને અંતરના પ્રશ્નો

JEEમાં વારંવાર પૂછાતા પ્રશ્નોમાં બે સમતલો વચ્ચેનું અંતર, બિંદુથી સમતલનું અંતર, અને સમતલો વચ્ચેનો ખૂણો શામેલ છે. આ પ્રશ્નો ઉકેલવા માટે લંબ સદિશો અને બિંદુ-સમતલ અંતર સૂત્રનો ઉપયોગ કરવો જરૂરી છે.

  • સમાંતર સમતલો વચ્ચેનું અંતર: |d₁ - d₂| / √(a² + b² + c²)
  • બિંદુથી સમતલનું અંતર: સૂત્ર યાદ રાખો
  • ખૂણો શોધવા માટે ડોટ પ્રોડક્ટનો ઉપયોગ
  • આંતરછેદ રેખા માટે ક્રોસ પ્રોડક્ટ
🧠 Trick: DAD નિયમ: Distance = Absolute Difference / Denominator

⚡ Quick Revision

  • સમતલનું સામાન્ય સમીકરણ: ax + by + cz + d = 0
  • લંબ સદિશ n̂ = (a, b, c) સમતલને લંબ હોય
  • બિંદુ-સમતલ અંતર: |ax₁ + by₁ + cz₁ + d| / √(a² + b² + c²)
  • બે સમતલો વચ્ચેનો ખૂણો: cosθ = |n̂₁·n̂₂| / (|n̂₁||n̂₂|)
  • સમાંતર સમતલો માટે n̂₁ = k n̂₂ (k ≠ 0)
  • લંબ સમતલો માટે n̂₁·n̂₂ = 0
  • બે સમતલોનું આંતરછેદ: રેખા (n̂₁ × n̂₂ દિશા)
  • સમતલનું સદિશ સમીકરણ: r̄ = ā + λb̄ + μc̄
  • સમાંતર સમતલો વચ્ચેનું અંતર: |d₁ - d₂| / √(a² + b² + c²)
  • રેખા-સમતલ આંતરછેદ: પ્રાચલ t માટે ઉકેલ
🎯 Exam Tip: JEEમાં સમતલના પ્રશ્નોમાં લંબ સદિશ (n̂) અને ક્રોસ પ્રોડક્ટનો ઉપયોગ મુખ્ય છે. પ્રશ્નમાં આપેલી માહિતી પરથી n̂ શોધી લો અને પછી અંતર, ખૂણો કે આંતરછેદ માટે યોગ્ય સૂત્ર લાગુ કરો. સમય બચાવવા માટે સદિશ પદ્ધતિનો ઉપયોગ કરો.
