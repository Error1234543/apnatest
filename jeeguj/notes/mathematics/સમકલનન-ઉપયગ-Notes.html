સમાકલનના ઉપયોગો

📖 સમાકલનના ઉપયોગો (Applications of Integration)

ક્ષેત્રફળ શોધવામાં (Area Under Curves)

સમાકલનનો મુખ્ય ઉપયોગ વક્ર અને x-અક્ષ વચ્ચેના ક્ષેત્રફળની ગણતરી કરવા માટે થાય છે. જો y = f(x) એ સતત વિધેય હોય, તો વક્ર, x=a, x=b અને x-અક્ષ વચ્ચેનું ક્ષેત્રફળ ∫ₐᵇ f(x) dx થી મળે છે. જો વક્ર x-અક્ષની નીચે હોય, તો સમાકલનનું મૂલ્ય ઋણ આવે છે, તેથી ક્ષેત્રફળ હંમેશા ધન લેવાય છે.

  • ક્ષેત્રફળ = |∫ₐᵇ f(x) dx| (વક્ર x-અક્ષની ઉપર કે નીચે હોય)
  • બે વક્રો વચ્ચેનું ક્ષેત્રફળ = ∫ₐᵇ [f(x) - g(x)] dx (f(x) ≥ g(x))
  • y-અક્ષને સમાંતર ક્ષેત્રફળ માટે x = f(y) સ્વરૂપે સમાકલન કરવું
🧠 Trick: ક્ષેત્રફળ માટે 'ઉપરનું ઓછું નીચેનું' યાદ રાખો (f(x) - g(x))

ઘનફળ શોધવામાં (Volumes of Solids of Revolution)

વક્રને x-અક્ષ કે y-અક્ષની આસપાસ ભ્રમણ કરાવતાં બનતા ઘનનું ઘનફળ સમાકલનથી ગણી શકાય છે. ડિસ્ક પદ્ધતિ: V = π ∫ₐᵇ [f(x)]² dx (x-અક્ષની આસપાસ). વોશર પદ્ધતિ: બે વક્રો વચ્ચેનું ઘનફળ = π ∫ₐᵇ ([f(x)]² - [g(x)]²) dx.

  • ડિસ્ક પદ્ધતિ: V = π ∫ y² dx (x-અક્ષ માટે)
  • શેલ પદ્ધતિ: V = 2π ∫ x·f(x) dx (y-અક્ષ માટે વધુ સરળ)
  • ઘનફળ હંમેશા ધન મૂલ્યમાં લેવું
🧠 Trick: ડિસ્ક માટે 'πr²' જેવું યાદ રાખો (π[y]²)

વક્રની લંબાઈ (Arc Length)

સતત વિકલનીય વિધેય y = f(x) માટે વક્રની લંબાઈ L = ∫ₐᵇ √(1 + [f'(x)]²) dx થી મળે છે. આ સૂત્ર પાયથાગોરસના પ્રમેય પર આધારિત છે, જ્યાં dx અને dy નાના રેખાખંડો છે.

  • લંબાઈ સૂત્ર: L = ∫ √(1 + (dy/dx)²) dx
  • પરમિતીય સ્વરૂપ માટે: L = ∫ √((dx/dt)² + (dy/dt)²) dt
  • ધ્રુવીય સ્વરૂપ માટે: L = ∫ √(r² + (dr/dθ)²) dθ
🧠 Trick: લંબાઈ માટે 'પાયથાગોરસનો સમાકલન' યાદ રાખો

પૃષ્ઠફળ શોધવામાં (Surface Area of Revolution)

વક્રને અક્ષની આસપાસ ભ્રમણ કરાવતાં બનતા પૃષ્ઠનું ક્ષેત્રફળ S = 2π ∫ₐᵇ f(x) √(1 + [f'(x)]²) dx થી મળે છે. આ સૂત્ર વક્રની લંબાઈ અને વર્તુળના પરિઘના ગુણાકાર પર આધારિત છે.

  • પૃષ્ઠફળ: S = 2π ∫ y √(1 + (dy/dx)²) dx (x-અક્ષ માટે)
  • y-અક્ષ માટે: S = 2π ∫ x √(1 + (dx/dy)²) dy
  • ધ્રુવીય સ્વરૂપમાં પણ લાગુ પડે છે
🧠 Trick: પૃષ્ઠફળ માટે '2π × ત્રિજ્યા × લંબાઈ' યાદ રાખો

ભૌતિક વિજ્ઞાનમાં ઉપયોગો (Applications in Physics)

સમાકલનનો ઉપયોગ કાર્ય (W = ∫ F·dx), દળ કેન્દ્ર (x̄ = ∫ x dm / ∫ dm), જડત્વની ચાકમાત્રા (I = ∫ r² dm) અને વિદ્યુતભારના વિતરણમાં થાય છે. સ્થિતિમાન ઊર્જા, વિદ્યુતક્ષેત્ર અને ગુરુત્વાકર્ષણ બળની ગણતરીમાં પણ સમાકલન આવશ્યક છે.

  • કાર્ય: W = ∫ F·ds (ચલ બળ માટે)
  • દળ કેન્દ્ર: x̄ = (∫ x ρ dV) / (∫ ρ dV)
  • જડત્વની ચાકમાત્રા: I = ∫ r² dm
  • વિદ્યુતક્ષેત્ર: E = (1/4πε₀) ∫ (dq/r²) r̂
🧠 Trick: ભૌતિકીમાં 'સમાકલન = સરવાળાનો સતત સ્વરૂપ'

આંકડાશાસ્ત્ર અને સંભાવનામાં ઉપયોગો (Probability & Statistics)

સતત ચલ માટે સંભાવના ઘનતા વિધેય (PDF) f(x) નું સમાકલન સંભાવના આપે છે: P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx. અપેક્ષિત મૂલ્ય E(X) = ∫ x f(x) dx અને વિચરણ Var(X) = ∫ (x - μ)² f(x) dx થી મળે છે.

  • સંભાવના: P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx
  • અપેક્ષિત મૂલ્ય: E(X) = ∫ x f(x) dx
  • વિચરણ: Var(X) = E(X²) - [E(X)]²
  • સામાન્ય વિતરણમાં પણ સમાકલન આવશ્યક
🧠 Trick: સંભાવનામાં 'PDF નું સમાકલન = સંભાવના'

⚡ Quick Revision

  • ક્ષેત્રફળ = |∫ f(x) dx| (વક્ર અને x-અક્ષ વચ્ચે)
  • બે વક્રો વચ્ચેનું ક્ષેત્રફળ = ∫ (f(x) - g(x)) dx
  • ઘનફળ (ડિસ્ક): V = π ∫ y² dx
  • લંબાઈ: L = ∫ √(1 + (dy/dx)²) dx
  • પૃષ્ઠફળ: S = 2π ∫ y √(1 + (dy/dx)²) dx
  • કાર્ય: W = ∫ F·dx (ચલ બળ માટે)
  • દળ કેન્દ્ર: x̄ = (∫ x dm) / (∫ dm)
  • સંભાવના: P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx
  • અપેક્ષિત મૂલ્ય: E(X) = ∫ x f(x) dx
  • જડત્વની ચાકમાત્રા: I = ∫ r² dm
