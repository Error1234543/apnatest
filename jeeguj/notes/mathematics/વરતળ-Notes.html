Pro Notes

વર્તુળ

📖 વર્તુળ (Circle)

વર્તુળની મૂળભૂત વ્યાખ્યા અને ગુણધર્મો

વર્તુળ એ ટપકાંથી સમાન અંતરે રહેલા બિંદુઓનો સંગ્રહ છે. તેનું કેન્દ્ર (O) અને ત્રિજ્યા (r) એ મૂળભૂત ઘટકો છે. વર્તુળની પરિઘ (Circumference) = 2πr, જ્યારે ક્ષેત્રફળ = πr². વર્તુળનો વ્યાસ (Diameter) એ ત્રિજ્યાનો દ્વિગુણ હોય છે.

  • વર્તુળ = {x | d(x, O) = r}
  • પરિઘ = 2πr, ક્ષેત્રફળ = πr²
  • વ્યાસ = 2r
  • વર્તુળનો કોઈપણ સરળ રેખાખંડ જે કેન્દ્રથી પસાર થાય તે વ્યાસ કહેવાય
🧠 Trick: વર્તુળ રે’રા: રેડિયસ રહે સરખો, પરિઘ રહે 2πr

વર્તુળના ચાપ અને કોણ

વર્તુળના બે બિંદુઓ વચ્ચેનો ખંડ ચાપ કહેવાય. કેન્દ્રીય કોણ એ ચાપને કેન્દ્રમાંથી જોવાનો કોણ છે. ચાપની લંબાઈ = (θ/360) × 2πr, જ્યાં θ એ કેન્દ્રીય કોણ છે. અર્ધવર્તુળનો કેન્દ્રીય કોણ 180° હોય છે.

  • ચાપની લંબાઈ = (θ/360) × 2πr
  • કેન્દ્રીય કોણ = ચાપ દ્વારા કેન્દ્ર પર બનતો કોણ
  • અર્ધવર્તુળનો કેન્દ્રીય કોણ = 180°
  • લઘુ ચાપ < 180°, દીર્ઘ ચાપ > 180°
🧠 Trick: ચાપ કોણ ચક્ર: ચાપ કોણ ચોક્કસ, લંબાઈ θ/360 × 2πr

વર્તુળની સ્પર્શરેખા અને લંબરેખા

સ્પર્શરેખા વર્તુળને એક જ બિંદુએ સ્પર્શે છે અને ત્રિજ્યાને લંબ હોય છે. સ્પર્શરેખા અને ત્રિજ્યાનો છેદબિંદુ સ્પર્શબિંદુ કહેવાય. એક બિંદુથી વર્તુળ પર બે સ્પર્શરેખાઓ દોરી શકાય, જેની લંબાઈ સરખી હોય છે.

  • સ્પર્શરેખા ⊥ ત્રિજ્યા (સ્પર્શબિંદુ પર)
  • એક બહારના બિંદુથી બે સ્પર્શરેખાઓની લંબાઈ સરખી
  • સ્પર્શરેખાની લંબાઈ = √(d² - r²), જ્યાં d = બિંદુથી કેન્દ્રનું અંતર
🧠 Trick: સ્પર્શ લંબ: સ્પર્શરેખા લંબ રહે ત્રિજ્યાથી

વર્તુળના જીવા અને ધનુષ્ય

જીવા એ વર્તુળના બે બિંદુઓને જોડતો રેખાખંડ છે. ધનુષ્ય એ જીવા અને ચાપ વચ્ચેનો પ્રદેશ છે. જીવાની લંબાઈ = 2r sin(θ/2), જ્યાં θ એ કેન્દ્રીય કોણ છે. સૌથી લાંબી જીવા વ્યાસ હોય છે.

  • જીવાની લંબાઈ = 2r sin(θ/2)
  • ધનુષ્ય = જીવા + ચાપ
  • વ્યાસ એ સૌથી લાંબી જીવા છે
  • જીવાનો લંબ સમદ્વિભાજક કેન્દ્રમાંથી પસાર થાય

વર્તુળોની પરસ્પર સ્થિતિ

બે વર્તુળોની પરસ્પર સ્થિતિ તેમના કેન્દ્રો વચ્ચેના અંતર (d) અને ત્રિજ્યાઓ (r₁, r₂) પર આધાર રાખે છે. જો d > r₁ + r₂ તો વર્તુળો અલગ પડે છે. જો d = r₁ + r₂ તો બહારથી સ્પર્શે છે. જો |r₁ - r₂| < d < r₁ + r₂ તો બે બિંદુએ છેદે છે.

  • d > r₁ + r₂ → અલગ પડે
  • d = r₁ + r₂ → બહારથી સ્પર્શે
  • |r₁ - r₂| < d < r₁ + r₂ → બે બિંદુએ છેદે
  • d = |r₁ - r₂| → અંદરથી સ્પર્શે
  • d < |r₁ - r₂| → એક અંદર બીજા
🧠 Trick: બહાર સ્પર્શ: d = r₁ + r₂, અંદર સ્પર્શ: d = |r₁ - r₂|

વર્તુળનું સમીકરણ (Cartesian અને Polar)

Cartesian પદ્ધતિમાં વર્તુળનું સમીકરણ (x - h)² + (y - k)² = r² છે, જ્યાં (h, k) કેન્દ્ર છે. Polar પદ્ધતિમાં વર્તુળનું સમીકરણ r = a (સરળ વર્તુળ) અથવા r = 2a cosθ (વ્યાસ પરથી પસાર થતું વર્તુળ) હોય છે.

  • Cartesian: (x - h)² + (y - k)² = r²
  • Polar: r = a (કેન્દ્ર મૂળબિંદુ)
  • Polar: r = 2a cosθ (વ્યાસ x-અક્ષ પર)
  • કેન્દ્ર (h, k), ત્રિજ્યા r

વર્તુળ અને ત્રિકોણની સંકળાયેલ સમસ્યાઓ

વર્તુળમાં લખેલ ત્રિકોણના શીર્ષો વર્તુળ પર હોય છે, જ્યારે વર્તુળને અંતર્ગત ત્રિકોણના બાજુઓ વર્તુળને સ્પર્શે છે. વર્તુળના કેન્દ્રથી ત્રિકોણના શીર્ષ પરના કોણને કેન્દ્રીય કોણ કહેવાય. પરિઘ કોણ એ વર્તુળના ચાપ પરના કોણ છે.

  • લખેલ ત્રિકોણ = શીર્ષો વર્તુળ પર
  • અંતર્ગત ત્રિકોણ = બાજુઓ વર્તુળને સ્પર્શે
  • પરિઘ કોણ = ચાપ પરનો કોણ = ½ × કેન્દ્રીય કોણ
  • સંલગ્ન કોણોનો સરવાળો 180°
🧠 Trick: પરિઘ કોણ અર્ધો: પરિઘ કોણ = ½ કેન્દ્રીય કોણ
