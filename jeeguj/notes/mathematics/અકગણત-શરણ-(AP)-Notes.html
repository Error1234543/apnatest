અંકગણિત શ્રેણી (AP)

📖 અંકગણિત શ્રેણી (AP)

પરિભાષા અને મૂળભૂત સૂત્ર

અંકગણિત શ્રેણી (AP) એ એક એવી શ્રેણી છે જેમાં દરેક પદ અને તેના પૂર્વવર્તી પદ વચ્ચેનો તફાવત સરખો હોય છે, જેને સામાન્ય તફાવત (d) કહેવાય છે. જો પ્રથમ પદ a અને સામાન્ય તફાવત d હોય, તો n-મા પદનું સૂત્ર aₙ = a + (n-1)d હોય છે.

  • APમાં સામાન્ય તફાવત (d) સરખો રહે છે.
  • n-મા પદનું સૂત્ર: aₙ = a + (n-1)d
  • d = aₙ - aₙ₋₁
  • જો d = 0 હોય, તો શ્રેણી સરખી રહે છે.
🧠 Trick: AP = a + (n-1)d → 'A'pple 'P'ie 'a'nd 'n-1' 'd'ays

શ્રેણીનો સરવાળો (Sum of n terms)

APના પ્રથમ n પદનો સરવાળો Sₙ = n/2 [2a + (n-1)d] અથવા Sₙ = n/2 (a₁ + aₙ) વડે મેળવી શકાય છે. આ સૂત્રોનો ઉપયોગ શ્રેણીના સરવાળાને ઝડપથી ગણવા માટે થાય છે.

  • Sₙ = n/2 [2a + (n-1)d]
  • Sₙ = n/2 (a₁ + aₙ)
  • જો શ્રેણી સરખી હોય (d=0), તો Sₙ = n × a
  • સરવાળાનું સૂત્ર ગાણિતિક શ્રેણી માટે મહત્વપૂર્ણ છે.
🧠 Trick: Sₙ = n/2 (First + Last) → 'S'um is 'n'/2 times 'F'irst plus 'L'ast

મધ્ય પદ (Middle Term)

જો APમાં પદની સંખ્યા વિષમ હોય, તો મધ્ય પદ એ શ્રેણીનો મધ્યમ પદ હોય છે. જો n વિષમ હોય, તો મધ્ય પદ a₍ₙ₊₁₎/₂ = a + (n-1)/2 × d વડે મેળવી શકાય છે.

  • વિષમ n માટે મધ્ય પદ: a₍ₙ₊₁₎/₂
  • મધ્ય પદ = સરવાળો / n
  • સરળીકરણ માટે ઉપયોગી
  • જો n સમાન હોય, તો બે મધ્ય પદો હોય છે.

APમાં પદોની ગણતરી

APમાં કોઈપણ પદને aₙ = a + (n-1)d વડે શોધી શકાય છે. જો કોઈ પદ x હોય, તો તેનું સ્થાન n = [(x - a)/d] + 1 વડે શોધી શકાય છે.

  • aₙ = a + (n-1)d
  • n = [(x - a)/d] + 1
  • પદની ગણતરી માટે ઉપયોગી
  • જો x શ્રેણીમાં ન હોય, તો n પૂર્ણાંક નહીં હોય.

APના ગુણધર્મો

APમાં, જો a, b, c ક્રમિક પદો હોય, તો 2b = a + c. આ ગુણધર્મનો ઉપયોગ શ્રેણીના પદોની તપાસ માટે થાય છે. એટલે કે, મધ્ય પદ એ પૂર્વ અને પશ્ચ પદનો સરેરાશ હોય છે.

  • 2b = a + c (ક્રમિક પદો માટે)
  • મધ્ય પદ = સરેરાશ
  • ગુણધર્મો શ્રેણીની પુષ્ટિ માટે ઉપયોગી
  • જો 2b ≠ a + c, તો શ્રેણી AP નથી.
🧠 Trick: 2b = a + c → 'T'wo 'b' is 'a' plus 'c'

AP અને GP વચ્ચેનો સંબંધ

જો APના પદોને ગુણોત્તર શ્રેણી (GP)માં રૂપાંતરિત કરવા હોય, તો તેના પદો પર કોઈ સરખો આધાર (base) લોગારિથમ લેવો પડે છે. પરંતુ સીધો સંબંધ નથી.

  • AP અને GP વચ્ચે સીધો સંબંધ નથી.
  • લોગારિથમ વડે રૂપાંતરણ શક્ય
  • સામાન્ય રીતે, AP અને GP અલગ શ્રેણીઓ છે.
  • જો d = 0, તો AP સરખી શ્રેણી બને છે.

ઉદાહરણો અને અરજી

APનો ઉપયોગ ભૌતિકશાસ્ત્રમાં સરળ હલનચલન, રસાયણશાસ્ત્રમાં સાંદ્રતા શ્રેણી, અને ગણિતમાં વિવિધ સમસ્યાઓ ઉકેલવા માટે થાય છે. ઉદાહરણ: 2, 5, 8, 11,... એ AP છે જેમાં a=2 અને d=3.

  • ભૌતિકશાસ્ત્ર: સરળ હલનચલન
  • રસાયણશાસ્ત્ર: સાંદ્રતા શ્રેણી
  • ગણિત: સમસ્યાઓ ઉકેલવા
  • ઉદાહરણ: 2, 5, 8, 11 (a=2, d=3)

⚡ Quick Revision

  • APમાં સામાન્ય તફાવત (d) સરખો રહે છે.
  • n-મા પદનું સૂત્ર: aₙ = a + (n-1)d
  • સરવાળાનું સૂત્ર: Sₙ = n/2 [2a + (n-1)d]
  • મધ્ય પદ = સરવાળો / n (વિષમ n માટે)
  • 2b = a + c (ક્રમિક પદો માટે)
  • AP અને GP વચ્ચે સીધો સંબંધ નથી.
  • જો d = 0, તો શ્રેણી સરખી રહે છે.
  • n = [(x - a)/d] + 1 (પદની ગણતરી માટે)
  • Sₙ = n/2 (a₁ + aₙ) (સરવાળાનું બીજું સૂત્ર)
  • APનો ઉપયોગ ભૌતિકશાસ્ત્ર અને રસાયણશાસ્ત્રમાં થાય છે.
🎯 Exam Tip: APની સમસ્યાઓ ઉકેલતી વખતે, હંમેશા પ્રથમ પદ (a) અને સામાન્ય તફાવત (d) ની કિંમતો સ્પષ્ટ કરો. સૂત્રોને યાદ રાખવા માટે મનમાં રાખો કે aₙ અને Sₙ ના સૂત્રો એકબીજા સાથે સંબંધિત છે.
