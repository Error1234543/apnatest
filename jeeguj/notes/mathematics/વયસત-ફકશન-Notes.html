વ્યસ્ત ફંક્શન

📖 વ્યસ્ત ફંક્શન (Inverse Function)

વ્યાખ્યા અને મૂળભૂત ખ્યાલ

જો કોઈ ફંક્શન f: A → B એ એક-એક અને onto (બાયજેક્ટિવ) હોય, તો તેનું વ્યસ્ત ફંક્શન f⁻¹: B → A અસ્તિત્વ ધરાવે છે. વ્યસ્ત ફંક્શન f⁻¹ એવું ફંક્શન છે જે f ના પરિણામને પાછું મૂળ મૂલ્યમાં પરિવર્તિત કરે છે, એટલે કે f⁻¹(f(x)) = x અને f(f⁻¹(y)) = y.

  • f બાયજેક્ટિવ (એક-એક અને onto) હોવું જરૂરી છે
  • f⁻¹(f(x)) = x અને f(f⁻¹(y)) = y (વ્યસ્તનો ગુણધર્મ)
  • f અને f⁻¹ ના આલેખ y = x રેખા પર સપ્રમાણ હોય છે
🧠 Trick: બાયજેક્ટિવ = બે જગ્યાએ જોડાણ (એક-એક અને onto)

વ્યસ્ત ફંક્શન શોધવાની રીત

વ્યસ્ત ફંક્શન શોધવા માટે, y = f(x) સમીકરણ લો અને તેને x માટે ઉકેલો. મળેલું x = f⁻¹(y) એ વ્યસ્ત ફંક્શન છે. ઉદાહરણ: f(x) = 2x + 3 નું વ્યસ્ત f⁻¹(y) = (y - 3)/2 છે.

  • y = f(x) લઈ x માટે ઉકેલો
  • પરિણામી x = f⁻¹(y) લખો
  • વ્યસ્ત ફંક્શન માટે ડોમેન અને રેન્જ બદલાય છે
🧠 Trick: y ને x બનાવો, x ને y બનાવો

વ્યસ્ત ત્રિકોણમિતીય ફંક્શન

સામાન્ય ત્રિકોણમિતીય ફંક્શનના વ્યસ્તને વ્યસ્ત ત્રિકોણમિતીય ફંક્શન કહે છે. ઉદાહરણ: sin⁻¹x, cos⁻¹x, tan⁻¹x. આ ફંક્શનનો ઉપયોગ કોણ શોધવા માટે થાય છે જ્યારે ત્રિકોણમિતીય ગુણોત્તર આપેલ હોય.

  • sin⁻¹x નો ડોમેન [-1,1] અને રેન્જ [-π/2, π/2]
  • cos⁻¹x નો ડોમેન [-1,1] અને રેન્જ [0, π]
  • tan⁻¹x નો ડોમેન R અને રેન્જ (-π/2, π/2)
🧠 Trick: સાઇન-પાઇ/2, કોસ-પાઇ, ટેન-પાઇ/2

વ્યસ્ત ફંક્શનના ગુણધર્મો

1) (f⁻¹)⁻¹ = f, 2) (f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹, 3) જો f વધતું હોય તો f⁻¹ પણ વધતું હોય છે. આ ગુણધર્મોનો ઉપયોગ જટિલ ફંક્શનના વ્યસ્ત શોધવામાં થાય છે.

  • (f⁻¹)⁻¹ = f (વ્યસ્તનું વ્યસ્ત મૂળ ફંક્શન)
  • (f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹ (ક્રમ ઉલટાવો)
  • વધતા ફંક્શનનું વ્યસ્ત પણ વધતું હોય છે
🧠 Trick: વ્યસ્તનું વ્યસ્ત મૂળ, ક્રમ ઉલટાવો

વ્યસ્ત ફંક્શનના આલેખ

f અને f⁻¹ ના આલેખ y = x રેખા પર સપ્રમાણ હોય છે. આનો ઉપયોગ વ્યસ્ત ફંક્શનનો આલેખ દોરવા માટે થાય છે. જો (a,b) એ f ના આલેખ પર હોય, તો (b,a) એ f⁻¹ ના આલેખ પર હશે.

  • y = x રેખા પર સપ્રમાણતા
  • (a,b) ∈ f ⇒ (b,a) ∈ f⁻¹
  • આલેખ દોરવા માટે મિરર ઇમેજ જેવું
🧠 Trick: y = x ની આસપાસ ફોલ્ડ કરો

વ્યસ્ત ફંક્શનના ઉપયોગો

વ્યસ્ત ફંક્શનનો ઉપયોગ ભૌતિકશાસ્ત્રમાં પ્રક્ષેપણની સમસ્યાઓ, અર્થશાસ્ત્રમાં માંગ અને પુરવઠાના વિશ્લેષણ, અને કમ્પ્યુટર વિજ્ઞાનમાં એન્ક્રિપ્શનમાં થાય છે. ગણિતમાં તેનો ઉપયોગ સમીકરણ ઉકેલવા અને ફંક્શનના ગુણધર્મોનો અભ્યાસ કરવા માટે થાય છે.

  • પ્રક્ષેપણની સમસ્યાઓમાં કોણ શોધવા
  • માંગ-પુરવઠાના વિશ્લેષણમાં
  • એન્ક્રિપ્શન અને ડિક્રિપ્શનમાં

⚡ Quick Revision

  • વ્યસ્ત ફંક્શન f⁻¹ ત્યારે જ અસ્તિત્વ ધરાવે જ્યારે f બાયજેક્ટિવ હોય
  • f⁻¹(f(x)) = x અને f(f⁻¹(y)) = y વ્યસ્તનો મૂળભૂત ગુણધર્મ
  • y = f(x) ને x માટે ઉકેલીને વ્યસ્ત ફંક્શન મેળવો
  • sin⁻¹x નો રેન્જ [-π/2, π/2], cos⁻¹x નો રેન્જ [0, π]
  • f અને f⁻¹ ના આલેખ y = x રેખા પર સપ્રમાણ હોય છે
  • (f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹ (ક્રમ ઉલટાવો)
  • વધતા ફંક્શનનું વ્યસ્ત પણ વધતું હોય છે
  • વ્યસ્ત ફંક્શનનો ઉપયોગ પ્રક્ષેપણ, માંગ-પુરવઠા અને એન્ક્રિપ્શનમાં થાય છે
🎯 Exam Tip: વ્યસ્ત ફંક્શનના પ્રશ્નોમાં પહેલા ચકાસો કે આપેલ ફંક્શન બાયજેક્ટિવ છે કે નહીં. જો ન હોય તો વ્યસ્ત અસ્તિત્વ ધરાવતું નથી. ત્રિકોણમિતીય ફંક્શનના વ્યસ્ત માટે રેન્જ યાદ રાખો અને MCQ માં વિકલ્પોને રેન્જ મુજબ ફિલ્ટર કરો.
