Pro Notes

સંબંધ

📖 સંબંધ (Relation) - ગણિત (Mathematics)

સંબંધની વ્યાખ્યા અને પ્રકાર

સંબંધ એ બે સેટ્સ વચ્ચેના કોઈપણ ઉપસેટનો સંબંધ દર્શાવે છે. જો A અને B સેટ્સ હોય, તો A × B નો કોઈપણ ઉપસેટ એ A થી B તરફનો સંબંધ કહેવાય. સંબંધ ચાર પ્રકારના હોય: સરળ, પૂર્ણ, પ્રતિબિંબી, અને સમમિત.

  • સંબંધ R ⊆ A × B
  • સરળ સંબંધ: R = {(a,b) | a ∈ A, b ∈ B, a = b}
  • પૂર્ણ સંબંધ: R = A × A
  • પ્રતિબિંબી સંબંધ: (a,a) ∈ R ∀ a ∈ A
  • સમમિત સંબંધ: (a,b) ∈ R ⇒ (b,a) ∈ R
🧠 Trick: સરલ પૂરા પ્રતિબિંબ સમમિત (સર-પૂ-પ્ર-સમ)

સંબંધના ગુણધર્મો

સંબંધના મહત્વના ગુણધર્મો: પ્રતિબિંબી, સમમિત, અને પારગમ્ય. પ્રતિબિંબી: (a,a) ∈ R, સમમિત: (a,b) ∈ R ⇒ (b,a) ∈ R, પારગમ્ય: (a,b) ∈ R અને (b,c) ∈ R ⇒ (a,c) ∈ R.

  • પ્રતિબિંબી: દરેક અવયવ પોતાની સાથે સંબંધ ધરાવે
  • સમમિત: જો a, b સંબંધિત હોય તો b, a પણ સંબંધિત
  • પારગમ્ય: a→b અને b→c ⇒ a→c
  • તુલ્યતા સંબંધ = પ્રતિબિંબી + સમમિત + પારગમ્ય
🧠 Trick: પ્ર-સ-પા (પ્રતિબિંબી, સમમિત, પારગમ્ય)

તુલ્યતા સંબંધ અને ભાગલ

જ્યારે સંબંધ પ્રતિબિંબી, સમમિત, અને પારગમ્ય હોય ત્યારે તે તુલ્યતા સંબંધ કહેવાય. તુલ્યતા સંબંધ દ્વારા સેટને અસરકારક રીતે ભાગલ પાડી શકાય.

  • તુલ્યતા સંબંધ = R એ પ્રતિબિંબી, સમમિત, પારગમ્ય
  • ભાગલ: સેટના ઉપસેટ્સનો સમૂહ જ્યાં દરેક અવયવ એક જ ભાગલમાં હોય
  • [a] = {x | x ∈ A, (a,x) ∈ R} એ a ની તુલ્યતા વર્ગ કહેવાય
  • A/R એ ભાગલ સેટ કહેવાય

સંબંધનું નિરૂપણ

સંબંધને રોસ્ટર પદ્ધતિ, સેટ બિલ્ડર પદ્ધતિ, અથવા મેટ્રિક્સ પદ્ધતિથી દર્શાવી શકાય. રોસ્ટર પદ્ધતિમાં કોષ્ટકના સ્વરૂપે લખવામાં આવે છે, જ્યારે મેટ્રિક્સ પદ્ધતિમાં 0 અને 1 નો ઉપયોગ થાય છે.

  • રોસ્ટર પદ્ધતિ: R = {(a,b), (c,d), ...}
  • સેટ બિલ્ડર: R = {(x,y) | x ∈ A, y ∈ B, x + y = 5}
  • મેટ્રિક્સ પદ્ધતિ: M[i][j] = 1 જો (a_i, b_j) ∈ R, નહીં તો 0
  • આલેખ પદ્ધતિ: X-Y ગ્રાફ પર બિંદુઓ દ્વારા દર્શાવવું

સંબંધ અને ફંક્શન વચ્ચેનો તફાવત

સંબંધ એ કોઈપણ ઉપસેટ હોઈ શકે, જ્યારે ફંક્શન એ ખાસ પ્રકારનો સંબંધ છે જ્યાં દરેક ઇનપુટ માટે એક જ આઉટપુટ હોય. ફંક્શનમાં, દરેક a ∈ A માટે એક જ b ∈ B હોય.

  • સંબંધ: કોઈપણ ઉપસેટ R ⊆ A × B
  • ફંક્શન: દરેક a ∈ A માટે એક જ b ∈ B જ્યાં (a,b) ∈ R
  • ફંક્શન એ સંબંધનો ખાસ કિસ્સો છે
  • વર્ટિકલ લાઇન ટેસ્ટ: જો કોઈ વર્ટિકલ લાઇન ગ્રાફને બે બિંદુઓ પર કાપે તો તે ફંક્શન નથી
🧠 Trick: સંબંધ = સામાન્ય, ફંક્શન = ખાસ

સંબંધનું સંયોજન

જો R એ A થી B તરફનો અને S એ B થી C તરફનો સંબંધ હોય, તો R અને S નું સંયોજન R∘S એ A થી C તરફનો સંબંધ હોય. (a,c) ∈ R∘S ⇔ ∃ b ∈ B જ્યાં (a,b) ∈ R અને (b,c) ∈ S.

  • R∘S = {(a,c) | ∃ b ∈ B, (a,b) ∈ R અને (b,c) ∈ S}
  • સંયોજનનો ક્રમ મહત્વનો છે: R∘S ≠ S∘R
  • (R∘S)∘T = R∘(S∘T)
  • R∘I = I∘R = R જ્યાં I એ ઓળખ સંબંધ છે

સંબંધ અને મેટ્રિક્સ

સંબંધને મેટ્રિક્સ સ્વરૂપે દર્શાવતી વખતે, મેટ્રિક્સના આકાર પરથી સેટ્સના કદનું નિર્ધારણ થાય. જો A અને B સેટ્સના કદ અનુક્રમે m અને n હોય, તો સંબંધ મેટ્રિક્સ m × n કદની હોય.

  • A = {a1, a2, ..., am}, B = {b1, b2, ..., bn} ⇒ મેટ્રિક્સ m × n
  • M[i][j] = 1 જો (ai, bj) ∈ R, નહીં તો 0
  • પ્રતિબિંબી સંબંધની મેટ્રિક્સમાં મુખ્ય વિકર્ણ પર 1 હોય
  • સમમિત સંબંધની મેટ્રિક્સ સમમિત મેટ્રિક્સ હોય

⚡ Quick Revision

  • સંબંધ R ⊆ A × B
  • પ્રતિબિંબી: (a,a) ∈ R ∀ a ∈ A
  • સમમિત: (a,b) ∈ R ⇒ (b,a) ∈ R
  • પારગમ્ય: (a,b) ∈ R અને (b,c) ∈ R ⇒ (a,c) ∈ R
  • તુલ્યતા સંબંધ = પ્રતિબિંબી + સમમિત + પારગમ્ય
  • ભાગલ: સેટના ઉપસેટ્સનો સમૂહ જ્યાં દરેક અવયવ એક જ ભાગલમાં હોય
  • ફંક્શન એ સંબંધનો ખાસ કિસ્સો છે જ્યાં દરેક ઇનપુટ માટે એક જ આઉટપુટ
  • સંબંધનું સંયોજન R∘S = {(a,c) | ∃ b, (a,b) ∈ R અને (b,c) ∈ S}
  • મેટ્રિક્સ પદ્ધતિમાં 0 અને 1 નો ઉપયોગ થાય
  • વર્ટિકલ લાઇન ટેસ્ટ ફંક્શન માટે વાપરાય
🎯 Exam Tip: તુલ્યતા સંબંધ અને ભાગલના પ્રશ્નોમાં, હંમેશા પ્રથમ ચકાસો કે સંબંધ પ્રતિબિંબી, સમમિત, અને પારગમ્ય છે કે નહીં. જો હા, તો પછી ભાગલ શોધવા માટે તુલ્યતા વર્ગો બનાવો.
