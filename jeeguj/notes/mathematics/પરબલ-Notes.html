Pro Notes

પરબોલા

📖 પરબોલા (Parabola)

પરિભાષા અને મૂળભૂત સ્વરૂપ

પરબોલા એ બિંદુના બહુવિધ લોકસ (locus) છે જે એક નિશ્ચિત બિંદુ (ફોકસ) અને એક નિશ્ચિત રેખા (ડાયરેક્ટ્રિક્સ)થી સમાન અંતરે રહે છે. તે શંકુવર્તુળનું ખંડ (conic section) છે જે શંકુને સમાંતર કાપવાથી મળે છે.

  • પરબોલાનું સમીકરણ: y² = 4ax (મૂળબિંદુ પર શિરોબિંદુ અને x-અક્ષ પર અક્ષ)
  • ફોકસ (a,0) અને ડાયરેક્ટ્રિક્સ x = -a
  • શિરોબિંદુ (0,0) એ પરબોલાનું નીચેનું બિંદુ છે
  • લંબાઈ of લેટસ રેક્ટમ = 4a
🧠 Trick: ફોકસ ડાયરેક્ટ્રિક્સથી દૂર, પરબોલા બનાવે સુર

પરબોલાનાં પ્રકાર

પરબોલા ચાર પ્રકારના હોય છે: ઉદ્ગમ બિંદુ પર શિરોબિંદુ અને અક્ષની દિશા અનુસાર. y²=4ax (જમણી તરફ), y²=-4ax (ડાબી તરફ), x²=4ay (ઉપર તરફ), x²=-4ay (નીચે તરફ).

  • y² = 4ax → જમણી તરફ ખુલતો પરબોલા
  • y² = -4ax → ડાબી તરફ ખુલતો પરબોલા
  • x² = 4ay → ઉપર તરફ ખુલતો પરબોલા
  • x² = -4ay → નીચે તરફ ખુલતો પરબોલા
🧠 Trick: y² → x-અક્ષ, x² → y-અક્ષ, + → ખુલે, - → બંધ

પરબોલાનાં મહત્વના ગુણધર્મો

પરબોલાનો આકાર તેના ફોકસ અને ડાયરેક્ટ્રિક્સ પર આધાર રાખે છે. લેટસ રેક્ટમ એ ફોકસમાંથી પસાર થતી અને ડાયરેક્ટ્રિક્સને લંબ રેખા છે. પરબોલાનો ઉત્કલન બિંદુ (vertex) એ તેનું નીચેનું અથવા ઉચ્ચતમ બિંદુ છે.

  • લેટસ રેક્ટમની લંબાઈ = 4a
  • ફોકલ દૂરી (focal length) = a
  • પરબોલાનું ઉત્કલન બિંદુ (vertex) એ શિરોબિંદુ છે
  • પરબોલાનો આકાર સમાન રહે છે પરંતુ કદ બદલાય છે

પરબોલાનું સમીકરણ અને રેખાંકન

પરબોલાનું સમીકરણ y²=4ax એ સૌથી સરળ સ્વરૂપ છે. આ સમીકરણમાં a એ ફોકલ દૂરી છે. પરબોલાનું રેખાંકન કરવા માટે, શિરોબિંદુ, ફોકસ, ડાયરેક્ટ્રિક્સ અને લેટસ રેક્ટમની સ્થિતિ નક્કી કરવી જરૂરી છે.

  • y² = 4ax → a > 0 હોવો જોઈએ
  • ફોકસ (a,0), ડાયરેક્ટ્રિક્સ x = -a
  • લેટસ રેક્ટમ x = a પર સ્થિત છે
  • રેખાંકન માટે બિંદુઓ (a,2a), (a,-2a) વાપરો

પરબોલા અને પ્રકાશનાં કિરણો

પરબોલિક અરીસો (parabolic mirror) પ્રકાશનાં કિરણોને એક બિંદુ (ફોકસ) પર કેન્દ્રિત કરે છે. આ ગુણધર્મનો ઉપયોગ સોલર ફર્નેસ, ટેલિસ્કોપ અને હેડલાઇટ્સમાં થાય છે.

  • પરબોલિક અરીસામાં ફોકસ પર આવતા કિરણો પરાવર્તન પામી સમાંતર થાય છે
  • સમાંતર કિરણો પરબોલિક અરીસા પર પડે તો ફોકસ પર કેન્દ્રિત થાય છે
  • આ ગુણધર્મનો ઉપયોગ ઉર્જા એકત્રિત કરવા માટે થાય છે
🧠 Trick: પરબોલા ફોકસ કરે, પ્રકાશ એકત્રિત થાય

પરબોલાનાં ઉપયોગ

પરબોલાનો ઉપયોગ વૈજ્ઞાનિક અને ઇજનેરી ક્ષેત્રમાં થાય છે. સેટેલાઇટ ડિશ, રડાર સિસ્ટમ્સ, અને બ્રિજના આકારમાં પરબોલિક ડિઝાઇન વાપરવામાં આવે છે.

  • સેટેલાઇટ ડિશમાં પરબોલિક અરીસો વાપરવામાં આવે છે
  • રડાર સિસ્ટમ્સમાં પરબોલિક એન્ટેના વાપરવામાં આવે છે
  • બ્રિજ અને બિલ્ડિંગ્સના આકારમાં પરબોલિક ડિઝાઇન વાપરવામાં આવે છે

પરબોલા સંબંધિત મહત્વના સૂત્રો

પરબોલા સંબંધિત કેટલાક મહત્વના સૂત્રો જેમ કે ફોકલ દૂરી, લેટસ રેક્ટમની લંબાઈ, અને પરબોલાનું સમીકરણ યાદ રાખવા જરૂરી છે.

  • ફોકલ દૂરી (f) = a
  • લેટસ રેક્ટમની લંબાઈ = 4a
  • પરબોલાનું સમીકરણ: y² = 4ax
  • ડાયરેક્ટ્રિક્સનું સમીકરણ: x = -a
🧠 Trick: 4a લેટસ, a ફોકલ, y²=4ax પરબોલા

⚡ Quick Revision

  • પરબોલા એ ફોકસ અને ડાયરેક્ટ્રિક્સથી સમાન અંતરે રહેતા બિંદુઓનો લોકસ છે
  • y²=4ax એ મૂળભૂત પરબોલાનું સમીકરણ છે
  • ફોકસ (a,0) અને ડાયરેક્ટ્રિક્સ x=-a
  • લેટસ રેક્ટમની લંબાઈ 4a હોય છે
  • પરબોલિક અરીસો પ્રકાશનાં કિરણોને ફોકસ પર કેન્દ્રિત કરે છે
  • પરબોલા ચાર પ્રકારના હોય છે: જમણી, ડાબી, ઉપર, નીચે તરફ ખુલતા
  • પરબોલાનો ઉપયોગ સેટેલાઇટ ડિશ અને રડારમાં થાય છે
  • શિરોબિંદુ (0,0) એ પરબોલાનું નીચેનું બિંદુ છે
  • ફોકલ દૂરી a હોય છે
  • પરબોલાનું રેખાંકન માટે ફોકસ, ડાયરેક્ટ્રિક્સ અને લેટસ રેક્ટમની સ્થિતિ નક્કી કરો
🎯 Exam Tip: પરબોલાનું સમીકરણ y²=4ax અને તેના ગુણધર્મો યાદ રાખો. પ્રશ્નોમાં ફોકસ, ડાયરેક્ટ્રિક્સ, અને લેટસ રેક્ટમની સ્થિતિ શોધવા માટે આ સૂત્રો વાપરો.
