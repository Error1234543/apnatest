વેક્ટર

📖 વેક્ટર (Vector) - ગણિત અને ભૌતિકવિજ્ઞાન

વેક્ટરની વ્યાખ્યા અને પ્રકાર

વેક્ટર એ પરિમાણ અને દિશા બંને ધરાવતી રાશિ છે. તેને ભૌતિકવિજ્ઞાન અને ગણિતમાં વેગ, બળ, વિસ્થાપન જેવી રાશિઓ વ્યક્ત કરવા વાપરવામાં આવે છે. વેક્ટર બે પ્રકારના હોય છે: સદિશ (Free Vector) અને બદ્ધ સદિશ (Position Vector).

  • વેક્ટર = પરિમાણ + દિશા
  • સદિશ વેક્ટરની દિશા અને પરિમાણ મહત્વપૂર્ણ
  • બદ્ધ સદિશ એ ટર્મિનલ પોઈન્ટથી શરૂ થતો વેક્ટર
  • શૂન્ય વેક્ટરનો પરિમાણ 0 અને દિશા અનિશ્ચિત
🧠 Trick: વેક્ટર = 'પરિમાણ + દિશા' (પદ્ધતિ)

વેક્ટરનું ભૌમિતિક પ્રાતિનિધ્ય

વેક્ટરને દિશા અને પરિમાણ સાથે તીર ચિહ્ન વડે દર્શાવવામાં આવે છે. તીરની લંબાઈ પરિમાણ અને તીરની દિશા વેક્ટરની દિશા બતાવે છે. દા.ત., વિસ્થાપન વેક્ટર A → B એ A બિંદુથી B બિંદુ સુધીનો વેક્ટર છે.

  • વેક્ટરને તીર ચિહ્ન (→) વડે દર્શાવવામાં આવે
  • લંબાઈ = પરિમાણ, તીરની દિશા = વેક્ટરની દિશા
  • બિંદુ Aથી B સુધીનો વેક્ટર AB⃗ અથવા →AB
  • સમતોલ વેક્ટરોનું પરિમાણ સરખું અને દિશા એકસરખી
🧠 Trick: તીર = દિશા + લંબાઈ = પરિમાણ

વેક્ટરનું બીજગણિત (Vector Algebra)

વેક્ટરના સરવણી અને ગુણાકાર માટે નિયમો અલગ હોય છે. સરવણી સદિશ રીતે કરવામાં આવે છે જ્યારે ગુણાકાર સ્કેલર અથવા વેક્ટર રૂપે થાય છે. ડોટ પ્રોડક્ટ (સ્કેલર) અને ક્રોસ પ્રોડક્ટ (વેક્ટર) મહત્વપૂર્ણ છે.

  • સરવણી: ત્રિકોણ નિયમ અથવા સમલંબ નિયમ
  • ડોટ પ્રોડક્ટ: A·B = |A||B|cosθ (સ્કેલર)
  • ક્રોસ પ્રોડક્ટ: A×B = |A||B|sinθ n̂ (વેક્ટર)
  • ક્રોસ પ્રોડક્ટનો પરિમાણ ક્ષેત્રફળ દર્શાવે
🧠 Trick: ડોટ = સ્કેલર, ક્રોસ = વેક્ટર

વેક્ટરના ઘટકો અને એકમ સદિશ

વેક્ટરને કાર્ટેશિયન નિર્દેશાંક પદ્ધતિમાં x, y, z ઘટકોમાં વહેંચી શકાય. એકમ સદિશ (î, ĵ, k̂) એ દિશા દર્શાવતા સદિશ છે જેમનું પરિમાણ 1 હોય છે. વેક્ટર A = A_x î + A_y ĵ + A_z k̂.

  • વેક્ટર = ઘટકોનો સરવણી
  • એકમ સદિશનું પરિમાણ 1
  • A = (A_x, A_y, A_z) = A_x î + A_y ĵ + A_z k̂
  • ઘટકો નિર્દેશાંક અક્ષ પરની પ્રોજેક્શન
🧠 Trick: î, ĵ, k̂ = x, y, z દિશા

વેક્ટરનું પરિમાણ અને દિશા કોણ

વેક્ટર A = A_x î + A_y ĵ + A_z k̂ નું પરિમાણ |A| = √(A_x² + A_y² + A_z²) થાય છે. દિશા કોણ (θ) ત્રણ અક્ષો સાથે બનાવેલા ખૂણાઓ વડે વ્યાખ્યાયિત થાય છે, જેમકે cosα, cosβ, cosγ.

  • |A| = √(A_x² + A_y² + A_z²)
  • દિશા કોણ: cosα = A_x/|A|, cosβ = A_y/|A|, cosγ = A_z/|A|
  • cos²α + cos²β + cos²γ = 1
  • દિશા કોણ 0° થી 180° વચ્ચે
🧠 Trick: પરિમાણ = √(x² + y² + z²)

વેક્ટર અને સ્કેલર રાશિઓ વચ્ચેનો તફાવત

સ્કેલર રાશિ ફક્ત પરિમાણ ધરાવે છે (દા.ત., દળ, તાપમાન) જ્યારે વેક્ટર રાશિ પરિમાણ અને દિશા બંને ધરાવે છે (દા.ત., વેગ, બળ). ભૌતિકવિજ્ઞાનમાં બળ, વેગ, ત્વરણ વેક્ટર છે જ્યારે કામ, ઉર્જા સ્કેલર છે.

  • સ્કેલર = ફક્ત પરિમાણ
  • વેક્ટર = પરિમાણ + દિશા
  • બળ, વેગ, ત્વરણ = વેક્ટર
  • કામ, ઉર્જા, દળ = સ્કેલર
🧠 Trick: સ્કેલર = એક જ મૂલ્ય, વેક્ટર = મૂલ્ય + દિશા

વેક્ટરના અનુપ્રયોગો (Applications)

વેક્ટરનો ઉપયોગ ભૌતિકવિજ્ઞાનમાં ગતિ, બળ, વિદ્યુત ક્ષેત્ર, ચુંબકીય ક્ષેત્ર વગેરેનો અભ્યાસ કરવા થાય છે. ગણિતમાં વેક્ટર કેલ્ક્યુલસ, 3D જ્યોમેટ્રી અને કમ્પ્યુટર ગ્રાફિક્સમાં મહત્વપૂર્ણ ભૂમિકા ભજવે છે.

  • ગતિ વિશ્લેષણમાં વેગ અને ત્વરણ વેક્ટર
  • વિદ્યુત ક્ષેત્ર E⃗ અને ચુંબકીય ક્ષેત્ર B⃗
  • 3D જ્યોમેટ્રીમાં બિંદુઓ અને રેખાઓ વચ્ચેનો ખૂણો
  • કમ્પ્યુટર ગ્રાફિક્સમાં ઓબ્જેક્ટની દિશા અને સ્થાન

⚡ Quick Revision

  • વેક્ટર = પરિમાણ + દિશા
  • સદિશ વેક્ટર અને બદ્ધ સદિશ વચ્ચેનો તફાવત જાણો
  • વેક્ટર સરવણી: ત્રિકોણ નિયમ અથવા સમલંબ નિયમ
  • ડોટ પ્રોડક્ટ (A·B) = સ્કેલર, ક્રોસ પ્રોડક્ટ (A×B) = વેક્ટર
  • વેક્ટરના ઘટકો: A = A_x î + A_y ĵ + A_z k̂
  • પરિમાણ |A| = √(A_x² + A_y² + A_z²)
  • દિશા કોણ: cosα, cosβ, cosγ
  • સ્કેલર vs વેક્ટર: દળ (સ્કેલર), બળ (વેક્ટર)
  • વેક્ટરના અનુપ્રયોગો: ગતિ, વિદ્યુત ક્ષેત્ર, 3D જ્યોમેટ્રી
  • શૂન્ય વેક્ટરનો પરિમાણ 0 અને દિશા અનિશ્ચિત
🎯 Exam Tip: JEE Mainમાં વેક્ટરના પ્રશ્નો મોટાભાગે ઘટકો, પરિમાણ, દિશા કોણ અને પ્રોડક્ટ પર આધારિત હોય છે. ત્રિકોણ નિયમ અને ક્રોસ પ્રોડક્ટના ગુણધર્મો યાદ રાખો.
