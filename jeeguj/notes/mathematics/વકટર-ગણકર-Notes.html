વેક્ટર ગુણાકાર

📖 વેક્ટર ગુણાકાર

સ્કેલર ગુણાકાર (ડોટ પ્રોડક્ટ)

બે વેક્ટરના સ્કેલર ગુણાકારમાં પરિણામ સ્કેલર (અદિશ) રાશિ મળે છે. તે વેક્ટરની લંબાઈ અને તેમની વચ્ચેના ખૂણાના કોસાઇનના ગુણાકારના બરાબર હોય છે. ફોર્મ્યુલા: A·B = |A||B|cosθ, જ્યાં θ એ બંને વેક્ટર વચ્ચેનો ખૂણો છે.

  • A·B = |A||B|cosθ
  • જો θ = 0°, તો A·B = |A||B| (મહત્તમ મૂલ્ય)
  • જો θ = 90°, તો A·B = 0 (વેક્ટર લંબરૂપ)
  • જો θ = 180°, તો A·B = -|A||B| (ન્યૂનતમ મૂલ્ય)
  • સ્કેલર ગુણાકાર ક્રમવિનિમય (A·B = B·A) અને વિતરણી (A·(B+C) = A·B + A·C) ગુણધર્મો ધરાવે છે.
🧠 Trick: ડોટ પ્રોડક્ટ = કોસાઇન થી ગુણો, સ્કેલર મળશે જણો

વેક્ટર ગુણાકાર (ક્રોસ પ્રોડક્ટ)

બે વેક્ટરના વેક્ટર ગુણાકારમાં પરિણામ વેક્ટર રાશિ મળે છે. તે વેક્ટરની લંબાઈ અને તેમની વચ્ચેના ખૂણાના સાઇનના ગુણાકારના બરાબર હોય છે. ફોર્મ્યુલા: |A × B| = |A||B|sinθ, જ્યાં θ એ બંને વેક્ટર વચ્ચેનો ખૂણો છે. પરિણામી વેક્ટર A અને B બંનેને લંબરૂપ હોય છે.

  • |A × B| = |A||B|sinθ
  • પરિણામી વેક્ટરની દિશા જમણા હાથના નિયમ (Right-Hand Rule) દ્વારા નક્કી કરવામાં આવે છે.
  • જો θ = 0° અથવા 180°, તો |A × B| = 0 (વેક્ટર સમરેખ)
  • જો θ = 90°, તો |A × B| = |A||B| (મહત્તમ મૂલ્ય)
  • વેક્ટર ગુણાકાર ક્રમવિનિમય નથી (A × B ≠ B × A), પરંતુ A × B = - (B × A)
🧠 Trick: ક્રોસ પ્રોડક્ટ = સાઇન થી ગુણો, વેક્ટર મળશે અને લંબરૂપ હશે

સ્કેલર અને વેક્ટર ગુણાકાર વચ્ચેનો તફાવત

સ્કેલર ગુણાકાર સ્કેલર રાશિ આપે છે, જ્યારે વેક્ટર ગુણાકાર વેક્ટર રાશિ આપે છે. સ્કેલર ગુણાકાર ક્રમવિનિમય છે, જ્યારે વેક્ટર ગુણાકાર ક્રમવિનિમય નથી. સ્કેલર ગુણાકારમાં ખૂણાનો કોસાઇન વપરાય છે, જ્યારે વેક્ટર ગુણાકારમાં સાઇન વપરાય છે.

  • સ્કેલર ગુણાકાર: પરિણામ સ્કેલર, ક્રમવિનિમય, કોસાઇન
  • વેક્ટર ગુણાકાર: પરિણામ વેક્ટર, ક્રમવિનિમય નથી, સાઇન
  • સ્કેલર ગુણાકારમાં લંબરૂપ વેક્ટર માટે પરિણામ શૂન્ય
  • વેક્ટર ગુણાકારમાં સમરેખ વેક્ટર માટે પરિણામ શૂન્ય
🧠 Trick: ડોટ = સ્કેલર, ક્રોસ = વેક્ટર, કોસ = ડોટ, સાઇન = ક્રોસ

વેક્ટર ગુણાકારના ગુણધર્મો

વેક્ટર ગુણાકારમાં કેટલાક મહત્વપૂર્ણ ગુણધર્મો છે જેમ કે વિતરણી ગુણધર્મ, શૂન્ય વેક્ટર સાથે ગુણાકાર, અને સ્વ-ગુણાકાર. આ ગુણધર્મો સમજવા અને લાગુ કરવા મહત્વપૂર્ણ છે.

  • A × (B + C) = A × B + A × C (વિતરણી ગુણધર્મ)
  • A × A = 0 (સ્વ-ગુણાકાર શૂન્ય)
  • A × 0 = 0 (શૂન્ય વેક્ટર સાથે ગુણાકાર)
  • જો A અને B સમરેખ હોય, તો A × B = 0

વેક્ટર ગુણાકારના ઉપયોગો

વેક્ટર ગુણાકારનો ઉપયોગ ભૌતિકશાસ્ત્રમાં ઘણા વિષયોમાં થાય છે, જેમ કે ચુંબકીય બળ, કોણીય વેગ, અને ટોર્ક. આ ઉપરાંત, તે ઇજનેરિંગ અને ગણિતમાં પણ મહત્વપૂર્ણ છે.

  • ચુંબકીય બળ: F = q(v × B)
  • ટોર્ક: τ = r × F
  • કોણીય વેગ: L = r × p
  • વિદ્યુત ચુંબકીય પ્રેરણામાં પણ ઉપયોગી
🧠 Trick: ફોર્સ = ક્રોસ, ટોર્ક = ક્રોસ, એંગ્યુલર મોમેન્ટમ = ક્રોસ

સ્કેલર અને વેક્ટર ત્રિપરિમાણીય ગુણાકાર

ત્રિપરિમાણીય વેક્ટર માટે સ્કેલર અને વેક્ટર ગુણાકારને કાર્ટેશિયન નિર્દેશાંક પદ્ધતિમાં ગણી શકાય છે. સ્કેલર ગુણાકાર માટે A·B = A_xB_x + A_yB_y + A_zB_z, જ્યારે વેક્ટર ગુણાકાર માટે A × B = (A_yB_z - A_zB_y)î + (A_zB_x - A_xB_z)ĵ + (A_xB_y - A_yB_x)k̂.

  • સ્કેલર ગુણાકાર: A·B = A_xB_x + A_yB_y + A_zB_z
  • વેક્ટર ગુણાકાર: A × B = (A_yB_z - A_zB_y, A_zB_x - A_xB_z, A_xB_y - A_yB_x)
  • ત્રિપરિમાણીય ગુણાકારમાં ડેટર્મિનન્ટ પદ્ધતિ વપરાય છે
  • આ પદ્ધતિ JEE મેઇનમાં મહત્વપૂર્ણ છે
🧠 Trick: ડોટ = સરવાળો, ક્રોસ = ડેટર્મિનન્ટ

⚡ Quick Revision

  • સ્કેલર ગુણાકાર = |A||B|cosθ, પરિણામ સ્કેલર
  • વેક્ટર ગુણાકાર = |A||B|sinθ, પરિણામ વેક્ટર
  • ડોટ પ્રોડક્ટ ક્રમવિનિમય છે, ક્રોસ પ્રોડક્ટ નથી
  • લંબરૂપ વેક્ટર માટે ડોટ પ્રોડક્ટ શૂન્ય
  • સમરેખ વેક્ટર માટે ક્રોસ પ્રોડક્ટ શૂન્ય
  • જમણા હાથનો નિયમ ક્રોસ પ્રોડક્ટની દિશા નક્કી કરે
  • સ્કેલર ગુણાકારમાં કોસાઇન, વેક્ટર ગુણાકારમાં સાઇન
  • ત્રિપરિમાણીય ડોટ = A_xB_x + A_yB_y + A_zB_z
  • ત્રિપરિમાણીય ક્રોસ = ડેટર્મિનન્ટ પદ્ધતિ
  • ચુંબકીય બળ F = q(v × B)
🎯 Exam Tip: JEE Mainમાં વેક્ટર ગુણાકારના પ્રશ્નો મોટાભાગે ત્રિપરિમાણીય હોય છે, તો કાર્ટેશિયન નિર્દેશાંક પદ્ધતિ અને ડેટર્મિનન્ટ પદ્ધતિની પ્રેક્ટિસ કરો.
