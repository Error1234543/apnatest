સંકુલ સંખ્યાઓ

📖 સંકુલ સંખ્યાઓ

પરિચય અને વ્યાખ્યા

સંકુલ સંખ્યાઓ એ વાસ્તવિક સંખ્યાઓનું વિસ્તરણ છે, જેમાં કાલ્પનિક એકમ 'i' (i² = -1) નો સમાવેશ થાય છે. દરેક સંકુલ સંખ્યા z = a + ib સ્વરૂપે લખાય છે, જ્યાં a અને b વાસ્તવિક સંખ્યાઓ છે અને i કાલ્પનિક એકમ છે. આ સંખ્યાઓનો ઉપયોગ ભૌતિકશાસ્ત્ર, ઇજનેરી અને ગણિતમાં વ્યાપક રીતે થાય છે.

  • z = a + ib, જ્યાં a = વાસ્તવિક ભાગ, b = કાલ્પનિક ભાગ
  • i² = -1, i³ = -i, i⁴ = 1
  • વાસ્તવિક સંખ્યાઓ સંકુલ સંખ્યાઓનો ઉપગણ છે (b=0)
🧠 Trick: RICK: Real + Imaginary = Complex (વાસ્તવિક + કાલ્પનિક = સંકુલ)

સંકુલ સંખ્યાનું આલેખન અને મોડ્યુલસ

સંકુલ સંખ્યા z = a + ib ને આર્ગન્ડ સમતલ પર (a,b) બિંદુ તરીકે દર્શાવાય છે. તેનું મોડ્યુલસ |z| = √(a² + b²) છે, જે ઉદ્ગમથી બિંદુનું અંતર દર્શાવે છે. આર્ગ્યુમેન્ટ θ = tan⁻¹(b/a) છે, જે ધન x-અક્ષ સાથેનો ખૂણો છે.

  • |z| = √(a² + b²) (મોડ્યુલસ)
  • arg(z) = θ = tan⁻¹(b/a) (આર્ગ્યુમેન્ટ)
  • z = |z|(cosθ + i sinθ) (ધ્રુવીય સ્વરૂપ)
🧠 Trick: MAC: Modulus-Argument-Complex (મોડ્યુલસ-આર્ગ્યુમેન્ટ-સંકુલ)

સંકરણ અને ગુણધર્મો

સંકુલ સંખ્યા z = a + ib નું સંકરણ (conjugate) z̅ = a - ib છે. સંકરણના મહત્વના ગુણધર્મો: z + z̅ = 2a (વાસ્તવિક), z - z̅ = 2ib (કાલ્પનિક), z·z̅ = |z|². સંકરણનો ઉપયોગ ભાગાકાર અને વાસ્તવિક ભાગ અલગ કરવામાં થાય છે.

  • z̅ = a - ib (સંકરણ)
  • z + z̅ = 2Re(z)
  • z·z̅ = |z|² = a² + b²
  • arg(z̅) = -arg(z)
🧠 Trick: CONJUGATE: Change Imaginary Sign (કાલ્પનિક ચિહ્ન બદલો)

સંકુલ સંખ્યાઓ પર ક્રિયાઓ

સંકુલ સંખ્યાઓ પર સરવાળો, બાદબાકી, ગુણાકાર અને ભાગાકાર વાસ્તવિક સંખ્યાઓની જેમ જ થાય છે, પરંતુ i² = -1 નો ઉપયોગ કરવો પડે. ભાગાકાર માટે, છેદને તેના સંકરણ વડે ગુણીને વાસ્તવિક બનાવાય છે. ધ્રુવીય સ્વરૂપમાં ગુણાકાર: |z₁z₂| = |z₁||z₂|, arg(z₁z₂) = arg(z₁) + arg(z₂).

  • (a+ib) ± (c+id) = (a±c) + i(b±d)
  • (a+ib)(c+id) = (ac-bd) + i(ad+bc)
  • z₁/z₂ = (z₁·z̅₂)/|z₂|²
  • ધ્રુવીય ગુણાકાર: મોડ્યુલસ ગુણાય, આર્ગ્યુમેન્ટ ઉમેરાય
🧠 Trick: DIVIDE: Denominator's Imaginary Vanishes In Division Everytime (ભાગાકારમાં છેદનો કાલ્પનિક ભાગ દૂર થાય)

ડી મોઇવરનો પ્રમેય

ડી મોઇવરનો પ્રમેય સંકુલ સંખ્યાઓના ધ્રુવીય સ્વરૂપ માટે છે: [r(cosθ + i sinθ)]ⁿ = rⁿ(cos nθ + i sin nθ). આ પ્રમેયનો ઉપયોગ સંકુલ સંખ્યાઓના ઘાત અને મૂળ શોધવામાં થાય છે. n-મૂળ માટે: z^(1/n) = r^(1/n)[cos((θ+2kπ)/n) + i sin((θ+2kπ)/n)], k=0,1,...,n-1.

  • [r(cosθ + i sinθ)]ⁿ = rⁿ(cos nθ + i sin nθ)
  • n-મૂળ માટે n જુદા જુદા ઉકેલો
  • મૂળ આર્ગન્ડ સમતલ પર નિયમિત બહુકોણ બનાવે છે
🧠 Trick: De Moivre: Power = Polar Power (ઘાત = ધ્રુવીય ઘાત)

સંકુલ સમીકરણો અને વાસ્તવિક બહુપદી

વાસ્તવિક ગુણાંકવાળી બહુપદીના સંકુલ મૂળ જોડીમાં આવે છે (સંકરણ જોડી). જો z = a + ib મૂળ હોય, તો z̅ = a - ib પણ મૂળ છે. આ ગુણધર્મનો ઉપયોગ સમીકરણ ઉકેલવામાં અને બહુપદીના અવયવીકરણમાં થાય છે. દા.ત., x² + 1 = 0 ના મૂળ i અને -i છે.

  • વાસ્તવિક ગુણાંકવાળી બહુપદીના સંકુલ મૂળ સંકરણ જોડીમાં
  • અયુગ્મ ઘાતની બહુપદીને ઓછામાં ઓછું એક વાસ્તવિક મૂળ હોય
  • x² + a² = (x + ai)(x - ai)
🧠 Trick: COMPLEX ROOTS: Come In Pairs (સંકુલ મૂળ જોડીમાં આવે)

⚡ Quick Revision

  • સંકુલ સંખ્યા z = a + ib, જ્યાં i² = -1
  • મોડ્યુલસ |z| = √(a² + b²), આર્ગ્યુમેન્ટ θ = tan⁻¹(b/a)
  • સંકરણ z̅ = a - ib, z·z̅ = |z|²
  • ધ્રુવીય સ્વરૂપ: z = r(cosθ + i sinθ)
  • સરવાળો/બાદબાકી: વાસ્તવિક અને કાલ્પનિક ભાગ અલગ અલગ
  • ગુણાકાર: (a+ib)(c+id) = (ac-bd) + i(ad+bc)
  • ભાગાકાર: છેદને સંકરણ વડે ગુણી વાસ્તવિક બનાવો
  • ડી મોઇવર: [r(cosθ + i sinθ)]ⁿ = rⁿ(cos nθ + i sin nθ)
  • n-મૂળ માટે n ઉકેલો, આર્ગન્ડ સમતલ પર નિયમિત બહુકોણ
  • વાસ્તવિક બહુપદીના સંકુલ મૂળ સંકરણ જોડીમાં
🎯 Exam Tip: સંકુલ સંખ્યાના પ્રશ્નોમાં ધ્રુવીય સ્વરૂપનો ઉપયોગ કરવાથી ગણતરી સરળ બને છે, ખાસ કરીને ઘાત અને મૂળ સંબંધિત પ્રશ્નોમાં. હંમેશા મોડ્યુલસ અને આર્ગ્યુમેન્ટની ગણતરી કરીને ચકાસણી કરો, કારણ કે આર્ગ્યુમેન્ટ માટે યોગ્ય ચરણ (quadrant) પસંદ કરવું મહત્વપૂર્ણ છે.
