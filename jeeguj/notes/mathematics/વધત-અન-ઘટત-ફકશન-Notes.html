વધતા અને ઘટતા ફંક્શન

📖 વધતા અને ઘટતા ફંક્શન

પરિભાષા અને મૂળભૂત સંકલ્પના

ફંક્શન f(x)ને વર્ગીકૃત કરવા માટે તેના વર્ધન અથવા ઘટનના ગુણધર્મોનો અભ્યાસ કરવામાં આવે છે. જો x₁ < x₂ હોત તો f(x₁) < f(x₂) થાય તો f(x)ને વર્ધમાન કહેવાય, જ્યારે f(x₁) > f(x₂) થાય તો ઘટતું કહેવાય.

  • વર્ધમાન ફંક્શન: x વધે ત્યારે f(x) પણ વધે.
  • ઘટતું ફંક્શન: x વધે ત્યારે f(x) ઘટે.
  • સ્થિર ફંક્શન: f(x) અચળ રહે.
  • વર્ધમાન/ઘટતાં ફંક્શન માટે f'(x) > 0 અથવા f'(x) < 0 હોવું જરૂરી છે.
🧠 Trick: વધે x, વધે f(x) → વર્ધમાન; ઘટે f(x) → ઘટતું

વિષયક કસોટી: પ્રથમ વક્રતા કસોટી

ફંક્શનના વર્ધન અથવા ઘટનની ચકાસણી માટે પ્રથમ વક્રતા કસોટી વાપરવામાં આવે છે. જો f'(x) > 0 તો ફંક્શન વર્ધમાન અને f'(x) < 0 તો ઘટતું ગણાય.

  • f'(x) > 0 → સ્થાનિક વર્ધમાન.
  • f'(x) < 0 → સ્થાનિક ઘટતું.
  • f'(x) = 0 → ક્રાંતિ બિંદુ (Critical Point).
  • પરિવર્તનશીલ ચિહ્નો વર્ધન/ઘટન દર્શાવે છે.
🧠 Trick: પોઝિટિવ ડેરિવેટિવ → વર્ધે, નેગેટિવ → ઘટે

અંતરાળ પર વર્ધન અને ઘટન

ફંક્શનના વર્ધન અથવા ઘટનનું વિશ્લેષણ કરવા માટે અંતરાળોની ચકાસણી કરવામાં આવે છે. જો f'(x) > 0 અંતરાળ [a, b] પર તો f(x) તે અંતરાળ પર વર્ધમાન ગણાય.

  • ફંક્શનના ડોમેનને અંતરાળોમાં વહેંચી શકાય.
  • હર એક અંતરાળ પર f'(x)નું ચિહ્ન નક્કી કરો.
  • f'(x) > 0 → વર્ધમાન અંતરાળ.
  • f'(x) < 0 → ઘટતું અંતરાળ.

દ્વિતીય વક્રતા કસોટી અને ઉચ્ચતમ/નિમ્નતમ મૂલ્ય

દ્વિતીય વક્રતા કસોટી વાપરીને સ્થાનિક ઉચ્ચતમ અને નિમ્નતમ મૂલ્ય શોધી શકાય. જો f''(x) > 0 તો સ્થાનિક નિમ્નતમ અને f''(x) < 0 તો સ્થાનિક ઉચ્ચતમ.

  • f'(x) = 0 અને f''(x) > 0 → સ્થાનિક નિમ્નતમ.
  • f'(x) = 0 અને f''(x) < 0 → સ્થાનિક ઉચ્ચતમ.
  • f''(x) = 0 → કસોટી નિષ્ફળ, પ્રથમ વક્રતા કસોટી વાપરો.
  • ઉચ્ચતમ/નિમ્નતમ મૂલ્ય વર્ધન/ઘટન સાથે સંબંધિત છે.
🧠 Trick: પોઝિટિવ દ્વિતીય ડેરિવેટિવ → નીચે (નિમ્નતમ), નેગેટિવ → ઉપર (ઉચ્ચતમ)

વ્યવહારિક ઉદાહરણો અને એપ્લિકેશન

વર્ધમાન અને ઘટતા ફંક્શનનો ઉપયોગ અર્થશાસ્ત્ર, ભૌતિકશાસ્ત્ર અને ઇજનેરીમાં થાય છે. ઉદાહરણ તરીકે, માગ વક્ર (Demand Curve) ઘટતું ફંક્શન છે જ્યારે પૂરવઠા વક્ર (Supply Curve) વર્ધમાન છે.

  • માગ વક્ર: ઘટતું ફંક્શન (કિંમત વધે ત્યારે માગ ઘટે).
  • પૂરવઠા વક્ર: વર્ધમાન ફંક્શન (કિંમત વધે ત્યારે પૂરવઠો વધે).
  • વેગ અને પ્રવેગના ફંક્શનમાં વર્ધન/ઘટનનો ઉપયોગ.
  • ઓપ્ટિમાઇઝેશન સમસ્યાઓમાં ઉપયોગી.
🧠 Trick: માગ ઘટે, પૂરવઠો વધે

ગ્રાફિકલ વિશ્લેષણ

ફંક્શનના ગ્રાફ દ્વારા વર્ધન અને ઘટનની સરળતાથી ઓળખી શકાય. વર્ધમાન ફંક્શનના ગ્રાફ ડાબેથી જમણે ઉપર તરફ જાય છે જ્યારે ઘટતા ફંક્શનના ગ્રાફ ડાબેથી જમણે નીચે તરફ જાય છે.

  • વર્ધમાન ફંક્શન: ગ્રાફ ઉપર તરફ ઢાળવાળો.
  • ઘટતું ફંક્શન: ગ્રાફ નીચે તરફ ઢાળવાળો.
  • સ્થિર ફંક્શન: ગ્રાફ સમતલ (Horizontal) રેખા.
  • ક્રાંતિ બિંદુ: ગ્રાફનો ઢાળ શૂન્ય થાય છે.
🧠 Trick: ઉપર ઢાળ → વર્ધે, નીચે ઢાળ → ઘટે

સમગ્ર અને અંશતઃ વર્ધન/ઘટન

ફંક્શન સંપૂર્ણ ડોમેન પર વર્ધમાન અથવા ઘટતું હોઈ શકે છે અથવા કોઈ અંશતઃ અંતરાળ પર. ઉદાહરણ તરીકે, f(x) = x³ સંપૂર્ણ ડોમેન પર વર્ધમાન છે જ્યારે f(x) = x² અંશતઃ વર્ધમાન અને ઘટતું છે.

  • સમગ્ર વર્ધમાન: સંપૂર્ણ ડોમેન પર f'(x) > 0.
  • સમગ્ર ઘટતું: સંપૂર્ણ ડોમેન પર f'(x) < 0.
  • અંશતઃ વર્ધમાન/ઘટતું: કેટલાક અંતરાળ પર જ વર્ધન/ઘટન.
  • f(x) = e^x સમગ્ર વર્ધમાન છે.

⚡ Quick Revision

  • વર્ધમાન ફંક્શન: x વધે ત્યારે f(x) વધે.
  • ઘટતું ફંક્શન: x વધે ત્યારે f(x) ઘટે.
  • f'(x) > 0 → વર્ધમાન, f'(x) < 0 → ઘટતું.
  • f''(x) > 0 → સ્થાનિક નિમ્નતમ, f''(x) < 0 → સ્થાનિક ઉચ્ચતમ.
  • માગ વક્ર ઘટતું, પૂરવઠા વક્ર વર્ધમાન.
  • ગ્રાફ ઉપર ઢાળ → વર્ધે, નીચે ઢાળ → ઘટે.
  • સમગ્ર વર્ધમાન: સંપૂર્ણ ડોમેન પર f'(x) > 0.
  • ક્રાંતિ બિંદુ: f'(x) = 0.
  • દ્વિતીય વક્રતા કસોટી: ઉચ્ચતમ/નિમ્નતમ શોધવા.
  • વ્યવહારિક ઉપયોગ: અર્થશાસ્ત્ર, ભૌતિકશાસ્ત્ર, ઇજનેરી.
🎯 Exam Tip: જEE મેઈનમાં વર્ધન/ઘટનના પ્રશ્નો માટે હંમેશા f'(x)નું ચિહ્ન ચકાસો અને ગ્રાફ દોરવા માટે ડેરિવેટિવના ચિહ્નોનો ઉપયોગ કરો.
