અવકલનના નિયમો

📖 અવકલનના નિયમો (Differentiation Rules)

અવકલનનો પાયાનો નિયમ (Basic Differentiation Rule)

અવકલન એ ફંક્શનના ફેરફારનો દર શોધવાની પ્રક્રિયા છે. જો y = f(x) હોય, તો તેનું અવકલન dy/dx અથવા f'(x) વડે દર્શાવાય છે. પાયાનો નિયમ એ છે કે xⁿ નું અવકલન nxⁿ⁻¹ થાય છે, જેને પાવર રૂલ કહે છે. આ નિયમ બહુપદી ફંક્શન (polynomial functions) માટે મૂળભૂત છે.

  • xⁿ → nxⁿ⁻¹ (પાવર રૂલ)
  • સ્થિરાંક (constant)નું અવકલન શૂન્ય થાય
  • 1/x → -1/x², √x → 1/(2√x)
🧠 Trick: પાવર નીચે લાવો, પાવરમાંથી એક બાદ કરો (Power niche lavo, power thi ek bad karo)

સરવાળા અને તફાવતનો નિયમ (Sum & Difference Rule)

જો બે ફંક્શનનો સરવાળો અથવા તફાવત હોય, તો તેમનું અવકલન અલગ-અલગ કરીને પછી સરવાળો/તફાવત કરાય છે. ગાણિતિક રીતે: d/dx [f(x) ± g(x)] = f'(x) ± g'(x). આ નિયમ બહુપદી ફંક્શનના અવકલનમાં સૌથી વધુ ઉપયોગી છે.

  • d/dx [f + g] = f' + g'
  • d/dx [f - g] = f' - g'
  • સરવાળા/તફાવતના અવકલનમાં ક્રમ મહત્વનો નથી
🧠 Trick: સરવાળો-તફાવતનું અવકલન, અલગ-અલગ કરીને પછી જોડો (Sum-difference nu differentiation, alag-alag kari ne pachi jodo)

ગુણાકારનો નિયમ (Product Rule)

જ્યારે બે ફંક્શનનો ગુણાકાર હોય, ત્યારે તેમનું અવકલન ગુણાકારના નિયમ વડે થાય: d/dx [f(x)g(x)] = f'(x)g(x) + f(x)g'(x). આ નિયમ ત્રિકોણમિતીય અને લઘુગણકીય ફંક્શનના ગુણાકાર માટે આવશ્યક છે.

  • uv → u'v + uv'
  • ત્રણ ફંક્શનના ગુણાકાર માટે: (uvw)' = u'vw + uv'w + uvw'
  • ઉદાહરણ: x sin x → sin x + x cos x
🧠 Trick: પહેલાનું અવકલન × બીજું + પહેલું × બીજાનું અવકલન (Phelanu differentiation × biju + phelu × bijanu differentiation)

ભાગાકારનો નિયમ (Quotient Rule)

જ્યારે બે ફંક્શનનો ભાગાકાર હોય, ત્યારે અવકલન ભાગાકારના નિયમ વડે થાય: d/dx [f(x)/g(x)] = [f'(x)g(x) - f(x)g'(x)] / [g(x)]². આ નિયમ ત્રિકોણમિતીય અને બહુપદી ફંક્શનના ભાગાકાર માટે ઉપયોગી છે.

  • u/v → (u'v - uv')/v²
  • વિભાજક (denominator)નું વર્ગ લેવાનું ભૂલશો નહીં
  • ઉદાહરણ: tan x → sec²x (sin x/cos x પર ભાગાકાર નિયમ લાગુ કરીને)
🧠 Trick: ઉપર અવકલન × નીચે - ઉપર × નીચે અવકલન, પછી નીચેનો વર્ગ (Upar differentiation × niche - upar × niche nu differentiation, pachi niche no varg)

શૃંખલા નિયમ (Chain Rule)

જ્યારે ફંક્શનનું ફંક્શન હોય (composite function), ત્યારે અવકલન શૃંખલા નિયમ વડે થાય: d/dx [f(g(x))] = f'(g(x)) × g'(x). આ નિયમ ત્રિકોણમિતીય, લઘુગણકીય અને ઘાતાંકીય ફંક્શનના સંયોજન માટે આવશ્યક છે.

  • f(g(x)) → f'(g(x)) × g'(x)
  • બહુવિધ સંયોજન માટે: f(g(h(x))) → f'(g(h(x))) × g'(h(x)) × h'(x)
  • ઉદાહરણ: sin(2x) → 2 cos(2x)
🧠 Trick: બહારનું અવકલન × અંદરનું અવકલન (Bahar nu differentiation × andar nu differentiation)

ઘાતાંકીય અને લઘુગણકીય ફંક્શનનું અવકલન (Exponential & Logarithmic Differentiation)

eˣ નું અવકલન eˣ જ રહે છે, જ્યારે aˣ નું અવકલન aˣ ln a થાય છે. ln x નું અવકલન 1/x થાય છે. લઘુગણકીય અવકલનનો ઉપયોગ જટિલ ગુણાકાર/ભાગાકારવાળા ફંક્શન માટે થાય છે, જ્યાં બંને બાજુ ln લઈને અવકલન કરાય છે.

  • eˣ → eˣ
  • aˣ → aˣ ln a
  • ln x → 1/x
  • logₐx → 1/(x ln a)
🧠 Trick: e ની પોતાની જાતનું અવકલન, લઘુગણકનું અવકલન 1/x (e ni potani jat nu differentiation, logarithmic nu differentiation 1/x)

ત્રિકોણમિતીય ફંક્શનનું અવકલન (Trigonometric Differentiation)

મૂળભૂત ત્રિકોણમિતીય ફંક્શનના અવકલન યાદ રાખવા જરૂરી છે: sin x → cos x, cos x → -sin x, tan x → sec²x. વ્યસ્ત ત્રિકોણમિતીય ફંક્શનના અવકલન પણ મહત્વપૂર્ણ છે, જેમ કે sin⁻¹x → 1/√(1-x²). આ નિયમો ભૌતિકશાસ્ત્ર અને ભૂમિતિમાં વ્યાપક ઉપયોગ ધરાવે છે.

  • sin x → cos x
  • cos x → -sin x
  • tan x → sec²x
  • cot x → -cosec²x
  • sec x → sec x tan x
  • cosec x → -cosec x cot x
🧠 Trick: સાઇન કોસાઈન, કોસાઈન માઇનસ સાઇન (Sine cosine, cosine minus sine)

⚡ Quick Revision

  • પાવર રૂલ: xⁿ → nxⁿ⁻¹
  • સરવાળો/તફાવત: (f ± g)' = f' ± g'
  • ગુણાકાર: (uv)' = u'v + uv'
  • ભાગાકાર: (u/v)' = (u'v - uv')/v²
  • શૃંખલા નિયમ: f(g(x))' = f'(g(x)) × g'(x)
  • eˣ → eˣ, aˣ → aˣ ln a
  • ln x → 1/x, logₐx → 1/(x ln a)
  • sin x → cos x, cos x → -sin x, tan x → sec²x
  • સ્થિરાંકનું અવકલન શૂન્ય
  • વ્યસ્ત ત્રિકોણમિતીય ફંક્શનના અવકલન યાદ રાખો
🎯 Exam Tip: JEE Main માં અવકલનના પ્રશ્નોમાં સૌથી વધુ ભૂલો ગુણાકાર/ભાગાકાર નિયમ અને શૃંખલા નિયમમાં થાય છે. પ્રશ્નને ધ્યાનથી વાંચો અને કયો નિયમ લાગુ પડે છે તે ઓળખો. પ્રથમ પ્રયાસમાં જવાબ લખતા પહેલા બે વાર ગણતરી તપાસો, ખાસ કરીને ચિહ્નો (signs) માટે.
