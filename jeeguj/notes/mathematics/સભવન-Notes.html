સંભાવના

📖 સંભાવના (Probability)

સંભાવનાનું મૂળભૂત પરિભાષા

સંભાવના એટલે કોઈ ઘટનાની શક્યતાનું અંકગણિતીય મૂલ્ય, જે 0 થી 1 વચ્ચે હોય છે. જ્યાં 0 = અશક્ય ઘટના, 1 = નિશ્ચિત ઘટના. નમૂના અવકાશ (Sample Space) એ બધી શક્ય પરિણામોનો સંગ્રહ હોય છે.

  • સંભાવના P(E) = (અનુકૂળ પરિણામોની સંખ્યા) / (કુલ શક્ય પરિણામોની સંખ્યા)
  • 0 ≤ P(E) ≤ 1
  • નમૂના અવકાશ (S) એ બધા શક્ય પરિણામોનો સેટ છે.
  • અશક્ય ઘટનાની P(E) = 0, નિશ્ચિત ઘટનાની P(E) = 1
🧠 Trick: સંભાવના = અનુકૂળ / કુલ (સાચો સૂત્ર)

સંભાવનાના પ્રકાર

સંભાવના ત્રણ પ્રકારની હોય છે: (1) ક્લાસિકલ (Classical) - સમાન શક્યતાવાળા પરિણામો, (2) સાંખ્યિકી (Statistical) - આંકડાકીય ડેટા પર આધારિત, (3) ભૌગોલિક (Geometric) - પુનરાવર્તિત સ્વતંત્ર પ્રયોગો.

  • ક્લાસિકલ સંભાવના: સિક્કા અથવા પાસાની ઉદાહરણો
  • સાંખ્યિકી સંભાવના: ડેટા આધારિત, જેમકે વરસાદની શક્યતા
  • ભૌગોલિક સંભાવના: પ્રથમ સફળતાની રાહ જોવી

ઘટનાઓની સંભાવના

દ્વિ-ઘટના સિદ્ધાંતો: (A ∪ B) = P(A) + P(B) - P(A ∩ B). પૂરક ઘટનાની સંભાવના P(A') = 1 - P(A). સ્વતંત્ર ઘટનાઓ માટે P(A ∩ B) = P(A) * P(B).

  • P(A ∪ B) = P(A) + P(B) - P(A ∩ B) (યોગ સૂત્ર)
  • P(A') = 1 - P(A) (પૂરક ઘટના)
  • P(A ∩ B) = P(A) * P(B) (સ્વતંત્ર ઘટનાઓ)
  • P(A | B) = P(A ∩ B) / P(B) (શરતી સંભાવના)
🧠 Trick: યોગ = A + B - બંને, પૂરક = 1 - A

શરતી સંભાવના અને બેયઝ થિયરમ

શરતી સંભાવના P(A|B) એ ઘટના Aની સંભાવના જ્યારે B ઘટી ચૂકી હોય. બેયઝ થિયરમ P(A|B) = [P(B|A) * P(A)] / P(B) એ ઉપયોગી છે જ્યારે પૂર્વ સંભાવનાઓ જાણીતી હોય.

  • P(A|B) = P(A ∩ B) / P(B)
  • બેયઝ થિયરમ: P(A|B) = [P(B|A) * P(A)] / P(B)
  • બેયઝ થિયરમનો ઉપયોગ મેડિકલ ટેસ્ટિંગમાં થાય છે.
  • P(B) = P(B|A)P(A) + P(B|A')P(A') (કુલ સંભાવના સિદ્ધાંત)
🧠 Trick: બેયઝ = (B|A * A) / B

સ્વતંત્ર ઘટનાઓ

દ્વિ ઘટનાઓ A અને B સ્વતંત્ર હોય ત્યારે P(A ∩ B) = P(A) * P(B). એટલે કે એક ઘટનાનું પરિણામ બીજી ઘટના પર અસર કરતું નથી.

  • P(A ∩ B) = P(A) * P(B) (સ્વતંત્ર ઘટનાઓ)
  • સ્વતંત્ર ઘટનાઓ માટે P(A|B) = P(A)
  • પાસાના બે ફેંકણી સ્વતંત્ર ઘટનાઓ છે.
  • સિક્કાના બે ફેંકણી સ્વતંત્ર ઘટનાઓ છે.
🧠 Trick: સ્વતંત્ર = ગુણાકાર

પુનરાવર્તિત સ્વતંત્ર પ્રયોગો (બર્નૌલી પ્રયોગો)

n વખત પુનરાવર્તિત સ્વતંત્ર પ્રયોગોમાં k વખત સફળતા મેળવવાની સંભાવના C(n,k) * p^k * (1-p)^(n-k) હોય છે, જ્યાં p = એક પ્રયોગમાં સફળતાની સંભાવના.

  • બાયનોમિયલ સંભાવના: P(k) = C(n,k) * p^k * (1-p)^(n-k)
  • C(n,k) = n! / (k! (n-k)!)
  • સરેરાશ (Mean) = n * p
  • વેરિયન્સ (Variance) = n * p * (1-p)
🧠 Trick: બાયનોમિયલ = C * p^k * q^(n-k)

સંભાવના વિતરણ

સંભાવના વિતરણ એ રેન્ડમ વેરિયેબલના મૂલ્યો અને તેમની સંભાવનાઓનો સંગ્રહ હોય છે. બાયનોમિયલ, પોઇસન, અને નોર્મલ વિતરણ JEEમાં મહત્વના છે.

  • બાયનોમિયલ વિતરણ: n અને p પર આધારિત
  • પોઇસન વિતરણ: λ (લેમ્બડા) પર આધારિત, દુર્લભ ઘટનાઓ માટે
  • નોર્મલ વિતરણ: સરેરાશ μ અને સ્ટાન્ડર્ડ ડેવિયેશન σ પર આધારિત
  • નોર્મલ વિતરણ સિમેટ્રિક અને બેલ-શેપ્ડ હોય છે.

⚡ Quick Revision

  • સંભાવના = અનુકૂળ / કુલ (0 થી 1)
  • P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
  • P(A') = 1 - P(A) (પૂરક ઘટના)
  • સ્વતંત્ર ઘટનાઓ: P(A ∩ B) = P(A) * P(B)
  • શરતી સંભાવના: P(A|B) = P(A ∩ B) / P(B)
  • બેયઝ થિયરમ: P(A|B) = [P(B|A) * P(A)] / P(B)
  • બાયનોમિયલ સંભાવના: C(n,k) * p^k * (1-p)^(n-k)
  • બાયનોમિયલ સરેરાશ = n * p, વેરિયન્સ = n * p * (1-p)
  • નોર્મલ વિતરણ: μ અને σ પર આધારિત
  • પોઇસન વિતરણ: λ પર આધારિત, દુર્લભ ઘટનાઓ માટે
🎯 Exam Tip: સંભાવનાના પ્રશ્નોમાં હંમેશા નમૂના અવકાશ (Sample Space) સ્પષ્ટ કરો અને કોઈપણ ઘટનાની સંભાવના કાઢતાં પહેલાં સ્વતંત્રતા અથવા શરતી સંભાવનાનો ઉપયોગ કરવાનો છે કે કેમ તે ચકાસો.
