આર્ગાન્ડ સમતલ

📖 આર્ગાન્ડ સમતલ

પરિચય અને વ્યાખ્યા

આર્ગાન્ડ સમતલ એ જટિલ સંખ્યાઓને દર્શાવવા માટેનું દ્વિ-પરિમાણીય કાર્ટેશિયન સમતલ છે. તેમાં X-અક્ષને વાસ્તવિક અક્ષ (Real Axis) અને Y-અક્ષને કાલ્પનિક અક્ષ (Imaginary Axis) કહે છે. દરેક જટિલ સંખ્યા z = a + ib ને આ સમતલ પર બિંદુ (a, b) તરીકે દર્શાવાય છે.

  • X-અક્ષ: વાસ્તવિક ભાગ (a)
  • Y-અક્ષ: કાલ્પનિક ભાગ (b)
  • z = a + ib → બિંદુ (a, b)
  • મૂળબિંદુ (0,0) → 0 + 0i = 0
🧠 Trick: RIYA: Real Axis X, Imaginary Axis Y

જટિલ સંખ્યાનું મોડ્યુલસ અને આર્ગ્યુમેન્ટ

આર્ગાન્ડ સમતલ પર જટિલ સંખ્યા z = a + ib નું મોડ્યુલસ |z| = √(a² + b²) છે, જે મૂળબિંદુથી તે બિંદુનું અંતર દર્શાવે છે. આર્ગ્યુમેન્ટ (arg z) એ વાસ્તવિક અક્ષ સાથે બનતો ખૂણો θ = tan⁻¹(b/a) છે, જે ધન X-અક્ષથી ઘડિયાળની વિરુદ્ધ દિશામાં માપવામાં આવે છે.

  • |z| = √(a² + b²) → અંતર
  • arg z = θ = tan⁻¹(b/a) → ખૂણો
  • મુખ્ય આર્ગ્યુમેન્ટ: -π < θ ≤ π
  • z = |z|(cosθ + i sinθ) → ધ્રુવીય સ્વરૂપ
🧠 Trick: MAT: Modulus = અંતર, Argument = ખૂણો, Tan⁻¹(b/a)

ધ્રુવીય સ્વરૂપ અને ઓયલરનું સૂત્ર

જટિલ સંખ્યાનું ધ્રુવીય સ્વરૂપ z = r(cosθ + i sinθ) છે, જ્યાં r = |z| અને θ = arg z. ઓયલરના સૂત્ર અનુસાર, e^(iθ) = cosθ + i sinθ, તેથી z = re^(iθ) લખી શકાય. આ સ્વરૂપ ગુણાકાર અને ભાગાકાર માટે અત્યંત ઉપયોગી છે.

  • z = r(cosθ + i sinθ) → ધ્રુવીય સ્વરૂપ
  • e^(iθ) = cosθ + i sinθ → ઓયલરનું સૂત્ર
  • z = re^(iθ) → સંક્ષિપ્ત સ્વરૂપ
  • ગુણાકાર: z₁z₂ = r₁r₂ e^(i(θ₁+θ₂))
🧠 Trick: RCT: r, cosθ, sinθ → ધ્રુવીય સ્વરૂપ

આર્ગાન્ડ સમતલ પર ક્રિયાઓ

જટિલ સંખ્યાઓનું સરવાળો અને બાદબાકી આર્ગાન્ડ સમતલ પર સદિશોના સરવાળા-બાદબાકી જેવું છે. ગુણાકાર માટે, મોડ્યુલસનો ગુણાકાર અને આર્ગ્યુમેન્ટનો સરવાળો થાય છે. ભાગાકાર માટે, મોડ્યુલસનો ભાગાકાર અને આર્ગ્યુમેન્ટની બાદબાકી થાય છે.

  • સરવાળો: સમાંતરબાજુ ચતુષ્કોણના નિયમ મુજબ
  • ગુણાકાર: |z₁z₂| = |z₁||z₂|, arg(z₁z₂) = arg z₁ + arg z₂
  • ભાગાકાર: |z₁/z₂| = |z₁|/|z₂|, arg(z₁/z₂) = arg z₁ - arg z₂
  • સંયુગ્મ: z̅ = a - ib → X-અક્ષ પર પ્રતિબિંબ
🧠 Trick: MAS: Multiply Modulus, Add Arguments for product

જટિલ સંખ્યાઓના સમૂહોનું આલેખન

આર્ગાન્ડ સમતલ પર જટિલ સંખ્યાઓના સમૂહોને વિવિધ ભૌમિતિક આકારોમાં દર્શાવી શકાય. ઉદાહરણ તરીકે, |z - z₀| = r એ z₀ કેન્દ્ર અને r ત્રિજ્યાવાળું વર્તુળ દર્શાવે છે. arg(z - z₀) = θ એ z₀ થી નીકળતી કિરણરેખા દર્શાવે છે.

  • |z - z₀| = r → વર્તુળ
  • |z - z₁| = |z - z₂| → લંબદ્વિભાજક
  • arg(z - z₀) = θ → કિરણરેખા
  • Re(z) = a → Y-અક્ષને સમાંતર રેખા
🧠 Trick: CRR: Circle (|z-z₀|=r), Ray (arg), Line (Re/Im)

જટિલ સંખ્યાઓ અને ભૂમિતિ

આર્ગાન્ડ સમતલ પર જટિલ સંખ્યાઓનો ઉપયોગ કરીને ભૂમિતિય પ્રશ્નો ઉકેલી શકાય. ઉદાહરણ તરીકે, ત્રિકોણની ત્રણ શિરોબિંદુઓ z₁, z₂, z₃ હોય તો તેનું કેન્દ્રબિંદુ (z₁ + z₂ + z₃)/3 થાય. બે બિંદુઓ વચ્ચેનું અંતર |z₁ - z₂| થી મળે છે.

  • કેન્દ્રબિંદુ: (z₁ + z₂ + z₃)/3
  • અંતર: |z₁ - z₂|
  • સમરેખ બિંદુઓ: (z₂ - z₁)/(z₃ - z₁) વાસ્તવિક
  • લંબરેખા: arg((z₃ - z₁)/(z₂ - z₁)) = ±π/2
🧠 Trick: CID: Centroid, Intercept, Distance

⚡ Quick Revision

  • આર્ગાન્ડ સમતલ: X-વાસ્તવિક, Y-કાલ્પનિક અક્ષ
  • z = a + ib → બિંદુ (a, b) તરીકે દર્શાવો
  • |z| = √(a² + b²) → મૂળથી અંતર
  • arg z = tan⁻¹(b/a) → ધન X-અક્ષ સાથે ખૂણો
  • ધ્રુવીય સ્વરૂપ: z = r(cosθ + i sinθ) = re^(iθ)
  • ગુણાકાર: મોડ્યુલસનો ગુણાકાર, આર્ગ્યુમેન્ટનો સરવાળો
  • |z - z₀| = r → વર્તુળ, arg(z - z₀) = θ → કિરણરેખા
  • ત્રિકોણનું કેન્દ્રબિંદુ: (z₁ + z₂ + z₃)/3
  • સંયુગ્મ z̅ → X-અક્ષ પર પ્રતિબિંબ
  • સમરેખ બિંદુઓ: (z₂ - z₁)/(z₃ - z₁) વાસ્તવિક સંખ્યા
🎯 Exam Tip: JEE Main માં આર્ગાન્ડ સમતલ પરના પ્રશ્નોમાં મોડ્યુલસ અને આર્ગ્યુમેન્ટના ગુણધર્મોનો ઉપયોગ કરીને ઝડપથી ઉકેલો. ધ્રુવીય સ્વરૂપનો ઉપયોગ કરીને ગુણાકાર/ભાગાકારના પ્રશ્નો ઉકેલો અને ભૂમિતિય આકારોને જટિલ સંખ્યાના સમીકરણ તરીકે ઓળખો.
