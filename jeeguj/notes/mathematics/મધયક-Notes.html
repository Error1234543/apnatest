મધ્યિકા

📖 મધ્યિકા (Median)

મધ્યિકાની વ્યાખ્યા

મધ્યિકા એ ક્રમમાં ગોઠવેલા આંકડાકીય મૂલ્યોની મધ્યમાં આવતી કિંમત છે. જો આંકડાઓની સંખ્યા વિષમ હોય, તો મધ્યિકા મધ્યમાં આવતું મૂલ્ય હોય છે. જો સંખ્યા સમ હોય, તો મધ્યિકા મધ્યના બે મૂલ્યોના સરેરાશથી મેળવવામાં આવે છે.

  • વિષમ સંખ્યામાં મધ્યિકા = (n+1)/2 મો ક્રમ
  • સમ સંખ્યામાં મધ્યિકા = (n/2 મો + (n/2 + 1) મો ક્રમ)/2
  • મધ્યિકા ક્રમમાં ગોઠવણી જરૂરી છે
  • અસરકારક રીતે આઉટલાયર્સથી પ્રભાવિત થતી નથી
🧠 Trick: મધ્યમાં બેસો, મધ્યિકા મળશે!

મધ્યિકા અને મધ્યક (Mean) વચ્ચેનો તફાવત

મધ્યિકા એ ક્રમબદ્ધ ડેટાની મધ્ય કિંમત છે, જ્યારે મધ્યક એ બધા મૂલ્યોનો સરેરાશ છે. મધ્યિકા આઉટલાયર્સ પ્રત્યે અસંવેદનશીલ હોય છે, જ્યારે મધ્યક તેનાથી પ્રભાવિત થાય છે.

  • મધ્યિકા = ક્રમબદ્ધ ડેટાની મધ્ય કિંમત
  • મધ્યક = (Σx)/n
  • મધ્યિકા આઉટલાયર્સથી પ્રભાવિત થતી નથી
  • મધ્યક આઉટલાયર્સથી પ્રભાવિત થાય છે
🧠 Trick: મધ્યક મધ્યમાં નહીં, સરેરાશમાં!

મધ્યિકાના ગુણધર્મો

મધ્યિકા એ એક એવી કેન્દ્રીય પ્રવૃત્તિ છે જે ડેટાની અસમમિતીને ધ્યાનમાં લે છે. તે ડેટાના મૂલ્યોના ક્રમ પર આધારિત છે અને ડેટામાં ફેરફાર થવા પર તે બદલાય છે.

  • ક્રમબદ્ધ ડેટા જરૂરી
  • અસમમિત ડેટામાં મધ્યિકા મધ્યક કરતાં વધુ વિશ્વસનીય
  • ડેટામાં ફેરફાર થવા પર મધ્યિકા બદલાય
  • મૂલ્યોની સંખ્યા પર આધારિત

મધ્યિકાની ગણતરી માટેની પગલાં

મધ્યિકાની ગણતરી કરવા માટે ડેટાને ચડતા અથવા ઉતરતા ક્રમમાં ગોઠવો. જો n વિષમ હોય, તો મધ્યમાં આવતું મૂલ્ય મધ્યિકા છે. જો n સમ હોય, તો મધ્યના બે મૂલ્યોના સરેરાશથી મધ્યિકા મેળવો.

  • ડેટાને ક્રમમાં ગોઠવો
  • n વિષમ હોય ત્યારે (n+1)/2 મો ક્રમ
  • n સમ હોય ત્યારે n/2 અને (n/2 + 1) મો ક્રમનો સરેરાશ
  • ક્રમમાં ગોઠવણી વિના મધ્યિકા શક્ય નથી
🧠 Trick: ગોઠવો, ગણો, મધ્યિકા મેળવો!

મધ્યિકાનાં ઉદાહરણો

ઉદાહરણ તરીકે, ડેટા {3, 1, 4, 2, 5} માટે, ક્રમમાં ગોઠવણી {1, 2, 3, 4, 5} થાય. n=5 (વિષમ) હોવાથી મધ્યિકા 3 છે. ડેટા {3, 1, 4, 2, 5, 6} માટે, ક્રમમાં ગોઠવણી {1, 2, 3, 4, 5, 6} થાય. n=6 (સમ) હોવાથી મધ્યિકા (3+4)/2 = 3.5 છે.

  • વિષમ n માટે મધ્યમાં આવતું મૂલ્ય
  • સમ n માટે મધ્યના બે મૂલ્યોનો સરેરાશ
  • ક્રમમાં ગોઠવણી અગત્યની
  • ઉદાહરણો દ્વારા સ્પષ્ટતા

મધ્યિકાનું મહત્વ

મધ્યિકા એ આંકડાશાસ્ત્રમાં એક મહત્વપૂર્ણ કેન્દ્રીય પ્રવૃત્તિ છે જેમાં ડેટાની અસમમિતી હાજર હોય ત્યારે તે મધ્યક કરતાં વધુ ઉપયોગી થાય છે. તે ડેટાના વિતરણને સમજવામાં મદદ કરે છે.

  • અસમમિત ડેટામાં ઉપયોગી
  • આઉટલાયર્સથી પ્રભાવિત થતી નથી
  • ડેટાના વિતરણને સમજવામાં મદદરૂપ
  • કેન્દ્રીય પ્રવૃત્તિ તરીકે મહત્વપૂર્ણ

મધ્યિકા અને બહુલક (Mode) વચ્ચેનો તફાવત

મધ્યિકા એ ક્રમબદ્ધ ડેટાની મધ્ય કિંમત છે, જ્યારે બહુલક એ ડેટામાં સૌથી વધુ વાર આવતું મૂલ્ય છે. મધ્યિકા ડેટાના ક્રમ પર આધારિત છે, જ્યારે બહુલક ડેટામાં સૌથી સામાન્ય મૂલ્ય પર આધારિત છે.

  • મધ્યિકા = ક્રમબદ્ધ ડેટાની મધ્ય કિંમત
  • બહુલક = સૌથી વધુ વાર આવતું મૂલ્ય
  • મધ્યિકા ક્રમ પર આધારિત
  • બહુલક આવર્તન પર આધારિત
🧠 Trick: મધ્યિકા મધ્યમાં, બહુલક બહુ વાર!

  • મધ્યિકા ડેટાના વિતરણને સમજવામાં મદદ કરે છે

🎯 Exam Tip: પરીક્ષામાં મધ્યિકા સંબંધિત પ્રશ્નો માટે ડેટાને ક્રમમાં ગોઠવવાનું ભૂલશો નહીં. વિષમ અને સમ સંખ્યાના કિસ્સાઓને સ્પષ્ટ રીતે સમજો.
