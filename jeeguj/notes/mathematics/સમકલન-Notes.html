સમાકલન

📖 સમાકલન (Integration)

સમાકલનનો પરિચય

સમાકલન એ અવકલનનો વિપરિત પ્રક્રિયા છે, જ્યાં ફંક્શનના વક્ર નીચેના ક્ષેત્રફળની ગણતરી કરવામાં આવે છે. તે અંતરાલ [a, b] પર ફંક્શન f(x) નો સરવાળો (summation) લીમિટની રૂપે વ્યાખ્યાયિત થાય છે. સમાકલનનો ઉપયોગ ભૌતિકશાસ્ત્રમાં કામ, ઉર્જા, ક્ષેત્રફળ વગેરેની ગણતરીમાં થાય છે.

  • સમાકલન એ અવકલનનો ઉલ્ટો પ્રક્રિયા છે.
  • અનિશ્ચિત સમાકલન (Indefinite Integral) એ F(x) + C રૂપે હોય છે, જ્યાં C એ સ્થિરાંક છે.
  • નિશ્ચિત સમાકલન (Definite Integral) એ અંતરાલ [a, b] પર ક્ષેત્રફળ દર્શાવે છે.
  • સમાકલનનો ઉપયોગ વક્ર નીચેના ક્ષેત્રફળ માટે થાય છે.
🧠 Trick: સમાકલન = સરવાળો + લીમિટ (Sum + Limit)

મૂળભૂત સમાકલન સૂત્રો

મૂળભૂત સમાકલન સૂત્રો એ અવકલનના સૂત્રોના વિપરિત હોય છે. ઉદાહરણ: ∫x^n dx = x^(n+1)/(n+1) + C (n ≠ -1). ∫1/x dx = ln|x| + C. ∫e^x dx = e^x + C. ∫a^x dx = a^x/ln(a) + C. આ સૂત્રો સરળ ફંક્શન્સ માટે ઉપયોગી છે.

  • ∫x^n dx = x^(n+1)/(n+1) + C (n ≠ -1)
  • ∫1/x dx = ln|x| + C
  • ∫e^x dx = e^x + C
  • ∫a^x dx = a^x/ln(a) + C
  • ∫sin(x) dx = -cos(x) + C
🧠 Trick: પાવર પ્લસ વન, ડિવાઇડ બાય પાવર પ્લસ વન (Power +1, Divide by Power +1)

સમાકલનની પદ્ધતિઓ

સમાકલન માટે વિવિધ પદ્ધતિઓ ઉપલબ્ધ છે જેમકે પ્રતિસ્થાપન પદ્ધતિ (Substitution), અંશતઃ ભાગાકાર (Partial Fractions), ભાગાકાર દ્વારા સમાકલન (Integration by Parts), અને ત્રિકોણમિતીય સમાકલન. પ્રતિસ્થાપન પદ્ધતિ એ સૌથી સામાન્ય છે, જ્યાં u = g(x) લેતા ∫f(g(x))g'(x) dx = ∫f(u) du થાય છે.

  • પ્રતિસ્થાપન પદ્ધતિ: u = g(x), du = g'(x) dx
  • ભાગાકાર દ્વારા સમાકલન: ∫u dv = uv - ∫v du
  • અંશતઃ ભાગાકાર: રેશનલ ફંક્શન્સ માટે ઉપયોગી
  • ત્રિકોણમિતીય સમાકલન: sin, cos, tan વગેરે માટે
🧠 Trick: LIATE (Logarithmic, Inverse Trigonometric, Algebraic, Trigonometric, Exponential) - ભાગાકાર દ્વારા સમાકલન માટે u અને dv પસંદ કરવા માટે

નિશ્ચિત સમાકલનના ગુણધર્મો

નિશ્ચિત સમાકલનના મહત્વપૂર્ણ ગુણધર્મો જેમકે રેખીયતા, અંતરાલનો સરવાળો, અને વિષમ-સમ ફંક્શન્સ માટેના ગુણધર્મો. ઉદાહરણ: ∫[a to b] f(x) dx = -∫[b to a] f(x) dx. જો f(x) વિષમ ફંક્શન હોય, તો ∫[-a to a] f(x) dx = 0. જો f(x) સમ ફંક્શન હોય, તો ∫[-a to a] f(x) dx = 2∫[0 to a] f(x) dx.

  • રેખીયતા: ∫[a to b] (k1f(x) + k2g(x)) dx = k1∫f(x)dx + k2∫g(x)dx
  • અંતરાલનો સરવાળો: ∫[a to c] f(x) dx = ∫[a to b] f(x) dx + ∫[b to c] f(x) dx
  • વિષમ ફંક્શન: ∫[-a to a] f(x) dx = 0
  • સમ ફંક્શન: ∫[-a to a] f(x) dx = 2∫[0 to a] f(x) dx

સમાકલનના અરજો

સમાકલનના અરજો ભૌતિકશાસ્ત્ર, રસાયણશાસ્ત્ર, અને ગણિતમાં વિશાળ છે. ભૌતિકશાસ્ત્રમાં, કામ (Work) = ∫F dx, વિદ્યુત પ્રવાહ (Electric Current) = ∫I dt, અને દબાણ (Pressure) = ∫P dA. રસાયણશાસ્ત્રમાં, રાસાયણિક પ્રક્રિયાઓના વેગની ગણતરી માટે સમાકલન ઉપયોગી છે.

  • કામ = ∫F dx (બળ અને વિસ્થાપન)
  • વિદ્યુત પ્રવાહ = ∫I dt (વિદ્યુતપ્રવાહ અને સમય)
  • ક્ષેત્રફળ = ∫f(x) dx (વક્ર નીચેના ક્ષેત્રફળ)
  • ગુરુત્વાકર્ષણ બળ = ∫GMm/r² dr (ગુરુત્વાકર્ષણના નિયમ માટે)
  • રાસાયણિક વેગ = ∫k[reactant] dt

સમાકલન અને ક્ષેત્રફળ

સમાકલનનો ઉપયોગ વક્ર અને x-અક્ષ વચ્ચેના ક્ષેત્રફળની ગણતરીમાં થાય છે. જો f(x) ≥ 0 હોય, તો ક્ષેત્રફળ = ∫[a to b] f(x) dx. જો f(x) ની ચિહ્ન બદલાય, તો ક્ષેત્રફળ = ∫[a to b] |f(x)| dx. બહુવિધ વક્રો વચ્ચેના ક્ષેત્રફળ માટે, ઉપરના વક્ર મિનસ નીચેના વક્રનું સમાકલન લેવામાં આવે છે.

  • વક્ર અને x-અક્ષ વચ્ચેનું ક્ષેત્રફળ = ∫[a to b] |f(x)| dx
  • બહુવિધ વક્રો વચ્ચેનું ક્ષેત્રફળ = ∫[a to b] (f(x) - g(x)) dx (જ્યાં f(x) ≥ g(x))
  • પરિભ્રમણથી ઉત્પન્ન થતા પદાર્થનો કદ = π∫[a to b] (f(x))² dx
  • પરિભ્રમણથી ઉત્પન્ન થતા પદાર્થનો પૃષ્ઠ ક્ષેત્રફળ = 2π∫[a to b] f(x)√(1 + (f'(x))²) dx
🧠 Trick: ઉપર મિનસ નીચે (Top - Bottom)

સમાકલનમાં સામાન્ય ભૂલો

વિદ્યાર્થીઓ સમાકલનમાં સામાન્ય ભૂલો કરે છે જેમકે સ્થિરાંક C ભૂલી જવું, અવકલન અને સમાકલનના સૂત્રો મિશ્રિત કરવા, અને પ્રતિસ્થાપન પદ્ધતિમાં du ની ગણતરી ખોટી કરવી. સમાકલનના ચિહ્ન (∫) અને અવકલનના ચિહ્ન (d/dx) વચ્ચેનો તફાવત સમજવો મહત્વપૂર્ણ છે.

  • સ્થિરાંક C ભૂલી જવું (Indefinite Integral માટે)
  • અવકલન અને સમાકલનના સૂત્રો મિશ્રિત કરવા
  • પ્રતિસ્થાપન પદ્ધતિમાં du ની ખોટી ગણતરી
  • નિશ્ચિત સમાકલનમાં લીમિટ્સ ભૂલી જવી
  • ફંક્શનની ચિહ્ન પર ધ્યાન ન આપવું (ક્ષેત્રફળ માટે |f(x)| ઉપયોગી છે)
🧠 Trick: C = સ્થિરાંક, ભૂલશો નહીં!

⚡ Quick Revision

  • સમાકલન એ અવકલનનો ઉલ્ટો પ્રક્રિયા છે.
  • ∫x^n dx = x^(n+1)/(n+1) + C (n ≠ -1)
  • પ્રતિસ્થાપન પદ્ધતિ: u = g(x), du = g'(x) dx
  • ભાગાકાર દ્વારા સમાકલન: ∫u dv = uv - ∫v du
  • નિશ્ચિત સમાકલન: ∫[a to b] f(x) dx = F(b) - F(a)
  • વિષમ ફંક્શન: ∫[-a to a] f(x) dx = 0
  • સમ ફંક્શન: ∫[-a to a] f(x) dx = 2∫[0 to a] f(x) dx
  • ક્ષેત્રફળ = ∫[a to b] |f(x)| dx
  • કામ = ∫F dx, વિદ્યુત પ્રવાહ = ∫I dt
  • સ્થિરાંક C ભૂલશો નહીં!
🎯 Exam Tip: સમાકલનના પ્રશ્નોમાં, પ્રથમ પ્રતિસ્થાપન પદ્ધતિ અજમાવો. જો કામ ન લાગે, તો ભાગાકાર દ્વારા સમાકલન અથવા અંશતઃ ભાગાકાર અજમાવો. નિશ્ચિત સમાકલનમાં, હંમેશા લીમિટ્સ લખો અને ફંક્શનની ચિહ્ન તપાસો.
