આંકડાશાસ્ત્ર

📖 આંકડાશાસ્ત્ર (Statistics)

આંકડાશાસ્ત્રની મૂળભૂત સંકલ્પના

આંકડાશાસ્ત્ર એ ડેટાનું સંગ્રહણ, વર્ગીકરણ, વિશ્લેષણ અને નિષ્કર્ષ કાઢવાની વિજ્ઞાન છે. JEEમાં મુખ્યત્વે મધ્યક, મધ્યમા, બહુલક, પ્રસરણ અને સહસંબંધ જેવા મૂળભૂત માપદંડ પર ધ્યાન આપવામાં આવે છે.

  • ડેટા બે પ્રકારનો હોય છે: અંકીય (Discrete) અને સતત (Continuous).
  • મધ્યક (Mean) એ ડેટાનું સરેરાશ મૂલ્ય દર્શાવે છે.
  • મધ્યમા (Median) એ ડેટાનું મધ્યમ મૂલ્ય હોય છે.
  • બહુલક (Mode) એ સૌથી વધુ વાર આવતું મૂલ્ય હોય છે.
🧠 Trick: MMM = Mean, Median, Mode

મધ્યક, મધ્યમા અને બહુલક

મધ્યક એ સરવૈવ મૂલ્યોનો સરાસરી હોય છે. મધ્યમા એ ક્રમબદ્ધ ડેટાનું મધ્યમ મૂલ્ય હોય છે. બહુલક એ ડેટામાં સૌથી વધુ વાર આવતું મૂલ્ય હોય છે. આ ત્રણેય કેન્દ્રીય પ્રવૃત્તિના માપદંડ છે.

  • મધ્યક = (Σx_i) / n
  • મધ્યમા માટે ડેટાને ચડતા અથવા ઉતરતા ક્રમમાં ગોઠવો.
  • બહુલક એ ડેટાનું સૌથી વધુ પુનરાવર્તિત મૂલ્ય હોય છે.
  • જો બે બહુલક હોય તો ડેટા દ્વિબહુલકી (Bimodal) કહેવાય.

પ્રસરણના માપદંડ

પ્રસરણ એ ડેટાનું ફેલાવો દર્શાવે છે. પરાસ (Range), વરિયન્સ (Variance) અને સ્ટાન્ડર્ડ ડેવિયેશન (SD) એ પ્રસરણના મુખ્ય માપદંડ છે. SD એ વરિયન્સનો વર્ગમૂળ હોય છે.

  • પરાસ = મહત્તમ મૂલ્ય - લઘુતમ મૂલ્ય
  • વરિયન્સ (σ²) = Σ(x_i - μ)² / n
  • SD (σ) = √(Σ(x_i - μ)² / n)
  • SD એ ડેટાનું પ્રસરણ માપવાનો સૌથી વ્યાપક ઉપયોગી માપદંડ છે.
🧠 Trick: RVS = Range, Variance, SD

સહસંબંધ અને રેખીય રિગ્રેશન

સહસંબંધ એ બે ચલ વચ્ચેના સંબંધની તીવ્રતા અને દિશા દર્શાવે છે. રેખીય રિગ્રેશન એ ડેટાને સૌથી યોગ્ય રેખા ફિટ કરવાની પદ્ધતિ છે. સહસંબંધ ગુણાંક (r) એ -1 થી +1 વચ્ચે હોય છે.

  • સહસંબંધ ગુણાંક (r) = Cov(X,Y) / (σ_X * σ_Y)
  • r = +1 એ પૂર્ણ ધન સહસંબંધ દર્શાવે છે.
  • r = -1 એ પૂર્ણ ઋણ સહસંબંધ દર્શાવે છે.
  • રેખીય રિગ્રેશનની રેખા y = mx + c સ્વરૂપની હોય છે.
🧠 Trick: r = +1 (પૂર્ણ ધન), r = -1 (પૂર્ણ ઋણ), r = 0 (કોઈ સહસંબંધ નહીં)

પ્રાયિકતા અને પ્રાયિકતા વિતરણ

પ્રાયિકતા એ કોઈ ઘટનાનું થવાની સંભાવના દર્શાવે છે. પ્રાયિકતા વિતરણ એ ચલના મૂલ્યો અને તેની સંભાવનાનું વિતરણ દર્શાવે છે. બર્નૌલી, બાઇનોમિયલ અને પોઇસન વિતરણ એ મહત્વપૂર્ણ પ્રાયિકતા વિતરણ છે.

  • પ્રાયિકતા (P) = અનુકૂળ પરિણામો / કુલ પરિણામો
  • બાઇનોમિયલ વિતરણ: P(X=k) = nCk * p^k * (1-p)^(n-k)
  • પોઇસન વિતરણ: P(X=k) = (e^-λ * λ^k) / k!
  • બર્નૌલી વિતરણ એ બાઇનોમિયલ વિતરણનો વિશેષ કિસ્સો છે (n=1).

ડેટાનું રજૂઆત

ડેટાનું રજૂઆત આલેખો, કોષ્ટકો અને ચાર્ટ્સ દ્વારા કરવામાં આવે છે. હિસ્ટોગ્રામ, પાઇ ચાર્ટ, બાર ચાર્ટ અને લાઇન ગ્રાફ એ ડેટા રજૂઆતના મુખ્ય સાધનો છે.

  • હિસ્ટોગ્રામ એ સતત ડેટાનું રજૂઆત કરે છે.
  • પાઇ ચાર્ટ એ ડેટાનું ટકાવારી રજૂઆત કરે છે.
  • બાર ચાર્ટ એ વર્ગીકૃત ડેટાનું રજૂઆત કરે છે.
  • લાઇન ગ્રાફ એ સમય સાથે બદલાતા ડેટાનું રજૂઆત કરે છે.
🧠 Trick: HBL = Histogram, Bar chart, Line graph

અનુમાનિત આંકડાશાસ્ત્ર

અનુમાનિત આંકડાશાસ્ત્રમાં મોટા સમૂહ વિશેના નિષ્કર્ષો નાના નમૂણા આધારે કાઢવામાં આવે છે. મધ્યક અને પ્રમાણિત વિચલન જેવા માપદંડોનો અંદાજ કાઢવો એ અનુમાનિત આંકડાશાસ્ત્રનો મુખ્ય ઉદ્દેશ છે.

  • નમૂણા મધ્યક (x̄) એ સમૂહ મધ્યક (μ)નો અંદાજ આપે છે.
  • નમૂણા પ્રમાણિત વિચલન (s) એ સમૂહ પ્રમાણિત વિચલન (σ)નો અંદાજ આપે છે.
  • કેંદ્રીય મર્યાદા થિયોરમ (CLT) અનુસાર, નમૂણા મધ્યકનું વિતરણ સમાન્ય વિતરણ તરફ ઢળે છે.
  • અનુમાન માટે નમૂણાનો કદ મહત્વપૂર્ણ છે.

⚡ Quick Revision

  • આંકડાશાસ્ત્ર એ ડેટાનું વિશ્લેષણ અને નિષ્કર્ષ કાઢવાની વિજ્ઞાન છે.
  • મધ્યક, મધ્યમા, બહુલક એ કેન્દ્રીય પ્રવૃત્તિના માપદંડ છે.
  • પરાસ, વરિયન્સ, SD એ પ્રસરણના માપદંડ છે.
  • સહસંબંધ ગુણાંક (r) એ બે ચલ વચ્ચેના સંબંધની તીવ્રતા દર્શાવે છે.
  • બાઇનોમિયલ અને પોઇસન વિતરણ એ મહત્વપૂર્ણ પ્રાયિકતા વિતરણ છે.
  • હિસ્ટોગ્રામ, પાઇ ચાર્ટ, બાર ચાર્ટ એ ડેટા રજૂઆતના સાધનો છે.
  • કેંદ્રીય મર્યાદા થિયોરમ (CLT) અનુસાર નમૂણા મધ્યકનું વિતરણ સમાન્ય વિતરણ તરફ ઢળે છે.
  • નમૂણા મધ્યક અને પ્રમાણિત વિચલન એ સમૂહ માપદંડોના અંદાજ આપે છે.
🎯 Exam Tip: JEEમાં આંકડાશાસ્ત્રના પ્રશ્નો મુખ્યત્વે ફોર્મ્યુલા આધારિત હોય છે, તો ફોર્મ્યુલા યાદ રાખો અને તેના ઉપયોગની પ્રેક્ટિસ કરો.
