મેટ્રિક્સ

📖 મેટ્રિક્સ (Matrix)

મેટ્રિક્સની વ્યાખ્યા અને પ્રકાર

મેટ્રિક્સ એ આયામ m × n ની કોઠાકાર ગોઠવણી છે, જ્યાં m = વર્ગોની સંખ્યા અને n = સ્તંભોની સંખ્યા. તેને [a_ij] અથવા A = [a_ij]m×n લખાય છે. મેટ્રિક્સના પ્રકારોમાં વર્ગ મેટ્રિક્સ (m = n), શૂન્ય મેટ્રિક્સ, એકમ મેટ્રિક્સ, સંમિત મેટ્રિક્સ (A = A^T), વિષમસંમિત મેટ્રિક્સ (A = -A^T) અને ડાયગોનલ મેટ્રિક્સનો સમાવેશ થાય છે.

  • મેટ્રિક્સની ક્રમ (Order) = m × n, જ્યાં m = વર્ગો, n = સ્તંભો
  • વર્ગ મેટ્રિક્સમાં m = n (ઉદા. 2×2, 3×3)
  • એકમ મેટ્રિક્સ Iમાં મુખ્ય વર્ગતલ પર 1 અને બાકી 0 હોય છે
  • સંમિત મેટ્રિક્સમાં A = A^T (ટ્રાન્સપોઝ)
  • વિષમસંમિત મેટ્રિક્સમાં A^T = -A અને મુખ્ય વર્ગતલ પર 0 હોય છે
🧠 Trick: સંમિત = સરખું (A = A^T), વિષમ = વિરુદ્ધ (A = -A^T)

મેટ્રિક્સના મૂળભૂત ઓપરેશન્સ

મેટ્રિક્સના મૂળભૂત ઓપરેશન્સમાં સરવણી, બાદબાકી, ગુણાકાર (સ્કેલર અને મેટ્રિક્સ) અને ટ્રાન્સપોઝનો સમાવેશ થાય છે. સરવણી/બાદબાકી માટે મેટ્રિક્સની ક્રમ સરખી હોવી જરૂરી છે. મેટ્રિક્સ ગુણાકાર માટે પ્રથમ મેટ્રિક્સના સ્તંભોની સંખ્યા = બીજી મેટ્રિક્સના વર્ગોની સંખ્યા હોવી જોઈએ. ટ્રાન્સપોઝ (A^T)માં વર્ગો અને સ્તંભોની અદલાબદલી થાય છે.

  • A + B = B + A (સરવણી ક્રમવિહીન)
  • A(B + C) = AB + AC (વિતરણ નિયમ)
  • AB ≠ BA (ગુણાકાર ક્રમસાપેક્ષ)
  • (AB)^T = B^T A^T
  • સ્કેલર ગુણાકાર: k(A + B) = kA + kB
🧠 Trick: ગુણાકાર ક્રમ = AB ≠ BA, ટ્રાન્સપોઝ = A^T = વર્ગ↔સ્તંભ

મેટ્રિક્સનો વ્યસ્ત (Inverse of a Matrix)

વર્ગ મેટ્રિક્સ Aનો વ્યસ્ત A^-1 એવી મેટ્રિક્સ છે કે A * A^-1 = A^-1 * A = I (એકમ મેટ્રિક્સ). વ્યસ્ત અસ્તિત્વમાં હોય તો |A| ≠ 0 (ડિટર્મિનન્ટ શૂન્ય ન હોવું જોઈએ). વ્યસ્તની ગણતરી માટે એડજસ્ટ મેટ્રિક્સ અને ડિટર્મિનન્ટનો ઉપયોગ થાય છે: A^-1 = (1/|A|) * adj(A).

  • A^-1 અસ્તિત્વમાં હોય તો |A| ≠ 0
  • A^-1 = (1/|A|) * adj(A)
  • વ્યસ્ત મેળવવા માટે: 1) adj(A) શોધો, 2) |A| શોધો, 3) (1/|A|) * adj(A)
  • (AB)^-1 = B^-1 A^-1
  • (A^T)^-1 = (A^-1)^T
🧠 Trick: વ્યસ્ત = 1/|A| * adj(A), ડિટર્મિનન્ટ શૂન્ય નહીં તો વ્યસ્ત નહીં

ડિટર્મિનન્ટ (Determinant)

ડિટર્મિનન્ટ એ વર્ગ મેટ્રિક્સ સાથે સંકળાયેલ એક સ્કેલર મૂલ્ય છે, જે મેટ્રિક્સની વ્યસ્ત અને હલ કરવાની સમસ્યાઓમાં ઉપયોગી છે. 2×2 મેટ્રિક્સ માટે |A| = ad - bc (A = [a b; c d]). 3×3 મેટ્રિક્સ માટે સર્રસ નિયમ અથવા કોફેક્ટર વિસ્તરણનો ઉપયોગ થાય છે. ડિટર્મિનન્ટના ગુણધર્મોમાં |A^T| = |A|, |AB| = |A||B|, |kA| = k^n |A| (n = ક્રમ)નો સમાવેશ થાય છે.

  • 2×2 મેટ્રિક્સ: |A| = ad - bc
  • 3×3 મેટ્રિક્સ: સર્રસ નિયમ અથવા કોફેક્ટર
  • |A^T| = |A|
  • |AB| = |A||B|
  • |kA| = k^n |A| (n = ક્રમ)
🧠 Trick: 2×2 ડિટર્મિનન્ટ: 'ad - bc' (ક્રોસ ગુણાકાર)

રેખીય સમીકરણોની પ્રણાલી અને મેટ્રિક્સ

રેખીય સમીકરણોની પ્રણાલીને મેટ્રિક્સ સ્વરૂપે AX = B લખી શકાય છે, જ્યાં A = ગુણાંક મેટ્રિક્સ, X = અજ્ઞાત મેટ્રિક્સ, B = અચળ મેટ્રિક્સ. હલ કરવા માટે ક્રેમર નિયમ અથવા મેટ્રિક્સ વ્યસ્ત પદ્ધતિનો ઉપયોગ થાય છે. ક્રેમર નિયમ મુજબ, જો |A| ≠ 0, તો X = A^-1 B. જો |A| = 0, તો પ્રણાલી અસંગત અથવા અનંત હલ ધરાવે છે.

  • AX = B, જ્યાં A = ગુણાંક મેટ્રિક્સ
  • ક્રેમર નિયમ: X_i = |A_i| / |A| (જ્યાં |A| ≠ 0)
  • જો |A| = 0: અસંગત અથવા અનંત હલ
  • મેટ્રિક્સ વ્યસ્ત પદ્ધતિ: X = A^-1 B
  • હલ અસ્તિત્વમાં હોય તો |A| ≠ 0
🧠 Trick: ક્રેમર = |A_i| / |A|, |A| = 0 → કોઈ હલ નહીં અથવા અનંત

મેટ્રિક્સના અનુપ્રયોગો

મેટ્રિક્સનો ઉપયોગ કમ્પ્યુટર ગ્રાફિક્સ, ક્રિપ્ટોગ્રાફી, રોબોટિક્સ, આર્ટિફિશિયલ ઇન્ટેલિજન્સ અને ઇજનેરીમાં થાય છે. કમ્પ્યુટર ગ્રાફિક્સમાં 3D ટ્રાન્સફોર્મેશન (રોટેશન, સ્કેલિંગ, ટ્રાન્સલેશન) માટે મેટ્રિક્સનો ઉપયોગ થાય છે. ક્રિપ્ટોગ્રાફીમાં ડેટા એન્ક્રિપ્શન માટે મેટ્રિક્સ ગુણાકાર ઉપયોગી છે. રોબોટિક્સમાં રોબોટની ગતિ અને સ્થિતિ નિયંત્રણ માટે મેટ્રિક્સનો ઉપયોગ થાય છે.

  • કમ્પ્યુટર ગ્રાફિક્સ: 3D ટ્રાન્સફોર્મેશન
  • ક્રિપ્ટોગ્રાફી: ડેટા એન્ક્રિપ્શન
  • રોબોટિક્સ: ગતિ અને સ્થિતિ નિયંત્રણ
  • AI: મશીન લર્નિંગ એલગોરિધમ્સ
  • ઇજનેરી: સ્ટ્રક્ચરલ એનાલિસિસ

મહત્વના સૂત્રો અને ગુણધર્મો

મેટ્રિક્સના મહત્વના સૂત્રો અને ગુણધર્મોમાં (A + B)^2 = A^2 + AB + BA + B^2, (A - B)^2 = A^2 - AB - BA + B^2, A^2 - B^2 = (A - B)(A + B) + BA - ABનો સમાવેશ થાય છે. એડજસ્ટ મેટ્રિક્સના ગુણધર્મોમાં A * adj(A) = adj(A) * A = |A|I અને adj(AB) = adj(B) * adj(A)નો સમાવેશ થાય છે.

  • (A + B)^2 = A^2 + AB + BA + B^2
  • (A - B)^2 = A^2 - AB - BA + B^2
  • A * adj(A) = |A|I
  • adj(AB) = adj(B) * adj(A)
  • |adj(A)| = |A|^(n-1) (n = ક્રમ)
🧠 Trick: એડજસ્ટ = |A|I / A, ગુણાકાર ક્રમ બદલાય = adj(AB) = adj(B)adj(A)

⚡ Quick Revision

  • મેટ્રિક્સ = m × n કોઠાકાર ગોઠવણી
  • વર્ગ મેટ્રિક્સમાં m = n
  • સંમિત મેટ્રિક્સ: A = A^T, વિષમસંમિત: A = -A^T
  • ડિટર્મિનન્ટ |A| = 0 → વ્યસ્ત અસ્તિત્વમાં નહીં
  • 2×2 ડિટર્મિનન્ટ: ad - bc
  • ક્રેમર નિયમ: X_i = |A_i| / |A|
  • મેટ્રિક્સ ગુણાકાર: AB ≠ BA (ક્રમસાપેક્ષ)
  • વ્યસ્ત: A^-1 = (1/|A|) * adj(A)
  • રેખીય સમીકરણ પ્રણાલી: AX = B
  • મેટ્રિક્સના અનુપ્રયોગો: ગ્રાફિક્સ, ક્રિપ્ટોગ્રાફી, રોબોટિક્સ
🎯 Exam Tip: JEE Mainમાં મેટ્રિક્સના પ્રશ્નો મોટાભાગે ડિટર્મિનન્ટ, વ્યસ્ત, અને રેખીય સમીકરણ પ્રણાલી પર આધારિત હોય છે. તમારી ગણતરીમાં ડિટર્મિનન્ટ અને એડજસ્ટ મેટ્રિક્સની ગણતરી સચોટ રાખો.
