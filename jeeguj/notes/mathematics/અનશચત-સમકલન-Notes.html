અનિશ્ચિત સમાકલન

📖 અનિશ્ચિત સમાકલન

પરિભાષા અને મૂળભૂત સંકલ્પના

અનિશ્ચિત સમાકલન એટલે જ્યારે સમાકલનની હદ મર્યાદા અથવા અસ્તિત્વ અંગે ખાતરી ન હોય. જો f(x) રેખીય અથવા ટુકડાટુકડા રેખીય હોય તો અનિશ્ચિત સમાકલન શક્ય બને છે. NCERT મુજબ, આ સંકલ્પના JEEમાં અગત્યનો છે કારણ કે તે અસીમિત ક્ષેત્રો અને વક્રોના ક્ષેત્રફળ માટે ઉપયોગી છે.

  • અનિશ્ચિત સમાકલન = ∫f(x)dx = F(x) + C, જ્યાં F'(x) = f(x)
  • C એ સમાકલન અચળાંક (Integration Constant) છે
  • જો f(x) સતત હોય તો અનિશ્ચિત સમાકલન હંમેશા અસ્તિત્વ ધરાવે છે
  • રેખીય ફંક્શનના સમાકલન માટે સરળ નિયમો લાગુ પડે છે
🧠 Trick: સી (C) એ 'સ્થિર' અચળાંક, ભૂલશો નહીં!

મૂળભૂત સમાકલન નિયમો

મૂળભૂત નિયમો જેવા કે ∫x^n dx = x^(n+1)/(n+1) + C (n ≠ -1), ∫1/x dx = ln|x| + C, અને ∫e^x dx = e^x + C એ JEE માટે અગત્યના છે. આ નિયમોને યાદ રાખવા અને લાગુ કરવા માટે અભ્યાસ કરો.

  • ∫x^n dx = x^(n+1)/(n+1) + C (n ≠ -1)
  • ∫1/x dx = ln|x| + C
  • ∫e^x dx = e^x + C
  • ∫a^x dx = a^x / ln(a) + C
  • ∫sin(x) dx = -cos(x) + C
🧠 Trick: પાવર પ્લસ વન, ડિવાઇડ બાય પાવર પ્લસ વન!

ત્રિકોણમિતીય અને હાયપરબોલિક ફંક્શનના સમાકલન

ત્રિકોણમિતીય ફંક્શનો જેવા કે sin(x), cos(x), tan(x) અને હાયપરબોલિક ફંક્શનો જેવા કે sinh(x), cosh(x)ના સમાકલન JEEમાં વારંવાર પૂછાય છે. આ ફંક્શનોના સમાકલન યાદ રાખવા અને લાગુ કરવા માટે નિયમિત અભ્યાસ કરો.

  • ∫sin(x) dx = -cos(x) + C
  • ∫cos(x) dx = sin(x) + C
  • ∫tan(x) dx = -ln|cos(x)| + C
  • ∫sinh(x) dx = cosh(x) + C
  • ∫cosh(x) dx = sinh(x) + C
🧠 Trick: સાઇન કોસ, કોસ સાઇન, ટેન લોગ કોસ!

પરિવર્તન પદ્ધતિ (Substitution Method)

જ્યારે ફંક્શન કોઈ એક ફંક્શન અને તેના ડેરિવેટિવના ગુણાકાર રૂપે હોય ત્યારે પરિવર્તન પદ્ધતિ ઉપયોગી થાય છે. ઉદાહરણ તરીકે, ∫f(g(x))g'(x)dx = ∫f(u)du, જ્યાં u = g(x). આ પદ્ધતિ JEEમાં અગત્યની છે.

  • u = g(x) મૂકો, તો du = g'(x)dx
  • ∫f(g(x))g'(x)dx = ∫f(u)du
  • પરિવર્તન પદ્ધતિને 'U-Substitution' પણ કહે છે
  • સરળતાથી ઓળખી શકાય એવા ફંક્શન માટે ઉપયોગી
🧠 Trick: U એ ઉકેલનો રસ્તો!

ભાગાકાર પદ્ધતિ (Integration by Parts)

ભાગાકાર પદ્ધતિ ∫u dv = uv - ∫v du પર આધારિત છે. આ પદ્ધતિ જ્યારે ફંક્શન બે ફંક્શનોના ગુણાકાર રૂપે હોય ત્યારે ઉપયોગી થાય છે. JEEમાં આ પદ્ધતિ વારંવાર પૂછાય છે.

  • ∫u dv = uv - ∫v du
  • LIATE નિયમ: L-log, I-inverse trig, A-algebraic, T-trig, E-exponential
  • u એ LIATE ક્રમમાં ઉચ્ચ સ્થાને હોય તે પસંદ કરો
  • ભાગાકાર પદ્ધતિને વારંવાર પુનરાવર્તન કરવી પડે છે
🧠 Trick: LIATE: લોગ, ઇન્વર્સ, એલ્જીબ્રા, ટ્રિગ, એક્સપોનેંશિયલ!

વિશિષ્ટ સમાકલન (Special Integrals)

વિશિષ્ટ સમાકલનો જેવા કે ∫√(a² - x²) dx, ∫√(a² + x²) dx, અને ∫√(x² - a²) dx એ JEE માટે અગત્યના છે. આ સમાકલનો માટે ત્રિકોણમિતીય પરિવર્તન અથવા હાયપરબોલિક પરિવર્તન ઉપયોગી થાય છે.

  • ∫√(a² - x²) dx = (x/2)√(a² - x²) + (a²/2)sin⁻¹(x/a) + C
  • ∫√(a² + x²) dx = (x/2)√(a² + x²) + (a²/2)ln|x + √(a² + x²)| + C
  • ∫√(x² - a²) dx = (x/2)√(x² - a²) - (a²/2)ln|x + √(x² - a²)| + C
  • ત્રિકોણમિતીય પરિવર્તન ઉપયોગી

અનિશ્ચિત સમાકલનના અનુપ્રયોગો

અનિશ્ચિત સમાકલનના અનુપ્રયોગો જેવા કે વક્રની લંબાઈ, ક્ષેત્રફળ, અને વોલ્યુમ ગણતરીમાં થાય છે. JEEમાં આ અનુપ્રયોગો વારંવાર પૂછાય છે.

  • વક્રની લંબાઈ: ∫√(1 + (dy/dx)²) dx
  • ક્ષેત્રફળ: ∫f(x) dx (x-અક્ષ અને વક્ર વચ્ચે)
  • વોલ્યુમ: π∫[f(x)]² dx (ઘૂમરણ પદ્ધતિ)
  • અનિશ્ચિત સમાકલનનો ઉપયોગ વેગ અને સ્થાન વચ્ચેના સંબંધ માટે થાય છે

  • LIATE નિયમ: લોગ, ઇન્વર્સ, એલ્જીબ્રા, ટ્રિગ, એક્સપોનેંશિયલ

🎯 Exam Tip: JEEમાં અનિશ્ચિત સમાકલનના પ્રશ્નો માટે, પહેલા ફંક્શનને ઓળખો અને ત્યારબાદ યોગ્ય પદ્ધતિ (પરિવર્તન, ભાગાકાર, વગેરે) પસંદ કરો. નિયમિત અભ્યાસ અને પ્રેક્ટિસથી ગતિ વધશે!
