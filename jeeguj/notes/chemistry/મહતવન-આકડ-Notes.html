મહત્વના આંકડા

📖 મહત્વના આંકડા (JEE Main - Physics, Chemistry, Mathematics)

ભૌતિકશાસ્ત્ર: મૂળભૂત અચળાંકો

JEE માટે અગત્યના ભૌતિક અચળાંકો જેવા કે g = 9.8 m/s², G = 6.67×10⁻¹¹ Nm²/kg², e = 1.6×10⁻¹⁹ C, mₑ = 9.1×10⁻³¹ kg, h = 6.626×10⁻³⁴ Js, c = 3×10⁸ m/s, ε₀ = 8.85×10⁻¹² F/m, μ₀ = 4π×10⁻⁷ Tm/A. આ અચળાંકોની કિંમતો અને એકમો યાદ રાખવા અગત્યના છે.

  • g = 9.8 m/s² (પૃથ્વીનો ગુરુત્વાકર્ષણ અચળાંક)
  • G = 6.67×10⁻¹¹ Nm²/kg² (સાર્વત્રિક ગુરુત્વાકર્ષણ અચળાંક)
  • e = 1.6×10⁻¹⁹ C (ઇલેક્ટ્રોનનો વીજભાર)
  • h = 6.626×10⁻³⁴ Js (પ્લાંક અચળાંક)
  • c = 3×10⁸ m/s (પ્રકાશનો વેગ)
🧠 Trick: G g h c e mₑ μ₀ ε₀ → 'Gujju Ghare Hasi Chhe Emi Mithai Muke Ene'

ભૌતિકશાસ્ત્ર: વીજભાર અને વીજભારના ગુણધર્મો

ઇલેક્ટ્રોનનો વીજભાર e = -1.6×10⁻¹⁹ C, પ્રોટોનનો વીજભાર +1.6×10⁻¹⁹ C. કૂલોમના નિયમમાં k = 9×10⁹ Nm²/C². વીજભારના ક્વોન્ટીઝેશનનો સિદ્ધાંત: q = ±ne. વીજભારની સંરક્ષણ નિયમ પણ મહત્વનો છે.

  • e = ±1.6×10⁻¹⁹ C (ઇલેક્ટ્રોન/પ્રોટોનનો વીજભાર)
  • k = 9×10⁹ Nm²/C² (કૂલોમ અચળાંક)
  • q = ne (વીજભારનું ક્વોન્ટીઝેશન)
  • વીજભારનું સંરક્ષણ

રસાયણશાસ્ત્ર: અણુ અને પરમાણુના આંકડા

અવોગેડ્રો અચળાંક Nₐ = 6.022×10²³ mol⁻¹, ગેસ અચળાંક R = 8.314 J/mol·K, બોલ્ટ્ઝમેન અચળાંક k = 1.38×10⁻²³ J/K. પરમાણુ દળ એકમ (u) = 1.66×10⁻²⁷ kg. આ આંકડા રાસાયણિક ગણતરીઓ માટે અગત્યના છે.

  • Nₐ = 6.022×10²³ mol⁻¹ (અવોગેડ્રો અચળાંક)
  • R = 8.314 J/mol·K (સાર્વત્રિક ગેસ અચળાંક)
  • k = 1.38×10⁻²³ J/K (બોલ્ટ્ઝમેન અચળાંક)
  • 1 u = 1.66×10⁻²⁷ kg (પરમાણુ દળ એકમ)
  • 1 amu = 1 g/mol
🧠 Trick: Nₐ R k u → 'NaRa Ku'

રસાયણશાસ્ત્ર: બંધન લંબાઈ અને બંધન ઊર્જા

મહત્વના બંધન લંબાઈ: H-H = 74 pm, C-C = 154 pm, C=C = 134 pm, O-H = 96 pm. બંધન ઊર્જા: H-H = 436 kJ/mol, C-C = 347 kJ/mol, O=O = 498 kJ/mol. આ આંકડા અણુની સ્થિરતા અને પ્રક્રિયાઓની દિશા નક્કી કરે છે.

  • H-H બંધન લંબાઈ = 74 pm
  • C-C બંધન લંબાઈ = 154 pm
  • H-H બંધન ઊર્જા = 436 kJ/mol
  • O=O બંધન ઊર્જા = 498 kJ/mol
  • બંધન લંબાઈ ∝ બંધન ક્રમ⁻¹

ગણિત: મહત્વના સૂત્રો અને આંકડા

અપૂર્ણાંક શ્રેણીના સરવાળા, બિનોમિયલ પ્રમેય, ત્રિકોણમિતીય ફંક્શન્સના મૂલ્યો (sin30°=0.5, cos60°=0.5, tan45°=1), e = 2.718, π ≈ 3.1416. લોગરિધમના નિયમો અને કેલ્ક્યુલસના મૂળભૂત સૂત્રો પણ યાદ રાખવા.

  • sin30° = cos60° = 0.5
  • tan45° = 1
  • e ≈ 2.718, π ≈ 3.1416
  • Σn = n(n+1)/2, Σn² = n(n+1)(2n+1)/6
  • d/dx (xⁿ) = n xⁿ⁻¹
🧠 Trick: sin30 cos60 tan45 → 'SaCo Ta'

ભૌતિકશાસ્ત્ર: પ્રકાશ અને તરંગો

પ્રકાશનો વેગ c = 3×10⁸ m/s, પ્લાંક અચળાંક h = 6.626×10⁻³⁴ Js, વીજચુંબકીય સ્પેક્ટ્રમની તરંગલંબાઈ શ્રેણી: રેડિયો તરંગો (10⁻¹ m) થી ગામા કિરણો (10⁻¹² m). સ્નેલનો નિયમ: n₁ sinθ₁ = n₂ sinθ₂.

  • c = 3×10⁸ m/s (પ્રકાશનો વેગ)
  • h = 6.626×10⁻³⁴ Js (પ્લાંક અચળાંક)
  • વીજચુંબકીય સ્પેક્ટ્રમની શ્રેણી
  • સ્નેલનો નિયમ: n₁ sinθ₁ = n₂ sinθ₂
  • વક્રીભવનાંક (n) = c/v
