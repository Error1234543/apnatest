પર્યાવરણીય રસાયણ

📖 પર્યાવરણીય રસાયણ

પર્યાવરણીય રસાયણની મૂળભૂત સમજ

પર્યાવરણીય રસાયણ એ રસાયણશાસ્ત્રની શાખા છે જે પર્યાવરણમાં થતી રાસાયણિક પ્રક્રિયાઓ, પ્રદૂષકો અને તેમના પર્યાવરણ પરના અસરોનો અભ્યાસ કરે છે. તે વાયુ, જળ, મૃદા અને જૈવ મંડળમાં થતી રાસાયણિક પરસ્પર ક્રિયાઓ પર ધ્યાન કેન્દ્રિત કરે છે. JEEમાં આ વિષય વાતાવરણીય પ્રદૂષણ, ઓઝોન સ્તરનું ક્ષય, ગ્રીનહાઉસ અસર જેવા મહત્વપૂર્ણ વિષયોને આવરી લે છે.

  • પર્યાવરણીય રસાયણ = પર્યાવરણ + રસાયણશાસ્ત્ર
  • વાયુ, જળ, મૃદા અને જૈવ મંડળ પર ધ્યાન
  • પ્રદૂષકો અને તેમના પર્યાવરણીય અસરોનો અભ્યાસ
  • JEEમાં વાતાવરણીય પ્રદૂષણ, ઓઝોન ક્ષય, ગ્રીનહાઉસ અસર મહત્વપૂર્ણ

વાયુ પ્રદૂષણ અને તેના સ્ત્રોત

વાયુ પ્રદૂષણ એ વાતાવરણમાં હાનિકારક પદાર્થોની હાજરી છે જે મનુષ્ય, પ્રાણી અને વનસ્પતિના સ્વાસ્થ્યને નુકસાન પહોંચાડે છે. મુખ્ય સ્ત્રોતોમાં વાહનો, ઉદ્યોગો, કોળસો અને લાકડાનું દહન, અને કુદરતી સ્ત્રોતો જેવા કે જ્વાળામુખી ફાટી નીકળવા સામેલ છે. પ્રાથમિક પ્રદૂષકો (CO, NOx, SO2, SPM) અને દ્વિતીયક પ્રદૂષકો (O3, PAN) મહત્વપૂર્ણ છે.

  • વાયુ પ્રદૂષણ = હાનિકારક પદાર્થોની વાતાવરણમાં હાજરી
  • મુખ્ય સ્ત્રોત: વાહનો, ઉદ્યોગો, કોળસો દહન
  • પ્રાથમિક પ્રદૂષકો: CO, NOx, SO2, SPM
  • દ્વિતીયક પ્રદૂષકો: O3 (ઓઝોન), PAN (પેરોક્સીએસીટાઇલ નાઇટ્રેટ)
  • ફોટોકેમિકલ ધૂમાડો = NOx + HC + સૂર્યપ્રકાશ
🧠 Trick: CO NOx SO2 SPM → પ્રાથમિક; O3 PAN → દ્વિતીયક

ગ્રીનહાઉસ અસર અને જલવાયુ પરિવર્તન

ગ્રીનહાઉસ અસર એ પૃથ્વીના વાતાવરણમાં ગ્રીનહાઉસ વાયુઓ (CO2, CH4, N2O, CFCs) દ્વારા ઉષ્માનું શોષણ અને પુનઃઉત્સર્જન છે, જેના કારણે પૃથ્વીનું તાપમાન વધે છે. આના કારણે જલવાયુ પરિવર્તન થાય છે, જે ગ્લોબલ વોર્મિંગ, હિમનદીઓનું પિગળવું અને સમુદ્ર સપાટીમાં વધારો જેવી સમસ્યાઓ ઉભી કરે છે. CO2 સૌથી મહત્વપૂર્ણ ગ્રીનહાઉસ વાયુ છે.

  • ગ્રીનહાઉસ અસર = ઉષ્મા શોષણ + પુનઃઉત્સર્જન
  • મુખ્ય વાયુઓ: CO2 (સૌથી મહત્વપૂર્ણ), CH4, N2O, CFCs
  • પરિણામ: ગ્લોબલ વોર્મિંગ, હિમનદીઓ પિગળવું, સમુદ્ર સપાટી વધારો
  • CO2નું સ્તર પૂર્વ-ઔદ્યોગિક કાળથી 280 ppm થી 400+ ppm સુધી વધ્યું
  • જલવાયુ પરિવર્તન = લાંબા ગાળાના હવામાન પરિવર્તન
🧠 Trick: CO2 CH4 N2O CFC → ગ્રીનહાઉસ વાયુઓ

ઓઝોન સ્તરનું ક્ષય અને તેના પરિણામો

ઓઝોન સ્તર (O3) પૃથ્વીના વાતાવરણના સ્ટ્રેટોસ્ફિયરમાં આવેલું છે અને તે સૂર્યના અલ્ટ્રાવાયોલેટ (UV) કિરણોથી રક્ષણ આપે છે. CFCs (ક્લોરોફ્લોરોકાર્બન) અને હેલોન જેવા રસાયણો ઓઝોન સ્તરને નુકસાન પહોંચાડે છે, જેના કારણે ઓઝોન છિદ્ર બને છે. આના કારણે ત્વચા કૅન્સર, મોતિયાબિંદ અને ઇમ્યુન સિસ્ટમ પર અસર થાય છે.

  • ઓઝોન સ્તર = સ્ટ્રેટોસ્ફિયરમાં O3નું સ્તર
  • રક્ષણ: UV કિરણોથી
  • ઓઝોન ક્ષયના કારણ: CFCs, હેલોન, NOx
  • પરિણામ: ત્વચા કૅન્સર, મોતિયાબિંદ, ઇમ્યુન સિસ્ટમ નબળી પડવી
  • મોન્ટ્રીયલ પ્રોટોકોલ (1987) એ CFCs પર પ્રતિબંધ મૂક્યો
🧠 Trick: CFCs → ક્લોરિન → O3 નાશ → UV કિરણો → કૅન્સર

જળ પ્રદૂષણ અને તેના સ્ત્રોત

જળ પ્રદૂષણ એ જળ સ્રોતોમાં હાનિકારક પદાર્થોની હાજરી છે, જે જળચર જીવન અને મનુષ્યના સ્વાસ્થ્યને નુકસાન પહોંચાડે છે. મુખ્ય સ્ત્રોતોમાં કચરો, ઉદ્યોગિક કચરો, ખેતીના રસાયણો (કીટનાશકો, ખાતરો), અને તેલના રિસાવ સામેલ છે. BOD (બાયોકેમિકલ ઓક્સિજન ડિમાન્ડ) અને COD (કેમિકલ ઓક્સિજન ડિમાન્ડ) જળ પ્રદૂષણના મહત્વપૂર્ણ પેરામીટર છે.

  • જળ પ્રદૂષણ = જળ સ્રોતોમાં હાનિકારક પદાર્થો
  • મુખ્ય સ્ત્રોત: કચરો, ઉદ્યોગિક કચરો, ખેતી રસાયણો, તેલ રિસાવ
  • BOD = જીવાણુઓ દ્વારા ઓક્સિજન વપરાશનો દર
  • COD = રાસાયણિક પદ્ધતિથી ઓક્સિજન વપરાશનો દર
  • યુટ્રોફિકેશન = ખાતરોથી જળાશયમાં શેવાળનો વધારો
🧠 Trick: BOD → જીવાણુ; COD → રસાયણ

મૃદા પ્રદૂષણ અને તેના પરિણામો

મૃદા પ્રદૂષણ એ મૃદામાં હાનિકારક પદાર્થોની હાજરી છે, જે મૃદાની ઉત્પાદકતા અને જૈવ વૈવિધ્યને નુકસાન પહોંચાડે છે. મુખ્ય સ્ત્રોતોમાં ઉદ્યોગિક કચરો, ખેતીના રસાયણો (કીટનાશકો, ખાતરો), પ્લાસ્ટિક કચરો, અને ખાણકામ સામેલ છે. મૃદા પ્રદૂષણના કારણે મૃદાની ઉત્પાદકતા ઘટે છે અને ખોરાક શૃંખલામાં વિષાક્ત પદાર્થોનો પ્રવેશ થાય છે.

  • મૃદા પ્રદૂષણ = મૃદામાં હાનિકારક પદાર્થો
  • મુખ્ય સ્ત્રોત: ઉદ્યોગિક કચરો, ખેતી રસાયણો, પ્લાસ્ટિક, ખાણકામ
  • પરિણામ: ઉત્પાદકતા ઘટે, જૈવ વૈવિધ્ય નુકસાન
  • બાયોરીમેડિએશન = જીવાણુઓ દ્વારા મૃદા શુદ્ધિકરણ
  • ખોરાક શૃંખલામાં વિષાક્ત પદાર્થોનો પ્રવેશ = બાયોએકમ્યુલેશન

પર્યાવરણીય નિયમન અને સંરક્ષણ

પર્યાવરણીય પ્રદૂષણને નિયંત્રિત કરવા અને પર્યાવરણનું સંરક્ષણ કરવા માટે વિવિધ પગલાં લેવામાં આવે છે. આમાં કાયદાઓ, નીતિઓ, અને તકનીકી ઉકેલો સામેલ છે. મોન્ટ્રીયલ પ્રોટોકોલ (ઓઝોન સ્તરનું રક્ષણ), ક્યોટો પ્રોટોકોલ (ગ્રીનહાઉસ વાયુઓનો ઉત્સર્જન ઘટાડવો), અને પેરિસ કરાર (જલવાયુ પરિવર્તન સામે લડવું) મહત્વપૂર્ણ આંતરરાષ્ટ્રીય કરારો છે.

  • મોન્ટ્રીયલ પ્રોટોકોલ (1987) → O3 સ્તરનું રક્ષણ
  • ક્યોટો પ્રોટોકોલ (1997) → ગ્રીનહાઉસ વાયુઓ ઘટાડવો
  • પેરિસ કરાર (2015) → જલવાયુ પરિવર્તન સામે લડવું
  • BOD અને COD માપન દ્વારા જળ પ્રદૂષણ નિયંત્રણ
  • બાયોરીમેડિએશન દ્વારા મૃદા પ્રદૂષણ નિયંત્રણ
🧠 Trick: મોન્ટ્રીયલ → O3; ક્યોટો → CO2; પેરિસ → જલવાયુ

⚡ Quick Revision

  • પર્યાવરણીય રસાયણ = પર્યાવરણ + રસાયણશાસ્ત્ર
  • વાયુ પ્રદૂષણ: પ્રાથમિક (CO, NOx, SO2, SPM) + દ્વિતીયક (O3, PAN)
  • ગ્રીનહાઉસ અસર: CO2, CH4, N2O, CFCs → ગ્લોબલ વોર્મિંગ
  • ઓઝોન ક્ષય: CFCs → ક્લોરિન → O3 નાશ → UV કિરણો
  • જળ પ્રદૂષણ: BOD, COD, યુટ્રોફિકેશન
  • મૃદા પ્રદૂષણ: ઉદ્યોગિક કચરો, ખેતી રસાયણો, બાયોએકમ્યુલેશન
  • નિયમન: મોન્ટ્રીયલ, ક્યોટો, પેરિસ કરાર
🎯 Exam Tip: પર્યાવરણીય રસાયણના પ્રશ્નોમાં પ્રદૂષકો, તેમના સ્ત્રોતો, અસરો અને નિયંત્રણ પદ્ધતિઓ પર ધ્યાન આપો. ઓઝોન ક્ષય અને ગ્રીનહાઉસ અસર જેવા વિષયો પર ખાસ ધ્યાન આપો, કારણ કે તે JEEમાં વારંવાર પૂછવામાં આવે છે.
