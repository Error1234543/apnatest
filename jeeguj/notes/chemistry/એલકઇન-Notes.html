એલ્કાઇન

📖 એલ્કાઇન (Alkynes)

પરિભાષા અને સૂત્ર

એલ્કાઇન હાઇડ્રોકાર્બનના સદસ્ય છે જેમાં કાર્બન-કાર્બન વચ્ચે ત્રિપલ બંધ (C≡C) હોય છે. સરળતમ એલ્કાઇન એથાઇન (C₂H₂) છે. સામાન્ય સૂત્ર CₙH₂ₙ₋₂ છે, જ્યાં n ≥ 2. આલ્કાઇનને એસિટિલીન સિરીઝ પણ કહેવાય છે.

  • ત્રિપલ બંધ (C≡C) ધરાવે છે
  • સામાન્ય સૂત્ર: CₙH₂ₙ₋₂
  • એથાઇન (C₂H₂) સરળતમ એલ્કાઇન છે
  • sp-હાઇબ્રિડાઇઝેશન ધરાવે છે
  • અસંતૃપ્ત હાઇડ્રોકાર્બન છે
🧠 Trick: ત્રિપલ બંધ = એલ્કાઇન, ડબલ બંધ = એલ્કીન, સિંગલ બંધ = એલ્કેન

નામકરણ (IUPAC)

એલ્કાઇનનું નામકરણ કરતી વખતે સૌથી લાંબી કાર્બન શૃંખલામાં ત્રિપલ બંધ ધરાવતી સ્થિતિને 'ઇન' પ્રત્યયથી અંતે લખવામાં આવે છે. ઉદા. CH≡CH → એથાઇન, CH₃-CH₂-C≡CH → બ્યુટ-1-ઇન.

  • લાંબી શૃંખલામાં ત્રિપલ બંધની સ્થિતિ નિર્ધારિત કરો
  • ત્રિપલ બંધની સ્થિતિ નંબરથી દર્શાવો
  • 'ઇન' પ્રત્યય વાપરો
  • શાખાઓને પ્રાથમિક શૃંખલા કરતાં પહેલા લખો
  • નામકરણમાં સૌથી નીચો નંબર ત્રિપલ બંધને આપો

બંધન અને જ્યોમેટ્રી

એલ્કાઇનમાં કાર્બન sp-હાઇબ્રિડાઇઝ્ડ હોય છે, જેના કારણે રેખીય જ્યોમેટ્રી બને છે. C≡C બંધ લંબાઈ 120 pm અને બંધ ઉર્જા 839 kJ/mol હોય છે. ત્રિપલ બંધમાં 1 σ-બંધ અને 2 π-બંધ હોય છે.

  • sp-હાઇબ્રિડાઇઝેશન
  • રેખીય જ્યોમેટ્રી (બંધ કોણ 180°)
  • C≡C બંધ લંબાઈ: 120 pm
  • બંધ ઉર્જા: 839 kJ/mol
  • 1 σ-બંધ + 2 π-બંધ
🧠 Trick: sp-હાઇબ્રિડ = રેખીય, sp² = ત્રિકોણીય, sp³ = ટેટ્રાહેડ્રલ

ભૌતિક ગુણધર્મો

એલ્કાઇનના ભૌતિક ગુણધર્મો એલ્કેન અને એલ્કીન કરતાં અલગ હોય છે. એથાઇન ગંધવિહીન, રંગવિહીન વાયુ છે. એલ્કાઇન પાણીમાં અલ્પ દ્રાવ્ય હોય છે પરંતુ કાર્બનિક દ્રાવકોમાં દ્રાવ્ય હોય છે. ઉચ્ચ અણુભાર ધરાવતા એલ્કાઇન પ્રવાહી અથવા ઘન સ્વરૂપે હોય છે.

  • એથાઇન: ગંધવિહીન, રંગવિહીન વાયુ
  • પાણીમાં અલ્પ દ્રાવ્ય
  • કાર્બનિક દ્રાવકોમાં દ્રાવ્ય
  • ઉચ્ચ અણુભારવાળા એલ્કાઇન પ્રવાહી/ઘન
  • ગલનબિંદુ અને ઉત્કલનબિંદુ એલ્કેન કરતાં ઉચ્ચ

રાસાયણિક પ્રક્રિયાઓ

એલ્કાઇન રાસાયણિક દૃષ્ટિએ ખૂબ જ સક્રિય હોય છે. મુખ્ય પ્રક્રિયાઓમાં જોડાણ (એડિશન), બદલાણી (સબ્સ્ટિટ્યુશન), અને ઓક્સિડેશન પ્રક્રિયાઓનો સમાવેશ થાય છે. ઉદા. હાઇડ્રોજનેશન, હેલોજનેશન, હાઇડ્રોહેલોજનેશન, અને ઓઝોનોલિસિસ.

  • જોડાણ પ્રક્રિયાઓ (H₂, X₂, HX, H₂O)
  • બદલાણી પ્રક્રિયાઓ (મેટલ સાથે)
  • ઓક્સિડેશન (KMnO₄ સાથે)
  • એસિટિલાઇડ આયન બનાવે છે (સોડિયમ સાથે)
  • ઓઝોનોલિસિસથી કાર્બોક્સિલિક એસિડ બને છે
🧠 Trick: એલ્કાઇન + H₂ → એલ્કેન, એલ્કાઇન + X₂ → ડાઇહેલાઇડ

તૈયારી પધ્ધતિઓ

એલ્કાઇનની તૈયારી માટે વિકર્ણી ડાઇહેલાઇડના ડિહાઇડ્રોહેલોજનેશન, એસિટિલીનથી વિકર્ણી એલ્કાઇનની તૈયારી, અને કાર્બાઇડ વિક્રિયા મહત્વની પધ્ધતિઓ છે. ઉદા. CH₂=CH₂ + Br₂ → CH₂Br-CH₂Br → (alc. KOH) CH≡CH.

  • ડાઇહેલાઇડનું ડિહાઇડ્રોહેલોજનેશન (alc. KOH)
  • વિકર્ણી એલ્કીનથી એલ્કાઇન (Br₂ + alc. KOH)
  • કેલ્શિયમ કાર્બાઇડથી એસિટિલીન (CaC₂ + H₂O → C₂H₂)
  • વર્ટ્ઝ પ્રક્રિયા (2R-X + 2Na → R-R)
  • કોલ્બ પ્રક્રિયા (R-COONa + NaOH → R-H)
🧠 Trick: ડિહાઇડ્રોહેલોજનેશન = હેલોજન કાઢીને ત્રિપલ બંધ બનાવો

મહત્વપૂર્ણ એલ્કાઇન અને ઉપયોગો

એથાઇન (C₂H₂) એ સૌથી મહત્વપૂર્ણ એલ્કાઇન છે, જેનો ઉપયોગ વેલ્ડીંગ, રબર ઉત્પાદન, અને પ્લાસ્ટિક ઉત્પાદનમાં થાય છે. પ્રોપાઇન (C₃H₄) અને બ્યુટાઇન (C₄H₆) પણ ઉદ્યોગિક મહત્વ ધરાવે છે.

  • એથાઇન: વેલ્ડીંગ, રબર, પ્લાસ્ટિક
  • પ્રોપાઇન: ઓક્સી-એસિટિલીન વેલ્ડીંગ
  • બ્યુટાઇન: સિંથેટિક રબર
  • એસિટિલીન: વીજળીનો સ્રોત (પહેલાં)
  • ઉદ્યોગમાં મહત્વપૂર્ણ કાચો માલ

  • નામકરણમાં 'ઇન' પ્રત્યય વાપરાય છે
