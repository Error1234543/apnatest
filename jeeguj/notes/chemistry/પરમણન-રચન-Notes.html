પરમાણુની રચના

📖 પરમાણુની રચના

પરમાણુનો મૂળભૂત ઘટક

પરમાણુ એ પદાર્થનો સૌથી નાનો એકમ છે જે રાસાયણિક પ્રક્રિયાઓમાં ભાગ લે છે. તે ઇલેક્ટ્રૉન, પ્રોટૉન અને ન્યૂટ્રૉનના બનેલો છે. પ્રોટૉન અને ન્યૂટ્રૉન કોષકેન્દ્રમાં જોવા મળે છે, જ્યારે ઇલેક્ટ્રૉન કોષકેન્દ્રની આસપાસ કક્ષાઓમાં ફરે છે.

  • પરમાણુ = પ્રોટૉન (p) + ન્યૂટ્રૉન (n) + ઇલેક્ટ્રૉન (e⁻)
  • પ્રોટૉન અને ન્યૂટ્રૉન કોષકેન્દ્રમાં હોય છે
  • ઇલેક્ટ્રૉન કોષકેન્દ્રની બહાર કક્ષાઓમાં ગતિ કરે છે
  • પ્રોટૉન ધન વીજભારિત, ઇલેક્ટ્રૉન ઋણ વીજભારિત, ન્યૂટ્રૉન વીજભારરહિત
🧠 Trick: પ્રો-ન્યૂ-ઇ = પ+ન+ઇ

પરમાણુ ક્રમાંક અને દળ ક્રમાંક

પરમાણુ ક્રમાંક (Z) એ કોષકેન્દ્રમાં પ્રોટૉનની સંખ્યા દર્શાવે છે, જ્યારે દળ ક્રમાંક (A) એ પ્રોટૉન અને ન્યૂટ્રૉનના સરવાળાની સંખ્યા દર્શાવે છે. પરમાણુનું દળ A ≈ પ્રોટૉન + ન્યૂટ્રૉન (ઇલેક્ટ્રૉનનું દળ નગણ્ય).

  • Z = પ્રોટૉનની સંખ્યા = ઇલેક્ટ્રૉનની સંખ્યા (તટસ્થ પરમાણુમાં)
  • A = પ્રોટૉન + ન્યૂટ્રૉન
  • સમસ્થાનિકો: Z સરખો, A જુદો (જે. ન્યૂટ્રૉન જુદા)
  • દળ ક્રમાંક - પરમાણુ ક્રમાંક = ન્યૂટ્રૉનની સંખ્યા
🧠 Trick: Z = p = e⁻, A = p + n

થૉમસનનો પરમાણુ મોડલ

થૉમસનના મોડલ અનુસાર, પરમાણુ એક ધન વીજભારિત ગોળો છે જેમાં ઇલેક્ટ્રૉન એમ્બેડેડ હોય છે, જેમ કિશમિશ કેકમાં હોય છે. આ મોડલને 'કિશમિશ પુડીંગ મોડલ' પણ કહેવાય છે.

  • પરમાણુ ધન વીજભારિત ગોળો છે
  • ઇલેક્ટ્રૉન ગોળામાં વિતરિત હોય છે
  • મોડલ રદરફોર્ડના પ્રયોગ દ્વારા ખોટો પડ્યો

રદરફોર્ડનો પરમાણુ મોડલ

રદરફોર્ડના અલ્ફા-કણ પ્રકીર્ણન પ્રયોગ દ્વારા જાણવા મળ્યું કે પરમાણુનો મોટાભાગનો દળ અને ધન વીજભાર કોષકેન્દ્રમાં કેન્દ્રિત છે. ઇલેક્ટ્રૉન કોષકેન્દ્રની આસપાસ ખૂબ જ ઝડપથી ફરે છે.

  • કોષકેન્દ્ર ખૂબ જ નાનો અને ઘન છે
  • પરમાણુનો મોટાભાગનો દળ કોષકેન્દ્રમાં છે
  • ઇલેક્ટ્રૉન કોષકેન્દ્રની આસપાસ કક્ષાઓમાં ફરે છે
  • પરમાણુ મોટેભાગે ખાલી જગ્યા છે
🧠 Trick: રદરફોર્ડ = કોષકેન્દ્ર + ખાલી જગ્યા

બોહ્રનો પરમાણુ મોડલ

બોહ્રના મોડલ અનુસાર, ઇલેક્ટ્રૉન નિયત કક્ષાઓમાં ફરે છે જ્યાં તેમની ઊર્જા નિયત હોય છે. ઇલેક્ટ્રૉન એક કક્ષાથી બીજી કક્ષામાં કૂદી શકે છે, પરંતુ માત્ર ઊર્જા શોષી અથવા ઉત્સર્જીને.

  • ઇલેક્ટ્રૉન નિયત કક્ષાઓમાં ફરે છે (n=1,2,3...)
  • કક્ષા n માટે ઊર્જા Eₙ = -13.6/n² eV
  • ઊર્જા શોષીને ઉચ્ચ કક્ષામાં જાય, ઉત્સર્જીને નીચી કક્ષામાં આવે
  • લાઇમન શ્રેણી: UV, બાલ્મર: દૃશ્ય, પશ્ચેન: IR
🧠 Trick: બોહ્ર = કક્ષા + ઊર્જા કૂદો

ક્વોન્ટમ યાંત્રિક મોડલ

આધુનિક મોડલ અનુસાર, ઇલેક્ટ્રૉન કોષકેન્દ્રની આસપાસ પ્રોબેબિલિટી વિતરણ (ઓર્બિટલ)માં જોવા મળે છે. ઓર્બિટલ એ ત્રિપરિમાણીય જગ્યા છે જ્યાં ઇલેક્ટ્રૉન મળવાની સંભાવના 90% હોય છે.

  • ઇલેક્ટ્રૉન ઓર્બિટલમાં હોય છે, કક્ષામાં નહીં
  • હાઇઝનબર્ગનો અનિશ્ચિતતાનો સિદ્ધાંત: x·p ≥ ħ/2
  • ઓર્બિટલને n, l, m, s ક્વોન્ટમ સંખ્યાઓ વડે વર્ણવવામાં આવે છે
  • s, p, d, f ઓર્બિટલના આકાર જુદા જુદા હોય છે
🧠 Trick: ક્વોન્ટમ = ઓર્બિટલ + અનિશ્ચિતતા

પરમાણુની ત્રિજ્યા અને આયનીકરણ ઊર્જા

પરમાણુની ત્રિજ્યા કોષકેન્દ્રથી બહારતમ કક્ષા સુધીના અંતર તરીકે વ્યાખ્યાયિત છે. આયનીકરણ ઊર્જા એ પરમાણુમાંથી ઇલેક્ટ્રૉન કાઢવા માટે જરૂરી ઊર્જા છે. બંને પરમાણુ ક્રમાંક અને કક્ષાના આધારે બદલાય છે.

  • પરમાણુ ત્રિજ્યા આર = r₀A^(1/3) (r₀ ≈ 1.2 fm)
  • આયનીકરણ ઊર્જા કોષકેન્દ્રીય વીજભાર અને ઇલેક્ટ્રૉનની કક્ષા પર આધાર રાખે છે
  • પરમાણુ ક્રમાંક વધે ત્યારે આયનીકરણ ઊર્જા વધે છે
  • અલ્કલી ધાતુઓની આયનીકરણ ઊર્જા સૌથી ઓછી હોય છે

⚡ Quick Revision

  • પરમાણુ = પ્રોટૉન + ન્યૂટ્રૉન + ઇલેક્ટ્રૉન
  • Z = પ્રોટૉનની સંખ્યા, A = પ્રોટૉન + ન્યૂટ્રૉન
  • થૉમસન: કિશમિશ પુડીંગ મોડલ
  • રદરફોર્ડ: કોષકેન્દ્ર + ખાલી જગ્યા
  • બોહ્ર: નિયત કક્ષા + ઊર્જા કૂદો
  • ક્વોન્ટમ: ઓર્બિટલ + અનિશ્ચિતતા
  • પરમાણુ ત્રિજ્યા = r₀A^(1/3)
  • આયનીકરણ ઊર્જા = કોષકેન્દ્રીય વીજભાર અને કક્ષા પર આધારિત
  • સમસ્થાનિકો: Z સરખો, A જુદો
  • ઇલેક્ટ્રૉન ઊર્જા Eₙ = -13.6/n² eV
🎯 Exam Tip: પરમાણુની રચના પરના પ્રશ્નોમાં કોષકેન્દ્ર, ઇલેક્ટ્રૉન કક્ષા, Z, A, અને ક્વોન્ટમ સંખ્યાઓ પર ધ્યાન કેન્દ્રિત કરો. બોહ્ર મોડલ અને ક્વોન્ટમ મોડલ વચ્ચેનો તફાવત સ્પષ્ટ કરો.
