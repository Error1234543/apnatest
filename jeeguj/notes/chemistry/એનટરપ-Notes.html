એન્ટ્રોપી

📖 એન્ટ્રોપી

એન્ટ્રોપીની વ્યાખ્યા

એન્ટ્રોપી એ થર્મોડાયનેમિક્સનો મહત્વપૂર્ણ ગુણધર્મ છે જે સિસ્ટમની અવ્યવસ્થા અથવા અસ્થિરતાનું માપ છે. તે સિસ્ટમની માઇક્રોસ્કોપિક અવસ્થાઓની સંખ્યાનું પ્રમાણ છે. JEE માટે, એન્ટ્રોપીને ΔS = Q_rev/T દ્વારા વ્યાખ્યાયિત કરવામાં આવે છે, જ્યાં Q_rev એ રિવર્સિબલ પ્રક્રિયામાં હીટ ટ્રાન્સફર છે અને T એ તાપમાન છે.

  • એન્ટ્રોપી (S) એ સિસ્ટમની અવ્યવસ્થાનું માપ છે.
  • SI એકમ: J/K (Joule per Kelvin).
  • અવ્યવસ્થા વધે ત્યારે એન્ટ્રોપી વધે છે.
  • ડેલ્ટા S = Q_rev / T (રિવર્સિબલ પ્રક્રિયા માટે).
🧠 Trick: S = Disorder, More Disorder = More S

એન્ટ્રોપી અને દ્વિતીય નિયમ

થર્મોડાયનેમિક્સનો દ્વિતીય નિયમ કહે છે કે બંધ સિસ્ટમ માટે, એન્ટ્રોપી હંમેશા વધે છે અથવા સ્થિર રહે છે (ΔS ≥ 0). આ નિયમ પ્રકૃતિમાં પ્રક્રિયાઓની દિશા નક્કી કરે છે. ઉદાહરણ તરીકે, ગેસનું વિસ્તરણ એ એન્ટ્રોપી વધારતી પ્રક્રિયા છે.

  • બંધ સિસ્ટમમાં ΔS ≥ 0 (દ્વિતીય નિયમ).
  • પ્રકૃતિમાં સ્વત:સ્ફૂર્ત પ્રક્રિયાઓ એન્ટ્રોપી વધારે છે.
  • ઉદાહરણ: ગેસનું વિસ્તરણ, બરફનું પીગળવું.
  • દ્વિતીય નિયમ એન્ટ્રોપીના ભાષાંતર દ્વારા સમજાવી શકાય છે.
🧠 Trick: Nature Loves Disorder (ΔS ≥ 0)

એન્ટ્રોપી બદલાવની ગણતરી

એન્ટ્રોપી બદલાવ (ΔS)ની ગણતરી થર્મોડાયનેમિક ડેટા અથવા સૂત્રો દ્વારા કરવામાં આવે છે. ઉદાહરણ તરીકે, તાપમાન બદલાવ માટે ΔS = nCv ln(T2/T1) (સ્થિર વોલ્યુમ) અથવા ΔS = nCp ln(T2/T1) (સ્થિર દબાણ). વાયુના વિસ્તરણ માટે ΔS = nR ln(V2/V1) (આઇસોથર્મલ).

  • ΔS = nCv ln(T2/T1) (સ્થિર વોલ્યુમ).
  • ΔS = nCp ln(T2/T1) (સ્થિર દબાણ).
  • ΔS = nR ln(V2/V1) (આઇસોથર્મલ વિસ્તરણ).
  • ΔS = ΔH/T (ફેઝ બદલાવ માટે, જેમ કે પીગળવું અથવા બાષ્પીભવન).

એન્ટ્રોપી અને પ્રક્રિયાની સ્વત:સ્ફૂર્તતા

પ્રક્રિયાની સ્વત:સ્ફૂર્તતા નક્કી કરવા માટે, ગિબ્સ મુક્ત ઉર્જા (ΔG)નો ઉપયોગ કરવામાં આવે છે: ΔG = ΔH - TΔS. જો ΔG < 0, તો પ્રક્રિયા સ્વત:સ્ફૂર્ત છે. એન્ટ્રોપી (ΔS) અને એનથાલ્પી (ΔH) બંને પ્રક્રિયાની દિશા નક્કી કરે છે.

  • ΔG = ΔH - TΔS (ગિબ્સ મુક્ત ઉર્જાનું સૂત્ર).
  • ΔG < 0: સ્વત:સ્ફૂર્ત પ્રક્રિયા.
  • ΔS > 0: એન્ટ્રોપી વધારતી પ્રક્રિયા (અવ્યવસ્થા વધે).
  • ઉચ્ચ તાપમાને TΔSનો પ્રભાવ વધે છે.
🧠 Trick: G = H - TS (G for Go, H for Heat, S for Disorder)

એન્ટ્રોપી અને રાસાયણિક સમતોલન

રાસાયણિક સમતોલનમાં, સિસ્ટમની એન્ટ્રોપી મહત્તમ હોય છે. સમતોલન અવસ્થામાં, ΔG = 0, જેથી ΔH = TΔS. એન્ટ્રોપી બદલાવ સમતોલન સ્થળાંતરને અસર કરે છે, ખાસ કરીને જ્યારે તાપમાન બદલાય છે.

  • સમતોલનમાં ΔG = 0 ⇒ ΔH = TΔS.
  • એન્ટ્રોપી સમતોલન સ્થળાંતરને અસર કરે છે.
  • તાપમાન વધારવાથી એન્ટ્રોપી વધારતી પ્રક્રિયાઓ અનુકૂળ બને છે.
  • ઉદાહરણ: એમોનિયાના સંશ્લેષણમાં, નીચા તાપમાને ΔS < 0 હોવા છતાં પ્રક્રિયા અનુકૂળ બને છે.

એન્ટ્રોપીના વ્યાવહારિક ઉદાહરણો

એન્ટ્રોપીના વ્યાવહારિક ઉદાહરણોમાં ગેસનું વિસ્તરણ, બરફનું પીગળવું, અને રાસાયણિક પ્રક્રિયાઓ જેમ કે કોમ્બસ્ટન શામેલ છે. આ પ્રક્રિયાઓમાં, સિસ્ટમની અવ્યવસ્થા વધે છે, જે એન્ટ્રોપી વધારે છે.

  • ગેસનું વિસ્તરણ: ΔS > 0.
  • બરફનું પીગળવું: ΔS > 0 (ઘન → દ્રવ).
  • કોમ્બસ્ટન: ગેસી પદાર્થોનું નિર્માણ ΔS વધારે છે.
  • પ્રકૃતિમાં સ્વત:સ્ફૂર્ત પ્રક્રિયાઓ હંમેશા એન્ટ્રોપી વધારે છે.
🧠 Trick: Gas Expands = Entropy Increases

⚡ Quick Revision

  • એન્ટ્રોપી એ સિસ્ટમની અવ્યવસ્થાનું માપ છે.
  • ΔS = Q_rev / T (રિવર્સિબલ પ્રક્રિયા માટે).
  • દ્વિતીય નિયમ: ΔS ≥ 0 (બંધ સિસ્ટમ માટે).
  • ΔG = ΔH - TΔS (ગિબ્સ મુક્ત ઉર્જા).
  • ΔS > 0: એન્ટ્રોપી વધારતી પ્રક્રિયા.
  • ΔS = nR ln(V2/V1) (આઇસોથર્મલ વિસ્તરણ).
  • સમતોલનમાં ΔG = 0 ⇒ ΔH = TΔS.
  • ગેસનું વિસ્તરણ અને બરફનું પીગળવું એ એન્ટ્રોપી વધારતી પ્રક્રિયાઓ છે.
  • તાપમાન વધારવાથી એન્ટ્રોપી વધારતી પ્રક્રિયાઓ અનુકૂળ બને છે.
  • એન્ટ્રોપીનું SI એકમ J/K છે.
🎯 Exam Tip: JEEમાં એન્ટ્રોપીના પ્રશ્નો માટે, ΔSની ગણતરી અને દ્વિતીય નિયમના અર્થને સ્પષ્ટ કરવા પર ધ્યાન કેન્દ્રિત કરો. ગિબ્સ મુક્ત ઉર્જા (ΔG) અને એન્ટ્રોપી (ΔS) વચ્ચેના સંબંધને યાદ રાખો.
