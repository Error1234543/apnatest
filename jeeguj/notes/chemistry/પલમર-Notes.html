પોલિમર

📖 પોલિમર

પોલિમરની વ્યાખ્યા અને વર્ગીકરણ

પોલિમર મોટા અણુઓ છે જે નાના અણુઓ (મોનોમર)ના પુનરાવર્તિત એકમોથી બને છે. NCERT અનુસાર, પોલિમરને કુદરતી (જેમકે સેલ્યુલોઝ, સ્ટાર્ચ) અને કૃત્રિમ (જેમકે પોલિથિન, નાયલોન)માં વર્ગીકૃત કરવામાં આવે છે. આ ઉપરાંત, સંરચના અનુસાર રેખીય, શાખાયુક્ત અને ત્રિપરિમાણીય પોલિમર પણ હોય છે.

  • પોલિમર = પોલી (બહુ) + મર (એકમ)
  • કુદરતી પોલિમર: સેલ્યુલોઝ, સ્ટાર્ચ, પ્રોટીન
  • કૃત્રિમ પોલિમર: પોલિથિન, PVC, નાયલોન-6,6
  • રેખીય પોલિમર: હાઈ-ડેન્સિટી પોલિઇથિલીન (HDPE)
  • ત્રિપરિમાણીય પોલિમર: બેકેલાઇટ, મેલામાઇન
🧠 Trick: કુદરતી = ક, કૃત્રિમ = કૃ, રેખીય = ર, શાખાયુક્ત = શ, ત્રિપરિમાણીય = ત

પોલિમરીકરણની પદ્ધતિઓ

પોલિમરીકરણ બે મુખ્ય પદ્ધતિઓ દ્વારા થાય છે: ૧) સંયોજન પોલિમરીકરણ (અલ્કીન/ડાયનથી) અને ૨) સઘનન પોલિમરીકરણ (બાયફંક્શનલ મોનોમરથી). સંયોજનમાં ડબલ બોન્ડ તૂટીને નવા બોન્ડ બને છે, જ્યારે સઘનનમાં નાના અણુઓ (જેમકે H2O) બહાર નીકળે છે.

  • સંયોજન પોલિમરીકરણ: ઇથિલીન → પોલિઇથિલીન
  • સઘનન પોલિમરીકરણ: હેક્સામિથિલીન ડાયએમાઇન + એડિપિક એસિડ → નાયલોન-6,6
  • ફ્રી રેડિકલ પોલિમરીકરણ: સ્ટાયરિન → પોલિસ્ટાયરિન
  • આયનિક પોલિમરીકરણ: ઇથિલીન ઓક્સાઇડ → પોલિઇથિલીન ગ્લાયકોલ
🧠 Trick: સંયોજન = સ, સઘનન = સગ

પોલિમરની ભૌતિક અવસ્થા અને ગુણધર્મો

પોલિમરની ભૌતિક અવસ્થા તેમના આંતરઅણુ બળો પર આધાર રાખે છે. એલાસ્ટોમર (રબર)માં કમનસીબ બળો હોય છે, જ્યારે ફાઇબર (નાયલોન)માં મજબૂત હાઇડ્રોજન બોન્ડ હોય છે. થર્મોપ્લાસ્ટિક (PVC) ગરમ કરતાં નરમ થાય છે, જ્યારે થર્મોસેટિંગ (બેકેલાઇટ) ગરમ કરતાં કઠણ થાય છે.

  • એલાસ્ટોમર: નેચરલ રબર, નિયોપ્રીન (સિન્થેટિક)
  • ફાઇબર: નાયલોન-6,6, ટેરિલીન (Dacron)
  • થર્મોપ્લાસ્ટિક: પોલિથિન, પોલિપ્રોપિલીન
  • થર્મોસેટિંગ: બેકેલાઇટ, મેલામાઇન-ફોર્માલ્ડિહાઇડ
  • પોલિમરનું કાચબિંદુ (Tg) અને ગલનબિંદુ (Tm) મહત્વના ગુણધર્મો છે
🧠 Trick: એલાસ્ટોમર = એ, ફાઇબર = ફ, થર્મોપ્લાસ્ટિક = થપ, થર્મોસેટિંગ = થસ

વ્યાવસાયિક મહત્વના પોલિમર

JEE Main માટે મહત્વના પોલિમરમાં નાયલોન-6,6 (પહેલા વપરાયેલ કૃત્રિમ ફાઇબર), ટેફલોન (PTFE, નોન-સ્ટિક કૂકવેર), અને બુના-R (સિન્થેટિક રબર)નો સમાવેશ થાય છે. નાયલોન-6,6 હેક્સામિથિલીન ડાયએમાઇન અને એડિપિક એસિડના સઘનનથી બને છે.

  • નાયલોન-6,6: હેક્સામિથિલીન ડાયએમાઇન + એડિપિક એસિડ
  • ટેફલોન (PTFE): ટેટ્રાફ્લુઓરો ઇથિલીનનું પોલિમર
  • બુના-R: 1,3-બ્યુટાડાયન + સ્ટાયરિન (SBR રબર)
  • પોલિએસ્ટર: ટેરિફ્થેલિક એસિડ + ઇથિલીન ગ્લાયકોલ (ટેરિલીન)
  • પોલીવિનાઇલ ક્લોરાઇડ (PVC): વિનાઇલ ક્લોરાઇડનું પોલિમર
🧠 Trick: નાયલોન = ના, ટેફલોન = ટે, બુના-R = બુ

પોલિમરના ઉપયોગો

પોલિમરનો ઉપયોગ દૈનિક જીવનમાં થાય છે જેમકે પ્લાસ્ટિકની બોટલ (PET), કપડાં (નાયલોન, પોલિએસ્ટર), અને ચિકિત્સા ક્ષેત્રે (પોલિપ્રોપિલીનના સૂત્ર). બાયોડિગ્રેડેબલ પોલિમર (જેમકે PHBV) પર્યાવરણ અનુકૂળ છે.

  • PET: પેકેજિંગ (બોટલ)
  • નાયલોન: કપડાં, રસ્સા
  • ટેફલોન: નોન-સ્ટિક કૂકવેર
  • પોલિપ્રોપિલીન: ચિકિત્સા સૂત્ર
  • PHBV: બાયોડિગ્રેડેબલ પોલિમર

પોલિમર અને પર્યાવરણ

પોલિમરના નિકાલની સમસ્યા માટે બાયોડિગ્રેડેબલ પોલિમર (જેમકે પોલિહાઇડ્રોક્સીબ્યુટાઇરેટ) વિકસાવવામાં આવ્યા છે. આ પોલિમર સૂક્ષ્મજીવો દ્વારા તોડી શકાય છે, જેથી પર્યાવરણને નુકસાન થતું નથી.

  • બાયોડિગ્રેડેબલ પોલિમર: PHBV, PLA
  • પર્યાવરણ અનુકૂળ પોલિમરનો ઉપયોગ વધારવો
  • પ્લાસ્ટિક કચરાનું પુનઃચક્રીકરણ મહત્વનું છે
  • પોલિથિનના બેગ પર પ્રતિબંધ લગાવવો

પોલિમર સંબંધી મહત્વના પ્રશ્નો (JEE Main)

JEE Mainમાં પોલિમરના પ્રશ્નો મુખ્યત્વે વર્ગીકરણ, પોલિમરીકરણ પદ્ધતિઓ, અને વ્યાવસાયિક પોલિમર પર આધારિત હોય છે. નાયલોન-6,6 અને બેકેલાઇટના સંરચનાને સમજવું મહત્વનું છે.

  • નાયલોન-6,6ની સંરચના: એમાઇડ બોન્ડ
  • બેકેલાઇટ: ફિનોલ + ફોર્માલ્ડિહાઇડ
  • પોલિથિન: ઇથિલીનનું પોલિમર
  • ટેફલોન: ટેટ્રાફ્લુઓરો ઇથિલીનનું પોલિમર

⚡ Quick Revision

  • પોલિમર = મોનોમરના પુનરાવર્તિત એકમો
  • કુદરતી પોલિમર: સેલ્યુલોઝ, સ્ટાર્ચ, પ્રોટીન
  • કૃત્રિમ પોલિમર: પોલિથિન, PVC, નાયલોન-6,6
  • સંયોજન પોલિમરીકરણ: ડબલ બોન્ડ તૂટીને નવા બોન્ડ
  • સઘનન પોલિમરીકરણ: નાના અણુઓ બહાર નીકળે છે
  • થર્મોપ્લાસ્ટિક: ગરમ કરતાં નરમ થાય (PVC)
  • થર્મોસેટિંગ: ગરમ કરતાં કઠણ થાય (બેકેલાઇટ)
  • નાયલોન-6,6: હેક્સામિથિલીન ડાયએમાઇન + એડિપિક એસિડ
  • ટેફલોન (PTFE): ટેટ્રાફ્લુઓરો ઇથિલીનનું પોલિમર
  • બાયોડિગ્રેડેબલ પોલિમર: PHBV, PLA
🎯 Exam Tip: પોલિમરના પ્રશ્નો માટે મોનોમર, પોલિમરીકરણ પદ્ધતિ, અને વ્યાવસાયિક ઉપયોગો યાદ રાખો. નાયલોન-6,6 અને બેકેલાઇટની સંરચના પર ખાસ ધ્યાન આપો.
