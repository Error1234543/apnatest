દ્રાવ્યતા

📖 દ્રાવ્યતા

દ્રાવ્યતા શું છે?

દ્રાવ્યતા એટલે કોઈ પદાર્થ (દ્રાવ્ય)નું આપેલા દ્રાવકમાં મહત્તમ પ્રમાણમાં ઓગળવાની ક્ષમતા. તેને સામાન્ય રીતે 100 ગ્રામ દ્રાવકમાં ઓગળેલા દ્રાવ્યના ગ્રામમાં દર્શાવાય છે. દ્રાવ્યતા તાપમાન, દબાણ અને દ્રાવ્ય-દ્રાવકના પ્રકાર પર આધારિત હોય છે.

  • દ્રાવ્યતા = દ્રાવ્યનું મહત્તમ દળ / દ્રાવકનું દળ × 100
  • સંતૃપ્ત દ્રાવણમાં દ્રાવ્યતા મહત્તમ હોય છે
  • અસંતૃપ્ત દ્રાવણમાં વધુ દ્રાવ્ય ઓગાળી શકાય છે
🧠 Trick: દ્રાવ્યતા = દ્રાવ્યનો દ્રાવક સાથેનો 'પ્રેમ' (સંબંધ)

દ્રાવ્યતાને અસર કરતા પરિબળો

તાપમાન વધતા ઘન પદાર્થોની દ્રાવ્યતા સામાન્ય રીતે વધે છે, જ્યારે વાયુઓની ઘટે છે. દબાણ વાયુઓની દ્રાવ્યતા પર સીધી અસર કરે છે (હેનરીનો નિયમ). દ્રાવ્ય અને દ્રાવકના કણો વચ્ચેના આંતરઆણ્વીય બળો પણ દ્રાવ્યતા નક્કી કરે છે.

  • તાપમાન ↑ → ઘનની દ્રાવ્યતા ↑, વાયુની દ્રાવ્યતા ↓
  • દબાણ ↑ → વાયુની દ્રાવ્યતા ↑ (હેનરીનો નિયમ)
  • સમાન સમાનને ઓગાળે (Like dissolves like)
🧠 Trick: ગરમી ઘનને ખુશ કરે, વાયુને દુઃખી

હેનરીનો નિયમ

હેનરીના નિયમ મુજબ, નિશ્ચિત તાપમાને વાયુની દ્રાવ્યતા તેના દ્રાવણ પરના આંશિક દબાણના સમપ્રમાણમાં હોય છે. ગાણિતિક રીતે: S = kH × P, જ્યાં S દ્રાવ્યતા, kH હેનરીનો અચળાંક અને P વાયુનું આંશિક દબાણ છે.

  • S ∝ P (નિશ્ચિત તાપમાને)
  • kH તાપમાન પર આધારિત
  • કાર્બોનેટેડ પીણાંમાં CO₂ ની દ્રાવ્યતા માટે લાગુ
🧠 Trick: હેનરીનો નિયમ: વધુ દબાણ, વધુ વાયુ અંદર

દ્રાવ્યતા ગુણાકાર (Ksp)

દ્રાવ્યતા ગુણાકાર (Ksp) એ અવક્ષેપિત ક્ષારના સંતૃપ્ત દ્રાવણમાં આયનોની સાંદ્રતાનો ગુણાકાર છે. તે દ્રાવ્યતાનું માપ છે - Ksp વધારે તો દ્રાવ્યતા વધારે. ઉદાહરણ: AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq), Ksp = [Ag⁺][Cl⁻].

  • Ksp = આયનોની સાંદ્રતાનો ગુણાકાર
  • Ksp ↑ → દ્રાવ્યતા ↑
  • સામાન્ય આયન અસરથી દ્રાવ્યતા ઘટે છે
🧠 Trick: Ksp = ક્ષારની 'શક્તિ' (દ્રાવ્યતા)

સામાન્ય આયન અસર

જો દ્રાવણમાં પહેલેથી જ કોઈ આયન હાજર હોય, તો તે જ આયન ધરાવતા ક્ષારની દ્રાવ્યતા ઘટે છે. આ લ શૅટેલિયરના સિદ્ધાંત મુજબ છે. ઉદાહરણ: NaCl ઉમેરવાથી AgCl ની દ્રાવ્યતા ઘટે છે કારણ કે Cl⁻ આયન પહેલેથી હાજર છે.

  • સમાન આયન → દ્રાવ્યતા ↓
  • લ શૅટેલિયરનો સિદ્ધાંત લાગુ
  • અવક્ષેપન પ્રક્રિયામાં ઉપયોગી
🧠 Trick: સમાન આયન = દ્રાવ્યતાનો 'દુશ્મન'

દ્રાવ્યતા અને ઉષ્મા

દ્રાવ્યતા પ્રક્રિયા ઉષ્માક્ષેપક કે ઉષ્માશોષક હોઈ શકે. ઉષ્માક્ષેપક દ્રાવ્યતા તાપમાન વધતા ઘટે છે (લ શૅટેલિયર), જ્યારે ઉષ્માશોષક દ્રાવ્યતા તાપમાન વધતા વધે છે. ઉદાહરણ: NaOH ઉષ્માક્ષેપક દ્રાવ્ય છે, જ્યારે KNO₃ ઉષ્માશોષક છે.

  • ઉષ્માક્ષેપક: તાપમાન ↑ → દ્રાવ્યતા ↓
  • ઉષ્માશોષક: તાપમાન ↑ → દ્રાવ્યતા ↑
  • ΔH_solvation નું મહત્વ
🧠 Trick: ગરમી આપો → ઉષ્માશોષક ખુશ, ઉષ્માક્ષેપક નારાજ

⚡ Quick Revision

  • દ્રાવ્યતા = દ્રાવ્યનું મહત્તમ દળ / દ્રાવકનું દળ × 100
  • તાપમાન ↑ → ઘનની દ્રાવ્યતા ↑, વાયુની ↓
  • હેનરીનો નિયમ: S = kH × P (વાયુઓ માટે)
  • Ksp = આયનોની સાંદ્રતાનો ગુણાકાર (અવક્ષેપિત ક્ષાર માટે)
  • સામાન્ય આયન અસર → દ્રાવ્યતા ઘટે
  • ઉષ્માક્ષેપક દ્રાવ્યતા તાપમાન ↑ → ઘટે
  • ઉષ્માશોષક દ્રાવ્યતા તાપમાન ↑ → વધે
  • Like dissolves like: ધ્રુવીય દ્રાવક ધ્રુવીય દ્રાવ્ય ઓગાળે
  • દબાણ ↑ → વાયુની દ્રાવ્યતા ↑
  • સંતૃપ્ત દ્રાવણમાં દ્રાવ્યતા મહત્તમ
🎯 Exam Tip: JEE Main માં દ્રાવ્યતા સંબંધિત પ્રશ્નોમાં હંમેશા એકમો (mol/L vs g/100g) અને તાપમાનની સ્થિતિ તપાસો. Ksp ના પ્રશ્નોમાં આયનોનો સ્ટૉઇકિયોમેટ્રિક ગુણોત્તર ભૂલશો નહીં (દા.ત. Ba₃(PO₄)₂ માટે Ksp = [Ba²⁺]³[PO₄³⁻]²).
