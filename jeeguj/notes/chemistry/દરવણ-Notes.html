દ્રાવણ

📖 દ્રાવણ

દ્રાવણની વ્યાખ્યા અને ઘટકો

દ્રાવણ એ બે અથવા વધુ પદાર્થોનો સજાતીય મિશ્રણ છે જેમાં દ્રાવ્ય (solute) દ્રાવક (solvent)માં એકસરખું વિતરિત થાય છે. દ્રાવક પ્રમાણમાં વધુ હોય છે અને દ્રાવ્ય ઓછું હોય છે. ઉદાહરણ: મીઠું પાણીમાં ઓગળે ત્યારે મીઠું દ્રાવ્ય અને પાણી દ્રાવક છે.

  • દ્રાવણ = દ્રાવ્ય + દ્રાવક
  • દ્રાવકનું પ્રમાણ દ્રાવ્ય કરતાં વધુ હોય છે
  • દ્રાવણ સજાતીય અને પારદર્શક હોય છે
  • દ્રાવ્ય અને દ્રાવક વચ્ચે આણ્વીય આંતરક્રિયા થાય છે

દ્રાવણના પ્રકારો

દ્રાવણને દ્રાવ્ય અને દ્રાવકની ભૌતિક અવસ્થા મુજબ વર્ગીકૃત કરવામાં આવે છે. મુખ્ય પ્રકારો: ઘન-દ્રાવણ (ઉદા. પિત્તળ), દ્રવ-દ્રાવણ (ઉદા. શર્કરાનું પાણી), અને વાયુ-દ્રાવણ (ઉદા. હવા). દ્રાવ્યની સાંદ્રતા મુજબ તેને અસંતૃપ્ત, સંતૃપ્ત અને અતિસંતૃપ્ત દ્રાવણમાં વર્ગીકૃત કરવામાં આવે છે.

  • ઘન-દ્રાવણ: દ્રાવ્ય + ઘન દ્રાવક (ઉદા. પિત્તળ)
  • દ્રવ-દ્રાવણ: દ્રાવ્ય + દ્રવ દ્રાવક (ઉદા. શર્કરાનું પાણી)
  • વાયુ-દ્રાવણ: દ્રાવ્ય + વાયુ દ્રાવક (ઉદા. હવા)
  • સાંદ્રતા મુજબ: અસંતૃપ્ત, સંતૃપ્ત, અતિસંતૃપ્ત
🧠 Trick: ઘદવા: ઘન, દ્રવ, વાયુ

સાંદ્રતાનાં માપન પદ્ધતિઓ

દ્રાવણની સાંદ્રતા માપવા માટે મોલરિટી (M), મોલાલિટી (m), મોલ ભાગ (x), અને ટકાવારી દ્રવ્યમાન (w/w, w/v, v/v) વાપરવામાં આવે છે. મોલરિટી = દ્રાવ્યના મોલ / દ્રાવણનો લીટર, મોલાલિટી = દ્રાવ્યના મોલ / દ્રાવકનો કિલોગ્રામ.

  • મોલરિટી (M) = મોલ દ્રાવ્ય / લીટર દ્રાવણ
  • મોલાલિટી (m) = મોલ દ્રાવ્ય / કિલોગ્રામ દ્રાવક
  • મોલ ભાગ (x) = દ્રાવ્યના મોલ / કુલ મોલ
  • ટકાવારી: w/w, w/v, v/v
🧠 Trick: MMXW: મોલરિટી, મોલાલિટી, મોલ ભાગ, ટકાવારી

રાઉલ્ટનો નિયમ અને દ્રાવણના ગુણધર્મો

રાઉલ્ટનો નિયમ કહે છે કે દ્રાવણનો વરાળ દબાણ દ્રાવકના મોલ ભાગના સમપ્રમાણમાં હોય છે. દ્રાવણના ગુણધર્મોને બે પ્રકારમાં વર્ગીકૃત કરવામાં આવે છે: સંલગ્ન ગુણધર્મો (જેમ કે ક્વથનાંક ઉત્થાન, હિમાંક અવનતી) અને અસંલગ્ન ગુણધર્મો (જેમ કે વરાળ દબાણ).

  • રાઉલ્ટનો નિયમ: P = P° * x (x = મોલ ભાગ)
  • સંલગ્ન ગુણધર્મો: ક્વથનાંક ઉત્થાન, હિમાંક અવનતી
  • અસંલગ્ન ગુણધર્મો: વરાળ દબાણ, પરાસરણ દબાણ
  • કોલિગેટિવ ગુણધર્મો દ્રાવ્યના કણોની સંખ્યા પર આધારિત છે
🧠 Trick: રાઉલ્ટ = P° * x

હેનરીનો નિયમ

હેનરીનો નિયમ કહે છે કે નિશ્ચિત તાપમાને, વાયુની દ્રાવ્યતા દ્રાવકમાં તેના આંશિક દબાણના સમપ્રમાણમાં હોય છે. P = K_H * C, જ્યાં K_H હેનરીનો અચળાંક છે અને C એ દ્રાવ્યની સાંદ્રતા છે.

  • હેનરીનો નિયમ: P = K_H * C
  • K_H હેનરીનો અચળાંક છે
  • તાપમાન વધે ત્યારે K_H વધે છે (દ્રાવ્યતા ઘટે છે)
  • ઉચ્ચ દબાણે દ્રાવ્યતા વધે છે
🧠 Trick: હેનરી = P = K_H * C

પરાસરણ અને પરાસરણ દબાણ

પરાસરણ એ અર્ધપારગમ્ય પડદા મારફતે દ્રાવકના અણુઓની ગતિ છે જે દ્રાવણની સાંદ્રતા સમાન કરવા માટે થાય છે. પરાસરણ દબાણ એ દબાણ છે જે પરાસરણ અટકાવવા માટે લાગુ પાડવું પડે છે. π = iCRT, જ્યાં i = વાન્ટ હોફ ગુણાંક, C = મોલરિટી, R = વાયુ અચળાંક, T = તાપમાન.

  • પરાસરણ: અર્ધપારગમ્ય પડદા મારફતે દ્રાવકની ગતિ
  • પરાસરણ દબાણ: π = iCRT
  • i = વાન્ટ હોફ ગુણાંક (આયનિક દ્રાવ્ય માટે)
  • પરાસરણ દબાણ દ્રાવ્યની સાંદ્રતા અને તાપમાન પર આધારિત છે
🧠 Trick: π = iCRT

દ્રાવણની વરાળ દબાણ અવનતી

દ્રાવણનો વરાળ દબાણ શુદ્ધ દ્રાવક કરતાં ઓછો હોય છે, જેને વરાળ દબાણ અવનતી કહેવાય છે. ΔP = P° - P = P° * x_dravy, જ્યાં x_dravy એ દ્રાવ્યનો મોલ ભાગ છે. આ રાઉલ્ટના નિયમનો એક અનુપ્રયોગ છે.

  • વરાળ દબાણ અવનતી: ΔP = P° * x_dravy
  • x_dravy = દ્રાવ્યનો મોલ ભાગ
  • અવનતી દ્રાવ્યના પ્રમાણ પર આધારિત છે
  • રાઉલ્ટના નિયમનો અનુપ્રયોગ

  • હેનરીનો નિયમ: P = K_H * C
  • પરાસરણ દબાણ: π = iCRT
  • વરાળ દબાણ અવનતી: ΔP = P° * x_dravy
  • કોલિગેટિવ ગુણધર્મો: ક્વથનાંક ઉત્થાન, હિમાંક અવનતી

🎯 Exam Tip: કોલિગેટિવ ગુણધર્મોના પ્રશ્નોમાં દ્રાવ્યના આયનિક વિભાજનને ધ્યાનમાં લેવા માટે વાન્ટ હોફ ગુણાંક (i)નો ઉપયોગ કરો.
