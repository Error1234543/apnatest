રેડોક્સ અભિક્રિયાઓ

📖 રેડોક્સ અભિક્રિયાઓ

રેડોક્સ અભિક્રિયાની વ્યાખ્યા

રેડોક્સ અભિક્રિયા એ ઓક્સિડેશન અને રિડક્શનની સમાનકાલીન પ્રક્રિયા છે. ઓક્સિડેશનમાં ઇલેક્ટ્રૉન ગુમાવવામાં આવે છે, જ્યારે રિડક્શનમાં ઇલેક્ટ્રૉન મેળવવામાં આવે છે. આ પ્રક્રિયાઓ હંમેશા એકસાથે થાય છે, કારણ કે એક પદાર્થ ઓક્સિડાઇઝ થાય છે ત્યારે બીજો રિડ્યુસ થાય છે.

  • રેડોક્સ = રિડક્શન + ઓક્સિડેશન
  • ઓક્સિડેશન = ઇલેક્ટ્રૉન ગુમાવવું (ઑક્સિડેશન સ્ટેટ વધે)
  • રિડક્શન = ઇલેક્ટ્રૉન મેળવવું (ઑક્સિડેશન સ્ટેટ ઘટે)
  • ઓક્સિડાઇઝિંગ એજન્ટ રિડ્યુસ થાય છે, રિડ્યુસિંગ એજન્ટ ઓક્સિડાઇઝ થાય છે
🧠 Trick: OIL RIG: Oxidation Is Loss, Reduction Is Gain

ઑક્સિડેશન સ્ટેટ (ઑક્સિડેશન નંબર)

ઑક્સિડેશન સ્ટેટ એ પરમાણુ પરનો કાલ્પનિક ચાર્જ છે જો બધા બંધન આયનિક હોય. તે રેડોક્સ પ્રક્રિયાઓને ઓળખવા માટે મહત્વપૂર્ણ છે. મૂળતત્વોનો ઓક્સિડેશન સ્ટેટ શૂન્ય હોય છે, જ્યારે આયનોનો ચાર્જ તેમનો ઓક્સિડેશન સ્ટેટ હોય છે.

  • મૂળતત્વો (H₂, O₂, Cl₂)નો ઓક્સિડેશન સ્ટેટ = 0
  • Hનો ઓક્સિડેશન સ્ટેટ = +1 (હાઇડ્રાઇડમાં -1)
  • Oનો ઓક્સિડેશન સ્ટેટ = -2 (પેરોક્સાઇડમાં -1, OF₂માં +2)
  • ફ્લોરિનનો ઓક્સિડેશન સ્ટેટ હંમેશા -1
  • સંયોજનમાં ઓક્સિડેશન સ્ટેટનો સરવૈશ = શૂન્ય
🧠 Trick: H is +1, O is -2, F is -1, Free elements are 0

રેડોક્સ અભિક્રિયાના પ્રકારો

રેડોક્સ અભિક્રિયાઓ ચાર મુખ્ય પ્રકારની હોય છે: સંયોજન, વિયોજન, વિસ્થાપન, અને ડિસ્પ્રોપોર્શનેશન. સંયોજનમાં ઓક્સિડેશન સ્ટેટ વધે અથવા ઘટે, જ્યારે વિયોજનમાં એક જ પદાર્થ ઓક્સિડાઇઝ અને રિડ્યુસ બંને થાય છે.

  • સંયોજન રેડોક્સ: 2Mg + O₂ → 2MgO (Mg ઓક્સિડાઇઝ, O રિડ્યુસ)
  • વિયોજન રેડોક્સ: 2KClO₃ → 2KCl + 3O₂ (Cl ઓક્સિડાઇઝ અને રિડ્યુસ)
  • વિસ્થાપન રેડોક્સ: Zn + CuSO₄ → ZnSO₄ + Cu (Zn ઓક્સિડાઇઝ, Cu²⁺ રિડ્યુસ)
  • ડિસ્પ્રોપોર્શનેશન: Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O (Cl બંને થાય છે)

રેડોક્સ અભિક્રિયામાં સંતુલન

રેડોક્સ અભિક્રિયાઓને આયન-ઇલેક્ટ્રૉન પદ્ધતિ અથવા ઓક્સિડેશન નંબર પદ્ધતિ વડે સંતુલિત કરવામાં આવે છે. આયન-ઇલેક્ટ્રૉન પદ્ધતિમાં, અભિક્રિયાને ઓક્સિડેશન અને રિડક્શનના અર્ધ-અભિક્રિયામાં વિભાજીત કરવામાં આવે છે અને પછી સંતુલિત કરવામાં આવે છે.

  • આયન-ઇલેક્ટ્રૉન પદ્ધતિ: અર્ધ-અભિક્રિયાઓ લખો, ઇલેક્ટ્રૉન સંતુલિત કરો, H⁺/OH⁻ ઉમેરી સંતુલન કરો
  • ઓક્સિડેશન નંબર પદ્ધતિ: ઓક્સિડેશન સ્ટેટ બદલો, ઇલેક્ટ્રૉન સંતુલિત કરો
  • એસિડિક મધ્યમમાં H⁺ ઉમેરો, બેઝિક મધ્યમમાં OH⁻ ઉમેરો
  • ઇલેક્ટ્રૉનની સંખ્યા સમાન કરવા માટે ગુણાકાર કરો

રેડોક્સ અભિક્રિયાના ઉદાહરણો (JEE મહત્વપૂર્ણ)

JEE માટે મહત્વપૂર્ણ રેડોક્સ અભિક્રિયાઓમાં પોટેશિયમ પર્મેંગેનેટ (KMnO₄) અને પોટેશિયમ ડાઇક્રોમેટ (K₂Cr₂O₇)ના ઓક્સિડેશન ગુણધર્મો શામેલ છે. આ પ્રક્રિયાઓ એસિડિક, બેઝિક, અને તટસ્થ મધ્યમમાં અલગ અલગ થાય છે.

  • KMnO₄ (એસિડિક મધ્યમ): MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O
  • KMnO₄ (બેઝિક મધ્યમ): MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻
  • K₂Cr₂O₇ (એસિડિક મધ્યમ): Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O
  • H₂O₂ રેડોક્સ ગુણધર્મ: H₂O₂ → H⁺ + O₂ (ઓક્સિડાઇઝિંગ એજન્ટ) અથવા H₂O₂ + 2e⁻ → 2OH⁻ (રિડ્યુસિંગ એજન્ટ)
🧠 Trick: Purple MnO4- to Colorless Mn2+ in Acid, Green Cr2O7 2- to Green Cr3+

રેડોક્સ અભિક્રિયા અને વિદ્યુત-રસાયણશાસ્ત્ર

રેડોક્સ અભિક્રિયાઓ વિદ્યુત-રસાયણશાસ્ત્રના આધારે કોષમાં થાય છે. ગેલ્વેનિક કોષમાં સ્વત:સ્ફૂર્તિ રેડોક્સ અભિક્રિયા થાય છે, જ્યારે ઇલેક્ટ્રોલાઇસિસ કોષમાં બળપૂર્વક રેડોક્સ અભિક્રિયા થાય છે. વિદ્યુતધ્રુવ પોટેન્શિયલ (E°) રેડોક્સ પ્રક્રિયાની સ્પોન્ટેનિયટી નક્કી કરે છે.

  • ગેલ્વેનિક કોષ: સ્વત:સ્ફૂર્તિ રેડોક્સ અભિક્રિયા (ΔG < 0, E° > 0)
  • ઇલેક્ટ્રોલાઇસિસ કોષ: બળપૂર્વક રેડોક્સ અભિક્રિયા (ΔG > 0, E° < 0)
  • Nernst સમીકરણ: E = E° - (RT/nF) ln Q
  • સ્ટાન્ડર્ડ હાઇડ્રોજન ઇલેક્ટ્રોડ (SHE)નો E° = 0 V
  • E° સેલ = E° કેથોડ - E° એનોડ
🧠 Trick: LEO says GER: Loss of Electrons Oxidation (Anode), Gain of Electrons Reduction (Cathode)

⚡ Quick Revision

  • રેડોક્સ = ઓક્સિડેશન + રિડક્શન
  • ઓક્સિડેશન = ઇલેક્ટ્રૉન ગુમાવવું, રિડક્શન = ઇલેક્ટ્રૉન મેળવવું
  • મૂળતત્વોનો ઓક્સિડેશન સ્ટેટ શૂન્ય
  • KMnO₄ એસિડિક મધ્યમમાં Mn²⁺ બને છે
  • ગેલ્વેનિક કોષમાં E° > 0 હોય છે
  • Nernst સમીકરણ E = E° - (RT/nF) ln Q
  • H₂O₂ ઓક્સિડાઇઝિંગ અને રિડ્યુસિંગ એજન્ટ બંને છે
  • ડિસ્પ્રોપોર્શનેશનમાં એક જ પદાર્થ ઓક્સિડાઇઝ અને રિડ્યુસ થાય છે
  • રેડોક્સ અભિક્રિયાઓ આયન-ઇલેક્ટ્રૉન અથવા ઓક્સિડેશન નંબર પદ્ધતિથી સંતુલિત થાય છે
  • સ્ટાન્ડર્ડ હાઇડ્રોજન ઇલેક્ટ્રોડનો E° = 0 V
🎯 Exam Tip: JEEમાં રેડોક્સ અભિક્રિયાઓના પ્રશ્નો માટે KMnO₄ અને K₂Cr₂O₇ના અર્ધ-અભિક્રિયાઓ યાદ રાખો. એસિડિક, બેઝિક, અને તટસ્થ મધ્યમમાં તેમના વર્તનમાં તફાવત છે.
