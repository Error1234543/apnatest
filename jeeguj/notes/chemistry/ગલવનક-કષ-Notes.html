ગેલ્વેનિક કોષ

📖 ગેલ્વેનિક કોષ

પરિચય અને મૂળભૂત સિદ્ધાંત

ગેલ્વેનિક કોષ એક વિદ્યુત-રાસાયણિક કોષ છે જે રસાયણિક ઉર્જાને વિદ્યુત ઉર્જામાં રૂપાંતરિત કરે છે. તે સ્વયંસ્ફુરિત (spontaneous) રેડોક્સ પ્રક્રિયા પર આધારિત છે જ્યાં એનોડ પર ઓક્સિડેશન અને કેથોડ પર રિડક્શન થાય છે. કોષનો વિદ્યુતવાહક બળ (EMF) પ્રક્રિયાની ગિબ્સ મુક્ત ઉર્જામાંથી નક્કી થાય છે.

  • રેડોક્સ પ્રક્રિયા સ્વયંસ્ફુરિત હોવી જોઈએ (ΔG < 0).
  • એનોડ: ઓક્સિડેશન થાય છે (ઇલેક્ટ્રોન ગુમાવે છે).
  • કેથોડ: રિડક્શન થાય છે (ઇલેક્ટ્રોન મેળવે છે).
  • વિદ્યુતવાહક બળ (EMF) = E_cathode - E_anode.
  • સોલ્ટ બ્રિજ કોષમાં વીજભારનું સંતુલન જાળવે છે.
🧠 Trick: OIL RIG: ઓક્સિડેશન Is Loss (of electrons), રિડક્શન Is Gain (of electrons).

ગેલ્વેનિક કોષની રચના

ગેલ્વેનિક કોષમાં બે અર્ધ-કોષ (half-cells) હોય છે: એનોડ અર્ધ-કોષ અને કેથોડ અર્ધ-કોષ. દરેક અર્ધ-કોષમાં એક ઇલેક્ટ્રોડ અને ઇલેક્ટ્રોલાઇટનો દ્રાવણ હોય છે. એનોડ અને કેથોડ વાયર દ્વારા જોડાયેલા હોય છે, જ્યારે ઇલેક્ટ્રોલાઇટ્સ સોલ્ટ બ્રિજ દ્વારા જોડાયેલા હોય છે.

  • એનોડ: ઝિંક (Zn) જેવું ધાતુ જે ઓક્સિડાઇઝ થાય છે.
  • કેથોડ: કોપર (Cu) જેવું ધાતુ કે જ્યાં રિડક્શન થાય છે.
  • સોલ્ટ બ્રિજ: KNO3 અથવા NH4NO3 જેવા ઉદાસીન ઇલેક્ટ્રોલાઇટનો ઉપયોગ થાય છે.
  • ઇલેક્ટ્રોનનો પ્રવાહ એનોડથી કેથોડ તરફ થાય છે.
  • વીજભારનો પ્રવાહ કેથોડથી એનોડ તરફ થાય છે.

રેડોક્સ પ્રક્રિયા અને અર્ધ-પ્રક્રિયાઓ

ગેલ્વેનિક કોષમાં થતી રેડોક્સ પ્રક્રિયાને બે અર્ધ-પ્રક્રિયાઓમાં વિભાજિત કરી શકાય છે. એનોડ પર ઓક્સિડેશન અર્ધ-પ્રક્રિયા અને કેથોડ પર રિડક્શન અર્ધ-પ્રક્રિયા થાય છે. ઉદાહરણ તરીકે, Zn-Cu કોષમાં Zn ઓક્સિડાઇઝ થાય છે અને Cu²⁺ આયન રિડ્યુસ થાય છે.

  • એનોડ અર્ધ-પ્રક્રિયા: Zn → Zn²⁺ + 2e⁻ (ઓક્સિડેશન).
  • કેથોડ અર્ધ-પ્રક્રિયા: Cu²⁺ + 2e⁻ → Cu (રિડક્શન).
  • સંપૂર્ણ પ્રક્રિયા: Zn + Cu²⁺ → Zn²⁺ + Cu.
  • અર્ધ-પ્રક્રિયાઓનો સરવૈયો (sum) સંપૂર્ણ રેડોક્સ પ્રક્રિયા આપે છે.
  • ઇલેક્ટ્રોનનો સંતુલન હોવો જરૂરી છે.

કોષનો વિદ્યુતવાહક બળ (EMF) અને નર્ન્સ્ટ સમીકરણ

ગેલ્વેનિક કોષનો EMF કોષની સ્થિતિમાં નક્કી થાય છે અને નર્ન્સ્ટ સમીકરણ દ્વારા ગણી શકાય છે: E_cell = E°_cell - (RT/nF) ln Q. જ્યાં Q પ્રક્રિયા ક્વોશ્યન્ટ છે, E°_cell માપદંડ વિદ્યુતવાહક બળ છે, R વાયુ અચળાંક, T તાપમાન, n ઇલેક્ટ્રોનની સંખ્યા, અને F ફેરેડે અચળાંક છે.

  • E°_cell = E°_cathode - E°_anode.
  • Q = [પ્રોડક્ટ્સ]/[રિએક્ટન્ટ્સ] (સાંદ્રતા અથવા દબાણ).
  • 25°C પર: E_cell = E°_cell - (0.0591/n) log Q.
  • જો Q < 1, તો E_cell > E°_cell (કોષ વધુ સક્રિય).
  • જો Q = 1, તો E_cell = E°_cell (માપદંડ સ્થિતિ).

ગેલ્વેનિક કોષના ઉપયોગો

ગેલ્વેનિક કોષનો ઉપયોગ વિવિધ ક્ષેત્રોમાં થાય છે જેમ કે બેટરીઓ, કોરોઝન નિયંત્રણ, અને વિદ્યુત-રાસાયણિક સેન્સર્સ. ડેનિયલ કોષ (Zn-Cu કોષ) અને લેડ-એસિડ બેટરી તેના ઉદાહરણો છે.

  • ડેનિયલ કોષ: Zn અને Cu ઇલેક્ટ્રોડ્સ સાથેનો કોષ, E°_cell ≈ 1.10 V.
  • લેડ-એસિડ બેટરી: Pb અને PbO2 ઇલેક્ટ્રોડ્સ સાથેનો કોષ, ઉપયોગ કારમાં થાય છે.
  • કોરોઝન નિયંત્રણ: ધાતુઓને રક્ષણ આપવા ગેલ્વેનાઇઝેશન (Zn કોટિંગ) વાપરવામાં આવે છે.
  • વિદ્યુત-રાસાયણિક સેન્સર્સ: pH મીટરમાં ઉપયોગ થાય છે.
  • બેટરીઓ: મોબાઇલ, લેપટોપ વગેરેમાં ઉપયોગ થાય છે.

ગેલ્વેનિક કોષ અને ગિબ્સ મુક્ત ઉર્જા

ગેલ્વેનિક કોષની રેડોક્સ પ્રક્રિયાની ગિબ્સ મુક્ત ઉર્જા (ΔG) અને EMF વચ્ચેનો સંબંધ ΔG = -nFE_cell છે. જો ΔG < 0, તો પ્રક્રિયા સ્વયંસ્ફુરિત છે અને કોષ વીજળી ઉત્પન્ન કરે છે.

  • ΔG = -nFE_cell (n = ઇલેક્ટ્રોનની સંખ્યા, F = ફેરેડે અચળાંક).
  • જો E_cell > 0, તો ΔG < 0 (સ્વયંસ્ફુરિત પ્રક્રિયા).
  • જો E_cell = 0, તો ΔG = 0 (સંતુલન સ્થિતિ).
  • જો E_cell < 0, તો ΔG > 0 (અસ્વયંસ્ફુરિત પ્રક્રિયા).
  • F = 96485 C/mol (ફેરેડે અચળાંક).

ગેલ્વેનિક કોષ અને લેવાન્સિયર નિયમ

લેવાન્સિયર નિયમ મુજબ, રેડોક્સ પ્રક્રિયાની દિશા એન્ટ્રોપી અને એન્થાલ્પી પર આધારિત છે. ગેલ્વેનિક કોષમાં, પ્રક્રિયા એવી રીતે થાય છે કે જેમાં મુક્ત ઉર્જા ઘટે છે (ΔG < 0).

  • ΔG = ΔH - TΔS (G = ગિબ્સ મુક્ત ઉર્જા, H = એન્થાલ્પી, S = એન્ટ્રોપી).
  • સ્વયંસ્ફુરિત પ્રક્રિયા માટે ΔG < 0 હોવું જોઈએ.
  • ગેલ્વેનિક કોષમાં, ΔG = -nFE_cell.
  • જો TΔS > ΔH, તો પ્રક્રિયા ઉષ્મા શોષીને થાય છે.
  • જો TΔS < ΔH, તો પ્રક્રિયા ઉષ્મા મુક્ત કરીને થાય છે.

  • ગેલ્વેનિક કોષ રેડોક્સ પ્રક્રિયા દ્વારા વિદ્યુત ઉત્પન્ન કરે છે.
  • એનોડ પર ઓક્સિડેશન, કેથોડ પર રિડક્શન થાય છે.

  • સોલ્ટ બ્રિજ કોષમાં વીજભારનું સંતુલન જાળવે છે.
  • ડેનિયલ કોષ (Zn-Cu)નો EMF ≈ 1.10 V.
  • લેડ-એસિડ બેટરી કારમાં ઉપયોગ થાય છે.
  • સ્વયંસ્ફુરિત પ્રક્રિયા માટે ΔG < 0 હોવું જોઈએ.
  • OIL RIG: ઓક્સિડેશન Is Loss, રિડક્શન Is Gain.
🎯 Exam Tip: ગેલ્વેનિક કોષના પ્રશ્નોમાં, એનોડ અને કેથોડની ઓળખ કરવા માટે સ્ટાન્ડર્ડ ઇલેક્ટ્રોડ પોટેન્શિયલ (E°)ના મૂલ્યો યાદ રાખો. E° જેટલું ઓછું હોય તે એનોડ બને છે.
