ઇલેક્ટ્રોલિસિસ

📖 ઇલેક્ટ્રોલિસિસ

ઇલેક્ટ્રોલિસિસની મૂળભૂત સંકલ્પના

ઇલેક્ટ્રોલિસિસ એ વિદ્યુત પ્રવાહ દ્વારા રાસાયણિક ક્રિયાને ઉત્તેજિત કરવાની પ્રક્રિયા છે. જ્યારે વિદ્યુત પ્રવાહને ઇલેક્ટ્રોલાઇટ (વિદ્યુત વહન કરતું દ્રાવણ)માંથી પસાર કરવામાં આવે છે, ત્યારે કેટાયન (ધન આયન) કેથોડ તરફ અને એનાયન (ઋણ આયન) એનોડ તરફ ગતિ કરે છે. આ પ્રક્રિયામાં રાસાયણિક બંધ તૂટી જાય છે, જેથી નવા પદાર્થો બને છે.

  • ઇલેક્ટ્રોલિસિસ = વિદ્યુત + લિસિસ (વિભાજન)
  • કેટાયન કેથોડ પર રિડક્શન પામે છે
  • એનાયન એનોડ પર ઓક્સિડેશન પામે છે
  • ઇલેક્ટ્રોલાઇટમાં મુક્ત આયન હાજર હોવા જરૂરી છે
  • ફેરાડેના નિયમો ઇલેક્ટ્રોલિસિસને નિયંત્રિત કરે છે
🧠 Trick: કેથોડ = રિડક્શન (કેથોડ રિડ્યુસ કરે), એનોડ = ઓક્સિડેશન (એનોડ ઓક્સિડાઇઝ કરે)

ફેરાડેના ઇલેક્ટ્રોલિસિસના નિયમો

પહેલો નિયમ: ઇલેક્ટ્રોડ પર મુક્ત થતાં પદાર્થની માત્રા વિદ્યુત પ્રવાહની તીવ્રતા અને સમયના ગુણાકારની સીધી પ્રમાણમાં હોય છે (m ∝ I × t). બીજો નિયમ: એક જ પ્રમાણમાં વિદ્યુત પ્રવાહ પસાર કરતાં, વિવિધ પદાર્થોની માત્રા તેમના રાસાયણિક સમતોલન વજનના પ્રમાણમાં હોય છે.

  • m = Z × I × t (Z = ઇલેક્ટ્રોકેમિકલ સમતોલન)
  • 1 ફેરાડે = 96500 કુલોમ (1 મોલ ઇલેક્ટ્રોનનો ચાર્જ)
  • Z = M / (n × F) (M = મોલર માસ, n = ઇલેક્ટ્રોનની સંખ્યા)
  • ફેરાડેનો બીજો નિયમ રાસાયણિક સમતોલન પર આધારિત છે
🧠 Trick: F = 96500 C = 1 mol e⁻

ઇલેક્ટ્રોલિટિક સેલની રચના

ઇલેક્ટ્રોલિટિક સેલમાં બે ઇલેક્ટ્રોડ (એનોડ અને કેથોડ), ઇલેક્ટ્રોલાઇટ (દ્રાવણ અથવા ગલિત અવસ્થા) અને બાહ્ય વિદ્યુત સ્રોત હોય છે. એનોડ ઓક્સિડેશન સ્થળ છે, જ્યારે કેથોડ રિડક્શન સ્થળ છે. ઉદાહરણ: કોપર સલ્ફેટ દ્રાવણનું ઇલેક્ટ્રોલિસિસ કરતાં કેથોડ પર કોપર જમા થાય છે.

  • એનોડ: ઓક્સિડેશન (ઉદા. Cl⁻ → Cl₂ + 2e⁻)
  • કેથોડ: રિડક્શન (ઉદા. Cu²⁺ + 2e⁻ → Cu)
  • બાહ્ય બેટરી અથવા DC સપ્લાય જરૂરી છે
  • ઇલેક્ટ્રોડ સક્રિય અથવા નિષ્ક્રિય હોઈ શકે

ઇલેક્ટ્રોલિસિસના ઉપયોગો

ઇલેક્ટ્રોલિસિસનો ઉપયોગ ધાતુ શુદ્ધિકરણ (ઉદા. કોપર, એલ્યુમિનિયમ), ધાતુની નિક્ષેપણ (ઇલેક્ટ્રોપ્લેટિંગ), હાઇડ્રોજન અને ઓક્સિજન ગેસની ઉત્પાદન (પાણીનું ઇલેક્ટ્રોલિસિસ), અને ક્લોર-આલ્કલાઇન ઉદ્યોગમાં થાય છે.

  • કોપર શુદ્ધિકરણ: અશુદ્ધ કોપર એનોડ, શુદ્ધ કોપર કેથોડ
  • હાલર પ્રક્રિયા: NaCl નું ઇલેક્ટ્રોલિસિસ → NaOH + Cl₂ + H₂
  • ઇલેક્ટ્રોપ્લેટિંગ: સોનું, ચાંદી, નિકલની પાતળી પરત ચડાવવા
  • પાણીનો ઇલેક્ટ્રોલિસિસ: 2H₂O → 2H₂ + O₂ (H₂:O₂ = 2:1 ગુણોત્તર)
🧠 Trick: H₂O → H₂ (કેથોડ) + O₂ (એનોડ)

ઇલેક્ટ્રોલિસિસ અને ગિબ્સ મુક્ત ઉર્જા

ઇલેક્ટ્રોલિસિસ માટે જરૂરી ન્યૂનતમ વોલ્ટેજને ડિકોમ્પોઝિશન પોટેન્શિયલ કહે છે. ગિબ્સ મુક્ત ઉર્જા (ΔG) અને સેલ પોટેન્શિયલ (E) વચ્ચેનો સંબંધ ΔG = -nFE છે. જો ΔG > 0, તો પ્રક્રિયા સ્વત: થતી નથી અને ઇલેક્ટ્રોલિસિસ જરૂરી બને છે.

  • ΔG = -nFE (n = ઇલેક્ટ્રોનની સંખ્યા, F = ફેરાડે)
  • ડિકોમ્પોઝિશન પોટેન્શિયલ = થિયોરેટિકલ E° - ઓવરપોટેન્શિયલ
  • ઓવરપોટેન્શિયલ ઇલેક્ટ્રોડની સામગ્રી અને સ્તર પર આધાર રાખે છે
  • જ્યારે E < 0, ઇલેક્ટ્રોલિસિસ જરૂરી બને છે
🧠 Trick: ΔG > 0 → ઇલેક્ટ્રોલિસિસ જરૂરી

ઇલેક્ટ્રોલિસિસમાં ઉર્જા પરિવર્તન

ઇલેક્ટ્રોલિસિસમાં વિદ્યુત ઉર્જા રાસાયણિક ઉર્જામાં રૂપાંતરિત થાય છે. વિદ્યુત પ્રવાહ દ્વારા પૂરા પાડેલી ઉર્જા રાસાયણિક બંધ તોડવા અને નવા બંધ બનાવવા વપરાય છે. ઉદાહરણ: પાણીનું ઇલેક્ટ્રોલિસિસ 286 kJ/mol ઉર્જા લે છે.

  • વિદ્યુત ઉર્જા → રાસાયણિક ઉર્જા
  • ઉર્જા અવશ્યકતા = ΔH + TΔS (એન્થાલ્પી + એન્ટ્રોપી)
  • પાણીના ઇલેક્ટ્રોલિસિસ માટે 1.23 V થિયોરેટિકલ પોટેન્શિયલ જરૂરી છે
  • પ્રેક્ટિકલમાં ઓવરપોટેન્શિયલને લીધે વધુ વોલ્ટેજ જરૂરી પડે છે

ઇલેક્ટ્રોલિસિસ અને ફેરાડેની કુશળતા

ફેરાડેની કુશળતા (F) એ ઇલેક્ટ્રોલાઇટની ક્ષમતા દર્શાવે છે કે કેટલી માત્રામાં પદાર્થ ઇલેક્ટ્રોડ પર મુક્ત થાય છે. તે ઇલેક્ટ્રોલાઇટની સાંદ્રતા, તાપમાન, અને ઇલેક્ટ્રોડની સામગ્રી પર આધાર રાખે છે. ઉચ્ચ ફેરાડે કુશળતા = વધુ પદાર્થ મુક્ત થાય.

  • ફેરાડે કુશળતા = (પદાર્થની માત્રા / થિયોરેટિકલ માત્રા) × 100%
  • સાંદ્રતા વધે → કુશળતા વધે (પરંતુ પૂરતી સાંદ્રતા પછી ઘટે)
  • તાપમાન વધે → આયન ગતિશીલતા વધે → કુશળતા વધે
  • ઇલેક્ટ્રોડની સામગ્રી પણ અસર કરે છે

⚡ Quick Revision

  • ઇલેક્ટ્રોલિસિસ = વિદ્યુત દ્વારા રાસાયણિક વિભાજન
  • કેથોડ: રિડક્શન (કેટાયન મુક્ત થાય)
  • એનોડ: ઓક્સિડેશન (એનાયન મુક્ત થાય)
  • ફેરાડેનો પહેલો નિયમ: m = ZIt
  • ફેરાડેનો બીજો નિયમ: પદાર્થની માત્રા રાસાયણિક સમતોલન વજનના પ્રમાણમાં
  • 1 ફેરાડે = 96500 C = 1 મોલ e⁻
  • પાણીનું ઇલેક્ટ્રોલિસિસ: 2H₂O → 2H₂ + O₂ (2:1 ગુણોત્તર)
  • ડિકોમ્પોઝિશન પોટેન્શિયલ = થિયોરેટિકલ E° - ઓવરપોટેન્શિયલ
  • ઉપયોગ: ધાતુ શુદ્ધિકરણ, ઇલેક્ટ્રોપ્લેટિંગ, H₂/O₂ ઉત્પાદન
  • ΔG = -nFE (જો ΔG > 0, ઇલેક્ટ્રોલિસિસ જરૂરી)
🎯 Exam Tip: ફેરાડેના નિયમો અને ડિકોમ્પોઝિશન પોટેન્શિયલ પર પ્રશ્નો વારંવાર પૂછાય છે — સૂત્રો અને એકમો યાદ રાખો!
