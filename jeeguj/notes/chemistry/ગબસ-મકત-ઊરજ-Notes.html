ગિબ્સ મુક્ત ઊર્જા

📖 ગિબ્સ મુક્ત ઊર્જા

પરિભાષા અને સૂત્ર

ગિબ્સ મુક્ત ઊર્જા (G) એ થર્મોડાયનેમિક્સનો મહત્વનો પેરામીટર છે જે પ્રક્રિયાની સ્વતઃસિદ્ધતા નક્કી કરે છે. સૂત્ર G = H - TS છે, જ્યાં H એ એન્થાલ્પી, T એ તાપમાન (Kમાં) અને S એ એન્ટ્રોપી છે.

  • G = H - TS (ગિબ્સ મુક્ત ઊર્જાનું મૂળ સૂત્ર)
  • ΔG ≤ 0 → પ્રક્રિયા સ્વતઃસિદ્ધ (spontaneous) છે
  • ΔG > 0 → પ્રક્રિયા અસ્વતઃસિદ્ધ (non-spontaneous) છે
  • ΔG = 0 → પ્રક્રિયા સંતુલનમાં છે
🧠 Trick: G = H - TS → 'Ghar Hoga To Sab Theek' (ગિબ્સ હશે તો સર્વ ઠીક)

સ્વતઃસિદ્ધતા અને ΔG

ΔG ની કિંમત પ્રક્રિયાની દિશા અને સ્વતઃસિદ્ધતા નક્કી કરે છે. જો ΔG નેગેટિવ હોય, તો પ્રક્રિયા આગળ વધે છે; પોઝિટિવ ΔG એ પ્રક્રિયા પાછળ જાય છે. સંતુલન પર ΔG = 0.

  • ΔG < 0 → આગળની દિશામાં સ્વતઃસિદ્ધ
  • ΔG > 0 → પાછળની દિશામાં અસ્વતઃસિદ્ધ
  • ΔG = 0 → સંતુલન અવસ્થા
  • ΔG તાપમાન પર આધાર રાખે છે (T બદલાય તો ΔG બદલાય)

ગિબ્સ મુક્ત ઊર્જા અને સંતુલન સ્થિરાંક (K)

ΔG° = -RT ln K, જ્યાં ΔG° એ સ્ટાન્ડર્ડ ગિબ્સ મુક્ત ઊર્જા છે, R એ ગેસ સ્થિરાંક, T એ તાપમાન, અને K એ સંતુલન સ્થિરાંક. આ સૂત્ર સંતુલન અવસ્થા અને પ્રક્રિયાની સ્વતઃસિદ્ધતા વચ્ચેનો સંબંધ દર્શાવે છે.

  • ΔG° = -RT ln K
  • K > 1 → ΔG° < 0 (પ્રક્રિયા આગળ વધે)
  • K < 1 → ΔG° > 0 (પ્રક્રિયા પાછળ જાય)
  • K = 1 → ΔG° = 0 (સંતુલન)
🧠 Trick: ΔG° = -RT ln K → 'Ghar Rahe To Kaam Ho' (ગિબ્સ રહે તો કામ થાય)

તાપમાનનો પ્રભાવ

તાપમાન બદલવાથી ΔG બદલાય છે, કારણ કે ΔG = ΔH - TΔS. જો ΔS પોઝિટિવ હોય, તો તાપમાન વધારવાથી ΔG ઘટે છે અને પ્રક્રિયા સ્વતઃસિદ્ધ બને છે. જો ΔS નેગેટિવ હોય, તો તાપમાન વધારવાથી ΔG વધે છે.

  • ΔS > 0 → T ↑ → ΔG ↓ (સ્વતઃસિદ્ધતા વધે)
  • ΔS < 0 → T ↑ → ΔG ↑ (સ્વતઃસિદ્ધતા ઘટે)
  • ΔH અને ΔS ની કિંમતો તાપમાન પર આધાર રાખે છે

ગિબ્સ મુક્ત ઊર્જા અને કોષીય પ્રક્રિયાઓ

જીવવિજ્ઞાનમાં, ગિબ્સ મુક્ત ઊર્જા કોષીય પ્રક્રિયાઓ જેમ કે પ્રકાશસંશ્લેષણ, શ્વસન, અને ATP સંશ્લેષણની સ્વતઃસિદ્ધતા નક્કી કરે છે. ATP નું જળવિભાજન (ΔG° = -30.5 kJ/mol) એ ઉર્જા મુક્ત કરતી પ્રક્રિયા છે.

  • ATP → ADP + Pi (ΔG° = -30.5 kJ/mol)
  • પ્રકાશસંશ્લેષણ અને શ્વસનમાં ΔG નેગેટિવ હોય છે
  • કોષીય પ્રક્રિયાઓમાં ઉર્જા વહન ΔG દ્વારા નિયંત્રિત થાય છે

ગિબ્સ મુક્ત ઊર્જા અને રાસાયણિક પ્રક્રિયાઓ

રસાયણશાસ્ત્રમાં, ગિબ્સ મુક્ત ઊર્જા રાસાયણિક પ્રક્રિયાઓની સ્વતઃસિદ્ધતા નક્કી કરે છે. ઉદાહરણ તરીકે, H₂ + Cl₂ → 2HCl પ્રક્રિયા માટે ΔG° નેગેટિવ છે, જે દર્શાવે છે કે પ્રક્રિયા સ્વતઃસિદ્ધ છે.

  • ΔG° ની ગણતરી સ્ટાન્ડર્ડ અવસ્થામાં થાય છે
  • રાસાયણિક પ્રક્રિયાઓમાં ΔG° ની કિંમત પ્રક્રિયાની દિશા નક્કી કરે છે
  • ΔG° = ΣΔG°(પ્રોડક્ટ્સ) - ΣΔG°(રિએક્ટન્ટ્સ)

ગિબ્સ મુક્ત ઊર્જા અને ઉત્ક્રાંતિ

જીવવિજ્ઞાનમાં, ગિબ્સ મુક્ત ઊર્જા ઉત્ક્રાંતિ પ્રક્રિયાઓમાં પણ મહત્વની ભૂમિકા ભજવે છે. ઉર્જા-યુક્ત અણુઓ (જેમ કે ATP) ની રચના અને વપરાશ ઉત્ક્રાંતિ દરમિયાન થતી પ્રક્રિયાઓની સ્વતઃસિદ્ધતા નક્કી કરે છે.

  • ઉત્ક્રાંતિ પ્રક્રિયાઓમાં ΔG નેગેટિવ હોય છે
  • ATP નું સંશ્લેષણ અને વિઘટન ઉત્ક્રાંતિ માટે મહત્વપૂર્ણ છે
  • ઉર્જા વહન ઉત્ક્રાંતિ પ્રક્રિયાઓને ચલાવે છે

⚡ Quick Revision

  • G = H - TS એ ગિબ્સ મુક્ત ઊર્જાનું સૂત્ર છે
  • ΔG < 0 → પ્રક્રિયા સ્વતઃસિદ્ધ છે
  • ΔG > 0 → પ્રક્રિયા અસ્વતઃસિદ્ધ છે
  • ΔG° = -RT ln K એ સંતુલન સ્થિરાંક સાથેનો સંબંધ છે
  • તાપમાન બદલવાથી ΔG બદલાય છે
  • ATP નું જળવિભાજન ΔG° = -30.5 kJ/mol છે
  • રાસાયણિક પ્રક્રિયાઓમાં ΔG° પ્રક્રિયાની દિશા નક્કી કરે છે
  • કોષીય પ્રક્રિયાઓમાં ΔG ઉર્જા વહન નિયંત્રિત કરે છે
  • ઉત્ક્રાંતિ પ્રક્રિયાઓમાં ΔG નેગેટિવ હોય છે
  • ΔG = 0 એ સંતુલન અવસ્થા દર્શાવે છે
🎯 Exam Tip: ગિબ્સ મુક્ત ઊર્જા સંબંધી પ્રશ્નોમાં, ΔG, ΔH, અને ΔS ની કિંમતોની ગણતરી કરવા માટે સૂત્રો યાદ રાખો અને તાપમાનના પ્રભાવને સમજો. સંતુલન સ્થિરાંક (K) સાથેનો સંબંધ પણ મહત્વપૂર્ણ છે.
