વેગ

📖 વેગ

વેગની વ્યાખ્યા અને સૂત્ર

વેગ એ વસ્તુની સ્થાનમાં થતો ફેરફાર દર એકમ સમય છે. તે સદિશ રાશિ છે, જેમાં પરિમાણ અને દિશા બંને અગત્યના છે. સૂત્ર: **v = Δr/Δt**, જ્યાં Δr = સ્થાનાંતર અને Δt = સમયાંતર.

  • વેગ = સ્થાનાંતર / સમયાંતર
  • સદિશ રાશિ (પરિમાણ + દિશા)
  • SI એકમ: m/s
  • વેગનો વેગમનથી ભેદ: વેગમન એ સ્કેલર રાશિ છે
🧠 Trick: વેગ = વેગમન + દિશા (વ + દ = વેગ)

વેગ અને વેગમનમાં તફાવત

વેગમન એ સ્કેલર રાશિ છે જ્યારે વેગ એ સદિશ રાશિ છે. ઉદાહરણ: 5 m/s વેગમન કહે છે કે કેટલી ઝડપે ગતિ થાય છે, પરંતુ 5 m/s ઉત્તર દિશામાં વેગ કહે છે કે કેટલી ઝડપે અને ક્યાં દિશામાં ગતિ થાય છે.

  • વેગમન: માત્ર પરિમાણ
  • વેગ: પરિમાણ + દિશા
  • વેગમન કદાચ ઋણ ન હોય, વેગ ઋણ હોઈ શકે (દિશા વિરુદ્ધ)
  • વેગ = વેગમન જ્યારે દિશા નિર્ધારિત હોય
🧠 Trick: સ્કેલર = વેગમન, સદિશ = વેગ

સરેરાશ વેગ અને તાત્કાલિક વેગ

સરેરાશ વેગ એ કુલ સ્થાનાંતર અને કુલ સમયનો ગુણોત્તર છે. તાત્કાલિક વેગ એ કોઈ એક ક્ષણે વસ્તુનો વેગ છે, જે Δt → 0 હોવાને લીધે મર્યાદા રૂપે વ્યાખ્યાયિત થાય છે.

  • સરેરાશ વેગ = કુલ સ્થાનાંતર / કુલ સમય
  • તાત્કાલિક વેગ = lim (Δt→0) Δr/Δt
  • તાત્કાલિક વેગ એ વેગ-સમય આલેખની ઢાળ છે
  • સરેરાશ વેગ વાસ્તવિક ગતિને દર્શાવતો નથી

વેગ-સમય આલેખ

વેગ-સમય આલેખની ઢાળ પ્રવેગને દર્શાવે છે. આલેખ હેઠળનો ક્ષેત્રફળ સ્થાનાંતરને દર્શાવે છે. સરળ રેખા = સ્થિર પ્રવેગ, ક્ષિતિજ રેખા = સ્થિર વેગ (પ્રવેગ = 0).

  • ઢાળ = પ્રવેગ (a = Δv/Δt)
  • ક્ષેત્રફળ = સ્થાનાંતર (Δr)
  • સ્થિર વેગ → ક્ષિતિજ રેખા
  • સ્થિર પ્રવેગ → સરળ રેખા
🧠 Trick: ઢાળ = પ્રવેગ, ક્ષેત્ર = સ્થાન

વેગનો સદિશ સ્વરૂપ

વેગને સદિશ રૂપે દર્શાવવા માટે પરિમાણ અને દિશા બંને જરૂરી છે. ઉદાહરણ: **v = 5î + 3ĵ m/s** એ X-દિશામાં 5 m/s અને Y-દિશામાં 3 m/s વેગ દર્શાવે છે.

  • વેગ સદિશ = v = v_x î + v_y ĵ + v_z k̂
  • પરિમાણ = √(v_x² + v_y² + v_z²)
  • દિશા = tan⁻¹(v_y / v_x)
  • સદિશ યોગ: વેગોનો સરવાળો સદિશ રીતે થાય

વેગ અને પ્રવેગ વચ્ચેનો સંબંધ

પ્રવેગ એ વેગમાં થતો ફેરફાર દર એકમ સમય છે. સૂત્ર: **a = Δv/Δt**. જ્યારે વેગ બદલાય છે ત્યારે પ્રવેગ અસ્તિત્વમાં આવે છે.

  • પ્રવેગ = વેગનો ફેરફાર / સમય
  • a = Δv/Δt
  • વેગ સ્થિર → પ્રવેગ = 0
  • પ્રવેગ અને વેગ એક જ દિશામાં હોય તો વેગ વધે, વિરુદ્ધ દિશામાં હોય તો વેગ ઘટે
🧠 Trick: પ્રવેગ = વેગનો 'પિતા' (ફેરફાર)

વેગના પ્રકાર

વેગને તેની દિશા અને પરિમાણ અનુસાર વર્ગીકૃત કરી શકાય: સ્થિર વેગ (પરિમાણ અને દિશા સ્થિર), પરિવર્તી વેગ (પરિમાણ બદલાય), અને ચળકતી ગતિ (દિશા બદલાય).

  • સ્થિર વેગ: પરિમાણ + દિશા સ્થિર
  • પરિવર્તી વેગ: પરિમાણ બદલાય, દિશા સ્થિર
  • ચળકતી ગતિ: દિશા બદલાય (ઉદા. વર્તળ ગતિ)
  • સરળ રેખામાં ગતિ: દિશા સ્થિર અથવા વિરુદ્ધ
🧠 Trick: સ્થિર = સ્થિર, ચળકતી = દિશા બદલે

⚡ Quick Revision

  • વેગ = સ્થાનાંતર / સમય (સદિશ રાશિ)
  • વેગમન = અંતર / સમય (સ્કેલર રાશિ)
  • સરેરાશ વેગ = કુલ સ્થાનાંતર / કુલ સમય
  • તાત્કાલિક વેગ = વેગ-સમય આલેખની ઢાળ
  • વેગ-સમય આલેખ હેઠળનો ક્ષેત્રફળ = સ્થાનાંતર
  • પ્રવેગ = વેગનો ફેરફાર / સમય
  • વેગ સદિશ = v_x î + v_y ĵ + v_z k̂
  • સ્થિર વેગ → પ્રવેગ = 0
  • વેગ અને વેગમનમાં મુખ્ય તફાવત: દિશા
  • વેગની દિશા હંમેશા ગતિની દિશામાં હોય છે
🎯 Exam Tip: વેગ અને વેગમન વચ્ચેનો તફાવત સ્પષ્ટ રાખો. વેગ-સમય આલેખના પ્રશ્નોમાં ઢાળ અને ક્ષેત્રફળની ગણતરી પર ધ્યાન આપો.
