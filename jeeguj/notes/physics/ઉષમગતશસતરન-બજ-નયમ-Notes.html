ઉષ્માગતિશાસ્ત્રનો બીજો નિયમ

📖 ઉષ્માગતિશાસ્ત્રનો બીજો નિયમ

નિયમનું નિવેદન

ઉષ્માગતિશાસ્ત્રનો બીજો નિયમ કહે છે કે એન્ટ્રોપી (સ્વાભાવિક અવ્યવસ્થા) એ એક અલગ થર્મોડાયનેમિક પ્રોપર્ટી છે જે સમય જતાં વૃદ્ધિ પામે છે. બંધ સિસ્ટમમાં, એન્ટ્રોપી હંમેશા વધે છે અથવા સ્થિર રહે છે, પરંતુ ક્યારેય ઘટતી નથી.

  • બંધ સિસ્ટમમાં ΔS ≥ 0 (ΔS = એન્ટ્રોપીનો ફેરફાર)
  • એન્ટ્રોપી એ સિસ્ટમની અવ્યવસ્થાનું માપ છે
  • સ્વત:સ્ફૂર્ત પ્રક્રિયાઓમાં એન્ટ્રોપી વધે છે
  • બીજો નિયમ થર્મોડાયનેમિક્સના ચાર નિયમોમાંથી એક છે
🧠 Trick: એન્ટ્રોપી = અવ્યવસ્થા, બંધ સિસ્ટમમાં હંમેશા વધે!

એન્ટ્રોપીનું મહત્વ

એન્ટ્રોપી એ સિસ્ટમની અવ્યવસ્થા અથવા યાદચ્છિકતાનું માપ છે. ઉર્જાના વિતરણને સમજવા માટે તે મહત્વપૂર્ણ છે. ઉચ્ચ એન્ટ્રોપીનો અર્થ એ છે કે સિસ્ટમ વધુ અવ્યવસ્થિત છે.

  • એન્ટ્રોપી (S) = k ln W (Boltzmann સૂત્ર, W = માઇક્રોસ્ટેટ્સની સંખ્યા)
  • ઉર્જા વિતરણ જેટલું વધુ અવ્યવસ્થિત, એન્ટ્રોપી એટલી વધુ
  • ગેસની એન્ટ્રોપી > દ્રવ > ઘન
  • તાપમાન વધારવાથી એન્ટ્રોપી વધે છે
🧠 Trick: ગેસ > દ્રવ > ઘન (એન્ટ્રોપીનો ક્રમ)

બીજા નિયમના ગણિતીય સ્વરૂપ

બીજા નિયમને ગણિતીય રીતે ΔS = ΔQ/T (રુદ્ધોષ્મ પ્રક્રિયા માટે) વડે વ્યક્ત કરવામાં આવે છે. જ્યાં ΔS એ એન્ટ્રોપીનો ફેરફાર, ΔQ એ ઉષ્માનો વિનિમય, અને T એ તાપમાન છે.

  • ΔS = ΔQ_rev / T (રુદ્ધોષ્મ પ્રક્રિયા)
  • ΔS_universe = ΔS_system + ΔS_surroundings ≥ 0
  • સ્વત:સ્ફૂર્ત પ્રક્રિયાઓ માટે ΔS_universe > 0
  • સંતુલનમાં ΔS_universe = 0
🧠 Trick: ΔS = Q/T, સ્વત:સ્ફૂર્ત માટે ΔS_universe > 0

બીજા નિયમના ઉપયોગો

ઉષ્માગતિશાસ્ત્રનો બીજો નિયમ ઉર્જા રૂપાંતરણ, યંત્રોની કાર્યક્ષમતા, અને પ્રકૃતિમાં થતી પ્રક્રિયાઓની દિશા સમજવા માટે ઉપયોગી છે. તે કર્ણો ચક્ર અને ઉર્જા સંરક્ષણને પણ સમજાવે છે.

  • કર્ણો એન્જિનની મહત્તમ કાર્યક્ષમતા η = 1 - T_cold/T_hot
  • બીજો નિયમ કહે છે કે 100% કાર્યક્ષમ યંત્ર શક્ય નથી
  • પ્રકૃતિમાં સ્વત:સ્ફૂર્ત પ્રક્રિયાઓ એન્ટ્રોપી વધારીને થાય છે
  • ઉર્જા હંમેશા ઉચ્ચ તાપમાનથી નીચા તાપમાન તરફ વહે છે
🧠 Trick: 100% કાર્યક્ષમ યંત્ર = અશક્ય (બીજો નિયમ)

એન્ટ્રોપી અને પ્રકૃતિ

પ્રકૃતિમાં, એન્ટ્રોપી હંમેશા વધતી જોવા મળે છે. ઉદાહરણ તરીકે, એક ગ્લાસમાં પાણી અને કોફી મિશ્ર થાય છે, તો તે પાછું અલગ થઈ શકતું નથી. આ બીજા નિયમનું ઉદાહરણ છે.

  • પ્રકૃતિ એન્ટ્રોપી વધારીને સંતુલન તરફ આગળ વધે છે
  • અવ્યવસ્થા હંમેશા વધે છે (ઉદા. ગેસનું પ્રસરણ)
  • એન્ટ્રોપી એ સમયની દિશા દર્શાવે છે
  • બીજો નિયમ 'તીરના નિયમ' તરીકે પણ ઓળખાય છે
🧠 Trick: એન્ટ્રોપી = સમયનો તીર, હંમેશા આગળ!

બીજા નિયમ અને રાસાયણિક પ્રક્રિયાઓ

રાસાયણિક પ્રક્રિયાઓમાં, એન્ટ્રોપીનો ફેરફાર પ્રક્રિયાની સ્વત:સ્ફૂર્તતાને નક્કી કરે છે. ΔG = ΔH - TΔS (ગિબ્સ મુક્ત ઉર્જા) સૂત્રમાં એન્ટ્રોપીનો સમાવેશ થાય છે.

  • ΔG < 0 → સ્વત:સ્ફૂર્ત પ્રક્રિયા
  • ΔG = ΔH - TΔS
  • ΔS > 0 → એન્ટ્રોપી વધે છે (અનુકૂળ)
  • ΔH < 0 અને ΔS > 0 → હંમેશા સ્વત:સ્ફૂર્ત
🧠 Trick: ΔG = ΔH - TΔS, સ્વત:સ્ફૂર્ત માટે ΔG < 0

બીજા નિયમના અપવાદો

બીજો નિયમ ખૂબ જ સૂક્ષ્મ સિસ્ટમો (જેમ કે ક્વોન્ટમ સિસ્ટમ) અથવા ખૂબ જ ટૂંકા સમયગાળા માટે અપવાદ ધરાવી શકે છે. પરંતુ મેક્રોસ્કોપિક સિસ્ટમો માટે તે હંમેશા લાગુ પડે છે.

  • સૂક્ષ્મ સિસ્ટમોમાં એન્ટ્રોપી ટૂંકા ગાળા માટે ઘટી શકે
  • મેક્રોસ્કોપિક સિસ્ટમોમાં બીજો નિયમ હંમેશા લાગુ
  • ક્વોન્ટમ ફ્લક્ચુએશન અપવાદ તરીકે ગણી શકાય
  • પ્રયોગશાળામાં બીજો નિયમ ક્યારેય ભંગ થતો નથી
🧠 Trick: મેક્રો સિસ્ટમ = બીજો નિયમ હંમેશા લાગુ

⚡ Quick Revision

  • બીજો નિયમ: ΔS_universe ≥ 0
  • એન્ટ્રોપી = અવ્યવસ્થાનું માપ
  • ΔS = ΔQ_rev / T
  • ગેસ > દ્રવ > ઘન (એન્ટ્રોપીનો ક્રમ)
  • કર્ણો એન્જિનની મહત્તમ કાર્યક્ષમતા = 1 - T_cold/T_hot
  • ΔG = ΔH - TΔS (ગિબ્સ મુક્ત ઉર્જા)
  • સ્વત:સ્ફૂર્ત પ્રક્રિયા માટે ΔG < 0
  • 100% કાર્યક્ષમ યંત્ર અશક્ય છે
  • એન્ટ્રોપી હંમેશા વધે છે (પ્રકૃતિનો નિયમ)
  • બીજો નિયમ 'તીરના નિયમ' તરીકે ઓળખાય
🎯 Exam Tip: બીજા નિયમને સમજવા માટે એન્ટ્રોપી અને ΔG ના સૂત્રો યાદ રાખો. પ્રશ્નોમાં ΔS_universe ≥ 0 ની શરત લાગુ કરો અને સ્વત:સ્ફૂર્તતાનું વિશ્લેષણ કરો.
