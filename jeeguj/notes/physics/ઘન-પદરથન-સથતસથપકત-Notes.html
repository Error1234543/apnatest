ઘન પદાર્થોની સ્થિતિસ્થાપકતા

📖 ઘન પદાર્થોની સ્થિતિસ્થાપકતા

સ્થિતિસ્થાપકતાનો અર્થ અને પ્રકારો

સ્થિતિસ્થાપકતા એ પદાર્થની વિકૃત થયા પછી મૂળ આકાર મેળવવાની ક્ષમતા છે. ઘન પદાર્થોમાં આ અણુઓની ગોઠવણી અને આંતરઅણુ બળો પર આધાર રાખે છે. પ્રકારો: (1) લીનીયર સ્થિતિસ્થાપકતા (Hookeનો નિયમ), (2) વોલ્યુમેટ્રિક સ્થિતિસ્થાપકતા, (3) આકાર સ્થિતિસ્થાપકતા.

  • સ્થિતિસ્થાપકતા = વિકૃતિ પછી મૂળ આકાર મેળવવાની ક્ષમતા
  • Hookeનો નિયમ: F = kx (x = વિસ્થાપન, k = સ્પ્રિંગ કોન્સ્ટન્ટ)
  • સ્થિતિસ્થાપક સીમાએ પાર થાય ત્યારે પ્લાસ્ટિક વિકૃતિ થાય
  • ઘન પદાર્થોમાં આંતરઅણુ બળો મજબૂત હોવાથી સ્થિતિસ્થાપકતા વધુ
🧠 Trick: હુકે કહે: F = kx, સ્થિતિ સ્થાપક રહે!

તણાવ અને વિકૃતિ

તણાવ (Stress) = આંતરિક બળ/ક્ષેત્રફળ (N/m²), વિકૃતિ (Strain) = લંબાઈમાં ફેરફાર/મૂળ લંબાઈ (બેડીમરૂ). તણાવ અને વિકૃતિ વચ્ચેનો ગુણોત્તર 'યંગ મોડ્યુલસ' (Y) કહેવાય. Y = તણાવ/વિકૃતિ.

  • તણાવ (σ) = F/A (પાસ્કલમાં)
  • વિકૃતિ (ε) = ΔL/L (બેડીમરૂ)
  • યંગ મોડ્યુલસ (Y) = σ/ε (પદાર્થની કડકાઈનું માપ)
  • Yનું મૂલ્ય પદાર્થ પર આધાર રાખે: સ્ટીલ > કોપર > રબર
🧠 Trick: Y = σ/ε, યાદ રાખો 'યંગ' એ 'સ્ટ્રોંગ'!

પોઇસનનો ગુણાંક (Poisson’s Ratio)

જ્યારે પદાર્થને લંબાઈ દિશામાં ખેંચવામાં આવે ત્યારે ચોખ્ખી દિશામાં સંકોચન થાય. પોઇસનનો ગુણાંક (μ) = આડી વિકૃતિ/લંબ વિકૃતિ. આદર્શ સ્થિતિસ્થાપક પદાર્થ માટે μ = 0.5.

  • μ = - (Δd/d) / (ΔL/L)
  • μનું મૂલ્ય 0 થી 0.5 વચ્ચે હોય
  • μ = 0.5 → અસંકોચનશીલ પદાર્થ (ઉદા. રબર)
  • μ < 0.5 → સામાન્ય ઘન પદાર્થો
🧠 Trick: મ્યુ (μ) એ આડી અને લંબ વિકૃતિનો ગુણોત્તર, 0.5 સુધી જાય!

વોલ્યુમેટ્રિક સ્થિતિસ્થાપકતા અને બલ્ક મોડ્યુલસ

જ્યારે પદાર્થ પર સમાન દબાણ લાગે ત્યારે તેના વોલ્યુમમાં ફેરફાર થાય. બલ્ક મોડ્યુલસ (K) = -V(dP/dV). Kનું મૂલ્ય પદાર્થની અસંકોચનશીલતાનું માપ છે.

  • બલ્ક મોડ્યુલસ (K) = -V(dP/dV)
  • Kનું મૂલ્ય જેટલું વધુ, પદાર્થ એટલો અસંકોચનશીલ
  • દ્રવ્યો અને વાયુઓ કરતાં ઘન પદાર્થોનું K વધુ
  • K અને Y વચ્ચે સંબંધ: K = Y / 3(1-2μ)
🧠 Trick: K એ 'કડક' પદાર્થનું માપ, V(dP/dV) સાથે જોડાય!

આકાર સ્થિતિસ્થાપકતા અને શિયર મોડ્યુલસ

જ્યારે પદાર્થ પર સમાન અને વિરુદ્ધ બળો લાગે ત્યારે આકારમાં ફેરફાર થાય. શિયર મોડ્યુલસ (G) = તણાવ/વિકૃતિ (આકાર વિકૃતિ). G = Y / 2(1+μ).

  • શિયર મોડ્યુલસ (G) = F/A / (Δx/L)
  • Gનું મૂલ્ય પદાર્થની આકાર સ્થિતિસ્થાપકતાનું માપ
  • G = Y / 2(1+μ)
  • સ્ટીલનું G ≈ 8 × 10¹⁰ N/m²
🧠 Trick: G એ 'ગોઠવણી' બદલવાની ક્ષમતા, Y અને μ સાથે જોડાય!

સ્થિતિસ્થાપક પદાર્થોની શક્તિ (Elastic Energy)

વિકૃત પદાર્થમાં સંગ્રહિત શક્તિ = ½ × સ્પ્રિંગ કોન્સ્ટન્ટ × (વિસ્થાપન)². આ શક્તિ પદાર્થને મૂળ આકારમાં પરત લાવે છે.

  • સંગ્રહિત શક્તિ (U) = ½ kx²
  • U = ½ × તણાવ × વિકૃતિ × વોલ્યુમ
  • આ શક્તિ પદાર્થની સ્થિતિસ્થાપક સીમાએ આધાર રાખે
  • x વધે ત્યારે U વર્ગ પ્રમાણે વધે
🧠 Trick: U = ½ kx², ઉર્જા એ 'અર્ધ કેએક્સ સ્ક્વેર'!

સ્થિતિસ્થાપકતાનાં પ્રાયોગિક ઉદાહરણો

સ્પ્રિંગ, રબર બેન્ડ, ધાતુઓની તાર, બ્રિજના કેબલ્સ વગેરે સ્થિતિસ્થાપક વર્તન દર્શાવે. ઇજિનિયરિંગમાં બિલ્ડિંગ, પુલ અને વાહનોના ડિઝાઇનમાં સ્થિતિસ્થાપકતાનું મહત્વ પડે છે.

  • સ્પ્રિંગ અને રબર બેન્ડ → Hookeનો નિયમ અનુસરે
  • ધાતુઓની તાર → યંગ મોડ્યુલસનું મહત્વ
  • બ્રિજના કેબલ્સ → તણાવ અને વિકૃતિનું સંચાલન
  • ઇજિનિયરિંગમાં સ્થિતિસ્થાપકતા → સુરક્ષા અને ટકાઉપણું

⚡ Quick Revision

  • સ્થિતિસ્થાપકતા = વિકૃતિ પછી મૂળ આકાર મેળવવાની ક્ષમતા
  • Hookeનો નિયમ: F = kx (સીમાએ અંદર)
  • તણાવ (σ) = F/A, વિકૃતિ (ε) = ΔL/L
  • યંગ મોડ્યુલસ (Y) = σ/ε (પદાર્થની કડકાઈ)
  • પોઇસનનો ગુણાંક (μ) = - (Δd/d) / (ΔL/L) (0 થી 0.5)
  • બલ્ક મોડ્યુલસ (K) = -V(dP/dV) (અસંકોચનશીલતા)
  • શિયર મોડ્યુલસ (G) = Y / 2(1+μ) (આકાર સ્થિતિસ્થાપકતા)
  • સંગ્રહિત શક્તિ (U) = ½ kx² અથવા ½ × σ × ε × V
  • સ્પ્રિંગ, રબર, ધાતુઓ → સ્થિતિસ્થાપક વર્તનના ઉદાહરણો
🎯 Exam Tip: સ્થિતિસ્થાપકતાના પ્રશ્નોમાં યંગ મોડ્યુલસ, પોઇસનનો ગુણાંક અને શિયર મોડ્યુલસ વચ્ચેના સંબંધો યાદ રાખો. ગણતરીમાં એકમો (N/m², પાસ્કલ) પર ધ્યાન આપો.
