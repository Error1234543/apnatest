Pro Notes

એન્ટ્રોપી

📖 એન્ટ્રોપી

એન્ટ્રોપીની વ્યાખ્યા

એન્ટ્રોપી એ થરમોડાયનેમિક્સનું એક મહત્વપૂર્ણ ગુણધર્મ છે જે સિસ્ટમની અવ્યવસ્થા અથવા અસ્તવ્યસ્તતાનું માપ આપે છે. તે સિસ્ટમની મક્રોસ્કોપિક અવસ્થાઓની સંખ્યાનો લોગારિધમિક માપ છે. એન્ટ્રોપીને S દ્વારા દર્શાવવામાં આવે છે અને તેની એસઆઈ યુનિટ J/K છે.

  • એન્ટ્રોપી = સિસ્ટમની અવ્યવસ્થાનું માપ
  • એસઆઈ યુનિટ: J/K (Joule per Kelvin)
  • એન્ટ્રોપી એ સ્થિતિજ ઉર્જાના વિતરણનું માપ છે
  • અવ્યવસ્થા વધે ત્યારે એન્ટ્રોપી વધે
🧠 Trick: S = k ln W (Boltzmann's formula, W = અવસ્થાઓની સંખ્યા)

એન્ટ્રોપી અને થરમોડાયનેમિક્સનો દ્વિતીય નિયમ

થરમોડાયનેમિક્સનો દ્વિતીય નિયમ કહે છે કે અલગ થયેલ સિસ્ટમની એન્ટ્રોપી હંમેશા વધે અથવા સ્થિર રહે. ΔS ≥ 0, જ્યાં ΔS એ એન્ટ્રોપીનો ફેરફાર છે. આ નિયમ એન્ટ્રોપીની દિશા સૂચવે છે — તે હંમેશા વધુ અવ્યવસ્થા તરફ વળે છે.

  • ΔS ≥ 0 (અલગ સિસ્ટમ માટે)
  • એન્ટ્રોપી ક્યારેય ઘટતી નથી (અલગ સિસ્ટમમાં)
  • દ્વિતીય નિયમ એન્ટ્રોપીની દિશા સૂચવે છે
  • ઉદા. ઉષ્મા હંમેશા ગરમથી ઠંડા તરફ વહે છે
🧠 Trick: એન્ટ્રોપીનો તીર હંમેશા ↑ (વધે)

એન્ટ્રોપીનો ગણિતીય સૂત્ર

એન્ટ્રોપીનો ફેરફાર ΔS = q_rev / T દ્વારા ગણી શકાય, જ્યાં q_rev એ રિવર્સિબલ પ્રક્રિયામાં વહન પામેલી ઉષ્મા છે અને T એ તાપમાન (Kમાં) છે. બોલ્ટ્ઝમેનના સૂત્ર મુજબ S = k ln W, જ્યાં k એ બોલ્ટ્ઝમેનનો અચળાંક (1.38 × 10^-23 J/K) અને W એ માઇક્રોસ્કોપિક અવસ્થાઓની સંખ્યા છે.

  • ΔS = q_rev / T (રિવર્સિબલ પ્રક્રિયા માટે)
  • S = k ln W (Boltzmann's formula)
  • k = 1.38 × 10^-23 J/K
  • W = માઇક્રોસ્કોપિક અવસ્થાઓની સંખ્યા

એન્ટ્રોપી પર તાપમાનનો પ્રભાવ

તાપમાન વધારવાથી એન્ટ્રોપી વધે છે કારણ કે ઉર્જાના વિતરણની સંભાવનાઓ વધે છે. ઉદાહરણ તરીકે, બરફ પીગળવાથી પાણી બનવું એ એન્ટ્રોપી વધારવાની પ્રક્રિયા છે. તાપમાન ઘટાડવાથી એન્ટ્રોપી ઘટે છે, પરંતુ ક્યારેય શૂન્ય સુધી પહોંચતી નથી (ત્રિજ્યા નિયમ).

  • તાપમાન ↑ → એન્ટ્રોપી ↑
  • બરફ → પાણી: ΔS > 0
  • તાપમાન ↓ → એન્ટ્રોપી ↓ (પરંતુ S ≠ 0)
  • ત્રિજ્યા નિયમ: S → 0 જ્યારે T → 0K
🧠 Trick: ગરમી વધે, ગડબડ વધે

એન્ટ્રોપી અને રાસાયણિક પ્રક્રિયાઓ

રાસાયણિક પ્રક્રિયાઓમાં એન્ટ્રોપીનો ફેરફાર ΔS = ΣS(પ્રોડક્ટ્સ) - ΣS(રિએક્ટન્ટ્સ) દ્વારા ગણી શકાય. જ્યારે પ્રક્રિયામાં ગેસની મોલની સંખ્યા વધે ત્યારે એન્ટ્રોપી વધે. ઉદા. CaCO3(s) → CaO(s) + CO2(g)માં ΔS > 0.

  • ΔS = ΣS(પ્રોડક્ટ્સ) - ΣS(રિએક્ટન્ટ્સ)
  • ગેસની મોલ ↑ → ΔS ↑
  • ઘન/દ્રવ → ગેસ: ΔS > 0
  • ઉદા. CaCO3(s) → CaO(s) + CO2(g): ΔS > 0
🧠 Trick: ગેસ બને, એન્ટ્રોપી વધે

એન્ટ્રોપી અને જીવન પ્રક્રિયાઓ

જીવન પ્રક્રિયાઓ એન્ટ્રોપીને ઘટાડવા પ્રયત્ન કરે છે, પરંતુ અલગ સિસ્ટમ (બ્રહ્માંડ)ની એન્ટ્રોપી હંમેશા વધે છે. ઉદા. પ્રકાશસંશ્લેષણમાં સૂર્યપ્રકાશની ઉર્જાનો ઉપયોગ કરીને ગ્લુકોઝ બનાવવામાં આવે છે, જે એન્ટ્રોપી ઘટાડવાની પ્રક્રિયા છે, પરંતુ સિસ્ટમ અને પર્યાવરણની કુલ એન્ટ્રોપી વધે છે.

  • જીવન પ્રક્રિયાઓ એન્ટ્રોપી ઘટાડવા પ્રયત્ન કરે છે
  • પ્રકાશસંશ્લેષણ: એન્ટ્રોપી ઘટાડવી પ્રક્રિયા
  • બ્રહ્માંડની કુલ એન્ટ્રોપી હંમેશા વધે છે
  • ΔS_total = ΔS_system + ΔS_surroundings ≥ 0

  • એસઆઈ યુનિટ: J/K
  • ΔS ≥ 0 (દ્વિતીય નિયમ)

  • ગેસની મોલ ↑ → ΔS ↑

  • બ્રહ્માંડની કુલ એન્ટ્રોપી હંમેશા વધે છે
  • ત્રિજ્યા નિયમ: S → 0 જ્યારે T → 0K
🎯 Exam Tip: એન્ટ્રોપીના પ્રશ્નોમાં હંમેશા ΔS = ΣS(પ્રોડક્ટ્સ) - ΣS(રિએક્ટન્ટ્સ) નો ઉપયોગ કરો અને ગેસની મોલની સંખ્યાને ધ્યાનમાં લો — જ્યારે ગેસની મોલ વધે ત્યારે ΔS હંમેશા ધન હશે.
