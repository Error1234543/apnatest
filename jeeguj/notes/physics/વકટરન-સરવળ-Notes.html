વેક્ટરનું સરવાળું

📖 વેક્ટરનું સરવાળું

વેક્ટરની મૂળભૂત સમજ

વેક્ટર એ પરિમાણ અને દિશા ધરાવતી ભૌતિક રાશિ છે. તેને ગ્રાફ પર તીરની મદદથી દર્શાવાય છે, જ્યાં તીરની લંબાઈ પરિમાણ અને દિશા દર્શાવે છે. વેક્ટરનું સરવાળું એ બે અથવા વધુ વેક્ટરના પરિણામી વેક્ટરને શોધવાની પ્રક્રિયા છે.

  • વેક્ટર = પરિમાણ + દિશા
  • સદિશ રાશિનું ઉદાહરણ: બળ, વેગ, વિસ્થાપન
  • વેક્ટરને **A→** અથવા **A** (બોલ્ડ) વડે દર્શાવાય છે
  • વેક્ટરની લંબાઈ = |A| = A
🧠 Trick: વેક્ટર = વેગ + દિશા (વ + દ)

વેક્ટર સરવાળાનાં નિયમો

વેક્ટર સરવાળા માટે મુખ્યત્વે ત્રણ પદ્ધતિઓ વપરાય છે: (1) ત્રિકોણ નિયમ, (2) સમલંબ નિયમ, (3) ઘટક પદ્ધતિ. ત્રિકોણ નિયમમાં બે વેક્ટરને ક્રમશઃ જોડીને પરિણામી વેક્ટર મેળવવામાં આવે છે.

  • ત્રિકોણ નિયમ: A→ + B→ = R→ (Aના અંતથી Bની શરૂઆત)
  • સમલંબ નિયમ: બે વેક્ટરને સમાન બિંદુ પર મૂકીને સમલંબ પૂરો કરો
  • ઘટક પદ્ધતિ: X અને Y અક્ષ પર વેક્ટરના ઘટકો શોધીને સરવાળો કરો
  • પરિણામી વેક્ટર R = √(A² + B² + 2ABcosθ) (ત્રિકોણ નિયમ)
🧠 Trick: ત્રિ-સમ-ઘટક (ત્રિકોણ, સમલંબ, ઘટક)

ત્રિકોણ નિયમનો ઉપયોગ

ત્રિકોણ નિયમમાં, પ્રથમ વેક્ટરના અંતબિંદુ પર દ્વિતીય વેક્ટરની શરૂઆત મૂકવામાં આવે છે. પરિણામી વેક્ટર પ્રથમ વેક્ટરની શરૂઆતથી દ્વિતીય વેક્ટરના અંત સુધી લંબાય છે. આ નિયમ વેક્ટરના સરવાળા અને બાદબાકી બંને માટે લાગુ પડે છે.

  • A→ + B→: Aના અંતથી Bની શરૂઆત
  • A→ - B→ = A→ + (-B→)
  • પરિણામી વેક્ટરની દિશા: પ્રથમ વેક્ટરથી દ્વિતીય વેક્ટર તરફ
  • ત્રિકોણ નિયમ ફક્ત બે વેક્ટર માટે જ લાગુ પડે છે

સમલંબ નિયમનો ઉપયોગ

સમલંબ નિયમમાં, બે વેક્ટરને સમાન બિંદુ પર મૂકીને તેમની દિશા અનુસાર સમલંબ પૂરો કરવામાં આવે છે. પરિણામી વેક્ટર સમલંબના વિકર્ણ તરીકે મળે છે. આ પદ્ધતિ વેક્ટરના સરવાળા માટે સરળ અને દ્રષ્ટિગત રીતે સ્પષ્ટ છે.

  • બે વેક્ટરને સમાન બિંદુ પર મૂકો
  • સમલંબ પૂરો કરો, પરિણામી વેક્ટર = વિકર્ણ
  • R = √(A² + B² + 2ABcosθ)
  • θ = બે વેક્ટર વચ્ચેનો ખૂણો
🧠 Trick: સમલંબ = સરવાળો + વિકર્ણ

ઘટક પદ્ધતિ

ઘટક પદ્ધતિમાં, વેક્ટરને X અને Y અક્ષ પરના ઘટકોમાં વિભાજીત કરવામાં આવે છે. પ્રત્યેક વેક્ટરના X અને Y ઘટકોનો સરવાળો કરીને પરિણામી વેક્ટરના ઘટકો મેળવવામાં આવે છે. આ પદ્ધતિ ગણિતીય રીતે સચોટ અને વ્યવહારુ છે.

  • A→ = A_x î + A_y ĵ
  • પરિણામી વેક્ટર R = (A_x + B_x)î + (A_y + B_y)ĵ
  • Rની લંબાઈ = √((A_x+B_x)² + (A_y+B_y)²)
  • Rની દિશા: tanφ = (A_y+B_y)/(A_x+B_x)
🧠 Trick: X-Y ઘટક = સરવાળો + દિશા

વેક્ટર સરવાળાના ગુણધર્મો

વેક્ટર સરવાળા માટે કમ્યુટેટિવ અને એસોસિએટિવ ગુણધર્મો લાગુ પડે છે. એટલે કે, A→ + B→ = B→ + A→ અને (A→ + B→) + C→ = A→ + (B→ + C→). આ ગુણધર્મો વેક્ટરના સરવાળાને સરળ બનાવે છે.

  • કમ્યુટેટિવ: A→ + B→ = B→ + A→
  • એસોસિએટિવ: (A→ + B→) + C→ = A→ + (B→ + C→)
  • શૂન્ય વેક્ટર: A→ + 0→ = A→
  • ઇનવર્સ વેક્ટર: A→ + (-A→) = 0→
🧠 Trick: કમ-એસો-શૂન્ય (કમ્યુટેટિવ, એસોસિએટિવ, શૂન્ય)

વેક્ટર સરવાળાનાં ઉદાહરણો

વેક્ટર સરવાળાનાં ઉદાહરણો ભૌતિક વિજ્ઞાનમાં ઘણા જોવા મળે છે, જેમ કે બળોનું સરવાળું, વેગનું સરવાળું, વિસ્થાપનનું સરવાળું વગેરે. ઉદાહરણ તરીકે, બે બળો F₁ અને F₂ એક જ બિંદુ પર લાગુ થાય ત્યારે પરિણામી બળ F = F₁ + F₂ થાય છે.

  • બળોનું સરવાળું: F→ = F₁→ + F₂→
  • વેગનું સરવાળું: v→ = v₁→ + v₂→
  • વિસ્થાપનનું સરવાળું: d→ = d₁→ + d₂→
  • વેક્ટર સરવાળું ભૌતિક રાશિઓના સંયોજન માટે ઉપયોગી

⚡ Quick Revision

  • વેક્ટર = પરિમાણ + દિશા
  • ત્રિકોણ નિયમ: A→ + B→ = R→ (Aના અંતથી Bની શરૂઆત)
  • સમલંબ નિયમ: પરિણામી વેક્ટર = સમલંબનો વિકર્ણ
  • ઘટક પદ્ધતિ: X અને Y ઘટકોનો સરવાળો
  • R = √(A² + B² + 2ABcosθ) (ત્રિકોણ નિયમ)
  • કમ્યુટેટિવ ગુણધર્મ: A→ + B→ = B→ + A→
  • એસોસિએટિવ ગુણધર્મ: (A→ + B→) + C→ = A→ + (B→ + C→)
  • શૂન્ય વેક્ટર: A→ + 0→ = A→
  • બળ, વેગ, વિસ્થાપન વગેરેનું સરવાળું વેક્ટર સરવાળા વડે થાય
  • વેક્ટર સરવાળા માટે ત્રણ મુખ્ય પદ્ધતિઓ: ત્રિકોણ, સમલંબ, ઘટક
🎯 Exam Tip: વેક્ટર સરવાળાના પ્રશ્નોમાં, હંમેશા ચિત્ર દોરીને ત્રિકોણ અથવા સમલંબ નિયમ લાગુ કરો. ઘટક પદ્ધતિ વાપરતી વખતે X અને Y ઘટકોને અલગ અલગ ગણો.
