ફોટોઇલેક્ટ્રિક અસર

📖 ફોટોઇલેક્ટ્રિક અસર

પરિભાષા અને મૂળભૂત સંકલ્પના

ફોટોઇલેક્ટ્રિક અસરમાં, પ્રકાશની તરંગલંબાઇ ની ચોક્કસ કિંમતથી ઓછી હોવી જોઈએ જેથી ધાતુની સપાટી પરથી ઇલેક્ટ્રૉન બહાર નીકળે. આ અસર એલબર્ટ આઈન્સ્ટાઈન દ્વારા સમજાવવામાં આવ્યો હતો, જેમણે પ્રકાશને ફોટોન (કણ) તરીકે ગણાવ્યો હતો.

  • ફોટોનની ઊર્જા E = hν (h = પ્લાંક અચળાંક, ν = આવર્તન)
  • કામ કરવાની ફંક્શન (φ) ધાતુ પર આધાર રાખે છે
  • ઇલેક્ટ્રૉનની ગતિઊર્જા KE = hν - φ
  • અસર તરત જ થાય છે, વિલંબ રહિત
🧠 Trick: હે ફોટોન, કામ કર અને ઇલેક્ટ્રૉન કાઢ (E = hν - φ)

પરીક્ષણની યોજના અને નિરીક્ષણો

હર્ટઝના પ્રયોગમાં, જ્યારે અલ્ટ્રાવાયોલેટ પ્રકાશ ધાતુની પ્લેટ પર પડે છે, ત્યારે ઇલેક્ટ્રૉન બહાર નીકળે છે અને વિદ્યુત ક્ષેત્ર દ્વારા વેગવાન કરવામાં આવે છે. નિરીક્ષણો: (1) પ્રકાશની તીવ્રતા વધારવાથી ઇલેક્ટ્રૉનની સંખ્યા વધે છે, પરંતુ ગતિઊર્જા નહીં. (2) આવર્તન વધારવાથી ગતિઊર્જા વધે છે.

  • તીવ્રતા ⇒ ઇલેક્ટ્રૉનની સંખ્યા ↑
  • આવર્તન ⇒ ગતિઊર્જા ↑
  • ક્રિટિકલ આવર્તન (ν₀) નીચે અસર થતી નથી
  • વિલંબ રહિત પ્રતિક્રિયા

આઈન્સ્ટાઈનનું સમીકરણ

આઈન્સ્ટાઈનના ફોટોઇલેક્ટ્રિક સમીકરણ અનુસાર, ફોટોનની ઊર્જા ધાતુની કામ કરવાની ફંક્શન અને ઇલેક્ટ્રૉનની ગતિઊર્જાનો સરવૈયો હોય છે. KE_max = hν - φ, જ્યાં φ = hν₀ (ν₀ = ક્રિટિકલ આવર્તન).

  • KE_max = hν - hν₀
  • ν < ν₀ ⇒ KE = 0 (ઇલેક્ટ્રૉન બહાર નહીં નીકળે)
  • hν₀ = કામ કરવાની ફંક્શન (φ)
  • સમીકરણ નોબેલ પારિતોષિક જીતવાનું કારણ બન્યું
🧠 Trick: હે નીકળ, KE = h(ν - ν₀)

ગતિઊર્જા અને સ્ટોપિંગ પોટેન્શિયલ

ઇલેક્ટ્રૉનની મહત્તમ ગતિઊર્જાને રોકવા માટે જરૂરી વિદ્યુત ક્ષેત્રને સ્ટોપિંગ પોટેન્શિયલ (V₀) કહે છે. eV₀ = KE_max = hν - φ. આના દ્વારા h અને φ નક્કી કરી શકાય છે.

  • V₀ ∝ (ν - ν₀)
  • ગ્રાફ: V₀ vs ν ⇒ સરળ રેખા, ઢાળ = h/e
  • X-અક્ષ કાપ = ν₀
  • Y-અક્ષ કાપ = -φ/e
🧠 Trick: V₀ = (h/e)ν - (φ/e) → સરળ રેખાનું સમીકરણ

અનુપ્રયોગો અને ઉપયોગિતા

ફોટોઇલેક્ટ્રિક અસરનો ઉપયોગ ફોટોસેલ, સોલાર પેનલ, અને ડિજિટલ કેમેરામાં થાય છે. ફોટોસેલમાં, પ્રકાશ પડવાથી ઇલેક્ટ્રૉન મુક્ત થાય છે અને વિદ્યુત પ્રવાહ ઉત્પન્ન થાય છે.

  • ફોટોસેલ: પ્રકાશ ⇒ વિદ્યુત પ્રવાહ
  • સોલાર પેનલ: સૂર્યપ્રકાશ ⇒ વિદ્યુત ઊર્જા
  • ડિજિટલ કેમેરા: પ્રકાશ ⇒ ડિજિટલ સિગ્નલ
  • અત્યાધુનિક ટેક્નોલોજીમાં મહત્વપૂર્ણ

સીમા અને વાસ્તવિક જીવનમાં મર્યાદાઓ

ફોટોઇલેક્ટ્રિક અસર માટે પ્રકાશનું આવર્તન ક્રિટિકલ આવર્તનથી વધારે હોવું જરૂરી છે. તીવ્રતા વધારવાથી ઇલેક્ટ્રૉનની સંખ્યા વધે છે, પરંતુ એક ઇલેક્ટ્રૉનની ગતિઊર્જા પર અસર થતી નથી.

  • ν < ν₀ ⇒ કોઈ ઇલેક્ટ્રૉન બહાર નહીં
  • તીવ્રતા ↑ ⇒ ઇલેક્ટ્રૉનની સંખ્યા ↑, KE સમાન
  • અસર કેવળ ધાતુઓ અને કેટલીક અર્ધચાલકોમાં જોવા મળે છે
  • ઊર્જા સંરક્ષણનો નિયમ લાગુ પડે છે

⚡ Quick Revision

  • ફોટોઇલેક્ટ્રિક અસર = પ્રકાશ + ધાતુ ⇒ ઇલેક્ટ્રૉન બહાર
  • E = hν (ફોટોનની ઊર્જા)
  • KE_max = hν - φ (φ = કામ કરવાની ફંક્શન)
  • ν₀ = ક્રિટિકલ આવર્તન, ν < ν₀ ⇒ કોઈ અસર નહીં
  • V₀ = સ્ટોપિંગ પોટેન્શિયલ, eV₀ = KE_max
  • ગ્રાફ V₀ vs ν ⇒ સરળ રેખા, ઢાળ = h/e
  • આઈન્સ્ટાઈનનું સમીકરણ ⇒ નોબેલ પારિતોષિક
  • ફોટોસેલ: પ્રકાશ ⇒ વિદ્યુત પ્રવાહ
  • સોલાર પેનલ: સૂર્યપ્રકાશ ⇒ વિદ્યુત ઊર્જા
  • અસર તરત જ થાય છે, વિલંબ રહિત
🎯 Exam Tip: ગ્રાફ-આધારિત પ્રશ્નોમાં V₀ vs ν ગ્રાફ યાદ રાખો: ઢાળ = h/e અને X-અક્ષ કાપ = ν₀. આથી h અને φ શોધી શકાશે.
