ઉષ્મા ક્ષમતા

📖 ઉષ્મા ક્ષમતા

પરિભાષા અને મૂળભૂત સૂત્ર

ઉષ્મા ક્ષમતા (Heat Capacity) એ પદાર્થની તેની તાપમાનમાં એક યુનિટ વધારો કરવા માટે જરૂરી ઉષ્મા છે. તેને Q = mcΔT સૂત્ર વડે વ્યાખ્યાયિત કરવામાં આવે છે, જ્યાં m = દળ, c = વિશિષ્ટ ઉષ્મા ક્ષમતા, ΔT = તાપમાન પરિવર્તન.

  • ઉષ્મા ક્ષમતા (C) = mc (દળ × વિશિષ્ટ ઉષ્મા)
  • SI એકમ: J/K અથવા J/°C
  • તાપમાન પરિવર્તન સાથે ઉષ્મા ક્ષમતા બદલાતી નથી
  • પદાર્થની અવસ્થા (ઘન, દ્રવ, વાયુ) અનુસાર બદલાય છે
🧠 Trick: C = mc → 'સી' મહત્વનું છે, 'મ' દળ છે, 'સી' વિશિષ્ટ છે

વિશિષ્ટ ઉષ્મા ક્ષમતા (c)

વિશિષ્ટ ઉષ્મા ક્ષમતા એ એક ગ્રામ પદાર્થની તાપમાનમાં 1°C વધારવા માટે જરૂરી ઉષ્મા છે. તે પદાર્થની પ્રકૃતિ પર આધાર રાખે છે. ઉદા. પાણીની c = 4.18 J/g°C.

  • પાણીની વિશિષ્ટ ઉષ્મા સૌથી વધુ છે (4.18 J/g°C)
  • ધાતુઓની c ઓછી હોય છે (ઉદા. તાંબા = 0.385 J/g°C)
  • વાયુઓમાં c, દબાણ અને વોલ્યુમ પર આધાર રાખે છે (Cp, Cv)
  • Cv (સ્થિર વોલ્યુમ) < Cp (સ્થિર દબાણ)
🧠 Trick: પાણી ગરમ થાય છે ધીમે → c વધારે

ઉષ્મા ક્ષમતા અને અવસ્થા પરિવર્તન

અવસ્થા પરિવર્તન દરમિયાન (ઉદા. બરફ → પાણી) તાપમાન સ્થિર રહે છે, પરંતુ ઉષ્મા શોષાય છે. આને ગુપ્ત ઉષ્મા (Latent Heat) કહે છે. ઉષ્મા ક્ષમતા અહીં અનંત હોય છે કેમ કે ΔT = 0.

  • ગુપ્ત ઉષ્મા (L) = Q/m (J/kg)
  • બરફના ગલનની L = 334 kJ/kg
  • પાણીના બાષ્પીભવનની L = 2260 kJ/kg
  • અવસ્થા પરિવર્તન દરમિયાન તાપમાન બદલાતું નથી
🧠 Trick: ગુપ્ત ઉષ્મા → 'ગુપ્ત' રીતે ઉષ્મા શોષાય છે

ઉષ્મા ક્ષમતાનો વાયુઓમાં ઉપયોગ

વાયુઓ માટે ઉષ્મા ક્ષમતા દબાણ (Cp) અને વોલ્યુમ (Cv) પર આધાર રાખે છે. Cp - Cv = R (વાયુ અચળાંક). એકપરમાણ્વિક વાયુઓમાં Cv = (3/2)R, Cp = (5/2)R.

  • Cp - Cv = R (મેયરનો નિયમ)
  • દ્વિપરમાણ્વિક વાયુઓ: Cv = (5/2)R, Cp = (7/2)R
  • γ (Cp/Cv) એ વાયુનો અચળાંક છે
  • γ એકપરમાણ્વિક = 1.66, દ્વિપરમાણ્વિક = 1.4
🧠 Trick: Cp - Cv = R → 'સી પી માઈનસ સી વી આર છે'

ઉષ્મા ક્ષમતા અને ઉષ્મગતિકીનો પ્રથમ નિયમ

ઉષ્માગતિકીનો પ્રથમ નિયમ ΔQ = ΔU + ΔW છે. ઉષ્મા ક્ષમતા આ નિયમ સાથે સંકળાયેલ છે કેમ કે ΔU = mcΔT (જ્યારે કોઈ કામ ન થાય).

  • ΔU = mcΔT (આંતરિક ઉર્જા પરિવર્તન)
  • ΔQ = ઉષ્માનું શોષણ/મુક્તિ
  • ΔW = પદાર્થ દ્વારા કરેલ કામ
  • સ્થિર વોલ્યુમે ΔW = 0, આથી ΔQ = ΔU
🧠 Trick: Q = U + W → 'ક્યૂ યુ ડબલ્યુ'

ઉષ્મા ક્ષમતાનો વ્યવહારિક ઉપયોગ

ઉષ્મા ક્ષમતાનો ઉપયોગ કેલોરિમીટ્રી, ઉષ્મા ઇજનેરિંગ, અને હવામાનશાસ્ત્રમાં થાય છે. ઉદા. કેલોરિમીટ્રીમાં પદાર્થની વિશિષ્ટ ઉષ્મા માપવા માટે ઉષ્મા ક્ષમતાનો ઉપયોગ કરવામાં આવે છે.

  • કેલોરિમીટ્રી: Q_gain = Q_loss
  • ઉષ્મા ઇજનેરિંગ: બોઈલર, કંડેન્સર ડિઝાઈન
  • હવામાનશાસ્ત્ર: તાપમાન પરિવર્તનનો અભ્યાસ
  • ઔદ્યોગિક પ્રક્રિયાઓમાં ઉષ્મા વહનનું નિયંત્રણ

⚡ Quick Revision

  • ઉષ્મા ક્ષમતા (C) = mc (દળ × વિશિષ્ટ ઉષ્મા)
  • SI એકમ: J/K અથવા J/°C
  • પાણીની વિશિષ્ટ ઉષ્મા = 4.18 J/g°C (સૌથી વધુ)
  • ગુપ્ત ઉષ્મા = Q/m (J/kg), અવસ્થા પરિવર્તન દરમિયાન ΔT = 0
  • Cp - Cv = R (મેયરનો નિયમ)
  • γ = Cp/Cv (વાયુઓ માટે)
  • ΔU = mcΔT (આંતરિક ઉર્જા પરિવર્તન)
  • કેલોરિમીટ્રીમાં Q_gain = Q_loss
  • ઉષ્મા ક્ષમતા અવસ્થા પર આધાર રાખે છે
  • વાયુઓમાં Cp > Cv
🎯 Exam Tip: ઉષ્મા ક્ષમતા અને વિશિષ્ટ ઉષ્મા વચ્ચેનો તફાવત સ્પષ્ટ કરો. JEEમાં Cp, Cv, અને γ ના સૂત્રો યાદ રાખવા ખૂબ જ મહત્વના છે.
