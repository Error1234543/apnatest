ઉષ્મા સંચાર

📖 ઉષ્મા સંચાર

ઉષ્મા સંચારની મૂળભૂત સમજ

ઉષ્મા સંચાર એ ઉર્જાના સ્ત્રોતથી નીચા તાપમાનવાળા વિસ્તાર તરફ ઉર્જાનું સ્થાનાંતરણ છે. તે ત્રણ પ્રકારે થાય છે: ચાલન, સંવહન અને વિકિરણ. JEEમાં આ ત્રણેય પ્રકારની ગણતરીઓ અને અનુપ્રયોગો મહત્વના છે.

  • ઉષ્મા હંમેશા ઉચ્ચ તાપમાનથી નીચા તાપમાન તરફ વહે છે.
  • ચાલનમાં પદાર્થના કણોની ગતિ દ્વારા ઉષ્મા સ્થાનાંતરિત થાય છે.
  • સંવહનમાં પદાર્થના બલ્ક ફ્લો દ્વારા ઉષ્મા સ્થાનાંતરિત થાય છે.
  • વિકિરણમાં ઉર્જા વિદ્યુતચુંબકીય તરંગો દ્વારા સ્થાનાંતરિત થાય છે.
🧠 Trick: ચસવ: ચાલન, સંવહન, વિકિરણ

ચાલન (Conduction)

ચાલનમાં ઉષ્મા પદાર્થના કણોની ટક્કર દ્વારા એક બાજુથી બીજી બાજુએ સ્થાનાંતરિત થાય છે. ધાતુઓમાં મુક્ત ઇલેક્ટ્રોનના કારણે ચાલનની ક્ષમતા ઉચ્ચ હોય છે. ફુરિયરનો નિયમ: Q = -kA(dT/dx).

  • ચાલન માટે પદાર્થમાં તાપમાન પ્રસર (temperature gradient) જરૂરી છે.
  • ધાતુઓ ઉત્તમ ચાલક છે, જ્યારે વાયુઓ ખરાબ ચાલક છે.
  • ઉષ્મીય ચાલકતા (k) પદાર્થની મૂળભૂત ગુણધર્મ છે.
  • ફુરિયરનો નિયમ: Q = -kA(dT/dx), જ્યાં Q = ઉષ્મા પ્રવાહ, k = ઉષ્મીય ચાલકતા, A = ક્ષેત્રફળ, dT/dx = તાપમાન પ્રસર.
🧠 Trick: ક્યાં કામ આ રહ્યું? ક = ઉષ્મીય ચાલકતા, A = ક્ષેત્રફળ, dT/dx = પ્રસર

સંવહન (Convection)

સંવહનમાં ઉષ્મા પદાર્થના બલ્ક ફ્લો દ્વારા સ્થાનાંતરિત થાય છે. તે પ્રવાહી (દ્રવ અને વાયુ)માં જોવા મળે છે. પ્રાકૃતિક અને બળાત્મક સંવહન એ બે પ્રકાર છે.

  • પ્રાકૃતિક સંવહનમાં પદાર્થનો ફ્લો ગુરુત્વાકર્ષણના કારણે થાય છે.
  • બળાત્મક સંવહનમાં બાહ્ય બળ (જેમ કે પંખો) દ્વારા ફ્લો થાય છે.
  • સંવહન માટે પદાર્થમાં ગતિ જરૂરી છે.
  • ન્યૂટનનો શીતલન નિયમ: dQ/dt = hA(T - T₀), જ્યાં h = સંવહન ગુણાંક.
🧠 Trick: પ્રબળ: પ્રાકૃતિક અને બળાત્મક સંવહન

વિકિરણ (Radiation)

વિકિરણમાં ઉર્જા વિદ્યુતચુંબકીય તરંગો દ્વારા સ્થાનાંતરિત થાય છે. તે નિર્વાતમાં પણ થઈ શકે છે. સ્ટેફન-બોલ્ટઝમેનનો નિયમ: P = σAT⁴, જ્યાં σ = સ્ટેફન-બોલ્ટઝમેન અચળાંક.

  • વિકિરણ માટે માધ્યમની જરૂરિયાત નથી.
  • કાળા પદાર્થો ઉત્તમ શોષક અને ઉત્સર્જક છે.
  • સ્ટેફન-બોલ્ટઝમેનનો નિયમ: P = σAT⁴, જ્યાં P = વિકિરણ શક્તિ, A = ક્ષેત્રફળ, T = તાપમાન.
  • વિનના વિકિરણ નિયમ: λ_max * T = b, જ્યાં b = વિનનો અચળાંક.
🧠 Trick: કાળો = શોષક = ઉત્સર્જક

ઉષ્મા સંચારના અનુપ્રયોગો

ઉષ્મા સંચારના અનુપ્રયોગો દૈનિક જીવન અને ટેક્નોલોજીમાં વિશાળ છે. ઉદાહરણ તરીકે, થર્મલ પાવર પ્લાન્ટ્સ, રેફ્રિજરેટર, અને સોલાર પેનલ્સમાં ઉષ્મા સંચારના સિદ્ધાંતોનો ઉપયોગ થાય છે.

  • થર્મલ પાવર પ્લાન્ટ્સમાં બોઈલરમાં ઉષ્મા સંચાર થાય છે.
  • રેફ્રિજરેટરમાં ઉષ્મા નીકાળવા માટે સંવહન અને ચાલનનો ઉપયોગ થાય છે.
  • સોલાર પેનલ્સમાં સૂર્યના વિકિરણને વિદ્યુત ઉર્જામાં રૂપાંતરિત કરવામાં આવે છે.
  • થર્મોસ ફ્લાસ્કમાં વિકિરણ અને સંવહન દ્વારા ઉષ્મા હાનિ રોકવામાં આવે છે.

ઉષ્મીય પ્રતિરોધ અને સંયુક્ત પદાર્થો

ઉષ્મીય પ્રતિરોધ એ પદાર્થની ઉષ્મા પ્રવાહને વિરોધ કરવાની ક્ષમતા છે. સંયુક્ત પદાર્થોમાં ઉષ્મીય પ્રતિરોધોનો સરવાળો થાય છે. ઉષ્મીય ચાલકતા અને પ્રતિરોધ વચ્ચેનો સંબંધ R = L/(kA) છે.

  • ઉષ્મીય પ્રતિરોધ (R) = L/(kA), જ્યાં L = લંબાઈ, k = ઉષ્મીય ચાલકતા, A = ક્ષેત્રફળ.
  • શ્રેણીમાં જોડેલા પદાર્થોના ઉષ્મીય પ્રતિરોધોનો સરવાળો થાય છે.
  • સમાંતરમાં જોડેલા પદાર્થોના ઉષ્મીય ચાલકતાનો સરવાળો થાય છે.
  • ઉષ્મીય પ્રતિરોધનો એકમ K/W છે.
🧠 Trick: રસ્તા: R = L/(kA)
