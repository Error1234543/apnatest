કોણીય સંવેગનું સંરક્ષણ

📖 કોણીય સંવેગનું સંરક્ષણ

પરિભાષા અને મૂળભૂત સંકલ્પના

કોણીય સંવેગ (Angular momentum) એ વસ્તુની ઘૂર્ણન ગતિ સાથે સંકળાયેલ વેક્ટર રાશિ છે. તેને L = r × p વડે વ્યાખ્યાયિત કરવામાં આવે છે, જ્યાં r સ્થાન વેક્ટર અને p રેખીય સંવેગ છે. તેની દિશા લંબરૂપે ઘૂર્ણન અક્ષને અનુરૂપ હોય છે.

  • L = r × p (વેક્ટર ક્રોસ ગુણાકાર)
  • SI એકમ: kg·m²/s
  • સદિશ રાશિ, દિશા લંબરૂપે ઘૂર્ણન અક્ષને
  • ઘૂર્ણન ગતિ માટે L = Iω (I = જડત્વ આઘૂર્ણ, ω = કોણીય વેગ)
🧠 Trick: LARP: L = r × p

સંરક્ષણનો નિયમ

બાહ્ય બળઆઘૂર્ણ શૂન્ય હોય ત્યારે કોણીય સંવેગ સંરક્ષિત રહે છે. આનો અર્થ એ કે, L = સ્થિર. આ નિયમ ક્લાસિકલ અને ક્વોન્ટમ મેકેનિક્સ બંનેમાં લાગુ પડે છે.

  • બાહ્ય ટોર્ક (τ) = 0 ⇒ dL/dt = 0
  • L સંરક્ષિત રહે છે
  • ઉદા: સ્કેટરનું ઘૂર્ણન, ગ્રહોની કક્ષા
  • ક્વોન્ટમ મેકેનિક્સમાં L ક્વોન્ટાઇઝ્ડ હોય છે
🧠 Trick: ટોર્ક શૂન્ય, L સ્થિર

જડત્વ આઘૂર્ણ (I) અને કોણીય વેગ (ω)

જડત્વ આઘૂર્ણ (I) એ વસ્તુની ઘૂર્ણન જડત્વનું માપ છે. કોણીય સંવેગ L = Iω વડે વ્યક્ત કરવામાં આવે છે. Iનું મૂલ્ય વસ્તુના દળ અને દળના વિતરણ પર આધાર રાખે છે.

  • I = Σmr² (વ્યાખ્યા)
  • L = Iω (ઘૂર્ણન ગતિ માટે)
  • Iનું મૂલ્ય ઘૂર્ણન અક્ષ પર આધાર રાખે છે
  • ઉદા: ડિસ્ક, રિંગ, સિલિન્ડર માટે I અલગ અલગ

ઉદાહરણ: ગ્રહોની ગતિ

ગ્રહો સૂર્યની આસપાસ અંડાકાર કક્ષામાં ફરે છે. સૂર્યના ગુરુત્વાકર્ષણ બળનું ટોર્ક શૂન્ય હોય છે, જેથી કોણીય સંવેગ સંરક્ષિત રહે છે. આના કારણે ગ્રહોની કક્ષીય ગતિ સ્થિર રહે છે.

  • ગ્રહો માટે τ = 0 ⇒ L સંરક્ષિત
  • કેપલરનો બીજો નિયમ: r × v = સ્થિર (L સંરક્ષણનું પરિણામ)
  • કોણીય સંવેગ સંરક્ષણ ગ્રહોની ગતિ સમજાવે છે
🧠 Trick: કેપલર + L = સ્થિર કક્ષા

ઉદાહરણ: સ્કેટરનું ઘૂર્ણન

જ્યારે સ્કેટર તેના હાથ પસવારે ખેંચે છે, ત્યારે તેનું જડત્વ આઘૂર્ણ (I) ઘટે છે. કોણીય સંવેગ સંરક્ષણના કારણે, કોણીય વેગ (ω) વધે છે, જેથી L = Iω સ્થિર રહે છે.

  • I ઘટે ⇒ ω વધે (L સ્થિર)
  • ઉદા: બેલે ડાન્સર, આઇસ સ્કેટર
  • ઘૂર્ણન વેગમાં વધારો થાય છે
🧠 Trick: I↓ ⇒ ω↑ (L સ્થિર)

ક્વોન્ટમ મેકેનિક્સમાં કોણીય સંવેગ

ક્વોન્ટમ મેકેનિક્સમાં, કોણીય સંવેગ ક્વોન્ટાઇઝ્ડ હોય છે. ઇલેક્ટ્રોનની કક્ષા માટે, L = √[l(l+1)]ħ, જ્યાં l કોણીય ક્વોન્ટમ સંખ્યા છે અને ħ રિડ્યુસ્ડ પ્લાન્ક સ્થિરાંક છે.

  • L = √[l(l+1)]ħ (ક્વોન્ટમ મેકેનિક્સ)
  • l = 0, 1, 2, ..., (n-1)
  • કોણીય સંવેગ ક્વોન્ટાઇઝ્ડ હોય છે
  • ઇલેક્ટ્રોનની કક્ષા માટે લાગુ
🧠 Trick: L = √l(l+1)ħ

અનુપ્રયોગો અને મહત્વ

કોણીય સંવેગનું સંરક્ષણ ખગોળશાસ્ત્ર, અવકાશ યાન ડિઝાઇન, અને કણ ભૌતિકશાસ્ત્રમાં મહત્વનું છે. તે ગ્રહો, તારાઓ, અને ગેલેક્સીઓની ગતિ સમજાવવામાં મદદ કરે છે.

  • ખગોળશાસ્ત્રમાં ગ્રહો અને તારાઓની ગતિ
  • અવકાશ યાનમાં સ્થિરતા અને નિયંત્રણ
  • કણ ભૌતિકશાસ્ત્રમાં કણોની ઘૂર્ણન ગતિ
  • ટેક્નોલોજી અને ઇજનેરીમાં ઉપયોગ

  • સ્કેટરનું ઘૂર્ણન: I↓ ⇒ ω↑ (L સ્થિર)

🎯 Exam Tip: કોણીય સંવેગના સંરક્ષણને સમજવા માટે, ટોર્ક શૂન્ય હોવાની સ્થિતિ અને L = Iω ના સૂત્રને યાદ રાખો. ઉદાહરણો જેવા કે સ્કેટર અને ગ્રહોની ગતિ પર ધ્યાન કેન્દ્રિત કરો.
