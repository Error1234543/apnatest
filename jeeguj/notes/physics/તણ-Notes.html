તાણ

📖 તાણ (Stress)

તાણની વ્યાખ્યા અને પ્રકારો

તાણ એ ટકાઉ પદાર્થ પર લાગતી બળ પ્રતિ એકમ ક્ષેત્રફળ છે. તે બે પ્રકારનો હોય છે: ૧) ખેંચણ તાણ (Tensile Stress) - પદાર્થને ખેંચવા માટે લાગતું બળ. ૨) દબાણ તાણ (Compressive Stress) - પદાર્થને દબાવવા માટે લાગતું બળ.

  • તાણ = બળ / ક્ષેત્રફળ (σ = F/A)
  • ખેંચણ તાણ પદાર્થને લંબાઈમાં વધારે છે
  • દબાણ તાણ પદાર્થને લંબાઈમાં ઘટાડે છે
  • તાણનું SI એકમ: પાસ્કલ (Pa) અથવા N/m²
🧠 Trick: ખેંચો દબાવો, તાણ બનાવો

વિકૃતિ (Strain) અને તેના પ્રકારો

વિકૃતિ એ પદાર્થની લંબાઈ, કદ અથવા આકારમાં થતો સાપેક્ષ ફેરફાર છે. તે પણ બે પ્રકારની હોય છે: ૧) લંબ વિકૃતિ (Longitudinal Strain) - લંબાઈમાં ફેરફાર. ૨) ખેંચણ/દબાણ વિકૃતિ (Tensile/Compressive Strain) - ખેંચણ અથવા દબાણને લીધે થતી વિકૃતિ.

  • વિકૃતિ = ΔL / L (લંબ વિકૃતિ)
  • વિકૃતિ એ એક વિમીય રાશિ છે
  • તાણ અને વિકૃતિ વચ્ચેનો ગુણોત્તર યંગ મોડ્યુલસ (Y) કહેવાય છે
  • વિકૃતિનું કોઈ એકમ નથી
🧠 Trick: લંબાઈ બદલાય, વિકૃતિ થાય

હૂકનો નિયમ (Hooke's Law)

હૂકના નિયમ મુજબ, જ્યાં સુધી પદાર્થની પ્રત્યાસ્થ હદ (Elastic Limit) ન વટાય, ત્યાં સુધી તાણ વિકૃતિના સમપ્રમાણમાં હોય છે. σ = Y × ε, જ્યાં Y એ યંગ મોડ્યુલસ છે.

  • હૂકનો નિયમ: σ ∝ ε (પ્રત્યાસ્થ હદ સુધી)
  • Y = σ / ε (યંગ મોડ્યુલસ)
  • પ્રત્યાસ્થ હદ પાર કરતા પદાર્થ સ્થાયી વિકૃતિ અનુભવે છે
  • Yનું એકમ: પાસ્કલ (Pa) અથવા N/m²
🧠 Trick: હૂકનો નિયમ: તાણ વિકૃતિનો મિત્ર

પ્રત્યાસ્થતા (Elasticity) અને તેના પ્રકારો

પ્રત્યાસ્થતા એ પદાર્થની તે ગુણધર્મ છે જ્યારે બાહ્ય બળ હટાવ્યા પછી પદાર્થ તેની મૂળ આકારમાં પરત ફરે છે. પ્રત્યાસ્થતાની ત્રણ મહત્વની સીમાઓ છે: ૧) પ્રત્યાસ્થ હદ (Elastic Limit), ૨) પ્લાસ્ટિક હદ (Plastic Limit), ૩) તૂટવાની હદ (Breaking Point).

  • પ્રત્યાસ્થ હદ: પદાર્થ સંપૂર્ણપણે પ્રત્યાસ્થ રહે છે
  • પ્લાસ્ટિક હદ: પદાર્થ સ્થાયી વિકૃતિ અનુભવે છે
  • તૂટવાની હદ: પદાર્થ તૂટી જાય છે
  • પ્રત્યાસ્થતા ગુણાંક: Y, η, K

પોઆસોનનો ગુણોત્તર (Poisson's Ratio)

પોઆસોનનો ગુણોત્તર (σ) એ લંબ વિકૃતિ અને પાર્શ્વ વિકૃતિ (Lateral Strain) ના ગુણોત્તરનો નકારાત્મક ગુણ છે. σ = - (Δd/d) / (ΔL/L). તે પદાર્થની પાર્શ્વ દિશામાં થતી વિકૃતિ દર્શાવે છે.

  • પોઆસોનનો ગુણોત્તર: σ = - (પાર્શ્વ વિકૃતિ / લંબ વિકૃતિ)
  • સ્થિર પદાર્થો માટે σની કિંમત 0 થી 0.5 વચ્ચે હોય છે
  • અવિભાજ્ય પદાર્થો માટે σ ≈ 0.5
  • અસંકોચનીય પદાર્થો માટે σ = 0.5
🧠 Trick: પાર્શ્વમાં ઘટે, લંબાઈમાં વધે

તાણ-વિકૃતિ વક્ર (Stress-Strain Curve)

તાણ-વિકૃતિ વક્ર પદાર્થના યાંત્રિક ગુણધર્મો દર્શાવે છે. વક્રના મહત્વના બિંદુઓ: ૧) સમપ્રમાણતાની હદ (Proportional Limit), ૨) પ્રત્યાસ્થ હદ (Elastic Limit), ૩) ઉત્ક્રાંતિ બિંદુ (Yield Point), ૪) અલ્ટિમેટ તાણ (Ultimate Stress), ૫) તૂટવાનું બિંદુ (Breaking Point).

  • સમપ્રમાણતાની હદ: હૂકનો નિયમ લાગુ પડે છે
  • ઉત્ક્રાંતિ બિંદુ: પ્લાસ્ટિક વિકૃતિ શરૂ થાય છે
  • અલ્ટિમેટ તાણ: મહત્તમ તાણ જે પદાર્થ સહન કરે છે
  • તૂટવાનું બિંદુ: પદાર્થ તૂટી જાય છે
🧠 Trick: વક્ર ચડે, પદાર્થ તૂટે

યંગ મોડ્યુલસ, બલ્ક મોડ્યુલસ અને રિગિડિટી મોડ્યુલસ

યંગ મોડ્યુલસ (Y) લંબ તાણ અને વિકૃતિ માટે, બલ્ક મોડ્યુલસ (K) દબાણ તાણ અને કદ વિકૃતિ માટે, રિગિડિટી મોડ્યુલસ (η) અપરૂપણ તાણ (Shear Stress) અને અપરૂપણ વિકૃતિ (Shear Strain) માટે વાપરવામાં આવે છે.

  • Y = તણાવ / લંબ વિકૃતિ
  • K = કદ તણાવ / કદ વિકૃતિ
  • η = અપરૂપણ તણાવ / અપરૂપણ વિકૃતિ
  • તમામ મોડ્યુલસનું એકમ: પાસ્કલ (Pa)
🧠 Trick: Y લંબાઈ, K કદ, η અપરૂપણ

⚡ Quick Revision

  • તાણ = બળ / ક્ષેત્રફળ (σ = F/A)
  • વિકૃતિ = ΔL / L (લંબ વિકૃતિ)
  • હૂકનો નિયમ: σ = Y × ε (પ્રત્યાસ્થ હદ સુધી)
  • યંગ મોડ્યુલસ (Y) = તણાવ / વિકૃતિ
  • પોઆસોનનો ગુણોત્તર (σ) = - (પાર્શ્વ વિકૃતિ / લંબ વિકૃતિ)
  • તાણ-વિકૃતિ વક્રના મહત્વના બિંદુઓ: પ્રત્યાસ્થ હદ, ઉત્ક્રાંતિ બિંદુ, અલ્ટિમેટ તણાવ
  • બલ્ક મોડ્યુલસ (K) = કદ તણાવ / કદ વિકૃતિ
  • રિગિડિટી મોડ્યુલસ (η) = અપરૂપણ તણાવ / અપરૂપણ વિકૃતિ
  • પ્રત્યાસ્થ હદ પાર કરતા પદાર્થ સ્થાયી વિકૃતિ અનુભવે છે
  • તૂટવાની હદે પદાર્થ તૂટી જાય છે
🎯 Exam Tip: તાણ-વિકૃતિ વક્ર અને હૂકના નિયમ પર આધારિત પ્રશ્નો JEE Mainમાં વારંવાર પૂછવામાં આવે છે, તો વક્રના મહત્વના બિંદુઓ અને હૂકના નિયમને યાદ રાખો.
