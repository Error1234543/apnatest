અંતર

📖 અંતર (Distance and Displacement)

અંતર અને વિસ્થાપનનો મૂળભૂત ફરક

અંતર એ ટોટલ પથની લંબાઈ છે જે વસ્તુ એ પસાર કરે છે, જ્યારે વિસ્થાપન એ પ્રારંભિક અને અંતિમ સ્થાન વચ્ચેનો સીધો અંતર છે. અંતર સદિશ રાશિ નથી, જ્યારે વિસ્થાપન સદિશ રાશિ છે.

  • અંતર = કુલ પથલંબાઈ (સ્કેલર રાશિ)
  • વિસ્થાપન = પ્રારંભિક અને અંતિમ સ્થાન વચ્ચેનો સીધો અંતર (સદિશ રાશિ)
  • અંતર કદાચ વિસ્થાપન કરતાં મોટું અથવા સમાન હોઈ શકે
  • વિસ્થાપન શૂન્ય હોઈ શકે પરંતુ અંતર કદી શૂન્ય ન હોય
  • અંતરનો SI એકમ મીટર (m) છે
🧠 Trick: અંતર = પથ, વિસ્થાપન = સીધો રસ્તો

અંતરનો સૂત્ર અને ગણતરી

અંતરની ગણતરી પથની લંબાઈના સરવાળા દ્વારા થાય છે. જો વસ્તુ n ભાગમાં ગતિ કરે તો અંતર = d₁ + d₂ + ... + dₙ. વિસ્થાપનની ગણતરી પાયથાગોરસ પ્રમેય દ્વારા થાય છે જો ગતિ બે પરસ્પર લંબ ક્ષેત્રમાં થાય.

  • અંતર = Σ |Δx| (કુલ પથલંબાઈ)
  • વિસ્થાપન = √(Δx² + Δy²) (બે પરસ્પર લંબ દિશામાં)
  • જો વસ્તુ સરળ રેખામાં ગતિ કરે તો અંતર = |વિસ્થાપન|
  • ગોળાકાર પથ પર અંતર = 2πr, વિસ્થાપન = 0
  • અંતર હંમેશા ધન હોય છે

ગતિના પ્રકાર પ્રમાણે અંતર અને વિસ્થાપન

સરળ રેખીય ગતિમાં અંતર અને વિસ્થાપન સમાન હોઈ શકે. વર્તુળ ગતિમાં એક પૂર્ણ ચક્ર પૂર્ણ કર્યા બાદ વિસ્થાપન શૂન્ય હોય છે, પરંતુ અંતર શૂન્ય નથી. પ્રવેગી ગતિમાં અંતર અને વિસ્થાપન વચ્ચેનો તફાવત વધુ સ્પષ્ટ થાય છે.

  • સરળ રેખીય ગતિ: અંતર = |વિસ્થાપન| જો દિશા ન બદલાય
  • વર્તુળ ગતિ: એક ચક્ર બાદ વિસ્થાપન = 0, અંતર = 2πr
  • પરિવલન ગતિ: અંતર અને વિસ્થાપન બંને બદલાય છે
  • પ્રવેગી ગતિ: અંતર અને વિસ્થાપન વચ્ચેનો તફાવત વધે છે
  • ગતિના પ્રકાર અનુસાર અંતર અને વિસ્થાપન બદલાય છે
🧠 Trick: વર્તુળમાં વિસ્થાપન શૂન્ય, અંતર નહીં

અંતર-સમય ગ્રાફ

અંતર-સમય ગ્રાફ દ્વારા વસ્તુની ગતિનો અભ્યાસ કરવામાં આવે છે. ગ્રાફની ઢાળ વસ્તુની ઝડપ દર્શાવે છે. જો ગ્રાફ સરળ રેખા હોય તો ઝડપ સ્થિર હોય છે. ગ્રાફની ઢાળ શૂન્ય હોય તો વસ્તુ સ્થિર હોય છે.

  • અંતર-સમય ગ્રાફની ઢાળ = ઝડપ
  • સરળ રેખા = સ્થિર ઝડપ
  • આડી રેખા = સ્થિર વસ્તુ (ઝડપ = 0)
  • વક્ર રેખા = બદલાતી ઝડપ
  • ગ્રાફનો x-અક્ષ સમય, y-અક્ષ અંતર દર્શાવે છે
🧠 Trick: ઢાળ = ઝડપ, આડી રેખા = સ્થિર

વિશેષ પ્રશ્નો અને ઉકેલો

જ્યારે વસ્તુ પાછી તેની પ્રારંભિક સ્થિતિમાં આવે ત્યારે અંતર કુલ પથલંબાઈ હોય છે જ્યારે વિસ્થાપન શૂન્ય હોય છે. જો વસ્તુ A બિંદુએથી B બિંદુએ જાય અને પાછી A બિંદુએ આવે તો અંતર = AB + BA, વિસ્થાપન = 0.

  • પાછી પ્રારંભિક સ્થિતિમાં આવવું = વિસ્થાપન = 0
  • અંતર = કુલ પથલંબાઈ
  • જો વસ્તુ ગોળાકાર પથ પર ગતિ કરે તો વિસ્થાપન શૂન્ય
  • અંતર હંમેશા ધન અને વિસ્થાપન ધન, ઋણ અથવા શૂન્ય હોઈ શકે
  • વિસ્થાપનનો મહત્તમ મૂલ્ય અંતર જેટલો હોઈ શકે
🧠 Trick: પાછી આવવું = વિસ્થાપન શૂન્ય

અંતર અને વિસ્થાપનના ઉદાહરણો

જો એક વિદ્યાર્થી 4 m પૂર્વ તરફ અને પછી 3 m ઉત્તર તરફ ચાલે તો અંતર = 4 + 3 = 7 m, વિસ્થાપન = √(4² + 3²) = 5 m. જો એક કાર 10 km ઉત્તર તરફ અને પછી 10 km દક્ષિણ તરફ જાય તો અંતર = 20 km, વિસ્થાપન = 0.

  • પૂર્વ અને ઉત્તર દિશામાં ગતિ = પાયથાગોરસ પ્રમેય
  • સમાન દિશામાં ગતિ = અંતર = કુલ પથલંબાઈ
  • વિપરિત દિશામાં ગતિ = વિસ્થાપન = અંતરનો તફાવત
  • ગોળાકાર પથ = વિસ્થાપન શૂન્ય
  • સરળ રેખીય ગતિ = અંતર = |વિસ્થાપન| જો દિશા ન બદલાય
🧠 Trick: પૂર્વ-ઉત્તર = પાયથાગોરસ, વિપરિત = વિસ્થાપન શૂન્ય

⚡ Quick Revision

  • અંતર = કુલ પથલંબાઈ (સ્કેલર), વિસ્થાપન = સીધો અંતર (સદિશ)
  • અંતર હંમેશા ધન, વિસ્થાપન ધન/ઋણ/શૂન્ય
  • વિસ્થાપન શૂન્ય હોઈ શકે, અંતર કદી નહીં
  • અંતર-સમય ગ્રાફની ઢાળ = ઝડપ
  • વર્તુળ ગતિમાં એક ચક્ર બાદ વિસ્થાપન = 0, અંતર = 2πr
  • પાછી પ્રારંભિક સ્થિતિમાં આવવું = વિસ્થાપન = 0
  • સરળ રેખીય ગતિમાં અંતર = |વિસ્થાપન| જો દિશા ન બદલાય
  • પાયથાગોરસ પ્રમેય વાપરી વિસ્થાપન શોધો જો બે લંબ દિશામાં ગતિ થાય
  • અંતરનો SI એકમ મીટર (m)
  • વિસ્થાપનનો મહત્તમ મૂલ્ય અંતર જેટલો હોઈ શકે
🎯 Exam Tip: પરીક્ષામાં અંતર અને વિસ્થાપન વચ્ચેનો તફાવત સ્પષ્ટ કરવા માટે હંમેશા ઉદાહરણો સાથે સમજાવો, ખાસ કરીને વર્તુળ ગતિ અને પાછી પ્રારંભિક સ્થિતિમાં આવવાના કિસ્સામાં.
