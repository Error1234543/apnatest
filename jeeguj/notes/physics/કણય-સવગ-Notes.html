કોણીય સંવેગ

📖 કોણીય સંવેગ

પરિભાષા અને મૂળભૂત સંકલ્પના

કોણીય સંવેગ એટલે બે વસ્તુઓ વચ્ચેનો ખૂણો જે તેમની ગતિ અથવા સ્થિતિના ફેરફાર દરમિયાન ઉત્પન્ન થતો સંવેગ. તે સદિશ રાશિ છે અને તેનો SI એકમ રેડિયન/સેકન્ડ² (rad/s²) છે. કોણીય સંવેગ, કોણીય વેગના ફેરફારના દર તરીકે વ્યાખ્યાયિત થાય છે.

  • કોણીય સંવેગ (α) = Δω/Δt, જ્યાં ω = કોણીય વેગ
  • SI એકમ: rad/s²
  • સદિશ રાશિ, દિશા હમેશા કોણીય વેગના ફેરફારની દિશામાં હોય છે
  • ઘડિયાળની વિરુદ્દ દિશા ધન અને ઘડિયાળની દિશા ઋણ ગણાય છે
🧠 Trick: α = Δω/Δt → 'અલ્ફા વેગ બદલે'

કોણીય સંવેગ અને રેખીય સંવેગ વચ્ચેનો સંબંધ

રેખીય સંવેગ (a) અને કોણીય સંવેગ (α) વચ્ચેનો સંબંધ a = rα છે, જ્યાં r = વર્તુળની ત્રિજ્યા. આ સંબંધ દર્શાવે છે કે કોણીય સંવેગ વસ્તુની ગતિના વર્તુળાકાર પથ પર નિર્ભર રહે છે.

  • a = rα (r = ત્રિજ્યા)
  • કોણીય સંવેગ સમાન રહે તો રેખીય સંવેગ ત્રિજ્યાના સમપ્રમાણમાં બદલાય
  • વર્તુળ ગતિમાં, કોણીય સંવેગ શૂન્ય હોવા છતાં રેખીય સંવેગ શૂન્ય ન પણ હોઈ શકે (જેમ કે સમાન ગતિમાં)
  • સંવેગનો અભ્યાસ ગતિના નિયમો સાથે સંકળાયેલ છે
🧠 Trick: a = rα → 'અરે, રેડિયસ અલ્ફા'

કોણીય સંવેગના પ્રકારો

કોણીય સંવેગ બે પ્રકારનો હોઈ શકે: ૧) સમાન કોણીય સંવેગ (Uniform Angular Acceleration) અને ૨) અસમાન કોણીય સંવેગ (Non-Uniform Angular Acceleration). સમાન કોણીય સંવેગમાં, કોણીય વેગ સમય સાથે રેખીય રીતે બદલાય છે.

  • સમાન કોણીય સંવેગ: α = constant
  • અસમાન કોણીય સંવેગ: α = f(t)
  • સમાન કોણીય સંવેગમાં, ω = ω₀ + αt (જ્યાં ω₀ = પ્રારંભિક કોણીય વેગ)
  • અસમાન કોણીય સંવેગમાં, સંકલન (integration) વાપરી શકાય

કોણીય સંવેગ અને બળ આઘાત (Torque)

બળ આઘાત (τ) એ કોણીય સંવેગનો મુખ્ય કારણ છે. ન્યૂટનના ગતિના નિયમ અનુસાર, τ = Iα, જ્યાં I = જડત્વનો આઘાત (Moment of Inertia). આ સૂત્ર દર્શાવે છે કે કોણીય સંવેગ, લાગુ પડતા બળ આઘાત અને પદાર્થના જડત્વના આઘાત પર નિર્ભર કરે છે.

  • τ = Iα
  • I = જડત્વનો આઘાત (kg·m²)
  • બળ આઘાત = બળ × લંબ અંતર (τ = r × F)
  • જડત્વનો આઘાત પદાર્થની જડત્વ અને તેની ત્રિજ્યાની વિતરણ પર નિર્ભર કરે છે
🧠 Trick: τ = Iα → 'ટોરક ઇનરશિયા અલ્ફા'

કોણીય સંવેગ અને વર્તુળ ગતિ

વર્તુળ ગતિમાં, કોણીય સંવેગ વસ્તુની ગતિની દિશા અને વેગમાં ફેરફાર લાવે છે. જ્યારે વસ્તુ વર્તુળ પથ પર ગતિ કરે છે, ત્યારે તેના પર કેંદ્રગામી બળ લાગે છે, જે કોણીય સંવેગ ઉત્પન્ન કરે છે.

  • કેંદ્રગામી બળ (F_c) = mω²r અથવા mv²/r
  • કોણીય સંવેગ વર્તુળ ગતિની દિશા બદલવા માટે જવાબદાર છે
  • કોણીય વેગ અને કોણીય સંવેગ વર્તુળ ગતિના અભ્યાસમાં મહત્વપૂર્ણ છે
  • વર્તુળ ગતિ માટે, કોણીય સંવેગ શૂન્ય હોવા છતાં કેંદ્રગામી સંવેગ શૂન્ય નથી

કોણીય સંવેગના ઉદાહરણો

કોણીય સંવેગના વાસ્તવિક જીવનના ઉદાહરણોમાં પંખોનું ફરવું, કારના ચાકાનું ફરવું, અને ગોળાકાર પથ પર દોડતી વસ્તુનો સમાવેશ થાય છે. આ ઉદાહરણોમાં, કોણીય સંવેગ વસ્તુની ગતિની દિશા અને વેગમાં ફેરફાર લાવે છે.

  • પંખોનું ફરવું: સમાન કોણીય સંવેગ
  • કારના ચાકાનું ફરવું: અસમાન કોણીય સંવેગ (બ્રેક લગાડવા પર)
  • ગોળાકાર પથ પર દોડતી વસ્તુ: કોણીય સંવેગ અને કેંદ્રગામી બળ
  • ઘડિયાળની કાંટા: સમાન કોણીય સંવેગ

કોણીય સંવેગ અને ઉર્જા

કોણીય સંવેગ સાથે સંકળાયેલ ઉર્જાનો અભ્યાસ ગતિ ઉર્જા અને સ્થિતિજ ઉર્જા દ્વારા થાય છે. કોણીય ગતિ ઉર્જા = ½Iω², જ્યાં I = જડત્વનો આઘાત અને ω = કોણીય વેગ. કોણીય સંવેગ ફેરફાર થવા પર, ગતિ ઉર્જામાં પણ ફેરફાર થાય છે.

  • ગતિ ઉર્જા (KE) = ½Iω²
  • બળ આઘાત દ્વારા કરવામાં આવેલ કામ, કોણીય સંવેગ ઉત્પન્ન કરે છે
  • કોણીય સંવેગ અને ઉર્જા વચ્ચેનો સંબંધ, ગતિના નિયમો દ્વારા વ્યાખ્યાયિત થાય છે
  • જડત્વનો આઘાત (I) પદાર્થની જડત્વ અને તેની આકાર પર નિર્ભર કરે છે
🧠 Trick: KE = ½Iω² → 'કિનેટિક ઇનરશિયા ઓમેગા સ્ક્વેર'

⚡ Quick Revision

  • કોણીય સંવેગ (α) = Δω/Δt, SI એકમ: rad/s²
  • રેખીય સંવેગ (a) = rα, જ્યાં r = ત્રિજ્યા
  • બળ આઘાત (τ) = Iα, જ્યાં I = જડત્વનો આઘાત
  • સમાન કોણીય સંવેગ: ω = ω₀ + αt
  • વર્તુળ ગતિમાં, કેંદ્રગામી બળ (F_c) = mω²r
  • ગતિ ઉર્જા (KE) = ½Iω²
  • કોણીય સંવેગ સદિશ રાશિ છે, દિશા ωના ફેરફારની દિશામાં
  • ઘડિયાળની વિરુદ્ધ દિશા ધન અને ઘડિયાળની દિશા ઋણ ગણાય
  • કોણીય સંવેગ વર્તુળ ગતિની દિશા બદલવા માટે જવાબદાર
  • જડત્વનો આઘાત (I) પદાર્થની જડત્વ અને આકાર પર નિર્ભર કરે
🎯 Exam Tip: કોણીય સંવેગ અને બળ આઘાત (τ = Iα) વચ્ચેનો સંબંધ યાદ રાખો. આ સૂત્ર પરીક્ષામાં વારંવાર પૂછવામાં આવે છે, ખાસ કરીને વર્તુળ ગતિ અને ઘૂર્ણન ગતિ સંબંધિત પ્રશ્નોમાં.
